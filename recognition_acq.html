CHAPTER 07

바코드·OCR과 모의 영상 취득

인식 결과와 좌표, 모델 준비, 결정적 카메라·PLC 시뮬레이션 계약

인식과 모의 취득 선택

Gray8 영상에서 단일 바코드 또는 지정된 한 줄의 인쇄 문자를 읽습니다. 바코드는 모델이 필요 없고, OCR은 별도 RTen 모델이 필요합니다. 여러 바코드, 자동 줄 검출, 페이지 분석, 한국어, 임의 촬영 조건의 성공률은 지원 계약에 포함되지 않습니다. 실제 카메라 SDK, 장치 열거, 영상 전송, PLC 통신은 구현되지 않았습니다. 모의 계층의 이벤트와 시간은 호출자가 제공하며 대기나 백그라운드 동작이 없습니다.

공통 결과와 바코드

image.read_barcode(spec) / image.ReadBarcode(spec)는 최대 한 심벌을 반환합니다. BarcodeSpec(formats, try_rotate=False, min_contrast=0.0)의 formats는 CODE128=1, CODE39=2, EAN13=4, QR_CODE=8, DATA_MATRIX=16의 비트 OR이며 0은 불가합니다. C# 이름은 Code128, Code39, Ean13, QrCode, DataMatrix이며 All=31도 있습니다. try_rotate는 bool, min_contrast는 유한한 0~1입니다. 현재 입력의 보이는 픽셀만 복사하며 너비와 높이는 양수 및 i32 이하, 면적과 최대 차원의 합은 u32 이하여야 합니다.

대비는 원본의 (최대 픽셀−최소 픽셀)/255이며 문턱과 같으면 통과합니다. 예를 들어 10~110이면 대비는 100/255입니다. 이는 검증 등급이나 정확도 점수가 아닙니다. 문턱 미달 시 백엔드 실행 없이 REJECTED/LOW_CONTRAST입니다. 유효 영상의 미검출은 NO_READ/NOT_FOUND이며 예외가 아닙니다. 디코더가 세부 오류를 합칠 수 있어 체크섬 손상이라고 단정할 수 없습니다.

열거형값과 의미
ReadStatusACCEPTED=1 판정 통과, NO_READ=2 읽을 내용 없음, REJECTED=3 판정 거부
ReadReasonNONE=0, NOT_FOUND=1, LOW_CONTRAST=2, CHARSET=4, LENGTH=8, EMPTY=16. OR 조합 가능
BarcodeReadstatus, reasons; format은 발견 형식 또는 None; quarter_turns는 성공한 명시적 회전 수; text는 Unicode; backend_raw_bytes는 백엔드 종속 바이트; points는 가변 개수의 위치; contrast; confidence는 현재 항상 None

raw bytes는 반드시 원래 payload나 UTF-8이 아니며 Code39에서 비어 있을 수 있습니다. 점은 형식별 탐색점으로 사각형의 개수나 순서를 보장하지 않습니다. try_rotate 시 원본, 시계 90°, 180°, 270° 순으로 첫 결과를 선택합니다. false여도 백엔드 내부 회전 가능성이 있어 quarter_turns는 심벌의 전체 방향이 아닙니다.

RecognitionPoint.local은 현재 이미지 기준, global_(C# Global)은 입력 이미지 origin을 더한 좌표입니다. 회전된 영상의 중심점 (u,v)을 원본 w,h로 역변환하면 q=0: (u,v), 1: (v,h−1−u), 2: (w−1−u,h−1−v), 3: (w−1−v,u)입니다. 원본이 ROI이면 global은 부모 기준이 됩니다.

OCR 준비와 판독

OcrRegionSpec(roi, quarter_turns=0, light_text=False, normalize=False)의 roi는 현재 이미지 기준 (x,y,width,height) 정수 튜플이며 half-open입니다. x,y는 0 이상, 너비와 높이는 양수이고 영역 전체가 이미지 안이어야 합니다. 차원은 i32 이하, 면적은 u32 이하입니다. quarter_turns는 시계 방향 90° 단위 0~3, 두 플래그는 bool입니다. C#은 new OcrRegionSpec(x,y,width,height,quarterTurns,lightText,normalize)입니다.

image.prepare_ocr(region_spec) / image.PrepareOcr(spec)는 독립 연속 Gray8 영상의 소유 결과를 만듭니다. light_text는 255−p 반전, normalize는 반전 후 비단색 픽셀의 최솟값과 최댓값을 0과 255로 선형 매핑하고 중간값을 올려 반올림합니다. 단색은 반전 후 그대로입니다. contrast는 두 처리 전 ROI 기준입니다. OcrEngine.load(path) / OcrEngine.Load(path)는 호출자가 준비한 로컬 RTen 모델을 로드합니다. 자동 다운로드하지 않으며 모델 출처와 라이선스는 사용자 책임입니다. 입력은 NCHW rank 4, batch 1 또는 동적, 고정 채널 1, 높이 1~4096, 폭 비영이어야 합니다. 출력 shape 메타데이터가 있으면 rank 3과 기본 alphabet 96자 및 blank에 맞는 97 label 등을 검사합니다. 검사 통과가 추론 성공을 보증하지 않습니다. 경로 오류, 손상 모델과 백엔드 실패는 예외이며 모델과 이미지를 context manager 또는 using으로 해제합니다.

OcrSpec(region, min_contrast, min_length, max_length, allowed_chars)는 유한한 대비 0~1, 1 ≤ min_length ≤ max_length, 비어 있지 않은 출력 가능 ASCII 0x20~0x7e 문자열을 요구합니다. 길이는 UTF-8 바이트가 아닌 Unicode scalar 수입니다. image.read_text(engine, spec) / image.ReadText(engine,spec)는 지정 ROI 전체를 한 줄로 판독합니다. allowed_chars는 모델의 출력을 제한하지 않고 결과를 검사합니다. 공백을 포함한 문자를 제거·정규화하지 않습니다. CHARSET과 LENGTH는 OR 가능하며 거부해도 예측 내용은 보존합니다. 대비 미달은 REJECTED/LOW_CONTRAST, 단색이나 빈 결과는 NO_READ/NOT_FOUND|EMPTY입니다.

OcrRead는 status, reasons, text, chars, contrast, confidence를 소유한 스냅샷입니다. confidence는 현재 항상 None(null)이며 0점과 다릅니다. OcrChar.codepoint는 Unicode 코드 포인트, corners는 각각 local/global을 갖는 네 경계점입니다. 텍스트 순서와 공백을 보존하며 클리핑된 근사 사각형이지 정밀 윤곽은 아닙니다. 바코드 및 OCR 결과 문자열과 점은 원본 해제 후에도 유지됩니다.

다음은 실제 판독을 위한 부분 예제입니다. 별도 호환 모델과 한 줄을 포함한 Gray8 이미지가 필요하며 모델 없이 실행되는 아래 전체 예제와는 다릅니다.

with OcrEngine.load(model_path) as engine:
    result = image.read_text(engine, OcrSpec(
        OcrRegionSpec((x, y, width, height)), 0.1, 1, 20,
        "ABCDEFGHIJKLMNOPQRSTUVWXYZ 0123456789"))
    if result.status == ReadStatus.ACCEPTED:
        print(result.text)

각 변환은 anchor_host_ns + round((device_ticks−anchor_ticks) × 1,000,000,000 / tick_hz)입니다. 부호 있는 정수 계산이며 정확한 절반은 0에서 먼 쪽으로 반올림합니다. 범위나 산술 overflow는 오류입니다. ClockComparison의 a_ns, b_ns는 변환 시간, skew_ns는 절대 차, total_uncertainty_ns는 두 불확실성 합, within_tolerance는 skew + 합 ≤ tolerance입니다. 예를 들어 skew 500 ns와 불확실성 3+4 ns는 허용치 507 ns에 통과합니다. 맵은 호출자 제공값이며 공통 domain만으로 동기화나 PTP 성능을 입증하지 않습니다.

PlcDisposition은 APPLIED=1, DUPLICATE=2, NO_CHANGE=3, TIMED_OUT=4입니다. Request/Publish/Ack는 기한을 자동 검사하지 않으므로 적절한 시점에 Poll을 호출해야 합니다. Faulted에서 반복 Poll은 timeout을 다시 세지 않습니다. PlcInfo는 state, result_code, request_id, last_request_id, timeout_ns, started_ns, last_ns, stats이며 PlcStats는 requests, published, acks, duplicates, timeouts, resets입니다.

잘못된 상태·범위·역행 시간·오버플로는 예외입니다. 유효하지 않은 모의 명령은 상태·통계·시각을 변경하지 않습니다. Python은 타입 오류에 TypeError, 값 오류에 ValueError 또는 네이티브 ZVisionError가 날 수 있습니다. 실패한 읽기와 유효한 NO_READ를 구별하십시오.

from zvision import (ZImage, BarcodeSpec, BarcodeFormat, ReadStatus, ReadReason,
                     SimulatedCamera, CameraSpec, TriggerMode, OfferDisposition,
                     SimulatedPlc, PlcOperation, PlcDisposition)

with ZImage.from_gray8(8, 8, bytes([127] * 64)) as image:
    result = image.read_barcode(BarcodeSpec(BarcodeFormat.QR_CODE))
    assert result.status == ReadStatus.NO_READ and result.reasons == ReadReason.NOT_FOUND
    with SimulatedCamera.create(CameraSpec(1, 2, 1000, 2, TriggerMode.SOFTWARE)) as camera:
        camera.connect(); camera.start(); camera.trigger(1, 100)
        assert camera.offer_frame(image, 1, 10, 101, 1) == OfferDisposition.ACCEPTED
        with camera.try_get_frame() as frame:
            assert frame.info.frame_id == 1
            with frame.image as captured:
                assert captured.to_array_gray8() == bytes([127] * 64)
        assert camera.try_get_frame() is None
    with SimulatedPlc.create(10) as plc:
        assert plc.command(PlcOperation.REQUEST, 1, 0, 100) == PlcDisposition.APPLIED
        assert plc.command(PlcOperation.PUBLISH, 1, 42, 101) == PlcDisposition.APPLIED
        assert plc.command(PlcOperation.ACK, 1, 0, 102) == PlcDisposition.APPLIED
        assert plc.info.stats.acks == 1
print('No barcode; simulated frame and PLC handshake succeeded')

using System;
using ZVision;
namespace ManualExamples;
public static class RecognitionAcq
{
    public static void Run()
    {
        var pixels = new byte[64]; for (int i = 0; i < pixels.Length; i++) pixels[i] = 127;
        using var image = ZImage.FromGray8(8, 8, pixels);
        var read = image.ReadBarcode(new BarcodeSpec(BarcodeFormat.QrCode));
        if (read.Status != ReadStatus.NoRead || read.Reasons != ReadReason.NotFound) throw new Exception("Expected no barcode");
        using var camera = SimulatedCamera.Create(new CameraSpec(1, 2, 1000, 2, TriggerMode.Software));
        camera.Connect(); camera.Start(); camera.Trigger(1, 100);
        if (camera.OfferFrame(image, 1, 10, 101, 1) != OfferDisposition.Accepted) throw new Exception("Offer failed");
        using (var frame = camera.TryGetFrame() ?? throw new Exception("Missing frame"))
        {
            if (frame.Info.FrameId != 1) throw new Exception("Wrong frame");
            using var captured = frame.Image;
        }
        if (camera.TryGetFrame() != null) throw new Exception("Queue was not empty");
        using var plc = SimulatedPlc.Create(10);
        if (plc.Command(PlcOperation.Request, 1, 0, 100) != PlcDisposition.Applied ||
            plc.Command(PlcOperation.Publish, 1, 42, 101) != PlcDisposition.Applied ||
            plc.Command(PlcOperation.Ack, 1, 0, 102) != PlcDisposition.Applied || plc.Info.Stats.Acks != 1) throw new Exception("PLC handshake failed");
        Console.WriteLine("No barcode; simulated frame and PLC handshake succeeded");
    }
}
