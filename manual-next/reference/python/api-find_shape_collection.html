Python API · find_shape_collection

find_shape_collection 멤버와 선언

공개 타입

zvision.find_shape_collection: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_collection.find_shape_collection.

Search <=64 models using common options, total pose budget and optional oriented IoU suppression.

공유 포즈 예산으로 여러 형상 모델을 검색합니다.

Python
find_shape_collection(source, entries, options, *, total_budget, max_results, overlap=<ShapeOverlapMode.DISABLED: 0>, max_iou=1.0, mask=None)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • entries · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • total_budget · KEYWORD_ONLY · 기본값 없음
  • max_results · KEYWORD_ONLY · 기본값 없음
  • overlap · KEYWORD_ONLY · 기본값 <ShapeOverlapMode.DISABLED: 0>
  • max_iou · KEYWORD_ONLY · 기본값 1.0
  • mask · KEYWORD_ONLY · 기본값 None

확인된 인자 조건

source
검색 ZImage입니다.
entries
고유 ID와 형상 모델을 담은 1..64개 항목입니다.
options
AdvancedMatchOptions 값입니다. x·y·angle·scale_x·scale_y에 각각 SearchAxis(minimum, maximum, step)를 지정합니다. 일반 검색에서 x·y는 검색 ROI 로컬 픽셀, angle은 라디안이며 scale은 양수입니다. candidate_budget은 평가 포즈 수 상한입니다. 항목별 별도 설정이 아닌 모든 형상 모델의 공통 설정입니다. total_budget은 별도의 전체 포즈 예산입니다.
total_budget
전체 평가 포즈 예산 1..1000000입니다.
max_results
반환 상한 1..256입니다.
overlap
ShapeOverlapMode 억제 범위이며 기본값 DISABLED입니다.
max_iou
겹침 허용 IoU 0..1이며 기본값 1입니다.
mask
선택 검색 마스크이며 기본값 None입니다.

반환: 독립 ShapeCollectionResult입니다.

오류: 중복 ID 또는 검색 설정·예산 오류를 보고합니다.

overlap: 정수 검사 · 최소 0.

total_budget: 정수 검사 · 최소 1.

max_results: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
