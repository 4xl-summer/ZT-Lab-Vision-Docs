    병합된 성분의 값

    BlobMergedTileBlob은 가로로 이어 붙인 타일에서 다시 연결된 성분의 area와 centroid_x, centroid_y를 담습니다. area는 병합 결과에 속한 전경 픽셀 수이고 중심은 결합 영상 로컬 좌표의 픽셀 중심 평균입니다. 각 타일에서 별도로 계산한 중심과 좌표 기준이 다릅니다.

    경계에서 이어진 경우

    왼쪽 타일의 오른쪽 끝과 오른쪽 타일의 왼쪽 끝이 연결되면 하나의 성분으로 합쳐질 수 있습니다. 예를 들어 합쳐진 좌표의 두 픽셀이 (1,0), (2,0)이면 면적은 2이고 중심은 (1.5,0)입니다. 오른쪽 타일의 로컬 좌표를 그대로 평균하면 위치가 어긋납니다.

    연결성과 판독

    가로 타일 병합 시 선택한 4 또는 8 연결성에 따라 경계의 대각선 접촉이 같은 성분이 되는지가 달라질 수 있습니다. 블롭 수만 보지 말고 레이블 맵과 면적, 중심을 함께 확인합니다. ROI와 결합 영상의 시작점을 기록해 원본에 올바르게 표시합니다.

    한계

    이 결과는 입력 타일의 전경 마스크와 연결 조건에 대한 측정입니다. 타일이 서로 잘 정렬되었는지 또는 검출된 물체가 실제 하나인지까지 자동으로 입증하지는 않습니다.
