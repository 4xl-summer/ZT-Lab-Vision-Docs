Python API · encode_lens

encode_lens 멤버와 선언

공개 타입

zvision.encode_lens: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.encode_lens.

Encode a Brown lens in the 84-byte version-1 little-endian CRC format.

Brown 렌즈를 버전 1 이진 형식으로 인코딩합니다.

Python
encode_lens(lens)

인자 선언

  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

lens
유효한 LensModel입니다.

반환: CRC가 포함된 84바이트 little-endian bytes입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: RuntimeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    encode_lens는 Brown 렌즈 모델을 버전 1의 리틀 엔디언 CRC 포함 바이트 형식으로 인코딩합니다. 결과는 정확히 84바이트인 Python bytes입니다. 영상이나 카메라 장치의 상태를 저장하는 함수가 아니라 렌즈 모델 값을 보관하고 전달하는 함수입니다. 복원할 때는 대응하는 decode_lens를 사용합니다.

    구체 사례와 판독

    예를 들어 보정한 렌즈를 인코딩해 파일에 바이너리로 기록하고 다음 실행에서 그대로 읽어 디코딩할 수 있습니다. 문자열로 변환하거나 일부 바이트를 누락하면 원래의 84바이트 데이터와 달라집니다. 파일을 열 때 바이너리 모드를 사용하고 디코딩 결과의 초점 거리, 주점과 왜곡 계수가 기대한 모델과 일치하는지 확인하세요.

    적용 시 확인

    인코딩된 바이트를 사람이 읽는 설명이나 설정 파일에 넣을 때는 바이트를 보존하는 인코딩과 복구 절차가 별도로 필요합니다. 원본 84바이트를 그대로 전달하는 것이 가장 직접적인 왕복입니다. 렌즈에 해당하는 카메라와 영상 해상도도 함께 기록해 다른 카메라의 보정값으로 잘못 사용하는 일을 방지하세요. 보관 후 다시 읽은 바이트의 길이가 84인지와 실제 모델 값의 왕복 결과를 함께 비교하면 전송 경로의 실수를 찾을 수 있습니다.
