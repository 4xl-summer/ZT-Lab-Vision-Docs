dot_grid_svg 멤버와 선언

공개 타입

zvision.dot_grid_svg: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.dot_grid_svg.

Generate a physical-size, unencoded dot-grid SVG document in millimeters.

물리 크기를 지정한 점 격자 SVG 문서를 만듭니다.

Python
dot_grid_svg(grid, diameter, margin)

인자 선언

  • grid · POSITIONAL_OR_KEYWORD · 기본값 없음
  • diameter · POSITIONAL_OR_KEYWORD · 기본값 없음
  • margin · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

grid
최소 2행 2열이며 최대 4096점인 MetricGrid입니다.
diameter
격자 길이 단위의 양의 점 직경이며 두 pitch보다 작아야 합니다.
margin
격자 길이 단위의 여백으로 직경의 절반 이상이어야 합니다.

반환: 밀리미터 크기의 SVG 문자열입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

diameter: 유한한 수 검사.

margin: 유한한 수 검사.

래퍼에서 발생 가능한 오류: RuntimeError, TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    dot_grid_svg는 평면 보정에 사용할 점 격자의 SVG를 생성합니다. grid로 점의 행과 열, 간격 및 단위를 정하고 diameter와 margin을 지정합니다. 최소 2×2의 점이 필요하고 총 점 수는 4096 이하이며 지름은 양수이고 격자 간격보다 작아야 합니다. 여백은 적어도 지름의 절반이어야 점의 외곽이 잘리지 않습니다.

    구체 사례와 판독

    예를 들어 간격이 10 mm인 격자에서 지름 4 mm를 선택하면 인접 점 중심 간 거리는 10 mm이고 점 외곽 간 거리는 6 mm입니다. 최소 여백 2 mm는 가장자리 점의 반지름에 해당합니다. SVG를 출력한 후 프린터의 자동 맞춤이나 배율 변경이 실제 치수를 바꿀 수 있으므로 인쇄물의 기준 길이를 직접 확인하세요.

    적용 시 확인

    출력된 SVG의 화면 표시 크기와 실물 인쇄 크기는 같다고 보장할 수 없습니다. 인쇄 설정의 용지 맞춤을 끄고 두 점 중심 사이 거리를 자로 확인한 뒤 보정에 사용하세요. 점 격자 자체에는 식별 코드가 없으므로 패턴의 방향과 행·열 대응을 관측 과정에서 별도로 확인해야 합니다. 지름과 여백도 격자와 같은 길이 단위로 해석해야 합니다. 저장한 SVG와 인쇄한 종이의 실제 간격을 모두 기록하세요. 입력의 좌표와 값을 기록해 결과를 다시 확인할 수 있습니다.
