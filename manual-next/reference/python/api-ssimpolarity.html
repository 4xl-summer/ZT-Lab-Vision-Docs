사용 조건과 흐름

SsimPolarity는 기준 영상에 비해 검사 영상이 밝아지거나 어두워지는 방향을 결함 판정에 어떻게 반영할지 고릅니다. BOTH는 양방향, BRIGHTER는 밝아진 방향, DARKER는 어두워진 방향을 선택합니다. 국소 SSIM 윈도나 기준 점수와는 별도의 설정입니다.

구체 사례와 결과 판독

예를 들어 밝은 배경에서 어두운 흠집을 찾는다면 어두워지는 방향을 살펴볼 수 있습니다. 반대로 밝은 이물과 어두운 흠집을 모두 검사한다면 양방향 선택이 필요할 수 있습니다. 실제 기준과 검사 영상의 순서를 확인하고 알려진 결함을 사용해 선택한 극성이 기대한 마스크를 만드는지 검증하세요.

적용 시 확인

BRIGHTER와 DARKER는 기준 대비 변화의 방향을 지정하므로 입력 순서를 바꾸면 같은 물리적 결함도 반대 방향으로 보일 수 있습니다. 유사도 점수와 극성 기반 결함 마스크를 구분하고, 검사 기준과 실제 결함의 밝기 관계를 작은 합성 영상으로 확인하세요. 예를 들어 기준 밝기 100에서 검사 밝기 120이면 밝아진 방향이고 80이면 어두워진 방향입니다. 실제 SSIM 판정은 단순한 한 픽셀 차이가 아니라 국소 윈도와 설정을 사용하므로 이 예는 방향만 설명합니다. 두 방향의 결함 사례를 따로 시험하세요.
