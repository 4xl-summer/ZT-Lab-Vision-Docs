Successful generation, settings dirty flag and current-result availability.

Python
BlobContextState(generation: int, dirty: bool, has_current: bool) -> None

  • generation · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • dirty · POSITIONAL_OR_KEYWORD · 타입 <class 'bool'> · 기본값 없음
  • has_current · POSITIONAL_OR_KEYWORD · 타입 <class 'bool'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

BlobContextState(<class 'int'>, <class 'bool'>, <class 'bool'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    generationint필수계산 세대 번호입니다.
    dirtybool필수마지막 계산 이후 기하 설정이 변경되었는지 나타냅니다.
    has_currentbool필수현재 결과가 저장되어 있는지 나타냅니다.

    재사용 컨텍스트 상태

    BlobContextState는 generation, dirty, has_current를 통해 재사용하는 Blob 컨텍스트의 계산 상태를 설명합니다. generation은 성공한 계산의 세대 번호이고 dirty는 마지막 계산 이후 기하 설정이 변경되었는지를 나타냅니다. has_current는 현재 저장된 결과가 있는지 표시합니다.

    계산 순서

    설정을 정하고 분석을 수행한 뒤 상태를 확인해 현재 결과를 읽습니다. 이후 기하 설정을 바꾸면 이전 계산의 조건과 현재 설정이 달라질 수 있으므로 dirty를 확인하고 새 계산이 필요한지 판단합니다. 결과 유무와 설정 변경 여부는 서로 다른 질문입니다.

    세대의 의미

    예를 들어 계산 결과를 저장할 때 generation도 함께 기록하면 어느 성공 계산에서 얻은 값인지 구별하는 데 도움이 됩니다. 세대 번호는 객체의 영구 ID나 영상 내용의 품질 점수가 아닙니다. 두 다른 컨텍스트의 번호가 같다는 것만으로 같은 결과라고 볼 수 없습니다.

    결과 사용

    has_current와 dirty를 살핀 뒤 label과 area 등 필요한 항목을 읽고 영상 및 설정 정보와 함께 저장합니다. 설정과 계산의 수명을 구분하면 오래된 결과를 새 조건의 결과로 오인하는 실수를 줄일 수 있습니다.
