Python API · arc_profile

arc_profile 멤버와 선언

공개 타입

zvision.arc_profile: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._arc_profile.arc_profile.

Return independent arc samples; release the native result after copying.

Raises for invalid geometry, unsupported image, out-of-ROI samples, or work limit.

원호의 각 위치에서 반경 방향 강도 평균을 구합니다.

Python
arc_profile(image, spec)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
지원 그레이스케일 ZImage.
spec
ROI 로컬 ArcProfileSpec; 유효 반경·각도와 표본 수 필요.

반환: 독립 ArcProfileSample 튜플.

오류: 유효하지 않은 설정, 범위 밖 샘플 또는 작업 예산 초과는 오류.

래퍼에서 발생 가능한 오류: RuntimeError, TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    영상의 원호를 따라 여러 중심 위치를 배치하고 각 위치에서 반경 방향 강도를 평균한 표본을 반환합니다. image는 지원되는 그레이 영상이고 spec은 ROI 로컬 중심과 원호 기하, 표본 수 등 검색 조건을 정합니다. 반환된 각 ArcProfileSample은 위치, 원호를 따라간 픽셀 거리, 평균 강도를 가집니다. 예를 들어 반경 2픽셀의 90도 원호는 중심선을 따라 π픽셀 길이이므로, x 좌표 차이 하나만으로 진행 거리를 대신할 수 없습니다. 원호 방향은 표본의 순서와 거리 기준에 영향을 주므로 시작과 끝 각도를 함께 기록합니다. 반경 방향 평균에 필요한 표본이 ROI 밖이면 호출이 실패할 수 있습니다. 오류가 발생한 경우를 강도 0의 정상 표본이나 에지가 없다는 결과로 치환하지 마십시오. 원호 기하, 이미지 형식, 표본 범위와 작업 제한을 순서대로 점검합니다. 래퍼는 네이티브 결과를 복사한 뒤 해제하며 반환된 표본은 독립적으로 보관할 수 있습니다. 두 프레임을 비교할 때는 ROI 원점, 원호 중심과 반경, 샘플 수를 같게 유지해야 강도 변화가 설정 차이로 생긴 것은 아닌지 구분할 수 있습니다. 원호를 따라 정해진 여러 점의 강도 배열이 만들어지는 것이며 자동으로 형상 피팅까지 완료되는 것은 아닙니다. 후속 검출은 별도 단계로 확인합니다.
