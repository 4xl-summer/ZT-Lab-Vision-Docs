Python API · decode_yolo_tensor

decode_yolo_tensor 멤버와 선언

공개 타입

zvision.decode_yolo_tensor: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._ai_advanced.decode_yolo_tensor.

Decode a flat candidate- or attribute-major raw YOLO tensor.

Coordinates must be center form in options. Logits use independent sigmoid;
the class score is multiplied by objectness when supplied.

평탄화 YOLO 텐서를 검출 결과로 변환합니다.

Python
decode_yolo_tensor(values, candidates, classes, transform, options, *, attributes_first=False, logits=False, has_objectness=True)

인자 선언

  • values · POSITIONAL_OR_KEYWORD · 기본값 없음
  • candidates · POSITIONAL_OR_KEYWORD · 기본값 없음
  • classes · POSITIONAL_OR_KEYWORD · 기본값 없음
  • transform · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • attributes_first · KEYWORD_ONLY · 기본값 False
  • logits · KEYWORD_ONLY · 기본값 False
  • has_objectness · KEYWORD_ONLY · 기본값 True

확인된 인자 조건

values
유한 float 값, candidates×(4+objectness 유무+classes)개
candidates
후보 수 0 이상
classes
양의 클래스 수
transform
prepare_image 좌표 복원 변환
options
중심 좌표 형식과 크기·NMS DecodeOptions
attributes_first
True면 속성 우선 배열
logits
True면 점수에 sigmoid 적용
has_objectness
True면 objectness 성분 포함

반환: 독립 AiDetection 리스트

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
