Python API · ColorQuery

ColorQuery 멤버와 선언

공개 타입

zvision.ColorQuery: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._color.ColorQuery.

Mutable builder: append methods return self; clone() creates an independent plan.

Aliases observe later appends. Failed appends leave the plan unchanged. Rust
consumes the previous plan instead, so use clone() explicitly to fork.

이 Query는 변경 가능한 계획입니다. 단계 추가는 같은 객체를 갱신하므로 별칭에도 반영됩니다. 분기하려면 clone()을 사용하고 execute()로 실행합니다. 실행과 Query는 각각 닫아야 합니다. 실패한 단계 추가는 기존 계획을 바꾸지 않습니다.

Python
ColorQuery()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

clone

method · 선언 타입 zvision._query._Query · 상속

Python
clone(self)

다른 계획과 독립적으로 확장할 수 있는 계획 복제본을 만듭니다.

반환: 같은 종류의 독립 소유 계획이며 close합니다.

오류: 닫힌 계획 또는 네이티브 실행 실패는 오류입니다.

Return an independent plan that can be extended without changing this one.

execute

method · 선언 타입 zvision._color.ColorQuery

Python
execute(self) -> 'QueryResourceExecution[ColorPlanesResult]'

지연 색상 계획을 실행합니다.

반환: QueryResourceExecution이며 acquire_output으로 얻은 ColorPlanesResult와 실행을 각각 close합니다.

오류: 닫힌 계획 또는 네이티브 실행 실패는 오류입니다.

반환 타입 주석: QueryResourceExecution[ColorPlanesResult]

Execute; acquire_output returns independently owned color planes.
