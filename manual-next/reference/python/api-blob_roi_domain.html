Python API · blob_roi_domain

blob_roi_domain 멤버와 선언

공개 타입

zvision.blob_roi_domain: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_roi_domain.blob_roi_domain.

Return an independent strict or axis-aligned bounding-box ROI mask.

이진 ROI를 엄격 마스크 또는 전경의 축 정렬 경계 사각형으로 만듭니다.

Python
blob_roi_domain(mask, bounding_box, work_budget)

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • bounding_box · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

mask
Gray8 마스크, 비제로가 전경.
bounding_box
True면 전경의 경계 사각형, False면 전경을 정규화.
work_budget
최소 3 × 픽셀 수를 포함하는 양의 작업 예산.

반환: 원점·크기를 보존하는 독립 소유 Gray8 영상이며 close합니다.

오류: 부적합한 형식·크기·인수 또는 작업 한도 위반은 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
