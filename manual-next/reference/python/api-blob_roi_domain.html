blob_roi_domain 멤버와 선언

공개 타입

zvision.blob_roi_domain: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_roi_domain.blob_roi_domain.

Return an independent strict or axis-aligned bounding-box ROI mask.

이진 ROI를 엄격 마스크 또는 전경의 축 정렬 경계 사각형으로 만듭니다.

Python
blob_roi_domain(mask, bounding_box, work_budget)

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • bounding_box · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

mask
Gray8 마스크, 비제로가 전경.
bounding_box
True면 전경의 경계 사각형, False면 전경을 정규화.
work_budget
최소 3 × 픽셀 수를 포함하는 양의 작업 예산.

반환: 원점·크기를 보존하는 독립 소유 Gray8 영상이며 close합니다.

오류: 부적합한 형식·크기·인수 또는 작업 한도 위반은 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    blob_roi_domain은 이진 ROI 마스크를 엄격한 영역 또는 축 정렬 경계 상자 영역으로 변환한 독립 마스크를 반환합니다. bounding_box는 bool이고 work_budget은 양수입니다. False는 원래 마스크 영역을 따르는 해석이고 True는 포함된 영역을 감싸는 경계 상자를 사용합니다. 결과 영상은 소유 객체로 정리해야 합니다.

    구체 사례와 결과 판독

    예를 들어 3×3 마스크에서 왼쪽 위와 오른쪽 아래 두 픽셀만 포함된다면 엄격한 영역에는 두 위치만 들어갑니다. 두 점을 감싸는 축 정렬 상자는 전체 3×3 영역이므로 가운데 같은 원래 제외 픽셀도 포함됩니다. 블롭 계산 전에 어느 영역을 의도했는지와 작업 예산을 확인하세요.

    적용 시 확인

    경계 상자의 넓이는 원래 마스크의 포함 픽셀 수와 다를 수 있습니다. 예시에서는 엄격한 2픽셀과 상자 9픽셀을 구분합니다. 블롭이 원래 제외 영역을 통해 연결될 가능성도 있으므로 결과를 사용한 연결 성분의 수와 범위를 다시 확인하세요. 경계 상자 모드에서 작은 틈이 채워지는 것이 목적에 맞을 수도 있지만, 원래 ROI 밖의 픽셀을 검사하지 않아야 한다면 엄격한 영역을 선택해야 합니다. 반환 마스크의 실제 픽셀을 확인하세요.
