    incompletebool필수공유 예산 때문에 검색이 미완료되었는지 나타냅니다.

    사용 맥락과 결과 해석

    한 특징 모델의 반복 인스턴스 검색에서 얻은 독립 instances 튜플, 총 가설 평가 수와 incomplete 상태입니다. evaluated는 실제 물체의 수가 아닙니다. incomplete가 참이면 공유 가설 예산 등으로 나머지 검색이 끝나지 않았다는 상태이므로 빈 목록을 전체 탐색 결과로 단정하지 않습니다.

    각 FeatureInstance의 행렬은 모델 로컬에서 검색 영상 로컬로 가며 대응점과 내점 수를 제공합니다. 예를 들어 두 결과가 있다면 각각의 행렬을 별도로 적용하고 같은 객체의 중복인지 검사합니다. 사용한 검색 옵션에서 mutual=False가 필요합니다. 결과는 네이티브 결과를 복사한 값이지만 입력 모델과 영상은 검색을 수행하는 동안 열려 있어야 합니다.

    복수 후보의 위치를 같은 원본 영상에 표시할 때는 검색 ROI 원점을 반영합니다.

    값을 확인하는 순서

    instances 항목: 검출된 인스턴스의 독립 불변 튜플입니다. evaluated 항목: 평가된 가설의 총수입니다. incomplete 항목: 공유 예산 때문에 검색이 미완료되었는지 나타냅니다.

    항목읽을 때 확인할 내용
