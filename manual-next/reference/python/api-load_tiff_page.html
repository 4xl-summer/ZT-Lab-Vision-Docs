Python API · load_tiff_page

load_tiff_page 멤버와 선언

공개 타입

zvision.load_tiff_page: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._io_advanced.load_tiff_page.

Read a zero-based TIFF page into a new owned ZImage.

TIFF의 지정 페이지를 새 영상으로 읽습니다.

Python
load_tiff_page(path, index=0)

인자 선언

  • path · POSITIONAL_OR_KEYWORD · 기본값 없음
  • index · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

path
TIFF 파일 경로입니다.
index
0부터 시작하는 페이지 정수이며 기본값은 0입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    load_tiff_page는 여러 페이지가 있는 TIFF에서 지정한 한 페이지를 읽어 영상 객체를 돌려줍니다. index는 0부터 시작하며 생략하면 0입니다. 파일 경로와 페이지 인덱스를 함께 지정하고, 받은 영상의 크기와 픽셀 형식을 확인한 뒤 후속 처리에 전달합니다. 반환 영상은 소유 객체이므로 사용 후 해당 언어의 자원 정리 방법을 적용합니다.

    구체 사례와 판독

    예를 들어 순서대로 저장된 세 페이지 중 가운데를 읽으려면 index=1을 사용합니다. index=2는 세 번째 페이지이며 페이지 수가 두 개인 파일의 index=2는 유효한 페이지가 아닙니다. 여러 페이지를 읽으려면 필요한 각 인덱스를 별도로 요청하고 반환된 객체 각각의 수명을 관리하세요. 파일을 열 수 없거나 인덱스가 범위를 벗어난 경우에는 빈 이미지라고 가정하지 말고 오류를 확인해야 합니다.

    적용 시 확인

    페이지마다 서로 다른 크기나 형식을 가질 수 있으므로 첫 페이지만 보고 뒤 페이지의 크기를 추정하지 말고 필요한 페이지에서 확인합니다. 처리 순서와 페이지 번호가 중요하다면 인덱스를 로그에 남기세요. 페이지를 다시 읽었을 때 어느 입력으로 계산한 결과인지 확인하는 데 도움이 됩니다. 읽은 영상은 다음 호출 전에 해제하지 않도록 주의하세요.
