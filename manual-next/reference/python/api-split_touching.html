Python API · split_touching

split_touching 멤버와 선언

공개 타입

zvision.split_touching: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._region_topology.split_touching.

Generate distance maxima markers and split using the bounded watershed.

거리 최대점의 마커와 워터셰드로 접촉 영역을 나눕니다.

Python
split_touching(image, options=SplitOptions(connectivity=8, border=<SplitBorder.OUTSIDE_BACKGROUND: 1>, exclude_border_peaks=False, tie=<TopologyTie.DAM: 0>, spacing_x=1.0, spacing_y=1.0, min_height=1.0, min_prominence=0.0, min_peak_distance=1.0, min_region_size=1, max_markers=64, work_budget=100000000))

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 SplitOptions(connectivity=8, border=<SplitBorder.OUTSIDE_BACKGROUND: 1>, exclude_border_peaks=False, tie=<TopologyTie.DAM: 0>, spacing_x=1.0, spacing_y=1.0, min_height=1.0, min_prominence=0.0, min_peak_distance=1.0, min_region_size=1, max_markers=64, work_budget=100000000)

확인된 인자 조건

image
ZImage 입력 영상
options
SplitOptions; 연결성·경계·동률·간격·피크와 작업 예산 설정

반환: 마커와 라벨 영상을 소유하는 SplitResult; close 필요

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    붙은 전경을 마커로 분리

    split_touching은 전경 마스크의 거리 피크에서 마커를 만들고 제한된 watershed로 서로 닿은 영역을 분리합니다. 물체마다 명확한 거리 피크가 있는지, ROI 경계가 물체를 자르는지에 따라 마커와 분할선이 달라집니다. 입력 영상 자체가 자동으로 원하는 물체 개수를 보장하지는 않습니다.

    옵션과 기본값

    기본 설정은 8연결, ROI 밖을 배경으로 보는 경계, DAM 동률 처리, 두 축 간격 1.0, 최대 마커 64개입니다. 최소 높이와 돌출도, 피크 간 거리, 최소 영역 크기는 후보와 결과를 조정하며 작업량 제한도 함께 지정합니다. 마커 상한은 1부터 64까지로 검사됩니다.

    결과와 수명

    SplitResult는 markers와 labels 영상 및 각각의 개수를 담습니다. 마커가 예상 위치에 놓였는지 원본과 겹쳐 본 다음 레이블 경계와 영역 수를 확인합니다. 결과의 close는 두 영상 핸들을 모두 닫으므로 필요한 표시와 후속 처리를 먼저 수행합니다.

    설정 비교

    두 객체가 하나로 남으면 마커 후보의 위치와 거리 조건을 먼저 살피고, 하나의 객체가 지나치게 나뉘면 피크 검출과 최소 영역 조건을 점검합니다. 한 번에 한 옵션을 바꾸고 입력 마스크를 유지해야 결과 차이를 해석하기 쉽습니다.
