Python API · decode_lens

decode_lens 멤버와 선언

공개 타입

zvision.decode_lens: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.decode_lens.

Decode an 84-byte version-1 Brown lens, checking version and CRC.

버전과 CRC를 검사하여 Brown 렌즈를 복원합니다.

Python
decode_lens(data)

인자 선언

  • data · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

data
버전 1 렌즈 직렬화 bytes류, 정확히 84바이트

반환: 독립 LensModel 값

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    decode_lens는 84바이트 버전 1 Brown 렌즈 인코딩을 읽어 LensModel을 반환합니다. 입력은 bytes, bytearray 또는 memoryview 같은 바이트 객체여야 하며 길이가 정확히 84바이트여야 합니다. 디코딩 과정에서 버전과 CRC를 검사하므로 임의의 수치 배열이나 텍스트를 같은 형식으로 취급하지 않습니다.

    구체 사례와 판독

    예를 들어 encode_lens로 만든 바이트를 파일에 기록한 뒤 바이너리로 다시 읽어 이 함수에 전달하면 렌즈 값을 복원하는 왕복을 구성할 수 있습니다. 파일이 잘리거나 전송 중 손상되었다면 길이 또는 무결성 검사가 실패할 수 있습니다. 오류가 발생했을 때 기본 렌즈를 조용히 대신 쓰면 투영 결과가 틀어질 수 있으므로 원인을 확인해야 합니다.

    적용 시 확인

    CRC는 바이트가 손상되었는지 검출하는 데 도움을 주지만 그 렌즈 모델이 현재 카메라를 정확하게 표현한다는 것을 보증하지 않습니다. 영상 크기, 카메라 설정, 보정 일자를 확인하고 실제 검증점을 재투영해 차이를 확인하세요. 원본 파일과 장치의 대응을 유지하는 것이 중요합니다. 디코딩된 모델을 원본과 비교할 때에는 초점 거리뿐 아니라 주점과 각 왜곡 계수도 모두 확인합니다.
