    사용과 결과 해석

    고급 결함 판정에서 한 영역에 적용할 규칙을 묶습니다. region과 max_scratch_count, max_surface_count, max_score, max_length, max_width를 judge_advanced에 전달합니다. 스크래치와 표면 후보 개수는 별도 한도이므로 하나만 보고 나머지 유형의 허용 여부를 추정하지 않습니다.

    예를 들어 max_scratch_count를 0으로 설정하면 스크래치를 허용하지 않는 규칙을 표현할 수 있습니다. 동시에 지정한 점수, 길이와 폭의 상한도 그 규칙의 일부이므로 실제 반환 passed와 violating_indices를 함께 확인합니다. 규칙 사각형과 후보의 좌표계가 일치하는지도 중요합니다.

    판정 전 단계에서는 마스크, 점수와 DefectSpec으로 후보를 구성합니다. 영역 규칙은 차분이나 정렬을 대신하지 않으며, 입력이 잘못된 오류와 규칙에 의한 불합격을 구분해야 합니다. 여러 규칙을 전달하면 결과도 규칙 순서에 맞추어 해석합니다.

    서로 겹치는 규칙은 각 영역의 설정에 따라 별도 판정됩니다. 규칙과 결과를 순서대로 짝지어야 어떤 영역의 어떤 한도가 적용됐는지 나중에 확인할 수 있습니다.
