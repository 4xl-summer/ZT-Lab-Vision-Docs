    사용 맥락과 결과 해석

    확장 모델 학습 후 표본 수와 선택된 기울기 임계값을 보여 주는 정보 값입니다. NCC 모델에서는 sample_count가 선택된 명암 표본 수이고 threshold는 0입니다. 형상 모델에서는 표본 수가 사용한 기울기 특징의 수이고 threshold는 형상 학습에 적용한 임계값입니다. 같은 필드라도 모델 종류를 알고 읽어야 합니다.

    자동 임계값을 사용한 형상 학습에서는 실제 적용된 값과 특징점 수를 기록하면 입력이나 마스크를 바꾼 뒤 모델이 달라진 이유를 추적할 수 있습니다. 이 정보만으로 검색 성공이나 충분한 품질을 보장하지는 않습니다. 모델의 기준점과 검색 격자, 결과의 점수 및 종료 이유는 별도로 확인하고 입력 영상과 모델은 언어의 소유권 규칙에 따라 정리합니다.

    학습 직후 정보를 읽어 선택점이 예상보다 적은지 확인할 수 있습니다. 마스크나 표본 간격을 변경하면 수가 달라지므로 이전 모델의 진단과 단순히 섞지 말고 학습 설정을 같이 보관합니다.
