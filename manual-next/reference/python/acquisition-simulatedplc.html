SimulatedPlc 멤버와 선언

공개 타입

zvision.SimulatedPlc: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._acquisition.SimulatedPlc.

A deterministic request/result simulator, with no PLC transport.

판독 기준

  • 모의 상태 기계이며 실제 PLC 통신은 아닙니다.

수치와 도형은 연결된 계약의 핵심 관계를 설명하는 예입니다. 실제 SDK 출력으로 명시한 자료를 제외하면 실행 결과나 장비 실측으로 해석하지 않습니다. 좌표계·입력 형식·수명과 오류 조건은 관련 API 계약을 확인한 뒤 적용하세요.

Python
SimulatedPlc()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
