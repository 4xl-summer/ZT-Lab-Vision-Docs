공개 타입

zvision.scan_multiple_barcodes: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.scan_multiple_barcodes.

Decode multiple symbols; angle_range overrides options angles and search can miss symbols.

여러 바코드를 검색하고 영상 통계를 계산합니다.

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    ZImage와 MultiBarcodeOptions를 받아 여러 심볼을 탐색하고 MultiBarcodeScan을 반환합니다. 결과에는 읽힌 항목들과 전체 입력의 밝기 통계가 함께 들어 있습니다. formats, angles_degrees, try_harder, also_inverted, 결과 수 및 길이 조건이 탐색 설정에 영향을 줍니다.

    선택 인자 angle_range를 제공하면 options의 개별 각도 목록 대신 (최소, 최대, 간격) 범위를 사용합니다. 범위는 세 원소여야 합니다. 예를 들어 형식과 각도 조건을 좁히면 그 조건 밖의 심볼은 놓칠 수 있으므로 검색 결과가 비었다는 사실을 영상에 심볼이 없다는 증명으로 취급하지 않습니다.

    각 읽기의 텍스트, 원시 바이트, 형식 및 위치를 확인하고 length_accepted도 구분합니다. image_metrics는 전체 입력 밝기의 통계로 심볼 검증기 등급이 아닙니다. 반환은 복사된 값이며 입력 이미지와 소유 핸들을 혼동하지 않습니다.

    max_results를 지정했으면 목록이 그 수에 도달했는지 확인해 결과가 제한되었을 가능성을 살펴봅니다. 다른 각도 범위로 재시도한 결과는 요청 조건과 함께 구별해 저장합니다.
