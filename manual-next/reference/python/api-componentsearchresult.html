    사용 맥락과 결과 해석

    루트 상대 관계를 만족하는 컴포넌트 객체들의 불변 튜플과 평가 포즈 수, 미완료 상태입니다. objects가 비었다는 것은 반환된 객체가 없다는 뜻이고 incomplete가 참이면 제한된 공유 검색을 전부 마치지 못했을 수 있습니다. 두 상태를 따로 보관해야 합니다.

    각 객체의 parts에는 루트와 나머지 형상 모델 id 및 자세가 들어 있습니다. 최대 객체 수가 작거나 공유 예산이 부족하면 예상한 모든 조합을 반환하지 못할 수 있으므로 입력 옵션과 함께 evaluated를 확인합니다. 구성요소의 상대 위치와 각도는 루트에 대한 관계이며 검색 영상의 전역 좌표와 바로 같은 의미가 아닙니다.

    객체의 점수만 보고 각 부품의 상세 포즈를 생략하면 어느 부품이 관계 경계에 가까웠는지 알기 어렵습니다. parts와 최대 위치 오차를 같이 살펴봅니다.

    값을 확인하는 순서

    objects 항목: 검색된 컴포넌트 객체들의 독립 불변 튜플입니다. evaluated 항목: 평가한 포즈 수입니다. incomplete 항목: 공유 검색이 끝까지 완료되지 않았는지 나타냅니다.

    항목읽을 때 확인할 내용

    incomplete공유 검색이 끝까지 완료되지 않았는지 나타냅니다.
