Python API · train_contour_shape

train_contour_shape 멤버와 선언

공개 타입

zvision.train_contour_shape: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.train_contour_shape.

Train directed polylines (at most 128, 65536 points) using a positive pixel spacing and Point2 reference.

방향이 있는 선분 경로에서 형상 특징을 추출해 모델을 학습합니다.

Python
train_contour_shape(contours, reference, spacing)

인자 선언

  • contours · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spacing · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

contours
각 2점 이상인 Point2 경로 1..128개, 전체 최대 65536점입니다.
reference
템플릿 로컬 Point2 기준점입니다.
spacing
유한한 양의 표본 간격(픽셀)입니다.

반환: 호출자가 닫아야 하는 형상 AdvancedMatchModel입니다.

오류: 경로·간격 또는 특징점 조건이 유효하지 않으면 오류입니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    방향이 있는 선분 경로에서 표본을 만들어 형상 모델을 학습합니다. contours는 1..128개의 경로이며 각 경로에 Point2 두 개 이상, 전체 65536점 이하가 필요합니다. reference는 템플릿 로컬 기준점이고 spacing은 유한한 양의 픽셀 간격입니다. 호출 결과는 닫아야 하는 형상 모델입니다.

    경로의 순서는 방향을 정하므로 점을 뒤집으면 법선 방향에도 영향을 줄 수 있습니다. 예를 들어 한 경로에 두 끝점을 두면 그 선분 위를 지정 간격으로 표본화하지만, 실제 학습에는 충분한 유효 특징점이 필요합니다. 이후 검색 시 입력 영상의 기울기 방향과 모델을 비교합니다. 잘못된 경로, 간격 또는 특징점 부족은 빈 검색 결과가 아니라 학습 오류입니다.

    값을 확인하는 순서

    contours 항목: 각 2점 이상인 Point2 경로 1..128개, 전체 최대 65536점입니다. reference 항목: 템플릿 로컬 Point2 기준점입니다. spacing 항목: 유한한 양의 표본 간격(픽셀)입니다.

    항목읽을 때 확인할 내용
    contours각 2점 이상인 Point2 경로 1..128개, 전체 최대 65536점입니다.
    reference템플릿 로컬 Point2 기준점입니다.
    spacing유한한 양의 표본 간격(픽셀)입니다.
