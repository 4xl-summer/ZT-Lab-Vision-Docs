Python API · prune_skeleton

prune_skeleton 멤버와 선언

공개 타입

zvision.prune_skeleton: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._region_topology.prune_skeleton.

Remove short endpoint-to-junction branches in spacing units.

끝점에서 분기점까지의 짧은 가지를 제거합니다.

Python
prune_skeleton(image, options=PruneOptions(max_length=1.0, spacing_x=1.0, spacing_y=1.0, max_iterations=100, work_budget=100000000))

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 PruneOptions(max_length=1.0, spacing_x=1.0, spacing_y=1.0, max_iterations=100, work_budget=100000000)

확인된 인자 조건

image
ZImage 입력 영상
options
PruneOptions; 기본 최대 길이 1.0, 간격 x=y=1.0, 최대 100회, 작업량 100000000

반환: 영상을 소유하는 IterationResult; close 필요

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    짧은 가지 정리

    prune_skeleton은 골격에서 끝점부터 접합점까지 이어지는 짧은 가지를 제거합니다. 원본 영상의 노이즈 때문에 생긴 짧은 돌기를 줄이는 데 쓰지만 실제 물체의 중요한 짧은 가지도 조건에 맞으면 없어질 수 있으므로 적용 전후의 구조를 확인해야 합니다.

    길이와 간격

    기본 PruneOptions는 max_length 1.0, spacing_x와 spacing_y 1.0, 최대 반복 100, 작업량 한도 100000000입니다. 가지 길이는 지정한 축 간격을 반영한 단위로 해석합니다. 가로와 세로의 물리 간격이 다른 영상이라면 단순한 픽셀 수와 실제 가지 길이가 같지 않을 수 있습니다.

    반복 결과 해석

    입력 골격과 길이 한도를 설정해 실행하고 IterationResult의 제거 수, 반복 수와 converged를 확인합니다. 수렴하지 않았다면 한도 때문에 중간에 끝난 가능성을 검토합니다. 필요한 그래프 분석을 끝낸 후 결과를 close하여 포함된 영상 핸들을 해제합니다.

    짧은 가지 제거가 반복되면 처음 제거한 가지 주변의 연결 구조가 이후 단계에서 달라질 수 있습니다. 결과의 제거 수만이 아니라 중요한 분기가 남아 있는지 출력 골격을 원본과 나란히 확인합니다.
