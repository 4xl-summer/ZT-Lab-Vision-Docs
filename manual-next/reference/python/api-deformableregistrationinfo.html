    사용 맥락과 결과 해석

    변위 제어 격자를 이용한 영상 정합의 진단 값입니다. found가 참이면 columns와 rows가 결과 격자의 크기를 나타내고, residual_rms는 유효 영역의 밝기 잔차, objective는 오차와 평활 페널티가 결합된 목적값입니다. coverage는 유효 기준 표본의 비율이며 evaluated는 시험된 변위 후보 수입니다.

    found가 거짓일 때 기본 숫자를 유효한 격자나 품질 결과로 사용하면 안 됩니다. 먼저 존재 여부를 분기한 다음 별도 변위 복사와 정렬 이미지 획득을 수행합니다. 예컨대 3열과 2행의 결과라면 제어점은 6개이고 행 우선 순서로 다뤄야 합니다. 목적값은 선택한 평활 가중치의 영향을 받으므로 조건이 다른 실행끼리 순수한 픽셀 오차로 직접 비교하지 않습니다.
