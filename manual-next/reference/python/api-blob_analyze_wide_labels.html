blob_analyze_wide_labels 멤버와 선언

공개 타입

zvision.blob_analyze_wide_labels: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_wide_label_analysis.blob_analyze_wide_labels.

Analyze each nonzero wide label as a global binary group.

비영 넓은 정수 라벨별로 전체 영역을 측정합니다.

Python
blob_analyze_wide_labels(image, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 BlobResult

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    넓은 정수 레이블의 분석

    blob_analyze_wide_labels는 비영의 넓은 정수 레이블 값별로 전체 영역을 측정합니다. 각 레이블 값은 영역 그룹을 나타내며 0은 배경입니다. 이미 지정된 레이블별 집계를 수행하는 것이므로 일반적인 이진 마스크 연결 성분 찾기와 구분합니다.

    레이블 그룹

    같은 숫자의 픽셀들이 같은 레이블 그룹에 속합니다. 예를 들어 화면의 떨어진 두 위치에 같은 비영 레이블이 있으면 레이블별 분석에서는 같은 값의 그룹으로 읽어야 합니다. 서로 떨어졌는지만을 기준으로 새로운 번호를 자동 지정한다고 가정하지 않습니다.

    입력과 작업량

    image에 지원되는 넓은 정수 레이블 ZImage를 전달하고 work_budget에 양의 상한을 지정합니다. 레이블 영상의 형식과 ROI를 확인하고 결과의 면적 및 위치를 원본 레이블 맵과 비교합니다. 번호의 크기는 물체의 면적이나 중요도를 나타내지 않습니다.

    결과 비교

    다른 프레임에서 같은 레이블 값이 같은 물체인지 여부는 레이블을 만든 과정에 달려 있습니다. 추적이 필요하면 위치와 기타 특징을 함께 사용하고, 픽셀 수를 물리 면적으로 바꿀 때는 별도 보정을 적용합니다.
