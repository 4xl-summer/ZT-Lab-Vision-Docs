Python API · eye_to_hand_motions

eye_to_hand_motions 멤버와 선언

공개 타입

zvision.eye_to_hand_motions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._hand_eye.eye_to_hand_motions.

Build adjacent AX=XB pairs for X=base←camera from absolute poses.

절대 자세의 인접 쌍을 base←camera 손-눈 문제의 운동 쌍으로 변환합니다.

Python
eye_to_hand_motions(gripper_to_base, target_to_camera)

인자 선언

  • gripper_to_base · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_to_camera · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

gripper_to_base
그리퍼에서 베이스로의 자세 3–1025개입니다.
target_to_camera
같은 개수의 타깃에서 카메라로의 자세입니다.

반환: HandEyePair의 독립 튜플입니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    eye_to_hand_motions는 카메라가 외부에 고정된 구성의 로봇과 타깃 절대 자세에서 핸드아이 운동 쌍을 구성합니다. gripper_to_base와 target_to_camera 목록은 동일한 시점 순서로 맞추고 같은 개수의 자세를 제공해야 합니다. 최소 세 자세를 준비한 후 생성된 운동을 solve_hand_eye에 전달하여 카메라에서 베이스로 가는 변환을 추정합니다.

    구체 사례와 판독

    예를 들어 로봇이 세 자세에서 정지할 때마다 타깃을 한 번씩 관측했다면 첫 로봇 자세와 첫 영상 관측을 한 쌍으로 기록합니다. 한쪽만 시간순으로 다시 정렬하면 잘못된 운동 대응이 만들어집니다. 로봇 자세가 미터이고 타깃 변환이 밀리미터인 혼합 입력도 피해야 합니다. 결과를 사용하기 전에 독립된 자세에서 대상 좌표를 확인하세요.

    적용 시 확인

    이 함수는 절대 자세에서 상대 운동을 만드는 단계이며 보정 결과 자체를 반환하는 호출과는 구별합니다. 운동 쌍을 푼 후에는 도출된 변환의 방향이 적용하려는 카메라와 베이스 프레임에 맞는지 살펴보세요. 적어도 세 자세라는 입력 조건과 다양한 운동을 확보해야 한다는 정확도 요구는 별개입니다. 결과의 잔차를 확인하고 보류된 관측으로 검증합니다.
