Python API · validate_stage

validate_stage 멤버와 선언

공개 타입

zvision.validate_stage: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.validate_stage.

Fit a full linear stage response from 4–4096 independent unwrapped 2D poses.

명령 및 관측 자세로 3자유도 선형 스테이지 응답을 적합합니다.

Python
validate_stage(command, observed, unit)

인자 선언

  • command · POSITIONAL_OR_KEYWORD · 기본값 없음
  • observed · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

command
명령 StagePose2 4~4096개
observed
같은 수의 관측 StagePose2
unit
이동 길이 단위

반환: 행렬, 오차와 축 척도가 담긴 StageValidation

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    validate_stage는 명령한 평면 스테이지 자세와 실제 관측 자세의 대응을 받아 3자유도 선형 응답을 적합합니다. command와 observed는 같은 개수의 StagePose2이며 4쌍부터 4096쌍까지 전달합니다. X와 Y는 지정한 길이 단위를 따르고 회전은 래핑하지 않은 라디안 값입니다. 각 명령은 같은 시점의 관측과 짝지어야 합니다.

    구체 사례와 판독

    예를 들어 X 이동 명령이 10 mm인 시점에 실제 관측이 9.9 mm였다면 그 한 쌍에서 차이는 0.1 mm입니다. 이 한 점만으로 전체 선형 응답을 추정할 수는 없습니다. X, Y, 회전의 서로 독립적인 움직임을 포함하고 반환된 행렬과 축별 잔차를 함께 검토하세요. 관측이 안정되기 전의 위치를 사용하면 정착 후 오차와 다르게 나타날 수 있습니다.

    적용 시 확인

    명령 범위가 X만 변하고 Y와 회전은 변하지 않는 자료라면 전체 3축 응답을 독립적으로 결정할 정보가 부족할 수 있습니다. 각 자유도를 구별할 수 있는 자세를 준비하고 위치와 회전의 단위 차이를 기록하세요. 예측과 관측의 차이는 자료의 순서, 장치의 안정 시간, 측정 좌표 프레임을 확인한 후 해석해야 합니다. 사용하지 않은 자세를 보류해 적합 후 예측 오차를 별도로 확인할 수 있습니다.
