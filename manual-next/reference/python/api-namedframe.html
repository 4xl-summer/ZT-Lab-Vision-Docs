Python API · NamedFrame

NamedFrame 멤버와 선언

공개 타입

zvision.NamedFrame: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.NamedFrame.

One UTF-8 frame name bound to a nonzero frame ID.

Python
NamedFrame(name: str, id: int) -> None

인자 선언

  • name · POSITIONAL_OR_KEYWORD · 타입 <class 'str'> · 기본값 없음
  • id · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

NamedFrame(<class 'str'>, <class 'int'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    namestr필수좌표계를 식별하는 UTF-8 이름입니다.
    idint필수프레임을 식별하는 0이 아닌 정수 ID입니다.

    사용 맥락과 계약

    NamedFrame은 좌표 프레임의 이름과 0이 아닌 숫자 ID를 연결합니다. resolve_named_rigid_tree는 이 연결을 사용해 이름으로 지정한 출발과 도착 프레임 사이의 변환을 찾습니다. 이름은 비어 있지 않은 문자열이며 UTF-8 인코딩 기준 64바이트를 넘을 수 없고 NUL 문자를 포함할 수 없습니다.

    구체 사례와 판독

    예를 들어 camera와 base를 서로 다른 ID에 연결하고 camera→gripper→base 경로를 구성하면 이름으로 camera에서 base까지의 변환을 요청할 수 있습니다. 이름이 다르더라도 같은 물리 프레임인지 또는 같은 이름이 장치 교체 후 다른 기준을 뜻하는지 관리해야 합니다. 숫자 ID와 이름 매핑을 변환 간선과 함께 저장하세요.

    적용 시 확인

    한글처럼 UTF-8에서 여러 바이트를 차지하는 문자는 글자 수가 64 이하라도 바이트 수가 64를 넘을 수 있습니다. 저장하거나 전송할 때 실제 UTF-8 길이로 확인하세요. ID 0은 허용되는 프레임 식별자가 아니므로 다른 유효한 ID를 배정해야 합니다. 이름은 좌표 프레임의 별칭이지 변환 행렬이 아닙니다. 이름을 바꾸면 해당 이름으로 요청하는 모든 호출과 목록도 함께 갱신해야 합니다.
