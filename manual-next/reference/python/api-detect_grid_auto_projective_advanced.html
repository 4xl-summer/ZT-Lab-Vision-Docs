detect_grid_auto_projective_advanced 멤버와 선언

공개 타입

zvision.detect_grid_auto_projective_advanced: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._metrology_advanced.detect_grid_auto_projective_advanced.

Infer a projective grid when all four outer corners are visible.

외곽 네 모서리 관측을 이용해 격자를 자동 추론합니다.

Python
detect_grid_auto_projective_advanced(image, spec)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
지원 그레이스케일 ZImage.
spec
AdvancedGridSpec.

반환: AdvancedGridPoint 튜플.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류. 격자 추론이 불가능해도 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    영상에서 격자 표적의 원근 관계를 자동 추론하는 경로입니다. image는 지원되는 그레이 영상이고 spec은 대상 종류, 행·열 및 대비·거리 조건을 정합니다. 이 경로는 격자의 네 바깥 모서리가 관찰되는 상황을 전제로 하므로 일부가 잘렸거나 다른 무늬에 가려진 입력을 전제 없이 성공 사례로 판단하지 마십시오. 반환된 각 점은 행·열 인덱스, 영상 픽셀 위치와 점수를 갖습니다. 예를 들어 네 모서리가 모두 보이는 합성 격자에서 반환 인덱스를 알려진 표적의 배열과 비교한 뒤 실제 이미지에 적용할 수 있습니다. 자동 추론에 실패하면 대비나 표적 종류뿐 아니라 모서리 가시성과 ROI를 확인합니다. 얻은 점으로 세계 보정을 학습하더라도 보류점 잔차는 별도로 검증해야 합니다. 표적의 한 모서리가 영상 바깥이면 네 모서리를 이용하는 자동 추론의 전제가 깨집니다. 이때는 무작정 결과 숫자를 보정점으로 사용하기보다 ROI와 촬영 구도를 먼저 확인하십시오. 자동 인덱스의 방향도 표적의 기준 행과 열에 맞는지 육안으로 대조하는 것이 좋습니다. 입력 영상이 바뀌면 모서리의 가시성도 달라집니다. 한 프레임의 성공만으로 다른 프레임의 관측 조건을 보장할 수 없습니다. 검출 전후의 표적 배치도 보관합니다.
