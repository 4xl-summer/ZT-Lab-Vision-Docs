사용과 결과 해석

템플릿 폰트 OCR의 전체 판독 결과입니다. score와 accepted, rotation_degrees, line_count, glyphs 및 선택적 layout_accepted를 포함합니다. glyphs에는 문자별 라벨과 셀, 유사도 및 원본 모서리가 있으므로 전체 점수와 함께 어떤 문자가 문제인지 확인할 수 있습니다.

예를 들어 글자가 세 개 감지된 결과에서 한 문자만 낮은 점수라면 전체 문자열만 표시하는 대신 각 FontGlyph의 accepted를 확인합니다. score는 템플릿 유사도이며 보정된 확률이 아닙니다. rotation_degrees는 회전 각도이므로 픽셀 좌표나 길이와 단위를 혼동하지 않습니다.

layout_accepted는 None일 수 있어 검사하지 않은 상태를 거짓과 무조건 같게 취급하지 않습니다. 인식 문자열의 수락과 글자 배치 검사 결과를 별도 항목으로 보관하고, 각 줄의 순서와 입력 프레임 식별자를 함께 남깁니다.

줄 수와 글자 수는 서로 다릅니다. 각 glyph의 line을 사용해 표시 순서를 구성하고 회전된 결과의 원본 모서리도 확인하면 잘못된 분할과 인식 오류를 구별하는 데 도움이 됩니다.
