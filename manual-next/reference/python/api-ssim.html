Python API · ssim

ssim 멤버와 선언

공개 타입

zvision.ssim: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._adaptive_inspection.ssim.

국소 SSIM으로 기준과 검사 영상의 유사도를 계산합니다.

기준 영상과 검체의 국소 SSIM을 계산합니다. 두 영상은 동일 크기·원점·형식의 Gray8, Gray16 또는 GrayF32여야 합니다. 마스크는 같은 크기·원점의 Gray8 가중치이며 0은 제외합니다. 반환한 SsimResult와 그 map/defect_mask 이미지 공유는 각각 닫습니다. 빈 유효 영역이나 옵션 위반은 네이티브 오류입니다.

Python
ssim(reference, image, options, mask=None)

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

reference
Gray8, Gray16 또는 GrayF32 기준 영상.
image
기준과 형식·크기·원점이 같은 검사 영상.
options
SsimOptions 창·극성·점수 및 작업 한도.
mask
선택적 동일 기하 Gray8 가중 마스크; 0은 제외하고 None은 전체.

반환: 호출자가 close할 SsimResult 소유 객체.

오류: 형식·기하·옵션 오류 또는 작업 한도 위반은 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
