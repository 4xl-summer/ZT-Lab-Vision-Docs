Python API · signed_parallel_line_distance

signed_parallel_line_distance 멤버와 선언

공개 타입

zvision.signed_parallel_line_distance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.signed_parallel_line_distance.

Signed offset to the second line; reject nonparallel unit directions.

첫 직선에서 평행한 둘째 직선까지 부호 있는 거리를 계산합니다.

Python
signed_parallel_line_distance(first, second, angle_tolerance)

인자 선언

  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • second · POSITIONAL_OR_KEYWORD · 기본값 없음
  • angle_tolerance · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

first
DirectedLine2; 유한한 원점과 0이 아닌 방향.
second
DirectedLine2; 유한한 원점과 0이 아닌 방향.
angle_tolerance
정규화 방향 외적 크기의 허용치; 유한한 0 이상 1 미만, 무차원.

반환: 좌표 단위의 부호 있는 float.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류. 평행 조건을 벗어나도 오류.

angle_tolerance: 유한한 수 검사.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    첫 유향선에 대해 둘째 평행선이 어느 쪽에 얼마나 떨어져 있는지를 부호와 함께 계산합니다. 두 선은 DirectedLine2이고 방향은 0이 아니어야 합니다. angle_tolerance는 두 단위 방향의 외적 크기에 적용되는 무차원 한계이며 유한한 0 이상 1 미만입니다. 예를 들어 첫 선이 (0,0)에서 오른쪽을 향하고 둘째 기준점이 (0,2)인 같은 방향의 선이면 부호 거리는 +2 좌표 단위입니다. 이 한도를 넘는 비평행선에는 부호 있는 평행 간격을 반환하지 않고 오류로 처리합니다. 영상의 좌표가 픽셀이라면 결과도 픽셀이며 물리 단위로 기록하기 전 프레임과 보정 조건을 확인하십시오. 평행 판정의 숫자를 라디안 각도 허용치로 잘못 해석하면 비교 조건이 달라집니다. 첫 선과 둘째 선의 역할을 바꾸면 기준이 되는 방향도 바뀌므로 반환 부호를 단순히 거리 크기만으로 해석하지 마십시오. 같은 방향의 수평선 y=0과 y=2는 기준 방향에 대한 둘째 선의 위치를 나타냅니다. 보고서에는 두 선의 순서와 좌표 단위를 함께 기록합니다. 방향 외적의 허용치는 거리 단위의 오차가 아닙니다. 입력선이 같은 프레임에 속하는지와 평행 조건을 각각 검토하십시오.
