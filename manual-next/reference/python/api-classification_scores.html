Python API · classification_scores

classification_scores 멤버와 선언

공개 타입

zvision.classification_scores: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._ai_advanced.classification_scores.

분류 logits에 softmax를 적용하거나 이미 정규화된 확률을 검증합니다.

Python
classification_scores(values, probabilities=False)

인자 선언

  • values · POSITIONAL_OR_KEYWORD · 기본값 없음
  • probabilities · POSITIONAL_OR_KEYWORD · 기본값 False

확인된 인자 조건

values
비어 있지 않은 유한 float 점수 순서열입니다.
probabilities
기본 False는 logits를 softmax로 변환합니다. True는 각 값이 0~1이고 합이 1에서 1e-4 이내인 확률로 검증합니다.

반환: 확률의 독립 float 튜플입니다.

오류: 점수가 비거나 유한하지 않거나 확률 조건이 맞지 않으면 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    모델의 분류 출력 수치에 대해 분류 점수 후처리를 수행하고 값 튜플을 반환합니다. values는 점수 원소의 순서열이며 probabilities 인자는 입력의 해석 방식을 지정합니다. 어느 인덱스가 어떤 클래스에 대응하는지는 모델의 클래스 순서와 함께 관리해야 합니다.

    예를 들어 세 클래스의 출력이라면 반환된 세 점수의 같은 인덱스를 모델의 세 레이블과 대응시켜 가장 높은 값을 찾습니다. 점수 값만 보관하고 레이블 순서를 누락하면 나중에 0번과 1번 클래스의 의미를 복원할 수 없습니다. probabilities 설정을 실제 출력 형식과 맞추어야 비교가 유효합니다.

    함수 내부의 임시 텐서는 값을 읽은 뒤 닫으며 호출자에게는 값 튜플이 반환됩니다. 이 후처리는 모델을 실행하거나 이미지의 전처리를 대신하지 않습니다. 입력이 잘못되어 오류가 반환된 경우 빈 점수 목록이나 특정 클래스의 정상 판정으로 바꾸지 않습니다.

    후처리의 입력이 확률인지 모델 점수인지에 따라 probabilities 선택이 달라집니다. 여러 실행을 비교할 때는 모델 버전과 그 설정을 함께 기록하고 점수만으로 모델 정확도를 판단하지 않습니다.

    클래스 인덱스와 레이블의 연결을 모델마다 확인합니다.
