blob_inner_rectangle 멤버와 선언

공개 타입

zvision.blob_inner_rectangle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_inner_rectangle.blob_inner_rectangle.

Return the largest fully foreground axis-aligned pixel rectangle.

전경에 완전히 포함되는 최대 축 정렬 픽셀 사각형을 구합니다.

Python
blob_inner_rectangle(image, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
work_budget
양의 정수 작업량 상한

반환: BlobInnerRectangle 값

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    전경에 포함되는 영역

    blob_inner_rectangle은 전경에 완전히 포함되는 최대 축 정렬 픽셀 사각형을 구합니다. 경계 상자는 전체 전경을 둘러싸지만 이 사각형은 전경 안에 들어갑니다. 물체에 홈이나 구멍이 있으면 두 사각형은 다른 영역을 나타냅니다.

    입력과 작업량

    image에는 분석할 ZImage를 전달하고 work_budget에는 양의 작업량 상한을 지정합니다. 연산 전에 원하는 물체가 전경으로 표시된 마스크인지 확인하세요. 다른 물체가 함께 포함되면 결과가 의도한 단일 객체에 해당하는지 마스크에서 직접 살펴봐야 합니다.

    결과 예

    반환되는 BlobInnerRectangle의 x와 y는 ROI 로컬 시작점이며 width와 height는 픽셀 셀 수입니다. 폭 3, 높이 2라면 사각형은 6개 셀입니다. 원래 전체 전경의 면적이 반드시 6이라는 뜻은 아니며 사각형 바깥에도 전경이 있을 수 있습니다.

    표시와 판독

    결과 사각형을 입력 마스크와 겹쳐 내부에 배경이 끼지 않았는지 확인합니다. 전체 영상에 표시할 때는 ROI 원점을 더해야 합니다. 회전된 사각형을 찾는 연산이 아니므로 기울어진 물체에서는 축 정렬 조건이 결과 크기에 영향을 줍니다.
