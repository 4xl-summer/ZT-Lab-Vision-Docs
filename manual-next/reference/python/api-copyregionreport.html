    복사 결과의 두 숫자

    CopyRegionReport는 복사된 픽셀 수 copied와 대상 경계에 의해 잘린 픽셀 수 clipped를 보고합니다. 요청된 영역의 크기와 실제로 대상에 들어간 양이 다를 수 있으므로 두 값을 함께 읽습니다. 이 값들은 픽셀 수이며 바이트 수나 영역의 물리 면적이 아닙니다.

    경계에 걸친 사례

    대상 이미지 밖으로 걸쳐지는 복사 영역이 있으면 보이는 부분과 경계 밖 부분을 구분해야 합니다. 예를 들어 한 행의 다섯 픽셀을 복사하려는데 대상 범위에 세 픽셀만 들어간다면 나머지 두 위치는 잘리는 상황입니다. 실제 반환 숫자는 호출의 ROI와 복사 조건을 기준으로 확인합니다.

    후속 처리

    복사 전에 원본 및 대상의 좌표 기준과 픽셀 형식을 확인하고 연산 뒤 copied와 clipped를 검사합니다. clipped가 예상보다 크면 대상 원점, 크기 및 오프셋을 점검합니다. 보고 객체의 숫자는 복사된 영상 데이터를 대신하지 않으며 대상 영상은 별도로 유지해야 합니다.

    판정 기준

    일부 복사가 허용되는 작업에서는 clipped가 0이 아니더라도 의도한 결과일 수 있습니다. 반대로 전체 영역 복사가 필요한 작업에서는 잘림 여부를 명시적으로 판정하고 대상 위치의 픽셀을 확인해야 합니다.
