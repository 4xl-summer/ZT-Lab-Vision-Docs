COLOR_NCC maximizes pooled RGB correlation; GRAY_SAD minimizes mean absolute difference.

GRAY_SAD

attribute · 선언 타입 zvision._matching_bounded.TemplateMetric

COLOR_NCC maximizes pooled RGB correlation; GRAY_SAD minimizes mean absolute difference.

열거 값

  • COLOR_NCC = 0 · RGB 상관 점수를 최대화합니다.
  • GRAY_SAD = 1 · Gray8 평균 절대 차이를 최소화합니다.

사용 맥락과 결과 해석

BoundedTemplateModel의 점수 방식을 선택합니다. COLOR_NCC는 RGB8 채널을 이용한 정규화 상관으로 높은 값이 더 좋고, GRAY_SAD는 Gray8의 평균 절대 차이로 낮은 값이 더 좋습니다. 두 방식은 서로 다른 픽셀 형식을 요구하며 같은 숫자 임계값을 같은 의미로 적용할 수 없습니다.

색 상관의 수용 조건은 값이 임계값 이상이고 임계값 범위는 −1..1입니다. Gray SAD는 차이가 임계값 이하일 때 허용하며 범위는 0..255입니다. 예를 들어 완전히 같은 비상수 색 패턴은 높은 상관을 기대하고, 동일한 회색 패턴의 SAD는 0입니다. 이 모델은 정수 평행이동을 검색하며 기본 회전·배율 NCC와 설정과 좌표 기준이 다릅니다.

값을 확인하는 순서

COLOR_NCC 항목: RGB 상관 점수를 최대화합니다. GRAY_SAD 항목: Gray8 평균 절대 차이를 최소화합니다.
