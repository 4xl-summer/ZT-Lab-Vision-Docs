사용과 결과 해석

결함 마스크의 연결 성분별 종류, 영역과 점수를 독립 튜플로 담은 스냅샷입니다. 각 결함에는 ROI 로컬 경계와 중심, 길이·폭 및 평균·최대 점수 같은 측정이 포함됩니다. 이 결과 자체는 입력 이미지의 소유 핸들을 유지하지 않습니다.

같은 결함 면적이라도 길고 가늘게 이어진 성분과 둥근 성분은 길이·폭 및 분류가 다를 수 있습니다. 평균 점수와 최대 점수도 서로 다른 정보를 주므로 하나만으로 전체 결함의 심각도를 확정하지 마십시오. 연결성과 최소 면적 조건은 후보 수에 영향을 줍니다.

결과 좌표와 크기는 픽셀 기준이며 전체 영상 또는 물리 단위로 쓰려면 ROI 원점과 보정을 적용해야 합니다. 빈 튜플은 조건을 만족한 후보가 없다는 결과일 수 있고 계산 오류와 구분해야 합니다. 허용 공차는 사용자 검사 기준에서 별도로 정합니다.
