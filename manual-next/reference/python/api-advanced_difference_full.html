공개 타입

zvision.advanced_difference_full: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_advanced.advanced_difference_full.

포함 마스크와 밝기 회귀·극성을 함께 적용한 고급 차분입니다.

Python
advanced_difference_full(source, reference, spec, *, threshold_map=None, dark_frame=None, flat_frame=None, include=None, correction=0, polarity=0)

확인된 인자 조건

source
Gray8·Gray16·GrayF32 검사 영상.
reference
source와 형식·크기·원점이 같은 기준 영상.
spec
AdvancedDifferenceSpec의 기본 허용치, 질감 및 조명 보정 조건.
threshold_map
선택적 같은 기하의 양의 GrayF64 임계치 맵; None은 생략.
dark_frame
선택적 같은 형식·기하의 다크 영상; None이면 spec.dark 사용.
flat_frame
선택적 같은 형식·기하의 플랫 영상; None이면 플랫 보정 생략.
include
선택적 같은 기하 Gray8 포함 마스크; 비제로 포함.
correction
PhotometricCorrection; 기본 NONE.
polarity
DifferencePolarity; 기본 ABSOLUTE.

반환: 호출자가 close할 AdvancedDifference 소유 결과.

오류: 유효하지 않은 영상 형식·기하·옵션 또는 계산 범위는 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
