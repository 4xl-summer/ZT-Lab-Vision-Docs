사용 맥락과 계약

WorldFitOptions는 월드 평면 도형 적합의 방법과 허용 조건을 설정합니다. inlier_threshold와 tolerance는 요청한 출력 길이 단위로 해석하며 min_inliers, max_candidates, max_refit_iterations는 적합에 필요한 점과 계산 제한을 정합니다. min_arc_radians는 원호에 관한 각도 조건으로 라디안입니다.

구체 사례와 판독

예를 들어 출력 단위를 mm로 선택했다면 내점 기준 0.5는 0.5 mm입니다. 같은 장면을 m로 표현하면서 0.5를 그대로 쓰면 물리적으로 다른 한계가 됩니다. 원호 각도는 길이 단위와 별개이므로 180도는 π 라디안입니다. 방법과 기준을 기록하고 반환 관측의 잔차와 사용 여부를 확인해 적합 결과를 해석하세요.
