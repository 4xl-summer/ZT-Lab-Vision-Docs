center_x: 입력 ROI 로컬 중심의 X 좌표이며 픽셀 단위입니다.

center_y: 입력 ROI 로컬 중심의 Y 좌표이며 픽셀 단위입니다.

start_angle: 각도 축의 시작값으로 라디안 단위입니다.

end_angle: 각도 축의 끝값으로 라디안 단위입니다. 시작보다 커야 하며 각도 폭은 최대 16π입니다.

start_radius: 반경 축의 시작값으로 음이 아닌 픽셀 단위입니다.

end_radius: 반경 축의 끝값으로 시작 반경보다 커야 하며 픽셀 단위입니다.

width: 각도 방향 출력 크기로 2 이상의 정수입니다.

height: 반경 방향 출력 크기로 2 이상의 정수입니다.

interpolation: 최근접 또는 쌍선형 샘플링이며 기본값은 최근접입니다.

border: 입력 ROI 밖에 사용하는 상수 밝기이며 기본값은 0입니다.
