Python API · blob_offset_mask

blob_offset_mask 멤버와 선언

공개 타입

zvision.blob_offset_mask: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_offset_mask.blob_offset_mask.

Return a reference-sized Gray8 mask placed at signed local offset.

마스크를 부호 있는 로컬 오프셋에 배치합니다.

Python
blob_offset_mask(reference, mask, offset_x, offset_y, work_budget)

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

reference
기준 ZImage
mask
선택 마스크
offset_x
부호 있는 로컬 x 오프셋
offset_y
부호 있는 로컬 y 오프셋
work_budget
양의 정수 작업량 상한

반환: 기준 크기의 독립 Gray8 영상

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    기준 좌표에 마스크 배치

    blob_offset_mask는 선택 마스크를 기준 영상의 로컬 좌표에 부호 있는 x, y 오프셋으로 배치합니다. 양수와 음수 오프셋은 서로 다른 방향으로 시작 위치를 옮기므로 마스크 원점과 기준 영상 원점을 명시해야 합니다. 이는 마스크 모양의 크기 조정과는 다른 연산입니다.

    좌표 계산 예

    마스크 로컬 위치 (2,3)을 기준 위치로 옮길 때 offset_x=5, offset_y=-1이면 배치 위치는 (7,2)입니다. 오프셋은 좌표에 더하는 값이므로 절댓값만 사용하면 음수 방향 이동을 잃습니다. 기준 범위 밖으로 가는 부분의 처리는 호출 조건과 결과를 확인해야 합니다.

    호출 준비

    reference와 mask에 해당 ZImage를 전달하고 정수 오프셋 및 양의 work_budget을 지정합니다. 두 영상의 ROI와 픽셀 좌표 기준을 확인한 뒤 결과를 기준 영상과 겹쳐 배치가 의도대로인지 확인합니다. 화면상 표시 위치와 실제 로컬 좌표의 차이를 특히 주의합니다.

    결과 해석

    이동한 마스크를 블롭 또는 다른 영역 연산에 쓰면 전경 픽셀의 위치가 달라지므로 이후 좌표 측정도 달라집니다. 객체의 위치를 이동한 것과 픽셀 형식을 바꾸거나 스케일을 조정한 것은 서로 다른 단계로 기록합니다.
