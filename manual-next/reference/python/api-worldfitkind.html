  • CIRCLE = 2 · 세계 좌표의 원을 적합합니다.

사용 맥락과 계약

WorldFitKind는 평면 보정으로 월드 좌표에 옮긴 관측점들에 적합할 도형을 선택합니다. LINE은 직선이고 CIRCLE은 원입니다. 선택하는 것은 출력 도형의 종류이며 관측을 월드로 변환하는 평면 보정이나 이상치를 다루는 적합 방법과는 별개의 설정입니다.

구체 사례와 판독

예를 들어 보정된 세 점이 (0,2), (1,2), (2,2) mm이면 직선 모델은 y=2 mm를 설명할 수 있습니다. 원 모델은 중심과 반지름이 있는 다른 기하학적 가정이므로 같은 점에 다른 종류를 적용해 결과가 같다고 볼 수 없습니다. 측정하려는 물체의 형상과 유효한 점의 분포를 보고 모델을 선택하세요.

적용 시 확인

원 적합에서는 점들이 원의 충분한 부분을 덮는지도 중요합니다. 매우 짧은 원호만으로 중심을 구하면 작은 측정 오차에도 결과가 불안정할 수 있습니다. 직선도 점들이 한 위치에 몰려 있으면 방향을 안정적으로 정하기 어렵습니다. 입력 점의 분포와 적합 잔차를 함께 확인하세요. 선택된 도형과 점의 좌표를 그림에 겹쳐 보면 잘못된 모델 선택을 찾는 데 도움이 됩니다. 점이 원래 ROI 로컬 픽셀이라면 평면 보정에 필요한 전역 좌표로 먼저 바꾸고 변환된 월드 단위를 확인하세요. 출력 단위도 함께 확인합니다.
