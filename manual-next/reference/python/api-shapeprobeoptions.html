데이터 필드

필드타입기본값의미와 조건
countint16타원 전체 또는 사각형 한 변의 탐침 수입니다. 타원은 최소 5개, 사각형은 변당 최소 2개이며 총 탐침은 최대 4096개입니다. 기본값은 16입니다.
search_lengthfloat12.0각 탐침의 전체 탐색 길이로 양의 픽셀 값이며 기본값은 12입니다.
widthint3횡단 띠의 양의 홀수 표본 수이며 기본값은 3입니다.
samplesint13탐색 방향 표본 수로 최소 2×미분 반경+3이며 기본값은 13입니다.
directionint00은 정방향 또는 바깥쪽, 1은 반대 방향이며 기본값은 0입니다.
selectionint20 첫 에지, 1 마지막 에지, 2 가장 강한 에지이며 기본값은 2입니다.
min_foundint5최소 검출 수이며 사각형은 변마다 적용됩니다. 탐침 수 이하여야 하며 기본값은 5입니다.
min_valid_widthint3필요한 유효 폭 표본 수로 1 이상 width 이하여야 하며 기본값은 3입니다.
interpolationint10 최근접, 1 쌍선형이며 기본값은 1입니다.
derivative_filterint0미분 방식으로 0은 중앙 차분, 1은 회귀입니다. 기본값 0입니다.
derivative_radiusint1미분 표본 반경으로 양의 정수이며 기본값은 1입니다.
polarityint31 상승, 2 하강, 3 양방향이며 기본값은 3입니다.
thresholdfloat10.0에지 기울기 강도의 음이 아닌 하한으로 기본값은 10입니다.
prominencefloat0.0에지 피크의 음이 아닌 최소 돌출값이며 기본값은 0입니다.
max_edgesint4탐침마다 보유할 후보의 양의 상한이며 기본값은 4입니다.
filtertuple<builtins.tuple>합이 0이 아닌 유한한 홀수 길이 평활 커널이며 기본값은 (1.0,)입니다.
