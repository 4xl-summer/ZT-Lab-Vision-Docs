    판독 상태와 위치를 해석하기

    텍스트만 확인하기 전에 상태와 이유를 살펴봅니다. 영상 대비가 지정한 하한보다 낮으면 디코더를 호출하지 않고 거절 상태와 낮은 대비 이유, 빈 내용 및 점 목록을 반환할 수 있습니다. 따라서 빈 문자열을 모든 실패 원인의 동일한 표시로 취급하면 대비 거절과 디코딩 실패를 구별할 수 없습니다.

    명시적 회전이 활성화된 경우 원본과 시계 방향 90도 단위의 회전을 순서대로 시도합니다. quarter_turns는 성공한 명시적 회전 횟수이며, 백엔드 내부 탐색 회수나 심벌의 전체 방향으로 해석하지 않습니다. 회전 옵션을 끄더라도 백엔드 자체의 탐색 방식이 내부 회전을 전혀 하지 않는다는 의미는 아닙니다.

    backend_raw_bytes는 형식과 백엔드에 따른 데이터이므로 항상 text의 UTF-8이나 원래 페이로드와 같지 않습니다. points는 형식별 탐색점·코너·선상 점일 수 있어 개수와 순서가 일정한 사각형이라고 가정하지 않습니다. 후속 처리에서 네 꼭짓점이 필요하다면 해당 형식의 결과를 별도로 확인해야 합니다.
