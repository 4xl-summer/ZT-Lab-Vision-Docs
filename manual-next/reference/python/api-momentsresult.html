사용과 결과 해석

각 전경 연결 성분의 면적, ROI 로컬 중심, 중심 모멘트와 관성 타원 측정을 독립 튜플로 담습니다. 원본 영상 또는 임시 Query 결과의 수명과 별개로 보관할 수 있습니다. 성분 수와 목록 순서는 사용한 연결 조건과 입력 마스크에 따라 결정됩니다.

면적은 전경 픽셀 수이고 중심은 그 좌표의 평균입니다. 관성 타원 축 길이는 픽셀 단위이므로 물리 길이를 원한다면 보정이 별도로 필요합니다. 예를 들어 동일한 물체도 다른 영상 배율로 촬영하면 픽셀 축 길이는 달라질 수 있습니다.

ROI 경계에서 잘린 성분은 전체 물체의 모멘트와 다를 수 있습니다. 마스크 정의와 경계 접촉을 확인하고, 타원이 계산한 분포 요약임을 기억하십시오. 이 값만으로 표면 재질이나 실제 결함 원인을 판정할 수는 없습니다.
