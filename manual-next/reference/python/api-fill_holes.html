공개 멤버

    구멍의 정의

    전경에 둘러싸여 ROI 바깥쪽 경계에 연결되지 않은 배경 영역을 찾고 선택한 면적 범위의 구멍을 전경으로 채웁니다. 단순히 어두운 픽셀을 모두 바꾸는 연산이 아니며 외부 배경과 연결되는 틈이 있으면 닫힌 내부 구멍과 구별됩니다. 연결성은 배경 영역을 판별하는 이웃 관계에 영향을 줍니다.

    작은 마스크로 이해하기

    3×3 영상의 여덟 테두리 픽셀이 전경이고 가운데 한 픽셀만 배경이면 가운데는 면적 1의 내부 구멍입니다. 면적 선택 범위에 1이 포함되면 이 픽셀이 채워져 아홉 픽셀 모두 전경인 마스크가 됩니다. 테두리에 틈이 있는 경우에는 가운데가 외부 배경에 연결될 수 있으므로 같은 결론을 내리지 않습니다.

    설정과 확인

    입력 영상과 4 또는 8 연결성, 최소 및 최대 면적을 지정합니다. 작은 흠집만 없애려면 채울 구멍의 범위를 검사 대상에 맞게 고르고 처리 전후 마스크를 비교합니다. 관심 영역의 경계를 바꾸면 외부에 연결되었는지 여부가 달라질 수 있으므로 실제 검사에 사용하는 ROI에서 검증합니다.

    구멍 채우기 후에는 원래 전경과 새로 채워진 픽셀을 분리하여 비교해 보세요. 채우려던 작은 구멍 외의 배경까지 바뀌었다면 영역의 연결 상태와 지정한 면적 조건을 다시 확인해야 합니다.
