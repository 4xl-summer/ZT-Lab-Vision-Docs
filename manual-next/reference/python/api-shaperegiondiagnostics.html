공개 멤버

    데이터 필드

    필드타입기본값의미와 조건

    outside_feature_fractionfloat필수변환 모델 특징점 중 지정 사각형 밖에 있는 비율입니다.
    anchor_insidebool필수기준점이 지정 사각형에 포함되는지 나타냅니다.

    사용 맥락과 결과 해석

    지정 포즈로 변환한 형상 모델이 소스 로컬 사각형과 어떤 관계인지 나타냅니다. outside_area_fraction은 변환 모델 경계 면적 중 사각형 밖 비율이고 outside_feature_fraction은 특징점 중심 중 밖에 있는 비율입니다. anchor_inside는 모델 기준점이 영역 안인지 나타냅니다.

    영역이 (xmin,ymin,xmax,ymax)로 주어질 때 네 경계는 포함됩니다. 기준점이 안에 있어도 변환된 모델의 일부는 밖에 있을 수 있으므로 anchor_inside만으로 전체 포함을 판단하지 않습니다. 예를 들어 밖의 특징 비율이 0이어도 면적 비율은 다를 수 있습니다. 퇴화된 모델 경계나 무효한 사각형은 진단 입력 오류입니다.

    값을 확인하는 순서

    outside_area_fraction 항목: 변환 모델 경계 면적에서 지정 사각형 밖에 있는 비율입니다. outside_feature_fraction 항목: 변환 모델 특징점 중 지정 사각형 밖에 있는 비율입니다. anchor_inside 항목: 기준점이 지정 사각형에 포함되는지 나타냅니다.

    항목읽을 때 확인할 내용

    outside_feature_fraction변환 모델 특징점 중 지정 사각형 밖에 있는 비율입니다.
    anchor_inside기준점이 지정 사각형에 포함되는지 나타냅니다.
