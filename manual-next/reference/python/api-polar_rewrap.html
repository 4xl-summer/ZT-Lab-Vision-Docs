Python API · polar_rewrap

polar_rewrap 멤버와 선언

공개 타입

zvision.polar_rewrap: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._polar_gap.polar_rewrap.

Reconstruct one angular branch into an independent Cartesian canvas.

극좌표 영상을 지정한 Cartesian 캔버스의 선택 회전에 다시 표본화합니다.

Python
polar_rewrap(image, options, width, height, origin_x=0, origin_y=0, revolution=0)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • origin_x · POSITIONAL_OR_KEYWORD · 기본값 0
  • origin_y · POSITIONAL_OR_KEYWORD · 기본값 0
  • revolution · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

image
극좌표 입력 ZImage입니다.
options
PolarSpec 설정입니다.
width
출력 너비로 양의 정수입니다.
height
출력 높이로 양의 정수입니다.
origin_x
출력 X 원점으로 음이 아닌 정수이며 기본값은 0입니다.
origin_y
출력 Y 원점으로 음이 아닌 정수이며 기본값은 0입니다.
revolution
선택할 0–4294967295 정수 회전 번호이며 기본값은 0입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

height: 정수 검사 · 최소 1.

origin_x: 정수 검사.

origin_y: 정수 검사.

revolution: 정수 검사 · 최소 0.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.
