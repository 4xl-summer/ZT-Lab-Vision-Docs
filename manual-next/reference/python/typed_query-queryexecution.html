QueryExecution 멤버와 선언

공개 타입

zvision.QueryExecution: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._typed_query.QueryExecution.

불변 출력과 캡처를 소유하는 실행. close 후 스냅샷은 유효하다.

불변 결과와 캡처를 소유하는 타입이 지정된 Query 실행입니다.

execute()가 생성합니다. output은 캐시된 불변 값이며 이미 꺼낸 스냅샷은 실행을 닫은 뒤에도 유효합니다. get_image(name)의 독립 이미지 공유는 호출자가 닫습니다. 닫은 실행의 속성 접근은 ValueError입니다.

Python
QueryExecution() -> 'None'

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
