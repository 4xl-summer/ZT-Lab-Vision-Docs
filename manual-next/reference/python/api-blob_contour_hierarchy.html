공개 멤버

    링의 직접 포함 관계

    blob_contour_hierarchy는 단순 윤곽 링의 직접 부모와 자식 관계를 계산합니다. 바깥 경계, 내부 구멍, 그 안에 다시 포함된 영역을 계층으로 구분할 때 사용합니다. 단순히 경계의 나열 순서나 블롭 면적 순위와는 다른 정보입니다.

    최소 면적

    image에 마스크 ZImage를 전달하고 min_area로 포함할 최소 면적, work_budget으로 양의 작업량 상한을 지정합니다. 결과 노드의 selected는 면적 선택 여부를 나타냅니다. 선택 상태와 원래 직접 부모·자식 관계를 각각 확인해야 필터로 빠진 링을 혼동하지 않습니다.

    중첩 예

    하나의 큰 링 안에 구멍 링이 있고 그 안에 또 작은 링이 있으면 세 단계의 관계입니다. 큰 링의 직접 자식은 가운데 구멍이고 가장 안쪽 링은 그 구멍의 자식입니다. 직접 자식 수를 전체 자손 수로 해석하면 구조가 달라집니다.

    검사

    결과의 is_hole, parent와 enclosed_area를 원본 윤곽과 함께 표시합니다. 반환 id는 이 결과의 발견 순서 인덱스이므로 다른 입력의 같은 번호와 자동으로 대응하지 않습니다. 잘린 ROI나 바뀐 마스크는 링의 포함 관계를 바꿀 수 있습니다.
