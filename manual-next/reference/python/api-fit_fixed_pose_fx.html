Python API · fit_fixed_pose_fx

fit_fixed_pose_fx 멤버와 선언

공개 타입

zvision.fit_fixed_pose_fx: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.fit_fixed_pose_fx.

Fit selected cameras' fx while all poses and all other lens coefficients stay fixed.

자세와 다른 내참수를 고정하고 선택된 카메라의 fx를 적합합니다.

Python
fit_fixed_pose_fx(observations, lenses, cameras, boards, optimize_mask)

인자 선언

  • observations · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lenses · POSITIONAL_OR_KEYWORD · 기본값 없음
  • cameras · POSITIONAL_OR_KEYWORD · 기본값 없음
  • boards · POSITIONAL_OR_KEYWORD · 기본값 없음
  • optimize_mask · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

observations
카메라와 보드 인덱스 및 점 대응을 담는 GraphObservation 3–32개입니다.
lenses
카메라별 LensModel 2–8개입니다.
cameras
렌즈와 같은 수의 초기 6값 카메라 자세입니다.
boards
초기 6값 보드 자세 3–16개입니다.
optimize_mask
최적화할 카메라를 선택하는 0이 아닌 비트 마스크입니다.

반환: 렌즈와 오차 및 선택 마스크를 담은 FocalConstraintResult입니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: RuntimeError, TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
