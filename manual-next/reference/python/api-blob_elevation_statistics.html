blob_elevation_statistics 멤버와 선언

공개 타입

zvision.blob_elevation_statistics: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_elevation_stats.blob_elevation_statistics.

Measure already-corrected GrayF32 elevation in each blob local frame.

이미 보정된 높이 영상의 라벨별 통계를 계산합니다.

Python
blob_elevation_statistics(source, depth, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • depth · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
입력 BlobResult
depth
이미 보정한 GrayF32 높이 영상
work_budget
양의 정수 작업량 상한

반환: 독립 측정값 list

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    레이블별 보정 높이 통계

    blob_elevation_statistics는 BlobResult의 레이블을 이용해 이미 보정된 높이 영상의 값을 영역별로 통계화합니다. 높이 영상은 GrayF32이며 분할 결과의 레이블과 같은 공간을 나타내야 합니다. 이 호출이 원시 센서 깊이를 물리 높이로 자동 보정하는 단계는 아닙니다.

    좌표와 값

    같은 크기의 두 영상이라도 ROI가 서로 다른 위치를 가리키면 다른 물체의 높이를 읽을 수 있습니다. 레이블 맵과 depth의 위치와 크기를 맞추고 높이 값에 적용된 영점과 단위를 기록합니다. 같은 숫자라도 보정 방식이 다르면 직접 비교하기 어렵습니다.

    호출과 판독

    source에 BlobResult, depth에 보정된 높이 ZImage, work_budget에 양의 정수 상한을 전달합니다. 각 레이블이 의도한 객체를 가리키는지 마스크를 먼저 확인한 다음 해당 객체의 통계값을 읽습니다. 숫자만 보고 영역 분할이 정확했다고 판단하지 않습니다.

    측정 한계

    입력 높이의 유효성, 센서 잡음, 가려진 픽셀과 실제 장비의 교정은 별도 검증이 필요합니다. 보정이나 기준 평면이 바뀌면 결과 통계도 달라질 수 있으므로 분석 조건을 함께 저장합니다.
