    사용 맥락과 결과 해석

    여러 형상 모델을 공통 옵션과 공유 예산으로 검색한 결과입니다. matches는 모델 id가 붙은 후보의 불변 튜플이며 evaluated는 평가한 포즈 수입니다. incomplete는 모든 모델의 검색이 끝나기 전에 중단되었는지를 나타냅니다. 이 상태는 목록이 비었는지와 별개로 읽어야 합니다.

    예를 들어 한 후보가 발견되어도 incomplete가 참이면 아직 평가하지 않은 모델이 있을 수 있습니다. 항목 id로 학습 모델을 연결하고 매치의 위치·점수·각도를 확인한 뒤 검색 옵션과 예산을 기록합니다. 겹침 억제 방식을 켠 경우 실제 가까운 물체 후보가 제거될 수도 있으므로 결과 개수와 원래 기대 물체 수를 함께 검토합니다. 이 값은 네이티브 결과에서 복사된 스냅샷입니다.

    값을 확인하는 순서

    matches 항목: 검색 및 억제 후 남은 매치의 독립 불변 튜플입니다. evaluated 항목: 평가된 포즈 수입니다. incomplete 항목: 모든 모델의 검색을 끝내기 전에 종료했는지 나타냅니다.
