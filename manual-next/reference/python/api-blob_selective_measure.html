blob_selective_measure 멤버와 선언

공개 타입

zvision.blob_selective_measure: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_selective_measure.blob_selective_measure.

Analyze Gray8 components with optional inertia computation.

Gray8 연결 성분의 면적·중심과 선택적 관성을 계산합니다.

Python
blob_selective_measure(image, connectivity, compute_inertia, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음
  • compute_inertia · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
Gray8 ZImage; 최대 250,000픽셀.
connectivity
4 또는 8.
compute_inertia
bool; False면 축·방향은 0.
work_budget
양의 작업 한도; 픽셀 수의 10배(관성 없음) 또는 30배 이상.

반환: BlobSelectiveMeasurement 리스트.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류. 작업 예산 초과 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    Gray8 영상의 연결 성분을 분석하여 면적과 중심을 구하고 필요하면 관성에 기초한 축도 계산합니다. image는 입력 영상이고 connectivity는 어떤 이웃을 같은 성분으로 연결할지 정합니다. compute_inertia는 추가 축 계산 여부이며 work_budget은 호출의 작업 제한을 지정합니다. 같은 두 픽셀이 대각선으로만 닿은 경우 선택한 연결 규칙에 따라 하나 또는 둘의 성분으로 분류될 수 있습니다. 반환한 성분의 area는 픽셀 면적이고 중심은 이미지 좌표이므로 물리 면적이나 세계 좌표로 이름만 바꾸어 사용하지 마십시오. 관성 계산을 생략했다면 has_inertia 상태를 확인하고 축 숫자를 실제 물체의 크기 0으로 취급하지 않습니다. 예를 들어 같은 프레임에서 연결 규칙만 바꾸어 성분 수와 중심이 어떻게 달라지는지 비교하면 분리된 물체의 원인을 확인할 수 있습니다. 영상 형식과 설정이 유효하지 않거나 작업 제한에 걸린 오류는 성분이 없는 정상 결과와 구별합니다. 결과를 다른 ROI의 결과와 비교할 때는 중심을 공통 좌표계로 옮기고 각 성분이 같은 물체인지 별도로 확인하십시오. 단일 픽셀 크기와 면적 환산도 차원이 다르므로 물리 결과에는 알맞은 보정 조건을 사용합니다.
