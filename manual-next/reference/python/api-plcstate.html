열거 값

  • IDLE = 1 · 요청을 기다리는 상태입니다.
  • WAITING = 2 · 값 2. 모의 PLC가 요청을 수락한 뒤 결과 게시를 기다리는 상태입니다.
  • RESULT_READY = 3 · 결과가 준비된 상태입니다.
  • FAULTED = 4 · 모의 PLC 오류 상태입니다.

사용 맥락과 계약

PlcState는 장비와 통신하지 않는 모의 PLC 핸드셰이크의 진행 상태입니다. IDLE은 요청을 받을 수 있는 상태이고 WAITING은 요청이 진행 중인 상태, RESULT_READY는 결과가 게시되어 확인을 기다리는 상태입니다. FAULTED는 시간 초과 등으로 오류 상태에 들어간 경우를 나타냅니다. 각 상태는 외부 PLC가 실제로 같은 신호를 냈다는 의미가 아닙니다.

구체 사례와 판독

일반적인 흐름은 IDLE에서 REQUEST, WAITING에서 PUBLISH, RESULT_READY에서 ACK로 돌아오는 순서입니다. 예제의 요청 ID 1과 결과 코드 42는 명령의 상관관계를 보여 주기 위한 값입니다. 시간이 초과될 수 있는 상태에서는 POLL을 호출해 상태를 평가하며, FAULTED에서 RESET으로 복구합니다. 잘못된 순서나 요청 식별자는 오류이므로 상태 값과 반환된 PlcDisposition을 함께 기록하세요.

적용 시 확인

READY와 IDLE은 결과를 이미 확인했는지에 따라 다릅니다. ACK를 생략한 채 다음 요청을 시작하는 코드는 상태 전이 계약을 확인해야 합니다. 모의 객체가 반환한 상태는 물리적 배선이나 PLC 주기를 나타내지 않습니다.
