사용 맥락과 계약

AcquiredFrame은 모의 카메라 큐에서 꺼낸 프레임을 소유하는 객체입니다. info에는 소스와 epoch, 프레임·트리거 ID, 장치 틱과 호스트 시각 등이 담기고 image에서는 별도 소유 이미지 핸들을 얻습니다. 프레임 정보와 이미지 핸들은 역할이 다르므로 픽셀을 사용하려면 image를 얻고 그 핸들도 정리해야 합니다.

구체 사례와 판독

예를 들어 소프트웨어 트리거 ID 1을 등록하고 같은 ID의 프레임을 수락한 뒤 try_get_frame을 호출하면, 반환된 프레임의 ID와 영상 픽셀을 확인할 수 있습니다. 큐가 비어 있으면 None이므로 빈 상태를 먼저 분기하세요. 프레임과 이미지의 사용이 끝나면 각각 close하거나 with로 정리합니다. 원본 제출 영상과 취득 영상의 값이 같은 합성 사례가 실제 장치의 노출, 수송 또는 시간 정확도를 검증하는 것은 아닙니다.

적용 시 확인

AcquiredFrame.info는 픽셀 배열을 복사해 주는 값이 아닙니다. 데이터를 읽으려면 반환 이미지의 형식과 크기를 확인하고 그 객체에서 읽은 뒤 닫습니다. 프레임 ID와 트리거 ID는 실제 장치가 아닌 제출 데이터에서 온 모의 정보입니다. 영상 핸들을 얻기 전에 프레임이 None인지 확인해야 빈 큐를 정상 처리할 수 있습니다.
