    사용과 결과 해석

    고급 렌즈 추정의 결과 모델과 반복 진단을 담는 값입니다. model은 초점과 주점 및 왜곡 계수를 가진 LensModel이고 rms_pixels는 관측 픽셀에 대한 재투영 오차의 RMS입니다. iterations는 수행된 반복 수이며 converged는 종료 당시 수렴 여부를 나타냅니다. 예를 들어 초기 모델과 결과 모델의 RMS를 비교하려면 동일한 광선·픽셀 대응을 같은 순서로 사용해야 합니다. RMS가 작아도 사용 영역 전체의 정확도나 렌즈의 유일한 해를 보장하지 않습니다. 일부 계수만 최적화했다면 선택하지 않은 계수의 고정값과 입력 좌표계도 기록하십시오. 독립적인 보류 관측으로 예측 위치를 비교하고, 수렴하지 않은 결과를 수치가 있다는 이유만으로 정상 보정으로 사용하지 않습니다. 학습 결과를 비교할 때 두 모델의 수렴 플래그와 반복 수를 함께 보관합니다. 예를 들어 같은 픽셀 관측에서 재투영 RMS가 감소해도 일부 영역의 오차는 증가할 수 있으므로 위치별 오차도 검토해야 합니다. 숫자가 반환되었다는 사실만으로 미관측 영역까지 유효하다고 결론 내리지 마십시오. 모델의 각 계수와 RMS의 단위가 같다고 가정하지 말고 각 필드의 정의를 따르십시오. 반환된 반복 수는 수행된 횟수를 나타냅니다.
