Python API · euclidean_distance

euclidean_distance 멤버와 선언

공개 타입

zvision.euclidean_distance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._regions_flexible.euclidean_distance.

Exact Euclidean center distance using positive spacing; ROI exterior is not a target.

지정 대상 픽셀 중심까지 간격을 반영한 유클리드 거리를 구합니다.

Python
euclidean_distance(image, target_foreground, spacing_x, spacing_y, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_foreground · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spacing_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spacing_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
target_foreground
bool; 전경을 거리 측정 대상으로 선택할지 여부
spacing_x
x 방향 양의 표본 간격
spacing_y
y 방향 양의 표본 간격
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 거리 영상

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

work_budget: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
