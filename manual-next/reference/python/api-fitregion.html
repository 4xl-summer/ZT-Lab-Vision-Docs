  • maximum · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision._regions.Point2'> · 기본값 없음

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    minimumzvision._regions.Point2필수포함되는 입력 좌표계의 최소 모서리입니다.
    maximumzvision._regions.Point2필수포함되는 입력 좌표계의 최대 모서리입니다.

    포함 경계의 영역

    FitRegion은 minimum과 maximum 두 점으로 입력 원본 좌표계의 닫힌 영역을 나타냅니다. 두 경계는 포함됩니다. 이는 오른쪽과 아래를 제외하는 반열림 픽셀 슬라이스와 다른 규칙이므로 경계 위의 점을 선택할 때 구분해야 합니다.

    경계점 예

    minimum이 (1,2), maximum이 (4,6)이면 (1,2)와 (4,6)은 각각 경계에 있는 점입니다. 닫힌 영역이라는 정의상 이 두 경계도 포함됩니다. 점의 좌표 단위는 원본 점의 좌표계에 따르며 픽셀 또는 물리 단위인지 타입 이름만으로 확정할 수 없습니다.

    피팅 입력 선택

    영역에 포함되는 점을 피팅할 때 원본 점과 FitRegion이 같은 좌표 기준인지 먼저 확인합니다. ROI 로컬 점과 전체 영상 좌표의 경계를 그대로 비교하면 선택되는 점이 잘못될 수 있습니다. 필요하면 둘 중 하나를 공통 좌표계로 변환합니다.

    검증

    영역을 바꾼 뒤 선택된 점 수와 위치를 표시하고 피팅 결과의 잔차와 인라이어 여부를 확인합니다. 경계 영역을 지정하는 객체 자체가 충분한 점의 개수나 기하학적 배치를 보장하지는 않습니다.
