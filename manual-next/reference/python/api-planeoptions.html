PlaneOptions 멤버와 선언

공개 타입

zvision.PlaneOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.PlaneOptions.

Structure base class

옵션을 전달해 평면 가설 탐색과 정제를 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

Python
PlaneOptions(hypotheses=512, refinement=64, outlier_fraction=0.99, rms_tolerance=0.0, target_fraction=0.0)

인자 선언

  • hypotheses · POSITIONAL_OR_KEYWORD · 기본값 512
  • refinement · POSITIONAL_OR_KEYWORD · 기본값 64
  • outlier_fraction · POSITIONAL_OR_KEYWORD · 기본값 0.99
  • rms_tolerance · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • target_fraction · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

hypotheses
가설 탐색 횟수, 양의 정수; 기본 512
refinement
정제 반복 상한, 양의 정수; 기본 64
outlier_fraction
허용 이상치 비율, 유한한 [0,1); 기본 0.99
rms_tolerance
조기 종료 RMS 개선 허용값, 점군 길이 단위의 유한한 0 이상; 기본 0
target_fraction
조기 종료할 지지 비율; 0은 비활성, 그렇지 않으면 (0,1]; 기본 0

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
