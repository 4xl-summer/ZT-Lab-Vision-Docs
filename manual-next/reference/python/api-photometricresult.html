사용과 결과 해석

조명 방향이 다른 영상들로 계산한 광도 스테레오 결과를 소유합니다. image(index)로 필요한 출력을 각각 별도 소유 ZImage로 획득하고, 결과 객체와 획득한 영상은 각각 close해야 합니다. 인덱스에 따라 값의 의미와 형식이 다르므로 모든 출력을 같은 밝기 영상으로 취급하지 마십시오.

0은 반사량, 1~3은 법선 x·y·z, 4는 형상, 5는 강화 영상, 6은 유효 마스크입니다. 7과 8은 각각 Gaussian 및 평균 곡률, 9는 곡률 유효 마스크입니다. 예를 들어 법선 z가 존재하더라도 유효 마스크를 확인하지 않고 마스크 밖 위치를 실제 표면 값으로 해석하면 안 됩니다.

출력은 입력 조명과 마스크, 신호 및 조건수 설정에 의존하는 추정입니다. 획득한 영상의 수명과 결과 객체의 수명을 따로 관리하고, 실제 표면 높이의 물리 정확도나 실장비 검사 성능은 별도 검증해야 합니다.
