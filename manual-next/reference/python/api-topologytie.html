동률 처리

TopologyTie는 접촉 물체 분할에서 영역 확장 과정에 동률이 생겼을 때의 선택을 나타냅니다. DAM은 경계 댐을 두는 방식이고 LOWEST_LABEL은 낮은 레이블을 선택하는 방식입니다. 마커나 거리 계산을 대신하는 설정이 아니라 경합이 발생한 지점의 처리 규칙입니다.

결과 차이

두 마커에서 같은 조건으로 도달하는 지점이 있다면 어느 영역에 속하는지 또는 경계로 남는지가 결과의 모양과 크기에 영향을 줄 수 있습니다. 따라서 영역 개수만 비교하면 동률 규칙으로 바뀐 경계 위치를 놓칠 수 있습니다.

설정과 판독

SplitOptions의 tie를 선택하고 다른 거리, 마커, 연결 옵션을 고정한 상태에서 결과 레이블을 비교합니다. 분할선이 원하는 물체 접촉부를 따르는지 원본 영상과 겹쳐 확인하세요. LOWEST_LABEL의 숫자 선택을 물체의 중요도나 품질 순위로 해석하지 않습니다.

한계

이 규칙은 동률에서 결정을 내리는 방법이며 마커 자체가 올바른 물체에 놓였다는 보장은 아닙니다. 결과가 기대와 다르면 마커 위치와 개수, ROI, 거리와 경계 설정을 먼저 함께 점검합니다.
