사용 조건과 흐름

SsimBorder는 국소 SSIM 윈도가 영상 경계를 넘을 때의 처리 방식을 선택합니다. CLIP은 영상 안에 있는 범위로 윈도를 제한하고 REPLICATE는 가장자리 샘플을 확장하여 사용합니다. 이 선택은 SsimOptions에서 윈도 종류 및 반경과 별도로 지정하며 특히 영상 가장자리의 결과에 영향을 줍니다.

구체 사례와 결과 판독

예를 들어 왼쪽 위 모서리에 중심을 둔 3×3 윈도는 영상 밖 이웃을 포함합니다. CLIP은 이용 가능한 영역으로 제한하는 반면 REPLICATE는 경계 값을 반복해 이웃을 채웁니다. 같은 두 영상과 임계값이라도 모서리 점수가 달라질 수 있으므로 실제 검사 영역이 경계에 닿는지 확인하세요.

적용 시 확인

반경이 커질수록 경계의 영향을 받는 위치도 달라집니다. 대상이 영상 끝에 닿는 검사라면 중심부 점수만 확인하지 말고 경계 주변의 점수 맵과 결함 마스크를 직접 비교하세요. 포함 마스크는 영상 경계 처리와 별개의 조건이므로 함께 기록합니다. 예를 들어 모서리 픽셀이 100이고 바로 안쪽이 50이라면 반복 경계는 영상 밖을 100으로 채우지만 잘라내기는 그 위치를 통계에서 제외합니다. 이는 윈도 평균과 분산의 차이로 이어질 수 있습니다. 경계 처리와 임계값을 함께 보관하세요.
