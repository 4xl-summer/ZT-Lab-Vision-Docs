    사용과 결과 해석

    복합 계측 진단에서 원본 픽셀 좌표로 계산한 적합 계수와 선택적 통계를 담습니다. kind는 적합의 종류이고 values는 그 종류에 해당하는 수치 열이며 stats는 추가 적합 통계가 있으면 제공됩니다. 값의 위치별 의미는 kind를 확인한 뒤 해당 적합 형상의 계약에 따라 읽어야 합니다. 예를 들어 직선의 방향 성분과 원의 반경은 서로 다른 의미이므로 같은 인덱스의 숫자라는 이유로 동일한 단위나 필드로 처리하지 마십시오. stats가 None이면 통계가 없다는 뜻이며 RMS가 정확히 0이라는 뜻이 아닙니다. 프로브 진단의 선택 위치와 최종 적합의 채택 상태를 함께 보면 잘못된 경계가 들어갔는지 확인할 수 있습니다. 이 원본 적합 계수는 픽셀 기준이므로 물리 단위로 표현된 최종 복합 결과와 직접 같은 수치로 비교해서는 안 됩니다. 다른 ROI의 결과와 중심이나 점을 비교할 때는 각 원점을 공통 좌표계로 맞춥니다. 결과를 보관할 때 kind, values, stats의 존재 여부와 입력 ROI 설정을 함께 남겨야 나중에 형상과 좌표의 의미를 복원할 수 있습니다. 통계가 있다면 채택점 수와 잔차의 의미를 함께 확인하십시오. 한 개의 집계 수치만으로 각 프로브가 어느 경계에서 왔는지 알 수 없으므로 원본 관측도 같이 살핍니다.
