RecognitionQuery 멤버와 선언

공개 타입

zvision.RecognitionQuery: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition.RecognitionQuery.

Base class for typed recognition query terminals.

이 Query는 변경 가능한 계획입니다. 단계 추가는 같은 객체를 갱신하므로 별칭에도 반영됩니다. 분기하려면 clone()을 사용하고 execute()로 실행합니다. 실행과 Query는 각각 닫아야 합니다. 실패한 단계 추가는 기존 계획을 바꾸지 않습니다.

사용과 결과 해석

RecognitionQuery는 바코드 및 문자 인식용 지연 쿼리의 기반입니다. 구체 종단 타입에 따라 실행 후 결과의 형태가 다릅니다. BarcodeQuery는 BarcodeRead 값 스냅샷을, OcrQuery는 OcrRead 스냅샷을 반환하는 실행 경로를 사용하며, PreparedOcrQuery는 별도로 소유하는 준비 결과를 획득하는 경로를 사용합니다.

이미지에 인식 작업을 추가하고 구체 쿼리의 execute를 호출한 뒤 결과를 읽습니다. 바코드의 형식이나 OCR의 설정과 엔진은 해당 작업에서 선택합니다. 인식 실패 상태와 빈 문자열을 같은 성공으로 해석하지 말고 반환 상태와 입력 영역을 같이 확인해야 합니다.

clone은 독립적으로 확장할 수 있는 계획을 만듭니다. 따라서 조건이 다른 두 분기를 만들 때 원래 계획에 대한 변경을 피할 수 있습니다. 계획과 실행은 사용 뒤 닫고, 준비 OCR의 획득 결과도 별도 자원으로 해제합니다. 복사된 값 스냅샷과 소유 핸들의 수명을 혼동하지 않습니다.

읽기 설정과 이미지 영역이 바뀐 분기를 비교하려면 각 분기의 계획과 결과를 같은 실행 식별자에 연결합니다. 준비 영상의 좌표와 문자 결과의 위치를 표시할 때는 로컬 좌표와 원본 좌표를 구분합니다.
