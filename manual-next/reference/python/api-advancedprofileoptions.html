공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    interpolationint필수0 최근접, 1 이중선형 보간.

    filtertuple필수유한한 홀수 길이의 커널 튜플. 합이 기계 엡실론보다 절댓값이 커야 하고 합으로 정규화.

    사용과 결과 해석

    고급 프로파일의 보간, 위치별 최소 유효 횡단 폭과 길이 방향 필터를 지정합니다. 기본 프로파일과 달리 영상 밖 횡단 표본을 생략할 수 있지만, 각 중심에서 남은 유효 표본 수는 min_valid_width 이상이어야 합니다. interpolation은 최근접 또는 이중선형이며 filter는 유한한 홀수 길이 계수의 튜플입니다. 계수 합이 0에 너무 가깝지 않아야 하며 실제 합으로 정규화됩니다. 예를 들어 [1,1,1]은 합 3으로 나누는 세 위치 평균이고 끝에서는 끝값을 연장합니다. 필터를 바꾸면 기울기 피크도 달라질 수 있어 같은 임계값의 에지 결과를 그대로 가정하면 안 됩니다. ROI 경계 가까이에서 에지가 없는 이유를 조사할 때는 후보 자체뿐 아니라 유효 폭 부족으로 인한 오류도 구별하십시오. 폭 3의 표본에서 유효 횡단 위치가 두 개 남았다면 min_valid_width가 2인 설정은 그 위치의 최소 폭을 충족합니다. 최소 폭이 3이면 같은 위치는 조건을 충족하지 않습니다. 이 차이를 픽셀 강도가 낮아 에지 후보가 없는 경우와 구별하여 진단하십시오. 보간과 필터를 동시에 바꾸면 피크 차이의 원인을 분리하기 어렵습니다. 재현 실험에서는 한 조건씩 변경하십시오.
