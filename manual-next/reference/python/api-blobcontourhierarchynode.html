    selected_child_countint필수직접 자식 중 면적 선택을 통과한 수입니다.

    윤곽의 포함 관계

    BlobContourHierarchyNode는 윤곽 링의 id, 직접 parent, is_hole과 면적 선택 상태 selected를 담습니다. parent가 None이면 바깥쪽 노드입니다. id는 발견 순서로 부여된 반환 벡터 인덱스이며 서로 다른 분석 결과에서 유지되는 물체 ID로 보지 않습니다.

    면적과 자식

    enclosed_area는 중첩 링을 포함한 절대 다각형 면적입니다. child_count는 재부모화 전 직접 자식 수이고 selected_child_count는 그중 면적 선택을 통과한 직접 자식 수입니다. 모든 자손의 수나 전경 픽셀 수와 같은 값으로 해석하면 안 됩니다.

    중첩 예

    외곽 링 안에 구멍 링이 하나 있으면 외곽은 구멍의 직접 부모가 될 수 있습니다. 그 구멍 안에 다른 링이 있으면 그것은 구멍의 자식이며 처음 외곽의 직접 자식 수에 단순히 모두 더하지 않습니다. is_hole과 parent를 함께 따라가 구조를 확인합니다.

    사용 조건

    blob_contour_hierarchy의 최소 면적 설정을 함께 기록하고 selected 상태와 원래 구조를 함께 확인합니다. 이미지의 경계나 분할 조건이 바뀌면 윤곽과 포함 관계도 변할 수 있으므로 결과 인덱스만으로 다른 영상의 링을 대응시키지 않습니다.
