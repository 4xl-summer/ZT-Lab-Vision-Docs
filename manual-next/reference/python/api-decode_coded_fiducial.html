Python API · decode_coded_fiducial

decode_coded_fiducial 멤버와 선언

공개 타입

zvision.decode_coded_fiducial: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.decode_coded_fiducial.

Read a supplied axis-aligned Gray8 cell crop; recognizes quarter turns only.

지정한 Gray8 영역의 축 정렬 마커를 판독합니다.

Python
decode_coded_fiducial(image, x, y, cell_size, threshold=127, expected_id=None)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • cell_size · POSITIONAL_OR_KEYWORD · 기본값 없음
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 127
  • expected_id · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

image
Gray8 ZImage입니다.
x
마커의 ROI 로컬 X 원점입니다.
y
마커의 ROI 로컬 Y 원점입니다.
cell_size
1–256 픽셀 셀 크기입니다.
threshold
0–254 이진화 임계값이며 기본값은 127입니다.
expected_id
확인할 양의 16비트 ID 또는 None입니다.

반환: 디코딩된 CodedFiducial 값입니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
