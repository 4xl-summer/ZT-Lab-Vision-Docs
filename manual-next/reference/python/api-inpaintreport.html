Convergence means change tolerance only, not successful restoration.

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    iterationsint필수실제로 수행된 반복 횟수입니다.
    max_changefloat필수마지막 반복의 최대 픽셀 변경량입니다.
    convergedbool필수변화가 허용치 이하고 차단이 없으면 참입니다. 복원 품질 보증이 아닙니다.
    stalledbool필수변화가 허용치 이하지만 전도가 차단된 이웃이 있으면 참입니다.

    사용 조건과 흐름

    InpaintReport는 반복 복원의 종료 상태를 설명합니다. iterations는 실행한 반복 수이고 max_change는 변화의 최대 크기입니다. converged는 변화가 지정한 허용 조건을 만족했는지, stalled는 계산이 정체된 상태를 나타냅니다. 이 값은 원래 가려진 실제 픽셀을 정확히 복구했는지의 판정이 아닙니다.

    구체 사례와 결과 판독

    예를 들어 허용 변화가 0.01이고 반복 중 최대 변화가 그 기준 이내에 들어가 수렴으로 보고될 수 있습니다. 그 결과가 매우 부드러워졌더라도 복원된 내용이 실제 물체의 원래 무늬와 일치한다는 의미는 아닙니다. 마스크의 위치와 반복 제한, 결과 영상의 경계도 함께 확인하세요.

    적용 시 확인

    반복 상한에 도달해 종료한 것과 변화 허용치를 만족한 것은 구별해야 합니다. max_change와 iterations를 설정값과 비교하고 stalled도 함께 기록하세요. 원본이 알려진 일부 영역을 가려 복원해 보는 독립 검증은 설정별 오차를 비교하는 데 도움이 됩니다. 예를 들어 반복 한도가 100이고 100회에 도달한 결과라면 converged와 stalled를 확인해 종료 이유를 구분하세요. 값이 거의 변하지 않는 것과 참값을 회복한 것은 다른 주장입니다.
