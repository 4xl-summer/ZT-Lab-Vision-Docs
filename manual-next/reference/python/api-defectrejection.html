공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    indexint필수입력 결함 배열의 0부터 시작하는 인덱스입니다.
    reasonsint필수해당 결함의 개별 면적 또는 위치 위반 비트입니다.

    사용과 결과 해석

    후보 하나에 연결된 개별 위반 기록입니다. index는 입력 결함 배열의 0부터 시작하는 위치이고 reasons는 해당 후보의 개별 면적 또는 허용 위치 위반을 나타내는 비트입니다. 후보 전체의 개수 초과나 총 면적 초과는 판정 결과 전체의 이유에 나타나며, 그 조건만으로 각 후보의 개별 기록이 생기는 것은 아닙니다.

    예를 들어 후보 두 개의 총 면적이 상한을 넘지만 각 후보가 개별 면적과 위치 조건을 만족한다면 전체 판정에는 TOTAL_AREA 사유가 생길 수 있습니다. 이때 Rejections의 길이만 보고 판정이 통과했다고 결론내리면 안 됩니다. 반대로 한 후보의 경계가 허용 영역을 벗어나면 해당 index와 LOCATION 비트를 살펴 그 후보를 찾아갈 수 있습니다.

    index가 가리키는 순서는 판정에 전달한 후보 배열을 기준으로 합니다. 다른 실행에서 얻은 후보 배열과 섞어 사용하면 표시할 위치가 달라질 수 있으므로 같은 프레임의 후보와 판정을 함께 기록합니다. 이 값은 판정 결과에서 복사된 기록이며 결과의 소유 핸들 또는 원본 영상과 동일한 수명으로 취급하지 않습니다.

    면적 한도는 픽셀 수이고 위치는 후보 경계의 로컬 사각형으로 평가합니다. 기록을 해석할 때 두 조건의 단위와 전체 판정의 이유를 따로 확인하세요.
