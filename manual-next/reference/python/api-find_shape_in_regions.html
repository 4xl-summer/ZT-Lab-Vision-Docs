Python API · find_shape_in_regions

find_shape_in_regions 멤버와 선언

공개 타입

zvision.find_shape_in_regions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.find_shape_in_regions.

Search every bounded grid pose subject to inclusive anchor and model-region constraints.

기준점과 변환 모델에 각각 영역 제약을 적용해 검색합니다.

Python
find_shape_in_regions(source, model, options, anchor, region, max_outside, require_full=False, mask=None)

확인된 인자 조건

source
검색할 ZImage입니다.
model
형상 AdvancedMatchModel입니다.
options
AdvancedMatchOptions 값입니다. x·y·angle·scale_x·scale_y에 각각 SearchAxis(minimum, maximum, step)를 지정합니다. 일반 검색에서 x·y는 검색 ROI 로컬 픽셀, angle은 라디안이며 scale은 양수입니다. candidate_budget은 평가 포즈 수 상한입니다. coarse=False, subpixel=False, certainty=None, max_occlusion_fraction=0이어야 합니다. anchor와 region은 별도 로컬 포함 사각형입니다.
anchor
기준점 허용 사각형입니다.
region
모델 허용 사각형입니다.
max_outside
허용 밖 비율 0..1입니다.
require_full
전체 포함 요구 여부이며 기본값 False입니다.
mask
선택적 검색 마스크 ZImage이며 기본값 None입니다.

반환: 독립 매치 결과와 종료 진단입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
