    사용 맥락과 결과 해석

    사각형 탐침 측정의 상태, 선택적 적합과 탐침별 진단을 담는 독립 결과입니다. status가 0이면 fit이 있으며 다른 상태에서는 None입니다. probes에는 각 탐침의 위치, 면 연결과 사용 여부 등 진단이 들어갑니다. 먼저 상태를 확인하고 유효한 fit만 후속 계산에 사용합니다.

    converged와 iterations는 수치 최적화의 종료 상태이며 정확도의 보장은 아닙니다. condition_proxy는 가중 Jacobian 열 노름의 비율이지 신뢰구간이 아닙니다. 사각형의 초기 면별 탐침이 충분한 에지를 찾았는지 살펴보면 실패 원인을 좁힐 수 있습니다. 중심과 반축은 측정에 사용한 ROI의 로컬 픽셀 단위입니다.

    값을 확인하는 순서

    status 항목: 적합 성공(0), 점 부족(1), 적합 실패(2) 상태입니다. fit 항목: 성공 시 적합된 사각형 값이고 그 외에는 None입니다. probes 항목: 탐침별 관측과 진단을 담은 독립 튜플입니다. converged 항목: 반복 적합의 수렴 여부입니다. iterations 항목: 적합 반복 횟수입니다. condition_proxy 항목: 가중 Jacobian 열 노름의 최대/최소 비율 또는 계산되지 않았으면 None입니다. 행렬 조건수는 아닙니다.
