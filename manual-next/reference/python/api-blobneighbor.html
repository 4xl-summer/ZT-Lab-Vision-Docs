공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    firstint필수입력 영역 목록에서 첫 영역의 인덱스입니다.
    secondint필수입력 영역 목록에서 둘째 영역의 인덱스입니다.
    distancefloat필수두 영역 경계 픽셀 중심 사이의 최소 거리(픽셀)입니다.

    입력 영역의 이웃 쌍

    BlobNeighbor는 입력 영역 목록의 first와 second 인덱스 및 distance를 담습니다. distance는 두 영역의 경계 픽셀 중심 사이 최소 거리이며, 각 영역의 무게중심이나 외접 사각형 중심의 거리가 아닙니다. 인덱스는 해당 호출에 전달한 영역 목록의 순서에 대응합니다.

    거리 예

    두 영역에서 가장 가까운 경계 픽셀 중심이 (1,2)와 (4,6)이면 차이는 (3,4)이고 거리는 5픽셀입니다. 두 셀의 모서리 사이 빈 공간 폭이 5라는 뜻은 아닙니다. 거리를 실제 길이로 바꾸려면 좌표 보정과 축 간격을 별도로 고려해야 합니다.

    후속 사용

    blob_region_neighbors의 결과에서 두 인덱스로 원래 마스크를 찾아 어떤 영역끼리 가까운지 확인합니다. 목록 순서를 바꾼 뒤 이전 결과의 인덱스를 재사용하면 다른 영역을 가리킬 수 있으므로 입력 순서를 결과와 함께 보관합니다.

    좌표와 제한

    두 영역은 서로 비교 가능한 같은 좌표 기준에 있어야 합니다. ROI가 다른 이미지를 한 목록에 넣을 때는 로컬 좌표가 같은 실제 위치를 나타내는지 확인합니다. 영역 분할이 바뀌면 경계와 최근접 거리도 바뀔 수 있습니다.
