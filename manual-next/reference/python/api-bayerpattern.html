사용 맥락과 계약

BayerPattern은 단일 센서 픽셀에 배치된 색 필터의 반복 순서를 지정합니다. RGGB, BGGR, GRBG, GBRG는 2×2 타일의 왼쪽 위부터 행 순서로 읽은 배열을 구별합니다. 같은 원본 샘플을 다른 패턴으로 해석하면 빨강과 파랑 또는 녹색 위치가 달라져 복원 색상이 틀어질 수 있습니다.

구체 사례와 판독

예를 들어 RGGB 타일은 첫 행 R,G이고 둘째 행 G,B입니다. 한 픽셀씩 오른쪽으로 이동한 위치를 새 원점으로 삼으면 그 위치에서 보이는 반복의 시작은 달라집니다. 따라서 센서의 실제 필터 배열뿐 아니라 사용 중인 영상이나 ROI의 원점이 패턴에 어떤 영향을 주는지 확인해야 합니다. 패턴 이름은 RGB 완성 영상의 채널 순서를 뜻하지 않습니다.

적용 시 확인

2×2 타일은 영상 전체에서 반복되므로 원점의 짝수·홀수 위치가 중요합니다. 하드웨어나 파일이 보고하는 센서 패턴과 잘라낸 영상의 실제 시작 위치를 함께 확인하고, 알려진 빨강·파랑 대상의 결과로 색상 복원이 올바른지 점검하세요. 잘못된 패턴은 필터링 강도를 조정해 해결할 문제가 아닙니다. 촬영 영상의 방향 회전이나 뒤집기도 결과 픽셀의 배치를 바꿀 수 있으므로 영상이 어디에서 만들어졌는지 확인합니다.
