    사용과 결과 해석

    OCR이 읽은 한 문자의 유니코드 codepoint와 네 모서리 좌표를 묶는 불변 값입니다. corners는 RecognitionPoint의 튜플로 정규화되며 각 점은 로컬과 전역 위치를 함께 보유합니다. 결과의 전체 문자열과 함께 읽으면 특정 문자가 원본 영상의 어느 위치에 대응하는지 살펴볼 수 있습니다.

    화면에 사각형을 표시할 때 현재 보여 주는 영상의 좌표계에 맞춰 local 또는 global_을 선택합니다. ROI 원점을 이미 반영한 전역 점에 원점을 다시 더하면 오버레이가 이동합니다. 문자별 경계는 네 점이므로 회전된 글자도 단순 축 정렬 사각형으로 축약하기 전에 원래 모서리를 살펴보는 것이 좋습니다.

    OcrRead의 chars는 문자 스냅샷의 튜플입니다. codepoint와 모서리가 있다는 사실만으로 전체 읽기가 수락되었다고 추정하지 말고 status와 reasons도 확인합니다. 인식 설정의 allowed_chars는 출력 가능한 ASCII만 허용하지만 이 필드 자체는 정수 코드 포인트를 표현합니다.

    좌표는 사각형을 둘러싼 영상의 원점에 따라 해석해야 합니다. 글자 단위의 표시와 전체 문자열의 수락 상태를 함께 보여 주면 사용자가 어느 문자가 어느 영역에 대응하는지 살펴볼 수 있습니다.
