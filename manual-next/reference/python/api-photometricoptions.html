    lights: 네 조명 방향·강도의 xyz 벡터 네 개이며 각 성분은 유한해야 합니다.

    min_signal: 법선 추정의 최소 반사 신호로 유한한 0 이상입니다.

    min_rcond: 조명 정규 방정식의 역조건수 하한으로 유한한 [0, 1)입니다.

    spacing_x: 세계 x 방향 픽셀 간격으로 유한한 양수입니다.

    spacing_y: 세계 y 방향 픽셀 간격으로 유한한 양수입니다.

    min_normal_z: 곡률 계산에 필요한 법선 z 절댓값의 하한으로 유한한 [0, 1)입니다.

    smooth_radius: 법선 평활 반경(픽셀)입니다. 작업량 제한에도 영향을 줍니다.

    brightness: 평탄부 출력 밝기 비율로 유한한 [0, 1]입니다.

    contrast: 부호 있는 형상 응답의 출력 배율로 유한한 0 이상입니다.

    max_work: 평활 등 계산의 양의 작업량 상한입니다.
