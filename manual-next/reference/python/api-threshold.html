Python API · threshold

threshold 멤버와 선언

공개 타입

zvision.threshold: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._processing_advanced.threshold.

Kinds fixed/range-in/range-out/percentile/triangle/Otsu/dominant/bimodal/mean/midrange/Gaussian = 0..10; result 0 mask, 1 threshold map.

선택한 전역·지역 임계값 규칙으로 영상 또는 임계값 맵을 생성합니다.

Python
threshold(image, kind, a=0.0, b=0.0, radius=0, comparison=4, minimum=0.0, maximum=255.0, seed=None, result=0)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • kind · POSITIONAL_OR_KEYWORD · 기본값 없음
  • a · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • b · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • radius · POSITIONAL_OR_KEYWORD · 기본값 0
  • comparison · POSITIONAL_OR_KEYWORD · 기본값 4
  • minimum · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • maximum · POSITIONAL_OR_KEYWORD · 기본값 255.0
  • seed · POSITIONAL_OR_KEYWORD · 기본값 None
  • result · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

image
ZImage 입력 영상
kind
0 고정, 1 범위 내, 2 범위 밖, 3 분위, 4 삼각형, 5 Otsu, 6 지배값, 7 쌍봉, 8 평균, 9 중간 범위, 10 가우시안
a
고정 임계값·범위 하한·분위수 또는 국소 오프셋; kind에 따라 해석, 기본값 0.0
b
범위 상한 또는 국소 Gaussian sigma; 기본값 0.0
radius
국소 이웃 반경; 기본값 0
comparison
0 미만, 1 이하, 2 같음, 3 다름, 4 이상, 5 초과; 기본값 4
minimum
계산된 임계값의 유한한 클램프 하한; 기본값 0.0
maximum
계산된 임계값의 유한한 클램프 상한; minimum 이상, 기본값 255.0
seed
선택된 마스크에서 연결 전경을 제한할 선택 시드 ZImage; 기본값 None
result
0 마스크, 1 임계값 맵; 기본값 0

반환: result=0이면 별도로 close할 Gray8 마스크, 1이면 GrayF32 임계값 맵입니다.

오류: 범위형은 비교 코드 4가 필요하고, 범위 역전·비유한 값·지원되지 않는 입력은 오류입니다.

kind: 정수 검사 · 최소 0.

radius: 정수 검사.

comparison: 정수 검사 · 최소 0.

result: 정수 검사 · 최소 0.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
