    간선의 양 끝과 경로

    SkeletonEdge는 start와 end 노드 인덱스, 경로를 구성하는 points, 그 경로의 length를 담습니다. 시작과 끝의 좌표만을 이은 직선과 실제 골격 경로는 다를 수 있으므로 굽은 가지를 측정할 때는 전체 점 경로와 계산된 길이를 사용합니다.

    길이 해석

    점이 (0,0), (1,0), (1,1) 순서로 이어지고 두 축의 간격이 1이면 두 인접 이동 길이의 합은 2입니다. 두 끝점을 잇는 직선 거리는 √2로 더 짧습니다. 축 간격이 다른 경우에는 각 방향 이동의 실제 간격을 반영해야 하므로 그래프 생성 옵션도 확인합니다.

    인덱스와 입력 검증

    start와 end는 같은 SkeletonGraph의 nodes를 참조합니다. 점 시퀀스는 생성 시 튜플로 보관되고 Point2가 아닌 값이 있으면 TypeError가 발생합니다. 그래프를 여러 개 비교할 때 한 그래프의 인덱스를 다른 그래프의 식별자로 사용하지 말고 위치와 연결 구조를 기준으로 대조합니다.

    분기점을 공유하는 여러 간선이 있으면 각 간선의 start와 end가 같은 노드를 가리킬 수 있습니다. 경로 배열의 점 수만으로 길이를 판단하지 말고 축 간격이 적용된 length를 확인합니다.
