blob_convex_region 멤버와 선언

공개 타입

zvision.blob_convex_region: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_convex_region.blob_convex_region.

Return a detached Gray8 mask of selected Blob hull at pixel centers.

선택 Blob의 볼록 껍질 내부 픽셀 중심을 마스크로 그립니다.

Python
blob_convex_region(source, index, reference, work_budget)

공개 멤버

    볼록껍질 내부 마스크

    blob_convex_region은 선택한 Blob의 볼록껍질 내부에 있는 픽셀 중심을 마스크로 그립니다. 오목한 물체의 홈은 볼록껍질 안에 포함될 수 있으므로 이 결과의 전경 면적은 원래 블롭의 전경 면적과 같은 뜻이 아닙니다.

    성분과 기준

    source의 BlobResult에서 index로 0 기반 성분을 선택하고 reference 영상으로 출력 기준을 지정합니다. 첫 성분은 0이며 다른 분석 결과의 같은 번호가 같은 객체를 뜻한다고 보장하지 않습니다. 양의 work_budget을 지정하고 결과와 원본이 같은 좌표 기준에 있는지 확인합니다.

    형상 해석

    예를 들어 U자 모양 전경의 양 끝을 연결한 볼록껍질에는 원래 비어 있던 안쪽 일부가 포함될 수 있습니다. 결과를 원래 마스크와 겹쳐 보면 새로 포함된 영역을 구별할 수 있습니다. 이는 구멍 채우기와도 다르게 전체 외곽의 볼록성을 사용합니다.

    적용 조건

    후속 면적이나 거리 측정은 원본 대신 볼록 영역을 사용하는지 명시해야 합니다. ROI에서 잘린 물체는 보이는 부분을 기준으로 껍질을 만들게 되므로 완전한 물체의 모양으로 추정하지 않습니다.
