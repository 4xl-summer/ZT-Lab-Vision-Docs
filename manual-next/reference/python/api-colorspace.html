사용과 결과 해석

색 평면 묶음이 어떤 좌표 체계를 갖는지 나타내는 값입니다. HSV는 색상·채도·명도의 세 채널이고 LAB은 CIELAB의 L*, a*, b* 세 채널을 나타냅니다. 같은 세 개의 영상으로 저장되어도 채널 숫자의 의미가 다르므로 공간 정보를 확인하지 않고 두 번째나 세 번째 채널을 같은 물리량으로 취급하지 않습니다. ColorPlanesInfo의 space를 확인하면 반환된 평면이 어떤 체계인지 알 수 있습니다.

색 변환은 입력 영상과 별도의 결과를 만듭니다. 평면 결과에서 채널을 얻으면 그 영상도 별도 소유 객체이므로 결과를 닫는 것과 구별해 정리합니다. 다시 RGB 영상이 필요하면 평면 결과의 변환 호출에 지원되는 출력 형식을 지정합니다. 결과의 너비와 높이, 전역 원점은 부분 영상을 처리할 때 위치를 해석하는 데 필요합니다.

예를 들어 RGB의 단순 채널 순서 변경과 Lab 색차 계산은 서로 다른 작업입니다. D50 Lab 좌표에서 기준과의 거리를 계산하려면 좌표 체계와 기준 백색점을 맞춰야 합니다. 출력의 색 공간만으로 검사 허용 색차가 정해지는 것은 아니므로 필요한 거리 기준과 임계값을 별도로 선택합니다.

공간을 변환한 뒤 채널 하나를 수정 가능한 공유 버퍼로 간주하지 말고 반환된 영상의 API와 수명 계약을 확인하세요.
