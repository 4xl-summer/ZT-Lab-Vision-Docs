    사용과 결과 해석

    Data Matrix 오류 정정 진단의 text, version, blocks, corrected_codewords와 accepted를 담는 값입니다. 블록 항목은 QrEccBlock 형식의 데이터·패리티·정정 코드워드 수를 사용하지만 결과의 기호 형식은 Data Matrix입니다. 타입 이름만 보고 QR 영상의 버전이나 오류 정정 수준으로 해석하지 않습니다.

    동일한 문자가 복원되어도 정정된 코드워드 수는 입력 손상에 따라 달라질 수 있습니다. 총 수치와 각 블록을 같이 읽고, 지정된 블록별 한도에 대한 accepted를 확인합니다. 한도는 정정 이후의 수락 검사로 사용되며 디코더의 정정 능력을 새로 설정하는 값이 아닙니다.

    모듈 격자와 이미지 입력 중 사용한 함수의 조건을 확인하고 입력 및 결과를 함께 기록합니다. 코드워드는 여러 비트로 이루어진 단위이므로 정정 수와 손상된 셀 또는 픽셀 수를 동일시하지 않습니다. 품질 인증 등급으로도 쓰지 않습니다.

    블록별 정정 수를 비교하면 전체 합계가 같아도 특정 블록에 손상이 몰린 사례를 구별할 수 있습니다. 기준을 변경한 재실행에서는 사용한 한도와 해당 결과의 accepted를 짝지어 보관합니다.
