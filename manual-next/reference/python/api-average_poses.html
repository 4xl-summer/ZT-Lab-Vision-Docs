Python API · average_poses

average_poses 멤버와 선언

공개 타입

zvision.average_poses: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.average_poses.

Compute a sign-invariant weighted quaternion and translation mean.

동일 프레임 자세를 가중 쿼터니언 및 이동 평균으로 합칩니다.

Python
average_poses(poses, weights)

인자 선언

  • poses · POSITIONAL_OR_KEYWORD · 기본값 없음
  • weights · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

poses
RigidTransform3 1–4096개입니다.
weights
같은 개수의 가중치입니다.

반환: 평균 자세와 진단을 담은 PoseAverage 값입니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    average_poses는 1개부터 4096개까지의 강체 자세와 동일 개수의 가중치를 받아 회전과 이동의 가중 평균을 구합니다. 회전은 부호에 불변인 쿼터니언 방식이고 이동도 가중치를 반영합니다. 결과의 pose와 count 및 회전 평균의 eigen_gap을 함께 확인해야 합니다.

    구체 사례와 판독

    예를 들어 회전이 같고 X 위치가 각각 0과 10인 두 자세에 같은 가중치를 사용하면 X 평균은 5입니다. 첫 가중치를 더 크게 주면 평균 위치는 첫 자세 쪽으로 이동합니다. 서로 다른 프레임이나 서로 다른 길이 단위의 자세를 평균하면 숫자 결과가 나오더라도 의미가 없으므로 공통 프레임과 단위로 먼저 변환합니다.

    적용 시 확인

    가중치와 자세의 순서가 한 칸만 어긋나도 어느 관측을 더 신뢰할지가 바뀝니다. 가중치는 대응하는 자세와 함께 보관하고 모든 입력이 동일한 물리적 프레임을 기준으로 하는지 확인하세요. 결과는 개별 관측을 대신하지 않으므로 이상치를 분석할 때 원본 자세 목록도 보존합니다. 예를 들어 같은 두 위치에 가중치 3과 1을 쓰면 이동 X의 가중 평균은 (3×0+1×10)/4=2.5입니다. 회전의 결과를 이 선형 계산으로 대체하지 마세요. 이 값은 이동 성분에만 적용한 예입니다.
