통과 대역의 선택

FrequencyPass는 주파수 필터에서 LOW, HIGH, BAND, NOTCH를 구별합니다. 저역 선택은 느린 공간 변화, 고역 선택은 빠른 공간 변화와 관련이 있으며 대역 통과와 노치는 지정한 주파수 영역을 다르게 다룹니다. 실제 컷오프와 마스크 모양은 이를 사용하는 필터 옵션에서 함께 지정해야 합니다.

영상에서의 의미

천천히 바뀌는 조명과 급격한 가장자리가 함께 있는 영상에서 저역을 강조하면 큰 밝기 변화의 흐름을 살펴볼 수 있고 고역을 강조하면 빠르게 변하는 구조가 강조될 수 있습니다. 노이즈도 고주파일 수 있으므로 고역 결과가 곧 물체 경계만을 뜻하지는 않습니다.

설정과 확인

공간 영상을 주파수 영역으로 변환한 후 통과 방식과 해당 주파수 설정을 적용하고 필요하면 역변환하여 결과를 확인합니다. 입력 크기와 변환 격자, 주파수의 기준을 기록해야 같은 숫자의 설정을 다른 영상에서 재현할 수 있습니다. 이 열거형 자체가 컷오프 값이나 스펙트럼을 보관하지는 않습니다.

주파수 필터를 적용한 뒤 역변환 결과를 원본과 같은 좌표에서 비교하면 강조되거나 억제된 구조를 볼 수 있습니다. 경계 근처의 변화와 원본의 주기적 무늬를 따로 살펴 설정이 의도에 맞는지 판단합니다.
