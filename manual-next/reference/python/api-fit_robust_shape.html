Python API · fit_robust_shape

fit_robust_shape 멤버와 선언

공개 타입

zvision.fit_robust_shape: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_measurement.fit_robust_shape.

Fit 1=line, 2=circle or 3=ellipse to at most 10,000 Point2 values.

제공한 점에 선·원·타원을 강건 적합합니다.

Python
fit_robust_shape(points, kind, options=RobustFitOptions(loss=1, scale=0.5, initial_threshold=2.0, inlier_threshold=1.0, max_iterations=30, tolerance=1e-08, damping=0.001))

인자 선언

  • points · POSITIONAL_OR_KEYWORD · 기본값 없음
  • kind · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 RobustFitOptions(loss=1, scale=0.5, initial_threshold=2.0, inlier_threshold=1.0, max_iterations=30, tolerance=1e-08, damping=0.001)

확인된 인자 조건

points
최대 10000개의 Point2 시퀀스입니다.
kind
1 선, 2 원, 3 타원입니다.
options
RobustFitOptions 값입니다. RobustFitOptions()의 기본 손실은 Huber이며 scale, initial_threshold, inlier_threshold는 입력 좌표 단위, tolerance는 정규화 좌표의 수렴 기준입니다. max_iterations는 1..1000입니다.

반환: 상태, 적합 및 점별 진단을 담은 ShapeResult입니다.

오류: 입력 타입, 점 수 또는 설정이 유효하지 않으면 오류입니다.

kind: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
