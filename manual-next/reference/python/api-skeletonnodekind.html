노드 분류

SkeletonNodeKind는 골격 그래프 노드의 역할을 ENDPOINT, JUNCTION, ISOLATED, LOOP_ANCHOR로 구분합니다. 각각 끝점, 가지가 만나는 접합점, 고립점, 닫힌 루프를 표현하는 기준점입니다. 값은 해당 노드의 좌표와 차수와 함께 읽어야 합니다.

선과 고리

직선 모양의 골격은 양쪽에 끝점이 있고 중간에 접합점이 없을 수 있습니다. 반면 가지들이 만나는 구조에는 접합점이 생깁니다. 닫힌 고리에는 자연스러운 끝점이 없으므로 그래프가 경로를 표현할 수 있도록 합성 루프 기준점을 둘 수 있습니다.

생성과 사용

skeleton_graph가 만든 SkeletonGraph에서 각 SkeletonNode의 kind를 확인하고 연결된 SkeletonEdge를 따라갑니다. 원래 마스크의 잡음, 세선화, 짧은 가지 제거 설정에 따라 노드 수가 달라질 수 있으므로 서로 다른 결과를 비교할 때 전처리 과정을 함께 기록합니다.

해석의 범위

노드 종류는 그래프 연결 구조에 대한 분류이지 객체가 양품인지 불량인지 직접 알려주는 판정값은 아닙니다. 예를 들어 끝점이 추가된 이유가 실제 갈라짐인지 마스크 잡음인지는 원본 영상과 함께 확인해야 합니다.
