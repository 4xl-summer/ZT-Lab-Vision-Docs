    데이터 필드

    필드타입기본값의미와 조건
    regionzvision._recognition.OcrRegionSpec필수현재 이미지의 로컬 픽셀 좌표에 지정한 OCR 영역 설정입니다.
    min_contrastfloat필수원본 영역 대비의 최소값으로 0~1이며 같은 값은 통과합니다.
    min_lengthint필수허용할 최소 Unicode 문자 수로 1 이상입니다.
    max_lengthint필수허용할 최대 Unicode 문자 수이며 최소 길이 이상이어야 합니다.
    allowed_charsstr필수결과 판정에 허용할 출력 가능 ASCII 문자 집합이며 비어 있을 수 없습니다.

    사용과 결과 해석

    단일 행 OCR의 입력 영역과 수락 조건을 담는 값입니다. region은 OcrRegionSpec이고 min_contrast는 요구하는 대비, min_length와 max_length는 읽은 문자열의 길이 조건, allowed_chars는 허용 문자 집합입니다. 이미지에서 영역을 준비하는 설정과 읽은 문자열을 수락할 기준을 한 요청에서 함께 전달합니다.

    allowed_chars는 비어 있지 않은 출력 가능한 ASCII 문자열이어야 하며 Python 바인딩은 UTF-8 바이트가 32에서 126 범위인지 확인합니다. 길이 인자는 각각 1 이상이어야 합니다. 예를 들어 숫자만 허용할 때 해당 숫자 문자를 집합에 넣으면 인식 결과의 문자 조건을 그 설정과 함께 판독할 수 있습니다.

    인식에는 OcrEngine과 이미지가 별도로 필요합니다. 결과 OcrRead의 status와 reasons를 읽어 미발견, 대비 또는 문자와 길이 조건 관련 결과를 확인합니다. min_contrast는 원시 픽셀 밝기 차이에 대한 기준이며 표준 바코드 품질 등급이나 인식 확률을 뜻하지 않습니다.

    영역의 quarter_turns는 0부터 3까지의 정수이고 ROI의 폭과 높이는 양수입니다. OCR 설정을 바꾼 재시도 결과는 기존 결과를 덮어쓰기보다 어떤 조건이 사용되었는지 함께 비교합니다.
