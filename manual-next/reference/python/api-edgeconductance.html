확산의 전도 함수

EdgeConductance는 비등방 확산에서 밝기 변화에 대응하는 전도 함수 종류를 선택합니다. EXPONENTIAL은 지수형, RECIPROCAL은 역수형을 나타냅니다. 이 선택은 반복 중 경계 부근의 확산 정도에 관여하지만, 함수 이름만으로 모든 이미지에서 어떤 결과가 더 적합한지 정할 수는 없습니다.

설정 비교

같은 입력에서 두 방식을 비교할 때는 반복 횟수, kappa, 시간 단계와 정지 조건을 고정합니다. 그래야 결과 차이를 전도 함수의 선택과 연결해 살펴볼 수 있습니다. 밝기 변화가 큰 경계와 균일한 영역을 각각 확인하면 잡음 감소와 경계 보존 사이의 차이를 관찰하기 쉽습니다.

결과의 판독

처리 후에는 영상과 반복 보고를 함께 확인합니다. 수렴 여부는 정지 조건에 대한 정보이고 실제 물체의 세부가 충분히 보존됐다는 보장은 아닙니다. 관심 있는 결함의 폭이나 대비에 따라 설정을 평가하고, 비교 결과를 재현하려면 입력 형식과 옵션 전체를 저장합니다.

고정된 입력에서 전도 방식만 바꾼 출력과 원본을 같은 표시 범위로 비교하세요. 표시 범위가 각 영상마다 자동으로 바뀌면 실제 밝기 차이와 시각화 스케일 차이를 구별하기 어려워집니다.
