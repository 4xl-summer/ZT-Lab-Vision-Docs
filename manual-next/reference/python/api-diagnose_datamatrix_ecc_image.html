diagnose_datamatrix_ecc_image 멤버와 선언

공개 타입

zvision.diagnose_datamatrix_ecc_image: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.diagnose_datamatrix_ecc_image.

Detect one Data Matrix symbol in a Gray8 image and recompute ECC diagnostics.

영상에서 Data Matrix 하나를 검출한 뒤 ECC200을 진단합니다.

Python
diagnose_datamatrix_ecc_image(image, max_corrected_per_block)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_corrected_per_block · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
Gray8 ZImage
max_corrected_per_block
정정 후 수락 판정의 블록별 정정 코드워드 상한

반환: 독립 DataMatrixEccDiagnostics

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    Gray8 영상에서 Data Matrix 심볼 하나를 찾고 모듈을 샘플링한 후 ECC200 정정 진단을 계산합니다. 카메라 영상의 심볼 검출과 정정 결과의 판정을 포함하는 경로이므로 이미 샘플된 1픽셀 모듈 격자를 받는 함수와 입력 조건이 다릅니다. max_corrected_per_block은 블록별 수정 코드워드의 사후 허용 기준입니다.

    구체 사례와 결과 판독

    예를 들어 한 블록의 수정 수가 3이고 한계가 2이면 그 블록은 지정 기준을 초과합니다. 한계를 3으로 바꾸어 판정하는 것은 실제 오류 정정 능력이나 심볼의 ECC 구성을 바꾸는 것이 아닙니다. 검출·해독 실패와 정정 수가 0인 성공을 구별하고, 반환된 모든 블록의 수와 accepted 및 텍스트를 함께 기록하세요.

    적용 시 확인

    ROI를 전달했다면 그 안에서 읽힌 심볼을 진단합니다. 조명이나 초점으로 심볼이 검출되지 않은 경우에는 입력 영상과 검출 조건을 먼저 확인하세요. 한 영상에서 심볼을 먼저 찾아야 하므로 심볼이 흐리거나 영역 바깥에 있는 상황을 정정 실패와 구별해야 합니다. 반환된 블록 수정 수는 실제 정정된 코드워드 단위입니다. 해당 영상과 허용 한계를 함께 저장하면 이후 결과를 비교할 수 있습니다. 각 블록의 결과를 확인하세요.
