열거 값

  • QUANTIZE = 0 · 양자화 단계를 선택합니다.
  • MEDIAN = 1 · 중앙값 필터 단계를 선택합니다.
  • GAUSSIAN = 2 · 가우시안 필터 단계를 선택합니다.

사용 맥락과 계약

PipelineOperation은 전처리 단계의 종류를 지정합니다. QUANTIZE는 밝기 레벨을 줄이고 MEDIAN은 중앙값 필터를, GAUSSIAN은 가우시안 필터를 선택합니다. 이 값은 PipelineStage의 operation에 지정하며 실제 레벨 수 또는 커널과 sigma 등은 해당 단계의 나머지 설정으로 전달합니다.

구체 사례와 판독

예를 들어 양자화 뒤 가우시안 평활을 수행하는 두 단계는 원본의 밝기 레벨을 먼저 줄인 후 그 결과를 평활합니다. 순서를 바꾸면 일반적으로 픽셀 결과도 달라집니다. 처리 목적과 입력 형식에 맞는 단계별 매개변수를 정하고, 결과의 작은 영역을 원본과 비교해 의도한 순서가 적용되었는지 확인하세요.

적용 시 확인

중앙값과 가우시안은 주변 픽셀을 다르게 조합하고 양자화는 밝기 표현을 줄이는 작업이므로 서로 같은 결과를 기대할 수 없습니다. 예를 들어 양자화로 서로 같은 레벨이 된 두 밝기는 이후 필터가 원래 차이로 되돌릴 수 없습니다. 단계별 설정과 실행 순서를 함께 기록하세요. 각 단계의 매개변수가 유효한 범위에 있는지 실제 호출의 조건을 확인합니다. 활성화된 단계가 실패하면 예상한 후속 결과를 사용하지 않습니다. 적용 순서를 기록하세요.
