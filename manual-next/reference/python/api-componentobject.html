    사용 맥락과 결과 해석

    루트 상대 형상 컴포넌트 검색에서 조합된 객체 하나입니다. parts는 루트가 첫 항목인 매치 튜플이며 각 항목의 id로 입력 모델을 식별합니다. score는 구성요소 점수 중 최솟값이고 max_position_error는 예상 상대 위치에 대한 최대 오차로 픽셀 단위입니다.

    한 부품의 점수만 높아도 객체의 score가 높다고 가정할 수 없습니다. 예를 들어 부품 점수가 0.9와 0.7이면 최소값은 0.7입니다. 관계 허용 오차와 실제 최대 위치 오차를 비교하고 각 포즈의 로컬 좌표계를 확인하세요. 반환된 객체 수는 상위 결과의 최대 개수 및 공유 예산에도 영향을 받습니다.

    부품들의 각도가 유사하더라도 루트에 대한 상대 위치가 허용 오차를 벗어나면 원하는 조합이 아닐 수 있습니다. max_position_error는 이런 위치 관계를 읽는 진단입니다.

    값을 확인하는 순서

    parts 항목: 루트가 첫 항목인 컴포넌트 매치들의 불변 튜플입니다. score 항목: 컴포넌트 점수 중 최솟값입니다. max_position_error 항목: 컴포넌트 위치 오차의 최댓값(픽셀)입니다.

    항목읽을 때 확인할 내용

    score컴포넌트 점수 중 최솟값입니다.
