Python API · blob_mapped_subtraction

blob_mapped_subtraction 멤버와 선언

공개 타입

zvision.blob_mapped_subtraction: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_mapped_subtraction.blob_mapped_subtraction.

Apply Gray8/Gray16 LUT subtraction; outside reference overlap is zero.

조회표와 정렬 오프셋을 적용한 영상 차이로 멤버십을 만듭니다.

Python
blob_mapped_subtraction(source, reference, premap, postmap, scaling, offset_x, offset_y, work_budget)

확인된 인자 조건

source
입력 Gray8 또는 Gray16 ZImage
reference
빼기 기준 ZImage
premap
빼기 전에 적용할 정수 조회표
postmap
빼기 결과에 적용할 멤버십 조회표
scaling
1–255 정수 멤버십 배율
offset_x
부호 있는 로컬 x 오프셋
offset_y
부호 있는 로컬 y 오프셋
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 BlobSegmentationResult

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
