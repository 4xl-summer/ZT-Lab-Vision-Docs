Python API · DepthMap

DepthMap Python 소유 객체와 공개 멤버

개요와 수명

직교 격자에 부호 있는 높이를 담는 소유 객체입니다. width × height 개의 값은 행 우선이며 누락 샘플은 None입니다. 간격은 양의 유한값, 원점은 유한한 Point3, frame은 0이 아닌 정수입니다. 기본 변환은 셀 (x, y, h)을 origin + (x·spacing_x, y·spacing_y, h)로 나타내며 원근 카메라 거리로 자동 해석하지 않습니다.

네이티브 핸들을 소유합니다. close() 또는 with로 해제합니다. 닫힌 객체에서 핸들을 필요로 하는 호출은 ValueError를 냅니다. 네이티브 오류는 ZVisionError로 전달됩니다. 동시 호출과 장치별 조건은 이 선언만으로 확정할 수 없습니다.

상속 멤버 close()는 소유 핸들을 해제하며 컨텍스트 관리자도 지원합니다.

from_values

Python
def from_values(cls, width, height, values, spacing_x, spacing_y, origin, unit, frame)

클래스 메서드. width와 height는 양의 정수, values는 그 곱만큼의 수 또는 None입니다. spacing_x와 spacing_y는 수, origin은 Point3, unit은 LengthUnit, frame은 1 이상의 정수입니다. 새 DepthMap을 반환합니다. 값 개수가 맞지 않으면 ValueError가 발생합니다.

행 우선 높이와 좌표 메타데이터로 깊이 격자를 생성합니다.

확인된 인자 조건

width
양의 정수 너비, 셀 수
height
양의 정수 높이, 셀 수
values
width×height 길이의 유한 숫자 또는 None 시퀀스
spacing_x
X 간격, 유한 양수, unit 단위
spacing_y
Y 간격, 유한 양수, unit 단위
origin
로컬 (0,0)의 유한 Point3 원점
unit
길이 단위 LengthUnit
frame
0이 아닌 좌표계 ID

반환: 새 소유 DepthMap이며 사용 후 닫습니다.

오류: 치수·값 수·간격·frame 또는 값이 무효이면 오류입니다.

info

Python
DepthMap.info

읽기 전용 속성. DepthInfo의 width, height, valid_count, unit, frame, spacing_x, spacing_y, origin을 확인합니다.

크기, 유효 수, 단위, frame, 간격과 원점을 읽습니다.

반환: DepthInfo 값 스냅샷입니다.

오류: 닫힌 객체에서 접근하면 오류입니다.

to_values

Python
def to_values(self)

값을 Python 리스트로 복사합니다. 누락된 값은 None으로 표현합니다.

행 우선 높이를 복사하고 결측은 None으로 반환합니다.

반환: 독립 float 또는 None 목록입니다.

오류: 닫힌 객체에서 호출하면 오류입니다.

share

Python
def share(self)

공유된 깊이 데이터에 대한 별도의 소유 객체를 반환합니다. 반환 객체도 닫아야 합니다.

원본 저장소를 공유하는 별도 핸들을 만듭니다.

반환: 새 소유 DepthMap; 원본을 닫아도 유지되며 별도로 닫습니다.

오류: 닫힌 객체에서 호출하면 오류입니다.

roi

Python
def roi(self, x, y, width, height)

x, y, width, height로 ROI를 요청합니다. x와 y는 0 이상의 정수, width와 height는 1 이상의 정수이며 ROI는 원본 경계 안이어야 합니다. 반환 객체는 저장소와 stride를 공유하고 XY 원점은 ROI 오프셋에 간격을 곱해 이동합니다. 부모를 닫아도 별도로 소유한 ROI는 유효합니다.

현재 맵 기준 사각형의 저장소를 공유하고 원점을 x와 y 방향으로 각각 인덱스×간격만큼 이동합니다.

확인된 인자 조건

x
0 이상의 왼쪽 셀 인덱스
y
0 이상의 위쪽 셀 인덱스
width
양의 너비, 셀 단위
height
양의 높이, 셀 단위

반환: 별도 소유 DepthMap 핸들입니다.

오류: 영역이 범위 밖이거나 크기가 잘못되면 오류입니다.

median

Python
def median(self, kernel, min_valid)

kernel은 양의 홀수, min_valid는 1 이상 kernel² 이하입니다. 경계 밖은 제외한 유효 이웃의 중앙값을 사용합니다. 결측 중심은 결측을 유지하고 유효 이웃이 부족한 출력도 결측입니다. 표본 수가 짝수이면 가운데 두 값의 평균을 사용하며 독립 결과를 반환합니다.

유효 이웃 중앙값을 사용하고 결측 중심은 유지합니다. 짝수 개는 가운데 두 값의 평균입니다.

확인된 인자 조건

kernel
양의 홀수 커널 폭, 셀 단위
min_valid
1 이상 kernel² 이하인 최소 유효 이웃 수

반환: 새 소유 DepthMap; 사용 후 닫습니다.

오류: 유효 이웃 부족은 결측이고 잘못된 옵션은 오류입니다.

fill_holes

Python
def fill_holes(self, kernel, min_valid)

kernel은 양의 홀수, min_valid는 1 이상 kernel² 이하입니다. 경계 밖은 제외하고 원본의 유효 이웃으로 결측 중심만 채웁니다. 같은 호출에서 새로 채운 값은 다른 셀에 전파되지 않으며 독립 결과를 반환합니다.

원본의 유효 이웃 중앙값으로 결측 중심만 채웁니다. 새 값은 같은 호출에서 전파되지 않습니다.

확인된 인자 조건

kernel
양의 홀수 커널 폭, 셀 단위
min_valid
1 이상 kernel² 이하인 최소 유효 이웃 수

반환: 새 소유 DepthMap; 사용 후 닫습니다.

오류: 유효 이웃 부족은 결측이고 잘못된 옵션은 오류입니다.

to_point_cloud

Python
def to_point_cloud(self)

깊이 데이터를 PointCloud 소유 객체로 변환합니다. 반환 객체도 닫아야 합니다.

행 우선 깊이를 직교 점으로 바꾸고 결측·단위·frame을 보존합니다.

반환: 새 소유 PointCloud; 사용 후 닫습니다.

오류: 유한 범위를 벗어난 좌표 계산이나 닫힌 객체는 오류입니다.
