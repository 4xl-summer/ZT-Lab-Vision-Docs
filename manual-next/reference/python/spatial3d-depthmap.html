Python API · DepthMap

DepthMap Python 소유 객체와 공개 멤버

개요와 수명

직교 격자에 부호 있는 높이를 담는 소유 객체입니다. width × height 개의 값은 행 우선이며 누락 샘플은 None입니다. 간격은 양의 유한값, 원점은 유한한 Point3, frame은 0이 아닌 정수입니다. 기본 변환은 셀 (x, y, h)을 origin + (x·spacing_x, y·spacing_y, h)로 나타내며 원근 카메라 거리로 자동 해석하지 않습니다.

네이티브 핸들을 소유합니다. close() 또는 with로 해제합니다. 닫힌 객체에서 핸들을 필요로 하는 호출은 ValueError를 냅니다. 네이티브 오류는 ZVisionError로 전달됩니다. 동시 호출과 장치별 조건은 이 선언만으로 확정할 수 없습니다.

상속 멤버 close()는 소유 핸들을 해제하며 컨텍스트 관리자도 지원합니다.

from_values

클래스 메서드. width와 height는 양의 정수, values는 그 곱만큼의 수 또는 None입니다. spacing_x와 spacing_y는 수, origin은 Point3, unit은 LengthUnit, frame은 1 이상의 정수입니다. 새 DepthMap을 반환합니다. 값 개수가 맞지 않으면 ValueError가 발생합니다.

info

Python
DepthMap.info

읽기 전용 속성. DepthInfo의 width, height, valid_count, unit, frame, spacing_x, spacing_y, origin을 확인합니다.

크기, 유효 수, 단위, frame, 간격과 원점을 읽습니다.

반환: DepthInfo 값 스냅샷입니다.

오류: 닫힌 객체에서 접근하면 오류입니다.

to_values

값을 Python 리스트로 복사합니다. 누락된 값은 None으로 표현합니다.

share

공유된 깊이 데이터에 대한 별도의 소유 객체를 반환합니다. 반환 객체도 닫아야 합니다.

roi

x, y, width, height로 ROI를 요청합니다. x와 y는 0 이상의 정수, width와 height는 1 이상의 정수이며 ROI는 원본 경계 안이어야 합니다. 반환 객체는 저장소와 stride를 공유하고 XY 원점은 ROI 오프셋에 간격을 곱해 이동합니다. 부모를 닫아도 별도로 소유한 ROI는 유효합니다.

median

kernel은 양의 홀수, min_valid는 1 이상 kernel² 이하입니다. 경계 밖은 제외한 유효 이웃의 중앙값을 사용합니다. 결측 중심은 결측을 유지하고 유효 이웃이 부족한 출력도 결측입니다. 표본 수가 짝수이면 가운데 두 값의 평균을 사용하며 독립 결과를 반환합니다.

fill_holes

kernel은 양의 홀수, min_valid는 1 이상 kernel² 이하입니다. 경계 밖은 제외하고 원본의 유효 이웃으로 결측 중심만 채웁니다. 같은 호출에서 새로 채운 값은 다른 셀에 전파되지 않으며 독립 결과를 반환합니다.

to_point_cloud

깊이 데이터를 PointCloud 소유 객체로 변환합니다. 반환 객체도 닫아야 합니다.

close()

상속된 소유 핸들을 해제합니다. 이미 닫힌 객체를 다시 닫을 수 있습니다.

합성 데이터 예제

예제는 실제 장비 측정이 아니며 이 페이지 생성 시 실행 여부를 검증하지 않았습니다.

Python
from zvision import DepthMap, LengthUnit, Point3

with DepthMap.from_values(2, 2, [1.0, None, 2.0, 3.0],
                          1.0, 1.0, Point3(0.0, 0.0, 0.0),
                          LengthUnit.MILLIMETER, 1) as depth:
    print(depth.info.width, depth.to_values())
