피팅의 선택과 한도

RegionFitOptions는 method, inlier_threshold, min_inliers, max_candidates, max_refit_iterations, tolerance, min_arc_radians를 묶습니다. 후보 생성과 인라이어 판정, 재피팅 종료 조건을 각각 제어하므로 하나의 값만으로 피팅의 품질을 판단할 수 없습니다.

잔차의 단위

inlier_threshold는 입력 점 좌표 단위의 잔차 한도입니다. 예를 들어 좌표가 픽셀이면 임계값도 그 좌표 단위로 해석합니다. 점을 물리 단위로 변환해 피팅할 때 같은 숫자를 그대로 유지하면 허용 오차의 실제 크기가 달라질 수 있습니다.

호와 반복

min_arc_radians는 원 피팅에 필요한 최소 호 범위이며 기본값은 0 라디안입니다. 후보 수와 재피팅 반복 수는 탐색 또는 반복의 한도를 나타냅니다. tolerance는 수렴 판단의 허용 오차로, 결과가 실제 장비에서 충분히 정확하다는 보증은 아닙니다.

결과 판독

설정 후 선택된 점과 각 관측의 잔차, 인라이어 사용 여부를 함께 확인합니다. 임계값이 너무 크면 원하지 않는 점이 포함될 수 있고 너무 작으면 유효 점이 제외될 수 있습니다. 입력의 단위와 설정을 함께 보관해 비교합니다.
