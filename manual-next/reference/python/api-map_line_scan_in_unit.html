map_line_scan_in_unit 멤버와 선언

공개 타입

zvision.map_line_scan_in_unit: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.map_line_scan_in_unit.

Project or unproject only when the explicit physical unit equals the camera unit.

지정 단위가 카메라 단위와 같을 때 라인스캔 점을 변환합니다.

Python
map_line_scan_in_unit(camera, point, unit, inverse=False)

인자 선언

  • camera · POSITIONAL_OR_KEYWORD · 기본값 없음
  • point · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음
  • inverse · POSITIONAL_OR_KEYWORD · 기본값 False

camera

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    LineScanCamera의 평면 좌표와 영상 좌표 사이에서 점 하나를 변환하며 명시한 물리 단위가 카메라 단위와 같은지 확인합니다. 기본 inverse=False는 투영, True는 역변환입니다. 카메라에는 가로 방향 픽셀 밀도와 중심, 이동 방향 원점 및 라인당 이동량이 들어 있으므로 면적 카메라의 원근 투영과 동일하게 해석하면 안 됩니다.

    호출할 때 point는 방향에 맞는 2D 좌표를 전달하고 unit에는 카메라에 기록된 LengthUnit과 같은 값을 지정합니다. 예를 들어 카메라 설정이 밀리미터라면 미터 값을 같은 숫자로 넘기는 것이 자동 단위 변환을 뜻하지 않습니다. 명시 단위가 다르면 계산을 거절하므로 필요한 변환을 적용한 뒤 다시 호출해야 합니다.

    반환값은 변환된 Point2 스냅샷이고 입력 카메라를 수정하지 않습니다. 유한하지 않은 좌표나 유효하지 않은 카메라 기하도 오류가 될 수 있습니다. inverse는 실제 bool이어야 하며 앞 단계에서 어느 좌표계를 반환했는지 기록해야 결과 좌표를 다음 영상 처리나 물리 계산에 올바르게 연결할 수 있습니다.
