열거 값

  • DISABLED = 0 · 겹침 억제를 비활성화합니다.
  • SAME_MODEL = 1 · 같은 모델의 후보끼리 겹침을 억제합니다.
  • ALL_MODELS = 2 · 모든 모델의 후보 사이에서 겹침을 억제합니다.

사용 맥락과 결과 해석

여러 특징 모델·인스턴스 검색에서 방향 다각형 겹침을 어느 범위에 적용할지 지정합니다. DISABLED는 억제를 끄고 SAME_MODEL은 같은 모델 후보끼리만 비교하며 ALL_MODELS는 서로 다른 모델의 후보도 비교합니다. max_iou는 별도로 허용할 겹침 비율을 정합니다.

예를 들어 동일 물체를 두 모델이 모두 찾아내는 상황에서는 ALL_MODELS가 중복을 줄일 수 있습니다. 반면 서로 다른 실제 물체가 겹쳐 보일 때도 하나가 억제될 수 있으므로 적용 전에 장면을 확인해야 합니다. 억제된 결과 개수는 원래 평가한 후보 수와 같지 않습니다. scope와 IoU 기준, 공유 가설 예산을 함께 기록해 선택 과정을 해석합니다.

값을 확인하는 순서

ALL_MODELS 항목: 모든 모델의 후보 사이에서 겹침을 억제합니다. DISABLED 항목: 겹침 억제를 비활성화합니다. SAME_MODEL 항목: 같은 모델의 후보끼리 겹침을 억제합니다.

항목읽을 때 확인할 내용
