    사용 맥락과 결과 해석

    정수 위치 범위에서 검색한 결과 매치의 불변 튜플과 evaluated를 담습니다. 허용 후보가 없으면 matches는 빈 튜플이며 정상적인 빈 결과입니다. evaluated는 살펴본 정수 위치의 수이고 최종 반환된 매치 수와 같을 필요가 없습니다. 모델과 네이티브 결과를 정리한 뒤에도 이미 복사된 값은 유지됩니다.

    입력 범위는 좌상단의 포함 경계이며 템플릿이 검색 영상에 완전히 들어가야 합니다. 예를 들어 x 0부터 2, y를 0 하나로 지정했다면 가능한 위치는 세 개입니다. 모델 표본 수와 채널에 비례하는 작업량이 max_work를 넘으면 빈 결과가 아니라 오류입니다. NCC와 SAD는 값의 좋은 방향이 다르므로 매치 값은 사용한 metric과 함께 판독합니다.

    검색 범위가 x 0..2, y 0..1이면 두 축 끝점을 포함해 위치는 여섯 개입니다. 결과가 상한에 도달한 경우 반환 목록에 들어오지 않은 수용 후보가 있을 수 있습니다.

    값을 확인하는 순서

    matches 항목: 검색 후 복사된 불변 매치 튜플입니다. 허용 후보가 없으면 비어 있습니다. evaluated 항목: 평가된 정수 위치의 수입니다.

    evaluated평가된 정수 위치의 수입니다.
