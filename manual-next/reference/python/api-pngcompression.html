열거 값

  • FAST = 0 · 빠른 PNG 압축 설정입니다.
  • DEFAULT = 1 · 기본 PNG 압축 설정입니다.
  • BEST = 2 · 높은 PNG 압축 설정입니다.

사용 맥락과 계약

PngCompression은 PNG를 저장할 때 압축 작업에 사용하는 선택지입니다. FAST, DEFAULT, BEST 가운데 하나를 save_with_options의 png_compression에 전달하며 생략하면 FAST입니다. 이 값은 JPEG 품질 값이나 영상 처리의 임계값이 아닙니다. PNG 출력의 압축 방식 선택이므로 원본 픽셀의 명암 범위를 바꾸는 설정으로 해석하지 않습니다.

구체 사례와 판독

예를 들어 같은 영상을 FAST와 BEST로 각각 저장해 파일 크기와 저장 시간을 비교할 수 있습니다. 실제 차이는 영상의 반복 패턴과 내용에 따라 달라집니다. 특정 선택이 반드시 일정 비율만큼 작거나 빠르다고 가정하지 말고 사용하는 영상으로 측정하세요. 결과 파일을 다시 읽어 크기와 픽셀을 비교하면 저장 경로와 파일 내용을 함께 확인할 수 있습니다.

적용 시 확인

압축 선택지는 파일 표현을 바꾸는 입력이며 PNG를 JPEG로 변환하는 스위치가 아닙니다. 저장 경로의 확장자와 함께 기록하면 결과 비교를 재현할 수 있습니다. 같은 파일 이름에 반복 저장하면 앞선 결과를 덮어쓸 수 있으므로 비교 실험에는 서로 다른 경로를 사용하세요. 읽은 파일이 의도한 경로의 결과인지도 함께 확인합니다.
