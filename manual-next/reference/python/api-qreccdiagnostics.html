    사용과 결과 해석

    QR 오류 정정 진단의 텍스트, version, error_correction_level, blocks, corrected_codewords 및 accepted를 묶은 값입니다. blocks에는 데이터와 패리티 및 정정된 코드워드 수를 가진 QrEccBlock이 순서대로 들어갑니다. 전체 정정 수와 각 블록의 수를 별도로 살펴볼 수 있습니다.

    같은 텍스트가 읽혔더라도 블록별 정정 수가 다를 수 있습니다. 설정한 블록별 정정 한도는 디코딩 후 결과 수락 여부를 판단하는 기준이며 디코더가 고치는 양을 조절하는 옵션이 아닙니다. accepted와 정정 수를 함께 기록해야 한도에 따른 결과를 다시 해석할 수 있습니다.

    모듈 입력 진단과 영상 입력 진단은 입력 준비 조건이 다릅니다. 모듈 격자를 사용할 때는 요구된 방향과 표본 형식을 확인합니다. 정정 코드워드 수는 결함 픽셀 수나 ISO 심볼 품질 등급이 아니며 진단에 사용한 입력에 한정됩니다.

    실험 결과를 비교하려면 입력 격자의 방향과 크기, 조명 조건 및 설정된 한도를 같이 보존합니다. 디코딩된 텍스트가 같다는 사실과 오류 정정에 사용된 여유가 같다는 사실은 서로 다릅니다.

    입력별 결과를 별도로 보관합니다.
