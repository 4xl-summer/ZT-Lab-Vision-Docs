사용과 결과 해석

전경 연결 성분, 내부 구멍과 오일러 수를 담은 독립 스냅샷입니다. topology의 오일러 수는 전경 성분 수에서 구멍 수를 뺀 값입니다. 이 결과는 원본 영상 핸들을 계속 보유해야만 읽을 수 있는 배열이 아니라 복사된 값입니다.

예를 들어 성분 하나 안에 구멍 하나가 있으면 오일러 수는 0입니다. ROI 외곽에 닿은 배경은 내부 구멍과 구별되므로 물체를 경계에서 자르면 위상 결과가 달라질 수 있습니다. 대각선 접촉도 선택한 연결성에 따라 성분 수를 바꿉니다.

입력 마스크의 전경 정의, ROI와 연결성 설정을 결과와 함께 기록하십시오. 성분 수가 같다는 사실만으로 물체의 면적이나 위치가 같다는 뜻은 아니며, 세부 형상은 모멘트 또는 윤곽 결과로 별도 확인해야 합니다.
