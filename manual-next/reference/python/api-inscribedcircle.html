    사용 맥락과 계약

    InscribedCircle은 볼록 다각형 안에 들어가는 원의 중심과 반지름을 나타내는 값 결과입니다. center와 radius는 입력 다각형의 좌표 단위를 따릅니다. 원을 구할 때 사용한 다각형이 픽셀 좌표라면 반지름은 픽셀이고, 밀리미터 좌표라면 반지름도 밀리미터입니다. 이 값은 원의 지름이나 넓이가 아닙니다.

    구체 사례와 판독

    예를 들어 꼭짓점이 (0,0), (4,0), (4,4), (0,4)인 정사각형의 최대 내접원은 중심 (2,2), 반지름 2입니다. 같은 단위에서 지름은 4이고 넓이는 4π입니다. 결과를 사용할 때는 원래 꼭짓점의 순서와 볼록성 및 좌표 프레임을 함께 확인하세요. 부동소수 계산에서는 공차를 두고 변과의 거리를 비교합니다.

    적용 시 확인

    직사각형이 너비 8, 높이 4라면 반지름은 짧은 변의 절반인 2를 넘을 수 없습니다. 중심은 길이 방향으로 하나가 아닐 수도 있으므로 최대 반지름이 같다는 이유만으로 특정 중심 하나를 항상 기대해서는 안 됩니다. 측정 목적에 맞게 중심의 허용 범위와 반지름 공차를 따로 정하세요. 다각형의 경계가 단위가 다른 두 좌표계에서 만들어졌다면 원의 반지름도 의미가 달라집니다. 먼저 같은 기준으로 변환하세요.
