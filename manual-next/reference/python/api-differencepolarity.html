사용과 결과 해석

보정된 입력에서 기준을 뺀 잔차를 어느 방향으로 해석할지 지정합니다. ABSOLUTE는 부호와 관계없이 변화의 크기를 사용합니다. BRIGHTER는 양의 잔차만, DARKER는 음의 잔차의 크기만 점수에 반영합니다. 이 값은 차분 영상을 만드는 기준 밝기 보정과는 별도의 선택이므로, 먼저 잔차의 부호가 어떤 입력 순서에서 만들어지는지 확인해야 합니다.

예를 들어 보정이 없고 한 픽셀의 입력이 30, 기준이 20이면 잔차는 +10입니다. 기본 허용치가 5이고 질감 가중치가 0일 때 ABSOLUTE와 BRIGHTER의 점수는 2이고 DARKER의 점수는 0입니다. 점수 1 이상이 마스크의 전경이므로 양쪽 변화를 모두 검사할지 한쪽만 검사할지에 따라 후보가 달라집니다. 실제 값은 조명 보정을 적용했다면 그 보정 후 잔차를 기준으로 계산합니다.

극성만 바꿔도 같은 위치가 후보에 들어오거나 제외될 수 있으므로 허용치와 함께 기록합니다. 비제로 포함 마스크로 선택하지 않은 위치는 결과에서 검사된 픽셀로 취급하지 않습니다. 극성 설정이 유효하지 않거나 입력 기하가 맞지 않는 오류를 결함이 없는 결과로 바꾸어 해석해서는 안 됩니다.

검사 방향을 바꾸었다면 합성 밝은 점과 어두운 점에서 선택이 의도대로 바뀌는지 각각 확인합니다.
