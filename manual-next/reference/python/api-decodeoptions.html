0 픽셀 모서리, 1 정규화 모서리, 2 픽셀 중심, 3 정규화 중심 좌표; 기본 0.
nms

score_threshold
포함할 최소 유한 점수 [0,1], 기본 0.5.
iou_threshold
억제 판단의 유한 IoU 임계값 [0,1], 기본 0.5.
max_detections
