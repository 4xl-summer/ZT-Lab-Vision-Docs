공개 타입

zvision.segment_font_image: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.segment_font_image.

Return line-indexed cells for review or correction before training.

글꼴 학습에 쓸 문자 셀을 분할합니다.

반환: 줄 인덱스와 사각형을 담은 독립 FontCell 튜플

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    ZImage와 FontOptions를 받아 문자 후보를 분할하고 줄 번호가 있는 FontCell 튜플을 반환합니다. 이 단계는 셀을 검토하거나 학습 자료를 준비하기 위한 것으로 문자 라벨이나 인식 확률을 반환하지 않습니다. threshold, light_text, 셀 크기 범위와 붙은 문자 분리 옵션이 분할에 영향을 줍니다.

    예를 들어 두 글자가 하나의 셀로 검출되면 원본에 사각형을 겹쳐 표시하고 split_touching과 이진화 조건을 검토합니다. 반대로 글자 하나가 여러 조각으로 나뉘었다면 닫기와 크기 조건을 비교합니다. line을 보존해야 여러 줄에서 각 셀의 소속을 알 수 있습니다.

    반환값은 내부 결과에서 셀을 복사한 튜플이며 임시 네이티브 핸들은 함수가 해제합니다. 입력 ZImage는 호출자가 보유합니다. 분할 성공과 문자 인식 수락은 별도 단계이므로 결과의 셀 개수를 정답 글자 수로 단정하지 않습니다.

    ROI를 입력으로 사용했다면 셀 위치는 해당 입력과의 관계를 먼저 확인해야 합니다. 샘플을 학습에 넘기기 전에 빈 배경이나 인접 문자 조각이 포함되어 있지 않은지 검토합니다.

    인식 단계에 넘긴 셀과 분할 설정을 함께 보관합니다.
