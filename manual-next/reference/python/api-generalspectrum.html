forward(cls, image, options)

지정 크기와 정규화의 일반 DFT를 계산합니다. 이 팩터리는 기존 호환 API입니다.

확인된 인자 조건

image
입력 ZImage입니다.
options
폭, 높이 및 정규화를 담은 FftOptions입니다.

반환: 호출자가 닫아야 하는 GeneralSpectrum입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Transform an image with the requested arbitrary size and normalization. Legacy factory retained through 0.1.x; prefer image.general_dft(options.width, options.height, options.normalization).

반환: 호출자가 닫아야 하는 GeneralSpectrum입니다.

  • real · POSITIONAL_OR_KEYWORD · 기본값 없음
  • imaginary · POSITIONAL_OR_KEYWORD · 기본값 없음
  • normalization · POSITIONAL_OR_KEYWORD · 기본값 <FftNormalization.BACKWARD: 0>

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

inverse_complex(self, crop=True)

복소 역변환 값을 계산합니다.

확인된 인자 조건

crop
True면 원본 크기로 자르고 False면 변환 크기를 사용합니다. 기본값은 True입니다.

반환: 너비, 높이, 실수부 튜플과 허수부 튜플을 반환합니다.

오류: crop이 bool이 아니거나 소유 객체가 닫혔으면 오류입니다.

인자 선언

  • crop · POSITIONAL_OR_KEYWORD · 기본값 True

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Return width, height, real and imaginary values, optionally cropped.
