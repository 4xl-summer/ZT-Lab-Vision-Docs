공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    xfloat필수스테이지 X 위치이며 호출에서 지정한 길이 단위입니다.
    yfloat필수스테이지 Y 위치이며 호출에서 지정한 길이 단위입니다.
    thetafloat필수펼쳐진 스테이지 회전각이며 라디안입니다.

    사용 맥락과 계약

    StagePose2는 평면 스테이지의 X, Y 위치와 회전 theta를 함께 표현하는 자세 값입니다. x와 y는 스테이지의 길이 단위를 따르고 theta는 래핑하지 않은 라디안 각도로 해석합니다. 같은 숫자의 위치라도 서로 다른 원점이나 축 방향에서 표현하면 다른 물리적 자세이므로 명령과 관측에서 동일한 기준을 사용해야 합니다.

    구체 사례와 판독

    예를 들어 기준 원점에서 X로 10, Y로 5 이동하고 회전이 0인 자세는 (10,5,0)으로 기록할 수 있습니다. theta가 0이 아니면 위치 이동과 회전을 함께 고려해야 하며, 단순히 x와 y 차이만으로 전체 자세 오차를 판정할 수 없습니다. 회전의 단위와 부호, 길이 단위를 장치 설정과 일치시켜 비교하세요.

    적용 시 확인

    상대 이동과 절대 자세는 같은 숫자라도 의미가 다릅니다. 명령이 원점 기준의 목표인지 현재 자세에서의 증분인지 장치 쪽 규약을 먼저 확인하세요. 측정 결과와 비교할 때는 시간 대응도 중요합니다. 이동이 끝나기 전의 관측을 완료 후 목표와 비교하면 실제 정착 오차와 다르게 보일 수 있습니다. 검증 보고에는 명령 자세와 관측 자세를 함께 남겨 어느 기준에서 차이를 계산했는지 추적할 수 있게 합니다. 입력의 좌표와 값을 기록해 결과를 다시 확인할 수 있습니다.
