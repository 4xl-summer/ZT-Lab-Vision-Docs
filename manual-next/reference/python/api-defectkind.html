시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

열거 값

  • SCRATCH = 1 · 긴 변·짧은 변·종횡비의 스크래치 조건을 모두 만족한 후보입니다.
  • SURFACE = 2 · 스크래치 조건을 모두 만족하지 않는 표면 후보입니다.

사용과 결과 해석

표면 결함 추출에서 연결 요소의 형상을 기준으로 붙이는 분류입니다. SCRATCH는 회전 사각형의 긴 변이 최소 길이 이상이고 짧은 변이 최대 폭 이하이며 긴 변 대 짧은 변 비율이 최소 종횡비 이상인 세 조건을 모두 만족합니다. SURFACE는 추출된 후보 중 이 세 조건을 함께 만족하지 않는 나머지 후보입니다. 이는 기하 규칙의 결과이지 학습된 재질 분류나 결함 원인의 진단이 아닙니다.

먼저 차분 또는 다른 처리로 전경 마스크를 만들고, 같은 크기와 원점의 점수 영상과 DefectSpec을 사용해 연결 요소를 추출합니다. 최소 면적보다 작은 요소는 후보 목록에서 제외됩니다. 남은 각 후보의 Kind와 함께 Area, Bounds, Length, Width와 Angle을 읽어 분류 근거를 확인할 수 있습니다. 회전 사각형은 픽셀 셀의 외곽을 감싸는 도형이고 축 정렬 Bounds와 역할이 다릅니다.

예를 들어 길이는 충분하지만 폭이 허용 폭을 초과하면 SCRATCH가 아니라 SURFACE로 분류됩니다. 종횡비 조건도 독립적으로 만족해야 합니다. 판정의 최대 개수나 영역 허용 규칙은 이 분류 이후에 적용되므로 Kind만 보고 전체 검사 통과 여부를 결정하지 않습니다.
