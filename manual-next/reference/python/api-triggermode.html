열거 값

  • FREE_RUN = 1 · 트리거 없이 자유 실행합니다.
  • SOFTWARE = 2 · 소프트웨어 트리거를 사용합니다.
  • EXTERNAL = 3 · 외부 트리거에 연결합니다.

사용 맥락과 계약

TriggerMode는 모의 카메라가 프레임과 트리거를 연결하는 방식을 선택합니다. FREE_RUN에서는 별도 트리거 없이 프레임을 제출하며 트리거 ID는 0이어야 합니다. SOFTWARE와 EXTERNAL은 트리거를 등록한 뒤 그 식별자를 제출 프레임에 연결하는 모드를 나타냅니다. 이 열거값은 실제 카메라 드라이버가 소프트웨어 또는 외부 신호를 수신했다는 증거가 아닙니다.

구체 사례와 판독

CameraSpec을 만들 때 한 방식을 선택하고 카메라 연결과 취득 시작을 거쳐 사용합니다. 트리거 방식에서 등록하지 않은 ID를 프레임에 연결하거나 자유 실행에서 0이 아닌 트리거 ID를 제출하면 입력 조건에 맞지 않습니다. 대기 트리거의 수와 만료는 큐 용량 및 호출자가 제공하는 시간에 영향을 받으므로 시뮬레이션 결과를 읽을 때 프레임 ID와 트리거 ID를 같이 기록하세요. 하드웨어 타이밍은 별도 장비 시험이 필요합니다.

적용 시 확인

예제에서 트리거 ID 1을 등록하고 프레임에 1을 붙이는 것은 명령과 입력의 대응 관계를 확인하기 위한 설정입니다. 숫자만 같고 등록 순서나 카메라 상태가 틀리면 같은 성공 경로가 아니므로 반환과 오류를 따로 확인해야 합니다. 모드와 트리거 식별자를 프레임 기록에 함께 남기면 수락 여부를 해석할 수 있습니다.
