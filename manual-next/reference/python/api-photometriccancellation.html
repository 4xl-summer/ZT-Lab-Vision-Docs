사용과 결과 해석

PhotometricCancellation은 제어 가능한 광도 스테레오 작업에 전달하는 일회성 취소 토큰입니다. 직접 생성자가 아니라 create로 소유 토큰을 얻고 photometric_stereo_controlled의 cancellation 인자로 전달합니다. cancel 호출은 진행 중인 작업에 협력적 취소를 요청합니다. 이는 AdvancedDifference의 차분 결과 객체와 별도의 기능입니다.

제어 함수의 timeout_ms는 0이면 시간 제한을 사용하지 않습니다. 취소 또는 제한 시간 초과는 반환 영상이 정상적으로 계산되었다는 표시가 아니라 예외로 전달되므로 호출 측에서 성공 결과와 구별합니다. 토큰을 닫는 행위 자체는 실행 중인 작업을 취소하지 않습니다. 중단을 요청해야 한다면 닫기 전에 cancel의 목적과 시점을 분명히 해야 합니다.

토큰은 한 번 쓰는 공유 취소 수단으로 문서화되어 있으므로 취소된 토큰을 다음 작업의 새 토큰으로 재사용하는 흐름에 의존하지 않습니다. 연산의 완료 또는 예외를 처리하고 결과와 토큰 각각의 소유 규칙에 따라 해제합니다. 제한 시간에 걸리지 않은 실행도 영상 내용의 정확성을 자동 보증하지 않습니다.
