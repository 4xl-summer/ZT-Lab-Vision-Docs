공개 멤버

    사용과 결과 해석

    영상의 지정 선분을 따라 수직 띠를 샘플링하고 선택한 커널로 길이 방향 강도 곡선을 만듭니다. spec은 ROI 로컬 시작·끝, 샘플 수와 양의 홀수 폭을 지정하며 options는 보간 방식, 최소 유효 횡단 폭과 필터를 정합니다. 기본 프로파일과 달리 영상 밖의 횡단 샘플은 제외하지만 각 중심에서 남은 수가 최솟값 이상이어야 합니다. 예를 들어 폭 3인 띠의 한쪽이 영상 밖이어도 유효한 두 표본이 있고 최소 폭이 2라면 그 위치에서 두 값의 평균을 구합니다. 필터 [1]은 추가 평활 없이 같은 값을 전달합니다. 반환 튜플의 각 샘플은 로컬 위치, 시작점에서의 픽셀 거리와 평균 강도입니다. 무효한 커널, 부족한 폭이나 비유한 값은 오류이며 이를 에지 없음과 혼동하지 않습니다. 처음과 끝 표본의 distance는 선분 시작점을 기준으로 읽습니다. 반환 배열의 값은 에지 목록이 아니므로 다음 단계에서 극성과 기울기 기준을 적용해야 합니다. 프로파일을 그려 보면 선택하려는 경계가 실제 탐색 구간에 들어왔는지 확인하는 데 도움이 됩니다. 영상 경계의 유효 폭은 위치마다 달라질 수 있습니다. 첫 표본에서 조건이 맞았다고 선분 전체가 유효한 것은 아닙니다. 각 표본의 위치와 강도는 별도 필드입니다.
