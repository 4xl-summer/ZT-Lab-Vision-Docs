공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    lensestuple필수선택된 카메라의 fx를 조정한 렌즈 값들의 튜플입니다. 다른 렌즈 계수는 고정됩니다.
    initial_rmsfloat필수초기 재투영 RMS 오차이며 픽셀 단위입니다.
    final_rmsfloat필수최종 재투영 RMS 오차이며 픽셀 단위입니다.
    optimized_maskint필수fx를 조정한 카메라의 비트 마스크입니다.

    사용과 결과 해석

    카메라 자세를 고정하고 선택된 렌즈의 fx를 조정한 결과를 담습니다. lenses는 각 카메라의 결과 렌즈 튜플이고 optimized_mask는 어느 카메라의 fx를 조정했는지 표시합니다. 다른 렌즈 계수는 고정되므로 이 결과를 모든 내부 계수를 다시 추정한 모델로 해석하면 안 됩니다.

    initial_rms와 final_rms는 전체 재투영 오차를 픽셀 단위로 요약합니다. 최종값이 초기값보다 작다면 주어진 관측과 모델에서 목적값이 줄어든 것이지만, 각 카메라의 모든 위치에서 정확도가 향상됐다는 보장은 아닙니다. 렌즈 순서와 마스크 비트의 대응을 함께 확인하십시오.

    값은 독립 스냅샷으로 반환됩니다. 고정한 자세와 관측 대응, 픽셀 좌표계가 올바른지 먼저 확인하고, 학습에 쓰지 않은 점의 재투영 오차를 별도로 평가해야 실제 사용 영역의 오차를 살펴볼 수 있습니다.
