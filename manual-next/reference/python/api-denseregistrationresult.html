    사용 맥락과 결과 해석

    기준 영상 격자에서 소스 방향으로의 dx·dy 변위, 밝기 잔차와 유효성 마스크를 담은 독립 결과입니다. width와 height는 기준 격자 크기이고 배열은 행 우선입니다. x,y 픽셀의 인덱스는 y×width+x로 계산합니다. valid는 재표본화가 가능한 위치를 나타내므로 무효 위치의 숫자를 유효한 측정으로 쓰지 않습니다.

    iterations와 converged는 정합 과정의 진단으로, 수렴 여부는 마지막 워프의 수치적 조건입니다. 이것만으로 전역 최적이나 실제 변위 정확도를 보장하지 않습니다. 기준에서 소스로 향하는 변위 방향과 ROI 좌표를 확인한 뒤 결과를 적용하고, 밝기 잔차 및 유효 비율을 같이 검토합니다. 각 배열은 네이티브 결과에서 복사된 튜플 또는 바이트열입니다.

    값을 확인하는 순서

    width 항목: 기준 격자의 가로 크기(픽셀)입니다. height 항목: 기준 격자의 세로 크기(픽셀)입니다. dx 항목: 기준에서 소스로의 로컬 x 변위를 행 우선으로 복사한 튜플입니다. dy 항목: 기준에서 소스로의 로컬 y 변위를 행 우선으로 복사한 튜플입니다. residual 항목: 표본별 밝기 잔차를 행 우선으로 복사한 튜플입니다. valid 항목: 재표본화 유효성을 담은 바이트열입니다. iterations 항목: 보고된 반복 횟수입니다. converged 항목: 마지막 워프의 수치적 수렴 여부입니다.
