    사용과 결과 해석

    QR 모듈 크기 추정의 x_pixels, y_pixels와 accepted를 담는 값입니다. 두 크기는 각각 가로와 세로 방향의 픽셀 단위 추정입니다. 표시 배율이 아니라 입력 영상에서 모듈 하나가 어느 정도 픽셀을 차지하는지 해석할 때 사용합니다.

    예를 들어 x_pixels가 4, y_pixels가 5라면 두 방향의 표본 크기가 동일하지 않다는 정보를 얻습니다. 이 값만으로 원근 왜곡의 원인이나 전체 심볼 품질을 단정하지 말고 입력과 판정 조건을 함께 확인합니다. accepted는 그 추정에 대해 적용된 수락 결과입니다.

    작은 모듈은 촬영 해상도와 초점의 영향을 받을 수 있으므로 원본 이미지의 실제 크기를 기록합니다. 화면에 확대한 영상의 모듈 크기와 원본 픽셀의 크기는 다릅니다. 이 스냅샷은 디코딩된 문자나 오류 정정 블록을 포함하지 않습니다.

    추정 조건에 맞지 않는 입력에서 accepted가 거짓이면 크기 수치만 근거로 촬영이 충분하다고 판단하지 않습니다. 실제 판독 여부와 크기 추정은 각각 별도로 확인해야 합니다.

    크기 추정과 실제 판독 결과를 프레임별로 연결해 기록합니다.

    촬영 크기와 판독 조건을 함께 보관해 비교합니다.
