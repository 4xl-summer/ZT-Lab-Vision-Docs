    소수 좌표 경계

    SubpixelContour는 경계가 닫혀 있는지 나타내는 closed와 경계 점들의 순서 있는 모음을 담습니다. 점은 ROI 로컬 픽셀 중심 좌표계를 사용하며 정수 픽셀 위치 사이의 소수 좌표를 표현할 수 있습니다. 이것은 좌표 표현의 정밀도이며 카메라나 검사 장비의 실제 측정 정확도를 자동으로 보증하지 않습니다.

    열린 경로와 닫힌 경로

    닫힌 경로를 처리할 때는 마지막 점과 첫 점의 연결 여부가 길이 계산에 영향을 줍니다. 예를 들어 세 점 (0,0), (1,0), (1,1)을 순서대로 이으면 열린 선분의 총 길이는 2이고 마지막 점을 첫 점에 연결하면 여기에 대각선 길이 √2가 더해집니다. 실제 소비 API의 닫힘 규칙은 별도로 확인합니다.

    좌표 사용

    점 순서를 보존한 채 윤곽 측정이나 표시 단계에 전달합니다. ROI 내부의 점을 전체 이미지에 표시할 때는 해당 ROI 원점을 더해 기준을 맞춥니다. 정수 화면 픽셀로 변환할 때 반올림된 값은 원래 소수 좌표와 다르므로 후속 측정에는 가능한 한 원래 결과를 사용합니다.

    예를 들어 x가 2.25인 점을 화면의 정수 열에 그릴 수는 있지만 원래 좌표는 그대로 2.25입니다. 표시용 반올림의 결과를 정밀 계산에 다시 사용하면 여러 점에서 양자화 오차가 누적될 수 있습니다.
