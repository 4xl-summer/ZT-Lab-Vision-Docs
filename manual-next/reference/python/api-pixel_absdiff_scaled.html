pixel_absdiff_scaled 멤버와 선언

공개 타입

zvision.pixel_absdiff_scaled: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._arithmetic_gap.pixel_absdiff_scaled.

Scale the absolute difference before rounding and saturation.

두 영상의 절대 차이에 배율을 적용하고 출력 형식으로 변환합니다.

Python
pixel_absdiff_scaled(left, right, scale, output_format)

인자 선언

  • left · POSITIONAL_OR_KEYWORD · 기본값 없음
  • right · POSITIONAL_OR_KEYWORD · 기본값 없음
  • scale · POSITIONAL_OR_KEYWORD · 기본값 없음
  • output_format · POSITIONAL_OR_KEYWORD · 기본값 없음

right

scale
양의 유한 배율

반환: 별도 close할 ZImage

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

공개 멤버

    사용과 결과 해석

    두 입력의 대응 성분에서 절대 차이를 구하고 양의 scale을 곱한 뒤 지정한 출력 형식으로 변환합니다. 부호를 없앤 차이이므로 같은 위치의 밝기가 어느 쪽에서 더 높았는지는 반환 영상에서 구별할 수 없습니다. 위치별 결함의 크기를 빠르게 확인하고 싶을 때 쓸 수 있지만, 밝아진 결함과 어두워진 결함을 나누려면 부호를 보존하는 다른 연산이 필요합니다.

    예를 들어 같은 위치의 값이 10과 14이고 scale이 2이면 출력 변환 전 값은 8입니다. 입력 순서를 바꾸어도 절대 차이는 같습니다. 정수 출력에서는 출력 형식의 범위에 맞춘 반올림과 포화가 일어나므로 scale을 크게 잡으면 서로 다른 차이가 같은 최댓값으로 보일 수 있습니다. 실제 결과를 비교할 때는 선택한 출력 형식과 스케일을 함께 기록하십시오.

    두 인자는 ZImage이고 scale은 유한한 양수여야 합니다. 크기나 채널 구성 등 지원 조건이 맞지 않거나 잘못된 형식을 지정하면 오류가 전달됩니다. 결과 영상은 입력과 독립된 소유 객체이므로 사용 후 close합니다. 실제 제품 결함의 검출률을 이 산술 결과만으로 보장하지 않으며, 현장의 기준과 임계값은 별도로 검증해야 합니다.
