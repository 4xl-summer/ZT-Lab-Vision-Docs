    사용과 결과 해석

    인식 위치를 두 좌표계로 보존하는 불변 값입니다. local과 global_은 각각 Point2이며 생성 시 두 값의 타입을 확인합니다. 예를 들어 ROI 원점이 전역 (100,50)이고 해당 이미지의 로컬 점이 (4,3)이라면, 단순 평행 이동 관계에서 전역 점은 (104,53)입니다. 실제 결과에서는 반환된 두 좌표를 사용해 원점을 중복해서 더하지 않습니다.

    BarcodeRead의 points와 OcrChar의 corners가 이 타입을 사용합니다. 위치를 원본 영상 위에 그릴 때는 전역 좌표가 필요한지 표시 대상의 로컬 좌표가 필요한지 먼저 확인합니다. 로컬 좌표는 해당 이미지 또는 ROI에 상대적이므로 다른 원점의 영상에 그대로 그리면 위치가 어긋날 수 있습니다.

    이 객체는 좌표 스냅샷으로 인식 쿼리나 이미지 핸들 자체가 아닙니다. 인식 품질과 상태는 좌표 존재만으로 알 수 없으므로 ReadStatus와 reasons도 확인합니다. 변환이 단순 원점 이동이 아닌 준비 영상의 회전·정규화 경로에서는 관련 변환 정보를 따로 확인해야 합니다.

    문자 결과에서 네 모서리의 순서와 표시 좌표계를 유지하면 회전된 영역의 형상을 원래대로 살펴볼 수 있습니다. 영상이 잘리거나 다시 배치된 경우 현재 화면의 좌표 변환도 별도로 적용해야 합니다.
