solve_hand_eye 멤버와 선언

공개 타입

zvision.solve_hand_eye: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._hand_eye.solve_hand_eye.

Fit X in A X = X B; thresholds use radians and the common length unit.

A X = X B 관계의 손-눈 변환을 계산합니다.

Python
solve_hand_eye(pairs, options)

인자 선언

  • pairs · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

pairs
같은 단위와 프레임 조건을 갖춘 HandEyePair 순서열이며 최대 1024개입니다.
options
각도와 공통 길이 단위 임계값을 포함하는 HandEyeOptions입니다.

반환: 변환과 잔차를 담은 HandEyeResult 스냅샷입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    solve_hand_eye는 대응 운동 쌍과 HandEyeOptions를 받아 AX=XB를 만족하는 변환을 추정합니다. 각 A와 B는 같은 움직임에 대응해야 하며 회전과 이동은 서로 일관된 좌표 프레임과 길이 단위로 표현해야 합니다. 결과에는 추정 변환뿐 아니라 후보 수, 조건 지표, 입력별 회전·이동 잔차가 포함됩니다.

    구체 사례와 판독

    예를 들어 로봇 자세 목록과 카메라 관측 목록의 순서가 한 프레임 어긋나면 두 운동이 같은 실제 움직임을 나타내지 않게 됩니다. 이 경우 계산이 숫자를 반환하더라도 결과가 올바르다고 해석할 수 없습니다. 시간 대응과 프레임 방향을 먼저 확인하고 다양한 회전 운동을 포함한 자료를 준비하세요. 반환된 잔차와 독립 자세의 검증 오차를 함께 확인합니다.

    적용 시 확인

    후보에 대한 내점 임계값은 회전은 라디안, 이동은 변환에 사용한 길이 단위로 설정합니다. 예를 들어 모든 이동을 밀리미터로 입력했다면 0.5의 이동 기준도 밀리미터입니다. 결과의 변환은 B에서 A 방향으로 정의된 X이므로 이를 적용할 점의 출발 프레임을 확인합니다. 동일한 자세만 반복하면 필요한 운동 정보를 충분히 제공하지 못할 수 있습니다. 입력의 시점 대응은 변환 계산에 앞서 검증해야 합니다.
