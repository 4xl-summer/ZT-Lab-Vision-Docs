분할의 두 영상

SplitResult는 거리 기반 분할에서 생성한 markers 영상과 labels 영상을 함께 보관합니다. marker_count는 생성된 마커 수, region_count는 결과 영역 수입니다. 마커는 분할의 출발점이고 레이블은 분할 결과이므로 두 영상을 같은 의미로 읽지 않습니다.

개수와 위치 확인

예를 들어 붙어 있는 두 객체를 두 영역으로 나누고 싶다면 숫자 두 개만 확인하지 말고 각 마커가 목표 객체 안에 위치하는지, 레이블 경계가 의도한 접촉 부위를 가르는지 원본과 겹쳐 봅니다. 마커 선택 옵션이나 ROI 경계 설정에 따라 이 결과는 달라질 수 있습니다.

자원 관리

결과의 close는 markers와 labels 두 ZImage를 닫으며 컨텍스트 관리자로 사용할 수 있습니다. 두 영상이 필요한 표시와 측정을 결과가 열린 동안 완료합니다. 닫은 뒤의 핸들을 다시 사용하지 말고 나중에도 값이 필요하면 해당 API가 정한 방식으로 별도로 보관합니다.

markers와 labels는 별도 영상이므로 어느 쪽을 화면에 띄웠는지 표시해 두는 것이 좋습니다. 경계가 잘못된 것처럼 보일 때 출발 마커부터 원본 위에 겹쳐 보면 설정 문제를 찾는 데 도움이 됩니다.
