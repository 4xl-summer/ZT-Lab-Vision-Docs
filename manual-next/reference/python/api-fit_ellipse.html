확인된 인자 조건

points
유한한 Point2 열; 최소 5개.

채택 잔차 거리; 좌표 단위의 유한한 양수.

반환: EllipseFit 값과 채택점 통계.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류. 퇴화 점 배치도 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    다섯 개 이상의 유한한 점에서 타원 후보를 만들고 허용 잔차 안의 점으로 결과를 정련합니다. threshold는 입력 좌표 단위의 양수이며 반환 값에는 중심, 긴 반축, 짧은 반축, 회전 각도와 피팅 통계가 포함됩니다. 예를 들어 중심이 원점이고 반축이 4와 2라면 축 위의 위치는 (±4,0), (0,±2)입니다. 실제 피팅에는 다섯 점 이상이 필요하므로 이 네 점만으로는 입력 조건을 충족하지 않습니다. 점들이 지나치게 한쪽에 몰리거나 퇴화하면 유한한 좌표라도 유효한 타원을 얻지 못할 수 있습니다. 각도는 라디안이며 반축은 전체 지름이 아닙니다. 결과가 반환되면 채택점 수와 잔차를 확인하고 ROI 로컬 좌표를 다른 영상의 좌표와 바로 혼합하지 마십시오. 긴 반축과 짧은 반축의 순서를 기록할 때 반환 필드를 그대로 사용해야 회전 각도의 해석을 헷갈리지 않습니다. 예시의 반축 4는 전체 장축 길이 8에 해당합니다. 하나의 수치만 바꾸어 비교할 때도 좌표 기준과 입력점 분포를 유지합니다. 결과를 표에 표시할 때 반축 길이의 두 배와 원본 반축을 혼합하지 마십시오. 네 극점은 계산을 이해하기 위한 예이며 실제 입력 요건인 다섯 점을 대신하지 않습니다. 피팅을 검증하려면 추가 점과 기대 형상을 함께 준비합니다.
