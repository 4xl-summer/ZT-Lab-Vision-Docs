Python API · contour_metrics

contour_metrics 멤버와 선언

공개 타입

zvision.contour_metrics: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._regions_flexible.contour_metrics.

Return length and signed turn-angle/mean-chord curvature.

경로 길이와 부호 있는 회전 기반 이산 곡률을 계산합니다.

Python
contour_metrics(points, closed, step)

인자 선언

  • points · POSITIONAL_OR_KEYWORD · 기본값 없음
  • closed · POSITIONAL_OR_KEYWORD · 기본값 없음
  • step · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

points
Point2 점 시퀀스
closed
bool; 경로가 닫혔는지 여부
step
곡률 평가 간격

반환: 독립 윤곽 측정값

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

step: 정수 검사 · 최소 1.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    경로 길이와 방향 변화

    순서 있는 경로에서 길이와 점별 이산 곡률을 계산합니다. 길이는 인접 점 사이 거리의 합으로 이해할 수 있고, 곡률은 경로를 따라 방향이 어떻게 바뀌는지 나타냅니다. 이 두 수치는 점의 순서와 좌표 단위에 의존하므로 임의로 점을 재정렬한 뒤 같은 결과를 기대하면 안 됩니다.

    열림과 닫힘의 차이

    예를 들어 (0,0), (1,0), (1,1) 순서의 열린 경로는 두 선분의 길이를 더해 2입니다. 마지막 점과 첫 점을 연결하는 닫힌 경로라면 그 대각선 구간이 추가됩니다. closed를 실제 경로에 맞추어야 길이뿐 아니라 경계 부근의 방향 변화도 의도대로 해석할 수 있습니다.

    측정 간격

    step은 이산 곡률을 계산하는 간격입니다. 다른 간격을 사용한 결과는 같은 위치의 변화라도 비교 조건이 달라질 수 있으므로 원본 점 간격과 step을 같이 기록합니다. 픽셀 좌표로 계산한 길이를 물리 길이로 바꾸려면 별도 보정과 단위 변환이 필요합니다.

    예를 들어 경로 좌표를 모두 두 배로 확대하면 같은 모양이라도 선분 길이 합은 두 배가 됩니다. 다른 영상의 결과를 비교하려면 크기 보정과 좌표 단위를 통일한 뒤 같은 측정 설정을 적용해야 합니다.
