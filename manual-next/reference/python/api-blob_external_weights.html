blob_external_weights 멤버와 선언

공개 타입

zvision.blob_external_weights: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_external_weights.blob_external_weights.

Measure same-sized GrayF32 membership for each BlobResult label.

외부 멤버십 영상으로 라벨별 가중 면적과 중심을 구합니다.

Python
blob_external_weights(source, weights, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • weights · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
입력 BlobResult
weights

work_budget

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    별도 가중치 영상으로 측정

    blob_external_weights는 BlobResult의 각 레이블에 대해 외부 멤버십 영상의 가중 면적과 중심을 구합니다. 분할 결과가 픽셀의 소속을 정하고 weights가 각 소속 픽셀의 기여도를 정합니다. 가중 면적과 단순한 전경 픽셀 개수를 구분해야 합니다.

    계산 예

    좌표 x가 0, 2인 두 픽셀에 가중치가 1, 3이면 합은 4이고 가중 중심 x는 (0×1+2×3)/4=1.5입니다. 가중치를 모두 1로 둔 평균 1과 다릅니다. 가중치의 분포가 달라지면 픽셀 마스크가 같아도 중심이 이동할 수 있습니다.

    입력 조건

    weights는 라벨 결과와 같은 크기의 유한한 GrayF32 멤버십 영상입니다. 같은 크기만으로 위치가 정렬되었다고 보장되지는 않으므로 ROI와 원본 기준도 확인합니다. source에는 BlobResult를, work_budget에는 양의 정수 상한을 지정합니다.

    결과 사용

    결과의 label로 대상 성분을 확인하고 area와 로컬 중심을 함께 읽습니다. 다른 영상에 중심을 표시할 때 ROI 원점을 맞춥니다. 가중치 값의 측정 단위나 실제 물리적 의미는 입력 데이터의 생성 및 보정 조건에서 별도 확인해야 합니다.
