공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    afloat필수직선 방정식 a×x+b×y+c=0에서 x 계수.
    bfloat필수직선 방정식의 y 계수; (a,b)는 유한하고 0벡터가 아니어야 함.
    cfloat필수직선 방정식의 상수항.

    사용 맥락과 계약

    PointLine2는 2차원 직선을 a·x+b·y+c=0 계수로 표현합니다. a와 b는 직선의 법선 방향을 정의하며 c는 위치에 관련됩니다. 하나의 직선은 모든 계수를 같은 0이 아닌 수로 곱해도 동일한 점 집합을 나타내므로 계수 숫자만으로 두 직선의 기하학적 차이를 판단하면 안 됩니다.

    구체 사례와 판독

    예를 들어 y=2는 0·x+1·y−2=0으로 쓸 수 있고 계수를 두 배 한 0·x+2·y−4=0도 같은 직선입니다. 점 (3,2)를 넣으면 두 식 모두 0이 됩니다. 거리를 구하려면 식의 값을 법선 길이 sqrt(a²+b²)로 나누는 정규화가 필요합니다. 입력 점의 좌표계와 직선 계수가 사용한 좌표계가 같은지도 확인하세요.

    적용 시 확인

    계수 a=b=0이면 정상적인 직선 법선이 정의되지 않으므로 거리 계산의 분모도 0이 됩니다. 입력을 만들 때 유효한 법선을 사용하고 값의 단위가 점 좌표와 일관되는지 확인합니다. 계수의 부호를 모두 뒤집으면 같은 직선이지만 부호 있는 거리의 방향은 뒤집힙니다. 예를 들어 y−2=0을 −y+2=0으로 바꾸어도 선은 동일하지만 두 식을 한 점에 대입한 값의 부호가 반대입니다. 입력의 좌표와 값을 기록해 결과를 다시 확인할 수 있습니다.
