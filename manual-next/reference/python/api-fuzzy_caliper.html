Python API · fuzzy_caliper

fuzzy_caliper 멤버와 선언

공개 타입

zvision.fuzzy_caliper: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._fuzzy_caliper.fuzzy_caliper.

Detect all budgeted edges, score candidates, then apply threshold and result cap.

Scorer components are 0..1 triangular memberships and combined by geometric mean.
Fits and any proprietary scoring functions are outside this operation.

에지 후보의 삼각 소속도를 결합해 점수 순으로 선택합니다.

Python
fuzzy_caliper(image, spec, caliper, scorers, options)

확인된 인자 조건

image
지원 그레이스케일 ZImage.
spec
ROI 로컬 ProfileSpec.
caliper
AdvancedCaliperOptions; max_results는 options.max_candidates와 같아야 함.
scorers
FuzzyScorer 1–16개, 활성 규칙 1개 이상.
options
FuzzyOptions; 후보·작업 예산과 점수 하한.

반환: 독립 FuzzyCandidate 튜플; 점수는 활성 소속도의 기하평균.

오류: 유효하지 않은 옵션·규칙 또는 작업 예산 초과는 오류.

래퍼에서 발생 가능한 오류: RuntimeError, TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
