사용 맥락과 계약

PolarInterpolation은 극좌표 펼침에서 입력 영상의 연속 위치에 대응하는 픽셀 값을 구하는 방식을 선택합니다. NEAREST는 가까운 픽셀 하나를 사용하고 BILINEAR는 주변 픽셀을 이용하는 선형 보간입니다. polar_unwrap의 옵션으로 지정하며 어느 방법이 적합한지는 영상이 연속 밝기인지 이산 라벨인지와 후속 측정 목적에 따라 달라집니다.

구체 사례와 판독

예를 들어 인접 픽셀 밝기가 0과 100이고 두 위치의 정확한 중간을 샘플링한다면 선형 보간은 그 두 값 사이의 밝기를 만들 수 있습니다. 최근접 보간은 원래 이웃 중 하나를 선택하므로 새로운 중간 밝기를 만들지 않습니다. 실제 2차원 쌍선형 보간은 네 이웃과 두 축의 비율을 사용합니다. 경계 부근의 처리와 결과 형식도 함께 확인하세요.

적용 시 확인

최근접 방식은 원본에 존재하는 값을 보존하기 쉬워 정수 라벨의 확인에 유용하지만 계단 모양이 나타날 수 있습니다. 쌍선형은 경계에서 부드러운 중간값을 만들 수 있으므로 이진 마스크의 값이 입력의 두 값 중 하나로만 남을 것이라고 가정하지 마세요. 출력에 임계값을 적용한다면 보간으로 바뀐 경계가 측정에 미치는 영향도 검증해야 합니다. 이산 경계의 위치가 중요한 경우 두 보간 결과를 직접 비교하세요.
