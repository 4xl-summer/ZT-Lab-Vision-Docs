Python API · ImageQueryExecution

ImageQueryExecution 멤버와 선언

공개 타입

zvision.ImageQueryExecution: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._typed_query.ImageQueryExecution.

이미지 출력과 캡처를 독립 공유로 취득하는 실행.

영상 결과와 캡처를 독립 이미지 공유로 취득하는 Query 실행입니다.

이미지 Query의 execute() 결과입니다. acquire_output()과 get_image(name)으로 독립 이미지 공유를 얻으며 각각 닫아야 합니다. 실행도 close() 또는 with로 해제합니다.

Python
ImageQueryExecution() -> 'None'

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

  • acquire_output
  • close
  • get_image

acquire_output

반환: 호출자가 close할 독립 소유 이미지 핸들입니다.

close

실행 소유권을 해제한다. 반복 호출은 안전하다.

get_image

지정 이름의 캡처 영상의 공유 핸들을 취득합니다.
