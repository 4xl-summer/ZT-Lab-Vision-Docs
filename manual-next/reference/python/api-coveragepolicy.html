시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    referencefloat필수기준 길이 또는 원호 각도; 유한한 양수. 원은 2π 라디안 이하.
    minimum_fractionfloat필수필요한 최소 커버 비율; 유한한 0–1.

    사용과 결과 해석

    직선 또는 원 측정에서 확보한 관측 범위를 기준 범위와 비교하는 설정입니다. reference는 비교 기준 길이 또는 각도이고 minimum_fraction은 요구하는 최소 커버리지 비율입니다. 직선의 기준 길이는 해당 측정 좌표 단위로, 원의 기준 각도는 라디안으로 해석해야 하므로 서로 숫자를 바꾸어 넣어서는 안 됩니다.

    예를 들어 기준 길이가 100이고 측정에 실제로 포함된 범위가 70이면 비율은 0.7입니다. 최소 비율을 0.8로 지정했다면 유효한 선이 적합되더라도 최종 커버리지 판정은 거절될 수 있습니다. 이 비교는 점의 개수만 세는 대신 기하적으로 얼마나 덮였는지를 확인합니다.

    결과의 coverage_measured와 coverage_fraction은 적용된 경우의 실제 범위와 비율을 확인할 때 사용합니다. 커버리지 정책을 생략한 경우 해당 값이 없는 상태와 비율 0을 구별하십시오. 탐침이 잘리거나 에지를 찾지 못한 이유는 별도의 탐침 진단을 살펴야 하며, 설정값만으로 입력 영상이 충분하다고 보장할 수 없습니다.
