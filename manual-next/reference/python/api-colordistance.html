ColorDistance 멤버와 선언

공개 타입

zvision.ColorDistance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._naming_advanced_color.ColorDistance.

A Lab distance variant and its variant-specific parameters.

Lab 색차 방식과 방식별 계수의 불변 값입니다. cie76(), cie94(), ciede2000(), cmc(), mahalanobis() 등 공개 팩터리로 생성할 수 있습니다.

Python
ColorDistance(_kind: zvision._color_advanced.AdvancedMetricKind, _parameters: tuple = ()) -> None

인자 선언

  • _kind · POSITIONAL_OR_KEYWORD · 타입 <enum 'AdvancedMetricKind'> · 기본값 없음
  • _parameters · POSITIONAL_OR_KEYWORD · 타입 <class 'tuple'> · 기본값 ()

반환 타입 주석: None

확인된 인자 조건

_kind
AdvancedMetricKind 거리 방식 열거값.
_parameters
방식 순서에 따라 각각 0, 0, 3, 3, 2, 9, 9개인 계수 튜플; 생성 시 길이를 검사하고 튜플로 복사합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
