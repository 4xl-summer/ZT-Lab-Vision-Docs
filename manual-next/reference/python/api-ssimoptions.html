SsimOptions(radius: int, window: zvision._adaptive_inspection.SsimWindow, border: zvision._adaptive_inspection.SsimBorder, sigma: float, data_range: float, k1: float, k2: float, min_score: float, polarity: zvision._adaptive_inspection.SsimPolarity, max_work: int)

국소 가중 SSIM의 창, 밝기 범위와 결함 판정 조건을 지정하는 값입니다.

국소 가중 모집단 SSIM의 창과 결함 조건입니다. 모든 필드는 생성 시 명시합니다. 참조 및 검체는 동일 크기·원점·형식의 Gray8, Gray16 또는 GrayF32여야 합니다. 선택 마스크는 동일 크기·원점의 Gray8 가중치이며 0은 제외합니다. 유효 중심이 없거나 작업 상한을 넘으면 오류입니다.

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    radiusint필수창 반경(픽셀), 0–1024. 창의 한 변은 2 × radius + 1입니다.
    windowSsimWindow필수BOX는 균일 가중, GAUSSIAN은 Gaussian 가중입니다.
    borderSsimBorder필수CLIP은 경계 밖을 제외하고 REPLICATE는 가장자리 픽셀을 복제합니다.
    sigmafloat필수Gaussian 표준편차(픽셀), 양의 유한값입니다. BOX에서는 정확히 1이어야 합니다.
    data_rangefloat필수밝기 정규화에 사용하는 양의 유한 기준 범위입니다.
    k1float필수밝기 안정 상수 계수, 양의 유한값입니다.
    k2float필수구조 안정 상수 계수, 양의 유한값입니다.
    min_scorefloat필수결함 후보 판단의 SSIM 하한이며 −1 이상 1 이하입니다.
    polaritySsimPolarity필수BOTH는 양쪽, BRIGHTER는 검체가 더 밝은 방향, DARKER는 더 어두운 방향입니다.
    max_workint필수국소 표본 방문 상한, 1 이상의 정수입니다. 유효 중심 수 × 창의 한 변²이 이 한도를 넘으면 오류입니다.
