blob_merge_horizontal_tiles 멤버와 선언

공개 타입

zvision.blob_merge_horizontal_tiles: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_merge_tiles.blob_merge_horizontal_tiles.

Join two equal-height nonoverlapping horizontal binary tiles.

같은 높이의 좌우 이진 타일을 연결하고 성분을 재계산합니다.

Python
blob_merge_horizontal_tiles(left, right, connectivity, work_budget)

인자 선언

  • left · POSITIONAL_OR_KEYWORD · 기본값 없음
  • right · POSITIONAL_OR_KEYWORD · 기본값 없음
  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

left
왼쪽 타일 ZImage
right
오른쪽 타일 ZImage
connectivity
연결성 4 또는 8
work_budget
양의 정수 작업량 상한

반환: 독립 BlobMergedTiles 스냅샷

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    인접한 두 타일 결합

    blob_merge_horizontal_tiles는 높이가 같은 왼쪽과 오른쪽 이진 타일을 가로로 이어 붙인 뒤 연결 성분을 다시 계산합니다. 독립 타일 분석 결과를 단순히 나란히 붙이면 경계에 걸친 한 물체가 두 개로 남을 수 있어 이음새의 연결을 함께 확인해야 합니다.

    연결성의 차이

    connectivity에는 4 또는 8을 지정합니다. 이음새의 두 전경 픽셀이 같은 행에서 변을 공유하면 연결될 수 있고, 대각선으로만 만나는 경우는 선택한 이웃 관계에 따라 달라집니다. 입력 마스크를 고정하고 연결 옵션만 바꾸어 비교하면 효과를 쉽게 확인할 수 있습니다.

    입력과 결과

    left와 right에 같은 높이의 ZImage 타일을 전달하고 양의 work_budget을 둡니다. BlobMergedTiles에는 결합 폭과 높이, 행 우선 레이블과 결합 성분의 면적 및 중심이 들어 있습니다. 레이블 0은 배경이며 오른쪽 타일의 좌표에는 왼쪽 타일 폭이 반영된 결합 기준을 사용합니다.

    확인할 점

    이음새의 레이블과 원래 마스크를 함께 표시해 실제로 연결할 객체가 이어졌는지 확인합니다. 두 타일의 영상 정렬이 틀리거나 중복 영역을 잘못 준비하면 연결 계산만으로 정렬 오류를 바로잡을 수 없습니다.
