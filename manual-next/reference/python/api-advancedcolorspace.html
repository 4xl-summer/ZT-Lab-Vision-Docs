사용과 결과 해석

convert_advanced가 만들 색 공간을 선택하는 열거값입니다. LAB=0은 명도 L과 두 색축 a, b를, LCH=1은 명도와 채도 및 색상각을 나타냅니다. 기본은 LAB입니다. 세 채널의 수치는 같은 의미의 RGB 채널이 아니므로 순서와 공간을 함께 기록합니다.

예를 들어 두 색의 a와 b가 각각 3과 4라면 Lab 평면에서 원점까지의 채도 크기는 5입니다. LCH에서 색상각은 두 축의 방향을 표현합니다. 숫자 3과 4를 원본 빨강·초록 채널 값처럼 해석하거나 각도와 색차를 같은 단위로 비교하지 않습니다.

AdvancedPlanes의 channel 인덱스는 0부터 2까지이고 각 호출은 별도 소유 영상을 반환합니다. LCH 결과를 다시 Lab으로 바꾸는 to_lab도 별도 결과를 만듭니다. white와 transfer는 공간 선택과 별도이므로 변환 조건을 누락하지 않습니다.

색상각은 원점 근처의 작은 채도에서 수치 변화의 의미가 달라질 수 있으므로 L과 채도도 함께 살펴봅니다. 비교 시에는 모든 입력을 같은 공간과 변환 조건으로 준비합니다.

LCH의 채널을 읽을 때 순서와 각도의 의미를 확인합니다.
