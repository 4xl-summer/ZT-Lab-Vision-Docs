사용 조건과 흐름

InpaintConductance는 마스크 영역을 이방성 확산으로 복원할 때 확산 계수의 형태를 선택합니다. EXPONENTIAL과 RECIPROCAL은 영상의 밝기 변화에 따라 확산을 조절하는 서로 다른 함수입니다. 반복 횟수, 시간 간격, kappa와 수렴 허용치는 InpaintOptions에서 따로 정합니다.

구체 사례와 결과 판독

예를 들어 복원할 빈 영역의 한쪽이 밝고 다른 쪽이 어둡다면 경계를 가로지르는 확산 정도가 설정에 따라 달라질 수 있습니다. 같은 입력과 마스크로 두 방식을 비교하고 경계가 지나치게 번지는지 확인하세요. 함수 선택만으로 원래 가려진 실제 장면이 복원되었다는 보장은 없습니다.

적용 시 확인

확산 계수의 효과는 kappa와 입력 밝기 스케일에도 의존합니다. 8비트 밝기를 0~1로 정규화한 뒤 이전 kappa 숫자를 그대로 사용하면 서로 다른 조건이 됩니다. 결과 영상과 수렴 보고를 확인하고 실제 검사 데이터에 복원값을 적용하기 전 목적에 맞는지 검증하세요. 두 방식의 비교는 마스크와 초기화 방식, 반복 횟수 및 시간 간격을 고정한 상태에서 수행해야 원인을 구분하기 쉽습니다. 복원 영역 외부의 원본 값과 경계 주변의 출력도 함께 확인합니다.
