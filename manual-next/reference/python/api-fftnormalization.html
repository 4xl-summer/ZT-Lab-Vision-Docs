열거 값

  • BACKWARD = 0 · 순변환은 배율 1, 역변환은 1/N입니다.
  • ORTHONORMAL = 1 · 순·역변환 각각 1/√N 배율입니다.

변환 크기와 정규화

이 열거형은 푸리에 정변환과 역변환의 배율을 선택합니다. N을 변환 격자의 전체 샘플 수라고 하면 BACKWARD는 정변환에 배율 1, 역변환에 1/N을 적용합니다. ORTHONORMAL은 양쪽 모두 1/√N을 적용합니다. 동일한 입력이라도 중간 스펙트럼의 숫자는 선택한 정규화에 따라 달라집니다.

2×2 상수 입력

모든 값이 1인 2×2 격자에서 N은 4입니다. BACKWARD 정변환의 직류 성분은 네 표본의 합인 4이고 같은 설정의 역변환은 1/4 배율을 적용합니다. ORTHONORMAL 정변환은 1/2 배율이므로 직류 성분이 2가 됩니다. 각 변환과 역변환에 일관된 정규화를 사용해야 원래 크기로 복원됩니다.

비교 조건

FftOptions에 정규화를 지정하며 기본값은 BACKWARD입니다. 스펙트럼을 외부 결과나 다른 라이브러리와 비교할 때는 입력 크기, 패딩, 정규화와 복소 성분을 함께 맞춥니다. 숫자 크기만 비교하고 배율을 무시하면 주파수 내용이 같은 결과도 달라 보일 수 있습니다.

입력 전체가 일정하면 직류 성분이 핵심 비교값이고 다른 주파수 성분은 이상적인 산술에서 0입니다. 실제 계산은 부동소수 연산이므로 복원 결과를 비교할 때 작은 수치 오차를 고려해야 합니다.
