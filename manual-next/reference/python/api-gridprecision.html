    사용 맥락과 계약

    GridPrecision은 이미 존재하는 그리드 점의 위치 정밀도 평가 결과를 담습니다. covariance는 이동 위치의 공분산으로 픽셀 제곱 단위이며 major_sigma는 가장 큰 표준편차로 픽셀 단위입니다. accepted는 지정한 기준에 대한 판정이므로 반환 숫자만으로 카메라 전체의 보정 정확도를 뜻한다고 해석하지 않습니다.

    구체 사례와 판독

    예를 들어 공분산이 대각 성분 0.04와 0.01, 비대각 성분 0인 경우 두 축 표준편차는 각각 0.2와 0.1 픽셀이고 큰 값은 0.2 픽셀입니다. 실제 계산은 주어진 밝기 잡음 모델과 국소 영상 패턴에 의존합니다. 검출점의 위치, 사용한 잡음 가정과 판정 한계를 함께 보관해야 결과를 재현할 수 있습니다.

    적용 시 확인

    공분산의 단위는 픽셀 제곱이고 표준편차는 픽셀입니다. 예를 들어 분산 0.04 픽셀²의 제곱근은 0.2 픽셀입니다. 이 값은 가정한 독립 밝기 잡음과 선택된 점 주변의 영상 정보에 따른 추정입니다. 모델이 실제 잡음을 잘 표현하는지와 점이 적절한 영역에 있는지 별도로 검증하세요. accepted가 거짓인 경우에도 위치 숫자만 골라 사용하지 말고 지정한 허용 기준과 주변 영상의 무늬를 살펴 원인을 확인하세요.
