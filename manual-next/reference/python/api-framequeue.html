Python API · FrameQueue

FrameQueue 멤버와 선언

공개 타입

zvision.FrameQueue: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._frame_queue.FrameQueue.

A bounded, independent queue. close() wakes blocked producers and consumers.

Python
FrameQueue()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

  • close
  • create
  • offer
  • shutdown
  • take

close

큐를 닫고 대기 항목을 폐기하며 대기 중인 호출을 깨운 뒤 소유 핸들을 해제합니다.

create

반환: 호출자가 닫아야 하는 FrameQueue입니다.

offer

독립 이미지 큐에 이미지를 제출하고 큐 정책에 따른 처리 상태를 돌려줍니다.

shutdown

Close queue and discard queued frames; current and future waiters wake closed.

take

큐에서 항목을 꺼내거나 대기 종료 상태를 돌려줍니다.
