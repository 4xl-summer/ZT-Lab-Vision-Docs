Python API · FrameQueue

FrameQueue 멤버와 선언

공개 타입

zvision.FrameQueue: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._frame_queue.FrameQueue.

판독 기준

  • 시뮬레이션 카메라의 독립 복사 큐와 FrameQueue의 공유 계약은 별개입니다.
  • 큐의 share는 원본 핸들이 해제되어도 유효합니다.
  • 이는 소프트웨어 프레임 전달이며 실제 카메라 취득을 의미하지 않습니다.

수치와 도형은 연결된 계약의 핵심 관계를 설명하는 예입니다. 실제 SDK 출력으로 명시한 자료를 제외하면 실행 결과나 장비 실측으로 해석하지 않습니다. 좌표계·입력 형식·수명과 오류 조건은 관련 API 계약을 확인한 뒤 적용하세요.

A bounded, independent queue. close() wakes blocked producers and consumers.

Python
FrameQueue()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

  • close
  • create
  • offer
  • shutdown
  • take

close

큐를 닫고 대기 항목을 폐기하며 대기 중인 호출을 깨운 뒤 소유 핸들을 해제합니다.

create

반환: 호출자가 닫아야 하는 FrameQueue입니다.

offer

독립 이미지 큐에 이미지를 제출하고 큐 정책에 따른 처리 상태를 돌려줍니다.

shutdown

Close queue and discard queued frames; current and future waiters wake closed.

take

큐에서 항목을 꺼내거나 대기 종료 상태를 돌려줍니다.
