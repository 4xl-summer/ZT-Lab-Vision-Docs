    사용 맥락과 결과 해석

    여러 특징 모델 검색을 거쳐 승인 및 중복 억제 후 남은 matches와 평가된 RANSAC 가설 수를 담습니다. budget_exhausted는 공유 가설 예산으로 처리가 잘렸는지 나타냅니다. matches가 비어 있어도 검색 전체가 정상적으로 완료되었는지 예산으로 중단되었는지는 이 상태를 따로 읽어야 합니다.

    각 항목의 id로 입력 모델을 식별하고 score와 개별 result의 대응점·변환을 검토합니다. evaluated는 모든 모델에서 평가한 가설의 합이지 검출된 객체 수가 아닙니다. 한 모델의 탐색이 예산을 많이 사용하면 다른 모델의 평가 기회가 제한될 수 있으므로 총 예산과 입력 순서를 함께 기록합니다. 반환 후보는 원래 네이티브 결과가 해제된 뒤에도 독립 값으로 남습니다.

    값을 확인하는 순서

    matches 항목: 승인 및 중복 억제 후 남은 결과의 불변 튜플입니다. evaluated 항목: 모델들의 평가된 RANSAC 가설 수 합계입니다. budget_exhausted 항목: 공유 가설 예산으로 검색이 잘렸는지 나타냅니다.

    항목읽을 때 확인할 내용

    budget_exhausted공유 가설 예산으로 검색이 잘렸는지 나타냅니다.
