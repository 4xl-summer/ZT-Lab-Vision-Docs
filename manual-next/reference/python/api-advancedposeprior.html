    사용 맥락과 결과 해석

    확장 NCC 검색에서 예상 위치, 회전과 두 축 배율을 나타냅니다. position은 검색 영상 로컬 기준점이며 angle은 라디안, scale_x와 scale_y는 유한한 양의 비율입니다. 이 값은 후보를 무한한 연속 공간에서 생성하는 설정이 아니라 지정한 검색 격자의 방문 순서를 예상 포즈 근처부터 정하는 데 사용됩니다.

    예상 위치가 격자의 중간에 있으면 가까운 격자점이 먼저 평가됩니다. 예산이나 시간 제한, 조기 종료가 있다면 평가 순서가 실제 반환 후보에 영향을 줄 수 있습니다. 이전 프레임의 결과를 우선값으로 쓸 때에는 같은 ROI 로컬 좌표인지 확인하고, 영상 원점이 바뀌었다면 변환해야 합니다. prior 자체를 검출된 결과나 확정 자세로 취급하지 않습니다.

    값을 확인하는 순서

    position 항목: 예상 검색 영상 로컬 기준점 좌표입니다. 성분은 유한해야 합니다. angle 항목: 우선 탐색할 유한 회전각(라디안)입니다. scale_x 항목: 우선 탐색할 유한한 양의 x 배율입니다. scale_y 항목: 우선 탐색할 유한한 양의 y 배율입니다.
