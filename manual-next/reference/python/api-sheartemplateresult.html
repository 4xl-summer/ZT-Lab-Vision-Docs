    사용 맥락과 결과 해석

    x 전단 계수를 포함한 NCC 매치 튜플, 평가 포즈 수와 종료 이유입니다. matches는 점수 순의 독립 값이며 비어 있을 수 있습니다. evaluated와 termination을 함께 읽어 전체 격자를 평가한 미검출과 예산 또는 시간으로 중지된 미검출을 구분합니다.

    각 항목의 shear는 u′=u+shear×v의 무차원 계수이고 기본 포즈는 match에 있습니다. 검색 시 전단 축과 별도의 max_work를 지정해야 하며 coarse와 subpixel은 이 경로에서 지원되지 않습니다. 후보가 없다고 해서 잘못된 입력 오류까지 포함하는 것은 아닙니다. 템플릿과 마스크, 격자 및 예산이 유효한지 먼저 확인하세요.

    전단 검색의 입력 마스크는 선택 사항이고 해당 옵션의 마스크 오프셋을 따릅니다. 결과를 다른 영상과 비교할 때는 원점과 검색에 사용한 전단 범위를 함께 남깁니다.

    값을 확인하는 순서

    matches 항목: 점수순 전단 매치의 독립 불변 튜플입니다. evaluated 항목: 평가한 포즈 수입니다. termination 항목: 전체 완료 또는 검색 제한에 따른 종료 이유입니다.

    항목읽을 때 확인할 내용
