m01: 행 우선 3×3 투영 행렬의 1행 2열 계수.

m21: 행 우선 3×3 투영 행렬의 3행 2열 계수.

m22: 행 우선 3×3 투영 행렬의 3행 3열 계수.

점 변환과 피팅을 구별하기

이 값은 행 우선 3×3 계수를 저장합니다. 점 (x, y)에 세 번째 성분 1을 붙여 행렬을 적용한 다음 앞의 두 성분을 세 번째 성분으로 나눕니다. 예를 들어 단위 행렬에 (10, 20)을 넣으면 결과도 (10, 20)입니다. 이 예는 투영 방향을 확인하는 계산이며 실제 카메라 보정 정확도를 입증하지 않습니다.

직접 만든 가역 행렬은 마지막 계수가 0이어도 유효할 수 있습니다. 반면 대응점에서 행렬을 추정하는 기본 피팅은 서로 대응하는 점이 네 쌍 이상 필요하고 내부적으로 다른 표현 제약을 사용합니다. 중복이나 공선으로 제약이 부족하면 실패할 수 있으며 이 함수가 대응점을 자동 검출하거나 이상점을 제거한다고 가정하지 않습니다.

결과의 분모가 투영 지평선 근처에서 너무 작아지거나 계산이 유한하지 않으면 점 변환은 오류가 될 수 있습니다. 합성은 먼저 현재 변환을 적용하고 다음 변환을 적용하는 순서이므로 두 행렬의 순서를 바꾸면 일반적으로 결과도 달라집니다.
