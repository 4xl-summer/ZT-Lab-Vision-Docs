to_advanced_planes 멤버와 선언

공개 타입

zvision.to_advanced_planes: 패키지 속성으로 접근 가능하지만 __all__에는 없습니다. 선언 출처: zvision._naming_advanced_color.to_advanced_planes.

Convert this image to closeable Lab or LCH planes.

Python
to_advanced_planes(self, white=<AdvancedWhitePoint.D50: 0>, transfer=None, space=<AdvancedColorSpace.LAB: 0>)

인자 선언

  • white · POSITIONAL_OR_KEYWORD · 기본값 <AdvancedWhitePoint.D50: 0>
  • transfer · POSITIONAL_OR_KEYWORD · 기본값 None
  • space · POSITIONAL_OR_KEYWORD · 기본값 <AdvancedColorSpace.LAB: 0>

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    입력 색 영상을 Lab 또는 LCH 색 평면으로 변환해 소유 결과를 반환합니다. white는 기준 백색이고 기본값은 D50, transfer가 None이면 sRGB 전달 함수를 사용하며 기본 space는 Lab입니다. 출력 색 좌표의 의미는 전달 함수와 백색점에 의존하므로 입력의 실제 인코딩에 맞는 설정을 선택해야 합니다.

    Lab에서는 밝기 L과 두 색축 a, b를, LCH에서는 밝기와 채도·색상각을 해석합니다. 같은 RGB 숫자라도 D50과 D65로 변환한 좌표를 그대로 비교하면 백색점 차이가 섞입니다. 두 영상의 색차를 비교할 때는 변환 조건과 관측자 설정이 일치하는지 확인하십시오.

    결과 객체와 각 채널 접근자로 얻은 영상은 각각 독립 소유이므로 사용 후 close합니다. 결과를 해제한다고 획득한 채널의 사용을 자동으로 끝내는 것으로 가정하지 마십시오. 이 수치 변환은 실제 카메라 프로파일이나 조명의 변화를 자동 보정하지 않습니다.
