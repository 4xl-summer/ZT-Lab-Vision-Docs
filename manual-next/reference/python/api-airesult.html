zvision.AiResult: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inference.AiResult.

Owned result independent of its engine and input image.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

detections

property · 선언 타입 zvision._inference.AiResult

AiResult.detections

검출 결과의 상자 목록을 복사합니다.

반환: 독립 AiDetection 튜플입니다.

오류: 닫힌 객체 또는 해당 작업과 맞지 않는 결과 접근 시 오류가 전달됩니다.

Detection boxes as an owned tuple; other tasks error.

AiResult.info

결과 메타데이터를 조회합니다.

반환: 독립 AiResultInfo 값입니다.

오류: 닫힌 객체나 네이티브 오류가 전달됩니다.

Return an immutable metadata snapshot.

map

property · 선언 타입 zvision._inference.AiResult

Python
AiResult.map

분할 또는 이상 맵을 얻습니다.

반환: 분할은 GrayU32, 이상 맵은 GrayF32인 소유 ZImage로 별도 close가 필요합니다.

오류: 닫힌 객체 또는 해당 작업과 맞지 않는 결과 접근 시 오류가 전달됩니다.

Owned GrayU32 segmentation or GrayF32 anomaly map; close separately.

scores

property · 선언 타입 zvision._inference.AiResult

Python
AiResult.scores

분류 결과의 softmax 점수를 복사합니다.

오류: 닫힌 객체 또는 해당 작업과 맞지 않는 결과 접근 시 오류가 전달됩니다.

Classification softmax scores as an owned tuple; other tasks error.
