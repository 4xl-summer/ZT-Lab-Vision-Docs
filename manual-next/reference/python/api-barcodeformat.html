  • CODE39 = 2 · 값 2. 단일 바코드 탐색에 Code 39를 포함하는 선택 비트입니다.
  • EAN13 = 4 · 값 4. 단일 바코드 탐색에 EAN-13을 포함하는 선택 비트입니다.

사용과 결과 해석

바코드에서 탐색할 종류를 선택하는 비트 플래그입니다. CODE128=1, CODE39=2, EAN13=4, QR_CODE=8, DATA_MATRIX=16이며 여러 형식을 비트 OR로 조합해 BarcodeSpec의 formats에 전달합니다. 예를 들어 Code 128과 QR을 함께 찾으려면 1과 8을 결합한 값 9를 사용합니다. 값 0이나 정의된 다섯 비트 밖의 마스크는 이 바인딩의 허용 범위를 벗어납니다.

탐색 형식을 정확히 지정하면 반환된 BarcodeRead의 format이 무엇인지 사용 조건과 함께 판독할 수 있습니다. 결과에 format이 없거나 읽기 상태가 NO_READ인 경우에는 텍스트가 비어 있다고 해서 특정 형식의 정상 바코드로 해석하면 안 됩니다. try_rotate와 min_contrast는 형식 선택과 별도의 BarcodeSpec 설정입니다.

형식 플래그는 이미지의 방향을 바꾸거나 인쇄 품질 등급을 측정하는 옵션이 아닙니다. 인식이 되지 않으면 입력 영역과 대비, 허용 형식, 회전 시도 설정을 순서대로 비교합니다. 반환 contrast는 Gray8 ROI의 (최댓값−최솟값)/255이며 바코드 검증기 품질 등급으로 취급하지 않습니다.
