intrinsic_to_lens 멤버와 선언

공개 타입

zvision.intrinsic_to_lens: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.intrinsic_to_lens.

Read a zero-skew K matrix as an undistorted Brown lens.

무왜곡·무기울기 카메라 내부행렬을 Brown 렌즈로 변환합니다.

Python
intrinsic_to_lens(matrix)

인자 선언

  • matrix · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

matrix
3×3 내부행렬 Homography

반환: 왜곡 계수가 0인 LensModel 값

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    intrinsic_to_lens는 카메라 내부행렬에서 렌즈 모델을 구성합니다. 입력 행렬에는 픽셀 단위의 초점 거리와 주점 등 내부 투영 정보가 들어갑니다. 3×3 행렬은 일반적으로 렌즈의 방사·접선 왜곡 계수를 포함하지 않으므로 외부에서 전달받은 행렬만으로 실제 렌즈의 모든 왜곡을 복원할 수 없습니다.

    구체 사례와 판독

    예를 들어 초점 거리 500 픽셀과 주점 (320,240)을 가진 내부행렬은 핀홀 투영의 규모와 기준점을 나타냅니다. 이 행렬로 모델을 만든 다음 화면 중심의 광축 방향을 점검할 수 있지만, 화면 가장자리의 실제 왜곡 정확도는 별도의 계수와 관측으로 검증해야 합니다. 행렬이 정의된 영상의 해상도와 좌표 원점을 사용하는지도 함께 확인하세요.

    적용 시 확인

    내부행렬의 각 원소가 사용하는 행과 열의 관례도 전달하는 쪽과 일치해야 합니다. 행렬을 평탄한 배열로 저장한다면 행 우선인지 열 우선인지 확인하고 주점이 올바른 위치에 들어갔는지 작은 투영 예제로 검사하세요. 보정된 카메라를 교환할 때는 원본 왜곡 계수도 별도로 유지합니다. 이 함수는 비틀림이 0인 내부행렬을 왜곡이 없는 Brown 렌즈로 읽습니다. 행렬에 없는 왜곡 계수를 추정하는 보정 단계가 아닙니다.
