    소수 좌표 경계 체인

    BlobSubpixelEdge는 ROI 로컬 픽셀 좌표의 순서 있는 에지 점들과 closed 플래그를 담습니다. 소수 좌표는 픽셀 중심 사이의 위치를 표현할 수 있습니다. 점 목록의 각 숫자가 실제 장비에서 같은 수준의 측정 정확도를 보장한다는 의미는 아닙니다.

    닫힘과 길이

    닫힌 경계는 끝점과 시작점 사이에도 연결이 있는 경로로 해석합니다. 예를 들어 (0,0), (1,0), (1,1)을 순서대로 잇는 열린 경로는 길이 2이고 닫힌 경로는 마지막 대각선이 추가됩니다. 소비하는 연산이 closed를 어떻게 적용하는지 확인해야 합니다.

    점의 순서

    점들은 경계를 따라 정렬된 체인입니다. 좌표값을 단순히 x순으로 정렬하면 원래의 이웃 관계가 깨져 길이나 형상 계산이 달라질 수 있습니다. 결과를 다른 ROI나 전체 영상 위에 그릴 때는 원점을 맞추고 원래의 순서를 유지합니다.

    정밀 측정

    정수 화면에 표시하려고 반올림한 점은 원본 소수 좌표와 다릅니다. 후속 기하 계산에서는 원래 좌표를 사용하고 표시용 변환을 분리하세요. 입력 영상의 경계 대비나 보정 상태에 따른 오차도 따로 평가합니다.
