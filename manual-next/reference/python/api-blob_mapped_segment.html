Python API · blob_mapped_segment

blob_mapped_segment 멤버와 선언

공개 타입

zvision.blob_mapped_segment: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_segmentation.blob_mapped_segment.

Segment with a 256-byte lookup table scaled to membership 0..1.

256항목 조회표로 회색값을 멤버십에 매핑합니다.

Python
blob_mapped_segment(image, lut, scaling, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lut · POSITIONAL_OR_KEYWORD · 기본값 없음
  • scaling · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
lut
0부터 scaling까지 값 256개의 조회표
scaling
1–255 정수 멤버십 분모
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 BlobSegmentationResult

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    조회표 분할

    blob_mapped_segment는 256개 항목의 조회표로 입력 회색값을 멤버십에 매핑합니다. 각 회색값이 테이블의 대응 항목을 선택하므로 단일 임계값보다 다양한 값별 규칙을 표현할 수 있습니다. LUT 분할의 설정은 단순한 low와 high 임계값 한 쌍과 구분해야 합니다.

    테이블과 스케일

    lut는 256개 값으로 구성하고 각 값은 0부터 scaling까지의 범위를 사용합니다. scaling은 1부터 255까지의 정수 멤버십 분모입니다. 예를 들어 scaling이 100이라면 테이블의 0과 100은 각각 범위의 양 끝을 나타냅니다. 중간 값은 지정된 스케일에 대한 멤버십으로 해석합니다.

    호출과 검사

    입력 ZImage와 LUT, scaling, 양의 work_budget을 전달합니다. 값 하나를 바꾸면 해당 회색값을 가진 모든 위치의 매핑에 영향을 주므로 작은 입력으로 테이블의 관심 항목을 확인합니다. 입력 픽셀 형식과 실제 값 범위도 맞춰야 합니다.

    결과 해석

    서로 다른 밝기를 같은 값으로 보내거나 인접한 밝기를 다르게 보낼 수 있으므로 결과는 설정한 LUT 전체에 의존합니다. 분할을 재현할 때는 테이블과 scaling을 함께 보관하고 실제 객체 마스크와 판정 결과를 따로 검증합니다.
