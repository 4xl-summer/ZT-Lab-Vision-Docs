fit_cylinder(cloud, threshold, options)

인자 선언

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
threshold
유한 양수 표면 거리 임계값, 점군 단위
options
CylinderOptions: 반복·이상치·축·허용값 설정

반환: CylinderFit 값 스냅샷입니다.

오류: 점 부족, 퇴화, 합의 부족 또는 무효 옵션이면 오류입니다.

threshold: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    fit_cylinder는 점군의 유효점을 사용해 축 방향과 대표점, 반지름을 갖는 원통을 국소 적합합니다. threshold는 표면과 점 사이의 유한 양수 거리로 점군 단위입니다. CylinderOptions는 반복 한도와 허용 이상치 비율, 선택적 초기 축, 정지 조건을 담습니다. 지정한 축은 유한하고 0이 아닌 방향이어야 하며 계산에서 정규화됩니다.

    반환된 CylinderFit의 inliers는 채택된 점, total은 결측을 제외한 유효점 수입니다. 반지름과 잔차는 같은 길이 단위이므로 예를 들어 2 mm 반지름을 기대하는 입력과 다른 단위의 숫자를 섞지 않습니다. 최소 점이 있더라도 짧은 호, 부족한 축 방향 범위 또는 퇴화는 피팅을 불안정하게 하거나 실패시킬 수 있습니다. 제한된 국소 탐색은 임의의 입력에서 전역 최적을 보장하지 않으므로 관측 범위와 보류 데이터도 확인합니다.
