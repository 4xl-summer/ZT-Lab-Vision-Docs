공개 멤버

    사용과 결과 해석

    한 점과 원의 경계 사이의 음수가 아닌 최단 거리를 계산합니다. 점에서 중심까지의 거리와 반경의 차이에 절댓값을 취하므로 원 안쪽과 바깥쪽을 구분하지 않습니다. 중심 (0,0), 반경 2인 원에서 점 (3,0)의 거리는 1이고 점 (1,0)의 거리도 1입니다. 내부인지 외부인지가 필요한 판정이라면 중심까지의 거리와 반경을 별도로 비교해야 합니다. 점과 원은 같은 좌표계와 길이 단위를 사용해야 하며 반경은 유한한 양수여야 합니다. 예를 들어 ROI에서 찾은 중심에 글로벌 점을 직접 비교하면 수치가 유효해도 서로 다른 위치를 측정할 수 있습니다. 모델이 없거나 잘못된 값인 경우를 실제 경계와 일치하는 거리 0으로 바꾸지 마십시오. 반경 2인 원에서 중심까지의 거리가 2이면 경계 위이므로 결과는 0입니다. 결과 1만 보면 예시의 안쪽 점과 바깥쪽 점을 구별할 수 없다는 점이 중요합니다. 부호를 사용한 다른 관계량을 선택할 때에는 그 정의도 함께 확인하십시오. 원의 크기 자체를 구하는 연산은 아니므로 반경과 결과 거리를 혼동해서는 안 됩니다. 예시 점 (3,0)의 거리가 1이라는 것은 중심 거리가 3이고 반경이 2인 상황에서 둘레까지 남은 길이를 나타냅니다.
