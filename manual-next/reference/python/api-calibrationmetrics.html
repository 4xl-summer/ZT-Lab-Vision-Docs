    사용과 결과 해석

    보류 대응점의 세계 좌표와 픽셀 좌표 오차를 한 번에 읽는 집계 값입니다. count는 평가한 점 수이고 rms_world와 max_world는 정방향 세계 거리의 RMS와 최대입니다. rms_pixel과 max_pixel은 기준 세계점을 역변환해 관측 픽셀과 비교한 거리이므로 서로 다른 단위를 사용합니다. 예를 들어 세계 차이가 (0.3,0.4)밀리미터인 보류점 하나의 거리, RMS와 최대값은 각각 0.5밀리미터입니다. passed는 최대 세계 잔차가 전달한 허용치 이하인지를 나타냅니다. 여러 점에서는 작은 RMS와 큰 최대 오차가 함께 나올 수 있으므로 합격 여부만 남기지 말고 점별 잔차도 살펴보십시오. 학습점에 대한 오차와 독립 보류점의 오차는 다른 질문에 답하며, 실제 장비 정확도는 별도로 검증해야 합니다. 서로 다른 위치의 잔차를 집계한 숫자 하나는 문제가 발생한 지점을 직접 알려 주지 않습니다. 따라서 평균이나 RMS와 최대값을 함께 읽고, 값이 커진 위치를 개별 잔차 배열 및 기준점 배치와 대조합니다. 점의 개수와 단위도 기록해야 두 평가를 비교할 수 있습니다. 학습에 사용한 점에서의 작은 오차는 보류 위치에서 같은 정확도를 보장하지 않습니다. 평가 점을 영상 영역에 분산해 결과를 별도로 기록하십시오.
