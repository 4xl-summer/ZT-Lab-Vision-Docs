Fit an affine transform to known paired points; no image search occurs.

알려진 대응점에 아핀 변환을 적합합니다. 영상에서 점을 검색하지 않습니다.

확인된 인자 조건

reference
기준 좌표의 Point2 시퀀스로 세 점 이상입니다.
source
대응하는 소스 좌표의 같은 길이 Point2 시퀀스입니다.

반환: 기준→소스 행렬과 개별 잔차를 담은 독립 LandmarkAffineFit입니다.

오류: 점 개수가 다르거나 적합 불가능한 입력은 오류입니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    호출자가 이미 알고 있는 기준점과 소스점의 대응을 사용해 아핀 변환을 적합합니다. reference와 source는 각각 Point2 시퀀스이며 길이가 같고 적어도 세 쌍이 필요합니다. 이 함수는 영상에서 점을 찾지 않습니다. 반환 행렬은 기준 좌표를 소스 좌표로 옮기는 행 우선 2×3 계수입니다.

    예를 들어 기준의 세 점을 같은 양만큼 이동한 소스 점과 순서대로 대응시키면 회전이나 배율 변경 없이 그 이동을 설명하는 아핀 변환을 기대할 수 있습니다. 적합의 잔차 RMS뿐 아니라 각 대응점의 잔차를 확인해야 잘못 연결된 점을 찾기 쉽습니다. 점 개수가 다르거나 기하가 퇴화한 경우는 오류이며 정상적으로 계산된 작은 잔차와 구분합니다.
