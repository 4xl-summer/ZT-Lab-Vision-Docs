blob_angle_box 멤버와 선언

공개 타입

zvision.blob_angle_box: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_angle_box.blob_angle_box.

Return a tight enclosing rectangle at the given angle in radians.

지정 축 방향으로 Blob을 감싸는 사각형을 측정합니다.

Python
blob_angle_box(source, index, angle, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • index · POSITIONAL_OR_KEYWORD · 기본값 없음
  • angle · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
입력 BlobResult
index
0 기반 영역 인덱스
angle
유한한 방향 각도(라디안)
work_budget
양의 정수 작업량 상한

반환: BlobAngleBox 값

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    지정 축의 외접 상자

    blob_angle_box는 선택한 Blob을 유한한 angle 방향의 두 직교 축에 투영하여 감싸는 사각형을 측정합니다. 입력 각도는 라디안이며, 결과의 폭과 높이는 각각 첫 축과 직교 축 방향의 길이입니다. 상자의 중심은 ROI 로컬 좌표입니다.

    선택과 설정

    source는 BlobResult이고 index는 0 기반 영역 인덱스입니다. 첫 성분은 0입니다. 각도를 도 단위 수치로 넣으면 다른 방향이 되므로 필요한 경우 라디안으로 변환합니다. 예를 들어 90도는 π/2 라디안입니다. work_budget은 양의 정수 상한입니다.

    결과 해석

    같은 물체도 angle을 바꾸면 투영 폭과 높이가 달라집니다. 따라서 두 물체의 크기를 비교할 때 방향을 통일하거나 각 결과의 방향을 함께 기록해야 합니다. 외접 상자의 내부에 구멍이나 배경이 포함될 수 있으므로 폭×높이를 전경 면적으로 사용하지 않습니다.

    확인

    원본 마스크에 사각형을 겹쳐 원하는 성분이 감싸졌는지 확인합니다. 전체 영상 표시에는 ROI 원점이 필요합니다. 주어진 각도에서의 결과이므로 방향을 자동 최적화한 결과라고 가정하지 않습니다.
