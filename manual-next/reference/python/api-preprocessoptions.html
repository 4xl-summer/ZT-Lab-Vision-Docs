확인된 인자 조건

width
모델 출력 너비(픽셀), 양수이며 height와의 곱은 1,048,576 이하.
height
모델 출력 높이(픽셀), 양수이며 width와의 곱은 1,048,576 이하.
resize
0은 늘이기, 1은 비율 유지 레터박스; 기본 0.
interpolation
0은 최근접, 1은 이중선형; 기본 0.
channel_order
0은 RGB, 1은 BGR 채널 순서; 기본 0.
pad
상수 패딩에 쓰는 0–255 정수 채널 세 개; 기본 (0,0,0).
mean
정규화에서 채널마다 빼는 유한한 세 값; 기본 (0,0,0).
std
정규화에서 채널마다 나누는 유한한 양의 세 값; 기본 (1,1,1).
pad_alignment
레터박스 배치: 0 가운데, 1 왼쪽 위, 2 오른쪽 아래; 기본 0.
padding
0 상수 패딩, 1 경계 픽셀 복제; 기본 0.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
