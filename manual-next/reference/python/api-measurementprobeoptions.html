MeasurementProbeOptions 멤버와 선언

공개 타입

zvision.MeasurementProbeOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.MeasurementProbeOptions.

Probe count/length/width/samples, filters, selection and robust fit settings.

direction: 0 forward, 1 reverse; selection: 0 first, 1 last, 2 strongest.
interpolation: 0 nearest, 1 bilinear; derivative: 0 central, 1 regression;
polarity: 1 rising, 2 falling, 3 either; fit_method: 0 least squares, 1 consensus.
threshold and prominence are gradient intensity per pixel; lengths and fit
threshold/tolerance are in ROI-local pixels; min_arc is in radians. Filter
is an odd-length, nonzero-sum sequence normalized by its sum.
