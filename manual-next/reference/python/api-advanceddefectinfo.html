    사용과 결과 해석

    고급 윤곽 결과에서 결함 하나의 진단 측정값을 복사한 불변 값입니다. area는 영역의 픽셀 면적, perimeter는 셀 경계의 둘레, holes는 구멍 수입니다. roughness와 feret_max는 형상의 거칠기와 최대 Feret 측정값을 나타내고 contrast는 값이 없을 수 있습니다.

    면적과 둘레는 서로 다른 양입니다. 예를 들어 한 픽셀 셀의 면적은 1이고 네 변의 둘레는 4입니다. 구멍이 있는 영역은 외곽과 내부 경계를 함께 고려해야 하므로 경계 사각형의 크기만으로 면적이나 둘레를 대신하지 않습니다.

    AdvancedContours.info에 결함 인덱스를 전달해 이 값을 얻고, AdvancedDiagnosticRange를 사용하는 select로 조건을 확인할 수 있습니다. contrast가 None인 경우 측정이 없는 상태이며 숫자 0과 구분해야 합니다. 이 정보는 입력 마스크와 밝기 영상의 같은 기하를 전제로 읽습니다.

    Feret 값은 형상의 방향에 따른 거리 측정이고 경계 상자의 폭과 자동으로 같지 않습니다. 값을 비교할 때 같은 마스크 해상도와 처리 조건을 유지해야 픽셀 단위 수치의 차이를 의미 있게 읽을 수 있습니다.
