공개 타입

zvision.MatchResult: 패키지 속성으로 접근 가능하지만 __all__에는 없습니다. 선언 출처: zvision._matching.MatchResult.

Independent immutable snapshot of the matches returned by a search.

The input iterable is copied into a tuple; no native resource needs closing.

MatchResult(matches: Iterable[zvision._matching.Match])

사용 맥락과 결과 해석

기본 MatchModel.find가 반환하는 독립적인 불변 결과 스냅샷입니다. matches는 Match 값으로 복사된 튜플이고 best는 첫 항목 또는 None입니다. 입력 영상과 모델을 닫은 뒤에도 이미 얻은 값은 유지되며 이 결과 자체는 닫아야 할 네이티브 핸들을 소유하지 않습니다.

모델 검색에서 얻은 후보는 점수순 정렬과 중심 거리 억제를 거치므로 첫 항목이 가장 높은 점수의 결과입니다. 빈 튜플은 정상적인 미검출일 수 있으며 잘못된 입력이나 검색 설정의 오류와 다릅니다. 생성자를 직접 호출하면 전달한 iterable 순서로 복사하므로 임의 입력까지 자동으로 정렬된다고 가정하면 안 됩니다. 결과의 위치는 검색 ROI 로컬 기준점이고 전역 위치는 영상 원점을 더한 값입니다.

값을 확인하는 순서

matches 항목: 입력 매치들을 복사해 만든 불변 튜플입니다. best 항목: 첫 매치이며 비어 있으면 None입니다.

항목읽을 때 확인할 내용
matches입력 매치들을 복사해 만든 불변 튜플입니다.
best첫 매치이며 비어 있으면 None입니다.
