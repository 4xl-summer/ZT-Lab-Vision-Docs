    영상 크기와 행 간격

    이 레코드는 영상의 폭과 높이를 픽셀 단위로 나타내고, 한 행에서 다음 행으로 이동하는 바이트 간격과 픽셀 형식을 함께 보관합니다. 폭과 행 간격은 서로 다른 단위입니다. 폭이 10픽셀이라는 사실만으로 각 행이 반드시 10바이트라고 판단할 수 없으며 픽셀당 저장 크기와 행 패딩을 함께 고려해야 합니다.

    읽기 전 확인

    예를 들어 폭 3, 높이 2인 영상에는 화면상 픽셀 위치가 여섯 개 있지만, 메모리의 두 번째 행 위치는 기록된 stride_bytes만큼 이동해 찾아야 합니다. 픽셀 형식이 여러 바이트를 사용하거나 행 사이에 여유 공간이 있으면 폭과 stride를 같은 숫자로 놓고 계산하면 행의 시작을 잘못 찾습니다.

    사용과 한계

    픽셀 형식을 먼저 확인한 다음 각 행의 시작과 읽을 픽셀 범위를 계산하고 영상 접근 API의 소유권 규칙을 따릅니다. 이 정보는 배치와 형식을 설명하며 영상의 내용을 복사하거나 버퍼 수명을 연장한다는 보장은 아닙니다. ROI와 원본의 좌표 관계가 필요한 작업에서는 해당 영상의 좌표 기준도 별도로 확인합니다.

    행의 시작 위치를 계산할 때는 바이트 단위 stride를 사용하고, 각 행 안에서 픽셀 위치를 계산할 때는 형식별 픽셀 크기를 적용합니다. 영상 너비와 바이트 간격을 섞으면 패딩이 있는 데이터에서 두 번째 행부터 판독이 어긋날 수 있습니다.
