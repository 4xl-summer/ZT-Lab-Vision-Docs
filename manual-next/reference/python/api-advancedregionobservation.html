    점별 피팅 진단

    AdvancedRegionObservation은 선택된 원본 입력 점의 input_index, 피팅 결과에 대한 residual, 인라이어로 사용되었는지의 used를 담습니다. 최종 모델 하나만 보는 대신 각 점이 결과에 어떤 영향을 주었는지 살펴보는 자료입니다.

    잔차와 선택

    예를 들어 어떤 점의 잔차가 설정한 인라이어 한도보다 크다면 그 점의 사용 여부를 결과의 used와 함께 확인합니다. 잔차가 작다는 사실만으로 해당 점의 센서 측정 자체가 정확하다고 보장할 수는 없으며 피팅된 모델과의 차이를 설명하는 값입니다.

    인덱스 기준

    input_index는 원래 입력 점의 인덱스입니다. 선택된 점 목록의 새로운 순번으로 해석하면 원본에서 엉뚱한 점을 표시할 수 있습니다. 원본 점 배열을 유지하고 각 관측을 원본 영상 또는 좌표에 연결해 진단합니다.

    사용 조건

    잔차의 단위는 피팅에 넣은 좌표 단위와 관계가 있습니다. 픽셀 좌표와 물리 좌표로 구한 결과를 같은 숫자 기준으로 비교하지 말고, 설정한 임계값과 모델 및 입력의 좌표계를 함께 기록합니다.
