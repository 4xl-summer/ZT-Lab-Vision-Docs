사용과 결과 해석

프로파일 실행에서 얻은 샘플을 독립적으로 보관하는 결과입니다. samples에는 선분을 따라 얻은 ProfileSample 값이 들어 있으며 각 샘플은 위치, 시작점에서의 거리와 강도를 구분해 읽습니다. 예를 들어 길이 4픽셀의 선분을 끝점을 포함해 다섯 위치에서 표본화하면 위치 간 간격은 1픽셀입니다. 값 배열은 에지 목록이 아니므로 기울기와 극성에 따른 경계 선택은 별도로 수행해야 합니다. 선분 방향을 반대로 정하면 같은 물리 위치라도 시작점에서의 거리와 배열 순서가 달라집니다. 결과를 비교할 때 원래 선분과 ROI 원점, 표본 수와 폭도 같이 기록하십시오. 독립 결과는 실행 객체의 수명과 분리하여 샘플을 보관할 수 있다는 뜻이며, 다른 입력 영상에도 같은 강도가 나타난다는 보장은 아닙니다. 위치는 ROI 로컬 픽셀이고 강도는 원본 영상의 자료형과 보간 설정을 따라 해석합니다. 샘플을 얻는 호출이 실패했다면 이를 강도 0의 정상 표본으로 채워 넣지 마십시오. 입력 영상과 선분 기하가 유효한지 먼저 확인해야 합니다. 직선의 끝점을 포함한 거리 간격은 길이를 표본 수에서 1을 뺀 값으로 나눈 것입니다. 같은 길이에 표본 수가 달라지면 표본 간격이 달라져 인접 차분의 해석도 달라집니다. 각 표본의 거리 필드를 이용해 읽으십시오.
