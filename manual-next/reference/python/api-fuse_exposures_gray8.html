fuse_exposures_gray8 멤버와 선언

공개 타입

zvision.fuse_exposures_gray8: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._exposure_fusion_gap.fuse_exposures_gray8.

Fuse registered Gray8 exposures using a triangular saturation weight.

정렬된 Gray8 노출 영상을 포화 가중치로 융합합니다.

Python
fuse_exposures_gray8(images, exposures)

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • exposures · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

images
정렬된 Gray8 영상 2–256개입니다.
exposures
영상과 같은 개수의 유한한 양의 상대 노출값입니다.

반환: 호출자가 닫아야 하는 ExposureFusionResult입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    fuse_exposures_gray8은 정렬된 Gray8 노출 영상 2장부터 256장과 각 영상에 대응하는 양수 노출값을 받아 합성합니다. 입력과 노출 목록의 길이와 순서가 일치해야 합니다. 포화에 대한 삼각 가중치를 사용하므로 어두운 부분과 밝은 부분의 정보를 서로 다른 노출에서 활용하는 흐름에 적용할 수 있습니다.

    구체 사례와 판독

    예를 들어 첫 영상이 짧은 노출, 둘째 영상이 긴 노출이라면 exposures에도 같은 순서로 두 양수 값을 제공합니다. 순서를 바꾸면서 노출값만 원래 순서로 남기면 각 영상의 입력 조건이 잘못 연결됩니다. 카메라나 대상이 움직였다면 먼저 같은 좌표로 정렬해야 하며, 합성 결과가 실제 물리 단위의 절대 광량이라고 자동으로 가정하지 마세요.

    적용 시 확인

    촬영 중 대상이 움직이면 노출별 같은 위치가 같은 물체를 나타내지 않을 수 있습니다. 예를 들어 짧은 노출과 긴 노출 사이에 부품이 이동했다면 합성 전에 기하 정렬을 해야 합니다. 입력 노출이 0 또는 음수면 유효하지 않으며 노출 시간의 단위는 목록 전체에서 일관되게 사용해야 합니다. 모든 영상이 같은 픽셀 형식과 대응 영역을 갖는지도 확인합니다. 결과의 과노출 영역과 어두운 영역을 원본들과 나란히 비교하세요.
