Python API · IcpOptions

IcpOptions 멤버와 선언

공개 타입

zvision.IcpOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.IcpOptions.

Structure base class

점대점 ICP의 반복, 대응 거리와 정지 조건을 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

Python
IcpOptions(iterations, max_distance, trim_fraction=1.0, rms_tolerance=1e-08)

인자 선언

  • iterations · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_distance · POSITIONAL_OR_KEYWORD · 기본값 없음
  • trim_fraction · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • rms_tolerance · POSITIONAL_OR_KEYWORD · 기본값 1e-08

확인된 인자 조건

iterations
최대 ICP 반복 수, 양의 정수
max_distance
대응점 최대 거리, 점군 길이 단위의 유한 양수
trim_fraction
거리 선별 후 유지하는 대응점 비율, 유한한 (0,1]; 기본 1
rms_tolerance
RMS 변화의 종료 허용값, 점군 길이 단위의 유한한 0 이상; 기본 1e-8

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
