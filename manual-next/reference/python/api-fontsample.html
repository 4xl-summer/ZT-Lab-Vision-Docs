    사용과 결과 해석

    폰트 학습에 사용할 image, label, cell을 묶습니다. image는 ZImage이고 label은 해당 샘플의 문자이며 cell은 이미지 안의 (x, y, width, height) 사각형입니다. 샘플의 사각형이 실제 글자와 대응해야 학습된 템플릿도 의도한 형태를 나타냅니다.

    예를 들어 같은 숫자 3의 인쇄 모양이 두 가지라면 각각의 영상과 셀, 동일한 라벨을 가진 샘플로 표현할 수 있습니다. 셀에 이웃 문자의 일부나 넓은 배경이 섞이면 분할 및 학습 결과에 영향을 줄 수 있으므로 원본에 사각형을 그려 확인합니다.

    샘플은 이미지 객체를 참조하므로 학습 호출이 입력을 사용하는 동안 영상의 수명을 유지합니다. 학습 후 판독에서는 문자별 FontGlyph와 전체 FontRead의 수락 및 유사도를 확인합니다. 템플릿 점수는 확률이 아니라 형태 유사도로 해석합니다.

    원본 셀의 크기와 영상의 좌표계를 함께 보관하면 다른 이미지에서 샘플을 재구성할 수 있습니다. 학습 방식이 바뀌면 같은 샘플이라도 대표 템플릿을 사용하는 방식이 달라지므로 알고리즘도 기록합니다.

    셀 경계와 라벨이 같은 문자에 대응하는지 학습 전에 직접 확인합니다.
