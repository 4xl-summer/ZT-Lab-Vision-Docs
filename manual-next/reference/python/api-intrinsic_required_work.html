Python API · intrinsic_required_work

intrinsic_required_work 멤버와 선언

공개 타입

zvision.intrinsic_required_work: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.intrinsic_required_work.

Return the conservative projection-work limit for point count and iteration cap.

점 수와 반복 상한에 대한 보수적인 투영 작업량을 계산합니다.

Python
intrinsic_required_work(points, iterations)

인자 선언

  • points · POSITIONAL_OR_KEYWORD · 기본값 없음
  • iterations · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

points
양의 점 개수입니다.
iterations
양의 반복 상한입니다.

반환: 필요 작업량 정수입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    intrinsic_required_work는 관측점 수와 반복 상한을 받아 카메라 내부 파라미터 최적화에 필요한 보수적 투영 작업 한도를 정수로 계산합니다. 결과는 경과 시간이나 바이트 수가 아니라 해당 알고리즘의 작업 예산을 설정하는 데 쓰는 수치입니다. points와 iterations는 사용하려는 문제의 점 개수와 반복 한도에 맞춰 지정합니다.

    구체 사례와 판독

    예를 들어 같은 관측 자료에 대해 더 큰 반복 상한을 사용하려면 그 상한을 전달하여 필요한 한도를 다시 계산합니다. 이전 설정의 작업량 숫자를 변경된 자료에 그대로 적용하기보다 실제 점 수와 반복 수로 다시 산정하세요. 반환값을 IntrinsicOptions의 max_work와 비교하고 계산 후 종료 진단도 확인합니다.

    적용 시 확인

    보수적 한도는 최악을 고려한 작업량 설정을 돕는 값이므로 실제 수행한 반복 횟수나 소요 시간과 같다고 가정하지 마세요. 입력 관측점의 수를 세는 기준을 최적화 호출의 자료와 맞추고 옵션의 반복 한도도 동일하게 사용해야 계산 결과를 올바르게 해석할 수 있습니다. 예산이 충분하더라도 수렴 여부와 최종 재투영 잔차는 별도의 문제입니다. 최적화 결과의 진단을 반드시 확인하세요.
