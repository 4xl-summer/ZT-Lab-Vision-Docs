Python API · select_blob_features

select_blob_features 멤버와 선언

공개 타입

zvision.select_blob_features: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_feature_select.select_blob_features.

Return original indices matching all or any inclusive feature ranges.

포함 범위 조건의 전체 또는 일부를 만족하는 Blob을 선택합니다.

Python
select_blob_features(source, criteria, match_all, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • criteria · POSITIONAL_OR_KEYWORD · 기본값 없음
  • match_all · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
열린 BlobResult입니다.
criteria
1..64개 BlobFeatureRange이며 각 ID는 0..29입니다.
match_all
True면 모든 조건, False면 하나 이상의 조건을 요구합니다.
work_budget
양의 작업 상한입니다.

반환: 선택된 원본 0 기반 인덱스의 튜플입니다.

오류: 잘못된 범위, 타입 또는 작업 한도 위반은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
