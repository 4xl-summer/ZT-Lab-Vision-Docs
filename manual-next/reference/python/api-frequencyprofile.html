사용과 결과 해석

주파수 필터가 차단 주파수 부근에서 어떤 형태로 응답하는지 지정하는 열거형입니다. IDEAL, GAUSSIAN, BUTTERWORTH는 같은 차단 위치를 선택해도 경계 부근의 가중치 변화가 다른 프로파일을 뜻합니다. 이 값은 영상의 공간 좌표나 변환의 정규화 방식이 아니라 필터 마스크를 구성할 때 선택하는 형태입니다. 예를 들어 동일한 입력과 차단 주파수에서 프로파일만 바꾸어 마스크와 역변환 영상을 비교하면 전이 형태에 따른 차이를 관찰할 수 있습니다. 같은 비교에서 영상 크기, 변환 크기, 정규화 및 주파수 배열의 배치를 함께 고정해야 다른 설정이 만든 차이를 프로파일 효과로 잘못 돌리지 않습니다. 표시를 위해 스펙트럼을 이동한 배열과 실제 계산에 쓰는 배열의 위치도 구별하십시오. 실수부와 허수부의 복소 계수에 필터를 적용한 뒤 역변환해야 하며 표시용 진폭 영상은 복소 계수 전체가 아닙니다. 각 프로파일의 구체적인 인자와 지원 범위는 사용하는 필터 호출의 계약을 확인해야 합니다. 결과의 좋고 나쁨은 대상 패턴과 사용 목적에 따라 달라지므로 어느 한 형태를 항상 정답으로 가정하지 마십시오. 예제 입력이 일정한 영상이면 DC 성분을 쉽게 확인할 수 있지만 특정 방향 성분을 선택하는 효과까지 충분히 살피지는 못합니다. 검증할 신호에 맞는 별도의 패턴을 준비하십시오.
