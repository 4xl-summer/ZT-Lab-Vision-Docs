    필드타입기본값의미와 조건
    matrixtuple필수관측=matrix×명령+offset의 행 우선 3×3 계수 튜플. 입력 각도는 언랩된 라디안.
    offsettuple필수관측 x, y, theta 순서의 오프셋.
    rmstuple필수각 출력 축 x, y, theta의 잔차 RMS 튜플.
    maximumtuple필수각 출력 축의 최대 절대 잔차 튜플.
    x_scalefloat필수명령 x열의 평면 x,y 성분 노름.
    y_scalefloat필수명령 y열의 평면 x,y 성분 노름.
    theta_scalefloat필수명령 theta가 관측 theta에 기여하는 matrix[2,2].
    skew_radiansfloat필수정규화된 두 평면 축에 대해 atan2(내적, 행렬식)으로 계산한 라디안 값.
    unitobject필수평면 x,y 거리의 길이 단위; theta는 라디안.
    countint필수평가한 포즈 쌍 수.
