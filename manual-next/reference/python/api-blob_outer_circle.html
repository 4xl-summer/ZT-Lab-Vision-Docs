blob_outer_circle 멤버와 선언

공개 타입

zvision.blob_outer_circle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_outer_circle.blob_outer_circle.

Return the enclosing circle of a selected Blob's cell-corner hull.

선택 Blob의 픽셀 셀 꼭짓점 껍질을 감싸는 원을 구합니다.

Python
blob_outer_circle(source, index, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • index · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
입력 BlobResult
index
0 기반 영역 인덱스
work_budget
양의 정수 작업량 상한

반환: BlobOuterCircle 값

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    셀을 감싸는 원 계산

    blob_outer_circle은 선택한 Blob의 픽셀 셀 꼭짓점 볼록껍질을 감싸는 원을 구합니다. 영역의 중심만 보거나 외접 사각형의 대각선을 이용한 근사와는 다른 측정입니다. 결과에는 ROI 로컬 중심과 픽셀 단위 반지름이 들어 있습니다.

    성분 선택

    source는 입력 BlobResult이고 index는 선택할 0 기반 영역 인덱스입니다. 예를 들어 첫 성분은 인덱스 0으로 선택합니다. 성분 순서는 특정 분석 결과의 순서이므로 다른 프레임의 같은 번호가 동일한 물체를 가리킨다고 가정하지 않습니다. 양의 work_budget도 지정합니다.

    결과 판독

    원은 선택된 전경 셀의 꼭짓점 껍질을 감싸므로 원 안에 배경이 포함될 수 있습니다. 내부 구멍이 있는 물체에서 원의 면적을 전경 면적과 같다고 해석하면 안 됩니다. 원본 마스크 위에 결과를 겹쳐 실제 선택한 영역과 좌표 기준을 확인합니다.

    좌표와 단위

    출력 중심은 ROI 로컬이므로 전체 영상으로 옮길 때 ROI 원점을 더합니다. 반지름은 픽셀 좌표 기준의 길이이며 물리 길이와 비교하려면 보정과 축 간격을 따로 확인합니다.

    원의 중심이 물체의 전경 픽셀에 반드시 놓인다고 가정하지 않습니다. 오목한 물체나 구멍이 있는 물체에서는 중심 위치에 배경이 있을 수도 있습니다.
