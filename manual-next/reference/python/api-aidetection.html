    사용과 결과 해석

    AiDetection은 검출 상자의 x_min, y_min, x_max, y_max와 score, class_id를 담는 불변 값입니다. 좌표는 입력 영상 좌표계의 반열린 픽셀 경계입니다. 예를 들어 x_min=2, x_max=7이면 가로 경계 폭은 5이며 x_max에 1을 더해 면적을 계산하지 않습니다.

    검출 상자를 표시할 때 사용한 입력 영역과 전처리 변환을 함께 확인합니다. decode_boxes는 전처리 변환을 사용해 영상 좌표의 결과로 복원하므로 변환된 좌표에 패딩이나 원점 이동을 다시 적용하면 상자가 틀어집니다. 표시 도구가 정수 포함 끝점을 요구한다면 그 도구의 규칙에 맞춰 명시적으로 변환합니다.

    score와 class_id는 모델 및 후처리 설정에 의존합니다. 점수 임계값과 중복 제거를 바꾸면 결과 개수가 달라지며, 감지 목록이 비어 있는 일과 호출 오류는 다릅니다. 객체는 값 스냅샷으로 영상이나 엔진 핸들을 소유하지 않습니다.

    예를 들어 y_min=4, y_max=10이면 세로 경계 폭은 6입니다. 해당 상자가 어느 프레임에서 나왔는지 식별자를 보관하면 다른 영상에 잘못 겹쳐 그리는 일을 줄일 수 있습니다.
