    사용과 결과 해석

    선형 sRGB에 적용하는 3×3 행렬과 세 채널의 편향을 담는 보정 값입니다. matrix는 행 우선 순서의 계수 9개, bias는 RGB 순서의 값 3개입니다. Python 생성 시 각 시퀀스의 길이를 확인하고 튜플로 보관하므로 나중에 원래 시퀀스를 바꾸더라도 그 값 객체를 변경하는 방식으로 사용하지 않습니다. 실제 연산에서는 계수의 유효성도 확인됩니다.

    입력은 인코딩된 RGB로 저장되어 있어도 보정은 선형 sRGB에서 affine 변환을 적용한 뒤 출력 색역에 맞추어 처리합니다. 따라서 이 행렬을 이미지 바이트에 바로 곱하는 것으로 동작을 대체하면 안 됩니다. 알파가 있는 지원 영상에서는 알파를 보존합니다. 보정 결과는 원본이 아닌 새 소유 영상이므로 사용 후 닫아야 합니다.

    계수를 직접 알고 있다면 ColorCorrection을 만들고, 측정한 색 패치와 목표 패치를 가지고 있다면 피팅 API로 보정을 구할 수 있습니다. 피팅에는 최소 네 개의 선형 독립 패치가 필요합니다. 결과의 보정 전후 색차를 확인해 모델이 입력 패치에 미친 영향을 살펴보되 그 수치가 다른 조명이나 소재에서의 성능을 보증한다고 해석하지 않습니다.

    패치 수가 충분한지와 계수가 유한한지 먼저 확인한 다음 결과를 별도의 검증 데이터와 비교합니다.
