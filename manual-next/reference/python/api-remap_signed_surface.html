Python API · remap_signed_surface

remap_signed_surface 멤버와 선언

공개 타입

zvision.remap_signed_surface: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_surface_remap.remap_signed_surface.

Return (owned Gray8/Gray16 image, applied factor); None selects automatic scaling.

부호 있는 표면 데이터를 표시 밝기로 변환합니다.

Python
remap_signed_surface(image, mask, max_work, factor=None, depth=8)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_work · POSITIONAL_OR_KEYWORD · 기본값 없음
  • factor · POSITIONAL_OR_KEYWORD · 기본값 None
  • depth · POSITIONAL_OR_KEYWORD · 기본값 8

확인된 인자 조건

image
GrayF32 부호 표면 영상.
mask
같은 기하의 Gray8 유효 마스크; 하나 이상 비제로.
max_work
양의 작업 상한.
factor
유한한 양의 배율 또는 None의 자동 배율.
depth
출력 비트 깊이 8 또는 16, 기본 8.

반환: 독립 소유 Gray8/Gray16 영상과 적용 배율의 튜플; 영상은 close합니다.

오류: 유효하지 않은 인자 또는 작업 한도 초과 시 오류입니다.

max_work: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
