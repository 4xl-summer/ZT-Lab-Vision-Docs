열거 값

  • SRGB = 0 · 값 0. 입력 RGB에 sRGB 역전달 함수를 적용합니다.
  • LINEAR = 1 · 값 1. 입력 RGB를 이미 선형인 값으로 사용합니다.
  • GAMMA = 2 · 값 2. 입력 RGB의 각 정규화 값에 지정한 양의 감마 지수를 적용합니다.

사용과 결과 해석

RGB에서 고급 Lab 또는 LCH 공간으로 변환할 때 입력 전달 함수를 선택합니다. SRGB=0, LINEAR=1, GAMMA=2이며 convert_advanced의 기본은 SRGB입니다. GAMMA를 사용할 때 전달하는 gamma의 기본값은 2.2입니다. 선택한 함수는 입력 채널을 해석하는 과정에 영향을 주므로 출력값과 함께 기록합니다.

예를 들어 카메라가 이미 선형화한 채널을 제공하는지, sRGB처럼 인코딩된 채널인지 확인해야 합니다. 같은 숫자라도 선형 값과 인코딩 값은 물리적인 빛의 크기로 읽는 방법이 다릅니다. 출처가 다른 영상의 숫자만 비교하면 변환 차이를 실제 색 차이로 오해할 수 있습니다.

전달 함수는 백색점 D50 또는 D65와 별개의 옵션이며 출력 LAB 또는 LCH도 따로 선택합니다. 반환된 채널은 원본 입력 핸들과 별도 소유 자원입니다. 유형이나 형식이 잘못된 입력으로 오류가 나면 값이 0인 색상으로 처리하지 않습니다.

GAMMA를 지정할 때 사용하는 값은 변환 호출에 전달한 gamma입니다. 입력 데이터가 선형인지 확인할 수 없으면 출력의 수치만으로 원래 전달 함수를 역으로 단정할 수 없습니다.

동일한 입력과 설정으로 변환을 재현할 수 있도록 기록합니다.
