선형 sRGB affine 보정을 정규화 색 패치에서 피팅합니다.

fit_color_correction(patches)

인자 선언

  • patches · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

patches
최소 4개의 선형 독립 ColorPatch 시퀀스. 각 입력·기준 RGB는 정규화 인코딩 sRGB입니다.

반환: 호출자가 close할 ColorFitResult 소유 객체.

오류: 패치 부족, 랭크 부족 또는 유효하지 않은 색 값은 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    대응하는 측정 색과 목표 색 패치로 선형 RGB affine 보정 모델을 구합니다. patches에는 ColorPatch 시퀀스를 전달하며 각 source와 reference는 정규화 인코딩 sRGB 세 채널입니다. 피팅에는 최소 네 개의 선형 독립 패치가 필요합니다. 패치 수만 네 개 이상이고 색의 정보가 서로 종속되어 있으면 안정적인 모델을 만들 수 없으므로 입력 구성과 오류를 함께 확인해야 합니다.

    함수는 보정 행렬·편향과 학습 패치의 색차 통계를 소유한 결과를 반환합니다. Python에서는 결과 객체를 사용한 후 close해야 하며, 패치별 잔차는 복사된 값으로 읽습니다. 구한 보정은 별도의 색 영상 처리 호출에서 적용하고 새 영상의 소유권도 관리합니다. 훈련 데이터에서의 평균 또는 최대 CIE76 잔차는 모델이 그 패치에 얼마나 맞았는지를 보여 줍니다.

    패치 순서가 바뀌면 개별 잔차의 index가 가리키는 대상도 바뀝니다. 소스와 목표가 같은 실제 패치를 나타내도록 짝을 유지하고 적용할 입력의 색 표현과 채널 순서도 맞춰야 합니다. 학습 패치에서 성공한 결과만으로 다른 조명, 소재 또는 생산 설비의 색 정확도를 보증하지 않습니다.
