    사용 맥락과 계약

    RobotWorldResult는 AX=ZB 형태의 로봇·월드 보정에서 추정한 두 강체 변환과 진단을 담습니다. x는 카메라에서 H로, z는 Q에서 P로 가는 변환이며 hypotheses는 평가한 후보 수입니다. exhausted는 후보 검색의 종료 상황을 나타내고 residuals는 입력 방정식별 오차를 제공합니다. 각 변환의 출발·도착 프레임을 기록해 적용 방향을 구분해야 합니다.

    구체 사례와 판독

    예를 들어 A·X와 Z·B는 같은 출발 프레임에서 같은 도착 프레임으로 가는 결과여야 비교할 수 있습니다. 이 두 경로의 회전과 이동 잔차를 입력 자세별로 확인하면 잘못 대응한 관측을 찾는 데 도움이 됩니다. 작은 전체 오차만으로 모든 자세에서 측정이 정확하다고 단정하지 말고 보류한 자세로 검증하세요.

    적용 시 확인

    x와 z는 서로 다른 프레임을 잇기 때문에 숫자 배열이 모두 4×4 형태라고 하여 서로 바꾸어 적용할 수 없습니다. 문제 설정에서 H, C, P, Q가 어떤 장치를 가리키는지 적고 길이 단위를 통일하세요. 회전 잔차는 라디안, 이동 잔차는 입력의 길이 단위로 해석합니다. 후보 제한에 이른 경우 진단을 함께 확인합니다. 동일한 프레임의 점으로 두 경로의 결과를 비교해 보세요.
