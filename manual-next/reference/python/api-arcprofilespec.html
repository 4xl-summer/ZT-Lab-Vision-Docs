공개 타입

zvision.ArcProfileSpec: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._arc_profile.ArcProfileSpec.

Center, radius, radial half-width (pixels), start/extent (radians), counts and interpolation.

Positive angle runs clockwise in the image's y-down coordinates. Partial arcs
include both endpoints; a full turn omits the duplicate endpoint. Interpolation
is 0 nearest or 1 bilinear, and every sampled point must be in the ROI.
