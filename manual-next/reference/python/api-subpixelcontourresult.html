사용과 결과 해석

등값 경로를 픽셀 중심 사이에서 보간한 SubpixelContour들의 독립 튜플입니다. 각 점은 ROI 로컬 픽셀 좌표이며 정수 셀 경계만 사용하는 윤곽과 표현 방식이 다릅니다. 부분 픽셀 숫자가 들어 있다고 해서 입력 자체의 광학 정밀도가 자동으로 그만큼 높아지는 것은 아닙니다.

예를 들어 이웃 픽셀의 값이 지정한 등값 양쪽에 있다면 경로의 교차 위치를 그 사이에서 보간합니다. 등값을 바꾸면 같은 영상에서도 경로가 달라지므로 비교 시 입력 형식과 임계값을 함께 유지해야 합니다.

좌표를 전체 이미지나 물리 좌표와 결합하려면 ROI 원점과 보정을 적용합니다. 마스크, 경계 및 영상 잡음이 경로에 미치는 영향을 별도로 살펴보고, 숫자의 소수 자릿수만으로 실장비의 치수 정확도를 주장하지 마십시오.
