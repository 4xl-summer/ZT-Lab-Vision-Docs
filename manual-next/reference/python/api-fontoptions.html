데이터 필드

필드타입기본값의미와 조건
allowed_charsstr필수인식에서 허용할 비어 있지 않은 문자 집합입니다.
thresholdint127이진화 문턱값으로 0~255입니다. 지정값도 전경 판정에 포함합니다.
light_textboolFalseTrue면 문턱값 이상의 밝은 픽셀을 글자로 취급합니다.
closing_radiusint0정사각형 닫기 반경(픽셀)입니다. 0이면 사용하지 않고 최대 8입니다.
min_widthint1허용하는 글자 영역의 최소 너비(픽셀)로 1 이상입니다.
max_widthint4096허용하는 글자 영역의 최대 너비(픽셀)이며 최소 너비 이상입니다.
min_heightint1허용하는 글자 영역의 최소 높이(픽셀)로 1 이상입니다.
max_heightint4096허용하는 글자 영역의 최대 높이(픽셀)이며 최소 높이 이상입니다.
split_touchingboolFalse너비가 큰 연결 요소를 내부의 가장 빈 열에서 나눌지 정합니다.
min_glyph_scorefloat0.0개별 글자 유사도의 수락 하한으로 0~1입니다.
min_string_scorefloat0.0문자열 유사도의 수락 하한으로 0~1입니다.
position_charstuple[str, ...]<builtins.tuple>문자 위치별 허용 집합입니다. 빈 튜플은 위치 제한을 끕니다.
