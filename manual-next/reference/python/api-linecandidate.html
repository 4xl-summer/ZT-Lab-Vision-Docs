    필드타입기본값의미와 조건
    probe_indexint필수해당 피크를 얻은 탐침의 인덱스입니다.
    positionzvision._regions.Point2필수피크의 ROI 로컬 위치입니다.
    distancefloat필수탐침 프로파일 시작점에서 피크까지 거리(픽셀)입니다.
    strengthfloat필수검출된 에지의 부호 있는 기울기 강도입니다.
    classificationLineCandidateClass필수인라이어, 고려된 이상치 또는 고려되지 않은 이상치 구분입니다.
    reasonLineCandidateReason필수해당 처리 단계 분류의 이유입니다.
    line_indexint | None필수할당된 선 인덱스이며 할당되지 않으면 None입니다.

    사용과 결과 해석

    직선 탐침에서 추출한 하나의 피크와 그 피크가 적합 단계에서 받은 분류를 담습니다. probe_index는 원래 탐침의 인덱스이고 position은 현재 ROI의 로컬 좌표입니다. distance와 strength는 탐침을 따른 검출 위치와 에지 강도를 나타내므로 위치를 월드 좌표로 사용할 때는 별도 좌표 변환이 필요합니다.

    classification은 내점, 실제로 고려된 외점, 적합에 고려되지 않은 외점을 구별하며 reason은 그 단계의 이유를 나타냅니다. line_index는 후보가 선에 연결된 경우의 선택적 인덱스이므로 None을 0번 선으로 해석하지 마십시오. 예를 들어 극성에서 제외된 후보와 적합 후 거절된 후보는 둘 다 배정되지 않을 수 있지만 처리 경로가 다릅니다.

    반환 목록에는 추출 문턱을 넘은 피크가 담기며 영상 속 모든 가능한 에지가 포함된다는 뜻은 아닙니다. 선 검색 개수 제한이나 적합 실패도 reason으로 구분할 수 있습니다. 결과는 복사된 값이므로 입력 영상 해제와 별개로 보관할 수 있지만, 물리적 허용값 판정은 호출자가 좌표와 단위를 맞춘 뒤 수행해야 합니다.
