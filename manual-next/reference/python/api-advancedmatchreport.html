    사용 맥락과 결과 해석

    확장 검색의 후보 튜플과 평가한 포즈 수, 종료 이유를 함께 담는 독립 스냅샷입니다. 후보가 없더라도 보고서는 존재할 수 있으며 matches가 빈 튜플이라는 사실과 termination이 전체 완료인지 예산·시간·확실도에 의한 종료인지는 각각 확인합니다. 입력 영상이나 모델을 닫은 후에도 이미 복사된 값은 읽을 수 있습니다.

    예를 들어 평가 수가 후보 예산과 같고 종료 이유가 예산이라면 검색 공간의 나머지가 시험되지 않았을 수 있습니다. 조기 점수 종료 역시 가장 먼저 기준을 만족한 후보 이후의 공간을 완전히 조사했다는 뜻이 아닙니다. 각 매치의 로컬·전역 기준점, 각도와 축별 배율을 검사하고 점수만으로 실제 위치나 물체 수를 대신하지 않습니다.

    값을 확인하는 순서

    matches 항목: 복사된 불변 매치 튜플입니다. 후보가 없으면 비어 있습니다. evaluated 항목: 평가한 포즈 수입니다. termination 항목: 전체 완료, 후보 예산, 시간 제한, 조기 점수 중 검색 종료 원인입니다.
