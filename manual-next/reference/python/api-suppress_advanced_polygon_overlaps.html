suppress_advanced_polygon_overlaps 멤버와 선언

공개 타입

zvision.suppress_advanced_polygon_overlaps: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._matching_advanced.suppress_advanced_polygon_overlaps.

변환된 템플릿 다각형의 겹침을 사용해 후보를 억제합니다.

Python
suppress_advanced_polygon_overlaps(model, matches, max_iou, limit)

인자 선언

  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • matches · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_iou · POSITIONAL_OR_KEYWORD · 기본값 없음
  • limit · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

model
NCC AdvancedMatchModel입니다.
matches
억제할 AdvancedMatch 값들의 시퀀스입니다.
max_iou
허용할 최대 겹침 IoU로 0..1입니다.
limit
유지할 최대 후보 수인 양의 정수입니다.

반환: 남은 후보의 독립 불변 튜플입니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

limit: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    NCC 모델과 매치 시퀀스를 사용해 변환된 템플릿 다각형의 교집합 비율을 기준으로 중복 후보를 억제합니다. max_iou는 0..1의 한계이고 limit은 양의 최대 반환 개수입니다. 높은 점수의 후보부터 남기므로 각 후보의 점수와 변환 포즈가 올바른 모델에서 생성되었는지 확인해야 합니다.

    기울어진 후보의 실제 다각형을 비교하므로 축 정렬 경계상자를 이용하는 suppress_advanced_matches와 겹침 판단이 다를 수 있습니다. 같은 물체에서 나온 중복은 줄일 수 있지만 실제 물체가 서로 겹치는 장면에서는 유효한 하나가 제외될 수도 있습니다. 반환 튜플은 입력 후보에서 선택한 독립 결과이며 잘못된 모델 종류나 범위는 오류로 처리합니다.

    값을 확인하는 순서

    model 항목: NCC AdvancedMatchModel입니다. matches 항목: 억제할 AdvancedMatch 값들의 시퀀스입니다. max_iou 항목: 허용할 최대 겹침 IoU로 0..1입니다. limit 항목: 유지할 최대 후보 수인 양의 정수입니다.

    항목읽을 때 확인할 내용
    modelNCC AdvancedMatchModel입니다.

    limit유지할 최대 후보 수인 양의 정수입니다.
