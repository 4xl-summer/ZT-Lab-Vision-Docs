Python API · FuzzyOptions

FuzzyOptions 멤버와 선언

공개 타입

zvision.FuzzyOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._fuzzy_caliper.FuzzyOptions.

Pair mode, directional polarities, conservative candidate/work limits and result threshold.

In single mode both polarities must be zero. In pair mode polarities are 1 rising,
2 falling or 3 either, relative to probe travel. `max_candidates` must equal the
caliper maximum and be at least profile sample count. Work is bounded by 262144.

Python
FuzzyOptions(pair: bool, first_polarity: int, second_polarity: int, max_candidates: int, max_work: int, max_results: int, threshold: float) -> None
