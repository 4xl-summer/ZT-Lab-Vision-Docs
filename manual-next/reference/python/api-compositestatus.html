열거 값

  • PASS = 0 · 공차를 통과한 상태.

  • NOT_EVALUATED = 2 · 판정되지 않은 상태.

사용과 결과 해석

복합 계측의 허용치 판정 상태를 PASS, FAIL, NOT_EVALUATED로 표현합니다. PASS는 평가한 기준을 충족한 경우, FAIL은 평가한 기준을 충족하지 못한 경우, NOT_EVALUATED는 해당 판정이 이루어지지 않은 경우를 구분하는 데 사용합니다. 예를 들어 검출 실패로 필요한 측정값이 없다면 결과가 정상 범위에 들어 합격한 것으로 간주해서는 안 됩니다. 값이 없거나 평가되지 않은 상태는 수치 0이나 실패로 무조건 치환하지 말고 원래 상태를 보존해야 합니다. 개별 허용치의 결과와 전체 복합 결과는 각각의 상태를 가질 수 있으므로 전체 상태만 표시하면 어느 항목에서 판정이 불가능했는지 놓칠 수 있습니다. 보고서에는 해당 허용치의 식별자, 실제 측정값이 있는지, 상태와 단위를 함께 기록하십시오. 같은 결과라도 허용치 설정이 달라지면 판정이 달라질 수 있으며 상태 하나만으로 사용된 한계값이나 측정 기하를 복원할 수 없습니다. 판단 규칙을 재현하려면 입력 형상과 설정, 각 결과를 함께 보존합니다. 여러 프레임의 합격률을 계산할 때도 미평가를 분모에서 어떻게 다룰지 명시해야 합니다. 미평가의 수를 따로 표시하면 장비가 충분히 관측하지 못한 상황을 성공률에 숨기지 않을 수 있습니다.
