공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    trained_countint필수평균에 포함된 학습 프로브 수.
    mean_widthfloat필수포함된 학습 폭의 산술 평균; 픽셀.
    acceptedbool필수활성화된 nominal×scale 하한과 상한을 평균이 모두 만족하는지 여부; 경계 포함.

    사용과 결과 해석

    학습된 비드 폭의 평균이 명목 폭에 대한 활성 경계 안에 드는지 보여 줍니다. trained_count는 평균에 포함된 탐침 수, mean_width는 해당 폭의 산술 평균으로 픽셀 단위입니다. accepted는 활성화한 하한과 상한을 모두 만족했는지 나타냅니다.

    명목 폭이 10픽셀이고 최소 배율이 0.8, 최대 배율이 1.2라면 활성 범위는 8~12픽셀입니다. 평균이 경계와 같아도 통과합니다. 하한 또는 상한은 각각 생략할 수 있으므로 두 경계가 모두 사용되었다고 결과만 보고 추론하지 마십시오.

    평균은 개별 탐침의 폭 분포나 최악의 좁은 구간을 모두 보여 주지 않습니다. 학습에 포함된 탐침 수와 제외 조건을 확인하고, 경로별 편차나 실제 생산 공차는 별도 품질 검사와 보정을 통해 평가하십시오.
