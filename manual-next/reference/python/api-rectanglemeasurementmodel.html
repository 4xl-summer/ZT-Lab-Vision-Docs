RectangleMeasurementModel 멤버와 선언

공개 타입

zvision.RectangleMeasurementModel: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_models.RectangleMeasurementModel.

Validated rectangle probe configuration without a native lifetime.

사각형 측정을 위한 검증된 불변 설정 객체를 직접 생성합니다. 설정은 스냅샷으로 보관하며 객체 자체는 닫아야 할 네이티브 핸들을 소유하지 않습니다. 생성 후 measure(image)를 호출합니다. 세 인자는 모두 필수이며 타입이나 값이 유효하지 않으면 생성 시 예외가 발생합니다.

Python
RectangleMeasurementModel(spec, probes, robust)

인자 선언

  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음
  • probes · POSITIONAL_OR_KEYWORD · 기본값 없음
  • robust · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

spec
RectangleShape 값입니다. ROI 로컬 픽셀의 예상 중심·반축과 라디안 각도를 지정합니다.
probes
ShapeProbeOptions 값으로 에지 탐침 위치, 프로파일과 선택 조건을 지정합니다. 사각형의 탐침 수는 각 면에 적용됩니다.
robust
RobustFitOptions 값으로 강건 손실과 적합 반복·수렴 조건을 지정합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

확인된 인자 조건

image
측정할 영상입니다.

반환: 사각형 측정 상태, 선택적 적합과 탐침 진단을 담은 독립 불변 결과입니다.

오류: 입력 오류는 예외이며, 측정 상태가 성공이 아니면 fit은 None입니다.
