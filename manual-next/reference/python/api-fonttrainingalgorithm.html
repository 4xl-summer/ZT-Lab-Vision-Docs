열거 값

  • NEAREST_EXAMPLE = 1 · 값 1. 각 학습 예제를 저장하고 가장 유사한 예제로 글자를 분류합니다.
  • CLASS_MEAN = 2 · 값 2. 같은 라벨의 학습 특징을 평균한 대표값으로 글자를 분류합니다.

사용과 결과 해석

폰트 템플릿 학습 방식을 지정합니다. NEAREST_EXAMPLE=1은 예제 중 가까운 것을 활용하고 CLASS_MEAN=2는 클래스별 평균을 사용하는 선택입니다. 문자별 입력 FontSample의 라벨과 영상 셀을 함께 제공해야 어느 문자의 형태인지 구분할 수 있습니다.

두 방식은 같은 샘플을 사용해도 문자 형태 변형에 서로 다르게 반응할 수 있습니다. 예를 들어 숫자 8에 여러 필체가 있으면 각 예제와 대표 형태를 사용하는 차이를 별도 시험 영상에서 비교합니다. FontGlyph의 score는 이진 템플릿 유사도이며 확률로 보정된 신뢰도가 아닙니다.

학습과 시험에 동일 이미지만 사용하면 현장의 인쇄 편차를 확인하기 어렵습니다. 문자 영역 분할, 입력 조명과 임계값, 허용 문자 및 점수 한도를 함께 기록하고 별도 입력에서 문자열과 문자별 수락 여부를 살펴봅니다. 값이 유효하지 않은 경우 빈 모델로 대체하지 않습니다.

학습 샘플 수나 대표 형태만으로 미지의 글자에 대한 정확도를 수치화할 수 없습니다. 현장에 예상되는 크기와 인쇄 편차가 있는 독립 샘플에서 분할부터 판독까지 별도로 평가합니다.

라벨 오기가 학습에 반영되지 않도록 샘플을 먼저 검토합니다.
