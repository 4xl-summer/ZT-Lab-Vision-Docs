사용과 결과 해석

ColorFitResult는 fit_color_correction에 색 패치 쌍을 전달해 얻는 소유 결과입니다. 직접 생성자는 사용하지 않습니다. 패치마다 측정한 source RGB와 목표 reference RGB를 짝지으며, 계산된 보정은 세 채널의 3×3 행렬과 편향을 가진 ColorCorrection입니다. 예를 들어 실제 회색 패치가 목표보다 한 채널에서 높으면 여러 패치의 대응 관계를 이용해 보정 계수를 추정합니다.

info는 보정 행렬과 편향, 패치 수, 보정 전후 색차의 평균·RMS·최대를 값으로 돌려줍니다. 평균이 낮아져도 최대 오차가 큰 패치가 남을 수 있으므로 두 수치를 함께 살펴봅니다. residuals는 각 패치 인덱스와 전후 색차의 튜플을 복사하므로 어떤 샘플의 오차가 개선 또는 악화됐는지 비교할 수 있습니다.

결과 핸들은 사용 후 close합니다. 이미 읽어 복사한 info와 residuals는 결과의 핸들 그 자체가 아닙니다. 보정 학습에 사용된 패치의 결과만으로 새로운 조명과 재질의 정확성을 보장할 수 없으므로, 별도의 확인 패치에서도 보정 전후 색차를 검토합니다.

각 패치의 인덱스를 입력 순서와 연결해 확인합니다.
