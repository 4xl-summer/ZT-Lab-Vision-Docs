    사용 맥락과 결과 해석

    원근 NCC 검색의 한 후보로, 기본 AdvancedMatch와 두 원근 분모 계수를 함께 담습니다. 기본 매치에서 검색 기준점, 각도, 축별 배율과 점수, 커버리지를 읽고 perspective_x와 perspective_y는 그 포즈에 추가된 원근 성분으로 해석합니다. 단순 회전·배율 결과만으로 원근 효과를 표현했다고 가정하지 않습니다.

    사용자는 별도 두 원근 축의 격자를 설정해 검색합니다. 예산이 제한되어 있다면 모든 원근 조합을 평가하지 못할 수 있으므로 이 후보가 들어 있는 보고서의 evaluated와 termination도 같이 확인합니다. 기준점은 검색 영상의 로컬 좌표와 원점이 반영된 전역 좌표를 구분해야 합니다. 점수는 매치의 유사도이며 보정된 카메라 위치나 물리적 거리 자체가 아닙니다.
