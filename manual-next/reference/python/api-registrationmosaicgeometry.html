    사용과 결과 해석

    정합된 영상들을 출력할 공통 캔버스의 크기와 원점을 나타냅니다. width와 height는 출력 픽셀 수이고 origin_x, origin_y는 출력 (0,0)에 대응하는 공통 좌표계의 위치입니다. scale은 공통 좌표 단위당 출력 픽셀 배율입니다.

    캔버스 위치 (x,y)는 공통 좌표 (origin_x+x/scale, origin_y+y/scale)에 대응합니다. 예를 들어 원점이 (10,20), scale이 2이고 출력 좌표가 (4,6)이면 공통 좌표는 (12,23)입니다. 이 계산은 캔버스 좌표와 입력 영상의 로컬 좌표가 동일하다는 뜻은 아닙니다.

    모자이크를 실제로 렌더할 때는 각 입력 영상의 변환과 겹침 정책, 유효 마스크도 필요합니다. 크기와 원점 메타데이터만으로 픽셀 값이나 유효 영역을 알 수 없으며, 잘못된 배율 또는 좌표계를 사용하면 캔버스가 물체를 잘라낼 수 있습니다.
