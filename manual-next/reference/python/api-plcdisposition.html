열거 값

  • APPLIED = 1 · 명령이 적용되었습니다.
  • DUPLICATE = 2 · 중복 명령으로 처리되었습니다.
  • NO_CHANGE = 3 · 상태가 변경되지 않았습니다.
  • TIMED_OUT = 4 · 요청 시간이 초과되었습니다.

사용 맥락과 계약

PlcDisposition은 모의 PLC 명령의 처리 결과를 구분합니다. APPLIED는 상태에 반영된 명령, DUPLICATE는 중복으로 인식된 명령, NO_CHANGE는 상태가 바뀌지 않은 확인, TIMED_OUT은 제한 시간을 초과한 경우입니다. 오류로 거부된 잘못된 인자나 상태 전이와 이 정상 반환 상태를 한 가지 결과로 합쳐서는 안 됩니다.

구체 사례와 판독

예를 들어 REQUEST, PUBLISH, ACK가 각각 적용되면 통계의 요청·게시·확인 수가 달라집니다. 반면 같은 요청을 반복했을 때는 DUPLICATE가 나올 수 있으며 새로운 작업이 한 건 더 완료된 것으로 세면 안 됩니다. POLL은 전달한 now_ns를 기준으로 시간 초과를 확인합니다. 로그에 operation, request_id, 반환 상태와 현재 PlcInfo를 함께 남기면 중복과 순서 오류를 구별하기 쉽습니다.

적용 시 확인

반환값이 DUPLICATE라면 요청 ID와 이전 상태를 보고 재시도가 감지된 것인지 확인합니다. TIMED_OUT 이후에는 오류 상태에서 복구하는 명령 흐름을 따르며, 단순 재전송을 새 정상 요청으로 세지 않습니다. 상태가 바뀌지 않은 결과도 정상 반환일 수 있으므로 예외로 치환하지 마세요.
