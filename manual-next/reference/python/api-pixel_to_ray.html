Python API · pixel_to_ray

pixel_to_ray 멤버와 선언

공개 타입

zvision.pixel_to_ray: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.pixel_to_ray.

Invert a distorted global pixel locally; check converged before using its direction.

왜곡된 전역 픽셀에서 카메라 광선을 국소 역산합니다.

Python
pixel_to_ray(lens, pixel, options)

인자 선언

  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

lens
LensModel입니다.
pixel
전역 픽셀 Point2입니다.
options
역산 반복과 허용 오차를 담은 RayOptions입니다.

반환: 방향과 수렴 진단을 담은 RayResult입니다. 방향 사용 전 converged를 확인합니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
