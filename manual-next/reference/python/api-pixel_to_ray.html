pixel_to_ray 멤버와 선언

공개 타입

zvision.pixel_to_ray: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.pixel_to_ray.

Invert a distorted global pixel locally; check converged before using its direction.

왜곡된 전역 픽셀에서 카메라 광선을 국소 역산합니다.

Python
pixel_to_ray(lens, pixel, options)

인자 선언

  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

lens
LensModel입니다.
pixel
전역 픽셀 Point2입니다.
options
역산 반복과 허용 오차를 담은 RayOptions입니다.

반환: 방향과 수렴 진단을 담은 RayResult입니다. 방향 사용 전 converged를 확인합니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    pixel_to_ray는 렌즈 모델과 영상의 픽셀 좌표를 받아 카메라 좌표계의 광선 방향을 계산합니다. 왜곡을 포함한 모델에서는 역변환 반복이 필요하므로 RayOptions를 전달하고 결과의 converged 및 residual_pixels를 검사합니다. 입력 픽셀이 ROI에서 나온 경우 모델이 기대하는 전체 영상 좌표인지 확인하고 필요한 원점 변환을 먼저 적용해야 합니다.

    구체 사례와 판독

    예를 들어 주점에 해당하는 픽셀은 왜곡이 없는 단순 카메라에서 광축 방향을 가리킵니다. 이 방향만으로는 카메라에서 대상까지의 실제 거리를 알 수 없으며 평면이나 두 번째 카메라 같은 추가 조건이 필요합니다. 반복이 수렴하지 않은 결과를 교점이나 스테레오 계산에 그대로 연결하면 후속 좌표가 정밀해 보여도 근거가 부족합니다.

    적용 시 확인

    결과의 잔차는 역투영 계산이 입력 픽셀을 얼마나 잘 재현하는지를 픽셀로 보여 줍니다. 렌즈 중심, 초점 거리 또는 왜곡 계수가 다른 영상에서 얻은 설정을 쓰면 수치 계산이 수렴해도 실제 광선은 잘못될 수 있습니다. 카메라 모델과 영상의 해상도, 좌표 원점 및 단위를 함께 관리하고 화면 중심뿐 아니라 가장자리 관측점도 검증에 포함하세요. 광선의 방향과 출발 프레임을 결과와 함께 남깁니다.
