공개 타입

zvision.VariationInspectOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_models.VariationInspectOptions.

Absolute and sigma allowances and deviation floor for variation inspection.

Python
VariationInspectOptions(low_absolute: float, high_absolute: float, low_sigma: float, high_sigma: float, deviation_floor: float) -> None

  • low_sigma · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • high_sigma · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • deviation_floor · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

    사용 조건과 흐름

    VariationInspectOptions는 학습한 픽셀별 평균에 대해 어둡거나 밝은 변화의 허용치를 설정합니다. low_absolute와 high_absolute는 양 방향의 절대 허용치이고 low_sigma와 high_sigma는 편차 배수입니다. deviation_floor는 사용 편차의 하한이며 모든 값은 유한하고 0 이상이어야 합니다. 각 방향의 허용치는 절대값과 배수 적용값 중 큰 값입니다.

    구체 사례와 결과 판독

    예를 들어 평균 100, 학습 편차 2, 편차 하한 1, 밝은 방향 절대 허용치 5와 배수 3이면 사용 편차는 2이고 허용치는 max(5,6)=6입니다. 위쪽 경계는 106입니다. 어두운 쪽은 low 설정으로 따로 계산합니다. 같은 검사 조건을 정상 및 알려진 결함 영상으로 검증하고 모델 영상과 입력의 위치 정렬도 확인하세요.

    적용 시 확인

    같은 위치의 검사값이 107이면 밝은 쪽 경계 106을 초과합니다. 반면 104는 이 예의 밝은 쪽 범위 안입니다. 실제 결함 마스크에는 검사 마스크와 유효한 학습 위치도 영향을 주므로 개별 결과와 검사 개수를 함께 살펴야 합니다. 어두운 방향과 밝은 방향은 각각 다른 허용치를 사용할 수 있습니다. 조명의 변화와 실제 결함을 구분할 수 있도록 두 방향을 별도의 시험 사례로 검증하세요.
