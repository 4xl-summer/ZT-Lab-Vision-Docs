barcode_decode_stability 멤버와 선언

공개 타입

zvision.barcode_decode_stability: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.barcode_decode_stability.

Fraction of actual offset-perturbed decodes matching baseline; not probability.

밝기 오프셋별 실제 판독이 기준과 일치하는 비율을 계산합니다.

Python
barcode_decode_stability(image, spec, offsets)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offsets · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
Gray8 ZImage
spec
BarcodeSpec
offsets
정수 오프셋 1~256개, 각 -255~255; 픽셀은 0~255로 제한

반환: 독립 BarcodeStability; 점수는 확률이 아닌 일치 비율

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    barcode_decode_stability는 원본 바코드의 기준 디코드와 밝기 오프셋을 각각 적용한 실제 재디코드를 비교합니다. image는 Gray8, spec은 BarcodeSpec이고 offsets는 1개부터 256개의 정수이며 각각 −255부터 255까지입니다. 픽셀 값은 0부터 255 범위로 제한됩니다. 반환 점수는 지정한 시도 중 기준 결과와 일치한 비율입니다.

    구체 사례와 결과 판독

    예를 들어 오프셋 네 개에 대한 실제 결과 중 세 개가 기준 형식과 내용에 일치하면 비율은 3/4=0.75입니다. 이 값은 선택한 네 번의 시험 결과이며 미지의 촬영 조건에서 성공할 확률이 아닙니다. 기준 읽기 상태와 각 시도의 일치 여부도 확인하고, 서로 다른 실험에서는 오프셋 목록과 BarcodeSpec을 함께 기록하세요.

    적용 시 확인

    오프셋이 0인 시도는 원본 밝기 조건에 대응하며, 큰 양수나 음수에서는 포화로 정보가 사라질 수 있습니다. 목록의 각 값과 결과를 함께 남겨 재현합니다. 예를 들어 offsets가 −10, 0, 10이면 세 번의 결과만 비교하며 주변의 모든 조명 조건을 시험한 것은 아닙니다. 원본 결과가 실패한 경우에도 반환된 기준 상태를 확인하고 점수만으로 정상 바코드라고 판단하지 마세요.
