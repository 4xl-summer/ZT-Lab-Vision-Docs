planar_target_facing 멤버와 선언

공개 타입

zvision.planar_target_facing: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.planar_target_facing.

Classify target +Z as 0 grazing, 1 front-facing, or 2 back-facing to the camera.

카메라에 대한 타깃 +Z 방향을 분류합니다.

Python
planar_target_facing(pose)

인자 선언

  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

pose
타깃과 카메라 사이 강체 자세

반환: 0 접선, 1 정면, 2 후면 정수

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    planar_target_facing은 평면 타깃의 +Z 방향이 카메라를 향하는 관계를 분류합니다. 입력 pose는 타깃과 카메라 사이의 올바른 방향을 가진 3차원 자세이며 반환 정수는 0 접선 방향, 1 정면, 2 후면입니다. 이 분류는 타깃이 영상 프레임 안에 보이는지의 판정이나 재투영 오차가 아닙니다.

    구체 사례와 판독

    예를 들어 결과가 1이면 정의된 면이 카메라 쪽을 향한다는 분류로 읽고, 2이면 반대쪽을 향하는 분류로 읽습니다. 0은 거의 비스듬한 접선 관계를 나타냅니다. 타깃의 앞면을 어느 축으로 정의했는지와 자세의 변환 방향을 바꿔 전달하지 않았는지 확인해야 결과가 물리적 장면과 일치합니다.

    적용 시 확인

    같은 3차원 평면이라도 타깃의 +Z 축을 반대로 정의하면 앞면과 뒷면의 해석이 바뀝니다. 모델을 만들 때 사용한 타깃 축을 문서화하고 알려진 자세를 넣어 반환값을 시험하세요. 특히 접선에 가까운 자세는 작은 자세 변화로 분류가 바뀔 수 있어 실제 검출 품질을 별도로 평가해야 합니다. 방향 분류와 타깃 검출은 별개이므로 정면 분류를 얻었다고 실제 이미지에서 점을 모두 찾을 수 있다고 가정하지 마세요. 가림이나 조명도 따로 확인해야 합니다. 반환값의 정의를 장면과 대조하세요.
