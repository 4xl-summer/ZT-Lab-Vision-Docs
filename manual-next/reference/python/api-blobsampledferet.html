    표본 방향의 폭

    BlobSampledFeret는 여러 표본 각도에서 구한 투영 폭 중 최소와 최대의 폭·각도 및 고려한 표본 수 considered를 담습니다. 각도는 라디안입니다. 모든 연속 방향을 완전히 검색한 결과가 아니라 선택된 표본 방향의 범위에서 얻은 결과입니다.

    각도 간격의 영향

    예를 들어 0도와 90도만 표본으로 삼으면 45도 방향의 폭은 직접 평가하지 않습니다. 표본 간격을 더 촘촘하게 정하면 새로운 극값을 발견할 수 있으므로 두 측정의 표본 각도와 개수를 함께 비교해야 합니다.

    결과 해석

    min_width와 max_width는 투영된 극값 차이이고 min_angle과 max_angle은 해당 표본 방향입니다. considered는 범위 안에서 실제 고려한 각도 수입니다. 결과 폭을 ROI 로컬 픽셀 단위로 읽고 물리 길이가 필요하면 보정과 축 간격을 확인합니다.

    검증

    원본 마스크에 선택된 방향을 표시하고 다른 방향의 폭과 비교하면 물체의 방향성과 결과를 해석하기 쉽습니다. 마스크가 잘리거나 노이즈가 남으면 지지 경계가 달라져 폭과 극값 각도도 달라질 수 있습니다.
