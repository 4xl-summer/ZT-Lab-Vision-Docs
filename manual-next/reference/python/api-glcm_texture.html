Python API · glcm_texture

glcm_texture 멤버와 선언

공개 타입

zvision.glcm_texture: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_models.glcm_texture.

선택된 이웃 픽셀 쌍의 공발생 행렬과 질감 통계를 계산합니다.

Python
glcm_texture(image, options, mask=None)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

image
Gray8, Gray16 또는 GrayF32 영상.
options
GlcmOptions 양자화 범위·이웃 오프셋·작업 상한.
mask
선택적 동일 기하 Gray8 마스크; 양 끝 모두 비제로여야 포함되며 None은 전체.

반환: 호출자가 close할 GlcmResult 소유 객체.

오류: 형식·기하·옵션 오류 또는 작업 한도 위반은 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    glcm_texture는 영상, GlcmOptions와 선택적인 마스크로 픽셀 쌍의 밝기 동시발생 행렬을 계산합니다. 결과에는 정규화된 확률 행렬과 쌍 수, 대비, 균일성, 에너지, 상관 및 엔트로피 정보가 있습니다. 결과 객체는 소유 자원이므로 사용 후 정리하고 필요한 수치는 그 전에 읽습니다.

    구체 사례와 결과 판독

    예를 들어 levels=2이면 확률 행렬은 2×2이고 네 칸이 각 밝기 레벨 쌍을 나타냅니다. 가로 이웃과 세로 이웃을 비교하면 서로 다른 무늬의 방향성이 드러날 수 있습니다. 마스크로 선택된 영역과 offset, 양자화 범위 및 쌍 수를 함께 확인하세요. 상관을 정의할 수 없는 경우에는 결과가 None일 수 있으므로 숫자 0으로 바꾸어 해석하지 않습니다.

    적용 시 확인

    행렬 요소는 각 레벨 쌍의 확률이며 결과 해석은 선택한 방향과 영역에 의존합니다. 균일한 영상에서는 한 레벨에 쌍이 몰릴 수 있고, 이때 분산이 없어 상관이 정의되지 않을 수 있습니다. 행렬과 요약 지표를 같은 조건에서 비교하세요. 유효 픽셀 쌍이 충분하지 않거나 옵션이 잘못된 경우 실패를 처리하고 빈 특징값을 정상 결과로 가정하지 마세요. 입력 영상 형식과 마스크의 좌표 정렬을 확인합니다. 입력과 결과의 설정을 함께 보관하세요.
