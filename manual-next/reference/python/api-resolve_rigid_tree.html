Python API · resolve_rigid_tree

resolve_rigid_tree 멤버와 선언

공개 타입

zvision.resolve_rigid_tree: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.resolve_rigid_tree.

Resolve target <- source from 1–128 child-to-parent transforms.

강체 변환 트리에서 출발 프레임부터 도착 프레임까지의 변환을 찾습니다.

Python
resolve_rigid_tree(edges, from_frame, to_frame)

인자 선언

  • edges · POSITIONAL_OR_KEYWORD · 기본값 없음
  • from_frame · POSITIONAL_OR_KEYWORD · 기본값 없음
  • to_frame · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

edges
자식에서 부모 방향의 RigidTransform3 1–128개입니다.
from_frame
0이 아닌 출발 프레임 ID입니다.
to_frame
0이 아닌 도착 프레임 ID입니다.

반환: 도착 프레임 ← 출발 프레임의 RigidTransform3 값입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    resolve_rigid_tree는 자식에서 부모로 향하는 강체 변환 간선으로 구성된 트리에서 지정한 출발 프레임과 도착 프레임 사이의 변환을 찾습니다. 간선의 프레임 연결과 방향을 명확하게 지정하고 모든 이동량은 같은 길이 단위를 사용해야 합니다. 찾은 경로의 변환을 필요한 방향으로 합성하여 결과를 구성합니다.

    구체 사례와 판독

    예를 들어 카메라에서 그리퍼, 그리퍼에서 베이스로 가는 간선이 있다면 카메라에서 베이스로 가는 경로는 두 변환을 차례로 적용합니다. 반대 방향이 필요하면 경로의 각 변환을 역방향으로 사용해야 합니다. 프레임 이름이 비슷해도 실제 기준이 다르면 같은 노드가 아니므로 장치 설정과 일치하는 이름을 사용하세요. 경로가 올바른지 알려진 점으로 검증합니다.

    적용 시 확인

    프레임 사이에 경로가 없거나 트리 구성이 유효하지 않으면 임의의 단위 행렬로 대체해서는 안 됩니다. 입력 간선 목록과 요청한 두 프레임 이름을 확인하고 오류를 처리하세요. 동일한 프레임에 대한 결과를 해석할 때도 길이 단위와 좌표계의 정의가 실제 작업 시점에 일치하는지 관리해야 합니다. 연결 경로의 길이가 여러 단계인 경우 중간 기준이 어느 장치에 고정되어 있는지와 당시 보정 값을 확인해야 이후 계산을 재현할 수 있습니다.
