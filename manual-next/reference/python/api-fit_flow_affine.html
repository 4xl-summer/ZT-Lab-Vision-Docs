fit_flow_affine 멤버와 선언

공개 타입

zvision.fit_flow_affine: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.fit_flow_affine.

Approximate a packed displacement field by an affine map; mask zero excludes a sample.

변위 필드의 선택된 점을 아핀 맵으로 근사합니다.

Python
fit_flow_affine(width, height, origin, flow, mask=None)

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • origin · POSITIONAL_OR_KEYWORD · 기본값 없음
  • flow · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

width
필드의 양의 너비 픽셀 수입니다.
height
필드의 양의 높이이며 너비와 곱은 최대 50000입니다.
origin
필드 원점 Point2입니다.
flow
너비×높이 개수의 변위 Point2 순서열입니다.
mask
0인 점을 제외하는 같은 길이의 바이트 마스크 또는 None입니다.

반환: 추정 Affine2 값입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
