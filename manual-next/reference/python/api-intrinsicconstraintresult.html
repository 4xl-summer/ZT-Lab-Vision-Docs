    사용과 결과 해석

    고정된 자세에서 선택한 카메라 내부 계수를 적합한 결과입니다. lenses는 카메라별 LensModel의 불변 튜플이고 diagnostics는 대응 카메라의 최적화 진단입니다. initial_rms와 final_rms는 전체 재투영 RMS를 픽셀 단위로 나타내며 work는 계산 전에 산정한 보수적 작업량입니다.

    카메라 배열의 순서와 진단 튜플의 순서가 대응하므로 한 카메라의 결과를 다른 영상에 적용하지 않도록 원래 인덱스를 보존하십시오. 전체 RMS가 감소해도 개별 카메라가 같은 정도로 개선되었는지는 진단을 따로 읽어야 합니다.

    고정된 자세나 보드 대응이 잘못되면 렌즈 계수가 그 오차를 일부 흡수할 수 있습니다. 설정한 계수 마스크와 수렴·rank 진단, 사용하지 않은 관측의 오차를 함께 확인하고 계산 작업량을 실제 경과 시간으로 오해하지 마십시오.
