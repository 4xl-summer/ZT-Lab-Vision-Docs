gaussian 멤버와 선언

공개 타입

zvision.gaussian: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._processing_advanced.gaussian.

Anisotropic Gaussian; border 0 replicate, 1 reflect, 2 constant.

비등방 Gaussian 평활화를 적용합니다.

Python
gaussian(image, sigma_x, sigma_y, radius_x, radius_y, border=0, constant=0.0, format=1)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sigma_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sigma_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • border · POSITIONAL_OR_KEYWORD · 기본값 0
  • constant · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • format · POSITIONAL_OR_KEYWORD · 기본값 1
