Python API · copy_region_to_image

copy_region_to_image 멤버와 선언

공개 타입

zvision.copy_region_to_image: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._copy_region_gap.copy_region_to_image.

Copy selected source rectangle pixels into a new destination snapshot.

원본 사각형의 선택 픽셀을 대상 복사본에 복사합니다.

Python
copy_region_to_image(source, destination, source_x, source_y, width, height, destination_x, destination_y, mask=None, clip=False)
