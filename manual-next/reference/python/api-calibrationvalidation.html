    사용과 결과 해석

    평면 보정을 별도의 대응점에 적용한 뒤 집계 통계와 점별 잔차를 보관하는 불변 스냅샷입니다. metrics에는 세계와 픽셀 공간의 RMS·최댓값·판정이 있고 residuals는 입력 순서에 대응하는 항목의 튜플입니다. 정방향으로 얻은 세계 예측점과 세계 기준점의 거리가 세계 오차이고, 기준점을 역변환한 픽셀과 관측 픽셀 사이의 거리가 픽셀 오차입니다. 예시의 예측이 (12,42), 기준이 (12.3,42.4)밀리미터면 세계 잔차는 0.5밀리미터입니다. 같은 점의 픽셀 잔차는 보정의 역변환에 따라 따로 계산해야 합니다. 학습과 검증에 동일한 대응점을 쓰면 학습 범위 밖에서의 적합도를 독립적으로 평가할 수 없습니다. 배열의 순서, 단위와 tolerance를 함께 기록하십시오. 예측 세계점이 (12,42) mm이고 기준이 (12.3,42.4) mm이면 잔차 거리는 0.5 mm입니다. 이 점의 결과를 다른 단위의 허용치와 바로 비교하지 말고 먼저 단위를 맞춥니다. 학습점만으로 계산한 지표와 독립 보류점 지표는 따로 보관합니다. 예측과 기준의 순서가 바뀌면 같은 수의 좌표라도 잘못된 잔차가 만들어집니다. 대응점 배열을 만들 때 각각의 물리 위치를 함께 식별하십시오.
