공개 멤버

    전경 좌표의 중앙값

    blob_area_median은 비영 전경 픽셀 수와 각 축 좌표의 낮은 중앙값을 계산합니다. 산술 평균 중심은 모든 좌표를 더해 개수로 나누지만 이 연산은 축별로 정렬된 좌표의 중앙을 사용하므로 분포에 따라 결과가 다를 수 있습니다.

    중앙값 계산

    예를 들어 x 좌표가 0, 1, 4, 9로 정렬되면 짝수 개에서 낮은 중앙값은 1입니다. x와 y를 독립적으로 계산한 쌍은 전경의 한 픽셀에 반드시 해당하지는 않습니다. 반환 area는 선택된 비영 픽셀의 개수입니다.

    호출 조건

    image에는 전경 마스크 ZImage를 전달하고 work_budget에는 양의 정수 상한을 둡니다. 입력 ROI가 바뀌면 로컬 좌표와 포함되는 전경이 모두 달라질 수 있습니다. 결과를 전체 영상에 표시할 때는 ROI 원점을 적용합니다.

    활용과 한계

    좌표 중앙값은 치우친 분포를 볼 때 평균 중심과 함께 비교할 수 있습니다. 여러 떨어진 객체를 함께 넣으면 모든 전경 픽셀에 대한 값이므로 각 객체별 위치가 필요할 때는 먼저 객체를 구분해 분석합니다.

    평균과 중앙값의 차이가 클 때에는 일부 멀리 떨어진 전경이나 다른 성분이 마스크에 들어왔는지 확인합니다. 이 차이 자체를 결함 판정으로 단정하지는 않습니다.
