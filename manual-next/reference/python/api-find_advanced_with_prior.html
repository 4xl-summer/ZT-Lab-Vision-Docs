find_advanced_with_prior(source, model, options, prior, mask=None)

확인된 인자 조건

source
검색할 ZImage입니다.
model
학습된 모델입니다.
options
AdvancedMatchOptions 값입니다. x·y·angle·scale_x·scale_y에 각각 SearchAxis(minimum, maximum, step)를 지정합니다. 일반 검색에서 x·y는 검색 ROI 로컬 픽셀, angle은 라디안이며 scale은 양수입니다. candidate_budget은 평가 포즈 수 상한입니다. prior는 격자를 바꾸지 않고 평가 순서를 바꾸므로 예산이나 조기 종료에 따라 결과가 달라질 수 있습니다. 예를 들어 고정 각도·배율은 SearchAxis(0, 0, 1), SearchAxis(1, 1, 1)로 각각 지정하고 x·y는 검색 범위에 맞게 구성합니다.
prior
검색 기준 또는 우선 순위에 사용할 AdvancedPosePrior입니다.
mask
선택적 검색 마스크 ZImage이며 기본값 None입니다.

반환: 독립 검색 결과와 종료 진단을 반환합니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
