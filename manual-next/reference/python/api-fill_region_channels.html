Python API · fill_region_channels

fill_region_channels 멤버와 선언

공개 타입

zvision.fill_region_channels: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._copy_region_gap.fill_region_channels.

Fill each channel in native pixel order, preserving all other pixels.

채널별 값으로 선택 대상 영역을 채운 복사본을 만듭니다.

Python
fill_region_channels(destination, x, y, width, height, values, mask=None, mask_offset_x=0, mask_offset_y=0, clip=False, invert_mask=False)

인자 선언

  • destination · POSITIONAL_OR_KEYWORD · 기본값 없음
  • x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • values · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None
  • mask_offset_x · POSITIONAL_OR_KEYWORD · 기본값 0
  • mask_offset_y · POSITIONAL_OR_KEYWORD · 기본값 0
  • clip · POSITIONAL_OR_KEYWORD · 기본값 False
  • invert_mask · POSITIONAL_OR_KEYWORD · 기본값 False

확인된 인자 조건

destination
대상 ZImage
x
대상 ROI 로컬 부호 있는 시작 x
y
대상 ROI 로컬 부호 있는 시작 y
width
채울 사각형의 양의 폭(픽셀)
height
채울 사각형의 양의 높이(픽셀)
values
채널 순서의 값 시퀀스
mask
선택 마스크; 기본값 None
mask_offset_x
마스크의 부호 있는 로컬 x 오프셋; 기본값 0
mask_offset_y
마스크의 부호 있는 로컬 y 오프셋; 기본값 0
clip
bool; 대상 범위 밖 부분을 자를지 여부; 기본값 False
invert_mask
bool; 마스크 선택을 뒤집을지 여부; 기본값 False

반환: 소유 ZImage와 CopyRegionReport

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.
