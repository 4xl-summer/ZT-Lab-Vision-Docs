확인된 인자 조건

lights
입력 영상과 같은 수의 조명 xyz 벡터 3–128개. 각 벡터는 유한한 성분 세 개이며 독립적인 조명 기하가 필요합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
