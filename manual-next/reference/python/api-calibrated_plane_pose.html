calibrated_plane_pose 멤버와 선언

공개 타입

zvision.calibrated_plane_pose: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._calibrated_plane_pose.calibrated_plane_pose.

Return one +Z camera pose; input is distortion-corrected global pixels and metric plane coordinates. Mirror ambiguity is not resolved.

보정된 평면 호모그래피에서 +Z 카메라 자세를 구합니다.

Python
calibrated_plane_pose(homography, fx, fy, cx, cy, *, max_orthogonality_error=0.01, max_scale_error=0.01)
