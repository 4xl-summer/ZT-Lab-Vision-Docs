Python API · calibrated_plane_pose

calibrated_plane_pose 멤버와 선언

공개 타입

zvision.calibrated_plane_pose: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._calibrated_plane_pose.calibrated_plane_pose.

Return one +Z camera pose; input is distortion-corrected global pixels and metric plane coordinates. Mirror ambiguity is not resolved.

보정된 평면 호모그래피에서 +Z 카메라 자세를 구합니다.

Python
calibrated_plane_pose(homography, fx, fy, cx, cy, *, max_orthogonality_error=0.01, max_scale_error=0.01)

인자 선언

  • homography · POSITIONAL_OR_KEYWORD · 기본값 없음
  • fx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • fy · POSITIONAL_OR_KEYWORD · 기본값 없음
  • cx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • cy · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_orthogonality_error · KEYWORD_ONLY · 기본값 0.01
  • max_scale_error · KEYWORD_ONLY · 기본값 0.01

확인된 인자 조건

homography
왜곡 보정한 전역 픽셀과 평면 좌표 사이 유한 계수 9개
fx
초점거리 x(픽셀)
fy
초점거리 y(픽셀)
cx
주점 x(픽셀)
cy
주점 y(픽셀)
max_orthogonality_error
허용 직교 오차, 기본 0.01
max_scale_error
허용 축척 오차, 기본 0.01

반환: 회전·이동 및 오차를 담은 CalibratedPlanePose 값

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
