    예를 들어 변형 목록에서 두 번째 항목을 사용했다면 0 기반 인덱스 1을 원래 입력 목록에 연결해 해석합니다. 목록 순서를 변경하면 같은 숫자의 의미도 바뀌므로 모델과 변형 정의를 함께 보관합니다. 일반 매치의 위치가 검색 ROI 로컬인지 전역인지 구분하고, 보고서의 종료 이유를 확인해 전체 변형 은행이 평가되었는지도 살펴봅니다.

    기본 매치에 기록된 점수와 원근 또는 다른 모델의 점수를 같은 척도로 가정하지 않습니다. 학습 목록의 변형과 검색 ROI를 추적하면 결과가 어느 조건에서 나왔는지 확인할 수 있습니다.
