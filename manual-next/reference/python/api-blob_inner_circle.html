공개 멤버

    내부의 이산 원 찾기

    blob_inner_circle은 격자 중심 원이 배경 픽셀 중심을 포함하지 않도록 최대 반경을 찾습니다. 결과는 ROI 로컬 정수 중심과 픽셀 단위 반지름을 담습니다. 이 정의는 물체의 연속 곡선에 접하는 이론적 원과 정확히 같다고 가정할 수 없습니다.

    입력과 제한

    image에 전경 마스크 ZImage를 전달하고 work_budget에 양의 정수 작업량 상한을 지정합니다. 구멍이나 인접한 배경 픽셀은 허용 가능한 원에 영향을 줍니다. ROI가 물체를 자르면 보이는 마스크에서의 측정이므로 전체 물체의 원으로 해석하지 않습니다.

    결과 판독

    중심 (3,4), 반경 2라는 결과는 해당 좌표를 중심으로 하는 픽셀 단위 원을 뜻합니다. 결과 중심을 원본 마스크에 표시하고 주변의 배경 위치를 확인하면 선택된 원이 무엇을 나타내는지 이해하기 쉽습니다. ROI 원점을 적용해야 전체 영상과 위치가 맞습니다.

    외접원과 구분

    내부 원은 배경을 포함하지 않는 방향의 제약을 쓰고 외접원은 물체의 셀 꼭짓점을 감싸는 문제입니다. 두 결과는 같은 반지름이 아니며 단순한 반대 연산도 아닙니다. 물리적 크기로 비교하려면 보정과 픽셀 축 간격을 확인합니다.
