    사용과 결과 해석

    색 보정 피팅에 사용된 한 패치의 보정 전후 CIE76 색차를 담습니다. index는 입력 패치 배열의 0부터 시작하는 위치이고 before_delta_e와 after_delta_e는 각각 보정 전과 후의 거리입니다. 패치마다 두 값을 비교하면 전체 평균만 보았을 때 가려지는 개별 색의 변화를 확인할 수 있습니다. 값이 작을수록 해당 패치의 Lab 좌표가 목표에 가까운 방향의 결과입니다.

    먼저 측정 source와 목표 reference의 대응을 ColorPatch로 구성하고 보정 피팅을 실행합니다. 결과의 잔차를 입력 순서와 연결해 읽으며, 다른 패치 배열에 같은 index를 적용하지 않습니다. 피팅은 선형 RGB 보정을 구하지만 보고하는 잔차는 Lab에서 계산한 CIE76 거리이므로 두 값의 좌표와 단위를 혼동하지 않습니다.

    한 패치의 잔차가 개선되었더라도 모든 패치가 같은 정도로 개선된다는 보장은 없습니다. 전체 평균과 최대값을 ColorFitInfo에서 함께 읽고 개별 잔차로 큰 차이가 있는 패치를 찾습니다. 결과 값은 복사된 스냅샷이며 피팅 결과 핸들과 보정 영상을 소유하는 객체는 각자의 수명에 따라 별도로 닫습니다.
