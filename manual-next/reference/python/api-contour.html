    경계와 소속

    Contour는 연결 성분 인덱스, 구멍 경계인지 나타내는 플래그, 순서가 있는 점들의 불변 컬렉션으로 구성됩니다. 인덱스는 해당 분석 결과의 연결 성분을 가리키며 영상 전체에서 영구적으로 유지되는 물체 식별자는 아닙니다. points의 점은 ROI 로컬 픽셀 격자 기준으로 해석합니다.

    외곽과 구멍

    같은 전경 성분에 외부 경계와 내부 구멍 경계가 있으면 경계의 소속 성분과 is_hole을 함께 읽습니다. 경계 점 수와 성분의 면적은 서로 다른 측정치입니다. 특히 구멍이 있는 물체에서는 외곽만 보고 픽셀 면적을 직접 추정하면 내부의 배경을 놓칠 수 있습니다.

    후속 계산

    마스크와 연결 조건을 정한 뒤 윤곽을 구하고 점 순서를 유지하여 둘레나 도형 분석에 전달합니다. 전체 영상 위에 표시할 때 ROI 원점을 적용해야 하며 점을 임의로 정렬하면 경계의 순서가 바뀌어 선분 길이와 인접 관계가 달라집니다. 점 목록만으로 모든 연산의 닫힘 처리 방식을 추정하지 말고 해당 연산의 옵션을 확인합니다.

    경계 점의 순서와 닫힘 처리에 따라 길이 계산에서 포함되는 선분이 달라집니다. 경계가 구멍을 나타내는지 확인한 후 후속 면적 또는 둘레 계산에 전달해야 외부 경계와 내부 경계를 혼동하지 않습니다.
