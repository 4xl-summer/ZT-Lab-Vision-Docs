Python API · find_feature_collection

find_feature_collection 멤버와 선언

공개 타입

zvision.find_feature_collection: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._matching_features.find_feature_collection.

여러 특징 모델을 검색하고 결과 경계의 겹침을 억제합니다.

Python
find_feature_collection(source, entries, *, mask=None, max_results=10, max_iou=0.5, max_ransac_hypotheses=4096)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • entries · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · KEYWORD_ONLY · 기본값 None
  • max_results · KEYWORD_ONLY · 기본값 10
  • max_iou · KEYWORD_ONLY · 기본값 0.5
  • max_ransac_hypotheses · KEYWORD_ONLY · 기본값 4096

확인된 인자 조건

source
검색할 ZImage입니다.
entries
1..64개의 고유 ID FeatureCollectionEntry입니다.
mask
선택적 마스크이며 기본값 None입니다.
max_results
양의 최대 결과 수이며 기본값 10입니다.
max_iou
허용 AABB IoU 0..1이며 기본값 0.5입니다.
max_ransac_hypotheses
공유 가설 예산 1..100000이며 기본값 4096입니다.

반환: 독립 FeatureCollectionReport입니다.

오류: 잘못된 항목, 중복 ID 또는 예산·설정 위반은 오류입니다.

max_results: 정수 검사 · 최소 1.

max_ransac_hypotheses: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
