Recompute Data Matrix ECC200 diagnostics on a sampled module grid.

샘플링된 Data Matrix에서 ECC200 정정을 진단합니다.

Python
diagnose_datamatrix_ecc_modules(image, max_corrected_per_block)

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
정방향 Gray8 격자, 모듈당 1픽셀, 0 검정·255 흰색, quiet zone 없음
max_corrected_per_block
정정 후 수락 판정의 블록별 정정 코드워드 상한

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    샘플된 Data Matrix ECC200 모듈 격자의 실제 오류 정정 결과를 진단합니다. 입력은 Gray8이며 모듈 하나가 한 픽셀이고 검정 0, 흰색 255로 표현된 바로 선 격자입니다. quiet zone은 포함하지 않습니다. max_corrected_per_block은 각 블록에서 정정된 코드워드 수에 대한 사후 판정 기준입니다.

    구체 사례와 결과 판독

    예를 들어 한 블록에서 코드워드 2개가 수정되었다면 한계 1을 초과하고 한계 2는 해당 블록 조건을 만족합니다. 이 숫자는 손상된 모듈 또는 픽셀의 개수와 같다고 가정할 수 없습니다. 전체 블록의 결과와 accepted, 복원된 텍스트를 함께 확인하세요. 허용 한계를 바꾸는 것은 ECC200 디코더의 정정 동작을 바꾸는 일이 아닙니다.

    적용 시 확인

    격자 크기와 모듈 순서를 정확히 유지해야 ECC200 데이터가 의도한 심볼에 대응합니다. 반환된 수정 수는 정정된 코드워드의 개수입니다. 두 블록의 수정 수가 각각 1이면 합계는 2지만 블록별 최대는 1입니다. 한계는 각 블록에 적용되므로 전체 합계가 한계보다 큰지만 비교하는 판정은 의미가 다릅니다. 원본 격자의 크기와 정정 결과를 함께 보관하세요. 각 블록의 결과를 확인하세요.
