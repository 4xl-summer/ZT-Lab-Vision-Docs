connect

classmethod · 선언 타입 zvision._devices_advanced.ModbusTcp

Python
connect(cls, address, unit=1, timeout_ms=1000)

지정한 숫자 주소와 포트에 Modbus TCP 연결을 엽니다.

확인된 인자 조건

address
IP:포트 또는 [IPv6]:포트 문자열입니다.
unit
0–255 유닛 식별자이며 기본값은 1입니다.
timeout_ms
양의 연결·입출력 시간 제한이며 밀리초 단위 기본값은 1000입니다.

반환: 호출자가 닫아야 하는 ModbusTcp 연결입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • address · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 1
  • timeout_ms · POSITIONAL_OR_KEYWORD · 기본값 1000

unit: 정수 검사 · 최소 0.

timeout_ms: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: RuntimeError, TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

count: 정수 검사 · 최소 1.
