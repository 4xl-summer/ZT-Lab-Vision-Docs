ModbusTcp 멤버와 선언

공개 타입

zvision.ModbusTcp: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._devices_advanced.ModbusTcp.

Owns a Modbus TCP connection. Writes are never retried automatically.

Python
ModbusTcp()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
