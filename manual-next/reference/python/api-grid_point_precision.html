Python API · grid_point_precision

grid_point_precision 멤버와 선언

공개 타입

zvision.grid_point_precision: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.grid_point_precision.

Assess one existing local-pixel point under a constant independent intensity noise model.

강도 잡음 모델에서 하나의 격자점 정밀도를 평가합니다.

Python
grid_point_precision(image, point, radius, noise_sigma, max_sigma)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • point · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음
  • noise_sigma · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_sigma · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력
point
영상 로컬 픽셀 좌표
radius
분석 반경(픽셀)
noise_sigma
강도 잡음 표준편차
max_sigma
허용 최대 위치 표준편차(픽셀)

반환: 공분산, 장축 표준편차와 수락 여부를 담은 GridPrecision

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

noise_sigma: 유한한 수 검사.

max_sigma: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
