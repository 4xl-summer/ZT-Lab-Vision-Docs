공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    firstint필수연속 실패 구간의 첫 번째 0 기반 탐침 인덱스입니다.
    lastint필수연속 실패 구간의 마지막 0 기반 탐침 인덱스이며 끝을 포함합니다.
    flagsint필수구간에 나타난 실패 비트의 합집합입니다.

    사용과 결과 해석

    연속적으로 실패한 비드 탐침 구간의 양끝과 사유를 표현합니다. first와 last는 0부터 시작하는 탐침 인덱스이며 양끝을 포함합니다. flags는 구간에 나타난 각 실패 사유 비트의 합집합입니다.

    예를 들어 first가 2이고 last가 4이면 2, 3, 4번 탐침이 해당 범위에 들어 총 3개입니다. 구간의 flags에 두 비트가 설정되어 있어도 모든 탐침이 그 두 사유를 각각 가졌다는 뜻은 아닙니다. 개별 원인은 탐침별 결과를 확인해야 합니다.

    인덱스 범위는 픽셀 좌표나 물리 길이가 아닙니다. 경로 간격이 일정하지 않다면 last−first만으로 결손 길이를 계산하지 말고 해당 검사 결과의 길이 계산을 사용하십시오. 제외된 탐침과 구간의 연결 규칙도 설정에 따라 확인해야 합니다.
