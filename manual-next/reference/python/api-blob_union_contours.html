blob_union_contours 멤버와 선언

공개 타입

zvision.blob_union_contours: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_union_contours.blob_union_contours.

Join two open polylines if endpoint gap and tangent angle pass.

끝점 간격과 접선 각도가 조건에 맞는 열린 경로를 잇습니다.

Python
blob_union_contours(a, b, max_gap, max_angle, work_budget)

인자 선언

  • a · POSITIONAL_OR_KEYWORD · 기본값 없음
  • b · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_gap · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_angle · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

a
첫 열린 Point2 폴리라인; 2점 이상
b
둘째 열린 Point2 폴리라인; 2점 이상
max_gap
끝점 사이 허용 최대 거리
max_angle
접선 간 허용 최대 각도(라디안)
work_budget
양의 정수 작업량 상한

반환: 독립 윤곽 구간 list

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    열린 경로 이어 붙이기

    blob_union_contours는 두 열린 Point2 폴리라인의 끝점 간격과 접선 각도를 검사해 조건에 맞는 경로를 잇습니다. 영역 마스크의 집합 합집합이나 임의로 교차하는 두 도형의 기하학적 합집합과는 다른 작업입니다. 두 입력은 각각 최소 두 점이 필요합니다.

    거리와 각도

    max_gap은 끝점 사이에 허용할 최대 거리이고 max_angle은 접선 간 허용 각도를 라디안으로 지정합니다. 끝점이 가깝더라도 두 경로의 방향이 크게 꺾이면 각도 조건 때문에 연결되지 않을 수 있습니다. 반대로 방향이 비슷해도 간격이 너무 크면 거리 조건에 맞지 않습니다.

    준비와 확인

    두 경로의 점 순서와 좌표계를 맞추고 양의 work_budget을 지정합니다. ROI가 다르면 각각의 점을 공통 좌표로 변환해야 간격을 올바르게 계산할 수 있습니다. 결과 경로를 원본 두 경로와 겹쳐 의도한 끝점이 연결되었는지 확인합니다.

    튜닝

    허용치를 지나치게 크게 두면 서로 다른 물체의 가까운 윤곽이 이어질 위험이 있습니다. 작게 두면 실제로 하나였던 경계의 끊어진 부분이 남을 수 있으므로 예상되는 틈 크기와 방향 변화를 사례별로 검증합니다.
