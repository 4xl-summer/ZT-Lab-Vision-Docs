    사용 맥락과 결과 해석

    학습된 기본 모델의 종류와 템플릿 폭·높이, 선택 표본 수, 템플릿 로컬 기준점을 나타내는 값입니다. NCC에서는 선택된 마스크 픽셀 수가 표본 수이고 형상에서는 추출된 기울기 특징점 수입니다. 따라서 이 숫자는 찾은 물체의 개수가 아닙니다. 모델을 학습하거나 복원한 뒤 의도한 입력이 사용되었는지 확인하는 데 유용합니다.

    기준점은 ((폭−1)/2, (높이−1)/2)입니다. 폭 3, 높이 2라면 기준점은 (1,0.5)이며 이 반 픽셀 중심이 검색 포즈의 기준이 됩니다. 결과 위치는 이 점이 검색 영상에서 어디에 있는지를 표현합니다. 모델 정보 값은 템플릿의 픽셀 전체나 검색 설정을 나타내지 않으므로 결과를 재현하려면 영상 원점과 MatchSpec을 따로 보관해야 합니다.

    값을 확인하는 순서

    kind 항목: 모델의 NCC 또는 형상 종류입니다. width 항목: 템플릿의 가로 크기(픽셀)입니다. height 항목: 템플릿의 세로 크기(픽셀)입니다. sample_count 항목: NCC에서는 선택 픽셀 수, 형상 모델에서는 특징점 수입니다. anchor 항목: 템플릿 로컬 중심 ((폭−1)/2, (높이−1)/2)입니다.
