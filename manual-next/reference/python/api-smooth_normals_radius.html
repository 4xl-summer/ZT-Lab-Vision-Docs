공개 타입

zvision.smooth_normals_radius: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.smooth_normals_radius.

점군의 반경 이웃으로 법선을 반복 평균합니다.

Python
smooth_normals_radius(cloud, normals, radius, iterations)

인자 선언

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • normals · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음
  • iterations · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
normals
Point3 또는 None의 슬롯별 법선 시퀀스; 점군 슬롯 수와 같아야 함
radius
유한 양수 이웃 반경, 점군 길이 단위
iterations
양의 정수 반복 횟수

반환: 독립 Point3 또는 None 목록; 결측과 상쇄된 법선은 None입니다.

오류: 길이, 반경, 횟수 또는 법선이 무효이면 오류입니다.

radius: 유한한 수 검사.

iterations: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
