공개 타입

점군의 반경 이웃으로 법선을 반복 평균합니다.

Python
smooth_normals_radius(cloud, normals, radius, iterations)

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • normals · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
normals
Point3 또는 None의 슬롯별 법선 시퀀스; 점군 슬롯 수와 같아야 함
radius
유한 양수 이웃 반경, 점군 길이 단위
iterations
양의 정수 반복 횟수

반환: 독립 Point3 또는 None 목록; 결측과 상쇄된 법선은 None입니다.

오류: 길이, 반경, 횟수 또는 법선이 무효이면 오류입니다.

radius: 유한한 수 검사.

iterations: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    smooth_normals_radius는 점군에서 주어진 거리 이내에 있는 점의 법선을 반복 평균합니다. normals의 슬롯 수는 cloud의 전체 슬롯 수와 같아야 하며 결측을 None으로 나타냅니다. radius는 점군 길이 단위의 유한 양수, iterations는 양의 정수입니다. 예를 들어 단위가 밀리미터이고 반경이 2라면 각 중심에서 거리 2 mm 이하의 유효한 점과 법선을 이웃으로 봅니다.

    매 반복은 이전 반복 결과를 사용하고, 해당 점이나 법선이 결측인 슬롯은 그대로 결측입니다. 반대 방향을 합해 길이가 0이 되면 방향을 정할 수 없어 None이 될 수 있습니다. 메시 연결을 사용하는 smooth_normals와 달리 이 연산의 이웃은 공간 거리로 정해집니다. 따라서 반경이 가까운 서로 다른 표면을 함께 포함할 수 있는지 확인해야 합니다. 길이 불일치, 무효 반경이나 횟수, 유효하지 않은 법선은 오류입니다.
