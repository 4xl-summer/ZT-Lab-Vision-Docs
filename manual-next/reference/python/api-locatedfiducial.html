    사용 맥락과 계약

    LocatedFiducial은 검출된 ZVFD-1 표식과 그 위치를 함께 제공합니다. marker에는 해독된 CodedFiducial이 있고 x와 y는 흰색 여백 고리를 제외한 표식 원점의 ROI 로컬 픽셀 좌표입니다. 위치 좌표와 표식 안에 기록된 격자 row·column 또는 물리 pitch는 서로 다른 정보입니다.

    구체 사례와 판독

    예를 들어 ROI 원점이 전체 영상의 (100,200)이고 이 결과의 로컬 위치가 (10,20)이면 전체 영상 위치는 (110,220)입니다. 보정이나 다른 영상 결과와 비교할 때 원점을 정확히 한 번 더하세요. marker의 id와 방향도 함께 확인하면 같은 위치의 다른 표식을 대상으로 착각하는 일을 줄일 수 있습니다.

    적용 시 확인

    표식 위치가 이미지 영역 밖이라고 보인다면 먼저 ROI의 원점을 적용했는지 확인합니다. 흰색 여백 고리는 검출에 필요할 수 있지만 반환 원점의 기준에는 포함되지 않습니다. 로컬 좌표를 전역 좌표로 바꾸는 과정과 표식의 물리 격자 좌표로 변환하는 과정은 구별해야 합니다. ROI를 변경한 다음 이전 결과의 로컬 좌표를 새 ROI 기준으로 해석하면 위치가 바뀝니다. 검출 당시 원점을 보관해야 합니다.
