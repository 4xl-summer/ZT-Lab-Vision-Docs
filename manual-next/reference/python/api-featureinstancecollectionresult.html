    사용 맥락과 결과 해석

    여러 모델의 반복 특징 인스턴스를 검색하고 방향 겹침을 억제한 뒤 얻는 독립 결과입니다. matches는 결과 튜플이고 evaluated는 총 평가 가설 수이며 incomplete는 전체 검색이 완료되지 않았는지 나타냅니다. 결과가 비어 있는 상태와 예산 중단 상태는 서로 별개의 정보입니다.

    각 항목은 모델 id, 변환 행렬, 네 모서리와 내점 수를 담습니다. 검색 공간이 너무 넓거나 총 가설 예산이 작으면 일부 모델이 충분히 평가되지 않을 수 있으므로 입력 순서와 예산을 함께 기록합니다. max_iou와 억제 scope도 최종 개수에 영향을 줍니다. 이 스냅샷을 읽는 작업과 원래 영상·모델의 소유 및 해제는 구분합니다.

    같은 모델끼리만 억제할지 다른 모델까지 비교할지도 결과에 영향을 줍니다. 인접 물체가 겹친 장면에서는 억제 범위와 최대 IoU를 바꿔 실제로 잃는 후보가 있는지 시험하세요.

    값을 확인하는 순서

    matches 항목: 억제 후 남은 결과의 독립 불변 튜플입니다. evaluated 항목: 평가한 가설의 총수입니다. incomplete 항목: 공유 예산으로 검색이 완료되지 않았는지 나타냅니다.
