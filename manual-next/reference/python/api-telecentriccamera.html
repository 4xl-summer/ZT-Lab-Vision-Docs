fit_xy

staticmethod · 선언 타입 zvision._camera_models.TelecentricCamera

Python
fit_xy(points, pixels, unit, camera_frame)

카메라 평면 XY와 픽셀 대응에서 축 정렬 직교 모델을 적합합니다.

확인된 인자 조건

points
카메라 평면 Point2 3–100000개입니다.
pixels
대응 전역 픽셀 Point2로 points와 개수가 같습니다.
unit
카메라 좌표 길이 단위입니다.
camera_frame
0이 아닌 카메라 프레임 ID입니다.

반환: 모델과 픽셀 RMS를 담은 TelecentricFit입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.
