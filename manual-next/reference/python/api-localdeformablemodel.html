find(self, source, options, mask=None, *, max_deformation_rate=None, photometric=False, robust=None, curvature=False)

거친 NCC 후보를 찾고 선택한 후보의 제어 격자를 국소 정밀화합니다.

확인된 인자 조건

source
검색 ZImage입니다.
options
LocalDeformableOptions입니다.
mask
선택 검색 마스크이며 기본값 None입니다.
max_deformation_rate
선택적 유한 비음수 인접 변위율 한계입니다.
photometric
밝기 gain/bias 보정 여부이며 기본값 False입니다.
robust
선택적 LocalDeformableRobustOptions입니다.
curvature
2차 차분 평활을 사용하며 기본값 False입니다.

반환: 결과가 없을 때도 거친 종료와 국소 상태를 담는 독립 LocalDeformableReport입니다.

오류: robust와 photometric은 함께 사용할 수 없습니다. curvature는 rate, photometric, robust와 함께 사용할 수 없습니다. 잘못된 입력·예산은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None
  • max_deformation_rate · KEYWORD_ONLY · 기본값 None
  • photometric · KEYWORD_ONLY · 기본값 False
  • robust · KEYWORD_ONLY · 기본값 None
  • curvature · KEYWORD_ONLY · 기본값 False

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Return detached result and diagnostics. curvature=True uses a second-difference penalty and cannot combine with rate, photometric or robust options.

template

mask
같은 크기·원점의 선택 Gray8 마스크입니다.

반환: 호출자가 닫아야 하는 독립 모델입니다.

오류: 템플릿, 기준점, 표본 간격 또는 마스크가 유효하지 않으면 오류입니다.

  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

sample_step: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Train from a grayscale ZImage and optional same-origin Gray8 mask.
