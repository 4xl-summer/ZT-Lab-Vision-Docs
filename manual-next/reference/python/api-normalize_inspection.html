Python API · normalize_inspection

normalize_inspection 멤버와 선언

공개 타입

zvision.normalize_inspection: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_normalization.normalize_inspection.

Return a GrayF64 normalized image. Excluded mask pixels are zero.

기준 밝기 분포에 맞춰 검사 영상을 정규화합니다.

Python
normalize_inspection(source, reference, options, mask=None)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

source
기준과 형식·크기·원점이 같은 검사 영상.
reference
정규화 목표 기준 영상.
options
InspectionNormalizationOptions의 방식·타일·꼬리 비율 및 작업 한도.
mask
선택적 같은 기하 Gray8 포함 마스크; None은 전체.

반환: 제외 픽셀은 0인 독립 소유 GrayF64 영상; close합니다.

오류: 잘못된 기하·형식·방식별 옵션 또는 작업 한도 초과는 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
