CircleMeasurementModel 멤버와 선언

공개 타입

zvision.CircleMeasurementModel: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.CircleMeasurementModel.

검증된 원 계측 설정을 소유하며 ROI 로컬 좌표를 사용한다.

영상 없이 원 기하와 탐침 설정을 검증하고 필터를 복사한 불변 모델을 만듭니다. 이후 measure(image)로 독립 결과를 얻습니다.

확인된 인자 조건

spec
MeasurementCircleSpec; ROI 로컬 픽셀 좌표와 라디안 각도.
options
MeasurementProbeOptions; 유효한 프로브·피팅 설정. 필터는 모델이 보유할 값으로 복사됨.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
