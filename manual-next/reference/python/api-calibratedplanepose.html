    사용 맥락과 계약

    CalibratedPlanePose는 평면 좌표계에서 카메라 좌표계로 가는 회전과 이동 및 두 진단값을 담습니다. rotation은 행 우선 3×3 회전이며 translation은 카메라 프레임에서 본 평면 원점입니다. 이동의 길이 단위는 사용한 평면 모델의 단위와 같습니다. orthogonality_error와 scale_error는 입력 열의 정규화와 크기 차이를 해석하는 데 사용합니다.

    구체 사례와 판독

    예를 들어 평면 원점의 위치가 카메라 좌표 (0,0,100) mm라면 translation의 Z는 100 mm로 읽습니다. 평면 위의 다른 점은 회전을 적용한 뒤 이동을 더해 카메라 좌표로 나타냅니다. 양의 원점 깊이만으로 평면 자세의 모든 모호성이 해소되는 것은 아니므로 실제 장면의 방향과 독립 검증점도 확인하세요. 픽셀 좌표와 이동량을 같은 단위로 비교하지 않습니다.

    적용 시 확인

    평면 좌표 (u,v,0)에 회전 행렬 R과 이동 벡터 t를 적용하면 카메라 좌표는 R·(u,v,0)+t입니다. 평면 원점은 u=v=0이므로 결과가 t가 됩니다. 예제는 좌표 변환 방향을 확인하는 손계산이며 실제 이미지의 픽셀 좌표는 렌즈 투영을 한 뒤에 얻습니다. 입력 단위와 회전 행렬의 배치를 전달하는 쪽과 일치시켜야 합니다.
