공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    trainedint필수점수 분모에 포함된 학습 탐침 수입니다. 제외된 탐침은 세지 않습니다.
    passedint필수측정 에지 쌍이 있고 대체 에지와 실패 플래그가 없는 포함 탐침의 수입니다.
    score_percentfloat필수100 × passed / trained로 계산한 통과 백분율입니다.
    acceptedbool필수점수가 지정한 승인 백분율 이상인지 나타냅니다.

    사용과 결과 해석

    학습에 포함된 비드 탐침 중 품질 조건을 통과한 비율을 백분율로 요약합니다. trained는 분모에 포함된 탐침 수이고 passed는 측정 에지 쌍이 있으며 대체 에지와 실패 플래그 없이 통과한 수입니다. 제외된 탐침은 분모에 넣지 않습니다.

    score_percent는 100×passed/trained입니다. 예를 들어 포함된 학습 탐침 10개 중 8개가 조건을 만족하면 점수는 80%입니다. accepted는 이 점수가 지정한 승인 백분율 이상인지 나타내며 경계를 포함합니다. 80%라는 점수 자체가 자동으로 모든 시스템의 합격 기준이 되는 것은 아닙니다.

    구간별 실패 사유와 대체 에지 여부는 점수 하나만으로 복원할 수 없습니다. 보고서의 탐침과 연속 실패 구간을 함께 확인하고 trained의 정의를 유지해 서로 다른 마스크나 제외 조건의 결과를 비교하십시오.
