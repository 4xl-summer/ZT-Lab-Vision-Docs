공개 타입

zvision.SurfaceDefectsQuery: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection.SurfaceDefectsQuery.

Base class for typed lazy inspection query terminals.

이 Query는 변경 가능한 계획입니다. 단계 추가는 같은 객체를 갱신하므로 별칭에도 반영됩니다. 분기하려면 clone()을 사용하고 execute()로 실행합니다. 실행과 Query는 각각 닫아야 합니다. 실패한 단계 추가는 기존 계획을 바꾸지 않습니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

사용과 결과 해석

SurfaceDefectsQuery는 결함 마스크와 점수 영상에서 표면 후보를 만드는 지연 실행 계획의 종단 타입입니다. 이미지 쿼리에서 surface_defects를 선택할 때 만들어지며, 후보 목록을 읽기 전 execute를 호출합니다. 마스크의 전경 연결 방식과 최소 면적 등은 지정한 DefectSpec에 따라 결정됩니다. 점수 영상은 마스크와 같은 크기와 원점을 가져야 하므로 다른 ROI의 영상을 혼합하지 않습니다.

execute가 돌려주는 실행에서 출력 자원을 획득하면 SurfaceDefectResult를 별도로 사용할 수 있습니다. 해당 결과에서 후보 배열을 읽고 필요하면 judge로 판정을 수행합니다. 후보를 추출하는 최소 면적과 제품 합격을 가르는 최종 판정 한도는 다른 설정입니다. 전경이 없어서 후보가 빈 결과와 입력 오류를 구별해야 합니다.

clone은 원래 계획을 바꾸지 않고 확장할 수 있는 독립 계획을 만듭니다. 만들어진 계획, 실행 및 획득한 소유 결과는 각각 사용이 끝나면 닫습니다. 하나의 핸들을 여러 스레드에서 동시에 해제해도 모든 작업이 성공한다는 보장은 이 사례에서 확인된 범위가 아닙니다.
