diagnose_advanced_shape 멤버와 선언

공개 타입

zvision.diagnose_advanced_shape: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._matching_advanced.diagnose_advanced_shape.

Compare a found shape pose with nearby compatible source edges.

찾은 형상 포즈를 주변의 호환 에지와 비교합니다.

Python
diagnose_advanced_shape(source, model, pose, min_gradient=0.0, radius=1, either_polarity=False)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_gradient · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • radius · POSITIONAL_OR_KEYWORD · 기본값 1
  • either_polarity · POSITIONAL_OR_KEYWORD · 기본값 False

확인된 인자 조건

source
검색할 ZImage입니다.
model
형상 AdvancedMatchModel입니다.
pose
진단할 AdvancedMatch 포즈입니다.
min_gradient
최소 검색 기울기이며 기본값 0입니다.
radius
근방 반경(픽셀)이며 기본값 1입니다.
either_polarity
반전 극성 허용 bool이며 기본값 False입니다.

반환: 모델 특징 일치, 에지 커버리지, 클러터와 적합 진단의 독립 값입니다.

오류: 유효하지 않은 입력, 모델 또는 지원하지 않는 설정은 오류입니다.

radius: 정수 검사 · 최소 0.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
