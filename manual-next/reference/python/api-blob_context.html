blob_context 멤버와 선언

공개 타입

zvision.blob_context: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_context.blob_context.

Create a reusable context with default 8-connectivity and index mode.

재사용할 Blob 분석 컨텍스트를 만듭니다.

Python
blob_context()

반환: 별도로 close할 BlobContext

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    재사용 가능한 분석 상태

    blob_context는 Blob 분석 설정과 현재 결과를 관리할 수 있는 재사용 컨텍스트를 만듭니다. 설정, 실행, 결과 읽기는 구별되는 단계입니다. 새 컨텍스트를 만들었다는 사실만으로 분석 결과가 이미 존재한다고 가정하지 않습니다.

    설정과 세대

    컨텍스트의 상태에는 성공한 계산의 generation, 마지막 계산 이후 기하 설정 변경 여부 dirty, 현재 결과 존재 여부 has_current가 있습니다. 설정을 바꾼 뒤 이전 결과를 새 설정의 결과로 오인하지 않도록 분석을 다시 수행하고 상태를 확인합니다.

    결과 읽기

    현재 결과의 항목은 label과 전경 픽셀 면적을 포함합니다. 레이블은 해당 결과의 성분을 가리키므로 다른 프레임의 같은 번호를 같은 물체로 간주하지 않습니다. 결과를 기록할 때 입력 영상, 설정과 계산 세대를 함께 남기면 재현에 도움이 됩니다.

    자원과 적용

    실제 호출 순서와 컨텍스트의 닫기 규칙은 해당 객체 메서드 계약을 따릅니다. 입력 영상의 ROI와 마스크가 바뀌면 분석 결과도 달라질 수 있습니다. 컨텍스트를 재사용한다는 것은 영상 분할이나 검사 품질이 자동 검증된다는 뜻이 아닙니다.
