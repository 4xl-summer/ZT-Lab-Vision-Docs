공개 타입

zvision.blob_context: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_context.blob_context.

Create a reusable context with default 8-connectivity and index mode.

재사용할 Blob 분석 컨텍스트를 만듭니다.
