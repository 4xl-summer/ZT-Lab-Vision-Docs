Python API · rectangle_pose_candidates

rectangle_pose_candidates 멤버와 선언

공개 타입

zvision.rectangle_pose_candidates: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.rectangle_pose_candidates.

Initialize one planar pose from ordered physical rectangle corners.

순서 있는 직사각형 꼭짓점으로 초기 평면 자세 후보를 계산합니다.

Python
rectangle_pose_candidates(corners, width, height, lens, ray_options, unit, target_frame, camera_frame)

인자 선언

  • corners · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • ray_options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_frame · POSITIONAL_OR_KEYWORD · 기본값 없음
  • camera_frame · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

corners
순서가 있는 4개 전역 픽셀 Point2입니다.
width
타깃의 양의 물리 너비입니다.
height
타깃의 양의 물리 높이입니다.
lens
LensModel 값입니다.
ray_options
역투영 반복에 사용할 RayOptions입니다.
unit
타깃 길이 단위입니다.
target_frame
0이 아닌 타깃 프레임 ID입니다.
camera_frame
0이 아닌 카메라 프레임 ID입니다.

반환: ShapePoseCandidates 값입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

width: 유한한 수 검사.

height: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
