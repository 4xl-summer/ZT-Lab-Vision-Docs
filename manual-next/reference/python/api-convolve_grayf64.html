zvision.convolve_grayf64: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._convolution_f64_gap.convolve_grayf64.

Return a finite GrayF64 ROI-preserving convolution result.

GrayF64로 2차원 커널을 적용합니다.

Python
