Python API · convert_similarity_measurement

convert_similarity_measurement 멤버와 선언

공개 타입

zvision.convert_similarity_measurement: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.convert_similarity_measurement.

Convert length or area under a uniform planar similarity in its world unit.

등방 평면 유사 변환으로 픽셀 길이 또는 면적을 환산합니다.

Python
convert_similarity_measurement(calibration, value, area=False)

인자 선언

  • calibration · POSITIONAL_OR_KEYWORD · 기본값 없음
  • value · POSITIONAL_OR_KEYWORD · 기본값 없음
  • area · POSITIONAL_OR_KEYWORD · 기본값 False

확인된 인자 조건

calibration
PlanarCalibration; 등방 유사 변환만 허용.
value
유한한 0 이상의 픽셀 길이 또는 픽셀² 면적.
area
bool; False(기본)는 길이, True는 면적.

반환: 세계 단위 길이 또는 세계 단위 제곱 면적 float.

오류: 비등방·전단·투영 변환, 음수 또는 비유한 값은 오류.

value: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    등방 평면 유사 보정에서 픽셀 길이 또는 픽셀 면적을 보정의 세계 단위로 환산합니다. calibration은 해당 조건을 만족하는 PlanarCalibration이고 value는 환산할 측정값입니다. area의 기본값은 False이며 면적을 환산할 때 True를 지정합니다. 등방 길이 배율이 0.1 mm/px라면 길이 20 px는 2 mm이고 면적 100 px²는 배율의 제곱을 적용하여 1 mm²입니다. 길이와 면적에 같은 배율을 한 번만 곱하면 면적 결과가 틀립니다. 이 변환은 한 값에 대한 스케일 환산으로, 임의의 원근 또는 축마다 다른 배율을 가진 평면 변환을 단일 길이 배율로 대체하지 않습니다. 보정이 허용하는 유사 변환 조건을 만족하지 않으면 오류를 처리하고 임의의 평균 배율을 만들어 결과를 표시하지 마십시오. 입력 측정이 길이인지 면적인지와 결과 단위를 함께 저장해야 숫자 2가 mm인지 mm²인지 구별할 수 있습니다. ROI 로컬 측정의 위치를 세계 좌표로 옮기는 작업은 이 스칼라 길이 환산과 구분해야 합니다. 동일한 배율에서 픽셀 길이가 두 배가 되면 세계 길이도 두 배가 됩니다. 픽셀 면적을 환산할 때에는 각 축에 길이 배율을 적용한다는 차원을 확인하십시오.
