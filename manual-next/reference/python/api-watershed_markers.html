watershed_markers 멤버와 선언

공개 타입

zvision.watershed_markers: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._regions_flexible.watershed_markers.

Assign GrayU32 markers by minimax paths; ties are dam or lowest label.

표고와 마커로 최소 최대 비용 경로의 라벨 분할을 수행합니다.

Python
watershed_markers(elevation, markers, connectivity, dam, work_budget)

인자 선언

  • elevation · POSITIONAL_OR_KEYWORD · 기본값 없음
  • markers · POSITIONAL_OR_KEYWORD · 기본값 없음
  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음
  • dam · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

elevation
표고 ZImage
markers
마커 라벨 ZImage
connectivity
연결성 4 또는 8
dam
bool; 동률 위치에 댐을 남길지 여부
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 라벨 영상

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

work_budget: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    표고와 시작 마커

    이 연산은 표고 영상과 마커 레이블을 이용해 여러 영역을 확장하는 분할입니다. 마커는 영역의 출발점이고 표고는 확장 과정에 쓰이는 값이므로 두 입력을 같은 영상이라고 가정하지 않습니다. 마커의 위치와 값이 바뀌면 같은 표고에서도 결과 영역이 달라질 수 있습니다.

    분할 설정

    연결성은 이웃 관계를 정합니다. dam 옵션은 영역이 만나는 위치의 처리를 선택하며 work_budget은 계산에 허용할 작업량 한도입니다. 물체가 서로 붙어 있을 때 각 물체에 해당하는 마커를 적절히 제공해야 분리 결과를 판단할 수 있으며, 이 함수가 원하는 마커를 자동으로 찾는다고 가정하지 않습니다.

    결과 확인

    표고와 마커가 같은 공간을 가리키는지 확인하고 둘의 정렬과 ROI를 맞춘 뒤 분할합니다. 결과의 레이블을 원 영상 위에 표시하여 마커가 의도한 물체에 들어갔는지, 경계가 예상 위치를 통과하는지 점검합니다. 마커 부족과 경계 설정의 문제는 결과만으로 구별하기 어려울 수 있어 입력도 함께 기록합니다.

    마커가 한 객체에 두 개 있거나 여러 객체에 하나뿐이면 원하는 분할 수와 결과가 다를 수 있습니다. 따라서 숫자로 영역 개수만 비교하지 말고 마커 영상과 레이블 경계를 함께 표시해 입력 단계의 문제를 확인합니다.
