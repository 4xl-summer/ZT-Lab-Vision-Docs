Python API · world_refit_circle_center_distance

world_refit_circle_center_distance 멤버와 선언

공개 타입

zvision.world_refit_circle_center_distance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._world_refit.world_refit_circle_center_distance.

Return world-unit center distance for two same-frame circle fits.

동일 세계 프레임과 단위의 두 원 중심 간 거리를 계산합니다.

Python
world_refit_circle_center_distance(a, b)

인자 선언

  • a · POSITIONAL_OR_KEYWORD · 기본값 없음
  • b · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

a
첫 원 WorldRefit 값입니다.
b
둘째 원 WorldRefit 값입니다.

반환: 공통 세계 길이 단위의 거리 float입니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    이 함수는 월드 좌표에 맞춘 두 원의 중심 간 거리를 구합니다. 두 입력 모두 원 종류의 WorldRefit 스냅샷이어야 하며 프레임 식별자는 서로 같고 0이 아니어야 합니다. 길이 단위도 같아야 하므로 서로 다른 단위의 결과를 단순히 숫자로 비교하지 마십시오. 예를 들어 같은 평면에 대한 두 보정 결과라도 단위나 프레임을 다르게 지정했다면 먼저 동일한 좌표계로 결과를 다시 구성해야 합니다.

    원 반경이 아니라 각 결과의 중심 좌표 두 성분을 사용합니다. 중심이 (1, 2)와 (4, 6)이라면 x 차이 3과 y 차이 4에서 유클리드 거리는 5가 됩니다. 두 결과의 길이 단위가 밀리미터라면 반환값도 5 mm입니다. 크기가 다른 원이어도 중심이 같으면 이 거리는 0이며, 원과 원의 가장자리 사이 간격과는 다릅니다.

    결과는 독립적인 숫자이며 입력 스냅샷을 수정하지 않습니다. 직선 결과를 전달하거나 프레임 또는 길이 단위가 일치하지 않으면 비교를 거부합니다. 중심에서 유한한 거리를 계산할 수 없는 경우도 오류입니다. 판정 임계값을 적용할 때는 이 값이 중심 간 거리라는 점과 양쪽 적합의 잔차·수렴 상태를 함께 확인하십시오.
