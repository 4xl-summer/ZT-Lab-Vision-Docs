Python API · diagnose_spatial_pnp

diagnose_spatial_pnp 멤버와 선언

공개 타입

zvision.diagnose_spatial_pnp: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial_pnp.diagnose_spatial_pnp.

Return typed initialization outcome, including no-pose failures.

Pointer/format exceptions remain exceptions. Rank ratios are None until computed.

자세를 얻지 못한 경우도 단계별 진단으로 반환합니다.

Python
diagnose_spatial_pnp(target, pixels, lens, unit, target_frame, camera_frame, options=SpatialPnpOptions(ray_iterations=32, ray_tolerance=1e-09, refine_iterations=30, tolerance=1e-09, max_work=10000000))

인자 선언

  • target · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_frame · POSITIONAL_OR_KEYWORD · 기본값 없음
  • camera_frame · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 SpatialPnpOptions(ray_iterations=32, ray_tolerance=1e-09, refine_iterations=30, tolerance=1e-09, max_work=10000000)

확인된 인자 조건

target
타깃 frame의 유한 Point3 시퀀스; pixels와 같은 길이; 최대 4096점
pixels
관측된 글로벌 픽셀 Point2 시퀀스; target과 순서대로 대응
lens
알려진 카메라 LensModel
unit
타깃 좌표와 출력 이동에 사용할 LengthUnit
target_frame
0이 아닌 타깃 좌표계 ID
camera_frame
0이 아니고 target_frame과 다른 카메라 좌표계 ID
options
SpatialPnpOptions: 역왜곡·정련 반복과 허용값 및 작업 한도; 기본 생성값 사용

반환: SpatialPnpOutcome 값; 실패 시 estimate가 None일 수 있습니다.

오류: Python 변환·타입 및 0인 frame·옵션 오류는 예외이며 알고리즘 단계 실패는 outcome으로 보고합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
