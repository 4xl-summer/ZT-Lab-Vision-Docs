공개 타입

Return the inverse of a validated proper rigid transform.

검증된 강체 변환의 역변환을 구합니다.

Python

확인된 인자 조건

value
회전, 이동, 단위 및 프레임을 포함한 RigidTransform3

반환: 역방향 강체 변환 값

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    inverse_rigid3는 강체 변환의 출발점과 도착점을 바꾸는 역변환을 계산합니다. 원본이 A에서 B로 가는 변환이면 결과는 B에서 A로 갑니다. 회전의 역은 전치 행렬이고 이동의 역은 회전을 고려해 계산되므로 이동 벡터의 부호만 바꾸는 방식은 일반적인 회전이 있을 때 올바르지 않습니다.

    구체 사례와 판독

    예를 들어 회전 없이 (10,5,0)을 더하는 변환의 역은 (-10,-5,0)을 더합니다. 하지만 회전이 함께 있다면 역이동은 -Rᵀt입니다. 한 점을 원래 변환한 다음 역변환하면 수치 오차 범위에서 원점으로 돌아오는지 확인할 수 있습니다. 좌표의 길이 단위는 변환 전후에 같으며 역변환이 단위 변환을 대신하지 않습니다.

    적용 시 확인

    계산 검증에는 임의의 원점 하나뿐 아니라 원점에서 떨어진 점도 사용하세요. 원점만 맞는 경우에도 회전 방향이 틀릴 수 있습니다. 예를 들어 (1,0,0)과 (0,1,0)을 각각 변환하고 되돌리면 두 축 방향까지 비교할 수 있습니다. 부동소수 계산의 작은 오차는 허용 공차를 정해 판정합니다. 출발과 도착을 뒤집은 결과는 원래 변환과 다른 용도에 사용됩니다. 실제 카메라에서 로봇으로 갈지 로봇에서 카메라로 갈지 먼저 정하세요. 적용 순서도 확인하세요.
