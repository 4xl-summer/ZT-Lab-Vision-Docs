    영역에서의 평균 배율

    RegionalScale은 전역 픽셀 사각형에서 표본화한 면적 등가 길이 배율 mean_length와 면적 배율 mean_area를 보관합니다. 각 표본의 변환 야코비안 J에 대해 길이 배율은 √|det J|, 면적 배율은 |det J|를 사용해 각각 평균한 값입니다.

    간단한 배율 예

    모든 표본에서 |det J|가 4라면 면적 배율의 평균은 4이고 면적 등가 길이 배율의 평균은 2입니다. 표본마다 값이 다르면 √의 평균과 평균의 √는 일반적으로 같지 않으므로 mean_length를 무조건 √mean_area로 계산하지 않습니다.

    영역과 단위

    x, y, width, height는 표본을 취한 전역 픽셀 사각형을 나타내고 samples는 사용된 표본 수, unit은 보정의 길이 단위입니다. ROI 로컬 좌표와 전역 좌표를 혼용하지 말고 결과에 기록된 범위를 확인합니다.

    근사의 범위

    이 값은 영역 전체의 평균적인 면적 등가 배율입니다. 방향에 따라 배율이 다르거나 투영이 위치마다 달라지는 경우 모든 선분의 정확한 길이를 하나의 평균값으로 보장하지 않습니다. 필요한 정확도는 실제 보정과 대상 위치에서 별도 검증합니다.
