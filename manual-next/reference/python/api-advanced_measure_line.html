공개 타입

zvision.advanced_measure_line: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._advanced_probe_model.advanced_measure_line.

Measure line with optional maximum spacing and inlier coverage; clipping is always reported.

간격과 관측 범위를 선택적으로 적용하여 계측합니다.
