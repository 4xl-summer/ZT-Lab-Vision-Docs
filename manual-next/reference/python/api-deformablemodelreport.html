    사용 맥락과 결과 해석

    변형 모델 은행 전체에서 얻은 매치 튜플과 평가 수, 검색 종료 이유를 담습니다. 각 결과의 variant_index는 학습 입력 변형 목록의 0 기반 위치입니다. matches가 비어도 보고서는 존재할 수 있으며 이때 종료 이유를 읽어 모든 후보를 완료했는지 예산이나 시간 제한에 걸렸는지 분리해야 합니다.

    은행의 각 변형은 별도 NCC 모델로 검색되지만 후보 예산과 시간은 은행 전체에서 공유됩니다. 앞쪽 변형이 많은 예산을 사용하면 뒤쪽이 충분히 평가되지 않을 수 있습니다. 반환 결과는 독립 스냅샷이지만 검색의 재현을 위해 변형 순서, 포즈 격자와 예산을 함께 기록하세요. 결과 점수는 모델 일치도이지 실제 물체의 변형을 연속적으로 측정한 수치가 아닙니다.

    값을 확인하는 순서

    matches 항목: 변형 모델 검색의 독립 불변 결과 튜플입니다. evaluated 항목: 전체 모델 은행에서 평가한 포즈 수입니다. termination 항목: 완료, 후보 예산, 시간 제한, 조기 점수 중 종료 이유입니다.

    항목읽을 때 확인할 내용
    matches변형 모델 검색의 독립 불변 결과 튜플입니다.

    termination완료, 후보 예산, 시간 제한, 조기 점수 중 종료 이유입니다.
