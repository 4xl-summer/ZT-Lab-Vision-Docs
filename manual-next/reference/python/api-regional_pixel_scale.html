regional_pixel_scale 멤버와 선언

공개 타입

zvision.regional_pixel_scale: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.regional_pixel_scale.

Average sqrt(abs(det J)) and abs(det J) at regular rectangle cell centers.

영역 표본에서 면적 등가 길이 및 면적 배율을 평균합니다.

Python
regional_pixel_scale(calibration, x, y, width, height, nx, ny)
