공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    xfloat필수방향 외접 사각형의 로컬 중심 x입니다.
    yfloat필수방향 외접 사각형의 로컬 중심 y입니다.
    widthfloat필수첫 번째 축의 길이(픽셀)입니다.
    heightfloat필수직교 축의 길이(픽셀)입니다.
    anglefloat필수첫 번째 축의 각도(라디안)입니다.

    방향을 지정한 외접 사각형

    BlobAngleBox는 ROI 로컬 중심 x, y와 첫 축의 길이 width, 직교 축의 길이 height, 첫 축의 angle을 담습니다. 각도 단위는 라디안입니다. 축에 평행한 일반 경계 상자와 달리 지정한 방향의 두 축을 기준으로 블롭을 감쌉니다.

    축과 반길이

    예를 들어 중심이 (10,20), width가 6, height가 2라면 중심에서 두 축 방향의 반길이는 각각 3과 1입니다. angle이 0이면 첫 축은 기준 방향을 따릅니다. 같은 중심과 크기라도 각도를 바꾸면 네 꼭짓점의 위치는 달라집니다.

    결과 사용

    blob_angle_box 호출에 선택한 성분과 방향을 전달한 뒤 반환된 중심과 두 길이를 이용해 사각형을 표시합니다. ROI 로컬 중심을 전체 영상에 올릴 때는 원점을 적용합니다. 사각형 내부에 배경이나 구멍이 없다는 뜻은 아닙니다.

    측정 조건

    이 결과는 주어진 각도에서의 외접 사각형입니다. 방향을 지정했다는 사실과 모든 가능한 방향에서 최적의 사각형을 자동으로 찾았다는 주장은 다릅니다. 각도와 픽셀 보정 조건을 비교 대상마다 동일하게 관리합니다.
