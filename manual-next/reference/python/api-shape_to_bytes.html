Python API · shape_to_bytes

shape_to_bytes 멤버와 선언

공개 타입

zvision.shape_to_bytes: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.shape_to_bytes.

Serialize a shape model into its own versioned checksum-protected format.

형상 모델을 버전과 체크섬을 포함한 아카이브로 직렬화합니다.

Python
shape_to_bytes(model)

인자 선언

  • model · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

model
형상 AdvancedMatchModel입니다.

반환: 모델과 독립된 bytes입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    형상 모델을 해당 SDK의 버전 있는 체크섬 보호 아카이브 바이트로 복사합니다. 인자는 열린 형상 AdvancedMatchModel이며 결과 bytes는 모델을 닫은 뒤에도 독립적으로 보관할 수 있습니다. 체크섬은 우발적 손상 검출을 위한 것으로 인증이나 외부 제품 형식과의 호환을 의미하지 않습니다.

    복원할 때는 shape_from_bytes를 사용해 별도 소유 모델을 얻고, 그 모델 역시 사용 후 닫습니다. 저장 매체의 쓰기 권한과 버전 관리는 호출자의 책임입니다. 모델이 열려 있지 않거나 다른 종류라면 오류이며, 바이트 생성에 성공했다는 사실만으로 특정 영상에서의 검출 품질이 증명되지는 않습니다. 기준 검색 조건과 검증 입력을 따로 보관하세요.

    모델이 다른 템플릿에서 만들어졌는지 확인하려면 바이트 길이만 비교해서는 부족합니다. 복원한 뒤 같은 입력과 검색 설정으로 기준 결과를 비교하고, 학습 데이터와 설정의 식별자를 애플리케이션에 보관하세요.
