    사용과 결과 해석

    SpatialPnpOutcome은 비평면 자세 초기화의 성공 또는 실패 단계를 값으로 전달합니다. estimate가 있으면 타깃에서 카메라로 가는 자세와 픽셀 RMS, 반복 및 정련 종료 상태를 볼 수 있습니다. 실패 시 estimate는 None이 될 수 있고 failure는 관측, 기하 랭크, DLT 식별성, Brown 역왜곡, 깊이 조건, 예산 또는 수치 단계 중 어디에서 실패했는지 구분합니다.

    point_count는 입력한 3D 대응점의 수이고 failed_index는 해당 단계에서 특정 점을 기록했을 때만 제공됩니다. geometry_rank_ratio와 dlt_rank_ratio도 실제로 계산되기 전에는 None입니다. 예를 들어 점들이 한 평면에 몰린 입력은 비평면 기하 조건을 만족하지 못할 수 있으므로 결과가 없을 때 None을 0 오차로 바꾸면 안 됩니다. 타입이나 포인터 형식 등의 호출 오류는 outcome과 별개의 예외로 처리하고, 성공한 자세도 독립 보류점으로 평가합니다.
