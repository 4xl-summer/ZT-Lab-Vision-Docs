    사용과 결과 해석

    고급 렌즈 정련에서 바꿀 계수와 반복 종료 조건을 지정합니다. optimize_mask의 비트는 fx, fy, cx, cy, k1, k2, k3, p1, p2 순서의 내부 및 왜곡 계수에 대응하며 선택하지 않은 계수는 입력 모델의 값을 유지합니다. max_iterations는 반복 상한, tolerance는 수렴 판단 기준, damping은 정련 단계의 감쇠 설정입니다. 입력 광선과 관측 픽셀이 정확히 대응하고 초기 렌즈 모델의 좌표계가 일치해야 결과를 해석할 수 있습니다. 일부 계수만 선택하는 것은 알려진 값을 고정하는 방법이지 해당 계수가 실제로 정확하다는 증명은 아닙니다. 결과에서는 픽셀 재투영 RMS뿐 아니라 반복 수와 수렴 플래그를 함께 보십시오. 유효하지 않은 숫자나 식별하기 어려운 점 배치는 오류가 될 수 있으며, 학습에 사용하지 않은 관측으로 별도 평가하는 편이 좋습니다. 최적화할 계수를 달리한 실험에서는 초기 모델과 대응점, 반복 기준을 고정해야 선택한 계수의 영향을 비교할 수 있습니다. 카메라의 이미지 크기나 좌표 기준이 바뀌었다면 이전 모델의 숫자를 그대로 재사용하기 전에 입력 좌표와 모델의 의미가 일치하는지 검토하십시오. 정련이 종료되었다는 사실과 수렴 여부도 구별합니다.
