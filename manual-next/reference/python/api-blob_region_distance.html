Python API · blob_region_distance

blob_region_distance 멤버와 선언

공개 타입

zvision.blob_region_distance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_region_distance.blob_region_distance.

Return nearest four-neighbor boundary pixel centers; origins must match.

두 영역의 4이웃 경계 픽셀 중심 사이 최근접점을 찾습니다.

Python
blob_region_distance(first, second, work_budget)

인자 선언

  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • second · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

first
첫 Gray8 영역 마스크
second
둘째 Gray8 영역 마스크; 크기와 원점 일치
work_budget
양의 정수 작업량 상한

반환: BlobRegionDistance 값

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
