blob_region_distance 멤버와 선언

공개 타입

zvision.blob_region_distance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_region_distance.blob_region_distance.

Return nearest four-neighbor boundary pixel centers; origins must match.

두 영역의 4이웃 경계 픽셀 중심 사이 최근접점을 찾습니다.

Python
blob_region_distance(first, second, work_budget)

  • second · POSITIONAL_OR_KEYWORD · 기본값 없음

공개 멤버

    영역 경계의 최근접 쌍

    blob_region_distance는 두 Gray8 영역 마스크의 4이웃 경계 픽셀 중심 사이에서 최근접 쌍을 찾습니다. 각 마스크의 전경 형태와 경계가 계산의 대상이며 영역 중심 간 거리나 윤곽 선분 간 최단 거리와는 정의가 다릅니다.

    입력 조건

    first와 second는 크기와 원점이 일치하는 마스크여야 합니다. 같은 숫자 좌표가 실제로 같은 영상 위치를 뜻해야 두 영역 사이 거리를 해석할 수 있습니다. work_budget에는 양의 정수 상한을 지정하고 형식과 ROI 조건도 호출 전에 확인합니다.

    결과 계산 예

    반환된 두 경계 중심이 (1,2), (4,6)이면 그 차이는 (3,4)이고 거리 값은 5픽셀입니다. 출력 좌표와 거리를 함께 확인하면 선택된 위치를 원본 마스크에 표시할 수 있습니다. 결과는 픽셀 중심 거리이므로 셀 모서리 사이의 간격과 혼동하지 않습니다.

    단위와 검증

    물리 거리를 얻으려면 영상의 보정과 픽셀 간격을 고려해야 합니다. 마스크를 임계 처리하거나 형태학으로 바꾸면 경계 위치가 이동하므로 그 전후 결과를 비교할 때 입력 마스크도 함께 기록합니다.

    좌표를 표시하면 서로 가까운 두 경계가 실제로 선택됐는지 육안으로 대조할 수 있습니다. 원본에서 경계의 일부가 잘려 있다면 이 거리 역시 보이는 영역만을 기준으로 합니다.
