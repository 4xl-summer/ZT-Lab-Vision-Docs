zvision.RayOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.RayOptions.

Local Brown inverse iteration limit (1–1024) and positive pixel tolerance.

Brown 렌즈 역투영의 반복과 수렴 허용치를 지정합니다.

Python
RayOptions(max_iterations=32, pixel_tolerance=1e-09)

인자 선언

  • max_iterations · POSITIONAL_OR_KEYWORD · 기본값 32
  • pixel_tolerance · POSITIONAL_OR_KEYWORD · 기본값 1e-09

확인된 인자 조건

max_iterations
1–1024 정수이며 기본값은 32입니다.
pixel_tolerance
유한한 양의 픽셀 오차 허용치이며 기본값은 1e-9입니다. 양수 조건은 연산에서 검증합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

사용 맥락과 계약

RayOptions는 왜곡된 영상 좌표에서 카메라 광선 방향을 구할 때 반복 계산의 한계와 수렴 기준을 지정합니다. max_iterations의 기본값은 32이고 유효 범위는 1부터 1024까지이며 pixel_tolerance 기본값은 1e-9 픽셀입니다. 허용 오차는 양수여야 합니다. 이 값은 실제 카메라의 보정 정확도나 관측 잡음을 나타내지 않습니다.

구체 사례와 판독

예를 들어 최대 반복 수가 32이면 계산이 수렴하지 않아도 그 한계를 넘어 무한히 계산하지 않습니다. 반환된 RayResult의 converged와 residual_pixels를 확인하고, 수렴하지 않았다면 방향을 확정된 측정값으로 사용하지 마세요. 허용 오차를 엄격하게 만든다고 보정 모델이 표현하지 못한 실제 렌즈 오차까지 없어지는 것은 아닙니다.

적용 시 확인

수렴 판정의 기준은 영상면에서 다시 계산한 픽셀 차이입니다. 반복 횟수를 줄이면 계산 시간이 줄 수 있지만 어려운 점에서 허용 오차에 도달하지 못할 수 있습니다. 반대로 횟수를 늘리더라도 잘못된 렌즈 계수가 자동으로 수정되지는 않습니다. 결과와 함께 반복 수, 잔차, 렌즈 설정을 기록해 실패가 특정 위치에 집중되는지 확인하세요. 광각 영상의 가장자리처럼 왜곡이 큰 위치도 검증점에 포함하는 편이 좋습니다.
