    전경 내부의 사각형

    BlobInnerRectangle은 전경에 완전히 포함되는 축 정렬 최대 픽셀 사각형의 ROI 로컬 x, y, width, height를 나타냅니다. 외접 경계 상자와 반대로 내부가 전경으로 채워진 사각형을 설명합니다. 오목한 모양이나 구멍이 있으면 외접 사각형과 크기가 다를 수 있습니다.

    셀의 크기

    예를 들어 전경 안에 폭 3, 높이 2인 사각형이 들어간다면 그 사각형은 6개 픽셀 셀을 차지합니다. 반환된 width와 height는 셀 수이므로 좌표 차이를 계산할 때 시작과 끝의 포함 규칙을 혼동하지 않습니다. 전체 성분 면적이 6이라는 뜻도 아닙니다.

    사용 순서

    이진 마스크에서 blob_inner_rectangle을 실행하고 결과가 나타내는 사각형을 동일 ROI 위에 겹쳐 봅니다. 다른 ROI나 전체 영상에 그리려면 시작점에 원점 변환이 필요합니다. 사각형은 축에 정렬되므로 회전한 물체의 방향을 따라가는 회전 사각형과 구별해야 합니다.

    측정의 범위

    이 값은 픽셀 격자에서의 내부 영역이며 물리 단위의 최대 사각형을 자동으로 계산하지 않습니다. 보정이나 비등방 픽셀 간격이 중요한 경우 해석에 필요한 좌표 변환을 따로 고려합니다.
