Python API · rectify

rectify 멤버와 선언

공개 타입

zvision.rectify: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.rectify.

Return two independently owned images: rectified result and complete-footprint validity mask.

월드 평면의 정렬 영상과 유효 마스크를 생성합니다.

Python
