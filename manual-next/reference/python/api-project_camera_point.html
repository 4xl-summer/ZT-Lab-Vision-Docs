project_camera_point 멤버와 선언

공개 타입

zvision.project_camera_point: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.project_camera_point.

Project a positive-Z camera-space point to a distorted global pixel.

양의 Z 카메라 좌표를 왜곡된 전역 픽셀에 투영합니다.

Python
project_camera_point(lens, point)

인자 선언

  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • point · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

lens
LensModel
point
카메라 좌표계의 3D 점, Z>0

반환: 투영 픽셀 결과

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    project_camera_point는 카메라 좌표계의 3차원 점을 렌즈 모델에 따라 영상 픽셀로 투영합니다. 점은 카메라 프레임으로 이미 변환되어 있어야 하며 깊이 Z가 양수인 점을 사용합니다. 월드 프레임의 좌표를 그대로 전달하면 숫자가 유효해 보여도 카메라 위치와 방향이 반영되지 않아 잘못된 픽셀이 나올 수 있습니다.

    구체 사례와 판독

    왜곡이 없는 핀홀 모델에서 점 (0,0,Z)가 Z 양수이면 투영은 주점에 놓입니다. X를 두 배로 하거나 Z를 절반으로 하면 정규화된 X/Z는 두 배가 되어 주점에서 가로로 더 멀어집니다. 실제 픽셀은 초점 거리와 주점 및 렌즈 계수도 반영합니다. 결과를 관측 픽셀과 비교할 때 같은 영상 좌표계와 ROI 원점을 사용하는지 확인하세요.

    적용 시 확인

    한 점을 투영한 결과가 영상 범위 바깥에 있을 수 있습니다. 양의 깊이를 가진다는 조건은 화면 안에 보인다는 조건과 같지 않으므로 출력 좌표를 영상 크기와 별도로 비교하세요. 관측 픽셀과 차이를 계산할 때는 두 좌표 모두 전체 영상 기준인지 또는 같은 ROI 기준인지 명시합니다. 실제 왜곡이 있는 렌즈에서는 단순 핀홀 손계산과 결과가 달라질 수 있습니다. 보정된 렌즈와 점의 좌표 프레임을 변경했다면 새 조건에서 다시 확인하세요.
