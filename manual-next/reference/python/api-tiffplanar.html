사용 맥락과 계약

TiffPlanar는 다중 채널 TIFF에서 채널 샘플을 파일에 배치하는 방식을 지정합니다. CHUNKY는 한 픽셀의 채널을 모아 기록하고 SEPARATE는 채널별 평면으로 구분합니다. save_tiff_pages의 planar 인자로 사용하며 기본값은 CHUNKY입니다. 이것은 각 픽셀의 색을 바꾸는 색 변환이나 공간 좌표 변환이 아닙니다.

구체 사례와 판독

예를 들어 두 RGB 픽셀이 (R1,G1,B1), (R2,G2,B2)라면 개념적으로 CHUNKY는 R1,G1,B1,R2,G2,B2의 묶음이며 SEPARATE는 R1,R2 다음에 G와 B 평면을 둡니다. 실제 파일에는 형식의 헤더와 스트립 등의 구조도 포함되므로 이 순서를 파일 전체 바이트 배열로 단정해서는 안 됩니다. 저장 후 대상 판독기로 채널과 색을 확인하세요.

적용 시 확인

입력 영상의 메모리 배치와 출력 TIFF의 평면 배치를 같은 개념으로 취급하지 마세요. 파일을 읽는 쪽의 지원 여부를 확인합니다. 예제의 두 픽셀은 배치 순서를 설명하기 위한 것입니다. 단일 채널 영상에서는 채널을 분리하더라도 여러 색 평면이 새로 생기지 않습니다. 하나의 픽셀을 색상 순서대로 해석하는 일과 저장 시 샘플을 그룹화하는 일은 구별합니다.
