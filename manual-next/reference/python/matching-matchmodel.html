find

Python
find(self, image: zvision.ZImage, spec: zvision._matching.MatchSpec) -> zvision._matching.MatchResult

학습 모델로 영상의 보이는 ROI에서 포즈를 검색합니다.

확인된 인자 조건

image
검색할 Gray8, Gray16 또는 유한 GrayF32 영상입니다.
spec
각도와 배율 격자, 임계 점수, 거리 및 결과 수 설정입니다.

반환: 영상과 모델이 닫힌 뒤에도 유효한 독립 MatchResult입니다.

오류: 형식, 픽셀 또는 설정이 유효하지 않으면 오류입니다. 후보가 없으면 빈 결과입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision.ZImage'> · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision._matching.MatchSpec'> · 기본값 없음

반환 타입 주석: <class 'zvision._matching.MatchResult'>

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Search image with this model and return an independent snapshot.

Positions, scores, ordering, and errors follow the existing direct search.
The returned snapshot remains valid after the image or model is closed.
