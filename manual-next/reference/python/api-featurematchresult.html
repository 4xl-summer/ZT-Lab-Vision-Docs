    사용 맥락과 결과 해석

    특징점 검색의 검출점, 대응쌍, 선택적 변환 행렬과 기하 검증 진단을 복사한 결과입니다. source_points는 검색 영상 측 점이고 pairs는 모델과 검색 영상 사이의 대응입니다. matrix가 있으면 모델 로컬에서 검색 영상 로컬로 가는 3×3 행 우선 변환이며, 적합이 되지 않으면 None입니다.

    먼저 matrix 존재 여부와 inlier_count를 확인한 뒤 개별 대응점의 잔차를 살펴보세요. evaluated는 평가된 RANSAC 가설의 수로 실제 물체의 개수가 아닙니다. 충분한 대응이나 적절한 기하 배치가 없으면 실행이 성공해도 변환이 없을 수 있습니다. 점과 대응은 불변 튜플이므로 결과를 만든 영상이나 모델을 닫은 후에도 복사된 값을 읽을 수 있습니다.

    값을 확인하는 순서

    source_points 항목: 검색 영상에서 검출된 특징점의 불변 튜플입니다. pairs 항목: 모델과 검색 영상 간 대응점의 불변 튜플입니다. matrix 항목: 추정된 3×3 변환 행렬의 값 튜플이며 추정하지 못하면 None입니다. inlier_count 항목: 추정된 기하 변환의 내점 수입니다. evaluated 항목: 평가된 RANSAC 가설 수입니다.
