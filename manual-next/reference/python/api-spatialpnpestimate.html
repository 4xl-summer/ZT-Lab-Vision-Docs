    사용과 결과 해석

    SpatialPnpEstimate는 알려진 카메라와 비평면 3D–2D 대응에서 구한 타깃→카메라 강체 자세와 진단입니다. pose의 from_frame은 타깃, to_frame은 카메라이며 이동은 입력에 지정한 길이 단위를 따릅니다. initial_rms_pixels는 DLT 초기 자세의 재투영 RMS, rms_pixels는 선택적 정련 후 RMS입니다. 두 값은 3D 길이가 아니라 이미지 픽셀 오차입니다.

    iterations와 evaluations는 정련에서 사용한 반복과 평가를, termination은 미요청·수렴·반복 상한·진행 불가를 나타냅니다. 예를 들어 초기 RMS가 2 px이고 최종이 0.5 px이면 해당 대응의 재투영 오차가 줄었다는 뜻이지만 독립 점의 정확도나 전역 최적이 자동으로 보장되지는 않습니다. 대응점의 프레임과 모델을 기록하고 수렴 상태와 보류점 오차를 함께 평가합니다. 퇴화 또는 카메라 뒤쪽 깊이 등 실패는 진단 outcome으로 구분할 수 있습니다.
