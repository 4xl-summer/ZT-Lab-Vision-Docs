    사용 조건과 흐름

    VariationOptions는 0.1.x에서 유지되는 VariationInspectOptions의 이전 이름입니다. 어두운 방향과 밝은 방향 각각의 절대 허용치와 편차 배수, 편차 하한을 담으며 다섯 값은 유한하고 0 이상이어야 합니다. 새 코드에서는 VariationInspectOptions 이름을 사용하면 검사 옵션의 용도가 명확합니다.

    구체 사례와 결과 판독

    학습 평균이 100, 편차가 2이고 밝은 방향 절대 허용치가 5, 편차 배수가 3이면 허용치는 max(5,3×2)=6입니다. 따라서 위쪽 경계는 106입니다. 어두운 방향은 low 값을 사용해 별도로 계산하며 편차가 하한보다 작으면 하한을 사용합니다. 양방향의 설정과 검사 영상의 밝기 단위를 일치시키세요.

    적용 시 확인

    두 이름은 동일한 옵션 클래스의 호환 별칭입니다. 기존 데이터를 읽을 때 이전 이름이 보일 수 있으며 새 코드에서 값의 의미가 바뀐 것은 아닙니다. 편차가 0에 가까울 때 하한을 쓰는 이유와 방향별 한계를 함께 확인하세요. 예를 들어 학습 편차 0.5에 하한 1을 정하면 배수 계산에는 1이 사용됩니다. 지나치게 작은 정상 편차가 검사 허용치를 불필요하게 좁히는 상황을 제어할 수 있습니다. 실제 기준은 검증 영상으로 정하세요.
