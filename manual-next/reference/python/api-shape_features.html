Python API · shape_features

shape_features 멤버와 선언

공개 타입

zvision.shape_features: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.shape_features.

Copy model features as tuples (x, y, nx, ny); contour connectivity is not retained.

학습된 형상 특징점을 복사합니다.

Python
shape_features(model)

인자 선언

  • model · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

model
형상 AdvancedMatchModel입니다.

반환: 기준점 상대 로컬 좌표와 방향인 (x, y, nx, ny) 튜플들의 독립 튜플입니다. 원래 contour 연결은 포함하지 않습니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    학습된 형상 모델의 특징을 (x,y,nx,ny) 튜플로 복사합니다. 위치는 기준점 상대의 모델 로컬 픽셀 좌표이고 nx,ny는 특징 방향 성분입니다. 반환 튜플은 모델 핸들과 독립적이며 원래 contour의 점 연결 관계는 보존하지 않습니다.

    모델이 기대 영역에서 학습되었는지 확인할 때 특징 위치와 방향을 시각적으로 살펴볼 수 있습니다. 다만 튜플 하나가 영상의 완전한 외곽선이나 검출된 검색 결과를 뜻하지는 않습니다. 형상 모델이 아니거나 닫힌 모델을 전달하면 오류이며, 검색 성능은 특징 목록 자체 외에 검색 영상의 에지와 설정으로 평가해야 합니다.

    원점 기준을 잘못 놓으면 같은 특징도 다른 템플릿 좌표처럼 보입니다. 튜플의 앞 두 값은 위치, 뒤 두 값은 방향이며 각각 다른 의미를 가집니다. 반환된 내용을 파일로 저장한다면 모델 버전과 기준점도 같이 보관합니다.

    값을 확인하는 순서

    model 항목: 형상 AdvancedMatchModel입니다.
