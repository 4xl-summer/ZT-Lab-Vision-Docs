blob_cleanup 멤버와 선언

공개 타입

zvision.blob_cleanup: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_cleanup.blob_cleanup.

Fill small holes, optionally open with 3x3 square, then remove small components.

작은 구멍 채우기, 선택적 3×3 열기, 작은 성분 제거를 순서대로 수행합니다.

Python
blob_cleanup(image, connectivity, max_hole_area, open_three, min_component_area, work_budget)

확인된 인자 조건

image
ZImage 입력 영상
connectivity
연결성 4 또는 8
max_hole_area
채울 최대 구멍 면적(픽셀)
open_three
bool; 3×3 열기 적용 여부
min_component_area
유지할 최소 성분 면적(픽셀)
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 Gray8 영상

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
