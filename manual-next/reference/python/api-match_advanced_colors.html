공개 타입

zvision.match_advanced_colors: 패키지 속성으로 접근 가능하지만 __all__에는 없습니다. 선언 출처: zvision._naming_advanced_color.match_advanced_colors.

Find the nearest reference per pixel using a typed color distance.

Python
match_advanced_colors(self, samples, metric)

인자 선언

  • samples · POSITIONAL_OR_KEYWORD · 기본값 없음
  • metric · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    ZImage에 대해 Lab 기준 색 목록과 타입 지정 ColorDistance로 픽셀마다 가장 가까운 기준 색을 찾습니다. samples는 비어 있지 않은 LabColor 시퀀스이고 metric은 거리 방식 및 필요한 계수를 담습니다. 반환된 AdvancedMatches와 그로부터 얻은 인덱스·거리 영상은 각각 소유권에 따라 닫아야 합니다.

    반환 인덱스는 입력 기준 색의 순서에 대응하므로 목록의 순서를 바꾸면 같은 인덱스의 의미도 바뀝니다. 거리값은 선택한 색차 방식의 결과이며 매칭 확률이 아닙니다. 이미지 형식과 기준 색, 거리 계수가 유효하지 않으면 오류로 처리합니다. 거리 임계값을 품질 판정에 쓸 때는 선택한 방식과 조명·색상 조건을 함께 검증해야 합니다.

    두 기준 색의 거리가 같은 경우 어떤 인덱스가 선택되었는지까지 필요하다면 해당 입력으로 별도 검증하세요. 인덱스 영상과 거리 영상은 서로 다른 결과이므로 얻은 각 영상의 수명도 따로 관리합니다.
