blob_threshold_image 멤버와 선언

공개 타입

zvision.blob_threshold_image: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_threshold_image.blob_threshold_image.

Compare source and shifted threshold image; outside overlap is background.

원본을 이동된 임계값 영상과 비교해 전경 마스크를 만듭니다.

Python
blob_threshold_image(source, threshold, offset_x, offset_y, light, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • light · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
비교할 ZImage
threshold
픽셀별 임계값 ZImage
offset_x
부호 있는 로컬 x 오프셋
offset_y
부호 있는 로컬 y 오프셋
light
bool; 밝은 전경을 선택할지 여부
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 Gray8 영상

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
