    사용과 결과 해석

    평면 유사변환을 적합할 때 초기값과 조정할 자유도를 지정합니다. initial의 네 값은 순서대로 각도, x 이동, y 이동, 양의 축척입니다. 각도는 라디안이고 이동은 입력 점 좌표와 같은 단위입니다. mask에서 각도, x, y, 축척 비트를 선택하면 그 성분만 최적화 대상으로 삼습니다.

    예를 들어 축척을 측정 장치에서 이미 알고 있다면 축척 비트를 끄고 나머지 자유도만 선택할 수 있습니다. 선택하지 않은 스칼라는 초기값을 유지하므로 적합이 모든 값을 새로 추정한다고 생각해서는 안 됩니다. 초기 축척이 유효한 양수인지와 원본·대상 점이 같은 좌표 단위인지 호출 전에 확인하십시오.

    max_iterations, damping, gradient_tolerance와 max_work는 국소 최적화의 반복, 감쇠, 종료 및 작업량 한도를 정합니다. 설정과 점쌍을 fit_planar_dofs에 전달한 뒤 반환된 초기·최종 RMS, 반복 수와 상태를 함께 읽습니다. 선택한 자유도가 관측으로 충분히 결정되지 않거나 예산이 부족한 경우 낮은 RMS 숫자만으로 보정을 승인하면 안 됩니다.
