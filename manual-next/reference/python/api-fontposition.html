    사용과 결과 해석

    폰트 OCR의 배치 확인에 사용하는 기대 위치와 허용 편차입니다. x와 y는 기준 위치이고 max_dx와 max_dy는 각 축에 대한 최대 편차입니다. 글자 셀의 위치를 예상 배치와 비교할 때 사용하며 문자열의 문자 인식 점수와는 다른 조건입니다.

    예를 들어 기대 x=100이고 max_dx=3이면 x 방향 허용 범위를 기준으로 실제 글자의 위치를 비교할 수 있습니다. y축에도 별도 편차가 있으므로 한 축의 허용 폭만으로 전체 배치를 판정하지 않습니다. 값의 좌표계와 입력의 크기 및 원점이 일치하는지 먼저 확인합니다.

    글자 자체의 라벨이 맞아도 위치 규칙을 만족하지 않을 수 있습니다. FontRead의 layout_accepted가 없는 경우는 배치 결과가 제공되지 않은 상태로 읽고, 글자별 accepted와 별도로 기록합니다. 입력 좌표를 화면에 표시할 때 확대와 이동도 고려합니다.

    기준 좌표가 영상의 로컬 좌표라면 확대된 화면 픽셀이나 전역 원점을 더한 좌표와 바로 비교하지 않습니다. 기대 위치와 허용 편차를 어떤 해상도에서 설정했는지도 함께 기록합니다.

    입력 크기가 바뀌면 기대 위치와 편차의 단위도 함께 재검토합니다.

    배치 시험 결과와 기대 위치도 함께 보관합니다.
