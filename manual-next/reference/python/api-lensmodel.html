카메라 좌표와 왜곡 방향

초점 계수와 주점은 카메라 전체 영상의 글로벌 픽셀 좌표계에 속합니다. 예를 들어 ROI의 원점이 (100, 200)이고 ROI 안의 점이 (10, 20)이면 카메라 좌표는 (110, 220)입니다. ROI 로컬 점을 그대로 렌즈 모델에 넣으면 같은 수치라도 다른 위치를 보정하게 됩니다. 세계 길이 단위와 픽셀 좌표도 서로 다른 값입니다.

점 왜곡은 보정된 좌표에서 왜곡된 좌표로 가는 전방 계산입니다. 역방향 점 계산은 반복법으로 국소 해를 찾으며 수렴 실패나 특이 계산은 오류가 될 수 있습니다. 왜곡 계수를 모두 0으로 두면 점 변환은 항등이지만, 계수가 맞는다는 사실만으로 실측 보정 정확도가 검증된 것은 아닙니다.

영상 왜곡 보정은 결과 픽셀 위치를 원본으로 역매핑해 표본을 읽습니다. 보이는 ROI 밖은 지정한 경계값을 사용하며 출력 크기와 형식, ROI 원점은 유지합니다. 제공된 계수를 적용하는 연산과 촬영된 기준판으로 계수를 추정·검증하는 작업을 구별해야 합니다.
