Python API · fit_planar_dofs

fit_planar_dofs 멤버와 선언

공개 타입

zvision.fit_planar_dofs: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.fit_planar_dofs.

Fit selected planar similarity scalars and preserve all unselected scalar bits.

선택한 평면 유사변환 계수만 적합하고 미선택 계수는 보존합니다.

Python
fit_planar_dofs(source, target, options)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
원본 2D 점 2~100000개
target
같은 수의 대응 타깃 2D 점
options
초기 계수 4개, 선택 마스크 0~15 및 최적화 제한을 담은 PlanarDofOptions

반환: 계수, affine 변환 및 최적화 진단을 담은 PlanarDofResult

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    대응하는 원본과 대상 2D 점으로 선택된 평면 유사변환 성분을 적합합니다. source와 target은 순서대로 대응해야 하며 개수가 같고 2~100000개여야 합니다. options에는 초기 각도, x·y 이동, 양의 축척과 조정 마스크를 지정합니다. 입력 점이 ROI 로컬인지 전역인지와 길이 단위는 호출자가 양쪽에서 맞춰야 합니다.

    각도와 축척, 두 이동 중 선택한 자유도만 최적화하며 선택하지 않은 성분은 초기값을 그대로 보존합니다. 예를 들어 두 점 집합의 이동만 조정하고 축척은 고정하려면 이동 비트만 선택합니다. 결과의 affine은 최종 네 성분으로 만든 변환이고, 결과의 초기·최종 RMS와 반복 진단은 개선 여부를 해석하는 데 쓰입니다.

    점쌍 개수나 옵션 구조가 잘못되면 오류가 전달됩니다. 기하가 퇴화하거나 선택된 계수를 충분히 제약하지 못하는 경우에는 상태와 rank 관련 진단도 확인해야 합니다. 이 결과는 전달한 대응점에 대한 적합이지 다른 프레임의 좌표까지 자동으로 변환하거나 생산 장비의 정확도를 보장하는 모델이 아닙니다.
