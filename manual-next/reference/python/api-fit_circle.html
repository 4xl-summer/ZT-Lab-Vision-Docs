fit_circle 멤버와 선언

공개 타입

zvision.fit_circle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._metrology.fit_circle.

합의 후보와 채택점으로 형상을 피팅합니다.

Python
fit_circle(points, threshold)

인자 선언

  • points · POSITIONAL_OR_KEYWORD · 기본값 없음
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

points
유한한 Point2 열; 최소 3개.
threshold
채택 잔차 거리; 좌표 단위의 유한한 양수.

반환: CircleFit 값과 채택점 통계.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류. 퇴화 점 배치도 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    최소 세 개의 유한한 Point2에서 원 후보를 정하고 채택점을 사용해 중심과 반경을 정련합니다. threshold는 원 경계까지 허용할 거리이며 입력 좌표가 픽셀이면 픽셀로 해석합니다. 예를 들어 중심 (10,10), 반경 2인 합성 원의 네 점 (12,10), (10,12), (8,10), (10,8)은 같은 원을 정의합니다. 결과의 중심과 반경뿐 아니라 채택 수와 잔차도 비교하십시오. 세 점이 모두 유효한 숫자여도 배치가 퇴화하면 안정적인 원을 정할 수 없어 오류가 될 수 있습니다. 카메라 영상에서 선택한 점이 목표 원호의 한쪽에만 몰렸다면 적합이 성공해도 다른 부분의 위치를 보장하지 않습니다. 픽셀과 세계 단위의 점을 하나의 입력 배열에 섞지 마십시오. 원호 일부만 영상에 들어온 상황에서는 누락된 둘레의 나머지 위치를 실제로 관측했다고 볼 수 없습니다. 동일한 결과 반경이라도 관측점의 분포와 잔차가 다른 사례가 있으므로 그림에 입력점과 적합 원을 함께 표시해 확인하십시오. 예시의 네 점은 원 중심에서 모두 거리 2에 있습니다. 다른 거리의 점을 섞으면 임계값과 적합 단계에 따라 채택 여부가 달라집니다. 결과의 상태를 확인하고 기각점이 실제로는 다른 물체의 경계인지 영상에서 대조하십시오.
