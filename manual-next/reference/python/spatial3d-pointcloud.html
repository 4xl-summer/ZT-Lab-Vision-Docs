Python API · PointCloud

PointCloud Python 소유 객체와 공개 멤버

개요와 수명

오른손 좌표계의 3차원 점을 담는 불변 소유 객체입니다. Point3 또는 누락 점 None의 시퀀스, LengthUnit 및 0이 아닌 frame으로 생성하며 빈 시퀀스도 허용합니다. 결측 슬롯은 삭제하지 않습니다. 장비별 축 방향과 단위는 호출자가 맞춰야 합니다.

네이티브 핸들을 소유합니다. close() 또는 with로 해제합니다. 닫힌 객체에서 핸들을 필요로 하는 호출은 ValueError를 냅니다. 네이티브 오류는 ZVisionError로 전달됩니다. 동시 호출과 장치별 조건은 이 선언만으로 확정할 수 없습니다.

상속 멤버 close()는 소유 핸들을 해제하며 컨텍스트 관리자도 지원합니다.

from_points

클래스 메서드. points는 Point3 또는 None의 시퀀스, unit은 LengthUnit, frame은 1 이상의 정수입니다. 새 PointCloud를 반환합니다.

info

Python
PointCloud.info

읽기 전용 속성. CloudInfo의 count, valid_count, unit, frame을 확인합니다.

슬롯 수, 유효점 수, 길이 단위와 frame을 읽습니다.

반환: CloudInfo 값 스냅샷입니다.

오류: 닫힌 객체에서 접근하면 오류입니다.

to_points

점들을 Python 리스트로 복사합니다. 누락 점은 None으로 표현합니다.

share

공유 데이터에 대한 별도의 소유 객체를 반환합니다. 반환 객체도 닫아야 합니다.

transform

RigidTransform3을 적용하여 새 PointCloud를 반환합니다. 다른 타입은 TypeError입니다. 변환의 단위·프레임 호환성은 네이티브 호출이 검사합니다.

estimate_normals

neighbors는 2 이상의 정수이고 viewpoint는 Point3입니다. 각 중심과 가장 가까운 유효 이웃으로 PCA 법선을 계산해 시점을 향하도록 정합니다. 결측, 이웃 부족 또는 공선 이웃의 결과는 None입니다. 거리 동률은 입력 슬롯 순서로 처리합니다.

fit_plane

양의 threshold를 점군 길이 단위로 지정합니다. 평면은 normal·p + offset = 0이고 해당 거리 이하의 점을 inlier로 분류합니다. PlaneFit은 normal, offset, inliers, total, rms_error, max_error를 담으며 잔차는 최종 inlier 기준입니다. 점 부족이나 공선 등 퇴화 입력은 오류입니다.

fit_cylinder

양의 threshold를 점군 길이 단위로 지정합니다. 축까지의 거리와 반지름의 차이 절댓값이 임계값 이하인 점을 inlier로 분류합니다. CylinderFit은 axis_point, axis_direction, radius, inliers, total, rms_error, max_error를 담습니다. 기본 적합은 최소 6점과 과반수 inlier를 요구하며 부분 호나 이상치에서는 실패하거나 불안정할 수 있습니다.

close()

상속된 소유 핸들을 해제합니다. 이미 닫힌 객체를 다시 닫을 수 있습니다.

합성 데이터 예제

예제는 실제 장비 측정이 아니며 이 페이지 생성 시 실행 여부를 검증하지 않았습니다.

Python
from zvision import LengthUnit, Point3, PointCloud

with PointCloud.from_points([Point3(0.0, 0.0, 1.0), None],
                            LengthUnit.MILLIMETER, 1) as cloud:
    print(cloud.info.count, cloud.to_points())
