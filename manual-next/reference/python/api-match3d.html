    사용과 결과 해석

    Match3D는 여러 점군 모델을 목표 점군에서 검색한 한 후보를 나타냅니다. model_index는 전달한 모델 목록의 0 기반 인덱스이고, registration에는 그 모델에서 목표로 가는 변환과 ICP 반복·잔차·수렴 진단이 들어 있습니다. overlap은 대응 거리 안에 들어온 모델 점의 비율입니다. 따라서 모델 목록의 순서를 결과와 함께 보관해야 숫자 인덱스를 실제 부품 모델에 다시 연결할 수 있습니다.

    검색은 점 삼중항으로 제한된 수의 가설을 만들고 ICP로 정제한 뒤 이동 범위, 회전각과 RMS 조건으로 결과를 걸러냅니다. 예를 들어 model_index가 1이면 두 번째 입력 모델을 가리킵니다. 검색 결과가 빈 목록이면 조건에 맞는 후보를 얻지 못했다는 뜻이며 무효 입력 오류와 구별합니다. 제한된 예산과 대칭 또는 부분 가림 때문에 이 목록이 가능한 모든 자세를 망라한다고 가정하지 않습니다.
