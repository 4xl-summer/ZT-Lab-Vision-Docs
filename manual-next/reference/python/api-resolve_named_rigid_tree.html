Python API · resolve_named_rigid_tree

resolve_named_rigid_tree 멤버와 선언

공개 타입

zvision.resolve_named_rigid_tree: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.resolve_named_rigid_tree.

Resolve target<-source through a fully named rooted rigid tree.

이름이 부여된 강체 트리에서 대상←원본 변환을 계산합니다.

Python
resolve_named_rigid_tree(edges, names, from_name, to_name)

인자 선언

  • edges · POSITIONAL_OR_KEYWORD · 기본값 없음
  • names · POSITIONAL_OR_KEYWORD · 기본값 없음
  • from_name · POSITIONAL_OR_KEYWORD · 기본값 없음
  • to_name · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

edges
강체 트리 간선 1~128개
names
간선보다 하나 많은 NamedFrame 순서열
from_name
출발 프레임 이름, UTF-8 최대 64바이트
to_name
도착 프레임 이름, UTF-8 최대 64바이트

반환: 합성된 RigidTransform3 값

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    resolve_named_rigid_tree는 프레임 이름을 ID와 연결한 트리에서 지정한 이름 사이의 3차원 강체 변환을 찾습니다. 간선은 1개부터 128개까지이고 이름 항목 수는 간선 수보다 하나 많아야 합니다. 이름은 UTF-8 기준 최대 64바이트이며 빈 문자열이나 NUL 문자는 허용되지 않습니다.

    구체 사례와 판독

    예를 들어 camera→gripper와 gripper→base의 두 간선이 있다면 camera, gripper, base의 세 이름을 연결해 camera에서 base로 가는 변환을 요청합니다. 결과를 역방향에 적용할 때는 출발과 도착을 바꾸어 요청하거나 올바른 역변환을 사용해야 합니다. 이름이 같은 문자열인지뿐 아니라 실제 장치의 좌표 기준과 길이 단위도 확인하세요.

    적용 시 확인

    두 간선이 같은 중간 프레임을 가리켜야 경로가 연결됩니다. 이름과 ID의 대응이 실제 간선의 프레임 ID와 맞는지 먼저 검토하고 간선 이동량의 단위도 통일하세요. 예를 들어 한 간선은 mm이고 다른 간선은 m이면 합성하기 전에 같은 단위로 변환해야 합니다. 경로가 없는 경우 오류를 처리합니다. 반환된 변환의 방향을 알려진 점 하나로 확인하면 출발과 도착을 뒤집는 실수를 줄일 수 있습니다.
