사용과 결과 해석

원의 중심과 반경, 점 피팅 통계를 묶은 값입니다. 중심과 반경은 입력 점의 좌표계와 단위를 따르며 실제 영상에서 찾은 점이면 보통 해당 영상 ROI 로컬 픽셀로 해석해야 합니다. 예를 들어 중심 (10,10), 반경 2인 원의 오른쪽 점은 (12,10)입니다. 네 방향의 점이 이 원 위에 정확히 놓인 합성 입력이라면 중심과 반경을 해당 관계와 비교할 수 있습니다. 피팅 통계의 인라이어 수와 잔차는 원의 유효성을 판단할 단서이지만 단일 RMS가 장비 정밀도를 보증하지는 않습니다. 원 경계까지의 거리와 두 원 사이의 거리를 계산할 때에는 중심과 반경의 단위가 같아야 하고 양의 반경이 필요합니다. 결과가 없거나 퇴화 입력이면 임의 반경 0으로 대체하지 마십시오. 같은 ROI에서 프레임마다 원을 찾는 경우 중심의 이동과 반경의 변화를 구분해 기록하십시오. 반경만 비교하면 영상 전체의 이동이 가려지고, 중심만 비교하면 원 크기의 변화를 놓칩니다. 채택점이 충분히 넓게 분포하는지도 함께 확인합니다. 한 장의 영상에서 발견한 원과 다른 ROI의 원을 비교할 때는 각 원점이 일치하는지 먼저 확인합니다. 두 중심을 같은 글로벌 좌표로 옮긴 후 중심 이동을 계산하고, 반경은 같은 픽셀 단위인지 확인하십시오. 보정 후의 세계 형상은 변환 모델에 따라 따로 해석해야 합니다.
