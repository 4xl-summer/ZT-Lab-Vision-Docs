    사용과 결과 해석

    Point3는 세 좌표 또는 벡터 성분을 묶는 값입니다. 이 값 자체에는 단위나 좌표계 식별자가 없으므로 어느 점군, 변환 또는 카메라의 입력으로 사용하는지 함께 기록해야 합니다. 예를 들어 (1,2,3)이 밀리미터 점군의 위치라면 각 성분은 그 점군의 길이 단위를 따르지만, 단위 법선에 사용한 같은 세 성분은 방향을 나타냅니다. 숫자의 모양만으로 두 용도를 구분할 수 없습니다.

    점군 생성에서는 유한한 Point3와 None 슬롯을 함께 전달할 수 있습니다. None은 좌표가 빠진 위치이고 (0,0,0)은 유효한 원점입니다. 강체 변환은 회전된 점에 이동 벡터를 더하며 입력과 출력 frame을 별도로 확인합니다. 예를 들어 이동 (2,-3,4)를 점 (2,3,4)에 적용하면 (4,0,8)입니다. Point3는 값이지만 이를 담는 점군은 별도 소유 객체이므로 언어의 수명 규칙에 맞게 닫습니다.
