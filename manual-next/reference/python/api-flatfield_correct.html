Python API · flatfield_correct

flatfield_correct 멤버와 선언

공개 타입

zvision.flatfield_correct: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._flatfield_gap.flatfield_correct.

Return input*global_gain*gain_map+global_offset+offset_map.

입력×전역 gain×gain 맵 + 전역 offset + offset 맵을 계산합니다.

Python
flatfield_correct(image, gain_map=None, offset_map=None, global_gain=1.0, global_offset=0.0, output_format=<PixelFormat.GRAYF32: 3>)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • gain_map · POSITIONAL_OR_KEYWORD · 기본값 None
  • offset_map · POSITIONAL_OR_KEYWORD · 기본값 None
  • global_gain · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • global_offset · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • output_format · POSITIONAL_OR_KEYWORD · 기본값 <PixelFormat.GRAYF32: 3>

확인된 인자 조건

image
입력 ZImage입니다.
gain_map
선택적 gain ZImage 또는 None입니다.
offset_map
선택적 offset ZImage 또는 None입니다.
global_gain
유한한 양의 배율이며 기본값은 1입니다.
global_offset
유한한 전역 편향이며 기본값은 0입니다.
output_format
출력 형식이며 기본값은 GrayF32입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

global_gain: 유한한 수 검사.

global_offset: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
