블롭과 레이블의 복사

AdvancedBlobSnapshot은 이미지, 컨텍스트 및 결과 핸들과 독립적인 블롭 값 튜플 blobs와 행별 불변 레이블 맵 labels를 보관합니다. 스냅샷을 얻은 시점의 내용을 이후에도 비교할 수 있으며 원본 영상 자체를 포함한다는 뜻은 아닙니다.

레이블 맵 판독

labels는 행별 구조이므로 먼저 행과 열 순서를 확인합니다. 배경과 각 성분의 레이블을 표시하고 blobs의 면적이나 위치와 대조하면 어떤 픽셀이 해당 성분에 속하는지 이해할 수 있습니다. 단순히 목록 순번이 레이블 번호와 같다고 추정하지 않습니다.

수명과 비교

스냅샷 값은 원래의 영상과 결과 핸들에 독립적이지만, 원본 영상을 나중에 다시 보려면 그 영상은 별도 수명 관리가 필요합니다. 두 스냅샷을 비교할 때 입력 프레임, ROI와 연결 조건을 같이 기록합니다.

식별자의 한계

연결 조건이나 면적 필터가 달라지면 성분 수와 레이블 배치가 바뀔 수 있습니다. 다른 프레임의 동일 레이블을 영구 물체 ID로 취급하지 말고 위치와 형상 등을 이용한 대응 규칙을 별도로 사용합니다.
