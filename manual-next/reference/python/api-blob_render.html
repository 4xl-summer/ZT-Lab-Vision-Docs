Python API · blob_render

blob_render 멤버와 선언

공개 타입

zvision.blob_render: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_render.blob_render.

Render selected labels; viewable mode uses 128/255/0 for background/blob/hole.

선택 라벨과 구멍을 지정 표시 방식으로 렌더링합니다.

Python
blob_render(source, segmented, connectivity, viewable, background, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • segmented · POSITIONAL_OR_KEYWORD · 기본값 없음
  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음
  • viewable · POSITIONAL_OR_KEYWORD · 기본값 없음
  • background · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
입력 BlobResult
segmented
분할된 ZImage
connectivity
연결성 4 또는 8
viewable
bool; True면 배경 128, 블롭 255, 구멍 0
background
0–255 정수 배경 표시 값
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 Gray8 영상

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
