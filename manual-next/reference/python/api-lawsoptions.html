    size: 기저 벡터와 정사각형 커널의 길이이며 3, 5 또는 7입니다.

    vertical: y 방향 Laws 기저입니다. 크기별로 지원되는 기저가 다릅니다.

    horizontal: x 방향 Laws 기저입니다. 크기별로 지원되는 기저가 다릅니다.

    shift: 응답을 2의 이 거듭제곱으로 나누는 지수이며 0–9입니다.

    border: 경계에서 복제, 반사 또는 상수 중 선택합니다.

    border_value: 상수 경계에 쓰는 유한 값입니다. 상수 경계가 아니면 0이어야 합니다.

    max_work: 픽셀 수 × 커널 원소 수의 작업 예산 상한이며 양수입니다.
