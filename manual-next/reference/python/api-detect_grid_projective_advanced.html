Match detected target points to a supplied projective grid-to-pixel map.

주어진 투영 격자 변환으로 표적을 검출합니다.

공개 멤버

    사용과 결과 해석

    이미 알고 있는 격자→픽셀 호모그래피를 이용해 영상의 격자 표적 관측을 대응시킵니다. image에는 지원되는 그레이 영상을, spec에는 타깃 종류와 예상 행·열 및 검출 조건을, grid_to_pixel에는 격자 좌표에서 영상 픽셀로 가는 투영 변환을 전달합니다. 결과는 각 점의 행·열, 픽셀 위치와 대비 점수를 갖는 튜플입니다. 이 행렬은 세계 좌표에서 픽셀로 가는 임의의 보정과 자동으로 같은 것이 아니므로 입력 프레임을 확인하십시오. 예를 들어 (열,행) 좌표가 한 칸 증가했을 때 어느 픽셀 위치에 투영되는지 먼저 점검하면 행렬 방향을 검사할 수 있습니다. 격자 배치나 영상 경계가 맞지 않으면 후보가 실패할 수 있습니다. 검출 점수는 세계 보정의 독립 검증 잔차와 별개입니다. 투영 변환의 방향을 반대로 전달하면 좌표가 모두 유한하더라도 예상 픽셀 위치가 목적 표적과 맞지 않을 수 있습니다. 소수의 알려진 격자 인덱스를 먼저 대입해 영상 위의 위치를 검토하고, 반환 인덱스와 픽셀 좌표를 세계 기준점 배열과 같은 순서로 연결하십시오. 검출된 각 위치는 영상의 픽셀 좌표입니다. 행과 열은 격자의 논리 인덱스이므로 물리 거리와 구별해야 합니다. 픽셀 위치는 영상 기준으로 기록합니다.
