공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    widthint필수출력 캔버스 폭(픽셀)입니다.
    heightint필수출력 캔버스 높이(픽셀)입니다.
    origin_xfloat필수출력 캔버스 (0,0)에 대응하는 공통 좌표계 x 원점입니다.
    origin_yfloat필수출력 캔버스 (0,0)에 대응하는 공통 좌표계 y 원점입니다.
    scalefloat필수공통 좌표 단위당 출력 픽셀 배율입니다. 캔버스 (x,y)는 공통 좌표 (origin_x+x/scale, origin_y+y/scale)입니다.

    사용과 결과 해석

    모자이크 출력의 픽셀 크기와 공통 좌표계 원점, 배율을 묶은 값입니다. width와 height는 출력 픽셀 수이며 origin_x, origin_y는 캔버스 (0,0)에 대응하는 공통 좌표입니다. scale은 공통 좌표 단위당 출력 픽셀의 양의 배율입니다.

    출력 위치 (x,y)는 공통 좌표 (origin_x+x/scale, origin_y+y/scale)에 대응합니다. 예를 들어 원점이 (10,20), 배율이 2이고 출력 좌표가 (4,6)이면 공통 좌표는 (12,23)입니다. 이 공통 좌표는 어느 한 입력 영상의 로컬 위치와 자동으로 같지 않습니다.

    실제 렌더링에는 각 영상의 정합 변환과 유효 표본, 겹침 처리 방법도 필요합니다. 영역 크기만 보고 모든 픽셀이 채워진다고 가정하지 말고 유효 마스크를 확인하십시오. 캔버스를 명시적으로 지정하면 필요한 영상 영역이 잘리지 않는지도 검토해야 합니다.
