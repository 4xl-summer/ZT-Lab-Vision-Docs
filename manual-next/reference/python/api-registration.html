    사용과 결과 해석

    Registration은 점대점 ICP가 산출한 강체 변환과 반복 진단의 값 스냅샷입니다. transform은 원본 점군의 frame에서 목표 점군의 frame으로 가는 변환이고, iterations는 수행한 반복 수, inliers는 유지된 대응점 수입니다. rms는 대응 거리의 제곱 평균 제곱근으로 점군의 길이 단위를 따릅니다. 원본과 목표의 단위 및 초기 변환의 방향이 맞지 않으면 이 결과를 얻을 수 없습니다.

    converged는 반복 중 RMS 변화가 설정한 기준에 도달했는지를 나타냅니다. 예를 들어 임계값이 0.01이고 변화가 그 이하로 작아져 멈춰도 결과 RMS가 실제 공차보다 클 수 있습니다. 따라서 수렴과 품질을 따로 보고 inliers, rms, 독립 보류점의 거리, 현장의 허용오차를 함께 비교합니다. 대응점 부족은 오류이고 수렴하지 않은 반환 결과는 다른 상태입니다. 대칭 형상이나 나쁜 초기값에서는 국소 해에 도달할 수 있습니다.
