    사용과 결과 해석

    DepthCalibrationMetrics는 선형 깊이 보정을 대응 높이 쌍에 적용해 계산한 평가 통계입니다. 각 부호 있는 잔차는 보정 높이에서 기준 높이를 뺀 값입니다. count는 평가에 사용한 쌍의 개수이며 bias는 이 잔차의 평균입니다. 예를 들어 두 잔차가 -1과 1이면 bias는 0이지만 RMS는 1이므로, 평균만 보고 오차가 없다고 판단하면 안 됩니다.

    rms_error는 잔차 제곱 평균의 제곱근이고 max_abs_error는 가장 큰 절댓값입니다. stddev는 평균을 뺀 잔차의 모집단 표준편차입니다. 이 값들은 보정 모델의 길이 단위를 따릅니다. evaluate에 넘긴 두 배열은 길이가 같고 비어 있지 않으며 값이 유한해야 합니다. 학습에 사용하지 않은 보류 높이로 평가하면 학습 잔차와 별도의 비교를 할 수 있지만 합성 값이 센서의 실측 정확도를 보증하지는 않습니다.
