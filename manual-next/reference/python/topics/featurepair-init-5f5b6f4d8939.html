FeaturePair(model_index: int, source_index: int, model_point: zvision._regions.Point2, source_point: zvision._regions.Point2, global_source_point: zvision._regions.Point2, distance: float, inlier: bool, residual: float | None)

model_index: 모델 특징점 목록에서 대응점의 인덱스입니다.

source_index: 검색 영상 특징점 목록에서 대응점의 인덱스입니다.

model_point: 대응 모델 특징점의 모델 로컬 좌표입니다.

source_point: 대응 검색 특징점의 검색 영상 로컬 좌표입니다.

global_source_point: 검색 영상 원점을 더한 대응점의 전역 좌표입니다.

distance: 두 정규화 기술자 사이의 L2 거리입니다.

inlier: 추정 기하 변환에 대한 내점 여부입니다.

residual: 추정 변환에 대한 픽셀 잔차이며 계산할 수 없으면 None입니다.

값을 구성하고 해석하기

하나의 모델 특징과 검색 영상 특징의 대응을 담습니다. model_index와 source_index는 각자의 목록에 대한 인덱스이며 model_point와 source_point도 서로 다른 로컬 좌표계에 있습니다. global_source_point에는 검색 영상 원점이 반영됩니다. 변환 추정을 평가할 때는 inlier와 residual을 함께 확인합니다.
