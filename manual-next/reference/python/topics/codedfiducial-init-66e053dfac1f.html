CodedFiducial(id: int, row: int, column: int, unit: object, clockwise_quarter_turns: int, has_spacing: bool, pitch_x: float, pitch_y: float) -> None

Decoded ZVFD-1 ID, grid origin index, physical pitch, unit and quarter turn.

id: 복호된 마커 식별자.

row: 기준 격자의 행 인덱스.

column: 기준 격자의 열 인덱스.

unit: 물리 간격 단위; spacing이 없으면 None.

clockwise_quarter_turns: 감지된 시계 방향 90도 회전 횟수.

has_spacing: 물리 간격이 인코딩되어 있는지 여부.

pitch_x: 복호된 가로 간격; unit 단위.

pitch_y: 복호된 세로 간격; unit 단위.

이 호출의 입력과 객체 맥락

CodedFiducial은 ZVFD-1 표식을 해독한 식별자와 격자 정보를 담습니다. id는 표식 식별자이고 row와 column은 격자 원점 인덱스입니다. clockwise_quarter_turns는 시계 방향 90도 단위 회전이며 has_spacing은 pitch_x, pitch_y 간격 정보의 존재 여부를 표시합니다. 간격이 있는 경우 unit과 함께 물리적 크기로 해석합니다.

예를 들어 quarter turn이 1이면 기준 방향에서 시계 방향으로 90도 회전한 상태입니다. 간격이 10 mm로 기록된 경우 인접 격자 중심 사이의 물리적 간격을 의미하며 영상에서의 10픽셀과 같다고 가정할 수 없습니다. has_spacing이 거짓이면 간격 필드를 유효한 치수로 임의 해석하지 마세요.
