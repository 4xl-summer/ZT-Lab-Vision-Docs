model_images(self)

모델의 기준과 편차 영상을 획득합니다.

반환: 각각 독립 소유 GrayF64 영상인 쌍이며 둘 다 close합니다.

오류: 닫힌 객체, 부적합 입력 또는 한도 초과 시 오류입니다.

Acquire owned reference and deviation images; callers must close each.

Existing native indexed calls each reconstruct both GrayF64 buffers.

기준 및 편차 영상 획득

모델의 기준 영상과 편차 영상을 순서대로 획득합니다. 각 반환 영상은 독립 소유이므로 두 영상 모두 사용 후 close합니다. 첫 영상을 얻은 뒤 둘째 획득이 실패하면 구현이 첫 영상도 해제합니다.

모델이 어떤 기준값과 편차를 갖는지 검사 결과와 비교할 때 사용할 수 있습니다. 모델의 소유 핸들과 획득한 두 영상을 동일 수명으로 취급하지 않습니다. 인덱스로 하나씩 가져오는 model_image는 이전 호환 경로입니다.

두 영상과 복원 비용

반환 순서는 기준과 편차이며 두 영상은 독립 소유입니다. 각 인덱스 조회가 두 GrayF64 버퍼를 재구성하므로 반복 호출은 픽셀 버퍼 할당 비용을 수반합니다.

기준과 편차의 동일 위치를 함께 읽고 영상의 origin이 입력 검사 프레임과 같은지 확인합니다. 두 영상은 모델이나 서로의 해제와 별도로 각각 close합니다.

반환 순서수명
기준 영상독립 소유
편차 영상독립 소유
정리각각 close
