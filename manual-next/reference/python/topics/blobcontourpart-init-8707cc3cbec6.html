값의 해석과 사용

선택된 연속 점을 원본 순서로 보관하며 closed는 닫힌 입력 전체가 선택된 경우에만 참입니다. 고리의 일부 호를 선택했다면 양 끝을 임의로 연결하지 않습니다.

선택한 연속 경로

points는 윤곽에서 선택한 연속 점이고 closed는 닫힌 입력 전체가 선택된 경우에만 참입니다. 원본이 닫힌 고리여도 그중 일부 호만 선택했다면 이 부분의 양 끝을 자동으로 연결하지 않습니다.
