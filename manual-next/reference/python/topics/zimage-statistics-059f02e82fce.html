statistics

method · 선언 타입 zvision.ZImage

Python
statistics(self)

Gray8 픽셀의 기본 통계를 계산합니다.

반환: 독립 통계 값 스냅샷입니다.

오류: 형식이 지원되지 않으면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

영상 값의 요약

영상 통계는 선택된 픽셀 값의 분포를 숫자로 요약합니다. 평균이 같더라도 값의 분포나 위치는 다를 수 있습니다. 예를 들어 0과 100의 평균과 50 두 개의 평균은 모두 50이지만 두 입력의 변화 폭은 다릅니다.

결과 해석

값의 단위와 픽셀 형식, 분석 ROI를 기록하고 필요한 최소·최대 또는 분포 정보를 함께 확인합니다. 요약 숫자는 각 픽셀의 위치를 보존하지 않으므로 위치 기반 결함 판정에는 원본 영상과 별도 마스크 또는 경계 분석이 필요합니다.

요약과 위치

두 영역의 평균이 같더라도 밝은 픽셀이 한곳에 몰렸는지 흩어졌는지는 통계 하나로 알 수 없습니다. 위치가 중요한 검사는 원본 또는 마스크와 함께 수행하고 ROI 크기와 픽셀 형식을 기록합니다.
