ZImage.threshold 공개 계약

상위 목차로 돌아가기

threshold

method · 선언 타입 zvision.ZImage

Python
threshold(self, t)

임계값 이상을 255, 미만을 0으로 분할합니다.

확인된 인자 조건

t: 유한 실수 임계값, 원본 픽셀 단위

반환: 입력 7종 Gray 형식에 대한 새 Gray8 마스크; 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 비유한 임계값·부동소수 픽셀 또는 미지원 입력은 오류입니다.

인자 선언

  • t · POSITIONAL_OR_KEYWORD · 기본값 없음

t: 유한한 수 검사.

Return an owned Gray8 mask for seven Gray formats, using pixel >= finite t.

경계값을 포함한 선택

입력 픽셀을 지정한 임계값과 비교해 이진 마스크를 만듭니다. 임계값 7에서 입력 0, 6, 7, 8의 출력은 0, 0, 255, 255입니다. 값이 정확히 7인 위치도 전경에 포함되어 등호의 방향을 확인할 수 있습니다.

형식과 수명

임계값은 입력 표본의 단위로 지정하며 결과의 255는 선택 표시이지 원래 밝기 값이 아닙니다. 원본 밝기 측정과 마스크 기반 분석을 구분하고 반환된 독립 영상은 사용 후 close 또는 with로 정리합니다.
