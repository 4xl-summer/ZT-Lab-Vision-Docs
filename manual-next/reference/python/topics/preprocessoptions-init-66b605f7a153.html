PreprocessOptions(width: int, height: int, resize: int = 0, interpolation: int = 0, channel_order: int = 0, pad: tuple = (0, 0, 0), mean: tuple = (0.0, 0.0, 0.0), std: tuple = (1.0, 1.0, 1.0), pad_alignment: int = 0, padding: int = 0) -> None

AI 입력 이미지의 크기, 배치 및 채널 정규화 설정값입니다. 실제 제약은 prepare_image 호출 시 검사됩니다.

width: 모델 출력 너비(픽셀), 양수이며 height와의 곱은 1,048,576 이하.

height: 모델 출력 높이(픽셀), 양수이며 width와의 곱은 1,048,576 이하.

resize: 0은 늘이기, 1은 비율 유지 레터박스; 기본 0.

interpolation: 0은 최근접, 1은 이중선형; 기본 0.

channel_order: 0은 RGB, 1은 BGR 채널 순서; 기본 0.

pad: 상수 패딩에 쓰는 0–255 정수 채널 세 개; 기본 (0,0,0).

mean: 정규화에서 채널마다 빼는 유한한 세 값; 기본 (0,0,0).

std: 정규화에서 채널마다 나누는 유한한 양의 세 값; 기본 (1,1,1).

pad_alignment: 레터박스 배치: 0 가운데, 1 왼쪽 위, 2 오른쪽 아래; 기본 0.

padding: 0 상수 패딩, 1 경계 픽셀 복제; 기본 0.

이 호출의 입력과 객체 맥락

PreprocessOptions.channel_order: 출력 채널 순서: 0 RGB, 1 BGR; 기본 0. Gray8은 한 채널.

PreprocessOptions.interpolation: 보간 방식: 0 최근접, 1 이중선형; 기본 0.

PreprocessOptions.mean: 출력 채널별 유한한 평균 3개; 정규화된 강도에서 뺌. 기본 (0,0,0).

PreprocessOptions.pad: 상수 패딩의 RGB 순서 바이트 3개(각 0–255); 기본 (0,0,0).

PreprocessOptions.pad_alignment: letterbox 배치: 0 중앙, 1 왼쪽 위, 2 오른쪽 아래; 기본 0.

PreprocessOptions.padding: 패딩 방식: 0 지정 상수, 1 가장자리 복제; 기본 0.

PreprocessOptions.resize: 크기 변경 방식: 0 전체 늘이기, 1 비율 유지 letterbox; 기본 0.

PreprocessOptions.std: 출력 채널별 유한한 양의 표준편차 3개; (강도/255−mean)을 나눔. 기본 (1,1,1).
