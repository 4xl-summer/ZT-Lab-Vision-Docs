calculate

calculate(cls, image, mask, bins, lower, upper, offset_x=0, offset_y=0)

비영 care 마스크를 통과한 채널별 히스토그램을 계산합니다.

확인된 인자 조건

image: ZImage 원본

mask: ZImage care 마스크

bins: 빈 수 2–65536

lower: 유한한 하한

upper: lower보다 큰 유한 상한

offset_x: 마스크 x 오프셋; 기본값 0

offset_y: 마스크 y 오프셋; 기본값 0

반환: 별도로 close할 히스토그램입니다.

오류: 타입·빈 수·범위가 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • bins · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lower · POSITIONAL_OR_KEYWORD · 기본값 없음
  • upper · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_x · POSITIONAL_OR_KEYWORD · 기본값 0
  • offset_y · POSITIONAL_OR_KEYWORD · 기본값 0

bins: 정수 검사 · 최소 2.

lower: 유한한 수 검사.

upper: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

관심 마스크의 분포

비영 care 마스크를 통과한 픽셀의 채널별 히스토그램을 계산합니다. bins는 2–65536이며 lower와 upper는 유한하고 upper가 더 커야 합니다. offset_x와 offset_y는 마스크의 위치 관계를 정하며 기본값은 0입니다.

범위와 결과

원본과 마스크의 좌표 정렬을 확인하고 빈 수, 포함 범위와 채널 순서를 결과와 함께 기록합니다. 같은 입력이라도 마스크가 달라지면 집계할 픽셀 집합이 달라집니다. 결과의 중앙값·최빈값은 밝기 자체가 아닌 빈 인덱스일 수 있습니다.
