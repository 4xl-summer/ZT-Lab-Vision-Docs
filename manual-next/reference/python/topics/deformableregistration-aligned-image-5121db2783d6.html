aligned_image(self)

정합된 영상을 얻습니다.

반환: 호출자가 닫아야 하는 별도 소유 ZImage입니다.

오류: 정합 결과가 없거나 객체가 닫혔다면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

변형 정합 영상

DeformableRegistration의 정합된 영상을 별도 소유 ZImage로 획득합니다. 정합 결과가 없거나 객체가 닫혀 있으면 오류입니다. 변형 정합은 한 개의 전역 이동만으로 설명되지 않을 수 있으므로 공간별 결과를 살펴야 합니다.

검증

기준의 여러 위치에서 정합 영상과 대응 특징이 맞는지 비교합니다. 한 위치가 맞는 것만으로 전체 영역의 정확성을 판단하지 않습니다. 획득한 ZImage는 반환 객체와 별도로 close합니다.

국소 정합 확인

변형 정합은 위치에 따라 다른 변화를 나타낼 수 있으므로 영상의 여러 위치를 기준 영상과 비교합니다. 결과 영상이 존재하는 것과 실제 장비에서 허용 오차를 만족하는지는 별도로 판단합니다.
