HandEyeOptions(rotation_threshold: float, translation_threshold: float, max_hypotheses: int)

rotation_threshold: 합의점 판정에 허용할 회전 잔차 임계값이며 라디안입니다.

translation_threshold: 합의점 판정에 허용할 이동 잔차 임계값이며 변환의 길이 단위입니다.

max_hypotheses: 평가할 가설의 최대 수입니다.

이 호출의 입력과 객체 맥락

HandEyeOptions는 핸드아이 계산에서 후보 변환을 평가하는 조건을 지정합니다. rotation_threshold는 회전 잔차의 한계로 라디안 단위이며 translation_threshold는 이동 잔차의 한계로 입력 변환과 같은 길이 단위입니다. max_hypotheses는 평가할 후보 개수의 상한이며 허용 범위는 1부터 100000까지입니다.

예를 들어 이동 변환을 밀리미터로 표현한다면 이동 임계값 0.5도 밀리미터로 해석합니다. 동일한 장면을 미터로 표현하면서 숫자 0.5를 유지하면 허용 거리가 천 배 달라집니다. 회전과 이동의 조건을 둘 다 만족해야 해당 잔차가 내점으로 표시됩니다. 임계값은 장치 반복성 및 검증 데이터에 맞춰 정하고 입력의 프레임 방향부터 확인하세요.

입력과 결과를 읽는 순서

핸드아이 후보의 회전·이동 잔차에 각각 다른 허용치를 지정합니다. rotation_threshold는 라디안, translation_threshold는 입력 강체 변환에 사용한 길이 단위입니다. max_hypotheses는 유한한 후보 평가 상한이며 1~100000 범위입니다.

예를 들어 입력 이동이 밀리미터이고 translation_threshold가 0.5라면 0.5mm로 해석합니다. 같은 물리 거리의 데이터를 미터로 바꾸면서 숫자 0.5를 그대로 두면 허용 길이가 달라집니다. 회전 임계값도 도가 아니라 라디안인지 확인해야 합니다.

한 운동 쌍의 inlier 판정은 회전과 이동 잔차가 각각의 조건을 모두 만족하는지에 달립니다. 평가된 후보 수가 유한하므로 설정을 작게 잡거나 예산에 도달한 경우 전역 최적이 보장된다고 해석하지 마세요. 입력 운동의 프레임 방향과 최종 잔차도 함께 검토합니다.
