orthogonal_wavelet_filter_bank_ex(self, levels, analysis_low, analysis_high, synthesis_low, synthesis_high, centered=False)

지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

analysis_low: 분석 저역 필터

analysis_high: 분석 고역 필터

synthesis_low: 합성 저역 필터

synthesis_high: 합성 고역 필터

centered: 중심 정렬 여부; 기본값 False

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • analysis_low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • analysis_high · POSITIONAL_OR_KEYWORD · 기본값 없음
  • synthesis_low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • synthesis_high · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 False

Return a variable-length filter-bank transform; the bank may be non-orthogonal.

확장 필터 뱅크 변환

이 호출은 분석 저역·고역과 합성 저역·고역 필터를 명시하고 변환 단계를 지정합니다. 네 필터의 역할이 다르므로 배열을 섞거나 분석과 합성 방향을 바꾸면 원하는 결과를 기대할 수 없습니다. centered 기본값은 False입니다.

반환 형식 확인

확장 메서드가 반환하는 결과 타입과 소유권을 선언에서 확인한 뒤 계수 및 관련 정보를 사용합니다. 유효하지 않은 형식, 단계 또는 필터는 오류가 될 수 있습니다. 같은 입력을 복원해 비교할 때 필터 계수와 위상 정렬을 함께 기록합니다.
