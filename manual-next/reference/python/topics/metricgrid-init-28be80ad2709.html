python 공개 선언
MetricGrid(rows: int, columns: int, pitch_x: float, pitch_y: float, unit: object) -> None

Rectangular target indices and physical pitch in the declared length unit.

rows: 격자 행 수로 양의 정수이며 열 수와의 곱은 1000000 이하여야 합니다.

columns: 격자 열 수로 양의 정수이며 행 수와의 곱은 1000000 이하여야 합니다.

pitch_x: 가로 점 간격으로 지정 길이 단위의 유한한 양수입니다.

pitch_y: 세로 점 간격으로 지정 길이 단위의 유한한 양수입니다.

unit: 격자 물리 좌표의 길이 단위입니다.

이 호출의 입력과 객체 맥락

행·열 수와 물리 점 간격, 길이 단위를 묶어 격자를 정의합니다. 예를 들어 2행 3열이면 점은 6개이고 pitch_x는 같은 행의 이웃 열 사이 간격, pitch_y는 이웃 행 사이 간격입니다. 행×열은 최대 1000000이고 두 간격은 유한한 양수입니다. 이 물리 격자와 카메라 픽셀 좌표는 단위가 다르므로 포즈나 보정 변환 없이 같은 숫자로 비교하지 않습니다.

물리 격자 구성

rows와 columns는 행·열 수, pitch_x와 pitch_y는 각 방향 간격, unit은 길이 단위입니다. 같은 격자의 점을 카메라 보정이나 합성에 사용할 때 행과 열의 순서를 유지합니다.

예를 들어 3행 4열, pitch_x=2.5, pitch_y=1.25이면 0부터 시작하는 (행 2, 열 3)의 점은 (7.5,2.5)입니다. 이 좌표는 지정한 격자 단위이며 영상의 픽셀 좌표가 아닙니다.

렌즈나 pose를 이용해 영상에 투영한 결과는 픽셀 좌표이고 격자 자체의 점은 물리 좌표입니다. 두 자료의 좌표계와 단위를 섞지 말고 각 인덱스가 같은 물리 표식을 가리키도록 대응시킵니다.

격자의 point는 행과 열을 0부터 받습니다. 세 행이면 유효 행은 0, 1, 2이고 행 3은 범위 밖입니다. 실제 호출은 행·열의 값과 격자 크기를 검증합니다.

예제에서 열 간격이 2.5이고 열이 3이면 x는 7.5입니다. 물리 격자의 원점과 렌즈·pose로 투영한 글로벌 픽셀 중심은 서로 다른 좌표이므로 보정이나 표시에서 구분합니다.

격자의 물리 좌표는 지정된 unit으로 기록합니다. 카메라에 투영한 중심과 격자의 대상 좌표가 같은 숫자처럼 보여도 하나는 픽셀이고 다른 하나는 길이 단위일 수 있습니다.
