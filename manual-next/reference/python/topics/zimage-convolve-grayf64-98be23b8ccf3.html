GrayF64 영상에 지정된 커널로 상관 또는 컨볼루션을 적용합니다.

  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Correlate or convolve a GrayF64 image with the supplied kernel.

GrayF64 커널과 중심점

이 메서드는 GrayF64 입력에 유한한 2차원 커널을 적용하고 GrayF64 결과를 만듭니다. ConvolutionSpec의 width와 height가 커널 모양을 정하고 anchor는 현재 출력 위치에 대응하는 커널 내부 좌표입니다. 커널 계수의 개수는 width × height와 같아야 하며 anchor는 그 범위 안에 있어야 합니다.

각 출력 위치에서는 설정한 경계 규칙으로 이웃 표본을 얻어 계수와 곱해 더합니다. 그 합을 0이 아닌 divisor로 나눈 다음 offset을 더합니다. 예를 들어 1×1 커널 계수가 1, divisor가 1, offset이 0이면 한 픽셀의 계산값은 입력 픽셀과 같습니다. 실제 결과의 유한성과 입력 형식 검사는 이 단순한 수식과 별도로 적용됩니다.

correlate가 참이면 지정한 커널 방향의 표본 오프셋을 사용하고 거짓이면 오프셋 방향을 반전합니다. 비대칭 커널에서는 두 결과가 다를 수 있으므로 원하는 방향을 명시해야 합니다. 경계는 보이는 ROI를 독립 영역으로 취급하며 replicate, reflect 또는 유한한 constant 값을 사용합니다. 반환 영상은 원본 ROI 원점을 유지하는 새 소유 객체입니다.

호출 단편과 오류 조건

이미 준비한 GrayF64 영상과 유효한 ConvolutionSpec을 사용하는 단편입니다. 다른 입력 형식, 비유한 입력이나 계수, 0인 divisor 또는 유한하지 않은 결과는 실패할 수 있습니다. 결과 영상은 원본과 별도로 닫습니다.

with image.convolve_grayf64(spec) as filtered:
