forward(cls, image, levels)

주기 경계를 사용하는 다운샘플링하지 않는 웨이블릿 변환을 만듭니다. 이 팩터리는 기존 호환 API입니다.

확인된 인자 조건

image: 변환할 ZImage입니다.

levels: 1–32 정수 분해 레벨입니다.

반환: 호출자가 닫아야 하는 독립 변환 모델입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음

levels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Legacy factory retained through 0.1.x; prefer image.stationary_haar(levels).

이 호출의 입력과 객체 맥락

입력 ROI의 변환 모델을 새로 생성합니다. levels는 분해 단계이며 적용 가능한 크기 조건은 선택한 변환 계열에서 확인해야 합니다. 소유 모델에서 coefficients로 계수 사본을 얻거나 inverse로 영상을 복원할 수 있습니다. 입력 영상, 생성 모델, 복원 영상의 각 소유권은 따로 관리합니다. 각 축의 단계별 오프셋은 영상 크기보다 작아야 합니다.
