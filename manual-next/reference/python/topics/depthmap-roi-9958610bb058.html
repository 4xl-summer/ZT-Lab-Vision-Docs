깊이 격자의 관심 영역

DepthMap.roi(x, y, width, height)는 원본 격자에서 사각 영역을 선택하여 별도로 소유하는 DepthMap 핸들을 반환합니다. 좌표와 크기는 픽셀이나 셀 인덱스이며 길이 단위의 세계 좌표가 아닙니다. x와 y는 0 이상의 정수이고 width와 height는 1 이상의 정수입니다. 요청한 영역 전체가 원본 경계 안에 들어가야 합니다.

결과는 원본 저장소와 행 간격을 공유하므로 이 호출이 새 깊이 배열 전체를 복사한다고 가정하지 않습니다. 동시에 결과는 독립적인 소유 핸들을 갖습니다. 원본 핸들을 닫은 뒤에도 결과를 사용할 수 있지만, 결과를 다 사용하면 결과 핸들도 닫아야 합니다. 여러 ROI를 얻었다면 각각의 수명을 따로 관리합니다.

ROI의 좌표 원점은 선택한 셀 위치에 맞춰 이동합니다. 원본 원점의 X에 x × spacing_x, Y에 y × spacing_y를 더하고 Z 원점은 유지합니다. 예를 들어 X 간격이 0.5이고 x가 4이면 새 원점 X는 원본보다 2 길이 단위만큼 증가합니다. 결과의 단위와 frame은 원본과 같은 의미를 유지합니다.

호출 전 확인과 해제

다음은 이미 열린 깊이 맵에서 시작하는 호출 단편입니다. 먼저 원본의 info.width와 info.height를 확인해 x + width, y + height가 각각 격자 범위 이내인지 검토합니다. 아래 숫자는 호출 형태를 보여 주며 모든 입력 맵에서 유효하다는 뜻은 아닙니다.

Python
with depth.roi(x=2, y=1, width=4, height=3) as region:
    info = region.info
    values = region.to_values()

정수가 아닌 좌표, 음수 시작점, 0인 크기 또는 범위 밖 영역은 성공 결과로 취급하지 않습니다. 래퍼의 인자 검사나 네이티브 호출에서 오류가 발생할 수 있습니다. 복사된 값 목록과 공유 핸들은 수명이 다르므로, 목록을 읽었다는 사실만으로 region을 해제한 것으로 간주하지 않습니다.
