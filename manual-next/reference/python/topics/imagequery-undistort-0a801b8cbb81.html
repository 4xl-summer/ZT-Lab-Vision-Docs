렌즈 왜곡 보정 단계를 현재 계획에 추가합니다.

확인된 인자 조건

interpolation: 보간 방식

border: 바깥 샘플에 사용할 값

lens: 렌즈 모델

반환: 수정된 ImageQuery입니다.

오류: 행렬, 크기 또는 보간 인자가 유효하지 않으면 오류입니다.

인자 선언

  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • interpolation · POSITIONAL_OR_KEYWORD · 기본값 없음
  • border · POSITIONAL_OR_KEYWORD · 기본값 없음

border: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

렌즈 보정 단계

렌즈 모델로 영상의 왜곡을 보정하는 계획을 추가합니다. 출력 위치에 대응하는 원본 표본을 읽을 때 보간과 영역 밖 경계값이 결과에 영향을 줍니다. 렌즈 파라미터의 전체 영상 좌표와 ROI 로컬 좌표를 구분합니다.

실행과 검증

lens, interpolation, border의 유효 조건을 확인하고 출력의 기준점을 원본과 비교합니다. 계수가 0인 항등 사례는 방향을 확인하는 데 유용하지만 실제 보정 정확도의 증거는 아닙니다. 실행 중 입력이나 옵션 오류가 날 수 있습니다.
