requests: 적용된 요청의 수입니다.

published: 적용된 결과 게시의 수입니다.

acks: 적용된 확인 응답의 수입니다.

duplicates: 중복으로 처리된 명령의 수입니다.

timeouts: 시간 초과로 전환된 횟수입니다.

resets: 적용된 초기화 횟수입니다.

이 호출의 입력과 객체 맥락

PlcStats는 모의 핸드셰이크에서 처리된 요청, 결과 게시, 확인, 중복, 시간 초과와 초기화의 누적 횟수를 담는 값입니다. 현재 상태 자체는 PlcInfo.state에서 확인하고, 통계는 이전에 무엇이 일어났는지 해석할 때 사용합니다. 성공한 명령 수와 네트워크로 실제 전송한 패킷 수는 같은 개념이 아닙니다. SimulatedPlc는 장비 전송을 수행하지 않습니다.

요청 ID 1에 대해 REQUEST, PUBLISH, ACK가 각각 한 번 적용되면 requests, published, acks를 확인하는 간단한 흐름을 만들 수 있습니다. 같은 요청을 반복해 DUPLICATE를 얻으면 중복 통계가 증가할 수 있으므로 요청 수만으로 모든 명령 시도를 세지 마세요. POLL을 통한 시간 초과와 RESET의 수도 별도로 볼 수 있습니다. 어떤 시각과 순서로 명령했는지 함께 보관해야 숫자를 올바르게 해석할 수 있습니다.
