python 공개 선언
PlanarDofResult(parameters: tuple, transform: object, initial_rms: float, final_rms: float, gradient: float, rank_ratio: float, iterations: int, accepted_steps: int, status: int, work: int) -> None

Selected-DOF transform, parameters, pixel-or-coordinate RMS and local solver status.

parameters: 적합된 (각도, X 이동, Y 이동, 양의 스케일) 튜플입니다. 각도는 라디안입니다.

transform: 적합된 평면 유사 변환입니다.

initial_rms: 최적화 전 대응점 잔차 RMS입니다.

final_rms: 최적화 후 대응점 잔차 RMS입니다.

gradient: 정규화 기울기 값입니다.

rank_ratio: 정규화 정규방정식의 피벗 비율입니다.

iterations: 수행한 반복 횟수입니다.

accepted_steps: 수용된 갱신 수입니다.

status: 고정, 수렴, 랭크 부족, 정지 또는 반복 한도 종료 상태입니다.

work: 사전 계산한 보수적 작업량 n × (12 × max_iterations + 3)이며 실제 소모 횟수가 아닙니다.

이 호출의 입력과 객체 맥락

적합된 각도·x/y 이동·양의 스케일과 평면 유사 변환, 전후 잔차 RMS 및 종료 상태를 담습니다. 각도는 라디안입니다. rank_ratio와 status는 랭크 부족이나 정지 상태를 읽는 데 필요하며 수렴 상태만으로 모든 관측 기하가 완벽하다고 가정하지 마세요. work는 보수적으로 사전 계산한 작업량이지 실제 소모 횟수가 아닙니다.
