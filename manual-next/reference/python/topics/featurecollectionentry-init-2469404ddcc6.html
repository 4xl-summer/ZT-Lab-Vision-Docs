FeatureCollectionEntry(id: int, model: 'FeatureModel', options: zvision._matching_features.FeatureSearchOptions, min_inliers: int = 3, min_inlier_fraction: float = 0.5) -> None

고유 u64 id, 소유 model, 모델별 options, 최소 inlier 수와 대응 대비 최소 비율을 지정합니다.

id: 모델 항목을 구별하는 부호 없는 64비트 고유 식별자입니다.

model: 검색할 특징점 모델입니다.

options: 이 모델에 적용할 FeatureSearchOptions입니다.

min_inliers: 승인에 필요한 최소 내점 수이며 3 이상입니다. 기본값 3입니다.

min_inlier_fraction: 전체 대응점 대비 필요한 최소 내점 비율로 0..1입니다. 기본값 0.5입니다.

값을 구성하고 해석하기

컬렉션에서 한 특징 모델을 검색할 때 모델, 고유 id 및 해당 모델에 적용할 검색 옵션과 수락 조건을 묶습니다. min_inliers는 내점 개수이고 min_inlier_fraction은 전체 대응점 대비 내점 비율이므로 두 값을 같은 조건으로 해석하지 않습니다. 결과 id를 입력 항목과 연결할 때 중복 없는 식별자를 사용합니다.
