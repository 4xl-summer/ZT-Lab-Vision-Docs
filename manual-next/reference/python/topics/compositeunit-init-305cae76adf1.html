CompositeUnit(unit_id: int, units_per_pixel: float) -> None

Explicit isotropic physical unit ID and positive units-per-pixel scale. The origin remains ROI-local, and this is not an optical or world calibration. Probe diagnostics retain pixel units.

unit_id: 출력 단위 식별자; 0은 픽셀.

units_per_pixel: 픽셀당 등방 배율; 양수이며 unit_id 0이면 1.

이 호출의 입력과 객체 맥락

복합 계측에서 픽셀 값을 물리 단위로 표현할 때 단위 식별자와 양의 등방 배율을 함께 전달합니다. units_per_pixel은 한 픽셀 길이에 대응하는 물리 길이이며 unit_id는 결과에 기록할 단위를 식별합니다. 예를 들어 배율이 0.1 mm/px인 경우 길이 20 px는 2 mm로 환산됩니다. 면적은 두 축의 길이 배율이 모두 적용되므로 같은 예의 100 px²는 1 mm²입니다. 이 값은 원점이나 회전, 원근을 정하는 카메라 보정이 아니며 계측 원점은 ROI 로컬 기준으로 남습니다. 또한 프로브의 개별 진단은 픽셀 단위를 유지하므로 물리 단위의 집계 결과와 같은 숫자로 직접 비교하지 마십시오. 서로 다른 축의 배율이 필요한 경우 이 단일 등방 배율 하나로 표현할 수 없습니다. 결과를 저장할 때 unit_id와 배율을 같이 남기고, 동일 설정에서 얻은 결과인지 확인해야 숫자의 변화가 영상의 변화인지 단위 변경인지 구분할 수 있습니다. 예시에서 0.1은 픽셀을 밀리미터로 바꾸는 길이 비율이지 좌표 원점을 이동시키는 벡터가 아닙니다. 관측 위치를 전체 영상의 위치로 표시하려면 별도로 ROI 원점을 더해야 합니다. 보고서에서는 수치와 함께 픽셀 또는 선택한 물리 단위를 명시하여 사용자가 단위를 추측하지 않게 합니다.

사용 흐름과 판독 기준

CompositeUnit은 복합 계측의 출력 단위 식별자와 픽셀당 등방 길이 배율을 묶습니다. unit_id는 결과의 단위를 식별하고 units_per_pixel은 한 픽셀 길이에 해당하는 단위 길이입니다. ID 0은 픽셀을 뜻하며 이 경우 배율은 1이어야 합니다. 물리 단위를 사용할 때 배율은 유한한 양수로 지정합니다.

길이에는 배율을 한 번, 면적에는 두 축에 각각 적용하므로 배율의 제곱을 사용합니다. 예를 들어 0.1 mm/px이면 20 px는 2 mm이고 100 px²는 100×0.1²=1 mm²입니다. 단일 등방 배율은 x와 y에 서로 다른 배율이 필요한 경우나 원근에 따라 위치마다 달라지는 보정을 표현하지 못합니다.

이 설정은 ROI 원점을 이동시키거나 회전과 렌즈 왜곡을 보정하지 않습니다. 결과의 기준 원점은 ROI 로컬이며 개별 프로브 진단은 픽셀 단위를 유지합니다. 따라서 물리 단위의 최종 결과와 프로브의 픽셀 수치를 직접 같은 숫자로 비교하지 말고 unit_id, 배율, 진단이 사용하는 단위를 함께 보관합니다.
