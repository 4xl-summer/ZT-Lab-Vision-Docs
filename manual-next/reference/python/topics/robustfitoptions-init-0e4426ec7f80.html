RobustFitOptions(loss: int = 1, scale: float = 0.5, initial_threshold: float = 2.0, inlier_threshold: float = 1.0, max_iterations: int = 30, tolerance: float = 1e-08, damping: float = 0.001) -> None

loss 0 least squares, 1 Huber, 2 Tukey; scale and thresholds use coordinate units. tolerance is dimensionless in normalized coordinates; damping is positive. Initial line/circle/ellipse estimates use the existing deterministic consensus.

loss: 손실 함수: 0 최소제곱, 1 Huber, 2 Tukey입니다. 기본값 1입니다.

scale: 강건 손실의 좌표 단위 스케일로 유한한 양수입니다. 기본값 0.5입니다.

initial_threshold: 초기 합의 적합의 좌표 단위 임계값으로 유한한 양수입니다. 기본값 2입니다.

inlier_threshold: 내점 판정의 좌표 단위 임계값으로 유한한 양수입니다. 기본값 1입니다.

max_iterations: 최대 반복 수 1..1000이며 기본값 30입니다.

tolerance: 정규화 좌표에서 사용하는 무차원 수렴 기준으로 유한한 양수입니다. 기본값 1e−8입니다.

damping: 최적화 감쇠값으로 유한한 양수입니다. 기본값 0.001입니다.

이 호출의 입력과 객체 맥락

손실 함수 loss, 좌표 단위 scale 및 초기 합의·내점 판정 임계값을 지정합니다. loss는 0 최소제곱, 1 Huber, 2 Tukey이고 기본은 Huber입니다. tolerance는 정규화 좌표의 무차원 수렴 기준이므로 좌표 단위인 inlier_threshold와 구분합니다. max_iterations는 1~1000이고 damping은 양수입니다. 설정값과 별도로 결과의 채택점 수와 잔차를 확인합니다.
