기준과 편차 영상으로 모델 생성

reference, variation과 선택적 mask로 이미 준비한 기준 및 편차 영상을 이용해 모델을 만듭니다. 세 입력은 영상 객체이며 기준과 편차가 같은 좌표의 값을 표현하는지 확인해야 합니다.

여러 표본을 train으로 학습하는 경로와 달리 이 호출은 전달한 영상에서 모델을 구성합니다. 선택 영역을 바꾸거나 편차의 단위를 잘못 해석하면 이후 검사 허용 범위도 달라질 수 있습니다. 반환 모델은 소유 객체로 사용 후 close합니다.
