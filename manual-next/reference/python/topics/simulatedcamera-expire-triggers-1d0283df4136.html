expire_triggers

method · 선언 타입 zvision._acquisition.SimulatedCamera

Python
expire_triggers(self, now_ns, timeout_ns)

기다린 트리거를 시간 기준으로 만료시킵니다.

확인된 인자 조건

now_ns: 현재 시각, 나노초 단위의 음이 아닌 정수입니다.

timeout_ns: 시간 초과 간격, 나노초 단위의 양의 정수입니다.

반환: 만료된 트리거 수를 반환합니다.

오류: 유효하지 않은 시간이나 상태는 오류입니다.

인자 선언

  • now_ns · POSITIONAL_OR_KEYWORD · 기본값 없음
  • timeout_ns · POSITIONAL_OR_KEYWORD · 기본값 없음

now_ns: 정수 검사.

timeout_ns: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

now_ns를 기준으로 대기 트리거 중 경과 시간이 양수 timeout_ns 이상인 항목을 제거하고 제거 개수를 반환합니다. 제거된 수는 trigger_missing에 더해집니다. 이 수는 프레임 ID 사이에서 계산하는 frame_missing과 다른 관측치이므로 물리적 손실량으로 단순 합산하지 않습니다. 같은 epoch에서 다른 취득 이벤트보다 시간이 뒤로 가면 오류이며 이 호출은 실제 시계를 기다리지 않습니다.
