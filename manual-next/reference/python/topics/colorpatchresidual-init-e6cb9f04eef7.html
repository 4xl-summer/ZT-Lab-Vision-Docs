index: 입력 패치 배열의 0부터 시작하는 인덱스입니다.

패치별 색차 기록

index는 입력 패치의 위치이고 before_delta_e와 after_delta_e는 보정 전후 색차입니다. 예를 들어 같은 패치에서 전이 6, 후가 2라면 그 패치의 색차는 줄어든 것입니다.

전체 평균이 낮아져도 개별 패치가 악화될 수 있으므로 인덱스를 원래 패치와 연결해 확인합니다. 값 스냅샷은 색 보정 결과의 소유 핸들과 다릅니다.
