dilate_values

method · 선언 타입 zvision._query.ImageQuery

Python
dilate_values(self, kernel, op=19)

값 팽창 단계를 가변 계획에 추가합니다.

확인된 인자 조건

kernel: 양의 홀수 정사각형 커널 폭

op: 기본값 19은 이 메서드에 연결된 ABI 연산 코드입니다. 다른 값을 전달하면 그 코드가 네이티브 Query에 전달되어 동작이 달라지거나 오류가 날 수 있습니다. 이 인자는 보통 기본값으로 둡니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 유효하지 않은 커널 또는 실행 오류가 보고될 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • op · POSITIONAL_OR_KEYWORD · 기본값 19

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

국소 밝기 최댓값

값 팽창은 각 위치 주변의 최댓값을 사용하는 단계를 추가합니다. 이웃 값이 1, 4, 2이면 최댓값은 4입니다. 밝은 값이 넓은 영역에 영향을 줄 수 있으므로 이진 성분 확대와 구별합니다.

폭의 의미

양의 홀수 kernel은 주변 범위의 폭이며 반복 횟수가 아닙니다. 실행 결과에서 작은 밝은 구조와 영상 테두리를 원본과 비교합니다. op는 기본 ABI 동작 코드로, 다른 값을 전달하면 다른 코드가 네이티브 계획에 전달될 수 있습니다.
