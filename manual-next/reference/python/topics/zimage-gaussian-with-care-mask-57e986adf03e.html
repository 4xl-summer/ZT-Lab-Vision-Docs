Filter care samples and mark pixels where the filter was applied.

유효 표본과 대체 픽셀

이 연산은 마스크가 선택한 이웃 표본만으로 Gaussian 가중 평균을 계산합니다. 일반적인 블러와 달리 모든 이웃을 같은 방식으로 포함한다고 가정하지 않습니다. 마스크는 Gray8이며 설정의 offset은 입력 픽셀 위치와 care 마스크 위치의 정렬을 지정합니다. 마스크의 비영 영역과 영상 위치가 의도대로 대응하는지 먼저 확인해야 합니다.

결과에는 필터 영상과 계산 여부를 나타내는 Gray8 마스크가 있습니다. 계산 마스크의 255는 해당 위치에서 필터가 적용됐음을, 0은 조건이 충족되지 않아 원래 중심 값을 복사했음을 뜻합니다. 양의 가중치를 가진 care 표본이 없거나 선택 비율이 minimum_fraction보다 낮은 경우가 복사 경로입니다. 따라서 결과 영상만 보고 모든 픽셀이 실제 평균으로 계산됐다고 판단할 수 없습니다.

가로·세로 sigma는 유한한 양수이며 minimum_fraction은 0부터 1까지입니다. 출력은 지정한 Gray8, Gray16 또는 GrayF32 중 하나입니다. 다른 형식이나 허용되지 않은 경계 설정, 크기·작업량 제한 위반은 오류가 됩니다. 반경을 키우면 창의 각 변이 2 × 반경 + 1이 되어 검사할 이웃 수가 늘어나므로, 출력 품질과 작업량을 입력 크기에 맞춰 평가해야 합니다.

두 결과 영상을 얻는 단편

이미 열린 입력 영상과 Gray8 마스크, 유효한 CareGaussianOptions를 사용하는 단편입니다. 결과 객체와 그 안에서 얻은 두 영상은 각각 소유 객체이므로 모두 닫습니다.

with image.gaussian_with_care_mask(mask, options) as result:
    with result.image(0) as filtered, result.image(1) as computed:
        filtered_info = filtered.info
