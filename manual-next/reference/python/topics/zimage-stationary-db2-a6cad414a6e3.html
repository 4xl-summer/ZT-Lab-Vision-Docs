stationary_db2(self, levels, centered)

지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

centered: 위상 중심 정렬 여부

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 없음

Return an independently owned stationary Daubechies-2 transform.

정지 Daubechies-2 변환

stationary_db2는 Daubechies-2 계열의 정지 웨이블릿 변환을 계산합니다. levels는 분해 단계이고 centered는 위상 중심 정렬 여부입니다. 단계와 정렬을 바꾸면 계수의 위치 해석이 달라질 수 있으므로 서로 다른 결과를 비교할 때 기록합니다.

결과 수명

입력 형식과 유효한 levels를 확인하고 반환된 독립 변환 객체를 사용한 뒤 닫습니다. 계수 영상은 원본 밝기와 같은 의미가 아니며 복원이나 밴드 접근은 해당 결과 타입의 계약을 따릅니다. 기준 입력을 사용해 정렬 효과를 확인합니다.
