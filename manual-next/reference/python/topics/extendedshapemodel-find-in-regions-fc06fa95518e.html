find_in_regions(self, source, options, anchor, region, max_outside, require_full=False, mask=None)

기준점과 변환 모델에 각각 영역 제약을 적용해 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 형상 검색 설정입니다.

anchor: 기준점 허용 사각형 (xmin,ymin,xmax,ymax)입니다.

region: 모델 허용 사각형입니다.

max_outside: 허용하는 영역 밖 비율로 0..1입니다.

require_full: 전체 포함을 요구할지 지정합니다.

mask: 선택 검색 마스크입니다.

반환: 독립 매치 결과와 종료 진단입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • anchor · POSITIONAL_OR_KEYWORD · 기본값 없음
  • region · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_outside · POSITIONAL_OR_KEYWORD · 기본값 없음
  • require_full · POSITIONAL_OR_KEYWORD · 기본값 False
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search subject to anchor and model region constraints.

호출 맥락과 결과 해석

anchor 사각형은 모델 기준점에 적용되고 region 사각형은 변환된 모델에 적용됩니다. 두 영역은 서로 다른 대상을 제한하므로 같은 사각형을 주더라도 기준점만 허용하는 것과 모델 전체의 영역 관계를 요구하는 것은 다른 조건입니다.

max_outside는 영역 밖에 허용하는 비율이며 0부터 1까지입니다. require_full의 전체 포함 요구와 함께 설정해 의도한 허용 범위를 표현합니다. 먼저 제약 없이 검색해 후보 포즈를 확인한 다음 영역 조건을 적용해 차이를 비교하면 좌표나 영역 설정 오류를 찾기 쉽습니다.
