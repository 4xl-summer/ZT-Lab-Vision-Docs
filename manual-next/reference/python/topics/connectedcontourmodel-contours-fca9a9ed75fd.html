원래 연결 순서의 모델 로컬 점들을 복사합니다.

반환: 폴리라인별 점 튜플의 독립 튜플입니다.

오류: 닫힌 모델은 오류입니다.

Return independent tuples of original ordered model-local input vertices.

모델 로컬 점 복사

원래 연결 순서의 모델 로컬 점들을 폴리라인별 독립 튜플로 복사합니다. 점을 x순으로 재정렬하면 원래 경로의 인접 관계가 깨질 수 있습니다. 닫힌 모델은 조회할 수 없어 오류입니다.

표시와 비교

각 폴리라인의 경계를 유지해 모델 좌표에 표시하고 검색 결과의 영상 좌표와 비교하려면 해당 변환을 적용합니다. 독립 튜플은 입력 꼭짓점의 복사이며 검색 영상에서 검출된 경계 자체와는 다릅니다.

모델 점의 독립 복사

contours()는 학습 모델의 원래 연결 순서에 있는 모델 로컬 꼭짓점을 폴리라인별 튜플로 복사합니다. 반환 구조의 바깥 튜플은 경로를 구분하고 각 경로는 순서 있는 점들을 보관합니다. 닫힌 모델에서 호출하면 오류입니다.

예를 들어 (0,0), (1,0), (1,1)의 순서를 바꾸면 원래 두 선분과 다른 연결이 만들어집니다. x 또는 y 좌표만으로 다시 정렬하지 말고 각 폴리라인의 경계도 유지합니다. 이 점들은 검색된 영상에서 새로 검출한 에지 목록이 아닙니다.

모델을 검색 영상 위에 표시할 때는 검색 결과가 제공하는 포즈와 모델 기준을 사용해 영상 좌표로 옮깁니다. 복사된 튜플과 모델 핸들의 수명은 구분하며, 서로 다른 입력 영상의 같은 좌표가 같은 장면을 뜻하는지도 확인합니다.

적용과 판독을 더 살펴보기

반환된 경로의 바깥 튜플은 모델을 구성하는 서로 다른 폴리라인을 구분합니다. 한 경로의 마지막 점을 다음 경로의 첫 점에 무조건 연결하면 모델에 없던 선분이 추가됩니다. 각 경로 안의 순서를 유지하여 모델의 형태를 살펴보고, 점의 개수와 닫힘 처리가 후속 도형 연산에 맞는지 확인합니다. 모델 로컬 좌표를 이미지 위에 그대로 그리면 검색으로 얻은 이동이나 회전이 반영되지 않습니다. 검색 결과가 제공하는 변환과 ROI 원점을 적용한 위치를 원본과 대조해야 합니다. 이미 복사한 값의 보관과 모델 핸들의 종료 시점도 별도로 다룹니다.
