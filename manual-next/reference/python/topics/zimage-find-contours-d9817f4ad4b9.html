find_contours

Python
find_contours(self, connectivity) -> 'ContourResult'

성분 셀 경계 윤곽를 계산합니다.

확인된 인자 조건

connectivity: 4 또는 8

반환: 원본과 독립된 값 스냅샷입니다.

오류: 연결 값 또는 입력이 잘못되면 오류입니다.

인자 선언

  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음

반환 타입 주석: ContourResult

Return independent contours with immutable point sequences.

영역 경계 읽기

전경의 경계는 성분 면적과 다른 정보를 담습니다. 구멍이 있는 성분은 바깥 윤곽과 내부 경계를 모두 살펴야 합니다. 윤곽을 따라 정렬된 점이나 선분의 순서를 임의로 바꾸면 경계 길이와 연결이 달라질 수 있습니다.

결과 활용

분석할 마스크의 전경 값과 ROI를 먼저 확인하고 결과를 원본과 겹쳐 봅니다. ROI 로컬 경로를 전체 영상에 표시하려면 원점이 필요합니다. 경계 점 수와 면적을 혼동하지 말고, 열린 경로인지 닫힌 경로인지 후속 측정의 조건을 확인합니다.
