색 보정 행렬 적용

ColorCorrection의 3×3 행렬과 RGB 편향을 사용해 입력 색을 조정합니다. 각 출력 채널은 입력의 세 채널이 행렬을 통해 결합된 뒤 해당 편향이 더해진 값으로 해석합니다. 예를 들어 단위 행렬과 0 편향은 색 보정의 기준 설정입니다.

보정 계수는 패치 대응값을 이용한 fit_color_correction 결과에서 얻을 수 있습니다. 결과의 보정 전후 평균과 최대 색차를 함께 확인하면 소수의 패치가 크게 벗어나는 경우를 놓치지 않을 수 있습니다. 학습 패치 외의 별도 입력에서도 효과를 확인합니다.

이 호출은 현재 영상의 즉시 처리 경로입니다. 반환이 소유 영상이나 소유 결과이면 사용 후 close하고, 값 스냅샷과 핸들의 수명을 구별합니다. 잘못된 입력이나 형식에서 발생한 오류를 빈 정상 결과로 치환하지 않습니다.
