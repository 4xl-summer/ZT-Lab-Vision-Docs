find(self, source, options, mask=None)

학습된 연결 윤곽으로 영상을 검색합니다.

확인된 인자 조건

source: 검색 ZImage

options: AdvancedMatchOptions

mask: 선택 ZImage 마스크; 기본값 None

반환: 독립 AdvancedMatchReport입니다.

오류: 인자 타입이 잘못되거나 max_occlusion_fraction이 0이 아니면 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Search the trained directed shape; returns detached shape matches.

연결 윤곽 모델 검색

학습된 연결 윤곽으로 source ZImage를 검색합니다. options는 AdvancedMatchOptions이고 선택 mask의 기본값은 None입니다. 입력 영상과 마스크가 같은 위치를 가리키는지 확인해야 탐색 영역을 올바르게 제한할 수 있습니다.

검색 결과

독립 AdvancedMatchReport를 읽어 후보의 위치와 진단 정보를 확인하고 원본 영상에 겹쳐 검토합니다. 인자 형식이나 옵션 제약이 잘못되면 오류가 납니다. 모델 입력 경로와 검출 결과의 좌표 기준도 구분합니다.
