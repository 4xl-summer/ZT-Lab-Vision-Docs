Python
encode(self, *, max_bytes)

온라인 기준을 바이트로 직렬화합니다.

확인된 인자 조건

max_bytes: 출력의 양의 바이트 상한.

반환: 독립 bytes 값입니다.

오류: 닫힌 객체 또는 호환되지 않는 입력과 한도 초과는 오류입니다.

인자 선언

  • max_bytes · KEYWORD_ONLY · 기본값 없음

max_bytes: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

현재 온라인 참조를 bytes로 직렬화합니다. max_bytes는 양수로 지정하고 반환한 바이트를 보관할 때 복원에 필요한 template 영상도 따로 관리합니다. 반환값은 파이썬 bytes이며 네이티브 결과 핸들이 아닙니다. 같은 객체에서 계속 작업할 수 있고, 나중에 decode할 때 바이트 한도와 픽셀 한도를 명시해야 합니다.
