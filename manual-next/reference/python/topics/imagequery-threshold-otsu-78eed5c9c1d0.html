method · 선언 타입 zvision._query.ImageQuery

Python
threshold_otsu(self, bin_count=None, lower=None, upper=None)

히스토그램 기준 Otsu 마스크 단계를 추가합니다.

확인된 인자 조건

bin_count: 균등 빈 수; 세 인자를 모두 생략할 수 있음

lower: 값 범위 하한; 기본값 None

upper: 값 범위 상한; 기본값 None

반환: 수정된 동일 ImageQuery입니다.

오류: 범위 인자를 일부만 넣거나 범위가 유효하지 않으면 오류입니다.

인자 선언

  • bin_count · POSITIONAL_OR_KEYWORD · 기본값 None
  • lower · POSITIONAL_OR_KEYWORD · 기본값 None
  • upper · POSITIONAL_OR_KEYWORD · 기본값 None

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

Otsu 분할 계획

현재 영상의 밝기 분포에서 Otsu 기준을 이용한 임계 분할 단계를 계획합니다. 입력 ROI나 이전의 대비 조정이 달라지면 히스토그램도 바뀌므로 선택되는 분할 경계를 고정된 숫자로 가정하지 않습니다.

실제 영상에서 검증

계획을 실행한 후 출력 마스크가 원하는 물체를 전경으로 포함하는지 원본과 비교합니다. 자동 선택은 알고리즘의 기준에 따른 값이지 조명 변화나 분포가 겹치는 모든 영상에서 검사 목적을 보장하는 판정은 아닙니다.
