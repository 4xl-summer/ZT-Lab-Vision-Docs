method · 선언 타입 zvision._blob_advanced.BlobResult

Python
get(self, index)

선택 Blob의 측정값을 복사합니다.

확인된 인자 조건

index: 0 기반 Blob 인덱스

반환: Blob 값입니다.

오류: 인덱스 범위 밖은 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

index: 정수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

0 기반 성분 조회

index가 가리키는 Blob 측정값을 복사해 반환합니다. 첫 성분은 인덱스 0이며 범위를 벗어나면 오류입니다. 반환 Blob의 면적은 전경 픽셀 수이고 좌표는 해당 결과의 ROI 기준으로 해석합니다.

결과 사용

예를 들어 3×3 테두리가 전경이고 가운데가 배경이면 면적 8과 폭·높이 3을 구분해야 합니다. 다른 프레임에서 같은 index가 같은 물체라는 보장은 없으므로 위치와 입력 프레임을 함께 기록합니다.
