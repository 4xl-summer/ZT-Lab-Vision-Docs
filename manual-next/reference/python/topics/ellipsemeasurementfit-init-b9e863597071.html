EllipseMeasurementFit(center: zvision._regions.Point2, major_radius: float, minor_radius: float, angle: float) -> None

Fitted ellipse center, radii and angle in ROI-local pixels and radians.

center: 타원 중심의 ROI 로컬 픽셀 좌표입니다.

major_radius: 장반축 길이로 픽셀 단위입니다.

minor_radius: 단반축 길이로 픽셀 단위입니다.

angle: 장축 회전각으로 라디안 단위입니다.

생성과 결과 판독

적합 타원의 중심, 두 반축과 라디안 각도를 ROI 로컬 픽셀 기준으로 표현합니다. 예를 들어 반축 4와 2는 전체 축 길이 8과 4이며 원점 중심에 회전이 없다면 (4,0)과 (0,2)는 축 끝점입니다. 다른 ROI 결과와 비교하려면 중심을 공통 좌표로 맞추고 각도의 기준을 함께 기록합니다.

단계별 확인

타원 중심과 장반축·단반축은 ROI 로컬 픽셀이고 angle은 장축 방향의 라디안입니다. 반축은 중심에서 경계까지의 거리이므로 전체 축 길이를 기록하려면 두 배가 됩니다.

예를 들어 중심 (0,0), 장반축 4, 단반축 2, 회전 0이면 축 끝점은 (±4,0), (0,±2)입니다. 다른 ROI의 중심과 비교할 때는 각각의 글로벌 원점을 적용하고, 각도와 반축의 정의를 같은 기준으로 맞추십시오.
