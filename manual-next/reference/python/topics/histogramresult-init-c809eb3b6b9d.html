값의 해석과 사용

channels는 채널별 빈의 2차원 불변 튜플입니다. 단일 채널도 채널 축을 유지합니다. 같은 빈 인덱스라도 빈 수와 값 범위가 다르면 다른 밝기 구간을 나타낼 수 있습니다.

채널별 빈 스냅샷

HistogramResult는 channels에 채널별 빈의 2차원 불변 튜플을 보관합니다. 바깥 축은 채널이고 안쪽 축은 값 구간별 개수입니다. 단일 채널 영상이어도 채널 축을 생략한 단일 숫자 목록으로 해석하지 않습니다.

한 채널의 세 빈이 (2,7,3)이면 세 구간에 포함된 표본 수가 각각 2, 7, 3입니다. 총 표본 수는 12입니다. 인덱스 1은 가운데 빈의 위치이지 밝기 값 1을 뜻하지 않습니다. 실제 구간은 빈 수와 하한·상한 설정으로 판독합니다.

한계공간 위치는 보존하지 않음

같은 빈 배열이라도 공간적 픽셀 배치는 보존되지 않습니다. 같은 분포를 가진 두 영상에서 결함의 위치가 다를 수 있으므로 공간 검사는 원본을 함께 사용합니다. 서로 다른 결과를 비교할 때 채널 순서, ROI와 빈 범위를 맞춥니다.

적용과 판독을 더 살펴보기

구간을 읽을 때 결과를 만든 히스토그램의 하한과 상한, 빈 수를 먼저 확인합니다. 같은 채널의 인덱스 1이어도 전체 범위를 다르게 지정했다면 포함하는 밝기 구간이 달라집니다. 마스크가 적용된 분석이라면 채널 빈의 합이 전체 영상 픽셀 수가 아니라 선택된 표본과 관련됩니다. 히스토그램은 분포를 요약하므로 밝은 픽셀이 영상의 가운데에 있는지 가장자리에 있는지는 알 수 없습니다. 위치가 필요한 판정에서는 원본이나 마스크를 함께 사용합니다. 다른 실행과 비교할 때 ROI, 채널 순서 및 값 범위를 일치시키고 입력 형식에 따른 단위도 기록합니다.
