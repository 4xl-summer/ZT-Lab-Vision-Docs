decode(cls, template, data, *, max_bytes, max_probes, max_work)

직렬화된 비드 기준 모델을 제한된 크기로 복원합니다.

확인된 인자 조건

template: ZImage 템플릿

data: bytes, bytearray 또는 memoryview

max_bytes: 양의 바이트 상한, 키워드 전용

max_probes: 2 이상의 탐침 상한, 키워드 전용

max_work: 양의 작업 상한, 키워드 전용

반환: 별도로 close할 BeadReference입니다.

오류: 데이터나 상한이 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • data · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_bytes · KEYWORD_ONLY · 기본값 없음
  • max_probes · KEYWORD_ONLY · 기본값 없음
  • max_work · KEYWORD_ONLY · 기본값 없음

max_bytes: 정수 검사 · 최소 1.

max_probes: 정수 검사 · 최소 2.

max_work: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

인자형식역할과 조건

비드 기준 복원

template 영상과 저장 바이트, 크기·탐침 수·작업 한도를 지정해 기준을 복원합니다. template은 복원된 경로를 검증할 영상의 기하와 형식을 제공하며 반환 모델은 close해야 합니다.

ROI 로컬 경로가 실제 검사 영상의 기준과 대응하는지 확인합니다. 손상된 데이터 또는 제한 초과 오류를 빈 경로의 유효 모델과 구분하고, 호출에 사용한 한도를 기록합니다.
