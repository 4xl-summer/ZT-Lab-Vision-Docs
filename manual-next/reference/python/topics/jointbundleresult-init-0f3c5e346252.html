JointBundleResult(cameras: tuple, boards: tuple, lenses: tuple, diagnostics: tuple, observation_rms: tuple, unit: object, initial_rms: float, final_rms: float, iterations: int, accepted_pose_steps: int, accepted_intrinsic_steps: int, planned_work: int, converged: bool, stalled: bool, exhausted: bool, rank_deficient: bool) -> None

Shared poses, Brown models and diagnostics. With all intrinsic masks fixed, per-camera initial and final RMS are both evaluated at the final poses.

cameras: 카메라별 6개 자세 값의 불변 튜플; 카메라 0 좌표계를 기준으로 함.

boards: 보드별 6개 자세 값의 불변 튜플; 카메라 0 좌표계 기준.

lenses: 카메라별 결과 LensModel 튜플.

diagnostics: 카메라별 내부 파라미터 블록의 IntrinsicDiagnostic 튜플. 모든 내부 계수 마스크가 0이면 각 진단의 초기·최종 RMS는 모두 반환된 최종 자세에서 계산됨.

observation_rms: 입력 관측 순서의 재투영 RMS; 픽셀.

unit: 보드 좌표와 자세 이동의 길이 단위.

initial_rms: 초기 전체 2D 재투영 거리 RMS; 픽셀.

final_rms: 최종 전체 2D 재투영 거리 RMS; 픽셀.

iterations: 수행한 외부 반복 횟수.

accepted_pose_steps: 목적함수 감소로 수용한 자세 갱신 횟수.

accepted_intrinsic_steps: 목적함수 감소로 수용한 내부 계수 갱신 횟수.

planned_work: 검사된 보수적 작업량.

converged: 국소 수렴 상태.

stalled: 국소 단계가 정체되었는지 여부.

exhausted: 반복 상한에 도달했는지 여부.

rank_deficient: 내부 계수 블록에서 랭크 부족이 발견되었는지 여부; 자세 블록 전체의 관측가능성 보증은 아님.

이 호출의 입력과 객체 맥락

카메라 0 프레임 기준의 카메라·보드 자세, 렌즈와 관측별 픽셀 RMS를 담습니다. 자세 이동과 보드 좌표는 unit 길이 단위입니다. accepted_pose_steps와 accepted_intrinsic_steps는 서로 다른 갱신 수이며, rank_deficient는 내부 계수 블록의 랭크 부족을 뜻할 뿐 자세 블록 전체의 관측가능성을 보장하지 않습니다. 수렴·정체·예산 소진 상태를 함께 확인합니다.
