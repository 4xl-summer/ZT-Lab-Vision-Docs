from_bgr8

classmethod · 선언 타입 zvision.ZImage

Python
from_bgr8(cls, width, height, pixels)

BGR 순서 바이트를 복사하여 영상을 만듭니다.

확인된 인자 조건

width: 양의 픽셀 폭

height: 양의 픽셀 높이

pixels: 행 우선 BGR 순서 바이트; 폭×높이×3개 성분

반환: 별도로 close할 ZImage입니다.

오류: 크기·성분 수·형식 또는 값 범위가 잘못되면 오류입니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음

Copy packed BGR bytes.

픽셀 배치와 크기

BGR8는 픽셀마다 파랑·초록·빨강 바이트를 3개 성분으로 저장합니다. width와 height는 픽셀 크기이고 입력 성분은 행 우선 순서입니다. 예를 들어 폭 2, 높이 2이면 3×2×2 = 12개 성분을 준비해야 합니다. 픽셀 수와 성분 수를 같은 것으로 취급하면 다채널 영상의 길이가 맞지 않습니다.

형식과 결과 확인

pixels에는 bytes 또는 bytearray를 해당 형식의 허용 범위에 맞게 전달합니다. 한 픽셀의 성분 순서 예는 0, 0, 255입니다. 반환 ZImage는 별도 소유 객체이므로 사용이 끝나면 close 또는 with로 정리합니다. 크기, 자료형, 성분 수 또는 값 범위가 맞지 않는 입력은 오류 조건을 확인합니다.

항목이 호출의 값
형식BGR8
픽셀당 성분3
2×2 성분 수12
