LocalDeformableOptions(coarse: zvision._matching_advanced.AdvancedMatchOptions, grid_x: int = 3, grid_y: int = 3, iterations: int = 20, initial_step: float = 1.0, tolerance: float = 0.05, smoothness: float = 1.0, max_deformation: float = 3.0, min_quality: float = 0.0, max_work: int = 100000000) -> None

Coarse NCC search and local displacement optimization. Quality uses input intensity units.

coarse: 거친 NCC 포즈용 AdvancedMatchOptions입니다. 형상 극성·격자 정밀화와 형상 전용 옵션은 지원하지 않습니다.

grid_x: x 제어점 수 2..16이며 기본값 3입니다.

grid_y: y 제어점 수 2..16이며 기본값 3입니다.

iterations: 국소 반복 상한 1..100이며 기본값 20입니다.

initial_step: 초기 변위 탐색 간격(픽셀)으로 유한한 양수이며 기본값 1입니다.

tolerance: 국소 정지 간격(픽셀)으로 유한한 양수이며 기본값 0.05입니다.

smoothness: 평활 가중치로 유한한 비음수이며 기본값 1입니다.

max_deformation: 허용할 국소 변위 크기(픽셀)로 유한한 양수이며 기본값 3입니다.

min_quality: 허용 품질 하한 0..1이며 기본값 0입니다.

max_work: 작업 상한 1..1000000000이며 기본값 100000000입니다.

이 호출의 입력과 객체 맥락

거친 NCC 포즈 설정 coarse와 2~16개의 각 축 제어점, 변위 탐색·평활 조건을 묶습니다. initial_step, tolerance, max_deformation은 픽셀 기준이며 iterations와 max_work는 각각 별도 상한입니다. grid_x=3, grid_y=3이면 제어점 격자는 3×3입니다. coarse는 형상 극성·격자 정밀화 및 형상 전용 옵션을 지원하지 않습니다. 결과의 품질과 실제 허용 변형을 함께 확인하세요.
