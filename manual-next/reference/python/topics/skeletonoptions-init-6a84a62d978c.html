SkeletonOptions(connectivity: int = 8, max_iterations: int = 1000, work_budget: int = 100000000)

connectivity: 전경 이웃 연결성입니다.

max_iterations: 반복 횟수의 상한입니다.

work_budget: 허용하는 작업량의 상한입니다.

이 호출의 입력과 객체 맥락

이진 형상을 골격화할 때 전경 이웃 connectivity와 최대 반복 수, 작업 예산을 지정합니다. 기본값은 8연결, 1000회, 100000000 작업량입니다. 연결 기준에 따라 대각선으로 만나는 전경의 관계가 달라질 수 있으므로 후속 그래프 해석에도 같은 기준을 기록하세요. 이 설정을 생성하는 것만으로 영상이 처리되지는 않습니다.

입력과 결과를 읽는 순서

이진 전경을 골격화할 때 사용할 연결성, 반복 상한 및 작업 예산을 담습니다. 기본 connectivity는 8, max_iterations는 1000, work_budget은 100000000입니다. 설정 객체를 만드는 동작과 실제 마스크에서 골격을 계산하는 동작은 서로 별개입니다.

연결성은 4 또는 8 이웃으로 해석합니다. 예를 들어 대각선으로만 닿은 두 전경 픽셀은 4연결과 8연결에서 같은 방식으로 묶이지 않습니다. 후속 그래프의 노드·간선을 비교하려면 원래 마스크의 ROI와 사용한 연결 기준을 함께 기록하세요.

max_iterations는 반복 횟수의 상한이고 work_budget은 허용 계산량의 상한입니다. 두 수는 서로 대체할 수 없으며 충분한 예산을 지정하지 못한 실패를 완성된 골격으로 취급하지 않습니다. 실제 반환 결과의 수렴 상태와 반복 정보를 확인해야 합니다.

예를 들어 대각선으로 연결된 한 쌍의 전경을 처리할 때 연결성을 바꾸면 이후 만들어지는 연결 구조의 해석도 바뀔 수 있습니다. 두 실행의 출력이 다른 경우 반복 상한, 작업 예산과 입력 마스크까지 함께 비교하세요. iterations는 허용 최대치이고 실제 수행한 수는 실행 결과의 보고에서 확인해야 합니다. 결과 영상은 이 옵션 값 자체와 수명이 다릅니다.
