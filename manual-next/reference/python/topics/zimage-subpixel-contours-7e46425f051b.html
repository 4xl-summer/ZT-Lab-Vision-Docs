subpixel_contours(self, level) -> 'SubpixelContourResult'

입력에서 등값선 경로를 구합니다.

확인된 인자 조건

level: 유한한 등값 레벨

반환: 점 배열을 포함한 독립 스냅샷입니다.

오류: 지원하지 않는 입력이나 비유한 레벨은 오류입니다.

인자 선언

  • level · POSITIONAL_OR_KEYWORD · 기본값 없음

반환 타입 주석: SubpixelContourResult

level: 유한한 수 검사.

Return independent subpixel contours with immutable point sequences.

등치선의 소수 위치

밝기 등치선을 픽셀 중심 사이에서 보간하여 소수 좌표의 경로를 구합니다. 점의 소수 표현은 격자 사이 위치를 나타내지만 실제 장비 정확도가 그 자릿수만큼 보장된다는 뜻은 아닙니다. 등치값과 입력 대비가 경로 위치에 영향을 줍니다.

경로 해석

각 경로의 점 순서와 닫힘 여부를 유지하여 길이나 표시 계산에 사용합니다. ROI 로컬 점을 전체 영상에 표시할 때 원점을 적용하고, 정수 화면 좌표로 반올림한 값을 정밀 계산의 원본으로 사용하지 않도록 구분합니다.
