classmethod · 선언 타입 zvision._matching_features.FeatureModel

Python
from_bytes(cls, data)

직렬화된 특징 모델을 복원합니다.

확인된 인자 조건

data: 비어 있지 않고 16000000바이트 이하인 모델 bytes입니다.

반환: 호출자가 닫아야 하는 독립 모델입니다.

오류: 잘못된 타입·길이·형식 또는 손상된 데이터는 오류입니다.

인자 선언

  • data · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

직렬화된 특징 모델 바이트를 읽어 독립 모델로 복원합니다. data는 비어 있지 않아야 하고 길이는 16000000바이트 이하여야 합니다. 이미지의 원본 픽셀 바이트가 아니라 해당 모델 형식의 데이터를 입력합니다.

반환 모델은 호출자가 닫습니다. to_bytes로 얻은 전체 바이트를 보관하고 복원 뒤 동일 검색 조건을 적용해 확인하면 됩니다. 로드가 실패하면 바이트의 길이, 완전성과 모델 종류를 살핍니다.

입력 선택을 위한 확인

입력의미와 조건
data비어 있지 않고 16000000바이트 이하인 모델 bytes입니다.

반환값 확인

호출자가 닫아야 하는 독립 모델입니다.
