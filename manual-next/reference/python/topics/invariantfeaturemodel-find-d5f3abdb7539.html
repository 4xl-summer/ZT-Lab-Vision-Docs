find(self, source, options, mask=None)

다중 해상도 모델을 검색 영상 특징과 대응시킵니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 특징 대응과 기하 검증 설정입니다.

mask: 선택적 검색 마스크입니다.

반환: 영상과 모델에서 독립된 FeatureMatchResult입니다.

오류: 닫힌 모델 또는 유효하지 않은 입력은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

다중 해상도 모델 특징을 검색 영상의 특징과 대응시킵니다. options는 대응과 기하 검증 설정이며 mask는 선택 검색 마스크입니다. 학습된 특징의 위치, 배율 및 방향이 해석의 출발점입니다.

반환 FeatureMatchResult는 입력 영상과 모델에 독립적입니다. 결과의 대응과 추정 변환을 함께 확인하고, 기대한 변환을 얻지 못하면 검색 영상의 특징 분포와 대응 조건을 살핍니다. 모델 종류가 다르면 적용할 학습·복원 경로도 구분합니다.

options특징 대응과 기하 검증 설정입니다.
mask선택적 검색 마스크입니다.
