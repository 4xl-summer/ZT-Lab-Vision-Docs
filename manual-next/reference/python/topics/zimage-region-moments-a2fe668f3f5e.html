region_moments(self, connectivity) -> 'MomentsResult'

연결 성분의 모멘트를 계산합니다.

확인된 인자 조건

connectivity: 4 또는 8

반환: 원본과 독립된 값 스냅샷입니다.

오류: 연결 값 또는 입력이 잘못되면 오류입니다.

인자 선언

  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음

반환 타입 주석: MomentsResult

Return an independent region moments snapshot.

영역의 위치 통계

영역 모멘트는 선택된 픽셀의 좌표와 가중치에 따른 합으로 형상을 요약합니다. 예를 들어 균일한 두 픽셀 x=0과 x=2의 좌표 합은 2이고 픽셀 수는 2이므로 평균 x는 1입니다. 차수와 정규화 여부를 확인해야 숫자의 의미가 정해집니다.

좌표계와 해석

ROI의 원점이나 픽셀 좌표 단위가 바뀌면 위치를 포함한 모멘트의 값도 달라질 수 있습니다. 원본 전경과 결과를 함께 확인하고 물리 좌표가 필요하면 보정을 별도로 적용합니다. 결과 하나만으로 모든 형상 차이를 구별할 수는 없습니다.
