find_projective(self, source, options, perspective_x, perspective_y, mask=None)

원근 분모의 두 계수 격자를 포함하여 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 검색 설정입니다.

mask: 선택적 검색 마스크입니다.

perspective_x: x 원근 계수의 격자입니다.

perspective_y: y 원근 계수의 격자입니다.

반환: 원근 계수가 포함된 독립 검색 결과와 종료 진단을 반환합니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • perspective_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • perspective_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search with explicit perspective axes.

호출 맥락과 결과 해석

기본 포즈 격자에 더해 원근 분모의 x·y 계수 격자를 검색합니다. perspective_x와 perspective_y는 각각 해당 방향의 계수 축이며 결과에는 선택된 원근 계수가 포함됩니다. 이 값은 단순한 평행 이동 거리나 회전각이 아닙니다.

원근 축을 추가하면 다른 포즈 축과 조합되는 후보 수가 늘어납니다. 입력 영상과 검색 범위, 후보 예산 및 종료 진단을 함께 기록하고, 반환된 포즈의 원근 계수까지 확인해야 어떤 변환이 선택되었는지 재현할 수 있습니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options확장 검색 설정입니다.
perspective_xx 원근 계수의 격자입니다.
perspective_yy 원근 계수의 격자입니다.
mask선택적 검색 마스크입니다.

반환값 확인
