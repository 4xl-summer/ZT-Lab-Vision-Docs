train_ncc

classmethod · 선언 타입 zvision._matching_advanced.AdvancedMatchModel

Python
train_ncc(cls, template, reference, sample_step=1, mask=None)

표본화한 NCC 템플릿을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 ZImage입니다.

reference: 유한한 템플릿 로컬 Point2 기준점이며 영상 밖도 가능합니다.

sample_step: 양의 표본 간격(픽셀)이며 기본값 1입니다.

mask: 같은 크기·원점의 선택 Gray8 마스크입니다.

반환: 호출자가 닫아야 하는 독립 모델입니다.

오류: 선택 표본이 3개 미만이거나 상수, 또는 마스크·설정이 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

템플릿을 표본화해 확장 NCC 모델을 만듭니다. reference는 템플릿 로컬 좌표의 유한한 Point2로 영상 밖의 점도 지정할 수 있습니다. 검색 결과의 포즈는 이 기준점이 검색 영상에서 놓이는 위치로 해석합니다.

sample_step은 양의 픽셀 간격이고 마스크는 템플릿과 크기 및 원점이 같은 Gray8 영상입니다. 템플릿은 Gray8, Gray16 또는 유한 GrayF32입니다. 반환된 독립 모델을 검색에 사용하고 작업이 끝나면 호출자가 닫습니다.

입력의미

reference유한한 템플릿 로컬 Point2 기준점이며 영상 밖도 가능합니다.
sample_step양의 표본 간격(픽셀)이며 기본값 1입니다.
mask같은 크기·원점의 선택 Gray8 마스크입니다.
