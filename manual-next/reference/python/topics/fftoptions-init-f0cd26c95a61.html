FftOptions(width: int, height: int, normalization: zvision._frequency_processing.FftNormalization = <FftNormalization.BACKWARD: 0>)

width: 입력 폭 이상인 2의 거듭제곱 변환 폭입니다.

height: 입력 높이 이상인 2의 거듭제곱 변환 높이입니다.

normalization: 정규화 방식이며 기본값 BACKWARD입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
width입력 폭 이상인 2의 거듭제곱 변환 폭입니다.필수
height입력 높이 이상인 2의 거듭제곱 변환 높이입니다.필수
normalization정규화 방식이며 기본값 BACKWARD입니다.<FftNormalization.BACKWARD: 0>

값의 해석과 사용

예를 들어 입력이 5×3이면 폭 8, 높이 4는 각각 입력 이상인 2의 거듭제곱입니다. 변환 격자의 총 표본 수는 32입니다. BACKWARD 정규화의 정변환과 역변환 배율을 함께 기록합니다.

정규화 예

입력 5×3을 8×4 격자로 변환하면 N은 32입니다. BACKWARD는 정변환 배율 1과 역변환 1/N을 사용하고 ORTHONORMAL은 각각 1/√N을 사용합니다. 변환과 역변환의 설정을 함께 기록합니다.
