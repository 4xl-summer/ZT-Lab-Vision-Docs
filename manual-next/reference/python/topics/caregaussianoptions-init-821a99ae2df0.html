CareGaussianOptions(radius_x: int, radius_y: int, sigma_x: float, sigma_y: float, minimum_fraction: float = 0.0, offset_x: int = 0, offset_y: int = 0, border: int = 0, output_format: int = <PixelFormat.GRAYF32: 3>, constant: float = 0.0) -> None

Radii in pixels, positive sigmas, care fraction and mask alignment.

radius_x: 가로 창 반경으로 음이 아닌 픽셀 정수입니다.

radius_y: 세로 창 반경으로 음이 아닌 픽셀 정수입니다.

sigma_x: 가로 방향의 유한한 양의 표준편차입니다.

sigma_y: 세로 방향의 유한한 양의 표준편차입니다.

minimum_fraction: 계산에 필요한 care 표본 비율로 0–1이며 기본값은 0입니다.

offset_x: 영상 ROI 기준 care 마스크 원점의 가로 오프셋으로 기본값은 0입니다.

offset_y: 영상 ROI 기준 care 마스크 원점의 세로 오프셋으로 기본값은 0입니다.

border: 복제·반사·상수 경계 방식이며 기본값은 복제입니다.

output_format: 출력 회색 형식으로 Gray8, Gray16 또는 GrayF32이며 기본값은 GrayF32입니다.

constant: 상수 경계 밝기이며 기본값은 0입니다. 상수 경계가 아니면 0이어야 합니다.

이 호출의 입력과 객체 맥락

가로·세로 창 반경과 양의 sigma, care 표본 최소 비율 및 마스크 오프셋을 지정합니다. 반경은 픽셀이고 minimum_fraction은 0~1입니다. care 마스크 오프셋은 영상 ROI 기준이며 border가 상수가 아니면 constant는 0이어야 합니다. 결과의 계산 마스크에서 필터가 실제 계산된 위치와 입력을 복사한 위치를 구분합니다.
