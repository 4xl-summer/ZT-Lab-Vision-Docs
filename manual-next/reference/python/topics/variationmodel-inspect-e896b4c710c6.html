inspect(self, image, options)

모델 기준과 입력의 편차를 허용치와 비교합니다.

확인된 인자 조건

image: 모델 템플릿과 형식·기하가 같은 영상.

options: VariationInspectOptions의 유한한 0 이상 허용치.

반환: VariationResult 소유 객체이며 close합니다.

오류: 닫힌 객체나 유효하지 않은 인수는 오류입니다.

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

변동 모델로 영상 검사

검사 영상과 VariationInspectOptions를 사용해 모델 기준에서 벗어난 픽셀을 검사하고 소유 VariationResult를 반환합니다. 영상과 모델이 같은 좌표의 대상을 가리키는지 먼저 확인합니다.

정상 학습 표본의 편차와 검사 옵션은 결과에 영향을 줍니다. 정렬에 실패한 영상을 비교하면 경계가 결함으로 나타날 수 있으므로 비교 전에 정렬 상태를 확인합니다. 결과와 그 결과에서 획득한 영상의 수명은 각각 확인하고 해제합니다.
