CircleSearchGrid(origin: zvision._regions.Point2, step_x: float, step_y: float, columns: int, rows: int, center_separation: float, radius_separation: float, max_results: int = 64) -> None

Bounded ROI-local candidate centers; steps and suppression distances use pixels.

origin: 첫 후보의 ROI 로컬 기준 Point2.

step_x: 양의 가로 격자 간격; 픽셀.

step_y: 양의 세로 격자 간격; 픽셀.

columns: 열 수; rows와 곱은 1–64.

rows: 행 수; columns와 곱은 1–64.

center_separation: 중복 제거 중심 간 거리 한계; 유한한 0 이상 픽셀.

radius_separation: 중복 제거 반경 차 한계; 유한한 0 이상 픽셀.

max_results: 최대 반환 수 1–64.

이 호출의 입력과 객체 맥락

ROI 로컬 기준 origin에서 양의 step_x/y와 열·행 개수로 원 후보 기준점 격자를 만듭니다. columns×rows는 1~64이고 max_results도 1~64입니다. 예를 들어 2열 3행은 후보 기준점 6개를 나타냅니다. 중심 거리와 반경 차의 중복 제거 한계는 모두 픽셀 단위입니다. 입력 영상의 글로벌 원점과 로컬 후보 좌표를 구분하세요.
