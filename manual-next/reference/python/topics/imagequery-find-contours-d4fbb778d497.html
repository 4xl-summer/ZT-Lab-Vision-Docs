전경 경계의 분석 계획

현재 계획 결과의 전경 경계를 윤곽으로 분석합니다. 내부 구멍이 있으면 외부 윤곽과 구멍 경계를 함께 살펴야 합니다. 경계 점의 수는 물체의 전경 픽셀 면적과 다른 측정치입니다.

순서와 좌표

실행 결과의 경로 순서와 닫힘 여부를 유지해 표시합니다. ROI 로컬 좌표와 전체 영상의 원점을 맞추고, 이전 임계 처리나 형태학 단계가 경계 위치에 영향을 줄 수 있음을 고려합니다. 목록 순서를 프레임 간 물체 ID로 가정하지 않습니다.
