train_with_mask_offset(cls, image, metric, mask, offset_x, offset_y)

템플릿 로컬 offset에 놓인 마스크로 모델을 학습합니다.

확인된 인자 조건

image: 방식에 맞는 RGB8 또는 Gray8 템플릿입니다.

metric: TemplateMetric 방식입니다.

mask: 템플릿 전체를 덮는 Gray8 마스크입니다.

offset_x: 마스크 원점의 템플릿 로컬 x 오프셋인 int32입니다.

offset_y: 마스크 원점의 템플릿 로컬 y 오프셋인 int32입니다.

반환: 호출자가 닫아야 하는 모델입니다.

오류: 마스크 범위·형식이나 선택점이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • metric · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_y · POSITIONAL_OR_KEYWORD · 기본값 없음

metric: 정수 검사 · 최소 0.

offset_x: 정수 검사.

offset_y: 정수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Train with a Gray8 care mask whose (0,0) is at the specified template-local offset.

호출 맥락과 결과 해석

템플릿 로컬 offset에 놓인 Gray8 마스크를 사용해 정수 평행이동 모델을 만듭니다. offset_x와 offset_y는 마스크 원점의 템플릿 로컬 좌표를 나타내는 int32 값입니다. 마스크는 템플릿 전체를 덮어야 합니다.

마스크 이미지의 원점과 템플릿 원점을 같다고 가정하지 말고 offset과 함께 선택 영역을 확인합니다. 입력 영상은 COLOR_NCC라면 RGB8, GRAY_SAD라면 Gray8을 사용합니다. 만들어진 모델은 호출자가 닫습니다.

입력 선택을 위한 확인

입력의미와 조건
image방식에 맞는 RGB8 또는 Gray8 템플릿입니다.
metricTemplateMetric 방식입니다.
mask템플릿 전체를 덮는 Gray8 마스크입니다.
offset_x마스크 원점의 템플릿 로컬 x 오프셋인 int32입니다.
offset_y마스크 원점의 템플릿 로컬 y 오프셋인 int32입니다.

반환값 확인
