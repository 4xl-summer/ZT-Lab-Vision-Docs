StatisticsQuery.execute 공개 계약

상위 목차로 돌아가기

execute

method · 선언 타입 zvision._query.StatisticsQuery

Python
execute(self) -> 'QueryExecution[Statistics]'

계획을 실행해 통계 스냅샷과 캡처를 제공합니다.

반환: 닫아야 하는 형식 지정 실행 객체입니다. 얻은 값 스냅샷은 실행을 닫은 뒤에도 유효합니다.

오류: 닫힌 계획 또는 실행 오류가 발생하면 예외가 발생합니다.

반환 타입 주석: QueryExecution[Statistics]

계획을 실행하고 불변 결과를 반환한다.

이 호출의 입력과 객체 맥락

계획된 통계 쿼리를 실행하여 QueryExecution[Statistics]를 반환합니다. 실행이 열린 동안 output에서 count, min, max, mean, variance가 있는 불변 스냅샷을 얻습니다. 예를 들어 결과를 변수에 저장한 뒤 실행을 close하면 저장한 스냅샷은 계속 유효하지만 닫힌 실행에서 output을 다시 가져올 수는 없습니다. 캡처 이미지가 있으면 get_image로 별도 소유 영상을 얻고 각각의 수명을 관리합니다.

통계 계획의 실행

StatisticsQuery.execute는 구성된 지연 계획을 실제로 실행해 QueryExecution[Statistics]를 반환합니다. execute 이전에는 계획이 통계값을 계산했다고 가정하지 않습니다. 실행 중 입력 형식이나 영상 상태가 유효하지 않으면 오류를 확인해야 합니다.

실행 후 output에서 통계를 읽고 분석한 영상의 ROI 및 전처리 순서를 함께 기록합니다. 예를 들어 값 0과 100의 평균과 값 50 두 개의 평균은 모두 50입니다. 평균이 같아도 분포와 공간 배치는 다르므로 필요한 최소·최대 등 다른 필드도 확인합니다.

실행 객체는 close합니다. 이미 읽은 독립 불변 값 스냅샷과 실행에 이름 붙인 영상 캡처는 서로 다른 수명 관계를 가질 수 있습니다. 캡처를 획득했다면 반환 ZImage도 별도로 close하고, 원본 데이터가 필요한 분석에는 입력을 유지합니다.

적용과 판독을 더 살펴보기

통계를 구성한 계획의 이전 단계를 확인해야 결과의 대상이 원본인지 변환된 영상인지 알 수 있습니다. 예를 들어 밝기를 조정한 다음 통계를 실행하면 평균도 조정된 값의 평균입니다. 다른 실행과 비교할 때는 픽셀 형식과 ROI, 전처리 옵션을 함께 기록합니다. 평균이나 최댓값 같은 요약 통계는 각 값이 영상의 어느 위치에 있었는지 보존하지 않습니다. 위치가 중요한 결함 검사는 결과 영상이나 마스크를 같은 좌표에서 따로 확인해야 합니다. 실행 실패와 통계 결과가 0인 정상 사례는 다르므로 예외를 정상 숫자로 대체하지 않습니다.
