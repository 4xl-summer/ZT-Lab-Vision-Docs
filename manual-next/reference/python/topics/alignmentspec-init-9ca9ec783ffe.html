AlignmentSpec(reference_roi: tuple, search: zvision._matching.MatchSpec, interpolation: zvision._calibration.Interpolation = <Interpolation.BILINEAR: 1>, min_valid_fraction: float = 1.0)

reference_roi: 기준 영상 로컬 (x, y, 너비, 높이)이며 반열림 사각형입니다. 크기는 양수이고 기준 영상 범위 안에 있어야 합니다.

search: 기준 ROI의 NCC 모델을 검사 영상에서 찾는 MatchSpec입니다.

interpolation: 정렬된 영상을 생성할 Nearest 또는 Bilinear 보간입니다. 기본값은 Bilinear입니다.

min_valid_fraction: 기준 전체 격자 중 필요한 유효 픽셀 비율이며 (0, 1]입니다. 기본값은 1입니다.

이 호출의 입력과 객체 맥락

reference_roi는 기준 영상 로컬의 (x, y, 너비, 높이) 반열림 사각형이며 크기가 양수이고 영상 안에 있어야 합니다. search는 이 ROI의 NCC 모델을 검사 영상에서 찾는 설정입니다. interpolation은 정렬 영상의 보간이고 min_valid_fraction은 기준 전체 격자에서 필요한 유효 픽셀 비율로 (0,1]입니다. 예를 들어 기본값 1은 전체 기준 격자에 유효 표본을 요구합니다. 정렬 성공과 유효 마스크는 결과에서 따로 확인합니다.

기준 영역부터 정렬 결과까지

AlignmentSpec은 기준 영상에서 모델로 사용할 reference_roi, NCC 검색용 MatchSpec, 결과 영상의 interpolation과 min_valid_fraction을 묶습니다. reference_roi는 기준 영상 로컬의 반열림 (x,y,width,height)이며 크기가 양수이고 기준 영상 안에 있어야 합니다.

예를 들어 ROI가 (2,3,4,2)이면 기준 영상에서 x=2..5, y=3..4의 셀이 모델 영역입니다. search의 회전·배율 격자와 점수 조건으로 이 영역에 대응하는 위치를 검사 영상에서 찾습니다. ROI 좌상단과 모델 기준점은 다르므로 반환 위치를 해석할 때 기준점을 확인합니다.

interpolation은 정렬 영상을 생성할 때 사용할 Nearest 또는 Bilinear이며 기본은 Bilinear입니다. min_valid_fraction은 기준 전체 격자 중 필요한 유효 비율로 (0,1]이고 기본 1은 모든 위치의 유효성을 요구합니다. 정렬 결과의 found와 유효 마스크를 함께 읽어 검색 실패와 일부 유효 영역을 구분합니다.
