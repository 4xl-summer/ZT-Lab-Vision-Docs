mapping: 글로벌 픽셀에서 세계 평면으로의 호모그래피.

unit: 매핑에 저장된 세계 좌표의 길이 단위.

생성과 결과 판독

글로벌 픽셀에서 세계 평면으로 가는 Homography와 세계 길이 단위로 평면 보정 값을 구성합니다. ROI 로컬 점은 원점을 더해 글로벌 픽셀로 바꿔야 합니다. 예를 들어 원점 (100,200)과 로컬 (10,20)은 글로벌 (110,220)입니다. 매핑의 방향과 세계 단위를 함께 기록하고 별도 보류점에서 결과를 검증하십시오.

단계별 확인

호모그래피는 글로벌 픽셀 위치를 세계 평면에 대응시키는 투영 변환입니다. 로컬 ROI 점을 입력으로 사용할 때는 영상에서 ROI가 시작하는 글로벌 원점을 먼저 더해야 합니다. 예를 들어 로컬 (10,20)에 원점 (100,200)을 더한 (110,220)이 보정 입력입니다.

세계 좌표는 구성한 LengthUnit으로 해석합니다. 기준점 배열의 순서를 서로 바꾸면 동일한 개수의 유한한 좌표라도 다른 대응이 됩니다. 학습에 쓰지 않은 점에서 정방향과 역방향을 각각 비교하고 결과를 별도 평가하십시오.

항목확인할 내용
mapping글로벌 픽셀에서 세계 평면으로 가는 방향을 지정합니다.
unit세계 좌표와 세계 거리의 길이 단위를 나타냅니다.
ROI 원점측정한 로컬 좌표를 글로벌 픽셀로 옮깁니다.
보류점학습에 넣지 않은 대응점으로 예측을 확인합니다.
단위 비교세계 잔차와 허용치를 같은 단위로 맞춥니다.
역변환세계점에서 글로벌 픽셀로 돌아오는 결과도 확인합니다.

입력 매핑을 준비하는 과정과 구성된 매핑을 적용하는 과정은 구분됩니다. 학습점에 잘 맞는 행렬이라도 다른 영역의 예측이 허용 범위에 드는지는 독립 검증으로 확인해야 합니다. 영상 크기나 ROI 원점이 바뀌면 기존 매핑이 기대하는 글로벌 프레임과 입력의 관계를 다시 살펴보십시오.
