image

method · 선언 타입 zvision._inspection_advanced.AdvancedDifference

Python
image(self, index)

차이 검사 결과에서 영상을 취득합니다.

확인된 인자 조건

index: 0 점수, 1 마스크, 2 부호 있는 차이

반환: 호출자가 close할 독립 ZImage입니다.

오류: 0–2 이외의 인덱스는 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

차이 검사의 출력 선택

index 0은 점수 영상, 1은 마스크, 2는 부호 있는 차이 영상을 선택합니다. 세 출력의 의미와 값 범위는 서로 다르므로 같은 밝기 척도로 해석하지 않습니다. 0–2 이외 인덱스는 오류입니다.

획득과 해제

선택한 ZImage는 별도 소유이므로 사용 후 close합니다. 마스크와 점수 및 차이 영상을 동일 ROI에 겹쳐 보면 왜 한 위치가 선택되었는지 진단할 수 있습니다. 정렬 오차도 차이로 보일 수 있으므로 입력 정합을 확인합니다.

세 출력의 용도

0은 점수, 1은 마스크, 2는 부호 있는 차이 영상입니다. 세 영상을 같은 ROI에 표시하면 점수와 마스크가 어떤 차이 위치에 대응하는지 확인할 수 있습니다. 반환 핸들은 각각 닫습니다.
