ShapeProbe(index: int, anchor: zvision._regions.Point2, status: int, side: int | None, edge_position: zvision._regions.Point2 | None, distance: float | None, strength: float | None, used: bool, residual: float | None, weight: float | None) -> None

Per-probe status, side association, optional edge, residual and weight.

index: 탐침의 인덱스입니다.

anchor: 탐침 기준점의 ROI 로컬 Point2(픽셀)입니다.

status: 개별 탐침의 측정 상태 코드입니다.

side: 사각형 면 연결 번호이며 없으면 None입니다.

edge_position: 검출된 에지의 ROI 로컬 위치이며 없으면 None입니다.

distance: 검출된 에지까지의 거리이며 없으면 None입니다.

strength: 검출된 에지 강도이며 없으면 None입니다.

used: 최종 적합에 사용했는지 나타냅니다.

residual: 적합 잔차이며 계산되지 않으면 None입니다.

weight: 최종 적합 가중치이며 계산되지 않으면 None입니다.

값을 구성하고 해석하기

영상 형상 측정에서 한 탐침의 상태와 발견된 에지, 최종 적합 참여 여부를 담습니다. anchor와 edge_position은 ROI 로컬 좌표이며 에지가 검출되지 않으면 edge_position, distance, strength가 None일 수 있습니다. 검출되었다는 사실과 최종 적합에 used로 반영되었다는 사실을 구분합니다.
