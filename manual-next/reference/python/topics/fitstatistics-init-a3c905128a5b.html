FitStatistics(count: int = 0, inliers: int = 0, rms_error: float = 0.0, max_error: float = 0.0) -> None

FitStatistics(count: int = 0, inliers: int = 0, rms_error: float = 0.0, max_error: float = 0.0)

count: 피팅에 전달된 점 수.

inliers: 최종 잔차 조건을 통과한 점 수.

rms_error: 채택점 기하 잔차의 RMS; 입력 좌표 단위.

max_error: 채택점 기하 잔차의 최대; 입력 좌표 단위.

이 호출의 입력과 객체 맥락

이 값은 피팅에 전달된 점 수 count와 최종 잔차 기준을 통과한 inliers, 채택점 잔차의 RMS와 최대값을 함께 담습니다. 예를 들어 count=10, inliers=8이면 나머지 두 점은 최종 채택 수에 포함되지 않습니다. rms_error와 max_error는 입력 좌표의 단위를 따르므로 서로 다른 길이 단위의 값을 바로 비교하지 마세요. 각 필드의 기본값은 0이며 숫자를 직접 담는 것과 실제 피팅 실행은 별개입니다.

입력 수와 채택점 잔차

FitStatistics는 count, inliers, rms_error와 max_error를 담는 값 스냅샷입니다. count는 피팅에 전달된 점 수이고 inliers는 최종 잔차 기준을 통과한 점 수입니다. RMS와 최대 오차는 채택점의 기하 잔차를 입력 좌표 단위로 나타냅니다. 기본 필드는 모두 0입니다.

예를 들어 count=10, inliers=8이면 전달된 열 점 중 여덟 점이 최종 채택 수에 포함됩니다. 채택 잔차가 간단히 [0,0,0,0,0,0,0,2] mm라면 RMS는 √(4/8)≈0.707 mm이고 최대는 2 mm입니다. 평균 RMS만으로 최대 잔차의 위치나 제외된 점 두 개의 상태를 알 수는 없습니다.

단위입력 좌표의 길이 단위

적용과 결과 확인

직접 FitStatistics 값을 구성하는 것은 실제 점들을 피팅하거나 필드 사이의 관계를 재계산하는 연산이 아닙니다. 실제 계산에서 얻은 값과 수동으로 조립한 예시를 구분하고, 서로 다른 단위의 결과를 비교하기 전에 길이를 변환하세요. 인라이어 수만 높아도 점들이 한곳에 몰리면 모델의 전체 영역 정확도를 보장하지 않습니다.

예시의 RMS는 각 채택 잔차를 제곱해 합산한 뒤 채택 수로 나누고 제곱근을 취한 값입니다. 최대 오차는 그 채택 잔차들 가운데 가장 큰 값이므로 두 수가 다른 것을 오류로 볼 수 없습니다. 좌표가 픽셀인 결과와 밀리미터인 결과는 서로 다른 단위이며, 보정을 거치지 않은 픽셀 오차를 바로 밀리미터 오차로 쓰면 안 됩니다. count와 inliers가 모두 0인 기본 객체는 유효한 피팅이 이미 성공했다는 증거도 아닙니다.
