Tensor.create 공개 계약

상위 목차로 돌아가기

create

classmethod · 선언 타입 zvision._ai_advanced.Tensor

Python
create(cls, shape, values, dtype=<TensorType.F32: 0>)

형상과 값을 복사해 텐서를 만듭니다.

확인된 인자 조건

shape: 각 차원이 양수인 최대 32차원 시퀀스

values: 형상 곱과 같은 길이의 값

dtype: F32, I32, I8 또는 U8; 기본값 F32

반환: 별도로 close할 Tensor입니다.

오류: 형상·원소 수 또는 정수 자료형 범위를 위반하면 오류입니다.

인자 선언

  • shape · POSITIONAL_OR_KEYWORD · 기본값 없음
  • values · POSITIONAL_OR_KEYWORD · 기본값 없음
  • dtype · POSITIONAL_OR_KEYWORD · 기본값 <TensorType.F32: 0>

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

shape의 각 축 크기와 values를 복사해 독립 소유 텐서를 만듭니다. 차원은 최대 32개이고 각 크기는 양의 정수이며 값 개수는 형상의 곱과 같아야 합니다. 예를 들어 (2,3)에는 값 6개가 필요합니다. dtype은 F32/I32/I8/U8 중 하나이며 정수 값은 해당 형식의 범위를 지켜야 합니다. 반환 Tensor는 사용 후 close합니다.
