FeatureMatchResult(source_points: tuple, pairs: tuple, matrix: tuple[float, ...] | None, inlier_count: int, evaluated: int)

source_points: 검색 영상에서 검출된 특징점의 불변 튜플입니다.

pairs: 모델과 검색 영상 간 대응점의 불변 튜플입니다.

matrix: 추정된 3×3 변환 행렬의 값 튜플이며 추정하지 못하면 None입니다.

inlier_count: 추정된 기하 변환의 내점 수입니다.

evaluated: 평가된 RANSAC 가설 수입니다.

값을 구성하고 해석하기

특징점 검색의 검출점, 대응쌍, 선택적 변환 행렬과 기하 검증 진단을 복사한 결과입니다. source_points는 검색 영상 측 점이고 pairs는 모델과 검색 영상 사이의 대응입니다. matrix가 있으면 모델 로컬에서 검색 영상 로컬로 가는 3×3 행 우선 변환이며, 적합이 되지 않으면 None입니다.
