아핀 영상 변환

행렬로 정의한 아핀 변환과 출력 크기에 따라 영상을 다시 표본화합니다. 평행 이동과 크기 조정 등을 다룰 때 결과 픽셀의 위치와 원본 위치 사이의 대응을 정확히 구분해야 합니다. 출력의 폭과 높이는 양수 조건을 확인합니다.

보간과 경계

interpolation은 표본값을 고르는 방식을, border는 원본 밖을 읽을 때 사용할 값을 정합니다. 같은 행렬이라도 두 설정에 따라 경계와 픽셀 값이 달라질 수 있습니다. 단위 변환 또는 간단한 이동 사례로 방향을 확인하고 반환 영상을 닫습니다.
