inverse(self)

역변환 행렬을 계산합니다.

반환: 새 Affine2 값.

오류: 역행렬이 존재하지 않거나 유효하지 않은 값은 오류.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

왕복을 확인할 때는 실제 측정점 몇 개를 원래 변환에 넣고 결과를 역변환에 다시 넣어 비교합니다. 오차의 단위는 점 좌표의 단위이며 픽셀과 세계 길이의 차이를 같은 수치로 해석하지 않습니다. 역행렬 계산 자체가 실패하면 그 결과를 적용할 수 없습니다.

역변환은 이미 적용된 아핀 변환을 반대 방향으로 되돌리는 새 계수 값을 계산합니다. 예를 들어 원래 변환이 (3, 4)만큼 이동한다면 역변환은 같은 좌표 단위로 (−3, −4)만큼 이동합니다. 원래 변환으로 점을 바꾼 뒤 역변환을 적용해 입력에 가까운지 확인할 수 있지만, 실제 부동소수 계산의 반올림과 기하 상태를 함께 고려해야 합니다. 선형 부분이 특이하거나 수치적으로 불안정하면 역을 만들 수 없어 오류입니다. 유효한 Affine2 값과 별개로 이미지 전체를 워프하는 작업은 다른 호출입니다.

이 객체의 확인된 공개 생성 경로: Affine2(a: float, b: float, tx: float, c: float, d: float, ty: float) -> None.
