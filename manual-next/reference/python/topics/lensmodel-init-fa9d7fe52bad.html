LensModel(fx: float, fy: float, cx: float, cy: float, k1: float, k2: float, k3: float, p1: float, p2: float)

fx: x 방향 초점 거리; 픽셀 단위이며 사용 시 유한한 양수.

fy: y 방향 초점 거리; 픽셀 단위이며 사용 시 유한한 양수.

cx: 글로벌 픽셀 좌표의 주점 x.

cy: 글로벌 픽셀 좌표의 주점 y.

k1: 정규화 좌표의 r² 방사 왜곡 계수.

k2: 정규화 좌표의 r⁴ 방사 왜곡 계수.

k3: 정규화 좌표의 r⁶ 방사 왜곡 계수.

p1: 정규화 좌표의 접선 왜곡 첫 계수.

p2: 정규화 좌표의 접선 왜곡 둘째 계수.

이 호출의 입력과 객체 맥락

fx, fy는 초점 배율, cx, cy는 중심이며 k1, k2, k3는 방사 왜곡, p1, p2는 접선 왜곡 계수입니다. 점과 내부 파라미터는 카메라 글로벌 픽셀 좌표를 기준으로 사용합니다. fx와 fy는 유한한 양수여야 하고 나머지 계수도 유한해야 합니다. ROI에서 읽은 로컬 점을 이 모델에 넘길 때는 이미지 원점을 더해 전체 프레임 좌표로 맞춥니다. 계수값이 주어졌다는 사실만으로 실제 카메라의 보정 정확도가 검증된 것은 아닙니다.
