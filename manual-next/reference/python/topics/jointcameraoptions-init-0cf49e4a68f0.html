JointCameraOptions(unit: object, max_iterations: int, damping: float, gradient_tolerance: float, optimize_camera: bool = True, optimize_boards: bool = True) -> None

Finite local LM settings and fixed/variable pose blocks.

unit: 기준판 좌표와 이동의 길이 단위입니다.

max_iterations: 외부 반복 한도이며 1–25입니다.

damping: 초기 감쇠이며 유한한 양수입니다.

gradient_tolerance: 정규화 기울기 수렴 임계값이며 유한한 양수입니다.

optimize_camera: A←B 카메라 자세를 갱신할지 지정하며 기본값은 True입니다.

optimize_boards: 각 기준판 자세를 갱신할지 지정하며 기본값은 True입니다. 적어도 한 블록은 갱신해야 합니다.

이 호출의 입력과 객체 맥락

두 카메라와 기준판 자세 최적화의 길이 단위, 외부 반복·감쇠·기울기 기준과 갱신할 블록을 지정합니다. max_iterations는 1~25이고 damping과 gradient_tolerance는 유한한 양수입니다. optimize_camera와 optimize_boards 중 적어도 하나는 참이어야 합니다. 설정 뒤 결과의 초기·최종 픽셀 RMS와 수렴·정지 상태를 함께 확인합니다.

사용 조건과 결과 판독

JointCameraOptions는 두 카메라와 여러 보드 관측의 공동 정련에서 사용할 길이 단위, 반복과 감쇠, 갱신할 자세 블록을 지정합니다. unit은 기준판 좌표와 이동의 길이 단위입니다. optimize_camera는 A←B 카메라 자세, optimize_boards는 각 보드 자세의 갱신 여부를 뜻합니다.

max_iterations는 1~25의 외부 반복 상한이고 damping과 gradient_tolerance는 유한한 양수입니다. 두 갱신 플래그를 모두 false로 두면 조정할 블록이 없으므로 적어도 하나는 활성화해야 합니다. 허용 반복 수와 실제 결과 iterations를 같은 것으로 보지 마세요.

결과의 initial_rms와 final_rms는 픽셀 재투영 오차이고 보드 이동은 unit의 길이 단위입니다. 수치가 감소했는지와 converged, stalled, exhausted를 함께 읽되 지역 수렴을 전역 최적이나 실제 장비 정확도의 증명으로 해석하지 않습니다. 관측 프레임과 좌표 단위를 실행 전 맞추세요.
