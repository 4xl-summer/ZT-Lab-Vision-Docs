BoundedTemplateResult(matches: tuple, evaluated: int) -> None

Independent immutable matches and number of poses evaluated.

matches: 검색 후 복사된 불변 매치 튜플입니다. 허용 후보가 없으면 비어 있습니다.

evaluated: 평가된 정수 위치의 수입니다.

값을 구성하고 해석하기

정수 위치 범위에서 검색한 결과 매치의 불변 튜플과 evaluated를 담습니다. 허용 후보가 없으면 matches는 빈 튜플이며 정상적인 빈 결과입니다. evaluated는 살펴본 정수 위치의 수이고 최종 반환된 매치 수와 같을 필요가 없습니다. 모델과 네이티브 결과를 정리한 뒤에도 이미 복사된 값은 유지됩니다.

인자값의 의미
matches검색 후 복사된 불변 매치 튜플입니다. 허용 후보가 없으면 비어 있습니다.
evaluated평가된 정수 위치의 수입니다.

평가 수와 반환 수

evaluated는 검색 범위에서 실제로 평가한 정수 위치의 수이며 matches는 조건을 통과해 반환된 후보입니다. 예를 들어 12개 위치를 평가하고 결과가 2개라면 evaluated는 12이고 matches의 길이는 2입니다. 두 숫자는 서로 대체할 수 없습니다.

matches가 비어 있어도 실행이 정상 종료되었다면 빈 결과입니다. 검색 범위, 판정 기준과 작업 한도를 함께 기록하면 후보가 없었던 이유를 검토할 수 있습니다. 각 매치의 위치는 정수 평행이동 검색의 위치이므로 회전·배율 포즈로 해석하지 않습니다.
