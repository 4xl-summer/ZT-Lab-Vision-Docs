def to_point_cloud(self)

깊이 데이터를 PointCloud 소유 객체로 변환합니다. 반환 객체도 닫아야 합니다.

행 우선 깊이를 직교 점으로 바꾸고 결측·단위·frame을 보존합니다.

반환: 새 소유 PointCloud; 사용 후 닫습니다.

오류: 유한 범위를 벗어난 좌표 계산이나 닫힌 객체는 오류입니다.

직교 격자를 점군으로 변환

각 유효 깊이를 격자의 x, y 위치와 결합해 3차원 점으로 만듭니다. 픽셀 (x,y)의 좌표는 (origin.x + x·spacing.x, origin.y + y·spacing.y, origin.z + depth)입니다. 원본의 결측 위치는 점군의 같은 슬롯에서 결측으로 보존됩니다.

원점 (10,20,30), 간격 (2,3), 두 번째 열과 두 번째 행의 깊이 4라면 좌표는 (12,23,34)입니다. 이는 직교 격자 모델이며 카메라의 초점거리와 렌즈 왜곡을 사용하는 원근 투영과 구분해야 합니다. 점군의 단위와 frame은 원본에서 이어집니다.
