python 공개 선언
InpaintOptions(iterations, timestep, kappa, tolerance=0.0, conductance=<InpaintConductance.EXPONENTIAL: 0>, nearest_known=True, *, initialization=None)

마스크 복원 설정값입니다. 생성 시 초기화 별칭이 지정되면 nearest_known을 덮어씁니다.

iterations: 확산 반복 상한으로 양의 정수입니다.

timestep: 확산 시간 간격으로 유한한 (0, 0.25]입니다.

kappa: 대비 스케일로 유한한 양수입니다.

tolerance: 변화 정지 허용치로 유한한 0 이상이며 기본값은 0입니다.

conductance: EXPONENTIAL 또는 RECIPROCAL 전도 함수이며 기본값은 EXPONENTIAL입니다.

nearest_known: True면 인접한 알려진 픽셀로 초기화하고 False면 입력 값을 사용합니다. 기본 True.

initialization: 키워드 전용 HoleInitialization.INPUT 또는 NEAREST_KNOWN; None이면 nearest_known을 사용합니다.

입력과 결과 판독

결손 영역 복원에 사용할 반복과 시간 간격, 전도도 및 초기화 방식을 지정합니다. initialization을 지정하면 nearest_known의 선택을 덮어쓰므로 두 설정을 함께 기록해야 합니다. 복원 결과를 원본과 비교할 때는 마스크의 결손 영역과 알려진 영역을 구별하십시오.
