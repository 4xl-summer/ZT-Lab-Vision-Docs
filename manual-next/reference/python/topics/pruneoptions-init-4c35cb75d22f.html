PruneOptions(max_length: float = 1.0, spacing_x: float = 1.0, spacing_y: float = 1.0, max_iterations: int = 100, work_budget: int = 100000000)

max_length: 제거할 끝점 가지의 길이 한도이며 기본값 1입니다.

spacing_x: x 표본 간격이며 기본값 1입니다.

spacing_y: y 표본 간격이며 기본값 1입니다.

max_iterations: 최대 반복 수이며 기본값 100입니다.

work_budget: 작업량 상한이며 기본값 100000000입니다.

이 호출의 입력과 객체 맥락

끝점 가지 제거에 사용할 최대 길이 max_length, x·y 표본 간격, 반복 수와 작업 예산을 지정합니다. 기본 길이 한도와 두 간격은 1, 최대 반복은 100입니다. 길이 한도는 지정한 spacing에 따른 길이 기준이므로 간격이 다르면 같은 픽셀 가지도 다르게 평가될 수 있습니다. 결과 그래프를 비교할 때 사용한 간격과 반복 조건을 함께 기록하세요.

사용 조건과 결과 판독

PruneOptions는 골격 그래프에서 끝점 가지를 정리할 길이 한계와 x·y 표본 간격, 반복 상한 및 작업 예산을 담습니다. max_length와 spacing은 같은 길이 기준으로 해석하고, max_iterations와 work_budget은 서로 다른 계산 한도입니다.

예를 들어 spacing_x=2, spacing_y=1이면 가로로 한 표본 이동한 길이는 설정 기준으로 2이고 세로 한 표본은 1입니다. 같은 픽셀 칸 수라도 방향과 간격에 따라 가지 길이 해석이 다를 수 있으므로 max_length와 간격을 함께 기록해야 합니다.

기본 max_length와 두 간격은 각각 1, 반복 상한은 100입니다. 설정 객체는 그래프를 즉시 변경하지 않습니다. 정리 전후의 노드·간선과 사용한 연결 기준, 실제 결과를 확인하고 작업 한도에 걸린 실패를 완성된 결과로 취급하지 마세요.
