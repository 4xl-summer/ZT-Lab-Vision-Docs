QrEccBlock(data_codewords: int, parity_codewords: int, corrected_codewords: int)

data_codewords: 해당 Reed–Solomon 블록의 데이터 코드워드 수입니다.

parity_codewords: 해당 블록의 오류 정정 코드워드 수입니다.

corrected_codewords: 해당 블록에서 실제 정정한 데이터와 오류 정정 코드워드 수입니다. 이미지 픽셀 수나 등급이 아닙니다.

이 호출의 입력과 객체 맥락

QR 또는 Data Matrix 오류 정정 진단에서 한 블록의 코드워드 수를 나타내는 값입니다. data_codewords, parity_codewords, corrected_codewords가 각각 데이터, 패리티, 실제 정정된 코드워드의 수입니다. 모듈 하나와 코드워드 하나는 같은 단위가 아니므로 정정 수를 손상 픽셀 수로 읽지 않습니다.

예를 들어 어떤 블록의 corrected_codewords가 2라면 해당 진단에서 두 코드워드를 정정한 것으로 기록된 것입니다. 이 수치만으로 원래 영상에서 손상된 모듈 위치나 다른 블록의 결과를 복원할 수 없습니다. 전체 결과의 blocks와 총 corrected_codewords를 함께 확인합니다.

입력과 결과를 읽는 순서

한 Reed–Solomon 블록의 데이터·패리티 코드워드 수와 실제 정정된 코드워드 수를 함께 담습니다. data_codewords와 parity_codewords는 블록의 구성이고 corrected_codewords는 이 판독에서 수정한 양이므로 서로 더해 하나의 손상 픽셀 수로 읽지 않습니다.

예를 들어 두 블록의 corrected_codewords가 각각 1과 3이면 전체 수정 수는 4입니다. 그러나 한 블록에 정정이 집중되었는지 보려면 합계만이 아니라 각 QrEccBlock을 읽어야 합니다. 블록별 허용 한도와 accepted 판정은 전체 합과 다른 판단입니다.

이 값은 QR 또는 Data Matrix 진단에 담기는 코드워드 단위 정보입니다. 코드워드 하나가 영상의 픽셀 또는 모듈 하나와 동일한 것은 아니므로 해당 숫자만으로 영상의 손상 위치를 복원하지 않습니다. 객체 생성 자체가 심볼의 디코딩이나 오류 정정을 수행하지도 않습니다.

항목확인할 내용
data_codewords이 블록의 데이터 코드워드 수
parity_codewords이 블록의 정정 코드워드 수
corrected_codewords실제로 수정된 코드워드 수
전체 합각 블록의 수정 수를 합산
accepted지정된 블록별 한도의 판정
단위픽셀·모듈 수와 다름
