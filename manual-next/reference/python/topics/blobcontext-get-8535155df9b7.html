BlobContext.get 공개 계약

상위 목차로 돌아가기

get

method · 선언 타입 zvision._blob_context.BlobContext

Python
get(self, selector)

현재 결과의 라벨과 면적을 조회합니다.

확인된 인자 조건

selector: 현재 인덱스 모드에 따른 0 기반 인덱스 또는 0이 아닌 라벨

반환: BlobContextItem 값입니다.

오류: 현재 결과가 없거나 선택자가 없으면 오류입니다.

인자 선언

  • selector · POSITIONAL_OR_KEYWORD · 기본값 없음

Get current label and area by the selected index or label mode.

현재 성분 조회

컨텍스트의 현재 결과에서 지정한 성분을 조회합니다. 선택 방식이 인덱스인지 레이블인지 set_index_mode의 설정을 먼저 확인해야 같은 숫자를 올바르게 해석할 수 있습니다. 현재 결과가 없으면 조회할 대상이 없습니다.

결과의 의미

반환 항목의 label은 해당 결과의 영역 번호이고 area는 비영 전경 픽셀 수입니다. 목록의 순번이나 레이블을 다른 프레임의 동일 물체라고 단정하지 말고 입력과 계산 세대를 함께 기록합니다.
