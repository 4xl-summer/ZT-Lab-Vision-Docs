python 공개 선언
CalibratedPlanePose(rotation: tuple, translation: tuple, orthogonality_error: float, scale_error: float) -> None

Plane-to-camera row-major rotation, translation in plane units, axis orthogonality and scale errors.

rotation: 평면 좌표에서 카메라 좌표로 가는 행 우선 3×3 회전입니다.

translation: 평면 원점의 카메라 좌표이며 길이 단위는 평면 모델과 같습니다.

orthogonality_error: 입력 두 평면 축의 정규화 내적 절댓값입니다.

scale_error: 입력 두 축 배율의 상대 차이입니다.

이 호출의 입력과 객체 맥락

CalibratedPlanePose는 평면 좌표계에서 카메라 좌표계로 가는 회전과 이동 및 두 진단값을 담습니다. rotation은 행 우선 3×3 회전이며 translation은 카메라 프레임에서 본 평면 원점입니다. 이동의 길이 단위는 사용한 평면 모델의 단위와 같습니다. orthogonality_error와 scale_error는 입력 열의 정규화와 크기 차이를 해석하는 데 사용합니다.

예를 들어 평면 원점의 위치가 카메라 좌표 (0,0,100) mm라면 translation의 Z는 100 mm로 읽습니다. 평면 위의 다른 점은 회전을 적용한 뒤 이동을 더해 카메라 좌표로 나타냅니다. 양의 원점 깊이만으로 평면 자세의 모든 모호성이 해소되는 것은 아니므로 실제 장면의 방향과 독립 검증점도 확인하세요. 픽셀 좌표와 이동량을 같은 단위로 비교하지 않습니다.

입력과 결과 확인

CalibratedPlanePose는 평면 좌표에서 카메라 좌표로 가는 회전과 이동, 두 진단을 담습니다. rotation은 행 우선 3×3 회전이고 translation은 평면 원점을 카메라 프레임에서 표현한 위치입니다. 이동의 길이 단위는 평면 모델의 단위와 같습니다.

평면 원점의 카메라 좌표가 (0,0,100) mm라면 translation의 z 성분은 100 mm입니다. 평면의 다른 점은 회전을 적용한 뒤 이동을 더해 카메라 좌표로 나타냅니다. 픽셀에서 측정한 잔차와 밀리미터 이동량은 단위가 다르므로 직접 같은 수치로 비교하지 마십시오.

orthogonality_error는 입력 두 평면 축의 정규화 내적 절댓값이고 scale_error는 두 축 배율의 상대 차이입니다. 예를 들어 정규화된 축이 직교하면 내적은 0입니다. 이 진단과 함께 실제 장면의 방향 및 독립 검증점의 예측을 확인해야 합니다.
