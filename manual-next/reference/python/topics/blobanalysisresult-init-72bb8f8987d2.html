값의 해석과 사용

blobs는 실행 핸들과 독립적인 불변 성분 값입니다. 성분의 면적과 ROI 좌표를 입력 마스크와 대조하고 서로 다른 프레임의 목록 순번을 영구 식별자로 가정하지 않습니다.

연결 성분의 독립 값

BlobAnalysisResult는 blobs에 실행 수명과 독립적인 불변 성분 스냅샷을 담습니다. Blob의 area는 전경 픽셀 수이며 x, y, width, height는 ROI 로컬 외접 사각형입니다. 성분의 중심과 상자의 면적도 구분해 읽습니다.

3×3의 바깥 여덟 픽셀만 전경이면 area는 8이고 외접 상자의 폭과 높이는 각각 3입니다. 상자의 넓이 9와 영역의 실제 픽셀 수가 다르므로 영역 안이 모두 채워져 있다고 가정할 수 없습니다. 가운데 구멍이 그 차이를 만듭니다.

연결성성분이 묶이는 이웃 조건
프레임 비교입력과 별도 대응 규칙 확인

블롭 분석의 입력 마스크와 연결 조건을 함께 기록합니다. 대각선 이웃을 묶는 4·8 연결 설정에 따라 성분 수가 달라질 수 있습니다. 목록 순서를 다른 프레임의 영구 객체 ID로 쓰지 말고 위치와 별도 대응 규칙을 사용합니다.

적용과 판독을 더 살펴보기

각 Blob의 x와 y는 외접 사각형의 ROI 로컬 시작 위치입니다. 결과를 원본 전체 영상에 표시할 때는 해당 ROI의 전역 원점을 적용해야 합니다. centroid_x와 centroid_y는 전경 픽셀 중심 좌표의 평균이므로 상자의 기하학적 중심과 항상 같지 않습니다. 예를 들어 한쪽으로 돌출한 픽셀이 있으면 중심이 그쪽으로 이동하지만 외접 사각형만으로는 전경의 실제 분포를 알 수 없습니다. 분석 실행에서 얻은 값은 불변 스냅샷이지만 입력 프레임의 물체가 다음 프레임에도 같은 목록 위치에 있을 것이라고 가정하지 않습니다. 필요한 추적은 위치와 크기 등을 이용해 별도로 수행합니다.
