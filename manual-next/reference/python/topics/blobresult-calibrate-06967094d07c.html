BlobResult.calibrate 공개 계약

상위 목차로 돌아가기

calibrate

method · 선언 타입 zvision._blob_advanced.BlobResult

Python
calibrate(self, xx, xy, yx, yy, tx, ty)

아핀 계수로 영역의 세계 면적과 중심을 계산합니다.

확인된 인자 조건

xx: x축 선형 계수

xy: x 출력의 y 계수

yx: y 출력의 x 계수

yy: y축 선형 계수

tx: x 이동

ty: y 이동

반환: 별도로 close할 BlobResult입니다.

오류: 비유한 또는 특이 보정은 오류입니다.

인자 선언

  • xx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • xy · POSITIONAL_OR_KEYWORD · 기본값 없음
  • yx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • yy · POSITIONAL_OR_KEYWORD · 기본값 없음
  • tx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • ty · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

아핀 보정의 중심과 면적

xx, xy, yx, yy는 선형 변환 계수이고 tx, ty는 이동입니다. 예를 들어 단위 선형 변환과 이동 (10,20)을 사용하면 점 (1,2)는 (11,22)로 옮겨집니다. 면적에는 선형 부분의 행렬식 크기가 영향을 주며 이동은 면적을 바꾸지 않습니다.

결과와 오류

유한하지 않거나 특이한 보정은 오류입니다. 별도 소유 BlobResult를 반환하므로 사용 후 닫습니다. 입력 ROI와 보정이 같은 좌표계를 쓰는지 확인하고 세계 길이와 면적의 단위를 기록합니다.
