add_point

method · 선언 타입 zvision._composite_metrology.CompositeModelBuilder

Python
add_point(self, id, position, frame=None)

고정 점을 선택한 fixture에 추가합니다.

확인된 인자 조건

id: 형상 식별자.

position: fixture 로컬 Point2.

frame: 이전 fixture 인덱스 또는 None.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • position · POSITIONAL_OR_KEYWORD · 기본값 없음
  • frame · POSITIONAL_OR_KEYWORD · 기본값 None

Add a fixed point in the selected fixture.

이 호출의 입력과 객체 맥락

선택한 프레임에 고정 점 position을 특성으로 추가하고 0부터 시작하는 특성 인덱스를 반환합니다. frame=None은 ROI 로컬 루트입니다. 예를 들어 점을 먼저 추가한 뒤 그 반환 인덱스를 해당 점이 필요한 허용오차 정의에서 참조할 수 있습니다. 좌표는 ROI 로컬 픽셀 기준이며 이 객체는 좌표값을 세계 길이로 자동 보정하지 않습니다. 검증에 실패한 추가는 되돌려집니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
