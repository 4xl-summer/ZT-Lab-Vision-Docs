상위 목차로 돌아가기

decode

classmethod · 선언 타입 zvision._adaptive_inspection.OnlineReference

Python
decode(cls, template, data, *, max_bytes, max_pixels)

직렬화된 모델을 제한된 크기로 복원합니다.

확인된 인자 조건

template: ZImage 템플릿

data: 직렬화 바이트

max_bytes: 양의 바이트 상한, 키워드 전용

max_pixels: 양의 픽셀 상한, 키워드 전용

반환: 별도로 close할 OnlineReference입니다.

오류: 형식·상한 또는 모델 데이터가 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • data · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_bytes · KEYWORD_ONLY · 기본값 없음
  • max_pixels · KEYWORD_ONLY · 기본값 없음

max_bytes: 정수 검사 · 최소 1.

max_pixels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

저장된 bytes 또는 bytearray를 template 영상과 함께 읽어 온라인 참조 객체를 복원합니다. max_bytes와 max_pixels는 양수여야 하고 입력 바이트가 max_bytes를 넘으면 호출 전에 오류입니다. template은 ZImage여야 하며 잘못된 데이터나 호환되지 않는 기준 영상에 대한 오류는 호출자에게 전달됩니다. 반환한 객체는 이후 update 또는 freeze에 사용하고 사용 후 close합니다.
