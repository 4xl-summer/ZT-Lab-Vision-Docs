ZImage.shift 공개 계약

상위 목차로 돌아가기

shift

method · 선언 타입 zvision.ZImage

Python
shift(self, dx, dy)

정수 픽셀만큼 평행 이동하고 유효 마스크를 구합니다.

확인된 인자 조건

dx: 부호 있는 x 이동량(픽셀)

dy: 부호 있는 y 이동량(픽셀)

반환: 소유 영상과 유효 마스크를 포함한 ShiftResult입니다.

오류: 정수 범위 밖 값 또는 지원되지 않는 영상은 오류입니다.

인자 선언

  • dx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • dy · POSITIONAL_OR_KEYWORD · 기본값 없음

dx: 정수 검사.

dy: 정수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

영상 위치 이동

shift는 지정한 이동에 따라 영상의 표본 위치를 바꿉니다. 좌표계의 원점 변환과 픽셀 데이터를 실제로 이동하는 처리는 다른 단계이므로 출력 영상과 원본의 대응을 작은 입력에서 확인해야 합니다.

영역 밖의 값

이동하면 일부 출력 위치가 원본 범위 밖에 대응할 수 있습니다. 그 위치의 경계 처리 방식과 이동 단위를 호출 계약에서 확인합니다. 결과를 원본 위에 표시할 때 이동 방향을 작은 비대칭 패턴으로 검증하면 부호 혼동을 줄일 수 있습니다.
