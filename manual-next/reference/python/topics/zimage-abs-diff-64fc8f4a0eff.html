abs_diff(self, reference)

대응 픽셀의 절대 차이를 계산합니다.

확인된 인자 조건

reference: 비교할 ZImage

반환: 새 영상. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 입력 형식·크기가 호환되지 않으면 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

대응 위치의 차이

두 영상의 같은 위치에서 표본값 차이의 절댓값을 구합니다. 두 영상이 같은 크기와 호환되는 형식이어야 위치별 결과를 해석할 수 있습니다. 픽셀 값 10과 7의 차이는 3이고 순서를 바꾸어도 절댓값은 3입니다.

호출과 결과

reference에는 비교할 ZImage를 전달합니다. 반환 영상은 별도 소유 핸들이므로 사용이 끝나면 close 또는 with로 해제합니다. 정렬이 어긋난 두 영상은 실제 물체 변화가 없어도 가장자리에서 큰 차이를 낼 수 있으므로 크기뿐 아니라 ROI 위치도 확인합니다.
