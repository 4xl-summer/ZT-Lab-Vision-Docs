ImageQuery.open_values 공개 계약

상위 목차로 돌아가기

open_values

method · 선언 타입 zvision._query.ImageQuery

Python
open_values(self, kernel, op=20)

값 열기 단계를 가변 계획에 추가합니다.

확인된 인자 조건

kernel: 양의 홀수 정사각형 커널 폭

op: 기본값 20은 이 메서드에 연결된 ABI 연산 코드입니다. 다른 값을 전달하면 그 코드가 네이티브 Query에 전달되어 동작이 달라지거나 오류가 날 수 있습니다. 이 인자는 보통 기본값으로 둡니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 유효하지 않은 커널 또는 실행 오류가 보고될 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • op · POSITIONAL_OR_KEYWORD · 기본값 20

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

밝기 값의 열기 단계

이 단계는 값 침식 다음 값 팽창을 적용합니다. 작고 밝은 돌기와 필요한 세부 구조가 함께 변화할 수 있습니다. 이진 마스크의 전경 선택이 아니라 입력의 회색 수준을 다룬다는 점에 주의합니다.

커널과 판독

커널 폭이 정하는 주변 범위를 바꾸면 결과가 달라지므로 같은 입력에서 크기를 한 번에 하나씩 비교합니다. 후속 임계 처리의 결과가 달라졌다면 중간 밝기 영상부터 살펴보고 계획 실행 오류를 확인합니다.
