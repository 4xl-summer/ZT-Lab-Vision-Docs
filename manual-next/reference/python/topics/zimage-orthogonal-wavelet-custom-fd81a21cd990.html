orthogonal_wavelet_custom(self, levels, low, centered=False)

지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

low: 사용자 저역 통과 필터

centered: 중심 정렬 여부; 기본값 False

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 False

Return a transform using a custom low-pass filter.

사용자 저역 필터

직교 웨이블릿 변환에 사용자가 지정한 저역 통과 필터 low를 전달합니다. levels는 분해 단계 수이고 centered는 중심 정렬 여부이며 기본값은 False입니다. 필터 계수와 정렬이 달라지면 같은 영상에서도 변환 계수가 달라집니다.

유효성과 결과

저역 필터가 호출에서 요구하는 길이와 직교 조건을 만족하는지 확인하고 유효하지 않은 형식이나 필터의 오류를 처리합니다. 결과는 별도 소유 변환 객체입니다. 역변환 결과를 입력과 비교하려면 같은 계수, 단계와 정렬을 기록해야 합니다.
