dilate

method · 선언 타입 zvision._query.ImageQuery

Python
dilate(self, kernel, op=15)

이진 팽창 단계를 가변 계획에 추가합니다.

확인된 인자 조건

kernel: 양의 홀수 정사각형 커널 폭

op: 기본값 15은 이 메서드에 연결된 ABI 연산 코드입니다. 다른 값을 전달하면 그 코드가 네이티브 Query에 전달되어 동작이 달라지거나 오류가 날 수 있습니다. 이 인자는 보통 기본값으로 둡니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 유효하지 않은 커널 또는 실행 오류가 보고될 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • op · POSITIONAL_OR_KEYWORD · 기본값 15

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

계획의 이진 팽창

전경을 지정한 커널 이웃으로 확장하는 단계를 추가합니다. 두 물체 사이의 얇은 배경 틈이 없어지면 이후 분석에서 하나의 연결 성분이 될 수 있습니다. kernel은 양의 홀수 정사각형 폭입니다.

동작 코드와 결과

op 기본값은 이 메서드에 연결된 ABI 코드이며 다른 값을 전달하면 네이티브 Query에 그 값이 전달됩니다. 보통 기본값을 유지하고 실행 결과의 마스크를 확인합니다. 커널 폭을 조정할 때 입력 전경과 ROI는 고정해 비교합니다.
