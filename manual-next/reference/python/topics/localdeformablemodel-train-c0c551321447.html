train(cls, template, reference, sample_step=1, mask=None)

회색 템플릿과 기준점으로 국소 변형 검색 모델을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 ZImage입니다.

reference: 유한한 템플릿 로컬 Point2 기준점이며 영상 밖도 가능합니다.

sample_step: 양의 표본 간격(픽셀)이며 기본값 1입니다.

mask: 같은 크기·원점의 선택 Gray8 마스크입니다.

반환: 호출자가 닫아야 하는 독립 모델입니다.

오류: 템플릿, 기준점, 표본 간격 또는 마스크가 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

sample_step: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Train from a grayscale ZImage and optional same-origin Gray8 mask.

사용과 결과 판독

기준 템플릿과 기준점, 샘플 조건으로 국소 변형 검색 모델을 만듭니다. 템플릿 로컬 좌표와 이후 검색 영상의 ROI 좌표를 혼동하지 말고 모델의 기준점을 결과와 함께 기록하십시오. 입력 자료에 없는 변형까지 정확히 찾는다고 가정하지 않습니다.
