add_circle

method · 선언 타입 zvision._composite_metrology.CompositeModelBuilder

Python
add_circle(self, id, center, radius, frame=None)

고정 원을 추가합니다.

확인된 인자 조건

id: 형상 식별자.

center: fixture 로컬 중심 Point2.

radius: 양의 픽셀 반경.

frame: 이전 fixture 인덱스 또는 None.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • center · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음
  • frame · POSITIONAL_OR_KEYWORD · 기본값 None

Add a fixed circle with positive pixel radius.

이 호출의 입력과 객체 맥락

center와 양의 radius로 고정 원을 정의하고 그 특성 인덱스를 반환합니다. 반지름은 픽셀 기준이며 frame=None이면 ROI 로컬 루트 프레임을 사용합니다. 반환 인덱스는 이후 add_circle_center에서 원을 참조하는 데 사용할 수 있습니다. 이 단계는 모델의 기하를 정의하며 이미지에서 원을 찾아 측정하는 작업과 구분됩니다. 잘못된 원의 정의는 유효성 검사에서 거절됩니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
