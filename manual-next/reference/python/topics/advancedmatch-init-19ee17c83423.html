position: 검색 영상의 로컬 모델 기준점 좌표입니다.

global_position: 검색 영상 원점을 로컬 위치에 더한 전역 좌표입니다.

angle: 검출 포즈의 회전각(라디안)입니다.

model_coverage: 검색 영상과 마스크에서 유효한 모델 표본의 비율입니다.

contrast: 검색된 패치의 대비 값입니다.

sample_count: 평가에 사용된 모델 표본 수입니다.

값을 구성하고 해석하기

하나의 고급 매치 포즈와 점수, 표본 진단을 담습니다. position은 검색 ROI 로컬 모델 기준점이고 global_position은 여기에 영상 원점을 더한 좌표입니다. 예를 들어 로컬 위치 (3, 4), 원점 (10, 20)이면 전역 위치는 (13, 24)입니다. 점수와 유효 표본 비율은 서로 다른 의미입니다.
