PipelineStage.__init__

python 공개 선언
PipelineStage(operation: zvision._preprocess_pipeline_gap.PipelineOperation, parameter: int, sigma: float = 0.0, enabled: bool = True) -> None

Operation kind, levels or kernel, sigma and enabled state.

operation: 양자화, 중앙값 또는 가우시안 단계 종류입니다.

parameter: 양자화 레벨 2–256 또는 중앙값·가우시안 홀수 커널 1–31입니다.

sigma: 가우시안의 유한한 양의 표준편차입니다. 다른 단계는 0이어야 하며 기본값은 0입니다.

enabled: 단계 적용 여부로 기본값은 True입니다. 비활성 단계의 설정은 평가하지 않습니다.

이 호출의 입력과 객체 맥락

양자화·중앙값·Gaussian 중 한 단계와 parameter, sigma 및 활성 여부를 담습니다. 양자화 parameter는 2~256 수준, 중앙값과 Gaussian은 1~31의 홀수 커널입니다. sigma는 Gaussian일 때 유한한 양수이고 다른 단계에서는 0이어야 합니다. enabled=False인 단계는 설정을 평가하지 않습니다. 여러 단계의 실행 순서는 파이프라인에 전달한 순서입니다.

연산별 인자와 실행 순서

PipelineStage는 전처리 operation, 정수 parameter, sigma와 enabled를 묶는 값입니다. QUANTIZE의 parameter는 2~256 밝기 수준이고 MEDIAN과 GAUSSIAN의 parameter는 1~31 사이의 홀수 커널입니다. sigma는 GAUSSIAN에서 유한한 양수이며 다른 활성 단계에서는 0이어야 합니다.

예를 들어 QUANTIZE에서 parameter=4와 sigma=0을 지정하면 네 수준의 양자화 단계가 됩니다. GAUSSIAN에서 parameter=3을 쓴다면 홀수 커널 조건에 맞지만 sigma도 양수로 지정해야 합니다. parameter=4를 가우시안 커널로 쓰면 홀수 조건에 맞지 않습니다. 기본 sigma=0을 그대로 둔 활성 가우시안 단계가 유효하다고 가정하지 마세요.

적용과 결과 확인

execute_preprocessing_pipeline은 활성 단계를 입력 순서대로 적용하고 실행·건너뜀 보고와 소유 영상을 반환합니다. enabled=False인 단계는 설정을 평가하지 않고 건너뜁니다. 같은 연산 집합이라도 양자화 후 평활과 평활 후 양자화는 결과가 달라질 수 있으므로 단계 순서와 보고를 함께 확인하세요.
