AiResultInfo(model_version: int, task: zvision._inference.AiTask, class_id: int, region: tuple, scores_count: int, detection_count: int, map_width: int, map_height: int, score: float, anomalous: bool) -> None

Metadata snapshot. class_id is UINT32_MAX outside classification. score is the top classification softmax or maximum anomaly score, zero otherwise. region is (x, y, width, height).

model_version: 호출자가 지정한 모델 추적 식별자입니다.

task: 결과의 작업 종류입니다.

class_id: 분류 클래스 식별자이며 다른 작업은 UInt32 최대값입니다.

region: 입력 영상 내 사용 영역의 (x, y, 너비, 높이)입니다.

scores_count: 분류 점수의 개수입니다.

detection_count: 검출 상자의 개수입니다.

map_width: 분할 또는 이상 지도 너비(픽셀)입니다.

map_height: 분할 또는 이상 지도 높이(픽셀)입니다.

score: 분류 최고 softmax 또는 최대 이상 점수이며 그 외 작업은 0입니다.

anomalous: 이상 작업의 이상 판정값입니다.

입력과 결과 해석

AiResultInfo의 생성 인자는 다음 조건으로 해석합니다. 호출자가 지정한 모델 추적 식별자입니다. 결과의 작업 종류입니다. 분류 클래스 식별자이며 다른 작업은 UInt32 최대값입니다.

이 값은 해당 입력과 반환 맥락에 연결하여 읽어야 합니다. 입력 영상 내 사용 영역의 (x, y, 너비, 높이)입니다. 분류 점수의 개수입니다. 검출 상자의 개수입니다.
