CircleMeasurementResult(kind: int, status: int, converged: bool, parameters: tuple | None, inliers: int | None, rms: float | None, maximum: float | None, refit_iterations: int, probes: tuple, fit_count: int = 0) -> None

독립 불변 원 계측 결과 값입니다. 일반적인 경로는 대응 모델의 measure(image)입니다. status와 fit을 함께 확인합니다.

kind: 결과 형상 코드 2; 다른 값은 거부.

status: 정수 0 적합, 1 점 부족, 2 피팅 실패.

converged: 수렴 여부 bool.

parameters: 성공 시 (중심 x, y, 반경) 세 값의 숫자 튜플. 실패 시 None으로 정리.

inliers: 성공 시 채택점 수; 실패 시 None으로 정리.

rms: 성공 시 채택점 잔차 RMS(픽셀); 실패 시 None으로 정리.

maximum: 성공 시 채택점 최대 잔차(픽셀); 실패 시 None으로 정리.

refit_iterations: 재피팅 반복 횟수.

probes: MeasurementProbe 값들의 열; 불변 튜플로 복사.

fit_count: 피팅 입력점 수; 기본 0. fit 통계에 사용.

생성과 결과 판독

원 계측 결과를 status, fit 및 개별 프로브 관측과 함께 보관합니다. 일반 경로는 원 모델의 measure(image)입니다. 여러 점을 찾았어도 일부가 적합에서 기각될 수 있으며 점이 한쪽 원호에 몰려 있으면 분포도 함께 검토해야 합니다. 중심과 반경은 입력 영상의 ROI 로컬 픽셀로 해석하십시오.
