AdvancedGridPoint(row: int, column: int, pixel: object, score: float)

row: 격자 행 인덱스.

column: 격자 열 인덱스.

pixel: 탐지된 픽셀 Point2.

score: 해당 후보의 대비 점수.

이 호출의 입력과 객체 맥락

검출된 격자점 하나에 대응하는 행과 열 인덱스, 픽셀 위치와 대비 점수를 보관합니다. row와 column은 표적의 논리적인 인덱스이고 pixel은 영상에서 관측된 위치이므로 수치의 단위가 서로 다릅니다. score는 후보를 구별하는 대비 정보이며 실제 물리 좌표의 정확도 보증치가 아닙니다. 예를 들어 기준점의 row가 0, column이 1이면 이는 두 번째 열의 관측이라는 뜻이지 x좌표가 1픽셀이라는 뜻은 아닙니다. 세계 보정을 하려면 해당 격자 인덱스가 가리키는 물리 기준점과 관측 픽셀을 같은 순서로 대응시켜야 합니다. 일부 점이 누락되거나 예상 인덱스와 다르면 힌트, 대상의 형태, 대비·거리 조건과 ROI 좌표 기준을 먼저 확인하십시오. 예를 들어 반환된 픽셀 (110,208)이 표적의 행 1, 열 1에 대응한다면 세계점은 미리 준비한 그 행과 열의 기준표에서 찾아야 합니다. 단순히 반환 순서만 믿고 다른 표를 정렬하면 서로 다른 위치를 짝지을 수 있습니다. 결과 위치와 인덱스를 같이 기록해 점 누락도 식별하십시오. 기준 인덱스가 같은 두 관측을 중복 사용하면 서로 다른 표적점의 대응이 늘어난 것이 아닙니다. 점을 식별하는 행과 열, 픽셀 위치를 함께 저장하십시오.
