median_filter(self, kernel)

주변 픽셀의 중앙값으로 필터링합니다.

확인된 인자 조건

kernel: 양의 홀수 커널 폭

반환: 별도 소유 ZImage이며 close 또는 with로 해제합니다.

오류: 잘못된 커널이나 지원되지 않는 형식이면 오류입니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이웃의 중앙값

중앙값 필터는 주변 값들을 정렬했을 때의 중앙값을 사용합니다. 예를 들어 이웃 값이 0, 0, 0, 0, 255라면 중앙값은 0이므로 하나의 큰 점 잡음이 결과를 지배하지 않습니다. 실제 커널의 모양과 크기는 호출 조건을 따릅니다.

설정과 한계

창이 커지면 제거되는 작은 잡음뿐 아니라 실제 작은 구조에도 영향을 줍니다. 같은 입력의 평탄한 영역과 가는 선을 함께 보고 커널 값을 한 번에 하나씩 바꿉니다. 영상 경계의 이웃은 내부와 다를 수 있으므로 별도로 살펴봅니다.
