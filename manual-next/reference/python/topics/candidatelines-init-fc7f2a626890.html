CandidateLines(lines: tuple, candidates: tuple) -> None

Copied line and detected peak results, independent of the source image.

lines: 피팅된 선 결과의 독립 튜플입니다.

candidates: 탐침에서 검출된 피크 결과의 독립 튜플입니다.

이 호출의 입력과 객체 맥락

탐침 피크와 선 적합 결과를 함께 복사한 독립 보고서입니다. lines는 적합된 CandidateLine 튜플이고 candidates는 검출된 LineCandidate 튜플입니다. 두 목록은 같은 실행을 설명하지만 원소 수가 같을 필요가 없습니다. 한 선에 여러 후보가 배정되거나 어느 선에도 배정되지 않은 후보가 있을 수 있기 때문입니다.

후보의 line_index가 있으면 그 인덱스로 선 목록과 연결하고, None이면 해당 후보에 연결된 선이 없음을 뜻합니다. 후보의 classification과 reason을 함께 확인해야 적합에서 고려된 뒤 거절된 것과 애초에 고려되지 않은 것을 구분할 수 있습니다. 추출 문턱 아래의 피크는 candidates에 들어오지 않습니다.

사용 순서와 결과 확인

CandidateLines는 피팅된 선들과 탐침에서 검출한 피크 후보들을 독립 튜플로 보관합니다. 두 목록은 같은 실행을 설명하지만 항목 수가 같아야 하는 것은 아닙니다. 하나의 선에 여러 후보가 연결될 수도 있고 연결되지 않은 후보도 있습니다.

후보의 line_index가 있으면 해당 인덱스를 lines와 연결하고 None이면 배정된 선이 없는 상태로 둡니다. classification과 reason을 함께 읽어 고려 후 거절된 후보와 애초에 고려되지 않은 후보를 구별하십시오. 없는 인덱스를 0으로 바꾸면 첫 번째 선에 잘못 연결됩니다.

추출 문턱 아래의 피크는 candidates에 나타나지 않으므로 후보 목록의 부재가 프로파일 전체에 아무 변화도 없었다는 뜻은 아닙니다. 원본 영상과 탐침 설정, 각 선과 후보의 좌표 기준을 같이 기록해 검출과 피팅을 따로 분석합니다.

단계 또는 항목확인할 내용
lines피팅된 선의 독립 튜플입니다.
candidates검출된 피크 후보의 독립 튜플입니다.
line_index연결된 선 인덱스 또는 None입니다.
classification후보가 어떻게 분류됐는지 확인합니다.
reason거절 또는 미고려 이유를 함께 읽습니다.
문턱 아래추출되지 않은 피크는 목록에 없습니다.
