Python
close(self)

읽기 뷰 소유권을 해제합니다.

반환: None입니다. 내보낸 행은 별도 lease가 살아 있으면 유지됩니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

읽기 뷰 해제

close는 ImageReadView가 소유한 읽기 뷰를 해제하고 None을 반환합니다. 뷰를 닫은 뒤 이 객체로 새 행을 얻으려고 하면 오류가 납니다. 이미 내보낸 행은 별도 lease가 살아 있는 동안 유지될 수 있습니다.

사용 순서

필요한 행을 읽어 소비하거나 별도 값으로 복사한 다음 뷰를 닫습니다. 원본 영상과 읽기 뷰, 내보낸 행의 수명은 서로 구분합니다. 읽기 전용 행을 통해 원본에 쓸 수 있다고 추정하지 않습니다.

내보낸 행과 수명

close는 읽기 뷰 소유권을 해제하지만 별도 lease가 살아 있는 내보낸 행은 유지될 수 있습니다. 행은 읽기 전용이며 영상, 뷰, 행의 수명을 구분해 관리하고 뷰를 닫은 뒤 새 행을 요청하지 않습니다.
