find_shear(self, source, options, shear, *, max_work, mask=None)

실제 NCC 영상에서 명시한 x 전단 격자를 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 NCC 검색 설정입니다.

mask: 선택 검색 마스크입니다.

shear: 무차원 계수 u′=u+shear×v의 격자입니다.

max_work: 허용 작업량 상한으로 1..100000000입니다.

반환: 독립 전단 결과와 종료 진단입니다.

오류: 유효하지 않은 입력, 모델 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • shear · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_work · KEYWORD_ONLY · 기본값 없음
  • mask · KEYWORD_ONLY · 기본값 None

Search explicit shear values with a bounded work budget.

호출 맥락과 결과 해석

명시한 x 전단 격자를 실제 NCC 영상 검색에 적용합니다. 전단 계수는 무차원이며 템플릿 로컬 좌표에서 u′ = u + shear × v로 작용합니다. 예를 들어 shear가 0이면 이 식의 추가 x 이동은 0입니다.

전단 축을 넓히거나 촘촘히 하면 평가 조합이 증가합니다. max_work의 허용 범위는 1부터 100000000까지이므로 기대하는 변형 범위와 작업 상한을 함께 고려합니다. 반환 결과의 전단 값과 종료 진단을 같이 해석합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options확장 NCC 검색 설정입니다.
shear무차원 계수 u′=u+shear×v의 격자입니다.
max_work허용 작업량 상한으로 1..100000000입니다.
mask선택 검색 마스크입니다.

반환값 확인

독립 전단 결과와 종료 진단입니다.
