BoundedTemplateMatch(x: int, y: int, global_x: int, global_y: int, value: float, relative_contrast: float, relative_brightness: float) -> None

Top-left local/global coordinates, score or distance, standard-deviation ratio and mean ratio.

x: 검출된 템플릿 좌상단의 검색 영상 로컬 x(정수 픽셀)입니다.

y: 검출된 템플릿 좌상단의 검색 영상 로컬 y(정수 픽셀)입니다.

global_x: 검색 영상 원점 x를 로컬 x에 더한 전역 좌표입니다.

global_y: 검색 영상 원점 y를 로컬 y에 더한 전역 좌표입니다.

value: 색 NCC의 상관 점수 또는 Gray SAD의 평균 절대 차이입니다.

relative_contrast: 후보 표준편차를 모델 표준편차로 나눈 값입니다. 모델 분산이 0이면 0입니다.

relative_brightness: 후보 평균을 모델 평균으로 나눈 값입니다. 모델 평균이 0이면 0입니다.

값을 구성하고 해석하기

정수 평행이동 검색에서 선택된 템플릿의 좌상단과 점수·밝기 진단입니다. x,y는 검색 영상 로컬 좌상단이고 global_x,global_y는 검색 영상 원점을 더한 값입니다. 기본 Match의 중심 기준점과 다르므로 두 결과를 비교할 때 템플릿 크기를 이용해 좌표 기준을 맞춰야 합니다.
