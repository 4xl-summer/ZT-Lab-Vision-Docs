inverse_complex(self, crop=True)

복소 역변환 값을 계산합니다.

확인된 인자 조건

crop: True면 원본 크기로 자르고 False면 변환 크기를 사용합니다. 기본값은 True입니다.

반환: 너비, 높이, 실수부 튜플과 허수부 튜플을 반환합니다.

오류: crop이 bool이 아니거나 소유 객체가 닫혔으면 오류입니다.

인자 선언

  • crop · POSITIONAL_OR_KEYWORD · 기본값 True

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Return width, height, real and imaginary values, optionally cropped.

이 호출의 입력과 객체 맥락

켤레 대칭이 아닌 스펙트럼도 실수부와 허수부를 모두 갖는 복소 역변환으로 읽습니다. crop은 원본 크기로 자를지 선택하며 False일 때는 변환 크기를 사용합니다. 결과의 폭·높이와 각 값 배열을 함께 해석하세요. 값 배열은 영상 소유 핸들이 아니며 스펙트럼 객체는 사용 후 별도로 해제합니다.
