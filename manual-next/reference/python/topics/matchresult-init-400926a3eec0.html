MatchResult(matches: Iterable[zvision._matching.Match])

Independent immutable snapshot of the matches returned by a search. The input iterable is copied into a tuple; no native resource needs closing.

matches: 점수 순으로 정렬된 매칭 값의 독립 불변 튜플입니다. 이미지와 모델을 닫은 뒤에도 사용할 수 있습니다.

값을 구성하고 해석하기

기본 MatchModel.find가 반환하는 독립적인 불변 결과 스냅샷입니다. matches는 Match 값으로 복사된 튜플이고 best는 첫 항목 또는 None입니다. 입력 영상과 모델을 닫은 뒤에도 이미 얻은 값은 유지되며 이 결과 자체는 닫아야 할 네이티브 핸들을 소유하지 않습니다.

인자값의 의미
matches점수 순으로 정렬된 매칭 값의 독립 불변 튜플입니다. 이미지와 모델을 닫은 뒤에도 사용할 수 있습니다.

빈 결과와 첫 후보

생성자는 전달된 matches iterable을 튜플로 복사합니다. 따라서 입력 목록을 나중에 변경해도 이미 만들어진 결과의 항목 목록은 바뀌지 않습니다. 실제 검색 결과는 점수 순으로 제공되며 best는 첫 매치가 있을 때 그 값을 가리킵니다.

예를 들어 matches가 빈 튜플이면 best는 None입니다. 이는 정상적인 검색에서 조건을 통과한 후보가 없을 수 있다는 뜻이며 실행 오류와 구분해야 합니다. 각 위치는 검색 ROI와 템플릿 중심 기준점에 따라 해석하고, 값 스냅샷에는 닫을 네이티브 핸들이 없습니다.
