DivisionCamera.__init__

python 공개 선언
DivisionCamera(fx: float, fy: float, cx: float, cy: float, k: float) -> None

u=d/(1+k|d|²), with k on normalized distorted coordinates.

fx: 가로 초점 거리로 픽셀 단위의 유한한 양수입니다.

fy: 세로 초점 거리로 픽셀 단위의 유한한 양수입니다.

cx: 주점의 전역 X 픽셀 좌표입니다.

cy: 주점의 전역 Y 픽셀 좌표입니다.

k: 정규화된 왜곡 좌표의 division 왜곡 계수입니다.

이 호출의 입력과 객체 맥락

예를 들어 k=0이면 정규화 왜곡 좌표와 무왜곡 좌표가 같습니다. 그렇더라도 fx/fy와 cx/cy는 픽셀 좌표를 정규화하는 데 사용됩니다. 투영할 3차원 점은 카메라 좌표로 전달하고 세계 좌표로 사용할 포즈와는 구분합니다.

fx, fy와 중심 cx, cy에 단일 왜곡 계수 k를 결합한 카메라 모델 값입니다. 정규화된 왜곡 좌표 d에서 무왜곡 좌표는 d/(1+k|d|²)입니다. k의 기준은 픽셀 제곱이 아니라 정규화 좌표입니다. 픽셀은 글로벌 카메라 픽셀 중심이고 카메라 +Z가 전방입니다. 값 생성과 특정 점이 모델의 유효 분기 안에 있는지 검사는 별개입니다.

정규화 좌표와 유효 가지

DivisionCamera는 fx, fy, cx, cy와 k를 담는 데이터 값입니다. 실제 투영과 광선 계산 시 fx와 fy가 양의 유한 값이고 다른 계수도 유한한지 검증합니다. 픽셀 점 (x,y)의 정규화 왜곡 좌표는 d=((x−cx)/fx,(y−cy)/fy)입니다.

무왜곡 좌표는 u=d/(1+k|d|²)입니다. 예를 들어 k=0이면 분모가 1이어서 u=d이고, 주점 (cx,cy)은 d=(0,0)이므로 카메라 원점에서 +Z 방향의 광선에 대응합니다. k는 정규화 좌표에 적용되므로 원본 픽셀 반지름을 그대로 대입하지 않습니다.

pixel_to_ray는 중심에 연결된 국소 가지에서 분모와 방사 미분이 유효한 점만 처리합니다. project는 양의 Z를 가진 카메라 좌표 점을 해당 전방 가지에 투영합니다. 값 생성과 구체 입력의 가지 검사는 별개이며 계산 오류를 임의의 원점이나 빈 점으로 바꾸지 않습니다.
