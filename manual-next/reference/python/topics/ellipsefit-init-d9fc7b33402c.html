EllipseFit(center: zvision._regions.Point2, major_radius: float, minor_radius: float, angle: float, stats: zvision._metrology.FitStatistics = FitStatistics(count=0, inliers=0, rms_error=0.0, max_error=0.0))

center: 입력 좌표계의 타원 중심.

major_radius: 입력 좌표 단위의 긴 반축.

minor_radius: 입력 좌표 단위의 짧은 반축.

angle: 타원 방향 각도; 라디안.

stats: 잔차 통계.

이 호출의 입력과 객체 맥락

타원의 중심, 긴 반축 major_radius, 짧은 반축 minor_radius와 방향 angle을 담는 값입니다. 두 반축은 입력 좌표 단위이며 angle은 라디안입니다. 예를 들어 긴 반축이 6이고 짧은 반축이 2이면 전체 축 길이는 각각 12와 4입니다. stats는 FitStatistics이며 잔차와 채택 수를 함께 읽어 형상 파라미터만으로 적합 품질을 판단하지 않습니다. center와 stats는 각각 해당 타입이어야 합니다.

사용 조건과 결과 판독

EllipseFit은 center, 긴 반축 major_radius, 짧은 반축 minor_radius, 방향 angle과 FitStatistics를 묶는 값입니다. 반축은 중심에서 경계까지의 길이이므로 전체 축 길이와 구분합니다. 입력 좌표가 픽셀이면 반축도 픽셀 기준이며 angle은 라디안입니다.

예를 들어 중심 (10,20), 긴 반축 6, 짧은 반축 2의 타원은 두 전체 축 길이가 각각 12와 4입니다. angle이 달라지면 중심과 반축 길이가 같아도 영상에 놓인 방향은 달라집니다. 다른 ROI에서 얻은 중심과 비교하기 전에 원점을 공통 기준으로 맞춰야 합니다.

stats에는 전달된 점 수와 인라이어 수, 채택점의 RMS·최대 잔차가 들어갑니다. 잔차는 입력 좌표 단위이므로 숫자만 보고 물리 오차로 바꾸지 않습니다. 이 값의 생성만으로 영상에서 타원을 검출하거나 피팅이 성공했다고 보증하지 않습니다.
