execute(self) -> 'QueryExecution[CaliperResult]'

지연 계획을 실행합니다.

반환: 소유 QueryExecution의 output에 독립 CaliperResult 스냅샷; 실행은 close 필요.

오류: 닫힌 계획 또는 유효하지 않은 영상·설정은 오류.

반환 타입 주석: QueryExecution[CaliperResult]

계획을 실행하고 불변 에지를 반환한다.

사용과 결과 판독

계획된 캘리퍼를 실행해 서브픽셀 위치와 부호 있는 강도를 가진 에지 스냅샷을 얻습니다. 실행 객체는 사용 후 해제해야 합니다. 에지 목록이 비어 있는 경우와 실행 오류를 구별하고, 극성은 선분의 진행 방향에 따라 읽으십시오. 예를 들어 같은 프로파일의 에지 거리가 2와 7이면 간격은 5픽셀입니다.
