FuzzyScorer(measure: zvision._fuzzy_caliper.FuzzyMeasure, center: float, radius: float, enabled: bool = True) -> None

Triangular membership centered at center with positive radius; enabled selects it.

measure: 평가할 위치·폭 또는 강도 선택.

center: 삼각 소속도 1의 중심.

radius: 중심에서 소속도가 0에 도달하는 양의 거리.

enabled: 규칙 사용 여부; 기본 True.

이 호출의 입력과 객체 맥락

위치·폭·강도 중 평가 대상을 고르고 삼각 소속도의 center와 양의 radius를 설정합니다. 중심에서 점수는 1이고 중심에서 radius만큼 떨어진 곳에서 0에 도달합니다. 예를 들어 중심 10, 반경 2이면 값 12는 해당 규칙의 0 경계입니다. enabled는 규칙 사용 여부이며 여러 규칙을 결합하는 최종 결과와 이 한 규칙의 점수를 구분하세요.

삼각 소속도 해석

FuzzyScorer는 위치·폭·강도 중 평가할 measure와 삼각 소속도의 center, 양의 radius, enabled 상태를 지정합니다. 중심에서는 소속도가 1이고 중심에서 radius만큼 벗어나면 0입니다. 값의 단위는 선택한 측정값의 단위에 따라야 하므로 픽셀 위치와 밝기 강도의 반경을 혼용하지 않습니다.

예를 들어 center=10, radius=2이면 측정값 10의 점수는 1, 11의 점수는 0.5, 12의 점수는 0입니다. 반대쪽 8도 0 경계입니다. enabled는 해당 규칙을 사용할지 선택하는 값이며, 여러 규칙을 결합한 최종 점수와 이 규칙 하나의 소속도를 구분해 해석하십시오.
