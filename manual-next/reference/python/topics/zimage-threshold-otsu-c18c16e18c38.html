threshold_otsu(self, bin_count: int, lower: float, upper: float)

Otsu 임계값으로 마스크를 만듭니다.

확인된 인자 조건

bin_count: 히스토그램 빈 수

lower: 유한 하한

upper: 하한보다 큰 유한 상한

반환: 독립 소유 Gray8 마스크입니다.

오류: 유효하지 않은 히스토그램 범위 또는 형식은 오류입니다.

인자 선언

  • bin_count · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • lower · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • upper · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음

Return an owned Gray8 Otsu mask for a grayscale image.

자동 임계 분할

입력의 밝기 히스토그램을 이용해 Otsu 기준으로 임계값을 선택하고 분할합니다. 선택값은 입력 분포와 ROI에 의존하므로 촬영 조건이 달라지면 같은 숫자로 유지된다고 보장되지 않습니다. 명시적 고정 임계값과 선택 과정을 구분합니다.

마스크 판독

출력에서 물체가 원하는 전경으로 나타나는지 원본과 겹쳐 확인합니다. 대상과 배경의 분포가 겹치거나 조명이 공간적으로 달라지면 자동으로 선택된 경계도 실제 목표와 다를 수 있습니다. 후속 블롭 분석 전에 입력과 결과를 함께 기록합니다.
