보정 영상의 독립 복사

보이는 픽셀을 독립 복사하고 원점과 보정을 유지한 CalibratedImage를 반환합니다. 저장소를 공유하는 핸들을 획득하는 것과 픽셀의 깊은 복사는 다른 작업입니다. 닫힌 핸들이나 복사 실패는 오류입니다.

좌표와 수명

복사 전후의 크기와 전역 원점, 보정이 필요한 분석에 일치하는지 확인합니다. 반환 객체는 별도 소유이므로 사용 후 close합니다. 복사된 데이터가 실제 촬영 보정의 정확도를 개선하는 것은 아닙니다.

보정을 유지한 깊은 복사

CalibratedImage.copy()는 보이는 픽셀을 독립 복사하고 전역 원점과 평면 보정을 유지한 새 CalibratedImage를 반환합니다. 공유 핸들을 얻는 image()와 픽셀을 복사하는 이 호출은 목적과 저장 관계가 다릅니다.

예를 들어 전역 원점이 (100,200)인 ROI의 로컬 점 (10,20)은 복사 후에도 전역 (110,220)에 대응합니다. 픽셀의 데이터는 독립 복사되지만 세계 좌표의 해석에는 유지된 보정이 필요합니다. 복사가 보정 계수의 실측 정확도를 개선하는 것은 아닙니다.

적용과 판독을 더 살펴보기

복사할 대상이 ROI라면 보이는 영역만 독립 픽셀로 복사한다는 점을 확인합니다. 원본 전체의 다른 픽셀이 복사본에 들어 있다고 가정하지 않습니다. 복사한 영상의 로컬 원점은 그 영역의 전역 원점과 연결되어 있으므로 전체 영상 기준의 위치를 그릴 때 동일한 원점 변환을 사용합니다. 보정은 전역 픽셀 좌표를 세계 평면에 대응시키는 정보이며, 임의의 픽셀 좌표에 물리 단위를 붙이는 것과 다릅니다. 원본과 복사본의 같은 보이는 픽셀을 비교한 후 각 객체를 닫으면 복사 범위와 수명 관계를 점검할 수 있습니다.
