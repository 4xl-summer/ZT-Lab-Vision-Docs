to_bytes(self)

모델을 버전이 있는 바이트 형식으로 직렬화합니다.

반환: 모델 수명과 독립된 bytes입니다.

오류: 닫힌 모델 또는 유효하지 않은 입력은 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

학습된 특징 모델을 버전이 있는 바이트 형식으로 직렬화합니다. 반환 bytes는 모델 수명과 독립되어 있어 모델을 닫은 뒤에도 저장할 수 있습니다. 검색 영상이나 검색 옵션이 포함된 실행 결과를 만드는 호출은 아닙니다.

동일한 모델 종류의 from_bytes로 복원한 후 검색 옵션과 영상은 따로 지정합니다. 저장과 복원 전후에 동일 입력을 사용해 points와 검색 결과를 비교하면 모델 전달 과정을 확인할 수 있습니다.

반환값 확인

모델 수명과 독립된 bytes입니다.
