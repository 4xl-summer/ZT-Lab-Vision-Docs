연결 상태에서 취득을 시작하고 새 epoch를 만듭니다.

반환: None을 반환합니다.

오류: 현재 상태에서 허용되지 않는 전환은 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

예를 들어 connect 직후 첫 start는 epoch 0에서 1로 갑니다. stop 후 다시 start하면 다음 epoch가 시작되므로 이전 스트림의 ID 순서 기준과 새 스트림을 구분합니다. 이미 꺼낸 프레임의 정보에는 그 프레임이 속한 epoch가 들어 있습니다.

Connected에서 Acquiring으로 전환하고 새 epoch를 시작합니다. epoch가 1 증가하고 해당 스트림의 마지막 프레임·틱·시간·트리거 ID 기준은 초기화되며 누적 통계는 유지됩니다. 이후 모드에 맞는 트리거와 프레임을 호출자가 직접 제공합니다. 이 메서드가 하드웨어나 백그라운드 스레드에서 영상을 가져오지는 않습니다.

호출과 결과 판독

start는 Connected 상태의 모의 카메라를 Acquiring으로 전환하고 새로운 epoch를 시작합니다. 이 메서드는 하드웨어에서 영상을 가져오거나 백그라운드 취득 스레드를 생성하는 호출이 아닙니다. 이후 트리거와 프레임 입력은 해당 모드에 맞게 호출자가 제공합니다.

예를 들어 연결 직후 첫 start에서 epoch가 0에서 1로 증가하고, stop 뒤 다시 start하면 다음 epoch가 시작됩니다. 각 새 스트림에서는 마지막 프레임·틱·시간·트리거 ID의 순서 기준이 초기화되지만 누적 통계는 유지됩니다. 이전 epoch의 프레임과 새 epoch의 프레임을 ID만으로 같은 순서열로 묶지 마십시오.

이미 꺼낸 프레임은 자신이 속한 epoch 정보를 보관합니다. 지원하지 않는 상태에서 start하면 전환 오류이므로 성공한 취득으로 기록하지 말고 먼저 연결·취득 상태를 확인하십시오.
