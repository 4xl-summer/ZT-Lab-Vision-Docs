이 호출의 입력과 객체 맥락

입력 RGB에 sRGB 전달 방식을 지정하는 불변 설정값을 만듭니다. 이 객체만 만드는 단계에서 영상이 변환되지는 않습니다. sRGB로 부호화된 입력과 선형 입력은 서로 다른 선택이므로 영상 출처에 맞게 사용하세요. 변환 결과는 선택한 백색점과 색 공간의 조건과 함께 해석합니다.

sRGB 전달 함수 설정

InputTransfer.srgb()는 sRGB 전달 방식을 나타내는 불변 InputTransfer 설정을 생성합니다. 이 호출 자체가 입력 영상을 변환하거나 픽셀 값을 읽지는 않습니다. 색 변환 연산에 전달해 RGB 입력이 어떤 방식으로 부호화되었는지 명시하는 역할입니다.

sRGB로 부호화된 입력과 선형 RGB 입력은 서로 다른 해석이 필요합니다. 같은 숫자 0.5라도 어느 전달 방식을 적용하느냐에 따라 이후 선형 광량 및 색 공간 변환의 계산이 달라집니다. 인코딩을 알 수 없는 입력에 이름만 보고 설정을 추측하지 않습니다.
