train_shape_grain(cls, template, reference, min_component, max_component, sample_step=1, threshold=None, max_gradient=1e+300, sobel=False, mask=None)

학습 에지의 연결 구성요소 크기를 제한해 형상 모델을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 템플릿입니다.

reference: 템플릿 로컬 기준점 Point2입니다.

sample_step: 양의 표본 간격(픽셀)이며 기본값 1입니다.

threshold: 비음수 기울기 임계값 또는 자동 선택 None입니다.

max_gradient: 허용 최대 기울기입니다.

sobel: Sobel 기울기 사용 여부입니다.

mask: 선택 Gray8 마스크입니다.

min_component: 허용할 양의 최소 에지 구성요소 크기입니다.

max_component: 최소 이상인 최대 에지 구성요소 크기입니다.

반환: 호출자가 닫아야 하는 독립 형상 모델입니다.

오류: 구성요소·기울기 범위 또는 템플릿 조건 위반은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Train shape edges filtered by sampled-grid 8-connected component size.

호출 맥락과 결과 해석

학습 영상의 연결된 에지 구성요소 크기를 제한해 형상 모델을 구성합니다. min_component는 양의 최소 크기이고 max_component는 그 이상이어야 합니다. 이는 검색 영상의 에지 크기를 거르는 find_edge_grain과 적용 단계가 다릅니다.

작은 잡음을 학습 특징에서 줄이거나 지나치게 큰 구성요소를 제외할 때 크기 범위를 조정합니다. 원하는 윤곽도 범위 밖이면 특징에서 빠질 수 있으므로 모델의 features를 확인하고 같은 영상의 검색 결과를 비교합니다. 결과 모델은 호출자가 닫습니다.
