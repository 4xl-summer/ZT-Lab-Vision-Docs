FrameQueue.take 공개 계약

상위 목차로 돌아가기

take

method · 선언 타입 zvision._frame_queue.FrameQueue

Python
take(self, timeout_ms)

큐에서 항목을 꺼내거나 대기 종료 상태를 돌려줍니다.

확인된 인자 조건

timeout_ms: 최대 대기 시간으로 밀리초 단위 음이 아닌 정수입니다.

반환: FrameQueueTakeStatus와 독립 ZImage 또는 None의 쌍입니다. 영상은 호출자가 닫습니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • timeout_ms · POSITIONAL_OR_KEYWORD · 기본값 없음

timeout_ms: 정수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

timeout_ms 동안 FIFO 선두 영상을 기다립니다. 0은 즉시 검사이며 반환값은 (상태, 영상 또는 None)입니다. ITEM일 때 반환된 ZImage는 호출자가 close해야 합니다. TIMED_OUT과 CLOSED는 영상이 없는 서로 다른 상태이므로 단순한 빈 영상으로 취급하지 마세요. 닫힘은 대기 중인 소비자를 깨우며 OS 스케줄링으로 실제 반환 시각은 다소 늦을 수 있습니다.
