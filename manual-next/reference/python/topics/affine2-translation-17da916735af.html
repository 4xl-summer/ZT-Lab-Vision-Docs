translation

staticmethod · 선언 타입 zvision._calibration.Affine2

Python
translation(tx, ty)

평행이동 변환을 만듭니다.

확인된 인자 조건

tx: 유한한 x 이동.

ty: 유한한 y 이동.

반환: 새 Affine2 값.

오류: 비유한 계수는 오류.

인자 선언

  • tx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • ty · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

tx와 ty는 각각 x·y 방향의 유한한 이동량입니다. 양의 tx는 입력 x에 더해지고 양의 ty는 입력 y에 더해집니다. 예를 들어 이동량이 (3, 4)이고 점이 (10, 20)이면 적용 결과는 (13, 24)입니다. 값의 단위는 변환을 적용하는 좌표의 단위를 따르며, 픽셀 이동량을 자동으로 mm로 바꾸지 않습니다. 이 팩터리는 변환 계수 값만 만들고 영상의 픽셀을 즉시 이동시키지 않습니다. 실제 이미지를 바꾸려면 해당 영상 워프 API와 출력 기하를 별도로 지정해야 합니다.
