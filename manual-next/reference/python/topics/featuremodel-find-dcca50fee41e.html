FeatureModel.find 공개 계약

상위 목차로 돌아가기

find

method · 선언 타입 zvision._matching_features.FeatureModel

Python
find(self, source, options, mask=None)

검색 영상에서 특징점을 검출하고 모델과 대응시켜 기하 변환을 추정합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 특징 대응과 기하 검증 설정입니다.

mask: 선택적 검색 마스크입니다.

반환: 영상과 모델에 독립된 FeatureMatchResult입니다. 추정이 성립하지 않으면 matrix가 None입니다.

오류: 닫힌 모델 또는 유효하지 않은 입력은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

검색 영상에서 특징을 검출해 모델 특징과 대응시키고 기하 변환을 추정합니다. options는 특징 대응과 기하 검증 설정이고 mask는 선택적 검색 마스크입니다. 단일 픽셀 유사도만 보는 템플릿 검색과 결과 해석이 다릅니다.

FeatureMatchResult는 영상과 모델에 독립된 값이며 추정이 성립하지 않으면 matrix가 None입니다. 대응점 목록만으로 변환이 성공했다고 간주하지 말고 matrix와 검증 결과를 함께 확인합니다. 검색 영상의 특징과 옵션도 실패 진단에 중요합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options특징 대응과 기하 검증 설정입니다.
mask선택적 검색 마스크입니다.

반환값 확인

영상과 모델에 독립된 FeatureMatchResult입니다. 추정이 성립하지 않으면 matrix가 None입니다.
