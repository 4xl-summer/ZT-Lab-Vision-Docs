Affine2.scale 공개 계약

상위 목차로 돌아가기

scale

staticmethod · 선언 타입 zvision._calibration.Affine2

Python
scale(sx, sy)

x,y 방향 배율 변환을 만듭니다.

확인된 인자 조건

sx: 유한한 x 배율.

sy: 유한한 y 배율.

반환: 새 Affine2 값.

오류: 비유한 계수는 오류.

인자 선언

  • sx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sy · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

sx와 sy는 각각 x축과 y축에 적용할 유한한 배율입니다. 예를 들어 (2, 3) 배율로 점 (10, 20)을 변환하면 (20, 60)이 됩니다. 두 배율을 같게 주면 두 축에 같은 비율이 적용되고 다르게 주면 축별로 다른 비율이 적용됩니다. 음수 배율은 허용되므로 부호만으로 실패라고 판단하지 않습니다. 반면 0 배율은 가역 변환을 만들 수 없어 거절됩니다. 배율을 정할 때 픽셀 좌표에 쓰는지 세계 길이에 쓰는지 별도로 구분하세요.
