AdvancedRegionRule(region: tuple, max_scratch_count: int, max_surface_count: int, max_score: float, max_length: float, max_width: float)

region: 결함 중심이 포함되는지 판단하는 사각형입니다. 오른쪽과 아래 경계는 제외합니다.

max_scratch_count: 영역에서 허용하는 스크래치 개수의 포함 상한입니다.

max_surface_count: 영역에서 허용하는 표면 결함 개수의 포함 상한입니다.

max_score: 개별 결함의 최대 점수에 대한 포함 상한이며 유한하고 0 이상입니다.

max_length: 개별 결함 길이의 포함 상한이며 유한하고 0 이상입니다.

max_width: 개별 결함 폭의 포함 상한이며 유한하고 0 이상입니다.
