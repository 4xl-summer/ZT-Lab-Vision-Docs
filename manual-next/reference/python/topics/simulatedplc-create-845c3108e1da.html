요청 및 결과 핸드셰이크를 흉내 내는 PLC를 만듭니다.

확인된 인자 조건

timeout_ns: 양의 시간 초과 간격이며 나노초 단위입니다.

반환: 호출자가 닫아야 하는 SimulatedPlc입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • timeout_ns · POSITIONAL_OR_KEYWORD · 기본값 없음

timeout_ns: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

양의 timeout_ns를 지정해 요청/결과 핸드셰이크를 시험하는 모의 PLC를 만듭니다. 시간과 이벤트는 호출자가 command로 제공하며 실제 PLC 네트워크 연결은 하지 않습니다. 기한 경과는 명시적인 Poll 명령에서 평가되므로 단순히 시간이 흘렀다는 이유로 자동 판정된다고 가정하지 마세요. info 스냅샷에서 상태와 통계를 확인하고 소유 객체는 사용 후 close합니다.
