자세 추정 결과

자세 추정 결과에는 대상 frame에서 카메라 frame으로 가는 변환과 재투영 오차, 반복 및 종료 정보가 담깁니다. 3차원 점을 변환해 영상에 다시 투영했을 때 관측 픽셀에 가까운지를 읽는 결과이며, 결과 객체를 직접 구성하는 것은 추정 실행과 별개입니다.

초기 재투영 RMS와 최종 RMS를 비교하면 정제의 영향을 볼 수 있습니다. 예를 들어 최종 RMS가 1픽셀이라도 실제 깊이의 물리 오차가 항상 1이라는 뜻은 아닙니다. 점의 배치와 카메라 모델이 바뀌면 같은 픽셀 오차의 공간적 영향도 달라집니다.
