equalize_histogram

method · 선언 타입 zvision._query.ImageQuery

Python
equalize_histogram(self, op=11)

히스토그램 평탄화 단계를 가변 계획에 추가합니다.

확인된 인자 조건

op: 기본값 11은 이 메서드에 연결된 ABI 연산 코드입니다. 다른 값을 전달하면 그 코드가 네이티브 Query에 전달되어 동작이 달라지거나 오류가 날 수 있습니다. 이 인자는 보통 기본값으로 둡니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 입력 또는 실행 오류가 보고될 수 있습니다.

인자 선언

  • op · POSITIONAL_OR_KEYWORD · 기본값 11

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

분포 기반 대비 조정

현재 계획의 영상 분포를 이용한 히스토그램 평활화 단계를 추가합니다. 조정 후 밝기는 원본의 물리적 센서 값과 같은 값이 아니며 ROI의 분포가 달라지면 매핑도 달라질 수 있습니다.

후속 임계 처리

평활화 뒤의 임계값은 변환된 영상에 적용됩니다. 원본과 평활화 결과의 분포를 함께 확인하고, 원래 밝기를 측정해야 한다면 중간 결과와 원본을 별도로 유지합니다. 결과의 소유권은 실행 객체의 계약을 따릅니다.
