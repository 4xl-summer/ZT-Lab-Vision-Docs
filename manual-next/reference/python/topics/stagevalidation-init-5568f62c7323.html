python 공개 선언
StageValidation(matrix: tuple, offset: tuple, rms: tuple, maximum: tuple, x_scale: float, y_scale: float, theta_scale: float, skew_radians: float, unit: object, count: int) -> None

Full 3-DOF linear response and per-axis residual diagnostics.

matrix: 관측=matrix×명령+offset의 행 우선 3×3 계수 튜플. 입력 각도는 언랩된 라디안.

offset: 관측 x, y, theta 순서의 오프셋.

rms: 각 출력 축 x, y, theta의 잔차 RMS 튜플.

maximum: 각 출력 축의 최대 절대 잔차 튜플.

x_scale: 명령 x열의 평면 x,y 성분 노름.

y_scale: 명령 y열의 평면 x,y 성분 노름.

theta_scale: 명령 theta가 관측 theta에 기여하는 matrix[2,2].

skew_radians: 정규화된 두 평면 축에 대해 atan2(내적, 행렬식)으로 계산한 라디안 값.

unit: 평면 x,y 거리의 길이 단위; theta는 라디안.

count: 평가한 포즈 쌍 수.

이 호출의 입력과 객체 맥락

관측=matrix×명령+offset의 행 우선 3×3 계수와 각 출력 축의 잔차를 담습니다. x/y는 unit 길이 단위이고 theta와 skew_radians는 라디안입니다. rms와 maximum은 x,y,theta 순서이므로 길이와 각도 성분을 같은 수치 단위로 비교하지 않습니다. 입력 각도는 언랩된 값이며 count는 평가한 포즈 쌍 수입니다.
