mosaic_geometry(self, scale=1.0)

변환된 영상의 합집합 캔버스 기하를 계산합니다.

확인된 인자 조건

scale: 유한한 양의 출력 배율, 기본 1.

반환: 크기·공통 좌표 원점·배율의 값 스냅샷입니다.

오류: 닫힌 객체 또는 부적합한 캔버스·배율·옵션은 오류입니다.

인자 선언

  • scale · POSITIONAL_OR_KEYWORD · 기본값 1.0

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Compute union canvas dimensions and common-coordinate origin without rendering.

사용과 결과 판독

변환된 입력 영상들이 차지하는 합집합의 캔버스 크기와 공통 좌표 원점, 배율을 계산합니다. 이 값은 영상 픽셀 배열과 별도 기하 스냅샷입니다. 출력에서 원본 위치를 찾으려면 크기뿐 아니라 원점과 배율도 보관해야 합니다.
