method · 선언 타입 zvision._color_advanced.XyzLabResult

Python
channel(self, index)

선택 색상 평면의 소유 이미지 핸들을 취득합니다.

확인된 인자 조건

index: 0–2 채널 인덱스

반환: 호출자가 close할 독립 ZImage입니다.

오류: 인덱스 또는 결과 핸들이 유효하지 않으면 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

XYZ에서 Lab으로 변환된 결과의 0~2번 평면을 선택하여 ZImage로 반환합니다. xyz_to_lab 호출에 사용한 백색점이 이 결과의 해석에 필요합니다. 각 반환 영상은 별도 소유 핸들이므로 사용 후 close하고 XyzLabResult도 따로 close합니다. 범위 밖 채널이나 닫힌 결과는 오류입니다.
