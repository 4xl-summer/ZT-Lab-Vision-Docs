region_diagnostics

method · 선언 타입 zvision._extended_matching.ExtendedShapeModel

Python
region_diagnostics(self, pose, region)

변환된 모델과 소스 로컬 영역의 관계를 계산합니다.

확인된 인자 조건

pose: 진단할 매치 포즈입니다.

region: 양 끝을 포함하는 (xmin,ymin,xmax,ymax) 사각형입니다.

반환: 바깥 면적·특징 비율과 기준점 포함 여부를 담은 독립 값입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • region · POSITIONAL_OR_KEYWORD · 기본값 없음

Measure a pose against an inclusive source-local rectangle.

호출 맥락과 결과 해석

선택한 매치 포즈로 변환된 모델과 region의 관계를 계산합니다. region은 검색 영상 로컬 좌표의 (xmin, ymin, xmax, ymax) 사각형이며 양 끝을 포함합니다. 결과는 바깥 면적 비율과 특징 비율, 기준점이 포함되는지 여부를 구분합니다.

기준점이 사각형 안에 있어도 변환된 모델 일부가 밖으로 나갈 수 있습니다. 따라서 기준점 포함 여부 하나만 보고 전체 형상이 영역 안에 있다고 판단하지 말고 바깥 비율을 함께 살펴야 합니다. 이 호출은 후보를 새로 검색하지 않고 전달한 포즈를 진단합니다.

입력 선택을 위한 확인

입력의미와 조건
pose진단할 매치 포즈입니다.
region양 끝을 포함하는 (xmin,ymin,xmax,ymax) 사각형입니다.

반환값 확인

바깥 면적·특징 비율과 기준점 포함 여부를 담은 독립 값입니다.
