LineSearchGrid(origin: zvision._regions.Point2, step_x: float, step_y: float, columns: int, rows: int, offset_separation: float, angle_separation: float, max_results: int = 64) -> None

Translation grid and duplicate tolerances in pixels and radians.

origin: 첫 후보의 ROI 로컬 기준 Point2.

step_x: 양의 가로 격자 간격; 픽셀.

step_y: 양의 세로 격자 간격; 픽셀.

columns: 열 수; rows와 곱은 1–64.

rows: 행 수; columns와 곱은 1–64.

offset_separation: 중복 제거 수직 오프셋 차 한계; 유한한 0 이상 픽셀.

angle_separation: 중복 제거 방향 각도 차 한계; 유한한 0–π/2 라디안.

max_results: 최대 반환 수 1–64.

이 호출의 입력과 객체 맥락

ROI 로컬 origin에서 양의 픽셀 간격과 열·행 개수로 선 탐색 기준점 격자를 정합니다. columns×rows와 max_results는 각각 1~64 범위입니다. offset_separation은 중복 제거에 쓸 수직 오프셋 차의 픽셀 한계, angle_separation은 0~π/2 라디안의 방향 차 한계입니다. 위치와 각도는 단위가 다르므로 같은 숫자로 비교하지 않습니다.
