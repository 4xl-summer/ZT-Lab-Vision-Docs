InscribedCircle(center: zvision._regions.Point2, radius: float) -> None

Circle center and radius in polygon coordinate units.

center: 볼록 다각형 내접원의 중심이며 입력 좌표 단위입니다.

radius: 내접원 반경이며 입력 좌표 단위입니다.

이 호출의 입력과 객체 맥락

InscribedCircle은 볼록 다각형 안에 들어가는 원의 중심과 반지름을 나타내는 값 결과입니다. center와 radius는 입력 다각형의 좌표 단위를 따릅니다. 원을 구할 때 사용한 다각형이 픽셀 좌표라면 반지름은 픽셀이고, 밀리미터 좌표라면 반지름도 밀리미터입니다. 이 값은 원의 지름이나 넓이가 아닙니다.

예를 들어 꼭짓점이 (0,0), (4,0), (4,4), (0,4)인 정사각형의 최대 내접원은 중심 (2,2), 반지름 2입니다. 같은 단위에서 지름은 4이고 넓이는 4π입니다. 결과를 사용할 때는 원래 꼭짓점의 순서와 볼록성 및 좌표 프레임을 함께 확인하세요. 부동소수 계산에서는 공차를 두고 변과의 거리를 비교합니다.

사용 흐름과 판독 기준

InscribedCircle은 다각형 내접원의 중심과 반지름을 보관하는 값입니다. center는 입력 다각형의 좌표계에 있는 Point2이고 radius는 같은 좌표 단위의 길이입니다. 이 데이터 생성자는 두 값을 담는 일이며 점 목록을 받아 최대 내접원을 새로 계산하는 호출은 아닙니다. 실제 다각형에서 원을 구하려면 해당 계산 함수를 사용하고 결과를 이 값으로 해석합니다.

꼭짓점이 (0,0), (4,0), (4,4), (0,4)인 정사각형의 최대 내접원은 중심 (2,2), 반지름 2입니다. 중심에서 네 변까지 거리가 모두 2이고 지름은 4입니다. 반지름과 지름, 넓이를 구분해야 하며 이 예의 면적은 π×2²=4π 제곱 단위입니다. 입력이 픽셀이면 결과도 픽셀 기준입니다.

다각형 계산의 입력은 순서와 볼록성 조건을 따라야 하며, 이 값 객체의 center와 radius만으로 원래 꼭짓점이나 계산 조건을 복원할 수 없습니다. 다른 ROI에서 얻은 원과 중심을 비교할 때에는 각 ROI의 로컬 원점을 공통 좌표로 옮깁니다. 부동소수 결과를 경계와 대조할 때는 사용하는 계산의 공차와 좌표 단위를 함께 기록합니다.
