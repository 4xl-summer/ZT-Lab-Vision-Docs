to_buffer_gray16(self)

Return an independent, writable flat unsigned 16-bit buffer.

16비트 표본의 독립 버퍼

Gray16 영상에서 쓰기 가능한 독립적인 평탄 unsigned 16비트 버퍼를 반환합니다. 영상 폭과 높이는 픽셀 단위이며 버퍼의 표본 순서는 보이는 영역의 행 순서를 기준으로 해석해야 합니다. 바이트 하나를 한 표본으로 취급하면 16비트 값을 잘못 읽습니다.

복사와 형식

반환 버퍼는 독립적이므로 영상 핸들과 동일한 빌린 뷰라고 가정하지 않습니다. 요청 형식과 실제 영상 형식의 일치 조건을 확인하고 작은 영상에서 원래 숫자와 읽은 값을 대조합니다. 바이트 표현이 필요한 경우 네이티브 순서와 표본 폭을 따로 확인합니다.

표본과 바이트

폭 3, 높이 2이면 보이는 회색 표본은 6개입니다. 각 표본은 unsigned 16비트이므로 숫자 하나와 바이트 하나를 동일시하지 않습니다. 독립 버퍼의 쓰기와 원본 영상의 수명은 반환 계약대로 구분합니다.
