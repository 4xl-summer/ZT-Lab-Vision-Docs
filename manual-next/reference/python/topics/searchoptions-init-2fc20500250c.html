SearchOptions(max_hypotheses, max_results, edge_tolerance, min_overlap, icp, min_translation, max_translation, max_rotation, max_rms)

여러 모델의 제한된 3D 후보 탐색과 결과 필터를 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

max_hypotheses: 전체 가설 상한, 모델 수 이상인 양의 정수

max_results: 최대 결과 수, 양의 정수

edge_tolerance: 삼중항 변 길이 비교 허용값, 점군 단위의 유한 양수

min_overlap: 최소 겹침 비율, 유한한 (0,1]

icp: 후보 정제에 사용할 IcpOptions

min_translation: 이동 벡터의 성분별 포함 하한 Point3, 점군 길이 단위

max_translation: 이동 벡터의 성분별 포함 상한 Point3, 하한 이상이며 점군 단위

max_rotation: 항등 회전에서 허용할 최대 각도, 유한한 0–π 라디안

max_rms: 허용할 최대 ICP RMS, 점군 단위의 유한한 0 이상

이 호출의 입력과 객체 맥락

점군 가설 탐색의 개수·결과 상한, 겹침 및 ICP 품질 조건을 묶습니다. edge_tolerance와 max_rms, 이동 하한·상한은 점군 길이 단위이고 max_rotation은 항등 회전에서의 라디안 값 0~π입니다. min_overlap은 0보다 크고 1 이하이며 후보 정제 조건은 icp에 담습니다. 예를 들어 이동 범위를 좁히면 그 범위 밖 가설은 허용 대상이 아니므로 좌표 프레임과 범위를 함께 확인하세요.
