python 공개 선언
CompositeDiagnostics(kind: int, status: int, converged: bool, iterations: int, condition_proxy: float | None, probes: tuple, fit: zvision._composite_metrology.CompositeDiagnosticFit | None = None) -> None

Measurement type/status, convergence, iteration count, optional condition and probes.

kind: 측정 형상의 종류.

status: 피팅 상태.

converged: 피팅 수렴 여부.

iterations: 반복 횟수.

condition_proxy: 제공되는 경우 피팅 조건 지표, 없으면 None.

probes: 프로브 진단의 불변 튜플.

fit: 원본 픽셀 피팅 또는 None.

이 호출의 입력과 객체 맥락

복합 계측의 실행 종류와 상태, 수렴 여부, 반복 수, 선택적 조건 지표와 프로브 관측을 모은 진단 결과입니다. fit이 있으면 원본 적합 결과도 확인할 수 있지만 없을 수 있으므로 존재 여부를 먼저 확인해야 합니다. 형상이 반환되었다는 사실과 반복 과정의 수렴 상태는 구분하여 기록하십시오. 예를 들어 여러 프로브가 에지를 찾았더라도 일부 선택점이 다른 경계에 속하면 적합 결과가 목적 형상과 다를 수 있습니다. probes에서 각 관측의 위치와 상태를 확인하고, 적합에 사용된 점과 기각된 점을 구분하면 원인을 찾는 데 도움이 됩니다. condition_proxy가 없는 경우를 0이라는 정상 수치로 대체하지 마십시오. 진단점과 원본 피팅 계수는 픽셀 기준으로 해석해야 할 수 있으므로 물리 단위의 최종 결과와 비교할 때 각 필드의 단위를 확인합니다. iterations는 수행 횟수이고 converged는 종료 상태에 대한 별도 정보입니다. 한 프레임의 진단이 양호해도 다른 프레임의 조명과 ROI 위치가 같다는 보장은 없으므로 결과마다 모델과 입력 설정을 함께 보관하십시오. 예를 들어 반복 횟수가 기록되어도 수렴 여부는 따로 봅니다. 개별 프로브의 발견과 피팅 채택도 서로 다른 상태라는 점을 유지하십시오.
