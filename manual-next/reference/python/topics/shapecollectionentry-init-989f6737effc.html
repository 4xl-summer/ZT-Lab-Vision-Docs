ShapeCollectionEntry(id: int, model: zvision._matching_advanced.AdvancedMatchModel) -> None

Unique u64 ID and a shape model.

id: 모델 항목을 구별할 고유 u64 식별자입니다.

model: 검색할 형상 모델입니다.

값을 구성하고 해석하기

여러 형상 모델을 함께 검색할 때 한 모델과 이를 구별할 u64 id를 묶습니다. model은 열린 형상 AdvancedMatchModel이어야 하며 각 항목의 id는 한 컬렉션에서 고유해야 합니다. 이 입력은 모델이 감지된 위치나 점수 자체가 아닙니다.

생성할 때 확인할 값

인자값의 의미
id모델 항목을 구별할 고유 u64 식별자입니다.
model검색할 형상 모델입니다.

입력 항목을 결과와 연결

id는 호출자가 정하는 고유 모델 식별자입니다. 예를 들어 A와 B 모델에 각각 10과 20을 부여하면 결과 id를 통해 어느 모델의 매치인지 다시 찾을 수 있습니다. 컬렉션 안에서 id를 중복하면 결과를 입력 항목에 명확히 연결할 수 없습니다.

model은 검색할 열린 형상 AdvancedMatchModel입니다. 항목은 검색 조건을 묶는 입력이며 그 자체가 후보 위치나 점수를 제공하지 않습니다. 컬렉션 검색을 실행하는 동안 모델을 유효하게 유지하고 결과의 id와 매치를 함께 읽습니다.

model검색에 사용할 열린 형상 모델
