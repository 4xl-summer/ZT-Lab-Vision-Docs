ZImage.haar_wavelet 공개 계약

상위 목차로 돌아가기

haar_wavelet

method · 선언 타입 zvision.ZImage

Python
haar_wavelet(self, levels)

지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음

Return an independently owned Haar transform.

Haar 분해

Haar 웨이블릿은 이웃 표본의 저주파 성분과 변화 성분을 분리하는 변환입니다. levels는 변환 단계 수를 나타내며 단계가 바뀌면 결과의 분해 구조도 달라집니다. 입력 영상의 형식과 단계 수 제한을 호출 계약에서 확인합니다.

결과와 재구성

반환되는 변환 결과는 별도 소유 객체로 사용 후 close합니다. 각 계수는 원래 영상의 픽셀 밝기와 다른 의미이며, 원본을 재구성하려면 같은 변환의 역변환 계약과 계수 배치를 사용합니다. 표시된 계수 그림의 밝기만으로 원본이 보존되었다고 판단하지 않습니다.
