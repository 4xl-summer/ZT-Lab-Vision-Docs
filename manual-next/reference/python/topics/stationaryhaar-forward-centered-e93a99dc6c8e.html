forward_centered

classmethod · 선언 타입 zvision._stationary_wavelet_gap.StationaryHaar

Python
forward_centered(cls, image, levels)

주기 경계를 사용하는 다운샘플링하지 않는 웨이블릿 변환을 만듭니다. 이 팩터리는 기존 호환 API입니다.

확인된 인자 조건

image: 변환할 ZImage입니다.

levels: 1–32 정수 분해 레벨입니다.

반환: 호출자가 닫아야 하는 독립 변환 모델입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음

levels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Use periodic centered stationary Haar; phase shifts by each level offset. Legacy factory retained through 0.1.x; prefer image.stationary_haar_centered(levels, True).

이 호출의 입력과 객체 맥락

중심 위상을 사용하는 비감쇠 Haar 모델을 생성합니다. levels는 양의 단계 수이고 입력은 Gray8/16/F32입니다. 일반 Forward와 위상 선택이 다르므로 계수를 비교하거나 복원할 때 어떤 생성 경로를 썼는지 기록하세요. 반환 모델과 나중에 inverse로 얻는 영상은 별도로 close합니다.
