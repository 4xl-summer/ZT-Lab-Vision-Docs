descriptors(self)

각 특징점의 정규화 기술자를 복사합니다.

반환: 특징점별 실수 튜플의 튜플입니다.

오류: 닫힌 모델 또는 유효하지 않은 입력은 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

학습된 각 특징점의 정규화 기술자를 실수 튜플들의 튜플로 복사합니다. 검색 이미지의 특징을 모델과 대응할 때 사용되는 모델 쪽 기술자를 살피는 용도이며, 이 호출 자체가 검색이나 기하 변환 추정을 수행하지 않습니다.

points는 위치와 응답을, descriptors는 기술자 값을 제공합니다. 두 조회 결과를 학습 모델의 내용으로 해석하고, 반환값과 검색 결과의 대응 관계 및 변환 행렬을 혼동하지 않습니다.
