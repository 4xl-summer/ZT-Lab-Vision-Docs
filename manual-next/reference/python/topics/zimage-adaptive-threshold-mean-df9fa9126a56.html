adaptive_threshold_mean

method · 선언 타입 zvision.ZImage

Python
adaptive_threshold_mean(self, kernel, offset)

지역 평균과 오프셋을 사용해 분할합니다.

확인된 인자 조건

kernel: 양의 홀수 폭

offset: 유한 오프셋

반환: 별도 소유 ZImage이며 close 또는 with로 해제합니다.

오류: 인자 또는 입력이 유효하지 않으면 오류입니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

offset: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

국소 평균을 사용하는 분할

각 위치 주변의 평균과 offset을 이용해 분할하므로 영상 전체에 하나의 기준을 쓰는 전역 임계값과 다릅니다. 조명이 한쪽에서 점차 변하는 영상에서는 지역별 기준이 달라질 수 있으나, 커널이 물체 구조에 비해 너무 작으면 결과가 잡음에 민감할 수 있습니다.

설정과 해석

kernel은 양의 홀수 폭이고 offset은 유한한 수입니다. 같은 입력에서 한 값씩 바꾸어 출력의 전경을 확인하고, 영상 경계는 이웃 표본의 처리 영향을 받는다는 점을 살펴봅니다. 반환된 독립 ZImage는 사용 후 닫습니다.
