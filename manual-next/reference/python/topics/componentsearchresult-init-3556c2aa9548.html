python 공개 선언
ComponentSearchResult(objects: tuple, evaluated: int, incomplete: bool) -> None

Independent objects, evaluated count and incomplete shared search flag.

objects: 검색된 컴포넌트 객체들의 독립 불변 튜플입니다.

evaluated: 평가한 포즈 수입니다.

incomplete: 공유 검색이 끝까지 완료되지 않았는지 나타냅니다.

이 호출의 입력과 객체 맥락

루트 상대 관계를 만족하는 컴포넌트 객체들의 불변 튜플과 평가 포즈 수, 미완료 상태입니다. objects가 비었다는 것은 반환된 객체가 없다는 뜻이고 incomplete가 참이면 제한된 공유 검색을 전부 마치지 못했을 수 있습니다. 두 상태를 따로 보관해야 합니다.

각 객체의 parts에는 루트와 나머지 형상 모델 id 및 자세가 들어 있습니다. 최대 객체 수가 작거나 공유 예산이 부족하면 예상한 모든 조합을 반환하지 못할 수 있으므로 입력 옵션과 함께 evaluated를 확인합니다. 구성요소의 상대 위치와 각도는 루트에 대한 관계이며 검색 영상의 전역 좌표와 바로 같은 의미가 아닙니다.

입력과 결과를 읽는 순서

검색된 ComponentObject들의 불변 objects 튜플과 evaluated 포즈 수, 공유 검색의 incomplete 상태를 담습니다. objects가 비었다는 사실은 반환된 객체가 없음을 뜻하고 incomplete는 검색을 끝까지 완료하지 못했는지를 뜻하므로 둘을 따로 읽어야 합니다.

예를 들어 objects가 비어 있고 incomplete가 참이라면 이 보고만으로 전체 탐색 공간에 가능한 객체가 없었다고 확정할 수 없습니다. evaluated와 공유 예산, 결과 수 상한을 함께 확인하세요. 반대로 결과가 있더라도 incomplete 상태는 검색 범위의 완료 여부에 관한 정보입니다.

각 객체의 parts는 루트와 나머지 모델의 id·자세를 포함하며, 객체 score는 구성요소 점수의 최솟값입니다. 탐색의 제한과 루트 상대 조건을 기록하면 다른 예산으로 얻은 결과와 비교할 때 의미를 보존할 수 있습니다. 반환 결과는 소유 영상 핸들이 아닌 값 스냅샷입니다.
