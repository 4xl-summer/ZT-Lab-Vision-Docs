train_detailed

classmethod · 선언 타입 zvision._extended_matching.ExtendedShapeModel

Python
train_detailed(cls, template, reference, sample_step=1, threshold=None, max_gradient=1.7976931348623157e+308, sobel=False, mask=None)

기울기 범위와 스텐실을 지정해 확장 형상 모델을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 템플릿입니다.

reference: 템플릿 로컬 기준점 Point2입니다.

sample_step: 양의 표본 간격(픽셀)이며 기본값 1입니다.

threshold: 비음수 기울기 임계값 또는 자동 선택 None입니다.

max_gradient: 허용 최대 기울기입니다.

sobel: Sobel 기울기 사용 여부입니다.

mask: 선택 Gray8 마스크입니다.

반환: 호출자가 닫아야 하는 독립 형상 모델입니다.

오류: 형식, 기울기 범위 또는 특징점 조건이 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 None
  • max_gradient · POSITIONAL_OR_KEYWORD · 기본값 1.7976931348623157e+308
  • sobel · POSITIONAL_OR_KEYWORD · 기본값 False
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Train with explicit gradient bounds and stencil.

호출 맥락과 결과 해석

템플릿 기울기에서 특징을 추출하면서 최대 기울기와 Sobel 사용 여부를 추가로 지정합니다. 기본 train보다 에지 추출 조건을 세밀하게 조정하는 학습 경로이며 검색 영상의 조건을 바로 바꾸는 호출은 아닙니다.

template은 Gray8, Gray16 또는 유한 GrayF32이고 sample_step은 양의 픽셀 간격입니다. threshold는 비음수 임계값 또는 자동 선택 None입니다. 동일 템플릿과 기준점에서 조건을 바꾸어 학습한 모델의 특징을 비교하고, 각각의 모델을 사용 후 닫습니다.
