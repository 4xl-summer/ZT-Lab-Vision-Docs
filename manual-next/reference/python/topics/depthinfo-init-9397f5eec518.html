깊이 영상 정보

이 생성자는 깊이 영상의 크기와 격자 메타데이터를 담는 정보 값을 나타냅니다. 가로와 세로는 픽셀 수이며 간격과 원점은 점을 복원할 때 사용하는 좌표 정보입니다. 정보 값만 따로 만든다고 깊이 샘플 저장소가 생기지는 않습니다.

2×2 영상이면 전체 위치는 네 곳입니다. 위치의 배열 인덱스와 물리 좌표는 서로 다르며, x 간격이 2이고 원점 x가 10이면 두 번째 열의 x는 12입니다. ROI를 추출한 결과의 원점은 선택한 시작 위치만큼 이동하므로 원래 원점과 구분합니다.
