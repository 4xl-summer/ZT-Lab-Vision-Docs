CylinderOptions(iterations=50, outlier_fraction=0.49, axis=None, step_tolerance=1e-10, rms_tolerance=0.0, target_fraction=0.0)

원통 국소 피팅의 탐색과 종료를 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

iterations: 각 단계의 최대 반복 수, 양의 정수; 기본 50

outlier_fraction: 허용 이상치 비율, 유한한 [0,1); 기본 0.49

axis: 초기 축 Point3 또는 None; 지정하면 유한하고 0이 아닌 방향을 정규화해 사용

step_tolerance: 무차원 매개변수 단계 종료 허용값, 유한 양수; 기본 1e-10

rms_tolerance: 목표 RMS, 점군 단위의 유한한 0 이상; 0은 비활성이고 기본값

target_fraction: 조기 종료할 지지 비율; 0은 비활성, 그렇지 않으면 (0,1]; 기본 0

원통 적합 옵션

반복 횟수, 이상치 허용, 축 초기값과 종료 조건은 원통 탐색의 범위와 정제 동작을 조정합니다. 거리 임계값과 함께 쓰이며 인라이어 판정에 쓰이는 길이 단위는 점군의 단위입니다. 언어별 생성자의 기본값과 필수 인자는 위 선언을 기준으로 확인합니다.

부분 원호처럼 가능한 축이 많은 데이터에서는 반복 수를 늘려도 입력에 없는 기하 정보가 생기지 않습니다. 적합된 축과 반지름뿐 아니라 지지 점 수와 잔차를 확인하고, 예상 축을 사용하는 경우 실제 장면의 좌표계에서 표현합니다. 종료 조건은 목표 정확도를 보장하는 증명과 다릅니다.
