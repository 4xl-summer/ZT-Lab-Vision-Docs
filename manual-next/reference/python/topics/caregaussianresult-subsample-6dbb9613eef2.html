subsample(self, step_x, step_y)

결과를 ROI 로컬 원점에서 일정 간격으로 표본화합니다.

확인된 인자 조건

step_x: 가로 방향 양의 정수 간격입니다.

step_y: 세로 방향 양의 정수 간격입니다.

반환: 호출자가 닫아야 하는 새 CareGaussianResult입니다.

오류: 간격이나 결과 크기가 유효하지 않으면 오류입니다.

인자 선언

  • step_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • step_y · POSITIONAL_OR_KEYWORD · 기본값 없음

step_x: 정수 검사 · 최소 1.

step_y: 정수 검사 · 최소 1.

Return a floor-sized Gaussian result sampled from ROI-local (0,0).

이 호출의 입력과 객체 맥락

필터 영상과 계산 여부 마스크를 같은 간격으로 축소 표본화해 독립 결과를 만듭니다. 가로·세로 간격은 양의 정수이며 ROI 로컬 (0,0)에서 시작합니다. 예를 들어 x 간격 2는 가로로 한 표본씩 건너뛰며 출력 크기는 내림 기준입니다. 영상과 마스크를 같은 격자로 해석하고 새 결과와 각 영상 핸들의 수명을 따로 관리하세요. 사용 후 각 결과를 close합니다.
