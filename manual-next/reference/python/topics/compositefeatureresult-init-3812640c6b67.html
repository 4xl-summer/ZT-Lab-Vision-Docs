CompositeFeatureResult(id: int, kind: zvision._composite_metrology.CompositeGeometryKind, failure: zvision._composite_metrology.CompositeFailure, parameters: tuple | None, diagnostics: object | None = None) -> None

Feature id, kind, failure and parameters; unavailable geometry has None parameters.

id: 복합 모델에서 특성을 구분하는 식별자입니다.

kind: 결과 기하의 종류이며 사용 불가능 상태를 포함합니다.

failure: 특성 평가의 실패 이유 또는 실패 없음입니다.

parameters: 형상별 계수의 불변 튜플이며 사용 불가 형상은 None입니다. 좌표·길이 단위는 선택한 CompositeUnit을 따릅니다.

diagnostics: 해당 측정의 탐침과 적합 진단 스냅샷 또는 없는 경우 None입니다.

값을 구성하고 해석하기

복합 모델의 한 기하 특성 결과를 id와 kind, failure로 식별하고 계수 및 진단과 함께 보관합니다. 사용 불가능한 형상은 parameters가 None일 수 있으므로 kind와 failure를 먼저 읽습니다. 좌표와 길이의 단위는 해당 작업의 CompositeUnit을 따릅니다.
