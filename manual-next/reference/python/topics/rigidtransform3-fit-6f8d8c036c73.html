fit(source, reference, unit, from_frame, to_frame)

대응 3D 점에서 강체 변환을 적합합니다.

확인된 인자 조건

source: 원본 Point3 시퀀스, 유한 좌표

reference: source와 대응하는 같은 길이의 Point3 시퀀스

unit: 대응점과 이동의 LengthUnit

from_frame: 0이 아닌 원본 frame ID

to_frame: 0이 아닌 목표 frame ID

반환: RigidTransform3 값 스냅샷입니다.

오류: 대응 부족, 길이 불일치, 퇴화 또는 무효 인자는 오류입니다.

대응점으로 강체 변환 학습

같은 물리 위치를 나타내는 두 점 집합으로 회전과 이동을 추정합니다. 배열의 순서가 대응 관계이며 원본과 기준의 좌표계 식별자와 길이 단위를 명확히 지정해야 합니다. 적어도 세 점이 필요하고 한 직선에 놓인 점처럼 회전을 결정할 수 없는 퇴화 입력은 사용할 수 없습니다.

학습 대응점에 이동 (2, -3, 4)을 적용해 기준을 만들었다면 독립된 검사점 (2, 3, 4)는 (4, 0, 8)에 가까워야 합니다. 학습에 쓴 점의 오차뿐 아니라 보류한 점도 평가하면 대응 오류나 과도하게 제한된 배치를 더 쉽게 찾을 수 있습니다. 이 적합은 이상치 제거를 약속하지 않습니다.

확인 항목해석
원본 점변환 전 좌표의 대응 목록
기준 점같은 순서의 목표 좌표
최소 조건세 개 이상의 비공선 대응
검사별도의 점에 적용하고 거리 확인
