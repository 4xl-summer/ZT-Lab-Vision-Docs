execute(self) -> 'QueryExecution[ColorStatistics]'

지연 색상 계획을 실행합니다.

반환: QueryExecution이며 output은 독립 ColorStatistics 값 스냅샷입니다. 실행은 close합니다.

오류: 닫힌 계획 또는 네이티브 실행 실패는 오류입니다.

반환 타입 주석: QueryExecution[ColorStatistics]

Execute and return an independent color statistics snapshot.

통계 계획의 실행

색 통계 쿼리를 실제로 실행하고 QueryExecution의 ColorStatistics 값 스냅샷을 얻습니다. 단계 추가는 실행 계획의 구성이고 이 호출에서 계산이 수행됩니다.

입력 영역과 색 채널의 의미를 확인하고 평균, 최소·최대와 픽셀 수를 함께 읽습니다. 평균이 같더라도 분포나 선택 영역은 다를 수 있어 영상 및 설정을 결과와 함께 보관합니다.

실행 객체와 쿼리는 각각 사용 후 닫습니다. 반환된 색 통계는 복사된 값 스냅샷으로 별도의 이미지 핸들과 혼동하지 않습니다. 잘못된 기하나 닫힌 계획의 오류를 통계 0으로 처리하지 않습니다.
