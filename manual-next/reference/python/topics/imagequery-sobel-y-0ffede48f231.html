y Sobel 단계를 현재 계획에 덧붙입니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

Y 방향의 밝기 변화

Sobel Y는 행 방향의 밝기 변화와 관련된 필터 단계를 계획합니다. 값의 크기와 부호는 방향성 정보를 담을 수 있으며 결과를 입력의 단순 밝기 복사로 해석하면 안 됩니다.

실행 후 확인

세로 방향으로 일정한 부분과 값이 변하는 경계를 비교하고 출력 형식의 범위를 살핍니다. 필요하면 X 방향 단계와 별도의 결과를 비교하되 같은 이미지, ROI와 경계 설정을 유지합니다.

원본과의 대응

계획 실행 후 입력과 출력의 같은 위치를 비교하세요. 행 방향 밝기 변화의 결과와 원본 밝기 자체는 다른 값입니다. 테두리의 결과는 이웃 샘플 처리에 영향을 받으므로 내부와 분리해 확인합니다.
