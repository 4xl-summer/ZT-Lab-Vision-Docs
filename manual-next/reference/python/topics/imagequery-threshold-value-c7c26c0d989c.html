threshold_value

method · 선언 타입 zvision._query.ImageQuery

Python
threshold_value(self, t)

픽셀이 임계값 이상인지 비교하는 Gray8 마스크 단계를 추가합니다.

확인된 인자 조건

t: 유한한 밝기 임계값

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·형식 검증은 단계 추가 시, 픽셀 유효성은 execute 시 실패할 수 있습니다.

인자 선언

  • t · POSITIONAL_OR_KEYWORD · 기본값 없음

Alias for threshold; append in place with the same validation and output.

기준값을 이용한 선택

지정한 값과 입력 표본을 비교하는 임계 단계를 계획합니다. 기준보다 작은 표본, 같은 표본, 큰 표본을 나란히 놓고 비교하면 등호의 포함 여부를 확인할 수 있습니다. 임계값은 입력 표본의 단위로 해석해야 합니다.

후속 연산

반환되는 계획을 실행하고 결과 형식과 각 위치의 값을 확인합니다. 마스크를 블롭 분석에 전달하면 선택된 픽셀과 연결 조건이 물체 수를 좌우합니다. 원본의 밝기 통계가 필요하다면 전처리 이전 영상도 유지합니다.
