orthogonal_wavelet_filter_bank(self, levels, analysis_low, analysis_high, synthesis_low, synthesis_high, centered=False)

지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

analysis_low: 분석 저역 필터

analysis_high: 분석 고역 필터

synthesis_low: 합성 저역 필터

synthesis_high: 합성 고역 필터

centered: 중심 정렬 여부; 기본값 False

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • analysis_low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • analysis_high · POSITIONAL_OR_KEYWORD · 기본값 없음
  • synthesis_low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • synthesis_high · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 False

Return a custom filter-bank transform; the bank may be non-orthogonal.

분석과 합성 필터

분석 저역·고역 필터와 합성 저역·고역 필터를 각각 지정하는 직교 웨이블릿 변환입니다. 분석 필터는 분해, 합성 필터는 복원에 관여하므로 네 배열의 순서와 의미를 구분해야 합니다. levels와 centered도 결과 해석에 필요합니다.

계수 검증

필터의 형식과 길이 등 공개 유효성 조건을 확인하고 선택한 계수 집합이 원하는 복원 성질을 만족하는지 작은 입력으로 시험합니다. centered의 기본값은 False입니다. 반환된 변환 객체는 독립적으로 관리하고 사용 후 닫습니다.
