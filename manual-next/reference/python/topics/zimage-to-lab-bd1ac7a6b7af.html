to_lab(self)

색상 영상을 D50 기준 CIELAB 세 채널로 변환합니다.

반환: 별도로 close할 ColorPlanesResult입니다.

오류: 미지원 형식 또는 범위 밖 부동소수 색은 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

D50 기준 Lab 색

색상 영상을 D50 기준 CIELAB 세 평면으로 변환합니다. L, a, b는 색의 서로 다른 성분이며 HSV의 색조·채도·명도와 같은 범위로 해석하지 않습니다. Lab 색 차이 계산에서는 같은 기준과 인코딩을 사용하는 것이 필요합니다.

평면과 수명

지원되는 색 입력 형식과 유효한 부동소수 범위를 확인한 뒤 결과 ColorPlanesResult를 읽습니다. 결과는 별도로 close해야 합니다. CIE76 비교는 세 좌표 차이의 유클리드 거리이지만 이 값만으로 실제 조명이나 센서 보정의 정확성을 보장하지 않습니다.

색 차이 예

두 D50 Lab 색의 성분 차이가 (3,4,0)이면 CIE76 거리는 5입니다. 결과 평면은 세 좌표를 따로 보관하므로 기준색과 동일한 백색점·인코딩을 사용해 비교합니다. 반환 ColorPlanesResult는 사용 후 닫습니다.
