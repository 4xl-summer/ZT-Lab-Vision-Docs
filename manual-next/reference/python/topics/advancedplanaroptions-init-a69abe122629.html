AdvancedPlanarOptions(model: int, unit: int, min_inliers: int, max_candidates: int, threshold: float | None = None)

model: 1 아핀, 2 투영 모델.

unit: 세계 길이 단위 식별자.

min_inliers: 피팅에 필요한 최소 채택 대응점 수.

max_candidates: 합의 후보 상한.

threshold: 세계 단위 인라이어 거리 한계; None(기본)은 가중 최소제곱, 지정 시 유한한 양수의 합의 기준.

이 호출의 입력과 객체 맥락

고급 평면 보정에서 아핀 또는 투영 모델, 세계 단위, 최소 채택점과 합의 후보 예산을 지정합니다. 모델 값 1은 아핀, 2는 투영을 뜻하며 아핀에는 최소 세 점, 투영에는 최소 네 점이 필요합니다. threshold가 기본 None이면 가중 최소제곱 경로를 사용하고 값을 주면 세계 좌표 단위의 양의 잔차 한계로 후보를 비교합니다. 예를 들어 입력 세계 좌표를 밀리미터로 표현했다면 이 문턱도 밀리미터입니다. 가중치는 별도 함수 인자이므로 옵션에 포함된 최소점과 입력 배열의 수를 함께 확인하십시오. 대응점이 같은 직선에 몰리는 등 퇴화한 경우 점 개수만 충분해도 변환을 정할 수 없습니다. 학습 결과를 독립 보류점으로 평가하고 합의 한계를 실제 장비의 보장 오차로 해석하지 마십시오. 세계점의 단위를 바꿀 경우 임계값도 같은 길이 비율로 바꾸어야 동일한 물리 오차 기준이 유지됩니다. 추정 모델을 선택할 때 최소점 수뿐 아니라 점이 평면에 어떻게 분포하는지 확인하고, 학습에 쓰지 않은 점으로 별도 검증하십시오. 아핀 모델은 평행성이 유지되는 변환을 표현하고 투영 모델은 원근에 따른 평행성 변화를 표현할 수 있습니다. 촬영 조건에 맞는 모델을 선택하고 학습점의 잔차뿐 아니라 별도 영역의 보류점 결과를 확인하십시오.
