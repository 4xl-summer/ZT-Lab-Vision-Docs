사용과 결과 판독

준비된 OCR 계획을 실행해 자원 보유 실행 결과를 얻습니다. 획득한 결과와 실행 객체는 각각 별도 close가 필요합니다. 전처리 결과와 최종 텍스트의 단계가 다르므로 원하는 결과를 올바른 객체에서 확인하십시오.
