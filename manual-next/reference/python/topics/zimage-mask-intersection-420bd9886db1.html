mask_intersection(self, reference)

두 마스크의 교집합을 만듭니다.

확인된 인자 조건

reference: 기준 ZImage 마스크

반환: 새 마스크. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 호환되지 않는 마스크는 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

공통 전경 선택

두 마스크의 공통 전경 위치를 선택합니다. 첫 입력이 {A,B}, 둘째가 {B,C}인 예에서는 공통 위치가 {B}입니다. 이진 마스크 결합이므로 밝기 평균이나 두 영상의 차이값과 구분해야 합니다.

정렬 조건

같은 크기여도 서로 다른 ROI 위치를 가리키면 공통 픽셀로 판단하는 위치가 의도와 다릅니다. 두 영상의 원점과 전경 형식, 결과 수명을 함께 확인하고 마스크를 원본 위에 겹쳐 실제 공통 대상이 선택되었는지 살펴봅니다.
