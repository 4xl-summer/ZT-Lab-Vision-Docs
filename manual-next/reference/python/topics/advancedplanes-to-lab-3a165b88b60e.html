to_lab(self)

LCH 평면을 Lab 평면으로 변환합니다.

반환: 호출자가 close할 AdvancedPlanes 소유 객체입니다.

오류: 닫힌 객체 또는 지원되지 않는 형식·옵션은 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

LCh 평면을 Lab 평면으로 바꾸어 새로운 AdvancedPlanes 소유 객체를 반환합니다. 입력 평면이 해당 변환의 색 공간 계약에 맞는지 확인하고, 결과의 channel(0), channel(1), channel(2)로 각 평면을 읽습니다. 새 결과와 채널 영상은 각기 소유 핸들이므로 사용이 끝나면 각각 close합니다. 원본 객체에 대해 값을 제자리에서 수정하는 호출로 해석하지 마세요.

LCH 평면에서 Lab 평면

to_lab은 LCH 색 평면을 같은 백색점을 사용하는 Lab 평면으로 바꾸고 새 AdvancedPlanes를 반환합니다. 입력 객체를 제자리에서 바꾸지 않으며, 기존 평면과 변환 결과는 각자 close해야 합니다.

Lab의 첫 성분은 명도 L, 나머지는 a와 b 색축입니다. 예를 들어 a=3, b=4이면 색축 원점에서의 채도 크기는 5입니다. LCH의 C와 H를 RGB 채널 값으로 읽지 않습니다.

channel로 획득한 영상도 독립 소유이므로 결과 객체와 별도로 close합니다. 색차 비교를 하기 전 두 데이터의 백색점과 입력 전달 함수를 맞추고, 닫힌 객체에서 변환을 요청하는 오류를 빈 평면으로 바꾸지 않습니다.

LCH에서 Lab으로 되돌릴 때 L은 명도이고 C와 H가 두 색축의 크기와 방향을 나타냅니다. LCH 평면의 두 번째 채널을 Lab의 a 값으로 그대로 복사하지 않습니다. 변환된 두 번째와 세 번째 평면을 함께 읽어야 색축 위치를 해석할 수 있습니다.

색 차이를 계산하려면 대상과 기준을 같은 백색점으로 준비합니다. 색 평면의 channel 인덱스는 0, 1, 2이고 범위 밖의 요청은 오류입니다. 호출할 때마다 얻은 영상은 사용이 끝나면 별도로 닫습니다.

평면을 얻은 후에는 채널의 숫자 범위와 화면 표시 범위를 따로 확인합니다. 가령 음수가 가능한 색축 값은 8비트 미리 보기의 검은색으로 표시될 수 있지만, 원래의 부호가 사라진 것은 아닙니다.
