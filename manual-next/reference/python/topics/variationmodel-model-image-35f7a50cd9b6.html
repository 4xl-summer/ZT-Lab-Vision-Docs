model_image

method · 선언 타입 zvision._inspection_models.VariationModel

Python
model_image(self, index)

모델의 기준 또는 편차 영상을 취득합니다.

확인된 인자 조건

index: 0 기준, 1 편차

반환: 호출자가 close할 독립 ZImage입니다.

오류: 0 또는 1이 아니면 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Legacy 0.1.x indexed image acquisition; prefer model_images().

인자별 입력 조건

인자형식역할과 조건
index0 기준, 1 편차

인덱스로 모델 영상 획득

기존 호환용 인덱스 접근으로 0은 기준 영상, 1은 편차 영상을 가져옵니다. 정수 0과 1 이외 값은 ValueError입니다. 반환된 각 영상은 독립 소유이므로 사용 후 close합니다.

새 코드에서 두 영상이 모두 필요하면 model_images를 사용합니다. 기준과 편차를 바꾸어 해석하면 검사 허용 범위의 의미가 달라지므로 반환 순서를 보존합니다. 이 호출은 모델 자체를 다시 학습시키지 않습니다.
