forward_custom(cls, image, levels, low_filter, centered=False)

사용자 정의 필터로 주기적 웨이블릿 변환을 수행합니다.

확인된 인자 조건

image: 입력 ZImage

levels: 1–64 변환 레벨

low_filter: 유한한 짝수 개의 사용자 저역 필터 탭, 2–64개

centered: bool; 중심 위상 여부, 기본값 False

반환: 별도로 close할 OrthogonalWavelet입니다.

오류: 필터, 레벨 또는 영상이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • low_filter · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 False

levels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Periodic orthonormal real QMF; centered shifts by -(tap_count/2-1). Legacy factory retained through 0.1.x; prefer image.orthogonal_wavelet_custom(levels, low_filter, centered).

이 호출의 입력과 객체 맥락

사용자가 제공한 실수 저역 필터로 직교 QMF 변환을 구성합니다. centered는 중심 위상 사용 여부입니다. 다른 필터나 위상으로 만든 계수를 단순히 같은 배치라고 가정하지 말고 생성 조건을 함께 보관하세요. 결과는 독립 소유 모델이며 입력 영상과 모델, 나중에 복원한 영상은 각각 수명을 관리합니다.
