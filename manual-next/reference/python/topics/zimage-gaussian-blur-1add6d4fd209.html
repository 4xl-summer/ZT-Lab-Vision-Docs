gaussian_blur

method · 선언 타입 zvision.ZImage

Python
gaussian_blur(self, kernel: int, sigma: float)

분리형 가우시안으로 ROI를 평활화합니다.

확인된 인자 조건

kernel: 양의 홀수 커널 폭(픽셀)

sigma: 유한한 양의 표준편차(픽셀)

반환: 입력 형식·크기·ROI 원점을 유지하는 새 영상. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 미지원 형식, 잘못된 인자나 비유한 입력은 오류입니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • sigma · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음

kernel: 정수 검사 · 최소 1.

sigma: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

거리별 가중 평균

가우시안 필터는 중심에 가까운 샘플에 더 큰 가중치를 주는 평활화입니다. 커널 크기와 표준편차는 서로 다른 설정으로, 이웃 범위와 그 안의 가중치 분포를 각각 바꿉니다. 한 점만 밝은 영상을 적용하면 주변으로 퍼지는 모습을 볼 수 있습니다.

튜닝과 검증

노이즈 감소와 작은 물체의 경계 손실을 같은 입력에서 확인합니다. 내부의 일정한 영역과 영상 가장자리는 주변 샘플 조건이 다를 수 있으므로 각각 살펴봅니다. 반환된 영상은 입력과 구분하여 보관하고 사용 후 수명을 정리합니다.
