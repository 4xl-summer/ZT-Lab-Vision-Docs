method · 선언 타입 zvision._devices_advanced.ModbusTcp

Python
write_single_register(self, address, value)

Modbus TCP FC06으로 한 레지스터를 쓰며 자동 재시도하지 않습니다.

확인된 인자 조건

address: 0부터 시작하는 주소로 0–65535 정수입니다.

value: 쓸 값으로 0–65535 정수입니다.

반환: None을 반환합니다.

오류: 입력 범위 오류 또는 통신·프로토콜 오류가 발생할 수 있습니다.

인자 선언

  • address · POSITIONAL_OR_KEYWORD · 기본값 없음
  • value · POSITIONAL_OR_KEYWORD · 기본값 없음

address: 정수 검사 · 최소 0.

value: 정수 검사 · 최소 0.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

FC06으로 0 기반 16비트 주소의 레지스터 하나에 0~65535 값을 씁니다. 정상 응답은 서버가 되돌린 주소와 값을 검사합니다. 쓰기 중 시간 초과나 연결 오류가 나더라도 서버가 이미 값을 적용했을 수 있습니다. 자동 재전송은 수행하지 않으므로 명시적으로 reconnect한 뒤 애플리케이션이 장치 상태를 확인하세요.
