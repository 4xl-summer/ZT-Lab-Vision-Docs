median_filter(self, kernel)

중앙값 필터 단계를 현재 계획에 덧붙입니다.

확인된 인자 조건

kernel: 커널 폭(픽셀)

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이웃 순위 기반 평활화

중앙값 단계는 주변 값을 정렬했을 때 중간의 값을 선택합니다. 값 0,0,0,0,255의 중앙값은 0이므로 고립된 큰 값의 영향을 평균과 다르게 다룹니다. 창 크기가 커지면 실제 작은 구조도 달라질 수 있습니다.

결과 검토

이 필터와 후속 분할의 순서를 확인하고 실행 결과에서 잡음과 가는 선을 모두 살펴봅니다. 입력 영역 테두리의 표본 처리는 내부와 다를 수 있으므로 경계 근처도 확인합니다. 창 크기 및 입력 형식 조건을 지킵니다.
