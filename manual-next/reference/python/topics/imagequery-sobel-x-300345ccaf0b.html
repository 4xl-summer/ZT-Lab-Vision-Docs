x Sobel 단계를 현재 계획에 덧붙입니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

X 방향의 밝기 변화

Sobel X 단계를 현재 이미지 계획에 추가합니다. 이 결과는 x 방향 밝기 변화에 관한 값이므로 원본 밝기와 다릅니다. 부호와 출력 표현에 따라 경계가 화면에 표시되는 방식이 달라질 수 있습니다.

결과 해석

평탄한 구간과 가로 방향으로 값이 바뀌는 경계를 같은 좌표에서 비교합니다. 영상 테두리의 이웃 처리를 별도로 살피고, Y 방향 결과나 그라디언트 크기를 사용할 때는 각 값의 의미를 혼동하지 않습니다.

단계별 검토

원본의 명암 경계와 실행 결과의 위치를 나란히 표시합니다. X 방향 미분의 부호와 표시 범위가 바뀌면 같은 경계도 다르게 보일 수 있으므로 결과 형식과 표시 변환을 기록합니다.
