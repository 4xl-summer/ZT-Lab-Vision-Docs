mosaic_on_canvas(self, geometry, overlap=<MosaicOverlap.MEAN: 2>)

명시한 공통 좌표 원점과 크기의 캔버스에 모자이크를 만듭니다.

확인된 인자 조건

geometry: 양의 크기와 배율, 유한한 원점의 RegistrationMosaicGeometry.

overlap: FIRST, LAST 또는 MEAN; 기본 MEAN.

반환: 호출자가 close할 RegistrationMosaic 소유 결과입니다.

오류: 닫힌 객체 또는 부적합한 캔버스·배율·옵션은 오류입니다.

인자 선언

  • geometry · POSITIONAL_OR_KEYWORD · 기본값 없음
  • overlap · POSITIONAL_OR_KEYWORD · 기본값 <MosaicOverlap.MEAN: 2>

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Render using explicit common origin, output dimensions and scale.

사용과 결과 판독

호출자가 정한 공통 좌표 원점과 크기를 가진 캔버스에 모자이크를 만듭니다. 기하와 출력 배율, 겹침 선택을 함께 확인해 의도하지 않은 잘림이나 영상 선택을 판독하십시오. 반환 모자이크는 독립 소유 결과입니다.
