evaluate(self, image: zvision.ZImage | None = None, unit: zvision._composite_metrology.CompositeUnit | None = None) -> zvision._composite_metrology.CompositeResult

저장된 또는 지정한 등방 단위로 복합 계측을 평가합니다.

확인된 인자 조건

image: ZImage 또는 None; 영상 측정 형상에는 영상 필요.

unit: CompositeUnit 또는 None; None이면 저장 단위 사용.

반환: 소유 모델과 분리된 CompositeResult 스냅샷.

오류: 닫힌 모델·영상, 잘못된 단위 또는 평가 실패는 오류.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 타입 zvision.ZImage | None · 기본값 None
  • unit · POSITIONAL_OR_KEYWORD · 타입 zvision._composite_metrology.CompositeUnit | None · 기본값 None

반환 타입 주석: <class 'zvision._composite_metrology.CompositeResult'>

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

저장된 단위 또는 명시 단위로 평가해 독립 스냅샷을 반환한다.

이 호출의 입력과 객체 맥락

저장된 복합 계측 그래프를 평가해 모델과 독립된 CompositeResult 스냅샷을 반환합니다. 입력 형상의 좌표는 ROI 로컬 픽셀이고 출력의 등방 단위와 탐침 진단의 픽셀 단위는 구분해야 합니다. 결과에서 형상과 공차 판정을 확인하세요. 영상 측정 형상에는 전달한 ROI 영상이 필요합니다. 명시 unit은 결과 형상과 공차에 적용합니다.
