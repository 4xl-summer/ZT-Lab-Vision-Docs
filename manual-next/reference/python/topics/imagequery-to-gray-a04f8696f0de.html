to_gray(self)

회색 변환 단계를 현재 계획에 덧붙입니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

색을 단일 밝기로

현재 계획의 색상 영상을 회색 영상으로 바꾸는 단계를 추가합니다. RGB와 BGR은 성분 순서가 다르므로 입력 형식이 정확해야 합니다. 서로 다른 색도 비슷한 회색값으로 변환될 수 있어 색상 정보가 필요한 경우 원본을 유지합니다.

형식과 실행

지원 입력 형식과 출력의 회색 형식을 확인한 다음 계획을 실행합니다. 원본의 채널 값과 회색 결과의 같은 픽셀을 비교해 입력 순서가 맞는지 점검합니다. 반환 실행 객체와 출력 영상의 수명은 해당 결과 계약을 따릅니다.

후속 분석과 채널

RGB와 BGR은 성분 순서가 다릅니다. 회색 변환은 색상을 단일 채널로 줄이므로 비슷한 회색값을 가진 다른 색이 구분되지 않을 수 있습니다. 색상 비교가 필요하면 쿼리 입력이나 중간 캡처도 유지합니다.
