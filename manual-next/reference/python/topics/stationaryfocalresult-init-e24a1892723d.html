StationaryFocalResult(focal: float, rms_pixels: float, lower_focal: float, upper_focal: float, evaluations: int) -> None

Equal focal length, pixel RMS, bounded local search interval and evaluations.

focal: 동일한 fx=fy 추정 초점 거리; 픽셀.

rms_pixels: 재투영의 2D 픽셀 거리 RMS.

lower_focal: 최종 초점 검색 구간 하한; 픽셀.

upper_focal: 최종 초점 검색 구간 상한; 픽셀.

evaluations: 목적함수 평가 횟수.

이 호출의 입력과 객체 맥락

StationaryFocalResult는 알려진 회전과 고정된 주점을 이용한 초점 거리 추정의 결과입니다. focal은 동일한 X·Y 초점 거리이고 rms_pixels는 재투영 RMS이며 lower_focal과 upper_focal은 제한된 국소 탐색 구간, evaluations는 평가 횟수입니다. 초점 거리와 재투영 오차는 픽셀 단위로 읽습니다.

예를 들어 결과 focal이 500이면 카메라 내부행렬의 초점 스케일 500픽셀로 해석하며 렌즈의 물리 초점거리 500 mm라는 뜻이 아닙니다. 탐색 결과가 구간의 끝에 가깝다면 설정한 범위가 적절했는지 검토할 필요가 있습니다. 재투영 RMS와 독립된 회전 관측에서도 결과를 확인하세요.

사용 흐름과 결과 판독

StationaryFocalResult는 알려진 회전과 고정 주점을 사용한 공통 초점 거리 추정의 결과 값입니다. focal은 fx와 fy에 같은 값으로 쓰는 초점 스케일이고 rms_pixels는 재투영의 2차원 픽셀 거리 RMS입니다. lower_focal과 upper_focal은 최종 국소 탐색 구간이며 evaluations는 목적함수를 평가한 횟수입니다.

예를 들어 focal=500은 초점 스케일이 500픽셀이라는 뜻이지 렌즈의 물리 초점거리가 500 mm라는 뜻이 아닙니다. 이미지 크기나 좌표 기준을 바꾸면 주점과 초점의 픽셀 값도 같은 기준에서 다시 해석해야 합니다. RMS는 관측 픽셀과 예측 픽셀의 차이를 요약하며 공간상 거리 오차와 직접 같은 단위가 아닙니다.

이 추정은 알려진 회전, 고정 주점과 모델의 전제에 의존합니다. 반환된 최종 구간은 제한된 국소 탐색의 결과이고 모든 가능한 초점에서의 전역 최적을 증명하지 않습니다. 구간과 평가 횟수, 입력 관측을 기록하고 학습에 쓰지 않은 회전 대응으로 재투영을 별도 확인합니다.
