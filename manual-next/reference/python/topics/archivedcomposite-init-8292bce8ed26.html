ArchivedComposite(data)

직렬화 아카이브를 검증해 독립 네이티브 모델을 소유합니다. 사용 후 close하거나 컨텍스트 관리자를 사용합니다.

data: bytes, bytearray 또는 memoryview; 길이 1–2,200,000바이트의 유효한 모델 아카이브.

이 호출의 입력과 객체 맥락

버전이 있는 복합 계측 아카이브 bytes, bytearray 또는 memoryview를 받아 보관합니다. 길이는 1~2200000바이트의 유효한 모델 아카이브여야 합니다. 이후 복원은 내용을 다시 검증하는 별도 모델 경로를 사용하며, 바이트 값의 존재만으로 해당 그래프가 원하는 영상·단위에 적합하다고 보장하지 않습니다.

보관 모델 복원

data는 bytes, bytearray 또는 memoryview여야 합니다. 바이트 수가 0이거나 2,200,000을 초과하면 ValueError이고, 바이트형이 아니면 TypeError입니다. 생성자는 입력을 바이트로 복사한 다음 보관 모델을 복원합니다.

복원 시 네이티브 디코더가 보관 데이터를 검사하고 저장된 출력 단위를 읽습니다. 단위 ID가 없는 결과는 unit이 None이며 픽셀 단위를 뜻합니다. 단위가 있는 경우 숫자 값과 단위 정보를 함께 보관해야 후속 측정값을 올바르게 해석할 수 있습니다.

단위를 읽는 과정에서 오류가 발생하면 이미 만든 네이티브 핸들을 정리합니다. 생성이 성공한 ArchivedComposite는 불변 복원 모델로 close하거나 context manager로 사용합니다. 잘못된 바이트를 빈 그래프의 정상 모델로 취급하지 않습니다.

복원된 그래프 평가에서 반환된 결과는 값 스냅샷이며 이미 반환한 스냅샷은 모델을 닫은 뒤에도 유지됩니다. 입력 영상이 필요한 모델과 고정 모델의 평가 경로는 다릅니다. 저장된 데이터와 평가에 사용한 영상의 좌표·단위를 함께 확인합니다.
