quantize_gray8(image, levels)

Gray8 밝기를 균등한 왼쪽 경계 수준으로 양자화합니다.

확인된 인자 조건

image: Gray8 ZImage

levels: 균등 수준 수 2–256

반환: 별도로 close할 Gray8 영상입니다.

오류: levels 또는 형식이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음

levels: 정수 검사 · 최소 2.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Quantize to 2..256 uniform left-edge levels in an independent image.

회색 출력의 이산화

회색값 양자화는 입력 값을 Gray8로 표현하는 과정입니다. 연속적이거나 더 넓은 범위의 입력을 제한된 단계로 옮길 때 서로 다른 두 입력이 같은 출력값이 될 수 있습니다. 입력 범위와 변환 설정을 함께 읽어야 합니다.

손실과 검증

작은 값 차이가 중요한 측정에서는 변환 전후의 표본값과 경계를 비교합니다. 양자화된 출력으로는 원래의 모든 세부 값을 복구할 수 없으므로 원본이 필요한 분석에는 별도로 보관합니다. 범위 밖 값 처리와 반환 객체의 수명은 해당 계약을 확인합니다.
