IcpOptions.__init__

python 공개 선언
IcpOptions(iterations, max_distance, trim_fraction=1.0, rms_tolerance=1e-08)

점대점 ICP의 반복, 대응 거리와 정지 조건을 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

iterations: 최대 ICP 반복 수, 양의 정수

max_distance: 대응점 최대 거리, 점군 길이 단위의 유한 양수

trim_fraction: 거리 선별 후 유지하는 대응점 비율, 유한한 (0,1]; 기본 1

rms_tolerance: RMS 변화의 종료 허용값, 점군 길이 단위의 유한한 0 이상; 기본 1e-8

이 호출의 입력과 객체 맥락

점군 ICP 정제의 최대 iterations와 대응점 거리 상한 max_distance, 거리 선별 뒤 보유할 비율 trim_fraction, RMS 변화 허용값을 지정합니다. max_distance와 rms_tolerance는 점군 길이 단위입니다. trim_fraction 기본 1은 선별 후 대응점을 모두 유지하며 허용 범위는 (0,1]입니다. 최대 반복 수는 실제 반복 완료를 보증하지 않으므로 결과의 수렴 및 RMS를 확인합니다.

ICP 반복과 거리 조건

iterations와 max_distance, trim_fraction 및 rms_tolerance로 ICP 반복 조건을 구성합니다. 반복 상한과 대응 거리 한도, 일부 대응을 사용하는 비율과 종료 허용치는 서로 다른 역할입니다.

예를 들어 max_distance를 작게 하면 멀리 떨어진 점 쌍이 대응 후보에서 제외될 수 있습니다. 초기 정렬이 크게 어긋난 데이터에서는 이 값과 초기 변환을 함께 살펴야 하며, 수치만 낮춘다고 무조건 정확도가 좋아지는 것은 아닙니다.

trim_fraction과 반복·RMS 기준은 사용하는 연산의 유효 범위와 단위를 확인해 설정합니다. 결과의 수렴 상태와 대응 수, 잔차를 함께 읽고, 반복이 끝났다는 사실을 독립 데이터에 대한 정확도 보증으로 바꾸지 않습니다.

반복 횟수가 충분해도 대응 조건이 잘못되면 원하는 정렬에 수렴하지 않을 수 있습니다. 기준과 입력 점의 길이 단위, 초기 자세와 최대 대응 거리를 한 설정으로 기록합니다.

trim_fraction을 변경한 결과는 같은 대응 집합으로 계산한 결과가 아닐 수 있습니다. 반복 수와 RMS만이 아니라 사용된 대응 수와 최종 변환 방향을 보고, 별도의 확인 점에서 오차를 평가합니다.
