  • image · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Return an independent angular-by-radial image with zero origin.

각도와 반경의 출력 좌표

이 연산은 입력 ROI의 로컬 픽셀 좌표에 지정한 중심을 기준으로 직교 영상을 극좌표 영상으로 표본화합니다. 결과 영상의 x축은 각도, y축은 반경입니다. 결과에는 독립된 원점 (0, 0)이 주어지므로 입력 ROI의 글로벌 원점을 결과에 그대로 적용하면 안 됩니다.

출력의 첫 열과 마지막 열은 각각 시작 각도와 끝 각도에 대응하고, 첫 행과 마지막 행은 시작 반경과 끝 반경에 대응합니다. 예를 들어 출력 너비가 3이면 열 1은 지정한 두 각도의 중간을 표본화합니다. 각도는 라디안이고 중심과 반경은 입력 ROI의 픽셀 단위입니다. 입력 경계를 벗어난 표본은 선택한 보간과 경계값 규칙에 따라 처리됩니다.

너비와 높이는 각각 2 이상이어야 하며 시작 반경은 0 이상, 끝 반경은 그보다 커야 합니다. 끝 각도 역시 시작 각도보다 커야 하고 허용된 범위를 넘어서는 회전 구간은 오류입니다. 입력 부동소수 픽셀이 유한하지 않거나 출력 크기·형식·보간 조건이 맞지 않아도 연산은 실패할 수 있습니다. 조건 검증과 실제 장비의 측정 정확도는 별도입니다.

호출 단편과 소유권

아래는 이미 열린 image와 유효한 PolarOptions인 options를 사용하는 호출 단편입니다. 결과는 새로 소유하는 영상이므로 사용 후 닫습니다. 결과의 info를 확인할 때 원본 크기가 아닌 options의 출력 너비와 높이를 기대해야 합니다.

Python
with image.polar_unwrap(options) as polar:
    output_info = polar.info
