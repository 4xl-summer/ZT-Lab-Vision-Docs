SearchAxis(minimum: float, maximum: float, step: float)

minimum: 유한한 격자 시작값입니다. 배율 축에서는 양수여야 합니다.

maximum: 유한한 격자 상한으로 minimum 이상입니다. 간격이 맞지 않으면 마지막으로 방문하는 값보다 클 수 있습니다.

step: 유한한 양의 격자 간격입니다. 각 축은 최대 4096점입니다.

이 호출의 입력과 객체 맥락

확장 검색에서 위치, 각도 또는 축별 배율을 최소값·최대값·간격으로 표현합니다. 시작값과 상한은 유한하고 시작값은 상한 이하여야 하며 간격은 유한한 양수입니다. 배율 축으로 사용할 때는 최소 배율도 양수여야 합니다. 해당 축에서 최대 4096점까지 생성할 수 있습니다.

격자는 minimum+i×step으로 만들고 i는 0부터 floor((maximum−minimum)/step)까지입니다. 예를 들어 0부터 1까지 간격 0.4이면 0, 0.4, 0.8만 평가하므로 상한 1은 포함되지 않습니다. 위치 축은 검색 영상 로컬 픽셀, 각도는 라디안, 배율은 무차원 비율로 해석합니다. 고정값도 최소와 최대를 같게 하고 양수 간격을 주어야 합니다.

사용 순서와 결과 확인

SearchAxis는 확장 검색의 한 축을 minimum, maximum, step으로 정의합니다. 최소와 최대는 유한하며 minimum≤maximum이고 step은 유한한 양수입니다. 배율 축으로 쓰면 최소 배율도 양수여야 합니다. 한 축에는 최대 4096점이 허용됩니다.

격자의 i번째 값은 minimum+i×step이고 마지막 i는 floor((maximum−minimum)/step)입니다. 예를 들어 0부터 1까지 간격 0.4이면 방문 값은 0, 0.4, 0.8입니다. 상한 1은 허용 상한이지만 간격에 맞지 않으므로 실제 표본으로 방문하지 않습니다.

위치 축은 검색 영상의 로컬 픽셀, 각도 축은 라디안, 배율 축은 무차원 비율입니다. 고정값이 필요하다면 minimum과 maximum을 같게 하되 step은 여전히 양수여야 합니다. 축별 점 수를 계산하고 전체 검색 조건과 함께 기록하십시오.
