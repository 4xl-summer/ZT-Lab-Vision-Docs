BlobInnerCircle(x: int, y: int, radius: float) -> None

ROI-local grid center and inclusive discrete radius.

x: 최대 내부 원의 ROI 로컬 정수 중심 x입니다.

y: 최대 내부 원의 ROI 로컬 정수 중심 y입니다.

radius: 배경 픽셀 중심을 포함하지 않는 닫힌 원의 반지름(픽셀)입니다.

생성 인자와 보관되는 값

값의 해석과 사용

중심은 ROI 로컬 정수 격자 위치이고 radius는 배경 픽셀 중심을 포함하지 않는 이산 원의 반경입니다. 셀 꼭짓점을 감싸는 외접원과 다른 문제이므로 두 반경을 바꾸어 읽지 않습니다.
