find_coarse(self, source, options, pyramid_levels, coarse_acceptance=0.0, retained_candidates=128, mask=None)

이미지를 축소하지 않고 위치 격자를 거칠게 검색한 뒤 정밀화합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 검색 설정입니다.

mask: 선택적 검색 마스크입니다.

pyramid_levels: 격자 정밀화 단계 수입니다.

coarse_acceptance: 거친 단계에서 유지할 최소 점수이며 기본값 0입니다.

retained_candidates: 단계마다 유지할 양의 최대 후보 수이며 기본값 128입니다.

반환: 독립 검색 결과와 종료 진단을 반환합니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

Search with explicit NCC position-grid refinement.

호출 맥락과 결과 해석

원본 이미지를 축소하지 않고 거친 위치 격자에서 후보를 선택한 뒤 위치 격자를 정밀화합니다. 실제 축소 영상 피라미드를 사용하는 find_image_pyramid와는 다른 절차입니다. pyramid_levels는 격자 정밀화의 단계 수입니다.

coarse_acceptance는 거친 단계에서 유지할 최소 점수이며 retained_candidates는 각 단계에서 보유할 양의 최대 후보 수입니다. 두 조건을 너무 엄격하게 정하면 뒤 단계에서 정밀화할 후보가 없어질 수 있습니다. 종료 진단과 후보 수를 함께 비교합니다.
