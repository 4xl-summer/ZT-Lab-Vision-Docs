read(self)

Return `(dtype, shape, values)` in native tensor order.

이 호출의 입력과 객체 맥락

열린 텐서에서 (dtype, shape, values)를 순서대로 읽습니다. dtype은 TensorType이고 shape와 values는 각각 독립 튜플입니다. 예를 들어 shape가 (2, 3)이면 값은 네이티브 텐서 순서의 6개이며, 차원 수와 배치를 모델 입출력 계약에 맞추어 해석해야 합니다. 숫자 튜플 자체는 핸들이 아니지만 Tensor 객체는 소유 핸들이므로 사용 후 close합니다. 닫힌 객체에서는 읽을 수 없습니다.

사용 순서와 결과 해석

열린 Tensor의 형상과 원소를 복사해 (dtype, shape, values) 순서의 튜플로 돌려줍니다. dtype은 TensorType이고 shape와 values도 각각 튜플입니다. 이 값들은 읽기 시점의 복사 결과이며 Tensor 핸들 자체를 반환하는 것이 아닙니다.

예를 들어 shape가 (2, 3)이면 values에는 6개 원소가 네이티브 텐서 순서로 들어갑니다. 차원과 원소 수는 함께 읽어야 하며 6개 숫자만으로 어떤 축이 채널·높이·너비인지 자동으로 알 수 없습니다. 그 의미는 사용 중인 모델의 입출력 계약에 맞춥니다.

F32, I32, I8, U8은 서로 다른 원소 형식입니다. 읽은 값을 형식과 함께 보관하고, Tensor 소유 객체의 사용이 끝나면 close합니다. 이미 반환한 파이썬 튜플은 별도 값이지만 닫은 Tensor에서 새 read를 호출할 수는 없습니다.

예를 들어 dtype이 I8이면 각 값은 부호 있는 8비트 정수 형식의 텐서에서 복사된 값입니다. 같은 정수라도 U8은 음수가 없는 다른 원소 형식이므로 반환 dtype을 버리고 숫자만 전달하면 모델 입력 형식을 잘못 맞출 수 있습니다. 모델 출력을 저장할 때 dtype과 shape를 values와 함께 보관하면 이후 같은 순서로 복원·검사하기 쉽습니다. 읽는 동안 텐서가 열려 있어야 하며 반환된 복사 튜플은 소유 텐서 핸들과 구분됩니다.
