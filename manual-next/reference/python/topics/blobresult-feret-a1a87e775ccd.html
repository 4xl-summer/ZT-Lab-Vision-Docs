feret

method · 선언 타입 zvision._blob_advanced.BlobResult

Python
feret(self, index, angle)

선택 각도에서 Blob 투영 폭을 계산합니다.

확인된 인자 조건

index: 0 기반 Blob 인덱스

angle: 유한 각도(라디안)

반환: 폭 float입니다.

오류: 잘못된 인덱스 또는 각도는 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음
  • angle · POSITIONAL_OR_KEYWORD · 기본값 없음

index: 정수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

지정 방향의 투영 폭

0 기반 index로 성분을 선택하고 유한한 라디안 angle에서의 투영 폭을 float로 얻습니다. 투영의 최소값이 2, 최대값이 7이면 폭은 5입니다. 각도를 90도로 정하려면 π/2 라디안을 사용합니다.

인덱스와 비교

잘못된 인덱스나 각도는 오류입니다. 같은 물체라도 방향을 바꾸면 폭이 바뀌므로 다른 결과와 비교할 때 방향을 기록합니다. 인덱스는 정수이며 Blob 값 자체가 아닙니다. 물리 길이는 보정과 좌표 단위를 별도 확인합니다.
