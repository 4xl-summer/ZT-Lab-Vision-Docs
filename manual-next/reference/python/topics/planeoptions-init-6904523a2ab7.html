python 공개 선언
PlaneOptions(hypotheses=512, refinement=64, outlier_fraction=0.99, rms_tolerance=0.0, target_fraction=0.0)

옵션을 전달해 평면 가설 탐색과 정제를 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

hypotheses: 가설 탐색 횟수, 양의 정수; 기본 512

refinement: 정제 반복 상한, 양의 정수; 기본 64

outlier_fraction: 허용 이상치 비율, 유한한 [0,1); 기본 0.99

rms_tolerance: 조기 종료 RMS 개선 허용값, 점군 길이 단위의 유한한 0 이상; 기본 0

target_fraction: 조기 종료할 지지 비율; 0은 비활성, 그렇지 않으면 (0,1]; 기본 0

이 호출의 입력과 객체 맥락

점군 평면 추정의 가설 탐색 횟수 hypotheses와 정제 상한 refinement는 양의 정수입니다. outlier_fraction은 0 이상 1 미만이며 rms_tolerance는 점군 길이 단위의 0 이상 개선 허용값입니다. target_fraction은 0이면 지지 비율을 이용한 조기 종료를 사용하지 않고, 그 외에는 0보다 크고 1 이하여야 합니다. 기본값 구성과 실제 점군에 대한 평면 적합 실행은 별개입니다.

평면 탐색과 조기 종료 설정

PlaneOptions는 점군 평면 피팅의 가설 수 hypotheses와 정제 상한 refinement, 이상치 비율, RMS 개선 허용값 및 목표 지지 비율을 묶습니다. 기본값은 512, 64, 0.99, 0.0, 0.0입니다. 가설 수와 정제 수는 양의 정수이며 나머지 조건은 피팅 호출의 계약도 만족해야 합니다.

예를 들어 target_fraction=0이면 지지 비율을 이용한 조기 종료는 비활성입니다. 0.8이면 80%라는 지지 기준을 나타내며 허용 구간은 0보다 크고 1 이하입니다. outlier_fraction은 0 이상 1 미만이고 rms_tolerance는 0 이상의 점군 길이 단위 값입니다. 이 두 비율과 RMS를 같은 단위 숫자로 비교하지 마세요.

적용과 결과 확인

직접 옵션 객체를 만든다고 평면이 이미 계산되는 것은 아닙니다. 점군을 전달해 실제 피팅을 실행한 뒤 법선, 잔차, 인라이어와 종료 상태를 검토해야 합니다. 점군 좌표를 mm에서 m로 바꾸면 길이 단위의 rms_tolerance도 일관되게 변환하고, 잘못된 범위의 값은 연산 단계에서 오류가 날 수 있음을 처리합니다.
