BlobResult.filter 공개 계약

상위 목차로 돌아가기

filter

method · 선언 타입 zvision._blob_advanced.BlobResult

Python
filter(self, feature, low, high, include=True)

특성 범위에 따라 Blob을 포함 또는 제외합니다.

확인된 인자 조건

feature: 특성 코드 0–9

low: 포함 하한

high: 포함 상한

include: bool; 범위 일치 항목 포함 여부, 기본값 True

반환: 별도로 close할 BlobResult입니다.

오류: 인자 또는 결과가 유효하지 않으면 오류입니다.

인자 선언

  • feature · POSITIONAL_OR_KEYWORD · 기본값 없음
  • low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • high · POSITIONAL_OR_KEYWORD · 기본값 없음
  • include · POSITIONAL_OR_KEYWORD · 기본값 True

feature: 정수 검사 · 최소 0.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

특성 범위 선택

feature 코드 0–9가 지정하는 특성에 대해 low와 high는 포함 경계입니다. include=True가 기본이며 범위에 맞는 항목을 포함합니다. 예를 들어 특성값 7은 포함 범위 [7,10]의 경계에 해당합니다.

반환 객체

include=False의 의미와 각 feature의 단위를 해당 계약에서 확인합니다. 새 BlobResult는 별도 소유이므로 사용 후 닫고, 필터 전후의 성분 수와 위치를 비교합니다. 레이블 번호를 특성값이나 영구 객체 ID로 혼동하지 않습니다.
