AdvancedTrainingInfo(sample_count: int, threshold: float)

sample_count: 학습된 NCC 표본 또는 형상 특징점의 수입니다.

threshold: 형상 학습에 사용한 기울기 임계값이며 NCC 모델에서는 0입니다.

인자별 입력 조건

sample_count<class 'int'>학습된 NCC 표본 또는 형상 특징점의 수입니다.
threshold<class 'float'>형상 학습에 사용한 기울기 임계값이며 NCC 모델에서는 0입니다.

학습 결과 요약

sample_count는 학습 표본 수이고 threshold는 학습 결과의 임계값입니다. 수가 많다는 사실만으로 표본이 조명과 형태의 모든 변동을 대표한다고 보장할 수 없습니다.

동일 임계값을 다른 모델이나 데이터에 그대로 옮겨 판정하기보다 해당 학습 설정과 별도 시험 결과를 함께 기록합니다. 이 객체는 두 값을 담는 스냅샷입니다.
