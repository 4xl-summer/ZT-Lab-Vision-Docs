iterations: 최대 반복 수이며 양수입니다.

output_format: 출력 픽셀 형식 코드이며 기본값 GrayF32입니다.

conductance: 에지 전도도 함수이며 기본값 EXPONENTIAL입니다.

이 호출의 입력과 객체 맥락

비등방 확산의 반복 한도와 에지 전도도, 시간 단계를 지정합니다. iterations와 kappa는 양수이고 timestep은 0보다 크고 0.25 이하여야 합니다. tolerance는 마지막 최대 변화량을 판단하는 기준이며 기본 0입니다. 경계 방식과 출력 형식도 함께 지정합니다. 예를 들어 반복 상한만 늘려도 실제 수행 횟수는 종료 조건에 의해 달라질 수 있으므로 반환 보고서의 반복 수와 변화를 확인하세요.
