BlobContourHierarchyNode(id: int, parent: int | None, is_hole: bool, selected: bool, enclosed_area: float, child_count: int, selected_child_count: int) -> None

Contour identity, direct parent and immediate child counts.

id: 발견 순서로 부여한 반환 벡터 인덱스입니다.

parent: 직접 부모 ID이며 외부는 None입니다.

is_hole: 구멍 경계인지 나타냅니다.

selected: 최소 면적을 충족하는지 나타냅니다.

enclosed_area: 중첩 링을 포함한 절대 다각형 면적입니다.

child_count: 재부모화하기 전의 직접 자식 수입니다.

selected_child_count: 직접 자식 중 면적 선택을 통과한 수입니다.
