Rectification.__init__

python 공개 선언
Rectification(width, height, origin_u, origin_v, pitch_u, pitch_v, interpolation=<Interpolation.BILINEAR: 1>, border=0.0)

평면 보정 출력 격자와 보간 경계를 지정합니다. pitch의 양수 조건 등은 기하 연산 시 검증합니다.

width: 양의 출력 너비 픽셀 수입니다.

height: 양의 출력 높이 픽셀 수입니다.

origin_u: 출력 시작점의 평면 U 좌표입니다.

origin_v: 출력 시작점의 평면 V 좌표입니다.

pitch_u: U 방향의 유한한 양의 물리 간격입니다.

pitch_v: V 방향의 유한한 양의 물리 간격입니다.

interpolation: Interpolation 값이며 기본값은 BILINEAR입니다.

border: 영상 밖 샘플에 사용하는 유한한 상수 밝기이며 기본값은 0입니다.

이 호출의 입력과 객체 맥락

출력 폭과 높이는 양의 픽셀 수이며 origin_u/v는 세계 평면의 시작 좌표, pitch_u/v는 각 축의 양의 물리 간격입니다. 예를 들어 origin_u=10, pitch_u=0.5이면 U 방향 이웃 출력 표본의 평면 좌표 차이는 0.5입니다. interpolation 기본은 BILINEAR, border 기본은 0입니다. 기하 연산에서는 평면과 포즈의 프레임·단위를 맞추고 결과 유효 마스크를 함께 확인합니다.
