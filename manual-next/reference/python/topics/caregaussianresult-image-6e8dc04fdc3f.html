Copy an owned image handle: index 0 filtered image, 1 computed mask.

필터 결과와 계산 마스크

index 0은 필터 영상이며 기본값입니다. index 1은 계산 마스크입니다. 마스크를 필터 밝기 영상과 혼동하지 않도록 형식과 선택 위치를 함께 확인합니다. 지원되지 않는 인덱스나 닫힌 결과는 오류입니다.

비교

두 출력을 같은 ROI에 겹쳐 어디에서 가우시안 계산이 이루어졌는지 살펴봅니다. 반환 ZImage는 별도 소유 핸들이므로 각각 사용 후 close합니다. 경계의 결과는 선택 마스크와 이웃 설정을 함께 고려합니다.
