ZImage.convex_shapes 공개 계약

convex_shapes

method · 선언 타입 zvision.ZImage

Python
convex_shapes(self, connectivity) -> 'ConvexShapeResult'

전경 연결 성분의 볼록 형상과 최소 면적 사각형을 계산합니다.

확인된 인자 조건

connectivity: 성분 연결 방식으로 4 또는 8을 지정합니다.

반환: 독립 ConvexShapeResult 스냅샷입니다.

오류: 닫힌 객체, 지원하지 않는 입력 또는 실행 실패는 오류입니다.

인자 선언

  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음

반환 타입 주석: ConvexShapeResult

Return independent convex shapes with immutable hulls.

호출과 결과 확인

Gray8 전경의 연결 구성요소마다 볼록 껍질과 최소 면적 회전 사각형을 즉시 계산합니다. connectivity는 4 또는 8입니다. 대각선으로만 닿은 두 전경 픽셀은 4연결이면 두 성분이고 8연결이면 한 성분입니다. 껍질은 픽셀 중심이 아니라 셀 외곽으로 구성하며 좌표는 ROI 로컬입니다. 반환 값은 입력과 독립적인 형상 스냅샷입니다.
