read_holding_registers(self, address, count)

Modbus TCP FC03으로 연속 보유 레지스터를 읽습니다.

확인된 인자 조건

address: 0부터 시작하는 주소로 0–65535 정수입니다.

count: 읽을 개수로 1–125 정수입니다.

반환: 레지스터 값의 독립 정수 목록입니다.

오류: 입력 범위 오류 또는 통신·프로토콜 오류가 발생할 수 있습니다.

인자 선언

  • address · POSITIONAL_OR_KEYWORD · 기본값 없음
  • count · POSITIONAL_OR_KEYWORD · 기본값 없음

address: 정수 검사 · 최소 0.

count: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

FC03으로 0 기반 주소에서 연속된 보유 레지스터를 읽어 독립 정수 목록을 반환합니다. count는 1~125이고 주소와 수의 합은 65536 이하여야 합니다. 예를 들어 주소 0, count 2는 프로토콜 주소 0과 1을 요청합니다. 40001 같은 문서 표기는 자동 변환하지 않습니다. 통신·프로토콜 오류 뒤 재연결 여부와 diagnostic을 확인하세요.
