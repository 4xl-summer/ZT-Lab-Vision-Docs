InitialOverlapReport(matrix: tuple, initial_overlap: float, status: zvision._registration_constraints.InitialOverlapStatus, quality: zvision._registration_constraints.InitialOverlapQuality | None) -> None

Initial-overlap result, preserved fallback matrix and optional quality.

matrix: 최적화된 행 우선 3×3 행렬 또는 실패 시 보존된 초기 행렬입니다.

initial_overlap: 작은 영상의 픽셀 면적을 분모로 한 초기 겹침 비율이며 0–1입니다.

status: 최적화 완료, 초기 겹침 미달 또는 유효 점수 없음 상태입니다.

quality: 정합에 성공해 측정된 품질 값이며 실패 또는 미측정이면 None입니다.

이 호출의 입력과 객체 맥락

행 우선 3×3 matrix와 초기 겹침 비율, 처리 status 및 선택적인 quality를 담습니다. 성공한 경우 matrix는 최적화된 값이고 실패 시 초기 행렬이 보존됩니다. initial_overlap은 작은 영상의 픽셀 면적을 분모로 한 0~1 비율입니다. quality는 성공해 측정된 경우에만 제공되므로 status를 확인한 후 읽어야 합니다.

초기 겹침과 결과 상태

InitialOverlapReport는 행 우선 matrix, initial_overlap, status와 선택적 quality를 담는 값입니다. 정상 최적화 결과라면 matrix는 최적화된 변환을 담고, 조건 미달이나 유효 점수가 없는 경로에서는 초기 행렬이 보존될 수 있습니다. 따라서 행렬만 읽지 말고 status를 먼저 확인해야 합니다.

initial_overlap은 겹친 픽셀 면적을 두 영상 중 작은 영상의 픽셀 면적으로 나눈 0..1 비율입니다. 예를 들어 작은 영상이 100픽셀이고 초기 겹침이 40픽셀이면 비율은 0.4입니다. 이 값은 최적화 후 최종 점수나 coverage와 다른 단계의 수치입니다.

quality는 유효하게 측정된 경우에만 제공되며 그렇지 않으면 None입니다. 생성자는 matrix를 튜플로 복사하고 quality의 형식을 확인하지만, 직접 만든 값이 실제 정합을 수행했다는 뜻은 아닙니다. 결과를 생산한 함수의 상태와 기준·소스 좌표계, 초기 조건을 함께 기록합니다.

판독과 확인 사례

initial_overlap이 0.4라고 해서 최종 결과가 반드시 40%의 유효 표본을 사용했다는 뜻은 아닙니다. 초기 겹침의 분모는 작은 영상의 픽셀 면적이고, quality가 존재할 때의 coverage는 정합 평가에서 측정된 별도의 값입니다. 서로 다른 단계의 수치를 구분합니다.

matrix를 읽을 때 status가 실패 경로라면 보존된 초기 행렬임을 호출자에게 표시해야 합니다. 사용자가 직접 데이터 값을 만들 때 생성자는 숫자 시퀀스를 튜플로 복사하고 quality 타입을 검사하지만, 그 값이 실제 정합 연산에서 나왔는지 검증하는 것은 아닙니다.
