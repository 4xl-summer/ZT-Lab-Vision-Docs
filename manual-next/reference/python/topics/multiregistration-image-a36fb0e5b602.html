MultiRegistration.image 공개 계약

상위 목차로 돌아가기

image

method · 선언 타입 zvision._multi_registration.MultiRegistration

Python
image(self, index, validity=False)

정렬 영상 또는 유효 마스크를 취득합니다.

확인된 인자 조건

index: 0 기반 영상 인덱스

validity: True면 유효 마스크, 기본값 False

반환: 별도로 close할 GrayF64 정렬 영상 또는 Gray8 마스크입니다.

오류: 인덱스 범위나 validity 타입이 잘못되면 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음
  • validity · POSITIONAL_OR_KEYWORD · 기본값 False

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Return independently owned aligned F64 image or Gray8 validity mask.

정렬 영상 또는 마스크

index는 0 기반 영상 인덱스이고 validity 기본값은 False입니다. False면 GrayF64 정렬 영상, True면 Gray8 유효 마스크를 얻습니다. 마스크의 값은 밝기 측정값과 다른 의미입니다.

결과 확인

지정 영상과 유효 마스크를 같은 좌표에서 확인해 유효하지 않은 위치를 제외합니다. 범위 밖 인덱스나 bool이 아닌 validity는 오류입니다. 반환 ZImage는 별도 소유이므로 사용 후 닫습니다.
