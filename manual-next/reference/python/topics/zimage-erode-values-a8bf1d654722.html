erode_values

method · 선언 타입 zvision.ZImage

Python
erode_values(self, kernel_size: int)

밝기 최솟값 침식을 적용합니다.

확인된 인자 조건

kernel_size: 양의 홀수 커널 폭

반환: 별도로 close할 ZImage입니다.

오류: 인자나 영상 형식이 지원되지 않으면 오류입니다.

인자 선언

  • kernel_size · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

kernel_size: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

회색값의 국소 최솟값

값 침식은 지정된 이웃의 밝기 최솟값을 사용합니다. 예를 들어 이웃이 1, 4, 2이면 그 최솟값은 1입니다. 이진 전경의 크기만 조절하는 연산으로 해석하지 말고 원본 회색값의 범위를 함께 확인합니다.

창의 폭

kernel_size는 양의 홀수 커널 폭입니다. 폭과 반복 횟수는 다른 설정이며 넓은 창은 어두운 값이 영향을 미치는 범위를 바꿀 수 있습니다. 영상 가장자리와 작은 어두운 구조를 입력과 같은 좌표에서 비교하고 반환 영상을 닫습니다.
