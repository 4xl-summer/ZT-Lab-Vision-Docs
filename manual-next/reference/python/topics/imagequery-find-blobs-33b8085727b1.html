find_blobs

method · 선언 타입 zvision._query.ImageQuery

Python
find_blobs(self, connectivity=8)

Blob 종료 계획을 만듭니다.

확인된 인자 조건

connectivity: 4 또는 8; 기본값 8

반환: 별도 close할 타입 지정 Query입니다.

오류: 유효하지 않은 연결성은 오류입니다.

인자 선언

  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 8

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

계획된 마스크의 성분 분석

앞 단계에서 만든 전경 마스크를 연결 성분으로 분석합니다. 대각선 픽셀 (0,0), (1,1)은 4연결에서 두 성분이고 8연결에서는 면적 2인 하나입니다. 같은 마스크라도 연결 설정에 따라 결과 개수가 달라집니다.

결과를 읽기

반환되는 BlobQuery의 실행 결과에서 면적과 위치를 확인합니다. 면적은 전경 픽셀 수이며 사각형의 폭과 높이의 곱과는 다를 수 있습니다. ROI 로컬 위치를 전체 원본에 표시할 때 원점을 반영하고 실행 객체의 수명을 지킵니다.
