encode(self, *, max_bytes)

버전과 무결성 정보를 갖는 모델을 직렬화합니다.

확인된 인자 조건

max_bytes: 출력 바이트 수의 양의 상한.

반환: 독립 bytes 값입니다.

오류: 닫힌 객체, 부적합 입력 또는 한도 초과 시 오류입니다.

인자 선언

  • max_bytes · KEYWORD_ONLY · 기본값 없음

max_bytes: 정수 검사 · 최소 1.

Serialize this model using a bounded versioned, checksummed format.

인자별 입력 조건

인자형식역할과 조건
max_bytes출력 바이트 수의 양의 상한.

변동 모델 직렬화

max_bytes로 양의 바이트 한도를 지정하고 버전과 체크섬이 있는 모델 데이터를 bytes로 복사합니다. 크기 한도는 생성할 직렬화 결과의 제한이며 값이 0인 설정은 허용하지 않습니다.

반환 바이트와 소유 모델 핸들은 다른 수명입니다. 저장할 때 모델을 만든 입력과 옵션도 별도로 기록하면 결과의 출처를 추적할 수 있습니다. 체크섬은 임의 데이터 손상을 검출하는 형식 정보이며 모델의 검사 정확도를 증명하지 않습니다.
