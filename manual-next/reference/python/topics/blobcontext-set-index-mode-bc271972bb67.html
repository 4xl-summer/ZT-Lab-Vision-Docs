BlobContext.set_index_mode 공개 계약

set_index_mode

method · 선언 타입 zvision._blob_context.BlobContext

Python
set_index_mode(self, by_label)

현재 결과 조회를 인덱스 또는 라벨 방식으로 지정합니다.

확인된 인자 조건

by_label: bool; True면 라벨, False면 0 기반 인덱스

반환: None입니다.

오류: bool이 아니면 TypeError입니다.

인자 선언

  • by_label · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Use labels rather than indices for current-result get without recomputing.

조회 키의 해석

by_label이 True면 레이블 방식, False면 0 기반 인덱스 방식으로 현재 결과를 조회합니다. 전달한 숫자가 같은 1이어도 두 모드에서는 다른 성분을 가리킬 수 있습니다. bool이 아니면 TypeError입니다.

get과의 관계

모드를 설정한 후 get에 넘기는 값을 선택한 방식에 맞춥니다. 레이블은 결과 내 영역 번호이며 리스트 순번이나 다음 프레임의 영구 식별자와 구분합니다. 필요한 현재 계산 결과가 존재하는지도 함께 확인합니다.
