read_text(self, image: zvision.ZImage, spec: zvision._recognition.OcrSpec) -> zvision._recognition.OcrRead

OCR 엔진과 이미지의 지정 영역으로 문자를 읽고 결과를 스냅샷으로 복사합니다.

확인된 인자 조건

image: ZImage 입력입니다.

spec: OcrSpec 영역 및 결과 판정 설정입니다.

반환: OcrRead 값이며 이미지와 엔진 해제 후에도 유효합니다.

오류: 잘못된 입력이나 인식 오류가 전달됩니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision.ZImage'> · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision._recognition.OcrSpec'> · 기본값 없음

반환 타입 주석: <class 'zvision._recognition.OcrRead'>

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Read text from image using this engine and return an independent snapshot.

The snapshot remains usable after the image or engine is closed. Invalid
input and native recognition errors propagate to the caller.

사용과 결과 판독

영역 설정을 영상의 로컬 좌표에 맞춘 뒤 읽습니다. 반환된 텍스트와 문자별 결과의 상태를 함께 확인하고, 인식할 문자가 없거나 읽지 못한 상황을 좌표 0의 문자로 대체하지 마십시오. 결과는 엔진 및 영상과 독립된 스냅샷입니다.
