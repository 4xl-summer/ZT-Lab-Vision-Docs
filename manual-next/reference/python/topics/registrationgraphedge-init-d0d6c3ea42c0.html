RegistrationGraphEdge(reference: int, source: int, options: zvision._matching_advanced.AdvancedRegistrationOptions) -> None

Reference and source image indices and pairwise registration options.

reference: 기준 영상 인덱스.

source: 정합할 소스 영상 인덱스.

options: 쌍 정합 AdvancedRegistrationOptions.

이 호출의 입력과 객체 맥락

RegistrationGraphEdge는 여러 영상 정합 그래프에서 한 쌍의 기준 영상과 원본 영상 인덱스 및 쌍별 정합 옵션을 지정합니다. reference와 source의 방향은 변환 해석에 중요하며 options에는 AdvancedRegistrationOptions를 사용합니다. 숫자 인덱스가 영상 목록의 올바른 항목을 가리키는지 먼저 확인해야 합니다.

예를 들어 영상 목록 [A,B,C]에서 reference=0, source=1인 간선은 A와 B의 쌍을 나타냅니다. C까지 연결하려면 C가 포함된 다른 간선을 구성해야 합니다. 인덱스를 뒤집으면 같은 두 영상이라도 기준과 원본 역할이 달라집니다. 동일한 장면의 겹치는 영역이 충분한지와 입력 순서가 바뀌지 않았는지 함께 확인하세요.

기준과 소스의 방향

RegistrationGraphEdge는 영상 목록의 두 인덱스와 AdvancedRegistrationOptions를 묶는 입력 값입니다. reference는 기준 영상이고 source는 그 기준에 정합할 영상입니다. 예를 들어 [A,B,C]에서 reference=0, source=1이면 A가 기준이고 B가 소스입니다. 순서를 바꾸면 변환의 기준 방향도 달라집니다.

options에는 쌍 정합을 위한 초기 변환, 단계와 반복, 유효 범위 등의 설정이 들어갑니다. 같은 두 영상을 가리키더라도 각 간선에 다른 초기 조건을 줄 수 있으므로 입력 목록 순서와 각 간선의 옵션을 함께 기록합니다. 간선을 만드는 것만으로 영상이 정합되거나 결과 행렬이 계산되지는 않습니다.

여러 영상을 공통 좌표계에 연결할 때는 그래프의 연결성과 각 쌍의 실제 겹침을 함께 살핍니다. A-B 간선 하나로 C까지 자동으로 연결되지는 않습니다. 평가 결과가 있다면 그 간선의 score, coverage, residual과 입력 인덱스를 대조해 올바른 영상 쌍의 품질인지 확인합니다.
