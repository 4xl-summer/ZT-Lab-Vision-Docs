train(cls, image, metric, mask=None)

정수 평행이동 검색을 위해 선택 템플릿 픽셀을 복사합니다.

확인된 인자 조건

image: COLOR_NCC의 RGB8 또는 GRAY_SAD의 Gray8 템플릿입니다.

metric: TemplateMetric 방식입니다.

mask: 템플릿과 같은 크기·원점의 선택 Gray8 마스크입니다.

반환: 호출자가 닫아야 하는 모델입니다.

오류: 선택점이 3개 미만이거나 색 NCC 분산이 0, 형식·마스크가 잘못되면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • metric · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

metric: 정수 검사 · 최소 0.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Train RGB8 COLOR_NCC or Gray8 GRAY_SAD with an optional matching Gray8 care mask.

호출 맥락과 결과 해석

정수 평행이동 검색에 사용할 선택 템플릿 픽셀을 복사해 모델을 만듭니다. metric이 COLOR_NCC일 때 RGB8, GRAY_SAD일 때 Gray8 템플릿을 사용합니다. 옵션 마스크는 같은 크기와 원점의 Gray8입니다.

선택된 metric과 입력 형식은 나중의 검색 영상에도 맞아야 합니다. 모델 생성 이후 find에서 검색 범위와 허용 판정값을 별도로 정하고, 작업이 끝나면 모델을 닫습니다. 템플릿 픽셀을 복사한 모델이므로 검색 옵션 자체를 학습하는 호출은 아닙니다.

입력 선택을 위한 확인

입력의미와 조건
imageCOLOR_NCC의 RGB8 또는 GRAY_SAD의 Gray8 템플릿입니다.
metricTemplateMetric 방식입니다.
mask템플릿과 같은 크기·원점의 선택 Gray8 마스크입니다.
