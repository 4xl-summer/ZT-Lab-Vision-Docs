find_image_pyramid(self, source, options, first_level, last_level=0)

실제로 축소한 영상과 모델을 사용해 지정 층을 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 검색 설정입니다.

first_level: 시작 축소 수준입니다.

last_level: 마지막 축소 수준이며 기본값 0입니다.

반환: 독립 검색 결과와 종료 진단을 반환합니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first_level · POSITIONAL_OR_KEYWORD · 기본값 없음
  • last_level · POSITIONAL_OR_KEYWORD · 기본값 0

Search actual reduced images over the requested levels.

호출 맥락과 결과 해석

실제로 축소한 영상과 모델을 사용해 선택한 피라미드 수준을 검색합니다. 위치 격자만 거칠게 만드는 find_coarse와 달리 영상 자체가 바뀌므로 작은 무늬가 축소 단계에서 표현되는지도 고려해야 합니다.

first_level은 시작 축소 수준, last_level은 마지막 축소 수준이며 마지막 수준의 기본값은 0입니다. 같은 입력과 다른 설정을 유지하고 수준 범위를 비교하면 축소 단계가 결과와 종료 진단에 미치는 영향을 파악할 수 있습니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options확장 검색 설정입니다.
first_level시작 축소 수준입니다.
last_level마지막 축소 수준이며 기본값 0입니다.

반환값 확인

독립 검색 결과와 종료 진단을 반환합니다.
