Line2DSegment(point: zvision._regions.Point2, direction: zvision._regions.Point2, start: zvision._regions.Point2, end: zvision._regions.Point2, length: float, coverage: float, intensity: float, contrast: float, normalized_contrast: float, rms: float, maximum: float, inliers: int, converged: bool, iterations: int) -> None

Inlier-extrema segment, distinct-stripe coverage and measured statistics.

point: 직선 위의 ROI 로컬 픽셀 좌표입니다.

direction: 직선의 단위 방향 벡터입니다.

start: 인라이어 범위의 시작 끝점으로 ROI 로컬 픽셀 좌표입니다.

end: 인라이어 범위의 끝점으로 ROI 로컬 픽셀 좌표입니다.

length: 양 끝점 사이 거리이며 픽셀 단위입니다.

coverage: 점유된 서로 다른 띠 수를 포함 띠 인덱스 범위 길이로 나눈 비율입니다.

intensity: 인라이어 평균 밝기입니다.

contrast: 인라이어 평균 기울기 크기의 절반입니다.

normalized_contrast: 각 반응을 제한한 정규화 대비의 평균입니다.

rms: 인라이어 거리 잔차의 RMS이며 픽셀 단위입니다.

maximum: 인라이어 최대 거리 잔차이며 픽셀 단위입니다.

inliers: 인라이어 개수입니다.

converged: 지역 적합 수렴 여부입니다.

iterations: 적합 반복 횟수입니다.

이 호출의 입력과 객체 맥락

ROI 로컬 직선 위 점과 단위 방향, 인라이어 범위의 시작·끝점, 길이와 품질을 담습니다. length, rms, maximum은 픽셀 단위이고 coverage는 포함 띠 범위에서 점유된 서로 다른 띠의 비율입니다. 예를 들어 길이가 길어도 coverage가 낮으면 중간 관측이 희소할 수 있습니다. 점과 끝점을 전체 프레임과 비교할 때 ROI 원점을 고려하세요.
