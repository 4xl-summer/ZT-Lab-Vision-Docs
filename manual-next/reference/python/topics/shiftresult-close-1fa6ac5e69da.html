close(self)

결과가 소유한 영상과 유효 마스크를 모두 닫습니다.

반환: None을 반환합니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

이 결과가 보유한 image와 valid_mask를 모두 닫습니다. 먼저 영상 닫기를 시도하고 오류가 나더라도 마스크 닫기를 시도합니다. 예를 들어 이동 영상에서 경계 채움 위치와 실제 입력에서 온 픽셀을 마스크로 구별한 뒤 두 영상 사용이 끝나면 이 메서드를 호출합니다. with 문으로 결과를 사용하면 블록 종료 시 close가 호출됩니다. 닫힌 핸들로 이미지나 마스크를 계속 읽지 마세요.

이 객체의 확인된 공개 생성 경로: ShiftResult(image, valid_mask).

사용 조건과 결과 판독

ShiftResult는 이동 결과 image와 valid_mask를 함께 소유합니다. close는 image를 닫고, 그 도중 오류가 있어도 finally에서 valid_mask를 닫으려 합니다. 둘을 모두 열어 사용할 수 있는 동안 영상과 유효 위치를 함께 판독하는 것이 중요합니다.

예를 들어 한 행 [0,10,20]을 오른쪽 한 픽셀로 이동하고 경계를 0으로 채웠다면 결과의 앞부분 0은 경계 채움이고 다음 0은 입력의 실제 0일 수 있습니다. 유효 마스크를 사용하면 같은 수치가 나타나더라도 실제 입력에서 온 위치를 구분할 수 있습니다.

사용이 끝나면 결과의 close를 호출하거나 with 블록으로 수명을 제한합니다. 닫힌 image나 valid_mask를 이용해 다른 연산을 시작하지 마세요. 두 영상에 별도 소유 공유를 취득한 경우에는 그 공유의 계약과 수명도 별도로 확인해야 합니다.

예를 들어 원본의 실제 밝기 0과 이동으로 입력 영역 밖에서 채워진 0은 출력 밝기만 보면 같습니다. valid_mask에서 대응 여부를 확인하면 두 위치를 구분할 수 있습니다. 필요한 출력과 마스크를 열린 동안 함께 처리한 뒤 결과를 close하세요. 이미지 하나만 닫고 마스크가 자동으로 정리됐다고 판단하는 대신 결과의 수명 규칙을 따릅니다.
