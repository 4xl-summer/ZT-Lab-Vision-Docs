method · 선언 타입 zvision._rigid_frames.CalibrationSession

Python
insert(self, camera, target, pose, object_points, pixels)

새 키에 대응점 관측을 삽입합니다.

확인된 인자 조건

camera: 카메라 ID.

target: 타깃 ID.

pose: 포즈 ID.

object_points: 1–4096개의 객체 평면 Point2.

pixels: 같은 개수의 픽셀 Point2.

반환: None.

오류: 키·점 타입, 대응점 개수 또는 닫힌 세션이 유효하지 않으면 오류. 이미 존재하는 키는 오류.

인자 선언

  • camera · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • object_points · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Atomically insert a new key; reject an existing camera/target/pose.

사용과 결과 판독

새 카메라·표적·자세 키에 표적점과 글로벌 픽셀의 대응을 추가합니다. 이미 있는 키는 거부하므로 기존 관측을 교체하는 set과 목적이 다릅니다. 점 배열의 길이와 순서를 맞추고 세 식별자가 어떤 촬영 시점과 표적인지 기록하십시오. 실패한 삽입을 성공으로 보고 기존 관측이 교체됐다고 가정하지 않습니다.
