Python
where(self, expression)

표현식 필터를 가변 계획에 추가합니다.

확인된 인자 조건

expression: Blob 필드에 대한 논리 표현식

반환: 수정된 동일 BlobQuery입니다.

오류: 표현식이 유효하지 않으면 오류입니다.

인자 선언

  • expression · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

블롭 조건 필터

expression은 Blob 필드에 대한 논리 표현식으로, 해당 조건을 계획에 추가합니다. 예를 들어 픽셀 면적을 조건으로 사용하면 작은 성분을 제외할 수 있지만 외접 사각형 넓이와 전경 픽셀 수를 구별해야 합니다.

좌표와 실행

x, y는 ROI 로컬 경계 사각형의 시작 위치이고 area는 연결된 비영 픽셀 수입니다. 수정된 동일 BlobQuery에서 실행한 결과를 확인하며, 유효하지 않은 표현식은 오류가 될 수 있습니다. 원본 마스크와 조건을 함께 기록합니다.
