threshold: 원시 밝기 단위의 기본 허용치로 유한한 양수입니다.

correction: 밝기 보정 방식으로 기본값은 NONE입니다.

polarity: 잔차에서 선택하는 극성이며 기본값은 ABSOLUTE입니다.

texture_kernel: 국소 표준편차 창의 양의 홀수 폭이며 픽셀 단위, 기본값은 1입니다.

texture_weight: 기준 국소 표준편차 가중치로 유한한 0 이상이며 기본값은 0입니다.

이 호출의 입력과 객체 맥락

정렬된 영상의 밝기 차이를 판정할 기본 threshold와 보정·극성 및 국소 텍스처 보조 조건을 묶습니다. threshold는 원시 밝기 단위의 유한한 양수입니다. texture_kernel은 양의 홀수 픽셀 폭이고 texture_weight는 유한한 0 이상입니다. 기본 correction은 NONE, polarity는 ABSOLUTE, 텍스처 가중치는 0입니다. 다른 픽셀 형식의 밝기 범위를 비교할 때 같은 숫자 임계치를 자동으로 같은 물리량으로 취급하지 마세요.

사용 조건과 결과 판독

DifferenceSpec은 정렬된 입력과 기준의 밝기 차이를 판정할 기본 허용치, 보정과 극성, 기준 영상의 국소 텍스처 조건을 묶습니다. threshold는 원시 밝기 단위의 유한한 양수이고 correction의 기본은 NONE, polarity의 기본은 ABSOLUTE입니다.

기본 경로의 각 픽셀 허용치는 threshold + texture_weight×기준 이웃의 표준편차입니다. 예를 들어 threshold=4, texture_weight=2, 국소 표준편차=3이면 허용치는 10입니다. 선택한 극성 잔차 크기가 10이면 score=1이고 마스크의 판정 경계에 도달합니다.

texture_kernel은 양의 홀수 픽셀 폭이고 texture_weight는 유한한 0 이상입니다. kernel=1 또는 weight=0이면 텍스처 항이 없는 기본 threshold 비교로 돌아갑니다. 입력과 기준의 크기·origin, include 영역을 맞춘 다음 부호 차이·점수·마스크를 서로 다른 결과로 읽어야 합니다.
