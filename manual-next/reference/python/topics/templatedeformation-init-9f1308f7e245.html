TemplateDeformation(columns: int, rows: int, displacements: tuple) -> None

TemplateDeformation(columns: int, rows: int, displacements: tuple)

columns: 변위 격자의 열 수로 2 이상입니다. 격자점 총수는 최대 1024입니다.

rows: 변위 격자의 행 수로 2 이상입니다. 격자점 총수는 최대 1024입니다.

displacements: 출력에서 템플릿 방향의 로컬 픽셀 변위입니다. 행 우선으로 행×열개의 유한 좌표를 지정합니다.

값을 구성하고 해석하기

비강체 템플릿 변형 한 가지를 제어 격자의 변위로 지정합니다. columns와 rows는 각각 2 이상이며 변위의 개수는 두 값의 곱과 같아야 하고 총점은 1024 이하여야 합니다. Point2 변위는 템플릿 로컬 픽셀 단위로 행 우선 저장되며 성분은 유한해야 합니다.
