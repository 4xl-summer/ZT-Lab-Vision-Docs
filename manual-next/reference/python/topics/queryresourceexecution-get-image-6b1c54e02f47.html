get_image(self, name: 'str')

이름 붙은 캡처의 별도 소유 영상 공유를 얻습니다.

확인된 인자 조건

name: 캡처 이름

반환: 호출자가 close할 독립 ZImage입니다.

오류: 닫힌 실행 또는 없는 캡처 이름은 오류입니다.

인자 선언

  • name · POSITIONAL_OR_KEYWORD · 타입 str · 기본값 없음

Acquire an independent captured image; the caller must close it.

리소스 실행의 캡처

name으로 캡처된 영상의 별도 소유 ZImage 공유를 얻습니다. 해당 이름이 계획에 존재해야 하며 이미 닫힌 실행이나 없는 이름은 오류입니다. 결과 핸들과 실행 결과는 같은 소유 객체가 아닙니다.

단계별 비교

획득한 캡처를 원본 및 최종 출력과 같은 ROI 기준으로 표시하면 처리 중 변화한 위치를 확인할 수 있습니다. 사용이 끝난 이미지와 실행 객체를 각각 close하고, 공유 핸들을 깊은 복제라고 가정하지 않습니다.
