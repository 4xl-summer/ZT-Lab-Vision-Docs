to_rgb(self, format)

색 평면을 지정된 RGB 계열 형식의 영상으로 변환합니다.

확인된 인자 조건

format: 출력 PixelFormat이며 지원 색 형식이어야 합니다.

반환: 독립 소유 영상이며 사용 후 close합니다.

오류: 닫힌 결과 또는 유효하지 않은 인수는 오류입니다.

인자 선언

  • format · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

사용과 결과 판독

색 평면을 요청한 RGB 계열 출력 형식으로 변환합니다. 변환 전 평면의 색 공간과 출력 포맷을 함께 기록하면 채널 배열의 의미를 바꾸어 해석하는 실수를 줄일 수 있습니다. 결과 영상은 별도 소유 자원입니다.

항목확인된 계약
역할색 평면을 지정된 RGB 계열 형식의 영상으로 변환합니다.
format출력 PixelFormat이며 지원 색 형식이어야 합니다.
반환독립 소유 영상이며 사용 후 close합니다.
