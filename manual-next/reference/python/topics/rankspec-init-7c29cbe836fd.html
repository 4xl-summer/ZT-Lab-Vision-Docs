RankSpec.__init__

python 공개 선언
RankSpec(width: int, height: int, anchor: tuple, quantile: float, footprint: object, border: int, output: zvision.PixelFormat, constant: float = 0.0) -> None

Rank footprint, anchor, border and output format.

width: 순위 창의 양의 너비입니다.

height: 순위 창의 양의 높이입니다.

anchor: 창 내부의 (X, Y) 앵커 인덱스입니다.

quantile: 선택할 분위로 유한한 0–1 값입니다.

footprint: 활성 위치의 바이트 배열 또는 None입니다. 배열은 창 크기와 같고 하나 이상이 활성이어야 합니다.

border: 입력 ROI 밖에서 복제·반사·상수 중 적용할 경계 방식입니다.

output: 출력 회색 형식으로 Gray8, Gray16 또는 GrayF32입니다.

constant: 상수 경계에 사용하는 밝기이며 기본값은 0입니다.

이 호출의 입력과 객체 맥락

순위 필터의 창 너비·높이와 창 내부 anchor, 선택 quantile을 지정합니다. quantile은 0~1이고 선택적 footprint는 창 크기와 같은 활성 바이트 배열이며 적어도 한 위치가 활성이어야 합니다. 예를 들어 3×3 창은 footprint 9개로 이웃을 고릅니다. border는 ROI 밖 표본 처리이고 output은 Gray8/16/F32이므로 창 선택과 출력 형식을 구분하세요.
