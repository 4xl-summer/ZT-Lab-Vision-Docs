학습된 NCC 또는 형상 모델로 지정 격자에서 검색합니다.

확인된 인자 조건

options: 확장 검색 설정입니다.

mask: 선택적 검색 마스크입니다.

반환: 모델과 영상에서 독립된 AdvancedMatchReport입니다.

오류: 닫힌 모델 또는 잘못된 영상·설정은 오류입니다.

호출 맥락과 결과 해석

학습된 NCC 또는 형상 모델을 검색 영상과 옵션에 적용합니다. 옵션의 위치·각도·배율 격자는 후보 포즈를 지정하며 위치는 검색 ROI 로컬 픽셀, 각도는 라디안입니다. 학습한 모델 종류에 따라 점수의 해석도 달라집니다.

반환된 매치 목록과 평가 수·종료 상태를 함께 확인합니다. 후보 예산은 평가할 포즈를 제한하며 최대 결과 수와 별도입니다. 마스크를 사용할 때 영상과 마스크의 좌표 관계도 확인합니다.
