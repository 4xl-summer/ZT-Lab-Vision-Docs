CareHistogram.mode_bin 공개 계약

mode_bin

method · 선언 타입 zvision._masked_gap.CareHistogram

Python
mode_bin(self, channel=0)

최빈값 빈 인덱스를 계산합니다.

확인된 인자 조건

channel: 0 기반 채널 인덱스; 기본값 0

반환: 정수 빈 인덱스입니다.

오류: 채널이 유효하지 않으면 오류입니다.

인자 선언

  • channel · POSITIONAL_OR_KEYWORD · 기본값 0

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

최빈 빈 인덱스

지정 채널의 최빈 빈 인덱스를 계산합니다. 기본 channel=0은 첫 채널이며 유효하지 않은 채널은 오류입니다. 출력은 개수나 실제 밝기 자체가 아니라 0 기반 빈 위치로 해석해야 합니다.

예와 비교

빈 개수가 2, 7, 3이면 최다 빈의 인덱스는 1입니다. 같은 인덱스라도 lower, upper, bins가 다르면 다른 값 구간일 수 있습니다. 결과와 함께 마스크, 채널 및 구간 설정을 보관합니다.
