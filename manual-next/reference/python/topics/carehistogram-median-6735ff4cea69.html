method · 선언 타입 zvision._masked_gap.CareHistogram

Python
median(self, channel=0)

낮은 중앙값 빈 인덱스를 계산합니다.

확인된 인자 조건

channel: 0 기반 채널 인덱스; 기본값 0

반환: 정수 빈 인덱스입니다.

오류: 채널이 유효하지 않으면 오류입니다.

인자 선언

  • channel · POSITIONAL_OR_KEYWORD · 기본값 0

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

별칭과 결과 해석

MaskedHistogram은 CareHistogram과 같은 클래스이며 median과 median_bin은 같은 함수입니다. channel은 0부터 시작하고 기본값은 0입니다. 결과는 해당 채널의 낮은 중앙값에 해당하는 빈 인덱스 정수입니다. 잘못된 채널 또는 닫힌 히스토그램은 오류이며 정수 결과 자체에는 별도 해제가 필요하지 않습니다.

낮은 중앙 빈 인덱스

지정 채널에서 낮은 중앙값에 해당하는 빈 인덱스를 계산합니다. channel은 0 기반이고 기본 0입니다. 반환 정수는 픽셀 밝기 자체가 아니라 히스토그램의 빈 위치입니다.

범위와 선택

짝수 개 표본에서는 낮은 쪽 중앙 정의가 중요합니다. 빈 수와 lower·upper 범위를 함께 보아야 해당 인덱스의 값 구간을 해석할 수 있습니다. 존재하지 않는 채널은 오류이며 care 마스크가 집계 대상을 정합니다.
