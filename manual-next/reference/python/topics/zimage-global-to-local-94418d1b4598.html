global_to_local

method · 선언 타입 zvision.ZImage

Python
global_to_local(self, point)

전역 좌표에서 ROI 원점을 빼 로컬 좌표로 변환합니다.

확인된 인자 조건

point: 변환할 Point2

반환: 변환된 Point2입니다.

오류: 닫힌 영상 또는 유효하지 않은 좌표는 오류입니다.

인자 선언

  • point · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

전역 좌표를 ROI 안으로

전역 픽셀 좌표에서 영상의 전역 원점을 빼 로컬 좌표를 얻습니다. 예를 들어 원점이 (100,200)이고 전역 점이 (110,220)이면 로컬 점은 (10,20)입니다. 이 계산은 원점 변환이며 픽셀 값을 바꾸지 않습니다.

범위와 보정

좌표 변환 결과가 영상 안에 있는지는 별도로 확인합니다. 영상 바깥 전역 점도 원점을 뺀 로컬 수치로 표현될 수 있으므로 좌표 변환을 자동 잘라내기로 취급하지 않습니다. 픽셀과 물리 단위 사이의 카메라 보정은 또 다른 변환입니다.
