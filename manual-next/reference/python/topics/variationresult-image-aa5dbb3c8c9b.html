일반 변동 검사 결과 영상을 취득합니다.

확인된 인자 조건

index: 0 잔차, 1 심각도, 2 결함 마스크

반환: 호출자가 close할 독립 ZImage입니다.

오류: 0–2 밖이면 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

Legacy 0.1.x indexed image acquisition; prefer named properties.

사용과 결과 판독

결과 영상 0은 잔차, 1은 심각도, 2는 결함 마스크입니다. 숫자 인덱스에 따라 데이터의 의미가 달라지므로 출력과 인덱스를 함께 기록하십시오. 획득 영상은 독립 소유이며 사용 후 닫습니다.
