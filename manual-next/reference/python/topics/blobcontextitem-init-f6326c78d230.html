BlobContextItem(label: int, area: int) -> None

Current result's label and binary pixel area.

label: 선택한 영역의 라벨입니다.

area: 선택한 영역의 전경 픽셀 수입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
label선택한 영역의 라벨입니다.필수
area선택한 영역의 전경 픽셀 수입니다.필수

값의 해석과 사용

label은 현재 결과의 영역 번호이고 area는 전경 픽셀 수입니다. 가운데가 빈 3×3 고리의 area는 8이지만 외접 상자의 넓이는 9입니다. 레이블을 프레임 간 영구 ID로 가정하지 않습니다.

현재 결과의 영역

label은 현재 결과의 선택 영역 레이블이고 area는 그 영역의 전경 픽셀 수입니다. 이 두 값은 현재 컨텍스트 계산에 속하며, label의 크기를 면적이나 다른 프레임의 물체 ID로 해석하지 않습니다.

항목의미와 사용
label현재 결과의 영역 레이블
area비영 전경 픽셀 수
고리 예3×3 중 가운데 배경이면 8
상자 넓이3×3=9; area와 다름
컨텍스트현재 결과 및 설정 상태 확인
프레임 비교별도의 객체 대응 규칙 필요

가운데만 배경인 3×3 고리는 area가 8이고 외접 상자 크기는 3×3입니다. 상자 넓이 9와 area가 다른 이유는 상자 안의 배경이 전경 픽셀 수에 포함되지 않기 때문입니다. 컨텍스트 설정을 변경했다면 현재 결과의 상태와 계산 세대를 함께 확인합니다.
