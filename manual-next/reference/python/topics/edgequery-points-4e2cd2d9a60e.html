points

method · 선언 타입 zvision._edge_query_result.EdgeQuery

Python
points(self, selector, by_label=False)

에지 점들을 순서대로 복사합니다.

확인된 인자 조건

selector: 포함 인덱스 또는 레이블입니다.

by_label: True면 레이블로 선택합니다. 기본값은 False입니다.

반환: 독립 Point2 튜플입니다.

오류: 선택 오류나 복사 개수 제한 초과 시 오류입니다.

인자 선언

  • selector · POSITIONAL_OR_KEYWORD · 기본값 없음
  • by_label · POSITIONAL_OR_KEYWORD · 기본값 False

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Copy ordered edge points; the returned tuple is independently owned.

이 호출의 입력과 객체 맥락

현재 포함된 에지 하나의 점들을 순서대로 복사합니다. 기본 selector는 0 기반 포함 인덱스이고 레이블 선택이 참이면 안정된 레이블입니다. 예를 들어 중간 에지를 제외하면 조밀 인덱스는 바뀔 수 있으나 재포함 가능한 레이블은 유지됩니다. 반환 점 값은 독립 복사이며 에지 순서와 메타데이터를 함께 사용하세요.
