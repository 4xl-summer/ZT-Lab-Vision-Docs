python 공개 선언
GridWarpSpec(rows: int, columns: int, width: int, height: int, grid_pitch_x: float, grid_pitch_y: float, origin_x: float, origin_y: float, output_pitch_x: float, output_pitch_y: float, angle: float = 0.0) -> None

Metric lattice and rotated destination sampling grid.

rows: 격자 노드의 행 수로 2 이상입니다.

columns: 격자 노드의 열 수로 2 이상입니다.

width: 출력 영상 너비이며 픽셀 수로 양수입니다.

height: 출력 영상 높이이며 픽셀 수로 양수입니다.

grid_pitch_x: 원래 격자의 X 방향 물리 간격이며 유한 양수입니다.

grid_pitch_y: 원래 격자의 Y 방향 물리 간격이며 유한 양수입니다.

origin_x: 출력 격자 원점의 X 위치이며 격자의 물리 좌표 단위입니다.

origin_y: 출력 격자 원점의 Y 위치이며 격자의 물리 좌표 단위입니다.

output_pitch_x: 출력 픽셀의 X 방향 물리 간격이며 유한 양수입니다.

output_pitch_y: 출력 픽셀의 Y 방향 물리 간격이며 유한 양수입니다.

angle: 출력 격자의 회전각이며 라디안 단위의 유한수입니다.

이 호출의 입력과 객체 맥락

입력 노드의 행·열, 원래 격자 간격, 출력 폭·높이와 출력 물리 원점·간격·회전을 정의합니다. 입력 노드는 최소 2×2이고 두 출력 픽셀 간격은 유한 양수입니다. 예를 들어 output_pitch_x=0.5면 출력 이웃 픽셀의 물리 x 간격은 0.5입니다. 원본 및 출력 간격의 단위는 호출자가 일치시켜야 하며 별도 단위 변환이 자동으로 적용되지 않습니다.
