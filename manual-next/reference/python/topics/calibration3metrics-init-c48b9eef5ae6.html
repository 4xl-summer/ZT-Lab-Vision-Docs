Calibration3Metrics(count: int, mean_error: float, rms_error: float, max_error: float)

count: 평가에 사용한 점 대응 쌍의 개수입니다.

mean_error: 대응점 유클리드 거리의 평균이며 변환 길이 단위입니다.

rms_error: 대응점 유클리드 거리의 RMS이며 변환 길이 단위입니다.

max_error: 대응점 유클리드 거리의 최대값이며 변환 길이 단위입니다.

생성과 결과 판독

3차원 거리 평가의 개수, 평균 오차, RMS와 최대 오차를 보관합니다. 거리 잔차 두 값이 0과 2라면 평균은 1, RMS는 √2, 최대는 2입니다. 집계값과 개별 관측은 다르므로 가장 큰 오차가 어디서 생겼는지도 별도로 살펴야 합니다. 지표의 단위는 입력 좌표의 길이 단위를 따릅니다.

단계별 확인

각 대응점의 3차원 거리 오차를 요약하는 네 값입니다. 평균은 거리의 합을 개수로 나누고 RMS는 거리 제곱의 평균에 제곱근을 적용합니다. 최대값은 개별 점 중 가장 큰 거리입니다.

예를 들어 잔차가 0과 2인 두 점이면 평균은 1, RMS는 √2, 최대는 2입니다. 평균과 RMS가 달라도 서로 모순이 아닙니다. 지표는 변환의 길이 단위를 따르므로 허용치와 비교하기 전에 단위를 맞추십시오.

항목확인할 내용

mean_error점별 거리의 산술 평균입니다.
rms_error거리 제곱 평균의 제곱근입니다.
max_error평가된 거리 중 최댓값입니다.
예시오차 0과 2의 평균 1, RMS √2, 최대 2입니다.
개별 점집계만으로 어느 점이 문제인지 알 수 없습니다.
