CloudInfo(count: int, valid_count: int, unit: zvision._calibration.LengthUnit, frame: int)

count: 결측을 포함한 전체 점 슬롯 수입니다.

valid_count: 유효 슬롯 수입니다.

unit: 위치와 거리의 길이 단위입니다.

frame: 0이 아닌 좌표계 ID입니다.

점군 정보

점군의 정보 값은 슬롯 수와 단위, 좌표계 등 점 배열을 해석하는 데 필요한 메타데이터를 나타냅니다. 유효한 점의 수는 슬롯 전체의 수와 다를 수 있으므로 결측이 있는 입력에서 둘을 혼동하지 않습니다. 이 정보 값을 구성하는 일은 실제 점 저장소를 생성하는 것과 별개입니다.

예를 들어 네 슬롯 가운데 하나가 결측이면 배열 길이는 4이고 실제 좌표를 가진 점은 3개입니다. 같은 인덱스를 결과 배열에 유지하는 처리에서는 빠진 위치를 제거하지 않고 결측으로 남길 수 있습니다. 결과를 사용하기 전 원본 점군의 frame과 단위를 확인합니다.
