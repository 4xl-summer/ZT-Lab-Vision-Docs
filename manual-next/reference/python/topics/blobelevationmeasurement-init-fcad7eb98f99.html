BlobElevationMeasurement(label: int, count: int, min: float, max: float, mean: float, size_z: float) -> None

Label and finite elevation minimum, maximum, mean and Z range.

label: 원본 Blob 라벨.

count: 유효 측정 픽셀 수.

min: 최소 고도; 입력 깊이 단위.

max: 최대 고도; 입력 깊이 단위.

mean: 평균 고도; 입력 깊이 단위.

size_z: 최대 고도와 최소 고도의 차이.

계산과 결과 해석

연결 성분에 대응하는 유한한 높이 값의 개수와 최솟값, 최댓값, 평균 및 높이 범위를 담습니다. label은 성분 식별자이고 count는 해당 통계에 포함된 높이 값의 수입니다. min과 max는 관측된 높이의 양 끝이며 size_z는 그 차이입니다. 예를 들어 세 높이가 2, 4, 6이면 최솟값은 2, 최댓값은 6, 평균은 4이고 범위는 4입니다. 이 수치는 입력 높이 자료의 단위를 따르므로 자동으로 밀리미터라고 가정하지 마십시오. 같은 label 번호만 보고 서로 다른 프레임에서 같은 물체라고 판단할 수 없으며 영상상의 위치와 객체 대응을 따로 관리해야 합니다. 유한한 값이 어느 위치에서 포함됐는지는 집계 수치만으로 복원할 수 없으므로 검토에 필요한 원본 입력과 유효성 정보를 보관합니다. 높이 범위가 0인 경우는 값이 모두 같을 때도 생기며 대상이 없거나 계산에 실패한 상태와 다릅니다. 결과가 반환된 상태와 실제 픽셀 수를 확인한 다음 값을 사용하십시오. 조명 영상의 밝기 통계와 높이 통계도 서로 다른 물리량이므로 숫자를 직접 비교해서는 안 됩니다. 같은 높이 단위의 기준값과 결과를 비교하고, 데이터의 단위가 바뀌면 허용 범위도 같이 변환하십시오. 최소와 최대가 같은 것은 정상적인 일정 높이일 수 있습니다.
