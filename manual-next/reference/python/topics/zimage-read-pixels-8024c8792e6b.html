read_pixels(self)

읽기 전용 행 뷰를 취득합니다.

반환: 읽기 전용 ImageReadView입니다. 뷰에서 내보낸 행은 소유 lease를 통해 뷰보다 오래 유지될 수 있습니다.

오류: 닫힌 핸들은 오류입니다.

Acquire an immutable, zero-copy view of the image rows.

픽셀 데이터 읽기

read_pixels는 영상의 픽셀 데이터를 읽는 경로입니다. 결과를 해석하려면 폭과 높이뿐 아니라 픽셀 형식, 채널 순서와 행 간격을 확인해야 합니다. 예를 들어 세 채널 영상의 픽셀 수와 바이트 수는 같은 단위가 아닙니다.

수명과 배치

ROI에서 읽는 범위와 원본 위치를 구분하고, 행 단위 간격이 폭과 다를 수 있다는 점을 고려합니다. 반환 데이터가 복사인지 빌린 뷰인지 해당 시그니처의 계약을 따르고, 영상이 닫힌 뒤의 접근을 임의로 보장하지 않습니다.

행 단위 읽기

영상 폭은 픽셀 수이고 행 간격은 바이트 수입니다. 세 채널 형식에서는 한 픽셀에 여러 성분이 있으므로 폭과 바이트 길이가 같지 않습니다. ROI의 행을 읽을 때 픽셀 형식과 성분 순서도 확인합니다.
