ZImage.white_balance 공개 계약

상위 목차로 돌아가기

white_balance

method · 선언 타입 zvision.ZImage

Python
white_balance(self, gains)

색상 화이트 밸런스를 적용합니다.

확인된 인자 조건

gains: 세 채널 게인

반환: 별도 소유 ZImage이며 close 또는 with로 해제합니다.

오류: 입력이나 인자가 유효하지 않으면 오류입니다.

인자 선언

  • gains · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

채널별 게인

화이트 밸런스는 색상 영상의 세 채널에 지정한 gains를 적용합니다. 채널 순서를 혼동하면 다른 색 성분에 배율이 적용됩니다. 기본적으로 세 게인의 의미와 입력 RGB 또는 BGR 인코딩을 함께 확인해야 합니다.

비교와 범위

중립 색 표본이나 색이 알려진 입력을 사용해 보정 전후를 비교합니다. 큰 게인은 출력 표현의 범위에 영향을 줄 수 있으므로 입력 및 출력 형식의 계약을 확인합니다. 반환 ZImage는 별도 소유 객체이며 필요가 끝나면 닫습니다.
