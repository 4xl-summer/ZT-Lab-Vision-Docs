edge_quality

method · 선언 타입 zvision._multi_registration.MultiRegistration

Python
edge_quality(self, index)

선택 에지의 등록 품질을 조회합니다.

확인된 인자 조건

index: 0부터 시작하는 에지 인덱스입니다.

반환: RegistrationEdgeQuality 값이며 평가되지 않은 고정 에지는 None입니다.

오류: 범위 밖 인덱스나 닫힌 결과는 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Return measured quality, or None when an edge was fixed without evaluation.

이 호출의 입력과 객체 맥락

0 기반 등록 에지 index의 품질 스냅샷을 읽습니다. 평가되지 않은 고정 에지는 None이므로 점수 0과 구분해야 합니다. edge_optimized로 해당 방향 에지의 최적화 여부를 따로 확인하고, 영상 매핑이 필요하면 이미지 인덱스를 사용하는 info를 사용합니다.
