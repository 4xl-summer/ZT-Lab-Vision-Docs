FontCell(line: int, cell: tuple)

line: 검출 셀이 속한 줄의 인덱스입니다.

cell: 검출 셀의 로컬 (x,y,width,height) 픽셀 영역입니다.

이 호출의 입력과 객체 맥락

분할된 문자 후보의 줄 번호 line과 사각형 cell을 담는 불변 값입니다. cell은 (x, y, width, height) 정수 튜플로, 실제로 읽어 낸 문자 라벨이나 템플릿 점수를 포함하지 않습니다. segment_font_image의 분할 결과를 확인할 때 영역의 경계를 살펴보는 데 사용합니다.

예를 들어 붙어 있는 두 문자가 하나의 셀로 나오면 문자 인식 이전의 분할 설정을 점검해야 합니다. 반대로 하나의 문자가 여러 셀로 나뉘면 폭·높이 조건, 임계값과 붙은 글자 분리 설정을 해당 영상과 함께 비교합니다. 줄 번호도 문장 순서 해석에 필요합니다.

사용 순서와 결과 확인

FontCell은 문자 후보가 속한 줄 인덱스와 검출 셀의 로컬 사각형을 묶습니다. cell은 (x,y,width,height)이며 인식된 문자 레이블이나 템플릿 점수를 직접 담지 않습니다. 분할 결과의 위치를 먼저 확인한 다음 문자 인식 결과와 연결해야 합니다.

예를 들어 셀이 (10,20,8,12)라면 로컬 시작점은 (10,20), 폭은 8, 높이는 12픽셀입니다. x와 y는 우하단 좌표가 아니며 영상 전체의 글로벌 좌표도 아닙니다. ROI 원점이 있으면 표시 목적에 맞게 기준을 복원해야 합니다.

두 문자가 붙어 하나의 셀로 검출되거나 한 문자가 여러 셀로 나뉜다면 인식 점수만 바꾸기보다 먼저 분할 설정과 해당 영상의 셀 경계를 살펴보십시오. line은 줄을 구별하는 인덱스이므로 여러 줄의 순서 해석에도 사용합니다.

단계 또는 항목확인할 내용
line검출 셀이 속한 줄의 인덱스입니다.
cell.x, cell.y영상 로컬 사각형의 시작 위치입니다.
width셀의 가로 크기(픽셀)입니다.
height셀의 세로 크기(픽셀)입니다.
분할 결과문자 레이블이나 인식 점수 자체는 아닙니다.
ROI다른 좌표계에 표시할 때 원점을 확인합니다.
