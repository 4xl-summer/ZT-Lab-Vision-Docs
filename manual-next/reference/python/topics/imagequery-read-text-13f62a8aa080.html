계획 영상의 문자 판독

앞선 이미지 처리 결과에서 문자를 판독하는 분석을 지정합니다. 전처리와 ROI가 달라지면 판독에 전달되는 영상도 달라집니다. 모델과 판독 옵션의 입력 조건 및 지원 범위는 해당 호출 계약을 확인합니다.

결과 검토

실행 후 판독 결과의 텍스트와 위치, 상태 등 실제 반환 필드를 함께 살펴봅니다. 문자열만으로 영상의 잘림이나 잘못된 영역 선택을 구별할 수 없으므로 원본과 처리 결과를 나란히 확인하고 해당 결과 객체의 수명을 관리합니다.
