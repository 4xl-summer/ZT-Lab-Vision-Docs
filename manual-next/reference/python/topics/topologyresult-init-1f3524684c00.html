TopologyResult.__init__

python 공개 선언
TopologyResult(topology: 'RegionTopology') -> None

Independent topology snapshot.

topology: 전경 성분 수, 구멍 수와 오일러 수를 가진 독립 RegionTopology 값입니다.

이 호출의 입력과 객체 맥락

topology.holes: 외곽 배경에 연결되지 않은 구멍 수입니다.

topology.euler: 전경 성분 수에서 구멍 수를 뺀 값입니다.

사용 순서와 판독

RegionTopology는 전경 성분과 외부 배경에 연결되지 않은 구멍을 셉니다. Euler 수는 성분 수에서 구멍 수를 뺀 값이므로 두 원본 수를 함께 살펴야 같은 Euler 값을 가진 서로 다른 형상을 구별할 수 있습니다.

예를 들어 성분 1개에 구멍 1개면 Euler는 0이고, 성분 2개에 구멍 2개여도 0입니다. 숫자 하나만 보고 두 마스크의 구조가 같다고 판단하지 마세요. 결과는 값 스냅샷이어서 이를 얻은 실행의 캡처 영상과 수명이 다릅니다.

연결성 선택은 어떤 전경 픽셀을 같은 성분으로 셀지에 영향을 주므로 위상 결과를 비교할 때 사용한 연결 조건도 함께 기록하세요. 경계에서 바깥 배경과 연결된 영역을 내부 구멍으로 세는지 여부가 결과 해석을 바꾸므로 holes의 정의를 기준으로 확인해야 합니다. Euler 값이 같더라도 components와 holes의 조합을 별도로 비교하는 것이 유용합니다.

항목확인할 내용
components전경 연결 성분 수
holes외곽 배경과 연결되지 않은 구멍 수
eulercomponents − holes
