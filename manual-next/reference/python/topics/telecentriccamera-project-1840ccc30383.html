Python
project(self, point)

카메라 프레임 점의 XY를 축 정렬 직교 투영합니다.

확인된 인자 조건

point: 카메라 프레임의 유한한 Point3입니다.

반환: 전역 픽셀 좌표 Point2 값입니다.

오류: 유효하지 않은 카메라 또는 좌표는 오류입니다.

인자 선언

  • point · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

카메라 좌표 점 (x, y, z)을 글로벌 픽셀 (cx+sx×x, cy+sy×y)로 보냅니다. 예를 들어 중심이 (100, 200), 두 배율이 2 픽셀/길이면 (3, 4, z)는 (106, 208)입니다. z가 달라도 같은 x/y는 같은 픽셀로 투영되므로 픽셀만으로 깊이를 복원할 수 없습니다. 세계 점이라면 먼저 올바른 포즈로 카메라 좌표에 맞추세요.

이 객체의 확인된 공개 생성 경로: TelecentricCamera(sx: float, sy: float, cx: float, cy: float, unit: zvision._calibration.LengthUnit, camera_frame: int) -> None.
