otsu_threshold

method · 선언 타입 zvision.ZImage

Python
otsu_threshold(self, bin_count: int, lower: float, upper: float) -> float

회색 영상의 Otsu 임계값을 계산합니다.

확인된 인자 조건

bin_count: 히스토그램 빈 수

lower: 유한 하한

upper: 하한보다 큰 유한 상한

반환: 계산한 스칼라 임계값입니다.

오류: 유효하지 않은 히스토그램 범위 또는 형식은 오류입니다.

인자 선언

  • bin_count · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • lower · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • upper · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음

반환 타입 주석: <class 'float'>

Return the Otsu threshold for a grayscale image.

히스토그램에서 임계값 선택

Otsu 방식은 입력 밝기 분포를 이용해 두 부류를 나누는 임계값을 선택합니다. 영상 전체의 분포가 바뀌면 같은 물체에도 선택값이 달라질 수 있으므로 촬영 조건과 ROI를 함께 고려합니다. 명시한 고정 임계값과 자동 선택 임계값은 같은 설정이 아닙니다.

결과 확인

반환 형태와 영상 또는 수치의 소유권은 선언을 따릅니다. 조명이 불균일하거나 한 부류가 매우 적은 영상에서는 선택된 경계가 원하는 물체 분할과 일치하는지 마스크를 원본에 겹쳐 확인합니다. 자동 선택 결과도 실제 검사 기준으로 검증해야 합니다.
