python 공개 선언
RadialSelfResult(k1: float, cx: float, cy: float, initial_rms: float, final_rms: float, iterations: int, accepted_steps: int, converged: bool, stalled: bool, exhausted: bool) -> None

Estimated k1 and pixel center, normalized residual RMS, and termination state.

k1: 추정된 반경 왜곡 계수입니다.

cx: 추정된 주점 중심 X 좌표이며 픽셀 단위입니다.

cy: 추정된 주점 중심 Y 좌표이며 픽셀 단위입니다.

initial_rms: 초기 점-직선 거리의 RMS이며 정규화 좌표 단위입니다.

final_rms: 최종 점-직선 거리의 RMS이며 정규화 좌표 단위입니다.

iterations: 실행한 최적화 반복 횟수입니다.

accepted_steps: 개선을 받아들인 갱신 횟수입니다.

converged: 국소 최적화의 수렴 여부입니다.

stalled: 개선 없이 멈췄는지 나타냅니다.

exhausted: 반복 예산 소진 여부입니다.

이 호출의 입력과 객체 맥락

추정 반경 왜곡 k1과 픽셀 주점 cx/cy, 전후 점-직선 RMS 및 최적화 상태를 담습니다. RMS는 정규화 좌표 단위이고 주점은 픽셀이므로 같은 단위로 비교하지 않습니다. accepted_steps는 개선을 받아들인 횟수이며 converged, stalled, exhausted는 서로 다른 종료 상태입니다. 이 수치만으로 실제 장비 보정 인수를 뜻하지는 않습니다.
