set(self, camera, target, pose, object_points, pixels)

대응점 관측을 삽입하거나 같은 키를 교체합니다.

확인된 인자 조건

camera: 카메라 ID.

target: 타깃 ID.

pose: 포즈 ID.

object_points: 1–4096개의 객체 평면 Point2.

pixels: 같은 개수의 픽셀 Point2.

반환: None.

오류: 키·점 타입, 대응점 개수 또는 닫힌 세션이 유효하지 않으면 오류.

인자 선언

  • camera · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • object_points · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Atomically insert or replace one observation of up to 4096 pairs.

사용과 결과 판독

카메라·표적·자세의 세 ID를 키로 대응점 관측을 추가하거나 기존 키를 원자적으로 교체합니다. object와 pixels의 같은 인덱스가 같은 표적점을 가리켜야 하며 입력 순서를 보존해야 합니다. 한쪽 배열만 정렬하면 유효한 수치라도 잘못된 짝이 됩니다. 덮어쓰기가 의도된 키인지 확인하고 닫힌 세션에 사용하지 마십시오.
