train_shape

classmethod · 선언 타입 zvision._matching.MatchModel

Python
train_shape(cls, template, min_gradient, mask=None)

템플릿의 기울기 방향으로 기본 형상 모델을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 ZImage입니다.

min_gradient: 원시 밝기/픽셀 단위의 유한한 양의 기울기 하한입니다.

mask: 같은 크기·원점의 선택 Gray8 마스크입니다.

반환: 호출자가 닫아야 하는 독립 모델입니다.

오류: 3×3 미만, 특징점 3개 미만 또는 잘못된 설정은 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_gradient · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

min_gradient: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

템플릿의 기울기 방향으로 기본 형상 모델을 학습합니다. min_gradient는 원시 밝기/픽셀 단위의 유한한 양의 기울기 하한이며, 선택 마스크는 템플릿과 같은 크기와 원점을 사용합니다.

같은 템플릿이라도 하한에 따라 모델에 들어가는 특징이 달라집니다. 너무 높은 기준으로 유용한 경계를 제외하지 않았는지 모델 정보를 살피고 같은 검색 조건에서 결과를 비교합니다. 생성된 모델은 호출자가 닫습니다.

입력 선택을 위한 확인

입력의미와 조건
templateGray8, Gray16 또는 유한 GrayF32 ZImage입니다.
min_gradient원시 밝기/픽셀 단위의 유한한 양의 기울기 하한입니다.
mask같은 크기·원점의 선택 Gray8 마스크입니다.

반환값 확인
