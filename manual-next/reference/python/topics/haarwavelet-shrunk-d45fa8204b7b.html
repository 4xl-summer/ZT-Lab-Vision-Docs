shrunk

method · 선언 타입 zvision._wavelet_inpaint_gap.HaarWavelet

Python
shrunk(self, threshold, mode=<WaveletShrink.SOFT: 1>)

세부 계수를 임계화하고 LL 계수는 유지합니다.

확인된 인자 조건

threshold: 유한한 0 이상의 임계치.

mode: 축소 방식; 기본값은 SOFT.

반환: 호출자가 close할 새 변환 객체입니다.

오류: 닫힌 객체, 잘못된 계수 또는 옵션은 오류입니다.

인자 선언

  • threshold · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mode · POSITIONAL_OR_KEYWORD · 기본값 <WaveletShrink.SOFT: 1>

threshold: 유한한 수 검사.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Return a new model with thresholded detail coefficients and unchanged LL.

이 호출의 입력과 객체 맥락

0 이상의 유한 threshold와 hard 또는 soft 방식을 선택해 세부 계수를 축소한 독립 모델을 만듭니다. 최종 LL은 보존됩니다. 원본의 계수를 제자리에서 덮어쓰는 작업이 아니므로 원본과 새 모델을 각각 inverse로 복원해 비교할 수 있습니다. 모델 두 개와 반환 영상은 각각 close합니다.
