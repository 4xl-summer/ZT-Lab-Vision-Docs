ZImage.load 공개 계약

상위 목차로 돌아가기

load

classmethod · 선언 타입 zvision.ZImage

Python
load(cls, path)

경로에서 영상 코덱으로 영상을 읽습니다.

확인된 인자 조건

path: 읽을 파일 경로

반환: 별도로 close할 ZImage입니다.

오류: 경로가 유효하지 않거나 디코딩이 실패하면 오류입니다.

인자 선언

  • path · POSITIONAL_OR_KEYWORD · 기본값 없음

Load an image from a filesystem path using the native codecs.

파일에서 영상 읽기

load는 파일의 영상 데이터를 읽어 ZImage를 만듭니다. 파일 경로와 실제 내용이 올바른지, 결과의 크기와 픽셀 형식이 후속 처리에 지원되는지 확인해야 합니다. 파일 이름만으로 실제 픽셀 배치와 값 범위를 단정하지 않습니다.

실패와 수명

파일이 없거나 읽기 또는 디코딩이 실패하면 영상이 생성되지 않을 수 있으므로 오류를 처리합니다. 성공한 반환 영상은 사용 후 close 또는 with로 해제합니다. ROI나 색상 채널을 분석하기 전에 읽은 결과의 정보를 확인합니다.
