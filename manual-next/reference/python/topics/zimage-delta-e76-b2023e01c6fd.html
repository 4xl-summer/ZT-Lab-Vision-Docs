delta_e76

method · 선언 타입 zvision.ZImage

Python
delta_e76(self, target)

색상 기준 Lab 색과의 CIE76 거리를 계산합니다.

확인된 인자 조건

target: 기준 LabColor

반환: 별도 소유 ZImage이며 close 또는 with로 해제합니다.

오류: 입력이나 인자가 유효하지 않으면 오류입니다.

인자 선언

  • target · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

Lab 색 차이

CIE76은 각 픽셀의 Lab 색과 기준 LabColor 사이의 유클리드 거리입니다. 두 색의 차이가 ΔL=3, Δa=4, Δb=0이면 거리는 √(3²+4²)=5입니다. 이는 Lab 좌표상의 계산값이며 이미지 밝기 차이를 직접 빼는 것과 다릅니다.

기준과 결과

target은 기준 LabColor입니다. 입력 색 변환의 기준과 픽셀 형식을 확인하고 결과 영상을 같은 좌표에서 읽습니다. 결과 ZImage는 별도 소유 핸들이므로 사용 후 닫습니다. 거리 하나만으로 모든 지각 차이나 실제 조명 조건의 영향을 보장하지 않습니다.
