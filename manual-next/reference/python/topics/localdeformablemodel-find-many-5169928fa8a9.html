find_many(self, source, options, mask=None, *, max_deformation_rate=None, photometric=False, robust=None)

서로 다른 거친 포즈를 각각 국소 정밀화합니다.

확인된 인자 조건

source: 검색 ZImage입니다.

options: LocalDeformableOptions입니다.

mask: 선택 검색 마스크이며 기본값 None입니다.

max_deformation_rate: 선택적 유한 비음수 인접 변위율 한계입니다.

photometric: 밝기 gain/bias 보정 여부이며 기본값 False입니다.

robust: 선택적 LocalDeformableRobustOptions입니다.

반환: 복사된 여러 결과와 단계별 진단을 담은 LocalDeformableManyReport입니다.

오류: robust와 photometric은 함께 사용할 수 없으며 잘못된 입력·예산은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None
  • max_deformation_rate · KEYWORD_ONLY · 기본값 None
  • photometric · KEYWORD_ONLY · 기본값 False
  • robust · KEYWORD_ONLY · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Independently refine distinct coarse poses; results are detached snapshots.

이 호출의 입력과 객체 맥락

서로 다른 거친 포즈 후보를 각각 지역 정밀화하여 여러 결과와 단계별 진단을 복사한 보고서를 반환합니다. 검색 마스크, 밝기 보정, 강건 설정과 인접 변위율 한계를 선택할 수 있습니다. 각 후보의 결과와 거친 종료 이유를 따로 읽고, 단일 find의 결과 하나와 보고서 전체를 혼동하지 마세요.
