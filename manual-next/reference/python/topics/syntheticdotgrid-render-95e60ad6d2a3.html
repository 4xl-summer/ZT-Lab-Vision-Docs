render(cls, grid, lens, target_to_camera, width, height, radius)

물리 격자를 카메라에 투영한 합성 점 영상과 중심 좌표를 만듭니다.

확인된 인자 조건

grid: MetricGrid 값입니다.

lens: 투영 LensModel입니다.

target_to_camera: 타깃에서 카메라로의 RigidTransform3입니다.

width: 양의 출력 너비 픽셀 수입니다.

height: 양의 출력 높이 픽셀 수입니다.

radius: 1–32 픽셀 점 반경입니다.

반환: 호출자가 닫아야 하는 SyntheticDotGrid입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • grid · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_to_camera · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Render fixed-pixel-radius markers; this is not a physical disc projection.

이 호출의 입력과 객체 맥락

물리 MetricGrid를 target_to_camera 포즈와 렌즈 모델로 투영해 합성 도트 영상과 중심 좌표를 만듭니다. 출력 width와 height는 양의 픽셀 수, radius는 1~32 픽셀입니다. 렌즈와 포즈의 좌표 프레임·길이 단위를 격자와 맞추세요. 결과는 합성 데이터이며 실제 카메라 촬영 정확도의 검증을 뜻하지 않습니다. 소유 결과와 별도로 얻은 영상은 각각 close합니다.
