general_dft

method · 선언 타입 zvision.ZImage

Python
general_dft(self, width, height, normalization=<FftNormalization.BACKWARD: 0>)

임의 크기의 제한된 일반 DFT를 계산합니다.

확인된 인자 조건

width: 양의 변환 폭; 변환 크기는 입력 이상

height: 양의 변환 높이; 폭×높이 ≤ 1,048,576, 폭×높이×(폭+높이) ≤ 25,000,000

normalization: 정규화 방식, 기본값 BACKWARD

반환: 별도로 close할 GeneralSpectrum입니다.

오류: 크기 또는 작업량 한도를 초과하면 오류입니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • normalization · POSITIONAL_OR_KEYWORD · 기본값 <FftNormalization.BACKWARD: 0>

Return an independently owned bounded arbitrary-size DFT spectrum.

일반 이산 푸리에 변환

DFT는 각 주파수 위치에서 입력의 복소 기여를 합산합니다. 직류 성분은 변환 배율을 적용하기 전 입력의 합으로 해석할 수 있습니다. 상수 1로 채운 2×2 입력의 합은 4이며 정규화에 따라 표시되는 직류 크기는 달라질 수 있습니다.

복소 결과와 제한

정변환과 역변환의 크기 및 정규화를 일치시키고 실수부와 허수부를 함께 보관합니다. 스펙트럼을 진폭으로 표시하면 위상 정보는 그 그림에 남지 않습니다. 지원 크기와 계산량 제한은 호출의 공개 계약을 확인하며 작은 입력으로 먼저 검증합니다.
