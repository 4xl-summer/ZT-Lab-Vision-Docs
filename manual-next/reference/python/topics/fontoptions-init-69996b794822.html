FontOptions(allowed_chars: str, threshold: int = 127, light_text: bool = False, closing_radius: int = 0, min_width: int = 1, max_width: int = 4096, min_height: int = 1, max_height: int = 4096, split_touching: bool = False, min_glyph_score: float = 0.0, min_string_score: float = 0.0, position_chars: tuple = ())

allowed_chars: 인식에서 허용할 비어 있지 않은 문자 집합입니다.

threshold: 이진화 문턱값으로 0~255입니다. 지정값도 전경 판정에 포함합니다.

light_text: True면 문턱값 이상의 밝은 픽셀을 글자로 취급합니다.

closing_radius: 정사각형 닫기 반경(픽셀)입니다. 0이면 사용하지 않고 최대 8입니다.

min_width: 허용하는 글자 영역의 최소 너비(픽셀)로 1 이상입니다.

max_width: 허용하는 글자 영역의 최대 너비(픽셀)이며 최소 너비 이상입니다.

min_height: 허용하는 글자 영역의 최소 높이(픽셀)로 1 이상입니다.

max_height: 허용하는 글자 영역의 최대 높이(픽셀)이며 최소 높이 이상입니다.

split_touching: 너비가 큰 연결 요소를 내부의 가장 빈 열에서 나눌지 정합니다.

min_glyph_score: 개별 글자 유사도의 수락 하한으로 0~1입니다.

min_string_score: 문자열 유사도의 수락 하한으로 0~1입니다.

position_chars: 문자 위치별 허용 집합입니다. 빈 튜플은 위치 제한을 끕니다.

이 호출의 입력과 객체 맥락

허용 문자와 전경 이진화, 연결 요소 크기 및 문자·문자열 수락 점수를 지정합니다. threshold는 0~255이고 light_text는 문턱값 이상을 밝은 글자로 볼지 정합니다. closing_radius=0은 닫기를 사용하지 않으며 split_touching은 넓은 연결 요소를 가장 빈 내부 열에서 나눕니다. position_chars가 빈 튜플이면 위치별 문자 제한을 끕니다. 분할 셀을 확인한 뒤 인식 점수와 문자열 점수를 각각 해석하세요.
