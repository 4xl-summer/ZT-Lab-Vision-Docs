python 공개 선언
ShiftResult(image, valid_mask)

이동 영상과 유효 마스크를 함께 보유하는 결과입니다. 일반적으로 ZImage.shift()로 취득하고 close() 또는 with로 두 영상을 함께 닫습니다.

image: 이동된 ZImage 핸들입니다. 결과를 닫을 때 이 핸들도 닫힙니다.

valid_mask: 유효성 Gray8 ZImage 핸들입니다. 결과를 닫을 때 이 핸들도 닫힙니다.

이 호출의 입력과 객체 맥락

ShiftResult는 영상 이동의 출력 영상과 유효 마스크를 함께 보유하는 결과입니다. 보통 직접 두 핸들을 조립하기보다 열린 ZImage의 shift 호출을 통해 얻습니다. 이동 결과에는 원본에서 대응하는 픽셀이 없는 위치가 생길 수 있으므로 image만 읽지 말고 valid_mask도 같이 확인해야 합니다. 이 마스크는 어느 출력 위치를 유효한 입력에 연결할 수 있는지 해석하는 데 쓰입니다.

예를 들어 한 행 [0,10,20]을 오른쪽으로 한 픽셀 이동하면 결과 영상은 [0,0,10], 유효 마스크는 [0,255,255]입니다. 앞의 0은 경계로 채워진 위치이고 둘째 0은 실제 원본 값에서 왔다는 점을 마스크가 구별합니다. ShiftResult.close()는 image와 valid_mask를 모두 닫으므로 각각을 같은 핸들로 다시 사용하지 않습니다. 이후에도 필요한 픽셀은 결과가 열린 동안 복사하거나 별도 소유권 계약을 확인하세요.

두 영상의 소유 관계

ShiftResult는 이동된 image와 valid_mask를 함께 가진 소유 결과입니다. 공개 생성자에 두 핸들을 직접 전달할 수 있지만 일반적인 경로는 ZImage.shift(dx,dy)입니다. shift의 dx와 dy는 정수 픽셀 이동량이며 반환 결과의 두 영상은 같은 출력 위치를 기준으로 해석합니다.

valid_mask의 255는 입력에 대응하는 위치이고 0은 대응하지 않아 경계로 채워진 위치를 구분합니다. 예를 들어 원본 [0,10,20]을 오른쪽으로 한 칸 이동한 결과 [0,0,10]에서 마스크 [0,255,255]는 첫 0이 경계, 둘째 0이 실제 입력임을 보여 줍니다. 값이 같아도 출처가 다릅니다.

close는 image를 닫고 이어 valid_mask도 닫습니다. with 블록을 사용하면 블록을 나갈 때 같은 정리가 수행됩니다. 결과가 닫힌 뒤 동일 핸들을 다시 사용하지 말고 이후에도 필요한 픽셀 값은 열린 동안 복사하거나 지원되는 별도 소유 공유를 확보합니다.

유효 마스크가 필요한 이유는 채움값과 입력의 실제 값이 같을 수 있기 때문입니다. 출력의 검은 픽셀이 원본의 검은 픽셀인지 이동으로 비어 채워진 자리인지 영상 값 하나만으로는 알 수 없습니다. 후속 통계나 비교에 경계 채움을 포함할지 결정할 때 마스크를 사용합니다.
