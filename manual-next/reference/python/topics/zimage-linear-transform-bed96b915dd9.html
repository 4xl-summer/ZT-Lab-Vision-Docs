Python API · ZImage · linear_transform

ZImage.linear_transform 공개 계약

상위 목차로 돌아가기

linear_transform

method · 선언 타입 zvision.ZImage

Python
linear_transform(self, gain, bias)

각 픽셀에 gain과 bias를 적용합니다.

확인된 인자 조건

gain: 유한한 곱셈 계수

bias: 유한한 덧셈값

반환: 새 영상. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 유효하지 않은 값이나 형식은 오류입니다.

인자 선언

  • gain · POSITIONAL_OR_KEYWORD · 기본값 없음
  • bias · POSITIONAL_OR_KEYWORD · 기본값 없음

gain: 유한한 수 검사.

bias: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

선형 값 변환

선형 변환은 입력 값에 배율과 오프셋을 적용하는 방식으로 밝기 범위를 조정합니다. 예를 들어 실수 산술에서 배율 2와 오프셋 1을 적용하면 입력 3은 7이 됩니다. 실제 출력 형식의 범위 및 변환 규칙은 별도 계약을 확인해야 합니다.

설정과 판독

배율과 오프셋을 동시에 바꾸면 어느 값이 결과를 변화시켰는지 구분하기 어려우므로 작은 입력으로 각각 시험합니다. 출력 형식의 범위를 넘는 입력과 비유한 수의 처리도 선언된 조건에 따라 확인하고 원본은 별도로 보존합니다.
