find_matches(self, model, spec)

현재 영상 계획에 모델 매칭을 최종 연산으로 지정합니다.

확인된 인자 조건

model: 학습된 매칭 모델입니다.

spec: 포즈 격자 및 점수 설정입니다.

반환: 닫아야 하는 MatchQuery입니다. 모델 데이터를 계획이 공유합니다.

오류: 닫힌 객체, 지원하지 않는 입력 또는 실행 실패는 오류입니다.

인자 선언

  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출과 결과 확인

현재 영상 계획에 학습 모델과 MatchSpec을 연결해 MatchQuery를 만듭니다. 아직 매칭을 실행한 결과가 아니므로 execute를 호출한 뒤 스냅샷을 읽습니다. 회전·배율 격자와 점수, 중심 억제 거리 및 결과 수를 설정하고 결과 포즈를 영상 ROI와 기준점에 맞춰 해석합니다.
