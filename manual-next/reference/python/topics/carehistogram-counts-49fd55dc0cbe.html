채널별 빈 튜플

각 채널의 빈 개수를 튜플로 묶은 결과를 반환합니다. 바깥 튜플은 채널, 각 내부 튜플은 해당 채널의 빈입니다. 단일 채널이라도 채널 축과 빈 축을 구분합니다.

분포 해석

빈 값 3과 5는 각각의 밝기 구간에 들어간 표본 수가 3과 5임을 뜻합니다. 원본의 공간 위치는 보존하지 않으므로 같은 히스토그램이어도 영상의 물체 배치는 다를 수 있습니다. 범위와 마스크를 함께 확인합니다.

선택된 표본을 빈으로 읽기

이 결과는 채널별 빈 개수의 튜플입니다. 바깥 튜플에서 채널을 선택하고 그 안에서 빈 인덱스를 읽습니다. 예를 들어 첫 채널의 빈 개수가 (2, 7, 3)이면 세 구간의 표본 수가 각각 2, 7, 3입니다. 최빈 빈 인덱스는 1이지만 숫자 1 자체가 밝기라는 뜻은 아닙니다.

항목판독할 내용
채널바깥 튜플의 축
빈선택 채널의 구간별 개수
값의 단위픽셀 수이며 원본 밝기 값이 아님
공간 위치히스토그램에는 보존되지 않음

빈의 해석에는 계산할 때 지정한 lower, upper, bins와 care 마스크가 필요합니다. 같은 1번 빈이라도 범위가 달라지면 해당하는 밝기 구간이 달라집니다. 마스크를 이동하거나 ROI를 바꾸면 집계된 표본이 달라지므로 분포를 비교할 때 입력 설정도 함께 저장합니다.
