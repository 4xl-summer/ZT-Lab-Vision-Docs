python 공개 선언
SsimOptions(radius: int, window: zvision._adaptive_inspection.SsimWindow, border: zvision._adaptive_inspection.SsimBorder, sigma: float, data_range: float, k1: float, k2: float, min_score: float, polarity: zvision._adaptive_inspection.SsimPolarity, max_work: int) -> None

국소 가중 SSIM의 창, 밝기 범위와 결함 판정 조건을 지정하는 값입니다.

radius: 창 반경(픽셀), 0–1024. 창의 한 변은 2 × radius + 1입니다.

window: BOX는 균일 가중, GAUSSIAN은 Gaussian 가중입니다.

border: CLIP은 경계 밖을 제외하고 REPLICATE는 가장자리 픽셀을 복제합니다.

sigma: Gaussian 표준편차(픽셀), 양의 유한값입니다. BOX에서는 정확히 1이어야 합니다.

data_range: 밝기 정규화에 사용하는 양의 유한 기준 범위입니다.

k1: 밝기 안정 상수 계수, 양의 유한값입니다.

k2: 구조 안정 상수 계수, 양의 유한값입니다.

min_score: 결함 후보 판단의 SSIM 하한이며 −1 이상 1 이하입니다.

polarity: BOTH는 양쪽, BRIGHTER는 검체가 더 밝은 방향, DARKER는 더 어두운 방향입니다.

max_work: 국소 표본 방문 상한, 1 이상의 정수입니다. 유효 중심 수 × 창의 한 변²이 이 한도를 넘으면 오류입니다.

입력과 결과 해석

SsimOptions의 생성 인자는 다음 조건으로 해석합니다. 국소 창 반경(픽셀), 정수 0–1024입니다. BOX 또는 GAUSSIAN 창 가중치입니다. 영상 경계 처리로 CLIP 또는 REPLICATE입니다.

이 값은 해당 입력과 반환 맥락에 연결하여 읽어야 합니다. 가우시안 표준편차이며 유한한 양수입니다. BOX에서는 1이어야 합니다. 밝기 정규화 범위이며 유한한 양수입니다. SSIM 안정화 계수로 유한한 양수입니다.
