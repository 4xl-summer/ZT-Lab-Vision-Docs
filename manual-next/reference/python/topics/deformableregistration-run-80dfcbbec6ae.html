제어 격자 변위를 이용해 영상을 국소 정합합니다.

확인된 인자 조건

source: 정합할 소스 영상입니다.

reference: 기준 영상입니다.

options: DeformableRegistrationOptions입니다.

반환: 호출자가 닫아야 하는 DeformableRegistration입니다. info.found로 결과 유무를 확인합니다.

오류: 유효하지 않은 영상, 격자 또는 옵션은 오류입니다.

이 호출의 입력과 객체 맥락

소스와 기준 영상 및 제어 격자 설정으로 지역 변형 정합을 계산합니다. 결과 info.found를 먼저 확인하고 제어점 변위와 유효 마스크를 함께 읽어야 합니다. 변위는 기준 로컬 픽셀 기준이므로 영상 원점과 별개입니다. 반환 결과와 별도 취득한 영상은 각각 소유 객체이며 사용 후 close합니다.
