region_topology

method · 선언 타입 zvision.ZImage

Python
region_topology(self, connectivity) -> 'TopologyResult'

연결 성분과 구멍 수를 계산합니다.

확인된 인자 조건

connectivity: 4 또는 8

반환: 원본과 독립된 값 스냅샷입니다.

오류: 연결 값 또는 입력이 잘못되면 오류입니다.

인자 선언

  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음

반환 타입 주석: TopologyResult

Return an independent region topology snapshot.

연결과 구멍

전경 연결 성분 수와 내부 구멍 수를 위상으로 요약합니다. 전경 고리 하나와 구멍 하나라면 성분 1, 구멍 1이며 Euler 수는 1-1=0입니다. 같은 Euler 값을 가진 다른 형상도 있으므로 세 결과를 함께 확인해야 합니다.

입력과 ROI

마스크의 전경 값과 연결 조건을 고정한 뒤 계산합니다. ROI 경계에 의해 물체가 잘리면 내부와 외부의 연결이 달라질 수 있습니다. 면적이나 물체 위치는 위상 숫자만으로 알 수 없으므로 원본 마스크와 성분 측정을 같이 봅니다.
