find(self, source, options, mask=None)

명시적으로 학습한 각 변형 모델을 검색하며 예산과 시간을 공유합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 NCC 검색 설정입니다.

mask: 선택 검색 마스크입니다.

반환: 변형 인덱스와 매치를 포함한 독립 보고서입니다.

오류: 닫힌 모델 또는 잘못된 영상·설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

학습할 때 명시한 변형 모델들을 검색 영상에 적용하며 예산과 시간을 공유합니다. options는 확장 NCC 검색 설정이고 mask는 선택 검색 마스크입니다. 변형 하나마다 독립적으로 무제한 검색하는 것으로 해석하지 않습니다.

반환된 독립 보고서에서 변형 인덱스와 매치를 함께 읽습니다. 같은 포즈라도 어느 변형 모델에 해당하는지에 따라 해석이 달라지므로, 학습 때 사용한 deformation 목록과 인덱스 순서를 기록해 둡니다.

options확장 NCC 검색 설정입니다.
