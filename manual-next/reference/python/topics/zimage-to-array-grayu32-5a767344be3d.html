to_array_grayu32(self)

행 패딩을 제외한 보이는 성분을 복사합니다.

반환: 8비트 형식은 bytes, 그 외 형식은 숫자 list입니다.

오류: 요청한 형식과 영상 형식이 다르면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

픽셀 배치와 크기

이 메서드는 GrayU32 영상의 보이는 픽셀 성분을 행 우선으로 복사합니다. 부호 없는 32비트 회색 정수의 성분 수는 픽셀당 1개이며 반환형은 숫자 list입니다. 폭 2, 높이 2라면 보이는 성분은 4개입니다. 저장소의 행 패딩은 반환 성분에 포함하지 않습니다.

형식과 결과 확인

요청 형식과 실제 영상 형식이 다르면 오류가 납니다. 2×2에서 읽을 수 있는 값 순서의 예는 0, 1, 2, 3입니다. 픽셀 순서와 채널 순서를 같은 형식의 생성 입력과 대조하고, ROI라면 원본의 해당 위치를 확인합니다. 값 복사 결과와 영상 핸들의 수명은 별도로 관리합니다.
