local_to_global

method · 선언 타입 zvision.ZImage

Python
local_to_global(self, point)

영상 로컬 좌표에 ROI 원점을 더해 전역 좌표로 변환합니다.

확인된 인자 조건

point: 변환할 Point2

반환: 변환된 Point2입니다.

오류: 닫힌 영상 또는 유효하지 않은 좌표는 오류입니다.

인자 선언

  • point · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

ROI 좌표를 원본 기준으로

영상 로컬 점에 전역 원점을 더해 전체 영상 기준 위치를 계산합니다. 원점 (100,200)과 로컬 점 (10,20)은 전역 (110,220)입니다. 이 변환으로 ROI에서 측정한 중심이나 윤곽을 원본 영상에 맞추어 표시할 수 있습니다.

좌표 범위

점의 좌표계와 원점을 함께 보관해 같은 원점을 두 번 더하지 않도록 합니다. 전역 좌표 변환과 카메라의 물리 좌표 보정은 별도 단계입니다. 변환된 수치가 원하는 영상 범위 안에 있는지는 필요할 때 따로 확인합니다.
