execute(self) -> 'QueryExecution[SubpixelContourResult]'

종료 계획을 실행해 타입 지정 결과를 얻습니다.

반환: close할 실행 객체와 독립 값 스냅샷입니다.

오류: 연산이 실패하면 오류입니다.

반환 타입 주석: QueryExecution[SubpixelContourResult]

Execute and return subpixel contours with immutable point sequences.

소수 윤곽 실행

밝기 등치선의 소수 좌표 분석 계획을 실행해 QueryExecution[SubpixelContourResult]를 얻습니다. 결과 점은 픽셀 중심 사이의 위치를 나타낼 수 있으나 그 자릿수가 측정 정확도를 보증하지는 않습니다.

경로와 수명

실행 객체는 close하고 독립 스냅샷의 각 경로에서 점 순서와 닫힘 상태를 확인합니다. ROI 원점과 등치값을 기록하고 원본 밝기 변화와 경로를 겹쳐 위치를 검증합니다.
