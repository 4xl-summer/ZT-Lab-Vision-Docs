python 공개 선언
Line2DReport(lines: tuple, peaks: tuple) -> None

Copied independent segments and all post-threshold peaks.

lines: 적합 순서의 독립 선분 튜플입니다.

peaks: 추출 임계값을 통과한 피크와 적합 결과의 독립 튜플입니다.

이 호출의 입력과 객체 맥락

2차원 피크 추출과 선 적합 실행에서 생성된 선분과 피크를 복사해 담는 보고서입니다. lines에는 Line2DSegment 값이, peaks에는 Line2DPeak 값이 들어갑니다. 선분은 내점의 끝 범위와 스트립 커버리지를 담고, 피크는 검출 위치와 적합 단계의 분류를 담으므로 두 목록의 역할이 다릅니다.

각 피크의 선택적 line_index로 연결된 선을 확인할 수 있지만 배정되지 않은 피크도 있습니다. 최대 선 수를 0으로 선택하면 적합 선 없이 추출 피크만 보고할 수 있습니다. 또한 추출 문턱 아래의 피크는 결과에 없으므로 목록 길이는 영상의 모든 변화 수와 같다고 가정할 수 없습니다.

직선과 후보 스냅샷

lines에는 Line2DSegment 값, peaks에는 임계값 이후의 Line2DPeak 값을 전달합니다. 생성자는 각 입력을 튜플로 바꾸고 각 요소의 타입을 확인하므로 잘못된 요소는 TypeError입니다. 반환 객체는 독립 값 스냅샷입니다.

lines의 선분은 피팅된 결과이고 peaks는 추출된 후보 관측입니다. 두 튜플의 길이는 같은 의미가 아닙니다. 예를 들어 후보 다섯 개가 선분 하나에 기여할 수 있으므로 후보 수를 검출된 직선 수로 사용하지 않습니다.

후보는 ROI 로컬 위치와 기울기, 투영 영역, 분류 및 사유와 선택적 line_index를 가집니다. line_index가 없으면 특정 선분에 연결되지 않은 상태로 보존합니다. 선분의 길이와 coverage, inliers, 수렴 상태도 함께 확인합니다.

Line2DOptions의 max_lines=0은 피팅 없이 추출된 peak만 보고하는 조건입니다. 따라서 lines가 비고 peaks가 있는 결과도 가능합니다. 이 결과를 실패 예외와 혼동하지 않고 사용한 옵션과 입력 ROI를 보관합니다.
