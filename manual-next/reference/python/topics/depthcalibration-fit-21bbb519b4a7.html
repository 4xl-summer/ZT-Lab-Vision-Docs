상위 목차로 돌아가기

fit

staticmethod · 선언 타입 zvision._spatial3d.DepthCalibration

Python
fit(raw, reference, unit)

대응 높이로 선형 깊이 보정을 적합합니다.

확인된 인자 조건

raw: 최소 2개의 유한한 원시 높이

reference: raw에 대응하는 같은 수의 유한한 기준 높이

unit: 두 높이의 LengthUnit

반환: DepthCalibration 값 스냅샷입니다.

오류: 길이 불일치, 분산 부족 또는 비양수 배율 등 유효하지 않은 입력은 오류입니다.

인자 선언

  • raw · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

깊이 보정의 선형 적합

원시 깊이와 기준 깊이의 대응값에서 배율과 절편을 추정합니다. 두 목록의 길이는 같아야 하며 유한한 값으로 이루어진 두 쌍 이상이 필요합니다. 원시 입력이 모두 같으면 기울기를 결정할 수 없으므로 서로 다른 깊이를 포함해야 합니다.

원시값 0, 1, 2와 기준값 1, 3, 5를 대응시키면 scale 2와 offset 1인 직선이 나옵니다. 얻은 식을 새 샘플에 적용하고 평가하면 학습에 사용한 범위 밖에서의 차이도 확인할 수 있습니다. 데이터의 실제 단위를 모델과 동일하게 지정합니다.
