SpectrumInfo(width: int, height: int, source_width: int, source_height: int, origin_x: int, origin_y: int, normalization: zvision._frequency_processing.FftNormalization) -> None

SpectrumInfo(width: int, height: int, source_width: int, source_height: int, origin_x: int, origin_y: int, normalization: zvision._frequency_processing.FftNormalization)

width: 변환된 패딩 배열의 폭입니다.

height: 변환된 패딩 배열의 높이입니다.

source_width: 패딩 전 입력 폭입니다.

source_height: 패딩 전 입력 높이입니다.

origin_x: 입력 ROI x 원점입니다.

origin_y: 입력 ROI y 원점입니다.

normalization: 순·역변환의 정규화 방식입니다.

이 호출의 입력과 객체 맥락

width와 height는 변환에 사용된 패딩 배열 크기, source_width와 source_height는 패딩 전 입력 크기입니다. 예를 들어 입력 5×3을 8×4로 변환했다면 저장된 배열은 8×4이지만 원본 크기로 자른 역변환은 5×3입니다. origin_x/y는 입력 ROI 원점이며 normalization은 순·역변환 정규화 방식입니다. 패딩 크기를 원본 이미지의 유효 영역으로 오해하지 마세요.
