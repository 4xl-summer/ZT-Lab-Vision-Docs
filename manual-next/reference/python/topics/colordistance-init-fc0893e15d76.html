python 공개 선언
ColorDistance(_kind: zvision._color_advanced.AdvancedMetricKind, _parameters: tuple = ()) -> None

Lab 색차 방식과 방식별 계수의 불변 값입니다. cie76(), cie94(), ciede2000(), cmc(), mahalanobis() 등 공개 팩터리로 생성할 수 있습니다.

_kind: AdvancedMetricKind 거리 방식 열거값.

_parameters: 방식 순서에 따라 각각 0, 0, 3, 3, 2, 9, 9개인 계수 튜플; 생성 시 길이를 검사하고 튜플로 복사합니다.

인자별 입력 조건

인자형식역할과 조건
_kind<enum 'AdvancedMetricKind'>AdvancedMetricKind 거리 방식 열거값.
_parameters<class 'tuple'>방식 순서에 따라 각각 0, 0, 3, 3, 2, 9, 9개인 계수 튜플; 생성 시 길이를 검사하고 튜플로 복사합니다.

색 거리 옵션 구성

거리 종류와 해당 종류에 필요한 매개변수 튜플을 담는 값입니다. 맨해튼과 CIE76은 매개변수 0개, CIE94와 CIEDE2000은 3개, CMC는 2개, 두 Mahalanobis 방식은 9개가 필요합니다.

직접 종류 숫자를 조립하기보다 각 이름 있는 팩터리로 생성하면 선택과 매개변수의 관계가 분명합니다. 개수가 맞지 않으면 ValueError이며 거리 계산을 수행한 결과가 아닙니다.
