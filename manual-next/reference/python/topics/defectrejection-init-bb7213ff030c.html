DefectRejection(index: int, reasons: int)

index: 입력 결함 배열의 0부터 시작하는 인덱스입니다.

reasons: 해당 결함의 개별 면적 또는 위치 위반 비트입니다.

인자별 입력 조건

인자형식역할과 조건
index<class 'int'>입력 결함 배열의 0부터 시작하는 인덱스입니다.
reasons<class 'int'>해당 결함의 개별 면적 또는 위치 위반 비트입니다.

개별 후보의 위반

index는 평가된 결함 목록에서 해당 후보의 위치이고 reasons는 그 후보에 해당하는 위반 사유입니다. 전체 결함 수나 총면적 초과의 이유와 개별 후보 기록은 다른 수준입니다.

예를 들어 전체 최대 개수만 초과하면 전체 판정은 불합격일 수 있어도 개별 rejection이 반드시 생기는 것은 아닙니다. 결과의 전체 사유와 후보 인덱스를 함께 읽습니다.
