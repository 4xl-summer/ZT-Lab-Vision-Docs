호출 맥락과 결과 해석

save가 작성한 버전 있는 매칭 모델 파일을 읽어 독립된 모델을 복원합니다. path는 비어 있지 않은 경로여야 합니다. 템플릿 이미지 파일이 아니라 학습된 모델 형식을 입력으로 사용합니다.

복원한 모델은 호출자가 닫아야 합니다. 같은 영상과 MatchSpec을 사용해 저장 전후의 검색 결과를 비교하고, 로드에 실패하면 경로와 파일 완전성 및 모델 형식을 살핍니다. 검색 옵션과 검색 영상은 이 호출에서 별도로 주어지지 않습니다.
