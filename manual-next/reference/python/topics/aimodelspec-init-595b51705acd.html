AiModelSpec(task: zvision._inference.AiTask, width: int, height: int, channels: int, classes: int, model_version: int) -> None

Fixed input contract; model_version is a caller-supplied trace ID.

task: 분류·검출·분할·이상 중 모델 작업 종류입니다.

width: 모델 입력 너비(픽셀)이며 양수이고 높이와의 곱은 1,048,576 이하입니다.

height: 모델 입력 높이(픽셀)이며 양수이고 너비와의 곱은 1,048,576 이하입니다.

channels: 입력 채널 수로 1 또는 3입니다.

classes: 분류·분할은 2–256, 검출은 1–256, 이상은 1인 클래스 수입니다.

model_version: 호출자가 지정한 양의 추적 식별자이며 내용 해시가 아닙니다.

입력과 결과 해석

AiModelSpec은 고정 모델의 task, width, height, channels, classes, model_version을 담습니다. 너비와 높이는 각각 1 이상이며 바인딩은 픽셀 곱이 1,048,576을 넘지 않도록 검사합니다. 채널 수는 1 또는 3입니다. 모델이 학습할 때 사용한 입력과 이 계약이 일치하는지 확인해야 합니다.

클래스 수 범위는 작업에 따라 달라집니다. 분류와 분할은 최소 2개, 이상 작업은 정확히 1개이며 일반 상한은 256입니다. 예를 들어 640×480은 307,200 픽셀로 픽셀 수 제한 이내지만 이것만으로 채널 형식이나 모델 바이트가 적합하다는 뜻은 아닙니다.
