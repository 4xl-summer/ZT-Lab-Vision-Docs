python 공개 선언
JointGraphResult(cameras: tuple, boards: tuple, observation_rms: tuple, unit: object, initial_rms: float, final_rms: float, iterations: int, accepted_steps: int, converged: bool, exhausted: bool, stalled: bool) -> None

Shared camera/board poses, pixel RMS, and explicit local-solver termination flags.

cameras: 카메라 0 기준 카메라별 6성분 자세입니다. 카메라 0은 기준 자세입니다.

boards: 카메라 0 기준 보드별 6성분 자세입니다.

observation_rms: 관측별 재투영 RMS이며 픽셀 단위입니다.

unit: 입력 타깃과 자세의 길이 단위입니다.

initial_rms: 정련 전 전체 재투영 RMS이며 픽셀 단위입니다.

final_rms: 정련 후 전체 재투영 RMS이며 픽셀 단위입니다.

iterations: 수행한 최적화 반복 횟수입니다.

accepted_steps: 목적함수 감소로 받아들인 갱신 횟수입니다.

converged: 국소 최적화의 수렴 여부입니다.

exhausted: 반복 예산 소진 여부입니다.

stalled: 개선 없이 멈춘 상태인지 나타냅니다.

이 호출의 입력과 객체 맥락

카메라 0을 기준으로 한 카메라·보드별 6성분 자세와 관측별 재투영 RMS를 담습니다. 보드 좌표 및 자세 이동은 unit 길이 단위, 초기·최종 RMS는 픽셀입니다. accepted_steps는 목적함수가 감소해 수용된 갱신 수이고 converged, stalled, exhausted는 서로 다른 종료 상태입니다. 결과 좌표 프레임과 단위를 보관해 다른 보정과 비교하세요.
