pixel_to_ray

method · 선언 타입 zvision._camera_models.DivisionCamera

Python
pixel_to_ray(self, pixel)

전역 픽셀을 카메라 원점과 단위 방향 광선으로 변환합니다.

확인된 인자 조건

pixel: 전역 픽셀 중심의 유한한 Point2입니다.

반환: 카메라 좌표의 ModelRay 값입니다.

오류: 카메라 계수나 중심 연결 분기가 유효하지 않으면 오류입니다.

인자 선언

  • pixel · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

글로벌 픽셀을 카메라 좌표 광선으로 바꿉니다. 정규화 왜곡 좌표 d에 d/(1+k|d|²)을 적용하고 모델의 중심 연결 분기와 특이 조건을 검사합니다. k는 정규화 좌표 기준이므로 픽셀 단위의 계수로 혼용하지 않습니다. 광선을 세계 평면에 교차시키려면 별도의 포즈와 세계 좌표·단위가 필요합니다.

이 객체의 확인된 공개 생성 경로: DivisionCamera(fx: float, fy: float, cx: float, cy: float, k: float) -> None.
