adaptive_threshold_mean

method · 선언 타입 zvision._query.ImageQuery

Python
adaptive_threshold_mean(self, kernel, offset)

국소 평균 임계값 단계를 현재 계획에 덧붙입니다.

확인된 인자 조건

kernel: 커널 폭(픽셀)

offset: 지역 평균에서 사용할 오프셋

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

offset: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

지역 기준을 계획에 추가

kernel은 주변 평균에 사용할 픽셀 폭이고 offset은 지역 평균에 적용할 값입니다. 영상의 위치에 따라 평균이 달라지므로 하나의 전역 임계값과 다른 분할 결과를 낼 수 있습니다. 커널이 물체보다 지나치게 작으면 작은 변동의 영향도 커질 수 있습니다.

실행과 판독

수정된 동일 ImageQuery가 반환되며 실제 픽셀 계산은 실행 단계에서 확인합니다. 결과 마스크를 원본에 겹쳐 조명 변화와 작은 물체가 어떻게 처리되었는지 살펴봅니다. 커널 폭과 offset을 동시에 바꾸지 않으면 결과 변화의 원인을 구분하기 쉽습니다.
