close(self)

결과가 소유한 영상 핸들을 해제합니다.

반환: None입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

분리 결과가 보유한 markers 영상과 labels 영상을 닫습니다. markers 닫기에서 오류가 나도 labels 닫기를 시도합니다. marker_count와 region_count는 숫자 결과이지만 두 영상은 소유 핸들입니다. 분리 표식과 영역 라벨을 모두 확인하고 필요한 데이터를 복사한 다음 결과를 닫으세요. with 블록을 사용하면 종료 시 close가 호출됩니다.

이 객체의 확인된 공개 생성 경로: SplitResult(markers: zvision.ZImage, labels: zvision.ZImage, marker_count: int, region_count: int) -> None.

사용 조건과 결과 판독

SplitResult는 markers와 labels 영상, marker_count와 region_count 값을 담습니다. close는 markers를 먼저 닫고 그 과정에서 오류가 발생하더라도 labels 닫기를 시도합니다. 두 개의 영상 핸들과 두 개의 숫자 결과를 같은 종류의 자원으로 취급하지 않습니다.

마커 수와 최종 영역 수는 서로 다른 집계입니다. 예를 들어 마커 영상을 살펴 얻은 시작 위치와 labels의 영역 구분을 같이 확인해야 어느 영역이 어떤 분리 결과인지 판독할 수 있습니다. 필요한 영상 데이터는 해당 핸들이 열려 있는 동안 사용해야 합니다.

with 블록을 사용하면 범위를 벗어날 때 close가 호출됩니다. 닫은 markers나 labels를 재사용해 새 영상 연산을 시작하지 마세요. 반환된 숫자 값을 기록하는 것과, 결과가 소유한 두 영상 핸들의 사용을 끝내는 것은 별도의 작업입니다.

예를 들어 한 연결 영역의 분리 결과를 살펴볼 때 markers의 표식 위치와 labels의 영역 번호는 서로 다른 영상이므로 각각 확인해야 합니다. marker_count와 region_count가 같다고 가정하기보다 결과에 보고된 두 숫자를 읽으세요. 검토가 끝나면 close가 두 영상의 닫기를 차례로 시도하며, 이미 닫힌 영상으로 별도 그래프를 만들지 않습니다.
