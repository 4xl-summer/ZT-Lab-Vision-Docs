래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Associate a shared image and global pixel-to-world planar calibration.

영상에 평면 보정 결합

ZImage의 공유 핸들에 전역 픽셀에서 세계 평면으로 가는 PlanarCalibration을 결합합니다. ROI 로컬 좌표를 보정에 사용할 때는 전역 원점을 먼저 고려해야 합니다. 영상 픽셀의 깊은 복사와 공유 결합은 다릅니다.

수명과 검증

타입과 열린 핸들을 확인하고 반환 CalibratedImage를 사용 후 닫습니다. 보정 기준점이 실제 영상과 일치하는지 별도로 확인하며, 객체를 생성했다는 사실만으로 카메라의 보정 정확도가 입증되지는 않습니다.
