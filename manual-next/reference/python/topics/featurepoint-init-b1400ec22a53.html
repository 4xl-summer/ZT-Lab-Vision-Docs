FeaturePoint(position: zvision._regions.Point2, response: float)

position: 검출된 특징점의 해당 영상 로컬 픽셀 중심입니다.

response: 특징점의 Harris 원시 응답입니다.

값을 구성하고 해석하기

특징점의 position과 Harris 원시 response를 담는 값입니다. 위치는 해당 영상의 로컬 픽셀 좌표이며 response는 그 점의 검출 강도를 나타냅니다. 학습 모델의 점인지 검색 영상에서 검출한 점인지에 따라 position이 기준으로 삼는 영상이 달라집니다. 이 값 자체는 대응 관계나 변환을 뜻하지 않습니다.

생성할 때 확인할 값

인자값의 의미
position검출된 특징점의 해당 영상 로컬 픽셀 중심입니다.
response특징점의 Harris 원시 응답입니다.

좌표와 응답의 해석

position은 특징을 검출한 해당 영상의 로컬 픽셀 중심입니다. 템플릿 모델의 점과 검색 영상의 점은 둘 다 Point2이더라도 서로 다른 영상 좌표계에 속합니다. 같은 숫자의 좌표라는 이유만으로 두 점이 대응한다고 판단하지 않습니다.

response는 Harris 검출의 원시 응답이며 인식 확률이나 기하 변환의 오차가 아닙니다. 대응 여부와 변환 추정은 별도 검색 결과의 대응점과 내점·행렬에서 확인합니다. 검색 영상이 ROI라면 원본 좌표 표시 시 그 영상의 원점을 고려합니다.
