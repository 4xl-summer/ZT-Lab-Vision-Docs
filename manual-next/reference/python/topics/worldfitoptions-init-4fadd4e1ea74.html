WorldFitOptions.__init__

python 공개 선언
WorldFitOptions(method: zvision._world_refit.WorldFitMethod, inlier_threshold: float, min_inliers: int, max_candidates: int, max_refit_iterations: int, tolerance: float, min_arc_radians: float = 0.0) -> None

Fit thresholds/tolerance use the requested output length unit.

method: 최소제곱 또는 후보 합의 피팅 방식을 선택합니다.

inlier_threshold: 합의 판정의 유한 양수 거리이며 출력 길이 단위입니다.

min_inliers: 최소 합의점 수입니다.

max_candidates: 후보 탐색의 최대 횟수입니다.

max_refit_iterations: 재피팅 반복 한도입니다.

tolerance: 재피팅 수렴 허용값이며 출력 길이 단위의 0 이상 유한수입니다.

min_arc_radians: 원 피팅에 필요한 최소 각 범위이며 0–2π 라디안입니다.

이 호출의 입력과 객체 맥락

WorldFitOptions는 월드 평면 도형 적합의 방법과 허용 조건을 설정합니다. inlier_threshold와 tolerance는 요청한 출력 길이 단위로 해석하며 min_inliers, max_candidates, max_refit_iterations는 적합에 필요한 점과 계산 제한을 정합니다. min_arc_radians는 원호에 관한 각도 조건으로 라디안입니다.

예를 들어 출력 단위를 mm로 선택했다면 내점 기준 0.5는 0.5 mm입니다. 같은 장면을 m로 표현하면서 0.5를 그대로 쓰면 물리적으로 다른 한계가 됩니다. 원호 각도는 길이 단위와 별개이므로 180도는 π 라디안입니다. 방법과 기준을 기록하고 반환 관측의 잔차와 사용 여부를 확인해 적합 결과를 해석하세요.
