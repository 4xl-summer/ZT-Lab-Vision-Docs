pixels(cls) -> 'CompositeUnit'

반환 타입 주석: CompositeUnit

저장된 물리 단위 대신 픽셀 좌표를 명시적으로 선택한다.

이 호출의 입력과 객체 맥락

물리 등방 단위 대신 픽셀 출력을 명시하는 값으로 unit_id=0, units_per_pixel=1을 만듭니다. 저장된 물리 단위가 있는 모델 평가에서 픽셀 출력을 명시적으로 선택할 때 사용할 수 있습니다. 원점은 ROI 로컬이며 이 선택은 광학 보정이나 세계 좌표 변환이 아닙니다. 탐침 진단도 픽셀 단위로 해석합니다.

픽셀 단위의 명시적 선택

CompositeUnit.pixels()는 unit_id=0과 units_per_pixel=1.0을 가진 CompositeUnit 값을 만듭니다. 이 선택은 복합 측정에서 픽셀 출력을 명시하는 방법입니다. 새로운 영상이나 모델 핸들을 생성하는 호출이 아니며 객체를 만들 때 위치 좌표를 세계 좌표로 변환하지도 않습니다.

예를 들어 ROI 로컬 점 (10,20)은 픽셀 단위 선택에서 그 ROI 기준 픽셀 위치로 읽습니다. ROI 원점이 전체 영상의 (100,200)이라면 같은 위치의 전체 영상 좌표는 (110,220)입니다. 이는 원점 이동을 설명하는 계산이며 CompositeUnit.pixels()가 자동으로 이를 수행한다는 뜻은 아닙니다. 탐침 진단도 픽셀 단위로 유지됩니다.

수명과 결과 확인

물리 길이가 필요하면 보정된 좌표와 단위를 사용하는 별도 절차를 준비해야 합니다. 10픽셀이라는 수치에 mm라는 이름만 붙이면 물리 거리가 되지 않습니다. 모델에 저장된 물리 단위와 이 명시적 픽셀 선택을 구분하고, 평가 결과를 다른 영상과 비교할 때 ROI와 단위 설정을 함께 기록하세요.
