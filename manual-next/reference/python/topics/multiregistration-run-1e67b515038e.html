run(cls, images, edges, common_index=0, *, fixed_sources=None)

여러 영상의 등록 그래프를 계산해 공통 격자에 맞춥니다.

확인된 인자 조건

images: 3–16개의 ZImage입니다.

edges: 영상 간 RegistrationGraphEdge 순서열입니다.

common_index: 기준 영상 인덱스이며 기본값은 0입니다.

fixed_sources: 영상마다 고정 여부를 지정하는 bool 순서열 또는 None입니다.

반환: 호출자가 닫아야 하는 MultiRegistration입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • edges · POSITIONAL_OR_KEYWORD · 기본값 없음
  • common_index · POSITIONAL_OR_KEYWORD · 기본값 0
  • fixed_sources · KEYWORD_ONLY · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Estimate all edges, reject disconnected graphs and align to the common image.

이 호출의 입력과 객체 맥락

3~16개의 ZImage와 영상 간 등록 에지로 공통 격자의 정합 그래프를 계산합니다. common_index는 기준 영상 인덱스이고 fixed_sources는 영상별 고정 여부 또는 None입니다. 결과에서 각 이미지의 공통 좌표계 매핑과 에지 품질을 읽을 수 있습니다. 반환 MultiRegistration은 소유 객체이므로 사용 후 close합니다.
