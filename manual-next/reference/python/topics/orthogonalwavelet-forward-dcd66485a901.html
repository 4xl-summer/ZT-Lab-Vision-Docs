OrthogonalWavelet.forward 공개 계약

forward

classmethod · 선언 타입 zvision._wavelet_inpaint_gap.OrthogonalWavelet

Python
forward(cls, image, levels, family=<WaveletFamily.HAAR: 0>)

영상에서 소유 웨이블릿 계수를 계산합니다.

확인된 인자 조건

image: 입력 ZImage

levels: 1–64 변환 레벨

family: WaveletFamily; 기본값 HAAR

반환: 별도로 close할 OrthogonalWavelet입니다.

오류: 영상, 레벨 또는 계열이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • family · POSITIONAL_OR_KEYWORD · 기본값 <WaveletFamily.HAAR: 0>

levels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Legacy factory retained through 0.1.x; prefer image.orthogonal_wavelet_with_family(levels, family).

이 호출의 입력과 객체 맥락

입력 영상과 분해 단계 수, 선택한 웨이블릿 계열로 독립 소유 변환 모델을 만듭니다. Python 기본 계열은 Haar입니다. 생성 후 계수 복사와 역변환은 모델의 별도 호출이며 입력 ROI와 크기 조건을 확인해야 합니다. 모델을 사용한 뒤 close하고 복원 영상도 별도로 해제합니다.
