유효 표본 마스크을 얻습니다.

반환: 호출자가 닫아야 하는 별도 소유 ZImage입니다.

오류: 정합 결과가 없거나 객체가 닫혔다면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

정합 결과에 대응하는 유효 마스크 영상을 반환합니다. 정렬된 영상을 비교할 때 마스크를 함께 확인해 입력에서 대응하지 않는 영역을 실제 관측값으로 해석하지 않도록 합니다. 반환 ZImage는 별도 소유 핸들이므로 close하고 AdvancedRegistration 결과도 따로 close합니다. 정합 성공 여부와 점수·coverage는 결과 info에서 확인합니다.

정합 영상과 마스크를 함께 읽기

이 메서드는 정합 결과에서 유효 표본 마스크를 별도 소유 ZImage로 얻습니다. 정렬된 영상에서 픽셀 값이 0이라는 사실만으로 입력 영역 밖이라고 판단할 수 없습니다. 0이 실제 관측 밝기일 수도 있으므로 같은 정합 결과의 유효 마스크를 함께 사용해 대응 표본이 있는 위치를 구분합니다.

정합이 결과를 찾았는지와 점수·coverage는 결과 정보에서 먼저 확인하십시오. 결과가 없거나 소유 객체가 닫혀 있으면 마스크 획득은 오류입니다. 마스크 영상과 AdvancedRegistration은 별도 소유이므로 사용이 끝나면 각각 close합니다. ROI를 비교할 때는 두 영상의 좌표 관계도 일치시켜야 합니다.
