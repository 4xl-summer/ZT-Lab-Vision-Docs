FrameInfo(source_id: int, epoch: int, frame_id: int, trigger_id: int, device_ticks: int, host_ns: int, clock_domain: int, tick_hz: int)

source_id: 프레임의 소스 식별자입니다.

epoch: 취득 세션을 구분하는 값입니다.

frame_id: 프레임 식별자입니다.

trigger_id: 프레임에 연결된 트리거 식별자입니다.

device_ticks: 장치 시계의 틱 값입니다.

host_ns: 호스트 측 시간 값이며 나노초 단위입니다.

clock_domain: 장치 시계의 도메인 식별자입니다.

tick_hz: 장치 시계의 초당 틱 수입니다.

이 호출의 입력과 객체 맥락

이 스냅샷은 source_id와 epoch, frame_id 및 trigger_id를 장치 시계와 호스트 시각 정보와 함께 담습니다. device_ticks는 장치 시계의 틱이고 tick_hz는 그 시계의 초당 틱 수이며 host_ns는 호스트 나노초입니다. 서로 다른 clock_domain의 틱을 숫자만으로 직접 비교하지 말고 해당 시계 매핑과 불확도를 사용하세요. 트리거가 없는 프레임의 trigger_id는 0입니다. 프레임 영상의 소유 핸들과는 별개의 값입니다.
