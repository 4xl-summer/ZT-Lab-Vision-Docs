SpatialCalibration.fit 공개 계약

상위 목차로 돌아가기

fit

classmethod · 선언 타입 zvision._spatial3d_advanced.SpatialCalibration

Python
fit(cls, raw, reference, trim_fraction=0.0, model=None)

각 셀의 대응 깊이로 공간 보정을 학습합니다.

확인된 인자 조건

raw: 같은 크기·단위·frame·격자 메타데이터의 원시 DepthMap 시퀀스

reference: raw와 동일 개수이며 같은 격자 조건의 기준 DepthMap 시퀀스

trim_fraction: 제거할 잔차 비율; 유한한 [0,1), 기본 0

model: None은 이차 모델; 정수 0 선형, 1 이차

반환: 새 소유 SpatialCalibration이며 사용 후 닫습니다.

오류: 대응 수 부족·메타데이터 불일치·결측 부족·퇴화 또는 옵션 오류는 예외입니다.

인자 선언

  • raw · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • trim_fraction · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • model · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

픽셀별 공간 보정 학습

여러 원시 영상과 같은 순서의 기준 영상을 짝지어 각 위치의 깊이 보정 계수를 구합니다. 영상은 크기, 단위, frame, 간격과 원점이 일치해야 하며 모델의 차수에 맞는 충분한 유효 대응이 각 픽셀에 필요합니다. 선형 모델은 두 쌍, 이차 모델은 세 쌍을 필요로 합니다.

한 위치에 서로 다른 원시 깊이 0, 1, 2와 기준 깊이 1, 3, 5가 있다면 선형식 1 + 2h가 맞습니다. 이차식을 사용한다면 세 대응 이상이 필요하며 퇴화한 값들은 계수를 결정하지 못할 수 있습니다. 잔차 제거 비율은 0 이상 1 미만이고 0은 제거하지 않음을 뜻합니다.

model선형 또는 이차 계수 선택
trim_fraction제거할 잔차 비율 [0,1)
