find_image_pyramid(self, source, options, first_level, last_level=0)

실제로 축소된 영상 및 형상 특징으로 지정 층을 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 형상 검색 설정입니다.

first_level: 시작 축소 수준입니다.

last_level: 마지막 축소 수준입니다. 기본값 0입니다.

반환: 독립 매치 결과와 종료 진단입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first_level · POSITIONAL_OR_KEYWORD · 기본값 없음
  • last_level · POSITIONAL_OR_KEYWORD · 기본값 0

Search actual reduced images and shape features.

호출 맥락과 결과 해석

축소된 영상과 축소된 형상 특징을 사용하는 피라미드 수준을 지정해 검색합니다. first_level과 last_level은 검색할 축소 수준을 정하며 last_level의 명시된 기본값은 0입니다. 단순히 원본 영상에서 위치 간격만 넓히는 설정과 구별해야 합니다.

큰 축소 수준에서는 작은 형상 세부가 약해질 수 있으므로 같은 입력과 검색 조건에서 수준을 바꾸어 후보와 종료 진단을 비교합니다. 매치가 기대와 다르면 모델의 특징, 선택한 수준 범위 및 검색 격자를 함께 확인하는 것이 유용합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options형상 검색 설정입니다.
first_level시작 축소 수준입니다.
last_level마지막 축소 수준입니다. 기본값 0입니다.
