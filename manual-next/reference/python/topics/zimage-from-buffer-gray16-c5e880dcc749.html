from_buffer_gray16

classmethod · 선언 타입 zvision.ZImage

Python
from_buffer_gray16(cls, width, height, pixels)

네이티브 바이트 순서의 Gray16 버퍼를 복사하여 영상을 만듭니다.

확인된 인자 조건

width: 양의 픽셀 폭

height: 양의 픽셀 높이

pixels: 행 우선 네이티브 바이트 순서의 Gray16 버퍼; 폭×높이×1개 성분

반환: 별도로 close할 ZImage입니다.

오류: 크기·성분 수·형식 또는 값 범위가 잘못되면 오류입니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음

Copy a packed native-endian unsigned 16-bit buffer into an image.

16비트 버퍼의 복사

이 생성자는 네이티브 바이트 순서의 Gray16 버퍼를 복사해 영상을 만듭니다. 폭 2, 높이 2이면 4개의 16비트 표본이며 표본의 바이트 표현을 포함한 버퍼 크기와 정렬을 맞춰야 합니다. 숫자 목록을 받는 생성자와 입력 표현을 혼동하지 않습니다.

바이트 순서와 수명

width와 height는 양의 픽셀 크기이고 pixels는 행 우선 네이티브 바이트 순서 버퍼입니다. 입력 바이트가 다른 엔디언으로 기록되었다면 값이 달라지므로 준비 단계에서 확인합니다. 생성된 ZImage는 독립 소유 핸들로 사용 후 닫습니다.
