RayResult(direction: object, iterations: int, residual_pixels: float, converged: bool) -> None

Camera unit direction, iterations, pixel residual and convergence; failed direction is diagnostic.

direction: 카메라 좌표의 단위 방향입니다. 수렴하지 않았다면 추정값입니다.

iterations: 역산에 사용한 반복 횟수입니다.

residual_pixels: 픽셀 단위의 역산 잔차입니다.

converged: 역산의 수렴 여부입니다.

이 호출의 입력과 객체 맥락

RayResult는 픽셀에서 카메라 광선을 복원한 결과를 담습니다. direction은 카메라 좌표계의 방향이고 iterations는 계산 반복 횟수, residual_pixels는 픽셀 단위의 잔차입니다. converged는 지정한 수렴 조건을 만족했는지 나타냅니다. 잔차의 단위가 픽셀인 점을 확인하고 월드 좌표의 밀리미터 오차와 직접 비교하지 않아야 합니다.

예를 들어 관측 좌표를 광선으로 변환하고 이 광선을 다시 카메라에 투영했을 때 남는 차이가 작으면 수치 역변환이 잘 맞았는지 살펴볼 수 있습니다. converged가 거짓이면 반환 방향을 확정 값으로 간주하지 말고 입력 좌표, 렌즈 계수, 반복 조건을 점검하세요. 수렴했다는 결과는 실제 카메라 보정이 완벽하다는 증명은 아닙니다.

사용 흐름과 결과 판독

RayResult는 픽셀에서 카메라 광선 방향을 역산한 결과를 담는 값입니다. direction은 카메라 좌표계의 단위 방향, iterations는 사용한 반복 횟수, residual_pixels는 재투영 잔차, converged는 지정한 수렴 조건을 만족했는지입니다. 값을 직접 생성하는 것은 렌즈 역산을 실행하는 것과 별개입니다.

픽셀에서 얻은 방향을 카메라 모델로 다시 투영하여 원래 관측과의 차이를 보면 수치 역변환의 잔차를 이해할 수 있습니다. residual_pixels가 0.2라면 그 차이는 픽셀 기준이며 0.2 mm의 공간 오차가 아닙니다. 실제 공간 위치의 오차는 깊이와 카메라 기하에도 의존하므로 단위만 바꾸어 환산하지 않습니다.

converged가 거짓이어도 direction 필드에 추정 방향이 있을 수 있지만 이를 확정된 해로 취급하지 않습니다. 입력 픽셀과 렌즈의 초점·주점·왜곡, 반복 상한과 허용 오차를 함께 검토합니다. 반대로 수렴이 참이라는 사실도 렌즈 모델과 실제 장비의 보정 정확도가 완벽하다는 의미는 아닙니다.
