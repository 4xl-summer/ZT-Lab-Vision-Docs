ImageQuery.align_reference 공개 계약

상위 목차로 돌아가기

align_reference

method · 선언 타입 zvision._query.ImageQuery

Python
align_reference(self, reference, spec)

입력과 기준 영상의 정렬을 계획합니다.

확인된 인자 조건

reference: 기준 ZImage

spec: AlignmentSpec

반환: close할 AlignmentQuery입니다.

오류: 입력 또는 설정이 유효하지 않으면 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

기준 영상과 정렬

현재 계획에서 사용할 영상과 reference 기준 ZImage의 정렬을 AlignmentSpec에 따라 계산합니다. 같은 숫자의 픽셀 좌표가 실제 같은 장면 위치를 가리키는지 맞추는 단계이며 정렬 후의 차이 측정과는 별개입니다.

결과와 수명

반환 AlignmentResult의 공개 계약을 확인하고 필요한 변환과 영상을 읽은 뒤 close합니다. 정렬이 계산되었다는 사실만으로 실제 장비의 정확도가 검증되는 것은 아니므로 기준점과 입력 ROI를 확인합니다.
