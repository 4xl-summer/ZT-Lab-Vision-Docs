BarcodeSpec(formats: zvision._recognition.BarcodeFormat, try_rotate: bool = False, min_contrast: float = 0.0)

formats: 읽을 바코드 형식을 지정하는 0이 아닌 비트 조합입니다.

try_rotate: 원본 외 회전된 방향도 시도할지 정합니다. 기본값은 False입니다.

min_contrast: 입력 Gray8 대비의 최소값으로 0~1이며 기본값은 0입니다. 값이 같으면 통과합니다.

인자별 입력 조건

인자형식역할과 조건
formats<enum 'BarcodeFormat'>읽을 바코드 형식을 지정하는 0이 아닌 비트 조합입니다.
try_rotate<class 'bool'>원본 외 회전된 방향도 시도할지 정합니다. 기본값은 False입니다.
min_contrast<class 'float'>입력 Gray8 대비의 최소값으로 0~1이며 기본값은 0입니다. 값이 같으면 통과합니다.

형식과 대비 선택

formats는 허용할 형식의 비트 조합입니다. Code 128의 1과 QR의 8을 함께 선택하면 마스크 9이며, try_rotate는 회전 탐색을 별도로 선택합니다.

min_contrast는 Gray8 (최댓값−최솟값)/255로 정규화한 대비의 기준이며 검증기 품질 등급이 아닙니다. 호출 결과의 status와 reasons를 함께 확인하고 미발견과 오류를 구분합니다.
