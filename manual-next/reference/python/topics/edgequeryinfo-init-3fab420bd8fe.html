EdgeQueryInfo(label: int, available: int, closed: bool, size: int, first: zvision._regions.Point2, minimum: zvision._regions.Point2, maximum: zvision._regions.Point2) -> None

Detached metadata; consult available bits before reading optional values.

label: 포함 여부 변경에도 유지되는 양의 에지 레이블입니다.

available: 계산된 선택 기능을 나타내는 비트 마스크입니다.

closed: 닫힌 체인인지 나타내며 해당 기능 비트를 확인해야 합니다.

size: 체인의 점 개수이며 해당 기능 비트를 확인해야 합니다.

first: 첫 점의 좌표이며 해당 기능 비트를 확인해야 합니다.

minimum: 좌표 경계의 최솟값이며 해당 기능 비트를 확인해야 합니다.

maximum: 좌표 경계의 최댓값이며 해당 기능 비트를 확인해야 합니다.

이 호출의 입력과 객체 맥락

에지 체인의 식별자와 선택 기능 메타데이터를 분리해 보관하는 값입니다. label은 제외와 재포함에도 유지되는 양의 레이블이고 available은 실제로 계산된 선택 기능의 비트 마스크입니다. 목록 인덱스는 포함된 항목에 따라 달라질 수 있으므로 장기 식별에는 레이블을 사용하고 호출 시 인덱스 선택과 레이블 선택을 구별하십시오.

size는 점 개수, closed는 닫힌 체인 여부, first는 첫 점이며 minimum과 maximum은 좌표 경계입니다. 이 필드들은 항상 사용 가능한 것으로 가정하지 말고 해당 기능 비트가 available에 있는지 확인해야 합니다. 예를 들어 bounds 기능을 요청하지 않은 결과의 좌표를 실제 측정 범위로 해석하면 안 됩니다.
