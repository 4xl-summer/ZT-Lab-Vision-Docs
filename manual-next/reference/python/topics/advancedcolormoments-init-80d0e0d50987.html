AdvancedColorMoments(label: int, count: int, mean: tuple, min: tuple, max: tuple, std_dev: tuple, covariance: tuple, eigenvalues: tuple, eigenvectors: tuple) -> None

라벨별 색 통계를 담는 값 스냅샷입니다. moments_by_label 결과로 얻을 수 있습니다.

label: 0이 아닌 레이블 값; 0은 배경.

count: 레이블에 포함된 픽셀 수.

mean: 정규화된 인코딩 RGB 순서의 평균 3값 튜플.

min: 라벨에 포함된 표본의 채널별 최소값 튜플.

max: 라벨에 포함된 표본의 채널별 최대값 튜플.

std_dev: 라벨 표본의 채널별 표준편차 튜플.

covariance: 정규화 RGB의 행 우선 3×3 모집단 공분산 9값 튜플.

eigenvalues: 공분산 PCA 고유값 3개; 내림차순.

eigenvectors: 고유벡터를 열로 둔 행 우선 3×3 튜플; 고유벡터 부호는 유일하지 않음.

입력과 결과 해석

AdvancedColorMoments의 생성 인자는 다음 조건으로 해석합니다. 0이 아닌 레이블 값; 0은 배경. 레이블에 포함된 픽셀 수. 정규화된 인코딩 RGB 순서의 평균 3값 튜플.

이 값은 해당 입력과 반환 맥락에 연결하여 읽어야 합니다. 라벨에 포함된 표본의 채널별 최소값 튜플. 라벨에 포함된 표본의 채널별 최대값 튜플. 라벨 표본의 채널별 표준편차 튜플.
