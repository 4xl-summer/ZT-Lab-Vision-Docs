suppress(self, matches, max_iou, limit)

변환된 NCC 표본의 축 정렬 경계상자 IoU로 매치를 점수순 억제합니다.

확인된 인자 조건

matches: 억제할 AdvancedMatch 값들의 시퀀스입니다.

max_iou: 허용할 최대 겹침 IoU로 0..1입니다.

limit: 유지할 최대 후보 수인 양의 정수입니다.

반환: 남은 후보의 독립 list입니다.

오류: 타입, IoU 또는 개수 조건이 맞지 않으면 오류입니다.

인자 선언

  • matches · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_iou · POSITIONAL_OR_KEYWORD · 기본값 없음
  • limit · POSITIONAL_OR_KEYWORD · 기본값 없음

Suppress overlapping match bounding boxes.

호출 맥락과 결과 해석

이미 구한 AdvancedMatch 후보를 점수 순으로 비교하고 변환된 NCC 표본의 축 정렬 경계상자 IoU를 사용해 겹치는 후보를 억제합니다. 새 후보를 검색하는 호출이 아니므로 입력 matches가 어떤 검색에서 나왔는지 함께 보존합니다.

max_iou는 0에서 1 사이의 최대 겹침 기준이고 limit은 유지할 양의 최대 개수입니다. 회전된 형상의 축 정렬 상자는 실제 모양보다 클 수 있어 다각형 겹침 억제와 결과가 다를 수 있습니다. 반환 list는 입력과 독립적입니다.

입력 선택을 위한 확인

입력의미와 조건
matches억제할 AdvancedMatch 값들의 시퀀스입니다.
max_iou허용할 최대 겹침 IoU로 0..1입니다.
limit유지할 최대 후보 수인 양의 정수입니다.

반환값 확인

남은 후보의 독립 list입니다.
