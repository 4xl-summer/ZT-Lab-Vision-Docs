threshold

method · 선언 타입 zvision._query.ImageQuery

Python
threshold(self, t)

픽셀이 임계값 이상인지 비교하는 Gray8 마스크 단계를 추가합니다.

확인된 인자 조건

t: 유한한 밝기 임계값

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·형식 검증은 단계 추가 시, 픽셀 유효성은 execute 시 실패할 수 있습니다.

인자 선언

  • t · POSITIONAL_OR_KEYWORD · 기본값 없음

t: 유한한 수 검사.

Append in place a pixel >= finite t mask for seven Gray formats.

Validate arguments and image metadata now; validate pixels at execute().
The output is an owned Gray8 image.

고정 기준 분할 단계

픽셀을 임계값과 비교해 이진 마스크를 만드는 계획을 추가합니다. 임계값 7에서 0, 6, 7, 8은 각각 0, 0, 255, 255로 선택되므로 경계에 같은 값도 포함됩니다. 이전 단계에서 밝기를 바꾸었다면 변환된 값을 기준으로 비교합니다.

마스크 확인

실행 결과를 원본 위에 겹쳐 물체가 원하는 전경인지 확인합니다. 255는 선택 표시로 원본의 밝기를 보존하지 않습니다. 뒤이어 블롭을 찾는 경우 마스크, 연결성과 면적 조건을 각각 기록합니다.
