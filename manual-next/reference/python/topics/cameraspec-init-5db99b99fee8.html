CameraSpec(source_id: int, clock_domain: int, tick_hz: int, capacity: int, trigger_mode: zvision._acquisition.TriggerMode)

source_id: 0이 아닌 소스 식별자입니다.

clock_domain: 0이 아닌 장치 시계 도메인 식별자입니다.

tick_hz: 장치 시계의 초당 틱 수이며 양수입니다.

capacity: 프레임과 트리거 큐의 용량이며 1부터 65536까지입니다.

trigger_mode: 자유 실행, 소프트웨어 또는 외부 트리거 방식을 선택합니다.

이 호출의 입력과 객체 맥락

CameraSpec은 모의 카메라의 소스 식별자, 시계 도메인, 초당 틱 수, 큐 용량과 트리거 모드를 묶습니다. source_id, clock_domain, tick_hz는 0이 아니어야 하고 capacity는 1부터 65536까지입니다. trigger_mode는 FREE_RUN, SOFTWARE 또는 EXTERNAL 중 하나로 선택합니다. 이 설정은 모의 객체에 제공하는 값이며 물리 카메라에서 장치 정보가 자동 발견되었다는 의미는 아닙니다.

예를 들어 소스 1, 도메인 2, 초당 1000틱, 용량 2인 소프트웨어 트리거 카메라를 만든다면 연결과 시작 후 트리거를 등록하고 그 ID로 프레임을 제출합니다. 용량은 보관 프레임과 대기 트리거를 제한하므로 소비가 늦어졌을 때 처리 상태를 확인해야 합니다. 서로 다른 소스 시각을 비교할 때는 숫자가 같은 도메인이라는 이유만으로 동기화되었다고 가정하지 않고 명시적 ClockMap을 사용하세요.
