AdvancedMatches.image 공개 계약

상위 목차로 돌아가기

image

method · 선언 타입 zvision._color_advanced.AdvancedMatches

Python
image(self, index)

색상 매칭 결과에서 인덱스 또는 거리 영상을 얻습니다.

확인된 인자 조건

index: 0은 기준 색 인덱스, 1은 거리 영상입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 0 또는 1이 아니거나 결과가 닫혔다면 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출과 결과 확인

index 0은 선택된 기준 색 인덱스 영상이고 index 1은 거리 영상입니다. 그 밖의 값은 ValueError입니다. 반환 ZImage는 별도로 소유하므로 결과 객체와 각 영상을 각각 close 또는 with로 관리합니다. 거리 해석에는 검색에 사용한 색 거리 방식을 함께 기록합니다.
