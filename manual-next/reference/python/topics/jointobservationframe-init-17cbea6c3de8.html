JointObservationFrame(camera_frame: int, board_frame: int, unit: object) -> None

Observation camera/board frame IDs and physical length unit.

camera_frame: 해당 관측의 카메라 프레임 ID.

board_frame: 해당 관측의 보드 프레임 ID.

unit: 보드 좌표와 pose 이동의 길이 단위.

이 호출의 입력과 객체 맥락

공동 카메라·보드 보정에서 관측 하나가 어떤 카메라 프레임과 보드 프레임에 속하는지, 어떤 물리 길이 단위를 사용하는지 지정하는 태그입니다. camera_frame과 board_frame은 숫자로 표현된 프레임 식별자이고 unit은 LengthUnit입니다. 이름이 비슷한 관측 인덱스와 프레임 식별자는 서로 다른 역할을 합니다.

프레임 태그를 받는 보정 호출에서는 관측 순서에 맞게 태그를 제공하고, 태그에 지정한 식별자가 해당 카메라 및 보드 프레임 목록과 일치해야 합니다. 단위도 전체 계산의 길이 단위와 맞아야 합니다. 예를 들어 관측의 보드 인덱스가 1인 경우 그 항목에 태그된 보드 프레임은 목록의 해당 프레임과 일치해야 합니다.

입력과 결과를 읽는 순서

관측 하나가 어떤 카메라 프레임과 보드 프레임에 속하며 어떤 길이 단위를 쓰는지 지정합니다. camera_frame과 board_frame은 프레임 식별자이고 unit은 보드 좌표와 pose 이동의 길이 단위입니다. 관측 배열의 인덱스와 프레임 식별자는 같은 역할이 아닙니다.

예를 들어 보드 목록의 두 번째 항목을 사용하는 관측에는 그 항목에 지정된 보드 프레임을 태그해야 합니다. 숫자 인덱스가 1이라는 이유만으로 임의로 프레임 ID를 1로 두면 실제 목록의 ID와 다를 수 있습니다. 관측 순서에 맞게 태그를 제공하고 해당 카메라·보드 목록과 대조하세요.

보드 좌표와 자세 이동의 단위도 공동 계산의 길이 단위와 맞아야 합니다. 이 태그 자체는 좌표를 자동 변환하거나 카메라 자세를 측정하지 않습니다. 프레임 방향과 단위를 보정 결과 및 관측 출처와 함께 보관해야 나중에 해석할 수 있습니다.
