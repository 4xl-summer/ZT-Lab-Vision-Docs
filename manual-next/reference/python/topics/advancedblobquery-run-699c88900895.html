고급 Blob 조건 계획을 실행합니다.

반환: 원본 BlobResult의 0 기반 인덱스 list입니다.

오류: 계획 또는 실행 오류가 전파됩니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

조건 계획 실행

고급 Blob 조건 계획을 실행해 원본 BlobResult의 0 기반 인덱스 list를 얻습니다. list의 값은 선택된 객체 자체나 레이블 번호가 아닙니다. 예를 들어 결과 0은 원본 결과의 첫 항목을 가리킵니다.

대상 결과와 오류

계획과 원본 결과의 수명이 유효한 상태에서 실행하고 반환 인덱스로 원본 측정값을 조회합니다. 실행 오류는 전파되므로 결과 목록을 사용하기 전에 확인합니다. 다른 프레임 결과의 같은 인덱스와 자동 대응시키지 않습니다.

인덱스의 기준

반환 list의 0은 원본 BlobResult의 첫 성분을 뜻합니다. 레이블 번호나 다른 프레임의 인덱스로 취급하지 않습니다. 조건의 포함 여부와 원본 성분 측정값을 함께 비교한 뒤 쿼리 자원을 해제합니다.
