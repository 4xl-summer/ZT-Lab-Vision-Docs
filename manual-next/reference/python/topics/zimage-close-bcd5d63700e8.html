영상 핸들의 수명

close는 이 ZImage가 소유한 핸들을 해제합니다. 반환값은 None이며 반복 호출은 안전합니다. 닫힌 뒤에는 그 영상으로 픽셀을 읽거나 새로운 영상 연산을 실행할 수 없으므로 필요한 처리와 복사를 먼저 마칩니다.

공유와 독립 복사

share로 얻은 핸들은 같은 저장소를 공유하는 별도 소유 핸들이고 clone_deep은 독립적인 픽셀 복사입니다. 각각의 객체를 사용한 뒤 해당 수명 규칙에 맞게 닫아야 합니다. with 구문을 사용하면 블록을 벗어날 때 영상 핸들을 정리할 수 있습니다.

다른 핸들과의 관계

share로 얻은 영상은 같은 저장소를 가리키는 별도 소유 핸들입니다. 한 객체를 닫는 동작과 모든 공유 핸들을 정리하는 일은 구분합니다. 이미 닫힌 객체를 다시 쓰지 않도록 사용 범위와 종료 시점을 명시합니다.
