InputTransfer.__init__

python 공개 선언
InputTransfer(_kind: zvision._color_advanced.AdvancedTransfer, _exponent: float = 0.0) -> None

입력 색 전달 함수를 나타내는 불변 값입니다. 공개 srgb(), linear(), gamma(exponent) 팩터리를 사용하면 방식과 인자를 명확히 지정할 수 있습니다.

_kind: AdvancedTransfer 방식 열거값.

_exponent: GAMMA 방식의 지수; 기본 0.0이며 실제 색 변환에서 유효성을 검사합니다.

이 호출의 입력과 객체 맥락

InputTransfer._kind: 내부 AdvancedTransfer 종류: sRGB, 선형 또는 gamma. srgb(), linear(), gamma()로 구성할 수 있음.

InputTransfer._exponent: gamma 전달 함수의 지수; gamma 방식 사용 시 유한한 양수. 기본 0.0은 비감마 생성자의 저장값.

사용 순서와 판독

InputTransfer는 입력 RGB의 전달 방식 선택을 나타내며, 값 자체를 생성하는 것만으로 영상을 변환하지 않습니다. 공개 팩터리를 사용하면 방식과 지수를 호출부에서 읽기 쉽게 표시할 수 있습니다.

srgb()는 sRGB, linear()는 선형, gamma(exponent)는 지정 감마 방식을 선택합니다. 감마로 사용하는 지수는 실제 색 변환의 유효성 조건을 따라야 합니다. 비감마 팩터리에서 저장되는 0.0을 감마 지수로 해석하지 마세요.

예를 들어 같은 RGB 수치라도 입력이 sRGB로 부호화되었는지 이미 선형인지에 따라 변환에서 적용할 전달 함수가 달라집니다. 따라서 입력을 만든 장치나 파일의 색 처리 조건에 맞는 팩터리를 선택해야 합니다. 이 객체가 불변 설정이라는 점과 변환 결과로 반환되는 영상의 별도 수명을 구분하세요.
