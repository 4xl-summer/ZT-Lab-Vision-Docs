ControlledEccResult(format: zvision._recognition_advanced.ControlledEccFormat, text: str, version: int, error_correction_level: str | None, correction_enabled: bool, blocks: tuple, corrected_codewords: int, accepted: bool)

format: 판독한 코드가 QR인지 Data Matrix인지 나타내는 열거값입니다.

text: 디코딩된 텍스트입니다.

version: 디코더가 읽은 심볼 버전 번호입니다.

error_correction_level: QR의 오류 정정 레벨 문자열이며 Data Matrix에서는 None입니다.

correction_enabled: 코드워드 오류 정정 실행 여부입니다.

blocks: 블록별 데이터·패리티·정정 코드워드 수를 담은 튜플입니다.

corrected_codewords: 모든 블록에서 정정한 코드워드 수의 합입니다.

accepted: 각 블록의 정정 코드워드 수가 지정된 블록당 한도를 만족하면 참입니다.

이 호출의 입력과 객체 맥락

읽은 QR 또는 Data Matrix 형식과 텍스트, 심볼 버전, 오류 정정 상태를 담습니다. blocks는 각 블록의 데이터·패리티·정정 코드워드 수이며 corrected_codewords는 정정 수의 합입니다. accepted는 지정된 블록당 한도를 만족했는지 뜻합니다. QR 오류 정정 레벨 문자열은 Data Matrix에서 None일 수 있으므로 형식별로 읽어야 합니다. 텍스트가 존재한다는 사실과 한도 판정은 별개입니다.
