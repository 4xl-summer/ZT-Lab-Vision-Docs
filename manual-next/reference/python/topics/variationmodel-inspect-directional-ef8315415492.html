inspect_directional(self, image, options)

모델 기준의 상하 허용 경계와 어두운·밝은 결함을 계산합니다.

확인된 인자 조건

image: 모델 템플릿과 호환되는 영상.

options: VariationInspectOptions의 허용치.

반환: 호출자가 close할 VariationDirectionalResult 소유 객체입니다.

오류: 닫힌 객체, 부적합 입력 또는 한도 초과 시 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Return lower/upper thresholds and dark/bright defect masks.

인자별 입력 조건

인자형식역할과 조건
image모델 템플릿과 호환되는 영상.
optionsVariationInspectOptions의 허용치.

밝고 어두운 편차 분리

검사 영상과 VariationInspectOptions로 방향별 변동 검사를 수행합니다. 결과에서 lower_threshold와 upper_threshold, darker_mask와 brighter_mask를 각각 획득할 수 있어 기준보다 어두운 변화와 밝은 변화를 나눠 살핍니다.

결과 객체와 네 영상은 각각 소유 자원이므로 각자 사용이 끝나면 close합니다. 같은 위치의 하한·상한과 입력값을 비교하고 마스크를 해석해야 어떤 방향으로 벗어났는지 알 수 있습니다. 정렬이나 모델 학습 자체를 수행하는 호출은 아닙니다.
