inspect_quality(self, training, image, options, fill_left=None, fill_right=None, world=None, world_maps=None)

훈련 기준과 현재 비드의 폭·명암·점유율·에지 변화를 비교합니다.

확인된 인자 조건

training: 학습에 사용된 기준 ZImage

image: 검사 ZImage

options: BeadQualityOptions

fill_left: 탐침별 왼쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None

fill_right: 탐침별 오른쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None

world: 선택적 6개 아핀 계수; 기본값 None

world_maps: 선택적 세계 좌표 영상 2개; 기본값 None, world와 동시 사용 불가

반환: 별도로 close할 BeadQualityResult입니다.

오류: 영상, 옵션·대체 배열 또는 상호 배타적인 세계 보정이 유효하지 않으면 오류입니다.

Compare bead width, intensity, coverage and edge movement.

비드 품질 검사

학습 영상과 검사 영상, 품질 옵션 및 선택적 좌우 포함 배열을 사용해 폭, 밝기, 적용 범위와 에지 이동을 비교합니다. world 또는 world_maps를 지정하면 좌표 해석에 사용됩니다.

선택 배열의 순서가 경로 탐침과 일치하는지 확인합니다. 픽셀과 세계 좌표의 길이를 섞지 말고 반환 품질 결과는 소유 객체로 사용 후 close합니다. 모델 학습과 품질 평가는 별도 단계입니다.
