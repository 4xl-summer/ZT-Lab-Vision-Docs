ShapeCollectionItem(id: int, match: zvision._matching_advanced.AdvancedMatch) -> None

Model ID and immutable copied advanced shape match.

id: 매치를 산출한 모델 항목의 식별자입니다.

match: 해당 모델이 산출한 독립 AdvancedMatch 값입니다.

값을 구성하고 해석하기

형상 모델 컬렉션에서 반환된 한 매치로, id는 모델 항목 식별자이며 match는 해당 모델이 산출한 AdvancedMatch 값입니다. match의 위치·각도·축 배율과 점수를 읽어 실제 포즈를 해석합니다. id는 검색 결과의 순번이 아니라 호출자가 입력한 모델 id입니다.

생성할 때 확인할 값

인자값의 의미
id매치를 산출한 모델 항목의 식별자입니다.
match해당 모델이 산출한 독립 AdvancedMatch 값입니다.

모델 식별과 검출 포즈

id는 반환 배열의 몇 번째 항목이라는 뜻이 아니라 검색 입력에서 지정한 모델 식별자입니다. 결과 순서가 달라지더라도 입력 항목의 id와 연결해 어떤 형상 모델이 후보를 만들었는지 확인합니다.

match에는 실제 검출 포즈와 점수가 있습니다. position은 검색 ROI 로컬 모델 기준점이고 global_position에는 영상 원점이 반영됩니다. 예를 들어 로컬 위치 (3,4), ROI 원점 (10,20)이면 전역 위치는 (13,24)입니다.

항목확인할 내용
id입력 형상 모델의 식별자
match.position검색 ROI 로컬 기준점
match.global_position영상 원점이 반영된 위치
