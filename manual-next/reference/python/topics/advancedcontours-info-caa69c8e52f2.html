선택 결함의 기하·대비 진단을 조회합니다.

결함의 기하·대비 진단

defect 인덱스로 선택한 결함의 AdvancedDefectInfo를 얻습니다. 기하와 대비는 서로 다른 측정이므로 필드별 단위와 입력 좌표 기준을 확인합니다. 범위 밖 인덱스나 유효하지 않은 결과는 오류입니다.

해석

선택한 결함의 마스크와 경계를 원본 영상에 표시하고 진단값을 함께 봅니다. 숫자 하나만으로 결함의 원인을 확정하지 말고 조명, 분할과 ROI가 계산에 미친 영향을 별도로 확인합니다.

원본과 비교

defect 인덱스로 읽은 진단은 선택한 결함의 결과입니다. 같은 인덱스 숫자를 다른 검사 실행에 그대로 대응시키지 말고 원본 마스크와 경계를 표시해 기하 및 대비 수치가 어떤 영역을 설명하는지 확인합니다.
