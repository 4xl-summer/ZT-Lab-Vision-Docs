execute(self) -> 'QueryExecution[ProfileResult]'

지연 계획을 실행합니다.

반환: 소유 QueryExecution의 output에 독립 ProfileResult 스냅샷; 실행은 close 필요.

오류: 닫힌 계획 또는 유효하지 않은 영상·설정은 오류.

반환 타입 주석: QueryExecution[ProfileResult]

계획을 실행하고 불변 샘플을 반환한다.

사용과 결과 판독

계획된 프로파일을 실행하여 위치·거리·강도 표본의 독립 스냅샷을 담은 실행 결과를 만듭니다. 반환된 실행 객체는 사용 후 해제해야 하며 표본 스냅샷과 소유 실행의 수명을 구분합니다. 선분을 반대로 설정하면 같은 위치의 순서와 시작점 거리가 달라집니다. 실패한 실행을 강도 0인 표본으로 바꾸지 마십시오.
