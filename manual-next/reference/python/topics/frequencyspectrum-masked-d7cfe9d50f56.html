FrequencySpectrum.masked 공개 계약

masked

method · 선언 타입 zvision._frequency_processing.FrequencySpectrum

Python
masked(self, weights)

실수 가중치를 복소 실수·허수 양쪽에 적용합니다.

확인된 인자 조건

weights: 스펙트럼 픽셀 수와 같은 길이의 유한 가중치

반환: 별도 소유 스펙트럼입니다.

오류: 길이 불일치나 비유한 가중치는 오류입니다.

인자 선언

  • weights · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

복소 성분에 가중치

실수 weights를 각 주파수 위치의 복소 실수부와 허수부 양쪽에 곱합니다. 예를 들어 3+4i에 0.5를 적용하면 1.5+2i가 됩니다. 같은 가중치가 두 성분에 적용되므로 진폭도 그 배율의 영향을 받습니다.

길이와 수명

weights는 스펙트럼 픽셀 수와 같은 길이의 유한 값이어야 합니다. 길이가 다르거나 비유한 값이면 오류입니다. 반환 스펙트럼은 별도 소유 객체이며 역변환 결과를 원본과 비교한 뒤 각각 닫습니다.
