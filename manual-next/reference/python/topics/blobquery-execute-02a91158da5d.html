execute

method · 선언 타입 zvision._query.BlobQuery

Python
execute(self) -> 'QueryExecution[BlobAnalysisResult]'

종료 계획을 실행해 타입 지정 결과를 얻습니다.

반환: close할 실행 객체와 독립 값 스냅샷입니다.

오류: 연산이 실패하면 오류입니다.

반환 타입 주석: QueryExecution[BlobAnalysisResult]

계획을 실행하고 불변 블롭을 반환한다.

블롭 분석 계획 실행

where 또는 order_by 등으로 구성한 종료 계획을 실행하여 QueryExecution[BlobAnalysisResult]를 얻습니다. 계획을 만들었다는 사실과 실제 성분 분석 성공은 다르며 실행 중 오류가 발생할 수 있습니다.

스냅샷과 수명

결과의 불변 블롭 스냅샷에서 성분 값을 읽고 실행 객체는 close합니다. 면적과 ROI 로컬 좌표를 입력 마스크의 위치 기준과 함께 해석합니다. 정렬 순번을 다른 프레임에서 같은 물체의 영구 ID로 사용하지 않습니다.
