사용 조건과 결과 판독

AdvancedMetric은 Lab 색 거리 방식 kind와 정확히 9개 숫자의 parameters를 담는 불변 설정값입니다. 생성 시 kind를 AdvancedMetricKind로 변환하고 계수는 float 튜플로 복사합니다. 기본 튜플은 0.0이 아홉 개이지만 모든 거리 방식에 그 조합이 유효하다는 의미는 아닙니다.

예를 들어 CIE76과 CIE94는 같은 Lab 색을 비교해도 거리 방식과 필요한 계수의 의미가 다릅니다. 색상 비교 결과를 저장할 때 kind와 그 방식에 사용한 계수를 함께 기록해야 같은 숫자를 다른 방식의 거리와 혼동하지 않습니다. 길이가 9가 아닌 parameters는 생성 시 오류입니다.

이 값은 match_advanced 또는 distance_advanced의 metric 입력으로 쓰입니다. 방식별 계수 조건은 실제 거리 연산에서 검증되므로 객체가 만들어졌다는 사실만으로 호출 성공을 보장하지 않습니다. 이 설정은 이미지나 색 거리 결과의 소유 핸들이 아닙니다.
