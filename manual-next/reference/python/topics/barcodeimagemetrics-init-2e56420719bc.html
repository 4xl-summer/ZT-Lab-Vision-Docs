BarcodeImageMetrics(minimum: int, maximum: int, mean: float, standard_deviation: float) -> None

Full visible input intensity statistics, not symbol verifier metrics.

minimum: 입력 영상의 최소 Gray8 픽셀 값입니다.

maximum: 입력 영상의 최대 Gray8 픽셀 값입니다.

mean: 입력 영상 픽셀 강도의 평균입니다.

standard_deviation: 입력 영상 픽셀 강도의 표준편차입니다.

입력과 결과 해석

여러 바코드 스캔에서 입력으로 보인 전체 영상의 밝기 통계입니다. minimum과 maximum은 최소·최대 픽셀 값, mean은 평균, standard_deviation은 표준편차입니다. 이 값들은 바코드 기호만 잘라서 계산한 표준 검증기 품질 등급이 아닙니다.

예를 들어 입력 영상 전체의 최소가 20이고 최대가 220이면 전체 보이는 영역의 밝기 폭은 200입니다. 이 숫자는 배경과 다른 물체도 포함할 수 있으므로 특정 심볼의 인쇄 대비로 자동 해석하지 않습니다. 조명이나 노출이 달라진 입력 사이의 분포를 살피는 데 사용할 수 있습니다.
