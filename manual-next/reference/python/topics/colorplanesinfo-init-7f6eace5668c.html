ColorPlanesInfo(space: zvision._color.ColorSpace, width: int, height: int, origin_x: int, origin_y: int)

space: 색 평면의 HSV 또는 Lab 색 공간입니다.

width: 평면 너비(픽셀)입니다.

height: 평면 높이(픽셀)입니다.

origin_x: 영상 전역 원점의 x 좌표입니다.

origin_y: 영상 전역 원점의 y 좌표입니다.

입력과 결과 해석

색 평면 결과의 공간과 격자를 설명하는 값 스냅샷입니다. space는 HSV 또는 Lab을 나타내며 width와 height는 평면의 픽셀 크기입니다. origin_x와 origin_y는 결과가 이어받은 전역 원점을 나타냅니다. 이 정보는 채널에 어떤 의미를 부여하고 어느 위치에 표시할지를 판단하는 데 사용하며, 각 채널의 실제 픽셀 값 자체를 담고 있지는 않습니다.

색 변환 결과에서 첫 번째 평면을 획득하면 해당 영상은 결과와 별도의 소유 핸들입니다. 사용 후 채널 영상과 평면 결과를 각각 닫아야 합니다. 이미 획득한 영상의 로컬 (0,0)이 부모 전체 영상의 (0,0)이라고 단정하지 말고 이 정보의 origin을 함께 읽습니다. ROI에서 변환한 경우 특히 로컬 좌표와 전역 위치를 구별해야 합니다.
