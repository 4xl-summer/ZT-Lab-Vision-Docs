to_buffer_grayf32(self)

Return an independent, writable flat float32 buffer.

부동소수 표본의 독립 버퍼

GrayF32의 쓰기 가능한 독립적인 평탄 float32 버퍼를 반환합니다. 폭 2, 높이 2의 영상이라면 네 개의 보이는 표본이 있으며 각 숫자는 32비트 부동소수로 해석합니다. 바이트 수와 숫자 표본 수는 서로 다른 단위입니다.

결과 검증

원본의 픽셀 형식과 반환 버퍼 형식이 맞는지 확인하고 음수나 소수 등 작은 표본의 값을 비교합니다. 반환 버퍼는 독립적이므로 영상 저장소의 빌린 참조로 취급하지 않습니다. 이미지 핸들의 수명과 버퍼 사용은 각각의 계약을 따릅니다.

숫자 배열의 해석

폭 3, 높이 2이면 출력에는 6개의 보이는 float32 표본이 있습니다. 예를 들어 −1.0과 0.5는 각각 별도의 숫자 원소입니다. 원시 바이트 길이를 원소 개수로 오해하지 말고 형식과 배치를 확인합니다.
