train(cls, template, reference, sample_step=1, threshold=None, mask=None)

표본화한 템플릿 기울기로 확장 형상 모델을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 ZImage입니다.

reference: 유한한 템플릿 로컬 Point2 기준점이며 영상 밖도 가능합니다.

sample_step: 양의 표본 간격(픽셀)이며 기본값 1입니다.

mask: 같은 크기·원점의 선택 Gray8 마스크입니다.

threshold: 유한한 비음수 기울기 임계값 또는 자동 선택 None입니다.

반환: 호출자가 닫아야 하는 독립 형상 모델입니다.

오류: 형식, 임계값 또는 선택 특징점이 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 None
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Train from image gradients; None selects automatic thresholding.

호출 맥락과 결과 해석

템플릿의 기울기를 표본화해 확장 형상 모델을 만듭니다. reference는 템플릿 로컬 좌표의 유한한 Point2이며 영상 밖의 점도 지정할 수 있습니다. 결과 포즈는 이 기준점을 기준으로 해석하므로 검색 후 표시할 위치를 고려해 정합니다.

sample_step은 양의 픽셀 간격이고 threshold는 유한한 비음수 또는 자동 선택 None입니다. 마스크를 주면 템플릿과 크기 및 원점이 같은 Gray8 영상을 사용합니다. 생성된 모델은 독립 소유 객체이므로 검색을 마친 뒤 호출자가 닫습니다.
