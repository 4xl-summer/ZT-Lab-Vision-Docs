RegionalScale(mean_length: float, mean_area: float, x: float, y: float, width: float, height: float, unit: object, samples: int) -> None

Approximate area-equivalent mean length and area scales over a pixel rectangle.

mean_length: 표본의 sqrt(|det J|) 평균으로, 면적 등가 길이 배율입니다.

mean_area: 표본의 |det J| 평균 면적 배율입니다.

x: 샘플 영역의 전역 픽셀 x입니다.

y: 샘플 영역의 전역 픽셀 y입니다.

width: 샘플 영역의 픽셀 폭입니다.

height: 샘플 영역의 픽셀 높이입니다.

unit: 보정의 길이 단위입니다.

samples: 사용된 표본 수입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
mean_length표본의 sqrt(|det J|) 평균으로, 면적 등가 길이 배율입니다.필수
mean_area표본의 |det J| 평균 면적 배율입니다.필수
x샘플 영역의 전역 픽셀 x입니다.필수
y샘플 영역의 전역 픽셀 y입니다.필수

unit보정의 길이 단위입니다.필수
samples사용된 표본 수입니다.필수

값의 해석과 사용

표본마다 |det J|가 4이면 평균 면적 배율은 4이고 면적 등가 길이 배율은 2입니다. 값이 위치마다 달라지면 √의 평균과 평균의 √는 일반적으로 다릅니다. 영역은 전역 픽셀 좌표입니다.
