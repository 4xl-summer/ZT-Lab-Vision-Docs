from_points(source, destination)

대응점으로 투영 변환을 피팅합니다.

확인된 인자 조건

source: 유한한 입력 Point2 열, 최소 4개.

destination: source와 동수의 대상 Point2 열.

반환: 새 Homography 값.

오류: 서로 다른 길이·퇴화 배치·비유한 좌표는 오류.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • destination · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

source와 destination은 같은 순서로 대응하는 두 점 집합이어야 하고 길이는 같으며 각각 네 점 이상이어야 합니다. 함수는 대응점을 자동으로 찾거나 이상점을 제거하지 않습니다. 정규화된 좌표에서 8개 미지수의 최소제곱 문제를 QR로 풀어 사영 변환을 추정합니다. 중복이나 공선성으로 제약이 부족한 집합은 실패합니다. 계산 결과를 실제 사용할 때는 피팅과 별개의 대응점으로 오차를 확인하고 같은 좌표 프레임과 단위를 유지하세요.
