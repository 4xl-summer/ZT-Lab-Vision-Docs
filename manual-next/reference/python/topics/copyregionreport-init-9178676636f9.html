CopyRegionReport(copied: int, clipped: int) -> None

Selected copied and clipped pixel counts.

copied: 대상에 복사된 선택 픽셀 수입니다.

clipped: 대상 영역 밖으로 잘린 선택 픽셀 수입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
copied대상에 복사된 선택 픽셀 수입니다.필수
clipped대상 영역 밖으로 잘린 선택 픽셀 수입니다.필수

값의 해석과 사용

copied는 실제 복사한 선택 픽셀 수, clipped는 대상 경계 밖으로 잘린 선택 픽셀 수입니다. 5개 선택 위치 중 3개만 대상에 들어가는 사례는 위치와 잘림을 구분해 검토하는 데 유용합니다.

복사된 픽셀과 잘린 픽셀

copied는 목적 영상에 실제 복사된 선택 픽셀 수이고 clipped는 목적 영역 밖으로 잘린 선택 픽셀 수입니다. 두 값은 바이트 수가 아닙니다. 선택 마스크와 원본·대상 ROI의 좌표 기준을 확인해야 어떤 위치가 이 숫자에 들어갔는지 알 수 있습니다.

항목의미와 사용
copied대상에 실제 복사된 선택 픽셀
clipped대상 밖으로 잘린 선택 픽셀
단위픽셀 수
원본 ROI선택할 위치의 로컬 기준
대상 ROI배치 위치와 경계
결과 확인보고 값과 대상 픽셀을 함께 비교

예를 들어 선택 픽셀 5개 중 3개가 목적 영역 안에 있고 2개가 밖에 있다면 복사와 잘림을 각각 살펴볼 수 있습니다. 일부 잘림을 허용하는지 여부는 복사 옵션에 따릅니다. 보고 값만으로 복사된 색이나 밝기를 알 수 없으므로 대상 영상도 확인합니다.
