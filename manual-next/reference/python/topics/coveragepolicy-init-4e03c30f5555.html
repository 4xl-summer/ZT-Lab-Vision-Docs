CoveragePolicy(reference: float, minimum_fraction: float) -> None

Reference length or angle and minimum covered fraction.

reference: 기준 길이 또는 원호 각도; 유한한 양수. 원은 2π 라디안 이하.

minimum_fraction: 필요한 최소 커버 비율; 유한한 0–1.

이 호출의 입력과 객체 맥락

직선 또는 원 측정에서 확보한 관측 범위를 기준 범위와 비교하는 설정입니다. reference는 비교 기준 길이 또는 각도이고 minimum_fraction은 요구하는 최소 커버리지 비율입니다. 직선의 기준 길이는 해당 측정 좌표 단위로, 원의 기준 각도는 라디안으로 해석해야 하므로 서로 숫자를 바꾸어 넣어서는 안 됩니다.

예를 들어 기준 길이가 100이고 측정에 실제로 포함된 범위가 70이면 비율은 0.7입니다. 최소 비율을 0.8로 지정했다면 유효한 선이 적합되더라도 최종 커버리지 판정은 거절될 수 있습니다. 이 비교는 점의 개수만 세는 대신 기하적으로 얼마나 덮였는지를 확인합니다.

관측 범위의 기준

CoveragePolicy는 reference와 minimum_fraction으로 측정된 관측 범위가 기준의 어느 정도를 덮어야 하는지 정합니다. reference는 유한한 양수이며 직선에서는 기준 길이, 원에서는 기준 각도입니다. 원의 기준 각도는 최대 2π 라디안입니다.

minimum_fraction은 유한한 0–1 사이 비율입니다. 기준 길이가 100이고 실제 관측 범위가 70이면 비율은 0.7입니다. 최소 비율이 0.8이라면 피팅이 계산되더라도 커버리지 요구를 충족하지 못합니다. 점 개수와 덮인 길이는 같은 값이 아닙니다.

직선측정 좌표계의 길이 단위

원 측정에서는 각도 범위를 라디안으로 사용하고 직선 길이는 입력 좌표의 단위로 해석합니다. 비교할 때 reference의 단위와 관측 결과를 맞추고 피팅 상태·잔차·커버리지 판정을 함께 기록합니다. 값이 범위를 벗어나거나 비유한 경우는 사용 계약의 오류 조건을 확인합니다.
