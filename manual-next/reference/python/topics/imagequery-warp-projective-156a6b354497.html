warp_projective(self, matrix, width, height, interpolation, border)

기하 변환 단계를 현재 계획에 추가합니다.

확인된 인자 조건

interpolation: 보간 방식

border: 바깥 샘플에 사용할 값

matrix: 변환 행렬

width: 양의 출력 폭

height: 양의 출력 높이

반환: 수정된 ImageQuery입니다.

오류: 행렬, 크기 또는 보간 인자가 유효하지 않으면 오류입니다.

인자 선언

  • matrix · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • interpolation · POSITIONAL_OR_KEYWORD · 기본값 없음
  • border · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

투영 변환 계획

투영 행렬을 사용해 현재 영상을 지정한 폭과 높이로 재표본화합니다. 투영 관계는 위치에 따라 배율이 달라질 수 있으므로 단순한 평행 이동과 구분합니다. 행렬 방향과 좌표 기준을 먼저 확인해야 합니다.

경계와 수치

interpolation 및 border는 원본의 샘플과 영역 밖 값을 결정합니다. 투영 분모가 불안정한 위치나 부적절한 행렬은 오류가 될 수 있으므로 기준점으로 결과를 검증합니다. 출력 영상의 소유권은 실행 결과 계약을 따릅니다.
