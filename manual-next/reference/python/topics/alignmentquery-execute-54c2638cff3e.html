execute(self) -> 'QueryResourceExecution[AlignmentResult]'

지연 검사 계획을 실행합니다.

반환: QueryResourceExecution; acquire_output으로 얻은 AlignmentResult와 실행을 각각 닫습니다.

오류: 닫힌 계획 또는 네이티브 실행 실패 시 오류입니다.

반환 타입 주석: QueryResourceExecution[AlignmentResult]

Execute; acquire_output returns an independently owned alignment.

이 호출의 입력과 객체 맥락

지연 정렬 계획을 실행해 QueryResourceExecution을 반환합니다. 열린 실행에서 acquire_output으로 AlignmentResult를 별도 소유 핸들로 얻어 정렬 정보와 마스크를 확인합니다. 실행을 닫는 것과 취득한 AlignmentResult를 닫는 것은 별도이므로 둘 다 close합니다. 결과에서 따로 얻은 영상도 해당 영상의 소유권을 관리하세요.

정렬 계획 실행

AlignmentQuery의 execute는 정렬 계획을 실행해 QueryResourceExecution<AlignmentResult>를 반환합니다. 실행 객체에서 독립 소유 정렬 결과를 획득하며 실행과 결과는 각각 close해야 합니다.

결과의 found를 먼저 확인합니다. 참이면 변환 및 aligned와 valid_mask를 해당 반환 계약에 따라 읽고, 거짓이면 정렬이 성립하지 않은 상태로 분기합니다. 미발견을 후보가 없는 정상 차분으로 바꾸지 않습니다.

예를 들어 5×5 기준 격자의 25개가 모두 표본 가능하면 valid_count는 25입니다. 실제 비교에 사용할 유효 마스크와 좌표 원점을 함께 확인한 다음 차분을 실행합니다. 획득한 영상도 각각 close합니다.

정렬 결과의 변환과 영상은 같은 입력 프레임을 기준으로 해석해야 합니다. ROI 로컬 좌표와 기준 영상 원점이 다른 경우 반환 변환의 전역 기준을 확인하고 원점을 중복 적용하지 않습니다.

Found가 참이어도 valid_count가 기준 전체 픽셀 수보다 작을 수 있습니다. 유효 마스크를 차분의 포함 영역으로 연결하고, 검사에 포함된 픽셀 수가 바뀌었다면 통계의 범위도 바뀐 것을 기록합니다.
