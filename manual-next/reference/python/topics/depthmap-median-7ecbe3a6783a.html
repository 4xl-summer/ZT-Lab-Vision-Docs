DepthMap.median 공개 계약과 사용

깊이 격자의 중앙값 필터

DepthMap.median(kernel, min_valid)은 직교 깊이 격자에서 각 유효 중심 주변의 유효 깊이만 모아 중앙값을 구합니다. 단발성 극단값을 줄일 때 사용할 수 있지만 결측을 채우는 연산은 아닙니다. 입력은 이미지 Query가 아니라 단위와 frame을 가진 DepthMap이어야 합니다. 결과는 별도 저장소를 소유하므로 원본과 결과를 각각 닫습니다.

kernel은 셀 단위 창의 한 변으로 양의 홀수이고, min_valid는 1 이상 kernel² 이하의 최소 유효 이웃 수입니다. 창이 격자 경계를 넘으면 바깥 셀은 제외합니다. 유효 중심이라도 조건을 만족할 만큼 이웃이 없으면 그 출력은 결측입니다. 입력 중심이 결측이면 이웃이 충분해도 결측을 유지합니다.

표본 수가 홀수이면 정렬된 가운데 값이 중앙값입니다. 짝수이면 가운데 두 값의 평균을 사용합니다. 예를 들어 이웃 값이 1, 2, 8, 9라면 중앙값은 5입니다. 실제 결과에서는 경계와 결측으로 이웃 집합이 달라질 수 있으므로 필터 창의 전체 크기만 보고 유효 표본 수를 가정하지 않습니다.

호출과 결과 확인

다음은 이미 생성한 depth를 사용하는 호출 단편입니다. 3×3 창과 최소 유효 이웃 4개를 지정하며, 반환 객체의 값은 to_values()로 복사해 결측 여부를 확인합니다. 이 단편은 장비 측정 예제가 아닙니다.

Python
with depth.median(kernel=3, min_valid=4) as filtered:
    values = filtered.to_values()

짝수 또는 0인 커널, 범위를 벗어난 유효 이웃 조건은 허용되지 않습니다. 닫힌 입력을 사용하거나 네이티브 연산이 실패한 경우에도 결과를 사용할 수 없습니다. 결측 중심을 원본 이웃의 중앙값으로 채우려는 목적이라면 별도의 fill_holes를 선택합니다. 두 연산을 연결할 때 중간 결과도 소유 객체이므로 수명을 명시해야 합니다.
