지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음

Return an independently owned stationary Haar transform.

정지 Haar 변환

stationary_haar는 지정한 levels의 정지 Haar 변환을 반환합니다. 일반적인 다단 분해의 개념에서 저주파 정보와 변화 정보를 나누지만, 계수의 크기와 배치는 이 결과 타입의 실제 계약에 따라 읽어야 합니다.

입력과 결과

입력 형식과 단계 수 조건이 유효한지 확인하고 결과의 밴드 및 역변환 API를 사용합니다. 변환 결과는 별도 소유 객체로 작업 후 close합니다. 원본과 복원 결과를 비교할 때는 같은 단계 수와 입력 범위를 기록합니다.
