MeasurementCircle2(center: zvision._regions.Point2, radius: float) -> None

Circle center and positive radius in the same coordinate units.

center: 원의 유한한 중심 Point2.

radius: 유한한 양의 반경; 좌표 단위.

계산과 결과 해석

기하 관계 계산에 사용하는 2차원 원을 중심과 반경으로 표현합니다. center는 유한한 Point2이고 radius는 같은 좌표 단위의 양수입니다. 영상에서 추출한 원이라면 두 값이 ROI 로컬 픽셀인지 세계 좌표인지 기록해 다른 프레임의 원과 섞지 않도록 해야 합니다. 예를 들어 중심 (0,0), 반경 2이면 (2,0)은 원 경계 위입니다. 이 타입은 두 원의 부호 간격이나 교차 상태를 계산할 때 입력으로 쓰이며 원을 영상에서 찾는 프로브 설정 자체는 포함하지 않습니다. 두 원의 중심 간 거리에서 반경 합을 뺀 값은 겹치거나 포함되는 경우 음수일 수 있으므로 음수만으로 결측이라고 해석하지 마십시오. 유효하지 않은 반경이나 비유한 중심은 호출 오류로 다룹니다. 예를 들어 중심 (0,0), 반경 2의 원과 중심 (5,0), 반경 1의 원은 중심 간 거리가 5입니다. 둘레의 바깥쪽 간격은 5−2−1로 2입니다. 같은 수치로 비교하려면 두 원이 같은 기준 영상과 동일한 길이 단위를 사용해야 합니다. 반경은 중심에서 원 경계까지의 거리이며 전체 지름은 그 두 배입니다. 두 형상의 입력 좌표가 동일한 원점 기준인지 먼저 확인합니다. 중심과 반경의 단위가 일치하는지도 확인합니다.

단계별 확인

이 원은 영상에서 에지를 검색하는 모델이 아니라 기하 관계의 입력입니다. 중심과 반경은 같은 좌표계와 길이 단위로 나타내며 반경은 양수입니다.

중심 (0,0), 반경 2인 원의 경계에는 (2,0)과 (0,2)가 놓입니다. 중심 (5,0), 반경 1인 다른 원과 비교하면 중심 간 거리는 5이고 바깥쪽 둘레 간격은 5−2−1=2입니다. 다른 ROI의 중심을 비교하기 전에는 원점을 맞추십시오.
