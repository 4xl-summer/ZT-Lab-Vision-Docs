histogram(self, bin_count=None, lower=None, upper=None)

히스토그램 종료 계획을 만듭니다.

확인된 인자 조건

bin_count: 균등 빈 수; 세 인자를 모두 생략할 수 있음

lower: 값 범위 하한; 기본값 None

upper: 값 범위 상한; 기본값 None

반환: HistogramQuery입니다.

오류: 범위 인자를 일부만 넣거나 범위가 유효하지 않으면 오류입니다.

인자 선언

  • bin_count · POSITIONAL_OR_KEYWORD · 기본값 None
  • lower · POSITIONAL_OR_KEYWORD · 기본값 None
  • upper · POSITIONAL_OR_KEYWORD · 기본값 None

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

계획 결과의 분포

현재 계획의 영상에 대한 히스토그램 분석을 지정합니다. 빈도는 선택한 값 범위와 빈 수, 채널에 따라 해석되며 픽셀의 공간 위치를 보존하지 않습니다. 같은 평균을 가진 영상도 밝기 분포가 다를 수 있습니다.

실행과 빈 비교

반환되는 분석 쿼리와 실행 결과 타입을 확인한 후 각 채널의 빈을 읽습니다. 빈 개수가 같더라도 범위가 다르면 같은 인덱스가 같은 밝기를 나타내지 않습니다. 입력 ROI와 전처리 단계를 같이 기록합니다.
