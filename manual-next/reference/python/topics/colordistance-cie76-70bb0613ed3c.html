CIE76 색 거리 선택

Lab 좌표의 유클리드 거리를 사용하는 선택을 만듭니다. 예를 들어 L 차이가 3, a 차이가 4이고 b가 같으면 거리는 5입니다. 별도 가중 매개변수는 받지 않습니다.

동일한 백색점 및 관측 조건에서 얻은 좌표를 비교합니다. CIE76의 5와 다른 색차 척도의 5가 같은 지각적 차이를 의미한다고 가정하지 않습니다.

CIE76의 계산과 적용

CIE76은 두 Lab 값의 각 성분 차이에 대해 제곱의 합에 제곱근을 취합니다. 예를 들어 차이가 (3, 4, 0)이면 √(9+16)=5입니다. 메서드는 이 계산을 즉시 실행하지 않고, 이후 색 비교에 전달하는 거리 설정 값을 구성합니다.

이 거리에는 이 팩터리에서 추가 가중치를 전달하지 않습니다. 다른 CIE94나 CIEDE2000은 별도 계수와 계산을 사용하므로 같은 허용 숫자를 모든 방식에 자동 적용하지 않습니다. 어떤 거리와 백색점을 사용했는지 결과 옆에 기록합니다.

기준색과 검사색은 같은 관측 조건과 백색점으로 만든 Lab 좌표여야 비교가 의미 있습니다. 먼저 색 변환 조건을 확인하고, 거리 설정을 지정한 뒤 비교 결과를 공정별 허용치와 대조합니다. 설정 객체 자체가 이미지나 소유 결과 핸들은 아닙니다.
