DeformableModelReport(matches: tuple, evaluated: int, termination: zvision._matching_advanced.AdvancedTermination)

matches: 변형 모델 검색의 독립 불변 결과 튜플입니다.

evaluated: 전체 모델 은행에서 평가한 포즈 수입니다.

termination: 완료, 후보 예산, 시간 제한, 조기 점수 중 종료 이유입니다.

이 호출의 입력과 객체 맥락

변형 모델 은행 전체에서 얻은 매치 튜플과 평가 수, 검색 종료 이유를 담습니다. 각 결과의 variant_index는 학습 입력 변형 목록의 0 기반 위치입니다. matches가 비어도 보고서는 존재할 수 있으며 이때 종료 이유를 읽어 모든 후보를 완료했는지 예산이나 시간 제한에 걸렸는지 분리해야 합니다.

은행의 각 변형은 별도 NCC 모델로 검색되지만 후보 예산과 시간은 은행 전체에서 공유됩니다. 앞쪽 변형이 많은 예산을 사용하면 뒤쪽이 충분히 평가되지 않을 수 있습니다. 반환 결과는 독립 스냅샷이지만 검색의 재현을 위해 변형 순서, 포즈 격자와 예산을 함께 기록하세요. 결과 점수는 모델 일치도이지 실제 물체의 변형을 연속적으로 측정한 수치가 아닙니다.

사용 흐름과 판독 기준

DeformableModelReport는 모델 은행의 검색 결과를 matches 튜플, evaluated 수와 termination으로 묶는 독립 값입니다. 각 매치의 variant_index는 학습 입력 변형 목록의 0 기반 위치이므로 점수와 함께 원래 변형 목록의 순서를 보관해야 어떤 모델의 결과인지 찾을 수 있습니다. 이 생성자는 결과 필드를 담는 값 생성이지 검색을 새로 실행하는 호출은 아닙니다.

예를 들어 세 변형을 [A,B,C]로 학습했다면 variant_index 1은 B입니다. 이를 1부터 시작하는 번호로 읽으면 A와 잘못 연결됩니다. matches가 비어 있어도 보고서는 존재할 수 있으므로 evaluated와 termination을 읽어 후보를 평가했는지, 예산이나 시간 제한으로 중단했는지 구별합니다.

은행의 각 변형은 별도 NCC 모델로 검색되지만 후보 예산과 시간은 전체 은행에서 공유됩니다. 앞선 변형이 예산을 많이 사용하면 뒤쪽 변형의 탐색이 제한될 수 있으므로 빈 매치만으로 모든 변형을 완전히 검증했다고 판단하지 않습니다. 점수는 저장된 모델과의 일치도이며 연속적인 실제 물체 변형량 그 자체가 아닙니다.
