python 공개 선언
JointBundleOptions(unit: object, max_iterations: int, damping: float, gradient_tolerance: float, camera_pose_mask: int, board_pose_mask: int, max_work: int) -> None

Pose-block masks, local LM limits, units and conservative work budget; camera 0 is fixed.

unit: 보드 좌표와 병진이 공유하는 길이 단위.

max_iterations: 외부 반복 상한 1–25.

damping: 초기 감쇠; 유한한 양수.

gradient_tolerance: 기울기 종료 기준; 유한한 양수.

camera_pose_mask: 최적화할 카메라 자세 비트. 0번은 고정이므로 최하위 비트는 0.

board_pose_mask: 최적화할 보드 자세의 비트; 존재하지 않는 보드 비트는 0.

max_work: 계획 작업 상한 1–20,000,000.

이 호출의 입력과 객체 맥락

여러 카메라의 자세, 보드 자세와 Brown 렌즈 계수를 함께 조정할 때 사용하는 설정입니다. unit은 기하 값에 사용하는 길이 단위이고 camera_pose_mask와 board_pose_mask는 조정할 자세 블록을 선택합니다. 기준 프레임을 고정해 해의 자유도를 묶기 위해 카메라 0의 자세는 고정되며 해당 비트를 선택할 수 없습니다.

max_iterations는 반복 상한이고 이 Python 경로에서는 최대 25입니다. damping과 gradient_tolerance는 국소 최적화의 감쇠와 종료 조건을 조절하며 max_work는 허용 계산량을 제한합니다. 관측 수나 선택된 블록이 늘면 작업량도 늘어나므로 예산이 너무 작으면 실제 보정에 도달하기 전에 한도 조건이 나타날 수 있습니다.
