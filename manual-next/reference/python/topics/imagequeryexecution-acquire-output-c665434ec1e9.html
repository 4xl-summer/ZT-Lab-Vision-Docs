acquire_output(self) -> 'ZImage'

실행 출력 영상의 공유 핸들을 취득합니다.

반환: 호출자가 close할 독립 소유 이미지 핸들입니다.

오류: 닫힌 실행 또는 잘못된 이름은 오류입니다.

반환 타입 주석: ZImage

호출자가 닫는 독립 출력 이미지 공유를 반환한다.

출력 영상 공유 획득

실행 출력의 별도 소유 ZImage 공유 핸들을 얻습니다. 결과를 단순한 빌린 참조로 취급하지 말고 호출자가 이 핸들을 close해야 합니다. 실행 객체가 이미 닫힌 상태의 접근은 오류입니다.

사용 순서

이미지 계획을 실행한 뒤 출력 공유를 얻고 필요한 표시나 분석을 수행합니다. 실행 소유권과 획득한 영상 핸들의 수명을 각각 관리합니다. 공유는 픽셀을 깊게 복제한다는 뜻이 아닙니다.
