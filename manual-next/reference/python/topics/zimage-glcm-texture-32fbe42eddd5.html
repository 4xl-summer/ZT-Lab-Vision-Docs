glcm_texture

method · 선언 타입 zvision.ZImage

Python
glcm_texture(self, options, mask=None)

선택된 픽셀 쌍의 공발생 행렬을 계산합니다.

확인된 인자 조건

options: GlcmOptions: 양자화, 오프셋 및 쌍 수 상한.

mask: 선택적 Gray8 포함 마스크. 양 끝 픽셀이 모두 포함되어야 합니다.

반환: GlcmResult 소유 객체이며 close합니다.

오류: 닫힌 객체나 유효하지 않은 인수는 오류입니다.

인자 선언

  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Calculate GLCM features; close the returned GlcmResult.

이웃 쌍의 밝기 분포

GLCM은 지정한 공간 관계에 있는 두 픽셀의 밝기 조합을 집계해 질감 지표를 계산합니다. 같은 히스토그램이라도 픽셀의 공간 배열이 다르면 이웃 쌍의 분포가 달라질 수 있습니다. 따라서 단일 밝기 평균과는 다른 정보를 제공합니다.

설정의 영향

방향, 거리, 밝기 단계 등 호출에서 받는 설정은 비교 조건에 영향을 줄 수 있습니다. 서로 다른 ROI의 질감을 비교할 때 입력 형식과 설정을 맞추고, 영역이 너무 작거나 마스크가 달라지는 상황은 별도로 확인합니다. 결과 수치는 지정된 조건의 요약입니다.
