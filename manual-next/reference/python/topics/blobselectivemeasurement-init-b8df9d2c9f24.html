python 공개 선언
BlobSelectiveMeasurement(area: int, centroid_x: float, centroid_y: float, has_inertia: bool, major_axis: float, minor_axis: float, orientation: float) -> None

Area, centroid and optional inertia-derived axes.

area: 연결 성분의 픽셀 수.

centroid_x: 성분의 ROI 로컬 중심 x.

centroid_y: 성분의 ROI 로컬 중심 y.

has_inertia: 관성 계산을 수행했는지 여부.

major_axis: 관성 기반 장축; 계산하지 않으면 0.

minor_axis: 관성 기반 단축; 계산하지 않으면 0.

orientation: 장축 방향; 계산하지 않으면 0.

계산과 결과 해석

선택적 연결 성분 분석 결과의 면적, 중심과 선택적으로 계산한 관성 축을 담습니다. area는 성분의 픽셀 면적이고 centroid_x, centroid_y는 성분 중심의 영상 좌표입니다. has_inertia는 관성 기반 결과가 있는지 나타내며 major_axis, minor_axis, orientation을 해석하기 전에 이 상태를 확인해야 합니다. 예를 들어 이웃한 픽셀 두 개가 (0,0)과 (2,0)에 있다면 두 위치의 산술 중심은 (1,0)입니다. 이것은 중심을 이해하기 위한 기하 예이며 두 점의 연결 여부는 분석에 사용한 연결 규칙에 달려 있습니다. 관성 계산을 선택하지 않은 결과의 축 숫자를 실제 크기 0인 물체로 취급하지 마십시오. 면적이 픽셀 수라는 사실도 중요합니다. 물리 면적이 필요하면 영상과 보정의 조건에 맞게 별도 변환하고, 단일 길이 배율을 면적에 한 번만 곱하지 않습니다. 다른 ROI에서 얻은 중심을 비교할 때는 각각의 원점을 복원하고 같은 좌표계로 맞춥니다. 결과를 보고할 때 축의 계산 여부와 성분의 입력 조건을 함께 보존해야 다른 실행과 올바르게 비교할 수 있습니다. 성분 중심과 개별 픽셀 위치도 서로 다른 값입니다. 전체 영상에 표시할 때에는 중심이 사용한 ROI 기준이 무엇인지 먼저 확인하십시오.
