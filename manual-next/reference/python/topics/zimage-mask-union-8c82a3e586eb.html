mask_union

method · 선언 타입 zvision.ZImage

Python
mask_union(self, reference)

두 마스크의 합집합을 만듭니다.

확인된 인자 조건

reference: 기준 ZImage 마스크

반환: 새 마스크. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 호환되지 않는 마스크는 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

전경의 합집합

두 입력 마스크 중 어느 쪽이든 전경인 위치를 합칩니다. 첫 마스크가 {A,B}, 둘째가 {B,C}이면 합집합은 {A,B,C}입니다. 합친 뒤 연결 성분 수는 입력별 성분 수의 단순 합과 다를 수 있습니다.

블롭 분석 전 확인

두 마스크의 크기, ROI와 전경 형식을 맞춘 뒤 결과를 확인합니다. 물체 사이를 잇는 전경이 생기면 다음 블롭 분석에서 하나의 객체가 될 수 있으므로 각 입력과 결합 마스크를 함께 살펴봅니다. 반환 영상의 수명은 입력과 별도로 관리합니다.
