world_to_pixel

method · 선언 타입 zvision._calibration.PlanarCalibration

Python
world_to_pixel(self, point, input_unit)

세계 점을 글로벌 픽셀로 역변환합니다.

확인된 인자 조건

point: 세계 Point2.

input_unit: 입력 세계 길이 단위.

반환: 새 글로벌 픽셀 Point2.

오류: 잘못된 타입·단위 또는 역변환 실패는 오류.

인자 선언

  • point · POSITIONAL_OR_KEYWORD · 기본값 없음
  • input_unit · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

사용과 결과 판독

요청 단위로 표현한 세계 좌표를 글로벌 영상 픽셀로 역변환합니다. 예제의 보류 세계점 (12.3,42.4) mm는 해당 합성 매핑에서 픽셀 (113,222)에 해당합니다. 이 결과를 ROI 로컬 좌표로 표시하려면 그 ROI 원점을 별도로 빼야 합니다. 단위를 잘못 지정한 입력과 올바른 세계점을 구분해 기록하고 호출 결과를 확인하십시오.
