PhotometricNOptions(lights: object, min_signal: float, min_rcond: float, spacing_x: float, spacing_y: float, min_normal_z: float, smooth_radius: int, brightness: float, contrast: float, max_work: int) -> None

다조명 형상 추정 설정값입니다. 유효성은 photometric_stereo_n 호출 시 검사합니다.

lights: 입력 영상과 같은 수의 조명 xyz 벡터 3–128개. 각 벡터는 유한한 성분 세 개이며 독립적인 조명 기하가 필요합니다.

min_signal: 법선 추정의 최소 반사 신호로 유한한 0 이상입니다.

min_rcond: 조명 정규 방정식의 역조건수 하한으로 유한한 [0, 1)입니다.

spacing_x: 세계 x 방향 픽셀 간격으로 유한한 양수입니다.

spacing_y: 세계 y 방향 픽셀 간격으로 유한한 양수입니다.

min_normal_z: 곡률 계산에 필요한 법선 z 절댓값의 하한으로 유한한 [0, 1)입니다.

smooth_radius: 법선 평활 반경(픽셀)입니다. 작업량 제한에도 영향을 줍니다.

brightness: 평탄부 출력 밝기 비율로 유한한 [0, 1]입니다.

contrast: 부호 있는 형상 응답의 출력 배율로 유한한 0 이상입니다.

max_work: 평활 등 계산의 양의 작업량 상한입니다.

이 호출의 입력과 객체 맥락

입력 영상과 같은 수의 조명 xyz 벡터 3~128개와 법선·공간 간격·응답 조건을 지정합니다. 조명은 유한한 성분과 독립적인 기하가 필요하며 영상 순서와 벡터 순서를 맞춰야 합니다. spacing_x/y는 세계 길이 단위의 픽셀 간격, smooth_radius는 픽셀입니다. 숫자 영상의 수만 맞는 것으로 조명 기하의 유효성이나 실제 측정 정확도를 보증하지 않습니다.
