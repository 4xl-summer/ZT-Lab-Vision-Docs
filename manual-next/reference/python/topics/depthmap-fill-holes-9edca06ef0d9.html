fill_holes

Python
def fill_holes(self, kernel, min_valid)

kernel은 양의 홀수, min_valid는 1 이상 kernel² 이하입니다. 경계 밖은 제외하고 원본의 유효 이웃으로 결측 중심만 채웁니다. 같은 호출에서 새로 채운 값은 다른 셀에 전파되지 않으며 독립 결과를 반환합니다.

원본의 유효 이웃 중앙값으로 결측 중심만 채웁니다. 새 값은 같은 호출에서 전파되지 않습니다.

확인된 인자 조건

kernel: 양의 홀수 커널 폭, 셀 단위

min_valid: 1 이상 kernel² 이하인 최소 유효 이웃 수

반환: 새 소유 DepthMap; 사용 후 닫습니다.

오류: 유효 이웃 부족은 결측이고 잘못된 옵션은 오류입니다.

결측 깊이 채우기

주변 유효 깊이를 이용해 결측 픽셀을 채우되 이미 유효한 중앙 픽셀은 그대로 둡니다. 커널은 양의 홀수 크기이고 최소 유효 개수는 1부터 커널 면적까지입니다. 경계에서는 영상 밖을 읽지 않고 사용 가능한 이웃만 계산합니다.

원본 이웃이 부족하면 해당 위치는 결측으로 남습니다. 한 번에 새로 채운 값을 다음 결측의 이웃으로 연쇄 전파하는 방식이 아니라 원본 이웃을 기준으로 계산하므로, 큰 구멍이 한 번에 모두 채워진다고 가정하지 않습니다. 채우기 전후의 유효 수와 경계의 값을 비교합니다.

확인 항목해석
kernel양의 홀수인 이웃 창 크기
min_valid채우기에 필요한 원본 유효 표본 수
유효 중심원래 값 유지
결측 중심조건을 만족할 때만 이웃값으로 채움
