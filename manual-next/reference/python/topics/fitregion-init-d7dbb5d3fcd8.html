FitRegion(minimum: zvision._regions.Point2, maximum: zvision._regions.Point2) -> None

Inclusive source-coordinate region.

minimum: 포함되는 입력 좌표계의 최소 모서리입니다.

maximum: 포함되는 입력 좌표계의 최대 모서리입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
minimum포함되는 입력 좌표계의 최소 모서리입니다.필수
maximum포함되는 입력 좌표계의 최대 모서리입니다.필수

값의 해석과 사용

minimum과 maximum은 포함 경계입니다. 최소 (1,2), 최대 (4,6)이면 두 모서리의 점도 영역에 포함됩니다. 점과 영역은 같은 원본 좌표계와 단위를 사용해야 합니다.

포함 경계의 원본 영역

minimum과 maximum은 원본 점 좌표계의 포함되는 최소·최대 모서리입니다. 이미지 배열의 오른쪽 끝을 제외하는 반열림 범위와 혼동하지 않습니다. 두 값은 Point2이며 점들과 같은 좌표 기준과 단위로 전달해야 합니다.

항목의미와 사용
minimum포함되는 최소 모서리
maximum포함되는 최대 모서리
입력 타입두 필드 모두 Point2
경계최소와 최대를 포함
좌표원본 점과 같은 기준
피팅선택 점의 개수·배치 및 잔차 확인

예를 들어 최소 (1,2), 최대 (4,6)인 영역에서는 두 모서리 위의 점도 포함 경계에 놓입니다. ROI 로컬 점과 전체 영상 기준의 영역을 섞으면 선택되는 점이 달라질 수 있습니다. 선택된 점의 분포와 피팅 결과의 잔차를 원본에 함께 표시해 확인합니다.
