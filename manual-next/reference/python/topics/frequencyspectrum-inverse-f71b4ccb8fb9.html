inverse

method · 선언 타입 zvision._frequency_processing.FrequencySpectrum

Python
inverse(self, crop=True)

스펙트럼을 실수 값으로 역변환합니다.

확인된 인자 조건

crop: True면 원래 입력 크기로 자름, 기본값 True

반환: (폭, 높이, 값 튜플)입니다.

오류: crop이 bool이 아니거나 역변환이 실패하면 오류입니다.

인자 선언

  • crop · POSITIONAL_OR_KEYWORD · 기본값 True

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

별칭과 결과 해석

Spectrum은 FrequencySpectrum과 같은 클래스입니다. inverse와 inverse_values는 같은 함수이며 crop=True는 원본 크기, False는 스펙트럼 크기를 사용합니다. 결과는 폭, 높이, 독립 실수 값 튜플이며 영상 핸들이 아닙니다. crop은 bool이어야 하고 스펙트럼 객체는 별도로 close합니다.

역변환의 값

복소 스펙트럼에서 역변환을 계산해 폭, 높이와 값 튜플을 반환합니다. crop=True가 기본값이며 원래 입력 크기로 잘라 결과를 읽습니다. 변환을 위해 사용한 격자 크기와 잘라낸 크기는 다를 수 있습니다.

정규화의 영향

2×2 상수 1의 BACKWARD 정변환에서 직류가 4라면 역변환의 1/4 배율로 각 위치가 1로 복원됩니다. 같은 정규화 규칙과 격자를 사용했는지 확인하고 수치 비교에서는 부동소수 오차를 고려합니다.
