OcrChar(codepoint: int, corners: tuple)

codepoint: 인식된 문자의 Unicode 코드 포인트입니다.

corners: 문자 경계의 좌표 네 점을 로컬과 전역 좌표로 담습니다.

인자별 입력 조건

인자형식역할과 조건
codepoint<class 'int'>인식된 문자의 Unicode 코드 포인트입니다.
cornerstuple[zvision._recognition.RecognitionPoint, ...]문자 경계의 좌표 네 점을 로컬과 전역 좌표로 담습니다.

한 글자와 모서리

codepoint는 글자의 정수 코드 포인트이고 corners는 RecognitionPoint의 튜플입니다. 각 점은 입력 로컬과 전역 위치를 함께 담아 원본 영상의 글자 위치를 표시할 수 있습니다.

모서리 중 잘못된 타입이 있으면 TypeError입니다. 글자 위치가 존재해도 전체 OCR 결과의 상태가 수락인지 따로 확인합니다.
