AdvancedRegistrationOptions(projective: bool = False, mse: bool = True, initial: tuple = (1, 0, 0, 0, 1, 0, 0, 0), steps: tuple = (0, 0, 1, 0, 0, 1, 0, 0), levels: int = 3, iterations_per_level: int = 10, min_coverage: float = 1.0)

projective: True이면 원근 변환, False이면 아핀 변환으로 최적화합니다. 기본값 False입니다.

mse: True이면 음의 평균 제곱 오차, False이면 NCC를 최적화합니다. 기본값 True입니다.

initial: 기준 영상 로컬 좌표에서 소스 로컬 좌표로의 3×3 행 우선 변환의 앞 8개 유한 계수입니다. 마지막 값은 1로 고정되며 아핀에서는 7·8번째 계수가 0이어야 합니다.

steps: 8개 계수의 초기 좌표 탐색 간격으로 유한한 비음수입니다. 각 단계에서 절반으로 줄어듭니다.

levels: 간격을 줄이는 단계 수이며 1..32입니다. 기본값 3입니다.

iterations_per_level: 단계당 반복 상한으로 1..10000입니다. 기본값 10입니다.

min_coverage: 유효 표본 비율의 하한이며 0보다 크고 1 이하여야 합니다. 기본값 1입니다.

이 호출의 입력과 객체 맥락

기준 영상 로컬에서 소스 영상 로컬로 가는 3×3 행 우선 변환의 앞 8개 계수와 탐색 간격을 지정합니다. 마지막 계수는 1로 고정되고 아핀 모드에서는 7·8번째 계수가 0이어야 합니다. projective는 원근/아핀, mse는 음의 평균 제곱 오차/NCC 선택입니다. levels와 단계당 반복에는 별도 상한이 있고 min_coverage는 (0,1]입니다. 결과의 유효 마스크와 점수를 함께 확인하세요.
