build(self, unit: zvision._composite_metrology.CompositeUnit | None = None) -> 'CompositeModel'

현재 그래프를 검증해 독립 불변 모델로 고정합니다.

확인된 인자 조건

unit: CompositeUnit 또는 None(픽셀).

반환: 사용 후 close해야 하는 CompositeModel.

오류: 무효 그래프 또는 단위는 오류.

인자 선언

  • unit · POSITIONAL_OR_KEYWORD · 타입 zvision._composite_metrology.CompositeUnit | None · 기본값 None

반환 타입 주석: CompositeModel

그래프를 검증하고 독립적인 불변 모델을 생성한다.

이 호출의 입력과 객체 맥락

지금까지 추가한 프레임, 특성과 허용오차에서 모델을 만듭니다. 특성이 다른 항목을 참조하는 경우 참조 대상은 먼저 추가되어 있어야 하므로, 고정 기하를 추가한 다음 파생 특성과 허용오차를 정의하는 순서가 실용적입니다. 입력 좌표는 ROI 로컬 픽셀 기준이며 선택적 등방 출력 배율을 세계 좌표 보정과 동일하게 취급하지 않습니다. 모델 평가 결과를 사용하기 전 필요한 기하와 판정 항목이 모두 들어갔는지 확인하세요.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
