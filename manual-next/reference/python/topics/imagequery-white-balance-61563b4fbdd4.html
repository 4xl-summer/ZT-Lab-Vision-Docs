색상 채널별 보정

현재 색상 영상에 세 채널 게인을 적용하는 단계를 추가합니다. 입력의 RGB 또는 BGR 순서를 확인해야 배율이 의도한 색 성분에 적용됩니다. 채널별 게인은 밝기 범위와 후속 색 변환 결과에 영향을 줍니다.

결과 검토

색이 알려진 입력을 사용해 계획 실행 전후의 채널을 비교합니다. 큰 배율은 결과 표현 범위에 영향을 줄 수 있으므로 지원되는 형식과 값의 조건을 확인합니다. 촬영 조명과 실제 색 정확도는 별도 보정 검증이 필요합니다.
