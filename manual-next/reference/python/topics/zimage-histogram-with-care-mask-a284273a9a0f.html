histogram_with_care_mask

method · 선언 타입 zvision.ZImage

Python
histogram_with_care_mask(self, mask, offset_x, offset_y, spec)

비영 care 마스크 픽셀의 채널별 히스토그램을 계산합니다.

확인된 인자 조건

mask: care 마스크

offset_x: 마스크 x 오프셋

offset_y: 마스크 y 오프셋

spec: 빈 수와 범위를 담은 HistogramSpec

반환: 별도로 close할 MaskedHistogram입니다.

오류: 입력·범위가 유효하지 않으면 오류입니다.

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Calculate channel-major counts of nonzero care samples.

관심 픽셀의 분포

care mask로 선택한 픽셀의 밝기 분포를 히스토그램으로 집계합니다. 마스크가 달라지면 동일한 원본 영상이라도 집계 대상이 달라집니다. 전체 영상의 분포와 관심 영역의 분포를 같은 것으로 해석하지 않습니다.

크기와 빈 범위

마스크와 영상의 크기 및 좌표 정렬을 확인하고 빈 수와 값 범위를 기록합니다. 같은 빈 인덱스라도 두 결과의 범위가 다르면 서로 다른 밝기 구간일 수 있습니다. 히스토그램 자체는 각 픽셀의 공간 위치를 보존하지 않습니다.
