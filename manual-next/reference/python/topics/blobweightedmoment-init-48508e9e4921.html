BlobWeightedMoment(label: int, value: float) -> None

Blob label and its unnormalized weighted moment.

label: 모멘트 대상 라벨입니다.

value: 선택한 차수의 정규화하지 않은 가중 모멘트 합입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
label모멘트 대상 라벨입니다.필수
value선택한 차수의 정규화하지 않은 가중 모멘트 합입니다.필수

값의 해석과 사용

value는 정규화하지 않은 가중 모멘트 합입니다. x=0,2와 가중치 1,3이면 1차 합은 6이고 가중 중심은 별도로 6/4=1.5입니다. 차수와 원점이 의미를 결정합니다.

정규화하지 않은 가중 합

label은 대상 성분의 레이블이고 value는 선택된 차수의 정규화하지 않은 가중 모멘트 합입니다. 레이블 번호와 목록 순번, 다른 프레임의 객체 ID를 구분합니다. 모멘트의 차수와 좌표 원점이 value의 의미를 결정합니다.

항목의미와 사용
label측정 대상 레이블
value정규화하지 않은 모멘트 합
0차 예가중치 1+3=4
1차 예0×1+2×3=6
가중 중심6/4=1.5의 별도 계산
비교 기준차수·원점·가중치를 함께 기록

예를 들어 x=0과 2에 가중치 1과 3을 주면 가중치 합은 4이고 x의 1차 가중 합은 6입니다. 가중 중심 1.5는 6을 4로 나눈 별도 계산입니다. 비교할 때 입력 가중치와 좌표 단위를 맞추고 1차 합을 이미 정규화된 위치로 취급하지 않습니다.
