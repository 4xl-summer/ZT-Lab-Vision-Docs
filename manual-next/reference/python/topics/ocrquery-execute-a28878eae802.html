execute(self) -> 'QueryExecution[OcrRead]'

지연 인식 계획을 실행합니다.

반환: 독립 결과 스냅샷을 포함하는 QueryExecution입니다.

오류: 실행 또는 인식 오류가 전달됩니다.

반환 타입 주석: QueryExecution[OcrRead]

Execute and return an independent OCR snapshot.

사용과 결과 판독

지연 OCR 계획을 실행하여 독립 스냅샷을 얻습니다. 인식된 문자와 상태를 함께 확인하고 실행 오류를 단지 빈 문자열로 치환하지 마십시오. 입력 영역은 원래 영상의 로컬 픽셀 기준으로 기록합니다.

항목확인된 계약
역할지연 인식 계획을 실행합니다.
반환독립 결과 스냅샷을 포함하는 QueryExecution입니다.
오류실행 또는 인식 오류가 전달됩니다.

한 문자라도 읽지 못한 경우와 전체 실행이 오류로 끝난 경우를 구별하십시오. 문자 위치나 영역을 화면에 표시할 때는 결과가 사용하는 영상 로컬 픽셀 기준과 원본 ROI 원점을 확인해야 합니다.
