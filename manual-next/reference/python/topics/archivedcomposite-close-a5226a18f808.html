close(self)

Release the native archive; previously returned result snapshots remain valid.

이 호출의 입력과 객체 맥락

이 객체의 확인된 공개 생성 경로: ArchivedComposite(data).

사용 순서와 판독

close는 복합 계측 아카이브를 평가할 때 사용하는 소유 리소스를 해제합니다. 예를 들어 보관 바이트로 객체를 열어 고정 형상과 공차를 평가했다면 필요한 결과 스냅샷을 먼저 확보하고 아카이브 사용이 끝난 시점에 close합니다.

이미 반환된 독립 결과 스냅샷은 아카이브가 닫힌 뒤에도 유효합니다. 반대로 닫힌 아카이브를 계속 사용해 새 평가를 시작하는 흐름으로 해석하지 않습니다. 아카이브에 저장한 등방 단위와 입력 ROI 로컬 픽셀 좌표는 서로 다른 맥락입니다.

예를 들어 같은 아카이브에서 여러 차례 평가해 결과를 각각 변수에 보관한 경우, 아카이브를 닫더라도 이미 얻은 독립 결과는 읽을 수 있습니다. 결과에 포함된 형상과 공차를 보관하고 싶다면 실행 시점의 입력 영상·설정·단위도 함께 기록해야 이후 결과를 같은 기준으로 해석할 수 있습니다. 아카이브 해제는 그 독립 값들을 지우는 명령이 아닙니다.

항목확인할 내용
닫기 전필요한 평가를 실행하고 결과를 확보
닫은 뒤이미 반환한 독립 스냅샷을 판독
단위저장된 출력 단위와 ROI 픽셀 기준을 구분
