python 공개 선언
PlanarDofOptions(initial: tuple, mask: zvision._rigid_frames.PlanarDofMask, max_iterations: int, damping: float, gradient_tolerance: float, max_work: int) -> None

Initial (radians, tx, ty, positive scale), selected mask and bounded local LM controls.

initial: 초기 (각도, X 이동, Y 이동, 양의 스케일) 튜플이며 각도는 라디안입니다.

mask: 조정할 각도, X 이동, Y 이동, 스케일 자유도를 선택하는 비트 마스크입니다.

max_iterations: 최적화 반복 상한입니다.

damping: 유한 양수 초기 감쇠값입니다.

gradient_tolerance: 유한 양수 기울기 수렴 허용값입니다.

max_work: 계산 작업 상한으로 1–20,000,000입니다.

이 호출의 입력과 객체 맥락

평면 유사변환을 적합할 때 초기값과 조정할 자유도를 지정합니다. initial의 네 값은 순서대로 각도, x 이동, y 이동, 양의 축척입니다. 각도는 라디안이고 이동은 입력 점 좌표와 같은 단위입니다. mask에서 각도, x, y, 축척 비트를 선택하면 그 성분만 최적화 대상으로 삼습니다.

예를 들어 축척을 측정 장치에서 이미 알고 있다면 축척 비트를 끄고 나머지 자유도만 선택할 수 있습니다. 선택하지 않은 스칼라는 초기값을 유지하므로 적합이 모든 값을 새로 추정한다고 생각해서는 안 됩니다. 초기 축척이 유효한 양수인지와 원본·대상 점이 같은 좌표 단위인지 호출 전에 확인하십시오.
