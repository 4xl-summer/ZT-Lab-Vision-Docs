PlaneFit(normal: zvision._spatial3d.Point3, offset: float, inliers: int, total: int, rms_error: float, max_error: float)

normal: 단위 법선이며 평면식은 normal·점 + offset = 0입니다.

offset: 평면 방정식의 상수항이며 점군 길이 단위입니다.

inliers: 임계 거리 이내로 채택된 점 수입니다.

total: 피팅에 사용된 결측을 제외한 유효 점 수입니다.

rms_error: 채택점의 평면 거리 잔차 RMS이며 점군 길이 단위입니다.

max_error: 채택점의 최대 평면 거리 잔차이며 점군 길이 단위입니다.

이 호출의 입력과 객체 맥락

PlaneFit은 평면을 n·p+d=0으로 표현하는 normal과 offset, 입력 유효점 수, 합의점 수와 잔차를 함께 담습니다. normal은 단위 벡터이므로 한 점 p의 평면 거리 잔차는 |n·p+d|로 해석할 수 있습니다. 예를 들어 n=(0,0,1), d=-4이면 z=4인 점의 잔차는 0입니다. 법선과 offset을 동시에 반대로 바꾸어도 같은 평면이므로 부호 하나만으로 결과가 달라졌다고 판단하지 않습니다.

inliers는 지정한 거리 임계값을 만족한 점의 수이고 total은 결측을 제외한 입력 유효점 수입니다. rms_error와 max_error는 채택점의 잔차를 점군의 길이 단위로 보여 줍니다. 25개 평면점이 모두 합의점이어도 그것은 해당 입력과 임계값에 대한 결과입니다. 점이 부족하거나 기하가 퇴화하면 피팅은 오류가 될 수 있으며, 제한된 후보 탐색이 임의의 이상치 분포에 대해 전역 최적해를 보장하지 않습니다.
