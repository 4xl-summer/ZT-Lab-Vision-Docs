distort(self, point)

정규화 카메라 좌표에 왜곡 모델을 적용합니다.

확인된 인자 조건

point: 글로벌 픽셀 Point2.

반환: 변환된 독립 Point2 값.

오류: 타입 오류, 유효하지 않은 렌즈 또는 역변환 실패는 오류.

인자 선언

  • point · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

보정된 글로벌 픽셀 점을 모델의 왜곡된 글로벌 픽셀 점으로 보냅니다. 내부 파라미터로 점을 정규화하고 방사 계수 k1·k2·k3와 접선 계수 p1·p2를 적용한 뒤 픽셀 좌표로 되돌립니다. 왜곡 계수가 모두 0이면 점은 그대로입니다. ROI 로컬 점은 이미지 원점을 먼저 더해야 하며 결과는 영상 전체를 바꾸지 않는 Point2 값입니다. 잘못된 계수나 비유한 계산은 오류가 될 수 있습니다.

이 객체의 확인된 공개 생성 경로: LensModel(fx: float, fy: float, cx: float, cy: float, k1: float, k2: float, k3: float, p1: float, p2: float) -> None.
