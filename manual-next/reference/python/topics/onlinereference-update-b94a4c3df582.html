update(self, images, *, max_batch)

호환 영상을 누적해 평균과 분산 통계를 갱신합니다.

확인된 인자 조건

images: 비어 있지 않은 호환 ZImage 시퀀스.

max_batch: 한 번에 제출할 최대 영상 수, 양의 정수.

반환: None. 전체 입력 검증이 성공한 후 통계를 반영합니다.

오류: 닫힌 객체 또는 호환되지 않는 입력과 한도 초과는 오류입니다.

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_batch · KEYWORD_ONLY · 기본값 없음

max_batch: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

비어 있지 않은 ZImage 시퀀스로 참조를 갱신합니다. max_batch는 양수이며 한 번에 전달할 입력 개수의 한도입니다. 요소가 ZImage가 아니거나 목록이 비어 있으면 오류입니다. 호출 뒤 count를 읽어 현재 누적 상태를 확인하고, 고정된 결과가 필요할 때 freeze를 별도로 호출합니다. 입력 영상과 참조 객체는 호출 중 유효해야 합니다.
