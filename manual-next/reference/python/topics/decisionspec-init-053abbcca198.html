DecisionSpec(max_count: int, max_total_area: int, max_single_area: int, allowed_region: tuple)

max_count: 허용 결함 수 상한으로 0 이상이며 등호를 포함합니다.

max_total_area: 허용 총 면적 상한으로 픽셀 수이며 등호를 포함합니다.

max_single_area: 각 결함의 허용 면적 상한으로 픽셀 수이며 등호를 포함합니다.

allowed_region: 모든 결함 경계를 포함해야 하는 로컬 반열림 (x, y, 너비, 높이)이며 크기는 양수입니다.

이 호출의 입력과 객체 맥락

후보 목록을 받은 뒤 허용할 결함의 수, 전체 면적, 개별 면적 및 위치를 정의하는 값입니다. max_count는 후보 개수이고 max_total_area와 max_single_area는 전경 픽셀 수로 측정한 면적의 상한입니다. 허용 사각형 allowed_region은 현재 영상의 로컬 (x,y,width,height)이며 폭과 높이가 양수여야 합니다. 각 후보의 전체 경계가 이 영역 안에 있어야 위치 조건을 통과합니다.

상한과 같은 값은 허용됩니다. 예를 들어 단일 면적 상한이 4이면 면적 4의 후보는 이 조건에 맞고 면적 5는 위반합니다. 후보가 하나도 없어야 한다면 개수와 면적 한도를 0으로 지정할 수 있습니다. 허용 영역은 판정 API가 받는 독립 사각형이므로 영상 크기에 자동으로 맞춰진다고 가정하지 말고 현재 마스크와 같은 로컬 좌표로 정합니다.

결함 수·면적·위치 판정

DecisionSpec은 결함 후보를 얻은 뒤 허용 기준을 나타내는 값입니다. max_count는 후보의 개수, max_total_area는 후보 면적의 합, max_single_area는 하나의 후보에 허용하는 면적 상한입니다. 면적은 픽셀 수이며 세 조건은 서로 다른 양을 제한합니다.

상한은 등호를 포함합니다. 예를 들어 최대 개수 2, 총 면적 7, 개별 면적 4일 때 면적이 3과 4인 두 후보는 이 세 수치 조건의 경계에 맞지만, 면적 5인 후보는 개별 상한을 위반합니다. 다만 수치 조건을 만족해도 허용 위치 조건을 별도로 확인해야 합니다.

allowed_region은 영상 로컬의 반열림 (x,y,width,height)입니다. 예를 들어 (10,20,4,3)의 오른쪽과 아래 경계는 각각 14,23이며 포함되는 셀은 x=10..13, y=20..22입니다. 후보 전체 경계가 이 영역에 들어가야 위치 조건을 만족하므로 ROI 원점과 후보 좌표계를 맞춥니다.
