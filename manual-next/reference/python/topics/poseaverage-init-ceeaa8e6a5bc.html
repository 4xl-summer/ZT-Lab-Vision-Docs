PoseAverage(pose: zvision._spatial3d.RigidTransform3, eigen_gap: float, count: int) -> None

Weighted proper rigid pose and quaternion eigenvalue separation.

pose: 가중 강체 자세 평균입니다.

eigen_gap: 최대와 두 번째 쿼터니언 고유값의 정규화된 차이입니다.

count: 평균에 사용된 자세 수입니다.

이 호출의 입력과 객체 맥락

PoseAverage는 여러 강체 자세의 가중 평균 결과입니다. pose는 평균 자세, count는 사용한 입력 수, eigen_gap은 회전 평균의 고유값 간격을 살피는 진단값입니다. 입력 자세들은 같은 출발·도착 프레임과 길이 단위로 정의되어야 하며 같은 물리적 방향을 서로 다른 기준으로 표현한 값을 임의로 섞으면 안 됩니다.

예를 들어 회전이 같고 이동이 X=0과 X=10인 자세 두 개를 같은 가중치로 평균하면 이동의 X 평균은 5입니다. 회전은 각도 숫자를 단순 평균하는 대신 부호에 불변인 쿼터니언 방식으로 처리합니다. 서로 크게 다른 자세나 불안정한 입력을 평균하면 결과 한 개가 개별 자세의 오차를 감출 수 있으므로 입력과 진단값을 함께 확인하세요.

입력과 결과를 읽는 순서

PoseAverage는 여러 강체 자세의 가중 평균 pose, 회전 평균 진단 eigen_gap, 사용한 자세 수 count를 담습니다. 입력 자세들은 같은 출발·도착 프레임과 길이 단위를 사용해야 합니다. 서로 다른 좌표계에 표현된 자세 숫자를 그대로 평균하지 않습니다.

예를 들어 회전이 같고 x 이동이 0과 10인 두 자세에 같은 가중치를 주면 평균 이동 x는 5입니다. 회전은 각도 숫자를 단순 산술 평균하는 대신 부호에 불변인 쿼터니언 방식으로 다뤄집니다. eigen_gap은 최대와 두 번째 고유값의 정규화된 차이로 이 회전 평균의 진단입니다.

평균 하나는 개별 자세의 산포를 가릴 수 있으므로 count와 입력별 차이도 살펴야 합니다. eigen_gap은 진단 수치이지 모든 실제 장치 오차나 물리적 정확도에 대한 인증이 아닙니다. 평균 pose를 다른 시스템에 넘길 때 프레임 방향과 이동 단위를 함께 기록하세요.
