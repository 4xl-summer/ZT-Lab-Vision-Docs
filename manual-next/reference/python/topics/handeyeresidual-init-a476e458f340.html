HandEyeResidual(rotation_radians: float, translation: float, inlier: bool)

rotation_radians: 해당 대응쌍의 회전 잔차이며 라디안입니다.

translation: 해당 대응쌍의 이동 잔차이며 변환의 길이 단위입니다.

inlier: 회전과 이동 잔차가 두 임계값을 모두 만족하면 참입니다.

이 호출의 입력과 객체 맥락

HandEyeResidual은 핸드아이 해에 대한 한 운동 쌍의 잔차를 담습니다. rotation_radians는 회전 차이의 크기이고 translation은 이동 차이로, 입력 변환에 사용한 길이 단위를 따릅니다. inlier는 회전과 이동 잔차가 각각 지정된 조건을 만족하는지 보여 줍니다. 각 결과를 입력 운동 쌍과 같은 순서로 연결해 이상한 관측을 추적할 수 있습니다.

예를 들어 회전 잔차는 허용 범위 안이지만 이동 잔차가 0.8 mm이고 한계가 0.5 mm라면 두 조건을 모두 충족하지 못합니다. 반대로 내점 표시 하나만 보고 모든 위치에서의 정확도가 충분하다고 판단할 수는 없습니다. 특정 자세의 잔차가 반복적으로 크다면 해당 관측의 좌표 변환과 로봇 및 카메라 기록 시점을 확인하세요.

입력과 결과를 읽는 순서

HandEyeResidual은 하나의 입력 운동 대응쌍에 대해 계산된 회전 잔차, 이동 잔차와 인라이어 여부를 담습니다. rotation_radians는 라디안이고 translation은 입력 변환의 길이 단위입니다. 같은 숫자라도 두 필드는 서로 다른 물리량입니다.

예를 들어 회전 잔차가 허용치 안이어도 이동 잔차가 0.8mm이고 이동 한계가 0.5mm라면 두 조건을 모두 만족하지 못합니다. 반대로 이동은 통과하지만 회전이 벗어난 경우도 별도로 살펴야 합니다. inlier 하나로 어느 조건이 영향을 주었는지 알 수 없으므로 두 수치를 같이 기록하세요.

결과는 원래 입력 운동 쌍의 순서와 연결해 검사합니다. 특정 쌍만 잔차가 크다면 프레임 방향, 로봇·카메라 관측 시각과 해당 변환을 점검할 수 있습니다. 한 쌍의 inlier 판정만으로 전체 작업 범위의 실제 정확도가 보장되지는 않습니다.
