스냅샷 영상을 인덱스로 획득합니다.

확인된 인자 조건

index: 0 평균, 1 모집단 표준편차, 2 포함 마스크.

오류: 닫힌 객체 또는 호환되지 않는 입력과 한도 초과는 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

Legacy 0.1.x indexed acquisition; prefer named image properties.

온라인 스냅샷의 영상

index 0은 평균, 1은 모집단 표준편차, 2는 포함 마스크를 선택합니다. 평균과 편차는 서로 다른 통계이며 마스크는 집계에 포함되는 위치를 나타냅니다. 반환 영상은 별도 소유이며 사용 후 close합니다.

판독

평균 영상과 표준편차를 같은 좌표에서 확인하면 기대 밝기와 변동을 나눠 볼 수 있습니다. 포함 마스크 밖의 값을 유효한 학습 통계로 가정하지 않습니다. 닫힌 객체 또는 유효하지 않은 호출은 오류입니다.

영상 선택 기준

평균과 모집단 표준편차는 서로 다른 통계이며 2번은 포함 마스크입니다. 각 영상을 같은 위치에서 비교하고 마스크 밖의 픽셀을 유효한 통계라고 가정하지 않습니다. 각 반환 핸들은 닫습니다.
