Python
image(self, validity=False)

모자이크 또는 유효 마스크를 획득합니다.

확인된 인자 조건

validity: False는 GrayF64 모자이크, True는 Gray8 유효 마스크.

반환: 독립 소유 영상이며 close합니다.

오류: 닫힌 객체 또는 부적합한 캔버스·배율·옵션은 오류입니다.

인자 선언

  • validity · POSITIONAL_OR_KEYWORD · 기본값 False

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Acquire the GrayF64 mosaic; validity=True is the legacy mask selector.

사용과 결과 판독

validity가 False이면 GrayF64 모자이크, True이면 Gray8 유효 마스크를 획득합니다. 모자이크의 픽셀값이 0이라는 사실만으로 해당 위치가 유효한지 판단하지 말고 마스크를 따로 확인하십시오. 획득 영상은 각각 닫습니다.
