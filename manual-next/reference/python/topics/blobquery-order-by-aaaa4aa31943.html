order_by(self, expression, descending=False)

표현식 기준 정렬을 가변 계획에 추가합니다.

확인된 인자 조건

expression: 정렬에 사용할 표현식

descending: bool; 내림차순 여부, 기본값 False

반환: 수정된 동일 BlobQuery입니다.

오류: descending이 bool이 아니거나 표현식이 유효하지 않으면 오류입니다.

인자 선언

  • expression · POSITIONAL_OR_KEYWORD · 기본값 없음
  • descending · POSITIONAL_OR_KEYWORD · 기본값 False

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

표현식으로 정렬

expression이 계산하는 Blob 특성을 기준으로 결과 순서를 정합니다. descending은 bool이고 기본 False입니다. 예를 들어 면적 기준으로 정렬하면 크기 순으로 확인할 수 있지만 레이블 자체가 면적 값이 되는 것은 아닙니다.

계획과 결과

수정된 동일 BlobQuery를 반환하므로 필요한 필터와 정렬을 지정한 후 실행합니다. 잘못된 표현식이나 bool이 아닌 descending은 오류가 될 수 있습니다. 정렬 전후의 목록 인덱스는 달라지므로 결과 순번을 영구 식별자로 취급하지 않습니다.
