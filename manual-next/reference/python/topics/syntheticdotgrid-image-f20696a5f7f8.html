Get a separately owned Gray8 image.

합성 격자 영상

생성된 도트 격자를 별도 소유 Gray8 ZImage로 얻습니다. 도트 위치와 영상의 픽셀 좌표는 합성 입력 설정에 따릅니다. 닫힌 소유 객체에서 영상을 얻으려고 하면 오류입니다.

검증에 사용

생성 설정과 결과 크기를 기록해 검출 결과의 점 위치를 비교할 수 있습니다. 합성 격자가 예상대로 표시된다는 사실만으로 실제 카메라의 왜곡이나 조명 정확도가 검증되는 것은 아닙니다. 획득한 영상은 사용 후 닫습니다.

Gray8 합성 영상 획득

SyntheticDotGrid.image()는 생성된 도트 격자를 별도 소유 Gray8 ZImage로 얻습니다. 닫힌 결과 객체에서는 획득할 수 없습니다. 반환 영상과 격자 결과 객체는 각각의 수명을 관리해야 합니다.

격자의 물리 배치, 카메라 모델과 포즈가 투영된 픽셀 위치를 결정합니다. centers로 얻은 점을 영상 위에 표시하면 렌더링한 표식과 좌표가 대응하는지 검증할 수 있습니다. 영상의 픽셀 좌표와 격자 물리 좌표는 다른 단위입니다.

항목확인할 내용
반환별도 소유 Gray8 ZImage
centers투영된 중심 좌표
격자물리 배치와 간격
영상픽셀 좌표계의 렌더링 결과
닫힌 결과영상 획득 오류
정리영상과 결과를 각각 close

합성 영상을 검출기의 작은 재현 사례로 사용한 뒤 얻은 ZImage를 close하고 결과 객체도 정리합니다. 합성 이미지에서 점을 찾았다는 사실은 실제 장비의 조명, 왜곡 보정 또는 카메라 정확도를 자동으로 검증하지 않습니다.

적용과 판독을 더 살펴보기

생성 설정을 기록할 때 영상 크기, 격자의 행과 열, 표식 반경, 카메라 모델과 투영에 사용한 포즈를 서로 다른 항목으로 구분합니다. 물리 격자의 한 칸 간격을 이미지에서 항상 같은 픽셀 수라고 가정하면 원근이나 왜곡이 있는 영상에서 어긋날 수 있습니다. 중심 목록을 함께 사용하면 검출기의 출력이 어느 합성 표식에 대응하는지 확인할 수 있습니다. 결과의 점을 ROI 내부에서 분석했다면 먼저 ROI 로컬 좌표를 전역 픽셀 좌표로 옮긴 뒤 중심과 비교합니다. 실제 촬영 영상에는 합성 입력에 포함되지 않은 노이즈와 조명 변화가 있을 수 있으므로 별도 시험 자료도 필요합니다.
