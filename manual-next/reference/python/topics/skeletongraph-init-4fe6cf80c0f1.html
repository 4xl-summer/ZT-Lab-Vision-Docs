SkeletonGraph(nodes: tuple, edges: tuple)

nodes: 독립 골격 노드의 튜플입니다.

edges: 독립 골격 에지의 튜플입니다.

이 호출의 입력과 객체 맥락

SkeletonGraph는 nodes와 edges 두 튜플로 골격의 분기 구조를 표현합니다. 노드는 끝점이나 접합점 등이고 간선은 노드 사이를 잇는 경로입니다. 단순한 픽셀 영상과 달리 연결 관계를 직접 따라갈 수 있지만, 원본 마스크의 면적이나 밝기 정보 전체를 대신하지는 않습니다.

각 간선의 start와 end는 해당 결과의 노드 인덱스이고 points와 length는 그 경로를 설명합니다. 두 끝점이 같은 닫힌 루프에서도 그래프가 경로를 나타낼 수 있으며 구현은 루프를 표현할 합성 기준점을 사용합니다. 간선의 두 끝점만 그리면 굽은 골격을 정확히 표시할 수 없습니다.

노드 인덱스와 경로

SkeletonGraph는 nodes와 edges의 두 튜플을 저장하는 불변 값 스냅샷입니다. nodes에는 SkeletonNode, edges에는 SkeletonEdge가 들어가야 하며 생성 과정에서 각 입력을 튜플로 바꾸고 항목 타입을 확인합니다. 이 생성자는 마스크를 골격화하거나 영상 핸들을 생성하는 호출이 아닙니다.

예를 들어 nodes가 끝점 A와 끝점 B 두 개이고 하나의 간선이 start=0, end=1이면 그 간선은 첫 노드와 둘째 노드를 연결합니다. 간선의 points는 그 사이의 실제 점 사슬이고 length는 경로 길이입니다. 굽은 사슬은 양 끝점을 직선으로만 이은 그림과 다를 수 있으므로 points를 순서대로 사용하세요.

수명과 결과 확인

노드 종류에는 끝점, 접합점, 고립점과 닫힌 루프를 나타내는 기준점이 있습니다. 루프에서 start와 end가 같더라도 points가 하나의 닫힌 경로를 표현할 수 있습니다. 노드 인덱스는 같은 그래프의 nodes 순서에 연결하고, 원래 마스크의 밝기나 전체 면적이 이 값 객체에 모두 저장되어 있다고 가정하지 마세요.
