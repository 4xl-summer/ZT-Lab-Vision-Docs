python 공개 선언
StereoOptions(ray, min_angle_radians, max_ray_gap, max_reprojection_pixels, require_positive_depth=True)

삼각측량 광선 역산과 결과 품질 조건을 지정합니다. 수치 범위는 사용 시에도 검증합니다.

ray: 광선 역산에 사용할 RayOptions입니다.

min_angle_radians: 최소 광선 각도로 0 초과 π/2 미만의 라디안 값입니다.

max_ray_gap: 허용 최대 광선 간격으로 세계 길이 단위의 유한한 비음수입니다.

max_reprojection_pixels: 허용 최대 재투영 오차로 픽셀 단위의 유한한 비음수입니다.

require_positive_depth: 두 카메라에서 양의 깊이를 요구하는 bool이며 기본값은 True입니다.

이 호출의 입력과 객체 맥락

두 카메라 광선의 교차 품질을 판정할 옵션입니다. ray는 역산 설정, min_angle_radians는 0보다 크고 π/2보다 작은 최소 각도입니다. max_ray_gap은 세계 길이 단위, max_reprojection_pixels는 픽셀 단위이므로 같은 숫자라도 서로 다른 조건입니다. require_positive_depth=True는 두 카메라에서 양의 깊이를 요구합니다. 결과에서는 광선 간격과 재투영 오차를 각각 확인하세요.

삼각측량 품질 조건

StereoOptions는 두 카메라의 픽셀을 광선으로 역산하는 RayOptions와 교차 결과의 허용 조건을 묶습니다. min_angle_radians는 두 광선 사이 최소 각도이며 0보다 크고 π/2보다 작아야 합니다. 거의 평행한 광선은 깊이 추정에 민감하므로 이 기준을 설정합니다.

max_ray_gap은 두 광선의 최대 간격으로 세계 길이 단위를 사용하고 max_reprojection_pixels는 최대 재투영 오차로 픽셀 단위를 사용합니다. 예를 들어 두 값이 모두 1이라고 해도 하나는 모델의 물리 길이 1, 다른 하나는 영상 1픽셀입니다. 단위를 확인하지 않고 숫자만 비교하지 않습니다.

require_positive_depth는 기본 true로 두 카메라에서 양의 깊이를 요구합니다. 생성자에서 ray 형식과 bool을 확인하고 수치 범위는 실제 사용 시에도 검증합니다. 반환 삼각측량 결과의 광선 각도·간격·각 카메라의 깊이와 재투영 오차를 개별 조건과 대조합니다.
