Python
bayer_to_rgb8(image, pattern, red_gain=1.0, green_gain=1.0, blue_gain=1.0)

Bayer8 ROI를 쌍선형 보간해 RGB8로 변환합니다.

확인된 인자 조건

image: 입력 ZImage

pattern: RGGB/BGGR/GRBG/GBRG 패턴

red_gain: 유한한 양수 빨강 게인; 기본값 1

green_gain: 유한한 양수 초록 게인; 기본값 1

blue_gain: 유한한 양수 파랑 게인; 기본값 1

반환: 별도로 close할 RGB8 ZImage입니다.

오류: 패턴이나 게인이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pattern · POSITIONAL_OR_KEYWORD · 기본값 없음
  • red_gain · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • green_gain · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • blue_gain · POSITIONAL_OR_KEYWORD · 기본값 1.0

red_gain: 유한한 수 검사.

green_gain: 유한한 수 검사.

blue_gain: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Return independent RGB8 using 3x3 in-ROI bilinear channel estimates.

Bayer 패턴의 색 복원

Bayer8 입력의 한 픽셀은 색 필터 배열의 한 성분을 샘플링합니다. 이 호출은 지정된 RGGB, BGGR, GRBG, GBRG 패턴에 따라 쌍선형 보간해 RGB8을 생성합니다. 실제 센서 배열과 다른 패턴을 지정하면 색 채널 해석이 달라집니다.

게인과 ROI

red_gain, green_gain, blue_gain은 유한한 양수이며 기본값은 각각 1.0입니다. ROI 원점에 따라 배열의 시작 위치를 어떻게 해석하는지 입력 패턴 계약을 확인하고, 색이 알려진 표본에서 순서와 게인을 검증합니다. 결과는 독립 영상으로 관리합니다.
