coefficients(self)

모든 밴드 계수를 순서대로 복사합니다.

반환: 최종 LL 뒤 레벨별 HL/LH/HH 순서의 독립 튜플입니다.

오류: 닫힌 모델은 오류입니다.

Return a packed independent tuple of all bands.

이 호출의 입력과 객체 맥락

현재 모델의 계수를 행 우선 숫자 튜플로 복사합니다. 튜플은 독립 값이므로 일부 계수를 바꾸려면 목록 등으로 복사해 편집한 뒤 with_coefficients로 새 모델을 만듭니다. 원래 모델과 새 모델은 각각 close합니다. 계수 크기와 밴드 순서를 모델 정보와 함께 확인하세요. 순서는 최종 LL 다음 각 단계의 HL, LH, HH입니다.

사용 흐름과 결과 판독

현재 비감쇠 Daubechies-2 모델의 모든 계수를 독립 튜플로 복사합니다. 배열은 최종 LL 대역 다음 각 단계의 HL, LH, HH 대역을 행 우선으로 담습니다. 튜플을 읽는 것은 모델 계수를 제자리에서 변경하는 작업이 아니며 이미 반환된 튜플은 모델 내부의 빌린 포인터가 아닙니다.

계수를 수정해 다시 합성하려면 튜플을 편집 가능한 목록으로 복사하고 필요한 값을 바꾼 뒤 with_coefficients에 전달하여 새 모델을 만듭니다. 원본 모델과 새 모델은 독립적으로 관리합니다. 예를 들어 계수 한 개를 목록에서 0으로 바꾸더라도 원본 모델의 값은 그대로이며 새 모델을 만든 후에야 수정된 계수로 역변환할 수 있습니다.

모델 정보의 영상 너비·높이와 단계별 밴드 배치를 계수와 함께 보존해야 각 인덱스의 의미를 복원할 수 있습니다. 같은 숫자 배열이라도 크기나 단계 수가 다른 모델의 계수로 임의 해석하지 않습니다. 모델이 닫힌 상태에서 이 접근자를 호출하면 오류이며 모델과 새 모델은 사용 후 각각 close합니다.
