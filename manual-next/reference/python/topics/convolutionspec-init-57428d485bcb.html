python 공개 선언
ConvolutionSpec(width: int, height: int, anchor: tuple, kernel: object, divisor: float, offset: float, border: int, output: zvision.PixelFormat, correlate: bool, constant: float = 0.0) -> None

Kernel geometry, coefficients, scaling, border and output format.

width: 커널의 양의 너비입니다.

height: 커널의 양의 높이입니다.

anchor: 커널 내부의 (X, Y) 앵커 인덱스입니다.

kernel: 행 우선 유한 계수로 너비×높이 개수가 필요합니다.

divisor: 가중 합을 나누는 0이 아닌 유한 값입니다.

offset: 나눗셈 후 더하는 유한 값입니다.

border: 입력 ROI 밖에서 복제·반사·상수 중 적용할 경계 방식입니다.

output: 출력 형식이며 이 연산에서는 GrayF64여야 합니다.

correlate: True면 상관, False면 합성곱을 선택합니다.

constant: 상수 경계에 사용하는 밝기이며 기본값은 0입니다.

이 호출의 입력과 객체 맥락

커널 너비·높이, 내부 anchor와 행 우선 kernel, 0이 아닌 divisor와 출력 offset을 묶습니다. 예를 들어 3×3 커널이면 계수는 9개가 필요합니다. correlate=True는 상관, False는 합성곱이며 계수 방향의 해석이 달라집니다. 이 연산의 output은 GrayF64여야 하고 ROI 밖 표본은 지정 border와 constant를 따릅니다. 설정값 생성과 실제 영상 처리는 별개입니다.
