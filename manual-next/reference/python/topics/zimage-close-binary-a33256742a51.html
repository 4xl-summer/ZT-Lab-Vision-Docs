close_binary

method · 선언 타입 zvision.ZImage

Python
close_binary(self, kernel)

이진 Gray8 마스크를 팽창 후 침식합니다.

확인된 인자 조건

kernel: 양의 홀수 정사각형 폭

반환: 별도로 close할 0/255 마스크입니다.

오류: 잘못된 커널이나 입력 형식은 오류입니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

Apply binary morphological closing; close() releases this image.

틈을 다듬는 닫기

이진 닫기는 팽창 다음 침식으로 이루어집니다. 가까운 전경 영역 사이의 작은 틈이나 내부의 작은 배경 부분이 줄어들 수 있습니다. 전경의 배치와 구조 요소의 크기에 따라 별도 물체가 연결될 수 있으므로 적용 전후를 비교합니다.

커널 선택

커널의 폭은 각 단계에서 살펴보는 이웃 범위입니다. 반복 횟수와 같은 값이라고 해석하지 않습니다. 후속 연결 성분 분석의 수와 면적이 바뀌면 중간 마스크를 확인해 분할, 형태학, 연결 설정 중 원인을 구분합니다.
