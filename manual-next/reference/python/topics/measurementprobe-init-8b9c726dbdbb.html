MeasurementProbe.__init__

python 공개 선언
MeasurementProbe(index: int, anchor: zvision._regions.Point2, status: int, edge_position: zvision._regions.Point2 | None, distance: float | None, strength: float | None, used: bool, residual: float | None) -> None

Probe index, anchor, status, optional selected edge, inlier use and residual.

index: 프로브 인덱스.

anchor: ROI 로컬 기준점 Point2.

status: 0 Found, 1 NoEdge, 2 OutsideOrInvalidSamples.

edge_position: 선택된 에지의 ROI 로컬 Point2 또는 None.

distance: 선택 에지의 프로파일 시작점부터 픽셀 거리 또는 None.

strength: 선택된 에지의 부호 있는 원시 강도/픽셀 또는 None.

used: 피팅 채택 여부; 에지 발견과 별개.

residual: 피팅된 형상까지 잔차(픽셀) 또는 None.

계산과 결과 해석

다중 프로브 계측에서 한 탐색 위치의 관측을 담는 독립 값입니다. index와 anchor는 어느 기준점에서 검사했는지 나타내며 status는 에지를 찾았는지, 발견하지 못했는지, 샘플이 유효하지 않았는지를 구분합니다. 에지가 있으면 edge_position, distance, strength를 읽고 없으면 해당 값은 None입니다. 선택된 에지가 있어도 최종 피팅에 사용되지 않을 수 있으므로 used와 residual은 별도로 살펴야 합니다. 예를 들어 여덟 곳에서 에지가 발견되어도 이상점이 기각되면 사용된 점 수는 더 적을 수 있습니다. anchor와 edge_position은 ROI 로컬 픽셀, distance는 프로파일을 따라간 픽셀, strength는 원시 강도/픽셀입니다. 미검출과 미계산 잔차를 숫자 0으로 바꾸지 말고 상태와 함께 전달하십시오. 선택 위치가 있더라도 used가 거짓이면 그 점이 최종 적합을 지지한 점이라고 해석하면 안 됩니다. 반대로 관측이 없을 때는 잔차가 계산되지 않을 수 있으므로 선택 위치와 잔차의 존재 여부를 각각 확인하십시오. 시각화에서는 발견점과 채택점을 다른 표시로 구별할 수 있습니다.
