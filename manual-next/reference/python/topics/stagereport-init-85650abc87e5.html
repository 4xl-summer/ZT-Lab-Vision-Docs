python 공개 선언
StageReport(requested: int, computed: int, failed: int, reason: int, rotation_span: float, validation: object) -> None

Requested/computed/failed bitmasks and reason; validation is None on failure.

requested: 요청한 지표의 비트 마스크입니다.

computed: 계산된 지표의 비트 마스크입니다.

failed: 계산에 실패한 요청 지표의 비트 마스크입니다.

reason: 실패 원인 코드입니다. 0은 없음, 1은 회전 범위 부족, 2는 전체 피팅 실패입니다.

rotation_span: 명령된 펼친 회전각의 최대−최소이며 라디안입니다.

validation: 성공한 전체 진단 값이며 계산 실패 시 None입니다.

이 호출의 입력과 객체 맥락

StageReport는 스테이지 검증에서 요청한 지표, 계산된 지표와 실패한 지표를 비트마스크로 보고합니다. requested, computed, failed는 개수가 아니라 비트의 조합이며 reason은 실패 원인, rotation_span은 회전 범위를 나타냅니다. validation은 실패한 경우 None일 수 있으므로 사용 전에 확인해야 합니다.

예를 들어 요청 마스크가 3이라면 이진수 11로 두 비트가 설정된 것입니다. computed가 1이면 두 요청 지표가 모두 계산되었다고 해석해서는 안 됩니다. 정확히 어떤 지표를 각 비트가 나타내는지는 호출한 보고 API의 정의를 확인하세요. validation이 None인데 수치 필드를 읽으려고 하면 실패 원인을 놓치기 쉽습니다.
