train_contours

classmethod · 선언 타입 zvision._extended_matching.ExtendedShapeModel

train_contours(cls, contours, reference, spacing)

방향이 있는 선분 경로에서 형상 특징을 추출해 모델을 학습합니다.

확인된 인자 조건

contours: 각 2점 이상인 Point2 경로 1..128개, 전체 최대 65536점입니다.

reference: 템플릿 로컬 Point2 기준점입니다.

spacing: 유한한 양의 표본 간격(픽셀)입니다.

반환: 호출자가 닫아야 하는 ExtendedShapeModel입니다.

오류: 경로·간격 또는 특징점 조건이 유효하지 않으면 오류입니다.

인자 선언

  • contours · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spacing · POSITIONAL_OR_KEYWORD · 기본값 없음

Train from directed contour polylines.

호출 맥락과 결과 해석

방향이 있는 선분 경로에서 표본을 만들어 형상 모델을 학습합니다. 경로는 1개에서 128개이고 각 경로에는 2점 이상이 필요하며 전체 점 수는 최대 65536입니다. 영상의 픽셀 기울기를 추출하는 train과 입력의 표현이 다릅니다.

reference는 템플릿 로컬 기준점이고 spacing은 유한한 양의 픽셀 간격입니다. 경로의 점 순서가 방향을 가진 경계를 정의하므로 입력을 구성할 때 의도한 순서를 유지합니다. 생성된 모델은 검색에 사용한 뒤 호출자가 닫습니다.

입력 선택을 위한 확인

입력의미와 조건
contours각 2점 이상인 Point2 경로 1..128개, 전체 최대 65536점입니다.
reference템플릿 로컬 Point2 기준점입니다.
spacing유한한 양의 표본 간격(픽셀)입니다.

반환값 확인

호출자가 닫아야 하는 ExtendedShapeModel입니다.
