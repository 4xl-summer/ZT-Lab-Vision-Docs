to_archive_bytes(self) -> bytes

생성 시 검증한 아카이브 바이트를 반환합니다.

반환: 불변 bytes.

오류: 모델이 닫혔으면 오류.

반환 타입 주석: <class 'bytes'>

검증된 그래프와 단위의 아카이브를 반환한다.

이 호출의 입력과 객체 맥락

검증된 그래프와 저장 단위를 가진 아카이브 내용을 반환합니다. 모델이 열린 동안 호출해야 하며 결과는 독립 바이트 값입니다. 이 바이트를 보관하면 나중에 FromArchiveBytes 또는 from_archive_bytes로 모델을 다시 검증해 복원할 수 있습니다. 결과 바이트를 이미지 핸들처럼 해제할 필요는 없습니다.

생성 시 검증된 아카이브

to_archive_bytes는 열린 CompositeModel이 보유한 아카이브 내용을 불변 bytes 값으로 반환합니다. 바이트에는 검증된 복합 계측 그래프와 저장 단위가 포함됩니다. 이 호출이 반환하는 것은 한 번의 영상 평가 결과나 이미지 핸들이 아닙니다.

예를 들어 모델을 바이트로 보관한 뒤 나중에 from_archive_bytes에 다시 전달하면 아카이브를 검증해 모델을 복원할 수 있습니다. 저장할 때는 텍스트로 손상시키지 않도록 바이너리 바이트를 그대로 사용하세요. 복원된 모델로 알려진 입력을 평가하고 특징 및 공차 구성이 기대와 일치하는지 확인하는 것이 좋습니다.

적용과 결과 확인

반환 bytes는 독립 값이므로 모델을 닫은 뒤에도 이미 얻은 바이트를 보관할 수 있으며 close가 필요하지 않습니다. 반대로 닫힌 모델에 to_archive_bytes를 새로 호출하면 오류입니다. 원본 모델과 복원된 모델은 각각의 핸들로 관리하고, 저장된 물리 단위와 ROI 좌표 기준도 평가에 사용할 조건과 함께 기록하세요.

아카이브 바이트를 얻는 시점은 모델을 평가하는 시점과 다릅니다. 같은 바이트로 복원한 모델이라도 입력 영상이나 검사 조건이 달라지면 평가 결과가 달라질 수 있습니다. 따라서 모델 바이트뿐 아니라 어느 카메라 영상과 좌표 기준에 적용했는지도 검사 기록에 남겨야 합니다. 파일을 전송했다면 복원 단계의 유효성 검사를 통해 손상이나 잘못된 형식이 있는지 확인하고, 모델이 닫힌 상태의 호출 오류를 빈 바이트로 바꾸지 마세요.
