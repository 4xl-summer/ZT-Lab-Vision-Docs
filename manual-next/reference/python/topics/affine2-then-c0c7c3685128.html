then(self, next)

현재 변환 후 next를 적용하는 합성 변환을 만듭니다.

확인된 인자 조건

next: 같은 종류의 다음 변환.

반환: 새 Affine2 값.

오류: 다른 타입 또는 유효하지 않은 계산은 오류.

인자 선언

  • next · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

현재 변환을 먼저 적용하고 인자 next를 그 결과에 적용한 합성 값을 만듭니다. 두 연산의 순서를 바꾸면 일반적으로 결과가 달라집니다. 예를 들어 점 (10, 20)에 먼저 (3, 4) 이동을 적용한 뒤 x·y를 각각 2배 하면 (26, 48)입니다. 반대로 먼저 두 배로 만든 후 이동하면 (23, 44)입니다. 따라서 호출 순서가 데이터 흐름과 일치하는지 확인해야 합니다. 인자는 같은 종류의 Affine2여야 하며 잘못된 값이나 유효하지 않은 계산은 오류가 될 수 있습니다.

이 객체의 확인된 공개 생성 경로: Affine2(a: float, b: float, tx: float, c: float, d: float, ty: float) -> None.
