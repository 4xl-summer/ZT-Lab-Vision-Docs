FontSample(image: zvision.ZImage, label: str, cell: tuple) -> None

FontSample(image: zvision.ZImage, label: str, cell: tuple)

image: 학습 셀을 포함한 Gray8 영상입니다.

label: 학습 셀의 Unicode 문자 하나입니다.

cell: 영상 로컬 (x,y,width,height) 픽셀 영역입니다.

이 호출의 입력과 객체 맥락

폰트 학습에 사용할 image, label, cell을 묶습니다. image는 ZImage이고 label은 해당 샘플의 문자이며 cell은 이미지 안의 (x, y, width, height) 사각형입니다. 샘플의 사각형이 실제 글자와 대응해야 학습된 템플릿도 의도한 형태를 나타냅니다.

예를 들어 같은 숫자 3의 인쇄 모양이 두 가지라면 각각의 영상과 셀, 동일한 라벨을 가진 샘플로 표현할 수 있습니다. 셀에 이웃 문자의 일부나 넓은 배경이 섞이면 분할 및 학습 결과에 영향을 줄 수 있으므로 원본에 사각형을 그려 확인합니다.

입력과 결과를 읽는 순서

FontSample은 학습할 Gray8 image, 대응 문자 하나인 label, 영상 로컬 cell을 묶는 값입니다. cell은 (x,y,width,height)이므로 x·y는 화면 전체 원점이 아니라 이 image의 로컬 좌표로 해석합니다. 영상이 ROI인 경우 전체 프레임 위치와 비교할 때는 그 영상의 원점을 별도로 고려합니다.

예를 들어 같은 글자 A의 모양이 서로 다른 두 셀은 각각의 영상과 셀을 보존하면서 같은 label로 제공할 수 있습니다. 한 셀의 사각형에 이웃 글자가 섞이면 제공한 라벨과 영상 내용이 일치하지 않을 수 있으므로 분할 결과를 먼저 검토하세요. 이 값의 생성만으로 학습이 실행되는 것은 아닙니다.

생성된 샘플은 image 객체를 필드로 참조합니다. 학습 호출에 전달할 때 영상이 유효해야 하며 샘플 값의 수명과 영상 소유 핸들의 해제를 혼동하지 마세요. label은 문자열 전체의 임의 문장이 아니라 학습 셀에 대응하는 Unicode 문자 하나의 계약을 따릅니다.
