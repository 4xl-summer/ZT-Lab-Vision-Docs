GraphOptions(spacing_x: float = 1.0, spacing_y: float = 1.0, work_budget: int = 100000000)

spacing_x: 그래프 길이에 사용할 x 표본 간격이며 기본값 1입니다.

spacing_y: 그래프 길이에 사용할 y 표본 간격이며 기본값 1입니다.

work_budget: 작업량 상한이며 기본값 100000000입니다.

이 호출의 입력과 객체 맥락

골격 그래프의 길이를 계산할 x·y 표본 간격과 작업 예산을 지정합니다. 기본 간격은 두 축 모두 1이고 기본 예산은 100000000입니다. 예를 들어 가로 표본 간격이 2인 기준에서는 가로로 한 표본 떨어진 길이를 2로 읽습니다. 간격 단위는 호출자가 사용하는 좌표 단위와 맞춰야 하며 픽셀 길이가 자동으로 물리 길이로 변환되는 것은 아닙니다.

입력과 결과를 읽는 순서

골격 그래프를 만들 때 길이 계산에 사용할 x·y 표본 간격과 작업 예산을 지정합니다. 기본 spacing_x와 spacing_y는 각각 1이고 work_budget은 100000000입니다. 입력 간격의 단위는 호출자가 정한 좌표 단위와 일치시켜야 합니다.

예를 들어 인접한 점이 x 방향으로 한 표본 떨어졌고 spacing_x=2라면 해당 가로 거리는 2입니다. 같은 한 표본이라도 y 방향 길이는 spacing_y로 판단하므로 두 간격이 다르면 픽셀 인덱스 거리와 실제 설정 거리도 달라집니다.

이 설정은 표본 간격을 제공할 뿐 영상의 원점이나 렌즈 보정을 자동으로 계산하지 않습니다. 그래프의 노드 좌표와 간선 길이를 판독할 때 입력 골격의 좌표 기준, 간격과 작업 예산을 함께 보관하세요. 옵션을 만드는 것만으로 노드·간선이 계산되지는 않습니다.

예를 들어 x 좌표가 3과 4이고 y가 같은 이웃 노드의 가로 표본 차이는 1입니다. spacing_x가 2라면 설정된 거리 기준의 가로 길이는 2입니다. y 방향도 spacing_y로 따로 해석하므로 두 간격이 다를 때 무조건 같은 물리 길이라고 놓지 마세요. 간격과 작업 예산은 그래프의 결과 수치와 함께 기록합니다.
