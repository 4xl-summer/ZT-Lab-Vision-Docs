Contour(component_index: int, is_hole: bool, points: tuple)

component_index: 연결 성분의 0 기반 인덱스입니다.

is_hole: 구멍 경계 여부입니다.

points: ROI 로컬 픽셀 셀 경계 점들의 불변 스냅샷입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
component_index연결 성분의 0 기반 인덱스입니다.필수
is_hole구멍 경계 여부입니다.필수
pointsROI 로컬 픽셀 셀 경계 점들의 불변 스냅샷입니다.필수

값의 해석과 사용

component_index는 결과 내 성분 순번이며 is_hole은 구멍 경계 여부입니다. points는 경계 순서를 유지해야 합니다. 외곽과 구멍의 점을 하나로 이어 붙이면 원래 없던 선분이 생길 수 있습니다.

성분과 구멍

component_index는 연결 성분의 결과 내 인덱스이고 is_hole은 구멍 경계를 나타냅니다. 같은 성분이라도 외부 경계와 구멍 경계를 각각 읽어야 하며 points의 순서를 바꾸면 원래 경로가 달라집니다.
