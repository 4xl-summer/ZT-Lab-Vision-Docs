OcrRead(status: zvision._recognition.ReadStatus, reasons: zvision._recognition.ReadReason, text: str, chars: tuple, contrast: float, confidence: float | None)

status: 인식 결과의 수락·미판독·거절 상태입니다.

reasons: 결과의 이유를 나타내는 비트 조합입니다.

text: 인식된 문자열의 독립 복사본입니다.

chars: 인식 문자와 위치의 독립 튜플입니다.

contrast: 원본 영역의 (최댓값−최솟값)/255입니다.

confidence: 신뢰도 값이 없으면 None입니다.

입력과 결과 해석

OCR 읽기의 상태, 사유, 전체 text, 문자별 chars, 대비와 선택적 confidence를 담는 불변 스냅샷입니다. chars는 OcrChar 튜플이며 각 문자는 코드 포인트와 로컬·전역 모서리 좌표를 담습니다. confidence는 값이 없을 수 있으므로 None을 숫자 0이나 확정된 낮은 신뢰도로 바꾸어 읽지 않습니다.

전체 문자열을 소비하기 전 status와 reasons를 함께 확인합니다. 예를 들어 이미지의 문자는 감지됐어도 지정한 allowed_chars 또는 길이 조건에 맞지 않으면 결과를 생산 설비의 수락 문자열로 바로 사용하지 않아야 합니다. contrast는 입력 픽셀 범위이며 확률이나 검증 등급이 아닙니다.
