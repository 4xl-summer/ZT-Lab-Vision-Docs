highpass_gray8(image, radius_x, radius_y, mode, sigma_x=0.0, sigma_y=0.0)

평활화 결과를 Gray8 원본에서 빼 고주파 잔차를 구합니다.

확인된 인자 조건

image: Gray8 ZImage

radius_x: x 반경 0–31

radius_y: y 반경 0–31

mode: 평균, 중앙값 또는 가우시안 방식

sigma_x: Gaussian x 표준편차; 기본값 0

sigma_y: Gaussian y 표준편차; 기본값 0

반환: 별도로 close할 부호 있는 GrayF32 영상입니다.

오류: Gaussian 모드는 양의 sigma, 다른 모드는 0이 필요합니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mode · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sigma_x · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • sigma_y · POSITIONAL_OR_KEYWORD · 기본값 0.0

radius_x: 정수 검사 · 최소 0.

radius_y: 정수 검사 · 최소 0.

sigma_x: 유한한 수 검사.

sigma_y: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Return a signed GrayF32 residual with replicate boundaries.

빠른 밝기 변화를 강조

고역 통과 처리는 주변에 비해 빠르게 변하는 밝기 구조를 강조할 수 있습니다. 가장자리뿐 아니라 작은 잡음도 빠른 변화이므로 출력에서 밝은 점이 모두 실제 결함이라는 뜻은 아닙니다. Gray8 입력과 결과의 표현을 확인합니다.

후속 판정

원본과 고역 결과를 같은 위치로 비교하고, 필터 설정을 고정해 관심 결함과 배경 잡음이 어떻게 바뀌는지 확인합니다. 출력의 임계값을 조절할 때 평활화와 함께 동시에 바꾸지 않으면 각 단계의 영향을 구분하기 쉽습니다.
