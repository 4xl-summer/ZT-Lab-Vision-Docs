inspection_difference

method · 선언 타입 zvision.ZImage

Python
inspection_difference(self, reference, mask, spec)

밝기 보정과 마스크를 적용해 기준과 차분을 계산합니다.

확인된 인자 조건

reference: 기준 Gray8·Gray16·GrayF32 영상. 입력은 같은 형식 또는 정렬 GrayF64이며 크기·원점이 같아야 합니다.

mask: 선택적 같은 기하의 Gray8 포함 마스크. 비제로 포함, None은 전체.

spec: DifferenceSpec의 밝기 보정·극성·허용치 조건.

반환: 호출자가 close할 DifferenceResult.

오류: 닫힌 객체 또는 유효하지 않은 입력은 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

정렬 후 차분 비교

기준 영상과 검사 영상을 비교하여 점수, 이진 마스크 및 부호 있는 차분을 생성합니다. 각 영상은 같은 크기와 원점을 가리켜야 하며 선택 마스크가 있으면 그 유효 영역에 대해서만 검사합니다. 위치가 다른 입력은 먼저 정렬의 발견 상태를 확인해야 합니다.

예를 들어 보정 후 잔차가 10이고 허용치가 5이며 질감 가중치가 0이면 점수는 2입니다. 극성 설정은 밝아진 쪽, 어두워진 쪽 또는 절대 변화 중 무엇을 검사하는지 정합니다. 후보 추출과 최종 제품 판정은 차분 다음 단계입니다.

이 호출은 현재 영상의 즉시 처리 경로입니다. 반환이 소유 영상이나 소유 결과이면 사용 후 close하고, 값 스냅샷과 핸들의 수명을 구별합니다. 잘못된 입력이나 형식에서 발생한 오류를 빈 정상 결과로 치환하지 않습니다.

mask선택적 같은 기하의 Gray8 포함 마스크. 비제로 포함, None은 전체.
