QueryExecution.close 공개 계약

상위 목차로 돌아가기

close

method · 선언 타입 zvision._typed_query.QueryExecution

Python
close(self) -> 'None'

반환 타입 주석: None

실행과 캡처 소유권을 해제한다. 반복 호출은 안전하다.

이 호출의 입력과 객체 맥락

형식 지정 쿼리 실행과 그 실행이 소유한 캡처를 해제합니다. 이미 output에서 꺼낸 불변 값 스냅샷은 계속 유효하지만 닫힌 실행에서 output을 다시 읽을 수는 없습니다. get_image로 따로 얻은 캡처 영상은 별도 소유 핸들이므로 각각 close합니다. close는 반복 호출할 수 있으며 with 블록 종료 시에도 실행됩니다.

형식 지정 실행의 종료

QueryExecution.close는 실행과 그 실행이 소유한 캡처를 해제하고 None을 반환합니다. 반복 호출은 안전합니다. 닫힌 실행에서 output이나 캡처를 새로 요청하지 않도록 필요한 값을 먼저 읽습니다.

이미 output에서 얻은 불변 값 스냅샷은 실행 객체와 독립적으로 사용할 수 있습니다. 반면 GetImage로 획득한 ZImage는 별도의 소유 핸들이므로 사용 후 그 영상도 close합니다. 공유 영상의 소유와 픽셀을 깊게 복사하는 것은 다른 관계입니다.

항목의미와 사용
output실행 결과의 불변 값 스냅샷
get_image별도 소유 캡처 영상 획득
close실행 및 자체 캡처 해제
획득 영상사용 후 별도로 close
반복 close안전
닫힌 실행새 결과 접근에 사용하지 않음

예를 들어 블롭 분석 실행에서 면적 목록을 읽고 중간 마스크를 별도로 획득했다면, 실행을 닫는 작업과 마스크 영상의 종료를 각각 관리합니다. 영상이 필요할 때는 계획 단계에서 지정한 정확한 캡처 이름으로 조회하고 오류를 확인합니다.
