ZImage.open 공개 계약

상위 목차로 돌아가기

open

method · 선언 타입 zvision.ZImage

Python
open(self, kernel)

Gray8의 비영 전경에 이진 침식 후 팽창을 적용합니다.

확인된 인자 조건

kernel: 기본값 없는 양의 홀수 정사각형 폭(픽셀)

반환: 0/255 새 Gray8 마스크. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 0·짝수 폭이나 미지원 형식은 오류입니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

작은 전경을 다듬는 열기

열기는 침식 다음 팽창을 적용하는 형태학 조합입니다. 좁은 돌기나 작은 전경 잡음이 약해질 수 있지만 커널보다 작은 실제 물체도 사라질 수 있습니다. 이진 전경과 커널 모양을 먼저 정하고 대상의 최소 크기를 확인합니다.

중간 단계 확인

침식과 팽창의 순서를 바꾸면 닫기가 되므로 동일한 연산이 아닙니다. 결과에서 작은 물체가 사라졌다면 먼저 침식 단계에서 구조 요소가 물체에 들어가는지 살펴봅니다. 반환 마스크를 원본과 겹쳐 필요한 구조가 남았는지 확인합니다.
