labels

method · 선언 타입 zvision._blob_advanced.BlobResult

Python
labels(self, width, height)

라벨 맵의 행 우선 값을 복사합니다.

확인된 인자 조건

width: 라벨 맵과 같은 양의 폭

height: 라벨 맵과 같은 양의 높이

반환: 독립 정수 list입니다.

오류: 실제 맵 크기와 다르면 오류입니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

행 우선 레이블 복사

레이블 맵의 정수들을 독립 list로 복사합니다. width와 height는 실제 맵과 같은 양의 크기여야 하며 맞지 않으면 오류입니다. 폭 3, 높이 2면 6개의 위치를 행 순서로 읽습니다.

성분과 배경

0은 배경으로 읽고 나머지 레이블은 해당 결과의 성분 소속을 나타냅니다. ROI 원점을 적용해 전체 영상에 표시하고, 정수 목록의 레이블 번호를 다른 결과의 영구 물체 식별자로 가정하지 않습니다.
