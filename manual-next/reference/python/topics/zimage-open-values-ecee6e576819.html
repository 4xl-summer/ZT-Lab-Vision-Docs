open_values(self, kernel_size: int)

값 침식 후 팽창을 적용합니다.

확인된 인자 조건

kernel_size: 양의 홀수 커널 폭

반환: 별도로 close할 ZImage입니다.

오류: 인자나 영상 형식이 지원되지 않으면 오류입니다.

인자 선언

  • kernel_size · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

kernel_size: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

밝기 값의 열기

값 열기는 회색값 침식 후 팽창을 적용하는 조합입니다. 한 위치의 밝기만 독립적으로 조정하는 방식이 아니라 커널 안의 주변 표본에 영향을 받습니다. 작은 밝은 돌기와 유지해야 하는 구조를 구분해 평가합니다.

커널과 해석

홀수 커널 폭과 반복 적용 횟수를 혼동하지 말고 지정된 호출 조건을 확인합니다. 같은 입력에서 결과를 원본과 겹쳐 본 뒤 후속 통계나 임계 처리에 어떤 영향을 주었는지 비교합니다. 독립 출력 영상은 더 이상 필요하지 않을 때 닫습니다.
