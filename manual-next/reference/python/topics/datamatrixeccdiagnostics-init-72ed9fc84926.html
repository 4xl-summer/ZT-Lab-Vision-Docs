DataMatrixEccDiagnostics(text: str, version: int, blocks: tuple, corrected_codewords: int, accepted: bool)

text: ECC 복구 후 디코딩한 문자열입니다.

version: 디코딩된 Data Matrix 버전 번호입니다.

blocks: 각 Reed–Solomon 블록의 코드워드 진단을 담은 불변 튜플입니다.

corrected_codewords: 모든 블록에서 실제 정정한 코드워드 수의 합입니다.

accepted: 각 블록의 정정 수가 지정한 허용 상한을 만족하는지 나타냅니다. 정정 자체는 승인 판정 전에 수행됩니다.

이 호출의 입력과 객체 맥락

Data Matrix 오류 정정 진단의 text, version, blocks, corrected_codewords와 accepted를 담는 값입니다. 블록 항목은 QrEccBlock 형식의 데이터·패리티·정정 코드워드 수를 사용하지만 결과의 기호 형식은 Data Matrix입니다. 타입 이름만 보고 QR 영상의 버전이나 오류 정정 수준으로 해석하지 않습니다.

동일한 문자가 복원되어도 정정된 코드워드 수는 입력 손상에 따라 달라질 수 있습니다. 총 수치와 각 블록을 같이 읽고, 지정된 블록별 한도에 대한 accepted를 확인합니다. 한도는 정정 이후의 수락 검사로 사용되며 디코더의 정정 능력을 새로 설정하는 값이 아닙니다.

전체 정정량과 블록별 판정

DataMatrixEccDiagnostics는 디코딩된 text, 버전, QrEccBlock 튜플, 전체 corrected_codewords 및 accepted를 담는 불변 값입니다. blocks는 각 Reed–Solomon 블록의 데이터·패리티·수정 코드워드 수를 나타냅니다. 블록 타입의 이름에 QR이 있어도 이 진단 값은 Data Matrix의 결과입니다.

예를 들어 두 블록의 수정 수가 각각 1과 2라면 전체 corrected_codewords는 3입니다. 블록당 허용 한도가 1인 진단에서는 두 번째 블록이 한도를 초과합니다. 반면 한도가 2라면 두 블록의 수정 수는 각각 그 한도 이내입니다. 이 판단은 정정 후의 허용 규칙으로 정정 동작을 바꾸는 설정이 아닙니다.

적용과 결과 확인

생성자는 blocks의 항목이 QrEccBlock인지 검사해 튜플로 보관하지만, 수동 생성한 총합과 각 블록 숫자가 실제 디코드에서 나온 것인지 대신 증명하지 않습니다. 실제 진단 호출의 반환값과 손으로 만든 예시 값을 구분하세요. 수정된 코드워드 수를 손상 모듈의 수, 성공 확률 또는 ISO 등급으로 바꾸어 읽지 않습니다.
