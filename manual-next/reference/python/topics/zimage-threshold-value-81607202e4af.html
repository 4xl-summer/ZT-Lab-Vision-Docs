ZImage.threshold_value 공개 계약

threshold_value

method · 선언 타입 zvision.ZImage

Python
threshold_value(self, t)

threshold의 별칭입니다.

확인된 인자 조건

t: 유한 실수 임계값, 원본 픽셀 단위

반환: 입력 7종 Gray 형식에 대한 새 Gray8 마스크; 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 비유한 임계값·부동소수 픽셀 또는 미지원 입력은 오류입니다.

인자 선언

  • t · POSITIONAL_OR_KEYWORD · 기본값 없음

Alias for threshold: finite scalar t, seven Gray formats, owned Gray8 mask.

명시 임계값의 비교

지정한 기준값을 이용해 픽셀을 나누는 연산입니다. 입력 형식과 임계값의 단위를 일치시켜야 결과를 해석할 수 있습니다. 값이 기준과 정확히 같을 때 포함되는지 비교 규칙을 확인하면 경계 한 픽셀의 차이를 진단할 수 있습니다.

결과 확인

임계값보다 작은 값, 같은 값, 큰 값을 한 입력에 놓고 각 위치의 출력을 비교합니다. 반환 마스크의 전경 값은 선택 표시이며 원래 밝기 값을 보존하는 것은 아닙니다. 밝기 측정이 필요하면 원본을 따로 유지하고 출력 핸들을 정리합니다.
