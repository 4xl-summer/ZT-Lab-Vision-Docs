parts(self)

스펙트럼의 실수부와 허수부를 복사합니다.

반환: 행 우선 순서인 독립 실수부와 허수부 튜플의 쌍을 반환합니다.

오류: 닫힌 스펙트럼에서는 오류입니다.

Return independently copied real and imaginary row-major tuples.

이 호출의 입력과 객체 맥락

현재 복소 스펙트럼의 실수부와 허수부를 행 우선으로 각각 복사해 반환합니다. 예를 들어 너비 2, 높이 3이면 두 복사 배열은 같은 6개 좌표를 같은 순서로 나타냅니다. 배열의 항목과 좌표는 스펙트럼 메타데이터의 크기와 함께 해석하고, 값을 수정해 다른 모델을 만들려면 FromParts 또는 from_parts를 별도로 호출합니다.

입력과 결과 확인

parts는 현재 복소 스펙트럼의 실수부와 허수부를 각각 복사한 행 우선 튜플 쌍을 반환합니다. 같은 인덱스의 두 숫자는 동일한 주파수 위치에서 한 복소 계수를 구성합니다. 둘 중 하나만으로 위상 정보를 보존하는 복소 계수 전체를 대신할 수 없습니다.

예를 들어 변환 크기가 폭 2, 높이 3이면 실수부와 허수부는 각각 6개 원소입니다. 인덱스 0과 1은 첫 행의 두 위치이고 2와 3은 둘째 행입니다. 튜플을 해석할 때 입력 영상 크기와 변환 크기, 정규화와 출력 배열 배치를 함께 확인하십시오.

두 튜플은 독립 복사 값이며 스펙트럼 객체를 열어 둔 동안 얻은 다음 별도 자료로 보관할 수 있습니다. 값을 바꾸어 새로운 스펙트럼을 만들려면 해당 생성 경로를 별도로 호출해야 합니다. 닫힌 객체의 조회 오류를 실수부와 허수부가 모두 0인 정상 스펙트럼으로 치환하지 마십시오.

항목확인할 내용
반환실수부와 허수부의 독립 튜플 쌍입니다.
순서두 튜플이 같은 위치를 행 우선으로 나타냅니다.
크기 예2×3 스펙트럼이면 각 튜플이 6개입니다.
복소 계수같은 인덱스의 실수부와 허수부를 묶습니다.
수정수정한 값은 별도 생성 경로에 전달합니다.
수명스펙트럼을 사용 후 close합니다.

한 위치의 계수가 3+4i라면 실수부 항목은 3, 허수부 항목은 4입니다. 두 부분의 같은 인덱스를 묶어야 해당 복소 계수가 되며, 배열 하나를 다른 순서로 재정렬하면 다른 위치끼리 결합됩니다. 변환을 표시할 때 사용하는 진폭은 이 두 값을 계산해 얻는 별도의 표현입니다. 이후 역변환을 검토한다면 변환 크기와 정규화 조건을 원본 스펙트럼과 일치시키고 복사된 배열의 배치를 보존하십시오.

두 튜플의 인덱스 5는 예시의 세 번째 행 두 번째 위치입니다. 폭을 모르면 같은 인덱스를 어느 행과 열로 읽어야 하는지 판단할 수 없으므로 크기 정보를 같이 보관하십시오.
