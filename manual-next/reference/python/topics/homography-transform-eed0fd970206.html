행렬로 한 점을 변환합니다.

반환: 변환된 새 Point2 값.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

입력 점에 3×3 행렬을 적용한 뒤 앞의 두 결과를 동차 성분 w로 나누어 Point2를 돌려줍니다. 단위 행렬에 (10, 20)을 넣으면 결과는 (10, 20)입니다. 변환이 정의된 입력 프레임이 ROI 로컬인지 글로벌인지 확인하고 출력의 기준도 별도로 기록하세요. 투영 지평선에 가깝거나 계산 결과가 유한하지 않은 점은 오류입니다. 한 점의 좌표 변환은 영상 전체를 리샘플링하는 워프와 별개의 호출입니다.

이 객체의 확인된 공개 생성 경로: Homography(m00: float, m01: float, m02: float, m10: float, m11: float, m12: float, m20: float, m21: float, m22: float) -> None.
