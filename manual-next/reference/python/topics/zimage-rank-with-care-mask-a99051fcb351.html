rank_with_care_mask(self, mask, offset_x, offset_y, spec)

선택된 이웃 표본의 순위값으로 필터링합니다.

확인된 인자 조건

mask: care 마스크

offset_x: 마스크 x 오프셋

offset_y: 마스크 y 오프셋

spec: RankSpec

반환: 별도로 close할 ZImage입니다.

오류: 설정이 유효하지 않거나 선택된 이웃이 없으면 오류입니다.

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • offset_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Filter using the rank among selected samples.

관심 위치의 순위 필터

care mask와 순위 필터 설정을 사용하여 이웃 값의 순서 통계를 적용합니다. 중앙값은 순위 통계의 한 예로, 정렬된 값의 중간을 선택합니다. 실제 순위와 이웃 범위는 이 호출의 옵션을 확인해야 합니다.

입력과 결과

원본과 마스크의 크기 및 위치를 맞추고 선택한 순위와 커널 설정을 기록합니다. 결과의 관심 경계와 작은 구조를 원본과 비교하면 필터가 잡음뿐 아니라 대상에도 미친 영향을 볼 수 있습니다. 선택되지 않은 위치는 해당 계약에 따라 해석합니다.
