python 공개 선언
IntrinsicOptions(max_iterations: int, damping: float, gradient_tolerance: float, max_work: int) -> None

Fixed-pose local LM limits and conservative maximum projection work.

max_iterations: 내부 파라미터 적합의 반복 상한입니다.

damping: 초기 LM 감쇠값입니다.

gradient_tolerance: 정규화 기울기의 수렴 임계값입니다.

max_work: 허용할 추정 투영 작업량 상한입니다.

이 호출의 입력과 객체 맥락

IntrinsicOptions는 고정된 자세를 사용하는 카메라 내부 파라미터 국소 최적화의 조건을 지정합니다. max_iterations는 반복 상한이고 damping은 최적화 감쇠, gradient_tolerance는 종료 판정에 쓰이는 기준이며 max_work는 보수적인 투영 작업량 한도입니다. 이 값들은 카메라의 실제 초점 거리나 픽셀 크기가 아닙니다.

예를 들어 관측점과 반복 상한으로 필요한 보수적 작업 한도를 intrinsic_required_work에서 확인해 max_work 설정에 반영할 수 있습니다. 제한이 너무 작으면 원하는 최적화에 필요한 작업량을 허용하지 못할 수 있습니다. 반대로 계산량을 크게 정하는 것만으로 잘못된 관측 대응이나 틀린 고정 자세를 수정할 수는 없습니다.

고정 자세 최적화의 한도

IntrinsicOptions는 고정된 자세에서 카메라 내부 계수를 국소적으로 적합할 때 반복 상한 max_iterations, 초기 감쇠 damping, 정규화 기울기 허용값 gradient_tolerance와 작업 한도 max_work를 묶습니다. 옵션을 구성하는 것과 실제 관측을 최적화하는 호출은 별개입니다.

예를 들어 관측점 개수와 최대 반복 수가 바뀌면 필요한 보수적 투영 작업량도 달라질 수 있습니다. intrinsic_required_work에 동일한 점 수와 반복 상한을 전달해 값을 구하고 max_work를 계획하세요. 이 값은 바이트나 실제 소요 밀리초가 아니라 알고리즘이 허용하는 투영 작업 예산입니다.

적용과 결과 확인

결과의 status, iterations, accepted_steps와 초기·최종 RMS를 함께 확인합니다. 최종 RMS가 줄어도 고정된 카메라 자세가 틀렸거나 관측 대응이 잘못되었다면 물리적으로 올바른 보정을 보장하지 않습니다. 관측점을 화면 전반에 분포시키고 보류한 점으로 재투영 차이를 평가하세요. 기울기 허용값과 RMS는 서로 다른 진단입니다.
