inspect_quality_scored(self, training, image, options, acceptance_percent, fill_left=None, fill_right=None, world=None, world_maps=None)

훈련 기준과 현재 비드의 폭·명암·점유율·에지 변화를 비교합니다.

확인된 인자 조건

training: 학습에 사용된 기준 ZImage

image: 검사 ZImage

options: BeadQualityOptions

fill_left: 탐침별 왼쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None

fill_right: 탐침별 오른쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None

world: 선택적 6개 아핀 계수; 기본값 None

world_maps: 선택적 세계 좌표 영상 2개; 기본값 None, world와 동시 사용 불가

acceptance_percent: 승인 백분율 0–100

반환: close할 BeadQualityResult와 점수 값의 쌍입니다.

오류: 영상, 옵션·대체 배열 또는 상호 배타적인 세계 보정이 유효하지 않으면 오류입니다.

인자 선언

  • training · POSITIONAL_OR_KEYWORD · 기본값 없음
  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • acceptance_percent · POSITIONAL_OR_KEYWORD · 기본값 없음
  • fill_left · POSITIONAL_OR_KEYWORD · 기본값 None
  • fill_right · POSITIONAL_OR_KEYWORD · 기본값 None
  • world · POSITIONAL_OR_KEYWORD · 기본값 None
  • world_maps · POSITIONAL_OR_KEYWORD · 기본값 None

acceptance_percent: 유한한 수 검사.

Return (quality result, score over included trained probes).

인자별 입력 조건

인자형식역할과 조건
training학습에 사용된 기준 ZImage
image검사 ZImage
optionsBeadQualityOptions
acceptance_percent승인 백분율 0–100
fill_left탐침별 왼쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None
fill_right탐침별 오른쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None
world선택적 6개 아핀 계수; 기본값 None
world_maps선택적 세계 좌표 영상 2개; 기본값 None, world와 동시 사용 불가

품질과 수락 점수

품질 결과와 포함된 학습 탐침에 대한 수락 점수를 튜플로 반환합니다. acceptance_percent는 0부터 100까지이며 범위 밖은 ValueError입니다.

예를 들어 한도를 90으로 설정했다면 그 설정과 반환 점수를 함께 기록합니다. 점수 하나만으로 위반 위치를 알 수 없으므로 품질 결과의 탐침 및 구간을 확인합니다. 반환된 소유 품질 결과는 사용 후 close합니다.
