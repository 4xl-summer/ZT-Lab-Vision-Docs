UnicodeTextCheck(scalar_count: int, reasons: int, accepted: bool) -> None

UnicodeTextCheck(scalar_count: int, reasons: int, accepted: bool)

scalar_count: 문자열의 Unicode 스칼라 값 개수입니다. 바이트 수와 다를 수 있습니다.

reasons: 빈 문자열, 길이, 문자 집합 규칙 위반을 나타내는 비트 마스크입니다.

accepted: 규칙 위반 비트가 없으면 참입니다.

이 호출의 입력과 객체 맥락

문자열 검사 결과의 scalar_count, reasons, accepted를 담는 불변 값입니다. scalar_count는 유니코드 스칼라 값의 수이고 UTF-8 바이트 길이와 구분해야 합니다. 예를 들어 문자 하나가 UTF-8에서 여러 바이트로 인코딩되더라도 스칼라 수는 바이트 수와 같지 않을 수 있습니다.

accepted는 적용한 문자 및 길이 조건에 대한 수락 여부이며 reasons는 거절 사유를 나타냅니다. 텍스트가 눈에 보이는 모양만으로 바이트 수나 스칼라 수를 추정하지 않고 반환값과 실제 검사 조건을 함께 기록합니다. 결합 문자가 있는 표시상의 글자 수도 스칼라 수와 다를 수 있습니다.

입력과 결과를 읽는 순서

scalar_count는 문자열을 이루는 Unicode 스칼라 값의 수입니다. UTF-8 바이트 길이나 화면에 보이는 글자 모양의 개수와는 서로 다른 단위입니다. 예를 들어 한 스칼라가 UTF-8에서 여러 바이트로 표현될 수 있고, 표시상 하나의 글자가 기본 문자와 결합 문자로 구성될 수도 있습니다.

reasons는 빈 문자열, 길이, 허용 문자 집합 등의 위반을 표현하는 비트 마스크입니다. 여러 사유가 동시에 설정될 수 있으므로 하나의 배타적 상태 번호로만 읽지 말고 각 비트를 확인합니다. accepted는 적용된 규칙에 위반 비트가 없는지를 나타냅니다.

예를 들어 길이와 문자 집합을 함께 검사했다면 거절 시 어느 조건이 문제였는지를 reasons로 구분하고 원래 규칙과 문자열을 같이 기록하세요. 이 값은 문자열 검사 결과 스냅샷이며 생성자에 숫자를 넣는 것만으로 OCR이나 바코드 판독을 실행하지 않습니다.
