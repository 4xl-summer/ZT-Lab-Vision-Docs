Lab 값의 비교

l, a, b는 각각 명도와 두 색축입니다. 예를 들어 두 값의 차이가 (3, 4, 0)이면 CIE76의 유클리드 거리는 5입니다. 이 숫자는 원본 RGB 채널 값과 다른 색 공간의 수치입니다.

두 색을 비교하기 전에 같은 백색점과 변환 조건을 사용했는지 확인합니다. 좌표값 자체를 만든 것과 실제 색 거리 함수를 실행한 것은 다른 단계입니다.
