이 호출의 입력과 객체 맥락

예를 들어 변환을 순서대로 구성할 때 항등값 다음에 (3,4) 이동을 then으로 연결하면 입력 (10,20)은 (13,24)가 됩니다. 항등값을 만든 시점에는 이미지를 읽거나 새 픽셀을 만들지 않습니다. 이미지 전체의 변환은 별도 워프 호출에 이 값을 전달하는 단계입니다.

항등 변환은 좌표를 바꾸지 않는 기준 변환입니다. 여섯 계수의 선형 부분은 단위 행렬이고 이동항은 0입니다. 따라서 점 (10, 20)을 적용하면 결과도 (10, 20)입니다. 이 계산은 입력과 출력 좌표계가 같은 기준이라는 뜻이지, 서로 다른 ROI나 세계 좌표계를 자동으로 연결한다는 뜻은 아닙니다. 변환 합성의 초기값으로 쓰면 뒤에 연결한 변환이 그대로 적용됩니다. 반환된 Affine2는 계수를 담은 값이므로 이미지 핸들을 만들거나 해제하지 않습니다.

사용 조건과 결과 판독

identity는 2×3 아핀 계수 [1,0,0,0,1,0]을 담는 값입니다. x′=a×x+b×y+tx, y′=c×x+d×y+ty에 이 계수를 넣으면 x′=x, y′=y입니다. 예를 들어 (10,20)에 적용해도 결과는 (10,20)입니다.

then은 현재 변환을 먼저, 인자를 나중에 적용합니다. 항등값 다음에 (3,4) 이동을 연결하면 (10,20)은 (13,24)가 됩니다. 반면 원점·좌표계가 다른 데이터를 항등값에 넣어도 숫자가 바뀌지 않을 뿐, 서로 다른 기준이 자동으로 일치하는 것은 아닙니다.

ROI 로컬 픽셀과 전체 프레임 픽셀을 연결하려면 실제 원점 이동을 명시해야 합니다. 세계 길이로 바꾸는 보정도 별도의 변환입니다. 반환 Affine2는 계수 스냅샷이며 이미지를 읽거나 새 영상 핸들을 생성하지 않으므로 영상 워프가 필요하면 별도 API를 사용합니다.
