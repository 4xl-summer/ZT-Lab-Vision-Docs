Match3D(model_index: int, overlap: float, registration: zvision._spatial3d_advanced.Registration)

model_index: 입력 모델 시퀀스에서 일치한 모델의 0 기반 인덱스입니다.

overlap: 모델과 목표의 정합 겹침 비율입니다.

registration: 일치 후보의 정합 변환과 진단입니다.

값을 구성하고 해석하기

모델 목록 중 어느 항목이 정합되었는지 model_index로 연결하고 overlap과 registration을 함께 보관합니다. 인덱스는 0부터 시작하므로 호출에 전달한 입력 모델 순서를 유지해야 원래 모델을 찾을 수 있습니다. 겹침 비율만으로 정합 변환과 진단을 대신할 수는 없습니다.
