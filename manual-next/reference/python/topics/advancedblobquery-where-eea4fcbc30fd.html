where

method · 선언 타입 zvision._advanced_blob_query.AdvancedBlobQuery

Python
where(self, expression, include=True)

선택 표현식으로 새 불변 고급 Blob 계획을 만듭니다.

확인된 인자 조건

expression: Expr 또는 프록시를 받는 callable

include: bool; 조건에 맞는 항목 포함 여부, 기본값 True

반환: 별도로 close할 새 AdvancedBlobQuery입니다.

오류: 표현식 또는 include가 유효하지 않으면 오류입니다.

인자 선언

  • expression · POSITIONAL_OR_KEYWORD · 기본값 없음
  • include · POSITIONAL_OR_KEYWORD · 기본값 True

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

새 선택 계획

Expr 또는 프록시를 받는 callable 조건을 이용해 새 불변 고급 Blob 계획을 만듭니다. include는 bool이고 기본 True로 조건 일치 항목을 포함합니다. 원래 계획을 제자리에서 변경하는 것과 구분합니다.

선택과 실행

예를 들어 면적에 관한 조건을 적용할 때 area가 픽셀 수인지 확인한 뒤 run으로 원본 성분 인덱스를 얻습니다. 반환 쿼리는 별도 소유이므로 닫고, 잘못된 표현식이나 include 타입은 오류 조건을 확인합니다.
