suppress_polygon_overlaps(self, matches, max_iou, limit)

변환된 템플릿 다각형의 겹침을 사용해 후보를 억제합니다.

확인된 인자 조건

matches: 억제할 후보들의 열입니다.

max_iou: 허용할 최대 교집합 비율입니다.

limit: 유지할 결과의 최대 개수입니다.

반환: 남은 후보의 독립 불변 튜플입니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

인자 선언

  • matches · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_iou · POSITIONAL_OR_KEYWORD · 기본값 없음
  • limit · POSITIONAL_OR_KEYWORD · 기본값 없음

Suppress overlapping transformed match polygons.

호출 맥락과 결과 해석

변환된 템플릿 다각형끼리의 겹침을 기준으로 기존 후보를 억제합니다. 축 정렬 경계상자 IoU를 사용하는 suppress와 비교하면 회전된 후보의 겹침 판단 기준이 다릅니다. 후보를 새로 찾는 기능은 아닙니다.

max_iou로 허용 겹침을 지정하고 limit으로 남길 결과 수를 제한합니다. 같은 후보 집합을 두 억제 방식에 전달해 어떤 포즈가 유지되는지 비교하면 경계상자와 실제 템플릿 다각형의 차이를 확인할 수 있습니다.

입력 선택을 위한 확인

입력의미와 조건
matches억제할 후보들의 열입니다.
max_iou허용할 최대 교집합 비율입니다.
limit유지할 결과의 최대 개수입니다.

반환값 확인

남은 후보의 독립 불변 튜플입니다.
