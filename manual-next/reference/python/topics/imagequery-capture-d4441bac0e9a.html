capture(self, name)

지정 이름으로 중간 영상을 캡처하도록 단계를 추가합니다.

확인된 인자 조건

name: 캡처 이름

반환: 수정된 동일 ImageQuery입니다.

오류: 이름 또는 계획이 유효하지 않으면 오류입니다.

인자 선언

  • name · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

중간 영상의 이름 지정

현재 계획의 중간 영상을 이름 붙여 캡처합니다. 후속 필터나 임계 처리 이후의 출력과 그 이전 단계를 비교할 수 있으므로 결과가 달라진 지점을 찾는 데 유용합니다. 이름은 조회할 때 정확히 구분해 사용합니다.

실행과 조회

캡처 설정만으로 픽셀이 계산되는 것은 아닙니다. 계획을 실행한 다음 실행 결과에서 지정한 이름으로 이미지를 조회하고 실패 여부를 확인합니다. 캡처 영상과 실행 객체의 공유 및 해제 규칙을 해당 결과 계약에 따라 관리합니다.
