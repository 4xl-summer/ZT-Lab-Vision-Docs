이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

맨해튼 색 거리 선택

Lab 각 축의 차이의 절댓값을 더하는 거리 선택을 만듭니다. 예를 들어 축별 차이가 1, -2, 3이면 합은 6입니다. 이 팩터리는 추가 매개변수를 요구하지 않습니다.

이 객체를 사용하는 색 비교에서 입력 Lab의 백색점과 단위를 맞춰야 합니다. 이 선택만으로 두 영상을 정렬하거나 허용 기준을 자동 설정하지 않습니다.

축별 절댓값 합

맨해튼 거리는 Lab 각 축의 차이에 절댓값을 취한 다음 더합니다. 예를 들어 차이가 (1, -2, 3)이면 1+2+3=6입니다. 이 팩터리는 거리 계산을 아직 실행하지 않으며 선택된 방식의 ColorDistance 값을 반환합니다.

같은 차이에 대한 CIE76 유클리드 거리는 √14이므로 두 방식의 결과를 같은 수치로 보지 않습니다. 한 방식에서 사용한 허용치를 다른 방식에 바꾸지 않고 적용하기 전에 해당 기준이 유효한지 별도로 검토합니다.

두 색상은 같은 Lab 백색점과 관측 조건으로 준비해야 합니다. 방법을 선택한 다음 기준과 검사 색의 거리를 계산하고, 정한 허용치에 따라 별도 판정합니다. 거리 설정은 이미지를 정렬하거나 조명을 자동 보정하지 않습니다.
