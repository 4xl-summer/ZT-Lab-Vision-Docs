ShapePoseRefineOptions(position_step: float = 0.5, angle_step: float = 0.1, scale_step: float = 0.01, tolerance: float = 0.001, levels: int = 8, iterations_per_level: int = 10, max_evaluations: int = 1000, min_gradient: float = 1.0, min_coverage: float = 1.0, either_polarity: bool = False, mask_offset_x: int = 0, mask_offset_y: int = 0) -> None

Position/angle/scale steps; tolerance; levels; iterations; evaluation and edge/coverage limits; polarity and mask offset.

position_step: 위치의 초기 정밀화 간격(픽셀)이며 유한한 비음수입니다. 기본값 0.5입니다.

angle_step: 각도의 초기 정밀화 간격(라디안)이며 유한한 비음수입니다. 기본값 0.1입니다.

scale_step: 배율의 초기 정밀화 간격이며 유한한 비음수입니다. 기본값 0.01입니다.

tolerance: 혼합된 위치·각도·배율 간격에 적용할 수치적 수렴 기준으로 유한한 비음수입니다. 정밀도나 전역 최적 보장은 아닙니다. 기본값 0.001입니다.

levels: 간격 정밀화 단계 수로 1..16입니다. 기본값 8입니다.

iterations_per_level: 각 단계의 반복 상한으로 1..100입니다. 기본값 10입니다.

max_evaluations: 포즈 평가 상한으로 1..1000000입니다. 모델 특징점 수와의 곱도 100000000 이하여야 합니다. 기본값 1000입니다.

min_gradient: 기울기 하한으로 유한한 비음수입니다. 기본값 1입니다.

min_coverage: 유효 표본 비율의 하한으로 0보다 크고 1 이하여야 합니다. 기본값 1입니다.

either_polarity: 반전 극성 허용 여부입니다. 기본값 False입니다.

mask_offset_x: 검색 영상 로컬 기준의 마스크 원점 x(부호 있는 32비트 정수)입니다. 기본값 0입니다.

mask_offset_y: 검색 영상 로컬 기준의 마스크 원점 y(부호 있는 32비트 정수)입니다. 기본값 0입니다.

기존 형상 포즈 주변을 국소 정밀화할 때 위치·각도·배율 간격과 평가 예산을 정합니다. position_step은 픽셀, angle_step은 라디안이며 scale_step은 배율 간격입니다. tolerance는 혼합된 간격에 적용하는 수치 수렴 기준으로 전역 최적이나 최종 정밀도를 보장하지 않습니다.
