inverse(self)

계수로 영상을 역변환합니다.

반환: 입력 ROI 원점을 보존하는 독립 GrayF64 영상이며 close합니다.

오류: 닫힌 객체, 잘못된 계수 또는 옵션은 오류입니다.

Reconstruct a new GrayF64 image retaining the input ROI origin.

이 호출의 입력과 객체 맥락

모델 계수를 합성하여 입력 ROI 원점을 유지하는 GrayF64 영상을 반환합니다. 숫자 계수 배열과 달리 이 결과는 소유 ZImage이므로 사용 후 close합니다. 모델을 변경한 결과를 비교하려면 각 모델에서 별도 복원 영상을 얻고 같은 ROI 원점과 크기 기준으로 비교하세요. 모델 자체도 별도로 close해야 합니다.

계수에서 영상으로

inverse는 HaarWavelet 모델의 현재 계수를 합성해 새 GrayF64 ZImage를 반환합니다. 결과 영상은 모델이나 계수 배열이 아니며 별도 소유 핸들이므로 사용 후 close 또는 with로 정리합니다. 출력의 ROI 원점은 처음 변환한 입력 ROI의 원점을 유지합니다.

모델의 계수는 분해 대역을 담는 행 우선 배열입니다. 계수를 바꾸거나 축소한 별도 모델에서 inverse를 호출하면 각 모델의 계수에 해당하는 복원 영상을 얻습니다. 원본과 복원을 비교할 때 크기와 ROI 원점이 같은지 먼저 확인하고, 소수 정밀도 차이를 고려해 픽셀 차이를 읽습니다.

예를 들어 ROI 원점이 (10,20)인 입력에서 변환 모델을 만든 경우 복원 영상도 그 원점을 갖습니다. 영상 로컬 (2,3)은 원본 좌표계의 (12,23)에 대응합니다. 모델과 반환 영상은 서로 다른 소유 객체이므로 복원 영상 사용을 마친 뒤 영상과 모델을 각각 닫습니다.

판독과 확인 사례

분해 수준은 입력의 해당 단계 양축이 짝수여야 하는 조건과 연결됩니다. Forward가 성공한 모델에 대해 inverse를 수행하며, 닫힌 모델에 재호출하면 오류가 납니다. 변환 모델을 이미 닫았는지와 반환된 영상의 핸들을 닫았는지는 각각 확인합니다.

계수의 행 우선 배열을 따로 읽었다면 폭과 높이, 분해 수준과 함께 보관해야 값이 어느 위치의 계수인지 해석할 수 있습니다. 계수 배열의 수정은 원래 모델을 자동으로 변경하지 않으므로 변경 내용을 적용한 별도 모델에서 복원한 영상과 원래 복원 영상을 같은 ROI로 비교합니다.
