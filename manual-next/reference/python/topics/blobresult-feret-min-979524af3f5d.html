최소 페레 폭

선택한 Blob의 최소 페레 폭을 계산해 float로 반환합니다. 특정 방향에서 측정하는 feret과 구분하며 index는 0 기반입니다. 예를 들어 가로와 세로 크기가 다른 도형은 방향에 따라 투영 폭이 달라집니다.

결과 검사

존재하지 않는 성분 인덱스는 오류입니다. 마스크가 잘리거나 잡음이 붙으면 외곽과 폭이 달라질 수 있으므로 원본 성분과 결과를 함께 확인합니다. 이 인덱스는 정수이므로 속성 접근 대상이 아닙니다.
