find_with_prior(self, source, options, prior, mask=None)

주어진 예상 포즈에 가까운 격자점부터 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 검색 설정입니다.

mask: 선택적 검색 마스크입니다.

prior: 평가 순서에 사용할 예상 포즈입니다.

반환: 독립 검색 결과와 종료 진단을 반환합니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • prior · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search the bounded grid with an explicit pose prior.

호출 맥락과 결과 해석

prior에 가까운 격자점부터 후보를 평가합니다. prior는 평가 순서를 위한 예상 포즈이며 검색 설정의 격자 자체를 대체하는 인자가 아닙니다. 따라서 prior와 각 축의 범위가 서로 맞는지 함께 확인해야 합니다.

평가 예산이 검색 전체 조합보다 작으면 평가 순서가 확인된 후보에 영향을 줄 수 있습니다. 우선 포즈, 후보 예산, 반환된 종료 진단을 같이 저장하면 일찍 종료된 결과와 충분히 평가된 결과를 구분하는 데 도움이 됩니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options확장 검색 설정입니다.
prior평가 순서에 사용할 예상 포즈입니다.
mask선택적 검색 마스크입니다.

반환값 확인
