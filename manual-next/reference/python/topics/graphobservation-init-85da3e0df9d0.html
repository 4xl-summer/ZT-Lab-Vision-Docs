GraphObservation(camera: int, board: int, target: object, pixels: object) -> None

One camera's corresponding target points and image pixels for a shared board index.

camera: 0부터 시작하는 카메라 인덱스.

board: 0부터 시작하는 보드 자세 인덱스.

target: 해당 보드 평면의 물리 Point2 좌표 열.

pixels: 대응 글로벌 영상 픽셀 Point2 좌표 열.

이 호출의 입력과 객체 맥락

GraphObservation은 공동 보정 그래프에서 한 카메라가 한 보드를 관측한 자료를 나타냅니다. camera와 board는 각각 카메라와 보드 인덱스이고 target과 pixels는 타깃 점과 해당 영상 픽셀의 대응 목록입니다. 보드의 한 점과 픽셀의 같은 순번이 실제로 같은 물리적 점을 뜻해야 합니다.

예를 들어 camera=0, board=2인 항목과 camera=1, board=2인 항목은 두 카메라가 같은 보드 인덱스를 관측하는 관계를 표현합니다. 각각의 픽셀 배열이 서로 달라도 target의 점 대응은 정확해야 합니다. 실제로 동시에 또는 일관된 자세에서 얻은 관측인지와 영상의 ROI 원점을 먼저 확인하세요.

사용 흐름과 결과 판독

GraphObservation은 한 카메라가 한 보드 자세에서 본 표적 점과 영상 픽셀의 대응을 묶습니다. camera와 board는 각각 카메라 배열과 보드 자세 배열의 0 기반 인덱스입니다. target은 보드 평면의 물리 Point2이고 pixels는 그 점에 대응하는 글로벌 영상 픽셀 Point2입니다. 두 배열은 같은 순서로 같은 실제 점을 가리켜야 합니다.

예를 들어 camera=0, board=2와 camera=1, board=2인 두 관측은 같은 보드 인덱스를 두 카메라가 관찰하는 연결을 표현합니다. 두 영상의 픽셀 좌표는 다를 수 있지만 각 target[i]와 pixels[i]는 해당 관측에서 같은 표적점이어야 합니다. 하나의 배열만 재정렬하면 길이가 맞고 수치가 유한해도 다른 대응 문제를 풀게 됩니다.

ROI 로컬에서 얻은 점이라면 해당 원점을 더해 글로벌 픽셀 기준으로 준비합니다. 보드가 실제로 같은 자세로 취급될 수 있는 관측인지와 카메라의 좌표계를 확인하고 입력 단위도 기록합니다. 이 값 객체의 생성은 공동 정련을 실행하지 않으며 이후 그래프 보정의 입력으로 사용됩니다.
