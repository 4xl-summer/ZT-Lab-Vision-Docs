to_advanced_planes(self, white=<AdvancedWhitePoint.D50: 0>, transfer=None, space=<AdvancedColorSpace.LAB: 0>)

영상을 지정 백색점·입력 전달 함수의 Lab 또는 LCH 평면으로 변환합니다.

확인된 인자 조건

white: 백색점; 기본 D50.

transfer: 입력 전달 함수; None이면 sRGB.

space: 출력 색 공간; 기본 LAB.

반환: 호출자가 close할 AdvancedPlanes 소유 객체입니다.

오류: 닫힌 객체 또는 지원되지 않는 형식·옵션은 오류입니다.

인자 선언

  • white · POSITIONAL_OR_KEYWORD · 기본값 <AdvancedWhitePoint.D50: 0>
  • transfer · POSITIONAL_OR_KEYWORD · 기본값 None
  • space · POSITIONAL_OR_KEYWORD · 기본값 <AdvancedColorSpace.LAB: 0>

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Convert this image to closeable Lab or LCH planes.

고급 색상 평면

색상 영상의 채널을 고급 평면 표현으로 가져오는 호출입니다. 각 평면의 색 공간과 채널 순서는 반환 타입의 계약으로 확인해야 하며, 원본의 RGB 또는 BGR 바이트 배열을 그대로 한 채널로 해석해서는 안 됩니다.

입력과 수명

입력 형식과 결과의 평면 수, 각 평면의 값 범위를 확인한 뒤 필요한 채널을 사용합니다. 결과 객체나 개별 영상의 소유 관계는 반환 타입의 계약에 따릅니다. 다른 색 공간의 같은 숫자를 직접 비교하기 전에 인코딩과 기준을 맞춥니다.
