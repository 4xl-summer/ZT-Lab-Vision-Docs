BlobSampledFeret(min_width: float, min_angle: float, max_width: float, max_angle: float, considered: int) -> None

Minimum/maximum projected width and angle over sampled directions.

min_width: 표본 각도에서의 최소 투영 폭입니다.

min_angle: 최소 폭의 표본 각도(라디안)입니다.

max_width: 표본 각도에서의 최대 투영 폭입니다.

max_angle: 최대 폭의 표본 각도(라디안)입니다.

considered: 범위에 들어간 각도 표본 수입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
min_width표본 각도에서의 최소 투영 폭입니다.필수
min_angle최소 폭의 표본 각도(라디안)입니다.필수
max_width표본 각도에서의 최대 투영 폭입니다.필수
max_angle최대 폭의 표본 각도(라디안)입니다.필수
considered범위에 들어간 각도 표본 수입니다.필수

값의 해석과 사용

min_width와 max_width는 고려한 각도 표본들에서의 극값이고 각도는 라디안입니다. 0도와 90도만 표본으로 하면 45도는 직접 평가되지 않으므로 considered와 각도 간격을 함께 확인합니다.
