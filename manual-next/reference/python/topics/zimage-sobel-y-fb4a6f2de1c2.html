sobel_y(self)

수직 방향 Sobel 미분을 계산합니다.

반환: 새 소유 영상. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 지원되지 않는 입력은 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

수직 방향의 밝기 변화

Sobel Y는 y 방향으로 밝기가 달라지는 정도를 측정하는 미분 필터입니다. X 방향 변화와 구분해 해석하며, 결과를 화면에 표시한 밝기만 보고 원래 영상의 밝기로 취급해서는 안 됩니다.

입력과 경계

행 방향으로 일정한 부분과 값이 달라지는 부분을 같은 좌표에서 비교합니다. 이미지 테두리의 결과는 이웃 샘플 처리에 영향을 받습니다. 출력 자료형과 부호를 확인한 뒤 필요하면 X와 Y 결과를 별도 단계에서 결합합니다.

방향별 비교

수평으로 길게 이어진 밝기 경계는 행 방향의 변화와 관련될 수 있습니다. 같은 입력의 Sobel X와 Y 결과를 같은 표시 범위로 비교하면 방향별 차이를 살펴보기 쉽습니다. 화면상 밝기는 표시 방식의 영향도 받습니다.
