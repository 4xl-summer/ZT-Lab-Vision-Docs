method · 선언 타입 zvision._frequency_processing.FrequencySpectrum

view(self, view=<SpectrumView.AMPLITUDE: 1>)

선택한 스펙트럼 보기를 복사합니다.

확인된 인자 조건

view: SpectrumView 종류; 기본값 AMPLITUDE

반환: 독립 값 튜플입니다.

오류: 보기 값이 유효하지 않으면 오류입니다.

인자 선언

  • view · POSITIONAL_OR_KEYWORD · 기본값 <SpectrumView.AMPLITUDE: 1>

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

별칭과 결과 해석

Spectrum은 FrequencySpectrum과 같은 클래스입니다. view와 values는 같은 함수이며 SpectrumView로 표시 종류를 선택합니다. 반환값은 너비×높이 개수의 독립 숫자 튜플입니다. 기본 보기는 AMPLITUDE이며 유효하지 않은 보기와 닫힌 스펙트럼은 오류입니다.

주파수 보기의 선택

SpectrumView로 복소 스펙트럼의 실수부, 허수부, 진폭, 위상, 전력 또는 로그 진폭을 선택합니다. 기본 보기는 AMPLITUDE이며 반환값은 독립 튜플입니다. 동일한 주파수 위치도 선택에 따라 다른 수치를 갖습니다.

숫자 예와 활용

복소값 3+4i의 실수부는 3, 허수부는 4, 진폭은 5이고 로그 진폭은 ln 6입니다. 결과의 보기와 주파수 격자를 함께 기록합니다. 진폭 표시에는 위상이 들어 있지 않으므로 그것만으로 일반적인 역변환을 재현하지 않습니다.
