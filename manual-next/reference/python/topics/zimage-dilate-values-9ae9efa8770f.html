dilate_values(self, kernel_size: int)

밝기 최댓값 팽창을 적용합니다.

확인된 인자 조건

kernel_size: 양의 홀수 커널 폭

반환: 별도로 close할 ZImage입니다.

오류: 인자나 영상 형식이 지원되지 않으면 오류입니다.

인자 선언

  • kernel_size · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

kernel_size: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

회색값의 국소 최댓값

값 팽창은 양의 홀수 kernel_size가 정하는 이웃에서 밝기 최댓값을 적용합니다. 예를 들어 이웃 값이 1, 4, 2라면 최댓값은 4입니다. 이진 마스크의 전경 확대와 달리 여러 회색 수준 자체를 다룹니다.

커널과 결과

kernel_size는 폭이지 반복 횟수가 아닙니다. 창이 커지면 밝은 부분이 더 넓은 주변에 영향을 줄 수 있습니다. 입력 영상 형식이 지원되는지 확인하고 원본과 출력의 경계 및 작은 밝은 구조를 비교합니다. 독립 출력은 사용 후 close합니다.
