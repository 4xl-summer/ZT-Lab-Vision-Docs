train_aligned

classmethod · 선언 타입 zvision._extended_matching.ExtendedShapeModel

Python
train_aligned(cls, images, reference, min_fraction, sample_step=1, threshold=None, mask=None)

동일 격자에 이미 정렬된 여러 영상의 공통 에지로 형상 모델을 학습합니다.

확인된 인자 조건

images: 정렬된 ZImage 2..64개입니다.

reference: 템플릿 로컬 Point2 기준점입니다.

min_fraction: 유지할 에지 출현 비율로 0보다 크고 1 이하여야 합니다.

sample_step: 양의 표본 간격(픽셀)이며 기본값 1입니다.

threshold: 유한한 비음수 기울기 임계값 또는 자동 선택 None입니다.

mask: 선택적 마스크이며 기본값 None입니다.

반환: 호출자가 닫아야 하는 ExtendedShapeModel입니다.

오류: 격자·영상·옵션이 유효하지 않으면 오류입니다.

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_fraction · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 None
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Train from multiple already aligned images.

호출 맥락과 결과 해석

이미 같은 격자에 정렬된 영상 2개에서 64개를 입력해 공통 에지로 모델을 학습합니다. 이 함수에 영상을 전달한다고 자동 정렬되는 것은 아니므로 학습 전에 각 영상의 대응 위치를 맞추고 동일한 기준점을 정해야 합니다.

min_fraction은 특징을 유지하는 데 필요한 에지 출현 비율이며 0보다 크고 1 이하여야 합니다. 예를 들어 여러 표본에서 일관된 경계를 남기려면 이 조건을 사용하고, 실제 유지된 형상은 학습 결과의 features로 점검합니다. 반환 모델은 호출자가 닫습니다.

입력 선택을 위한 확인

입력의미와 조건
images정렬된 ZImage 2..64개입니다.
reference템플릿 로컬 Point2 기준점입니다.
min_fraction유지할 에지 출현 비율로 0보다 크고 1 이하여야 합니다.
sample_step양의 표본 간격(픽셀)이며 기본값 1입니다.
threshold유한한 비음수 기울기 임계값 또는 자동 선택 None입니다.
mask선택적 마스크이며 기본값 None입니다.
