ImageQuery.close_binary 공개 계약

상위 목차로 돌아가기

close_binary

method · 선언 타입 zvision._query.ImageQuery

Python
close_binary(self, kernel, op=17)

이진 닫기 단계를 가변 계획에 추가합니다.

확인된 인자 조건

kernel: 양의 홀수 정사각형 커널 폭

op: 기본값 17은 이 메서드에 연결된 ABI 연산 코드입니다. 다른 값을 전달하면 그 코드가 네이티브 Query에 전달되어 동작이 달라지거나 오류가 날 수 있습니다. 이 인자는 보통 기본값으로 둡니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 유효하지 않은 커널 또는 실행 오류가 보고될 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • op · POSITIONAL_OR_KEYWORD · 기본값 17

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이진 닫기 단계

팽창 후 침식하는 닫기 단계를 계획에 추가합니다. 작은 틈이 메워질 수 있지만 서로 가까운 두 전경이 연결되어 후속 블롭 수가 줄어들 수 있습니다. 커널은 각 단계에서 고려하는 이웃의 크기를 정합니다.

실행 결과 확인

마스크의 전경 방향을 먼저 확인하고 계획의 닫기 전후 영상을 비교합니다. 커널 폭과 반복 횟수는 같은 인자가 아닙니다. 후속 성분 분석이 예상과 다르면 먼저 연결이 생긴 위치를 원본 마스크에서 확인합니다.
