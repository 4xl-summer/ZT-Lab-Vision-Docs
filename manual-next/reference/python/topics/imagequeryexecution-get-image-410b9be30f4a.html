get_image(self, name: 'str') -> 'ZImage'

지정 이름의 캡처 영상의 공유 핸들을 취득합니다.

확인된 인자 조건

name: 캡처 이름

반환: 호출자가 close할 독립 소유 이미지 핸들입니다.

오류: 닫힌 실행 또는 잘못된 이름은 오류입니다.

인자 선언

  • name · POSITIONAL_OR_KEYWORD · 타입 str · 기본값 없음

반환 타입 주석: ZImage

호출자가 닫는 이름 붙은 캡처 공유를 반환한다.

이름 붙인 캡처

실행 결과에서 name에 해당하는 중간 캡처의 별도 소유 ZImage 공유 핸들을 얻습니다. 쿼리 계획의 캡처 이름과 정확히 맞아야 원하는 단계를 읽을 수 있습니다.

오류와 수명

닫힌 실행이나 알 수 없는 이름은 오류입니다. 실행 후 캡처를 조회하고 원본 및 최종 출력과 같은 좌표에서 비교한 다음 획득한 영상을 close합니다. 캡처를 획득하는 것과 픽셀을 깊게 복사하는 것은 다릅니다.
