gap_stats_units

method · 선언 타입 zvision._inspection_models.BeadResult

Python
gap_stats_units(self, mode, maximum, *, max_work, world=None, world_maps=None)

포함 경로의 전체 길이와 누락 길이, 비율을 구합니다.

확인된 인자 조건

maximum: 허용 누락 비율 0–1

max_work: 양의 작업 예산, 키워드 전용

world: 선택적 6계수 아핀 변환; 기본값 None

world_maps: 선택적 세계 좌표 영상 2개; 기본값 None, world와 동시 사용 불가

mode: 픽셀 또는 세계 좌표 모드; 픽셀은 보정 불허, 세계는 보정 필요

반환: (포함 길이, 누락 길이, 비율, 통과 여부) 값 튜플입니다.

오류: 범위·작업 예산·보정 조합이 유효하지 않으면 오류입니다.

인자 선언

  • mode · POSITIONAL_OR_KEYWORD · 기본값 없음
  • maximum · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_work · KEYWORD_ONLY · 기본값 없음
  • world · KEYWORD_ONLY · 기본값 None
  • world_maps · KEYWORD_ONLY · 기본값 None

Pixel forbids calibration; World requires it. Gap map pairs must use the probe ROI-local grid; source geometry is not stored. Nonlinear distances are endpoint chords.

사용과 결과 판독

누락 길이와 전체 길이를 지정 단위의 좌표 변환 조건에 맞춰 읽고 비율을 판정합니다. 길이는 단위의 영향을 받지만 같은 단위의 길이끼리 나눈 비율은 무차원입니다. 변환 설정과 허용 비율을 결과와 함께 보관하십시오.
