Python API · ZImage · resize_nearest

ZImage.resize_nearest 공개 계약

상위 목차로 돌아가기

resize_nearest

method · 선언 타입 zvision.ZImage

Python
resize_nearest(self, width: int, height: int)

최근접 보간으로 크기를 변경합니다.

확인된 인자 조건

width: 양의 출력 폭

height: 양의 출력 높이

반환: 새 영상. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 폭·높이가 0이거나 형식이 지원되지 않으면 오류입니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

가장 가까운 표본 선택

최근접 리사이즈는 출력 위치에 대응하는 가까운 입력 표본을 선택합니다. 입력에 없는 중간 밝기를 보간해 만드는 방식과 다르므로 이진 레이블이나 범주값을 다룰 때 값의 종류를 살펴보기 쉽습니다. 위치 매핑과 출력 크기 조건은 해당 호출 계약을 따릅니다.

결과 해석

확대 시 같은 입력 표본이 여러 출력 위치에 반복될 수 있어 경계가 계단처럼 보일 수 있습니다. 축소 시 작은 구조가 빠질 수도 있으므로 중요한 물체의 크기와 위치를 원본과 비교합니다. 보정 좌표와 픽셀 간격도 크기 변경에 맞춰 관리합니다.
