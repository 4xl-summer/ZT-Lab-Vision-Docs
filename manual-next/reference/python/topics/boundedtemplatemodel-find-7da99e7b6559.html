find(self, image, options)

정수 평행이동 위치를 한정된 범위에서 검색합니다.

확인된 인자 조건

image: 모델 방식에 맞는 RGB8 또는 Gray8 검색 영상입니다.

options: 포함 범위, 판정값과 결과·작업 상한입니다.

반환: 네이티브 결과를 복사한 독립 BoundedTemplateResult입니다.

오류: 형식이나 범위, 작업 상한이 맞지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Search integer translations; returns immutable copies independent of the native result.

호출 맥락과 결과 해석

학습된 템플릿을 지정 범위의 정수 평행이동 위치에서 검색합니다. 입력 영상은 학습 방식에 맞게 COLOR_NCC에는 RGB8, GRAY_SAD에는 Gray8을 사용합니다. 회전이나 배율을 탐색하는 확장 포즈 검색과 입력 해석이 다릅니다.

BoundedTemplateOptions의 포함 범위, 판정값, 결과 및 작업 상한이 함께 결과를 정합니다. 검색 결과가 비면 지정 범위와 판정값, 작업 한도부터 확인합니다. 반환 BoundedTemplateResult는 네이티브 결과에서 복사한 독립 값입니다.

입력 선택을 위한 확인

입력의미와 조건
image모델 방식에 맞는 RGB8 또는 Gray8 검색 영상입니다.
options포함 범위, 판정값과 결과·작업 상한입니다.

반환값 확인
