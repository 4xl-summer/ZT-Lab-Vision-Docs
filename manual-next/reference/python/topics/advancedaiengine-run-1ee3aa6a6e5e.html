run(self, inputs)

선언된 입력 순서로 텐서를 전달해 모델을 실행합니다.

확인된 인자 조건

inputs: Tensor 객체들의 순서 있는 iterable입니다.

반환: 독립 소유 Tensor 객체의 리스트입니다. 각 텐서를 별도로 close해야 합니다.

오류: Tensor가 아닌 입력에는 TypeError가 발생하며 모델과 텐서의 불일치 및 네이티브 실행 오류가 전달됩니다.

인자 선언

  • inputs · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

사용과 결과 판독

텐서 입력은 모델이 선언한 순서대로 전달해야 합니다. 텐서 수와 크기가 맞더라도 서로 다른 입력의 순서를 바꾸면 의미가 달라집니다. 반환된 각 텐서는 독립 소유이므로 사용 후 각각 닫습니다.
