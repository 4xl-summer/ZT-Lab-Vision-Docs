Python API · BlobContext · set_connectivity

BlobContext.set_connectivity 공개 계약

상위 목차로 돌아가기

set_connectivity

method · 선언 타입 zvision._blob_context.BlobContext

Python
set_connectivity(self, connectivity)

연결성 변경을 다음 계산에 적용합니다.

확인된 인자 조건

connectivity: 4 또는 8

반환: None입니다.

오류: 4와 8 이외는 ValueError입니다.

인자 선언

  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Set 4 or 8 connectivity; changed geometry is applied next calculation.

전경 이웃 설정

블롭 계산에 사용할 연결성을 설정합니다. 4연결은 변을 공유하는 이웃을, 8연결은 대각 이웃도 포함하는 방식으로 이해할 수 있습니다. 대각선 두 점의 성분 수가 설정에 따라 달라집니다.

재계산

기하 설정을 바꾼 뒤 기존 결과를 새 조건의 결과라고 가정하지 말고 컨텍스트 상태의 dirty와 현재 결과 여부를 확인합니다. 새 설정으로 calculate한 뒤 성분 수와 면적을 같은 입력 마스크에서 비교합니다.
