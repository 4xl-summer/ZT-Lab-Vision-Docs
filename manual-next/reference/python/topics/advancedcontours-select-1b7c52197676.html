method · 선언 타입 zvision._inspection_advanced.AdvancedContours

Python
select(self, defect, limits)

선택 결함이 진단 범위를 충족하는지 검사합니다.

확인된 인자 조건

defect: 결함 인덱스

limits: AdvancedDiagnosticRange

반환: bool입니다.

오류: 인덱스 또는 범위가 유효하지 않으면 오류입니다.

인자 선언

  • defect · POSITIONAL_OR_KEYWORD · 기본값 없음
  • limits · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

진단 범위 판정

defect 인덱스의 진단값이 AdvancedDiagnosticRange limits를 충족하는지 bool로 반환합니다. 판정 대상 결함의 인덱스와 각 범위의 단위를 확인해야 합니다. 유효하지 않은 인덱스나 범위는 오류입니다.

결과 확인

반환 True 또는 False와 실제 info의 수치를 나란히 보면 어느 설정에서 판정되었는지 조사하기 쉽습니다. 경계 포함 여부는 limits의 계약을 따르고, 분할 마스크와 조명 조건은 별도 검사합니다.

판정과 진단

범위 조건의 True 또는 False만으로 원인을 알기 어려울 때 info의 기하·대비 수치와 limits를 나란히 확인합니다. 결함 인덱스와 입력 ROI가 같은 결과를 가리키는지도 살펴봐야 합니다.
