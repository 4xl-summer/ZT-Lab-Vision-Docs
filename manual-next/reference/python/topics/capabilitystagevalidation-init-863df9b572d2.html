python 공개 선언
CapabilityStageValidation(validation: zvision._rigid_frames.StageValidation, computed: int, active_axes: int, rotation_span: float) -> None

Stage response with explicit active axes and computed metric mask.

validation: 축 능력을 반영한 스테이지 진단 결과입니다.

computed: 계산된 진단 지표의 비트 마스크입니다.

active_axes: 입력에서 활성화된 X, Y, theta 축의 비트 마스크입니다.

rotation_span: 명령된 펼친 회전각의 범위이며 라디안입니다.

이 호출의 입력과 객체 맥락

CapabilityStageValidation은 선택한 활성 축에 대한 스테이지 응답 결과와 어떤 지표가 계산되었는지를 묶습니다. validation은 StageValidation이고 active_axes와 computed는 비트마스크이며 rotation_span은 명령 회전의 범위입니다. 비활성 축이 일정해야 한다는 입력 조건을 만족해야 선택한 축의 응답을 의미 있게 해석할 수 있습니다.

예를 들어 X축만 움직이는 장치라면 해당 축을 활성화하고 비활성 Y와 회전은 일정하게 유지한 관측을 준비합니다. 계산된 비트에 없는 지표를 0이라는 유효 측정값으로 읽지 마세요. 명령과 관측을 시점별로 짝지어 응답과 잔차를 확인하고 길이 단위와 회전 라디안을 구분합니다.

활성 축과 검증 지표

CapabilityStageValidation은 validation, computed, active_axes, rotation_span을 담는 불변 결과입니다. validation은 StageValidation이며 잘못된 타입을 전달하면 TypeError입니다. computed는 계산된 지표의 마스크, active_axes는 선택한 활성 축의 마스크입니다.

명령 포즈와 관측 포즈를 비교할 때 X·Y의 길이 단위와 회전의 라디안을 구분합니다. 예를 들어 각도 잔차 0.01과 위치 잔차 0.01은 서로 다른 물리량입니다. rotation_span은 관측된 회전 범위를 나타내므로 단일 포즈 값과 혼동하지 않습니다.
