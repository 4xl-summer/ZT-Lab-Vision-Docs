DecisionInfo(passed: bool, reasons: int, defect_count: int, total_area: int, rejection_count: int)

passed: 모든 판정 조건을 통과했는지 나타냅니다.

reasons: 개수, 총 면적, 개별 면적, 위치 위반을 조합한 비트입니다.

defect_count: 판정한 결함 수입니다.

total_area: 결함 픽셀 면적의 합입니다.

rejection_count: 개별 면적 또는 위치 위반 기록의 수입니다.

이 호출의 입력과 객체 맥락

표면 후보에 대한 전체 판정의 값 스냅샷입니다. passed는 모든 조건의 통과 여부이고 reasons는 위반한 조건의 비트 조합입니다. defect_count는 평가된 후보 수, total_area는 후보 전경 면적의 합이며 rejection_count는 개별 면적 또는 위치 위반 기록의 수입니다. 이 값들은 차분이 검사한 픽셀 수나 정렬의 유효 픽셀 수와 서로 다른 단계의 통계입니다.

예를 들어 후보 하나가 있고 최대 개수가 0이면 COUNT가 설정됩니다. 개별 후보의 면적과 위치가 허용 범위라면 개별 Rejections는 비어 있을 수도 있으므로 rejection_count만으로 전체 합격 여부를 판단하지 않습니다. 총 면적도 개별 면적 상한과 별도로 비교합니다. 각 상한은 등호를 포함하므로 같은 값인지 초과인지 정확히 확인합니다.
