ComponentObject(parts: tuple, score: float, max_position_error: float) -> None

Root-first parts, minimum component score, maximum positional error in pixels.

parts: 루트가 첫 항목인 컴포넌트 매치들의 불변 튜플입니다.

score: 컴포넌트 점수 중 최솟값입니다.

max_position_error: 컴포넌트 위치 오차의 최댓값(픽셀)입니다.

이 호출의 입력과 객체 맥락

루트 상대 형상 컴포넌트 검색에서 조합된 객체 하나입니다. parts는 루트가 첫 항목인 매치 튜플이며 각 항목의 id로 입력 모델을 식별합니다. score는 구성요소 점수 중 최솟값이고 max_position_error는 예상 상대 위치에 대한 최대 오차로 픽셀 단위입니다.

한 부품의 점수만 높아도 객체의 score가 높다고 가정할 수 없습니다. 예를 들어 부품 점수가 0.9와 0.7이면 최소값은 0.7입니다. 관계 허용 오차와 실제 최대 위치 오차를 비교하고 각 포즈의 로컬 좌표계를 확인하세요. 반환된 객체 수는 상위 결과의 최대 개수 및 공유 예산에도 영향을 받습니다.

입력과 결과를 읽는 순서

ComponentObject는 루트가 첫 항목인 매치 parts 튜플, 컴포넌트 점수의 최솟값 score, 최대 위치 오차 max_position_error를 담습니다. 개별 매치의 id와 자세는 parts에서 읽고 객체 요약 점수와 구분합니다.

예를 들어 세 컴포넌트의 점수가 0.9, 0.8, 0.7이면 이 객체의 score는 최솟값 0.7입니다. max_position_error는 각 구성요소의 위치 오차 중 가장 큰 값이며 픽셀 단위입니다. 평균 점수나 전체 픽셀 오차의 합으로 해석하면 다른 의미가 됩니다.

상대 위치와 각도 조건은 루트 모델과 나머지 구성요소 사이 관계입니다. 검색 영상에서의 로컬·글로벌 자세와 루트 상대 관계를 비교할 때 원점과 기준을 맞추세요. parts는 불변 튜플 스냅샷이므로 어떤 모델 id가 어떤 위치로 매치됐는지 함께 보관할 수 있습니다.
