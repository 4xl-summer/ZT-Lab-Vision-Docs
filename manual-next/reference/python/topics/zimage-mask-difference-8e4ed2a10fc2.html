현재 마스크에서 기준 마스크를 제외한 차집합을 만듭니다.

확인된 인자 조건

reference: 기준 ZImage 마스크

반환: 새 마스크. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 호환되지 않는 마스크는 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

마스크의 차집합

첫 마스크에서 두 번째 마스크에 해당하는 위치를 제외하는 차집합을 계산합니다. 예를 들어 첫 전경 위치가 {A,B}, 두 번째가 {B}이면 결과는 {A}입니다. 입력 순서를 바꾸면 일반적으로 다른 결과가 됩니다.

좌표와 형식

두 마스크가 같은 크기와 좌표계를 나타내는지 확인합니다. ROI 원점이 다르면 동일 인덱스가 다른 실제 위치일 수 있습니다. 전경 값의 규칙과 지원 형식을 확인하고 결과를 두 입력 위에 겹쳐 제거된 위치를 살펴봅니다.
