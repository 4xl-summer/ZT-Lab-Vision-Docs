PixelArithmeticOptions(operation: zvision._arithmetic_gap.PixelArithmetic, gain: float, bias: float, output: zvision.PixelFormat) -> None

Operation, gain, bias and output format for componentwise arithmetic.

operation: 성분별 더하기, 곱하기, 나누기, 최솟값, 최댓값 또는 빼기를 선택합니다.

gain: 성분별 연산 결과에 곱하는 유한 계수입니다.

bias: 계수를 적용한 뒤 더하는 유한 값입니다.

output: 결과 이미지에 요청할 픽셀 형식입니다.

이 호출의 입력과 객체 맥락

두 영상의 성분별 산술을 호출할 때 연산 종류와 출력 변환을 한 값으로 묶습니다. operation은 덧셈, 곱셈, 나눗셈, 최솟값, 최댓값, 뺄셈 중 연산을 정하고 gain과 bias는 연산 뒤에 적용됩니다. output은 결과 픽셀 형식이므로 입력 영상의 형식과 항상 같다고 가정하지 마십시오.

예를 들어 두 성분을 더한 결과가 20이고 gain이 2, bias가 3이라면 출력 형식으로 변환하기 전 값은 43입니다. 그 뒤 정수 출력에서 범위 밖인 값은 해당 형식의 변환 규칙에 따라 제한될 수 있습니다. 따라서 강한 배율을 사용할 때는 포화 때문에 차이가 사라질 가능성을 살펴야 합니다.

입력과 결과 확인

PixelArithmeticOptions는 두 영상의 각 성분에 적용할 산술 연산과 후처리 계수, 출력 형식을 묶습니다. operation은 더하기, 곱하기, 나누기, 최솟값, 최댓값 또는 빼기 중 하나입니다. gain과 bias는 유한한 값이어야 합니다.

각 성분에서 선택한 연산을 먼저 계산하고 그 결과에 gain을 곱한 뒤 bias를 더합니다. 예를 들어 덧셈 결과가 20이고 gain=2, bias=3이면 출력 형식으로 변환하기 전 값은 20×2+3=43입니다. bias를 먼저 더해 곱하는 식과는 다릅니다.

output은 결과 영상에 요청하는 픽셀 형식이므로 입력과 항상 같다고 가정하지 마십시오. 정수 출력에서 범위 밖의 수치는 형식의 변환 규칙을 확인해야 하며 포화가 생기면 서로 다른 큰 값이 같은 최대값이 될 수 있습니다. 실제 연산 호출에서는 두 영상의 크기와 성분 호환 조건도 별도로 확인합니다.

항목확인할 내용
operation성분별 산술 종류를 선택합니다.
gain산술 결과에 곱하는 유한 계수입니다.
bias곱한 결과에 더하는 유한 값입니다.
output결과에 요청하는 픽셀 형식입니다.
예시20×2+3은 변환 전 43입니다.
호출옵션 생성과 실제 영상 산술은 별도입니다.

예를 들어 같은 두 입력에서 연산 결과가 10과 20으로 다른 두 픽셀이 있다고 해도, 이후 gain과 정수 출력 범위에 따라 두 값이 같은 포화값이 될 수 있습니다. 따라서 출력의 최대값이 관측됐다는 사실만으로 변환 전 두 성분이 같았다고 판단하지 않습니다. 연산 종류와 gain, bias, 출력 픽셀 형식을 결과와 함께 기록하고, 나눗셈이나 자료형 변환에서 발생한 오류는 정상적인 값으로 덮어쓰지 마십시오.
