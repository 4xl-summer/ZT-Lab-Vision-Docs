반환: None을 반환합니다.

오류: 닫힌 객체나 자원 처리 실패 시 오류가 발생할 수 있습니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

예를 들어 취득 도중 연결 상태를 끊으면 큐에 남아 있던 항목과 대기 트리거가 각각 폐기·취소 통계에 반영됩니다. 다음 흐름을 시작하려면 다시 connect와 start를 순서대로 호출합니다. 반환된 AcquiredFrame은 카메라 객체와 수명을 따로 관리합니다.

상태를 Disconnected로 바꾸며 반복 호출할 수 있습니다. 스트림을 나갈 때 대기 프레임은 discarded, 대기 트리거는 cancelled_triggers에 반영됩니다. 이미 꺼낸 프레임은 살아남습니다. 이 명령은 모의 연결 상태를 바꾸며 카메라 객체를 해제하지 않으므로 사용을 마친 소유 객체는 별도로 close합니다.

사용 조건과 결과 판독

disconnect는 모의 카메라를 모든 상태에서 Disconnected로 전환하며 반복할 수 있습니다. 취득을 떠날 때 대기 프레임은 discarded에, 대기 트리거는 cancelled_triggers에 반영됩니다. 이미 꺼낸 프레임은 대기 큐에서 버려지는 항목과 다릅니다.

예를 들어 Acquiring 상태에서 아직 꺼내지 않은 프레임이 둘 있고 소비자가 이전 프레임 하나를 소유하고 있다면, 대기한 둘은 전환 시 폐기되고 이미 얻은 프레임은 독립 수명으로 남습니다. info에서 상태와 누적 통계를 읽어 어떤 전환이 일어났는지 확인하세요.

다음 취득을 시작하려면 connect와 start를 순서대로 다시 호출합니다. disconnect는 모의 상태를 바꾸는 동작이고 카메라 객체의 소유 핸들을 해제하는 close와 구분됩니다. 카메라와 이미 취득한 프레임·이미지는 각자 사용이 끝났을 때 해당 수명을 정리해야 합니다.
