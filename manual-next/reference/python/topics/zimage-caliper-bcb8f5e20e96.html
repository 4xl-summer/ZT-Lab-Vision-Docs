caliper(self, spec) -> 'CaliperResult'

조건에 맞는 거리순 에지를 계산합니다.

확인된 인자 조건

spec: CaliperSpec; ROI 로컬 픽셀 기준.

반환: 영상 수명과 독립된 불변 CaliperResult.

오류: 잘못된 타입·영상 형식·표본 기하 또는 닫힌 영상은 오류.

인자 선언

  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

반환 타입 주석: CaliperResult

Return an independent caliper edge snapshot.

계산과 결과 해석

캘리퍼 실행이 선택한 에지들을 독립적으로 보관하는 결과입니다. edges는 개별 CaliperEdge의 순서 있는 모음이며 에지마다 ROI 로컬 위치, 선분 시작점에서의 거리와 부호 있는 강도를 확인할 수 있습니다. 반환된 에지가 없다는 것은 선택 조건을 만족한 피크가 없는 정상 결과일 수 있으며 입력 검증 실패와는 구별해야 합니다. 예를 들어 한 프로파일에서 에지가 거리 2와 7에 있다면 진행 방향을 따른 간격은 5픽셀입니다. 선분을 거꾸로 지정하면 첫째와 둘째 경계의 의미가 바뀌므로 화면의 왼쪽과 오른쪽을 고정 순서로 가정하지 마십시오. 서브픽셀 위치는 표본 사이 피크 보간 결과이며 그 소수 자릿수가 실제 장비 정확도를 보증하지 않습니다. 결과는 실행 수명과 독립적으로 보관할 수 있지만 각 값이 어떤 영상과 설정에서 나왔는지 알려면 원본 프레임, ROI 원점, 극성과 임계값을 함께 기록해야 합니다. 서로 다른 ROI의 위치를 비교하기 전에는 해당 원점을 복원하고 같은 좌표계로 맞춥니다. 에지 강도와 원시 픽셀 강도는 다른 양이므로 수치를 그대로 비교하지 않습니다. 두 에지의 프로파일 거리는 같은 시작점과 진행 방향을 공유할 때 차이로 비교할 수 있습니다. 서로 다른 프로파일에서 나온 거리 숫자만 뺀 값은 두 영상 위치의 실제 거리가 아닐 수 있습니다.
