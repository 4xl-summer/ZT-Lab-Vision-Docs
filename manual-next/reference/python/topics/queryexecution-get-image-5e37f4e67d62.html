get_image(self, name: 'str') -> 'ZImage'

이름 붙은 캡처의 별도 소유 이미지 공유 핸들을 취득합니다.

확인된 인자 조건

name: 캡처 이름

반환: 호출자가 close할 ZImage입니다.

오류: 닫힌 실행 또는 알 수 없는 이름은 오류입니다.

인자 선언

  • name · POSITIONAL_OR_KEYWORD · 타입 str · 기본값 없음

반환 타입 주석: ZImage

이름 붙은 캡처의 독립 이미지 공유를 반환한다.

캡처의 공유 핸들

name으로 실행 결과의 중간 영상을 선택해 별도 소유 ZImage를 얻습니다. 이 메서드가 읽는 대상은 최종 결과 타입과 별개로 이름 붙인 이미지 캡처입니다. 이름이 없거나 실행이 닫혔으면 오류입니다.

사용과 해제

계획에 캡처를 지정하고 실행한 뒤 같은 이름으로 조회합니다. 얻은 영상은 호출자가 close하고 실행 객체도 각자 해제합니다. 중간 결과와 최종 결과를 비교하면 어느 단계에서 마스크나 밝기가 바뀌었는지 찾을 수 있습니다.
