create(cls, template, mask=None, *, max_samples, max_pixels)

템플릿과 선택 마스크로 온라인 기준 모델을 만듭니다.

확인된 인자 조건

template: ZImage 템플릿

mask: 선택 마스크; 기본값 None

max_samples: 양의 샘플 수 상한, 키워드 전용

max_pixels: 양의 픽셀 수 상한, 키워드 전용

반환: 별도로 close할 OnlineReference입니다.

오류: 영상 또는 상한이 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None
  • max_samples · KEYWORD_ONLY · 기본값 없음
  • max_pixels · KEYWORD_ONLY · 기본값 없음

max_samples: 정수 검사 · 최소 1.

max_pixels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

template 영상과 선택적 mask 영상을 기준으로 온라인 참조 객체를 만듭니다. 둘 다 지정하는 경우 ZImage여야 하며 max_samples와 max_pixels는 양의 정수로 지정해야 합니다. 이후 이미지 배치를 update하고 count로 누적 상태를 확인할 수 있습니다. 반환 객체는 소유 핸들이므로 사용 후 close하거나 context manager로 관리합니다. 마스크를 생략할 때의 해석과 영상 호환 조건은 해당 연산의 검증 결과를 따릅니다.
