ExtendedShapeCollectionEntry(id: int, model: zvision._extended_matching.ExtendedShapeModel) -> None

An ID and typed shape owner for a multi-model search.

id: 모델 항목을 구별할 고유 u64 식별자입니다.

model: 검색할 형상 모델입니다.

값을 구성하고 해석하기

타입 지정 ExtendedShapeModel과 고유 id를 하나로 묶어 형상 모델 컬렉션 검색에 전달합니다. 검색 함수가 내부적으로 형상 컬렉션 입력으로 변환하므로 id는 같은 호출의 다른 항목과 중복되지 않아야 합니다. model은 검색 도중 유효한 소유 모델이어야 합니다.

생성할 때 확인할 값

인자값의 의미
id모델 항목을 구별할 고유 u64 식별자입니다.
model검색할 형상 모델입니다.

타입 지정 모델을 구분하기

id는 같은 컬렉션 호출 안에서 각 모델을 구별하는 u64 값입니다. 예를 들어 두 모델에 100과 200을 부여하면 반환 결과의 식별자를 입력 목록과 대조해 어떤 모델이 검출되었는지 확인할 수 있습니다. 모델의 점수나 결과 순번으로 id를 해석하지 않습니다.

model은 학습 또는 복원한 ExtendedShapeModel입니다. 항목을 만들었다고 검색이 실행되거나 포즈가 생성되지는 않습니다. 검색이 진행되는 동안 모델을 유효하게 유지하고 검색이 끝나면 그 소유 모델의 수명을 정리합니다.
