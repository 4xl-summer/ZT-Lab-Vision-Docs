이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

입력과 기준 영상 정렬

align_reference는 입력과 reference 영상의 정렬을 AlignmentSpec에 따라 계산합니다. 두 영상의 같은 숫자 좌표가 같은 장면을 가리키도록 관계를 구하는 단계이며, 밝기 차이 측정이나 블롭 분석 자체와 구분합니다.

결과 사용

reference에 기준 ZImage, spec에 AlignmentSpec을 전달합니다. 반환 AlignmentResult는 닫아야 하는 객체이므로 필요한 결과를 읽은 뒤 close 또는 해당 수명 규칙을 따릅니다. 정렬이 계산되었다고 실제 장비의 정확도가 보증되는 것은 아니므로 기준점과 결과를 확인합니다.
