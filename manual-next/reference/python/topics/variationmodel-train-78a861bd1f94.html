train(cls, images, mask=None, mode=<VariationMode.STANDARD: 0>, *, max_samples, max_values)

영상 시퀀스로 변동 모델을 학습합니다.

확인된 인자 조건

images: 비어 있지 않은 ZImage 시퀀스

mask: 선택 마스크; 기본값 None

mode: VariationMode; 기본값 STANDARD

max_samples: 양의 샘플 수 상한, 키워드 전용

max_values: 양의 값 수 상한, 키워드 전용

반환: 별도로 close할 VariationModel입니다.

오류: 이미지·모드·상한이 유효하지 않으면 오류입니다.

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None
  • mode · POSITIONAL_OR_KEYWORD · 기본값 <VariationMode.STANDARD: 0>
  • max_samples · KEYWORD_ONLY · 기본값 없음
  • max_values · KEYWORD_ONLY · 기본값 없음

max_samples: 정수 검사 · 최소 1.

max_values: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

정상 표본에서 모델 학습

images에 정상 표본 영상을 전달하고 선택적으로 mask와 VariationMode를 지정합니다. max_samples와 max_values는 각각 양의 정수인 작업 한도이며 표본은 비어 있을 수 없습니다. 입력과 마스크는 ZImage여야 합니다.

훈련 표본이 실제 정상 편차를 얼마나 대표하는지에 따라 이후 검사 해석이 달라집니다. 위치가 다른 영상을 같은 픽셀끼리 비교하지 않도록 입력 기하를 먼저 맞추고, 학습에 사용하지 않은 정상·결함 영상으로 별도 확인합니다. 반환 모델은 소유 객체로 close합니다.
