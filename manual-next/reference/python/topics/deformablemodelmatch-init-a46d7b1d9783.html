DeformableModelMatch(matched: zvision._matching_advanced.AdvancedMatch, variant_index: int)

matched: 해당 변형 모델이 산출한 기본 포즈와 점수입니다.

variant_index: 학습 시 제공한 변형 목록에서의 인덱스입니다.

값을 구성하고 해석하기

명시한 변형 모델 은행을 검색해 얻은 한 후보입니다. matched에는 기본 확장 매칭 자세와 점수가 들어 있고 variant_index는 학습 때 전달한 변형 목록의 순서를 가리킵니다. 인덱스는 사용된 학습 변형을 식별하며 임의의 연속 변형량을 직접 추정한 값이 아닙니다.

변형 인덱스와 포즈를 함께 읽기

학습할 때 변형들을 어떤 순서로 전달했는지가 variant_index의 해석 기준입니다. 예를 들어 세 변형을 [A, B, C] 순서로 준비했다면 인덱스 1은 B를 식별합니다. 이 정수는 변위 크기나 점수가 아니므로 숫자 자체를 전단량이나 픽셀 거리로 표시하지 않습니다.

matched에는 선택된 변형에 대한 위치, 각도, 배율과 점수가 별도로 있습니다. 서로 다른 후보의 점수를 비교할 때는 대응하는 변형 인덱스도 유지하고, 로컬 위치를 원본 영상 위에 그릴 때는 검색 ROI 원점을 반영합니다.
