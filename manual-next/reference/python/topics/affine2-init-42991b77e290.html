Affine2(a: float, b: float, tx: float, c: float, d: float, ty: float)

a: x 출력에 곱하는 입력 x 계수.

b: x 출력에 곱하는 입력 y 계수.

tx: x 출력의 이동량.

c: y 출력에 곱하는 입력 x 계수.

d: y 출력에 곱하는 입력 y 계수.

ty: y 출력의 이동량.

이 호출의 입력과 객체 맥락

예를 들어 (a,b,tx,c,d,ty)=(1,0,3,0,1,4)는 x에 3, y에 4를 더하는 값입니다. 결과 좌표의 기준은 입력과 이 계수를 구성한 기준에 따라 정해집니다.

이 값은 행 우선 2×3 계수를 a, b, tx, c, d, ty 순서로 담습니다. 첫 행은 출력 x를, 둘째 행은 출력 y를 결정합니다. 선형 계수 a와 d를 1, b와 c를 0으로 두고 tx=3, ty=4로 두면 점 (10, 20)을 (13, 24)로 보내는 이동 표현이 됩니다. 생성된 값은 영상 저장소가 아니라 작은 계수 스냅샷입니다. 이 값에 점을 적용하거나 역변환을 계산할 때 실제 수치의 유한성과 가역 조건이 검사될 수 있으므로 객체 생성 자체를 모든 후속 연산의 성공 보증으로 해석하지 않습니다.
