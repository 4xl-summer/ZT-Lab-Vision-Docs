유효 표본 마스크을 얻습니다.

반환: 호출자가 닫아야 하는 별도 소유 ZImage입니다.

오류: 정합 결과가 없거나 객체가 닫혔다면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

변형 정합 결과에 대응하는 유효 마스크 영상을 반환합니다. 정렬 영상과 함께 읽어 유효한 대응 영역을 구분하고, 정합 성공 여부와 품질은 결과 info에서 별도로 확인합니다. 반환 ZImage와 DeformableRegistration은 각각 소유 핸들이므로 사용을 마친 객체를 각각 close합니다.

정렬 영상과 유효 표본

valid_mask()는 변형 정합 결과의 유효 표본 마스크를 별도 소유 ZImage로 취득합니다. 정합 결과가 없거나 DeformableRegistration이 닫혔다면 호출은 오류입니다. 마스크는 어떤 위치의 표본이 유효한지를 나타내며 정합의 전체 성공이나 품질 점수 자체는 아닙니다.

예를 들어 변형으로 입력 영상의 일부가 원본 범위를 벗어나면 정렬 영상의 모든 위치가 유효한 대응 표본이라고 가정할 수 없습니다. 정렬 영상과 valid_mask를 같은 좌표 기준으로 읽고 마스크가 제외한 영역을 일반적인 검은 결함으로 오인하지 마세요. 결과 info의 found, coverage, residual_rms를 함께 확인하면 검색 상태와 유효 범위를 구분할 수 있습니다.

적용과 결과 확인

반환 마스크와 정합 결과는 각각 소유 핸들이므로 각각 close합니다. 마스크를 얻기 전에 결과를 닫으면 새 영상을 취득할 수 없으며, 이미 얻은 마스크는 자신의 수명으로 관리합니다. ROI와 변형 설정, 마스크 및 검증에 쓴 영상의 크기를 함께 기록하면 이후 차영상의 유효 영역을 재현하기 쉽습니다.

정합 결과에서 유효 비율이 낮다면 마스크가 표시하는 위치가 입력 영상의 경계, 가림 또는 변형된 표본 범위와 어떻게 겹치는지 확인하세요. 마스크는 각 픽셀의 사용 가능성을 나타내고 coverage는 이를 요약한 지표이므로 요약 하나로 위치를 복원할 수는 없습니다. 예를 들어 유효 비율이 같아도 제외된 부분이 검사 대상 중앙인지 가장자리인지에 따라 후속 판정이 달라질 수 있습니다. 차분을 계산할 때에도 같은 유효 영역을 적용해야 합니다.
