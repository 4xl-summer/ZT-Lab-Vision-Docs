reconnect(self)

기존 연결을 닫고 같은 주소로 다시 연결합니다.

반환: None을 반환합니다.

오류: 연결 실패 시 ModbusTcpError가 발생합니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

통신 또는 프로토콜 오류 뒤 무효화된 실제 Modbus TCP 연결을 명시적으로 다시 연결합니다. 자동 재접속이나 이전 쓰기의 자동 재전송은 하지 않습니다. 쓰기 중 시간 초과나 연결 오류가 났다면 PLC가 이미 값을 적용했을 수도 있으므로 재연결 후 애플리케이션이 장치 상태를 확인해야 합니다. 실패하면 ModbusTcpError에서 operation, status, diagnostic을 확인합니다. 소유 클라이언트는 사용 후 close합니다.

사용 흐름과 결과 판독

reconnect는 기존 Modbus TCP 연결을 닫고 저장된 같은 주소로 새 연결을 시도합니다. 새 주소를 받는 호출이 아니며 호출이 성공하면 None을 반환합니다. 통신 또는 프로토콜 오류로 연결이 무효화된 경우 애플리케이션이 명시적으로 호출할 수 있습니다. 연결에 실패하면 ModbusTcpError가 발생하므로 연결된 상태라고 가정하고 다음 요청을 이어서 보내지 않습니다.

연결 복구와 이전 요청의 성공 여부는 서로 다른 문제입니다. 예를 들어 레지스터 쓰기 중 응답을 기다리다 연결이 끊겼다면 장치가 값을 적용한 뒤 응답만 전달되지 않았을 수도 있습니다. 이 클라이언트는 쓰기를 자동 재시도하지 않으므로 재연결 뒤 장치의 현재 상태를 읽어 애플리케이션의 목적 상태와 비교합니다.

오류 객체의 operation은 실패한 연산, status는 네이티브 상태, diagnostic은 추가 진단입니다. I/O 오류, 프로토콜 오류와 연결 끊김을 구분해 기록하면 복구 실패의 원인을 추적할 수 있습니다. 소유 클라이언트는 사용 후 close하며 닫힌 객체를 새 연결 객체처럼 재사용하지 않습니다.
