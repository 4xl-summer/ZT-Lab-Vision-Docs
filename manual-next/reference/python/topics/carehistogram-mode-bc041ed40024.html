CareHistogram.mode 공개 계약

상위 목차로 돌아가기

mode

method · 선언 타입 zvision._masked_gap.CareHistogram

Python
mode(self, channel=0)

최빈값 빈 인덱스를 계산합니다.

확인된 인자 조건

channel: 0 기반 채널 인덱스; 기본값 0

반환: 정수 빈 인덱스입니다.

오류: 채널이 유효하지 않으면 오류입니다.

인자 선언

  • channel · POSITIONAL_OR_KEYWORD · 기본값 0

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

별칭과 결과 해석

MaskedHistogram은 CareHistogram과 같은 클래스이며 mode와 mode_bin은 같은 함수입니다. channel은 0부터 시작하고 기본값은 0입니다. 결과는 해당 채널의 최빈 빈 인덱스 정수입니다. 잘못된 채널 또는 닫힌 히스토그램은 오류이며 정수 결과 자체에는 별도 해제가 필요하지 않습니다.

가장 빈번한 빈

선택 채널에서 최빈값에 해당하는 빈 인덱스를 구합니다. channel은 0 기반이고 기본값은 0입니다. 반환 숫자를 원본의 밝기 값으로 바로 해석하지 말고 히스토그램의 빈 범위에 연결합니다.

분포 확인

예를 들어 빈별 개수가 2, 7, 3이면 가장 빈번한 위치는 두 번째 빈입니다. 동률 상황은 해당 연산의 규칙을 확인합니다. ROI나 care 마스크가 바뀌면 집계 대상도 바뀝니다.
