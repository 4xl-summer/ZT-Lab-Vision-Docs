lut(self, table)

조회표 변환 단계를 현재 계획에 덧붙입니다.

확인된 인자 조건

table: 256바이트 표

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

인자 선언

  • table · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

조회표 변환 계획

입력값에 대응하는 LUT 항목을 출력하는 단계를 추가합니다. 값 7에 대한 표 항목이 255라면 그 값의 픽셀은 해당 출력에 대응합니다. 테이블 길이와 입력 형식은 호출의 허용 조건을 확인해야 합니다.

설정과 실행

매핑을 재현하려면 표 전체와 입력 형식을 저장합니다. 계획을 실행한 뒤 관심 있는 입력값 몇 개와 결과 위치를 대조하고, LUT 이후의 임계값이나 밝기 통계가 변환된 값을 다룬다는 점을 고려합니다.
