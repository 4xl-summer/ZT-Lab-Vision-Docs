PlanarPoseEstimate(pose: zvision._spatial3d.RigidTransform3, rms_pixels: float) -> None

Initial target-to-camera pose and pixel reprojection RMS.

pose: 타깃 좌표계에서 카메라 좌표계로 보내는 초기 강체 자세입니다.

rms_pixels: 초기 자세의 재투영 RMS 오차이며 픽셀 단위입니다.

이 호출의 입력과 객체 맥락

PlanarPoseEstimate는 평면 타깃에서 구한 초기 타깃→카메라 자세와 픽셀 재투영 RMS를 담습니다. pose는 강체 변환이며 rms_pixels는 관측 영상 위치와 모델 투영의 차이를 픽셀로 요약한 값입니다. 자세의 이동량은 타깃 좌표에 사용한 길이 단위를 따르므로 RMS 숫자와 이동량을 직접 비교하지 않습니다.

예를 들어 타깃 원점이 카메라 프레임에서 (0,0,100) mm인 자세라면 변환의 이동은 그 원점의 위치를 나타냅니다. 타깃의 나머지 점에는 회전을 적용하고 이동을 더한 뒤 렌즈 모델로 투영해야 픽셀과 비교할 수 있습니다. 반환 자세가 초기 추정이라는 점을 고려하고 보류한 점에서도 관측과의 차이를 확인하세요.

평면 자세와 재투영 오차

pose는 대상 좌표에서 카메라 좌표로 가는 초기 RigidTransform3이고 rms_pixels는 픽셀 재투영 RMS입니다. 생성자는 pose가 RigidTransform3인지 검사하며 다른 타입이면 TypeError입니다. 두 필드는 서로 다른 단위를 가집니다.

평면 자세 추정은 대응하는 대상 점과 영상 픽셀, 렌즈 및 ray 옵션 등을 사용합니다. 바인딩은 두 점 목록의 길이가 같고 대응점이 4부터 4096개인지 확인합니다. 결과를 읽을 때 실제 추정에 사용한 프레임 이름과 렌즈 조건을 같이 기록합니다.

재투영 RMS는 관찰 픽셀과 모델 투영 위치의 차이를 픽셀 단위로 요약합니다. 예를 들어 두 점의 오차 크기가 3과 4픽셀이면 제곱 평균의 제곱근은 √((9+16)/2)입니다. 이것을 pose의 이동 거리나 물리 단위 오차로 읽지 않습니다.

초기 pose와 RMS가 존재한다는 사실만으로 모든 점이 잘 맞거나 최종 보정이 완료되었다고 단정할 수 없습니다. 개별 대응점과 독립 확인 자료를 살펴보고 실제 사용 프레임 및 단위를 명시합니다. 객체는 결과 값 스냅샷입니다.
