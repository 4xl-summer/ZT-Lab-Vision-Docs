close_values

method · 선언 타입 zvision.ZImage

Python
close_values(self, kernel_size: int)

값 팽창 후 침식을 적용합니다.

확인된 인자 조건

kernel_size: 양의 홀수 커널 폭

반환: 별도로 close할 ZImage입니다.

오류: 인자나 영상 형식이 지원되지 않으면 오류입니다.

인자 선언

  • kernel_size · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

kernel_size: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

밝기 값의 닫기

값 닫기는 회색값 팽창을 적용한 뒤 값 침식을 적용합니다. 두 단계의 순서는 결과에 중요하며, 침식 후 팽창인 열기와 같지 않습니다. 이진화 여부와 원본 값의 범위를 확인한 상태에서 결과를 해석합니다.

폭과 적용

kernel_size는 양의 홀수 폭으로 각 단계의 이웃을 정의합니다. 작은 어두운 구조가 변하는지 원본과 결과의 같은 위치를 비교하고, 폭을 바꿀 때 후속 임계값이나 밝기 측정에도 영향이 있는지 확인합니다. 반환 ZImage는 사용 후 해제합니다.
