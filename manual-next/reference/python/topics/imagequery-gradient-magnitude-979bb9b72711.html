밝기 변화의 크기

계획된 그라디언트 크기는 방향별 밝기 변화를 결합한 수치입니다. 강한 경계가 강조될 수 있지만 결과의 크기만으로 변화 방향이나 부호를 복원할 수는 없습니다. 배경 잡음 역시 변화로 나타날 수 있습니다.

후속 판단

계획을 실행한 후 원본의 밝기 변화 위치와 결과를 겹쳐 확인합니다. 후속 임계값은 출력 형식과 값 범위를 기준으로 선택하고, 원본에 없던 노이즈가 강조된 위치도 함께 조사합니다.

크기와 방향

변화 크기가 같더라도 수평과 수직 방향은 다를 수 있습니다. 방향이 필요한 검사에서는 X와 Y 성분을 따로 확인하고, 결과에서 강하게 나타난 잡음이 실제 물체 경계인지 원본과 대조합니다.
