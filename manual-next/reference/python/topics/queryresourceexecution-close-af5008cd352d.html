close(self) -> 'None'

실행 결과 소유권을 해제합니다.

반환: None입니다. 반복 호출은 안전합니다.

반환 타입 주석: None

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

실행이 소유한 결과와 캡처를 해제합니다. 이미 acquire_output으로 취득한 결과는 별도 소유이므로 실행을 닫은 뒤에도 그 객체의 close를 따로 호출해야 합니다. get_image로 취득한 영상도 각각 닫습니다. close는 반복 호출할 수 있고 with 블록으로 실행 수명을 제한할 수 있습니다.

실행과 획득 자원의 종료

close는 타입 지정 쿼리 실행이 보유한 결과를 닫습니다. 실행은 종단 쿼리의 execute로 만들며, 이 클래스의 생성자를 직접 호출하지 않습니다. 사용이 끝나면 명시적으로 close하거나 context manager를 사용합니다.

acquire_output은 호출자가 별도로 닫을 독립 소유 결과를 획득합니다. 이미 획득한 결과는 실행 객체와 다른 수명이므로 실행을 닫았다는 이유만으로 획득 결과의 close를 생략하지 않습니다. 캡처에서 얻은 자원 역시 반환 타입의 소유 규칙을 확인합니다.

예를 들어 정렬 실행에서 AlignmentResult를 얻고 실행을 먼저 닫았다면, 결과를 사용한 뒤 결과를 닫습니다. 정렬 성공일 때 별도로 획득한 영상도 각각 닫습니다. 실행을 닫은 후 새 출력 획득을 정상 빈 결과로 처리하지 않습니다.

각 acquire_output 호출은 호출자가 관리할 소유 결과를 반환합니다. 예를 들어 한 실행에서 두 번 획득했다면 두 결과를 각각 정리해야 합니다. 실행을 닫는 일은 이 두 결과 중 어느 하나를 대신 닫는 호출이 아닙니다.

쿼리 계획을 분기한 경우에도 원래 계획과 복제 계획은 별도 자원입니다. 어떤 실행과 결과가 어느 입력 프레임에서 왔는지 함께 보관하면 서로 다른 분기의 출력을 혼동하지 않습니다.

실행과 출력의 해제 순서를 기록하면 예외가 발생한 경우에도 각 핸들의 소유자를 알 수 있습니다. 이미 얻은 결과를 별도로 보관하는 동안 실행만 먼저 닫을 수 있습니다.
