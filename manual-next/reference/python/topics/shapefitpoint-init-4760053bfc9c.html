ShapeFitPoint(residual: float, weight: float, inlier: bool) -> None

Signed residual, actual final robust weight, and threshold-derived inlier flag.

residual: 부호 있는 좌표 단위 잔차입니다. 타원에서는 최근접 거리가 아닌 반경 방향 대리 잔차입니다.

weight: 최종 강건 적합에서 사용한 가중치입니다.

inlier: 잔차와 인라이어 임계값으로 판정한 채택 여부입니다.

값을 구성하고 해석하기

강건 적합에 참여한 한 점의 부호 있는 잔차, 최종 가중치와 내점 판정을 담습니다. residual은 입력 점 좌표와 같은 단위이고 weight는 최종 최적화에서 실제 사용된 값입니다. inlier는 지정된 내점 임계값을 기준으로 한 bool입니다. 세 값은 서로 관련되지만 동일한 의미는 아닙니다.
