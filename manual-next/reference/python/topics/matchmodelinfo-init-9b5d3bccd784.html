MatchModelInfo(kind: zvision._matching.MatchKind, width: int, height: int, sample_count: int, anchor: zvision._regions.Point2) -> None

MatchModelInfo(kind: zvision._matching.MatchKind, width: int, height: int, sample_count: int, anchor: zvision._regions.Point2)

kind: 모델의 NCC 또는 형상 종류입니다.

width: 템플릿의 가로 크기(픽셀)입니다.

height: 템플릿의 세로 크기(픽셀)입니다.

sample_count: NCC에서는 선택 픽셀 수, 형상 모델에서는 특징점 수입니다.

anchor: 템플릿 로컬 중심 ((폭−1)/2, (높이−1)/2)입니다.

값을 구성하고 해석하기

학습된 기본 모델의 종류와 템플릿 폭·높이, 선택 표본 수, 템플릿 로컬 기준점을 나타내는 값입니다. NCC에서는 선택된 마스크 픽셀 수가 표본 수이고 형상에서는 추출된 기울기 특징점 수입니다. 따라서 이 숫자는 찾은 물체의 개수가 아닙니다. 모델을 학습하거나 복원한 뒤 의도한 입력이 사용되었는지 확인하는 데 유용합니다.
