pixel_to_ray

method · 선언 타입 zvision._camera_models.TelecentricCamera

Python
pixel_to_ray(self, pixel)

픽셀에 대응하는 Z=0 원점과 공통 +Z 방향을 계산합니다.

확인된 인자 조건

pixel: 유한한 전역 픽셀 좌표 Point2입니다.

반환: 카메라 좌표의 ModelRay 값입니다.

오류: 유효하지 않은 카메라 또는 좌표는 오류입니다.

인자 선언

  • pixel · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

글로벌 픽셀마다 카메라 z=0 평면 위 원점 ((u−cx)/sx, (v−cy)/sy, 0)과 공통 +Z 단위 방향을 가진 광선을 돌려줍니다. 서로 다른 픽셀의 광선은 방향은 같지만 원점이 다릅니다. 이 광선만으로 세계 점 하나가 정해지지는 않으며, 세계 평면과 교차하려면 프레임과 길이 단위가 일치하는 카메라→세계 포즈가 필요합니다.

이 객체의 확인된 공개 생성 경로: TelecentricCamera(sx: float, sy: float, cx: float, cy: float, unit: zvision._calibration.LengthUnit, camera_frame: int) -> None.
