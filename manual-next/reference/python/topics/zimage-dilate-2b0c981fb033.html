dilate

method · 선언 타입 zvision.ZImage

Python
dilate(self, kernel)

Gray8의 비영 전경에 이진 팽창을 적용합니다.

확인된 인자 조건

kernel: 기본값 없는 양의 홀수 정사각형 폭(픽셀)

반환: 0/255 새 Gray8 마스크. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 0·짝수 폭이나 미지원 형식은 오류입니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

전경 확장

팽창은 구조 요소가 보는 이웃의 전경에 따라 출력 전경을 확장합니다. 가까운 물체 사이의 작은 틈이 메워지거나 별도 성분이 합쳐질 수 있습니다. 이진 전경 선택이 의도한 방향인지 확인한 뒤 결과를 해석합니다.

설정과 검증

커널 크기와 적용 횟수는 다른 의미입니다. 입력에 두 물체를 두고 틈과 커널 크기를 비교하면 연결 여부를 관찰할 수 있습니다. 팽창 후 연결 성분의 수와 면적이 바뀔 수 있으므로 후속 블롭 결과만 보지 말고 중간 마스크도 확인합니다.
