add_measured_ellipse(self, id, shape, probes, fit, frame=None)

영상에서 측정하는 형상을 fixture에 추가합니다.

확인된 인자 조건

id: 형상 ID.

shape: EllipseShape; fixture 로컬 픽셀 좌표.

probes: ShapeProbeOptions; 추가 시 복사.

fit: RobustFitOptions; 추가 시 복사.

frame: 이전 fixture 인덱스 또는 None(기본).

반환: 추가된 형상 인덱스.

오류: 타입·참조·형상·설정 또는 예산이 유효하지 않으면 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • shape · POSITIONAL_OR_KEYWORD · 기본값 없음
  • probes · POSITIONAL_OR_KEYWORD · 기본값 없음
  • fit · POSITIONAL_OR_KEYWORD · 기본값 없음
  • frame · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Add an image-measured ellipse; fit residual is the existing radial surrogate.

추가와 실행 결과

복합 모델에 영상에서 측정할 타원 형상을 추가합니다. 형상 ID와 fixture 로컬 기준 기하를 지정하고 탐색 및 적합 설정을 함께 전달합니다. frame이 지정되면 해당 fixture 기준을 확인하고, 없을 때와 서로 다른 기준의 좌표를 혼합하지 마십시오. 추가 시 설정이 복사되므로 이후 원래 설정 객체를 바꾼 사실을 이미 추가된 구성의 변경으로 가정하지 않습니다. 긴 반축과 짧은 반축은 전체 지름이 아니므로 단위를 확인하십시오. 반환한 형상 인덱스와 ID를 보관하고 실행 후 관측 상태와 적합 결과를 따로 확인하십시오.

probesShapeProbeOptions; 추가 시 복사.
fitRobustFitOptions; 추가 시 복사.
