method · 선언 타입 zvision.ZImage

Python
stationary_haar_centered(self, levels, centered)

지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

centered: 위상 중심 정렬 여부

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Return a stationary Haar transform with the selected phase.

중심 정렬 선택

stationary_haar_centered는 정지 Haar 변환의 levels와 centered 정렬 선택을 받습니다. 정렬 조건은 결과 계수의 위치를 해석할 때 중요하므로 단순히 시각적 표시 옵션으로 취급하지 않습니다.

결과 비교

같은 입력과 단계에서 centered 설정만 바꾸어 계수 위치를 비교할 수 있습니다. 반환 변환 결과는 독립 소유 객체이므로 밴드 조회나 재구성을 마친 뒤 닫습니다. 지원 형식과 잘못된 단계의 오류는 호출 계약을 확인합니다.
