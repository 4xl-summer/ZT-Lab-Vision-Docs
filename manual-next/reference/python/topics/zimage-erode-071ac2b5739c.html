ZImage.erode 공개 계약

상위 목차로 돌아가기

erode

method · 선언 타입 zvision.ZImage

Python
erode(self, kernel)

Gray8의 비영 전경에 이진 침식을 적용합니다.

확인된 인자 조건

kernel: 기본값 없는 양의 홀수 정사각형 폭(픽셀)

반환: 0/255 새 Gray8 마스크. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 0·짝수 폭이나 미지원 형식은 오류입니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

전경 축소

침식은 구조 요소가 요구하는 이웃의 전경 배치에 따라 출력 전경을 선택합니다. 작은 돌기와 얇은 연결이 줄어들 수 있으며 충분히 작은 객체는 사라질 수 있습니다. 이진 마스크의 전경과 배경을 먼저 확인해야 결과 방향을 올바르게 해석할 수 있습니다.

커널과 후속 분석

커널의 폭과 연산 반복 횟수는 서로 다른 설정입니다. 한 번에 참조하는 이웃 범위와 적용 횟수를 구분해 기록합니다. 침식 뒤 블롭의 연결과 면적이 달라질 수 있으므로 원본 및 결과 마스크를 같은 좌표에서 비교합니다.
