RectangleMeasurementFit(center: zvision._regions.Point2, half_width: float, half_height: float, angle: float) -> None

Fitted rectangle center, half-axes and angle in ROI-local pixels and radians.

center: 사각형 중심의 ROI 로컬 픽셀 좌표입니다.

half_width: 로컬 X 방향 반너비로 픽셀 단위입니다.

half_height: 로컬 Y 방향 반높이로 픽셀 단위입니다.

angle: 로컬 X축 회전각으로 라디안 단위입니다.

생성과 결과 판독

적합 사각형의 중심, 반축과 라디안 각도를 ROI 로컬 픽셀 기준으로 나타냅니다. 반폭 4, 반높이 2면 전체 폭은 8, 전체 높이는 4픽셀입니다. 회전이 있는 경우 화면의 x·y 방향 경계 폭과 변 길이를 같은 숫자로 취급하지 마십시오. 원본 관측과 적합 상태도 함께 확인합니다.

단계별 확인

사각형의 half_width와 half_height는 중심에서 각 로컬 축 방향의 변까지의 거리입니다. angle은 로컬 x축의 회전각이므로 화면 축에 정렬된 외접 상자의 크기와 원래 변 길이를 혼동하지 마십시오.

반폭 4, 반높이 2인 사각형은 회전과 무관하게 로컬 전체 폭 8, 높이 4입니다. 중심이 ROI 로컬 좌표라면 다른 ROI에서 얻은 중심을 비교하기 전에 각 원점을 글로벌 좌표에 반영해야 합니다.

항목확인할 내용
centerROI 로컬 사각형 중심입니다.
half_width로컬 x 방향의 반너비입니다.
half_height로컬 y 방향의 반높이입니다.
angle로컬 x축 회전각이며 라디안입니다.
예시반폭 4, 반높이 2는 전체 8×4입니다.
판독화면상 외접 상자와 원래 변 길이를 구별합니다.
