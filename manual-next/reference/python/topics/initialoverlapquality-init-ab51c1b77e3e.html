InitialOverlapQuality(score: float, residual_rms: float, coverage: float, evaluated: int) -> None

Measured score and diagnostics for a successful optimization.

score: 성공한 정합의 점수; 선택한 점수 방식에 따름.

residual_rms: 정합의 강도 잔차 RMS.

coverage: 유효 표본의 비율.

evaluated: 평가한 정합 후보 수.

이 호출의 입력과 객체 맥락

성공한 정합의 score, 밝기 residual_rms, 유효 표본 비율 coverage와 평가 후보 수를 담습니다. score의 의미는 선택한 점수 방식에 따르고 residual_rms는 강도 잔차이므로 같은 척도로 비교하지 않습니다. 실패 또는 미측정인 InitialOverlapReport의 quality는 None일 수 있으므로 숫자 0을 실패의 대체 표기로 사용하지 마세요.

입력과 결과 확인

InitialOverlapQuality는 성공한 초기 정합에서 점수와 잔차, 유효 표본 비율 및 평가 후보 수를 담습니다. score의 뜻은 선택한 점수 방식에 따르고 residual_rms는 밝기 잔차의 RMS입니다. 두 값은 서로 다른 양이므로 같은 크기라는 이유로 동일한 품질 지표라고 읽지 않습니다.

coverage는 유효 표본의 비율입니다. 예를 들어 100개 후보 표본 중 80개가 유효한 사례라면 비율은 0.8입니다. 이는 표본이 사용 가능했다는 비율이지 정합이 80% 정확하다는 뜻이 아닙니다. evaluated는 평가한 후보 수로, coverage의 분모와 자동으로 같은 값이라고 가정하지 마십시오.

상위 보고서의 quality가 None인 경우는 성공한 품질값이 제공되지 않은 상태입니다. 이를 score=0으로 바꾸면 실제 계산된 0 점수와 구별할 수 없습니다. 기준 영상, 검색 범위, 점수 방식 및 반환 상태를 함께 기록하고 결과를 판독하십시오.

항목확인할 내용
score선택한 점수 방식에 따른 정합 점수입니다.
residual_rms밝기 잔차의 RMS입니다.
coverage사용 가능한 표본의 비율입니다.

None미측정 또는 실패 상태와 숫자 0을 구별합니다.
비교동일한 점수 방식과 입력 조건을 맞춥니다.

score와 residual_rms가 둘 다 부동소수로 저장된다는 사실은 두 수치가 같은 단위를 갖는다는 뜻이 아닙니다. 점수 방식이 바뀌거나 영상의 강도 스케일이 바뀌면 비교 기준도 달라질 수 있습니다. 정합 후보 수가 많아졌다는 것 역시 선택된 후보의 품질이 반드시 좋아졌다는 증거는 아닙니다. 실제 실행에서 어떤 후보를 선택했는지와 그때의 변환, 유효 표본 및 잔차를 한 기록으로 묶어 확인하십시오.
