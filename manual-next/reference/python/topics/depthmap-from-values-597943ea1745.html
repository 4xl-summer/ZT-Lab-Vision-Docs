from_values

Python
def from_values(cls, width, height, values, spacing_x, spacing_y, origin, unit, frame)

클래스 메서드. width와 height는 양의 정수, values는 그 곱만큼의 수 또는 None입니다. spacing_x와 spacing_y는 수, origin은 Point3, unit은 LengthUnit, frame은 1 이상의 정수입니다. 새 DepthMap을 반환합니다. 값 개수가 맞지 않으면 ValueError가 발생합니다.

행 우선 높이와 좌표 메타데이터로 깊이 격자를 생성합니다.

확인된 인자 조건

width: 양의 정수 너비, 셀 수

height: 양의 정수 높이, 셀 수

values: width×height 길이의 유한 숫자 또는 None 시퀀스

spacing_x: X 간격, 유한 양수, unit 단위

spacing_y: Y 간격, 유한 양수, unit 단위

origin: 로컬 (0,0)의 유한 Point3 원점

unit: 길이 단위 LengthUnit

frame: 0이 아닌 좌표계 ID

반환: 새 소유 DepthMap이며 사용 후 닫습니다.

오류: 치수·값 수·간격·frame 또는 값이 무효이면 오류입니다.

깊이 영상 만들기

가로와 세로의 픽셀 수에 맞춰 행 우선 깊이값을 넣고 격자의 간격, 원점, 단위와 frame을 지정합니다. 크기는 양수이며 표본 수는 가로 × 세로와 같아야 합니다. 유효 깊이는 유한해야 하고 결측은 숫자 0과 구분합니다.

2×2 값이 [1, 결측, 3, 4]이면 첫 행의 두 번째 위치는 없는 측정입니다. 간격 (2, 3), 원점 (10, 20, 30)에서는 맨 오른쪽 아래 격자의 x와 y가 각각 12와 23입니다. 그 위치의 깊이 4를 직교 좌표로 변환하면 z는 34입니다.

확인 항목해석
크기양의 가로·세로 픽셀 수
값행 우선이며 개수는 가로 × 세로
간격과 원점격자 위치를 좌표로 바꾸는 기준
결측과 frame빈 측정은 결측, 좌표계는 0이 아닌 식별자
