shifted(self, shift)

정수 회색 결과를 비트 이동합니다. 왼쪽 이동은 포화하고 오른쪽 이동은 절삭합니다.

확인된 인자 조건

shift: −7부터 7까지의 정수 이동량입니다.

반환: 호출자가 닫아야 하는 새 CareGaussianResult입니다.

오류: 이동량 또는 출력 형식이 유효하지 않으면 오류입니다.

인자 선언

  • shift · POSITIONAL_OR_KEYWORD · 기본값 없음

shift: 정수 검사.

Shift Gray8/16 results, saturating left and truncating right.

이 호출의 입력과 객체 맥락

Gray8 또는 Gray16 정수 Gaussian 결과에 −7~7 비트 이동을 적용한 독립 결과를 만듭니다. 양수는 왼쪽 이동 후 형식 범위에 포화되고 음수는 오른쪽으로 이동해 하위 비트를 버립니다. 예를 들어 5를 한 비트 오른쪽으로 이동하면 2입니다. 부동소수 결과에도 적용된다고 가정하지 마세요. 원래 결과와 새 결과는 별도 소유 객체입니다. 사용 후 각 결과를 close합니다.
