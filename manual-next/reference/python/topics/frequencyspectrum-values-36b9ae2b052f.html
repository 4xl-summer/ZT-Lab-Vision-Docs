values

method · 선언 타입 zvision._frequency_processing.FrequencySpectrum

Python
values(self, view=<SpectrumView.AMPLITUDE: 1>)

진폭·위상·파워 등의 스펙트럼 보기를 복사합니다.

확인된 인자 조건

view: SpectrumView, 기본값 AMPLITUDE

반환: 독립 값 튜플입니다.

오류: 지원되지 않는 보기 값은 오류입니다.

인자 선언

  • view · POSITIONAL_OR_KEYWORD · 기본값 <SpectrumView.AMPLITUDE: 1>

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

별칭과 결과 해석

Spectrum은 FrequencySpectrum과 같은 클래스입니다. values와 view는 같은 함수이며 SpectrumView로 표시 종류를 선택합니다. 반환값은 너비×높이 개수의 독립 숫자 튜플입니다. 기본 보기는 AMPLITUDE이며 유효하지 않은 보기와 닫힌 스펙트럼은 오류입니다.

선택한 스펙트럼 값

view에 지정한 진폭·위상·전력 등 스펙트럼 보기를 독립 값 튜플로 복사합니다. 기본은 AMPLITUDE입니다. 복소값 3+4i의 진폭은 5, 전력은 25이며 두 보기는 같은 숫자가 아닙니다.

배치와 제한

결과를 격자의 폭과 높이에 맞춰 읽고 선택한 보기와 정규화를 기록합니다. LOG_AMPLITUDE는 ln(1+진폭)입니다. 하나의 보기만으로 실수부와 허수부의 모든 정보를 복원할 수 없으므로 복소 연산에는 원본 스펙트럼을 유지합니다.
