resize_bilinear

method · 선언 타입 zvision.ZImage

Python
resize_bilinear(self, width: int, height: int)

쌍선형 보간으로 크기를 변경합니다.

확인된 인자 조건

width: 양의 출력 폭

height: 양의 출력 높이

반환: 새 영상. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 폭·높이가 0이거나 형식이 지원되지 않으면 오류입니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

네 이웃의 보간

쌍선형 리사이즈는 가까운 표본들의 값을 위치에 따른 가중치로 섞어 중간값을 만듭니다. 예를 들어 네 꼭짓점 값이 0, 0, 100, 100이고 정확한 중앙에서 네 가중치가 같다면 결과는 50입니다. 실제 위치 대응과 경계 조건은 구현 계약을 확인합니다.

형식과 구조

연속적인 밝기 영상을 부드럽게 크기 변경할 수 있지만 레이블의 중간 숫자가 새 값으로 생길 수 있어 범주형 마스크에는 의미를 따져야 합니다. 작은 물체와 경계의 위치를 원본과 비교하고 출력 형식의 변환 규칙도 확인합니다.
