method · 선언 타입 zvision._edge_query_result.EdgeQuery

Python
get(self, selector, by_label=False)

포함된 에지의 메타데이터를 조회합니다.

확인된 인자 조건

selector: 0부터 시작하는 포함 인덱스 또는 양의 레이블입니다.

by_label: True면 레이블로 선택합니다. 기본값은 False입니다.

반환: 독립 EdgeQueryInfo 값입니다.

오류: 선택 대상이 없거나 인자가 유효하지 않으면 오류입니다.

인자 선언

  • selector · POSITIONAL_OR_KEYWORD · 기본값 없음
  • by_label · POSITIONAL_OR_KEYWORD · 기본값 False

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Get an included edge by dense zero-based index or stable positive label.

이 호출의 입력과 객체 맥락

selector를 기본 설정에서는 현재 포함된 에지의 0 기반 조밀 인덱스로, 레이블 선택이 참이면 안정된 양의 레이블로 해석합니다. 제외 또는 삭제에 따라 조밀 인덱스는 바뀔 수 있으므로 나중에 같은 에지를 참조할 때는 반환 메타데이터의 label을 기록하세요. 반환 EdgeQueryInfo는 독립 값 스냅샷이며 점 배열은 points로 별도 복사합니다.
