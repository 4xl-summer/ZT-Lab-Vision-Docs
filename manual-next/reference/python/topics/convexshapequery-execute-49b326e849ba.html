method · 선언 타입 zvision._query.ConvexShapeQuery

Python
execute(self) -> 'QueryExecution[ConvexShapeResult]'

지연 계획을 실행하고 결과 스냅샷을 만듭니다.

반환: 닫아야 하는 QueryExecution입니다. 출력 값 스냅샷은 실행을 닫은 후에도 유효합니다.

오류: 닫힌 객체, 지원하지 않는 입력 또는 실행 실패는 오류입니다.

반환 타입 주석: QueryExecution[ConvexShapeResult]

Execute and return shapes with immutable hulls.

호출과 결과 확인

볼록 성분 분석 계획을 실행해 QueryExecution에 ConvexShapeResult 스냅샷을 만듭니다. 각 구성요소의 ROI 로컬 껍질과 최소 회전 사각형을 읽고 원본 좌표가 필요하면 영상 원점을 반영합니다. 빈 성분 결과와 실행 오류는 구분해야 합니다.

성분 연결과 결과 확인

ImageQuery에서 전경 연결 방식을 정해 계획을 만든 다음 execute로 실제 분석을 수행합니다. 4연결과 8연결은 대각선으로만 닿는 전경 픽셀을 같은 성분으로 볼지에 차이가 있습니다. 예를 들어 두 픽셀이 대각선으로만 만나면 4연결에서는 두 성분, 8연결에서는 한 성분입니다.

QueryExecution은 닫아야 하지만 꺼낸 ConvexShapeResult는 독립 값 스냅샷입니다. 각 성분의 껍질은 ROI 로컬 픽셀 셀의 외곽이며 최소 면적 회전 사각형도 같은 로컬 좌표로 읽습니다. 전경이 없다면 빈 shapes와 실행 오류를 구분합니다.
