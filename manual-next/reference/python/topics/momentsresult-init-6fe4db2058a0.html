MomentsResult(moments: 'tuple[RegionMoments, ...]') -> None

Independent region moments snapshot.

moments: 각 성분의 면적, 로컬 중심과 중심 모멘트 및 관성 타원 측정을 담은 독립 튜플입니다.

이 호출의 입력과 객체 맥락

각 성분의 모멘트 값을 담는 독립 튜플을 보관합니다. 각 항목은 면적, 로컬 중심, 중심 모멘트 및 관성 타원 측정을 나타냅니다. 결과 중심을 전체 이미지나 세계 좌표에 바로 섞지 말고 원래 ROI의 기준을 확인하세요. 이 값 스냅샷은 결과 영상 핸들이 아니며, 쿼리 실행에서 얻은 뒤 실행을 닫아도 이미 얻은 스냅샷은 사용할 수 있습니다.

사용 흐름과 판독 기준

MomentsResult는 각 연결 성분의 RegionMoments 값을 튜플로 보관하는 불변 스냅샷입니다. 튜플의 한 항목은 해당 성분의 면적과 ROI 로컬 중심, 중심 모멘트 및 관성 타원 관련 값을 설명합니다. 결과 객체를 생성하는 일은 입력 영상을 새로 분석하는 작업이 아니며 이미 준비된 moments를 묶는 생성입니다.

중심은 해당 ROI를 기준으로 하므로 다른 ROI의 중심과 비교할 때 각각의 원점을 먼저 확인합니다. 예를 들어 ROI 원점이 (100,200)이고 로컬 중심이 (2,3)이면 전체 영상 기준 중심은 (102,203)입니다. 면적은 픽셀 영역의 크기이고 중심 좌표는 위치이므로 숫자가 같아도 서로 다른 양입니다.

쿼리에서 얻은 이 스냅샷은 결과 영상 핸들이 아닙니다. 실행을 닫은 후에도 이미 얻은 튜플은 독립 값으로 보관할 수 있습니다. 여러 성분의 항목을 다른 라벨 결과와 연결할 때는 해당 실행의 항목 순서와 성분 식별 정보를 함께 기록하고, 다른 영상의 같은 위치 인덱스가 같은 물체라고 가정하지 않습니다.
