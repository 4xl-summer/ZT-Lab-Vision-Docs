roi(self, x, y, width, height)

원점과 보정을 유지하는 하위 ROI를 만듭니다.

확인된 인자 조건

x: 로컬 시작 x

y: 로컬 시작 y

width: 양의 픽셀 폭

height: 양의 픽셀 높이

반환: 별도로 close할 CalibratedImage입니다.

오류: 범위를 벗어나거나 크기가 유효하지 않으면 오류입니다.

인자 선언

  • x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음

Create a child ROI retaining global origin and calibration.

보정을 유지한 하위 영역

로컬 시작 x, y와 양의 width, height로 하위 ROI를 만듭니다. 반환 CalibratedImage는 원점과 보정을 유지하며 별도 소유입니다. 원본 경계를 벗어나거나 유효하지 않은 크기는 오류입니다.

전역 좌표

부모 전역 원점이 (100,200)이고 하위 시작이 (10,20)이면 하위 원점은 전역 (110,220)에 대응합니다. 로컬 점을 세계 보정에 전달할 때 이 원점을 빠뜨리지 않습니다. 반환 객체는 사용 후 닫습니다.
