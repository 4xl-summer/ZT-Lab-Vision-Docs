match_advanced_colors(self, samples, metric)

픽셀마다 선택한 Lab 거리 방식으로 가장 가까운 기준 색을 찾습니다.

확인된 인자 조건

samples: 비어 있지 않은 LabColor 기준 색 시퀀스입니다.

metric: 타입이 지정된 ColorDistance입니다.

반환: 호출자가 닫아야 하는 AdvancedMatches입니다.

오류: 입력 타입·샘플·거리 설정이 유효하지 않으면 오류입니다.

인자 선언

  • samples · POSITIONAL_OR_KEYWORD · 기본값 없음
  • metric · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Find the nearest reference per pixel using a typed color distance.

호출과 결과 확인

각 픽셀에 대해 LabColor 기준 표본 가운데 지정한 ColorDistance로 가장 가까운 색을 찾습니다. samples는 빈 배열이 아닌 기준 색 목록이며 선택 인덱스와 거리는 다른 출력입니다. 반환 AdvancedMatches의 image(0)과 image(1)에서 각각 인덱스와 거리 영상을 얻고 결과와 영상들을 각각 닫습니다.
