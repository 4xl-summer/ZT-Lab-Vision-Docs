DifferenceInfo(gain: float, bias: float, inspected_count: int, mean_score: float, max_score: float)

gain: 입력 밝기에 적용된 보정 배율입니다.

bias: 보정 입력에 더한 밝기 편향입니다.

inspected_count: 포함 마스크로 선택된 픽셀 수입니다.

mean_score: 선택 픽셀의 평균 차분 점수입니다.

max_score: 선택 픽셀의 최대 차분 점수입니다.

이 호출의 입력과 객체 맥락

차분 과정에서 실제로 사용한 밝기 보정과 점수 통계를 담습니다. gain과 bias는 검사 입력에 적용된 계수이며, 부호 있는 잔차는 gain × 입력 + bias − 기준으로 해석합니다. inspected_count는 포함 마스크에서 선택한 픽셀 수이고 mean_score와 max_score는 그 선택 집합의 점수 통계입니다. 제외된 표본을 정상 픽셀로 추가해 평균한 값이 아닙니다.

기본 허용치가 5이고 보정 후 한 픽셀의 절대 잔차가 10이며 질감 가중치가 0이라면 해당 점수는 2입니다. 점수가 1 이상인 위치는 결함 마스크에 들어갑니다. 평균 점수가 작더라도 국소적으로 큰 점이 있을 수 있으므로 max_score와 후보 목록을 함께 확인해야 합니다. 전체 밝기 변화에 OFFSET을 적용하면 gain은 1이고 평균 차이에 따른 bias가 사용됩니다.
