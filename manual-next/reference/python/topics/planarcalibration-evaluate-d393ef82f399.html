evaluate

method · 선언 타입 zvision._calibration.PlanarCalibration

Python
evaluate(self, pixels, world, world_unit, tolerance)

대응점의 양방향 잔차와 허용치를 평가합니다.

확인된 인자 조건

pixels: 비어 있지 않은 글로벌 픽셀 Point2 열.

world: 같은 개수의 세계 Point2 열.

world_unit: 세계점 및 tolerance 단위.

tolerance: 유한한 0 이상의 세계 거리 허용치.

반환: 독립 CalibrationValidation; 최대 세계 잔차가 한계 이하이면 passed.

오류: 다른 길이, 빈 입력, 무효 단위·허용치·좌표 또는 역변환 실패는 오류.

인자 선언

  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • world · POSITIONAL_OR_KEYWORD · 기본값 없음
  • world_unit · POSITIONAL_OR_KEYWORD · 기본값 없음
  • tolerance · POSITIONAL_OR_KEYWORD · 기본값 없음

tolerance: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

사용과 결과 판독

대응 픽셀과 세계 기준점에 대한 검증 통계와 잔차 스냅샷을 계산합니다. 픽셀과 세계 배열의 순서가 같은 물리점을 가리켜야 하며 unit과 tolerance는 세계 길이 단위를 따릅니다. 합성 사례에서 예측 (12,42) mm와 기준 (12.3,42.4) mm의 거리는 0.5 mm입니다. 집계와 개별 잔차를 함께 보고 학습점과 보류점의 평가를 구별하십시오.
