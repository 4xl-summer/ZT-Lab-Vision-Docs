TelecentricCamera.intersect_plane 공개 계약

상위 목차로 돌아가기

intersect_plane

method · 선언 타입 zvision._camera_models.TelecentricCamera

Python
intersect_plane(self, pixel, pose, plane, min_abs_cos=1e-09, allow_behind=False)

픽셀별 직교 광선과 세계 평면의 교점을 계산합니다.

확인된 인자 조건

pixel: 전역 픽셀 Point2입니다.

pose: 카메라에서 세계로의 RigidTransform3입니다.

plane: 세계 프레임의 WorldPlane입니다.

min_abs_cos: 광선과 평면 법선 사이 최소 절대 코사인이며 기본값은 1e-9입니다.

allow_behind: 광선 원점 뒤 교점 허용 여부로 기본값은 False입니다.

반환: 세계 좌표 Point3입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • pixel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • plane · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_abs_cos · POSITIONAL_OR_KEYWORD · 기본값 1e-09
  • allow_behind · POSITIONAL_OR_KEYWORD · 기본값 False

min_abs_cos: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

입력 글로벌 픽셀에서 만들어진 텔레센트릭 광선을 카메라→세계 pose로 옮겨 plane과 교차시킵니다. 포즈와 평면의 프레임·길이 단위가 맞아야 하며 min_abs_cos는 평행에 가까운 교차의 허용 기준입니다. allow_behind는 bool이며 뒤쪽 교차를 허용할지 선택합니다. 반환은 세계 3차원 점이고, 교차가 안정적으로 정의되지 않으면 오류입니다.

이 객체의 확인된 공개 생성 경로: TelecentricCamera(sx: float, sy: float, cx: float, cy: float, unit: zvision._calibration.LengthUnit, camera_frame: int) -> None.
