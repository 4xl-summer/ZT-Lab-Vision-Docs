rotation

staticmethod · 선언 타입 zvision._calibration.Affine2

Python
rotation(angle)

원점 기준 회전 변환을 만듭니다.

확인된 인자 조건

angle: 유한한 회전 각도, 라디안.

반환: 새 Affine2 값.

오류: 비유한 각도는 오류.

인자 선언

  • angle · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

입력 angle은 유한한 라디안이고 회전 중심은 좌표 원점입니다. 영상 좌표에서 x는 오른쪽, y는 아래이므로 양의 각도는 시계 방향으로 보입니다. 예를 들어 π/2 회전은 점 (1, 0)을 이론적으로 (0, 1) 방향으로 보냅니다. 실제 계산 결과는 부동소수 표현이므로 0 근처의 작은 오차가 생길 수 있습니다. 원점이 아닌 점을 중심으로 회전하려면 먼저 그 중심을 원점으로 이동하고 회전한 다음 다시 이동하는 변환을 올바른 순서로 합성해야 합니다.
