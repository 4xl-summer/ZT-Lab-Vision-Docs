method · 선언 타입 zvision._blob_context.BlobContext

Python
calculate(self, image, work_budget)

유효한 입력 핸들 확인 후 이전 현재 결과를 폐기하고 분석합니다.

확인된 인자 조건

image: Gray8 ZImage

work_budget: 양의 작업량 상한; 최소 64 × 픽셀 수

반환: 별도로 close할 독립 BlobResult입니다.

오류: Python 인자나 입력 핸들 검증 실패는 기존 결과를 폐기하지 않습니다. 검증을 통과해 네이티브 계산이 시작된 후 실패하면 현재 결과가 없습니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

After input handle validation, discard current result and return an independent BlobResult.

현재 결과 계산

컨텍스트에 설정한 조건으로 Blob 분석을 수행해 현재 결과를 갱신합니다. 설정을 바꾸는 단계와 실제 계산은 구분되며 성공한 세대와 현재 결과의 존재 여부를 확인해야 합니다.

후속 조회

계산 후 상태를 확인하고 get으로 필요한 성분을 읽습니다. 입력 전경과 연결성에 따라 같은 대각선 픽셀도 성분 수가 달라질 수 있으므로 이미지와 설정을 함께 기록합니다. 계산 이전의 결과를 새 설정의 결과로 취급하지 않습니다.
