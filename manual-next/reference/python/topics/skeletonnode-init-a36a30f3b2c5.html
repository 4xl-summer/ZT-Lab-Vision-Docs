SkeletonNode(point: zvision._regions.Point2, degree: int, kind: zvision._region_topology.SkeletonNodeKind)

point: 노드의 좌표입니다.

degree: 노드에 접한 그래프 연결 차수입니다.

kind: 끝점, 분기점 등의 노드 분류입니다.

이 호출의 입력과 객체 맥락

SkeletonNode는 골격의 위치를 나타내는 Point2, 연결된 간선의 차수 degree, 분류 kind를 담습니다. 노드의 위치와 연결 구조는 서로 다른 정보입니다. 같은 위치에 표시되는 점이라도 연결된 가지의 수와 분류에 따라 끝점 또는 접합점 등으로 해석됩니다.

SkeletonNodeKind는 ENDPOINT, JUNCTION, ISOLATED, LOOP_ANCHOR를 구분합니다. 예를 들어 하나의 가지 끝은 끝점으로, 여러 가지가 만나는 위치는 접합점으로 해석합니다. 닫힌 루프는 자연스러운 끝점이 없어 그래프 표현에서 합성 루프 기준점이 사용될 수 있습니다.

입력과 결과를 읽는 순서

SkeletonNode는 골격 그래프의 한 위치 point, 접하는 간선 수 degree, 노드 종류 kind를 담습니다. 좌표와 연결 차수는 서로 다른 정보입니다. Point2가 같은 기준의 위치를 나타내더라도 접한 간선 수와 분류가 다르면 그래프에서 하는 역할이 다릅니다.

kind에는 끝점, 접합점, 고립점, 루프 기준점 등의 분류가 있습니다. 예를 들어 열린 가지의 끝은 끝점으로 해석할 수 있고, 닫힌 루프에는 자연스러운 끝점이 없어 표현을 위한 루프 기준점이 사용될 수 있습니다. kind와 degree를 한 필드로 합쳐 읽지 마세요.

point를 원본 영상이나 다른 ROI의 그래프와 비교할 때는 각 좌표의 기준과 영상 원점을 확인합니다. 노드 하나만으로 간선 전체의 길이나 점 배열을 알 수 없으므로 연결된 edge 정보도 별도로 확인해야 합니다. 이 생성자는 그래프 전체를 계산하는 호출이 아닙니다.
