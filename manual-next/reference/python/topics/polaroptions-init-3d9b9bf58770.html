PolarOptions(center_x: float, center_y: float, start_angle: float, end_angle: float, start_radius: float, end_radius: float, width: int, height: int, interpolation: zvision._polar_gap.PolarInterpolation = <PolarInterpolation.NEAREST: 0>, border: float = 0.0) -> None

Center/radii in pixels, angles in radians, output dimensions and border.

center_x: 입력 ROI 로컬 중심 X 좌표이며 픽셀 단위입니다.

center_y: 입력 ROI 로컬 중심 Y 좌표이며 픽셀 단위입니다.

start_angle: 시작 각도이며 라디안 단위입니다.

end_angle: 끝 각도이며 시작보다 크고 각도 폭은 최대 16π 라디안입니다.

start_radius: 음이 아닌 시작 반경이며 픽셀 단위입니다.

end_radius: 시작보다 큰 끝 반경이며 픽셀 단위입니다.

width: 각도 방향 출력 크기로 2 이상의 정수입니다.

height: 반경 방향 출력 크기로 2 이상의 정수입니다.

interpolation: 최근접 또는 쌍선형 보간이며 기본값은 최근접입니다.

border: 입력 영역 밖의 상수 밝기이며 기본값은 0입니다.

이 호출의 입력과 객체 맥락

입력 ROI 로컬 중심, 시작·끝 각도와 반경, 각도 방향 width와 반경 방향 height를 지정합니다. 각도는 라디안이고 반경은 픽셀입니다. 끝 각도와 반경은 각각 시작보다 커야 하며 각도 폭은 최대 16π입니다. 출력 두 크기는 2 이상입니다. 예를 들어 중심 좌표를 전체 프레임에서 얻었다면 ROI 원점과의 차이를 먼저 고려해야 올바른 위치를 펼칠 수 있습니다.
