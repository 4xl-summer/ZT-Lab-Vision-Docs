CaliperEdge(position: zvision._regions.Point2, distance: float, strength: float) -> None

CaliperEdge(position: zvision._regions.Point2, distance: float, strength: float)

position: 보간된 에지의 ROI 로컬 위치.

distance: 프로파일 시작점에서의 픽셀 거리.

strength: 보간된 부호 있는 기울기; 원시 강도/픽셀.

계산과 결과 해석

캘리퍼가 프로파일에서 선택한 에지 하나를 위치, 선분 시작점부터의 거리, 부호 있는 강도로 표현합니다. position은 해당 ROI의 로컬 픽셀 좌표이고 distance는 탐색 방향의 픽셀 거리입니다. strength는 원시 강도/픽셀 단위의 보간된 기울기여서 강도값 자체와 비교해서는 안 됩니다. 에지가 픽셀 중심 사이에 있을 때 위치가 소수로 나올 수 있으며, 이는 피크 보간의 결과이지 실제 장비의 절대 정확도를 보장하는 수치가 아닙니다. 같은 물리 경계라도 선분 진행 방향을 반대로 하면 상승과 하강이 바뀌고 강도 부호도 달라집니다. 에지 결과가 여러 개라면 시작점에서의 거리와 선택 정책을 함께 확인하십시오. 조건에 맞는 피크가 없을 때는 항목이 없는 결과가 정상일 수 있습니다. 두 에지를 너비 계산에 사용하려면 먼저 같은 프로파일에 속하는지와 시작점에서의 거리 순서를 확인합니다. 위치 좌표의 x 차이만 빼면 비스듬한 탐색선에서 실제 프로파일 거리와 다를 수 있습니다. 극성과 점수를 변경한 비교에서는 각 에지가 어느 경계에서 왔는지도 함께 확인하십시오. 선분을 비스듬히 설정했다면 이 거리는 선분을 따라 잰 길이입니다. 픽셀 인덱스의 차이와 단순히 동일하다고 가정하지 마십시오.

단계별 확인

에지의 프로파일 거리는 시작점에서 탐색 방향을 따라간 길이이고, 영상 위치는 그 지점을 표현하는 두 좌표입니다. 선분이 기울어져 있다면 두 에지의 x 좌표 차이만으로 프로파일 간격을 얻을 수 없습니다.

예를 들어 같은 프로파일에서 두 에지가 거리 2와 7에 있으면 진행 방향 간격은 5픽셀입니다. 선분의 방향을 뒤집으면 순서와 극성의 해석이 바뀔 수 있으므로 사용한 시작점, 끝점과 선택 정책을 같이 기록하십시오.
