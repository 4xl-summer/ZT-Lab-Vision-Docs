find(self, source, options, clutter_threshold, clutter_weight, mask=None)

care 특징에 대한 형상 점수에 지정된 clutter 위치의 검색 에지 밀도 페널티를 적용합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 형상 검색 설정입니다.

clutter_threshold: 유한한 양의 clutter 기울기 임계값입니다.

clutter_weight: 페널티 가중치로 0..1입니다.

mask: 선택 검색 마스크입니다.

반환: 독립 AdvancedMatchReport입니다.

오류: coarse, subpixel, certainty, 절삭 가림 점수는 이 검색에서 지원하지 않으며 잘못된 입력은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • clutter_threshold · POSITIONAL_OR_KEYWORD · 기본값 없음
  • clutter_weight · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Penalize source edge density at transformed labelled clutter positions.

클래스별 검색 해석

학습한 care 특징으로 형상 점수를 구하고 변환된 clutter 위치의 검색 에지 밀도로 점수를 조정합니다. 보이는 clutter 표본의 에지 비율을 f, 가중치를 w라면 조정 배수는 1−w×f입니다. 예를 들어 w=0.5, f=0.4이면 배수는 0.8입니다. 보이는 clutter 표본이 없으면 감점하지 않습니다. threshold와 weight는 서로 다른 역할이므로 옵션과 종료 진단을 함께 확인합니다.
