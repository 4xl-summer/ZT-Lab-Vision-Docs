method · 선언 타입 zvision._multi_registration.MultiRegistration

Python
mosaic(self, scale=1.0, overlap=<MosaicOverlap.MEAN: 2>)

영상 합집합 캔버스에 모자이크를 만듭니다.

확인된 인자 조건

scale: 유한한 양의 출력 배율, 기본 1.

overlap: 겹침 선택 FIRST, LAST 또는 MEAN; 기본 MEAN.

반환: 호출자가 close할 RegistrationMosaic 소유 결과입니다.

오류: 닫힌 객체 또는 부적합한 캔버스·배율·옵션은 오류입니다.

인자 선언

  • scale · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • overlap · POSITIONAL_OR_KEYWORD · 기본값 <MosaicOverlap.MEAN: 2>

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Render the union canvas with first, last or mean overlap policy.

사용과 결과 판독

변환된 영상들의 합집합으로 캔버스를 정하고 겹치는 영역을 지정 정책으로 합성합니다. FIRST, LAST, MEAN은 같은 겹침 픽셀을 다르게 선택할 수 있습니다. 출력 배율과 결과 캔버스의 공통 좌표 원점을 함께 기록하십시오.
