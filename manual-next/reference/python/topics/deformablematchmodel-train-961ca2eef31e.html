train(cls, template, reference, deformations, sample_step=1, mask=None)

명시된 변위 격자 각각으로 NCC 변형 모델을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 ZImage입니다.

reference: 유한한 템플릿 로컬 Point2 기준점이며 영상 밖도 가능합니다.

sample_step: 양의 표본 간격(픽셀)이며 기본값 1입니다.

mask: 같은 크기·원점의 선택 Gray8 마스크입니다.

deformations: 1..64개 TemplateDeformation이며 각 격자는 2×2 이상이고 각 격자의 점 수는 1024 이하입니다.

반환: 호출자가 닫아야 하는 변형 모델 은행입니다.

오류: 변위·템플릿·마스크 또는 표본이 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • deformations · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

sample_step: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

명시한 각 변위 격자로 NCC 변형 모델 은행을 학습합니다. deformations는 1개에서 64개이며 각 격자는 2×2 이상이고 각 격자의 점 수는 1024개 이하여야 합니다. 임의의 연속 변형 전체를 자동 학습하는 기능은 아닙니다.

reference는 유한한 템플릿 로컬 기준점이고 sample_step은 양의 픽셀 간격입니다. 선택 Gray8 마스크는 템플릿과 같은 크기·원점을 사용합니다. 각 변형의 인덱스를 보관해 검색 결과와 연결하고 모델은 사용 후 닫습니다.
