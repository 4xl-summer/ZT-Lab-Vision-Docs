method · 선언 타입 zvision._adaptive_inspection.BeadReference

inspect(self, image, width_tolerance, center_tolerance)

학습된 기준과 현재 영상의 비드 폭·중심을 비교합니다.

확인된 인자 조건

image: 기준과 호환되는 검사 영상.

width_tolerance: 폭 차이의 유한한 0 이상 허용치(픽셀).

center_tolerance: 중심 차이의 유한한 0 이상 허용치(픽셀).

반환: 호출자가 close할 BeadReferenceResult 소유 객체입니다.

오류: 닫힌 객체 또는 유효하지 않은 입력은 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width_tolerance · POSITIONAL_OR_KEYWORD · 기본값 없음
  • center_tolerance · POSITIONAL_OR_KEYWORD · 기본값 없음

width_tolerance: 유한한 수 검사.

center_tolerance: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

인자별 입력 조건

인자형식역할과 조건
image기준과 호환되는 검사 영상.
width_tolerance폭 차이의 유한한 0 이상 허용치(픽셀).
center_tolerance중심 차이의 유한한 0 이상 허용치(픽셀).

폭과 중심 비교

모델의 기준 경로를 따라 검사 영상의 비드를 측정하고 width_tolerance와 center_tolerance를 적용합니다. 폭과 중심은 서로 다른 편차이므로 한 조건만 보고 다른 조건의 통과를 단정하지 않습니다.

반환된 BeadReferenceResult는 소유 자원입니다. 결과의 탐침 및 위반 구간과 사용한 허용치를 함께 살펴보고 사용 후 close합니다. 입력이 정렬되지 않았다면 실제 위치 변화와 검사 오차가 섞일 수 있습니다.
