copy_region_to_image

Python
copy_region_to_image(self, destination, mask, options)

선택 영역을 대상 영상의 독립 복사본에 복사합니다.

확인된 인자 조건

destination: 대상 ZImage

mask: 선택 마스크

options: ROI 로컬 복사 영역과 클리핑 설정

반환: 독립 영상과 복사 보고서입니다.

오류: 옵션·입력이 유효하지 않으면 오류입니다.

인자 선언

  • destination · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Copy selected pixels to an independent destination snapshot and report.

선택 영역의 복사

입력에서 마스크로 선택된 영역을 대상 영상의 독립 복사본에 배치합니다. options에는 ROI 로컬 복사 영역과 클리핑 설정이 포함됩니다. 원본 대상 영상과 반환 복사본을 구분하고 두 영상의 좌표 기준을 확인해야 합니다.

보고 값의 해석

반환되는 독립 영상과 복사 보고서를 함께 확인합니다. Copied는 실제 복사한 선택 픽셀 수이고 Clipped는 대상 밖으로 잘린 선택 픽셀 수입니다. 예를 들어 선택한 5개 중 3개만 대상 안에 들어가면 잘린 위치와 좌표 설정을 살펴야 합니다.
