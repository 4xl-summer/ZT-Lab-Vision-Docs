add_tolerance

Python
add_tolerance(self, id, relation, first, minimum, maximum, second=0, include_minimum=True, include_maximum=True)

형상 관계의 허용 범위를 추가합니다.

확인된 인자 조건

id: 공차 식별자.

relation: 관계 종류.

first: 첫 형상 인덱스.

minimum: 최솟값; 거리·좌표는 픽셀, 각은 라디안.

maximum: 최댓값; 관계에 따른 단위.

second: 관계에 따라 둘째 형상, fixture 또는 연속 점 수.

include_minimum: 최솟값 포함 bool; 기본 True.

include_maximum: 최댓값 포함 bool; 기본 True.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • relation · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • minimum · POSITIONAL_OR_KEYWORD · 기본값 없음
  • maximum · POSITIONAL_OR_KEYWORD · 기본값 없음
  • second · POSITIONAL_OR_KEYWORD · 기본값 0
  • include_minimum · POSITIONAL_OR_KEYWORD · 기본값 True
  • include_maximum · POSITIONAL_OR_KEYWORD · 기본값 True

minimum: 유한한 수 검사.

maximum: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Add a tolerance; second is the second feature, fixture index, or point count.

Bounds are pixels for distances/coordinates and radians for angular relations.
Straightness uses `first` as the first of `second` consecutive point features.

이 호출의 입력과 객체 맥락

relation과 first·second 참조를 사용해 평가할 허용오차를 정의합니다. minimum과 maximum은 허용 구간의 경계이며 include_minimum과 include_maximum은 각각 경계 포함 여부를 결정하는 bool입니다. 거리·좌표 경계는 픽셀, 각도 관계는 라디안입니다. second의 의미는 관계에 따라 두 번째 특성, 프레임 인덱스 또는 점 개수이므로 선택한 relation의 계약을 확인하세요. 반환 인덱스와 사용자 지정 id를 혼동하지 않습니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
