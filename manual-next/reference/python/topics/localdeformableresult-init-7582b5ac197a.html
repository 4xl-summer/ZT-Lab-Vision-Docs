position: 검색 영상의 로컬 기준점 위치입니다.

global_position: 검색 영상 원점을 더한 전역 기준점 위치입니다.

scale_x: 거친 포즈의 양의 x 배율입니다.

scale_y: 거친 포즈의 양의 y 배율입니다.

coarse_score: 거친 NCC 검색의 점수입니다. 국소 품질과 다른 척도입니다.

quality: 1/(1+평가에 사용하는 밝기 잔차 RMS)인 국소 품질입니다. 강건 모드의 잔차는 제한될 수 있어 raw residual_rms와 다를 수 있으며 입력 밝기 단위에 영향을 받습니다.

coverage: 활성 템플릿 중 유효한 표본의 비율입니다.

iterations: 선택된 후보의 국소 반복 횟수입니다.

evaluations: 선택된 후보의 국소 목적값 평가 횟수입니다. 다른 후보는 포함하지 않습니다.

converged: 국소 정지 간격 도달 여부이며 전역 최적 보장은 아닙니다.

coarse_termination: 거친 검색이 완료, 예산, 시간 또는 확실도 중 어떤 이유로 끝났는지 나타냅니다.

dx: 거친 변환 후 검색 영상 x축의 국소 변위(픽셀)를 템플릿 좌표에서 행 우선으로 복사한 튜플입니다.

dy: 거친 변환 후 검색 영상 y축의 국소 변위(픽셀)를 템플릿 좌표에서 행 우선으로 복사한 튜플입니다.

warped: 템플릿 좌표로 정렬한 검색 밝기의 행 우선 튜플입니다.

residual: 정렬 밝기에서 템플릿 밝기를 뺀 행 우선 잔차 튜플입니다.

valid: 각 표본의 유효 여부를 0 또는 1로 나타낸 바이트열입니다.

grid_x: 제어 격자의 x 방향 점 수입니다.

grid_y: 제어 격자의 y 방향 점 수입니다.

control_dx: 제어점 x 변위의 행 우선 튜플입니다.

control_dy: 제어점 y 변위의 행 우선 튜플입니다.

objective: 최종 잔차 항과 제어 격자 평활 항을 결합한 목적값입니다.

residual_rms: 유효 영역의 밝기 잔차 RMS이며 입력 밝기 단위입니다.

valid_count: 영상과 마스크에서 유효한 표본 수입니다.

photometric_gain: 검색 밝기를 템플릿 밝기로 변환하는 gain입니다. 보정을 사용하지 않으면 1입니다.

photometric_bias: 검색 밝기를 템플릿 밝기로 변환하는 bias입니다. 보정을 사용하지 않으면 0입니다.

inlier: 유효 표본의 잔차 내점 여부를 나타낸 바이트열입니다. 강건 모드를 사용하지 않으면 valid와 같습니다.

inlier_count: 유효 내점 수입니다.

이 호출의 입력과 객체 맥락

거친 포즈와 국소 변형 정합의 결과 스냅샷입니다. position은 검색 영상 로컬 기준점이고 global_position은 영상 원점을 더한 위치입니다. dx/dy, warped, residual은 템플릿 좌표 행 우선 값이며 valid는 표본 유효 여부입니다. coarse_score와 국소 quality는 서로 다른 척도이고, converged는 국소 정지 조건이지 전역 최적 보증이 아닙니다.
