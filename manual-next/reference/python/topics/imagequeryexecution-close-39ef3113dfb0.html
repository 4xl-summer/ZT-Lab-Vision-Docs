close(self) -> 'None'

반환 타입 주석: None

실행 소유권을 해제한다. 반복 호출은 안전하다.

실행 소유권 해제

ImageQueryExecution의 소유권을 해제하고 None을 반환합니다. 반복 close는 안전합니다. 닫은 실행에서 새 출력이나 캡처를 획득하려고 하면 오류가 날 수 있으므로 필요한 접근을 먼저 마칩니다.

획득한 영상

이미 acquire_output 또는 get_image로 획득한 별도 소유 이미지 핸들은 그 핸들 자체의 수명 규칙에 따라 관리합니다. 저장소 공유와 깊은 픽셀 복사는 다르므로 독립 복사가 필요한 경우 해당 API를 확인합니다.

닫기 전후의 접근

close는 실행 객체의 소유권을 해제하고 None을 반환합니다. 같은 객체에서 반복 호출해도 안전합니다. 닫힌 실행에서 acquire_output이나 이름 붙인 캡처를 새로 얻는 것은 유효한 접근으로 가정하지 않습니다.

항목판독할 내용
execute계획을 실행해 실행 객체를 얻음
acquire_output별도 소유 출력 영상 공유 획득
get_image이름에 해당하는 캡처 영상 획득
close실행 소유권 해제; 반복 호출 가능

실행과 출력은 별개의 수명 단위입니다. 먼저 필요한 출력과 캡처를 획득하고 사용을 마친 뒤 각 ZImage 핸들과 실행 객체를 정리합니다. 이미 획득한 공유 핸들은 각자의 소유권 규칙으로 관리하며 공유가 픽셀의 깊은 복사를 뜻하지는 않습니다.
