python 공개 선언
DecodeOptions(model_width: int, model_height: int, coordinates: int = 0, nms: int = 0, score_threshold: float = 0.5, iou_threshold: float = 0.5, max_detections: int = 100) -> None

검출 상자 좌표 해석과 비최대 억제 설정값입니다. 실제 제약은 디코드 호출 시 검사됩니다.

model_width: 모델 좌표의 양의 너비(픽셀).

model_height: 모델 좌표의 양의 높이(픽셀).

coordinates: 0 픽셀 모서리, 1 정규화 모서리, 2 픽셀 중심, 3 정규화 중심 좌표; 기본 0.

nms: 0 클래스별, 1 클래스 무관, 2 억제 해제; 기본 0.

score_threshold: 포함할 최소 유한 점수 [0,1], 기본 0.5.

iou_threshold: 억제 판단의 유한 IoU 임계값 [0,1], 기본 0.5.

max_detections: 반환할 최대 검출 수인 양의 정수, 기본 100.

이 호출의 입력과 객체 맥락

DecodeOptions.coordinates: 박스 좌표 해석: 0 픽셀 모서리, 1 정규화 모서리, 2 픽셀 중심·크기, 3 정규화 중심·크기; 기본 0. YOLO 경로는 2 또는 3.

DecodeOptions.iou_threshold: NMS 중복 IoU 한계; 유한한 0–1, 기본 0.5. 이 값보다 클 때 억제.

DecodeOptions.max_detections: 반환할 최대 검출 수; 양의 정수, 기본 100.

DecodeOptions.nms: 비최대 억제: 0 클래스별, 1 클래스 무관, 2 비활성; 기본 0.

DecodeOptions.score_threshold: 후보 점수 하한; 유한한 0–1, 기본 0.5.

DecodeOptions.model_width: 모델 입력 너비; 양의 정수 픽셀. 정규화 x 좌표 복원에 사용.

DecodeOptions.model_height: 모델 입력 높이; 양의 정수 픽셀. 정규화 y 좌표 복원에 사용.
