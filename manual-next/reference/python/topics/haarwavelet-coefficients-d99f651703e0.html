coefficients(self)

행 우선으로 저장된 계수를 복사합니다.

반환: 독립 숫자 튜플입니다.

오류: 닫힌 객체, 잘못된 계수 또는 옵션은 오류입니다.

Return packed row-major coefficients as an independent tuple.

이 호출의 입력과 객체 맥락

현재 모델의 계수를 행 우선 숫자 튜플로 복사합니다. 튜플은 독립 값이므로 일부 계수를 바꾸려면 목록 등으로 복사해 편집한 뒤 with_coefficients로 새 모델을 만듭니다. 원래 모델과 새 모델은 각각 close합니다. 계수 크기와 밴드 순서를 모델 정보와 함께 확인하세요.

계수 배열과 모델

coefficients()는 HaarWavelet 모델의 계수를 행 우선 순서의 독립 숫자 튜플로 복사합니다. 튜플의 각 값은 웨이블릿 계수이며 원본 영상의 같은 위치 밝기라고 해석하면 안 됩니다. 닫힌 모델에서 조회하려고 하면 오류가 납니다.

변환은 저주파와 세부 변화 성분을 다룹니다. 결과의 크기와 밴드 배치는 모델 정보를 이용해 읽어야 합니다. 예를 들어 원본 영상이 일정한 영역이라도 세부 밴드의 값과 원본 픽셀의 밝기는 서로 다른 의미를 나타냅니다.

항목확인할 내용
coefficients()행 우선 독립 튜플
값의 의미웨이블릿 계수; 원본 밝기와 구분

닫힌 모델조회 오류

일부 계수를 바꾸려면 독립 튜플에서 편집 가능한 값을 준비하고 with_coefficients로 새 모델을 만듭니다. 원래 모델과 새 모델은 각각 close합니다. 역변환 결과를 입력과 비교할 때 크기, ROI 원점과 정규화·계수 배치를 함께 확인합니다.

적용과 판독을 더 살펴보기

모델에서 읽은 계수는 변환 단계에 따라 저주파와 세부 정보를 나타냅니다. 한 밴드의 큰 계수가 원본에서 곧바로 같은 값의 밝은 픽셀이라는 뜻은 아닙니다. 계수의 위치를 바꾸거나 일부를 제거하면 역변환 영상도 달라지므로 변경 전 계수와 변경 후 계수를 따로 보관합니다. 계수 값의 개수와 순서는 with_coefficients가 요구하는 모델 구조에 맞아야 합니다. 출력이 예상과 다르면 먼저 영상 크기, 단계 수와 밴드 배치를 확인한 다음 동일한 입력의 복원 결과와 비교합니다. 모델이 닫힌 뒤에 계수를 새로 조회할 수는 없지만 이미 복사한 불변 튜플은 별도 값으로 보유할 수 있습니다.
