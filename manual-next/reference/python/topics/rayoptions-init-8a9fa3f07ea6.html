Brown 렌즈 역투영의 반복과 수렴 허용치를 지정합니다.

max_iterations: 1–1024 정수이며 기본값은 32입니다.

pixel_tolerance: 유한한 양의 픽셀 오차 허용치이며 기본값은 1e-9입니다. 양수 조건은 연산에서 검증합니다.

이 호출의 입력과 객체 맥락

RayOptions는 왜곡된 영상 좌표에서 카메라 광선 방향을 구할 때 반복 계산의 한계와 수렴 기준을 지정합니다. max_iterations의 기본값은 32이고 유효 범위는 1부터 1024까지이며 pixel_tolerance 기본값은 1e-9 픽셀입니다. 허용 오차는 양수여야 합니다. 이 값은 실제 카메라의 보정 정확도나 관측 잡음을 나타내지 않습니다.

예를 들어 최대 반복 수가 32이면 계산이 수렴하지 않아도 그 한계를 넘어 무한히 계산하지 않습니다. 반환된 RayResult의 converged와 residual_pixels를 확인하고, 수렴하지 않았다면 방향을 확정된 측정값으로 사용하지 마세요. 허용 오차를 엄격하게 만든다고 보정 모델이 표현하지 못한 실제 렌즈 오차까지 없어지는 것은 아닙니다.

사용 흐름과 판독 기준

RayOptions는 Brown 렌즈의 왜곡된 픽셀에서 광선 방향을 역으로 구할 때 반복 횟수와 픽셀 잔차의 허용치를 지정합니다. 기본 max_iterations는 32, pixel_tolerance는 1e-9 픽셀입니다. 반복 상한은 1~1024의 정수이고 허용치는 유한한 양수여야 합니다. 객체 생성과 광선 역산은 다른 단계이며 양수 조건은 실제 연산에서 검증합니다.

예를 들어 최대 반복을 32로 지정했다면 계산은 그 횟수를 넘겨 무한히 정련하지 않습니다. 허용 오차를 만족하여 일찍 끝날 수도 있고 제한 안에 수렴하지 않을 수도 있습니다. RayResult의 converged와 residual_pixels, 반복 결과를 함께 살펴보고 수렴하지 않은 방향을 검증된 결과로 간주하지 않습니다.

pixel_tolerance는 계산한 투영 잔차의 픽셀 기준이지 실제 장비의 물리 정확도나 렌즈 모델의 전 범위 오차 보증이 아닙니다. 관측점, 렌즈 파라미터 및 이미지 좌표계가 달라지면 역산 결과도 달라집니다. 입력 픽셀과 렌즈의 주점·초점 값이 같은 영상 기준인지 확인하고, 허용치를 바꾼 경우 원래 오차와 종료 상태를 함께 기록합니다.
