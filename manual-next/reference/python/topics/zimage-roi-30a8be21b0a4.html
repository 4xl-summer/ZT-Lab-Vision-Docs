ZImage.roi 공개 계약

상위 목차로 돌아가기

roi

method · 선언 타입 zvision.ZImage

Python
roi(self, x, y, width, height)

현재 영상의 로컬 사각형을 공유 ROI로 얻습니다.

확인된 인자 조건

x: 로컬 시작 열, 0 이상

y: 로컬 시작 행, 0 이상

width: 양의 폭(픽셀)

height: 양의 높이(픽셀)

반환: 원점이 갱신된 별도 소유 ROI 핸들. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: ROI가 범위 밖이거나 폭·높이가 0이면 오류입니다.

인자 선언

  • x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

공유 관심 영역

ROI는 원본의 일부를 선택하여 해당 부분을 영상으로 다루는 방법입니다. 위치와 크기를 정할 때 원본 경계 안의 범위인지 확인하고 ROI 로컬 좌표와 원본 전체 좌표를 구분합니다. 로컬 점 (10,20)과 ROI 원점 (100,200)은 전체 좌표 (110,220)에 대응합니다.

수명과 좌표

반환 객체가 공유 핸들인지 복사 영상인지 호출 계약을 확인하고 각 객체의 수명을 관리합니다. 같은 위치의 결과를 전체 영상에 그릴 때 원점을 적용합니다. 관심 영역의 경계에서 물체가 잘리면 면적과 윤곽은 보이는 부분을 기준으로 달라질 수 있습니다.
