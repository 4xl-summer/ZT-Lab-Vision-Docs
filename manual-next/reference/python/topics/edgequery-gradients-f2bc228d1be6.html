gradients

method · 선언 타입 zvision._edge_query_result.EdgeQuery

gradients(self, selector, feature, by_label=False)

선택 에지에 저장된 크기 또는 법선 방향 각도를 복사합니다.

확인된 인자 조건

selector: 포함 인덱스 또는 레이블입니다.

feature: 요청할 크기 또는 각도 기능 비트입니다.

by_label: True면 레이블로 선택하며 기본값은 False입니다.

반환: 독립 부동소수점 튜플입니다. 각도는 라디안입니다.

오류: 해당 기능을 계산하지 않았거나 선택이 유효하지 않으면 오류입니다.

인자 선언

  • selector · POSITIONAL_OR_KEYWORD · 기본값 없음
  • feature · POSITIONAL_OR_KEYWORD · 기본값 없음
  • by_label · POSITIONAL_OR_KEYWORD · 기본값 False

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Copy stored magnitudes or gradient-normal angles for an included edge.

이 호출의 입력과 객체 맥락

현재 포함된 에지의 요청한 크기 또는 법선 각도 응답을 점 순서에 맞춰 복사합니다. 기본 selector는 조밀 인덱스이고 레이블 선택이 참이면 안정된 레이블입니다. 각도는 영상 y 아래 방향 기준 라디안입니다. 점 배열과 응답을 같은 순서로 사용하고, 필요한 기능이 계산되었는지 available로 확인하세요. 반환 숫자들은 독립 값입니다.
