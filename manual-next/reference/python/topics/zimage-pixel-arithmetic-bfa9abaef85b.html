ZImage.pixel_arithmetic 공개 계약

상위 목차로 돌아가기

pixel_arithmetic

method · 선언 타입 zvision.ZImage

Python
pixel_arithmetic(self, right, options, policy=<ZeroDivisorPolicy.ERROR: 0>)

입력 영상 또는 스칼라에 산술식을 적용합니다.

확인된 인자 조건

right: 다른 영상 또는 스칼라 피연산자

options: PixelArithmeticOptions

policy: 0 나눗셈 처리 방식; 기본값 ERROR

반환: 별도로 close할 ZImage입니다.

오류: 옵션, 피연산자 또는 나눗셈 정책이 유효하지 않으면 오류입니다.

인자 선언

  • right · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • policy · POSITIONAL_OR_KEYWORD · 기본값 <ZeroDivisorPolicy.ERROR: 0>

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Apply arithmetic using an explicit zero-divisor policy.

대응 픽셀 계산

두 영상의 대응 위치에 산술 연산을 수행하는 호출입니다. 같은 좌표가 실제 같은 장면 위치를 가리키도록 크기와 ROI를 확인하고 연산 종류를 지정해야 합니다. 입력이 정렬되지 않으면 물체 가장자리에서 예상과 다른 결과가 생길 수 있습니다.

결과 범위

정수와 부동소수 영상은 허용 범위와 출력 표현이 다를 수 있습니다. 초과 값의 처리와 지원 형식은 선택한 연산의 계약을 확인하고, 작은 입력으로 기대값을 비교합니다. 반환 영상과 입력 영상의 수명도 각각 관리합니다.
