DivisionCamera.fit_k 공개 계약

상위 목차로 돌아가기

fit_k

method · 선언 타입 zvision._camera_models.DivisionCamera

Python
fit_k(self, rays, pixels)

고정된 나머지 내참수에서 division 계수 k만 적합합니다.

확인된 인자 조건

rays: 양의 Z 카메라 광선의 반복 가능 값입니다.

pixels: 대응 전역 픽셀의 반복 가능 값입니다.

반환: 적합 카메라와 재투영 픽셀 RMS를 담은 DivisionFit 값입니다.

오류: 배열 길이가 다르거나 표본이 2–100000개 범위를 벗어나거나 적합이 식별되지 않으면 오류입니다.

인자 선언

  • rays · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

알려진 양의 Z 광선과 대응하는 왜곡 픽셀에서 k만 추정합니다. rays와 pixels는 같은 길이이고 순서가 대응해야 하며 2~100000쌍을 지원합니다. fx, fy, cx, cy는 고정하고 기존 k는 초기값으로 사용하지 않습니다. 반환 DivisionFit의 camera와 rms_pixels를 읽습니다. RMS는 픽셀 단위 진단이며 이 값 자체를 직접 최적화하는 과정은 아닙니다.

이 객체의 확인된 공개 생성 경로: DivisionCamera(fx: float, fy: float, cx: float, cy: float, k: float) -> None.
