AdvancedDiagnosticRange(min_roughness: float, max_roughness: float, min_holes: int, max_holes: int, min_feret: float, max_feret: float, min_contrast: float, max_contrast: float)

min_roughness: 거칠기 포함 하한; 유한한 0 이상, 상한 이하. 거칠기는 둘레²/(4π×면적).

max_roughness: 거칠기 포함 상한; 유한하며 하한 이상.

min_holes: 구멍 수 포함 하한; 상한 이하.

max_holes: 구멍 수 포함 상한.

min_feret: 최대 Feret 거리의 포함 하한; 유한한 0 이상 픽셀.

max_feret: 최대 Feret 거리의 포함 상한; 픽셀.

min_contrast: 절대 전경·배경 대비의 포함 하한; 유한한 0 이상.

max_contrast: 절대 대비의 포함 상한; 배경이 없어 대비를 계산하지 못한 후보는 선택되지 않음.

이 호출의 입력과 객체 맥락

영역 후보의 거칠기, 구멍 수, 최대 Feret 거리와 절대 전경·배경 대비의 포함 구간을 지정합니다. 거칠기는 둘레²/(4π×면적)이며 Feret 거리는 픽셀 단위입니다. 각 최솟값은 해당 최댓값 이하여야 합니다. 배경이 없어 대비를 계산하지 못한 후보는 대비 범위에 선택되지 않으므로 숫자 0 대비와 구분하세요. 설정 뒤 결과 후보 수와 각 진단값을 확인합니다.
