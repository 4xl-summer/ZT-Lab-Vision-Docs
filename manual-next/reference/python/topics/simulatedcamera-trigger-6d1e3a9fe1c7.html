method · 선언 타입 zvision._acquisition.SimulatedCamera

Python
trigger(self, id, now_ns)

모의 카메라의 트리거를 등록합니다.

확인된 인자 조건

id: 양의 정수 트리거 식별자입니다.

now_ns: 호출자가 제공하는 나노초 단위 시각입니다.

반환: None을 반환합니다.

오류: 상태, 순서 또는 용량에 맞지 않는 트리거는 오류입니다.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • now_ns · POSITIONAL_OR_KEYWORD · 기본값 없음

id: 정수 검사 · 최소 1.

now_ns: 정수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

Acquiring 상태의 Software 또는 External 모드에서 트리거 이벤트를 등록합니다. id는 양수이며 같은 epoch에서 엄격히 증가해야 하고 대기 항목은 capacity를 넘을 수 없습니다. now_ns는 같은 epoch의 이전 trigger·offer·expire 시간보다 작을 수 없으며 같은 값은 허용됩니다. 성공하면 triggers 통계가 증가합니다. External도 호출자가 관측했다고 제공하는 모의 이벤트입니다.
