PlcInfo(state: zvision._acquisition.PlcState, result_code: int, request_id: int, last_request_id: int, timeout_ns: int, started_ns: int, last_ns: int, stats: zvision._acquisition.PlcStats)

state: 모의 PLC의 현재 상태입니다.

result_code: 현재 결과 코드입니다.

request_id: 현재 요청 식별자입니다.

last_request_id: 이전 요청 식별자입니다.

timeout_ns: 요청 시간 초과 간격으로 나노초 단위입니다.

started_ns: 현재 요청의 시작 시간으로 나노초 단위입니다.

last_ns: 마지막 명령 시간으로 나노초 단위입니다.

stats: 요청과 응답 등의 누적 통계 값입니다.

이 호출의 입력과 객체 맥락

모의 PLC의 현재 state와 request_id, 이전 last_request_id, 결과 코드 및 누적 stats를 한 시점의 값으로 담습니다. timeout_ns, started_ns, last_ns는 나노초 기준입니다. 예를 들어 현재 요청이 언제 시작되었는지와 마지막 명령이 언제였는지 비교할 수 있지만, 이 모의 상태 기계는 Poll 명령으로 기한을 판정합니다. 이 스냅샷은 실제 PLC 네트워크 상태를 조회한 결과가 아닙니다.
