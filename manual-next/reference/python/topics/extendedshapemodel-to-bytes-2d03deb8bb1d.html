to_bytes(self)

형상 모델을 버전과 체크섬을 포함한 아카이브로 직렬화합니다.

반환: 모델과 독립된 bytes입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

Serialize this shape model into its versioned archive.

호출 맥락과 결과 해석

현재 학습된 확장 형상 모델을 버전과 체크섬이 포함된 바이트 아카이브로 만듭니다. 반환 bytes는 모델과 독립된 값이므로 모델의 사용 수명과 별개로 저장할 수 있습니다. 이미지 자체를 저장하는 호출이 아니라 학습 모델을 저장하는 호출입니다.

다시 사용할 때는 대응하는 from_bytes에 완전한 바이트를 전달해 새 모델을 얻습니다. 검색 옵션과 입력 영상은 별도로 준비해야 하며, 저장과 복원 후 동일 조건으로 검색해 결과를 비교하는 방식으로 사용하는 모델의 연결을 확인할 수 있습니다.

반환값 확인

모델과 독립된 bytes입니다.
