close_values(self, kernel, op=21)

값 닫기 단계를 가변 계획에 추가합니다.

확인된 인자 조건

kernel: 양의 홀수 정사각형 커널 폭

op: 기본값 21은 이 메서드에 연결된 ABI 연산 코드입니다. 다른 값을 전달하면 그 코드가 네이티브 Query에 전달되어 동작이 달라지거나 오류가 날 수 있습니다. 이 인자는 보통 기본값으로 둡니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 유효하지 않은 커널 또는 실행 오류가 보고될 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • op · POSITIONAL_OR_KEYWORD · 기본값 21

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

밝기 값의 닫기 단계

밝기 값 팽창 후 침식을 적용하는 단계입니다. 먼저 침식한 뒤 팽창하는 열기와 순서가 다르므로 동일한 결과가 아닙니다. 이진 전경만 다루는 닫기와도 구분하여 입력의 회색값 범위를 확인합니다.

폭과 실행

양의 홀수 커널 폭은 이웃의 크기이며 반복 횟수와 같지 않습니다. 계획 실행 후 작은 어두운 구조와 관심 경계를 입력과 비교하고 결과 영상의 값 형식과 수명을 확인합니다.
