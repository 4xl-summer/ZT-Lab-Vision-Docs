결과 제어점 변위를 행 우선으로 복사합니다.

반환: Point2 리스트입니다.

오류: 정합 결과가 없으면 ValueError입니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

찾은 변형 정합의 격자 변위를 Point2 목록으로 복사합니다. info의 columns와 rows를 곱한 개수이며 격자 크기와 함께 결과를 해석해야 합니다. 정합을 찾지 못한 경우 ValueError입니다. 반환 목록은 이미지 핸들이 아니지만 이를 만든 DeformableRegistration 객체는 사용 후 close합니다. 목록 인덱스를 영상의 전역 좌표로 바로 해석하지 마세요.

변위 필드 획득

displacements는 비강체 등록 결과의 변위 격자를 Point2 목록으로 복사합니다. info.found가 거짓이면 ValueError이며, 참이면 columns×rows개의 값을 복사합니다. 각 변위를 격자의 순서와 좌표 기준에 연결해 읽습니다.

예를 들어 어떤 위치의 변위가 (2,-1)이라면 선택한 방향 규약에 따라 x와 y의 이동 성분을 해석합니다. 반환된 변환 방향을 확인하지 않은 채 원본→목적지 또는 그 반대라고 추정하면 워프 위치가 틀어집니다.

반환 목록은 복사된 Point2 값이며 등록 결과 핸들과 다른 수명입니다. 등록 결과와 aligned_image, valid_mask로 획득한 영상은 각각 close합니다. 미발견 오류를 변위 0의 정상 격자로 바꾸지 않습니다.

반환 Point2 목록의 원소 수는 info의 columns×rows입니다. 예를 들어 열 3, 행 2이면 여섯 변위가 있으며 각 항목을 격자 순서와 연결해 해석합니다. info.found가 거짓이면 이 호출은 ValueError입니다.

복사된 목록은 이미 읽은 값으로 남지만 aligned_image와 valid_mask는 별도 소유 영상입니다. 결과를 사용한 뒤 결과 객체와 획득 영상 각각을 close하고 유효하지 않은 영역을 정상 정렬로 읽지 않습니다.
