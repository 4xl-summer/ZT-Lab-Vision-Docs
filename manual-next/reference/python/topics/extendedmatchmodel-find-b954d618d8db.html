find(self, source, options, mask=None)

확장 NCC 모델과 명시한 격자로 검색합니다.

확인된 인자 조건

source: 검색할 영상입니다.

options: 확장 검색 설정입니다.

mask: 선택적 검색 마스크입니다.

반환: 모델과 입력 영상에서 독립된 결과 스냅샷입니다.

오류: 영상, 마스크 또는 검색 설정이 유효하지 않으면 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search and return an immutable, detached result.

호출 맥락과 결과 해석

확장 NCC 모델을 검색 영상에 적용합니다. ExtendedMatchOptions에서 위치·각도·배율을 각각 명시된 격자로 지정하며 위치는 검색 ROI 로컬 픽셀, 각도는 라디안입니다. 모델 학습 때 지정한 템플릿 로컬 기준점이 검출 포즈를 해석하는 기준입니다.

검색 결과의 매치 목록과 종료 진단을 함께 확인합니다. 격자가 넓거나 촘촘하면 평가할 후보가 늘어나므로 candidate_budget과 실제 평가 상태를 함께 기록합니다. 마스크를 사용하는 경우 검색 대상 영상에 맞는 마스크를 전달합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색할 영상입니다.
options확장 검색 설정입니다.
mask선택적 검색 마스크입니다.

반환값 확인

모델과 입력 영상에서 독립된 결과 스냅샷입니다.
