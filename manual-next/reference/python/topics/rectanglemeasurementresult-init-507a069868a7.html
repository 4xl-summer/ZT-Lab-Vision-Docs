RectangleMeasurementResult(status: int, fit: zvision._shape_models.RectangleMeasurementFit | None, probes: tuple, converged: bool, iterations: int, condition_proxy: float | None) -> None

Detached rectangle result; fit is None when status is not 0 (fit).

status: 적합 성공(0), 점 부족(1), 적합 실패(2) 상태입니다.

fit: 성공 시 적합된 사각형 값이고 그 외에는 None입니다.

probes: 탐침별 관측과 진단을 담은 독립 튜플입니다.

converged: 반복 적합의 수렴 여부입니다.

iterations: 적합 반복 횟수입니다.

condition_proxy: 가중 Jacobian 열 노름의 최대/최소 비율 또는 계산되지 않았으면 None입니다. 행렬 조건수는 아닙니다.

생성과 결과 판독

독립적인 사각형 측정 결과를 나타냅니다. 적합 성공이 아닌 상태에서는 fit이 None이므로 크기 0의 정상 사각형으로 처리하지 마십시오. 적합 결과의 중심과 반축, 각도를 ROI 로컬 좌표계에서 해석하고 어떤 변의 관측이 부족했는지 진단과 함께 확인합니다.

단계별 확인

status는 성공, 점 부족, 적합 실패를 구별하며 성공이 아닌 경우 fit은 None입니다. 관측을 찾았다는 사실과 네 변을 가진 최종 사각형이 적합됐다는 사실도 다릅니다.

probes에서 각 변의 선택점과 채택 여부를 확인한 뒤 fit의 중심과 반축을 ROI 로컬 픽셀로 읽으십시오. condition_proxy는 가중 Jacobian 열 노름의 최대/최소 비율이며 일반적인 행렬 조건수와 같다고 단정하지 않습니다.
