command(self, op, request_id, result_code, now_ns)

요청·게시·확인 등을 모의 PLC에 적용합니다.

확인된 인자 조건

op: PlcOperation 또는 해당 정수입니다.

request_id: 음이 아닌 요청 식별자입니다.

result_code: 0–4294967295 정수 결과 코드입니다.

now_ns: 음이 아닌 명령 시각으로 나노초 단위입니다.

반환: PlcDisposition을 반환합니다.

오류: 상태, 식별자 또는 시간 순서가 유효하지 않으면 오류입니다.

인자 선언

  • op · POSITIONAL_OR_KEYWORD · 기본값 없음
  • request_id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • result_code · POSITIONAL_OR_KEYWORD · 기본값 없음
  • now_ns · POSITIONAL_OR_KEYWORD · 기본값 없음

request_id: 정수 검사.

result_code: 정수 검사 · 최소 0.

now_ns: 정수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

호출자가 제공한 op, request_id, result_code와 now_ns로 모의 핸드셰이크 상태를 진행합니다. 시각은 객체 수명 동안 감소할 수 없습니다. Request는 Idle에서 새 양의 ID로 Waiting을 만들고 Publish는 해당 요청의 결과를 저장하며 Ack는 Idle로 돌아갑니다. 기한 경과는 명시적 Poll만 판정합니다. 이 상태 머신은 실제 PLC 네트워크 I/O가 아닙니다.
