reset(self)

누적 평균·편차 통계와 샘플 수를 초기화합니다.

반환: None.

오류: 닫힌 객체 또는 호환되지 않는 입력과 한도 초과는 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

예를 들어 기존 배치를 누적한 참조를 새로운 기준으로 다시 학습하려면 현재 count를 기록하고 reset한 뒤 새 배치를 update합니다. reset은 새로운 template을 전달하거나 객체를 새로 생성하는 호출이 아닙니다. 저장된 스냅샷은 해당 객체의 별도 계약과 수명을 따릅니다.

현재 온라인 참조의 누적 상태를 초기화합니다. 객체 자체를 해제하는 close와 별도의 동작이며, 이후 새 이미지 배치를 update할 수 있습니다. reset 뒤 count를 확인해 다음 처리 단계에서 어떤 누적 상태를 사용하는지 명확히 하세요. 과거에 별도로 얻은 스냅샷의 수명과 동작은 해당 스냅샷 계약을 확인해야 합니다.

누적 통계 초기화와 새 배치

reset은 OnlineReference의 누적 평균·편차 통계와 샘플 수를 초기화하고 None을 반환합니다. 객체를 해제하는 close나 새로운 템플릿을 전달해 재생성하는 동작이 아닙니다. 초기화 후에는 동일 참조 객체의 유효한 입력 조건을 지켜 새 영상을 update할 수 있습니다.

예를 들어 첫 배치의 count를 기록하고 reset한 뒤 count를 확인하면 다음 학습이 이전 배치 누적값을 섞지 않는지 점검할 수 있습니다. 이후 새 배치의 정상 이미지를 순서대로 update하고 충분한 기준이 준비된 뒤 스냅샷을 얻습니다. reset 이전과 이후를 비교하려면 초기화 전에 필요한 이전 스냅샷이나 기록을 따로 보관해야 합니다.

실행과 판독에서 확인

이전 누적값을 지우는 동작은 자동으로 카메라 조건 변화나 제품 종류를 판단하지 않습니다. 새 배치가 같은 크기와 형식, ROI 기준으로 구성되는지 확인하고 변경된 제조 조건에 맞는 정상 데이터를 준비하세요. 닫힌 참조에 reset을 호출하면 오류이며 count가 0이라는 사실을 이미 유효한 평균 영상이 있다고 해석해서는 안 됩니다.
