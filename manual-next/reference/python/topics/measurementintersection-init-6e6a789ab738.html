python 공개 선언
MeasurementIntersection(kind: int, first: zvision._regions.Point2 | None, second: zvision._regions.Point2 | None) -> None

kind 0 none, 1 point/tangent, 2 two, 3 coincident, 4 parallel.

kind: 교차 분류: 0 없음, 1 한 점, 2 두 점, 3 일치, 4 평행.

first: 한 점 또는 두 점 교차의 첫 점; 없으면 None.

second: 두 점 교차의 둘째 점; 없으면 None.

계산과 결과 해석

직선 또는 원의 교차를 종류와 최대 두 좌표로 반환합니다. kind는 0 없음, 1 한 점 또는 접점, 2 두 점, 3 일치, 4 평행을 나타냅니다. first는 한 점 또는 두 점인 경우 첫 좌표이고 second는 두 점인 경우 둘째 좌표이며 나머지는 None입니다. 예를 들어 서로 다른 평행선은 교점 좌표를 0으로 반환하는 것이 아니라 평행 상태와 좌표 없음으로 구분됩니다. 한 원에 접하는 선은 한 점이지만 두 위치에서 가로지르면 두 점이 됩니다. 판정은 호출에서 지정한 거리 또는 방향 허용치에 의존하므로 입력 좌표 단위와 허용치의 뜻을 같이 기록해야 합니다. None을 원점으로 바꾸면 유효한 (0,0) 교점과 구별할 수 없으니 상태를 보존하십시오. 선과 원의 예에서 직선이 원을 통과하면 두 좌표가 반환될 수 있고 접하면 하나입니다. 교차점이 원점이라도 종류가 한 점임을 유지하면 좌표가 없다는 상태와 구별할 수 있습니다. 판정 후 각 좌표를 처리하기 전에 반드시 종류와 값의 존재 여부를 확인합니다. 일치하는 경우는 모든 점이 같다는 관계로 해석하며 한 개의 대표 교점이 있다는 의미가 아닙니다. 평행 역시 좌표 없음으로 처리합니다. 둘째 좌표는 두 교점인 결과에서 확인합니다.

단계별 확인

교차 결과는 종류에 따라 좌표의 존재 여부가 달라집니다. 원점 (0,0)은 실제 교점이 될 수 있으므로 좌표가 없다는 None을 원점으로 치환하면 올바른 판정과 결측을 구별하지 못합니다.

반경 1의 원을 y=0인 선이 가르면 두 점에서 만나고, y=1이면 한 점에서 접합니다. 일치하는 두 형상은 하나의 대표 교점이 있다는 뜻이 아니므로 반환된 kind를 먼저 읽은 후 허용된 좌표만 사용하십시오.

항목확인할 내용
0교차 없음이며 좌표가 제공되지 않습니다.
1한 점 또는 접점이며 first를 확인합니다.
2두 점 교차이며 first와 second를 확인합니다.
3일치 관계이며 임의 교점 하나가 아닙니다.
4평행 관계를 나타냅니다.
