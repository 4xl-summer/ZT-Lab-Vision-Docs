선형 RGB 전달 함수를 선택합니다.

반환: 불변 InputTransfer 설정입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

입력 RGB의 선형 전달 방식을 지정하는 불변 설정값을 만듭니다. 실제 영상 변환을 실행하거나 영상 핸들을 만들지는 않습니다. 입력이 이미 선형인 경우 해당 색 변환 설정에 이 값을 전달하고, sRGB로 부호화된 입력과 같은 것으로 가정하지 마세요. 변환 결과 비교에는 입력 전달 함수와 백색점 정보를 함께 기록합니다.

이미 선형인 RGB 입력 지정

InputTransfer.linear()는 입력 RGB가 선형 전달 특성을 가진다는 불변 설정값을 만듭니다. 이 호출은 영상에 변환을 수행하거나 이미지 핸들을 만들지 않습니다. 설정을 색상 변환 호출에 전달하면 입력 성분을 어떤 전달 함수로 해석할지 지정하는 역할을 합니다.

예를 들어 선형 RGB의 성분 0.5를 입력하면 이 설정은 그 입력이 선형으로 표현되었다는 조건을 전달합니다. sRGB로 인코딩된 값 0.5는 일반적으로 같은 선형 광량 0.5와 동일하게 취급할 수 없습니다. 입력 영상이 어느 표현으로 만들어졌는지 확인한 다음 맞는 InputTransfer를 선택해야 합니다.

수명과 결과 확인

색 공간 변환 결과는 전달 함수뿐 아니라 선택된 백색점과 입력 색 공간에도 영향을 받습니다. 동일 영상에서 설정만 바꾼 결과를 비교할 때는 원본 값, 전달 함수, 백색점을 함께 기록하세요. 설정값 생성에 성공했다는 사실만으로 영상이 실제로 선형인지 검증되는 것은 아니며 촬영·전처리 경로에서 입력 표현을 확인해야 합니다.
