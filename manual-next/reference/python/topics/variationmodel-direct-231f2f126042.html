direct(cls, reference, variation, mask=None)

기존 별칭으로 기준·변동 영상에서 모델을 만듭니다.

확인된 인자 조건

reference: 기준 ZImage

variation: 변동 ZImage

mask: 선택 ZImage; 기본값 None

반환: 별도로 close할 VariationModel입니다.

오류: 입력 타입 또는 영상 조건이 맞지 않으면 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • variation · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Legacy 0.1.x alias for from_envelopes; retained for migration.

인자별 입력 조건

인자형식역할과 조건
reference기준 ZImage
variation변동 ZImage
mask선택 ZImage; 기본값 None

기존 이름으로 모델 생성

direct는 from_envelopes의 이전 버전 호환 별칭이며 reference와 variation, 선택적 mask를 그대로 전달합니다. 새 코드에서는 from_envelopes로 호출 목적을 명확히 할 수 있습니다.

기준 영상과 편차 영상이 같은 위치와 단위에 대응하는지 확인합니다. 입력 하나가 잘못되어 오류가 발생한 경우 빈 모델이 만들어진 것으로 처리하지 않습니다. 반환된 모델은 다른 생성 경로와 마찬가지로 사용 후 close합니다.
