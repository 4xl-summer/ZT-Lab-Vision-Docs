add_region_fit_circle(self, id, first, count, region, options, coverage=None)

이전 연속 점의 ROI 루트 영역에서 원을 피팅하는 형상을 추가합니다.

확인된 인자 조건

id: 형상 식별자.

first: 첫 이전 점 인덱스.

count: 연속 점 개수.

region: 포함 경계의 ROI 루트 영역.

options: RegionFitOptions.

coverage: CoveragePolicy 또는 None.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • count · POSITIONAL_OR_KEYWORD · 기본값 없음
  • region · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • coverage · POSITIONAL_OR_KEYWORD · 기본값 None

Fit a circle to earlier contiguous point features in an inclusive ROI-root region.

영역 점에서 원 피팅

이전 연속 점 중 first부터 count개를 대상으로 ROI 루트 영역에서 원 피팅 형상을 추가합니다. id는 새 형상 식별자이고 region은 포함 경계의 선택 영역입니다. options와 선택 coverage가 피팅과 적용 범위에 관여합니다.

입력과 진단

원 피팅에 쓰는 점이 영역 안에 충분히 분포하는지 확인합니다. 단위와 잔차 임계값, 최소 호 범위는 options의 계약을 따르며 짧거나 퇴화한 점 분포에서 결과의 의미를 별도 검토해야 합니다. 선택된 점과 잔차를 원본에 표시합니다.
