flatfield_correct

method · 선언 타입 zvision.ZImage

Python
flatfield_correct(image, gain_map=None, offset_map=None, global_gain=1.0, global_offset=0.0, output_format=<PixelFormat.GRAYF32: 3>)

전역 및 픽셀별 게인과 오프셋을 적용합니다.

확인된 인자 조건

image: 입력 ZImage

gain_map: 선택적 게인 ZImage; 기본값 None

offset_map: 선택적 오프셋 ZImage; 기본값 None

global_gain: 양의 유한 게인; 기본값 1

global_offset: 유한 오프셋; 기본값 0

output_format: 출력 회색 형식; 기본값 GRAYF32

반환: 별도로 close할 ZImage입니다.

오류: 입력, 게인 또는 출력 형식이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • gain_map · POSITIONAL_OR_KEYWORD · 기본값 None
  • offset_map · POSITIONAL_OR_KEYWORD · 기본값 None
  • global_gain · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • global_offset · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • output_format · POSITIONAL_OR_KEYWORD · 기본값 <PixelFormat.GRAYF32: 3>

global_gain: 유한한 수 검사.

global_offset: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Return input*global_gain*gain_map+global_offset+offset_map.

픽셀별 보정과 전역 보정

플랫필드 보정은 전역 및 픽셀별 게인과 오프셋을 사용해 입력의 공간별 편차를 보정합니다. 게인 맵과 오프셋 맵의 위치가 입력 영상과 어긋나면 다른 픽셀의 보정값이 적용될 수 있으므로 크기와 ROI 정렬을 확인합니다.

기본값과 단위

선언의 기본값은 gain_map과 offset_map이 None, global_gain 1.0, global_offset 0.0, 출력 형식 GrayF32입니다. 이 설정과 실제 입력 맵을 함께 기록합니다. 보정이 실행되었다는 사실은 카메라의 조명이나 기준 맵 정확도가 검증되었다는 뜻은 아닙니다.
