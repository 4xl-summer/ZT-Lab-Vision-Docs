MatchQuery.execute 공개 계약

상위 목차로 돌아가기

execute

method · 선언 타입 zvision._query.MatchQuery

Python
execute(self) -> 'QueryExecution[MatchResult]'

지연 계획을 실행하고 결과 스냅샷을 만듭니다.

반환: 닫아야 하는 QueryExecution입니다. 출력 값 스냅샷은 실행을 닫은 후에도 유효합니다.

오류: 닫힌 객체, 지원하지 않는 입력 또는 실행 실패는 오류입니다.

반환 타입 주석: QueryExecution[MatchResult]

매칭 계획을 실행하고 불변 결과를 반환한다.

호출과 결과 확인

준비된 영상과 모델 매칭 계획을 실행하고 QueryExecution의 독립 MatchResult 스냅샷을 만듭니다. 결과 목록이 비면 성공한 검색에서 후보가 없을 수 있으므로 오류와 구분합니다. 매치 좌표는 모델 기준점과 검색 ROI를 기준으로 읽고 필요한 캡처가 있다면 실행 결과에서 확인합니다.

실행과 결과의 수명

먼저 ImageQuery에서 검색 모델과 MatchSpec을 연결해 MatchQuery를 준비합니다. execute는 그 계획을 실제로 실행하므로 계획을 만들어 둔 시점과 영상 처리가 수행되는 시점을 구분해야 합니다. 반환 QueryExecution은 사용 후 닫고, 얻은 MatchResult 값 스냅샷은 실행을 닫은 뒤에도 사용할 수 있습니다.

예를 들어 평가된 후보 중 점수·거리 조건을 통과한 항목이 하나도 없다면 실행은 성공해도 matches는 비고 best는 None입니다. 닫힌 계획이나 지원하지 않는 입력은 오류이므로 이 정상적인 빈 결과와 같은 상태로 처리하지 않습니다. ROI 원점과 모델 기준점은 결과 위치를 해석할 때 함께 기록합니다.
