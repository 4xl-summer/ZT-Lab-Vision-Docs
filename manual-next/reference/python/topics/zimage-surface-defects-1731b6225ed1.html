surface_defects(self, score, spec)

마스크의 연결 요소를 점수 영상으로 측정합니다.

확인된 인자 조건

score: 같은 크기와 원점의 GrayF64 점수 영상. 전경 점수는 유한하고 0 이상.

spec: DefectSpec; 연결성과 최소 면적 및 스크래치 분류 조건.

반환: SurfaceDefectResult 소유 객체. 사용 후 close합니다.

오류: 잘못된 형식·기하·조건은 오류입니다.

인자 선언

  • score · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

마스크에서 후보 추출

결함 마스크의 전경 픽셀을 연결하고 대응하는 점수 영상에서 후보별 측정값을 구합니다. 두 영상은 크기와 원점이 같아야 하며 DefectSpec에서 연결 방식과 최소 면적 등을 선택합니다. 대각선으로 닿은 두 점은 4 연결과 8 연결에서 서로 다른 후보 수를 만들 수 있습니다.

결과에는 각 후보의 면적과 기하, 점수 및 형상 기반 분류가 들어 있습니다. 최소 면적 필터와 최종 합격 기준은 별개이므로 후보가 추출되었다는 사실만으로 불합격을 단정하지 않습니다. DecisionSpec을 사용한 별도 판정이 필요합니다.

이 호출은 현재 영상의 즉시 처리 경로입니다. 반환이 소유 영상이나 소유 결과이면 사용 후 close하고, 값 스냅샷과 핸들의 수명을 구별합니다. 잘못된 입력이나 형식에서 발생한 오류를 빈 정상 결과로 치환하지 않습니다.
