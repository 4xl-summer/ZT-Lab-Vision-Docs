학습 패치의 짝

source는 측정 RGB, reference는 대응하는 목표 RGB입니다. 같은 물체의 패치를 서로 짝지어 fit_color_correction에 여러 개 전달해야 행렬과 편향을 추정할 수 있습니다.

예를 들어 회색 표본의 측정 값과 목표 값을 한 패치로 두고, 다른 색상의 대응 패치도 함께 사용합니다. 입력 순서가 바뀌면 이후 잔차 인덱스와 연결할 때 그 순서를 보존해야 합니다.
