ArcProfileSpec(center: zvision._regions.Point2, radius: float, radial_half_width: float, start_angle: float, angular_extent: float, angular_samples: int, radial_samples: int, interpolation: int = 1) -> None

Center, radius, radial half-width (pixels), start/extent (radians), counts and interpolation. Positive angle runs clockwise in the image's y-down coordinates. Partial arcs include both endpoints; a full turn omits the duplicate endpoint. Interpolation is 0 nearest or 1 bilinear, and every sampled point must be in the ROI.

center: ROI 로컬 픽셀 원호 중심.

radius: 중심선 반경; 유한한 양의 픽셀 값.

radial_half_width: 반경 방향 반폭; 유한하고 0보다 크며 radius보다 작음.

start_angle: 원호 시작 각도; 유한한 라디안.

angular_extent: 양의 각도 범위; 2π 이하 라디안.

angular_samples: 호 방향 표본 수 2–4096.

radial_samples: 반경 표본 수 3–4096; 각 방향 수의 곱 ≤1,000,000.

interpolation: 최근접 또는 이중선형 보간.

생성과 결과 판독

중심과 반경, 반경 방향 반폭은 ROI 로컬 픽셀이며 시작과 범위는 라디안입니다. 양의 각도는 영상 y축이 아래로 향하는 좌표에서 시계 방향으로 진행합니다. 부분 원호는 두 끝을 포함하고 한 바퀴는 중복 끝점을 생략합니다. 요청한 모든 표본이 ROI 안에 있어야 하므로 중심선뿐 아니라 반경 방향 범위도 점검하십시오.
