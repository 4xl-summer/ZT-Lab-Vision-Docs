first: 연속 실패 구간의 첫 번째 0 기반 탐침 인덱스입니다.

last: 연속 실패 구간의 마지막 0 기반 탐침 인덱스이며 끝을 포함합니다.

연속 탐침 구간

first와 last는 구간의 처음과 마지막 탐침을 나타내고 flags는 구간에 연결된 상태 비트입니다. 구간 하나는 여러 탐침으로 이루어질 수 있습니다.

따라서 구간 수와 위반한 탐침 수를 같은 숫자로 읽지 않습니다. 원래 비드 경로의 표본 순서를 유지해 구간을 영상 위치와 연결합니다.
