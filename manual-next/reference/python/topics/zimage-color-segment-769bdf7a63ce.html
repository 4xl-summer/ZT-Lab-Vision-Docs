color_segment(self, target, threshold)

D50 Lab 색차가 임계값 이하인 픽셀을 분리합니다.

확인된 인자 조건

target: 목표 LabColor.

threshold: 유한한 0 이상의 CIE76 색차 상한; 등호 포함.

반환: 255 또는 0의 독립 Gray8 영상이며 close합니다.

오류: 닫힌 객체 또는 잘못된 영상·마스크·인수는 오류입니다.

인자 선언

  • target · POSITIONAL_OR_KEYWORD · 기본값 없음
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

기준 색 주변의 선택

기준 Lab 색상과 허용 거리에 따라 색상을 선택하는 처리입니다. 입력의 색 표현과 참조 Lab 값의 기준 조건이 일치해야 의미 있는 색 거리를 비교할 수 있습니다. 거리 기준을 바꾸면 같은 픽셀도 선택 영역에 들어오거나 빠질 수 있습니다.

예를 들어 기준색과 같은 Lab 좌표는 색 거리 0입니다. 입력 조명과 변환 백색점이 다르면 실제 표면이 같아도 값이 달라질 수 있으므로 설정과 결과를 함께 보관합니다. 선택된 마스크는 제품 합격 판정 자체가 아닙니다.

이 호출은 현재 영상의 즉시 처리 경로입니다. 반환이 소유 영상이나 소유 결과이면 사용 후 close하고, 값 스냅샷과 핸들의 수명을 구별합니다. 잘못된 입력이나 형식에서 발생한 오류를 빈 정상 결과로 치환하지 않습니다.
