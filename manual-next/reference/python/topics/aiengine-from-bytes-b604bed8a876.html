from_bytes

classmethod · 선언 타입 zvision._inference.AiEngine

Python
from_bytes(cls, model: bytes, spec: zvision._inference.AiModelSpec)

선언한 고정 사양으로 RTen 모델을 로드합니다.

확인된 인자 조건

model: 1바이트–64MiB의 bytes 모델

spec: AiModelSpec

반환: 별도로 close할 AiEngine입니다.

오류: 타입, 모델 크기 또는 모델·사양이 유효하지 않으면 오류입니다.

인자 선언

  • model · POSITIONAL_OR_KEYWORD · 타입 <class 'bytes'> · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision._inference.AiModelSpec'> · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Load trusted RTen bytes using the declared fixed model spec.

사용과 결과 판독

모델 바이트와 고정 입력·출력 사양이 서로 맞아야 합니다. 유효한 크기의 바이트라도 모델 형식이나 사양이 맞지 않으면 로드에 실패할 수 있습니다. 얻은 엔진은 독립 소유 자원으로 사용 후 닫습니다.
