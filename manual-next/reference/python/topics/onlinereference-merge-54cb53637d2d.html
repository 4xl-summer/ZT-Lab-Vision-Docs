merge(self, other)

다른 온라인 기준의 누적 통계를 합칩니다.

확인된 인자 조건

other: 형식·기하·포함 마스크가 같고 샘플이 있는 OnlineReference.

반환: None. 합산 개수는 대상 상한을 넘을 수 없습니다.

오류: 닫힌 객체 또는 호환되지 않는 입력과 한도 초과는 오류입니다.

인자 선언

  • other · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

다른 OnlineReference의 정보를 현재 객체에 병합합니다. other는 OnlineReference여야 하며 두 객체는 호출 중 유효해야 합니다. 병합 후 count로 현재 객체의 상태를 확인하고 필요하면 freeze로 스냅샷을 얻습니다. 서로 다른 기준 영상이나 설정의 호환성은 이름이 같다는 이유만으로 가정하지 말고 병합 결과 또는 오류를 확인하세요.
