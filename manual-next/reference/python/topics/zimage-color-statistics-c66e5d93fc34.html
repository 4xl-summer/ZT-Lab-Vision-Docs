color_statistics(self, mask=None)

선택 픽셀의 인코딩 RGB 채널별 모집단 통계를 계산합니다.

확인된 인자 조건

mask: 선택적 동일 크기·원점의 Gray8 마스크; 비제로 포함, None은 전체.

반환: 독립 ColorStatistics 값 스냅샷입니다.

오류: 닫힌 객체 또는 잘못된 영상·마스크·인수는 오류입니다.

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

색 통계의 영역과 값

영상의 색 통계를 계산합니다. 평균 같은 요약값은 입력의 색 분포를 하나의 값으로 압축하므로 밝은 부분과 어두운 부분이 섞인 경우 원래의 공간적 배치를 보여 주지 않습니다. 비교하려는 영상이 같은 제품 영역과 조명 조건을 가리키는지 먼저 확인합니다.

마스크나 ROI를 사용한 경로라면 선택 영역이 달라졌는지도 통계와 함께 살펴봅니다. 값이 달라졌을 때 원본 영상의 분포와 표본 범위를 비교하면 조명 변화와 물체 구성 변화의 가능성을 구별하는 데 도움이 됩니다.

이 호출은 현재 영상의 즉시 처리 경로입니다. 반환이 소유 영상이나 소유 결과이면 사용 후 close하고, 값 스냅샷과 핸들의 수명을 구별합니다. 잘못된 입력이나 형식에서 발생한 오류를 빈 정상 결과로 치환하지 않습니다.
