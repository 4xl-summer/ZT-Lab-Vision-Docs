python 공개 선언
FeatureSearchOptions(ratio: float = 0.8, max_distance: float = 0.2, inlier_threshold: float = 1.0, ransac_iterations: int = 128, seed: int = 17, max_descriptor_comparisons: int = 200000, mutual: bool = True, transform: zvision._matching_features.FeatureGeometry = <FeatureGeometry.AFFINE: 0>) -> None

ratio는 (0,1) 최근접 거리 비율, max_distance는 정규화 패치 L2 상한, inlier_threshold는 픽셀 잔차 상한입니다. ransac_iterations는 1..4096, seed는 u64, max_descriptor_comparisons는 1..10000000, mutual은 상호 최근접, transform은 기하 종류입니다.

ratio: 최근접 후보 거리 비율 한계로 0보다 크고 1 미만입니다. 기본값 0.8입니다.

max_distance: 정규화 기술자 L2 거리의 유한한 비음수 상한입니다. 기본값 0.2입니다.

inlier_threshold: 기하 잔차 임계값(픽셀)으로 유한한 양수입니다. 기본값 1입니다.

ransac_iterations: RANSAC 반복 수로 1..4096입니다. 기본값 128입니다.

seed: 반복에서 쓰는 부호 없는 64비트 시드입니다. 기본값 17입니다.

max_descriptor_comparisons: 기술자 비교 상한으로 1..10000000입니다. 기본값 200000입니다.

mutual: 상호 최근접 검사 여부입니다. 기본값 True입니다.

transform: AFFINE 또는 PROJECTIVE 기하 추정 종류이며 기본값 AFFINE입니다.

값을 구성하고 해석하기

특징 기술자 대응과 기하 검증을 설정합니다. ratio와 max_distance는 대응 후보의 거리 조건이고 inlier_threshold는 변환 잔차의 픽셀 기준입니다. RANSAC 반복 수·시드와 기술자 비교 상한은 따로 지정하므로 입력 영상과 이 설정을 함께 보관해야 검색을 비교하기 쉽습니다.
