Python
forward(cls, image, options)

지정 크기와 정규화의 일반 DFT를 계산합니다. 이 팩터리는 기존 호환 API입니다.

확인된 인자 조건

image: 입력 ZImage입니다.

options: 폭, 높이 및 정규화를 담은 FftOptions입니다.

반환: 호출자가 닫아야 하는 GeneralSpectrum입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Transform an image with the requested arbitrary size and normalization. Legacy factory retained through 0.1.x; prefer image.general_dft(options.width, options.height, options.normalization).

이 호출의 입력과 객체 맥락

입력 실수 영상과 변환 크기·정규화 옵션으로 일반 DFT 스펙트럼을 만듭니다. 이 경로는 분리 직접 DFT로 표본 수 최대 1,048,576과 너비×높이×(너비+높이) 25,000,000 한도를 검사합니다. FFT와 같은 성능을 가정하지 마세요. 생성한 소유 스펙트럼은 사용 후 close하고 계수가 필요하면 parts로 실수부와 허수부 복사값을 읽습니다.
