ConvexShapeResult(shapes: 'tuple[ConvexShape, ...]') -> None

Independent convex shapes with immutable hulls.

shapes: 성분별 볼록 껍질과 최소 면적 사각형을 담는 독립 스냅샷 튜플입니다.

값을 구성하고 해석하기

전경 연결 성분별 ConvexShape 값을 담는 독립 스냅샷입니다. 각 형상에는 성분 인덱스, ROI 로컬 볼록 껍질 점과 최소 면적 회전 사각형이 들어 있습니다. 전경이 없다면 형상 목록이 비어 있을 수 있으므로 첫 항목을 읽기 전에 개수를 확인합니다.

생성할 때 확인할 값

인자값의 의미
shapes성분별 볼록 껍질과 최소 면적 사각형을 담는 독립 스냅샷 튜플입니다.

형상 한 개의 구성

shapes의 각 ConvexShape는 구성요소 인덱스, 볼록 껍질 점들, 최소 면적 회전 사각형을 묶습니다. 껍질은 전경 픽셀의 중심점 집합이 아니라 셀 외곽을 둘러싼 경계입니다. 시작점을 끝에 다시 반복하지 않으므로 닫힌 선을 그릴 때는 표시 단계에서 마지막 점과 첫 점을 연결합니다.

전경을 연결 성분으로 나누는 방식이 4인지 8인지에 따라 shapes의 개수가 달라질 수 있습니다. 결과 좌표는 ROI 로컬이므로 원본 영상에 표시하려면 ROI 원점을 반영합니다. 빈 튜플은 전경 성분이 없는 정상 결과가 될 수 있습니다.

항목확인할 내용
component_index해당 연결 성분의 인덱스
hullROI 로컬 셀 외곽의 볼록 껍질
rectangle최소 면적 회전 사각형
빈 shapes형상 항목이 없는 결과

결과를 점검하는 방법

예를 들어 전경이 없는 마스크는 shapes가 빈 튜플일 수 있고, 두 개의 분리된 성분을 가진 마스크는 각 성분의 형상 항목을 따로 가집니다. 대각선 접촉 여부와 연결 방식에 따라 성분 수가 달라지므로 결과 개수만을 고정된 물체 수로 가정하지 않습니다.
