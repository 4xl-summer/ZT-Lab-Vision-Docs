Line2DOptions(normal_angle: float = 0.0, gradient_radius: int = 1, projection_length: int = 4, min_contrast: float = 1.0, min_normalized_contrast: float = 0.0, max_extract_work: int = 16000000, max_candidates: int = 4096, line_angle_tolerance: float = 0.2, edge_angle_tolerance: float = 0.2, min_length: float = 0.0, min_coverage: float = 0.0, polarity: int = 0, max_lines: int = 4, max_fit_work: int = 16000000, fit: zvision._advanced_probe_model.RegionFitOptions = <factory>) -> None

ROI-local central gradient, projection, angle/length/coverage and consensus limits. Angles are radians. Polarity is 0=either, 1=rising, 2=falling along the expected normal. Projection regions retain their physical stripe indices after masking. Coverage is occupied stripes / inclusive stripe-index span. max_lines=0 reports extracted peaks without fitting. min_contrast uses half gradient magnitude; normalized contrast divides by mean intensity.

normal_angle: 예상 법선 각도로 라디안 단위이며 기본값은 0입니다.

gradient_radius: 중심 차분 간격으로 양의 픽셀 정수이며 기본값은 1입니다.

projection_length: 투영 스트라이프 길이로 양의 픽셀 정수이며 기본값은 4입니다.

min_contrast: 기울기 크기의 절반에 적용하는 음이 아닌 임계값이며 기본값은 1입니다.

min_normalized_contrast: 정규화 대비 하한으로 0–1이며 기본값은 0입니다.

max_extract_work: 추출 작업 상한인 양의 정수이며 기본값은 16000000입니다.

max_candidates: 추출 후보의 상한으로 1–4096이며 기본값은 4096입니다.

line_angle_tolerance: 직선 법선 각도 허용 오차로 0–π/2 라디안이며 기본값은 0.2입니다.

edge_angle_tolerance: 에지 법선 각도 허용 오차로 0–π/2 라디안이며 기본값은 0.2입니다.

min_length: 직선 구간 최소 길이로 음이 아닌 픽셀 값이며 기본값은 0입니다.

min_coverage: 점유 스트라이프 비율의 하한으로 0–1이며 기본값은 0입니다.

polarity: 예상 법선 방향의 극성으로 0 양쪽, 1 상승, 2 하강이며 기본값은 0입니다.

max_lines: 최대 적합 직선 수로 0–32이며 0이면 적합하지 않습니다. 기본값은 4입니다.

max_fit_work: 적합 작업 상한으로 1–16000000이며 기본값은 16000000입니다.

fit: 직선 적합에 전달할 RegionFitOptions 값입니다.

이 호출의 입력과 객체 맥락

예상 법선 각도, 중심 차분 간격과 스트라이프 길이, 대비 및 선 적합 조건을 지정합니다. 각도 허용치는 라디안이고 gradient_radius와 min_length는 픽셀 기준입니다. max_lines=0이면 선을 적합하지 않으며 추출·적합 작업 예산은 서로 별개입니다. 검출 에지의 극성은 예상 법선 방향 기준이므로 좌표 방향을 맞추세요.
