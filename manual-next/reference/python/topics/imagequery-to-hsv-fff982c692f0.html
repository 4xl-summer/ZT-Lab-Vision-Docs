to_hsv(self)

HSV 색상 변환 계획을 만듭니다.

반환: 타입 지정 색상 Query입니다.

오류: 입력이나 계획이 유효하지 않으면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

HSV 평면 계획

색상 영상을 HSV 평면으로 변환하는 계획입니다. H는 0 이상 360 미만의 도 단위, S와 V는 0부터 1의 범위입니다. 0도와 360도 가까운 색조는 원형으로 이웃하므로 단순한 직선 거리만으로 색 차이를 판단하지 않습니다.

입력과 결과

지원되는 sRGB 인코딩과 부동소수 색 값의 유효 범위를 확인하고 반환 쿼리를 실행합니다. 채도가 낮은 색의 색조는 별도로 해석해야 하므로 H만 보지 말고 S와 V도 함께 확인합니다. 출력 평면의 소유 및 해제 규칙을 지킵니다.

평면의 범위

H는 [0,360)도, S와 V는 [0,1]입니다. 예를 들어 H=1도와 359도는 원형 색조에서 인접합니다. 실행 후 세 평면을 같은 위치에서 읽고 무채색에 가까운 픽셀은 채도도 함께 확인합니다.
