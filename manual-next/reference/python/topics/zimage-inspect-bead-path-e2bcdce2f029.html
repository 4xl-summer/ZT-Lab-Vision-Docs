inspect_bead_path(self, path, options, include=None)

영상 로컬 경로의 법선 방향에서 에지쌍을 찾아 비드를 검사합니다.

확인된 인자 조건

path: 최소 2개, 최대 options.max_probes개의 유한한 (x,y) 로컬 탐침 좌표.

options: BeadInspectionOptions 폭·대비·극성·작업 한도.

include: 선택적 경로와 같은 길이의 bool 시퀀스; 하나 이상 참이어야 함.

반환: 호출자가 close할 BeadResult 소유 객체입니다.

오류: 닫힌 객체 또는 잘못된 영상·경로·옵션은 오류입니다.

인자 선언

  • path · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • include · POSITIONAL_OR_KEYWORD · 기본값 None

Inspect a local-coordinate path and return a closeable BeadResult.

경로 기반 비드 검사

지정된 경로를 따라 영상의 비드를 검사합니다. 경로와 검사 설정은 이미지와 같은 좌표 기준을 가리켜야 하고, 결과의 구간과 폭 및 간격을 그 경로의 순서와 연결해 읽습니다. 직선이 아닌 경로에서도 결과 위치를 단순히 하나의 화면 x 좌표로 간주하지 않습니다.

BeadResult에서 가장 긴 간격과 전체 판정을 별도로 확인합니다. 판정은 지정한 조건에 대한 결과이므로 같은 데이터라도 설정한 폭이나 간격 허용치가 달라지면 판단이 달라질 수 있습니다. 결과 객체의 소유 관계를 따르고 사용 후 닫습니다.

인자형식역할과 조건
