otsu_threshold(self, bin_count, lower, upper)

지정 히스토그램 범위의 Otsu 임계값 종료 계획을 만듭니다.

확인된 인자 조건

bin_count: 빈 수

lower: 유한 하한

upper: lower보다 큰 유한 상한

반환: 별도로 close할 OtsuThresholdQuery입니다.

오류: 히스토그램 인자가 유효하지 않으면 오류입니다.

인자 선언

  • bin_count · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lower · POSITIONAL_OR_KEYWORD · 기본값 없음
  • upper · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

분포 기반 임계값 분석

현재 계획 영상의 밝기 분포에서 Otsu 기준 임계값을 구하는 분석입니다. 선택값은 입력 ROI와 전처리 결과에 의존합니다. 서로 다른 조명이나 관심 영역에서도 동일한 숫자가 나온다고 가정하지 않습니다.

숫자와 마스크

자동으로 선택한 임계값을 얻는 단계와 해당 값을 이용해 마스크를 만드는 단계를 구분합니다. 결과 숫자뿐 아니라 실제 물체가 원하는 전경으로 선택되는지 원본과 분할 결과를 비교해 검증합니다.
