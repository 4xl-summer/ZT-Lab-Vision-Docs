find(self, source, options, mask=None)

형상 모델과 설정 격자로 영상을 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 형상 검색 설정입니다.

mask: 선택 검색 마스크입니다.

반환: 입력과 모델에 독립된 검색 결과와 종료 진단입니다.

오류: 유효하지 않은 입력, 모델 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search and return an immutable, detached result.

호출 맥락과 결과 해석

학습한 확장 형상 모델을 검색 영상과 ShapeSearchOptions에 전달해 후보 포즈를 평가합니다. 검색 격자의 x와 y는 검색 ROI의 로컬 픽셀 좌표이고 각도는 라디안입니다. 모델에서 기준점으로 정한 위치가 검색 포즈를 해석하는 기준이 됩니다.

반환 보고서에서는 매치 목록과 종료 진단을 함께 확인합니다. 후보가 비었다는 사실만으로 대상이 영상에 없다고 결론 내리기보다 검색 범위와 후보 예산, 점수 및 에지 조건을 함께 비교합니다. 결과는 입력 영상과 모델에서 독립된 값입니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options형상 검색 설정입니다.
mask선택 검색 마스크입니다.
