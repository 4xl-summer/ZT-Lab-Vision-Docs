가우시안 평활화 단계를 현재 계획에 덧붙입니다.

확인된 인자 조건

kernel: 양의 홀수 폭

sigma: 양의 유한 표준편차

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sigma · POSITIONAL_OR_KEYWORD · 기본값 없음

kernel: 정수 검사 · 최소 1.

sigma: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

가중 평활화 단계

가우시안 단계는 이웃 표본의 가중 평균을 계획에 추가합니다. 커널의 크기는 참조할 주변 범위를, 표준편차는 가중 분포를 조절합니다. 잡음이 줄어들 때 얇은 선도 흐려질 수 있어 후속 경계 결과를 함께 살펴야 합니다.

실행 순서

평활화 후 임계 처리하는 계획은 임계 처리 후 평활화하는 계획과 다를 수 있습니다. 중간 결과가 필요하면 캡처 계약에 따라 저장하고 실행 후 원본과 같은 위치에서 비교합니다. 커널과 입력 형식의 제한도 확인합니다.
