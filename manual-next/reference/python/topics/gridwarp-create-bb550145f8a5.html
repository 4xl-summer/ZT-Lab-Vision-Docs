create

classmethod · 선언 타입 zvision._rigid_frames.GridWarp

Python
create(cls, nodes, spec)

입력 격자점으로 재사용 가능한 격자 맵을 만듭니다.

확인된 인자 조건

nodes: 행 우선 Point2 순서열로 rows×columns 개수입니다.

spec: GridWarpSpec 설정입니다.

반환: 호출자가 닫아야 하는 GridWarp입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • nodes · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

행 우선 전체 교차점과 물리 격자 간격으로 재사용할 쌍선형 역맵을 만듭니다. 노드는 글로벌 픽셀 좌표이며 최소 2×2 격자가 필요합니다. 예를 들어 2행 3열이면 점 6개를 행 순서로 전달합니다. 특이하거나 방향이 바뀐 셀은 거절되지만 국소 검사가 떨어진 셀 사이의 전역 중첩 부재까지 보장하지는 않습니다. 반환 맵은 별도 소유 객체입니다. Python에서는 close합니다.
