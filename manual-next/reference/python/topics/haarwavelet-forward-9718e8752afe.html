영상에서 소유 웨이블릿 계수를 계산합니다.

확인된 인자 조건

image: 입력 ZImage

levels: 1–64 변환 레벨

반환: 별도로 close할 HaarWavelet입니다.

오류: 영상, 레벨 또는 계열이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음

levels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Legacy factory retained through 0.1.x; prefer image.haar_wavelet(levels).

이 호출의 입력과 객체 맥락

입력 ROI의 변환 모델을 새로 생성합니다. levels는 분해 단계이며 적용 가능한 크기 조건은 선택한 변환 계열에서 확인해야 합니다. 소유 모델에서 coefficients로 계수 사본을 얻거나 inverse로 영상을 복원할 수 있습니다. 입력 영상, 생성 모델, 복원 영상의 각 소유권은 따로 관리합니다. 각 분해 단계의 양축은 짝수여야 합니다.
