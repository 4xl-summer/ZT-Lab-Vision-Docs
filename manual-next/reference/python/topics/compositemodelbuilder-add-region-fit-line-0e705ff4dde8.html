add_region_fit_line(self, id, first, count, region, options, coverage=None)

이전 연속 점의 ROI 루트 영역에서 직선을 피팅하는 형상을 추가합니다.

확인된 인자 조건

id: 형상 식별자.

first: 첫 이전 점 인덱스.

count: 연속 점 개수.

region: 포함 경계의 ROI 루트 영역.

options: RegionFitOptions.

coverage: CoveragePolicy 또는 None.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • count · POSITIONAL_OR_KEYWORD · 기본값 없음
  • region · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • coverage · POSITIONAL_OR_KEYWORD · 기본값 None

Fit a line to earlier contiguous point features in an inclusive ROI-root region.

영역 점에서 직선 피팅

이전 점의 first와 count로 연속 입력 범위를 정하고 ROI 루트의 region 안에서 직선 피팅 형상을 추가합니다. id는 형상 식별자이며 options와 선택 coverage는 피팅 설정과 적용 범위를 나타냅니다.

좌표와 검증

region의 경계는 포함되므로 경계에 놓인 점의 선택을 확인합니다. 원본 점과 영역의 좌표 단위를 일치시키고 결과 직선, 인라이어와 잔차를 함께 살펴봅니다. 점의 수와 배치가 부적절한 경우 피팅의 유효성을 별도로 검토합니다.
