row(self, y)

지정 행의 읽기 전용 뷰를 얻습니다.

확인된 인자 조건

y: 0 기반 행 인덱스

반환: 읽기 전용 행 뷰입니다.

오류: 행이 범위 밖이거나 뷰가 닫히면 오류입니다.

인자 선언

  • y · POSITIONAL_OR_KEYWORD · 기본값 없음

y: 정수 검사 · 최소 0.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

읽기 전용 행 뷰

0 기반 y행의 읽기 전용 뷰를 얻습니다. 예를 들어 높이 3의 뷰에서는 유효한 행 위치를 0, 1, 2로 확인합니다. 범위 밖의 행이나 닫힌 뷰는 오류이며 행의 바이트 해석에는 픽셀 형식이 필요합니다.

행과 수명

보이는 행의 성분과 저장소의 전체 stride를 혼동하지 않습니다. 내보낸 행은 별도 lease가 살아 있는 동안 유지될 수 있으며 쓰기 가능한 배열이라고 가정하지 않습니다. 사용이 끝난 뷰와 행 자원을 각 계약에 맞게 해제합니다.
