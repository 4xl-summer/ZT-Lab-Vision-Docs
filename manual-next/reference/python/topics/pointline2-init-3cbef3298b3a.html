PointLine2(a: float, b: float, c: float) -> None

Line a*x+b*y+c=0 for point-to-line calibration.

a: 직선 방정식 a×x+b×y+c=0에서 x 계수.

b: 직선 방정식의 y 계수; (a,b)는 유한하고 0벡터가 아니어야 함.

c: 직선 방정식의 상수항.

이 호출의 입력과 객체 맥락

PointLine2는 2차원 직선을 a·x+b·y+c=0 계수로 표현합니다. a와 b는 직선의 법선 방향을 정의하며 c는 위치에 관련됩니다. 하나의 직선은 모든 계수를 같은 0이 아닌 수로 곱해도 동일한 점 집합을 나타내므로 계수 숫자만으로 두 직선의 기하학적 차이를 판단하면 안 됩니다.

예를 들어 y=2는 0·x+1·y−2=0으로 쓸 수 있고 계수를 두 배 한 0·x+2·y−4=0도 같은 직선입니다. 점 (3,2)를 넣으면 두 식 모두 0이 됩니다. 거리를 구하려면 식의 값을 법선 길이 sqrt(a²+b²)로 나누는 정규화가 필요합니다. 입력 점의 좌표계와 직선 계수가 사용한 좌표계가 같은지도 확인하세요.

입력과 결과를 읽는 순서

PointLine2는 직선 a×x+b×y+c=0을 계수 세 개로 담습니다. (a,b)는 직선의 법선 방향이고 유한한 0이 아닌 벡터여야 합니다. 계수는 특정 점 하나를 나타내는 것이 아니라 방정식을 만족하는 모든 2차원 점의 집합을 나타냅니다.

예를 들어 y=2는 (a,b,c)=(0,1,−2)이고, (0,2,−4)도 모든 계수를 두 배 한 동일한 직선입니다. 점 (3,2)를 넣으면 두 식의 값은 모두 0입니다. 따라서 두 직선의 계수를 숫자 그대로 비교하는 것만으로 기하학적 차이를 판정할 수 없습니다.

점과 직선의 거리는 방정식의 절댓값을 법선 길이 √(a²+b²)로 나누어 해석합니다. 예를 들어 y=2에서 점 (3,5)의 거리는 3입니다. 이 계산의 단위는 점 좌표의 단위이며, 서로 다른 좌표계의 점과 직선을 변환 없이 섞지 않아야 합니다.
