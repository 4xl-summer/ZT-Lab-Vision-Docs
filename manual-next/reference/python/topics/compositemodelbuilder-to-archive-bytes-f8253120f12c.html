to_archive_bytes

Python
to_archive_bytes(self, unit=None)

영상 계측 설정·fixture·출력 단위를 포함해 보관합니다.

확인된 인자 조건

unit: CompositeUnit 또는 None(픽셀).

반환: 독립 bytes.

오류: 무효 그래프·단위 또는 예산 초과는 오류.

인자 선언

  • unit · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: RuntimeError, TypeError, ValueError. 네이티브 오류는 별도입니다.

Archive all model features, probe/fit settings, fixture frames and output unit.

이 호출의 입력과 객체 맥락

프레임, 고정·파생 및 이미지 측정 형상, 탐침·적합 설정과 선택적 출력 단위를 아카이브로 저장합니다. unit=None은 픽셀이고, 단위를 지정하면 양의 units_per_pixel이 필요합니다. 단위 ID가 0이면 배율은 1이어야 합니다. 반환은 독립 bytes이며 길이가 2200000바이트를 넘으면 오류입니다. 이 등방 배율은 일반적인 세계 좌표 보정과 다릅니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
