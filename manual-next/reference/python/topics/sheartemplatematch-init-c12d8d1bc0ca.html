ShearTemplateMatch(match: zvision._matching_advanced.AdvancedMatch, shear: float) -> None

Advanced match and dimensionless x-shear coefficient.

match: 해당 전단 값에서 얻은 독립 AdvancedMatch 값입니다.

shear: 템플릿 변환 u′=u+shear×v에 쓰인 무차원 x 전단 계수입니다.

값을 구성하고 해석하기

전단 NCC 검색의 한 결과로 match에 기본 포즈와 점수, shear에 무차원 x 전단 계수를 담습니다. 템플릿 로컬 좌표에서 전단은 u′=u+shear×v로 적용됩니다. 0이면 이 전단 성분이 없고, 다른 자세의 회전과 축 배율은 포함된 AdvancedMatch에서 읽습니다.

생성할 때 확인할 값

인자값의 의미
match해당 전단 값에서 얻은 독립 AdvancedMatch 값입니다.
shear템플릿 변환 u′=u+shear×v에 쓰인 무차원 x 전단 계수입니다.

전단값의 수치 해석

shear는 x 방향 변형 u′=u+shear×v의 무차원 계수입니다. 예를 들어 shear=0.25이고 템플릿 로컬 점이 (u,v)=(4,8)이면 전단 뒤 u′는 6입니다. shear=0이면 이 식에 의한 추가 x 이동은 없습니다.

이 값은 각도나 축 배율과 별도입니다. 실제로 검색된 포즈와 점수는 match에서 읽고 shear까지 함께 보관해야 해당 후보의 변환을 재구성할 수 있습니다. 값 하나만 보고 모든 영상에 동일한 x 이동이 적용된다고 해석하지 않습니다.
