TelecentricFit(camera: zvision._camera_models.TelecentricCamera, rms_pixels: float)

camera: 적합된 카메라 모델 값입니다.

rms_pixels: 대응점 재투영 오차의 RMS이며 픽셀 단위입니다.

이 호출의 입력과 객체 맥락

TelecentricFit은 텔레센트릭 카메라 모델의 적합 결과를 나타냅니다. camera에는 추정된 모델이 있고 rms_pixels에는 입력 관측에 대한 재투영 RMS가 픽셀 단위로 담깁니다. 모델을 다음 측정에 사용할 때는 입력 픽셀의 좌표계와 적합에 사용한 영상 크기 및 광학 구성을 동일하게 유지해야 합니다.

텔레센트릭 투영의 광선은 서로 평행할 수 있어 원근 카메라처럼 모든 광선이 카메라 원점에서 출발한다고 가정하면 안 됩니다. 잔차가 예를 들어 0.2 픽셀이라면 이는 해당 자료에 대한 재투영 오차의 요약값이지 0.2 mm의 측정 정확도가 아닙니다. 독립된 검증점과 실제 사용 영역에서 오차를 살펴 모델 선택의 타당성을 확인하세요.

사용 순서와 결과 확인

TelecentricFit은 적합된 텔레센트릭 camera 값과 입력 대응점의 재투영 RMS인 rms_pixels를 묶습니다. RMS는 픽셀 단위이므로 숫자에 물리 길이 단위를 붙여 장비의 절대 정확도로 해석하면 안 됩니다.

예를 들어 두 점의 재투영 거리 잔차가 0과 2픽셀이면 RMS는 √((0²+2²)/2)=√2픽셀입니다. 평균 1픽셀과 RMS는 다른 요약값이며 집계만으로 어느 점에서 큰 잔차가 발생했는지는 알 수 없습니다.

camera를 실제 측정에 사용할 때는 적합에 사용한 영상 좌표계, 영상 크기와 광학 구성이 현재 입력에 맞는지 확인하십시오. 학습에 사용하지 않은 대응점과 실제 작업 영역에서 예측을 별도로 평가해야 사용 범위를 판단할 수 있습니다.
