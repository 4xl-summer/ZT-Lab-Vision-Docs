inpaint_anisotropic

method · 선언 타입 zvision.ZImage

Python
inpaint_anisotropic(image, mask, options)

마스크된 픽셀에 이방성 확산을 적용합니다.

확인된 인자 조건

image: Gray8·Gray16·GrayF32 입력 영상.

mask: 같은 기하의 Gray8 마스크. 비제로가 복원 대상.

options: InpaintOptions의 반복·안정 시간 간격 및 종료 조건.

반환: 독립 GrayF64 영상과 InpaintReport 튜플; 영상은 close합니다.

오류: 닫힌 객체 또는 유효하지 않은 입력은 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Diffuse only nonzero mask pixels; returns an owned image and change report.

비등방성 복원

mask에서 0이 아닌 픽셀만 확산 방식으로 복원합니다. options의 iterations는 1 이상, timestep은 0보다 크고 0.25 이하, kappa는 양수, tolerance는 0 이상이어야 합니다. conductance 선택과 nearest_known도 결과에 영향을 줍니다.

반환은 새 소유 ZImage와 InpaintReport입니다. 보고서의 iterations, max_change, converged, stalled를 보고 계산이 끝난 상태를 해석합니다. 예를 들어 반복 한도에 도달한 결과를 무조건 수렴이라고 표시하지 않습니다. 출력 영상은 사용 후 close합니다.
