execute_preprocessing_pipeline

method · 선언 타입 zvision.ZImage

Python
execute_preprocessing_pipeline(image, stages)

활성화된 Gray8 양자화·중앙값·가우시안 단계를 순서대로 적용합니다.

확인된 인자 조건

image: 입력 ZImage

stages: 최대 64개 PipelineStage

반환: 별도 소유 영상과 PipelineReport입니다.

오류: 유효하지 않은 단계 또는 설정은 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • stages · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Apply enabled stages in order and return an owned image and report.

순서가 있는 전처리

활성화된 Gray8 양자화, 중앙값, 가우시안 단계를 지정된 순서로 적용합니다. 단계 순서가 바뀌면 한 단계의 입력이 달라져 결과도 달라질 수 있습니다. 활성 단계와 설정을 함께 저장해 같은 처리를 재현합니다.

보고와 제한

stages에는 최대 64개 PipelineStage를 지정합니다. 반환되는 독립 영상과 PipelineReport를 함께 확인하고 어느 단계가 실행되었는지 기록합니다. 지원하지 않는 입력이나 유효하지 않은 설정은 오류 조건을 따르며 반환 영상의 수명은 별도로 관리합니다.
