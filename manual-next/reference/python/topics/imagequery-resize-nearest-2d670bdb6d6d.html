resize_nearest(self, width, height)

최근접 크기 변경 단계를 현재 계획에 덧붙입니다.

확인된 인자 조건

width: 양의 출력 폭

height: 양의 출력 높이

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

최근접 표본의 재배치

출력 위치에 대응하는 가까운 입력 표본을 선택하는 크기 변경 단계를 추가합니다. 새로운 중간 색을 섞는 보간과 구분되며, 확대된 결과에서는 한 입력 표본이 여러 위치에 반복될 수 있습니다.

크기와 작은 구조

출력 폭과 높이를 호출 조건에 맞게 지정하고 실행 결과의 위치를 원본과 비교합니다. 축소 시 작은 물체가 사라질 수 있으며, 변환된 좌표를 원본과 비교할 때는 배율과 원점을 함께 관리해야 합니다.
