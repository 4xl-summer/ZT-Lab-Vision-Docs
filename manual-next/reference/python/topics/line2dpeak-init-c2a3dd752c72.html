python 공개 선언
Line2DPeak(position: zvision._regions.Point2, gradient: zvision._regions.Point2, intensity: float, projection_region: int, classification: zvision._line_candidates.LineCandidateClass, reason: zvision._line_candidates.LineCandidateReason, line_index: int | None) -> None

Extracted ROI-local observation and actual fitting stage outcome.

position: ROI 로컬 픽셀 좌표입니다.

gradient: 영상 강도/픽셀 단위의 기울기 벡터입니다.

intensity: 해당 투영에서의 평균 밝기입니다.

projection_region: 마스크 후에도 다시 번호를 매기지 않는 투영 띠 인덱스입니다.

classification: 적합 단계의 피크 분류입니다.

reason: 분류된 이유입니다.

line_index: 배정된 0부터 시작하는 선 번호 또는 None입니다.

이 호출의 입력과 객체 맥락

2차원 기울기 투영에서 추출된 피크 하나와 적합 단계 결과를 담습니다. position은 ROI 로컬 위치, gradient는 그 위치의 기울기 벡터이며 intensity는 보고된 강도입니다. projection_region은 피크를 만든 투영 스트립의 인덱스이므로 좌표나 픽셀 값과는 다른 식별 정보입니다.

classification과 reason을 이용해 적합에 사용된 내점, 고려 후 배정되지 않은 후보, 고려되지 않은 후보를 구별합니다. line_index가 None이면 어떤 선에도 연결되지 않은 것이며 0번 선을 의미하지 않습니다. 예를 들어 극성 조건에서 제외된 피크는 적합에서 거절된 피크와 동일한 경로를 거치지 않습니다.
