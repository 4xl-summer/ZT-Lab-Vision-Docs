python 공개 선언
JointCameraViewResult(board: tuple, rms_a: float, rms_b: float) -> None

Board pose A<-board and each camera's Euclidean reprojection RMS in pixels.

board: A←기준판 자세의 축각 3개와 이동 3개입니다.

rms_a: 카메라 A의 재투영 거리 RMS(픽셀)입니다.

rms_b: 카메라 B의 재투영 거리 RMS(픽셀)입니다.

이 호출의 입력과 객체 맥락

JointCameraViewResult는 공동 카메라 계산의 한 보드 관측에 대한 결과입니다. board는 보드에서 카메라 A로 가는 자세이고 rms_a와 rms_b는 각각 카메라 A와 B에서의 유클리드 재투영 RMS이며 픽셀 단위입니다. 두 카메라의 오차를 구분해 보면 어느 쪽 관측이나 모델을 먼저 점검할지 판단할 수 있습니다.

예를 들어 rms_a가 0.2 픽셀이고 rms_b가 1.0 픽셀이면 이 관측에서는 B의 재투영 오차가 더 큽니다. 이것만으로 특정 장치 고장을 증명할 수는 없으며 B의 점 대응, 렌즈 계수와 영상 좌표 원점을 확인해야 합니다. board의 회전과 이동은 픽셀 RMS와 다른 물리량입니다.

입력과 결과를 읽는 순서

한 보드 관측에 대한 결과로 board 자세와 카메라별 재투영 RMS를 담습니다. board는 A←board 방향의 축각 회전 세 값과 이동 세 값이며 rms_a, rms_b는 각각 카메라 A와 B에서의 유클리드 재투영 거리 RMS입니다. RMS의 단위는 픽셀입니다.

예를 들어 rms_a=0.2픽셀, rms_b=1.0픽셀이면 이 관측에서 B의 재투영 오차가 더 큽니다. 다만 그 차이만으로 원인을 렌즈, 대응점 또는 자세 중 하나로 단정할 수는 없습니다. 해당 뷰의 대응점과 각 카메라의 모델·좌표 기준을 함께 살펴야 합니다.

board의 회전은 축각 표현이고 이동 성분의 길이 단위는 공동 보정에 지정한 unit을 따릅니다. 픽셀 RMS와 자세 이동을 같은 단위로 비교하지 마세요. 여러 뷰를 판독할 때는 각 결과를 원래 보드 관측과 연결해 기록합니다.
