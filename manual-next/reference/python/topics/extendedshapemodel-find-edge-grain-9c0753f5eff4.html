find_edge_grain(self, source, options, min_size, max_size, mask=None)

검색 영상의 연결된 에지 크기 조건을 적용해 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 형상 검색 설정입니다.

min_size: 최소 에지 구성요소 크기입니다.

max_size: 최대 에지 구성요소 크기입니다.

mask: 선택 검색 마스크입니다.

반환: 독립 매치 결과와 종료 진단입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search source edge components in a size range.

호출 맥락과 결과 해석

검색 영상에서 연결된 에지 구성요소의 크기를 조건으로 삼아 형상 검색을 수행합니다. 학습 단계에서 특징을 거르는 train_grain과 달리 이 호출의 min_size와 max_size는 검색 영상의 에지 쪽에 적용됩니다.

작은 잡음과 긴 실제 경계가 섞인 영상이라면 최소 크기를 달리한 두 번의 결과를 비교해 볼 수 있습니다. 최대 크기까지 함께 좁히면 원하는 경계도 조건에서 제외될 수 있으므로 결과 목록과 종료 진단을 함께 살피고, 나머지 옵션은 동일하게 유지해 비교합니다.

max_size최대 에지 구성요소 크기입니다.
