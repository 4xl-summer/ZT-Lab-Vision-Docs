abs_diff(self, reference)

절대 차이 단계를 현재 계획에 덧붙입니다.

확인된 인자 조건

reference: 기준 ZImage

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

기준 영상과의 차이 단계

reference는 같은 위치의 값을 비교할 기준 ZImage입니다. 표본 10과 7의 절대 차이는 3이며 비교 순서가 바뀌어도 크기는 3입니다. 크기와 형식뿐 아니라 ROI가 같은 장면 위치를 가리키는지 확인해야 정렬 오차를 변화로 오인하지 않습니다.

계획의 실행

이 메서드는 변경된 동일 ImageQuery를 반환합니다. 단계가 추가된 뒤 실행 시 입력 메타데이터나 픽셀 검사가 실패할 수 있으므로 실행 결과를 확인합니다. 차이 영상은 원본 밝기가 아닌 변화 크기이며 기준 영상과 계획의 수명도 함께 관리합니다.
