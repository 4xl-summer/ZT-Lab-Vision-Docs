ShapeComponent(id: int, model: zvision._matching_advanced.AdvancedMatchModel, relative_position: zvision._regions.Point2, relative_angle: float, position_tolerance: float, angle_tolerance: float) -> None

Unique ID, shape model, root-local relative position/angle, and positional/angular tolerances.

id: 컴포넌트를 구분하는 고유한 u64 식별자입니다.

model: 컴포넌트의 형상 모델입니다.

relative_position: 루트 기준 로컬 상대 위치(픽셀)입니다.

relative_angle: 루트에 대한 상대 회전각(라디안)입니다.

position_tolerance: 예상 위치로부터 허용하는 거리(픽셀)입니다.

angle_tolerance: 예상 각도에 대한 허용 오차(라디안)입니다.

값을 구성하고 해석하기

루트 형상에 상대적인 한 컴포넌트 모델과 기하 제약을 지정합니다. id는 고유 식별자, model은 형상 모델이며 relative_position과 relative_angle은 루트 기준의 위치와 각도입니다. position_tolerance는 픽셀, angle_tolerance는 라디안 단위로 허용 오차를 정합니다.
