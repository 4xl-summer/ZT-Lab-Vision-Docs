classmethod · 선언 타입 zvision._classified_shape.ClassifiedShapeModel

Python
train(cls, template, classes, reference, sample_step=1, threshold=None)

care 에지와 별도 clutter 위치를 라벨 영상에서 학습합니다.

확인된 인자 조건

template: 학습할 회색 ZImage입니다.

classes: 0 무시, 1 care, 2 clutter를 지정하는 라벨 영상입니다.

reference: 템플릿 로컬 Point2 기준점입니다.

sample_step: 양의 표본 간격이며 기본값 1입니다.

threshold: 유한한 비음수 기울기 하한 또는 자동 선택 None입니다.

반환: 호출자가 닫아야 하는 ClassifiedShapeModel입니다.

오류: 영상·라벨·임계값 또는 특징점이 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • classes · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Train care edges and store independently labelled clutter sample locations.

클래스별 검색 해석

템플릿과 같은 크기의 Gray8 classes 영상을 사용해 0은 무시, 1은 care, 2는 clutter로 표시합니다. 두 영상의 원점은 (0, 0)이어야 합니다. care 에지로 형상을 만들고 clutter는 별도 위치 표본으로 저장합니다. 예를 들어 배경을 0, 필요한 윤곽을 1, 에지가 나타나지 않기를 바라는 영역을 2로 구분합니다. 학습 기준점은 템플릿 로컬 좌표입니다.
