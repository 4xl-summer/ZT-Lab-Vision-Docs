AdvancedFitResult(kind: int, parameters: tuple, residuals: tuple, inliers: tuple, rms: float, maximum: float, iterations: int, converged: bool, arc_radians: float, residual_stddev: float | None, confidence: tuple | None)

kind: 결과 형상: 1 선, 2 원.

parameters: 4개 값: 선은 점 x,y와 방향 x,y; 원은 중심 x,y, 반경, 0.0.

residuals: 입력 순서의 절대 기하 잔차 튜플.

inliers: 입력 순서의 채택 여부 튜플.

rms: 채택점 잔차 RMS.

maximum: 채택점 최대 잔차.

iterations: 재피팅 반복 수.

converged: 재피팅 수렴 여부.

arc_radians: 원 채택점 각 범위. 선 결과는 0.0.

residual_stddev: 계산 가능한 경우 자유도 보정 잔차 표준편차; 아니면 None.

confidence: 요청한 경우 추정치·표준오차·하한·상한의 튜플; 아니면 None.

이 호출의 입력과 객체 맥락

직선 또는 원 적합의 계수와 입력 순서별 잔차·채택 여부를 담습니다. kind=1의 parameters는 점 x/y와 방향 x/y이고 kind=2는 중심 x/y, 반경, 0입니다. residuals와 inliers를 같은 인덱스로 읽고 rms와 maximum은 채택점의 잔차로 해석합니다. residual_stddev와 confidence는 계산·요청 조건에 따라 None일 수 있으며 원의 각 범위 arc_radians는 라디안입니다.
