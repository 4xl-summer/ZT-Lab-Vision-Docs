point(self, row, column)

0부터 시작하는 행과 열을 (열×가로 간격, 행×세로 간격)의 물리 좌표로 변환합니다.

확인된 인자 조건

row: 0 이상 rows 미만의 정수입니다.

column: 0 이상 columns 미만의 정수입니다.

반환: 격자의 지정 길이 단위인 Point2 값입니다.

오류: 격자 크기, 인덱스 또는 간격이 유효하지 않으면 오류입니다.

인자 선언

  • row · POSITIONAL_OR_KEYWORD · 기본값 없음
  • column · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Return the physical point of a zero-based grid row and column.
