Match(position: zvision._regions.Point2, global_position: zvision._regions.Point2, angle: float, scale: float, score: float, sample_count: int)

position: 모델 기준점의 검색 ROI 로컬 좌표입니다.

global_position: 검색 영상의 원점을 로컬 기준점 위치에 더한 좌표입니다.

angle: 영상 좌표에서 양수가 시계 방향인 회전각(라디안)입니다.

scale: 검색된 등방 배율입니다.

score: 모델 종류에 따른 일치 점수이며 확률이 아닙니다.

sample_count: 모델에서 점수 계산에 사용하는 표본 수입니다.

값을 구성하고 해석하기

기본 매칭에서 채택된 한 자세의 값입니다. position은 검색 ROI에서 모델 기준점이 놓인 로컬 좌표이고 global_position은 검색 영상 원점을 더한 좌표입니다. 예를 들어 로컬이 (2,0.5), 원점이 (10,20)이면 전역 값은 (12,20.5)입니다. 둘 다 템플릿의 좌상단이 아니라 학습 모델의 중심을 뜻합니다.
