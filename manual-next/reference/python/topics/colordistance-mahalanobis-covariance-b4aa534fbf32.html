mahalanobis_covariance

classmethod · 선언 타입 zvision._naming_advanced_color.ColorDistance

Python
mahalanobis_covariance(cls, covariance)

공분산 행렬을 사용하는 마할라노비스 거리를 선택합니다.

확인된 인자 조건

covariance: 행 우선 3×3 공분산 계수 9개

반환: 불변 ColorDistance 설정입니다.

오류: 행렬 계수 개수가 맞지 않으면 오류입니다.

인자 선언

  • covariance · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

인자별 입력 조건

인자형식역할과 조건
covariance행 우선 3×3 공분산 계수 9개

공분산 거리 선택

covariance의 아홉 값을 3×3 공분산 행렬 입력으로 저장합니다. 역공분산을 받는 mahalanobis와 입력 의미가 다르며 아홉 값이 아니면 오류입니다.

행렬의 축 순서를 입력 Lab의 L, a, b에 맞추고 적절한 통계 표본에서 계산했는지 확인합니다. 행렬이 있다는 사실만으로 이후 거리 계산의 수치 유효성이나 검사 정확도가 보장되지는 않습니다.
