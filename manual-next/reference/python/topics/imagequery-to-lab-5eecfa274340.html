to_lab(self)

D50 CIELAB 색상 변환 계획을 만듭니다.

반환: 타입 지정 색상 Query입니다.

오류: 입력이나 계획이 유효하지 않으면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

D50 Lab로 변환

현재 계획의 색상 영상을 D50 기준 CIELAB 평면으로 변환합니다. L, a, b는 HSV의 색조·채도·명도와 다른 좌표이며 같은 숫자 범위로 비교할 수 없습니다. CIE76 거리에는 동일한 기준의 Lab 값이 필요합니다.

결과 사용

지원되는 인코딩과 부동소수 입력의 값 범위를 확인한 뒤 결과 평면을 읽습니다. 두 Lab 색의 차이가 (3,4,0)이면 CIE76 유클리드 거리는 5입니다. 평면과 실행 결과의 수명을 관리하고 실제 조명 보정은 별도로 검증합니다.

기준색과 비교

Lab 세 성분 차이가 (3,4,0)이면 CIE76 거리는 5입니다. D50 기준 평면을 다른 백색점의 값과 바로 비교하지 말고 입력 인코딩과 기준색을 맞춥니다. 각 평면의 소유권은 실행 결과 계약을 따릅니다.
