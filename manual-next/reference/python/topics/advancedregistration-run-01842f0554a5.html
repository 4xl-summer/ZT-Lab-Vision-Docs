run(cls, source, reference, options)

초기 변환 주변에서 영상 정합을 국소 최적화합니다.

확인된 인자 조건

source: 정합할 소스 영상입니다.

reference: 기준 영상입니다.

options: AdvancedRegistrationOptions입니다.

반환: 호출자가 닫아야 하는 AdvancedRegistration입니다. info.found로 결과 유무를 확인합니다.

오류: 유효하지 않은 영상, 변환 또는 예산 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

소스와 기준 영상 및 AdvancedRegistrationOptions를 받아 초기 변환 주변에서 지역 정합을 계산합니다. 결과의 info.found로 유효한 결과가 있는지 확인하고 행렬·점수·coverage를 함께 읽습니다. 기준 로컬에서 소스 로컬로 가는 변환 방향과 두 ROI 기준을 혼동하지 마세요. 반환 결과와 별도로 얻은 정렬 영상·마스크는 각각 close합니다.
