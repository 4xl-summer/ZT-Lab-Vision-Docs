계수에서 영상을 복원합니다.

반환: 입력 ROI 원점을 가진 독립 GrayF64 이미지이며 호출자가 닫습니다.

오류: 닫힌 모델 또는 비유한 복원 결과는 오류입니다.

Reconstruct a new GrayF64 image with the input ROI origin.

이 호출의 입력과 객체 맥락

모델 계수를 합성하여 입력 ROI 원점을 유지하는 GrayF64 영상을 반환합니다. 숫자 계수 배열과 달리 이 결과는 소유 ZImage이므로 사용 후 close합니다. 모델을 변경한 결과를 비교하려면 각 모델에서 별도 복원 영상을 얻고 같은 ROI 원점과 크기 기준으로 비교하세요. 모델 자체도 별도로 close해야 합니다.

계수에서 복원까지

StationaryDb2 모델의 현재 계수를 합성해 독립 GrayF64 영상을 반환합니다. 모델의 입력 ROI 원점이 복원 영상에 유지되므로 같은 좌표계에서 원본이나 다른 계수로 만든 결과와 비교할 수 있습니다. 계수를 수정한 모델을 별도로 만들었다면 각 모델에서 inverse를 호출해 결과를 얻습니다.

복원 영상은 모델의 숫자 배열이 아니라 별도 소유 ZImage입니다. 영상과 모델을 각각 close해야 합니다. 모델이 닫혔거나 복원 결과가 비유한 경우에는 오류가 발생합니다. 비교 시 크기와 ROI 원점, 픽셀 형식을 함께 확인하고 부동소수 계산 오차를 고려하십시오.
