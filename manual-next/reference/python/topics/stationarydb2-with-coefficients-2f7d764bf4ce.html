Python
with_coefficients(self, values)

외부 계수의 스냅샷을 가진 새 모델을 만듭니다.

확인된 인자 조건

values: 기존 밴드 총 원소 수와 같은 유한 수 반복값입니다.

반환: 호출자가 닫아야 하는 새 모델입니다.

오류: 개수 불일치, 비유한 값 또는 닫힌 모델은 오류입니다.

인자 선언

  • values · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Return a new model containing a snapshot of external coefficients.

이 호출의 입력과 객체 맥락

외부의 유한 계수 배열을 복사해 독립 모델을 만듭니다. 배열은 원 모델이 요구하는 전체 크기와 순서에 맞아야 합니다. 예를 들어 coefficients로 복사한 값을 수정한 뒤 이 메서드에 주면 원본과 별도의 모델을 갖게 됩니다. 새 모델을 inverse로 확인하고, 원본 모델·새 모델·반환 영상의 수명은 각각 관리합니다.
