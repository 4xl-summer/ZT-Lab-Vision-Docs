learn(cls, image, path, options, include=None)

경로 앵커와 설정을 사용해 기준 비드를 학습합니다.

확인된 인자 조건

image: 학습 ZImage

path: 2개 이상 좌표 쌍의 경로

options: BeadReferenceOptions

include: 앵커마다 bool인 선택 시퀀스; 기본값 None

반환: 별도로 close할 BeadReference입니다.

오류: 입력, 경로 또는 선택 길이가 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • path · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • include · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

경로 기준 학습

학습 영상과 순서가 있는 ROI 로컬 경로, 탐침 옵션 및 선택적 포함 여부로 비드 기준을 만듭니다. 경로점의 순서를 바꾸면 따라가는 경로가 달라지므로 입력 순서를 보존합니다.

학습 영상에서 비드가 실제 있는 위치와 점을 겹쳐 확인하고 로컬 원점을 기록합니다. 반환 모델은 소유 객체이며 사용 후 close합니다. 모델을 얻었다는 사실만으로 실제 불량에 대한 검출 성능을 보장하지 않습니다.
