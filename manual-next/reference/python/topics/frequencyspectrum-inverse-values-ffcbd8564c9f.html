FrequencySpectrum.inverse_values 공개 계약

inverse_values

method · 선언 타입 zvision._frequency_processing.FrequencySpectrum

Python
inverse_values(self, crop=True)

스펙트럼의 실수 역변환을 계산합니다.

확인된 인자 조건

crop: bool; True면 원본 크기로 자름, 기본값 True

반환: (폭, 높이, 독립 값 튜플)입니다.

오류: crop이 bool이 아니거나 계산이 실패하면 오류입니다.

인자 선언

  • crop · POSITIONAL_OR_KEYWORD · 기본값 True

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

별칭과 결과 해석

Spectrum은 FrequencySpectrum과 같은 클래스입니다. inverse_values와 inverse는 같은 함수이며 crop=True는 원본 크기, False는 스펙트럼 크기를 사용합니다. 결과는 폭, 높이, 독립 실수 값 튜플이며 영상 핸들이 아닙니다. crop은 bool이어야 하고 스펙트럼 객체는 별도로 close합니다.

실수 값으로 복원

역변환의 실수 결과를 독립 값 튜플과 폭, 높이로 얻습니다. crop은 bool이며 기본 True는 원본 입력 크기로 잘라냅니다. 스펙트럼 격자가 패딩으로 더 컸다면 크기를 확인한 뒤 행 단위로 값을 읽어야 합니다.

결과 해석

정변환에 사용한 정규화와 대응되는 역변환을 사용합니다. 2×2의 모든 입력이 1인 예에서는 올바른 왕복에서 각 값이 1에 가까워야 합니다. 표시된 진폭 값만을 완전한 복소 스펙트럼으로 취급하지 않습니다.
