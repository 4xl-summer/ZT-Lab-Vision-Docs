gaussian_with_output_selector(self, mask, selector, selector_x, selector_y, options)

별도의 care 마스크를 사용하고 출력 선택 영역에 가우시안을 적용합니다.

확인된 인자 조건

mask: care 마스크

selector: 출력 선택 마스크

selector_x: 선택 마스크 x 오프셋

selector_y: 선택 마스크 y 오프셋

options: 가우시안 옵션

반환: 별도로 close할 결과입니다.

오류: 입력과 설정이 유효하지 않으면 오류입니다.

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • selector · POSITIONAL_OR_KEYWORD · 기본값 없음
  • selector_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • selector_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

Filter selected output pixels using the separate care mask.

출력 선택과 필터

가우시안 평활화는 이웃 픽셀의 가중 평균을 계산하며 출력 선택자는 결과에 적용할 선택 조건을 나타냅니다. 커널과 선택 조건을 함께 기록해야 동일한 입력의 출력 범위를 재현할 수 있습니다.

결과를 읽는 순서

영상, 필터 설정과 선택자에 요구되는 형식·크기를 확인한 뒤 호출합니다. 선택 경계 주변에서 원본 및 결과를 나란히 확인하고 선택되지 않은 위치의 값은 해당 API 계약에 맞추어 해석합니다. 출력 영상은 입력과 별도로 관리합니다.
