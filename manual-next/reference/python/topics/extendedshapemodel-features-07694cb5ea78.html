features(self)

학습된 형상 특징점을 복사합니다.

반환: 기준점 상대 로컬 좌표와 방향인 (x, y, nx, ny) 튜플들의 독립 튜플입니다. 원래 contour 연결은 포함하지 않습니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

Return independent feature tuples.

호출 맥락과 결과 해석

학습 결과가 어떤 형상 표본을 보유하는지 확인할 때 사용합니다. 각 항목은 기준점 상대 로컬 위치 x, y와 방향 nx, ny를 담으며, 반환된 전체 튜플도 모델과 독립된 값입니다. 학습 템플릿의 원점이나 검색 영상의 전역 좌표로 바로 표시하지 않도록 주의합니다.

이 목록은 방향을 가진 표본 모음이지 원래 입력 contour의 연결 관계가 아닙니다. 예를 들어 이웃한 두 항목을 임의로 선분으로 연결해 원래 경계를 복원하는 용도로 쓰면 안 됩니다. 모형의 기준점을 바꾸어 학습했다면 로컬 좌표의 해석도 그 기준점을 따라 달라집니다.

반환값 확인

기준점 상대 로컬 좌표와 방향인 (x, y, nx, ny) 튜플들의 독립 튜플입니다. 원래 contour 연결은 포함하지 않습니다.
