execute(self) -> 'QueryExecution[SurfaceDefectsResult]'

반환 타입 주석: QueryExecution[SurfaceDefectsResult]

Execute and return an immutable defect snapshot.

실행과 결과 판독

지연 표면 결함 계획을 실행해 불변 결함 스냅샷이 담긴 QueryExecution을 얻습니다. 결함 후보의 종류와 면적은 실행 후 읽을 수 있으며 계획을 만드는 단계와 실제 실행은 구별해야 합니다. 후보가 없다는 결과와 실행 자체의 오류를 같게 기록하지 마십시오. 소유 실행은 사용이 끝난 뒤 닫고, 반환 스냅샷의 정보를 원래 프레임과 ROI 기준에 연결해 보관합니다.

단계확인할 내용
입력준비된 표면 결함 쿼리 계획을 실행합니다.
반환QueryExecution의 불변 결함 스냅샷입니다.
판독결함 후보와 실행 오류를 구분합니다.
수명소유 실행을 사용 후 닫습니다.
