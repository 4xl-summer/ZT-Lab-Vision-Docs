RecognitionPoint(local: zvision._regions.Point2, global_: zvision._regions.Point2) -> None

RecognitionPoint(local: zvision._regions.Point2, global_: zvision._regions.Point2)

local: 현재 입력 이미지의 로컬 픽셀 좌표입니다.

global_: 로컬 좌표에 입력 이미지 원점을 더한 전역 픽셀 좌표입니다.

인자별 입력 조건

인자형식역할과 조건
local<class 'zvision._regions.Point2'>현재 입력 이미지의 로컬 픽셀 좌표입니다.
global_<class 'zvision._regions.Point2'>로컬 좌표에 입력 이미지 원점을 더한 전역 픽셀 좌표입니다.

두 좌표계의 대응

local과 global_은 모두 Point2입니다. ROI 원점이 (100, 50)이고 로컬 점이 (4, 3)인 단순 이동 예에서는 전역 점이 (104, 53)입니다.

원본 화면에 그릴 때 전역 좌표에 원점을 다시 더하지 않습니다. 바코드 위치나 OCR 모서리와 함께 이 두 좌표를 사용하며, 두 인자가 Point2가 아니면 TypeError입니다.

좌표사용 기준
local입력 영상 또는 ROI
global_전체 프레임
표시같은 프레임에 매핑
