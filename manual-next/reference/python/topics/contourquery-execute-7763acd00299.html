execute

method · 선언 타입 zvision._query.ContourQuery

Python
execute(self) -> 'QueryExecution[ContourResult]'

종료 계획을 실행해 타입 지정 결과를 얻습니다.

반환: close할 실행 객체와 독립 값 스냅샷입니다.

오류: 연산이 실패하면 오류입니다.

반환 타입 주석: QueryExecution[ContourResult]

Execute and return contours with immutable point sequences.

윤곽 계획 실행

계획을 실행해 QueryExecution[ContourResult]를 얻습니다. 결과에는 불변 점 시퀀스의 윤곽이 들어 있으며 실행 객체는 close해야 합니다. 전경 마스크와 ROI가 어떤 경계를 생성하는지 결정합니다.

점의 순서

윤곽 점의 순서를 보존해 길이나 경계를 표시합니다. 고리의 외곽과 구멍을 구분하고 ROI 로컬 위치를 원본에 표시할 때 원점을 맞춥니다. 점 수를 전경 면적으로 해석하지 않습니다.
