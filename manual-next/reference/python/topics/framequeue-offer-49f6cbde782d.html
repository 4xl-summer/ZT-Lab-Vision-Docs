FrameQueue.offer 공개 계약

offer

method · 선언 타입 zvision._frame_queue.FrameQueue

Python
offer(self, image, timeout_ms)

독립 이미지 큐에 이미지를 제출하고 큐 정책에 따른 처리 상태를 돌려줍니다.

확인된 인자 조건

image: 제출할 ZImage입니다.

timeout_ms: 대기 정책의 최대 대기 시간으로 밀리초 단위 음이 아닌 정수입니다.

반환: FrameQueueOffer 상태 값입니다.

오류: 닫힌 핸들이나 유효하지 않은 입력은 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • timeout_ms · POSITIONAL_OR_KEYWORD · 기본값 없음

timeout_ms: 정수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

ZImage를 큐에 넣고 처리 상태를 반환합니다. timeout_ms는 밀리초이며 0이면 즉시 검사합니다. 큐가 가득 찼을 때 결과는 생성 시 선택한 REJECT_NEW, DROP_OLDEST 또는 WAIT 정책에 따라 달라집니다. ADDED와 DROPPED_OLDEST, FULL, TIMED_OUT, CLOSED를 구분해 처리하세요. 큐에 들어간 영상은 별도 핸들로 관리되므로 입력 영상 핸들의 수명과 구분합니다.
