AnnulusSearchOptions(tolerance: float, max_nodes: int, max_work: int) -> None

Absolute optimality gap tolerance and finite node/distance-work budgets.

tolerance: 최적성 간격에 대한 유한 양수 허용값이며 입력 좌표 단위입니다.

max_nodes: 탐색 셀 수 상한으로 1–100,000입니다.

max_work: 점과 중심 사이 거리 평가의 상한이며 점 개수 이상이고 최대 10,000,000입니다.

이 호출의 입력과 객체 맥락

AnnulusSearchOptions는 최소 원환 검색의 절대 최적성 간격 허용치와 계산량 제한을 지정합니다. tolerance는 점 좌표와 같은 길이 단위이고 max_nodes와 max_work는 각각 검색 노드 및 거리 계산 작업의 유한한 한계입니다. 이 조건은 원환의 반지름 자체가 아니라 검색을 언제 멈출지와 관련됩니다.

예를 들어 좌표를 mm로 표현하면 tolerance 0.01은 0.01 mm의 절대 간격으로 해석합니다. 동일한 물리 크기를 미터로 표현할 때 숫자를 그대로 0.01로 두면 허용 간격이 달라집니다. 더 작은 허용치를 주더라도 노드나 작업 한도에 먼저 도달할 수 있으므로 결과 status와 optimality_gap을 함께 확인하세요.

입력과 결과를 읽는 순서

최소 원환 탐색에서 절대 최적성 간격 tolerance와 두 작업 한도를 지정합니다. tolerance는 입력 점 좌표와 같은 길이 단위의 유한 양수입니다. max_nodes는 탐색 셀 개수, max_work는 점과 중심 사이 거리 평가 횟수의 상한이므로 서로 다른 자원입니다.

max_nodes는 1~100000이고 max_work는 입력 점 개수 이상이면서 최대 10000000입니다. 예를 들어 입력 좌표를 mm로 쓴다면 tolerance=0.01은 0.01mm입니다. 좌표를 m로 바꿀 때 같은 물리 한계를 원하면 허용치도 그 단위로 변환해야 합니다.

더 작은 tolerance를 지정하더라도 유한한 셀·거리 예산이 먼저 소진될 수 있습니다. 결과의 status와 optimality_gap을 함께 확인해 허용 간격에 도달한 종료와 예산 소진을 구분하세요. tolerance는 원환 자체의 반경이나 판독된 실제 오차가 아닙니다.
