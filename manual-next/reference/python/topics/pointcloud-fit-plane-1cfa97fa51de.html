PYTHON API · PointCloud.fit_plane

PointCloud.fit_plane 공개 계약과 사용

상위 목차로 돌아가기

점군의 평면 적합

PointCloud.fit_plane(threshold)은 점군에 평면을 적합하고 평면 계수와 지지점 통계를 값 스냅샷인 PlaneFit으로 반환합니다. 평면은 단위 법선 n과 절편 offset을 사용해 n·p + offset = 0으로 나타냅니다. 입력 점군의 길이 단위와 frame을 먼저 확인해야 하며, threshold는 그 점군의 길이 단위로 해석되는 양의 거리입니다.

평면까지 거리가 threshold 이하인 유효점을 inlier로 분류합니다. 반환 필드 inliers는 선택된 점의 수, total은 전체 유효점 수입니다. rms_error와 max_error는 최종 inlier의 거리 잔차를 요약합니다. 결측 슬롯은 유효점 수에 더해지지 않으므로 원래 슬롯 수와 total이 다를 수 있습니다.

기본 방법은 제한된 수의 삼점 가설을 만들고 TLS 적합과 점 분류를 반복해 정제합니다. 데이터가 부족하거나 점이 공선인 경우, 또는 정제가 실패한 경우에는 오류가 발생합니다. 제한된 가설과 관측 형태에 따라 전역 최적이나 모든 이상치에 대한 성공을 보장하지 않으므로 잔차와 inlier 비율을 함께 확인해야 합니다.

결과 판독

다음은 이미 만든 점군에서 적합을 요청하는 호출 단편입니다. 0.2는 점군에 설정한 길이 단위를 따르는 예시이며 보편적인 공차가 아닙니다. 실제 기준물과 측정 불확도에 맞춰 호출자가 임계값을 정해야 합니다.

Python
fit = cloud.fit_plane(threshold=0.2)
print(fit.normal, fit.offset, fit.inliers, fit.total, fit.rms_error)

예를 들어 inliers가 total보다 훨씬 작으면 잔차가 작더라도 선택된 일부 점만 설명할 수 있습니다. 반대로 지지점이 많아도 최대 잔차가 목적 공차를 넘는지 확인해야 합니다. 반환된 PlaneFit은 복사된 값이며 점군 핸들과 별개지만, 점군 객체 자체는 사용 후 close() 또는 컨텍스트 관리자로 해제합니다.
