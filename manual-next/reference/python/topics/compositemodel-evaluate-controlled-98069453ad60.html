evaluate_controlled(self, image: zvision.ZImage | None = None, unit: zvision._composite_metrology.CompositeUnit | None = None, cancellation=None, timeout_ms: int = 0) -> zvision._composite_metrology.CompositeResult

취소와 시간제한을 적용해 완성된 결과만 반환합니다.

확인된 인자 조건

image: ZImage 또는 None.

unit: CompositeUnit 또는 None.

cancellation: PhotometricCancellation 또는 None.

timeout_ms: 시간제한 밀리초; 기본 0.

반환: 독립 CompositeResult.

오류: 취소 시 PhotometricCancelledError, 시간초과 시 TimeoutError.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 타입 zvision.ZImage | None · 기본값 None
  • unit · POSITIONAL_OR_KEYWORD · 타입 zvision._composite_metrology.CompositeUnit | None · 기본값 None
  • cancellation · POSITIONAL_OR_KEYWORD · 기본값 None
  • timeout_ms · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 0

반환 타입 주석: <class 'zvision._composite_metrology.CompositeResult'>

래퍼에서 발생 가능한 오류: RuntimeError, TypeError. 네이티브 오류는 별도입니다.

취소 및 시간 제한을 적용하고 완성된 스냅샷만 반환한다.

이 호출의 입력과 객체 맥락

저장된 복합 계측 그래프를 평가해 모델과 독립된 CompositeResult 스냅샷을 반환합니다. 입력 형상의 좌표는 ROI 로컬 픽셀이고 출력의 등방 단위와 탐침 진단의 픽셀 단위는 구분해야 합니다. 결과에서 형상과 공차 판정을 확인하세요. 영상 측정 형상에는 전달한 ROI 영상이 필요합니다. 명시 unit은 결과 형상과 공차에 적용합니다. 제한 시간은 밀리초이며 0은 제한 없음입니다. 취소 또는 시간 초과는 오류이고 부분 결과를 반환하지 않습니다.
