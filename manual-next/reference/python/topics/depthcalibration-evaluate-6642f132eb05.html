evaluate(self, raw, reference)

보정 높이 − 기준 높이의 잔차 통계를 구합니다.

확인된 인자 조건

raw: 유한 원시 높이 시퀀스

reference: raw와 같은 수의 유한 기준 높이

반환: DepthCalibrationMetrics 값 스냅샷입니다.

오류: 배열이 비거나 길이가 다르거나 수치·보정이 유효하지 않으면 오류입니다.

인자 선언

  • raw · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

선형 깊이 보정 평가

원시값에 현재 모델을 적용한 뒤 같은 위치의 기준값을 빼서 잔차를 계산합니다. 두 배열은 같은 순서의 대응이어야 하며 비어 있지 않고 길이가 같아야 합니다. 평가 결과는 모델을 다시 학습하지 않고 현재 계수가 기준에 얼마나 맞는지 보여 줍니다.

원시값 0, 1, 2에 scale 2와 offset 1을 적용하면 1, 3, 5입니다. 기준이 이와 같으면 모든 잔차와 RMS가 0입니다. 기준이 하나 달라지면 평균 편향과 최대 오차가 서로 다르게 나타날 수 있으므로 샘플 수와 함께 살펴봅니다.
