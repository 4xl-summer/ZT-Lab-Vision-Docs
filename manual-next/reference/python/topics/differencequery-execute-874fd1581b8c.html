execute(self) -> 'QueryResourceExecution[DifferenceResult]'

지연 검사 계획을 실행합니다.

반환: QueryResourceExecution; acquire_output으로 얻은 DifferenceResult와 실행을 각각 닫습니다.

오류: 닫힌 계획 또는 네이티브 실행 실패 시 오류입니다.

반환 타입 주석: QueryResourceExecution[DifferenceResult]

Execute; acquire_output returns an independently owned difference.

이 호출의 입력과 객체 맥락

지연 차분 계획을 실행해 QueryResourceExecution을 반환합니다. 열린 실행에서 acquire_output으로 DifferenceResult를 별도 소유 핸들로 얻어 차분 정보와 마스크를 확인합니다. 실행을 닫는 것과 취득한 DifferenceResult를 닫는 것은 별도이므로 둘 다 close합니다. 결과에서 따로 얻은 영상도 해당 영상의 소유권을 관리하세요.

사용 흐름과 결과 판독

DifferenceQuery는 설정된 차분 검사 계획을 execute에서 실제로 실행하고 QueryResourceExecution을 반환합니다. 실행 자체가 DifferenceResult를 직접 반환하는 것은 아닙니다. 열린 실행에서 acquire_output을 호출하면 결과를 독립 소유 핸들로 얻을 수 있고, 실행과 획득한 결과는 각각 close해야 합니다.

차분 결과에서 정보와 마스크 또는 결과 영상을 읽을 때는 기준 영상과 검사 영상의 위치와 ROI 원점이 맞는지 먼저 확인합니다. 예를 들어 정렬되지 않은 두 영상의 경계가 어긋나면 물체가 실제로 변하지 않았어도 차분이 나타날 수 있습니다. 선택된 검사 조건과 결과의 상태를 같이 보존해야 차분값의 의미를 재현할 수 있습니다.

사용 순서는 계획 실행, 실행에서 결과 획득, 필요한 정보와 영상 획득, 각 소유 객체 해제입니다. 이미 획득한 결과와 별도 영상의 수명은 실행 핸들과 구분합니다. 닫힌 계획이나 네이티브 실행 실패는 오류이며 빈 차분 또는 정상적인 차분값 0으로 치환하지 않습니다.
