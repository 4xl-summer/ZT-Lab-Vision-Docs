고급 선택 계획 생성

열린 BlobResult를 source로 받아 AdvancedBlobQuery를 만듭니다. 이 단계는 선택 계획을 준비하는 것이며 조건에 맞는 결과 인덱스를 아직 확정하는 실행과 구분합니다. 잘못된 타입이나 닫힌 핸들은 오류입니다.

수명과 후속 호출

반환 쿼리는 별도 소유 객체로 사용 후 close합니다. where로 조건을 만들고 run으로 원래 BlobResult의 인덱스 목록을 얻습니다. source의 각 성분은 입력 결과에 속하므로 목록을 다른 결과에 적용하지 않습니다.
