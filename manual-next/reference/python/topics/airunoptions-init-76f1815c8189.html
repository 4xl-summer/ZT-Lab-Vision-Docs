AiRunOptions(score_threshold: float = 0.5, iou_threshold: float = 0.5, max_detections: int = 100) -> None

Thresholds in [0, 1] and maximum retained detection count.

score_threshold: 점수 임계값으로 유한한 [0, 1]이며 기본 0.5입니다.

iou_threshold: 중복 억제 IoU 임계값으로 유한한 [0, 1]이며 기본 0.5입니다.

max_detections: 보존할 최대 검출 수로 1–4096이며 기본 100입니다.

인자별 입력 조건

인자형식역할과 조건
score_threshold<class 'float'>점수 임계값으로 유한한 [0, 1]이며 기본 0.5입니다.
iou_threshold<class 'float'>중복 억제 IoU 임계값으로 유한한 [0, 1]이며 기본 0.5입니다.
max_detections<class 'int'>보존할 최대 검출 수로 1–4096이며 기본 100입니다.

추론 후처리 조건

score_threshold와 iou_threshold는 0부터 1까지이고 max_detections는 남길 검출 수 상한입니다. 점수와 중복 정도는 서로 다른 기준입니다.

예를 들어 낮은 점수 상자를 제외해도 겹치는 상자의 정리는 IoU 조건에 따릅니다. 모델과 전처리, 두 한도를 같이 기록해야 결과 개수의 변화를 해석할 수 있습니다.
