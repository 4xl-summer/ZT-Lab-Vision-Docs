ImageQuery.erode 공개 계약

상위 목차로 돌아가기

erode

method · 선언 타입 zvision._query.ImageQuery

Python
erode(self, kernel, op=14)

이진 침식 단계를 가변 계획에 추가합니다.

확인된 인자 조건

kernel: 양의 홀수 정사각형 커널 폭

op: 기본값 14은 이 메서드에 연결된 ABI 연산 코드입니다. 다른 값을 전달하면 그 코드가 네이티브 Query에 전달되어 동작이 달라지거나 오류가 날 수 있습니다. 이 인자는 보통 기본값으로 둡니다.

반환: 수정된 동일 ImageQuery입니다.

오류: 유효하지 않은 커널 또는 실행 오류가 보고될 수 있습니다.

인자 선언

  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • op · POSITIONAL_OR_KEYWORD · 기본값 14

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

계획의 이진 침식

침식 단계는 커널이 요구하는 전경 이웃을 기준으로 영역을 줄입니다. 좁은 다리가 끊기거나 작은 객체가 사라질 수 있으므로 후속 블롭 개수가 입력보다 많아지거나 적어질 수 있습니다. 커널의 양의 홀수 폭을 확인합니다.

실행과 원인 분리

계획 구성 후 실행해 원본과 침식 결과의 같은 위치를 비교합니다. 작은 객체가 사라졌다면 커널이 그 객체 안에 어떻게 놓이는지 살펴봅니다. op 기본 코드는 해당 연산에 연결된 값이므로 특별한 목적 없이 바꾸지 않습니다.
