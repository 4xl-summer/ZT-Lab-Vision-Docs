find_masked_pyramid

method · 선언 타입 zvision._extended_matching.ExtendedMatchModel

Python
find_masked_pyramid(self, source, options, mask, *, first_level, last_level=0, max_work=100000000)

검색 마스크를 사용하여 실제 축소 영상 피라미드를 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 검색 설정입니다.

mask: 필수 검색 마스크입니다.

first_level: 시작 수준 0..10입니다.

last_level: 마지막 수준 0..10이며 기본값 0입니다.

max_work: 허용 작업 상한으로 1..100000000이며 기본값은 100000000입니다.

반환: 독립 검색 결과와 종료 진단입니다.

오류: 유효하지 않은 입력, 모델 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first_level · KEYWORD_ONLY · 기본값 없음
  • last_level · KEYWORD_ONLY · 기본값 0
  • max_work · KEYWORD_ONLY · 기본값 100000000

Search a masked image pyramid with explicit work bounds.

호출 맥락과 결과 해석

검색 마스크를 사용해 실제로 축소된 영상 피라미드를 검색합니다. mask는 이 호출의 필수 입력이며 first_level과 last_level은 각각 0에서 10 사이입니다. 선택된 수준만큼 작업이 수행되므로 마스크 적용과 수준 선택을 함께 기록합니다.

max_work는 1부터 100000000까지의 작업 상한이고 기본값은 100000000입니다. 결과가 없거나 예상보다 적을 때 매치 목록뿐 아니라 종료 진단을 확인해 검색 범위, 마스크 및 작업 한도를 함께 검토합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options확장 검색 설정입니다.
mask필수 검색 마스크입니다.
first_level시작 수준 0..10입니다.
last_level마지막 수준 0..10이며 기본값 0입니다.
max_work허용 작업 상한으로 1..100000000이며 기본값은 100000000입니다.
