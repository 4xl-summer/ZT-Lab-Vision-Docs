GlcmOptions(levels: int, minimum: float, maximum: float, offset_x: int, offset_y: int, symmetric: bool, max_pairs: int)

levels: 양자화 단계 수로 2–256입니다.

minimum: 유한한 밝기 구간 하한이며 maximum보다 작아야 합니다.

maximum: 유한한 밝기 구간 상한이며 minimum보다 커야 하고 구간 폭도 유한해야 합니다.

offset_x: 두 픽셀 사이 수평 오프셋(정수 픽셀)입니다. 두 오프셋이 모두 0일 수 없습니다.

offset_y: 두 픽셀 사이 수직 오프셋(정수 픽셀)입니다. 두 오프셋이 모두 0일 수 없습니다.

symmetric: 역방향 쌍을 함께 반영할지 정하는 bool입니다.

max_pairs: 처리할 쌍의 양의 상한입니다.

이 호출의 입력과 객체 맥락

밝기 동시발생 행렬의 양자화 levels, 밝기 구간과 두 픽셀 사이 정수 오프셋을 정합니다. levels는 2~256이고 minimum은 maximum보다 작아야 합니다. 예를 들어 offset_x=1, offset_y=0은 가로 방향으로 한 픽셀 떨어진 쌍을 선택합니다. 두 오프셋은 동시에 0일 수 없습니다. symmetric은 역방향 쌍 포함 여부, max_pairs는 처리 쌍의 양의 상한입니다.
