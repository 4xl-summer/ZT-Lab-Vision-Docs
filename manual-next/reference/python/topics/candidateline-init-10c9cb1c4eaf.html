python 공개 선언
CandidateLine(point: zvision._regions.Point2, direction: zvision._regions.Point2, inliers: int, rms: float, maximum: float, converged: bool, iterations: int) -> None

Fitted infinite line, error statistics and refit convergence.

point: 피팅된 무한 직선 위의 점이며 ROI 로컬 좌표입니다.

direction: 피팅된 직선의 방향 벡터입니다.

inliers: 해당 직선에 채택된 후보 수입니다.

rms: 채택점 잔차의 RMS입니다.

maximum: 채택점 잔차의 최대값입니다.

converged: 재피팅 수렴 여부입니다.

iterations: 실행한 재피팅 반복 횟수입니다.

이 호출의 입력과 객체 맥락

검출된 후보를 이용해 적합한 하나의 무한 직선을 나타냅니다. point는 선 위의 점, direction은 선의 방향이며 두 값은 결과 영상의 ROI 로컬 좌표에서 해석합니다. 이 표현에는 별도의 유한 선분 끝점이 없으므로 화면의 한 구간 길이를 바로 읽는 용도로 사용하지 마십시오.

inliers는 해당 선 적합에 사용된 내점 수이고 rms와 maximum은 잔차 요약입니다. 예를 들어 내점 수가 충분해도 최대 잔차가 RMS보다 매우 크면 일부 점이 선에서 더 멀리 떨어졌을 수 있으므로 두 값을 함께 살펴볼 수 있습니다. converged와 iterations는 재적합 과정의 상태를 설명하며 단독으로 제품 합격을 보장하지 않습니다.
