PYTHON API · ZImage.ssim

ZImage.ssim 공개 계약과 사용

상위 목차로 돌아가기

ssim

method · 선언 타입 zvision.ZImage

Python
ssim(self, reference, options, mask=None)

기준 영상과 이 영상을 국소 SSIM으로 비교합니다.

확인된 인자 조건

reference
입력과 형식·크기·원점이 같은 Gray8, Gray16 또는 GrayF32 기준 영상.
options
SsimOptions 창, 점수와 작업량 조건.
mask
선택적 동일 기하의 Gray8 가중 마스크; 0은 제외.

반환: 호출자가 close할 SsimResult 소유 객체.

오류: 잘못된 형식·기하·옵션 또는 작업 한도 위반은 오류입니다.

인자 선언

  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Inspect this image against reference; return an owned SSIM result.

비교 전제와 결과 판독

이 호출에서 현재 영상은 검사 대상이고 reference는 비교 기준입니다. 두 영상은 크기와 원점, 픽셀 형식이 일치하는 Gray8·Gray16·GrayF32여야 합니다. 선택 마스크는 같은 크기와 원점의 Gray8 영상이며 0인 위치는 검사에서 제외됩니다. 비어 있는 유효 영역을 정상 점수로 해석하지 않습니다.

반경이 1이면 창의 한 변은 3입니다. 유효 중심이 16개인 예에서는 작업량 상한을 검사할 때 16 × 3 × 3 = 144의 방문 예산이 필요합니다. 경계 처리를 CLIP으로 선택해 실제로 살펴보는 표본이 줄더라도 상한 검사에 쓰이는 창 크기와 실제 유효 이웃 수는 구별해야 합니다. BOX 가중을 사용한다면 sigma는 1이어야 합니다.

결과 score는 포함된 중심의 마스크 가중 평균이고 defect_count는 조건을 만족한 결함 중심 수입니다. 국소 점수 맵의 한 지점만 보고 전체 평균이 같을 것이라고 가정하지 않습니다. 점수가 min_score보다 낮은지와 밝기 극성 조건을 함께 검사하므로, 기준보다 밝은 차이만 선택한 설정과 양쪽 차이를 선택한 설정의 결함 마스크는 다를 수 있습니다.

호출 단편과 수명

이미 열린 기준·검사 영상과 검증한 SsimOptions를 사용한 호출 단편입니다. result는 소유 객체이므로 with 블록으로 닫습니다. map 또는 defect_mask를 별도로 취득한다면 반환된 영상 공유도 각각 닫아야 합니다.

Python
with sample.ssim(reference, options, mask=None) as result:
    score = result.score
    defects = result.defect_count
