execute(self) -> 'QueryExecution[MomentsResult]'

계획을 실행해 영역 모멘트 스냅샷과 캡처를 제공합니다.

반환: 닫아야 하는 형식 지정 실행 객체입니다. 얻은 값 스냅샷은 실행을 닫은 뒤에도 유효합니다.

오류: 닫힌 계획 또는 실행 오류가 발생하면 예외가 발생합니다.

반환 타입 주석: QueryExecution[MomentsResult]

Execute and return immutable moments with captures.

이 호출의 입력과 객체 맥락

지연된 영역 계획을 실행해 모멘트 결과와 캡처를 갖는 QueryExecution을 반환합니다. 열린 실행의 output에서 MomentsResult 불변 스냅샷을 얻고, 필요한 캡처는 get_image로 별도 취득합니다. 실행을 닫은 후에도 미리 얻은 값 스냅샷은 유효합니다. 실행과 별도로 취득한 ZImage는 각각 close하세요.

입력과 결과 확인

MomentsQuery.execute는 계획된 영역 모멘트를 계산해 QueryExecution<MomentsResult>를 반환합니다. 실행의 output에서 얻은 값은 불변 스냅샷이며 실행을 닫은 뒤에도 유지됩니다. 실제 연산 오류나 닫힌 계획 오류를 정상적인 모멘트 0으로 바꾸지 마십시오.

모멘트의 의미는 어떤 영역과 좌표 기준을 사용했는지에 달려 있습니다. 같은 도형이라도 좌표 원점이 바뀌면 위치에 관련된 값의 해석이 달라질 수 있으므로 입력 ROI와 캡처 시점을 함께 기록합니다. 값 스냅샷이 독립적이라는 사실은 입력이 같았다는 보장은 아닙니다.

get_image로 캡처 영상을 별도 취득한 경우 실행 객체와 해당 ZImage는 각각 close해야 합니다. 필요한 스냅샷과 캡처를 얻은 뒤 소유 자원을 정리하고, 취득하지 않은 캡처를 이미 존재하는 영상으로 가정하지 마십시오.

항목확인할 내용

실행 수명사용 후 QueryExecution을 close합니다.

예를 들어 처리 흐름 중간에 캡처 이름을 지정했다면 get_image는 그 이름이 가리키는 시점의 영상을 획득하는 별도 작업입니다. 이 영상과 output의 모멘트 값은 같은 객체가 아닙니다. 캡처의 좌표와 모멘트를 비교하려면 캡처가 어느 처리 단계의 영상인지, 영역의 ROI 원점이 무엇인지 확인하십시오. 실행을 닫기 전에 필요한 캡처를 얻고, 이미 취득한 영상의 핸들은 해당 영상의 수명에 맞게 따로 닫습니다.
