x: 검색 영상 로컬 기준점 x 격자(픽셀)입니다. 최소·최대·양의 간격을 지정합니다.

y: 검색 영상 로컬 기준점 y 격자(픽셀)입니다. 최소·최대·양의 간격을 지정합니다.

angle: 회전각 격자(라디안)입니다. 유한 최소·최대 및 양의 간격이 필요합니다.

scale_x: x축 배율 격자입니다. 최소 배율과 간격은 양수여야 합니다.

scale_y: y축 배율 격자입니다. 최소 배율과 간격은 양수여야 합니다.

min_score: 최소 허용 점수이며 0..1입니다. 기본값 0.8입니다.

min_coverage: 유효 모델 표본의 최소 비율이며 0보다 크고 1 이하여야 합니다. 기본값 1입니다.

min_distance: 결과 중심 간 억제 거리(픽셀)로 유한한 비음수입니다. 기본값 1입니다.

max_matches: 최대 반환 수로 양의 정수입니다. 기본값 1입니다.

candidate_budget: 평가 포즈 수 상한이며 양의 정수입니다. 기본값 100000입니다. 결과 수 상한과 별개입니다.

timeout_ms: 시간 제한(밀리초)으로 0이면 제한하지 않습니다. 기본값 0입니다.

certainty: 지정하면 0..1의 조기 종료 점수이며 None이면 사용하지 않습니다.

mask_offset_x: 검색 영상 로컬 좌표에서 검색 마스크 원점의 x 오프셋입니다. 32비트 부호 정수이며 기본값 0입니다.

mask_offset_y: 검색 영상 로컬 좌표에서 검색 마스크 원점의 y 오프셋입니다. 32비트 부호 정수이며 기본값 0입니다.

either_polarity: 반전 극성도 허용할지 나타내는 bool입니다. 기본값 False입니다.

subpixel: 부픽셀 위치 정밀화를 요청하는 bool입니다. 기본값 False입니다.

coarse: 위치 격자 정밀화 검색을 사용할지 지정합니다. 기본값 False입니다.

pyramid_levels: 위치 격자 정밀화 단계 수이며 기본값 0입니다. 실제 영상을 축소하는 영상 피라미드와 구분합니다.

retained_candidates: 정밀화 단계에서 유지할 최대 후보 수이며 양의 정수입니다. 기본값 128입니다.

coarse_acceptance: 거친 단계에서 유지할 최소 점수이며 기본값 0입니다.

min_gradient: 형상 검색 기울기 하한입니다. 기본값 0입니다.

max_occlusion_fraction: 형상 점수에서 절삭할 가림 비율입니다. 기본값 0입니다.

값을 구성하고 해석하기

고급 검색에 필요한 위치·회전·독립 x/y 배율 격자와 종료·선별 조건을 함께 표현합니다. candidate_budget은 평가할 포즈의 수이고 max_matches는 반환할 결과 수이므로 서로 대신하지 않습니다. coarse와 pyramid_levels는 위치 격자의 정밀화이며 실제 축소 영상을 사용하는 피라미드 검색과 구분합니다.
