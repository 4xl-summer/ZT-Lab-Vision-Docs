add_intersection(self, id, first, second)

이전 직선 둘의 교점을 추가합니다.

확인된 인자 조건

id: 형상 식별자.

first: 이전 첫 직선 인덱스.

second: 이전 둘째 직선 인덱스.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • second · POSITIONAL_OR_KEYWORD · 기본값 없음

Add the intersection of two earlier line features.

이 호출의 입력과 객체 맥락

먼저 추가한 두 직선 특성의 인덱스 first와 second를 받아 두 직선의 교차점을 파생 특성으로 추가합니다. 새 항목의 0부터 시작하는 인덱스를 반환하므로 이후 허용오차 정의에서 이 점을 참조할 수 있습니다. 두 참조는 이미 모델에 있는 직선이어야 하며, 아직 추가하지 않은 특성을 앞당겨 참조하지 않습니다. 좌표는 모델의 ROI 로컬 기준에서 해석합니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
