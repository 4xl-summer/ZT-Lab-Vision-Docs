CompositeToleranceResult(id: int, status: zvision._composite_metrology.CompositeStatus, value: float | None) -> None

Tolerance id, three-state decision and optional measured value.

id: 공차 식별자.

status: 통과·실패·미평가 중 공차 판정.

value: 계산된 관계 값 또는 미사용 시 None.

이 호출의 입력과 객체 맥락

개별 허용치의 식별자 id, 세 가지 상태 status, 선택적 측정값 value를 묶습니다. 이 값은 전체 복합 결과에 들어 있는 각 판정의 관찰 단위이므로 id를 이용해 어떤 허용치 설정을 평가했는지 연결해야 합니다. value가 None인 경우와 실제 값 0은 다르며, 수치가 없는데 0으로 바꾸면 원점이나 0 간격처럼 정상적인 계측 결과와 구별할 수 없습니다. 예를 들어 같은 허용치에서 측정값이 존재하고 한계를 만족한 결과와, 형상 미검출로 측정 자체가 불가능한 결과는 status를 통해 분리해서 기록합니다. 수치의 단위는 해당 측정과 복합 결과의 단위 설정을 함께 확인해야 하며 id가 단위나 합격 한계 자체를 뜻하는 것은 아닙니다. 전체 상태가 실패했더라도 어떤 개별 항목이 실패했는지 찾으려면 개별 결과 목록을 살펴야 합니다. 반대로 허용치가 평가되지 않은 경우를 합격으로 표시하면 누락된 데이터가 통과한 것처럼 보일 수 있습니다. 재현을 위해 판정 상태뿐 아니라 원래 입력 형상과 허용치 설정도 보존하십시오. 같은 식별자의 결과를 프레임 간 비교할 때에는 설정한 허용치가 변경되지 않았는지도 대조하십시오. 식별자만 같고 한계가 바뀐 경우 결과의 상태 차이를 측정값 변화만으로 설명할 수 없습니다.

입력과 결과를 읽는 순서

한 공차 항목의 사용자 식별자 id, 판정 status와 선택적 관계값 value를 보관합니다. status는 통과·실패·미평가를 구분하며, value가 None이면 값이 제공되지 않았다는 뜻입니다. 숫자 0으로 바꾸면 실제 0이라는 측정 결과와 구분할 수 없습니다.

예를 들어 점과 선의 거리 관계가 계산되어 0이 나온 경우는 값이 존재하는 정상적인 수치입니다. 형상 검출이 실패해 관계를 평가하지 못한 경우는 수치가 없는 미평가 상태일 수 있습니다. 어느 공차인지 id를 원래 공차 설정과 연결하고 각 status를 따로 확인하세요.

길이 관계의 값은 CompositeResult에 적용된 출력 단위를 따르며 각도 관계는 해당 각도 계약을 따릅니다. id는 단위나 허용 범위 자체가 아닙니다. 서로 다른 실행을 비교할 때 같은 id의 공차 한계와 모델 구성도 같았는지 확인해야 상태 변화를 해석할 수 있습니다.
