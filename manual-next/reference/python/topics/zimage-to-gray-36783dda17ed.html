Python
to_gray(self)

RGB/BGR 입력을 단일 회색 영상으로 변환합니다.

반환: 색 성분 형식에 대응하는 독립 회색 영상. 반환한 ZImage는 별도 소유 핸들이므로 close 또는 with로 해제합니다.

오류: 미지원 형식이면 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

색상에서 회색으로

RGB 또는 BGR 색상 입력을 단일 회색 영상으로 변환합니다. 입력의 채널 순서와 픽셀 형식을 먼저 확인해야 빨강과 파랑의 기여를 잘못 해석하지 않습니다. 변환 결과는 색상 채널 전체를 보존하지 않는 단일 채널 표현입니다.

형식과 수명

출력 회색 형식은 색 성분 형식에 대응하며 지원되지 않는 입력은 오류가 납니다. 반환 ZImage는 독립 소유 핸들이므로 사용 후 닫습니다. 밝기가 비슷한 서로 다른 색은 회색 결과에서 구분이 어려울 수 있어 색상 판정이 필요하면 원본도 유지합니다.

정보 손실

단일 회색값은 여러 색 채널을 하나로 요약합니다. 따라서 다른 색이 비슷한 회색으로 나타날 수 있고 회색 영상만으로 원래 RGB 세 값을 복원할 수 없습니다. 후속 색상 판정에는 원본을 유지합니다.
