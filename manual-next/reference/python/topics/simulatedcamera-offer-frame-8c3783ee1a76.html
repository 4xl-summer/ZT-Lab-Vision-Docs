offer_frame

method · 선언 타입 zvision._acquisition.SimulatedCamera

Python
offer_frame(self, image, frame_id, device_ticks, host_ns, trigger_id=0)

프레임을 모의 취득 큐에 제출합니다.

확인된 인자 조건

image: 제출할 ZImage입니다.

frame_id: 양의 프레임 식별자입니다.

device_ticks: 음이 아닌 장치 틱 값입니다.

host_ns: 음이 아닌 호스트 시각으로 나노초 단위입니다.

trigger_id: 트리거 식별자이며 기본값은 0입니다.

반환: OfferDisposition을 반환합니다.

오류: 이미지 타입, 상태 또는 시간 조건이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • frame_id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • device_ticks · POSITIONAL_OR_KEYWORD · 기본값 없음
  • host_ns · POSITIONAL_OR_KEYWORD · 기본값 없음
  • trigger_id · POSITIONAL_OR_KEYWORD · 기본값 0

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

호출자가 제공한 ZImage와 frame_id, device_ticks, host_ns 및 trigger_id를 모의 취득 스트림에 제안합니다. Acquiring 상태가 필요하며 frame_id는 양수입니다. FreeRun은 trigger_id가 0이고 Software·External은 일치하는 대기 트리거가 필요합니다. 순서가 같은 ID는 Duplicate, 작은 ID는 OutOfOrder로 분류합니다. 큐에 공간이 있으면 독립 이미지 복사와 Accepted, 가득 찼으면 기존 프레임을 유지하고 새 프레임을 버린 뒤 QueueFull을 반환합니다.
