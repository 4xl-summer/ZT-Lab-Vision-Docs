delta_e76

method · 선언 타입 zvision._query.ImageQuery

Python
delta_e76(self, target)

색상 CIE76 거리 단계를 계획에 추가합니다.

확인된 인자 조건

target: 기준 LabColor

반환: 수정된 동일 ImageQuery입니다.

오류: 입력 또는 인자가 유효하지 않으면 오류입니다.

인자 선언

  • target · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

기준 Lab 색과의 거리

각 위치의 Lab 색과 target LabColor의 CIE76 거리를 계획합니다. L, a, b 차이가 각각 3, 4, 0이라면 유클리드 거리는 5입니다. target의 세 값은 D50 기준 Lab 좌표이며 RGB 바이트로 직접 해석하지 않습니다.

결과 판독

계획을 실행하고 색 차이 영상의 값 범위를 확인합니다. 서로 다른 조명이나 인코딩, 색 보정은 Lab 값에 영향을 주므로 입력 조건을 함께 기록합니다. 거리 숫자 하나만으로 실제 카메라 색 정확도를 보증하지 않습니다.
