train_ncc(cls, template, mask=None)

템플릿의 선택 픽셀로 기본 NCC 모델을 학습합니다.

확인된 인자 조건

template: Gray8, Gray16 또는 유한 GrayF32 ZImage입니다.

mask: 같은 크기·원점의 선택 Gray8 마스크입니다. 0은 제외합니다.

반환: 호출자가 닫아야 하는 독립 모델입니다.

오류: 선택 픽셀이 2개 미만이거나 상수, 형식·마스크가 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

호출 맥락과 결과 해석

템플릿의 선택 픽셀로 기본 NCC 모델을 학습합니다. 선택 마스크는 템플릿과 크기·원점이 같은 Gray8이며 0인 위치는 제외됩니다. 마스크로 제외한 배경은 모델의 선택 표본에 포함되지 않습니다.

NCC는 선택 표본의 밝기 변화를 비교하므로 분산이 없는 템플릿이나 검색 패치에서는 정상적인 상관 점수를 만들 수 없습니다. 선택 영역에 무늬가 충분한지 확인하고, 생성된 모델을 find에 전달한 뒤 호출자가 닫습니다.

입력 선택을 위한 확인

입력의미와 조건
templateGray8, Gray16 또는 유한 GrayF32 ZImage입니다.
mask같은 크기·원점의 선택 Gray8 마스크입니다. 0은 제외합니다.

반환값 확인

호출자가 닫아야 하는 독립 모델입니다.
