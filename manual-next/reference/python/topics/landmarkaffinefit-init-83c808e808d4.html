LandmarkAffineFit(matrix: tuple, residual_rms: float, residuals: tuple)

matrix: 기준에서 소스 좌표로 가는 2×3 아핀 행렬의 행 우선 여섯 계수입니다.

residual_rms: 대응점의 유클리드 거리 잔차 RMS(픽셀)입니다.

residuals: 대응점별 유클리드 거리 잔차(픽셀)의 튜플입니다.

이 호출의 입력과 객체 맥락

알려진 대응점으로 계산한 아핀 변환과 잔차의 독립 값입니다. matrix에는 기준에서 소스 좌표로 가는 2×3 행렬의 여섯 계수가 행 우선으로 들어갑니다. 각 대응점의 유클리드 거리 잔차와 그 RMS는 좌표 단위이며 영상 픽셀로 입력했다면 픽셀 단위입니다. 이 객체는 영상에서 랜드마크를 자동 검출한 결과가 아닙니다.

최소 세 쌍의 유효한 대응점으로 적합을 요청한 다음 행렬과 개별 잔차를 함께 살펴봅니다. 평균 수준의 RMS가 작더라도 특정 점 하나가 크게 어긋날 수 있으므로 residuals를 확인하는 것이 유용합니다. 변환 방향을 거꾸로 사용하면 정렬 위치가 달라집니다. 입력 점이 퇴화하거나 대응이 잘못되면 원하는 변환을 얻을 수 없습니다.

대응점 피팅의 결과

matrix는 아핀 계수 튜플이고 residual_rms와 residuals는 대응점 피팅의 오차 요약과 각 잔차입니다. 생성자는 matrix와 residuals를 튜플로 바꾸고 숫자가 아닌 값이나 bool이 포함되면 TypeError를 발생시킵니다.

fit_advanced_landmark_affine은 이미 알려진 reference와 source의 대응점을 사용합니다. 두 목록은 길이가 같고 Point2로 구성되어야 하며 함수가 영상에서 대응점을 자동으로 탐색하지 않습니다. 입력 순서가 바뀌면 잘못된 점끼리 짝이 됩니다.

예를 들어 세 점의 잔차가 0, 0, 3이라면 RMS는 √((0²+0²+3²)/3)=√3입니다. 평균적인 RMS가 작아도 한 점의 잔차가 클 수 있으므로 residuals도 살펴봅니다. 오차의 단위는 입력 점의 좌표 기준에 따라 해석합니다.

네이티브 피팅에서 반환된 계수 여섯 개와 잔차는 복사된 값이며 임시 결과 핸들은 함수 내부에서 해제됩니다. 같은 변환을 다른 ROI에 적용할 때 기준과 검사 좌표의 원점 및 변환 방향을 확인합니다. 결과 값만으로 독립 검증의 정확도가 보장되지는 않습니다.
