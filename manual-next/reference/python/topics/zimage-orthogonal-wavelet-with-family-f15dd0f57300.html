orthogonal_wavelet_with_family

Python
orthogonal_wavelet_with_family(self, levels, family)

지정한 웨이블릿 변환을 계산합니다.

확인된 인자 조건

levels: 변환 레벨 수

family: 웨이블릿 계열

반환: 별도로 close할 변환 결과입니다.

오류: 형식, 레벨 또는 필터가 유효하지 않으면 오류입니다.

인자 선언

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • family · POSITIONAL_OR_KEYWORD · 기본값 없음

Return a transform using the requested family.

선택한 계열의 변환

family로 웨이블릿 계열을 선택하고 levels로 분해 단계를 지정합니다. 계열에 따라 사용하는 필터와 분해된 계수의 의미가 달라지므로 다른 설정의 값을 같은 수치 기준으로 비교하지 않습니다.

처리 순서

지원되는 family와 입력 형식, 유효한 단계 수를 확인해 변환합니다. 결과는 독립 소유 객체이며 필요한 계수나 역변환을 사용한 뒤 닫습니다. 원본과 복원 결과를 비교할 때 계열과 단계, 입력 범위를 함께 기록합니다.
