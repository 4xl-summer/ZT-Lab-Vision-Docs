coefficients

method · 선언 타입 zvision._stationary_wavelet_gap.StationaryHaar

Python
coefficients(self)

모든 밴드 계수를 순서대로 복사합니다.

반환: 최종 LL 뒤 레벨별 HL/LH/HH 순서의 독립 튜플입니다.

오류: 닫힌 모델은 오류입니다.

Return a packed independent tuple of all bands.

이 호출의 입력과 객체 맥락

현재 모델의 계수를 행 우선 숫자 튜플로 복사합니다. 튜플은 독립 값이므로 일부 계수를 바꾸려면 목록 등으로 복사해 편집한 뒤 with_coefficients로 새 모델을 만듭니다. 원래 모델과 새 모델은 각각 close합니다. 계수 크기와 밴드 순서를 모델 정보와 함께 확인하세요. 순서는 최종 LL 다음 각 단계의 HL, LH, HH입니다.

입력과 결과 확인

coefficients는 정지 Haar 변환에 보관된 모든 밴드 계수를 복사한 불변 튜플을 돌려줍니다. 원래 모델의 버퍼를 빌려주는 것이 아니므로 반환 값과 모델 핸들은 다른 수명 경로를 가집니다. 닫힌 모델에서의 호출 오류를 빈 계수 튜플과 구별해야 합니다.

배열 순서는 최종 LL 다음에 레벨별 HL, LH, HH입니다. 각 밴드의 크기와 레벨 수는 모델 정보와 함께 기록하여 같은 위치를 올바른 밴드로 해석합니다. 이름이 비슷한 다른 변환의 계수 배열 순서와 자동으로 같다고 가정하지 마십시오.

값을 바꾸어 새로운 모델을 만들려면 튜플을 편집 가능한 자료로 복사한 뒤 with_coefficients에 전달합니다. 원본을 읽는 호출 자체가 모델을 수정하지는 않습니다. 생성한 새 모델과 원본 모델은 각각 소유 핸들이므로 사용이 끝나면 각각 close합니다.

항목확인할 내용
반환모든 밴드의 독립 계수 튜플입니다.
첫 밴드최종 LL 계수입니다.
세부 밴드각 레벨의 HL, LH, HH 순서입니다.
편집목록 등으로 복사한 값을 새 모델 생성에 사용합니다.
수명원본과 새 모델을 각각 close합니다.
오류닫힌 모델의 호출을 정상 빈 결과로 바꾸지 않습니다.

최종 LL은 낮은 주파수의 근사 성분을 나타내며 레벨별 세 상세 밴드와는 역할이 다릅니다. 계수 튜플의 원소 하나를 편집해도 원본 StationaryHaar 객체가 바로 수정되는 것은 아닙니다. 새 모델을 만드는 호출에서는 원래 모델이 요구한 계수 개수를 유지해야 하므로 밴드 수와 전체 길이를 먼저 확인하십시오. 정지 변환의 각 밴드를 시각화할 때는 크기와 순서를 모델 정보로 해석하고, 표시용으로 스케일을 바꾼 값이 원래 역변환 계수와 같다고 가정하지 않습니다.

편집한 계수의 개수와 값이 모델이 요구하는 조건을 만족하지 않으면 새 모델 생성에 실패할 수 있습니다. 실패를 원본 계수가 모두 0인 정상 모델로 표시하지 마십시오.
