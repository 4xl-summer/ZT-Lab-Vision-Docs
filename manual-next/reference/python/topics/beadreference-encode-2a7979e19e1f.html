비드 기준 저장

max_bytes로 크기 한도를 지정해 비드 기준을 직렬화된 bytes로 복사합니다. 반환 바이트는 원래 모델 핸들과 수명이 다른 값입니다.

저장 데이터와 함께 영상 형식, ROI 원점, 경로와 학습 설정을 기록하면 복원 후 기준의 출처를 확인할 수 있습니다. 직렬화에 실패한 경우 빈 정상 모델 데이터로 처리하지 않습니다.
