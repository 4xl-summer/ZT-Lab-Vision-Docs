find_relative(self, source, options, prior, mask=None)

기준 포즈에 대한 위치·각도 오프셋과 배율 비율 격자를 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 확장 NCC 검색 설정입니다.

mask: 선택 검색 마스크입니다.

prior: 상대 격자의 기준 포즈입니다.

반환: 독립 결과와 종료 진단입니다.

오류: 유효하지 않은 입력, 모델 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • prior · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search offsets and scales relative to a prior pose.

호출 맥락과 결과 해석

prior 포즈를 기준으로 위치와 각도의 오프셋, 배율의 비율 격자를 검색합니다. 절대 좌표 격자를 그대로 해석하는 검색과 달리 설정값을 기준 포즈와의 관계로 읽어야 합니다. 기준이 달라지면 같은 상대 격자도 다른 포즈들을 나타냅니다.

예상 포즈와 오프셋 범위를 함께 보관해야 같은 검색을 재현할 수 있습니다. 결과는 독립 스냅샷이고 종료 진단도 포함하므로, 후보가 없으면 기준 포즈와 상대 범위 및 검색 조건을 차례로 확인합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options확장 NCC 검색 설정입니다.
prior상대 격자의 기준 포즈입니다.
mask선택 검색 마스크입니다.

반환값 확인

독립 결과와 종료 진단입니다.
