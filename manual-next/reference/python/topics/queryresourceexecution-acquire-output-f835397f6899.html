Acquire an independent owned result; the caller must close it.

이 호출의 입력과 객체 맥락

열린 실행의 결과를 별도 소유 객체로 취득합니다. 예를 들어 정렬 실행이면 AlignmentResult, 차분 실행이면 DifferenceResult를 받아 각 결과의 정보를 읽습니다. 반환 객체는 실행을 닫는 것과 별도로 호출자가 close해야 합니다. 이미 닫힌 실행에서 다시 취득하면 오류이며 캡처 영상은 get_image로 별도 취득합니다.

실행·출력·캡처의 소유권

QueryResourceExecution은 소유 결과를 반환하는 타입 지정 쿼리 실행을 감쌉니다. acquire_output은 실행이 열린 상태에서 결과를 별도 소유 객체로 취득하며, 호출자는 그 결과를 close해야 합니다. 획득한 결과의 형식은 실행한 쿼리의 출력 형식에 따라 결정됩니다.

예를 들어 정렬 쿼리라면 AlignmentResult를 얻어 정렬 상태와 영상을 살피고, 차분 쿼리라면 DifferenceResult의 차분 정보와 영상들을 살핍니다. 이름으로 캡처한 영상은 get_image로 따로 획득하므로 결과 객체와 캡처 영상을 같은 소유 핸들로 취급하지 않습니다.

실행을 close하기 전에 필요한 출력과 캡처를 얻고, 이미 얻은 각 소유 객체도 사용 후 각각 닫습니다. 실행을 닫은 뒤에는 acquire_output이나 get_image를 다시 호출할 수 없으며 열린 상태 확인에서 ValueError가 납니다. 이미 취득한 독립 결과의 수명은 실행 객체와 구분됩니다.

여러 종류의 쿼리가 같은 제네릭 실행 형식을 사용하지만 acquire_output이 반환하는 구체 결과는 그 실행이 만든 결과 종류에 따라 달라집니다. 형식에 맞는 결과 메서드를 사용하고, 실행이 닫히기 전에 필요한 출력이나 이름 있는 캡처를 확보합니다. 결과를 하나 획득했다고 모든 캡처가 자동으로 복사되는 것은 아닙니다.
