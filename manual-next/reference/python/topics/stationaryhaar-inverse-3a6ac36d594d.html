inverse(self)

계수에서 영상을 복원합니다.

반환: 입력 ROI 원점을 가진 독립 GrayF64 이미지이며 호출자가 닫습니다.

오류: 닫힌 모델 또는 비유한 복원 결과는 오류입니다.

Reconstruct a new GrayF64 image with the input ROI origin.

이 호출의 입력과 객체 맥락

모델 계수를 합성하여 입력 ROI 원점을 유지하는 GrayF64 영상을 반환합니다. 숫자 계수 배열과 달리 이 결과는 소유 ZImage이므로 사용 후 close합니다. 모델을 변경한 결과를 비교하려면 각 모델에서 별도 복원 영상을 얻고 같은 ROI 원점과 크기 기준으로 비교하세요. 모델 자체도 별도로 close해야 합니다.

정지 Haar 역변환

inverse는 StationaryHaar에 저장된 계수에서 영상을 복원해 독립 소유 ZImage를 반환합니다. 정지 웨이블릿의 계수 배치와 수준은 forward 시의 설정에 대응하며 원본 화면의 픽셀 밝기와 계수 배열을 동일한 것으로 취급하지 않습니다.

coefficients는 복사된 값이고 with_coefficients나 shrunk는 새 모델을 만드는 경로입니다. 계수를 변경해 새 모델을 만든 뒤 inverse를 호출하면 그 모델의 계수로 복원합니다. 변환 전후의 크기와 origin을 확인하여 같은 ROI를 비교합니다.

출력 영상은 호출자가 close하고 모델도 별도로 닫습니다. 원본 또는 계수 변경으로 생긴 손실이 있는 상황에서 복원이라는 이름만으로 원본 픽셀이 항상 정확히 같다고 주장하지 않습니다. 입력과 출력의 수치 및 사용한 수준을 함께 기록합니다.

정지 변환은 여러 수준의 밴드 정보를 보존하므로 복원할 모델과 계수의 순서를 함께 확인합니다. 사용자가 수정한 배열의 길이나 값이 모델의 계수 계약에 맞지 않으면 새 모델 생성이 실패할 수 있습니다.

복원 영상의 픽셀을 비교할 때 화면에서 자동으로 조절된 표시 범위만 보지 않습니다. 같은 ROI와 수치 형식에서 원본과 출력의 값을 확인하고, 축소 임계값을 사용했다면 그 설정도 기록합니다.
