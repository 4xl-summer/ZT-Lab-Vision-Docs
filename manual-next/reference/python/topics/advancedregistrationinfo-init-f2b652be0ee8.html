AdvancedRegistrationInfo(found: bool, matrix: tuple, score: float, residual_rms: float, coverage: float, evaluated: int)

found: 유효한 정합 결과를 찾았는지 나타냅니다. False면 행렬과 점수 등은 결과로 해석하지 마세요.

matrix: 기준 로컬에서 소스 로컬로 가는 3×3 행 우선 변환 값입니다. found가 True일 때 사용합니다.

score: NCC 또는 음의 평균 제곱 오차로, 클수록 좋습니다. found가 True일 때 사용합니다.

residual_rms: 유효 표본의 밝기 잔차 RMS입니다. found가 True일 때 사용합니다.

coverage: 유효한 기준 표본 비율입니다. found가 True일 때 사용합니다.

evaluated: 평가한 변환 후보 수입니다. found가 True일 때 사용합니다.

이 호출의 입력과 객체 맥락

국소 아핀 또는 원근 영상 정합에서 유효 결과의 존재 여부와 변환 진단을 제공합니다. found가 참일 때 matrix는 기준 영상 로컬 좌표에서 소스 로컬 좌표로 가는 3×3 행 우선 행렬입니다. score는 선택 방식에 따라 NCC 또는 음의 평균 제곱 오차이며 모두 큰 값이 더 좋습니다. residual_rms는 유효 표본의 밝기 잔차이고 coverage는 기준 표본의 유효 비율입니다.

found가 거짓이면 채워진 기본 숫자를 유효한 변환으로 해석하지 않습니다. 먼저 결과 유무를 검사한 다음에만 행렬과 점수를 후속 정렬에 전달합니다. evaluated는 평가한 변환 수이며 전역 최적을 보증하는 값이 아닙니다. 이 연산은 초기값 주변의 국소 최적화이므로 초기 포즈가 멀거나 가시 영역이 부족하면 기대 결과를 얻지 못할 수 있습니다.
