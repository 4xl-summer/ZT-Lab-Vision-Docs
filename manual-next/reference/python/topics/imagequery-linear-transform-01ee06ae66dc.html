ImageQuery.linear_transform 공개 계약

상위 목차로 돌아가기

linear_transform

method · 선언 타입 zvision._query.ImageQuery

Python
linear_transform(self, gain, bias)

선형 변환 단계를 현재 계획에 덧붙입니다.

확인된 인자 조건

gain: 곱셈 계수

bias: 덧셈값

반환: 수정된 동일 ImageQuery입니다.

오류: 인자·메타데이터 또는 실행 시 픽셀 검증이 실패할 수 있습니다.

인자 선언

  • gain · POSITIONAL_OR_KEYWORD · 기본값 없음
  • bias · POSITIONAL_OR_KEYWORD · 기본값 없음

gain: 유한한 수 검사.

bias: 유한한 수 검사.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

선형 값 처리 단계

배율과 오프셋을 적용하는 단계를 현재 계획에 추가합니다. 예를 들어 실수 산술에서 값 3에 배율 2와 오프셋 1을 적용하면 7입니다. 실제 출력 형식과 범위 밖 처리 규칙은 호출 계약을 따라야 합니다.

순서의 영향

이 단계 전후의 임계 처리 위치를 바꾸면 같은 임계값으로 선택되는 픽셀이 달라질 수 있습니다. 작은 입력으로 출력 값을 대조하고 배율과 오프셋을 각각 조정해 영향과 오류 조건을 확인합니다.
