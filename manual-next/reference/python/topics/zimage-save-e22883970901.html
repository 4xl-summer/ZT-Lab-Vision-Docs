save

method · 선언 타입 zvision.ZImage

Python
save(self, path)

경로에 영상을 저장합니다.

확인된 인자 조건

path: 출력 파일 경로

반환: None입니다.

오류: 경로·형식이나 저장에 문제가 있으면 오류입니다.

인자 선언

  • path · POSITIONAL_OR_KEYWORD · 기본값 없음

Save the visible image to a filesystem path using its extension.

영상 기록

save는 영상 데이터를 지정된 경로에 기록합니다. 출력 형식은 저장 API의 계약과 경로에 맞게 선택해야 하며, 저장하려는 영상의 픽셀 형식이 해당 형식에 지원되는지 확인합니다. 원본 영상 데이터와 저장 파일은 서로 다른 자원입니다.

결과 확인

경로 접근 권한이나 지원되지 않는 형식으로 인해 저장이 실패할 수 있으므로 오류를 확인합니다. 저장한 파일을 다른 도구로 읽어 크기, 채널 순서 및 필요한 픽셀값이 보존되었는지 검증할 수 있습니다. 영상 핸들은 저장 후에도 별도 수명 규칙을 따릅니다.
