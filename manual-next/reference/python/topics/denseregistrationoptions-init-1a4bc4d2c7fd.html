DenseRegistrationOptions(levels: int = 1, warps: int = 3, iterations: int = 80, smoothness: float = 0.01, robust_epsilon: float = 1.0, tolerance: float = 1e-08, max_displacement: float = 3.0, max_work: int = 1000000) -> None

Pyramid/warp/iteration limits, smoothness, robust brightness epsilon, convergence tolerance in pixels, max displacement and work.

levels: 피라미드 층 수로 1..6입니다. 기본값 1입니다.

warps: 각 층의 워프 수로 1..20입니다. 기본값 3입니다.

iterations: 각 워프의 반복 상한으로 1..500입니다. 기본값 80입니다.

smoothness: 유한한 양의 평활 계수입니다. 기본값 0.01입니다.

robust_epsilon: 밝기 잔차의 안정화에 쓰는 유한한 양수입니다. 기본값 1입니다.

tolerance: 수렴 비교에 사용하는 유한한 비음수 픽셀 기준입니다. 기본값 1e−8입니다.

max_displacement: 허용 최대 변위(픽셀)로 유한한 양수입니다. 기본값 3입니다.

max_work: 작업 추정 상한으로 1..1000000000입니다. 픽셀 수×층 수×워프 수×(반복 수+3)이 이보다 크면 오류입니다. 기본값 1000000입니다.

이 호출의 입력과 객체 맥락

피라미드 levels, 층별 warps, 워프별 iterations와 평활·수렴·변위 제한을 지정합니다. max_displacement와 tolerance는 픽셀 기준입니다. 작업 추정은 픽셀 수×층 수×워프 수×(반복 수+3)이며 max_work보다 크면 오류입니다. 예를 들어 층이나 워프를 늘리면 같은 이미지에서도 이 예산이 커집니다. 설정값을 키우는 것만으로 정합 정확도나 수렴이 보장되지는 않습니다.
