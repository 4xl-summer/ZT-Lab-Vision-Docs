NamedFrame.__init__

python 공개 선언
NamedFrame(name: str, id: int) -> None

One UTF-8 frame name bound to a nonzero frame ID.

name: 좌표계를 식별하는 UTF-8 이름입니다.

id: 프레임을 식별하는 0이 아닌 정수 ID입니다.

이 호출의 입력과 객체 맥락

NamedFrame은 좌표 프레임의 이름과 0이 아닌 숫자 ID를 연결합니다. resolve_named_rigid_tree는 이 연결을 사용해 이름으로 지정한 출발과 도착 프레임 사이의 변환을 찾습니다. resolve_named_rigid_tree에 전달하는 이름은 비어 있지 않고 UTF-8 인코딩 기준 64바이트를 넘을 수 없으며 NUL 문자를 포함할 수 없습니다.

예를 들어 camera와 base를 서로 다른 ID에 연결하고 camera→gripper→base 경로를 구성하면 이름으로 camera에서 base까지의 변환을 요청할 수 있습니다. 이름이 다르더라도 같은 물리 프레임인지 또는 같은 이름이 장치 교체 후 다른 기준을 뜻하는지 관리해야 합니다. 숫자 ID와 이름 매핑을 변환 간선과 함께 저장하세요.

이름과 프레임 ID의 연결

NamedFrame은 name과 id를 담는 불변 데이터 값입니다. 생성된 값은 resolve_named_rigid_tree에서 이름을 숫자 프레임 ID에 연결하는 입력으로 사용합니다. 이 데이터 생성자 자체와 실제 트리 해석 호출에서 수행되는 유효성 검사를 구분해야 합니다.

해석 함수에 전달할 이름은 비어 있지 않은 문자열이고 NUL을 포함하지 않으며 UTF-8 인코딩이 최대 64바이트여야 합니다. 예를 들어 ASCII 문자 10개는 10바이트이지만 한글은 글자 수와 UTF-8 바이트 수가 다를 수 있습니다. ID는 0이 아니어야 하며 트리의 변환 간선에 쓰인 프레임과 맞아야 합니다.

예를 들어 camera, gripper, base에 각각 다른 ID를 연결하고 camera→gripper→base 간선을 구성한 뒤 이름으로 양 끝을 요청할 수 있습니다. 결과 변환의 방향과 단위를 간선의 프레임 관계와 함께 확인하고, 이름과 ID의 대응을 장치 교체 이후에도 추적할 수 있게 보관합니다.

예를 들어 frame ID 1을 camera, ID 2를 base로 부여했다면 이름 목록과 변환 간선이 동일 ID를 참조해야 합니다. 이름은 사람이 읽기 쉬운 별칭이고 숫자 ID는 변환의 프레임 관계를 식별합니다. 같은 문자열만으로 서로 다른 시점의 물리 좌표계가 동일하다고 확정하지 않습니다.
