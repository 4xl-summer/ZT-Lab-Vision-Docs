channel

method · 선언 타입 zvision._color_advanced.AdvancedPlanes

Python
channel(self, index)

선택 색상 평면의 소유 이미지 핸들을 취득합니다.

확인된 인자 조건

index: 0–2 채널 인덱스

반환: 호출자가 close할 독립 ZImage입니다.

오류: 인덱스 또는 결과 핸들이 유효하지 않으면 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

index 0, 1, 2 중 하나로 현재 색 공간의 평면을 선택합니다. 각 인덱스의 의미는 변환 시 선택한 색 공간을 기준으로 해석해야 하며 채널 번호만으로 RGB라고 가정하지 마세요. 반환된 ZImage는 별도 소유 핸들이므로 사용 후 close합니다. 범위를 벗어난 index 또는 닫힌 결과는 오류입니다. 원래 AdvancedPlanes도 별도로 close해야 합니다.
