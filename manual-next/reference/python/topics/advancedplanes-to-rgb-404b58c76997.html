AdvancedPlanes.to_rgb 공개 계약

상위 목차로 돌아가기

to_rgb

method · 선언 타입 zvision._color_advanced.AdvancedPlanes

Python
to_rgb(self, format)

색 평면을 지정된 RGB 계열 영상으로 변환합니다.

확인된 인자 조건

format: 지원되는 출력 PixelFormat.

반환: 독립 소유 영상이며 close합니다.

오류: 닫힌 객체 또는 지원되지 않는 형식·옵션은 오류입니다.

인자 선언

  • format · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

현재 색 평면을 지정한 PixelFormat의 RGB 영상으로 변환합니다. format 인자는 PixelFormat이어야 하며 실제 지원 형식과 원본 색 공간은 변환 계약을 따릅니다. 반환 ZImage는 소유 핸들이므로 사용 후 close하고, 입력 AdvancedPlanes도 별도로 관리합니다. 색 공간과 변환에 사용된 백색점·전달 함수를 함께 기록해야 서로 다른 변환 결과를 올바르게 비교할 수 있습니다.
