ShapeMatchDiagnostics(matched_model_fraction: float, target_edge_coverage: float, clutter_fraction: float, fit_rms: float | None, matched_features: int, target_edges: int)

matched_model_fraction: 변환 모델 특징점 중 지정 반경 내 호환 에지가 있는 비율입니다.

target_edge_coverage: 확장된 모델 경계 내 검색 에지 중 근처에 호환 모델 특징점이 있는 비율입니다. 에지가 없으면 0입니다.

clutter_fraction: 검색 에지 중 호환 모델 특징점에 대응하지 않는 비율입니다. 에지가 없으면 0입니다.

fit_rms: 일치 모델 특징점과 가장 가까운 호환 검색 에지 거리의 RMS(픽셀)입니다. 일치가 없으면 None입니다.

matched_features: 호환 검색 에지와 연결된 모델 특징점 수입니다.

target_edges: 확장된 경계 내 임계 기울기를 통과한 검색 에지 수입니다.

값을 구성하고 해석하기

지정 포즈에서 모델 특징과 검색 에지의 대응을 진단하는 값입니다. 모델 특징 일치 비율과 검색 에지 커버리지는 분모가 다르므로 같다고 가정하지 않습니다. fit_rms는 일치가 없으면 None이고 그 밖에는 픽셀 거리의 RMS이므로, matched_features 및 target_edges와 함께 해석합니다.
