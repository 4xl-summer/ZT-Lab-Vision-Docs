rectify(self, image, pose, plane, spec)

직교 카메라와 평면을 이용해 영상과 유효 마스크를 만듭니다.

확인된 인자 조건

image: 입력 ZImage입니다.

pose: 카메라에서 세계로의 RigidTransform3입니다.

plane: 세계 평면 WorldPlane입니다.

spec: 출력 격자를 정의하는 Rectification입니다.

반환: 각각 닫아야 하는 보정 영상과 마스크 쌍입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • plane · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

입력 ZImage를 지정 세계 평면과 Rectification 격자에 맞춰 한 번 보간합니다. 카메라→세계 포즈와 평면의 프레임·단위를 맞추고 원본 ROI의 글로벌 원점을 고려합니다. 반환되는 두 ZImage는 정류 영상과 전체 보간 footprint 유효 마스크이며 각각 독립 소유이므로 둘 다 close합니다. 카메라 뒤쪽 z<0은 경계 처리되며 마스크로 유효 표본을 구분합니다.

이 객체의 확인된 공개 생성 경로: TelecentricCamera(sx: float, sy: float, cx: float, cy: float, unit: zvision._calibration.LengthUnit, camera_frame: int) -> None.
