BlobSegmentationInfo(low: float, high: float, has_thresholds: bool) -> None

Thresholds; has_thresholds is false for LUT segmentation.

low: 상대 분할의 낮은 임계값입니다.

high: 상대 분할의 높은 임계값입니다.

has_thresholds: 임계값 정보가 존재하는지 나타내며 LUT 분할에서는 거짓입니다.

생성 인자와 보관되는 값

인자확인된 의미기본값
low상대 분할의 낮은 임계값입니다.필수
high상대 분할의 높은 임계값입니다.필수
has_thresholds임계값 정보가 존재하는지 나타내며 LUT 분할에서는 거짓입니다.필수

값의 해석과 사용

has_thresholds를 먼저 확인합니다. LUT 분할에서는 거짓이므로 low와 high만으로 분할 규칙을 재구성할 수 없습니다. 실제 조회표와 스케일을 별도 기록해야 재현할 수 있습니다.
