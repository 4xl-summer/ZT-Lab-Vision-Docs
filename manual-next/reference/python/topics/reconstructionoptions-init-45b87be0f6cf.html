mode: 재구성에 사용할 팽창 또는 침식 방식입니다.

이 호출의 입력과 객체 맥락

마커와 마스크에 적용할 형태학 재구성의 팽창 또는 침식 mode, 이웃 connectivity, 최대 반복 수와 작업 예산을 묶습니다. 기본값은 팽창, 8연결, 1000회, 100000000 작업량입니다. 연결 방식을 바꾸면 대각선 이웃을 같은 연결 관계로 볼지 달라집니다. 반복과 작업량은 서로 다른 상한이므로 입력 크기와 함께 설정하고, 한도 초과를 완료된 재구성으로 해석하지 마세요.

사용 흐름과 결과 판독

ReconstructionOptions는 마커와 마스크에 적용하는 형태학 재구성의 모드, 이웃 연결성, 반복 및 작업량 상한을 설정합니다. 기본 모드는 팽창, connectivity는 8, max_iterations는 1000, work_budget은 100000000입니다. 옵션 객체의 생성과 실제 재구성 실행은 서로 다른 단계입니다.

연결성은 전경의 이웃 관계를 정합니다. 예를 들어 두 위치가 대각선으로만 인접하면 8연결에서는 이웃이지만 4연결에서는 같은 방식으로 직접 연결되지 않습니다. 팽창 재구성과 침식 재구성도 다른 방향의 연산이므로 마커와 제한 마스크의 역할을 선택한 mode에 맞춰 확인해야 합니다.

반복 상한은 반복 횟수의 한계이고 작업 예산은 전체 계산량의 한계이므로 하나를 늘렸다고 다른 제한이 자동으로 늘어나지는 않습니다. 실행 후에는 반환 영상과 실제 반복 수, 고정점에 도달했는지를 함께 확인합니다. 한도에 걸린 실행을 완전히 수렴한 재구성으로 취급하지 말고 입력 격자와 설정을 함께 기록합니다.
