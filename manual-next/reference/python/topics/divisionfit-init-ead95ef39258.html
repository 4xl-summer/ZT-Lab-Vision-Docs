DivisionFit(camera: zvision._camera_models.DivisionCamera, rms_pixels: float)

camera: 적합된 카메라 모델 값입니다.

rms_pixels: 대응점 재투영 오차의 RMS이며 픽셀 단위입니다.

이 호출의 입력과 객체 맥락

DivisionFit은 디비전 왜곡 카메라 모델을 관측 데이터에 맞춘 결과입니다. camera는 후속 투영이나 광선 계산에 사용할 적합 모델이며 rms_pixels는 관측 픽셀과 모델의 재투영 차이로 계산한 RMS입니다. 값의 단위는 픽셀이므로 월드 거리나 각도와 바로 비교하지 않습니다. 모델 자체와 적합 품질 지표를 함께 저장해야 나중에 결과를 해석할 수 있습니다.

예를 들어 두 관측점의 픽셀 오차 크기가 1과 3이면 단순한 제곱평균 제곱근은 sqrt((1²+3²)/2), 즉 약 2.24 픽셀입니다. 실제 반환값은 해당 적합의 전체 관측과 정의를 따릅니다. 작은 학습 잔차만으로 다른 위치의 정확도를 보장할 수는 없으므로 보류한 점에서도 투영 차이를 확인하고 사용 영역을 기록하세요.

모델과 오차를 함께 해석

DivisionFit은 적합된 DivisionCamera 값과 rms_pixels를 묶는 불변 데이터 값입니다. 생성자는 camera가 DivisionCamera인지 확인합니다. 이 객체 자체를 만들었다는 사실만으로 원본 관측을 다시 적합하거나 새 카메라 측정을 수행하는 것은 아닙니다.

카메라 적합 경로에서는 알려진 양의 Z 카메라 광선과 대응 픽셀을 사용해 분할 왜곡 계수 k를 맞추고, 반환 RMS는 재투영 픽셀 오차를 요약합니다. 두 오차의 크기가 1과 3픽셀이라면 sqrt((1²+3²)/2), 약 2.24픽셀입니다. 관측 전체의 분포는 이 한 값에 압축됩니다.

camera는 후속 project 또는 pixel_to_ray 계산에 사용할 모델이고 rms_pixels는 적합 데이터에서의 품질 지표입니다. 작은 RMS가 보정 범위 밖의 역변환 유일성이나 다른 위치의 정확도를 보장하지 않으므로 관측 범위와 별도 검증점을 함께 기록합니다.

rms_pixels가 2라고 해도 모든 관측점의 오차가 정확히 2픽셀인 것은 아닙니다. 제곱 후 평균을 취해 제곱근을 계산하는 요약치이기 때문입니다. 넓은 영역의 투영에 쓸 모델이라면 점별 재투영 차이와 관측 위치를 별도로 확인해 큰 국소 오차가 숨겨지지 않았는지 살핍니다.
