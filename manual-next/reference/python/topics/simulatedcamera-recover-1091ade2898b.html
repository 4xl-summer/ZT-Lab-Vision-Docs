오류 상태에서 연결 상태로 복구합니다.

반환: None을 반환합니다.

오류: 현재 상태에서 허용되지 않는 전환은 오류입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

예를 들어 취득 중 오류 코드로 Faulted가 된 뒤 recover가 성공하면 Connected가 됩니다. 이때 큐가 다시 자동으로 채워지지는 않습니다. 필요한 경우 start를 호출하고 새 epoch의 트리거와 프레임을 다시 제공하세요. info의 fault code와 recoveries를 확인하면 전이를 판독할 수 있습니다.

Faulted 상태에서 Connected로 되돌리고 fault code를 0으로 초기화하며 recoveries 통계를 증가시킵니다. 취득은 자동으로 다시 시작되지 않으므로 다시 Acquiring이 필요하면 start를 별도로 호출합니다. 이는 실제 장비 자동 재접속이 아니라 호출자가 제어하는 모의 상태 전환입니다.

사용 조건과 결과 판독

recover는 모의 카메라가 Faulted일 때 Connected로 복구하고 fault code를 0으로 지우며 recoveries를 증가시킵니다. 허용 상태가 아닌 전환은 오류입니다. 이 객체는 호출자가 시간·이벤트·영상을 제공하는 시뮬레이터이며 실제 장치 재연결을 수행하지 않습니다.

예를 들어 취득 도중 fail로 Faulted가 된 다음 recover가 성공해도 상태는 Connected입니다. 다시 Acquiring이 필요하면 start를 별도로 호출합니다. start는 새 epoch를 시작하므로 이전 스트림의 마지막 프레임·틱·트리거 기준과 다음 스트림을 구분해야 합니다.

info 스냅샷에서 상태, fault code와 recoveries를 확인하고, 새 epoch에서 제공할 트리거와 프레임의 조건을 다시 맞추세요. 복구는 카메라 소유 객체를 해제하지 않습니다. 사용이 끝난 객체는 disconnect와 별개로 close하며 이미 꺼낸 프레임도 각자의 수명을 관리합니다.
