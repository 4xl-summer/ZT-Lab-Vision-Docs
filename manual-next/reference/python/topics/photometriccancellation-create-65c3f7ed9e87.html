반환: 별도로 close할 PhotometricCancellation 토큰입니다. 토큰을 닫는 것만으로 활성 작업이 취소되지는 않습니다.

이 호출의 입력과 객체 맥락

스레드 간 공유할 수 있는 일회성 협조 취소 토큰을 만듭니다. 제어형 연산에 전달하고 다른 흐름에서 cancel을 호출해 취소를 요청할 수 있습니다. 생성한 토큰은 소유 핸들이므로 사용 후 close합니다. close 자체는 진행 중인 작업을 취소하지 않으므로 취소 요청과 리소스 해제를 구분해야 합니다.

취소 요청과 자원 해제

create는 취소되지 않은 일회성 PhotometricCancellation 토큰을 반환합니다. 토큰은 광도 검사 작업에 전달할 수 있는 소유 핸들이며 생성 자체가 검사를 시작하지는 않습니다. 작업과 토큰을 사용할 범위를 정하고 사용 후 close 또는 with로 핸들을 정리합니다.

cancel은 공유된 상태에 협조적 중단을 요청합니다. 검사 측이 취소를 확인하는 지점에서 중단되므로 요청이 되었다는 사실과 작업이 이미 종료되었다는 사실은 다릅니다. 이미 취소된 토큰을 다시 초기 상태로 되돌리는 API는 없으므로 새 취소 상태가 필요하면 새 토큰을 만듭니다.

close는 토큰의 소유 핸들을 해제하지만 실행 중인 검사를 취소하는 명령이 아닙니다. 중단이 필요하다면 cancel을 명시하고 작업의 종료 결과를 확인한 뒤 토큰을 정리합니다. 시간 제한을 쓰는 제어형 검사에서는 취소와 시간 초과 상태도 별도로 처리합니다.

판독과 확인 사례

공유 토큰은 여러 흐름이 같은 취소 요청을 관찰할 수 있도록 쓰입니다. 토큰을 생성한 쪽과 검사를 실행하는 쪽이 수명을 조정하고, 취소를 요청한 뒤에도 검사 측이 종료 상태를 반환했는지 확인해야 합니다. 참조하는 핸들을 정리하는 일과 계산 결과를 판정하는 일은 별개입니다.

시간 제한을 함께 쓰는 경우에는 제한시간에 의한 종료와 외부 cancel 요청을 구분해 기록합니다. 어느 쪽이든 완료된 측정 결과가 없을 수 있으므로 사용 가능한 결과를 받았는지 확인한 다음 후속 검사를 진행합니다. 재실행에는 해당 실행에 맞는 새 토큰과 입력을 준비합니다.
