add_measured_circle(self, id, spec, options, frame=None)

영상에서 프로브로 측정할 원을 추가합니다.

확인된 인자 조건

id: 형상 식별자.

spec: MeasurementCircleSpec.

options: MeasurementProbeOptions; 추가 시 복사.

frame: 이전 fixture 인덱스 또는 None.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • frame · POSITIONAL_OR_KEYWORD · 기본값 None

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Add an image-measured circle or circular arc.

추가와 실행 결과

복합 모델에 영상에서 측정할 원 형상을 추가합니다. 형상 ID와 fixture 로컬 기준 기하를 지정하고 탐색 및 적합 설정을 함께 전달합니다. frame이 지정되면 해당 fixture 기준을 확인하고, 없을 때와 서로 다른 기준의 좌표를 혼합하지 마십시오. 추가 시 설정이 복사되므로 이후 원래 설정 객체를 바꾼 사실을 이미 추가된 구성의 변경으로 가정하지 않습니다. 기준 원호에서 찾은 점이 충분한 각도 범위에 분포하는지 확인하십시오. 반환한 형상 인덱스와 ID를 보관하고 실행 후 관측 상태와 적합 결과를 따로 확인하십시오.
