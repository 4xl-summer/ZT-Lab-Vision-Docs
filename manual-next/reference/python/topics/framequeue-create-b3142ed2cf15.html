FrameQueue.create 공개 계약

상위 목차로 돌아가기

create

classmethod · 선언 타입 zvision._frame_queue.FrameQueue

Python
create(cls, capacity, policy)

독립된 제한 용량 영상 큐를 만듭니다.

확인된 인자 조건

capacity: 1–65536의 큐 용량입니다.

policy: 가득 찼을 때의 FrameQueuePolicy입니다.

반환: 호출자가 닫아야 하는 FrameQueue입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • capacity · POSITIONAL_OR_KEYWORD · 기본값 없음
  • policy · POSITIONAL_OR_KEYWORD · 기본값 없음

capacity: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

용량 1~65536의 독립 FIFO 큐를 만들고 가득 찼을 때의 정책을 지정합니다. REJECT_NEW는 새 항목을 거부하고 DROP_OLDEST는 가장 오래된 항목을 제거한 뒤 추가하며 WAIT는 제한 시간 동안 공간을 기다립니다. 반환된 큐는 소유 객체이므로 사용 후 close합니다. 카메라를 열거나 백그라운드로 영상을 취득하는 기능은 아닙니다.
