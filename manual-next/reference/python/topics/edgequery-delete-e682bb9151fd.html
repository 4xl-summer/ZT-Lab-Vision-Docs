delete(self, label)

레이블의 에지를 영구적으로 삭제합니다.

확인된 인자 조건

label: 양의 에지 레이블입니다.

반환: None을 반환합니다.

오류: 존재하지 않는 레이블은 오류입니다.

인자 선언

  • label · POSITIONAL_OR_KEYWORD · 기본값 없음

Permanently delete a stable edge label.

이 호출의 입력과 객체 맥락

안정된 양의 label에 해당하는 에지를 영구 삭제합니다. 임시 제외를 다시 포함하는 set_included와 구분해야 합니다. 삭제 뒤에는 포함 목록의 조밀 인덱스가 달라질 수 있으므로 다른 에지의 인덱스를 다시 조회하세요. 이 메서드는 쿼리 객체 전체를 해제하는 close와도 별개입니다.
