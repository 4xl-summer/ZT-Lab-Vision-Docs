RegistrationGraphInfo(matrix: tuple, valid_count: int) -> None

Common-to-image homography and number of valid aligned pixels.

matrix: 공통 로컬에서 해당 영상 로컬로 가는 행 우선 호모그래피 계수.

valid_count: 정합 영상의 유효 보간 픽셀 수.

이 호출의 입력과 객체 맥락

RegistrationGraphInfo는 다중 정합에서 공통 좌표계에서 각 영상으로 가는 호모그래피와 유효 정렬 픽셀 수를 담습니다. matrix의 방향을 영상에서 공통 좌표계로 가는 역변환으로 임의 해석하면 위치가 달라집니다. valid_count는 유효한 정렬 픽셀의 개수이며 정합 점수나 오류 확률이 아닙니다.

예를 들어 공통 출력이 100×100 픽셀이고 한 영상의 valid_count가 8000이라면 10000개 중 8000개의 위치가 유효하게 샘플링되었다는 의미입니다. 이 개수만으로 해당 영상이 정확히 정합되었다는 보장은 없습니다. 행렬 방향과 함께 겹침 영역 및 별도의 정합 품질을 확인하고 영상 크기를 비교 기준에 포함하세요.

사용 순서와 결과 확인

RegistrationGraphInfo는 공통 로컬 좌표에서 해당 영상 로컬 좌표로 가는 호모그래피와 유효 보간 픽셀 수를 담습니다. matrix는 행 우선 계수이며 방향을 거꾸로 해석하면 같은 좌표가 다른 위치로 이동합니다.

예를 들어 공통 출력이 100×100이면 전체 10000픽셀입니다. valid_count가 8000이라면 해당 영상에서 유효하게 샘플링된 위치가 8000개라는 뜻으로, 이 단순 비율은 8000/10000=0.8입니다. 전체 유효 개수와 정합의 정확도는 서로 다른 판단입니다.

각 영상의 matrix를 서로 바꾸어 연결하지 말고 해당 영상 식별자와 공통 캔버스의 기준을 함께 기록하십시오. valid_count가 높아도 영상 내용의 정렬 오차가 없다고 단정할 수 없으므로 겹침 영역의 정합 품질을 별도로 확인합니다.
