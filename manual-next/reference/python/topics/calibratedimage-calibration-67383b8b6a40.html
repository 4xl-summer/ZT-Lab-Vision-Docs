calibration(self)

연결된 평면 보정 값을 복사해 읽습니다.

반환: PlanarCalibration 값 또는 보정이 제거되었으면 None.

오류: 닫힌 핸들은 오류.

Copy the planar calibration, or None if explicitly discarded.

사용과 결과 판독

이미지에 연결된 평면 보정을 복사해 조회합니다. 보정이 제거된 경우는 None 또는 null이며 이 상태를 항등 보정으로 대체하면 픽셀과 세계 좌표가 같다는 잘못된 가정이 됩니다. 보정이 있는 경우 글로벌 픽셀에서 세계 평면으로 가는 방향과 저장된 단위를 확인하십시오. 이미지의 ROI 로컬 점은 글로벌 원점을 반영한 다음 매핑해야 합니다.

단계별 확인

연결된 평면 보정이 있는 경우 복사한 값을 얻고 제거된 경우 None을 받습니다. 보정 없음은 변환이 필요 없다는 뜻이나 항등 호모그래피가 자동으로 지정됐다는 뜻이 아닙니다.

보정이 있으면 입력 좌표가 글로벌 영상 픽셀인지와 세계 길이 단위를 확인하십시오. ROI 로컬 (10,20)에 원점 (100,200)을 더하면 글로벌 (110,220)입니다. 닫힌 이미지에서의 조회 오류와 보정이 없는 정상 상태도 구별해야 합니다.

항목확인할 내용
조회이미지에 연결된 보정의 복사본을 요청합니다.
보정 존재글로벌 픽셀→세계 평면의 방향을 확인합니다.
None보정이 제거된 상태이며 항등 변환이 아닙니다.
ROI로컬 점에 글로벌 원점을 먼저 더합니다.
수명복사 값과 이미지 핸들의 수명 계약을 구별합니다.
실패닫힌 핸들의 오류와 보정 없음을 구분합니다.

보정 복사본이 반환되더라도 현재 영상의 ROI 로컬 좌표를 자동으로 글로벌 좌표라고 볼 수는 없습니다. 결과를 사용할 때 이미지의 실제 원점과 보정이 학습한 영상 기준이 같은지 확인하고, 보정이 없으면 후속 세계 좌표 계산을 수행할 수 있는 다른 근거를 준비해야 합니다.
