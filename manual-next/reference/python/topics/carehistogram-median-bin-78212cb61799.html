median_bin

method · 선언 타입 zvision._masked_gap.CareHistogram

Python
median_bin(self, channel=0)

낮은 중앙값 빈 인덱스를 계산합니다.

확인된 인자 조건

channel: 0 기반 채널 인덱스; 기본값 0

반환: 정수 빈 인덱스입니다.

오류: 채널이 유효하지 않으면 오류입니다.

인자 선언

  • channel · POSITIONAL_OR_KEYWORD · 기본값 0

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

중앙값의 빈 찾기

선택 채널의 낮은 중앙값 빈 인덱스를 반환합니다. channel 기본 0은 첫 채널이고 다른 채널을 원하면 0 기반 인덱스를 명시합니다. 잘못된 채널은 오류입니다.

의미 있는 비교

중앙 빈은 각 표본의 공간 위치가 아니라 값 분포의 중심을 요약합니다. 빈의 폭과 하한이 다른 결과에서 같은 인덱스는 다른 밝기 구간이므로 설정과 마스크를 함께 기록합니다.
