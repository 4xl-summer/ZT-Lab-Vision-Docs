from_parts(cls, width, height, real, imaginary, normalization=<FftNormalization.BACKWARD: 0>)

외부 실수부와 허수부의 스냅샷으로 스펙트럼을 만듭니다.

확인된 인자 조건

width: 양의 스펙트럼 너비입니다.

height: 양의 스펙트럼 높이입니다.

real: 너비×높이 개수의 유한한 실수부 값입니다.

imaginary: 너비×높이 개수의 유한한 허수부 값입니다.

normalization: FftNormalization이며 기본값은 BACKWARD입니다.

반환: 호출자가 닫아야 하는 GeneralSpectrum입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • real · POSITIONAL_OR_KEYWORD · 기본값 없음
  • imaginary · POSITIONAL_OR_KEYWORD · 기본값 없음
  • normalization · POSITIONAL_OR_KEYWORD · 기본값 <FftNormalization.BACKWARD: 0>

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Create a spectrum from finite independent real and imaginary arrays.

이 호출의 입력과 객체 맥락

행 우선 실수부와 허수부를 너비·높이와 정규화 방식과 함께 복사해 새 스펙트럼을 만듭니다. 예를 들어 2×3 스펙트럼이면 각 배열의 좌표를 같은 행 우선 순서로 대응시켜야 합니다. 입력 배열과 반환 모델은 별도로 관리하며, 복소 역변환 결과가 필요할 때 inverse_complex를 사용합니다. 반환 모델은 소유 객체입니다.
