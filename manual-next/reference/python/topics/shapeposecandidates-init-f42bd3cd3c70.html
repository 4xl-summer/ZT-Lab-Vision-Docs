ShapePoseCandidates(poses: tuple, rms_pixels: float, continuous_rotation: bool) -> None

Candidate camera<-target poses and explicit in-plane ambiguity.

poses: 타깃 프레임에서 카메라 프레임으로의 강체 자세 후보 튜플입니다.

rms_pixels: 대응 픽셀의 재투영 RMS입니다.

continuous_rotation: 평면 내 회전이 연속적으로 식별되지 않는지 나타냅니다.

값을 구성하고 해석하기

평면 형상으로부터 얻은 가능한 자세들과 재투영 잔차 및 연속 회전 모호성 정보를 담는 값입니다. poses를 검사하기 전에 후보가 존재하는지 확인하고 rms_pixels는 영상 픽셀 단위의 오차로 해석합니다. continuous_rotation은 관측 형상이 특정 회전을 유일하게 결정하지 못하는 상황을 표시합니다.
