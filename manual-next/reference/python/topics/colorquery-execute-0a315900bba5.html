execute(self) -> 'QueryResourceExecution[ColorPlanesResult]'

지연 색상 계획을 실행합니다.

반환: QueryResourceExecution이며 acquire_output으로 얻은 ColorPlanesResult와 실행을 각각 close합니다.

오류: 닫힌 계획 또는 네이티브 실행 실패는 오류입니다.

반환 타입 주석: QueryResourceExecution[ColorPlanesResult]

Execute; acquire_output returns independently owned color planes.

색 평면 계획의 실행

색 변환 쿼리를 실행하고 QueryResourceExecution을 반환합니다. acquire_output으로 얻는 ColorPlanesResult는 독립 소유 결과이므로 실행 객체와 별도로 닫아야 합니다.

획득한 색 평면의 채널은 원본 RGB와 다른 공간의 수치입니다. 예를 들어 Lab은 L, a, b의 순서로 해석하고 비교 샘플의 백색점과 입력 전달 함수를 맞춥니다.

쿼리 계획을 분기하려면 실행 전에 clone을 사용합니다. 쿼리, 실행 객체, 획득한 평면 결과 및 추가로 얻은 영상은 각각의 소유 관계에 따라 정리합니다. 잘못된 입력의 오류는 빈 평면이 아닙니다.
