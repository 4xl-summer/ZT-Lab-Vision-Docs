from_buffer_grayf32

classmethod · 선언 타입 zvision.ZImage

Python
from_buffer_grayf32(cls, width, height, pixels)

네이티브 바이트 순서의 GrayF32 버퍼를 복사하여 영상을 만듭니다.

확인된 인자 조건

width: 양의 픽셀 폭

height: 양의 픽셀 높이

pixels: 행 우선 네이티브 바이트 순서의 GrayF32 버퍼; 폭×높이×1개 성분

반환: 별도로 close할 ZImage입니다.

오류: 크기·성분 수·형식 또는 값 범위가 잘못되면 오류입니다.

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음

Copy a packed native-endian float32 buffer into an image.

부동소수 버퍼의 복사

네이티브 바이트 순서의 GrayF32 버퍼에서 행 우선 표본을 복사합니다. 폭 2, 높이 2는 4개의 32비트 부동소수 표본입니다. 값의 숫자 목록과 원시 바이트 버퍼는 다른 입력 표현이므로 호출의 요구 형식을 확인합니다.

형식과 결과

width와 height는 양의 픽셀 크기이고 pixels는 네이티브 바이트 순서의 버퍼입니다. 바이트 순서나 표본 크기가 다르면 원하는 값으로 해석되지 않을 수 있습니다. 반환 영상의 형식과 작은 입력의 값을 대조하고 사용 후 close합니다.
