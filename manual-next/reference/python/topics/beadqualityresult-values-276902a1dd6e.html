values(self, index)

탐침별 측정값을 지정 인덱스로 복사합니다.

확인된 인자 조건

index: 0 밝기, 1 커버리지 비율, 2 측정 폭, 3 기준 폭.

반환: 값이 없는 탐침은 None인 독립 튜플입니다.

오류: 닫힌 결과 또는 인덱스 범위 오류가 발생할 수 있습니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

index: 정수 검사 · 최소 0.

0 intensity, 1 coverage ratio, 2 measured width, 3 reference width; missing probes are None.

사용과 결과 판독

탐침별 값은 인덱스에 따라 밝기, 커버리지, 측정 폭 또는 기준 폭을 뜻합니다. 값이 없는 탐침은 None이므로 실제 폭 0으로 바꾸지 마십시오. 프로브의 순서와 값을 함께 기록해야 누락 위치를 추적할 수 있습니다.
