RotatedRect(center: zvision._regions.Point2, width: float, height: float, angle: float) -> None

RotatedRect(center: zvision._regions.Point2, width: float, height: float, angle: float)

center: 사각형 중심 좌표입니다.

width: 사각형 장축의 길이입니다.

height: 사각형 단축의 길이입니다.

angle: 장축 방향 각도입니다.

이 호출의 입력과 객체 맥락

이 값은 중심 Point2, 폭과 높이, 각도로 사각형을 표현합니다. 중심의 좌표계와 폭·높이의 단위는 이 값을 생성하는 연산의 입력 기준을 따릅니다. 축에 평행한 경계 상자의 폭과 높이를 그대로 이 회전 사각형의 두 변 길이로 해석하면 회전된 물체에서 다른 결과가 나올 수 있습니다.

예를 들어 중심이 (10, 20)이고 폭과 높이가 각각 6과 2인 사각형은 중심을 기준으로 서로 직교하는 두 방향의 반길이가 각각 3과 1입니다. 각도는 그 방향을 결정합니다. 각도의 단위와 회전 방향은 생성 API의 계약을 확인해야 하며 이름만 보고 도 또는 라디안을 선택하지 않습니다.

값의 구성과 좌표계

RotatedRect는 center, width, height, angle을 담는 불변 데이터 값입니다. 이 생성자는 center가 Point2인지 확인합니다. 폭과 높이, 각도의 수치 유효성이나 폭이 높이보다 큰지까지 이 생성자에서 검증한다고 가정하지 마십시오. 값을 사용하는 연산의 조건과 단위를 별도로 확인해야 합니다.

예를 들어 중심 (10,20), 폭 6, 높이 2이면 각 변의 반길이는 3과 1입니다. 회전 각도에 따라 두 변의 방향이 달라지므로 회전된 사각형의 변 길이와 축에 평행한 경계 상자 크기를 같은 것으로 볼 수 없습니다. center가 ROI 로컬인지 전체 좌표인지도 이 값을 만든 연산의 계약을 따라야 합니다.
