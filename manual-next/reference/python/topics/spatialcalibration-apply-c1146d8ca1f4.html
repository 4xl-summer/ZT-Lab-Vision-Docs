픽셀별 공간 깊이 보정 적용

보정 모델이 각 픽셀의 계수로 깊이를 보정합니다. 입력 영상의 크기와 단위가 모델과 맞아야 하며 각 위치에 저장된 다항식의 계수를 그 위치에 적용합니다. 결측 깊이는 결측으로 남고 출력 영상은 입력 격자의 메타데이터를 유지합니다.

한 셀의 계수가 a=1, b=2, c=0이고 입력이 4이면 보정 결과는 9입니다. 이 계산은 각 픽셀의 계수가 서로 다를 수 있으므로 한 픽셀의 보정값을 영상 전체에 적용하는 전역 선형 모델과 구분합니다. 적용 전 보정 데이터와 대상의 영상 크기와 단위를 먼저 비교합니다.
