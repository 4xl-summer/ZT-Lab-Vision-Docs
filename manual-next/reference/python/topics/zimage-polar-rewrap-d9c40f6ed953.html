polar_rewrap(image, options, width, height, origin_x=0, origin_y=0, revolution=0)

극좌표 영상의 선택 회전을 직교 캔버스로 재표본화합니다.

확인된 인자 조건

image: 극좌표 ZImage

options: PolarOptions

width: 양의 출력 폭

height: 양의 출력 높이

origin_x: 출력 x 원점; 기본값 0

origin_y: 출력 y 원점; 기본값 0

revolution: 선택 회전 번호; 기본값 0

반환: 별도로 close할 ZImage입니다.

오류: 설정이나 출력 범위가 유효하지 않으면 오류입니다.

극좌표 결과를 직교 격자로 되돌리기

이 호출은 각도와 반경이 축인 입력 영상을 지정한 직교 캔버스로 다시 표본화합니다. 입력의 너비와 높이는 원래 극좌표 설정의 출력 너비·높이와 같아야 합니다. 복원할 캔버스의 width와 height는 별도 인자이며 둘 다 양수입니다. 원본 영상의 크기를 설정과 대조하지 않고 무조건 같은 크기의 이미지를 반환한다고 생각하면 입력 기하를 잘못 해석할 수 있습니다.

options의 중심과 반경은 직교 영상의 ROI 로컬 픽셀 기준이고 각도는 라디안입니다. revolution은 각도 범위에서 선택할 한 바퀴 분기를 나타냅니다. 같은 위치가 여러 회전에 나타날 수 있으므로 선택한 분기를 기록해야 하며, 그 분기에서 대응할 위치를 찾을 수 없는 출력 좌표는 설정의 경계 규칙을 따릅니다.

origin_x와 origin_y는 새 직교 결과에 지정하는 원점이며 기본값은 각각 0입니다. 예를 들어 둘 다 기본값인 경우 반환 영상 원점은 (0, 0)입니다. 극좌표 영상을 펼치기 전 원본의 원점이 자동으로 복원된다고 가정하지 말고 필요한 원점을 명시해야 합니다. 보간으로 다시 표본화하므로 unwrap과 rewrap을 연속 적용해도 모든 원본 픽셀이 정확히 복원된다는 보장은 없습니다.
