CMC 색차와 가중 계수를 선택합니다.

확인된 인자 조건

lightness: 명도 가중 계수

chroma: 채도 가중 계수

반환: 불변 ColorDistance 설정입니다.

  • lightness · POSITIONAL_OR_KEYWORD · 기본값 없음

인자형식역할과 조건
lightness명도 가중 계수
chroma채도 가중 계수

CMC 색 거리 선택

lightness와 chroma 두 매개변수로 CMC 거리 방식을 구성합니다. 두 수치는 색차의 명도와 채도 관련 가중 조건을 전달하며 이 호출은 설정 값만 만듭니다.

색차 허용치를 정할 때 사용한 가중치와 같은 설정으로 실제 입력을 비교해야 합니다. 다른 척도의 수치와 동일 기준을 쓰기 전에 해당 기준을 검증합니다.
