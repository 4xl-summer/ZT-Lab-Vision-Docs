Independent surface defect snapshot.

defects: 성분별 결함 종류, 영역, 로컬 좌표와 점수를 담은 독립 불변 튜플입니다.

입력과 결과 해석

SurfaceDefectsResult의 생성 인자는 다음 조건으로 해석합니다. 성분별 결함 종류, 영역, 로컬 좌표와 점수를 담은 독립 불변 튜플입니다.

인자선언 타입기본값의미와 조건
defects'tuple[SurfaceDefect, ...]'필수성분별 결함 종류, 영역, 로컬 좌표와 점수를 담은 독립 불변 튜플입니다.

결함 목록의 각 항목은 종류와 면적, 위치 및 형상 정보를 함께 읽어야 합니다. 후보가 없다는 것은 목록이 비어 있다는 뜻이며 전체 검사 판정이나 실행 오류와 자동으로 같은 의미는 아닙니다. 각 결함 좌표의 영상 ROI 기준을 기록하십시오.

입력과 결과 확인

SurfaceDefectsResult는 성분별 결함을 담은 독립 불변 튜플을 보관합니다. defects의 각 SurfaceDefect에는 종류, 면적, 경계, 중심과 형상·점수 정보가 있으므로 목록 길이만으로 모든 판정을 대신할 수 없습니다. 이 생성 자체는 영상을 다시 분석하지 않습니다.

예를 들어 후보가 두 개라면 하나의 큰 영역인지 두 개의 분리된 성분인지 각각의 면적과 경계를 확인해야 합니다. 두 후보의 합계 면적과 개별 최대 면적은 서로 다른 판정 조건이 될 수 있습니다. 좌표는 결함이 추출된 영상의 ROI 기준으로 기록하십시오.

빈 튜플은 저장된 후보가 없다는 값이며 실행 오류 또는 전체 검사 합격과 자동으로 같은 뜻이 아닙니다. 판정 단계가 필요한 경우 결함 목록과 허용치 설정을 함께 전달하고, 불변 스냅샷을 만든 원본 프레임과 설정을 보관해야 결과를 재현할 수 있습니다.

면적개별 후보와 합계의 의미를 구분합니다.
좌표경계·중심의 ROI 로컬 기준을 보존합니다.
빈 목록후보 없음과 실행 실패를 구별합니다.
후속 판정허용치에 따른 합격 판단은 별도입니다.

예를 들어 두 결함 면적이 3과 5픽셀이면 총 면적은 8이지만 개별 최대 면적은 5입니다. 전체 면적 기준과 한 결함의 면적 기준은 따라서 다른 조건입니다. 표면 분류는 후보 형상에 기반한 결과이므로 종류만으로 왜 결함이 생겼는지까지 판단하지 마십시오. 각 경계와 중심은 입력의 ROI 로컬 기준이며 원본 영상에 표시하려면 해당 원점과 연결해야 합니다.

한 후보의 경계가 ROI 밖인지 판단할 때는 경계가 어느 로컬 영역을 기준으로 하는지 함께 확인해야 합니다. 결함 스냅샷의 좌표를 글로벌 영상에 표시하려면 ROI 원점을 반영합니다.
