execute(self) -> 'QueryExecution[float]'

종료 계획을 실행해 타입 지정 결과를 얻습니다.

반환: close할 실행 객체와 독립 값 스냅샷입니다.

오류: 연산이 실패하면 오류입니다.

반환 타입 주석: QueryExecution[float]

계획을 실행하고 불변 결과를 반환한다.

Otsu 임계값 실행

계획을 실행해 QueryExecution[float]의 임계값을 얻습니다. 숫자는 현재 계획의 영상 분포를 바탕으로 선택되므로 원본과 전처리된 영상의 값이 다를 수 있습니다. 이 결과 자체는 이진 마스크가 아닙니다.

값 사용

실행 객체를 닫기 전에 결과를 읽고 입력 형식과 ROI를 기록합니다. 선택값을 적용한 마스크가 원하는 대상을 분리하는지 원본과 겹쳐 검증합니다. 계획이 유효해 보여도 실제 실행이 실패할 수 있습니다.
