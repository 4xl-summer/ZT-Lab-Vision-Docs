find_min_contrast(self, source, options, min_contrast, mask=None)

유효 영역의 평균 기울기 조건을 만족하는 형상만 검색합니다.

확인된 인자 조건

source: 검색 영상입니다.

options: 형상 검색 설정입니다.

min_contrast: 유한한 비음수 최소 대비입니다.

mask: 선택 검색 마스크입니다.

반환: 독립 매치 결과와 종료 진단입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_contrast · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

Search subject to a minimum mean gradient.

호출 맥락과 결과 해석

형상 후보의 유효 영역에서 평균 기울기가 지정한 최소 대비 조건을 만족하는지 반영해 검색합니다. min_contrast는 유한한 비음수이며 영상의 에지 강도 조건입니다. 매치 점수 하한과는 서로 다른 역할을 하므로 두 값을 혼동하지 않습니다.

조명이 낮거나 경계가 희미한 영상에서 기준을 올리면 후보가 줄 수 있습니다. 기존 검색 옵션과 입력을 고정하고 최소 대비만 바꾸어 매치 목록과 종료 상태를 비교하면 대비 조건이 결과에 미치는 영향을 분리할 수 있습니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options형상 검색 설정입니다.
min_contrast유한한 비음수 최소 대비입니다.
mask선택 검색 마스크입니다.
