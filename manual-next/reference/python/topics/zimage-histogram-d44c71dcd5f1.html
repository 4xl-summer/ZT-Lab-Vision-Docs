histogram

method · 선언 타입 zvision.ZImage

Python
histogram(self, bin_count: int, lower: float, upper: float) -> list

채널별 값 분포를 계산합니다.

확인된 인자 조건

bin_count: 히스토그램 빈 수

lower: 유한 하한

upper: 하한보다 큰 유한 상한

반환: 채널별 빈 카운트 list입니다.

오류: 유효하지 않은 히스토그램 범위 또는 형식은 오류입니다.

인자 선언

  • bin_count · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • lower · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • upper · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음

반환 타입 주석: list[list[int]]

래퍼에서 발생 가능한 오류: OverflowError. 네이티브 오류는 별도입니다.

Count visible values in channel-major bins, including alpha.

픽셀 값의 빈도

히스토그램은 값 구간별 픽셀 수를 집계합니다. 예를 들어 0과 100이 하나씩 있는 영상과 50이 두 개인 영상은 평균이 같지만 분포가 다릅니다. 빈 수와 범위가 달라지면 같은 빈 인덱스의 의미도 달라집니다.

영역과 채널

입력 형식, 분석 ROI와 채널 순서를 확인하고 결과 빈을 해당 범위와 함께 읽습니다. 히스토그램은 픽셀의 공간 위치를 보존하지 않으므로 같은 분포라도 서로 다른 형상의 영상이 가능합니다. 위치 판정에는 마스크나 원본 영상도 필요합니다.
