close(self)

결과가 소유한 영상 핸들을 해제합니다.

반환: None입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

반복 연산 결과의 image 핸들을 닫습니다. iterations, removed, converged는 결과에 저장된 숫자·bool 값이며 image 자체와 수명이 다릅니다. 먼저 반복 횟수와 수렴 여부를 확인하고 필요한 영상 처리를 끝낸 다음 close하세요. with 블록을 사용하면 종료 시 close가 호출됩니다. 닫은 image 핸들로 새 처리를 시작하지 마세요.

이 객체의 확인된 공개 생성 경로: IterationResult(image: zvision.ZImage, iterations: int, removed: int, converged: bool) -> None.

사용 조건과 결과 판독

IterationResult는 반복 영상 연산의 image와 iterations, removed, converged를 함께 담습니다. close는 결과에 들어 있는 image 핸들을 닫습니다. 숫자·bool 보고 값과 영상 핸들은 역할이 다르므로 먼저 결과를 판독하고 필요한 영상 작업을 마친 뒤 수명을 정리하세요.

예를 들어 iterations=12, converged=true이면 실제로 12번 수행해 정지 조건에 도달했다는 보고입니다. removed는 제거된 양의 보고이며 이 세 값만으로 결과 영상의 각 픽셀을 복원할 수 없습니다. 필요한 픽셀 데이터는 image가 열린 동안 읽거나 별도의 소유권 계약에 따라 확보해야 합니다.

with 블록으로 IterationResult를 사용하면 블록 종료 시 close가 호출됩니다. 닫힌 image 핸들로 새 처리를 시작하지 말고, 결과가 미리 보관한 숫자 값인지 영상 핸들인지 구분하세요. 생성자에 필드 값을 넣는 것과 실제 반복 연산을 실행하는 것도 별개입니다.

예를 들어 반복 상한을 100으로 정한 작업이 12회에서 converged=true로 끝났다면 보고된 iterations는 실제 수행 횟수 12입니다. 이 정보는 결과 영상을 보지 않고도 기록할 수 있지만, 어느 픽셀이 제거됐는지는 image를 확인해야 합니다. 사용이 끝나면 이 결과의 close가 그 image를 닫으므로 후속 영상 처리는 닫기 전에 마칩니다.
