inspect_quality_units(self, training, image, options, mode, fill_left=None, fill_right=None, world=None, world_maps=None)

훈련 기준과 현재 비드의 폭·명암·점유율·에지 변화를 비교합니다.

확인된 인자 조건

training: 학습에 사용된 기준 ZImage

image: 검사 ZImage

options: BeadQualityOptions

fill_left: 탐침별 왼쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None

fill_right: 탐침별 오른쪽 에지 대체 허용 bool 시퀀스 또는 None; 기본값 None

world: 선택적 6개 아핀 계수; 기본값 None

world_maps: 선택적 세계 좌표 영상 2개; 기본값 None, world와 동시 사용 불가

mode: 픽셀 또는 세계 좌표 모드; 세계 모드는 보정 필요

반환: 별도로 close할 BeadQualityResult입니다.

오류: 영상, 옵션·대체 배열 또는 상호 배타적인 세계 보정이 유효하지 않으면 오류입니다.

  • training · POSITIONAL_OR_KEYWORD · 기본값 없음
  • image · POSITIONAL_OR_KEYWORD · 기본값 없음

  • mode · POSITIONAL_OR_KEYWORD · 기본값 없음

  • world_maps · POSITIONAL_OR_KEYWORD · 기본값 None

Width and center tolerances use selected units; returned edge points remain ROI-local pixels.

좌표 단위를 지정한 품질 검사

mode로 좌표 단위를 명시해 비드 품질을 검사합니다. 폭과 중심 허용치는 선택한 단위를 사용하지만 반환된 에지 점은 ROI 로컬 픽셀 좌표로 남습니다.

world와 world_maps 중 선택한 매핑이 모드와 맞는지 확인합니다. 같은 결과의 길이와 에지 좌표가 서로 다른 단위를 가질 수 있으므로 표시 및 기록할 때 각각의 단위를 명시합니다. 소유 결과는 close합니다.
