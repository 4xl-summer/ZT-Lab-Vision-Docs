classmethod · 선언 타입 zvision._frequency_processing.FrequencySpectrum

Python
forward(cls, image, options)

영상을 radix-2 스펙트럼으로 변환합니다.

확인된 인자 조건

image: Gray8, Gray16 또는 유한한 GrayF32 ZImage

options: FftOptions; 각 크기는 입력 이상인 2의 거듭제곱

반환: 별도로 close할 스펙트럼입니다.

오류: 형식·크기 또는 4194304 픽셀 제한 위반은 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Legacy factory retained through 0.1.x; prefer image.fft(options).

정변환과 격자

입력 영상과 FFT 설정으로 독립 스펙트럼을 만듭니다. 변환 격자의 폭과 높이는 입력 이상인 2의 거듭제곱이어야 하며 정규화는 중간 복소값의 크기에 영향을 줍니다. 2×2의 모든 값이 1인 입력은 BACKWARD 정규화에서 직류 성분이 4입니다.

수명과 검증

입력 형식과 FftOptions를 확인하고 결과의 실제 격자 및 정규화를 기록합니다. 결과 FrequencySpectrum은 별도 소유 객체로 사용 후 닫습니다. 역변환 시 동일한 배율 규칙을 사용해야 입력 값의 크기를 올바르게 비교할 수 있습니다.
