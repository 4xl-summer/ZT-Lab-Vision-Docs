edge_optimized

method · 선언 타입 zvision._multi_registration.MultiRegistration

Python
edge_optimized(self, index)

선택한 방향 에지가 최적화되었는지 확인합니다.

확인된 인자 조건

index: 0부터 시작하는 에지 인덱스입니다.

반환: 최적화 여부 bool입니다.

오류: 범위 밖 인덱스나 닫힌 결과는 오류입니다.

인자 선언

  • index · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Return whether the directed edge was optimized rather than fixed.

이 호출의 입력과 객체 맥락

0 기반 에지 index가 최적화되었는지 bool로 확인합니다. 이미지 index와 에지 index를 혼동하지 마세요. 결과가 False라는 사실만으로 에지 품질의 숫자 값을 만들지 않고 edge_quality의 반환 여부도 함께 확인합니다. MultiRegistration 객체는 사용 후 close합니다.
