BoundedTemplateOptions(x_min: int, x_max: int, y_min: int, y_max: int, threshold: float, max_matches: int = 1, max_work: int = 1000000, contrast_range: tuple[float, float] | None = None, brightness_range: tuple[float, float] | None = None) -> None

Inclusive source-local integer bounds; threshold, optional contrast/brightness ratios, output and scalar work limits.

x_min: 검색 영상 로컬에서 템플릿 좌상단 x의 포함 하한(정수 픽셀)입니다.

x_max: 좌상단 x의 포함 상한이며 x_min 이상이어야 하고 템플릿이 영상 안에 들어가야 합니다.

y_min: 검색 영상 로컬에서 템플릿 좌상단 y의 포함 하한(정수 픽셀)입니다.

y_max: 좌상단 y의 포함 상한이며 y_min 이상이어야 하고 템플릿이 영상 안에 들어가야 합니다.

threshold: 유한한 판정값입니다. 색 NCC는 −1..1의 하한, Gray SAD는 0..255의 상한입니다.

max_matches: 반환 상한이며 1..256입니다. 기본값은 1입니다.

max_work: 작업량 상한으로 1..100000000이며 기본값은 1000000입니다. 후보 수 × 선택 표본 수 × 채널 수 × 2가 이를 넘으면 오류입니다.

contrast_range: 후보/모델 표준편차 비율의 선택적 포함 범위 (최소, 최대)입니다. 두 값은 유한하고 0 이상이며 순서대로여야 합니다. 기본값 None은 필터를 끕니다.

brightness_range: 후보/모델 평균 비율의 선택적 포함 범위 (최소, 최대)입니다. 두 값은 유한하고 0 이상이며 순서대로여야 합니다. 기본값 None은 필터를 끕니다.

값을 구성하고 해석하기

정수 평행이동 템플릿 검색의 포함 범위와 판정 및 작업 한도를 표현합니다. x_min과 x_max, y_min과 y_max는 검색 영상 로컬의 템플릿 좌상단 좌표이며 양 끝을 포함합니다. 색 NCC의 threshold는 하한이고 Gray SAD의 threshold는 상한이므로 metric에 맞게 해석합니다.
