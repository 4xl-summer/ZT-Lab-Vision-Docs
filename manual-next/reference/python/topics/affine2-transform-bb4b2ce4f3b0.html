transform

method · 선언 타입 zvision._calibration.Affine2

Python
transform(self, point)

행렬로 한 점을 변환합니다.

확인된 인자 조건

point: Point2 입력 점.

반환: 변환된 새 Point2 값.

오류: 잘못된 타입, 비유한 입력 또는 유효하지 않은 변환은 오류.

인자 선언

  • point · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

이 호출의 입력과 객체 맥락

이 호출은 Point2 한 점에 저장된 2×3 계수를 적용합니다. 계산은 x′ = a×x + b×y + tx, y′ = c×x + d×y + ty입니다. 예를 들어 선형 부분이 단위 행렬이고 이동이 (3, 4)이면 입력 (10, 20)은 (13, 24)로 갑니다. 반환값은 새로운 Point2 값이며 이미지 픽셀 배열을 바꾸는 워프가 아닙니다. 입력 점과 계수는 연산에 전달할 때 유한해야 하며, ROI 로컬 픽셀인지 전체 프레임 좌표인지와 같은 기준을 호출자가 맞춰야 합니다.

이 객체의 확인된 공개 생성 경로: Affine2(a: float, b: float, tx: float, c: float, d: float, ty: float) -> None.
