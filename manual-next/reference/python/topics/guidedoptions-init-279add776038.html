radius: 국소 평균 창 반경입니다.

epsilon: 유한하고 양수인 분산 정규화 계수입니다.

border: 경계 방식 코드이며 기본값 0입니다.

constant: 상수 경계의 값이며 기본값 0입니다.

output_format: 출력 픽셀 형식 코드이며 기본값 GrayF32입니다.

이 호출의 입력과 객체 맥락

guided_filter에 넘길 국소 창과 정규화, 경계 및 출력 형식을 묶습니다. radius는 국소 평균 창 반경이고 epsilon은 유한한 양의 분산 정규화 계수입니다. border 0은 복제, 1은 끝점을 중복하지 않는 반사, 2는 상수 경계입니다. 상수 방식이 아니면 constant는 0이어야 합니다. 기본 출력 형식은 GrayF32이며 옵션 값만 만드는 단계와 실제 영상을 필터링하는 호출은 별개입니다.

입력과 결과 확인

GuidedOptions는 guided_filter의 국소 평균 창, 분산 정규화, 경계 처리와 출력 형식을 묶습니다. radius는 창의 반경이고 epsilon은 유한한 양수입니다. 설정값을 만드는 호출과 실제 가이드 영상 및 입력을 필터링하는 실행은 별개입니다.

border 0은 가장자리 복제, 1은 끝점을 중복하지 않는 반사, 2는 상수 경계입니다. constant는 상수 경계에서 사용하는 값이며 다른 경계 방식에서는 0이어야 합니다. 예를 들어 경계 근처 창에는 선택한 방식으로 보충한 값이 포함되므로 경계 옵션에 따라 결과가 달라질 수 있습니다.

기본 output_format은 GrayF32입니다. 출력 형식을 바꾸거나 epsilon을 변경할 때는 동일한 입력과 가이드, radius와 border를 유지해야 차이의 원인을 분리할 수 있습니다. 영상의 실제 형식과 크기, 실행 결과의 오류도 필터 호출에서 확인하십시오.
