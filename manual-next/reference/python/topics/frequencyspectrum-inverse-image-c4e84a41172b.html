inverse_image

method · 선언 타입 zvision._frequency_processing.FrequencySpectrum

Python
inverse_image(self, crop=True, output_format=14)

스펙트럼을 영상으로 역변환합니다.

확인된 인자 조건

crop: True면 원래 입력 크기로 자름, 기본값 True

output_format: Gray8/Gray16/GrayF32/GrayF64, 기본값 GrayF64

반환: 별도 소유 ZImage입니다.

오류: 지원되지 않는 출력 형식 또는 비유한 결과는 오류입니다.

인자 선언

  • crop · POSITIONAL_OR_KEYWORD · 기본값 True
  • output_format · POSITIONAL_OR_KEYWORD · 기본값 14

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

원점이 보존된 독립 Gray8/16/F32/F64 영상을 반환합니다.

역변환을 영상으로

역변환 결과를 ZImage로 얻습니다. crop=True는 원래 입력 크기로 자르며 output_format의 기본값은 GrayF64입니다. Gray8, Gray16, GrayF32, GrayF64 중 공개 계약이 허용하는 형식을 선택할 수 있습니다.

출력 형식과 수명

정수 출력과 부동소수 출력은 값의 범위와 표현이 다르므로 변환할 결과의 범위를 먼저 살핍니다. 지원되지 않는 형식 또는 비유한 결과는 오류가 날 수 있습니다. 반환 영상은 별도 소유이므로 사용 후 close합니다.
