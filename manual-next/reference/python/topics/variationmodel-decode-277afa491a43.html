decode

classmethod · 선언 타입 zvision._inspection_models.VariationModel

Python
decode(cls, template, data, *, max_bytes, max_pixels)

직렬화된 모델을 제한된 크기로 복원합니다.

확인된 인자 조건

template: ZImage 템플릿

data: 직렬화 바이트

max_bytes: 양의 바이트 상한, 키워드 전용

max_pixels: 양의 픽셀 상한, 키워드 전용

반환: 별도로 close할 VariationModel입니다.

오류: 형식·상한 또는 모델 데이터가 유효하지 않으면 오류입니다.

인자 선언

  • template · POSITIONAL_OR_KEYWORD · 기본값 없음
  • data · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_bytes · KEYWORD_ONLY · 기본값 없음
  • max_pixels · KEYWORD_ONLY · 기본값 없음

max_bytes: 정수 검사 · 최소 1.

max_pixels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

인자별 입력 조건

인자형식역할과 조건
templateZImage 템플릿
data직렬화 바이트
max_bytes양의 바이트 상한, 키워드 전용
max_pixels양의 픽셀 상한, 키워드 전용

직렬화된 모델 복원

template ZImage와 bytes 형태 data, 양의 max_bytes 및 max_pixels 한도를 받아 모델을 복원합니다. 바인딩은 데이터 길이가 max_bytes와 64 MiB 중 작은 한도를 넘으면 ValueError를 발생시킵니다.

template과 저장된 모델이 사용할 영상 기하 및 형식에 맞는지 확인합니다. 손상 또는 한도 초과 오류를 정상적으로 비어 있는 모델로 해석하지 않습니다. 반환된 모델은 소유 객체이므로 사용 후 close하고 원래 입력 바이트와 수명을 구별합니다.
