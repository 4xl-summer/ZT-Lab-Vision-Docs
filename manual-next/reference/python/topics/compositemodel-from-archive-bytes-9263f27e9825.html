from_archive_bytes(cls, data: bytes | bytearray | memoryview) -> 'CompositeModel'

아카이브를 검증하여 독립 소유 모델을 복원합니다.

확인된 인자 조건

data: bytes, bytearray 또는 memoryview; 1–2,200,000바이트.

반환: 소유 CompositeModel; 사용 후 close.

오류: 형식·길이·내용이 무효이면 오류.

인자 선언

  • data · POSITIONAL_OR_KEYWORD · 타입 bytes | bytearray | memoryview · 기본값 없음

반환 타입 주석: CompositeModel

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

아카이브를 검증하고 독립 native 모델을 소유한다.

이 호출의 입력과 객체 맥락

검증된 복합 계측 그래프와 출력 단위가 저장된 아카이브에서 독립 소유 모델을 복원합니다. 입력은 비어 있으면 안 되고 최대 2200000바이트입니다. 버전과 그래프가 유효한지 확인한 뒤 모델을 만들며, 결과는 이후 평가에 재사용할 수 있습니다. 사용 후 close합니다.
