호출 맥락과 결과 해석

방향과 다중 해상도를 갖는 특징 모델을 회색 템플릿에서 학습합니다. InvariantFeatureOptions가 검출 조건을 지정하며 선택적인 Gray8 마스크로 학습 영역을 제한할 수 있습니다.

학습된 점의 위치뿐 아니라 배율과 방향은 points에서 확인합니다. 이 모델과 일반 FeatureModel은 사용하는 모델 표현과 학습 옵션이 다르므로 저장 데이터와 복원 API를 각 모델 종류에 맞게 관리합니다. 생성된 모델은 호출자가 닫습니다.
