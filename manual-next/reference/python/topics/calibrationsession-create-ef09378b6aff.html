사용과 결과 판독

빈 관측 테이블을 새로 만들며 이후 카메라, 표적, 자세의 세 식별자에 대응점 배열을 저장할 수 있습니다. 새 테이블에는 기존 관측이 없으므로 조회 전에 필요한 점을 삽입하십시오. 세션 객체는 소유 자원이며 사용이 끝나면 해당 언어의 해제 절차를 따라야 합니다. 관측점은 표적의 각 위치와 영상 픽셀의 대응 순서를 유지합니다.

단계별 확인

세션은 카메라, 표적, 자세 ID의 조합으로 표적점과 픽셀 관측을 관리하는 테이블입니다. Create는 빈 테이블을 만들므로 그 직후에는 아직 대응점이 들어 있지 않습니다.

관측을 추가할 때 같은 인덱스의 표적점과 픽셀점이 동일한 물리 위치를 가리켜야 합니다. 새 키를 추가하는 insert와 기존 키도 교체하는 set의 차이를 확인하고, 필요한 조회와 계산을 마친 뒤 소유 세션을 닫으십시오.

항목확인할 내용
생성빈 관측 테이블을 소유합니다.
키카메라·표적·자세 ID로 관측을 구별합니다.
insert새 키를 추가하며 중복 키를 거부합니다.
set새 관측을 넣거나 같은 키의 관측을 교체합니다.
get선택한 관측의 대응점 배열을 조회합니다.
종료세션 사용이 끝나면 소유 자원을 해제합니다.

예를 들어 같은 카메라와 표적을 두 자세에서 촬영했다면 자세 ID를 달리하여 두 관측을 구별할 수 있습니다. 한 관측 안에서는 표적점과 픽셀점이 같은 순서여야 하며, ID만 맞더라도 대응점 순서가 바뀌면 의도한 기하를 나타내지 않습니다.
