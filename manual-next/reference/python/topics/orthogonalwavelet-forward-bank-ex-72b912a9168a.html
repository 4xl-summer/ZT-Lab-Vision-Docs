forward_bank_ex(cls, image, levels, analysis_low, analysis_high, synthesis_low, synthesis_high, centered=False)

사용자 정의 필터로 주기적 웨이블릿 변환을 수행합니다.

확인된 인자 조건

image: 입력 ZImage

levels: 1–64 변환 레벨

analysis_low: 분석 저역 필터 탭

analysis_high: 분석 고역 필터 탭

synthesis_low: 합성 저역 필터 탭

synthesis_high: 합성 고역 필터 탭

centered: bool; 중심 위상 여부, 기본값 False

반환: 별도로 close할 OrthogonalWavelet입니다.

오류: 필터, 레벨 또는 영상이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • analysis_low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • analysis_high · POSITIONAL_OR_KEYWORD · 기본값 없음
  • synthesis_low · POSITIONAL_OR_KEYWORD · 기본값 없음
  • synthesis_high · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 False

levels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Use periodic real analysis/synthesis filters with independent lengths. Legacy factory retained through 0.1.x; prefer image.orthogonal_wavelet_filter_bank_ex(...).

이 호출의 입력과 객체 맥락

분석·합성 저역과 고역의 네 실수 필터를 각각 지정하는 확장 뱅크 경로입니다. 서로 다른 길이의 필터를 사용할 수 있으며 유효한 각 필터의 길이와 입력 조건은 검사됩니다. centered는 중심 위상 선택입니다. 반환 모델은 독립 소유이며 분석·합성 필터 순서와 위상 설정을 결과와 함께 보관하세요.
