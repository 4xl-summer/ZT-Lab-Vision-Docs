add_line

method · 선언 타입 zvision._composite_metrology.CompositeModelBuilder

Python
add_line(self, id, origin, direction, frame=None)

유향 무한 직선을 추가합니다.

확인된 인자 조건

id: 형상 식별자.

origin: fixture 로컬 선 위의 Point2.

direction: 0이 아닌 방향 벡터 Point2.

frame: 이전 fixture 인덱스 또는 None.

반환: 추가한 fixture 또는 항목의 인덱스.

오류: 잘못된 형상·참조·설정 또는 한도 초과는 오류; 실패한 추가는 되돌림.

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • origin · POSITIONAL_OR_KEYWORD · 기본값 없음
  • direction · POSITIONAL_OR_KEYWORD · 기본값 없음
  • frame · POSITIONAL_OR_KEYWORD · 기본값 None

Add a fixed directed infinite line; direction must be nonzero.

이 호출의 입력과 객체 맥락

origin과 direction으로 선택한 프레임의 고정 유향 무한 직선을 추가합니다. direction은 0 벡터일 수 없습니다. 반환된 0부터 시작하는 특성 인덱스를 보관하면 나중에 다른 직선과의 교차점 정의에 사용할 수 있습니다. frame=None은 ROI 로컬 루트이며 좌표 기준은 픽셀입니다. 유한한 선분 검출을 실행하는 호출이 아니라 모델에 고정 직선 정의를 추가하는 단계입니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
