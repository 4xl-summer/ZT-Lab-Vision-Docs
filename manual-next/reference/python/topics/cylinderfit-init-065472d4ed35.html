CylinderFit(axis_point: zvision._spatial3d.Point3, axis_direction: zvision._spatial3d.Point3, radius: float, inliers: int, total: int, rms_error: float, max_error: float)

axis_point: 원통 축 위의 대표점입니다.

axis_direction: 원통의 단위 축 방향입니다.

radius: 현재 길이 단위의 반지름입니다.

inliers: 임계 거리 이내로 채택된 점 수입니다.

total: 피팅에 사용된 결측을 제외한 유효 점 수입니다.

rms_error: 채택점의 원통 표면 거리 잔차 RMS이며 점군 길이 단위입니다.

max_error: 채택점의 최대 표면 거리 잔차이며 점군 길이 단위입니다.

원통 적합 결과

이 값은 점군에 원통을 적합한 결과를 나타냅니다. 축 위의 점과 단위 방향 벡터, 반지름은 원통의 기하를 정의하며, 인라이어 수와 오차는 그 기하가 선택된 데이터에 얼마나 맞는지 보여 줍니다. 결과 값을 직접 생성하는 것과 데이터에서 적합을 계산하는 것은 다릅니다.

축 방향이 (0,0,1)이고 반지름이 2라면 축과의 수직 거리가 2인 점들이 이상적인 원통면을 이룹니다. 실제 적합에서는 임계 거리 안의 점이 인라이어가 되며 오차 수치는 이 선택된 점들에 대해 해석합니다. 짧은 호나 축 방향으로 충분하지 않은 입력은 해를 불안정하게 만듭니다.
