이 호출의 입력과 객체 맥락

사용 순서는 설정으로 객체를 만든 뒤 connect로 Connected를 만들고 start로 새 취득 epoch를 여는 것입니다. 이미 Acquiring인 객체에 같은 connect를 무조건 반복하는 식으로 상태를 건너뛰지 말고 info.state를 확인하세요. 사용을 마친 객체는 disconnect와 별개로 close합니다.

Disconnected 상태에서 Connected 상태로 바꿉니다. 이어 start를 호출해야 Acquiring 상태로 전환됩니다. 이는 외부 장비를 검색하거나 연결하는 동작이 아니라 모의 세션의 상태 전환입니다. CameraInfo 스냅샷으로 현재 상태를 확인할 수 있으며 허용되지 않은 상태에서 명령하면 오류입니다.

사용 조건과 결과 판독

connect는 모의 카메라를 Disconnected에서 Connected로 전환합니다. 카메라 생성은 CameraSpec을 이용한 별도 create이고, 이 호출은 실제 카메라를 탐색하거나 GigE·USB 장치에 접속하지 않습니다. 반환은 None이며 허용되지 않은 상태의 전환은 오류입니다.

Connected는 취득이 이미 시작됐다는 뜻이 아닙니다. start를 별도로 호출하면 Acquiring이 되고 새 epoch가 시작됩니다. 예를 들어 create→connect→start 순서로 진행한 뒤 트리거 방식에 맞는 이벤트와 영상을 호출자가 직접 제공해야 프레임을 시험할 수 있습니다.

info 스냅샷으로 현재 상태와 epoch를 확인하고 사용을 마치면 상태 전환 disconnect와 소유 핸들 close를 각각 다룹니다. 이미 큐에서 꺼낸 AcquiredFrame과 거기서 얻은 Image는 카메라 객체와 별도 소유 수명입니다. 이 상태 전환만으로 실제 장치의 연결 품질은 검증되지 않습니다.
