Python
region_topology(self, connectivity)

위상 종료 계획을 만듭니다.

확인된 인자 조건

connectivity: 4 또는 8

반환: 별도 close할 타입 지정 Query입니다.

오류: 유효하지 않은 연결성은 오류입니다.

인자 선언

  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

전경의 위상 요약

현재 계획 영상의 연결 성분과 구멍 수를 분석합니다. 성분 하나에 내부 구멍 하나가 있으면 Euler 수는 1-1=0입니다. 구멍 수와 성분 수를 함께 읽어야 서로 다른 위상이 같은 차이값을 갖는 경우를 구분할 수 있습니다.

마스크와 분석

이 단계 앞의 임계 처리와 형태학 결과가 전경을 정의합니다. ROI 경계에서 물체가 잘리거나 연결성이 바뀌면 위상도 달라질 수 있으므로 실행한 마스크와 조건을 함께 기록합니다. 위상 숫자만으로 각 물체의 위치를 알 수는 없습니다.
