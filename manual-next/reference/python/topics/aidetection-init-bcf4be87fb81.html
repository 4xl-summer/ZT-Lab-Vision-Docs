AiDetection(x_min: float, y_min: float, x_max: float, y_max: float, score: float, class_id: int) -> None

Half-open pixel-edge box in the input image's coordinate domain.

x_min: 입력 영상 좌표계의 반열림 상자 왼쪽 픽셀 경계입니다.

y_min: 입력 영상 좌표계의 반열림 상자 위쪽 픽셀 경계입니다.

x_max: 입력 영상 좌표계의 반열림 상자 오른쪽 픽셀 경계입니다.

y_max: 입력 영상 좌표계의 반열림 상자 아래쪽 픽셀 경계입니다.

score: 검출의 점수입니다.

class_id: 검출 클래스 식별자입니다.

입력과 결과 해석

AiDetection은 검출 상자의 x_min, y_min, x_max, y_max와 score, class_id를 담는 불변 값입니다. 좌표는 입력 영상 좌표계의 반열린 픽셀 경계입니다. 예를 들어 x_min=2, x_max=7이면 가로 경계 폭은 5이며 x_max에 1을 더해 면적을 계산하지 않습니다.

검출 상자를 표시할 때 사용한 입력 영역과 전처리 변환을 함께 확인합니다. decode_boxes는 전처리 변환을 사용해 영상 좌표의 결과로 복원하므로 변환된 좌표에 패딩이나 원점 이동을 다시 적용하면 상자가 틀어집니다. 표시 도구가 정수 포함 끝점을 요구한다면 그 도구의 규칙에 맞춰 명시적으로 변환합니다.
