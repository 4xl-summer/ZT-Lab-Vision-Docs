Python API · blob_none_segment

blob_none_segment 멤버와 선언

공개 타입

zvision.blob_none_segment: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_none_segment.blob_none_segment.

Convert Gray8 samples to 0..1 membership by dividing by scaling.

Gray8 값을 배율로 나누어 멤버십을 만듭니다.

Python
blob_none_segment(image, scaling, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • scaling · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
scaling
1–255 정수 멤버십 분모
work_budget
양의 정수 작업량 상한

반환: 별도로 close할 BlobSegmentationResult

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    밝기를 멤버십으로 사용

    blob_none_segment는 별도 임계값 없이 Gray8 값을 scaling으로 나누어 멤버십으로 해석합니다. 이진 임계 처리처럼 모든 픽셀을 단순히 선택과 비선택으로만 나누는 방식과 다릅니다. 원본 회색값과 멤버십의 스케일을 함께 기록해야 결과를 해석할 수 있습니다.

    스케일 예

    scaling은 1부터 255까지의 정수 분모입니다. 예를 들어 scaling이 100이고 픽셀 값이 50이라면 밝기와 분모의 비는 0.5입니다. 입력 값의 범위와 선택한 분모가 결과에 영향을 주므로 다른 scaling 결과를 같은 기준 없이 비교하지 않습니다.

    입력과 호출

    image에 조건에 맞는 ZImage를 전달하고 양의 work_budget을 지정합니다. 이 연산은 임계값 한 쌍을 사용하지 않으므로 결과의 임계값 정보 존재 여부와 실제 멤버십 설정을 구분해 기록합니다. 원본과 결과를 같은 좌표에서 비교하면 변환의 영향을 이해하기 쉽습니다.

    활용 시 주의

    입력 밝기는 카메라 노출이나 전처리에 따라 달라질 수 있습니다. 같은 scaling을 사용해도 다른 촬영 조건의 값이 같은 물리량을 나타낸다고 보장되지 않으므로 실제 검사 데이터로 기준을 검증합니다.
