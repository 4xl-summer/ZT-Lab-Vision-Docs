Jointly refine selected lens parameters and initialized target poses.

공개 멤버

    사용과 결과 해석

    여러 표적 뷰의 관측점과 초기 자세를 사용해 공유 렌즈 계수와 뷰별 자세를 함께 정련합니다. views는 AdvancedLensView의 열이고 각 뷰의 표적·픽셀 대응점 수가 같아야 합니다. initial은 초기 LensModel이며 options는 선택할 계수와 반복 설정을 정합니다. 결과는 렌즈 진단 값과 각 뷰의 회전·병진 쌍으로 구성됩니다. 서로 다른 자세를 사용하더라도 모든 표적 좌표가 같은 단위와 프레임 규칙을 따라야 합니다. 잘못된 대응 순서, 세 값이 아닌 자세 또는 퇴화한 배치는 오류나 부적절한 결과를 만들 수 있으므로 입력을 먼저 대조하십시오. 재투영 RMS는 픽셀 기준이며 수렴 여부와 함께 확인합니다. 학습 관측에서 오차가 작다는 사실을 실제 장비의 전 영역 정확도나 최적해의 유일성으로 확대하지 않습니다. 예를 들어 두 장의 관측을 넣을 때 두 장의 렌즈는 공유하되 표적의 자세는 각기 다를 수 있습니다. 한 장의 표적 순서만 바뀌면 다른 장이 올바르더라도 전체 최적화에 잘못된 대응이 들어갑니다. 뷰별 입력과 반환 자세, 재투영 결과를 함께 저장해 문제를 추적합니다. 표적 좌표의 단위가 뷰마다 달라지면 자세의 이동 성분도 일관되게 해석하기 어렵습니다. 모든 뷰의 표적 기준을 맞추십시오.
