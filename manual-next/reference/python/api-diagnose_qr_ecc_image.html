공개 타입

zvision.diagnose_qr_ecc_image: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.diagnose_qr_ecc_image.

Detect and sample one QR from a Gray8 image, then recompute RS diagnostics.

영상에서 QR 하나를 검출한 후 RS 정정을 진단합니다.

Python
diagnose_qr_ecc_image(image, max_corrected_per_block)

image

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    Gray8 영상에서 QR 심볼 하나를 검출하고 모듈을 샘플링한 다음 실제 Reed–Solomon 정정 진단을 계산합니다. 입력은 이미 1픽셀당 모듈 하나로 샘플된 격자일 필요가 없지만 심볼이 검출되고 읽혀야 합니다. max_corrected_per_block은 정정 후 각 블록의 허용 수정 코드워드 수이며 디코더의 정정 능력을 설정하지 않습니다.

    구체 사례와 결과 판독

    예를 들어 영상에서 읽은 심볼의 한 블록이 2개 코드워드를 수정했다면 한계 1에서는 그 블록이 조건을 넘고 한계 2에서는 해당 조건을 만족합니다. 모든 블록과 accepted를 함께 확인해야 최종 판정을 해석할 수 있습니다. 검출 실패나 읽기 실패를 수정 수 0으로 바꾸지 마세요. 이 수치는 확률이나 인쇄물의 ISO 등급을 뜻하지 않습니다.

    적용 시 확인

    영상의 초점, 대비, 크기와 심볼 위치는 검출에 영향을 줄 수 있습니다. 진단값이 나왔는지부터 확인하고 성공한 결과의 블록별 수와 적용한 한계를 보존하세요. 예를 들어 블록이 두 개이고 각각 1개씩 수정되었다면 전체 2개이지만 블록별 최대는 1입니다. 총합과 블록 기준을 서로 바꾸어 해석하지 않습니다. 읽힌 심볼의 종류와 장면도 함께 기록하세요. 각 블록의 결과를 확인하세요.
