    사용 맥락과 계약

    GraphObservation은 공동 보정 그래프에서 한 카메라가 한 보드를 관측한 자료를 나타냅니다. camera와 board는 각각 카메라와 보드 인덱스이고 target과 pixels는 타깃 점과 해당 영상 픽셀의 대응 목록입니다. 보드의 한 점과 픽셀의 같은 순번이 실제로 같은 물리적 점을 뜻해야 합니다.

    구체 사례와 판독

    예를 들어 camera=0, board=2인 항목과 camera=1, board=2인 항목은 두 카메라가 같은 보드 인덱스를 관측하는 관계를 표현합니다. 각각의 픽셀 배열이 서로 달라도 target의 점 대응은 정확해야 합니다. 실제로 동시에 또는 일관된 자세에서 얻은 관측인지와 영상의 ROI 원점을 먼저 확인하세요.

    적용 시 확인

    같은 번호의 board가 서로 다른 물리적 타깃을 뜻하면 그래프가 실제 장면을 잘못 연결하게 됩니다. 반대로 같은 보드를 서로 다른 번호로 넣으면 공유 관계가 사라질 수 있습니다. 번호표와 관측 시점, 점 순서를 함께 보관하고 대상 보드의 좌표 단위를 일관되게 사용하세요. 그래프의 연결성과 동일 카메라의 렌즈 설정도 확인해야 합니다. 각 관측의 타깃 점과 픽셀 수가 대응하는지 입력을 만들 때 검사하세요. 입력 순서를 기록하세요.
