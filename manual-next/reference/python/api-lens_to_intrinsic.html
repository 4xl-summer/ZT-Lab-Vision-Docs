Python API · lens_to_intrinsic

lens_to_intrinsic 멤버와 선언

공개 타입

zvision.lens_to_intrinsic: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.lens_to_intrinsic.

Return K without altering the input lens or its distortion coefficients.

렌즈의 초점과 주점으로 내부 파라미터 행렬을 만듭니다.

Python
lens_to_intrinsic(lens)

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    lens_to_intrinsic은 렌즈 모델의 내부 파라미터를 카메라 내부행렬로 변환합니다. 내부행렬은 초점 거리와 주점 등 픽셀 좌표에 대한 선형 투영 성분을 표현합니다. 방사 및 접선 왜곡은 일반적인 3×3 내부행렬만으로 표현되지 않으므로 이 변환 결과 하나에 전체 렌즈 왜곡 정보가 들어 있다고 해석하면 안 됩니다.

    구체 사례와 판독

    예를 들어 주점이 (320,240) 픽셀이고 X와 Y 초점 거리가 각각 500 픽셀인 단순 모델은 대각선에 500,500,1과 마지막 열에 320,240,1이 들어가는 내부행렬로 표현합니다. 왜곡 계수가 있다면 같은 행렬을 가진 두 렌즈도 화면 가장자리에서 다른 픽셀을 생성할 수 있습니다. 데이터를 교환할 때 왜곡 정보를 별도로 보존하세요.

    적용 시 확인

    영상 크기가 바뀌거나 잘려 좌표 원점이 바뀌면 기존 행렬을 그대로 재사용하기 전에 초점 거리와 주점이 새 픽셀 좌표계에서 어떻게 표현되는지 점검해야 합니다. 행렬 값과 왜곡 계수, 영상 크기를 함께 기록하면 다른 프로그램에서 동일한 카메라 모델을 구성하는 데 도움이 됩니다. 렌즈를 K로 바꾸는 과정은 입력 렌즈를 수정하지 않습니다. 출력 행렬로부터 원래 왜곡 렌즈를 완전히 되살릴 수 있는지와는 별개의 문제입니다.
