    사용 맥락과 계약

    HandEyeResult는 AX=XB 문제의 추정 변환과 진단값을 묶습니다. transform은 B 프레임에서 A 프레임으로 가는 X이고, rotation_condition과 translation_condition은 해당 계산의 조건을 살피는 지표입니다. hypotheses는 평가한 후보 개수이며 residuals는 입력 운동 쌍에 대응하는 잔차 목록입니다. 좌표 프레임 방향을 기록하지 않은 채 변환 행렬만 전달하면 적용 방향을 혼동하기 쉽습니다.

    구체 사례와 판독

    예를 들어 한 운동 쌍의 잔차가 크다면 전체 결과의 숫자만 확인하지 말고 해당 쌍의 회전과 이동 잔차 및 내점 여부를 찾아봅니다. 운동이 다양하지 않으면 해를 안정적으로 구별하기 어려울 수 있으므로 조건 지표도 함께 검토하세요. 보류한 자세에 변환을 적용해 실제 오차를 확인하는 절차가 필요합니다.

    적용 시 확인

    반환한 변환은 그리퍼 장착 구성과 외부 고정 구성에서 같은 이름의 물리적 방향을 뜻하지 않을 수 있습니다. 문제를 만들 때 각 A와 B를 어느 프레임으로 정의했는지와 X의 출발·도착 프레임을 함께 문서화하세요. 변환의 역행렬이 필요한 처리에서는 명시적으로 역변환을 구하고, 임의로 회전과 이동 숫자의 부호만 바꾸지 않도록 합니다.
