blob_trimmed_bounds 멤버와 선언

공개 타입

zvision.blob_trimmed_bounds: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_trimmed_bounds.blob_trimmed_bounds.

Trim up to k pixels independently at each axis extreme; ties stay.

축별 극단에서 지정 수까지 제외한 경계를 계산합니다.

Python
blob_trimmed_bounds(image, exclude_per_side, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • exclude_per_side · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
exclude_per_side
각 축 극단에서 제외할 최대 픽셀 수
work_budget
양의 정수 작업량 상한

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    극단 픽셀을 제한한 경계

    blob_trimmed_bounds는 전경 좌표의 각 축 극단에서 지정된 수까지 제외한 경계를 계산합니다. 외곽의 소수 잡음점 때문에 일반 경계 상자가 크게 늘어나는 경우를 살펴볼 수 있지만, 실제 물체의 가는 끝도 극단에 있으면 함께 제외될 수 있습니다.

    입력과 설정

    image는 전경 마스크이고 exclude_per_side는 각 축의 양쪽 극단에서 제외할 최대 픽셀 수입니다. work_budget은 양의 정수 작업량 상한입니다. 각 축을 독립적으로 다루므로 모든 축에서 같은 픽셀 집합이 하나로 제거된다고 단정하지 않습니다.

    결과 좌표

    결과의 left와 top은 포함 경계이고 right와 bottom은 제외 경계입니다. 예를 들어 x 범위 [2,5)는 2, 3, 4의 세 열을 포함합니다. area는 원래 전경 픽셀 수이므로 트림 후 사각형의 폭×높이와 다를 수 있습니다.

    검증 순서

    원본 마스크와 결과 사각형을 같은 ROI에 표시하고 제외 수를 바꾸면서 범위 변화를 확인합니다. 결과를 전체 영상에 그리거나 다른 영상과 비교할 때는 ROI 원점을 더해 기준을 맞춥니다. 물리 길이 기준의 판정은 보정 정보를 별도로 사용합니다.
