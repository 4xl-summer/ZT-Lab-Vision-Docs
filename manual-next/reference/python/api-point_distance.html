두 점의 유클리드 거리를 구합니다.

Python
point_distance(a, b)

인자 선언

  • a · POSITIONAL_OR_KEYWORD · 기본값 없음
  • b · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

a
첫 Point2; 유한한 좌표.
b
둘째 Point2; 같은 좌표계.

반환: 좌표 단위의 비음수 float.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    같은 2차원 좌표계의 두 점 사이 유클리드 거리를 계산합니다. x 차이와 y 차이의 제곱 합에 제곱근을 적용하므로 입력이 (0,0)과 (3,4)라면 결과는 5입니다. 결과 단위는 두 점에 사용한 단위와 같으며 픽셀 좌표를 주면 픽셀 거리입니다. 이 함수가 영상 원점을 더하거나 렌즈 및 평면 보정을 자동 적용하지는 않습니다. 두 점이 서로 다른 ROI에서 온 경우 각 점을 공통 글로벌 좌표로 옮기거나 같은 세계 좌표계로 변환한 뒤 비교해야 합니다. 세계 변환이 원근 또는 비등방 매핑이라면 픽셀 거리만 단일 배율로 환산하는 접근이 일반적으로 동일하지 않습니다. 유효하지 않은 숫자나 타입의 입력은 오류로 분리하여 처리하십시오. 같은 점을 두 인자로 넣으면 차이가 모두 0이어서 거리는 0입니다. 반대로 점의 순서를 바꾸어도 제곱된 성분의 합은 같으므로 거리는 변하지 않습니다. 방향이나 부호가 필요하면 이 무방향 거리와 다른 기하 연산을 선택해야 합니다. 예시의 (3,4)는 각 축 차이의 크기이고 5는 두 점을 잇는 직선 길이입니다. x 거리와 y 거리 각각이 필요한 경우 합쳐진 거리 하나로는 원래 성분을 복원할 수 없습니다. 비교 전에 어느 치수가 필요한지 정하십시오. 두 좌표의 프레임도 확인하십시오.
