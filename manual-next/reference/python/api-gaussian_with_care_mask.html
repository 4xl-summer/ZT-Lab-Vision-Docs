공개 타입

zvision.gaussian_with_care_mask: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._gaussian_care_gap.gaussian_with_care_mask.

Filter care samples and mark pixels where the filter was applied.

care 마스크의 표본으로 가우시안 필터를 계산하고 계산 위치를 기록합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    gaussian_with_care_mask는 입력 영상과 관심 샘플을 나타내는 마스크를 받아 가우시안 필터를 적용하고 적용 여부를 표시하는 결과를 제공합니다. CareGaussianOptions에서 가로·세로 sigma는 양수이며 minimum_fraction은 0부터 1까지입니다. 경계 방식과 출력 형식도 선택하므로 영상과 마스크의 대응 위치가 맞는지 먼저 확인합니다.

    구체 사례와 판독

    예를 들어 결함이 있는 영역을 관심 샘플에서 제외하면 이 함수는 유효한 샘플 조건을 고려해 필터 결과와 적용 마스크를 만듭니다. 결과 밝기만 보고 모든 위치에서 필터가 적용되었다고 가정하지 말고 반환된 적용 표시를 함께 확인하세요. 상수 경계 값은 상수 경계 방식에만 쓰이며 다른 경계 방식에서 0이 아닌 상수를 지정하면 유효하지 않습니다.

    적용 시 확인

    필터 반경과 마스크 유효 비율 때문에 관심 영역의 경계에서는 내부와 다른 적용 결과가 나올 수 있습니다. 작은 영상과 마스크를 사용해 적용 마스크의 값을 직접 확인하고, 필터가 적용되지 않은 위치를 후속 측정에서 어떻게 처리할지 정하세요. sigma와 출력 정밀도, 경계 설정을 함께 기록하면 결과를 재현하기 쉽습니다.
