    사용 조건과 흐름

    BeadReferenceOptions는 학습된 비드 기준을 이용하는 검사에 프로브 조건과 기준의 평활 및 허용 변화를 지정합니다. probe는 BeadOptions이고 smooth_radius, max_missing, max_center_step, max_width_step과 max_work는 각각 기준 처리 및 검사 제한에 사용됩니다. 폭과 중심의 기준은 같은 경로 좌표계에서 해석해야 합니다.

    구체 사례와 결과 판독

    예를 들어 일정한 폭의 정상 비드를 학습한 뒤 검사에서 중심이 급격히 이동하거나 폭이 변하는 구간을 찾을 수 있습니다. 고정된 하나의 숫자로 모든 대상이 합격하는 것은 아니며, 프로브 극성과 대비, 누락 허용 조건, 경로 위치가 함께 영향을 줍니다. 정상 샘플과 알려진 결함을 이용해 반환된 개별 프로브와 판정을 확인하세요.

    적용 시 확인

    예를 들어 프로브 검출이 누락된 위치가 연속될 때 max_missing이 기준 구성과 검사에 영향을 줍니다. 폭이나 중심의 단계 변화는 경로의 순서와 간격에 따라 해석해야 하며, 잘못된 경로 정렬을 허용치만 늘려 해결하면 실제 결함이 가려질 수 있습니다. 기준 학습에 사용한 영상의 촬영 조건과 경로도 보존해 이후 검사에 같은 기준이 적용되도록 합니다.
