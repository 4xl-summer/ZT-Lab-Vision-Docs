사용과 결과 해석

고급 차분의 허용치 결합 방식을 지정합니다. SUM=0과 MAX=1 중 선택하며 AdvancedDifferenceSpec의 combine 필드에 전달합니다. 기본 허용치와 질감 또는 선택적으로 제공한 허용치 맵이 어떻게 결합되는지 결과 점수를 해석할 때 함께 확인해야 합니다.

합과 최댓값은 같은 입력에서도 일반적으로 다른 값을 만듭니다. 예를 들어 비교할 두 양이 3과 4라면 합은 7이고 최댓값은 4입니다. 이 예는 두 결합 연산의 차이를 보여 주며 실제 처리의 각 항목 정의와 설정을 대체하지 않습니다.

허용치 설정을 바꾸면 같은 잔차의 결함 마스크가 달라질 수 있습니다. 원하는 밝은 점과 어두운 점, 질감이 있는 정상 영역을 포함한 입력으로 score와 mask를 함께 확인합니다. 이 열거값 자체는 최종 제품 합격 판정이 아닙니다.

실제 차분에는 기본 임계값과 선택한 텍스처 설정 및 옵션 영상이 함께 관여합니다. 두 방식 중 어떤 것이 더 적합한지는 정상 질감과 알려진 결함을 포함한 입력에서 검토합니다. 임계값을 바꾼 결과를 비교할 때 보정 계수와 유효 픽셀 수를 동일하게 기록합니다.

합성 영상에서 같은 점의 점수와 마스크를 두 선택으로 각각 비교합니다.
