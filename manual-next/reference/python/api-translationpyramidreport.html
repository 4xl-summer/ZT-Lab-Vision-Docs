    사용과 결과 해석

    피라미드 기반 평행이동 정합의 최종 결과와 실제 사용한 레벨 정보를 담습니다. registration은 값 스냅샷이며 found 상태를 확인해야 합니다. levels_used는 실제 처리한 레벨 수이고 두 coarse 크기는 가장 거친 소스 및 기준 영상의 너비와 높이를 픽셀 튜플로 나타냅니다.

    요청한 레벨 수와 실제 처리한 수가 다를 수 있으므로 결과의 levels_used와 거친 영상 크기를 읽어 해석하십시오. 원본과 가장 거친 레벨의 픽셀 간격은 같지 않으며 최종 평행이동을 거친 레벨 좌표라고 임의로 가정하면 오차가 납니다.

    found가 false인 경우 결과 스냅샷이 존재해도 정합 위치가 검증되었다는 뜻은 아닙니다. 입력의 원점, ROI 및 평행이동만으로 설명 가능한지 확인하고, 실제 회전이나 원근 변화가 큰 경우 다른 정합 모델을 고려하십시오.
