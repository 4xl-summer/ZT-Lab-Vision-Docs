열거 값

  • MEAN_STD = 0 · 값 0. 전체 포함 표본의 평균과 표준편차를 기준에 맞추는 선형 정규화입니다.
  • HISTOGRAM = 1 · 값 1. 입력과 기준의 정렬된 표본 순위로 광도를 대응시킵니다.
  • ROBUST_LINE = 2 · 값 2. 표본 쌍의 기울기 중앙값과 잔차 중앙값으로 선형 보정합니다.
  • LOCAL_MEAN_STD = 3 · 값 3. 겹치지 않는 타일별 평균과 표준편차로 정규화합니다.
  • MATCH_TAILS = 4 · 지정된 양쪽 꼬리를 제외한 기준·검사 밝기 분위수로 선형 매핑하고 범위 밖을 제한합니다.
