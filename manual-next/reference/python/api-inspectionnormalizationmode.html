열거 값

  • MEAN_STD = 0 · 값 0. 전체 포함 표본의 평균과 표준편차를 기준에 맞추는 선형 정규화입니다.

  • MATCH_TAILS = 4 · 지정된 양쪽 꼬리를 제외한 기준·검사 밝기 분위수로 선형 매핑하고 범위 밖을 제한합니다.

사용 조건과 흐름

InspectionNormalizationMode는 검사 영상을 기준 영상의 조명 분포에 맞추는 방식입니다. MEAN_STD, HISTOGRAM, ROBUST_LINE, LOCAL_MEAN_STD, MATCH_TAILS 중 목적에 맞는 방식을 InspectionNormalizationOptions에서 선택합니다. 위치 정렬과 결함 판정은 별도의 단계이며 정규화가 모든 차이를 자동으로 제거하는 것은 아닙니다.

구체 사례와 결과 판독

예를 들어 같은 부품이 전체적으로 밝게 촬영된 경우 평균·표준편차를 이용한 전역 정규화를 시험할 수 있습니다. 조명이 영역별로 달라진다면 LOCAL_MEAN_STD의 타일 크기가 결과에 영향을 줍니다. MATCH_TAILS는 꼬리 비율을 사용하며 다른 모드에 임의로 그 값을 넣을 수 없습니다. 결과와 마스크를 함께 검증하세요.

적용 시 확인

정규화된 출력은 GrayF64이며 마스크에서 제외된 픽셀은 0입니다. 이 0을 실제 측정된 검은 결함으로 오인하지 않도록 마스크를 후속 판정에도 사용하세요. 타일 크기는 LOCAL_MEAN_STD에만, 꼬리 비율은 MATCH_TAILS에만 지정할 수 있습니다.
