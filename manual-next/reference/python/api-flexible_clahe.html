Python API · flexible_clahe

flexible_clahe 멤버와 선언

공개 타입

zvision.flexible_clahe: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._processing_flexible.flexible_clahe.

Gray8 CLAHE with clipped tile histograms and bilinear tile-center interpolation.

Gray8 타일의 제한된 히스토그램을 이용해 국소 대비를 조정합니다.

Python
flexible_clahe(image, tiles_x, tiles_y, bins=256, clip_limit=2.0)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • tiles_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • tiles_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • bins · POSITIONAL_OR_KEYWORD · 기본값 256
  • clip_limit · POSITIONAL_OR_KEYWORD · 기본값 2.0

확인된 인자 조건

image
Gray8 ZImage입니다.
tiles_x
가로 타일 수인 양의 정수입니다.
tiles_y
세로 타일 수인 양의 정수입니다.
bins
2–256 빈 수이며 기본값은 256입니다.
clip_limit
양의 대비 제한값이며 기본값은 2입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

tiles_x: 정수 검사 · 최소 1.

tiles_y: 정수 검사 · 최소 1.

bins: 정수 검사 · 최소 2.

clip_limit: 유한한 수 검사.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
