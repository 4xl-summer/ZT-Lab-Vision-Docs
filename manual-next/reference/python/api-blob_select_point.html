Python API · blob_select_point

blob_select_point 멤버와 선언

공개 타입

zvision.blob_select_point: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_point_select.blob_select_point.

Return stable zero-based indices of input masks containing `(x,y)`.

지정 픽셀을 포함하는 입력 영역들의 인덱스를 구합니다.

Python
blob_select_point(regions, x, y, work_budget)

인자 선언

  • regions · POSITIONAL_OR_KEYWORD · 기본값 없음
  • x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

regions
입력 ZImage 마스크 시퀀스
x
ROI 로컬 정수 x
y
ROI 로컬 정수 y
work_budget
양의 정수 작업량 상한

반환: 0 기반 인덱스 tuple

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    지정 위치를 포함하는 마스크

    blob_select_point는 입력 영역 마스크 시퀀스에서 지정한 픽셀을 포함하는 영역의 인덱스를 구합니다. 점과 마스크의 포함 관계를 확인하는 호출이며 점에 가장 가까운 물체를 찾는 거리 검색과는 다릅니다. 여러 영역이 같은 점을 포함하면 결과 해석에 그 가능성을 고려합니다.

    좌표 지정

    x와 y는 ROI 로컬 정수 좌표입니다. 전체 영상의 점을 넣어야 하는 상황이라면 해당 ROI 원점을 빼서 로컬 좌표로 바꿉니다. 예를 들어 ROI 원점이 (100,200)이고 전체 점이 (110,220)이면 로컬 입력은 (10,20)입니다.

    입력과 결과

    regions에는 ZImage 마스크들의 시퀀스를, work_budget에는 양의 정수 상한을 전달합니다. 선택된 인덱스는 그 호출에 전달한 시퀀스의 순서와 연결해 해석합니다. 입력 순서를 바꾸면 같은 숫자가 다른 마스크를 가리킬 수 있습니다.

    오류 진단

    예상한 물체가 선택되지 않으면 점이 전경인지와 좌표 기준, ROI 정렬을 먼저 살핍니다. 경계선 위의 점은 마스크 생성 방식에 따라 전경이 아닐 수 있으므로 표시 화면의 선 두께만 보고 포함 여부를 단정하지 않습니다.
