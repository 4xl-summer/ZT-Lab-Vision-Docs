사용과 결과 해석

고급 색 변환에서 참조 백색점을 선택합니다. D50=0과 D65=1이 있으며 convert_advanced의 기본은 D50입니다. Lab의 수치는 참조 백색점에 의존하므로 같은 RGB라도 백색점을 다르게 선택한 변환 결과를 조건 없이 같은 수치 기준으로 비교하지 않습니다.

convert_advanced에 입력 영상과 white, transfer, gamma 및 출력 space를 전달합니다. 예를 들어 측정 기준이 D65인 자료와 비교하려면 입력 영상과 샘플이 어떤 백색점을 기준으로 만들어졌는지 확인하고 그 조건을 기록합니다. 출력은 세 채널 평면을 소유하는 결과입니다.

백색점은 RGB 전달 함수나 감마 값과 서로 다른 선택입니다. 이미지의 색 프로파일을 자동 감지한다는 뜻으로 이 열거값을 사용하지 말고 측정과 변환에서 적용한 조건을 함께 보관합니다. 각 채널 영상과 결과 객체는 사용 후 각각 닫습니다.

예를 들어 샘플 색과 검사 색을 각각 다른 백색점으로 변환하면 같은 표면도 다른 좌표로 표현될 수 있습니다. 두 자료의 생성 조건을 먼저 맞추고 색차를 계산합니다.

변환의 백색점과 샘플 기준을 함께 남깁니다. 다른 조건은 비교 전에 정리합니다.
