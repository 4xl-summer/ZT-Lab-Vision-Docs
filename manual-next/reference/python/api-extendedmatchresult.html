    사용 맥락과 결과 해석

    타입 지정 확장 NCC 및 형상 검색이 반환하는 독립 보고서의 공개 이름입니다. matches는 AdvancedMatch의 불변 튜플, evaluated는 실제 평가 포즈 수, termination은 완료·예산·시간·확실도 중 종료 이유입니다. 후보가 비었는지와 검색을 끝까지 했는지는 별도로 판독합니다.

    점수순 후보마다 로컬·전역 기준점, 각도, 축별 배율과 커버리지를 확인합니다. 예산 중단이면 결과가 하나 있더라도 나머지 격자에서 더 나은 후보가 없다고 보장할 수 없습니다. Python 값은 네이티브 결과에서 복사되어 입력과 모델을 닫은 뒤에도 유지됩니다. 정확한 검색 범위와 옵션은 보고서 밖에서 함께 보관해야 합니다.

    값을 확인하는 순서

    matches 항목: 복사된 불변 매치 튜플입니다. 후보가 없으면 비어 있습니다. evaluated 항목: 평가한 포즈 수입니다. termination 항목: 전체 완료, 후보 예산, 시간 제한, 조기 점수 중 검색 종료 원인입니다.
