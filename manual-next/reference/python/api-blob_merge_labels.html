Python API · blob_merge_labels

blob_merge_labels 멤버와 선언

공개 타입

zvision.blob_merge_labels: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_merge_labels.blob_merge_labels.

Return same-format Gray8/Gray16/GrayU32 labels with smallest group ID.

서로 닿는 라벨을 연결 그룹의 최소 라벨로 통합합니다.

Python
blob_merge_labels(image, connectivity, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
connectivity
연결성 4 또는 8
work_budget
양의 정수 작업량 상한

반환: 원본과 같은 라벨 형식의 독립 영상

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    닿는 레이블의 결합

    blob_merge_labels는 서로 닿은 레이블을 연결 그룹으로 묶고 각 그룹의 최소 레이블로 통합합니다. 픽셀 값을 임의로 연속 번호로 바꾸는 재레이블과는 다른 작업입니다. 연결 관계를 구성한 다음 같은 그룹 전체에 최소 레이블을 적용합니다.

    그룹의 최소값 예

    레이블 2와 5가 서로 닿고 5와 9가 닿아 하나의 연결 그룹이 된다면 그룹의 최소 레이블은 2입니다. 결과에서 이 그룹의 레이블을 2로 해석합니다. 직접 접하지 않은 2와 9도 중간의 5를 통해 같은 그룹이 될 수 있습니다.

    연결 선택

    connectivity에 4 또는 8을 지정합니다. 대각선으로만 접한 두 레이블은 이웃 정의에 따라 결합 여부가 달라질 수 있습니다. 입력 레이블 영상과 양의 work_budget을 전달하고, 설정을 바꾸는 실험에서는 같은 영상으로 결과 맵을 비교합니다.

    결과 사용

    레이블을 합치면 서로 다른 번호였던 영역의 구분 정보가 사라질 수 있으므로 기존 레이블이 필요하면 별도로 보관합니다. 결과 숫자의 크기를 객체의 크기나 우선순위로 취급하지 말고 그룹 식별값으로 해석합니다.
