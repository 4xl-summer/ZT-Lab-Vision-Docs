calibrated_feature_pose 멤버와 선언

공개 타입

zvision.calibrated_feature_pose: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._calibrated_plane_pose.calibrated_feature_pose.

Convert a feature model-to-source-local matrix to one calibrated plane-to-camera pose.

모델→검색 로컬 특징 행렬을 보정된 평면→카메라 포즈로 변환합니다.

Python
calibrated_feature_pose(matrix, zero_pixel, units_per_pixel, source_origin, fx, fy, cx, cy, *, max_orthogonality_error=0.01, max_scale_error=0.01)

확인된 인자 조건

matrix
모델 로컬→검색 로컬의 유한 3×3 행 우선 행렬입니다.
zero_pixel
평면 원점에 대응하는 모델 픽셀 좌표쌍입니다.
units_per_pixel
모델 픽셀의 x/y 물리 단위 배율쌍입니다.
source_origin
검색 영상 로컬 원점의 글로벌 픽셀 좌표쌍입니다.
fx
카메라 x 초점거리(픽셀)입니다.
fy
카메라 y 초점거리(픽셀)입니다.
cx
주점 x(글로벌 픽셀)입니다.
cy
주점 y(글로벌 픽셀)입니다.
max_orthogonality_error
허용 직교성 오차이며 기본값 0.01입니다.
max_scale_error
허용 축 배율 오차이며 기본값 0.01입니다.

반환: 포즈와 평면 모호성·깊이 확인 한계를 담은 CalibratedFeaturePose입니다.

오류: 비유한 입력 또는 기하·보정 조건 위반은 오류입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
