    노드와 간선의 모음

    SkeletonGraph는 nodes와 edges 두 튜플로 골격의 분기 구조를 표현합니다. 노드는 끝점이나 접합점 등이고 간선은 노드 사이를 잇는 경로입니다. 단순한 픽셀 영상과 달리 연결 관계를 직접 따라갈 수 있지만, 원본 마스크의 면적이나 밝기 정보 전체를 대신하지는 않습니다.

    간선 읽는 순서

    각 간선의 start와 end는 해당 결과의 노드 인덱스이고 points와 length는 그 경로를 설명합니다. 두 끝점이 같은 닫힌 루프에서도 그래프가 경로를 나타낼 수 있으며 구현은 루프를 표현할 합성 기준점을 사용합니다. 간선의 두 끝점만 그리면 굽은 골격을 정확히 표시할 수 없습니다.

    구성과 수명

    생성자는 nodes의 각 항목이 SkeletonNode이고 edges의 각 항목이 SkeletonEdge인지 확인하며 잘못된 항목은 TypeError를 냅니다. skeleton_graph는 네이티브 결과에서 노드와 경로를 복사하여 반환합니다. 다른 입력이나 전처리 설정에서 얻은 그래프와 비교할 때는 인덱스 자체가 아닌 좌표와 연결 관계를 비교합니다.

    원래 마스크가 여러 조각이라면 그래프에도 서로 연결되지 않은 노드와 간선 묶음이 있을 수 있습니다. 그래프 전체의 간선 수만 보는 대신 각 노드가 어떤 경로로 이어지는지 확인합니다.
