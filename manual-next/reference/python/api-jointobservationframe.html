zvision.JointObservationFrame: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.JointObservationFrame.

Observation camera/board frame IDs and physical length unit.

Python
JointObservationFrame(camera_frame: int, board_frame: int, unit: object) -> None

인자 선언

  • camera_frame · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • board_frame · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 타입 <class 'object'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

JointObservationFrame(<class 'int'>, <class 'int'>, <class 'object'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    camera_frameint필수해당 관측의 카메라 프레임 ID.
    board_frameint필수해당 관측의 보드 프레임 ID.
    unitobject필수보드 좌표와 pose 이동의 길이 단위.

    사용과 결과 해석

    공동 카메라·보드 보정에서 관측 하나가 어떤 카메라 프레임과 보드 프레임에 속하는지, 어떤 물리 길이 단위를 사용하는지 지정하는 태그입니다. camera_frame과 board_frame은 숫자로 표현된 프레임 식별자이고 unit은 LengthUnit입니다. 이름이 비슷한 관측 인덱스와 프레임 식별자는 서로 다른 역할을 합니다.

    프레임 태그를 받는 보정 호출에서는 관측 순서에 맞게 태그를 제공하고, 태그에 지정한 식별자가 해당 카메라 및 보드 프레임 목록과 일치해야 합니다. 단위도 전체 계산의 길이 단위와 맞아야 합니다. 예를 들어 관측의 보드 인덱스가 1인 경우 그 항목에 태그된 보드 프레임은 목록의 해당 프레임과 일치해야 합니다.

    이 값은 점 좌표를 변환하는 행렬이 아니라 입력의 좌표계와 단위를 검증하기 위한 메타데이터입니다. 태그를 올바르게 붙였더라도 기하 관측이 충분하고 수치 최적화가 안정적이라는 보장은 없습니다. 호출 결과의 수렴, 잔차와 rank 진단을 별도로 확인하고 태그 오류와 적합 실패를 구분하십시오.
