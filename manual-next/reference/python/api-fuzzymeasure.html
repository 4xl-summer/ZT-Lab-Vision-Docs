  • FIRST_POSITION = 0 · 첫 에지의 프로파일 거리.
  • SECOND_POSITION = 1 · 둘째 에지의 프로파일 거리.

  • FIRST_STRENGTH = 3 · 첫 에지 강도의 절댓값.
  • SECOND_STRENGTH = 4 · 둘째 에지 강도의 절댓값.

사용과 결과 해석

삼각형 형태의 점수 함수에 입력할 에지 특징을 선택하는 열거형입니다. FIRST_POSITION과 SECOND_POSITION은 첫째와 둘째 에지의 프로파일상 위치를, FIRST_STRENGTH와 SECOND_STRENGTH는 각 에지 강도를, WIDTH는 두 에지 사이의 너비를 선택합니다. 예를 들어 같은 프로파일에서 에지가 시작점으로부터 2와 7픽셀에 있다면 너비는 5픽셀입니다. 위치와 너비는 픽셀 거리이지만 강도는 원시 강도와 픽셀 거리의 비율이므로 같은 숫자 범위로 해석하지 마십시오. 둘째 에지가 필요한 특징을 선택할 때는 해당 후보에 둘째 에지가 존재하는지 확인해야 합니다. 점수는 설정된 삼각형 함수에 대한 적합도를 나타내며 직접적인 세계 길이 또는 장비 정확도가 아닙니다. 진행 방향이 뒤집히면 첫째와 둘째의 의미도 바뀌므로 탐색선의 시작점과 끝점을 함께 기록합니다. 여러 특징을 조합한 결과는 어느 특징이 점수에 영향을 주었는지 구성 요소와 함께 확인해야 설정을 바꾼 후 순위가 달라진 이유를 찾을 수 있습니다. 특징별 기준의 단위와 유효한 범위는 해당 점수 함수 설정의 계약을 따릅니다. 후보가 하나의 에지만 가진다면 둘째 위치를 정상적인 0픽셀로 대체하지 마십시오. 해당 특징이 실제로 계산 가능한지 먼저 확인합니다.
