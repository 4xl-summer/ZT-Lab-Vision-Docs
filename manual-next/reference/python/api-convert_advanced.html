Python API · convert_advanced

convert_advanced 멤버와 선언

공개 타입

zvision.convert_advanced: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._color_advanced.convert_advanced.

색상을 지정 백색점과 전달 함수의 Lab 또는 LCH 세 평면으로 변환합니다.

Python
convert_advanced(image, white=<AdvancedWhitePoint.D50: 0>, transfer=<AdvancedTransfer.SRGB: 0>, gamma=2.2, space=<AdvancedColorSpace.LAB: 0>)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • white · POSITIONAL_OR_KEYWORD · 기본값 <AdvancedWhitePoint.D50: 0>
  • transfer · POSITIONAL_OR_KEYWORD · 기본값 <AdvancedTransfer.SRGB: 0>
  • gamma · POSITIONAL_OR_KEYWORD · 기본값 2.2
  • space · POSITIONAL_OR_KEYWORD · 기본값 <AdvancedColorSpace.LAB: 0>

확인된 인자 조건

image
지원되는 RGB 계열 영상.
white
D50 또는 D65 백색점; 기본 D50.
transfer
sRGB, LINEAR 또는 GAMMA 입력 전달 함수; 기본 SRGB.
gamma
GAMMA 전달 함수의 지수; 기본 2.2.
space
LAB 또는 LCH 출력 공간; 기본 LAB.

반환: 호출자가 close할 AdvancedPlanes 소유 객체.

오류: 부적합한 영상·옵션 또는 비유한 값은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    RGB 영상을 지정한 백색점과 전달 함수로 Lab 또는 LCH의 고급 색 평면으로 변환합니다. image는 ZImage이고 기본 white는 D50, transfer는 SRGB, gamma는 2.2, space는 LAB입니다. 필요에 따라 D65, 선형 또는 감마 전달, LCH 출력을 선택할 수 있습니다.

    반환된 AdvancedPlanes에서 channel(0), channel(1), channel(2)를 얻어 세 채널을 살펴봅니다. 입력이 sRGB로 인코딩되었는지 이미 선형인지가 전달 함수의 선택에 영향을 주며, 백색점이 다른 참조값과 단순 비교하면 의미가 달라집니다. 입력 조건과 출력 공간을 결과와 함께 기록합니다.

    각 channel 호출은 별도 소유 ZImage를 돌려주고 평면 결과 자체도 닫아야 합니다. 인덱스가 0부터 2 밖이면 ValueError입니다. 입력이 ZImage가 아니거나 옵션이 유효한 열거값이 아니면 오류이므로 빈 채널 영상을 정상 결과로 간주하지 않습니다.

    변환된 평면을 원본과 나란히 볼 때 채널별 범위가 일반적인 바이트 밝기 범위와 다를 수 있습니다. 화면에 표시한 색과 원본 채널 수치를 구별해서 확인합니다.
