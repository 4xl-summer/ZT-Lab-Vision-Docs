공개 타입

zvision.ZImage: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision.ZImage.

픽셀 저장소를 소유하는 영상 객체입니다.

픽셀 저장소를 소유하는 이미지입니다. from_* 팩터리로 만들고 close() 또는 with로 해제합니다. 읽기나 결과를 공유하는 메서드는 각 메서드의 반환 수명을 확인하세요. 닫힌 핸들이 필요한 호출은 ValueError, 네이티브 실패는 ZVisionError를 냅니다.

Python
ZImage()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
