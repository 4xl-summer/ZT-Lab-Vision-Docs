공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    matrixtuple필수공통 로컬에서 해당 영상 로컬로 가는 행 우선 호모그래피 계수.
    valid_countint필수정합 영상의 유효 보간 픽셀 수.

    사용 맥락과 계약

    RegistrationGraphInfo는 다중 정합에서 공통 좌표계에서 각 영상으로 가는 호모그래피와 유효 정렬 픽셀 수를 담습니다. matrix의 방향을 영상에서 공통 좌표계로 가는 역변환으로 임의 해석하면 위치가 달라집니다. valid_count는 유효한 정렬 픽셀의 개수이며 정합 점수나 오류 확률이 아닙니다.

    구체 사례와 판독

    예를 들어 공통 출력이 100×100 픽셀이고 한 영상의 valid_count가 8000이라면 10000개 중 8000개의 위치가 유효하게 샘플링되었다는 의미입니다. 이 개수만으로 해당 영상이 정확히 정합되었다는 보장은 없습니다. 행렬 방향과 함께 겹침 영역 및 별도의 정합 품질을 확인하고 영상 크기를 비교 기준에 포함하세요.

    적용 시 확인

    유효 픽셀 수가 출력 전체 크기보다 작으면 영상 경계 밖이거나 유효하지 않은 위치가 있다는 뜻으로 해석할 수 있습니다. 이때 합성이나 차영상에서 유효하지 않은 영역을 일반적인 검은 픽셀로 처리하면 가짜 결함이 생길 수 있으므로 유효 마스크를 함께 사용하세요. 공통 좌표계에 찍은 점을 행렬로 각 영상에 대응시키는 방향을 작은 예제로 검증하면 역행렬 혼동을 줄일 수 있습니다. 각 영상에 대해 따로 확인합니다.
