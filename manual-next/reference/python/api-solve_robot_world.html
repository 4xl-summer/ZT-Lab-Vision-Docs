Python API · solve_robot_world

solve_robot_world 멤버와 선언

공개 타입

zvision.solve_robot_world: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.solve_robot_world.

Estimate AX=ZB from 3–1025 absolute pose pairs; no joint refinement.

절대 자세 쌍으로 AX=ZB의 X와 Z를 추정합니다.

Python
solve_robot_world(a, b, options)

인자 선언

  • a · POSITIONAL_OR_KEYWORD · 기본값 없음
  • b · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

a
절대 강체 자세 A 순서열 3~1025개
b
A와 같은 수의 절대 강체 자세 B
options
회전 문턱(라디안), 이동 문턱 및 가설 한도를 담은 HandEyeOptions

반환: X, Z, 가설 수와 잔차를 담은 RobotWorldResult

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    solve_robot_world는 대응하는 절대 자세 A와 B, HandEyeOptions를 받아 AX=ZB의 두 변환을 추정합니다. 입력은 같은 개수의 3쌍부터 1025쌍까지이며 각 쌍은 동일한 실제 관측 시점에 대응해야 합니다. 후보 평가에 쓰는 회전 기준은 라디안, 이동 기준은 입력 변환과 같은 길이 단위입니다.

    구체 사례와 판독

    예를 들어 세 자세의 A와 B를 각각 시간순으로 넣을 때 두 번째 A와 두 번째 B는 같은 촬영 상황을 나타내야 합니다. 한 목록만 정렬 순서가 바뀌면 방정식이 실제 장치 운동을 나타내지 않습니다. 반환된 변환의 프레임 방향, 각 잔차, 검색 종료 상태를 확인하고 별도 자세에 적용하여 검증하세요.

    적용 시 확인

    이 호출은 절대 자세로 구성한 문제를 풀며 joint refinement를 수행하지 않습니다. 자세의 방향과 시점 대응을 확인한 뒤 서로 다양한 움직임을 포함하세요. 후보 수를 늘려도 잘못된 기준 프레임이나 단위 혼합은 고쳐지지 않습니다. 결과의 x와 z는 서로 다른 좌표 변환이므로 용도에 맞게 선택합니다. 예를 들어 입력 이동이 mm이면 이동 잔차 기준도 mm입니다. 자세 쌍의 개수가 최소 조건을 만족해도 운동의 다양성과 검증 정확도는 별도로 확인해야 합니다.
