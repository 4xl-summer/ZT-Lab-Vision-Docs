독립적인 성분 스냅샷

BlobAnalysisResult는 실행 수명과 독립적인 블롭 값의 불변 스냅샷을 blobs로 보관합니다. 분석 결과의 각 성분을 나중에 읽기 위해 사용하는 값이며 원본 영상 전체나 원래 핸들을 대신하지는 않습니다.

내용과 해석

blobs에는 측정된 성분 값이 들어 있습니다. 면적은 전경 픽셀 수, 위치는 해당 분석의 좌표 기준으로 읽어야 합니다. 예를 들어 3×3 고리에서 중앙만 배경이면 전경 면적은 8이지만 외접 사각형의 크기는 3×3입니다.

소유와 사용

이 스냅샷은 실행 결과 핸들의 수명과 독립적으로 읽도록 복사된 값입니다. 원본 영상 또는 분석 핸들의 수명 규칙과 분리하여 생각하고, 다른 입력의 결과와 비교할 때는 이미지와 ROI 식별 정보도 함께 보관합니다.
