brightness_rangetuple[float, float] | NoneNone후보/모델 평균 비율의 선택적 포함 범위 (최소, 최대)입니다. 두 값은 유한하고 0 이상이며 순서대로여야 합니다. 기본값 None은 필터를 끕니다.
