필드타입기본값의미와 조건
x_minint필수검색 영상 로컬에서 템플릿 좌상단 x의 포함 하한(정수 픽셀)입니다.
x_maxint필수좌상단 x의 포함 상한이며 x_min 이상이어야 하고 템플릿이 영상 안에 들어가야 합니다.
y_minint필수검색 영상 로컬에서 템플릿 좌상단 y의 포함 하한(정수 픽셀)입니다.
y_maxint필수좌상단 y의 포함 상한이며 y_min 이상이어야 하고 템플릿이 영상 안에 들어가야 합니다.
thresholdfloat필수유한한 판정값입니다. 색 NCC는 −1..1의 하한, Gray SAD는 0..255의 상한입니다.
max_matchesint1반환 상한이며 1..256입니다. 기본값은 1입니다.
max_workint1000000작업량 상한으로 1..100000000이며 기본값은 1000000입니다. 후보 수 × 선택 표본 수 × 채널 수 × 2가 이를 넘으면 오류입니다.
contrast_rangetuple[float, float] | NoneNone후보/모델 표준편차 비율의 선택적 포함 범위 (최소, 최대)입니다. 두 값은 유한하고 0 이상이며 순서대로여야 합니다. 기본값 None은 필터를 끕니다.
brightness_rangetuple[float, float] | NoneNone후보/모델 평균 비율의 선택적 포함 범위 (최소, 최대)입니다. 두 값은 유한하고 0 이상이며 순서대로여야 합니다. 기본값 None은 필터를 끕니다.
