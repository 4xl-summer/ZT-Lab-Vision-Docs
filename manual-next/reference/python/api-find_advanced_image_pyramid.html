find_advanced_image_pyramid 멤버와 선언

공개 타입

zvision.find_advanced_image_pyramid: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._matching_advanced.find_advanced_image_pyramid.

실제로 축소한 영상과 모델을 사용해 지정 층을 검색합니다.

Python
find_advanced_image_pyramid(source, model, options, first_level, last_level)

확인된 인자 조건

source
검색할 ZImage입니다.
model
학습된 모델입니다.
options
AdvancedMatchOptions 값입니다. x·y·angle·scale_x·scale_y에 각각 SearchAxis(minimum, maximum, step)를 지정합니다. 일반 검색에서 x·y는 검색 ROI 로컬 픽셀, angle은 라디안이며 scale은 양수입니다. candidate_budget은 평가 포즈 수 상한입니다. 위치 범위는 원본 픽셀 단위입니다. 마스크 오프셋은 0이어야 하며 subpixel을 쓰면 last_level은 0이어야 합니다. retained_candidates와 coarse_acceptance는 각 층의 후보 유지 조건입니다.
first_level
검색을 시작할 축소 수준입니다.
last_level
검색을 마칠 축소 수준입니다.

반환: 독립 검색 결과와 종료 진단을 반환합니다.

오류: 유효하지 않은 영상, 설정 또는 모델 상태에서는 오류입니다.

first_level: 정수 검사.

last_level: 정수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
