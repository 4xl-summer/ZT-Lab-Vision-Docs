    좌표 쌍의 역할

    Point2는 부동소수점 x와 y를 함께 담는 2차원 점입니다. 두 수는 어떤 API가 이 점을 만들거나 받았는지에 따라 영상 픽셀 좌표, 관심 영역 좌표 또는 다른 좌표계를 나타낼 수 있습니다. 타입 이름만으로 원점이나 길이 단위를 확정할 수 없으므로 호출한 연산의 계약을 같이 읽습니다.

    좌표계를 맞춘 예

    관심 영역 원점이 전체 영상의 (100, 200)이고 점이 그 안의 로컬 좌표 (10, 20)이라면 전체 영상 기준으로 옮긴 위치는 (110, 220)입니다. 반대로 전체 좌표를 로컬 연산에 사용하려면 원점을 빼야 합니다. 좌표 변환이 필요한지 확인하지 않고 숫자만 복사하면 점이 잘못된 위치에 표시됩니다.

    후속 연산

    윤곽 점, 도형 중심 또는 기하 계산에 점을 전달할 때는 좌표의 기준과 단위를 함께 기록합니다. 소수 성분은 픽셀 중심 사이의 위치를 표현할 수 있으므로 화면에 정수로 표시할 때 적용한 반올림 정책은 원래 계산 값과 분리합니다. 점 한 개는 도형의 방향이나 길이를 단독으로 정의하지 않습니다.

    같은 좌표 쌍이라도 표시 대상 이미지의 원점이나 픽셀 간격이 다르면 같은 물리 위치를 뜻하지 않습니다. 점을 저장할 때 생성한 영상과 ROI 정보를 함께 남기면 다른 처리 단계에서 좌표를 다시 맞추기 쉽습니다.
