사용과 결과 해석

보정이나 계측 결과에 붙이는 길이 단위를 선택합니다. 밀리미터, 마이크로미터, 미터는 같은 물리량을 서로 다른 크기의 숫자로 나타냅니다. 예를 들어 1밀리미터는 1000마이크로미터이고 0.001미터입니다. 보정 객체가 저장한 단위와 호출자가 원하는 출력 단위가 다를 수 있으므로 세계점을 변환하거나 평가할 때 전달하는 단위를 확인하십시오. 보류점 평가의 거리 허용치도 평가에서 지정한 세계 단위를 따릅니다. 픽셀 오차는 길이 단위 선택으로 자동 변환되는 물리 오차가 아닙니다. 단위를 혼동해 0.5밀리미터를 0.5마이크로미터로 입력하면 허용 기준이 1000배 달라집니다. 숫자만 비교하지 말고 결과와 기준의 단위를 함께 기록하세요. 같은 길이라도 단위에 따라 표시 숫자가 달라집니다. 예를 들어 10 mm는 1 cm이고, 같은 두 물리 위치의 거리가 바뀐 것은 아닙니다. 좌표 배열 전체와 허용치가 동일 단위를 사용하는지 확인해야 잔차 판정에서 단위 혼합을 막을 수 있습니다. 면적이나 제곱 단위는 길이 변환 계수를 한 번만 곱해 처리할 수 없습니다. 길이의 단위 환산과 면적의 단위 환산은 차원을 확인해 구분하십시오. 결과값의 숫자와 단위를 함께 전달하십시오.
