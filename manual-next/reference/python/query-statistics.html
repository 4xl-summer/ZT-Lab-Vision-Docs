    사용 맥락과 계약

    Statistics는 영상 통계 연산이 돌려주는 독립 값 스냅샷입니다. count는 포함된 픽셀 수, min과 max는 관측한 밝기 범위, mean은 산술 평균, variance는 평균에서의 제곱 편차 합을 픽셀 수로 나눈 모집단 분산입니다. 영상 핸들이 아니므로 결과를 얻은 뒤 원본 영상의 수명과 따로 값을 읽을 수 있습니다. 제공된 숫자 필드의 의미를 원본 영상의 채널 수나 밝기 단위와 함께 확인하세요.

    구체 사례와 판독

    Gray8 세 표본 [0,10,20]을 예로 들면 count는 3, 최솟값은 0, 최댓값은 20, 평균은 10입니다. 편차의 제곱은 100, 0, 100이므로 분산은 200/3입니다. 분모를 2로 나누는 표본 분산을 기대하면 이 값과 달라집니다. 결과가 예상과 다를 때는 선택한 ROI의 픽셀과 실제 입력 형식을 먼저 확인하고, 스냅샷에 없는 히스토그램이나 색상 통계를 추측하지 마세요.

    적용 시 확인

    평균과 분산은 서로 다른 질문에 답합니다. [0,10,20]과 같은 평균을 갖는 일정 영상은 평균이 같아도 분산이 0입니다. 따라서 평균만으로 영상의 밝기 변화나 모든 픽셀의 값을 복원할 수는 없습니다. 빈 영역이나 지원되지 않는 입력은 결과 숫자를 추정하지 말고 호출 오류를 확인하세요.
