Python API · inpaint_anisotropic

inpaint_anisotropic 멤버와 선언

공개 타입

zvision.inpaint_anisotropic: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._wavelet_inpaint_gap.inpaint_anisotropic.

Diffuse only nonzero mask pixels; returns an owned image and change report.

마스크의 비제로 픽셀에 4이웃 이방성 확산을 적용합니다.

Python
inpaint_anisotropic(image, mask, options)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
Gray8, Gray16 또는 GrayF32 영상.
mask
영상과 크기·원점이 같은 Gray8 마스크; 비제로가 복원 대상.
options
InpaintOptions 반복, (0,0.25] timestep, 양의 kappa와 종료 조건.

반환: 독립 소유 GrayF64 영상과 InpaintReport 튜플; 영상을 close합니다.

오류: 전부 마스크된 영상, 잘못된 조건 또는 작업량 초과는 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
