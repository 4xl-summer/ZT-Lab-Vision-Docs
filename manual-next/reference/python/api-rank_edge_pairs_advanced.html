공개 멤버

    사용과 결과 해석

    캘리퍼가 만든 여러 에지에서 진행 방향의 첫째·둘째 극성에 맞는 쌍을 골라 점수 순으로 반환합니다. 각 후보에는 첫 에지, 둘째 에지와 점수가 포함되고, 첫 에지의 프로파일 거리는 둘째보다 작아야 합니다. 합 또는 작은 강도를 기본 점수로 사용하며 선택적으로 예상 위치와 너비에 대한 차이를 감점합니다. 예를 들어 예상 너비를 지정하면 실제 두 거리의 차이가 그 값에서 멀어질수록 점수가 낮아집니다. 너비와 예상 위치는 프로파일의 픽셀 거리이고 강도는 원시 강도/픽셀입니다. 예상값이 None이면 해당 감점은 생략됩니다. 에지 순서를 영상의 고정 왼쪽·오른쪽으로 가정하지 말고 탐색 방향을 확인하십시오. 비유한 값, 음수 예상 폭 또는 비교 작업량 초과는 오류입니다. 가령 두 에지가 거리 2와 7에 있으면 진행 방향을 따른 폭은 5픽셀입니다. 예상 폭을 지정했다면 이 5와 예상값의 차이가 점수에 사용됩니다. 서로 다른 후보의 점수만 저장하지 말고 선택된 두 거리와 극성도 남겨야 후속 검토에서 순위의 근거를 이해할 수 있습니다. 두 거리의 차이는 시작점이 같을 때 정의됩니다. 다른 프로파일의 거리를 무작위로 짝지어 같은 폭으로 취급하지 마십시오. 결과 순위와 후보 수를 함께 살핍니다.
