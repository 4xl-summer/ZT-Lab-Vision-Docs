공개 타입

zvision.pixel_add_wrap: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._arithmetic_gap.pixel_add_wrap.

Add matching integer images with componentwise modular wrap.

같은 형식의 정수 영상을 성분별 모듈러 덧셈합니다.

공개 멤버

    사용 맥락과 계약

    pixel_add_wrap은 대응 픽셀을 더할 때 8비트 범위를 넘는 값을 순환시키는 산술 연산입니다. 포화 덧셈처럼 최대값에 고정하는 것과 다르며 256을 기준으로 나머지를 취하는 방식으로 이해할 수 있습니다. 두 영상은 대응 픽셀끼리 계산되므로 영상 크기와 형식 등 호출의 입력 조건이 맞아야 합니다.

    구체 사례와 판독

    예를 들어 250과 10을 더한 수학적 결과는 260이지만 8비트 순환 결과는 260−256=4입니다. 250+5는 범위 안의 255이고 255+1은 0이 됩니다. 밝기 보정에서 포화를 기대하고 이 함수를 사용하면 밝은 영역이 어둡게 돌아갈 수 있으므로 사용 목적을 먼저 확인하세요. 결과는 새 영상으로 관리하며 경계값을 포함해 검증합니다.

    적용 시 확인

    이 연산의 순환 결과는 8비트 정수 표현에 관한 것이며 물리적 광량이 실제로 256에서 0으로 바뀐다는 의미는 아닙니다. 연속된 밝기 비교나 임계값 검사는 이러한 경계에서 뜻밖의 결과를 낼 수 있습니다. 입력과 결과의 형식, 각 픽셀의 대응 관계를 시험 영상으로 확인하고 사용하세요. 예를 들어 두 입력이 각각 1×1 픽셀일 때 결과 4가 나오면 260으로 포화되지 않은 것을 분명하게 확인할 수 있습니다. 입력의 좌표와 값을 기록해 결과를 다시 확인할 수 있습니다.
