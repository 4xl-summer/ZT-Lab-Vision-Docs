Python API · flexible_rank

flexible_rank 멤버와 선언

공개 타입

zvision.flexible_rank: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._processing_flexible.flexible_rank.

Select floor(quantile*(n-1)) among the active kernel footprint samples.

활성 창 표본의 정렬 순위 floor(q×(n−1))를 선택합니다.

Python
flexible_rank(image, width, height, anchor_x, anchor_y, quantile=0.5, footprint=None, border=0, constant=0.0, output_format=3)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • anchor_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • anchor_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • quantile · POSITIONAL_OR_KEYWORD · 기본값 0.5
  • footprint · POSITIONAL_OR_KEYWORD · 기본값 None
  • border · POSITIONAL_OR_KEYWORD · 기본값 0
  • constant · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • output_format · POSITIONAL_OR_KEYWORD · 기본값 3

확인된 인자 조건

image
입력 ZImage입니다.
width
양의 창 너비입니다.
height
양의 창 높이입니다.
anchor_x
창 안의 X 앵커입니다.
anchor_y
창 안의 Y 앵커입니다.
quantile
0–1 분위이며 기본값은 0.5입니다.
footprint
활성 창 위치의 바이트 배열 또는 None입니다.
border
경계 정책이며 기본값은 0입니다.
constant
상수 경계 밝기이며 기본값은 0입니다.
output_format
요청할 출력 형식이며 기본값은 3입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

quantile: 유한한 수 검사.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
