calculate_gradients

method · 선언 타입 zvision._edge_query_result.EdgeQuery

Python
calculate_gradients(self, image, kernel, sigma, features, work_budget)

원래 추출 이미지에 가우시안과 Sobel을 적용하고 에지 점에서 응답을 저장합니다. 각도는 영상 Y 아래 방향 기준 atan2이며 접선이 아닌 법선 방향입니다.

확인된 인자 조건

image
추출 이미지로, ROI 크기와 원점이 일치해야 합니다.
kernel
1–127 범위의 홀수 가우시안 창 크기입니다.
sigma
유한한 양의 가우시안 표준편차입니다.
features
크기 16, 각도 32 또는 두 비트의 조합입니다.
work_budget
양의 작업 예산입니다.

반환: None을 반환합니다.

오류: 프레임, 기능, 창, 시그마 또는 작업 예산이 유효하지 않으면 오류입니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sigma · POSITIONAL_OR_KEYWORD · 기본값 없음
  • features · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Store bilinear Sobel normal magnitude/angle; +y points down.

The image must match the bound source frame; angle is atan2(gy,gx)
in radians and zero gradient has angle 0. Sobel uses replicated ROI
borders. The caller must supply the original extraction image.
