Python API · intersect_plane

intersect_plane 멤버와 선언

공개 타입

zvision.intersect_plane: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.intersect_plane.

Intersect a calibrated pixel ray with a same-frame world plane.

보정된 픽셀 광선과 동일 세계 프레임의 평면을 교차합니다.

Python
intersect_plane(lens, pixel, pose, plane, options, min_abs_cos=1e-09, allow_behind=False)

인자 선언

  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pixel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • plane · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_abs_cos · POSITIONAL_OR_KEYWORD · 기본값 1e-09
  • allow_behind · POSITIONAL_OR_KEYWORD · 기본값 False

확인된 인자 조건

lens
카메라 LensModel입니다.
pixel
전역 픽셀 Point2입니다.
pose
카메라에서 세계로의 RigidTransform3입니다.
plane
세계 평면 WorldPlane입니다.
options
광선 역산 RayOptions입니다.
min_abs_cos
평행에 가까운 광선을 거르는 최소 절대 코사인이며 기본값은 1e-9입니다.
allow_behind
광선 원점 뒤 교점을 허용할지 정하는 bool이며 기본값은 False입니다.

반환: 교점과 광선 진단을 담은 PlaneHit 값입니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

min_abs_cos: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
