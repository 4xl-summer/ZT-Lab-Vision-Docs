공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    max_countint필수허용 결함 수 상한으로 0 이상이며 등호를 포함합니다.
    max_total_areaint필수허용 총 면적 상한으로 픽셀 수이며 등호를 포함합니다.
    max_single_areaint필수각 결함의 허용 면적 상한으로 픽셀 수이며 등호를 포함합니다.
    allowed_regiontuple[int, int, int, int]필수모든 결함 경계를 포함해야 하는 로컬 반열림 (x, y, 너비, 높이)이며 크기는 양수입니다.

    사용과 결과 해석

    후보 목록을 받은 뒤 허용할 결함의 수, 전체 면적, 개별 면적 및 위치를 정의하는 값입니다. max_count는 후보 개수이고 max_total_area와 max_single_area는 전경 픽셀 수로 측정한 면적의 상한입니다. 허용 사각형 allowed_region은 현재 영상의 로컬 (x,y,width,height)이며 폭과 높이가 양수여야 합니다. 각 후보의 전체 경계가 이 영역 안에 있어야 위치 조건을 통과합니다.

    상한과 같은 값은 허용됩니다. 예를 들어 단일 면적 상한이 4이면 면적 4의 후보는 이 조건에 맞고 면적 5는 위반합니다. 후보가 하나도 없어야 한다면 개수와 면적 한도를 0으로 지정할 수 있습니다. 허용 영역은 판정 API가 받는 독립 사각형이므로 영상 크기에 자동으로 맞춰진다고 가정하지 말고 현재 마스크와 같은 로컬 좌표로 정합니다.

    SurfaceDefectResult에서 Judge를 호출한 뒤 Passed와 Reasons를 함께 읽으면 통과 여부와 원인을 분리할 수 있습니다. 개별 Rejections는 단일 면적 또는 위치 위반을 기록하며 전체 개수나 총 면적 위반은 전체 이유에서 확인합니다. 잘못된 빈 사각형은 정상적인 불합격이 아니라 입력 오류입니다.
