Python API · calibrate_radial_lines

calibrate_radial_lines 멤버와 선언

공개 타입

zvision.calibrate_radial_lines: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.calibrate_radial_lines.

Locally estimate one radial coefficient and center from ordered line contours.

정렬된 직선 윤곽에서 방사 왜곡 계수 하나와 중심을 추정합니다.

Python
calibrate_radial_lines(lines, options)

인자 선언

  • lines · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

lines
윤곽선 3~16개, 각각 점 5~128개와 전체 최대 1024점
options
초기 렌즈 값과 최대 25회 반복 등 RadialSelfOptions

반환: k1, 중심, RMS 및 반복 상태의 RadialSelfResult

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    calibrate_radial_lines는 순서가 있는 직선 윤곽들로부터 방사 계수 한 항과 중심을 국소적으로 추정합니다. 윤곽은 3개부터 16개까지, 각 윤곽은 5점부터 128점까지이며 전체 점 수는 1024개 이하여야 합니다. RadialSelfOptions에 알려진 fx, fy와 초기 중심·계수 및 최적화 조건을 전달합니다.

    구체 사례와 판독

    예를 들어 화면을 가로지르는 여러 실제 직선이 왜곡 영상에서 휘어 보일 때 각 선의 픽셀 점들을 순서대로 수집합니다. 한 직선의 점을 다른 직선 목록에 잘못 섞으면 모델에 잘못된 제약이 들어갑니다. 반환된 잔차와 종료 상태를 확인하고 입력에 쓰지 않은 선도 보정해 직선성이 좋아졌는지 검증하세요.

    적용 시 확인

    이 알고리즘의 결과는 국소 최적화 결과이며 한 항의 방사 모델에 한정됩니다. 충분히 다양한 방향과 위치의 선을 확보하지 못하면 중심과 왜곡을 구별하기 어려울 수 있습니다. 수렴 상태와 입력 영상의 좌표 원점을 기록하고 결과를 현재 렌즈 설정에만 적용할 수 있는지 검증합니다. 직선 윤곽의 각 점 수가 범위를 벗어나거나 총합이 1024를 넘으면 입력 조건에 맞지 않습니다. 선의 ID와 점 순서를 함께 저장하세요. 각 윤곽을 구분하세요.
