simplify_contour 멤버와 선언

공개 타입

zvision.simplify_contour: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._regions_flexible.simplify_contour.

RDP contour reduction; closed input uses implicit last-to-first edge.

RDP 방식으로 점 경로를 허용 오차 내에서 단순화합니다.

Python
simplify_contour(points, tolerance, closed, work_budget)

공개 멤버

    허용 오차로 경로 단순화

    순서 있는 점 경로를 Ramer–Douglas–Peucker 방식으로 단순화합니다. 허용 오차를 이용해 세부 점을 줄이면서 경로의 형상을 근사하므로 반환 점 수와 원본 점 수는 일반적으로 다를 수 있습니다. 좌표의 단위가 픽셀이면 tolerance도 같은 좌표 단위로 해석해야 합니다.

    선분과 오차

    일직선에 놓인 중간 점은 양 끝점을 잇는 선분으로 나타낼 수 있지만, 크게 벗어난 점은 형상 유지에 중요합니다. 허용 오차를 키우면 세부 굴곡이 더 많이 생략될 수 있고 작게 잡으면 더 많은 점을 남깁니다. 필요한 곡선의 세부 크기에 비해 허용 오차가 크지 않은지 원본과 겹쳐 확인합니다.

    입력과 사용

    Point2 점의 순서를 보존하고 tolerance, 경로 닫힘 여부, 작업량 제한을 전달합니다. 닫힌 경로를 열린 경로처럼 취급하면 양 끝의 연결이 형상 해석에 영향을 주므로 closed를 원본 경로에 맞춥니다. 단순화 결과는 근사 경로이므로 정밀한 면적이나 거리의 허용 오차는 별도로 평가합니다.

    단순화 전후의 길이나 면적이 정확히 같다고 가정해서는 안 됩니다. 후속 계산이 작은 홈이나 모서리에 민감하면 이 부분을 충분히 보존하는 허용 오차를 선택하고 원래 경로와 비교합니다.
