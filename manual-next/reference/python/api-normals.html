Python API · normals

normals 멤버와 선언

공개 타입

zvision.normals: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.normals.

지정 이웃 방식으로 슬롯별 법선을 추정합니다.

Python
normals(cloud, method, viewpoint, radius=1.0, width=0, height=0, pixel_radius=0)

인자 선언

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • method · POSITIONAL_OR_KEYWORD · 기본값 없음
  • viewpoint · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • width · POSITIONAL_OR_KEYWORD · 기본값 0
  • height · POSITIONAL_OR_KEYWORD · 기본값 0
  • pixel_radius · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
method
0 반경, 1 격자 사각 이웃, 2 k-d 트리 반경
viewpoint
부호를 향하게 할 유한 Point3 시점; 점군 frame과 단위
radius
방식 0/2의 양의 반경, 점군 단위; 기본 1.0
width
방식 1의 양의 격자 폭; 기본 0
height
방식 1의 양의 격자 높이; width×height가 슬롯 수와 같아야 함; 기본 0
pixel_radius
방식 1의 양의 정수 이웃 반경, 픽셀; 기본 0

반환: 독립 Point3 또는 None 목록; 결측·퇴화나 이웃 부족은 None입니다.

오류: 방식 또는 필요한 이웃 파라미터가 무효이면 오류입니다.

method: 정수 검사.

radius: 유한한 수 검사.

width: 정수 검사.

height: 정수 검사.

pixel_radius: 정수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
