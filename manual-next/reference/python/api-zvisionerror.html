사용 맥락과 계약

ZVisionError는 네이티브 SDK가 실패 상태를 반환했을 때 Python 호출 경계에서 전달하는 예외입니다. status_code는 반환된 상태의 정수이고 operation은 실패한 SDK 연산을 식별합니다. 정상 결과를 담는 객체가 아니므로 반환값의 빈 목록이나 매치 미발견 상태와 같은 것으로 해석하지 않아야 합니다. 프로그램에서는 실패한 호출의 operation과 status_code를 함께 기록한 다음 그 호출에 들어간 영상 형식, 크기, 옵션을 살펴보는 것이 좋습니다.

구체 사례와 판독

예를 들어 ROI 생성 요청이 입력의 보이는 범위를 벗어나면, 이후 알고리즘의 픽셀 결과를 검사하기 전에 생성 단계의 오류를 조사해야 합니다. 예외가 발생했다는 사실만으로 어느 하드웨어나 전체 알고리즘을 진단할 수는 없습니다. 라이브러리 로딩 실패나 Python 타입 검증은 다른 예외로 나타날 수 있으므로 모든 실패가 이 클래스라고 가정하지 마세요. 소유 영상은 실패 경로에서도 with 또는 close로 정리하고, 재현 시 SDK 버전과 최초 오류를 함께 남깁니다.

적용 시 확인

상태 코드를 기록할 때 사용자에게 표시한 메시지만 남기면 실패한 연산을 구별하기 어렵습니다. 동일 입력에서 다시 실행할 수 있도록 operation, status_code와 호출 인자를 함께 보존하고, 오류가 처리된 뒤에도 이미 취득한 소유 객체의 종료를 빠뜨리지 마세요.
