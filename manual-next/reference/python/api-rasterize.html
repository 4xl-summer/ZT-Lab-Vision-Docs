Python API · rasterize

rasterize 멤버와 선언

공개 타입

zvision.rasterize: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.rasterize.

카메라 좌표 점을 가장 가까운 출력 픽셀의 깊이 격자로 만듭니다.

Python
rasterize(cloud, width, height, camera, convention=0, collision=0)

인자 선언

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • camera · POSITIONAL_OR_KEYWORD · 기본값 없음
  • convention · POSITIONAL_OR_KEYWORD · 기본값 0
  • collision · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
width
양의 정수 출력 폭, 픽셀 수
height
양의 정수 출력 높이, 픽셀 수
camera
Camera: fx/fy는 유한 양수, cx/cy와 5개 왜곡 계수는 유한한 카메라 내참수
convention
정수 깊이 정의: 0은 축 방향 Z, 1은 카메라까지 거리; 기본 0
collision
같은 픽셀 충돌 처리: 0 최소(기본), 1 최대, 2 평균

반환: 새 소유 DepthMap; 비투영 슬롯은 결측이며 사용 후 닫습니다.

오류: 크기·내참수·방식이 잘못되면 오류입니다. 뒤쪽 또는 범위 밖 점은 건너뜁니다.

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

convention: 정수 검사.

collision: 정수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
