    사용과 결과 해석

    QR 또는 Data Matrix 오류 정정 진단에서 한 블록의 코드워드 수를 나타내는 값입니다. data_codewords, parity_codewords, corrected_codewords가 각각 데이터, 패리티, 실제 정정된 코드워드의 수입니다. 모듈 하나와 코드워드 하나는 같은 단위가 아니므로 정정 수를 손상 픽셀 수로 읽지 않습니다.

    예를 들어 어떤 블록의 corrected_codewords가 2라면 해당 진단에서 두 코드워드를 정정한 것으로 기록된 것입니다. 이 수치만으로 원래 영상에서 손상된 모듈 위치나 다른 블록의 결과를 복원할 수 없습니다. 전체 결과의 blocks와 총 corrected_codewords를 함께 확인합니다.

    정정 한도는 진단 결과의 수락을 검사하는 조건이며 디코더의 정정 자체를 더 많이 수행하도록 설정하는 값이 아닙니다. 결과는 주어진 입력과 설정에 대한 관찰이고 점수나 표준 검증기 품질 등급으로 취급하지 않습니다.

    예를 들어 두 블록이 있다면 각 블록의 정정 수를 따로 확인해야 어느 블록이 한도에 가까운지 알 수 있습니다. 패리티 수만으로 실제 입력에서 정정된 수를 대신 계산하지 않습니다.
