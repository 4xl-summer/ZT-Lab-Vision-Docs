Python API · photometric_stereo

photometric_stereo 멤버와 선언

공개 타입

zvision.photometric_stereo: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_photometric.photometric_stereo.

Estimate signed normals/shape from exactly four calibrated illumination images.

보정된 조명 영상들로 반사, 법선과 표면 형상을 추정합니다.

Python
photometric_stereo(images, options, mask=None)

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

images
정확히 네 개의 동일 기하 조명 영상 시퀀스.
options
PhotometricOptions의 네 조명 벡터 및 출력·작업 한도.
mask
선택적 동일 기하 Gray8 마스크; None은 전체.

반환: 호출자가 close할 PhotometricResult 소유 객체.

오류: 입력·기하·조명 조건 또는 작업량 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    정확히 네 장의 조명 영상과 각각에 대응하는 보정된 조명 벡터로 반사량, 법선 및 표면 형상을 추정합니다. images의 순서와 options.lights의 순서가 맞아야 하고 영상의 기하가 일치해야 합니다. 선택적 mask는 같은 기하의 Gray8 영상이며 None이면 전체 영역을 대상으로 합니다.

    조명 벡터는 각 세 성분이며 신호 문턱, 역조건수, 픽셀 간격 및 작업 상한이 계산 가능 영역에 영향을 줍니다. 방향이 서로 충분히 다른 보정 조명을 사용해야 표면 법선을 제약할 수 있습니다. mask로 제외된 곳과 실제로 유효한 표면값을 구별하기 위해 반환 결과의 valid 영상을 함께 확인하십시오.

    결과 PhotometricResult는 소유 객체이고 image로 얻은 각 출력도 별도로 close합니다. 이 알고리즘의 형상은 입력 조명 보정과 모델 가정에 의존하므로 단일 예제의 출력만으로 실제 장비의 물리 정밀도를 보증하지 않습니다.
