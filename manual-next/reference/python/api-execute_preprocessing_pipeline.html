Python API · execute_preprocessing_pipeline

execute_preprocessing_pipeline 멤버와 선언

공개 타입

zvision.execute_preprocessing_pipeline: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._preprocess_pipeline_gap.execute_preprocessing_pipeline.

Apply enabled stages in order and return an owned image and report.

활성 Gray8 전처리 단계를 순서대로 실행합니다.

Python
execute_preprocessing_pipeline(image, stages)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • stages · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
Gray8 입력 ZImage입니다.
stages
최대 64개의 PipelineStage 순서열입니다.

반환: 닫아야 하는 독립 영상과 PipelineReport의 쌍입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    execute_preprocessing_pipeline은 입력 영상과 최대 64개의 PipelineStage를 받아 활성 단계를 목록 순서대로 적용합니다. 결과는 소유 영상과 실행·건너뜀 개수를 기록한 보고입니다. 양자화, 중앙값, 가우시안 단계는 각 단계에 맞는 매개변수를 지정해야 하며 enabled가 거짓인 단계는 건너뜁니다.

    구체 사례와 판독

    예를 들어 양자화 단계 다음에 가우시안 단계를 두면 첫 결과를 두 번째 단계의 입력으로 사용합니다. 비활성 단계가 하나 있으면 보고의 skipped로 확인할 수 있습니다. 순서를 바꾼 파이프라인은 같은 구성요소를 사용해도 다른 결과를 낼 수 있으므로 단계 순서를 설정과 함께 기록하세요. 반환된 영상은 필요할 때까지 유지하고 사용 후 정리합니다.

    적용 시 확인

    한 번에 전체 체인을 적용하기 전에 작은 합성 영상으로 한 단계씩 검증하면 기대값을 계산하기 쉽습니다. 이후 전체 파이프라인의 보고와 출력을 함께 확인하세요. 64개를 넘는 목록은 허용되지 않으며 단계 비활성화는 해당 연산의 실행 자체를 건너뜁니다. 영상의 형식과 결과를 비교하는 기준도 고정합니다. 처리 단계가 전부 비활성인 경우에도 보고를 확인하고 반환 영상의 소유권을 관리해야 합니다.
