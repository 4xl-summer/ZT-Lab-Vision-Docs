사용 조건과 흐름

BeadPolarity는 경로를 따라 비드의 양쪽 경계를 찾을 때 대상이 주변보다 밝은지 어두운지 지정합니다. BRIGHT는 밝은 비드, DARK는 어두운 비드에 해당하며 BeadOptions의 polarity로 사용합니다. 값은 비드의 물리적 재질이나 결과 합격 여부가 아니라 영상의 명암 관계를 나타냅니다.

구체 사례와 결과 판독

예를 들어 배경이 20이고 비드가 180인 밝기 영상이라면 밝은 비드 방향을 선택합니다. 반대로 배경이 180이고 비드가 20이면 어두운 방향이 맞습니다. 조명이 바뀌어 극성이 뒤집히면 기존 옵션으로 양쪽 경계를 안정적으로 찾지 못할 수 있습니다. 촬영 영상과 대비 임계값을 확인한 뒤 검출된 폭과 경계 위치를 살펴보세요.

적용 시 확인

극성만으로 폭과 품질의 합격을 정하지 않습니다. 기대 폭, 최소·최대 폭, 중심 이동과 대비 기준도 함께 설정해야 합니다. 알려진 정상 비드와 결함 구간에서 두 경계가 실제 비드의 양쪽을 따라가는지 검증하세요. 예를 들어 표면 반사가 심하면 비드의 일부가 예상과 반대 밝기로 보일 수 있습니다. 프로브별 검출 결과를 영상 위에 겹쳐 확인해 극성과 경계가 실제 대상에 맞는지 검증합니다. 입력과 결과의 설정을 함께 보관하세요.
