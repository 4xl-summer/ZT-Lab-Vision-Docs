fit_lens_from_rays 멤버와 선언

공개 타입

zvision.fit_lens_from_rays: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._metrology_advanced.fit_lens_from_rays.

Estimate selected lens parameters from known normalized camera rays.

정규화 광선과 관측으로 선택된 렌즈 계수를 추정합니다.

Python
fit_lens_from_rays(rays, observed, initial, options)

공개 멤버

    사용과 결과 해석

    알려진 정규화 카메라 광선과 대응하는 관측 픽셀을 사용해 초기 렌즈 모델의 선택된 계수를 정련합니다. rays와 observed는 같은 수와 같은 순서의 Point2 열이며, 전자는 정규화된 광선 좌표이고 후자는 픽셀 좌표입니다. initial에는 시작 모델, options에는 최적화할 계수 마스크와 반복 설정을 전달합니다. 반환된 모델의 재투영 RMS는 픽셀 단위이며 수렴 상태도 같이 확인해야 합니다. 광선과 픽셀 순서를 섞거나 한 영역에만 대응점이 몰리면 유효한 수치라도 의도한 보정이 되지 않을 수 있습니다. 비유한 값과 길이가 다른 배열, 퇴화한 최적화 문제는 오류입니다. 적합에 사용하지 않은 다른 광선·관측 쌍에서 예측값을 비교하면 특정 학습 자료만의 일치를 구별할 수 있습니다. 입력 쌍은 하나의 광선과 그 광선이 관측된 이미지 위치를 뜻합니다. 첫 번째 광선이 두 번째 픽셀에 대응하도록 순서가 섞이면 배열 길이가 같더라도 다른 문제를 풀게 됩니다. 카메라의 시야에 걸친 관측을 준비하고 별도 보류 쌍을 사용해 학습 이후의 예측을 확인하십시오. 정규화 광선 좌표를 이미지 픽셀 좌표로 그대로 취급하지 마십시오. 두 입력은 서로 다른 역할의 짝이며 같은 배열에 합쳐 놓은 점의 집합이 아닙니다.
