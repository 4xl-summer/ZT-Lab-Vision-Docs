WorldPlane 멤버와 선언

공개 타입

zvision.WorldPlane: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.WorldPlane.

World origin, orthonormal U/V axes, length unit and nonzero world frame ID.

세계 평면의 원점, 축, 단위와 프레임을 지정합니다. 축의 직교 정규 조건은 기하 연산 시 검증합니다.

Python
WorldPlane(origin, axis_u, axis_v, unit, world_frame)

인자 선언

  • origin · POSITIONAL_OR_KEYWORD · 기본값 없음
  • axis_u · POSITIONAL_OR_KEYWORD · 기본값 없음
  • axis_v · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음
  • world_frame · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

origin
세계 프레임의 원점 Point3입니다.
axis_u
세계 프레임의 U축 단위 Point3입니다.
axis_v
U축에 직교하는 V축 단위 Point3입니다.
unit
평면 좌표의 LengthUnit입니다.
world_frame
0이 아닌 세계 프레임 ID 정수입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
