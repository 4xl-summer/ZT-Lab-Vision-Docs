열거 값

  • HARD = 0 · 경계 아래 세부 계수를 제거하는 경성 축소입니다.
  • SOFT = 1 · 세부 계수 크기를 임계치만큼 줄이는 연성 축소입니다.

사용과 결과 해석

웨이블릿 세부 계수에 적용할 임계 축소 방식을 선택합니다. HARD는 임계치 아래의 세부 계수를 제거하고, SOFT는 세부 계수의 크기를 임계치만큼 줄입니다. 이 열거형은 어떤 계수를 어떻게 바꿀지 정하는 정책이며 역변환 자체를 수행하지 않습니다.

예를 들어 크기가 임계치보다 큰 양의 계수는 HARD에서 유지되는 반면 SOFT에서는 임계치만큼 작아집니다. 임계값의 경계와 부호는 사용 중인 shrink 연산의 계약에 따라 해석해야 합니다. 같은 임계값이라도 두 정책의 남은 계수가 달라 재구성 영상도 달라질 수 있습니다.

보통 변환을 만든 뒤 세부 계수를 축소하고 역변환 결과를 확인합니다. 잡음이 줄어든 모양이 곧 실제 결함 보존을 보장하지는 않으므로 원본과 처리 결과를 비교하고 허용 오차와 목적에 맞는 임계값을 별도로 선정하십시오.
