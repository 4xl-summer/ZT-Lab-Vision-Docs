사용 조건과 흐름

SsimWindow는 국소 구조 유사도 계산에서 윈도 안의 픽셀에 주는 가중 방식을 선택합니다. BOX는 균일한 상자형 가중이고 GAUSSIAN은 중심에 가까운 샘플에 더 큰 가중을 주는 방식입니다. 반경과 가우시안 sigma 등 나머지 설정은 SsimOptions에서 지정합니다.

구체 사례와 결과 판독

예를 들어 같은 3×3 이웃에서도 BOX는 각 위치를 같은 비중으로 고려하지만 GAUSSIAN은 중심과 주변의 비중이 다를 수 있습니다. 결과 점수와 결함 마스크는 윈도 선택에 따라 달라질 수 있으므로 두 모드에 동일한 임계값을 무조건 재사용하지 마세요. 같은 정렬 영상과 포함 마스크로 비교해 적절한 설정을 정합니다.

적용 시 확인

윈도의 영상 경계 처리 방식은 SsimBorder에서 별도로 정합니다. 윈도 종류와 반경이 같아도 CLIP과 REPLICATE의 가장자리 결과는 다를 수 있습니다. 유사도 맵의 국소 결과와 전체 평균, 포함 픽셀 수를 함께 확인하세요. 반경을 늘리면 한 점의 점수가 더 넓은 이웃의 영향을 받으므로 작은 결함의 위치별 응답도 달라질 수 있습니다. 검사하려는 결함의 크기에 맞춰 검증 데이터를 사용해 선택하세요. 입력과 결과의 설정을 함께 보관하세요.
