    사용 맥락과 결과 해석

    초기 형상 포즈 주변을 국소 정밀화한 결과입니다. match는 유효 포즈가 발견되면 AdvancedMatch이고 없으면 None입니다. evaluated는 평가된 포즈 수, converged는 간격 기준 도달 여부, budget_exhausted는 평가 예산 소진 여부를 나타냅니다. 이 상태들은 각각 확인해야 합니다.

    converged가 참이어도 전역 최적이나 실측 정확도가 보장되지는 않습니다. 위치·각도·배율의 서로 다른 단위를 가진 간격에 수치적 tolerance가 적용되기 때문입니다. match가 None이면 이전 초기 포즈를 자동으로 성공 결과로 바꾸지 말고 별도 상태로 처리하세요. 결과는 독립 값이며 원래 영상과 모델의 검색 수명과 구별됩니다.

    match 항목: 유효한 정밀화 포즈가 있으면 AdvancedMatch이고 없으면 None입니다. evaluated 항목: 평가한 포즈 수입니다. converged 항목: 간격이 수치적 허용 기준에 도달했는지 나타냅니다. budget_exhausted 항목: 평가 예산이 소진되었는지 나타냅니다.
