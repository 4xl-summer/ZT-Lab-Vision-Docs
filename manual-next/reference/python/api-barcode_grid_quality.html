barcode_grid_quality 멤버와 선언

공개 타입

zvision.barcode_grid_quality: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.barcode_grid_quality.

Cell contrast, modulation and regularity diagnostics; not ISO grades.

그리드 셀의 대비·변조도·규칙성을 계산합니다. ISO 등급은 아닙니다.

Python
barcode_grid_quality(image, region, columns, rows, inset_fraction=0.0)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • region · POSITIONAL_OR_KEYWORD · 기본값 없음
  • columns · POSITIONAL_OR_KEYWORD · 기본값 없음
  • rows · POSITIONAL_OR_KEYWORD · 기본값 없음
  • inset_fraction · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

image
Gray8 ZImage
region
로컬 (x,y,width,height), 픽셀
columns
열 수 1 이상이고 영역 너비 이하
rows
행 수 1 이상이고 영역 높이 이하
inset_fraction
셀 안쪽 여백 비율 0 이상 0.5 미만

반환: 독립 BarcodeGridQuality

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

columns: 정수 검사 · 최소 1.

rows: 정수 검사 · 최소 1.

inset_fraction: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
