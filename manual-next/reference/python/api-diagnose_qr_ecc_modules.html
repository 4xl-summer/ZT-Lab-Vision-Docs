공개 타입

zvision.diagnose_qr_ecc_modules: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.diagnose_qr_ecc_modules.

Recompute RS diagnostics for an upright sampled QR module grid.

샘플링된 QR에서 실제 RS 정정 결과를 진단합니다.

Python
diagnose_qr_ecc_modules(image, max_corrected_per_block)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
정방향 Gray8 격자, 모듈당 1픽셀, 0 검정·255 흰색, quiet zone 없음
max_corrected_per_block
정정 후 수락 판정의 블록별 정정 코드워드 상한

반환: 독립 QrEccDiagnostics

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    샘플된 QR 모듈 격자에 실제 Reed–Solomon 오류 정정 진단을 수행합니다. 입력은 바로 선 Gray8 격자로 모듈 하나가 픽셀 하나에 대응하고 검정은 0, 흰색은 255이며 바깥 여백은 포함하지 않습니다. max_corrected_per_block은 정정 후 각 블록의 수정 코드워드 수를 판정하는 한계입니다. 이 값은 디코더가 실행하는 정정량이나 QR에 기록된 ECC 등급을 바꾸지 않습니다.

    구체 사례와 결과 판독

    예를 들어 한 블록에서 코드워드 2개가 수정되었다면 한계 1은 판정 조건을 넘고 한계 2는 해당 블록 조건을 만족합니다. 반환 텍스트, 버전, 블록별 정정 수와 accepted를 함께 읽으세요. 코드워드 개수는 손상된 픽셀 수나 읽기 성공 확률, ISO 품질 등급이 아닙니다. 모듈 격자가 아니라 카메라 영상이라면 영상 검출을 수행하는 별도 함수를 사용해야 합니다.

    적용 시 확인

    여백이 있거나 회전된 격자를 그대로 넣으면 이 입력 경로의 샘플 조건과 다릅니다. 검출과 격자 생성을 먼저 검증하고, 오류 정정 후 판정과 해독 실패를 분리하여 기록하세요. QR의 블록이 여러 개이면 총 정정 수만 보지 말고 각 블록의 수정 수가 한계 이내인지 확인해야 합니다. 블록별 한계는 전체 합계 한계와 다릅니다.
