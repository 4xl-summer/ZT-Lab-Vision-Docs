사용 조건과 흐름

HandEyePair는 AX=XB 핸드아이 문제의 대응 운동 A와 B, 그리고 weight를 묶습니다. a와 b는 RigidTransform3이며 같은 실제 운동에 대응해야 합니다. weight의 기본값은 1입니다. 각 변환의 프레임 방향과 이동 길이 단위를 통일해야 반환된 변환의 의미를 올바르게 해석할 수 있습니다.

구체 사례와 결과 판독

예를 들어 로봇 자세 두 시점의 상대 운동 A와 같은 두 시점의 카메라 관측에서 만든 상대 운동 B를 하나의 쌍으로 사용합니다. 한쪽이 다른 시점의 영상에서 나온다면 방정식의 두 항은 같은 운동을 표현하지 않습니다. 추정 후에는 입력별 회전 잔차를 라디안으로, 이동 잔차를 선택한 길이 단위로 확인하세요.

적용 시 확인

한 쌍의 회전과 이동이 모두 거의 없으면 X를 구분하는 정보가 부족할 수 있습니다. 다양한 회전 운동을 포함한 여러 쌍을 준비하고 각 목록의 시간 대응을 확인하세요. 가중치만 크게 정해도 잘못된 프레임이나 단위가 수정되지는 않습니다. 예를 들어 동일한 움직임에 대해 로봇이 밀리미터를 사용하고 카메라 변환이 미터를 사용하면 이동 항이 서로 일치하지 않습니다. 한 단위로 바꾼 후 여러 쌍을 구성합니다. 입력과 결과의 설정을 함께 보관하세요.
