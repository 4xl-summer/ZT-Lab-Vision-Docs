    사용과 결과 해석

    원 또는 원호 측정의 기준 중심, 반경과 탐색 각도 범위를 지정합니다. center와 radius는 현재 영상의 ROI 로컬 픽셀 기준이며 반경은 유한한 양수입니다. start_angle과 end_angle은 라디안이고 끝에서 시작을 뺀 범위는 0보다 크고 한 바퀴 이하입니다. 예를 들어 0부터 π까지 지정하면 기준 원의 절반을 따라 프로브가 배치되고 0부터 2π까지면 전체 원을 조사합니다. 전체 한 바퀴의 경우 같은 시작점과 끝점을 중복된 프로브로 사용하지 않습니다. 기준 원이 최종 결과와 반드시 같아야 한다는 뜻은 아니며 각 앵커의 탐색선이 실제 경계를 가로질러야 피팅에 쓸 점을 얻습니다. 범위가 영상 밖으로 나가거나 에지가 충분하지 않을 때 결과 상태를 별도로 확인하십시오. 반원 구간의 끝 각과 전체 원의 끝 각은 라디안으로 다릅니다. 관측점이 기준 원의 어느 방향에 분포하는지 결과와 함께 기록하면 원호가 짧아 적합이 불안정할 가능성을 파악할 수 있습니다. ROI 원점을 바꾼 영상에는 기준 중심도 해당 로컬 좌표로 다시 표현해야 합니다. 기준 반경은 탐색 위치를 만드는 입력입니다. 최종 반경이 달라졌을 때는 관측된 에지와 검색 길이부터 확인하십시오.
