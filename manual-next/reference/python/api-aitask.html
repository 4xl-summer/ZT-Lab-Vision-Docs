열거 값

  • CLASSIFICATION = 1 · 값 1. 클래스 logits를 점수와 클래스 ID로 후처리하는 분류 작업을 선택합니다.
  • DETECTION = 2 · 값 2. 경계 상자·점수·클래스 행을 후처리하는 검출 작업을 선택합니다.
  • SEGMENTATION = 3 · 값 3. 클래스별 공간 출력을 분할 맵으로 해석하는 작업을 선택합니다.
  • ANOMALY = 4 · 값 4. 단일 채널 이상 맵과 이상 점수를 해석하는 작업을 선택합니다.

사용과 결과 해석

AiTask는 고정 모델 출력의 작업 종류를 구분합니다. CLASSIFICATION=1, DETECTION=2, SEGMENTATION=3, ANOMALY=4입니다. AiModelSpec에 설정한 작업은 같은 바이트라도 결과를 어떤 구조로 해석하는지 결정합니다. 분류의 클래스 점수, 검출의 상자, 분할의 맵, 이상 점수는 서로 다른 출력이므로 동일한 목록으로 가정하지 않습니다.

모델의 입력 너비·높이·채널 및 클래스 수와 작업을 함께 지정합니다. 예를 들어 분류 모델에는 적어도 두 클래스가 필요하지만 이상 작업의 클래스 수는 1입니다. 반환된 결과의 task와 모델 버전을 함께 기록하면 어떤 입력 계약에서 나온 결과인지 추적할 수 있습니다.

이 타입 선택은 실제 영상에서 모델 정확도를 검증하거나 전처리의 색 순서를 자동으로 결정하지 않습니다. 원본 영상의 크기와 선택 영역, 모델이 기대하는 입력 형식 및 후처리 임계값을 함께 확인하고 작업 유형에 맞는 결과 필드를 읽습니다.

분할 맵과 검출 상자는 각각 픽셀별 출력과 영역별 출력을 설명합니다. 모델에서 사용하는 클래스 순서를 따로 보관하고 출력 인덱스를 사용자에게 표시할 이름에 연결해야 합니다.
