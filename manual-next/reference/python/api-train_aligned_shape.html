train_aligned_shape 멤버와 선언

공개 타입

zvision.train_aligned_shape: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.train_aligned_shape.

Combine same-grid edge occurrence from 2..64 already aligned images.

동일 격자에 이미 정렬된 여러 영상의 공통 에지로 형상 모델을 학습합니다.

Python
train_aligned_shape(images, reference, min_fraction, sample_step=1, threshold=None, mask=None)

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_fraction · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sample_step · POSITIONAL_OR_KEYWORD · 기본값 1
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 None
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

images
정렬된 ZImage 2..64개입니다.
reference
템플릿 로컬 Point2 기준점입니다.
min_fraction
유지할 에지 출현 비율로 0보다 크고 1 이하여야 합니다.
sample_step
양의 표본 간격(픽셀)이며 기본값 1입니다.
threshold
유한한 비음수 기울기 임계값 또는 자동 선택 None입니다.
mask
선택적 마스크이며 기본값 None입니다.

반환: 호출자가 닫아야 하는 형상 AdvancedMatchModel입니다.

오류: 격자·영상·옵션이 유효하지 않으면 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
