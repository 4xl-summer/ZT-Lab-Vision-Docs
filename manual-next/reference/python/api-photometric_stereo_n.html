photometric_stereo_n 멤버와 선언

공개 타입

zvision.photometric_stereo_n: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_photometric_n.photometric_stereo_n.

Estimate a surface from 3–128 calibrated images.

보정된 조명 영상들로 반사, 법선과 표면 형상을 추정합니다.

Python
photometric_stereo_n(images, options, mask=None)

인자 선언

  • images · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

images
3–128개의 동일 기하 조명 영상 시퀀스.
options
PhotometricNOptions의 영상과 수가 같은 조명 벡터 및 출력·작업 한도.
mask
선택적 동일 기하 Gray8 마스크; None은 전체.

반환: 호출자가 close할 PhotometricResult 소유 객체.

오류: 입력·기하·조명 조건 또는 작업량 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    3~128장의 동일 기하 조명 영상과 같은 수의 조명 벡터로 광도 스테레오를 계산합니다. images와 options.lights는 같은 순서로 대응해야 합니다. mask는 선택적 Gray8 영상이며 None은 전체 영역을 뜻합니다. 정확히 네 장을 받는 별도 경로와 입력 개수 조건을 혼동하지 마십시오.

    각 조명은 세 성분 벡터이고 신호·조건수·픽셀 간격 설정은 유효 계산에 영향을 줍니다. 예를 들어 네 영상을 전달하더라도 벡터를 다른 순서로 나열하면 각 강도를 잘못된 조명 방향과 연결합니다. 출력 법선과 형상은 보정된 조명 및 반사 모델의 가정에 의존합니다.

    반환된 PhotometricResult와 image로 획득한 개별 영상은 각각 close합니다. 유효 마스크를 함께 읽어 제외되거나 계산되지 않은 곳을 실제 0 값으로 판단하지 마십시오. 실장비 표면의 물리 정밀도와 조명 안정성은 별도의 측정이 필요합니다.
