eye_in_hand_motions 멤버와 선언

공개 타입

zvision.eye_in_hand_motions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._hand_eye.eye_in_hand_motions.

Build adjacent AX=XB pairs for X=gripper←camera from absolute poses.

절대 자세로 X=gripper←camera인 인접 AX=XB 운동 쌍을 만듭니다.

Python
eye_in_hand_motions(gripper_to_base, target_to_camera)

인자 선언

  • gripper_to_base · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_to_camera · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

gripper_to_base
gripper→base 절대 강체 자세 3~1025개
target_to_camera
같은 수의 target→camera 절대 강체 자세

반환: 독립 HandEyePair 튜플

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    eye_in_hand_motions는 카메라가 로봇 그리퍼에 장착된 구성에서 절대 자세들의 대응 목록을 핸드아이 운동 쌍으로 바꿉니다. gripper_to_base와 target_to_camera는 같은 시점의 관측 순서로 정렬되어야 하며 두 목록의 길이가 같고 적어도 세 자세가 필요합니다. 생성된 운동 쌍을 solve_hand_eye에 전달합니다.

    구체 사례와 판독

    예를 들어 첫 번째 그리퍼 자세와 첫 번째 타깃 관측은 같은 촬영 시점을 가리켜야 합니다. 둘째 관측과의 차이로 만든 운동에서 한쪽 목록만 순서가 바뀌면 로봇과 카메라의 실제 운동이 대응하지 않습니다. 이 구성에서 구하려는 변환은 카메라에서 그리퍼 방향입니다. 길이 단위를 일치시키고 추정 후 별도의 자세에서 타깃 위치가 일관되는지 검증하세요.

    적용 시 확인

    최소 개수는 문제를 구성하는 출발점이며 세 장만 있으면 항상 안정적인 보정이 된다는 뜻은 아닙니다. 서로 다른 회전 방향을 포함한 자세와 시점이 맞는 관측을 준비하고 실패한 타깃 검출을 잘못된 자세와 결합하지 마세요. 변환의 이동량은 목록 전체에서 같은 길이 단위를 사용해야 합니다. 추정에 사용하지 않은 자세를 남겨 결과를 검증할 수 있습니다.
