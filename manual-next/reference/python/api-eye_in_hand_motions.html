eye_in_hand_motions 멤버와 선언

공개 타입

zvision.eye_in_hand_motions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._hand_eye.eye_in_hand_motions.

Build adjacent AX=XB pairs for X=gripper←camera from absolute poses.

절대 자세로 X=gripper←camera인 인접 AX=XB 운동 쌍을 만듭니다.

Python
eye_in_hand_motions(gripper_to_base, target_to_camera)

인자 선언

  • gripper_to_base · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_to_camera · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

gripper_to_base
gripper→base 절대 강체 자세 3~1025개
target_to_camera
같은 수의 target→camera 절대 강체 자세

반환: 독립 HandEyePair 튜플

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
