    사용과 결과 해석

    개별 허용치의 식별자 id, 세 가지 상태 status, 선택적 측정값 value를 묶습니다. 이 값은 전체 복합 결과에 들어 있는 각 판정의 관찰 단위이므로 id를 이용해 어떤 허용치 설정을 평가했는지 연결해야 합니다. value가 None인 경우와 실제 값 0은 다르며, 수치가 없는데 0으로 바꾸면 원점이나 0 간격처럼 정상적인 계측 결과와 구별할 수 없습니다. 예를 들어 같은 허용치에서 측정값이 존재하고 한계를 만족한 결과와, 형상 미검출로 측정 자체가 불가능한 결과는 status를 통해 분리해서 기록합니다. 수치의 단위는 해당 측정과 복합 결과의 단위 설정을 함께 확인해야 하며 id가 단위나 합격 한계 자체를 뜻하는 것은 아닙니다. 전체 상태가 실패했더라도 어떤 개별 항목이 실패했는지 찾으려면 개별 결과 목록을 살펴야 합니다. 반대로 허용치가 평가되지 않은 경우를 합격으로 표시하면 누락된 데이터가 통과한 것처럼 보일 수 있습니다. 재현을 위해 판정 상태뿐 아니라 원래 입력 형상과 허용치 설정도 보존하십시오. 같은 식별자의 결과를 프레임 간 비교할 때에는 설정한 허용치가 변경되지 않았는지도 대조하십시오. 식별자만 같고 한계가 바뀐 경우 결과의 상태 차이를 측정값 변화만으로 설명할 수 없습니다.
