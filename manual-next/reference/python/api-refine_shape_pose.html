Python API · refine_shape_pose

refine_shape_pose 멤버와 선언

공개 타입

zvision.refine_shape_pose: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.refine_shape_pose.

Locally optimize against source gradients; tolerance applies numerically to mixed pixel/radian/scale steps and is not accuracy or global optimality.

초기 포즈 주변에서 위치, 각도 및 배율을 국소 정밀화합니다.

Python
refine_shape_pose(source, model, initial, options, mask=None)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • initial · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

source
검색할 ZImage입니다.
model
형상 AdvancedMatchModel입니다.
initial
초기 AdvancedMatch 포즈입니다.
options
ShapePoseRefineOptions 값입니다. ShapePoseRefineOptions()로 기본 설정을 만들 수 있습니다. position_step은 픽셀, angle_step은 라디안, scale_step은 배율이며 max_evaluations가 국소 포즈 평가 상한입니다. tolerance는 혼합 단위 간격의 수치적 정지 기준이지 정확도 보장이 아닙니다.
mask
선택적 검색 마스크 ZImage이며 기본값 None입니다.

반환: 매치 유무, 평가 수, 수렴 및 예산 상태를 포함한 독립 결과입니다. 전역 최적을 보장하지 않습니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
