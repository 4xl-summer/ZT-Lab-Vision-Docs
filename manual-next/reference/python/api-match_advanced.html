Python API · match_advanced

match_advanced 멤버와 선언

공개 타입

zvision.match_advanced: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._color_advanced.match_advanced.

픽셀마다 선택한 Lab 거리 방식으로 가장 가까운 기준 색을 찾습니다.

Python
match_advanced(image, samples, metric)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • samples · POSITIONAL_OR_KEYWORD · 기본값 없음
  • metric · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
색 매칭할 ZImage입니다.
samples
하나 이상의 LabColor 기준 색입니다.
metric
AdvancedMetric 거리 방식과 계수입니다.

반환: 호출자가 닫아야 하는 AdvancedMatches입니다.

오류: 입력 타입·샘플·거리 설정이 유효하지 않으면 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    영상의 각 픽셀을 주어진 Lab 기준 색과 비교하여 가장 가까운 항목과 거리를 구합니다. image는 ZImage, samples는 하나 이상의 LabColor 값, metric은 거리 종류와 계수를 담은 AdvancedMetric입니다. 기준 색의 순서가 반환 인덱스의 해석 기준이므로 결과를 나중에 사용할 때 기준 색 목록도 함께 보관해야 합니다.

    반환되는 AdvancedMatches는 닫아야 하는 소유 결과입니다. 그 결과에서 얻는 인덱스 영상과 거리 영상은 각각 별도 소유 이미지이므로 사용 후 따로 정리합니다. 거리의 수치 의미는 선택한 방식과 계수에 따라 달라집니다. 잘못된 영상 형식, 빈 기준 색 목록 또는 잘못된 거리 설정은 정상적으로 색이 매칭되지 않은 상태와 구분해 오류로 처리합니다.

    값을 확인하는 순서

    image 항목: 색 매칭할 ZImage입니다. samples 항목: 하나 이상의 LabColor 기준 색입니다. metric 항목: AdvancedMetric 거리 방식과 계수입니다.

    항목읽을 때 확인할 내용
    image색 매칭할 ZImage입니다.
    samples하나 이상의 LabColor 기준 색입니다.
    metricAdvancedMetric 거리 방식과 계수입니다.
