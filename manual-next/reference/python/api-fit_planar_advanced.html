fit_planar_advanced 멤버와 선언

공개 타입

zvision.fit_planar_advanced: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._metrology_advanced.fit_planar_advanced.

Weighted affine (1) or projective (2) fit, optionally with disjoint holdout pairs.

가중 아핀 또는 투영 보정 및 선택적 보류점 평가를 수행합니다.

Python
fit_planar_advanced(pixels, world, weights, options, validation=None, tolerance=0.0, uncertainty=None)

인자 선언

  • pixels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • world · POSITIONAL_OR_KEYWORD · 기본값 없음
  • weights · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • validation · POSITIONAL_OR_KEYWORD · 기본값 None
  • tolerance · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • uncertainty · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

pixels
글로벌 픽셀 Point2 열; 아핀 최소 3, 투영 최소 4.
world
픽셀과 동수의 세계 Point2 열.
weights
대응점별 유한한 양의 상대 역분산 가중치.
options
AdvancedPlanarOptions; 모델과 세계 단위 등.
validation
독립 평가용 (pixels, world) 대응 열 또는 None(기본).
tolerance
보류점 세계 잔차 통과 한계; 유한한 0 이상, 기본 0.0.
uncertainty
(글로벌 픽셀 Point2, 행 우선 2×2 입력 공분산 4개) 또는 None(기본).

반환: 독립 AdvancedPlanarResult 및 선택적 평가·공분산.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류. 배열 길이 불일치·퇴화·보정 실패는 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
