fit_plane 멤버와 선언

공개 타입

zvision.fit_plane: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.fit_plane.

옵션으로 점군의 평면을 추정합니다.

Python
fit_plane(cloud, threshold, options)

인자 선언

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • threshold · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
threshold
유한 양수 합의 거리, 점군 단위; 경계 포함
options
PlaneOptions: 가설·정제 반복, 이상치 비율과 수렴 설정

반환: PlaneFit 값 스냅샷입니다.

오류: 유효점 부족, 퇴화 또는 무효 옵션이면 오류입니다.

threshold: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    fit_plane은 점군에서 평면을 찾고 합의점과 잔차를 담은 PlaneFit 값을 반환합니다. cloud에는 유효 좌표와 결측이 섞일 수 있으나 피팅에는 유효점이 필요합니다. threshold는 점군의 길이 단위인 유한 양수이며 이 거리 이하의 점을 합의점으로 셉니다. options에는 가설 탐색과 정제 반복, 허용 이상치 비율 및 조기 종료 조건을 설정합니다.

    결과의 normal과 offset은 n·p+d=0을 정의합니다. 예를 들어 z=4인 점들의 평면은 n=(0,0,1), d=-4로 나타낼 수 있습니다. inliers 및 total과 함께 rms_error, max_error를 읽어 어떤 점이 모델을 지지했는지 판단합니다. 점이 부족하거나 배치가 퇴화하면 오류입니다. 후보 수는 제한되어 있어 모든 이상치 분포에서 최적해를 보장하지 않으므로 결과를 별도의 보류점과 실제 공차로 확인합니다.
