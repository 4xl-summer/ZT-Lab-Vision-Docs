SearchOptions 멤버와 선언

공개 타입

zvision.SearchOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.SearchOptions.

Structure base class

여러 모델의 제한된 3D 후보 탐색과 결과 필터를 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

확인된 인자 조건

max_hypotheses
전체 가설 상한, 모델 수 이상인 양의 정수
max_results
최대 결과 수, 양의 정수
edge_tolerance
삼중항 변 길이 비교 허용값, 점군 단위의 유한 양수
min_overlap
최소 겹침 비율, 유한한 (0,1]
icp
후보 정제에 사용할 IcpOptions
min_translation
이동 벡터의 성분별 포함 하한 Point3, 점군 길이 단위
max_translation
이동 벡터의 성분별 포함 상한 Point3, 하한 이상이며 점군 단위
max_rotation
항등 회전에서 허용할 최대 각도, 유한한 0–π 라디안
max_rms
허용할 최대 ICP RMS, 점군 단위의 유한한 0 이상

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
