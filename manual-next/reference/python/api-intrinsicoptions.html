IntrinsicOptions 멤버와 선언

공개 타입

zvision.IntrinsicOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.IntrinsicOptions.

Fixed-pose local LM limits and conservative maximum projection work.

Python
IntrinsicOptions(max_iterations: int, damping: float, gradient_tolerance: float, max_work: int) -> None

인자 선언

  • max_iterations · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • damping · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • gradient_tolerance · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • max_work · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    max_iterationsint필수내부 파라미터 적합의 반복 상한입니다.
    dampingfloat필수초기 LM 감쇠값입니다.
    gradient_tolerancefloat필수정규화 기울기의 수렴 임계값입니다.
    max_workint필수허용할 추정 투영 작업량 상한입니다.

    사용 맥락과 계약

    IntrinsicOptions는 고정된 자세를 사용하는 카메라 내부 파라미터 국소 최적화의 조건을 지정합니다. max_iterations는 반복 상한이고 damping은 최적화 감쇠, gradient_tolerance는 종료 판정에 쓰이는 기준이며 max_work는 보수적인 투영 작업량 한도입니다. 이 값들은 카메라의 실제 초점 거리나 픽셀 크기가 아닙니다.

    구체 사례와 판독

    예를 들어 관측점과 반복 상한으로 필요한 보수적 작업 한도를 intrinsic_required_work에서 확인해 max_work 설정에 반영할 수 있습니다. 제한이 너무 작으면 원하는 최적화에 필요한 작업량을 허용하지 못할 수 있습니다. 반대로 계산량을 크게 정하는 것만으로 잘못된 관측 대응이나 틀린 고정 자세를 수정할 수는 없습니다.

    적용 시 확인

    점 개수와 반복 수를 변경하면 예상 작업 한도도 달라질 수 있으므로 intrinsic_required_work를 다시 호출하세요. damping과 gradient_tolerance는 숫자가 작을수록 언제나 좋은 결과가 된다는 보장이 없습니다. 종료 상태와 잔차 및 관측 데이터의 분포를 함께 살펴 적절한 설정을 판단합니다.
