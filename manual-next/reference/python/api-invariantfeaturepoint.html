    사용 맥락과 결과 해석

    다중 해상도 특징 모델에 저장된 한 점의 로컬 위치, 이산 피라미드 배율, 방향과 Harris 응답입니다. 위치는 모델 영상의 픽셀 좌표이고 angle은 라디안입니다. scale은 특징이 검출된 피라미드 수준에 대응하는 값이므로 임의의 연속 배율 추정 결과와 구분해야 합니다.

    모델의 points로 값을 복사해 학습에서 어떤 위치와 방향의 특징이 선택되었는지 살펴볼 수 있습니다. 예를 들어 여러 수준에 비슷한 구조가 나오면 위치뿐 아니라 scale과 angle을 함께 비교합니다. response가 크다고 검색 영상의 어느 점과 대응하는지 확정되지는 않습니다. 실제 기하 정합에서는 매치 결과의 대응점과 내점 수, 선택적 변환 행렬을 확인해야 합니다.

    값을 확인하는 순서

    position 항목: 특징점의 모델 로컬 좌표(픽셀)입니다. scale 항목: 특징점이 검출된 이산 피라미드 배율입니다. angle 항목: 특징점 방향(라디안)입니다. response 항목: 해당 층의 Harris 응답입니다.
