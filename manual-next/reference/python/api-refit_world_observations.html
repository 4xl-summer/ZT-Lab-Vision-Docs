Python API · refit_world_observations

refit_world_observations 멤버와 선언

공개 타입

zvision.refit_world_observations: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._world_refit.refit_world_observations.

Transform each ROI-local point to world, then fit a line or circle.

ROI origin is added exactly once before the global-pixel homography. The
supplied planar calibration does not include automatic Brown lens correction.
frame_id labels the caller's world frame; fit parameters and residuals are
in output_unit except line direction and angular options.

ROI 로컬 점을 전역 픽셀과 물리 좌표로 변환한 뒤 직선 또는 원을 적합합니다.

Python
refit_world_observations(points, roi_origin, calibration, output_unit, frame_id, kind, options)

확인된 인자 조건

points
ROI 로컬 Point2 2–4096개입니다. 원 적합은 최소 3개가 필요합니다.
roi_origin
한 번 더할 ROI 원점 Point2입니다.
calibration
전역 픽셀에서 세계 좌표로의 PlanarCalibration입니다.
output_unit
출력 길이 단위입니다.
frame_id
0이 아닌 세계 프레임 식별자입니다.
kind
WorldFitKind LINE 또는 CIRCLE입니다.
options
WorldFitOptions 적합 설정입니다.

반환: 독립 WorldRefit 값입니다. 거리와 잔차는 output_unit 단위입니다.

오류: 인자, 좌표계 또는 수치 조건이 유효하지 않거나 계산이 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: RuntimeError, TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
