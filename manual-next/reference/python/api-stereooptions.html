StereoOptions 멤버와 선언

공개 타입

zvision.StereoOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.StereoOptions.

Ray options and minimum angle in radians, maximum gap in world units, pixel error and depth policy.

삼각측량 광선 역산과 결과 품질 조건을 지정합니다. 수치 범위는 사용 시에도 검증합니다.

Python
StereoOptions(ray, min_angle_radians, max_ray_gap, max_reprojection_pixels, require_positive_depth=True)

인자 선언

  • min_angle_radians · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_ray_gap · POSITIONAL_OR_KEYWORD · 기본값 없음

  • require_positive_depth · POSITIONAL_OR_KEYWORD · 기본값 True

확인된 인자 조건

ray
광선 역산에 사용할 RayOptions입니다.
min_angle_radians
최소 광선 각도로 0 초과 π/2 미만의 라디안 값입니다.
max_ray_gap
허용 최대 광선 간격으로 세계 길이 단위의 유한한 비음수입니다.
max_reprojection_pixels
허용 최대 재투영 오차로 픽셀 단위의 유한한 비음수입니다.
require_positive_depth
두 카메라에서 양의 깊이를 요구하는 bool이며 기본값은 True입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
