사용과 결과 해석

복합 계측의 전체 상태와 개별 feature, 허용치 결과, 선택적 단위 정보를 담는 독립 결과입니다. features와 tolerances를 같이 살펴보면 어떤 기하가 계산되었고 그 기하에 적용한 각 조건이 어떻게 판정되었는지 추적할 수 있습니다. 전체 상태 하나만 읽으면 어떤 특성이 발견되지 않았거나 어느 허용치가 실패했는지 알 수 없습니다. 예를 들어 선의 검출이 실패해 거리 조건을 평가하지 못한 경우에는 미평가 상태와 없는 측정값을 보존해야 합니다. 숫자 0은 정상적인 거리일 수 있으므로 오류 대신 대입하지 마십시오. unit이 지정된 결과는 해당 식별자와 배율에 따라 물리 단위를 해석하지만, 개별 프로브 진단은 픽셀 단위를 유지할 수 있습니다. 결과를 저장할 때 원래 영상의 ROI 기준과 입력 설정을 함께 남겨야 좌표와 단위가 다른 실행을 섞지 않습니다. 독립 스냅샷이라는 성질은 추후 결과를 읽기 쉽게 하지만 현재 프레임의 설정이 이후 프레임에도 유효하다는 뜻은 아닙니다. 새 입력을 측정하면 그 결과를 별도의 실행으로 비교하십시오. 측정값과 상태를 내보낼 때 각 결과의 단위와 원점도 같이 기록합니다. 같은 이미지에서 얻은 두 특징이라도 서로 다른 계산 단계의 상태를 가질 수 있으므로 결과 목록의 연관 관계를 유지하십시오.
