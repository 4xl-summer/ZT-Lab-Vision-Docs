render

classmethod · 선언 타입 zvision._rigid_frames.SyntheticDotGrid

render(cls, grid, lens, target_to_camera, width, height, radius)

물리 격자를 카메라에 투영한 합성 점 영상과 중심 좌표를 만듭니다.

확인된 인자 조건

grid
MetricGrid 값입니다.
lens
투영 LensModel입니다.
target_to_camera
타깃에서 카메라로의 RigidTransform3입니다.
width
양의 출력 너비 픽셀 수입니다.
height
양의 출력 높이 픽셀 수입니다.
radius
1–32 픽셀 점 반경입니다.

반환: 호출자가 닫아야 하는 SyntheticDotGrid입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • grid · POSITIONAL_OR_KEYWORD · 기본값 없음

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Render fixed-pixel-radius markers; this is not a physical disc projection.
