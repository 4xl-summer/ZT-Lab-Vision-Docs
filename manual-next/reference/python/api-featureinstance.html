    pairstuple[zvision._matching_features.FeaturePair, ...]필수이 인스턴스의 대응점 튜플입니다.

    사용 맥락과 결과 해석

    반복된 특징 모델의 한 인스턴스에 대한 변환과 대응점 정보를 담습니다. matrix는 모델 로컬에서 검색 영상 로컬로 가는 3×3 행 우선 값이고 pairs는 대응의 불변 튜플입니다. inlier_count는 기하 검증을 통과한 점 수, evaluated는 그 인스턴스의 가설 평가 수입니다.

    같은 모델이 영상에서 여러 번 발견되면 각 인스턴스의 행렬과 내점 집합을 별도로 확인합니다. ROI 원점이 다른 좌표를 비교할 때 모델 로컬과 검색 로컬을 혼동해서는 안 됩니다. 다수 인스턴스 검색은 상호 최근접을 끄는 조건이 필요하며 총 가설 예산이 제한됩니다. 개별 결과가 존재해도 상위 보고서의 incomplete를 살펴 전체 탐색 여부를 판단합니다.

    값을 확인하는 순서

    matrix 항목: 모델 로컬에서 검색 영상 로컬로 가는 3×3 행 우선 행렬입니다. pairs 항목: 이 인스턴스의 대응점 튜플입니다. inlier_count 항목: 수락된 내점 수입니다. evaluated 항목: 이 인스턴스 검색에서 평가된 가설 수입니다.
