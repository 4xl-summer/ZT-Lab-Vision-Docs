Python API · outlier_mask

outlier_mask 멤버와 선언

공개 타입

zvision.outlier_mask: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.outlier_mask.

반경 이내 이웃 수로 슬롯별 유지 여부를 계산합니다.

Python
outlier_mask(cloud, radius, min_neighbors)

인자 선언

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음
  • min_neighbors · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
radius
유한 양수 반경, 점군 길이 단위
min_neighbors
중심 자체를 제외한 최소 유효 이웃 수; 양의 정수

반환: 독립 bool 목록; True는 유지, 결측은 False입니다.

오류: 반경 또는 이웃 수가 유효하지 않으면 오류입니다.

radius: 유한한 수 검사.

min_neighbors: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    outlier_mask는 각 유효점 주변의 유효 이웃 수가 지정한 최소 수에 도달하는지 계산해 슬롯별 불리언 목록을 만듭니다. radius는 점군의 길이 단위로 유한한 양수이고 min_neighbors는 양의 정수입니다. 중심점 자신과 결측 슬롯은 이웃 수에 포함하지 않습니다. 반경 경계에 있는 유효 이웃은 거리 조건에 포함됩니다.

    반환값 True는 해당 점을 유지한다는 뜻이며 None인 원본 슬롯은 False입니다. 예를 들어 중심을 제외하고 반경 안에 두 점이 있을 때 최소 이웃이 2이면 그 중심은 유지됩니다. 목록의 순서는 원래 점군 슬롯과 같으므로 값을 원본과 인덱스로 대응해 사용합니다. 이웃 밀도 기준은 반드시 물리적 결함이나 잡음을 판정하는 것은 아니며 반경과 데이터 샘플링 밀도를 함께 정해야 합니다. 무효 반경 또는 이웃 수는 오류입니다. 결과를 적용할 때는 원본 점군과 마스크의 길이가 같은지도 확인합니다.
