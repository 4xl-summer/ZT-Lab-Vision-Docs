Python API · suppress_advanced_matches

suppress_advanced_matches 멤버와 선언

공개 타입

zvision.suppress_advanced_matches: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._matching_advanced.suppress_advanced_matches.

Greedily suppress transformed NCC sample AABB overlaps.

변환된 NCC 표본의 축 정렬 경계상자 IoU로 매치를 점수순 억제합니다.

Python
suppress_advanced_matches(model, matches, max_iou, limit)

인자 선언

  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • matches · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_iou · POSITIONAL_OR_KEYWORD · 기본값 없음
  • limit · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

model
NCC AdvancedMatchModel입니다.
matches
억제할 AdvancedMatch 값들의 시퀀스입니다.
max_iou
허용할 최대 겹침 IoU로 0..1입니다.
limit
유지할 최대 후보 수인 양의 정수입니다.

반환: 남은 후보의 독립 list입니다.

오류: 타입, IoU 또는 개수 조건이 맞지 않으면 오류입니다.

limit: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    학습된 NCC 모델과 AdvancedMatch 후보 시퀀스를 받아 변환된 모델 표본의 축 정렬 경계상자를 비교합니다. 점수가 높은 후보부터 검사하고 이미 남긴 후보와의 교집합 대 합집합 비율이 허용 범위를 초과하는 후보를 억제합니다. max_iou는 0부터 1, limit은 양의 반환 개수입니다.

    같은 물체에서 여러 가까운 포즈가 나온 뒤 중복을 줄일 때 사용합니다. 예를 들어 두 경계상자가 많이 겹치면 기준을 넘는 낮은 점수의 후보가 빠질 수 있지만, 서로 가까운 두 실제 물체도 같은 규칙의 영향을 받습니다. 회전된 사각형을 축 정렬 상자로 감싸므로 공간 자체의 정확한 다각형 겹침과 다를 수 있습니다. 결과는 복사된 목록이며 잘못된 모델이나 범위는 오류입니다.

    값을 확인하는 순서

    model 항목: NCC AdvancedMatchModel입니다. matches 항목: 억제할 AdvancedMatch 값들의 시퀀스입니다. max_iou 항목: 허용할 최대 겹침 IoU로 0..1입니다. limit 항목: 유지할 최대 후보 수인 양의 정수입니다.

    항목읽을 때 확인할 내용
