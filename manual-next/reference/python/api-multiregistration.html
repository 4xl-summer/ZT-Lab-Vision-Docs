close(self)

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

edge_optimized

오류: 범위 밖 인덱스나 닫힌 결과는 오류입니다.

edge_quality

반환: RegistrationEdgeQuality 값이며 평가되지 않은 고정 에지는 None입니다.

image

반환: 별도로 close할 GrayF64 정렬 영상 또는 Gray8 마스크입니다.

info

공통 좌표계에서 선택 이미지로의 매핑 정보를 조회합니다.

mosaic

반환: 호출자가 close할 RegistrationMosaic 소유 결과입니다.

mosaic_feather

영상 경계까지의 거리에 따른 가중치로 겹침을 합성합니다.

mosaic_geometry

변환된 영상의 합집합 캔버스 기하를 계산합니다.

mosaic_on_canvas

명시한 공통 좌표 원점과 크기의 캔버스에 모자이크를 만듭니다.

run

여러 영상의 등록 그래프를 계산해 공통 격자에 맞춥니다.
