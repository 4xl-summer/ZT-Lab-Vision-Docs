HaarWavelet 멤버와 선언

공개 타입

zvision.HaarWavelet: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._wavelet_inpaint_gap.HaarWavelet.

Owned even-axis Haar coefficients; close or use as a context manager.

Python
HaarWavelet()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.

coefficients

오류: 닫힌 객체, 잘못된 계수 또는 옵션은 오류입니다.

forward

반환: 별도로 close할 HaarWavelet입니다.

inverse

반환: 입력 ROI 원점을 보존하는 독립 GrayF64 영상이며 close합니다.

shrunk

세부 계수를 임계화하고 LL 계수는 유지합니다.

with_coefficients

반환: 호출자가 close할 새 변환 객체입니다.
