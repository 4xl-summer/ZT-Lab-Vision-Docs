공개 타입

zvision.blob_axis_median: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_axis_median.blob_axis_median.

Return lower median projections in axes rotated by angle radians.

회전 축에 투영한 전경 좌표의 낮은 중앙값을 구합니다.

Python
blob_axis_median(image, angle, work_budget)

공개 멤버

    지정 방향의 좌표 중앙값

    blob_axis_median은 비영 전경 좌표를 angle로 정한 두 직교 축에 투영하고 각 축의 낮은 중앙값을 구합니다. 이후 중앙값을 ROI 로컬 좌표로 되돌린 점과 축별 투영값을 반환합니다. 회전 축과 원래 영상 축의 좌표를 구분해야 합니다.

    라디안과 예

    angle은 유한한 라디안 값입니다. 90도에 해당하는 방향은 π/2 라디안입니다. 한 축에 투영된 값이 0, 1, 4, 9이면 낮은 중앙값은 1입니다. 두 축을 각각 계산하므로 결과 점은 전경의 한 픽셀과 반드시 일치하지 않습니다.

    입력과 결과

    image에 전경 마스크를, work_budget에 양의 정수 상한을 전달합니다. 반환 area는 비영 전경 픽셀 수이고 x, y는 ROI 로컬 위치입니다. 전체 영상에 그리려면 원점을 반영하고, 비교 대상에는 같은 방향과 마스크 생성 조건을 사용합니다.

    한계

    중앙값은 산술 평균 중심과 다른 통계입니다. 일부 멀리 떨어진 픽셀의 영향 양상이 달라질 수 있지만 입력에 여러 물체가 섞이면 전체 분포를 대표하므로 각 성분의 중심이 필요한 작업에서는 성분을 먼저 분리합니다.
