    격자 중심 내부 원

    BlobInnerCircle은 ROI 로컬 정수 격자 중심 x, y와 이산 반지름 radius를 담습니다. 배경 픽셀 중심을 포함하지 않도록 정한 내부 원을 나타내며 픽셀 셀 꼭짓점까지 감싸는 외접원과 정의가 다릅니다.

    중심과 반지름

    중심이 (3,4)이고 반지름이 2라면 원은 그 격자 중심을 기준으로 합니다. 반지름의 기준은 배경 픽셀 중심에 대한 포함 조건이므로 연속적인 물체의 정확한 내접원 반지름이라고 단정할 수 없습니다. 정수 격자에서의 정의를 유지해 비교합니다.

    결과 표시

    blob_inner_circle로 결과를 얻은 뒤 원본 전경 마스크 위에 중심과 원을 표시합니다. ROI 로컬 중심을 전체 영상에 옮길 때는 원점을 더합니다. 전경에 구멍이나 가는 부분이 있으면 후보 원의 크기와 위치에 영향을 줍니다.

    측정의 한계

    한 픽셀 크기나 분할 경계가 바뀌면 이산 원의 중심 또는 반지름도 달라질 수 있습니다. 물리 치수로 사용할 때는 영상 보정과 축 방향별 픽셀 간격을 따로 고려하고 동일한 마스크 생성 조건을 유지합니다.
