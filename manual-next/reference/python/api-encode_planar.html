Python API · encode_planar

encode_planar 멤버와 선언

공개 타입

zvision.encode_planar: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.encode_planar.

Encode a global-pixel-to-world planar calibration and unit in 88 checked bytes.

전역 픽셀→월드 평면 보정과 단위를 직렬화합니다.

Python
encode_planar(calibration)

인자 선언

  • calibration · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

calibration
PlanarCalibration 값

반환: 88바이트 bytes

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: RuntimeError, TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    encode_planar는 전역 영상 픽셀에서 월드로 가는 평면 보정과 길이 단위를 검증 정보가 포함된 정확히 88바이트로 인코딩합니다. 입력은 PlanarCalibration이며 결과는 바이너리 bytes입니다. 보정에 사용한 관측 영상 전체를 저장하는 기능은 아니므로 보정의 출처와 적용할 영상 조건은 별도로 기록해야 합니다.

    구체 사례와 판독

    예를 들어 X=0.1x+1, Y=0.2y−2인 보정에서 전역 픽셀 (110,220)은 월드 (12,42)입니다. 이 보정을 저장하고 decode_planar로 복원한 후 같은 점을 변환해 (12,42)와 단위를 비교하면 기본적인 왕복을 검증할 수 있습니다. ROI의 로컬 점 (10,20)은 원점 (100,200)을 더한 후 전역 좌표로 사용합니다.

    적용 시 확인

    88바이트 결과의 길이는 텍스트 인코딩 후 문자 수가 아니라 원래 바이너리의 바이트 수입니다. 파일을 바이너리로 저장하고 불러온 뒤 검증점과 단위를 다시 확인하세요. 월드 단위가 mm인 경우 (12,42)는 mm로 읽으며 픽셀과 직접 더하거나 비교하지 않습니다. 측정 프로그램의 ROI 좌표를 사용할 때는 전역 원점을 정확히 한 번 반영해야 같은 검증점에 도달합니다.
