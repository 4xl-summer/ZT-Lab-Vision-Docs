    사용과 결과 해석

    초기 겹침을 확인하며 수행한 정합의 행렬, 상태 및 선택적 품질을 담습니다. matrix는 성공 시 최적화된 행 우선 3×3 행렬이고 실패 시 초기 행렬을 보존할 수 있습니다. 따라서 행렬이 있다는 사실만으로 검색이 성공했다고 판단하면 안 됩니다.

    initial_overlap은 더 작은 영상의 픽셀 면적을 분모로 한 초기 겹침 비율입니다. status는 완료, 초기 겹침 부족 또는 유효 점수 없음 같은 경우를 구분하고 quality는 성공해 품질이 측정된 경우에만 존재합니다. quality가 None이면 잔차가 0인 결과로 취급하지 마십시오.

    행렬을 다른 영상에 적용하기 전에는 입력과 기준의 좌표 방향, ROI 원점 및 유효 마스크를 확인하십시오. 초기 겹침이 충분하지 않은 상태의 보존 행렬은 후속 처리의 fallback일 수 있지만, 검증된 정합 결과와 같은 의미는 아닙니다.
