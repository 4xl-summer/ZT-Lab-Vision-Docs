Python API · register_translation_image_pyramid

register_translation_image_pyramid 멤버와 선언

공개 타입

zvision.register_translation_image_pyramid: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._registration_constraints.register_translation_image_pyramid.

Register actual 2x2 reduced source and reference images to the requested last level.

실제 축소 영상 피라미드를 사용해 이동 정합을 수행합니다.

Python
register_translation_image_pyramid(source, reference, options, first_level, last_level=0, *, max_work=100000000)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • first_level · POSITIONAL_OR_KEYWORD · 기본값 없음
  • last_level · POSITIONAL_OR_KEYWORD · 기본값 0
  • max_work · KEYWORD_ONLY · 기본값 100000000

확인된 인자 조건

source
정합할 검사 영상.
reference
기준 영상.
options
AdvancedRegistrationOptions 정합 조건.
first_level
시작 피라미드 레벨, last_level 이상 8 이하.
last_level
마지막 레벨, 0 이상이며 기본 0.
max_work
1–100,000,000의 작업 상한; 기본 100,000,000.

반환: 정합 결과, 사용 레벨과 축소 크기의 TranslationPyramidReport 값.

오류: 잘못된 형식·옵션·범위 또는 작업 한도 위반은 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
