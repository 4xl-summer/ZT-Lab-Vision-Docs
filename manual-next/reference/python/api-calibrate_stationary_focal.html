Estimate equal focal length from known rotations and fixed principal point.

확인된 인자 조건

views
RotationCorrespondence 1–16개이며 총 대응점은 최대 1024개입니다.
cx
고정 주점 X 픽셀 좌표입니다.
cy
고정 주점 Y 픽셀 좌표입니다.
min_focal
탐색할 최소 초점거리이며 픽셀 단위입니다.
max_focal
탐색할 최대 초점거리이며 픽셀 단위입니다.
