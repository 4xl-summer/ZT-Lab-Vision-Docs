CircleMeasurementResult 멤버와 선언

공개 타입

zvision.CircleMeasurementResult: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.CircleMeasurementResult.

독립 원 계측 스냅샷.

status가 0일 때 parameters는 (중심 x, 중심 y, 반지름)이다.
적합이 없으면 parameters와 inliers, rms, maximum은 None이다.

독립 불변 원 계측 결과 값입니다. 일반적인 경로는 대응 모델의 measure(image)입니다. status와 fit을 함께 확인합니다.
