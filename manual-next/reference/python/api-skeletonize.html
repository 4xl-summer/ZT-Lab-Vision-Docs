Python API · skeletonize

skeletonize 멤버와 선언

공개 타입

zvision.skeletonize: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._region_topology.skeletonize.

Two-phase 8-foreground/4-background thinning; convergence is explicit.

8-전경과 4-배경의 두 단계 세선화를 반복합니다.

Python
skeletonize(image, options=SkeletonOptions(connectivity=8, max_iterations=1000, work_budget=100000000))

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 SkeletonOptions(connectivity=8, max_iterations=1000, work_budget=100000000)

확인된 인자 조건

image
ZImage 입력 영상
options
SkeletonOptions; 기본값 8연결, 최대 1000회, 작업량 100000000

반환: 영상을 소유하는 IterationResult; 수렴 여부 확인 후 close

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    전경의 세선화

    skeletonize는 전경 마스크를 가늘게 줄이는 반복 세선화를 수행합니다. 구현은 전경 8연결과 배경 4연결을 사용하는 두 단계 처리이며 단순히 경계 픽셀을 모두 한 번에 지우는 방식이 아닙니다. 입력의 작은 가지나 연결은 결과 그래프의 구조에 영향을 줄 수 있습니다.

    기본 설정

    기본 SkeletonOptions는 connectivity 8, 최대 반복 1000, 작업량 한도 100000000입니다. 반복과 작업량은 서로 다른 제한으로, 큰 입력이나 복잡한 마스크에서는 실제 결과와 수렴 상태를 확인해야 합니다. 연결 조건에 허용되는 값과 연산의 구체적인 제약은 옵션 계약에 따릅니다.

    결과 사용과 해제

    반환된 IterationResult에서 image뿐 아니라 iterations와 converged를 함께 확인합니다. 수렴하지 않은 중간 결과를 완성된 골격으로 단정하지 말고 제한과 입력을 점검합니다. 결과는 close 또는 컨텍스트 관리자로 닫아 영상 자원을 해제하고, 이후 그래프를 만들려면 닫기 전에 처리합니다.

    전처리에서 마스크의 좁은 틈을 메우면 세선화 이후 연결 구조도 달라질 수 있습니다. 원본 이진 마스크와 세선화 영상을 같은 좌표계로 보관해 어느 단계에서 가지가 생겼는지 살펴봅니다.
