공개 멤버

    사용과 결과 해석

    두 D50 CIELAB 색 좌표 사이의 CIE76 거리를 계산합니다. 입력 a와 b는 각각 LabColor 값이며 L*, a*, b*의 각 차이를 제곱해 합한 다음 제곱근을 취합니다. 두 좌표가 완전히 같으면 결과는 0이고, 좌표가 멀어질수록 유클리드 거리는 커집니다. 반환값은 하나의 숫자이며 영상 전체나 결함 후보 목록을 생성하지 않습니다.

    예를 들어 첫 점이 (50,0,0), 둘째 점이 (53,4,0)이면 축 차이는 3과 4, 0이므로 거리는 5입니다. 이 계산은 같은 기준 백색점과 관찰 조건으로 표현된 Lab 좌표를 전제로 합니다. RGB 바이트의 각 채널 차이를 그대로 이 함수의 좌표로 넣으면 다른 계산이 되며, LabColor로 변환한 목표 값인지 먼저 확인해야 합니다.

    실제 영상의 모든 픽셀과 기준색을 비교하려면 영상 색차나 색 분할 호출을 사용하고 결과 형식 및 소유권을 확인합니다. 판정 임계값은 이 거리 계산 자체에 포함되지 않습니다. 거리 상한을 정할 때는 대상 색과 조명, 허용 기준에 맞는 데이터로 따로 확인해야 합니다.

    유한하지 않은 좌표는 의미 있는 색차로 취급하지 않습니다. 연산 전 입력의 표현을 확인하고 함수가 반환한 숫자를 영상 픽셀 배열이나 후보 개수와 혼동하지 마세요.
