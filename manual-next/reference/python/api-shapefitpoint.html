    사용 맥락과 결과 해석

    강건 적합에 참여한 한 점의 부호 있는 잔차, 최종 가중치와 내점 판정을 담습니다. residual은 입력 점 좌표와 같은 단위이고 weight는 최종 최적화에서 실제 사용된 값입니다. inlier는 지정된 내점 임계값을 기준으로 한 bool입니다. 세 값은 서로 관련되지만 동일한 의미는 아닙니다.

    예를 들어 점의 잔차가 큰 경우 강건 손실은 그 점의 영향력을 줄일 수 있고, 별도의 내점 기준으로도 분류합니다. 따라서 하나의 값만 보고 다른 값을 임의로 유추하지 말고 함께 확인하세요. 타원 잔차는 곡선에 대한 정확한 최근접 거리 대신 반경 방향 대용값입니다. 비교할 때 형상 종류와 좌표 단위, 적합 옵션을 함께 기록해야 합니다.

    강건 옵션을 바꾼 두 실행의 잔차 분포를 비교할 때도 같은 입력 좌표 단위와 동일한 형상 종류를 사용해야 합니다.

    값을 확인하는 순서

    residual 항목: 부호 있는 좌표 단위 잔차입니다. 타원에서는 최근접 거리가 아닌 반경 방향 대리 잔차입니다. weight 항목: 최종 강건 적합에서 사용한 가중치입니다. inlier 항목: 잔차와 인라이어 임계값으로 판정한 채택 여부입니다.
