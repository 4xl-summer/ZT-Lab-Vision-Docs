Search with an 8-connected source edge-component size range.

확인된 인자 조건

source
검색할 ZImage입니다.
model
형상 AdvancedMatchModel입니다.
options
AdvancedMatchOptions 값입니다. x·y·angle·scale_x·scale_y에 각각 SearchAxis(minimum, maximum, step)를 지정합니다. 일반 검색에서 x·y는 검색 ROI 로컬 픽셀, angle은 라디안이며 scale은 양수입니다. candidate_budget은 평가 포즈 수 상한입니다. max_occlusion_fraction=0이어야 합니다. min_size와 max_size는 별도 입력의 에지 구성요소 크기 범위입니다.
min_size
8연결 에지의 양의 최소 크기입니다.
max_size
최소 크기 이상의 최대 크기입니다.
mask
선택적 검색 마스크 ZImage이며 기본값 None입니다.

반환: 독립 매치 결과와 종료 진단입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
