ExtendedShapeModel 멤버와 선언

공개 타입

zvision.ExtendedShapeModel: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._extended_matching.ExtendedShapeModel.

Extended edge-direction shape model.

Python
ExtendedShapeModel()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

close(self)

Release this model's native resource.

diagnose

찾은 형상 포즈를 주변의 호환 에지와 비교합니다.

features

반환: 기준점 상대 로컬 좌표와 방향인 (x, y, nx, ny) 튜플들의 독립 튜플입니다. 원래 contour 연결은 포함하지 않습니다.

find

반환: 입력과 모델에 독립된 검색 결과와 종료 진단입니다.

find_edge_grain

검색 영상의 연결된 에지 크기 조건을 적용해 검색합니다.

find_global_polarity

한 번에 전체 모델에 공통인 극성을 사용해 형상을 검색합니다.

find_image_pyramid

실제로 축소된 영상 및 형상 특징으로 지정 층을 검색합니다.

find_in_regions

기준점과 변환 모델에 각각 영역 제약을 적용해 검색합니다.

find_min_contrast

유효 영역의 평균 기울기 조건을 만족하는 형상만 검색합니다.

find_robust

가려진 특징을 고려하는 절삭 점수로 형상을 검색합니다.

find_with_clutter

형상 후보에서 주변 에지의 clutter를 감점하여 검색합니다.

from_bytes

버전과 체크섬이 있는 형상 모델 아카이브를 복원합니다.

refine_pose

초기 포즈 주변에서 위치, 각도 및 배율을 국소 정밀화합니다.

region_diagnostics

변환된 모델과 소스 로컬 영역의 관계를 계산합니다.

to_bytes

형상 모델을 버전과 체크섬을 포함한 아카이브로 직렬화합니다.

train

표본화한 템플릿 기울기로 확장 형상 모델을 학습합니다.

train_aligned

동일 격자에 이미 정렬된 여러 영상의 공통 에지로 형상 모델을 학습합니다.

train_contours

방향이 있는 선분 경로에서 형상 특징을 추출해 모델을 학습합니다.

train_detailed

기울기 범위와 스텐실을 지정해 확장 형상 모델을 학습합니다.

train_grain

학습 에지의 연결 구성요소 크기를 제한해 형상 모델을 학습합니다.

training_info

property · 선언 타입 zvision._extended_matching._TypedModel · 상속

Python
ExtendedShapeModel.training_info

학습된 모델의 표본 수와 임계 정보를 읽습니다.

반환: 모델에서 독립된 AdvancedTrainingInfo 값입니다.

오류: 유효하지 않은 입력, 모델 또는 지원하지 않는 설정은 오류입니다.

Return independent training metadata.
