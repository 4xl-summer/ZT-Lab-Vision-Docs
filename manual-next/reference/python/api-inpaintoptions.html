Python API · InpaintOptions

InpaintOptions 멤버와 선언

공개 타입

zvision.InpaintOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._wavelet_inpaint_gap.InpaintOptions.

Iteration limit, stable timestep, positive intensity scale and tolerance.

마스크 복원 설정값입니다. 생성 시 초기화 별칭이 지정되면 nearest_known을 덮어씁니다.

Python
InpaintOptions(iterations, timestep, kappa, tolerance=0.0, conductance=<InpaintConductance.EXPONENTIAL: 0>, nearest_known=True, *, initialization=None)

인자 선언

  • iterations · POSITIONAL_OR_KEYWORD · 기본값 없음
  • timestep · POSITIONAL_OR_KEYWORD · 기본값 없음
  • kappa · POSITIONAL_OR_KEYWORD · 기본값 없음
  • tolerance · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • conductance · POSITIONAL_OR_KEYWORD · 기본값 <InpaintConductance.EXPONENTIAL: 0>
  • nearest_known · POSITIONAL_OR_KEYWORD · 기본값 True
  • initialization · KEYWORD_ONLY · 기본값 None

확인된 인자 조건

nearest_known
True면 인접한 알려진 픽셀로 초기화하고 False면 입력 값을 사용합니다. 기본 True.
initialization
키워드 전용 HoleInitialization.INPUT 또는 NEAREST_KNOWN; None이면 nearest_known을 사용합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
