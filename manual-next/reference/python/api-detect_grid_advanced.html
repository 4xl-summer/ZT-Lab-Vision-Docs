Python API · detect_grid_advanced

detect_grid_advanced 멤버와 선언

공개 타입

zvision.detect_grid_advanced: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._metrology_advanced.detect_grid_advanced.

Detect affine-grid checkerboard (1) or dark dots (2), optionally using a fiducial hint.

기준점 또는 자동 추론으로 격자 표적을 검출합니다.

Python
detect_grid_advanced(image, spec, hint=None)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spec · POSITIONAL_OR_KEYWORD · 기본값 없음
  • hint · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

image
Gray8, Gray16 또는 GrayF32 ZImage.
spec
AdvancedGridSpec.
hint
AdvancedGridHint 또는 None(기본 자동 추론).

반환: AdvancedGridPoint 튜플.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류. 격자 추론이 불가능해도 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    그레이 영상에서 체커보드 또는 어두운 점 격자를 찾고 관측 위치를 행·열 인덱스와 연결합니다. image에는 지원되는 Gray8, Gray16 또는 GrayF32 영상, spec에는 예상 격자 크기와 대비·거리 조건을 지정합니다. hint가 있으면 기준 격자점과 픽셀 축 변위를 사용하고 None이면 자동 추론 경로를 택합니다. 결과의 각 항목은 row, column, 픽셀 위치와 대비 점수를 담습니다. 예를 들어 표적이 4행 5열이면 반환된 인덱스가 설정 범위에 들어가는지 확인하고 같은 인덱스의 세계 기준점과 짝지어야 합니다. 빈 결과나 실패를 실제 세계 위치 0으로 치환하지 마십시오. 영상 밖 기준점이나 유효하지 않은 간격, 검출 불가능한 표적은 오류가 될 수 있으며 검출 점수는 보정 정밀도 자체가 아닙니다. 보정 입력으로 넘기기 전에는 각 관측 위치를 원래 표적 위에 표시해 인덱스가 방향에 맞는지 살펴보는 것이 유용합니다. 행과 열을 서로 바꾸어도 좌표는 유한하지만 세계점의 대응이 달라집니다. 점이 부족한 경우 검출 설정과 보정 모델의 최소점 조건을 각각 확인하십시오. 대비 점수는 후보의 영상 특징을 나타내므로 mm 단위의 세계 잔차로 읽지 않습니다. 검출과 보정 평가를 별도 단계로 기록하십시오.
