공개 멤버

    잘린 물체 판정

    blob_not_clipped는 각 Blob이 영상 또는 선택 ROI에 의해 잘리지 않았는지 판정합니다. 경계에 닿은 물체는 화면 밖으로 계속될 가능성이 있으므로 전체 면적이나 둘레를 신뢰하기 전에 이를 확인하는 데 사용할 수 있습니다. 이 결과는 물체의 외관 불량 여부 자체가 아닙니다.

    선택 ROI

    source에는 BlobResult를 전달하고 필요하면 선택적인 roi 마스크를 지정합니다. 영상 경계뿐 아니라 선택 ROI도 검사 기준이 될 수 있으므로 두 조건을 혼동하지 않습니다. ROI를 변경하면 같은 원본 물체에 대한 판정이 달라질 수 있어 검사 범위를 함께 기록합니다.

    검사 예

    물체 하나가 ROI 안쪽에 완전히 있고 다른 물체가 ROI 경계에 닿아 있으면 두 결과를 원본 마스크 위에 표시해 비교합니다. 경계 접촉 여부가 다른 이유를 면적 수치만 보고 유추하지 말고 ROI와 성분의 실제 위치를 확인하세요.

    후속 판정

    잘리지 않은 후보를 골라 크기나 모양을 측정하면 부분 객체로 인한 편차를 줄일 수 있습니다. 다만 잘리지 않았다는 판정이 분할의 정확성이나 보정의 정확성을 보증하지는 않습니다. 양의 작업량 상한을 지정하고 실제 데이터의 경계 사례로 검증합니다.
