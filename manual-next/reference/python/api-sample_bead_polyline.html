Python API · sample_bead_polyline

sample_bead_polyline 멤버와 선언

공개 타입

zvision.sample_bead_polyline: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_bead_path.sample_bead_polyline.

Uniformly sample an open or closed ordered polyline; closed paths omit duplicate endpoint.

열린 또는 닫힌 경로를 일정 간격으로 표본화합니다.

Python
sample_bead_polyline(vertices, spacing, *, closed=False, max_points, max_work)

인자 선언

  • vertices · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spacing · POSITIONAL_OR_KEYWORD · 기본값 없음
  • closed · KEYWORD_ONLY · 기본값 False
  • max_points · KEYWORD_ONLY · 기본값 없음
  • max_work · KEYWORD_ONLY · 기본값 없음

확인된 인자 조건

vertices
유한한 로컬 (x,y) 좌표 순서; 열린 경로 2개 이상, 닫힌 경로 3개 이상.
spacing
유한한 양의 표본 간격(픽셀).
closed
닫힌 경로 여부, 기본 False.
max_points
출력 점 수 상한 2–1,000,000.
max_work
양의 작업 상한, 최대 1,000,000.

반환: 로컬 좌표 쌍의 독립 튜플; 닫힌 경로는 끝점 중복을 생략합니다.

오류: 유효하지 않은 인자 또는 작업 한도 초과 시 오류입니다.

max_points: 정수 검사 · 최소 2.

max_work: 정수 검사 · 최소 1.

spacing: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
