Python API · fit_constrained_planar

fit_constrained_planar 멤버와 선언

공개 타입

zvision.fit_constrained_planar: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.fit_constrained_planar.

Fit a proper rigid or isotropic similarity mapping from paired 2D points.

쌍을 이룬 2D 점의 강체 또는 등방 유사 변환을 피팅합니다.

Python
fit_constrained_planar(source, target, similarity=False)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target · POSITIONAL_OR_KEYWORD · 기본값 없음
  • similarity · POSITIONAL_OR_KEYWORD · 기본값 False

확인된 인자 조건

source
2–100000개 입력 Point2 시퀀스.
target
source와 같은 수의 대응 Point2 시퀀스.
similarity
True면 등방 유사 변환, False면 강체 변환; 기본 False.

반환: 독립 Affine2 값.

오류: 부적합한 형식·크기·인수 또는 작업 한도 위반은 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    fit_constrained_planar는 대응하는 2차원 점을 이용해 회전·이동 강체 변환 또는 등방성 배율을 포함한 유사 변환을 적합합니다. source와 target은 같은 개수의 2개부터 100000개까지의 점이며 similarity는 bool입니다. 반환되는 Affine2는 source에서 target으로 가는 변환입니다.

    구체 사례와 결과 판독

    예를 들어 source [(0,0),(1,0)]이 target [(2,3),(3,3)]에 대응한다면 배율과 회전이 없는 이동 (2,3)이 이 두 점을 설명합니다. similarity=True는 동일한 가로·세로 배율을 허용하지만 임의의 비등방성 변형이나 반사를 뜻하지 않습니다. 입력 점의 순서와 좌표계를 확인하고 보류한 점에서 결과를 시험하세요.

    적용 시 확인

    같은 물리적 점이 source와 target의 같은 인덱스에 있어야 합니다. 두 점이 동일하거나 분포가 퇴화하면 변환을 안정적으로 결정할 정보가 부족할 수 있습니다. 회전과 배율을 추정한 뒤 독립 점의 거리 오차를 입력 좌표 단위로 평가하세요. 유사 변환의 단일 배율은 두 축에 공통 적용됩니다. 가로와 세로의 서로 다른 배율이 필요한 문제는 이 조건과 다릅니다.
