morphology 멤버와 선언

공개 타입

zvision.morphology: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._processing_advanced.morphology.

Binary morphology. Operation 0 dilates and 1 erodes.

사용자 구조 요소로 이진 팽창 또는 침식을 반복합니다.

Python
morphology(image, kernel, width, height, anchor_x, anchor_y, iterations=1, operation=0)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • kernel · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • anchor_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • anchor_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • iterations · POSITIONAL_OR_KEYWORD · 기본값 1
  • operation · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

image
ZImage 입력 영상
kernel
width×height개 바이트로 구성된 이진 구조 요소
width
양의 폭(픽셀 또는 커널 셀)
height
양의 높이(픽셀 또는 커널 셀)
anchor_x
커널 안 기준점의 x 인덱스
anchor_y
커널 안 기준점의 y 인덱스
iterations
반복 횟수; 기본값 1
operation
형태학 동작 코드; 0 팽창, 1 침식; 기본값 0

반환: 별도로 close할 ZImage

오류: 커널 길이 불일치, 기준점 범위 밖, 모든 셀 0 또는 잘못된 동작 코드는 오류입니다.

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

anchor_x: 정수 검사.

anchor_y: 정수 검사.

iterations: 정수 검사.

operation: 정수 검사 · 최소 0.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
