열거 값

  • DILATION = 0 · 마스크로 제한한 팽창 재구성입니다.
  • EROSION = 1 · 마스크로 제한한 침식 재구성입니다.

재구성의 두 방향

ReconstructionMode는 마커 영상과 마스크 영상을 이용하는 측지 재구성의 방향을 선택합니다. DILATION은 팽창 방향이고 EROSION은 침식 방향입니다. 마스크는 반복이 진행되는 범위를 제한하며, 단순히 한 번의 팽창이나 침식을 실행하는 설정과 구별해야 합니다.

반복과 제한

마커에서 시작한 변화가 마스크에 의해 제한되면서 더 이상 변하지 않을 때까지 반복할 수 있습니다. 예를 들어 마스크가 허용하는 연결 영역 안에서 마커를 확장하는 문제와 바깥을 침식해 가는 문제는 설정 방향이 다릅니다. 어떤 방향이 유효한지는 입력 마커와 마스크의 관계도 함께 확인해야 합니다.

결과의 수렴

ReconstructionOptions의 mode로 방향을 선택하고 연결성과 반복 및 작업 한도를 지정합니다. 결과 IterationResult의 converged와 실제 반복 횟수를 확인하며, 한도에 도달한 중간 영상을 수렴한 최종 결과로 가정하지 않습니다. 결과에 포함된 영상은 사용 후 close하거나 컨텍스트 관리자로 해제합니다.

영상 비교

같은 입력의 두 설정을 비교할 때 결과 영상의 변화 위치를 살펴봅니다. 연결성과 마커를 동시에 바꾸면 방향 선택의 영향을 분리하기 어려우므로 하나씩 바꾸고 ROI와 픽셀 형식 조건은 유지합니다.
