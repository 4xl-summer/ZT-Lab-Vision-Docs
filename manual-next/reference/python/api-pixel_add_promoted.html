Python API · pixel_add_promoted

pixel_add_promoted 멤버와 선언

공개 타입

zvision.pixel_add_promoted: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._arithmetic_gap.pixel_add_promoted.

Add documented mixed Gray8/Gray16/GrayI16/GrayI32 pairs with promotion.

지원되는 정수 회색 형식 쌍을 승격해 성분별로 더합니다.

Python
pixel_add_promoted(left, right, gain=1.0, bias=0.0)

인자 선언

  • left · POSITIONAL_OR_KEYWORD · 기본값 없음
  • right · POSITIONAL_OR_KEYWORD · 기본값 없음
  • gain · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • bias · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

left
첫 ZImage입니다.
right
둘째 ZImage입니다.
gain
합에 곱할 유한 배율이며 기본값은 1입니다.
bias
합에 더할 유한 값이며 기본값은 0입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

gain: 유한한 수 검사.

bias: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    서로 다른 두 단일 채널 정수 형식을 더할 때 정해진 승격 규칙에 따라 출력 형식을 선택합니다. 단순히 왼쪽 영상 형식으로 잘라내는 방식이 아니므로 서로 다른 비트 깊이나 부호를 가진 입력을 조합하기 전에 어떤 형식으로 결과가 나오는지 확인할 수 있습니다. 입력 순서는 승격 결과를 바꾸지 않습니다.

    지원 조합은 Gray8과 GrayI16이면 GrayI16, Gray8과 Gray16이면 Gray16입니다. Gray8 또는 GrayI16 또는 Gray16을 GrayI32와 조합하면 GrayI32가 됩니다. 예를 들어 Gray8의 200과 Gray16의 1000을 기본 배율 1과 편향 0으로 더하면 출력은 Gray16의 1200입니다. 이 예의 합계는 승격된 표현 범위 안에 있으므로 포화되지 않습니다.

    먼저 두 값을 더하고 gain을 곱한 다음 bias를 더합니다. 그 결과를 승격 형식의 정수로 반올림하고 해당 범위에 포화시킵니다. 크기가 다르거나 명시된 조합이 아니면 오류이며, 유한하지 않은 gain 또는 bias도 허용하지 않습니다. 반환 영상은 별도 소유이므로 사용 후 close하고, 이후 연산에서는 원본이 아닌 승격된 픽셀 형식을 기준으로 조건을 확인하십시오.
