공개 멤버

    사용 맥락과 계약

    polar_unwrap은 입력 영상의 중심을 기준으로 각도와 반경 방향 샘플을 직사각형 영상으로 펼칩니다. 결과의 가로 방향은 각도, 세로 방향은 반경이며 중심은 입력 영상의 로컬 좌표로 지정합니다. 각도는 라디안 단위이고 범위는 양수이며 최대 16π입니다. 출력의 가로와 세로 샘플 수는 각각 적어도 2여야 합니다.

    구체 사례와 판독

    예를 들어 중심을 원의 중심에 두고 반경을 안쪽에서 바깥쪽으로 늘리면 원형 무늬가 출력 영상의 세로 방향으로 펼쳐집니다. 각도가 0에서 π까지라면 한 바퀴가 아니라 반 바퀴를 다룹니다. ROI를 사용할 때 전체 영상 좌표를 그대로 중심에 넣으면 원점 차이만큼 잘못된 위치가 펼쳐질 수 있습니다. 보간 방식과 결과 영상을 함께 확인하세요.

    적용 시 확인

    펼친 좌표는 입력 원본의 직교 좌표가 아닙니다. 결과에서 찾은 결함을 원본에 표시하려면 사용한 중심, 각도 범위, 반경 범위와 샘플 수를 보관해 역으로 위치를 해석해야 합니다. 결과 영상의 원점이 새로 정해지므로 원본 ROI의 원점도 별도로 관리합니다. 가장자리 샘플은 입력 범위와 보간 조건에 영향을 받을 수 있습니다. 한 바퀴 경계가 출력의 양쪽 끝에 나뉘므로 그 부근을 처리할 때 연속성을 어떻게 다룰지도 애플리케이션에서 정해야 합니다.
