analyze 멤버와 선언

공개 타입

zvision.analyze: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_advanced.analyze.

Modes: components, labels, touching labels, whole (0..3); foreground: nonzero, zero, relative, soft (0..3).

회색 영상과 선택 마스크에서 연결 영역 또는 라벨별 측정을 생성합니다.

확인된 인자 조건

image
분석할 Gray8 ZImage
gray
같은 크기의 선택 Gray8 측정 영상; None이면 입력 image 사용, 기본값 None
mask
선택적 Gray8 마스크; None이면 제한 없음; 기본값 None
mode
0 성분, 1 라벨, 2 접촉 라벨, 3 전체; 기본값 0
foreground
0 비영, 1 영, 2 상대, 3 소프트 전경 방식; 기본값 0
a
상대 전경이면 0–1 비율, 소프트 전경이면 낮은 임계값; 기본값 0.0
b
소프트 전경의 높은 임계값; a보다 커야 함, 기본값 0.0
softness
소프트 전경의 완화값; 기본값 1.0
eight_connected
bool; 8연결 사용 여부; 기본값 True
max_blobs
최대 Blob 수; 기본값 (1 << 63) - 1
min_area
포함 최소 면적; 기본값 1
max_area
최대 영역 면적(픽셀 수); 기본값 (1 << 63) - 1
pixel_size
유한한 양의 x,y 픽셀 크기 쌍; 기본값 (1.0,1.0)

반환: 별도로 close할 BlobResult

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.
