HoleInitialization 멤버와 선언

공개 타입

zvision.HoleInitialization: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._naming_preprocessing.HoleInitialization.

Initial masked values are input pixels or nearest known pixels.

Python
HoleInitialization(value)

인자 선언

  • value · POSITIONAL_OR_KEYWORD · 기본값 없음

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

  • INPUT
  • NEAREST_KNOWN

attribute · 선언 타입 zvision._naming_preprocessing.HoleInitialization

열거 값

  • INPUT = 0 · 입력의 기존 값으로 결손을 초기화합니다.
  • NEAREST_KNOWN = 1 · 가장 가까운 알려진 값으로 결손을 초기화합니다.

사용과 결과 해석

마스크로 지정한 구멍을 이방성 보간하기 전에 시작값을 어떻게 채울지 정하는 열거형입니다. INPUT은 입력 영상에 이미 있는 값을 초기값으로 사용하고 NEAREST_KNOWN은 알려진 픽셀 중 가까운 값을 이용합니다. 이 선택은 반복 계산의 출발점을 바꾸는 것이며 마스크 바깥을 구멍으로 바꾸는 설정이 아닙니다.

예를 들어 구멍 안에 입력 픽셀 값이 0으로 채워져 있고 주변의 알려진 값이 100이면 INPUT은 0에서, NEAREST_KNOWN은 주변 알려진 값에서 시작할 수 있습니다. 이후 확산 계산은 반복 횟수, timestep, kappa와 conductance 등 별도의 설정에도 영향을 받습니다. 초기화 방식만 바꾸어 얻은 결과가 항상 동일하다고 가정하면 안 됩니다.

InpaintOptions에서 initialization을 명시하면 기존 nearest_known 선택에 대응해 적용됩니다. 입력 마스크의 의미와 영상 형식, 반복 수 및 정지 보고를 함께 확인하십시오. 복원된 영역은 관측되지 않은 내용을 추정한 것이므로 원본 픽셀로 검증된 사실과 구별해 사용해야 합니다.
