사용과 결과 해석

기준 형상에서 특정 계측 인스턴스가 놓인 ROI 좌표계로 가는 강체 배치를 표현합니다. translation은 픽셀 이동이고 angle은 시계 방향 라디안이며 기본값은 0입니다. 평행 이동과 회전은 별개의 요소이므로 이동 (10,20), 각도 0이면 기준 좌표의 축 방향을 유지하면서 원점을 이동한 예로 해석할 수 있습니다. 각도가 달라지면 좌표의 방향도 바뀌므로 이동 벡터만 더해 같은 배치라고 처리할 수 없습니다. 이 배치는 세계 단위 보정이나 렌즈 보정이 아니며 변환된 결과가 어느 ROI를 기준으로 하는지 기록해야 합니다. 여러 인스턴스에 같은 모델을 적용하는 경우 각 인스턴스의 placement와 결과를 짝지어야 다른 위치의 관측을 혼합하지 않습니다. 라디안과 도를 혼동하지 말고 화면 좌표에서 시계 방향이라는 규칙을 확인하십시오. 예를 들어 90도는 π/2 라디안입니다. ROI가 바뀌었는데 이전 배치 숫자만 복사하면 위치가 어긋날 수 있으므로 입력 영상의 원점과 모델 좌표계를 함께 대조합니다. 실패한 측정도 해당 배치의 결과 상태로 보존합니다. 같은 이동을 쓰더라도 기준 형상의 좌표계가 바뀌면 결과 위치도 달라집니다. 변환의 입력과 출력 기준을 함께 기록하십시오.
