LineMeasurementResult 멤버와 선언

공개 타입

zvision.LineMeasurementResult: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.LineMeasurementResult.

독립 선 계측 스냅샷.

status가 0일 때 parameters는 (점 x, 점 y, 방향 x, 방향 y)이다.
적합이 없으면 parameters와 inliers, rms, maximum은 None이다.

독립 불변 선 계측 결과 값입니다. 일반적인 경로는 대응 모델의 measure(image)입니다. status와 fit을 함께 확인합니다.

확인된 인자 조건

kind
결과 형상 코드 1; 다른 값은 거부.
status
정수 0 적합, 1 점 부족, 2 피팅 실패.
converged
수렴 여부 bool.
parameters
성공 시 (직선 위 점 x, y, 방향 x, y) 숫자 네 값. 측정 결과의 방향은 단위 벡터이며 직접 생성할 때는 정규화를 검사하지 않음. 실패 시 None으로 정리.
inliers
성공 시 채택점 수; 실패 시 None으로 정리.
rms
성공 시 채택점 잔차 RMS(픽셀); 실패 시 None으로 정리.
maximum
성공 시 채택점 최대 잔차(픽셀); 실패 시 None으로 정리.
refit_iterations
재피팅 반복 횟수.
probes
MeasurementProbe 값들의 열; 불변 튜플로 복사.
fit_count
피팅 입력점 수; 기본 0. fit 통계에 사용.
