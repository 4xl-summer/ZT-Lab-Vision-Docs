Python API · laws_texture

laws_texture 멤버와 선언

공개 타입

zvision.laws_texture: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_laws.laws_texture.

Return an independent signed GrayF32 Laws convolution image.

분리 가능한 Laws 기저 커널을 적용해 부호 있는 질감 응답을 계산합니다.

Python
laws_texture(image, options)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
처리할 입력 영상.
options
LawsOptions: 3·5·7 커널 크기와 호환 기저, shift 0–9, 경계 조건과 양의 작업 상한.

반환: 독립 소유 GrayF32 응답 영상; close합니다.

오류: 지원하지 않는 기저·크기, 경계 조건 또는 작업 한도 초과는 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    세로 및 가로 Laws 기저를 분리 가능한 커널로 적용해 부호 있는 질감 응답을 만듭니다. image는 입력 영상이고 options에는 기저, 크기, shift, 경계와 작업 상한을 지정합니다. 반환된 독립 GrayF32 영상은 사용 후 close해야 합니다. 음수 응답도 가능하므로 Gray8 강도로 그대로 해석하면 안 됩니다.

    커널 크기는 3, 5 또는 7이며 사용할 기저는 선택한 크기와 호환되어야 합니다. shift는 0~9입니다. 예를 들어 경계 근처에 상수 경계를 택하면 지정 강도값이 사용되지만 복제나 반사에서는 상수값을 0으로 두어야 합니다. 작업 상한은 양수여야 하며 유효하지 않은 조합은 오류입니다.

    필터 출력은 선택한 방향 성분에 대한 응답이지 결함 판정 자체가 아닙니다. 기준과 검사 영상에 같은 기저와 경계 조건을 적용하고 후속 통계나 임계값을 별도로 정해야 합니다. 합성 무늬와 실제 조명의 차이를 구분해 평가하십시오.
