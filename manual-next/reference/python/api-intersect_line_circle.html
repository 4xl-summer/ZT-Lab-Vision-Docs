Python API · intersect_line_circle

intersect_line_circle 멤버와 선언

공개 타입

zvision.intersect_line_circle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.intersect_line_circle.

Classify no intersection, tangent or two points; tolerance is a distance.

유향 선과 원의 교차를 분류합니다.

Python
intersect_line_circle(line, circle, tolerance)

인자 선언

  • line · POSITIONAL_OR_KEYWORD · 기본값 없음
  • circle · POSITIONAL_OR_KEYWORD · 기본값 없음
  • tolerance · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

line
DirectedLine2; 유한한 원점과 0이 아닌 방향.
circle
MeasurementCircle2; 유한한 중심과 양의 반경.
tolerance
유한한 0 이상의 거리 허용치; 입력 좌표 단위.

반환: MeasurementIntersection: 없음, 접점 또는 두 점.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    유향 무한선과 원이 만나는 형태를 분류합니다. line은 유한한 원점과 0이 아닌 방향을 가진 DirectedLine2이고 circle은 유한한 중심과 양의 반경을 가진 MeasurementCircle2입니다. tolerance는 좌표와 같은 단위의 유한한 0 이상의 거리 허용치입니다. 예를 들어 원점 중심의 반경 1인 원과 y=0인 선은 (−1,0), (1,0) 두 점에서 만나고, y=1인 선은 한 점에서 접합니다. y=2인 선은 교점이 없습니다. 이는 무한선에 대한 계산이므로 영상 안의 유한 선분과 만나는지 판단하려면 별도의 선분 범위 검사가 필요합니다. 반환한 MeasurementIntersection의 종류를 먼저 확인하고 해당 상태가 제공하는 좌표만 사용하십시오. 교점 없음의 좌표를 (0,0)으로 대체하면 원점에 존재하는 실제 교점과 구별할 수 없습니다. ROI 로컬 픽셀의 선과 세계 단위의 원을 바로 혼합하지 말고 공통 좌표계로 변환한 뒤 허용치도 그 단위에 맞추어 지정합니다. 허용치를 바꾸면 접촉 부근의 분류가 바뀔 수 있으므로 결과를 비교할 때 입력과 허용치를 함께 기록합니다. 선 방향을 반대로 해도 무한선의 기하학적 위치는 같지만 결과 점의 나열 순서에 의존하는 후속 처리는 별도로 확인하십시오.
