공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    areaint필수원래 전경 픽셀 수입니다.
    leftint필수트림된 ROI 로컬 왼쪽 포함 경계입니다.
    topint필수트림된 ROI 로컬 위쪽 포함 경계입니다.
    rightint필수트림된 ROI 로컬 오른쪽 제외 경계입니다.
    bottomint필수트림된 ROI 로컬 아래쪽 제외 경계입니다.

    극단값을 제외한 경계

    BlobTrimmedBounds는 원래 비영 전경 픽셀 수 area와 트림된 ROI 로컬 left, top, right, bottom을 나타냅니다. 왼쪽과 위는 포함하고 오른쪽과 아래는 제외하는 반열림 경계입니다. 반환 사각형의 면적과 원래 전경 픽셀 수는 같은 값이 아닙니다.

    반열림 좌표 예

    left=2, right=5라면 포함되는 x 위치는 2, 3, 4이고 폭은 5-2=3입니다. top=1, bottom=3이면 높이는 2입니다. 오른쪽과 아래를 포함으로 해석해 각각 1을 더하면 표시나 잘라내기 범위가 한 픽셀씩 커집니다.

    트림의 해석

    이 경계는 각 축 극단의 일부 픽셀을 제외한 결과이므로 가장 먼 잡음점의 영향을 줄이는 데 사용할 수 있습니다. 원래 area는 제외 전 전경 수를 나타내므로 반환 사각형 안의 전경 수와 혼동하지 않습니다. 트림 수를 크게 하면 실제 물체의 끝부분도 범위에서 빠질 수 있습니다.

    적용과 확인

    blob_trimmed_bounds의 결과를 ROI 위에 표시하고 제외하려는 극단점과 사각형이 기대에 맞는지 확인합니다. 전체 영상에 표시할 때는 ROI 원점을 적용합니다. 물리 크기로 판정하려면 픽셀 간격과 좌표 보정도 필요합니다.
