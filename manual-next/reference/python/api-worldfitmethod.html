사용 맥락과 계약

WorldFitMethod는 보정된 관측점에서 월드 도형을 적합할 방법을 선택합니다. LEAST_SQUARES는 최소 제곱 방식이고 CONSENSUS는 결정적인 후보 합의를 이용합니다. 도형의 종류를 고르는 WorldFitKind와 독립적이며 두 선택을 함께 정해야 결과를 올바르게 해석할 수 있습니다.

구체 사례와 판독

예를 들어 대부분의 점이 y=2 mm의 직선 부근에 있고 하나가 멀리 떨어져 있다면 최소 제곱은 모든 잔차의 제곱에 영향을 받습니다. 합의 방법에서는 내점 임계값과 후보 제한 등 설정을 함께 고려해야 합니다. 어느 방식이든 잘못된 보정이나 좌표 단위 혼동을 자동으로 고쳐 주지는 않으므로 보류점으로 결과를 검증하세요.

적용 시 확인

내점 여부와 잔차는 결과의 개별 관측 정보에서 확인할 수 있습니다. 임계값을 넓히면 더 많은 점을 허용할 수 있지만 실제 이상점이 포함될 수 있고, 너무 좁히면 정상 관측이 제외될 수 있습니다. 기준은 월드 출력 단위와 현장의 측정 오차에 맞춰 정하고 독립 데이터로 확인합니다. 예를 들어 0.5 mm를 기준으로 사용한다면 잔차가 0.3 mm인 점과 0.8 mm인 점은 서로 다른 위치에 있습니다. 실제 사용 여부는 반환된 진단과 선택한 방식의 계약으로 확인합니다.
