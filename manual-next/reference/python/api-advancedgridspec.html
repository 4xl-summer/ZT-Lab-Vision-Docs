    사용과 결과 해석

    체커보드 또는 어두운 점 격자의 기대 크기와 영상에서 후보를 찾는 조건을 지정합니다. kind는 체커보드 1, 어두운 점 2이며 rows와 columns는 예상 격자 크기입니다. sample_radius는 국소 대비를 계산하는 픽셀 반경, min_contrast는 최소 대비, suppression_radius는 가까운 후보를 억제하는 거리, match_tolerance는 격자의 예상 위치와 검출점을 짝짓는 거리입니다. 거리 조건은 픽셀로 해석합니다. 예를 들어 4행 5열을 지정했다면 결과의 행·열 인덱스가 이 범위에 해당하는지 확인하십시오. 작은 대비나 잘못된 대상 종류는 후보 발견에 영향을 주며 지나치게 큰 억제 거리는 서로 다른 점을 하나로 취급할 수 있습니다. 영상 형식, 양의 반경·허용치와 검출 결과를 함께 확인해야 합니다. 격자점 사이 거리가 서로 가까운 영상에서는 억제 반경이 인접한 두 점을 구분할 수 있는지 살펴야 합니다. 반대로 너무 약한 대비 기준은 배경의 무늬를 후보로 포함할 수 있습니다. 검출된 인덱스와 영상 위 위치를 같이 표시하고 필요할 때 한 설정씩 바꾸어 결과 차이를 관찰하십시오. 정확한 물리 간격은 영상상의 후보 거리 설정과 별도로 정의해야 합니다.
