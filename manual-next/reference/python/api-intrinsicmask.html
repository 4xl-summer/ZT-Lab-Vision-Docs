열거 값

  • NONE = 0 · 내참수를 선택하지 않습니다.
  • FX = 1 · 가로 초점거리를 선택합니다.
  • FY = 2 · 세로 초점거리를 선택합니다.
  • CX = 4 · 가로 주점 좌표를 선택합니다.
  • CY = 8 · 세로 주점 좌표를 선택합니다.
  • K1 = 16 · 첫 방사 왜곡 계수를 선택합니다.
  • K2 = 32 · 둘째 방사 왜곡 계수를 선택합니다.
  • K3 = 64 · 셋째 방사 왜곡 계수를 선택합니다.
  • P1 = 128 · 첫 접선 왜곡 계수를 선택합니다.
  • P2 = 256 · 둘째 접선 왜곡 계수를 선택합니다.
