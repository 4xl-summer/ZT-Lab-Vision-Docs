search 멤버와 선언

공개 타입

zvision.search: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.search.

여러 모델의 점 삼중항으로 후보 자세를 찾고 ICP로 정제합니다.

Python
search(models, target, options)

인자 선언

  • models · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

models
PointCloud 시퀀스; 비어 있지 않고 각 모델에 유효점 3개 이상
target
목표 PointCloud; 모델과 단위가 같고 유효점 3개 이상
options
SearchOptions: 가설·결과 한도, 대응 거리·겹침·ICP 및 자세 제약

반환: Match3D 값의 독립 목록; 검색 결과가 없으면 빈 목록입니다.

오류: 단위·옵션이 다르거나 점 또는 가설 예산이 부족하면 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    search는 여러 모델 점군과 목표 점군에서 점 삼중항으로 자세 가설을 만들고 ICP로 후보를 정제합니다. models는 비어 있지 않아야 하며 각 모델과 target에는 최소 세 개의 유효점이 필요하고 길이 단위가 일치해야 합니다. SearchOptions의 전체 가설 예산은 모델 수 이상이어야 각 모델에 예산을 배분할 수 있습니다. edge_tolerance는 삼중항 변의 길이 차이 기준이고 min_overlap은 최소 겹침 비율입니다.

    각 반환 Match3D는 원래 모델 목록의 인덱스와 겹침, 등록 변환 및 RMS를 담습니다. 예를 들어 model_index 1은 두 번째 모델이므로 입력 목록 순서를 결과와 함께 보관합니다. 이동 범위, 회전 한도 및 RMS 조건이 후보를 걸러낼 수 있어 빈 목록은 정상적인 무검출일 수 있습니다. 유효하지 않은 설정이나 점 부족은 오류입니다. 탐색이 유한하고 대칭 또는 가림이 있을 수 있으므로 결과가 모든 가능한 자세를 찾았다고 가정하지 않습니다.
