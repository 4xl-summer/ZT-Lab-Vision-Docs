frontoparallel_circle_pose_candidates 멤버와 선언

공개 타입

zvision.frontoparallel_circle_pose_candidates: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.frontoparallel_circle_pose_candidates.

Recover two normal directions for a zero-distortion frontoparallel circle.

왜곡이 없는 정면 원에 대한 두 법선 방향 자세 후보를 계산합니다.

Python
frontoparallel_circle_pose_candidates(center, radius_x, radius_y, radius_world, lens, unit, target_frame, camera_frame)

인자 선언

  • center · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_world · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lens · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음
  • target_frame · POSITIONAL_OR_KEYWORD · 기본값 없음
  • camera_frame · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

center
영상의 원 중심 픽셀 좌표
radius_x
양의 영상 x 방향 반경(픽셀); radius_x/fx와 radius_y/fy는 서로 일치해야 함
radius_y
양의 영상 y 방향 반경(픽셀)
radius_world
양의 월드 원 반경(지정 단위)
lens
왜곡이 0인 LensModel
unit
월드 길이 단위
target_frame
0이 아니고 카메라와 다른 타깃 프레임 ID
camera_frame
0이 아니고 타깃과 다른 카메라 프레임 ID

반환: 두 자세 후보 값

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

radius_x: 유한한 수 검사.

radius_y: 유한한 수 검사.

radius_world: 유한한 수 검사.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
