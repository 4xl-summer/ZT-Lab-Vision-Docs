ROI 경계의 정의

SplitBorder는 거리 기반 물체 분할에서 관심 영역 바깥을 어떻게 취급할지 선택합니다. INSIDE_ROI_ONLY는 ROI 내부 기준이고 OUTSIDE_BACKGROUND는 ROI 밖을 배경으로 보는 선택입니다. 객체가 경계에 닿았을 때 거리와 마커 후보에 영향을 줄 수 있으므로 ROI 위치와 함께 고정합니다.

경계에 닿은 물체

마스크의 물체가 영상 중간에 완전히 들어온 경우와 ROI 가장자리에서 잘린 경우를 구분해야 합니다. ROI 밖을 배경으로 취급하면 바깥을 생각하지 않는 설정과 경계 근처 거리의 해석이 달라집니다. 결과가 달라진 것을 연결 조건 변경의 효과로 혼동하지 않도록 다른 옵션은 유지합니다.

분할 확인

SplitOptions의 border를 지정하고 생성된 마커와 레이블 영상을 원본에 겹쳐 확인합니다. 마커의 수만 같아도 위치와 분할 경계는 다를 수 있습니다. 경계 피크 제외 옵션 역시 별개이므로 border와 함께 기록해 재현합니다.

적용 범위

경계 설정은 화면 밖의 실제 물체 모양을 복원하지 않습니다. 검사에서 잘린 객체를 허용할지 제외할지 먼저 정하고, ROI를 바꾼 경우에는 같은 설정이라도 경계에 닿는 물체가 달라질 수 있음을 고려합니다.
