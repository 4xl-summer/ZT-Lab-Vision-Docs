compose_rigid3 멤버와 선언

공개 타입

zvision.compose_rigid3: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.compose_rigid3.

Return next * first; transforms must have matching frames and units.

프레임이 이어지는 두 강체 변환을 next × first 순서로 합성합니다.

Python
compose_rigid3(first, next)

인자 선언

  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • next · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

first
첫 RigidTransform3입니다.
next
첫 변환 뒤에 적용할 RigidTransform3입니다.

반환: 합성된 RigidTransform3 값입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    compose_rigid3는 두 3차원 강체 변환을 순서대로 적용한 변환을 만듭니다. first를 먼저 적용하고 next를 그 결과에 적용하므로 전체 변환은 행렬 표기로 next × first입니다. 첫 변환의 도착 프레임과 다음 변환의 출발 프레임이 이어져야 하며 두 이동량의 길이 단위도 일치해야 합니다.

    구체 사례와 판독

    예를 들어 A에서 B로 X 방향 10만큼 이동하고 B에서 C로 Y 방향 5만큼 이동하는 두 변환에 회전이 없다면 A의 원점은 C에서 (10,5,0)이 됩니다. 회전이 있는 경우에는 이동 벡터도 다음 회전의 영향을 받으므로 두 이동 벡터를 무조건 더하는 것으로 대체할 수 없습니다. 입력 순서를 바꾸면 일반적으로 결과가 달라집니다.

    적용 시 확인

    예를 들어 회전이 없는 A→B 이동과 B→C 이동을 연결할 때 중간 프레임 B가 동일해야 합니다. B와 이름만 비슷한 별도 기준을 연결하면 계산은 가능해도 실제 물리적 위치와 맞지 않습니다. 변환마다 출발과 도착 프레임을 기록하고 알려진 기준점을 연쇄 변환해 예상한 위치에 도달하는지 확인하세요. 변환을 행렬로 기록할 때 벡터를 왼쪽이나 오른쪽 어디에 두는지의 표기 관례도 점검합니다. 이 함수의 적용 순서는 first 다음 next입니다.
