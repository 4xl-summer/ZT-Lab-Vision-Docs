    사용과 결과 해석

    쌍선 계측에서 한쪽 선의 적합 결과를 점, 방향, 채택점 수, RMS, 수렴 여부와 반복 횟수로 담습니다. point는 선 위의 한 위치이고 direction은 선의 방향이므로 두 값 모두 원본 관측의 좌표계를 따라 읽어야 합니다. inliers는 실제 적합에 채택한 점 수이며 전체 프로브 수와 같다고 가정하지 않습니다. RMS가 작더라도 잘못 선택된 경계의 점들이 서로 직선에 가깝다면 목적 대상과 다른 선이 나올 수 있으므로 관측점의 위치도 확인하십시오. 예를 들어 y=2 위의 점들이라면 방향의 부호가 반대여도 같은 무한 직선을 나타낼 수 있습니다. converged와 iterations는 계산 종료의 정보를 제공하지만 수렴만으로 실제 장비의 정밀도를 보장하지 않습니다. 결과가 ROI 로컬 픽셀이라면 다른 ROI의 결과와 비교하기 전에 원점을 맞추고, 잔차의 단위도 같은 픽셀 기준으로 기록합니다. 피팅 결과가 존재하지 않는 상태를 선 위의 점 (0,0)이나 RMS 0으로 대체하면 정상 값과 구별할 수 없습니다. 결과가 제공되었는지 먼저 확인한 뒤 필드를 사용하십시오. 두 선의 결과를 비교한다면 각 선에 사용된 점을 따로 표시하여 서로 교차하거나 같은 경계를 중복 선택한 상황을 살핍니다. 점 수와 잔차는 어느 쪽 적합에 속하는지도 유지해야 합니다.
