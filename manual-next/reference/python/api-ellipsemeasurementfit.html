    사용 맥락과 결과 해석

    성공한 타원 측정의 중심, 장반축과 단반축, 회전각을 나타냅니다. 중심과 길이는 측정 영상 ROI의 로컬 픽셀이고 각도는 라디안입니다. 직경이 필요하면 각 반축을 두 배로 변환해야 합니다. 예를 들어 장반축이 5이면 장축 길이는 10픽셀입니다.

    이 값은 EllipseMeasurementResult에서 status가 성공일 때만 존재합니다. 결과의 탐침 진단과 수렴 상태를 같이 확인하여 값의 출처를 평가합니다. ROI 원점이 있는 원본 영상에 중심을 표시할 때는 좌표계를 맞춰야 합니다. 단순히 반축이 양수라는 사실만으로 실제 부품의 치수 정확도나 정렬 품질이 보증되지는 않습니다.

    타원 호의 일부만 관찰된 경우에도 숫자 적합이 나올 수 있으므로 사용된 탐침 위치와 잔차를 같이 봅니다. 결과 중심을 원본 영상에 표시한다면 ROI 원점도 포함합니다.

    값을 확인하는 순서

    center 항목: 타원 중심의 ROI 로컬 픽셀 좌표입니다. major_radius 항목: 장반축 길이로 픽셀 단위입니다. minor_radius 항목: 단반축 길이로 픽셀 단위입니다. angle 항목: 장축 회전각으로 라디안 단위입니다.
