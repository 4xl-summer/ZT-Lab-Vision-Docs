    사용 맥락과 계약

    CodedFiducial은 ZVFD-1 표식을 해독한 식별자와 격자 정보를 담습니다. id는 표식 식별자이고 row와 column은 격자 원점 인덱스입니다. clockwise_quarter_turns는 시계 방향 90도 단위 회전이며 has_spacing은 pitch_x, pitch_y 간격 정보의 존재 여부를 표시합니다. 간격이 있는 경우 unit과 함께 물리적 크기로 해석합니다.

    구체 사례와 판독

    예를 들어 quarter turn이 1이면 기준 방향에서 시계 방향으로 90도 회전한 상태입니다. 간격이 10 mm로 기록된 경우 인접 격자 중심 사이의 물리적 간격을 의미하며 영상에서의 10픽셀과 같다고 가정할 수 없습니다. has_spacing이 거짓이면 간격 필드를 유효한 치수로 임의 해석하지 마세요.

    적용 시 확인

    식별자와 격자 인덱스는 표식의 데이터이고 영상에서 표식을 발견한 위치는 별도의 검출 결과에 있습니다. 회전 정보는 90도 단위이므로 2는 180도입니다. 서로 다른 단위의 격자 간격을 비교할 때에는 먼저 동일한 길이 단위로 바꾸고 표식 해독 여부를 확인하세요. 예를 들어 0은 회전하지 않은 기준 방향이고 2는 시계 방향 반 바퀴로 해석합니다. 길이 단위도 함께 기록하세요.
