    사용 조건과 흐름

    BeadRun은 비드 검사에서 이어진 프로브 구간의 시작 인덱스 first, 끝 인덱스 last와 상태 flags를 담습니다. 인덱스는 입력 경로의 프로브 순서와 연결하여 해석해야 하며 좌표 자체나 실제 길이가 아닙니다. 상태 비트는 해당 연속 구간에 나타난 검사 조건을 구분하는 데 사용합니다.

    구체 사례와 결과 판독

    예를 들어 입력 경로 순서의 프로브 3부터 5까지가 한 구간으로 보고되면 시작과 끝을 이용해 원본 경로의 해당 위치를 찾을 수 있습니다. 간격이 일정하지 않은 경로에서는 인덱스 차이만으로 실제 길이를 추정할 수 없습니다. 프로브 좌표와 반환된 flags, 포함 여부를 함께 살피고 길이 통계가 필요하면 해당 결과 API를 사용하세요.

    적용 시 확인

    연속 구간의 첫 인덱스와 마지막 인덱스는 경로를 따라 어디를 다시 확인해야 하는지 가리킵니다. 별도의 좌표 변환 없이 인덱스를 픽셀 위치로 표시하지 마세요. 결과 전체의 프로브 목록과 동일한 순서를 유지하여 검토합니다. 예를 들어 3,4,5번 점의 좌표 간 거리가 각각 다르다면 구간이 세 프로브를 포함한다고 해서 길이를 세 픽셀이라 할 수 없습니다. 보정된 길이가 필요하면 좌표와 단위를 명시해야 합니다. 입력과 결과의 설정을 함께 보관하세요.
