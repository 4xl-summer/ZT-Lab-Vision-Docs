edges

BeadQualityResult.edges

탐침별 양 에지 좌표와 보간 비트를 복사합니다.

반환: 에지쌍이 없는 위치는 None인 독립 튜플입니다.

오류: 닫힌 결과 또는 인덱스 범위 오류가 발생할 수 있습니다.

Per probe ((left x,y),(right x,y),fill bits), or None when no pair.

대체된 에지를 나타내는 탐침별 비트를 복사합니다.

Bit 1 means left edge synthesized, bit 2 means right edge synthesized.
