transfer_planar_calibration 멤버와 선언

공개 타입

zvision.transfer_planar_calibration: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.transfer_planar_calibration.

Transfer planar calibration through a source-to-output projective warp.

원본→출력 투영 워프에 맞게 평면 보정을 전달합니다.

Python
transfer_planar_calibration(source, source_to_output)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • source_to_output · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
원본 PlanarCalibration.
source_to_output
원본에서 출력으로 가는 Homography; 좌표계가 보정과 호환되어야 함.

반환: 출력 픽셀에서 같은 세계 단위로 가는 새 PlanarCalibration.

오류: 타입이 틀리거나 워프가 가역이 아니면 오류.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    원본 영상에서 학습한 평면 보정을 원본에서 출력으로 가는 투영 워프에 맞게 이전합니다. source는 원본 PlanarCalibration이고 source_to_output은 원본 픽셀을 출력 픽셀로 보내는 Homography입니다. 반환된 보정은 출력 영상의 픽셀 좌표에서 같은 세계 평면으로 가는 매핑을 제공합니다. 예를 들어 원본의 점이 워프된 출력의 다른 픽셀 위치로 이동했다면 출력 좌표를 원본 보정에 그대로 넣지 말고 이전된 보정을 적용해야 합니다. 워프의 방향을 출력에서 원본으로 가는 행렬로 착각하면 숫자가 모두 유한해도 잘못된 세계 좌표가 나올 수 있으므로 알려진 점 하나의 대응 방향을 먼저 확인하십시오. 입력 보정이 사용하는 원점과 워프가 정의된 픽셀 좌표계가 일치해야 하고 ROI 로컬 점은 적절한 전체 영상 기준으로 변환해야 합니다. 이전은 렌즈 왜곡이나 촬영 환경 변화를 자동으로 새로 보정하는 과정이 아닙니다. 학습에 쓰지 않은 대응점을 출력 영상에서 따로 검증하고, 반환된 세계점의 단위와 기준 평면을 원본 설정과 함께 기록하십시오. 원본에서 출력으로 이동시키는 워프와 출력에서 세계로 가는 이전 결과는 역할이 다릅니다. 알려진 점의 양쪽 픽셀 위치와 세계값을 함께 기록해 방향 오류를 확인하십시오.
