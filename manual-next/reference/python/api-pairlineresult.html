    사용과 결과 해석

    두 경계의 선 적합과 각 프로브 결과를 묶는 결과입니다. status는 0이면 적합, 1이면 충분한 관측이 없음, 2이면 적합 실패를 나타냅니다. first와 second는 각각 독립적인 적합 결과이며 해당 결과가 없으면 None일 수 있습니다. probes에는 선택된 에지와 탐색 상태를 조사할 수 있는 개별 관측이 포함됩니다. 먼저 status와 두 결과의 존재 여부를 확인한 뒤 각 선의 채택점 수와 잔차를 살피십시오. 두 선의 점이 각각 직선에 가깝더라도 목적 물체의 양쪽 경계인지 여부는 프로브 위치와 선택된 에지를 영상과 대조해야 합니다. 탐색 방향을 반대로 바꾸면 첫째와 둘째 경계의 해석도 달라질 수 있어 기준 방향을 함께 기록해야 합니다. 충분한 점이 없다는 상태는 정상적인 간격 0과 다르고, 하나의 피팅이 없다는 사실을 원점 직선으로 표현해서도 안 됩니다. 두 선 사이 간격이 필요하다면 먼저 이들이 같은 좌표계에서 유효하고 목적에 맞는 관계인지 확인한 다음 적절한 기하 연산을 적용합니다. 각 프로브에서 두 에지를 찾는 경우라도 최종 적합의 채택 여부는 별도로 확인해야 합니다. 첫 선의 관측과 둘째 선의 관측을 섞으면 간격이 아닌 평균적인 한 선을 적합하는 문제가 될 수 있습니다. 실패 시에는 입력의 검색 범위와 극성, 영상 경계를 차례로 검토하십시오.
