    연결 성분의 값

    Blob은 하나의 연결된 전경 성분을 측정한 결과입니다. area는 성분에 속하는 픽셀 수이며 x와 y, width와 height는 ROI 로컬 좌표의 최소 둘러싸는 사각형을 나타냅니다. 사각형 내부의 모든 픽셀이 전경이라는 뜻은 아니므로 사각형 넓이와 성분 면적을 구분합니다.

    중심 계산 예

    예를 들어 전경 픽셀이 ROI 안의 (0, 0), (1, 1)에 있고 이 둘을 하나의 성분으로 연결했다면 면적은 2이고 픽셀 좌표의 평균 중심은 (0.5, 0.5)입니다. 둘러싸는 사각형은 폭 2와 높이 2이므로 사각형 넓이는 4입니다. 구멍이나 빈 칸은 사각형에 포함되지만 성분 픽셀 수에는 포함되지 않습니다.

    호출과 해석

    이진 마스크를 만든 뒤 연결 방식을 선택하고 블롭 분석을 실행하여 결과를 읽습니다. 대각선 이웃을 연결하는지에 따라 위의 두 점이 하나 또는 두 성분이 될 수 있습니다. ROI에서 얻은 좌표를 전체 영상에 표시할 때는 ROI의 원점을 더하는 등 기준을 맞추어야 합니다. 성분 순서를 프레임 간 물체의 고유 식별자로 가정하지 않습니다.

    전경 픽셀이 대각선으로만 접할 때 4연결이면 두 성분이고 8연결이면 하나가 될 수 있습니다. 따라서 면적 필터를 비교할 때도 마스크뿐 아니라 연결 방식을 같게 유지해야 합니다. 결과의 폭과 높이는 성분의 최대 범위이지 채워진 면적이 아닙니다.
