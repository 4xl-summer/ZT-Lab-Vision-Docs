사용 맥락과 결과 해석

기본 매칭 모델의 점수 방식은 NCC와 SHAPE 두 종류로 구분합니다. NCC는 선택한 명암값의 정규화 상관으로 패턴을 비교하고, 형상 방식은 기울기 방향 특징을 이용합니다. 동일한 점수 숫자가 두 방법에서 동일한 신뢰도를 나타내지는 않으므로 모델을 바꾸면 정상·불량 영상에서 임계값을 각각 다시 평가해야 합니다.

종류는 학습된 모델의 정보에서 확인할 수 있습니다. NCC 학습에는 적어도 두 개의 서로 다른 선택 픽셀이 필요합니다. 형상은 최소 3×3 영상과 유효 기울기 특징이 필요하므로 내부 텍스처보다 경계가 안정적인지를 먼저 살펴봅니다. 이 열거값은 포즈 결과나 검사 통과 여부가 아니며, 모델 정보의 종류를 판독하는 데 사용합니다.

모델 정보의 종류를 확인한 뒤 표본 수의 의미도 함께 읽어야 합니다. NCC의 선택 픽셀 수와 형상 특징점 수는 같은 이름으로 보고되지만 계산에 참여하는 대상이 서로 다릅니다. 형상 임계값은 입력 밝기 단위의 기울기와 연결됩니다.

값을 확인하는 순서

NCC 항목: 정규화 상관 매칭 모델을 지정합니다. SHAPE 항목: 기울기 방향 형상 매칭 모델을 지정합니다.
