    사용과 결과 해석

    복수 바코드 스캔의 읽기 목록 reads와 전체 입력의 밝기 통계 image_metrics를 함께 담습니다. 각 읽기는 MultiBarcodeRead로 형식, 텍스트, 원시 바이트, 위치와 회전 및 길이 조건을 보유합니다. 반환 값은 목록의 각 코드가 어떤 결과인지 개별적으로 해석할 수 있게 합니다.

    예를 들어 한 영상에서 QR과 Code 128이 둘 다 검출되면 두 항목의 형식과 텍스트를 따로 확인합니다. 읽기 항목의 length_accepted는 지정 길이 조건에 대한 정보이고, 읽기 개수가 0이라는 관찰과 호출 오류는 다릅니다. 입력 옵션의 최대 결과 수에 도달했는지도 확인합니다.

    image_metrics는 전체 보이는 입력의 밝기 통계로 심볼별 검증기 등급이 아닙니다. 텍스트와 raw_bytes도 다른 표현이므로 원시 자료가 필요하면 복사된 바이트를 보관합니다. 위치를 그릴 때 각 결과의 로컬과 전역 점을 표시 대상에 맞춥니다.

    읽힌 심볼마다 위치가 다르므로 입력이 ROI일 때 로컬 점을 원본에 그대로 표시하지 않습니다. 또한 디코더가 모든 심볼을 발견한다고 보장하지 않으므로 결과 개수를 제품 수량과 비교할 때 주의합니다.
