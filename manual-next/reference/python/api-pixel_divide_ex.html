Python API · pixel_divide_ex

pixel_divide_ex 멤버와 선언

공개 타입

zvision.pixel_divide_ex: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._arithmetic_gap.pixel_divide_ex.

Divide componentwise with explicit zero handling; ZERO bypasses gain/bias.

성분별 나누기를 수행하며 0 제수 정책을 적용합니다.

Python
pixel_divide_ex(left, right, output_format, zero_policy=<ZeroDivisorPolicy.ERROR: 0>, gain=1.0, bias=0.0)

인자 선언

  • left · POSITIONAL_OR_KEYWORD · 기본값 없음
  • right · POSITIONAL_OR_KEYWORD · 기본값 없음
  • output_format · POSITIONAL_OR_KEYWORD · 기본값 없음
  • zero_policy · POSITIONAL_OR_KEYWORD · 기본값 <ZeroDivisorPolicy.ERROR: 0>
  • gain · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • bias · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

left
분자 ZImage입니다.
right
분모 ZImage입니다.
output_format
요청할 출력 PixelFormat입니다.
zero_policy
ERROR 또는 ZERO이며 기본값은 ERROR입니다. ZERO는 해당 성분에 gain과 bias를 적용하지 않습니다.
gain
결과 배율이며 기본값은 1입니다.
bias
결과에 더할 값이며 기본값은 0입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

gain: 유한한 수 검사.

bias: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
