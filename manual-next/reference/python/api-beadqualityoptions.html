width_negative: 훈련 기준 폭보다 좁아지는 허용 거리입니다. 유한하고 0 이상입니다. 좌표 변환이 없으면 픽셀, 세계 변환 또는 맵을 쓰면 해당 출력 좌표 단위입니다.

width_positive: 훈련 기준 폭보다 넓어지는 허용 거리입니다. 유한하고 0 이상입니다. 좌표 변환이 없으면 픽셀, 세계 변환 또는 맵을 쓰면 해당 출력 좌표 단위입니다.

intensity_negative: 기준 밝기보다 어두워지는 허용량이며 유한하고 0 이상입니다.

intensity_positive: 기준 밝기보다 밝아지는 허용량이며 유한하고 0 이상입니다.

center_max: 훈련 중심에 대한 최대 허용 중심 편차이며 유한하고 0 이상입니다. 좌표 변환이 없으면 픽셀, 세계 변환 또는 맵을 쓰면 해당 출력 좌표 단위입니다.

coverage_min: 훈련 대비 점유율 비율의 포함 하한이며 유한하고 0 이상입니다.

coverage_max: 훈련 대비 점유율 비율의 포함 상한이며 coverage_min 이상입니다.

step_ratio: 인접 에지 이동에 대한 기준 폭 비율의 허용 상한이며 유한하고 0 이상입니다.

foreground_threshold: 전경 샘플을 판정하는 입력 밝기 임계값이며 유한해야 합니다.

coverage_half_length: 커버리지 샘플의 접선 방향 반길이(픽셀)이며 0–1024입니다.

samples_per_probe: 탐침 내부의 표본 수이며 2–1024입니다.

max_work: 작업 예산의 양의 상한입니다.

nominal_intensity: 선택적 기준 밝기입니다. None이면 훈련 밝기를 사용하며, 지정하면 유한해야 합니다.
