blob_boundary_stats 멤버와 선언

공개 타입

zvision.blob_boundary_stats: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_boundary_stats.blob_boundary_stats.

Return centroid-to-four-neighbor-boundary shape statistics.

무게중심에서 경계 픽셀 중심까지의 거리 통계를 구합니다.

Python
blob_boundary_stats(image, work_budget)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
work_budget
양의 정수 작업량 상한

반환: BlobBoundaryStats 값

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    경계 거리 분포

    blob_boundary_stats는 전경 무게중심에서 4방향 경계 픽셀 중심까지의 거리 통계를 계산합니다. 반환 결과는 전경 수, 경계 수, 거리 평균과 표준편차, 원형도와 비원형도 등을 담습니다. 경계 픽셀의 개수는 픽셀 셀의 노출 변 길이와는 다릅니다.

    수치 예

    평균 경계 거리가 4, 모집단 표준편차가 1이면 구현의 roundness 식 1 - 1/4에 따라 0.75입니다. 한 픽셀의 0거리 사례는 1로 정의됩니다. 등가 원에 대한 RMS 차이인 acircularity_rms는 이 값과 다른 수치이므로 혼동하지 않습니다.

    입력과 결과

    image에 분석할 전경 마스크를 전달하고 양의 work_budget을 지정합니다. ROI 안에 여러 성분이나 잡음이 들어간 경우 결과가 의도한 물체를 나타내는지 원본 마스크와 함께 확인합니다. 중심과 경계가 한 픽셀만 바뀌어도 분포가 변할 수 있습니다.

    판정 기준

    수치가 비슷한 두 형상도 국소 결함의 위치는 다를 수 있습니다. 원형도 하나만으로 양품을 판정하기보다 필요한 경계와 물리 보정 조건을 별도로 확인하고, 측정 기준과 사용한 마스크를 기록합니다.
