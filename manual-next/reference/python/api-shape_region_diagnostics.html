Python API · shape_region_diagnostics

shape_region_diagnostics 멤버와 선언

공개 타입

zvision.shape_region_diagnostics: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.shape_region_diagnostics.

Measure an explicit pose against inclusive (xmin,ymin,xmax,ymax); degenerate model bounds are rejected.

변환된 모델과 소스 로컬 영역의 관계를 계산합니다.

Python
shape_region_diagnostics(model, pose, region)

인자 선언

  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pose · POSITIONAL_OR_KEYWORD · 기본값 없음
  • region · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

model
형상 AdvancedMatchModel입니다.
pose
진단할 AdvancedMatch입니다.
region
포함 사각형 (xmin,ymin,xmax,ymax)입니다.

반환: 바깥 면적·특징 비율과 기준점 포함 여부를 담은 독립 값입니다.

오류: 닫힌 모델, 잘못된 입력 또는 지원하지 않는 설정은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    형상 모델, 검색 포즈와 소스 로컬 사각형을 받아 변환 모델의 영역 관계를 측정합니다. region은 유한한 (xmin,ymin,xmax,ymax) 네 좌표이며 각 상한은 하한 이상입니다. 반환값은 바깥 면적 비율, 바깥 특징점 비율 및 기준점 포함 여부의 독립 진단 값입니다.

    기준점이 영역 안에 있다는 사실만으로 모델 전체가 안에 있지는 않습니다. 예를 들어 모델이 사각형 가장자리에 걸쳐 있으면 기준점은 안에 있어도 바깥 면적 비율이 양수일 수 있습니다. 검색 ROI와 다른 원점의 사각형을 넘기지 않도록 좌표계를 맞추세요. 모델이나 포즈 타입, 퇴화한 경계 또는 잘못된 직사각형은 오류로 처리합니다.

    값을 확인하는 순서

    model 항목: 형상 AdvancedMatchModel입니다. pose 항목: 진단할 AdvancedMatch입니다. region 항목: 포함 사각형 (xmin,ymin,xmax,ymax)입니다.

    항목읽을 때 확인할 내용
    model형상 AdvancedMatchModel입니다.
    pose진단할 AdvancedMatch입니다.
