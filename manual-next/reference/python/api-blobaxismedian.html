    회전 축에서의 중앙값

    BlobAxisMedian은 전경 픽셀 수 area, ROI 로컬 좌표 x와 y, 회전한 두 축의 중앙 투영값 axis_u와 axis_v를 담습니다. 전경 좌표를 지정 방향의 두 축에 투영하고 각 축의 낮은 중앙값을 구한 뒤 원래 좌표계로 되돌린 점입니다.

    축에 따른 차이

    짝수 개 값의 낮은 중앙값은 정렬된 가운데 두 값 중 작은 쪽입니다. 예를 들어 투영값이 0, 1, 4, 9라면 중앙값은 1입니다. x와 y의 단순 평균이나 픽셀 중심의 산술 무게중심과는 다른 정의이므로 두 결과를 같은 기준으로 취급하지 않습니다.

    방향과 좌표

    blob_axis_median 호출에서 지정한 각도에 따라 투영 축이 바뀌므로 같은 마스크라도 결과가 달라질 수 있습니다. 각도를 라디안으로 기록하고 x, y를 전체 영상에 표시할 때 ROI 원점을 적용합니다. 축별 중앙값에서 만든 점이 실제 전경 픽셀 위에 있어야 하는 것은 아닙니다.

    적용 범위

    여러 떨어진 성분을 하나의 마스크에 넣으면 모든 전경 좌표의 중앙값이 계산됩니다. 개별 객체의 중심을 원한다면 먼저 대상을 분리하고 같은 각도 및 마스크 조건으로 비교합니다.
