  • FAULTED = 4 · 오류가 발생한 상태입니다.

사용 맥락과 계약

CameraState는 모의 카메라의 현재 단계가 DISCONNECTED, CONNECTED, ACQUIRING 또는 FAULTED 중 무엇인지 나타냅니다. 카메라를 만든 뒤 연결하면 CONNECTED가 되고 start를 호출하면 취득 세션이 시작됩니다. 프레임 제출과 트리거 등록은 ACQUIRING 상태에서 처리하므로 생성 직후 바로 프레임을 넣는 흐름과 구분해야 합니다.

구체 사례와 판독

오류 상태에서는 recover를 통해 연결 상태로 복구한 뒤 다시 시작합니다. stop이나 disconnect는 대기 중인 프레임과 트리거의 정리에 영향을 주므로 전환 전에 필요한 프레임을 이미 취득했는지 확인하세요. start가 새 epoch를 만드는 점은 서로 다른 취득 세션의 프레임을 구분할 때 중요합니다. 상태는 시뮬레이터의 명시적인 값이며 실제 드라이버의 장치 연결이나 동기화 상태를 자동으로 측정하지 않습니다.

적용 시 확인

취득을 다시 시작한 뒤에는 새 epoch를 기준으로 프레임과 시계 맵을 맞추어야 합니다. 이전 세션의 맵을 새 프레임에 무심코 재사용하면 출처가 다른 시간을 비교하게 됩니다. 상태 전환과 세션 값을 기록해 두세요. 연결 상태에서 시작한 세션과 복구 전의 세션은 epoch를 확인해 구분하세요.
