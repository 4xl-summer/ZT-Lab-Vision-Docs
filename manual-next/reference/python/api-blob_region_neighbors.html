Python API · blob_region_neighbors

blob_region_neighbors 멤버와 선언

공개 타입

zvision.blob_region_neighbors: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_neighbors.blob_region_neighbors.

Return lexicographically ordered pairs within max_distance.

경계 픽셀 중심 사이 거리가 한도 이하인 영역 쌍을 찾습니다.

Python
blob_region_neighbors(regions, max_distance, work_budget)

인자 선언

  • regions · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_distance · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

regions
입력 ZImage 마스크 시퀀스
max_distance
이웃으로 인정할 최대 경계 거리
work_budget
양의 정수 작업량 상한

반환: 인덱스 순으로 정렬된 독립 이웃 list

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    가까운 영역 쌍 찾기

    blob_region_neighbors는 여러 영역의 경계 픽셀 중심 사이 거리를 비교해 max_distance 이하인 쌍을 구합니다. 각 결과는 입력 시퀀스의 두 인덱스와 최소 거리를 담습니다. 영역의 중심이 가까운 순서를 반환하는 연산과는 판단 기준이 다릅니다.

    거리 기준

    가장 가까운 경계 중심의 차이가 x로 3, y로 4픽셀이면 유클리드 거리는 5픽셀입니다. max_distance가 5이면 한도 이하라는 기준에 해당합니다. 거리 수치는 중심 간 정의이므로 픽셀 셀 사이의 실제 빈 공간 폭으로 바로 해석하지 않습니다.

    입력과 제한

    regions에는 ZImage 마스크의 순서 있는 시퀀스를 전달하고 양의 work_budget을 지정합니다. 마스크들이 같은 공간을 가리키는지 확인해야 합니다. 반환 인덱스는 입력 순서에 대응하므로 나중에 목록을 재정렬한다면 대응 관계를 따로 보관합니다.

    결과 확인

    관심 있는 쌍의 마스크를 겹쳐 표시하고 경계가 원하는 물체를 나타내는지 살펴봅니다. 거리 한도를 바꾸면 후보 쌍의 범위가 바뀌지만 원래 마스크가 분리되거나 합쳐지는 것은 아닙니다.
