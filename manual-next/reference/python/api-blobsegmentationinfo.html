BlobSegmentationInfo 멤버와 선언

공개 타입

zvision.BlobSegmentationInfo: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_segmentation.BlobSegmentationInfo.

Thresholds; has_thresholds is false for LUT segmentation.

Python
BlobSegmentationInfo(low: float, high: float, has_thresholds: bool) -> None

인자 선언

  • low · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • high · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • has_thresholds · POSITIONAL_OR_KEYWORD · 타입 <class 'bool'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

BlobSegmentationInfo(<class 'float'>, <class 'float'>, <class 'bool'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    lowfloat필수상대 분할의 낮은 임계값입니다.
    highfloat필수상대 분할의 높은 임계값입니다.
    has_thresholdsbool필수임계값 정보가 존재하는지 나타내며 LUT 분할에서는 거짓입니다.

    임계값의 존재 여부

    BlobSegmentationInfo는 상대 분할의 low, high와 임계값 정보가 존재하는지 나타내는 has_thresholds를 보관합니다. LUT 분할에서는 has_thresholds가 거짓입니다. 이 경우 low와 high 숫자만 읽어 적용된 두 임계값이라고 해석하면 분할 방식을 잘못 설명하게 됩니다.

    분할 방식의 차이

    임계값 기반 분할은 설정된 경계와 픽셀 값을 비교하는 방식으로 설명할 수 있습니다. LUT 분할은 각 입력 밝기를 조회표의 항목에 매핑하므로 하나의 연속된 낮은 값과 높은 값만으로 모든 선택 관계를 표현하지 못할 수 있습니다.

    결과 기록

    분석 결과를 기록할 때 has_thresholds를 먼저 확인한 다음 참인 경우 low와 high의 의미를 확인합니다. 거짓인 경우에는 분할에 사용한 LUT와 그 스케일을 별도로 기록하는 편이 재현에 도움이 됩니다. 정보 객체 자체가 원본 영상이나 분할 마스크 전체를 대체하지는 않습니다.

    확인 방법

    같은 이미지라도 LUT의 각 항목을 바꾸면 다른 멤버십이 생길 수 있습니다. 표시된 숫자만 비교하기보다 분할 결과 마스크와 설정을 함께 확인하고, 픽셀 형식 및 값 범위가 설정에 맞는지 점검합니다.
