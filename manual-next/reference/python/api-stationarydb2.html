classmethod · 선언 타입 zvision._stationary_db2_gap.StationaryDb2

forward(cls, image, levels, centered=False)

주기 경계를 사용하는 다운샘플링하지 않는 웨이블릿 변환을 만듭니다. 이 팩터리는 기존 호환 API입니다.

확인된 인자 조건

image
변환할 ZImage입니다.
levels
1–32 정수 분해 레벨입니다.
centered
중심 위상 선택 bool이며 기본값은 False입니다.

반환: 호출자가 닫아야 하는 독립 변환 모델입니다.

오류: 유효하지 않은 인자 또는 네이티브 처리 오류는 예외가 발생합니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • centered · POSITIONAL_OR_KEYWORD · 기본값 False

levels: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Use periodic DB2 bands and optionally the centered phase. Legacy factory retained through 0.1.x; prefer image.stationary_db2(levels, centered).

확인된 인자 조건

threshold

mode
hard 또는 soft 방식이며 기본값은 SOFT입니다.

반환: 호출자가 닫아야 하는 새 모델입니다.

오류: 임계값이나 방식이 유효하지 않으면 오류입니다.

인자 선언

  • threshold · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mode · POSITIONAL_OR_KEYWORD · 기본값 <WaveletShrink.SOFT: 1>

threshold: 유한한 수 검사.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

Return a new model with thresholded detail bands and unchanged final LL.
