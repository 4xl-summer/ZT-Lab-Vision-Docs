열거 값

  • INLIER = 0 · 직선에 배정된 인라이어입니다.
  • CONSIDERED_OUTLIER = 1 · 적합에서 고려되었으나 제외된 후보입니다.
  • UNCONSIDERED_OUTLIER = 2 · 적합에서 고려되지 않은 후보입니다.

사용과 결과 해석

검출된 피크가 선 적합 단계에서 어떤 처리를 받았는지 구분합니다. INLIER는 선에 배정된 후보이고 CONSIDERED_OUTLIER는 적합에 실제로 고려되었지만 배정되지 않은 후보입니다. UNCONSIDERED_OUTLIER는 극성 등으로 그 적합에 제출되지 않은 후보를 나타냅니다.

이 분류는 영상에 존재할 수 있는 모든 에지를 나열하는 상태가 아닙니다. 임계값이나 prominence를 넘지 못한 피크는 결과 후보로 반환되기 전에 제외됩니다. 따라서 결과에 없는 피크를 미고려 외점이라고 세면 안 됩니다. max_lines가 0인 경로는 피크만 보고 선 적합을 수행하지 않는 별도 선택입니다.

LineCandidate의 reason과 선택적 line_index를 같이 살펴보면 미배정의 원인을 더 좁힐 수 있습니다. 좌표는 현재 ROI 기준이며 분류 이름만으로 월드 좌표 또는 물리 단위를 뜻하지 않습니다. 적합선의 inlier 수와 후보 개수의 차이가 예상과 다르면 먼저 추출 문턱과 극성 설정을 확인하십시오.
