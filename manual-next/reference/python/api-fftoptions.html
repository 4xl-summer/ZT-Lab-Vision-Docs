변환 격자와 기본값

FftOptions는 width와 height로 FFT 변환 격자의 크기를 지정하고 normalization으로 배율을 고릅니다. 각 변환 크기는 해당 입력 크기 이상인 2의 거듭제곱이어야 하며 기본 정규화는 BACKWARD입니다. 영상 크기와 변환 격자가 다르면 주파수 샘플의 해석도 달라지므로 두 크기를 함께 기록합니다.

크기 선택 예

입력 폭이 5이고 높이가 3이면 각각 이상인 2의 거듭제곱의 한 선택은 폭 8과 높이 4입니다. 변환 격자의 표본 수 N은 8×4=32입니다. 입력 자체의 15픽셀과 변환 격자의 32개 위치는 같은 개수가 아니므로 정규화 계산에 어떤 크기를 쓰는지 구분해야 합니다.

호출 순서

입력 크기를 확인해 유효한 변환 크기를 고르고 정규화를 지정한 다음 FFT를 실행합니다. 역변환과 외부 결과 비교에서도 같은 배율 규칙과 격자를 확인합니다. 격자를 크게 잡는 선택은 메모리와 작업량에도 영향을 주므로 필요 없이 큰 값을 사용하기보다 제한과 처리 목적을 함께 살핍니다.

변환 격자가 입력보다 큰 경우 원래 영상이 차지하는 영역과 추가된 영역을 구분해야 합니다. 역변환을 원본 크기로 해석할 때도 전체 변환 격자와 관심 영역을 같은 것으로 혼동하지 않습니다.
