사용 조건과 흐름

VariationMode는 정상 영상으로 학습한 픽셀별 기준의 통계 방법을 고릅니다. STANDARD와 ROBUST는 변동 모델의 기준과 편차를 구하는 서로 다른 방식이며 이후 검사에서 픽셀의 정상 범위를 정하는 데 사용됩니다. 기준 영상들은 같은 장면과 위치에 정렬되어 있어야 같은 픽셀 위치의 변동을 의미 있게 비교할 수 있습니다.

구체 사례와 결과 판독

예를 들어 정상 영상들이 같은 위치에서 밝기 100 부근을 보인다면 그 위치의 변동은 학습된 정상 분포에 따라 해석합니다. 한 장의 영상이 정렬되지 않아 다른 물체 위치가 겹치면 그 차이가 정상 변동으로 학습될 수 있습니다. 모델 방식과 검사 허용치를 따로 기록하고, 학습에 쓰지 않은 정상 영상과 알려진 결함 영상으로 결과를 확인하세요.

적용 시 확인

정상 학습 영상의 양과 내용이 결과에 영향을 줍니다. 한 종류의 조명이나 위치에서만 확인한 기준을 다른 촬영 조건에 그대로 적용하기 전에 검증하세요. ROBUST와 STANDARD는 옵션 이름이 아닌 학습 방식의 차이입니다. 선택을 바꾸어 학습한 두 모델은 같은 허용치라도 결과가 달라질 수 있으므로 독립된 검증 영상으로 각각 확인하세요. 정상 데이터의 정렬과 밝기 범위도 같은 조건으로 유지합니다.
