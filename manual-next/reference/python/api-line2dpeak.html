    사용과 결과 해석

    2차원 기울기 투영에서 추출된 피크 하나와 적합 단계 결과를 담습니다. position은 ROI 로컬 위치, gradient는 그 위치의 기울기 벡터이며 intensity는 보고된 강도입니다. projection_region은 피크를 만든 투영 스트립의 인덱스이므로 좌표나 픽셀 값과는 다른 식별 정보입니다.

    classification과 reason을 이용해 적합에 사용된 내점, 고려 후 배정되지 않은 후보, 고려되지 않은 후보를 구별합니다. line_index가 None이면 어떤 선에도 연결되지 않은 것이며 0번 선을 의미하지 않습니다. 예를 들어 극성 조건에서 제외된 피크는 적합에서 거절된 피크와 동일한 경로를 거치지 않습니다.

    이 값은 임계값 적용 이후 추출된 피크만 나타냅니다. 문턱 아래에서 제거된 에지가 보고서에 없다는 사실을 배경에 에지가 전혀 없다는 증거로 쓰지 마십시오. 입력 마스크와 마스크 오프셋은 추출에 영향을 주며, 원본 ROI의 위치를 전체 이미지나 월드 좌표로 해석하려면 별도 좌표 변환이 필요합니다.
