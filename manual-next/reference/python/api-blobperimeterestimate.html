    셀 둘레와 보정값

    BlobPerimeterEstimate는 전경 픽셀 수 area, 노출된 셀 경계 길이 cell_perimeter, 코너 보정에 쓰이는 corners, 보정 추정치 estimate를 담습니다. 네 수치는 같은 의미가 아닙니다. 특히 전경 픽셀 수는 면적이고 노출된 변의 합은 길이입니다.

    한 셀의 예

    전경 픽셀이 한 개이고 주변이 배경이면 셀의 네 변이 노출됩니다. 따라서 셀 경계 길이는 4픽셀 길이 단위이고 면적은 1픽셀입니다. 코너 보정을 적용한 estimate는 이 원래 셀 둘레와 별도의 값이므로 어느 측정치를 쓰는지 명시해야 합니다.

    결과 활용

    blob_perimeter_estimate에 전경 마스크를 전달해 결과를 얻고 원본 마스크의 픽셀 배치와 함께 읽습니다. 계단 형태의 디지털 경계를 보정하는 추정치는 연속 곡선의 실제 길이를 정확하게 보장하지 않습니다. 다른 장비나 해상도 간 비교에는 축 간격과 보정 조건이 필요합니다.

    판독 시 주의

    구멍이 있거나 작은 성분이 여러 개인 마스크에서는 노출 경계의 구성이 단순한 한 물체와 다를 수 있습니다. 필터링 전후에 결과가 달라졌다면 먼저 어떤 전경 픽셀이 포함되었는지 확인합니다.
