Python API · fixture_delta3

fixture_delta3 멤버와 선언

공개 타입

zvision.fixture_delta3: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.fixture_delta3.

Return observed-world <- nominal-world from same-frame 3D object poses.

동일 프레임의 기준·관측 물체 자세에서 observed-world←nominal-world 변환을 구합니다.

Python
fixture_delta3(nominal, observed)

인자 선언

  • nominal · POSITIONAL_OR_KEYWORD · 기본값 없음
  • observed · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

nominal
기준 물체 RigidTransform3
observed
관측 물체 RigidTransform3, 같은 단위 및 프레임

반환: 보정 RigidTransform3 값

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    fixture_delta3는 같은 기준 프레임에서 표현한 물체의 기준 자세와 관측 자세를 비교하여 기준 세계에서 관측 세계로 가는 3차원 강체 변환을 계산합니다. nominal과 observed는 동일한 물체와 프레임 정의를 사용해야 하며 이동값의 길이 단위도 일치해야 합니다. 결과는 단순한 위치 차이 세 숫자에 그치지 않고 회전도 포함합니다.

    구체 사례와 판독

    예를 들어 두 자세가 회전 없이 기준에서 X=10, 관측에서 X=12라면 대응 이동 차이는 X 방향 2입니다. 실제 자세에 회전이 포함되면 이동량만 빼는 것으로 전체 보정을 대신할 수 없습니다. 반환 변환을 기준 물체의 알려진 점에 적용해 관측 위치와 비교하고 적용 방향이 후속 보정 파이프라인과 맞는지 확인하세요.

    적용 시 확인

    예를 들어 물체의 기준 좌표점 (1,0,0)이 관측 자세에서 어떻게 이동하는지 변환 전후로 비교하면 위치뿐 아니라 회전 방향까지 확인할 수 있습니다. 두 자세의 출발 및 도착 프레임을 기록하고 해당 객체와 관계없는 변환을 섞지 마세요. 입력 단위가 mm이면 결과 이동도 같은 단위로 읽습니다. 기준 자세와 관측 자세가 같으면 결과는 항등 변환이어야 합니다. 이 간단한 사례는 입력 방향이 예상과 같은지 확인하는 출발점입니다.
