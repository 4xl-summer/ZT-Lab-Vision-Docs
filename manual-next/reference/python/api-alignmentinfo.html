    사용과 결과 해석

    기준 정렬이 발견되었는지와 발견된 변환의 품질 정보를 담는 값입니다. found가 참이면 matched의 위치·각도·배율과 reference_to_inspection을 읽을 수 있습니다. 이 변환은 기준 영상의 전역 픽셀 좌표를 검사 영상의 전역 좌표로 옮깁니다. ROI 로컬 좌표를 그대로 넣거나 이미 전역화된 위치에 원점을 다시 더하면 실제 위치와 어긋납니다.

    valid_count는 기준 격자에서 보간에 필요한 입력 표본이 확보된 픽셀 수입니다. 예제의 5×5 기준 전체가 유효하면 25입니다. residual_rms는 유효한 픽셀의 보정 전 밝기 차이를 요약한 값이며 이동 거리나 기하학적 위치 오차가 아닙니다. 조명 변화가 있는 정상 영상에서도 이 값이 달라질 수 있으므로 정렬 탐색의 발견 여부와 별개로 해석합니다.

    Python에서는 정렬을 찾지 못하면 matched와 변환이 None입니다. 결과의 aligned와 valid_mask를 요청하기 전에 found를 확인하고 미발견을 검사 불가 경로로 처리합니다. 정렬 결과와 획득한 두 영상은 각각 소유 자원이므로 사용 후 별도로 닫습니다. 유효 표본 수가 충분한지 정하는 조건은 AlignmentSpec의 최소 비율입니다.
