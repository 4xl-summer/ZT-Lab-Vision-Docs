    데이터 필드

    필드타입기본값의미와 조건
    levelsint필수양자화 단계 수로 2–256입니다.
    minimumfloat필수유한한 밝기 구간 하한이며 maximum보다 작아야 합니다.
    maximumfloat필수유한한 밝기 구간 상한이며 minimum보다 커야 하고 구간 폭도 유한해야 합니다.
    offset_xint필수두 픽셀 사이 수평 오프셋(정수 픽셀)입니다. 두 오프셋이 모두 0일 수 없습니다.
    offset_yint필수두 픽셀 사이 수직 오프셋(정수 픽셀)입니다. 두 오프셋이 모두 0일 수 없습니다.
    symmetricbool필수역방향 쌍을 함께 반영할지 정하는 bool입니다.
    max_pairsint필수처리할 쌍의 양의 상한입니다.

    사용 조건과 흐름

    GlcmOptions는 밝기 동시발생 행렬의 양자화와 픽셀 쌍 선택을 지정합니다. levels는 2부터 256까지이고 minimum과 maximum은 밝기 범위를 정합니다. offset_x, offset_y는 비교할 이웃의 상대 위치이며 symmetric은 방향을 대칭으로 취급할지 고르는 bool입니다. max_pairs는 계산할 쌍 수에 대한 작업 제한입니다.

    구체 사례와 결과 판독

    예를 들어 offset=(1,0)이면 가로 방향으로 한 픽셀 떨어진 쌍을 살핍니다. offset=(0,1)은 세로 방향이므로 줄무늬의 방향에 따라 행렬과 특징값이 달라질 수 있습니다. levels를 변경하면 양자화 구간도 바뀌므로 서로 다른 설정의 대비나 엔트로피를 수치만으로 직접 비교하지 말고 설정과 밝기 범위를 함께 기록하세요.

    적용 시 확인

    두 좌표 오프셋을 모두 0으로 두면 같은 위치를 비교하는 셈이므로 이웃 질감에 대한 의도와 맞지 않습니다. 마스크와 영상 범위 때문에 실제로 유효한 쌍이 줄어들 수 있으므로 결과의 쌍 수를 확인합니다. 작업 제한은 품질 점수가 아닙니다. 예를 들어 가로로 두 픽셀 떨어진 비교는 offset=(2,0)으로 지정합니다. 같은 영상이라도 간격이 커지면 관찰하는 무늬의 공간 규모가 달라집니다.
