    사용 맥락과 계약

    ModelRay는 카메라 모델에서 만들어진 광선의 원점과 단위 방향을 카메라 좌표계로 표현합니다. 두 값은 모두 3차원 벡터이지만 원점은 위치이고 direction은 길이가 1인 방향입니다. 픽셀 하나가 나타내는 것은 공간의 단일 점이 아니라 이 광선을 따라 가능한 점들의 집합입니다. 실제 대상 위치는 평면 등 다른 제약과 함께 결정합니다.

    구체 사례와 판독

    예를 들어 일반적인 원근 카메라의 광선은 카메라 원점에서 출발하지만 텔레센트릭 모델은 픽셀에 따라 원점이 달라지고 방향은 평행할 수 있습니다. 따라서 두 모델의 direction만 비교해 광선이 같은 위치를 지나간다고 결론 내리면 안 됩니다. 좌표 변환 시 원점에는 회전과 이동을 적용하고 방향에는 회전만 적용하는 차이도 중요합니다.

    적용 시 확인

    광선의 두 점을 구성하려면 원점 O와 방향 D에 대해 O+tD를 사용합니다. t가 0이면 원점이고 양수이면 방향을 따라 전진한 위치입니다. 예를 들어 O=(1,2,0), D=(0,0,1), t=3이면 위치는 (1,2,3)입니다. 방향이 단위 벡터이므로 같은 길이 단위에서 t는 이동 거리에 대응합니다. 카메라 모델이 원점을 어떻게 정하는지도 함께 확인하세요. 원점도 방향과 함께 보관하세요.
