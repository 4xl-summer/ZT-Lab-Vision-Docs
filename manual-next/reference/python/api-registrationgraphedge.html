    사용 맥락과 계약

    RegistrationGraphEdge는 여러 영상 정합 그래프에서 한 쌍의 기준 영상과 원본 영상 인덱스 및 쌍별 정합 옵션을 지정합니다. reference와 source의 방향은 변환 해석에 중요하며 options에는 AdvancedRegistrationOptions를 사용합니다. 숫자 인덱스가 영상 목록의 올바른 항목을 가리키는지 먼저 확인해야 합니다.

    구체 사례와 판독

    예를 들어 영상 목록 [A,B,C]에서 reference=0, source=1인 간선은 A와 B의 쌍을 나타냅니다. C까지 연결하려면 C가 포함된 다른 간선을 구성해야 합니다. 인덱스를 뒤집으면 같은 두 영상이라도 기준과 원본 역할이 달라집니다. 동일한 장면의 겹치는 영역이 충분한지와 입력 순서가 바뀌지 않았는지 함께 확인하세요.

    적용 시 확인

    그래프 전체에서 각 영상이 기준 영상으로 이어지는 경로가 필요한지도 확인합니다. 겹침이 거의 없는 쌍을 연결하면 추정이 불안정할 수 있습니다. 쌍별 설정은 해당 두 영상의 내용과 움직임에 맞게 정하고, 얻어진 변환의 방향을 알려진 대응점으로 검증하세요. 정합 실패나 잘못된 연결을 성공한 변환으로 대체하지 말고 오류와 간선의 두 인덱스를 함께 기록하세요.
