smooth_normals 멤버와 선언

공개 타입

zvision.smooth_normals: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.smooth_normals.

메시 인접 정점의 법선을 반복 평균하고 정규화합니다.

Python
smooth_normals(normals, faces, iterations)

인자 선언

  • normals · POSITIONAL_OR_KEYWORD · 기본값 없음
  • faces · POSITIONAL_OR_KEYWORD · 기본값 없음
  • iterations · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

normals
Point3 또는 None의 슬롯별 법선 시퀀스
faces
각각 서로 다른 0 이상 정점 인덱스 3개를 담은 삼각형 목록
iterations
양의 정수 반복 횟수

반환: 독립 Point3 또는 None 목록이며 결측은 유지됩니다.

오류: 반복 수, 면 인덱스 또는 법선이 무효이면 오류입니다.

iterations: 정수 검사 · 최소 1.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    smooth_normals는 삼각형 메시의 인접 관계를 따라 법선을 균일하게 평균하고 정규화하는 연산입니다. normals는 Point3 또는 None의 슬롯 목록이며 faces는 서로 다른 세 유효 인덱스로 이루어진 삼각형 목록입니다. iterations는 양의 정수입니다. 한 반복은 이전 단계의 법선들로 다음 단계를 계산하므로 입력 순서대로 즉시 갱신된 값을 연쇄 적용하는 방식이 아닙니다.

    중심 법선이 None이면 그 슬롯은 결측으로 유지됩니다. 반대 방향의 합이 정확히 상쇄돼 길이가 0이 되면 결과가 None이 될 수 있습니다. 예를 들어 서로 이웃한 반대 방향만 평균할 때는 방향 취소 가능성을 확인해야 합니다. 면 인덱스가 범위를 벗어나거나 같은 면 안에서 중복되거나 입력 법선이 무효이면 오류입니다. 반환은 독립 목록이며 평활 결과가 원래의 날카로운 경계를 보존한다고 보장하지 않습니다.
