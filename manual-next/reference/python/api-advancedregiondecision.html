    사용과 결과 해석

    judge_advanced가 각 영역 규칙에 대해 반환하는 불변 결과입니다. passed는 해당 규칙의 통과 여부이고 scratch_count와 surface_count는 두 후보 종류의 수입니다. violating_indices는 위반과 연결된 인덱스의 튜플이며 생성 시 정수만 포함하도록 확인합니다.

    예를 들어 첫 규칙과 둘째 규칙이 다른 영역을 대상으로 한다면 각각의 통과 여부와 후보 수를 규칙 순서에 연결해 읽습니다. 한 규칙의 passed가 참이라고 다른 영역도 통과했다고 가정하지 않습니다. 인덱스를 후보 위치로 표시할 때는 해당 실행의 후보와 좌표계를 유지합니다.

    함수는 내부 결과를 읽어 값들을 복사한 뒤 임시 핸들을 닫습니다. 반환된 튜플은 소유 영상이 아닙니다. 마스크와 점수 생성에 실패했거나 정렬을 찾지 못한 경우 판정 결과가 존재하지 않으므로 빈 인덱스를 성공과 동의어로 사용하지 않습니다.

    스크래치와 표면 구분은 후보 추출 설정에 영향을 받습니다. 면적 필터와 형상 기준을 바꾸면 같은 마스크에서도 각 종류의 개수가 달라질 수 있으므로 규칙과 후보 설정을 함께 저장합니다.

    결과를 기록할 때 규칙 사각형과 판정 이유에 연결합니다.
