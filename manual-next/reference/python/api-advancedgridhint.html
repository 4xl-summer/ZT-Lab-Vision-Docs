    사용과 결과 해석

    격자의 한 기준점과 두 축의 픽셀 변위를 명시해 부분 관측을 행·열 인덱스에 연결합니다. row와 column은 기준점의 격자 인덱스이고 position은 영상의 픽셀 위치입니다. column_step과 row_step은 한 열 또는 한 행을 이동할 때의 픽셀 변위이므로 위치 좌표와 같은 의미가 아닙니다. 예를 들어 기준 위치가 (100,200), 열 방향이 (10,0), 행 방향이 (0,8)이면 한 열 오른쪽의 예측 위치는 (110,200)입니다. 이 예는 축이 직교한 단순 아핀 격자이며 모든 촬영 조건을 대표하지 않습니다. 기준 인덱스는 지정된 행·열 범위 안에 있어야 하고 좌표와 벡터는 유한해야 합니다. 원근 효과가 큰 격자라면 별도의 투영 매핑 경로를 검토하십시오. 한 행 아래의 예상 위치는 기준 위치 (100,200)에 행 변위 (0,8)을 더한 (100,208)입니다. 한 행과 한 열을 함께 이동하면 (110,208)이 됩니다. 이 계산은 해당 단순 예제의 가정이며 격자 전체가 원근 투영된 상황에서는 하나의 고정된 변위로 정확히 표현되지 않을 수 있습니다. 기준점의 인덱스가 격자 범위에 맞지 않으면 예상 위치 전체의 기준도 잘못됩니다. 입력한 행과 열을 먼저 점검하십시오.
