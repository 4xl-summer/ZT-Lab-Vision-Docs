열거 값

  • ERROR = 0 · 0 제수를 오류로 처리합니다.
  • ZERO = 1 · 0 제수의 출력 성분을 0으로 둡니다.

사용과 결과 해석

이 열거형은 두 영상을 성분별로 나누는 연산에서 분모가 0인 위치를 어떻게 처리할지 선택합니다. 기본 정책은 ERROR이고, ZERO를 선택하면 해당 출력 성분을 0으로 처리합니다. 이 선택은 분모가 0인 경우의 처리 규칙이며 모든 입력 값을 0으로 바꾸거나 영상 전체를 마스킹하는 옵션이 아닙니다.

ERROR에서는 0인 분모가 발견되면 나눗셈 결과를 사용할 수 없도록 오류를 반환합니다. ZERO에서는 그 위치를 출력 0으로 정하고 gain과 bias를 그 성분에 적용하지 않습니다. 따라서 예를 들어 bias가 10이어도 분모가 0인 성분은 10이 아니라 0입니다. 분모가 0이 아닌 위치는 일반 나눗셈을 한 뒤 배율과 편향을 적용하고 지정한 출력 형식으로 변환합니다.

분모가 0이라는 사실이 측정 불가능 상태를 뜻하는지, 결과 0으로 대체해도 후속 검사에 문제가 없는지를 호출 전에 결정하십시오. ZERO를 쓰면 유효한 0과 대체된 0만으로는 원인을 구별하기 어려울 수 있습니다. 두 입력의 크기와 지원 형식, 출력 형식을 별도로 확인하고 반환된 영상은 독립 소유 객체로 해제합니다.
