사용과 결과 해석

영상의 소수 좌표에서 값을 구할 때 이 열거형은 최근접 또는 이중선형 방식을 구분합니다. 최근접 방식은 가까운 위치의 픽셀을 선택하고 이중선형 방식은 주변 픽셀 네 값의 위치별 가중 조합을 사용합니다. 예를 들어 두 이웃 값의 중간 지점에서는 이중선형 결과가 두 값 사이에 놓일 수 있지만, 최근접 결과는 선택된 한 픽셀의 값을 따릅니다. 이 차이는 회전, 워프 또는 고급 프로파일의 경계 위치에 영향을 줄 수 있으므로 비교하는 실험에서는 같은 보간 설정을 사용해야 합니다. 보간은 영상 밖 데이터를 만드는 권한을 자동으로 부여하지 않으며 호출별 경계 조건도 별도로 확인합니다. 결과가 흐리거나 피크가 달라졌다면 임계값뿐 아니라 입력 위치와 보간 방식을 먼저 비교하십시오. 소수 좌표 (1.5,2)에 위치한 표본은 이웃 픽셀을 어떻게 읽는지에 따라 달라질 수 있습니다. 선분과 이미지가 같아도 보간 정책이 바뀌면 단면과 기울기 피크가 달라지므로 에지 임계값을 비교할 때 이 설정을 함께 기록하십시오. 최근접은 선택한 위치 주변의 픽셀을 하나 고르고 이중선형은 주변 값을 조합합니다. 어느 방식이 현장에 적합한지는 같은 영상에서 검출 결과를 비교해 판단하십시오. 경계 부근의 유효 표본 조건도 별도로 확인합니다.
