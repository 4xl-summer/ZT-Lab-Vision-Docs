사용 조건과 흐름

ControlledEccFormat은 오류 정정 실행을 제어하는 디코드 호출에서 심볼 종류를 선택합니다. QR과 DATA_MATRIX는 서로 다른 바코드 형식이며 controlled_ecc_decode의 format 인자에 전달합니다. 입력이 카메라 영상인지 샘플된 격자인지는 별도의 ControlledEccInput으로 지정합니다. 형식 선택만으로 정정 실행을 켜거나 끄지는 않습니다.

구체 사례와 결과 판독

예를 들어 QR 모듈 격자를 읽으려면 format은 QR, 입력 종류는 MODULES로 지정합니다. Data Matrix 격자는 DATA_MATRIX를 선택해야 합니다. 정정 실행 여부와 블록별 허용 수정 수는 별도 인자로 정하고, 반환된 형식과 텍스트 및 accepted를 확인하세요. 형식을 잘못 지정한 실패를 정정 코드워드가 0개였던 정상 읽기로 해석해서는 안 됩니다.

적용 시 확인

QR과 Data Matrix는 같은 정수 식별자가 아니며 형식별 모듈 구조도 다릅니다. 결과의 형식과 실제 심볼을 대조하고 다른 입력 모드와 조합을 명시하세요. 각 심볼의 오류 정정 구조는 다를 수 있으므로 반환된 블록 정보를 해당 형식과 연결해 읽습니다. 형식만 같아도 입력 종류와 정정 설정은 각각 확인해야 합니다.
