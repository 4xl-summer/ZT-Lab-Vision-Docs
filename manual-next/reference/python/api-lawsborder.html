사용과 결과 해석

Laws 질감 필터가 영상 밖의 샘플을 만날 때 사용할 경계 규칙입니다. REPLICATE는 가장 가까운 경계 픽셀을 사용하고, REFLECT는 경계 픽셀을 반복하지 않는 반사 좌표를 사용합니다. CONSTANT는 지정한 상수 강도값을 사용합니다. 필터의 중심이 영상 안에 있어도 커널이 경계를 넘으면 이 규칙이 적용됩니다.

예를 들어 맨 왼쪽 픽셀을 처리할 때 커널 일부는 입력 영상 왼쪽 밖에 있습니다. 복제와 반사는 다른 원본 픽셀을 참조할 수 있고, 상수 경계는 별도 border_value를 사용합니다. 따라서 영상 중앙의 결과가 같아도 가장자리 응답은 달라질 수 있습니다.

상수값은 CONSTANT에만 적용하며 다른 경계 방식에서 0이 아닌 값을 지정하면 오류입니다. 기준 영상과 검사 영상을 비교할 때 필터 크기와 경계 방식을 일치시켜야 경계 효과를 실제 결함 변화로 오인하지 않습니다.
