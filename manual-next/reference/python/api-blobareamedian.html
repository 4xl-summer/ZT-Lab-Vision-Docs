    면적과 좌표 중앙값

    BlobAreaMedian은 비영 전경 픽셀 수 area와 x, y 좌표의 각각 낮은 중앙값을 담습니다. 중앙값은 각 축의 좌표를 정렬해 가운데를 찾는 통계이며 픽셀 좌표의 산술 평균인 무게중심과 일반적으로 다릅니다.

    짝수 개의 예

    한 축의 전경 픽셀 좌표가 정렬 후 0, 1, 4, 9라면 낮은 중앙값은 가운데 두 값 중 작은 1입니다. 두 값의 평균 2.5를 반환하는 정의가 아닙니다. x와 y를 각각 계산하므로 결과 좌표가 실제 전경 픽셀 위치와 반드시 일치한다고 가정하지 않습니다.

    입력과 좌표

    blob_area_median으로 얻은 x와 y는 영상 ROI 로컬 좌표입니다. 전경이 비영으로 선택된 마스크인지 확인하고 표시 대상이 전체 영상이라면 ROI 원점을 더합니다. area는 전경 픽셀 수이므로 외접 사각형의 면적이나 물리 면적과 구별합니다.

    해석

    중앙값은 멀리 떨어진 일부 픽셀이 산술 평균에 주는 영향을 다르게 반영할 수 있습니다. 그러나 서로 떨어진 여러 물체를 하나의 입력으로 넣으면 전체 전경을 대상으로 한 통계가 되므로 단일 물체의 중심처럼 해석하지 않습니다.

    짝수 개에서 낮은 값을 택하는 규칙을 기록해야 다른 통계 도구의 중앙값과 결과를 정확하게 비교할 수 있습니다. 픽셀의 분포도 함께 살펴보세요.
