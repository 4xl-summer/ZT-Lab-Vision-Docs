search_circle_instances 멤버와 선언

공개 타입

zvision.search_circle_instances: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_instances.search_circle_instances.

Fit each grid candidate, rank by inliers/RMS, and suppress duplicate fitted circles.

Candidate centers are a discrete grid; the model supplies radius and arc. At
most 64 grid points are evaluated; budget overflow fails without partial results.

유한 격자의 배치를 평가하고 피팅 결과 중복을 억제합니다.

Python
