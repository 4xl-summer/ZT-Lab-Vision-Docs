    사용 맥락과 계약

    RadialSelfOptions는 직선 윤곽에서 방사 왜곡 한 항과 중심을 국소 추정할 때 필요한 설정입니다. fx와 fy는 알고 있는 초점 스케일이고 initial_cx, initial_cy와 initial_k1은 중심과 계수의 시작값입니다. max_iterations, damping과 gradient_tolerance는 국소 최적화의 반복과 종료 조건을 정합니다.

    구체 사례와 판독

    예를 들어 영상 중심 부근의 주점 추정값을 initial_cx와 initial_cy에 넣고 여러 방향의 직선 윤곽을 제공합니다. 초기값은 최종 결과가 아니며 반환된 계수, 잔차와 종료 상태를 확인해야 합니다. 반복 수는 최대 25이고 잘못된 초점 스케일이나 영상 원점은 반복을 늘려도 자동으로 고쳐지지 않습니다.

    적용 시 확인

    하나의 방사 계수만 추정하는 모델은 실제 렌즈의 모든 왜곡을 설명하지 못할 수 있습니다. 화면 중심과 가장자리, 여러 방향에 분포한 선을 사용하고 보정에 쓰지 않은 윤곽으로 확인하세요. fx와 fy는 픽셀 좌표계와 맞아야 하며 영상 크기나 자르기가 바뀌면 초기 중심도 다시 검토해야 합니다. 중심 초기값은 영상의 픽셀 단위이며 k1은 모델의 방사 항 계수입니다. 수렴 실패와 보정 품질을 구분해서 기록하세요.
