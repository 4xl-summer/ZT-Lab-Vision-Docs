    사용 맥락과 결과 해석

    여러 형상 모델을 함께 검색할 때 한 모델과 이를 구별할 u64 id를 묶습니다. model은 열린 형상 AdvancedMatchModel이어야 하며 각 항목의 id는 한 컬렉션에서 고유해야 합니다. 이 입력은 모델이 감지된 위치나 점수 자체가 아닙니다.

    컬렉션 검색은 1..64개 항목과 공통 검색 옵션, 전체 포즈 예산 및 결과 상한을 받습니다. 반환 항목의 id를 원래 설정과 대조하면 어떤 모델이 해당 포즈를 냈는지 식별할 수 있습니다. 예를 들어 서로 다른 부품 두 모델에는 1과 2처럼 중복되지 않는 id를 부여합니다. 검색 호출 중 모델을 유효하게 유지하고 호출이 끝난 결과의 독립 수명을 확인하세요.

    ID는 한 번의 검색 입력에서 고유해야 합니다. 같은 ID를 서로 다른 모델에 주면 반환 결과의 출처를 구별할 수 없기 때문에 오류입니다. 공통 옵션은 각 항목의 모델에 적용되는 검색 공간과 평가 수를 정합니다. 검색이 끝난 뒤 원본 모델을 해제하더라도 이미 복사된 후보 값과는 수명이 다릅니다.

    값을 확인하는 순서

    id 항목: 모델 항목을 구별할 고유 u64 식별자입니다. model 항목: 검색할 형상 모델입니다.
