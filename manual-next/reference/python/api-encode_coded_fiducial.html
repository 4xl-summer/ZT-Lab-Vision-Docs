Python API · encode_coded_fiducial

encode_coded_fiducial 멤버와 선언

공개 타입

zvision.encode_coded_fiducial: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.encode_coded_fiducial.

Encode binary dark cells in a 9x9 ZVFD-1 marker; pitch is integer thousandths of unit.

9×9 ZVFD-1 마커 셀을 생성합니다.

Python
encode_coded_fiducial(id, row, column, pitch_x, pitch_y, unit)

인자 선언

  • id · POSITIONAL_OR_KEYWORD · 기본값 없음
  • row · POSITIONAL_OR_KEYWORD · 기본값 없음
  • column · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pitch_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pitch_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • unit · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

id
마커 식별자 1~65535
row
행 인덱스 0~511
column
열 인덱스 0~511
pitch_x
x 피치, 단위의 1/1000 정수. y와 모두 0이면 unit=None, 아니면 양수 및 단위 지정
pitch_y
y 피치, 단위의 1/1000 정수. x와 모두 0이거나 모두 양수여야 함
unit
길이 단위 또는 None; None은 두 피치가 0일 때만 허용

반환: 81개의 셀을 담은 bytes

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
