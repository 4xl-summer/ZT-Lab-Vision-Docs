Python API · correct_advanced

correct_advanced 멤버와 선언

공개 타입

zvision.correct_advanced: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._color_advanced.correct_advanced.

기준 영상의 색 분포에 맞춰 입력 색을 상대 보정합니다.

Python
correct_advanced(source, reference, method, *, variance_floor=1e-08, bins=256, strength=1.0)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • method · POSITIONAL_OR_KEYWORD · 기본값 없음
  • variance_floor · KEYWORD_ONLY · 기본값 1e-08
  • bins · KEYWORD_ONLY · 기본값 256
  • strength · KEYWORD_ONLY · 기본값 1.0

확인된 인자 조건

source
보정할 지원 색 영상.
reference
목표 색 분포를 제공할 지원 색 영상.
method
MEAN_VARIANCE 또는 HISTOGRAM 방식.
variance_floor
평균·분산 방식의 유한한 양의 분산 하한; 기본 1e-8.
bins
히스토그램 방식의 2–65536 단계; 기본 256.
strength
유한한 [0,1] 보정 강도; 기본 1.

반환: 독립 소유 영상이며 close합니다.

오류: 부적합한 영상·옵션 또는 비유한 값은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    source 영상의 색 분포를 reference를 기준으로 보정하고 새 ZImage를 반환합니다. method는 MEAN_VARIANCE 또는 HISTOGRAM이며 선택 인자는 variance_floor=1e-8, bins=256, strength=1.0입니다. 두 입력은 모두 ZImage여야 하며 bins는 바인딩에서 부호 없는 정수 범위인지 확인합니다.

    평균·분산 방식과 히스토그램 방식은 사용한 통계가 다르므로 한 옵션을 바꿨을 때의 차이를 같은 입력 쌍에서 비교합니다. strength나 bins를 조정했다면 실제 출력 색과 기준 분포가 의도한 방향으로 바뀌는지 확인하고 설정을 남깁니다. 밝기 보정은 기하 정렬의 대체물이 아닙니다.

    두 입력은 호출 중 잠금으로 보호되고 반환 영상은 독립 소유 객체입니다. 사용자는 출력과 입력을 각자의 소유 규칙에 따라 해제합니다. 호환되지 않는 입력이나 처리 실패를 원본이 그대로 나온 성공으로 취급하지 않습니다.

    출력 영상을 시각적으로 비교할 때 표시 범위 설정도 함께 고정해야 처리 차이와 화면 표시 차이를 구분할 수 있습니다. 보정된 값의 사용 목적에 맞는 별도 평가가 필요합니다.
