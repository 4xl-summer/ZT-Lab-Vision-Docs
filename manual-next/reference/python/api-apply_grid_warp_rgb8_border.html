apply_grid_warp_rgb8_border 멤버와 선언

공개 타입

zvision.apply_grid_warp_rgb8_border: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.apply_grid_warp_rgb8_border.

Apply a cached map to RGB8 with distinct RGB boundary bytes and a validity mask.

캐시된 격자 맵으로 RGB8을 변환하며 채널별 경계색을 사용합니다.

Python
apply_grid_warp_rgb8_border(grid_map, image, border, interpolation=1)

인자 선언

  • grid_map · POSITIONAL_OR_KEYWORD · 기본값 없음
  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • border · POSITIONAL_OR_KEYWORD · 기본값 없음
  • interpolation · POSITIONAL_OR_KEYWORD · 기본값 1

확인된 인자 조건

grid_map
열려 있는 GridWarp입니다.
image
RGB8 ZImage입니다.
border
RGB 순서의 세 바이트입니다.
interpolation
보간 방식이며 기본값은 1입니다.

반환: 각각 닫아야 하는 영상과 유효 마스크 쌍입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    apply_grid_warp_rgb8_border는 미리 만든 GridWarp를 RGB8 영상에 적용하며 경계에 사용할 R, G, B 바이트 세 개와 보간 방식을 지정합니다. 맵과 영상은 같은 SDK 라이브러리에 속해야 합니다. 반환된 보정 영상뿐 아니라 유효 마스크도 사용하여 원본에서 유효하게 샘플링된 위치를 구분합니다.

    구체 사례와 판독

    예를 들어 border에 빨강·초록·파랑 값 (255,0,0)에 해당하는 세 바이트를 주면 범위 밖 경계 표현을 색으로 구별하는 데 사용할 수 있습니다. 다만 원본에도 같은 빨강이 있을 수 있으므로 색상만으로 유효 여부를 결정하지 말고 마스크를 확인하세요. 보간 방식과 맵이 만들어진 좌표계도 영상과 일치해야 합니다.

    적용 시 확인

    맵이 가리키는 위치와 입력 영상의 크기 또는 ROI 원점이 달라지면 예상한 위치가 아닌 샘플을 읽을 수 있습니다. 지도의 생성 조건과 영상 설정을 함께 관리하고 알려진 색 패턴을 변환해 좌표와 채널 순서를 검증하세요. 결과의 유효 마스크를 차영상이나 결함 판정 단계에도 전달합니다. 경계색은 세 채널을 각각 지정하므로 회색 하나를 모든 채널에 자동 확장한다고 가정하지 마세요. RGB 순서의 세 바이트를 전달해야 합니다.
