    최근 경계 점의 쌍

    BlobRegionDistance는 두 영역의 최근접 경계 픽셀 중심 좌표 ax, ay와 bx, by 및 그 거리 distance를 담습니다. 좌표는 ROI 로컬이며 거리는 두 점 중심 사이의 유클리드 거리입니다. 영역의 중심점 간 거리나 픽셀 셀의 빈 공간 폭과 같은 뜻으로 사용하면 안 됩니다.

    거리 계산 예

    두 경계 중심이 (1,2)와 (4,6)이라면 x 차이는 3, y 차이는 4이고 거리는 √(3²+4²)=5픽셀입니다. 이 계산은 점 중심 사이의 거리입니다. 두 경계 셀의 실제 가장자리 사이 간격이 5픽셀이라는 뜻은 아닙니다.

    좌표와 사용

    동일 원점과 크기를 가진 두 마스크에서 blob_region_distance를 호출한 뒤 결과 좌표를 마스크 위에 표시하면 선택된 점 쌍을 확인할 수 있습니다. 전체 영상에 그릴 때는 ROI 원점을 적용합니다. 물리 길이가 필요하면 픽셀 간격과 보정을 별도로 적용해야 합니다.

    결과의 범위

    서로 다른 점 쌍이 같은 최소 거리를 가질 수 있으므로 반환된 점을 해당 영역의 영구적인 특징점으로 취급하지 않습니다. 마스크의 형태나 경계 픽셀이 한 칸 바뀌어도 최근접 점이 달라질 수 있습니다.
