열거 값

  • CONVERGED = 0 · 계산된 상하한 차이가 허용치에 도달했습니다.
  • BUDGET_EXHAUSTED = 1 · 예산이 소진되어 탐색이 끝났습니다.
  • RESOLUTION_LIMIT = 2 · 부동소수점 해상도 한계에서 멈췄습니다.

사용 맥락과 계약

AnnulusSearchStatus는 제한된 최소 원환 검색이 종료된 이유를 나타냅니다. CONVERGED는 지정한 간격 조건에 도달한 종료이며 BUDGET_EXHAUSTED는 허용된 계산 자원을 다 쓴 경우, RESOLUTION_LIMIT은 표현 가능한 분해능의 한계에 도달한 경우를 구분합니다. 세 상태 모두 동일한 최적성 보장을 뜻하지 않습니다.

구체 사례와 판독

예를 들어 계산 예산을 작게 정한 검색은 후보 원환을 얻었더라도 BUDGET_EXHAUSTED로 끝날 수 있습니다. 이때 반환된 폭 하나만 보고 허용 오차 내 최적해라고 주장하지 말고 lower_bound와 optimality_gap을 확인하세요. 더 많은 계산을 허용하거나 적절한 중심 영역을 지정한 재실험의 필요성은 해당 결과와 측정 목적에 따라 결정합니다.

적용 시 확인

RESOLUTION_LIMIT은 더 미세한 구분이 수치 표현의 한계에 부딪힌 경우를 나타냅니다. 이때 단순히 공차를 극단적으로 작게 정하는 것만으로 결과가 더 정확해진다고 가정하지 마세요. 상태와 최적성 간격, 좌표 단위 및 입력 스케일을 함께 검토합니다. 관측 데이터의 실제 오차도 따로 평가해야 합니다.
