  • model · POSITIONAL_OR_KEYWORD · 타입 <class 'bytes'> · 기본값 없음

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Load trusted RTen bytes using the declared fixed model spec.

run

method · 선언 타입 zvision._inference.AiEngine

Python
run(self, image: zvision.ZImage, region: tuple, options: zvision._inference.AiRunOptions = AiRunOptions(score_threshold=0.5, iou_threshold=0.5, max_detections=100))

입력 영역을 모델 크기로 최근접 샘플링해 추론합니다.

확인된 인자 조건

image
ZImage 입력입니다.
region
이미지 로컬 (x,y,width,height), 픽셀입니다.
options
AiRunOptions이며 기본값은 점수 0.5, IoU 0.5, 최대 100개입니다.

반환: 엔진 및 이미지와 독립된 소유 AiResult이며 close해야 합니다.

오류: 타입, 영역, 모델 설정 또는 추론 오류가 전달됩니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision.ZImage'> · 기본값 없음
  • region · POSITIONAL_OR_KEYWORD · 타입 tuple[int, int, int, int] · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 타입 <class 'zvision._inference.AiRunOptions'> · 기본값 AiRunOptions(score_threshold=0.5, iou_threshold=0.5, max_detections=100)

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

Run on a visible-image region stretched by nearest-neighbor sampling.
