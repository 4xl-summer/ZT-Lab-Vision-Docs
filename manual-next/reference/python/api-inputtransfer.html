InputTransfer 멤버와 선언

공개 타입

zvision.InputTransfer: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._naming_advanced_color.InputTransfer.

An sRGB, linear or gamma RGB transfer function.

입력 색 전달 함수를 나타내는 불변 값입니다. 공개 srgb(), linear(), gamma(exponent) 팩터리를 사용하면 방식과 인자를 명확히 지정할 수 있습니다.

Python
InputTransfer(_kind: zvision._color_advanced.AdvancedTransfer, _exponent: float = 0.0) -> None

인자 선언

  • _kind · POSITIONAL_OR_KEYWORD · 타입 <enum 'AdvancedTransfer'> · 기본값 없음
  • _exponent · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 0.0

반환 타입 주석: None

확인된 인자 조건

_kind
AdvancedTransfer 방식 열거값.
_exponent
GAMMA 방식의 지수; 기본 0.0이며 실제 색 변환에서 유효성을 검사합니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
