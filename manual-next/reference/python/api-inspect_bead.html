Python API · inspect_bead

inspect_bead 멤버와 선언

공개 타입

zvision.inspect_bead: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_models.inspect_bead.

로컬 경로의 법선 방향 에지쌍으로 비드를 검사합니다.

Python
inspect_bead(image, path, options, include=None)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • path · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • include · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

image
Gray8, Gray16 또는 GrayF32 검사 영상.
path
최소 2개부터 options.max_probes개까지의 유한한 로컬 (x,y) 탐침 좌표.
options
BeadOptions 폭·극성·대비·작업 한도.
include
선택적 path와 같은 길이의 bool 시퀀스; 하나 이상 참이어야 하며 None은 전체.

반환: 호출자가 close할 BeadResult 소유 객체.

오류: 잘못된 경로·형식·옵션 또는 작업 한도 위반은 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 조건과 흐름

    inspect_bead는 영상과 경로 점들, BeadOptions를 사용해 경로를 따라 비드의 양쪽 경계와 폭, 위치 오차 및 결함 구간을 조사합니다. path는 2개 이상이며 max_probes를 넘을 수 없습니다. include를 지정하면 경로 점마다 bool 하나씩 있어야 합니다. 결과는 소유 객체로 반환되며 프로브와 연속 구간 및 passed를 제공합니다.

    구체 사례와 결과 판독

    예를 들어 경로에 세 점을 넣고 include를 [True, False, True]로 지정하면 가운데 점은 검사 포함 여부에서 제외됩니다. 검사하지 않은 점을 정상 통과 점으로 간주해서는 안 됩니다. 밝은 비드와 어두운 비드에 맞는 polarity, 폭 허용 범위와 탐색 반경을 정한 뒤 개별 경계와 flags, 최종 판정을 함께 확인하세요.

    적용 시 확인

    경로의 좌표계가 영상 ROI와 일치하는지 확인하세요. 결과를 검토할 때 폭을 얻지 못한 프로브는 숫자 폭이 없는 상태일 수 있으므로 이전 프로브의 값을 대체해 넣지 않습니다. 길이와 전체 합격을 해석할 때 포함 여부와 결함 구간도 함께 확인합니다. include가 주어지지 않으면 입력 경로의 전체 프로브를 대상으로 하는 설정입니다. 반환된 결과를 사용한 뒤 소유 객체와 얻은 영상 자원을 각각 정리합니다.
