Python API · find_feature_instances

find_feature_instances 멤버와 선언

공개 타입

zvision.find_feature_instances: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._feature_instances.find_feature_instances.

Find repeated instances; options.mutual must be False and outliers are removed per accepted instance.

한 특징 모델의 여러 인스턴스를 독립 기하 변환으로 찾습니다.

Python
find_feature_instances(source, model, options, *, max_instances=2, total_hypotheses=4096, min_inliers=3, mask=None)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_instances · KEYWORD_ONLY · 기본값 2
  • total_hypotheses · KEYWORD_ONLY · 기본값 4096
  • min_inliers · KEYWORD_ONLY · 기본값 3
  • mask · KEYWORD_ONLY · 기본값 None

확인된 인자 조건

source
검색 ZImage입니다.
model
학습된 FeatureModel입니다.
options
FeatureSearchOptions 값입니다. FeatureSearchOptions(mutual=False)로 시작할 수 있으며 이 함수는 mutual=False를 요구합니다. ratio는 최근접 기술자 거리 비율, inlier_threshold는 픽셀 잔차이고 별도 total_hypotheses가 공유 가설 예산입니다.
max_instances
최대 인스턴스 수 1..64이며 기본값 2입니다.
total_hypotheses
공유 가설 상한 1..100000이며 기본값 4096입니다.
min_inliers
최소 내점 수 3..2048이며 기본값 3입니다.
mask
선택 마스크이며 기본값 None입니다.

반환: 독립 FeatureInstancesResult입니다.

오류: 서로 일치하지 않는 입력이나 유효하지 않은 예산·옵션은 오류입니다.

max_instances: 정수 검사 · 최소 1.

total_hypotheses: 정수 검사 · 최소 1.

min_inliers: 정수 검사 · 최소 3.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
