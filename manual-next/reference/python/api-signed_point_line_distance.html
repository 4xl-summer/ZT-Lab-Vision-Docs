Python API · signed_point_line_distance

signed_point_line_distance 멤버와 선언

공개 타입

zvision.signed_point_line_distance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.signed_point_line_distance.

Signed distance, positive on the left of the directed line in x/y coordinates.

유향 직선의 왼쪽을 양으로 하는 점 거리를 계산합니다.

Python
signed_point_line_distance(point, line)

인자 선언

  • point · POSITIONAL_OR_KEYWORD · 기본값 없음
  • line · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

point
유한한 Point2.
line
DirectedLine2; 유한한 원점과 0이 아닌 방향.

반환: 좌표 단위의 부호 있는 float.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    유향 직선에 대한 점의 수직 거리를 부호와 함께 계산합니다. point는 유한한 Point2이고 line은 유한한 원점과 0이 아닌 방향의 DirectedLine2입니다. 사용한 x/y 좌표에서 선의 왼쪽이 양수이며 반환 단위는 좌표의 단위와 같습니다. 예를 들어 원점에서 (1,0) 방향으로 가는 선에 점 (0,2)를 비교하면 부호 거리는 +2입니다. 선 방향을 반대로 바꾸면 같은 물리 점에 대한 부호도 반대가 됩니다. 일반적인 점·무향선 거리 함수는 절댓값을 반환하므로 좌우를 판정하려는 목적과 구분해야 합니다. 영상에서는 y가 아래로 증가할 수 있으므로 화면상의 위쪽을 항상 양수라고 가정하지 말고 실제 좌표와 방향을 확인하십시오. 0 방향이나 비유한 값은 오류입니다. 같은 선에 점 (0,-2)를 비교하면 예시 좌표에서 부호 거리는 −2입니다. 두 결과의 절댓값은 같지만 서로 반대편에 있습니다. ROI가 바뀌어도 점과 선을 같은 방식으로 옮기면 상대 거리가 유지되므로 두 입력의 원점을 먼저 일치시키십시오. 선 위의 점이라면 부호 거리는 0입니다. 위치가 없거나 선 방향이 유효하지 않은 오류와 이 정상 값을 구별하십시오. 거리의 단위는 입력 좌표 단위를 따릅니다.
