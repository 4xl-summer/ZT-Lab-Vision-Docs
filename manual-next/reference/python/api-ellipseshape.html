    사용 맥락과 결과 해석

    영상에서 측정할 예상 타원을 ROI 로컬 중심, 장반축, 단반축과 회전각으로 지정합니다. 길이는 픽셀이고 각도는 라디안입니다. start_angle과 end_angle은 타원 위에서 탐침을 놓을 매개변수 호를 정하므로 타원의 전체 회전각과 역할이 다릅니다. 이 값은 최종 적합 결과가 아니라 측정의 초기 형상입니다.

    EllipseMeasurementModel 또는 measure_ellipse_shape에 탐침 및 강건 적합 설정과 함께 전달합니다. 에지 탐침이 충분히 발견되지 않으면 유효한 적합이 없을 수 있으므로 반환 상태와 탐침 진단을 읽습니다. ROI를 바꾸면 중심도 해당 로컬 프레임에 맞춰야 합니다. 타원 적합의 잔차는 최근접 거리와 동일하지 않은 반경 방향 대용값이라는 점을 비교 기준에 반영하세요.

    값을 확인하는 순서
