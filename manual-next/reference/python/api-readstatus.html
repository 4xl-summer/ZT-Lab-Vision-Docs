열거 값

  • ACCEPTED = 1 · 값 1. 판독 결과가 해당 경로의 수용 조건을 통과한 상태입니다.
  • NO_READ = 2 · 값 2. 코드 또는 텍스트를 읽지 못한 상태입니다.
  • REJECTED = 3 · 값 3. 판독 또는 입력이 해당 경로의 수용 조건에 의해 거절된 상태입니다.

사용과 결과 해석

바코드 또는 OCR 읽기의 전체 상태를 나타내는 열거값입니다. ACCEPTED=1은 읽은 결과가 수락된 경우이고 NO_READ=2는 읽지 못한 경우이며 REJECTED=3은 결과가 거절된 경우를 구분합니다. ReadReason의 비트들은 상태에 대한 세부 이유이므로 상태 값 하나만으로 구체적인 거절 조건까지 결정하지 않습니다.

예를 들어 문자열이 발견되더라도 OCR의 허용 문자 또는 길이 조건을 만족하지 않으면 수락 여부를 함께 확인해야 합니다. 결과 텍스트만 출력하면 읽기 실패와 빈 내용, 조건 거절을 구분하기 어렵습니다. status와 reasons, 입력 조건 및 텍스트를 같은 실행 기록으로 묶습니다.

바코드 결과의 format, 원시 바이트와 점 좌표, OCR 결과의 문자별 모서리는 각각 다른 부가 정보입니다. 상태가 기대와 다를 때 해당 결과의 대비와 영역을 살펴보고 지정된 형식이나 문자 집합을 점검합니다. 이 열거값은 예외로 끝난 잘못된 호출을 성공적인 NO_READ로 변환하지 않습니다.

상태와 사유를 데이터베이스에 저장할 때는 원본 입력 또는 프레임 식별자도 함께 남기면 이후 촬영 조건을 재검토할 수 있습니다. 동일한 상태라도 사유 비트의 조합은 다를 수 있으므로 단일 숫자로 요약하지 않습니다.
