사용과 결과 해석

제어 가능한 광도 스테레오 실행이 협조적 취소 요청을 관찰했을 때 전달되는 예외입니다. 이 상태는 정상적인 PhotometricResult나 시간 초과와 다릅니다. 호출자는 취소를 명시적으로 처리하고 성공 결과가 있다고 가정하여 출력 영상을 읽지 않아야 합니다.

PhotometricCancellation은 취소를 요청하는 토큰이며, 토큰을 close하는 동작은 진행 중 작업을 취소하는 것과 다릅니다. 취소 요청과 작업 종료 사이에는 협조적 확인 시점이 있으므로 취소 버튼을 누른 즉시 계산이 완료되었다고 단정하지 마십시오. 시간 제한 초과는 별도의 TimeoutError로 구분됩니다.

취소된 실행에서 결과 소유권을 얻지 못했다면 출력 영상도 획득하지 않습니다. 이미 별도로 소유한 입력 영상과 토큰은 각각의 수명에 따라 정리해야 합니다. 실제 장비 중단 또는 안전 제어가 이 예외 처리만으로 완료되는 것은 아닙니다.
