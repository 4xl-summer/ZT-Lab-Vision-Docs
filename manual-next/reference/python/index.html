Python 공개 API 색인

Python 실제 선언에서 클래스·메서드·프로퍼티·필드·열거값을 찾습니다.

이 색인을 실제 코드에 연결하기

Python 객체와 공개 범위

이 색인에는 패키지의 선언된 공개 이름과 추가 SDK 속성, 실제로 반환되는 내부 타입이 함께 표시됩니다. __all__의 917개 이름과 추가 SDK 속성 4개는 동일한 범주가 아니며, 내부 반환 타입 1개도 별도로 구분합니다. 같은 객체가 여러 이름으로 다시 공개되면 서로 다른 알고리즘이 추가된 것으로 세지 않습니다. import할 이름과 반환 객체의 실제 타입을 함께 확인하면 코드 자동 완성에서 찾은 이름이 문서의 어느 계약에 해당하는지 추적할 수 있습니다.

함수 호출 전 파라미터 읽기

함수 페이지의 선언은 인자의 순서, 위치 또는 키워드 전달 여부, 필수값과 기본값을 읽는 기준입니다. 영상 좌표, 길이, 임계값처럼 숫자 형태가 같아도 의미가 다른 인자는 설명과 단위를 함께 보세요. dataclass 형식의 설정에서는 필드가 개별 선택값이면서 동시에 하나의 알고리즘 조건을 이룹니다. 기본값이 있다는 이유로 실제 영상에 적합하다고 가정하지 말고 작은 합성 입력으로 경계값을 확인한 뒤 필요한 필드만 명시적으로 변경하는 편이 재현에 유리합니다.

소유 결과와 값 결과 구분

네이티브 자원을 소유한 결과는 해당 페이지에서 정한 close 또는 컨텍스트 관리자 사용법을 따릅니다. 반면 값 스냅샷은 이미 복사된 데이터일 수 있으므로 모든 결과에 같은 해제 규칙을 적용하면 안 됩니다. Query는 실행 계획이고 execute 결과는 실제 실행의 출력입니다. 체인을 만드는 단계에서 영상을 얻었다고 생각하지 말고 실행 결과의 타입을 확인하세요. 분기할 계획은 clone으로 독립시킨 뒤 각각 닫는 구조와 결과를 닫는 구조를 별도로 작성해야 합니다.

예제를 확장할 때 확인할 값

첫 단계에서는 예제의 픽셀 배열과 기대값을 유지한 채 실행해 설치와 라이브러리 로딩을 확인합니다. 다음 단계에서는 한 번에 하나의 설정만 바꾸고 출력의 크기, 포맷, 결과 개수와 수치를 기록합니다. 실제 파일 입력을 추가했다면 알고리즘 호출 전에 영상의 정보부터 확인하세요. 모델 또는 외부 데이터가 필요한 사례는 파일을 바꾸는 것만으로 같은 품질이 보장되지 않으므로 예제에서 확인한 계약과 새 데이터의 정확도 평가는 구분해서 관리합니다.

확인 범위와 사용 방법

이 색인은 고정 SDK에서 확인한 선언으로 연결합니다. 타입별 페이지에서 파라미터와 필드, 상속 멤버, 반환과 오류를 확인하세요. 주석과 실제 구현으로 확인하지 못한 계약은 미확인으로 구분하며, 선언 수를 독립 기능 수나 실행 성공률로 세지 않습니다.
