mode: 기준 영상에 맞추는 정규화 방식을 선택합니다.

tile_width: 로컬 평균·표준편차 방식에서 타일 너비이며 픽셀 단위의 양수입니다. 다른 방식에서는 0입니다.

tile_height: 로컬 평균·표준편차 방식에서 타일 높이이며 픽셀 단위의 양수입니다. 다른 방식에서는 0입니다.

max_work: 처리 작업량 한도이며 1 이상의 정수입니다.

tail_low: 꼬리 매칭의 낮은 쪽 비율로 0 이상이며 tail_high와 합이 1 미만입니다. 다른 방식에서는 0입니다.

tail_high: 꼬리 매칭의 높은 쪽 비율로 0 이상이며 tail_low와 합이 1 미만입니다. 다른 방식에서는 0입니다.
