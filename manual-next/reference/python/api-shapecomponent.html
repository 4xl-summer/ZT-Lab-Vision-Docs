    사용 맥락과 결과 해석

    루트 형상에 상대적인 한 컴포넌트 모델과 기하 제약을 지정합니다. id는 고유 식별자, model은 형상 모델이며 relative_position과 relative_angle은 루트 기준의 위치와 각도입니다. position_tolerance는 픽셀, angle_tolerance는 라디안 단위로 허용 오차를 정합니다.

    컴포넌트 검색은 루트가 첫 항목인 2..16개의 필수 구성요소를 받습니다. 예를 들어 두 번째 부품이 루트에서 오른쪽으로 일정 거리 떨어져야 한다면 그 오프셋과 허용 오차를 입력합니다. 각 모델이 높은 점수를 내는 것뿐 아니라 이 상대 관계도 만족해야 객체가 성립합니다. 공유 평가 예산이 소진되면 미완료 결과일 수 있으므로 상위 보고서를 함께 읽습니다.

    값을 확인하는 순서

    id 항목: 컴포넌트를 구분하는 고유한 u64 식별자입니다. model 항목: 컴포넌트의 형상 모델입니다. relative_position 항목: 루트 기준 로컬 상대 위치(픽셀)입니다. relative_angle 항목: 루트에 대한 상대 회전각(라디안)입니다. position_tolerance 항목: 예상 위치로부터 허용하는 거리(픽셀)입니다. angle_tolerance 항목: 예상 각도에 대한 허용 오차(라디안)입니다.
