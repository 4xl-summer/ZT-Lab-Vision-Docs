열거 값

  • PASS = 0 · 적합과 커버리지 조건을 통과했습니다.
  • COVERAGE_REJECTED = 1 · 적합되었으나 요구 커버리지를 충족하지 못했습니다.
  • MEASUREMENT_FAILED = 2 · 기초 측정 피팅 실패 또는 점 부족 상태.

사용과 결과 해석

이 상태는 고급 측정 모델의 적합 결과에 적용된 커버리지 판정을 표현합니다. PASS는 측정 및 적용된 조건이 통과된 경우이고 COVERAGE_REJECTED는 적합값이 있더라도 요구 커버리지를 만족하지 못한 경우입니다. MEASUREMENT_FAILED는 측정 자체가 유효한 적합을 만들지 못한 상태입니다. 적합 수치가 있는지와 최종 판정이 통과인지 같은 질문으로 취급하지 마십시오.

예를 들어 직선의 일부만 검출되어 수학적 선은 계산되더라도 지정한 기준 길이에 대한 관측 비율이 부족하면 커버리지 거절로 보고될 수 있습니다. 반대로 측정 실패는 임계 커버리지보다 낮다는 사실만을 뜻하지 않습니다. 결과에서 fit_status와 coverage_fraction, 탐침 관찰을 함께 확인하면 실패 지점을 더 구체적으로 이해할 수 있습니다.

이 열거값은 판정 스냅샷의 상태이며 실제 영상 좌표나 물리적 오차를 직접 담지 않습니다. 경계 조건과 최소 비율은 설정한 CoveragePolicy에서 확인하고, 결과만으로 제품의 실제 합격을 단정하지 말고 사용자 검사 기준에 연결하십시오.
