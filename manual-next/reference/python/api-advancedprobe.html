시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

    사용과 결과 해석

    고급 선 또는 원 측정의 탐침 하나에 대한 관찰과 잘림 여부를 묶은 독립 값입니다. observation은 해당 탐침의 인덱스와 기준 위치, 에지 발견 상태 및 사용 여부 등 MeasurementProbe 정보를 담고, clipped는 명목상 탐색 스트립이 입력 영역 경계에 걸렸는지 표시합니다.

    잘림은 검사 영역과 탐침 기하의 관계를 설명하며 그 자체로 모든 경우의 적합 실패를 뜻하지 않습니다. 먼저 observation에서 에지가 발견되었는지, 발견한 점이 적합에 사용되었는지 살펴보고 clipped를 함께 보면 검출 누락이 경계와 관련되는지 조사할 수 있습니다. 예를 들어 탐침 위치가 영상 외곽에 가까우면 같은 길이의 스트립이 내부 탐침보다 잘릴 가능성이 있습니다.

    관측값은 결과를 읽어 복사한 스냅샷으로 원본 영상의 이후 수명에 의존하지 않습니다. 다만 에지 거리나 잔차가 없는 상태는 0이라는 측정값과 다르므로 None 여부를 확인해야 합니다. 탐침 하나의 상태만으로 전체 측정 모델의 최종 수락을 판단하지 말고 결과의 모델 상태와 커버리지를 함께 보십시오.
