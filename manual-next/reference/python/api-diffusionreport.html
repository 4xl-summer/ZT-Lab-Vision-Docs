공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    iterationsint필수실제로 수행한 반복 횟수입니다.
    max_changefloat필수마지막 반복에서의 최대 변화량입니다.
    convergedbool필수수렴 조건에 도달했는지 나타냅니다.

    반복 실행 보고

    DiffusionReport는 확산 연산의 실제 iterations, 마지막 반복의 최대 변화량 max_change, 정지 조건 충족 여부 converged를 담습니다. 이 값은 처리 영상과 함께 반복이 어떻게 끝났는지를 설명합니다. iterations는 설정한 최대치와 같을 수도, 정지 조건이 먼저 만족되어 그보다 작을 수도 있습니다.

    변화량의 의미

    예를 들어 마지막 단계에서 가장 크게 바뀐 픽셀 값의 차이가 0.01이라면 max_change는 그 마지막 갱신 규모를 나타냅니다. 이 숫자는 원본 대비 전체 누적 변화량이나 영상의 결함 검출 오류율을 뜻하지 않습니다. 입력 값의 스케일이 다르면 같은 수치도 다른 정도의 변화로 해석해야 합니다.

    수렴의 해석

    converged는 해당 연산에 지정된 정지 조건을 만족했는지 보여줍니다. 참이라고 해서 결과가 사용 목적에 맞는 최적 영상이거나 검사 정확도가 검증되었다는 뜻은 아닙니다. 설정한 반복 한도와 정지 조건을 보고서와 함께 기록하고 원본과 결과에서 잡음과 경계 보존을 따로 확인합니다.

    최대 변화량이 작다는 사실과 반복 횟수가 많다는 사실은 다른 관찰입니다. 두 수치를 함께 보면 조건에 도달해 멈췄는지, 제한 횟수에 가까운 처리가 이루어졌는지 조사할 실마리를 얻을 수 있습니다.
