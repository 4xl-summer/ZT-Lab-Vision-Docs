    사용과 결과 해석

    에지 체인의 식별자와 선택 기능 메타데이터를 분리해 보관하는 값입니다. label은 제외와 재포함에도 유지되는 양의 레이블이고 available은 실제로 계산된 선택 기능의 비트 마스크입니다. 목록 인덱스는 포함된 항목에 따라 달라질 수 있으므로 장기 식별에는 레이블을 사용하고 호출 시 인덱스 선택과 레이블 선택을 구별하십시오.

    size는 점 개수, closed는 닫힌 체인 여부, first는 첫 점이며 minimum과 maximum은 좌표 경계입니다. 이 필드들은 항상 사용 가능한 것으로 가정하지 말고 해당 기능 비트가 available에 있는지 확인해야 합니다. 예를 들어 bounds 기능을 요청하지 않은 결과의 좌표를 실제 측정 범위로 해석하면 안 됩니다.

    Point2 값과 불리언은 조회 결과로 복사되어 원본 Query의 이후 포함 상태 변경과 독립적입니다. 경계는 원본 에지 좌표계에서 해석하며 물리 단위로 환산된 결과가 아닙니다. 기울기 크기나 각도처럼 별도 계산이 필요한 기능은 해당 기능 요청과 계산 경로를 이용하고, 메타데이터만으로 계산되었다고 추론하지 마십시오.
