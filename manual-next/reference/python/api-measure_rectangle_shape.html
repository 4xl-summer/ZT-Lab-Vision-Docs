Python API · measure_rectangle_shape

measure_rectangle_shape 멤버와 선언

공개 타입

zvision.measure_rectangle_shape: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_measurement.measure_rectangle_shape.

Fit an orthogonal rectangle using probes with known initial side associations.

예상 사각형에 탐침을 배치하여 에지를 찾고 형상을 적합합니다.

Python
measure_rectangle_shape(image, shape, probes=ShapeProbeOptions(count=16, search_length=12.0, width=3, samples=13, direction=0, selection=2, min_found=5, min_valid_width=3, interpolation=1, derivative_filter=0, derivative_radius=1, polarity=3, threshold=10.0, prominence=0.0, max_edges=4, filter=(1.0,)), options=RobustFitOptions(loss=1, scale=0.5, initial_threshold=2.0, inlier_threshold=1.0, max_iterations=30, tolerance=1e-08, damping=0.001))

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • shape · POSITIONAL_OR_KEYWORD · 기본값 없음
  • probes · POSITIONAL_OR_KEYWORD · 기본값 ShapeProbeOptions(count=16, search_length=12.0, width=3, samples=13, direction=0, selection=2, min_found=5, min_valid_width=3, interpolation=1, derivative_filter=0, derivative_radius=1, polarity=3, threshold=10.0, prominence=0.0, max_edges=4, filter=(1.0,))
  • options · POSITIONAL_OR_KEYWORD · 기본값 RobustFitOptions(loss=1, scale=0.5, initial_threshold=2.0, inlier_threshold=1.0, max_iterations=30, tolerance=1e-08, damping=0.001)

확인된 인자 조건

image
측정할 ZImage입니다.
shape
예상 사각형 형상 값입니다.
probes
ShapeProbeOptions 탐침 설정입니다.
options
RobustFitOptions 값입니다. RobustFitOptions()의 기본 손실은 Huber이며 scale, initial_threshold, inlier_threshold는 입력 좌표 단위, tolerance는 정규화 좌표의 수렴 기준입니다. max_iterations는 1..1000입니다. 사각형 탐침은 각 면에 연결됩니다.

반환: 상태·탐침·적합 진단을 담은 독립 ShapeResult입니다.

오류: 유효하지 않은 이미지·형상·설정은 오류입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
