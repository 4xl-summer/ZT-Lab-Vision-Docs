사용과 결과 해석

xyz_to_lab가 생성하는 Lab 세 채널의 소유 결과입니다. channel(0), channel(1), channel(2)로 각 평면을 획득하며 0에서 2 이외 인덱스는 ValueError입니다. 직접 생성하는 대신 X, Y, Z 영상과 기준 백색점으로 변환해 얻습니다.

입력 XYZ 세 평면은 같은 관측자에 대한 GrayF64 영상이며 white는 세 XYZ 값의 튜플입니다. 백색점은 Lab의 기준이므로 서로 다른 관측 조건의 XYZ나 백색점을 섞으면 출력의 비교 의미가 달라집니다. 사용한 white와 원본 영상의 조건을 함께 보관합니다.

결과 객체와 각 channel이 반환하는 ZImage는 별도의 소유 자원입니다. 각각 사용 후 닫고, 이미 얻은 채널을 결과 객체와 같은 핸들로 여기지 않습니다. Lab 채널은 각각 L, a, b의 의미를 가지며 원본 XYZ 수치나 RGB 색상과 직접 같은 값이 아닙니다.

세 입력 평면의 좌표와 크기가 서로 대응해야 같은 픽셀의 X, Y, Z를 하나의 색으로 해석할 수 있습니다. 평면을 다른 ROI에서 가져온 경우 먼저 기하 관계를 확인합니다.

획득한 채널이 필요한 동안 해당 채널의 핸들을 유지합니다.
