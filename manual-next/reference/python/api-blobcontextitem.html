BlobContextItem 멤버와 선언

공개 타입

zvision.BlobContextItem: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_context.BlobContextItem.

Current result's label and binary pixel area.

Python
BlobContextItem(label: int, area: int) -> None

인자 선언

  • label · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • area · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

BlobContextItem(<class 'int'>, <class 'int'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    labelint필수선택한 영역의 라벨입니다.
    areaint필수선택한 영역의 전경 픽셀 수입니다.

    현재 결과의 한 성분

    BlobContextItem은 재사용 가능한 Blob 분석 컨텍스트의 현재 결과에서 선택한 성분의 label과 이진 전경 픽셀 면적 area를 나타냅니다. 레이블은 결과 내 성분을 식별하고 면적은 그 성분에 속하는 전경 픽셀 수입니다. 두 숫자는 서로 다른 의미입니다.

    면적 예

    한 성분에 전경 픽셀이 8개 있으면 area는 8입니다. 그 픽셀들이 차지하는 외접 사각형이 3×3이면 상자 넓이는 9이므로 면적과 다릅니다. 중앙에 배경 한 픽셀이 있는 고리가 이런 차이를 보여줄 수 있습니다.

    현재 상태 확인

    컨텍스트의 계산 결과를 읽기 전에 현재 결과가 있는지와 설정 변경 여부를 확인합니다. 새로운 계산이나 기하 설정 변경이 있으면 이전 항목이 새로운 현재 결과와 같은 의미를 갖는다고 가정하지 않습니다.

    레이블의 범위

    label은 현재 분석 결과에서 성분을 가리키는 값입니다. 다른 프레임이나 다른 컨텍스트에서 같은 숫자가 같은 물체를 의미하는 것은 아니므로 위치와 면적 등 별도 정보로 대응 관계를 판단합니다.
