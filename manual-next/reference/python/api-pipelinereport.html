PipelineReport 멤버와 선언

공개 타입

zvision.PipelineReport: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._preprocess_pipeline_gap.PipelineReport.

Counts of applied and skipped stages.

Python
PipelineReport(executed: int, skipped: int) -> None

인자 선언

  • executed · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • skipped · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

PipelineReport(<class 'int'>, <class 'int'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    executedint필수실행된 단계의 수입니다.
    skippedint필수비활성으로 건너뛴 단계의 수입니다.

    사용 맥락과 계약

    PipelineReport는 전처리 파이프라인에서 적용한 단계 수 executed와 건너뛴 단계 수 skipped를 기록합니다. 실행된 개수만으로 영상이 특정 품질에 도달했다거나 검사가 합격했다는 결론을 내릴 수 없습니다. 단계 목록과 enabled 설정을 함께 보관해야 어떤 처리가 결과에 반영되었는지 해석할 수 있습니다.

    구체 사례와 판독

    예를 들어 세 단계를 등록하고 가운데 단계만 비활성화했다면 적용 2개와 건너뜀 1개를 기대할 수 있습니다. 비활성화 단계는 처리 결과에 적용되지 않으므로 같은 세 단계가 모두 실행된 영상과 결과가 다를 수 있습니다. 숫자가 기대와 다르면 입력 목록의 enabled 값을 확인하고, 순서가 올바른지도 별도로 점검하세요.

    적용 시 확인

    보고는 단계 실행 수의 요약입니다. 동일한 executed 값이더라도 서로 다른 두 단계가 활성화되었다면 영상의 내용은 다를 수 있습니다. 입력 영상과 활성 단계 목록, 각 파라미터를 남기고 필요한 경우 각 단계의 결과를 별도 실험으로 확인하세요. 보고 자체는 영상 핸들이 아닙니다. 예를 들어 양자화와 평활 중 어느 것이 비활성화되었는지는 숫자 두 개만으로 구별할 수 없습니다. 원래 단계 목록을 함께 확인합니다.
