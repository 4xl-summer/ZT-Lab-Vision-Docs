채널별 불변 빈

HistogramResult는 채널별 히스토그램 빈을 항상 2차원 불변 튜플 channels로 보관합니다. 바깥 축은 채널, 안쪽 축은 해당 채널의 빈입니다. 단일 채널이어도 하나의 긴 배열로 자동 간주하지 말고 채널 축을 먼저 선택해야 합니다.

빈의 의미

히스토그램은 값의 분포를 요약합니다. 예를 들어 두 빈의 개수가 각각 3과 5이면 해당 두 구간에 속한 표본이 각각 3개와 5개라는 뜻입니다. 이 합과 전체 입력 픽셀 수가 같은지 여부는 측정 범위와 선택된 영역 조건을 함께 확인해야 합니다.

범위와 비교

HistogramSpec의 빈 수와 포함 하한·상한을 같이 기록합니다. 빈 개수가 같아도 값의 범위가 다르면 같은 인덱스가 같은 밝기 구간을 뜻하지 않습니다. 채널의 순서와 원본 픽셀 형식도 다른 결과와 비교할 때 필요합니다.

사용 범위

분포를 통해 밝기 편향이나 포화 양상을 살필 수 있지만 각 픽셀의 공간 위치는 히스토그램에 들어 있지 않습니다. 같은 분포라도 서로 다른 패턴의 영상이 가능하므로 위치가 중요한 검사는 원본 영상과 함께 수행합니다.
