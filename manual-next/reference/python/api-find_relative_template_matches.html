Python API · find_relative_template_matches

find_relative_template_matches 멤버와 선언

공개 타입

zvision.find_relative_template_matches: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._matching_relative.find_relative_template_matches.

Search source-local x/y offsets, angle offsets in radians and scale factors relative to a prior; general affine shear is unsupported.

기준 포즈에 대한 위치·각도 오프셋과 배율 비율 격자를 검색합니다.

Python
find_relative_template_matches(source, model, options, prior, mask=None)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • model · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • prior · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

source
검색할 ZImage입니다.
model
NCC AdvancedMatchModel입니다.
options
AdvancedMatchOptions 값입니다. x·y는 prior에 대한 검색 로컬 픽셀 오프셋, angle은 라디안 오프셋, scale_x·scale_y는 양의 배율 비율 격자입니다. 각 축에 SearchAxis를 지정하고 candidate_budget으로 평가 수를 제한합니다. coarse=False, min_gradient=0, max_occlusion_fraction=0이어야 합니다.
prior
검색 기준 또는 우선 순위에 사용할 AdvancedPosePrior입니다.
mask
선택적 검색 마스크 ZImage이며 기본값 None입니다.

반환: 독립 결과와 종료 진단입니다.

오류: 유효하지 않은 입력, 모델 또는 지원하지 않는 설정은 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
