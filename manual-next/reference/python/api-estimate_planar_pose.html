estimate_planar_pose 멤버와 선언

공개 타입

zvision.estimate_planar_pose: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.estimate_planar_pose.

Initialize a planar target pose from converged Brown-undistorted rays.

왜곡 보정 광선으로 평면 타깃 자세를 초기화합니다.

Python
estimate_planar_pose(target, pixels, lens, ray_options, unit, target_frame, camera_frame)

target

LensModel

반환: 자세와 픽셀 RMS를 담은 PlanarPoseEstimate

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
