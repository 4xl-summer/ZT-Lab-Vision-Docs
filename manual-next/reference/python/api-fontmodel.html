read

method · 선언 타입 zvision._recognition_advanced.FontModel

Python
read(self, image, options, angles_degrees=(0.0,), positions=None, *, angle_range=None)

지정 회전각에서 템플릿 글자 인식을 수행하고 선택 결과를 복사합니다.

확인된 인자 조건

image
입력 ZImage입니다.
options
FontOptions 설정입니다.
angles_degrees
시계 방향 회전각(도)의 순서열이며 기본값은 (0.0,)입니다.
positions
선택적 FontPosition 순서열입니다.
angle_range
지정 시 angles_degrees 대신 (최소,최대,간격) 각도 탐색을 사용합니다.

반환: 독립 FontRead 스냅샷 또는 판독 후보가 없으면 None입니다.

오류: 잘못된 입력·각도·설정 또는 네이티브 판독 오류가 전달됩니다.

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • angles_degrees · POSITIONAL_OR_KEYWORD · 기본값 (0.0,)
  • positions · POSITIONAL_OR_KEYWORD · 기본값 None
  • angle_range · KEYWORD_ONLY · 기본값 None

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

Use explicit angles or an inclusive (minimum, maximum, step) range.

train

classmethod · 선언 타입 zvision._recognition_advanced.FontModel

Python
train(cls, samples, options, algorithm=<FontTrainingAlgorithm.NEAREST_EXAMPLE: 1>)

레이블이 있는 합성 또는 사용자 제공 글자 셀로 템플릿 모델을 학습합니다.

확인된 인자 조건

samples
FontSample 순서열; 각 셀은 Gray8 영상의 유효한 로컬 픽셀 사각형과 Unicode 문자 하나를 포함합니다.
options
FontOptions 설정입니다.
algorithm
FontTrainingAlgorithm이며 기본값은 NEAREST_EXAMPLE입니다.

반환: 소유 FontModel이며 별도 close해야 합니다.

오류: 잘못된 샘플, 설정 또는 네이티브 학습 오류가 전달됩니다.

인자 선언

  • samples · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • algorithm · POSITIONAL_OR_KEYWORD · 기본값 <FontTrainingAlgorithm.NEAREST_EXAMPLE: 1>

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

이 멤버의 추가 계약은 공개 설명에서 확인되지 않았습니다.
