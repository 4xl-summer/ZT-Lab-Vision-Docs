사용과 결과 해석

AdvancedDifference는 advanced_difference가 반환하는 소유 결과입니다. 입력 source와 reference 및 AdvancedDifferenceSpec을 전달하고 선택적으로 threshold_map, dark_frame, flat_frame을 함께 사용할 수 있습니다. 결과 객체를 직접 생성하는 대신 연산을 호출하여 얻으며, 사용을 마치면 close합니다.

image(0)은 score 영상, image(1)은 mask 영상, image(2)는 signed difference 영상입니다. 각 호출에서 얻은 ZImage도 독립 소유 자원이므로 결과 객체와 별도로 닫습니다. 0, 1, 2 외의 인덱스는 ValueError이며, 점수의 크기와 마스크의 이진 선택 및 부호 있는 차이를 같은 수치로 읽지 않습니다.

info는 gain, bias, inspected_count 튜플을 제공합니다. gain과 bias는 계산에 사용된 보정 계수이고 inspected_count는 검사에 포함된 픽셀 수입니다. 이 객체는 PhotometricCancellation 토큰이 아니며, 이름에 photometric이 포함된 별도의 광도 스테레오 계산과 수명 또는 취소 계약을 공유한다고 추론하지 않습니다.
