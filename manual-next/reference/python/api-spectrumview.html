  • IMAGINARY = 5 · 스펙트럼 허수부입니다.

복소 스펙트럼을 보는 방식

스펙트럼은 각 주파수 위치에서 실수부와 허수부를 가진 복소값으로 나타낼 수 있습니다. REAL과 IMAGINARY는 각 성분을 보고, AMPLITUDE는 크기, PHASE는 위상, POWER는 크기의 제곱을 나타냅니다. 하나의 보기 결과만으로 원래 복소값의 모든 정보를 보존한다고 가정해서는 안 됩니다.

숫자 예

복소값이 3+4i이면 실수부는 3, 허수부는 4, 진폭은 √(3²+4²)=5, 전력은 25입니다. LOG_AMPLITUDE는 ln(1+진폭)이므로 이 예에서는 ln 6입니다. 로그 표시는 큰 값과 작은 값을 함께 보기 쉽게 바꾸지만 표시값을 그대로 원래 진폭으로 취급할 수는 없습니다.

표시와 계산 구분

위상과 진폭은 서로 다른 정보를 담습니다. 주파수 결과를 가시화할 때 보기 모드와 변환의 정규화, 표시 범위를 기록하고, 역변환이나 복소 연산에는 필요한 복소 데이터를 유지합니다. 시각적으로 밝은 점의 위치만으로 입력의 정확한 공간 파형을 복원할 수는 없습니다.

복소값 3+4i의 진폭 5와 전력 25는 서로 다른 보기의 숫자입니다. 같은 주파수 위치라도 어떤 모드를 사용했는지 기록하지 않으면 밝기 값의 차이를 원본 데이터의 차이로 오해할 수 있습니다.
