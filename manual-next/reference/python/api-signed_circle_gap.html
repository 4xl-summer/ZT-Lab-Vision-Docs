공개 멤버

    사용과 결과 해석

    두 원 중심 사이 거리에서 두 반경의 합을 뺀 부호 있는 값을 계산합니다. 두 원이 바깥쪽으로 떨어져 있으면 양수, 바깥 접촉이면 0, 겹치거나 한 원이 다른 원을 포함하면 음수일 수 있습니다. 예를 들어 중심 간 거리가 5이고 반경이 각각 1이면 결과는 3입니다. 같은 중심에서 반경이 3과 1이면 결과는 −4이며 이것은 두 둘레 사이 최단 거리 2와 다릅니다. 따라서 내부 포함까지 음수인 이 결과를 언제나 물리적인 경계 간격으로 해석하지 마십시오. 입력 두 원의 중심과 반경은 같은 좌표계·단위를 따라야 하고 반경은 유한한 양수여야 합니다. 서로 다른 ROI의 로컬 좌표를 바로 비교하지 말고 공통 좌표로 옮긴 후 관계를 계산하십시오. 두 반경이 각각 1이고 중심 간 거리가 2라면 결과는 0으로 외접을 나타냅니다. 중심 간 거리가 5라면 3이고 같은 중심이라면 음수입니다. 결과의 부호와 크기를 기록할 때는 비교한 원의 순서와 형상, 좌표 단위를 같이 보존하십시오. 한 원이 다른 원 안에 있는 경우에도 음수가 나올 수 있습니다. 부호 간격만으로 둘레의 최단 거리나 교점 개수를 대신 판정하지 마십시오. 두 원의 중심과 반경이 같은 단위인지 먼저 점검합니다. 접촉으로 판정할 허용 오차는 후속 비교에서 명시하십시오.
