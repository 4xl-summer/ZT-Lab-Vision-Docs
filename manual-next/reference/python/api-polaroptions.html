center_x: 입력 ROI 로컬 중심 X 좌표이며 픽셀 단위입니다.

center_y: 입력 ROI 로컬 중심 Y 좌표이며 픽셀 단위입니다.

start_angle: 시작 각도이며 라디안 단위입니다.

end_angle: 끝 각도이며 시작보다 크고 각도 폭은 최대 16π 라디안입니다.

start_radius: 음이 아닌 시작 반경이며 픽셀 단위입니다.

end_radius: 시작보다 큰 끝 반경이며 픽셀 단위입니다.

width: 각도 방향 출력 크기로 2 이상의 정수입니다.

height: 반경 방향 출력 크기로 2 이상의 정수입니다.

interpolation: 최근접 또는 쌍선형 보간이며 기본값은 최근접입니다.

border: 입력 영역 밖의 상수 밝기이며 기본값은 0입니다.
