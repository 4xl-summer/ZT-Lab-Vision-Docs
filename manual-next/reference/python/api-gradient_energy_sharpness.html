공개 멤버

    사용 맥락과 계약

    gradient_energy_sharpness는 영상에서 인접한 픽셀의 가로·세로 밝기 차이를 제곱하여 평균한 선명도 지표를 계산합니다. 값의 크기는 영상 대비와 픽셀 값의 범위에 영향을 받습니다. 영상이 선명할수록 항상 일정한 절대값이 나온다는 보장은 없으므로 같은 영상 형식과 관심 영역, 조명 조건에서 비교하는 것이 중요합니다.

    구체 사례와 판독

    예를 들어 일정 밝기의 영상은 인접 차이가 0이어서 지표도 0입니다. 인접 값이 10과 14이면 그 한 방향 차이는 4이고 제곱은 16입니다. 실제 결과는 전체 유효 이웃 쌍을 고려한 평균이므로 한 쌍의 제곱과 같다고 단정하지 않습니다. 초점 위치를 바꿔 같은 대상의 값들을 비교하고 노이즈 증가가 값을 키울 수도 있음을 고려하세요.

    적용 시 확인

    이 점수는 확률이나 합격률이 아니며 단위가 밝기 값의 제곱에 관련됩니다. 8비트 영상과 정규화된 부동소수 영상의 값을 그대로 비교하면 범위 차이가 지표를 크게 바꿀 수 있습니다. 같은 대상으로 초점 단계별 곡선을 만들고 최댓값 주변의 영상을 직접 확인하면 해석에 도움이 됩니다. 텍스처가 거의 없는 영역에서는 초점이 바뀌어도 구분이 어려울 수 있습니다. 비교 전에 조명과 노출 변화도 가능한 한 일정하게 유지합니다.
