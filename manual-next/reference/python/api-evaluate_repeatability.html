evaluate_repeatability 멤버와 선언

공개 타입

zvision.evaluate_repeatability: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._metrology.evaluate_repeatability.

반복 측정의 평균, 편향과 표본 표준편차를 평가합니다.

Python
evaluate_repeatability(values, reference, max_abs_bias, max_stddev)

인자 선언

  • values · POSITIONAL_OR_KEYWORD · 기본값 없음
  • reference · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_abs_bias · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_stddev · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

values
유한한 측정값 최소 2개.
reference
유한한 기준값; 측정값과 같은 단위.
max_abs_bias
유한한 0 이상 절대 편향 한계.
max_stddev
유한한 0 이상 표본 표준편차 한계.

반환: RepeatabilityMetrics 값; 두 한계 이하일 때 passed.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류.

reference: 유한한 수 검사.

max_abs_bias: 유한한 수 검사.

max_stddev: 유한한 수 검사.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    동일 조건에서 얻은 여러 수치의 평균, 표본 표준편차와 기준값 대비 편향을 계산합니다. 입력은 유한한 값 두 개 이상이며 reference와 두 허용 한계도 측정값과 같은 단위를 사용합니다. 표본 표준편차는 편차 제곱합을 n−1로 나눈 값의 제곱근이고 평균의 Type A 표준 불확도는 이를 √n으로 나눈 값입니다. 예를 들어 세 값이 모두 5이고 기준도 5라면 편향과 표준편차는 0입니다. passed는 절대 편향과 표본 표준편차가 각각의 한계 이하일 때 참입니다. 반복성 통계는 제공한 데이터 집합의 특성을 요약할 뿐 다른 작업 조건이나 장비의 전체 오차를 자동으로 포함하지 않습니다. 값이 픽셀인지 밀리미터인지 기준과 함께 기록하고 서로 다른 단위를 섞지 마십시오. 측정값이 모두 같아 표준편차가 0이어도 그 값이 기준에서 떨어져 있으면 편향은 0이 아닙니다. 예를 들어 값이 모두 5이고 기준이 4라면 평균 편향은 1입니다. 반복 측정의 퍼짐과 기준에 대한 차이는 각각의 한계로 판독해야 합니다. 입력값의 순서를 바꾸더라도 같은 표본 집합의 평균과 표준편차는 변하지 않습니다. 다만 시간에 따른 드리프트는 이 집계값만으로 확인할 수 없으므로 측정 순서와 원래 기록을 별도로 보존하는 편이 좋습니다.
