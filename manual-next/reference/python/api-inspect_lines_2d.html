inspect_lines_2d 멤버와 선언

공개 타입

zvision.inspect_lines_2d: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._line_peaks_2d.inspect_lines_2d.

Extract and fit bounded 2D peaks in Gray8/16/F32/F64, returning owned copies.

mask is optional Gray8 care; its local index is source-local + mask_offset.
Out-of-mask stencil samples are excluded. Gradient uses central difference
and projected stripe averages, not a vendor-specific kernel. Work/point
exhaustion raises an error. Below-threshold peaks were never candidates.

영상의 선 피크를 추출하고 선분을 피팅합니다.

Python
inspect_lines_2d(image, options=None, mask=None, mask_offset=(0, 0))
