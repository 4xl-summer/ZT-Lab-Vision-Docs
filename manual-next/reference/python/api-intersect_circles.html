Python API · intersect_circles

intersect_circles 멤버와 선언

공개 타입

zvision.intersect_circles: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._measurement_model.intersect_circles.

Classify no intersection, tangent, two points or coincident; tolerance is a distance.

두 원의 교차를 분류합니다.

Python
intersect_circles(first, second, tolerance)

인자 선언

  • first · POSITIONAL_OR_KEYWORD · 기본값 없음
  • second · POSITIONAL_OR_KEYWORD · 기본값 없음
  • tolerance · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

first
MeasurementCircle2; 유한한 중심과 양의 반경.
second
MeasurementCircle2; 유한한 중심과 양의 반경.
tolerance
유한한 0 이상의 거리 허용치; 입력 좌표 단위.

반환: MeasurementIntersection: 없음, 접점, 두 점 또는 일치.

오류: 타입·유한성·기하 또는 허용 범위가 유효하지 않으면 오류.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    두 원이 만나지 않는지, 한 점에서 접하는지, 두 점에서 교차하는지 또는 일치하는지 분류합니다. first와 second는 각각 중심이 유한하고 반경이 양수인 MeasurementCircle2입니다. tolerance는 원의 중심과 반경에 사용한 좌표 단위의 유한한 0 이상의 거리 허용치입니다. 예를 들어 중심이 (0,0), (2,0)이고 반경이 모두 1인 두 원은 (1,0)에서 접합니다. 중심 간 거리가 3이면 두 원은 떨어져 있고, 동일한 중심과 반경이라면 원 전체가 일치합니다. 교차가 없는 경우와 일치하는 경우 모두 단순히 교점 배열이 비어 있을 수 있으므로 반환 종류를 먼저 확인해야 합니다. 두 점이 반환된 경우에만 두 번째 좌표를 사용하고, 없는 좌표를 원점으로 바꾸지 마십시오. 서로 다른 ROI에서 얻은 중심은 공통 글로벌 좌표로 옮겨 비교하며, 단위가 다른 좌표와 허용치를 직접 혼합하지 않습니다. 경계에 가까운 사례에서는 허용치에 따라 분류가 달라질 수 있어 입력과 기준을 함께 기록합니다. 반경이 1인 두 원의 중심을 (0,0)과 (1,0)으로 잡으면 중심 거리가 반경의 합 2보다 작아 두 경계가 교차합니다. 이 예에서 두 교점을 하나로 합치지 말고 반환된 종류와 각각의 좌표를 보존하십시오. 원이 서로 멀어졌는지 혹은 완전히 겹쳤는지도 종류를 확인해야 구별됩니다.
