blob_feret_contacts 멤버와 선언

공개 타입

zvision.blob_feret_contacts: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_feret_contacts.blob_feret_contacts.

Measure support corners for a given projection angle in radians.

선택 각도의 투영 폭과 양 끝 지지점을 계산합니다.

Python
blob_feret_contacts(source, index, angle, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • index · POSITIONAL_OR_KEYWORD · 기본값 없음
  • angle · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
입력 BlobResult
index
0 기반 영역 인덱스
angle
유한한 방향 각도(라디안)
work_budget
양의 정수 작업량 상한

반환: BlobFeretContacts 값

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    선택한 방향의 페레 폭

    blob_feret_contacts는 BlobResult에서 한 성분을 선택하고 지정 각도에서의 투영 폭 및 양 끝 지지점을 구합니다. 픽셀 셀 껍질의 꼭짓점을 사용하므로 픽셀 중심만의 극값과 다를 수 있습니다. 이 호출은 한 방향의 폭을 측정합니다.

    인자와 계산

    index는 0 기반 영역 인덱스, angle은 유한한 라디안 값, work_budget은 양의 정수 상한입니다. 선택 방향의 투영 최소값이 2, 최대값이 7이면 폭은 5입니다. 90도 방향은 π/2 라디안으로 지정해야 합니다.

    접촉점 판독

    결과의 최소·최대 지지점은 ROI 로컬 좌표입니다. 블롭 마스크에 두 점을 표시해 원하는 성분과 방향을 사용했는지 확인하세요. 전체 영상에 옮길 때 원점을 적용하며, 결과의 폭은 접촉점 사이 직선 길이보다 투영 차이라는 정의로 이해합니다.

    방향 선택

    같은 물체라도 각도를 바꾸면 폭이 달라집니다. 다른 물체의 폭을 비교할 때는 지정 방향을 같이 기록하고, 여러 방향의 최소·최대가 필요하다면 해당 표본 각도의 범위와 간격을 명시해야 합니다.
