    사용 맥락과 결과 해석

    타입 지정 형상 모델을 루트 상대 컴포넌트 검색에 사용하기 위한 항목입니다. id와 model 외에 relative_position, relative_angle 및 위치·각도 허용 오차를 지정합니다. 상대 위치는 루트 기준 픽셀, 상대 각도와 허용 각도는 라디안으로 해석합니다.

    첫 구성요소는 루트이고 나머지 구성요소는 해당 루트에 대한 관계를 만족해야 합니다. 두 부품이 각각 검색되더라도 지정한 상대 거리나 각도 오차를 넘으면 하나의 객체로 수락되지 않습니다. 항목마다 고유 id를 사용하고 검색 중 모델을 열어 둡니다. 전체 검색이 예산으로 중단되었는지는 반환된 ComponentSearchResult의 incomplete로 확인합니다.

    값을 확인하는 순서

    id 항목: 컴포넌트를 구분하는 고유한 u64 식별자입니다. model 항목: 컴포넌트의 형상 모델입니다. relative_position 항목: 루트 기준 로컬 상대 위치(픽셀)입니다. relative_angle 항목: 루트에 대한 상대 회전각(라디안)입니다. position_tolerance 항목: 예상 위치로부터 허용하는 거리(픽셀)입니다. angle_tolerance 항목: 예상 각도에 대한 허용 오차(라디안)입니다.
