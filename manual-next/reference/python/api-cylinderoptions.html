Python API · CylinderOptions

CylinderOptions 멤버와 선언

공개 타입

zvision.CylinderOptions: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.CylinderOptions.

Structure base class

원통 국소 피팅의 탐색과 종료를 설정하는 값 객체입니다. 직접 생성한 값 객체를 해당 공간 연산에 전달합니다. 입력 검증은 연산 호출에서도 수행됩니다.

Python
CylinderOptions(iterations=50, outlier_fraction=0.49, axis=None, step_tolerance=1e-10, rms_tolerance=0.0, target_fraction=0.0)

인자 선언

  • iterations · POSITIONAL_OR_KEYWORD · 기본값 50
  • outlier_fraction · POSITIONAL_OR_KEYWORD · 기본값 0.49
  • axis · POSITIONAL_OR_KEYWORD · 기본값 None
  • step_tolerance · POSITIONAL_OR_KEYWORD · 기본값 1e-10
  • rms_tolerance · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • target_fraction · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

iterations
각 단계의 최대 반복 수, 양의 정수; 기본 50
outlier_fraction
허용 이상치 비율, 유한한 [0,1); 기본 0.49
axis
초기 축 Point3 또는 None; 지정하면 유한하고 0이 아닌 방향을 정규화해 사용
step_tolerance
무차원 매개변수 단계 종료 허용값, 유한 양수; 기본 1e-10
rms_tolerance
목표 RMS, 점군 단위의 유한한 0 이상; 0은 비활성이고 기본값
target_fraction
조기 종료할 지지 비율; 0은 비활성, 그렇지 않으면 (0,1]; 기본 0

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
