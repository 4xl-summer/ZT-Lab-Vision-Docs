    사용 맥락과 계약

    CapabilityStageValidation은 선택한 활성 축에 대한 스테이지 응답 결과와 어떤 지표가 계산되었는지를 묶습니다. validation은 StageValidation이고 active_axes와 computed는 비트마스크이며 rotation_span은 명령 회전의 범위입니다. 비활성 축이 일정해야 한다는 입력 조건을 만족해야 선택한 축의 응답을 의미 있게 해석할 수 있습니다.

    구체 사례와 판독

    예를 들어 X축만 움직이는 장치라면 해당 축을 활성화하고 비활성 Y와 회전은 일정하게 유지한 관측을 준비합니다. 계산된 비트에 없는 지표를 0이라는 유효 측정값으로 읽지 마세요. 명령과 관측을 시점별로 짝지어 응답과 잔차를 확인하고 길이 단위와 회전 라디안을 구분합니다.

    적용 시 확인

    활성 축 비트와 계산 지표 비트는 서로 다른 의미의 마스크입니다. 어느 비트가 설정되었는지 각 정의에 따라 확인하고 비활성 축의 수치를 임의로 추정하지 마세요. 서로 다른 축이 동시에 움직이는 자료에서는 명령과 관측의 짝과 회전 각도의 연속 표현도 점검합니다. 선택된 축만 움직이는지 입력 자료를 검토하고 계산된 지표 마스크가 요청한 측정 목적을 충족하는지 확인합니다.
