같은 형식의 정수 영상을 성분별 모듈러 뺄셈합니다.

공개 멤버

    사용 맥락과 계약

    pixel_subtract_wrap은 8비트 대응 픽셀의 뺄셈 결과를 순환 범위로 표현합니다. 음수 결과를 0으로 고정하거나 절댓값을 취하는 차영상과 다릅니다. 입력 영상의 대응 위치와 연산 순서를 확인하고 빼는 값이 큰 경우에 어떤 출력이 나오는지 사전에 이해해야 합니다.

    구체 사례와 판독

    예를 들어 3−5는 수학적으로 −2이지만 256을 더해 표현한 순환 결과는 254입니다. 반대 순서인 5−3은 2이므로 두 입력을 바꾸면 결과가 달라집니다. 결함 차이를 밝기 크기로 보려는 작업이라면 이 결과의 큰 숫자가 큰 양의 차이를 의미한다고 가정하면 안 됩니다. 작은 합성 영상의 경계값으로 의도한 동작을 확인하세요.

    적용 시 확인

    순환 뺄셈은 모듈러 산술을 의도한 작업에서 유용하지만 두 영상의 차이 크기를 시각화할 때는 해석이 달라집니다. 예를 들어 차이가 −1인 위치는 255가 됩니다. 연산 결과의 최댓값 위치를 곧바로 가장 큰 물리적 결함으로 해석하지 말고 요구하는 차이의 정의를 먼저 선택하세요. 같은 픽셀에서 두 영상이 같다면 결과는 0입니다. 입력 순서를 바꿔도 결과가 같을 것이라는 가정은 차이가 0일 때 외에는 성립하지 않습니다. 입력의 좌표와 값을 기록해 결과를 다시 확인할 수 있습니다.
