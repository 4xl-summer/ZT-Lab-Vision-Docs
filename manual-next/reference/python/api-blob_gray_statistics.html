공개 멤버

    성분별 밝기 측정

    blob_gray_statistics는 라벨별 Gray8 픽셀 수와 밝기 통계, 히스토그램을 구합니다. BlobResult는 영역 소속을 정의하고 gray 영상은 각 위치의 측정값을 제공합니다. 이진 분할에 사용한 영상과 밝기를 측정할 원본이 다를 수 있으므로 두 입력의 역할을 구분합니다.

    크기와 위치

    측정 Gray8 영상은 라벨 맵과 크기가 같아야 합니다. 예를 들어 같은 3×3 크기라도 서로 다른 ROI 위치를 가리키면 각 레이블의 위치에서 읽는 밝기가 의도한 물체와 어긋납니다. 크기뿐 아니라 원본과의 정렬과 좌표 기준도 확인해야 합니다.

    통계 해석

    픽셀 수가 같은 두 영역도 밝기 분포가 다를 수 있습니다. 평균이 비슷해도 히스토그램은 어두운 값과 밝은 값의 분포 차이를 보여줄 수 있으므로 판정 기준에 맞는 항목을 사용합니다. 양의 work_budget을 지정하고 입력 영역과 Gray8 데이터의 범위를 함께 기록합니다.

    제약

    Gray8을 요구하는 호출에 다른 형식의 영상을 그대로 사용한다고 가정하지 않습니다. 형식 변환이 필요하면 변환 전후의 값 범위가 측정 기준에 미치는 영향을 별도로 확인합니다.
