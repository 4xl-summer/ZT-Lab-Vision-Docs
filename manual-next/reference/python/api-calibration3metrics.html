    사용과 결과 해석

    Calibration3Metrics는 강체 변환을 원본 대응점에 적용한 뒤 기준점과의 유클리드 거리를 요약하는 값입니다. count는 평가한 대응 쌍의 수이고 mean_error, rms_error, max_error는 각각 거리의 평균, RMS와 최대값입니다. 예를 들어 두 거리 잔차가 0과 2라면 평균은 1이고 RMS는 √2이며 최대는 2입니다. 모두 변환에 지정된 길이 단위를 따릅니다.

    원본과 기준 목록은 같은 순서와 길이의 유한한 점으로 준비하고 비어 있지 않아야 합니다. 평가 연산은 자동 이상치 제거를 수행하지 않으므로 어느 점을 넣었는지가 결과에 직접 영향을 줍니다. 변환을 구하는 데 사용한 점과 검증을 위해 남겨 둔 점의 통계는 구분해 기록합니다. 이 객체는 값 스냅샷이며 점군의 소유 핸들을 대신하지 않습니다. 좌표 단위와 from_frame, to_frame도 결과와 연결해 두어야 합니다.
