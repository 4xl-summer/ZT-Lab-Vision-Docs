공개 멤버

    사용과 결과 해석

    하나의 유한한 길이 값을 원래 단위에서 목표 단위로 환산합니다. 단위는 밀리미터·마이크로미터·미터 중에서 지정하며, 입력이 2밀리미터라면 마이크로미터 결과는 2000입니다. 이는 좌표 변환을 수행하는 함수가 아니라 이미 같은 물리량으로 표현된 수의 단위를 바꾸는 연산입니다. 따라서 ROI 로컬 픽셀에 이 함수를 직접 적용해 물리 거리를 얻을 수 없고 픽셀에서 세계로 가는 보정이 먼저 필요합니다. 입력 단위와 출력 단위가 같으면 같은 값을 반환하며 잘못된 열거값이나 비유한 결과는 오류로 처리해야 합니다. 보정 평가에서 허용치를 바꾸는 경우에는 기준점과 허용치 모두 같은 세계 단위로 표현되었는지 확인하십시오. 가령 10 mm와 1 cm는 같은 길이이므로 각각을 같은 목표 단위로 환산하면 같은 물리량을 나타냅니다. 입력 수치뿐 아니라 입력 단위와 목표 단위를 함께 기록하십시오. 이 함수의 단위 환산만으로 픽셀에서 물리 좌표로 가는 카메라 보정이 만들어지는 것은 아닙니다. 예를 들어 원본 값이 밀리미터인지 마이크로미터인지 잘못 기록하면 계산 자체가 성공해도 보고된 길이가 달라집니다. 변환 전에 단위를 명시적으로 검토하십시오. 입력과 출력의 단위 표기를 결과에 남깁니다.
