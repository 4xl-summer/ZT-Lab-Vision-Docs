Python API · fill_directional

fill_directional 멤버와 선언

공개 타입

zvision.fill_directional: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.fill_directional.

양쪽 유효 원본 표본 사이의 짧은 결측 구간을 선형 보간합니다.

Python
fill_directional(depth, direction, max_gap)

인자 선언

  • depth · POSITIONAL_OR_KEYWORD · 기본값 없음
  • direction · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_gap · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

depth
DepthMap: 깊이와 결측을 담은 입력 격자
direction
방향 정수: 0 가로, 1 세로
max_gap
채울 수 있는 양의 최대 결측 셀 수

반환: 새 소유 DepthMap이며 사용 후 닫습니다.

오류: 방향이나 간격이 유효하지 않으면 오류입니다.

direction: 정수 검사.

max_gap: 정수 검사 · 최소 1.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    fill_directional은 한 행 또는 열에서 결측 구간의 양쪽에 있는 원본 유효 높이를 찾아 선형 보간합니다. direction 0은 수평, 1은 수직이고 max_gap은 채울 수 있는 결측 셀 수의 양의 정수 상한입니다. 예를 들어 한 행이 [1,None,5]이고 가로 방향 max_gap이 1이면 가운데 값은 3입니다. 간격 양쪽에 원본 표본이 없거나 결측 구간이 상한보다 길면 그대로 남습니다.

    채운 값은 같은 호출의 추가 원본 표본으로 연쇄 전파되지 않습니다. 수평과 수직은 서로 다른 이웃을 보므로 구멍의 형태에 따라 결과가 달라질 수 있습니다. 깊이의 0은 유효 숫자이며 None만 결측이라는 점도 유지해야 합니다. 새 결과는 별도 소유 DepthMap으로 반환되며 원본을 덮어쓰지 않습니다. 방향 값이 범위 밖이거나 max_gap이 0이면 오류로 처리하고 결과의 결측을 다시 확인합니다.
