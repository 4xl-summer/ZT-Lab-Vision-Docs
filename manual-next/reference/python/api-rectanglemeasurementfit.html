    이 값은 RectangleMeasurementResult의 status가 성공일 때만 사용할 수 있습니다. 면별 탐침의 에지 상태와 수렴 진단을 함께 확인하여 일부 면이 제대로 측정되었는지 살펴봅니다. 원본 영상으로 좌표를 옮길 때 ROI 원점을 고려해야 합니다. 수치 적합의 성공은 자동으로 실제 장비의 공차 판정이나 물리 단위 보정을 의미하지 않습니다.
