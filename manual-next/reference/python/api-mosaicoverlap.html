열거 값

  • FIRST = 0 · 겹침에서 첫 유효 표본을 사용합니다.
  • LAST = 1 · 겹침에서 마지막 유효 표본을 사용합니다.
  • MEAN = 2 · 겹침의 유효 표본 평균을 사용합니다.

사용과 결과 해석

여러 정합 영상이 같은 출력 픽셀에 유효 표본을 제공할 때 값을 합치는 정책입니다. FIRST는 첫 유효 표본, LAST는 마지막 유효 표본을 선택하고 MEAN은 유효 표본의 평균을 사용합니다. 유효하지 않은 위치를 단순한 검은색 0 표본으로 평균에 넣는 정책이 아닙니다.

예를 들어 겹침에서 유효한 값이 입력 순서대로 10과 30이면 FIRST는 10, LAST는 30, MEAN은 20입니다. 첫째와 마지막 정책의 결과는 입력 순서에 영향을 받습니다. 평균을 택해도 기하 정렬이 틀린 이중 경계가 자동으로 사라지는 것은 아닙니다.

공통 캔버스 원점과 배율, 각 영상의 유효 마스크를 함께 확인해야 겹침 밖의 빈 영역과 실제 0 값을 구별할 수 있습니다. 이 열거형은 정합을 새로 추정하는 설정이 아니라 렌더 단계의 표본 결합 방법입니다.
