  • HISTOGRAM = 1 · 값 1. 채널별 히스토그램을 기준 영상에 맞추는 상대 색 보정을 선택합니다.

사용과 결과 해석

색 보정 방식의 열거값으로 MEAN_VARIANCE=0과 HISTOGRAM=1을 제공합니다. correct_advanced에 source, reference와 함께 전달하며 첫 방식은 평균과 분산에 기반하고 둘째는 히스토그램을 이용합니다. 두 방법은 같은 입력에서도 서로 다른 분포 변화를 만들 수 있습니다.

예를 들어 기준 영상과 입력 영상의 평균 밝기가 다르면 평균·분산 방식은 두 분포의 통계를 바탕으로 입력을 조정합니다. 히스토그램 방식은 bins 설정을 사용합니다. variance_floor, bins, strength는 각각의 처리 설정이며 실제 영상의 조명과 색 분포에 맞는지 결과를 확인합니다.

보정은 위치를 정렬하거나 기준 영상의 콘텐츠를 검출하는 기능이 아닙니다. 보정 전후의 비교 영역과 색 분포가 대응하는지 확인해야 의미 있는 결과를 얻습니다. 입력이 잘못되거나 네이티브 처리에서 실패하면 결과 영상 대신 오류가 반환됩니다.

기준 영상에 없는 물체가 입력에만 있을 경우 전체 분포 차이가 조명만을 뜻하지 않을 수 있습니다. 대응하는 영역에서 보정 전후를 확인하고 설정을 검토합니다.

방법을 바꾸면 결과 영상도 새로 생성하여 비교합니다.
