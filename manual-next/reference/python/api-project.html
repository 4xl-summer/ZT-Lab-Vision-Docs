project 멤버와 선언

공개 타입

zvision.project: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.project.

깊이 격자를 카메라 모델로 역투영합니다.

Python
project(depth, camera, convention=0)

인자 선언

  • depth · POSITIONAL_OR_KEYWORD · 기본값 없음
  • camera · POSITIONAL_OR_KEYWORD · 기본값 없음
  • convention · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

depth
DepthMap: 깊이와 결측을 담은 입력 격자
camera
Camera: fx/fy는 유한 양수, cx/cy와 5개 왜곡 계수는 유한한 카메라 내참수
convention
정수 깊이 정의: 0은 축 방향 Z, 1은 카메라까지 거리; 기본 0

반환: 새 소유 PointCloud; 결측 슬롯을 보존하며 사용 후 닫습니다.

오류: 유효 깊이가 0 이하, 내참수·방식이 무효이거나 역왜곡 실패면 오류입니다.

convention: 정수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    project는 깊이 격자의 각 유효 샘플을 카메라 광선을 따라 3D 점으로 되돌립니다. 카메라의 fx와 fy는 유한 양수이고 cx, cy 및 Brown 왜곡 계수는 유한해야 합니다. convention 0은 축 방향 Z 깊이이고 1은 카메라 원점으로부터의 거리입니다. 광축 밖에서는 이 두 수치가 다르므로 입력 센서의 정의를 확인하고 전달해야 합니다. 기본은 0입니다.

    입력 격자의 원점과 spacing은 이 카메라 내참수를 대신하지 않습니다. 유효 깊이는 양수여야 하고 역왜곡 계산이 실패하면 오류가 납니다. 결과 PointCloud는 결측 슬롯, 길이 단위와 frame을 유지하며 새 소유 객체로 반환되므로 사용 후 닫습니다. 주점 픽셀에서 왜곡이 없고 Z 깊이가 5라면 광선 방향의 X와 Y는 0이고 점은 (0,0,5)입니다. 이는 좌표식의 합성 예이며 실측 보정 정확도가 아닙니다.
