    사용과 결과 해석

    CloudInfo는 점군의 현재 슬롯 수와 좌표 메타데이터를 복사해 보여 주는 값입니다. count는 None을 포함한 전체 위치의 수이고 valid_count는 좌표가 있는 점의 수입니다. 예를 들어 세 슬롯이 점, None, 점이라면 count는 3이고 valid_count는 2입니다. 점군을 알고리즘에 넘기기 전 전체 배열 길이와 유효 데이터의 양을 각각 확인할 때 사용합니다.

    unit은 점의 위치 및 거리 임계값의 길이 단위이고 frame은 좌표계 식별자입니다. 같은 숫자 목록이라도 frame이 다르면 두 점이 같은 공간 위치를 나타낸다고 가정할 수 없습니다. 변환은 원본 frame과 변환의 from_frame을 맞추고, 출력 점군의 정보에서 목표 frame을 확인합니다. 이 정보 객체는 핸들 자체가 아니며, 소유한 PointCloud는 별도로 close 또는 with를 사용해 정리합니다.
