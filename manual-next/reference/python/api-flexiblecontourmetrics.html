    길이와 곡률

    이 결과는 순서 있는 경로의 전체 length와 각 점에서 계산된 curvature 값을 담습니다. 길이는 경로의 크기를 요약하고 곡률은 위치별 방향 변화의 양상을 설명하므로 둘은 서로 대체할 수 없습니다. 값의 단위와 부호 해석은 원래 점의 좌표 단위와 측정 연산의 설정에 의존합니다.

    경로 해석 예

    점들이 같은 직선 위에서 같은 방향으로 나열되어 있다면 중간에서 방향이 꺾이지 않습니다. 반면 꺾이는 점이 포함된 경로에서는 그 주변의 방향 변화가 나타날 수 있습니다. 점 간격, 곡률을 계산하는 간격, 경로를 닫는 방식이 바뀌면 같은 외형을 나타내더라도 수치 비교 조건이 달라집니다.

    비교할 때의 조건

    원래 점 목록의 순서를 유지하고 경로의 열림 또는 닫힘과 측정 간격을 동일하게 설정한 결과끼리 비교합니다. ROI 좌표를 전체 좌표로 평행 이동하면 점 사이 거리는 변하지 않지만 좌표계의 크기나 배율이 달라지면 수치 해석도 달라집니다. 표본 수가 적거나 점이 중복된 입력의 처리 조건은 해당 측정 함수의 계약을 확인합니다.

    길이의 수치가 같아도 두 경로의 굽은 위치나 방향 변화는 다를 수 있습니다. 각 점의 곡률을 검토할 때는 원본 점의 인덱스와 연결해 국소 형상에서 변화가 나타난 위치를 확인합니다.
