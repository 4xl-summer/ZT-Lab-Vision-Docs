    acceptedbool필수규칙 위반 비트가 없으면 참입니다.

    사용과 결과 해석

    문자열 검사 결과의 scalar_count, reasons, accepted를 담는 불변 값입니다. scalar_count는 유니코드 스칼라 값의 수이고 UTF-8 바이트 길이와 구분해야 합니다. 예를 들어 문자 하나가 UTF-8에서 여러 바이트로 인코딩되더라도 스칼라 수는 바이트 수와 같지 않을 수 있습니다.

    accepted는 적용한 문자 및 길이 조건에 대한 수락 여부이며 reasons는 거절 사유를 나타냅니다. 텍스트가 눈에 보이는 모양만으로 바이트 수나 스칼라 수를 추정하지 않고 반환값과 실제 검사 조건을 함께 기록합니다. 결합 문자가 있는 표시상의 글자 수도 스칼라 수와 다를 수 있습니다.

    이 결과는 OCR 모델의 문자 정확도를 평가한 확률이 아닙니다. 인식된 텍스트에 대한 별도의 규칙 검사 결과이므로 원래 인식 상태와 함께 해석합니다. 잘못된 입력으로 호출이 실패한 경우 accepted가 거짓인 정상 반환과 구별합니다.

    예를 들어 영문 A와 한글 한 글자는 각각 한 스칼라지만 UTF-8 바이트 수는 다릅니다. 허용 문자 규칙과 길이 한도가 어느 단위를 사용하는지 검사 호출의 설정과 함께 확인합니다.

    검사에 사용한 문자열과 조건을 함께 기록합니다.
