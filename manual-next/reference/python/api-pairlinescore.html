사용과 결과 해석

두 에지로 이루어진 후보를 강도로 점수화할 때 사용할 집계 방식을 나타냅니다. SUM은 두 에지 강도의 절댓값을 합하고 MINIMUM은 두 절댓값 중 작은 값을 사용합니다. 예를 들어 두 강도 크기가 10과 4이면 합은 14이고 작은 값은 4입니다. 전자는 두 강도의 전체 크기를, 후자는 약한 쪽의 크기를 보여 주므로 같은 후보라도 점수의 의미가 다릅니다. 하나의 에지가 매우 강하고 다른 하나가 약한 후보와 두 에지가 비슷한 후보를 비교할 때 선택 방식에 따라 순위가 달라질 수 있습니다. 점수는 선택 정책의 근거이며 실제 형상의 허용차나 세계 단위 거리를 뜻하지 않습니다. 에지 강도는 입력 강도의 단위와 픽셀 거리에 영향을 받으므로 다른 영상 형식의 점수를 무조건 같은 기준으로 비교하지 마십시오. 두 에지가 동일한 프로파일과 진행 방향에서 왔는지 확인하고, 선택된 후보의 두 위치와 극성도 함께 기록해야 순위 결과를 설명할 수 있습니다. 예상 너비나 위치에 따른 추가 점수를 사용하는 호출이라면 그 옵션도 따로 확인합니다. 예를 들어 다른 후보의 두 강도 크기가 7과 7이면 합은 14로 앞의 10과 4 후보와 같지만 최소값은 7로 더 큽니다. 이 비교는 합과 최소값이 서로 다른 기준을 표현한다는 점을 보여 줍니다. 결과가 동점인 경우의 세부 순서는 해당 호출 계약을 확인하십시오.
