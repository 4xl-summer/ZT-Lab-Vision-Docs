Python API · BlobFeatureRange

BlobFeatureRange 멤버와 선언

공개 타입

zvision.BlobFeatureRange: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_feature_select.BlobFeatureRange.

One inclusive feature range (feature IDs 0..29).

Python
BlobFeatureRange(feature: int, low: float, high: float) -> None

인자 선언

  • feature · POSITIONAL_OR_KEYWORD · 타입 <class 'int'> · 기본값 없음
  • low · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음
  • high · POSITIONAL_OR_KEYWORD · 타입 <class 'float'> · 기본값 없음

반환 타입 주석: None

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

BlobFeatureRange(<class 'int'>, <class 'float'>, <class 'float'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    featureint필수선택할 Blob 특징 ID로 0–29입니다.
    lowfloat필수포함되는 특징 범위의 유한한 하한입니다.
    highfloat필수포함되는 특징 범위의 유한한 상한으로 하한 이상이어야 합니다.

    사용 맥락과 결과 해석

    고급 Blob 선택에 사용할 한 특성의 포함 범위를 지정합니다. feature는 0..29의 특성 ID이고 low와 high는 유한하며 low가 high 이하여야 합니다. select_blob_features에 이 조건을 1..64개 전달하고 match_all로 모든 조건 또는 하나 이상의 조건을 요구합니다.

    예를 들어 동일한 특성에 하한 5와 상한 10을 지정하면 경계 5와 10도 해당 범위에 포함됩니다. 어떤 물리량을 검사하는지는 feature ID의 정의에 따라 달라지므로 숫자만 보고 면적이나 길이라고 가정하지 않습니다. 작업 상한을 넘거나 잘못된 범위를 주면 오류입니다. 반환되는 것은 원래 BlobResult에서의 0 기반 인덱스입니다.

    조건을 여러 개 주면 match_all의 선택에 따라 AND 또는 OR가 됩니다. 같은 범위를 사용해도 이 선택이 다르면 결과 인덱스가 달라질 수 있으므로 조건과 함께 저장합니다.

    값을 확인하는 순서

    feature 항목: 선택할 Blob 특징 ID로 0–29입니다. low 항목: 포함되는 특징 범위의 유한한 하한입니다. high 항목: 포함되는 특징 범위의 유한한 상한으로 하한 이상이어야 합니다.

    항목읽을 때 확인할 내용
    feature선택할 Blob 특징 ID로 0–29입니다.
    low포함되는 특징 범위의 유한한 하한입니다.
