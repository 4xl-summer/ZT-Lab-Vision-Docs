    사용과 결과 해석

    폰트 OCR에서 분할하고 읽은 한 글자의 불변 결과입니다. line, label, cell, score, accepted, source_corners를 포함합니다. cell은 정수 좌표 튜플이고 source_corners는 원본 영상상의 수치 좌표 쌍입니다. 회전된 입력에서는 단순한 셀 사각형과 원본 모서리의 표현을 혼동하지 않습니다.

    score는 이진 템플릿의 유사도이며 보정된 확률이 아닙니다. 예를 들어 0.9를 90%의 정확도라는 뜻으로 바꾸지 말고 설정한 최소 글자 점수와 accepted를 함께 확인합니다. 각 글자의 결과와 전체 문자열 FontRead의 수락은 서로 다른 수준입니다.

    line은 여러 줄 결과에서 글자를 어느 줄에 배치할지 해석하는 데 사용합니다. 원본 영상에 오버레이할 때는 source_corners의 좌표계를 사용하고 해당 프레임의 크기 및 원점을 확인합니다. 반환 튜플은 값 스냅샷이며 영상 핸들이 아닙니다.

    같은 라벨을 가진 글자가 여러 개 있을 때는 line과 cell을 함께 사용해 어느 글자인지 구분합니다. 프레임을 자른 뒤에는 원본 좌표와 잘린 영상의 좌표가 다른지도 확인합니다.
