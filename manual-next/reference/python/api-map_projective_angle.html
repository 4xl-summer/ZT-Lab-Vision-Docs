Python API · map_projective_angle

map_projective_angle 멤버와 선언

공개 타입

zvision.map_projective_angle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.map_projective_angle.

Map a tangent angle in radians at a point through a projective map.

주어진 점의 접선 각도를 사영 변환의 국소 방향으로 변환합니다.

Python
map_projective_angle(mapping, point, angle_radians, inverse=False)

인자 선언

  • mapping · POSITIONAL_OR_KEYWORD · 기본값 없음
  • point · POSITIONAL_OR_KEYWORD · 기본값 없음
  • angle_radians · POSITIONAL_OR_KEYWORD · 기본값 없음
  • inverse · POSITIONAL_OR_KEYWORD · 기본값 False

확인된 인자 조건

mapping
Homography 값입니다.
point
각도를 평가할 Point2입니다.
angle_radians
입력 각도이며 라디안 단위입니다.
inverse
True면 역방향 변환하며 기본값은 False입니다.

반환: 변환된 각도 float이며 라디안 단위입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

angle_radians: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    map_projective_angle은 사영 변환이 한 위치의 방향에 미치는 영향을 계산합니다. mapping과 기준 point, angle_radians를 전달하고 inverse를 선택하면 역방향 변환에 대한 방향을 구합니다. 각도는 라디안이며 방향은 점에서의 국소적인 방향입니다. 사영 변환에서는 영상의 위치에 따라 같은 입력 방향이 다른 출력 방향으로 바뀔 수 있습니다.

    구체 사례와 판독

    예를 들어 항등 변환에서는 한 점의 각도 0이 변환 뒤에도 0이고 π/2도 π/2입니다. 실제 원근 변환에서는 기준점이 달라지면 국소 방향의 결과도 달라질 수 있으므로 한 지점에서 얻은 각도를 모든 영역에 재사용하지 마세요. 역방향 요청에서는 입력 점이 역변환에 맞는 좌표계에 있는지 확인합니다. 각도 비교는 주기와 방향 정의를 함께 고려해야 합니다.

    적용 시 확인

    방향을 나타내는 아주 짧은 선분을 기준점에 놓고 선분 양 끝을 변환해 보는 것은 결과의 방향을 시각적으로 확인하는 방법입니다. 다만 유한한 길이의 선분은 국소 미분 방향과 정확히 같지 않을 수 있습니다. 변환의 특이점이나 분모가 0에 가까운 위치에서는 좌표와 방향이 불안정해질 수 있으므로 유효 영역도 확인해야 합니다.
