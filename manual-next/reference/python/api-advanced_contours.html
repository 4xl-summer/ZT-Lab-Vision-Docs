advanced_contours(mask, intensity)

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • intensity · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

mask
Gray8 전경 마스크.
intensity
마스크와 크기·원점이 같은 Gray8 밝기 영상.

반환: 호출자가 close할 AdvancedContours 소유 결과.

오류: 유효하지 않은 영상 형식·기하·옵션 또는 계산 범위는 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    이진 결함 마스크와 밝기 영상을 받아 연결된 결함의 픽셀 셀 경계를 순서 있는 변의 집합으로 돌려주는 AdvancedContours 소유 결과를 만듭니다. 두 인자는 ZImage입니다. 결함의 수를 읽고 인덱스별 contours와 info를 호출하여 경계와 측정값을 확인할 수 있습니다.

    각 변은 시작점과 끝점의 좌표 쌍입니다. 예를 들어 한 셀의 경계는 셀 중심 좌표 하나가 아니라 이웃한 격자점 사이의 변으로 표현됩니다. 구멍이 있는 영역은 여러 경계가 생길 수 있으므로 변을 단순한 무순서 점 목록으로 바꾸면 연결 관계가 사라집니다.

    info의 면적, 둘레, 구멍 수, 거칠기, 최대 Feret와 선택적 대비는 각각 다른 측정값입니다. 결함 하나의 대비가 None이면 0으로 치환하지 말고 측정값이 없는 상태로 읽습니다. 범위 선택은 select에 AdvancedDiagnosticRange를 넘깁니다.

    반환 결과는 소유 자원으로 사용 후 close합니다. 마스크와 밝기 영상의 좌표와 기하가 대응하는지 먼저 확인하고, 입력이 잘못되어 오류가 난 경우 결함이 없는 정상 결과로 취급하지 않습니다.

    경계선을 재구성할 때 각 변의 시작과 끝을 순서대로 연결합니다. 같은 영역의 외곽선과 구멍 경계를 하나로 이어 붙이면 위상이 달라지므로 반환된 윤곽별 구분을 유지해야 합니다.
