advanced_contours 멤버와 선언

공개 타입

zvision.advanced_contours: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_advanced.advanced_contours.

4연결 결함의 픽셀 셀 경계와 진단을 계산합니다.

Python
advanced_contours(mask, intensity)

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • intensity · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

mask
Gray8 전경 마스크.
intensity
마스크와 크기·원점이 같은 Gray8 밝기 영상.

반환: 호출자가 close할 AdvancedContours 소유 결과.

오류: 유효하지 않은 영상 형식·기하·옵션 또는 계산 범위는 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
