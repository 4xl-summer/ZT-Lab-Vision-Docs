공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    columnsint필수변위 격자의 열 수로 2 이상입니다. 격자점 총수는 최대 1024입니다.
    rowsint필수변위 격자의 행 수로 2 이상입니다. 격자점 총수는 최대 1024입니다.
    displacementstuple[zvision._regions.Point2, ...]필수출력에서 템플릿 방향의 로컬 픽셀 변위입니다. 행 우선으로 행×열개의 유한 좌표를 지정합니다.

    사용 맥락과 결과 해석

    비강체 템플릿 변형 한 가지를 제어 격자의 변위로 지정합니다. columns와 rows는 각각 2 이상이며 변위의 개수는 두 값의 곱과 같아야 하고 총점은 1024 이하여야 합니다. Point2 변위는 템플릿 로컬 픽셀 단위로 행 우선 저장되며 성분은 유한해야 합니다.

    각 출력 템플릿 위치의 변위는 제어 격자에서 쌍선형 보간해 계산합니다. 예를 들어 2×2 격자는 네 제어점을 필요로 하며 행 방향 두 점 다음에 다음 행 두 점을 제공합니다. 여러 변형을 학습하면 각각 별도 NCC 변형 모델이 만들어집니다. 이 데이터는 검색 결과의 연속 변형을 자동 추정하는 것이 아니라 호출자가 학습 전에 명시한 변형 사례입니다.

    값을 확인하는 순서

    columns 항목: 변위 격자의 열 수로 2 이상입니다. 격자점 총수는 최대 1024입니다. rows 항목: 변위 격자의 행 수로 2 이상입니다. 격자점 총수는 최대 1024입니다. displacements 항목: 출력에서 템플릿 방향의 로컬 픽셀 변위입니다. 행 우선으로 행×열개의 유한 좌표를 지정합니다.

    항목읽을 때 확인할 내용
