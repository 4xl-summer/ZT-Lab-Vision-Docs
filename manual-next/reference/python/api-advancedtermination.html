열거 값

  • COMPLETE = 0 · 검색 격자를 완료했습니다.
  • CANDIDATE_BUDGET = 1 · 후보 평가 예산으로 종료했습니다.
  • TIMEOUT = 2 · 시간 제한으로 종료했습니다.
  • CERTAINTY = 3 · 조기 종료 점수에 도달했습니다.

사용 맥락과 결과 해석

확장 매칭 보고서가 왜 검색을 끝냈는지 나타냅니다. COMPLETE는 요청한 검색을 마친 경우이며 CANDIDATE_BUDGET은 평가 가능한 포즈 예산에 도달한 경우입니다. TIMEOUT은 시간 제한, CERTAINTY는 설정된 조기 종료 점수에 도달한 경우입니다. 반환 목록이 비었는지와 종료 이유는 별개로 읽어야 합니다.

예를 들어 후보가 하나 나왔더라도 예산으로 멈췄다면 격자의 나머지 위치를 모두 평가했다고 볼 수 없습니다. 예상 포즈를 우선하는 검색에서는 평가 순서가 달라지므로 같은 예산에서 다른 후보가 관찰될 수도 있습니다. 결과의 evaluated와 종료 이유, 실제 검색 옵션을 같이 저장하면 미검출과 조기 종료를 구분하는 데 도움이 됩니다.

값을 확인하는 순서

CANDIDATE_BUDGET 항목: 후보 평가 예산으로 종료했습니다. CERTAINTY 항목: 조기 종료 점수에 도달했습니다. COMPLETE 항목: 검색 격자를 완료했습니다. TIMEOUT 항목: 시간 제한으로 종료했습니다.
