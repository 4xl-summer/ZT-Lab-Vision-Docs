    필드타입기본값의미와 조건
    sourcetuple[float, float, float]필수측정한 정규화 인코딩 sRGB의 세 채널입니다.
    referencetuple[float, float, float]필수목표 정규화 인코딩 sRGB의 세 채널입니다.

    사용과 결과 해석

    색 보정 모델을 학습할 때 사용하는 한 쌍의 색 값입니다. source는 측정한 정규화 인코딩 sRGB 세 채널이고 reference는 같은 패치에 대한 목표 sRGB 세 채널입니다. 각각 세 숫자의 시퀀스를 값 객체가 보관하며, 채널의 순서와 두 값이 같은 물리 패치를 나타내는지 확인해야 합니다. 하나의 패치는 행렬의 한 계수가 아니라 모델을 구하기 위한 대응 관측입니다.

    여러 ColorPatch를 fit_color_correction에 전달하면 선형 RGB에서 적용할 행렬과 편향을 피팅하고, 패치별 보정 전후 CIE76 색차를 결과에서 확인할 수 있습니다. 최소 네 개의 선형 독립 패치가 필요하므로 같은 색을 여러 번 나열하는 것만으로는 충분한 기하 정보를 제공하지 못합니다. 잘못된 채널 길이나 유효하지 않은 색 값은 정상적인 피팅 결과가 아닙니다.

    예를 들어 측정값이 목표보다 일관되게 어둡더라도 실제 보정은 세 채널과 편향을 함께 이용합니다. 학습에 사용한 패치의 잔차가 작다는 사실과 다른 표면이나 조명에서의 성능은 별개입니다. 결과 핸들에 포함된 값과 반환 영상의 소유권을 구분하고 실제 대상에서 별도로 확인합니다.

    패치 값을 넘길 때 채널 순서가 RGB인지 확인하면 측정값과 기준값을 서로 바꾸는 실수를 줄일 수 있습니다.
