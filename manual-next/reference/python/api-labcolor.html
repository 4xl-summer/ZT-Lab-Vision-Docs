    사용과 결과 해석

    D50/2° 기준의 CIELAB 한 점을 나타내는 값으로 l, a, b 세 좌표를 담습니다. l은 명도 축이고 a와 b는 색 방향을 표현합니다. 이 값은 한 픽셀 영상이나 RGB 바이트 배열이 아니라 색 좌표 하나이므로, 영상을 기준색과 비교하는 연산에 목표색으로 전달하거나 두 좌표 간 색차 계산에 사용할 수 있습니다.

    CIE76 거리는 두 Lab 점의 각 축 차이를 제곱해 더하고 제곱근을 취하는 유클리드 거리입니다. 두 점이 같으면 거리는 0입니다. 값의 차이를 해석할 때 입력이 같은 기준 백색점과 관찰 조건의 Lab인지 먼저 확인해야 합니다. 인코딩 RGB의 세 값과 Lab의 세 값을 단순히 서로 바꿔 넣으면 같은 색을 표현한다는 보장이 없습니다.

    색 분할에서는 영상의 각 픽셀을 Lab으로 바꾸어 목표 LabColor와의 거리가 지정한 상한 이하인지 검사합니다. 이때 거리 상한은 별도의 설정이며 LabColor 자체가 허용 불량 범위를 뜻하지 않습니다. 영상에서 얻은 결과 마스크는 소유 객체이고 LabColor는 좌표 값이므로 수명 관리 방식도 구분합니다.

    예를 들어 명도만 다른 두 점은 a와 b가 같더라도 L* 차이에 따라 거리가 생깁니다. 값의 순서를 바꾸면 다른 좌표가 됩니다.
