    사용 맥락과 결과 해석

    평면 형상으로부터 얻은 가능한 자세들과 재투영 잔차 및 연속 회전 모호성 정보를 담는 값입니다. poses를 검사하기 전에 후보가 존재하는지 확인하고 rms_pixels는 영상 픽셀 단위의 오차로 해석합니다. continuous_rotation은 관측 형상이 특정 회전을 유일하게 결정하지 못하는 상황을 표시합니다.

    평면 물체의 영상 일치만으로 실제 3차원 자세가 항상 하나로 결정되는 것은 아닙니다. 후보 중 하나의 재투영 오차가 작더라도 모호성 플래그와 카메라 보정 입력을 함께 확인해야 합니다. 다른 센서나 추가 제약 없이 임의의 후보를 확정 자세로 취급하면 후속 좌표 변환이 잘못될 수 있습니다. 이 값은 검출된 평면 특징으로부터 계산된 결과입니다.

    값을 확인하는 순서

    poses 항목: 타깃 프레임에서 카메라 프레임으로의 강체 자세 후보 튜플입니다. rms_pixels 항목: 대응 픽셀의 재투영 RMS입니다. continuous_rotation 항목: 평면 내 회전이 연속적으로 식별되지 않는지 나타냅니다.

    항목읽을 때 확인할 내용

    rms_pixels대응 픽셀의 재투영 RMS입니다.
    continuous_rotation평면 내 회전이 연속적으로 식별되지 않는지 나타냅니다.
