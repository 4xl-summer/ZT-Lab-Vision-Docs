Python API · fit_point_lines

fit_point_lines 멤버와 선언

공개 타입

zvision.fit_point_lines: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.fit_point_lines.

Fit an invertible affine map to 6–100000 source point/target line pairs.

대응 점과 직선으로 가역 아핀 맵을 적합합니다.

Python
fit_point_lines(points, lines)

인자 선언

  • points · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lines · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

points
원본 Point2 6–100000개입니다.
lines
각 점에 대응하는 같은 개수의 PointLine2입니다.

반환: 적합된 Affine2 값입니다.

오류: 인자·좌표계·형식이 유효하지 않거나 계산에 실패하면 예외가 발생합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    fit_point_lines는 점들과 대응 직선들의 관계를 이용하는 2차원 적합 단계입니다. 원본 점과 대상 직선의 대응을 6쌍 이상 100000쌍 이하로 제공하며 결과는 원본에서 대상으로 가는 가역 아핀 변환입니다. 각 목록 안에서 좌표 프레임과 길이 단위를 일관되게 사용해야 합니다. 직선의 계수는 a·x+b·y+c=0으로 표현하므로 계수의 부호나 배율 자체보다 나타내는 직선을 확인합니다.

    구체 사례와 판독

    예를 들어 변환된 점이 (3,2)이고 대상 직선 y=2의 계수가 (0,1,−2)이면 변환된 점을 식에 대입한 값은 0입니다. 변환된 점 (3,3)은 식의 값이 1이며 이 예에서는 법선 길이도 1이므로 거리는 1입니다. 일반 계수에서는 법선 길이로 나눠 거리를 해석해야 합니다. 대응 순서가 어긋나거나 직선들이 불충분하게 다양한 경우 적합의 안정성을 별도로 확인하세요.

    적용 시 확인

    적합 전에는 각 대응 쌍을 그림으로 표시하거나 알려진 변환을 가진 합성 데이터로 검증하면 순서 오류를 발견하기 쉽습니다. 결과가 숫자로 반환되더라도 입력 점이 거의 한곳에 몰리거나 기하 구조가 퇴화하면 다른 데이터에 대한 안정성이 보장되지 않습니다. 보류한 점과 직선으로 잔차를 따로 평가하세요. 원본 점에 결과 아핀 변환을 적용한 다음 해당 대상 직선과의 거리를 확인합니다. 원본 점을 변환 없이 대상 직선에 대입하는 검사는 일반적으로 올바른 잔차가 아닙니다.
