공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    componentsint필수전경 연결 성분 수입니다.
    holesint필수외곽 배경에 연결되지 않은 구멍 수입니다.
    eulerint필수전경 성분 수에서 구멍 수를 뺀 값입니다.

    연결과 구멍

    RegionTopology는 연결 성분의 수 components, 외부 경계에 연결되지 않은 배경 영역의 수 holes, 그리고 이 둘의 차인 euler를 함께 표현합니다. 이는 크기나 중심이 아니라 마스크가 몇 개의 조각과 구멍으로 이루어졌는지를 요약한 값입니다. 전경을 정하는 마스크와 연결 조건에 따라 수가 달라집니다.

    오일러 수 계산

    연결된 고리 하나 안에 구멍이 하나 있으면 components는 1이고 holes는 1이므로 euler는 0입니다. 같은 고리의 구멍이 채워져 연결 성분 하나만 남으면 holes는 0이고 euler는 1이 됩니다. 두 값의 차이가 같을 수 있으므로 euler 하나만으로 서로 다른 모든 모양을 구분할 수는 없습니다.

    사용 순서

    영상에서 전경을 선택하고 연결 조건을 결정한 뒤 위상 결과의 세 항목을 함께 비교합니다. 객체의 면적을 기준으로 필터링하거나 작은 틈을 메우면 연결 성분 또는 구멍 수가 바뀔 수 있습니다. 전체 영상에서 잘린 영역에서는 경계와 맞닿는 배경이 내부 구멍과 다르게 해석되므로 관심 영역을 정한 뒤 결과를 확인해야 합니다.

    예를 들어 서로 떨어진 원판 두 개는 성분 2개와 구멍 0개로 오일러 수가 2입니다. 성분 하나와 구멍 하나인 고리는 오일러 수가 0이므로 단순히 전경 픽셀 수가 같아도 위상은 서로 다를 수 있습니다.
