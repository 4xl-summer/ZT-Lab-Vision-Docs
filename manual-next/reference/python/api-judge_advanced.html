Python API · judge_advanced

judge_advanced 멤버와 선언

공개 타입

zvision.judge_advanced: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inspection_advanced.judge_advanced.

결함 연결 요소를 추출하고 영역별 규칙으로 판정합니다.

Python
judge_advanced(mask, score, defect_spec, rules)

인자 선언

  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • score · POSITIONAL_OR_KEYWORD · 기본값 없음
  • defect_spec · POSITIONAL_OR_KEYWORD · 기본값 없음
  • rules · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

mask
Gray8 결함 마스크.
score
같은 기하의 GrayF64 점수 영상; 전경 값은 유한한 0 이상.
defect_spec
DefectSpec 연결성과 분류·면적 조건.
rules
영역 및 개수·점수·길이 제한을 갖는 AdvancedRegionRule 시퀀스.

반환: 각 규칙의 AdvancedRegionDecision 독립 튜플.

오류: 유효하지 않은 영상 형식·기하·옵션 또는 계산 범위는 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    결함 마스크와 점수 영상, DefectSpec과 영역 규칙 목록을 받아 규칙마다 AdvancedRegionDecision을 반환합니다. 입력 마스크와 점수는 ZImage여야 하며 rules의 각 원소는 AdvancedRegionRule이어야 합니다. 후보 추출 설정과 영역별 허용치를 분리해 전달합니다.

    규칙은 사각형, 스크래치 및 표면 후보 수, 점수와 형상 한도를 담습니다. 예를 들어 특정 영역에서 스크래치 최대 개수를 0으로 정했다면 해당 영역 판정의 passed와 scratch_count, 위반 인덱스를 확인합니다. 여러 영역을 사용할 때 결과는 입력 규칙의 순서로 해석합니다.

    함수는 네이티브 판정 결과에서 값과 인덱스를 복사하고 내부 소유 객체를 닫습니다. 반환된 결정 튜플은 별도 핸들 해제가 필요한 이미지가 아닙니다. 정렬 실패나 잘못된 마스크를 후보가 없는 통과로 바꾸지 않으며, 원본 마스크와 점수의 기하가 대응하는지 확인합니다.

    각 규칙의 영역과 한도를 결과와 연결해서 기록하면 같은 후보가 어떤 조건에서 문제가 되었는지 재검토할 수 있습니다. 입력 영상이나 점수의 좌표계가 바뀐 경우 이전 규칙을 그대로 재사용하지 않습니다.
