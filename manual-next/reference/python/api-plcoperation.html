열거 값

  • REQUEST = 1 · 새 요청을 시작합니다.
  • PUBLISH = 2 · 요청 결과를 게시합니다.
  • ACK = 3 · 준비된 결과를 확인합니다.
  • POLL = 4 · 상태와 시간 초과를 확인합니다.
  • RESET = 5 · 오류 상태를 초기화합니다.

사용 맥락과 계약

PlcOperation은 모의 요청·결과 핸드셰이크에 적용할 명령 종류입니다. REQUEST는 새 요청을 시작하고 PUBLISH는 그 요청의 결과 코드를 기록합니다. ACK는 준비된 결과를 확인하여 대기 상태로 돌립니다. POLL은 호출자가 넘긴 시각으로 제한 시간을 평가하고, RESET은 오류 상태를 초기화합니다. 명령의 종류에 따라 필요한 request_id와 result_code 조건이 다릅니다.

구체 사례와 판독

예를 들어 ID 1을 REQUEST하고 같은 ID로 결과 42를 PUBLISH한 뒤 ID 1을 ACK하면 한 건의 완료 흐름이 됩니다. 서로 다른 ID로 결과를 게시하거나 결과가 준비되기 전에 확인하면 같은 흐름이 아닙니다. now_ns는 호출자가 제공하는 나노초 시각이며 이전 명령 시각보다 뒤로 가야 합니다. 이 API는 PLC 네트워크 전송이 아닌 시뮬레이터이므로 실제 장비 통신은 별도의 ModbusTcp 계약과 시험을 확인하세요.

적용 시 확인

동일 ID로 결과를 다시 게시하는 중복 경로와 새로운 ID의 정상 요청은 통계상 다른 사건입니다. 시간 초과는 임의의 호출이 아니라 명시적 POLL에서 평가되므로 호출 시각도 기록해야 합니다.
