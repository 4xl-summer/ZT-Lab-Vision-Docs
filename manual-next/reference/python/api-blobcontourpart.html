시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

BlobContourPart(<class 'bool'>, <class 'tuple'>) 생성자 설명

공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    closedbool필수닫힌 입력 전체가 선택된 경우에만 참입니다.
    pointstuple필수선택된 연속 윤곽 점입니다.

    연속된 윤곽 일부

    BlobContourPart는 윤곽에서 선택한 연속 점과 closed 플래그를 담습니다. 점들은 선택된 순서를 유지하며 입력이 닫힌 경계였더라도 그 일부만 선택했다면 그 부분을 자동으로 닫힌 도형으로 취급하지 않습니다.

    닫힘 조건

    closed는 닫힌 입력 전체가 선택된 경우에만 참입니다. 예를 들어 원래 고리에서 짧은 호만 추출했다면 호의 양 끝을 직선으로 연결하지 않습니다. 이를 임의로 연결하면 실제 선택 경로에 없던 선분이 추가되어 길이나 도형 해석이 달라집니다.

    좌표와 비교

    선택된 points를 해당 윤곽의 좌표계에서 읽고 원본 위에 겹쳐 확인합니다. 입력 윤곽을 ROI에서 얻었다면 다른 영상에 표시할 때 원점을 맞추어야 합니다. 동일한 길이의 두 부분이라도 선택 위치와 방향이 다를 수 있으므로 점 순서와 위치를 함께 비교합니다.

    후속 사용

    부분 경로의 길이 또는 다른 경로까지의 거리를 계산할 때 closed 값을 함께 전달하는 API가 있다면 이 플래그에 맞춥니다. 전체 물체의 외곽과 일부 호를 혼동하면 물체 전체 둘레나 면적으로 잘못 해석할 수 있습니다.

    추출 전의 전체 경로와 추출 후 부분 경로를 함께 표시하면 선택한 구간이 경계를 따라 연속적으로 유지됐는지 쉽게 점검할 수 있습니다.
