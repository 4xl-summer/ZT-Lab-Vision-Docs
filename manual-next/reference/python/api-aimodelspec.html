    사용과 결과 해석

    AiModelSpec은 고정 모델의 task, width, height, channels, classes, model_version을 담습니다. 너비와 높이는 각각 1 이상이며 바인딩은 픽셀 곱이 1,048,576을 넘지 않도록 검사합니다. 채널 수는 1 또는 3입니다. 모델이 학습할 때 사용한 입력과 이 계약이 일치하는지 확인해야 합니다.

    클래스 수 범위는 작업에 따라 달라집니다. 분류와 분할은 최소 2개, 이상 작업은 정확히 1개이며 일반 상한은 256입니다. 예를 들어 640×480은 307,200 픽셀로 픽셀 수 제한 이내지만 이것만으로 채널 형식이나 모델 바이트가 적합하다는 뜻은 아닙니다.

    model_version은 호출자가 제공하는 1 이상의 추적 식별자입니다. 값이 바뀌었다고 모델 파일의 내용이나 정확도가 자동 검증되는 것은 아닙니다. 실행 결과에 기록된 버전, 입력 영역과 작업을 보관하고 잘못된 크기나 클래스 수로 인한 예외는 추론 실패로 처리합니다.

    설정 검증이 통과하더라도 모델이 실제 현장의 영상에 잘 동작하는지는 별도입니다. 특히 입력의 채널 순서, 영상 크기와 영역은 실행 시 제공한 데이터와 함께 살펴야 합니다.
