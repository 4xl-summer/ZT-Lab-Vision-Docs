rows: 격자 행 수로 양의 정수이며 열 수와의 곱은 1000000 이하여야 합니다.

columns: 격자 열 수로 양의 정수이며 행 수와의 곱은 1000000 이하여야 합니다.

pitch_x: 가로 점 간격으로 지정 길이 단위의 유한한 양수입니다.

pitch_y: 세로 점 간격으로 지정 길이 단위의 유한한 양수입니다.

unit: 격자 물리 좌표의 길이 단위입니다.
