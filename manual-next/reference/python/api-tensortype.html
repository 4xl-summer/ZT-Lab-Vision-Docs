사용과 결과 해석

TensorType은 텐서 원소의 표현을 지정합니다. F32=0은 32비트 부동소수, I32=1은 32비트 부호 정수, I8=2는 8비트 부호 정수, U8=3은 8비트 부호 없는 정수입니다. Tensor.create에 형식과 shape, values를 전달하며 기본 형식은 F32입니다.

정수 입력은 형식 범위가 검사됩니다. 예를 들어 I8은 -128부터 127까지이고 U8은 0부터 255까지이므로 256은 U8 입력으로 허용되지 않습니다. shape가 (2,3)이면 원소 수는 6이어야 합니다. 차원은 양의 정수이고 차원 수는 최대 32입니다.

모델이 요구하는 텐서의 자료형을 지정하지 않고 단순히 수치만 맞추면 추론 입력 계약이 달라질 수 있습니다. Tensor.read는 dtype, shape와 네이티브 순서의 값 복사본을 반환합니다. 텐서 핸들은 사용 후 닫고 읽은 튜플과 동일한 소유 자원으로 혼동하지 않습니다.

차원과 원소 수가 맞더라도 모델이 요구하는 축 순서가 일치해야 올바른 입력입니다. 반환된 데이터의 형식과 순서를 읽은 뒤 모델의 입출력 명세와 대조합니다.

차원마다 길이를 곱한 값이 자료 개수와 정확히 같아야 합니다.
