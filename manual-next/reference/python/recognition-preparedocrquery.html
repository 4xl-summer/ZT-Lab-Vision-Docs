Python API · PreparedOcrQuery

PreparedOcrQuery 멤버와 선언

공개 타입

zvision.PreparedOcrQuery: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition.PreparedOcrQuery.

Base class for typed recognition query terminals.

이 Query는 변경 가능한 계획입니다. 단계 추가는 같은 객체를 갱신하므로 별칭에도 반영됩니다. 분기하려면 clone()을 사용하고 execute()로 실행합니다. 실행과 Query는 각각 닫아야 합니다. 실패한 단계 추가는 기존 계획을 바꾸지 않습니다.

Python
PreparedOcrQuery()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
