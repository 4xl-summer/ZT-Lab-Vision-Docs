guided_filter 멤버와 선언

공개 타입

zvision.guided_filter: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._frequency_processing.guided_filter.

영상과 선택 가이드의 국소 통계로 평활화합니다.

Python
guided_filter(image, options, guide=None)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • guide · POSITIONAL_OR_KEYWORD · 기본값 None

확인된 인자 조건

image
ZImage 입력 영상
options
GuidedOptions; 반경, 양의 epsilon, 경계와 출력 형식을 지정
guide
선택 가이드 ZImage; None이면 입력 image를 가이드로 사용, 기본값 None

반환: 별도로 close할 ZImage

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    가이드로 경계를 보존하는 평활화

    입력 영상을 가이드 영상의 국소 구조에 따라 평활화합니다. 노이즈를 줄일 때 단순한 평균과 달리 가이드에 나타난 경계가 결과에 영향을 줍니다. 가이드가 별도 영상이면 두 영상이 같은 공간의 같은 위치를 나타내도록 정렬되어 있어야 결과를 올바르게 해석할 수 있습니다.

    반경과 정규화

    옵션에는 국소 영역 반경과 정규화 epsilon이 포함됩니다. 반경을 조정하면 한 위치를 계산할 때 고려하는 주변 범위가 달라지고 epsilon은 국소 모델의 정규화에 영향을 줍니다. 값 하나만으로 모든 영상에서 최적의 경계 보존이 보장되는 것은 아니므로 잡음과 작은 구조를 함께 관찰합니다.

    가이드 선택

    guide를 지정하지 않으면 입력 image가 가이드로 사용됩니다. 별도 가이드를 쓰는 경우에는 구조가 일치하는지 확인한 뒤 입력, 가이드, 출력의 같은 위치를 비교합니다. 평활화 후 임계 처리나 측정을 한다면 원본의 약한 경계가 어떻게 달라졌는지도 중간 결과에서 확인합니다.

    별도 가이드에만 있는 강한 패턴도 출력 구조 해석에 영향을 줄 수 있습니다. 입력과 가이드의 정렬이 틀어져 있지 않은지 먼저 확인하고, 경계가 있는 위치에서 원본과 결과를 나란히 관찰합니다.
