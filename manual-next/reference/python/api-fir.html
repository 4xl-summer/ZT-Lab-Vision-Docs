Python API · fir

fir 멤버와 선언

공개 타입

zvision.fir: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._processing_advanced.fir.

Separable FIR correlation. Kernels are odd-length numeric sequences.

분리 가능한 1차원 커널 두 개로 FIR 상관을 수행합니다.

Python
fir(image, kernel_x, kernel_y, border=0, constant=0.0, format=1)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • kernel_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • kernel_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • border · POSITIONAL_OR_KEYWORD · 기본값 0
  • constant · POSITIONAL_OR_KEYWORD · 기본값 0.0
  • format · POSITIONAL_OR_KEYWORD · 기본값 1

확인된 인자 조건

image
ZImage 입력
kernel_x
홀수 길이 수평 커널
kernel_y
홀수 길이 수직 커널
border
경계 코드 0~2
constant
상수 경계값
format
출력 형식 코드 1~3

반환: 별도 close할 ZImage

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

border: 정수 검사 · 최소 0.

format: 정수 검사 · 최소 1.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    fir는 가로와 세로의 1차원 커널을 차례로 적용하는 분리형 FIR 필터입니다. kernel_x와 kernel_y는 각각 홀수 길이로 지정하고 border는 복제, 반사, 상수 경계 중 하나를 선택합니다. 상수 경계를 선택한 경우 constant가 영상 밖 샘플에 쓰이며 format은 출력 형식을 지정합니다. 반환 영상은 입력을 덮어쓰는 설정값이 아니라 별도로 관리할 결과입니다.

    구체 사례와 판독

    예를 들어 가로 커널 [0.25, 0.5, 0.25]와 세로 커널 [1]을 사용하면 가운데 픽셀은 좌우 이웃과 자기 자신의 가중합이 됩니다. 이웃이 0, 4, 0이면 결과는 2입니다. 가장자리에서는 없는 이웃을 어떤 방식으로 채우는지가 달라지므로 같은 커널이라도 결과가 다를 수 있습니다. 출력 형식의 정밀도와 값 범위를 확인한 뒤 임계값 처리에 연결하세요.

    적용 시 확인

    커널 합이 1인 평활 필터와 합이 0인 차분 필터는 결과 의미가 다릅니다. 계산하려는 목적에 맞춰 계수와 출력 형식을 정하세요. 영상의 경계와 내부를 따로 검토해야 경계 확장 효과를 구분할 수 있습니다. 예제처럼 중심 계산을 손으로 대조하고 가장자리는 선택한 경계 규칙으로 따로 계산합니다. 계수와 경계 옵션을 기록해 결과를 재현할 수 있습니다.
