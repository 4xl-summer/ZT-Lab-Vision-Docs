사용과 결과 해석

프로파일의 시작점에서 끝점으로 이동하면서 밝기가 증가하는 경계를 상승, 감소하는 경계를 하강으로 구분합니다. 양쪽을 허용하면 증가와 감소 후보를 모두 고려합니다. 이 방향은 영상의 절대적인 위·아래나 왼쪽·오른쪽과 같다고 단정할 수 없으며, 사용자가 정한 선분 진행 방향에 달려 있습니다. 예를 들어 왼쪽의 어두운 영역에서 오른쪽의 밝은 영역으로 읽으면 상승 에지가 되지만 같은 선분을 반대로 읽으면 하강으로 나타납니다. 반환된 강도는 원시 강도의 픽셀당 변화이며 하강 시 부호가 음수일 수 있습니다. 지정한 극성에 맞는 피크가 없을 때의 빈 결과와 잘못된 선분이나 영상 형식으로 발생하는 오류를 구별하십시오. 임계값은 밝기 그 자체가 아니라 기울기의 크기에 적용됩니다. 예를 들어 프로파일 진행 방향에서 강도가 0에서 80으로 증가하면 상승 경계이고 진행 방향을 뒤집어 읽으면 같은 물리 경계가 하강으로 나타납니다. 화면의 왼쪽이나 오른쪽만 보고 극성을 정하지 말고 실제 시작점과 끝점을 기준으로 판독하십시오. 두 경계가 함께 보이는 띠에서는 진입과 이탈의 부호가 서로 다를 수 있습니다. 선택한 극성과 에지 순서를 함께 점검해 목적 경계가 선택됐는지 확인합니다.
