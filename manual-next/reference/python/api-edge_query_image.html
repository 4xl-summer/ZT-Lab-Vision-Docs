zvision.edge_query_image: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._edge_query_result.edge_query_image.

0 이상의 유한한 낮은 기울기 임계값

에지 추출 작업량 상한

query_budget
질의 생성 작업량 상한
