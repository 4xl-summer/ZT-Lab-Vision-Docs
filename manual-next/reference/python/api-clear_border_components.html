Python API · clear_border_components

clear_border_components 멤버와 선언

공개 타입

zvision.clear_border_components: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._regions_flexible.clear_border_components.

Remove components touching the ROI boundary band, with margin zero at its edge.

ROI 경계 띠에 접하는 전경 성분을 제거합니다.

Python
clear_border_components(image, connectivity, margin)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • connectivity · POSITIONAL_OR_KEYWORD · 기본값 없음
  • margin · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력 영상
connectivity
연결성 4 또는 8
margin
ROI 경계에서의 띠 두께(픽셀)

반환: 별도로 close할 ZImage

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

margin: 정수 검사.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    경계 접촉 성분 제거

    전경 연결 성분 중 ROI 경계 또는 지정한 경계 띠에 닿는 성분을 제거합니다. 영상 밖에서 잘린 객체를 측정 대상에서 제외할 때 유용하지만 경계에 닿은 정상 객체도 함께 제거될 수 있습니다. 경계 여부는 전체 촬영 영상이 아니라 연산이 받는 ROI의 경계를 기준으로 판단합니다.

    연결성과 여백

    연결성은 이웃 픽셀이 같은 성분으로 묶이는 방식을 정하고 margin은 경계에서 안쪽으로 고려할 띠의 두께를 픽셀 단위로 지정합니다. 서로 대각선으로만 맞닿은 두 영역이 하나로 묶이면 한쪽의 경계 접촉으로 성분 전체가 제거될 수 있으므로 연결 설정을 먼저 고정해 비교합니다.

    검사 순서

    이진 전경 마스크를 준비하고 연결 방식과 여백을 정한 뒤 처리를 적용합니다. 결과에서 제거된 영역을 원본 마스크와 비교해 의도한 절단 객체만 빠졌는지 확인합니다. ROI를 좁히면 이전에는 내부였던 물체가 새로운 경계에 닿을 수 있으므로 ROI 변경 후에는 같은 설정을 다시 평가해야 합니다.

    결과를 검사할 때 경계 접촉 여부만으로 객체가 불량인지 정상인지 판단하지 않습니다. 경계에 잘린 물체를 측정에서 제외하려는 것인지, 화면 안의 모든 물체를 계수하려는 것인지 목적부터 정해야 합니다.
