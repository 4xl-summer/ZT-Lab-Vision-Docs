Python API · measure_shapes

measure_shapes 멤버와 선언

공개 타입

zvision.measure_shapes: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._regions_flexible.measure_shapes.

Measure selected advanced Blob labels; an empty label list selects all.

선택한 Blob 레이블에 대해 형상 측정값을 구합니다.

Python
measure_shapes(source, labels, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • labels · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
열린 BlobResult입니다.
labels
측정할 u32 레이블 시퀀스이며 비면 전체를 선택합니다.
work_budget
양의 작업 상한입니다.

반환: 독립 FlexibleShape 목록입니다.

오류: 형식, 레이블 또는 작업량 조건이 유효하지 않으면 오류입니다.

work_budget: 정수 검사 · 최소 1.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    BlobResult에서 선택한 레이블의 기하·형상 값을 계산합니다. labels는 u32 레이블 시퀀스이며 비어 있으면 모든 성분을 선택합니다. 양의 work_budget으로 계산량을 제한하고 결과는 FlexibleShape 값 목록으로 복사됩니다. 소스 결과는 호출 중 열려 있어야 하며 잘못된 입력과 예산 초과는 오류입니다.

    각 형상의 영역과 중심, 회전 사각형 및 껍질 면적 등을 읽어 전경 성분을 비교할 수 있습니다. 예를 들어 원본 결과에서 두 레이블만 선택하면 그 두 성분에 대한 결과를 얻는 흐름입니다. 레이블 번호는 목록 인덱스와 혼동하지 않고, 영상의 ROI 로컬 좌표를 원본 영상의 좌표와 비교할 때 원점을 별도로 고려합니다. 비어 있는 레이블 목록이 아무 성분도 선택하지 않는다는 뜻은 아닙니다.

    값을 확인하는 순서

    source 항목: 열린 BlobResult입니다. labels 항목: 측정할 u32 레이블 시퀀스이며 비면 전체를 선택합니다. work_budget 항목: 양의 작업 상한입니다.

    항목읽을 때 확인할 내용

    work_budget양의 작업 상한입니다.
