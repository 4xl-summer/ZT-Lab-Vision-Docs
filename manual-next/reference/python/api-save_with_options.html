Python API · save_with_options

save_with_options 멤버와 선언

공개 타입

zvision.save_with_options: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._io_advanced.save_with_options.

Save a ZImage using explicit JPEG quality and PNG compression.

JPEG 품질 또는 PNG 압축을 지정해 영상을 저장합니다.

Python
save_with_options(image, path, jpeg_quality=75, png_compression=<PngCompression.FAST: 0>)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • path · POSITIONAL_OR_KEYWORD · 기본값 없음
  • jpeg_quality · POSITIONAL_OR_KEYWORD · 기본값 75
  • png_compression · POSITIONAL_OR_KEYWORD · 기본값 <PngCompression.FAST: 0>

확인된 인자 조건

image
ZImage 입력
path
출력 경로
jpeg_quality
JPEG 품질 정수 1~100, 기본 75
png_compression
PngCompression, 기본 FAST

반환: None

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    save_with_options는 영상과 출력 경로를 받아 JPEG 품질 또는 PNG 압축 옵션을 지정하여 파일로 저장합니다. jpeg_quality는 1부터 100까지이고 기본값은 75이며 png_compression 기본값은 PngCompression.FAST입니다. 경로의 파일 형식에 맞는 옵션을 선택하고 반환된 영상이 있을 것으로 기대하지 마세요. 이 함수의 정상 반환은 None입니다.

    구체 사례와 판독

    예를 들어 한 입력을 JPEG 품질 75로 저장하고 PNG FAST로 별도 저장하면 두 파일은 서로 다른 인코딩을 거칩니다. JPEG는 손실 압축이므로 재로딩한 픽셀이 입력과 정확히 같다고 판정하는 검사를 쓰지 않아야 합니다. PNG 비교에서는 크기와 형식뿐 아니라 픽셀을 확인해 경로와 읽기 결과를 검증할 수 있습니다. 출력 위치의 쓰기 권한과 확장자를 함께 확인하세요.

    적용 시 확인

    품질 숫자가 높다고 처리 결과의 판정 정확도가 자동으로 보장되지는 않습니다. 재현이 필요하면 파일 형식과 설정값을 결과와 함께 남깁니다. JPEG 품질은 숫자 범위 안에서 정하고 용도에 따라 파일 크기와 재생성된 영상의 차이를 함께 확인합니다. 파일 이름만 바꿔 기존 파일 내용을 변환했다고 판단해서는 안 됩니다.
