    지정 방향의 투영 폭

    BlobFeretContacts는 선택 방향의 최소와 최대 투영 차이 width 및 양쪽 지지 껍질 꼭짓점의 ROI 로컬 좌표를 담습니다. 폭은 선택한 축에 대한 길이입니다. 두 지지점 사이의 유클리드 직선 거리가 언제나 투영 폭과 같다고 가정해서는 안 됩니다.

    투영 예

    어떤 방향에 투영한 최소값이 2이고 최대값이 7이면 폭은 7-2=5입니다. min_x와 min_y, max_x와 max_y는 이 극값에 해당하는 셀 껍질의 꼭짓점 위치를 나타냅니다. 방향이 바뀌면 극값과 접촉점도 달라질 수 있습니다.

    호출과 표시

    blob_feret_contacts에서 성분과 각도를 지정해 결과를 얻고 접촉점을 원래 마스크 위에 표시합니다. ROI 로컬 좌표를 전체 영상에 옮길 때 원점을 반영하고, 폭의 단위는 해당 픽셀 좌표 단위로 읽습니다.

    비교 조건

    물체가 회전하면 고정된 방향의 투영 폭이 달라질 수 있습니다. 물체 간 비교에 고정 방향을 쓸지 물체의 기준 방향을 쓸지 정하고 각도를 함께 기록하세요. 물리 단위 비교에는 픽셀 축 간격과 보정을 별도로 고려합니다.
