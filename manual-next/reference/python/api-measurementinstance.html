    사용과 결과 해석

    명시적으로 배치한 하나의 계측 인스턴스와 그 위치에서 얻은 복사된 측정 결과를 묶습니다. placement는 기준 형상에서 ROI로 가는 이동과 회전을 설명하고 result는 선 또는 원의 측정 결과입니다. 여러 인스턴스를 같은 프레임에서 실행하면 반환 목록의 각 배치와 결과를 함께 저장해 어느 위치의 결과인지 잃지 않도록 해야 합니다. 예를 들어 서로 다른 두 이동을 사용한 경우 첫 결과의 중심을 둘째 배치에 연결하면 각 수치가 유한해도 다른 물체의 치수를 보고하게 됩니다. 배치의 이동은 픽셀이고 각도는 시계 방향 라디안이며, 최종 관측 역시 해당 ROI 기준을 확인해야 합니다. 실패 상태도 결과에 포함되므로 단지 결과 객체가 존재한다는 이유로 피팅이 성공했다고 판정하지 마십시오. 개별 프로브의 관측과 최종 형상 상태를 함께 확인하고 결측을 좌표 0으로 치환하지 않습니다. 독립적으로 복사된 결과는 후속 보관에 유용하지만 다른 프레임에서 같은 배치가 정확하다는 뜻은 아닙니다. 위치와 입력 영상의 ROI 원점을 실행마다 기록하십시오. 두 인스턴스가 같은 수의 프로브를 사용하더라도 각 위치에서 발견된 에지 수는 다를 수 있습니다. 각 결과의 관측과 형상 상태를 따로 확인하십시오.
