read_multiple_barcodes 멤버와 선언

공개 타입

zvision.read_multiple_barcodes: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._recognition_advanced.read_multiple_barcodes.

Return decoded symbols; use scan_multiple_barcodes for image statistics.

여러 바코드의 판독 결과를 반환합니다.

Python
read_multiple_barcodes(image, options, *, angle_range=None)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • angle_range · KEYWORD_ONLY · 기본값 None

image
Gray8 ZImage

오류: 타입, 범위, 형식 또는 네이티브 처리 검증 실패 시 오류가 전달됩니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    복수 바코드 판독에서 읽힌 항목만 튜플로 반환합니다. 내부적으로 scan_multiple_barcodes를 호출하고 그 결과의 reads를 선택합니다. 전체 입력 밝기 통계가 필요하면 scan_multiple_barcodes의 MultiBarcodeScan을 사용해야 합니다.

    image는 ZImage이고 options는 MultiBarcodeOptions입니다. angle_range가 있으면 최소, 최대, 간격 세 원소의 탐색 범위가 options에 설정한 각도 목록을 대체합니다. 각 읽기의 형식과 텍스트, raw_bytes, 위치 및 length_accepted를 개별적으로 확인합니다.

    검색은 설정한 형식과 각도 및 영상 품질에 따라 심볼을 놓칠 수 있습니다. 예를 들어 결과가 없다는 것은 해당 실행에서 읽은 항목이 없다는 뜻이며 모든 가능한 심볼이 없다는 보장은 아닙니다. 함수 실패 예외와 빈 튜플을 구분하고, 결과의 점을 원본 영상에 표시할 때 좌표계를 확인합니다.

    이미지 밝기 통계는 이 함수의 반환 튜플에는 포함되지 않습니다. 같은 조건에서 통계와 읽기를 함께 확인해야 한다면 두 차례의 별도 호출을 맞추기보다 스캔 결과 전체를 사용합니다.
