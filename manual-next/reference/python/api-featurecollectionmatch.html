    사용 맥락과 결과 해석

    여러 특징 모델 중 하나에 대해 수락된 결과입니다. id는 입력 모델 항목의 식별자이고 score는 대응점 수에 대한 내점 수의 비율입니다. bounds는 변환된 모델 특징점의 축 정렬 경계 [xmin,ymin,xmax,ymax]이며 result에 세부 대응과 행렬이 들어 있습니다. 점수가 확률이라는 의미는 아닙니다.

    예를 들어 대응 8개 중 6개가 내점이면 비율은 0.75입니다. 다만 내점 수가 적은 결과의 비율이 높을 수 있으므로 score와 함께 result의 inlier_count를 비교해야 합니다. 경계는 영상 로컬 좌표의 축 정렬 상자이므로 회전된 실제 외곽과 같지 않을 수 있습니다. 상위 보고서의 예산 종료 여부까지 확인해 전체 모델을 검사했는지 판단합니다.

    값을 확인하는 순서

    id 항목: 이 결과를 낸 모델 항목의 식별자입니다. score 항목: 대응점 수에 대한 내점 수의 비율입니다. bounds 항목: 변환된 모델 특징점의 축 정렬 경계 [xmin, ymin, xmax, ymax]입니다. result 항목: 해당 모델의 대응점과 변환 결과입니다.
