사용 맥락과 계약

PixelArithmetic은 영상의 대응 픽셀에 적용할 산술 연산을 지정합니다. ADD와 SUBTRACT는 더하기와 빼기, MULTIPLY와 DIVIDE는 곱하기와 나누기, MINIMUM과 MAXIMUM은 두 값 중 작은 값과 큰 값을 선택합니다. 연산 종류는 픽셀 쌍마다 적용할 규칙이며 전체 영상의 평균이나 전역 최소값을 구하는 통계 연산과 다릅니다.

구체 사례와 판독

예를 들어 두 대응 픽셀이 10과 3이면 더하기는 13, 빼기는 7, 최솟값은 3, 최댓값은 10입니다. 나누기는 입력 순서에 따라 10/3과 3/10이 달라지므로 좌우 피연산자를 확인해야 합니다. 저장 형식에 따라 표현 범위와 정밀도가 다를 수 있으며, 0으로 나누는 경우를 포함해 사용하는 실제 연산의 조건을 확인해야 합니다.

적용 시 확인

부호가 있는 중간 결과가 필요한 빼기와 비율의 소수 부분이 필요한 나누기는 결과 영상의 형식을 신중히 선택해야 합니다. 입력과 출력의 크기, 채널 및 지원 형식 조건은 실제 호출하는 연산의 계약을 확인하세요. 합성 결과를 검사 기준으로 사용할 때는 포화 또는 변환이 일어나는 위치를 작은 입력으로 먼저 시험하는 것이 좋습니다. 실수 출력과 정수 출력을 혼동하면 같은 입력의 나눗셈 결과를 다르게 해석하게 됩니다.
