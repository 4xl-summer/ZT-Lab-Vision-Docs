unit: 기준판 좌표와 이동의 길이 단위입니다.

max_iterations: 외부 반복 한도이며 1–25입니다.

damping: 초기 감쇠이며 유한한 양수입니다.

gradient_tolerance: 정규화 기울기 수렴 임계값이며 유한한 양수입니다.

optimize_camera: A←B 카메라 자세를 갱신할지 지정하며 기본값은 True입니다.

optimize_boards: 각 기준판 자세를 갱신할지 지정하며 기본값은 True입니다. 적어도 한 블록은 갱신해야 합니다.
