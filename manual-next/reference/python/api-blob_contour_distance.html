blob_contour_distance 멤버와 선언

공개 타입

zvision.blob_contour_distance: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_contour_distance.blob_contour_distance.

Return Euclidean minimum segment distance; each contour may be a point.

두 폴리라인의 선분 사이 최소 유클리드 거리를 구합니다.

Python
blob_contour_distance(first, first_closed, second, second_closed, work_budget)

  • second · POSITIONAL_OR_KEYWORD · 기본값 없음
  • second_closed · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

공개 멤버

    두 경로의 최단 거리

    blob_contour_distance는 두 폴리라인의 선분 사이 최소 유클리드 거리를 구합니다. 첫 경로와 두 번째 경로에 각각 Point2 시퀀스와 닫힘 여부를 지정하며 한 점으로 이루어진 입력도 허용됩니다. 경로 사이 거리이므로 중심점끼리의 거리나 두 영역의 면적과는 다른 값입니다.

    닫힘의 영향

    열린 경로는 나열된 인접 점을 잇고 닫힌 경로는 마지막과 처음의 연결도 고려합니다. 예를 들어 삼각형 점 세 개를 열린 경로로 취급하면 마지막과 첫 점 사이의 한 변이 빠집니다. 다른 경로가 그 누락된 변 가까이에 있으면 열린 경우와 닫힌 경우의 최단 거리가 달라질 수 있습니다.

    같은 좌표계

    두 경로의 좌표계와 단위를 맞춘 뒤 first_closed와 second_closed를 각각 지정하고 양의 work_budget을 전달합니다. ROI가 다른 두 경로를 로컬 좌표 그대로 비교하면 영상에서 서로 떨어진 점이 같은 좌표로 보일 수 있습니다. 필요한 경우 각각 전체 영상 기준으로 옮깁니다.

    결과 해석

    거리는 입력 좌표 단위로 해석합니다. 점 또는 선분 사이의 기하 거리이므로 픽셀 셀 경계 간 거리나 보정된 물리 거리가 필요하다면 해당 정의에 맞는 별도 연산과 보정이 필요합니다.
