Python API · absolute_difference_sharpness

absolute_difference_sharpness 멤버와 선언

공개 타입

zvision.absolute_difference_sharpness: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._sharpness_gap.absolute_difference_sharpness.

Mean absolute ROI-local pixel difference at nonzero displacement (dx,dy).

영상에서 지정 오프셋 픽셀의 평균 절대 차이를 계산합니다.

Python
absolute_difference_sharpness(image, dx, dy)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • dx · POSITIONAL_OR_KEYWORD · 기본값 없음
  • dy · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
ZImage 입력
dx
수평 변위(픽셀), 0 이상이며 영상 너비 미만
dy
수직 변위(픽셀), 0 이상이며 영상 높이 미만; dx와 동시에 0 불가

반환: 평균 절대 차이 실수

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

dx: 정수 검사.

dy: 정수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    absolute_difference_sharpness는 영상의 관심 영역에서 지정한 이동량 (dx,dy)만큼 떨어진 픽셀 쌍의 밝기 절대 차이를 평균합니다. dx와 dy가 모두 0일 수는 없습니다. 결과는 영상 밝기 단위의 차이이며 제곱 차이를 평균하는 gradient_energy_sharpness와 서로 다른 지표입니다.

    구체 사례와 판독

    예를 들어 가로로 한 픽셀 이동해 비교하는 쌍이 10과 14라면 이 쌍의 절대 차이는 4입니다. 여러 유효 쌍이 있으면 각 차이를 평균하므로 전체 결과가 반드시 4는 아닙니다. 이동량의 방향과 크기를 바꾸면 비교 대상이 달라지므로 초점 단계끼리 비교할 때 같은 dx,dy와 관심 영역을 유지해야 합니다.

    적용 시 확인

    선명도 수치는 확률이 아닙니다. 대비가 강한 무늬, 조명 변화 또는 잡음도 인접 픽셀 차이를 키울 수 있습니다. 비교하는 이미지의 픽셀 형식과 밝기 스케일을 맞추고 같은 영역에서 측정하세요. 계산 가능한 픽셀 쌍은 이동한 두 위치가 모두 관심 영역에 있어야 하므로 큰 이동량에서 비교 범위가 달라질 수 있습니다. 값이 커진 이유를 구별하려면 실제 영상과 비교 영역도 함께 확인합니다. 같은 장면에서 노출을 바꾸면 지표가 달라질 수 있습니다.
