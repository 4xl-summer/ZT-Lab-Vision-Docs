mesh_normals 멤버와 선언

공개 타입

zvision.mesh_normals: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._spatial3d_advanced.mesh_normals.

삼각형 면의 방향과 면적으로 정점 법선을 계산합니다.

Python
mesh_normals(cloud, faces)

인자 선언

  • cloud · POSITIONAL_OR_KEYWORD · 기본값 없음
  • faces · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

cloud
PointCloud: 좌표·결측과 길이 단위·frame을 가진 입력 점군
faces
각각 서로 다른 0 이상 정점 인덱스 3개를 담은 삼각형 목록

반환: 슬롯별 Point3 또는 None 목록입니다.

오류: 범위를 벗어나거나 반복된 정점 인덱스는 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    mesh_normals는 점군 슬롯을 정점으로 보고 삼각형 면 목록의 방향과 면적에 따라 정점별 법선을 구합니다. faces의 각 항목은 서로 다른 세 정수 인덱스이며 모두 점군 슬롯 범위 안이어야 합니다. 면의 정점 순서가 뒤집히면 외적 방향이 바뀌므로 같은 표면의 면들은 일관된 방향으로 준비해야 합니다. 예를 들어 XY 평면의 (0,0,0), (1,0,0), (0,1,0)은 주어진 순서에서 +Z 방향의 면 법선을 만듭니다.

    결측 정점을 포함하는 면이나 면적이 0인 면은 방향 기여가 없습니다. 해당 정점의 합산 방향이 없으면 출력 슬롯은 None이 될 수 있습니다. 잘못된 인덱스나 면에서 같은 정점을 중복하면 오류이므로 None 결과와 구별합니다. 반환 목록은 원본 슬롯 순서를 따르는 독립 값이며, 점군의 위치 및 unit과 면 연결을 함께 보관해야 해석할 수 있습니다. 생성한 법선은 원래 면의 연결 관계와 함께 기록해야 합니다.
