Python API · skeleton_graph

skeleton_graph 멤버와 선언

공개 타입

zvision.skeleton_graph: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._region_topology.skeleton_graph.

Return deterministic copied nodes and chains, with synthetic loop anchors.

골격을 분기 노드와 연결 경로로 변환합니다.

Python
skeleton_graph(image, options=GraphOptions(spacing_x=1.0, spacing_y=1.0, work_budget=100000000))

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 GraphOptions(spacing_x=1.0, spacing_y=1.0, work_budget=100000000)

확인된 인자 조건

image
ZImage 입력 영상
options
GraphOptions; 기본 간격 x=y=1.0, 작업량 100000000

반환: 독립 SkeletonGraph 스냅샷

오류: 입력 타입, 인자 또는 작업 예산이 유효하지 않으면 오류가 발생할 수 있습니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    영상에서 연결 그래프로

    skeleton_graph는 골격 영상에서 노드와 노드 사이의 경로를 복사해 SkeletonGraph로 반환합니다. 노드는 끝점이나 분기점 등을 나타내며 간선은 그 사이의 점들과 길이를 담습니다. 루프에 자연스러운 끝점이 없을 때도 합성 기준점으로 경로를 표현합니다.

    거리 간격

    기본 GraphOptions의 spacing_x와 spacing_y는 각각 1.0이며 작업량 한도는 100000000입니다. 픽셀 간격이 다를 때 한 칸의 수평 이동과 수직 이동은 서로 다른 실제 길이를 가질 수 있습니다. 지정한 축 간격의 단위를 기록하고 간선 길이를 그 단위로 해석합니다.

    연결 관계 확인

    먼저 세선화 결과가 충분히 수렴했는지 확인한 다음 그래프를 만들고 노드 수, 간선의 양 끝과 점 경로를 함께 살펴봅니다. 파이썬 래퍼는 반환할 노드와 간선을 복사한 뒤 임시 네이티브 결과 핸들을 해제합니다. 입력의 잡음이나 짧은 가지는 그래프의 분기 수에 영향을 줄 수 있습니다.

    예를 들어 가지가 하나 더 생기면 접합점의 차수와 간선 수가 함께 달라질 수 있습니다. 이런 차이는 원본 물체 형상뿐 아니라 세선화나 가지 제거 설정의 영향일 수 있으므로 처리 이력을 함께 기록합니다.
