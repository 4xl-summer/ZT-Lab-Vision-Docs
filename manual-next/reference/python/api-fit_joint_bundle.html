fit_joint_bundle 멤버와 선언

공개 타입

zvision.fit_joint_bundle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._rigid_frames.fit_joint_bundle.

Refine selected shared poses and Brown scalars against one reprojection objective.

선택한 자세와 렌즈 계수를 함께 재투영 오차에 맞춥니다.

Python
fit_joint_bundle(observations, lenses, cameras, boards, masks, options)

인자 선언

  • observations · POSITIONAL_OR_KEYWORD · 기본값 없음
  • lenses · POSITIONAL_OR_KEYWORD · 기본값 없음
  • cameras · POSITIONAL_OR_KEYWORD · 기본값 없음
  • boards · POSITIONAL_OR_KEYWORD · 기본값 없음
  • masks · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

observations
GraphObservation 3~32개, 각 관측에 4~256개 대응점
lenses
LensModel 2~8개
cameras
렌즈와 같은 수의 6성분 카메라 자세
boards
6성분 보드 자세 3~16개
masks
카메라별 내부 계수 마스크
options
JointBundleOptions 단위, 자세 마스크 및 최적화 한도

반환: 최적화된 자세·렌즈·진단을 담은 JointBundleResult

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
