CompositeModelBuilder 멤버와 선언

공개 타입

zvision.CompositeModelBuilder: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._composite_metrology.CompositeModelBuilder.

Build fixed and derived features, then evaluate a snapshot.

Each add method returns its zero-based index. References and frame parents must
refer to earlier entries. `None` denotes the ROI-local root frame. x points right,
y down; fixture angle is clockwise radians and distances are ROI-local pixels.
This builder also supports image line/circle/ellipse/rectangle features.
Input coordinates are ROI-local pixels; optional isotropic output scale is not a global/world calibration.
