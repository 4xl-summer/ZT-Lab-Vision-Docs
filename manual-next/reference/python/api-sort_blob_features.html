Python API · sort_blob_features

sort_blob_features 멤버와 선언

공개 타입

zvision.sort_blob_features: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_feature_sort.sort_blob_features.

Return stable zero-based Blob indices sorted by existing feature 0..9.

지정 특성으로 Blob의 원래 인덱스를 안정적으로 정렬합니다.

Python
sort_blob_features(source, feature, ascending, work_budget)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • feature · POSITIONAL_OR_KEYWORD · 기본값 없음
  • ascending · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

source
열린 BlobResult입니다.
feature
정렬 특성 ID 0..9입니다.
ascending
오름차순이면 True인 bool입니다.
work_budget
양의 작업 상한입니다.

반환: 정렬된 0 기반 인덱스 튜플입니다.

오류: 타입, 특성, Blob 개수 또는 작업량이 잘못되면 오류입니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    기존 BlobResult의 성분 인덱스를 선택한 특성으로 안정 정렬합니다. feature는 0..9의 특성 ID, ascending은 정렬 방향 bool이고 work_budget은 양의 작업 상한입니다. 반환은 원래 BlobResult에 대한 0 기반 인덱스 튜플이므로 성분 값을 직접 복제하거나 원본 결과 순서를 변경하지 않습니다.

    예를 들어 면적 기준을 선택해 오름차순으로 정렬하면 반환 인덱스를 원본 성분 목록에 적용하여 작은 성분부터 읽습니다. 같은 값을 가진 항목은 안정 순서가 유지됩니다. 지원 ID, 예산 및 성분 수 상한을 벗어나면 오류이며 빈 결과를 성공으로 가장하지 않습니다. 사용할 특성 ID의 의미와 방향을 결과와 함께 기록해야 합니다.

    값을 확인하는 순서

    source 항목: 열린 BlobResult입니다. feature 항목: 정렬 특성 ID 0..9입니다. ascending 항목: 오름차순이면 True인 bool입니다. work_budget 항목: 양의 작업 상한입니다.
