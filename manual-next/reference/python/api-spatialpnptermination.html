사용과 결과 해석

SpatialPnpTermination은 비평면 자세 추정에서 선택적 국소 정련이 어떻게 끝났는지 나타내는 열거값입니다. NOT_REQUESTED는 정련 횟수를 0으로 두어 초기 자세만 사용한 경우이고 CONVERGED는 정련의 종료 기준에 도달한 경우입니다. ITERATION_LIMIT은 허용한 반복 수를 다 쓴 상태, NO_PROGRESS는 더 개선할 수 없어 멈춘 상태를 가리킵니다. 값은 각각 0, 1, 2, 3입니다.

이 상태는 자세의 물리 정확도를 나타내는 합격 판정이 아닙니다. 예를 들어 CONVERGED이어도 최종 재투영 RMS가 사용자가 정한 픽셀 공차보다 클 수 있습니다. 결과의 초기와 최종 RMS, 실제 반복 수, 사용한 카메라 내참수와 입력 대응점을 함께 기록합니다. 자세를 아예 얻지 못한 경우는 이 종료값만으로 설명할 수 없으며 SpatialPnpOutcome의 실패 단계와 estimate 유무를 확인해야 합니다. 최종 판단에는 독립 보류점이 필요합니다.
