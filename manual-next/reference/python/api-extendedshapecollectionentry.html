    사용 맥락과 결과 해석

    타입 지정 ExtendedShapeModel과 고유 id를 하나로 묶어 형상 모델 컬렉션 검색에 전달합니다. 검색 함수가 내부적으로 형상 컬렉션 입력으로 변환하므로 id는 같은 호출의 다른 항목과 중복되지 않아야 합니다. model은 검색 도중 유효한 소유 모델이어야 합니다.

    예를 들어 서로 다른 두 부품을 모델 10과 20으로 등록하면 반환 항목 id로 어떤 모델이 후보를 만들었는지 구분할 수 있습니다. 검색 격자 및 후보 예산은 항목이 아니라 공통 옵션에 지정합니다. 결과 개수는 중복 억제와 전체 예산의 영향을 받으며 id는 결과 목록의 인덱스와 다릅니다. 사용 후 모델은 별도로 닫습니다.

    공통 검색 옵션의 후보 예산과 전체 컬렉션 예산은 서로 다른 제한입니다. 모델 수가 많으면 결과가 비었다는 사실과 전체 모델 평가 완료 여부를 구분해 보고서를 확인해야 합니다. 중복 id를 허용하면 모델 출처를 구분할 수 없으므로 입력 검증에서 거절됩니다. 검색된 항목의 식별자는 결과의 각 매치에 남습니다.
