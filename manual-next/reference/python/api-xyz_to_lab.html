Python API · xyz_to_lab

xyz_to_lab 멤버와 선언

공개 타입

zvision.xyz_to_lab: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._color_advanced.xyz_to_lab.

Convert same-observer XYZ GrayF64 planes using caller-supplied XYZ white.

동일 관찰자의 XYZ 평면을 지정 백색점의 Lab 평면으로 변환합니다.

Python
xyz_to_lab(x, y, z, white)

인자 선언

  • x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • z · POSITIONAL_OR_KEYWORD · 기본값 없음
  • white · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

x
X GrayF64 평면.
y
x와 같은 기하의 Y GrayF64 평면.
z
x와 같은 기하의 Z GrayF64 평면.
white
유한한 양의 XYZ 백색점 성분 3개.

반환: 호출자가 close할 XyzLabResult 소유 객체.

오류: 형식·기하·백색점 또는 값이 유효하지 않으면 오류.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    같은 관측자 조건의 XYZ GrayF64 세 평면과 기준 백색점으로 Lab 평면을 생성합니다. x, y, z는 각각 ZImage이고 white는 세 원소의 XYZ 값입니다. 반환된 XyzLabResult에서 세 채널을 획득하여 L, a, b를 읽을 수 있습니다.

    백색점은 세 좌표의 기준이므로 white의 단위와 XYZ 평면의 스케일 및 관측 조건이 서로 맞아야 합니다. 같은 물체를 서로 다른 백색점으로 계산한 Lab 수치를 조건 없이 직접 비교하지 않습니다. white의 원소가 세 개가 아니면 바인딩이 ValueError를 발생시킵니다.

    입력은 변환 중 함께 잠기고 결과 객체와 각 채널은 별도 소유 자원으로 반환됩니다. 사용이 끝나면 결과와 얻은 영상을 각각 닫습니다. 이 함수는 RGB 감마 해제나 임의의 관측자 간 변환을 추정하는 기능이 아니라 전달한 XYZ와 white를 사용한 변환입니다.

    예를 들어 같은 좌표의 X, Y, Z 값이 하나의 픽셀 색을 구성하므로 입력 평면의 영역과 해상도는 서로 대응해야 합니다. 반환 평면의 같은 위치를 조합해 결과를 해석합니다.

    출력과 참조의 백색점이 일치하는지 수치를 비교하기 전에 확인합니다.
