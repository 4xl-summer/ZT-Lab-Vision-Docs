    사용 맥락과 결과 해석

    다중 모델·다중 인스턴스 검색에서 선택된 한 결과입니다. id는 입력 모델의 식별자이고 score는 지지 점수입니다. corners는 방향이 있는 네 좌표쌍, matrix는 모델에서 검색 영상으로 가는 3×3 행 우선 변환입니다. inliers와 evaluated는 기하 검증의 내점 수와 가설 평가 수를 나타냅니다.

    반환된 네 모서리와 행렬의 좌표 프레임을 검색 ROI와 맞춘 뒤 다른 영상에 표시합니다. id는 결과 배열의 위치가 아니라 모델을 구분하는 값입니다. 겹침 억제 이후 선택된 항목이므로 반환 개수만으로 원래 검출된 전체 후보 수를 알 수 없습니다. 상위 보고서의 incomplete를 확인해 공유 예산으로 검색이 중단되었는지도 판독합니다.

    값을 확인하는 순서

    id 항목: 해당 결과를 낸 모델의 식별자입니다. score 항목: 검출된 인스턴스의 지지 점수입니다. corners 항목: 변환된 네 모서리의 좌표쌍 튜플입니다. matrix 항목: 모델에서 검색 영상으로 가는 3×3 행 우선 변환입니다. inliers 항목: 인스턴스의 내점 수입니다. evaluated 항목: 이 결과와 관련된 평가 가설 수입니다.
