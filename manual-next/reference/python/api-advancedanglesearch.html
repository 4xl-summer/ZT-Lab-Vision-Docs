    사용과 결과 해석

    고급 캘리퍼 탐색 방향에 더할 각도 구간과 각도 표본 간격, 허용 오차를 지정합니다. min_angle과 max_angle은 포함되는 탐색 양 끝이며 라디안으로 표현합니다. angle_step은 표본 간격의 상한이고 max_angle_error는 실제 간격의 절반 이상이어야 하는 오차 한계입니다. 예를 들어 시작과 끝이 같으면 방향 후보가 하나이므로 실제 간격은 0입니다. 양 끝이 다른 경우 구현은 구간을 균등하게 나누므로 실제 간격은 지정한 최대 간격 이하가 됩니다. 각도가 유한하지 않거나 순서가 뒤집히거나 양수가 아닌 간격을 넣으면 오류입니다. 탐색 결과의 선택 각도와 에지 목록을 함께 확인하고, 각도 탐색 범위를 넓히는 것이 실제 장비의 각도 정밀도를 자동으로 높인다고 판단하지 마십시오. 예를 들어 기준 방향 주변을 여러 각도로 살피면 동일한 선분 하나만 사용할 때와 다른 에지가 후보가 될 수 있습니다. 선택된 방향을 결과와 함께 기록해 어떤 단면에서 에지가 나왔는지 확인합니다. 각도 범위와 간격을 바꿀 때 탐색 후보가 바뀌는 효과를 함께 고려하십시오. 방향의 각도는 라디안으로 입력하므로 화면에서 읽은 도 값을 변환 없이 넘기지 마십시오. 선택 각도도 같은 단위로 기록합니다.
