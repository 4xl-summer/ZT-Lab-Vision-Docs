rank_with_care_mask 멤버와 선언

공개 타입

zvision.rank_with_care_mask: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._masked_gap.rank_with_care_mask.

Select rank from nonzero care samples; empty neighborhoods are errors.

care 표본에서 지정 분위의 값을 선택합니다.

Python
rank_with_care_mask(image, mask, width, height, anchor_x, anchor_y, quantile=0.5, offset_x=0, offset_y=0, border=0, output_format=<PixelFormat.GRAYF32: 3>)

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mask · POSITIONAL_OR_KEYWORD · 기본값 없음
  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • anchor_x · POSITIONAL_OR_KEYWORD · 기본값 없음

  • offset_x · POSITIONAL_OR_KEYWORD · 기본값 0
  • offset_y · POSITIONAL_OR_KEYWORD · 기본값 0

확인된 인자 조건

image
입력 ZImage입니다.
mask
0이 아닌 값을 care로 사용하는 Gray8 마스크 ZImage입니다.
width
양의 창 너비 픽셀 수입니다.
height
양의 창 높이 픽셀 수입니다.
anchor_x
창 안의 0부터 시작하는 X 앵커입니다.
anchor_y
창 안의 0부터 시작하는 Y 앵커입니다.
quantile
0–1 분위이며 기본값은 0.5입니다.
offset_x
영상 ROI 기준 마스크 X 오프셋이며 기본값은 0입니다.
offset_y
영상 ROI 기준 마스크 Y 오프셋이며 기본값은 0입니다.
border
경계 정책 정수이며 기본값은 0입니다.
output_format
Gray8, Gray16 또는 GrayF32 출력이며 기본값은 GrayF32입니다.

반환: 호출자가 닫아야 하는 독립 ZImage입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

border: 정수 검사 · 최소 0.

width: 정수 검사 · 최소 1.

height: 정수 검사 · 최소 1.

anchor_x: 정수 검사.

anchor_y: 정수 검사.

quantile: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.
