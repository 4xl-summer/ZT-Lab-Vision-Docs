사용 조건과 흐름

ControlledEccInput은 controlled_ecc_decode에 전달하는 이미지가 일반 영상인지 이미 샘플된 모듈 격자인지를 선택합니다. IMAGE는 영상에서 심볼을 검출하는 경로이고 MODULES는 바로 선 흑백 모듈 격자를 사용하는 경로입니다. QR과 Data Matrix 중 어느 형식인지는 ControlledEccFormat에서 따로 지정합니다.

구체 사례와 결과 판독

예를 들어 모듈 하나를 1픽셀로 표현한 격자에서는 MODULES를 선택하고, 카메라에서 취득한 Gray8 장면에서는 IMAGE 경로를 선택합니다. 두 경로를 혼동하면 검출 또는 샘플링 단계의 전제가 달라집니다. 정정 사용 여부와 블록별 허용량은 입력 종류와 별개입니다. 반환 텍스트와 정정 진단, accepted를 모두 확인하세요.

적용 시 확인

MODULES 경로는 격자 정렬과 흑백 표현이 준비된 입력을 전제로 합니다. IMAGE 경로는 검출 단계의 성공 여부도 함께 고려해야 합니다. 격자에서 검정 0과 흰색 255를 사용하고 모듈당 픽셀 하나, 여백 제외 조건을 확인하세요. 일반 영상은 검출을 수행하므로 결과가 없다면 원본 영상의 대비와 대상 위치도 점검합니다.
