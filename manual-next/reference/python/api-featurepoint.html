공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    positionzvision._regions.Point2필수검출된 특징점의 해당 영상 로컬 픽셀 중심입니다.
    responsefloat필수특징점의 Harris 원시 응답입니다.

    사용 맥락과 결과 해석

    특징점의 position과 Harris 원시 response를 담는 값입니다. 위치는 해당 영상의 로컬 픽셀 좌표이며 response는 그 점의 검출 강도를 나타냅니다. 학습 모델의 점인지 검색 영상에서 검출한 점인지에 따라 position이 기준으로 삼는 영상이 달라집니다. 이 값 자체는 대응 관계나 변환을 뜻하지 않습니다.

    FeatureModel.points로 모델에 저장된 점을 읽거나 매칭 결과의 source_points에서 검색 측 점을 확인합니다. 대응을 보려면 FeaturePair의 모델·검색 인덱스와 좌표를 함께 살펴봅니다. 원본 영상에 ROI 원점이 있다면 표시 시 전역 변환을 따로 적용해야 합니다. response가 크다는 사실만으로 두 점이 같은 물체에 대응하거나 기하 검증을 통과했다고 볼 수 없습니다.

    반환된 점을 원본에 표시할 때 ROI 원점을 확인하세요.

    값을 확인하는 순서

    position 항목: 검출된 특징점의 해당 영상 로컬 픽셀 중심입니다. response 항목: 특징점의 Harris 원시 응답입니다.
