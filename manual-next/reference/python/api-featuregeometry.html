사용 맥락과 결과 해석

특징점 대응에서 추정할 기하 변환의 종류입니다. AFFINE은 아핀 변환, PROJECTIVE는 원근 변환을 선택합니다. 아핀은 최소 세 쌍, 원근은 최소 네 쌍의 대응이 필요하며 점 배치가 퇴화하면 추정할 수 없습니다. 선택한 방식은 FeatureSearchOptions의 transform에 전달합니다.

반환된 변환은 모델 로컬 좌표에서 검색 영상 로컬 좌표로 가는 행렬입니다. 검출 점이 충분하지 않거나 적합이 성립하지 않으면 결과의 matrix가 None일 수 있습니다. 따라서 일치점 수만으로 행렬이 유효하다고 단정하지 말고 실제 반환 상태와 내점 잔차를 함께 확인합니다. 좌표가 픽셀이고 원점이 다를 경우 전역 위치와 바로 혼합하지 않습니다.

선택한 기하가 원근이라고 해서 렌즈 왜곡 보정이나 카메라 내부 보정이 자동으로 이루어지지는 않습니다. 적합의 입력 좌표가 어떤 영상 프레임에 있는지와 내점 잔차를 명시적으로 확인합니다. 아핀의 마지막 행은 0,0,1이고 원근 변환에는 추가 분모 성분이 있습니다.

값을 확인하는 순서

AFFINE 항목: 아핀 기하 모델을 선택합니다. PROJECTIVE 항목: 원근 기하 모델을 선택합니다.
