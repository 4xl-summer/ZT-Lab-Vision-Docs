ExtendedMatchModel 멤버와 선언

공개 타입

zvision.ExtendedMatchModel: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._extended_matching.ExtendedMatchModel.

Extended NCC template model.

Python
ExtendedMatchModel()

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

실제로 축소한 영상과 모델을 사용해 지정 층을 검색합니다.

find_masked_pyramid

검색 마스크를 사용하여 실제 축소 영상 피라미드를 검색합니다.

find_projective

원근 분모의 두 계수 격자를 포함하여 검색합니다.

find_relative

기준 포즈에 대한 위치·각도 오프셋과 배율 비율 격자를 검색합니다.

find_shear

실제 NCC 영상에서 명시한 x 전단 격자를 검색합니다.

find_with_prior

주어진 예상 포즈에 가까운 격자점부터 검색합니다.

suppress

변환된 NCC 표본의 축 정렬 경계상자 IoU로 매치를 점수순 억제합니다.

suppress_polygon_overlaps

변환된 템플릿 다각형의 겹침을 사용해 후보를 억제합니다.

train

오류: 선택 표본이 3개 미만이거나 상수, 또는 마스크·설정이 유효하지 않으면 오류입니다.
