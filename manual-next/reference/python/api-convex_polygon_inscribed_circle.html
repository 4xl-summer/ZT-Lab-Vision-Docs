convex_polygon_inscribed_circle 멤버와 선언

공개 타입

zvision.convex_polygon_inscribed_circle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._inscribed_circle.convex_polygon_inscribed_circle.

Compute a largest inscribed circle from 3..64 cyclic convex vertices.

Floating-point accuracy and nearly parallel edges limit numerical accuracy.

볼록 다각형의 최대 내접원을 계산합니다.

Python
convex_polygon_inscribed_circle(points)

인자 선언

  • points · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

points
순환 순서의 볼록 꼭짓점 3–64개 Point2입니다.

반환: 중심과 반지름을 담은 InscribedCircle 값입니다.

오류: 유효하지 않은 형식·범위, 계산 불가 또는 작업 한도 초과 시 예외가 발생합니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 계약

    convex_polygon_inscribed_circle은 순환 순서로 나열된 3개부터 64개까지의 볼록 다각형 꼭짓점으로 최대 내접원을 계산합니다. 반환값은 다각형 좌표계의 중심과 반지름입니다. 임의 순서의 점 집합이나 오목한 윤곽을 같은 조건으로 취급하지 말고 입력 도형이 볼록하고 순서가 연결되어 있는지 확인합니다.

    구체 사례와 판독

    예를 들어 (0,0), (4,0), (4,4), (0,4)의 정사각형은 중심 (2,2), 반지름 2인 최대 내접원을 가집니다. 꼭짓점을 무작위로 섞으면 의도한 사각형 경계가 아닌 교차 순서가 될 수 있습니다. 거의 평행한 변과 부동소수 정밀도는 계산 정확도에 영향을 줄 수 있으므로 실제 치수의 허용 공차와 비교해 검증하세요.

    적용 시 확인

    예를 들어 직사각형 8×4의 최대 반지름은 2이며 길이 방향의 중심은 여러 위치가 가능할 수 있습니다. 따라서 결과 중심을 한 점과 완전히 같다고 단정하는 대신 원이 모든 변 안쪽에 있고 반지름이 기대값에 가까운지 확인합니다. 픽셀 좌표라면 물리 치수로 읽기 전에 보정이 필요합니다. 반환 반지름의 단위는 입력 꼭짓점과 같습니다. 입력 순서가 도형의 경계를 한 바퀴 따라가는지 검증하는 것이 먼저입니다.
