Python API · find_feature_instance_collection

find_feature_instance_collection 멤버와 선언

공개 타입

zvision.find_feature_instance_collection: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._feature_instance_collection.find_feature_instance_collection.

Search repeated feature-model instances then suppress oriented polygon overlaps.

여러 특징 모델의 반복 인스턴스를 검색하고 방향 다각형의 겹침을 억제합니다.

Python
find_feature_instance_collection(source, entries, *, max_per_model=2, total_hypotheses=4096, max_results=64, scope=<FeatureOverlapScope.ALL_MODELS: 2>, max_iou=0.5, mask=None)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • entries · POSITIONAL_OR_KEYWORD · 기본값 없음
  • max_per_model · KEYWORD_ONLY · 기본값 2
  • total_hypotheses · KEYWORD_ONLY · 기본값 4096
  • max_results · KEYWORD_ONLY · 기본값 64
  • scope · KEYWORD_ONLY · 기본값 <FeatureOverlapScope.ALL_MODELS: 2>
  • max_iou · KEYWORD_ONLY · 기본값 0.5
  • mask · KEYWORD_ONLY · 기본값 None
