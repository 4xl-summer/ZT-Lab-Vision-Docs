highpass_gray8 멤버와 선언

공개 타입

zvision.highpass_gray8: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._highpass_gap.highpass_gray8.

Return a signed GrayF32 residual with replicate boundaries.

경계 복제를 사용해 부호 있는 고역 잔차를 계산합니다.

Python
highpass_gray8(image, radius_x, radius_y, mode, sigma_x=0.0, sigma_y=0.0)

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_x · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius_y · POSITIONAL_OR_KEYWORD · 기본값 없음
  • mode · POSITIONAL_OR_KEYWORD · 기본값 없음
  • sigma_x · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

image
Gray8 ZImage
radius_x
x 반경 0~31픽셀
radius_y
y 반경 0~31픽셀
mode
고역 필터 모드 0~2
