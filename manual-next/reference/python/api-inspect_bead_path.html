공개 타입

zvision.inspect_bead_path: 패키지 속성으로 접근 가능하지만 __all__에는 없습니다. 선언 출처: zvision._naming_inspection.inspect_bead_path.

Inspect a local-coordinate path and return a closeable BeadResult.

Python
inspect_bead_path(self, path, options, include=None)

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    현재 이미지의 로컬 좌표로 주어진 경로를 따라 탐침을 배치해 비드의 폭과 오프셋, 실패 구간을 검사합니다. path는 경로 점들, options는 예상 폭과 허용 범위 및 탐색 조건을 제공하고 include는 선택적으로 검사에 포함할 탐침을 지정합니다. None은 별도의 제외 마스크를 주지 않는 경우입니다.

    탐침별 에지 검출과 전체 구간 판정은 구별해야 합니다. 예를 들어 한 탐침이 실패해도 전체 결과는 지정된 실패 구간 및 갭 길이 규칙에 따라 판정됩니다. 반환된 BeadResult에서 탐침, 연속 실패 구간, 최장 갭과 전체 passed를 함께 읽으면 어느 위치가 영향을 주었는지 확인할 수 있습니다.

    좌표와 폭은 ROI 로컬 픽셀 기준이며 전체 영상이나 물리 단위로 사용할 때는 원점과 보정이 필요합니다. 반환 결과는 소유 객체이므로 close합니다. 경로가 이미지 안에 있는 것만으로 조명 대비나 실제 비드 품질을 보증하지 않으며 설정과 입력을 별도 검증해야 합니다.
