    필드타입기본값의미와 조건
    angle_minfloat필수최소 회전각(라디안)으로 −π 이상이며 최대각 이하여야 합니다.
    angle_maxfloat필수최대 회전각(라디안)으로 π 이하이며 최소각 이상이어야 합니다.
    angle_stepfloat필수유한한 양의 각도 격자 간격(라디안)입니다. 각 축의 점 수와 각도·배율 점 수의 곱은 4096 이하여야 합니다.
    scale_minfloat필수유한한 양의 최소 등방 배율이며 최대 배율 이하여야 합니다.
    scale_maxfloat필수유한한 최대 등방 배율이며 최소 배율 이상이어야 합니다.
    scale_stepfloat필수유한한 양의 배율 격자 간격입니다. 끝점은 간격이 정확히 맞을 때만 방문합니다.
    min_scorefloat필수허용 점수의 하한으로 유한한 0 이상 1 이하입니다.
    min_distancefloat필수검색 ROI 픽셀 단위의 비음수 유한 중심 거리입니다. 더 가까운 후보를 억제합니다.
    max_matchesint필수반환할 최대 개수로 1 이상의 정수입니다.
