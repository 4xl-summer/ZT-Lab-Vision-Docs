Python API · moments_by_label

moments_by_label 멤버와 선언

공개 타입

zvision.moments_by_label: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._color_advanced.moments_by_label.

색상 영상에서 비영 라벨별 채널 통계, 공분산과 고유분해를 계산합니다.

Python
moments_by_label(image, labels)

인자 선언

  • image · POSITIONAL_OR_KEYWORD · 기본값 없음
  • labels · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

image
지원 색상 형식 ZImage
labels
같은 크기와 원점의 Gray8, Gray16 또는 GrayU32 라벨 영상; 0은 배경

반환: 라벨 오름차순의 독립 AdvancedColorMoments 튜플이며 비영 라벨이 없으면 빈 튜플입니다.

오류: 영상 타입·형식 또는 크기·원점이 맞지 않으면 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    색 영상과 레이블 영상을 받아 레이블별 색 통계를 값 튜플로 반환합니다. 각 항목의 label과 count는 대상 영역과 픽셀 수를 나타내며, mean, min, max, std_dev는 세 채널의 통계입니다. covariance와 고유값·고유벡터는 채널 간 분포를 살피는 추가 정보입니다.

    예를 들어 어떤 레이블에 두 픽셀이 있고 첫 채널 값이 10과 20이면 그 채널 평균은 15입니다. 레이블별 개수를 함께 보지 않으면 작은 영역의 평균과 큰 영역의 평균을 같은 근거로 판단하기 쉽습니다. 각 채널의 색 공간과 단위도 입력 영상의 의미를 따라 읽습니다.

    함수는 두 입력이 ZImage인지 확인하고 내부 결과를 복사한 후 닫습니다. 반환된 항목은 소유 이미지가 아닌 불변 통계 값입니다. 레이블과 영상이 동일 영역을 가리키는지 확인하고 형식 또는 기하 오류를 레이블이 없는 정상 결과와 구분합니다.

    공분산은 각 채널이 함께 변하는 정도를 담고, 고유벡터와 고유값은 분포 방향과 크기를 해석하는 데 사용합니다. 통계만으로 각 픽셀의 공간적 배치는 복원할 수 없습니다.

    레이블 번호와 개수는 영역 대응을 위해 함께 기록합니다.

    동일한 레이블 값이 가리키는 영역을 입력 영상과 함께 확인합니다.
