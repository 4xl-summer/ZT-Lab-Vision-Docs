Python API · pixel_arithmetic

pixel_arithmetic 멤버와 선언

공개 타입

zvision.pixel_arithmetic: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._arithmetic_gap.pixel_arithmetic.

Apply an operation then gain and bias. Zero divisors are errors.

두 영상에 산술 연산 후 gain과 bias를 적용합니다.

Python
pixel_arithmetic(left, right, operation, output_format, gain=1.0, bias=0.0)

인자 선언

  • left · POSITIONAL_OR_KEYWORD · 기본값 없음
  • right · POSITIONAL_OR_KEYWORD · 기본값 없음
  • operation · POSITIONAL_OR_KEYWORD · 기본값 없음
  • output_format · POSITIONAL_OR_KEYWORD · 기본값 없음
  • gain · POSITIONAL_OR_KEYWORD · 기본값 1.0
  • bias · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

left
왼쪽 ZImage
right
오른쪽 ZImage
operation
산술 연산 코드 0~5
output_format
출력 픽셀 형식
gain
유한 배율, 기본 1
bias
유한 오프셋, 기본 0

반환: 별도 close할 ZImage

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

gain: 유한한 수 검사.

bias: 유한한 수 검사.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
