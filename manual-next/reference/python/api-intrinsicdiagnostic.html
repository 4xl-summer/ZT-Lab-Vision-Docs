    사용 맥락과 계약

    IntrinsicDiagnostic은 카메라별 내부 파라미터 최적화의 선택 마스크와 종료 및 수치 진단을 담습니다. mask와 status, iterations와 accepted_steps, initial_rms와 final_rms, gradient와 rank_ratio를 함께 확인합니다. 고정된 자세에서 선택된 계수의 국소 최적화라는 범위를 이해하고 결과를 사용해야 합니다.

    구체 사례와 판독

    예를 들어 final_rms가 initial_rms보다 줄었다면 입력 관측에 대한 목적값이 개선된 상황을 나타낼 수 있습니다. 그러나 이 숫자만으로 최종 모델이 모든 영상 위치에서 정확하다고 보장할 수는 없습니다. 종료 상태와 선택된 계수, 관측의 분포 및 보류점의 재투영 오차를 함께 검토하세요.

    적용 시 확인

    accepted_steps는 수락된 최적화 단계의 수이지 관측점의 개수가 아닙니다. rank_ratio와 gradient는 수치 상태를 점검하는 진단으로, 특정 숫자 하나만으로 모든 보정의 품질을 일반화하기 어렵습니다. 고정 자세와 선택 마스크 및 관측의 공간 분포가 실제 사용 목적에 적합한지도 확인합니다. 카메라별 진단을 입력 카메라와 연결해 기록하세요.
