열거 값

  • STANDARD_DEVIATION = 0 · 값 0. 차이 검사 이웃의 표준편차로 텍스처를 측정합니다.
  • RANGE = 1 · 값 1. 차이 검사 이웃의 최대−최소 범위로 텍스처를 측정합니다.

사용과 결과 해석

고급 차분에서 주변 질감의 측정 방식을 선택합니다. STANDARD_DEVIATION=0은 주변 표본의 표준편차를, RANGE=1은 주변 값의 범위를 사용하는 선택입니다. AdvancedDifferenceSpec의 texture, texture_radius와 texture_weight가 함께 관련되므로 선택 하나만 보고 최종 점수를 결정할 수 없습니다.

예를 들어 주변 값이 모두 같으면 그 집합의 표준편차와 최대·최소의 차이는 모두 0입니다. 밝은 점과 어두운 점이 섞인 주변에서는 두 요약값의 수치와 변화 방식이 달라질 수 있습니다. 질감 반경이 바뀌면 측정에 사용하는 주변 영역도 바뀌므로 비교 조건을 기록합니다.

이 옵션은 입력 영상을 기하학적으로 정렬하지 않습니다. 기준과 검사 영상이 같은 위치를 가리키는지 먼저 확인하고 결과의 score, mask, signed difference를 각각 확인합니다. 질감 가중치를 적용한 점수와 원래 밝기 차이는 서로 다른 수치입니다.

반경이 커지면 국소 점 이외의 무늬도 주변 통계에 포함될 수 있습니다. 균일한 영역과 무늬가 있는 정상 영역을 따로 비교해 허용치가 결함을 지나치게 가리는지 살펴봅니다.
