    정규화하지 않은 모멘트

    BlobWeightedMoment는 대상 label과 선택한 차수의 정규화하지 않은 가중 모멘트 합 value를 담습니다. 모멘트는 위치와 가중치를 합산하는 통계이므로 차수와 좌표 기준이 값의 의미를 결정합니다. value만 보고 중심 좌표나 정규화된 형상 지표라고 해석할 수 없습니다.

    차수에 따른 해석

    0차 가중 합과 위치가 곱해진 고차 합은 서로 다른 양입니다. 예를 들어 x 좌표가 0과 2이고 가중치가 1과 3이라면 가중치 합은 4이고 x에 대한 1차 합은 6입니다. 가중 중심 1.5는 6을 4로 나눈 별도 계산입니다.

    레이블과 좌표

    label은 해당 가중 측정 대상의 레이블입니다. 다른 프레임의 동일 숫자를 같은 물체로 가정하지 말고 분석 결과와 함께 보관합니다. 모멘트를 비교할 때는 차수, 좌표 원점, 단위와 입력 가중치를 일치시켜야 합니다.

    수치 활용

    정규화하지 않은 합은 픽셀 수와 가중치 크기의 변화에도 영향을 받습니다. 서로 다른 크기의 물체를 비교할 때는 원하는 정규화가 무엇인지 먼저 정하고 별도로 계산해야 합니다. 입력 영상 보정이나 실제 측정 정확도는 이 값 자체가 보증하지 않습니다.
