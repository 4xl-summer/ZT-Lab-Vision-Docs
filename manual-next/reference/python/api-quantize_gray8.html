quantize_gray8 멤버와 선언

공개 타입

zvision.quantize_gray8: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._quantization_gap.quantize_gray8.

Quantize to 2..256 uniform left-edge levels in an independent image.

Gray8 값을 균일한 왼쪽 경계 레벨로 양자화합니다.

Python
quantize_gray8(image, levels)

  • levels · POSITIONAL_OR_KEYWORD · 기본값 없음

Gray8 ZImage

공개 멤버

    사용 맥락과 계약

    quantize_gray8은 Gray8 입력을 지정한 개수의 균일한 왼쪽 경계 레벨로 양자화해 독립 영상을 돌려줍니다. levels는 2부터 256까지의 정수입니다. 결과 영상은 입력 영상을 수정하는 설정이 아니라 별도로 관리하는 객체이며 결과의 픽셀을 확인한 뒤 후속 이진화나 표시 단계에 전달합니다.

    구체 사례와 판독

    레벨 개수를 줄이면 서로 다른 입력 밝기들이 같은 출력 레벨로 묶입니다. 따라서 원래 8비트 영상의 세부 명암을 손실 없이 복구할 수는 없습니다. 256레벨과 더 적은 레벨의 결과를 같은 입력에서 비교하면 경계가 어떻게 생기는지 확인할 수 있습니다. 입력 형식이 Gray8인지, 후속 임계값이 양자화된 레벨에 맞는지 확인하세요.

    적용 시 확인

    양자화는 표현 가능한 레벨을 줄이는 처리이며 자동으로 관심 물체와 배경을 분리하는 알고리즘은 아닙니다. 예를 들어 가까운 밝기 둘이 같은 레벨에 놓이면 이후 단계에서 그 차이를 사용할 수 없습니다. 원본과 양자화 결과를 나란히 확인하고 입력별 히스토그램과 후속 검사 기준을 함께 검토하세요. 입력 영상의 수명과 결과 영상의 수명은 분리해 관리합니다. levels 범위 밖의 값을 넣어 결과가 자동 보정될 것이라고 가정하지 마세요.
