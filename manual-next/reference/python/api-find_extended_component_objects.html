find_extended_component_objects 멤버와 선언

공개 타입

zvision.find_extended_component_objects: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._extended_matching.find_extended_component_objects.

Search typed shape components using root-relative constraints.

타입이 지정된 형상 컴포넌트의 루트 상대 관계를 만족하는 객체를 검색합니다.

Python
find_extended_component_objects(source, components, options, *, total_budget, max_objects=1, mask=None)

인자 선언

  • source · POSITIONAL_OR_KEYWORD · 기본값 없음
  • components · POSITIONAL_OR_KEYWORD · 기본값 없음
  • options · POSITIONAL_OR_KEYWORD · 기본값 없음
  • total_budget · KEYWORD_ONLY · 기본값 없음
  • max_objects · KEYWORD_ONLY · 기본값 1
  • mask · KEYWORD_ONLY · 기본값 None

확인된 인자 조건

source
검색 ZImage입니다.
components
ExtendedShapeComponent 시퀀스입니다.
options
ShapeSearchOptions 값입니다. search에 ExtendedMatchOptions(x, y, angle, scale_x, scale_y)를 넣고 각 축은 SearchAxis로 지정합니다. x·y는 검색 ROI 로컬 픽셀, angle은 라디안이며 candidate_budget은 공통 평가 상한입니다. 모든 타입 지정 컴포넌트에 공통 적용되며 total_budget은 별도의 전체 포즈 예산입니다.
total_budget
공유 포즈 예산입니다.
max_objects
최대 객체 수이며 기본값 1입니다.
mask
선택 검색 마스크이며 기본값 None입니다.

반환: 독립 ComponentSearchResult입니다.

오류: 입력 타입·관계·예산이 유효하지 않으면 오류입니다.

래퍼에서 발생 가능한 오류: TypeError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
