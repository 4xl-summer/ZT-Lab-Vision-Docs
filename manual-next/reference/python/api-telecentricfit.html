    사용 맥락과 계약

    TelecentricFit은 텔레센트릭 카메라 모델의 적합 결과를 나타냅니다. camera에는 추정된 모델이 있고 rms_pixels에는 입력 관측에 대한 재투영 RMS가 픽셀 단위로 담깁니다. 모델을 다음 측정에 사용할 때는 입력 픽셀의 좌표계와 적합에 사용한 영상 크기 및 광학 구성을 동일하게 유지해야 합니다.

    구체 사례와 판독

    텔레센트릭 투영의 광선은 서로 평행할 수 있어 원근 카메라처럼 모든 광선이 카메라 원점에서 출발한다고 가정하면 안 됩니다. 잔차가 예를 들어 0.2 픽셀이라면 이는 해당 자료에 대한 재투영 오차의 요약값이지 0.2 mm의 측정 정확도가 아닙니다. 독립된 검증점과 실제 사용 영역에서 오차를 살펴 모델 선택의 타당성을 확인하세요.

    적용 시 확인

    모델을 적합한 뒤에는 보류한 타깃 점을 다시 투영해 위치별 오차를 확인할 수 있습니다. 학습에 쓴 점들에서만 작은 잔차가 나오는 모델은 사용 영역 밖에서 같은 정확도를 보장하지 않습니다. 입력 관측의 품질, 실제 렌즈의 배율과 기구 설치 상태가 달라졌다면 기존 설정을 그대로 신뢰하기 전에 다시 검증해야 합니다. RMS의 숫자만으로 원인을 특정할 수는 없습니다. 모델의 사용 범위와 검증점의 위치를 기록하면 후속 변경을 비교하기 쉽습니다.
