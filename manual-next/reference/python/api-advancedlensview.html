    사용과 결과 해석

    다중 뷰 렌즈 정련에서 하나의 표적 관측과 초기 자세를 묶습니다. target은 표적 평면의 좌표 열이고 observed는 그에 대응하는 픽셀 좌표 열입니다. 각 위치의 두 점은 동일한 표적점을 가리켜야 하며 배열의 길이와 순서가 같아야 합니다. rotation과 translation은 초기 자세를 표현하는 각각 세 값의 튜플입니다. 서로 다른 뷰는 같은 초기 렌즈 모델을 공유하되 각 뷰의 자세는 별도로 지정합니다. 예를 들어 같은 표적의 여러 자세를 넣을 때 한 뷰에서만 점 순서가 바뀌면 모든 값이 유한해도 재투영 오차가 커질 수 있습니다. 반환된 렌즈와 뷰별 자세를 확인하고 학습에 쓰지 않은 관측점으로 예측을 따로 평가하십시오. 이 값은 이미지나 카메라 장치의 소유 핸들이 아닙니다. 같은 표적점이라도 뷰가 달라지면 이미지에서 관측된 픽셀 위치가 달라집니다. 각 뷰의 target과 observed 쌍을 보존하면서 그 뷰에 해당하는 초기 회전과 이동을 함께 전달하십시오. 자세를 다른 뷰의 값과 섞어 입력하면 결과 오차를 해석하기 어려워집니다. 각 뷰에서 대응점의 수와 순서를 먼저 확인하고, 회전·이동을 다른 뷰와 바꾸어 넣지 않도록 관측 식별자를 보관하십시오.
