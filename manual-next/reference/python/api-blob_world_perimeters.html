blob_world_perimeters 멤버와 선언

공개 타입

zvision.blob_world_perimeters: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_world_perimeter.blob_world_perimeters.

Return a world-perimeter tuple in source order for a 3x3 row-major homography.

각 영역 셀 경계를 지정 호모그래피로 옮겨 둘레를 계산합니다.

Python
blob_world_perimeters(source, matrix, work_budget)

  • matrix · POSITIONAL_OR_KEYWORD · 기본값 없음
  • work_budget · POSITIONAL_OR_KEYWORD · 기본값 없음

source
입력 BlobResult

공개 멤버

    경계를 세계 좌표로 변환

    blob_world_perimeters는 BlobResult의 각 영역 셀 경계를 지정한 호모그래피로 옮긴 뒤 둘레를 계산합니다. 영상 픽셀의 둘레에 임의의 단일 배율을 곱하는 것과 달리 위치에 따른 투영 효과가 있을 때 변환된 각 경계의 길이를 사용한다는 점이 중요합니다.

    행렬과 좌표

    matrix는 행 우선 3×3 호모그래피의 유한한 계수 9개입니다. 점 (x,y)에 행렬을 적용한 뒤 동차 좌표의 분모로 나누어 결과 좌표를 구합니다. 단위 행렬을 사용하면 좌표가 바뀌지 않지만 이는 실제 카메라 보정이 정확하다는 검증은 아닙니다.

    호출 전후 확인

    입력 성분과 변환이 같은 영상 좌표 기준을 사용하는지 확인하고 양의 work_budget을 지정합니다. 변환 결과의 길이 단위는 행렬의 목표 좌표계 단위에 따라 해석합니다. ROI 로컬 좌표와 전체 영상 보정 행렬을 그대로 섞으면 실제 위치에 맞지 않는 값을 얻을 수 있습니다.

    수치적 한계

    투영 변환의 분모가 0에 가까운 위치에서는 계산이 불안정하거나 실패할 수 있습니다. 결과를 물리 측정으로 쓰기 전 기준점과 보정 오차를 별도로 검증하고 원본 영상의 픽셀 크기와 세계 길이를 구분합니다.
