열거 값

  • D50 = 0 · 값 0. D65 원본 백색에서 Bradford 적응을 거친 D50 기준 백색을 사용합니다.
  • D65 = 1 · 값 1. sRGB 원색의 D65 기준 백색을 사용합니다.

사용과 결과 해석

Lab 변환의 기준 백색을 선택합니다. D50은 D65 원본 백색에서 Bradford 적응을 거친 기준이고 D65는 sRGB 원색의 기준 백색입니다. 같은 RGB 성분이라도 백색점이 다르면 얻는 Lab 좌표가 달라질 수 있으므로 결과를 비교할 때 선택을 함께 기록해야 합니다.

예를 들어 하나의 색을 D50으로 변환한 결과와 다른 색을 D65로 변환한 결과의 차이를 그대로 색차로 해석하면 색 자체와 변환 기준의 차이가 섞입니다. 비교하려는 두 측정에 같은 관측자와 백색점 조건을 적용해야 합니다.

백색점 선택은 입력 RGB가 sRGB인지 선형인지 정하는 전달 함수와 별도입니다. 채널 순서와 입력 전달 함수, 조명 및 카메라 보정도 확인하십시오. 수치 Lab 변환은 실제 조명 변화의 자동 보정이나 생산 색상 허용차 검증을 대신하지 않습니다.
