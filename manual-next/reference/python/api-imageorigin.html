    사용과 결과 해석

    영상에서 ROI를 떼어 처리할 때 결과의 로컬 좌표는 그 ROI의 왼쪽 위를 기준으로 합니다. ImageOrigin은 이 로컬 원점이 원본 영상의 글로벌 픽셀 좌표에서 어디에 해당하는지 나타내는 값입니다. x와 y는 각각 가로와 세로 위치이며 세계 평면의 물리 단위가 아닙니다. 예를 들어 원점이 (100,200)이고 ROI의 점이 (10,20)이면 같은 점의 글로벌 위치는 (110,220)입니다. 이 덧셈이 이미 포함된 영상 거리 메서드에 원점을 다시 더하면 잘못된 위치가 됩니다. 평면 보정은 글로벌 픽셀을 입력으로 사용하므로 프로파일이나 캘리퍼가 반환한 로컬 점을 사용할 때 원점을 먼저 확인하십시오. 두 숫자가 유한하고 영상 안에 있다는 사실만으로 올바른 좌표계라는 보장은 없습니다. 회전이나 원근 워프가 수행된 영상에서는 그 변환도 따로 추적해야 합니다. 예를 들어 ROI 원점이 (100,200)이고 로컬 점이 (10,20)이면 전체 영상의 점은 (110,220)입니다. 기존 로컬 좌표에 원점을 두 번 더하지 않도록 해당 점의 출처와 좌표계를 결과와 함께 기록하십시오. 평면 보정의 입력이 전체 영상 기준인지 확인하는 것도 같은 이유입니다.
