Python API · hit_or_miss

hit_or_miss 멤버와 선언

공개 타입

zvision.hit_or_miss: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._blob_hit_miss.hit_or_miss.

Return a new Gray8 ROI mask matching both footprints; outside is background.

Footprints are byte iterables of ``width * height`` cells. Nonzero cells
require foreground or background respectively. Overlap is invalid.

전경과 배경 구조 요소를 동시에 만족하는 위치를 찾습니다.

Python
hit_or_miss(image, foreground, background, width, height, anchor_x, anchor_y, work_budget)

확인된 인자 조건

image
ZImage 입력 영상

반환: 별도로 close할 Gray8 마스크

오류: 구조 요소 크기 불일치, 전경·배경 구조 요소 중복, 빈 구조 요소, 기준점 범위 오류는 실패합니다.

래퍼에서 발생 가능한 오류: TypeError, ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
