Python API · shape_from_bytes

shape_from_bytes 멤버와 선언

공개 타입

zvision.shape_from_bytes: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._shape_extensions.shape_from_bytes.

Restore a shape model; reject corrupt, truncated or oversized bytes.

버전과 체크섬이 있는 형상 모델 아카이브를 복원합니다.

Python
shape_from_bytes(data)

인자 선언

  • data · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

data
길이 128..2097184의 모델 bytes입니다.

반환: 호출자가 닫아야 하는 형상 AdvancedMatchModel입니다.

오류: 형식이 잘못되거나 잘리거나 손상된 데이터는 오류입니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용 맥락과 결과 해석

    shape_to_bytes가 만든 버전 형식에서 형상 모델을 복원합니다. data는 128바이트 이상 2097184바이트 이하의 bytes여야 하며 형식, 길이와 체크섬도 검증됩니다. 정상 복원 모델은 새로운 소유 객체이므로 사용 후 close 또는 with로 정리합니다.

    입력 데이터가 잘렸거나 손상되었다면 모델 검색에서 후보가 없는 것이 아니라 복원 오류입니다. 복원 후 학습 특징을 확인하고 동일한 검색 영상·옵션으로 기준 결과와 비교하면 파일을 잘못 선택한 문제를 찾을 수 있습니다. 아카이브는 SDK 고유 형식이며 외부 제품의 모델 파일을 받아들이거나 체크섬으로 데이터의 출처를 인증한다고 가정하지 않습니다.
