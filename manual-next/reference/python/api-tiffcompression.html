열거 값

  • LZW = 1 · LZW 압축을 사용합니다.
  • DEFLATE = 2 · Deflate 압축을 사용합니다.
  • PACKBITS = 3 · PackBits 압축을 사용합니다.

사용 맥락과 계약

TiffCompression은 여러 영상을 TIFF로 저장할 때 사용할 압축 방식을 지정합니다. save_tiff_pages의 compression 인자는 NONE, LZW, DEFLATE, PACKBITS 중 하나이며 기본값은 NONE입니다. 이 설정은 페이지 번호나 바이트 순서와 별개이므로, 페이지 순서는 images 입력으로 정하고 바이트 순서는 byte_order로 지정합니다.

구체 사례와 판독

예를 들어 두 장의 검사 영상을 같은 TIFF에 저장할 때 LZW를 선택하더라도 첫 영상은 페이지 0, 둘째 영상은 페이지 1이라는 입력 순서는 그대로 해석합니다. 압축률은 영상 내용에 따라 달라지므로 빈 배경이 많은 영상의 크기를 모든 영상에 대한 보장으로 삼지 마세요. 파일을 전달받는 프로그램이 선택한 압축을 읽을 수 있는지도 실제 열기로 확인하는 것이 좋습니다.

적용 시 확인

압축 방식뿐 아니라 이미지 형식과 대상 판독기의 지원 범위도 결과에 영향을 줍니다. 전송 전에 실제 파일의 페이지를 읽어 비교하세요. 저장한 페이지들을 각각 읽어 원래 영상의 크기와 픽셀을 대조하면 압축 방식 선택과 페이지 순서가 함께 올바른지 확인할 수 있습니다. 파일 크기만으로 픽셀의 순서를 판단할 수 없습니다.
