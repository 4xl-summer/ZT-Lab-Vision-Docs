bilateral 멤버와 선언

공개 타입

  • depth · POSITIONAL_OR_KEYWORD · 기본값 없음
  • radius · POSITIONAL_OR_KEYWORD · 기본값 없음
  • spatial_sigma · POSITIONAL_OR_KEYWORD · 기본값 없음
  • range_sigma · POSITIONAL_OR_KEYWORD · 기본값 없음

radius: 정수 검사 · 최소 1.

spatial_sigma: 유한한 수 검사.

range_sigma: 유한한 수 검사.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    bilateral은 깊이 값의 위치 거리와 중심값과의 높이 차이에 가우시안 가중을 주어 유효 중심을 평활합니다. radius와 spatial_sigma는 픽셀 단위, range_sigma는 깊이 격자의 길이 단위입니다. 반경은 양의 정수이고 두 표준편차는 유한 양수여야 합니다. 예를 들어 X 간격이 물리 단위로 2여도 radius=1은 한 셀 주변을 살피는 설정이며 거리 1 mm를 뜻하지 않습니다.

    결측 중심은 그대로 결측이고, 주변의 결측 샘플은 가중 평균에 들어가지 않습니다. 이 연산은 빠진 높이를 채우기 위한 fill_directional과 목적이 다릅니다. 영상 경계에서는 이웃 범위가 잘리므로 위치마다 참여 표본 수가 달라질 수 있습니다. 결과는 새 DepthMap 소유 객체이며 원본과 결과를 각각 관리합니다. 파라미터가 무효이거나 산술 결과가 유효하지 않으면 오류를 처리하고 무효값을 측정값으로 바꾸지 않습니다.
