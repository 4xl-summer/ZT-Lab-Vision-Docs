    사용과 결과 해석

    점수화된 에지 후보의 첫째 에지, 선택적인 둘째 에지, 정규화 점수 및 활성 점수 구성 요소를 묶습니다. first는 첫 에지이고 second는 두 에지를 사용하는 후보에서 제공될 수 있으며 없으면 None입니다. score만 보면 후보가 한 에지인지 두 에지인지 또는 어떤 특징이 점수에 기여했는지 알 수 없으므로 components와 실제 에지를 함께 보십시오. 예를 들어 같은 프로파일의 에지가 거리 2와 7에 있다면 두 위치와 너비 5를 확인한 뒤 너비를 사용하는 점수 요소가 활성화되었는지 살필 수 있습니다. 반대로 둘째 에지가 없는 후보에 0을 임의로 대입하면 실제 시작점에 있는 에지와 결측을 혼동하게 됩니다. 위치는 프로파일 시작점에서의 픽셀 거리이고 강도는 입력 강도의 단위와 픽셀 간격에 관계됩니다. 두 에지의 첫째와 둘째는 영상의 고정된 왼쪽과 오른쪽이 아니라 탐색 진행 방향에 의존하므로 선분 방향도 기록하십시오. 점수는 설정된 기준에 대한 상대적 평가이지 물리 거리나 실제 장비의 정확도 보증이 아닙니다. 동일한 기준과 입력에서 후보 순위를 비교하고, 기준이 바뀌었다면 점수 해석도 함께 확인합니다. 후보를 표시할 때는 점수와 함께 각 에지의 원래 위치도 영상 위에 표시하면 다른 경계가 선택된 문제를 확인하기 쉽습니다.
