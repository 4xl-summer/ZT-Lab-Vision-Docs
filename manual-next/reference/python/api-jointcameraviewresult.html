    사용 맥락과 계약

    JointCameraViewResult는 공동 카메라 계산의 한 보드 관측에 대한 결과입니다. board는 보드에서 카메라 A로 가는 자세이고 rms_a와 rms_b는 각각 카메라 A와 B에서의 유클리드 재투영 RMS이며 픽셀 단위입니다. 두 카메라의 오차를 구분해 보면 어느 쪽 관측이나 모델을 먼저 점검할지 판단할 수 있습니다.

    구체 사례와 판독

    예를 들어 rms_a가 0.2 픽셀이고 rms_b가 1.0 픽셀이면 이 관측에서는 B의 재투영 오차가 더 큽니다. 이것만으로 특정 장치 고장을 증명할 수는 없으며 B의 점 대응, 렌즈 계수와 영상 좌표 원점을 확인해야 합니다. board의 회전과 이동은 픽셀 RMS와 다른 물리량입니다.

    적용 시 확인

    한 관측의 평균 오차는 위치별 오차 분포를 가릴 수 있습니다. 보드 중심과 가장자리 점을 따로 다시 투영해 차이를 살펴보면 렌즈 왜곡이나 잘못된 대응의 징후를 찾는 데 도움이 됩니다. 두 RMS는 영상 픽셀 단위이므로 길이 보정 없이 밀리미터 오차로 해석하지 않습니다. 두 카메라의 해상도가 다르면 같은 픽셀 수의 오차라도 영상에서 차지하는 비율이 다를 수 있습니다. 영상 크기와 검증 목적을 함께 고려하세요. 관측한 보드의 위치도 함께 기록합니다.
