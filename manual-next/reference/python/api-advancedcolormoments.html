    label: 0이 아닌 레이블 값; 0은 배경.

    count: 레이블에 포함된 픽셀 수.

    mean: 정규화된 인코딩 RGB 순서의 평균 3값 튜플.

    min: 정규화 인코딩 RGB 순서의 채널별 최솟값 튜플.

    max: 정규화 인코딩 RGB 순서의 채널별 최댓값 튜플.

    std_dev: 정규화 RGB 채널별 모집단 표준편차 튜플.

    covariance: 정규화 RGB의 행 우선 3×3 모집단 공분산 9값 튜플.

    eigenvalues: 공분산 PCA 고유값 3개; 내림차순.

    eigenvectors: 고유벡터를 열로 둔 행 우선 3×3 튜플; 고유벡터 부호는 유일하지 않음.
