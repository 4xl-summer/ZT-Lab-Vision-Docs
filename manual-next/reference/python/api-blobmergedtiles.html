공개 멤버

    데이터 필드

    필드타입기본값의미와 조건
    widthint필수이어 붙인 결과의 픽셀 폭입니다.
    heightint필수이어 붙인 결과의 픽셀 높이입니다.
    labelstuple필수행별 라벨 맵이며 0은 배경입니다.
    blobstuple필수경계를 가로지르는 연결을 다시 계산한 성분 스냅샷입니다.

    결합 영상의 결과

    BlobMergedTiles는 결합 영상의 width와 height, 행 우선 labels, 경계를 넘는 연결을 반영한 blobs를 담습니다. 레이블 0은 배경입니다. labels의 각 숫자는 해당 결합 영상 안의 성분 소속을 나타내며 다른 분석 결과의 같은 숫자와 자동으로 대응하지 않습니다.

    행과 열 해석

    너비가 4인 맵에서 행 우선 배열의 한 행은 연속된 네 원소로 나타납니다. 다음 행은 그다음 네 원소입니다. 전체 원소를 영상에 표시할 때 너비를 잘못 사용하면 같은 값들도 다른 위치로 배치되어 이음새의 연결을 판독하기 어렵습니다.

    성분과 중심

    blobs에는 타일 경계를 가로지르는 연결을 반영한 면적과 결합 영상 로컬 중심이 들어 있습니다. 양쪽 타일에서 따로 관찰한 물체가 결합 후 하나가 됐는지 확인하려면 레이블 맵과 결과 목록을 같이 봅니다. 연결성 설정도 결과 개수에 영향을 줍니다.

    경계 조건

    입력 타일의 높이와 배열 정렬이 맞는지 확인하고, 원본 전체 영상 좌표가 필요하면 결합 영상의 원점 정보를 별도로 적용합니다. 레이블은 물체의 영구 식별자가 아니므로 프레임 간 추적에는 별도 대응이 필요합니다.
