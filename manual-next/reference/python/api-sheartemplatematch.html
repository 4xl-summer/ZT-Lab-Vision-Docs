    사용 맥락과 결과 해석

    전단 NCC 검색의 한 결과로 match에 기본 포즈와 점수, shear에 무차원 x 전단 계수를 담습니다. 템플릿 로컬 좌표에서 전단은 u′=u+shear×v로 적용됩니다. 0이면 이 전단 성분이 없고, 다른 자세의 회전과 축 배율은 포함된 AdvancedMatch에서 읽습니다.

    예를 들어 shear 1에서는 v가 1만큼 증가할 때 u가 1만큼 더해집니다. 이 계수는 단위가 픽셀이 아니라 축 간 비율입니다. 포즈 기준점은 검색 ROI 좌표와 그 원점을 더한 전역 좌표를 구별합니다. 상위 결과의 종료 이유와 평가 수를 확인해 전단 격자가 예산 안에서 얼마나 평가되었는지 살펴봐야 합니다.

    전단 방향과 회전 방향을 같은 숫자로 더할 수는 없습니다. 하나는 축 간 무차원 비율이고 다른 하나는 라디안 각도입니다. 후속 변환에서는 두 성분을 각각 적용해야 합니다. 보고서의 종료 이유도 함께 확인합니다.

    값을 확인하는 순서

    match 항목: 해당 전단 값에서 얻은 독립 AdvancedMatch 값입니다. shear 항목: 템플릿 변환 u′=u+shear×v에 쓰인 무차원 x 전단 계수입니다.
