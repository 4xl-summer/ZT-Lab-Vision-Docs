공개 멤버

    사용과 결과 해석

    두 ZImage와 AdvancedMetric을 받아 픽셀별 색 거리를 담은 새 영상을 만듭니다. metric은 종류와 아홉 매개변수로 구성됩니다. CIE76, CIE94, CIEDE2000, CMC 등 거리의 정의가 다르므로 같은 숫자라도 선택한 척도와 조건을 함께 읽어야 합니다.

    예를 들어 동일한 Lab 좌표끼리의 CIE76 거리는 0이고, 한 축만 3만큼 다르면 다른 두 축이 같을 때 유클리드 거리는 3입니다. 다른 척도는 가중 방식이 다르므로 이 단순 계산을 그대로 적용하지 않습니다. 기준 영상과 검사 영상이 대응 위치를 가리키도록 먼저 확인합니다.

    출력은 색 거리 영상이며 합격 또는 불합격의 자동 결정이 아닙니다. 별도 허용치로 검사한다면 그 척도와 기준을 기록해야 합니다. 결과는 새 소유 ZImage이므로 사용 후 닫고, 두 입력의 형식이나 기하가 맞지 않는 오류를 거리 0으로 변환하지 않습니다.

    거리 영상에서 특정 점이 높다면 해당 좌표의 두 입력색과 척도 매개변수를 함께 확인합니다. 표시를 위한 색상 맵이나 임계값이 원래 거리 수치를 바꾸지는 않습니다.

    서로 다른 거리 척도의 숫자에 동일 임계값을 무조건 쓰지 않습니다.
