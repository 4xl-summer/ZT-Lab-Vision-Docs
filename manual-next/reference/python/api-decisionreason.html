열거 값

  • NONE = 0 · 거절 사유가 없습니다.
  • COUNT = 1 · 결함 수가 상한을 넘었습니다.
  • TOTAL_AREA = 2 · 총 결함 면적이 상한을 넘었습니다.
  • SINGLE_AREA = 4 · 개별 결함 면적이 상한을 넘었습니다.
  • LOCATION = 8 · 결함 경계가 허용 영역 밖입니다.

사용과 결과 해석

검사 판정이 실패한 이유를 비트로 나타냅니다. COUNT는 후보 수, TOTAL_AREA는 전체 후보 면적 합, SINGLE_AREA는 어느 한 후보의 면적이 각각의 상한을 초과했음을 뜻합니다. LOCATION은 후보의 전체 경계가 허용 사각형 안에 들지 않은 경우입니다. 여러 조건을 동시에 위반하면 이유가 하나로 대체되지 않고 함께 나타날 수 있습니다. NONE은 거절 사유가 없을 때의 값입니다.

예를 들어 한 픽셀 결함 하나를 모든 상한이 0인 조건으로 검사하면 개수, 총 면적, 개별 면적의 한도를 각각 넘습니다. 이때 전체 Reasons에서 모든 관련 비트를 살펴보아야 합니다. 반면 개별 DefectRejection은 해당 후보의 개별 면적과 위치 위반을 기록하므로 전체 개수 또는 총 면적 위반만으로 개별 항목이 생긴다고 가정하지 않습니다.

한도는 등호를 허용합니다. 따라서 후보 면적이 상한과 정확히 같으면 그 조건 자체는 위반이 아닙니다. 사유를 읽기 전에 정렬과 차분이 실제로 수행되었는지 확인해야 합니다. 정렬 미발견으로 판정을 하지 않은 상황을 이유 비트가 없는 합격으로 표현하면 검사 불가와 정상 결과를 혼동하게 됩니다.

사유 비트는 서로 배타적인 상태가 아니므로 검사 기록에서 개별 이유를 각각 확인하는 것이 중요합니다.
