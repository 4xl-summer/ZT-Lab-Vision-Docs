    영역을 감싸는 원

    BlobOuterCircle은 선택한 블롭의 픽셀 셀 꼭짓점으로 만든 볼록껍질을 감싸는 원의 중심 x, y와 반지름 radius를 나타냅니다. 중심은 ROI 로컬 픽셀 좌표이고 반지름의 단위는 픽셀입니다. 픽셀 중심만 감싼 원이나 영역 안에 들어가는 원과는 정의가 다릅니다.

    셀 꼭짓점의 의미

    한 픽셀도 하나의 크기를 가진 정사각형 셀로 생각하면 중심점 하나가 아니라 네 꼭짓점이 경계를 이룹니다. 이 꼭짓점까지 감싸야 하므로 원의 반지름은 같은 위치의 픽셀 중심 한 점만 감싸는 경우보다 클 수 있습니다. 작은 물체일수록 이 정의 차이가 상대적으로 중요합니다.

    사용과 표시

    blob_outer_circle에 성분 결과와 0 기반 인덱스를 지정해 얻은 중심과 반지름을 원래 마스크 위에 표시합니다. 전체 영상에 표시할 때는 ROI 원점을 중심 좌표에 반영하고 반지름은 좌표의 크기 단위를 유지합니다. 원 안의 모든 픽셀이 전경이라는 의미는 아닙니다.

    측정의 한계

    물체가 ROI에 의해 잘리면 보이는 셀만으로 원을 계산하게 됩니다. 픽셀 크기가 가로와 세로에서 다르거나 투영 보정이 필요한 경우 픽셀 단위 원을 그대로 물리 단위 원으로 해석하지 않습니다.
