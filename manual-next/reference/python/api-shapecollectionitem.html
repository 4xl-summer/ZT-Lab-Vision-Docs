    사용 맥락과 결과 해석

    형상 모델 컬렉션에서 반환된 한 매치로, id는 모델 항목 식별자이며 match는 해당 모델이 산출한 AdvancedMatch 값입니다. match의 위치·각도·축 배율과 점수를 읽어 실제 포즈를 해석합니다. id는 검색 결과의 순번이 아니라 호출자가 입력한 모델 id입니다.

    예를 들어 입력 모델을 12와 40으로 구분했다면 결과 id 40은 두 번째 모델이라는 것을 가리키지만 목록에서의 인덱스 40을 뜻하지 않습니다. 결과가 어느 ROI에서 나왔는지에 따라 로컬 위치와 전역 위치를 구별해야 합니다. 컬렉션 검색의 공유 예산이 소진되었는지도 상위 결과에서 확인하고, 후보의 점수만으로 전체 모델이 평가되었다고 단정하지 않습니다.

    상위 보고서의 미완료 상태가 참이면 결과가 하나 나왔더라도 나머지 모델을 모두 처리하지 못했을 수 있습니다. 선택된 항목의 모델 출처와 별개로 전체 종료 상태를 확인해야 합니다.

    값을 확인하는 순서

    id 항목: 매치를 산출한 모델 항목의 식별자입니다. match 항목: 해당 모델이 산출한 독립 AdvancedMatch 값입니다.

    항목읽을 때 확인할 내용
    id매치를 산출한 모델 항목의 식별자입니다.
    match해당 모델이 산출한 독립 AdvancedMatch 값입니다.
