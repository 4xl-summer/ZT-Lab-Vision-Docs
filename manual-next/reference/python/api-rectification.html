Python API · Rectification

Rectification 멤버와 선언

공개 타입

zvision.Rectification: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._camera_geometry.Rectification.

Output size, world U/V origin and positive pitch, interpolation and constant border.

평면 보정 출력 격자와 보간 경계를 지정합니다. pitch의 양수 조건 등은 기하 연산 시 검증합니다.

Python
Rectification(width, height, origin_u, origin_v, pitch_u, pitch_v, interpolation=<Interpolation.BILINEAR: 1>, border=0.0)

인자 선언

  • width · POSITIONAL_OR_KEYWORD · 기본값 없음
  • height · POSITIONAL_OR_KEYWORD · 기본값 없음
  • origin_u · POSITIONAL_OR_KEYWORD · 기본값 없음
  • origin_v · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pitch_u · POSITIONAL_OR_KEYWORD · 기본값 없음
  • pitch_v · POSITIONAL_OR_KEYWORD · 기본값 없음
  • interpolation · POSITIONAL_OR_KEYWORD · 기본값 <Interpolation.BILINEAR: 1>
  • border · POSITIONAL_OR_KEYWORD · 기본값 0.0

확인된 인자 조건

width
양의 출력 너비 픽셀 수입니다.
height
양의 출력 높이 픽셀 수입니다.
origin_u
출력 시작점의 평면 U 좌표입니다.
origin_v
출력 시작점의 평면 V 좌표입니다.
pitch_u
U 방향의 유한한 양의 물리 간격입니다.
pitch_v
V 방향의 유한한 양의 물리 간격입니다.
interpolation
Interpolation 값이며 기본값은 BILINEAR입니다.
border
영상 밖 샘플에 사용하는 유한한 상수 밝기이며 기본값은 0입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.
