Python API · world_refit_line_angle

world_refit_line_angle 멤버와 선언

공개 타입

zvision.world_refit_line_angle: 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._world_refit.world_refit_line_angle.

Return the signed directed angle in radians for two same-frame line fits.

같은 프레임의 방향 직선 두 개 사이 부호 있는 각도를 구합니다.

Python
world_refit_line_angle(a, b)

인자 선언

  • a · POSITIONAL_OR_KEYWORD · 기본값 없음
  • b · POSITIONAL_OR_KEYWORD · 기본값 없음

확인된 인자 조건

a
첫 번째 world line fit
b
두 번째 world line fit

반환: 방향 각도(라디안)

오류: 타입·범위·형식 검증이나 네이티브 연산 실패 시 오류가 전달됩니다.

래퍼에서 발생 가능한 오류: ValueError. 네이티브 오류는 별도입니다.

시그니처와 설명에 없는 반환값, 오류, 제약 조건은 확인되지 않았습니다. 환경별 네이티브 지원 여부와 예제 실행은 별도 검증이 필요합니다.

공개 멤버

    사용과 결과 해석

    두 적합 직선의 방향 차이를 부호 있는 각도로 해석할 때 사용합니다. 두 입력은 직선 종류의 WorldRefit 스냅샷이어야 하며, 같은 0이 아닌 프레임 식별자와 같은 길이 단위를 가져야 합니다. 영상에서 얻은 선을 월드 좌표로 적합했다면 두 결과가 같은 보정 좌표계에서 나왔는지 먼저 확인하십시오. 좌표계가 다르면 화면에서 두 선이 평행해 보이더라도 이 함수의 비교 조건을 만족하지 않습니다.

    각 스냅샷에서 방향 벡터를 가져와 길이를 1로 정규화한 다음, 두 벡터의 외적과 내적을 이용해 순서가 있는 각도를 라디안으로 계산합니다. 예를 들어 첫 방향이 (1, 0), 둘째가 (0, 1)이면 결과는 π/2이고 입력 순서를 바꾸면 부호가 바뀝니다. 이는 방향이 있는 각도이므로 방향 벡터 자체를 반대로 잡으면 결과도 달라질 수 있습니다.

    반환값은 길이가 아니라 각도입니다. 단위가 같은 이유는 두 적합 결과가 같은 월드 좌표계를 표현하는지 확인하기 위해서이며, 반환 각도의 단위는 항상 라디안입니다. 원이나 다른 종류를 전달하거나 프레임 또는 단위가 일치하지 않으면 오류가 발생합니다. 방향 벡터가 0이거나 유한하지 않아도 계산을 거부하므로 적합 성공 여부와 방향을 먼저 확인하십시오.
