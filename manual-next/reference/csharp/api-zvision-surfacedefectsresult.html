사용과 결과 해석

결함 마스크의 연결 성분마다 계산한 형상과 점수를 담는 독립 스냅샷입니다. Defects에는 종류, 면적, ROI 로컬 경계·중심, 길이·폭 및 평균·최대 점수가 포함됩니다. 결과를 별도로 Dispose할 필요는 없지만 각 측정의 좌표계와 단위는 유지해야 합니다.

예를 들어 같은 면적의 성분이라도 길고 가는 모양과 둥근 모양은 길이·폭과 분류가 다를 수 있습니다. 평균 점수는 전체 성분의 요약이고 최대 점수는 가장 강한 위치를 보여 주므로 하나로 다른 하나를 대체할 수 없습니다.

연결성과 최소 면적 설정이 후보의 개수와 범위에 영향을 줍니다. ROI 로컬 좌표를 원본이나 월드 좌표에 연결할 때 원점과 보정을 적용하고, 픽셀 수를 실제 면적으로 쓰기 전에 카메라 배율을 확인하십시오.
