두 영역의 경계 거리

BlobRegionDistanceOps는 두 영역 경계 픽셀의 최단 거리를 측정합니다. 경계 픽셀 중심 사이의 거리이므로 영역 무게중심 거리 또는 픽셀 셀 가장자리 사이의 빈 공간 폭과 혼동해서는 안 됩니다.

계산 예

가장 가까운 경계 중심이 (1,2)와 (4,6)이면 차이는 (3,4)이고 유클리드 거리는 5픽셀입니다. 선택된 두 위치를 마스크에 표시하면 값이 어떤 경계쌍에서 나왔는지 확인하기 쉽습니다.

Measure의 입력

두 영역 마스크의 형식, 크기와 원점이 같은 공간을 나타내는지 확인한 뒤 Measure의 작업 한도와 함께 전달합니다. 서로 다른 ROI의 로컬 좌표를 그대로 비교하면 실제 위치 관계가 어긋날 수 있습니다.

측정 해석

임계값이나 형태학을 바꾸어 경계 픽셀이 이동하면 같은 물체도 다른 거리가 나올 수 있습니다. 결과를 물리 거리로 비교하기 전 픽셀 간격과 카메라 보정을 확인하고 마스크와 설정을 함께 저장합니다.
