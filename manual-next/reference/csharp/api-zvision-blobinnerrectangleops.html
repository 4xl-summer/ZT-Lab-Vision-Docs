최대 내부 사각형 측정

BlobInnerRectangleOps는 전경 안에 완전히 포함되는 최대 축 정렬 사각형을 찾습니다. 전체 물체를 둘러싸는 경계 상자와는 역할이 다릅니다. 배경 구멍이나 오목한 홈은 내부에 넣을 수 있는 사각형의 크기를 제한할 수 있습니다.

Measure의 결과

결과 BlobInnerRectangle은 ROI 로컬 시작 X, Y와 픽셀 폭·높이를 제공합니다. 예를 들어 폭 3과 높이 2는 6개 셀의 사각형을 뜻합니다. 전경 전체가 6픽셀이라는 뜻이 아니며 그 밖에 다른 전경이 존재할 수 있습니다.

검사 방법

Measure에 적절한 전경 마스크와 작업 한도를 전달하고 반환 사각형을 입력 영상과 겹쳐 확인합니다. ROI의 원점과 결과 좌표를 맞추어야 원본에서 정확한 위치에 표시됩니다. 전경 선택이 반대이면 원하는 물체 대신 배경에서 사각형을 찾을 수 있습니다.

비교 범위

사각형은 영상 축에 맞추어져 있어 물체가 회전하면 내부에 들어가는 폭과 높이가 바뀔 수 있습니다. 이를 물리 크기로 비교하려면 픽셀 단위, 보정과 물체 방향을 함께 고려합니다.
