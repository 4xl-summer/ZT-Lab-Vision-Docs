사용 맥락과 결과 해석

타입이 있는 색상 거리로 기준 Lab 색과 영상을 비교한 소유 결과입니다. Indices는 픽셀별 가장 가까운 기준 색의 인덱스 영상이고 Distances는 해당 거리 영상입니다. 이 결과 자체를 Dispose해야 하며 두 속성으로 획득한 영상도 각각 별도로 Dispose합니다.

기준 색의 입력 순서를 바꾸면 동일 인덱스가 가리키는 색도 바뀝니다. 거리 숫자는 선택한 색차 방식과 계수에 의존하며 확률이 아닙니다. 영상이나 기준 색, 거리 설정이 유효하지 않을 때 발생하는 오류와 정상적으로 큰 거리가 나온 픽셀을 구분하세요. 소유 결과를 해제하기 전에 필요한 영상을 획득해야 합니다.

먼저 결과의 필요한 영상 속성을 획득하고 이후 결과를 정리합니다. 얻은 각각의 영상은 원래 결과와 별개로 소유되므로 사용이 끝난 뒤에도 영상 객체를 따로 정리해야 합니다.

값을 확인하는 순서

Indices 항목: 기준 색 인덱스 영상입니다. Distances 항목: 거리 영상입니다.
