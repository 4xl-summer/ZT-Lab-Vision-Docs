공개 타입

ZVision.MatchModel · class

어셈블리: ZVision.

불변 템플릿 모델을 소유합니다. 학습 픽셀은 독립 복사되며 사용 후 Dispose해야 합니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object

TrainNcc

Method · 선언 타입 ZVision.MatchModel

C#
static ZVision.MatchModel TrainNcc(ZVision.ZImage template, ZVision.ZImage mask = null)

템플릿의 선택 픽셀로 NCC 모델을 학습합니다. 선택점은 2개 이상이고 분산이 0이 아니어야 합니다.

인자

template
학습할 Gray8, Gray16 또는 GrayF32 영상입니다.
mask
템플릿과 크기·원점이 같은 선택적 Gray8 마스크입니다. 0은 제외하고 비제로는 포함합니다.

반환: 사용 후 Dispose해야 하는 소유 모델입니다.
