공개 타입

ZVision.MatchModel · class

어셈블리: ZVision.

불변 템플릿 모델을 소유합니다. 학습 픽셀은 독립 복사되며 사용 후 Dispose해야 합니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object

컴파일된 ZVision 어셈블리에서 확인한 공개 멤버입니다. XML 설명이 없는 반환값, 오류와 지원 조건은 미확인입니다.

TrainNcc

템플릿의 선택 픽셀로 NCC 모델을 학습합니다. 선택점은 2개 이상이고 분산이 0이 아니어야 합니다.

TrainShape

템플릿의 기울기 방향으로 형상 모델을 학습합니다. 3×3 이상과 특징점 3개 이상이 필요합니다.

Save

Find

검색 영상에서 모델을 찾아 네이티브 자원과 독립된 결과를 반환합니다.
