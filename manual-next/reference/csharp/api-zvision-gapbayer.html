사용과 결과 해석

Gray8 Bayer 모자이크에서 RGB8 영상을 복원합니다. 패턴은 전역 원점 기준으로 지정하며 빨강·초록·파랑 gain은 각각 양수입니다. 입력의 양쪽 축은 최소 2픽셀이어야 하며 결과는 별도 소유 영상이므로 사용 후 Dispose해야 합니다.

각 채널은 ROI 내부의 3×3 표본을 이용해 선형 보간합니다. ROI를 잘랐을 때 로컬 (0,0)에서 새 패턴이 시작한다고 임의로 가정하면 센서의 색상 위상이 어긋날 수 있습니다. 원본 영상의 원점과 사용 중인 Bayer 배열을 함께 확인하십시오.

gain은 색 채널의 배율이지 카메라 전체 색 보정이나 조명 교정을 자동으로 수행하는 모델이 아닙니다. 출력은 RGB8이므로 변환 후 범위 제한과 양자화의 영향을 받을 수 있습니다. 합성 패턴으로 색상 순서를 먼저 검증하고 실제 카메라의 조명과 화이트밸런스는 별도로 평가하십시오.
