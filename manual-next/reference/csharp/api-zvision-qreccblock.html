사용과 결과 해석

QR 또는 Data Matrix Reed–Solomon 블록의 코드워드 수를 나타냅니다. DataCodewords는 데이터 코드워드 수, ParityCodewords는 오류 정정용 코드워드 수, CorrectedCodewords는 실제로 수정된 코드워드 수입니다. 하나의 이미지 픽셀이나 모듈과 코드워드 하나는 같은 단위가 아닙니다.

블록별 값을 읽으면 전체 수정 수만 보는 것보다 정정이 특정 블록에 집중되었는지 살펴볼 수 있습니다. 예를 들어 두 블록의 정정 수가 각각 1과 5라면 총합 6만 기록했을 때보다 블록별 사후 상한에 대한 결과를 더 잘 해석할 수 있습니다.

정정 개수는 보정된 확률이나 ISO 품질 등급이 아닙니다. 수락 상한은 정정 이후 결과를 판정하는 설정이며 인코딩된 오류 정정 수준 자체를 바꾸지 않습니다. 진단 입력이 이미 샘플링된 모듈 격자인지 카메라 영상인지와 디코딩 오류도 함께 구분하십시오.
