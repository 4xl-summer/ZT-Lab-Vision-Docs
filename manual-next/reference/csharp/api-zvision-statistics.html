사용과 결과 해석

Gray8 픽셀 집합의 개수, 최솟값, 최댓값, 평균 및 분산을 담은 값 스냅샷입니다. Count는 통계에 포함된 픽셀 수이고 Min과 Max는 그 집합에서 관측된 밝기 극값입니다. Mean과 Variance는 전체적인 밝기 수준과 분포를 함께 살펴보는 데 사용합니다.

예를 들어 세 픽셀 0, 10, 20의 평균은 10이고 최솟값과 최댓값은 각각 0과 20입니다. 평균이 같더라도 픽셀이 모두 10인 영상과 분산이 있는 영상은 다릅니다. 값은 Gray8 강도 기준이므로 센서의 실제 광량이나 물리 단위로 바로 해석할 수 없습니다.

어떤 ROI나 마스크의 픽셀이 포함됐는지에 따라 통계가 달라집니다. 결과는 복사된 값으로 영상 핸들을 유지하지 않지만, 수치를 비교할 때 원래 영역과 전처리 조건을 기록해야 합니다. 분산의 정의나 빈 입력 오류는 호출한 통계 API의 계약을 확인하십시오.
