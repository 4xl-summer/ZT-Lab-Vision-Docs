사용 맥락과 결과 해석

특징 검출에서 얻은 한 위치와 Harris 원시 응답입니다. X와 Y는 해당 모델 또는 검색 영상의 로컬 픽셀 좌표이고 Response는 검출 강도입니다. 이 값은 두 영상의 대응이나 정합 행렬을 자체적으로 나타내지 않습니다.

모델 점 목록과 검색 결과 점 목록을 사용할 때 어느 영상에 속하는지 먼저 구분합니다. 예를 들어 검색 영상이 원본의 ROI라면 원본에 표시할 때 원점을 반영해야 합니다. 높은 응답만으로 같은 물체의 대응점이라고 단정하지 말고 FeaturePair의 거리, 기하 변환의 내점과 잔차를 함께 살펴봅니다.

대응점의 모델 인덱스와 검색 인덱스는 서로 다른 목록을 가리킵니다. 위치가 같아 보이더라도 모델과 검색 영상이 같은 원점이라고 가정하지 않습니다. 실제 변환 결과는 적합된 행렬과 잔차로 검토합니다. 모델의 특징 수와 검출된 검색 점 수는 서로 다를 수 있습니다. 검출 옵션도 두 점 목록의 크기에 영향을 줍니다.
