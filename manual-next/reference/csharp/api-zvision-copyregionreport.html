복사와 잘림의 수

CopyRegionReport는 실제 복사된 선택 픽셀 수 Copied와 목적 영상 바깥으로 잘린 선택 픽셀 수 Clipped를 보고합니다. 두 수치는 픽셀 개수이며 바이트 수나 물리 면적이 아닙니다.

경계 예

선택된 한 행의 다섯 픽셀 중 목적 영상에 세 위치만 들어가고 나머지 두 위치가 경계 밖이면 복사와 잘림을 각각 구분해 확인해야 합니다. 전체 복사가 필요한 상황에서 Clipped가 0이 아니면 위치와 크기 설정을 검토합니다.

호출 후 확인

원본 및 대상 영상의 좌표 기준, 오프셋과 선택 마스크를 먼저 확인하고 복사 후 보고 값을 읽습니다. 결과 영상에서 실제 기록된 위치를 같이 보면 숫자가 기대와 다른 이유를 찾기 쉽습니다.

사용 범위

일부 잘림은 경계에 걸친 영역을 의도적으로 복사하는 작업에서 허용될 수 있습니다. 이 보고는 복사된 데이터 자체를 보유하는 영상이 아니므로 대상 영상의 수명과 형식은 별도로 관리해야 합니다.
