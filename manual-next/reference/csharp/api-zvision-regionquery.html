지연된 영역 분석 계획

RegionQuery는 영역 분석을 계획하는 지연 Query입니다. 계획을 구성하는 단계와 실행 후 결과를 읽는 단계를 구분해야 합니다. 메서드를 연결했다는 사실만으로 해당 결과가 이미 계산되었다고 가정하지 않습니다.

분기와 복제

Clone은 계획을 복제하는 데 사용합니다. 같은 시작 조건에서 서로 다른 후속 분석을 만들고 싶다면 계획을 분기해 각 쪽에 필요한 조건을 지정할 수 있습니다. 복제된 계획의 결과가 자동으로 이전 실행 결과와 동일하다는 의미는 아닙니다.

입력과 실행

영역의 좌표 기준과 전경 마스크를 확인하고 사용할 연산과 옵션을 계획한 뒤 해당 실행 API를 호출합니다. 오류는 실행 시점에 나타날 수 있으므로 결과를 얻기 전에 성공 여부를 확인하고 필요한 결과 객체의 수명을 관리합니다.

결과 해석

ROI와 연결성, 전처리 순서는 영역 측정에 영향을 줍니다. 같은 계획을 다른 입력이나 설정에서 비교할 때 각 실행의 조건을 함께 기록하고, 성분 번호를 프레임 간 영구 식별자로 가정하지 않습니다.
