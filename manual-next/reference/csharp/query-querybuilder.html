사용과 결과 해석

C#의 지연 Query 빌더가 공유하는 기반 소유 객체입니다. 연산을 추가할 때 즉시 픽셀 결과를 계산하는 대신 계획을 만들며, 결과는 실행 메서드에서 얻습니다. 빌더는 네이티브 자원을 소유하므로 사용 후 Dispose해야 합니다.

ImageQuery의 연산 추가는 같은 빌더 객체를 변경하고 반환합니다. 따라서 같은 객체를 가리키는 다른 변수에서도 변경된 계획이 보입니다. 서로 다른 연산으로 분기하려면 먼저 Clone하여 독립 계획을 만들고 각각을 별도로 해제하십시오. 연산 추가가 실패하면 기존 계획은 유지됩니다.

종결 Query와 실행 결과는 각각의 소유권을 가지므로 빌더를 해제하는 것과 모든 결과를 해제하는 것은 같은 동작이 아닙니다. 결과에서 얻은 스냅샷 또는 영상의 수명도 해당 타입의 계약을 따릅니다. 이 C# 가변 빌더의 별칭 동작을 Rust의 이동 기반 계획과 혼동하지 마십시오.
