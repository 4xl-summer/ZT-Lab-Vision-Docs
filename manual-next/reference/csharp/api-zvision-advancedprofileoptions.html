사용과 결과 해석

고급 프로파일이 영상 경계에서 표본을 읽는 방식과 최소 유효 폭을 지정하는 값입니다. Interpolation은 소수 좌표에서 영상값을 얻는 방법이고 MinValidWidth는 한 중심 위치에서 필요한 유효 횡단 표본의 최소 수입니다. 예를 들어 폭 3의 띠에서 영상 안에 남은 표본이 2개라면 최소 폭 2와 3은 서로 다른 유효성 조건이 됩니다. 폭이 유효한 위치의 평균 강도를 구하는 것과 프로파일에서 에지를 선택하는 것은 별도의 단계입니다. 최근접 방식과 이중선형 방식은 같은 소수 위치에서도 다른 강도를 만들 수 있으므로 에지 검출 임계값을 비교할 때 보간 설정도 기록하십시오. 선분 중심 하나만 영상 안에 있다고 전체 길이의 모든 위치가 충분한 횡단 폭을 갖는 것은 아닙니다. 에지 후보가 없다는 결과와 유효 폭 부족으로 인한 호출 실패를 구별하여 진단합니다. 위치는 ROI 로컬 픽셀 좌표이고 강도는 입력 영상의 값입니다. 다른 영상 형식이나 전처리 결과를 비교할 때 동일한 강도 수치가 동일한 물리 대비를 뜻한다고 가정하지 마십시오. 입력의 경계와 형식을 확인한 뒤 각 옵션의 실제 생성 조건을 지킵니다. 모든 위치에서 최소 폭을 충족하는지 확인하고 필터와 보간을 변경한 실험은 같은 입력으로 비교하십시오.
