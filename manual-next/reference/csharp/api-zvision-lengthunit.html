DepthCalibration..ctor: 깊이 선형 보정을 만듭니다. unit 인자: 위치와 거리의 길이 단위입니다.

DepthMap.FromValues: 행 우선 높이 배열을 복사해 격자를 만듭니다. null은 결측이며 NaN과 무한대는 유효값으로 허용하지 않습니다. unit 인자: 위치와 거리의 길이 단위입니다. 반환: 호출자가 해제할 소유 핸들입니다.

JointBundleOptions..ctor: 공동 정련 옵션을 지정합니다. unit 인자: 공통 길이 단위입니다.

JointCameraOptions..ctor: 고정 렌즈 공동 보정 옵션을 지정합니다. unit 인자: 물리 길이 단위입니다.

JointObservationFrame..ctor: 명시 프레임과 단위를 지정합니다. unit 인자: 물리 길이 단위입니다.

LineScanCamera..ctor: 횡방향 배율과 라인당 이동 거리를 지정합니다. unit 인자: 물리 길이 단위입니다.

LineScanUnitCalibration.Project: 물리 점을 픽셀·라인으로 변환합니다. unit 인자: 점의 길이 단위입니다. 반환: 픽셀과 라인입니다.

LineScanUnitCalibration.Unproject: 픽셀·라인을 물리 점으로 변환합니다. unit 인자: 요청 물리 길이 단위입니다. 반환: 지정 단위의 점입니다.

MetricGrid..ctor: 물리 격자의 크기와 축별 간격을 지정합니다. unit 인자: 간격의 단위입니다.

픽셀 좌표와 길이 단위

이 열거값은 밀리미터, 마이크로미터, 미터처럼 세계 공간의 길이 단위를 식별합니다. 픽셀은 이 열거값의 한 항목이 아닙니다. 예를 들어 1 mm는 1,000 µm이지만, 1픽셀을 1 mm로 바꾸려면 별도로 보정 모델이나 배율 정보가 필요합니다. 단위 변환만으로 픽셀과 세계 공간의 관계가 생기지는 않습니다.

평면 보정은 글로벌 픽셀 좌표와 모델의 세계 단위를 연결합니다. ROI 로컬 좌표를 사용한다면 먼저 ROI 원점을 더해 글로벌 픽셀로 바꾼 뒤 모델에 적용해야 합니다. 예를 들어 로컬 (10, 20)과 원점 (100, 200)을 합치면 글로벌 점은 (110, 220)입니다. 이 숫자는 좌표 변환 예이며 어떤 세계 길이 결과가 나온다는 뜻은 아닙니다.

세계 좌표를 주고받는 API에서는 입력 또는 출력 단위를 명시합니다. 잘못된 열거값, 유한하지 않은 값이나 표현 범위를 넘는 단위 변환은 오류가 될 수 있습니다. 값과 함께 단위를 기록하면 서로 다른 mm와 µm 결과를 같은 숫자로 잘못 비교하는 일을 줄일 수 있습니다.
