사용과 결과 해석

RGB 입력이 어떤 전달 함수로 인코딩되었는지 지정합니다. sRGB 선택과 감마 지수를 사용하는 선택은 색 성분을 선형 광도에 대응시키는 방법이 다릅니다. 색 공간 변환에 앞서 입력 데이터가 실제로 어떤 방식으로 만들어졌는지에 맞춰야 합니다.

예를 들어 이미 선형 광도인 숫자를 sRGB로 잘못 해석하면 중간 밝기 값의 변환 결과가 달라지고, 이후 XYZ나 Lab 비교에도 차이가 전파됩니다. 반대로 인코딩된 값을 선형으로 취급해도 같은 문제가 생깁니다. 감마 지수를 지정하는 경우 해당 설정의 유효 범위를 확인해야 합니다.

전달 함수는 채널 순서, 백색점, 관측자 및 카메라 색 보정 행렬과는 별도의 조건입니다. 같은 RGB 숫자를 비교하더라도 이 조건이 다르면 의미가 달라지므로 변환 설정을 결과와 함께 기록하십시오. 이 옵션 하나가 조명 변화를 자동으로 보정하지는 않습니다.
