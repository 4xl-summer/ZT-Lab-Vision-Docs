경계까지의 거리 통계

BlobBoundaryStatistics는 전경 무게중심과 경계 픽셀 중심 사이의 거리 분포를 측정합니다. 전경 면적, 경계 수, 평균 거리와 편차 등은 서로 다른 지표입니다. 경계 픽셀 수와 노출된 셀 변의 합도 같은 값이 아닙니다.

원형도 계산

거리 평균이 4이고 모집단 표준편차가 1인 경우 1 - 1/4는 0.75입니다. 이 원형도 정의는 다른 도구의 면적과 둘레 기반 원형도 식과 다를 수 있으므로 숫자를 직접 비교할 때 공식을 확인해야 합니다. 단일 픽셀의 0거리 사례는 별도 정의가 적용됩니다.

Measure와 입력

전경 마스크와 작업 한도를 Measure에 전달하고 각 결과를 원본 형상과 대조합니다. ROI가 물체를 자르거나 작은 잡음이 포함되면 중심과 경계가 함께 달라질 수 있어 분할 조건을 기록해야 합니다.

판정의 한계

평균과 편차가 비슷해도 국소 결함의 위치와 모양은 다를 수 있습니다. 하나의 요약 숫자만으로 결함 유무를 단정하지 말고 필요한 경계 위치 및 물리 보정 조건을 별도로 확인합니다.
