사용 맥락과 결과 해석

하나의 특징 모델에서 반복 인스턴스를 검색한 결과입니다. Instances는 각 인스턴스의 변환과 대응을, Evaluated는 전체 평가 가설 수를 제공합니다. Incomplete가 참이면 공유 예산 때문에 탐색이 완전히 끝나지 않았을 수 있으므로 결과가 없다는 사실만으로 영상 전체에 물체가 없다고 결론 내리지 않습니다.

각 변환은 모델 로컬에서 검색 영상 로컬로 향하며 대응점과 내점 수를 함께 확인합니다. 다중 인스턴스 검색에는 상호 최근접 옵션을 끄는 조건이 있습니다. 예산과 최대 인스턴스 수는 다른 제한이므로 둘을 구분해 설정하고, ROI 원점이 있는 경우 원본 표시 좌표로 옮기는 절차를 기록하세요.

각 인스턴스의 대응점 집합이 서로 다른 검출을 설명하는지 확인합니다. 총 가설 예산을 바꾸면 미완료 여부와 발견되는 결과가 함께 달라질 수 있습니다.

값을 확인하는 순서

Instances 항목: 발견된 인스턴스입니다. Evaluated 항목: 평가 가설 총수입니다. Incomplete 항목: 공유 예산으로 검색이 중단됐는지 나타냅니다.
