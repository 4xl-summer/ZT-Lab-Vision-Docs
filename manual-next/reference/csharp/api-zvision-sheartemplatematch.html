사용 맥락과 결과 해석

전단 NCC 검색의 기본 포즈 Matched와 무차원 x 전단 계수 Shear를 함께 나타냅니다. 전단은 템플릿 로컬 좌표에서 u′=u+shear×v로 정의됩니다. Shear가 0이면 이 성분이 없으며 회전과 배율은 기본 포즈에서 따로 읽습니다.

예를 들어 계수 1은 v가 한 단위 증가할 때 u에 한 단위를 더합니다. 반환 기준점의 로컬 및 전역 좌표를 구별하고 결과를 만든 전단 격자와 작업 상한도 함께 보관하세요. 상위 보고서가 예산이나 시간으로 중단되었다면 가능한 모든 전단값이 평가되었다고 볼 수 없습니다.

전단값과 angle은 서로 다른 단위이므로 직접 더하거나 비교하지 않습니다. 템플릿의 v 좌표와 전단 계수를 곱한 뒤 u에 반영하는 순서를 모델의 회전·배율 포즈와 함께 해석합니다. 서로 다른 전단 후보를 비교할 때 score만 보지 말고 적용한 격자와 제한을 기록합니다. 영상의 일부가 ROI 밖으로 나가면 해당 후보의 표본 조건도 달라질 수 있습니다.
