속성에 따른 경로 분할

BlobContourSegment는 윤곽의 점별 속성이 지정 범위를 만족하는 연속 구간으로 경로를 분할합니다. 결과는 전체 물체가 아니라 조건을 만족하는 경계의 일부이므로 선택한 속성과 범위를 함께 기록해야 합니다.

닫힌 윤곽의 일부

입력 윤곽이 고리여도 일부 호만 선택되면 그 구간의 양 끝을 자동으로 연결해 면적을 계산해서는 안 됩니다. 전체 닫힌 경로가 선택된 경우와 일부 연속 구간의 Closed 상태를 구분합니다.

Segment의 입력

윤곽 점 순서와 점별 속성의 대응을 유지하고 허용 범위 및 작업량 한도를 호출 시그니처에 맞게 지정합니다. 점 목록만 재정렬하면 속성과 위치가 어긋나 다른 구간이 선택될 수 있습니다.

결과 사용

선택 구간을 원본 윤곽에 겹쳐 조건이 적용된 위치를 확인합니다. ROI 로컬 경로를 전체 영상에 표시하려면 원점을 맞추고, 후속 길이 측정에서는 해당 구간의 열림·닫힘을 반영합니다.
