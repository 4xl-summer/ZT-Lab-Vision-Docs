사용과 결과 해석

매칭 검색 격자의 방문 우선순위를 정할 때 사용하는 예상 포즈입니다. X와 Y는 입력 영상의 로컬 위치, Angle은 라디안, ScaleX와 ScaleY는 두 축의 배율입니다. 이 값은 검색의 우선 위치를 표현하며 실제로 검출된 포즈나 검사 결과를 저장하는 구조체가 아닙니다.

예를 들어 이전 프레임에서 물체가 왼쪽 위에 있었다면 그 위치를 예상값으로 사용해 후보 방문 순서를 바꿀 수 있습니다. 다만 예상이 틀릴 수 있으므로 검색 범위와 점수 조건 자체가 어떤 후보를 허용하는지는 별도 검색 옵션에서 확인해야 합니다. prior의 사용만으로 특정 결과가 반드시 검출되거나 최적해가 보장된다고 추론하지 마십시오.

ROI를 사용하는 경우 X와 Y를 해당 로컬 좌표계에 맞추고 전체 영상 좌표를 그대로 넣지 않도록 주의합니다. 회전은 도가 아닌 라디안이며 축별 배율도 이미지 크기와 별도로 해석해야 합니다. 실제 결과의 점수와 종료 상태를 함께 기록하면 예측과 측정의 차이를 분석할 수 있습니다.
