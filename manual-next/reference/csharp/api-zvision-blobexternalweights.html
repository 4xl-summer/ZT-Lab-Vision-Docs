외부 가중치로 성분 측정

BlobExternalWeights는 Blob 레이블별로 별도의 가중치 영상에서 가중 면적과 중심을 측정합니다. 레이블은 소속을, 가중치 영상은 각 픽셀의 기여도를 결정합니다. 면적 값은 단순 전경 픽셀 수와 다를 수 있습니다.

계산 예

x=0과 x=2인 두 위치의 가중치가 1과 3이면 가중치 합은 4이고 가중 x 중심은 (0×1+2×3)/4=1.5입니다. 두 위치에 같은 가중치를 준 단순 중심 1과 다릅니다. 가중치 분포가 중심 위치를 바꿉니다.

Measure 입력

Blob 결과와 같은 크기의 가중치 영상, 작업량 한도를 해당 호출 조건에 맞게 준비합니다. 픽셀 형식과 값의 유효성, 두 영상의 ROI 정렬을 확인합니다. 크기만 같고 원점이 다르면 라벨과 잘못된 가중치가 결합될 수 있습니다.

결과 해석

반환 레이블과 가중 합 및 로컬 중심을 함께 읽고, 전체 영상에 표시할 때 ROI 원점을 맞춥니다. 가중치 영상의 물리적 의미나 보정은 입력을 만든 과정에서 별도 확인해야 합니다.
