블롭 외접원 계산

BlobOuterCircleOps는 선택한 블롭의 픽셀 셀 모서리를 감싸는 최소 외접원을 측정합니다. 외곽에 튀어나온 셀은 원의 크기에 영향을 줄 수 있습니다. 외접원 내부가 모두 전경이라고 가정하면 구멍이나 오목한 부분을 놓칩니다.

성분의 선택

Measure의 입력 결과와 성분 인덱스를 확인합니다. 인덱스는 0을 기준으로 하므로 첫 성분은 0입니다. 성분의 순서는 분석 결과에 속하며 다음 프레임의 같은 인덱스가 동일 객체를 의미하는 것은 아닙니다. 작업량 제한도 해당 호출 계약에 맞게 지정합니다.

결과와 좌표

반환되는 BlobOuterCircle은 ROI 로컬 중심과 픽셀 단위 반지름을 제공합니다. 마스크 위에 원을 겹쳐 선택한 성분의 경계를 감싸는지 살펴보고 전체 영상 좌표가 필요하면 ROI 원점을 더합니다.

해석 한계

원 면적은 전경 픽셀 면적과 다르며, ROI에서 잘린 객체의 원은 보이는 부분에 대한 결과입니다. 실제 직경으로 판정하려면 이미지 보정, 축 간격과 마스크 생성 조건을 함께 확인해야 합니다.
