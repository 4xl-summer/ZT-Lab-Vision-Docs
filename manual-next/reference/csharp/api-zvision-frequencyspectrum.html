ZVision.FrequencySpectrum · class

어셈블리: ZVision.

별도로 소유하는 복소 FFT 스펙트럼입니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

주파수 응답을 적용한 별도 모델을 생성합니다.

인자

profile
필터 응답입니다.
pass
통과 종류입니다.
low
주파수 하한 또는 차단 반경입니다.
high
대역 상한이며 대역 외에는 0입니다.
centerX
노치 중심 x이며 노치 외에는 0입니다.
centerY
노치 중심 y이며 노치 외에는 0입니다.
order
Butterworth 차수이며 그 외에는 0입니다.

반환: 독립 소유 모델입니다.
