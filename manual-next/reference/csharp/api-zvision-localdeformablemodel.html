Train

템플릿을 복사하고 NCC 후보 모델을 학습합니다.

Find

반환: 결과 유무와 종료 진단을 보존하는 보고입니다.

FindConstrained

인접 제어점의 변형률 상한을 적용해 탐색합니다.

FindPhotometric

양의 gain과 bias를 각 지역 후보에서 적합해 탐색합니다.

FindRobust

부분 가림에 대해 포화 잔차와 inlier 비율을 적용합니다.

FindCurvature

2차 곡률을 정규화해 아핀 변위를 보존하며 탐색합니다.

FindMany

서로 다른 거친 포즈의 국소 변형을 각각 탐색합니다.

FindManyPhotometric

각 인스턴스의 양의 gain과 bias를 함께 적합합니다.

FindManyRobust

복수 인스턴스에 강건 잔차와 inlier 조건을 적용합니다.
