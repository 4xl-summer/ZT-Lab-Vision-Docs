AdvancedRecognition.BarcodeGridQuality: 지정된 셀 격자의 비표준 대비, 변조, 규칙성 진단을 계산합니다. region 인자: 여백을 제외한 셀 격자 영역입니다. 반환: ISO 등급이 아닌 정량 진단입니다.

AiEngine.Run: 영역을 추론합니다. 픽셀을 255로 나눈 NCHW F32로 만들고 좌표별 floor 최근접 샘플링으로 비율 유지 없이 늘립니다. 입력은 바꾸지 않습니다. region 인자: 이미지 로컬 반열린 영역입니다. 반환: 호출자가 해제할 독립 결과입니다. 분류·분할 로짓 동률은 작은 클래스 ID를 선택하며 분류 점수의 F32 반올림 동률에서도 원래 로짓을 따릅니다.

ZImage.PrepareAdvanced: 영상 영역을 모델용 NCHW 텐서로 변환합니다. region 인자: 원본 영상 영역입니다. 반환: 호출자가 해제할 텐서입니다.
