사용과 결과 해석

전처리 파이프라인에서 실행한 단계와 비활성 상태로 생략한 단계의 개수를 알려줍니다. Executed와 Skipped는 단계 수이며 처리한 픽셀 수나 오류 수가 아닙니다. 동일한 입력에 여러 단계를 지정했을 때 실행 순서는 별도의 단계 배열에서 확인해야 합니다.

예를 들어 세 단계 중 두 단계가 활성화되고 한 단계가 비활성화되었다면 보고서는 실행 2와 생략 1을 나타냅니다. 이 숫자만으로 어느 단계가 생략되었는지 또는 각 단계의 파라미터가 무엇인지는 알 수 없으므로 입력 설정을 함께 기록하십시오.

보고서는 성공적으로 반환된 실행의 요약이며 생략된 단계가 적용되었다고 가정해서는 안 됩니다. 중간 필터의 수치 효과와 출력 픽셀 형식은 실제 파이프라인 계약을 따릅니다. 오류가 전달된 호출과 정상 반환된 보고서를 구별해 처리하십시오.
