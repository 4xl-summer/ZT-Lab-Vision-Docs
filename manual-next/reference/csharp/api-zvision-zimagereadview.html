ZVision.ZImageReadView 컴파일된 공개 멤버

공개 타입

ZVision.ZImageReadView · class

어셈블리: ZVision.

픽셀을 복사하지 않는 읽기 전용 임대입니다. 열린 행이 모두 닫힐 때까지 저장소가 유지됩니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object

컴파일된 ZVision 어셈블리에서 확인한 공개 멤버입니다. XML 설명이 없는 반환값, 오류와 지원 조건은 미확인입니다.

OpenRow

픽셀 복사 없이 패딩을 제외한 지정 행의 논리 바이트를 읽는 스트림을 엽니다. 뷰나 원본을 해제해도 열린 행은 스트림을 해제할 때까지 유효합니다. 뷰 해제 후에는 새 행을 열 수 없습니다.

Dispose

뷰의 임대를 해제합니다. 이미 열린 행은 각 스트림이 해제될 때까지 유효합니다.
