사용 맥락과 결과 해석

입력 점 집합에 대해 강건 선·원·타원 적합을 수행하는 공개 진입점입니다. 각 방법은 점과 강건 적합 옵션을 받아 적합 상태, 반복·수렴 진단과 점별 잔차·가중치를 반환합니다. 추정하려는 형상에 필요한 최소 점 수와 유한 좌표를 먼저 준비해야 합니다.

강건 손실은 큰 잔차의 영향을 조절하지만 잘못된 입력 점이나 퇴화 기하를 자동으로 올바르게 만들지는 않습니다. 특히 타원의 잔차는 최근접 거리와 동일하지 않은 반경 방향 대용값입니다. 결과의 상태와 내점·잔차 분포를 함께 확인하고, 픽셀 좌표를 썼다면 길이와 임계값도 같은 단위로 해석합니다.

예상 형상을 따라 영상에 탐침을 배치하는 측정 모델과 이미 주어진 점을 적합하는 이 API는 입력 단계가 다릅니다. 점을 생성한 방법과 ROI 원점을 별도로 추적해야 최종 계수의 좌표를 올바르게 해석할 수 있습니다. 최소 점 수를 충족해도 점들이 같은 위치에 모여 있으면 기하가 퇴화할 수 있습니다. 유효한 분포와 적합 상태, 반복 진단을 함께 확인한 뒤 후속 계산에 사용하세요.
