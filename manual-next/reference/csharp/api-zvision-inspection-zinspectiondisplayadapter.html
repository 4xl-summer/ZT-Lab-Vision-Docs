사용과 결과 해석

검사 결과의 지정 단계를 표시 프레임으로 바꾸는 어댑터입니다. result는 빌린 검사 결과, stage는 단계 이름이고 반환 프레임은 결과와 독립적으로 호출자가 해제해야 합니다. 내부에서 해당 단계의 영상 공유를 획득해 프레임에 연결합니다.

Threshold와 Close 단계에는 선택된 Blob의 ROI 로컬 경계를 사각형 오버레이로 추가합니다. 다른 단계에서 같은 오버레이가 자동으로 표시된다고 가정하지 말고 단계 이름을 확인하십시오. 오버레이는 표시용 기하이며 원본 검사 픽셀을 바꾸는 편집이 아닙니다.

프레임에는 원래 결과의 frame 및 recipe 세대가 전달됩니다. 화면이 오래된 결과를 표시하지 않도록 현재 입력과 세대를 비교하고, 결과와 표시 프레임의 수명을 각각 관리하십시오. 화면에 보이는 경계만으로 검사 정확도가 검증되지는 않습니다.
