사용과 결과 해석

비바이트 채널을 화면에 표시할 때 사용하는 표시 범위입니다. Minimum은 유한한 하한, Maximum은 그보다 큰 유한한 상한입니다. 생성자의 기본 범위는 0부터 65535까지이며 유효하지 않은 범위에는 인자 오류가 발생합니다.

예를 들어 값의 유용한 범위가 1000~2000에 집중된 영상을 기본 0~65535로 표시하면 명암 차이가 작게 보일 수 있습니다. 표시 범위를 1000~2000으로 지정하면 그 구간을 화면에서 더 잘 살펴볼 수 있습니다. 이는 표시 변환이며 원본 영상의 수치가 바뀌었다는 뜻은 아닙니다.

동일한 영상을 서로 다른 범위로 보면 색이나 밝기가 달라 보일 수 있으므로 시각 비교 시 범위도 함께 기록하십시오. 화면을 보기 좋게 만든 설정과 측정 알고리즘에 전달되는 원본 픽셀은 구분해야 하며, 표시만으로 센서 보정이나 수치 검증을 대신할 수 없습니다.
