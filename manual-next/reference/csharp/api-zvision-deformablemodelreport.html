사용과 결과 해석

변형 모델 검색에서 반환된 후보와 검색 종료에 관한 진단을 함께 보관합니다. Matches는 검색 조건을 만족한 변형 후보 배열이며 종료 상태는 전체 검색을 완료했는지 또는 제한에 도달했는지 해석하는 데 필요합니다. 후보가 하나 있다는 사실만으로 모든 가능한 위치를 검사했다고 가정하면 안 됩니다.

각 후보의 위치, 점수 및 변형 정보는 학습 모델과 검색 설정의 좌표계에서 확인하십시오. 변형 허용량과 마스크, 점수 임계값이 달라지면 같은 영상에서 결과 배열도 달라질 수 있습니다. 빈 배열은 유효한 검색에서 후보가 없다는 상태일 수도 있으므로 예외와 구별합니다.

배열은 결과의 독립 복사본으로 제공됩니다. 결과를 비교할 때는 후보 순서뿐 아니라 종료 진단과 실제 평가 범위를 함께 보관해야 시간 또는 후보 예산에 따른 중단을 놓치지 않습니다. 변형 모델이 허용하는 범위 바깥의 실제 변형에 대해서는 별도의 검증이 필요합니다.
