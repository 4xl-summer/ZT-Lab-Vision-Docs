사용과 결과 해석

SSIM 검사에서 계산한 마스크 가중 평균 점수와 검사 중심 수, 결함 중심 수를 요약합니다. Score는 포함된 중심들의 전역 평균이고 Included는 평가한 중심의 수, DefectCount는 결함 조건에 해당한 중심 수입니다. 이 수치는 전체 영상의 모든 픽셀을 검사했다는 뜻이 아닐 수 있습니다.

마스크로 작은 영역만 포함하면 평균이 높더라도 검사하지 않은 곳의 품질은 알 수 없습니다. 예를 들어 Included가 기대한 ROI의 중심 수보다 작으면 마스크와 경계 조건을 먼저 확인하십시오. 평균 점수와 결함 수는 서로 다른 요약이므로 함께 보아야 합니다.

SSIM은 기준과 검사 영상의 기하 정렬과 광도 조건에 민감합니다. 지정한 창, 마스크 및 임계값을 결과와 함께 기록하고 마스크 밖을 합격으로 단정하지 마십시오. 실제 장비의 불량 검출력은 별도 자료로 평가해야 합니다.
