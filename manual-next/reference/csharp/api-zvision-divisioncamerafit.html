사용과 결과 해석

고정된 내부 파라미터에서 division 왜곡 계수를 적합한 카메라와 재투영 RMS를 담습니다. Camera는 계산된 모델이고 RmsPixels는 대응점의 픽셀 기준 재투영 오차 요약입니다. 이 RMS는 구현이 최적화하는 대수 목적 함수 자체와 동일한 값이 아닙니다.

적합에 사용한 대응점의 픽셀 좌표와 정규화 좌표가 같은 카메라 설정을 따르는지 확인하십시오. 영상 중심 주변에만 점이 몰리면 가장자리 왜곡을 충분히 제약하지 못할 수 있습니다. RMS가 작더라도 시야 전반의 잔차와 별도의 보류점을 확인하는 이유입니다.

모델의 계수는 다른 렌즈 모델의 계수와 이름이 같다는 이유로 그대로 교환하면 안 됩니다. 계산된 카메라는 division 모델의 식과 좌표 규약에서 사용하고, 원점과 해상도 변경 시 설정을 다시 검토하십시오. 이 결과는 실제 렌즈나 조명 조건의 장기 안정성을 보증하지 않습니다.
