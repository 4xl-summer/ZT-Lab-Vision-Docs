사용 맥락과 결과 해석

확장 매칭의 복사된 후보 배열, 평가 포즈 수와 종료 상태를 함께 담습니다. Matches가 비어 있어도 Termination이 완료인지 예산·시간·확실도인지 확인해야 합니다. Evaluated는 실제 평가한 자세 수이며 발견된 물체의 수가 아닙니다.

후보가 있더라도 예산으로 멈췄다면 모든 격자점이 평가되었다는 뜻은 아닙니다. 각 매치의 로컬 및 전역 기준점, 회전·축 배율과 점수를 읽고 검색에 사용한 ROI와 설정을 함께 보관합니다. 반환 배열은 결과에서 복사되는 값이므로 원본 영상이나 모델의 네이티브 수명과 구분해 다룹니다.

점수 하한을 낮추는 것과 평가 예산을 늘리는 것은 서로 다른 조치입니다. 검색이 예산 때문에 일찍 끝났다면 먼저 공간이 실제로 얼마나 평가되었는지 확인해야 합니다.

값을 확인하는 순서

Matches 항목: 점수 순서의 후보 복사본입니다. Evaluated 항목: 평가된 포즈 수입니다. Termination 항목: 검색 종료 이유입니다.
