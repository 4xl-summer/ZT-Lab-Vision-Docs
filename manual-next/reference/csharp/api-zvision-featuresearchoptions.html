이 타입을 받는 공개 호출

FeatureCollectionEntry..ctor: 모델 ID, 소유 모델과 검색 옵션을 지정합니다. options 인자: 모델별 대응 설정입니다.

FeatureInstanceCollectionEntry..ctor: 모델 항목을 만듭니다. options 인자: 검색 중 변경하지 않을 설정입니다.

FeatureInstanceSearch.Find: 한 소스 특징은 한 객체에만 사용하며 모델 특징은 재사용합니다. options 인자: 대응 및 RANSAC 설정이며 Mutual=false여야 합니다. 호출 중 설정 객체를 수정하지 마세요. 반환: 독립 복사된 반복 검색 결과입니다.

FeatureModel.Find: 실제 소스 영상에서 특징을 검출하고 기하 변환을 검증합니다. options 인자: 기술자와 가설 설정입니다. 반환: 독립 대응·행렬·잔차 스냅샷입니다.

InvariantFeatureModel.Find: 소스 영상에서 방향 특징점을 검색하고 기하를 검증합니다. options 인자: 대응 및 기하 설정입니다. 반환: 독립 대응 결과입니다.
