전경 분포의 중앙

BlobAreaMedian은 전경 픽셀 좌표를 축별로 정렬해 낮은 중앙값을 측정합니다. 이 통계는 모든 좌표의 합을 개수로 나누는 산술 중심과 다르며 외곽의 일부 픽셀이 결과에 주는 영향도 다를 수 있습니다.

Measure의 결과

결과 BlobAreaMedianResult는 픽셀 수 Area와 ROI 로컬 X, Y를 제공합니다. 한 축에 값 0, 1, 4, 9가 있으면 낮은 중앙값은 1입니다. 각 축을 독립적으로 처리하므로 두 값으로 만든 위치가 반드시 전경 픽셀 위에 있지는 않습니다.

처리 순서

먼저 대상 전경이 선택된 마스크를 준비한 뒤 Measure의 입력과 작업 한도 조건을 확인합니다. 결과 좌표를 원본 전체 영상에 표시할 때는 ROI 원점을 적용하고 선택한 전경 분포와 함께 봅니다.

적용 조건

두 영상의 결과를 비교할 때 마스크가 같은 방식으로 생성되었는지 확인합니다. 먼 위치의 잡음이나 다른 물체가 함께 포함되면 전경 분포가 달라집니다. 결과 위치만으로 실제 장비 좌표나 객체 추적 ID가 정해지는 것은 아닙니다.
