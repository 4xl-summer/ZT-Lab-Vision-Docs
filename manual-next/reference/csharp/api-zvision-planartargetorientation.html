사용과 결과 해석

카메라에서 본 평면 타깃의 자세를 앞면, 뒷면 또는 접선 상태로 분류합니다. 입력은 camera←target 강체 자세이며 대상의 +Z 방향을 앞면 기준으로 사용합니다. 변환 방향을 반대로 전달하면 서로 다른 좌표계의 벡터를 비교하게 되므로 먼저 프레임을 확인해야 합니다.

앞면과 뒷면의 분류는 타깃 법선이 카메라에 대해 향하는 방향을 설명합니다. 접선 상태는 그 방향 관계가 경계에 가까워 앞뒤를 안정적으로 구별하기 어려운 경우입니다. 이는 2D 영상에서 타깃이 차지하는 면적이나 조명 밝기로 결정하는 단순 분류가 아닙니다.

결과는 입력 자세로부터 계산한 기하적 방향이며 평면 타깃의 실제 인쇄면이나 카메라 보정이 올바르다는 검증을 대신하지 않습니다. 자세가 다른 단위나 잘못된 프레임에서 왔다면 먼저 변환을 바로잡고, 자세 추정 오차가 큰 경우 별도의 진단도 함께 보십시오.
