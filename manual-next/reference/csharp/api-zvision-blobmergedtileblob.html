결합된 성분의 값

BlobMergedTileBlob은 가로 타일을 합친 뒤 연결된 성분의 Area와 CentroidX, CentroidY를 보관합니다. 면적은 전경 픽셀 수이며 중심은 결합 영상 로컬 좌표의 픽셀 중심 평균입니다. 각 타일에서 독립적으로 계산한 중심을 그대로 평균한 값과 구분합니다.

이음새 예

결합 좌표의 두 픽셀이 (1,0)과 (2,0)에 있고 하나의 성분으로 연결되면 Area는 2이고 중심은 (1.5,0)입니다. 오른쪽 타일만의 로컬 좌표에는 왼쪽 타일의 폭이 빠져 있으므로 그대로 평균하면 다른 위치가 됩니다.

연결 조건

타일 경계에서 대각선으로만 만나는 픽셀은 선택한 4 또는 8 연결성에 따라 하나의 성분이 될 수도, 따로 남을 수도 있습니다. 결과 수와 함께 결합 레이블 맵 및 각 면적을 확인하세요.

좌표 활용

결합 영상의 원점이 원본 전체 영상과 다르면 중심을 표시할 때 해당 기준을 맞춥니다. 타일의 정렬이나 분할 자체가 올바른지는 이 결과만으로 보장되지 않으므로 원본과 이음새를 함께 점검합니다.
