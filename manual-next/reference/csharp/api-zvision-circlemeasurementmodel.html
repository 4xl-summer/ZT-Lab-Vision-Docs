사용과 결과 해석

ROI 로컬 기준 원호와 프로브 설정을 복사·검증하여 재사용하는 원 측정 모델입니다. 생성자의 spec은 탐색할 기준 원호이고 options는 프로브와 피팅 설정입니다. Measure에 ZImage를 전달하면 해당 영상의 ROI에서 관측한 점을 바탕으로 원을 계산하며 이미지와 독립적인 불변 결과를 반환합니다. 기준 원의 중심과 반경은 검색 위치를 정하는 입력이지 결과가 반드시 같은 원이어야 한다는 뜻이 아닙니다. 예를 들어 반경 10픽셀의 기준 원을 설정해도 관측된 에지가 더 바깥에 있으면 실제 검색 범위와 선택 결과에 따라 적합 반경이 달라질 수 있습니다. 각 프로브가 경계를 가로지르는지, 충분한 에지가 발견됐는지와 적합에 채택됐는지를 구분하여 확인하십시오. 원호가 짧거나 한쪽에 점이 몰리면 점 수만으로 원의 모든 방향이 관측되었다고 말할 수 없습니다. 결과의 상태와 잔차를 확인하고 측정 실패를 반경 0의 정상 원으로 대체하지 마십시오. 모델을 다른 영상에 재사용할 때에는 그 영상의 ROI 크기와 원점, 목적 물체가 기준 원호의 검색 범위에 들어오는지 다시 점검합니다. 결과 중심과 반경의 단위는 픽셀입니다. 물리 단위 변환 전에는 보정 모델과 원호가 사용한 영상 좌표계를 확인하십시오.
