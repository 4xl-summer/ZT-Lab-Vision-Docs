사용과 결과 해석

한 탐침의 측정 결과와 명목상 탐침 띠가 ROI 바깥으로 잘렸는지를 함께 보여 줍니다. Observation은 탐침 인덱스, 기준 위치, 검출 상태 및 에지 관찰을 제공하고 Clipped는 설정된 띠와 영상 경계의 관계를 나타냅니다. ROI 가장자리에서 실패한 이유를 살펴볼 때 둘을 같이 보는 것이 중요합니다.

Clipped가 true라는 것은 스트립이 경계 밖으로 나간다는 뜻이지 모든 측정이 무조건 실패했다는 뜻은 아닙니다. 반대로 false여도 대비나 극성 조건 때문에 에지가 없을 수 있습니다. 관측의 에지 유무와 적합 사용 여부를 확인한 뒤 전체 모델 상태와 커버리지 결과를 살펴보십시오.

관측 위치는 ROI 로컬이므로 전체 이미지 또는 월드 좌표와 비교할 때 원점과 보정 변환을 적용해야 합니다. 이 객체는 독립 탐침 진단을 담으며 명목 탐침 하나의 기록만으로 모델 전체의 합격을 결정하지 않습니다. 여러 탐침의 분포와 누락을 함께 검토해야 합니다.
