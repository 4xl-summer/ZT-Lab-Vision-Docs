사용과 결과 해석

최종 기하 모델의 입력 수와 채택된 점들의 잔차를 요약합니다. Count는 입력 또는 검증된 항목 수, Inliers는 최종 모델에 채택된 점 수입니다. RmsError와 MaxError는 채택점의 기하 잔차이며 점 좌표와 같은 단위를 사용합니다.

예를 들어 픽셀 좌표로 선을 적합했다면 RMS가 0.5라는 값은 픽셀 기준입니다. 보정된 밀리미터 좌표로 적합했다면 같은 숫자의 물리적 의미가 달라집니다. 평균적 오차를 나타내는 RMS와 가장 큰 잔차는 서로 다른 정보를 주므로 어느 한 값만으로 분포 전체를 판단하지 마십시오.

내점 수가 Count보다 작다면 제외된 점과 그 선택 기준도 함께 살펴야 합니다. 이 통계는 채택된 데이터에 대한 요약이며, 제외된 모든 이상점의 최대 오차를 뜻하지 않습니다. 사용자 공차나 실제 장비의 정확도를 판정하려면 해당 모델의 좌표와 독립 검증 데이터를 추가로 확인하십시오.
