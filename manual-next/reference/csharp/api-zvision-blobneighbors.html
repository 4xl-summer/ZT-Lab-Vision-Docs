거리 기준 이웃

BlobNeighbors는 여러 영역 사이의 경계 거리를 비교해 주어진 한도에 해당하는 이웃 관계를 구합니다. 성분의 중심 거리가 아니라 경계 픽셀 중심의 최소 거리를 기준으로 하므로 큰 물체의 가장자리가 가까운 경우를 다르게 해석할 수 있습니다.

한도 예

가장 가까운 두 경계 중심의 차이가 가로 3, 세로 4픽셀이면 거리 5입니다. 최대 거리가 5인 조건은 이 경계값의 포함 여부를 확인하는 사례가 됩니다. 픽셀 중심 거리와 셀의 실제 빈틈 크기를 같은 값으로 읽지 않습니다.

Find의 입력

영역 마스크의 순서와 좌표 기준, 거리 한도 및 작업량 제한을 확인해 Find를 호출합니다. 결과의 인덱스는 입력 목록에 대응하므로 목록을 바꾸기 전의 순서를 보존해야 합니다. 서로 다른 ROI의 마스크는 비교 가능한 공통 위치로 맞춥니다.

활용

결과 쌍을 원본 영상에 표시해 가까운 물체를 조사할 수 있습니다. 한도를 바꾸면 이웃으로 선택되는 쌍이 달라지지만 원본 마스크의 성분이 합쳐지는 것은 아닙니다. 물리 거리 기준이 필요하면 보정과 축 간격을 고려합니다.
