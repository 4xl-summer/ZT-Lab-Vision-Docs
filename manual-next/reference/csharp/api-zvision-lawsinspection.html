사용과 결과 해석

분리 가능한 Laws 기저 커널을 영상에 적용해 방향성 질감 응답을 계산합니다. 세로와 가로 기저, 커널 크기, shift와 경계 처리 방식에 따라 같은 영상의 응답이 달라집니다. 반환 응답은 부호가 있으므로 일반 Gray8 밝기 영상과 동일하게 취급하지 마십시오.

커널 크기 3, 5, 7마다 사용할 수 있는 기저 조합이 다르며, 영상 가장자리에서는 복제·반사 또는 상수 경계가 결과에 영향을 줍니다. 기준과 검사 영상을 비교한다면 같은 기저와 경계 조건을 사용해야 필터 설정 차이를 실제 질감 차이로 오인하지 않습니다.

응답 영상은 특징을 표현할 뿐 자체적으로 불량 여부를 확정하지 않습니다. 후속 통계나 임계값을 검사 목적에 맞게 정하고 결과 영상의 소유권을 해제하십시오. 실제 표면 조명 및 배율 변화에 대한 성능은 별도 검증이 필요합니다.
