사용과 결과 해석

바코드나 OCR 같은 인식 연산을 실행 전까지 지연하는 Query의 공통 소유 기반입니다. 계획을 만드는 단계와 실행 결과를 얻는 단계가 분리되어 있으며 사용 후 Dispose해야 합니다. 입력 옵션은 해당 인식 종결 계획을 만들 때 검증되는 부분과 실행 시 처리되는 부분이 있습니다.

서로 다른 계획으로 분기하려면 Clone으로 독립 핸들을 얻고 원본과 복제본을 각각 해제합니다. 인식 실행에서 반환되는 텍스트·판독 스냅샷과 별도 소유 준비 영상은 서로 다른 수명 계약을 가질 수 있으므로 결과 타입을 확인하십시오.

빈 판독이나 거절 상태는 정상적으로 실행된 결과일 수 있고 예외와 같지 않습니다. 입력 ROI, 회전 및 문자 조건을 유지해 결과를 해석하고, 계획 자체가 실제 OCR 모델이나 카메라 하드웨어를 제공하는 것으로 가정하지 마십시오.
