방향이 있는 셀 경계

AdvancedContourEdge는 픽셀 셀의 꼭짓점 두 개를 잇는 방향 있는 단위 선분입니다. FromX, FromY에서 ToX, ToY로 가는 방향을 담으며 픽셀 중심을 잇는 선분과 구분합니다. 여러 선분을 순서대로 이어 전경의 경계를 표현할 수 있습니다.

단위 선분 예

(0,0)에서 (1,0)으로 가는 변은 가로 길이 1의 선분이고 반대로 (1,0)에서 (0,0)으로 가면 같은 위치이지만 방향이 반대입니다. From과 To를 임의로 바꾸면 링을 따라가는 방향 정보가 달라집니다.

윤곽 사용

서로 이어지는 선분을 읽을 때 한 선분의 끝점과 다음 선분의 시작점이 연결되는지 확인합니다. 좌표를 원본 영상에 표시할 때는 분석 ROI의 기준을 함께 고려합니다. 단위 선분의 개수는 셀 경계 길이와 관련되지만 연속 곡선의 보정 둘레와 같은 값이라고 단정하지 않습니다.

비교 조건

마스크의 전경 픽셀이 한 칸 바뀌면 인접한 노출 경계 변과 연결 순서가 달라질 수 있습니다. 원본 마스크와 윤곽을 함께 표시하고 구멍 경계와 외곽 경계를 혼동하지 않도록 결과의 소속을 확인합니다.
