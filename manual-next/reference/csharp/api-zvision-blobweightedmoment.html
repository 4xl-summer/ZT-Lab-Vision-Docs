레이블별 가중 모멘트

BlobWeightedMoment는 하나의 Blob Label과 정규화하지 않은 가중 모멘트 Value를 담습니다. 좌표의 차수와 가중치가 계산의 의미를 정하며 Value는 자동으로 중심 위치가 되는 값이 아닙니다.

가중 합 예

x 좌표 0과 2에 가중치 1과 3이 있으면 가중치 합은 4이고 x의 1차 가중 합은 6입니다. 가중 중심 1.5는 6을 4로 나누어 별도로 얻습니다. 이처럼 정규화하지 않은 합과 정규화된 위치를 구별해야 합니다.

레이블과 원점

Label은 계산 결과 안의 성분 번호입니다. 다른 이미지의 같은 숫자가 같은 물체라는 뜻은 아닙니다. 모멘트는 좌표 원점과 단위에 영향을 받을 수 있으므로 결과를 비교할 때 차수와 ROI 기준도 함께 기록합니다.

측정 조건

가중치의 범위나 전경 픽셀 수가 달라지면 합도 달라질 수 있습니다. 물체 크기가 다른 결과를 비교하기 전에 어떤 정규화가 필요한지 정하고 입력 가중치 영상의 의미와 보정을 확인합니다.
