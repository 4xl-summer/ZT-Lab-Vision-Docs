C# API · ZVision.DepthMap / spatial3d

ZVision.DepthMap 컴파일된 공개 멤버

공개 타입

ZVision.DepthMap · class

어셈블리: ZVision.

직교 격자의 부호 있는 높이를 소유하는 불변 핸들입니다. 각 점은 origin + (x×spacingX, y×spacingY, height)이며 결측은 null입니다. 사용 후 해제합니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object

컴파일된 ZVision 어셈블리에서 확인한 공개 멤버입니다. XML 설명이 없는 반환값, 오류와 지원 조건은 미확인입니다.

Dispose

소유 핸들을 해제합니다. 별도로 공유한 핸들은 유효하게 남습니다.

FromValues

행 우선 높이 배열을 복사해 격자를 만듭니다. null은 결측이며 NaN과 무한대는 유효값으로 허용하지 않습니다.

ToValues

높이를 행 우선 배열로 복사하며 결측은 null로 반환합니다.

Share

저장소를 공유하는 별도 소유 핸들을 만듭니다. 원본 해제 후에도 유효합니다.

Roi

로컬 사각형의 저장소를 공유하며 원점을 XY 간격만큼 이동한 별도 핸들을 만듭니다.

Median

유효 이웃의 중앙값을 계산합니다. 결측 중심은 보존하고 유효 이웃 부족 시 결측입니다. 짝수 개는 중앙 두 값의 반합입니다.

FillHoles

원본의 유효 이웃으로 결측 중심만 채웁니다. 새로 채운 값은 같은 호출에서 전파되지 않습니다.

ToPointCloud

행 우선 슬롯과 결측을 보존해 독립 점군을 만듭니다.

Info

Property · 선언 타입 ZVision.DepthMap

반환: 크기, 유효 개수와 좌표계 정보입니다.
