회전된 두 축의 중앙값

BlobAxisMedian은 지정 방향의 두 직교 축으로 전경 좌표를 투영해 각 축의 낮은 중앙값을 측정합니다. 좌표의 산술 평균이나 일반 무게중심과 다른 통계이며 각도에 따라 축과 결과가 달라질 수 있습니다.

낮은 중앙값 예

투영 좌표가 0, 1, 4, 9라면 정렬된 가운데 두 값 중 낮은 값은 1입니다. 각 축을 별도로 계산하므로 결합해 되돌린 점이 실제 전경 픽셀 위에 반드시 놓이는 것은 아닙니다. 반환 면적은 비영 전경 픽셀의 수입니다.

Measure 사용

전경 마스크와 방향 각도 및 작업량 상한을 Measure의 계약에 맞게 전달합니다. 각도 단위를 확인하고 로컬 결과 위치를 전체 영상에 표시하려면 ROI 원점을 적용합니다. 다른 대상과 비교할 때도 동일한 축 방향을 기록합니다.

적용의 범위

여러 성분이 함께 입력되면 전체 전경 좌표 분포의 중앙값이 될 수 있습니다. 개별 물체의 위치가 필요하다면 먼저 성분을 분리하고 원본 마스크에서 잡음과 잘림이 있는지 확인합니다.
