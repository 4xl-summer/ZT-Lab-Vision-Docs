사용과 결과 해석

기준 위반이 이어진 탐침 구간의 시작과 끝, 해당 구간의 사유 비트를 담습니다. First와 Last는 포함되는 탐침 인덱스이며 Flags는 구간 안에서 관찰된 위반 사유를 합친 값입니다. 경로의 실제 픽셀 좌표나 길이를 직접 담는 필드와 구별해야 합니다.

예를 들어 3번부터 5번까지의 구간은 세 탐침을 포함합니다. Flags에 여러 사유가 들어 있다면 그 구간 어딘가에서 각각 발생한 것이지 모든 탐침이 동일한 사유를 가졌다는 뜻은 아닙니다. 개별 탐침의 상태를 확인해야 원인을 분리할 수 있습니다.

탐침 간 간격이 일정하지 않으면 인덱스 범위만으로 실제 결함 길이를 계산할 수 없습니다. 결과의 길이 통계와 경로 좌표를 확인하고, 기준 자체가 현재 영상의 정렬과 품질 조건에 맞는지도 검토하십시오.
