포함 경계를 갖는 영역

FitRegion은 원본 점 좌표계의 닫힌 영역을 Minimum과 Maximum으로 나타냅니다. 두 경계는 포함되며, 오른쪽과 아래 끝을 제외하는 일반적인 반열림 이미지 슬라이스와 구별해야 합니다.

경계의 예

Minimum=(1,2), Maximum=(4,6)이면 두 모서리는 영역의 포함 경계에 놓입니다. 경계에 정확히 놓인 점도 선택되는 정의입니다. 숫자의 단위는 입력 점의 좌표계에 따르므로 타입 이름만 보고 픽셀 또는 밀리미터로 단정하지 않습니다.

점 선택

피팅 전에 점과 영역이 같은 좌표 기준을 쓰는지 확인합니다. ROI 로컬 점과 전체 영상 기준 경계를 그대로 비교하면 의도하지 않은 점이 선택될 수 있습니다. 필요하다면 한쪽을 공통 좌표로 변환합니다.

후속 진단

선택 영역이 적절하더라도 피팅에 충분한 점의 수와 배치가 보장되지는 않습니다. 입력 점의 분포와 반환 잔차 및 사용 여부를 함께 확인하고, 범위 변경 후에는 선택된 점을 원본에 표시해 검증합니다.
