사용과 결과 해석

대응 점을 이용해 평면 강체 또는 similarity 변환을 적합합니다. 기준과 대상의 같은 인덱스가 같은 점에 대응해야 하며 호출자가 좌표계와 길이 단위를 맞춰야 합니다. 점을 영상에서 자동 검출하는 기능과 구별하십시오.

평면 강체 변환은 회전과 이동을 표현하고 similarity 변환은 여기에 균일한 배율을 포함할 수 있습니다. 예를 들어 실제 배율 변화가 없는 두 점 집합에 강체 모델을 쓰면 불필요한 축척 자유도를 도입하지 않습니다. 반대로 배율 변화가 있다면 모델 가정을 먼저 검토해야 합니다.

점들이 한곳에 몰리거나 잘못 대응되면 수치적으로 적합하더라도 사용 영역의 오차가 커질 수 있습니다. 결과의 잔차와 좌표 방향을 확인하고 독립 점에서 검증하십시오. 원근 변화나 비균일 변형까지 모든 모델이 설명하는 것은 아닙니다.
