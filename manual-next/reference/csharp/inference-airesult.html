공개 타입

ZVision.AiResult · class

어셈블리: ZVision.

엔진과 입력을 해제한 뒤에도 사용할 수 있는 소유 추론 결과입니다. 사용 후 해제합니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object

컴파일된 ZVision 어셈블리에서 확인한 공개 멤버입니다. XML 설명이 없는 반환값, 오류와 지원 조건은 미확인입니다.

Scores

Property · 선언 타입 ZVision.AiResult

C#
System.Single[] Scores { get; }

분류 softmax 점수를 독립 배열로 복사합니다. 잘못된 과제에서는 네이티브 오류가 발생합니다.

반환: 클래스 ID 순서의 독립 softmax 점수 배열입니다.

Detections

Property · 선언 타입 ZVision.AiResult

C#
ZVision.AiDetection[] Detections { get; }

유지된 검출을 독립 배열로 복사합니다. 점수 내림차순이며 동점은 원래 행 순서입니다. 같은 클래스의 IoU가 임계값보다 클 때 억제합니다.

반환: 유지된 검출의 독립 배열입니다.

Map

Property · 선언 타입 ZVision.AiResult

C#
ZVision.ZImage Map { get; }

분할의 GrayU32 또는 이상의 GrayF32 맵을 독립 소유 핸들로 가져옵니다. 맵은 ROI 크기이며 사용 후 해제합니다.

반환: 호출자가 해제할 맵 이미지입니다.
