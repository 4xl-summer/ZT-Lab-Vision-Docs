ControlledEccDecode

QR 또는 Data Matrix의 ECC 정정 실행 여부를 선택해 디코딩합니다.

EstimateDataMatrixModuleSize

Data Matrix finder 간격으로 두 축의 평균 모듈 크기를 추정해 범위 검사합니다.

EstimateQrModuleSize

QR finder 중심 간격으로 양축 모듈 크기를 추정하고 사후 범위 검사합니다.

DiagnoseDataMatrixEccModules

표본 Data Matrix ECC200 모듈의 실제 RS 정정량을 계산합니다.

DiagnoseDataMatrixEccImage

Gray8 영상에서 Data Matrix 하나를 탐지하고 실제 RS 정정량을 계산합니다.

CheckUnicodeText

디코딩 결과를 바꾸지 않고 Unicode scalar 문자 집합과 길이를 검사합니다.

BarcodeGridQuality

지정된 셀 격자의 비표준 대비, 변조, 규칙성 진단을 계산합니다.

BarcodeDecodeStability

밝기 변화 시도의 실제 판독 일치 비율을 계산합니다.

DiagnoseQrEccModules

표본화된 QR 모듈에서 실제 RS 정정 코드워드 수를 계산합니다.

DiagnoseQrEccImage

Gray8 영상에서 QR 하나를 탐지하고 실제 RS 정정량을 계산합니다.

SegmentFontImage

학습 예제 이미지에서 문자 셀을 자동 분할합니다.
