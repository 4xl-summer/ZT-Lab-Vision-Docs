static ZVision.ControlledEccResult ControlledEccDecode(ZVision.ZImage image, ZVision.ControlledEccFormat format, ZVision.ControlledEccInput input, System.Boolean correctionEnabled, System.UInt64 maxCorrectedPerBlock)

QR 또는 Data Matrix의 ECC 정정 실행 여부를 선택해 디코딩합니다.

인자

image
표본 모듈 그리드 또는 심볼을 포함한 Gray8 영상입니다.
format
QR 또는 Data Matrix입니다.
input
모듈 그리드 또는 원본 영상입니다.
correctionEnabled
참이면 RS 정정하고 거짓이면 syndrome이 0인 경우만 정정 없이 디코딩합니다.
maxCorrectedPerBlock
블록별 정정량 사후 승인 상한입니다.

반환: 텍스트, 실제 정정량 및 사후 판정입니다.
