분할 정보의 유무

BlobSegmentationInfo는 Low, High와 HasThresholds를 담습니다. HasThresholds는 임계값 정보가 있는지를 나타내며 LUT 분할에서는 거짓입니다. 이 플래그를 확인하지 않고 숫자만 읽으면 LUT를 단순한 두 임계값 분할로 잘못 설명할 수 있습니다.

조회표와 임계값

조회표 방식은 각 밝기 입력에 해당하는 항목을 찾아 멤버십으로 매핑합니다. 여러 밝기값의 선택 관계를 단순히 하나의 연속 구간으로 표현할 수 없는 경우가 있습니다. 이때 Low와 High만 저장해 두면 원래 LUT를 재구성할 수 없습니다.

결과 기록

분석을 재현하려면 HasThresholds가 참인 경우 해당 임계값과 입력의 밝기 단위를 기록합니다. LUT 방식이라면 실제 조회표와 스케일을 함께 보관합니다. 정보 객체는 결과 마스크나 원본 밝기 영상 전체를 대신하지 않습니다.

검증

같은 입력이라도 분할 조건이 바뀌면 전경 픽셀과 후속 블롭 수가 달라질 수 있습니다. 설정값을 확인한 뒤 출력 마스크를 원본에 겹쳐 의도한 대상이 선택됐는지 직접 확인합니다.
