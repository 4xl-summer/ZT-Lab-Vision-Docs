격자 중심 내접원

BlobInnerCircle은 영역에 포함되는 격자 중심 이산 원의 X, Y와 Radius를 나타냅니다. 중심은 ROI 로컬 정수 위치이고 반지름은 픽셀 단위입니다. 배경 픽셀 중심을 포함하지 않는 원이라는 정의는 연속 곡선에서의 이론적 내접원과 구분해야 합니다.

중심 표시

예를 들어 X=3, Y=4인 결과는 해당 ROI 로컬 위치를 원의 중심으로 사용합니다. 전체 영상에 그리려면 ROI의 전역 원점을 중심에 더해야 합니다. 반지름은 좌표 원점의 평행 이동으로 바뀌지 않지만 좌표의 크기나 단위가 바뀌면 해석이 달라집니다.

내부와 외부

이 결과는 원 안에 배경 픽셀 중심이 들어가지 않도록 제한하는 내부 원입니다. 반대로 외접원은 블롭의 셀 모서리를 감싸는 문제입니다. 두 반지름의 의미가 다르므로 하나를 다른 하나의 반대로 계산한다고 가정하지 않습니다.

비교 조건

마스크의 구멍, 얇은 돌기, ROI 잘림은 중심과 반지름에 영향을 줍니다. 원본 전경 위에 결과를 표시해 원하는 영역에 대한 측정인지 확인하고 물리 치수에는 보정과 축별 픽셀 간격을 고려합니다.
