레이블별 밝기 분포

BlobGrayStatistics는 블롭 레이블별 Gray8 밝기 분포를 측정합니다. 레이블이 픽셀의 소속을 정하고 Gray8 영상이 그 픽셀의 밝기를 제공합니다. 이진 마스크의 값과 실제로 측정할 밝기 원본을 구별해야 합니다.

크기와 정렬

Measure에 전달하는 레이블 결과와 회색 영상은 같은 영상 위치를 나타내야 합니다. 크기가 같더라도 서로 다른 ROI를 가리키면 잘못된 물체의 밝기를 읽게 됩니다. 입력의 폭과 높이뿐 아니라 원점과 전처리 이력을 함께 확인합니다.

통계 해석

두 영역의 평균이 같아도 밝기 분포는 다를 수 있습니다. 예를 들어 값 0과 100이 하나씩 있는 영역과 값 50 두 개의 영역은 평균이 모두 50이지만 분포는 다릅니다. 필요한 경우 히스토그램과 픽셀 수를 같이 살펴봅니다.

판정 조건

측정값은 입력 Gray8 값의 스케일과 조명에 영향을 받습니다. 픽셀 형식 변환이나 노출이 달라졌다면 같은 숫자 기준이 유효한지 다시 확인하고, 라벨별 결과를 원본 마스크와 연결해 진단합니다.
