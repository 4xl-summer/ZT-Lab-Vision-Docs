사용과 결과 해석

주파수 역변환의 실수 결과 배열과 출력 크기를 담습니다. Width와 Height는 픽셀 격자의 크기이며 Values는 행 우선으로 배치된 독립 숫자 배열입니다. 영상 객체 자체가 아니라 배열이므로 후속 영상 API에 전달하려면 형식과 크기에 맞는 영상 생성이 별도로 필요합니다.

너비가 3인 결과의 위치 (1,2)는 인덱스 2×3+1에 해당합니다. 반환 크기가 패딩된 변환 전체인지 원본 크기로 자른 결과인지는 역변환 호출의 선택을 확인해야 합니다. 행렬처럼 화면에 표시할 때 폭을 잘못 적용하면 데이터는 그대로여도 위치가 뒤틀립니다.

정규화는 원래 변환과 역변환의 설정에 따라 크기에 영향을 줍니다. 입력 값과 복원 값을 검증할 때는 부동소수 허용 오차와 crop 범위를 명시하고 배열 수명과는 별도로 좌표 원점도 확인하십시오. 이 값은 진폭 보정이나 톤 매핑을 자동으로 수행하지 않습니다.
