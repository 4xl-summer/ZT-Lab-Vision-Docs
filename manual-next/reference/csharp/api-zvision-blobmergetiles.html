인접 타일의 연결

BlobMergeTiles는 인접한 두 수평 이진 타일을 결합하고 이음새를 포함한 연결 성분을 다시 계산합니다. 각 타일에서 따로 얻은 성분 목록만 합치면 경계를 가로지르는 물체를 두 개로 세는 문제가 생길 수 있습니다.

이웃 방식

같은 행의 경계 픽셀은 변을 공유할 수 있고 서로 한 행 어긋난 픽셀은 대각선으로 만납니다. 4연결과 8연결은 대각선 접촉의 해석이 다르므로 같은 타일에 두 설정을 적용해 성분 수가 달라지는지 살펴볼 수 있습니다.

MergeHorizontal 입력

왼쪽과 오른쪽 타일의 높이 및 픽셀 형식, 연결성과 작업 한도를 호출 조건에 맞게 확인합니다. 결합 좌표에서는 오른쪽 타일 위치가 왼쪽 타일 폭만큼 이동한 위치입니다. 개별 타일의 로컬 좌표를 그대로 섞지 않습니다.

결과 판독

결과의 레이블 맵과 성분 면적, 중심을 함께 확인하고 이음새 위에 표시합니다. 타일이 잘못 정렬되거나 예상치 못한 겹침이 있으면 연결 계산만으로 영상 정합을 해결할 수 없으므로 원본 준비 조건도 검증합니다.
