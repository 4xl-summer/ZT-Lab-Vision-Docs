이웃 점의 평균화

BlobContourSmooth는 순서가 있는 윤곽 점을 이웃 점 평균으로 평활화합니다. 입력 영상의 밝기 필터가 아니라 경계 좌표에 적용하는 연산입니다. 작은 들쭉날쭉함을 줄일 수 있지만 실제의 날카로운 모서리도 약해질 수 있습니다.

창과 경로

Run에서 지정하는 이동 창과 경로의 열림·닫힘 조건을 확인합니다. 닫힌 윤곽에서는 시작과 끝의 관계가 중요하며 열린 경로의 양 끝을 연결된 것으로 해석하면 다른 결과가 됩니다. 점의 순서를 바꾸면 이웃 자체가 바뀝니다.

결과 비교

원본 점열과 결과를 같은 좌표에 겹쳐 어디가 이동했는지 확인합니다. 평활화된 윤곽의 길이와 곡률은 원본과 달라질 수 있으므로 두 값을 비교할 때 어떤 점열을 측정했는지 기록합니다. 창 크기를 크게 바꿀수록 세부 형상에 대한 영향도 함께 살펴야 합니다.

좌표와 범위

ROI 로컬 점을 전체 영상에 표시할 때 원점을 맞춥니다. 결과가 매끈해 보이는 것과 실제 경계 위치가 더 정확해진 것은 다른 문제이므로 후속 치수 검사에 필요한 허용 오차는 실제 대상에서 별도로 검증합니다.
