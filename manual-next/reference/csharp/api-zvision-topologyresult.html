사용과 결과 해석

전경 연결 성분과 내부 구멍의 위상을 담은 독립 값 스냅샷입니다. Topology에는 성분 수, 외곽에 닿지 않는 구멍 수와 두 값의 차이인 오일러 수가 포함됩니다. 원본 영상의 소유 핸들을 유지하지 않으며 결과를 별도로 Dispose할 필요가 없습니다.

예를 들어 전경 성분 하나에 내부 구멍 하나가 있으면 성분 수 1에서 구멍 수 1을 빼 오일러 수는 0입니다. ROI 경계에 닿아 외부와 연결된 배경은 내부 구멍과 다르게 취급되므로 영역을 자르는 방식이 결과에 영향을 줄 수 있습니다.

전경 정의와 연결성 선택이 달라지면 대각선으로 접한 픽셀이 하나 또는 여러 성분으로 계산될 수 있습니다. 따라서 결과를 비교할 때 입력 마스크, ROI 및 연결 조건을 함께 기록하십시오. 위상 수치만으로 각 성분의 면적이나 실제 물리적 결함 크기를 알 수는 없습니다.
