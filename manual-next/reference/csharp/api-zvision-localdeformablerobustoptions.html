사용과 결과 해석

국소 변형 모델의 강건 판정에서 밝기 잔차 상한과 최소 내점 비율을 지정합니다. residualCutoff는 양수인 밝기 단위 임계값이고 minInlierFraction은 활성 템플릿 픽셀에 대한 비율로 0보다 크고 1 이하입니다. 두 설정은 서로 다른 양이므로 같은 숫자로 맞출 필요가 없습니다.

예를 들어 활성 픽셀이 100개이고 최소 내점 비율을 0.8로 정했다면 충분한 후보 평가에서 80% 이상이 지정된 잔차 조건을 만족해야 한다는 의미입니다. cutoff를 낮추면 작은 밝기 차이도 외점으로 간주될 수 있으므로 조명 변화와 입력 형식의 강도 범위를 고려해야 합니다.

이 설정은 허용 변형의 기하 범위나 검색 시간 예산을 대체하지 않습니다. 매칭 결과의 점수, 내점 및 종료 상태와 함께 읽어야 하며 실제 결함 검출에 사용할 기준은 합성 입력과 현장 데이터에서 별도로 검증해야 합니다.
