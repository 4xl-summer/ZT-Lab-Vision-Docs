사용과 결과 해석

스테이지의 전체 적합을 시도하기 전에 최소 회전 범위 등 전제 조건과 요청한 지표를 보고합니다. 명령과 관측 포즈는 같은 순서의 4~4096쌍이며 길이 단위와 최소 펼친 회전 범위는 명시해야 합니다. requested 비트는 계산을 요청할 지표를 선택합니다.

결과의 요청·계산·실패 비트와 사유를 함께 보면 단일 성공 여부보다 어떤 지표가 준비되지 않았는지 구분할 수 있습니다. 예를 들어 회전 운동이 충분하지 않으면 전체 적합 전제를 충족하지 못할 수 있으므로 없는 평가값을 0 오차라고 읽으면 안 됩니다.

이 진단은 제공된 합성 또는 실제 관측의 기하가 계산에 적합한지 설명합니다. 결과를 장비 수락 기준으로 쓰려면 각 지표의 단위와 사용자 공차를 별도로 적용하고, 명령과 관측의 시간적 대응과 프레임을 먼저 확인해야 합니다.
