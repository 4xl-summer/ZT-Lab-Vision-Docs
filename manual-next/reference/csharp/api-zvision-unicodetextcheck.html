사용과 결과 해석

인식된 문자열에 허용 문자와 길이 규칙을 적용한 결과입니다. ScalarCount는 Unicode scalar 수이고 Reasons는 빈 문자열, 길이 또는 문자 집합에 관련된 사유 비트입니다. Accepted는 해당 사후 조건을 모두 통과했는지 나타냅니다.

길이는 UTF-8 바이트 수가 아닙니다. 한글 한 글자가 여러 바이트를 사용하더라도 한 scalar로 계산됩니다. 예를 들어 허용 집합에 없는 글자가 포함되면 길이가 범위 안에 있어도 문자 조건 때문에 거절될 수 있습니다.

이 값은 이미 나온 텍스트를 판정하며 인식 엔진이 선택할 후보 문자를 바꾸거나 OCR을 다시 실행하지 않습니다. 설정 오류와 유효한 규칙에서의 거절을 구별하고, 시각적으로 한 글자인 조합이 여러 Unicode scalar로 표현될 수도 있음을 길이 기준에 반영하십시오.
