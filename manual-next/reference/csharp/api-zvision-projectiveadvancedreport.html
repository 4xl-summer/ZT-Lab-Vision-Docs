사용과 결과 해석

원근 매칭의 후보 배열과 검색 종료 진단을 함께 담습니다. Matches는 조건을 만족한 후보를 복사해 제공하며 종료 정보는 검색이 완료되었는지 또는 설정된 제한에 도달했는지 판단하는 데 필요합니다. 후보가 없다는 것과 검색 자체가 오류로 실패한 것은 구별해야 합니다.

원근 모델의 결과를 적용할 때는 기준과 입력 좌표의 방향을 확인하고 후보별 점수와 변환의 유효 범위를 함께 살펴보십시오. ROI 로컬 좌표를 전체 이미지 좌표와 그대로 섞으면 변환 행렬이 수치적으로 유효해도 잘못된 위치를 가리킬 수 있습니다.

시간 또는 후보 예산이 제한된 검색에서는 반환된 후보가 전체 가능한 범위의 전역 최선이라고 자동으로 보장되지 않습니다. 검색 설정과 종료 상태, 학습 기준을 함께 보관하고 변환의 실제 적용 위치에서 별도 검증을 수행하십시오.
