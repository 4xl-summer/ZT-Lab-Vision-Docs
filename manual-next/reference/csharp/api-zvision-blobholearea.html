내부 구멍의 면적

BlobHoleArea는 전경에 둘러싸인 배경 구멍의 전체 픽셀 면적을 계산합니다. 외부와 연결된 배경은 닫힌 구멍과 구분해야 하며, 전경과 배경의 이웃 관계도 결과에 영향을 줄 수 있습니다.

3×3 예

바깥 여덟 셀이 전경이고 중앙 하나가 배경인 3×3 고리의 구멍 면적은 한 픽셀입니다. 고리의 한 변을 열어 가운데가 외부 배경과 연결되면 더 이상 같은 닫힌 구조로 단정할 수 없습니다. 입력 마스크를 함께 확인하세요.

Measure 설정

연결 방식과 작업 한도를 해당 호출에 지정하고 결과를 원본 전경 마스크와 대조합니다. 대각선으로만 닿는 위치가 있으면 선택한 연결성에 따라 내부와 외부의 관계가 달라질 수 있습니다. 같은 마스크에 설정만 바꾸어 비교하면 차이를 확인할 수 있습니다.

결과의 의미

반환되는 총 면적이 같아도 구멍 개수나 위치는 서로 다를 수 있습니다. 개별 구멍의 형태가 필요한 검사는 별도의 윤곽이나 연결 분석을 사용합니다. 픽셀 수를 물리 면적으로 바꾸려면 보정도 필요합니다.
