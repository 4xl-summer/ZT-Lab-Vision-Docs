Solve

Method · 선언 타입 ZVision.HandEyeCalibration

C#
static ZVision.HandEyeResult Solve(ZVision.HandEyePair[] pairs, ZVision.HandEyeOptions options)

회전 quaternion 선형계와 이동 가중 최소제곱을 합의 쌍에 적용합니다.

인자

pairs
같은 프레임과 단위를 사용하는 2~1024개 상대 운동 쌍입니다.
options
합의 임계값과 가설 예산입니다.

반환: 강체 변환, 조건수와 입력별 잔차입니다.

C#
static ZVision.HandEyePair[] EyeInHandMotions(ZVision.RigidTransform3[] gripperToBase, ZVision.RigidTransform3[] targetToCamera)

고정 기준판을 보는 이동 카메라의 연속 상대 운동을 만듭니다.

인자

gripperToBase
base←gripper 절대 포즈입니다.
targetToCamera
camera←target 절대 포즈입니다.

반환: X=gripper←camera에 대한 연속 상대 운동입니다.
