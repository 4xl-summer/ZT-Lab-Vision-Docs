사용 맥락과 결과 해석

색 NCC 또는 Gray SAD의 정수 위치 검색에서 선택된 매치와 평가 위치 수입니다. Matches는 독립 복사 결과이며 비어 있을 수 있습니다. Evaluated는 전체 평가 위치 개수로 최종 매치 개수와 같을 필요가 없습니다. 입력의 검색 범위는 템플릿 좌상단 기준입니다.

색 NCC는 높은 상관을, Gray SAD는 작은 평균 절대 차이를 선호하므로 값만 보고 방향을 단정하지 않습니다. 검색할 템플릿이 지정된 위치에서 영상 안에 들어와야 하며 작업량이 상한을 넘으면 빈 결과가 아니라 오류입니다. 전역 위치에는 검색 영상 원점을 더하므로 ROI에서 얻은 좌표를 원본에 표시할 때 확인합니다.

x가 0..2이고 y가 0..1인 포함 범위는 위치 여섯 개입니다. 모델이 각 위치에서 영상에 완전히 들어가야 하고 작업 상한도 충족해야 이 검색을 정상 수행할 수 있습니다. 동일한 위치라도 모델에서 선택한 픽셀 수와 채널 수가 작업량에 영향을 줍니다.

값을 확인하는 순서

Matches 항목: 독립 복사된 검색 결과입니다. Evaluated 항목: 평가한 위치 개수입니다.
