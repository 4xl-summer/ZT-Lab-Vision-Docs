사용과 결과 해석

하나의 레이블에 포함된 색 표본의 통계와 주성분 분석을 묶습니다. Moments에는 평균과 공분산 및 PCA 정보가 있고 Details에는 최솟값, 최댓값과 표준편차가 들어 있습니다. 각 값은 선택한 색 좌표계에서 계산되므로 레이블마다 입력 조건을 일치시켜야 비교할 수 있습니다.

평균은 표본의 중심을 요약하지만 분포의 크기와 방향을 설명하지 못합니다. 예를 들어 평균이 비슷한 두 영역도 공분산이나 최댓값이 다를 수 있습니다. 표준편차와 PCA를 함께 확인하면 어느 색 방향으로 변동이 큰지 살펴볼 수 있습니다.

레이블의 선택과 유효 픽셀 수, 백색점 및 전달 함수가 바뀌면 결과 해석도 달라집니다. 통계가 나왔다는 사실만으로 색 보정이 완료되거나 사용자의 색상 공차를 만족했다는 뜻은 아니므로 독립 패치로 검증하십시오.
