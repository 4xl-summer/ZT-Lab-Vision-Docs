영역 번호 재부여

BlobRelabel은 Blob 결과의 레이블을 새 결과에서 연속 정수로 바꿉니다. 이는 성분의 번호 체계를 정리하는 작업이며 물체를 새로 검출하거나 밝기 값을 측정하는 연산과 다릅니다.

번호와 성분

기존 레이블에 빈 번호가 있을 때 연속 번호로 바뀌면 레이블 맵의 숫자가 달라집니다. 숫자만 비교해서 성분의 모양이 바뀌었다고 판단하지 말고 위치와 면적을 함께 비교합니다. 이전 레이블과 외부 데이터를 연결했다면 대응 관계를 별도로 관리해야 합니다.

Run의 사용

Run에 입력 Blob 결과와 작업량 상한을 해당 시그니처에 맞게 지정합니다. 새 레이블을 표시할 때 배경과 전경 성분을 구분하고 ROI 기준을 유지합니다. 원래 입력의 순서나 숫자가 다른 실행에서도 유지될 것이라고 가정하지 않습니다.

후속 단계

연속 번호는 결과 배열이나 레이블 맵을 다룰 때 편리하지만 프레임 간 객체 추적 ID는 아닙니다. 물체 추적에는 좌표와 형상 등을 이용한 별도 대응 정책이 필요하며, 번호 변경이 결과 해석에 미치는 영향을 기록합니다.
