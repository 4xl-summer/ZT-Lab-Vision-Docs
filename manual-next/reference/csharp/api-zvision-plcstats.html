사용과 결과 해석

모의 PLC 상태 기계가 처리한 명령의 누적 횟수입니다. Requests는 적용된 요청, Published는 게시된 결과, Acks는 확인된 결과를 셉니다. Duplicates, Timeouts, Resets는 각각 중복 분류, 시간 초과 판정 및 오류 초기화 횟수입니다.

예를 들어 요청 하나를 적용하고 그 결과를 게시한 뒤 확인했다면 각 정상 처리 횟수의 변화를 순서대로 살펴볼 수 있습니다. 중복 명령이 감지된 횟수는 새로운 작업이 처리된 횟수와 구별해야 합니다. 현재 활성 요청의 식별자와 상태는 통계가 아니라 PlcInfo에서 확인합니다.

값은 모의 PLC의 상태 스냅샷에 포함된 누적 카운터입니다. 한 시점의 카운터만으로 실제 외부 장치가 응답했는지 또는 네트워크 지연이 허용 범위인지 알 수 없습니다. 시험 전후의 카운터 차이와 명령 결과를 함께 확인하고 실장비 시험과 구분하십시오.
