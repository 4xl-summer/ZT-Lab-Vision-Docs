사용과 결과 해석

정합된 영상들의 겹침에 대해 계산한 품질 요약입니다. Score는 선택한 점수 방식의 값이고 ResidualRms는 광도 단위의 잔차, Coverage는 유효 겹침 범위, Evaluated는 평가에 사용된 수를 설명합니다. 서로 다른 점수 방식의 숫자를 같은 척도로 비교하지 마십시오.

예를 들어 점수가 좋아도 실제 겹침이 아주 작다면 전체 영상 정합을 대표한다고 보기 어렵습니다. Coverage와 Evaluated를 함께 살펴 결과가 충분한 표본에서 나왔는지 확인하고, ResidualRms는 영상의 밝기 스케일과 광도 보정 설정을 고려해 해석합니다.

이 품질 값은 성공한 정합 결과의 측정 요약이지 기하적 진실이나 실제 물체의 변형 허용 여부를 자동 판정하지 않습니다. 입력 마스크, 영상 원점 및 선택한 점수 방법을 함께 기록해야 서로 다른 실행을 비교할 수 있습니다.
