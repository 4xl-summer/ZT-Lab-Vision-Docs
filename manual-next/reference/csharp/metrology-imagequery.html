WarpAffine

원본 로컬에서 출력 로컬로의 아핀 변환을 역매핑해 리샘플링합니다. 14개 픽셀 형식을 지원합니다. 계획에 등록하며 픽셀 처리는 실행 시 수행합니다.

WarpProjective

원본 로컬에서 출력 로컬로의 투영 변환을 역매핑해 리샘플링합니다. 14개 픽셀 형식을 지원합니다. 계획에 등록하며 픽셀 처리는 실행 시 수행합니다.

Undistort

글로벌 렌즈 모델로 영상을 역매핑합니다. 크기와 ROI 원점을 유지하며 보이는 영역 밖은 경계값을 사용합니다. 실행 시 처리합니다.

ToHsv

Rgb8, Bgr8, Rgb16, Bgr16, Rgba8, Bgra8 또는 RgbF32 인코딩 sRGB를 HSV 세 GrayF64 평면으로 변환합니다. H는 [0, 360) 도, S와 V는 [0, 1]입니다.

ToLab

Rgb8, Bgr8, Rgb16, Bgr16, Rgba8, Bgra8 또는 RgbF32 인코딩 sRGB를 D50/2° CIELAB의 세 GrayF64 평면으로 변환합니다.

WhiteBalance

인코딩 sRGB를 선형화해 RGB별 양의 게인을 적용하고 클리핑 후 재인코딩합니다. 알파는 보존합니다.

ColorCorrect

선형 sRGB에서 행렬과 편향을 적용하고 클리핑 후 재인코딩합니다. 알파는 보존합니다.

DeltaE76

각 픽셀을 D50 Lab으로 변환해 목표와의 CIE76 거리를 계산합니다.

ColorSegment

D50 Lab 목표와의 CIE76 거리가 임계값 이하인 픽셀을 255로 표시하는 Gray8 마스크를 만듭니다.

ColorStatistics

선택 픽셀의 정규화 인코딩 RGB 통계를 계산합니다. 알파는 제외합니다.

AlignReference

Gray8, Gray16 또는 GrayF32 기준 ROI를 매칭해 기준 영상 기하로 정렬합니다. 검색 실패 또는 유효 비율 부족은 발견되지 않은 결과입니다.

InspectionDifference

같은 기하의 회색 영상에 밝기 보정과 선택 마스크를 적용해 차분 점수와 마스크를 계산합니다. 점수 1 이상을 결함으로 표시합니다.

SurfaceDefects

Gray8 마스크와 같은 기하의 GrayF64 점수에서 연결 요소를 추출하고 기하 조건으로 분류합니다.

FindMatches

검색 영상의 보이는 ROI에서 모델 포즈를 지연 탐색합니다. 모델 전체가 ROI 안에 들어와야 합니다. 즉시 실행의 독립 스냅샷에는 MatchModel.Find를 권장합니다.

Profile

Gray8, Gray16 또는 GrayF32 ROI의 스트립 프로파일을 계산합니다.

Caliper

Gray8, Gray16 또는 GrayF32 ROI에서 조건에 맞는 모든 에지를 거리순으로 찾습니다.

Clone

현재 계획을 독립적으로 변경할 수 있는 새 빌더로 복제합니다. 이후 한쪽의 추가는 다른 쪽에 반영되지 않습니다.

ThresholdValue

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

Threshold(System.Byte)

7종 회색 형식에서 임계값 이상은 255, 그 외는 0인 Gray8 마스크를 계획합니다.

Threshold(System.Double)

7종 회색 형식에서 임계값 이상은 255, 그 외는 0인 Gray8 마스크를 계획합니다. 픽셀 처리는 실행 시 수행합니다.

ToGray

컬러 영상을 대응하는 회색조 형식으로 변환하도록 계획합니다. 실제 처리는 Run에서 수행합니다.

LinearTransform

픽셀에 이득과 편향을 적용하도록 계획합니다. 실제 처리는 Run에서 수행합니다.

BoxBlur

박스 평균 필터를 계획합니다. 실제 처리는 Run에서 수행합니다.

GaussianBlur

가우시안 평활화를 계획합니다. 실제 처리는 Run에서 수행합니다.

SobelX

수평 방향 Sobel 미분을 계획합니다. 실제 처리는 Run에서 수행합니다.

SobelY

수직 방향 Sobel 미분을 계획합니다. 실제 처리는 Run에서 수행합니다.

GradientMagnitude

기울기 크기 계산을 계획합니다. 실제 처리는 Run에서 수행합니다.

MedianFilter

중앙값 필터를 계획합니다. 실제 처리는 Run에서 수행합니다.

AdaptiveThresholdMean

국소 평균을 이용한 적응형 이진화를 계획합니다. 실제 처리는 Run에서 수행합니다.

Canny

가우시안 평활화와 이중 임계값을 이용한 Canny 에지 검출을 계획합니다. 실제 처리는 Run에서 수행합니다.

ResizeNearest

최근접 보간 크기 변경을 계획합니다. 실제 처리는 Run에서 수행합니다.

ResizeBilinear

쌍선형 보간 크기 변경을 계획합니다. 실제 처리는 Run에서 수행합니다.

AbsDiff

참조 이미지와 픽셀별 절대 차이를 계획합니다. 참조 저장소를 공유해 실행까지 보유합니다. 실제 처리는 Run에서 수행합니다.

MaskUnion

동일 크기와 원점의 Gray8 마스크 합집합을 계획합니다. 실제 처리는 Run에서 수행합니다.

MaskIntersection

동일 크기와 원점의 Gray8 마스크 교집합을 계획합니다. 실제 처리는 Run에서 수행합니다.

MaskDifference

동일 크기와 원점의 Gray8 마스크 차집합을 계획합니다. 실제 처리는 Run에서 수행합니다.

RegionTopology

Gray8 전경의 컴포넌트, 구멍 및 오일러 수 분석을 계획합니다. 실제 처리는 반환된 계획의 Execute에서 수행합니다.

RegionMoments

Gray8 전경 컴포넌트별 모멘트와 형상 분석을 계획합니다. 실제 처리는 반환된 계획의 Execute에서 수행합니다.

FindContours

Gray8 전경 픽셀 셀의 경계 링 분석을 계획합니다. 실제 처리는 반환된 계획의 Execute에서 수행합니다.

SubpixelContours

Gray8, Gray16 또는 유한 GrayF32 밝기의 보간 등치선 분석을 계획합니다. 실제 처리는 반환된 계획의 Execute에서 수행합니다.

ConvexShapes

Gray8 전경 컴포넌트의 볼록 껍질과 최소 사각형 분석을 계획합니다. 실제 처리는 반환된 계획의 Execute에서 수행합니다.

Invert

Gray8 픽셀 값을 반전합니다. 실제 처리는 Run에서 수행합니다.

StretchContrast

Gray8의 명암 범위를 확장합니다. 실제 처리는 Run에서 수행합니다.

EqualizeHistogram

Gray8 히스토그램을 평활화합니다. 실제 처리는 Run에서 수행합니다.

ThresholdOtsu()

Otsu 방법으로 임계값을 정해 마스크를 만드는 연산을 계획합니다. 실제 처리는 Run에서 수행합니다.

ThresholdOtsu(System.Int32, System.Double, System.Double)

Otsu 방법으로 임계값을 정해 마스크를 만드는 연산을 계획합니다. 실제 처리는 Run에서 수행합니다.

Erode

침식 연산을 적용합니다. 실제 처리는 Run에서 수행합니다.

Dilate

팽창 연산을 적용합니다. 실제 처리는 Run에서 수행합니다.

Open

침식 후 팽창으로 열기 연산을 적용합니다. 실제 처리는 Run에서 수행합니다.

Close

팽창 후 침식으로 닫기 연산을 적용합니다. 실제 처리는 Run에서 수행합니다.

ErodeValues

픽셀 값의 침식을 계획합니다. 실제 처리는 Run에서 수행합니다.

DilateValues

픽셀 값의 팽창을 계획합니다. 실제 처리는 Run에서 수행합니다.

OpenValues

픽셀 값의 열기 연산을 계획합니다. 실제 처리는 Run에서 수행합니다.

CloseValues

픽셀 값의 닫기 연산을 계획합니다. 실제 처리는 Run에서 수행합니다.

Lut

Gray8 값에 조회 테이블을 적용합니다. 실제 처리는 Run에서 수행합니다.

Capture

현재 중간 이미지를 이름으로 결과에 보존하도록 계획합니다. GetImage로 얻는 이미지는 독립 소유 핸들로 저장소를 공유합니다. 실제 처리는 Run에서 수행합니다.

FindBlobs

Gray8의 비제로 픽셀을 전경으로 연결 영역을 찾습니다. 실제 처리는 Run에서 수행합니다.

Histogram()

히스토그램 계산을 종료 연산으로 계획합니다. 실제 처리는 Run에서 수행합니다.

Statistics

Gray8 픽셀의 통계를 계산합니다. 실제 처리는 Run에서 수행합니다.

Histogram(System.Int32, System.Double, System.Double)

히스토그램 계산을 종료 연산으로 계획합니다. 실제 처리는 Run에서 수행합니다.

OtsuThreshold

지정 히스토그램 규격으로 Otsu 임계값 계산을 계획합니다. 실제 처리는 Run에서 수행합니다.

ReadBarcode

Gray8 이미지의 단일 바코드 판독을 지연 쿼리에 등록합니다.

PrepareOcr

Gray8 이미지의 지정 영역 준비를 지연 쿼리에 등록합니다.

ReadText
