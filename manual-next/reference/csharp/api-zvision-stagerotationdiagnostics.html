사용과 결과 해석

명령 포즈의 펼친 회전 범위가 최소 요구치를 만족하는지 검사한 뒤 전체 3자유도 스테이지 응답을 적합합니다. 4~4096개의 명령 포즈와 같은 수의 관측 포즈를 순서대로 전달하고 거리 단위와 최소 회전 범위를 지정합니다. 각도 범위는 라디안입니다.

명령이 회전 경계를 통과할 때 값을 연속적으로 unwrap하지 않으면 실제보다 큰 또는 작은 범위로 계산될 수 있습니다. 최소 회전 범위는 단지 허용치이며, 해당 범위를 넘었다고 X와 Y 방향 운동까지 독립적으로 충분하다는 뜻은 아닙니다.

결과의 응답과 축별 잔차는 제공한 관측에 대한 적합 요약입니다. 프레임, 단위, 명령·관측 대응과 입력 기하를 검토하고 실제 장비 검증에는 별도의 반복 측정과 수락 공차를 적용해야 합니다.
