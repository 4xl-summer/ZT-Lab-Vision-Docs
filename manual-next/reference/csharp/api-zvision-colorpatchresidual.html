사용과 결과 해석

색 보정 학습에 사용된 패치 하나의 보정 전후 CIE76 색차를 담습니다. Index는 입력 패치 배열의 0부터 시작하는 인덱스이고 BeforeDeltaE와 AfterDeltaE는 같은 패치의 전후 차이입니다. 배열 순서를 바꾸면 어떤 패치의 잔차인지 연결하기 어려우므로 원래 순서를 보존해야 합니다.

예를 들어 보정 전 값이 5이고 보정 후 값이 2라면 그 학습 패치의 CIE76 색차가 감소한 것입니다. 그러나 여러 패치 중 일부가 악화되었을 수 있으므로 평균이나 한 패치만 보지 말고 전체 잔차 분포를 살펴야 합니다.

이 수치는 학습에 포함된 패치의 적합 결과이며 사용하지 않은 색에서의 일반화 정확도를 보장하지 않습니다. Lab 백색점과 입력 전달 함수를 일치시키고 별도의 검증 패치로 색차를 확인하십시오.
