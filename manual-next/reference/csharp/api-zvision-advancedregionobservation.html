원본 점의 피팅 진단

AdvancedRegionObservation은 InputIndex, Residual, Used로 선택된 원본 입력 점과 피팅 결과의 관계를 나타냅니다. 최종 도형의 파라미터만 보는 대신 어떤 점이 인라이어로 사용되었는지와 모델로부터 얼마나 벗어났는지 살펴볼 수 있습니다.

점과 잔차

InputIndex는 원래 입력 점의 인덱스입니다. 예를 들어 일부 점만 선택한 뒤 결과의 세 번째 항목이 원래 점 배열의 세 번째 점이라고 단정하면 잘못된 위치를 표시할 수 있습니다. 각 항목의 InputIndex로 원본 점을 찾아야 합니다.

사용 여부

Used는 그 점이 인라이어로 사용되었는지를 나타내고 Residual은 피팅된 모델에 대한 잔차입니다. 두 값을 함께 보면 작은 잔차와 실제 선택 상태를 구분할 수 있습니다. 잔차 수치의 단위는 피팅 입력 좌표계에 맞추어 해석합니다.

품질 판단

Used가 참이라는 사실만으로 센서 측정과 모델 전체가 정확하다고 보증할 수 없습니다. 입력 점의 분포, 설정한 인라이어 한도와 모델의 용도를 함께 확인하고 원본 위치에 잔차를 표시해 이상점을 진단합니다.
