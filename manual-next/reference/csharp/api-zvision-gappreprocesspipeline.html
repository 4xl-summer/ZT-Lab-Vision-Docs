사용과 결과 해석

Gray8 영상에 양자화, 중앙값 및 Gaussian 등의 선택 단계를 지정 순서대로 실행합니다. 단계 배열에는 적용 여부와 각 연산의 설정이 들어 있으며 최대 64단계입니다. 실행 순서는 결과에 영향을 주므로 단계를 단순히 집합으로 취급하거나 순서를 마음대로 바꾸면 안 됩니다.

예를 들어 먼저 양자화한 뒤 중앙값 필터를 적용하는 흐름과, 먼저 평활화한 뒤 양자화하는 흐름은 중간 영상의 값이 다를 수 있습니다. 비활성 단계는 연산하지 않고 보고서의 생략 수에 포함됩니다. 최종 결과와 실행·생략 개수를 함께 확인하면 전달한 설정이 의도대로 적용됐는지 점검할 수 있습니다.

출력 영상은 독립 소유이므로 사용 후 Dispose합니다. 각 필터의 커널 크기와 수치 제약은 단계별 계약을 따르며, 단계 설정이 유효하지 않으면 오류가 전달됩니다. 파이프라인을 실행하는 것만으로 최종 영상이 검사 목적에 적합하다는 판정을 얻지는 않습니다.
