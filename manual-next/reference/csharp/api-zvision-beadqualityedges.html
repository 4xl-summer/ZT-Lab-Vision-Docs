사용과 결과 해석

한 비드 탐침에서 선택한 좌우 에지와 대체 여부를 담습니다. HasPair가 유효한 쌍을 나타내며 Left와 Right는 ROI 로컬 좌표입니다. FillFlags는 누락된 에지를 대체했는지 표시하는 비트이므로 측정된 에지와 합성된 에지를 구분하는 데 필요합니다.

HasPair가 false인 경우 좌표를 실제 두께 측정으로 사용하지 마십시오. 쌍이 있어도 대체 비트가 설정되어 있으면 두 좌표 모두가 독립적으로 검출된 실제 에지라고 단정할 수 없습니다. 폭이나 중심을 계산할 때 이 상태와 개별 탐침의 실패 플래그를 함께 읽어야 합니다.

좌표는 입력 ROI 기준이므로 전체 영상이나 월드 위치에 연결하려면 원점과 보정을 적용해야 합니다. 하나의 탐침 결과는 전체 비드 경로의 합격을 의미하지 않으며 연속 결손 구간과 전체 점수도 별도로 확인하십시오.
