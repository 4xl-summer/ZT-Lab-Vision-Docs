사용과 결과 해석

인식에서 시도할 회전각의 최소값, 최대값과 간격을 도 단위로 지정합니다. Step은 양수이며 범위에는 하한과 min+k×step이 최대값 이하인 각도가 포함됩니다. 다른 기하 API에서 라디안을 쓰더라도 이 범위 값은 도입니다.

예를 들어 -10도부터 10도까지 5도 간격이면 -10, -5, 0, 5, 10의 다섯 각도를 시도합니다. 간격이 범위를 정확히 나누지 않으면 마지막 시도가 최대값과 같을 필요는 없습니다. 최대 시도 수에는 구현의 제한이 있으므로 지나치게 작은 간격을 무한정 지정할 수 없습니다.

넓은 범위와 작은 간격은 더 많은 후보 계산을 요구합니다. 이 구조체는 각도 범위를 나타내는 값일 뿐 영상 회전이나 인식 성공을 보장하지 않습니다. 실제 사용에서는 필요한 회전 범위와 처리 시간을 함께 평가하십시오.
