사용과 결과 해석

다중 영상 최적화 후 추정된 렌즈와 각 입력 영상에 대응하는 자세를 묶은 결과입니다. Lens는 렌즈 모델 및 그 적합 진단이고 Poses는 입력 순서의 자세 복사본입니다. 렌즈 하나의 결과와 영상별 여러 자세를 같은 배열로 취급하지 않도록 구조를 구분하십시오.

새 이미지의 점을 투영할 때는 추정 렌즈를 사용할 수 있지만, Poses의 각 항목은 학습에 제공된 해당 영상의 자세를 나타냅니다. 예를 들어 세 영상으로 적합했다면 두 번째 자세는 두 번째 입력 관측에 대응하며, 새 영상의 자세라고 볼 수 없습니다.

렌즈의 RMS와 수렴 상태를 점검한 뒤 입력에 사용되지 않은 점이나 영상으로 확인하는 것이 좋습니다. 반환 배열은 복사된 값으로 취득할 수 있으나 숫자만으로 단위와 프레임을 추론하지 말고 원래 설정과 함께 보관하십시오. 이 결과 자체가 영상의 랜드마크를 새로 찾거나 품질을 판정하지는 않습니다.
