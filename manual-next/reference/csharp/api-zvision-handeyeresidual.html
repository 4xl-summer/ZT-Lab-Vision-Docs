사용과 결과 해석

핸드아이 적합의 상대 운동 하나에 대해 AX와 XB가 얼마나 다른지 요약합니다. RotationRadians는 회전 오차를 라디안으로, Translation은 변환의 공통 길이 단위로 나타냅니다. Inlier는 설정한 회전과 이동 임계값을 모두 만족하는지 표시합니다.

두 오차는 서로 단위가 다르므로 하나를 다른 하나의 숫자와 직접 비교할 수 없습니다. 예를 들어 회전 오차가 작아도 이동 오차가 임계값을 넘으면 해당 운동은 내점이 아닙니다. 반대로 내점 여부만 보면 임계값에 얼마나 가까운지 알 수 없으므로 원래 두 잔차도 함께 살펴보십시오.

잔차는 각 상대 운동 쌍에 대한 결과이며 특정 절대 자세 하나의 물리 오차로 단순 환산할 수 없습니다. 반복되는 큰 잔차가 있다면 자세 쌍의 프레임 방향, 시간 동기화와 단위가 맞는지 확인하고, 사용하지 않은 자세로 해를 추가 검증해야 합니다.
