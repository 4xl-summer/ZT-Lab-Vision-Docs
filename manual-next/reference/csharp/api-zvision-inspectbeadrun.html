사용과 결과 해석

연속 실패 탐침 구간의 시작, 끝과 사유를 담습니다. First와 Last는 0 기반 탐침 인덱스이며 양끝을 포함합니다. Flags는 해당 범위에 나타난 실패 비트들의 합집합입니다.

예를 들어 First=2와 Last=4는 세 탐침 2, 3, 4를 뜻합니다. 여러 사유 비트가 있어도 세 탐침 모두가 동일한 이유로 실패했다고 가정할 수 없습니다. 실제 원인을 찾으려면 개별 탐침 결과와 연결해 확인하십시오.

탐침 인덱스는 픽셀 좌표가 아니며 간격이 고르지 않은 경로의 물리 길이도 아닙니다. 최장 갭과 누락 길이는 별도 통계를 확인하고 ROI 원점 및 보정을 고려해야 합니다.
