상속된 멤버 목록

    Execute

    검사를 수행합니다. 입력은 호출 동안만 빌리며 반환 결과는 호출자가 소유합니다.

    사용과 결과 해석

    빌린 입력 영상을 동기적으로 검사하는 실행기 인터페이스입니다. Execute는 입력, 양의 프레임 세대와 설정 세대, 불변 recipe 및 취소 토큰을 받으며 호출 동안에만 입력을 빌립니다. 반환 ZInspectionResult는 호출자가 소유하고 해제해야 합니다.

    프레임 식별자와 설정 버전을 함께 보관하면 비동기 호스트에서 결과가 어떤 입력과 레시피에 대응하는지 구별할 수 있습니다. 취소는 단계 사이에서 확인하도록 계약되어 있으므로 계산 커널 한 단계가 즉시 선점 중단된다고 가정하면 안 됩니다.

    실행 구현을 교체하더라도 입력을 호출 후 계속 소유하는지, 결과 단계 영상을 어떻게 확보하는지 계약을 지켜야 합니다. 정상 결과와 취소·오류를 구분하고 결과를 사용한 뒤 Dispose하여 보유 영상 임대를 정리하십시오.
