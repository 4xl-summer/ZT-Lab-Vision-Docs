ZVision.SimulatedCamera 컴파일된 공개 멤버

공개 타입

ZVision.SimulatedCamera · class

어셈블리: ZVision.

호출자가 이벤트를 제공하는 모의 카메라입니다. 실제 장치 연결이나 영상 전송은 수행하지 않습니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object

컴파일된 ZVision 어셈블리에서 확인한 공개 멤버입니다. XML 설명이 없는 반환값, 오류와 지원 조건은 미확인입니다.

Connect

Start

연결 상태에서 취득을 시작하고 새 epoch를 엽니다.

Stop

취득을 중지하고 대기 프레임과 트리거를 정리합니다.

Disconnect

연결을 해제하고 대기 프레임과 트리거를 정리합니다.

Fail

0이 아닌 오류 코드로 모의 카메라를 오류 상태로 전환합니다.

Recover

오류 상태를 연결 상태로 복구합니다. 취득은 별도로 시작해야 합니다.

Trigger

취득 중 소프트웨어 또는 외부 트리거를 등록합니다.

OfferFrame

취득 중 프레임을 제안합니다. 수락 시 독립 픽셀 복사본을 큐에 넣습니다.

TryGetFrame

취득 큐에서 가장 오래된 프레임을 꺼냅니다. 빈 큐는 null입니다.
