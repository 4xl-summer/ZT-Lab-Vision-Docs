사용과 결과 해석

색 좌표와 색차를 계산하는 진입점입니다. RGB 성분을 직접 빼는 값과 Lab 같은 지각 색 공간에서의 거리는 같은 척도가 아니므로 어떤 변환과 거리를 선택했는지 명시해야 합니다. 기준 백색과 입력 전달 함수도 좌표 해석에 영향을 줍니다.

예를 들어 두 패치의 CIE76 색차는 Lab 좌표 세 성분의 유클리드 거리로 계산합니다. 한 축에서 3, 다른 축에서 4만큼 차이가 나고 나머지 축이 같다면 거리는 5입니다. 다른 색차 공식은 가중과 비선형 보정이 다르므로 같은 숫자를 같은 허용차로 임의 비교하면 안 됩니다.

색 좌표 계산은 카메라 프로파일과 실제 조명의 안정성, 샘플링 영역의 대표성을 자동으로 보증하지 않습니다. 입력 색 형식과 백색점 조건을 일치시키고 사용자 공차를 독립 색 패치로 검증하십시오.
