사용과 결과 해석

3차원 대응점을 변환한 예측 위치와 기준 위치 사이의 거리 통계를 나타냅니다. Count는 평가한 점의 수이고 MeanError, RmsError, MaxError는 각각 평균, 제곱평균제곱근 및 최대 거리 오차를 요약합니다. 예를 들어 두 개의 거리 잔차가 0과 2라면 평균은 1이고 RMS는 √2이며 최대는 2입니다. 모든 거리 지표는 비교한 3차원 좌표의 길이 단위를 따르므로 밀리미터 좌표와 미터 허용치를 그대로 비교하면 안 됩니다. 평균이 작아도 한 점의 오차가 클 수 있으므로 최대값과 개별 잔차의 위치를 함께 살펴보십시오. 학습에 사용한 점의 통계와 독립 보류점의 통계는 다른 근거입니다. 보정 모델이 학습 자료에 잘 맞았다는 사실만으로 미관측 영역의 정확도를 보장하지 않습니다. 점의 순서가 바뀌어 서로 다른 물리 위치를 짝지으면 수치가 유한해도 오차가 커지거나 의미가 달라집니다. 기준과 예측을 같은 좌표계로 맞추고 Count가 의도한 평가 집합과 일치하는지 확인한 다음 기록하십시오. 통계 수치 하나만으로 어느 점이 문제인지 알 수 없으므로 원래 대응점과 개별 결과를 보존합니다. 예시의 제곱평균은 (0²+2²)/2로 2이며 여기에 제곱근을 적용합니다. 평균 1과 RMS √2는 서로 다른 요약값입니다.
