이 타입을 받는 공개 호출

AdvancedMatchingExtras.FindProjective: 영상에서 두 원근 분모 계수 격자를 포함해 NCC 템플릿을 찾습니다. perspectiveX 인자: X 원근 계수 격자입니다. 반환: 원근 후보와 종료 진단입니다.

AdvancedMatchingExtras.FindProjective: 영상에서 두 원근 분모 계수 격자를 포함해 NCC 템플릿을 찾습니다. perspectiveY 인자: Y 원근 계수 격자입니다. 반환: 원근 후보와 종료 진단입니다.

ExtendedMatchModel.FindProjective: 원근 격자를 포함해 검색합니다. perspectiveX 인자: X 방향 원근 계수 검색 격자입니다. 반환: 원근 후보와 진단입니다.

ExtendedMatchModel.FindProjective: 원근 격자를 포함해 검색합니다. perspectiveY 인자: Y 방향 원근 계수 검색 격자입니다. 반환: 원근 후보와 진단입니다.

ExtendedMatchModel.FindShear: 전단 격자를 포함해 검색합니다. shear 인자: 전단 계수 검색 격자입니다. 반환: 전단 후보와 진단입니다.

RelativeTemplateMatching.FindShear: 실제 영상 표본을 변환해 X 전단 계수를 검색합니다. shear 인자: u'=u+shear*v의 무차원 전단 범위입니다. 반환: 전단 계수와 검색 종료 진단입니다.
