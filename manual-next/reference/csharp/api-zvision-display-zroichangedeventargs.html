사용과 결과 해석

사용자가 표시 화면에서 변경한 픽셀 선택 영역을 이벤트 수신자에게 전달합니다. Roi는 선택된 ZPixelRect 또는 선택이 없는 경우 null입니다. 이 값은 이벤트에서 보고하는 로컬 픽셀 영역이며 자동으로 월드 좌표나 다른 영상의 좌표로 바뀌지 않습니다.

예를 들어 사용자가 기존 선택을 해제하면 null을 받을 수 있으므로 이를 너비와 높이가 0인 실제 사각형으로 무조건 바꾸지 말고 선택 없음으로 처리하십시오. 새 영역이 있으면 현재 표시 중인 영상의 크기와 원점을 고려해 후속 ROI 생성이나 표시 업데이트에 연결합니다.

이벤트가 발생했다는 사실은 사용자가 영역을 바꾸었다는 신호이지 그 영역에 검사 대상이 충분히 들어 있거나 이미지 처리가 완료됐다는 신호가 아닙니다. 수신 측은 현재 영상과 이벤트의 시점을 맞추고, 실제 영상 API에 전달할 때 해당 ROI 범위와 수명 조건을 다시 확인해야 합니다.
