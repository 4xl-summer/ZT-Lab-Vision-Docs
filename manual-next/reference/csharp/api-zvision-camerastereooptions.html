사용과 결과 해석

두 카메라의 광선으로 3차원 위치를 구할 때 사용할 역왜곡과 품질 조건을 묶습니다. 광선 계산 옵션 외에 최소 교차 각도, 두 광선 사이 허용 간격, 재투영 오차 상한과 양의 깊이 요구를 지정합니다. 각도는 라디안이고 간격은 해당 기하의 길이 단위이며 재투영 오차는 픽셀 단위이므로 숫자를 서로 바꾸어 해석하면 안 됩니다.

광선이 거의 평행하면 작은 픽셀 오차가 깊이에 큰 영향을 줄 수 있어 최소 각도 조건이 중요합니다. 두 광선이 실제로 만나지 않는 경우 허용 간격을 이용해 가까운 정도를 판단하고, 계산된 점을 양쪽 영상에 다시 투영한 오차도 함께 검사합니다. 양의 깊이 조건을 켜면 카메라 뒤쪽 해를 허용하지 않도록 선택할 수 있습니다.

이 설정은 스테레오 입력 점이 같은 실제 물체에 대응한다는 사실을 만들어 주지 않습니다. 두 카메라의 내부 보정과 상대 자세, 관측 대응 및 단위를 먼저 맞추고 결과 상태와 진단을 함께 읽어야 합니다. 허용 조건을 통과해도 실제 장비의 측정 정확도는 독립 표본으로 검증해야 합니다.
