사용과 결과 해석

두 개의 에지를 한 쌍으로 선택한 결과와 그 점수를 나타냅니다. First와 Second는 선택된 에지이고 Score는 에지 강도에서 예상 위치 및 폭의 오차를 고려한 점수입니다. 각각의 에지는 하나의 독립된 위치 관찰이며 점수는 두 관찰의 조합을 평가합니다.

예를 들어 두 에지가 강하더라도 예상 중심이나 폭에서 크게 벗어나면 쌍 점수의 해석이 달라질 수 있습니다. 반대로 단일 에지의 강도만 비교하면 실제로 원하는 두께를 형성하는 쌍인지 알기 어렵습니다. 위치와 폭의 좌표 단위는 호출한 탐침 설정을 따라야 합니다.

결과가 없는 경우를 임의의 0 좌표 쌍으로 만들지 말고 선택 결과와 오류를 구별하십시오. 점수는 설정한 기준에 종속되며 곧바로 확률이나 실제 부품 합격률을 뜻하지 않습니다. ROI 원점과 보정도 별도 확인이 필요합니다.
