공개 타입

ZVision.MultiRegistration · class

어셈블리: ZVision.

연결된 영상의 공통 격자 정합 결과를 소유합니다. 연결 그래프는 전역 최적화하지 않습니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object
