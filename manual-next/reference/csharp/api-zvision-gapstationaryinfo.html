사용과 결과 해석

비감쇠 Haar 변환 결과의 너비, 높이와 밴드 수를 설명합니다. 입력을 단계마다 축소하는 decimated 변환과 달리 이 경로는 비감쇠 밴드의 크기를 기준으로 계수를 보관합니다. Width와 Height는 픽셀 격자의 크기이고 BandCount는 포함된 밴드의 수입니다.

계수 배열을 해석할 때는 이 메타데이터와 변환에서 선택한 레벨 및 밴드 순서를 함께 사용하십시오. 너비와 높이만 보고 배열 전체가 한 장의 원본 영상이라고 가정하면 상세 밴드와 근사 밴드를 잘못 연결할 수 있습니다.

정보 값은 변환을 실행한 결과를 설명하며 계수를 자동 수정하거나 역변환을 수행하지 않습니다. 필터링 뒤 재구성이 필요하면 해당 모델의 역변환 경로를 사용하고, 수치 비교에는 부동소수 허용 오차를 적용하십시오. 경계 처리와 입력 형식도 결과에 영향을 줍니다.
