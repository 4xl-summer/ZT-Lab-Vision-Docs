사용 맥락과 결과 해석

명시된 변형 템플릿 모델 중 하나가 만든 확장 매치 후보입니다. Matched는 검색 기준점·자세·점수이고 VariantIndex는 학습에 전달한 변형 목록의 0 기반 번호입니다. 두 번째 변형이 선택되면 번호는 1이며 결과 목록 자체의 인덱스가 아닙니다.

학습 변형의 순서를 바꾸면 동일 숫자가 가리키는 변형도 달라지므로 모델과 입력 목록을 함께 추적합니다. 이 값은 지정한 변형 모델의 선택 결과이며 임의의 연속 변형량을 직접 측정한 값이 아닙니다. 상위 보고서의 평가 수와 종료 상태도 확인해 공유 예산으로 검색이 중단되지 않았는지 판단합니다.

은행의 여러 변형은 후보 평가 예산을 공유하므로 뒤쪽 변형이 실제로 평가되었는지 종료 진단을 확인해야 합니다. Matched의 점수만으로 미평가 변형에 대한 우열을 판단할 수 없습니다. 로컬 기준점의 전역 변환에는 검색 영상의 원점을 더합니다.

값을 확인하는 순서

Matched 항목: 기본 후보 포즈와 점수입니다. VariantIndex 항목: 입력 학습 변형의 0부터 시작하는 번호입니다.
