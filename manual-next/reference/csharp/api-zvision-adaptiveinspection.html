사용과 결과 해석

SSIM과 관련 유도 검사를 제공하는 C# 진입점입니다. 검사할 영상과 기준, 선택한 마스크 및 옵션을 실제 호출의 형식에 맞춰 준비합니다. 같은 크기의 영상이라도 위치가 어긋나면 구조 차이가 생기므로 입력의 정렬과 ROI 원점을 먼저 확인해야 합니다.

SSIM은 국소 밝기와 대비, 구조의 유사도를 결합하는 지표입니다. 결과의 평균 점수는 전체를 요약하지만 작은 결함이 평균에 묻힐 수 있으므로 결함 마스크와 포함된 중심 수를 함께 읽는 것이 좋습니다. 마스크에 의해 검사하지 않은 부분을 정상으로 판단해서는 안 됩니다.

결과 영상과 소유 결과 객체의 Dispose 계약은 호출한 메서드에 따라 따로 확인합니다. 기준 영상의 정상 변동, 조명 차이와 임계값을 합성 자료와 실제 사용 데이터에서 각각 검증해야 하며, 단일 점수가 실장비 인수를 대신하지 않습니다.
