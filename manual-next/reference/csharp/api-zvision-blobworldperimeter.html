경계를 세계 좌표로

BlobWorldPerimeter는 블롭의 픽셀 셀 경계를 세계 좌표로 투영하여 둘레를 계산합니다. 픽셀 둘레에 단일 상수를 곱하는 방식과 달리 각 경계가 변환된 위치에서 길이를 해석합니다. 투영 보정의 방향과 좌표계가 정확히 맞아야 합니다.

행렬과 위치

입력 호모그래피는 행 우선 3×3 계수로 점을 동차 좌표에 투영합니다. 단위 행렬은 좌표를 그대로 두므로 변환 방향을 점검하는 예로 쓸 수 있습니다. ROI 로컬 위치와 전체 영상의 보정 행렬을 혼합하면 다른 장소의 배율이 적용될 수 있습니다.

Run 순서

먼저 Blob 결과와 변환 행렬, 작업량 한도를 준비하고 해당 호출의 조건을 확인합니다. 결과 길이 단위는 목표 세계 좌표계의 단위에 따릅니다. 입력 픽셀 둘레와 출력 길이의 숫자만 비교하지 말고 변환과 영역을 함께 기록합니다.

측정 한계

투영 분모가 0에 가까운 위치에서는 결과가 불안정하거나 실패할 수 있습니다. 실제 길이 판정에는 보정의 유효 범위와 기준점 오차를 검증해야 하며, 계산 성공 자체가 카메라 정확도를 보증하지 않습니다.
