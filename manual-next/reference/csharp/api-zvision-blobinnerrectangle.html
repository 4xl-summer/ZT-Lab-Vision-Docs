전경 내부의 사각형

BlobInnerRectangle은 전경에 완전히 포함되는 최대 축 정렬 사각형의 X, Y, Width, Height를 보관합니다. 시작 좌표는 ROI 로컬이며 너비와 높이는 픽셀 셀 수입니다. 전체 전경을 감싸는 외접 상자와는 반대 방향의 제약을 가진 결과입니다.

크기 예

Width가 3이고 Height가 2이면 사각형 내부에는 6개의 픽셀 셀이 있습니다. 원래 물체의 전체 전경 면적은 그보다 클 수 있으며 사각형 바깥의 전경은 이 숫자에 포함되지 않습니다. 오목한 물체의 홈이나 구멍은 사각형 크기에 영향을 줄 수 있습니다.

위치 표시

BlobInnerRectangleOps의 측정 결과를 입력 마스크에 겹쳐 내부를 확인합니다. X와 Y를 전체 영상에 표시할 때는 분석 ROI의 원점을 적용합니다. 폭과 높이를 시작점의 좌표와 혼동하거나 화면 밖의 물체 부분을 포함해 추정하지 않습니다.

적용 조건

이 사각형은 영상 축에 정렬됩니다. 기울어진 물체의 방향을 따라 회전하는 사각형이 필요한 경우와 구분해야 합니다. 물리 단위 길이는 픽셀 좌표와 보정의 관계를 따로 확인해 계산합니다.
