넓은 레이블별 측정

BlobWideLabelAnalysis는 Gray16 또는 GrayU32 영상의 비영 레이블 그룹을 Blob으로 분석합니다. 각 레이블 값이 그룹을 정의하므로 단순 이진 마스크에서 이웃 연결을 새로 찾는 작업과 구분합니다. 값 0은 배경으로 취급합니다.

같은 값의 위치

예를 들어 떨어져 있는 두 위치에 같은 비영 레이블이 있으면 같은 값의 그룹으로 분석됩니다. 단순히 공간에서 멀리 떨어졌다는 이유만으로 별도 레이블을 자동 생성한다고 가정하지 않습니다. 서로 다른 레이블이 필요한 경우 입력 레이블을 만드는 단계부터 확인합니다.

Analyze 입력

지원되는 레이블 형식과 작업량 한도를 Analyze의 계약에 맞게 지정합니다. 레이블 맵을 원본에 표시하고 반환된 각 그룹의 면적과 위치가 예상 대상에 대응하는지 확인합니다. 숫자의 크기는 영역의 면적이나 중요도 순서가 아닙니다.

결과 비교

다른 프레임의 같은 레이블 값이 동일 물체인지 여부는 입력 레이블을 만든 과정에 달려 있습니다. 프레임, ROI와 레이블 생성 조건을 보관하고 물리 면적이 필요한 경우 픽셀 보정을 따로 적용합니다.
