사용과 결과 해석

SpatialCylinderOptions는 원통을 국소 피팅할 때 반복 수, 허용 이상치, 선택적 초기 축과 종료 조건을 지정하는 C# 값입니다. iterations는 양의 단계별 반복 한도이고 outlier는 유한한 0 이상 1 미만의 비율입니다. axis를 지정하면 0이 아닌 유한한 방향이 필요하며 계산 시 정규화합니다. null이면 초기 축을 직접 제공하지 않습니다.

step은 정규화된 매개변수 변화의 양의 허용값으로 기본 1e-10이고 rms는 점군 단위의 0 이상 목표값으로 기본 0입니다. target은 지지율 조기 종료 조건이며 0은 비활성입니다. 이 옵션은 Spatial3dAdvanced.FitCylinder의 별도 거리 threshold와 함께 사용합니다. 예를 들어 거리 기준을 0.1 mm로 주었다면 그 값은 해당 점군의 단위에서 해석합니다. 짧은 호나 축 범위 부족은 반복 횟수를 늘려도 식별 문제를 남길 수 있습니다.
