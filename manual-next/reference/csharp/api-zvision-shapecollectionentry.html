사용 맥락과 결과 해석

형상 모델 컬렉션에서 한 모델과 고유 식별자를 묶는 입력입니다. Id는 호출에서 중복되지 않아야 하고 Model은 검색에 사용할 형상 모델입니다. 이 항목은 물체를 찾은 결과나 목록 순번이 아니라 이후 결과의 모델 출처를 식별하기 위한 설정입니다.

여러 부품 모델을 같은 검색 영상에 적용할 때 각 모델에 서로 다른 id를 지정합니다. 결과 항목의 Id를 원래 입력에 연결하여 포즈와 점수를 해석하세요. 공통 검색 격자와 전체 포즈 예산은 별도로 전달되며, 모델을 검색하는 동안 유효하게 유지해야 합니다. 작업 종료 후 모델의 소유권은 호출자가 관리합니다.

항목 배열 순서와 지정한 Id는 다릅니다. 전체 검색이 예산에서 중단되면 특정 항목이 아직 평가되지 않았을 수 있으므로 결과 개수와 종료 진단을 같이 확인합니다. 반환된 결과를 다른 검사 결과와 연결할 때 id의 의미를 먼저 확인합니다.
