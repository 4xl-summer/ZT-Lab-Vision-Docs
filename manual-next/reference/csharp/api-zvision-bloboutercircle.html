셀을 감싸는 외접원

BlobOuterCircle은 블롭의 셀 모서리를 포함하는 원의 X, Y 중심과 Radius를 나타냅니다. 중심은 ROI 로컬이고 반지름은 픽셀 단위입니다. 내부 원이나 픽셀 중심들만 감싸는 원과는 서로 다른 정의입니다.

셀 경계의 역할

전경 픽셀 하나는 면적이 있는 셀로 표현할 수 있습니다. 셀의 중심 한 점만 감싸는 것과 네 모서리까지 포함하는 것은 다른 문제이므로 작은 물체에서 반지름 차이가 크게 보일 수 있습니다. 원 안의 모든 위치가 전경이라는 뜻도 아닙니다.

결과 표시

BlobOuterCircleOps에서 선택한 성분의 결과를 얻고 입력 마스크 위에 중심과 원을 그려 확인합니다. 전체 영상에 표시할 때는 중심의 ROI 원점을 반영합니다. 고리나 오목한 모양에서는 원의 중심이 배경에 위치할 수도 있습니다.

비교 조건

물체가 ROI 경계에서 잘리면 보이는 셀을 기준으로 원이 정해집니다. 픽셀 크기가 축마다 다르거나 투영 보정이 필요한 경우 픽셀 좌표의 원을 그대로 물리 단위 원으로 취급하지 않습니다.
