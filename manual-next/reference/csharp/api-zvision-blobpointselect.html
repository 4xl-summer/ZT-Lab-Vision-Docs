픽셀을 포함하는 영역

BlobPointSelect는 주어진 픽셀을 포함하는 입력 영역을 선택합니다. 가장 가까운 중심을 찾는 연산이 아니라 지정 위치가 마스크에 속하는지 확인하는 연산입니다. 둘 이상의 마스크가 겹치면 선택 관계를 해당 결과에 맞게 해석해야 합니다.

로컬 좌표 예

ROI 원점이 전체 영상의 (100,200)이고 선택할 점이 전체 좌표 (110,220)이면 로컬 위치는 (10,20)입니다. 원점을 빼지 않고 전체 좌표를 전달하면 다른 픽셀을 검사하게 됩니다. 입력 마스크와 좌표가 같은 기준을 사용하는지 먼저 확인합니다.

Select 순서

영역 목록과 정수 위치, 작업 한도를 Select에 전달하고 결과 인덱스를 입력 목록과 연결합니다. 목록의 순서를 변경하면 같은 인덱스가 다른 마스크를 가리킬 수 있으므로 결과와 입력 순서를 같이 보관합니다.

진단

예상한 영역이 선택되지 않으면 점이 실제 전경 픽셀인지, ROI 기준과 원점이 맞는지 확인합니다. 화면에 두껍게 그린 윤곽선과 실제 이진 마스크의 전경 픽셀은 완전히 일치하지 않을 수 있습니다.
