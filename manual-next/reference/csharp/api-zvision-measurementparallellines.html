사용과 결과 해석

두 유향 평행선 사이의 부호 있는 거리를 계산하는 연산을 제공합니다. 부호는 첫 기준선의 진행 방향과 둘째 선의 상대 위치에 따라 해석하므로 단순한 거리 크기만으로 어느 편에 있는지 복원할 수 없습니다. 예를 들어 첫 선이 원점에서 (1,0) 방향을 향하고 둘째 선의 기준점이 (0,2)이면 해당 x/y 좌표 관례에서 거리는 +2입니다. 첫 선의 방향을 뒤집으면 같은 위치 관계의 부호도 달라집니다. 결과 단위는 입력 선 좌표의 단위와 같고, 픽셀 입력이면 픽셀 거리입니다. 서로 다른 ROI에서 얻은 선은 공통 좌표계로 옮긴 뒤 비교해야 합니다. 유향 평행선은 일반적인 무향 무한선 거리와 역할이 다르며, 평행 조건을 만족하지 않는 선에 결과를 임의로 적용해서는 안 됩니다. 평행 판정에 사용하는 허용치가 무엇을 비교하는지 메서드 계약을 확인하고 거리 단위와 혼동하지 마십시오. 선의 방향 벡터가 0이면 진행 방향을 정할 수 없고, 실패를 정상적인 간격 0으로 바꾸면 일치하는 선과 구별할 수 없습니다. 동일 방향의 선 y=0과 y=2 예제에서 결과 크기 2는 두 선 사이의 수직 간격입니다. 첫 선의 방향을 (−1,0)으로 바꾸면 기준 왼쪽이 바뀌므로 부호도 반대로 해석됩니다. 두 선의 순서와 방향을 보고서에 보존하십시오.
