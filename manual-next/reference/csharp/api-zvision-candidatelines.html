사용과 결과 해석

선 탐침에서 검출한 피크와 적합된 선을 함께 담은 독립 결과입니다. Lines는 적합 순서의 선 배열이고 Candidates는 임계 조건을 통과해 반환된 피크의 배열입니다. 하나의 선에 여러 후보가 연결될 수 있고 선에 연결되지 않은 후보도 있으므로 두 배열 길이를 일대일로 대응시키면 안 됩니다.

각 후보의 선택적 선 인덱스와 분류, 이유를 사용해 실제 적합에 포함되었는지 확인합니다. 극성에서 제외된 후보와 적합에 고려되었다가 거절된 후보는 처리 단계가 다릅니다. 피크만 추출하도록 선 수를 0으로 제한한 실행에서는 선 배열이 비어 있을 수 있습니다.

반환 배열은 결과의 독립 복사본이며 원본 영상의 수명을 유지하기 위한 핸들이 아닙니다. 좌표는 ROI 로컬이므로 다른 영상이나 월드 좌표에 연결할 때 원점과 보정을 확인하십시오. 보고되지 않은 피크가 영상에 전혀 존재하지 않는다는 뜻은 아니며 추출 문턱 아래 피크는 목록에 들어오지 않습니다.
