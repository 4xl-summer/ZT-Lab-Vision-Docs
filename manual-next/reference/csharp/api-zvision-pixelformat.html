이 타입을 받는 공개 호출

AdvancedColorResult.ToRgb: Lab 또는 LCH 평면을 원래 백색점과 입력 전달 함수를 사용한 RGB 영상으로 복원합니다. format 인자: 출력 컬러 픽셀 형식입니다. 반환: 호출자가 해제할 독립 RGB 영상입니다.

AdvancedPlanes.ToRgb: 평면을 RGB 영상으로 변환합니다. format 인자: 출력 형식입니다. 반환: 호출자가 해제할 영상입니다.

CareGaussianOptions..ctor: 설정을 생성합니다. 유효 범위는 실행 시 검증합니다. output 인자: 출력 회색 형식입니다.

ColorPlanesResult.ToRgb: 색 평면을 지정한 RGB 또는 BGR 영상 형식으로 역변환합니다. 알파 출력은 지원하지 않습니다. format 인자: 출력 형식으로 Rgb8, Bgr8, Rgb16, Bgr16 또는 RgbF32입니다. 반환: 독립 소유 결과입니다. 사용 후 Dispose해야 합니다.

ConvolutionSpec..ctor: 커널을 복사해 설정을 만듭니다. 유효 범위는 계산 시 검사합니다. output 인자: GrayF64 출력 형식이어야 합니다.

FrequencySpectrum.InverseImage: 원래 ROI 원점을 보존한 독립 영상을 생성합니다. outputFormat 인자: Gray8, Gray16, GrayF32, GrayF64 중 하나입니다. 반환: 호출자가 해제할 독립 영상입니다.

GapCareGaussianResult.Run: 선택된 care 표본의 정규화 Gaussian을 계산합니다. outputFormat 인자: 회색 출력 형식입니다. 반환: 해제할 결과입니다.

GapCareGaussianResult.RunSelected: 입력 care 표본과 독립된 출력 위치 마스크를 적용합니다. outputFormat 인자: 출력 회색 형식입니다. 반환: 해제할 결과입니다.

GapCareRank.Apply: 비영 care 표본만 사용해 지정 순위를 선택합니다. outputFormat 인자: Gray8, Gray16 또는 GrayF32 출력입니다. 반환: 독립 소유 영상입니다.

GapCareRank.ApplyExtended: 커널 footprint와 care 마스크를 함께 적용합니다. outputFormat 인자: 출력 회색 형식입니다. 반환: 독립 소유 영상입니다.

GapFlatField.Correct: 입력×전역 gain×gain map+전역 offset+offset map을 계산합니다. outputFormat 인자: Gray8/16/F32/F64 출력 형식입니다. 반환: 입력 원점을 보존하는 독립 영상입니다.

GapImageArithmetic.Apply: 연산 후 gain과 bias를 적용한 독립 영상을 반환합니다. outputFormat 인자: 채널 순서가 보존되는 출력 형식입니다. 반환: 독립 소유 출력 영상입니다.
