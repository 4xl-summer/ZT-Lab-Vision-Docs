사용과 결과 해석

SpatialSearchResult는 검색에서 반환된 한 모델 후보의 인덱스, 겹침과 정합 진단을 담은 값입니다. ModelIndex는 전달한 모델 배열의 0부터 시작하는 위치입니다. 예를 들어 ModelIndex가 1이면 두 번째 모델에 해당하므로 결과를 저장할 때 입력 모델 목록의 순서와 식별자를 함께 보관해야 합니다. Overlap은 대응 거리 안에 들어온 모델 점의 비율입니다.

Registration에는 원본 모델에서 목표로 가는 Transform, Iterations, Inliers, Rms와 Converged가 있습니다. Rms는 점군 길이 단위이고 Converged는 반복 정지 조건의 결과이므로 둘을 함께 확인해야 합니다. 유사한 자세가 대칭이나 부분 가림 때문에 여러 개 나올 수 있으며, 검색 예산이 한정되어 가능한 모든 후보를 보장하지 않습니다. 빈 배열은 수용된 후보가 없다는 정상 결과일 수 있고 잘못된 옵션이나 점 부족은 오류로 구분합니다.
