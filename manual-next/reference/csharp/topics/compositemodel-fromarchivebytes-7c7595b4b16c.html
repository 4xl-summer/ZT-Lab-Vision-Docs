static ZVision.CompositeModel FromArchiveBytes(System.Byte[] data)

완전한 복합 계측 보관 형식을 검증하여 모델을 복원합니다.

인자

data: 버전이 있는 복합 계측 보관 바이트입니다.

반환: 호출자가 해제할 모델입니다.

이 호출의 입력과 객체 맥락

검증된 복합 계측 그래프와 출력 단위가 저장된 아카이브에서 독립 소유 모델을 복원합니다. 입력은 비어 있으면 안 되고 최대 2200000바이트입니다. 버전과 그래프가 유효한지 확인한 뒤 모델을 만들며, 결과는 이후 평가에 재사용할 수 있습니다. 사용 후 Dispose합니다.

보관 그래프를 검증해 복원

FromArchiveBytes는 버전이 있는 복합 계측 아카이브 바이트를 받아 독립 소유 CompositeModel을 복원합니다. data는 비어 있으면 안 되고 최대 2,200,000바이트입니다. 복원 시 버전과 그래프의 유효성을 확인하므로 임의의 바이트나 평가 결과 영상을 모델 아카이브처럼 전달할 수 없습니다.

예를 들어 프레임·특징·공차가 들어 있는 모델을 아카이브로 저장했다면 바이트를 변경하지 않고 읽어 이 메서드에 전달합니다. 복원에 성공한 모델에서 같은 입력을 평가해 특징과 공차가 예상대로 동작하는지 비교하세요. 바이트가 잘렸거나 버전·구성이 유효하지 않으면 오류를 처리하고 기본 모델로 임의 대체하지 않습니다.

항목의미와 처리
data버전이 있는 모델 아카이브
길이1~2,200,000바이트
검증버전과 그래프 유효성
반환독립 소유 CompositeModel
재평가알려진 입력으로 특징과 공차 확인
정리복원된 모델을 Dispose

적용과 결과 확인

반환된 모델은 호출자가 Dispose해야 합니다. 복원에 사용한 byte 배열은 관리되는 입력 값이며 모델의 네이티브 핸들과 다른 수명입니다. 아카이브에는 그래프와 출력 단위가 포함되지만 특정 검사의 입력 영상이나 실제 검사 판정을 대신하는 데이터는 아닙니다. 보관한 단위와 현재 영상의 좌표 기준도 확인하세요.

길이가 최대 조건 안에 들어간다는 것은 버전과 그래프가 유효하다는 뜻까지는 아닙니다. 빈 입력, 잘린 파일, 다른 형식의 데이터는 각각 복원 호출에서 실패할 수 있으므로 오류와 파일 출처를 기록하세요. 성공한 모델의 특징 식별자와 공차가 의도한 구성인지 확인하고, 현재 입력 영상이 그 모델의 ROI와 형식 조건에 맞는지 별도로 검증해야 합니다. 아카이브를 복원했다고 새로운 영상의 검사가 이미 실행된 것은 아닙니다.
