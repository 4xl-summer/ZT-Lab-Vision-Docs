ZVision.GapHaarWavelet WithCoefficients(System.Double[] values)

외부 계수의 스냅샷을 사용해 독립 모델을 만듭니다.

인자

values: 모델 크기의 유한한 행 우선 계수입니다.

반환: Dispose해야 하는 독립 모델입니다.

이 호출의 입력과 객체 맥락

외부의 유한 계수 배열을 복사해 독립 모델을 만듭니다. 배열은 원 모델이 요구하는 전체 크기와 순서에 맞아야 합니다. 예를 들어 Coefficients로 복사한 값을 수정한 뒤 이 메서드에 주면 원본과 별도의 모델을 갖게 됩니다. 새 모델을 Inverse로 확인하고, 원본 모델·새 모델·반환 영상의 수명은 각각 관리합니다.

계수 복사와 복원

WithCoefficients는 외부 계수의 스냅샷으로 원본과 독립적인 새 Haar 모델을 만듭니다. values는 원 모델이 요구하는 전체 크기의 행 우선 배열이며 모든 값이 유한해야 합니다. 계수 배열이 일부 밴드만 포함하거나 길이가 다르면 모델 전체를 재구성할 수 없으므로 요구 형식에 맞춰 전달해야 합니다.

원본 Coefficients를 복사해 원하는 값을 변경하고 새 모델에 전달하면 원본 모델과 구분해 실험할 수 있습니다. Inverse로 새 영상이 어떻게 달라졌는지 확인하되, 입력 ROI 원점과 영상 크기도 함께 비교하십시오. 원본 모델, 새 모델 및 별도 반환 영상을 각각 사용 후 Dispose합니다.

항목의미와 사용
values전체 크기의 행 우선 계수
값 조건모든 계수는 유한해야 함
입력 배열모델에 복사되는 스냅샷
반환독립 모델
원본새 모델 생성으로 변경되지 않음
Inverse새 계수의 복원 결과 확인
수명각 모델과 영상 별도 Dispose
