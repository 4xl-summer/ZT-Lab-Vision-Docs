결과와 사용 순서

입력과 결과 해석

이 객체가 가진 네이티브 자원 또는 뷰 임대를 해제합니다. 해제한 객체를 다시 사용하지 말고 별도로 취득한 영상이나 열린 행의 수명은 해당 객체의 계약에 따라 각각 관리하세요.

공유 영상과 해제 순서

Dispose는 이 ZImage가 소유한 네이티브 핸들을 해제합니다. 예를 들어 영상 A에서 별도로 공유 영상 B를 얻은 뒤 A를 해제해도 B는 자신의 공유 핸들을 통해 계속 유효합니다. 해제한 A를 다시 사용해서는 안 되며 B를 사용한 뒤에는 B도 정리합니다.

단계 또는 항목확인할 내용
A 사용원본 영상 핸들 열림
B 취득별도 공유 핸들 생성
A 해제A는 더 이상 사용 불가
B 사용B의 수명 동안 계속 유효
B 해제별도 소유 핸들을 정리

결과를 사용할 때

공유는 픽셀의 깊은 복사와 다릅니다. A와 B가 저장소를 공유할 수 있지만 각 핸들의 수명은 별도입니다. 읽기 뷰나 결과에서 얻은 다른 소유 영상도 각각의 계약에 따라 해제하세요. using 범위를 이용하면 정상 종료와 예외 경로에서 정리 시점을 명확히 할 수 있습니다.
