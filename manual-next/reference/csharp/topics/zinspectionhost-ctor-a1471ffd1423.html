ZInspectionHost(System.Int32 capacity = 2, ZVision.Inspection.IZInspectionExecutor executor = null)

검사 호스트를 시작합니다.

인자

capacity: 대기열 용량 1부터 16입니다. 실행 중인 요청은 포함하지 않습니다.

executor: 사용할 실행기 또는 기본 실행기입니다.

인자별 입력 조건

인자형식역할과 조건
capacitySystem.Int32대기열 용량 1부터 16입니다. 실행 중인 요청은 포함하지 않습니다.
executorZVision.Inspection.IZInspectionExecutor사용할 실행기 또는 기본 실행기입니다.

검사 호스트 생성

capacity는 대기 요청 수로 기본값 2이며 1부터 16까지입니다. 현재 실행 중인 요청은 이 대기열 용량에 포함하지 않습니다. executor를 생략하면 기본 ZInspectionExecutor를 사용하고 작업 스레드를 시작합니다.

예를 들어 capacity가 1이면 실행 중인 요청과 별도로 대기 요청 하나를 보관할 수 있습니다. 잘못된 capacity는 ArgumentOutOfRangeException입니다. 호스트 종료는 StopAsync 또는 Dispose로 수행합니다.
