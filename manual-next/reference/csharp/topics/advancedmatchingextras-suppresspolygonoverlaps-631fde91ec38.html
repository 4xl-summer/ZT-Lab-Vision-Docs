static ZVision.AdvancedMatch[] SuppressPolygonOverlaps(ZVision.AdvancedMatchModel model, ZVision.AdvancedMatch[] matches, System.Double maxIou, System.UInt64 limit)

회전된 템플릿 경계 다각형의 교집합 비율로 겹침을 억제합니다.

인자

model: NCC 모델입니다.

matches: 후보 배열입니다.

maxIou: 최대 교집합 비율입니다.

limit: 최대 반환 수입니다.

반환: 남은 후보 배열입니다.

관련 입력의 확인된 조건

model.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

호출 맥락과 결과 해석

변환된 템플릿 다각형끼리의 겹침을 기준으로 기존 후보를 억제합니다. 축 정렬 경계상자 IoU를 사용하는 SuppressOverlaps와 비교하면 회전된 후보의 겹침 판단 기준이 다릅니다. 후보를 새로 찾는 기능은 아닙니다.

maxIou로 허용 겹침을 지정하고 limit으로 남길 결과 수를 제한합니다. 같은 후보 집합을 두 억제 방식에 전달해 어떤 포즈가 유지되는지 비교하면 경계상자와 실제 템플릿 다각형의 차이를 확인할 수 있습니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
modelNCC 모델입니다.
matches후보 배열입니다.
maxIou최대 교집합 비율입니다.
limit최대 반환 수입니다.
