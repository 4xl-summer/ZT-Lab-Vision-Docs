ZPixelProbeEventArgs(System.Int32 x, System.Int32 y, System.String value)

픽셀 조사 이벤트를 생성합니다.

인자

x: 로컬 열입니다.

y: 로컬 행입니다.

value: 원본 값 문자열입니다.

사용 순서와 결과 해석

픽셀 조사 이벤트에 로컬 x, y와 표시할 value 문자열을 묶습니다. 이 생성자는 x와 y를 영상 크기와 비교해 유효성을 판단하지 않으므로 호출자는 조사 대상 영상의 경계를 확인해야 합니다. value는 null일 수 없습니다. 실제 원본 채널 문자열은 ZDisplayRaster.GetPixel로 얻을 수 있습니다.

입력별 확인

입력의미
x로컬 열입니다.
y로컬 행입니다.
value원본 값 문자열입니다.
