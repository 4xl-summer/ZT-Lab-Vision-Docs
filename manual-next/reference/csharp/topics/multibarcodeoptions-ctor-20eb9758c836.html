MultiBarcodeOptions()

기본 MultiBarcodeOptions 인스턴스를 만듭니다.

사용과 결과 해석

다중 바코드 판독의 기본 설정을 만듭니다. 회전 각도는 0도 하나, TryHarder는 true, MaxResults는 100이며 반전 영상 추가 탐색은 기본적으로 꺼져 있습니다.

형식과 회전 목록을 실제 기호에 맞게 지정하십시오. 최대 결과 수는 발견을 보장하는 개수가 아니며 재귀 백엔드가 모든 기호를 찾는다고 보장하지 않습니다.

기본 검색 조건

기본 설정의 회전 목록은 0도 하나이고 TryHarder는 true입니다. 반전 영상의 추가 탐색은 꺼져 있으며 MaxResults는 100입니다. Formats는 빈 배열로 시작하고 최소 길이는 0, 최대 길이는 UInt32 최대값입니다. 입력에 맞는 형식과 각도, 결과 제한을 설정한 뒤 판독 호출에 사용합니다.

각도는 시계 방향의 도 단위입니다. 예를 들어 90도 회전을 추가하려면 각도 목록에 명시해야 합니다. 반환 개수 상한을 높여도 모든 기호를 반드시 발견한다는 보장은 없습니다. MinLength와 MaxLength는 디코딩 후 문자열 승인 조건으로 검색 범위나 기호 개수와는 역할이 다릅니다.
