ZVision.Homography Then(ZVision.Homography next)

현재 변환을 먼저, 다음 변환을 나중에 적용하도록 합성합니다.

인자

next: 현재 변환 다음에 적용할 변환입니다.

반환: 계산된 결과입니다.

사용과 결과 해석

현재 변환을 먼저 적용하고 next를 그 결과에 적용하는 합성 변환을 반환합니다. 합성 순서는 좌표계의 연결 순서이므로 반대로 호출하면 일반적으로 다른 결과가 나옵니다.

예를 들어 x로 3 이동한 다음 두 배 확대하면 점 (1,1)은 (8,2)가 됩니다. 두 배 확대 후 이동하면 (5,2)입니다. 개별 적용 결과와 합성 결과를 비교해 방향을 확인하십시오.

첫째m00×x + m01×y + m02
둘째m10×x + m11×y + m12
셋째m20×x + m21×y + m22
