PixelArithmetic

Method · 선언 타입 ZVision.ZImage

C#
ZVision.ZImage PixelArithmetic(ZVision.ZImage right, ZVision.PixelArithmeticOptions options, ZVision.ZeroDivisorPolicy zeroPolicy = ZVision.ZeroDivisorPolicy.Error)

두 영상의 대응 성분을 산술 처리하고 배율과 편향을 적용합니다.

인자

right: 형식과 크기가 같은 오른쪽 영상입니다.

options: 연산 및 출력 설정입니다.

zeroPolicy: 나눗셈의 0 분모 정책입니다.

반환: 호출자가 Dispose할 독립 영상입니다.

관련 입력의 확인된 조건

options.Operation: 대응 성분의 산술 연산입니다.

options.Output: 출력 픽셀 형식입니다.

options.Gain: 결과에 곱할 유한 배율입니다.

options.Bias: 배율 적용 후 더할 유한 값입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
rightZVision.ZImage형식과 크기가 같은 오른쪽 영상입니다.
optionsZVision.PixelArithmeticOptions연산 및 출력 설정입니다.
zeroPolicyZVision.ZeroDivisorPolicy나눗셈의 0 분모 정책입니다.

options의 입력 값

필드의미와 조건
operation성분별 더하기, 곱하기, 나누기, 최솟값, 최댓값 또는 빼기를 선택합니다.
gain성분별 연산 결과에 곱하는 유한 계수입니다.
bias계수를 적용한 뒤 더하는 유한 값입니다.
output결과 이미지에 요청할 픽셀 형식입니다.

zeroPolicy의 입력 값

필드의미와 조건
ERROR0 제수를 오류로 처리합니다.
ZERO0 제수의 출력 성분을 0으로 둡니다.

결과와 사용 순서

호출자가 Dispose할 독립 영상입니다.

입력과 결과 해석

픽셀 좌표의 기준이 전체 영상인지 현재 ROI인지 확인해야 합니다. 같은 (x,y) 숫자라도 ROI 원점이 달라지면 가리키는 원본 위치가 달라질 수 있습니다.
