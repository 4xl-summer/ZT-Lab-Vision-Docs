ZVision.ImageQuery ThresholdOtsu(System.Int32 bins, System.Double lower, System.Double upper)

Otsu 방법으로 임계값을 정해 마스크를 만드는 연산을 계획합니다. 실제 처리는 Run에서 수행합니다.

인자

bins: 히스토그램 빈 수.

lower: 히스토그램 범위의 하한.

upper: 히스토그램 범위의 상한.

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

ThresholdOtsu의 사용과 결과 해석

이 오버로드의 선언에 지정된 인자와 반환 형식을 확인합니다. 이름이 같은 다른 Otsu 호출과 동일한 설정 경로인지 서명을 기준으로 구분합니다. 강도를 기준으로 픽셀을 전경과 배경으로 구분합니다. 임계값 자체와 결과 마스크는 다른 값이며, 경계에 걸린 픽셀이 어떻게 분류되는지는 선택한 연산의 비교 규칙을 확인합니다.

항목이 호출에서 확인할 내용
