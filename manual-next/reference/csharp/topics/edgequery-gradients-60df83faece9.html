Gradients

Method · 선언 타입 ZVision.EdgeQuery

C#
System.Double[] Gradients(System.UInt64 selector, System.UInt32 feature, System.Boolean byLabel = false)

Copies a requested stored gradient response array.

인자

selector: Index or label of an included edge.

feature: 16 magnitude or 32 normal angle.

byLabel: True when selector is a stable label.

반환: Independent response values, one per ordered point.

이 호출의 입력과 객체 맥락

현재 포함된 에지의 요청한 크기 또는 법선 각도 응답을 점 순서에 맞춰 복사합니다. 기본 selector는 조밀 인덱스이고 레이블 선택이 참이면 안정된 레이블입니다. 각도는 영상 y 아래 방향 기준 라디안입니다. 점 배열과 응답을 같은 순서로 사용하고, 필요한 기능이 계산되었는지 Available로 확인하세요. 반환 숫자들은 독립 값입니다.

사용 조건과 결과 판독

이 호출은 포함된 에지 하나에 저장된 기울기 응답을 점 순서에 맞춘 독립 double 배열로 복사합니다. feature=16은 크기, 32는 법선 방향 각도입니다. 결과 배열의 각 항목은 같은 에지를 Points로 얻었을 때의 순서에 대응합니다.

기본 byLabel=false는 selector를 현재 포함 목록의 0 기반 조밀 인덱스로 해석하고 true는 안정 레이블로 해석합니다. 중간 에지를 제외하면 조밀 인덱스가 바뀔 수 있으므로 다음 프레임이나 재포함 전후에 같은 에지를 추적하려면 반환된 레이블을 기록하세요.

기울기는 원래 추출 영상에서 CalculateGradients로 계산해야 하며 Available로 필요한 단일 기능 비트를 확인할 수 있습니다. 각도는 영상 +y가 아래인 좌표에서 atan2(gy,gx) 라디안인 법선 방향이지 접선 각도가 아닙니다. 배열은 복사값이고 쿼리 객체는 별도 Dispose합니다.
