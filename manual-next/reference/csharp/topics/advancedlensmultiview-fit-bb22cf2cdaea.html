static ZVision.AdvancedLensMultiviewResult Fit(ZVision.AdvancedLensView[] views, ZVision.LensModel initial, ZVision.AdvancedLensOptions options)

초기 렌즈와 영상별 자세에서 공동 최적화합니다.

인자

views: 대응점과 초기 자세입니다.

initial: 초기 렌즈 모델입니다.

options: 렌즈 변수와 수렴 설정입니다.

반환: 추정 렌즈와 영상별 자세입니다.

관련 입력의 확인된 조건

initial.Fx: x 방향 초점 거리(픽셀)입니다.

initial.Fy: y 방향 초점 거리(픽셀)입니다.

initial.Cx: 주점의 글로벌 x 픽셀 좌표입니다.

initial.Cy: 주점의 글로벌 y 픽셀 좌표입니다.

initial.K1: 1차 방사 왜곡 계수입니다.

initial.K2: 2차 방사 왜곡 계수입니다.

initial.K3: 3차 방사 왜곡 계수입니다.

initial.P1: 첫 번째 접선 왜곡 계수입니다.

initial.P2: 두 번째 접선 왜곡 계수입니다.

AdvancedLensMultiviewResult.Lens: 렌즈 모델과 진단입니다.

AdvancedLensMultiviewResult.Poses: 입력 순서의 최적화 자세입니다.

이 호출의 입력과 객체 맥락

options.OptimizeMask: fx, fy, cx, cy, k1, k2, k3, p1, p2 순서의 최적화 비트입니다.

options.Damping: 초기 양의 감쇠 계수입니다.
