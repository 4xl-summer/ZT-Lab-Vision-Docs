ContourMetrics

Method · 선언 타입 ZVision.FlexibleRegions

C#
static ZVision.FlexibleContourMetrics ContourMetrics(ZVision.Point2[] points, System.Boolean closed, System.UInt64 step)

윤곽 길이와 각 점의 이산 곡률을 계산합니다.

인자

points: 유한 좌표 배열입니다.

closed: 마지막 점과 처음 점을 연결하면 true입니다.

step: 양쪽에서 비교할 이웃 점 인덱스 거리입니다.

반환: 독립 길이와 곡률 배열입니다.

관련 입력의 확인된 조건

FlexibleContourMetrics.Length: 윤곽의 전체 길이입니다.

FlexibleContourMetrics.Curvature: 각 점의 부호 있는 회전각을 평균 인접 현 길이로 나눈 값입니다.

ContourMetrics의 사용과 결과 해석

곡선의 길이와 형상 지표를 읽을 때 좌표 단위와 열린 윤곽인지 닫힌 윤곽인지 구분합니다. 서로 다른 지표를 같은 차원의 값으로 비교하지 않습니다. 이진 영역의 내부 구조와 경계 형상을 다룹니다. 빈 공간의 채움, 영상 경계 접촉, 거리와 분할은 각각 다른 결과를 만들므로 전경과 배경의 의미 및 연결성을 먼저 정합니다.

closed마지막 점과 처음 점을 연결하면 true입니다.

FlexibleContourMetrics.Length윤곽의 전체 길이입니다.
FlexibleContourMetrics.Curvature각 점의 부호 있는 회전각을 평균 인접 현 길이로 나눈 값입니다.
반환독립 길이와 곡률 배열입니다.
