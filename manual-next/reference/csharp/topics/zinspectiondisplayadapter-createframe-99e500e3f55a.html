C#
static ZVision.Display.ZDisplayFrame CreateFrame(ZVision.Inspection.ZInspectionResult result, System.String stage)

단계의 표시 프레임을 만듭니다. Threshold와 Close에는 선택 영역의 로컬 경계를 표시합니다.

인자

result: 빌린 검사 결과입니다.

stage: 단계 이름입니다.

반환: 결과와 독립적으로 호출자가 해제할 프레임입니다.

관련 입력의 확인된 조건

result.Statistics: 닫기 영상의 통계입니다.

result.Metrics: 단계별 벽시계 시간입니다.

result.Elapsed: 전체 벽시계 시간입니다.

ZDisplayFrame.PixelFormat: 원본 픽셀 형식입니다.

ZDisplayFrame.Overlays: 불변 도형 장면입니다.

사용과 결과 해석

검사 결과와 단계 이름으로 독립 소유 표시 프레임을 만듭니다. Threshold와 Close 단계에는 선택 영역의 로컬 경계를 표시합니다.

반환 프레임은 결과와 별도로 해제해야 합니다. 단계명과 프레임·레시피 세대를 함께 사용해 표시 대상이 올바른 결과인지 확인하십시오.
