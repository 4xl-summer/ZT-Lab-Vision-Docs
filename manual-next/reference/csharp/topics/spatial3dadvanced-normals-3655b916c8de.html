Normals

Method · 선언 타입 ZVision.Spatial3dAdvanced

C#
static System.Nullable<ZVision.Point3>[] Normals(ZVision.PointCloud cloud, System.UInt32 method, ZVision.Point3 viewpoint, System.Double radius = 1, System.UInt64 width = 0, System.UInt64 height = 0, System.UInt64 pixelRadius = 0)

반경 또는 조직형 또는 k-d 트리 이웃의 PCA 법선을 계산합니다.

인자

cloud: 입력 점군입니다.

method: 0 반경, 1 조직형, 2 k-d 트리입니다.

viewpoint: 법선 방향 기준점입니다.

radius: 반경 탐색 거리입니다.

width: 조직형 너비입니다.

height: 조직형 높이입니다.

pixelRadius: 조직형 픽셀 반경입니다.

반환: 슬롯별 법선이며 결측은 null입니다.

관련 입력의 확인된 조건

cloud.Info: 격자 또는 점군의 메타데이터를 가져옵니다.

점군 법선 추정

각 유효 점의 이웃으로 국소 면의 방향을 추정합니다. 이웃은 중심 외의 점을 뜻하며, 주어진 관측 위치는 법선 방향을 정하는 데 사용됩니다. 결측점이나 충분하지 않거나 퇴화한 이웃에서는 방향을 정할 수 없어 해당 결과도 결측이 됩니다.

평평한 z=0 면에 서로 다른 위치의 점이 충분하면 법선은 z축과 평행합니다. 수직 방향의 부호는 관측 위치에 따른 방향 정렬을 함께 확인해야 하므로 절댓값만으로 앞면과 뒷면을 판정하지 않습니다. 출력은 원본 슬롯과 같은 순서로 해석합니다.

이 호출의 method 값 0은 반경 탐색, 1은 조직화 격자, 2는 k-d 트리 탐색을 선택합니다. 조직화 방식은 width × height가 점군 슬롯 수와 같아야 하며 pixelRadius를 격자 단위로 해석합니다. 반경 방식은 radius를 실제 점군 단위로 사용합니다.

확인 항목해석
이웃중심 외 점을 포함하는 국소 표본
viewpoint법선 방향을 정하는 관측 위치
출력각 슬롯의 단위 방향 또는 결측
실패 조건이웃 부족이나 퇴화한 기하
