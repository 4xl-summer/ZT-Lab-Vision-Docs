위상 계획을 독립 핸들로 복제합니다.

반환: 원본과 별도로 Dispose해야 하는 계획입니다.

사용과 결과 해석

위상 계획을 독립 핸들로 복제합니다. 반환 계획은 원본과 별도로 Dispose해야 합니다.

복제는 계산을 실행하거나 결과를 만들지 않습니다. 원본과 복제 계획을 각각 관리하고 필요한 계획을 Execute하여 위상 결과를 얻으십시오.

위상 계획 복제와 결과

TopologyQuery.Clone은 위상 연산 계획을 독립 쿼리 핸들로 복제합니다. Clone은 골격화나 영역 재구성 계산을 바로 실행하지 않습니다. 결과를 얻으려면 해당 계획의 Execute를 호출하고 실제 반환되는 위상 결과의 종류를 확인해야 합니다.

예를 들어 같은 Gray8 입력과 공통 전처리에서 출발하는 위상 처리 흐름을 비교할 때 원본과 복제 계획을 각각 보관하고 실행 결과를 구분할 수 있습니다. 골격 영상, 반복 수 또는 그래프 자료가 필요하다면 실제 선택한 위상 연산의 결과 계약을 확인하세요. 단순히 복제본이 생겼다는 사실은 계산의 수렴이나 성공을 뜻하지 않습니다.

항목의미와 처리
Clone위상 계획의 독립 핸들
실행 전계산이나 수렴 판정은 수행되지 않음
Execute선택한 위상 계획 실행
결과실제 반환 변형과 상태 확인
계획 수명원본과 복제본 별도 Dispose
영상 수명취득한 영상은 계약에 맞게 별도 관리

수명과 결과 확인

원본 계획과 복제 계획은 각각 Dispose해야 합니다. 실행에서 영상 핸들을 획득했다면 쿼리 계획과 독립적인 그 영상의 소유권도 정리합니다. 입력 ROI 원점과 연결성, 반복 또는 작업 한도를 기록하면 두 실행이 서로 다른 조건 때문에 달라진 경우를 확인할 수 있습니다.
