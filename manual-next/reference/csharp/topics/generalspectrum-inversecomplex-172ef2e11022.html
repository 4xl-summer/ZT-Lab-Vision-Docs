ZVision.ComplexInverse InverseComplex(System.Boolean crop = true)

복소 역변환합니다.

인자

crop: 입력 크기로 자릅니다.

반환: 독립 복소 값입니다.

이 호출의 입력과 객체 맥락

켤레 대칭이 아닌 스펙트럼도 실수부와 허수부를 모두 갖는 복소 역변환으로 읽습니다. crop은 원본 크기로 자를지 선택하며 False일 때는 변환 크기를 사용합니다. 결과의 폭·높이와 각 값 배열을 함께 해석하세요. 값 배열은 영상 소유 핸들이 아니며 스펙트럼 객체는 사용 후 별도로 해제합니다.

복소 역변환과 크기

InverseComplex는 현재 GeneralSpectrum의 복소 계수를 역변환해 실수부와 허수부를 포함한 독립 ComplexInverse 값을 반환합니다. 스펙트럼이 켤레 대칭이 아닌 경우에도 복소 결과를 다루므로 허수부가 항상 0이라고 가정하지 않습니다. 이 결과는 ZImage 소유 핸들과는 다른 관리 값입니다.

crop=true이면 저장된 원본 크기로 자르고 crop=false이면 변환 크기를 사용합니다. 예를 들어 원본이 3×2이고 변환 크기가 4×4라면 crop=true의 폭·높이는 3×2, false의 폭·높이는 4×4입니다. 실제 각 배열의 해석은 반환된 크기와 원본 스펙트럼 메타데이터에 맞춥니다.

입력 계수의 실수부와 허수부는 Parts로 복사해 확인할 수 있습니다. 역변환 후에도 반환된 두 성분을 같은 행 우선 위치끼리 비교하고, 정규화와 crop 선택을 결과와 함께 기록합니다. GeneralSpectrum 자체는 사용 후 Dispose해야 하며 복사된 값과 모델 핸들의 수명은 다릅니다.

항목확인할 내용
crop=true저장된 원본 크기로 자른 결과
crop=false전체 변환 크기의 결과
Real역변환 실수부 값
Imaginary역변환 허수부 값
크기반환 폭·높이와 배열 길이 함께 확인
수명스펙트럼 모델은 별도 Dispose

판독과 확인 사례

crop 선택은 출력의 어떤 크기를 읽을지 바꾸며 주파수 계수의 실수부와 허수부를 없애는 설정이 아닙니다. 메타데이터의 SourceWidth와 SourceHeight, 변환의 Width와 Height를 구분하면 각 경우의 배열 크기를 예상할 수 있습니다. 반환 크기를 확인한 뒤 행 우선 위치를 계산합니다.

예를 들어 폭 4의 결과에서 (x=1,y=2)는 인덱스 2×4+1=9입니다. 같은 인덱스의 실수부와 허수부는 하나의 복소 위치를 구성합니다. 원본 영상과 비교할 때는 선택한 crop, 변환 정규화와 두 성분을 함께 확인합니다.
