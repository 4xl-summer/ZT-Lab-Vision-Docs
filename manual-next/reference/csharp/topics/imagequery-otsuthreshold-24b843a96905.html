OtsuThreshold

Method · 선언 타입 ZVision.ImageQuery

C#
ZVision.OtsuThresholdQuery OtsuThreshold(System.Int32 bins, System.Double lower, System.Double upper)

지정 히스토그램 규격으로 Otsu 임계값 계산을 계획합니다. 실제 처리는 Run에서 수행합니다.

인자

bins: 히스토그램 빈 수.

lower: 히스토그램 범위의 하한.

upper: 히스토그램 범위의 상한.

반환: 원래 빌더를 유지하는 새 종료 Query입니다. 사용 후 해제해야 합니다.

OtsuThreshold의 사용과 결과 해석

자동으로 선택된 Otsu 기준값은 영상 강도의 한 값입니다. 이를 결과 마스크와 혼동하지 말고 사용할 영상 형식과 분포를 함께 확인합니다. 강도를 기준으로 픽셀을 전경과 배경으로 구분합니다. 임계값 자체와 결과 마스크는 다른 값이며, 경계에 걸린 픽셀이 어떻게 분류되는지는 선택한 연산의 비교 규칙을 확인합니다.
