static ZVision.BlobContourHierarchyNode[] Analyze(ZVision.ZImage image, System.Double minArea, System.UInt64 workBudget)

4연결 전경의 원래 고리와 선택 전후 직접 자식을 반환합니다.

인자

image: Gray8 영역 마스크입니다.

minArea: 자식 선택에 사용하는 포함 면적 하한입니다.

workBudget: 윤곽 탐색과 포함 검사의 작업 상한입니다.

반환: 발견 순서의 독립 계층 노드 목록입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

Analyze의 사용과 결과 해석

예를 들어 바깥 윤곽 안에 구멍 윤곽이 있으면 둘은 단순히 크기가 다른 독립 외곽선이라는 의미가 아닙니다. 부모와 자식 관계를 함께 사용해 내부 구조를 해석합니다. 윤곽의 바깥 경계와 내부 구멍의 포함 관계를 분석합니다. 결과의 상하 관계는 점의 순서나 단순한 면적 크기만으로 대체할 수 없으므로 각 윤곽의 계층 정보를 함께 읽습니다.
