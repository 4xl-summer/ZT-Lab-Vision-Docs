이 호출의 입력과 객체 맥락

ExposureFusionResult.Radiance: 독립 소유 방사량 영상을 얻습니다.

ExposureFusionResult.Validity: 독립 소유 유효 마스크를 얻습니다.

결과와 두 출력 영상의 수명

ExposureFusionResult는 서로 정렬된 Gray8 노출 영상들을 결합한 결과를 소유합니다. Create에는 영상 목록과 각 영상에 대응하는 양수 노출 시간이 필요합니다. 결과에서 Radiance를 읽으면 상대 방사량 영상의 독립 소유 핸들을 얻고, Validity를 읽으면 유효 마스크의 독립 소유 핸들을 얻습니다. 두 속성은 동일한 영상 하나의 다른 이름이 아닙니다.

예를 들어 짧은 노출 영상과 긴 노출 영상 두 장을 넣었다면 노출 시간도 같은 순서의 두 값으로 전달합니다. 결과를 얻은 뒤 Radiance와 Validity를 각각 취득하여 유효한 위치의 방사량만 해석할 수 있습니다. 결과 객체의 Dispose는 내부 결과를 해제합니다. 이미 취득한 두 영상 핸들은 각자의 수명을 가지므로 결과와 별도로 사용한 뒤 각각 Dispose해야 합니다.

수명과 결과 확인

유효 마스크를 보지 않고 모든 방사량 픽셀을 유효한 측정값으로 취급하지 마세요. 입력 영상이 정렬되지 않았거나 노출값 순서가 바뀌면 같은 위치의 영상과 노출 조건이 어긋납니다. 결과 해제는 입력 영상을 정렬하거나 노출 조건을 검증하는 연산도 아닙니다. using 범위를 결과와 각 출력 영상에 맞춰 설정하면 예외 발생 시에도 정리 순서를 분명히 할 수 있습니다.
