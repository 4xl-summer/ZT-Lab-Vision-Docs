ArchivedComposite(System.Byte[] data)

보관 바이트를 검증하고 복원합니다.

인자

data: 버전과 체크섬이 올바른 모델입니다.

이 호출의 입력과 객체 맥락

버전과 체크섬이 올바른 복합 계측 아카이브 바이트를 검증해 복원합니다. 보관된 그래프와 단위는 이후 평가의 해석 기준이므로 파일이나 전송 경로와 함께 출처를 기록하세요. 바이트가 존재한다는 사실만으로 해당 모델이 현재 입력 영상에 맞는다는 뜻은 아닙니다.

입력과 결과를 읽는 순서

ArchivedComposite는 버전과 체크섬이 있는 복합 계측 아카이브 byte 배열을 검증해 소유 모델을 복원합니다. data는 null이 아니고 길이는 1~2200000바이트여야 합니다. 잘린 데이터나 유효하지 않은 내용은 생성 실패로 처리하며 빈 모델로 바꾸지 않습니다.

아카이브의 Unit이 null이면 저장된 출력 기준은 픽셀입니다. 복원 후 인자 없는 Evaluate는 고정 모델을 저장 단위로 평가하고, 영상 측정 형상이 있는 모델은 ROI 영상을 받는 평가 경로를 사용합니다. 반환 CompositeResult는 독립 값 스냅샷입니다.

예를 들어 저장 파일을 읽어 ArchivedComposite를 만든 뒤 형상과 공차 결과를 확인했다면, 이미 반환된 스냅샷은 아카이브를 Dispose한 뒤에도 유지됩니다. 아카이브 자체는 소유 핸들이므로 사용 후 Dispose해야 합니다. 저장한 등방 단위를 일반적인 원근·렌즈 세계 보정으로 오해하지 마세요.

예를 들어 보관 바이트를 파일에서 읽었다면 파일을 읽은 성공과 모델의 버전·체크섬 검증 성공은 별개입니다. 생성이 성공한 뒤 Unit을 확인하고 저장된 모델이 영상 측정 형상을 포함하는지에 따라 올바른 Evaluate 오버로드를 선택하세요. 반환 형상·공차 결과를 별도로 보관한 뒤 아카이브 핸들을 Dispose할 수 있습니다. 각 공차 상태와 측정값은 원래 모델의 공차 식별자에 연결하여 확인합니다.
