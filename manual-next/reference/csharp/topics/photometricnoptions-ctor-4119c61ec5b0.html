PhotometricNOptions(System.Double minSignal, System.Double minRcond, System.Double spacingX, System.Double spacingY, System.Double minNormalZ, System.UInt64 smoothRadius, System.Double brightness, System.Double contrast, System.UInt64 maxWork)

다조명 계산 및 출력 설정을 만듭니다.

인자

minSignal: 최소 반사 신호입니다.

minRcond: 0 이상 1 미만의 역조건수 하한입니다.

spacingX: X 간격입니다.

spacingY: Y 간격입니다.

minNormalZ: 0 이상 1 미만의 법선 z 하한입니다.

smoothRadius: 평활 반경입니다.

brightness: 0~1 밝기입니다.

contrast: 0 이상의 대비입니다.

maxWork: 작업량 상한입니다.

설정과 사용 흐름

다조명 계산의 최소 신호와 조건수 기준, X/Y 간격, 최소 법선 Z, 평활과 출력 밝기·대비, 작업량을 지정합니다. minRcond와 minNormalZ는 0 이상 1 미만입니다.

spacingX와 spacingY는 각 축에서 인접 표본의 간격이므로 같은 단위로 지정하십시오. 밝기는 0~1, 대비는 0 이상이며 너무 작은 신호는 유효 표면으로 취급하지 않도록 기준을 정합니다.
