SkeletonGraphOptions()

단위 간격 기본 옵션을 만듭니다.

사용과 결과 해석

스켈레톤 그래프 계산의 기본 설정을 만듭니다. X와 Y 픽셀 간격은 각각 1이고 작업 예산은 100000000입니다.

실제 픽셀의 X/Y 간격이 다르면 각 축을 그 물리 간격으로 설정해야 길이가 올바른 단위로 계산됩니다. 예를 들어 가로 간격 2, 세로 간격 1인 영상은 단위 간격과 결과가 다릅니다.

단위 간격의 기본 설정

SkeletonGraphOptions()는 SpacingX=1, SpacingY=1, WorkBudget=100000000인 설정을 만듭니다. X와 Y는 양의 픽셀 간격이며 그래프 간선의 길이를 계산할 때 각 축 이동이 나타내는 단위를 정합니다.

예를 들어 가로 간격이 2, 세로 간격이 1인 영상에서 가로 한 칸과 세로 한 칸을 이동하면 길이의 합은 3입니다. 기본 간격 1, 1을 그대로 쓰면 같은 두 이동의 합은 2가 됩니다. 실제 축 간격이 다르면 기본값의 숫자를 물리 길이로 바로 읽지 않습니다.

가로 한 칸SpacingX의 길이

결과노드와 간선의 그래프

골격 마스크를 준비하고 해당 그래프 연산에 옵션을 전달한 다음 노드와 간선의 연결 및 길이를 확인합니다. WorkBudget은 계산 상한으로 간격과 다른 역할입니다. 입력 단위와 옵션을 기록하고 보정의 실제 정확도는 별도로 검증합니다.
