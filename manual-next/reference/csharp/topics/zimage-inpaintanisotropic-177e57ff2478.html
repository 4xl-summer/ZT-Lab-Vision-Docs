System.ValueTuple<ZVision.ZImage, ZVision.InpaintReport> InpaintAnisotropic(ZVision.ZImage mask, ZVision.InpaintOptions options)

마스크의 비영 위치를 비등방 확산으로 복원합니다.

인자

mask: 입력과 크기·원점이 같은 결손 마스크입니다.

options: 반복·전도·초기화 설정입니다.

반환: 호출자가 Dispose할 GrayF64 영상과 진단입니다.

관련 입력의 확인된 조건

options.Iterations: 양의 최대 반복 수입니다.

options.Timestep: 0 초과 0.25 이하 시간 간격입니다.

options.Kappa: 양의 밝기 차이 척도입니다.

options.Tolerance: 비음수 변화량 정지 기준입니다.

options.Initialization: 결손 픽셀 초기화 방식입니다.

이 호출의 입력과 객체 맥락

InpaintReport.MaxChange: 마지막 최대 밝기 변화량입니다.

InpaintReport.Converged: 변화량 기준에 도달했는지 나타냅니다.

InpaintReport.Stalled: 전도 억제로 차단된 밝기 차이가 남았는지 나타냅니다.

인자별 입력 조건

인자형식역할과 조건
maskZVision.ZImage입력과 크기·원점이 같은 결손 마스크입니다.
optionsZVision.InpaintOptions반복·전도·초기화 설정입니다.

비등방성 영역 복원

마스크에서 0이 아닌 영역을 반복 확산해 새 영상을 만듭니다. 반복 횟수, 시간 간격, 전도도 및 수렴 기준은 복원 상태에 영향을 주며 설정 범위를 확인해야 합니다.

변화 보고서의 반복 수, 최대 변화, 수렴 및 정체 상태를 확인합니다. 반복이 끝났다는 사실만으로 원본 결함의 실제 값을 복원했다고 가정하지 않으며 반환 영상은 사용 후 Dispose합니다.
