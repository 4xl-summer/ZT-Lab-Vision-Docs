Execute

Method · 선언 타입 ZVision.CaliperQuery

C#
ZVision.QueryExecution<ZVision.CaliperResult> Execute()

계획을 실행해 프로파일의 서브픽셀 에지와 부호 있는 강도 스냅샷을 만듭니다.

반환: 호출자가 해제할 실행입니다.

사용과 결과 판독

계획된 캘리퍼를 실행해 서브픽셀 위치와 부호 있는 강도를 가진 에지 스냅샷을 얻습니다. 실행 객체는 사용 후 해제해야 합니다. 에지 목록이 비어 있는 경우와 실행 오류를 구별하고, 극성은 선분의 진행 방향에 따라 읽으십시오. 예를 들어 같은 프로파일의 에지 거리가 2와 7이면 간격은 5픽셀입니다.

단계별 확인

Execute는 캘리퍼 지연 계획을 실제 영상에 적용하여 실행 객체와 독립 에지 스냅샷을 제공합니다. 반환된 실행은 사용을 마친 뒤 Dispose해야 하며 계획과 실행은 같은 소유 객체가 아닙니다.

에지마다 ROI 로컬 위치, 프로파일 시작점에서의 거리와 부호 있는 강도를 읽으십시오. 같은 선분에서 거리 2와 7인 두 에지는 간격 5픽셀입니다. 빈 에지 목록과 실행 실패를 구별하고 선분 진행 방향과 극성도 함께 남깁니다.

항목확인할 내용
계획선분과 에지 선택 조건을 준비합니다.
실행지연 계획을 실제 영상에 적용합니다.
위치에지의 ROI 로컬 픽셀 위치입니다.
거리와 강도진행 거리와 부호 있는 기울기를 구분합니다.
빈 목록조건에 맞는 에지가 없을 수 있습니다.
수명호출자가 실행 객체를 Dispose합니다.

서브픽셀 위치는 인접 표본에서 계산된 경계 위치입니다. 표시된 소수 자릿수를 카메라의 실제 절대 정확도로 해석하지 말고, 동일 프레임에서 선택된 극성과 기울기 강도를 확인하십시오. 필요한 스냅샷을 얻은 뒤 실행 객체와 계획 객체의 소유권을 각각 관리합니다.
