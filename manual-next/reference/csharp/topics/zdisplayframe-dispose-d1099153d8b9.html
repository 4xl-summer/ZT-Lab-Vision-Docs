void Dispose()

이 프레임의 영상 공유 핸들을 해제합니다.

수명과 사용 순서

표시 프레임이 소유한 영상 핸들을 해제합니다. 공유 프레임이나 별도 획득한 영상이 있다면 각각의 수명과 해제를 독립적으로 관리하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

공유 프레임과 표시 데이터

ZDisplayFrame은 입력 ZImage를 공유해 표시용 프레임 핸들을 소유합니다. 생성 시 양의 FrameId와 RecipeVersion, 크기·픽셀 형식 및 불변 Overlays를 보관합니다. Dispose는 이 프레임이 가진 영상 공유 핸들을 해제하고 IsDisposed 상태로 전환합니다.

AcquireImage는 별도 소유 영상 공유를 반환하고 Share는 독립 공유 프레임을 반환합니다. 예를 들어 원본 프레임에서 공유 프레임을 얻었다면 원본을 Dispose하더라도 공유 프레임은 자신의 핸들을 관리합니다. 획득한 영상과 공유 프레임도 각각 사용 후 Dispose해야 합니다.

CreateRaster는 열린 프레임에서 관리 메모리의 표시 스냅샷을 복사합니다. 표시 래스터와 원본 영상 핸들의 역할을 구분하고, 래스터화가 필요한 경우 프레임을 닫기 전에 수행합니다. 닫힌 프레임의 AcquireImage는 ObjectDisposedException이며 Dispose는 현재 보유 핸들을 정리하는 작업입니다.

판독과 확인 사례

생성자는 호출자가 소유한 입력을 Share해 자기 프레임의 독립 핸들을 갖습니다. 프레임의 Dispose가 호출자의 원래 ZImage 핸들 자체를 대신 닫는 것으로 생각하지 말고, 호출자와 프레임의 소유권을 각각 관리합니다. FrameId와 RecipeVersion은 프레임과 레시피의 양의 세대 식별자입니다.

AcquireImage와 Share는 프레임이 열린 동안 사용할 수 있고, 닫힌 프레임에서 이미지 취득은 ObjectDisposedException입니다. CreateRaster로 복사한 관리 메모리 래스터는 표시 픽셀과 원본 채널 스냅샷을 담습니다. 원본 표시 핸들과 래스터의 역할을 구분해 이후 사용합니다.
