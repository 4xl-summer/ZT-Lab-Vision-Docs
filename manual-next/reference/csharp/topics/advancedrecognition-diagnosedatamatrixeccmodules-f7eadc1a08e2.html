static ZVision.DataMatrixEccDiagnostics DiagnoseDataMatrixEccModules(ZVision.ZImage image, System.UInt64 maxCorrectedPerBlock)

표본 Data Matrix ECC200 모듈의 실제 RS 정정량을 계산합니다.

인자

image: quiet zone 없이 모듈당 Gray8 0 또는 255 픽셀 하나인 정방향 영상입니다.

maxCorrectedPerBlock: 블록당 정정량 사후 승인 상한입니다.

반환: 확률이나 ISO 등급이 아닌 실제 코드워드 정정 진단입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

DataMatrixEccDiagnostics.Version: Data Matrix 버전 번호입니다.

DataMatrixEccDiagnostics.Blocks: 각 RS 블록의 정정 결과입니다.

DataMatrixEccDiagnostics.CorrectedCodewords: 실제로 수정된 전체 코드워드 수입니다.

DataMatrixEccDiagnostics.Accepted: 각 블록의 정정량이 상한을 통과했는지 나타냅니다.

인자별 입력 조건

인자형식역할과 조건
imageZVision.ZImagequiet zone 없이 모듈당 Gray8 0 또는 255 픽셀 하나인 정방향 영상입니다.
maxCorrectedPerBlockSystem.UInt64블록당 정정량 사후 승인 상한입니다.

Data Matrix 모듈 진단

quiet zone 없이 모듈당 Gray8 0 또는 255 픽셀 하나인 정방향 격자를 입력으로 받습니다. 블록별 실제 RS 정정 코드워드를 계산합니다.

maxCorrectedPerBlock은 정정 후 승인 상한입니다. 결과를 읽을 때 블록별 정정량과 Accepted를 함께 확인하며 코드워드를 손상 픽셀 수나 ISO 등급으로 취급하지 않습니다.
