static ZVision.GapFocusStackResult Create(ZVision.ZImage[] images)

정렬된 Gray8 영상의 국소 라플라시안 에너지로 선명도를 선택합니다.

인자

images: 같은 크기와 원점의 Gray8 영상 2개 이상 256개 이하입니다.

반환: 해제할 독립 결과입니다.

이 호출의 입력과 객체 맥락

같은 크기·원점의 정렬된 Gray8 영상 2~256개에서 국소 라플라시안 에너지에 따라 선명한 입력을 선택합니다. 결합 영상뿐 아니라 프레임 선택 지도도 확인하면 위치마다 어떤 입력이 사용됐는지 알 수 있습니다. 반환 결과와 취득한 영상은 각각 Dispose합니다.

초점 스택 합성

Create는 크기와 원점이 같은 정렬된 Gray8 영상 2개부터 256개까지 받아 국소 라플라시안 에너지로 선명한 위치를 선택합니다. 같은 장면의 대응 위치가 맞아야 하며 영상 순서와 입력 기하를 함께 기록합니다.

위치가 어긋난 영상끼리 같은 픽셀을 비교하면 움직인 경계가 초점 차이처럼 나타날 수 있습니다. 서로 다른 초점 위치의 영상을 준비한 뒤 입력 배열로 전달하고 결과 영상과 선택 정보를 해당 입력 순서와 연결해 확인합니다.

반환 객체는 소유 자원이므로 사용 후 Dispose합니다. 결과에서 따로 획득하는 영상은 그 반환 계약에 따라 별도 해제합니다. 합성 결과만 보고 실제 깊이 단위나 각 픽셀의 물리 거리를 자동으로 추정하지 않습니다.

구현은 동일 크기와 원점의 Gray8 입력을 2개 이상 256개 이하로 받습니다. 입력 배열에 null이 있거나 개수가 범위 밖이면 정상 합성 대신 예외입니다. 처리 중 입력의 독립 공유를 얻고 임시 공유는 작업 후 정리합니다.

국소 라플라시안 에너지가 큰 입력을 선택하므로 질감이 약한 영역과 강한 에지가 있는 영역을 따로 살펴봅니다. 선택된 인덱스가 입력 배열의 어떤 촬영에 해당하는지 순서를 유지해야 원인을 추적할 수 있습니다.

결과 영상은 초점이 다른 입력에서 선택된 정보를 결합합니다. 각 입력의 화소 위치가 어긋나 있다면 선명한 화소를 고르는 과정에서도 서로 다른 장면의 경계를 섞을 수 있으므로 정렬 후 결과를 살펴야 합니다.

반환 영상의 위치별 값과 선택 정보를 비교하고 원래 입력 순서를 기록합니다. 이 합성은 깊이 맵의 물리 단위를 자동으로 제공하는 과정이 아닙니다.
