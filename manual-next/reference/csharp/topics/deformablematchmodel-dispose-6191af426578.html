사용을 마치는 순서

학습된 변형 모델 은행을 해제합니다. Find의 결과에서 변형 인덱스와 포즈를 필요한 곳에 보관한 뒤 더 이상 검색하지 않을 때 호출합니다. 인덱스를 해석하는 데 쓰는 학습 변형 목록도 별도로 보관합니다.

사용 순서

호출역할

Dispose변형 모델 은행 정리

변형 은행과 후보 값

학습 시 제공한 각 TemplateDeformation은 모델 은행의 한 변형을 정의합니다. Find는 명시적으로 학습한 변형들을 검색하며 결과의 변형 인덱스를 입력 순서와 연결합니다. 인덱스는 추정된 픽셀 변위 자체가 아닙니다.

예를 들어 입력 변형 목록이 [A,B,C]라면 인덱스 1은 B를 가리킵니다. 모델을 정리하기 전에 필요한 검색을 마치고 입력 변형 목록과 결과의 포즈·점수를 함께 기록합니다. Dispose는 이후 사용할 학습 모델 자원을 해제하는 단계입니다.
