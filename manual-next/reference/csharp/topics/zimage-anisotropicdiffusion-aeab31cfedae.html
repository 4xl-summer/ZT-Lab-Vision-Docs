AnisotropicDiffusion

Method · 선언 타입 ZVision.ZImage

C#
ZVision.ZImage AnisotropicDiffusion(System.UInt64 iterations, System.Double kappa, System.Double timestep, out ZVision.DiffusionReport report, System.Double tolerance = 0, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, System.Double constant = 0, ZVision.PixelFormat outputFormat = ZVision.PixelFormat.GrayF32, ZVision.EdgeConductance conductance = ZVision.EdgeConductance.Exponential)

4방향 Perona–Malik 확산과 종료 진단을 반환합니다.

인자

iterations: 최대 양의 반복 횟수입니다.

kappa: 양의 밝기 차이 척도입니다.

timestep: 0보다 크고 0.25 이하인 시간 간격입니다.

report: 독립 반복 진단입니다.

tolerance: 반복 종료 최대 변화입니다.

border: 영상 경계입니다.

constant: 상수 경계 값입니다.

outputFormat: 결과 회색 형식입니다.

conductance: 전도 함수입니다.

반환: 독립 소유 영상입니다.

관련 입력의 확인된 조건

report.Iterations: 실제로 수행한 반복 횟수입니다.

report.MaxChange: 마지막 반복의 최대 밝기 변화입니다.

report.Converged: 최대 변화가 허용 오차 이하인지 여부입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
iterationsSystem.UInt64최대 양의 반복 횟수입니다.
kappaSystem.Double양의 밝기 차이 척도입니다.
timestepSystem.Double0보다 크고 0.25 이하인 시간 간격입니다.
reportZVision.DiffusionReport독립 반복 진단입니다.
toleranceSystem.Double반복 종료 최대 변화입니다.

constantSystem.Double상수 경계 값입니다.
outputFormatZVision.PixelFormat결과 회색 형식입니다.
conductanceZVision.EdgeConductance전도 함수입니다.

report의 입력 값

필드의미와 조건

결과와 사용 순서

독립 소유 영상입니다.

입력과 결과 해석

밝기 경계를 고려하는 4방향 확산을 수행합니다. 반복 및 확산 조건에 따라 평활 정도가 달라지므로 반환 영상과 종료 진단을 함께 확인하세요. 과도한 평활은 작은 무늬를 약화할 수 있습니다.
