static ZVision.AdvancedMatchReport FindImagePyramid(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, System.UInt64 firstLevel, System.UInt64 lastLevel = 0)

Searches actual reduced source image and shape-feature levels.

인자

source: Source image.

model: Shape model.

options: Search options; do not mutate during the call.

firstLevel: Coarsest source and model level, 0..10.

lastLevel: Finest level, no greater than first level.

반환: Detached matches and search termination.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

축소된 영상과 축소된 형상 특징을 사용하는 피라미드 수준을 지정해 검색합니다. firstLevel과 lastLevel은 검색할 축소 수준을 정하며 lastLevel의 명시된 기본값은 0입니다. 단순히 원본 영상에서 위치 간격만 넓히는 설정과 구별해야 합니다.

큰 축소 수준에서는 작은 형상 세부가 약해질 수 있으므로 같은 입력과 검색 조건에서 수준을 바꾸어 후보와 종료 진단을 비교합니다. 매치가 기대와 다르면 모델의 특징, 선택한 수준 범위 및 검색 격자를 함께 확인하는 것이 유용합니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
sourceSource image.
modelShape model.
optionsSearch options; do not mutate during the call.
firstLevelCoarsest source and model level, 0..10.
lastLevelFinest level, no greater than first level.
