void Dispose()

모델 핸들을 해제합니다.

이 호출의 입력과 객체 맥락

GapStationaryHaar.Coefficients: 최종 LL 다음 각 단계 HL/LH/HH의 행 우선 계수를 복사합니다.

GapStationaryHaar.WithCoefficients: 외부 계수 스냅샷으로 독립 모델을 만듭니다.

GapStationaryHaar.Shrunk: 최종 LL을 보존하며 모든 세부 대역을 축소합니다.

GapStationaryHaar.Inverse: 원래 ROI 원점의 GrayF64 영상을 합성합니다.

GapStationaryHaar.Metadata: 밴드 크기를 반환합니다.

모델, 계수와 재구성 영상

GapStationaryHaar는 Gray8, Gray16 또는 GrayF32 영상에서 만든 비감쇠 Haar 변환 모델을 소유합니다. Forward 또는 ForwardCentered의 반환 모델은 사용 후 Dispose합니다. Metadata는 밴드의 너비, 높이와 개수이고 Coefficients는 최종 LL 다음 각 단계 HL·LH·HH 순서의 행 우선 계수를 독립 double 배열로 복사합니다.

예를 들어 Metadata의 너비가 4, 높이가 3, 밴드 수가 4라면 계수 배열은 4×3×4=48개입니다. 배열 자체는 관리되는 숫자 복사본이므로 원본 모델을 해제해도 보유한 배열을 읽을 수 있습니다. 배열을 수정해도 모델을 제자리에서 바꾸지 않으며, 수정된 계수로 모델을 만들려면 정확한 길이의 유한 값을 WithCoefficients에 전달해야 합니다.

Dispose이 모델 핸들을 해제

수명과 결과 확인

Inverse가 반환하는 GrayF64 영상은 원래 ROI 원점의 독립 소유 결과입니다. Shrunk와 WithCoefficients도 별도의 모델을 반환하므로 원래 모델의 Dispose가 이들을 대신 정리한다고 가정하지 마세요. 필요한 모델과 영상을 각자의 사용 범위에서 해제하고, 사용이 끝난 원래 모델에 Metadata나 Inverse를 다시 호출하지 않습니다.
