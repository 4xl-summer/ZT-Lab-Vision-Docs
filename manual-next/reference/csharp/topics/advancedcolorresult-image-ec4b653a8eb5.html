ZVision.ZImage Image(System.Int32 index)

평면 또는 매칭 이미지를 독립 소유 영상으로 가져옵니다.

인자

index: 색 평면은 0~2, 매칭은 0 샘플 인덱스 또는 1 거리입니다.

반환: 호출자가 해제할 GrayF64 영상입니다.

관련 입력의 확인된 조건

ZImage.Origin: ROI의 글로벌 픽셀 원점입니다.

ZImage.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

인자별 입력 조건

인자형식역할과 조건
indexSystem.Int32색 평면은 0~2, 매칭은 0 샘플 인덱스 또는 1 거리입니다.

색 평면 또는 매칭 영상

색 평면 결과에서 인덱스 0부터 2까지, 매칭 결과에서 0은 샘플 인덱스와 1은 거리 영상을 독립 소유 GrayF64로 가져옵니다. 반환 영상은 호출자가 Dispose합니다.

결과 종류에 따라 유효한 인덱스 범위가 다릅니다. 잘못된 인덱스는 ArgumentOutOfRangeException이고 닫힌 결과는 ObjectDisposedException입니다. 매칭 거리와 색 채널을 같은 의미로 읽지 않습니다.
