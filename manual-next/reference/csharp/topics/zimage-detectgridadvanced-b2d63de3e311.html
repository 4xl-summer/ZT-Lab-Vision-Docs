DetectGridAdvanced

Method · 선언 타입 ZVision.ZImage

C#
ZVision.AdvancedGridPoint[] DetectGridAdvanced(ZVision.AdvancedGridSpec spec, System.Nullable<ZVision.AdvancedGridHint> hint = null)

격자 후보를 자동 추론하거나 제공한 기준으로 부분 격자에 대응합니다.

인자

spec: 격자 형식과 검출 설정입니다.

hint: 기준점과 격자 방향이며 null이면 자동 추론합니다.

반환: 검출한 격자점입니다.

관련 입력의 확인된 조건

spec.Kind: 체커보드는 1, 어두운 원점은 2입니다.

spec.SampleRadius: 대비 표본 반경입니다.

spec.SuppressionRadius: 후보 간 억제 거리입니다.

spec.MatchTolerance: 격자 예상 위치의 허용 거리입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
specZVision.AdvancedGridSpec격자 형식과 검출 설정입니다.
hintSystem.Nullable<ZVision.AdvancedGridHint>기준점과 격자 방향이며 null이면 자동 추론합니다.

spec의 입력 값

필드의미와 조건
kind타깃 종류: 체커보드 1, 어두운 점 2.
rows격자의 예상 행 수; 양수.
columns격자의 예상 열 수; 양수.
sample_radius대비 표본 반경; 양의 픽셀 수.
min_contrast유한한 양의 최소 강도 대비.

hint의 입력 값

필드의미와 조건
row기준 격자 행 인덱스.
column기준 격자 열 인덱스.
position기준 위치의 픽셀 Point2.
column_step열 한 칸에 해당하는 픽셀 변위.
row_step행 한 칸에 해당하는 픽셀 변위.

결과와 사용 순서

검출한 격자점입니다.

반환 값의 읽을 항목

항목의미
row격자 행 인덱스.
column격자 열 인덱스.
pixel탐지된 픽셀 Point2.
score해당 후보의 대비 점수.

입력과 결과 해석

검출 후보를 격자점에 대응합니다. 위치 힌트의 사용 여부와 원근 모델의 입력 조건을 확인하고 결과의 행·열 대응을 영상의 실제 점과 대조하세요. 일부 점만 보이는 경우에도 결과 상태를 확인해야 합니다.
