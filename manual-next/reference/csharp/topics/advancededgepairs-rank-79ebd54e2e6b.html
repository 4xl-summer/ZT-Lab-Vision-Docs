Rank

Method · 선언 타입 ZVision.AdvancedEdgePairs

C#
static ZVision.AdvancedEdgePair[] Rank(ZVision.CaliperEdge[] edges, ZVision.AdvancedPairOptions options)

에지 극성, 기대 위치와 폭으로 쌍을 점수순 정렬합니다.

인자

edges: 입력 에지입니다.

options: 극성과 순위 설정입니다.

반환: 선택한 에지 쌍입니다.

관련 입력의 확인된 조건

options.SecondPolarity: 두 번째 에지 극성입니다.

options.Score: 강도 합 0 또는 최솟값 1입니다.

options.MaxResults: 최대 쌍 결과 수입니다.

사용과 결과 판독

진행 방향의 첫째와 둘째 에지 극성 및 예상 위치와 폭으로 후보 쌍을 순위화합니다. 같은 프로파일에서 거리 2와 7이면 폭은 5픽셀입니다. 첫째와 둘째는 화면 좌우가 아니라 탐색 진행 방향을 기준으로 읽습니다.

항목확인된 역할
edges입력 에지입니다.
options극성과 순위 설정입니다.
반환선택한 에지 쌍입니다.

두 에지의 점수만으로 실제 위치를 알 수 없으므로 선택된 첫째·둘째 거리와 극성도 함께 보십시오. 진행 방향이 반대라면 같은 물리 경계의 첫째와 둘째가 달라질 수 있어 선분의 시작과 끝을 기록해야 합니다.
