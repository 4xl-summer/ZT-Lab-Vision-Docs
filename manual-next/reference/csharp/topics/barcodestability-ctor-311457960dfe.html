기본 안정성 결과를 만듭니다.

사용과 결과 판독

안정성 결과의 기본 값을 생성합니다. 이 생성은 실제 프레임 집합에 대한 안정성 평가를 실행하지 않습니다. 측정된 결과와 비교할 때 각 필드가 어느 실행에서 얻어졌는지 확인하십시오.

기본 구조체의 존재는 실제 판독 여러 번의 결과가 수집되었다는 뜻이 아닙니다. 안정성 지표를 해석할 때 해당 결과를 채운 호출, 입력 프레임과 각 판독 상태를 확인하십시오.

사용 순서와 결과 확인

BarcodeStability의 기본 생성자는 안정성 결과 객체의 기본 상태를 만듭니다. 이 호출 자체가 바코드를 읽거나 밝기 변화 시도를 실행하는 것은 아닙니다. 따라서 객체가 만들어졌다는 사실을 실측 안정성 점수를 얻었다는 뜻으로 판정하지 마십시오.

Score는 기본 판독과 일치한 시도의 비율이며 확률 예측값이 아닙니다. 실제 평가에서 다섯 시도 중 네 번이 기본 판독과 일치했다면 일치 비율을 4/5=0.8로 해석할 수 있습니다. 이 숫자는 그 시도 집합에 대한 관측이며 다른 환경의 성공 확률을 보장하지 않습니다.

Matches는 각 밝기 변화 시도의 일치 여부를 담고 getter는 배열을 복사합니다. 기본 생성 상태의 배열은 비어 있으며 Text는 빈 문자열입니다. 기본 판독 상태와 형식, 텍스트도 함께 읽어 어떤 내용을 기준으로 일치를 계산했는지 확인하십시오.

BaselineFormat은 판독 형식을 찾지 못한 경우 null일 수 있습니다. 실제 결과를 보고할 때에는 기본 판독이 어떤 상태였는지와 수행된 시도 수를 함께 보관해야 빈 목록, 미실행 및 불일치 사례를 구별할 수 있습니다.

단계 또는 항목확인할 내용
생성기본 결과 객체를 만들며 판독을 실행하지 않습니다.
Score기본 판독과 일치한 시도의 비율입니다.
Matches시도별 일치 배열이며 읽을 때 복사됩니다.
BaselineStatus기본 판독 상태입니다.
BaselineFormat기본 형식이며 찾지 못하면 null일 수 있습니다.
Text기본 판독 문자열이며 초기값은 빈 문자열입니다.

실측 안정성을 기록할 때는 기준 판독과 비교한 각 시도의 결과를 입력 조건과 함께 묶어야 합니다. 시도가 모두 같아 Matches가 전부 true인 경우와 시도가 없어 배열이 빈 경우는 다릅니다. 전자는 실제 비교 결과이고 후자는 이 객체에 비교 항목이 없다는 뜻입니다. 값이 나중에 채워진 결과를 다룰 때는 기본 상태·형식과 텍스트가 어떤 판독을 가리키는지 확인하십시오.
