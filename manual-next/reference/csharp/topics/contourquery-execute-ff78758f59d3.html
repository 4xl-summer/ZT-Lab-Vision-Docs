계획을 실행하고 셀 경계 결과를 독립 스냅샷으로 복사합니다.

반환: Dispose해야 하는 실행입니다. Output으로 얻은 스냅샷은 실행 해제 후에도 유효합니다.

Execute의 사용과 결과 해석

선택된 윤곽 계획을 실행해 결과를 얻습니다. 반환 결과가 비어 있는 경우와 호출 오류는 다르므로 결과 상태와 사용한 조건을 함께 확인합니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.

셀 경계 실행과 결과 보존

ContourQuery.Execute는 셀 경계 윤곽 계획을 실행하고 QueryExecution<ContourResult>를 반환합니다. 실행 객체는 Dispose해야 합니다. Output으로 꺼낸 ContourResult는 독립 스냅샷으로 복사되므로 이미 얻은 스냅샷은 실행을 해제한 뒤에도 사용할 수 있습니다.

예를 들어 이진 영역의 윤곽을 계획한 뒤 Execute, Output 순으로 읽으면 해당 실행의 경계 목록을 얻습니다. 경계가 하나도 없는 유효한 입력과 실행 오류는 다릅니다. 빈 목록을 읽었다면 사용한 전경 마스크와 ROI를 확인하고, 오류가 발생했다면 실패한 호출과 설정을 별도로 기록하세요.

실행과 판독에서 확인

실행이 열린 동안 GetImage로 중간 캡처를 취득할 수 있으며 그 영상은 독립 소유 핸들로 별도 Dispose해야 합니다. 실행을 닫기 전에 필요한 Output과 캡처를 가져오고, 계획도 실행 객체와 따로 정리합니다. 셀 경계 좌표를 전체 영상에 표시할 때는 결과의 ROI 기준을 함께 확인해야 합니다.
