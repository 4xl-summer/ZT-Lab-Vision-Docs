ZVision.Point2 Transform(ZVision.Point2 point)

점에 변환을 적용합니다.

인자

point: 변환 또는 측정할 점입니다.

반환: 계산된 결과입니다.

관련 입력의 확인된 조건

point.X: 영역의 로컬 x 좌표입니다.

point.Y: 영역의 로컬 y 좌표입니다.

이 호출의 입력과 객체 맥락

이 호출은 Point2 한 점에 저장된 2×3 계수를 적용합니다. 계산은 x′ = a×x + b×y + tx, y′ = c×x + d×y + ty입니다. 예를 들어 선형 부분이 단위 행렬이고 이동이 (3, 4)이면 입력 (10, 20)은 (13, 24)로 갑니다. 반환값은 새로운 Point2 값이며 이미지 픽셀 배열을 바꾸는 워프가 아닙니다. 입력 점과 계수는 연산에 전달할 때 유한해야 하며, ROI 로컬 픽셀인지 전체 프레임 좌표인지와 같은 기준을 호출자가 맞춰야 합니다.

이 객체의 확인된 공개 생성 경로: Affine2(System.Double a, System.Double b, System.Double tx, System.Double c, System.Double d, System.Double ty).
