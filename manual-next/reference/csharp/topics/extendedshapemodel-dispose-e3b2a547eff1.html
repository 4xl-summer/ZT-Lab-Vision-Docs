사용을 마치는 순서

확장 형상 모델의 내부 모델 자원을 해제합니다. Find, Features, Diagnose 또는 직렬화 등 이 모델을 필요로 하는 작업을 먼저 마칩니다. 나중에 같은 학습 모델을 다시 사용해야 한다면 해제 전에 ToBytes로 자료를 저장하고 FromBytes로 별도 복원할 수 있습니다.

사용 순서

호출역할
Train / FromBytes학습 또는 바이트에서 모델 준비
Find / ToBytes검색 또는 학습 모델 저장
Dispose모델 사용이 끝나면 정리

특징과 저장의 순서

확장 형상 모델은 기준점 상대 위치와 방향을 가진 에지 특징을 보유합니다. 필요한 Find, Features와 Diagnose 호출은 모델이 유효할 때 수행합니다. 검색 영상과 모델의 수명은 각각 관리하며, 모델 해제가 영상을 저장하는 단계는 아닙니다.

이 모델을 나중에 복원하려면 Dispose 전에 ToBytes로 아카이브를 얻고, 이후 FromBytes로 별도 모델을 만듭니다. 검색을 재현하려면 모델 바이트뿐 아니라 영상과 ShapeSearchOptions도 따로 보관해야 합니다. 복원 모델도 사용을 마친 뒤 Dispose합니다.
