모델 핸들을 해제합니다.

사용을 마치는 순서

Harris 특징과 기술자를 보유한 모델을 해제합니다. Find 및 Points, Descriptors 조회를 마친 뒤 호출합니다. 모델을 이후에 재사용하려면 해제 전 ToBytes로 모델 바이트를 보관하고, 검색 영상과 검색 옵션은 별도로 관리합니다.

사용 순서

호출역할
Train / FromBytes특징 모델 학습 또는 복원
Find / ToBytes기하 검증 또는 모델 저장
Dispose모델 자원 정리

학습 특징과 저장 경로

FeatureModel은 Harris 특징과 정규화된 패치 기술자를 학습해 검색 영상과 대응시킵니다. 필요한 Points·Descriptors 조회와 Find가 끝나면 Dispose합니다. 검색 결과의 대응점과 학습 모델의 특징 목록은 서로 다른 값이므로 구분해 기록합니다.

나중에 모델을 다시 사용하려면 해제 전에 ToBytes로 바이트를 얻고 FromBytes로 복원할 수 있습니다. 복원한 모델도 별도 소유 객체입니다. 영상 및 FeatureSearchOptions는 모델 바이트와 별도로 준비해야 동일한 검색 조건을 재현할 수 있습니다.

Descriptors학습 특징 순서의 정규화 기술자
ToBytes / FromBytes모델 저장과 별도 복원
