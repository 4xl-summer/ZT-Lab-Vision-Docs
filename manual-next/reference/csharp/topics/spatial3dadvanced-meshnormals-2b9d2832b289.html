MeshNormals

Method · 선언 타입 ZVision.Spatial3dAdvanced

C#
static System.Nullable<ZVision.Point3>[] MeshNormals(ZVision.PointCloud cloud, System.UInt64[] faces)

삼각형 인덱스와 winding으로 면적 가중 정점 법선을 계산합니다.

인자

cloud: 입력 점군입니다.

faces: 행 우선 삼각형 인덱스 배열입니다.

반환: 정점별 법선입니다.

관련 입력의 확인된 조건

cloud.Info: 격자 또는 점군의 메타데이터를 가져옵니다.

삼각형 메시의 법선

점군의 삼각형 인덱스를 이용해 면 법선을 계산하고 꼭짓점에 면적 가중 기여를 합칩니다. 삼각형의 세 인덱스는 유효 범위의 서로 다른 위치여야 합니다. 꼭짓점이 결측이거나 삼각형이 퇴화하면 해당 면에서 유효한 기여를 만들지 못합니다.

(0,0,0), (1,0,0), (0,1,0)을 이 순서로 연결하면 외적 방향은 +z입니다. 두 꼭짓점의 순서를 바꾸면 방향은 -z가 되므로 메시의 감김 순서를 일관되게 유지해야 합니다. 여러 면의 기여가 합쳐진 꼭짓점 결과는 원본 점 슬롯과 대응합니다.

확인 항목해석
triangle indices서로 다르고 범위 안인 세 인덱스
winding면 법선의 부호를 결정
가중치면적에 비례하는 면 기여
결측·퇴화유효 면 법선 기여 없음
