FindEdgeGrain

Method · 선언 타입 ZVision.ExtendedShapeModel

C#
ZVision.ExtendedMatchResult FindEdgeGrain(ZVision.ZImage source, ZVision.ShapeSearchOptions options, System.UInt64 minSize, System.UInt64 maxSize, ZVision.ZImage mask = null)

에지 연결 성분의 크기 범위를 적용해 형상을 검색합니다.

인자

source: 검색 영상입니다.

options: 검색 설정입니다.

minSize: 허용할 최소 에지 연결 성분 크기입니다.

maxSize: 허용할 최대 에지 연결 성분 크기입니다.

mask: 선택적 마스크입니다.

반환: 독립 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ExtendedMatchResult.Matches: 점수 순서의 후보 복사본입니다.

ExtendedMatchResult.Evaluated: 평가된 포즈 수입니다.

ExtendedMatchResult.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

검색 영상에서 연결된 에지 구성요소의 크기를 조건으로 삼아 형상 검색을 수행합니다. 학습 단계에서 특징을 거르는 TrainGrain과 달리 이 호출의 min_size와 max_size는 검색 영상의 에지 쪽에 적용됩니다.

작은 잡음과 긴 실제 경계가 섞인 영상이라면 최소 크기를 달리한 두 번의 결과를 비교해 볼 수 있습니다. 최대 크기까지 함께 좁히면 원하는 경계도 조건에서 제외될 수 있으므로 결과 목록과 종료 진단을 함께 살피고, 나머지 옵션은 동일하게 유지해 비교합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options검색 설정입니다.
minSize허용할 최소 에지 연결 성분 크기입니다.
maxSize허용할 최대 에지 연결 성분 크기입니다.
mask선택적 마스크입니다.
