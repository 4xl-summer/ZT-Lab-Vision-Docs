Constructor · 선언 타입 ZVision.FeatureInstanceCollectionEntry

C#
FeatureInstanceCollectionEntry(System.UInt64 id, ZVision.FeatureModel model, ZVision.FeatureSearchOptions options, System.UInt64 minInliers = 3)

모델 항목을 만듭니다.

인자

id: 고유 ID입니다.

model: 소유 모델입니다.

options: 검색 중 변경하지 않을 설정입니다.

minInliers: 최소 인라이어 수입니다.

관련 입력의 확인된 조건

options.Ratio: 최선과 차선 기술자 거리의 비율 상한이며 0 초과 1 미만입니다.

options.MaxDistance: 단위 L2 기술자 간 최대 거리입니다.

options.InlierThreshold: 기하 인라이어 거리 상한 픽셀입니다.

options.RansacIterations: 최대 무작위 가설 수이며 1~4096입니다.

options.Seed: 재현 가능한 가설 생성 seed입니다.

options.MaxDescriptorComparisons: 왕복 기술자 비교 수 상한이며 1~10000000입니다.

options.Mutual: 소스에서 모델로의 최선 대응도 일치해야 합니다.

options.Geometry: 기하 검증 변환 종류입니다.

값을 구성하고 해석하기

특징 인스턴스 컬렉션에서 사용할 모델과 Id, 모델별 대응 설정 및 최소 내점 수를 묶습니다. 결과에서 어떤 모델이 선택되었는지 Id로 다시 연결하므로 입력 컬렉션의 모델과 식별자 관계를 보관합니다. 내점 수는 특징점 전체 개수와 구분해야 합니다.

구성 후 확인할 속성

속성의미
Id모델 ID입니다.
Model특징 모델입니다.
Options검색 설정입니다.
MinInliers최소 인라이어 수입니다.
