Method · 선언 타입 ZVision.FeatureInstanceSearch

C#
static ZVision.FeatureInstancesResult Find(ZVision.ZImage source, ZVision.FeatureModel model, ZVision.FeatureSearchOptions options, System.UInt64 maxInstances = 2, System.UInt64 totalHypotheses = 4096, System.UInt64 minInliers = 3, ZVision.ZImage mask = null)

한 소스 특징은 한 객체에만 사용하며 모델 특징은 재사용합니다.

인자

source: 검색 영상입니다.

model: 학습 특징 모델입니다.

options: 대응 및 RANSAC 설정이며 Mutual=false여야 합니다. 호출 중 설정 객체를 수정하지 마세요.

maxInstances: 최대 객체 수 1..64입니다.

totalHypotheses: 공유 가설 상한 1..100000입니다.

minInliers: 최소 인라이어 수입니다.

mask: 선택 검색 마스크입니다.

반환: 독립 복사된 반복 검색 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

FeatureInstancesResult.Instances: 발견된 인스턴스입니다.

FeatureInstancesResult.Evaluated: 평가 가설 총수입니다.

FeatureInstancesResult.Incomplete: 공유 예산으로 검색이 중단됐는지 나타냅니다.

호출과 결과 해석

한 특징 모델의 여러 인스턴스를 검색합니다. 검색 영상의 한 특징은 한 객체에만 사용되고 모델 특징은 다시 사용할 수 있습니다. maxInstances는 개수 상한, totalHypotheses는 공유 가설 예산, minInliers는 수락에 필요한 내점 수입니다. 결과가 적으면 이 세 제한과 대응 조건을 함께 확인합니다.

입력별 확인

입력의미
source검색 영상입니다.
model학습 특징 모델입니다.
options대응 및 RANSAC 설정이며 Mutual=false여야 합니다. 호출 중 설정 객체를 수정하지 마세요.
maxInstances최대 객체 수 1..64입니다.
totalHypotheses공유 가설 상한 1..100000입니다.
minInliers최소 인라이어 수입니다.
mask선택 검색 마스크입니다.

반환값

독립 복사된 반복 검색 결과입니다.
