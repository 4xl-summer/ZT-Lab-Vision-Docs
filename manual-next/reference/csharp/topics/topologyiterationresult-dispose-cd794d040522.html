void Dispose()

소유한 영상을 해제합니다.

수명과 사용 순서

위상 반복 결과 객체의 자원을 해제합니다. 반복 결과를 소비하는 동안에는 객체를 유지하고 처리가 끝난 뒤 해제하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

반복 결과의 종료

Dispose는 TopologyIterationResult가 소유한 결과 자원을 해제합니다. 이 결과의 Image 속성은 결과가 소유하며 Dispose할 때 함께 해제됩니다. 결과를 더 이상 조회하지 않을 때 호출합니다.

위상 처리에서는 입력과 출력의 전경뿐 아니라 연결 관계와 반복 상태를 함께 확인합니다. 예를 들어 전경 픽셀의 개수가 감소했더라도 연결 구조가 의도와 달라졌다면 단순한 개수만으로 원하는 결과라고 판단할 수 없습니다.

결과에서 제공하는 반복 정보와 영상을 읽은 후 필요한 값을 기록하고 종료합니다. 처리 도중 오류가 발생한 경우 완료된 결과의 빈 마스크와 구별합니다. 동일한 입력에 설정만 바꾼 실험은 결과와 옵션을 함께 연결해야 비교할 수 있습니다.

원본과 결과의 ROI 원점과 크기가 같아야 같은 위치를 비교할 수 있습니다. 화면 배율이 달라져 보이는 변화와 실제 마스크의 변화도 구분합니다. 값 스냅샷과 소유 이미지 핸들은 동일한 해제 대상이 아닙니다.
