C#
RectangleMeasurementModel(ZVision.RectangleShapeSpec spec, ZVision.ShapeProbeOptions probes, ZVision.ShapeRobustOptions robust)

설정을 복사하고 사각형 및 탐침과 작업량을 검증합니다.

인자

spec: ROI 로컬 기준 사각형입니다.

probes: 복사할 탐침 설정과 필터입니다.

robust: 복사할 강건 적합 설정입니다.

관련 입력의 확인된 조건

spec.Center: ROI 로컬 중심입니다.

spec.HalfWidth: 로컬 x 방향 반너비입니다.

spec.HalfHeight: 로컬 y 방향 반높이입니다.

spec.Angle: 로컬 x축의 라디안 각도입니다.

생성과 입력 확인

ROI 로컬 사각형 기준과 프로브 및 강건 적합 설정을 복사하고 검증합니다. 반폭 4와 반높이 2는 각각 전체 폭 8과 높이 4를 나타냅니다. 각도는 라디안입니다. 생성한 기준 사각형은 탐색 위치를 정하며 실제 실행에서 각 변의 관측과 최종 형상 상태를 확인해야 합니다.

입력의미
specROI 로컬 기준 사각형입니다.
probes복사할 탐침 설정과 필터입니다.
robust복사할 강건 적합 설정입니다.
