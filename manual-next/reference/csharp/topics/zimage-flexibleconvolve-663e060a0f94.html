ZVision.ZImage FlexibleConvolve(System.Double[] kernel, System.UInt64 width, System.UInt64 height, System.UInt64 anchorX, System.UInt64 anchorY, System.Double divisor = 1, System.Double offset = 0, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, System.Double constant = 0, ZVision.PixelFormat outputFormat = ZVision.PixelFormat.GrayF32, System.Boolean correlate = true)

임의 2차원 계수로 상관 또는 합성곱을 수행합니다.

인자

kernel: 행 우선 유한 계수입니다.

width: 커널 너비입니다.

height: 커널 높이입니다.

anchorX: 커널 기준점의 열입니다.

anchorY: 커널 기준점의 행입니다.

divisor: 누적값을 나눌 0이 아닌 유한 값입니다.

offset: 나눗셈 후 더할 유한 값입니다.

border: 경계 처리 방식입니다.

constant: 상수 경계 값이며 다른 경계에서는 0이어야 합니다.

outputFormat: 결과 회색 픽셀 형식입니다.

correlate: 참이면 상관, 거짓이면 앵커 기준 샘플 오프셋을 반전한 합성곱입니다.

반환: 독립 소유 결과 영상입니다. 사용 후 Dispose합니다.

관련 입력의 확인된 조건

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.

호출에 필요한 입력

인자선언된 형식확인할 내용

결과와 사용 순서

독립 소유 결과 영상입니다. 사용 후 Dispose합니다.

입력과 결과 해석

이웃 표본을 이용하는 연산에서는 중심부와 영상 가장자리의 결과가 다를 수 있습니다. 커널과 경계 처리를 고정하고 작은 입력의 중심 값과 가장자리 값을 따로 확인하세요.
