Method · 선언 타입 ZVision.EdgeQuery

C#
void Dispose()

Releases the query handle.

이 호출의 입력과 객체 맥락

EdgeQuery.Available: Checks whether a single feature bit is available.

EdgeQuery.Get: Gets included metadata by dense index or label.

EdgeQuery.Points: Copies an included edge's ordered points.

EdgeQuery.SetIncluded: Excludes or re-includes an existing stable label.

EdgeQuery.Delete: Deletes a label permanently.

사용 순서와 결과 해석

EdgeQuery가 소유한 쿼리 핸들을 해제합니다. 열린 쿼리의 Count는 현재 포함된 에지 수이고, Get과 Points는 에지의 메타데이터와 점들을 복사해 읽습니다. 반환된 값 정보와 쿼리 핸들 자체는 다른 수명을 가집니다.

Get의 기본 selector는 현재 포함된 에지의 0 기반 조밀 인덱스이고 byLabel을 선택하면 안정된 양의 레이블입니다. SetIncluded로 제외·재포함하면 조밀 인덱스가 달라질 수 있지만 레이블을 사용해 같은 에지를 식별할 수 있습니다. Delete는 단순 제외가 아닌 영구 삭제입니다.

Available은 요청한 단일 기능 비트가 계산되어 있는지 확인하며, Gradients는 포함 에지의 점 순서에 대응하는 응답 배열을 복사합니다. 필요한 점·기울기와 레이블을 먼저 보관한 뒤 쿼리를 Dispose하고, 해제된 쿼리에서 새 값을 읽으려 하지 마세요.

예를 들어 현재 포함된 에지의 조밀 인덱스가 0,1,2일 때 가운데 레이블을 제외하면 남은 조밀 인덱스는 다시 0,1로 조회됩니다. 이 때문에 이전 인덱스 1을 동일 에지의 영구 식별자로 저장하지 않습니다. Get에서 읽은 안정 레이블을 사용하고, 쿼리를 해제하기 전에 필요한 Points와 Gradients의 독립 복사값을 확보하세요.
