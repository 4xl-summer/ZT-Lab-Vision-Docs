void Dispose()

소유 결과 핸들을 해제합니다.

이 호출의 입력과 객체 맥락

변형 정합 결과의 소유 핸들을 해제합니다. 결과가 열린 동안 성공 상태와 제어 격자의 변위를 확인하고 필요하면 정렬 영상과 유효 마스크를 얻습니다. 반환 영상은 별도 소유 객체이므로 결과 Dispose와 별도로 해제합니다. 해제한 결과에서 다시 변위나 영상을 가져오려고 하지 마세요.

사용 순서와 결과 해석

DeformableRegistration의 소유 결과 핸들을 해제합니다. 결과를 읽을 때는 Info.Found를 먼저 확인하고 Columns와 Rows, ResidualRms와 Coverage를 함께 살펴야 합니다. 객체가 반환되었다는 것만으로 유효한 변형 정합이 발견되었다고 가정하지 않습니다.

Displacements는 제어점 변위를 행 우선 Point2 배열로 복사합니다. 예를 들어 열 3, 행 2의 격자면 제어점 변위는 6개이고 처음 3개가 첫 행에 해당합니다. 이 값은 기준 격자에서 소스로 가는 픽셀 변위이며 절대 글로벌 점 좌표가 아닙니다.

AlignedImage와 ValidMask는 각각 별도 소유 영상입니다. 필요한 영상은 결과가 열린 동안 얻고, 결과 객체와 취득한 영상의 사용이 끝나면 각각 Dispose합니다. 이미 복사한 Point2 배열은 값 배열이지만 해제된 결과에서 새 변위나 영상을 읽으려 하지 마세요.

예를 들어 Columns=3, Rows=2인 결과에서는 제어점 변위를 행 우선으로 6개 해석합니다. 해당 배열의 한 값은 한 제어점의 x·y 이동이며 이미지 전체의 모든 픽셀 이동을 직접 열거한 것은 아닙니다. 결과의 Info와 ValidMask를 함께 사용하고, 별도 영상 핸들은 결과 객체와 각각 독립적으로 해제합니다.

예를 들어 결과의 행·열이 각각 2와 3이라고 해도 배열의 해석 순서는 열 3개씩 두 행이라는 계약을 따라야 합니다. 다른 격자의 변위 배열을 단순히 같은 위치로 대응시키지 말고 각 결과의 격자 크기와 좌표 기준을 확인하세요. 성공 여부와 결과 마스크는 배열을 후속 영상 처리에 쓰기 전 살펴봅니다.
