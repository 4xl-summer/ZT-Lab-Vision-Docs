C#
ZVision.EdgeQueryInfo Get(System.UInt64 selector, System.Boolean byLabel = false)

Gets included metadata by dense index or label.

인자

selector: Index or stable label.

byLabel: Whether selector denotes a label.

반환: Detached metadata.

관련 입력의 확인된 조건

EdgeQueryInfo.Label: Stable positive label.

EdgeQueryInfo.Available: Requested and calculated feature bitmask.

EdgeQueryInfo.Closed: Implicit closure when requested.

EdgeQueryInfo.Size: Point count when requested.

EdgeQueryInfo.First: First chain point when requested.

EdgeQueryInfo.Minimum: Minimum point coordinates when requested.

이 호출의 입력과 객체 맥락

EdgeQueryInfo.Maximum: Maximum point coordinates when requested.

selector를 기본 설정에서는 현재 포함된 에지의 0 기반 조밀 인덱스로, 레이블 선택이 참이면 안정된 양의 레이블로 해석합니다. 제외 또는 삭제에 따라 조밀 인덱스는 바뀔 수 있으므로 나중에 같은 에지를 참조할 때는 반환 메타데이터의 label을 기록하세요. 반환 EdgeQueryInfo는 독립 값 스냅샷이며 점 배열은 Points로 별도 복사합니다.
