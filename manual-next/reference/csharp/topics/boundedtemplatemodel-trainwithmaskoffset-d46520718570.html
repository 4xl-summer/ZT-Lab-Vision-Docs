static ZVision.BoundedTemplateModel TrainWithMaskOffset(ZVision.ZImage image, ZVision.BoundedTemplateMetric metric, ZVision.ZImage mask, System.Int32 offsetX, System.Int32 offsetY)

영상보다 큰 마스크를 지정한 로컬 오프셋으로 학습합니다.

인자

image: 학습 영상입니다.

metric: 점수 방식입니다.

mask: 영상 전체를 덮는 Gray8 마스크입니다.

offsetX: 마스크 좌상단의 영상 로컬 X 픽셀입니다.

offsetY: 마스크 좌상단의 영상 로컬 Y 픽셀입니다.

반환: 해제 가능한 모델입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

템플릿 로컬 offset에 놓인 Gray8 마스크를 사용해 정수 평행이동 모델을 만듭니다. offsetX와 offsetY는 마스크 원점의 템플릿 로컬 좌표를 나타내는 int32 값입니다. 마스크는 템플릿 전체를 덮어야 합니다.

마스크 이미지의 원점과 템플릿 원점을 같다고 가정하지 말고 offset과 함께 선택 영역을 확인합니다. 입력 영상은 ColorNcc라면 RGB8, GraySad라면 Gray8을 사용합니다. 만들어진 모델은 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
image학습 영상입니다.
metric점수 방식입니다.
mask영상 전체를 덮는 Gray8 마스크입니다.
offsetX마스크 좌상단의 영상 로컬 X 픽셀입니다.
offsetY마스크 좌상단의 영상 로컬 Y 픽셀입니다.

반환값 확인
