WriteSingleRegister

Method · 선언 타입 ZVision.ModbusTcp

C#
void WriteSingleRegister(System.UInt16 address, System.UInt16 value)

보유 레지스터 하나를 씁니다. 실패 시 자동으로 재전송하지 않습니다.

인자

address: 0부터 시작하는 프로토콜 주소입니다.

value: 쓸 레지스터 값입니다.

사용과 결과 해석

0부터 시작하는 프로토콜 주소의 보유 레지스터 하나에 UInt16 값을 씁니다. 성공 시 반환값은 없으며 입출력 실패는 오류로 전달됩니다.

실패 후 자동으로 재전송하지 않습니다. 장치의 상태와 명령 의미를 확인한 뒤 호출자가 재시도 여부를 결정해야 중복 쓰기의 영향을 판단할 수 있습니다.

쓰기 순서와 실패 처리

열린 ModbusTcp 연결에서 0부터 시작하는 프로토콜 address의 보유 레지스터 하나에 UInt16 value를 씁니다. 반환값은 없으며 통신이나 프로토콜 실패는 진단을 포함한 예외로 전달됩니다. 장치 설명서가 1부터 시작하는 주소 표기를 사용한다면 전달할 프로토콜 주소와 구분해야 합니다.

예를 들어 address=10이면 프로토콜 주소 10의 한 레지스터를 대상으로 합니다. 호출 실패 시 이 API는 쓰기를 자동 재전송하지 않습니다. 통신이 끊긴 상황에서는 명령이 장치에 적용되었는지 확인한 뒤 재시도 여부를 결정하십시오. 필요하면 Reconnect 후 읽기 등으로 상태를 확인하고 사용이 끝난 연결은 Dispose합니다.
