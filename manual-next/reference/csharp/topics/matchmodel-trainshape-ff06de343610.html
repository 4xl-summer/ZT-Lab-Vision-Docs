TrainShape

C#
static ZVision.MatchModel TrainShape(ZVision.ZImage template, System.Double minGradient, ZVision.ZImage mask = null)

템플릿의 기울기 방향으로 형상 모델을 학습합니다. 3×3 이상과 특징점 3개 이상이 필요합니다.

인자

template: 학습할 Gray8, Gray16 또는 GrayF32 영상입니다.

minGradient: 원시 강도/픽셀 단위의 양의 유한 기울기 임계치입니다.

mask: 템플릿과 크기·원점이 같은 선택적 Gray8 마스크입니다. 0은 제외하고 비제로는 포함합니다.

반환: 사용 후 Dispose해야 하는 소유 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

템플릿의 기울기 방향으로 기본 형상 모델을 학습합니다. minGradient는 원시 밝기/픽셀 단위의 유한한 양의 기울기 하한이며, 선택 마스크는 템플릿과 같은 크기와 원점을 사용합니다.

같은 템플릿이라도 하한에 따라 모델에 들어가는 특징이 달라집니다. 너무 높은 기준으로 유용한 경계를 제외하지 않았는지 모델 정보를 살피고 같은 검색 조건에서 결과를 비교합니다. 생성된 모델은 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
template학습할 Gray8, Gray16 또는 GrayF32 영상입니다.
minGradient원시 강도/픽셀 단위의 양의 유한 기울기 임계치입니다.
mask템플릿과 크기·원점이 같은 선택적 Gray8 마스크입니다. 0은 제외하고 비제로는 포함합니다.

반환값 확인

사용 후 Dispose해야 하는 소유 모델입니다.
