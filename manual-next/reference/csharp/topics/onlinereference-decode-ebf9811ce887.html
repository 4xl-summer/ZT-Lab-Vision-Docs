Decode

Method · 선언 타입 ZVision.OnlineReference

C#
static ZVision.OnlineReference Decode(ZVision.ZImage template, System.Byte[] bytes, System.UInt64 maxBytes, System.UInt64 maxPixels)

버전과 체크섬을 검증하여 누적기를 복원합니다.

인자

template: 저장된 기하와 형식이 같은 템플릿입니다.

bytes: 인코딩된 모델 바이트입니다.

maxBytes: 입력 크기 상한입니다.

maxPixels: 픽셀 수 상한입니다.

반환: 호출자가 해제할 누적기입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

사용과 결과 해석

인코딩된 통계 상태를 템플릿과 함께 복원합니다. 버전, 체크섬, 입력 크기 제한 및 픽셀 수 제한을 검사하고 저장된 형식·크기·ROI 원점이 템플릿과 맞지 않으면 오류입니다.

복원된 누적기는 저장 당시의 표본 수와 통계를 이어서 사용할 수 있습니다. 잘못되거나 잘린 바이트를 정상 상태로 취급하지 마십시오. C# 래퍼는 입력 바이트를 복사하고 64 MiB 상한도 검사합니다.
