Capture

Method · 선언 타입 ZVision.BlobSegmentStages

C#
static ZVision.BlobSegmentStagesResult Capture(ZVision.ZImage segmented, ZVision.ZImage roi, ZVision.BlobStageMorphology mode, System.Byte[] kernel, System.UInt32 width, System.UInt32 height, System.UInt32 anchorX, System.UInt32 anchorY, System.UInt32 iterations, System.UInt64 workBudget)

ROI와 선택된 morphology를 적용하면서 세 단계의 마스크를 보존합니다.

인자

segmented: 입력 Gray8 분할 마스크입니다.

roi: 같은 크기·원점의 선택 Gray8 ROI이며 null이면 전체입니다.

mode: 모폴로지 종류입니다.

kernel: 비영 값이 활성인 커널입니다. None이면 빈 배열입니다.

width: 커널 너비입니다.

height: 커널 높이입니다.

anchorX: 커널 기준 열입니다.

anchorY: 커널 기준 행입니다.

iterations: 각 연산 반복 수입니다.

workBudget: 전체 단계의 작업 상한입니다.

반환: 호출자가 해제할 단계 결과입니다.

관련 입력의 확인된 조건

segmented.Origin: ROI의 글로벌 픽셀 원점입니다.

segmented.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BlobSegmentStagesResult.BeforeMask: ROI 마스킹 전 분할 마스크입니다.

BlobSegmentStagesResult.BeforeMorphology: ROI 마스킹 후 morphology 전 마스크입니다.

BlobSegmentStagesResult.FinalMask: morphology 후 최종 마스크입니다.

Capture의 사용과 결과 해석

예를 들어 임계 선택 전후의 단계를 따로 캡처하면 어느 단계에서 작은 영역이 사라졌는지 확인할 수 있습니다. 각 영상이 어떤 단계인지 이름과 순서를 기록합니다. 분할 과정의 중간 결과를 캡처하여 각 단계의 변화를 확인합니다. 최종 마스크와 중간 영상은 서로 다른 단계의 산출물이므로 저장할 때 단계 식별자와 입력 조건을 함께 남깁니다.

항목이 호출에서 확인할 내용

roi같은 크기·원점의 선택 Gray8 ROI이며 null이면 전체입니다.
mode모폴로지 종류입니다.
kernel비영 값이 활성인 커널입니다. None이면 빈 배열입니다.
width커널 너비입니다.
