사용과 결과 판독

비드 품질 결과의 자원을 해제합니다. Values는 탐침별 밝기, 충전 비율, 검체 폭 또는 기준 폭의 독립 배열을 제공합니다. 필요한 배열을 얻을 때 인덱스와 탐침 순서를 보존하고 미검출 NaN을 실제 0 폭과 구별하십시오.

사용 순서와 결과 확인

BeadQualityResult는 비드 품질 검사의 탐침별 진단을 소유합니다. Dispose는 이 결과의 네이티브 핸들을 해제합니다. 필요한 요약과 배열을 먼저 읽은 뒤 결과를 해제하고, 해제된 핸들로 새 조회를 요청하지 마십시오.

Info는 탐침·구간 수와 전체 통과 여부를 제공하고 Flags는 탐침별 사유 비트의 독립 배열입니다. Edges는 선택한 에지 쌍을 담으며 미검출은 HasPair=false입니다. FillFlags의 비트 1과 2는 각각 왼쪽과 오른쪽 보간 대체를 나타냅니다.

Values 인덱스 0은 밝기, 1은 충전 비율, 2는 검체 폭, 3은 기준 폭입니다. 반환 배열은 독립 복사이며 미검출 항목은 NaN입니다. 예를 들어 검체 폭을 읽을 때 NaN을 0으로 바꾸면 실제 0이라는 수치와 미검출을 구분할 수 없습니다.

Runs는 연속 결함 구간의 독립 배열입니다. 결과를 Dispose하기 전에 필요한 배열과 탐침 순서를 기록하고, 각 배열의 같은 인덱스를 해당 탐침과 연결해 판독하십시오. 폭과 밝기, 비율은 서로 다른 양이므로 단위를 섞어 비교하지 않습니다.

단계 또는 항목확인할 내용

Dispose필요한 결과를 읽은 뒤 핸들을 해제합니다.

탐침별 품질 배열은 같은 경로를 따라 배치된 관측들의 순서에 대응합니다. 예를 들어 index 2에서 가져온 검체 폭과 index 3에서 가져온 기준 폭을 비교할 때 같은 위치의 원소끼리 연결해야 합니다. Flags와 FillFlags도 같은 탐침 맥락에서 읽어야 실제 검출 실패와 보간으로 대체한 에지를 구별할 수 있습니다. 전체 통과 여부만 별도로 저장하면 어느 구간이 문제였는지 복원하기 어렵습니다.
