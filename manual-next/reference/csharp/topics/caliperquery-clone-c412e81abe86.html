ZVision.CaliperQuery Clone()

동일한 계획의 독립 복제본을 만듭니다.

반환: 호출자가 해제할 복제본입니다.

사용과 결과 판독

현재 계획과 같은 처리를 수행할 독립 소유 복제본을 만듭니다. 반환 계획은 원본과 별도로 Dispose해야 합니다. 한 계획에서 두 갈래 처리를 준비할 때 복제본을 사용하고, 각 계획의 수정과 실행 결과를 같은 객체라고 가정하지 마십시오. 작업을 마친 뒤 각 실행과 계획의 소유 관계에 맞게 해제합니다.

단계별 확인

Clone은 현재 캘리퍼 계획의 독립 소유 복제본을 만듭니다. 원본과 복제본을 각각 보관하고 사용을 마친 뒤 각각 Dispose해야 합니다. 계획의 복제와 영상에 대한 실제 실행은 서로 다른 단계입니다.

복제한 계획을 실행하면 별도의 실행 객체와 에지 스냅샷을 얻습니다. 같은 계획이라도 다른 입력 영상이나 ROI에서 실행하면 에지 위치가 다를 수 있으므로 각 실행의 영상, 선분 방향과 선택 조건을 함께 기록하십시오.

항목확인할 내용
원본 계획이미 설정한 캘리퍼 처리를 나타냅니다.

에지결과에서 위치와 부호 있는 강도를 확인합니다.
복제본 수명복제본을 사용 후 Dispose합니다.
원본 수명원본도 별도로 Dispose합니다.

예를 들어 원본과 복제본을 서로 다른 프레임에서 실행했다면 각 실행 결과를 해당 프레임과 연결해 보관합니다. 복제된 계획이 독립 핸들이라는 점은 원본을 재사용하는 동안 수명을 별도로 정할 수 있다는 의미이며, 두 실행에서 같은 에지가 발견된다는 뜻은 아닙니다.
