static ZVision.BlobAxisMedianResult Measure(ZVision.ZImage image, System.Double angle, System.UInt64 workBudget)

각 축에서 하위 중앙값을 선택하고 입력 좌표로 역회전합니다.

인자

image: 비어 있지 않은 Gray8 마스크입니다.

angle: u축 방향의 유한 라디안 각도입니다.

workBudget: 투영과 정렬의 추정 작업 단위 상한입니다.

반환: 입력 좌표와 회전 축의 중앙값입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BlobAxisMedianResult.AxisU: 회전 u축 중앙값입니다.

BlobAxisMedianResult.AxisV: 회전 v축 중앙값입니다.

적용과 결과 판독

전경 픽셀을 지정 각도의 축에 투영한 뒤 축별 하위 중앙값을 구하고 원래 좌표로 역회전합니다. 각도 0은 축이 입력 좌표축과 일치하는 비교 사례입니다. 축이 바뀌면 정렬 순서와 결과가 달라질 수 있으므로 각도는 라디안으로 기록하고, 결과 좌표가 어느 프레임인지 확인하십시오.

인자확인된 역할
image비어 있지 않은 Gray8 마스크입니다.
angleu축 방향의 유한 라디안 각도입니다.
workBudget투영과 정렬의 추정 작업 단위 상한입니다.
