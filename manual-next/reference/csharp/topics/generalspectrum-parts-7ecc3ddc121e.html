System.ValueTuple<System.Double[], System.Double[]> Parts()

복소 계수를 복사합니다.

반환: 실수부와 허수부입니다.

이 호출의 입력과 객체 맥락

현재 복소 스펙트럼의 실수부와 허수부를 행 우선으로 각각 복사해 반환합니다. 예를 들어 너비 2, 높이 3이면 두 복사 배열은 같은 6개 좌표를 같은 순서로 나타냅니다. 배열의 항목과 좌표는 스펙트럼 메타데이터의 크기와 함께 해석하고, 값을 수정해 다른 모델을 만들려면 FromParts를 별도로 호출합니다.

복소 계수의 위치와 수명

Parts는 현재 GeneralSpectrum의 복소 계수를 실수부와 허수부 double 배열로 각각 복사해 반환합니다. 각 배열은 같은 주파수 위치의 성분을 같은 행 우선 인덱스에 보관합니다. 반환 배열은 복사본이므로 호출자가 배열을 수정해도 기존 스펙트럼 모델의 내부 계수가 바뀌지 않습니다.

예를 들어 스펙트럼의 너비가 2, 높이가 3이면 각 배열에는 6개 값이 있습니다. 위치 (x=1,y=2)의 행 우선 인덱스는 2×2+1=5이며 Real[5]와 Imaginary[5]가 한 복소 계수의 두 성분입니다. 이 해석은 Metadata의 실제 스펙트럼 크기와 함께 사용해야 합니다.

새 계수로 다른 스펙트럼을 만들려면 크기, 실수부, 허수부 및 정규화를 FromParts에 전달해 별도 모델을 만듭니다. 역변환이 필요하면 해당 모델의 InverseComplex를 사용합니다. 스펙트럼 모델은 Dispose 대상이지만 이미 복사된 관리 배열은 별도 값입니다.

실수부만으로는 일반 복소 스펙트럼의 전체 값을 나타낼 수 없습니다. 같은 인덱스의 Real과 Imaginary를 한 쌍으로 다루고, 외부에서 값을 변경했다면 두 배열 길이가 새 스펙트럼의 폭×높이와 일치해야 합니다. InverseComplex는 실수부만 가정하지 않는 복소 역변환 결과를 제공합니다.

항목의미와 확인
반환 Real복소 계수의 실수부 복사 배열
반환 Imaginary같은 위치 순서의 허수부 복사 배열
인덱스y×스펙트럼 너비+x
Metadata배열 해석에 필요한 크기와 원점
FromParts외부 계수로 별도 스펙트럼 생성
Dispose스펙트럼 핸들 정리; 복사 배열과 구분

비교할 때 확인

복소 계수 한 위치는 Real[i]와 Imaginary[i] 두 숫자로 구성됩니다. 예를 들어 인덱스 5가 (3,4)라면 계수는 실수부 3과 허수부 4를 가집니다. 어느 하나의 배열만 새 모델에 전달하거나 두 배열의 좌표 순서를 바꾸면 원래 복소 계수의 대응 관계가 달라집니다.
