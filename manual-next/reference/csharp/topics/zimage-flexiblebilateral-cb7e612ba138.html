ZVision.ZImage FlexibleBilateral(System.UInt64 radiusX, System.UInt64 radiusY, System.Double sigmaSpatial, System.Double sigmaRange, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, System.Double constant = 0, ZVision.PixelFormat outputFormat = ZVision.PixelFormat.GrayF32)

공간 및 밝기 차이의 Gaussian 가중 bilateral 필터를 적용합니다.

인자

radiusX: 가로 이웃 반경입니다.

radiusY: 세로 이웃 반경입니다.

sigmaSpatial: 픽셀 단위의 양의 공간 시그마입니다.

sigmaRange: 입력 밝기 단위의 양의 범위 시그마입니다.

border: 경계 처리 방식입니다.

constant: 상수 경계 값이며 다른 경계에서는 0이어야 합니다.

outputFormat: 결과 회색 픽셀 형식입니다.

반환: 독립 소유 결과 영상입니다. 사용 후 Dispose합니다.

관련 입력의 확인된 조건

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
radiusXSystem.UInt64가로 이웃 반경입니다.
radiusYSystem.UInt64세로 이웃 반경입니다.
sigmaSpatialSystem.Double픽셀 단위의 양의 공간 시그마입니다.
sigmaRangeSystem.Double입력 밝기 단위의 양의 범위 시그마입니다.
borderZVision.FlexibleBorderMode경계 처리 방식입니다.
constantSystem.Double상수 경계 값이며 다른 경계에서는 0이어야 합니다.
outputFormatZVision.PixelFormat결과 회색 픽셀 형식입니다.

outputFormat의 입력 값

필드의미와 조건
BGR16채널당 16비트 BGR
BGR8채널당 8비트 BGR
BGRA8채널당 8비트 BGRA
GRAY1616비트 부호 없는 회색
GRAY88비트 부호 없는 회색

결과와 사용 순서

독립 소유 결과 영상입니다. 사용 후 Dispose합니다.

입력과 결과 해석

공간 거리와 밝기 차이에 대한 가중을 이용해 평활합니다. 같은 거리의 이웃이라도 밝기 차이가 크면 영향이 달라질 수 있으므로 경계 보존과 잡음 제거를 함께 확인하세요.
