C#
static ZVision.AdvancedMatchReport FindMinContrast(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, System.Double minContrast, ZVision.ZImage mask = null)

Applies mean visible edge contrast to each bounded grid pose before ranking and suppression. Pyramid, subpixel, certainty and trimmed scoring are unsupported.

인자

source: Source image.

model: Shape model.

options: Candidate search and suppression options. 호출 중 설정 객체를 수정하지 마세요.

minContrast: Nonnegative minimum mean visible gradient in source intensity units.

mask: Optional search mask.

반환: Detached candidates and underlying search termination.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

형상 후보의 유효 영역에서 평균 기울기가 지정한 최소 대비 조건을 만족하는지 반영해 검색합니다. minContrast는 유한한 비음수이며 영상의 에지 강도 조건입니다. 매치 점수 하한과는 서로 다른 역할을 하므로 두 값을 혼동하지 않습니다.

조명이 낮거나 경계가 희미한 영상에서 기준을 올리면 후보가 줄 수 있습니다. 기존 검색 옵션과 입력을 고정하고 최소 대비만 바꾸어 매치 목록과 종료 상태를 비교하면 대비 조건이 결과에 미치는 영향을 분리할 수 있습니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.
