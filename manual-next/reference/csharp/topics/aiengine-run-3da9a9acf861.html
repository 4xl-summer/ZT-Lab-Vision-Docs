C#
ZVision.AiResult Run(ZVision.ZImage image, ZVision.Rect region, ZVision.AiRunOptions options)

영역을 추론합니다. 픽셀을 255로 나눈 NCHW F32로 만들고 좌표별 floor 최근접 샘플링으로 비율 유지 없이 늘립니다. 입력은 바꾸지 않습니다.

인자

image: 입력 이미지입니다.

region: 이미지 로컬 반열린 영역입니다.

options: 실행 옵션입니다.

반환: 호출자가 해제할 독립 결과입니다. 분류·분할 로짓 동률은 작은 클래스 ID를 선택하며 분류 점수의 F32 반올림 동률에서도 원래 로짓을 따릅니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AiResult.Info: 과제 및 출력 메타데이터를 가져옵니다.

AiResult.Scores: 분류 softmax 점수를 독립 배열로 복사합니다. 잘못된 과제에서는 네이티브 오류가 발생합니다.

AiResult.Detections: 유지된 검출을 독립 배열로 복사합니다. 점수 내림차순이며 동점은 원래 행 순서입니다. 같은 클래스의 IoU가 임계값보다 클 때 억제합니다.

AiResult.Map: 분할의 GrayU32 또는 이상의 GrayF32 맵을 독립 소유 핸들로 가져옵니다. 맵은 ROI 크기이며 사용 후 해제합니다.

사용과 결과 판독

영상의 로컬 반열린 영역을 모델 크기로 최근접 샘플링하고 255로 나눈 NCHW F32로 추론합니다. 영역 위치와 출력 좌표의 기준을 기록하고 결과 상태와 점수를 함께 확인하십시오. 입력 영상은 변경하지 않으며 결과는 별도로 해제합니다.
