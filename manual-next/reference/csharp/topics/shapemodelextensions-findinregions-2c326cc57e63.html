static ZVision.AdvancedMatchReport FindInRegions(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, System.Double[] anchor, System.Double[] region, System.Double maxOutside, System.Boolean requireFull = false, ZVision.ZImage mask = null)

Searches a bounded grid using independent inclusive anchor and model-region constraints.

인자

source: Source image.

model: Shape model.

options: Grid options; do not mutate during the call. Pyramid, subpixel, certainty and trimmed scoring are unsupported.

anchor: Inclusive source-local anchor rectangle [left,top,right,bottom].

region: Inclusive source-local model rectangle.

maxOutside: Maximum fraction of features outside the model rectangle [0,1].

requireFull: Require the entire transformed feature-bounds rectangle inside the model rectangle.

mask: Optional source mask.

반환: Detached constrained matches and search termination.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

anchor 사각형은 모델 기준점에 적용되고 region 사각형은 변환된 모델에 적용됩니다. 두 영역은 서로 다른 대상을 제한하므로 같은 사각형을 주더라도 기준점만 허용하는 것과 모델 전체의 영역 관계를 요구하는 것은 다른 조건입니다.

maxOutside는 영역 밖에 허용하는 비율이며 0부터 1까지입니다. requireFull의 전체 포함 요구와 함께 설정해 의도한 허용 범위를 표현합니다. 먼저 제약 없이 검색해 후보 포즈를 확인한 다음 영역 조건을 적용해 차이를 비교하면 좌표나 영역 설정 오류를 찾기 쉽습니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.
