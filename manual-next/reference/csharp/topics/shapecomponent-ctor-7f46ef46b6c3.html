C#
ShapeComponent(System.UInt64 id, ZVision.AdvancedMatchModel model, ZVision.Point2 relativePosition, System.Double relativeAngle, System.Double positionTolerance, System.Double angleTolerance)

구성 요소와 상대 기하를 생성합니다.

인자

id: 호출 내 고유 ID입니다.

model: 형상 모델입니다.

relativePosition: 루트 모델 기준 위치입니다.

relativeAngle: 루트 기준 각도 라디안입니다.

positionTolerance: 위치 허용 픽셀 거리입니다.

angleTolerance: 각도 허용 라디안입니다.

관련 입력의 확인된 조건

model.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

값을 구성하고 해석하기

루트 모델을 기준으로 한 구성 형상 모델의 상대 위치와 상대 각도, 허용 오차를 지정합니다. relativePosition과 positionTolerance는 픽셀 관계이고 relativeAngle과 angleTolerance는 라디안입니다. 검색 결과의 구성 요소 id를 입력과 연결하도록 각 id를 호출 내에서 고유하게 정합니다.

생성 인자

항목의미
id호출 내 고유 ID입니다.
model형상 모델입니다.
relativePosition루트 모델 기준 위치입니다.
relativeAngle루트 기준 각도 라디안입니다.
positionTolerance위치 허용 픽셀 거리입니다.
angleTolerance각도 허용 라디안입니다.
