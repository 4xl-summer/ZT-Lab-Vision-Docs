C#
static ZVision.ComponentSearchResult Find(ZVision.ZImage source, ZVision.ShapeComponent[] components, ZVision.AdvancedMatchingOptions options, System.UInt64 totalBudget, System.UInt64 maxObjects = 1, ZVision.ZImage mask = null)

모든 구성 요소가 상대 관계를 만족하는 객체만 반환합니다.

인자

source: 검색 회색 영상입니다.

components: 루트가 첫 번째인 2..16개 필수 요소입니다.

options: 공통 형상 검색 설정입니다. 호출 중 설정 객체를 수정하지 마세요.

totalBudget: 공유 후보 평가 상한입니다.

maxObjects: 최대 객체 1..64개입니다.

mask: 선택 검색 마스크입니다.

반환: 복사된 객체·평가수·중단 상태입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ComponentSearchResult.Evaluated: 평가한 후보 총수입니다.

ComponentSearchResult.Incomplete: 모든 모델 검색이 끝나지 않았는지 나타냅니다.

호출과 결과 해석

형상 구성요소 배열을 검색하고 각 요소의 루트 기준 상대 위치·각도가 허용 범위를 만족하는 객체를 반환합니다. 개별 요소가 각각 검색되었다는 사실만으로 하나의 객체가 완성되는 것은 아닙니다. totalBudget은 공유 검색 예산이고 maxObjects는 반환 객체 수 상한입니다. 결과의 구성요소 id를 입력 배열과 연결해 관계를 확인합니다.

입력별 확인

입력의미
source검색 회색 영상입니다.
components루트가 첫 번째인 2..16개 필수 요소입니다.
options공통 형상 검색 설정입니다. 호출 중 설정 객체를 수정하지 마세요.
totalBudget공유 후보 평가 상한입니다.
maxObjects최대 객체 1..64개입니다.
mask선택 검색 마스크입니다.

반환값

복사된 객체·평가수·중단 상태입니다.
