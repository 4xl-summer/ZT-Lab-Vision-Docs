void Dispose()

결과 핸들을 해제합니다.

이 호출의 입력과 객체 맥락

GapCareGaussianResult.Subsample: 필터 영상과 계산 마스크를 동일한 비율로 축소 표본화합니다.

GapCareGaussianResult.Shifted: 정수 Gaussian 결과를 비트 이동합니다.

GapCareGaussianResult.Image: 필터 출력 또는 계산 여부 마스크의 독립 소유 핸들을 얻습니다.

필터 결과와 마스크의 수명

GapCareGaussianResult는 care 마스크로 선택한 표본의 정규화 Gaussian 결과와 계산 여부 마스크를 소유합니다. Run 또는 RunSelected가 만든 결과에서 Image(false)는 필터 출력, Image(true)는 계산 여부를 나타내는 Gray8 영상을 각각 별도 소유 핸들로 얻습니다. 필요한 영상은 결과를 해제하기 전에 취득합니다.

계산 마스크에서 255는 필터를 적용한 위치이고 0은 입력 값을 복사한 위치입니다. 예를 들어 출력값이 0인 두 위치라도 마스크가 각각 255와 0이면 한쪽은 계산 결과이고 다른 쪽은 복사 위치입니다. 숫자 값만으로 두 상황을 구분하지 말고 같은 좌표의 마스크를 함께 읽습니다.

Subsample은 두 영상을 같은 간격으로 표본화해 독립 결과를 만들고, Shifted는 정수 출력을 비트 이동한 독립 결과를 만듭니다. 새 결과와 Image로 얻은 영상은 각각의 소유 핸들이므로 원래 결과의 Dispose와 별도로 정리합니다. 해제한 원래 결과에 다시 Image를 호출하면 닫힌 객체 오류가 발생합니다.

출력 선택 마스크를 사용하는 RunSelected에서는 입력 표본을 고르는 care 마스크와 출력 위치를 고르는 selector의 역할이 다릅니다. 필터 값을 조사할 때는 어떤 입력 표본이 사용되었는지와 최종 computedMask가 해당 출력 위치에서 계산을 수행했는지를 따로 확인합니다. 두 마스크의 오프셋도 각각 설정됩니다.

항목의미와 확인

비교할 때 확인

Image(true)를 통해 획득한 마스크 영상도 독립 핸들이므로 마스크를 기록할 때 필터 영상과 서로 다른 객체로 관리합니다. Subsample 또는 Shifted가 만든 결과는 원본 결과를 변경하는 대신 별도 결과를 반환하므로 각 결과의 수명을 명확히 정합니다.
