static void SaveTiffPages(ZVision.ZImage[] images, System.String path, System.Boolean bigTiff = false, ZVision.TiffCompression compression = ZVision.TiffCompression.None, ZVision.TiffByteOrder byteOrder = ZVision.TiffByteOrder.Native, ZVision.TiffPlanar planar = ZVision.TiffPlanar.Chunky)

영상들을 지정한 순서와 TIFF 형식으로 저장합니다.

인자

images: 순서대로 기록할 영상입니다.

path: 저장 경로입니다.

bigTiff: BigTIFF를 선택합니다.

compression: 스트립 압축입니다.

byteOrder: 바이트 순서입니다.

planar: 채널 배치입니다.

관련 입력의 확인된 조건

compression.Deflate: Deflate 압축입니다.

compression.Packbits: PackBits 압축입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
imagesZVision.ZImage[]순서대로 기록할 영상입니다.
pathSystem.String저장 경로입니다.
bigTiffSystem.BooleanBigTIFF를 선택합니다.
compressionZVision.TiffCompression스트립 압축입니다.
byteOrderZVision.TiffByteOrder바이트 순서입니다.
planarZVision.TiffPlanar채널 배치입니다.

compression의 입력 값

필드의미와 조건

LZWLZW 압축을 사용합니다.

결과와 사용 순서

입력과 결과 해석

입력 또는 출력 경로와 선택한 형식이 일치하는지 확인하세요. 저장한 결과를 같은 형식으로 다시 읽어 크기와 내용을 비교하면 데이터 전달 과정의 오류를 찾는 데 도움이 됩니다.
