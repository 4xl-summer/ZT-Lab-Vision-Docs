static ZVision.SimulatedPlc Create(System.UInt64 timeoutNs)

설정에 따라 새로운 모의 객체를 만듭니다. 반환 객체는 사용 후 Dispose해야 합니다.

인자

timeoutNs: 양의 시간 초과 기준(나노초)입니다.

반환: 사용 후 Dispose해야 하는 모의 PLC입니다.

사용과 결과 해석

양의 timeoutNs를 지정해 새로운 소프트웨어 모의 PLC를 만듭니다. 시간 단위는 나노초이며 반환 객체는 사용 후 Dispose해야 합니다.

이 객체는 모의 상태와 명령 흐름을 검증하는 데 사용합니다. 실제 PLC 연결을 열거나 장치의 시간 기준을 자동으로 획득하는 것은 아닙니다.

모의 PLC의 시간과 수명

Create는 양의 timeoutNs로 소프트웨어 모의 PLC를 만들고 호출자가 소유할 객체를 반환합니다. 단위는 나노초이며 실제 장치를 검색하거나 연결하지 않습니다. 이후 Command에 명령과 요청 식별자, 결과 코드 및 호출자가 제공하는 현재 시각을 전달해 상태 흐름을 시험합니다.

시간 초과 판정은 Poll에서 수행합니다. 예를 들어 timeoutNs가 1000이면 이는 1000나노초이며 1마이크로초입니다. 호출 간에는 일관된 시계 기준을 사용해야 합니다. 테스트가 끝나면 소유 객체를 Dispose하고, 모의 명령의 결과를 실제 PLC 장치 응답으로 취급하지 마십시오.
