Histogram의 사용과 결과 해석

히스토그램의 빈 수와 범위가 같아야 동일한 인덱스의 빈을 비교할 수 있습니다. 선택된 영역도 다르면 절대 빈도에 영향을 줍니다. 현재 영상 단계에서 연결 성분, 히스토그램 또는 통계를 계산하는 계획입니다. 영상 전체의 통계와 선택된 영역의 통계는 다른 입력을 사용하므로 관심 영역과 설정을 같이 기록합니다.

호출과 결과 판독

ImageQuery.Histogram()은 현재 영상 단계의 히스토그램 계산을 종료 연산으로 계획하고 새 HistogramQuery를 반환합니다. 원래 ImageQuery는 유지되며 새 종료 쿼리는 사용 후 해제해야 합니다. 이 무인자 오버로드는 실행 자체를 뜻하지 않습니다.

실제 실행의 히스토그램은 선택된 영상 단계의 강도 분포를 요약합니다. 예를 들어 어떤 빈의 빈도가 4라면 그 구간에 포함된 표본이 네 개라는 뜻이지 픽셀 좌표가 4라는 뜻이 아닙니다. 다른 결과와 빈별로 비교할 때는 사용된 영상 영역과 빈 정의를 맞추어야 합니다.

원본 빌더와 반환된 종료 쿼리는 서로 다른 소유 객체입니다. 계획 구성과 실제 Run 결과, 결과를 읽은 뒤의 각 핸들 정리를 구분하십시오. 영상 전체 통계와 ROI 또는 마스크로 선택한 통계도 같은 표본 집합이라고 가정하지 않습니다.
