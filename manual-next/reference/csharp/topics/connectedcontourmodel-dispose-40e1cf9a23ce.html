Dispose의 사용과 결과 해석

모델의 사용을 마치면 소유 핸들을 해제합니다. 보관한 별도 결과가 있다면 그 결과의 수명 계약을 확인하고, 닫은 모델로 새로운 검색을 실행하지 않습니다. 연결 윤곽 모델의 구조와 검색 결과를 구분합니다. 검색 입력의 영상 좌표와 모델이 정의된 좌표를 일치시키고, 결과가 없다는 상태를 원점의 정상적인 위치로 대체하지 않습니다.

항목이 호출에서 확인할 내용
대상ConnectedContourModel.Dispose
계약모델을 해제합니다.

사용 순서와 결과 보관

ConnectedContourModel은 순서 있는 입력 폴리라인과 기준점으로 학습된 검색 모델입니다. Dispose는 이 모델의 핸들을 해제합니다. 검색 결과가 필요하면 해제 전에 Find를 수행하고, 모델에 저장된 원본 윤곽을 보관하려면 Contours로 독립 배열을 획득합니다.

Contours는 입력 좌표와 연결 순서를 복사합니다. 예를 들어 두 개의 폴리라인이 있다면 바깥 배열의 두 항목은 각각의 연결된 점열을 뜻하며 한 점열의 끝과 다른 점열의 시작을 자동으로 잇는 의미가 아닙니다. 검색에서 찾은 위치는 모델 좌표 자체가 아니라 입력 영상에 적용된 배치와 함께 해석합니다.

Contours에서 이미 복사한 배열은 모델을 해제한 뒤에도 독립 데이터로 유지됩니다. 반면 닫힌 모델로 새 Contours나 Find를 호출할 수는 없습니다. 폴리라인의 좌표 기준과 검색 영상의 ROI 원점, 결과 포즈를 보존하고 다른 소유 결과 객체도 자신의 계약에 따라 정리합니다.
