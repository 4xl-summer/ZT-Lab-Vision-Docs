ZVision.ImageQuery ColorCorrect(ZVision.ColorCorrection correction)

선형 sRGB에서 행렬과 편향을 적용하고 클리핑 후 재인코딩합니다. 알파는 보존합니다.

인자

correction: 적용할 선형 RGB 색 보정입니다.

반환: 단계가 추가된 현재 쿼리입니다.

관련 입력의 확인된 조건

correction.Matrix: 선형 RGB 보정의 행 우선 3×3 계수 복사본입니다.

correction.Bias: 선형 RGB 보정의 RGB 순서 편향 계수 복사본입니다.

인자별 입력 조건

인자형식역할과 조건
correctionZVision.ColorCorrection적용할 선형 RGB 색 보정입니다.

색 보정 행렬 적용

C#의 ImageQuery 호출은 이 처리를 실행 계획에 연결합니다. ColorCorrection의 3×3 행렬과 RGB 편향을 사용해 입력 색을 조정합니다. 각 출력 채널은 입력의 세 채널이 행렬을 통해 결합된 뒤 해당 편향이 더해진 값으로 해석합니다. 예를 들어 단위 행렬과 0 편향은 색 보정의 기준 설정입니다.

계획을 실행해 얻은 결과의 해석에서는 보정 계수는 패치 대응값을 이용한 fit_color_correction 결과에서 얻을 수 있습니다. 결과의 보정 전후 평균과 최대 색차를 함께 확인하면 소수의 패치가 크게 벗어나는 경우를 놓치지 않을 수 있습니다. 학습 패치 외의 별도 입력에서도 효과를 확인합니다.

이 호출은 지연 검사 계획을 구성합니다. 실행 결과와 그 출력의 소유 규칙을 반환 형식에서 확인하고 Dispose가 필요한 각 자원을 사용 후 해제합니다. 별도 분기가 필요하면 계획을 복제합니다.
