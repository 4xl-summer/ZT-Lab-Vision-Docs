static ZVision.AdvancedMatchModel TrainShapeGrain(ZVision.ZImage template, ZVision.Point2 reference, System.UInt64 minComponent, System.UInt64 maxComponent, System.UInt64 sampleStep = 1, System.Nullable<System.Double> threshold = null, System.Double maxGradient = 1.7976931348623157E+308, System.Boolean sobel = false, ZVision.ZImage mask = null)

표본 격자의 8연결 에지 특징 크기 범위로 형상 모델을 학습합니다.

인자

template: 회색 학습 영상입니다.

reference: 템플릿 로컬 기준점입니다.

minComponent: 연결된 표본 수의 포함 최솟값입니다.

maxComponent: 연결된 표본 수의 포함 최댓값입니다.

sampleStep: 표본 간격 픽셀입니다.

threshold: 최소 기울기이며 null이면 자동입니다.

maxGradient: 최대 기울기입니다.

sobel: 3×3 Sobel 추출을 선택합니다.

mask: 선택적 학습 마스크입니다.

반환: 사용 후 해제할 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

학습 영상의 연결된 에지 구성요소 크기를 제한해 형상 모델을 구성합니다. minComponent는 양의 최소 크기이고 maxComponent는 그 이상이어야 합니다. 이는 검색 영상의 에지 크기를 거르는 FindEdgeGrain과 적용 단계가 다릅니다.

작은 잡음을 학습 특징에서 줄이거나 지나치게 큰 구성요소를 제외할 때 크기 범위를 조정합니다. 원하는 윤곽도 범위 밖이면 특징에서 빠질 수 있으므로 모델의 Features를 확인하고 같은 영상의 검색 결과를 비교합니다. 결과 모델은 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미
template회색 학습 영상입니다.
reference템플릿 로컬 기준점입니다.
minComponent연결된 표본 수의 포함 최솟값입니다.
maxComponent연결된 표본 수의 포함 최댓값입니다.
sampleStep표본 간격 픽셀입니다.
threshold최소 기울기이며 null이면 자동입니다.
maxGradient최대 기울기입니다.
sobel3×3 Sobel 추출을 선택합니다.
mask선택적 학습 마스크입니다.
