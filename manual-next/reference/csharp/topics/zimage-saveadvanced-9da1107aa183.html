ZImage.SaveAdvanced 공개 계약

SaveAdvanced

Method · 선언 타입 ZVision.ZImage

C#
void SaveAdvanced(System.String path, System.UInt32 jpegQuality = 75, ZVision.PngCompression pngCompression = ZVision.PngCompression.Fast)

JPEG 품질 또는 PNG 압축 힌트를 지정해 영상을 저장합니다.

인자

path: 저장 경로입니다.

jpegQuality: JPEG 품질 1~100입니다.

pngCompression: PNG 압축 힌트입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
pathSystem.String저장 경로입니다.
jpegQualitySystem.UInt32JPEG 품질 1~100입니다.
pngCompressionZVision.PngCompressionPNG 압축 힌트입니다.

pngCompression의 입력 값

필드의미와 조건
BEST높은 PNG 압축 설정입니다.
DEFAULT기본 PNG 압축 설정입니다.
FAST빠른 PNG 압축 설정입니다.

결과와 사용 순서

입력과 결과 해석

입력 또는 출력 경로와 선택한 형식이 일치하는지 확인하세요. 저장한 결과를 같은 형식으로 다시 읽어 크기와 내용을 비교하면 데이터 전달 과정의 오류를 찾는 데 도움이 됩니다.
