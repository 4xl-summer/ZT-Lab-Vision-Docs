static ZVision.CalibratedPlanePose FromHomography(System.Double[] homography, System.Double fx, System.Double fy, System.Double cx, System.Double cy, System.Double maxOrthogonalityError = 0.01, System.Double maxScaleError = 0.01)

물리 평면→왜곡 보정된 전역 픽셀 homography에서 양의 깊이를 가진 한 자세를 계산합니다.

인자

homography: 행 우선 평면→전역 픽셀 3×3 행렬입니다.

fx: 수평 초점 픽셀입니다.

fy: 수직 초점 픽셀입니다.

cx: 주점 X 픽셀입니다.

cy: 주점 Y 픽셀입니다.

maxOrthogonalityError: 허용 축 비직교 오차 [0,1]입니다.

maxScaleError: 허용 축 배율 차이 [0,1]입니다.

반환: 카메라←평면의 한 자세이며 거울 모호성을 해소하지 않습니다.

관련 입력의 확인된 조건

CalibratedPlanePose.Rotation: 평면→카메라 회전입니다.

CalibratedPlanePose.Translation: 카메라 좌표의 평면 원점입니다.

CalibratedPlanePose.OrthogonalityError: 입력 두 축의 정규화 내적 절댓값입니다.

CalibratedPlanePose.ScaleError: 입력 두 축 배율의 상대 차이입니다.

호출과 결과 해석

물리 평면에서 왜곡 보정된 전역 픽셀로 향하는 homography와 카메라 내부 파라미터를 이용해 양의 깊이를 가진 자세 한 개를 계산합니다. 입력 행렬의 방향과 픽셀 좌표계가 반대라면 결과 해석이 달라지므로 먼저 확인합니다. maxOrthogonalityError와 maxScaleError는 물리적 회전으로 해석할 수 있는지 검사하는 오차 기준이며, 다른 가능한 자세를 전부 반환한다는 뜻은 아닙니다.

입력별 확인

입력의미
homography행 우선 평면→전역 픽셀 3×3 행렬입니다.
fx수평 초점 픽셀입니다.
fy수직 초점 픽셀입니다.
cx주점 X 픽셀입니다.
cy주점 Y 픽셀입니다.
maxOrthogonalityError허용 축 비직교 오차 [0,1]입니다.
maxScaleError허용 축 배율 차이 [0,1]입니다.

반환값

카메라←평면의 한 자세이며 거울 모호성을 해소하지 않습니다.
