ZVision.GapCareGaussianResult Subsample(System.UInt64 stepX, System.UInt64 stepY)

필터 영상과 계산 마스크를 동일한 비율로 축소 표본화합니다.

인자

stepX: 양의 X 간격입니다.

stepY: 양의 Y 간격입니다.

반환: 해제할 독립 결과입니다.

이 호출의 입력과 객체 맥락

필터 영상과 계산 여부 마스크를 같은 간격으로 축소 표본화해 독립 결과를 만듭니다. 가로·세로 간격은 양의 정수이며 ROI 로컬 (0,0)에서 시작합니다. 예를 들어 x 간격 2는 가로로 한 표본씩 건너뛰며 출력 크기는 내림 기준입니다. 영상과 마스크를 같은 격자로 해석하고 새 결과와 각 영상 핸들의 수명을 따로 관리하세요. 사용 후 각 결과를 Dispose합니다.

사용 흐름과 결과 판독

Subsample은 가우시안 결과의 필터 영상과 계산 여부 마스크를 같은 격자로 선택하여 새 독립 결과를 만듭니다. stepX와 stepY는 각각 양의 정수이고 출력 (x,y)는 입력 ROI 로컬의 (x×stepX,y×stepY)를 선택합니다. 필터 영상만 줄이고 마스크를 원래 크기로 두는 동작이 아니므로 두 출력의 같은 좌표를 함께 사용할 수 있습니다.

출력 폭과 높이는 각각 입력 크기를 해당 간격으로 나눈 몫입니다. 예를 들어 5×4 입력에 stepX=2, stepY=2를 지정하면 2×2 출력이 되고 입력 로컬 열 0, 2와 행 0, 2가 사용됩니다. 나머지 끝부분은 버려지며 출력 원점은 (0,0)입니다. 출력 위치를 원래 글로벌 영상에 표시할 때 입력 ROI 원점과 선택 간격을 함께 고려해야 합니다.

반환된 결과는 원본 결과와 별도 소유이므로 두 객체를 각각 Dispose합니다. 결과에서 영상과 마스크 핸들을 얻었다면 그 핸들도 각 반환 계약에 따라 따로 해제합니다. 간격 0, 비어 있는 출력, 영상과 마스크의 크기·원점 불일치 등은 정상적인 빈 영상으로 취급하지 않고 오류를 확인합니다.
