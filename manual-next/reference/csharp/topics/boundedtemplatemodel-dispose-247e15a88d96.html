사용을 마치는 순서

정수 평행이동용 템플릿 모델을 해제합니다. 학습 방식에 맞는 RGB8 또는 Gray8 영상으로 Find를 마친 뒤 호출합니다. BoundedTemplateResult는 검색 결과를 복사한 값이므로 보유 모델과 결과 객체의 역할을 구분해 사용합니다.

사용 순서

호출역할
Train방식에 맞는 템플릿으로 모델 생성
Find정수 위치를 지정 범위에서 검색
Dispose사용을 마친 모델 정리

검색 방식과 결과 판독

BoundedTemplateModel은 정수 평행이동 위치를 한정해 검색합니다. ColorNcc는 RGB8 입력을 사용하며 점수가 하한 이상인지 판단하고 GraySad는 Gray8 입력을 사용하며 차이가 상한 이하인지 판단합니다. 같은 threshold 숫자라도 두 방식에서 의미가 다릅니다.

Find의 BoundedTemplateResult는 후보와 평가한 위치 수를 복사한 값입니다. 예를 들어 위치 12개를 평가해 후보 2개를 반환한 경우 평가 수와 결과 수는 다릅니다. 필요한 검색이 끝나면 모델을 Dispose하고, 이미 얻은 값 결과는 별도 값으로 해석합니다.
