C#
static ZVision.InspectVariationModel Decode(ZVision.ZImage template, System.Byte[] bytes, System.UInt64 maxBytes, System.UInt64 maxPixels)

같은 기하와 형식의 템플릿으로 모델을 복원합니다.

인자

template: 형식·원점·크기를 제공하는 Gray 영상입니다.

bytes: 저장된 모델입니다.

maxBytes: 바이트 한도입니다.

maxPixels: 픽셀 한도입니다.

반환: 호출자가 해제할 불변 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

인자별 입력 조건

인자형식역할과 조건
templateZVision.ZImage형식·원점·크기를 제공하는 Gray 영상입니다.
bytesSystem.Byte[]저장된 모델입니다.
maxBytesSystem.UInt64바이트 한도입니다.
maxPixelsSystem.UInt64픽셀 한도입니다.

모델 복원

InspectVariationModel.Decode 호출은 형식·원점·크기를 제공하는 template과 저장 바이트, maxBytes 및 maxPixels 상한으로 모델을 복원합니다. 반환 모델은 호출자가 Dispose해야 합니다.

템플릿이 실제 검사 영상과 대응하는지 먼저 확인하고 데이터 손상 또는 제한 초과 오류를 정상 빈 모델로 간주하지 않습니다. 복원에 사용한 바이트와 결과 모델의 수명을 구별합니다.
