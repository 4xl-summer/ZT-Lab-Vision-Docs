ZVision.GapStationaryDb2 WithCoefficients(System.Double[] values)

외부 계수 스냅샷으로 독립 모델을 만듭니다.

인자

values: 모든 밴드의 정확한 길이 유한 계수입니다.

반환: 해제할 독립 모델입니다.

이 호출의 입력과 객체 맥락

외부의 유한 계수 배열을 복사해 독립 모델을 만듭니다. 배열은 원 모델이 요구하는 전체 크기와 순서에 맞아야 합니다. 예를 들어 Coefficients로 복사한 값을 수정한 뒤 이 메서드에 주면 원본과 별도의 모델을 갖게 됩니다. 새 모델을 Inverse로 확인하고, 원본 모델·새 모델·반환 영상의 수명은 각각 관리합니다.

계수 복사와 새 모델

WithCoefficients는 유한한 double 배열을 받아 현재 GapStationaryDb2의 기하와 맞는 독립 모델을 만듭니다. 입력은 Metadata.Width×Height×Bands와 정확히 같은 길이여야 하며 배열은 호출 안에서 복사됩니다. 원래 모델을 제자리에서 덮어쓰는 메서드가 아닙니다.

예를 들어 폭 4, 높이 3, 밴드 수 4인 메타데이터라면 입력은 4×3×4=48개의 계수여야 합니다. Coefficients로 받은 배열을 수정해 전달할 수 있지만 NaN이나 무한대, 길이가 다른 배열은 유효하지 않습니다. 순서는 최종 LL 다음 각 단계의 HL, LH, HH이며 밴드 내부는 행 우선입니다.

항목의미와 처리
values모든 밴드의 유한 double 배열
길이Width×Height×Bands
예시4×3×4=48개
순서LL 다음 단계별 HL/LH/HH
반환독립 GapStationaryDb2 모델
정리두 모델과 복원 영상을 각각 Dispose

적용과 결과 확인

원본 모델과 새 모델에서 각각 Inverse로 영상을 얻어 변경 전후를 같은 ROI와 크기로 비교할 수 있습니다. Inverse 결과는 별도 소유 ZImage이며 원본 모델, 새 모델과 함께 각각 Dispose해야 합니다. 입력 double 배열은 관리되는 값이므로 모델과 영상의 Dispose 대상으로 혼동하지 마세요.

배열을 변경할 때에는 위치가 어느 밴드의 어느 행·열에 속하는지 먼저 계산합니다. 폭 4, 높이 3인 밴드는 12개 값이므로 인덱스 0~11은 첫 밴드이고 12~23은 그다음 밴드입니다. 실제 밴드 개수와 단계는 Metadata에서 확인해야 하며 숫자 4를 모든 모델에 고정해서는 안 됩니다. 수정 전 배열과 수정 후 배열을 따로 보관하면 복원 영상의 차이가 어느 계수 변경에 따른 것인지 추적하기 쉽습니다.
