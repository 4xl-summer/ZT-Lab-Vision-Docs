C#
static ZVision.FeatureModel Train(ZVision.ZImage template, ZVision.FeatureDetectionOptions options, ZVision.ZImage mask = null)

영상과 선택 마스크에서 특징 모델을 학습합니다.

인자

template: Gray8, Gray16 또는 유한 GrayF32 영상입니다.

options: Harris와 패치 설정입니다.

mask: 같은 크기와 원점의 선택적 Gray8 마스크입니다.

반환: 사용 후 해제할 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

회색 템플릿에서 Harris 특징과 정규화 패치 기술자를 학습합니다. FeatureDetectionOptions는 특징 검출을 설정하고, 선택적 Gray8 마스크는 템플릿과 크기 및 원점이 같아야 합니다.

학습 후 Points와 Descriptors로 실제 저장된 특징을 확인할 수 있습니다. 이후 Find에서 검색 영상의 특징과 모델 특징을 대응시키므로 템플릿에 구분할 만한 특징이 있는지 먼저 살피고, 모델은 사용 후 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
templateGray8, Gray16 또는 유한 GrayF32 영상입니다.
optionsHarris와 패치 설정입니다.
mask같은 크기와 원점의 선택적 Gray8 마스크입니다.

반환값 확인
