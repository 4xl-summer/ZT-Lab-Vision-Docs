C#
static ZVision.DenseRegistrationResult Register(ZVision.ZImage reference, ZVision.ZImage source, ZVision.DenseRegistrationOptions options, ZVision.ZImage mask = null)

기준 영상의 각 픽셀에서 소스 영상으로 향하는 연속 변위를 구합니다.

인자

reference: 기준 회색 영상입니다.

source: 동일 크기·원점의 소스 영상입니다.

options: 워핑과 반복 설정입니다.

mask: 기준 좌표의 선택 Gray8 마스크입니다.

반환: 독립 변위·잔차·유효성 결과입니다.

관련 입력의 확인된 조건

reference.Origin: ROI의 글로벌 픽셀 원점입니다.

reference.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

DenseRegistrationResult.Residual: 워핑된 소스에서 기준을 뺀 밝기입니다.

DenseRegistrationResult.Valid: 마스크와 소스 샘플 범위의 유효성입니다.

DenseRegistrationResult.Iterations: 전체 내부 반복 횟수입니다.

DenseRegistrationResult.Converged: 마지막 워핑 내부 반복이 증분 기준에 도달했는지 나타냅니다.

이 호출의 입력과 객체 맥락

options.RobustEpsilon: 강건 광도 가중치 안정화 상수입니다.

options.Tolerance: 마지막 워핑 내부 반복 증분 수렴 기준입니다.

options.MaxDisplacement: 원본 좌표의 변위 크기 상한입니다.

options.MaxWork: 보수적 픽셀 반복 작업 상한입니다.
