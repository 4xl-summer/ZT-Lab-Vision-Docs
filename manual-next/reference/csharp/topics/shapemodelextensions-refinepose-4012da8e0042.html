static ZVision.ShapePoseRefineResult RefinePose(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatch initial, ZVision.ShapePoseRefineOptions options, ZVision.ZImage mask = null)

주어진 형상 pose의 위치, 각도와 두 축 배율을 국소 정밀화합니다.

인자

source: 검색 회색 영상입니다.

model: 형상 모델입니다.

initial: 초기 pose입니다.

options: 간격·반복·작업 한도입니다. 호출 중 설정 객체를 수정하지 마세요.

mask: 선택 검색 마스크입니다.

반환: 복사된 pose와 간격·예산 상태입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ShapePoseRefineResult.Match: 유효한 정밀화 pose입니다.

ShapePoseRefineResult.Evaluated: 평가한 pose 수입니다.

ShapePoseRefineResult.Converged: 모든 간격이 지정 허용치 이하인지 나타냅니다.

ShapePoseRefineResult.BudgetExhausted: 평가 상한에 도달했는지 나타냅니다.

호출 맥락과 결과 해석

initial로 지정한 형상 매치 포즈 주변에서 위치·각도·배율을 국소적으로 정밀화합니다. 전체 영상을 처음부터 탐색하는 기능이 아니므로 먼저 검색이나 다른 절차로 의미 있는 초기 후보를 마련해야 합니다.

반환 값에는 매치 유무와 평가 수, 수렴 및 예산 상태가 포함됩니다. 수렴 여부만으로 전역 최적을 보장하지 않으며, 기대한 자세를 놓쳤다면 초기 포즈와 정밀화 간격 및 예산을 함께 확인합니다. 마스크를 쓰는 경우에는 같은 검색 영상과의 관계도 확인합니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
source검색 회색 영상입니다.
model형상 모델입니다.
initial초기 pose입니다.
options간격·반복·작업 한도입니다. 호출 중 설정 객체를 수정하지 마세요.
mask선택 검색 마스크입니다.
