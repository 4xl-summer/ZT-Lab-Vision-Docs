static ZVision.ZImage Run(ZVision.ZImage image, System.Byte[] foreground, System.Byte[] background, System.UInt32 width, System.UInt32 height, System.UInt32 anchorX, System.UInt32 anchorY, System.UInt64 workBudget)

두 구조 요소를 모두 만족하는 위치의 독립 Gray8 마스크를 만듭니다.

인자

image: 입력 Gray8 영역 마스크입니다.

foreground: 비영 셀이 전경을 요구하는 구조 요소입니다.

background: 비영 셀이 배경을 요구하는 구조 요소입니다.

width: 구조 요소 너비입니다.

height: 구조 요소 높이입니다.

anchorX: 출력 픽셀에 정렬할 구조 요소의 x 인덱스입니다.

anchorY: 출력 픽셀에 정렬할 구조 요소의 y 인덱스입니다.

workBudget: 픽셀과 구조 요소 셀 검사 횟수 상한입니다.

반환: 호출자가 해제할 0 또는 255의 독립 결과입니다. ROI 밖은 배경입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

Run의 사용과 결과 해석

foreground와 background는 각각의 비영 셀로 전경과 배경 요구를 표현합니다. 기준점 anchorX와 anchorY는 구조 요소의 위치를 출력 픽셀에 맞춥니다. 전경과 배경 구조 요소의 조건을 같은 위치에서 함께 검사합니다. 예를 들어 어떤 셀이 전경을 요구하고 다른 셀이 배경을 요구하면 한쪽만 충족한 위치는 일치 결과가 아닙니다.

background비영 셀이 배경을 요구하는 구조 요소입니다.
width구조 요소 너비입니다.
height구조 요소 높이입니다.
반환호출자가 해제할 0 또는 255의 독립 결과입니다. ROI 밖은 배경입니다.
