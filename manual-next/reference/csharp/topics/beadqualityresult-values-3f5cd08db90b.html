System.Double[] Values(System.Int32 index)

탐침별 밝기 또는 충전 비율입니다.

인자

index: 0 밝기, 1 충전 비율, 2 검체 폭, 3 기준 폭입니다.

반환: 미검출은 NaN인 독립 배열입니다.

사용과 결과 판독

인덱스 0은 밝기, 1은 충전 비율, 2는 검체 폭, 3은 기준 폭입니다. 미검출은 NaN이므로 실제 폭 0과 구분해야 합니다. 독립 배열의 각 위치를 원래 탐침 순서와 연결해 누락 구간을 찾으십시오.

항목확인된 역할
index0 밝기, 1 충전 비율, 2 검체 폭, 3 기준 폭입니다.
반환미검출은 NaN인 독립 배열입니다.

예를 들어 index 2는 검체 폭이고 index 3은 기준 폭이므로 같은 탐침 순서에서 비교해야 합니다. 반환 배열의 NaN은 검출이 없음을 나타내며 수치 0으로 바꾸면 실제 0 폭과 구별할 수 없습니다.
