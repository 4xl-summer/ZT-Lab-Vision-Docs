C#
static ZVision.ExtendedShapeModel TrainAligned(ZVision.ZImage[] images, ZVision.Point2 reference, System.Double minFraction, System.UInt64 sampleStep = 1, System.Nullable<System.Double> threshold = null, ZVision.ZImage mask = null)

정렬된 여러 영상에서 공통 형상을 학습합니다.

인자

images: 서로 정렬된 학습 영상 배열입니다.

reference: 로컬 기준점입니다.

minFraction: 학습에 필요한 공통 특징의 최소 비율입니다.

sampleStep: 표본 간격입니다.

threshold: 기울기 임계값이며 null이면 자동입니다.

mask: 선택적 마스크입니다.

반환: 호출자가 해제할 모델입니다.

관련 입력의 확인된 조건

reference.X: 영역의 로컬 x 좌표입니다.

reference.Y: 영역의 로컬 y 좌표입니다.

호출 맥락과 결과 해석

이미 같은 격자에 정렬된 영상 2개에서 64개를 입력해 공통 에지로 모델을 학습합니다. 이 함수에 영상을 전달한다고 자동 정렬되는 것은 아니므로 학습 전에 각 영상의 대응 위치를 맞추고 동일한 기준점을 정해야 합니다.

minFraction은 특징을 유지하는 데 필요한 에지 출현 비율이며 0보다 크고 1 이하여야 합니다. 예를 들어 여러 표본에서 일관된 경계를 남기려면 이 조건을 사용하고, 실제 유지된 형상은 학습 결과의 Features로 점검합니다. 반환 모델은 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
images서로 정렬된 학습 영상 배열입니다.
reference로컬 기준점입니다.
minFraction학습에 필요한 공통 특징의 최소 비율입니다.
sampleStep표본 간격입니다.
threshold기울기 임계값이며 null이면 자동입니다.
mask선택적 마스크입니다.

반환값 확인

호출자가 해제할 모델입니다.
