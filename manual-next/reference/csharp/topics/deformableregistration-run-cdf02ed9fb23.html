static ZVision.DeformableRegistration Run(ZVision.ZImage source, ZVision.ZImage reference, ZVision.DeformableRegistrationOptions options)

초기 변위 격자 근처에서 영상 강도 오차를 최적화합니다.

인자

source: 정렬할 회색 영상입니다.

reference: 기준 회색 영상입니다.

options: 변위 격자와 탐색 설정입니다.

반환: 사용 후 해제할 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

options.InitialDisplacements: 기준 격자에서 소스로 가는 초기 픽셀 변위입니다.

options.Levels: 탐색 간격 반감 단계 수입니다.

options.MinCoverage: 유효 표본의 최소 비율입니다.

options.Smoothness: 인접 제어점 차이의 정규화 계수입니다.
