C#
ZVision.AdvancedBlobQuery Where(System.Linq.Expressions.Expression<System.Func<ZVision.AdvancedBlob, System.Boolean>> predicate, System.Boolean include = true)

면적, 구멍 수, 가중 면적, 최대 Feret을 조합한 제한된 식을 계획합니다.

인자

predicate: 지원 필드와 상수, 산술·비교·논리 연산으로 구성한 식입니다.

include: 참인 항목을 포함하면 true, 제외하면 false입니다.

반환: 기존 계획을 변경하지 않는 새 계획입니다.

Where의 사용과 결과 해석

include가 true이면 식을 만족하는 항목을 포함하고 false이면 만족하는 항목을 제외합니다. 조건식은 지원 필드와 연산으로 작성해야 합니다. 분석이 끝난 결과를 기준으로 선택 계획을 만들고 조건을 추가한 뒤 실행 결과를 확인합니다. 조건의 포함 여부와 결과 목록의 순서를 구분해야 하며, 소유한 계획과 실행 결과는 각각의 수명을 따릅니다.

항목이 호출에서 확인할 내용
predicate지원 필드와 상수, 산술·비교·논리 연산으로 구성한 식입니다.
