사용과 결과 판독

색 통계 지연 계획을 독립 핸들로 복제합니다. 원본과 복제본은 각각 해제해야 하며, 통계는 각 계획의 실행에서 계산됩니다. 입력 영역과 색 공간이 다른 결과를 같은 기준으로 비교하지 마십시오.

항목확인된 역할
반환지연 실행할 쿼리입니다. 사용 후 Dispose해야 합니다.

복제된 지연 계획은 실제 통계 스냅샷과 다릅니다. 원본과 복제본을 각각 실행할 때 처리한 입력과 각 실행 결과를 구별하고 두 계획 핸들을 독립적으로 Dispose하십시오.

사용 순서와 결과 확인

ColorStatisticsQuery.Clone은 동일한 색 통계 지연 계획을 독립 핸들로 복제합니다. 이 시점에는 평균이나 분산을 새로 계산하지 않으며 통계 스냅샷은 계획을 Execute한 뒤 얻습니다. 원본과 복제본은 각각 Dispose해야 합니다.

통계를 비교할 때는 입력 영상, ROI와 색 공간, 선택 마스크가 같은지 확인하십시오. 동일한 계획이라도 실제 입력 또는 선택된 픽셀이 다르면 평균이 달라질 수 있습니다. 한 숫자의 변화만으로 영상의 색 자체가 바뀌었다고 단정하기 어렵습니다.

실행 결과의 통계는 값으로 복사되지만 실행 객체에는 별도의 수명이 있습니다. 각 실행을 사용 후 해제하고, 계획 원본과 복제본도 각각 정리하십시오. 계산된 성분 배열의 순서를 기록해야 어느 채널의 평균인지 나중에 판독할 수 있습니다.
