수명과 사용 순서

학습된 변형 매칭 모델을 더 이상 검색에 사용하지 않을 때 해제합니다. 필요한 검색 결과를 먼저 얻고 모델을 사용하는 호출이 끝난 뒤 수명을 종료하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

검색 모델의 사용 순서

Train은 템플릿을 복사해 NCC 후보 및 국소 변형 검색 모델을 만들고 소유 핸들을 반환합니다. 반환 모델로 검색 영상에 대해 Find 계열 호출을 수행한 다음, 더 이상 같은 모델을 사용하지 않을 때 Dispose합니다. 학습 템플릿의 기준점은 로컬 좌표이므로 검색 결과를 해석할 때 그 기준을 유지해야 합니다.

일반 검색, 조명 보정, 강건 잔차 및 복수 인스턴스 검색은 각각 다른 옵션과 보고서를 사용합니다. 검색 보고서의 결과 유무와 종료 진단을 먼저 확인하십시오. 예를 들어 보고서가 돌아온 것만으로 후보가 존재한다고 가정할 수 없습니다. 해제된 모델로는 새 검색을 시작하지 않습니다.
