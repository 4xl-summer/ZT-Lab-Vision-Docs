C#
ZVision.DifferenceQuery InspectionDifference(ZVision.ZImage reference, ZVision.ZImage includeMask, ZVision.DifferenceSpec spec)

같은 기하의 회색 영상에 밝기 보정과 선택 마스크를 적용해 차분 점수와 마스크를 계산합니다. 점수 1 이상을 결함으로 표시합니다.

인자

reference: 기준 영상입니다.

includeMask: 같은 크기와 원점의 Gray8 포함 마스크입니다. 비제로를 포함하며 null이면 전체를 포함합니다.

spec: 연산에 적용할 조건입니다.

반환: 지연 실행할 쿼리입니다. 사용 후 Dispose해야 합니다.

관련 입력의 확인된 조건

reference.Origin: ROI의 글로벌 픽셀 원점입니다.

reference.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

spec.Threshold: 양의 유한한 기본 차분 허용치로 원시 밝기 단위입니다.

spec.Correction: 차분 전에 사용할 밝기 보정 방식입니다.

spec.Polarity: 점수 계산에 사용할 잔차 극성입니다.

spec.TextureKernel: 국소 표준편차를 구할 양의 홀수 커널 폭입니다.

spec.TextureWeight: 국소 표준편차에 곱할 유한한 0 이상의 가중치입니다.

인자별 입력 조건

인자형식역할과 조건
referenceZVision.ZImage기준 영상입니다.
includeMaskZVision.ZImage같은 크기와 원점의 Gray8 포함 마스크입니다. 비제로를 포함하며 null이면 전체를 포함합니다.
specZVision.DifferenceSpec연산에 적용할 조건입니다.

정렬 후 차분 비교

C#의 ImageQuery 호출은 이 처리를 실행 계획에 연결합니다. 기준 영상과 검사 영상을 비교하여 점수, 이진 마스크 및 부호 있는 차분을 생성합니다. 각 영상은 같은 크기와 원점을 가리켜야 하며 선택 마스크가 있으면 그 유효 영역에 대해서만 검사합니다. 위치가 다른 입력은 먼저 정렬의 발견 상태를 확인해야 합니다.

계획을 실행해 얻은 결과의 해석에서는 예를 들어 보정 후 잔차가 10이고 허용치가 5이며 질감 가중치가 0이면 점수는 2입니다. 극성 설정은 밝아진 쪽, 어두워진 쪽 또는 절대 변화 중 무엇을 검사하는지 정합니다. 후보 추출과 최종 제품 판정은 차분 다음 단계입니다.

이 호출은 지연 검사 계획을 구성합니다. 실행 결과와 그 출력의 소유 규칙을 반환 형식에서 확인하고 Dispose가 필요한 각 자원을 사용 후 해제합니다. 별도 분기가 필요하면 계획을 복제합니다.
