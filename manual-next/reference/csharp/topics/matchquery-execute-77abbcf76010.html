Execute

Method · 선언 타입 ZVision.MatchQuery

C#
ZVision.QueryExecution<ZVision.MatchResult> Execute()

계획을 실행하여 매칭 스냅샷을 만듭니다.

반환: 호출자가 해제할 실행입니다.

호출과 결과 확인

준비된 영상과 모델 매칭 계획을 실행하고 QueryExecution의 독립 MatchResult 스냅샷을 만듭니다. 결과 목록이 비면 성공한 검색에서 후보가 없을 수 있으므로 오류와 구분합니다. 매치 좌표는 모델 기준점과 검색 ROI를 기준으로 읽고 필요한 캡처가 있다면 실행 결과에서 확인합니다.

실행 결과와 소유권

ImageQuery.FindMatches에서 영상 계획, MatchModel과 MatchSpec을 연결한 다음 Execute로 실제 검색을 실행합니다. 반환 QueryExecution은 호출자가 Dispose해야 합니다. Output에서 얻은 MatchResult는 복사된 값 스냅샷이므로 실행 객체의 자원과 구분해 다룹니다.

정상 실행에서 점수·중복 거리 조건을 통과한 후보가 없으면 결과 목록이 비고 첫 후보도 없습니다. 이는 실행 예외와 다릅니다. 위치를 표시할 때 검색 ROI 원점과 템플릿 기준점을 함께 고려하고, 검색 격자 및 임계값을 결과와 함께 기록합니다.

항목확인할 내용
FindMatches모델과 MatchSpec을 연결한 계획
Execute실제 검색과 QueryExecution 생성
Output독립 MatchResult 값 스냅샷
Dispose실행 핸들을 정리

결과를 점검하는 방법

MatchSpec에는 각도와 배율 격자, 최소 점수, 후보 간 최소 거리와 결과 수가 함께 들어 있습니다. 각도는 라디안이고 중심 거리는 검색 ROI 픽셀 단위입니다. 결과가 기대보다 적을 때는 영상의 유효한 검색 영역과 이 조건을 함께 확인하며, 후보가 없는 결과를 예외와 별도로 처리합니다.
