ShapeCollectionEntry(System.UInt64 id, ZVision.AdvancedMatchModel model)

형상 모델 항목을 생성합니다.

인자

id: 호출 내 고유 ID입니다.

model: 형상 모델입니다.

관련 입력의 확인된 조건

model.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

값을 구성하고 해석하기

고급 형상 모델과 호출 내 고유 id를 컬렉션 항목으로 연결합니다. 검색 결과의 식별자를 입력 항목과 대응시키려면 각 모델의 id를 중복 없이 관리합니다. 여기서 만드는 값은 검색 결과가 아니며 model은 나중에 검색할 학습된 모델을 지정합니다.
