C#
RotationCorrespondence(System.Double[] rotation, ZVision.Point2[] source, ZVision.Point2[] target)

회전과 대응점을 지정합니다.

인자

rotation: 행 우선 순수 회전입니다.

source: 원본 글로벌 픽셀입니다.

target: 대상 글로벌 픽셀입니다.

설정과 사용 흐름

행 우선 순수 회전 행렬과 대응하는 원본·대상 글로벌 픽셀 배열을 함께 지정합니다. 두 점 배열에서 같은 인덱스는 같은 특징의 관측이어야 합니다.

배열 순서가 어긋나면 다른 대응 관계가 됩니다. 회전 방향과 각 영상의 글로벌 픽셀 좌표계를 수집 단계부터 일관되게 유지하십시오.

회전 방향과 점 배열

RotationCorrespondence는 원본 카메라에서 대상 카메라로 가는 행 우선 회전 행렬과 두 영상의 글로벌 픽셀 대응점을 묶습니다. rotation은 9개 계수이고 source와 target은 같은 길이의 Point2 배열로 4~256개의 대응을 전달해야 합니다. 생성자는 전달된 세 배열을 복사해 보관합니다.

예를 들어 행렬 [1,0,0,0,1,0,0,0,1]은 행 우선 항등 회전입니다. source[0]과 target[0]은 같은 물리적 특징의 두 관측이어야 합니다. 한쪽 배열만 별도 정렬하면 회전 행렬이 유효해도 점 대응이 바뀝니다. ROI 로컬 점을 수집했다면 각 ROI 원점을 반영해 전역 픽셀로 맞춘 뒤 입력하세요.

항목의미와 처리
rotation원본→대상 회전, 행 우선 9개
source원본 영상 글로벌 픽셀
target대상 영상 글로벌 픽셀
점 개수같은 길이, 4~256쌍
항등 예[1,0,0,0,1,0,0,0,1]
배열 수명생성·속성 접근 시 각각 복사

적용과 결과 확인

Rotation, Source, Target 속성도 내부 배열의 복사본을 반환합니다. 생성 뒤 원래 입력 배열을 수정하거나 읽은 속성 배열을 수정하는 일이 이 객체의 내부 배열을 제자리 변경하는 수단은 아닙니다. 알려진 회전과 대응점으로 재투영을 확인하고 회전 방향을 반대로 전달하지 않았는지 검증하세요.

항등 회전은 회전 행렬의 방향 확인에 도움이 되지만 서로 다른 촬영에서 같은 물체 점을 골랐다는 사실까지 보증하지 않습니다. 같은 코너를 source와 target의 같은 인덱스에 넣었는지 표시 영상으로 확인하세요. 회전 배열은 행 우선이므로 두 번째 행은 네 번째부터 여섯 번째 계수입니다. 최소 개수인 네 쌍을 채웠다는 조건과 실제 화면 전반에서 정확도를 검증했다는 조건도 구분해야 합니다. 속성으로 읽은 배열도 독립 복사본입니다.
