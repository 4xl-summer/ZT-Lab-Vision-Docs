C#
static ZVision.Display.ZOverlayPrimitive Circle(ZVision.Display.ZDisplayPoint center, System.Double radius, System.UInt32 rgba = 4278190335, System.Double strokeWidth = 1)

원을 만듭니다.

인자

center: 중심점입니다.

radius: 양의 반지름입니다.

rgba: 색상입니다.

strokeWidth: 선 두께입니다.

반환: 불변 원입니다.

관련 입력의 확인된 조건

center.X: 점의 가로 좌표입니다.

center.Y: 점의 세로 좌표입니다.

사용 순서와 결과 해석

영상 로컬 중심점과 양의 유한 반지름으로 불변 원을 만듭니다. 반지름과 선 두께는 픽셀 단위이고 색은 0xRRGGBBAA입니다. SVG에서는 중심에 0.5를 더하되 반지름은 그대로 사용합니다. 영상 픽셀을 그리거나 수정하는 연산이 아니라 장면에 넣을 표시 도형을 구성합니다.

입력별 확인

입력의미
center중심점입니다.
radius양의 반지름입니다.
rgba색상입니다.
strokeWidth선 두께입니다.

반환값

불변 원입니다.
