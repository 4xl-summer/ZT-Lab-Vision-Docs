static ZVision.ZImage Unwrap(ZVision.ZImage image, ZVision.GapPolarOptions options)

환형 영역을 각도×반경 영상으로 펼칩니다.

인자

image: 입력 영상입니다.

options: ROI 상대 설정입니다.

반환: 원점이 0인 독립 소유 영상입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

입력 영상의 환형 영역을 옵션으로 지정한 각도×반경 격자로 펼쳐 원점이 0인 독립 영상을 만듭니다. 옵션의 중심과 반경은 입력 ROI 상대 기준으로 해석해야 합니다. 펼친 영상에서 위치를 원래 직교 좌표와 대응할 때는 같은 옵션을 사용하는 MapPoint를 이용합니다. 반환 ZImage는 사용 후 Dispose합니다.
