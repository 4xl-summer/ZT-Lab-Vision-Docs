C#
AiModelSpec(ZVision.AiTask task, System.UInt64 width, System.UInt64 height, System.UInt32 channels, System.UInt64 classes, System.UInt64 modelVersion)

계약을 만듭니다. 네이티브 코드가 값과 모델 메타데이터를 검사합니다.

인자

task: 추론 과제입니다.

width: 너비(픽셀)입니다.

height: 높이(픽셀)입니다.

channels: 입력 채널 수입니다.

classes: 클래스 수입니다.

modelVersion: 0이 아닌 추적 ID입니다.

관련 입력의 확인된 조건

task.Classification: softmax 로짓을 분류합니다.

task.Detection: 박스를 검출하고 클래스별 NMS를 적용합니다.

task.Segmentation: 픽셀별 클래스 레이블을 반환합니다.

task.Anomaly: 이상 점수와 맵을 반환합니다.

사용과 결과 판독

추론 과제와 입력 폭·높이·채널 수, 클래스 수 및 0이 아닌 모델 추적 ID를 지정합니다. 모델의 실제 고정 입출력 메타데이터와 사양이 일치해야 합니다. 설정을 만든 사실만으로 로드가 성공했다고 판단하지 마십시오.

항목확인된 역할
task추론 과제입니다.
width너비(픽셀)입니다.
height높이(픽셀)입니다.
channels입력 채널 수입니다.
classes클래스 수입니다.
modelVersion0이 아닌 추적 ID입니다.
