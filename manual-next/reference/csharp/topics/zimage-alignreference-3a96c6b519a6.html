ZVision.AlignmentResult AlignReference(ZVision.ZImage reference, ZVision.AlignmentSpec spec)

Gray8, Gray16 또는 GrayF32 기준 ROI를 매칭해 기준 영상 기하로 정렬합니다. 검색 실패 또는 유효 비율 부족은 발견되지 않은 결과입니다.

인자

reference: 기준 영상입니다.

spec: 연산에 적용할 조건입니다.

반환: 독립 소유 결과입니다. 사용 후 Dispose해야 합니다.

관련 입력의 확인된 조건

spec.ReferenceRoi: 기준 영상에서 검색 모델을 만드는 로컬 ROI입니다.

spec.Search: 기준 ROI를 검사 영상에서 찾는 검색 조건입니다. 각도는 라디안입니다.

spec.Interpolation: 정렬 영상 생성에 사용할 보간 방식입니다.

spec.MinValidFraction: 요구하는 유효 픽셀 비율로 (0, 1] 범위입니다.

AlignmentResult.Info: 결과 메타데이터 스냅샷입니다.

AlignmentResult.Found: 정렬에 유효한 매치를 찾았는지 나타냅니다.

AlignmentResult.Aligned: 기준 영상 기하의 정렬된 GrayF64 영상입니다. 독립 핸들을 Dispose해야 합니다.

AlignmentResult.ValidMask: 유효 보간 픽셀을 255로 표시하는 Gray8 영상입니다. 독립 핸들을 Dispose해야 합니다.

호출에 필요한 입력

입력과 기준 영상의 정렬을 계산합니다.

인자선언된 형식확인할 내용
referenceZVision.ZImage기준 영상입니다.
specZVision.AlignmentSpec연산에 적용할 조건입니다.

spec의 입력 값

필드의미와 조건
interpolation정렬된 영상을 생성할 Nearest 또는 Bilinear 보간입니다. 기본값은 Bilinear입니다.
min_valid_fraction기준 전체 격자 중 필요한 유효 픽셀 비율이며 (0, 1]입니다. 기본값은 1입니다.
reference_roi기준 영상 로컬 (x, y, 너비, 높이)이며 반열림 사각형입니다. 크기는 양수이고 기준 영상 범위 안에 있어야 합니다.
search기준 ROI의 NCC 모델을 검사 영상에서 찾는 MatchSpec입니다.

결과와 사용 순서

독립 소유 결과입니다. 사용 후 Dispose해야 합니다.

반환 값의 읽을 항목

항목의미
aligned기준 격자의 GrayF64 정렬 영상. 미발견 시 접근 오류.
found정렬 발견 여부.
info정렬 정보의 값 스냅샷.
valid_mask기준 격자의 Gray8 유효 마스크. 미발견 시 접근 오류.

입력과 결과 해석

기준과 입력의 위치 관계를 찾는 단계입니다. 정렬 성공 여부와 변환을 확인한 다음에만 정렬 영상이나 후속 차이 검사를 사용하세요. 유효하지 않은 영역은 정상 검은 픽셀로 해석하지 않습니다.
