ZVision.CompositeResult Evaluate()

저장 단위로 고정 및 파생 형상을 평가합니다.

반환: 모델과 독립된 불변 결과입니다.

관련 입력의 확인된 조건

CompositeResult.Features: 형상 결과 목록입니다.

CompositeResult.Tolerances: 공차 결과 목록입니다.

CompositeResult.Unit: 형상 및 공차 값에 적용된 등방 단위입니다.

이 호출의 입력과 객체 맥락

저장된 복합 계측 그래프를 평가해 모델과 독립된 CompositeResult 스냅샷을 반환합니다. 입력 형상의 좌표는 ROI 로컬 픽셀이고 출력의 등방 단위와 탐침 진단의 픽셀 단위는 구분해야 합니다. 결과에서 형상과 공차 판정을 확인하세요. 이 호출은 영상 인자가 없으므로 영상 측정 형상이 필요한 모델에는 적합하지 않습니다. 이 호출은 모델에 저장된 단위를 사용합니다.

사용 조건과 결과 판독

이 인자 없는 Evaluate 오버로드는 모델에 저장된 단위로 고정·파생 형상 그래프를 평가합니다. 영상 측정 형상이 필요한 모델에는 영상 인자를 받는 별도 오버로드를 사용해야 합니다. 반환 CompositeResult는 모델과 독립된 불변 스냅샷입니다.

예를 들어 고정 점과 선을 추가하고 점-선 거리 공차를 만든 모델이라면 Features에서 각 형상이 계산됐는지 살핀 뒤 Tolerances에서 해당 공차의 상태와 값을 확인합니다. 형상 계산이 불가능한 경우를 거리 0이나 공차 통과로 바꾸어 읽지 마세요.

Unit은 형상과 공차 출력의 등방 단위이며 탐침 진단의 픽셀 단위와 다를 수 있습니다. 좌표 원점은 ROI 로컬 기준이므로 이 등방 배율을 렌즈·원근을 포함한 세계 좌표 보정으로 간주하지 않습니다. 결과 스냅샷과 모델 핸들의 수명을 구분하고 모델 사용 후 Dispose합니다.

예를 들어 모델의 Unit이 픽셀이면 점·선 거리 공차값도 해당 출력 기준으로 읽고, 명시 단위가 필요한 경우에는 unit을 받는 오버로드를 선택합니다. 결과의 개별 공차에서 값이 None이면 실제 거리 0과 다릅니다. 저장된 그래프와 해당 공차 한계가 무엇인지 함께 확인한 후 판정을 사용하세요.
