GridWarpSpec(System.UInt64 rows, System.UInt64 columns, System.UInt64 width, System.UInt64 height, System.Double gridPitchX, System.Double gridPitchY, System.Double originX, System.Double originY, System.Double outputPitchX, System.Double outputPitchY, System.Double angle = 0)

원본 격자와 출력 격자 매핑을 지정합니다.

인자

rows: 2 이상인 원본 행 수입니다.

columns: 2 이상인 원본 열 수입니다.

width: 양의 출력 폭입니다.

height: 양의 출력 높이입니다.

gridPitchX: 원본 X 간격입니다.

gridPitchY: 원본 Y 간격입니다.

originX: 출력 원점 X입니다.

originY: 출력 원점 Y입니다.

outputPitchX: 출력 X 간격입니다.

outputPitchY: 출력 Y 간격입니다.

angle: 출력 회전 라디안입니다.

이 호출의 입력과 객체 맥락

GridWarpSpec.GridPitchX: 원본 격자의 물리 X 간격입니다.

GridWarpSpec.GridPitchY: 원본 격자의 물리 Y 간격입니다.

GridWarpSpec.OriginX: 출력 좌상단의 물리 X 위치입니다.

GridWarpSpec.OriginY: 출력 좌상단의 물리 Y 위치입니다.

GridWarpSpec.Angle: 출력 샘플 격자의 회전 각도(라디안)입니다.
