값을 구성하고 해석하기

Harris 특징 검출과 기술자 패치, 선택 특징 수를 설정합니다. PatchRadius와 MinSpacing은 픽셀 단위이며 ResponseThreshold는 원시 Harris 응답의 하한입니다. 검출 조건을 조정한 뒤 실제 모델 특징의 위치와 개수를 확인해야 검색에 사용할 특징 분포를 이해할 수 있습니다.

구성 후 확인할 속성

속성의미
PatchRadius기술자 반경이며 1~8 픽셀입니다.
HarrisKHarris k 계수이며 0 이상 0.25 미만입니다.
ResponseThreshold원시 Harris 응답의 하한입니다.
MinSpacing선택한 특징점 사이의 최소 거리 픽셀입니다.
MaxFeatures선택할 최대 특징점 수이며 1~2048입니다.
