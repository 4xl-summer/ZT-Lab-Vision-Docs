void Dispose()

결과를 해제합니다.

사용과 결과 판독

비드 검사 결과의 자원을 해제합니다. 누락 통계를 읽을 때는 전체 길이, 누락 길이와 비율 및 좌표 단위를 확인한 다음 결과 사용을 마치십시오. 해제된 결과에서 통계를 다시 구하는 대신 필요한 값과 설정을 미리 보관합니다.

사용 순서와 결과 확인

BeadResult는 비드 경로 검사의 결과를 소유하며 Dispose가 내부 결과 자원을 해제합니다. 결과를 읽는 동안 핸들을 유지하고 필요한 판정과 진단을 복사한 뒤 해제하십시오. 입력 경로를 준비하는 단계와 검사 결과를 판독하는 단계는 다릅니다.

Passed는 전체 통과 여부이고 LongestGapLength는 가장 긴 갭 길이입니다. Probes와 Runs는 각각 탐침과 결함 구간의 복사 배열입니다. 전체 통과 여부 하나만으로 어느 구간이 문제였는지 알 수 없으므로 구간의 인덱스를 원래 경로 순서에 연결해야 합니다.

GapStats는 포함 경로의 전체 길이와 누락 길이, 비율을 평가합니다. 예를 들어 전체 100, 누락 5이면 비율은 0.05입니다. GapStatsUnits를 사용할 때는 선택한 좌표 모드와 단위를 확인하고 길이 단위가 같을 때 비율이 무차원임을 구분하십시오.

필요한 탐침·구간 배열과 통계, 검사 설정을 기록한 다음 결과를 Dispose합니다. 해제된 결과에서 다시 통계를 요청하지 않고, 이미 복사한 값은 결과 핸들과 구별해 관리합니다. ROI와 선택한 세계 좌표 변환도 결과의 해석에 필요합니다.

단계 또는 항목확인할 내용
Passed전체 검사 통과 여부를 읽습니다.
LongestGapLength가장 긴 갭 길이를 확인합니다.
Probes탐침 복사 배열과 원래 경로를 연결합니다.
Runs결함 구간의 복사 배열을 확인합니다.
GapStats전체·누락 길이와 비율을 평가합니다.
Dispose필요한 조회가 끝나면 결과를 해제합니다.

갭의 최대 길이와 전체 누락 비율은 서로 다른 통계입니다. 짧은 누락이 여러 곳에 흩어진 경우 전체 비율이 증가해도 가장 긴 단일 갭과 같은 숫자가 되지는 않습니다. Runs의 구간과 Probes의 순서를 함께 보관하면 결과를 Dispose한 뒤에도 복사한 진단값을 원래 경로와 대조할 수 있습니다. 좌표 모드가 바뀌면 길이의 단위도 결과와 함께 명시하십시오.
