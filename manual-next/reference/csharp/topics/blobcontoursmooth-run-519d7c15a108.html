static ZVision.Point2[] Run(ZVision.Point2[] points, System.UInt32 window, System.Boolean closed, System.UInt64 workBudget)

홀수 길이의 이동 평균으로 윤곽 점을 평활합니다.

인자

points: 유한한 ROI 로컬 점 배열입니다.

window: 점 개수 이내의 양의 홀수 창 길이입니다.

closed: 폐곡선은 끝을 이어서 평균합니다.

workBudget: 점 기여 횟수의 상한입니다.

반환: 점 개수와 순서가 같은 독립 결과 배열입니다.

Run의 사용과 결과 해석

평활 강도를 높이면 작은 요철이 줄어들 수 있지만 경계 위치도 달라질 수 있습니다. 선택한 설정을 기록하고 원본 윤곽과 같은 좌표 기준에서 비교합니다. 윤곽 좌표를 평활하여 국소적인 변화를 줄입니다. 매끄럽게 만든 점열은 원래의 관측점과 다른 좌표이므로 정밀 측정 전에는 원본과 결과의 차이를 비교해야 합니다.
