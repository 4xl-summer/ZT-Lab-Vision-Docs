사용과 결과 해석

기본 다중 바코드 스캔 결과 객체를 만듭니다. 기호 목록은 초기에 비어 있고 입력 영상 통계는 기본값입니다.

실제 스캔의 Reads는 발견된 기호 목록이고 ImageMetrics는 전체 입력의 강도 통계입니다. 강도 통계를 바코드 품질 검증 등급으로 해석하지 마십시오.

스캔 결과와 영상 통계

기본 객체의 Reads는 빈 배열이고 ImageMetrics는 기본값입니다. 생성자만 호출해서 실제 바코드를 탐지하거나 영상 통계를 계산하는 것은 아닙니다. 스캔 결과를 받으면 발견된 각 기호를 Reads에서 확인하고, 각 항목의 텍스트와 형식 및 길이 판정을 읽습니다.

ImageMetrics는 입력 영상 전체의 최소·최대 밝기, 평균 및 표준편차입니다. 예를 들어 평균 밝기가 같아도 기호의 인쇄 품질이나 판독 가능성이 같다는 뜻은 아닙니다. 반환된 기호 목록은 백엔드가 찾은 결과이며 영상 내 모든 기호를 찾았다는 보장으로 사용하지 마십시오.
