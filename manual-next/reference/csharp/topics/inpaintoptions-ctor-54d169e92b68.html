InpaintOptions(System.UInt64 iterations, System.Double timestep, System.Double kappa, System.Double tolerance, ZVision.InpaintConductance conductance, ZVision.HoleInitialization initialization = ZVision.HoleInitialization.NearestKnown)

설정을 생성합니다. 유효 범위는 실행 시 검증합니다.

인자

iterations: 양의 최대 반복 수입니다.

timestep: 0 초과 0.25 이하 시간 간격입니다.

kappa: 양의 밝기 차이 척도입니다.

tolerance: 비음수 변화량 정지 기준입니다.

conductance: 전도 함수입니다.

initialization: 결손 픽셀 초기화 방식입니다.

관련 입력의 확인된 조건

conductance.Exponential: 지수 전도 함수입니다.

conductance.Reciprocal: 역수 전도 함수입니다.

설정과 사용 흐름

결손 복원의 최대 반복, 시간 간격, 밝기 차이 척도, 변화량 정지 기준과 전도 함수 및 초기화를 설정합니다. timestep은 0 초과 0.25 이하, kappa는 양수, tolerance는 비음수입니다.

기본 초기화는 NearestKnown입니다. 설정 객체 생성과 계산 유효성 검사는 구분되므로 실제 Run에서 입력 및 값이 지원 범위인지 확인하십시오.
