C#
static ZVision.AdvancedMatchReport FindImagePyramid(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, System.UInt64 firstLevel, System.UInt64 lastLevel)

축소된 영상과 모델을 사용해 NCC 피라미드 검색합니다.

인자

source: 검색 영상입니다.

model: NCC 모델입니다.

options: 검색 옵션입니다.

firstLevel: 시작 축소 수준입니다.

lastLevel: 마지막 축소 수준입니다.

반환: 후보와 종료 진단입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

실제로 축소한 영상과 모델을 사용해 선택한 피라미드 수준을 검색합니다. 위치 격자만 거칠게 만드는 FindCoarse와 달리 영상 자체가 바뀌므로 작은 무늬가 축소 단계에서 표현되는지도 고려해야 합니다.

firstLevel은 시작 축소 수준, lastLevel은 마지막 축소 수준이며 마지막 수준을 명시합니다. 같은 입력과 다른 설정을 유지하고 수준 범위를 비교하면 축소 단계가 결과와 종료 진단에 미치는 영향을 파악할 수 있습니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
source검색 영상입니다.
modelNCC 모델입니다.
options검색 옵션입니다.
firstLevel시작 축소 수준입니다.
lastLevel마지막 축소 수준입니다.
