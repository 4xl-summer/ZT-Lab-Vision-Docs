C#
static ZVision.CodedFiducial Decode(ZVision.ZImage image, System.UInt64 x, System.UInt64 y, System.UInt64 cellSize, System.UInt32 threshold = 127, System.UInt32 expectedId = 0)

위치를 이미 아는 Gray8 셀 영역을 판독합니다.

인자

image: 입력 Gray8 영상입니다.

x: ROI 로컬 시작 x입니다.

y: ROI 로컬 시작 y입니다.

cellSize: 각 셀 크기 1~256 픽셀입니다.

threshold: 검은 셀 임계값 0~254입니다.

expectedId: 0이면 임의 ID를 허용하고, 그 외는 정확히 일치해야 합니다.

반환: 복원된 ID·기준점·물리 간격·회전입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

CodedFiducial.Unit: 물리 간격 단위입니다.

CodedFiducial.HasSpacing: 물리 간격이 표식에 있는지 나타냅니다.

CodedFiducial.ClockwiseQuarterTurns: 관측된 시계방향 90도 회전 수입니다.

CodedFiducial.PitchX: 가로 물리 간격입니다.

CodedFiducial.PitchY: 세로 물리 간격입니다.

이 호출의 입력과 객체 맥락

위치를 이미 아는 Gray8 표식 영역을 ROI 로컬 x/y와 알려진 cellSize로 판독합니다. cellSize는 1~256픽셀, threshold는 0~254입니다. expectedId=0은 임의 ID를 허용하고 다른 값은 일치해야 합니다. 결과의 기준점·간격·회전을 읽고 위치를 모르는 경우에는 별도의 Finder를 사용하세요.
