ZVision.ZImage Inverse()

입력 ROI 원점을 유지하는 GrayF64 영상을 복원합니다.

반환: 독립 소유 영상입니다.

관련 입력의 확인된 조건

ZImage.Origin: ROI의 글로벌 픽셀 원점입니다.

ZImage.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

모델 계수를 합성하여 입력 ROI 원점을 유지하는 GrayF64 영상을 반환합니다. 숫자 계수 배열과 달리 이 결과는 소유 ZImage이므로 사용 후 Dispose합니다. 모델을 변경한 결과를 비교하려면 각 모델에서 별도 복원 영상을 얻고 같은 ROI 원점과 크기 기준으로 비교하세요. 모델 자체도 별도로 Dispose해야 합니다.

계수에서 GrayF64로 복원

Inverse는 GapHaarWavelet 모델의 계수를 합성해 입력 ROI 원점을 유지하는 GrayF64 영상을 반환합니다. 결과는 호출자가 Dispose해야 하는 독립 소유 ZImage입니다. 모델도 별도의 소유 핸들이므로 복원 영상을 해제하는 것과 모델을 해제하는 것을 구분합니다.

예를 들어 원본 ROI의 글로벌 원점이 (100,200)이고 크기가 4×4라면, 해당 ROI에서 만든 모델의 복원 영상도 원래 ROI 원점을 유지합니다. 복원된 영상의 로컬 (0,0)은 같은 글로벌 위치를 나타냅니다. 데이터 비교는 GrayF64 값과 원본의 실제 형식을 고려하고 부동소수 공차를 정해 수행하세요.

적용과 결과 확인

계수를 수정하지 않은 모델의 복원과 임계값으로 세부 계수를 줄인 모델의 복원은 다른 실험입니다. 변경 전후를 같은 크기와 원점에서 비교하면 처리의 영향을 볼 수 있습니다. 각 모델과 각 Inverse 영상은 별도 수명으로 Dispose하고, 원본 영상과 모델은 별도로 관리하며, 모델을 해제한 뒤에는 그 모델로 새 Inverse를 호출하지 않습니다.

입력 ROI에서 변환 단계가 유효하려면 Forward 단계에서 각 레벨의 양축이 짝수라는 조건을 만족해야 합니다. Inverse는 성공적으로 생성된 모델을 합성하는 단계입니다. 계수를 그대로 사용한 왕복과 Shrunk 또는 WithCoefficients로 달라진 모델의 복원을 비교할 때에는 원본, 모델 설정과 실제 출력 형식을 함께 보관하세요. 복원 값은 GrayF64이므로 원본이 정수일 때도 정수 픽셀 배열과 형식이 같다고 가정하지 않습니다.
