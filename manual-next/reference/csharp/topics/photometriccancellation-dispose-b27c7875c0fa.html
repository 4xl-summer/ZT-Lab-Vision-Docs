void Dispose()

토큰을 해제합니다. 이미 시작된 검사를 취소하지 않습니다.

수명과 사용 순서

취소 토큰의 자원을 해제합니다. 토큰 해제 자체가 이미 시작된 검사를 취소하지 않으므로 중단이 필요하면 Cancel을 사용하고 실행의 종료도 별도로 관리하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

취소 요청과 토큰 해제

PhotometricCancellation.Create는 취소되지 않은 토큰을 만듭니다. Cancel은 진행 중인 검사에 협조적 중단을 요청하고 Dispose는 이 토큰이 소유한 핸들을 해제합니다. 두 호출의 역할이 다르며 Dispose만으로 이미 시작된 검사가 취소되지는 않습니다.

예를 들어 네 장의 동일 기하 영상을 RunControlled에 전달해 검사하던 중 중단이 필요하다면 먼저 Cancel을 호출하고 검사 호출이 어떤 결과나 오류로 종료하는지 확인합니다. 검사에서 토큰을 사용할 수 있도록 공유 수명도 고려해야 합니다. 작업이 더 이상 토큰을 필요로 하지 않을 때 Dispose로 소유 핸들을 정리합니다.

항목의미와 처리
Create취소되지 않은 토큰 생성
RunControlled선택적 토큰과 네 입력 영상을 사용
Cancel협조적 중단 요청
timeoutMs밀리초 제한, 0은 제한 없음
종료 확인검사 결과 또는 오류를 별도로 확인
Dispose토큰 핸들 해제, 취소 요청 아님

수명과 결과 확인

timeoutMs는 검사 호출의 밀리초 제한이며 0은 제한이 없다는 별도 설정입니다. Cancel 요청과 시간 제한을 같은 값으로 취급하지 말고 실제 종료를 확인하세요. 이미 해제한 토큰에 Cancel을 호출하면 사용할 수 없으므로 토큰을 관리하는 범위와 검사 작업의 종료 순서를 명확히 해야 합니다.
