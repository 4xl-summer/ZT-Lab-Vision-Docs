void Dispose()

소유 모델을 해제합니다.

사용을 마치는 순서

분류 형상 검색 모델이 보유한 자원을 해제합니다. 학습 모델로 Find를 수행하고 필요한 반환 결과를 확인한 다음 모델의 사용을 끝냅니다. 다시 검색하려면 유효한 모델을 새로 준비해야 합니다.

사용 순서

호출역할
Traincare와 clutter 라벨을 이용한 학습
Find형상 일치와 clutter 감점을 함께 평가
Dispose학습 모델 정리

학습 라벨과 결과 해석

이 모델의 학습 라벨은 0=무시, 1=care, 2=clutter입니다. care 에지에서 형상 모델을 만들고 clutter 위치는 검색 영상에서 원하지 않는 에지 밀도를 감점하는 데 사용합니다. 검색과 필요한 결과 확인이 끝나면 이 학습 모델을 Dispose합니다.

예를 들어 clutter 가중치가 0.5이고 보이는 clutter 위치의 에지 비율이 0.4이면 점수 배수는 1−0.5×0.4=0.8입니다. 입력 라벨과 검색 조건을 별도로 보관하면 결과가 어떤 영역을 근거로 계산되었는지 추적할 수 있습니다.
