TryGetPixel

Method · 선언 타입 ZVision.Display.ZViewport

C#
System.Boolean TryGetPixel(ZVision.Display.ZDisplayPoint screen, System.Int32 w, System.Int32 h, out System.Int32 x, out System.Int32 y)

화면 좌표가 가리키는 로컬 픽셀 셀을 찾습니다.

인자

screen: 화면 좌표입니다.

w: 영상 너비입니다.

h: 영상 높이입니다.

x: 성공 시 열입니다.

y: 성공 시 행입니다.

반환: 영상 내부이면 참입니다.

관련 입력의 확인된 조건

screen.X: 점의 가로 좌표입니다.

screen.Y: 점의 세로 좌표입니다.

사용 순서와 결과 해석

화면 좌표를 현재 이동과 배율로 역변환해 해당 픽셀 셀의 정수 x, y를 얻습니다. 왼쪽·위 경계는 포함하고 오른쪽·아래 경계는 제외합니다. 영상 안이면 true와 좌표를 반환하며 밖이면 false입니다. 예를 들어 기본 배율·이동에서 화면 (1.2,0.4)는 셀 (1,0)입니다.

입력별 확인

입력의미
screen화면 좌표입니다.
w영상 너비입니다.
h영상 높이입니다.
x성공 시 열입니다.
y성공 시 행입니다.

반환값

영상 내부이면 참입니다.
