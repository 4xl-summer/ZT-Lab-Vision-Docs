AdvancedSearchAxis(System.Double minimum, System.Double maximum, System.Double step)

검색 격자 범위를 만듭니다.

인자

minimum: 최소값입니다.

maximum: 최대값입니다.

step: 양의 간격입니다.

이 호출의 입력과 객체 맥락

minimum부터 maximum 이하까지 양의 step으로 검색 격자를 지정합니다. 예를 들어 0부터 1까지 0.4 간격이면 0, 0.4, 0.8이 방문되고 상한 1은 포함되지 않습니다. 위치 축은 픽셀, 각도는 라디안, 배율은 비율로 사용처에 맞게 해석합니다.

포함 범위와 격자 간격

AdvancedSearchAxis(minimum, maximum, step)은 검색 격자의 포함 최소값, 포함 최대값과 양의 간격을 담습니다. 객체의 각 필드는 double이며 검색 옵션의 X, Y, 각도 또는 배율 축 등에 사용됩니다. 축에 따라 값의 단위가 달라집니다.

예를 들어 minimum=0, maximum=4, step=2이면 격자 위치는 0, 2, 4로 이해할 수 있습니다. 간격이 커지면 평가할 위치가 줄어들 수 있지만 그 사이의 최적 후보를 직접 시험하지 않을 수 있습니다. 끝값이 간격에 정확히 맞지 않는 경우는 해당 검색의 격자 규칙을 확인합니다.

항목확인할 내용
Minimum포함 최소값
Maximum포함 최대값
Step양의 격자 간격
예시 0–4 / 20, 2, 4의 격자
각도 축라디안 단위
실행 확인다른 축과 예산·종료 상태 함께 확인

각도 축은 라디안이고 위치 축은 해당 영상 좌표, 배율 축은 비율로 해석합니다. step은 양수여야 하며 잘못된 범위는 검색 실행의 검증 조건을 따릅니다. 다른 축의 범위와 후보 예산도 평가 수와 종료 상태에 영향을 미칩니다.

적용과 판독을 더 살펴보기

격자의 각 값은 minimum에서 시작해 step씩 증가하는 후보 조건을 나타냅니다. 끝값이 정확히 간격의 배수가 아니라면 최대값이 선언에 있다는 이유만으로 반드시 독립적인 마지막 표본이 된다고 단정하지 말고 실제 검색의 표본 생성 규칙을 확인합니다. X와 Y 축의 위치 범위, 각도 축, 두 배율 축을 각각 결합하면 후보 수가 빠르게 늘어날 수 있으므로 작업 예산과 종료 이유도 함께 살펴야 합니다. 최소 점수나 중복 억제는 축의 범위와 별도의 선택 조건입니다. 간격만 좁히면 품질이 항상 보장되는 것은 아니며 실제 후보의 위치와 점수를 원본 영상에서 검증합니다.
