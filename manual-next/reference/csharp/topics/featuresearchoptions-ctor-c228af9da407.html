FeatureSearchOptions()

기본 검색 설정을 만듭니다.

관련 입력의 확인된 조건

기술자 대응과 결정적 기하 검증 설정입니다.

값을 구성하고 해석하기

특징 기술자 대응과 기하 검증을 설정합니다. Ratio와 MaxDistance는 대응 후보의 거리 조건이고 InlierThreshold는 변환 잔차의 픽셀 기준입니다. RANSAC 반복 수·시드와 기술자 비교 상한은 따로 지정하므로 입력 영상과 이 설정을 함께 보관해야 검색을 비교하기 쉽습니다.

구성 후 확인할 속성

속성의미
Ratio최선과 차선 기술자 거리의 비율 상한이며 0 초과 1 미만입니다.
MaxDistance단위 L2 기술자 간 최대 거리입니다.
InlierThreshold기하 인라이어 거리 상한 픽셀입니다.
RansacIterations최대 무작위 가설 수이며 1~4096입니다.
Seed재현 가능한 가설 생성 seed입니다.
MaxDescriptorComparisons왕복 기술자 비교 수 상한이며 1~10000000입니다.
Mutual소스에서 모델로의 최선 대응도 일치해야 합니다.
Geometry기하 검증 변환 종류입니다.
