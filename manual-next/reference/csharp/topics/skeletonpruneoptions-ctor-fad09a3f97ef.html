기본 옵션을 만듭니다.

사용과 결과 해석

스켈레톤 끝가지 제거의 기본 설정을 만듭니다. 포함 길이 상한은 1, X/Y 간격은 각각 1, 최대 반복은 100, 작업 예산은 100000000입니다.

길이 상한 이내의 끝가지가 제거 대상이므로 실제 픽셀 간격이 다르면 SpacingX/Y를 설정하십시오. 길이 기준과 반복 제한이 결과 형상에 영향을 줍니다.

가지치기 옵션의 기본값

기본 생성자는 MaxLength=1, SpacingX=1, SpacingY=1, MaxIterations=100, WorkBudget=100000000인 옵션 객체를 만듭니다. 이 호출은 스켈레톤을 계산하거나 가지를 제거하지 않으며, 실제 정리는 옵션을 해당 연산에 전달했을 때 수행됩니다.

가지치기는 단순히 전경 픽셀 수를 줄이는 작업으로 해석하지 말고 원래 스켈레톤의 연결과 가지 길이에 어떤 영향을 주는지 확인해야 합니다. 짧은 가지를 제거하는 기준이 적용된다면 관심 구조까지 없어지지 않는지 출력과 원본을 비교합니다.

입력 마스크의 픽셀 크기와 ROI를 보존하여 처리 전후를 같은 좌표에서 확인합니다. 예를 들어 픽셀 해상도가 달라지면 같은 픽셀 수의 가지가 실제로 나타내는 길이도 달라질 수 있습니다. 물리 단위가 필요한 경우 보정을 별도로 적용합니다.

기본 생성 값이 해당 데이터에서 적절한 설정이라는 보장은 아닙니다. 공개 필드의 의미와 연산이 요구하는 범위를 확인하고 옵션을 전달합니다. 잘못된 옵션으로 인한 오류를 가지가 없는 정상 결과와 혼동하지 않습니다.
