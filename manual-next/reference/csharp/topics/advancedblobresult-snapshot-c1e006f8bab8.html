ZVision.AdvancedBlobSnapshot Snapshot()

측정값과 라벨 맵을 독립 불변 스냅샷으로 복사합니다.

반환: 이 결과와 원본 해제 후에도 유효한 스냅샷입니다.

관련 입력의 확인된 조건

AdvancedBlobSnapshot.Width: 라벨 맵의 픽셀 너비입니다.

AdvancedBlobSnapshot.Height: 라벨 맵의 픽셀 높이입니다.

AdvancedBlobSnapshot.Blobs: 입력 순서의 측정값입니다.

AdvancedBlobSnapshot.Labels: 분석 영상 로컬 좌표의 행별 라벨입니다.

Snapshot의 사용과 결과 해석

스냅샷은 현재 분석 결과를 복사해 보관하는 경로입니다. 분석 결과 객체를 임의로 수정하는 행위와 구분하고, 복사된 측정값의 라벨과 단위가 무엇인지 기록합니다. 측정값과 라벨 배열은 서로 다른 표현입니다. 결과 인덱스와 라벨 번호를 혼동하지 말고, 좌표를 물리량으로 읽을 때 적용된 변환과 단위를 함께 기록합니다. 결과를 조회하기 전에 원본 분석과 선택 조건을 확인합니다.
