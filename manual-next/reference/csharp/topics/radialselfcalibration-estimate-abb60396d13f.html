static ZVision.RadialSelfResult Estimate(ZVision.Point2[][] lines, ZVision.RadialSelfOptions options)

알려진 초점 배율에서 공동 직선 잔차를 지역적으로 줄입니다.

인자

lines: 3~16개 순서가 있는 픽셀 윤곽입니다.

options: 고정 초점과 초기값 및 유한 반복 설정입니다.

반환: 중심·단일 계수와 종료 상태입니다.

관련 입력의 확인된 조건

options.Fx: x 방향의 알려진 초점 배율입니다.

options.Fy: y 방향의 알려진 초점 배율입니다.

options.InitialCx: 왜곡 중심의 초기 x 픽셀입니다.

options.InitialCy: 왜곡 중심의 초기 y 픽셀입니다.

options.InitialK1: 단일 방사 계수 초기값입니다.

options.MaxIterations: 최대 반복 횟수입니다.

options.Damping: 양의 초기 LM 감쇠입니다.

options.GradientTolerance: 열 정규화 기울기 수렴 허용값입니다.

RadialSelfResult.K1: 추정된 방사 계수입니다.

RadialSelfResult.Cx: 추정된 왜곡 중심 x입니다.

RadialSelfResult.Cy: 추정된 왜곡 중심 y입니다.

RadialSelfResult.InitialRms: 초기 직선 잔차 RMS입니다.

RadialSelfResult.FinalRms: 최종 직선 잔차 RMS입니다.

RadialSelfResult.Iterations: 실행된 반복 횟수입니다.

계산과 결과 해석

Estimate는 영상에서 원래 직선인 윤곽들을 사용해 방사 왜곡 중심과 단일 계수를 지역적으로 추정합니다. lines에는 순서가 있는 픽셀 윤곽 3~16개를 전달하고 options에는 고정 초점 배율, 초기값과 유한한 반복 설정을 지정합니다. 왜곡 보정 후 각 윤곽의 점이 더 직선에 가깝도록 공동 잔차를 줄이는 문제이므로, 입력이 실제로 직선이어야 한다는 기하 가정이 중요합니다. 예를 들어 곧은 격자선 여러 개가 영상의 서로 다른 위치에 분포한다면 보정 전후 직선 잔차를 비교할 수 있습니다. 원래 곡선인 윤곽을 직선으로 강제하면 추정된 왜곡이 물체의 형태까지 보상하려 할 수 있습니다. 결과 중심과 계수뿐 아니라 종료 상태를 확인하고 초기값, 고정 초점과 입력 ROI 기준을 함께 저장하십시오. 같은 부분에 모인 윤곽만으로는 영상 전체의 보정 품질을 판단하기 어렵습니다. 추정에 사용하지 않은 다른 직선 윤곽으로 검증하고, 반환된 수치를 새 카메라나 다른 해상도의 영상에 그대로 적용하지 마십시오. 고정 초점의 단위와 중심의 픽셀 기준이 입력 윤곽에 사용한 영상과 같은지도 확인해야 합니다. 한 윤곽만의 개선보다 전체 윤곽의 잔차 분포와 종료 원인을 같이 살펴보십시오.
