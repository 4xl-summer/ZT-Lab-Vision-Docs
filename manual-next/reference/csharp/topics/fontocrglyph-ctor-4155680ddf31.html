사용과 결과 해석

기본 문자 결과 객체를 만듭니다. 초기 좌표·점수는 기본값이고 원본 모서리 배열은 비어 있습니다.

실제 판독 결과의 Score는 0~1 템플릿 유사도이며 확률이 아닙니다. X/Y는 각도 보정 캔버스, SourceCorners는 원본 영상 로컬 좌표이므로 구분하십시오.

문자 결과를 읽는 방법

기본 생성은 문자를 인식하거나 셀을 분할하지 않습니다. 이 객체의 초기 값과 실제 판독에서 채워진 값을 구분해야 합니다. 실제 결과에서는 한 문자에 대해 줄 번호, Unicode 코드 포인트, 셀, 유사도와 판정이 함께 제공됩니다.

셀의 X와 Y는 회전 보정 캔버스 좌표입니다. 원본 영상에 경계를 그릴 때는 SourceCorners의 네 점을 사용해야 서로 다른 좌표계를 섞지 않습니다. 점수는 확률이 아닌 템플릿 유사도이며, 승인 여부는 설정된 문자 점수 조건의 결과입니다.
