Invert의 사용과 결과 해석

Gray8에서 0은 255로, 255는 0으로 반전됩니다. 중간 강도도 같은 밝기 범위의 반대편으로 대응합니다. Gray8 반전은 밝은 값과 어두운 값의 관계를 뒤집습니다. 예를 들어 0과 255는 반대 끝값으로 바뀌므로 전경을 비영으로 해석하는 후속 마스크 연산의 의미도 확인해야 합니다.

사용 조건과 결과 판독

ImageQuery.Invert는 현재 C# 쿼리 빌더의 계획에 Gray8 반전 단계를 등록하고 같은 빌더 객체를 반환합니다. 메서드 호출만으로 픽셀 결과가 이미 계산되는 것은 아닙니다. 실제 영상 처리는 계획의 Run에서 수행합니다.

Gray8 반전은 0을 255로, 255를 0으로 바꾸고 중간 값 v도 255−v로 대응합니다. 예를 들어 입력이 [0,100,255]이면 해당 단계의 반전값은 [255,155,0]입니다. 입력 형식이 Gray8이라는 조건과 후속 단계의 전경 의미를 함께 확인해야 합니다.

반환값이 기존 빌더와 동일 객체이므로 두 변수에 저장했다고 독립 계획 두 개가 만들어지는 것은 아닙니다. 예를 들어 반환 빌더에 후속 단계를 추가하면 그 갱신된 계획을 Run해야 결과를 볼 수 있습니다. 별도 계획이 필요한 경우 해당 API의 복제 계약을 확인하세요.

반전 전후 마스크를 비영 전경으로 사용하는 경우 0과 255의 위치가 뒤바뀌어 후속 성분 분석의 대상도 달라질 수 있습니다. Run의 결과와 오류를 처리하고, 쿼리와 반환 영상의 실제 소유 규칙에 따라 Dispose합니다. 계획 등록 성공과 실행 결과 성공을 같은 사건으로 취급하지 않습니다.

예를 들어 같은 빌더 변수에서 Invert를 호출하고 그 반환값을 다른 변수에 저장하더라도 두 변수는 동일한 빌더 객체를 가리킵니다. 따라서 이후 변경한 계획을 두 독립 분기로 혼동하지 마세요. 실제 Run 전에 영상은 반전된 출력이 아니고, Run 뒤 결과 영상은 쿼리와 별도 소유 계약에 따라 다뤄야 합니다.
