ZVision.MatchQuery Clone()

독립적으로 해제할 수 있는 동일 계획의 복제본을 만듭니다.

반환: 사용 후 Dispose해야 하는 소유 지연 계획입니다. 모델 데이터를 공유하므로 원본 모델 해제 후에도 유효합니다.

호출과 결과 확인

매칭 계획을 독립적으로 해제할 수 있는 핸들로 복제합니다. 복제는 매칭 실행이나 MatchResult 생성이 아닙니다. 각 계획의 Execute로 실행 결과를 얻으며 더 이상 필요하지 않은 계획은 각자 정리합니다. 모델·검색 조건과 반환 결과의 수명도 구분합니다.

복제된 계획의 실행

Clone은 같은 매칭 계획에 대해 독립적으로 해제할 소유 핸들을 만듭니다. 모델 데이터는 공유하므로 원본 모델을 해제한 뒤에도 복제된 계획은 유효합니다. 계획 복제는 결과를 즉시 계산하는 단계가 아닙니다.

각 계획에서 Execute를 호출해야 QueryExecution과 MatchResult 스냅샷을 얻습니다. 사용하지 않는 원본 계획과 복제본을 각각 Dispose하고 반환 실행도 별도 수명으로 관리합니다. MatchSpec의 각도·배율과 점수 조건은 결과를 해석할 때 함께 확인합니다.

결과를 점검하는 방법

복제와 실행을 혼동하지 않는 것이 중요합니다. 복제된 핸들에는 같은 검색 구성이 연결되지만 Clone의 반환값은 아직 매치 결과가 아닙니다. Execute 후 Output에서 후보를 확인하고, 검색 ROI와 기준점의 좌표계를 유지해 원본 화면이나 측정 단계로 전달합니다.
