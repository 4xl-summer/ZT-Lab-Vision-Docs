static ZVision.AdvancedMatchModel TrainShape(ZVision.ZImage template, ZVision.Point2 reference, System.UInt64 sampleStep = 1, System.Nullable<System.Double> threshold = null, ZVision.ZImage mask = null)

중심차 기울기 방향으로 형상 모델을 학습합니다.

인자

template: 회색 학습 영상입니다.

reference: 템플릿 로컬 기준점입니다.

sampleStep: 양의 특징 간격입니다.

threshold: 학습 기울기 임계값이며 null이면 자동입니다.

mask: 선택적 학습 마스크입니다.

반환: 사용 후 해제할 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

템플릿의 기울기를 표본화해 확장 형상 모델을 만듭니다. reference는 템플릿 로컬 좌표의 유한한 Point2이며 영상 밖의 점도 지정할 수 있습니다. 결과 포즈는 이 기준점을 기준으로 해석하므로 검색 후 표시할 위치를 고려해 정합니다.

sampleStep은 양의 픽셀 간격이고 threshold는 유한한 비음수 또는 자동 선택 null입니다. 마스크를 주면 템플릿과 크기 및 원점이 같은 Gray8 영상을 사용합니다. 생성된 모델은 독립 소유 객체이므로 검색을 마친 뒤 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미
template회색 학습 영상입니다.
reference템플릿 로컬 기준점입니다.
sampleStep양의 특징 간격입니다.
threshold학습 기울기 임계값이며 null이면 자동입니다.
mask선택적 학습 마스크입니다.
