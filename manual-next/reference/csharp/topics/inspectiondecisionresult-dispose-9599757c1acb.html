void Dispose()

소유한 네이티브 결과 핸들을 해제합니다.

수명과 사용 순서

검사 판정 결과의 네이티브 핸들을 해제합니다. 판정과 필요한 결과를 먼저 확인한 뒤 결과의 수명을 종료하십시오.

이 호출에는 반환값이 없습니다. C#에서 소유 객체의 사용 범위를 정하고 필요한 작업이 끝나면 해제하여 네이티브 자원을 정리하십시오. 해제된 객체는 이후 작업에 사용하지 않습니다.

판정 결과와 거절 사유

표면 결함 후보에 판정 조건을 적용하면 독립 소유 InspectionDecisionResult가 만들어집니다. 결과를 해제하기 전 Passed와 Reasons를 확인하고, 개별 면적 또는 위치 위반의 상세는 Rejections 복사 배열로 얻습니다. Info는 판정 메타데이터의 값 스냅샷을 제공합니다.

개수·총 면적·개별 면적의 한도는 등호를 포함합니다. 예를 들어 최대 결함 수가 3이면 3개는 그 개수 조건을 만족하지만 4개는 초과합니다. 전체 통과 여부만으로 원인을 알 수 없으므로 필요한 사유와 개별 위반을 먼저 기록한 뒤 결과 핸들을 해제하십시오.
