Constructor · 선언 타입 ZVision.PixelArithmeticOptions

C#
PixelArithmeticOptions(ZVision.PixelArithmetic operation, ZVision.PixelFormat output, System.Double gain = 1, System.Double bias = 0)

설정을 생성합니다. 유효 범위는 실행 시 검증합니다.

인자

operation: 대응 성분의 산술 연산입니다.

output: 출력 픽셀 형식입니다.

gain: 결과에 곱할 유한 배율입니다.

bias: 배율 적용 후 더할 유한 값입니다.

관련 입력의 확인된 조건

operation.Divide: 나눗셈이며 0 분모는 오류입니다.

operation.Subtract: 왼쪽에서 오른쪽을 뺍니다.

설정과 사용 흐름

대응 픽셀 성분에 적용할 산술 연산, 출력 형식, 배율과 편향을 지정합니다. gain은 산술 결과에 곱하고 bias는 그 뒤 더합니다. 두 값은 유한해야 합니다.

예를 들어 산술 결과가 4이고 gain=2, bias=1이면 출력 전 값은 9입니다. 빼기는 왼쪽에서 오른쪽을 빼며 나눗셈의 분모가 0이면 오류입니다.
