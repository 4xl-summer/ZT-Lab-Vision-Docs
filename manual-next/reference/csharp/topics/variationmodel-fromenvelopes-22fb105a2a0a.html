Method · 선언 타입 ZVision.VariationModel

C#
static ZVision.VariationModel FromEnvelopes(ZVision.ZImage reference, ZVision.ZImage variation, ZVision.ZImage mask = null)

기준과 편차 영상으로 모델을 생성합니다.

인자

reference: 기준 Gray 영상입니다.

variation: 음이 아닌 편차 Gray 영상입니다.

mask: 선택적 비영 Gray8 마스크입니다.

반환: 호출자가 Dispose할 모델입니다.

관련 입력의 확인된 조건

reference.Origin: ROI의 글로벌 픽셀 원점입니다.

reference.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

인자별 입력 조건

인자형식역할과 조건
referenceZVision.ZImage기준 Gray 영상입니다.
variationZVision.ZImage음이 아닌 편차 Gray 영상입니다.
maskZVision.ZImage선택적 비영 Gray8 마스크입니다.

기준과 편차로 모델 구성

VariationModel.FromEnvelopes 호출은 기준 Gray 영상과 음이 아닌 편차 Gray 영상, 선택적 Gray8 포함 마스크에서 모델을 생성합니다. 동일 좌표의 기준과 편차를 결합하므로 원점과 크기를 함께 확인합니다.

다수 표본의 Train과 달리 전달한 영상을 모델의 기준으로 사용합니다. 직접 구성된 모델의 SampleCount는 0이며 모델이 비어 있다는 뜻은 아닙니다. 반환 모델은 호출자가 Dispose합니다.
