C#
static ZVision.PhotometricResult RunControlled(ZVision.ZImage[] images, ZVision.PhotometricOptions options, ZVision.ZImage mask = null, ZVision.PhotometricCancellation cancellation = null, System.UInt64 timeoutMs = 0)

시간 제한 또는 외부 취소가 가능한 다조명 검사를 수행합니다.

인자

images: 동일 형식·기하의 네 입력 영상입니다.

options: 조명과 결과 설정입니다.

mask: 선택적 Gray8 마스크입니다.

cancellation: 공유 가능한 선택적 취소 토큰입니다.

timeoutMs: 제한 시간 밀리초이며 0은 제한 없음입니다.

반환: 호출자가 해제할 완성된 결과입니다.

관련 입력의 확인된 조건

options.Lights: 조명 xyz 계수의 독립 복사본입니다.

options.MinSignal: 법선 계산에 필요한 최소 신호입니다.

options.MinRcond: 조명 정규 방정식의 최소 역조건수입니다.

options.SpacingX: 세계 x 방향 픽셀 간격입니다.

options.SpacingY: 세계 y 방향 픽셀 간격입니다.

options.MinNormalZ: 곡률 유효 법선 z의 절댓값 하한입니다.

options.SmoothRadius: 형상 계산에 사용할 법선 평활 반경 픽셀입니다.

options.Brightness: 평탄부 출력 밝기 비율입니다.

options.Contrast: 부호 있는 형상 응답의 출력 대비입니다.

사용과 결과 해석

네 조명 영상의 검사를 선택적 취소 토큰과 시간 제한으로 실행합니다. timeoutMs는 밀리초이며 0이면 제한이 없습니다.

취소는 협력적으로 확인되므로 요청과 실행 종료를 구분하십시오. 완성된 반환 결과는 소유 객체이며 사용 후 해제합니다.
