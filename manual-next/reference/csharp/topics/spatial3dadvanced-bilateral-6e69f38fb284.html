Method · 선언 타입 ZVision.Spatial3dAdvanced

C#
static ZVision.DepthMap Bilateral(ZVision.DepthMap depth, System.UInt64 radius, System.Double spatialSigma, System.Double rangeSigma)

경계 보존 양방향 필터를 적용합니다.

인자

depth: 입력 깊이입니다.

radius: 픽셀 반경입니다.

spatialSigma: 공간 표준편차(픽셀)입니다.

rangeSigma: 깊이 표준편차입니다.

반환: 호출자가 해제할 결과입니다.

관련 입력의 확인된 조건

depth.Info: 격자 또는 점군의 메타데이터를 가져옵니다.

깊이 양방향 필터

공간적 거리와 깊이 차이를 모두 고려하여 유효한 중심 픽셀을 평활화합니다. 반경과 공간 시그마는 픽셀 단위이고 깊이 차이에 대한 시그마는 영상 깊이 단위입니다. 결측 중심을 채우는 기능은 아니므로 결측 처리와 평활화를 별도로 계획합니다.

서로 이웃한 픽셀이라도 깊이 차이가 크면 거리만 가까운 경우보다 가중치가 작아집니다. 따라서 깊이 경계를 보존하려는 설정과 잡음을 평균화하려는 설정의 효과가 다릅니다. 반경과 시그마는 유한한 양수로 지정하고 결과의 경계와 결측 위치를 비교합니다.

확인 항목해석
radius양의 픽셀 반경
spatial sigma픽셀 거리의 양의 척도
range sigma깊이 차이의 양의 척도
결측 중심결측으로 유지
