static ZVision.AiDetection[] Decode(System.Single[] rows, System.UInt64 columns, ZVision.AdvancedImageTransform transform, ZVision.AdvancedDecodeOptions options, System.Boolean yolo = false)

행 단위 검출 또는 YOLO 출력을 이미지 좌표 검출로 변환합니다.

인자

rows: 행 순서의 연속 실수 배열입니다.

columns: 행당 열 수입니다.

transform: 전처리에서 얻은 역변환입니다.

options: 좌표와 NMS 설정입니다.

yolo: YOLO 행 형식이면 참입니다.

반환: 선택된 검출입니다.

관련 입력의 확인된 조건

transform.Region: 원본 이미지 영역입니다.

사용과 결과 판독

연속 실수 행을 검출 후보로 읽고 전처리에서 얻은 역변환을 통해 이미지 좌표로 바꿉니다. 행의 열 수와 YOLO 형식 선택이 실제 데이터 배치와 맞아야 하며, NMS 설정을 바꾸면 선택되는 상자가 달라질 수 있습니다.

항목확인된 역할
rows행 순서의 연속 실수 배열입니다.
columns행당 열 수입니다.
transform전처리에서 얻은 역변환입니다.
options좌표와 NMS 설정입니다.
yoloYOLO 행 형식이면 참입니다.
반환선택된 검출입니다.
