C#
static System.ValueTuple<ZVision.ZImage, System.Double> Run(ZVision.ZImage image, ZVision.ZImage mask, System.UInt64 maxWork, System.Nullable<System.Double> factor = null, System.Int32 depth = 8)

유효 픽셀의 최대 절댓값 또는 지정 배율을 사용해 Gray8 또는 Gray16 영상을 만듭니다.

인자

image: GrayF32 부호 형상 또는 곡률 영상입니다.

mask: 유효 픽셀이 0이 아닌 Gray8 마스크입니다.

maxWork: 작업량 상한입니다.

factor: 양의 고정 배율이며 null이면 자동입니다.

depth: 출력 비트 깊이 8 또는 16입니다.

반환: 호출자가 해제할 Gray8 또는 Gray16 영상과 실제 배율입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

사용과 결과 해석

GrayF32 부호 형상 또는 곡률 영상과 비영 픽셀이 유효한 Gray8 마스크를 받아 Gray8 또는 Gray16으로 변환합니다. factor는 양의 고정 배율이며 null이면 유효 픽셀의 최대 절댓값을 기준으로 자동 결정합니다.

반환값은 출력 영상과 실제 사용한 배율입니다. 출력 영상은 호출자가 해제해야 합니다. 서로 다른 영상의 표시값을 비교할 때 자동 배율이 서로 달랐는지 확인하십시오.
