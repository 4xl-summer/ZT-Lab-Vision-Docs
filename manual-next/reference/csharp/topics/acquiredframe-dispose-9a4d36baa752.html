Method · 선언 타입 ZVision.AcquiredFrame

void Dispose()

소유한 네이티브 핸들을 해제합니다.

이 호출의 입력과 객체 맥락

모의 카메라에서 꺼낸 프레임 소유 핸들을 해제합니다. 해제 전 Info의 source, epoch, frame ID와 시계 정보를 확인하고 필요한 Image를 얻습니다. 반환 이미지도 별도 소유 핸들이므로 사용 후 따로 Dispose합니다. 프레임을 이미 꺼냈다면 카메라가 취득을 중단하더라도 이 프레임의 수명은 별도로 관리됩니다.

사용 순서와 결과 해석

Dispose는 모의 카메라에서 꺼낸 AcquiredFrame의 소유 핸들을 해제합니다. 아직 프레임이 열린 동안 Info에서 source ID, epoch, frame ID와 시계 정보를 읽고 이후 처리할 영상이 필요하면 Image를 취득하세요. 프레임을 닫은 뒤 새 Info나 Image를 요청하는 흐름은 허용되지 않습니다.

Image 속성은 별도 소유 ZImage 핸들을 돌려줍니다. 예를 들어 프레임을 꺼내 Info를 기록하고 Image를 취득한 다음 프레임을 Dispose할 수 있으며, 취득한 영상의 사용이 끝났을 때 그 영상도 별도로 Dispose해야 합니다. 이미 꺼낸 프레임은 카메라가 중지되어도 그 자신의 수명을 가집니다.

epoch는 취득 세션 구분값이고 frame ID는 그 스트림의 프레임 식별자입니다. device ticks와 host 나노초는 같은 숫자 단위가 아니므로 시계 매핑 없이 단순 비교하지 않습니다. 반환 Info는 값 스냅샷이며 영상 핸들과 해제 책임이 다릅니다.

예를 들어 두 번의 취득 시작 사이에는 epoch가 달라질 수 있습니다. frame ID가 같아 보이더라도 source와 epoch를 함께 기록하면 서로 다른 스트림의 프레임을 구분할 수 있습니다. 프레임을 이미 큐에서 꺼냈다면 카메라의 stop으로 대기 큐가 비워지는 상황과 구분하고, 해당 프레임과 Image의 별도 소유 수명을 정리하세요.
