void Dispose()

소유한 네이티브 자원을 해제합니다.

수명과 사용 순서

구성한 쿼리 빌더가 보유한 네이티브 자원을 해제합니다. 실행할 쿼리를 먼저 구성하고 더 이상 빌더가 필요하지 않을 때 수명을 끝냅니다.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

사용 흐름과 판독 기준

QueryBuilder는 영상 처리 쿼리를 구성하는 동안 네이티브 계획을 소유합니다. Dispose는 그 빌더의 자원을 해제하며 영상 처리 연산을 실행하는 메서드가 아닙니다. 필요한 연산과 캡처 조건을 구성한 뒤 실행하고 결과를 사용하는 순서에서, 빌더가 더 이상 필요하지 않은 시점을 정해 해제합니다.

쿼리 계획과 실행 결과는 서로 다른 역할입니다. 실행 결과를 얻었다면 반환된 실행 객체의 계약을 따로 확인하고, 빌더를 해제했다는 사실만으로 실행 출력까지 같은 객체라고 취급하지 않습니다. 특히 실행 결과에서 획득한 영상의 독립 소유 여부는 해당 접근자 문서에 따라 판단하며, 결과와 획득 영상은 각자의 소유 계약에 맞춰 정리합니다.

예를 들어 한 빌더에서 임계값 단계와 이름 있는 캡처를 등록했다면 필요한 결과를 얻기 전에 빌더를 닫아 이후 계획을 추가하거나 새 실행을 요청할 수는 없습니다. 사용이 끝난 빌더를 다시 호출하면 닫힌 자원에 접근하는 상황입니다. Dispose는 반환값이 없고 해당 빌더의 수명을 종료하는 데 사용합니다.
