void Expect(System.Int64 frameId, System.Int64 recipeVersion)

양의 세대 하한을 지정합니다. 각 하한은 감소할 수 없습니다.

인자

frameId: 프레임 세대 하한입니다.

recipeVersion: 레시피 세대 하한입니다.

사용과 결과 해석

프레임과 레시피 세대의 양의 하한을 설정합니다. 각 하한은 이전 값보다 감소할 수 없으므로 새로운 작업의 기대 세대를 순방향으로 관리합니다.

예를 들어 하한이 프레임 10, 레시피 3이면 그보다 오래된 값을 수락 대상으로 보지 않습니다. 실제 판정은 CanAccept 또는 TryAccept를 사용하십시오.

세대 하한과 표시 순서

Expect는 frameId와 recipeVersion의 양의 하한을 설정합니다. 각 하한은 기존 값보다 줄일 수 없으며, 이후 도착하는 프레임이 현재보다 오래된 프레임이나 설정으로 생성되었는지 판단할 때 사용합니다. 이 호출은 프레임을 직접 표시하거나 검사 결과를 변경하지 않습니다.

예를 들어 하한이 (10,3)이면 프레임 11과 레시피 3은 두 하한을 만족하지만 프레임 11과 레시피 2는 오래된 레시피입니다. CanAccept는 수락 가능 여부만 확인하고 TryAccept는 조건을 만족할 때 원자적으로 수락해 하한을 갱신합니다. 두 값 중 하나만 비교해서는 안 됩니다.
