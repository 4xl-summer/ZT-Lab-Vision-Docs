static ZVision.InspectVariationModel Direct(ZVision.ZImage reference, ZVision.ZImage variation, ZVision.ZImage mask = null)

기준 영상과 변동 영상으로 직접 모델을 만듭니다.

인자

reference: 기준 Gray 영상입니다.

variation: 음이 아닌 변동 Gray 영상입니다.

mask: 선택적 비영 Gray8 마스크입니다.

반환: 호출자가 해제할 모델입니다.

관련 입력의 확인된 조건

reference.Origin: ROI의 글로벌 픽셀 원점입니다.

reference.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

인자별 입력 조건

인자형식역할과 조건
referenceZVision.ZImage기준 Gray 영상입니다.
variationZVision.ZImage음이 아닌 변동 Gray 영상입니다.
maskZVision.ZImage선택적 비영 Gray8 마스크입니다.

기준과 편차로 모델 구성

InspectVariationModel.Direct 호출은 기준 Gray 영상과 음이 아닌 변동 Gray 영상, 선택적 Gray8 마스크로 모델을 만듭니다. 입력 영상의 형식, 크기와 원점이 대응해야 같은 위치의 값을 비교할 수 있습니다.

이 호출은 표본 집합을 새로 학습하지 않습니다. 기준과 편차가 실제 검사 대상의 위치와 밝기 단위를 표현하는지 확인하고 반환 모델은 사용 후 Dispose합니다.
