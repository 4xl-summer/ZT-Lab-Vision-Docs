static ZVision.ShapeCollectionResult FindCollection(ZVision.ZImage source, ZVision.TypedShapeEntry[] entries, ZVision.ShapeSearchOptions options, System.UInt64 totalBudget, System.UInt64 maxResults, ZVision.ZImage mask = null, ZVision.ShapeOverlapMode overlap = ZVision.ShapeOverlapMode.Disabled, System.Double maxIou = 1)

여러 형상 모델을 공동 예산으로 검색합니다.

인자

source: 검색 영상입니다.

entries: 모델과 식별자 배열입니다.

options: 형상 검색 설정입니다.

totalBudget: 공동 후보 예산입니다.

maxResults: 최대 결과 수입니다.

mask: 선택적 마스크입니다.

overlap: 겹침 억제 범위입니다.

maxIou: 허용 교집합 비율입니다.

반환: 독립 검색 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ShapeCollectionResult.Evaluated: 평가한 후보 개수입니다.

ShapeCollectionResult.Incomplete: 모든 모델을 끝까지 처리하지 못했는지 나타냅니다.

호출과 결과 해석

타입이 지정된 여러 확장 형상 모델을 공동 예산으로 검색합니다. entries의 고유 id가 반환 항목을 입력 모델에 연결하고 ShapeSearchOptions는 공통 검색 조건을 정합니다. totalBudget과 maxResults는 각각 평가 작업과 반환 개수의 한도입니다. overlap과 maxIou를 포함해 실행 조건을 같이 확인합니다.

입력별 확인

입력의미
source검색 영상입니다.
entries모델과 식별자 배열입니다.
options형상 검색 설정입니다.
totalBudget공동 후보 예산입니다.
maxResults최대 결과 수입니다.
mask선택적 마스크입니다.
overlap겹침 억제 범위입니다.
maxIou허용 교집합 비율입니다.

반환값

독립 검색 결과입니다.
