ZVision.ZImage ToGray()

RGB/BGR 색상 성분에 0.299R + 0.587G + 0.114B를 적용합니다. 알파는 무시하며 8비트 색상은 Gray8, 16비트 색상은 Gray16, RGBF32는 GrayF32를 반환합니다.

반환: 호출자가 Dispose해야 하는 새 소유 영상입니다.

호출에 필요한 입력

RGB/BGR 입력을 단일 회색 영상으로 변환합니다.

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

호출자가 Dispose해야 하는 새 소유 영상입니다.

입력과 결과 해석

색상 영상을 밝기 영상으로 변환합니다. 색상 채널의 순서와 출력 형식을 먼저 확인하세요. 서로 다른 색상이 비슷한 밝기로 변할 수 있으므로 색상 차이를 모두 유지한다고 가정하지 않습니다.
