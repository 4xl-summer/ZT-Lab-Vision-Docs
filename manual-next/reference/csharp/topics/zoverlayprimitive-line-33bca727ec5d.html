static ZVision.Display.ZOverlayPrimitive Line(ZVision.Display.ZDisplayPoint start, ZVision.Display.ZDisplayPoint end, System.UInt32 rgba = 4278190335, System.Double strokeWidth = 1)

선분을 만듭니다.

인자

start: 시작점입니다.

end: 끝점입니다.

rgba: 색상입니다.

strokeWidth: 선 두께입니다.

반환: 불변 선분입니다.

관련 입력의 확인된 조건

start.X: 점의 가로 좌표입니다.

start.Y: 점의 세로 좌표입니다.

사용 순서와 결과 해석

시작점과 끝점을 영상 로컬 픽셀 중심 좌표로 받는 불변 선분을 만듭니다. rgba는 0xRRGGBBAA이고 기본값은 불투명 빨강, strokeWidth 기본값은 1이며 유한한 양수여야 합니다. SVG로 저장할 때 두 점에 각각 0.5가 더해져 픽셀 중심에 놓입니다. 생성된 도형을 ZOverlayScene에 넣어 내보냅니다.

입력의미
start시작점입니다.
end끝점입니다.
rgba색상입니다.
strokeWidth선 두께입니다.

반환값

불변 선분입니다.
