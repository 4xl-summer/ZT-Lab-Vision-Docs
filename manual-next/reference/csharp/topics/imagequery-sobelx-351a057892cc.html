SobelX의 사용과 결과 해석

X 방향 성분은 수평 좌표에 따른 밝기 변화를 나타냅니다. 같은 위치의 Y 방향 변화와는 별개입니다. 영상의 밝기 변화 방향을 측정합니다. X와 Y 방향의 성분은 서로 다르며 기울기 크기는 방향 부호 자체가 아닙니다. 경계 위치와 강도를 원본 영상에서 함께 확인합니다.

사용 순서와 결과 판독

SobelX는 현재 ImageQuery에 수평 좌표 방향의 Sobel 미분을 추가하고 같은 빌더 객체를 반환합니다. 이 단계는 계획을 갱신하며 실제 영상 처리는 Run 또는 Execute에서 수행합니다. 별도의 독립 계획으로 분기하려면 Clone을 사용해야 하며 같은 빌더의 별칭은 동일한 계획을 봅니다.

처리는 Gray8, Gray16 또는 유한한 GrayF32 영상을 받아 부호 있는 GrayF64 미분을 만듭니다. 수평 방향 커널은 각 행의 오른쪽 값에서 왼쪽 값을 빼고 가운데 행에 두 배 가중치를 줍니다. 예를 들어 세 행 모두 왼쪽이 10, 오른쪽이 20인 내부 위치에서는 (20−10)+2×(20−10)+(20−10)=40입니다.

ROI 경계에서는 해당 ROI의 가장자리 값을 복제해 이웃을 만듭니다. 양의 결과는 이 커널에서 오른쪽 방향으로 밝기가 증가하는 경우이며 음수는 반대 방향을 나타냅니다. 기울기 크기는 부호를 가진 X 성분과 다르므로 방향이 필요하면 SobelX 자체를 확인합니다. 실행 결과의 영상 핸들은 반환 계약에 따라 별도로 관리합니다.
