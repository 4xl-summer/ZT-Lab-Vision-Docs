ZVision.PreparedOcrResult PrepareOcr(ZVision.OcrRegionSpec spec)

Gray8 이미지의 지정 영역을 회전하고 선택적으로 반전 및 정규화합니다.

인자

spec: 처리에 사용할 설정입니다.

반환: 사용 후 Dispose해야 하는 OCR 준비 결과입니다.

관련 입력의 확인된 조건

spec.LightText: 밝은 글자를 어두운 글자로 만들기 위해 픽셀을 반전할지 나타냅니다.

spec.Normalize: 단색이 아닌 영역의 픽셀 범위를 0~255로 선형 정규화할지 나타냅니다.

spec.X: 현재 이미지 기준 영역의 왼쪽 x 좌표입니다.

spec.Y: 현재 이미지 기준 영역의 위쪽 y 좌표입니다.

spec.Width: 영역 또는 준비 영상의 너비(픽셀)입니다.

spec.Height: 영역 또는 준비 영상의 높이(픽셀)입니다.

spec.QuarterTurns: 시계 방향 90도 회전 횟수입니다. OCR 영역은 0~3입니다.

PreparedOcrResult.Info: 현재 정보의 스냅샷을 반환합니다.

PreparedOcrResult.Image: 별도 소유 이미지 핸들을 반환합니다. 사용 후 Dispose해야 합니다.

인자별 입력 조건

인자형식역할과 조건
specZVision.OcrRegionSpec처리에 사용할 설정입니다.

문자 인식 영역 준비

C#의 ZImage 호출은 현재 영상에 이 처리를 적용합니다. OcrRegionSpec으로 사각형 ROI, 90도 단위 회전, 밝은 문자 여부 및 정규화를 지정해 OCR에 사용할 영역을 준비합니다. 반환 정보의 크기와 대비, 준비 좌표에서 입력 로컬 및 전역 좌표로의 변환을 함께 확인합니다.

현재 영상에서 얻은 결과의 해석에서는 회전된 준비 영상의 모서리를 원본에 표시할 때 변환을 적용해야 합니다. 동일한 폭과 높이라는 이유만으로 좌표계가 같다고 추정하지 않습니다. 준비 영상 생성은 문자 판독 자체가 아니며 인식에는 설정과 엔진이 별도로 필요합니다.

반환 형식이 소유 자원인 경우 사용 후 Dispose합니다. 오류와 실제로 계산된 빈 결과를 구별하고 입력과 결과를 같은 검사 실행의 조건에 연결합니다.
