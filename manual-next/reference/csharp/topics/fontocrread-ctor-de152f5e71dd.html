사용과 결과 해석

기본 문자 판독 결과 객체를 만듭니다. 문자 목록은 비어 있고 점수와 수락 여부는 기본값이며 위치 판정은 null입니다.

실제 판독의 Score는 모든 문자 유사도의 산술 평균이고 확률이 아닙니다. RotationDegrees는 선택된 시계 방향 각도이며 위치 조건을 지정하지 않으면 LayoutAccepted는 null입니다.

기본값과 실제 판독

기본 생성자는 빈 판독 결과 객체를 만들며 영상을 처리하지 않습니다. 실제 결과는 글꼴 모델의 Read로 얻고, 반환이 null일 수 있으므로 문자 결과가 있는지 먼저 확인해야 합니다. Glyphs는 줄 순서로 정리된 문자 결과의 복사 배열입니다.

Score는 모든 글자의 템플릿 유사도를 산술 평균한 값입니다. 예를 들어 두 문자의 점수가 0.8과 0.6이면 평균은 0.7입니다. 이는 확률이 아닙니다. RotationDegrees는 선택된 시계 방향 각도이며, 위치 기대값을 지정하지 않았다면 LayoutAccepted는 null입니다.
