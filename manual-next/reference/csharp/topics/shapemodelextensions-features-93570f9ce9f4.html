static ZVision.ShapeModelFeature[] Features(ZVision.AdvancedMatchModel model)

형상 특징 좌표와 법선을 복사합니다.

인자

model: 소유한 형상 모델입니다.

반환: 수명 독립적인 특징 배열입니다. 연결 관계는 포함되지 않습니다.

관련 입력의 확인된 조건

model.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

호출 맥락과 결과 해석

학습 형상 모델의 기준점 상대 로컬 위치와 방향을 ShapeModelFeature 배열로 얻습니다. 이 표본은 원래 contour의 연결 정보가 아니며 검색 영상의 전역 좌표도 아닙니다.

학습 조건을 달리한 모델의 특징 위치와 방향을 비교하거나 검색이 기대와 다른 이유를 살필 때 사용할 수 있습니다. 이 정적 메서드에는 검사할 AdvancedMatchModel을 model로 명시합니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
model소유한 형상 모델입니다.
