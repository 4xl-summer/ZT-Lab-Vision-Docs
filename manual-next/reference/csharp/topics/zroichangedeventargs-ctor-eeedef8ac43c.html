Constructor · 선언 타입 ZVision.Display.ZRoiChangedEventArgs

C#
ZRoiChangedEventArgs(System.Nullable<ZVision.Display.ZPixelRect> roi)

영역 변경 이벤트를 생성합니다.

인자

roi: 새 선택 영역입니다.

사용 순서와 결과 해석

영역 변경 이벤트에 선택된 ZPixelRect 또는 null을 담습니다. null은 현재 전달된 영역이 없음을 표현할 수 있으며 유효한 사각형은 양의 셀 너비·높이를 갖습니다. 좌표는 영상 로컬이므로 이벤트 수신자가 원본 영상의 다른 좌표계에 적용할 때 원점을 확인합니다.

입력별 확인

입력의미
roi새 선택 영역입니다.

선택 없음과 사각형 경계

ZRoiChangedEventArgs는 이벤트의 roi 필드에 ZPixelRect 값 또는 null을 저장합니다. null은 선택된 영역이 없음을 표현하며 크기 0의 사각형과 같은 값이 아닙니다. 생성자는 기존 ZPixelRect 값을 전달받을 뿐 현재 화면이나 영상 크기와 다시 교차 계산하지 않습니다.

정상 ZPixelRect는 음이 아닌 x,y와 양의 width,height를 사용합니다. 예를 들어 (2,3,4,2)는 x=2..5, y=3..4의 셀을 포함하고 오른쪽·아래 반열림 경계는 (6,5)입니다. 이 좌표는 영상 로컬이므로 원본의 다른 ROI 좌표계에 표시할 때 원점을 고려합니다.

화면 드래그에서 영역을 만드는 경우 ZViewport.CreateRoiFromScreen이 현재 배율과 이동을 역변환하고 영상 안의 셀 경계로 자릅니다. 그 결과가 null일 수 있으므로 이벤트 수신 측은 먼저 null을 확인한 후 사각형 크기를 읽습니다. 이벤트 인자는 영상 핸들을 소유하거나 픽셀을 복사하지 않습니다.
