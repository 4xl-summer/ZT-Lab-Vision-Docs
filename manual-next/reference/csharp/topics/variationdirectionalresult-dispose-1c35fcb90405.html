방향별 변동 결과의 수명

VariationDirectionalResult는 방향별 허용 임계 영상과 결함 마스크를 소유합니다. Dispose는 결과 핸들을 해제합니다. 이미 얻은 각 ZImage 핸들은 결과와 별개로 소유하므로 사용 후 각각 Dispose해야 합니다.

LowerThreshold는 어두움 허용 하한, UpperThreshold는 밝음 허용 상한입니다. DarkerMask는 하한보다 어두운 결함, BrighterMask는 상한보다 밝은 결함을 나타냅니다. 두 마스크의 위치를 밝기 값 자체나 서로 반대 방향의 결함과 혼동하지 않습니다.

예를 들어 한 위치의 입력이 하한보다 낮다면 어두운 방향의 마스크를 확인합니다. 상한 초과 여부는 밝은 방향의 별도 판단입니다. 입력, 두 임계 영상과 마스크를 같은 ROI에 표시한 뒤 획득한 영상과 결과를 각각 정리합니다.
