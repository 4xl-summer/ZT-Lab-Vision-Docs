Clone의 사용과 결과 해석

윤곽 쿼리의 동일한 계획을 독립 핸들로 복제합니다. 실제 윤곽은 각 계획의 실행 결과에서 확인합니다. 셀 경계 계획을 만든 후 Execute로 실제 계산을 수행합니다. 원본과 복제본의 수명 및 실행 결과의 항목 수를 각각 확인합니다.

호출과 결과 판독

ContourQuery.Clone은 셀 경계 추출의 같은 지연 계획을 독립 핸들로 복제합니다. Clone은 윤곽을 실제 계산하는 호출이 아니며 원본과 복제본은 별도로 Dispose해야 합니다. 실제 셀 경계 스냅샷은 Execute에서 얻습니다.

Execute는 ContourResult를 독립 스냅샷으로 복사하므로 실행 객체를 해제한 뒤에도 이미 얻은 Output은 유지됩니다. 경계의 점 목록과 결과 항목 수는 원래 입력 영상 및 연결 조건의 맥락에서 읽어야 합니다.

소유 계획 두 개와 각 실행 객체의 수명을 각각 기록하십시오. 복제본이 독립 핸들이라는 뜻은 원본 핸들과 정리를 분리할 수 있다는 뜻이며, 공개된 이 메서드가 복제 후 임의의 새 조건을 설정한다는 계약을 제공하는 것은 아닙니다.
