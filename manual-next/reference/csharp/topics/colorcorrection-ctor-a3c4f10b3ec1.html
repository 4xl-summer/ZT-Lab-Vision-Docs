ColorCorrection(System.Double[] matrix, System.Double[] bias)

선형 sRGB에 적용할 행 우선 3×3 행렬과 편향입니다. 생성 시 배열 값을 복사합니다.

인자

matrix: 행 우선 3×3 행렬의 9개 계수입니다.

bias: RGB 순서의 3개 편향 계수입니다.

사용과 결과 판독

선형 sRGB에 적용할 행 우선 3×3 행렬과 RGB 순서 편향을 복사해 구성합니다. 행렬은 9개, 편향은 3개 계수입니다. 인코딩된 sRGB 값과 선형 RGB 값은 다른 단계이므로 계수를 어느 단계에 적용하는지 확인하십시오.

항목확인된 역할
matrix행 우선 3×3 행렬의 9개 계수입니다.
biasRGB 순서의 3개 편향 계수입니다.

행렬과 편향은 각 출력 채널에 대한 선형 변환을 구성합니다. 예를 들어 항등 행렬과 0 편향은 선형 입력을 그대로 유지합니다. 생성 시 배열이 복사되므로 이후 원래 배열을 바꾸어도 이미 생성된 값의 변경으로 가정하지 않습니다.
