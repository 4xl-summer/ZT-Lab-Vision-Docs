Constructor · 선언 타입 ZVision.LocalDeformableOptions

C#
LocalDeformableOptions(ZVision.AdvancedMatchingOptions coarse, System.UInt64 gridX = 3, System.UInt64 gridY = 3, System.UInt64 iterations = 20, System.Double initialStep = 1, System.Double tolerance = 0.05, System.Double smoothness = 1, System.Double maxDeformation = 3, System.Double minQuality = 0, System.UInt64 maxWork = 100000000)

설정을 고정합니다. 품질은 1/(1+입력 밝기 단위 RMS)입니다.

인자

coarse: 기준점 NCC 격자입니다. pyramid 및 edge 전용 옵션은 지원하지 않습니다.

gridX: X 제어점 수 2..16입니다.

gridY: Y 제어점 수 2..16입니다.

iterations: 최대 반복 1..100입니다.

initialStep: 초기 이동 간격입니다.

tolerance: 정지 간격입니다.

smoothness: 이웃 제어점 차이 제곱 가중치입니다.

maxDeformation: 각 축별 변위 절댓값 제한 픽셀입니다.

minQuality: 최소 품질 0..1입니다.

maxWork: 추정 총 작업 상한입니다.

관련 입력의 확인된 조건

coarse.X: X 기준점 격자입니다.

coarse.Y: Y 기준점 격자입니다.

coarse.Angle: 각도 격자이며 라디안 단위입니다.

coarse.MinCoverage: 최소 가시 특징 비율입니다.

coarse.MinDistance: 결과 기준점 간 최소 거리입니다.

coarse.MaxMatches: 결과 최대 개수입니다.

coarse.CandidateBudget: 평가할 포즈의 최대 개수입니다.

coarse.TimeoutMilliseconds: 검색 시간 제한 밀리초이며 0은 제한 없음입니다.

coarse.Certainty: 조기 종료할 점수이며 null은 사용하지 않습니다.

coarse.MaskOffsetX: 검색 마스크 원점의 영상 로컬 X 좌표입니다.

coarse.MaskOffsetY: 검색 마스크 원점의 영상 로컬 Y 좌표입니다.

coarse.EitherPolarity: 명암 또는 에지 방향 반전을 허용합니다.

coarse.Subpixel: NCC 전체 격자에서 부픽셀 위치를 정밀화합니다.

coarse.Coarse: 위치 격자 coarse-to-fine 검색을 선택합니다.

coarse.PyramidLevels: 위치 격자의 정밀화 단계 수입니다.

coarse.RetainedCandidates: 각 단계에서 유지할 최대 후보 수입니다.

coarse.CoarseAcceptance: 거친 단계에서 허용할 최소 점수입니다.

coarse.MinGradient: 형상 검색 기울기 임계값입니다.

coarse.MaxOcclusionFraction: 형상 점수에서 제거할 최저 점수 비율입니다.

설정과 사용 흐름

거친 NCC 후보와 제어점 격자, 반복 및 변형 제약을 고정합니다. gridX와 gridY는 2~16, iterations는 1~100입니다. coarse에는 pyramid 및 edge 전용 옵션을 사용할 수 없습니다.

smoothness는 이웃 제어점 차이 제곱의 가중치이고 maxDeformation은 변형 상한입니다. 품질은 1/(1+입력 밝기 단위 RMS)이므로 밝기 범위가 다르면 같은 수치를 동일하게 해석하지 마십시오.
