합성 결과를 해제합니다.

수명과 사용 순서

합성 점 격자 객체를 해제합니다. 필요한 렌더링과 점 중심 조회를 먼저 수행하고 별도 반환된 영상은 해당 객체의 규칙에 따라 관리하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

합성 영상과 정답 중심

SyntheticDotGrid.Render는 물리 MetricGrid의 점을 Brown 렌즈와 기준판→카메라 자세로 투영하고 일정 픽셀 반경의 마커를 그립니다. 출력 크기는 양수이고 총 픽셀은 4000000 이하, 반경은 1..32픽셀, 격자점 수는 최대 4096입니다. 결과는 호출자가 Dispose하는 소유 객체입니다.

Image는 독립 소유 Gray8 영상을 반환하고 Centers는 투영 중심의 행 우선 Point2 배열을 복사합니다. 예를 들어 행이 2개, 열이 3개인 격자라면 중심 배열은 6개를 행 순서로 담습니다. 중심은 글로벌 픽셀 좌표이므로 ROI 로컬 좌표와 비교할 때 원점을 고려합니다.

필요한 Image와 Centers를 결과가 열린 동안 얻은 뒤 SyntheticDotGrid를 Dispose합니다. 이미 얻은 영상은 별도 핸들이므로 그 영상도 사용 후 Dispose해야 하고, 복사한 중심 배열은 관리 값입니다. 결과 해제는 생성된 영상을 파일로 저장하거나 카메라 보정을 실행하는 호출이 아닙니다.

Centers의 각 값은 기준판의 행·열 순서로 투영된 정답 중심입니다. 렌더된 영상에서 점을 다시 검출했다면 같은 행·열의 중심과 대응시켜 픽셀 차이를 계산할 수 있습니다. 예를 들어 정답 (10,20)과 검출 (11,20)의 차이는 x 방향 1픽셀이며, 검출 순서가 다르면 먼저 대응 관계를 확인해야 합니다.

비교할 때 확인

반경은 기준판의 물리 길이가 아니라 출력 영상에서 사용하는 픽셀 반경입니다. 격자의 PitchX와 PitchY는 물리 단위이므로 두 종류의 길이를 직접 같은 숫자로 비교하면 안 됩니다. 렌더 설정과 중심 배열을 같은 시험 사례로 묶어야 재검증이 가능합니다.
