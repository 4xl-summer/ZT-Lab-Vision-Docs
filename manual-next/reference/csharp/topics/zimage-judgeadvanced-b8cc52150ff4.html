JudgeAdvanced

Method · 선언 타입 ZVision.ZImage

C#
ZVision.AdvancedRegionDecision[] JudgeAdvanced(ZVision.ZImage score, ZVision.DefectSpec spec, ZVision.AdvancedRegionRule[] rules)

결함을 추출하고 여러 영역의 종류별 수와 점수·길이·폭을 각각 판정합니다.

인자

score: 같은 크기와 원점의 GrayF64 점수 영상입니다.

spec: 결함 추출과 종류 분류 옵션입니다.

rules: 영역별 독립 규칙입니다.

반환: 입력 규칙 순서의 판정 결과입니다.

관련 입력의 확인된 조건

spec.Connectivity: 결함 연결 요소의 연결 방식으로 4 또는 8입니다.

spec.MinArea: 포함할 결함의 최소 픽셀 수이며 같은 면적도 포함합니다.

spec.ScratchMinLength: 스크래치로 분류할 최소 긴 변 길이입니다. 픽셀 단위이며 등호를 포함합니다.

spec.ScratchMaxWidth: 스크래치로 분류할 최대 짧은 변 길이입니다. 픽셀 단위이며 등호를 포함합니다.

spec.ScratchMinAspect: 스크래치로 분류할 최소 길이 대 폭 비율로 1 이상이며 등호를 포함합니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
scoreZVision.ZImage같은 크기와 원점의 GrayF64 점수 영상입니다.
specZVision.DefectSpec결함 추출과 종류 분류 옵션입니다.
rulesZVision.AdvancedRegionRule[]영역별 독립 규칙입니다.

spec의 입력 값

필드의미와 조건
connectivity연결 요소 이웃 방식은 4 또는 8이며 기본값은 8입니다.
min_area포함할 최소 면적은 양의 픽셀 수이며 등호를 포함하고 기본값은 1입니다.
scratch_max_width스크래치 최대 짧은 변 길이, 유한한 양의 픽셀 값이며 기본값은 2입니다.
scratch_min_aspect스크래치 최소 길이 대 폭 비율로 유한한 1 이상이며 기본값은 4입니다.
scratch_min_length스크래치 최소 긴 변 길이, 유한한 양의 픽셀 값이며 기본값은 8입니다.

rules의 입력 값

필드의미와 조건
region결함 중심이 포함되는지 판단하는 사각형입니다. 오른쪽과 아래 경계는 제외합니다.
max_scratch_count영역에서 허용하는 스크래치 개수의 포함 상한입니다.
max_surface_count영역에서 허용하는 표면 결함 개수의 포함 상한입니다.
max_score개별 결함의 최대 점수에 대한 포함 상한이며 유한하고 0 이상입니다.
max_length개별 결함 길이의 포함 상한이며 유한하고 0 이상입니다.

결과와 사용 순서

입력 규칙 순서의 판정 결과입니다.

반환 값의 읽을 항목

항목의미
passed영역 내 각 결함 종류 개수 한계 이하이고 점수·크기 위반이 없을 때 참.
scratch_count중심이 영역 안에 있는 스크래치 수.
surface_count중심이 영역 안에 있는 표면 결함 수.
violating_indices영역 내 점수·길이·폭 한계를 초과한 입력 결함의 인덱스 튜플. 개수 초과만으로 인덱스가 추가되지는 않음.

입력과 결과 해석

결함을 추출하고 영역별 규칙에 따라 수, 점수, 길이 또는 폭을 판정합니다. 결과는 입력 규칙 순서에 대응하므로 각 판정과 해당 영역 규칙을 함께 읽어야 합니다.
