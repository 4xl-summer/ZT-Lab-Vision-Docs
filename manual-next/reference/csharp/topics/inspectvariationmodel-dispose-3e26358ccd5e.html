모델 핸들 해제

InspectVariationModel.Dispose 호출은 해당 모델이 소유한 핸들을 해제합니다. 사용이 끝난 모델에 대한 호출은 해제된 객체 오류 경로를 따르며 이미 별도로 얻은 영상도 각자의 소유 규칙에 따라 해제해야 합니다.

동일 객체의 호출과 종료를 애플리케이션의 실행 흐름에서 조정합니다. Dispose는 모델 결과를 저장하거나 검사 결과를 자동으로 확정하지 않습니다.

모델과 획득 영상 정리

Dispose는 InspectVariationModel이 소유하는 모델 핸들을 해제합니다. 사용이 끝난 뒤 호출하며 이미 닫힌 모델에 대한 후속 작업은 ObjectDisposedException 경로를 따릅니다. 모델이 작업에 쓰이는 동안 종료하지 않도록 애플리케이션의 종료 순서를 정합니다.

ModelImage로 이미 획득한 기준 또는 편차 영상은 호출자가 가진 별도 소유 핸들입니다. 모델을 닫는 것과 각 영상을 Dispose하는 것은 서로 다른 정리 단계입니다. 검사 결과와 그 결과에서 얻은 영상에도 각각의 수명 규칙이 적용됩니다.

예를 들어 기준 영상을 얻고 검사를 끝냈다면 획득 영상과 검사 결과를 각각 정리하고 마지막으로 모델을 닫을 수 있습니다. Dispose는 모델을 직렬화하지 않으므로 저장이 필요하면 종료 전에 Encode의 바이트 결과를 별도로 보관합니다.
