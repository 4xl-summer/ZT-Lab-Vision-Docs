C# API · StationaryDb2 · Shrunk

StationaryDb2.Shrunk 공개 계약

상위 목차로 돌아가기

Shrunk

Method · 선언 타입 ZVision.StationaryDb2

C#
ZVision.StationaryDb2 Shrunk(System.Double threshold, ZVision.ShrinkMode mode = ZVision.ShrinkMode.Soft)

세부 계수를 축소합니다.

인자

threshold: 임계값입니다.

mode: 축소 방식입니다.

반환: 독립 모델입니다.

관련 입력의 확인된 조건

mode.Hard: 임계치 이하를 제거합니다.

호출과 계산

세부 밴드에 임계 축소를 적용한 새 변환을 반환하고 기존 모델은 유지합니다. threshold는 유한한 0 이상의 값이며 mode는 Hard 또는 Soft를 선택합니다.

예를 들어 계수 3과 임계값 2에서 Hard는 3을 유지하고 Soft는 1로 줄입니다. 절댓값이 임계값 이하인 세부 계수는 0이 되며, 최종 근사 LL 밴드는 변경하지 않습니다.

항목Stationary DB2 계약
threshold유한하고 0 이상
Hard임계 이하 세부 계수 0
Soft절댓값에서 임계만큼 축소
근사 LL원래 값 유지

결과 해석

축소 결과는 선택한 변환과 밴드에 종속됩니다. 이 방법이 원하는 잡음만 제거한다고 가정하지 말고 새 모델을 역변환해 결함과 신호가 보존되는지 비교하십시오.

이 설명은 Stationary DB2의 Shrunk 호출에 적용됩니다. C#에서 얻은 독립 배열 또는 모델은 해당 소유 계약을 따르며 네이티브 소유자는 사용 후 Dispose합니다.
