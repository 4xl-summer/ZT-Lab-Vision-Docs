static ZVision.CompositeModelBuilder FromBytes(System.Byte[] data)

자체 형식의 고정/파생 모델을 복원합니다.

인자

data: 버전과 길이가 유효한 바이트 배열입니다.

반환: 독립된 새 빌더입니다.

이 호출의 입력과 객체 맥락

이 전용 형식으로 저장한 고정·파생 모델을 독립된 새 빌더로 복원합니다. data는 byte 배열이고 길이는 1~64000바이트여야 합니다. 잘못되었거나 알 수 없는 형식과 뒤에 남은 데이터는 오류입니다. 복원 후 빌더에서 프레임과 형상을 추가하거나 build하여 검증된 모델을 만들 수 있습니다.

사용 순서와 판독

data는 고정·파생 형상을 저장한 전용 형식이며 비어 있지 않고 64000바이트 이하여야 합니다. 잘못된 형식이나 남는 데이터는 실패하므로 파일을 읽었다는 이유만으로 복원 성공으로 처리하지 않습니다.

성공하면 원래 빌더와 독립된 새 빌더를 얻습니다. 여기에 형상과 공차를 더한 뒤 Build할 수 있습니다. 영상 측정 설정을 포함하는 아카이브는 ToArchiveBytes의 별도 형식이며 이 전용 고정·파생 형식과 구분해야 합니다.

복원 과정에서는 입력을 해석해 모델 요소들을 새 빌더에 구성합니다. 저장된 파일이 일부 잘렸거나 끝에 알 수 없는 데이터가 붙었다면 오류로 처리되므로, 원본 길이와 보관 출처를 함께 남기면 문제를 찾기 쉽습니다. 복원된 빌더에서 Build해 얻는 CompositeModel은 별도 소유 객체이므로 사용 후 Dispose해야 합니다.
