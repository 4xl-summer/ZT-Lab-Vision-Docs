void Dispose()

결과를 해제합니다.

수명과 사용 순서

SSIM 검사 결과를 해제합니다. 점수와 필요한 결과 영상을 먼저 확인하고 별도로 얻은 영상의 수명도 관리하십시오.

이 호출에는 반환값이 없습니다. C#에서 소유 객체의 사용 범위를 정하고 필요한 작업이 끝나면 해제하여 네이티브 자원을 정리하십시오. 해제된 객체는 이후 작업에 사용하지 않습니다.

사용 흐름과 판독 기준

SSIM 결과 객체는 유사도 검사에서 계산한 점수와 결함 관련 결과를 제공합니다. 해제하기 전에 필요한 점수와 결함 픽셀 수, 결과 영상의 의미를 확인합니다. 전체 점수와 결함 픽셀 수는 다른 값이며, 인접한 결함 픽셀 여러 개가 하나의 연결 성분일 수도 있으므로 픽셀 수를 물체 개수로 읽지 않습니다.

결과 영상이 필요하면 해당 접근자의 반환 계약에 따라 먼저 획득합니다. 독립 핸들로 얻은 영상은 결과 객체와 별도로 사용 수명을 관리하고, 더 이상 필요 없을 때 각 영상도 Dispose합니다. 결과를 닫은 다음에는 같은 SsimResult로 새 영상이나 점수를 요청하지 않습니다.

예를 들어 100픽셀 중 3픽셀이 결함으로 표시되면 결함 픽셀 수는 3입니다. 이 숫자만으로 세 개의 서로 떨어진 결함 물체가 있다고 결론 내릴 수는 없습니다. 결과에 사용한 기준 영상, 입력 영상과 검사 설정을 함께 기록해야 다른 실행의 점수나 마스크와 올바르게 비교할 수 있습니다. Dispose는 결과 핸들을 정리하며 추가 검사를 수행하지 않습니다.
