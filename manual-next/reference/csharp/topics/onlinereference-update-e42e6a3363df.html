C#
void Update(ZVision.ZImage[] images, System.UInt64 maxBatch)

동일 기하 표본을 하나의 원자적 배치로 누적합니다.

인자

images: 정상 영상 배열입니다.

maxBatch: 이 호출의 최대 영상 수입니다.

사용과 결과 해석

정상 영상 배치를 기존 픽셀별 평균과 분산 누적 상태에 더합니다. 빈 배치는 허용하지 않으며 각 영상의 형식, 크기, ROI 원점이 템플릿과 같고 값이 유한해야 합니다. 누적 영상 수는 생성 시 상한을 넘을 수 없습니다.

배치 전체가 검증된 후 결과가 반영되므로 도중에 유효하지 않은 영상이 있으면 이전 통계는 유지됩니다. 값 10과 14인 두 정상 표본이면 포함 픽셀 평균은 12입니다. C#에서는 이 호출의 maxBatch 상한도 확인합니다.

배치 판독

예를 들어 현재 4장이고 상한이 6장일 때 2장 배치는 수용 범위이지만 3장 배치는 상한을 초과합니다. 한 영상이라도 검증에 실패하면 배치 일부만 반영하지 않습니다.

항목확인할 내용
빈 배열허용되지 않습니다.
영상 형식템플릿의 Gray8·Gray16·GrayF32 형식과 같아야 합니다.
기하너비·높이·ROI 원점이 템플릿과 같아야 합니다.
픽셀 값읽은 값은 유한해야 합니다.
누적 한도기존 수와 배치 수의 합이 최대값 이하여야 합니다.
반영배치 전체가 유효할 때 통계를 갱신합니다.
