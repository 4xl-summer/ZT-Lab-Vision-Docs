Method · 선언 타입 ZVision.ExtendedShapeModel

C#
static ZVision.ExtendedShapeModel TrainContours(ZVision.Point2[][] contours, ZVision.Point2 reference, System.Double spacing)

순서가 있는 윤곽으로 형상 모델을 학습합니다.

인자

contours: 순서가 있는 학습 윤곽 배열입니다.

reference: 로컬 기준점입니다.

spacing: 윤곽에서 특징을 추출하는 간격입니다.

반환: 호출자가 해제할 모델입니다.

관련 입력의 확인된 조건

reference.X: 영역의 로컬 x 좌표입니다.

reference.Y: 영역의 로컬 y 좌표입니다.

호출 맥락과 결과 해석

방향이 있는 선분 경로에서 표본을 만들어 형상 모델을 학습합니다. 경로는 1개에서 128개이고 각 경로에는 2점 이상이 필요하며 전체 점 수는 최대 65536입니다. 영상의 픽셀 기울기를 추출하는 Train과 입력의 표현이 다릅니다.

reference는 템플릿 로컬 기준점이고 spacing은 유한한 양의 픽셀 간격입니다. 경로의 점 순서가 방향을 가진 경계를 정의하므로 입력을 구성할 때 의도한 순서를 유지합니다. 생성된 모델은 검색에 사용한 뒤 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
contours순서가 있는 학습 윤곽 배열입니다.
reference로컬 기준점입니다.
spacing윤곽에서 특징을 추출하는 간격입니다.

반환값 확인

호출자가 해제할 모델입니다.
