ZVision.AdvancedPlanes ToLab()

LCH를 Lab 평면으로 변환합니다.

반환: 호출자가 해제할 결과입니다.

이 호출의 입력과 객체 맥락

LCh 평면을 Lab 평면으로 바꾸어 새로운 AdvancedPlanes 소유 객체를 반환합니다. 입력 평면이 해당 변환의 색 공간 계약에 맞는지 확인하고, 결과의 Lightness, Second, Third로 각 평면을 읽습니다. 새 결과와 채널 영상은 각기 소유 핸들이므로 사용이 끝나면 각각 Dispose합니다. 원본 객체에 대해 값을 제자리에서 수정하는 호출로 해석하지 마세요.

사용 흐름과 판독 기준

ToLab은 입력 AdvancedPlanes가 보유한 LCh 성분을 Lab 성분으로 변환하여 새 소유 결과를 반환합니다. 입력 객체의 평면을 제자리에서 바꾸는 호출이 아닙니다. L은 명도이고 Ch의 C와 h는 색도의 크기와 각도를 표현합니다. 반환값에서는 Lightness, Second, Third 접근자로 Lab의 각 평면을 읽습니다.

색도 C와 각도 h의 관계를 이해하는 예로 h가 0인 경우 Lab의 두 색 성분은 각각 C와 0에 대응합니다. h는 도 단위이며 a=C·cos(h), b=C·sin(h)로 변환합니다. h의 숫자를 a 또는 b 채널 값으로 복사하는 것이 아닙니다. 색 공간이 잘못된 입력으로 다른 변환을 요청하지 않도록 현재 평면의 색 공간을 확인합니다.

원본 AdvancedPlanes와 반환 AdvancedPlanes는 각각 소유 객체입니다. 각 평면을 ZImage로 획득했다면 그 영상도 반환 계약에 따라 따로 관리하고, 사용한 원본·결과와 영상 핸들을 각각 해제합니다. 변환 전후를 비교할 때는 동일 픽셀 위치와 영상 크기를 사용하며 색 성분의 단위를 좌표 또는 픽셀 개수와 혼동하지 않습니다.
