사용을 마치는 순서

확장 NCC 모델이 보유한 내부 모델 자원을 해제합니다. 포즈 격자 검색이나 원근·전단 검색을 모두 마친 뒤 호출합니다. 검색에 사용한 기준점과 옵션은 결과를 해석할 때 필요하므로 모델을 정리하는 시점과 별개로 기록합니다.

NCC 모델과 포즈 검색

확장 NCC 모델은 템플릿의 선택 표본과 로컬 기준점을 사용합니다. 검색 결과 위치는 템플릿 좌상단이 아니라 학습 시 지정한 기준점의 검색 위치입니다. 포즈 격자, 원근 또는 전단 검색이 더 이상 필요하지 않을 때 모델을 Dispose합니다.

검색 설정의 후보 예산은 평가할 포즈 수를 제한하고 최대 결과 수는 반환 개수를 제한합니다. 모델을 해제하기 전에 필요한 보고서를 얻고 기준점, ROI 및 설정을 결과와 함께 기록하면 나중에 좌표와 종료 상태를 해석할 수 있습니다.
