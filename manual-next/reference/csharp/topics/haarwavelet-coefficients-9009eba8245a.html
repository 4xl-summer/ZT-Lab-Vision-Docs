이 호출의 입력과 객체 맥락

Haar 변환 모델의 행 우선 계수를 독립 배열로 복사합니다. 배열을 수정해도 기존 모델을 제자리에서 변경하는 호출이 아닙니다. 계수의 배치와 변환 크기를 모델 정보와 함께 해석하고, 다른 계수의 모델이 필요하면 해당 생성 경로를 사용하세요. 숫자 배열은 Dispose 대상이 아니지만 모델은 별도로 Dispose합니다.

Haar 계수 복사

Coefficients는 HaarWavelet의 계수를 독립 double 배열로 복사합니다. 반환 배열을 수정해도 기존 웨이블릿 모델이 제자리에서 바뀌지 않습니다. 모델의 크기와 행 우선 순서를 유지해 계수를 해석해야 합니다.

예를 들어 폭 4의 행 우선 배열에서 x=1, y=2는 인덱스 9입니다. 이 인덱스가 어떤 저주파 또는 세부 계수 영역에 속하는지는 변환 수준과 배치에 따라 읽으며 원본 영상의 동일 위치 밝기라고 가정하지 않습니다.

계수를 변경한 새 모델이 필요하면 WithCoefficients에 전체 크기의 유한한 값을 전달합니다. 배열 길이가 맞지 않으면 오류이고 기존 모델과 반환 모델은 독립 소유입니다. Shrunk는 최종 LL을 보존하면서 세부 계수를 선택한 방식으로 축소하는 별도 작업입니다.

모델을 사용한 뒤 Dispose하고 획득한 계수 배열은 관리 메모리로 유지할 수 있습니다. 역변환으로 얻는 ZImage는 별도의 소유 영상이므로 역시 사용 후 Dispose합니다. 닫힌 모델에서 새 계수 복사를 요청하는 오류를 처리합니다.
