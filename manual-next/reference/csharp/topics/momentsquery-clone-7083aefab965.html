ZVision.MomentsQuery Clone()

모멘트 계획을 독립 핸들로 복제합니다.

반환: 원본과 별도로 Dispose해야 하는 계획입니다.

사용과 결과 해석

현재 모멘트 계획을 독립 핸들로 복제합니다. 반환된 계획은 원본과 별도로 Dispose해야 하며 분기한 후 각 계획의 수명을 독립적으로 관리할 수 있습니다.

예를 들어 한 계획을 보존하면서 다른 계획을 사용하려면 복제한 핸들을 사용합니다. Clone은 모멘트 계산 결과를 반환하는 호출이 아니며 실제 계산은 Execute에서 수행합니다.

사용 흐름과 판독 기준

Clone은 현재 모멘트 쿼리의 계획을 독립 핸들로 복제합니다. 반환형은 MomentsQuery이며 실제 모멘트 값을 담은 MomentsResult가 아닙니다. 원본을 보존한 상태에서 다른 계획을 사용해야 할 때 복제된 핸들을 별도로 관리할 수 있고, 모멘트 계산은 각 계획의 Execute에서 수행합니다.

모멘트 결과는 영역의 면적과 중심, 중심 모멘트 등 입력 성분의 분포를 설명합니다. 동일한 계획에서 시작하더라도 이후 입력이나 선택 조건이 다르면 실행 결과도 다를 수 있으므로 어떤 쿼리와 ROI에서 얻었는지 기록합니다. 예를 들어 한 ROI의 로컬 중심 (2,3)을 다른 ROI의 같은 숫자와 비교하려면 각각의 원점을 먼저 맞춰야 합니다.

원본과 복제본은 각기 소유한 쿼리 핸들이므로 사용이 끝난 순서대로 각각 Dispose합니다. 결과 스냅샷의 수명은 실행 결과의 계약으로 판독하며 복제된 계획 핸들과 같은 객체로 취급하지 않습니다. 한 쪽을 해제한 뒤에는 닫힌 핸들로 Execute를 다시 요청하지 않습니다.
