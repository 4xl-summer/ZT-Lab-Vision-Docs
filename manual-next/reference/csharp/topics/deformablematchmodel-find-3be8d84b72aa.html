ZVision.DeformableModelReport Find(ZVision.ZImage source, ZVision.AdvancedMatchingOptions options, ZVision.ZImage mask = null)

학습 변형 모델들을 공유 예산으로 실제 영상에서 찾습니다.

인자

source: 검색 영상입니다.

options: 검색 격자와 예산입니다.

mask: 선택적 검색 마스크입니다.

반환: 후보, 학습 변형 번호, 종료 진단입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

DeformableModelReport.Evaluated: 평가한 포즈 수입니다.

DeformableModelReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

학습할 때 명시한 변형 모델들을 검색 영상에 적용하며 예산과 시간을 공유합니다. options는 확장 NCC 검색 설정이고 mask는 선택 검색 마스크입니다. 변형 하나마다 독립적으로 무제한 검색하는 것으로 해석하지 않습니다.

반환된 독립 보고서에서 변형 인덱스와 매치를 함께 읽습니다. 같은 포즈라도 어느 변형 모델에 해당하는지에 따라 해석이 달라지므로, 학습 때 사용한 deformation 목록과 인덱스 순서를 기록해 둡니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options검색 격자와 예산입니다.
mask선택적 검색 마스크입니다.

반환값 확인

후보, 학습 변형 번호, 종료 진단입니다.
