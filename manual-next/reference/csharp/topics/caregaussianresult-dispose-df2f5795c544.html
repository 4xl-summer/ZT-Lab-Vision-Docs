결과를 해제합니다. 획득한 영상은 따로 해제합니다.

이 호출의 입력과 객체 맥락

CareGaussianResult.Subsample: 결과와 계산 마스크를 동일한 간격으로 축소 표본화합니다.

CareGaussianResult.Shifted: 정수 결과의 비트를 이동합니다.

CareGaussianResult.FilteredImage: Gaussian 필터 출력입니다.

CareGaussianResult.ComputedMask: 필터 적용 위치가 255, 입력 복사 위치가 0인 마스크입니다.

사용 순서와 결과 해석

CareGaussianResult는 선택된 표본으로 계산한 Gaussian 결과와 계산 여부 마스크를 보유합니다. 필터 적용이 실제로 수행된 위치는 ComputedMask에서 255이고 입력을 복사한 위치는 0입니다. 따라서 출력 픽셀 값만 보고 필터 계산이 이루어졌는지 판단하지 않습니다.

FilteredImage와 ComputedMask에서 얻은 ZImage는 각각 별도 소유 핸들입니다. Subsample은 두 영상을 같은 간격으로 축소한 새 결과를, Shifted는 정수 결과에 비트 이동을 적용한 새 결과를 만듭니다. 원래 결과와 새 결과, 각 결과에서 취득한 영상은 각자의 Dispose 책임이 있습니다.

예를 들어 마스크가 0인 위치의 출력이 이웃과 비슷해 보여도 그 값은 입력 복사일 수 있습니다. 처리 결과를 해석할 때 필터 출력과 계산 여부를 같은 좌표로 묶어 확인하세요. 결과를 Dispose하면 그 객체에서 새 영상을 취득하지 말고, 이미 취득한 영상은 사용을 마친 뒤 따로 해제합니다.

예를 들어 3개 위치의 ComputedMask가 [255,0,255]라면 가운데 위치는 필터 계산 결과가 아니라 입력 복사로 표시된 위치입니다. 이 세 위치의 출력 밝기만 읽으면 처리 여부를 놓칠 수 있습니다. 결과에서 취득한 마스크와 영상의 같은 좌표를 비교하고, Subsample로 새 결과를 만들었다면 새 격자에 맞춰 다시 읽으세요.

예를 들어 가로와 세로를 각각 다른 간격으로 Subsample해도 출력 영상과 계산 여부 마스크는 같은 새 격자에서 해석해야 합니다. 이전 결과의 원본 좌표 인덱스를 새 결과의 인덱스로 그대로 취급하면 위치가 어긋날 수 있습니다. 원래 결과와 축소 결과는 별도의 결과 객체이며 각자 취득한 영상도 각각 정리합니다.
