Mosaic

Method · 선언 타입 ZVision.MultiRegistration

C#
ZVision.RegistrationMosaic Mosaic(System.Double scale = 1, ZVision.MosaicOverlap overlap = ZVision.MosaicOverlap.Mean)

합집합 캔버스에 정렬 영상을 합성합니다.

인자

scale: 공통 픽셀당 출력 배율입니다.

overlap: 겹침 선택 방식입니다.

반환: 해제할 소유 모자이크입니다.

관련 입력의 확인된 조건

overlap.First: 입력 순서 첫 표본입니다.

overlap.Last: 입력 순서 마지막 표본입니다.

overlap.Mean: 유효 표본의 산술 평균입니다.

RegistrationMosaic.ValidMask: 합성 영상의 유효 영역 마스크를 얻습니다.

사용과 결과 해석

정합 영상들을 합집합 캔버스에 합성합니다. 겹침 정책 First/Last는 입력 순서의 첫/마지막 유효 표본을, Mean은 유효 표본의 산술 평균을 사용합니다.

반환 모자이크는 소유 객체로 해제해야 합니다. 영상의 0 값과 데이터가 없는 위치를 구분하려면 ValidMask를 함께 확인하십시오.
