ZVision.ColorQuery Clone()

동일한 지연 계획을 독립 핸들로 복제합니다.

반환: 지연 실행할 쿼리입니다. 사용 후 Dispose해야 합니다.

사용과 결과 판독

색 변환 지연 계획의 독립 핸들을 만듭니다. 원본과 복제본은 각각 Dispose해야 합니다. 복제는 실행 결과를 만드는 일이 아니므로 실제 영상을 처리한 뒤 얻은 평면 결과를 따로 판독하십시오.

항목확인된 역할
반환지연 실행할 쿼리입니다. 사용 후 Dispose해야 합니다.

동일 계획의 복제본을 다른 수명으로 사용하려면 원본과 복제본을 각각 보관하고 각각 해제하십시오. 이후 획득하는 색 평면은 또 다른 결과 객체이므로 계획 핸들과 소유권을 혼동하지 않습니다.

사용 순서와 결과 확인

ColorQuery.Clone은 같은 색 변환 계획의 독립 소유 핸들을 만듭니다. 원본과 복제본은 별도로 Dispose해야 하며, Clone 자체는 HSV나 Lab 평면을 계산하지 않습니다. 실제 영상의 변환은 각 계획의 Execute에서 수행합니다.

ColorQuery 실행에서는 획득한 ColorPlanesResult와 실행 객체를 각각 해제해야 합니다. 평면 결과의 Info로 색 공간을 확인하고 GetChannel의 0~2 인덱스가 그 공간에서 어떤 성분을 뜻하는지 읽으십시오. HSV와 Lab은 세 채널을 갖더라도 성분의 의미가 다릅니다.

예를 들어 원본 계획과 복제본을 별도 처리 흐름에 두면 두 계획의 핸들을 각각 관리해야 합니다. 얻은 평면이나 ToRgb로 반환된 영상 또한 독립 소유이므로 계획 하나만 해제하고 모든 결과의 정리가 끝났다고 가정하지 마십시오.
