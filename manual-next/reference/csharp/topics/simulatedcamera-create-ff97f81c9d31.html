C#
static ZVision.SimulatedCamera Create(ZVision.CameraSpec spec)

설정에 따라 새로운 모의 객체를 만듭니다. 반환 객체는 사용 후 Dispose해야 합니다.

인자

spec: 처리에 사용할 설정입니다.

반환: 사용 후 Dispose해야 하는 모의 카메라입니다.

관련 입력의 확인된 조건

spec.SourceId: 0이 아닌 소스 식별자입니다.

spec.ClockDomain: 0이 아닌 시계 도메인 식별자입니다.

spec.TickHz: 초당 장치 틱 수입니다.

spec.Capacity: 프레임 및 대기 트리거 큐의 용량으로 1~65536입니다.

spec.TriggerMode: 모의 카메라에서 프레임과 연결할 트리거 방식을 지정합니다.

상태와 처리 순서

CameraSpec을 검증하고 연결되지 않은 모의 카메라를 만듭니다.

source_id, clock_domain, tick_hz는 0이 아니어야 하며 capacity는 1~65536입니다. trigger_mode와 함께 저장되고 생성 시 프레임 큐와 대기 트리거는 비어 있습니다.

결과 해석

예를 들어 capacity 2는 동시에 보관할 수 있는 큐 크기를 뜻합니다. 생성 자체는 장치에 연결하거나 취득을 시작하지 않습니다.

이 시뮬레이터의 상태와 시간은 호출자가 제공한 합성 이벤트에 기반합니다. 실제 카메라의 연결, 트리거 신호, 전송 지연 또는 하드웨어 인수 결과로 대신 해석하지 마십시오.
