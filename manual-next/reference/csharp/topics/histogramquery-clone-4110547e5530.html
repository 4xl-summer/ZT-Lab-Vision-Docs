Clone의 사용과 결과 해석

히스토그램 계획을 복제하고 각각 다른 조건을 적용해 비교할 수 있습니다. 계산 결과는 각 계획을 실행한 뒤 빈 범위와 선택 영역을 함께 해석합니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.

기준 계획을 독립 분기

HistogramQuery.Clone은 현재 히스토그램 계획을 독립적으로 변경할 수 있는 새 빌더로 복제합니다. Clone 호출 자체는 빈도 계산을 수행하지 않으며 원본과 복제본은 각각 사용 후 Dispose해야 합니다. 공통 영상 단계까지 구성한 후 두 분석 조건을 따로 비교할 때 사용할 수 있습니다.

예를 들어 동일한 영상에서 영역 A와 영역 B의 히스토그램을 비교하려면 공통 계획을 복제한 뒤 각 흐름의 실제 허용 설정에 맞춰 조건을 적용하고 각각 실행합니다. 각 결과의 빈 범위와 채널, 포함 픽셀 수가 다르면 같은 빈 번호의 수치도 다른 입력 집합을 나타낼 수 있습니다. 계산 결과는 계획을 실행한 이후에 얻습니다.

실행과 판독에서 확인

두 계획이 같은 시점에 같은 내용을 갖고 출발하더라도 이후의 계획 변경과 실행 결과를 하나의 객체로 취급하지 마세요. 반환되는 실행 결과와 독립 캡처가 있다면 그 소유 조건도 별도로 확인합니다. 숫자 배열을 비교할 때는 빈 수와 하한·상한을 함께 기록하고, 빈도 합계와 빈의 개수를 혼동하지 않습니다.
