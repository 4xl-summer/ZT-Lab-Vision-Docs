Select

Method · 선언 타입 ZVision.AdvancedContours

C#
System.Boolean Select(System.UInt64 index, ZVision.AdvancedDiagnosticRange range)

결함이 모든 포함 범위를 만족하는지 판정합니다.

인자

index: 결함의 0 기반 번호입니다.

range: 양끝 포함 진단 범위입니다.

반환: 모든 범위를 만족하면 true입니다.

관련 입력의 확인된 조건

range.MinFeret: 최소 Feret 지름입니다.

range.MaxFeret: 최대 Feret 지름입니다.

Select의 사용과 결과 해석

조건에 맞는 윤곽을 선택해 후속 처리에 넘깁니다. 선택 전 전체 결과와 선택 후의 개수를 비교하고 각 윤곽의 결함 소속을 함께 추적합니다. 결함 번호와 그 결함에 속한 윤곽 번호는 다른 인덱스입니다. 윤곽은 위치를 가진 순서 있는 에지들의 집합이므로 단순한 결함 면적이나 경계 사각형과 구별해 사용합니다.

항목이 호출에서 확인할 내용
index결함의 0 기반 번호입니다.
range양끝 포함 진단 범위입니다.
range.MinFeret최소 Feret 지름입니다.
range.MaxFeret최대 Feret 지름입니다.
반환모든 범위를 만족하면 true입니다.
