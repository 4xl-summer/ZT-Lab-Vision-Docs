네이티브 텐서 핸들을 해제합니다.

이 호출의 입력과 객체 맥락

AdvancedTensor.Read: 텐서의 형상과 형식에 맞는 새 값 배열을 복사합니다.

사용 순서와 결과 해석

AdvancedTensor가 보유한 네이티브 텐서 핸들을 해제합니다. Tensor의 Read는 열린 객체에서 축 크기를 out shape로 받고 원소 형식에 맞는 새 배열을 반환합니다. 사용 중인 모델의 입력과 출력 순서를 확인한 후 필요한 shape와 값을 복사해 두세요.

예를 들어 shape가 [2,3]이면 값 배열에는 6개 원소가 해당 텐서 순서로 들어갑니다. 배열 길이만 보고 어느 축이 채널이나 공간 축인지는 정할 수 없습니다. 반환 배열은 float, int, sbyte 또는 byte이며 실제 반환 형식을 확인해 읽어야 합니다.

Read의 shape와 값 배열은 새 관리 배열이고 AdvancedTensor는 별도로 Dispose할 소유 핸들입니다. 읽기를 마친 뒤 텐서를 해제해도 이미 복사한 배열을 값으로 보관할 수 있습니다. 반대로 해제한 텐서에서 추가 Read를 호출하지 않도록 객체의 사용 범위를 명확히 정하세요.

예를 들어 Read에서 shape=[2,3]과 float 배열을 받았다면 6개 float 값의 묶음입니다. 이후 텐서를 해제해도 이미 복사된 관리 배열을 출력 기록에 사용할 수 있습니다. 단 배열의 각 축이 의미하는 배치는 네이티브 모델의 입력·출력 정의에서 확인해야 하며, 단순히 두 차원의 이름을 임의로 붙여서는 안 됩니다. 값의 수치 형식도 함께 확인해 부호가 있는 정수 배열과 바이트 배열을 같은 입력 표현으로 혼동하지 마세요.

예를 들어 세 축 형상 [1,2,3]도 원소는 여섯 개이지만 형상 [2,3]과 동일한 차원 구조는 아닙니다. 값 배열만 보관하고 shape를 버리면 이 차이를 복구할 수 없습니다. Read의 out shape와 실제 배열 형식을 같이 보존하고, 텐서 객체에 더 이상 접근할 필요가 없어졌을 때 Dispose합니다.
