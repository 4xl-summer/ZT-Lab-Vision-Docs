void SetIncluded(System.UInt64 label, System.Boolean included)

Excludes or re-includes an existing stable label.

인자

label: Stable edge label.

included: True to include.

이 호출의 입력과 객체 맥락

안정된 양의 label로 지정한 에지를 포함 또는 제외합니다. 제외는 영구 삭제와 달리 같은 레이블로 다시 포함할 수 있습니다. 변경 뒤 현재 포함된 에지의 조밀 인덱스와 count는 달라질 수 있으므로 인덱스를 오래 보관하지 말고 레이블을 사용하세요. 실제 삭제는 Delete의 별도 동작입니다.

레이블별 포함 상태

SetIncluded(ulong label, bool included)는 지정한 에지 레이블의 포함 상태를 바꿉니다. label은 목록에서 보이는 0 기반 인덱스와 구별해야 합니다. 포함 상태 변경은 반환 영상 생성이 아니라 쿼리 결과의 선택 조건을 바꾸는 작업입니다.

예를 들어 레이블 12인 에지를 제외하려면 해당 레이블과 false를 지정합니다. 다시 포함할 때는 같은 레이블과 true를 사용합니다. 현재 순번이 12번째인 에지가 레이블 12라는 보장은 없으므로 결과의 레이블과 조회 모드를 먼저 확인합니다.

항목확인할 내용
label대상 에지의 레이블
included=true해당 레이블을 포함
included=false해당 레이블을 제외
목록 인덱스레이블과 다른 선택 기준
Dispose 후쿼리 사용 오류
검증변경 전후 에지 목록 비교

변경 전후의 포함 목록과 에지 경로를 같은 영상에 표시해 선택이 의도대로 바뀌었는지 확인합니다. 쿼리가 Dispose되었으면 Check에서 오류가 발생합니다. 포함 설정과 에지 추출의 커널·임계값은 다른 단계이므로 함께 기록합니다.

적용과 판독을 더 살펴보기

포함 상태를 바꾸기 전에 에지의 레이블과 현재 조회 결과를 확인합니다. 인덱스 모드에서 보이는 목록 순번은 필터나 정렬 이후 달라질 수 있으므로 레이블과 같은 숫자라고 보장되지 않습니다. 특정 레이블을 제외한 다음 다시 결과를 조회하면 선택 목록의 차이를 확인할 수 있습니다. 이 설정은 원본 영상 픽셀을 수정하는 작업이 아니며, 에지 추출 단계에서 정한 가우시안 커널과 낮음·높음 임계값을 자동으로 바꾸지도 않습니다. 제외한 에지가 결함 경계였는지 원본과 경로를 겹쳐 확인하고, 쿼리가 닫힌 후에는 설정을 다시 적용하려고 하지 않습니다.
