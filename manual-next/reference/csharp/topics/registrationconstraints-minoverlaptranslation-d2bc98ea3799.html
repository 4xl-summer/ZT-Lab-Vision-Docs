C#
static ZVision.InitialOverlapReport MinOverlapTranslation(ZVision.ZImage source, ZVision.ZImage reference, ZVision.AdvancedRegistrationOptions options, System.Double minOverlap, System.Double maxFraction, System.UInt64 maxWork = 100000000)

초기 겹침이 기준 이상일 때만 이동 정합을 실행합니다.

인자

source: 소스 영상입니다.

reference: 기준 영상입니다.

options: 축 정렬 이동 전용 설정이며 호출 중 변경하지 마세요.

minOverlap: 작은 영상 면적 기준 초기 겹침 하한입니다.

maxFraction: 장축 대비 최대 이동 비율입니다.

maxWork: 보수적 픽셀 작업 상한입니다.

반환: 겹침 미달이면 원래 행렬과 실패 상태 및 null 품질을 반환합니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

InitialOverlapReport.Matrix: 최적화 결과 또는 보존된 초기 행렬입니다.

InitialOverlapReport.InitialOverlap: 작은 영상 면적 기준 초기 겹침 비율입니다.

InitialOverlapReport.Status: 성공 또는 실패 사유입니다.

InitialOverlapReport.Quality: 실제 측정 품질입니다.

사용과 결과 해석

초기 겹침이 minOverlap 이상일 때 축 정렬 이동 정합을 수행합니다. 겹침 비율은 작은 영상의 면적을 기준으로 하며 maxFraction은 장축 대비 이동 상한입니다.

초기 겹침 조건을 만족하지 못한 상태와 실제 검색에서 일치하지 않은 상태는 보고서에서 구분하십시오. options는 이동 전용이며 호출 중 수정하지 않습니다.
