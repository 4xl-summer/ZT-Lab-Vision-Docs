ZPixelRect(System.Int32 x, System.Int32 y, System.Int32 width, System.Int32 height)

픽셀 영역을 만듭니다.

인자

x: 왼쪽 좌표입니다.

y: 위쪽 좌표입니다.

width: 양의 너비입니다.

height: 양의 높이입니다.

사용 순서와 결과 해석

영상 로컬 셀의 왼쪽 위 x, y와 양의 너비·높이를 저장합니다. x와 y는 음수가 아니어야 하며 끝점 덧셈은 checked로 검사됩니다. 예를 들어 (2,3,4,5)는 x=2,3,4,5의 네 셀과 y=3부터 7까지의 다섯 셀을 나타냅니다. 전체 영상 안에 드는지는 별도 영상 크기와 비교해야 합니다.

입력별 확인

입력의미
x왼쪽 좌표입니다.
y위쪽 좌표입니다.
width양의 너비입니다.
height양의 높이입니다.
