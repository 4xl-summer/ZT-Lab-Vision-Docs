ZVision.Point2 Transform(ZVision.Point2 point)

점에 변환을 적용합니다.

인자

point: 변환 또는 측정할 점입니다.

반환: 계산된 결과입니다.

관련 입력의 확인된 조건

point.X: 영역의 로컬 x 좌표입니다.

point.Y: 영역의 로컬 y 좌표입니다.

사용과 결과 해석

원본 점에 이 3×3 투영 행렬을 적용하고 동차 좌표의 세 번째 성분으로 나눈 목적지 점을 반환합니다. 변환이 유효하지 않거나 해당 점에서 분모가 유효하지 않으면 오류입니다.

예를 들어 항등 행렬은 (3,4)를 (3,4)로 유지합니다. 점의 좌표계와 변환을 추정한 좌표계를 일치시키고, ROI 로컬 점을 전체 영상 좌표로 착각하지 마십시오.

행동차 성분
첫째m00×x + m01×y + m02
둘째m10×x + m11×y + m12
셋째m20×x + m21×y + m22
