static ZVision.ClassifiedShapeModel Train(ZVision.ZImage template, ZVision.ZImage classes, ZVision.Point2 reference, System.UInt64 sampleStep = 1, System.Nullable<System.Double> threshold = null)

라벨 영상으로 형상 특징과 clutter 표본을 학습합니다.

인자

template: 학습 영상입니다.

classes: Gray8 라벨 0 ignored, 1 care, 2 clutter입니다.

reference: 로컬 기준점입니다.

sampleStep: 특징 표본 간격입니다.

threshold: 고정 gradient 하한 또는 자동 선택 null입니다.

반환: 해제할 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

클래스별 검색 해석

템플릿과 같은 크기의 Gray8 classes 영상을 사용해 0은 무시, 1은 care, 2는 clutter로 표시합니다. 두 영상의 원점은 (0, 0)이어야 합니다. care 에지로 형상을 만들고 clutter는 별도 위치 표본으로 저장합니다. 예를 들어 배경을 0, 필요한 윤곽을 1, 에지가 나타나지 않기를 바라는 영역을 2로 구분합니다. 학습 기준점은 템플릿 로컬 좌표입니다.
