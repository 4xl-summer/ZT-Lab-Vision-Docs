void Dispose()

소유한 네이티브 핸들을 해제합니다.

수명과 사용 순서

준비된 OCR 결과의 네이티브 핸들을 해제합니다. 필요한 준비 정보와 영상을 얻은 뒤 결과를 종료하십시오.

이 호출에는 반환값이 없습니다. C#에서 소유 객체의 사용 범위를 정하고 필요한 작업이 끝나면 해제하여 네이티브 자원을 정리하십시오. 해제된 객체는 이후 작업에 사용하지 않습니다.

준비 영상과 좌표 변환

PreparedOcrResult는 OCR용으로 준비된 결과와 그 정보를 소유합니다. Info는 준비 설정과 크기·대비·좌표 변환의 값 스냅샷이며 Image는 호출자가 별도로 Dispose해야 하는 준비 영상 핸들을 반환합니다. 이 객체를 문자 판독 문자열 자체로 해석하지 않습니다.

Info의 Contrast는 원본 Gray8 영역의 (최댓값−최솟값)/255입니다. 예를 들어 최솟값이 20, 최댓값이 220이면 대비는 200/255입니다. PreparedEdgesToLocal과 PreparedEdgesToGlobal은 준비 영상의 연속 픽셀 경계를 각각 입력 로컬 및 전역 좌표로 옮기는 변환이므로 대상 좌표계를 구분합니다.

필요한 Info와 Image를 결과가 열린 동안 얻고 PreparedOcrResult를 Dispose합니다. Image로 취득한 영상은 별도 소유이므로 그 영상도 사용이 끝나면 정리합니다. 이미 복사한 Info 값과 결과 핸들의 수명은 다르며, 실제 문자 인식은 별도 판독 결과에서 확인합니다.

준비 영상의 한 경계점을 입력 영상 위에 표시할 때는 먼저 로컬 변환을 쓸지 전역 변환을 쓸지 결정합니다. 원본 ROI에 대한 좌표와 원본 전체 영상에 대한 좌표를 혼용하면 같은 준비 점이 다른 위치에 표시될 수 있습니다. Info의 두 변환을 구분해 기록하면 이 차이를 추적할 수 있습니다.

항목의미와 확인
Info.Spec준비 처리에 사용한 설정
Info.Width / Height영역 또는 준비 영상의 픽셀 크기
Info.Contrast원본 Gray8 영역의 정규화 밝기 범위
PreparedEdgesToLocal준비 경계 → 입력 로컬
PreparedEdgesToGlobal준비 경계 → 입력 전역
Image / Dispose독립 소유 준비 영상 / 결과 핸들 정리

비교할 때 확인

Width와 Height는 준비된 처리 영역의 크기이며 문자 개수나 인식 신뢰도가 아닙니다. 영역의 밝기 대비가 낮은 경우 Info.Contrast를 통해 입력의 범위를 확인하고 준비 영상 자체를 별도 Image에서 살필 수 있습니다. 문자별 결과의 유무는 후속 판독 결과에서 확인합니다.
