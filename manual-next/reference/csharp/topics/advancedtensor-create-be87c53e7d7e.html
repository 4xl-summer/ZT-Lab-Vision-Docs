static ZVision.AdvancedTensor Create(System.UInt64[] shape, System.Array values)

형상과 값의 복사본으로 텐서를 만듭니다.

인자

shape: 텐서 각 축의 크기입니다.

values: float, int, sbyte 또는 byte 배열입니다.

반환: 호출자가 해제할 텐서입니다.

이 호출의 입력과 객체 맥락

shape의 축 크기와 float, int, sbyte 또는 byte 배열을 복사해 독립 텐서를 만듭니다. 예를 들어 형상이 2×3이면 값 6개가 해당 텐서 순서로 대응해야 합니다. 입력 배열의 형식으로 원소 종류가 선택되며 다른 배열 형식은 오류입니다. 반환 텐서는 사용 후 Dispose합니다.

형상과 값의 복사

Create는 shape의 축 크기와 values의 원소를 복사해 독립 AdvancedTensor를 만듭니다. 허용 배열 형식은 float, int, sbyte 또는 byte이며 배열 형식이 텐서 원소 종류를 결정합니다. shape나 values가 null이거나 지원하지 않는 값 배열 형식은 해당 생성 경로에서 오류입니다.

축 크기의 곱은 값의 개수와 맞아야 합니다. 예를 들어 shape가 [2,3]이면 원소는 2×3=6개입니다. 입력 배열은 생성 시 복사되므로 이후 원래 배열을 고치는 것을 기존 텐서의 값을 변경하는 방법으로 사용하지 않습니다. 모델의 입력 순서와 텐서 형상은 별도로 맞춰야 합니다.

Read는 텐서의 형상과 형식에 맞는 새 관리 배열을 복사해 줍니다. AdvancedAiEngine.Run의 입력이나 출력을 다룰 때 각 텐서가 별도 소유 객체임을 기억하고, 사용을 마친 텐서는 Dispose합니다. 형상과 원소 종류를 결과와 함께 기록하면 배열을 다시 해석할 수 있습니다.

항목확인할 내용

valuesfloat, int, sbyte 또는 byte 배열
원소 수축 크기의 곱과 값 개수 일치
예[2,3]은 원소 6개
Read형상과 값의 새 배열 복사
Dispose생성된 소유 텐서 해제

판독과 확인 사례

예를 들어 [2,3] 형상에 float 배열을 전달했다면 Read로 얻는 형상과 반환 배열의 원소 종류를 확인해 여섯 값이 의도한 축 순서로 해석되는지 살핍니다. 동일한 원소 수를 가진 [3,2]는 모양이 다르므로 숫자 개수만 같다고 같은 모델 입력이 되는 것은 아닙니다.

AdvancedAiEngine.Run은 모델이 선언한 순서로 입력 텐서들을 받습니다. 텐서 생성은 네이티브 소유 객체를 만들 뿐 모델의 의미와 자동으로 일치시켜 주지 않습니다. 모델 입력의 형상과 자료형을 대조하고 생성한 입력 및 반환된 출력 텐서를 각각 Dispose합니다.
