Select

Method · 선언 타입 ZVision.BlobPointSelect

C#
static System.UInt64[] Select(ZVision.ZImage[] regions, System.UInt64 x, System.UInt64 y, System.UInt64 workBudget)

겹치는 영역을 포함해 지정 픽셀이 전경인 모든 영역 인덱스를 반환합니다.

인자

regions: 동일 크기와 원점의 Gray8 마스크 배열입니다.

x: ROI 로컬 열 좌표입니다.

y: ROI 로컬 행 좌표입니다.

workBudget: 영역 검사 횟수 상한입니다.

반환: 입력 순서의 0 기반 인덱스 배열입니다.

Select의 사용과 결과 해석

선택 점이 (x,y)일 때 그 점은 영상 로컬 기준으로 해석됩니다. 다른 ROI에서 가져온 글로벌 점이라면 영상 원점과의 차이를 먼저 계산해야 올바른 위치를 가리킵니다. 점으로 선택할 성분을 찾습니다. 입력 점의 좌표가 라벨 영상과 같은 ROI 기준인지 확인하고, 배경에 해당하는 점과 유효한 성분을 가리키는 점을 구분합니다.

항목이 호출에서 확인할 내용
regions동일 크기와 원점의 Gray8 마스크 배열입니다.
xROI 로컬 열 좌표입니다.
yROI 로컬 행 좌표입니다.
workBudget영역 검사 횟수 상한입니다.
반환입력 순서의 0 기반 인덱스 배열입니다.
