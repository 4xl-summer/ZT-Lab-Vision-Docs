System.UInt64 AddMeasuredLine(System.UInt64 id, ZVision.MeasurementLineSpec spec, ZVision.MeasurementProbeOptions options, System.Nullable<System.UInt64> frame = null)

영상에서 탐침으로 선을 측정하는 형상을 추가합니다.

인자

id: 형상 ID입니다.

spec: fixture 로컬 선분입니다.

options: 추가 시 복사할 탐침 설정입니다.

frame: fixture 인덱스 또는 null입니다.

반환: 형상 인덱스입니다.

관련 입력의 확인된 조건

spec.Start: ROI 로컬 시작점입니다.

spec.End: ROI 로컬 끝점입니다.

spec.SearchSkewRadians: 왼쪽 법선에 더하는 라디안 각도입니다.

추가와 실행 결과

복합 모델에 영상에서 측정할 선 형상을 추가합니다. 형상 ID와 fixture 로컬 기준 기하를 지정하고 탐색 및 적합 설정을 함께 전달합니다. frame이 지정되면 해당 fixture 기준을 확인하고, 없을 때와 서로 다른 기준의 좌표를 혼합하지 마십시오. 추가 시 설정이 복사되므로 이후 원래 설정 객체를 바꾼 사실을 이미 추가된 구성의 변경으로 가정하지 않습니다. 기준 선분을 따라 프로브가 목적 경계를 가로지르는지 확인하십시오. 반환한 형상 인덱스와 ID를 보관하고 실행 후 관측 상태와 적합 결과를 따로 확인하십시오.

항목확인된 역할
id형상 ID입니다.
specfixture 로컬 선분입니다.
options추가 시 복사할 탐침 설정입니다.
framefixture 인덱스 또는 null입니다.
