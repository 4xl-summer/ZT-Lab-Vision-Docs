C#
void SaveSvg(System.String path, System.Int32 width, System.Int32 height)

픽셀 중심 좌표를 SVG로 저장합니다.

인자

path: 출력 경로입니다.

width: 영상 너비입니다.

height: 영상 높이입니다.

사용 순서와 결과 해석

불변 도형 목록을 지정 경로의 SVG로 기록합니다. width와 height는 양수이며 viewBox는 0 0 width height입니다. 점·선·원의 픽셀 중심은 SVG 좌표에 0.5를 더하지만 셀 사각형은 경계 좌표를 그대로 씁니다. 영상 자체를 저장하는 호출이 아니므로 영상 파일과 장면을 각각 관리합니다.

입력별 확인

입력의미
path출력 경로입니다.
width영상 너비입니다.
height영상 높이입니다.
