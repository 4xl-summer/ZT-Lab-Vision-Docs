ZVision.Spectrum Filtered(ZVision.FrequencyProfile profile, ZVision.FrequencyPass pass, System.Double low, System.Double high = 0, System.Double centerX = 0, System.Double centerY = 0, System.UInt32 order = 0)

필터를 적용합니다.

인자

profile: 응답입니다.

pass: 통과 방식입니다.

low: 하한입니다.

high: 상한입니다.

centerX: 중심 x입니다.

centerY: 중심 y입니다.

반환: 독립 스펙트럼입니다.

관련 입력의 확인된 조건

profile.Gaussian: Gaussian 응답입니다.

profile.Butterworth: Butterworth 응답입니다.

Filtered의 사용과 결과 해석

주파수 필터 적용 후의 계수와 적용 전 계수를 구분합니다. 필터 프로파일과 차단 설정을 기록하고 같은 정규화 조건에서 결과를 비교합니다. 주파수 계수는 복소수의 실수부와 허수부를 포함합니다. 필터 또는 마스크는 이 계수에 작용하며 역변환 결과를 볼 때 정규화와 변환 크기를 함께 확인해야 원본과 값의 크기를 비교할 수 있습니다.
