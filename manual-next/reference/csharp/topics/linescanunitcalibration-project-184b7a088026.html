Method · 선언 타입 ZVision.LineScanUnitCalibration

C#
static ZVision.Point2 Project(ZVision.LineScanCamera camera, ZVision.Point2 point, ZVision.LengthUnit unit)

물리 점을 픽셀·라인으로 변환합니다.

인자

camera: 라인 스캔 모델입니다.

point: 물리 점입니다.

unit: 점의 길이 단위입니다.

반환: 픽셀과 라인입니다.

관련 입력의 확인된 조건

camera.PixelsPerUnit: 횡방향 단위 길이당 픽셀 수입니다.

camera.CenterPixel: 객체 x=0의 횡방향 픽셀입니다.

camera.OriginY: 기준 라인에서 물체 평면 Y 좌표입니다.

camera.OriginLine: 물체 평면 기준 Y에 대응하는 라인입니다.

camera.DistancePerLine: 라인당 부호 있는 물리 이동 거리입니다.

camera.Unit: 물체 평면 거리의 단위입니다.

Point2.X: 영역의 로컬 x 좌표입니다.

Point2.Y: 영역의 로컬 y 좌표입니다.

적용과 결과 판독

물리 점을 지정 단위로 해석해 라인 스캔 모델의 픽셀 및 라인 좌표로 변환합니다. 예측 픽셀과 라인은 같은 물리 차원의 두 좌표가 아니므로 각각의 의미를 유지하십시오. 보정에 정의된 모델과 입력 점의 길이 단위가 일치하는지 확인하고 반환 좌표를 실제 영상 기준과 대조합니다.

입력확인된 역할
camera라인 스캔 모델입니다.
point물리 점입니다.
unit점의 길이 단위입니다.
