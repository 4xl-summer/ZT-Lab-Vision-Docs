Method · 선언 타입 ZVision.GapRegionCopy

static System.ValueTuple<ZVision.ZImage, ZVision.GapCopyReport> FillChannels(ZVision.ZImage destination, System.Int64 x, System.Int64 y, System.UInt64 width, System.UInt64 height, System.Double[] values, ZVision.ZImage mask = null, System.Int64 maskOffsetX = 0, System.Int64 maskOffsetY = 0, System.Boolean clip = false, System.Boolean invertMask = false)

선택 픽셀에 채널별 상수를 채웁니다.

인자

destination: 기준 목적 영상입니다.

x: 목적 ROI x입니다.

y: 목적 ROI y입니다.

width: 너비입니다.

height: 높이입니다.

values: RGB/BGR/RGBA/BGRA의 원래 채널 순서 값입니다.

mask: 선택 Gray8 마스크 또는 null입니다.

maskOffsetX: 마스크 X 오프셋입니다.

maskOffsetY: 마스크 Y 오프셋입니다.

clip: 영상 밖 선택 픽셀을 잘라냅니다.

invertMask: 참이면 마스크의 0을 선택합니다.

반환: 독립 영상과 처리 수입니다.

관련 입력의 확인된 조건

destination.Origin: ROI의 글로벌 픽셀 원점입니다.

destination.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

FillChannels의 사용과 결과 해석

채널별 값을 채우는 경우 입력 형식의 채널 순서를 알아야 원하는 색을 만들 수 있습니다. 같은 숫자 배열도 다른 채널 순서에서는 다른 색으로 보일 수 있습니다. 영역 복사와 채우기는 위치와 크기 및 선택 마스크를 기준으로 수행합니다. 원본과 목적 영상의 ROI 좌표를 각각 확인하고, 화면 밖 부분의 처리와 반환 보고서를 함께 살펴봅니다.

x목적 ROI x입니다.
y목적 ROI y입니다.
width너비입니다.
height높이입니다.
