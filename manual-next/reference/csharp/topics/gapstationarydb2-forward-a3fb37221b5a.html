static ZVision.GapStationaryDb2 Forward(ZVision.ZImage image, System.UInt64 levels, System.Boolean centered = false)

영상의 비감쇠 Daubechies-2 변환을 만듭니다.

인자

image: Gray8/16/F32 입력입니다.

levels: 각 축의 오프셋이 영상보다 작은 양의 단계입니다.

centered: 중심 위상 적용 여부입니다.

반환: 해제할 독립 모델입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

입력 ROI의 변환 모델을 새로 생성합니다. levels는 분해 단계이며 적용 가능한 크기 조건은 선택한 변환 계열에서 확인해야 합니다. 소유 모델에서 Coefficients로 계수 사본을 얻거나 Inverse로 영상을 복원할 수 있습니다. 입력 영상, 생성 모델, 복원 영상의 각 소유권은 따로 관리합니다. 각 축의 단계별 오프셋은 영상 크기보다 작아야 합니다.
