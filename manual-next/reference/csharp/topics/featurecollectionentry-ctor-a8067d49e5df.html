FeatureCollectionEntry(System.UInt64 id, ZVision.FeatureModel model, ZVision.FeatureSearchOptions options)

모델 ID, 소유 모델과 검색 옵션을 지정합니다.

인자

id: 모델을 식별하는 고유 ID입니다.

model: 검색할 소유 모델입니다.

options: 모델별 대응 설정입니다.

관련 입력의 확인된 조건

options.Ratio: 최선과 차선 기술자 거리의 비율 상한이며 0 초과 1 미만입니다.

options.MaxDistance: 단위 L2 기술자 간 최대 거리입니다.

options.InlierThreshold: 기하 인라이어 거리 상한 픽셀입니다.

options.RansacIterations: 최대 무작위 가설 수이며 1~4096입니다.

options.Seed: 재현 가능한 가설 생성 seed입니다.

options.MaxDescriptorComparisons: 왕복 기술자 비교 수 상한이며 1~10000000입니다.

options.Mutual: 소스에서 모델로의 최선 대응도 일치해야 합니다.

options.Geometry: 기하 검증 변환 종류입니다.

값을 구성하고 해석하기

컬렉션에서 한 특징 모델을 검색할 때 모델, 고유 Id 및 해당 모델에 적용할 검색 옵션과 수락 조건을 묶습니다. MinInliers는 내점 개수이고 MinInlierFraction은 전체 대응점 대비 내점 비율이므로 두 값을 같은 조건으로 해석하지 않습니다. 결과 Id를 입력 항목과 연결할 때 중복 없는 식별자를 사용합니다.

구성 후 확인할 속성

속성의미
Id고유 모델 ID입니다.
Model소유 모델입니다.
Options모델별 검색 설정입니다.
MinInliers최소 인라이어 수입니다.
MinInlierFraction대응점 대비 최소 인라이어 비율입니다.
