ZVision.BeadGapStats GapStatsUnits(ZVision.BeadCoordinateMode mode, System.Double maximum, System.UInt64 maxWork, System.Double[] world = null, ZVision.ZImage worldX = null, ZVision.ZImage worldY = null)

좌표 단위를 지정하여 누락 비율을 평가합니다.

인자

mode: 좌표 단위입니다.

maximum: 최대 비율입니다.

maxWork: 작업 상한입니다.

world: 선택 affine 변환입니다.

worldX: 선택 X 맵입니다.

worldY: 선택 Y 맵입니다.

반환: 누락 통계입니다.

관련 입력의 확인된 조건

mode.LegacyAuto: 보정이 있으면 세계, 없으면 픽셀인 기존 동작입니다.

mode.Pixel: ROI 로컬 픽셀이며 보정을 지정할 수 없습니다.

mode.World: 세계 좌표이며 아핀 또는 두 좌표 맵이 반드시 필요합니다.

BeadGapStats.IncludedLength: 포함된 경로 길이입니다.

BeadGapStats.MissingLength: 누락 경로 길이입니다.

BeadGapStats.Fraction: 누락 길이의 비율입니다.

BeadGapStats.Passed: 허용 비율 통과 여부입니다.

사용과 결과 판독

좌표 단위를 지정해 포함 경로의 누락 비율을 평가합니다. 길이의 수치는 선택 단위에 따라 바뀌지만 같은 단위의 누락 길이를 전체 길이로 나눈 비율은 무차원입니다. 단위와 선택 좌표 변환, 허용 비율을 함께 저장합니다.

항목확인된 역할
mode좌표 단위입니다.
maximum최대 비율입니다.
maxWork작업 상한입니다.
world선택 affine 변환입니다.
worldX선택 X 맵입니다.
worldY선택 Y 맵입니다.
반환누락 통계입니다.
