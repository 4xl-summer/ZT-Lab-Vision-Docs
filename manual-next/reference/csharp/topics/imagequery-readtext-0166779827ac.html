ZVision.OcrQuery ReadText(ZVision.OcrEngine engine, ZVision.OcrSpec spec)

Gray8 이미지의 단일 줄 OCR과 인식 후 판정을 지연 쿼리에 등록합니다.

인자

engine: 인식에 사용할 OCR 엔진입니다.

spec: 처리에 사용할 설정입니다.

반환: 실행할 인식 쿼리입니다.

관련 입력의 확인된 조건

spec.Region: 현재 이미지의 로컬 좌표를 사용하는 OCR 영역 설정입니다.

spec.MinContrast: 원본 Gray8 대비의 최솟값으로 0~1이며 같은 값은 통과합니다.

spec.MinLength: 허용할 최소 Unicode 문자 수입니다.

spec.MaxLength: 허용할 최대 Unicode 문자 수입니다.

spec.AllowedChars: 인식 후 판정에 사용할 비어 있지 않은 출력 가능 ASCII 문자 집합입니다.

ReadText의 사용과 결과 해석

인식은 모델 및 전처리 조건에 의존합니다. 결과 문자열만 저장하면 읽기 실패와 선택 조건을 추적하기 어려우므로 제공되는 상태도 함께 보관합니다. 영상과 설정한 인식 경로로 문자를 읽는 계획입니다. 인식 결과의 문자와 상태를 함께 확인하고, 읽지 못한 결과를 빈 문자열의 정상 인식으로 단정하지 않습니다.
