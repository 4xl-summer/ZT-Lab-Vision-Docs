C#
static ZVision.GapGeneralSpectrum Forward(ZVision.ZImage image, System.UInt64 width, System.UInt64 height, ZVision.FftNormalization normalization = ZVision.FftNormalization.Backward)

실수 영상의 임의 크기 정방향 DFT를 계산합니다.

인자

image: Gray8/16/F32/F64 입력 영상입니다.

width: 출력 너비입니다.

height: 출력 높이입니다.

normalization: 양방향 정규화 방식입니다.

반환: 해제할 독립 스펙트럼입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

normalization.Backward: 정방향 미정규화, 역방향 1/N입니다.

normalization.Orthonormal: 양방향 1/sqrt(N)입니다.
