ZVision.Display.ZDisplayFrame CreateDisplayFrame(System.String stage)

단계의 표시 프레임을 만듭니다. Threshold와 Close에는 선택 영역의 로컬 경계를 표시합니다.

인자

stage: 단계 이름입니다.

반환: 호출자가 해제할 프레임입니다.

관련 입력의 확인된 조건

ZDisplayFrame.PixelFormat: 원본 픽셀 형식입니다.

ZDisplayFrame.Overlays: 불변 도형 장면입니다.

이 호출의 입력과 객체 맥락

이 객체의 확인된 공개 생성 경로: ZInspectionResult(System.Int64 frameId, System.Int64 recipeVersion, System.Collections.Generic.IDictionary<System.String, ZVision.ZImage> stages, ZVision.Statistics statistics, System.Collections.Generic.IEnumerable<ZVision.Blob> blobs, System.Collections.Generic.IEnumerable<ZVision.Inspection.ZInspectionMetric> metrics, System.TimeSpan elapsed).

인자별 입력 조건

인자형식역할과 조건
stageSystem.String단계 이름입니다.

단계 표시 프레임

지정 단계의 영상과 표시 장면을 묶는 ZDisplayFrame을 생성합니다. Threshold와 Close 단계에는 선택된 Blob의 로컬 경계를 표시합니다. 프레임은 호출자가 Dispose합니다.

프레임이 어떤 FrameId와 RecipeVersion의 결과인지 확인하여 늦게 도착한 이전 결과를 새 영상에 표시하지 않습니다. 화면 배율이나 패닝은 표시 좌표를 바꾸며 검사 영상 픽셀을 다시 계산하지 않습니다.
