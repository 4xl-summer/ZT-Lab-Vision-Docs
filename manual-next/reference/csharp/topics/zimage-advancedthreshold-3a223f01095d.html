AdvancedThreshold

ZVision.ZImage AdvancedThreshold(System.UInt32 kind, System.Double a = 0, System.Double b = 0, System.UInt64 radius = 0, System.UInt32 comparison = 4, System.Double minimum = 0, System.Double maximum = 255, ZVision.ZImage seed = null, System.UInt32 result = 0)

고정, 구간, 자동 또는 국소 임계값으로 분할합니다.

인자

kind: 0 고정, 1 내부, 2 외부, 3 백분위, 4 삼각, 5 Otsu, 6 최빈, 7 이봉, 8 평균, 9 중간범위, 10 Gaussian입니다.

a: 방식별 임계값, 하한, 백분위 또는 국소 오프셋입니다.

b: 상한 또는 국소 Gaussian 시그마입니다.

radius: 국소 영역 반경입니다.

comparison: 0 미만, 1 이하, 2 같음, 3 다름, 4 이상, 5 초과입니다.

minimum: 전역 임계 하한입니다.

maximum: 전역 임계 상한입니다.

seed: 임계값을 만족하는 8연결 성분을 선택하는 Gray8 시드 영상입니다.

result: 0 마스크, 1 임계 영상입니다.

반환: 호출자가 해제하는 새 영상입니다.
