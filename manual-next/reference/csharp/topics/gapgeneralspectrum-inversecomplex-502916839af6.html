ZVision.GapComplexInverse InverseComplex(System.Boolean crop = true)

켤레 대칭이 아닌 경우에도 실수·허수 역변환을 반환합니다.

인자

crop: 입력 크기로 자를지 여부입니다.

반환: 독립 배열과 크기입니다.

이 호출의 입력과 객체 맥락

켤레 대칭이 아닌 스펙트럼도 실수부와 허수부를 모두 갖는 복소 역변환으로 읽습니다. crop은 원본 크기로 자를지 선택하며 False일 때는 변환 크기를 사용합니다. 결과의 폭·높이와 각 값 배열을 함께 해석하세요. 값 배열은 영상 소유 핸들이 아니며 스펙트럼 객체는 사용 후 별도로 해제합니다.

사용 흐름과 결과 판독

InverseComplex는 스펙트럼의 역변환을 실수 배열과 허수 배열로 반환합니다. 스펙트럼이 켤레 대칭이 아닐 때도 허수 성분을 버리지 않고 두 부분을 함께 확인할 수 있습니다. 출력은 영상 핸들이 아니라 크기와 독립 배열을 포함한 결과 값이며, 스펙트럼 모델은 사용 후 별도로 해제해야 합니다.

crop이 true이면 원본 입력 크기에 맞춰 결과를 자르고 false이면 전체 변환 격자의 크기를 사용합니다. 예를 들어 원본이 5×3이고 변환 격자가 8×4라면 crop=true는 원본 크기, false는 8×4 격자를 대상으로 해석합니다. 각 실수·허수 배열의 원소를 같은 인덱스에서 한 복소값의 두 성분으로 읽습니다.

실수부만 표시한 영상은 허수부가 실제로 0인지 알려주지 않습니다. 처리한 주파수 마스크와 정규화, 출력 크기 및 crop 선택을 함께 기록해야 역변환 값을 재현할 수 있습니다. 입력의 켤레 대칭 여부를 확인하지 않은 채 모든 허수값을 항상 0으로 가정하지 않습니다.
