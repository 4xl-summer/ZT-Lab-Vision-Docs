Roi

Method · 선언 타입 ZVision.DepthMap

C#
ZVision.DepthMap Roi(System.Int32 x, System.Int32 y, System.Int32 width, System.Int32 height)

로컬 사각형의 저장소를 공유하며 원점을 XY 간격만큼 이동한 별도 핸들을 만듭니다.

인자

x: X 성분 또는 영역의 왼쪽 셀입니다.

y: Y 성분 또는 영역의 위쪽 셀입니다.

width: 양의 격자 너비 또는 영역 너비입니다.

height: 양의 격자 높이 또는 영역 높이입니다.

반환: 호출자가 해제할 소유 핸들입니다.

관심 영역과 좌표

픽셀 격자에서 지정한 사각형을 선택합니다. 시작 좌표와 크기는 원본 범위 안에 있어야 하며, 새 영역의 픽셀 (0,0)은 원본의 선택 시작 위치에 해당합니다. 픽셀 인덱스는 새로 시작하지만 물리적 위치가 유지되도록 원점이 이동합니다.

원점 x가 10이고 x 간격이 2인 영상에서 x=1부터 영역을 자르면 새 원점 x는 12입니다. y도 시작 행 × y 간격만큼 이동하고 z 원점은 그대로입니다. 따라서 같은 실제 위치를 전체 영상과 ROI에서 계산할 때 결과 좌표는 같아야 합니다.

확인 항목해석
x, y원본 격자의 시작 열과 행
width, height선택할 양의 픽셀 크기
새 원점기존 원점 + 시작 인덱스 × 간격
범위 오류사각형이 원본을 벗어나면 실패
