static ZVision.CalibrationSession Create()

빈 관측 테이블을 만듭니다.

반환: 호출자가 해제할 관측 테이블입니다.

사용과 결과 판독

빈 관측 테이블을 새로 만들며 이후 카메라, 표적, 자세의 세 식별자에 대응점 배열을 저장할 수 있습니다. 새 테이블에는 기존 관측이 없으므로 조회 전에 필요한 점을 삽입하십시오. 세션 객체는 소유 자원이며 사용이 끝나면 해당 언어의 해제 절차를 따라야 합니다. 관측점은 표적의 각 위치와 영상 픽셀의 대응 순서를 유지합니다.

단계별 확인

Create는 카메라·표적·자세 ID로 구별할 관측을 담을 빈 테이블을 반환합니다. 생성 시 대응점이 자동으로 추가되는 것은 아니므로 표적점과 픽셀점의 배열을 별도로 준비해야 합니다.

동일 인덱스는 같은 물리 표적점을 가리켜야 하며, 한 배열만 정렬하면 대응이 어긋납니다. Insert는 새 키를 추가하고 Set은 같은 키의 관측을 교체할 수 있습니다. 사용이 끝난 세션은 호출자가 Dispose합니다.

항목확인할 내용
생성빈 소유 관측 테이블을 받습니다.
키0이 아닌 카메라·표적·자세 ID를 사용합니다.
대응표적과 글로벌 픽셀 배열의 순서를 맞춥니다.
Insert이미 존재하는 키를 거부합니다.
Set동일 키의 관측을 원자적으로 교체할 수 있습니다.
수명관측 작업을 마친 뒤 세션을 Dispose합니다.

예를 들어 같은 카메라와 표적을 두 자세에서 촬영했다면 자세 ID를 달리하여 두 관측을 구별할 수 있습니다. 한 관측 안에서는 표적점과 픽셀점이 같은 순서여야 하며, ID만 맞더라도 대응점 순서가 바뀌면 의도한 기하를 나타내지 않습니다.
