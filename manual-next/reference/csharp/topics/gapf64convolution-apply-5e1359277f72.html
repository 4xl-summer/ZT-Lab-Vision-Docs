Method · 선언 타입 ZVision.GapF64Convolution

C#
static ZVision.ZImage Apply(ZVision.ZImage image, System.Double[] kernel, System.UInt64 width, System.UInt64 height, System.UInt64 anchorX, System.UInt64 anchorY, System.Double divisor = 1, System.Double offset = 0, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, System.Double constant = 0, System.Boolean correlate = true)

GrayF64 영상에 합성곱 또는 상관을 적용합니다.

인자

image: 유한 GrayF64 입력입니다.

kernel: 행 우선 유한 커널입니다.

width: 커널 너비입니다.

height: 커널 높이입니다.

anchorX: 커널 X 앵커입니다.

anchorY: 커널 Y 앵커입니다.

divisor: 0이 아닌 유한 제수입니다.

offset: 유한 출력 offset입니다.

border: 경계 규칙입니다.

constant: 상수 경계 값입니다.

correlate: 참이면 상관, 거짓이면 합성곱입니다.

반환: 원점을 보존하는 독립 GrayF64 영상입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.
