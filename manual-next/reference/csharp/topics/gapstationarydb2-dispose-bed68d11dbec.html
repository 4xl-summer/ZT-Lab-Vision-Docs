void Dispose()

모델 핸들을 해제합니다.

이 호출의 입력과 객체 맥락

GapStationaryDb2.Coefficients: 최종 LL 다음 각 단계 HL/LH/HH의 행 우선 계수를 복사합니다.

GapStationaryDb2.WithCoefficients: 외부 계수 스냅샷으로 독립 모델을 만듭니다.

GapStationaryDb2.Shrunk: 최종 LL을 보존하며 모든 세부 대역을 축소합니다.

GapStationaryDb2.Inverse: 원래 ROI 원점의 GrayF64 영상을 합성합니다.

GapStationaryDb2.Metadata: 밴드 크기를 반환합니다.

사용 흐름과 판독 기준

GapStationaryDb2는 주기 경계의 비감쇠 Daubechies-2 계수를 보관하는 소유 모델입니다. Forward가 만든 모델의 계수를 읽거나 축소한 뒤 역변환을 마쳤으면 이 Dispose로 모델 핸들을 닫습니다. 이 연산은 계수의 임계값을 바꾸거나 역변환 영상을 새로 만드는 작업은 아닙니다.

Coefficients는 숫자 배열의 독립 복사본이고 WithCoefficients와 Shrunk는 각각 별도 소유 모델을 반환합니다. Inverse는 원래 ROI 원점을 가진 독립 GrayF64 영상입니다. 예를 들어 원본 모델에서 Shrunk와 Inverse를 각각 얻었다면 원본 모델을 닫는 시점과 새 모델 및 영상의 사용 종료 시점을 각각 정해야 합니다. 계수 배열 자체는 관리형 숫자 배열입니다.

Metadata에는 밴드 크기가 있고 계수는 최종 LL 다음 각 단계 HL, LH, HH의 순서로 제공됩니다. 이미 복사한 계수를 비교할 때 모델과 함께 단계 수와 영상 크기를 기록해야 배열의 위치를 해석할 수 있습니다. 닫힌 모델에 새 계수 조회나 역변환을 요청하지 말고, 반환받은 별도 핸들은 사용 후 해제합니다.
