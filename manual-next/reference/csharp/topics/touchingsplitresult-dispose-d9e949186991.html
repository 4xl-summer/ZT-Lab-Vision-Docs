수명과 사용 순서

접촉 객체 분리 결과의 자원을 해제합니다. 판독 및 후속 처리를 마친 뒤 결과 객체의 수명을 끝내고 별도 획득 자료의 수명도 확인하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

마커와 라벨 영상의 소유 관계

TouchingSplitResult는 접촉 전경을 분리한 마커 영상 Markers와 라벨 영상 Labels를 소유합니다. 두 영상은 GrayU32이며 Dispose는 Markers를 해제한 다음 Labels도 해제합니다. MarkerCount는 최소 크기 선택 전 마커 개수이고 RegionCount는 선택 후 보존된 영역 수입니다.

예를 들어 후보 마커가 3개라도 최소 영역 크기에 미달한 영역이 제거되면 보존된 영역 수는 더 적을 수 있습니다. 두 개수는 같은 단계의 숫자가 아니므로 차이를 곧 오류라고 판단하지 마세요. Markers에서 마커 위치를, Labels에서 최종 분할 라벨을 확인하고 둘 다 원본 전경과 좌표를 맞춰 비교합니다.

항목의미와 처리
Markers결과가 소유한 GrayU32 마커 영상
Labels결과가 소유한 GrayU32 라벨 영상
MarkerCount선택된 마커 수, 영역 제거 전
RegionCount최소 크기 선택 후 보존 영역 수
Dispose두 소유 영상을 모두 해제
추가 수명필요 시 해제 전에 독립 공유 취득

수명과 결과 확인

Markers와 Labels 속성은 결과가 소유한 영상 객체이므로 결과를 Dispose하면 두 영상도 함께 해제됩니다. 결과 해제 후에도 영상이 필요하다면 해제 전에 적절한 독립 공유를 취득해 별도 수명으로 관리하세요. 수만 보관하면 충분한 경우에는 정수 스냅샷을 읽은 뒤 결과를 정리할 수 있습니다.
