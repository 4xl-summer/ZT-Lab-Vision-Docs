수명과 사용 순서

방향별 편차 검사 결과를 해제합니다. 어두움과 밝음 방향의 결과를 필요한 만큼 읽고 각 획득 영상의 수명을 별도로 관리하십시오.

이 호출에는 반환값이 없습니다. C#에서 소유 객체의 사용 범위를 정하고 필요한 작업이 끝나면 해제하여 네이티브 자원을 정리하십시오. 해제된 객체는 이후 작업에 사용하지 않습니다.

방향별 결과의 소유권

이 호환 API 결과는 하한·상한 영상과 어두운 결함·밝은 결함 마스크를 인덱스로 제공합니다. Image를 호출하면 독립 소유 영상을 얻으므로 필요한 영상을 획득한 후 결과를 Dispose해도, 이미 획득한 각 영상의 해제 책임은 별도로 남습니다.

인덱스 0과 1은 임계 영상이고 2와 3은 각각 어두운 결함과 밝은 결함 마스크입니다. 예를 들어 어두운 결함의 위치를 표시하려면 2번을 선택합니다. 방향별 임계값과 마스크를 같은 종류의 영상으로 혼동하지 말고 각각의 의미에 맞게 판독하십시오.
