ZVision.ConvexShapeQuery Clone()

볼록 형상 계획을 독립 핸들로 복제합니다.

반환: 원본과 별도로 Dispose해야 하는 계획입니다.

호출과 결과 확인

볼록 형상 분석 계획을 독립적으로 해제할 수 있는 핸들로 복제합니다. 복제만으로 성분을 계산하지 않으며 각 계획의 Execute가 결과 스냅샷을 만듭니다. connectivity와 원래 영상 계획을 확인한 뒤 복제본과 원본 계획의 수명을 각각 관리합니다.

복제부터 실행까지

ImageQuery.ConvexShapes로 연결 방식을 선택해 볼록 형상 계획을 만든 뒤 Clone하면 같은 계획을 별도 핸들로 사용할 수 있습니다. Clone 자체는 영상을 다시 분석하지 않으며 아직 ConvexShapeResult를 만들지 않습니다. 원본과 복제본은 각각 사용 후 Dispose합니다.

결과가 필요하면 원하는 계획의 Execute를 호출하고 반환 QueryExecution의 Output을 확인합니다. 실행도 별도로 Dispose해야 하며 Output으로 얻은 형상 스냅샷은 실행을 해제한 뒤에도 유효합니다. 결과 껍질과 사각형은 검색 ROI 로컬 좌표입니다.

결과를 점검하는 방법

복제된 계획의 목적은 같은 분석 구성을 별도 소유 핸들로 유지하는 것입니다. 두 핸들의 해제 시점은 각각 관리해야 하며, 실행 결과를 얻으려면 Execute의 반환값도 별도로 처리합니다. 입력이 빈 전경이면 실행이 성공하더라도 결과 형상 목록은 비어 있을 수 있으므로 Clone의 성공 여부만으로 검출 성분이 존재한다고 단정하지 않습니다.
