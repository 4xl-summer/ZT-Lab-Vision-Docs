Constructor · 선언 타입 ZVision.ProfileSpec

C#
ProfileSpec(ZVision.Point2 start, ZVision.Point2 end, System.UInt64 samples, System.UInt64 width)

계수를 저장하는 ProfileSpec 값을 만듭니다. 값의 유효성은 연산 시 검증합니다.

인자

start: ROI 로컬 픽셀 중심의 시작점입니다.

end: ROI 로컬 픽셀 중심의 끝점입니다.

samples: 양 끝을 포함한 표본 수이며 3 이상입니다.

width: 중심선에 수직인 표본 수이며 양의 홀수입니다.

관련 입력의 확인된 조건

start.X: 영역의 로컬 x 좌표입니다.

start.Y: 영역의 로컬 y 좌표입니다.

생성과 입력 확인

프로파일의 시작점과 끝점은 현재 영상 ROI 안의 픽셀 중심 좌표로 작성합니다. samples는 두 끝을 포함하는 표본 수이고 3 이상이어야 하며 width는 각 중심에서 수직으로 평균할 표본 수로 양의 홀수입니다. 길이 8픽셀 선분에 9개를 지정하면 중심 간 간격은 8/(9−1)=1픽셀입니다. 폭 3이면 각 위치의 법선 방향 −1, 0, +1 픽셀에서 보간한 값을 평균합니다. 기본 프로파일은 선분 양 끝뿐 아니라 띠 전체가 영상 범위 안이어야 합니다. ROI를 원본에서 잘랐다면 원본 글로벌 좌표를 그대로 대입하지 말고 로컬 기준인지 확인하십시오. 기본 경로의 지원 영상 형식은 Gray8, Gray16, GrayF32이며 Float 입력의 비유한 값은 거부됩니다. 이 설정은 강도를 임계화하지 않고 밝기 곡선을 만드는 기하를 정의합니다. 예를 들어 폭 3의 스트립은 중심 위치와 법선 방향 양쪽의 샘플을 사용합니다. 중심이 영상 안에 있더라도 한쪽이 경계를 넘어갈 수 있으므로 전체 스트립의 유효 범위를 확인해야 합니다. 동일 선분에서 표본 수를 늘리면 끝점을 포함한 간격이 달라집니다. 선분 양 끝이 같으면 방향을 정할 수 없습니다. 숫자가 유한한지와 스트립 전체가 입력 영상에서 유효한지도 샘플링 전에 확인하십시오.

입력의미
startROI 로컬 픽셀 중심의 시작점입니다.
endROI 로컬 픽셀 중심의 끝점입니다.
samples양 끝을 포함한 표본 수이며 3 이상입니다.
width중심선에 수직인 표본 수이며 양의 홀수입니다.
