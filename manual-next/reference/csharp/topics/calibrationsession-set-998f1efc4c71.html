C#
void Set(System.UInt64 camera, System.UInt64 target, System.UInt64 pose, ZVision.Point2[] objectPoints, ZVision.Point2[] pixels)

관측을 추가하거나 같은 ID의 관측을 원자적으로 교체합니다.

인자

camera: 0이 아닌 카메라 ID입니다.

target: 0이 아닌 타겟 ID입니다.

pose: 0이 아닌 포즈 ID입니다.

objectPoints: 1~4096개 타겟 평면 점입니다.

pixels: 대응하는 글로벌 픽셀 점입니다.

사용과 결과 판독

카메라·표적·자세의 세 ID를 키로 대응점 관측을 추가하거나 기존 키를 원자적으로 교체합니다. object와 pixels의 같은 인덱스가 같은 표적점을 가리켜야 하며 입력 순서를 보존해야 합니다. 한쪽 배열만 정렬하면 유효한 수치라도 잘못된 짝이 됩니다. 덮어쓰기가 의도된 키인지 확인하고 닫힌 세션에 사용하지 마십시오.
