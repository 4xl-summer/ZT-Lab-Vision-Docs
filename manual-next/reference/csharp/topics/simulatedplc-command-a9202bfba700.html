C#
ZVision.PlcDisposition Command(ZVision.PlcOperation op, System.UInt64 requestId, System.UInt32 resultCode, System.UInt64 nowNs)

모의 PLC 명령을 지정 시각에 적용합니다. 시간 초과는 Poll에서만 판정합니다.

인자

op: 적용할 PLC 명령입니다.

requestId: 명령에 사용할 요청 식별자입니다.

resultCode: 명령에 사용할 결과 코드입니다.

nowNs: 호출자가 제공한 현재 시각(나노초)입니다.

반환: 명령 처리 결과입니다.

관련 입력의 확인된 조건

op.Request: 새 요청을 시작합니다.

op.Publish: 활성 요청의 결과를 게시합니다.

op.Ack: 게시된 결과를 확인합니다.

op.Poll: 명시적으로 시간 초과 여부를 검사합니다.

op.Reset: 오류 상태를 초기화합니다.

PlcDisposition.Applied: 명령이 적용되었습니다.

PlcDisposition.Duplicate: 이미 처리한 식별자 또는 명령이 반복되었습니다.

PlcDisposition.NoChange: 상태가 바뀌지 않았습니다.

PlcDisposition.TimedOut: 명시적 검사에서 시간 초과가 발생했습니다.

사용과 결과 해석

호출자가 제공한 나노초 시각에 요청, 결과 게시 또는 확인 등의 모의 PLC 명령을 적용하고 처리 결과를 반환합니다. requestId와 resultCode는 해당 명령의 요청 식별과 결과에 사용됩니다.

시간 초과는 Poll에서 판정하므로 Command 호출만으로 시간 초과 처리를 기대하지 마십시오. 같은 시계 기준을 유지하면서 명령 결과를 확인하십시오.
