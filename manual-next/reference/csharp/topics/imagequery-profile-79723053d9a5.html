ZVision.ProfileQuery Profile(ZVision.ProfileSpec spec)

Gray8, Gray16 또는 GrayF32 ROI의 스트립 프로파일을 계산합니다.

인자

spec: 연산에 사용할 설정 값입니다.

반환: 사용 후 Dispose해야 하는 소유 지연 계획입니다.

관련 입력의 확인된 조건

spec.Start: ROI 로컬 픽셀 좌표의 시작점입니다.

spec.End: ROI 로컬 픽셀 좌표의 끝점입니다.

spec.Samples: 양 끝을 포함한 표본 개수이며 3 이상이어야 합니다.

spec.Width: 스트립의 수직 방향 표본 수이며 양의 홀수입니다.

사용과 결과 판독

ROI 로컬 ProfileSpec으로 프로파일을 계산할 지연 계획을 만듭니다. 계획을 얻는 시점과 영상에 실제 실행하는 시점은 다릅니다. 표본 위치와 시작점 거리, 횡단 스트립의 평균 강도를 실행 결과에서 구별하십시오. 생성된 소유 계획은 사용이 끝나면 해당 언어의 close 또는 Dispose 규칙에 맞춰 해제해야 합니다.
