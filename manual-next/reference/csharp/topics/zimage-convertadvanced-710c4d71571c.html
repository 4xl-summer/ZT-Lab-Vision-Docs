ZVision.AdvancedColorResult ConvertAdvanced(ZVision.AdvancedWhitePoint white, ZVision.AdvancedTransfer transfer, System.Double gamma, ZVision.AdvancedColorSpace space)

선택 백색점과 입력 전달 함수로 Lab 또는 LCH 영상 평면을 생성합니다.

인자

white: D50 또는 D65 2도 백색점입니다.

transfer: 입력 전달 함수입니다.

gamma: Gamma 전달 함수에 사용할 양의 지수입니다.

space: 출력 색 공간입니다.

반환: 호출자가 해제할 세 평면 결과입니다.

관련 입력의 확인된 조건

transfer.Srgb: sRGB 전달 함수입니다.

transfer.Gamma: 지정한 지수로 디코딩합니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
whiteZVision.AdvancedWhitePointD50 또는 D65 2도 백색점입니다.
transferZVision.AdvancedTransfer입력 전달 함수입니다.
gammaSystem.DoubleGamma 전달 함수에 사용할 양의 지수입니다.
spaceZVision.AdvancedColorSpace출력 색 공간입니다.

white의 입력 값

필드의미와 조건
D50값 0. D65 원본 백색에서 Bradford 적응을 거친 D50 기준 백색을 사용합니다.
D65값 1. sRGB 원색의 D65 기준 백색을 사용합니다.

transfer의 입력 값

필드의미와 조건
GAMMA값 2. 입력 RGB의 각 정규화 값에 지정한 양의 감마 지수를 적용합니다.
LINEAR값 1. 입력 RGB를 이미 선형인 값으로 사용합니다.
SRGB값 0. 입력 RGB에 sRGB 역전달 함수를 적용합니다.

결과와 사용 순서

호출자가 해제할 세 평면 결과입니다.

입력과 결과 해석

색을 비교하거나 보정하기 전 입력 색 공간, 채널 순서와 전달 특성을 확인하세요. 같은 숫자라도 색 공간과 기준 백색점이 다르면 의미가 달라질 수 있습니다. 알려진 색 표본으로 결과를 검증하세요.
