ControlledEccResult()

빈 ECC 결과를 만듭니다.

이 호출의 입력과 객체 맥락

ControlledEccResult.Text: 디코딩된 문자열입니다.

ControlledEccResult.ErrorCorrectionLevel: QR에 기록된 ECC 레벨이며 Data Matrix는 null입니다.

ControlledEccResult.CorrectionEnabled: RS 정정 실행 여부입니다.

ControlledEccResult.Blocks: 블록별 데이터·패리티·정정량입니다.

ControlledEccResult.CorrectedCodewords: 수정된 코드워드 수의 합입니다.

ControlledEccResult.Accepted: 블록별 사후 정정량 한도의 통과 여부입니다.

사용 순서와 결과 해석

기본 생성자는 빈 ControlledEccResult 객체를 만듭니다. 이 호출 자체가 QR 또는 Data Matrix 영상을 판독하거나 Reed–Solomon 정정을 실행하지는 않습니다. 생성 직후 기본값을 실제 심볼 판독 결과로 취급하지 말고, 판독 경로에서 반환된 결과인지 확인하세요.

실제 결과를 읽을 때 Format과 Text, Version을 먼저 확인합니다. ErrorCorrectionLevel은 QR의 ECC 레벨이며 Data Matrix에서는 null입니다. CorrectionEnabled는 정정 실행 여부이고 Accepted는 적용한 블록별 사후 정정량 한도의 통과 여부이므로 서로 같은 속성이 아닙니다.

Blocks는 각 블록의 데이터·패리티·정정 정보를 제공하고 CorrectedCodewords는 실제 수정된 코드워드 수의 전체 합입니다. 합이 같더라도 블록별 분포가 달라 한도 판정은 달라질 수 있습니다. Text가 존재하는 것과 Accepted가 참인 것은 각각 확인해야 합니다.

예를 들어 블록 두 개의 수정 코드워드 수가 각각 다르면 CorrectedCodewords는 그 전체 합이지만 블록별 한도 비교는 각 항목에 적용됩니다. 따라서 합계가 같더라도 블록별 분포가 다른 두 판독의 Accepted를 합계만으로 다시 추정해서는 안 됩니다. 빈 생성자의 기본 값이 아니라 판독 API가 돌려준 결과를 기준으로 이 속성을 읽습니다.
