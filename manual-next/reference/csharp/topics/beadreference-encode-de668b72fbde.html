System.Byte[] Encode(System.UInt64 maxBytes)

기준 모델을 체크섬이 있는 바이트 배열로 저장합니다.

인자

maxBytes: 허용 바이트 수 상한입니다.

반환: 독립 바이트 배열입니다.

인자별 입력 조건

인자형식역할과 조건
maxBytesSystem.UInt64허용 바이트 수 상한입니다.

기준 모델 저장

maxBytes 상한을 사용해 체크섬이 있는 독립 바이트 배열로 모델을 저장합니다. 바이트 배열과 소유 모델 핸들의 수명은 다릅니다.

저장된 경로를 나중에 올바르게 적용하려면 모델이 학습된 영상의 기하와 설정도 함께 보관합니다. 직렬화 성공은 실제 제품의 비드 검사 정확도를 보장하지 않습니다.
