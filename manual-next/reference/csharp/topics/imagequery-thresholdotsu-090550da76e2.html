ZVision.ImageQuery ThresholdOtsu()

Otsu 방법으로 임계값을 정해 마스크를 만드는 연산을 계획합니다. 실제 처리는 Run에서 수행합니다.

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

ThresholdOtsu의 사용과 결과 해석

Otsu 임계는 입력 강도 분포에서 기준을 정하는 방식입니다. 선택된 기준 숫자와 그 기준을 적용한 마스크는 별도의 결과이므로 구분합니다. 강도를 기준으로 픽셀을 전경과 배경으로 구분합니다. 임계값 자체와 결과 마스크는 다른 값이며, 경계에 걸린 픽셀이 어떻게 분류되는지는 선택한 연산의 비교 규칙을 확인합니다.

Otsu 마스크를 계획하기

ThresholdOtsu()는 현재 ImageQuery의 처리 목록에 Otsu 자동 임계 마스크 단계를 추가하고 같은 빌더 객체를 반환합니다. 이 호출 시 입력 픽셀을 아직 검사하지 않으며 실제 계산은 실행 단계에서 수행합니다. 계획의 앞 단계가 바뀌면 Otsu가 보는 입력 영상도 달라질 수 있습니다.

Gray8 Otsu 커널의 예에서 입력 [0,0,200,200]은 선택 임계 1과 마스크 [0,0,255,255]를 만듭니다. 이 예는 해당 입력의 독립 기대값이며 모든 영상에 임계 1이 적용된다는 뜻은 아닙니다. 선택된 임계값 이상은 전경 255, 그 미만은 0으로 처리됩니다.

이 메서드가 추가하는 결과는 마스크 영상 단계이며 숫자 임계값을 직접 반환하지 않습니다. 임계 숫자가 필요하면 OtsuThresholdQuery의 스칼라 실행 경로를 사용하고, 마스크가 필요하면 이 영상 계획을 실행합니다. 독립적인 다른 처리 분기가 필요하면 추가 전에 ImageQuery.Clone을 사용합니다.
