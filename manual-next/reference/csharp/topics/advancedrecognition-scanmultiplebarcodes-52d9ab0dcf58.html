ScanMultipleBarcodes

Method · 선언 타입 ZVision.AdvancedRecognition

C#
static ZVision.MultiBarcodeScan ScanMultipleBarcodes(ZVision.ZImage image, ZVision.MultiBarcodeOptions options, System.Nullable<ZVision.RecognitionAngleRange> angleRange = null)

영상에서 여러 바코드를 재귀 탐색합니다.

인자

image: Gray8 입력 영상입니다.

options: 형식과 탐색 설정입니다.

angleRange: 지정하면 옵션의 각도 배열 대신 범위를 사용합니다.

반환: 발견된 심볼 결과입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

MultiBarcodeScan.Reads: 발견한 기호 목록입니다.

MultiBarcodeScan.ImageMetrics: 입력 영상 강도 통계입니다.

이 호출의 입력과 객체 맥락

options.AnglesDegrees: 시도할 시계 방향 회전 각도 목록입니다.

options.TryHarder: 백엔드의 추가 탐색 힌트입니다.

options.MinimumQrModulePixels: QR 전용 최소 모듈 픽셀 힌트이며 0은 지정하지 않습니다.

options.MaxResults: 반환할 최대 심볼 수입니다.

options.MinLength: 디코딩 후 문자열 길이 승인 하한입니다.

인자별 입력 조건

인자형식역할과 조건
imageZVision.ZImageGray8 입력 영상입니다.
optionsZVision.MultiBarcodeOptions형식과 탐색 설정입니다.
angleRangeSystem.Nullable<ZVision.RecognitionAngleRange>지정하면 옵션의 각도 배열 대신 범위를 사용합니다.

복수 심볼 스캔

Gray8 영상과 형식·탐색 옵션으로 여러 바코드를 찾습니다. angleRange를 지정하면 옵션의 각도 배열 대신 해당 범위를 사용합니다. 결과는 읽기 목록과 전체 입력의 밝기 통계를 포함합니다.

각 항목의 텍스트, 원시 바이트, 위치, 회전과 길이 조건을 개별적으로 확인합니다. 탐색은 심볼을 놓칠 수 있고 전체 영상 통계는 심볼 검증기 등급이 아닙니다.
