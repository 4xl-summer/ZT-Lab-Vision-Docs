C#
static ZVision.BlobContourPart[] Union(ZVision.Point2[] a, ZVision.Point2[] b, System.Double maxGap, System.Double maxAngle, System.UInt64 workBudget)

네 방향 조합 중 조건을 만족하는 최단 간격을 선택합니다.

인자

a: 첫 번째 열린 윤곽 점 배열입니다.

b: 두 번째 열린 윤곽 점 배열입니다.

maxGap: 포함 거리 상한입니다.

maxAngle: 접선 각도 상한이며 라디안 단위입니다.

workBudget: 총 점 수의 8배 이상입니다.

반환: 연결되면 하나, 아니면 원래 순서의 두 독립 윤곽입니다.

Union의 사용과 결과 해석

두 윤곽의 입력 순서와 폐곡선 여부를 호출의 선언대로 지정합니다. 합쳐진 결과의 점 수와 원본 윤곽의 점 수가 반드시 같다고 가정하지 않습니다. 두 윤곽의 결합 결과를 구할 때는 입력 좌표가 동일한 영상 기준인지 먼저 확인합니다. 서로 다른 ROI의 로컬 점을 그대로 결합하면 각 좌표는 유효해도 의도한 공간 관계가 달라집니다.

항목이 호출에서 확인할 내용
a첫 번째 열린 윤곽 점 배열입니다.
b두 번째 열린 윤곽 점 배열입니다.
maxGap포함 거리 상한입니다.
maxAngle접선 각도 상한이며 라디안 단위입니다.
workBudget총 점 수의 8배 이상입니다.
