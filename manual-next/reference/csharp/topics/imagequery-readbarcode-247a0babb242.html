ZVision.BarcodeQuery ReadBarcode(ZVision.BarcodeSpec spec)

Gray8 이미지의 단일 바코드 판독을 지연 쿼리에 등록합니다.

인자

spec: 처리에 사용할 설정입니다.

반환: 실행할 인식 쿼리입니다.

관련 입력의 확인된 조건

spec.TryRotate: 원본 외 시계 방향 90도 회전을 순서대로 시도할지 나타냅니다.

spec.Formats: 선택할 바코드 형식의 0이 아닌 비트 조합입니다.

spec.MinContrast: 원본 Gray8 대비의 최솟값으로 0~1이며 같은 값은 통과합니다.

인자별 입력 조건

인자형식역할과 조건
specZVision.BarcodeSpec처리에 사용할 설정입니다.

바코드 형식과 읽기 결과

C#의 ImageQuery 호출은 이 처리를 실행 계획에 연결합니다. BarcodeSpec에서 허용 형식 플래그, 회전 시도와 최소 대비를 지정합니다. CODE128과 QR을 함께 허용하려면 해당 플래그를 결합합니다. 형식 선택은 영상의 바코드를 자동으로 모두 찾는다는 보장이 아니므로 입력 영역과 회전 조건을 확인해야 합니다.

계획을 실행해 얻은 결과의 해석에서는 결과의 status와 reasons, format, text, 원시 바이트 및 위치를 함께 읽습니다. NO_READ와 입력 오류는 서로 다른 상황입니다. contrast는 Gray8 (최댓값−최솟값)/255로 정규화한 대비이며 표준 검증기 품질 등급이나 판독 확률이 아닙니다.

이 호출은 지연 검사 계획을 구성합니다. 실행 결과와 그 출력의 소유 규칙을 반환 형식에서 확인하고 Dispose가 필요한 각 자원을 사용 후 해제합니다. 별도 분기가 필요하면 계획을 복제합니다.
