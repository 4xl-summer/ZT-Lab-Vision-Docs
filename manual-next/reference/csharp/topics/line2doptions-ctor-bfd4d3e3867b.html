C#
Line2DOptions(System.Double normalAngle = 0, System.UInt64 gradientRadius = 1, System.UInt64 projectionLength = 4, System.Double minContrast = 1, System.Double minNormalizedContrast = 0, System.UInt64 maxExtractWork = 16000000, System.UInt64 maxCandidates = 4096, System.Double lineAngleTolerance = 0.2, System.Double edgeAngleTolerance = 0.2, System.Double minLength = 0, System.Double minCoverage = 0, System.UInt32 polarity = 0, System.UInt64 maxLines = 4, System.UInt64 maxFitWork = 16000000, System.Nullable<ZVision.RegionFitOptions> fit = null)

불변 2D 선 검출 설정을 만듭니다.

인자

normalAngle: 예상 법선 각도입니다. 라디안입니다.

gradientRadius: 중앙차분 반경입니다. 양의 픽셀 수입니다.

projectionLength: 접선 방향 투영 띠 길이입니다. 양의 픽셀 수입니다.

minContrast: 투영 기울기 크기의 절반 하한입니다.

minNormalizedContrast: 평균 밝기로 나눈 대비 하한입니다. 0~1입니다.

maxExtractWork: 픽셀 방문과 정렬의 추정 작업 상한입니다.

maxCandidates: 추출 후보 상한입니다. 1~4096이며 초과하면 오류입니다.

lineAngleTolerance: 선 법선과 예상 법선의 허용 각 차이입니다. 0~π/2 라디안입니다.

edgeAngleTolerance: 개별 기울기와 선 법선의 허용 각 차이입니다. 0~π/2 라디안입니다.

minLength: 인라이어 양 끝 사이 최소 길이입니다. ROI 픽셀입니다.

minCoverage: 점유 투영 띠 수/최소~최대 띠 범위의 하한입니다. 0~1입니다.

polarity: 예상 법선 방향의 극성입니다. 0 양쪽, 1 상승, 2 하강입니다.

maxLines: 반환 선 상한입니다. 0~32이며 0은 피크만 반환합니다.

maxFitWork: 피팅 추정 작업 상한입니다. 최대 16000000입니다.

fit: 선택 합의 피팅 설정이며 null이면 잔차 0.75픽셀, 최소 2점입니다.

설정과 사용 흐름

예상 법선 각도, 기울기 및 투영 범위, 대비 조건, 후보와 적합 예산으로 2D 선 검출을 설정합니다. normalAngle과 각도 허용치는 라디안입니다.

최소 길이와 커버리지, 극성 및 최대 선 수는 수용할 후보를 제한합니다. 검출이 없을 때는 영상 대비와 예상 방향뿐 아니라 작업·후보 상한도 함께 확인하십시오.
