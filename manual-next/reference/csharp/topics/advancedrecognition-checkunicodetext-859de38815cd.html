static ZVision.UnicodeTextCheck CheckUnicodeText(System.String text, System.String allowedChars, System.UInt64 minLength, System.UInt64 maxLength)

디코딩 결과를 바꾸지 않고 Unicode scalar 문자 집합과 길이를 검사합니다.

인자

text: 인식된 문자열입니다.

allowedChars: 허용할 유니코드 문자 집합입니다.

minLength: 최소 scalar 개수입니다.

maxLength: 최대 scalar 개수입니다.

반환: 사후 문자 규칙 판정입니다.

관련 입력의 확인된 조건

UnicodeTextCheck.Accepted: 모든 사후 규칙 통과 여부입니다.

UnicodeTextCheck.ScalarCount: 유니코드 scalar 개수입니다.

UnicodeTextCheck.Reasons: 문자·길이·빈 문자열 판정 사유 비트입니다.

인자별 입력 조건

인자형식역할과 조건
textSystem.String인식된 문자열입니다.
allowedCharsSystem.String허용할 유니코드 문자 집합입니다.
minLengthSystem.UInt64최소 scalar 개수입니다.
maxLengthSystem.UInt64최대 scalar 개수입니다.

유니코드 문자열 조건

text와 allowedChars, 최소·최대 길이를 전달해 유니코드 텍스트 조건을 검사합니다. 결과에는 스칼라 수, 사유와 수락 여부가 포함됩니다.

유니코드 스칼라 수는 UTF-8 바이트 길이 및 화면에 보이는 글자 수와 다를 수 있습니다. 인식 상태와 별도로 적용한 문자 및 길이 조건을 기록합니다.
