C#
Rect(System.UInt64 x, System.UInt64 y, System.UInt64 width, System.UInt64 height)

사각형을 만듭니다. 양의 크기와 이미지 범위는 실행 시 검사합니다.

인자

x: 왼쪽 픽셀 좌표입니다.

y: 위쪽 픽셀 좌표입니다.

width: 너비(픽셀)입니다.

height: 높이(픽셀)입니다.

설정과 사용 흐름

왼쪽 위 좌표와 픽셀 너비·높이를 저장합니다. 양의 크기와 영상 범위 조건은 사용하는 연산에서 검사합니다.

예를 들어 (x,y,width,height)=(2,3,4,2)는 좌측 상단 (2,3)에서 너비 4, 높이 2의 영역을 나타냅니다. 입력 영상의 좌표계와 경계를 함께 확인하십시오.

사각형 범위 해석

Rect는 왼쪽 위 x, y와 픽셀 너비·높이를 값으로 저장합니다. 이 생성자는 양의 크기와 실제 영상 범위의 유효성을 연산 시 검사한다고 명시합니다. 생성된 값만 보고 특정 영상에 들어맞는다고 판단하지 말고 사용하는 영상과 좌표 기준을 함께 확인하십시오.

예를 들어 x=2, y=3, width=4, height=2이면 가로는 x=2부터 5까지 네 픽셀, 세로는 y=3과 4의 두 픽셀을 가리키는 크기입니다. 끝 경계는 각각 x+width=6, y+height=5입니다. ROI 로컬 사각형을 전체 영상에 표시할 때는 원점의 차이를 고려해야 합니다.
