C#
ZVision.ImageQuery LinearTransform(System.Double gain, System.Double bias)

픽셀에 이득과 편향을 적용하도록 계획합니다. 실제 처리는 Run에서 수행합니다.

인자

gain: 픽셀에 곱할 이득.

bias: 곱셈 후 더할 편향.

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

LinearTransform의 사용과 결과 해석

예를 들어 4에 배율 2를 곱하고 1을 더하면 산술값은 9입니다. 출력 형식이 표현할 수 있는 범위는 별도 조건으로 확인합니다. 픽셀 값에 선형 배율과 오프셋을 적용합니다. 예를 들어 배율 2와 오프셋 1은 입력 4를 산술적으로 9에 대응시키며, 실제 출력 범위와 형식은 해당 연산 계약을 따릅니다.

항목이 호출에서 확인할 내용

bias곱셈 후 더할 편향.
