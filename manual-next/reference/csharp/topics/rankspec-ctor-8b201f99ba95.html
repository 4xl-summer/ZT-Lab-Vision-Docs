C#
RankSpec(System.UInt64 width, System.UInt64 height, System.UInt64 anchorX, System.UInt64 anchorY, System.Double quantile, System.Byte[] footprint = null, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, ZVision.PixelFormat output = ZVision.PixelFormat.GrayF32, System.Double constant = 0)

창과 앵커, 분위 및 선택적 footprint를 복사합니다. 유효성은 계산 시 검증합니다.

인자

width: 창 너비입니다.

height: 창 높이입니다.

anchorX: 창 내부 x 앵커입니다.

anchorY: 창 내부 y 앵커입니다.

quantile: 0~1 분위입니다.

footprint: 창 내부 활성 위치의 바이트 배열 또는 null입니다.

border: 복제·반사·상수 경계입니다.

output: 출력 회색 형식입니다.

constant: 상수 경계의 밝기 값입니다.

관련 입력의 확인된 조건

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.

설정과 사용 흐름

창 크기와 내부 앵커, 0~1 분위, 선택적 footprint와 경계·출력 형식을 설정합니다. footprint는 복사되며 null이면 선택적 마스크를 지정하지 않는 형태입니다.

예를 들어 quantile=0.5는 선택된 창 값의 가운데 분위에 해당합니다. 앵커는 창 안의 위치이며 영상의 ROI 원점이 아닙니다. 실제 유효성은 계산 시 검사됩니다.
