System.ValueTuple<System.Double, System.Double> ToInput(System.Double x, System.Double y)

극좌표 출력 좌표를 입력 ROI 좌표로 변환합니다.

인자

x: 출력 각도 축 좌표입니다.

y: 출력 반경 축 좌표입니다.

반환: 입력 ROI 좌표입니다.

사용과 결과 해석

극좌표 출력의 각도 축 x와 반경 축 y를 원래 입력 ROI 좌표로 변환합니다. 변환은 이 설정의 중심, 각도·반경 범위 및 출력 크기를 사용합니다.

결과는 글로벌 영상 좌표가 아닌 ROI 상대 좌표입니다. 글로벌 점으로 표시하려면 원본 ROI 원점을 반영하고 같은 PolarSpec으로 매핑 방향을 유지하십시오.

사용 흐름과 결과 판독

ToInput은 극좌표 출력 영상의 x·y 위치를 원본 입력 ROI 로컬 픽셀 좌표로 바꿉니다. 출력 x는 각도 축, y는 반경 축의 좌표이며 입력으로 소수 좌표도 받을 수 있습니다. 출력 범위는 x=0부터 width−1, y=0부터 height−1까지이며 범위를 벗어나거나 비유한 값이면 오류입니다.

설정된 시작·끝 각도와 반경을 출력 좌표 비율로 보간하여 각도 a와 반경 r을 얻고, 입력 위치는 (centerX+r·cos(a), centerY+r·sin(a))입니다. 예를 들어 중심 (10,20), 각도 0, 반경 5에 해당하는 출력 위치는 입력 로컬 (15,20)으로 돌아갑니다. 각도는 라디안이며 반환점은 글로벌 좌표가 아닙니다.

입력 ROI 원점이 (100,200)이라면 이 예의 글로벌 위치는 (115,220)입니다. ToInput은 좌표를 계산할 뿐 해당 위치의 강도를 표본화하거나 카메라 세계 보정을 수행하지 않습니다. 같은 PolarSpec의 출력 크기와 각도·반경 범위를 함께 기록하고 역방향 좌표 변환과 방향을 바꾸어 사용하지 않습니다.
