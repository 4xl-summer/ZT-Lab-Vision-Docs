void Dispose()

분류기 핸들을 해제합니다.

수명과 사용 순서

학습된 글꼴 OCR 분류기 핸들을 해제합니다. 필요한 Read 호출이 끝난 후 모델의 수명을 종료하십시오.

이 호출에는 반환값이 없습니다. C#에서 소유 객체의 사용 범위를 정하고 필요한 작업이 끝나면 해제하여 네이티브 자원을 정리하십시오. 해제된 객체는 이후 작업에 사용하지 않습니다.

학습 모델의 수명

Train이 반환한 FontOcrModel은 네이티브 분류기 핸들을 소유합니다. 예제 영상과 문자 셀로 학습한 뒤 같은 모델로 필요한 Read 호출을 수행하고, 더 이상 판독하지 않을 때 Dispose로 핸들을 해제합니다. 생성한 모델의 사용 범위를 명시하면 반복 처리에서도 자원 수명을 관리하기 쉽습니다.

Read는 Gray8 영상과 분할 설정, 시도할 각도 및 선택적 위치 조건을 받습니다. 문자가 없으면 null이므로 결과를 얻은 경우에만 문자와 점수를 확인하십시오. 점수는 템플릿 유사도이며 확률이 아닙니다. 모델을 해제한 뒤 해당 모델로 새 판독을 호출하지 않습니다.
