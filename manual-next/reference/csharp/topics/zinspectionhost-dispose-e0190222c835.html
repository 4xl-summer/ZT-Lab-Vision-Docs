동기 종료

StopAsync의 완료를 동기적으로 기다려 호스트를 종료합니다. 요청에 연결된 영상 임대의 정리가 끝난 뒤 반환합니다.

UI 스레드에서는 동기 대기로 응답이 멈출 수 있으므로 StopAsync를 사용합니다. 진행 중인 네이티브 호출을 강제로 중단하는 방식은 아닙니다.

호출과 결과 판독

ZInspectionHost.Dispose는 StopAsync가 반환하는 작업의 완료를 동기적으로 기다립니다. 호스트는 닫힌 상태를 표시하고 종료 토큰을 취소한 뒤 작업자 종료와 요청에 연결된 영상 임대 정리를 마칠 때까지 기다립니다.

이 대기는 진행 중인 네이티브 호출을 강제로 중단한다는 뜻이 아닙니다. 실행기가 현재 호출에서 돌아와 정리될 때까지 시간이 걸릴 수 있습니다. UI 스레드에서 동기 Dispose를 기다리면 응답이 멈출 수 있으므로 해당 경로에서는 StopAsync를 비동기로 기다리는 계약을 사용하십시오.

예를 들어 요청 처리 중 종료를 시작했다면 새 요청 수락 여부, 진행 요청의 완료 또는 취소, 입력 영상 임대의 정리와 작업자 종료를 구분해서 봅니다. 종료 요청을 보냈다는 사실과 모든 정리가 끝났다는 사실은 다릅니다.
