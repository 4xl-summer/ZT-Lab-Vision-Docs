Method · 선언 타입 ZVision.BlobQuery

C#
ZVision.BlobQuery OrderBy<T>(System.Linq.Expressions.Expression<System.Func<ZVision.Blob, T>> key, System.Boolean descending = false)

키 표현식으로 Blob 정렬을 계획합니다. 표현식은 Blob 필드, 상수, 캡처 필드와 지원 연산자만 IR로 변환합니다. 임의 메서드 호출은 지원하지 않습니다. 표현식은 최대 깊이 64, 노드 4096개로 제한되며 정수 연산은 검사된 i128 의미를 따릅니다.

인자

key: 정렬 키를 계산할 제한된 표현식 트리.

descending: 참이면 내림차순으로 정렬합니다. 기본값은 거짓입니다.

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

OrderBy의 사용과 결과 해석

정렬은 항목을 표시하는 순서를 바꾸는 조건입니다. 필터가 제외한 항목을 다시 만들어 내지 않으므로 선택 조건과 정렬 기준을 구별해 읽습니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.
