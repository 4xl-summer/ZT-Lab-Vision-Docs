C#
ZVision.FontOcrRead Read(ZVision.ZImage image, ZVision.FontOcrOptions options, System.Double[] anglesDegrees, ZVision.FontOcrPosition[] positions = null, System.Nullable<ZVision.RecognitionAngleRange> angleRange = null)

명시된 각도로 회전해 문자 유사도를 비교합니다.

인자

image: Gray8 입력 영상입니다.

options: 문자 분할과 후보 설정입니다.

anglesDegrees: 시도할 회전 각도입니다.

positions: 선택적 문자별 기대 위치와 오차입니다.

angleRange: 지정하면 anglesDegrees 대신 범위를 사용합니다.

반환: 문자가 없으면 null, 있으면 판독 결과입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

FontOcrRead.Score: 모든 글자의 유사도 산술 평균이며 확률이 아닙니다.

FontOcrRead.Accepted: 문자 및 문자열 기준 통과 여부입니다.

FontOcrRead.RotationDegrees: 선택한 시계 방향 회전 각도입니다.

FontOcrRead.LineCount: 검출된 줄의 수입니다.

FontOcrRead.LayoutAccepted: 위치 기대값을 지정했을 때 검사 통과 여부이며, 지정하지 않으면 null입니다.

FontOcrRead.Glyphs: 줄 순서의 문자 결과입니다.

사용과 결과 해석

Gray8 입력을 분할하고 지정 각도로 회전해 학습 예제의 문자 유사도를 비교합니다. angleRange가 지정되면 각도 배열 대신 범위를 사용하며 positions는 선택적 기대 위치입니다.

문자가 없으면 null이고 있으면 판독 결과입니다. 각도는 도 단위입니다. 분할 조건과 실제 글자 극성을 학습 자료와 맞추고 각 문자와 전체 판정을 함께 확인하십시오.
