CanAccept

Method · 선언 타입 ZVision.Display.ZDisplayFrameGate

C#
System.Boolean CanAccept(System.Int64 frameId, System.Int64 recipeVersion)

두 세대가 현재 하한 이상인지 확인합니다.

인자

frameId: 확인할 프레임 세대입니다.

recipeVersion: 확인할 레시피 세대입니다.

반환: 수락할 수 있으면 참입니다.

사용과 결과 해석

프레임과 레시피 세대가 현재 각 하한 이상인지 확인하고 불리언을 반환합니다. 이 조회는 단순 판정이며 하한을 갱신하는 동작은 TryAccept입니다.

하한이 (10,3)일 때 (11,3)은 조건을 만족하지만 (11,2)는 레시피가 오래되어 만족하지 않습니다. 두 값을 함께 확인해야 합니다.

프레임과 레시피 하한

CanAccept는 프레임 세대 frameId와 레시피 세대 recipeVersion이 모두 양수이고 현재 각 하한 이상인지 확인합니다. 게이트가 닫혔다면 false입니다. 이 호출은 단순 조회이며 하한을 갱신하지 않습니다. 조건을 만족하는 값을 원자적으로 수락하고 하한을 바꾸는 메서드는 TryAccept입니다.

예를 들어 현재 하한이 프레임 10, 레시피 3이면 (11,3)과 (10,3)은 모두 각 하한 이상입니다. (11,2)는 레시피가 오래되어 false이고 (9,4)는 프레임이 오래되어 false입니다. 0이나 음수도 false입니다. 한쪽만 더 최신이라는 사실로 다른 쪽의 오래된 세대를 보완할 수 없습니다.

항목의미와 처리
양수 조건두 세대가 모두 0보다 커야 함
하한 예현재 (10,3)
(11,3)두 하한 이상 → true
(11,2)레시피가 오래됨 → false
CanAccept조회만, 하한 갱신 없음
TryAccept원자적 수락과 하한 갱신

실행과 판독에서 확인

CanAccept가 true를 돌려준 뒤 실제 수락 전에 다른 흐름이 하한을 갱신할 수 있습니다. 따라서 검사 후 수락을 하나의 동작으로 처리해야 할 때 TryAccept의 반환을 확인합니다. Expect로 정한 하한은 감소할 수 없고 Close 후에는 더 이상 수락하지 않습니다. 영상 표시 시 두 세대를 결과와 함께 보관해 오래된 프레임이 새 설정을 덮어쓰지 않도록 하세요.
