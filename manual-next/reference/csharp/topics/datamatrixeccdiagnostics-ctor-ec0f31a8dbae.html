DataMatrixEccDiagnostics()

기본 Data Matrix 정정 진단을 만듭니다.

이 호출의 입력과 객체 맥락

DataMatrixEccDiagnostics.Version: Data Matrix 버전 번호입니다.

DataMatrixEccDiagnostics.Blocks: 각 RS 블록의 정정 결과입니다.

DataMatrixEccDiagnostics.CorrectedCodewords: 실제로 수정된 전체 코드워드 수입니다.

DataMatrixEccDiagnostics.Accepted: 각 블록의 정정량이 상한을 통과했는지 나타냅니다.

사용 순서와 결과 해석

기본 생성자는 DataMatrixEccDiagnostics의 빈 진단 객체를 만듭니다. 이 호출은 Data Matrix 심볼을 디코딩하거나 RS 정정을 실행하지 않습니다. 실제 판독에서 얻은 진단과 단순히 기본 생성한 객체를 구별해야 합니다.

실제 진단에서는 Text와 Version으로 복구된 문자열과 Data Matrix 버전을 확인하고 Blocks에서 각 RS 블록의 정정 결과를 읽습니다. CorrectedCodewords는 실제 수정된 전체 코드워드 수입니다. 전체 합만 보면 수정이 특정 블록에 집중됐는지는 알 수 없습니다.

Accepted는 각 블록의 정정량이 적용된 상한을 통과했는지 나타냅니다. 텍스트가 있다는 사실이나 전체 수정 합만으로 해당 판정을 대신하지 마세요. Blocks 배열은 속성에서 복사되어 제공되므로 판독 당시의 블록 값과 사용한 한도를 함께 기록하는 것이 좋습니다.

예를 들어 두 RS 블록 중 한 블록에서만 수정이 많이 발생한 경우 전체 수정 합은 그 분포를 감춥니다. Blocks의 각 블록을 확인하고 Accepted를 적용한 상한과 함께 해석하세요. Text가 비어 있지 않다는 것과 블록별 정정량이 사후 한도를 충족하는 것은 같은 판단이 아니므로 결과를 따로 기록해야 합니다.

예를 들어 Blocks에서 두 블록의 수정량이 각각 1과 3이면 전체 CorrectedCodewords는 4로 판독합니다. 하지만 Accepted를 해석하려면 합계 4뿐 아니라 각 블록에 적용된 상한을 확인해야 합니다. 기본 생성된 빈 객체의 값과 실제 ECC 판독 경로에서 채운 결과를 같은 것으로 취급하지 마세요.
