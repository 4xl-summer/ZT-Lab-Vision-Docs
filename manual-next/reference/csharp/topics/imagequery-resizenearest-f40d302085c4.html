ZVision.ImageQuery ResizeNearest(System.Int32 width, System.Int32 height)

최근접 보간 크기 변경을 계획합니다. 실제 처리는 Run에서 수행합니다.

인자

width: 출력 또는 사각형의 폭(픽셀).

height: 출력 또는 사각형의 높이(픽셀).

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

ResizeNearest의 사용과 결과 해석

최근접 보간은 출력 위치에 대응하는 입력 표본 하나를 선택합니다. 마스크처럼 중간 강도가 의미 없는 자료를 다룰 때도 출력의 실제 형식과 규칙을 확인합니다. 입력 격자를 출력 크기로 다시 표본화합니다. 최근접과 이중선형 보간은 소수 좌표에서 값을 만드는 방법이 다르므로 크기뿐 아니라 보간 방식도 재현 조건에 포함합니다.
