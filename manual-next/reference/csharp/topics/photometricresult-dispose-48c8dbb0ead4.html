void Dispose()

결과를 해제합니다.

수명과 사용 순서

포토메트릭 결과가 보유한 자원을 해제합니다. 후속 분석에 필요한 결과 영상과 값을 먼저 처리하고 각 획득 객체의 소유 규칙도 확인하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

광도 결과의 소유권

PhotometricResult는 네 방향 조명 검사에서 만들어진 결과 핸들을 소유합니다. Dispose는 결과 자체를 해제합니다. Image(index)로 이미 얻은 독립 ZImage는 별도 소유이므로 각각 사용 후 Dispose해야 합니다.

인덱스 0은 반사, 1–3은 법선 x·y·z, 4는 형상, 5는 강조, 6은 유효 마스크입니다. 7과 8은 각각 가우시안 곡률과 평균 곡률, 9는 곡률 유효 마스크입니다. 이 영상들은 값의 의미가 다르므로 같은 밝기 척도로 해석하지 않습니다.

항목의미와 사용
Image(0)반사 영상
Image(1–3)법선 x·y·z
Image(4–6)형상·강조·유효 마스크
Image(7–9)두 곡률과 곡률 마스크
획득한 ZImage각각 독립적으로 Dispose
결과 Dispose결과 핸들 해제

예를 들어 곡률 영상을 읽을 때는 해당 곡률 마스크로 유효한 위치를 함께 확인합니다. 인덱스가 범위를 벗어나거나 결과가 닫힌 상태에서 획득하면 오류입니다. 결과 영상과 네 입력 영상의 정렬 및 조명 조건은 별도로 검증합니다.
