사용과 결과 해석

현재 인식 계획을 독립 핸들로 복제합니다. 원본과 복제본은 각각 호출자가 해제합니다.

복제는 인식을 실행하지 않으며 결과 종류를 바꾸지 않습니다. 실행 후 실제 결과 변형과 오류를 확인하십시오.

인식 계획과 결과 종류

RecognitionQuery.Clone은 현재 인식 계획을 독립 핸들로 복제합니다. 이 호출은 인식을 실행하지 않고 기존 계획의 결과 종류도 바꾸지 않습니다. 원본과 복제본은 각각 호출자가 Dispose해야 하며 인식 결과는 해당 계획의 실행 단계에서 얻습니다.

예를 들어 같은 입력과 공통 전처리에서 출발하는 두 인식 흐름을 준비하려면 공통 계획을 복제하고 각 흐름을 별도로 실행합니다. 단, Clone만 호출한 시점에는 디코드 텍스트나 OCR 결과가 만들어지지 않았습니다. 실행 이후 실제 결과 종류와 상태를 확인하고, 읽히지 않은 결과를 빈 텍스트의 성공으로 치환하지 마세요.

수명과 결과 확인

복제 계획 하나를 해제해도 다른 계획의 해제 책임이 사라지지 않습니다. 캡처 영상이나 소유 결과를 별도로 취득한 경우에도 각 객체의 계약에 맞게 정리합니다. 비교 기록에는 입력 ROI와 사용한 인식 설정, 결과 형식과 성공 여부를 함께 남겨 서로 다른 실행을 섞지 않도록 합니다.
