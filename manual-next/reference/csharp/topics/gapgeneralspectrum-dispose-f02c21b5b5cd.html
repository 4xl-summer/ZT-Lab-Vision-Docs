직접 DFT 결과 정리

GapGeneralSpectrum은 임의 크기 직접 DFT의 복소 스펙트럼을 소유하는 호환 API입니다. Dispose는 이 객체의 네이티브 핸들을 해제합니다. Dispose 이후 Metadata나 Parts 또는 InverseComplex를 호출하려고 하지 않습니다.

Parts는 실수부와 허수부를 각각 독립 행 우선 배열로 복사합니다. 예를 들어 한 계수가 3+4i라면 두 배열의 같은 위치에서 각각 3과 4를 읽습니다. 진폭 5만 저장하면 위상을 보존하지 못하므로 복소 역변환을 계획한다면 두 성분을 함께 다룹니다.

항목의미와 사용
Metadata변환 크기와 원점
Parts.Real독립 실수부 배열
Parts.Imaginary독립 허수부 배열
InverseComplex복소 역변환 결과
crop원본 입력 크기 사용 여부
Dispose스펙트럼 핸들 해제

InverseComplex는 켤레 대칭이 아닌 경우에도 실수와 허수 역변환 배열을 반환하며 crop으로 입력 크기 여부를 선택합니다. 필요한 복사 배열이나 역변환을 먼저 얻고 스펙트럼을 해제합니다. 이 Gap API는 0.1.x 호환용으로 표시되어 있습니다.
