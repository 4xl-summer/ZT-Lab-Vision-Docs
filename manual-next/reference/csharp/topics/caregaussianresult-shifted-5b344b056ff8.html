ZVision.CareGaussianResult Shifted(System.Int32 shift)

정수 결과의 비트를 이동합니다.

인자

shift: -7~7이며 양수는 포화, 음수는 하위 비트를 버립니다.

반환: 호출자가 Dispose할 독립 결과입니다.

이 호출의 입력과 객체 맥락

Gray8 또는 Gray16 정수 Gaussian 결과에 −7~7 비트 이동을 적용한 독립 결과를 만듭니다. 양수는 왼쪽 이동 후 형식 범위에 포화되고 음수는 오른쪽으로 이동해 하위 비트를 버립니다. 예를 들어 5를 한 비트 오른쪽으로 이동하면 2입니다. 부동소수 결과에도 적용된다고 가정하지 마세요. 원래 결과와 새 결과는 별도 소유 객체입니다. 사용 후 각 결과를 Dispose합니다.

비트 이동과 결과 소유권

Shifted는 Gray8 또는 Gray16 정수 Gaussian 결과에서 지정한 비트 이동을 적용한 독립 결과를 만듭니다. shift 범위는 −7~7입니다. 양수는 왼쪽으로 이동한 뒤 해당 픽셀 형식의 상한에 포화하고, 음수는 오른쪽으로 이동해 밀려난 하위 비트를 버립니다. 원본 객체를 교체하는 호출이 아닙니다.

예를 들어 5를 오른쪽으로 한 비트 이동하면 이진수 101에서 끝 비트가 버려져 2가 됩니다. Gray8에서 200을 왼쪽으로 한 비트 이동하면 400을 그대로 저장하지 않고 255로 포화합니다. 원본 결과와 새 결과는 각각 소유 객체이므로 필요한 영상을 획득한 뒤 각자 Dispose하십시오.
