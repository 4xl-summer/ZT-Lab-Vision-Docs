사용과 결과 해석

마커 재구성의 기본 설정을 만듭니다. 기본은 팽창, 8연결, 최대 1000 반복, 작업 예산 100000000입니다.

팽창은 mask 아래로 전파하고 침식은 mask 위로 전파합니다. 데이터와 원하는 방향에 맞게 Mode를 선택하고 반복·작업 상한이 충분한지 결과를 확인하십시오.

방향과 제한을 정하는 순서

ReconstructionOptions는 마커와 마스크를 이용한 형태학적 재구성의 설정 객체입니다. 생성 직후 Mode는 Dilation, Connectivity는 Eight, MaxIterations는 1000, WorkBudget은 100000000입니다. 생성자는 입력 영상을 처리하지 않으며 설정을 채워 Reconstruct 호출에 전달합니다.

팽창 재구성은 마스크를 상한으로 하여 마커 값을 퍼뜨리고, 침식 재구성은 마스크를 하한으로 하여 값을 전파합니다. 예를 들어 관심 영역의 일부를 마커로 주면 허용 마스크의 연결 구조 안에서 전파하는 문제를 설정할 수 있습니다. 두 영상은 해당 연산의 크기·형식 조건에 맞아야 합니다.

MaxIterations는 동기 반복 수의 상한이고 WorkBudget은 이웃 검사 작업의 상한으로 서로 다른 제한입니다. 반환 TopologyIterationResult의 Image와 Iterations, Converged를 함께 확인해 반복이 수렴했는지 살핍니다. Image는 결과가 소유한 영상이므로 결과 사용 수명도 관리합니다.

연결성은 어떤 이웃으로 값이 전파되는지를 정하고 Mode는 마스크에 대한 상한·하한 관계를 정합니다. 마커와 마스크의 역할을 뒤바꾸면 같은 설정 이름이라도 의도한 전파 문제가 달라집니다. 결과를 비교할 때는 입력 두 영상, 연결성, 방향, 제한과 Converged를 한 묶음으로 기록합니다.

항목의미와 확인
Mode기본 Dilation; 팽창 또는 침식
Connectivity기본 Eight 연결
MaxIterations기본 1000 동기 반복
WorkBudget기본 100000000 이웃 검사
입력마커와 마스크 영상
결과 확인Image, Iterations 및 Converged

비교할 때 확인

예산을 높이는 것과 반복 상한을 높이는 것은 같은 설정이 아닙니다. 이웃 검사에 필요한 총 작업량과 수렴에 필요한 반복 횟수는 입력 형상에 따라 각각 달라집니다. 결과가 미수렴이라면 두 제한과 함께 마커·마스크의 관계를 확인하고 같은 입력에서 비교합니다.
