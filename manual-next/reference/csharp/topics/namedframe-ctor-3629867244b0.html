NamedFrame(System.String name, System.UInt64 id)

좌표계 이름과 ID를 지정합니다.

인자

name: 고유 이름입니다.

id: 0이 아닌 프레임 ID입니다.

설정과 사용 흐름

좌표계의 고유 이름과 0이 아닌 프레임 ID를 묶습니다. 이름은 사람이 구분하기 위한 문자열이고 ID는 좌표계 연결 시 사용하는 식별자입니다.

카메라와 보드처럼 서로 다른 좌표계에는 구분되는 이름과 ID를 사용하십시오. 동일한 좌표계를 참조하는 데이터는 같은 식별 관계를 유지해야 합니다.

이름과 프레임 ID

NamedFrame은 좌표계의 고유 이름과 0이 아닌 ID를 묶습니다. 이름과 ID는 카메라, 기준판, 로봇처럼 서로 다른 좌표계를 구분하는 데 사용됩니다. 이 값 자체가 위치나 회전 행렬을 만들지는 않으며, 실제 좌표 변환은 해당 프레임을 연결하는 강체 변환에서 정의합니다.

예를 들어 camera를 ID 1, world를 ID 2로 관리하면 이름을 사용해 원본 camera에서 목표 world로 가는 변환을 요청할 수 있습니다. 반환 방향은 목표←원본으로 해석합니다. 서로 다른 좌표계에 같은 이름이나 ID를 재사용하지 않고 간선에 기록한 프레임과 이름 배열의 대응을 유지하십시오.

역할이름과 좌표계 식별 관계를 묶음

예: world목표 프레임 이름
