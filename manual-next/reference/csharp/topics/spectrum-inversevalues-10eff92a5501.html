ZVision.InverseSpectrum InverseValues(System.Boolean crop = true)

실수 역변환합니다.

인자

crop: 입력 크기로 자릅니다.

반환: 독립 값입니다.

관련 입력의 확인된 조건

InverseSpectrum.Width: 결과 너비 픽셀입니다.

InverseSpectrum.Height: 결과 높이 픽셀입니다.

InverseSpectrum.Values: 독립 행 우선 값입니다.

데이터와 계산

주파수 스펙트럼을 실수 값 배열로 역변환합니다.

crop이 참이면 패딩 전 입력 크기로 자르고 거짓이면 변환 격자 전체를 반환합니다. 결과 크기와 배열을 함께 읽어 행 경계를 올바르게 해석해야 합니다.

항목이 호출의 의미
인자crop 여부
모델Spectrum
배열 배치행 우선
수명독립 결과와 소유자는 각각 관리

결과 확인

2×2 상수 1의 Backward 정규화 스펙트럼을 변화 없이 역변환하면 각 출력은 1입니다. 실제 부동소수 결과는 허용 오차로 비교하십시오.

Spectrum의 InverseValues 결과를 다른 영상 또는 주파수 처리에 연결할 때는 크기, 원점 및 정규화를 함께 확인하십시오.
