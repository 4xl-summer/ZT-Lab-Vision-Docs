Fit

Method · 선언 타입 ZVision.DepthCalibration

C#
static ZVision.DepthCalibration Fit(System.Double[] raw, System.Double[] reference, ZVision.LengthUnit unit)

대응 표본으로 보정을 적합합니다. 깊이는 최소 두 개의 서로 다른 raw 값이 필요합니다.

인자

raw: 대응하는 원시 높이 표본입니다.

reference: 대응하는 기준 표본입니다.

unit: 위치와 거리의 길이 단위입니다.

반환: 계산된 결과입니다.

깊이 보정의 선형 적합

원시 깊이와 기준 깊이의 대응값에서 배율과 절편을 추정합니다. 두 목록의 길이는 같아야 하며 유한한 값으로 이루어진 두 쌍 이상이 필요합니다. 원시 입력이 모두 같으면 기울기를 결정할 수 없으므로 서로 다른 깊이를 포함해야 합니다.

원시값 0, 1, 2와 기준값 1, 3, 5를 대응시키면 scale 2와 offset 1인 직선이 나옵니다. 얻은 식을 새 샘플에 적용하고 평가하면 학습에 사용한 범위 밖에서의 차이도 확인할 수 있습니다. 데이터의 실제 단위를 모델과 동일하게 지정합니다.

확인 항목해석
raw서로 다른 깊이를 포함하는 원시 목록
reference동일 순서와 개수의 기준 목록
결과scale과 offset을 가진 보정 모델
실패대응 부족, 퇴화 또는 잘못된 값
