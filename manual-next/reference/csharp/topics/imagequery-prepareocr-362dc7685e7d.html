ZVision.PreparedOcrQuery PrepareOcr(ZVision.OcrRegionSpec spec)

Gray8 이미지의 지정 영역 준비를 지연 쿼리에 등록합니다.

인자

spec: 처리에 사용할 설정입니다.

반환: 실행할 인식 쿼리입니다.

관련 입력의 확인된 조건

spec.LightText: 밝은 글자를 어두운 글자로 만들기 위해 픽셀을 반전할지 나타냅니다.

spec.Normalize: 단색이 아닌 영역의 픽셀 범위를 0~255로 선형 정규화할지 나타냅니다.

spec.X: 현재 이미지 기준 영역의 왼쪽 x 좌표입니다.

spec.Y: 현재 이미지 기준 영역의 위쪽 y 좌표입니다.

spec.Width: 영역 또는 준비 영상의 너비(픽셀)입니다.

spec.Height: 영역 또는 준비 영상의 높이(픽셀)입니다.

spec.QuarterTurns: 시계 방향 90도 회전 횟수입니다. OCR 영역은 0~3입니다.

인자별 입력 조건

인자형식역할과 조건
specZVision.OcrRegionSpec처리에 사용할 설정입니다.

문자 인식 영역 준비

C#의 ImageQuery 호출은 이 처리를 실행 계획에 연결합니다. OcrRegionSpec으로 사각형 ROI, 90도 단위 회전, 밝은 문자 여부 및 정규화를 지정해 OCR에 사용할 영역을 준비합니다. 반환 정보의 크기와 대비, 준비 좌표에서 입력 로컬 및 전역 좌표로의 변환을 함께 확인합니다.

계획을 실행해 얻은 결과의 해석에서는 회전된 준비 영상의 모서리를 원본에 표시할 때 변환을 적용해야 합니다. 동일한 폭과 높이라는 이유만으로 좌표계가 같다고 추정하지 않습니다. 준비 영상 생성은 문자 판독 자체가 아니며 인식에는 설정과 엔진이 별도로 필요합니다.

이 호출은 지연 검사 계획을 구성합니다. 실행 결과와 그 출력의 소유 규칙을 반환 형식에서 확인하고 Dispose가 필요한 각 자원을 사용 후 해제합니다. 별도 분기가 필요하면 계획을 복제합니다.
