static System.ValueTuple<ZVision.ZImage, ZVision.GapCopyReport> FillSelected(ZVision.ZImage destination, ZVision.ZImage mask, System.Int64 x, System.Int64 y, System.UInt64 width, System.UInt64 height, System.Double value, System.Boolean invertMask, System.Int64 maskOffsetX = 0, System.Int64 maskOffsetY = 0, System.Boolean clip = false)

마스크의 care 또는 dont-care 위치를 상수로 채웁니다.

인자

destination: 기준 목적 영상입니다.

mask: Gray8 선택 마스크입니다.

x: 목적 ROI 상대 x입니다.

y: 목적 ROI 상대 y입니다.

width: 영역 너비입니다.

height: 영역 높이입니다.

value: 모든 채널에 쓸 유한 상수입니다.

invertMask: 참이면 0인 dont-care를 선택합니다.

maskOffsetX: 마스크 x 오프셋입니다.

maskOffsetY: 마스크 y 오프셋입니다.

clip: 목적 밖 선택 픽셀 허용 여부입니다.

반환: 독립 영상과 처리 수입니다.

관련 입력의 확인된 조건

destination.Origin: ROI의 글로벌 픽셀 원점입니다.

destination.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

FillSelected의 사용과 결과 해석

선택 마스크에 포함된 위치만 채우는 경우 선택 여부와 채울 값을 별도로 다룹니다. 마스크의 크기와 좌표 기준이 대상과 맞는지 확인합니다. 영역 복사와 채우기는 위치와 크기 및 선택 마스크를 기준으로 수행합니다. 원본과 목적 영상의 ROI 좌표를 각각 확인하고, 화면 밖 부분의 처리와 반환 보고서를 함께 살펴봅니다.

항목이 호출에서 확인할 내용
destination기준 목적 영상입니다.
maskGray8 선택 마스크입니다.
x목적 ROI 상대 x입니다.
y목적 ROI 상대 y입니다.
width영역 너비입니다.
반환독립 영상과 처리 수입니다.
