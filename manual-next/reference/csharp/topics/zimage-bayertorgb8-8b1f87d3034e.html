ZVision.ZImage BayerToRgb8(ZVision.BayerPattern pattern, System.Double redGain = 1, System.Double greenGain = 1, System.Double blueGain = 1)

Bayer Gray8 영상을 RGB8로 복원합니다.

인자

pattern: 센서 원점 기준 배열입니다.

redGain: 빨간색 배율입니다.

greenGain: 초록색 배율입니다.

blueGain: 파란색 배율입니다.

반환: 독립 소유 RGB8 영상입니다.

관련 입력의 확인된 조건

pattern.Rggb: RG와 GB 행입니다.

pattern.Bggr: BG와 GR 행입니다.

pattern.Grbg: GR과 BG 행입니다.

pattern.Gbrg: GB와 RG 행입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
patternZVision.BayerPattern센서 원점 기준 배열입니다.
redGainSystem.Double빨간색 배율입니다.
greenGainSystem.Double초록색 배율입니다.
blueGainSystem.Double파란색 배율입니다.

pattern의 입력 값

필드의미와 조건
BGGR센서 원점 기준 BG/GR 배열입니다.
GBRG센서 원점 기준 GB/RG 배열입니다.
GRBG센서 원점 기준 GR/BG 배열입니다.
RGGB센서 원점 기준 RG/GB 배열입니다.

결과와 사용 순서

독립 소유 RGB8 영상입니다.

입력과 결과 해석

색상 처리는 채널 순서, 입력 형식과 값 범위의 영향을 받습니다. 알려진 단색 입력을 이용해 각 출력 채널이 기대한 의미를 갖는지 확인하고 서로 다른 색 공간의 값을 혼동하지 마세요.
