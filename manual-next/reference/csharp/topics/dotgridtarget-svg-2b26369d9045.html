static System.String Svg(ZVision.MetricGrid grid, System.Double diameter, System.Double margin)

부호화 표식이 없는 어두운 원 격자를 SVG 문자열로 만듭니다.

인자

grid: 행열·간격·길이 단위가 있는 격자입니다.

diameter: 격자 단위의 양의 원 지름입니다.

margin: 격자 단위의 인쇄 영역 여백입니다.

반환: 실제 크기가 밀리미터로 지정된 독립 SVG 문자열입니다.

관련 입력의 확인된 조건

grid.Unit: 간격의 길이 단위입니다.

이 호출의 입력과 객체 맥락

MetricGrid의 행·열·간격과 양의 원 지름, 여백으로 부호화 표식이 없는 어두운 원 격자를 SVG 문자열로 만듭니다. 지름과 여백은 격자의 단위로 주며 출력 SVG에는 실제 크기가 밀리미터로 지정됩니다. 출력 문자열 자체는 측정된 카메라 이미지가 아니므로 인쇄 크기와 실제 관측은 별도로 확인하세요.
