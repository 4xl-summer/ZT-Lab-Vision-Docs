static ZVision.BlobContourPart[] Segment(ZVision.Point2[] points, System.Double[] attributes, System.Double low, System.Double high, System.Boolean closed, System.UInt64 workBudget)

포괄 범위를 만족하는 최대 연속 점 구간을 만듭니다.

인자

points: 유한 ROI 로컬 점 배열입니다.

attributes: 각 점의 유한 속성값입니다.

low: 포함 하한입니다.

high: 포함 상한입니다.

closed: 입력 끝과 시작의 암묵적 연결 여부입니다.

workBudget: 총 점 처리 상한입니다.

반환: 순서 있는 독립 윤곽 구간 배열입니다.

Segment의 사용과 결과 해석

분할한 각 구간은 원래 곡선을 따라간 위치와 연관됩니다. 서로 다른 구간의 끝을 임의로 이어 하나의 닫힌 영역이라고 해석하지 않습니다. 하나의 윤곽을 지정 조건에 따라 여러 구간으로 나눕니다. 구간별 시작과 끝의 순서는 원래 윤곽의 순서와 함께 해석하고, 닫힌 경계의 시작점과 마지막 연결도 확인합니다.
