WarpAffine

Method · 선언 타입 ZVision.ImageQuery

C#
ZVision.ImageQuery WarpAffine(ZVision.Affine2 matrix, System.Int32 width, System.Int32 height, ZVision.Interpolation interpolation, System.Double border)

원본 로컬에서 출력 로컬로의 아핀 변환을 역매핑해 리샘플링합니다. 14개 픽셀 형식을 지원합니다. 계획에 등록하며 픽셀 처리는 실행 시 수행합니다.

인자

matrix: 원본 로컬 픽셀에서 출력 로컬 픽셀로의 변환입니다.

width: 출력 폭 또는 스트립 폭입니다.

height: 양의 출력 높이(픽셀)입니다.

interpolation: 표본 보간 방식입니다.

border: 영역 밖 표본에 사용할 유한 상수 강도입니다.

반환: 연산이 등록된 현재 계획입니다.

관련 입력의 확인된 조건

matrix.A: x 출력의 x 계수입니다.

matrix.B: x 출력의 y 계수입니다.

matrix.Tx: x 출력의 이동량입니다.

matrix.C: y 출력의 x 계수입니다.

matrix.D: y 출력의 y 계수입니다.

matrix.Ty: y 출력의 이동량입니다.

WarpAffine의 사용과 결과 해석

matrix는 원본 로컬에서 출력 로컬로 향하는 변환입니다. 출력에서 원본을 역으로 찾아 표본화하므로 같은 행렬을 반대 방향으로 착각하지 않습니다. 출력 격자의 각 위치에서 원본 영상을 표본화하는 변환을 계획합니다. 변환 방향과 보간 및 경계값을 함께 기록해야 위치 이동과 영상 밖 픽셀의 값을 재현할 수 있습니다.

항목이 호출에서 확인할 내용
matrix원본 로컬 픽셀에서 출력 로컬 픽셀로의 변환입니다.
width출력 폭 또는 스트립 폭입니다.
height양의 출력 높이(픽셀)입니다.
interpolation표본 보간 방식입니다.
border영역 밖 표본에 사용할 유한 상수 강도입니다.
