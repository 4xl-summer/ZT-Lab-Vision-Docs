이 호출의 입력과 객체 맥락

AdvancedXyzLabResult.Channel: Lab 평면을 독립 영상으로 가져옵니다.

사용 순서와 결과 해석

AdvancedXyzLabResult가 소유한 XYZ→Lab 변환 결과를 해제합니다. 결과가 열린 동안 Channel로 Lab의 각 평면을 독립 GrayF64 영상으로 가져올 수 있습니다. 평면 번호와 이 변환에 사용한 백색점을 함께 기억해야 수치가 어느 축과 기준에 속하는지 알 수 있습니다.

Channel에서 얻은 각 ZImage는 호출자가 별도로 Dispose해야 합니다. 예를 들어 세 평면을 모두 받았다면 평면 결과 하나를 Dispose했다고 해서 별도의 세 영상 핸들을 해제한 것으로 계산하지 않습니다. 필요한 영상의 처리를 마친 뒤 영상과 결과 객체의 수명을 각각 마무리하세요.

이 결과는 입력 XYZ 평면과 지정된 백색점으로 계산한 Lab 값입니다. 같은 숫자 배열이라도 백색점이나 좌표 기준이 다른 결과를 무조건 같은 조건으로 비교하지 마세요. 반환 평면은 독립 영상이지만 결과를 해제한 뒤에는 해당 결과에서 새 Channel을 취득하지 않습니다.

예를 들어 Channel을 여러 번 사용해 필요한 평면을 가져왔다면 반환된 각 영상 변수의 소유권을 개별적으로 추적하세요. Lab 수치는 지정 백색점을 기준으로 계산되므로 두 결과의 채널 값을 비교하기 전에 동일한 백색점과 입력 XYZ 조건인지 확인해야 합니다. 이 비교는 결과 핸들을 해제하는 동작과 별개의 계산입니다. 평면을 추가로 취득하려면 그 이전에 결과가 열려 있어야 합니다. 이미 얻은 각 GrayF64 영상은 별도 소유권이므로 결과와 함께 따로 관리합니다.

예를 들어 백색점 설정이 다른 두 변환 결과의 두 번째 평면을 비교할 때 단순히 배열 위치가 같다는 이유만으로 동일한 색 기준이라고 결론내리지 않습니다. 입력 XYZ 평면과 사용한 백색점을 함께 확인하세요. 결과가 열린 동안 Channel을 통해 평면을 얻고 반환된 각 영상의 사용 종료 시점을 별도로 관리합니다.
