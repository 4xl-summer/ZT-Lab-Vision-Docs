이 호출의 입력과 객체 맥락

GapExposureFusionResult.Image: 상대 방사량 또는 유효 마스크를 얻습니다.

사용 흐름과 판독 기준

이 객체는 여러 노출에서 계산한 상대 방사량과 유효 마스크를 보유합니다. Image(0)은 GrayF32 방사량 영상, Image(1)은 Gray8 유효 마스크를 각각 독립 영상 핸들로 반환합니다. 사용 순서는 결과 생성, 필요한 두 영상의 획득과 판독, 결과 해제입니다. 두 영상은 서로 다른 의미이므로 마스크의 0을 실제 방사량 0이라는 값과 혼동하지 않습니다.

이미 획득한 영상은 각각 별도 소유 핸들이므로 결과 객체를 해제하는 것과 영상 핸들을 해제하는 것은 별개입니다. 영상이 더 필요하다면 결과를 닫기 전에 해당 인덱스로 획득하고, 보관이 끝난 영상도 각각 Dispose합니다. 결과를 닫은 뒤 이 객체의 Image를 다시 호출하면 열린 결과가 아니므로 ObjectDisposedException이 발생합니다.

입력 노출은 2~256장의 같은 크기와 원점의 Gray8 영상이며 각 노출 시간은 양수 유한 값입니다. 이 메서드는 그 입력을 다시 합성하거나 저장하는 동작이 아니라 결과 핸들의 수명을 끝냅니다. 예를 들어 Image(0)과 Image(1)을 모두 얻었다면 결과 객체 한 개와 반환 영상 두 개의 사용 종료 시점을 각각 관리합니다.
