static ZVision.ExposureFusionResult Create(ZVision.ZImage[] images, System.Double[] exposures)

정렬된 노출 영상을 결합합니다.

인자

images: 입력 Gray8 영상들입니다.

exposures: 각 영상의 양수 노출 시간입니다.

반환: 해제할 결과입니다.

이 호출의 입력과 객체 맥락

정렬된 Gray8 입력 영상과 각 영상에 대응하는 양의 노출 시간을 결합합니다. 영상과 시간은 같은 순서여야 합니다. 반환 결과의 방사량 영상과 유효 마스크를 함께 살펴보고, 획득한 각 영상과 결과 객체를 별도로 Dispose합니다. 이 단계에서 입력 간 정렬을 자동으로 수행한다고 가정하지 마세요.

노출 영상 결합

정렬된 Gray8 영상 배열과 각 영상에 대응하는 양수 노출 시간 배열을 받아 노출 결합 결과를 만듭니다. 이미지와 노출의 순서를 같이 유지해야 각 밝기값이 올바른 노출 시간과 연결됩니다.

노출이 다른 영상도 같은 장면의 같은 위치가 대응해야 합니다. 정렬이 틀어지면 경계가 겹쳐 보이거나 잘못 결합될 수 있으므로 촬영 이동과 정렬 상태를 입력 전에 확인합니다. 결과는 상대 방사량 영상과 유효 마스크를 제공합니다.

Radiance와 Validity에서 획득한 영상은 각각 독립 소유이고 결과 객체와 별도로 Dispose합니다. 유효하지 않은 위치를 방사량 0의 정상 표본으로 해석하지 말고 마스크를 함께 확인합니다. 노출 시간과 결과의 단위를 기록합니다.

노출 시간이 1과 2인 두 입력을 전달한다면 첫 영상과 첫 시간, 둘째 영상과 둘째 시간을 같은 순서로 짝지어야 합니다. 시간 배열만 재정렬하면 각 픽셀에 적용되는 노출 정보가 달라집니다.

유효 마스크가 제외한 위치는 포화 또는 입력 조건 때문에 방사량을 사용할 수 없는 영역일 수 있습니다. 화면에서 검게 표시되더라도 이를 측정된 방사량 0으로 단정하지 말고 해당 위치의 Validity를 같이 봅니다.

출력의 각 위치에 대해 원본 입력들과 결과 마스크를 함께 확인하면 포화되거나 유효한 표본이 부족한 부분을 판별하는 데 도움이 됩니다. 결합된 결과의 화면 색만으로 어느 노출이 기여했는지는 확정할 수 없습니다.

촬영 조건이 다르면 동일 대상이라도 영상의 원점이나 크기가 달라질 수 있습니다. 처리 전 기하를 맞추고, 각 영상의 양수 노출 시간을 그 영상과 동일한 인덱스에 유지합니다.
