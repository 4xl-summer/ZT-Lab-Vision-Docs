static ZVision.GapOrthogonalWavelet ForwardFamily(ZVision.ZImage image, System.UInt64 levels, ZVision.GapWaveletFamily family)

선택한 계열의 다단 변환을 생성합니다.

인자

image: Gray8/16/F32 입력 영상입니다.

levels: 양축에서 지원되는 분해 단계입니다.

family: 웨이블릿 계열입니다.

반환: 해제할 독립 소유 모델입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

family.Daubechies2: 주기 경계의 4탭 Daubechies-2입니다.

family.Daubechies3: 주기 경계의 6탭 Daubechies-3입니다.

family.Daubechies4: 주기 경계의 8탭 Daubechies-4입니다.

입력 영상과 분해 단계 수, 선택한 웨이블릿 계열로 독립 소유 변환 모델을 만듭니다. 생성 후 계수 복사와 역변환은 모델의 별도 호출이며 입력 ROI와 크기 조건을 확인해야 합니다. 모델을 사용한 뒤 Dispose하고 복원 영상도 별도로 해제합니다.
