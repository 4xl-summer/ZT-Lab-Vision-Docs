static ZVision.ZImage Gray8(ZVision.ZImage image, System.UInt64 levels)

밝기를 지정된 개수의 왼쪽 빈 경계값으로 변환합니다.

인자

image: Gray8 입력 영상입니다.

levels: 2~256 양자화 수준 수입니다.

반환: 독립 소유 Gray8 영상입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

Gray8 입력 밝기를 2~256개 수준의 왼쪽 빈 경계값으로 바꿉니다. levels는 출력 밝기의 양자화 단계 수이며 출력 영상의 픽셀 수가 아닙니다. 반환 Gray8 영상은 독립 소유이므로 사용 후 Dispose합니다. 같은 입력을 다른 levels로 처리했다면 결과의 밝기 단계를 같은 세밀도로 비교하지 마세요.
