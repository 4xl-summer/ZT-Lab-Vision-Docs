ZVision.ZImage Threshold(System.Byte t)

인자

t: 원본 픽셀 값 단위의 임계값입니다.

반환: 호출자가 Dispose해야 하는 새 소유 영상입니다.

오류: T:ZVision.ZVisionException 회색 형식이 아니거나 입력 픽셀이 유한하지 않으면 발생합니다.

호출에 필요한 입력

임계값 이상을 255, 미만을 0으로 분할합니다.
