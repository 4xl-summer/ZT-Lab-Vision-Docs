static ZVision.FrameQueue Create(System.UInt64 capacity, ZVision.FrameQueuePolicy policy)

유한 용량의 독립 큐를 만듭니다.

인자

capacity: 큐 용량으로 1부터 65536까지입니다.

policy: 큐가 가득 찼을 때 사용할 정책입니다.

반환: 호출자가 해제할 큐입니다.

관련 입력의 확인된 조건

policy.RejectNew: 새 프레임을 거부합니다.

policy.DropOldest: 가장 오래된 프레임을 버립니다.

policy.Wait: 지정 시간 동안 빈 자리를 기다립니다.

이 호출의 입력과 객체 맥락

용량 1~65536의 독립 FIFO 큐를 만들고 가득 찼을 때의 정책을 지정합니다. RejectNew는 새 항목을 거부하고 DropOldest는 가장 오래된 항목을 제거한 뒤 추가하며 Wait는 제한 시간 동안 공간을 기다립니다. 반환 큐는 사용 후 Dispose합니다. 이 큐는 카메라를 열거나 영상을 자동 취득하지 않습니다.
