사용 순서와 결과 보관

FlexibleContourMetrics()는 윤곽 길이와 이산 곡률을 담을 빈 스냅샷을 만듭니다. 인자 없는 생성 자체는 윤곽 점열을 입력받거나 계측을 실행하지 않습니다. 실제 윤곽에 대한 값은 FlexibleRegions.ContourMetrics가 계산하여 채우므로 새로 만든 빈 객체의 기본값을 실제 측정 결과로 취급하지 않습니다.

Length는 윤곽 전체 길이이며 입력 점의 픽셀 좌표 단위입니다. Curvature는 각 점의 부호 있는 회전각을 그 점에 인접한 현 길이의 평균으로 나눈 값입니다. 따라서 길이와 곡률은 같은 차원이 아니고 점열의 순서를 뒤집으면 부호 해석에도 영향을 줄 수 있습니다. 배열 항목은 입력 점의 순서와 연결해 읽습니다.

Curvature 접근자는 내부 배열의 복사본을 반환하므로 반환 배열의 원소를 수정해도 스냅샷 내부 배열을 직접 변경하는 것이 아닙니다. 빈 생성 상태의 Length는 기본 숫자이고 Curvature는 빈 배열입니다. 실제 계측 결과와 비교할 때 입력 윤곽의 열린·닫힌 조건과 좌표 기준, 사용한 점의 순서를 함께 보존합니다.
