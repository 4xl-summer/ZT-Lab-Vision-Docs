Method · 선언 타입 ZVision.EdgeQuery

C#
ZVision.Point2[] Points(System.UInt64 selector, System.Boolean byLabel = false)

Copies an included edge's ordered points.

인자

selector: Index or stable label.

byLabel: Whether selector denotes a label.

반환: Independent point array.

이 호출의 입력과 객체 맥락

Point2.X: 영역의 로컬 x 좌표입니다.

Point2.Y: 영역의 로컬 y 좌표입니다.

현재 포함된 에지 하나의 점들을 순서대로 복사합니다. 기본 selector는 0 기반 포함 인덱스이고 레이블 선택이 참이면 안정된 레이블입니다. 예를 들어 중간 에지를 제외하면 조밀 인덱스는 바뀔 수 있으나 재포함 가능한 레이블은 유지됩니다. 반환 점 값은 독립 복사이며 에지 순서와 메타데이터를 함께 사용하세요.
