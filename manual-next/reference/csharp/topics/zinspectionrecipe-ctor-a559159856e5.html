C#
ZInspectionRecipe(System.Nullable<ZVision.Display.ZPixelRect> roi = null, System.Int32 gaussianKernel = 3, System.Double gaussianSigma = 1, System.Byte threshold = 128, System.Int32 closeKernel = 3, System.UInt64 minArea = 1)

검사 설정을 생성합니다.

인자

roi: 입력 로컬 영역 또는 전체 영상입니다.

gaussianKernel: 홀수 가우시안 커널 크기입니다.

gaussianSigma: 양의 표준편차입니다.

threshold: 이진화 임계값입니다.

closeKernel: 홀수 닫기 커널 크기입니다.

minArea: 선택할 최소 영역 픽셀 수입니다.

설정과 사용 흐름

입력 로컬 ROI 또는 전체 영상, Gaussian과 닫기 커널, 임계값 및 최소 영역 면적으로 검사 설정을 만듭니다. 커널은 홀수이고 Gaussian sigma는 양수입니다.

threshold는 이진화 밝기 기준이며 minArea는 픽셀 수입니다. ROI를 지정하면 전체 영상 좌표와 혼동하지 말고 입력 로컬 범위를 사용하십시오.
