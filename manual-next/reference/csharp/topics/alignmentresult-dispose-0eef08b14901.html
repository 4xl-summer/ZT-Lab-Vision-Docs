Dispose

Method · 선언 타입 ZVision.AlignmentResult

C#
void Dispose()

소유한 네이티브 결과 핸들을 해제합니다.

이 호출의 입력과 객체 맥락

AlignmentResult.Info: 결과 메타데이터 스냅샷입니다.

AlignmentResult.Found: 정렬에 유효한 매치를 찾았는지 나타냅니다.

AlignmentResult.Aligned: 기준 영상 기하의 정렬된 GrayF64 영상입니다. 독립 핸들을 Dispose해야 합니다.

AlignmentResult.ValidMask: 유효 보간 픽셀을 255로 표시하는 Gray8 영상입니다. 독립 핸들을 Dispose해야 합니다.

사용 순서와 결과 해석

AlignmentResult의 소유 정렬 결과 핸들을 해제합니다. 해제 전 Found와 Info를 통해 유효한 매치가 있는지와 정렬 메타데이터를 확인합니다. 실행 객체가 만들어졌다는 사실만으로 Found가 참이라고 가정하지 말고 성공 상태를 먼저 살피세요.

Aligned는 기준 영상 기하의 정렬된 GrayF64 영상이고 ValidMask는 유효 보간 픽셀을 255로 표시한 Gray8 영상입니다. 두 속성에서 획득한 영상은 독립 소유 핸들이므로 AlignmentResult와 각각 별도로 Dispose해야 합니다. 필요한 영상은 결과가 열린 동안 취득합니다.

예를 들어 정렬 영상에서 수치가 0인 픽셀을 보더라도 그것만으로 원래 입력에 실제 0이 있었는지 판단할 수 없습니다. ValidMask를 함께 읽어 유효 보간 위치인지 확인하세요. Info처럼 이미 얻은 값 스냅샷과 새로 취득해야 하는 영상 핸들의 수명도 구분합니다.

예를 들어 정렬 영상의 한 위치가 검은색으로 표시되어도 원본의 어두운 픽셀과 유효하지 않은 보간 위치를 시각적으로만 구별하기 어렵습니다. ValidMask의 해당 위치를 함께 확인한 뒤 측정 영역으로 사용할지 결정하세요. 정렬 결과의 성공 여부, 영상과 마스크의 핸들, 이미 읽은 메타데이터는 각각 다른 역할을 가집니다.

예를 들어 후속 차분 검사를 수행한다면 먼저 Found가 참인지 확인하고 기준 기하의 Aligned 영상과 ValidMask의 유효 영역을 함께 전달할 수 있습니다. 마스크는 점수 자체가 아니라 보간의 유효 위치를 나타냅니다. 후속 처리가 영상 핸들을 사용하는 동안에는 해당 영상의 수명을 유지하고 사용 후 각각 해제합니다.
