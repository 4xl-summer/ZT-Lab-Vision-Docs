C#
static ZVision.MultiRegistration Run(ZVision.ZImage[] images, ZVision.RegistrationGraphEdge[] edges, System.UInt64 commonIndex = 0, System.Boolean[] fixedSources = null)

모든 쌍 연결을 추정하고 선택 영상의 격자로 정렬합니다.

인자

images: 영상 3..16개입니다.

edges: 연결된 영상 쌍입니다.

commonIndex: 공통 격자로 사용할 영상 인덱스입니다.

fixedSources: true인 소스 영상으로 향하는 연결의 초기 변환을 고정합니다.

반환: 해제해야 하는 소유 결과입니다.

사용과 결과 해석

3~16개 영상과 연결된 쌍별 간선을 받아 선택한 commonIndex의 격자에 정렬합니다. fixedSources가 true인 소스로 향하는 간선은 초기 변환을 고정합니다.

반환 결과는 소유 객체이므로 사용 후 해제합니다. Info의 행렬은 공통 로컬에서 각 영상 로컬 방향이며 유효 픽셀 수와 간선 품질을 함께 확인하십시오.
