ZVision.AdvancedMatchReport Find(ZVision.ZImage source, ZVision.AdvancedMatchingOptions options, ZVision.ZImage mask = null)

보존된 폴리라인으로 학습된 형상을 검색합니다.

인자

source: 검색 영상입니다.

options: 검색 설정이며 호출 중 변경하지 마세요.

mask: 선택 검색 마스크입니다.

반환: 독립 검색 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

Find의 사용과 결과 해석

검색 결과의 위치와 방향은 입력 영상의 좌표 기준에서 해석합니다. 찾은 위치가 없을 때 원점에 모델이 있다고 간주하지 말고 결과 상태를 먼저 확인합니다. 연결 윤곽 모델의 구조와 검색 결과를 구분합니다. 검색 입력의 영상 좌표와 모델이 정의된 좌표를 일치시키고, 결과가 없다는 상태를 원점의 정상적인 위치로 대체하지 않습니다.
