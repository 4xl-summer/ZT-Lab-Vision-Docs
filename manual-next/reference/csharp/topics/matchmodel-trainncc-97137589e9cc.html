TrainNcc

Method · 선언 타입 ZVision.MatchModel

C#
static ZVision.MatchModel TrainNcc(ZVision.ZImage template, ZVision.ZImage mask = null)

템플릿의 선택 픽셀로 NCC 모델을 학습합니다. 선택점은 2개 이상이고 분산이 0이 아니어야 합니다.

인자

template: 학습할 Gray8, Gray16 또는 GrayF32 영상입니다.

mask: 템플릿과 크기·원점이 같은 선택적 Gray8 마스크입니다. 0은 제외하고 비제로는 포함합니다.

반환: 사용 후 Dispose해야 하는 소유 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

템플릿의 선택 픽셀로 기본 NCC 모델을 학습합니다. 선택 마스크는 템플릿과 크기·원점이 같은 Gray8이며 0인 위치는 제외됩니다. 마스크로 제외한 배경은 모델의 선택 표본에 포함되지 않습니다.

NCC는 선택 표본의 밝기 변화를 비교하므로 분산이 없는 템플릿이나 검색 패치에서는 정상적인 상관 점수를 만들 수 없습니다. 선택 영역에 무늬가 충분한지 확인하고, 생성된 모델을 Find에 전달한 뒤 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
template학습할 Gray8, Gray16 또는 GrayF32 영상입니다.
mask템플릿과 크기·원점이 같은 선택적 Gray8 마스크입니다. 0은 제외하고 비제로는 포함합니다.

반환값 확인

사용 후 Dispose해야 하는 소유 모델입니다.
