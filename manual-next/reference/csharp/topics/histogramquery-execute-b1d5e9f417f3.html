Execute의 사용과 결과 해석

히스토그램 쿼리를 실행해 집계 결과를 얻습니다. 같은 빈 수라도 입력 범위와 선택한 픽셀이 다르면 각 빈의 개수는 직접 비교하기 어렵습니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.

채널별 빈과 실행 수명

HistogramQuery.Execute는 준비된 히스토그램 계획을 실행하고 QueryExecution<HistogramResult>를 반환합니다. 실행 객체는 Dispose해야 하며 Output은 실행 시 복사한 채널별 히스토그램 값 스냅샷입니다. 빈 수와 입력 범위, 처리한 영상 ROI를 함께 기록해야 각 빈의 의미를 재현할 수 있습니다.

결과의 Channels는 채널별 빈 카운트를 담습니다. 예를 들어 한 채널의 빈 카운트가 [2,1,3]이면 그 세 빈에 포함된 수의 합은 6입니다. 단, 이 예의 빈 경계는 별도 입력 범위와 빈 수에 의해 결정되므로 숫자 2만 보고 특정 원본 밝기를 단정하지 않습니다.

필요한 Output 값과 이름 있는 캡처가 있다면 실행이 열린 동안 획득합니다. GetImage가 반환하는 캡처 영상은 별도 소유 핸들이므로 실행과 각각 Dispose합니다. 이미 얻은 값 스냅샷은 실행 정리 후에도 유효하지만, 다른 범위나 ROI로 계산한 히스토그램은 설정을 확인한 뒤 비교합니다.
