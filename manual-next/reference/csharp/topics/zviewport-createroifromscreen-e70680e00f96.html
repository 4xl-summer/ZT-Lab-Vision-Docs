CreateRoiFromScreen

Method · 선언 타입 ZVision.Display.ZViewport

C#
System.Nullable<ZVision.Display.ZPixelRect> CreateRoiFromScreen(ZVision.Display.ZDisplayPoint start, ZVision.Display.ZDisplayPoint end, System.Int32 w, System.Int32 h)

화면 드래그가 겹치는 픽셀 셀의 영상 내부 사각형을 반환합니다.

인자

start: 드래그 시작 화면 좌표입니다.

end: 드래그 끝 화면 좌표입니다.

w: 영상 너비입니다.

h: 영상 높이입니다.

반환: 빈 드래그나 영상과 겹치지 않으면 null입니다.

관련 입력의 확인된 조건

start.X: 점의 가로 좌표입니다.

start.Y: 점의 세로 좌표입니다.

사용 순서와 결과 해석

화면 드래그가 겹치는 픽셀 셀들을 영상 내부로 잘라 ZPixelRect로 만듭니다. 드래그 방향은 어느 쪽이든 가능하며 시작·끝의 어느 한 축이 같거나 영상과 겹치지 않으면 null입니다. 안쪽 경계는 floor, 바깥 경계는 ceiling을 사용하므로 일부만 걸친 셀도 포함됩니다. 입력 영상의 너비와 높이는 양수여야 합니다.

입력별 확인

입력의미
start드래그 시작 화면 좌표입니다.
end드래그 끝 화면 좌표입니다.
w영상 너비입니다.
h영상 높이입니다.

반환값

빈 드래그나 영상과 겹치지 않으면 null입니다.
