Method · 선언 타입 ZVision.BlobSubpixelEdges

C#
static ZVision.BlobSubpixelEdge[] Extract(ZVision.ZImage image, System.UInt32 kernel, System.Double sigma, System.Double low, System.Double high, System.UInt64 workBudget)

비최대 억제와 hysteresis 후 기울기 최대 위치를 보간합니다.

인자

image: Gray8, Gray16 또는 유한 GrayF32 영상입니다.

kernel: 1~127의 홀수 Gaussian 창 크기입니다.

sigma: 유한한 양의 Gaussian 표준편차입니다.

low: 0 이상의 낮은 Sobel 크기 임계값입니다.

high: 낮은 값 이상의 높은 Sobel 크기 임계값입니다.

workBudget: 필터와 그래프의 총 작업 상한입니다.

반환: 독립된 ROI 로컬 에지 사슬 배열입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

Extract의 사용과 결과 해석

검출된 소수 좌표는 에지의 계산 위치입니다. ROI 원점을 적용할지 여부를 확인하고 원본 영상에 좌표를 겹쳐 실제 경계를 따라가는지 살펴봅니다. 영상 경계의 위치를 픽셀보다 세밀한 좌표로 추출합니다. 소수 좌표는 계산된 위치를 뜻하며 표시 자릿수만으로 실제 촬영 장치의 정확도를 판단할 수 없습니다.
