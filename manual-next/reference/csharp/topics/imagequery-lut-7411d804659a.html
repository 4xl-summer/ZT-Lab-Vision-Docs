ZVision.ImageQuery Lut(System.Byte[] table)

Gray8 값에 조회 테이블을 적용합니다. 실제 처리는 Run에서 수행합니다.

인자

table: Gray8 입력 값별 출력 값을 담은 조회 테이블.

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

Lut의 사용과 결과 해석

입력 값 10이 있는 픽셀은 조회 테이블의 인덱스 10에 저장한 출력 값을 사용합니다. 표의 각 원소가 출력 Gray8 값입니다. 조회 테이블의 입력 인덱스는 원래 Gray8 값이며 해당 원소가 출력 값이 됩니다. 예를 들어 입력 10은 테이블의 10번 값을 사용합니다. 밝기 계산식과 다른 임의 매핑도 표현할 수 있습니다.
