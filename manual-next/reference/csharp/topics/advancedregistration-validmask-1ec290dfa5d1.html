C#
ZVision.ZImage ValidMask()

보간 가능한 픽셀의 Gray8 마스크를 얻습니다.

반환: 사용 후 해제할 독립 영상입니다.

관련 입력의 확인된 조건

ZImage.Origin: ROI의 글로벌 픽셀 원점입니다.

ZImage.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

정합 결과에 대응하는 유효 마스크 영상을 반환합니다. 정렬된 영상을 비교할 때 마스크를 함께 확인해 입력에서 대응하지 않는 영역을 실제 관측값으로 해석하지 않도록 합니다. 반환 ZImage는 별도 소유 핸들이므로 Dispose하고 AdvancedRegistration 결과도 따로 Dispose합니다. 정합 성공 여부와 점수·coverage는 결과 Info에서 확인합니다.

정합 영상의 유효 영역

ValidMask는 정합 결과에서 보간 가능한 위치를 나타내는 Gray8 마스크의 독립 소유 ZImage를 얻습니다. 정렬된 영상의 모든 픽셀이 입력에서 실제로 표본화되었다고 가정하지 말고 같은 좌표의 유효 마스크를 함께 읽습니다. 반환 영상은 사용 후 별도로 Dispose합니다.

예를 들어 정렬 영상의 경계에서 변환된 좌표가 원본 밖으로 나가면 해당 위치의 출력 숫자만으로 실제 관측인지 채움인지 구별하기 어렵습니다. 유효 마스크는 이 구분에 사용합니다. 마스크 위치와 영상이 같은 결과의 동일 좌표를 가리키는지, ROI 원점은 무엇인지 함께 확인합니다.

AdvancedRegistration의 Info에서 정합 여부와 점수·coverage를 확인하고 필요한 영상들을 결과가 살아 있을 때 취득합니다. 결과 객체를 Dispose하는 것과 ValidMask로 얻은 영상 핸들을 Dispose하는 것은 별도입니다. 값 스냅샷과 영상 소유 핸들의 수명을 구분해 처리합니다.

판독과 확인 사례

정합 결과가 제공하는 변환의 방향과 영상 ROI 원점을 보존하면 검사 영상과 기준 영상의 어느 위치가 대응하는지 추적할 수 있습니다. 마스크를 원본 전체 좌표로 표시하려면 반환 영상의 Origin과 로컬 인덱스 관계를 먼저 확인합니다. 점수와 coverage는 Info의 별도 필드입니다.

마스크만 얻었다고 정합이 반드시 성공했다는 뜻으로 해석하지 말고 Info의 상태를 먼저 확인합니다. 반환 마스크는 별도 ZImage 소유 핸들이므로 결과를 정리한 이후에도 사용하려는 코드는 획득한 핸들의 수명을 관리하고, 사용이 끝나면 그 핸들도 Dispose합니다.
