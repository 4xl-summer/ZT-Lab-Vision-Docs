FitSpatialCalibration

C#
static ZVision.SpatialDepthCalibration FitSpatialCalibration(ZVision.DepthMap[] raw, ZVision.DepthMap[] reference, System.Double trimFraction = 0)

동일 격자의 깊이 대응표에서 위치별 2차 보정을 적합합니다.

인자

raw: 원본 깊이 격자입니다.

reference: 대응 기준 격자입니다.

trimFraction: 잔차가 큰 관측의 제외 비율입니다.

반환: 호출자가 해제할 보정 핸들입니다.

픽셀별 공간 보정 학습

여러 원시 영상과 같은 순서의 기준 영상을 짝지어 각 위치의 깊이 보정 계수를 구합니다. 영상은 크기, 단위, frame, 간격과 원점이 일치해야 하며 모델의 차수에 맞는 충분한 유효 대응이 각 픽셀에 필요합니다. 선형 모델은 두 쌍, 이차 모델은 세 쌍을 필요로 합니다.

한 위치에 서로 다른 원시 깊이 0, 1, 2와 기준 깊이 1, 3, 5가 있다면 선형식 1 + 2h가 맞습니다. 이차식을 사용한다면 세 대응 이상이 필요하며 퇴화한 값들은 계수를 결정하지 못할 수 있습니다. 잔차 제거 비율은 0 이상 1 미만이고 0은 제거하지 않음을 뜻합니다.

확인 항목해석
raw / reference같은 개수와 순서의 영상 쌍
격자 메타데이터크기·간격·원점·단위·frame 일치
model선형 또는 이차 계수 선택
trim_fraction제거할 잔차 비율 [0,1)
