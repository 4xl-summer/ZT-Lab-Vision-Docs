void Dispose()

소유한 네이티브 결과 핸들을 해제합니다.

수명과 사용 순서

표면 결함 결과의 네이티브 핸들을 해제합니다. 개별 결함과 판정을 확인한 후 결과 객체를 정리하십시오.

이 호출에는 반환값이 없습니다. C#에서 소유 객체의 사용 범위를 정하고 필요한 작업이 끝나면 해제하여 네이티브 자원을 정리하십시오. 해제된 객체는 이후 작업에 사용하지 않습니다.

결함 후보와 판정 결과 정리

SurfaceDefectResult는 표면 결함 분석의 네이티브 결과 핸들을 소유합니다. Defects는 행 우선 연결 요소 순서로 복사한 결함 후보 배열을 제공합니다. Judge는 결함 수와 면적, 허용 영역 조건을 적용해 독립 소유 InspectionDecisionResult를 만듭니다. 한도와 같은 값은 허용됩니다.

예를 들어 최대 결함 수가 2인 규칙에서 후보가 정확히 2개인 경우 수 한도와 같다는 이유만으로 초과가 되지는 않습니다. 다른 면적이나 허용 영역 규칙도 함께 확인해야 전체 합격 여부를 알 수 있습니다. Defects 배열의 후보와 Judge 결과의 Passed, Reasons 및 Rejections를 연결해 어느 조건이 적용되었는지 살펴보세요.

수명과 결과 확인

SurfaceDefectResult.Dispose는 그 결과 핸들을 해제합니다. Judge가 반환한 독립 판정 결과는 별도 소유 객체이므로 사용 후 따로 Dispose해야 합니다. 결함 후보 배열은 복사된 값이지만 해제한 SurfaceDefectResult에서 Defects나 Judge를 다시 요청해서는 안 됩니다. 입력 영상과 차영상·유효 마스크의 수명도 각각 관리합니다.
