Fit

Method · 선언 타입 ZVision.AdvancedMetrology

C#
static ZVision.AdvancedFitResult Fit(ZVision.Point2[] points, ZVision.AdvancedFitOptions options, System.Nullable<System.Double> normalQuantile = null, System.Nullable<System.UInt64> sampleSize = null)

선 또는 원을 피팅하고 입력별 진단을 반환합니다.

인자

points: 입력 좌표입니다.

options: 알고리즘과 수렴 설정입니다.

normalQuantile: 신뢰구간에 적용할 정규 분위수이며 null이면 계산하지 않습니다.

sampleSize: 합의 후보의 표본 수이며 null이면 최소 표본을 사용합니다.

반환: 피팅 결과와 잔차, 인라이어 마스크입니다.

관련 입력의 확인된 조건

options.Kind: 선은 1, 원은 2입니다.

options.Method: 최소제곱은 0, 합의 표본은 1입니다.

options.Threshold: 좌표 단위 인라이어 거리입니다.

options.MinInliers: 최소 인라이어 개수입니다.

options.MaxCandidates: 최대 후보 개수입니다.

options.MaxRefitIterations: 최대 재피팅 반복 횟수입니다.

options.MinArcRadians: 원 피팅에 필요한 최소 원호 각도이며 라디안 단위입니다.

AdvancedFitResult.Kind: 선 1 또는 원 2입니다.

AdvancedFitResult.Parameters: 선은 점과 방향, 원은 중심과 반지름입니다.

AdvancedFitResult.Residuals: 입력 순서의 절대 잔차입니다.

AdvancedFitResult.Inliers: 입력 순서의 인라이어 여부입니다.

AdvancedFitResult.Rms: 인라이어 RMS 잔차입니다.

AdvancedFitResult.Maximum: 인라이어 최대 잔차입니다.

계산과 결과 해석

Fit은 점 배열과 옵션을 받아 선 또는 원을 적합하고 입력별 잔차와 채택 마스크를 반환합니다. options는 형상, 알고리즘과 수렴 관련 설정을 정하며 점 좌표가 픽셀이면 잔차 거리도 해당 픽셀 기준으로 해석합니다. 예를 들어 (0,2), (1,2), (2,2)는 y=2인 선 위에 있으므로 해당 선까지의 거리가 모두 0인 기하 예제입니다. 한 점을 멀리 옮긴 경우 채택 여부는 선택한 방법과 설정에 따라 확인해야 합니다. normalQuantile이 null이면 신뢰구간을 계산하지 않고 sampleSize가 null이면 합의 후보의 최소 표본을 사용합니다. 점 수가 충분하더라도 모두 같은 위치처럼 퇴화한 배치에서는 유효한 형상을 정할 수 없습니다. 피팅 결과만 표시하지 말고 각 점의 잔차와 마스크를 영상 위 관측점과 함께 비교하면 다른 경계를 잘못 선택했는지 진단할 수 있습니다. 수렴이나 작은 잔차는 선택한 입력점에 대한 결과이지 장비의 절대 정확도 보증이 아닙니다. 결과를 다른 ROI나 세계 좌표의 점과 비교할 때 공통 좌표계와 단위를 먼저 맞추십시오. 결과의 점별 마스크는 원래 points의 순서에 대응합니다. 입력 배열 순서를 변경했다면 이전 실행의 마스크를 그대로 연결하지 마십시오.
