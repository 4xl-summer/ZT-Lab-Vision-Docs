void Reconnect()

기존 연결을 닫고 동일한 주소에 다시 연결합니다.

사용과 결과 해석

기존 연결을 닫고 원래 주소에 다시 연결합니다. 연결 설정과 타임아웃을 사용하는 명시적 동작이며, 실패한 쓰기 명령을 자동 재실행하지 않습니다.

다시 연결한 뒤 장치 상태를 확인하고 필요한 읽기나 쓰기를 호출자가 결정하십시오. 통신 재개와 이전 명령의 성공 여부는 별도로 판단해야 합니다.

재연결과 명령 결과

Reconnect는 현재 연결을 닫고 Connect 때 지정한 동일한 주소로 다시 연결합니다. 객체의 핸들이 이미 해제되었다면 호출할 수 없으며, 네이티브 재연결이 실패하면 ModbusTcpException으로 상태와 진단이 전달됩니다. 반환값은 없으므로 예외 없이 완료되었는지로 호출 결과를 확인합니다.

연결 복구는 앞서 실패한 쓰기가 장치에 적용되었는지 알려 주지 않습니다. WriteSingleRegister는 실패 시 자동 재전송하지 않으므로 장치 상태와 명령의 의미를 확인한 뒤 호출자가 재시도 여부를 정해야 합니다. 재연결 뒤 필요한 보유 레지스터를 읽어 현재 상태를 확인하는 흐름을 구성할 수 있습니다.
