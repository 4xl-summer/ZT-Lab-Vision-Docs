C#
System.Byte[] Encode(System.UInt64 maxBytes)

체크섬을 포함한 little-endian 모델을 만듭니다.

인자

maxBytes: 출력 바이트 상한입니다.

반환: 독립 바이트 배열입니다.

사용과 결과 해석

현재 누적 상태를 버전과 체크섬이 포함된 바이트로 직렬화합니다. 출력 크기는 68 + 17 × 픽셀 수 바이트이며 지정한 max_bytes를 넘으면 오류입니다. 픽셀 수는 선택 마스크의 포함 개수가 아니라 전체 영상 크기입니다.

예: 2×2 영상의 상태는 68 + 17×4 = 136바이트입니다. 이후 decode에는 같은 형식, 크기와 ROI 원점의 템플릿이 필요하므로 저장한 상태와 함께 해당 기하 정보를 관리하십시오.

직렬화 내용과 복원

예를 들어 10×10 영상이면 68+17×100=1768바이트입니다. 선택 영역이 일부여도 크기는 전체 픽셀 수를 기준으로 계산하므로 저장 용량을 산정할 때 마스크의 비영 개수로 계산하지 마십시오.

항목확인할 내용
크기68 + 17 × 전체 픽셀 수 바이트입니다.
포함 여부각 픽셀의 마스크 포함 상태를 저장합니다.
누적 통계픽셀별 평균과 M2, 표본 수를 저장합니다.
형식버전과 체크섬을 포함합니다.
제한maxBytes보다 크면 오류입니다.
복원같은 형식·크기·원점의 템플릿이 필요합니다.
