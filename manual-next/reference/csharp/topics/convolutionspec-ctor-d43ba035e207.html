C#
ConvolutionSpec(System.UInt64 width, System.UInt64 height, System.UInt64 anchorX, System.UInt64 anchorY, System.Double[] kernel, System.Double divisor = 1, System.Double offset = 0, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, ZVision.PixelFormat output = ZVision.PixelFormat.GrayF64, System.Boolean correlate = true, System.Double constant = 0)

커널을 복사해 설정을 만듭니다. 유효 범위는 계산 시 검사합니다.

인자

width: 커널 너비입니다.

height: 커널 높이입니다.

anchorX: 커널 내부 x 앵커입니다.

anchorY: 커널 내부 y 앵커입니다.

kernel: 행 우선 커널 값입니다.

divisor: 0이 아닌 유한 제수입니다.

offset: 유한 출력 편향입니다.

border: 경계 방식입니다.

output: GrayF64 출력 형식이어야 합니다.

correlate: 참이면 상관, 거짓이면 합성곱입니다.

constant: 상수 경계의 밝기입니다.

관련 입력의 확인된 조건

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.

이 호출의 입력과 객체 맥락

ConvolutionSpec.Offset: 제수 적용 후 더할 값입니다.

ConvolutionSpec.Border: 입력 ROI 경계 방식입니다.

output.Gray8: 8비트 부호 없는 회색 형식입니다.

output.Gray16: 16비트 부호 없는 회색 형식입니다.

output.GrayF32: 32비트 부동소수 회색 형식입니다.

output.Rgba8: 8비트 RGBA 형식입니다.

output.Bgra8: 8비트 BGRA 형식입니다.
