TypedShapeComponent(System.UInt64 id, ZVision.ExtendedShapeModel model, ZVision.Point2 relativePosition, System.Double relativeAngle, System.Double positionTolerance, System.Double angleTolerance)

형상 구성 요소를 만듭니다.

인자

id: 고유 식별자입니다.

model: 형상 모델입니다.

relativePosition: 상대 위치입니다.

relativeAngle: 상대 각도입니다.

positionTolerance: 위치 허용치입니다.

angleTolerance: 각도 허용치입니다.

관련 입력의 확인된 조건

relativePosition.X: 영역의 로컬 x 좌표입니다.

relativePosition.Y: 영역의 로컬 y 좌표입니다.

값을 구성하고 해석하기

확장 형상 모델을 루트 기준 상대 위치와 상대 각도 및 허용치와 함께 구성 요소로 지정합니다. 위치 허용치와 각도 허용치는 서로 다른 단위의 제약입니다. 구성 요소를 식별하는 Id를 입력 내에서 고유하게 유지하면 반환 결과를 해당 모델과 연결하기 쉽습니다.
