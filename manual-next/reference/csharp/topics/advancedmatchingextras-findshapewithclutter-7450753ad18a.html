static ZVision.AdvancedMatchReport FindShapeWithClutter(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, System.Double maxClutter, System.Double weight, System.UInt64 radius)

대상 에지 clutter 제한과 점수 벌점을 적용해 형상 모델을 검색합니다.

인자

source: 검색 영상입니다.

model: 형상 모델입니다.

options: 검색 옵션입니다.

maxClutter: 허용하는 최대 clutter 비율입니다.

weight: clutter 점수 벌점 계수입니다.

radius: 에지 대응 반경입니다.

반환: 후보와 종료 진단입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

형상 후보 주변 에지를 진단해 clutter를 감점합니다. maxClutter와 weight는 0부터 1까지의 비율이며 radius는 픽셀 단위 주변 반경입니다. AdvancedMatchingOptions의 격자와 후보 예산은 이 감점 설정과 별도로 정합니다.

후보 포즈와 종료 진단을 함께 확인합니다. 같은 검색 영상과 격자를 유지하고 감점 조건을 바꾸어 비교하면 주변 에지의 영향과 검색 범위의 영향을 구분하는 데 도움이 됩니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
source검색 영상입니다.
model형상 모델입니다.
options검색 옵션입니다.
maxClutter허용하는 최대 clutter 비율입니다.
weightclutter 점수 벌점 계수입니다.
radius에지 대응 반경입니다.
