System.Double[] View(ZVision.SpectrumView view = ZVision.SpectrumView.Amplitude)

지정한 값을 복사합니다.

인자

view: 값 종류입니다.

반환: 독립 배열입니다.

관련 입력의 확인된 조건

view.LogAmplitude: log(1+진폭)입니다.

데이터와 계산

지정한 SpectrumView에 해당하는 주파수 표현을 계산합니다.

진폭, 위상 등 선택한 표현은 복소 계수의 서로 다른 요약이며 서로 같은 양으로 취급할 수 없습니다. 입력 mode를 보존해 결과 배열의 의미를 식별하십시오.

항목이 호출의 의미
인자표현 종류 mode
모델Spectrum
배열 배치행 우선
수명독립 결과와 소유자는 각각 관리

결과 확인

결과는 행 우선 값 배열입니다. 크기를 변환 격자로 해석하고 표시용 좌표 이동과 실제 필터의 계수 인덱스가 같은지 확인해야 합니다.

Spectrum의 View 결과를 다른 영상 또는 주파수 처리에 연결할 때는 크기, 원점 및 정규화를 함께 확인하십시오.
