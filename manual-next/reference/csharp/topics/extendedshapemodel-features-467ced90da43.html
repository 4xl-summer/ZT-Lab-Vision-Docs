반환: 특징 배열입니다.

호출과 결과 해석

학습된 형상 특징의 기준점 상대 로컬 좌표와 방향을 ShapeModelFeature 배열로 복사합니다. 원래 contour 연결이나 검색 영상의 전역 좌표를 반환하는 호출은 아닙니다. 학습 임계값이나 표본 간격을 바꾼 모델을 비교할 때 특징 분포를 확인하고, 실제 매치 포즈는 별도 Find 결과로 확인합니다.

반환값

특징 배열입니다.

특징 좌표와 방향

반환 배열의 각 ShapeModelFeature는 학습 기준점 상대 로컬 위치 (x,y)와 방향 성분 (nx,ny)을 나타냅니다. 예를 들어 기준점이 템플릿 로컬 (10,20)이고 특징의 상대 위치가 (2,−3)이면 학습 템플릿 좌표의 위치는 (12,17)입니다.

이는 모델이 보유한 방향 표본이지 원본 contour의 연결 순서나 검색된 물체 목록이 아닙니다. 임계값이나 표본 간격이 다르게 학습된 모델의 특징 수와 분포를 비교할 수 있으며, 검색 영상상의 포즈는 Find 결과의 변환을 함께 사용해야 해석할 수 있습니다.

결과를 점검하는 방법

모델의 특징을 검토할 때는 특징의 위치와 방향을 함께 봅니다. 기울기 임계값을 올리거나 표본 간격을 넓히면 학습에 남는 특징 분포가 달라질 수 있습니다. 같은 템플릿과 기준점에서 학습 조건만 바꾸어 반환 배열을 비교하면 검색 이전에 모델이 어떤 경계를 표현하는지 확인하는 데 도움이 됩니다.
