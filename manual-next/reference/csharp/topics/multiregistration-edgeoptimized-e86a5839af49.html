EdgeOptimized

Method · 선언 타입 ZVision.MultiRegistration

C#
System.Boolean EdgeOptimized(System.UInt64 index)

연결이 최적화되었는지 조회합니다.

인자

index: 연결 인덱스입니다.

반환: 초기 변환 고정이면 false입니다.

사용과 결과 해석

입력 연결 인덱스의 최적화 여부를 반환합니다. 초기 변환이 고정된 연결은 false이며 연결 순서는 입력 간선 배열 순서입니다.

EdgeQuality는 실제 측정 품질이 있는지 별도로 제공합니다. false를 무조건 정합 실패로 해석하지 말고 고정 설정과 함께 확인하십시오.

간선 상태 읽기

index는 입력 영상 번호가 아니라 정합 그래프를 만들 때 전달한 간선 배열의 인덱스입니다. EdgeOptimized는 해당 간선이 최적화되었는지 불리언을 반환합니다. 초기 변환이 고정된 연결은 false이므로 이 값 하나만으로 정합 실패 여부를 판정할 수 없습니다.

같은 간선 인덱스로 EdgeQuality를 조회하면 실제 측정 품질을 확인할 수 있습니다. 초기 변환만 고정된 간선은 품질이 null일 수 있는데 이는 품질 점수가 0이라는 뜻이 아닙니다. 입력 간선의 reference/source 방향과 고정 설정을 보존하고, 영상별 변환은 Info에서 별도로 확인하십시오.
