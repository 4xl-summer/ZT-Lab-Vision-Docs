모델을 해제합니다.

이 호출의 입력과 객체 맥락

GapHaarWavelet.Coefficients: 행 우선 계수의 독립 복사본을 반환합니다.

GapHaarWavelet.WithCoefficients: 외부 계수의 스냅샷을 사용해 독립 모델을 만듭니다.

GapHaarWavelet.Shrunk: 최종 LL을 보존하며 세부 계수를 축소한 모델을 만듭니다.

GapHaarWavelet.Inverse: 입력 ROI 원점을 유지하는 GrayF64 영상을 복원합니다.

변환 모델과 복사된 계수

GapHaarWavelet.Forward는 입력 ROI의 직교 Haar 변환을 독립 모델로 만듭니다. 각 분해 수준에서 양축이 짝수여야 하며 levels는 1..64입니다. 이 형식은 0.1.x 호환 API이므로 새 소비 경로에서는 문서에 안내된 정식 주파수 API를 확인합니다.

Coefficients는 모델의 행 우선 계수를 새 double 배열로 복사합니다. 폭 4, 높이 2인 입력이라면 계수 배열에는 8개 위치가 있습니다. 그 배열을 변경해도 이미 생성된 모델의 내부 계수가 바뀌지 않으며, 변경된 값을 사용하려면 WithCoefficients로 별도 모델을 만들어야 합니다.

Shrunk도 최종 LL 대역을 보존하는 별도 모델을 반환하고 Inverse는 독립 GrayF64 영상을 반환합니다. 원래 모델을 Dispose하기 전에 필요한 조회와 복원을 수행하고, 생성한 다른 모델과 영상은 각자의 소유권에 따라 정리합니다. 복사한 관리 배열은 모델의 네이티브 핸들과 별개입니다.

계수 배열의 행 우선 순서와 모델의 폭·높이를 함께 보관해야 특정 대역의 계수를 다시 연결할 수 있습니다. Shrunk의 임계값은 유한한 비음수이고 hard 또는 soft 방식을 선택합니다. 반환된 새 모델은 원래 모델과 별도이므로 각각의 역변환 결과를 같은 ROI에서 비교할 수 있습니다.

비교할 때 확인

WithCoefficients는 새 배열의 길이가 원래 계수 수와 같고 모든 값이 유한한지 확인합니다. 이 조건을 만족하지 않으면 새 모델을 얻기 전에 오류가 발생합니다. 원본 계수와 수정된 계수를 비교할 때는 어느 독립 모델에 속하는지 함께 표시합니다.
