Method · 선언 타입 ZVision.PhotometricInspection

C#
static ZVision.PhotometricResult Run(ZVision.ZImage[] images, ZVision.PhotometricOptions options, ZVision.ZImage mask = null)

같은 장면 네 장과 조명 벡터로 검사 영상을 만듭니다.

인자

images: 동일 형식·기하의 네 영상입니다.

options: 조명·출력 설정입니다.

mask: 선택적 Gray8 마스크입니다.

반환: 호출자가 해제할 결과입니다.

관련 입력의 확인된 조건

options.Lights: 조명 xyz 계수의 독립 복사본입니다.

options.MinSignal: 법선 계산에 필요한 최소 신호입니다.

options.MinRcond: 조명 정규 방정식의 최소 역조건수입니다.

options.SpacingX: 세계 x 방향 픽셀 간격입니다.

options.SpacingY: 세계 y 방향 픽셀 간격입니다.

options.MinNormalZ: 곡률 유효 법선 z의 절댓값 하한입니다.

options.SmoothRadius: 형상 계산에 사용할 법선 평활 반경 픽셀입니다.

options.Brightness: 평탄부 출력 밝기 비율입니다.

options.Contrast: 부호 있는 형상 응답의 출력 대비입니다.

사용과 결과 해석

동일 형식·기하의 네 영상과 대응 조명 벡터로 포토메트릭 검사 결과를 만듭니다. 선택적 Gray8 마스크는 유효 영역을 제한합니다.

조명 벡터 순서가 영상 순서에 대응해야 합니다. 결과의 유효 영역과 법선·형상 출력을 함께 확인하고 결과는 사용 후 해제하십시오.
