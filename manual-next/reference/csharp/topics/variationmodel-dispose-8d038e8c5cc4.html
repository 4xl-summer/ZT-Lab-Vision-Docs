소유한 모델 핸들을 해제합니다.

모델 핸들 해제

VariationModel.Dispose 호출은 해당 모델이 소유한 핸들을 해제합니다. 사용이 끝난 모델에 대한 호출은 해제된 객체 오류 경로를 따르며 이미 별도로 얻은 영상도 각자의 소유 규칙에 따라 해제해야 합니다.

동일 객체의 호출과 종료를 애플리케이션의 실행 흐름에서 조정합니다. Dispose는 모델 결과를 저장하거나 검사 결과를 자동으로 확정하지 않습니다.

래퍼 모델 종료

Dispose는 VariationModel이 소유한 내부 모델을 닫습니다. 사용이 끝난 모델을 더 이상 검사에 사용하지 않도록 요청의 완료와 종료 순서를 애플리케이션에서 조정합니다. 모델을 닫는 일은 실행 결과의 통과 여부를 변경하거나 기록을 저장하지 않습니다.

ModelImages에서 획득한 Reference와 Deviation은 각각 독립 소유 영상입니다. 모델 Dispose와 두 영상의 Dispose를 따로 수행합니다. 검사 결과 역시 별도 소유 객체이며 그 결과에서 획득한 영상도 각자 해제합니다.

모델을 저장해야 한다면 해제 전에 Encode를 호출하고 반환된 byte 배열을 보관합니다. 그 배열은 모델 핸들과 수명이 다른 관리 값입니다. 복원 시에는 형식, 크기 및 원점을 제공하는 template과 한도를 별도로 지정합니다.
