Method · 선언 타입 ZVision.ConvexShapeQuery

C#
ZVision.QueryExecution<ZVision.ConvexShapeResult> Execute()

계획을 실행하고 볼록 형상 결과를 독립 스냅샷으로 복사합니다.

반환: Dispose해야 하는 실행입니다. Output으로 얻은 스냅샷은 실행 해제 후에도 유효합니다.

호출과 결과 확인

볼록 성분 분석 계획을 실행해 QueryExecution에 ConvexShapeResult 독립 스냅샷을 만듭니다. 각 구성요소의 ROI 로컬 껍질과 최소 회전 사각형을 읽고 원본 좌표가 필요하면 영상 원점을 반영합니다. 빈 성분 결과와 실행 오류는 구분해야 합니다.

연결 방식과 성분 결과

이 호출은 미리 지정한 영상 계획과 연결 방식으로 실제 분석을 수행합니다. 대각선으로만 만나는 두 전경 픽셀은 4연결에서는 두 성분이고 8연결에서는 한 성분입니다. 따라서 같은 영상이라도 계획에 넣은 connectivity가 결과 형상 수를 바꿀 수 있습니다.

반환 QueryExecution의 Output에는 성분별 볼록 껍질과 최소 면적 회전 사각형이 있습니다. 껍질은 ROI 로컬 픽셀 셀의 외곽이며 원본 영상에 표시할 때 ROI 원점을 반영합니다. 실행을 Dispose한 뒤에도 이미 얻은 값 스냅샷은 유효합니다.

결과를 점검하는 방법

성분마다 반환되는 사각형은 볼록 껍질을 감싸는 최소 면적 회전 사각형입니다. 성분이 여러 개면 결과를 하나의 전역 사각형으로 합쳐 해석하지 말고 각 항목의 성분 인덱스와 함께 읽습니다. 영상 일부만 ROI로 분석했다면 로컬 점에 ROI 원점을 반영하여 원본 좌표로 표시합니다.
