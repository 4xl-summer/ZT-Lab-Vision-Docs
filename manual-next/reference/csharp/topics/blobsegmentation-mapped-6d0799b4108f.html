C#
static ZVision.BlobSegmentationResult Mapped(ZVision.ZImage image, System.Byte[] lut, System.UInt32 scaling, System.UInt64 workBudget)

256개 LUT와 scaling으로 Gray8 값을 membership으로 변환합니다.

인자

image: Gray8 영상입니다.

lut: 0~scaling의 256개 값입니다.

scaling: 완전 membership에 해당하는 1~255 값입니다.

workBudget: 픽셀 처리 상한입니다.

반환: 호출자가 해제할 분할 결과입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BlobSegmentationResult.Info: 계산된 임계값 정보입니다.

BlobSegmentationResult.Mask: 비영 membership의 이진 마스크입니다.

BlobSegmentationResult.Weights: 픽셀 membership 영상입니다.

Mapped의 사용과 결과 해석

매핑을 사용하는 분할에서는 원본 강도와 매핑 결과의 가중치를 구별합니다. 표의 같은 인덱스가 어느 입력 밝기에 대응하는지 확인한 뒤 반환 마스크와 가중치를 읽습니다. 입력 강도와 선택한 임계 조건으로 전경을 결정합니다. 강도 영상, 임계 기준과 결과 마스크는 서로 다른 데이터이므로 임계값의 범위와 밝은 쪽을 전경으로 볼지 함께 기록합니다.
