ZVision.Affine2 Then(ZVision.Affine2 next)

현재 변환을 먼저, 다음 변환을 나중에 적용하도록 합성합니다.

인자

next: 현재 변환 다음에 적용할 변환입니다.

반환: 계산된 결과입니다.

이 호출의 입력과 객체 맥락

현재 변환을 먼저 적용하고 인자 next를 그 결과에 적용한 합성 값을 만듭니다. 두 연산의 순서를 바꾸면 일반적으로 결과가 달라집니다. 예를 들어 점 (10, 20)에 먼저 (3, 4) 이동을 적용한 뒤 x·y를 각각 2배 하면 (26, 48)입니다. 반대로 먼저 두 배로 만든 후 이동하면 (23, 44)입니다. 따라서 호출 순서가 데이터 흐름과 일치하는지 확인해야 합니다. 인자는 같은 종류의 Affine2여야 하며 잘못된 값이나 유효하지 않은 계산은 오류가 될 수 있습니다.

이 객체의 확인된 공개 생성 경로: Affine2(System.Double a, System.Double b, System.Double tx, System.Double c, System.Double d, System.Double ty).

사용 순서와 판독

현재 변환의 출력 좌표가 next의 입력 좌표가 됩니다. 따라서 서로 다른 ROI, 카메라, 세계 좌표계를 연결하려면 각 변환이 어느 기준에서 어느 기준으로 가는지 먼저 맞춰야 합니다. 이름이 같은 좌표 숫자만으로 기준이 같다고 판단하지 마세요.

예를 들어 (1,1)을 먼저 (2,0)만큼 옮기고 2배 하면 (6,2)입니다. 순서를 바꾸면 (4,2)이므로 합성 결과도 달라집니다. 합성값은 새 Affine2이고 영상 재표본화는 별도의 작업입니다.
