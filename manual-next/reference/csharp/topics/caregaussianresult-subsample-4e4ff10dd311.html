ZVision.CareGaussianResult Subsample(System.UInt64 stepX, System.UInt64 stepY)

결과와 계산 마스크를 동일한 간격으로 축소 표본화합니다.

인자

stepX: 양의 x 간격입니다.

stepY: 양의 y 간격입니다.

반환: 호출자가 Dispose할 독립 결과입니다.

이 호출의 입력과 객체 맥락

필터 영상과 계산 여부 마스크를 같은 간격으로 축소 표본화해 독립 결과를 만듭니다. 가로·세로 간격은 양의 정수이며 ROI 로컬 (0,0)에서 시작합니다. 예를 들어 x 간격 2는 가로로 한 표본씩 건너뛰며 출력 크기는 내림 기준입니다. 영상과 마스크를 같은 격자로 해석하고 새 결과와 각 영상 핸들의 수명을 따로 관리하세요. 사용 후 각 결과를 Dispose합니다.

입력과 결과 확인

Subsample은 완료된 Gaussian 필터 영상과 계산 여부 마스크를 같은 격자로 축소 표본화한 독립 결과를 만듭니다. stepX와 stepY는 양의 정수이며 입력의 ROI 로컬 (0,0)에서 시작해 각 출력 위치 (x,y)에 입력 (x×stepX,y×stepY)을 대응시킵니다.

출력 폭과 높이는 각각 입력 폭과 높이를 간격으로 나눈 내림값이고 결과 원점은 (0,0)입니다. 예를 들어 폭 5와 stepX 2이면 출력 폭은 2이고 x=0과 2를 선택하며 남은 끝부분은 버립니다. 결과 영상과 마스크를 서로 다른 간격으로 읽으면 계산 여부가 다른 픽셀에 연결됩니다.

원본과 새 결과는 독립 소유 객체이며 획득한 영상 핸들도 별도로 Dispose합니다. step이 0인 경우는 유효한 축소가 아니며, 계산 마스크를 값이 0인 일반 영상과 혼동하지 마십시오. 이후 좌표를 원본에 대응할 때 간격과 결과 원점을 함께 기록해야 합니다.

항목확인할 내용
stepX양의 가로 표본 간격입니다.
stepY양의 세로 표본 간격입니다.
대응출력 (x,y)는 입력 (x×stepX,y×stepY)입니다.
크기각 축 크기를 간격으로 나누어 내림합니다.
원점출력의 원점은 (0,0)입니다.
수명원본·새 결과·획득 영상을 각각 해제합니다.

예시의 폭 5, 간격 2에서는 위치 4를 선택하면 세 번째 점이 될 것처럼 보일 수 있지만 구현은 출력 폭을 floor(5/2)=2로 정하기 때문에 그 남은 위치를 출력하지 않습니다. 세로축도 동일하게 계산합니다. 예를 들어 높이 4와 stepY 2라면 출력 높이는 2이고 y=0과 2가 대응합니다. 이렇게 만든 2×2 결과의 각 값에는 같은 위치에서 표본화한 계산 마스크 값이 연결됩니다.

예시에서 출력 (1,1)은 입력 로컬 (2,2)에 대응하며 영상과 계산 마스크가 모두 같은 좌표를 사용합니다. 출력 원점이 (0,0)이라는 사실을 원본의 글로벌 원점과 혼동하지 마십시오.
