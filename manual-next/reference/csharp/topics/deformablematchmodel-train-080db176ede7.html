static ZVision.DeformableMatchModel Train(ZVision.ZImage template, ZVision.Point2 reference, ZVision.TemplateDeformation[] deformations, System.UInt64 sampleStep = 1, ZVision.ZImage mask = null)

각 변위 격자로 템플릿을 변형해 독립 NCC 모델을 학습합니다.

인자

template: 학습 영상입니다.

reference: 템플릿 로컬 기준점입니다.

deformations: 학습할 변위 격자들입니다.

sampleStep: 표본 간격입니다.

mask: 선택적 학습 마스크입니다.

반환: 사용 후 해제할 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

명시한 각 변위 격자로 NCC 변형 모델 은행을 학습합니다. deformations는 1개에서 64개이며 각 격자는 2×2 이상이고 각 격자의 점 수는 1024개 이하여야 합니다. 임의의 연속 변형 전체를 자동 학습하는 기능은 아닙니다.

reference는 유한한 템플릿 로컬 기준점이고 sampleStep은 양의 픽셀 간격입니다. 선택 Gray8 마스크는 템플릿과 같은 크기·원점을 사용합니다. 각 변형의 인덱스를 보관해 검색 결과와 연결하고 모델은 사용 후 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
template학습 영상입니다.
reference템플릿 로컬 기준점입니다.
deformations학습할 변위 격자들입니다.
sampleStep표본 간격입니다.
mask선택적 학습 마스크입니다.
