사용과 결과 해석

스켈레톤 반복의 기본 설정을 만듭니다. 전경 연결성은 8이고 최대 반복 1000, 작업 예산 100000000입니다. 현재 전경 연결성은 8만 지원합니다.

반복 상한과 작업 예산은 계산 제한입니다. 복잡한 영역에서 처리가 완료되었는지 결과를 확인하고 입력 및 작업 예산을 함께 검토하십시오.

스켈레톤 반복 설정

SkeletonOptions는 전경 영역을 반복적으로 가늘게 만드는 Skeletonize의 설정 값입니다. 기본 Connectivity는 Eight, MaxIterations는 1000, WorkBudget은 100000000입니다. 이 구현에서 전경 연결성은 현재 8만 지원하므로 다른 연결 값을 사용 가능한 대안으로 가정하지 않습니다.

MaxIterations는 두 단계로 이루어진 반복의 상한이고 WorkBudget은 픽셀 이웃을 검사하는 작업 상한입니다. 두 제한은 출력의 목표 굵기나 물리 길이가 아닙니다. 동일한 입력이라도 영역의 크기와 형태에 따라 필요한 작업량이 달라지므로 처리 완료 여부를 결과에서 확인합니다.

Skeletonize가 반환하는 TopologyIterationResult에는 Image, Iterations, Removed, Converged가 있습니다. 결과 영상만 보고 수렴했다고 단정하지 말고 Converged와 실제 반복 수를 함께 기록합니다. 이후 가지의 길이를 측정할 때는 별도 그래프 설정의 픽셀 간격과 단위를 사용합니다.

스켈레톤 영상을 만든 뒤 그래프를 구성하는 작업은 별도 단계입니다. 반복이 수렴했는지 먼저 확인하고, 그래프에서 길이를 읽을 때는 그래프 설정의 X·Y 간격을 따로 지정합니다. 스켈레톤 반복의 WorkBudget 숫자를 길이 임계값이나 가지 제거 길이로 사용하지 않습니다.

항목의미와 확인
Connectivity기본 Eight; 현재 8연결만 지원
MaxIterations기본 1000; 두 단계 반복 상한
WorkBudget기본 100000000; 이웃 검사 상한
Image스켈레톤 결과 영상
Iterations / Removed실제 반복 수와 제거 수
Converged반복 수렴 여부

비교할 때 확인

Removed는 반복 처리에서 제거된 픽셀 수이며 생성된 가지 수가 아닙니다. Iterations 역시 그래프의 노드나 에지 개수를 뜻하지 않습니다. 스켈레톤 영상과 반복 진단을 먼저 확인한 다음 별도의 그래프 결과에서 노드와 연결 관계를 읽습니다.
