static ZVision.MatchModel Load(System.String path)

버전 1 모델 파일을 읽어 소유 모델을 만듭니다.

인자

path: 비어 있지 않고 NUL이 없는 모델 파일 경로입니다.

반환: 사용 후 Dispose해야 하는 소유 모델입니다.

관련 입력의 확인된 조건

불변 템플릿 모델을 소유합니다. 학습 픽셀은 독립 복사되며 사용 후 Dispose해야 합니다.

호출 맥락과 결과 해석

Save가 작성한 버전 있는 매칭 모델 파일을 읽어 독립된 모델을 복원합니다. path는 비어 있지 않은 경로여야 합니다. 템플릿 이미지 파일이 아니라 학습된 모델 형식을 입력으로 사용합니다.

복원한 모델은 호출자가 Dispose로 해제해야 합니다. 같은 영상과 MatchSpec을 사용해 저장 전후의 검색 결과를 비교하고, 로드에 실패하면 경로와 파일 완전성 및 모델 형식을 살핍니다. 검색 옵션과 검색 영상은 이 호출에서 별도로 주어지지 않습니다.

입력 선택을 위한 확인

입력의미와 조건
path비어 있지 않고 NUL이 없는 모델 파일 경로입니다.
