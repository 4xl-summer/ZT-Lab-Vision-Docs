ZOverlayScene(System.Collections.Generic.IEnumerable<ZVision.Display.ZOverlayPrimitive> primitives)

도형을 복사해 장면을 만듭니다.

인자

primitives: 최대 262144개의 도형입니다.

사용 순서와 결과 해석

전달받은 도형 열거를 복사해 읽기 전용 장면을 만듭니다. null 열거와 null 도형을 허용하지 않으며 도형은 최대 262144개입니다. 원래 목록에 나중에 항목을 추가해도 이미 생성된 장면의 목록은 바뀌지 않습니다. 완성된 장면은 SaveSvg로 픽셀 중심 좌표계를 유지해 기록할 수 있습니다.

입력별 확인

입력의미
primitives최대 262144개의 도형입니다.

도형 목록 복사와 SVG 좌표

ZOverlayScene 생성자는 primitives 열거를 복사해 읽기 전용 목록을 만듭니다. null 열거와 null 항목은 허용하지 않고 최대 262144개의 도형을 받습니다. 입력 리스트에 생성 후 도형을 더해도 이미 만든 장면의 Primitives 목록은 바뀌지 않습니다.

각 ZOverlayPrimitive는 선, 셀 사각형, 원, 다각형 또는 문자열 도형입니다. 점 기반 도형은 영상 로컬 픽셀 중심 좌표를 사용하고 ZPixelRect는 셀 경계를 나타냅니다. 예를 들어 로컬 중심 (0,0)의 선 끝점은 SVG에서 (0.5,0.5)로 기록되지만 셀 사각형의 왼쪽 경계 0에는 0.5를 더하지 않습니다.

SaveSvg는 양의 width와 height로 viewBox를 정하고 색 0xRRGGBBAA의 색·투명도를 기록합니다. 이것은 영상 픽셀을 바꾸거나 영상을 저장하는 작업이 아니라 표시 도형을 SVG로 내보내는 작업입니다. 장면이 어느 영상 ROI를 기준으로 만들어졌는지 함께 보관합니다.
