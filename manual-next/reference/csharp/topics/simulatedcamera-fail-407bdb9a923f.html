void Fail(System.UInt32 code)

0이 아닌 오류 코드로 모의 카메라를 오류 상태로 전환합니다.

인자

code: 0이 아닌 오류 코드입니다.

사용과 결과 해석

연결 중 또는 획득 중인 모의 카메라를 0이 아닌 code로 오류 상태에 전환합니다. 대기 프레임과 트리거가 정리되며 잘못된 상태나 코드 0은 오류입니다.

모의 장애 이후 recover로 연결 상태를 복구할 수 있습니다. 이 동작은 소프트웨어 상태 시험이며 실제 카메라에 물리적 장애를 발생시키지 않습니다.

오류 전환과 복구

Fail은 소프트웨어 모의 카메라에 0이 아닌 오류 코드를 지정해 Faulted 상태로 전환합니다. Connected 또는 Acquiring 상태에서만 사용할 수 있고, 코드가 0이거나 다른 상태이면 오류입니다. 이 호출은 실제 카메라 장치에 물리적 고장을 발생시키지 않습니다.

전환 과정에서는 큐에 남은 프레임과 대기 트리거를 정리하고 해당 통계를 갱신합니다. 예를 들어 획득 중 트리거가 대기하는 상태에서 Fail을 호출하면 기존 대기 항목을 그대로 다음 획득으로 넘기지 않습니다. Faulted 상태에서는 Recover로 Connected 상태에 돌아갈 수 있으며 다시 획득하려면 적절한 시작 흐름이 필요합니다.
