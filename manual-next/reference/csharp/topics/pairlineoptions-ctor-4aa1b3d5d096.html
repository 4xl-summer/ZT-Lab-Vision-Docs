PairLineOptions()

기본 쌍 선택 설정을 만듭니다.

사용과 결과 해석

선 탐침의 에지 쌍 선택 기본 설정을 만듭니다. 두 극성은 Any, 강도 점수 방식은 Sum이고 예상 위치 및 폭은 지정되지 않습니다.

예상 위치와 폭은 픽셀 단위이며 null이면 해당 벌점에 사용되지 않습니다. 실제 에지 극성과 기대 폭을 알고 있다면 이를 명시하여 쌍 선택 조건을 구성하십시오.

에지 쌍 선택 기준

기본 설정은 첫 번째와 두 번째 에지의 극성을 모두 Any로 두고, 강도 합성 방식은 Sum입니다. ExpectedFirst, ExpectedSecond, ExpectedWidth는 null로 시작합니다. 이 예상값을 지정하지 않으면 해당 항목은 선택 벌점에 사용되지 않으며, 옵션을 만드는 것만으로 에지 검색이 실행되지는 않습니다.

예상 거리와 폭은 픽셀 단위입니다. 예를 들어 첫 에지가 탐침 시작점에서 약 4픽셀, 두 번째가 약 10픽셀에 나타난다면 기대 폭은 6픽셀로 설정할 수 있습니다. 극성은 탐침 진행 방향을 기준으로 하므로 탐침 방향을 바꾸면 상승과 하강의 의미도 함께 확인해야 합니다.

항목의미와 사용
FirstPolarity첫 에지 극성, 기본 Any
SecondPolarity둘째 에지 극성, 기본 Any
ExpectedFirst첫 에지 예상 거리, 픽셀 또는 null
ExpectedSecond둘째 에지 예상 거리, 픽셀 또는 null
ExpectedWidth두 에지 예상 폭, 픽셀 또는 null
Score강도 합성 방식, 기본 Sum
null 예상값해당 예상 항목을 벌점에 사용하지 않음
