static ZVision.FocusStackResult Create(ZVision.ZImage[] images)

정렬된 영상들을 초점 에너지로 결합합니다.

인자

images: 입력 Gray8 영상들입니다.

반환: 해제할 결과입니다.

이 호출의 입력과 객체 맥락

정렬된 Gray8 영상들을 국소 초점 에너지에 따라 결합합니다. 반환 결과에서 결합 영상과 입력 선택 인덱스 지도를 각각 얻어 어느 입력이 선택되었는지 확인합니다. 결과와 취득한 영상들은 각각 소유 객체이므로 별도로 Dispose합니다. 정렬이 필요한 입력은 사전에 같은 좌표 기준으로 맞추세요.

정렬된 입력과 인덱스 지도

Create는 정렬된 Gray8 영상 배열을 국소 초점 에너지에 따라 결합하고 FocusStackResult를 반환합니다. 각 영상의 같은 좌표가 같은 장면 위치를 가리켜야 결과를 해석할 수 있으므로 움직임이나 시점 차이가 있다면 먼저 별도 정렬 단계를 수행합니다. 이 호출 자체가 입력들을 자동 정합하는 것은 아닙니다. 입력은 원점과 크기가 같은 Gray8 영상 2..256개이며 에너지 동률은 먼저 전달한 프레임을 선택합니다.

결과는 결합 영상과 입력 선택 인덱스 지도를 별도 영상으로 제공합니다. 예를 들어 입력 순서를 [A,B,C]로 정했다면 지도 값은 그 순서의 프레임과 연결해야 합니다. 순서를 바꾼 배열과 기존 지도를 섞으면 어느 입력이 선택되었는지 잘못 해석할 수 있습니다.

결과 객체와 얻은 각 영상은 소유권을 따로 관리해야 합니다. 필요한 영상을 결과가 열린 동안 획득하고, 화면 표시나 픽셀 복사를 마친 뒤 각각 Dispose합니다. 초점 결합의 품질을 확인할 때는 결과 영상과 인덱스 지도를 같은 좌표에서 원본 영상들과 비교합니다.

판독과 확인 사례

입력은 원점과 크기가 같은 Gray8 영상 2..256개입니다. 커널은 3×3 지역에서 네 이웃 라플라시안의 제곱합을 초점 에너지로 비교하고, 정확히 같은 점수라면 먼저 전달한 프레임을 선택합니다. 경계 표본은 가장자리 복제를 사용합니다.

예를 들어 A와 B의 해당 위치 에너지가 완전히 같으면 입력 목록에서 먼저 온 영상이 선택됩니다. 따라서 입력 순서를 바꾸면 동률 위치의 인덱스 지도도 달라질 수 있습니다. 지도에서 선택된 프레임 번호와 결합 영상의 같은 좌표를 입력 배열과 함께 대조합니다.
