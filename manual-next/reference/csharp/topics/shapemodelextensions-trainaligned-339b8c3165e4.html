C#
static ZVision.AdvancedMatchModel TrainAligned(ZVision.ZImage[] images, ZVision.Point2 reference, System.Double minFraction, System.UInt64 sampleStep = 1, System.Nullable<System.Double> threshold = null, ZVision.ZImage mask = null)

Trains a shape from edge occurrences at corresponding coordinates in already aligned images.

인자

images: Two to 64 same-size, same-origin aligned images.

reference: Shared local reference point.

minFraction: Minimum occurrence fraction in (0,1].

sampleStep: Common sampling step.

threshold: Fixed gradient threshold, or null for per-image automatic threshold.

mask: Optional shared training mask.

반환: An owned shape model.

관련 입력의 확인된 조건

reference.X: 영역의 로컬 x 좌표입니다.

reference.Y: 영역의 로컬 y 좌표입니다.

AdvancedMatchModel.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

호출 맥락과 결과 해석

이미 같은 격자에 정렬된 영상 2개에서 64개를 입력해 공통 에지로 모델을 학습합니다. 이 함수에 영상을 전달한다고 자동 정렬되는 것은 아니므로 학습 전에 각 영상의 대응 위치를 맞추고 동일한 기준점을 정해야 합니다.

minFraction은 특징을 유지하는 데 필요한 에지 출현 비율이며 0보다 크고 1 이하여야 합니다. 예를 들어 여러 표본에서 일관된 경계를 남기려면 이 조건을 사용하고, 실제 유지된 형상은 학습 결과의 Features로 점검합니다. 반환 모델은 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미
imagesTwo to 64 same-size, same-origin aligned images.
referenceShared local reference point.
minFractionMinimum occurrence fraction in (0,1].
sampleStepCommon sampling step.
thresholdFixed gradient threshold, or null for per-image automatic threshold.
maskOptional shared training mask.
