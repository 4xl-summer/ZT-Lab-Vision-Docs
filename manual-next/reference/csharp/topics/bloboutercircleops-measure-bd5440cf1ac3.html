static ZVision.BlobOuterCircle Measure(ZVision.AdvancedBlobResult source, System.UInt64 index, System.UInt64 workBudget)

선택 Blob의 셀 모서리 볼록 껍질을 감싸는 원을 계산합니다.

인자

source: Blob 결과입니다.

index: 결과 순서의 0 기반 Blob 인덱스입니다.

workBudget: 허용하는 껍질 처리 상한입니다.

반환: ROI 로컬 외접원입니다.

관련 입력의 확인된 조건

source.Count: 측정된 Blob 수입니다.

source.MapInfo: 라벨 영상의 크기를 조회합니다. 부모 ROI 원점은 저장되지 않습니다.

source.Width: 라벨 영상의 픽셀 너비입니다.

source.Height: 라벨 영상의 픽셀 높이입니다.

적용과 결과 판독

선택한 Blob의 픽셀 셀 모서리에서 만든 볼록 껍질을 포함하는 외접원을 구합니다. 픽셀 중심만을 포함하는 원과 셀 모서리까지 포함하는 원은 반경이 다를 수 있습니다. 0 기반 index로 선택한 대상이 의도한 Blob인지 확인하고 반환 중심을 해당 ROI의 좌표로 해석하십시오.

인자확인된 역할
sourceBlob 결과입니다.
index결과 순서의 0 기반 Blob 인덱스입니다.
workBudget허용하는 껍질 처리 상한입니다.
