C#
static ZVision.ClockComparison CompareFrameTimes(ZVision.FrameInfo a, ZVision.ClockMap mapA, ZVision.FrameInfo b, ZVision.ClockMap mapB, System.UInt64 toleranceNs)

서로 다른 소스의 프레임을 각 맵으로 나노초에 변환하고 불확실성을 포함해 비교합니다. 장치 동기화를 측정하지 않습니다.

인자

a: 첫 번째 프레임 정보입니다.

mapA: 첫 번째 프레임에 대응하는 시계 맵입니다.

b: 두 번째 프레임 정보입니다.

mapB: 두 번째 프레임에 대응하는 시계 맵입니다.

toleranceNs: 불확실성을 포함한 허용 오차(나노초)입니다.

반환: 변환 시각과 허용 오차 비교 결과입니다.

관련 입력의 확인된 조건

a.SourceId: 0이 아닌 소스 식별자입니다.

a.Epoch: 취득 시작 시 증가하는 스트림 세대입니다.

a.TriggerId: 연결된 트리거 식별자이며 트리거가 없으면 0입니다.

a.DeviceTicks: 장치 시계의 틱 값입니다.

a.HostNs: 호출자가 제공한 호스트 시각(나노초)입니다.

a.ClockDomain: 0이 아닌 시계 도메인 식별자입니다.

a.TickHz: 초당 장치 틱 수입니다.

ClockComparison.WithinTolerance: 시각 차이와 불확실성의 합이 허용 오차 이내인지 나타냅니다.

ClockComparison.ANs: 첫 프레임의 변환된 호스트 시각(나노초)입니다.

ClockComparison.BNs: 둘째 프레임의 변환된 호스트 시각(나노초)입니다.

ClockComparison.SkewNs: 두 변환 시각의 절대 차이(나노초)입니다.

ClockComparison.TotalUncertaintyNs: 두 맵의 불확실성 합(나노초)입니다.

이 호출의 입력과 객체 맥락

mapA.AnchorHostNs: 기준 틱에 대응하는 호스트 시각(나노초)입니다.

mapA.UncertaintyNs: 시간 변환의 불확실성(나노초)입니다.
