문서화된 기본 탐침·에지 선택·피팅 설정으로 측정 옵션을 만듭니다.

생성과 입력 확인

문서화된 기본 탐침과 에지 선택 및 피팅 설정을 구성합니다. 기본값이 대상 영상의 모든 경계에 적합한 것은 아닙니다. 검색 위치와 길이, 폭 및 방향을 영상에 맞게 검토하고 실제 실행에서는 개별 프로브가 찾은 점과 최종 피팅에 채택된 점을 구분하십시오. ROI 경계와 영상 형식도 별도로 확인합니다.

판독과 사용 순서

기본 생성은 옵션 객체의 필드를 초기값으로 채웁니다. 탐침을 10개 배치하고 각 탐침에서 길이 14픽셀을 15개 지점으로 표본화하며, 수직 띠 폭은 3입니다. 기본 선택은 가장 강한 에지이고 진행 방향은 Forward입니다. 형상 적합을 시작하려면 최소 세 검출점이 필요합니다. 이 숫자들은 현재 ROI의 픽셀 기준이므로, 가령 대상이 탐색 구간 밖에 있으면 표본 수가 충분해도 해당 경계를 찾을 수 없습니다. 설정을 선 또는 원 측정 모델에 전달한 다음 각 프로브의 Found 여부와 최종 적합 상태를 따로 확인합니다. 강도 기울기 기준의 기본 10은 밝기값 자체가 아니라 픽셀당 변화량입니다.
