C#
System.Double[] Descriptors()

정규화 기술자를 특징점 순으로 평탄화해 복사합니다.

반환: 행 우선 기술자 값입니다. 각 길이는 (2×반경+1)²입니다.

호출과 결과 해석

학습된 특징점 순서로 정규화 기술자를 평탄한 double 배열에 복사합니다. Points는 특징점의 위치와 응답을, Descriptors는 기술자 수치를 나타내므로 두 배열의 역할이 다릅니다. 이것은 검색 영상의 대응점이나 기하 변환이 아닙니다. 모델을 정리하기 전에 필요한 조회를 마칩니다.

반환값

행 우선 기술자 값입니다. 각 길이는 (2×반경+1)²입니다.

평탄 배열의 인덱스

특징점마다 기술자 길이는 (2×반경+1)²이며 반환 배열은 특징점 순서로 이어 붙인 행 우선 값입니다. 예를 들어 반경 2이면 한 기술자는 5×5=25개입니다. 특징 인덱스 i의 기술자는 평탄 배열의 i×25 위치에서 시작합니다.

Points는 같은 학습 모델의 특징 위치와 응답을 제공하지만 이 배열 자체는 검색 영상에서 검출된 대응점이 아닙니다. 기술자 거리를 이용한 대응과 기하 추정은 Find 결과에서 확인합니다. 반환 배열은 복사본이므로 모델 내부 저장소를 직접 수정하는 용도가 아닙니다.

항목확인할 내용
반경 r한 기술자 길이 (2r+1)²
r=2한 특징당 25개 값
인덱스 ii×기술자 길이부터 해당 특징의 값
Points특징 위치와 Harris 응답

결과를 점검하는 방법

반경이 달라지면 한 특징의 기술자 길이도 바뀝니다. 예를 들어 반경 1이면 3×3=9개이고 반경 2이면 25개입니다. 모델별 설정을 확인한 뒤 특징점 인덱스에 맞는 구간을 읽어야 하며, 서로 다른 반경의 배열을 동일한 길이로 나누어 대응시키면 의미가 달라집니다.
