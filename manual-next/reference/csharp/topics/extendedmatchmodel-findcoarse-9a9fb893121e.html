FindCoarse

Method · 선언 타입 ZVision.ExtendedMatchModel

C#
ZVision.ExtendedMatchResult FindCoarse(ZVision.ZImage source, ZVision.ExtendedMatchOptions options, System.UInt32 pyramidLevels, System.Double coarseAcceptance = 0, System.UInt64 retainedCandidates = 128, ZVision.ZImage mask = null)

거친 격자에서 정밀화하며 검색합니다.

인자

source: 검색 영상입니다.

options: 검색 설정입니다.

pyramidLevels: 위치 격자 정밀화 단계 수입니다.

coarseAcceptance: 거친 단계에서 유지할 최소 점수입니다.

retainedCandidates: 각 정밀화 단계에서 유지할 최대 후보 수입니다.

mask: 선택적 마스크입니다.

반환: 독립 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ExtendedMatchResult.Matches: 점수 순서의 후보 복사본입니다.

ExtendedMatchResult.Evaluated: 평가된 포즈 수입니다.

ExtendedMatchResult.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

원본 이미지를 축소하지 않고 거친 위치 격자에서 후보를 선택한 뒤 위치 격자를 정밀화합니다. 실제 축소 영상 피라미드를 사용하는 FindImagePyramid와는 다른 절차입니다. pyramidLevels는 격자 정밀화의 단계 수입니다.

coarseAcceptance는 거친 단계에서 유지할 최소 점수이며 retainedCandidates는 각 단계에서 보유할 양의 최대 후보 수입니다. 두 조건을 너무 엄격하게 정하면 뒤 단계에서 정밀화할 후보가 없어질 수 있습니다. 종료 진단과 후보 수를 함께 비교합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options검색 설정입니다.
pyramidLevels위치 격자 정밀화 단계 수입니다.
coarseAcceptance거친 단계에서 유지할 최소 점수입니다.
retainedCandidates각 정밀화 단계에서 유지할 최대 후보 수입니다.
mask선택적 마스크입니다.
