ZVision.BeadResult InspectBeadPath(ZVision.Point2[] path, ZVision.BeadInspectionOptions options, System.Boolean[] include = null)

영상 로컬 좌표의 비드 경로를 검사합니다.

인자

path: 탐침 경로입니다.

options: 검사 옵션입니다.

include: 선택 탐침 마스크입니다.

반환: 호출자가 해제할 결과입니다.

관련 입력의 확인된 조건

options.MaxOffset: 허용 중심 이탈의 절댓값입니다.

options.SearchRadius: 법선 방향 검색 반경입니다.

options.ContrastThreshold: 에지 최소 밝기 차이입니다.

options.Polarity: 비드 밝기 극성입니다.

options.MaxGapLength: 허용 최대 연속 결손 호 길이입니다.

options.MinFailedProbes: 보고할 연속 실패 탐침의 최소 개수입니다.

options.MaxProbes: 최대 경로 탐침 수입니다.

options.MaxWork: 에지 및 쌍 평가의 최대 작업 수입니다.

BeadResult.Info: 0.1.x 호환 검사 스냅샷입니다. 정식 속성을 사용하세요.

BeadResult.LongestGapLength: 가장 긴 갭 길이입니다.

BeadResult.Passed: 전체 합격 여부입니다.

BeadResult.Runs: 결함 구간 복사본입니다.

인자별 입력 조건

인자형식역할과 조건
pathZVision.Point2[]탐침 경로입니다.
optionsZVision.BeadInspectionOptions검사 옵션입니다.
includeSystem.Boolean[]선택 탐침 마스크입니다.

경로 기반 비드 검사

현재 영상과 순서 있는 경로, 비드 설정으로 폭과 결손 구간을 검사합니다. 경로의 점은 입력의 ROI 로컬 좌표를 기준으로 해석하고 표본의 순서를 유지합니다.

최장 간격과 개별 연속 구간, 전체 판정은 서로 다른 결과입니다. 픽셀 길이를 세계 단위로 보려면 별도 좌표 매핑을 지정하고 반환 소유 결과는 사용 후 Dispose합니다.
