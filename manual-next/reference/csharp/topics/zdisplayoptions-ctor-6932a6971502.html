C#
ZDisplayOptions(System.Double minimum = 0, System.Double maximum = 65535)

표시 범위를 만듭니다.

인자

minimum: 유한한 하한입니다.

maximum: 하한보다 큰 유한한 상한입니다.

사용 순서와 결과 해석

비바이트 채널을 표시용 바이트로 변환할 하한과 상한을 지정합니다. 두 수는 유한해야 하며 maximum은 minimum보다 커야 합니다. 기본값은 0과 65535입니다. 하한 이하는 0, 상한 이상은 255로 표시되고 중간 값은 선형 변환됩니다. 원본 채널 값은 이 설정으로 변경되지 않습니다.

입력별 확인

입력의미
minimum유한한 하한입니다.
maximum하한보다 큰 유한한 상한입니다.
