Fit

Method · 선언 타입 ZVision.Display.ZViewport

C#
void Fit(System.Int32 iw, System.Int32 ih, System.Double vw, System.Double vh)

영상 전체가 화면에 들어오도록 중앙 정렬합니다.

인자

iw: 영상 너비입니다.

ih: 영상 높이입니다.

vw: 화면 너비입니다.

vh: 화면 높이입니다.

사용 순서와 결과 해석

영상과 화면의 너비·높이를 이용해 전체 영상을 화면 중앙에 맞춥니다. 배율은 min(vw/iw, vh/ih)를 허용 범위로 제한하고 남는 공간을 양쪽에 나눕니다. 예를 들어 100×50 영상을 200×200 화면에 맞추면 배율 2, 이동 (0,50)입니다. 크기는 양수이고 화면 크기도 유한해야 합니다.

입력별 확인

입력의미
iw영상 너비입니다.
ih영상 높이입니다.
vw화면 너비입니다.
vh화면 높이입니다.
