C#
static ZVision.RepeatabilityMetrics EvaluateRepeatability(System.Double[] values, System.Double reference, System.Double maxAbsBias, System.Double maxStddev)

같은 단위의 유한한 측정값 2개 이상으로 편향과 표본 표준편차를 평가합니다.

인자

values: 같은 단위의 유한 측정값 2개 이상입니다.

reference: 측정값과 같은 단위의 유한 기준값입니다.

maxAbsBias: 허용 절대 편향의 유한한 비음수 상한입니다.

maxStddev: 허용 표본 표준편차의 유한한 비음수 상한입니다.

반환: 계산된 결과입니다.

관련 입력의 확인된 조건

RepeatabilityMetrics.Passed: 절대 편향과 표본 표준편차가 각각의 한계 이하이면 참입니다.

RepeatabilityMetrics.Count: 입력 또는 검증한 항목 수입니다.

RepeatabilityMetrics.Mean: 측정값의 산술 평균입니다.

RepeatabilityMetrics.SampleStddev: n-1로 나눈 분산의 제곱근인 표본 표준편차입니다.

RepeatabilityMetrics.Bias: 평균에서 기준값을 뺀 편향입니다.

RepeatabilityMetrics.Range: 최댓값에서 최솟값을 뺀 범위입니다.

계산과 결과 해석

동일 조건에서 얻은 여러 수치의 평균, 표본 표준편차와 기준값 대비 편향을 계산합니다. 입력은 유한한 값 두 개 이상이며 reference와 두 허용 한계도 측정값과 같은 단위를 사용합니다. 표본 표준편차는 편차 제곱합을 n−1로 나눈 값의 제곱근이고 평균의 Type A 표준 불확도는 이를 √n으로 나눈 값입니다. 예를 들어 세 값이 모두 5이고 기준도 5라면 편향과 표준편차는 0입니다. passed는 절대 편향과 표본 표준편차가 각각의 한계 이하일 때 참입니다. 반복성 통계는 제공한 데이터 집합의 특성을 요약할 뿐 다른 작업 조건이나 장비의 전체 오차를 자동으로 포함하지 않습니다. 값이 픽셀인지 밀리미터인지 기준과 함께 기록하고 서로 다른 단위를 섞지 마십시오. 측정값이 모두 같아 표준편차가 0이어도 그 값이 기준에서 떨어져 있으면 편향은 0이 아닙니다. 예를 들어 값이 모두 5이고 기준이 4라면 평균 편향은 1입니다. 반복 측정의 퍼짐과 기준에 대한 차이는 각각의 한계로 판독해야 합니다. 입력값의 순서를 바꾸더라도 같은 표본 집합의 평균과 표준편차는 변하지 않습니다. 다만 시간에 따른 드리프트는 이 집계값만으로 확인할 수 없으므로 측정 순서와 원래 기록을 별도로 보존하는 편이 좋습니다.
