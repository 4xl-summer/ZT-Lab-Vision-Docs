RegistrationGraphEdge(System.UInt64 reference, System.UInt64 source, ZVision.AdvancedRegistrationOptions options)

정합 연결을 생성합니다.

인자

reference: 기준 영상 인덱스입니다.

source: 소스 영상 인덱스입니다.

options: 쌍 정합 설정입니다. 호출 중 수정하지 마세요.

관련 입력의 확인된 조건

options.Projective: 원근 변환을 사용합니다. false는 affine입니다.

options.MeanSquaredError: 평균 제곱 오차를 사용합니다. false는 NCC입니다.

options.Initial: 마지막 계수 1을 생략한 행 우선 초기 행렬 8개입니다.

options.Steps: 각 계수의 초기 좌표 탐색 간격 8개입니다.

options.IterationsPerLevel: 단계별 최대 반복 횟수입니다.

options.MinCoverage: 최소 유효 표본 비율입니다.

설정과 사용 흐름

다중 정합 그래프의 기준 영상 인덱스, 소스 영상 인덱스와 쌍별 정합 설정을 묶습니다. options의 초기 행렬과 탐색 간격 등은 해당 간선의 추정에 사용됩니다.

reference와 source는 영상 배열의 위치이며 방향이 있습니다. 결과 행렬 방향과 혼동하지 않도록 입력 배열 순서를 유지하고 호출 중 설정 객체를 수정하지 마십시오.
