ZVision.BoundedTemplateResult Find(ZVision.ZImage image, ZVision.BoundedTemplateOptions options)

한 영상에서 정수 이동을 검색합니다.

인자

image: 모델과 동일한 형식의 검색 영상입니다.

options: 검색 영역·임계값·작업량입니다. 호출 중 설정 객체를 수정하지 마세요.

반환: 독립 검색 결과입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BoundedTemplateResult.Matches: 독립 복사된 검색 결과입니다.

BoundedTemplateResult.Evaluated: 평가한 위치 개수입니다.

호출 맥락과 결과 해석

학습된 템플릿을 지정 범위의 정수 평행이동 위치에서 검색합니다. 입력 영상은 학습 방식에 맞게 ColorNcc에는 RGB8, GraySad에는 Gray8을 사용합니다. 회전이나 배율을 탐색하는 확장 포즈 검색과 입력 해석이 다릅니다.

BoundedTemplateOptions의 포함 범위, 판정값, 결과 및 작업 상한이 함께 결과를 정합니다. 검색 결과가 비면 지정 범위와 판정값, 작업 한도부터 확인합니다. 반환 BoundedTemplateResult는 네이티브 결과에서 복사한 독립 값입니다.

입력 선택을 위한 확인

입력의미와 조건
image모델과 동일한 형식의 검색 영상입니다.
options검색 영역·임계값·작업량입니다. 호출 중 설정 객체를 수정하지 마세요.

반환값 확인

독립 검색 결과입니다.
