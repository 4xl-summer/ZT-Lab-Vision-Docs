T AcquireOutput()

호출할 때마다 실행 출력의 독립 소유 결과를 얻습니다. 실행 해제 후에도 획득한 결과는 유효합니다.

반환: 호출자가 별도로 Dispose해야 하는 결과입니다.

사용과 결과 해석

실행 출력에서 독립 소유 결과를 얻습니다. 호출할 때마다 별도 소유 결과를 획득하며 실행을 해제한 뒤에도 이미 얻은 결과는 유효합니다.

실행 객체와 획득 결과는 각각 Dispose해야 합니다. 필요한 결과를 얻고 실행을 정리한 뒤에도 획득한 객체의 별도 수명을 관리하십시오.

사용 흐름과 판독 기준

AcquireOutput은 실행 결과에서 T 형식의 독립 소유 결과를 획득합니다. 호출할 때마다 반환되는 소유 객체는 실행 핸들과 수명이 분리되어 있으며, 이미 얻은 결과는 실행 객체를 해제한 뒤에도 유효합니다. T는 IDisposable 제약이 있으므로 획득한 결과의 사용이 끝나면 호출자가 그 객체를 Dispose해야 합니다.

예를 들어 실행에서 결과 A를 획득하고 실행을 닫은 뒤에도 A를 읽을 수 있습니다. 이후 A의 작업이 끝나면 A를 별도로 해제합니다. 결과를 두 번 획득했다면 두 반환 객체 각각의 수명을 관리해야 하며, 한 번의 실행 Dispose를 두 결과의 해제와 같은 동작으로 간주하지 않습니다.

이 메서드는 저장된 출력을 획득하는 경로이며 결과를 계산하는 쿼리의 설정이나 입력을 새로 변경하지 않습니다. 호출 전에 실행이 유효한지 확인하고, 실행에서 얻은 결과의 실제 T 형식과 그 형식이 제공하는 판독 메서드를 사용합니다. 실행을 닫은 뒤 새 출력을 획득하는 행위와 닫기 전에 획득한 결과를 계속 사용하는 행위는 구분합니다.
