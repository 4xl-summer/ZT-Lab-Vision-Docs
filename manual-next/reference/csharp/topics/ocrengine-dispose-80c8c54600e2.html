void Dispose()

소유한 네이티브 핸들을 해제합니다.

수명과 사용 순서

OCR 엔진이 소유한 네이티브 핸들을 해제합니다. 해당 엔진의 텍스트 읽기를 마친 뒤 호출하십시오.

이 호출에는 반환값이 없습니다. C#에서 소유 객체의 사용 범위를 정하고 필요한 작업이 끝나면 해제하여 네이티브 자원을 정리하십시오. 해제된 객체는 이후 작업에 사용하지 않습니다.

OCR 엔진과 판독 스냅샷

OcrEngine.Load는 호출자가 준비한 RTen 모델 파일을 읽어 네이티브 엔진을 만듭니다. 모델은 자동 다운로드하지 않습니다. 엔진을 사용하는 동안 Gray8 영상과 OcrSpec을 ReadText에 전달하고, 필요한 판독이 끝나면 Dispose로 엔진 핸들을 해제합니다.

ReadText가 돌려주는 OcrRead는 영상과 엔진 해제 후에도 유효한 독립 판독 스냅샷입니다. 문자열과 함께 Status 및 Reasons를 확인해 수락, 미판독, 거절을 구분하십시오. 글자 길이와 허용 문자 조건은 인식 후 판정 조건이며, 결과의 텍스트에는 예측된 공백이 보존됩니다.
