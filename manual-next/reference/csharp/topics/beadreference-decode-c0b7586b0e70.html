C#
static ZVision.BeadReference Decode(ZVision.ZImage template, System.Byte[] bytes, System.UInt64 maxBytes, System.UInt64 maxProbes, System.UInt64 maxWork)

경로와 설정을 저장된 데이터에서 복원합니다.

인자

template: 경로 검증에 사용할 Gray 영상입니다.

bytes: 모델 데이터입니다.

maxBytes: 바이트 한도입니다.

maxProbes: 탐침 수 한도입니다.

maxWork: 탐침 작업량 한도입니다.

반환: 호출자가 해제할 불변 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

인자별 입력 조건

인자형식역할과 조건
templateZVision.ZImage경로 검증에 사용할 Gray 영상입니다.
bytesSystem.Byte[]모델 데이터입니다.
maxBytesSystem.UInt64바이트 한도입니다.
maxProbesSystem.UInt64탐침 수 한도입니다.
maxWorkSystem.UInt64탐침 작업량 한도입니다.

기준 모델 복원

경로 검증용 Gray template, 저장 바이트와 maxBytes, maxProbes, maxWork 한도로 모델을 복원합니다. 반환 모델은 호출자가 Dispose합니다.

template의 형식과 원점, 크기가 사용할 영상과 대응하는지 확인합니다. 손상된 데이터와 제한 초과 오류를 빈 경로의 정상 모델로 해석하지 않습니다.
