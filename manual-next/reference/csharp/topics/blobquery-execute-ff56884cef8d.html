Execute의 사용과 결과 해석

실행 후 생성된 결과는 계획의 설명 자체가 아니라 계산된 연결 영역입니다. 각 결과의 개수와 선택 기준을 확인하고 실행 객체의 해제 시점을 관리합니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.

사용 순서와 결과 보관

BlobQuery.Execute는 설정된 선택·정렬·분석 계획을 실행해 QueryExecution<BlobAnalysisResult>를 반환합니다. 계획을 구성하는 단계와 실제 입력에서 연결 영역 스냅샷을 만드는 단계는 다릅니다. 반환된 실행은 호출자가 해제해야 하며 계산 실패를 성분이 없는 정상 결과로 바꾸지 않습니다.

실행 출력의 각 성분은 같은 입력 영상과 설정에서 계산된 값입니다. 예를 들어 대각선으로 닿은 전경의 결과 개수는 선택한 4연결 또는 8연결 설정에 따라 달라질 수 있습니다. 실행 결과의 항목 수와 각 성분의 라벨·면적을 확인하고, 원본 영상의 ROI 기준을 함께 기록합니다.

출력 스냅샷과 실행 객체의 수명은 각각의 반환 계약에 따라 읽습니다. 실행에서 얻은 복사 값은 계획 자체가 아니며, 다른 실행의 인덱스가 같은 물체를 가리킨다고 단정하지 않습니다. 결과 판독 후 실행을 Dispose하고 계획도 더 이상 필요하지 않으면 그 소유 빌더를 별도로 정리합니다.
