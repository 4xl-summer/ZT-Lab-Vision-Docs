ZVision.AdvancedShapeDiagnostics Diagnose(ZVision.ZImage source, ZVision.AdvancedMatch pose, System.Double minGradient = 0, System.UInt64 radius = 1, System.Boolean eitherPolarity = false)

형상 포즈 주변의 대응 에지와 기하 잔차를 계산합니다.

인자

source: 검색 소스 영상입니다.

pose: 진단할 형상 포즈입니다.

minGradient: 대상 기울기 임계값입니다.

radius: 최근접 에지 탐색 반경 픽셀입니다.

eitherPolarity: 에지 반전을 허용합니다.

반환: 모델 및 대상 커버리지와 적합 오차입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedShapeDiagnostics.MatchedModelFraction: 대응 대상 에지가 있는 모델 특징 비율입니다.

AdvancedShapeDiagnostics.TargetEdgeCoverage: 대응 모델 특징이 있는 대상 에지 비율입니다.

AdvancedShapeDiagnostics.ClutterFraction: 대응되지 않은 대상 에지 비율입니다.

AdvancedShapeDiagnostics.FitRms: 대응 에지 거리 RMS이며 HasFit이 1일 때 유효합니다.

AdvancedShapeDiagnostics.MatchedFeatures: 대응된 모델 특징 수입니다.

AdvancedShapeDiagnostics.TargetEdges: 진단 영역의 대상 에지 수입니다.

호출 맥락과 결과 해석

먼저 검색 결과에서 진단할 포즈를 선택한 뒤 같은 소스 영상에 대해 호출합니다. 모델 특징 주변에서 기울기 조건과 반경에 맞는 에지를 찾아 특징 일치와 에지 커버리지, 클러터를 함께 살핍니다. 검색 자체를 다시 수행해 새 포즈를 찾는 호출은 아닙니다.

radius와 minGradient는 진단할 주변 에지의 범위와 강도를 바꿉니다. eitherPolarity가 False인 경우와 양쪽 극성을 허용하는 경우를 비교할 때는 다른 설정과 입력 포즈를 그대로 유지해야 차이를 해석할 수 있습니다. 반환값은 모델 및 영상과 독립된 진단 값입니다.

입력 선택을 위한 확인

입력의미
source검색 소스 영상입니다.
pose진단할 형상 포즈입니다.
minGradient대상 기울기 임계값입니다.
radius최근접 에지 탐색 반경 픽셀입니다.
eitherPolarity에지 반전을 허용합니다.
