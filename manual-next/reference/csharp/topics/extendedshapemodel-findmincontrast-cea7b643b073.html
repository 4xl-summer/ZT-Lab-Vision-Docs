C#
ZVision.ExtendedMatchResult FindMinContrast(ZVision.ZImage source, ZVision.ShapeSearchOptions options, System.Double minContrast, ZVision.ZImage mask = null)

대상 에지의 최소 대비를 적용해 형상을 검색합니다.

인자

source: 검색 영상입니다.

options: 검색 설정입니다.

minContrast: 허용할 최소 대비입니다.

mask: 선택적 마스크입니다.

반환: 독립 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ExtendedMatchResult.Matches: 점수 순서의 후보 복사본입니다.

ExtendedMatchResult.Evaluated: 평가된 포즈 수입니다.

ExtendedMatchResult.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

형상 후보의 유효 영역에서 평균 기울기가 지정한 최소 대비 조건을 만족하는지 반영해 검색합니다. minContrast는 유한한 비음수이며 영상의 에지 강도 조건입니다. 매치 점수 하한과는 서로 다른 역할을 하므로 두 값을 혼동하지 않습니다.

조명이 낮거나 경계가 희미한 영상에서 기준을 올리면 후보가 줄 수 있습니다. 기존 검색 옵션과 입력을 고정하고 최소 대비만 바꾸어 매치 목록과 종료 상태를 비교하면 대비 조건이 결과에 미치는 영향을 분리할 수 있습니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options검색 설정입니다.
minContrast허용할 최소 대비입니다.
mask선택적 마스크입니다.

반환값 확인

독립 결과입니다.
