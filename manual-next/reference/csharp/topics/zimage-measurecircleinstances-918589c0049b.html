MeasureCircleInstances

C#
ZVision.MeasurementInstance[] MeasureCircleInstances(ZVision.MeasurementCircleSpec spec, ZVision.MeasurementProbeOptions options, ZVision.InstancePlacement[] placements)

명시 배치마다 같은 원 모델을 측정합니다.

인자

spec: 배치 전 원 모델입니다.

options: 탐침 및 피팅 설정입니다.

placements: 1~64개 배치입니다.

반환: 입력 순서의 독립 결과이며 자동 배치 검색이나 중복 제거를 수행하지 않습니다.

관련 입력의 확인된 조건

spec.Center: ROI 로컬 원 중심입니다.

spec.Radius: 양의 픽셀 반지름입니다.

spec.StartAngle: 시작 라디안 각도입니다.

spec.EndAngle: 끝 라디안 각도이며 시작보다 크고 한 바퀴 이하여야 합니다.

사용과 결과 판독

명시한 1~64개 배치마다 같은 원 모델을 실행합니다. 반환 배열은 입력 순서의 독립 결과이며 물체를 자동으로 찾아 배치를 만들거나 중복을 제거하지 않습니다. 각 결과를 해당 배치와 연결하고 기준 원호가 실제 경계를 가로지르는지, 관측점이 원 주변에 어떻게 분포하는지 확인합니다. 실패한 인스턴스를 반경 0의 정상 원으로 기록하지 마십시오.

입력역할
spec배치 전 원 모델입니다.
options탐침 및 피팅 설정입니다.
placements1~64개 배치입니다.
