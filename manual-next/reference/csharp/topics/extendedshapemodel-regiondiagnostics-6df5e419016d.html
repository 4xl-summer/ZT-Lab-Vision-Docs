ZVision.ShapeRegionDiagnostics RegionDiagnostics(ZVision.AdvancedMatch pose, System.Double[] region)

영역 진단을 계산합니다.

인자

pose: 진단할 형상 포즈입니다.

region: 진단하거나 검색에 사용할 사각형 좌표 배열입니다.

반환: 영역 진단입니다.

관련 입력의 확인된 조건

pose.X: 로컬 X 기준 좌표입니다.

pose.Y: 로컬 Y 기준 좌표입니다.

pose.GlobalX: 전역 X 기준 좌표입니다.

pose.GlobalY: 전역 Y 기준 좌표입니다.

pose.ModelCoverage: 가시 모델 표본 비율입니다.

pose.Contrast: 후보의 광도 또는 기울기 대비입니다.

pose.SampleCount: 점수 계산에 사용된 표본 수입니다.

ShapeRegionDiagnostics.OutsideAreaFraction: 모델 경계 사각형 중 영역 밖 면적 비율입니다.

ShapeRegionDiagnostics.OutsideFeatureFraction: 영역 밖 특징 비율입니다.

ShapeRegionDiagnostics.AnchorInside: 모델 기준점이 영역 안인지 나타냅니다.

호출 맥락과 결과 해석

선택한 매치 포즈로 변환된 모델과 region의 관계를 계산합니다. region은 검색 영상 로컬 좌표의 (xmin, ymin, xmax, ymax) 사각형이며 양 끝을 포함합니다. 결과는 바깥 면적 비율과 특징 비율, 기준점이 포함되는지 여부를 구분합니다.

기준점이 사각형 안에 있어도 변환된 모델 일부가 밖으로 나갈 수 있습니다. 따라서 기준점 포함 여부 하나만 보고 전체 형상이 영역 안에 있다고 판단하지 말고 바깥 비율을 함께 살펴야 합니다. 이 호출은 후보를 새로 검색하지 않고 전달한 포즈를 진단합니다.

입력 선택을 위한 확인

입력의미와 조건
pose진단할 형상 포즈입니다.
region진단하거나 검색에 사용할 사각형 좌표 배열입니다.

반환값 확인

영역 진단입니다.
