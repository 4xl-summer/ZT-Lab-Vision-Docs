WithCoefficients

Method · 선언 타입 ZVision.GapStationaryHaar

C#
ZVision.GapStationaryHaar WithCoefficients(System.Double[] values)

외부 계수 스냅샷으로 독립 모델을 만듭니다.

인자

values: 모든 밴드의 정확한 길이 유한 계수입니다.

반환: 해제할 독립 모델입니다.

이 호출의 입력과 객체 맥락

외부의 유한 계수 배열을 복사해 독립 모델을 만듭니다. 배열은 원 모델이 요구하는 전체 크기와 순서에 맞아야 합니다. 예를 들어 Coefficients로 복사한 값을 수정한 뒤 이 메서드에 주면 원본과 별도의 모델을 갖게 됩니다. 새 모델을 Inverse로 확인하고, 원본 모델·새 모델·반환 영상의 수명은 각각 관리합니다.

새 계수로 독립 모델

WithCoefficients(double[] values)는 현재 정지 Haar 모델의 격자 및 밴드 구조에 맞는 새 계수로 독립 모델을 만듭니다. values가 null이면 오류이고 길이는 Width × Height × Bands와 같아야 합니다. 각 원소는 유한한 double이어야 합니다.

예를 들어 4×3 격자에 밴드가 4개라면 48개 계수가 필요합니다. 47개나 49개 배열은 모델 구조와 맞지 않습니다. 계수는 밴드와 행의 순서를 지키며 원본 영상의 같은 위치 밝기라고 해석하지 않습니다.

항목확인할 내용
values새 계수의 double 배열
길이Width × Height × Bands
수치모든 값이 유한해야 함
반환독립 GapStationaryHaar
기존 모델별도로 유지·해제
Inverse독립 GrayF64 복원 영상

Coefficients()로 복사한 배열을 준비해 필요한 계수만 수정하고 WithCoefficients로 새 모델을 얻습니다. 원래 모델은 그대로 별도 보유합니다. 각 모델의 Inverse 결과를 같은 ROI 원점과 크기에서 비교하고, 새 모델과 얻은 ZImage는 각각 Dispose합니다.

적용과 판독을 더 살펴보기

배열 길이만 일치해도 밴드 순서를 잘못 배치하면 의미가 다른 모델이 만들어질 수 있습니다. Metadata를 보고 각 밴드의 위치와 영상 크기를 확인한 다음 Coefficients가 반환한 순서를 유지해 수정합니다. 입력 배열의 원소가 NaN 또는 무한대이면 거절되므로 유한한 값으로 준비해야 합니다. 기존 모델과 새 모델은 별도 객체이므로 한쪽의 해제가 다른 쪽의 사용 순서를 대신하지 않습니다. 복원 영상을 비교할 때 원래 ROI 원점과 크기, 각 영상의 픽셀 형식을 같이 확인합니다. 원본과 복원 결과의 차이는 수정한 계수뿐 아니라 표시 범위에도 영향을 받을 수 있습니다.
