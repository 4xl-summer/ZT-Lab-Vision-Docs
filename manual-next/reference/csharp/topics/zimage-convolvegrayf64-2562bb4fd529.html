ZVision.ZImage ConvolveGrayF64(ZVision.ConvolutionSpec spec)

GrayF64 영상의 ROI에 유한 커널 합성곱 또는 상관을 적용합니다.

인자

spec: 커널·앵커·경계 설정입니다.

반환: 원점을 보존하며 호출자가 Dispose할 독립 GrayF64 영상입니다.

관련 입력의 확인된 조건

spec.AnchorX: 커널 내부 x 앵커입니다.

spec.AnchorY: 커널 내부 y 앵커입니다.

spec.Kernel: 행 우선 커널 값입니다.

spec.Divisor: 합산 결과의 제수입니다.

spec.Offset: 제수 적용 후 더할 값입니다.

spec.Border: 입력 ROI 경계 방식입니다.

spec.Output: 출력 픽셀 형식입니다.

spec.Correlate: 상관 연산 여부입니다.

spec.Constant: 상수 경계의 밝기입니다.

호출에 필요한 입력

GrayF64 영상에 지정된 커널로 상관 또는 컨볼루션을 적용합니다.

인자선언된 형식확인할 내용
specZVision.ConvolutionSpec커널·앵커·경계 설정입니다.

spec의 입력 값

필드의미와 조건
constant상수 경계에 사용하는 밝기이며 기본값은 0입니다.
width커널의 양의 너비입니다.
height커널의 양의 높이입니다.
kernel행 우선 유한 계수로 너비×높이 개수가 필요합니다.
divisor가중 합을 나누는 0이 아닌 유한 값입니다.

결과와 사용 순서

원점을 보존하며 호출자가 Dispose할 독립 GrayF64 영상입니다.

입력과 결과 해석

이웃 표본을 이용하는 연산에서는 중심부와 영상 가장자리의 결과가 다를 수 있습니다. 커널과 경계 처리를 고정하고 작은 입력의 중심 값과 가장자리 값을 따로 확인하세요.
