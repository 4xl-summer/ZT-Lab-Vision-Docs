ZInspectionExecutor()

기존 Rust 커널을 사용하는 동기 실행기를 만듭니다.

사용과 결과 해석

기존 Rust 커널을 사용하는 동기 검사 실행기를 만듭니다. 실제 입력 처리와 결과 생성은 Execute에서 수행합니다.

검사 설정과 입력, 프레임 및 레시피 세대, 취소 토큰은 실행 시 전달합니다. 생성 자체가 검사를 실행하거나 결과를 소유하는 것은 아닙니다.

실행기와 검사 단계

ZInspectionExecutor 생성자는 기존 Rust 커널을 사용하는 동기 실행기를 만듭니다. 생성자에는 영상이나 레시피가 전달되지 않으며 검사도 아직 실행되지 않습니다. 실제 Execute에서는 입력 영상, frameId, recipeVersion, 불변 ZInspectionRecipe와 CancellationToken을 받습니다.

레시피는 선택 ROI, Gaussian, 이진 임계값, 닫기와 최소 영역 조건을 담습니다. 예를 들어 frameId와 recipeVersion을 결과와 함께 유지하면 늦게 완료된 이전 프레임을 현재 설정 결과와 구분할 수 있습니다. 입력은 호출 중 빌리고 반환된 결과는 호출자가 소유합니다. 취소 토큰은 단계 사이에서 확인됩니다.
