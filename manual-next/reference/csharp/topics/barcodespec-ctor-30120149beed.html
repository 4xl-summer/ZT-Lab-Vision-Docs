Constructor · 선언 타입 ZVision.BarcodeSpec

C#
BarcodeSpec(ZVision.BarcodeFormat formats, System.Boolean tryRotate = false, System.Double minContrast = 0)

단일 바코드 판독의 형식, 회전 및 대비 설정입니다.

인자

formats: 선택할 바코드 형식의 0이 아닌 조합입니다.

tryRotate: 명시적 90도 회전도 시도할지 여부입니다. 기본값은 false입니다.

minContrast: 최소 대비로 0~1입니다.

관련 입력의 확인된 조건

formats.Code128: Code 128 바코드를 선택합니다.

formats.Code39: Code 39 바코드를 선택합니다.

formats.Ean13: EAN-13 바코드를 선택합니다.

formats.QrCode: QR Code를 선택합니다.

formats.DataMatrix: Data Matrix를 선택합니다.

formats.All: 지원하는 모든 바코드 형식을 선택합니다.

사용과 결과 판독

단일 바코드의 형식 조합, 90도 회전 시도 여부와 0~1 최소 대비를 지정합니다. 형식 조합은 0이 아니어야 하며 회전 시도 기본값은 false입니다. 후보가 없을 때 형식 선택과 ROI, 대비를 함께 살펴야 합니다.

항목확인된 역할
formats선택할 바코드 형식의 0이 아닌 조합입니다.
tryRotate명시적 90도 회전도 시도할지 여부입니다. 기본값은 false입니다.
minContrast최소 대비로 0~1입니다.

예를 들어 회전 시도를 끈 경우에는 입력이 놓인 방향을 먼저 검토하고, 최소 대비는 강도 차이를 고르는 기준으로 설정합니다. 형식 조합과 결과의 형식을 같이 기록하면 다른 코드 종류로 인한 혼동을 줄일 수 있습니다.
