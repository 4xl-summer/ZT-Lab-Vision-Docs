System.ValueTuple<ZVision.ZImage, ZVision.CopyRegionReport> CopyRegionToImage(ZVision.ZImage destination, ZVision.ZImage mask, ZVision.CopyRegionOptions options)

원본 ROI의 선택 영역을 목적 영상의 독립 복사본에 복사합니다.

인자

destination: 복사 대상 영상입니다.

mask: 원본에 정렬된 선택 마스크 또는 null입니다.

options: 원본·목적 ROI 상대 영역과 클리핑 설정입니다.

반환: 호출자가 Dispose할 영상과 복사 보고서입니다.

관련 입력의 확인된 조건

options.SourceX: 원본 ROI 상대 x 좌표입니다.

options.SourceY: 원본 ROI 상대 y 좌표입니다.

options.DestinationX: 목적 ROI 상대 x 좌표입니다.

options.DestinationY: 목적 ROI 상대 y 좌표입니다.

options.Clip: 목적 영상 밖을 잘라낼지 지정합니다.

호출에 필요한 입력

선택 영역을 대상 영상의 독립 복사본에 복사합니다.

인자선언된 형식확인할 내용
destinationZVision.ZImage복사 대상 영상입니다.
maskZVision.ZImage원본에 정렬된 선택 마스크 또는 null입니다.
optionsZVision.CopyRegionOptions원본·목적 ROI 상대 영역과 클리핑 설정입니다.

options의 입력 값

필드의미와 조건
clip대상 범위를 벗어난 부분을 자를지 지정합니다.
source_x원본 ROI 로컬 사각형의 x 시작점입니다.
source_y원본 ROI 로컬 사각형의 y 시작점입니다.
width원본 사각형의 폭(픽셀)입니다.
height원본 사각형의 높이(픽셀)입니다.

결과와 사용 순서

호출자가 Dispose할 영상과 복사 보고서입니다.

반환 값의 읽을 항목

항목의미
copied대상에 복사된 선택 픽셀 수입니다.
clipped대상 영역 밖으로 잘린 선택 픽셀 수입니다.

입력과 결과 해석

마스크나 영역의 좌표가 대상 영상의 보이는 영역과 일치해야 같은 픽셀을 선택합니다. ROI 원점과 크기를 함께 확인하고 제외된 영역의 값을 유효한 검사 결과와 구별하세요.
