void Dispose()

소유한 네이티브 모델 핸들을 해제합니다.

사용을 마치는 순서

기본 NCC 또는 형상 모델을 해제합니다. Find를 완료하고 필요한 MatchResult를 얻은 다음 호출합니다. MatchResult는 영상과 모델을 해제한 뒤에도 유효한 독립 결과입니다. 모델 자체를 나중에 다시 쓰려면 해제 전에 Save를 사용하고 Load로 복원할 수 있습니다.

사용 순서

호출역할
TrainNcc / TrainShape / Load기본 모델을 학습하거나 파일에서 복원
Find / Save독립 매치 결과 획득 또는 모델 저장
Dispose모델 사용이 끝나면 정리

템플릿 중심과 결과의 수명

기본 모델의 기준점은 템플릿 로컬 중심 ((폭−1)/2,(높이−1)/2)입니다. 예를 들어 3×2 템플릿이면 기준점은 (1,0.5)입니다. Find 결과 위치는 이 기준점의 검색 위치이므로 템플릿 좌상단으로 바로 해석하지 않습니다.

MatchResult는 독립 값 스냅샷으로 이미 획득한 결과는 모델과 입력 영상을 해제한 뒤에도 유효합니다. 모델 자체를 다시 사용하려면 Dispose 전에 Save하고 나중에 Load로 별도 모델을 복원합니다. 검색 영상의 ROI와 MatchSpec은 따로 보관해야 합니다.
