static ZVision.Affine2 Fit(ZVision.Point2[] source, ZVision.Point2[] target, System.Boolean similarity = false)

양의 균일 배율을 선택적으로 허용하고 평면 회전·이동을 피팅합니다.

인자

source: 두 개 이상인 원본 점입니다.

target: 원본과 일대일로 대응하는 목표 점입니다.

similarity: 참이면 하나의 양의 균일 배율도 추정합니다.

반환: 원본에서 목표로 가는 변환입니다.

관련 입력의 확인된 조건

Affine2.A: x 출력의 x 계수입니다.

Affine2.B: x 출력의 y 계수입니다.

Affine2.Tx: x 출력의 이동량입니다.

Affine2.C: y 출력의 x 계수입니다.

Affine2.D: y 출력의 y 계수입니다.

Affine2.Ty: y 출력의 이동량입니다.

사용과 결과 판독

원본과 목표의 대응점으로 평면 회전·이동을 적합하고 similarity가 참이면 양의 균일 배율도 추정합니다. 예를 들어 (0,0), (1,0)이 (2,3), (3,3)으로 대응하면 이동 (2,3)의 단순 사례입니다. 같은 인덱스가 같은 점을 가리키는지 확인하십시오.

항목확인된 역할
source두 개 이상인 원본 점입니다.
target원본과 일대일로 대응하는 목표 점입니다.
similarity참이면 하나의 양의 균일 배율도 추정합니다.
반환원본에서 목표로 가는 변환입니다.
