MapPoint

Method · 선언 타입 ZVision.GapPolar

C#
static System.ValueTuple<System.Double, System.Double> MapPoint(ZVision.GapPolarOptions options, System.Double x, System.Double y, System.Boolean toOutput = false, System.UInt32 revolution = 0)

입출력 점을 변환합니다. 중심의 각도는 선택 회전의 시작 각으로 대표합니다.

인자

options: 극좌표 설정입니다.

x: 입력 점 x입니다.

y: 입력 점 y입니다.

toOutput: 참이면 직교에서 극좌표 출력으로 변환합니다.

revolution: 출력 변환의 회전 번호입니다.

반환: 변환된 x와 y입니다.

이 호출의 입력과 객체 맥락

options와 점 x, y를 사용해 극좌표 출력과 직교 좌표 사이의 점을 변환합니다. toOutput=true는 직교에서 극좌표 출력 방향이고 revolution은 해당 출력 변환의 회전 분기입니다. 중심의 각도는 선택한 회전의 시작 각으로 대표됩니다. 반환은 두 double 값으로 이 호출은 영상 픽셀을 변환하거나 이미지 핸들을 만들지 않습니다.
