조건을 평가해 원본 결과의 인덱스를 순서대로 반환합니다.

반환: 0부터 시작하는 원본 결과 인덱스 배열입니다.

Run의 사용과 결과 해석

계획에 설정한 필터를 실행해 선택 결과를 얻습니다. 이전에 설정한 조건을 확인한 뒤 결과 항목의 수와 개별 측정값을 읽습니다. 분석이 끝난 결과를 기준으로 선택 계획을 만들고 조건을 추가한 뒤 실행 결과를 확인합니다. 조건의 포함 여부와 결과 목록의 순서를 구분해야 하며, 소유한 계획과 실행 결과는 각각의 수명을 따릅니다.

사용 순서와 결과 판독

AdvancedBlobQuery.Run은 선택 계획의 조건을 평가하고 원본 AdvancedBlobResult에서 선택된 항목의 0 기반 인덱스를 순서대로 담은 UInt64 배열을 반환합니다. 새 Blob 측정값을 배열에 담는 호출이 아니므로 각 성분의 면적이나 중심이 필요하면 그 인덱스로 동일한 원본 결과를 조회합니다.

예를 들어 원본에 세 항목이 있고 조건에 맞는 인덱스가 0과 2라면 반환 배열은 그 원본 위치를 연결하는 데 사용합니다. 라벨 영상의 값 0은 배경이므로 원본 결과의 인덱스 0과 같은 의미가 아닙니다. Where의 include 설정은 조건을 만족한 항목을 포함할지 제외할지 결정하며 선택 배열의 순서와도 구분합니다.

구현은 임시 선택 핸들에서 인덱스를 관리형 배열로 복사한 뒤 그 임시 핸들을 해제합니다. 따라서 반환 배열은 계획 객체를 빌리는 슬라이스가 아닙니다. 다만 배열의 숫자를 해석하려면 해당 원본 분석 결과와 조건을 함께 보관해야 합니다. 계획과 원본 결과는 각각 사용 후 Dispose합니다.
