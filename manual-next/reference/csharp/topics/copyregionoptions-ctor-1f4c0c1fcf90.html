CopyRegionOptions(System.UInt64 sourceX, System.UInt64 sourceY, System.UInt64 width, System.UInt64 height, System.Int64 destinationX, System.Int64 destinationY, System.Boolean clip = false)

설정을 생성합니다. 유효 범위는 실행 시 검증합니다.

인자

sourceX: 원본 ROI 상대 x 좌표입니다.

sourceY: 원본 ROI 상대 y 좌표입니다.

width: 복사 너비입니다.

height: 복사 높이입니다.

destinationX: 목적 ROI 상대 x 좌표입니다.

destinationY: 목적 ROI 상대 y 좌표입니다.

clip: 목적 영상 밖을 잘라낼지 지정합니다.

ctor의 사용과 결과 해석

sourceX와 sourceY는 원본 ROI 상대 좌표이고 destinationX와 destinationY는 목적 ROI 상대 좌표입니다. 두 좌표는 같은 원점이라고 가정하지 않습니다. 생성자에서 설정 값을 담는 일과 실제 영상 연산을 실행하는 일은 별개입니다. 각 인자의 좌표계와 단위를 지정하고 실행 시 적용되는 유효 범위 및 관련 옵션을 확인합니다.
