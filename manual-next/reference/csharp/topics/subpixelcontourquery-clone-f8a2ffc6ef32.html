Clone의 사용과 결과 해석

서브픽셀 윤곽 쿼리를 복제해 후속 조건을 따로 적용합니다. 두 결과를 비교할 때 입력 영상과 좌표 원점이 같았는지 먼저 확인합니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.

소수 윤곽 계획 복제

Clone은 SubpixelContourQuery 계획의 독립 핸들을 만듭니다. 원본과 복제본은 각각 Dispose해야 합니다. 복제는 아직 픽셀의 등치선을 계산하지 않으며, 각 계획의 Execute가 실제 경로 결과를 만듭니다.

항목의미와 사용
원본 계획기존 지연 윤곽 계획
Clone독립 쿼리 핸들
Execute각 계획의 실제 계산
결과독립 소수 윤곽 스냅샷
좌표ROI 로컬 픽셀 기준
수명원본·복제 계획을 각각 Dispose

동일한 시작 계획을 두 실행에 사용하면 설정이나 입력 조건에 따른 경로를 분리해 비교할 수 있습니다. 소수 점은 ROI 로컬 좌표이고 각 경로의 점 순서와 닫힘을 유지해야 합니다. 표시용 반올림과 원래 보간 좌표의 수치를 구분합니다.
