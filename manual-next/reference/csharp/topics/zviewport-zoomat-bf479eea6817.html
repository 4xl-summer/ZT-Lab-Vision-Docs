Method · 선언 타입 ZVision.Display.ZViewport

C#
void ZoomAt(System.Double scale, ZVision.Display.ZDisplayPoint anchorScreen)

화면 앵커 아래 영상 위치를 유지하며 절대 배율을 설정합니다.

인자

scale: 설정할 양의 배율이며 허용 범위로 제한됩니다.

anchorScreen: 고정할 화면 좌표입니다.

관련 입력의 확인된 조건

anchorScreen.X: 점의 가로 좌표입니다.

anchorScreen.Y: 점의 세로 좌표입니다.

사용 순서와 결과 해석

유한한 양의 절대 배율을 설정하고 앵커 화면점 아래의 영상 위치가 변하지 않도록 이동량을 조정합니다. 배율은 1/16777216부터 64까지로 제한됩니다. 예를 들어 이전 배율이 1이고 새 배율이 2이면 앵커를 기준으로 확대하며 화면 전체 원점을 고정하는 것이 아닙니다. PanBy와 함께 화면 탐색에 사용합니다.

입력별 확인

입력의미
scale설정할 양의 배율이며 허용 범위로 제한됩니다.
anchorScreen고정할 화면 좌표입니다.
