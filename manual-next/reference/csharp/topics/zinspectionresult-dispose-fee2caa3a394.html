단계 영상 해제

결과가 보유한 단계 영상 임대를 해제합니다. 이미 해제된 결과에 다시 호출하면 그대로 반환하며, 이후 AcquireStage는 ObjectDisposedException입니다.

이전에 별도로 획득한 단계 영상이나 표시 프레임은 해당 객체의 소유 규칙에 따라 별도로 해제합니다. 복사된 Blob 및 Metric 목록과 영상 핸들의 수명도 구별합니다.

검사 결과의 단계 임대 해제

Dispose는 ZInspectionResult가 보유한 단계 영상 임대를 해제합니다. 결과가 이미 해제된 경우에는 그대로 반환하며, 닫힌 결과에서 AcquireStage를 다시 호출하면 ObjectDisposedException입니다. 결과 객체가 보유한 단계와 호출자가 별도로 획득한 영상을 구분해야 합니다.

생성자는 전달된 단계 영상마다 Share를 호출해 자체 임대를 만들고, Blob과 Metric은 읽기 전용 배열로 복사합니다. 공유 도중 실패하면 이미 얻은 임대를 정리합니다. 따라서 입력 단계의 원래 영상과 결과가 보유하는 영상은 같은 해제 책임이 아닙니다.

AcquireStage로 얻은 ZImage와 CreateDisplayFrame으로 만든 프레임도 호출자가 별도로 Dispose합니다. 예를 들어 Threshold 영상과 Close 프레임을 획득했다면 결과 하나를 닫는 것 외에 두 획득 객체를 각각 정리해야 합니다. 복사된 통계와 목록은 영상 핸들이 아닙니다.

화면에서 비동기 요청을 처리한다면 FrameId와 RecipeVersion을 확인해 결과가 현재 입력에 대응하는지 판독합니다. Threshold와 Close 프레임에는 선택된 Blob의 로컬 경계가 표시됩니다. 결과의 해제는 해당 요청을 새로 실행하거나 판정을 저장하는 동작이 아닙니다.
