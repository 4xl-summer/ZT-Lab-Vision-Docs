PointLineDistance

Method · 선언 타입 ZVision.Metrology

static System.Double PointLineDistance(ZVision.Point2 point, ZVision.LineFit line)

점에서 무한 직선까지 수직 거리를 계산합니다.

인자

point: 변환 또는 측정할 점입니다.

line: 측정할 무한 직선입니다.

반환: 입력 좌표와 같은 단위의 계산값입니다.

관련 입력의 확인된 조건

point.X: 영역의 로컬 x 좌표입니다.

point.Y: 영역의 로컬 y 좌표입니다.

계산과 결과 해석

한 점에서 무한 직선까지의 최단 수직 거리를 반환합니다. line은 한 점과 0이 아닌 방향을 가진 LineFit이며 방향의 길이는 내부 계산에서 정규화됩니다. 예를 들어 x축을 지나는 수평선과 점 (3,4)의 거리는 4이며 선 위에 선택한 기준점이 달라져도 같은 무한선이면 같은 거리가 나옵니다. 이 결과는 음수가 아닌 좌표 단위 거리로, 유향 선의 왼쪽과 오른쪽을 구별하는 부호 있는 함수와 역할이 다릅니다. 이미지에서 찾은 점과 선이라면 같은 ROI 기준 픽셀 좌표인지 확인하고, 세계 거리로 쓰려면 물리 좌표계에서 별도로 계산하십시오. 방향이 0이거나 좌표가 비유한 경우에는 정상적인 거리 0이 아니라 입력 오류로 다룹니다. 무한선의 방향을 반대로 바꾸어도 가장 가까운 점까지의 거리는 변하지 않습니다. 점이 선 위에 있으면 유효 결과가 0이므로 계산 실패를 0으로 치환해서는 안 됩니다. 선분 끝까지의 최소 거리가 목적이라면 끝점 범위를 별도로 고려해야 합니다. 점의 위치가 (3,0)이면 예시의 수평선 위에 있어 거리는 0입니다. 점이 (3,-4)라면 거리는 여전히 4이므로 이 함수만으로는 선의 어느 편인지 구분하지 못합니다. 좌우 판정에는 부호를 보존하는 별도 연산이 필요합니다.
