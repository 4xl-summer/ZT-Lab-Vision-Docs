static ZVision.InputTransfer Gamma(System.Double exponent)

지정 지수의 전달 함수입니다.

인자

exponent: 커널에서 검증할 감마 지수입니다.

반환: 감마 전달 함수입니다.

사용과 결과 해석

지정한 지수의 감마 전달 함수를 구성합니다. 반환한 설정은 색 변환의 입력 전달 특성으로 사용하며 지수의 유효성은 커널에서 검사합니다.

감마는 픽셀의 색 성분을 선형 광량으로 해석하는 방식에 영향을 줍니다. 입력 데이터가 실제로 사용하는 전달 특성에 맞는 지수를 지정하고 왕복 변환에도 같은 설정을 유지하십시오.

감마 전달 함수의 사용

Gamma는 색 변환의 입력 전달 특성으로 사용할 지수를 담는 설정을 만듭니다. 변환 커널은 지수가 유한한 양수인지 검사합니다. 이 지수는 RGB 채널을 선형 광량으로 해석할 때 사용하며, Lab 백색점과 별개인 설정이므로 모델이나 영상의 실제 인코딩에 맞춰 선택해야 합니다.

정규화된 입력 성분 v에 감마 지수 g를 적용할 때 선형 값은 v의 g제곱입니다. 예를 들어 v=0.5, g=2라면 선형 값은 0.25입니다. 역방향 RGB 변환에서는 역지수를 사용합니다. 정수 출력은 양자화나 색역 제한이 있을 수 있으므로 왕복 결과를 완전히 동일하다고 가정하지 마십시오.
