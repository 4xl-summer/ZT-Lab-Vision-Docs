C#
static ZVision.Affine2 Rotation(System.Double angle)

원점 중심 회전 변환을 만듭니다. 영상 좌표에서 양의 각도는 시계 방향입니다.

인자

angle: 회전 또는 주축 각도(라디안)입니다.

반환: 계산된 결과입니다.

이 호출의 입력과 객체 맥락

입력 angle은 유한한 라디안이고 회전 중심은 좌표 원점입니다. 영상 좌표에서 x는 오른쪽, y는 아래이므로 양의 각도는 시계 방향으로 보입니다. 예를 들어 π/2 회전은 점 (1, 0)을 이론적으로 (0, 1) 방향으로 보냅니다. 실제 계산 결과는 부동소수 표현이므로 0 근처의 작은 오차가 생길 수 있습니다. 원점이 아닌 점을 중심으로 회전하려면 먼저 그 중심을 원점으로 이동하고 회전한 다음 다시 이동하는 변환을 올바른 순서로 합성해야 합니다.

사용 순서와 판독

회전 중심은 좌표 원점입니다. 예를 들어 영상 좌표에서 양의 π/2를 (1,0)에 적용하면 이론적으로 (0,1) 방향이며 아래쪽이 양의 y이므로 화면에서는 시계 방향으로 보입니다.

원점이 아닌 중심 C 주위를 회전하려면 C를 빼서 원점으로 옮기고 회전한 뒤 C를 다시 더합니다. 예를 들어 중심 (10,20)을 기준으로 한 점은 중심에서의 상대 좌표로 먼저 계산해야 합니다. 회전값 생성 자체는 영상 픽셀을 재배치하지 않습니다.
