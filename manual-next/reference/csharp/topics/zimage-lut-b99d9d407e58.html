ZVision.ZImage Lut(System.Byte[] table)

Gray8 값에 조회 테이블을 적용합니다.

인자

table: Gray8 입력 값별 출력 값을 담은 조회 테이블.

반환: 호출자가 해제해야 하는 독립 이미지입니다.

호출에 필요한 입력

Gray8 픽셀을 조회표를 통해 변환합니다.

인자선언된 형식확인할 내용
tableSystem.Byte[]Gray8 입력 값별 출력 값을 담은 조회 테이블.

결과와 사용 순서

호출자가 해제해야 하는 독립 이미지입니다.

입력과 결과 해석

룩업 테이블로 입력 값을 대응 출력 값에 매핑합니다. 예를 들어 입력 값 10의 결과를 알고 싶다면 테이블의 10번 항목을 확인합니다. 영상 형식에 필요한 테이블 크기와 출력 범위도 확인하세요.
