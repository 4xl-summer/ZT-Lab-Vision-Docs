static ZVision.JointBundleResult Fit(ZVision.GraphObservation[] observations, ZVision.JointObservationFrame[] tags, System.UInt64[] cameraFrames, System.UInt64[] boardFrames, ZVision.LensModel[] lenses, System.Double[] cameras, System.Double[] boards, ZVision.IntrinsicMask[] masks, ZVision.JointBundleOptions options)

프레임 메타데이터를 검증한 뒤 공유 pose와 렌즈를 적합합니다.

인자

observations: 연결된 관측입니다.

tags: 관측별 프레임과 단위입니다.

cameraFrames: 카메라 인덱스별 프레임 ID입니다.

boardFrames: 보드 인덱스별 프레임 ID입니다.

lenses: 초기 렌즈입니다.

cameras: 초기 카메라 pose입니다.

boards: 초기 보드 pose입니다.

masks: 내부 계수 선택 비트입니다.

options: pose 선택과 작업 제한입니다.

반환: 공동 정련 결과입니다.

관련 입력의 확인된 조건

options.Damping: 양의 LM 감쇠입니다.

options.GradientTolerance: 양의 기울기 한도입니다.

options.CameraPoseMask: 카메라별 pose 선택 비트입니다. 0번은 항상 고정입니다.

options.BoardPoseMask: 보드별 pose 선택 비트입니다.

options.MaxWork: 보수적 작업 상한입니다.

options.Unit: 공통 길이 단위입니다.

JointBundleResult.Diagnostics: 내부 계수 블록 진단입니다.

JointBundleResult.AcceptedPoseSteps: 수용된 pose 갱신입니다.

JointBundleResult.AcceptedIntrinsicSteps: 수용된 렌즈 갱신입니다.

JointBundleResult.Converged: 지역 수렴 여부입니다.

JointBundleResult.Exhausted: 반복 상한 도달 여부입니다.

JointBundleResult.RankDeficient: 렌즈 블록 rank 부족 여부입니다.

적용과 결과 판독

관측마다 연결된 프레임과 단위 메타데이터를 검증한 다음 공유 pose와 렌즈를 적합합니다. 관측 태그가 cameraFrames 및 boardFrames의 인덱스와 올바르게 대응하는지 확인하십시오. 단위가 다른 보드 좌표를 섞으면 유효한 숫자라도 다른 물리 문제를 풀게 됩니다. 결과 진단과 별도 보류 관측을 확인합니다.

입력확인된 역할
observations연결된 관측입니다.
tags관측별 프레임과 단위입니다.
cameraFrames카메라 인덱스별 프레임 ID입니다.
boardFrames보드 인덱스별 프레임 ID입니다.
lenses초기 렌즈입니다.
cameras초기 카메라 pose입니다.
boards초기 보드 pose입니다.
masks내부 계수 선택 비트입니다.
