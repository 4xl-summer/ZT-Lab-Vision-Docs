DenseRegistrationOptions()

기본 설정을 생성합니다.

이 호출의 입력과 객체 맥락

DenseRegistrationOptions.Levels: 피라미드 층 수입니다.

DenseRegistrationOptions.Warps: 층당 워핑 횟수입니다.

DenseRegistrationOptions.Iterations: 워핑당 반복 상한입니다.

DenseRegistrationOptions.Smoothness: 흐름의 평활화 계수입니다.

DenseRegistrationOptions.RobustEpsilon: 강건 광도 가중치 안정화 상수입니다.

DenseRegistrationOptions.Tolerance: 마지막 워핑 내부 반복 증분 수렴 기준입니다.

DenseRegistrationOptions.MaxDisplacement: 원본 좌표의 변위 크기 상한입니다.

DenseRegistrationOptions.MaxWork: 보수적 픽셀 반복 작업 상한입니다.

사용 순서와 결과 해석

기본 생성자는 밀집 정합 설정을 만들며 영상을 즉시 처리하지 않습니다. Levels는 피라미드 층 수, Warps는 각 층의 워핑 횟수, Iterations는 워핑당 반복 상한입니다. 이 셋은 서로 다른 반복 범위이므로 한 값만으로 전체 작업량을 판단하지 마세요.

기본값은 Levels=1, Warps=3, Iterations=80입니다. Smoothness는 흐름 평활 계수이고 RobustEpsilon은 광도 가중치의 안정화 상수입니다. Tolerance는 반복 증분에 대한 픽셀 기준, MaxDisplacement는 원본 좌표에서 허용할 변위 크기의 픽셀 상한입니다.

MaxWork는 보수적 작업 상한입니다. 추정 작업량은 픽셀 수×층 수×워프 수×(반복 수+3)이며 이 값이 상한을 넘으면 오류입니다. 예를 들어 영상 크기가 같아도 층이나 워프 수를 늘리면 예산 요구가 커집니다. 실행 뒤에는 설정의 상한과 별개로 결과의 수렴·유효 위치를 확인하세요.

예를 들어 100×100픽셀 영상에 기본 Levels=1, Warps=3, Iterations=80을 대입한 보수적 추정은 10000×1×3×83으로 2490000입니다. 기본 MaxWork 1000000을 초과하므로 다른 조건을 검토해야 합니다. 이 계산은 실제 소요 시간이나 실제 반복 횟수의 측정치가 아니라 사전에 검사하는 작업 상한입니다.

예를 들어 MaxDisplacement를 3픽셀로 둘 때 이 값은 변위 크기의 허용 상한이고 Tolerance 기본 1e-8픽셀은 반복 증분의 수렴 비교 기준입니다. 두 숫자는 모두 픽셀 단위지만 서로 다른 판단에 사용됩니다. 더 많은 반복을 허용하면 보수적 작업 추정이 커질 수 있으므로 MaxWork를 함께 살펴보세요.
