void Dispose()

소유 모델을 해제합니다.

사용을 마치는 순서

학습된 고급 NCC 또는 형상 모델이 보유한 자원을 해제합니다. TrainNcc 또는 TrainShape 계열로 모델을 얻은 뒤 필요한 Find와 진단을 마치고 해제합니다. 모델을 다시 검색에 쓰려면 새 모델을 학습하거나 해당 모델의 지원되는 복원 경로를 사용합니다.

사용 순서

호출역할
TrainNcc / TrainShape템플릿에서 모델 생성
Find영상의 후보와 종료 진단 획득
Dispose모델의 네이티브 자원 정리

모델 종류와 검색의 연결

이 모델은 NCC 템플릿 또는 형상 특징을 학습해 보유합니다. NCC는 선택된 템플릿 표본의 밝기 패턴을 사용하고 형상 경로는 기울기 방향 특징을 사용하므로 어떤 Train 계열로 생성했는지 결과와 함께 기록합니다. 더 이상 모델이 필요한 검색과 진단이 없을 때 Dispose합니다.

Find 결과를 해석할 때 모델 기준점과 검색 ROI의 좌표, 격자와 후보 예산을 함께 확인합니다. 학습 모델을 해제하는 호출은 저장된 설정을 자동으로 기록하지 않습니다. 다시 검색해야 한다면 해당 모델 종류가 제공하는 학습 또는 복원 절차로 유효한 모델을 준비합니다.
