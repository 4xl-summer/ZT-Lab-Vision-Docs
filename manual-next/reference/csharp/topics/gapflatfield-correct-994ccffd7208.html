Correct

Method · 선언 타입 ZVision.GapFlatField

C#
static ZVision.ZImage Correct(ZVision.ZImage image, ZVision.ZImage gainMap = null, ZVision.ZImage offsetMap = null, System.Double globalGain = 1, System.Double globalOffset = 0, ZVision.PixelFormat outputFormat = ZVision.PixelFormat.GrayF32)

입력×전역 gain×gain map+전역 offset+offset map을 계산합니다.

인자

image: Gray8/16/F32/F64 입력입니다.

gainMap: 입력과 같은 크기·원점의 양수 회색 gain 영상 또는 null입니다.

offsetMap: 입력과 같은 크기·원점의 회색 offset 영상 또는 null입니다.

globalGain: 양의 유한 배율입니다.

globalOffset: 유한한 전역 offset입니다.

outputFormat: Gray8/16/F32/F64 출력 형식입니다.

반환: 입력 원점을 보존하는 독립 영상입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

outputFormat.Gray8: 8비트 부호 없는 회색 형식입니다.

outputFormat.Gray16: 16비트 부호 없는 회색 형식입니다.

outputFormat.GrayF32: 32비트 부동소수 회색 형식입니다.

outputFormat.Rgba8: 8비트 RGBA 형식입니다.

outputFormat.Bgra8: 8비트 BGRA 형식입니다.
