Create의 사용과 결과 해석

분석 컨텍스트를 만든 뒤 연결성과 인덱스 방식을 지정합니다. 아직 계산하지 않은 설정과 계산이 완료된 결과를 혼동하지 않고 결과를 조회하기 전에 계산 단계를 수행합니다. 연결 성분 분석의 입력 영상과 연결성, 인덱스 방식을 먼저 설정하고 계산한 후 결과를 조회합니다. 4연결과 8연결은 대각선으로만 닿은 전경의 그룹 수를 다르게 만들 수 있습니다.

사용 순서와 결과 보관

Create는 연결 성분 분석을 위한 BlobContext를 생성합니다. 기본 연결성은 8이고 결과는 라벨이 아닌 0 기반 인덱스로 조회하는 설정입니다. 이 호출은 분석 영상을 받지 않으므로 성분을 아직 계산하지 않습니다. 반환된 context는 호출자가 해제할 소유 객체입니다.

계산 전에 SetConnectivity로 4 또는 8 연결을 선택하고 필요한 경우 SetIndexMode로 결과 조회 방식을 정합니다. 대각선으로만 닿은 두 전경 픽셀은 8연결이면 한 성분으로 연결될 수 있고 4연결이면 직접 연결되지 않습니다. 입력 영상과 연결 방식을 함께 기록해야 결과 개수를 해석할 수 있습니다.

Calculate에 Gray8 영상과 작업 예산을 전달하면 계산된 독립 AdvancedBlobResult를 얻습니다. 이후 Get은 설정된 방식으로 현재 결과의 라벨과 면적을 복사합니다. 컨텍스트를 해제하는 것과 독립 결과를 해제하는 것은 각각의 소유 범위이며, 사용이 끝난 두 객체를 따로 정리합니다.
