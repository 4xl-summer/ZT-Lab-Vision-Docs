InspectionRect(System.UInt64 x, System.UInt64 y, System.UInt64 width, System.UInt64 height)

영상 로컬 좌표의 사각형으로 끝 좌표는 포함하지 않습니다. 유효 범위와 양의 크기는 연산 시 검사합니다.

인자

x: 로컬 왼쪽 x 좌표입니다.

y: 로컬 위쪽 y 좌표입니다.

width: 너비입니다.

height: 높이입니다.

설정과 사용 흐름

영상 로컬 왼쪽 위와 너비·높이로 half-open 사각형을 나타냅니다. 끝 좌표는 포함하지 않으며 양의 크기와 영상 범위는 연산 시 검사합니다.

예를 들어 (2,3,4,2)는 x=2,3,4,5와 y=3,4를 포함합니다. 글로벌 ROI 원점과 로컬 좌표를 혼동하지 말고 입력 영상 기준으로 지정하십시오.

영상 로컬 사각형

InspectionRect는 x, y, width, height를 ulong 필드에 저장하는 값입니다. x와 y는 영상 로컬의 왼쪽 위 좌표, 너비와 높이는 픽셀 수이며 끝 좌표는 포함하지 않습니다. 생성자는 필드를 저장하고 유효한 영상 범위와 양의 크기는 연산 시 검사합니다.

예를 들어 x=2, y=3, width=4, height=2이면 x 방향으로 2,3,4,5 네 열과 y 방향으로 3,4 두 행을 포함합니다. 오른쪽 끝 6과 아래 끝 5는 포함하지 않으므로 전체 크기는 4×2=8픽셀입니다.

이 사각형을 ROI 영상에 적용할 때는 로컬 좌표와 전체 프레임 원점을 구분합니다. ROI의 원점이 (100,50)이라면 로컬 왼쪽 위 (2,3)의 글로벌 위치는 단순 이동으로 (102,53)입니다. 영상 영역 밖이거나 크기가 0인 설정은 사용하는 연산에서 오류가 될 수 있습니다.

사각형 값 생성은 이미지 자르기나 복사를 실행하지 않습니다. 실제 ROI 연산 후 반환된 영상의 소유 관계를 따로 확인하고, 화면의 확대·패닝 좌표를 영상 좌표로 변환한 뒤 사각형을 구성합니다.
