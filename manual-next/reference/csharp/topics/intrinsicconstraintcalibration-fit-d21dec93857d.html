Method · 선언 타입 ZVision.IntrinsicConstraintCalibration

C#
static ZVision.IntrinsicConstraintResult Fit(ZVision.GraphObservation[] observations, ZVision.LensModel[] lenses, System.Double[] cameras, System.Double[] boards, ZVision.IntrinsicMask[] masks, ZVision.IntrinsicOptions options)

모든 자세를 고정하고 선택된 내부 계수만 지역 LM으로 정련합니다.

인자

observations: 연결된 카메라·보드 관측입니다.

lenses: 카메라별 초기 Brown 렌즈입니다.

cameras: 카메라별 6개 고정 pose입니다.

boards: 보드별 6개 고정 pose입니다.

masks: 카메라별 내부 계수 선택 비트입니다.

options: 반복·감쇠·기울기·작업 제한입니다.

반환: 렌즈, 카메라별 진단 및 전체 오차입니다.

관련 입력의 확인된 조건

options.MaxIterations: 최대 반복 횟수입니다.

options.Damping: 초기 양의 LM 감쇠입니다.

options.GradientTolerance: 정규화된 기울기 수렴 한도입니다.

options.MaxWork: 보수적인 투영 작업 상한입니다.

IntrinsicConstraintResult.Lenses: 카메라별 결과 렌즈입니다.

IntrinsicConstraintResult.Diagnostics: 카메라별 종료 진단입니다.

IntrinsicConstraintResult.InitialRms: 초기 전체 오차입니다.

IntrinsicConstraintResult.FinalRms: 최종 전체 오차입니다.

IntrinsicConstraintResult.Work: 사전 계산된 보수 작업 상한입니다.

적용과 결과 판독

카메라·보드 자세를 고정한 채 마스크로 선택한 내부 계수만 지역 LM 방식으로 정련합니다. 입력 관측의 카메라와 보드 인덱스, 초기 렌즈와 고정 자세가 서로 맞아야 합니다. 결과의 카메라별 진단과 전체 오차를 함께 보고 선택하지 않은 계수가 정확하다고 단정하지 마십시오.

입력확인된 역할
observations연결된 카메라·보드 관측입니다.
lenses카메라별 초기 Brown 렌즈입니다.
cameras카메라별 6개 고정 pose입니다.
boards보드별 6개 고정 pose입니다.
masks카메라별 내부 계수 선택 비트입니다.
options반복·감쇠·기울기·작업 제한입니다.
