동일한 지연 계획을 독립 핸들로 복제합니다.

이 호출의 입력과 객체 맥락

같은 지연 차분 계획을 독립 핸들로 복제합니다. Clone 자체는 계획을 실행하지 않고 각 쿼리는 별도로 Dispose합니다. 실행 결과 및 별도로 획득한 차분 영상의 수명도 복제된 쿼리와 구분하세요.

계획 복제와 실제 실행

DifferenceQuery는 차분 연산을 실행하기 전에 구성한 지연 계획입니다. Clone은 그 계획의 별도 소유 핸들을 만들며 실제 차분 점수나 마스크를 계산하지 않습니다. 원본 쿼리와 복제본은 각각 사용 후 Dispose해야 합니다.

실제 결과를 얻으려면 계획의 Execute를 호출합니다. 반환 QueryResourceExecution<DifferenceResult>에서 AcquireOutput으로 차분 결과를 얻고, 그 결과에서 부호 차이·점수·마스크 영상을 확인합니다. 이 출력들은 같은 차분 작업의 서로 다른 양이므로 점수 영상만 보고 부호나 판정 마스크를 대체하지 않습니다.

쿼리 핸들, 실행, AcquireOutput으로 얻은 DifferenceResult와 그 결과에서 취득한 영상들은 각각의 소유 수명을 가집니다. 필요한 출력과 캡처를 열린 실행에서 확보하고 각 객체를 사용 후 정리합니다. 동일 계획의 복제는 계산 성공이나 특정 결과값을 보장하는 과정이 아닙니다.

결과를 비교할 때는 차분을 계산한 기준 영상과 검사 영상의 순서를 보관해야 부호 차이의 방향을 해석할 수 있습니다. Clone은 해당 순서를 바꾸거나 새로운 영상으로 자동 대체하지 않습니다. 두 계획을 각각 실행했다면 반환된 실행 결과도 각각 관리하며, 출력 취득 전과 취득 후의 핸들을 혼동하지 않습니다.

비교할 때 확인

Clone으로 두 핸들을 갖게 되어도 각 핸들의 실행 결과가 이미 만들어진 것은 아닙니다. 첫 쿼리의 Execute에서 얻은 실행을 정리하는 일과 두 번째 쿼리의 계획을 정리하는 일도 별개입니다. 각 실행에서 얻은 점수 영상과 마스크를 어떤 계획의 결과인지 연결해 보관합니다.
