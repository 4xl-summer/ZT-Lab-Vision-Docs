AdvancedRegistrationOptions()

기본 지역 등록 설정을 만듭니다.

이 호출의 입력과 객체 맥락

AdvancedRegistrationOptions.Projective: 원근 변환을 사용합니다. false는 affine입니다.

AdvancedRegistrationOptions.MeanSquaredError: 평균 제곱 오차를 사용합니다. false는 NCC입니다.

AdvancedRegistrationOptions.Initial: 마지막 계수 1을 생략한 행 우선 초기 행렬 8개입니다.

AdvancedRegistrationOptions.Steps: 각 계수의 초기 좌표 탐색 간격 8개입니다.

AdvancedRegistrationOptions.IterationsPerLevel: 단계별 최대 반복 횟수입니다.

AdvancedRegistrationOptions.MinCoverage: 최소 유효 표본 비율입니다.

사용 순서와 결과 해석

기본 생성자는 지역 영상 정합을 위한 설정 객체를 만듭니다. 초기 Projective는 false여서 affine을 선택하고 MeanSquaredError는 true입니다. 생성 즉시 영상이 정합되는 것은 아니며, 실제 source·reference 영상과 이 설정을 정합 호출에 전달해야 합니다.

Initial은 마지막 계수 1을 생략한 행 우선 3×3 변환의 앞 8개 값입니다. 기본값 [1,0,0,0,1,0,0,0]은 항등 행렬에 해당합니다. Steps는 각 계수의 초기 탐색 간격이고 기본 [0,0,1,0,0,1,0,0]입니다. 기준 로컬에서 소스 로컬로 가는 방향을 바꾸어 읽지 마세요.

Levels는 간격을 줄이는 단계 수로 기본 3, IterationsPerLevel은 단계별 상한으로 기본 10입니다. MinCoverage 기본 1은 기준 격자의 유효 표본 비율 하한을 나타냅니다. 반복 상한이 실제 반복 완료나 정합 성공을 보증하지 않으므로 결과 Found와 점수·유효 마스크도 확인하세요.

예를 들어 초기 행렬의 이동 항을 바꾸면 기준 영상에서 소스 영상으로 탐색을 시작할 위치가 달라집니다. Steps의 이동 항 간격을 0으로 두면 해당 계수의 초기 탐색 간격도 0이라는 점을 설정에서 확인할 수 있습니다. 비교 실험에서는 변환 모드와 점수 방식, 초기값과 단계 수를 함께 보관해야 결과 차이를 해석할 수 있습니다.
