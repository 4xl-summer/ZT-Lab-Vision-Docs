ClassificationScores

Method · 선언 타입 ZVision.AdvancedAiPostprocess

C#
static System.Single[] ClassificationScores(System.Single[] scores, System.Boolean probabilities = false)

로짓에 softmax를 적용하거나 확률을 검증합니다.

인자

scores: 클래스 점수입니다.

probabilities: 입력이 확률이면 참입니다.

반환: 정규화 확률입니다.

사용과 결과 판독

입력이 확률이면 해당 조건을 검증하고, 로짓이면 softmax로 정규화합니다. 확률과 로짓은 같은 숫자라도 다른 해석이므로 probabilities를 입력 자료에 맞춰 지정하십시오. 반환된 각 위치는 원래 클래스 순서를 따릅니다.

항목확인된 역할
scores클래스 점수입니다.
probabilities입력이 확률이면 참입니다.
반환정규화 확률입니다.

로짓 두 값이 같으면 softmax 결과도 서로 같은 비율입니다. 입력이 이미 확률인지 로짓인지 잘못 지정하면 정규화가 의도와 달라질 수 있습니다. 반환 배열의 순서와 클래스 이름의 대응도 따로 보관하십시오.
