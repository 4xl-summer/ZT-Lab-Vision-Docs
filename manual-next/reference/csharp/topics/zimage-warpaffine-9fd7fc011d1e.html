Method · 선언 타입 ZVision.ZImage

C#
ZVision.ZImage WarpAffine(ZVision.Affine2 matrix, System.Int32 width, System.Int32 height, ZVision.Interpolation interpolation, System.Double border)

원본 로컬에서 출력 로컬로의 아핀 변환을 역매핑해 리샘플링합니다. 14개 픽셀 형식을 지원합니다.

인자

matrix: 원본 로컬 픽셀에서 출력 로컬 픽셀로의 변환입니다.

width: 출력 폭 또는 스트립 폭입니다.

height: 양의 출력 높이(픽셀)입니다.

interpolation: 표본 보간 방식입니다.

border: 영역 밖 표본에 사용할 유한 상수 강도입니다.

반환: 원본과 독립된 소유 영상입니다. 사용 후 Dispose해야 합니다. Warp 출력 원점은 (0,0)입니다.

관련 입력의 확인된 조건

matrix.A: x 출력의 x 계수입니다.

matrix.B: x 출력의 y 계수입니다.

matrix.Tx: x 출력의 이동량입니다.

matrix.C: y 출력의 x 계수입니다.

matrix.D: y 출력의 y 계수입니다.

matrix.Ty: y 출력의 이동량입니다.

호출에 필요한 입력

기하 변환을 적용합니다.

인자선언된 형식확인할 내용
matrixZVision.Affine2원본 로컬 픽셀에서 출력 로컬 픽셀로의 변환입니다.
widthSystem.Int32출력 폭 또는 스트립 폭입니다.
heightSystem.Int32양의 출력 높이(픽셀)입니다.
interpolationZVision.Interpolation표본 보간 방식입니다.
borderSystem.Double영역 밖 표본에 사용할 유한 상수 강도입니다.

matrix의 입력 값

필드의미와 조건
ax 출력에 곱하는 입력 x 계수.
bx 출력에 곱하는 입력 y 계수.
txx 출력의 이동량.
cy 출력에 곱하는 입력 x 계수.
dy 출력에 곱하는 입력 y 계수.

interpolation의 입력 값

필드의미와 조건
BILINEAR이중선형 픽셀 보간.
NEAREST최근접 픽셀 보간.

결과와 사용 순서

원본과 독립된 소유 영상입니다. 사용 후 Dispose해야 합니다. Warp 출력 원점은 (0,0)입니다.

입력과 결과 해석

출력 픽셀에서 입력을 역으로 찾아 표본화합니다. 변환 행렬의 방향과 출력 원점, 보간 및 경계값을 함께 확인하세요. 항등 변환이라도 출력 크기가 다르면 보이는 영역은 달라집니다.
