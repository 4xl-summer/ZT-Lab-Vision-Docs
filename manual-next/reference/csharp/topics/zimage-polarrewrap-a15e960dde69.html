ZVision.ZImage PolarRewrap(ZVision.PolarSpec spec, System.UInt64 width, System.UInt64 height, System.UInt64 originX = 0, System.UInt64 originY = 0, System.UInt32 revolution = 0)

선택 회전 분기의 극좌표 영상을 직교 격자로 복원합니다.

인자

spec: 펼침에 사용한 설정입니다.

width: 출력 너비입니다.

height: 출력 높이입니다.

originX: 출력 x 원점입니다.

originY: 출력 y 원점입니다.

revolution: 선택할 회전 번호입니다.

반환: 호출자가 Dispose할 독립 영상입니다.

관련 입력의 확인된 조건

spec.CenterX: 입력 ROI 상대 중심 x 좌표입니다.

spec.CenterY: 입력 ROI 상대 중심 y 좌표입니다.

spec.StartAngle: 시작 각도 라디안입니다.

spec.EndAngle: 끝 각도 라디안입니다.

spec.StartRadius: 시작 반경 픽셀입니다.

spec.Width: 각도 방향 출력 크기입니다.

spec.Height: 반경 방향 출력 크기입니다.

spec.Interpolation: 샘플 보간 방식입니다.

spec.Border: 경계 상수 밝기입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
specZVision.PolarSpec펼침에 사용한 설정입니다.
widthSystem.UInt64출력 너비입니다.
heightSystem.UInt64출력 높이입니다.
originXSystem.UInt64출력 x 원점입니다.
originYSystem.UInt64출력 y 원점입니다.
revolutionSystem.UInt32선택할 회전 번호입니다.

spec의 입력 값

필드의미와 조건
border입력 ROI 밖에 사용하는 상수 밝기이며 기본값은 0입니다.
interpolation최근접 또는 쌍선형 샘플링이며 기본값은 최근접입니다.
center_x입력 ROI 로컬 중심의 X 좌표이며 픽셀 단위입니다.
center_y입력 ROI 로컬 중심의 Y 좌표이며 픽셀 단위입니다.
start_angle각도 축의 시작값으로 라디안 단위입니다.

결과와 사용 순서

호출자가 Dispose할 독립 영상입니다.

입력과 결과 해석

좌표를 바꾸는 처리에서는 입력과 출력의 좌표계, ROI 원점과 표본 위치를 함께 관리해야 합니다. 알려진 점을 변환 전후로 비교하면 방향과 원점 혼동을 발견하기 쉽습니다.
