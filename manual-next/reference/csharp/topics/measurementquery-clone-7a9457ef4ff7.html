ZVision.MeasurementQuery Clone()

독립적으로 해제할 수 있는 동일 계획의 복제본을 만듭니다.

반환: 사용 후 Dispose해야 하는 소유 지연 계획입니다.

사용과 결과 판독

현재 계획과 같은 처리를 수행할 독립 소유 복제본을 만듭니다. 반환 계획은 원본과 별도로 Dispose해야 합니다. 한 계획에서 두 갈래 처리를 준비할 때 복제본을 사용하고, 각 계획의 수정과 실행 결과를 같은 객체라고 가정하지 마십시오. 작업을 마친 뒤 각 실행과 계획의 소유 관계에 맞게 해제합니다.

계획을 분기할 때의 순서

예를 들어 같은 영상과 공통 측정 설정을 바탕으로 두 허용 기준을 비교하려면 공통 설정을 완료한 시점에서 계획을 복제합니다. 그 뒤 원본과 복제본에 각각 필요한 설정을 적용하고 별도로 실행합니다. 복제는 측정을 즉시 실행하거나 실행 결과까지 복사하는 호출이 아닙니다.

단계 또는 항목확인할 내용
공통 설정두 갈래에 공통인 영상과 측정 단계를 먼저 구성
복제Clone의 반환값을 두 번째 계획으로 보관
분기원본과 복제본에 필요한 조건을 각각 적용
실행두 계획의 실행 상태와 측정 결과를 따로 확인
정리각 소유 계획을 개별 Dispose

결과를 사용할 때

각 실행에서 나온 측정값과 상태는 해당 계획의 입력 조건에 연결해 기록합니다. 한쪽 계획을 Dispose했다고 다른 복제 계획도 해제된 것으로 취급하지 말고 각각의 소유 객체를 정리하세요. 실행 결과에 소유 영상이 있다면 그 영상도 자신의 계약에 따라 관리합니다.
