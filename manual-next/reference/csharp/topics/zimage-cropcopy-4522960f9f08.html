ZVision.ZImage CropCopy(System.Int32 x, System.Int32 y, System.Int32 width, System.Int32 height)

지정 사각형의 픽셀을 독립 버퍼에 복사합니다.

인자

x: 사각형 또는 점의 로컬 x 좌표(픽셀).

y: 행 인덱스 또는 로컬 y 좌표(픽셀).

width: 출력 또는 사각형의 폭(픽셀).

height: 출력 또는 사각형의 높이(픽셀).

반환: 선택 영역을 복사한 독립 이미지입니다. 사용 후 Dispose해야 합니다.

호출에 필요한 입력

로컬 사각형을 독립 저장소에 복사합니다.

인자선언된 형식확인할 내용
xSystem.Int32사각형 또는 점의 로컬 x 좌표(픽셀).
ySystem.Int32행 인덱스 또는 로컬 y 좌표(픽셀).
widthSystem.Int32출력 또는 사각형의 폭(픽셀).
heightSystem.Int32출력 또는 사각형의 높이(픽셀).

결과와 사용 순서

선택 영역을 복사한 독립 이미지입니다. 사용 후 Dispose해야 합니다.

입력과 결과 해석

지정한 영상 영역을 복사하여 사용합니다. 잘라낸 영역의 좌표와 크기를 원본의 보이는 범위에 맞추고, 복사본의 좌표를 다시 원본에 표시할 때 원점을 함께 고려하세요.
