계획을 실행하고 모멘트 결과를 독립 스냅샷으로 복사합니다.

반환: Dispose해야 하는 실행입니다. Output으로 얻은 스냅샷은 실행 해제 후에도 유효합니다.

사용과 결과 해석

모멘트 계획을 실행하고 독립 스냅샷을 담은 QueryExecution을 반환합니다. 실행 객체는 호출자가 Dispose해야 합니다.

Output으로 얻은 모멘트 스냅샷은 실행 해제 후에도 유효합니다. 계산 결과를 읽는 단계와 실행 객체의 해제 순서를 구분하십시오.

실행 객체와 독립 모멘트 스냅샷

MomentsQuery.Execute는 계획된 모멘트 계산을 실행하고 QueryExecution<MomentsResult>를 반환합니다. 이 실행 객체는 Dispose해야 합니다. Output으로 얻는 MomentsResult는 결과를 복사한 독립 스냅샷이므로 실행 객체를 해제한 후에도 이미 얻은 값을 읽을 수 있습니다.

예를 들어 실행을 만든 뒤 Output의 모멘트 목록을 변수에 보관하고 실행을 Dispose할 수 있습니다. 그다음 보관한 스냅샷을 읽는 것과 해제한 실행의 Output 속성을 새로 호출하는 것은 다릅니다. 후자는 해제된 실행에 접근하는 일이므로 필요한 스냅샷을 먼저 가져와야 합니다. 계산의 입력과 선택 영역도 결과와 함께 기록하세요.

수명과 결과 확인

QueryExecution은 이름으로 캡처한 이미지를 GetImage로 취득할 수도 있습니다. 그렇게 얻은 이미지는 독립 소유 핸들이므로 사용 후 별도로 Dispose합니다. 모멘트 스냅샷은 IDisposable 영상 핸들이 아니며, 실행·캡처 영상·원래 쿼리 계획의 수명은 각각 구분합니다. 계산 오류는 빈 모멘트 목록으로 조용히 대체하지 말고 호출 결과로 처리하세요.
