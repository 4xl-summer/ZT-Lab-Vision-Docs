void Cancel()

진행 중인 검사에 협조적 중단을 요청합니다.

사용과 결과 해석

토큰을 사용하는 진행 중인 검사에 협력적 중단을 요청합니다. 호출은 반환값이 없으며 검사 코드가 중단 지점에 도달해야 요청을 반영합니다.

요청을 보낸 직후 즉시 결과가 생성되었다고 가정하지 말고 실행 완료 또는 중단 결과를 별도로 확인하십시오. Dispose는 Cancel을 대신하지 않습니다.

사용 흐름과 판독 기준

Cancel은 취소 토큰에 중단 요청을 기록합니다. 토큰을 전달받은 진행 중 검사는 협력적으로 요청을 확인하며 중단 지점에 도달하면 취소 결과를 반환합니다. 따라서 Cancel 호출이 돌아왔다고 검사 스레드가 그 순간 이미 종료됐거나 결과 영상이 만들어졌다고 간주할 수 없습니다. 검사 호출의 완료 또는 예외를 따로 확인합니다.

이 토큰은 재설정할 수 없고 여러 동시 검사에 공유할 수 있습니다. 한 검사와 다른 검사가 같은 토큰을 사용한다면 하나의 취소 요청이 그 토큰을 사용하는 작업에 전달됩니다. 새 검사에 취소되지 않은 토큰이 필요하면 새 객체를 생성합니다. Dispose는 토큰 자원을 해제하는 동작이며 이미 시작된 검사의 취소 요청을 대신하지 않습니다.

RunControlled에서는 취소된 상태를 OperationCanceledException으로, 시간 초과를 TimeoutException으로 구분합니다. timeoutMs가 0인 경우에는 시간 제한이 없습니다. 호출 순서를 예로 들면 취소되지 않은 토큰 생성, 검사에 토큰 전달, 필요할 때 Cancel, 검사 종료 확인, 토큰 해제입니다. 이미 해제한 토큰에 Cancel을 호출하면 ObjectDisposedException입니다.
