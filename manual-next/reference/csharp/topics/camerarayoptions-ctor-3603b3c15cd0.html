CameraRayOptions(System.UInt64 maxIterations, System.Double pixelTolerance)

반복 상한과 픽셀 허용 오차를 지정합니다.

인자

maxIterations: 반복 상한이며 1부터 1024까지입니다.

pixelTolerance: 양의 픽셀 잔차 허용 오차입니다.

이 호출의 입력과 객체 맥락

카메라 광선 역산의 maxIterations와 pixelTolerance를 지정합니다. 반복 상한은 1~1024이고 허용 잔차는 양의 픽셀 값입니다. 반복 제한과 잔차 허용치는 서로 다른 조건이므로 반환 결과의 수렴 여부와 잔차를 함께 확인해야 합니다. 수렴하지 않은 방향을 성공한 세계 점으로 취급하지 마세요.

사용 흐름과 결과 판독

CameraRayOptions는 왜곡된 픽셀을 광선으로 역산할 때 사용할 반복 상한과 픽셀 잔차 허용치를 지정합니다. maxIterations는 1~1024이고 pixelTolerance는 유한한 양수입니다. 이 생성자는 옵션을 표현하는 값이며 실제 카메라 관측이나 광선 계산을 실행하지 않습니다.

반복 횟수와 오차 허용치는 각각 다른 조건입니다. 예를 들어 상한을 32로 설정하면 최대 32회까지 계산할 수 있지만 32회가 반드시 수행되거나 결과가 수렴한다는 뜻은 아닙니다. 수렴 허용치에 도달하기 전에 상한에 이를 수 있으므로 반환 결과의 수렴 상태와 픽셀 잔차를 함께 확인합니다.

픽셀 허용 오차는 수치 역투영의 잔차 기준이지 실제 렌즈의 물리 보정 오차나 밀리미터 허용치가 아닙니다. 렌즈의 초점과 주점, 왜곡 계수와 입력 픽셀이 같은 영상 좌표 기준에 있는지 확인하고, 수렴하지 않은 방향을 확정된 세계 위치로 사용하지 않습니다. 동일 조건의 재현에는 옵션 값과 렌즈 모델을 같이 보관합니다.
