Execute

Method · 선언 타입 ZVision.OcrQuery

C#
ZVision.QueryExecution<ZVision.OcrRead> Execute()

계획을 실행하고 OCR 판독 결과를 독립 스냅샷으로 복사합니다.

반환: Dispose해야 하는 실행입니다. Output으로 얻은 스냅샷은 실행 해제 후에도 유효합니다.

사용과 결과 해석

OCR 계획을 실행하고 독립 판독 스냅샷을 담은 실행 객체를 반환합니다. 실행 객체는 호출자가 Dispose합니다.

Output으로 얻은 스냅샷은 실행 해제 후에도 유효합니다. 상태와 이유, 텍스트를 함께 판독하고 인식 오류를 빈 문자열과 구별하십시오.

실행과 판독 스냅샷의 수명

OcrQuery.Execute는 계획을 실행해 QueryExecution<OcrRead>를 반환합니다. 실행 객체는 호출자가 Dispose해야 하며 Output으로 얻은 OcrRead는 독립 판독 스냅샷이어서 이미 취득한 후에는 실행을 해제해도 유효합니다. 인식 상태와 이유, 텍스트를 함께 읽어 실행 오류와 빈 문자열을 구분해야 합니다.

예를 들어 실행 E에서 Output을 읽어 판독값 R을 보관한 뒤 E를 Dispose할 수 있습니다. R을 읽는 것은 가능하지만 E.Output을 다시 호출하는 것은 해제된 실행에 접근하는 것입니다. 이름으로 캡처 이미지를 GetImage해 얻었다면 그 영상은 독립 소유 핸들이므로 실행과 별도로 Dispose합니다.

실행과 판독에서 확인

인식된 문자가 제품 코드 규칙에 맞는지는 후속 검사입니다. 예를 들어 길이 8이 필요한 경우 읽힌 문자열 길이와 허용 문자를 확인하고 불일치 사유를 기록할 수 있습니다. 이는 OCR 모델이 자동으로 그 업무 규칙에 맞게 고친다는 뜻이 아닙니다. 계획, 실행, 복사된 스냅샷, 캡처 영상의 수명과 역할을 따로 관리하세요.
