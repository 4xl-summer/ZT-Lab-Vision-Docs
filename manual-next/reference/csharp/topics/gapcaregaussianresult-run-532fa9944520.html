static ZVision.GapCareGaussianResult Run(ZVision.ZImage image, ZVision.ZImage mask, System.UInt64 radiusX, System.UInt64 radiusY, System.Double sigmaX, System.Double sigmaY, System.Double minimumFraction = 0, System.Int64 offsetX = 0, System.Int64 offsetY = 0, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, ZVision.PixelFormat outputFormat = ZVision.PixelFormat.GrayF32, System.Double constant = 0)

선택된 care 표본의 정규화 Gaussian을 계산합니다.

인자

image: Gray8/16/F32 입력입니다.

mask: Gray8 care 마스크입니다.

radiusX: x 창 반경입니다.

radiusY: y 창 반경입니다.

sigmaX: 양의 x sigma 픽셀입니다.

sigmaY: 양의 y sigma 픽셀입니다.

minimumFraction: 필터 적용에 필요한 care 표본 비율 0~1입니다.

offsetX: 마스크 x 오프셋입니다.

offsetY: 마스크 y 오프셋입니다.

border: 경계 방식입니다.

outputFormat: 회색 출력 형식입니다.

constant: 상수 경계 값입니다.

반환: 해제할 결과입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.

outputFormat.Gray8: 8비트 부호 없는 회색 형식입니다.

outputFormat.Gray16: 16비트 부호 없는 회색 형식입니다.

outputFormat.GrayF32: 32비트 부동소수 회색 형식입니다.

outputFormat.Rgba8: 8비트 RGBA 형식입니다.

outputFormat.Bgra8: 8비트 BGRA 형식입니다.
