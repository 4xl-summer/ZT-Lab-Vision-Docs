static ZVision.AdvancedMatchReport FindGlobalPolarity(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, ZVision.ZImage mask = null)

특징 전체에 공통인 한 극성으로 형상 모델을 검색합니다.

인자

source: 검색 회색 영상입니다.

model: 형상 모델입니다.

options: 검색 설정이며 지역 극성·certainty·가림 trim은 미지원입니다. 호출 중 설정 객체를 수정하지 마세요.

mask: 선택 Gray8 검색 마스크입니다.

반환: 두 공통 극성 중 점수순 결과와 공유 예산 진단입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

모델 전체에 공통인 에지 극성을 한 번에 사용하여 검색합니다. 각 특징점의 위치와 방향을 개별적으로 해석하는 것과 함께 모델 전체에 적용되는 극성 조건을 고려해야 하므로 일반 형상 검색과 결과를 구분해서 기록합니다.

밝은 대상과 어두운 배경의 관계가 영상에 따라 뒤집히는지 확인할 때, 동일한 검색 옵션과 영상에서 일반 검색 결과와 비교할 수 있습니다. 결과가 비면 포즈 범위, 에지 강도와 극성 조건을 각각 확인해야 하며 빈 결과만으로 영상의 대상 부재를 확정할 수 없습니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
source검색 회색 영상입니다.
model형상 모델입니다.
options검색 설정이며 지역 극성·certainty·가림 trim은 미지원입니다. 호출 중 설정 객체를 수정하지 마세요.
mask선택 Gray8 검색 마스크입니다.
