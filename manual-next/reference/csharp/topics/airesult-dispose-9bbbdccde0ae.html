void Dispose()

결과 핸들을 해제합니다. 이전에 반환된 맵은 계속 유효합니다.

사용과 결과 판독

이 결과 핸들을 해제해도 이전에 반환된 맵은 계속 유효합니다. 따라서 맵의 사용 기간과 결과 핸들의 사용 기간을 구분해 관리하십시오. 이미 해제한 결과에서 새로운 정보를 조회하지 말고 이전에 얻은 맵도 해당 소유 계약에 따라 해제합니다.

사용 순서와 결과 확인

AiResult는 추론의 메타데이터와 과제별 출력을 제공하는 소유 결과입니다. Dispose는 결과 핸들을 해제하지만 이전에 Map으로 반환한 독립 영상 핸들은 계속 유효합니다. 그 맵도 사용 후 별도로 Dispose해야 합니다.

Info에는 과제와 결과 크기 및 점수 정보가 있습니다. Scores는 분류 softmax 점수를 클래스 ID 순서의 독립 배열로 복사하고 Detections는 유지된 검출을 독립 배열로 복사합니다. 해당 과제에 맞지 않는 출력 요청은 오류가 될 수 있으므로 먼저 과제를 확인하십시오.

분할 맵은 GrayU32, 이상 맵은 GrayF32이며 맵의 크기는 입력 ROI 크기입니다. 예를 들어 분할의 클래스 값과 이상 점수 값은 서로 다른 양이므로 숫자만 보고 같은 척도로 비교하면 안 됩니다. 맵을 획득한 영상의 ROI와 과제 정보도 같이 보관합니다.

필요한 Info, 배열 또는 맵을 얻은 다음 결과 핸들을 해제합니다. 이미 복사한 배열과 독립 맵, 결과 객체는 서로 다른 수명 경로를 가집니다. 해제된 결과에서 새 출력을 조회하려고 하지 말고, 보유한 각 맵 영상은 별도로 정리하십시오.

단계 또는 항목확인할 내용
Info과제와 출력 메타데이터를 먼저 읽습니다.
Scores분류 점수를 독립 배열로 복사합니다.
Detections검출 목록을 독립 배열로 복사합니다.
Map분할 또는 이상 맵을 독립 영상으로 얻습니다.
결과 Dispose네이티브 결과 핸들을 해제합니다.
맵 Dispose이전에 획득한 맵은 별도로 해제합니다.

검출 결과 배열은 유지된 후보를 점수 내림차순으로 복사하며 동점은 원래 행 순서를 따릅니다. 반면 분할 또는 이상 맵은 독립 영상 핸들입니다. 배열과 맵의 성격이 다르므로 결과를 보관할 때 과제와 출력 형태를 먼저 확인해야 합니다. 모델이 분류 과제라면 클래스 순서의 Scores를 읽고, 검출 과제에서는 해당 검출 목록을 읽습니다. 결과 핸들이 이미 닫힌 상태라면 새 조회 대신 보관한 복사 값을 사용합니다.
