TryAccept

Method · 선언 타입 ZVision.Display.ZDisplayFrameGate

C#
System.Boolean TryAccept(System.Int64 frameId, System.Int64 recipeVersion)

두 세대가 하한 이상이면 원자적으로 수락하고 하한을 갱신합니다.

인자

frameId: 수락할 프레임 세대입니다.

recipeVersion: 수락할 레시피 세대입니다.

반환: 수락했으면 참입니다.

사용과 결과 해석

프레임과 레시피 세대가 각각 현재 하한 이상이면 원자적으로 수락하고 하한을 갱신합니다. 수락 여부를 불리언으로 반환합니다.

예를 들어 현재 하한 (10,3)에서 (11,4)를 수락하면 이후 더 오래된 세대는 거부됩니다. CanAccept는 조회만 수행하므로 상태를 갱신하려면 이 메서드를 사용하십시오.

두 세대의 원자적 수락

TryAccept는 frameId와 recipeVersion이 모두 양수이고 현재 각 하한 이상인 경우에만 둘을 원자적으로 수락하고 하한을 갱신합니다. 두 값은 각각 비교하므로 프레임이 새롭더라도 레시피가 오래되면 거부됩니다. 반환 bool은 실제 수락 여부입니다.

예를 들어 현재 하한이 (10,3)일 때 (11,4)는 true가 되어 하한을 (11,4)로 바꿉니다. 이후 (12,3)은 frameId가 더 커도 recipeVersion이 하한보다 작으므로 false입니다. (11,4)처럼 각 하한과 같은 양수 값은 조건상 수락 가능합니다.

CanAccept는 현재 조건을 조회하지만 하한을 갱신하지 않습니다. 여러 흐름에서 확인과 갱신을 한 번에 해야 한다면 TryAccept의 반환을 사용합니다. Close 이후에는 양수 세대라도 수락하지 않으며, 이 게이트는 영상 핸들을 보유하거나 해제하는 객체가 아닙니다.

항목확인할 의미
frameId양의 프레임 세대
recipeVersion양의 레시피 세대
true두 하한 이상; 하한을 함께 갱신
false닫힘·비양수·어느 한 하한 미달
CanAccept조회만 수행
Close이후 모든 수락 거부
