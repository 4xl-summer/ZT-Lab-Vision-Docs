Execute의 사용과 결과 해석

서브픽셀 윤곽 쿼리를 실행해 위치 결과를 얻습니다. 소수 좌표와 정수 픽셀의 위치를 비교할 때 같은 ROI 기준을 사용합니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.

등값 경로와 좌표

SubpixelContourQuery.Execute는 준비된 등값 경로 계획을 실행하고 QueryExecution<SubpixelContourResult>를 반환합니다. Output은 독립 값 스냅샷으로 실행을 Dispose한 뒤에도 이미 얻은 값이 유효합니다. 계획과 실행의 소유 핸들은 각각 정리합니다.

경로 점은 픽셀 중심 사이에서 밝기 등값을 보간한 ROI 로컬 소수 좌표입니다. 예를 들어 원본 ROI 원점이 (10,20)이고 경로 점이 로컬 (2.5,3.0)이면 원본 기준 위치는 (12.5,23.0)입니다. 정수 픽셀 셀의 경계와 같은 것으로 반올림해 취급하면 보간 위치를 잃습니다.

각 경로가 닫혔는지 여부는 결과의 경로 정보에서 확인합니다. 빈 경로 목록은 정상 실행 결과가 될 수 있고, 잘못된 입력이나 실행 실패는 예외이므로 구분합니다. 같은 영상이라도 등값이나 ROI가 다르면 경로가 달라지므로 두 조건을 결과와 함께 저장합니다.
