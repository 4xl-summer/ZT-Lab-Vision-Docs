OCR 판독 계획을 독립 핸들로 복제합니다.

사용과 결과 해석

OCR 판독 계획을 독립 핸들로 복제합니다. 원본과 복제본은 각각 Dispose해야 합니다.

복제는 실제 OCR 실행이 아닙니다. 각 계획을 필요한 시점에 Execute하고 반환 실행과 결과의 수명도 따로 관리하십시오.

OCR 계획의 독립 복제

OcrQuery.Clone은 현재 OCR 판독 계획을 독립 핸들로 복제합니다. 원본과 복제본은 각각 Dispose해야 합니다. 복제는 OCR 판독을 실행하거나 문자가 이미 인식되었다는 의미가 아닙니다.

같은 시작 계획에서 서로 다른 후속 설정이나 실행을 분리할 때 사용할 수 있습니다. 예를 들어 원본 계획을 한 실행에 사용하면서 복제본을 별도 범위에서 유지하면 두 핸들의 종료 시점을 각각 관리할 수 있습니다. 복제 후 실제 판독은 Execute로 수행합니다.

항목의미와 사용
원본 OcrQuery기존 판독 계획
Clone독립 계획 핸들 반환
복제 계획원본과 별도로 Dispose
Execute계획의 실제 판독 실행
Output독립 OcrRead 스냅샷
입력 조건ROI와 OCR 설정을 함께 확인

Execute는 QueryExecution<OcrRead>를 만들고 Output의 독립 스냅샷을 제공합니다. 원본·복제 계획, 각 실행 및 얻은 값의 수명과 역할을 구분합니다. 판독 문자열이 비어 있거나 실행이 실패한 경우를 복제 실패와 혼동하지 않습니다.
