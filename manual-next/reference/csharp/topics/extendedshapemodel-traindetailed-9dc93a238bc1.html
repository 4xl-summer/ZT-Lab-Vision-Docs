static ZVision.ExtendedShapeModel TrainDetailed(ZVision.ZImage template, ZVision.Point2 reference, System.UInt64 sampleStep = 1, System.Nullable<System.Double> threshold = null, System.Double maxGradient = 1.7976931348623157E+308, System.Boolean sobel = false, ZVision.ZImage mask = null)

기울기 추출 방식과 크기 범위를 지정해 형상 모델을 학습합니다.

인자

template: 학습 영상입니다.

reference: 로컬 기준점입니다.

sampleStep: 표본 간격입니다.

threshold: 기울기 임계값이며 null이면 자동입니다.

maxGradient: 학습에 사용할 최대 기울기입니다.

sobel: 중심차 대신 Sobel 기울기를 사용할지 지정합니다.

mask: 선택적 마스크입니다.

반환: 호출자가 해제할 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

템플릿 기울기에서 특징을 추출하면서 최대 기울기와 Sobel 사용 여부를 추가로 지정합니다. 기본 Train보다 에지 추출 조건을 세밀하게 조정하는 학습 경로이며 검색 영상의 조건을 바로 바꾸는 호출은 아닙니다.

template은 Gray8, Gray16 또는 유한 GrayF32이고 sampleStep은 양의 픽셀 간격입니다. threshold는 비음수 임계값 또는 자동 선택 null입니다. 동일 템플릿과 기준점에서 조건을 바꾸어 학습한 모델의 특징을 비교하고, 각각의 모델을 사용 후 Dispose로 해제합니다.

입력의미와 조건
template학습 영상입니다.
reference로컬 기준점입니다.
sampleStep표본 간격입니다.
threshold기울기 임계값이며 null이면 자동입니다.
maxGradient학습에 사용할 최대 기울기입니다.
sobel중심차 대신 Sobel 기울기를 사용할지 지정합니다.
mask선택적 마스크입니다.

반환값 확인

호출자가 해제할 모델입니다.
