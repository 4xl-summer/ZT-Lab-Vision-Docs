Gray8 히스토그램을 평활화합니다. 실제 처리는 Run에서 수행합니다.

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

EqualizeHistogram의 사용과 결과 해석

히스토그램 평활화는 강도 분포를 이용해 값을 재배치합니다. 영상마다 분포가 다르면 같은 원래 강도가 항상 같은 결과로 바뀐다고 가정하지 않습니다. 명암 분포를 바꾸는 연산을 계획합니다. 전체 분포를 늘리는 방식과 히스토그램을 이용하는 방식은 같지 않으며 입력 영상의 분포와 출력 범위를 함께 비교해야 합니다.

분포 기반 처리 단계

EqualizeHistogram은 현재 계획 영상의 밝기 분포를 바탕으로 매핑하는 단계를 추가합니다. 뒤에 임계 처리를 놓으면 원본이 아니라 평활화된 값에 임계값을 적용합니다. 지연 계획을 만들었다는 사실과 실제 계산의 성공은 구분합니다.
