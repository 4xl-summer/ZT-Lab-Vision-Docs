void SetIndexMode(System.Boolean byLabel)

현재 결과 조회 방식만 변경합니다.

인자

byLabel: true면 라벨, false면 0 기반 인덱스입니다.

SetIndexMode의 사용과 결과 해석

인덱스 방식은 결과의 식별과 조회 방법을 정하는 설정입니다. 프레임이나 연결 조건이 바뀐 경우 이전 번호가 같은 물체를 가리킨다고 가정하지 않습니다. 연결 성분 분석의 입력 영상과 연결성, 인덱스 방식을 먼저 설정하고 계산한 후 결과를 조회합니다. 4연결과 8연결은 대각선으로만 닿은 전경의 그룹 수를 다르게 만들 수 있습니다.
