ZVision.ZImage AdaptiveThresholdMean(System.Int32 kernel, System.Double offset)

Gray8, Gray16, GrayF32에서 픽셀이 이웃 평균에서 offset을 뺀 값 이상이면 255인 Gray8 마스크를 만듭니다.

인자

kernel: 중심 정사각형 커널의 한 변(픽셀)으로 양의 홀수입니다.

offset: 이웃 평균에서 빼는 유한한 값으로 원본 밝기 단위입니다.

반환: 호출자가 Dispose해야 하는 새 소유 영상입니다.

호출에 필요한 입력

지역 평균과 오프셋을 사용해 분할합니다.

인자선언된 형식확인할 내용
kernelSystem.Int32중심 정사각형 커널의 한 변(픽셀)으로 양의 홀수입니다.
offsetSystem.Double이웃 평균에서 빼는 유한한 값으로 원본 밝기 단위입니다.

결과와 사용 순서

호출자가 Dispose해야 하는 새 소유 영상입니다.
