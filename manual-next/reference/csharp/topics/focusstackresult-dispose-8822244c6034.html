void Dispose()

결과를 해제합니다.

이 호출의 입력과 객체 맥락

FocusStackResult.FusedImage: 독립 소유 결합 영상을 얻습니다.

FocusStackResult.IndexMap: 독립 소유 입력 인덱스 지도를 얻습니다.

초점 결합 결과와 영상의 수명

FocusStackResult는 여러 Gray8 영상의 초점 결합 결과를 소유합니다. Dispose는 결과 객체를 정리하며 반환값은 없습니다. 결과에서 얻는 결합 영상과 선택 지도는 각각 독립 소유 ZImage이므로 결과 객체와 같은 하나의 핸들로 취급하지 않습니다.

FusedImage는 합쳐진 밝기 영상이고 IndexMap은 각 위치의 입력 선택을 나타내는 지도입니다. 예를 들어 두 영상의 초점이 서로 다른 위치에서 선명하다면 결합 영상과 선택 지도를 같은 좌표에서 비교해 어느 입력이 선택됐는지 살펴볼 수 있습니다. 지도의 숫자를 픽셀 밝기로 읽지 않습니다.

항목의미와 사용
입력정렬된 Gray8 영상들
결과초점 결합을 소유하는 객체
FusedImage독립 소유 결합 영상
IndexMap독립 소유 입력 선택 지도
각 영상사용 후 별도로 Dispose
Dispose결과 객체 자원 해제

결과가 살아 있을 때 필요한 영상을 획득하고, 각 영상을 사용한 뒤 Dispose합니다. 결과도 작업이 끝나면 Dispose해야 합니다. 이미 해제한 결과에서 새 영상을 얻으려 하지 말고 입력 영상의 정렬과 ROI도 별도 확인합니다.
