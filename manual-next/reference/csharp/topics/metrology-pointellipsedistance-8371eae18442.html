PointEllipseDistance

Method · 선언 타입 ZVision.Metrology

C#
static System.Double PointEllipseDistance(ZVision.Point2 point, ZVision.EllipseFit ellipse)

점에서 타원 경계까지의 최소 유클리드 거리를 계산합니다.

인자

point: 변환 또는 측정할 점입니다.

ellipse: 측정할 타원입니다.

반환: 입력 좌표와 같은 단위의 계산값입니다.

관련 입력의 확인된 조건

point.X: 영역의 로컬 x 좌표입니다.

point.Y: 영역의 로컬 y 좌표입니다.

계산과 결과 해석

점에서 회전된 타원 경계까지의 최소 유클리드 거리를 계산합니다. 입력 점이 타원 내부에 있어도 경계까지의 거리를 양수로 반환하며, 타원 위에 있으면 0에 가깝습니다. 타원의 중심, 두 반축과 각도는 EllipseFit에서 가져오고 긴 반축은 짧은 반축 이상, 짧은 반축은 양수여야 합니다. 예를 들어 중심이 원점이고 회전이 없으며 반축이 4와 2인 타원의 오른쪽 끝 (4,0)은 경계 위에 있습니다. 두 반축은 전체 폭과 높이가 아니므로 지름을 그대로 전달하면 결과가 달라집니다. 함수는 좌표의 단위를 그대로 따르며 ROI나 물리 보정을 자동으로 수행하지 않습니다. 비유한 입력이나 유효하지 않은 형상은 정상적인 거리 0으로 대체하지 말고 오류로 처리하십시오. 예시의 위쪽 끝 (0,2)도 같은 타원 경계에 있습니다. 입력 타원이 회전했다면 축 끝점도 중심을 기준으로 회전한 위치가 되므로 회전을 무시한 (4,0)을 그대로 기대값으로 쓰지 않습니다. 각도와 좌표계의 축 방향을 함께 확인하십시오. 입력 점이 중심에 있다고 해서 경계와의 거리가 0인 것은 아닙니다. 회전 없는 반축 4와 2의 타원에서는 중심에서 가까운 경계까지의 거리가 2입니다. 경계까지의 최단 거리와 중심까지의 거리는 다른 계산입니다.
