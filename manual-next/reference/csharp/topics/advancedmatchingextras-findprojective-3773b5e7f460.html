FindProjective

C#
static ZVision.ProjectiveAdvancedReport FindProjective(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, ZVision.AdvancedSearchAxis perspectiveX, ZVision.AdvancedSearchAxis perspectiveY, ZVision.ZImage mask = null)

영상에서 두 원근 분모 계수 격자를 포함해 NCC 템플릿을 찾습니다.

인자

source: 검색 영상입니다.

model: NCC 모델입니다.

options: 검색 옵션입니다.

perspectiveX: X 원근 계수 격자입니다.

perspectiveY: Y 원근 계수 격자입니다.

mask: 선택적 검색 마스크입니다.

반환: 원근 후보와 종료 진단입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ProjectiveAdvancedReport.Termination: 탐색 종료 이유입니다.

호출 맥락과 결과 해석

기본 포즈 격자에 더해 원근 분모의 x·y 계수 격자를 검색합니다. perspectiveX와 perspectiveY는 각각 해당 방향의 계수 축이며 결과에는 선택된 원근 계수가 포함됩니다. 이 값은 단순한 평행 이동 거리나 회전각이 아닙니다.

원근 축을 추가하면 다른 포즈 축과 조합되는 후보 수가 늘어납니다. 입력 영상과 검색 범위, 후보 예산 및 종료 진단을 함께 기록하고, 반환된 포즈의 원근 계수까지 확인해야 어떤 변환이 선택되었는지 재현할 수 있습니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
source검색 영상입니다.
modelNCC 모델입니다.
options검색 옵션입니다.
perspectiveXX 원근 계수 격자입니다.
perspectiveYY 원근 계수 격자입니다.
mask선택적 검색 마스크입니다.
