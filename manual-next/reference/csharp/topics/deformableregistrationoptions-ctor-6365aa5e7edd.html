DeformableRegistrationOptions()

기본 비강체 등록 설정을 만듭니다.

이 호출의 입력과 객체 맥락

DeformableRegistrationOptions.InitialDisplacements: 기준 격자에서 소스로 가는 초기 픽셀 변위입니다.

DeformableRegistrationOptions.StepX: X 변위 탐색 간격입니다.

DeformableRegistrationOptions.StepY: Y 변위 탐색 간격입니다.

DeformableRegistrationOptions.Levels: 탐색 간격 반감 단계 수입니다.

DeformableRegistrationOptions.IterationsPerLevel: 단계별 반복 제한입니다.

DeformableRegistrationOptions.MinCoverage: 유효 표본의 최소 비율입니다.

DeformableRegistrationOptions.Smoothness: 인접 제어점 차이의 정규화 계수입니다.

사용 순서와 결과 해석

기본 생성자는 비강체 정합의 설정 객체를 만듭니다. Columns와 Rows는 기본 0이고 InitialDisplacements는 빈 배열이므로, 이 객체를 만든 것만으로 유효한 제어 격자가 완성되는 것은 아닙니다. 실제 정합 전 행·열과 초기 변위를 채워야 합니다.

각 축의 제어점 수는 2 이상이고 총 행×열은 최대 1024입니다. InitialDisplacements는 기준 격자에서 소스로 가는 픽셀 변위를 행 우선으로 담으며 수가 행×열과 일치해야 합니다. 예를 들어 3열 2행이면 Point2 변위 6개를 지정합니다.

StepX/Y의 기본 탐색 간격은 각각 1픽셀, Levels는 3, IterationsPerLevel은 10입니다. MinCoverage 기본은 1이고 Smoothness는 인접 제어점 차이에 대한 가중치입니다. 설정을 만들었다는 사실과 최적화가 성공했다는 사실은 다르므로 실행 결과의 Found와 유효 마스크를 확인하세요.

예를 들어 3열 2행을 지정했다면 초기 변위 배열의 항목 6개를 첫 행의 세 점 다음 둘째 행의 세 점으로 배치합니다. 이 값은 기준 격자에서 소스로 가는 픽셀 변위이므로 영상의 절대 원점 좌표를 그대로 넣는 자리가 아닙니다. 제어점 수를 바꾸면 배열도 같은 형상으로 다시 준비해야 합니다.

예를 들어 각 초기 변위를 (0,0)으로 채우면 모든 제어점에서 초기 픽셀 이동을 0으로 제시하는 설정이 됩니다. 이것만으로 정합이 완료된 것은 아니며 이후 검색 단계의 간격, 반복 상한, 유효 표본 비율이 실제 평가에 영향을 줍니다. 결과의 Found와 Coverage를 별도로 확인해야 합니다.
