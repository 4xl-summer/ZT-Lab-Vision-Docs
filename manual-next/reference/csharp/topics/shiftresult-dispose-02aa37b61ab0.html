void Dispose()

소유한 네이티브 자원을 해제합니다.

수명과 사용 순서

이동 추정 결과가 소유한 네이티브 자원을 해제합니다. 이동 값과 필요한 결과를 먼저 읽고 결과 객체의 사용이 끝났을 때 호출하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

사용 흐름과 판독 기준

ShiftResult는 이동 추정의 결과를 보관하는 소유 객체입니다. 필요한 이동값과 그 결과가 사용한 좌표 기준을 읽은 후 Dispose로 결과 핸들을 해제합니다. 이 호출은 영상을 이동시키거나 이동을 다시 계산하지 않습니다. 한 번의 결과를 서로 다른 프레임과 혼동하지 않도록 입력 영상과 추정 설정을 값과 함께 보관합니다.

이동값의 두 축은 위치 차이를 뜻하므로 적용 방향이 중요합니다. 예를 들어 x 이동 3, y 이동 -2라는 값이 나왔다면 이는 해당 호출이 정의한 출발과 도착 방향에서 해석해야 합니다. 역방향을 사용하는 코드에서 숫자의 부호나 입력 순서를 임의로 가정하지 말고 실제 추정 API의 변환 방향을 확인합니다.

결과 객체는 네이티브 자원을 소유하므로 사용이 끝난 뒤 명시적으로 해제합니다. 해제 후 같은 객체에서 값을 다시 읽지 않고 필요한 관리형 값은 그 전에 확보합니다. 입력 영상이나 다른 결과 객체도 모두 한꺼번에 해제하는 명령으로 이 Dispose를 해석하지 않으며 각각의 소유 범위를 따로 관리합니다.
