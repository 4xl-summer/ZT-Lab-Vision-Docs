static ZVision.TranslationPyramidReport TranslationPyramid(ZVision.ZImage source, ZVision.ZImage reference, ZVision.AdvancedRegistrationOptions options, System.UInt64 firstLevel, System.UInt64 lastLevel = 0, System.UInt64 maxWork = 100000000)

실제 소스·기준 축소 영상으로 이동을 거친 층부터 정합합니다.

인자

source: 소스 영상입니다.

reference: 기준 영상입니다.

options: 이동 전용 설정이며 호출 중 수정하지 마세요.

firstLevel: 가장 거친 층 0..8입니다.

lastLevel: 마지막으로 평가할 층입니다.

maxWork: 보수적 작업 상한입니다.

반환: 최종 정합과 거친 층 크기입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

TranslationPyramidReport.CoarseSourceWidth: 거친 소스 너비입니다.

TranslationPyramidReport.CoarseSourceHeight: 거친 소스 높이입니다.

TranslationPyramidReport.CoarseReferenceWidth: 거친 기준 너비입니다.

TranslationPyramidReport.CoarseReferenceHeight: 거친 기준 높이입니다.

사용과 결과 해석

실제 소스·기준 축소 영상으로 이동 정합을 가장 거친 firstLevel부터 lastLevel까지 수행합니다. firstLevel은 0~8이고 maxWork는 보수적 작업 상한입니다.

각 단계에서 얻은 변환이 다음 단계 검색의 문맥이 됩니다. 이동 전용 옵션과 층 범위를 확인하고 반환 보고서의 실제 평가 결과를 판독하십시오.
