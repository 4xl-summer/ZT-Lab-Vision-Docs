static ZVision.GapExposureFusionResult Create(ZVision.ZImage[] images, System.Double[] exposures)

등록된 Gray8 노출을 포화 제외 삼각 가중치로 결합합니다.

인자

images: 같은 크기·원점의 영상 2..256개입니다.

exposures: 각 영상의 양수 유한 노출 시간입니다.

반환: 해제할 독립 결과입니다.

이 호출의 입력과 객체 맥락

같은 크기와 원점을 가진 Gray8 영상 2~256개와 각 양의 유한 노출 시간을 입력 순서대로 전달합니다. 포화 표본을 제외하는 삼각 가중치로 상대 방사량을 결합합니다. 반환 결과의 방사량 영상과 유효 마스크를 함께 읽고, 결과 및 별도 획득한 영상들을 각각 Dispose합니다.

정렬된 영상과 노출값 대응

Create는 같은 크기와 원점의 Gray8 영상 2~256개와 각 영상에 대응하는 양의 유한 노출 시간을 받습니다. 포화 표본을 제외하는 삼각 가중치로 상대 방사량을 결합하고 독립 소유 결과를 반환합니다. 입력 영상의 배열 순서와 exposures 순서는 정확히 대응해야 합니다.

예를 들어 첫 영상이 짧은 노출, 둘째 영상이 긴 노출이면 두 노출 시간도 그 순서로 전달합니다. 두 영상을 바꾸면서 노출 배열은 그대로 두면 영상과 시간의 대응이 잘못됩니다. 영상마다 대상이 이동했다면 같은 픽셀이 다른 위치를 가리키므로 사전에 정렬하고 원점과 크기를 일치시켜야 합니다.

항목의미와 처리
images동일 크기·원점 Gray8 영상 2~256개
exposures영상별 양의 유한 노출 시간
대응영상과 시간의 배열 순서 일치

출력상대 방사량과 유효 마스크
수명결과와 취득 영상을 각각 Dispose

적용과 결과 확인

결과의 영상 취득 메서드에서 상대 방사량과 유효 마스크를 얻어 함께 판독하세요. 유효하지 않은 위치를 실제 방사량 0으로 곧바로 해석하지 않습니다. Create가 반환한 결과와 별도 취득 영상은 각각 소유 핸들이므로 작업 후 각각 Dispose합니다. 노출 시간은 목록 전체에서 같은 단위로 사용하고 결과와 함께 기록합니다.

상대 방사량과 유효 마스크는 서로 다른 의미의 출력입니다. 마스크가 유효하지 않다고 표시한 위치에 방사량 숫자가 있더라도 그 위치를 정상 측정값으로 판정해서는 안 됩니다. 두 영상의 노출 조건이 모두 같은 밝기 영역에서 포화되거나 너무 어두운 경우에는 활용할 표본이 부족할 수 있으므로 유효 마스크를 실제 영상과 함께 살펴보세요. 결과는 물리 단위로 교정된 절대 광량이라고 자동으로 간주하지 않습니다. 두 출력의 좌표와 입력 기하를 함께 확인하세요.
