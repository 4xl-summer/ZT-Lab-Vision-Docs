static ZVision.InvariantFeatureModel Train(ZVision.ZImage template, ZVision.InvariantFeatureOptions options, ZVision.ZImage mask = null)

회색 영상으로 특징 모델을 학습합니다.

인자

template: 학습 회색 영상입니다.

options: 특징 검출 설정입니다.

mask: 선택 Gray8 마스크입니다.

반환: 해제 가능한 모델입니다.

관련 입력의 확인된 조건

template.Origin: ROI의 글로벌 픽셀 원점입니다.

template.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

호출 맥락과 결과 해석

방향과 다중 해상도를 갖는 특징 모델을 회색 템플릿에서 학습합니다. InvariantFeatureOptions가 검출 조건을 지정하며 선택적인 Gray8 마스크로 학습 영역을 제한할 수 있습니다.

학습된 점의 위치뿐 아니라 배율과 방향은 Points에서 확인합니다. 이 모델과 일반 FeatureModel은 사용하는 모델 표현과 학습 옵션이 다르므로 저장 데이터와 복원 API를 각 모델 종류에 맞게 관리합니다. 생성된 모델은 호출자가 Dispose로 해제합니다.

입력 선택을 위한 확인

입력의미와 조건
template학습 회색 영상입니다.
options특징 검출 설정입니다.
mask선택 Gray8 마스크입니다.

반환값 확인

해제 가능한 모델입니다.
