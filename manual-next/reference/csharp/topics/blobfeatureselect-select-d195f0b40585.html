Select

Method · 선언 타입 ZVision.BlobFeatureSelect

C#
static System.UInt64[] Select(ZVision.AdvancedBlobResult source, ZVision.BlobFeatureRange[] criteria, System.Boolean matchAll, System.UInt64 workBudget)

모든 범위 또는 하나 이상의 범위를 만족하는 인덱스를 반환합니다.

인자

source: Blob 분석 결과입니다.

criteria: 1~64개의 포괄 특징 범위입니다.

matchAll: 모두 만족해야 하면 true, 하나 이상이면 false입니다.

workBudget: 특징 계산 및 비교 상한입니다.

반환: 입력 순서의 0 기반 Blob 인덱스 배열입니다.

관련 입력의 확인된 조건

source.Count: 측정된 Blob 수입니다.

source.MapInfo: 라벨 영상의 크기를 조회합니다. 부모 ROI 원점은 저장되지 않습니다.

source.Width: 라벨 영상의 픽셀 너비입니다.

source.Height: 라벨 영상의 픽셀 높이입니다.

호출과 결과 해석

Blob 결과의 특징 범위 조건들을 검사해 선택된 원래 항목의 인덱스를 반환합니다. matchAll이 참이면 모든 범위, 거짓이면 하나 이상의 범위를 만족하는 조건을 사용합니다. 각 BlobFeatureRange의 Feature, Low, High를 확인하고 반환 인덱스를 원본 Blob 결과와 연결합니다. workBudget은 허용 작업량이므로 결과 개수와 구분합니다.

입력별 확인

입력의미
sourceBlob 분석 결과입니다.
criteria1~64개의 포괄 특징 범위입니다.
matchAll모두 만족해야 하면 true, 하나 이상이면 false입니다.
workBudget특징 계산 및 비교 상한입니다.

반환값

입력 순서의 0 기반 Blob 인덱스 배열입니다.
