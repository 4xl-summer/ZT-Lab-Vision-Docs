static ZVision.AdvancedMatchModel FromBytes(System.Byte[] data)

자체 형식의 형상 모델을 복원합니다.

인자

data: 버전과 체크섬을 갖춘 바이트 배열입니다.

반환: 해제 가능한 형상 모델입니다.

관련 입력의 확인된 조건

AdvancedMatchModel.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

호출 맥락과 결과 해석

ToBytes로 얻은 형상 모델 아카이브를 전달해 검색에 사용할 모델을 복원합니다. 입력 길이는 128부터 2097184바이트까지이며 아카이브에는 버전과 체크섬이 있습니다. 임의의 이미지 바이트나 다른 모델 종류의 데이터를 형상 모델로 취급하지 않습니다.

반환 모델은 호출자가 Dispose로 해제해야 합니다. 저장된 바이트를 보관한 뒤 복원 모델로 같은 입력과 검색 옵션을 사용해 결과를 비교하면 배포한 모델과 설정을 함께 확인할 수 있습니다. 복원 오류가 나면 바이트의 완전성과 모델 종류를 먼저 살핍니다.

입력 선택을 위한 확인

입력의미
data버전과 체크섬을 갖춘 바이트 배열입니다.
