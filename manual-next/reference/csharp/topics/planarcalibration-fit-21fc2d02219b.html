C#
static ZVision.PlanarCalibration Fit(ZVision.Point2[] pixels, ZVision.Point2[] world, ZVision.LengthUnit unit)

글로벌 픽셀과 세계 대응점으로 평면 보정을 피팅합니다.

인자

pixels: 같은 픽셀 프레임의 글로벌 대응점 배열입니다.

world: 픽셀과 순서가 같은 세계 대응점 배열입니다.

unit: 세계 길이 단위입니다.

반환: 계산된 결과입니다.

사용과 결과 판독

대응하는 픽셀점과 세계점을 사용해 역변환 가능한 평면 매핑을 적합합니다. 배열의 같은 인덱스가 같은 표적 위치여야 하므로 한쪽만 정렬하면 잘못된 대응을 풉니다. 픽셀은 글로벌 영상 좌표이고 world는 지정한 길이 단위입니다. 점의 수뿐 아니라 배치가 퇴화하지 않았는지 확인하고 학습에 쓰지 않은 점의 잔차를 별도로 평가하십시오.

대응점과 보류점으로 검증

픽셀 (100,200), (120,200), (100,240), (120,240)에 월드 mm (11,38), (13,38), (11,46), (13,46)을 같은 순서로 대응시키면 X=0.1x+1, Y=0.2y−2를 설명하는 평면 변환을 만들 수 있습니다. 픽셀 목록과 월드 목록을 각각 독립적으로 정렬하면 대응 관계가 깨집니다.

단계 또는 항목확인할 내용
입력 좌표pixels는 전체 영상 기준
대응 관계배열의 같은 인덱스는 같은 물리 점
월드 단위world와 unit을 일관되게 지정
보류점 예측(110,220) → (12,42) mm
판독기준 (12.3,42.4)와의 월드 잔차 0.5 mm

결과를 사용할 때

학습에 쓰지 않은 전역 픽셀 (110,220)은 이 식에서 (12,42) mm입니다. 독립 기준이 (12.3,42.4) mm라면 잔차는 √(0.3²+0.4²)=0.5 mm입니다. ROI 원점이 (100,200)인 로컬 점 (10,20)을 넣을 때는 원점을 한 번 더해 전역 좌표로 바꿉니다.
