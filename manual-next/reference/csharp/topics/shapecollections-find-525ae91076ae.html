static ZVision.ShapeCollectionResult Find(ZVision.ZImage source, ZVision.ShapeCollectionEntry[] entries, ZVision.AdvancedMatchingOptions options, System.UInt64 totalBudget, System.UInt64 maxResults, ZVision.ZImage mask = null, ZVision.ShapeOverlapMode overlap = ZVision.ShapeOverlapMode.Disabled, System.Double maxIou = 1)

각 형상 모델을 검색하고 모델 ID를 결과에 보존합니다.

인자

source: 검색할 회색 영상입니다.

entries: 고유 ID를 가진 형상 모델 1..64개입니다.

options: 모든 모델에 적용할 검색 옵션입니다. 호출 중 설정 객체를 수정하지 마세요.

totalBudget: 공유할 후보 평가 상한입니다.

maxResults: 출력 개수 1..256입니다.

mask: 선택 Gray8 검색 마스크입니다.

overlap: 모델 간 겹침 억제 범위입니다.

maxIou: 허용 IoU [0,1]입니다.

반환: 독립 결과와 완료 여부입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ShapeCollectionResult.Matches: 독립 검색 결과입니다.

ShapeCollectionResult.Evaluated: 평가한 후보 개수입니다.

ShapeCollectionResult.Incomplete: 모든 모델을 끝까지 처리하지 못했는지 나타냅니다.

호출과 결과 해석

여러 고급 형상 모델을 검색하고 결과에 입력 모델 id를 보존합니다. totalBudget은 모델들이 공유하는 검색 예산이고 maxResults는 반환 상한입니다. overlap과 maxIou는 결과 간 중복을 처리하는 기준이므로 모델별 결과를 비교할 때 함께 기록합니다. 빈 결과와 예산으로 제한된 실행 상태를 구분합니다.

입력별 확인

입력의미
source검색할 회색 영상입니다.
entries고유 ID를 가진 형상 모델 1..64개입니다.
options모든 모델에 적용할 검색 옵션입니다. 호출 중 설정 객체를 수정하지 마세요.
totalBudget공유할 후보 평가 상한입니다.
maxResults출력 개수 1..256입니다.
mask선택 Gray8 검색 마스크입니다.
overlap모델 간 겹침 억제 범위입니다.
maxIou허용 IoU [0,1]입니다.

반환값

독립 결과와 완료 여부입니다.
