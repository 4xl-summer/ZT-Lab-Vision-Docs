static System.ValueTuple<ZVision.ZImage, ZVision.GapCopyReport> Fill(ZVision.ZImage destination, System.Int64 x, System.Int64 y, System.UInt64 width, System.UInt64 height, System.Double value, ZVision.ZImage mask = null, System.Int64 maskOffsetX = 0, System.Int64 maskOffsetY = 0, System.Boolean clip = false)

목적 영상의 선택 직사각 영역을 유한한 상수로 채웁니다.

인자

destination: 기준 목적 영상입니다.

x: 목적 ROI 상대 x입니다.

y: 목적 ROI 상대 y입니다.

width: 영역 너비입니다.

height: 영역 높이입니다.

value: 모든 성분에 적용할 유한 값입니다.

mask: Gray8 care 마스크 또는 null입니다.

maskOffsetX: 목적 ROI 상대 마스크 x입니다.

maskOffsetY: 목적 ROI 상대 마스크 y입니다.

clip: 목적 밖 선택 픽셀을 건너뛰는지 지정합니다.

반환: 독립 영상과 처리 수입니다.

관련 입력의 확인된 조건

destination.Origin: ROI의 글로벌 픽셀 원점입니다.

destination.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

Fill의 사용과 결과 해석

채울 영역과 대상 영상의 좌표 기준을 확인합니다. 지정 범위 안의 픽셀을 바꾸는 일과 새 영상을 얻는 반환 소유권은 선언을 기준으로 구분합니다. 영역 복사와 채우기는 위치와 크기 및 선택 마스크를 기준으로 수행합니다. 원본과 목적 영상의 ROI 좌표를 각각 확인하고, 화면 밖 부분의 처리와 반환 보고서를 함께 살펴봅니다.

항목이 호출에서 확인할 내용
destination기준 목적 영상입니다.
x목적 ROI 상대 x입니다.
y목적 ROI 상대 y입니다.
width영역 너비입니다.
height영역 높이입니다.
반환독립 영상과 처리 수입니다.
