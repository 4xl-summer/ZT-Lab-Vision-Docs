Train

Method · 선언 타입 ZVision.FontOcrModel

C#
static ZVision.FontOcrModel Train(ZVision.FontOcrSample[] samples, ZVision.FontOcrOptions options, ZVision.FontTrainingAlgorithm algorithm = ZVision.FontTrainingAlgorithm.NearestExample)

레이블이 지정된 셀들로 분류기를 학습합니다.

인자

samples: 학습 예제들입니다.

options: 이진화와 셀 설정입니다.

algorithm: 학습 알고리즘입니다.

반환: 소유한 분류기입니다.

관련 입력의 확인된 조건

options.AllowedChars: 후보 분류에 허용할 유니코드 문자 집합입니다.

options.LightText: 밝은 글자이면 true입니다.

options.ClosingRadius: 정사각 닫기 반경(픽셀)입니다.

options.MinWidth: 문자 너비 하한(픽셀)입니다.

options.MaxWidth: 문자 너비 상한(픽셀)입니다.

options.MinHeight: 문자 높이 하한(픽셀)입니다.

options.MaxHeight: 문자 높이 상한(픽셀)입니다.

options.SplitTouching: 폭이 큰 문자를 열 투영으로 분리합니다.

options.MinGlyphScore: 각 문자 유사도 승인 하한입니다.

options.MinStringScore: 평균 문자 유사도 승인 하한입니다.

options.PositionChars: 각 줄에서 위치별로 허용할 문자 집합입니다. 빈 배열은 제한이 없습니다.

사용과 결과 해석

레이블이 있는 문자 셀 배열과 이진화·분할 옵션으로 글꼴 분류기를 학습합니다. algorithm 기본값은 NearestExample이며 반환 모델은 호출자가 해제합니다.

각 셀의 문자 코드와 영상 위치가 올바르게 대응해야 합니다. 모델은 제공한 예제에 기반하므로 실제 판독 조건에서 별도 이미지로 결과를 확인하십시오.
