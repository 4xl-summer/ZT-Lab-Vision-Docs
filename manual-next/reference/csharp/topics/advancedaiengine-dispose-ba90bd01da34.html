네이티브 모델을 해제합니다.

사용과 결과 판독

모델 실행이 끝난 뒤 엔진의 네이티브 모델 자원을 놓습니다. Run에서 얻은 결과 텐서는 각각 Dispose해야 하는 별도 소유 객체이므로 엔진 해제와 텐서 해제를 한 번의 동작으로 혼동하지 마십시오. 모델을 다시 실행하려면 유효한 엔진이 필요합니다.

사용 순서와 결과 확인

AdvancedAiEngine은 RTen 모델을 소유하고 가변 형상 또는 여러 입출력을 가진 텐서 추론을 실행합니다. Dispose는 이 엔진의 네이티브 모델 핸들을 해제하므로 해당 엔진에 대한 실행을 마친 뒤 호출합니다. 입력과 출력 텐서는 엔진과 서로 다른 자원입니다.

FromBytes로 모델을 연 다음 모델이 선언한 순서대로 AdvancedTensor들을 Run에 전달합니다. 반환된 배열의 각 텐서는 별도로 Dispose해야 합니다. 예를 들어 출력이 두 개이면 결과 배열 하나만 정리했다고 두 텐서의 핸들이 자동으로 해제되는 것으로 취급하지 마십시오.

각 텐서의 Read는 형상과 형식에 맞는 새 값 배열을 복사합니다. 필요한 출력 값을 읽을 때 텐서 순서와 형상을 함께 기록해야 어느 출력에 속하는지 구분할 수 있습니다. 값 복사본과 텐서 핸들의 수명도 서로 다릅니다.

엔진을 해제한 뒤 같은 엔진으로 새로운 Run을 요청하지 마십시오. 입력으로 만든 텐서 역시 호출자가 소유한 자원이므로 각자의 사용을 마친 시점에 해제합니다. 모델 로드, 추론 실행, 출력값 판독 및 자원 해제는 분리된 단계입니다.

단계 또는 항목확인할 내용
모델 로드FromBytes로 소유 엔진을 만듭니다.

출력 텐서반환된 각 AdvancedTensor를 별도 관리합니다.

텐서 해제입력과 출력 텐서를 각각 사용 후 Dispose합니다.
엔진 해제실행을 마친 엔진의 모델 핸들을 Dispose합니다.

입력 텐서 역시 형상과 값의 복사본으로 생성한 별도 객체입니다. 예를 들어 두 개의 입력과 두 개의 출력을 사용했다면 엔진 하나의 수명 외에 네 텐서 각각의 사용 종료를 추적해야 합니다. 배열에 텐서 참조를 담았다는 사실과 각 텐서의 네이티브 핸들이 해제됐다는 사실은 다릅니다. 반환된 텐서의 형상이 모델의 어떤 출력인지 확인한 뒤 복사된 값을 저장하고, 더 이상 필요하지 않은 텐서를 순서대로 정리하십시오.
