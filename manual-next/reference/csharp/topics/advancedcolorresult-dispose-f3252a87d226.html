void Dispose()

결과 핸들을 해제합니다.

고급 색 결과 해제

고급 색 결과가 소유한 핸들을 해제합니다. 결과에서 이미 획득한 독립 영상은 각 영상의 소유 규칙에 따라 별도로 Dispose해야 합니다.

닫힌 결과의 Image, ToLab, ToRgb 호출은 ObjectDisposedException입니다. 복사된 값과 원본 결과 핸들을 같은 수명으로 가정하지 않습니다.

색 결과와 획득 영상의 수명

이 호출은 AdvancedColorResult가 소유한 결과 핸들을 해제합니다. 색 평면 변환 결과와 매칭 결과가 같은 래퍼를 사용하므로 어떤 결과에서 영상을 얻었는지 먼저 확인합니다. Dispose 이후 Image, ToLab, ToRgb는 닫힌 객체 오류 경로를 따릅니다.

색 평면의 Image 인덱스는 0부터 2까지입니다. 매칭 결과에서는 0이 샘플 인덱스, 1이 거리 영상입니다. 동일한 숫자 0이라도 결과 종류에 따라 의미가 다르므로 결과의 출처와 인덱스를 기록합니다.

Image나 ToRgb로 얻은 ZImage는 독립 소유 영상입니다. 결과를 Dispose한 것만으로 호출자가 획득한 영상의 해제를 대신하지 않으며, 각 영상도 사용 후 Dispose합니다. ToLab이 반환하는 새 색 결과 역시 별도 소유 자원입니다.

예를 들어 세 색 평면을 가져왔다면 결과 한 개와 영상 세 개를 각각 정리해야 합니다. 화면 표시가 끝난 뒤 영상을 먼저 닫고 결과를 닫는 순서를 사용할 수 있습니다. 복사된 관리 값과 네이티브 영상 핸들의 수명은 다릅니다.
