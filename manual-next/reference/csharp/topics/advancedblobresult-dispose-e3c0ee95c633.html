소유 핸들을 해제합니다.

Dispose의 사용과 결과 해석

분석 결과가 소유한 자원을 해제합니다. 이 결과를 통해 가져온 측정값과 별도 소유 영상의 수명은 각 반환 계약을 따르며, 닫힌 결과에서 다시 조회하지 않습니다. 측정값과 라벨 배열은 서로 다른 표현입니다. 결과 인덱스와 라벨 번호를 혼동하지 말고, 좌표를 물리량으로 읽을 때 적용된 변환과 단위를 함께 기록합니다. 결과를 조회하기 전에 원본 분석과 선택 조건을 확인합니다.

사용 순서와 결과 보관

AdvancedBlobResult는 성분의 측정값과 라벨 관련 분석 결과를 소유합니다. Dispose는 이 결과 핸들의 수명을 끝내므로 필요한 인덱스별 측정값과 라벨 배열을 먼저 읽습니다. 결과를 닫는 호출은 연결 성분을 다시 계산하거나 조건에 맞는 성분을 삭제하는 연산이 아닙니다.

Get은 0부터 시작하는 결과 인덱스로 측정값을 얻고 Labels는 배경 0을 포함하는 행 우선 라벨 배열을 복사합니다. 예를 들어 결과 인덱스 0은 첫 측정 항목을 가리키지만 라벨 영상의 값 0은 배경입니다. 두 숫자를 같은 식별자로 해석하면 첫 성분과 배경을 혼동할 수 있습니다.

복사해 얻은 관리형 값과 다른 소유 객체는 이 결과 핸들과 서로 다른 수명 규칙을 가집니다. 좌표를 세계 단위로 읽었다면 적용된 보정과 단위를 함께 보관합니다. 결과를 해제한 뒤에는 같은 결과에서 Get, Labels 또는 추가 계산을 다시 요청하지 않으며 별도 소유 핸들은 각 반환 계약대로 해제합니다.
