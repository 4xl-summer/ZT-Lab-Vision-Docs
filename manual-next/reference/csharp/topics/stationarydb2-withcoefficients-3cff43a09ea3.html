WithCoefficients

Method · 선언 타입 ZVision.StationaryDb2

C#
ZVision.StationaryDb2 WithCoefficients(System.Double[] values)

계수를 교체합니다.

인자

values: 새 계수입니다.

반환: 독립 모델입니다.

호출과 계산

지정한 계수로 새 독립 변환 모델을 만듭니다. values의 길이는 현재 계수 길이와 같아야 하고 모든 값이 유한해야 하며, 기존 모델은 변경되지 않습니다.

예를 들어 현재 계수가 16개라면 교체 배열도 16개가 필요합니다. 길이가 15개이거나 NaN이 포함되면 유효한 교체 결과 대신 오류를 처리해야 합니다.

항목Stationary DB2 계약
입력원래 길이와 같은 유한 계수 배열
출력독립 변환 모델
실패길이 불일치 또는 비유한 계수
수명C#에서 얻은 독립 배열 또는 모델은 해당 소유 계약을 따르며 네이티브 소유자는 사용 후 Dispose합니다.

결과 해석

계수는 비감쇠 변환의 전체 해상도 밴드의 원래 순서를 유지해야 합니다. 유효한 길이만 맞췄다고 다른 밴드 순서의 값이 같은 의미가 되는 것은 아닙니다. 새 모델을 역변환해 처리 효과를 확인하십시오.

이 설명은 Stationary DB2의 WithCoefficients 호출에 적용됩니다. C#에서 얻은 독립 배열 또는 모델은 해당 소유 계약을 따르며 네이티브 소유자는 사용 후 Dispose합니다.
