구성 전체와 저장 단위를 독립 바이트 배열로 반환합니다.

반환: 복합 계측 보관 형식의 복사본입니다.

이 호출의 입력과 객체 맥락

검증된 그래프와 저장 단위를 가진 아카이브 내용을 반환합니다. 모델이 열린 동안 호출해야 하며 결과는 독립 바이트 값입니다. 이 바이트를 보관하면 나중에 FromArchiveBytes 또는 from_archive_bytes로 모델을 다시 검증해 복원할 수 있습니다. 결과 바이트를 이미지 핸들처럼 해제할 필요는 없습니다.

그래프와 단위를 함께 저장

ToArchiveBytes는 복합 모델의 검증된 그래프와 모델에 저장된 단위를 바이트 배열로 직렬화합니다. 원본 영상이나 개별 측정 실행 결과를 저장하는 호출로 해석하지 않습니다. 모델 복원과 실제 영상 평가는 별도 단계입니다.

직렬화된 데이터를 FromArchiveBytes로 읽으면 모델과 저장된 단위를 함께 얻습니다. 길이 공차를 해석할 때 저장 단위와 평가 단위가 다르면 숫자만 비교해서는 안 됩니다. 모델이 유효해도 입력 영상에서 각 특징의 검출 성공 여부는 평가 시 별도로 확인합니다.

바이트는 끝까지 보관하고 전달 과정에서 손상되거나 일부가 누락되지 않았는지 확인합니다. 복원은 그래프 검증을 수행하므로 유효하지 않은 데이터는 오류입니다. 재현할 때는 아카이브뿐 아니라 입력 영상과 측정 설정도 기록합니다.
