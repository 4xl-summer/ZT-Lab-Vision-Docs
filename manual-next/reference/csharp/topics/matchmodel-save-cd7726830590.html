void Save(System.String path)

버전 1 모델 파일을 지정 경로에 저장하며 기존 파일을 덮어씁니다.

인자

path: 비어 있지 않고 NUL이 없는 모델 파일 경로입니다.

관련 입력의 확인된 조건

불변 템플릿 모델을 소유합니다. 학습 픽셀은 독립 복사되며 사용 후 Dispose해야 합니다.

호출 맥락과 결과 해석

학습된 기본 매칭 모델을 버전 1 파일로 저장합니다. 같은 경로에 파일이 있으면 덮어쓰므로 보관할 모델을 구분하려면 경로를 명시적으로 선택해야 합니다. 저장 작업은 반환 모델을 새로 만드는 호출이 아닙니다.

이후 Load로 파일에서 모델을 복원할 수 있습니다. 모델과 함께 실제 검색 영상의 ROI와 MatchSpec을 따로 기록해야 검색 조건을 다시 구성할 수 있습니다. 저장 전에 모델 학습과 검색이 의도대로 이루어졌는지 확인하는 것이 좋습니다.

입력 선택을 위한 확인

입력의미와 조건
path비어 있지 않고 NUL이 없는 모델 파일 경로입니다.
