ToArchiveBytes

Method · 선언 타입 ZVision.CompositeModelBuilder

C#
System.Byte[] ToArchiveBytes(System.Nullable<ZVision.CompositeUnit> unit = null)

영상 측정 설정과 출력 단위를 포함하여 모델을 보관합니다.

인자

unit: 저장할 등방 단위이며 null은 픽셀입니다.

반환: 독립 버전 형식의 바이트 배열입니다.

이 호출의 입력과 객체 맥락

프레임, 고정·파생 및 이미지 측정 형상, 탐침·적합 설정과 선택적 출력 단위를 아카이브로 저장합니다. unit=null은 픽셀이고, 단위를 지정하면 양의 UnitsPerPixel이 필요합니다. 단위 ID가 0이면 배율은 1이어야 합니다. 반환은 독립 byte 배열이며 길이가 2200000바이트를 넘으면 오류입니다. 이 등방 배율은 일반적인 세계 좌표 보정과 다릅니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().

사용 순서와 판독

ToArchiveBytes는 현재 프레임·형상·공차와 영상 측정의 탐침·적합 설정, 선택 단위를 하나의 보관 형식으로 복사합니다. 예를 들어 빌더를 다시 구성하기보다 검증된 아카이브를 저장하고 모델 복원 경로로 읽을 수 있습니다.

unit=null은 픽셀이고 물리 단위를 쓰면 픽셀당 양의 등방 배율을 명시합니다. 단위 ID가 0이면 배율은 1입니다. 출력 byte 배열은 독립 값이며 이 아카이브의 단위만으로 영상의 세계 위치나 원근 왜곡이 자동 보정되지는 않습니다.
