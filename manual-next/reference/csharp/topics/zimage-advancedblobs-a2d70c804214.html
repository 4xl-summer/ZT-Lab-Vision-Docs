ZVision.AdvancedBlobResult AdvancedBlobs(ZVision.ZImage gray = null, ZVision.ZImage mask = null, System.UInt32 mode = 0, System.UInt32 foreground = 0, System.Double a = 0, System.Double b = 0, System.Double softness = 1, System.Boolean eightConnected = true, System.UInt64 maxBlobs = 18446744073709551615, System.UInt64 minArea = 1, System.UInt64 maxArea = 18446744073709551615, System.Double scaleX = 1, System.Double scaleY = 1)

이진·라벨 또는 가중 전경의 Blob을 분석합니다.

인자

gray: 강도 측정용 Gray8 영상입니다.

mask: 선택 Gray8 분석 마스크입니다.

mode: 0 연결성분, 1 라벨별, 2 접촉 라벨별, 3 전체입니다.

foreground: 0 비영, 1 영, 2 상대 임계, 3 가중 임계입니다.

a: 상대값 또는 낮은 임계입니다.

b: 높은 임계입니다.

softness: 가중 지수입니다.

eightConnected: 8연결 여부입니다.

maxBlobs: Blob 수 상한입니다.

minArea: 면적 하한입니다.

maxArea: 면적 상한입니다.

scaleX: 픽셀 x 크기입니다.

scaleY: 픽셀 y 크기입니다.

반환: 호출자가 해제하는 결과입니다.

관련 입력의 확인된 조건

AdvancedBlobResult.Count: 측정된 Blob 수입니다.

AdvancedBlobResult.MapInfo: 라벨 영상의 크기를 조회합니다. 부모 ROI 원점은 저장되지 않습니다.

AdvancedBlobResult.Width: 라벨 영상의 픽셀 너비입니다.

AdvancedBlobResult.Height: 라벨 영상의 픽셀 높이입니다.

AdvancedBlobs의 사용과 결과 해석

예를 들어 4연결과 8연결에서 대각선 픽셀의 성분 수가 달라질 수 있습니다. scaleX와 scaleY를 바꾸면 결과 측정의 축 방향 배율도 함께 해석해야 합니다. 입력 전경을 연결 성분 또는 라벨 방식으로 분석하고 Blob별 형상을 얻습니다. 전경 규칙, 연결성, 면적 한계와 단위 배율은 결과의 성분 수와 측정값에 영향을 주므로 함께 기록합니다.

항목이 호출에서 확인할 내용
gray강도 측정용 Gray8 영상입니다.
mask선택 Gray8 분석 마스크입니다.
mode0 연결성분, 1 라벨별, 2 접촉 라벨별, 3 전체입니다.
foreground0 비영, 1 영, 2 상대 임계, 3 가중 임계입니다.
a상대값 또는 낮은 임계입니다.
반환호출자가 해제하는 결과입니다.
