Dispose의 사용과 결과 해석

히스토그램 결과를 모두 읽은 뒤 소유 자원을 해제합니다. 반환된 값이 복사본인지 별도 소유 객체인지는 해당 조회 메서드의 계약을 따릅니다. 이 객체가 소유한 자원을 작업 종료 시 해제합니다. 반환된 별도 소유 객체가 있다면 그 객체의 수명도 따로 관리하며, 해제한 핸들을 다시 연산 입력으로 사용하지 않습니다.

사용 순서와 결과 보관

GapCareHistogram은 선택된 픽셀의 히스토그램 결과를 보유합니다. Dispose는 이 결과 모델의 핸들을 해제하며 이미 수행한 빈도 계산을 다시 실행하거나 입력 영상을 수정하지 않습니다. 필요한 빈도와 중앙값·최빈값을 먼저 확인한 뒤 모델이 더 이상 필요 없을 때 호출합니다.

Counts는 각 강도 구간의 빈도를 나타냅니다. ModeBin은 가장 많은 표본이 들어간 빈이고 MedianBin은 누적 빈도의 가운데에 해당하는 빈이므로 두 값이 항상 같지는 않습니다. 예를 들어 한 빈에 유난히 많은 값이 몰려 있어도 다른 빈들까지 포함한 누적 분포의 가운데는 다른 곳에 있을 수 있습니다.

반환받은 빈 배열이 독립 복사라면 모델을 닫은 뒤에도 배열을 별도로 보관할 수 있으며, 결과 숫자를 재현하려면 입력과 선택 마스크, 빈의 해석 기준을 함께 기록해야 합니다. Dispose 뒤에는 같은 모델로 새 Counts, MedianBin 또는 ModeBin 조회를 요청하지 않습니다. 반환값은 없습니다.
