C#
static ZVision.FeatureInstanceCollectionResult Find(ZVision.ZImage source, ZVision.FeatureInstanceCollectionEntry[] entries, System.UInt64 maxPerModel = 2, System.UInt64 totalHypotheses = 4096, System.UInt64 maxResults = 64, ZVision.FeatureOverlapScope scope = ZVision.FeatureOverlapScope.AllModels, System.Double maxIou = 0.5, ZVision.ZImage mask = null)

실제 모델별 반복 검색 뒤 방향 다각형 IoU 억제를 적용합니다.

인자

source: 검색 영상입니다.

entries: 고유 ID 모델 항목입니다.

maxPerModel: 모델당 인스턴스 상한입니다.

totalHypotheses: 공유 가설 예산입니다.

maxResults: 결과 상한입니다.

scope: 중복 비교 범위입니다.

maxIou: 허용 IoU입니다.

mask: 선택 검색 마스크입니다.

반환: 독립 결과와 예산 상태입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

FeatureInstanceCollectionResult.Evaluated: 평가 가설 총수입니다.

FeatureInstanceCollectionResult.Incomplete: 예산 중단 여부입니다.

호출과 결과 해석

모델별 반복 특징 검색을 수행하고 방향 다각형 IoU로 결과 겹침을 억제합니다. maxPerModel은 모델별 인스턴스 상한, totalHypotheses는 공유 가설 예산, maxResults는 전체 결과 상한입니다. scope와 maxIou가 어느 후보를 서로 비교할지와 허용 겹침을 정하므로 입력 모델 id와 함께 결과를 해석합니다.

입력별 확인

입력의미
source검색 영상입니다.
entries고유 ID 모델 항목입니다.
maxPerModel모델당 인스턴스 상한입니다.
totalHypotheses공유 가설 예산입니다.
maxResults결과 상한입니다.
scope중복 비교 범위입니다.
maxIou허용 IoU입니다.
mask선택 검색 마스크입니다.

반환값

독립 결과와 예산 상태입니다.
