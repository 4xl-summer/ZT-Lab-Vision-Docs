C#
ZVision.ExtendedMatchResult Find(ZVision.ZImage source, ZVision.ExtendedMatchOptions options, ZVision.ZImage mask = null)

모델을 검색합니다.

인자

source: 검색 영상입니다.

options: 검색 설정입니다.

mask: 선택적 마스크입니다.

반환: 독립 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ExtendedMatchResult.Matches: 점수 순서의 후보 복사본입니다.

ExtendedMatchResult.Evaluated: 평가된 포즈 수입니다.

ExtendedMatchResult.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

확장 NCC 모델을 검색 영상에 적용합니다. ExtendedMatchOptions에서 위치·각도·배율을 각각 명시된 격자로 지정하며 위치는 검색 ROI 로컬 픽셀, 각도는 라디안입니다. 모델 학습 때 지정한 템플릿 로컬 기준점이 검출 포즈를 해석하는 기준입니다.

검색 결과의 매치 목록과 종료 진단을 함께 확인합니다. 격자가 넓거나 촘촘하면 평가할 후보가 늘어나므로 CandidateBudget과 실제 평가 상태를 함께 기록합니다. 마스크를 사용하는 경우 검색 대상 영상에 맞는 마스크를 전달합니다.

입력 선택을 위한 확인

입력의미와 조건
source검색 영상입니다.
options검색 설정입니다.
mask선택적 마스크입니다.

반환값 확인

독립 결과입니다.
