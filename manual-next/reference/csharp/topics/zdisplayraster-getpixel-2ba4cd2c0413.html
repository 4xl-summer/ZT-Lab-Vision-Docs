Method · 선언 타입 ZVision.Display.ZDisplayRaster

C#
System.String GetPixel(System.Int32 x, System.Int32 y)

원본 저장 순서의 채널 값을 문자열로 읽습니다.

인자

x: 로컬 가로 좌표입니다.

y: 로컬 세로 좌표입니다.

반환: 불변 문화권 숫자를 쉼표로 연결한 문자열입니다.

사용 순서와 결과 해석

로컬 정수 픽셀의 원본 채널을 원래 저장 순서대로 읽어 불변 문화권의 쉼표 구분 문자열로 반환합니다. 예를 들어 RGB 입력은 R, G, B 순서이고 BGR 입력은 B, G, R 순서입니다. 표시용 BGRA 변환값을 읽는 CopyBgra32와 다릅니다. 좌표가 영상 밖이면 ArgumentOutOfRangeException입니다.

입력별 확인

입력의미
x로컬 가로 좌표입니다.
y로컬 세로 좌표입니다.

반환값

불변 문화권 숫자를 쉼표로 연결한 문자열입니다.
