C#
static ZVision.PhotometricResult Run(ZVision.ZImage[] images, System.Double[] lights, ZVision.PhotometricNOptions options, ZVision.ZImage mask = null)

3~128장의 조명 영상으로 반사·법선·곡률을 추정합니다.

인자

images: 같은 기하와 형식의 영상입니다.

lights: 각 영상에 대응하는 xyz 벡터의 일차원 배열입니다.

options: 검사와 출력 설정입니다.

mask: 선택적 Gray8 마스크입니다.

반환: 호출자가 해제할 독립 결과입니다.

관련 입력의 확인된 조건

options.MinSignal: 최소 반사 신호입니다.

options.MinRcond: 조명 정규 행렬 역조건수 하한입니다.

options.MinNormalZ: 곡률 계산에 필요한 법선 z 하한입니다.

options.SmoothRadius: 법선 평활 반경 픽셀입니다.

options.Brightness: 강조 영상의 평탄부 밝기입니다.

options.Contrast: 강조 영상의 형상 대비입니다.

사용과 결과 해석

같은 형식·기하의 3~128장 영상과 각각 대응하는 xyz 조명 벡터로 반사, 법선과 곡률을 추정합니다. 선택적 Gray8 마스크로 영역을 제한합니다.

lights 배열의 벡터 순서와 영상 순서를 일치시키십시오. 결과의 유효 영역을 확인하고 소유 결과는 사용 후 해제합니다.
