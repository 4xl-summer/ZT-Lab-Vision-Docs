GetHashCode의 사용과 결과 해석

해시 코드는 값의 해시 기반 컬렉션 사용을 돕습니다. 같은 해시 숫자만으로 두 정보 값이나 실제 픽셀 버퍼가 같다고 판정하지 않습니다. 영상 정보 레코드의 값 표현과 동등성 비교를 다룹니다. 문자열 표시, 해시와 필드 분해는 픽셀을 처리하는 연산이 아니며, 크기나 형식이 실제 영상과 일치하는지 별도로 확인합니다.

값 해시와 영상 내용

GetHashCode는 ImageInfo 레코드의 필드에 따른 int 해시 코드를 반환합니다. 해시 기반 컬렉션에서 값을 분류하는 데 쓰는 값이며 이미지 픽셀을 해시해 영상 내용의 동일성을 판정하는 함수가 아닙니다. 같은 해시 코드가 나와도 서로 다른 정보 값이 충돌할 수 있습니다.

예를 들어 두 영상이 모두 폭 10, 높이 8의 같은 형식이라도 픽셀 내용은 다를 수 있습니다. 반대로 두 ImageInfo가 동일한 필드 값을 갖는지는 해당 값의 동등성 비교로 확인해야 하며 해시 숫자만으로 결론을 내리지 않습니다. 가로·세로 크기, 형식과 배치 정보가 현재 다루는 영상의 것인지 별도로 확인하세요.
