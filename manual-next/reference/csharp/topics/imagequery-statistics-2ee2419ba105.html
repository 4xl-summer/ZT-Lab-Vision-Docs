Statistics의 사용과 결과 해석

평균이나 최솟값·최댓값 같은 통계는 입력에 포함된 픽셀 집합의 요약입니다. 위치별 분포를 복원하려면 원본 영상이나 다른 결과가 필요합니다. 현재 영상 단계에서 연결 성분, 히스토그램 또는 통계를 계산하는 계획입니다. 영상 전체의 통계와 선택된 영역의 통계는 다른 입력을 사용하므로 관심 영역과 설정을 같이 기록합니다.

종료 쿼리와 통계 결과

Statistics는 현재 Gray8 영상 단계에 통계 계산을 연결하는 종료 쿼리를 만듭니다. 원래 ImageQuery를 유지하면서 별도의 StatisticsQuery를 반환하므로 이 호출에서 통계 숫자를 즉시 얻는 것은 아닙니다. 반환 쿼리의 Execute가 QueryExecution<Statistics>를 만들고 Output으로 통계 값을 읽습니다.

예를 들어 현재 ROI의 픽셀이 [9,10,11]이면 count는 3, 최솟값은 9, 최댓값은 11, 산술 평균은 10입니다. 이 숫자는 해당 세 픽셀의 요약이며 각 값의 위치 정보를 보존하지 않습니다. 전체 영상의 통계와 ROI의 통계는 입력 집합이 다를 수 있으므로 관심 영역을 같이 기록하세요.

실행과 판독에서 확인

StatisticsQuery와 원래 ImageQuery는 별도 소유 객체이며 각각의 사용 범위를 관리합니다. Execute 결과도 Dispose하고, Output 통계 값은 그 반환 타입의 값 계약에 따라 사용합니다. 원래 빌더에서 추가 단계를 계획했다고 이미 생성된 통계 종료 쿼리의 의미를 추측하지 말고 실행할 계획과 분기 시점을 명시하세요.
