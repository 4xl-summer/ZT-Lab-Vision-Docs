static ZVision.SpatialSearchResult[] Search(ZVision.PointCloud[] models, ZVision.PointCloud target, ZVision.SpatialSearchOptions options)

삼점 가설과 ICP로 여러 모델의 자세를 찾습니다. 가설 예산이 제한되어 전체 탐색을 보장하지 않습니다.

인자

models: 검색할 모델 점군입니다.

target: 목표 점군입니다.

options: 가설 및 결과 허용 조건입니다.

반환: 겹침 및 RMS 순의 결과입니다.

관련 입력의 확인된 조건

target.Info: 격자 또는 점군의 메타데이터를 가져옵니다.

여러 모델의 3차원 검색

대상 점군에서 후보 모델의 자세를 탐색하고 정합 및 겹침 조건으로 후보를 걸러냅니다. 각 모델과 대상에는 충분한 유효 점이 있어야 하며 단위가 같아야 합니다. 가설 수와 결과 수는 검색 작업량과 반환 목록을 제한하므로 설정과 결과를 함께 기록합니다.

결과의 model index는 입력 모델 목록의 0부터 시작하는 위치입니다. 예를 들어 두 모델 중 두 번째가 맞으면 인덱스는 1입니다. 높은 겹침 비율과 낮은 RMS를 함께 살피고 대칭 형상이나 제한된 가설에서 놓친 자세가 있을 가능성도 검토합니다.

확인 항목해석
models와 target같은 단위의 유효 점군
max hypotheses모델 수 이상인 탐색 가설 한도
max results반환할 최대 후보 수
match모델 인덱스, 겹침 및 정합 결과
