StretchContrast의 사용과 결과 해석

명암 스트레치는 입력 강도의 범위를 출력 범위에 맞추는 과정입니다. 결과 숫자는 원래 강도와 직접 같은 의미가 아닐 수 있으므로 적용 전후의 범위를 같이 기록합니다. 명암 분포를 바꾸는 연산을 계획합니다. 전체 분포를 늘리는 방식과 히스토그램을 이용하는 방식은 같지 않으며 입력 영상의 분포와 출력 범위를 함께 비교해야 합니다.

지연 계획과 동일 빌더

StretchContrast는 Gray8 영상의 명암 범위를 확장하는 단계를 ImageQuery 계획에 추가합니다. 반환값은 계획을 갱신한 현재 빌더와 동일한 객체입니다. 이 메서드를 호출한 즉시 출력 픽셀이 생성되는 것은 아니며 실제 영상 출력은 ImageQuery.Execute로 계획을 실행해 얻습니다.

예를 들어 원본의 어두운 영역과 밝은 영역의 명암 범위가 좁다면 스트레치 전후의 범위를 비교할 수 있습니다. 같은 빌더에서 이 단계를 추가하고 다음 연산을 연결하면 순서대로 계획이 구성됩니다. 스트레치 이후 고정 임계값을 적용하면 원본 밝기와 다른 분포를 사용하게 되므로 의도한 임계값인지 다시 검증하세요.

실행과 판독에서 확인

반환된 빌더가 새 독립 객체라고 가정해 같은 객체를 두 개로 혼동하지 마세요. 독립 분기가 필요하면 해당 Clone 계약을 확인해 별도로 계획을 복제합니다. Execute가 반환하는 실행과 AcquireOutput으로 취득한 영상은 각 소유 수명에 맞게 관리합니다. 결과의 픽셀 형식, ROI와 밝기 범위를 원본과 함께 기록하세요.
