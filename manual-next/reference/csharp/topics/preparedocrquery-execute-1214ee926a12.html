Execute

Method · 선언 타입 ZVision.PreparedOcrQuery

C#
ZVision.QueryResourceExecution<ZVision.PreparedOcrResult> Execute()

계획을 실행해 OCR 준비 영상과 변환 정보을 획득할 실행을 만듭니다.

반환: Dispose해야 하는 실행입니다. AcquireOutput으로 얻은 결과도 별도로 해제합니다.

사용과 결과 해석

OCR 준비 영상과 변환 정보를 획득할 실행 객체를 만듭니다. 결과는 AcquireOutput으로 획득하며 실행과 획득한 결과를 각각 해제해야 합니다.

준비 단계는 인식된 문자열이 아닙니다. 획득한 결과의 영상과 좌표 변환을 후속 OCR 처리와 연결하십시오.

입력과 결과 확인

PreparedOcrQuery.Execute는 OCR 준비 영상과 변환 정보를 획득할 QueryResourceExecution을 만듭니다. 지연 계획을 실제로 실행한 다음 AcquireOutput으로 PreparedOcrResult를 얻으며 실행과 획득 결과는 각각 Dispose해야 합니다.

PreparedOcrResult.Info는 준비 과정의 정보 스냅샷이고 Image는 별도 소유 영상 핸들입니다. 영상도 사용 후 Dispose해야 합니다. 준비 영상의 위치를 원본 ROI와 연결할 때는 반환된 변환 정보와 원본 영상의 좌표 기준을 같이 확인하십시오.

이 단계가 반환하는 준비 영상과 변환 정보는 인식 문자열 자체가 아닙니다. 후속 OCR 결과의 문자 위치를 원본에 표시하려면 어떤 준비 영역과 변환을 사용했는지 보관해야 합니다. 실행 오류를 빈 텍스트 인식 결과로 치환하지 말고 오류와 정상 준비 결과를 구분합니다.

항목확인할 내용
계획OCR 준비의 지연 처리입니다.
Execute처리를 수행하는 실행 객체를 만듭니다.
AcquireOutputPreparedOcrResult를 별도로 획득합니다.
Info와 Image변환 정보와 독립 준비 영상을 확인합니다.
후속 OCR준비 영상과 인식 문자열을 구분합니다.
수명영상·결과·실행을 각각 Dispose합니다.

준비 영상은 후속 인식 단계에 적합한 영상이고 Info는 그 준비와 좌표 관계를 설명하는 자료입니다. 이 둘을 같은 실행에서 얻어 함께 보관해야 나중에 문자 영역을 원래 영상으로 되돌려 표시할 수 있습니다. Image를 여러 번 별도로 획득했다면 반환된 각 영상 핸들을 개별 자원으로 추적하십시오. 실행 객체를 해제하는 것과 AcquireOutput의 결과, 그 결과에서 획득한 영상을 해제하는 것은 서로 다른 정리 단계입니다.

반환된 준비 영상의 크기나 변환 정보를 확인하지 않은 채 원본 좌표에 문자 상자를 표시하면 오프셋이나 크기가 어긋날 수 있습니다. 준비 결과와 이후 OCR 결과가 같은 실행에 연결되도록 관리하십시오.
