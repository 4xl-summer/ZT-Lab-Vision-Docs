void Dispose()

소유한 네이티브 결과 핸들을 해제합니다.

사용과 결과 판독

색 보정 피팅의 네이티브 결과 핸들을 해제합니다. 보정에 사용한 패치 대응과 피팅 결과를 읽는 작업을 먼저 마치고, 이후 해당 핸들로 다시 값을 요청하지 마십시오. 별도로 얻은 값의 소유 여부는 해당 반환 계약을 따릅니다.

사용 순서와 결과 확인

ColorFitResult는 색 보정 피팅의 네이티브 결과 핸들을 소유합니다. Dispose하기 전에 필요한 결과 정보와 학습 패치별 잔차를 읽으십시오. 이 메서드는 핸들을 해제할 뿐 색 보정을 새로 적합하거나 다른 영상에 적용하지 않습니다.

Info는 피팅 메타데이터 스냅샷이고 Residuals는 학습 패치의 보정 전후 색차를 복사한 배열입니다. 각 잔차를 원래 source와 reference 패치의 대응 순서에 연결해야 어떤 표본에서 차이가 남았는지 확인할 수 있습니다.

예를 들어 두 패치를 비교할 때 첫 잔차가 작아져도 둘째 잔차가 같은 비율로 작아졌다고 가정할 수 없습니다. 집계만 보고 결론 내리기보다 보정 전후의 각 패치 값을 살피고, 학습에 쓰지 않은 패치를 별도로 평가하십시오.

필요한 Info와 Residuals를 얻은 뒤 결과를 Dispose합니다. 반환된 복사 배열과 결과 핸들은 다른 수명 경로를 가집니다. 패치의 입력 색 공간 및 보정이 선형 RGB에 적용되는 조건도 함께 기록해야 다른 실험과 비교할 수 있습니다.

단계 또는 항목확인할 내용
Info피팅 메타데이터 스냅샷입니다.
Residuals패치별 보정 전후 색차의 복사 배열입니다.
대응측정 source와 목표 reference의 순서를 보존합니다.
비교집계뿐 아니라 개별 패치 잔차를 확인합니다.
보류학습 외 패치의 결과를 따로 평가합니다.
Dispose피팅 결과 핸들을 사용 후 해제합니다.

피팅의 입력 패치가 측정 source에서 목표 reference로 가는 대응이라는 점을 유지해야 보정 전후 차이의 방향과 맥락을 재현할 수 있습니다. 패치 배열의 순서를 바꾸었다면 이전 결과의 잔차 인덱스를 새 배열에 그대로 붙이지 마십시오. Info와 Residuals를 읽은 시점의 모델과 입력 조건을 함께 기록하고, 이후 결과 핸들의 추가 조회가 더 이상 필요하지 않을 때 해제합니다.
