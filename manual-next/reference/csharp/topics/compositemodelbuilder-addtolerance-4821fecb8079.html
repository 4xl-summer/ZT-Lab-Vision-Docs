CompositeModelBuilder.AddTolerance 공개 계약

AddTolerance

Method · 선언 타입 ZVision.CompositeModelBuilder

C#
System.UInt64 AddTolerance(System.UInt64 id, ZVision.CompositeRelation relation, System.UInt64 first, System.Double minimum, System.Double maximum, System.UInt64 second = 0, System.Boolean includeMinimum = true, System.Boolean includeMaximum = true)

관계의 허용 범위를 추가합니다.

인자

id: 공차 ID입니다.

relation: 관계 종류입니다.

first: 첫 형상 인덱스입니다.

minimum: 최솟값입니다.

maximum: 최댓값입니다.

second: 둘째 형상, fixture 인덱스 또는 연속 점 개수입니다.

includeMinimum: 최솟값 포함 여부입니다.

includeMaximum: 최댓값 포함 여부입니다.

반환: 공차 인덱스입니다.

관련 입력의 확인된 조건

relation.PointLineDistance: 점의 유향 선 거리입니다.

relation.LineAngle: 두 유향 선의 각도입니다.

relation.Parallelism: 두 선의 평행 편차 각도입니다.

relation.Perpendicularity: 두 선의 직각 편차 각도입니다.

relation.PointX: ROI 로컬 x 좌표입니다.

relation.PointY: ROI 로컬 y 좌표입니다.

relation.FramePointX: 지정 fixture의 x 좌표입니다.

relation.FramePointY: 지정 fixture의 y 좌표입니다.

relation.CircleCenterDistance: 두 원 중심 거리입니다.

relation.Straightness: 연속된 점의 최소 평행 띠 폭입니다.

이 호출의 입력과 객체 맥락

relation과 first·second 참조를 사용해 평가할 허용오차를 정의합니다. minimum과 maximum은 허용 구간의 경계이며 includeMinimum과 includeMaximum은 각각 경계 포함 여부를 결정하는 bool입니다. 거리·좌표 경계는 픽셀, 각도 관계는 라디안입니다. second의 의미는 관계에 따라 두 번째 특성, 프레임 인덱스 또는 점 개수이므로 선택한 relation의 계약을 확인하세요. 반환 인덱스와 사용자 지정 id를 혼동하지 않습니다.

이 객체의 확인된 공개 생성 경로: CompositeModelBuilder().
