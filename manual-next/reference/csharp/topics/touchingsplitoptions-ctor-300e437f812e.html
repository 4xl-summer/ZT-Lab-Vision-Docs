사용과 결과 해석

접촉 객체 분할의 기본 설정을 만듭니다. 기본은 8연결, ROI 바깥을 배경으로 보는 경계, 동점 시 경계 0, X/Y 간격 1입니다.

기본 최소 정점 높이와 정점 간 거리는 1이고 최대 마커는 64입니다. 실제 간격과 객체 크기에 맞게 조정하고 ROI 경계 정책이 분할 결과에 미치는 영향을 확인하십시오.

사용 흐름과 판독 기준

이 생성자는 접촉한 전경을 나누는 데 사용할 기본 옵션을 만듭니다. 기본 연결성은 8이고 ROI 밖은 배경으로 취급하며, 같은 거리의 동점에서는 경계 라벨 0을 사용합니다. 두 축의 간격은 각각 1이므로 기본 거리 계산은 x와 y의 한 픽셀 이동을 같은 간격으로 보는 설정입니다. 생성만으로 입력 마스크의 분할을 실행하지는 않습니다.

최소 정점 높이와 정점 사이 최소 거리는 기본 1, 최대 마커 수는 64입니다. 예를 들어 두 대상이 대각선으로만 닿았다면 8연결과 4연결에서 초기 연결 관계가 달라지므로 결과 마커와 분할 라벨도 같은 결과로 가정할 수 없습니다. 실제 영상에서 x와 y의 물리 간격이 다르다면 두 간격을 목적에 맞게 설정하고 거리의 단위를 함께 기록합니다.

분할할 Gray8 마스크와 옵션을 전달한 뒤 마커, 경계 및 반환 라벨을 원본 전경과 함께 확인합니다. 동점의 0은 분할 경계를 나타내는 설정이지 원래 대상의 밝기가 0이었다는 뜻이 아닙니다. ROI 밖을 배경으로 보는 정책은 영상 테두리 근처의 거리에도 영향을 주므로 영역을 잘라 쓰는 경우 경계 조건을 실행 설정에 포함합니다.
