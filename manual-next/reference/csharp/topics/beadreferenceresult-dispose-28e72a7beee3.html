사용과 결과 판독

비드 기준 학습 결과의 네이티브 자원을 해제합니다. 결과를 사용하는 작업을 끝낸 뒤 해제하며 기준 생성 설정과 독립적으로 보관할 필요가 있는 값은 해당 반환 계약에 따라 관리하십시오. 해제된 결과를 다시 탐침 입력으로 사용하지 않습니다.

사용 순서와 결과 확인

BeadReferenceResult는 학습된 기준 경로와 새 영상의 비교 결과를 소유합니다. Dispose는 결과 핸들을 해제하므로 필요한 통계와 탐침별 배열을 먼저 얻어야 합니다. 이 객체를 해제하는 동작은 기준 모델을 새로 학습하거나 영상을 다시 검사하지 않습니다.

Info는 탐침 수와 실패 수를 나타내고 WidthErrors는 탐침별 기준 폭에서의 부호 있는 차이를 독립 배열로 복사합니다. 미검출 항목은 NaN이므로 실제 폭 차이 0과 구분하십시오. 양수와 음수의 의미는 같은 기준 폭과 검체 폭의 순서를 유지하여 읽습니다.

ReferenceFlags는 각 탐침의 사유 비트를 담습니다. 비트 1은 미검출, 2는 폭, 4는 위치, 8은 기준 폭, 16은 기준 중심을 나타냅니다. 여러 비트가 나타날 수 있으므로 하나의 번호만 보고 나머지 사유를 버리지 않도록 합니다.

ReferenceRuns는 최소 연속 탐침 수를 만족한 실패 구간의 첫·마지막 포함 인덱스와 사유를 독립 배열로 제공합니다. 배열의 인덱스를 원래 경로의 탐침 순서에 연결해 문제 구간을 찾은 뒤 결과를 Dispose하십시오.

단계 또는 항목확인할 내용
Info탐침 수와 실패 수를 읽습니다.
WidthErrors부호 있는 폭 차이, 미검출은 NaN입니다.
ReferenceFlags탐침별 미검출·폭·위치 등 사유 비트입니다.
ReferenceRuns연속 실패 구간의 포함 인덱스를 복사합니다.
좌표와 순서원래 경로의 탐침 순서와 배열을 연결합니다.
Dispose필요한 조회 후 결과 핸들을 해제합니다.

폭 차이와 실패 사유를 같이 보면 값이 존재하지만 폭 조건을 벗어난 탐침과 애초에 에지를 찾지 못한 탐침을 나눌 수 있습니다. ReferenceRuns의 첫 인덱스와 마지막 인덱스는 모두 포함되므로, 첫 값이 2이고 마지막 값이 4이면 탐침 2, 3, 4의 연속 구간입니다. 해당 구간의 플래그와 원래 경로를 보관한 뒤 결과 핸들을 해제하면 진단을 다시 확인할 수 있습니다.
