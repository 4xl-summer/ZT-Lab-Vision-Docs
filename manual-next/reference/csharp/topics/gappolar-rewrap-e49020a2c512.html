Rewrap

Method · 선언 타입 ZVision.GapPolar

C#
static ZVision.ZImage Rewrap(ZVision.ZImage image, ZVision.GapPolarOptions options, System.UInt64 width, System.UInt64 height, System.UInt64 originX = 0, System.UInt64 originY = 0, System.UInt32 revolution = 0)

선택 회전 분기의 극좌표 영상을 직교 격자로 복원합니다.

인자

image: 극좌표 영상입니다.

options: 동일한 펼침 설정입니다.

width: 출력 너비입니다.

height: 출력 높이입니다.

originX: 출력 x 원점입니다.

originY: 출력 y 원점입니다.

revolution: 선택할 회전 번호입니다.

반환: 독립 소유 영상입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

극좌표 영상을 동일한 펼침 옵션과 출력 폭·높이·원점으로 직교 격자에 복원합니다. 여러 회전 분기가 있을 수 있으므로 revolution을 명시적으로 선택합니다. 펼침과 복원의 보간·경계 때문에 임의의 영상에서 모든 원래 픽셀이 정확히 복구된다고 가정하지 마세요. 반환 영상은 독립 소유 ZImage이며 Dispose합니다.
