void Dispose()

소유한 네이티브 핸들을 해제합니다.

수명과 사용 순서

소프트웨어 PLC 인스턴스의 네이티브 핸들을 해제합니다. 필요한 명령을 완료한 다음 수명을 끝내며 실제 PLC 장치의 연결 해제와 같은 동작으로 가정하지 마십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

모의 PLC 상태와 해제

SimulatedPlc는 소프트웨어 모의 PLC의 네이티브 핸들을 소유합니다. Create는 양의 timeoutNs를 받아 객체를 만들고, Command는 명령과 요청 ID, 결과 코드 및 호출자가 제공한 현재 시각 nowNs를 사용합니다. Info는 현재 정보의 스냅샷을 반환합니다. Dispose는 이 모의 객체의 핸들을 해제합니다.

예를 들어 시간 초과 기준 1,000,000 ns는 1 ms입니다. Command에 전달하는 nowNs도 나노초 단위로 사용하며, 시간 초과는 Poll 명령에서 판정합니다. 명령 결과의 disposition과 Info의 상태를 확인한 뒤 기록할 값을 스냅샷으로 보관하세요. 모의 상태 전이와 실제 외부 장치의 연결이나 통신은 별도 대상입니다.

수명과 결과 확인

Dispose 후에는 해당 객체의 Info나 Command를 다시 사용할 수 없습니다. 필요한 모의 명령과 결과 판독을 먼저 마친 뒤 using 또는 Dispose로 핸들을 정리합니다. 이미 읽어 둔 값 스냅샷과 해제된 객체를 다시 호출하는 행동을 구분하고, 같은 테스트를 재현하려면 명령 ID와 각 nowNs를 함께 기록하세요.
