Displacements

C#
ZVision.Point2[] Displacements()

행 우선 제어점 변위의 독립 복사본을 얻습니다.

반환: 픽셀 단위 제어점 변위 배열입니다.

이 호출의 입력과 객체 맥락

Point2.X: 영역의 로컬 x 좌표입니다.

Point2.Y: 영역의 로컬 y 좌표입니다.

사용 순서와 판독

정합이 찾은 제어 격자의 각 점에 대한 변위를 행 우선 Point2 배열로 복사합니다. 예를 들어 열이 3개인 격자에서는 처음 세 값이 첫 행의 제어점입니다. 배열 값은 픽셀 단위 변위이며 점의 절대 글로벌 좌표가 아닙니다.

결과의 Found와 격자 행·열을 먼저 확인해 배열의 의미와 크기를 해석합니다. 정렬 영상이나 ValidMask를 얻는 호출은 이 배열 복사와 별개이며 해당 영상은 Dispose가 필요합니다. 반환된 Point2 배열 자체는 독립 값입니다.

예를 들어 2행 3열 제어 격자라면 복사된 값은 총 6개이며 첫 세 개 다음에 두 번째 행 세 개가 옵니다. 각 Point2의 x와 y는 해당 제어점의 두 방향 변위입니다. 이 배열만으로 모든 출력 픽셀이 유효하다고 판단하지 말고 보간 가능한 위치를 나타내는 별도의 ValidMask를 확인하세요.
