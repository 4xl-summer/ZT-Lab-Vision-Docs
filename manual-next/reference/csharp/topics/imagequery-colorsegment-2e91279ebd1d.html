ZVision.ImageQuery ColorSegment(ZVision.LabColor target, System.Double threshold)

D50 Lab 목표와의 CIE76 거리가 임계값 이하인 픽셀을 255로 표시하는 Gray8 마스크를 만듭니다.

인자

target: 비교할 D50 Lab 색입니다.

threshold: 유한한 0 이상의 CIE76 색차 상한입니다. 등호를 포함합니다.

반환: 단계가 추가된 현재 쿼리입니다.

관련 입력의 확인된 조건

target.L: CIELAB L* 좌표입니다.

target.A: CIELAB a* 좌표입니다.

target.B: CIELAB b* 좌표입니다.

인자별 입력 조건

인자형식역할과 조건
targetZVision.LabColor비교할 D50 Lab 색입니다.
thresholdSystem.Double유한한 0 이상의 CIE76 색차 상한입니다. 등호를 포함합니다.

기준 색 주변의 선택

C#의 ImageQuery 호출은 이 처리를 실행 계획에 연결합니다. 기준 Lab 색상과 허용 거리에 따라 색상을 선택하는 처리입니다. 입력의 색 표현과 참조 Lab 값의 기준 조건이 일치해야 의미 있는 색 거리를 비교할 수 있습니다. 거리 기준을 바꾸면 같은 픽셀도 선택 영역에 들어오거나 빠질 수 있습니다.

계획을 실행해 얻은 결과의 해석에서는 예를 들어 기준색과 같은 Lab 좌표는 색 거리 0입니다. 입력 조명과 변환 백색점이 다르면 실제 표면이 같아도 값이 달라질 수 있으므로 설정과 결과를 함께 보관합니다. 선택된 마스크는 제품 합격 판정 자체가 아닙니다.

이 호출은 지연 검사 계획을 구성합니다. 실행 결과와 그 출력의 소유 규칙을 반환 형식에서 확인하고 Dispose가 필요한 각 자원을 사용 후 해제합니다. 별도 분기가 필요하면 계획을 복제합니다.
