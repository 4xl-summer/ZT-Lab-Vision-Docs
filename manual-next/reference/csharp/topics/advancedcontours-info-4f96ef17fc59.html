Method · 선언 타입 ZVision.AdvancedContours

C#
ZVision.AdvancedDefectInfo Info(System.UInt64 index)

결함의 거칠기, 구멍, 지름과 대비를 반환합니다.

인자

index: 결함의 0 기반 번호입니다.

반환: 결함 진단 수치입니다.

관련 입력의 확인된 조건

AdvancedDefectInfo.Contrast: 경계 인접 배경과 전경의 평균 차이이며 배경이 없으면 null입니다.

AdvancedDefectInfo.Area: 성분 픽셀 면적입니다.

AdvancedDefectInfo.Perimeter: 경계 에지의 개수입니다.

AdvancedDefectInfo.Roughness: 둘레 제곱을 4π 면적으로 나눈 거칠기입니다.

AdvancedDefectInfo.FeretMax: 픽셀 셀 꼭짓점의 최대 Feret 지름입니다.

Info의 사용과 결과 해석

Info는 윤곽 결과의 정보를 확인하는 출발점입니다. 결함의 개수와 각 결함의 윤곽 개수는 서로 다를 수 있으므로 먼저 결과 정보를 확인하고 유효한 번호로 조회합니다. 결함 번호와 그 결함에 속한 윤곽 번호는 다른 인덱스입니다. 윤곽은 위치를 가진 순서 있는 에지들의 집합이므로 단순한 결함 면적이나 경계 사각형과 구별해 사용합니다.
