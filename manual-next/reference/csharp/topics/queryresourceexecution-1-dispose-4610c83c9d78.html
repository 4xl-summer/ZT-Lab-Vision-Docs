실행과 그 캡처를 해제합니다. 이미 획득한 결과와 이미지는 별도로 해제해야 합니다.

수명과 사용 순서

쿼리 실행 결과와 캡처를 해제합니다. 이미 획득한 공유 영상은 별도 소유이므로 각 영상도 사용 후 독립적으로 해제해야 합니다.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

실행 결과와 획득 자원

QueryResourceExecution<T>는 쿼리 실행 결과와 캡처를 소유합니다. Dispose는 이 실행을 해제합니다. T는 IDisposable이며 AcquireOutput이 반환한 결과와 GetImage가 반환한 영상은 실행과 별도로 소유하고 정리해야 합니다.

AcquireOutput은 호출할 때마다 독립 소유 결과를 획득하며 실행 해제 후에도 이미 획득한 결과는 유효합니다. GetImage는 이름 붙인 캡처의 별도 소유 ZImage를 제공합니다. 예를 들어 최종 결과와 중간 캡처를 둘 다 얻었다면 두 객체를 각각 정리합니다.

항목의미와 사용
T호출자가 Dispose할 결과 형식
AcquireOutput호출마다 독립 소유 결과
GetImage(name)별도 소유 캡처 영상
실행 Dispose실행과 자체 캡처 해제
획득 결과실행과 별도로 Dispose
닫힌 실행새 출력 획득에 사용하지 않음

실행이 열린 동안 필요한 출력과 캡처를 획득하고 각 객체의 사용 범위를 정합니다. 이후 실행을 Dispose하고 획득 결과 역시 작업 종료 후 Dispose합니다. 닫힌 실행에서 새 획득을 시도하거나 없는 캡처 이름을 쓰면 오류를 확인해야 합니다.
