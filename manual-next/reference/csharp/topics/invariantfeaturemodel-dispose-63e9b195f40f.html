사용을 마치는 순서

방향과 다중 해상도 특징을 보유한 모델을 해제합니다. Find와 Points 확인을 마친 뒤 정리하며, 다시 사용할 모델이 필요하면 ToBytes로 저장하고 FromBytes로 복원합니다. 이 바이트는 검색 영상이나 검색 옵션을 대체하지 않습니다.

다중 해상도 모델의 재사용

InvariantFeatureModel은 방향과 여러 해상도를 고려한 특징 표현을 보유합니다. Points에서 학습 특징의 위치와 배율·방향을 확인하고 Find에서 검색 영상 특징과 대응시킵니다. 더 이상 모델을 사용하는 조회나 검색이 없다면 Dispose합니다.

다시 사용할 학습 모델은 해제 전에 ToBytes로 저장하고 나중에 FromBytes로 복원할 수 있습니다. 복원 모델은 별도 소유 객체이며, 검색 영상과 기하 검증 옵션은 바이트에 대신 담긴 실행 결과가 아니므로 별도로 준비합니다.
