static ZVision.DepthMap Rasterize(ZVision.PointCloud cloud, System.UInt64 width, System.UInt64 height, ZVision.SpatialCamera camera, System.Boolean range = false, System.UInt32 collision = 0)

점군을 원근 깊이 격자로 투영합니다.

인자

cloud: 카메라 좌표 점군입니다.

width: 격자 너비입니다.

height: 격자 높이입니다.

camera: 내참수와 왜곡입니다.

range: true면 광선 거리입니다.

collision: 0 최소, 1 최대, 2 평균입니다.

반환: 호출자가 해제할 깊이 격자입니다.

관련 입력의 확인된 조건

cloud.Info: 격자 또는 점군의 메타데이터를 가져옵니다.

점군의 깊이 영상 래스터화

3차원 점을 카메라의 영상 좌표로 투영해 픽셀별 깊이 영상으로 만듭니다. 카메라 뒤쪽의 점과 영상 범위 밖에 투영된 점은 픽셀에 기록하지 않습니다. 여러 점이 같은 픽셀에 도달하면 선택한 충돌 규칙으로 하나의 값을 결정합니다.

두 점이 같은 픽셀에 투영되고 깊이가 5와 9이면 최소 규칙의 값은 5, 최대 규칙은 9, 평균 규칙은 7입니다. 빈 픽셀은 결측으로 남으므로 결과에서 점의 전체 개수와 유효 픽셀 수가 같다고 가정하지 않습니다. 출력의 단위와 frame도 함께 확인합니다.

확인 항목해석
카메라초점거리·주점·왜곡을 사용
화면 밖 또는 z≤0결과 픽셀에서 제외
충돌최소·최대·평균 중 선택
빈 픽셀결측 깊이로 표현
