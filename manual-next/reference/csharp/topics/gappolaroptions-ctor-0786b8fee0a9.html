GapPolarOptions(System.Double centerX, System.Double centerY, System.Double startAngle, System.Double endAngle, System.Double startRadius, System.Double endRadius, System.UInt64 width, System.UInt64 height, ZVision.GapPolarInterpolation interpolation = ZVision.GapPolarInterpolation.Nearest, System.Double border = 0)

극좌표 변환의 불변 설정을 만듭니다.

인자

centerX: 입력 ROI 상대 중심 x 픽셀입니다.

centerY: 입력 ROI 상대 중심 y 픽셀입니다.

startAngle: 시작 각도(라디안)입니다.

endAngle: 시작보다 큰 끝 각도(라디안)입니다.

startRadius: 0 이상의 시작 반경(픽셀)입니다.

endRadius: 시작보다 큰 끝 반경(픽셀)입니다.

width: 각도 방향 출력 픽셀 수입니다.

height: 반경 방향 출력 픽셀 수입니다.

interpolation: 샘플 보간 방식입니다.

border: ROI 밖 상수 밝기입니다.

이 호출의 입력과 객체 맥락

입력 ROI 로컬 중심과 라디안 시작·끝 각도, 픽셀 시작·끝 반경을 지정합니다. width는 각도 방향, height는 반경 방향 출력 크기이며 보간과 바깥 border도 함께 정합니다. 예를 들어 중심을 전체 프레임에서 읽었다면 ROI 원점을 고려해 로컬 좌표로 맞춘 뒤 사용하세요. 같은 옵션을 펼침과 점 변환에 일관되게 사용합니다.
