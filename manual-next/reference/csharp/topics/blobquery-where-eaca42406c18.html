Method · 선언 타입 ZVision.BlobQuery

C#
ZVision.BlobQuery Where(System.Linq.Expressions.Expression<System.Func<ZVision.Blob, System.Boolean>> predicate)

조건식으로 Blob을 필터링하도록 계획합니다. 표현식은 Blob 필드, 상수, 캡처 필드와 지원 연산자만 IR로 변환합니다. 임의 메서드 호출은 지원하지 않습니다. 표현식은 최대 깊이 64, 노드 4096개로 제한되며 정수 연산은 검사된 i128 의미를 따릅니다.

인자

predicate: Blob을 선택할 제한된 표현식 트리.

반환: 연산 계획을 갱신한 현재 빌더와 동일한 객체입니다.

Where의 사용과 결과 해석

조건식이 고르는 항목과 이후 정렬 순서는 별개입니다. 조건의 기준값과 선택 전후 개수를 기록하면 의도한 성분이 남았는지 확인할 수 있습니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.
