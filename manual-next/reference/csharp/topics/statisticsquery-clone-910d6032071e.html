ZVision.StatisticsQuery Clone()

현재 계획을 독립적으로 변경할 수 있는 새 빌더로 복제합니다.

반환: 호출자가 해제해야 하는 독립 빌더입니다.

사용과 결과 해석

현재 통계 계획을 독립적으로 변경할 수 있는 새 빌더로 복제합니다. 반환 빌더는 원본과 별도로 해제해야 합니다.

서로 다른 조건의 통계를 준비할 때 공통 계획에서 분기할 수 있습니다. 복제 자체는 계산이 아니며 각 계획은 필요한 시점에 Execute합니다.

통계 계획의 분기

StatisticsQuery.Clone은 현재 통계 계획을 독립 핸들로 복제합니다. 복제본과 원본은 별도로 Dispose하며, Clone 자체가 픽셀 통계를 계산하지는 않습니다. 실제 계산은 각각의 Execute에서 이루어집니다.

예를 들어 동일한 입력 처리에서 만든 두 계획을 서로 다른 시점에 실행해 비교할 수 있습니다. 평균이 같은 결과라도 분포는 다를 수 있습니다. 값 0과 100의 평균과 50 두 개의 평균은 모두 50이므로 필요한 다른 통계도 함께 봅니다.

항목의미와 사용
원본 계획통계 계산을 위한 지연 계획
Clone독립 StatisticsQuery 핸들
각 계획사용 후 별도로 Dispose
Execute실제 통계 계산
Output계산된 Statistics 값
비교 기준입력 ROI와 전처리 순서

Execute가 돌려주는 QueryExecution<Statistics>의 Output에서 계산 결과를 읽고 실행을 정리합니다. 원본 영상과 ROI, 앞선 처리 단계가 무엇인지 기록해야 두 실행의 통계 차이를 해석할 수 있습니다. 계획의 복제와 결과 스냅샷의 복사는 다른 단계입니다.
