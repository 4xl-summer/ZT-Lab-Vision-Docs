C#
PipelineStage(ZVision.PipelineOperation operation, System.UInt64 parameter, System.Double sigma = 0, System.Boolean enabled = true)

설정을 생성합니다. 유효 범위는 실행 시 검증합니다.

인자

operation: 단계 연산 종류입니다.

parameter: 양자화 수준 또는 홀수 커널 크기입니다.

sigma: Gaussian 단계의 양의 표준편차입니다.

enabled: 단계 실행 여부입니다.

관련 입력의 확인된 조건

operation.Gaussian: Gaussian 필터입니다.

설정과 사용 흐름

연산 종류와 매개변수, Gaussian 표준편차, 활성 여부를 담는 단계 설정을 만듭니다. parameter의 의미는 연산에 따라 양자화 수준 또는 홀수 커널 크기입니다.

Gaussian 단계에는 양의 sigma를 지정합니다. enabled가 false인 단계는 실행하지 않으며 값의 유효 범위는 실행 시 검사하므로 연산 종류에 맞게 값을 선택하십시오.
