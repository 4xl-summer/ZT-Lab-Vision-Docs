static ZVision.TouchingSplitResult Split(ZVision.ZImage image, ZVision.TouchingSplitOptions options)

거리 정점 마커를 만들고 접촉 전경을 분리합니다.

인자

image: Gray8 전경 마스크입니다.

options: 거리·정점·경계·크기·작업 설정입니다.

반환: 마커와 라벨 영상을 소유하는 결과입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

TouchingSplitResult.Markers: 원본 좌표의 GrayU32 마커 영상입니다.

TouchingSplitResult.Labels: GrayU32 결과 라벨 영상입니다.

TouchingSplitResult.MarkerCount: 선택한 마커 개수입니다.

TouchingSplitResult.RegionCount: 최소 크기 선택 후 영역 수입니다.

Split의 사용과 결과 해석

분할 처리 결과는 입력 영역을 여러 부분으로 나누는 방법과 설정에 의존합니다. 결과의 각 라벨이 원래 물체와 어떻게 대응하는지 원본과 대조합니다. 영역의 연결 구조를 반복적으로 처리하거나 골격과 그래프로 표현합니다. 반복 횟수와 수렴 상태 또는 가지 구조를 함께 확인하여 중간 결과를 완성된 구조로 단정하지 않습니다.
