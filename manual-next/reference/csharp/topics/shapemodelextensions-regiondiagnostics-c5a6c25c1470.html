static ZVision.ShapeRegionDiagnostics RegionDiagnostics(ZVision.AdvancedMatchModel model, ZVision.AdvancedMatch pose, System.Double[] region)

변환된 모델의 검색 영역 밖 면적과 특징 비율을 계산합니다.

인자

model: 형상 모델입니다.

pose: 검사할 로컬 pose입니다.

region: 포함 경계 [xmin,ymin,xmax,ymax] 픽셀입니다.

반환: 독립 진단 결과입니다.

관련 입력의 확인된 조건

model.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

ShapeRegionDiagnostics.OutsideAreaFraction: 모델 경계 사각형 중 영역 밖 면적 비율입니다.

ShapeRegionDiagnostics.OutsideFeatureFraction: 영역 밖 특징 비율입니다.

ShapeRegionDiagnostics.AnchorInside: 모델 기준점이 영역 안인지 나타냅니다.

호출 맥락과 결과 해석

선택한 매치 포즈로 변환된 모델과 region의 관계를 계산합니다. region은 검색 영상 로컬 좌표의 (xmin, ymin, xmax, ymax) 사각형이며 양 끝을 포함합니다. 결과는 바깥 면적 비율과 특징 비율, 기준점이 포함되는지 여부를 구분합니다.

기준점이 사각형 안에 있어도 변환된 모델 일부가 밖으로 나갈 수 있습니다. 따라서 기준점 포함 여부 하나만 보고 전체 형상이 영역 안에 있다고 판단하지 말고 바깥 비율을 함께 살펴야 합니다. 이 호출은 후보를 새로 검색하지 않고 전달한 포즈를 진단합니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
model형상 모델입니다.
pose검사할 로컬 pose입니다.
region포함 경계 [xmin,ymin,xmax,ymax] 픽셀입니다.
