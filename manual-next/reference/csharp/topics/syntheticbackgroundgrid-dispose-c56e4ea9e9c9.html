void Dispose()

합성 결과를 해제합니다.

수명과 사용 순서

합성 배경 격자 객체를 해제합니다. 렌더링과 중심 좌표 조회를 마친 후 호출하고, 별도로 얻은 영상이 있다면 그 영상의 수명도 관리하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

합성 격자와 출력의 정리

SyntheticBackgroundGrid는 배경 위에 투영한 표식 결과를 소유합니다. Dispose는 합성 결과 핸들을 해제합니다. 결과 영상은 별도 소유로 획득하므로 사용한 각 ZImage도 따로 Dispose해야 합니다.

Render는 원점 (0,0)의 Gray8 배경, 물리 격자, 렌즈, 대상에서 카메라로 가는 포즈, 픽셀 반경 1–32와 표식 값을 받습니다. Centers는 글로벌 픽셀 좌표의 배열을 복사합니다. 격자 행·열이나 물리 간격과 화면 픽셀 좌표를 서로 혼동하지 않습니다.

항목의미와 사용
background원점 (0,0)의 Gray8 배경
radius픽셀 공간 반경 1–32
marker표식의 Gray8 값
Centers글로벌 픽셀 좌표 복사본
결과 영상별도 소유 ZImage
Dispose합성 결과 핸들 해제

먼저 생성 결과에서 필요한 영상과 중심 좌표를 얻어 검출 실험에 사용한 다음 결과를 정리합니다. 획득한 영상을 별도로 해제하고 닫힌 결과에서 Centers나 영상을 다시 요청하지 않습니다. 합성 성공은 실제 카메라 보정의 정확도를 보증하지 않습니다.
