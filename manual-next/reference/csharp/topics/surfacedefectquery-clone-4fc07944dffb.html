ZVision.SurfaceDefectQuery Clone()

동일한 지연 계획을 독립 핸들로 복제합니다.

반환: 지연 실행할 쿼리입니다. 사용 후 Dispose해야 합니다.

사용과 결과 해석

동일한 지연 표면 결함 계획을 독립 핸들로 복제합니다. 반환 계획은 사용 후 Dispose해야 합니다.

복제 시 결함 계산을 수행하는 것은 아닙니다. 각 계획을 Execute해 결과를 얻고 반환 실행도 별도로 해제하십시오.

사용 순서와 결과 확인

SurfaceDefectQuery.Clone은 표면 결함 추출의 지연 계획을 독립 핸들로 복제합니다. 이 호출은 결함 마스크를 분석하거나 후보를 즉시 생성하지 않습니다. 실제 후보는 각 계획의 Execute가 만든 실행 결과에서 확인합니다.

실행은 결함 후보의 불변 스냅샷을 복사하며 호출자가 해제할 실행 객체를 반환합니다. 후보의 종류, 면적과 위치를 읽을 때에는 입력 ROI 및 점수 영상의 기준을 함께 보십시오. 후보가 없다는 정상 결과와 실행 실패도 별개입니다.

예를 들어 원본과 복제본의 결과를 비교하려면 각 실행이 사용한 영상과 영역 및 결함 설정을 기록해야 합니다. 복제와 실행의 시점, 입력 영상 및 설정을 함께 확인해야 결과 비교의 조건을 재현할 수 있습니다. 원본 계획, 복제 계획과 각 실행을 각각 해제합니다.

단계 또는 항목확인할 내용
원본결함 추출을 위한 지연 계획입니다.
Clone동일 처리의 독립 계획 핸들을 만듭니다.
Execute실제 결함 추출을 수행합니다.
스냅샷결함 후보의 불변 복사 결과입니다.
실행 수명각 실행을 사용 후 해제합니다.
계획 수명원본과 복제본을 각각 Dispose합니다.
