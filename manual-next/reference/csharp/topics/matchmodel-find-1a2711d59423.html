ZVision.MatchResult Find(ZVision.ZImage image, ZVision.MatchSpec spec)

검색 영상에서 모델을 찾아 네이티브 자원과 독립된 결과를 반환합니다.

인자

image: 검색할 영상의 보이는 ROI입니다.

spec: 회전, 배율, 점수와 중복 억제 설정입니다.

반환: 영상과 모델을 해제한 뒤에도 유효한 불변 스냅샷입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

MatchResult.Matches: 점수 순으로 정렬된 매치의 읽기 전용 목록입니다.

MatchResult.Best: 가장 높은 점수의 매치이며 결과가 없으면 null입니다.

호출 맥락과 결과 해석

학습하거나 복원한 기본 모델을 영상의 보이는 ROI에서 검색합니다. MatchSpec의 각도·배율 축, 최소 점수, 중심 거리와 결과 수가 함께 후보를 제한합니다. 모델 기준점은 템플릿 로컬 중심이므로 반환 위치를 해석할 때 검색 ROI 원점도 확인합니다.

예를 들어 3×2 템플릿의 기준점은 (1, 0.5)입니다. 검색 결과의 위치는 템플릿 왼쪽 위가 아니라 이 기준점이 놓인 위치입니다. 결과가 비면 검색 범위와 분산, 점수 조건과 ROI를 확인하며, 결과 값은 모델과 영상의 Dispose 후에도 독립적으로 유지됩니다.

입력 선택을 위한 확인

입력의미와 조건
image검색할 영상의 보이는 ROI입니다.
spec회전, 배율, 점수와 중복 억제 설정입니다.
