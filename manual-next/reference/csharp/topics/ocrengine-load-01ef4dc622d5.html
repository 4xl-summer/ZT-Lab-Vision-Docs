static ZVision.OcrEngine Load(System.String path)

호출자가 제공한 RTen 모델 파일을 읽어 OCR 엔진을 만듭니다. 모델은 자동 다운로드하지 않습니다.

인자

path: 외부 RTen 모델 파일 경로입니다.

반환: 사용 후 Dispose해야 하는 OCR 엔진입니다.

사용과 결과 해석

호출자가 제공한 RTen 모델 파일을 읽어 OCR 엔진을 만듭니다. 모델을 자동 다운로드하지 않으며 반환 엔진은 사용 후 Dispose해야 합니다.

모델 경로와 해당 모델의 문자·입력 계약을 준비한 뒤 Gray8 영상과 OcrSpec으로 ReadText를 호출하십시오. 모델을 읽을 수 없으면 오류를 처리해야 합니다.

모델 로드와 판독 수명

Load는 사용자가 제공한 RTen 모델 파일 경로를 읽어 OCR 엔진을 만듭니다. 이 API는 모델을 자동 다운로드하지 않습니다. 파일을 열 수 없거나 모델을 사용할 수 없는 경우 오류를 처리하고, 생성된 엔진은 호출자가 소유하므로 사용 후 Dispose해야 합니다.

엔진이 준비되면 Gray8 영상과 영역·전처리·대비·길이·문자 조건을 담은 OcrSpec으로 ReadText를 호출합니다. ReadText의 OcrRead는 독립 스냅샷이므로 엔진과 영상의 수명과 구분해 결과를 보관할 수 있습니다. 텍스트뿐 아니라 상태와 거절 사유를 확인하고 모델이 제공하는 문자 계약과 실제 입력이 맞는지도 검토하십시오.
