ZInspectionMetric(System.String name, System.TimeSpan elapsed)

단계 시간을 생성합니다.

인자

name: 단계 이름입니다.

elapsed: 경과 시간입니다.

설정과 사용 흐름

검사 단계 이름과 TimeSpan 경과 시간을 담는 측정값을 만듭니다. name으로 단계의 의미를 식별하고 elapsed로 해당 단계의 기간을 표현합니다.

서로 다른 단계 시간을 비교할 때 같은 단계 이름과 시간 단위를 사용하십시오. 이 값 자체는 결함 여부나 검사 성공을 나타내지 않습니다.

단계 이름과 경과 시간

ZInspectionMetric은 검사 단계의 name과 TimeSpan elapsed를 묶는 값입니다. 생성은 값을 기록할 뿐 해당 단계를 실행하거나 시간을 측정하지 않습니다. 결과에 기록된 단계별 시간을 읽을 때 같은 이름이 어떤 처리 단계를 가리키는지 확인하십시오.

예를 들어 elapsed가 20밀리초인 Gaussian 단계와 5밀리초인 Threshold 단계는 이름과 함께 기록해야 서로 구분됩니다. TimeSpan은 기간이며 시각 자체가 아닙니다. 단계 시간은 성능 분석 자료이고 결함 판정이나 검사 성공 여부를 대신하지 않으므로 검사 결과와 별도로 해석합니다.
