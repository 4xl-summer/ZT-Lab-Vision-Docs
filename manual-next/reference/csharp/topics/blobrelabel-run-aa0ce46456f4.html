static ZVision.AdvancedBlobResult Run(ZVision.AdvancedBlobResult source, System.UInt64 workBudget)

기존 결과 순서로 라벨을 1부터 재번호화합니다.

인자

source: 기존 Blob 결과입니다.

workBudget: 라벨 비교 및 픽셀 검사 작업 상한입니다.

반환: 호출자가 해제할 독립 결과입니다.

관련 입력의 확인된 조건

source.Count: 측정된 Blob 수입니다.

source.MapInfo: 라벨 영상의 크기를 조회합니다. 부모 ROI 원점은 저장되지 않습니다.

source.Width: 라벨 영상의 픽셀 너비입니다.

source.Height: 라벨 영상의 픽셀 높이입니다.

Run의 사용과 결과 해석

라벨 재부여 후에도 같은 물리 성분을 추적하려면 재부여 전후의 대응을 확인해야 합니다. 번호만 같은 두 결과가 항상 같은 위치를 가리키는 것은 아닙니다. 라벨은 성분을 식별하는 정수이며 픽셀 강도나 위치가 아닙니다. 라벨을 합치거나 다시 부여한 결과를 이전 라벨과 비교할 때는 번호가 유지된다고 가정하지 않습니다.
