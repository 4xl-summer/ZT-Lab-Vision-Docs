Counts의 사용과 결과 해석

각 빈의 숫자는 해당 구간에 들어간 표본 수입니다. 원래 강도 범위와 빈 수를 모르면 배열 인덱스만으로 실제 강도 구간을 완전히 알 수 없습니다. 히스토그램은 값의 범위를 구간으로 나누어 각 구간의 빈도를 집계합니다. 최빈 구간은 빈도가 가장 큰 구간이고 중앙 구간은 누적 빈도로 찾으므로 일반적으로 같지 않습니다.

호출과 결과 판독

Counts는 계산된 GapCareHistogram의 빈도를 채널 우선 일차원 UInt64 배열로 복사합니다. 각 숫자는 그 채널의 해당 빈에 들어간 표본 수이며 독립 배열을 반환합니다. 빈 인덱스만으로 실제 강도 범위를 완전히 알 수 없으므로 계산 시의 bins, lower, upper를 함께 보관합니다.

예를 들어 한 채널의 빈 수가 3이고 빈도가 [1,4,2]라면 세 빈에 포함된 표본 수의 합은 7입니다. 두 채널이라면 첫 채널의 빈들 다음에 둘째 채널의 빈들이 오는 채널 우선 순서로 읽어야 합니다. 각 빈의 수와 영상 좌표는 다른 자료입니다.

선택 마스크의 비영 픽셀만 집계하는 계산에서는 마스크의 위치와 ROI 상대 오프셋이 포함 표본에 영향을 줍니다. 복사된 배열과 히스토그램 모델 핸들은 다른 객체이므로 필요한 Counts를 읽은 뒤 모델은 Dispose하십시오.
