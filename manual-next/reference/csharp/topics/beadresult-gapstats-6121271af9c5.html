C#
ZVision.BeadGapStats GapStats(System.Double maximum, System.UInt64 maxWork, System.Double[] world = null, ZVision.ZImage worldX = null, ZVision.ZImage worldY = null)

누락 비율을 평가합니다.

인자

maximum: 최대 비율입니다.

maxWork: 작업 상한입니다.

world: 선택 affine 변환입니다.

worldX: 선택 X 맵입니다.

worldY: 선택 Y 맵입니다.

반환: 누락 통계입니다.

관련 입력의 확인된 조건

worldX.Origin: ROI의 글로벌 픽셀 원점입니다.

worldX.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BeadGapStats.IncludedLength: 포함된 경로 길이입니다.

BeadGapStats.MissingLength: 누락 경로 길이입니다.

BeadGapStats.Fraction: 누락 길이의 비율입니다.

BeadGapStats.Passed: 허용 비율 통과 여부입니다.

사용과 결과 판독

포함 경로의 누락 비율을 평가합니다. 예를 들어 전체 길이 100에 누락 길이 5이면 비율은 0.05입니다. 선택한 affine 또는 좌표 맵의 좌표계와 작업 상한을 기록하고 허용 비율과 비교하십시오.

항목확인된 역할
maximum최대 비율입니다.
maxWork작업 상한입니다.
world선택 affine 변환입니다.
worldX선택 X 맵입니다.
worldY선택 Y 맵입니다.
반환누락 통계입니다.
