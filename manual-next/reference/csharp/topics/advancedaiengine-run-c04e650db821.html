ZVision.AdvancedTensor[] Run(params ZVision.AdvancedTensor[] inputs)

모델 선언 순서대로 텐서를 전달하고 결과들을 반환합니다.

인자

inputs: 모델 입력 텐서입니다.

반환: 각각 Dispose해야 하는 결과 텐서입니다.

사용과 결과 판독

모델이 선언한 순서대로 입력 텐서를 전달합니다. 텐서 수와 크기가 같아도 서로 다른 입력을 바꾸어 넣으면 모델에 전달되는 의미가 달라집니다. 반환된 각 텐서는 독립 소유이므로 사용 후 각각 Dispose하십시오.

항목확인된 역할
inputs모델 입력 텐서입니다.
반환각각 Dispose해야 하는 결과 텐서입니다.

예를 들어 모델에 입력이 두 개라면 첫 텐서와 둘째 텐서의 순서를 모델 선언과 일치시킵니다. 반환 텐서도 해당 출력 순서로 해석해야 하며 화면 이미지라고 임의로 취급해서는 안 됩니다. 각 독립 텐서를 사용 후 해제합니다.
