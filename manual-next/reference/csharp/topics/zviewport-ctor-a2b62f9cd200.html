ZViewport()

1배 배율과 이동이 없는 뷰포트를 만듭니다.

사용 순서와 결과 해석

배율 1, PanX=0, PanY=0인 화면 변환을 만듭니다. 픽셀 중심 (0,0)은 화면 (0.5,0.5)에 놓입니다. Fit으로 영상 전체를 맞추고 ZoomAt으로 화면 앵커를 유지하면서 배율을 바꾸며 PanBy로 화면 이동량을 조절할 수 있습니다. 이 객체는 영상 픽셀을 변경하지 않습니다.

기본 좌표 변환과 화면 맞춤

생성된 뷰포트는 Scale이 1이고 PanX와 PanY가 0입니다. 영상 픽셀 중심을 화면에 옮길 때 각 축에 0.5를 더한 뒤 배율을 적용하고 화면 이동량을 더합니다. 따라서 초기 영상 픽셀 (2, 3)의 중심은 화면 (2.5, 3.5)에 표시됩니다.

Fit은 영상과 화면의 크기를 받아 전체 영상이 들어가도록 축별 비율 중 작은 값을 사용하고 남는 공간을 중앙에 배치합니다. 예를 들어 영상 100×50을 화면 200×200에 맞추면 배율은 2이고 수평 이동은 0, 수직 이동은 50입니다. 영상 데이터의 크기나 픽셀 값은 바뀌지 않습니다.

ZoomAt은 지정한 화면 앵커 아래의 영상 위치를 유지하면서 배율을 바꾸고 PanBy는 화면 단위로 이동합니다. 배율은 허용 범위로 제한되며 유한하지 않은 값이나 양수가 아닌 크기는 거부됩니다. 새 객체의 기본 배율은 화면 크기에 맞춘 결과가 아니므로, 영상과 표시 영역을 알게 된 뒤 Fit을 호출합니다.
