static ZVision.PhotometricCancellation Create()

취소되지 않은 토큰을 만듭니다.

반환: 호출자가 해제할 토큰입니다.

사용과 결과 해석

취소되지 않은 새 협력적 취소 토큰을 반환합니다. 실행을 중단할 가능성이 있는 작업에 이 토큰을 전달하고 작업과 토큰의 수명을 함께 관리합니다.

토큰을 만든 것만으로 작업이 시작되거나 취소되지 않습니다. 취소 요청은 Cancel로 하고 사용이 끝난 토큰은 Dispose하십시오.

협력적 취소와 해제

Create는 취소되지 않은 PhotometricCancellation 토큰을 만들어 반환합니다. 이 토큰은 PhotometricInspection.RunControlled에 선택적으로 전달해 장시간 다조명 검사의 중단을 요청할 때 사용합니다. 토큰을 만드는 호출만으로 검사가 시작되거나 취소되는 것은 아닙니다.

Cancel은 진행 중인 검사에 협력적 취소를 요청하고, 토큰은 재설정할 수 없습니다. 실행은 작업의 검사 지점에서 취소를 관찰하므로 Cancel이 반환된 즉시 결과가 이미 정리되었다고 가정하지 않습니다. 취소된 실행은 OperationCanceledException으로 보고될 수 있고 시간 제한은 TimeoutException으로 구분됩니다.

RunControlled의 timeoutMs는 밀리초이며 0은 시간 제한이 없음을 뜻합니다. 실행이 사용하는 동안 토큰과 입력의 수명을 관리하고, 토큰이 더 이상 필요하지 않으면 Dispose합니다. Dispose 자체는 이미 시작된 검사를 취소하지 않으므로 중단 의도는 Cancel로 명시합니다.

RunControlled는 동일 기하와 형식의 영상 네 장, 옵션 및 선택 마스크를 사용합니다. 취소 토큰과 timeoutMs는 검사 입력이 아니라 실행 제어 조건이므로 결과를 비교할 때도 이 값을 별도로 기록합니다. 취소와 시간 초과는 완료 결과로 취급하지 않고 각 예외에 따라 호출자가 처리합니다.

비교할 때 확인

취소를 요청할 가능성이 없다면 선택 인자를 생략할 수 있고, 토큰을 전달했다면 검사 측과 요청 측이 같은 토큰 상태를 참조합니다. 작업이 끝난 뒤 토큰을 해제하는 것과 작업 중 Cancel을 호출하는 것은 서로 다른 동작입니다. 두 단계의 순서를 실행 관리 코드에서 분명히 합니다.
