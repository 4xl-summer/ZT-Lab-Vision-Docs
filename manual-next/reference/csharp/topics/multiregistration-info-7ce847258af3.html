ZVision.RegistrationGraphInfo Info(System.UInt64 index)

한 영상의 공통계 변환과 유효 픽셀 수를 반환합니다.

인자

index: 영상 인덱스입니다.

반환: 독립 수치 정보입니다.

관련 입력의 확인된 조건

RegistrationGraphInfo.Matrix: 공통 로컬에서 영상 로컬로 가는 행 우선 행렬입니다.

RegistrationGraphInfo.ValidCount: 유효한 보간 픽셀 수입니다.

사용과 결과 해석

입력 영상 인덱스에 대응하는 변환 행렬과 유효 픽셀 수를 독립 수치 정보로 반환합니다. 행렬은 공통 영상 로컬 좌표에서 해당 영상 로컬 좌표로 향합니다.

ValidCount는 보간에 유효한 픽셀의 개수입니다. 전체 격자 크기와 비교해 유효 범위를 파악하되 픽셀 위치 자체가 필요하면 유효 마스크를 사용하십시오.
