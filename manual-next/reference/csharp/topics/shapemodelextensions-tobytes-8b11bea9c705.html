static System.Byte[] ToBytes(ZVision.AdvancedMatchModel model)

형상 모델을 자체 버전 및 체크섬 형식으로 직렬화합니다.

인자

model: 소유한 형상 모델입니다.

반환: 독립 바이트 배열입니다.

관련 입력의 확인된 조건

model.TrainingInfo: 학습된 표본 수와 실제 기울기 임계값입니다.

호출 맥락과 결과 해석

현재 학습된 확장 형상 모델을 버전과 체크섬이 포함된 바이트 아카이브로 만듭니다. 반환 바이트 배열은 모델과 독립된 값이므로 모델의 사용 수명과 별개로 저장할 수 있습니다. 이미지 자체를 저장하는 호출이 아니라 학습 모델을 저장하는 호출입니다.

다시 사용할 때는 대응하는 FromBytes에 완전한 바이트를 전달해 새 모델을 얻습니다. 검색 옵션과 입력 영상은 별도로 준비해야 하며, 저장과 복원 후 동일 조건으로 검색해 결과를 비교하는 방식으로 사용하는 모델의 연결을 확인할 수 있습니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
model소유한 형상 모델입니다.
