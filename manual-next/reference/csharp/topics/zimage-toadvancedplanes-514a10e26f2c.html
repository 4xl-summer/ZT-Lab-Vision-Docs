ZVision.AdvancedPlanes ToAdvancedPlanes(ZVision.AdvancedWhitePoint white, ZVision.AdvancedTransfer transfer, System.Double gamma, ZVision.AdvancedColorSpace space)

0.1.x 호환 인자로 영상의 Lab 또는 LCH 평면을 만듭니다.

인자

white: 백색점입니다.

transfer: 전달 함수입니다.

gamma: 감마 지수입니다.

space: 출력 색 공간입니다.

반환: 호출자가 해제할 평면 결과입니다.

관련 입력의 확인된 조건

transfer.Srgb: sRGB 전달 함수입니다.

transfer.Gamma: 지정한 지수로 디코딩합니다.

AdvancedPlanes.Lightness: 밝기 평면을 가져옵니다.

AdvancedPlanes.Second: 두 번째 평면을 가져옵니다.

AdvancedPlanes.Third: 세 번째 평면을 가져옵니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
whiteZVision.AdvancedWhitePoint백색점입니다.
transferZVision.AdvancedTransfer전달 함수입니다.
gammaSystem.Double감마 지수입니다.
spaceZVision.AdvancedColorSpace출력 색 공간입니다.

white의 입력 값

필드의미와 조건
D50값 0. D65 원본 백색에서 Bradford 적응을 거친 D50 기준 백색을 사용합니다.
D65값 1. sRGB 원색의 D65 기준 백색을 사용합니다.

transfer의 입력 값

필드의미와 조건
GAMMA값 2. 입력 RGB의 각 정규화 값에 지정한 양의 감마 지수를 적용합니다.
LINEAR값 1. 입력 RGB를 이미 선형인 값으로 사용합니다.
SRGB값 0. 입력 RGB에 sRGB 역전달 함수를 적용합니다.

결과와 사용 순서

호출자가 해제할 평면 결과입니다.

반환 값의 읽을 항목

항목의미
lightness첫 번째 밝기 평면을 획득합니다.
second두 번째 색 평면을 획득합니다.
third세 번째 색 평면을 획득합니다.

입력과 결과 해석

색상 처리는 채널 순서, 입력 형식과 값 범위의 영향을 받습니다. 알려진 단색 입력을 이용해 각 출력 채널이 기대한 의미를 갖는지 확인하고 서로 다른 색 공간의 값을 혼동하지 마세요.
