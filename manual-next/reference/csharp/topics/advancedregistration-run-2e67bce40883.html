static ZVision.AdvancedRegistration Run(ZVision.ZImage source, ZVision.ZImage reference, ZVision.AdvancedRegistrationOptions options)

초기 변환 근처에서 실제 영상 점수를 최적화합니다.

인자

source: 정렬할 회색 영상입니다.

reference: 기준 회색 영상입니다.

options: 변환과 최적화 설정입니다.

반환: 사용 후 해제할 등록 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

options.Projective: 원근 변환을 사용합니다. false는 affine입니다.

options.MeanSquaredError: 평균 제곱 오차를 사용합니다. false는 NCC입니다.

options.Initial: 마지막 계수 1을 생략한 행 우선 초기 행렬 8개입니다.

options.Steps: 각 계수의 초기 좌표 탐색 간격 8개입니다.

options.IterationsPerLevel: 단계별 최대 반복 횟수입니다.
