ZVision.QueryExecution<ZVision.SurfaceDefectsResult> Execute()

계획을 실행하여 결함 후보의 불변 스냅샷을 복사합니다.

반환: 호출자가 해제할 실행입니다.

사용과 결과 해석

지연 계획을 실행해 결함 후보의 불변 스냅샷을 복사한 실행 객체를 반환합니다. 호출자는 실행 객체를 해제해야 합니다.

결함 목록은 검사 조건과 함께 해석하고 별도 판정이 필요하면 해당 조건을 적용하십시오. 실행 성공 자체가 결함이 없다는 뜻은 아닙니다.

지연 계획 실행과 결과

SurfaceDefectQuery는 검사 계획을 보유하며 Execute 호출에서 실제 결함 후보를 계산합니다. 반환 QueryExecution에는 불변 결과 스냅샷이 있으며 실행 객체는 호출자가 Dispose해야 합니다. 계획 생성과 실행은 별도 단계이므로 계획이 존재한다는 사실만으로 결함 계산이 끝난 것은 아닙니다.

결함 목록의 수와 각 후보의 면적·위치를 검사 조건과 함께 해석하십시오. 예를 들어 후보가 세 개 발견되어도 허용 개수가 세 개 이상이고 면적·영역 조건을 충족하면 별도의 판정 조건을 만족할 수 있습니다. 반대로 실행 성공은 후보가 없다는 뜻이 아닙니다. 결과 확인과 판정을 마친 뒤 소유 실행을 정리합니다.
