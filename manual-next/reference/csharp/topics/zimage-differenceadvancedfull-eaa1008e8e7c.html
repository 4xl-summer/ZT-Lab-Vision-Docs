DifferenceAdvancedFull

Method · 선언 타입 ZVision.ZImage

C#
ZVision.AdvancedDifferenceResult DifferenceAdvancedFull(ZVision.ZImage reference, ZVision.AdvancedDifferenceSpec spec, ZVision.PhotometricCorrection correction, ZVision.DifferencePolarity polarity, ZVision.ZImage thresholdMap = null, ZVision.ZImage darkFrame = null, ZVision.ZImage flatFrame = null, ZVision.ZImage include = null)

공간 임계값·dark/flat과 포함 마스크·명암 보정·극성을 조합한 차분을 계산합니다.

인자

reference: 같은 형식과 좌표의 기준 영상입니다.

spec: 공간 및 질감 옵션입니다.

correction: 포함 픽셀의 명암 보정 방식입니다.

polarity: 잔차 점수의 극성입니다.

thresholdMap: 선택적 GrayF64 임계값 맵입니다.

darkFrame: 선택적 같은 형식의 dark 영상입니다.

flatFrame: 선택적 같은 형식의 flat 영상입니다.

include: 선택적 Gray8 포함 마스크입니다.

반환: 호출자가 해제할 차분 결과입니다.

관련 입력의 확인된 조건

spec.Threshold: 양의 전역 임계값입니다.

spec.TextureWeight: 음수가 아닌 질감 가중치입니다.

spec.TextureRadius: 픽셀 단위 지역 반경입니다.

spec.Texture: 질감 측정 방법입니다.

spec.Combine: 허용차 결합 방법입니다.

spec.Dark: dark 프레임이 없을 때 사용할 상수입니다.

spec.FlatTarget: flat 정규화의 양의 목표값입니다.

AdvancedDifferenceResult.Info: 선택 픽셀에서 구한 명암 보정 계수와 픽셀 수입니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
referenceZVision.ZImage같은 형식과 좌표의 기준 영상입니다.
specZVision.AdvancedDifferenceSpec공간 및 질감 옵션입니다.
correctionZVision.PhotometricCorrection포함 픽셀의 명암 보정 방식입니다.
polarityZVision.DifferencePolarity잔차 점수의 극성입니다.
thresholdMapZVision.ZImage선택적 GrayF64 임계값 맵입니다.
darkFrameZVision.ZImage선택적 같은 형식의 dark 영상입니다.
flatFrameZVision.ZImage선택적 같은 형식의 flat 영상입니다.
includeZVision.ZImage선택적 Gray8 포함 마스크입니다.

spec의 입력 값

필드의미와 조건
threshold기본 차이 허용 임계값이며 유한한 양수입니다.
texture_weight텍스처 허용량에 적용하는 유한한 0 이상 가중치입니다.
texture_radius텍스처 이웃의 반경이며 픽셀 단위입니다. 영상 경계에서 이웃은 잘립니다.
texture텍스처를 표준편차 또는 범위로 측정하도록 선택합니다.
combine기본 임계값과 텍스처 허용량을 합 또는 최대값으로 결합합니다.

correction의 입력 값

필드의미와 조건
GAIN_OFFSET선형 회귀의 배율과 편향으로 보정합니다.
NONE밝기 보정을 하지 않습니다.
OFFSET평균 차이로 편향을 보정합니다.

결과와 사용 순서

호출자가 해제할 차분 결과입니다.

입력과 결과 해석

기준과 검사 영상의 대응 위치 및 유효 영역을 먼저 확인하세요. 전체 요약값만 읽으면 위치별 차이를 놓칠 수 있으므로 결과 마스크나 세부 항목이 제공되는 경우 함께 검토합니다.
