PolarSpec(System.Double centerX, System.Double centerY, System.Double startAngle, System.Double endAngle, System.Double startRadius, System.Double endRadius, System.UInt64 width, System.UInt64 height, ZVision.Interpolation interpolation = ZVision.Interpolation.Nearest, System.Double border = 0)

극좌표 변환 설정을 만들고 범위를 검증합니다.

인자

centerX: 입력 ROI 상대 중심 x입니다.

centerY: 입력 ROI 상대 중심 y입니다.

startAngle: 시작 각도 라디안입니다.

endAngle: 끝 각도 라디안입니다.

startRadius: 시작 반경 픽셀입니다.

endRadius: 끝 반경 픽셀입니다.

width: 각도 방향 출력 크기입니다.

height: 반경 방향 출력 크기입니다.

interpolation: 최근접 또는 쌍선형 보간입니다.

border: ROI 밖 상수 밝기입니다.

관련 입력의 확인된 조건

interpolation.Nearest: 가장 가까운 픽셀을 선택하며 동률은 높은 인덱스를 선택합니다.

interpolation.Bilinear: 네 이웃을 쌍선형 보간하며 영역 밖 이웃은 경계값을 사용합니다.

설정과 사용 흐름

ROI 로컬 중심, 각도·반경 범위, 출력 크기와 보간·경계값으로 극좌표 변환을 정의합니다. 각도는 라디안, 반경은 픽셀이며 출력 너비는 각도 방향이고 높이는 반경 방향입니다.

입력 ROI 밖 샘플은 지정된 border 밝기를 사용합니다. 중심을 글로벌 좌표로 측정했다면 ROI 원점과의 차이를 반영하고, ToInput/ToOutput에 같은 설정을 사용하십시오.
