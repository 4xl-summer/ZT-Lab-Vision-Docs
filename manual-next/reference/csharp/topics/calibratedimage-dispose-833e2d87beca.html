Dispose의 사용과 결과 해석

영상과 보정의 결합 객체 사용이 끝나면 소유 핸들을 해제합니다. 이 객체가 닫힌 뒤 동일 핸들에 ROI나 워프 연산을 다시 요청하지 않습니다. 이 객체가 소유한 자원을 작업 종료 시 해제합니다. 반환된 별도 소유 객체가 있다면 그 객체의 수명도 따로 관리하며, 해제한 핸들을 다시 연산 입력으로 사용하지 않습니다.

사용 순서와 결과 보관

CalibratedImage는 영상과 글로벌 픽셀에서 세계 평면으로 가는 평면 보정을 연결한 소유 객체입니다. Dispose는 이 결합 핸들의 수명을 끝내며 렌즈 보정을 다시 학습하거나 입력 영상의 픽셀을 변형하는 호출이 아닙니다. ROI, 복사 또는 워프 결과가 필요하면 해당 객체가 열려 있을 때 필요한 연산을 수행합니다.

ROI 로컬 점은 영상의 글로벌 원점과 구분합니다. 예를 들어 원점이 (100,200)이고 로컬 점이 (10,20)이면 보정에 사용하는 글로벌 픽셀은 (110,220)입니다. 영상과 보정의 결합을 닫기 전에 필요한 정보와 별도 반환 객체를 확보하고 어떤 좌표 기준에서 세계 값을 계산했는지 보관합니다.

Copy는 보정과 원점을 유지하면서 보이는 픽셀을 독립 복사합니다. 원본 결합 객체, 복사본 및 따로 얻은 영상 핸들은 같은 소유 핸들이 아니므로 사용이 끝나면 각 반환 계약에 맞게 해제합니다. 닫힌 결합 객체로 새 ROI나 Warp를 요청하지 않습니다.
