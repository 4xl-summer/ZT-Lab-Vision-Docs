InspectQualityUnits

Method · 선언 타입 ZVision.BeadReference

C#
ZVision.BeadQualityResult InspectQualityUnits(ZVision.ZImage training, ZVision.ZImage image, ZVision.BeadQualityOptions options, ZVision.BeadCoordinateMode mode, System.Boolean[] fillLeft = null, System.Boolean[] fillRight = null, System.Double[] world = null, ZVision.ZImage worldX = null, ZVision.ZImage worldY = null)

단위를 명시하고 비드 품질을 검사합니다.

인자

training: 학습 영상입니다.

image: 검사 영상입니다.

options: 폭·중심 허용치는 선택한 단위로 지정합니다.

mode: 픽셀, 세계, 기존 자동 단위입니다.

fillLeft: 왼쪽 대체 여부입니다.

fillRight: 오른쪽 대체 여부입니다.

world: 선택적 2×3 아핀 세계 변환입니다.

worldX: 선택적 세계 X 맵입니다.

worldY: 선택적 세계 Y 맵입니다.

반환: 독립 결과입니다. 에지 좌표는 항상 ROI 로컬 픽셀이며 폭은 선택한 단위입니다.

관련 입력의 확인된 조건

training.Origin: ROI의 글로벌 픽셀 원점입니다.

training.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BeadQualityResult.Info: 탐침·구간 수와 통과 여부입니다.

BeadQualityResult.Flags: 탐침별 원인 비트입니다.

BeadQualityResult.Edges: 탐침별 선택된 좌우 에지입니다.

BeadQualityResult.FillFlags: 탐침별 보간 에지 사용 여부입니다.

BeadQualityResult.Runs: 연속 결함 구간입니다.

이 호출의 입력과 객체 맥락

options.NominalIntensity: 사용자 기준 명암을 지정했는지 확인합니다.

options.WidthNegative: 기준 폭보다 좁아지는 허용 거리입니다.

options.WidthPositive: 기준 폭보다 넓어지는 허용 거리입니다.

options.IntensityNegative: 훈련 밝기보다 어두워지는 허용치입니다.

options.IntensityPositive: 훈련 밝기보다 밝아지는 허용치입니다.

mode.LegacyAuto: 보정이 있으면 세계, 없으면 픽셀인 기존 동작입니다.

mode.Pixel: ROI 로컬 픽셀이며 보정을 지정할 수 없습니다.

mode.World: 세계 좌표이며 아핀 또는 두 좌표 맵이 반드시 필요합니다.

인자별 입력 조건

인자형식역할과 조건
trainingZVision.ZImage학습 영상입니다.
imageZVision.ZImage검사 영상입니다.
optionsZVision.BeadQualityOptions폭·중심 허용치는 선택한 단위로 지정합니다.
modeZVision.BeadCoordinateMode픽셀, 세계, 기존 자동 단위입니다.
fillLeftSystem.Boolean[]왼쪽 대체 여부입니다.
fillRightSystem.Boolean[]오른쪽 대체 여부입니다.
worldSystem.Double[]선택적 2×3 아핀 세계 변환입니다.
worldXZVision.ZImage선택적 세계 X 맵입니다.
worldYZVision.ZImage선택적 세계 Y 맵입니다.

단위를 명시한 품질 검사

픽셀 또는 세계 좌표 모드를 지정해 학습 영상과 검사 영상의 품질을 계산합니다. 세계 아핀 변환 또는 좌표 맵 쌍을 선택할 때는 해당 모드와 입력의 대응을 확인합니다.

두 맵은 서로 짝이어야 하고 아핀 변환과 맵을 동시에 전달하지 않습니다. 좌표 맵은 탐침의 ROI 로컬 격자에 맞춰야 하며 결과는 선택한 단위로 해석합니다.
