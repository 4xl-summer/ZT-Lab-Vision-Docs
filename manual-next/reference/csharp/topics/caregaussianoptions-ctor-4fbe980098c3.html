C#
CareGaussianOptions(System.UInt64 radiusX, System.UInt64 radiusY, System.Double sigmaX, System.Double sigmaY, System.Double minimumFraction = 0, System.Int64 offsetX = 0, System.Int64 offsetY = 0, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, ZVision.PixelFormat output = ZVision.PixelFormat.GrayF32, System.Double constant = 0)

설정을 생성합니다. 유효 범위는 실행 시 검증합니다.

인자

radiusX: x 방향 창 반경입니다.

radiusY: y 방향 창 반경입니다.

sigmaX: 양의 x 표준편차입니다.

sigmaY: 양의 y 표준편차입니다.

minimumFraction: 필터 적용에 필요한 마스크 표본 비율입니다.

offsetX: 영상 ROI 상대 마스크 x 원점입니다.

offsetY: 영상 ROI 상대 마스크 y 원점입니다.

border: 경계 방식입니다.

output: 출력 회색 형식입니다.

constant: 상수 경계의 밝기 값입니다.

관련 입력의 확인된 조건

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.

이 호출의 입력과 객체 맥락

output.Gray8: 8비트 부호 없는 회색 형식입니다.

output.Gray16: 16비트 부호 없는 회색 형식입니다.

output.GrayF32: 32비트 부동소수 회색 형식입니다.

output.Rgba8: 8비트 RGBA 형식입니다.

output.Bgra8: 8비트 BGRA 형식입니다.
