static ZVision.ZImage FromBgra8(System.Int32 width, System.Int32 height, System.Byte[] pixels)

8비트 BGRA 성분 배열을 복사해 새 영상을 만듭니다.

인자

width: 양의 너비(픽셀)입니다.

height: 양의 높이(픽셀)입니다.

pixels: 행 우선으로 밀집된 성분 배열입니다. 길이는 너비 × 높이 × 채널 수여야 하며 입력은 복사됩니다.

반환: 호출자가 Dispose해야 하는 새 소유 영상입니다.

호출에 필요한 입력

BGRA 순서 바이트를 복사하여 영상을 만듭니다.

인자선언된 형식확인할 내용
widthSystem.Int32양의 너비(픽셀)입니다.
heightSystem.Int32양의 높이(픽셀)입니다.
pixelsSystem.Byte[]행 우선으로 밀집된 성분 배열입니다. 길이는 너비 × 높이 × 채널 수여야 하며 입력은 복사됩니다.

결과와 사용 순서

호출자가 Dispose해야 하는 새 소유 영상입니다.

입력과 결과 해석

입력 배열의 요소 형식과 채널 수는 메서드 이름에 표시된 픽셀 형식에 맞아야 합니다. 폭과 높이, 데이터 길이를 확인하고 첫 행과 마지막 행의 값을 비교해 행 순서와 채널 순서가 의도한 영상에 대응하는지 확인하세요.
