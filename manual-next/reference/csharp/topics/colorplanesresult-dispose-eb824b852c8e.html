void Dispose()

소유한 네이티브 결과 핸들을 해제합니다.

사용과 결과 판독

색 평면 결과의 네이티브 핸들을 해제합니다. GetChannel이나 ToRgb로 얻은 영상은 독립 소유 결과이므로 평면 결과의 해제와 별도로 Dispose해야 합니다. 획득할 채널과 출력 형식을 먼저 확인하고 각 객체의 수명을 관리하십시오.

사용 순서와 결과 확인

ColorPlanesResult는 색 평면의 네이티브 결과 핸들을 소유합니다. Dispose는 이 결과 핸들을 해제합니다. GetChannel이나 ToRgb로 얻은 영상은 독립 소유이므로 결과를 해제하는 것과 별도로 각 영상을 Dispose해야 합니다.

Info는 평면 결과의 메타데이터 스냅샷입니다. GetChannel에는 0부터 2까지의 인덱스를 사용하고, 해당 인덱스가 어떤 색 성분인지 현재 색 공간과 함께 확인합니다. 세 평면이라는 이유만으로 언제나 RGB 순서라고 가정하지 마십시오.

ToRgb는 Rgb8, Bgr8, Rgb16, Bgr16 또는 RgbF32 영상을 반환하며 알파 출력은 지원하지 않습니다. 예를 들어 RGB와 BGR은 같은 세 성분을 다른 순서로 저장하므로 후속 소비자가 기대하는 형식을 명시적으로 골라야 합니다.

필요한 채널 또는 역변환 영상을 획득하고 각각의 수명을 관리한 뒤 평면 결과를 해제합니다. 획득한 영상과 결과 핸들을 하나의 소유 객체로 취급하면 사용 후 해제해야 할 영상이 남을 수 있습니다. ROI와 색 공간 정보도 결과와 함께 기록하십시오.

단계 또는 항목확인할 내용
Info색 공간 등 평면 메타데이터를 확인합니다.
GetChannel0~2 중 한 평면의 독립 영상을 얻습니다.
채널 의미현재 HSV 또는 Lab 공간에 맞게 해석합니다.
ToRgb지원되는 RGB/BGR 형식의 독립 영상을 얻습니다.
영상 수명획득한 각 영상을 별도로 Dispose합니다.
결과 Dispose평면 결과 핸들을 사용 후 해제합니다.

색 평면에서 한 채널을 가져온 뒤 같은 결과에서 다른 채널을 추가로 획득할 수 있으므로, 어떤 영상 핸들을 소유하고 있는지 각 호출의 반환값을 기준으로 추적해야 합니다. 예를 들어 세 채널을 모두 획득했다면 세 영상의 사용 종료를 각각 관리합니다. 역변환 영상도 별도 핸들이며, 결과 핸들을 닫는 순서와 무관하게 각 획득 영상의 Dispose 책임을 놓치지 않아야 합니다.
