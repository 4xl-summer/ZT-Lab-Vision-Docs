모델 전용 버전과 체크섬을 검증해 복원합니다.

인자

data: 모델 바이트입니다.

반환: 해제 가능한 모델입니다.

관련 입력의 확인된 조건

방향 정규화 다중 해상도 특징점의 소유 모델입니다.

호출 맥락과 결과 해석

직렬화된 불변 특징 모델을 복원합니다. data는 비어 있지 않고 최대 16000000바이트입니다. 검색 영상 바이트나 다른 모델의 자료를 임의로 대신 전달하지 않습니다.

복원된 모델은 호출자가 닫아야 하며 검색 조건은 별도로 준비합니다. ToBytes로 얻은 전체 데이터를 전달하고, 오류가 나면 바이트 길이와 완전성, 사용하는 모델 종류를 확인합니다.
