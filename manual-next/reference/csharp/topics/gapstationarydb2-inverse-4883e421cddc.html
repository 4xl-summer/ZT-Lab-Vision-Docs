ZVision.ZImage Inverse()

원래 ROI 원점의 GrayF64 영상을 합성합니다.

반환: 해제할 독립 영상입니다.

관련 입력의 확인된 조건

ZImage.Origin: ROI의 글로벌 픽셀 원점입니다.

ZImage.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

모델 계수를 합성하여 입력 ROI 원점을 유지하는 GrayF64 영상을 반환합니다. 숫자 계수 배열과 달리 이 결과는 소유 ZImage이므로 사용 후 Dispose합니다. 모델을 변경한 결과를 비교하려면 각 모델에서 별도 복원 영상을 얻고 같은 ROI 원점과 크기 기준으로 비교하세요. 모델 자체도 별도로 Dispose해야 합니다.

정지 DB2 변환의 복원

GapStationaryDb2.Inverse는 모델 계수를 합성해 원래 ROI 원점을 유지하는 독립 GrayF64 ZImage를 반환합니다. 계수 배열과 결과 영상은 다른 타입이며 얻은 영상과 모델은 각각 Dispose해야 합니다. 닫힌 모델의 사용은 오류를 확인합니다.

계수는 원본 밝기 배열이 아니라 여러 변환 밴드의 표현입니다. 원래 모델과 계수를 수정한 새 모델을 비교하려면 각각 Inverse를 수행하고 동일한 ROI 원점과 크기의 복원 영상을 비교합니다. 부동소수 계산 결과는 정확한 비트 일치만으로 판단하지 않습니다.

복원 영상의 Info에서 폭·높이·픽셀 형식을 확인하고 Origin으로 전체 영상 기준을 맞춥니다. 예를 들어 로컬 (10,20)과 원점 (100,200)은 전역 (110,220)에 대응합니다. 이 호환 Gap API의 입력 단계와 실제 지원 형식은 해당 변환 계약을 따릅니다.

적용과 판독을 더 살펴보기

정지 웨이블릿 모델의 밴드 계수는 원본 영상의 위치별 밝기를 그대로 복사한 것이 아닙니다. 계수를 교체하거나 세부 밴드를 축소한 모델에서 Inverse를 실행하면 변경 효과가 복원 영상에 나타날 수 있습니다. 원본 모델과 변경 모델의 결과를 비교할 때는 같은 ROI 원점과 표시 범위를 사용해야 시각화 차이와 실제 값 차이를 구분할 수 있습니다. 독립 GrayF64 출력은 별도로 Dispose하고, 모델도 더 이상 필요하지 않으면 해제합니다. 역변환이 계산에 성공해도 변경된 계수가 원래 이미지와 동일한 복원을 보장하는 것은 아니므로 필요한 허용 오차를 직접 확인합니다.
