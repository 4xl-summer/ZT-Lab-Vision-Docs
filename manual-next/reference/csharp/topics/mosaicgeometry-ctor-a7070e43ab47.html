MosaicGeometry(System.UInt64 width, System.UInt64 height, System.Double originX, System.Double originY, System.Double scale)

명시한 캔버스 기하 값을 만듭니다.

인자

width: 출력 너비 픽셀 수입니다.

height: 출력 높이 픽셀 수입니다.

originX: 공통 좌표계의 x 원점입니다.

originY: 공통 좌표계의 y 원점입니다.

scale: 공통 픽셀당 출력 픽셀 배율입니다.

설정과 사용 흐름

출력 캔버스 픽셀 너비·높이, 공통 좌표 원점과 공통 픽셀당 출력 픽셀 배율을 지정합니다. 이 값은 모자이크 영상의 좌표 해석에 사용됩니다.

예를 들어 배율 2는 공통 좌표에서 한 픽셀 간격을 출력의 두 픽셀 간격에 대응시킵니다. 원점과 크기도 함께 보존해야 다른 모자이크 결과와 위치를 비교할 수 있습니다.
