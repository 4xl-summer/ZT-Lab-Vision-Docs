Clone의 사용과 결과 해석

영역 쿼리를 복제해 다른 조건을 붙인 후 각각 실행할 수 있습니다. 결과를 비교할 때 같은 원본 영역과 좌표 기준을 사용했는지 확인합니다. 선택·정렬·분석 조건을 계획으로 구성한 후 실행합니다. 조건을 바꾸기 전 계획과 이후 계획의 관계는 해당 메서드의 반환 계약에 따르며, 결과의 항목 수와 실제 선택 조건을 함께 확인합니다.

영역 계획을 두 갈래로

RegionQuery.Clone은 같은 영역 분석 계획을 독립 핸들로 복제합니다. 원본과 복제본은 각각 사용할 수 있고 사용 후 각각 Dispose해야 합니다. 복제는 연결 성분, 윤곽 또는 다른 영역 결과를 즉시 계산하는 동작이 아닙니다.

예를 들어 공통 입력과 전처리까지 만든 영역 계획을 복제해 두 흐름의 선택 조건을 비교할 수 있습니다. 각 흐름을 실행한 뒤 실제 결과 타입과 항목을 확인하고, 결과 좌표가 어떤 ROI 기준인지 함께 기록하세요. 계획의 결과가 비어 있는 것과 실행이 오류로 끝난 것은 다르므로 두 경우를 구분합니다.

실행과 판독에서 확인

복제 시점 이후 변경한 조건을 확인할 때에는 어느 계획에 적용했는지 기록하세요. 쿼리를 실행해 얻은 결과 객체나 캡처 영상은 원본 및 복제 계획과 소유 관계가 다를 수 있습니다. 각 결과 타입의 계약에 따라 취득과 해제를 수행하고, 서로 다른 계획의 결과 인덱스를 섞어 해석하지 않습니다.
