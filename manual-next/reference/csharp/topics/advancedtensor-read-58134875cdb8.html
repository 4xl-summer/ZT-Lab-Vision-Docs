C#
System.Array Read(out System.UInt64[] shape)

텐서의 형상과 형식에 맞는 새 값 배열을 복사합니다.

인자

shape: 결과 형상입니다.

반환: float, int, sbyte 또는 byte 배열입니다.

이 호출의 입력과 객체 맥락

텐서의 축 크기를 out shape로 받고 텐서 원소 형식에 맞는 새 float, int, sbyte 또는 byte 배열을 반환합니다. 예를 들어 shape가 2×3이면 값 6개를 텐서 순서로 해석합니다. 숫자 배열과 shape는 독립 복사값이지만 텐서 객체는 별도로 Dispose해야 합니다.

텐서 값 복사

Read는 텐서의 shape를 out 인자로 반환하고 원소 형식에 맞는 관리 Array를 복사해 돌려줍니다. 반환 배열은 네이티브 텐서 핸들을 직접 가리키는 수정 창이 아닙니다.

예를 들어 shape가 (2,3)이면 원소 수는 6입니다. 배열을 해석할 때 모델이 요구하는 축의 순서도 확인해야 하며, 길이가 6이라는 사실만으로 행과 채널의 의미가 정해지지는 않습니다. 원소 형식에 따라 정수 범위와 부동소수 표현도 다릅니다.

복사한 배열과 shape는 텐서 Dispose와 수명이 다릅니다. 텐서는 사용 후 해제하고 읽은 배열이 필요하다면 관리 값으로 보관합니다. 닫힌 텐서에서 새 읽기를 요청하는 오류와 이미 복사한 데이터를 읽는 것을 구분합니다.

차원 곱은 원소 수와 대응합니다. 예를 들어 (2,3,4)는 24개 원소지만 채널 우선인지 채널 후순위인지는 숫자만으로 알 수 없으므로 모델 입출력 명세를 확인합니다.

읽은 배열을 파일이나 후처리에 전달할 때 shape와 원소 타입도 같이 보존합니다. 출력 텐서가 여러 개라면 배열 순서를 모델의 출력 순서와 연결하고, 각 텐서를 사용 후 각각 Dispose합니다.

복사된 배열을 변경해도 원래 텐서의 네이티브 내용이 바뀌는 API가 아닙니다. 입력 텐서를 새로 구성해야 한다면 요구 형식과 차원 곱을 다시 확인합니다. 예를 들어 (2,3)의 6개 값과 (3,2)의 6개 값은 수량이 같지만 축의 의미가 다릅니다.

shape를 이용해 출력을 시각화할 때도 모델의 선언된 축 순서를 확인해야 합니다. 각 배열 값이 어떤 채널이나 위치를 가리키는지는 반환된 수의 개수만으로 결정되지 않습니다.
