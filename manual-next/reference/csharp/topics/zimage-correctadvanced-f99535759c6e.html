C#
ZVision.ZImage CorrectAdvanced(ZVision.ZImage reference, ZVision.AdvancedCorrection method, System.Double varianceFloor, System.UInt64 bins, System.Double strength)

기준 영상의 평균·분산 또는 히스토그램에 상대적으로 색을 보정합니다.

인자

reference: 목표 색 분포를 가진 영상입니다.

method: 보정 방식입니다.

varianceFloor: 평균·분산 방식의 양의 분산 하한입니다.

bins: 히스토그램 방식의 구간 수입니다.

strength: 원본과 보정 결과 사이 보간 계수 [0,1]입니다.

반환: 호출자가 해제할 보정 영상입니다.

관련 입력의 확인된 조건

method.MeanVariance: 채널 평균과 분산을 맞춥니다.

method.Histogram: 채널별 히스토그램 누적분포를 맞춥니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
referenceZVision.ZImage목표 색 분포를 가진 영상입니다.
methodZVision.AdvancedCorrection보정 방식입니다.
varianceFloorSystem.Double평균·분산 방식의 양의 분산 하한입니다.
binsSystem.UInt64히스토그램 방식의 구간 수입니다.
strengthSystem.Double원본과 보정 결과 사이 보간 계수 [0,1]입니다.

method의 입력 값

필드의미와 조건
HISTOGRAM값 1. 채널별 히스토그램을 기준 영상에 맞추는 상대 색 보정을 선택합니다.
MEAN_VARIANCE값 0. 채널별 평균과 분산에 맞추는 상대 색 보정을 선택합니다.

결과와 사용 순서

호출자가 해제할 보정 영상입니다.

입력과 결과 해석

색을 비교하거나 보정하기 전 입력 색 공간, 채널 순서와 전달 특성을 확인하세요. 같은 숫자라도 색 공간과 기준 백색점이 다르면 의미가 달라질 수 있습니다. 알려진 색 표본으로 결과를 검증하세요.
