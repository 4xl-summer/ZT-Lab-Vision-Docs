System.Byte[] ToBytes()

모델을 버전·체크섬이 포함된 독립 배열로 직렬화합니다.

반환: 모델 바이트 배열입니다.

관련 입력의 확인된 조건

Harris 특징점과 정규화 패치 기술자의 소유 모델입니다.

호출 맥락과 결과 해석

학습된 특징 모델을 버전이 있는 바이트 형식으로 직렬화합니다. 반환 바이트 배열은 모델 수명과 독립되어 있어 모델 Dispose 후에도 저장할 수 있습니다. 검색 영상이나 검색 옵션이 포함된 실행 결과를 만드는 호출은 아닙니다.

동일한 모델 종류의 FromBytes로 복원한 후 검색 옵션과 영상은 따로 지정합니다. 저장과 복원 전후에 동일 입력을 사용해 Points와 검색 결과를 비교하면 모델 전달 과정을 확인할 수 있습니다.
