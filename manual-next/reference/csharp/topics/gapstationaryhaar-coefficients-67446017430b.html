Coefficients

Method · 선언 타입 ZVision.GapStationaryHaar

C#
System.Double[] Coefficients()

최종 LL 다음 각 단계 HL/LH/HH의 행 우선 계수를 복사합니다.

반환: 독립 계수 배열입니다.

이 호출의 입력과 객체 맥락

현재 모델의 계수를 행 우선 배열로 복사합니다. 반환 배열을 읽거나 수정해도 원본 모델을 제자리 변경하는 호출이 아니며, 수정한 계수를 적용한 모델이 필요하면 WithCoefficients를 사용합니다. 모델과 독립적으로 반환된 숫자 배열 자체에는 Dispose가 필요하지 않습니다. 계수 배열의 크기와 밴드 순서를 모델 계약과 함께 보관하세요. 순서는 최종 LL 다음 각 단계의 HL, LH, HH입니다.

정지 Haar 계수의 복사

Coefficients는 모델의 밴드 계수를 독립 double[]로 복사합니다. 배열 길이는 Metadata의 Width × Height × Bands입니다. 모델 핸들이 닫혀 있거나 이 길이를 관리형 배열로 나타낼 수 없으면 오류가 납니다.

예를 들어 변환 격자가 4×3이고 밴드 수가 4라면 전체 계수 수는 48입니다. 각 계수의 위치는 밴드 배치와 행 순서를 함께 읽어야 하며 원본 밝기 픽셀 배열과 같은 의미가 아닙니다. 주기 경계를 사용하는 정지 Haar 모델의 설정도 기록합니다.

항목의미와 사용
Metadata.Width / Height각 밴드의 격자 크기
Metadata.Bands계수 밴드 수
Coefficients독립 double[] 복사
WithCoefficients동일 길이·유한 값의 새 모델
Inverse독립 GrayF64 복원 영상
Dispose모델 핸들 해제

WithCoefficients는 같은 길이의 유한한 새 값을 받아 독립 모델을 만듭니다. Inverse는 원래 ROI 원점을 가진 GrayF64 영상을 반환합니다. 복사한 배열, 새 모델 및 역변환 영상의 소유 관계를 구분하고 모델을 더 이상 쓰지 않을 때 Dispose합니다.
