인자

width: 출력 너비입니다.

반환: 기본 설정입니다.

이 호출의 입력과 객체 맥락

출력 width와 height에 대한 기본 전처리 설정을 만듭니다. 이 설정은 영상을 즉시 변환하지 않으며 후속 전처리 연산에 전달합니다. 입력 모델이 요구하는 출력 크기와 선택한 전처리 옵션을 함께 확인하고 결과 텐서 형식과 혼동하지 마세요.

출력 크기의 기본 설정

AdvancedPreprocessOptions.Create(width,height)는 지정한 출력 너비와 높이를 가진 기본 전처리 설정을 만듭니다. 이는 모델 입력으로 사용할 전처리 옵션 값이며 호출 자체가 원본 영상을 변환하거나 추론을 실행하지는 않습니다. 입력 영상과 결과 텐서는 후속 전처리·추론 호출에서 다룹니다.

예를 들어 모델이 224×224 출력을 기대한다면 width=224, height=224로 기본 설정을 만듭니다. 가로 224와 세로 224는 출력 공간의 픽셀 크기이며 입력 영상이 이미 그 크기라는 뜻은 아닙니다. 실제 모델이 요구하는 형식·채널 순서와 전처리 선택이 결과 텐서와 맞는지 별도로 확인하세요.

적용과 결과 확인

같은 모델이라도 출력 크기나 입력 색상 조건이 다르면 전처리 결과가 바뀝니다. 설정을 적용한 영상 또는 텐서를 모델에 전달하기 전에 크기와 형식을 검증하고, 설정과 모델 버전을 함께 기록하세요. 이 메서드가 만든 기본값을 임의로 정규화나 크롭 방식의 보장으로 읽지 말고 해당 옵션의 실제 필드를 확인해야 합니다.

출력 크기를 결정할 때는 모델이 실제로 기대하는 입력 텐서의 가로·세로를 먼저 확인해야 합니다. 예를 들어 모델이 224×224를 요구한다면 224×224 설정은 크기 조건을 표현하지만 채널 순서나 값 범위까지 자동으로 검증한 것은 아닙니다. 영상의 종횡비가 다를 때 어떤 변환이 일어나는지도 사용한 전처리 옵션의 계약에서 확인하세요. 입력과 출력 형식을 기록하면 모델별 설정을 혼동하지 않게 됩니다. Create의 반환 설정을 실제 전처리에 전달하기 전까지 입력 영상에는 아무 출력 크기 변경도 적용되지 않습니다.
