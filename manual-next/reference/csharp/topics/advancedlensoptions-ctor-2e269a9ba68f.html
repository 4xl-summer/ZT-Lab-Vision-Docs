AdvancedLensOptions(System.UInt32 optimizeMask, System.UInt64 maxIterations, System.Double tolerance, System.Double damping)

렌즈 추정 설정을 만듭니다.

인자

optimizeMask: 선택 매개변수의 9비트 마스크입니다.

maxIterations: 최대 반복 횟수입니다.

tolerance: 수렴 허용치입니다.

damping: 초기 감쇠 계수입니다.

이 호출의 입력과 객체 맥락

AdvancedLensOptions.OptimizeMask: fx, fy, cx, cy, k1, k2, k3, p1, p2 순서의 최적화 비트입니다.

AdvancedLensOptions.Damping: 초기 양의 감쇠 계수입니다.

사용 순서와 판독

optimizeMask의 각 비트는 fx, fy, cx, cy, k1, k2, k3, p1, p2 순서의 계수 갱신 여부를 선택합니다. 선택하지 않은 계수는 초기 모델의 값을 유지하므로 변경할 항목을 관측 데이터가 뒷받침하는지 함께 확인하세요.

maxIterations는 반복 상한, tolerance는 수렴 허용치, damping은 초기 감쇠입니다. 이 값들은 서로 대체 가능한 매개변수가 아닙니다. 결과의 픽셀 재투영 RMS와 반복·수렴 상태를 함께 읽고, 수치 수렴을 실제 촬영 인수와 구분합니다.

maxIterations / tolerance반복 예산과 수렴 기준
