ZVision.AdvancedColorResult ToLab()

LCH 평면을 같은 백색점의 Lab 평면으로 되돌립니다.

반환: 호출자가 해제할 Lab 결과입니다.

LCH를 Lab으로 복원

LCH 평면을 동일 백색점의 Lab 평면 결과로 변환하고 호출자가 Dispose할 새 AdvancedColorResult를 반환합니다. 매칭 결과는 색 평면이 아니므로 이 호출에 사용할 수 없습니다.

L, a, b 평면을 원래 RGB 채널 값과 직접 동일시하지 않습니다. 원본과 변환 결과의 수명은 별개이며 각 결과를 해제합니다. 닫힌 결과를 사용하는 경우 객체 해제 오류가 발생합니다.

LCH 평면을 Lab으로 변환

ToLab은 LCH 색 평면을 같은 백색점의 Lab 평면으로 변환해 새로운 AdvancedColorResult를 반환합니다. 이 메서드는 결과를 제자리에서 바꾸지 않으며 반환 결과도 호출자가 Dispose해야 하는 소유 자원입니다.

색 매칭 결과는 색 평면이 아니므로 ToLab을 호출하면 InvalidOperationException입니다. 이미 닫힌 결과에 호출하면 ObjectDisposedException입니다. 원래 결과가 평면 변환에서 나온 것인지 매칭 연산에서 나온 것인지 먼저 확인합니다.

LCH의 L은 명도, C는 채도, H는 색상각이며 Lab은 L, a, b의 세 채널로 해석합니다. 같은 백색점을 유지하는 변환이므로 다른 백색점으로 변환한 샘플의 숫자를 조건 확인 없이 곧바로 비교하지 않습니다. 각 색 평면을 획득했다면 반환 영상도 별도로 Dispose합니다.

예를 들어 a=3, b=4인 Lab 색의 채도 크기는 5입니다. 이 관계는 성분을 이해하기 위한 계산이며 반올림과 구체적인 변환 조건을 무시한 정확도 보장은 아닙니다. 입력 결과, 변환 결과, 획득 영상의 세 수명을 구분합니다.
