static System.ValueTuple<ZVision.ZImage, ZVision.GapInpaintReport> Run(ZVision.ZImage image, ZVision.ZImage mask, System.UInt64 iterations, System.Double timestep, System.Double kappa, System.Double tolerance, ZVision.GapInpaintConductance conductance, System.Boolean nearestKnown = true)

비영 마스크 위치만 갱신하고 나머지는 고정합니다.

인자

image: Gray8/16 또는 유한 GrayF32 입력입니다.

mask: 같은 크기와 원점의 Gray8 결손 마스크입니다.

iterations: 양의 최대 반복 수입니다.

timestep: 0 초과 0.25 이하 시간 간격입니다.

kappa: 양의 밝기 차이 척도입니다.

tolerance: 비음수 변화량 정지 허용치입니다.

conductance: 전도 함수 선택입니다.

nearestKnown: 참이면 최근접 정상 픽셀로 초기화합니다.

반환: 소유 GrayF64 영상과 변화량 보고서입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

사용과 결과 해석

Gray8/16 또는 유한 GrayF32 영상에서 비영 Gray8 마스크 위치만 반복적으로 복원하고 나머지 픽셀은 고정합니다. 마스크의 크기와 원점은 영상과 같아야 합니다.

timestep은 0 초과 0.25 이하, kappa는 양수, tolerance는 비음수입니다. 출력 영상과 반복 보고서를 함께 확인하고 반환된 영상은 사용 후 해제하십시오.
