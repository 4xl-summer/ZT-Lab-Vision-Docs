ToOutput

Method · 선언 타입 ZVision.PolarSpec

C#
System.ValueTuple<System.Double, System.Double> ToOutput(System.Double x, System.Double y, System.UInt32 revolution = 0)

입력 ROI 좌표를 선택한 극좌표 출력 분기로 변환합니다.

인자

x: 입력 ROI x 좌표입니다.

y: 입력 ROI y 좌표입니다.

revolution: 선택할 회전 번호입니다.

반환: 각도 축과 반경 축 좌표입니다.

사용과 결과 해석

입력 ROI 로컬 점을 극좌표 출력의 각도 축과 반경 축 좌표로 변환합니다. revolution은 여러 회전에 걸친 표현에서 선택할 회전 번호입니다.

같은 물리 방향이 여러 회차에 나타날 수 있으므로 원하는 분기를 지정하십시오. 입력이 글로벌 좌표라면 먼저 ROI 로컬 좌표로 변환해야 합니다.

ROI 좌표와 회전 분기

ToOutput은 입력 ROI 로컬의 x, y 점을 현재 PolarSpec이 정의한 각도 축과 반경 축의 출력 좌표로 바꿉니다. 이 설정에는 ROI 상대 중심, 시작·끝 각도와 반경, 출력 너비·높이가 있습니다. 출력 너비는 각도 축, 높이는 반경 축이므로 원래 영상의 x/y 축과 같은 의미가 아닙니다.

revolution은 여러 회전에 걸친 출력에서 사용할 회차를 선택합니다. 같은 방향이 한 바퀴 이후 다시 나타날 수 있으므로 원하는 회차를 지정해야 합니다. 예를 들어 전체 영상의 점을 사용한다면 먼저 ROI 원점을 빼서 로컬 점으로 만들고, 역방향 좌표 변환에는 동일한 PolarSpec의 ToInput을 사용하십시오.
