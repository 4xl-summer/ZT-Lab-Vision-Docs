static ZVision.DataMatrixEccDiagnostics DiagnoseDataMatrixEccImage(ZVision.ZImage image, System.UInt64 maxCorrectedPerBlock)

Gray8 영상에서 Data Matrix 하나를 탐지하고 실제 RS 정정량을 계산합니다.

인자

image: Data Matrix를 포함한 Gray8 영상입니다.

maxCorrectedPerBlock: 블록별 정정량 사후 승인 상한입니다.

반환: 실제 정정 코드워드 진단입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

DataMatrixEccDiagnostics.Version: Data Matrix 버전 번호입니다.

DataMatrixEccDiagnostics.Blocks: 각 RS 블록의 정정 결과입니다.

DataMatrixEccDiagnostics.CorrectedCodewords: 실제로 수정된 전체 코드워드 수입니다.

DataMatrixEccDiagnostics.Accepted: 각 블록의 정정량이 상한을 통과했는지 나타냅니다.

인자별 입력 조건

인자형식역할과 조건
imageZVision.ZImageData Matrix를 포함한 Gray8 영상입니다.
maxCorrectedPerBlockSystem.UInt64블록별 정정량 사후 승인 상한입니다.

Data Matrix 영상 진단

Data Matrix가 포함된 Gray8 영상에서 한 심볼을 탐지해 실제 RS 정정 코드워드를 진단합니다. 이미 표본화된 모듈 격자를 받는 메서드와 입력 준비가 다릅니다.

maxCorrectedPerBlock은 블록별 사후 승인 조건입니다. 정정량은 디코더가 실제로 복원한 코드워드 수이며 인쇄 품질 인증 점수가 아닙니다.
