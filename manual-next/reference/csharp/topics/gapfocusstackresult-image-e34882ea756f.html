ZVision.ZImage Image(System.UInt32 index = 0)

결합 영상 또는 프레임 선택 지도를 얻습니다.

인자

index: 0이면 영상, 1이면 입력 프레임의 0부터 시작하는 번호 지도입니다.

반환: 해제할 독립 영상 핸들입니다.

관련 입력의 확인된 조건

ZImage.Origin: ROI의 글로벌 픽셀 원점입니다.

ZImage.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

Image의 사용과 결과 해석

초점 스택 결과 영상을 읽습니다. 합성된 출력과 각 입력 프레임을 구분하고, 결과의 ROI와 크기를 확인한 뒤 같은 위치를 비교합니다. 영상 결과를 읽을 때 출력의 크기, 픽셀 형식과 ROI 원점을 함께 확인합니다. 표시된 값이 입력 영상 그대로인지 연산 후의 결과인지 구별하고, 반환된 영상의 소유 계약에 따라 수명을 관리합니다.
