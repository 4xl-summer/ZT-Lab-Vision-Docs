Copy

Method · 선언 타입 ZVision.GapRegionCopy

C#
static System.ValueTuple<ZVision.ZImage, ZVision.GapCopyReport> Copy(ZVision.ZImage source, ZVision.ZImage destination, System.UInt64 sourceX, System.UInt64 sourceY, System.UInt64 width, System.UInt64 height, System.Int64 destinationX, System.Int64 destinationY, ZVision.ZImage mask = null, System.Boolean clip = false)

선택된 원본 픽셀을 목적 영상에 복사합니다.

인자

source: 원본 영상입니다.

destination: 기준 목적 영상입니다.

sourceX: 원본 ROI 상대 x입니다.

sourceY: 원본 ROI 상대 y입니다.

width: 복사 너비입니다.

height: 복사 높이입니다.

destinationX: 목적 ROI 상대 x입니다.

destinationY: 목적 ROI 상대 y입니다.

mask: 원본과 같은 크기·원점의 Gray8 선택 마스크 또는 null입니다.

clip: 참이면 목적 영상 밖 선택 픽셀을 건너뜁니다.

반환: 독립 영상과 복사·클리핑 수입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

Copy의 사용과 결과 해석

마스크가 제공되면 선택 위치만 복사합니다. clip을 true로 지정한 경우 목적 영상 밖의 선택 픽셀을 건너뛰며 보고서에서 복사와 클리핑 수를 확인합니다. 영역 복사와 채우기는 위치와 크기 및 선택 마스크를 기준으로 수행합니다. 원본과 목적 영상의 ROI 좌표를 각각 확인하고, 화면 밖 부분의 처리와 반환 보고서를 함께 살펴봅니다.
