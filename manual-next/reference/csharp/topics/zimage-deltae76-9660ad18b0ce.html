ZVision.ZImage DeltaE76(ZVision.LabColor target)

각 픽셀을 D50 Lab으로 변환해 목표와의 CIE76 거리를 계산합니다.

인자

target: 비교할 D50 Lab 색입니다.

반환: 독립 소유 결과입니다. 사용 후 Dispose해야 합니다.

관련 입력의 확인된 조건

target.L: CIELAB L* 좌표입니다.

target.A: CIELAB a* 좌표입니다.

target.B: CIELAB b* 좌표입니다.

호출에 필요한 입력

색상 기준 Lab 색과의 CIE76 거리를 계산합니다.

인자선언된 형식확인할 내용
targetZVision.LabColor비교할 D50 Lab 색입니다.

target의 입력 값

필드의미와 조건
lD50/2° CIELAB L* 좌표입니다.
aD50/2° CIELAB a* 좌표입니다.
bD50/2° CIELAB b* 좌표입니다.

결과와 사용 순서

독립 소유 결과입니다. 사용 후 Dispose해야 합니다.

입력과 결과 해석

색을 비교하거나 보정하기 전 입력 색 공간, 채널 순서와 전달 특성을 확인하세요. 같은 숫자라도 색 공간과 기준 백색점이 다르면 의미가 달라질 수 있습니다. 알려진 색 표본으로 결과를 검증하세요.
