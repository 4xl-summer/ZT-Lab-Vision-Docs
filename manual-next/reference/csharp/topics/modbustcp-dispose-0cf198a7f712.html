void Dispose()

연결과 네이티브 핸들을 해제합니다.

수명과 사용 순서

Modbus TCP 클라이언트가 소유한 연결과 네이티브 핸들을 해제합니다. 필요한 레지스터 읽기·쓰기 작업을 마친 뒤 호출하며, 재접속이 필요하면 종료 전에 연결 흐름을 결정하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

통신 객체의 수명

Connect가 반환한 ModbusTcp는 TCP 연결과 네이티브 핸들을 소유합니다. 필요한 보유 레지스터 읽기와 단일 레지스터 쓰기를 끝낸 뒤 Dispose로 두 자원을 해제합니다. 이 객체의 이후 읽기·쓰기·재연결 호출은 열린 핸들을 요구하므로 수명이 끝난 객체를 다시 사용하지 않습니다.

주소는 프로토콜의 0부터 시작하는 주소입니다. 예를 들어 주소 10에서 3개를 읽으면 10, 11, 12에 대응하는 값을 받습니다. 쓰기 실패 시 자동으로 재전송하지 않으며, 재접속 여부와 장치 상태를 확인해 후속 작업을 결정해야 합니다. Dispose 자체는 쓰기 성공 여부를 판정하는 동작이 아닙니다.
