Scale

Method · 선언 타입 ZVision.Affine2

C#
static ZVision.Affine2 Scale(System.Double x, System.Double y)

축별 배율 변환을 만듭니다. 0 배율은 오류입니다.

인자

x: x 방향 값입니다.

y: y 방향 값입니다.

반환: 계산된 결과입니다.

이 호출의 입력과 객체 맥락

x와 y는 각각 x축과 y축에 적용할 유한한 배율입니다. 예를 들어 (2, 3) 배율로 점 (10, 20)을 변환하면 (20, 60)이 됩니다. 두 배율을 같게 주면 두 축에 같은 비율이 적용되고 다르게 주면 축별로 다른 비율이 적용됩니다. 음수 배율은 허용되므로 부호만으로 실패라고 판단하지 않습니다. 반면 0 배율은 가역 변환을 만들 수 없어 거절됩니다. 배율을 정할 때 픽셀 좌표에 쓰는지 세계 길이에 쓰는지 별도로 구분하세요.

사용 순서와 판독

x와 y 배율은 각 축에 독립적으로 작용합니다. 예를 들어 x=2, y=0.5이면 (4,6)은 (8,3)이 됩니다. 음수는 해당 축 방향을 뒤집을 수 있지만 0은 한 축의 정보를 없애 역을 만들 수 없으므로 거절됩니다.

이동을 함께 적용하면 순서가 중요합니다. 먼저 배율을 적용한 뒤 이동할지, 먼저 이동하고 배율을 적용할지 Then의 순서로 명시하세요. 결과는 계수 값이므로 이미지의 해상도나 픽셀이 즉시 바뀌지는 않습니다.
