Method · 선언 타입 ZVision.LineScanUnitCalibration

C#
static ZVision.Point2 Unproject(ZVision.LineScanCamera camera, ZVision.Point2 pixel, ZVision.LengthUnit unit)

픽셀·라인을 물리 점으로 변환합니다.

인자

camera: 라인 스캔 모델입니다.

pixel: 픽셀과 라인입니다.

unit: 요청 물리 길이 단위입니다.

반환: 지정 단위의 점입니다.

관련 입력의 확인된 조건

camera.PixelsPerUnit: 횡방향 단위 길이당 픽셀 수입니다.

camera.CenterPixel: 객체 x=0의 횡방향 픽셀입니다.

camera.OriginY: 기준 라인에서 물체 평면 Y 좌표입니다.

camera.OriginLine: 물체 평면 기준 Y에 대응하는 라인입니다.

camera.DistancePerLine: 라인당 부호 있는 물리 이동 거리입니다.

camera.Unit: 물체 평면 거리의 단위입니다.

Point2.X: 영역의 로컬 x 좌표입니다.

Point2.Y: 영역의 로컬 y 좌표입니다.

적용과 결과 판독

라인 스캔 모델의 픽셀·라인 좌표를 요청한 길이 단위의 물리 점으로 바꿉니다. 입력 좌표가 모델이 사용하는 픽셀 및 라인 기준과 같은지 먼저 확인하십시오. 왕복을 검토할 때 동일 모델과 같은 단위를 사용해야 좌표 변환 오류와 단위 환산 차이를 분리할 수 있습니다.

입력확인된 역할
camera라인 스캔 모델입니다.
pixel픽셀과 라인입니다.
unit요청 물리 길이 단위입니다.
