Fit

C#
static ZVision.AdvancedPlanarResult Fit(ZVision.Point2[] pixels, ZVision.Point2[] world, System.Double[] weights, ZVision.AdvancedPlanarOptions options, ZVision.Point2[] validationPixels = null, ZVision.Point2[] validationWorld = null, System.Double tolerance = 0, System.Nullable<ZVision.Point2> uncertaintyPixel = null, System.Double[] inputCovariance = null)

가중치와 선택적 합의 기준으로 보정하고 별도 검증점을 평가합니다.

인자

pixels: 학습 픽셀 좌표입니다.

world: 대응 세계 좌표입니다.

weights: 양의 상대 역분산 가중치입니다.

options: 평면 보정 설정입니다.

validationPixels: 별도 검증 픽셀 좌표 또는 null입니다.

validationWorld: 대응 검증 세계 좌표 또는 null입니다.

tolerance: 검증 허용 거리입니다.

uncertaintyPixel: 공분산을 전파할 픽셀 좌표입니다.

inputCovariance: 행 우선 픽셀 입력 공분산 네 개입니다.

반환: 계수, 진단, 공분산 및 선택적 검증 결과입니다.

관련 입력의 확인된 조건

options.Model: 아핀 1 또는 투영 2입니다.

options.Unit: 세계 좌표 단위입니다.

options.MaxCandidates: 최대 합의 후보 수입니다.

options.MinInliers: 최소 인라이어 수입니다.

AdvancedPlanarResult.Coefficients: 행 우선 투영 행렬 계수입니다.

AdvancedPlanarResult.Residuals: 입력 순서의 세계 좌표 거리 잔차입니다.

AdvancedPlanarResult.Inliers: 입력 순서의 인라이어 마스크입니다.

AdvancedPlanarResult.Covariance: 행 우선 계수 공분산이며 계산할 수 없으면 null입니다.

AdvancedPlanarResult.CovarianceDimension: 공분산의 한 변 길이입니다.

AdvancedPlanarResult.Validation: 검증점을 제공한 경우의 검증 통계입니다.

적용과 결과 판독

학습 픽셀과 세계점의 같은 인덱스가 동일한 표적점을 가리켜야 합니다. 양의 상대 역분산 가중치는 각 관측의 상대 신뢰도를 나타냅니다. 검증 배열은 학습 배열과 구별하고 tolerance를 세계 길이 단위로 지정하십시오. 입력 공분산은 픽셀 좌표의 행 우선 2×2 배열이며, 반환된 계수·인라이어·잔차와 선택적 검증을 함께 읽습니다.

입력확인된 역할
pixels학습 픽셀 좌표입니다.
world대응 세계 좌표입니다.
weights양의 상대 역분산 가중치입니다.
options평면 보정 설정입니다.
validationPixels별도 검증 픽셀 좌표 또는 null입니다.
validationWorld대응 검증 세계 좌표 또는 null입니다.
tolerance검증 허용 거리입니다.
uncertaintyPixel공분산을 전파할 픽셀 좌표입니다.
