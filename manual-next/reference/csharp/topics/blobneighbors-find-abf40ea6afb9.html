Method · 선언 타입 ZVision.BlobNeighbors

C#
static ZVision.BlobNeighbor[] Find(ZVision.ZImage[] regions, System.Double maxDistance, System.UInt64 workBudget)

경계 최단거리가 상한 이내인 무순서 영역 쌍을 반환합니다.

인자

regions: 동일 크기와 원점의 비어 있지 않은 Gray8 마스크 배열입니다.

maxDistance: 0 이상의 유한 거리 상한입니다.

workBudget: 경계 스캔과 쌍 비교 상한입니다.

반환: 인덱스 순으로 정렬된 독립 이웃 쌍 배열입니다.

Find의 사용과 결과 해석

인접 관계의 두 끝은 각각 다른 성분의 식별자입니다. 성분 수가 많을 때 단일 번호만 저장하면 어떤 쌍이 가까웠는지 복원할 수 없으므로 양쪽을 기록합니다. 근접한 성분의 관계를 찾습니다. 같은 성분인지와 공간적으로 이웃하는지는 다른 관계이므로 반환된 쌍의 양쪽 라벨과 사용한 거리 또는 접촉 조건을 함께 읽습니다.
