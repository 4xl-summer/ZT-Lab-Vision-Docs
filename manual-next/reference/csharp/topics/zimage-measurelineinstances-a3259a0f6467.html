MeasureLineInstances

Method · 선언 타입 ZVision.ZImage

C#
ZVision.MeasurementInstance[] MeasureLineInstances(ZVision.MeasurementLineSpec spec, ZVision.MeasurementProbeOptions options, ZVision.InstancePlacement[] placements)

명시 배치마다 같은 선 모델을 측정합니다.

인자

spec: 배치 전 선 모델입니다.

options: 탐침 및 피팅 설정입니다.

placements: 1~64개 배치입니다.

반환: 입력 순서의 독립 결과이며 자동 배치 검색이나 중복 제거를 수행하지 않습니다.

관련 입력의 확인된 조건

spec.Start: ROI 로컬 시작점입니다.

spec.End: ROI 로컬 끝점입니다.

spec.SearchSkewRadians: 왼쪽 법선에 더하는 라디안 각도입니다.

사용과 결과 판독

명시한 1~64개 배치 각각에 같은 선 모델을 적용하고 입력 순서의 독립 결과를 돌려줍니다. 자동 배치를 찾거나 중복을 제거하지 않으므로 각 배치가 목적 물체를 가리키는지 호출자가 준비해야 합니다. 결과를 배치와 같은 인덱스로 연결하고, 각 인스턴스의 프로브 상태와 형상 적합을 따로 확인하십시오.

입력역할
spec배치 전 선 모델입니다.
options탐침 및 피팅 설정입니다.
placements1~64개 배치입니다.
