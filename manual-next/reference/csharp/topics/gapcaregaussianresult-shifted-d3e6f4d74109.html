ZVision.GapCareGaussianResult Shifted(System.Int32 shift)

정수 Gaussian 결과를 비트 이동합니다.

인자

shift: -7..7이며 양수는 포화, 음수는 하위 비트 버림입니다.

반환: 해제할 독립 결과입니다.

이 호출의 입력과 객체 맥락

Gray8 또는 Gray16 정수 Gaussian 결과에 −7~7 비트 이동을 적용한 독립 결과를 만듭니다. 양수는 왼쪽 이동 후 형식 범위에 포화되고 음수는 오른쪽으로 이동해 하위 비트를 버립니다. 예를 들어 5를 한 비트 오른쪽으로 이동하면 2입니다. 부동소수 결과에도 적용된다고 가정하지 마세요. 원래 결과와 새 결과는 별도 소유 객체입니다. 사용 후 각 결과를 Dispose합니다.

입력과 결과 확인

Shifted는 완료된 정수 Gaussian 결과에 −7부터 7까지의 비트 이동을 적용한 독립 결과를 만듭니다. 양수는 왼쪽으로 이동한 뒤 픽셀 형식 범위에 포화하고 음수는 오른쪽으로 이동하여 하위 비트를 버립니다. 원본 결과를 제자리에서 바꾸는 호출이 아닙니다.

예를 들어 값 5를 한 비트 오른쪽으로 옮기면 2진수 101에서 마지막 비트가 버려져 2입니다. 반대로 양수 이동에서는 결과가 형식의 최대를 넘으면 포화되므로 단순한 무제한 정수 곱셈과 다릅니다. 이동량 0은 비트를 이동하지 않는 설정입니다.

이 경로는 Gray8 또는 Gray16 정수 결과를 대상으로 하며 부동소수 결과에도 같은 방식이 적용된다고 가정하지 마십시오. 결과 영상과 계산 마스크를 획득한 경우 각 영상 핸들의 소유권도 별도입니다. 원래 결과와 이동 결과를 각각 사용 후 Dispose합니다.

항목확인할 내용
shift 범위−7~7의 정수입니다.
양수왼쪽 이동 후 해당 형식의 범위에 포화합니다.
음수오른쪽 이동으로 하위 비트를 버립니다.
예시5를 한 비트 오른쪽으로 이동하면 2입니다.
반환원본과 독립된 새 결과입니다.
수명두 결과와 획득 영상을 각각 정리합니다.

예를 들어 Gray8 값 200을 한 비트 왼쪽으로 이동할 때 산술상 값은 400이지만 출력 형식의 최대 255를 넘으므로 255로 포화합니다. 반면 같은 입력을 오른쪽으로 한 비트 이동하면 낮은 비트를 버린 100입니다. 이 계산은 정수 형식과 이동 방향을 명확히 한 예이며, 필터 결과의 원래 값과 이동 후 결과를 비교할 때 사용한 shift도 함께 보존해야 합니다.

결과를 표시할 때는 먼저 입력 결과가 Gray8인지 Gray16인지 확인하고, 이동량과 함께 원본 값을 보관해야 포화 또는 비트 버림의 영향을 재현할 수 있습니다.

이동된 결과는 원본과 독립적으로 해제합니다.
