Execute의 사용과 결과 해석

실행을 호출하면 그동안 쌓인 계획을 실제 입력에 적용합니다. 반환된 실행 객체에서 필요한 출력을 얻고 사용을 마친 소유 객체는 각각 해제합니다. 계획을 실행한 결과와 그 결과에서 얻은 영상의 소유 관계를 구분합니다. 결과 객체의 수명과 별도로 반환된 영상 핸들의 계약을 확인하고, 캡처 이름을 사용하는 호출은 실제 등록한 이름과 맞춰야 합니다.

이미지 계획 실행

ImageQuery.Execute는 쌓인 영상 처리 단계를 실행하고 출력과 캡처를 가진 실행 객체를 만듭니다. 계획을 구성하는 동안과 실제 픽셀을 평가하는 시점은 다릅니다. 유효한 계획 형식이라도 입력 상태나 처리 조건 때문에 실행 오류가 날 수 있습니다.
