static ZVision.Affine2 Translation(System.Double x, System.Double y)

원점 기준 평행 이동 변환을 만듭니다.

인자

x: x 방향 값입니다.

y: y 방향 값입니다.

반환: 계산된 결과입니다.

이 호출의 입력과 객체 맥락

x와 y는 각각 x·y 방향의 유한한 이동량입니다. 양의 x는 입력 x에 더해지고 양의 y는 입력 y에 더해집니다. 예를 들어 이동량이 (3, 4)이고 점이 (10, 20)이면 적용 결과는 (13, 24)입니다. 값의 단위는 변환을 적용하는 좌표의 단위를 따르며, 픽셀 이동량을 자동으로 mm로 바꾸지 않습니다. 이 팩터리는 변환 계수 값만 만들고 영상의 픽셀을 즉시 이동시키지 않습니다. 실제 이미지를 바꾸려면 해당 영상 워프 API와 출력 기하를 별도로 지정해야 합니다.

사용 순서와 판독

평행 이동은 두 좌표에 각각 일정한 값을 더하는 변환입니다. 같은 이동을 두 점에 적용하면 두 점 사이의 차이는 변하지 않습니다. 예를 들어 (1,2)와 (5,2)에 (3,4)를 적용하면 각각 (4,6), (8,6)이 되어 두 점의 x 차이는 여전히 4입니다.

이 값은 이후 점 Transform이나 변환 합성에 사용할 수 있습니다. ROI 로컬을 글로벌 픽셀로 옮길 때는 실제 이미지 원점을 이동량으로 사용하고, 세계 길이로 바꾸는 보정 행렬과 같은 역할로 취급하지 마세요.
