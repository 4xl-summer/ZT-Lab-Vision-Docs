CIEDE2000 거리 설정

kL, kC, kH로 명도, 채도 및 색상 계수를 지정해 ColorDistance 값을 만듭니다. 이 설정은 비교 연산에 전달하며 객체 생성 시 두 색의 거리를 계산하지 않습니다.

예를 들어 서로 다른 계수로 계산한 색차를 비교할 때에는 각 설정을 함께 확인해야 합니다. 값 타입인 설정과 결과 영상의 소유 수명은 별개이며 색 변환 백색점도 일치시킵니다.
