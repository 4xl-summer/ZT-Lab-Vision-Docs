Method · 선언 타입 ZVision.GapGeneralSpectrum

C#
static ZVision.GapGeneralSpectrum FromParts(System.UInt64 width, System.UInt64 height, System.Double[] real, System.Double[] imaginary, ZVision.FftNormalization normalization = ZVision.FftNormalization.Backward)

외부 실수·허수 스펙트럼을 복사합니다.

인자

width: 너비입니다.

height: 높이입니다.

real: 실수부 행 우선 배열입니다.

imaginary: 허수부 행 우선 배열입니다.

normalization: 정규화 방식입니다.

반환: 해제할 독립 스펙트럼입니다.

관련 입력의 확인된 조건

normalization.Backward: 정방향 미정규화, 역방향 1/N입니다.

normalization.Orthonormal: 양방향 1/sqrt(N)입니다.

이 호출의 입력과 객체 맥락

행 우선 실수부와 허수부를 너비·높이와 정규화 방식과 함께 복사해 새 스펙트럼을 만듭니다. 예를 들어 2×3 스펙트럼이면 각 배열의 좌표를 같은 행 우선 순서로 대응시켜야 합니다. 입력 배열과 반환 모델은 별도로 관리하며, 복소 역변환 결과가 필요할 때 InverseComplex를 사용합니다. 반환 모델은 Dispose해야 하는 소유 객체입니다.
