static ZVision.AdvancedMatchReport Find(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, ZVision.AdvancedPosePrior prior, ZVision.ZImage mask = null)

기준 pose의 위치·각도 오프셋과 축 배율 비율로 NCC 모델을 검색합니다.

인자

source: 검색 회색 영상입니다.

model: NCC 템플릿 모델입니다.

options: 상대 X/Y 오프셋·각도와 양의 배율 범위입니다. 호출 중 설정 객체를 수정하지 마세요.

prior: 원본 영상 로컬 기준 pose입니다.

mask: 선택 검색 마스크입니다.

반환: 절대 로컬 pose와 종료 진단입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

호출 맥락과 결과 해석

prior 포즈를 기준으로 위치와 각도의 오프셋, 배율의 비율 격자를 검색합니다. 절대 좌표 격자를 그대로 해석하는 검색과 달리 설정값을 기준 포즈와의 관계로 읽어야 합니다. 기준이 달라지면 같은 상대 격자도 다른 포즈들을 나타냅니다.

예상 포즈와 오프셋 범위를 함께 보관해야 같은 검색을 재현할 수 있습니다. 결과는 독립 스냅샷이고 종료 진단도 포함하므로, 후보가 없으면 기준 포즈와 상대 범위 및 검색 조건을 차례로 확인합니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력 선택을 위한 확인

입력의미
source검색 회색 영상입니다.
modelNCC 템플릿 모델입니다.
options상대 X/Y 오프셋·각도와 양의 배율 범위입니다. 호출 중 설정 객체를 수정하지 마세요.
prior원본 영상 로컬 기준 pose입니다.
mask선택 검색 마스크입니다.
