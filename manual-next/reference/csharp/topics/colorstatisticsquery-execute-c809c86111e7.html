ZVision.QueryExecution<ZVision.ColorStatistics> Execute()

계획을 실행하여 색상 통계를 복사합니다.

반환: 호출자가 해제할 실행입니다.

사용과 결과 판독

지연 색 통계 계획을 실행해 통계를 복사합니다. 반환 실행은 호출자가 해제합니다. 통계의 채널과 입력 ROI가 어느 색 공간에 속하는지 함께 기록하면 다른 실행의 숫자와 잘못 비교하는 일을 피할 수 있습니다.

항목확인된 역할
반환호출자가 해제할 실행입니다.

계산된 통계의 각 값은 선택한 색 공간의 성분과 입력 영상 영역에 대응합니다. 다른 프레임과 비교할 때 채널 순서, 영역 크기와 전처리 조건을 함께 확인하고 실행 객체는 사용 후 해제합니다.

호출과 결과 판독

ColorStatisticsQuery.Execute는 지연 색 통계 계획을 실행하고 QueryExecution<ColorStatistics>를 반환합니다. 통계는 실행 결과에서 복사한 값 스냅샷이고 실행 핸들은 호출자가 사용 후 Dispose해야 합니다.

채널 통계는 입력 영상과 선택한 마스크 또는 영역을 기준으로 해석합니다. 예를 들어 선택 영역이 달라지면 같은 이미지라도 포함되는 픽셀이 달라져 평균과 표본 수가 달라질 수 있습니다. 색 공간과 채널 순서도 서로 다른 결과를 비교할 때 맞춰야 합니다.

계획 생성은 아직 통계를 계산한 상태가 아닙니다. 실제 실행이 성공했는지 확인하고 출력값을 얻은 다음 실행을 해제하십시오. 실행 오류를 모든 채널 평균이 0인 유효한 통계로 기록하면 입력 실패를 숨기게 됩니다.

항목확인할 내용
계획선택 픽셀의 색 통계를 지연 계산합니다.
실행Execute가 실제 계산을 수행합니다.
결과채널 통계를 복사한 값 스냅샷입니다.
선택 영역ROI와 마스크가 표본 집합을 정합니다.
비교색 공간·채널 순서와 입력 조건을 맞춥니다.
수명호출자가 실행을 Dispose합니다.

선택 마스크가 있는 경우 포함되는 픽셀이 달라지면 같은 이미지에서도 count와 평균이 달라질 수 있습니다. 예를 들어 두 선택 집합이 각각 10개와 100개의 픽셀을 포함한다면 단순한 절대 합을 바로 비교해 같은 밝기 변화라고 판단할 수 없습니다. 통계 값과 함께 선택 범위, 샘플 수 및 색 성분을 보존하면 다른 실행과 더 정확히 비교할 수 있습니다.
