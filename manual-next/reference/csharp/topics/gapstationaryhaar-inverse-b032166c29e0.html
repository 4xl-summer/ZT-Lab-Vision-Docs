ZVision.ZImage Inverse()

원래 ROI 원점의 GrayF64 영상을 합성합니다.

반환: 해제할 독립 영상입니다.

관련 입력의 확인된 조건

ZImage.Origin: ROI의 글로벌 픽셀 원점입니다.

ZImage.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

모델 계수를 합성하여 입력 ROI 원점을 유지하는 GrayF64 영상을 반환합니다. 숫자 계수 배열과 달리 이 결과는 소유 ZImage이므로 사용 후 Dispose합니다. 모델을 변경한 결과를 비교하려면 각 모델에서 별도 복원 영상을 얻고 같은 ROI 원점과 크기 기준으로 비교하세요. 모델 자체도 별도로 Dispose해야 합니다.

정지 Haar 계수의 복원

GapStationaryHaar.Inverse는 모델의 현재 계수에서 GrayF64 영상을 합성합니다. 반환 ZImage는 독립 소유 핸들이며 원본 입력 ROI의 원점을 유지합니다. 계수 배열의 조회와 복원 영상 생성은 다른 작업이므로 반환 형식과 수명을 구분해야 합니다.

예를 들어 입력 ROI 원점이 (10,20)이면 복원 영상의 로컬 (2,3)은 같은 원점 기준 원본 위치 (12,23)에 대응합니다. 모델의 계수를 수정한 별도 결과와 원본 모델을 비교할 때는 각 Inverse 결과의 크기와 원점을 먼저 맞춘 뒤 같은 위치의 값을 비교합니다.

복원 영상을 얻기 전에 모델이 열려 있어야 하며 사용 후 모델과 반환 영상을 각각 Dispose합니다. 독립 영상이라도 다른 핸들이 자동으로 닫히는 것은 아닙니다. 값의 차이를 평가할 때는 사용한 계수, 단계 및 전처리를 보관하고 부동소수 계산의 차이를 고려합니다.

판독과 확인 사례

정지 웨이블릿 모델은 계수 저장과 영상 합성을 구분합니다. 원본 계수와 수정 계수를 이용해 서로 다른 모델을 구성했다면 각 모델에서 별도 복원 영상을 얻고 같은 좌표의 값을 비교합니다. 모델을 정리하는 시점이 이미 얻은 영상 핸들의 정리 시점과 같을 필요는 없습니다.

GrayF64는 부동소수 영상이므로 원래 입력이 정수였더라도 복원 결과를 정수 바이트 배열처럼 해석하지 않습니다. 픽셀 형식과 행 정보를 확인하고 필요할 때 명시적인 변환을 수행합니다. ROI 원점이 다르면 로컬 인덱스가 같아도 원본 영상상의 위치는 달라집니다.
