Dispose의 사용과 결과 해석

마스크 히스토그램 결과의 사용을 마치면 소유 자원을 해제합니다. 보관할 빈 값은 조회 결과의 소유 형태를 확인한 뒤 별도로 저장합니다. 이 객체가 소유한 자원을 작업 종료 시 해제합니다. 반환된 별도 소유 객체가 있다면 그 객체의 수명도 따로 관리하며, 해제한 핸들을 다시 연산 입력으로 사용하지 않습니다.

사용 순서와 결과 보관

MaskedHistogram은 선택 마스크를 적용한 히스토그램 결과를 소유합니다. Dispose는 그 결과 핸들을 정리하며 입력 영상이나 마스크에 새 연산을 적용하지 않습니다. 필요한 빈 값과 중앙값·최빈값을 먼저 읽고 사용을 마친 뒤 모델을 해제합니다.

선택된 픽셀의 분포에 따라 Median과 Mode는 서로 다른 결과를 나타냅니다. 중앙값은 정렬된 분포의 가운데에 대응하고 최빈값은 가장 자주 나온 값입니다. 예를 들어 선택된 값이 1, 1, 2, 9, 9, 9라면 최빈값은 9이고 중앙 위치는 두 중간 값 2와 9 사이에 있으므로 중앙과 최빈의 역할이 다릅니다. 정확한 반환 규칙은 접근자의 계약을 따릅니다.

같은 영상이라도 마스크를 바꾸면 집계에 포함된 픽셀이 달라집니다. 결과 숫자만 저장하지 말고 입력 프레임, 선택 영역 및 빈의 기준을 함께 보관합니다. 독립 복사로 얻은 값과 모델 핸들의 수명을 구별하며, 닫힌 결과에서 새 Median이나 Mode를 조회하지 않습니다.
