C#
ZVision.BeadQualityResult InspectQuality(ZVision.ZImage training, ZVision.ZImage image, ZVision.BeadQualityOptions options, System.Boolean[] fillLeft = null, System.Boolean[] fillRight = null, System.Double[] world = null, ZVision.ZImage worldX = null, ZVision.ZImage worldY = null)

등록된 훈련 영상과 샘플의 비드 품질을 비교합니다.

인자

training: 모델을 학습한 정렬된 Gray 영상입니다.

image: 같은 기하의 검체 영상입니다.

options: 폭·밝기·충전·에지 허용치입니다.

fillLeft: 각 탐침의 왼쪽 에지 대체 허용 여부입니다.

fillRight: 각 탐침의 오른쪽 에지 대체 허용 여부입니다.

world: 선택적 행 우선 2×3 세계 좌표 변환입니다.

worldX: 선택적 비선형 세계 X 매핑 영상입니다.

worldY: 선택적 비선형 세계 Y 매핑 영상입니다.

반환: 호출자가 해제할 결과입니다.

관련 입력의 확인된 조건

training.Origin: ROI의 글로벌 픽셀 원점입니다.

training.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BeadQualityResult.Info: 탐침·구간 수와 통과 여부입니다.

BeadQualityResult.Flags: 탐침별 원인 비트입니다.

BeadQualityResult.Edges: 탐침별 선택된 좌우 에지입니다.

BeadQualityResult.FillFlags: 탐침별 보간 에지 사용 여부입니다.

BeadQualityResult.Runs: 연속 결함 구간입니다.

이 호출의 입력과 객체 맥락

options.NominalIntensity: 사용자 기준 명암을 지정했는지 확인합니다.

options.WidthNegative: 기준 폭보다 좁아지는 허용 거리입니다.

options.WidthPositive: 기준 폭보다 넓어지는 허용 거리입니다.

options.IntensityNegative: 훈련 밝기보다 어두워지는 허용치입니다.

options.IntensityPositive: 훈련 밝기보다 밝아지는 허용치입니다.

인자별 입력 조건

인자형식역할과 조건
trainingZVision.ZImage모델을 학습한 정렬된 Gray 영상입니다.
imageZVision.ZImage같은 기하의 검체 영상입니다.
optionsZVision.BeadQualityOptions폭·밝기·충전·에지 허용치입니다.
fillLeftSystem.Boolean[]각 탐침의 왼쪽 에지 대체 허용 여부입니다.
fillRightSystem.Boolean[]각 탐침의 오른쪽 에지 대체 허용 여부입니다.
worldSystem.Double[]선택적 행 우선 2×3 세계 좌표 변환입니다.
worldXZVision.ZImage선택적 비선형 세계 X 매핑 영상입니다.
worldYZVision.ZImage선택적 비선형 세계 Y 매핑 영상입니다.

비드 품질 검사

학습 및 검사 영상, 품질 옵션과 선택적 좌·우 탐침 선택, 좌표 매핑으로 품질 결과를 계산합니다. 입력 영상과 경로 좌표가 같은 영역을 가리켜야 합니다.

좌우 배열은 탐침의 순서에 맞추고 매핑이 있는 경우 길이의 단위를 결과와 함께 기록합니다. 반환 결과의 소유 핸들은 사용 후 Dispose합니다.
