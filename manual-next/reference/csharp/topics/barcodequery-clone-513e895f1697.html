ZVision.BarcodeQuery Clone()

바코드 판독 계획을 독립 핸들로 복제합니다.

반환: 원본과 별도로 Dispose해야 하는 계획입니다.

사용과 결과 판독

바코드 판독 지연 계획을 독립 핸들로 복제합니다. 원본과 복제본은 각각 Dispose해야 하며 계획을 복제한 시점과 실제 판독 실행은 별개입니다. 원본과 복제본의 실행 결과를 비교할 때 계획이 사용하는 입력 영역과 영상도 함께 기록하십시오.

항목확인된 역할
반환원본과 별도로 Dispose해야 하는 계획입니다.

복제한 계획과 원본을 각각 실행하면 두 실행의 결과와 소유권도 따로 관리해야 합니다. 다른 입력 조건을 비교하려면 해당 계획에 실제로 지정된 ROI와 바코드 형식이 무엇인지 기록하십시오.

사용 순서와 결과 확인

BarcodeQuery.Clone은 바코드 지연 판독 계획의 독립 핸들을 만듭니다. 복제 시점에 코드를 읽는 것은 아니며 원본과 복제본은 각각 Dispose해야 합니다. 같은 계획이라는 말은 동일한 처리 구성을 가리키며 실행 결과 하나를 두 이름으로 반환한다는 뜻은 아닙니다.

각 계획의 Execute는 별도 실행 객체를 만들고 바코드 판독 결과를 독립 스냅샷으로 복사합니다. 실행은 Dispose해야 하며 Output 스냅샷은 실행 해제 후에도 유효합니다. 결과의 상태와 형식, 텍스트를 함께 확인하여 판독 실패를 정상 내용과 구별하십시오.

예를 들어 원본과 복제본을 별도로 실행한다면 각 실행이 참조한 영상과 ROI, 바코드 형식 및 회전 시도 설정을 같이 기록해야 비교할 수 있습니다. 복제만으로 영상 자체가 새로 촬영되거나 코드가 자동으로 검출되는 것은 아닙니다.

단계 또는 항목확인할 내용
원본기존 바코드 지연 계획입니다.
Clone동일 처리를 위한 독립 계획 핸들입니다.
Execute각 계획에서 실제 판독을 실행합니다.
Output판독 상태와 데이터의 독립 스냅샷입니다.
실행 수명각 실행을 사용 후 Dispose합니다.
계획 수명원본과 복제본도 각각 Dispose합니다.
