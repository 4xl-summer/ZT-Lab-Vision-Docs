static ZVision.AdvancedBlobQuery Create(ZVision.AdvancedBlobResult source)

기존 분석 결과에 대한 지연 선택 계획을 만듭니다.

인자

source: 기존 Blob 분석 결과입니다.

반환: 독립적으로 해제할 선택 계획입니다.

관련 입력의 확인된 조건

source.Count: 측정된 Blob 수입니다.

source.MapInfo: 라벨 영상의 크기를 조회합니다. 부모 ROI 원점은 저장되지 않습니다.

source.Width: 라벨 영상의 픽셀 너비입니다.

source.Height: 라벨 영상의 픽셀 높이입니다.

Create의 사용과 결과 해석

생성에 전달하는 source는 원본 픽셀 배열이 아니라 이미 계산한 AdvancedBlobResult입니다. 선택 조건을 붙이기 전의 분석 결과와 선택 후 결과를 구분해 보관합니다. 분석이 끝난 결과를 기준으로 선택 계획을 만들고 조건을 추가한 뒤 실행 결과를 확인합니다. 조건의 포함 여부와 결과 목록의 순서를 구분해야 하며, 소유한 계획과 실행 결과는 각각의 수명을 따릅니다.

source기존 Blob 분석 결과입니다.
source.Count측정된 Blob 수입니다.
source.MapInfo라벨 영상의 크기를 조회합니다. 부모 ROI 원점은 저장되지 않습니다.
source.Width라벨 영상의 픽셀 너비입니다.
source.Height라벨 영상의 픽셀 높이입니다.
