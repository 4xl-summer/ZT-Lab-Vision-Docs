static ZVision.CalibratedFeaturePose FromMatrix(System.Double[] matrix, ZVision.Point2 zeroPixel, ZVision.Point2 unitsPerPixel, ZVision.Point2 sourceOrigin, System.Double fx, System.Double fy, System.Double cx, System.Double cy, System.Double maxOrthogonalityError = 0.01, System.Double maxScaleError = 0.01)

특징 model-to-source 행렬을 물리 평면에서 카메라 pose로 변환합니다.

인자

matrix: 특징 모델 로컬 픽셀에서 소스 로컬 픽셀로의 행렬입니다.

zeroPixel: 물리 원점에 해당하는 모델 픽셀입니다.

unitsPerPixel: 모델 X/Y 픽셀당 양의 물리 단위입니다.

sourceOrigin: 소스 ROI의 전역 픽셀 원점입니다.

fx: 왜곡 보정된 카메라 X 초점거리입니다.

fy: Y 초점거리입니다.

cx: 전역 X 주점입니다.

cy: 전역 Y 주점입니다.

maxOrthogonalityError: 축 직교 오차 상한입니다.

maxScaleError: 축 배율 상대 오차 상한입니다.

반환: 하나의 양의 원점 깊이 pose와 모호성 진단입니다.

관련 입력의 확인된 조건

zeroPixel.X: 영역의 로컬 x 좌표입니다.

zeroPixel.Y: 영역의 로컬 y 좌표입니다.

CalibratedFeaturePose.Pose: 평면에서 카메라로의 pose입니다.

CalibratedFeaturePose.OriginInFront: 평면 원점의 깊이가 양수입니다.

CalibratedFeaturePose.PlanarAmbiguityUnresolved: 평면 pose의 모호성을 해결하지 않았습니다.

CalibratedFeaturePose.WholePlaneDepthChecked: 전체 평면의 양의 깊이를 검사했는지 나타냅니다.

호출과 결과 해석

특징 모델 로컬에서 소스 로컬로 향하는 행렬을 물리 평면의 카메라 자세로 변환합니다. zeroPixel과 unitsPerPixel로 모델 평면의 픽셀과 물리 좌표를 연결하고 sourceOrigin으로 검색 영상의 원점을 반영합니다. fx, fy, cx, cy는 카메라 내부 파라미터이며 직교·스케일 허용오차는 자세의 적합성 검사에 사용됩니다. 좌표계와 단위를 확인한 뒤 반환 자세와 진단을 읽습니다.

입력별 확인

입력의미
matrix특징 모델 로컬 픽셀에서 소스 로컬 픽셀로의 행렬입니다.
zeroPixel물리 원점에 해당하는 모델 픽셀입니다.
unitsPerPixel모델 X/Y 픽셀당 양의 물리 단위입니다.
sourceOrigin소스 ROI의 전역 픽셀 원점입니다.
fx왜곡 보정된 카메라 X 초점거리입니다.
fyY 초점거리입니다.
cx전역 X 주점입니다.
cy전역 Y 주점입니다.
maxOrthogonalityError축 직교 오차 상한입니다.
maxScaleError축 배율 상대 오차 상한입니다.

반환값

하나의 양의 원점 깊이 pose와 모호성 진단입니다.
