Fit

Method · 선언 타입 ZVision.JointBundleCalibration

C#
static ZVision.JointBundleResult Fit(ZVision.GraphObservation[] observations, ZVision.LensModel[] lenses, System.Double[] cameras, System.Double[] boards, ZVision.IntrinsicMask[] masks, ZVision.JointBundleOptions options)

연결 관측에 지역 블록 정련을 실행합니다.

인자

observations: 카메라와 보드의 대응입니다.

lenses: 초기 렌즈입니다.

cameras: 초기 카메라 pose입니다.

boards: 초기 보드 pose입니다.

masks: 카메라별 내부 계수 비트입니다.

options: pose 마스크와 제한입니다.

반환: 독립 결과와 진단입니다.

관련 입력의 확인된 조건

options.Damping: 양의 LM 감쇠입니다.

options.GradientTolerance: 양의 기울기 한도입니다.

options.CameraPoseMask: 카메라별 pose 선택 비트입니다. 0번은 항상 고정입니다.

options.BoardPoseMask: 보드별 pose 선택 비트입니다.

options.MaxWork: 보수적 작업 상한입니다.

options.Unit: 공통 길이 단위입니다.

JointBundleResult.Diagnostics: 내부 계수 블록 진단입니다.

JointBundleResult.AcceptedPoseSteps: 수용된 pose 갱신입니다.

JointBundleResult.AcceptedIntrinsicSteps: 수용된 렌즈 갱신입니다.

JointBundleResult.Converged: 지역 수렴 여부입니다.

JointBundleResult.Exhausted: 반복 상한 도달 여부입니다.

JointBundleResult.RankDeficient: 렌즈 블록 rank 부족 여부입니다.

계산과 결과 해석

Fit은 여러 카메라와 보드의 연결 관측을 사용해 공유 카메라 자세, 보드 자세와 선택된 렌즈 계수를 함께 지역 정련합니다. observations는 어느 카메라가 어느 보드를 어떻게 관측했는지의 대응이고 lenses, cameras, boards는 각각 초기 렌즈와 초기 자세들입니다. masks는 카메라별로 조정할 내부 계수를 지정하고 options는 자세 마스크와 제한을 정합니다. 예를 들어 두 카메라가 같은 보드를 관측한다면 그 보드가 두 관측에 같은 식별자로 연결되어야 공유 조건이 형성됩니다. 서로 다른 보드를 같은 객체로 잘못 연결하면 숫자가 유효하더라도 의도한 기하 문제가 아닙니다. 정련 대상이 아닌 계수는 초기값의 의미를 유지하므로 선택 마스크와 초기 상태를 결과와 함께 기록하십시오. 반환된 독립 결과와 진단에서 종료 상태와 재투영 결과를 확인하고, 한 관측의 잘못된 점 순서가 전체 정련에 영향을 주는지도 뷰별로 살핍니다. 작은 학습 오차가 모든 미관측 위치의 정확도를 보장하지 않습니다. 카메라와 보드의 좌표 프레임, 물리 단위 및 별도 검증 관측을 준비해 결과를 평가하십시오. 각 관측의 카메라와 보드 인덱스를 입력 배열과 대조하고 동일한 기준 프레임을 유지하십시오.
