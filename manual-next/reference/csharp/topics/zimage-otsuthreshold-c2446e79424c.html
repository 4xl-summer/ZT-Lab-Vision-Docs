OtsuThreshold

Method · 선언 타입 ZVision.ZImage

C#
System.Double OtsuThreshold(System.Int32 binCount, System.Double lower, System.Double upper)

7종 회색 형식에서 히스토그램 두 클래스 간 분산을 최대화하는 내부 빈 경계를 계산합니다. 동률은 가장 낮은 경계를 선택하며 분리 가능한 두 클래스가 없으면 첫 내부 경계를 선택합니다.

인자

binCount: 균등 구간의 개수로 2에서 65536 사이입니다.

lower: 히스토그램 범위의 유한한 하한이며 upper보다 작아야 합니다.

upper: 히스토그램 범위의 유한한 상한이며 lower보다 커야 합니다.

반환: 원본 값 단위의 선택된 내부 빈 경계입니다.

호출에 필요한 입력

회색 영상의 Otsu 임계값을 계산합니다.

인자선언된 형식확인할 내용
binCountSystem.Int32균등 구간의 개수로 2에서 65536 사이입니다.
lowerSystem.Double히스토그램 범위의 유한한 하한이며 upper보다 작아야 합니다.
upperSystem.Double히스토그램 범위의 유한한 상한이며 lower보다 커야 합니다.

결과와 사용 순서

원본 값 단위의 선택된 내부 빈 경계입니다.
