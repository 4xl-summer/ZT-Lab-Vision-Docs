GuidedFilter

Method · 선언 타입 ZVision.ZImage

C#
ZVision.ZImage GuidedFilter(System.UInt64 radius, System.Double epsilon, ZVision.ZImage guide = null, ZVision.FlexibleBorderMode border = ZVision.FlexibleBorderMode.Replicate, System.Double constant = 0, ZVision.PixelFormat outputFormat = ZVision.PixelFormat.GrayF32)

자체 영상 또는 외부 가이드를 이용한 국소 선형 평활입니다.

인자

radius: 국소 반경 픽셀입니다.

epsilon: 밝기 제곱 단위 양의 정규화입니다.

guide: 같은 크기와 원점의 가이드 또는 null입니다.

border: 1차 모멘트 경계입니다.

constant: 상수 경계 값입니다.

outputFormat: 결과 회색 형식입니다.

반환: 독립 소유 영상입니다.

관련 입력의 확인된 조건

border.Replicate: 가장 가까운 경계 픽셀을 복제합니다.

border.Reflect: 끝 픽셀을 반복하지 않고 반사합니다.

border.Constant: 지정한 상수 값을 사용합니다.

호출에 필요한 입력

인자선언된 형식확인할 내용
radiusSystem.UInt64국소 반경 픽셀입니다.
epsilonSystem.Double밝기 제곱 단위 양의 정규화입니다.
guideZVision.ZImage같은 크기와 원점의 가이드 또는 null입니다.
borderZVision.FlexibleBorderMode1차 모멘트 경계입니다.
constantSystem.Double상수 경계 값입니다.
outputFormatZVision.PixelFormat결과 회색 형식입니다.

outputFormat의 입력 값

필드의미와 조건
BGR16채널당 16비트 BGR
BGR8채널당 8비트 BGR
BGRA8채널당 8비트 BGRA
GRAY1616비트 부호 없는 회색
GRAY88비트 부호 없는 회색

결과와 사용 순서

독립 소유 영상입니다.

입력과 결과 해석

입력 또는 외부 가이드 영상에 따른 국소 선형 평활을 적용합니다. 외부 가이드를 쓰는 경우 영상의 크기와 좌표가 입력에 대응하는지 확인하고 경계 주변을 비교하세요.
