EstimateDataMatrixModuleSize

static ZVision.QrModuleSizeEstimate EstimateDataMatrixModuleSize(ZVision.ZImage image, System.Double minPixels, System.Double maxPixels)

Data Matrix finder 간격으로 두 축의 평균 모듈 크기를 추정해 범위 검사합니다.

인자

image: Data Matrix를 포함한 Gray8 영상입니다.

minPixels: 각 축의 포함 최소 크기(픽셀)입니다.

maxPixels: 각 축의 포함 최대 크기(픽셀)입니다.

반환: 두 축의 전역 크기 추정과 사후 범위 판정입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

QrModuleSizeEstimate.Accepted: 두 축 모두 지정된 범위 이내인지 나타냅니다.

QrModuleSizeEstimate.XPixels: 가로 finder 방향의 추정 모듈 크기(픽셀)입니다.

QrModuleSizeEstimate.YPixels: 세로 finder 방향의 추정 모듈 크기(픽셀)입니다.

인자별 입력 조건

인자형식역할과 조건
imageZVision.ZImageData Matrix를 포함한 Gray8 영상입니다.
minPixelsSystem.Double각 축의 포함 최소 크기(픽셀)입니다.
maxPixelsSystem.Double각 축의 포함 최대 크기(픽셀)입니다.

Data Matrix 모듈 크기

Data Matrix finder 간격에서 두 축의 평균 모듈 크기를 픽셀로 추정합니다. minPixels와 maxPixels는 각 축에 적용하는 포함 범위입니다.

반환된 X와 Y 추정 및 수락 여부를 함께 확인합니다. 추정 범위 검사는 인쇄 품질 등급이나 디코더가 모든 심볼을 찾는다는 보장이 아닙니다.
