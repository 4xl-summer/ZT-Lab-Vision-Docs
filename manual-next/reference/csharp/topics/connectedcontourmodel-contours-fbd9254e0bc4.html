Contours의 사용과 결과 해석

모델이 제공하는 윤곽과 그 모델을 영상에서 찾은 위치는 구별해야 합니다. 모델 좌표의 윤곽을 영상에 표시할 때는 검색 결과의 배치도 함께 해석합니다. 연결 윤곽 모델의 구조와 검색 결과를 구분합니다. 검색 입력의 영상 좌표와 모델이 정의된 좌표를 일치시키고, 결과가 없다는 상태를 원점의 정상적인 위치로 대체하지 않습니다.

사용 순서와 결과 보관

Contours는 학습한 ConnectedContourModel의 입력 폴리라인 좌표와 연결 순서를 Point2[][]로 복사합니다. 바깥 배열은 개별 윤곽을 구분하고 안쪽 배열은 각 윤곽의 순서 있는 정점입니다. 반환 배열은 모델 내부 메모리를 빌리는 참조가 아니며 모델 해제 후에도 보관할 수 있습니다.

예를 들어 두 폴리라인이 각각 세 점과 네 점이라면 바깥 배열의 두 항목에 별도 점열로 담깁니다. 첫 폴리라인의 마지막 점과 둘째의 첫 점을 자동으로 연결하면 입력에 없던 선분을 만들게 됩니다. 배열의 점은 학습 모델의 좌표이므로 검색된 영상 위에 표시할 때는 검색 결과의 배치와 기준점을 함께 해석합니다.

반환 배열을 수정해도 이미 학습된 모델의 내부 윤곽을 제자리에서 편집하는 호출이 아닙니다. 원하는 기하가 달라졌다면 적절한 학습 경로로 모델을 다시 만드는 절차를 사용합니다. 결과를 다른 ROI와 비교할 때는 원래 좌표 기준과 입력 영상의 원점을 기록하고, 모델은 사용 후 Dispose합니다.
