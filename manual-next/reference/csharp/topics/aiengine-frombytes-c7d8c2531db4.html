C#
static ZVision.AiEngine FromBytes(System.Byte[] bytes, ZVision.AiModelSpec spec)

신뢰된 RTen 바이트와 명시적 고정 모델 계약으로 엔진을 로드합니다. 고정 형상의 F32 입출력이 각각 하나여야 합니다.

인자

bytes: 복사할 신뢰된 RTen 모델 바이트입니다.

spec: 모델 입출력 계약입니다.

반환: 호출자가 해제할 모델 엔진입니다.

관련 입력의 확인된 조건

spec.Channels: 입력 채널 수로 Gray8은 1, RGB8은 3입니다.

spec.Width: 모델 입력 너비(픽셀)입니다.

spec.Height: 모델 입력 높이(픽셀)입니다.

spec.Classes: 클래스 수이며 이상 과제는 1입니다.

spec.ModelVersion: 0이 아닌 호출자 지정 추적 ID이며 검증된 해시가 아닙니다.

사용과 결과 판독

RTen 바이트와 고정 모델 입출력 계약을 함께 전달합니다. 고정 형상의 F32 입력과 출력이 각각 하나라는 조건을 확인하고, 유효한 바이트 길이와 올바른 모델·사양을 구분하십시오. 엔진 핸들은 사용 후 Dispose합니다.

항목확인된 역할
bytes복사할 신뢰된 RTen 모델 바이트입니다.
spec모델 입출력 계약입니다.
반환호출자가 해제할 모델 엔진입니다.

고정 사양은 모델의 입력 폭·높이와 채널, 출력 과제의 의미를 함께 정의합니다. 이후 실행할 영상 영역의 좌표와 모델이 기대하는 입력 형태를 확인하십시오. 로드 실패는 정상적인 검출 없음과 다른 상태입니다.
