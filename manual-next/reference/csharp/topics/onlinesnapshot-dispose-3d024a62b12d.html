void Dispose()

스냅샷을 해제합니다.

수명과 사용 순서

고정된 온라인 기준 스냅샷을 해제합니다. 평균, 편차, 선택 마스크와 표본 수를 사용한 후 스냅샷의 수명을 종료하십시오.

이 호출은 반환값이 없습니다. C#에서는 소유 객체를 사용할 범위를 정하고 필요한 작업이 끝나면 해제하여 자원을 명확하게 정리할 수 있습니다. 해제된 객체를 다시 작업에 사용하지 마십시오.

고정 통계와 영상 수명

OnlineReference.Freeze는 현재 정상 샘플 통계의 불변 스냅샷을 만듭니다. Count는 고정 당시의 영상 수이고 Mean, Deviation, Mask는 각각 독립 영상 핸들을 반환합니다. 스냅샷을 Dispose하기 전에 필요한 값을 얻고, 이미 획득한 각 영상은 사용이 끝날 때 별도로 Dispose해야 합니다.

Deviation은 모집단 표준편차입니다. 예를 들어 한 픽셀의 표본이 10과 14이면 평균은 12, 편차는 2입니다. Mask는 어떤 픽셀이 기준 통계에 포함되는지 나타내므로 제외 위치의 값을 정상 통계로 해석하지 마십시오. 누적기와 스냅샷도 별개의 소유 객체로 각각 수명을 관리합니다.
