Method · 선언 타입 ZVision.Metrology

static System.Double LineDistance(ZVision.LineFit a, ZVision.LineFit b)

두 무한 직선이 교차하면 0, 평행하면 간격을 반환합니다.

인자

a: 첫 번째 측정 대상입니다.

b: 두 번째 측정 대상입니다.

반환: 입력 좌표와 같은 단위의 계산값입니다.

관련 입력의 확인된 조건

a.Point: 무한 직선 위의 점입니다.

a.Direction: 직선 방향 벡터입니다. 피팅 결과에서는 단위 벡터입니다.

a.Stats: 최종 채택점의 피팅 통계입니다.

계산과 결과 해석

두 무한 직선의 최단 거리를 반환합니다. 정규화 방향 벡터의 외적 절댓값이 1e-12 이하면 평행으로 취급하여 한 선의 점에서 다른 선까지의 수직 거리를 사용하고, 그보다 크면 무한선의 거리를 0으로 반환합니다. 이 값은 실제로 영상에서 관측한 유한 선분 사이 거리를 뜻하지 않습니다. 예를 들어 y=0과 y=2는 거리 2이지만 서로 교차하는 두 직선은 교점이 화면 밖에 있더라도 거리 0입니다. 두 선이 같은 좌표 프레임과 길이 단위를 사용하는지 먼저 확인하십시오. 방향 벡터의 부호가 반대여도 같은 무한선이 될 수 있으며, 방향이 0인 입력은 유효한 선이 아닙니다. 유향 평행선의 부호 있는 간격이 필요한 작업에는 별도의 방향성 계측 경로가 있습니다. 방향 외적이 구현의 평행 허용치보다 큰 두 직선은 실제 촬영 구간이 서로 떨어져 보여도 무한 연장선이 교차하므로 0을 반환합니다. 따라서 화면에 보이는 두 선분의 간격 판정에 이 결과를 그대로 사용하지 마십시오. 계산 전에 필요한 대상이 직선인지 선분인지 결정하는 것이 중요합니다. 평행선의 거리 예시에서 두 선을 함께 같은 방향으로 이동하면 상대 거리는 유지됩니다. 한 선만 옮기면 거리가 바뀝니다. 두 결과의 입력이 서로 다른 ROI에 속하는 경우 이런 이동을 적용하기 전에 공통 원점으로 바꾸십시오.
