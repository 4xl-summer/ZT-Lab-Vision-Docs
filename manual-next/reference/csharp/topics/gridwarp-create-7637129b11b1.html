C#
static ZVision.GridWarp Create(ZVision.Point2[] nodes, ZVision.GridWarpSpec spec)

글로벌 픽셀 좌표의 전체 격자에서 역맵을 만듭니다.

인자

nodes: 행 우선의 모든 격자 교차점입니다.

spec: 물리 간격과 출력 크기·회전입니다.

반환: 호출자가 해제할 불변 맵입니다.

관련 입력의 확인된 조건

spec.Rows: 원본 격자의 행 수입니다.

spec.Columns: 원본 격자의 열 수입니다.

spec.Width: 출력 영상 너비입니다.

spec.Height: 출력 영상 높이입니다.

spec.GridPitchX: 원본 격자의 물리 X 간격입니다.

spec.GridPitchY: 원본 격자의 물리 Y 간격입니다.

spec.OriginX: 출력 좌상단의 물리 X 위치입니다.

spec.OriginY: 출력 좌상단의 물리 Y 위치입니다.

spec.OutputPitchX: 출력 샘플 X 간격입니다.

spec.OutputPitchY: 출력 샘플 Y 간격입니다.

spec.Angle: 출력 샘플 격자의 회전 각도(라디안)입니다.

이 호출의 입력과 객체 맥락

행 우선 전체 교차점과 물리 격자 간격으로 재사용할 쌍선형 역맵을 만듭니다. 노드는 글로벌 픽셀 좌표이며 최소 2×2 격자가 필요합니다. 예를 들어 2행 3열이면 점 6개를 행 순서로 전달합니다. 특이하거나 방향이 바뀐 셀은 거절되지만 국소 검사가 떨어진 셀 사이의 전역 중첩 부재까지 보장하지는 않습니다. 반환 맵은 별도 소유 객체입니다. C#에서는 Dispose합니다.
