문자열 도형을 만듭니다.

인자

position: 기준점입니다.

text: 표시할 문자열입니다.

rgba: 색상입니다.

fontSize: 양의 글자 크기입니다.

반환: 불변 문자열 도형입니다.

관련 입력의 확인된 조건

position.Y: 점의 세로 좌표입니다.

사용 순서와 결과 해석

영상 로컬 기준점에 표시할 문자열 도형을 만듭니다. text는 null일 수 없고 fontSize는 유한한 양수이며 기본값 12입니다. rgba는 0xRRGGBBAA로 색과 투명도를 지정합니다. SVG 저장 시 기준 좌표에 0.5를 더하고 XML 기록기로 텍스트를 출력합니다.
