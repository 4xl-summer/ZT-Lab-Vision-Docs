사용과 결과 판독

이 호출은 추론 모델 핸들을 해제합니다. 실행을 마치고 결과를 필요한 방식으로 처리한 뒤 엔진을 해제하십시오. 엔진과 AiResult는 다른 소유 객체이므로 각자의 해제 책임을 관리하고 이미 해제한 엔진에 새 입력을 전달하지 않습니다.

사용 순서와 결과 확인

AiEngine은 모델 바이트와 고정 입출력 사양을 검증해 소유하는 추론 엔진입니다. Dispose는 모델 핸들을 해제합니다. 해제한 엔진에는 새 영상의 Run이나 사양 조회를 요청하지 않습니다.

FromBytes에서 고정 형상 F32 입력과 출력이 각각 하나인 모델 계약을 준비합니다. Run에는 입력 영상, 영상 로컬 반열린 영역, 실행 옵션을 전달합니다. 원본 영상은 변경되지 않으며 Run은 호출자가 해제할 독립 AiResult를 반환합니다.

예를 들어 하나의 엔진으로 두 ROI를 차례로 실행하면 두 결과 객체는 각각의 실행과 연결됩니다. 각 결과의 Info와 필요한 Scores, Detections 또는 Map을 해당 과제에 맞게 확인하고 결과별 소유권을 관리하십시오. 영역 좌표와 프레임을 같이 기록해야 어떤 결과인지 구별할 수 있습니다.

AiResult는 엔진과 입력을 해제한 후에도 사용할 수 있는 소유 결과입니다. 따라서 엔진 Dispose가 결과를 읽었다는 뜻은 아닙니다. 필요한 결과 사용을 마친 뒤 AiResult를 별도로 Dispose하고, 획득한 맵 영상도 그 소유 계약에 따라 해제하십시오.

영상 영역의 폭과 높이를 변경해 같은 엔진에서 여러 번 추론하는 경우에도 각 Run의 결과는 별개의 AiResult입니다. 결과를 처리할 때 원본 프레임과 ROI를 각각 연결해야 어느 위치에서 얻은 검출인지 확인할 수 있습니다. 엔진 사양은 모델 로드 시 검증한 계약이고 Run 옵션은 실행별 선택이므로 두 정보를 함께 기록하면 재현에 도움이 됩니다. 결과의 소유권과 모델 핸들의 소유권을 구분해 정리하십시오.
