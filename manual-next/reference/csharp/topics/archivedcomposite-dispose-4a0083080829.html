void Dispose()

보관 모델을 해제합니다. 이미 반환한 스냅샷은 유지됩니다.

이 호출의 입력과 객체 맥락

ArchivedComposite.Evaluate: 고정 모델을 저장된 단위로 평가합니다.

ArchivedComposite.Evaluate: 영상 측정 모델을 저장된 단위로 평가합니다.

ArchivedComposite.Unit: 보관된 출력 단위입니다.

이 객체의 확인된 공개 생성 경로: ArchivedComposite(System.Byte[] data).

입력과 결과 확인

ArchivedComposite는 버전과 체크섬을 검증한 보관 바이트에서 복원한 복합 모델을 소유합니다. Dispose는 이 보관 모델의 핸들을 해제하며 이미 Evaluate가 반환한 독립 결과 스냅샷은 유지됩니다. 모델의 사용과 결과 스냅샷의 판독은 수명 측면에서 별개입니다.

인자가 없는 Evaluate는 고정 모델을, ZImage를 받는 Evaluate는 영상 측정 모델을 보관된 단위로 평가합니다. Unit이 null이면 픽셀 기준입니다. 물리 단위가 저장된 경우에도 프로브의 원래 픽셀 진단과 최종 단위 결과를 구별해야 합니다.

예를 들어 평가 후 결과의 형상과 허용치 상태를 저장했다면 모델을 Dispose한 뒤에도 그 스냅샷을 읽을 수 있습니다. 다만 해제된 모델로 새 Evaluate를 요청할 수는 없습니다. 영상 입력을 쓴 실행에서는 ROI와 프레임도 결과에 연결해 기록하십시오.

항목확인할 내용
복원버전과 체크섬이 유효한 보관 바이트를 사용합니다.
Unitnull이면 픽셀, 그 외 저장된 출력 단위입니다.
고정 모델인자 없는 Evaluate로 평가합니다.
영상 모델ROI 영상을 받아 Evaluate합니다.
스냅샷이미 반환된 독립 결과는 모델 해제 후에도 유지됩니다.
Dispose더 이상 평가하지 않을 모델 핸들을 해제합니다.

보관 바이트의 생성과 복원, 평가, 해제는 각각 다른 단계입니다. 생성자는 입력 바이트를 복사한 뒤 버전과 체크섬을 검사하고 저장된 단위 정보를 읽습니다. 따라서 해제 메서드의 호출 시점에 새 보관 파일을 만들거나 결과를 자동으로 다시 평가한다고 생각해서는 안 됩니다. 평가에서 반환된 CompositeResult에는 형상과 허용치의 스냅샷이 있으므로 결과 상태와 각 항목을 보관한 후에도 모델 핸들의 독립적 해제 여부를 확인할 수 있습니다. 고정 모델을 평가하는 호출과 영상이 필요한 모델을 평가하는 호출은 서로 다른 오버로드입니다. 영상 결과를 기록할 때는 입력 이미지의 ROI 로컬 기준과 저장된 Unit을 함께 남기고, 이미 반환한 값의 수명과 새 평가에 필요한 모델의 수명을 혼동하지 마십시오.

평가 결과의 단위가 null이면 픽셀임을 표시하고, 저장된 물리 단위가 있으면 그 단위 설정도 스냅샷과 같이 기록합니다. 보관 모델을 닫기 전 마지막 평가가 성공했는지 확인해야 반환된 정상 결과와 오류를 구별할 수 있습니다.
