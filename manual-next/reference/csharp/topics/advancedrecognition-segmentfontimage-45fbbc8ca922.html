Method · 선언 타입 ZVision.AdvancedRecognition

C#
static ZVision.FontOcrCell[] SegmentFontImage(ZVision.ZImage image, ZVision.FontOcrOptions options)

학습 예제 이미지에서 문자 셀을 자동 분할합니다.

인자

image: Gray8 예제 이미지입니다.

options: 이진화와 문자 크기 설정입니다.

반환: 줄 번호와 이미지 로컬 셀 목록입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

이 호출의 입력과 객체 맥락

options.AllowedChars: 후보 분류에 허용할 유니코드 문자 집합입니다.

options.LightText: 밝은 글자이면 true입니다.

options.ClosingRadius: 정사각 닫기 반경(픽셀)입니다.

options.MinWidth: 문자 너비 하한(픽셀)입니다.

options.MaxWidth: 문자 너비 상한(픽셀)입니다.

인자별 입력 조건

인자형식역할과 조건
imageZVision.ZImageGray8 예제 이미지입니다.
optionsZVision.FontOcrOptions이진화와 문자 크기 설정입니다.

폰트 셀 분할

Gray8 예제 이미지와 이진화·문자 크기 옵션을 사용해 줄 번호가 붙은 이미지 로컬 셀 배열을 복사해 반환합니다. 임시 네이티브 결과는 함수 내부에서 해제합니다.

셀이 문자의 경계에 맞는지 원본 영상에 겹쳐 확인합니다. 분할은 학습 또는 인식 이전 단계이며 셀이 하나 나왔다는 사실만으로 문자가 올바르게 읽혔다고 볼 수 없습니다.
