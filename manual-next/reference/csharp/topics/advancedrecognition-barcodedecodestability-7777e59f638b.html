BarcodeDecodeStability

static ZVision.BarcodeStability BarcodeDecodeStability(ZVision.ZImage image, ZVision.BarcodeSpec spec, System.Int16[] offsets)

밝기 변화 시도의 실제 판독 일치 비율을 계산합니다.

인자

image: Gray8 입력 영상입니다.

spec: 기본 바코드 판독 설정입니다.

offsets: 시도할 -255~255 픽셀 밝기 편차입니다.

반환: 확률이 아닌 반복 판독 안정성 진단입니다.

관련 입력의 확인된 조건

image.Origin: ROI의 글로벌 픽셀 원점입니다.

image.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

BarcodeStability.Score: 기본 판독과 일치한 시도 비율입니다.

BarcodeStability.Matches: 각 밝기 변화 시도의 일치 여부입니다.

BarcodeStability.BaselineStatus: 기본 판독 상태입니다.

BarcodeStability.BaselineFormat: 기본 판독 형식이며 찾지 못하면 null입니다.

BarcodeStability.Text: 기본 판독 문자열입니다.

이 호출의 입력과 객체 맥락

spec.TryRotate: 원본 외 시계 방향 90도 회전을 순서대로 시도할지 나타냅니다.

spec.Formats: 선택할 바코드 형식의 0이 아닌 비트 조합입니다.

spec.MinContrast: 원본 Gray8 대비의 최솟값으로 0~1이며 같은 값은 통과합니다.

인자별 입력 조건

인자형식역할과 조건
imageZVision.ZImageGray8 입력 영상입니다.
specZVision.BarcodeSpec기본 바코드 판독 설정입니다.
offsetsSystem.Int16[]시도할 -255~255 픽셀 밝기 편차입니다.

밝기 변화 판독 안정성

입력 영상과 BarcodeSpec, short 오프셋 배열을 사용해 변형된 조건의 판독을 기준 결과와 비교합니다. 반환값에 기준 상태, 형식, 텍스트, 각 일치 여부와 점수가 포함됩니다.

오프셋의 순서와 Matches를 함께 보관하면 어느 변형에서 결과가 달라졌는지 알 수 있습니다. 기준 자체가 읽기 실패인 상태는 성공한 심볼의 안정성과 구분합니다.
