static ZVision.ShearTemplateResult FindShear(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, ZVision.AdvancedSearchAxis shear, System.UInt64 maxWork, ZVision.ZImage mask = null)

실제 영상 표본을 변환해 X 전단 계수를 검색합니다.

인자

source: 검색 회색 영상입니다.

model: NCC 모델입니다.

options: 일반 NCC pose 설정입니다. coarse 및 subpixel은 미지원입니다. 호출 중 설정 객체를 수정하지 마세요.

shear: u'=u+shear*v의 무차원 전단 범위입니다.

maxWork: 후보 예산×모델 표본 수 상한입니다.

mask: 선택 검색 마스크입니다.

반환: 전단 계수와 검색 종료 진단입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

ShearTemplateResult.Matches: 복사된 결과 배열입니다.

ShearTemplateResult.Evaluated: 평가 pose 수입니다.

ShearTemplateResult.Termination: 검색 종료 상태입니다.

호출 맥락과 결과 해석

명시한 x 전단 격자를 실제 NCC 영상 검색에 적용합니다. 전단 계수는 무차원이며 템플릿 로컬 좌표에서 u′ = u + shear × v로 작용합니다. 예를 들어 shear가 0이면 이 식의 추가 x 이동은 0입니다.

전단 축을 넓히거나 촘촘히 하면 평가 조합이 증가합니다. maxWork의 허용 범위는 1부터 100000000까지이므로 기대하는 변형 범위와 작업 상한을 함께 고려합니다. 반환 결과의 전단 값과 종료 진단을 같이 해석합니다.

이 정적 호출의 model 인자에는 사용할 학습 모델을 지정합니다. 결과를 해석할 때 사용한 모델과 검색 설정을 함께 연결합니다.

입력의미

shearu'=u+shear*v의 무차원 전단 범위입니다.
maxWork후보 예산×모델 표본 수 상한입니다.
