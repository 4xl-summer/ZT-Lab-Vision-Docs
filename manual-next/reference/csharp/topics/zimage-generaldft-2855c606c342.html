GeneralDft

Method · 선언 타입 ZVision.ZImage

C#
ZVision.GeneralSpectrum GeneralDft(System.UInt64 width, System.UInt64 height, ZVision.FftNormalization normalization = ZVision.FftNormalization.Backward)

일반 DFT를 계산합니다.

인자

width: 변환 너비입니다.

height: 변환 높이입니다.

normalization: 정규화입니다.

반환: 독립 스펙트럼입니다.

관련 입력의 확인된 조건

normalization.Backward: 정방향 미정규화, 역방향 1/N입니다.

normalization.Orthonormal: 양방향 1/sqrt(N)입니다.

GeneralSpectrum.Metadata: 변환 정보를 가져옵니다.

호출에 필요한 입력

임의 크기의 제한된 일반 DFT를 계산합니다.

인자선언된 형식확인할 내용
widthSystem.UInt64변환 너비입니다.
heightSystem.UInt64변환 높이입니다.
normalizationZVision.FftNormalization정규화입니다.

normalization의 입력 값

필드의미와 조건
BACKWARD순변환은 배율 1, 역변환은 1/N입니다.
ORTHONORMAL순·역변환 각각 1/√N 배율입니다.

결과와 사용 순서

독립 스펙트럼입니다.

입력과 결과 해석

변환 결과의 계수는 공간 영상의 원래 픽셀과 다른 표현입니다. 변환 설정과 정규화 방식을 역변환에 맞추고, 계수를 수정하지 않은 왕복과 수정한 결과를 따로 확인하세요.
