ZVision.ImageQuery Query()

이미지 저장소를 공유해 보유하는 지연 Query를 만듭니다. 원본 이미지를 해제한 뒤에도 실행할 수 있습니다.

반환: 입력 저장소를 공유하는 새 ImageQuery입니다. 사용 후 Dispose해야 합니다.

호출에 필요한 입력

영상에서 가변 이미지 계획을 만듭니다.

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

입력 저장소를 공유하는 새 ImageQuery입니다. 사용 후 Dispose해야 합니다.

입력과 결과 해석

영상에 연결된 쿼리 계획을 시작합니다. 필요한 연산을 계획에 추가한 뒤 실행 결과에서 영상 또는 측정 결과를 읽습니다. 계획을 만드는 호출과 실제 결과를 읽는 호출의 시점을 구분하세요.
