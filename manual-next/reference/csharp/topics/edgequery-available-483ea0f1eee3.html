C#
System.Boolean Available(System.UInt32 feature)

Checks whether a single feature bit is available.

인자

feature: One feature bit.

반환: True if computed.

사용과 결과 해석

하나의 특성 비트가 요청되어 계산되었는지 확인합니다. 여러 비트를 결합한 값은 단일 특성 조회가 아닙니다.

크기·경계 등의 기하 특성은 생성 시 요청하고, 기울기 크기나 각도는 별도로 계산한 뒤 확인합니다. false인 값을 실제 0 측정으로 취급하지 마십시오.

특성 비트와 결과 조회

Available은 하나의 feature 비트가 요청되어 계산되었는지를 반환합니다. 크기, 닫힘, 첫 점과 경계 등 기하 특성은 결과 생성 시 요청하며, 기울기 크기와 각도는 영상 프레임을 결합하고 별도로 계산한 뒤 사용할 수 있습니다. 여러 비트의 조합을 단일 특성으로 전달하지 마십시오.

예를 들어 경계 특성을 요청하지 않았다면 경계 값이 기본값이라고 해서 실제 경계가 원점이라고 판단할 수 없습니다. 해당 특성의 Available이 true인지 먼저 확인합니다. 프레임 크기나 원점이 바뀌면 기존 기울기 결과가 무효화될 수 있으므로 다시 계산하고 특성을 확인해야 합니다.
