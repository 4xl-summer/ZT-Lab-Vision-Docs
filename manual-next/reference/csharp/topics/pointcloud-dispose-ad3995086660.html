소유 핸들을 해제합니다. 별도로 공유한 핸들은 유효하게 남습니다.

소유 핸들의 해제

이 메서드는 관리 객체가 소유한 네이티브 자원을 해제합니다. 해제한 객체를 이후 연산에 다시 넘기지 말고, 작업이 끝난 소유 객체마다 수명을 명시적으로 끝냅니다. 같은 저장소를 별도 공유 핸들로 참조하는 경우 각 핸들은 자신의 수명을 따릅니다.

예를 들어 영상으로 ROI를 만든 뒤 각각 독립적으로 소유하는 객체라면 각 객체의 작업 종료 시점을 관리합니다. 결과 배열을 이미 복사해 얻었다면 그 값과 닫힌 네이티브 핸들은 서로 다른 수명입니다. 반복 처리에서는 프레임마다 불필요한 핸들이 남지 않도록 정리합니다.

확인 항목해석
호출 전해당 객체의 작업 완료
호출 효과소유한 네이티브 자원 해제
해제 후동일 객체를 다시 사용하지 않음
