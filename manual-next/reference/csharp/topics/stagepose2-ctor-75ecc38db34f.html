StagePose2(System.Double x, System.Double y, System.Double theta)

평면 위치와 각도를 지정합니다.

인자

x: X 위치입니다.

y: Y 위치입니다.

theta: 펼친 라디안 각도입니다.

설정과 사용 흐름

평면 위치 x, y와 펼친 각도 theta를 저장합니다. theta는 라디안이며 회전 수가 반영된 연속 각도로 해석합니다.

위치의 길이 단위는 이 값을 사용하는 스테이지 구성과 일치해야 합니다. 예를 들어 θ=π는 180도이며, 각도를 도 단위로 전달해서는 안 됩니다.

평면 위치와 펼친 각도

StagePose2(x, y, theta)는 평면 스테이지의 물리 X, Y 위치와 연속적으로 펼친 회전 각도를 담습니다. X와 Y는 사용 중인 길이 단위이고 Theta는 라디안입니다. 영상의 픽셀 좌표나 도 단위 각도와 직접 섞지 않습니다.

예를 들어 같은 물리 자세를 0과 2π 라디안으로 표현할 수 있지만, 연속 회전 이력을 유지하는 데이터에서는 두 숫자가 서로 다른 회전 진행을 나타낼 수 있습니다. 입력을 임의로 한 주기 범위로 접으면 측정 과정의 연속성이 사라질 수 있습니다.

비교 조건프레임·단위·회전 연속성 일치

명령 포즈와 관측 포즈를 비교하기 전에 좌표 프레임과 길이 단위를 통일합니다. X·Y의 위치 잔차와 Theta의 각도 잔차는 서로 다른 단위로 해석하고, 스테이지 보정의 배율이나 직교성 진단도 별도 결과에서 확인합니다.

적용과 판독을 더 살펴보기

평면 스테이지의 각 관측을 비교할 때 명령 포즈와 실제 관측 포즈가 같은 기준 좌표계에 표현되었는지 먼저 확인합니다. X와 Y의 배율이나 축 사이의 비직교성은 위치 오차에 영향을 줄 수 있고 Theta는 회전 진행에 대한 별도 축입니다. 회전이 여러 바퀴 누적되는 과정에서 단순히 각도를 한 바퀴 범위로 자르면 연속적인 변화량이 잘못 보일 수 있습니다. 각도는 라디안으로 기록하고 길이 단위도 각 포즈에 일관되게 사용합니다. 생성자에 들어간 숫자는 측정값의 컨테이너이며 실제 스테이지가 해당 위치에 도달했다는 확인 자체는 아닙니다.
