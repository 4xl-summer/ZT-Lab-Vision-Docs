static ZVision.AiDetection[] DecodeYoloTensor(System.Single[] values, System.UInt64 candidates, System.UInt64 classes, ZVision.AdvancedImageTransform transform, ZVision.AdvancedDecodeOptions options, System.Boolean attributesFirst = false, System.Boolean logits = false, System.Boolean hasObjectness = true)

YOLO 원시 텐서를 후보별 또는 속성별 순서로 해석합니다.

인자

values: 평탄화된 원시 텐서입니다.

candidates: 후보 수입니다.

classes: 클래스 수입니다.

transform: 전처리 좌표 변환입니다.

options: 중심 좌표와 NMS 설정입니다.

attributesFirst: 속성 우선 배치면 참입니다.

logits: 점수에 독립 sigmoid를 적용할 때 참입니다.

hasObjectness: objectness 열이 있으면 참입니다.

반환: 이미지 좌표의 검출 목록입니다.

관련 입력의 확인된 조건

transform.Region: 원본 이미지 영역입니다.

사용과 결과 판독

평탄화 텐서를 후보 우선 또는 속성 우선 순서로 읽습니다. 클래스 수와 후보 수, objectness 열의 유무가 실제 출력과 달라지면 같은 숫자도 잘못된 위치로 해석됩니다. 로짓 선택에 따른 sigmoid와 전처리 역변환을 함께 확인하십시오.
