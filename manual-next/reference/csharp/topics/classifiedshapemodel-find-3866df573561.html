ZVision.AdvancedMatchReport Find(ZVision.ZImage source, ZVision.AdvancedMatchingOptions options, System.Double clutterThreshold, System.Double clutterWeight, ZVision.ZImage mask = null)

clutter 영역의 실제 에지 비율을 점수에 반영합니다.

인자

source: 검색 영상입니다.

options: 검색 설정이며 호출 중 변경하지 마세요.

clutterThreshold: 양의 소스 gradient 하한입니다.

clutterWeight: 패널티 가중치 [0,1]입니다.

mask: 선택 형상 검색 마스크입니다.

반환: 독립 검색 결과입니다.

관련 입력의 확인된 조건

source.Origin: ROI의 글로벌 픽셀 원점입니다.

source.Info: 영상의 크기, 행 간격과 형식을 조회합니다.

AdvancedMatchReport.Matches: 점수 순서의 후보 복사본입니다.

AdvancedMatchReport.Evaluated: 평가된 포즈 수입니다.

AdvancedMatchReport.Termination: 검색 종료 이유입니다.

클래스별 검색 해석

학습한 care 특징으로 형상 점수를 구하고 변환된 clutter 위치의 검색 에지 밀도로 점수를 조정합니다. 보이는 clutter 표본의 에지 비율을 f, 가중치를 w라면 조정 배수는 1−w×f입니다. 예를 들어 w=0.5, f=0.4이면 배수는 0.8입니다. 보이는 clutter 표본이 없으면 감점하지 않습니다. threshold와 weight는 서로 다른 역할이므로 옵션과 종료 진단을 함께 확인합니다.
