극단 전경을 제외한 경계

BlobTrimmedBounds는 각 축에서 극단에 있는 일부 전경 픽셀을 독립적으로 제외한 경계를 계산합니다. 멀리 떨어진 잡음점 때문에 일반 외접 범위가 늘어나는 경우를 살펴볼 수 있지만 실제 물체의 가는 끝도 제외될 수 있습니다.

반열림 경계

결과의 왼쪽과 위 경계는 포함하고 오른쪽과 아래 경계는 제외합니다. 예를 들어 x 범위가 [2,5)이면 포함 열은 2, 3, 4로 폭이 3입니다. 오른쪽을 포함한다고 생각해 1을 더하면 잘라내기 폭이 잘못됩니다.

Measure 조건

입력 전경 마스크, 각 변에서 제외할 최대 픽셀 수와 작업량 한도를 지정합니다. 원래 전경 수와 트림된 사각형 넓이는 서로 다릅니다. 제외 수를 조정한 결과를 원본 마스크에 겹쳐 실제 물체가 잘리지 않았는지 확인합니다.

좌표와 비교

반환 경계는 ROI 로컬이므로 전체 영상 표시 시 원점을 적용합니다. 다른 검사 결과와 비교할 때 동일한 분할 및 제외 조건을 사용하고 물리 크기가 필요하면 픽셀 보정을 별도로 고려합니다.
