이 타입을 받는 공개 호출

CompositeModelBuilder.AddMeasuredLine: 영상에서 탐침으로 선을 측정하는 형상을 추가합니다. spec 인자: fixture 로컬 선분입니다. 반환: 형상 인덱스입니다.

LineMeasurementModel..ctor: 선 기준과 탐침 설정을 복사하고 검증합니다. spec 인자: ROI 로컬 기준 선분입니다.

ZImage.MeasureLineAdvanced: 최대 간격 및 coverage 정책으로 선을 측정합니다. spec 인자: 기준 선입니다. 반환: 적합과 절단·coverage 진단입니다.

ZImage.InspectLineCandidates: 프로브 피크를 수집하고 실제 피팅 단계별 선과 후보를 반환합니다. spec 인자: ROI 로컬 선 탐침 모델입니다. 반환: 복사된 결과입니다. 검출 임계치 및 prominence 미달 피크는 수집되지 않습니다. 공유 설정의 Selection은 First, MaxEdges는 1, MinFound와 MinInliers는 동일, MinArcRadians는 0, FitMethod는 Consensus여야 합니다. 고정 탐침 검색이며 상용 알고리즘과 수치적으로 같다고 가정하지 않습니다.

ZImage.MeasureLineInstances: 명시 배치마다 같은 선 모델을 측정합니다. spec 인자: 배치 전 선 모델입니다. 반환: 입력 순서의 독립 결과이며 자동 배치 검색이나 중복 제거를 수행하지 않습니다.

ZImage.SearchLineInstances: 유한 이동 격자에서 선을 측정하고 앞서 채택한 선의 법선 투영으로 중복을 제거합니다. 평행하지 않으면 기준점과 채택 순서에 따라 투영 거리가 달라집니다. spec 인자: 고정 방향 선 모델입니다. 반환: 인라이어 수와 RMS 순의 선 및 탐침 진단입니다.

ZImage.MeasureLinePairs: 각 선 탐침에서 에지 쌍을 선택하고 두 경계를 독립 적합합니다. spec 인자: ROI 로컬 선분 및 탐색 기울기입니다. 반환: 독립된 두 적합 결과와 탐침입니다.
