사용과 결과 해석

FitRays는 알려진 정규화 카메라 광선과 관측 픽셀의 대응을 이용해 선택된 렌즈 내부 및 왜곡 계수를 추정합니다. rays의 각 항목과 observed의 같은 위치 항목은 동일한 광선에 대한 짝이어야 합니다. initial은 시작 렌즈 모델이고 options는 어떤 계수를 바꾸고 어떻게 정련할지 정합니다. 예를 들어 세 광선의 픽셀을 입력할 때 관측 두 개의 순서를 바꾸면 값이 모두 유한해도 다른 대응 문제가 됩니다. 카메라 좌표의 정규화 광선과 이미지의 픽셀 좌표는 서로 다른 단위와 역할이므로 같은 점 배열처럼 합치지 마십시오. 결과의 렌즈 모델만 보지 말고 진단과 수렴 여부 및 재투영 오차를 함께 확인합니다. 일부 계수만 최적화하면 나머지 계수는 초기 모델의 의미를 유지하므로 초기값과 선택 마스크를 보관해야 결과를 재현할 수 있습니다. 학습 자료의 오차가 작다는 사실이 카메라 전체 시야에서의 정확도를 보장하지는 않습니다. 학습에 사용하지 않은 광선과 픽셀 대응으로 별도 평가하고, 잘못된 배열 길이나 좌표 기준이 의심되면 먼저 입력 짝을 검토하십시오. 동일 광선에 대해 관측 픽셀을 비교할 때는 초기 모델과 정련된 모델을 같은 입력으로 평가해야 개선 여부를 구분할 수 있습니다. 입력과 평가 자료를 분리해 보관합니다.
