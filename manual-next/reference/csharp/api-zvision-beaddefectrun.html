사용과 결과 해석

연속적으로 실패한 비드 탐침 구간의 양끝과 사유 비트를 담습니다. First와 Last는 0부터 시작하며 둘 다 구간에 포함됩니다. Flags는 구간에서 관측된 실패 사유들의 비트 합집합입니다.

예를 들어 First가 2이고 Last가 4이면 포함 탐침은 2, 3, 4로 세 개입니다. Flags에 여러 사유가 있더라도 구간의 모든 탐침에서 모든 사유가 동시에 발생했다는 뜻은 아닙니다. 각 탐침의 진단을 읽어 실제 위치별 원인을 구분해야 합니다.

탐침 인덱스는 물리 길이나 영상 좌표 자체가 아닙니다. 간격이 고르지 않은 경로에서 단순 인덱스 차이만으로 갭 길이를 계산하지 말고 결과가 제공하는 길이 통계를 확인하십시오. ROI 원점과 보정도 별도 적용이 필요합니다.
