최대 이산 내부 원

BlobInnerCircleOps는 배경 픽셀 중심을 포함하지 않는 격자 중심의 최대 이산 원을 계산합니다. 픽셀 격자의 특정 정의에 따른 측정이므로 물체의 연속적인 경계에 정확히 접하는 이론적 원과 동일하다고 단정할 수 없습니다.

Measure와 결과

Measure에 전경 마스크와 해당 작업량 한도를 지정합니다. 반환된 BlobInnerCircle은 ROI 로컬 중심과 픽셀 반지름을 제공합니다. 결과 원을 입력 마스크에 겹쳐 주변의 배경 픽셀과 중심 위치를 확인하면 측정 대상을 파악하기 쉽습니다.

내부 원과 외접원

내부 원은 배경이 원 안에 들어오지 않도록 찾고 외접원은 선택한 셀을 밖에서 감쌉니다. 예를 들어 오목한 물체에서는 좁은 홈이 내부 원을 제한하는 반면 외접원은 멀리 돌출한 부분의 영향을 받습니다.

판독 조건

ROI 경계에서 물체가 잘렸거나 임계값으로 작은 구멍이 생기면 결과가 달라질 수 있습니다. 실제 물리 반지름으로 사용할 때는 픽셀 간격, 보정 및 이산화 오차를 따로 검증해야 합니다.
