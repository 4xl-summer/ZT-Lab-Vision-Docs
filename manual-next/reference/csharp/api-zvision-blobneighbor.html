영역 쌍과 거리

BlobNeighbor는 입력 영역 목록의 First와 Second 인덱스 및 Distance를 담습니다. 이 거리는 경계 픽셀 중심 간 최소 거리이므로 객체의 무게중심 거리나 셀 모서리 사이 빈틈과 같은 뜻이 아닙니다.

숫자 예

가장 가까운 경계 중심이 (1,2)와 (4,6)이면 두 축의 차이는 3과 4이고 거리는 5픽셀입니다. 결과를 물리 길이로 비교하려면 해당 영상의 보정과 픽셀 축 간격을 별도로 확인해야 합니다.

인덱스 사용

First와 Second는 원래 영역 시퀀스의 위치를 가리킵니다. 목록을 재정렬한 뒤 같은 숫자를 사용하면 다른 영역이 선택되므로 결과와 입력 순서를 함께 유지합니다. 이 숫자는 다른 프레임에서 유지되는 객체 ID가 아닙니다.

결과 확인

선택된 두 마스크와 경계를 같은 좌표에 그려 가까운 영역이 의도한 두 물체인지 확인합니다. 분할 또는 ROI가 달라지면 경계 픽셀이 바뀌어 거리와 이웃 관계도 달라질 수 있습니다.
