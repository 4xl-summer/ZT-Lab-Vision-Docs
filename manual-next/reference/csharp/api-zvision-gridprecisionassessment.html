사용과 결과 해석

이미 검출한 격자점의 주변 영상으로 국소 위치 정밀도를 평가합니다. 입력 point는 ROI 로컬 픽셀 위치이고 radius는 1~32픽셀입니다. noiseSigma는 양의 강도 잡음 표준편차, maxSigma는 허용하는 양의 위치 표준편차 상한입니다.

주변의 기울기로 선형화된 위치 공분산을 계산한 뒤 가장 큰 방향의 표준편차를 상한과 비교합니다. 예를 들어 같은 점이라도 잡음을 더 크게 가정하거나 상한을 더 엄격하게 정하면 판정이 달라질 수 있습니다. 이 함수는 격자점을 새로 검출하는 기능이 아닙니다.

결과의 공분산과 accepted 여부를 함께 확인하고 입력 점이 실제 격자점인지, ROI 원점이 기대와 같은지도 점검하십시오. 이 수치는 가정된 독립 강도 잡음 모델에 대한 근사치이며 카메라 보정이나 실제 측정의 모든 오차를 포함하는 불확도 인증은 아닙니다.
