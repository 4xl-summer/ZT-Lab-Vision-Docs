방향 투영의 지지점

BlobFeretContacts는 블롭 볼록껍질을 지정 방향에 투영했을 때 양 끝 지지점과 폭을 측정합니다. 폭은 최대 투영값에서 최소 투영값을 뺀 길이이며 객체의 중심 간 거리와는 다른 양입니다.

투영 폭 예

선택 방향의 최소 투영이 2이고 최대 투영이 7이면 폭은 5입니다. 지지점 두 개의 좌표는 이 극값을 만드는 껍질 꼭짓점을 나타냅니다. 두 지지점 사이의 직선 거리와 선택 축의 투영 폭은 일반적으로 다를 수 있습니다.

Measure 설정

대상 Blob 결과와 0 기반 인덱스, 유한한 방향 각도 및 작업량 제한을 지정합니다. 각도는 라디안이며 90도는 π/2입니다. 결과 접촉점은 ROI 로컬 좌표이므로 전체 영상에 표시할 때 원점을 반영합니다.

방향 비교

같은 물체도 방향을 바꾸면 폭과 선택된 꼭짓점이 바뀔 수 있습니다. 여러 대상의 폭을 비교할 때는 방향 기준을 통일하고 픽셀 간격 및 보정을 확인합니다. 한 방향 측정만으로 모든 각도 중 최댓값이라고 결론 내릴 수 없습니다.
