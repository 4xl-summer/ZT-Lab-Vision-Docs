사용과 결과 해석

평면 스테이지의 X, Y 위치와 회전 Theta를 담습니다. X와 Y는 호출 시 지정한 공통 물리 길이 단위를 사용하고 Theta는 연속적으로 펼친 각도, 즉 라디안입니다. 같은 수의 명령과 관측 포즈를 순서대로 짝지어 응답을 평가할 때 쓰입니다.

회전이 각도 표현의 경계를 지나더라도 실제 움직임이 연속적이라면 입력 각도도 그 흐름에 맞게 unwrap해야 합니다. 예를 들어 경계 양쪽 값을 서로 멀리 떨어진 방향으로 잘못 전달하면 실제 작은 운동이 큰 회전 변화로 해석될 수 있습니다.

포즈 값은 특정 장비의 축 보정이나 프레임 변환을 스스로 수행하지 않습니다. 명령과 관측의 원점, 축 방향, 길이 단위 및 시간 대응을 먼저 일치시키십시오. 이후 적합 결과의 RMS와 최대 잔차를 해당 단위로 해석해야 합니다.
