사용과 결과 해석

정규화된 광선 관측을 바탕으로 적합한 렌즈 모델과 수치 진단을 함께 반환합니다. Model은 추정된 렌즈이고 RmsPixels는 픽셀 단위의 재투영 RMS입니다. Iterations와 Converged는 반복 최적화의 진행 결과를 나타내며 해당 숫자만으로 물리 장비에 대한 인수가 완료되었다고 볼 수 없습니다.

재투영 RMS는 사용된 관측을 렌즈와 자세로 다시 투영했을 때의 오차 요약입니다. 예를 들어 RMS가 작아도 일부 대응점의 오차가 크거나 관측이 영상 한쪽에만 몰려 있을 수 있습니다. 잔차 분포와 관측 영역을 함께 확인하고, 따로 확보한 점에서 평가해야 다른 위치의 사용 가능성을 판단할 수 있습니다.

렌즈 계수를 다른 해상도나 좌표계로 옮길 때는 사용한 픽셀 기준과 단위를 다시 맞춰야 합니다. 수렴하지 않은 상태를 모델이 정상적으로 검증되었다는 뜻으로 해석하지 말고 초기값, 관측 기하와 선택된 변수를 검토하십시오.
