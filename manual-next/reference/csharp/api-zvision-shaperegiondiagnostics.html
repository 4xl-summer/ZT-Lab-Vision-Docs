사용 맥락과 결과 해석

형상 모델의 변환된 경계와 특징점이 지정 사각형에 얼마나 들어오는지 진단합니다. OutsideAreaFraction은 경계 면적 중 바깥 비율, OutsideFeatureFraction은 바깥 특징점 비율이고 AnchorInside는 모델 기준점의 포함 여부입니다. 사각형은 검색 영상 로컬 좌표로 지정합니다.

기준점이 안쪽이어도 모델 일부가 영역을 벗어날 수 있습니다. 예를 들어 AnchorInside가 참이어도 OutsideAreaFraction이 양수일 수 있으므로 전체 포함 판정에 두 값을 구분해 사용합니다. 유효하지 않은 사각형이나 퇴화된 모델 경계는 오류입니다. 이 진단은 지정 포즈와 영역의 기하 관계이며 물체 검출 점수 자체가 아닙니다.

값을 확인하는 순서

OutsideAreaFraction 항목: 모델 경계 사각형 중 영역 밖 면적 비율입니다. OutsideFeatureFraction 항목: 영역 밖 특징 비율입니다. AnchorInside 항목: 모델 기준점이 영역 안인지 나타냅니다.
