C# API · ZVision.BlobQuery / query

ZVision.BlobQuery 컴파일된 공개 멤버

공개 타입

ZVision.BlobQuery · class

어셈블리: ZVision.

Blob 결과의 필터와 정렬을 계획하는 지연 Query입니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: ZVision.QueryBuilder

컴파일된 ZVision 어셈블리에서 확인한 공개 멤버입니다. XML 설명이 없는 반환값, 오류와 지원 조건은 미확인입니다.

Clone

현재 계획을 독립적으로 변경할 수 있는 새 빌더로 복제합니다.

Where

조건식으로 Blob을 필터링하도록 계획합니다. 표현식은 Blob 필드, 상수, 캡처 필드와 지원 연산자만 IR로 변환합니다. 임의 메서드 호출은 지원하지 않습니다. 표현식은 최대 깊이 64, 노드 4096개로 제한되며 정수 연산은 검사된 i128 의미를 따릅니다.

OrderBy

키 표현식으로 Blob 정렬을 계획합니다. 표현식은 Blob 필드, 상수, 캡처 필드와 지원 연산자만 IR로 변환합니다. 임의 메서드 호출은 지원하지 않습니다. 표현식은 최대 깊이 64, 노드 4096개로 제한되며 정수 연산은 검사된 i128 의미를 따릅니다.
