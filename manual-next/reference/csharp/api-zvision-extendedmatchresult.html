사용 맥락과 결과 해석

타입 지정 확장 NCC 또는 형상 모델이 반환하는 독립 결과입니다. Matches는 점수 순 후보 복사본, Evaluated는 평가된 포즈 수, Termination은 검색 종료 이유입니다. 입력 영상이나 모델이 닫혀도 이미 복사된 결과를 읽을 수 있습니다.

빈 Matches와 종료 이유는 별도 상태입니다. 예산이나 시간으로 끝났다면 후보가 하나 발견되더라도 나머지 격자를 모두 평가했다고 볼 수 없습니다. 각 후보의 기준점은 검색 ROI 로컬과 원점을 더한 전역 좌표를 구분하며, 축별 배율과 라디안 각도를 설정한 범위와 함께 확인합니다. 점수는 모델이 선택한 비교 방식에 따른 값입니다.

거리 억제와 결과 상한을 적용한 다음 목록이 반환되므로 목록 길이는 검색 중 임계값을 통과한 모든 후보의 수가 아닙니다. 선택된 각 점수와 자세를 함께 검사합니다.

값을 확인하는 순서

Matches 항목: 점수 순서의 후보 복사본입니다. Evaluated 항목: 평가된 포즈 수입니다. Termination 항목: 검색 종료 이유입니다.
