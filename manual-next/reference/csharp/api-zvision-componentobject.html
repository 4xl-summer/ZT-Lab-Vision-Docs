사용과 결과 해석

구성 모델에서 요구한 부분들이 모두 발견된 하나의 객체 결과입니다. Parts는 루트부터 시작하는 구성 결과이며 Score는 객체 점수, MaxPositionError는 구성 위치 오차의 요약입니다. 이 값은 단일 템플릿 한 장의 좌표만 기록하는 결과와 달리 여러 부분의 관계를 함께 표현합니다.

각 부분의 결과를 읽을 때 모델에서 정의한 루트와 자식 관계, 각 검색 범위를 함께 확인하십시오. 부분 점수가 좋아도 위치 제약이 나쁘면 전체 객체의 해석이 달라질 수 있습니다. 예를 들어 두 부품이 각각 발견되었더라도 예상한 상대 위치와 어긋난 경우를 구별하는 데 위치 오차가 유용합니다.

Parts는 독립 배열로 제공되며 배열을 읽는 순서가 임의의 화면 정렬 순서를 뜻한다고 가정하지 말고 모델 구성 순서를 확인하십시오. 입력 ROI 좌표와 전체 영상 좌표를 섞지 말고, 결과 점수는 설정한 검색과 기준에 종속된 값으로 해석해야 합니다.
