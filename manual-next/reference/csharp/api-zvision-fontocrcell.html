사용과 결과 해석

자동 문자 분할에서 얻은 하나의 셀 사각형과 줄 번호입니다. Line은 줄 인덱스이고 X와 Y는 입력 이미지 로컬의 왼쪽 위 위치, Width와 Height는 픽셀 크기입니다. 이 값은 문자 인식 레이블이나 유사도 점수와는 구별되는 분할 결과입니다.

예를 들어 한 줄에서 두 글자가 서로 닿아 하나의 연결 영역으로 분할되었다면 셀 하나가 두 문자를 포함할 수 있습니다. 학습 전에 셀을 검토·교정하는 이유이며, 셀 수만 보고 문자가 올바르게 분리되었다고 가정해서는 안 됩니다.

셀을 다른 ROI나 원본 전체 영상에 적용할 때는 로컬 원점과 범위를 확인해야 합니다. 이미지가 변경되거나 다른 크기로 변환된 뒤에는 예전 셀이 같은 문자 위치를 가리키지 않을 수 있습니다. 모델 학습 시 레이블은 별도로 올바르게 부여해야 합니다.
