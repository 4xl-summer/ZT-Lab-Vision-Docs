사용 맥락과 결과 해석

여러 특징 모델의 반복 인스턴스 검색 후 얻은 결과입니다. Matches에는 모델 id와 포즈, 모서리 및 내점 진단이 있고 Evaluated는 총 RANSAC 가설 평가 수입니다. Incomplete는 공유 예산으로 전체 검색이 끝나지 않았는지 표시하며 결과 배열과 독립적으로 판독합니다.

겹침 억제 범위를 모든 모델에 적용하면 다른 모델에서 나온 중복을 줄일 수 있지만 실제로 겹친 서로 다른 물체도 영향을 받을 수 있습니다. 후보의 id는 결과 배열 인덱스가 아니라 입력 모델 식별자입니다. 최종 개수와 함께 모델별 내점 수, 공유 예산과 IoU 조건을 기록해 선택 결과를 설명할 수 있게 합니다.

배열의 네 모서리와 변환 행렬을 표시할 때는 검색 영상의 로컬 프레임과 원본 원점을 맞춥니다. 평가 가설 수는 후보 점의 수와 다른 진단이므로 같은 지표로 집계하지 않습니다.

값을 확인하는 순서

Matches 항목: 검출 결과입니다. Evaluated 항목: 평가 가설 총수입니다. Incomplete 항목: 예산 중단 여부입니다.
