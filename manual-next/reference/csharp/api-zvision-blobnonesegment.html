밝기 비례 멤버십

BlobNoneSegment는 별도 임계값 없이 픽셀 강도를 스케일에 대한 비례 멤버십으로 해석합니다. 픽셀을 경계값 하나로 0 또는 255로 나누는 이진 임계 처리와는 다른 표현입니다.

스케일 예

분모가 100이고 입력 밝기가 50이면 비율은 0.5입니다. 같은 입력에 다른 스케일을 쓰면 멤버십 해석이 달라집니다. 입력 Gray8의 실제 범위와 선택한 분모를 함께 기록해야 결과를 다른 영상과 비교할 수 있습니다.

Segment 사용

입력 영상과 스케일, 작업량 제한을 메서드의 허용 범위에 맞게 전달합니다. 결과의 분할 정보에 임계값이 있다고 가정하지 말고 실제 분할 방식과 설정을 확인합니다. 출력과 원본을 같은 위치에서 비교하면 매핑 효과를 이해하기 쉽습니다.

실제 적용

조명, 노출 또는 전처리로 입력 밝기 분포가 바뀌면 동일한 스케일에서도 멤버십이 달라질 수 있습니다. 현장 영상의 밝기 범위와 후속 블롭 측정 결과를 함께 검증해 기준을 선택합니다.
