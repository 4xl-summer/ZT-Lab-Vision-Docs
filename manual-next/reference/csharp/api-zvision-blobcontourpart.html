윤곽의 연속 구간

BlobContourPart는 속성 조건에 따라 선택된 윤곽의 한 연속 구간을 Points와 Closed로 표현합니다. 전체 윤곽에서 일부만 선택하면 원래 물체 전체의 윤곽과 구간의 경계는 다릅니다.

닫힘 판독

닫힌 입력의 전체가 선택된 경우에만 선택 부분도 닫힌 경로로 해석합니다. 고리에서 짧은 호만 선택했다면 양 끝을 임의로 연결하면 실제 선택에 없던 선분이 생겨 길이나 면적이 달라집니다.

점의 순서

Points의 순서는 윤곽을 따라가는 연결을 나타냅니다. 단순히 X 또는 Y 순으로 재정렬하면 원래 이웃 관계가 바뀌므로 보존해야 합니다. ROI에서 얻은 경로를 전체 영상에 표시할 때는 원점을 맞춥니다.

후속 분석

부분 경로의 길이나 다른 경로까지의 거리를 계산할 때 Closed와 좌표 단위를 함께 사용합니다. 전체 물체의 둘레가 필요한지 선택된 부분의 길이가 필요한지 구분하고 결과를 원본 윤곽 위에서 확인합니다.
