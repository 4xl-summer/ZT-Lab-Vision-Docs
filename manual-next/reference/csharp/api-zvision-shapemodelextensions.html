TrainContours

방향 폴리라인의 왼쪽 법선으로 모델을 학습합니다.

Features

반환: 수명 독립적인 특징 배열입니다. 연결 관계는 포함되지 않습니다.

RegionDiagnostics

변환된 모델의 검색 영역 밖 면적과 특징 비율을 계산합니다.

FindGlobalPolarity

특징 전체에 공통인 한 극성으로 형상 모델을 검색합니다.

FindMinContrast

Applies mean visible edge contrast to each bounded grid pose before ranking and suppression. Pyramid, subpixel, certainty and trimmed scoring are unsupported.

FindImagePyramid

Searches actual reduced source image and shape-feature levels.

FindEdgeGrain

Searches only source edge components within the inclusive size range.

FindInRegions

Searches a bounded grid using independent inclusive anchor and model-region constraints.

TrainAligned

Trains a shape from edge occurrences at corresponding coordinates in already aligned images.

RefinePose

주어진 형상 pose의 위치, 각도와 두 축 배율을 국소 정밀화합니다.

ToBytes

형상 모델을 자체 버전 및 체크섬 형식으로 직렬화합니다.
