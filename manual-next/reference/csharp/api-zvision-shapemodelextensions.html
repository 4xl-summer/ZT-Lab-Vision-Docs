FindMinContrast

static ZVision.AdvancedMatchReport FindMinContrast(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, System.Double minContrast, ZVision.ZImage mask = null)

Applies mean visible edge contrast to each bounded grid pose before ranking and suppression. Pyramid, subpixel, certainty and trimmed scoring are unsupported.

인자

source
Source image.
model
Shape model.
options
Candidate search and suppression options. 호출 중 설정 객체를 수정하지 마세요.
minContrast
Nonnegative minimum mean visible gradient in source intensity units.
mask
Optional search mask.

반환: Detached candidates and underlying search termination.

FindInRegions

Method · 선언 타입 ZVision.ShapeModelExtensions

C#
static ZVision.AdvancedMatchReport FindInRegions(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, System.Double[] anchor, System.Double[] region, System.Double maxOutside, System.Boolean requireFull = false, ZVision.ZImage mask = null)

Searches a bounded grid using independent inclusive anchor and model-region constraints.

인자

source
Source image.
model
Shape model.
options
Grid options; do not mutate during the call. Pyramid, subpixel, certainty and trimmed scoring are unsupported.
anchor
Inclusive source-local anchor rectangle [left,top,right,bottom].
region
Inclusive source-local model rectangle.
maxOutside
Maximum fraction of features outside the model rectangle [0,1].
requireFull
Require the entire transformed feature-bounds rectangle inside the model rectangle.
mask
Optional source mask.

반환: Detached constrained matches and search termination.

TrainAligned

static ZVision.AdvancedMatchModel TrainAligned(ZVision.ZImage[] images, ZVision.Point2 reference, System.Double minFraction, System.UInt64 sampleStep = 1, System.Nullable<System.Double> threshold = null, ZVision.ZImage mask = null)

Trains a shape from edge occurrences at corresponding coordinates in already aligned images.

인자

images
Two to 64 same-size, same-origin aligned images.
reference
Shared local reference point.
minFraction
Minimum occurrence fraction in (0,1].
sampleStep
Common sampling step.
threshold
Fixed gradient threshold, or null for per-image automatic threshold.
mask
Optional shared training mask.

반환: An owned shape model.
