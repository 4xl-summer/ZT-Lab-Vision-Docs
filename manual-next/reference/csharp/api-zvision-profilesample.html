사용과 결과 해석

프로파일의 한 샘플을 Position, Distance, Value로 표현하는 값 형식입니다. Position은 스트립 중심선 위의 영상 위치이고 Distance는 선분 시작점부터의 픽셀 거리입니다. Value는 해당 위치에서 횡단 표본을 보간하고 평균한 영상 강도입니다. 예를 들어 시작점이 (10,20)이고 x축 방향으로 2픽셀 진행한 표본의 위치가 (12,20)이라면 Distance는 2입니다. 시작점이 원점이 아닐 때 위치 좌표의 x 값과 Distance를 같다고 가정해서는 안 됩니다. 이 값은 에지의 위치가 아니라 강도 단면의 한 점이므로 별도의 미분과 극성 선택이 필요합니다. 프로파일을 반대 방향으로 추출하면 위치의 물리적 집합이 같아도 순서와 거리 기준이 바뀝니다. Value는 입력 강도의 단위를 따르며 위치의 픽셀 단위와 다릅니다. 결과를 기록할 때 영상의 ROI 원점, 선분과 폭을 함께 남기면 다른 프레임의 위치를 공통 기준으로 비교할 수 있습니다. 영상 밖 표본이나 유효하지 않은 입력으로 계산에 실패한 상황을 값 0인 정상 샘플과 혼동하지 마십시오. 전체 샘플 배열의 길이와 시작·끝 위치를 함께 확인합니다. 표본은 지정한 방향의 순서를 따릅니다.
