BeadReference.InspectQuality: 등록된 훈련 영상과 샘플의 비드 품질을 비교합니다. options 인자: 폭·밝기·충전·에지 허용치입니다. 반환: 호출자가 해제할 결과입니다.

BeadReference.InspectQualityUnits: 단위를 명시하고 비드 품질을 검사합니다. options 인자: 폭·중심 허용치는 선택한 단위로 지정합니다. 반환: 독립 결과입니다. 에지 좌표는 항상 ROI 로컬 픽셀이며 폭은 선택한 단위입니다.

BeadReference.InspectQualityScored: 비드 품질과 학습 포함점에 대한 승인 점수를 함께 계산합니다. options 인자: 품질 설정입니다. 반환: 호출자가 해제할 품질 결과와 독립 점수입니다.
