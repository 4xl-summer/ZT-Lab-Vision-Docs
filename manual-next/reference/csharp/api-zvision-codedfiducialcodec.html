Encode

Method · 선언 타입 ZVision.CodedFiducialCodec

C#
static System.Byte[] Encode(System.UInt32 id, System.UInt32 row, System.UInt32 column, System.UInt32 pitchX, System.UInt32 pitchY, System.Nullable<ZVision.LengthUnit> unit)

부호화된 명암 셀을 생성합니다.

인자

id
1~65535 ID입니다.
row
0~511 기준 행입니다.
column
0~511 기준 열입니다.
pitchX
길이 단위의 1000분의 1 정수입니다.
pitchY
길이 단위의 1000분의 1 정수입니다.
unit
물리 길이 단위이며 간격이 없으면 null입니다.

반환: 행 우선 81개 셀, 1은 검은 셀입니다.

Decode

Method · 선언 타입 ZVision.CodedFiducialCodec

C#
static ZVision.CodedFiducial Decode(ZVision.ZImage image, System.UInt64 x, System.UInt64 y, System.UInt64 cellSize, System.UInt32 threshold = 127, System.UInt32 expectedId = 0)

위치를 이미 아는 Gray8 셀 영역을 판독합니다.

인자

image
입력 Gray8 영상입니다.
x
ROI 로컬 시작 x입니다.
y
ROI 로컬 시작 y입니다.
cellSize
각 셀 크기 1~256 픽셀입니다.
threshold
검은 셀 임계값 0~254입니다.
expectedId
0이면 임의 ID를 허용하고, 그 외는 정확히 일치해야 합니다.

반환: 복원된 ID·기준점·물리 간격·회전입니다.
