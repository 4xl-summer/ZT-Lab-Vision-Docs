사용 맥락과 결과 해석

강건 형상 적합에 사용된 한 점의 잔차와 실제 최종 가중치, 내점 여부를 담습니다. Residual은 부호가 있는 좌표 단위 값이고 Weight는 선택한 강건 손실의 가중치이며 Inlier는 별도의 잔차 한계에 따른 판정입니다. 하나가 같다고 다른 둘까지 같다고 가정하지 않습니다.

타원에서는 잔차가 정확한 최근접 거리가 아니라 반경 방향 대용값입니다. 다른 형상의 거리 잔차와 비교할 때 이 차이와 입력 좌표 단위를 함께 기록합니다. 전체 fit이 성공했더라도 특정 점의 가중치가 낮거나 내점이 아닐 수 있으므로 점별 진단과 수렴 상태를 함께 살펴 적합의 품질을 판단합니다.

동일한 잔차라도 설정한 내점 한계에 따라 Inlier 값은 달라질 수 있습니다. 사용한 강건 손실과 스케일을 보존해야 서로 다른 실행의 가중치를 의미 있게 비교할 수 있습니다.

값을 확인하는 순서

Residual 항목: 부호 있는 좌표 단위 잔차입니다. Weight 항목: 최종 강건 가중치입니다. Inlier 항목: 잔차 임계치 기준 채택 여부입니다.
