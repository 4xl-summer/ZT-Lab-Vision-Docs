사용과 결과 해석

스켈레톤에서 만든 노드와 간선을 독립 배열로 보관합니다. Nodes는 끝점, 분기점 등의 그래프 지점을, Edges는 그 지점들을 잇는 관계를 나타냅니다. 입력 영상 픽셀의 단순한 목록이 아니라 연결 구조를 해석하기 위한 표현입니다.

예를 들어 하나의 분기점에서 세 갈래가 이어진다면 노드의 차수와 그에 연결된 간선을 함께 확인해야 합니다. 영상에 작은 잡음 가지가 있으면 그래프 노드와 간선도 늘어날 수 있으므로 전처리와 전경 연결 규칙을 함께 살펴야 합니다.

반환 배열은 입력 영상 해제와 독립인 스냅샷입니다. 좌표는 원본 ROI의 픽셀 기준이며 전체 영상이나 물리 좌표로 자동 변환되지 않습니다. 그래프가 제공하는 연결 관계와 실제 대상의 물리적 접합 여부를 동일한 것으로 단정하지 마십시오.
