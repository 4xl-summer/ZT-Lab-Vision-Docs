ZVision.ZImage Image(System.Int32 index)

평면 또는 매칭 이미지를 독립 소유 영상으로 가져옵니다.

인자

index
색 평면은 0~2, 매칭은 0 샘플 인덱스 또는 1 거리입니다.

반환: 호출자가 해제할 GrayF64 영상입니다.

Method · 선언 타입 ZVision.AdvancedColorResult

C#
ZVision.ZImage ToRgb(ZVision.PixelFormat format)

Lab 또는 LCH 평면을 원래 백색점과 입력 전달 함수를 사용한 RGB 영상으로 복원합니다.

인자

format

반환: 호출자가 해제할 독립 RGB 영상입니다.
