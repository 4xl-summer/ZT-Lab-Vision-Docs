사용과 결과 해석

전체 입력 Gray8 영상의 강도 통계입니다. Minimum과 Maximum은 픽셀 극값, Mean은 평균 밝기, StandardDeviation은 밝기 표준편차입니다. 바코드 심볼 영역만의 통계 또는 ISO 코드 검증 등급과 혼동하면 안 됩니다.

예를 들어 값이 0과 255인 픽셀이 같은 수라면 평균은 127.5입니다. 평균이 같아도 픽셀 분포가 다르면 표준편차가 다르며, 입력에 넓은 배경이 포함되면 심볼 자체보다 배경이 통계를 지배할 수 있습니다. 영역 선택을 바꾸면 수치의 의미도 바뀝니다.

이 값은 다중 바코드 스캔 결과의 판독 목록과 함께 확인할 수 있지만, 대비 통계가 좋다는 이유만으로 특정 코드를 성공적으로 읽었다는 뜻은 아닙니다. 실제 판독 텍스트, 형식과 상태를 별도로 검토하십시오.
