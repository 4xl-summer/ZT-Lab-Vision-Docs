사용과 결과 해석

비드 경로 검사의 전체 요약입니다. ProbeCount는 탐침 수, RunCount는 보고된 연속 실패 범위 수이고 LongestGapLength는 가장 긴 결손 호 길이의 중점 셀 근사값입니다. Passed는 실패 범위와 갭 기준을 적용한 전체 판정입니다.

여러 탐침 실패가 연속되어 있으면 하나의 run으로 보고될 수 있으므로 두 개수는 같은 의미가 아닙니다. 최장 갭은 단순히 탐침 인덱스 차이가 아니라 경로 길이에 따른 근사이며, 경로 좌표와 단위를 함께 확인해야 합니다.

요약만으로 각 탐침이 왜 실패했는지는 알 수 없습니다. 개별 관찰과 구간별 사유를 함께 읽고 포함 마스크와 경로 설정을 비교하십시오. 픽셀 단위 결과를 실제 도포 길이 공차에 적용할 때는 이미지 보정이 필요합니다.
