사용과 결과 해석

Blob 결과의 한 성분을 다른 영상 처리에 사용할 ROI 도메인으로 바꾸는 도구입니다. 실제 성분의 마스크를 쓰는 경로와 그 성분을 둘러싼 외접 사각형을 쓰는 경로는 선택되는 픽셀이 다릅니다. 성분이 사각형 내부 전체를 채우지 않는다면 두 결과를 교환해서는 안 됩니다.

예를 들어 고리 모양 Blob의 외접 상자는 가운데 구멍까지 포함하지만 성분 마스크는 실제 전경만 포함할 수 있습니다. 배경이나 인접 객체의 픽셀을 후속 통계에 넣고 싶지 않다면 어떤 도메인이 생성되는지 명확히 선택하십시오.

Blob 경계와 원본 ROI의 좌표계를 확인하고 새 도메인을 적용할 영상과 크기·원점이 맞는지 검토해야 합니다. 도메인 생성은 Blob 자체의 물리 치수 보정이나 결함 합격 판정을 수행하지 않습니다.
