어셈블리: ZVision.

확장 NCC 또는 형상 모델을 소유합니다. 사용 후 해제해야 합니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.

기본 타입: System.Object
