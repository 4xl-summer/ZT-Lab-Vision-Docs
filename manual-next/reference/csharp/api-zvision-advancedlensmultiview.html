사용과 결과 해석

여러 타깃 영상의 대응점과 초기 자세를 사용해 렌즈와 영상별 자세를 공동으로 최적화합니다. 단일 영상에서 추정하기 어려운 내부 계수를 여러 시점의 관측으로 제약하려는 경우에 사용합니다. 입력의 각 관측은 해당 영상의 대상 점과 픽셀 점, 초기 자세를 서로 정확하게 대응시켜야 합니다.

초기 LensModel과 옵션은 최적화 출발점과 조정할 변수, 수렴 조건을 정합니다. 최적화 결과의 자세 배열은 입력 영상 순서를 따르므로 영상별 재투영을 평가할 때 순서가 바뀌지 않았는지 확인하십시오. 서로 비슷한 각도의 영상만 반복하면 점 수가 많아도 기하 제약이 충분하지 않을 수 있습니다.

결과의 렌즈 진단과 각 자세를 함께 확인하고, 보정에 사용하지 않은 관측에서 오차를 따로 평가하십시오. 이 메서드는 제공된 점을 최적화하는 것이지 영상에서 점을 검출하거나 실장비의 온도 변화까지 보증하는 과정이 아닙니다.
