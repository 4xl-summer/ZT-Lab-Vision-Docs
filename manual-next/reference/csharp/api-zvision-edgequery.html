FromImage

Method · 선언 타입 ZVision.EdgeQuery

static ZVision.EdgeQuery FromImage(ZVision.ZImage image, System.UInt32 kernel, System.Double sigma, System.Double low, System.Double high, System.UInt64 edgeBudget, System.UInt32 features, System.UInt64 queryBudget)

Extract gradient edges and create an independently owned query.

인자

image
Input image supported by the gradient edge extractor.
kernel
Odd Gaussian window size from 1 through 127.
sigma
Positive finite Gaussian sigma.
low
Nonnegative low hysteresis threshold.
high
High hysteresis threshold.
edgeBudget
Work budget for extraction.
features
Bitmask: 1 size, 2 closure, 4 first, 8 bounds.
queryBudget
At least eight times the sum of edges and points.

반환: Caller-owned edge query.

void CalculateGradients(ZVision.ZImage image, System.UInt32 kernel, System.Double sigma, System.UInt32 features, System.UInt64 workBudget)

Calculates unscaled Sobel normal response, bilinearly sampled at subpixel positions.

인자

image
Original extraction image, with matching ROI dimensions and origin.
kernel
Odd Gaussian window from 1 to 127.
sigma
Positive Gaussian sigma.
features
16 for magnitude, 32 for angle, or both.
workBudget
Response calculation work budget.
