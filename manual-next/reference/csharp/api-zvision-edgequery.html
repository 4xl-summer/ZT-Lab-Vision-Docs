FromImage

Extract gradient edges and create an independently owned query.

Available

Checks whether a single feature bit is available.

Get

Gets included metadata by dense index or label.

Points

Copies an included edge's ordered points.

SetIncluded

Excludes or re-includes an existing stable label.

Delete

Deletes a label permanently.

CalculateGradients

Calculates unscaled Sobel normal response, bilinearly sampled at subpixel positions.

Gradients

Copies a requested stored gradient response array.

Dispose

Releases the query handle.
