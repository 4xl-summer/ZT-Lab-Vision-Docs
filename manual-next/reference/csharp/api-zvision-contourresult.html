닫힌 윤곽의 스냅샷

ContourResult는 전경 픽셀 셀 경계의 닫힌 링을 담는 독립적인 스냅샷입니다. Contours에서 링의 목록을 읽으며 별도 해제가 필요하지 않습니다. 원본 영상 전체나 실시간으로 변하는 핸들의 대체물이 아닙니다.

외곽과 구멍

한 전경 영역에는 외부 경계뿐 아니라 내부 구멍 경계가 있을 수 있습니다. 예를 들어 중앙이 빈 고리의 외곽과 내부 배경 경계는 별개의 링으로 살펴야 합니다. 외곽만으로 전경의 모든 경계를 나타낸다고 가정하지 않습니다.

좌표와 순서

셀 경계는 픽셀 중심이 아니라 셀 꼭짓점과 그 사이 선분을 사용합니다. 원본 영상에 그릴 때 ROI의 위치 기준과 링의 순서를 함께 유지해야 합니다. 점을 임의로 정렬하면 연결 관계와 방향이 달라집니다.

사용 조건

스냅샷을 다른 프레임과 비교할 때 입력 마스크, 연결 조건과 ROI를 기록합니다. 원본이 잘리거나 임계값이 바뀌면 링의 모양과 개수가 달라질 수 있으며, 목록 순번을 영구 객체 ID로 취급해서는 안 됩니다.
