사용과 결과 해석

최소 원환을 찾을 때 중심 후보가 놓일 수 있는 닫힌 직사각형 영역을 지정합니다. Minimum은 작은 x와 y의 끝점, Maximum은 큰 끝점이며 좌표 단위는 입력 점과 같습니다. 중심의 허용 범위이지 원환의 안쪽·바깥쪽 반지름 자체를 지정하는 값은 아닙니다.

예를 들어 중심이 대략 (10, 20) 부근이라는 사전 정보가 있다면 그 주변의 최소·최대 좌표로 탐색 범위를 줄일 수 있습니다. 이때 실제 중심이 지정 범위 밖이라면 범위 내에서 계산된 결과를 전역 최적 중심으로 해석해서는 안 됩니다. 반대로 범위를 너무 넓게 잡으면 탐색 부담이 커질 수 있습니다.

최소 좌표와 최대 좌표의 순서와 유한성을 확인하고, 입력 점이 ROI 로컬인지 월드 좌표인지에 맞춰 같은 좌표계로 지정하십시오. 결과의 중심과 반지름은 입력과 같은 좌표 단위이며, 원환 두께를 생산 공차로 쓰려면 보정과 사용자 기준을 별도로 적용해야 합니다.
