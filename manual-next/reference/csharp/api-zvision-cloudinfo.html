사용과 결과 해석

CloudInfo는 C# 점군이 보유한 슬롯과 좌표 메타데이터의 값입니다. Count는 null을 포함한 전체 슬롯 수이고 ValidCount는 실제 점이 들어 있는 수입니다. 예를 들어 세 슬롯이 유효 점, null, 유효 점이면 두 값은 각각 3과 2입니다. ToPoints의 배열 인덱스는 전체 슬롯을 기준으로 하므로 ValidCount만큼 앞에서 자르면 결측 뒤의 점을 놓칠 수 있습니다.

Unit은 점과 거리 임계값의 길이 단위이며 Frame은 좌표계 식별자입니다. 같은 위치를 다른 frame의 점과 정합하려면 원본에서 목표로 가는 변환의 방향을 명시해야 합니다. Info는 그 시점의 값 스냅샷이므로 이를 읽었다고 PointCloud의 소유가 이전되지 않습니다. 생성한 점군은 using 또는 Dispose로 정리하고, 원본과 다른 공유 핸들을 얻었다면 그 핸들도 별도로 정리합니다.
