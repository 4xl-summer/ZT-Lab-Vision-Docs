두 윤곽의 선분 거리

BlobContourDistance는 두 점열 윤곽의 선분 사이 최소 유클리드 거리를 계산합니다. 물체의 중심 사이 거리와는 다르며, 열린 경로와 닫힌 경로에서 고려되는 선분도 달라질 수 있습니다.

닫힘의 효과

세 점을 차례로 잇는 경로에서 닫힘을 선택하면 마지막 점과 첫 점을 잇는 선분도 경계에 포함됩니다. 다른 윤곽이 이 선분 근처에 있다면 열린 경로로 계산한 거리와 차이가 날 수 있습니다. 각 입력의 경로 상태를 따로 확인해야 합니다.

Run 사용

Run에 두 점열과 각 경로의 닫힘 조건, 작업량 제한을 해당 시그니처에 맞게 전달합니다. 두 점열이 서로 다른 ROI에서 생성되었다면 공통 좌표로 옮긴 뒤 계산합니다. 단위가 픽셀이라면 반환 거리도 그 좌표의 길이 단위로 해석합니다.

검증

두 점이 각각 (1,2)와 (4,6)인 단순 예에서 유클리드 거리는 5입니다. 실제 경로에는 점뿐 아니라 선분도 있으므로 점끼리의 거리만 비교해 최단값을 단정하지 말고 원본 윤곽에 결과 관계를 표시해 확인합니다.
