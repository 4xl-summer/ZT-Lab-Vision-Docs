모델 위치를 원본으로

AdvancedImageTransform은 모델 좌표에서 원본 영역으로 되돌리는 변환의 ScaleX, ScaleY, PadX, PadY와 Region을 담습니다. 크기 조정과 패딩이 있었던 입력의 결과 좌표를 원래 영역에 대응시킬 때 필요한 정보입니다. 좌표 단위와 방향을 구별해야 합니다.

변환 순서

모델에 넣기 전 영상이 가로와 세로로 크기 조정되고 패딩되었다면 출력 위치를 원본에 표시할 때 그 전처리를 역방향으로 해석해야 합니다. 배율과 패딩을 뒤바꾸면 같은 숫자라도 원본에서 다른 위치가 됩니다. 실제 계산 순서는 해당 변환 메서드의 계약을 따릅니다.

영역과 스케일

Region은 원본 영역과의 관계를 나타내며 ScaleX와 ScaleY는 두 축의 배율을 구분합니다. 가로와 세로 배율이 같다고 가정하면 비등방 크기 조정 결과에서 상자의 종횡비나 위치가 어긋날 수 있습니다. 패딩도 두 축에 각각 기록합니다.

결과 검증

모델의 결과 점이나 경계 상자를 원본 영상에 겹쳐 눈에 보이는 대상과 맞는지 확인합니다. 변환 값이 있다는 것 자체가 추론의 검출 정확도나 보정 정확도를 보장하지는 않으며 입력 크기와 영역을 함께 보관해야 재현할 수 있습니다.
