사용과 결과 해석

세계 좌표계에서 평면을 원점과 두 개의 직교 단위 축으로 정의합니다. Origin은 3차원 위치이고 AxisU와 AxisV는 평면 안의 방향입니다. 두 축은 길이가 1이고 서로 직교해야 하며, 길이 단위와 세계 프레임 식별자도 함께 지정합니다.

평면상의 좌표 (u, v)는 원점에서 첫 축 방향으로 u, 둘째 축 방향으로 v만큼 이동한 위치로 해석합니다. 예를 들어 원점이 (0,0,10), 두 축이 세계 x와 y 방향이면 평면 좌표 (2,3)은 세계 위치 (2,3,10)에 대응합니다. 숫자의 길이 단위는 생성 시 지정한 단위를 따릅니다.

카메라 광선과의 교차나 평면 정류에 이 평면을 전달할 때는 카메라 자세의 세계 프레임과 단위가 일치해야 합니다. 축이 직교하지 않거나 잘못된 프레임을 혼용하면 결과 좌표를 의미 있게 해석할 수 없습니다. 이 구조는 실제 부품 표면이 평면이라는 가정을 대신 검증하지 않습니다.
