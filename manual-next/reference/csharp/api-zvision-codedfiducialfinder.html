사용과 결과 해석

흰 quiet ring과 알려진 셀 크기를 이용해 영상에서 부호화된 표식 하나를 찾습니다. 입력은 Gray8이고 셀 크기는 1~256픽셀, 검은 셀 판정 문턱은 0~254입니다. expectedId가 0이면 특정 식별자로 제한하지 않으며, 0이 아니면 지정한 표식을 찾는 조건으로 사용합니다.

함수는 제한된 영상 안의 위치를 검사하고 분리된 복수 후보가 발견되면 이를 임의의 단일 후보로 고르지 않고 거부합니다. 반환된 위치는 현재 ROI의 로컬 좌표이므로 전체 영상 좌표로 비교할 때는 영상 원점을 고려하십시오. 예를 들어 원점이 다른 두 ROI의 같은 로컬 좌표가 실제로 같은 전체 위치라는 뜻은 아닙니다.

셀 크기와 문턱은 실제 촬영 배율과 대비에 맞게 선정해야 하며, 잘린 quiet ring이나 여러 표식이 있을 때의 실패를 정상 결과와 구별해야 합니다. 합성 표식에서 검출된 사실만으로 인쇄, 조명 및 실제 카메라의 안정성을 보장하지 않습니다.
