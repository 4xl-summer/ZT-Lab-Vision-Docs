이 타입을 받는 공개 호출

AdvancedMatchModel.Diagnose: 형상 포즈 주변의 대응 에지와 기하 잔차를 계산합니다. pose 인자: 진단할 형상 포즈입니다. 반환: 모델 및 대상 커버리지와 적합 오차입니다.

ExtendedShapeModel.Diagnose: 형상 포즈를 진단합니다. pose 인자: 진단할 형상 포즈입니다. 반환: 형상 진단입니다.

ExtendedShapeModel.RegionDiagnostics: 영역 진단을 계산합니다. pose 인자: 진단할 형상 포즈입니다. 반환: 영역 진단입니다.

ExtendedShapeModel.RefinePose: 포즈를 정밀화합니다. initial 인자: 정밀화할 초기 포즈입니다. 반환: 정밀화 결과입니다.

ShapeModelExtensions.RegionDiagnostics: 변환된 모델의 검색 영역 밖 면적과 특징 비율을 계산합니다. pose 인자: 검사할 로컬 pose입니다. 반환: 독립 진단 결과입니다.

ShapeModelExtensions.RefinePose: 주어진 형상 pose의 위치, 각도와 두 축 배율을 국소 정밀화합니다. initial 인자: 초기 pose입니다. 반환: 복사된 pose와 간격·예산 상태입니다.
