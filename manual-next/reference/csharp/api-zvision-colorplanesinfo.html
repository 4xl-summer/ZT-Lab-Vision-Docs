사용과 결과 해석

색 변환 결과의 색 공간과 영상 기하를 담습니다. Space는 HSV 또는 CIELAB 좌표계이고 Width와 Height는 평면의 픽셀 크기입니다. OriginX와 OriginY는 전체 영상 좌표계에서 이 결과가 시작하는 원점입니다.

예를 들어 너비 2의 ROI가 전체 영상 x=10에서 시작한다면 평면의 로컬 x=0과 전역 x=10은 같은 위치를 가리킬 수 있습니다. 같은 배열 인덱스라는 이유만으로 원점이 다른 두 색 평면을 바로 비교하면 잘못된 픽셀이 대응될 수 있습니다.

Space가 다르면 세 채널의 물리적 의미와 값 범위가 다릅니다. HSV의 색상과 Lab의 색축을 같은 숫자로 비교하지 말고 변환 백색점과 전달 함수도 확인하십시오. 이 정보 구조는 개별 평면의 소유권을 대신 관리하지 않습니다.
