사용과 결과 해석

명목 물체 자세와 관측된 물체 자세에서 픽스처 이동을 계산합니다. 두 입력은 같은 단위와 프레임을 쓰는 world←object 강체 변환이어야 합니다. 결과는 명목 세계 점을 관측 위치로 옮기는 세계 내 변환이므로 물체 자세 자체와 합성 순서를 혼동해서는 안 됩니다.

계산은 관측 자세에 명목 자세의 역을 합성합니다. 명목과 관측이 같으면 결과는 항등 변환이고, 같은 방향으로 위치가 이동했다면 이 델타를 명목 좌표에 적용해 관측 위치를 예측할 수 있습니다. 회전과 이동이 함께 있을 때는 단순히 평행이동 벡터만 빼는 것과 같다고 가정할 수 없습니다.

측정 자세의 프레임이 다르거나 길이 단위가 다르면 직접 비교하지 말고 먼저 공통 프레임으로 변환하십시오. 결과는 제공된 두 자세의 관계를 수치적으로 계산하는 값이며, 각 자세 측정의 불확도나 실제 로봇의 안전 범위를 자동으로 평가하지 않습니다.
