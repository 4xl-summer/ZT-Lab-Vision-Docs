사용과 결과 해석

여러 바코드의 판독 목록과 입력 영상 강도 통계를 함께 담습니다. Reads는 발견한 기호의 독립 목록이고 ImageMetrics는 전체 입력 영상의 최소·최대·평균과 표준편차입니다. 영상 통계는 개별 심볼의 ISO 검증 등급이 아닙니다.

예를 들어 배경이 넓으면 전체 평균이 심볼보다 배경 밝기의 영향을 더 크게 받을 수 있습니다. 판독 문자열, 형식 및 위치는 각 Read에서 확인해야 하며, 목록이 비어 있어도 입력 통계는 존재할 수 있습니다. 검색이 모든 심볼을 반드시 찾는다는 보장은 없습니다.

각 위치의 로컬·전역 좌표와 영상 원점을 확인하고 회전 시도 및 길이 조건을 결과와 함께 기록하십시오. 통계가 적절해 보인다는 사실과 실제 코드 판독 성공은 서로 다른 판단입니다.
