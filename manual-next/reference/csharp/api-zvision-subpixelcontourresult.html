보간 경로의 스냅샷

SubpixelContourResult는 픽셀 중심 사이 밝기 등값을 보간한 경로의 독립 스냅샷을 Contours로 담습니다. 별도 해제가 필요하지 않으며 실행 결과의 수명과 독립적인 값으로 여러 경로를 읽을 수 있습니다.

경로별 판독

각 SubpixelContour의 Points와 Closed를 함께 확인합니다. 여러 경로가 있는 결과를 하나의 점열로 이어 붙이면 원래 서로 떨어진 선을 잘못 연결할 수 있습니다. 경로별 경계와 소속을 유지하여 표시합니다.

좌표 기준

경로 점은 ROI 로컬이므로 전체 영상에 그리려면 해당 원점을 적용합니다. 소수 좌표를 화면 표시용으로 반올림하면 원래 결과와 다를 수 있으므로 기하 계산에는 원본 좌표를 유지합니다.

결과 비교

두 실행의 경로 수가 같아도 위치와 형상은 다를 수 있습니다. 입력 등치값과 조명, ROI, 보정 및 전처리 조건을 같이 기록하고 원본 밝기 변화와 경로를 겹쳐 원하는 경계가 선택되었는지 확인합니다.
