사용과 결과 해석

직선 또는 원 측정에서 관측된 범위를 기준 길이 또는 원호 각도와 비교하는 정책입니다. Reference는 양수 기준값이고 MinimumFraction은 0~1의 최소 비율입니다. 선의 길이는 점 또는 영상 좌표의 길이 단위를, 원호 각도는 라디안을 따릅니다.

예를 들어 기준 길이가 100이고 실제로 덮인 범위가 70이면 비율은 0.7입니다. 최소값을 0.8로 정했다면 선을 계산할 수 있어도 커버리지 기준은 통과하지 못합니다. 이 정책은 탐침의 수를 단순히 세는 대신 모델을 따라 확보한 범위를 확인합니다.

고급 측정 결과에서는 적합 상태와 커버리지 상태를 함께 살펴보십시오. 정책을 적용하지 않은 결과의 값 없음과 적용했으나 비율이 0인 결과는 의미가 다릅니다. 명목 기준을 실제 부품 치수와 동일하게 사용할 때는 영상 좌표에서 물리 단위로의 보정을 먼저 확인해야 합니다.
