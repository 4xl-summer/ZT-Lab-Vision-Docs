사용과 결과 해석

SpatialIcpOptions는 원본 점군을 목표 점군에 점대점 정합할 때 최대 반복 수와 대응점 선택, 종료 기준을 지정합니다. iterations는 양수, distance는 점군 길이 단위의 유한 양수입니다. trim은 거리 조건을 통과한 대응 중 유지할 비율이며 0보다 크고 1 이하, 기본 1입니다. rms는 반복 간 RMS 변화의 유한한 0 이상 허용값이며 기본은 1e-8입니다.

예를 들어 점군 단위가 밀리미터이고 distance가 2라면 더 먼 점은 그 반복의 대응으로 유지되지 않습니다. 이 값이 너무 작으면 세 대응을 확보하지 못해 오류가 날 수 있고, 크게 잡으면 멀리 떨어진 대응을 허용할 수 있습니다. 결과의 Converged는 RMS 변화에 따른 정지 조건이지 실제 공차의 보증이 아닙니다. Transform 방향과 원본·목표 frame, Inliers와 Rms를 확인하고 독립 점을 별도로 평가합니다.
