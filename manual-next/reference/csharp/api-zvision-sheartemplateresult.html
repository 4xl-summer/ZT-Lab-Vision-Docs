사용 맥락과 결과 해석

전단 템플릿 검색의 복사된 매치 배열, 평가 포즈 수와 종료 상태입니다. Matches가 비어 있더라도 Termination이 전체 완료인지 제한으로 중단된 것인지 확인해야 합니다. 각 후보에는 기본 NCC 포즈와 무차원 전단 계수가 함께 있습니다.

전단 축, 위치·회전·배율 격자 및 별도의 작업 한도가 결과와 비용을 결정합니다. 이 검색은 coarse와 subpixel을 지원하지 않습니다. 예를 들어 한 후보가 나왔다고 해도 종료가 예산이면 아직 시험하지 않은 자세가 있을 수 있습니다. 결과의 기준점은 검색 ROI 로컬 좌표와 전역 좌표를 구별해 사용합니다.

작업 상한은 평가 예산과 모델 표본 수의 조합에도 영향을 받습니다. 영상과 설정을 바꾸면 같은 최대 반환 수라도 실제 작업량은 달라질 수 있으므로 별도로 측정하세요.
