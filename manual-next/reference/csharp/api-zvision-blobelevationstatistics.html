높이 영상의 영역 통계

BlobElevationStatistics는 Blob 레이블별로 이미 보정된 깊이 또는 높이 영상을 측정합니다. 라벨은 측정할 픽셀의 소속을 정의하고 깊이 영상은 해당 위치의 수치를 제공합니다. 호출이 원시 센서 값을 자동으로 물리 높이로 보정하는 것은 아닙니다.

정렬과 형식

측정 영상과 레이블이 동일한 이미지 위치를 가리키도록 크기와 ROI 원점을 확인합니다. 수치 영상 형식과 유한 값 조건은 Measure 계약을 따릅니다. 같은 크기라도 다른 영역을 나타내면 다른 물체의 값을 집계하게 됩니다.

단위 해석

입력 높이의 영점과 단위는 보정 과정에 달려 있습니다. 예를 들어 같은 수치 2라도 밀리미터로 보정한 영상과 다른 단위 영상은 직접 비교할 수 없습니다. 보정 버전과 입력 영상의 생성 방법을 결과와 함께 저장합니다.

결과 검사

각 레이블의 통계를 읽기 전 원본 마스크가 원하는 대상을 선택했는지 확인합니다. 가려진 픽셀, 센서 잡음과 기준면 오류는 통계에 영향을 줄 수 있으므로 실제 장비에서의 측정 정확도는 별도 검증해야 합니다.
