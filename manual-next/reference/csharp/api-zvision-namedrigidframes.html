사용과 결과 해석

이름이 부여된 좌표계들과 강체 변환 간선으로 구성한 트리에서 두 프레임 사이의 경로를 해석합니다. 이름과 프레임 식별자는 연결 구조를 찾기 위한 메타데이터이며 서로 다른 프레임의 좌표를 단순히 같은 숫자로 취급하는 대신 변환을 합성하도록 돕습니다.

예를 들어 카메라, 로봇 및 월드 프레임이 간선을 통해 이어져 있다면 출발 이름과 도착 이름을 지정해 경로상의 변환을 합성할 수 있습니다. 반환 방향이 대상←원본이라는 점을 확인하고 반대 방향이 필요하면 유효한 역변환을 사용해야 합니다. 이름은 UTF-8 기준 길이 제한과 유효성 조건을 따릅니다.

트리가 연결되어 있고 프레임 이름이 유일하며 각 강체 변환의 단위와 방향이 일관되는지 확인하십시오. 같은 이름을 임의로 붙였다고 서로 다른 물리 좌표계가 같아지는 것은 아닙니다. 결과는 제공된 간선의 합성이므로 각 간선 보정 오차는 별도로 관리해야 합니다.
