사용과 결과 해석

SpatialDepthCalibration은 격자의 각 셀에 대한 깊이 보정식을 보유하는 소유 핸들입니다. 대응하는 원시 격자와 기준 격자들을 준비한 뒤 Spatial3dAdvanced의 학습 경로로 생성하며, 선형 또는 이차 모델을 선택하는 경로가 있습니다. 학습 쌍은 크기, 단위, frame, 간격과 원점이 서로 맞아야 하고 각 셀에 모델을 구하기에 충분한 유효 대응이 필요합니다.

Apply는 일치하는 크기와 단위의 DepthMap에 보정식을 적용하고 새 소유 깊이 격자를 반환합니다. 입력이 결측인 셀은 출력에서도 결측으로 남습니다. 예를 들어 한 셀의 보정식이 1+2x이고 원시 높이가 4라면 그 셀의 보정값은 9입니다. 보정 객체와 결과 지도는 각각 using 또는 Dispose로 닫습니다. 메타데이터가 맞지 않거나 표본이 퇴화하면 오류를 처리해야 하며, 합성 식의 재현은 실장비 정확도 평가를 대신하지 않습니다.
