인자

static ZVision.ShearTemplateResult FindShear(ZVision.ZImage source, ZVision.AdvancedMatchModel model, ZVision.AdvancedMatchingOptions options, ZVision.AdvancedSearchAxis shear, System.UInt64 maxWork, ZVision.ZImage mask = null)

실제 영상 표본을 변환해 X 전단 계수를 검색합니다.

인자

source
검색 회색 영상입니다.
model
NCC 모델입니다.
options
일반 NCC pose 설정입니다. coarse 및 subpixel은 미지원입니다. 호출 중 설정 객체를 수정하지 마세요.
shear
u'=u+shear*v의 무차원 전단 범위입니다.
maxWork
후보 예산×모델 표본 수 상한입니다.
mask
선택 검색 마스크입니다.

반환: 전단 계수와 검색 종료 진단입니다.

all-care 마스크를 각 해상도로 축소해 NCC 피라미드를 검색합니다.

인자

source
검색 회색 영상입니다.
model
NCC 모델입니다.
options
pose 및 마스크 offset 설정입니다. 호출 중 설정 객체를 수정하지 마세요.
mask
Gray8 검색 마스크입니다.
firstLevel
거친 최초 층 0..10입니다.
lastLevel
마지막 층 0..firstLevel입니다.
maxWork
후보 예산×모델 표본수 한도입니다.

반환: 복사된 후보와 종료 상태입니다.
