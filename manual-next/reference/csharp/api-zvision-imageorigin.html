영상의 전역 원점

ImageOrigin은 이미지 또는 ROI의 전역 픽셀 원점 X와 Y를 나타냅니다. ROI 안에서 계산한 로컬 좌표를 원본 전체 영상에 표시하거나 두 영상의 위치 기준을 맞출 때 사용합니다.

좌표 변환 예

ROI 전역 원점이 (100,200)이고 로컬 점이 (10,20)이면 전역 점은 (110,220)입니다. 반대로 전역 위치를 로컬로 바꾸려면 원점을 빼야 합니다. 한쪽 원점만 적용하거나 두 번 더하면 표시가 어긋납니다.

크기와 구분

원점은 위치를 나타내며 ROI의 폭과 높이를 포함하지 않습니다. 같은 원점이어도 크기가 다른 영역일 수 있고, 크기가 같은 두 영상도 원점이 다를 수 있습니다. 두 정보를 함께 확인해 올바른 픽셀 대응을 정합니다.

후속 측정

블롭 중심이나 윤곽을 다른 영상 위에 표시할 때 로컬·전역 기준을 명시합니다. 픽셀 원점 변환은 카메라 보정이나 물리 단위 변환과 별개이므로 세계 좌표가 필요하면 해당 보정도 적용해야 합니다.
