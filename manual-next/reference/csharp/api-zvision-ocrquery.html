공개 타입

ZVision.OcrQuery · class

어셈블리: ZVision.

단일 줄 OCR 판독을 계산하는 지연 계획입니다. 사용 후 Dispose해야 합니다.

이 타입은 System.IDisposable을 구현합니다. 사용 후 Dispose() 또는 using으로 해제하세요.
