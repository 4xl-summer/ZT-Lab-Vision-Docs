사용 맥락과 결과 해석

다중 해상도 특징 모델의 한 점입니다. X와 Y는 모델 로컬 픽셀, Scale은 검출된 이산 피라미드 배율, Angle은 패치 기울기 방향의 라디안 값이며 Response는 해당 층의 Harris 응답입니다. 이 값은 이미지를 검색해 얻은 확정 포즈가 아닙니다.

모델 특징을 검사할 때는 좌표만이 아니라 배율과 방향도 함께 비교합니다. 서로 다른 피라미드 수준의 점을 한 영상에 표시할 때는 해당 값의 기준 프레임을 유지하세요. 응답이 크다고 대응이 자동으로 정확해지는 것은 아니며 실제 매칭 결과의 대응·내점과 변환 유무를 별도로 검토합니다.

Scale은 영상 전체를 임의의 비율로 변경하라는 명령이 아니라 해당 특징이 발견된 이산 수준을 설명하는 값입니다. 검색 결과의 물체 배율과 비교할 때 역할을 구분하세요.

값을 확인하는 순서

X 항목: 로컬 X 픽셀 좌표입니다. Y 항목: 로컬 Y 픽셀 좌표입니다. Scale 항목: 이산 피라미드 배율입니다. Angle 항목: 패치 기울기 방향 라디안입니다. Response 항목: 해당 층의 Harris 응답입니다.
