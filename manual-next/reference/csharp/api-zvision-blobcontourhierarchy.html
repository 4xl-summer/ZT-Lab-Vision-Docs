윤곽 링의 계층

BlobContourHierarchy는 서로 접촉하지 않는 단순 윤곽 고리의 포함 관계를 계산합니다. 외곽과 구멍, 그 안에 있는 다른 링을 직접 부모·자식 관계로 나타냅니다. 단순히 링의 크기순 목록과 같은 구조가 아닙니다.

중첩 예

큰 외곽 링 안에 구멍이 하나 있고 그 구멍 안에 작은 링이 있다면 큰 링의 직접 자식은 구멍이며 작은 링은 구멍의 자식입니다. 직접 자식 수에 모든 깊이의 자손을 합쳐 읽으면 계층이 달라집니다.

Analyze와 면적

Analyze에 마스크와 최소 면적 및 작업량 제한을 해당 계약에 맞게 지정합니다. 결과에서 선택 상태와 부모 관계를 함께 살펴보아야 면적 필터로 제외된 링과 원래의 포함 구조를 혼동하지 않습니다.

결과 검증

노드의 구멍 여부, 면적과 부모를 원본 윤곽 위에 표시합니다. 반환 순서나 식별자는 그 분석 결과의 범위에서 읽고 다른 이미지의 같은 번호를 같은 객체로 간주하지 않습니다. ROI 잘림이나 분할 변화는 계층을 바꿀 수 있습니다.
