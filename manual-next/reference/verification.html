API·예제 실행 검증 기록

실제 SDK와 대조한 기준, 합성 입력의 실행 결과, 문서 코드의 검증 상태.

환경과 실행 방식

SDK: ce902e85c3405eb63df40c699ddbdf70ee1d03bd · Linux x64 · Ubuntu 24.04 WSL · Rust 1.85.1 · CPython 3.14.0 · .NET SDK 10.0.403. 실제 예제 소스를 빌드하고 종료 코드와 수치 검사를 확인합니다. 문서 코드 블록은 별도로 발췌해 컴파일·실행하며, 선언과 호출 부분은 독립 프로그램으로 세지 않습니다.

예제 프로젝트에는 해당 입력과 기대값 검사가 있습니다. 실행 성공은 기록된 합성 입력에 한정하며 모든 API·경계·스레드·하드웨어의 검증을 뜻하지 않습니다.
