가이드와 참조의 역할

가이드는 알고리즘 원리·입력 형식·결과·실전 사용법을 설명합니다. 자동 선언 색인은 코드를 다시 읽지 않고 공개 멤버 이름·시그니처를 찾아볼 수 있도록 만든 보조 인덱스입니다. 오류 계약·기본값·실제 샘플의 컴파일까지 확인하지 않고 API 페이지를 완료로 표시하지 않습니다.
