      사용과 결과 해석

      문자 인식 결과에 대해 각 글자가 기대 위치에 있는지 확인합니다. read에는 글꼴 판독 스냅샷을, expected에는 줄별 기대 위치 목록을 전달합니다. 기대 목록은 검출된 줄 수와 각 줄의 글자 수에 정확히 대응해야 합니다. 이 검사는 글자를 새로 인식하거나 모델을 다시 학습하는 단계가 아니라 이미 나온 결과에 공간 조건을 추가하는 단계입니다.

      각 항목은 기대 중심 x와 y, 그리고 각 방향의 허용 오차를 갖습니다. 결과 셀의 중심은 사각형의 원점에 너비와 높이의 절반을 더해 구합니다. 예를 들어 중심이 (10, 20), 기대가 (11, 20), x 허용 오차가 1이면 x 조건을 통과합니다. 경계값은 포함되며 두 방향이 모두 허용 범위 안이어야 해당 글자가 통과합니다.

      위치는 판독 셀의 좌표계에서 해석해야 합니다. 줄 또는 글자 개수가 다르거나 기대 좌표가 유한하지 않거나 오차가 음수면 오류입니다. 반환 결과에는 글자별 통과 상태와 전체 상태가 담기며, 전체 통과에는 원래 판독의 수락과 모든 글자 위치 통과가 모두 필요합니다. 따라서 위치가 맞더라도 판독 점수에서 실패하면 전체 결과가 통과로 바뀌지는 않습니다.
