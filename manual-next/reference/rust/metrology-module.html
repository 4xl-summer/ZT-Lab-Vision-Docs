측정 API의 공개 경로

기본 Rust 빌드에서 metrology는 비공개 소스 모듈이며 공개 타입은 crate 루트에서 재수출됩니다. 타입별 참조를 이용하세요.

사용과 결과 해석

Rust에서 metrology 소스 모듈 이름을 공개 경로로 직접 사용하는 대신 crate 루트에서 공개한 타입과 함수를 선택합니다. 먼저 Gray 영상과 ROI 기준을 준비한 다음 ProfileSpec의 양 끝, 표본 수와 폭을 정해 단면 강도를 얻습니다. 단면의 변화에서 CaliperSpec의 극성과 임계값에 맞는 에지를 고르고, 여러 위치에서 형상을 찾을 때는 선 또는 원 계측 모델과 프로브 설정을 사용합니다. 개별 프로브가 에지를 찾았다는 상태와 최종 피팅에 그 점이 채택되었는지는 별개이므로 관측과 형상 상태를 함께 확인하십시오. 예를 들어 강도가 0에서 80으로 바뀌는 표본에서는 탐색 방향의 강도 변화로 에지 후보를 구하고, 반환된 위치와 강도를 실제 표본 및 선택한 임계값과 함께 확인합니다. 이 좌표는 영상의 ROI 로컬 픽셀이라는 점을 기록하고 세계 좌표가 필요하면 ROI 원점을 복원한 뒤 해당 글로벌 좌표계로 학습한 평면 보정을 적용합니다. 고급 강건 적합 설정에서 사용하는 일부 보조 열거형은 별도 패키지 경로가 필요할 수 있으므로 타입별 실제 공개 경로를 확인하십시오. 형상 실패나 빈 에지 목록을 유효한 0 좌표로 바꾸지 않아야 후속 판정에서 실제 원점과 구별할 수 있습니다. 같은 모델을 다른 영상에 적용할 때는 프레임의 크기와 ROI 기준, 검색 범위가 여전히 맞는지 다시 살펴야 합니다. 관련 타입별 참조는 필드의 실제 조건을 확인하는 출발점이며, 입력 검증 실패와 유효한 호출에서 발견된 빈 결과는 따로 처리합니다.
