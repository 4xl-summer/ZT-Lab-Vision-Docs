공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 ZImage in zvision입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub struct ZImage { /* private fields */ }

불변 픽셀 저장소를 소유하는 이미지 객체입니다. 공유와 ROI는 픽셀을 복사하지 않으며 원본이 해제된 뒤에도 유효합니다.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.
