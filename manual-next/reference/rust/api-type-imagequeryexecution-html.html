공개 멤버

    트레이트 구현 멤버

      이미지 출력 실행 결과

      ImageQueryExecution은 QueryExecution<ZImage>의 별칭입니다. ImageQuery의 execute는 계획을 실행하고 ZResult로 이 결과를 반환합니다. 성공한 실행 결과에는 출력 영상과 계획에서 이름을 붙인 캡처가 포함될 수 있습니다.

      출력 접근과 공유

      output()은 실행 결과가 살아 있는 동안 출력 ZImage에 대한 참조를 반환합니다. acquire_output()은 출력 영상의 독립적인 공유를 반환합니다. 실행 객체를 넘어 영상을 보관해야 하는 경우 단순 참조와 독립 공유의 수명 차이를 고려합니다.

      이름 붙인 캡처

      get_image(name)은 이름에 해당하는 캡처 영상의 독립 공유를 ZResult로 반환합니다. 존재하지 않는 이름 등 호출이 실패할 수 있으므로 결과를 확인해야 합니다. 캡처 이름은 쿼리 계획에서 지정한 이름과 정확히 맞아야 원하는 중간 영상을 얻을 수 있습니다.

      계획과 실행

      ImageQuery는 지연 계획이며 execute는 계획을 빌려 실행합니다. 같은 계획을 다시 실행할 수 있지만 각 실행의 출력과 캡처는 해당 실행 결과로 구분합니다. 연산을 덧붙이는 계획 구성과 결과를 읽는 시점을 혼동하지 않도록 소유권과 오류를 함께 처리합니다.
