공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 FromCore in zvision::bridge입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub trait FromCore: Sized { type Target; // Required method fn from_core(value: Self::Target) -> Self; }

Explicit bridge for from_core.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

연결과 소유권

Core가 이미 소유한 값을 공개 facade 객체로 넘겨 기존 Core 기반 코드와 새 객체 API를 연결합니다. 이 트레이트의 Target은 변환 대상 객체에 대응하는 Core 표현이며, from_core는 그 값을 받아 새 소유자로 이전합니다. 예를 들어 Core 이미지로 생성한 픽셀 저장소를 facade ZImage로 넘길 수 있습니다. 이미지 구현은 픽셀을 다시 복사하지 않으므로 변환 자체로 별도의 픽셀 버퍼가 만들어진다고 가정하면 안 됩니다.

호출부에서는 zvision의 bridge 모듈에서 FromCore를 가져와야 트레이트 메서드를 이름으로 사용할 수 있습니다. 매개변수로 Core 값을 넘긴 뒤에는 Rust 이동 규칙에 따라 그 값을 계속 사용할 수 없습니다. 변환 전에 별도 소유권이 필요하다면 해당 Core 객체가 제공하는 공유 방법과 그 수명을 확인하십시오.

이 경계는 픽셀 형식을 바꾸거나 수치 처리를 수행하는 연산이 아닙니다. 변환 후 ROI는 facade의 좌표 및 공유 저장소 규칙을 따르고, 원본 소유자를 해제해도 ROI가 보유한 공유는 독립적으로 유지됩니다. 실제 사용할 타입의 Target과 구현을 확인한 뒤 변환하면 타입 불일치와 수명 혼동을 줄일 수 있습니다.
