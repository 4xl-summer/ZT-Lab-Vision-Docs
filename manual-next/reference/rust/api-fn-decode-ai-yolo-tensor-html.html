    트레이트 구현 멤버

      사용과 결과 해석

      평탄화된 YOLO 텐서를 후보와 클래스 수, 배치 방식에 따라 읽어 검출 스냅샷으로 변환합니다. 한 후보의 속성 수는 좌표 4개와 선택적 objectness 1개, 클래스 수의 합입니다. values 길이는 후보 수와 속성 수를 곱한 값과 일치해야 합니다.

      layout은 후보 우선 또는 속성 우선 순서를 선택하고 score_meaning은 점수가 확률인지 logits인지 정합니다. logits는 독립 sigmoid로 변환하며 objectness가 있으면 클래스 점수에 곱합니다. options의 좌표 형식은 중심 기반이어야 하고 transform은 실제 모델 전처리와 대응해야 합니다.

      빈 후보는 유효한 빈 결과일 수 있지만 클래스 수, 비유한 값 또는 길이가 잘못된 텐서는 오류입니다. NMS와 점수 문턱을 거친 AiDetections는 독립 스냅샷이며, 후보가 없다는 사실과 모델 실행 자체의 실패는 별도로 처리하십시오.
