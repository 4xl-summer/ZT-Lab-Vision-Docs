공개 선언

Rust
pub trait IntoValue: Sized { type Target; // Required method fn into_value(self) -> Self::Target; }

Explicit bridge for into_value.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

연결과 소유권

Facade가 감싼 값을 소유권과 함께 꺼내는 트레이트입니다. Value가 제공하는 불변 참조와 달리 into_value는 self를 소비하고 Target 값을 반환합니다. 매칭 보고서 구현에서 엔진 보고서를 소유한 값으로 전달해야 할 때 사용할 수 있습니다.

예를 들어 결과를 검사한 뒤 엔진 보고서를 다른 소유 함수에 넘기려면 먼저 필요한 facade 수준 정보를 읽고 마지막에 변환합니다. 변환 뒤에는 기존 보고서 변수를 다시 쓸 수 없으며 반환값이 새 소유자가 됩니다. 단순히 항목 수나 점수를 읽으려는 경우에는 소유권을 이전하지 않는 결과 접근자가 더 적합할 수 있습니다.

이 변환은 매칭을 다시 수행하거나 결과 목록을 복제한다는 뜻이 아닙니다. 실제 Target과 값의 구조는 보고서 타입에 따라 결정됩니다. 호출부에 bridge::IntoValue를 가져와야 하며, facade 소유자를 계속 보관할 필요가 있으면 구체 타입의 공유 또는 복제 지원 여부를 변환 전에 확인하십시오.
