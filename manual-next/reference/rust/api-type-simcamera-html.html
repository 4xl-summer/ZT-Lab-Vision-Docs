Rust API · SimCamera in zvision / api-type-simcamera

SimCamera in zvision의 rustdoc 공개 선언

공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 SimCamera in zvision입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub type SimCamera = SimulatedCamera;

Legacy camera name retained through the 0.1.x series.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

공개 멤버

    트레이트 구현 멤버

      사용과 결과 해석

      SimCamera는 SimulatedCamera의 이전 이름으로 남아 있는 Rust 타입 별칭입니다. 새로운 코드에서는 정식 이름 SimulatedCamera를 사용하면 취득 예제와 이름을 일치시킬 수 있습니다. 이름이 다르다고 두 개의 별도 카메라 객체나 다른 장치 백엔드가 만들어지는 것은 아닙니다.

      시뮬레이터를 사용하려면 CameraSpec으로 소스와 시계, 큐 용량 및 트리거 모드를 지정하고 연결한 뒤 취득을 시작합니다. 소프트웨어 트리거 모드에서는 트리거를 발행하고 offer_frame으로 프레임을 제공한 다음 try_get_frame으로 큐에서 꺼냅니다. 더 이상 프레임이 없을 때의 빈 결과와 오류를 구별해야 합니다.

      제공한 이미지는 시뮬레이터의 프레임으로 복사되며 획득한 프레임에서 별도 공유를 얻을 수 있습니다. 이 동작은 실제 카메라의 전송 지연, 드라이버 또는 전기 트리거 특성을 검증하지 않습니다. 별칭은 deprecated로 표시되어 있으므로 기존 호출을 읽을 때는 호환 이름으로 이해하고 신규 호출에는 정식 이름을 선택하십시오.
