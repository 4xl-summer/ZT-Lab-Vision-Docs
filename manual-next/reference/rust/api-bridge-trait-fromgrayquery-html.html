연결과 소유권

기존 Gray 히스토그램 Query 계획을 facade의 히스토그램 계획으로 옮기는 연결점입니다. 연관 타입 Target은 변환을 구현한 객체가 받는 계획 타입을 정합니다. 이 트레이트는 계획을 실행하는 대신 소유한 계획을 facade 형식으로 감싸므로 변환만으로 히스토그램 수치가 계산되지는 않습니다.

HistogramQuery 구현에서는 기존 Gray 히스토그램 계획을 해당 facade 변형에 보관합니다. 계획을 실행한 다음에야 결과 채널과 빈 값을 확인할 수 있습니다. 미리 정해진 Gray 히스토그램 경로와 별도의 다중 채널 히스토그램 설정을 혼동하지 말고, 원래 계획이 요구하는 입력 형식과 빈 구성을 함께 확인하십시오.

from_gray_query는 계획 값을 소비하므로 원래 변수를 변환 후 다시 사용하려 하면 Rust가 이를 막습니다. 같은 계획을 여러 갈래에 사용해야 한다면 이동 전에 해당 계획의 복제 가능 여부와 비용을 확인합니다. 메서드가 탐색되지 않는 경우 bridge::FromGrayQuery 트레이트와 구체적인 대상 타입이 스코프에 있는지 확인하십시오.
