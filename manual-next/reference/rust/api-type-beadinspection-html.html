    트레이트 구현 멤버

      사용과 결과 해석

      BeadInspection은 BeadResult의 이전 Rust 이름으로 유지되는 타입 별칭입니다. 새 코드에서는 BeadResult를 사용하면 결과의 정식 이름과 탐침·실패 구간 접근자를 일관되게 읽을 수 있습니다. 별칭을 쓴다고 다른 검사 알고리즘이 실행되는 것은 아닙니다.

      결과에는 경로별 탐침과 실패 구간, 최장 갭 및 전체 passed 같은 판단 근거가 있습니다. 한 탐침의 실패와 전체 검사 실패는 설정된 연속 구간 및 갭 규칙에 따라 다를 수 있으므로 상태 하나만으로 원인을 확정하지 말고 탐침과 구간을 함께 확인하십시오.

      좌표와 길이는 검사 입력의 ROI 로컬 픽셀 기준에서 해석합니다. 물리 허용차에 적용할 때는 원점과 보정을 별도로 확인하고, 기존 이름 사용 여부보다 실제 측정 설정과 결과 소유 계약을 유지하는 것이 중요합니다.

      예를 들어 전체 통과 여부를 조회한 뒤 특정 연속 구간의 처음과 마지막 탐침을 확인하면, 점 하나의 실패와 경로를 따라 이어진 결손을 구분해 분석할 수 있습니다.
