      사용과 결과 해석

      VariationDirectional은 VariationDirectionalResult의 호환 Rust 이름입니다. 신규 코드에서는 정식 결과 이름을 선택하면 방향별 임계 영상과 검사 마스크를 다루는 API를 더 분명하게 읽을 수 있습니다. 별칭이 별도의 학습이나 검사를 실행하는 것은 아닙니다.

      방향별 허용차를 적용한 결과에서는 기준보다 밝은 변화와 어두운 변화가 서로 다른 조건으로 처리될 수 있습니다. 결과 영상과 결함 마스크를 읽을 때는 입력과 기준의 정렬, 검사 영역 및 해당 방향의 임계 설정을 함께 확인해야 합니다.

      반환된 영상 접근자의 소유 및 공유 계약은 정식 결과 타입을 따릅니다. 결함이 없다는 화면 표시만으로 실제 장비에 대한 성능이 검증되는 것은 아니므로 합성 입력과 실제 생산 조건을 구분하고 기준 모델을 별도로 평가하십시오.
