쿼리 표현의 명시적 변환

FromImageQuery는 이미지 쿼리의 엔진 표현을 공개 파사드 소유자로 옮기는 명시적 브리지 트레이트입니다. 연관 타입 Target이 대응하는 엔진 표현을 나타내고 from_image_query는 그 값을 받아 Self를 반환합니다. 트레이트에는 Sized 제약이 있습니다.

소유권의 방향

메서드의 인자 value는 참조가 아니라 Self::Target 값입니다. 따라서 호출은 전달된 표현의 소유권을 소비하여 반환된 파사드 소유자로 옮기는 방향으로 읽습니다. 변환 후 원래 value를 계속 사용한다고 가정하지 말고 소유권이 필요한 곳을 호출 전에 정합니다.

형식 선택

실제 Target과 Self는 이 트레이트의 구체적인 구현에 의해 결정됩니다. 트레이트 이름만으로 임의의 이미지 형식이나 서로 다른 쿼리 표현 사이의 자동 변환이 가능하다고 판단하면 안 됩니다. 구현된 타입과 해당 공개 경로를 확인해야 합니다.

사용 맥락

일반적인 이미지 쿼리는 공개 ImageQuery 빌더와 execute를 통해 계획하고 실행할 수 있습니다. 이 브리지는 그 내부 표현과 파사드 사이의 명시적 연결을 위한 계약이며, 호출 한 번으로 이미지를 실행하거나 분석 결과를 얻는 메서드는 아닙니다.
