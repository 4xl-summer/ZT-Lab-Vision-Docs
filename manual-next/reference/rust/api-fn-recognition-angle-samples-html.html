pub fn recognition_angle_samples( min: f64, max: f64, step: f64, ) -> Result<Vec<f64>, RecognitionError>

Creates an inclusive finite angle grid in degrees. It includes the lower endpoint and all min + k*step <= max; at most 360 trials are permitted.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

      사용과 결과 해석

      최솟값과 최댓값 사이에서 지정한 양의 간격으로 인식 회전 시도각을 생성합니다. 세 인자의 단위는 도이며 하한을 포함하고 min+k×step이 max 이하인 값들을 순서대로 만듭니다. 최대 360회의 시도로 제한됩니다.

      예를 들어 최소 -10도, 최대 10도, 간격 5도이면 -10, -5, 0, 5, 10의 다섯 시도각입니다. 간격이 범위를 정확히 나누지 않으면 마지막 값이 최대값과 같아야 하는 것은 아닙니다. 이 값들은 라디안 기반 기하 API에 그대로 전달할 수 없습니다.

      인자는 유한해야 하고 범위 순서와 양의 step, 허용 시도 수를 만족해야 합니다. 이 함수는 각도를 나열할 뿐 영상을 회전하거나 문자를 인식하지 않습니다. 넓은 탐색은 더 많은 작업을 뜻하므로 검출 범위와 계산량을 함께 결정하십시오.
