연결과 소유권

기존 엔진 표현의 소유권을 facade 소유자로 옮기는 트레이트입니다. Target은 각 구현이 받는 엔진 타입을 가리키며 공통으로 고정된 하나의 카메라나 인식 타입이 아닙니다. 공개 API를 이용하는 코드와 이미 엔진 값을 만든 코드 사이에서 소유자를 바꿔야 할 때 이 변환을 선택합니다.

예로 취득 기능의 SimulatedCamera 구현은 기존 카메라 엔진 값을 받아 facade 소유자로 감쌉니다. 인식 엔진 등 다른 구현의 Target과 사용 가능한 기능은 해당 타입에 따라 다릅니다. 변환이 연결을 수행하거나 장비를 시작한다는 뜻은 아니므로 카메라 상태 전이는 별도 connect와 start 호출로 관리해야 합니다.

from_engine은 값을 소비합니다. 원래 엔진 변수를 변환 후에도 쓰려는 코드라면 이동으로 인한 컴파일 오류가 발생합니다. 메서드 호출 전 bridge의 FromEngine을 가져오고 구체 타입의 구현과 feature 조건을 확인하십시오. 이 트레이트 선언만으로 모든 엔진 객체가 같은 변환을 지원하거나 깊은 복사가 일어난다고 추론해서는 안 됩니다.
