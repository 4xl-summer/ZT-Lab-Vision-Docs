공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 RecognitionEngineResult in zvision입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub type RecognitionEngineResult<T> = Result<T, RecognitionError>;

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

    사용과 결과 해석

    인식 엔진 호출에서 성공값 T 또는 RecognitionError를 표현하는 Result 타입 별칭입니다. 바코드, 글꼴 OCR 또는 AI 관련 호출이 실패할 수 있음을 서명에서 나타내며, 성공값의 실제 형식은 각 함수의 T에 따라 다릅니다.

    예를 들어 결과가 없는 정상 판독과 엔진이 실패해 오류를 반환한 경우는 같은 상태가 아닙니다. 성공한 값 안에 선택적 결과 또는 미검출 상태가 있을 수 있으므로 먼저 Result를 처리하고 그 다음 결과 타입의 상태를 확인해야 합니다. 물음표 연산자나 match를 사용해 오류를 호출자에게 전달하거나 구분할 수 있습니다.

    공통 인식 오류형이라는 사실만으로 모든 영상 처리 API가 같은 오류 타입을 쓰는 것은 아닙니다. 파일 읽기의 ImageIoResult와 일반 영상 연산의 ZResult 등은 각각의 서명을 확인하고, 실패를 빈 문자열이나 빈 검출 배열로 임의 변환하지 마십시오.
