연결과 소유권

Facade 소유 객체를 대응 엔진 표현으로 넘길 때 사용합니다. 연관 타입 Target이 반환 엔진 타입을 정하며 into_engine은 facade의 self를 이동시킵니다. 따라서 호출 뒤 기존 facade 인스턴스를 사용하지 않고 반환된 엔진 값을 사용해야 합니다. 이 경계는 서로 다른 객체 계층 간 표현을 넘기는 것이지 결과를 실행하거나 재계산하는 명령이 아닙니다.

예를 들어 AcquiredFrame 구현은 프레임 정보와 이미지의 소유권을 기존 취득 엔진 프레임으로 옮깁니다. 인식 결과 등 다른 구현의 구체 데이터와 공개 메서드는 별도로 확인해야 합니다. 이미지나 프레임을 두 경로에서 동시에 사용하고 싶다면 변환 전에 각 객체가 제공하는 공유 API로 독립적인 소유권을 확보해야 합니다.

호출 메서드가 보이지 않으면 bridge::IntoEngine 트레이트를 가져왔는지 점검하십시오. 타입이나 feature가 달라 해당 구현이 없을 때는 트레이트 이름만 가져와도 변환이 생기지 않습니다. 구체 타입의 소유권 이동을 기준으로 처리하고 장치 상태나 결과의 의미가 바뀐다고 가정하지 마십시오.
