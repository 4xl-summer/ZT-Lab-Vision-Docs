Rust API · ImageIoResult in zvision / api-type-imageioresult

ImageIoResult in zvision의 rustdoc 공개 선언

공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 ImageIoResult in zvision입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub type ImageIoResult<T> = Result<T, ImageIoError>;

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

  • variant.Err

    입출력 결과 별칭

    ImageIoResult<T>는 Result<T, ImageIoError>의 타입 별칭입니다. 성공하면 Ok에 T가 들어 있고 실패하면 Err에 ImageIoError가 들어 있습니다. 새로운 독립적인 결과 컨테이너가 아니라 Rust Result의 성공과 오류 분기 규칙을 그대로 사용합니다.

    읽기와 쓰기

    예를 들어 이미지 읽기에서 T가 ZImage이면 성공 값은 이미지입니다. 저장 함수의 T가 ()이면 성공 결과는 별도 이미지가 아닌 단위 값입니다. 둘 다 오류는 ImageIoError이므로 호출한 작업에 맞게 성공 값을 사용하고 실패를 처리합니다.

    호출 순서

    파일 경로와 해당 로딩 또는 저장 옵션을 준비하고 호출의 Result를 확인합니다. 정상 분기에서만 반환된 이미지를 후속 처리에 사용하며, 오류 분기에서는 작업과 경로를 함께 기록해 원인을 조사할 수 있습니다. 존재하지 않는 파일이나 지원되지 않는 입력의 처리는 해당 I/O API와 오류 값을 확인합니다.

    별칭의 범위

    이 별칭은 결과의 형태를 설명하며 모든 이미지 형식 지원이나 파일 읽기 성공을 보증하지 않습니다. 여러 페이지 TIFF의 페이지 인덱스나 저장 형식 선택 등 구체 조건은 각각의 load 및 save 호출 계약을 따라야 합니다.
