      사용과 결과 해석

      이미 얻은 문자열에 문자 집합과 길이 규칙을 적용합니다. 디코더가 어떤 글자를 후보로 선택할지는 바꾸지 않으므로, 인식 자체를 제한하는 설정과 구별해야 합니다. text와 allowed_chars는 문자열이며 허용 문자 집합은 비어 있을 수 없습니다. min_length는 max_length 이하여야 합니다.

      길이는 UTF-8 바이트 수가 아니라 Unicode scalar의 개수로 계산합니다. 예를 들어 한글 한 글자는 UTF-8에서 여러 바이트를 차지하지만 길이 판정에서는 한 scalar로 셉니다. 문자열의 각 문자가 허용 집합에 있는지도 검사합니다. 빈 문자열, 길이 범위 밖, 허용되지 않은 글자는 각각 결과의 사유 비트에 반영됩니다.

      반환된 값에는 scalar 수와 사유 비트, 전체 수락 여부가 들어 있습니다. 수락은 사유가 하나도 없을 때만 참입니다. 길이 범위가 잘못되거나 허용 집합이 비어 있으면 판정 실패 값이 아니라 오류를 반환하므로, 설정 오류와 유효한 설정에서의 불합격을 구별해 처리하십시오. 이 확인은 글꼴 유사도나 바코드의 품질 등급을 계산하지 않습니다.
