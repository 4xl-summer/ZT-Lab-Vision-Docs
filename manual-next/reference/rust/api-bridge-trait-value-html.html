연결과 소유권

Facade 객체 내부의 대응 값을 불변 참조로 관찰하는 트레이트입니다. Target은 구현마다 다르고 value는 소유권을 넘기지 않습니다. AlignmentResult와 DifferenceResult 등은 이 방식으로 엔진 수준의 상태나 측정값을 읽도록 제공하며, 참조는 원래 facade 객체보다 오래 유지할 수 없습니다.

정렬 결과에서는 일치하지 않은 상태가 실제 결과의 한 경우이므로 값을 읽을 때 성공 상태만 있다고 가정하지 마십시오. 차분 결과에서는 검사 픽셀 수처럼 계산된 정보를 확인할 수 있습니다. 독립된 이미지를 오래 보관해야 한다면 참조만 유지하는 대신 해당 결과가 제공하는 이미지 획득 메서드의 소유 계약을 따릅니다.

단순 조회에는 Value를, 기반 값을 소유한 채 다른 함수에 넘겨야 하는 경우에는 구체 타입이 제공하는 IntoValue를 검토합니다. 후자는 객체를 소비하지만 Value는 빌립니다. 메서드가 보이지 않으면 bridge::Value를 스코프에 가져왔는지 확인하고, 빌린 참조가 살아 있는 동안 원래 객체의 수명도 유지하십시오.
