      사용과 결과 해석

      분류 점수 배열을 확률로 해석하기 위한 함수입니다. meaning이 logits이면 수치적으로 안정적인 softmax를 적용하고, probabilities이면 입력이 확률 조건을 충족하는지 검사한 뒤 값을 복사합니다. 입력은 비어 있지 않고 모든 값이 유한해야 합니다.

      확률 모드에서는 각 값이 0~1이고 전체 합이 1에서 1e-4 이내여야 합니다. 예를 들어 [0.25, 0.75]는 유효하지만 [0.25, 0.50]은 합이 1이 아니어서 오류입니다. logits 모드에서 같은 수를 주면 이미 확률이라고 가정하지 않고 softmax를 계산합니다.

      반환 벡터는 독립 값이며 모델 추론 자체를 수행하지 않습니다. 분류 결과가 통계적으로 보정된 신뢰도인지 여부도 이 함수만으로 보장되지 않습니다. 텐서의 클래스 순서와 모델의 출력 의미를 확인한 뒤 호출하십시오.
