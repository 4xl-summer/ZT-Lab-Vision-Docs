ZResult in zvision의 rustdoc 공개 선언

공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 ZResult in zvision입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub type ZResult<T> = Result<T, ZError>;

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

    사용과 결과 해석

    ZResult는 성공값 T 또는 ZError를 담는 Rust Result의 타입 별칭입니다. 영상 생성, 처리, 좌표 변환 등에서 반환된 값이 성공인지 확인한 뒤에만 T를 사용하도록 표현합니다. 별칭 자체가 오류를 숨기거나 실패를 기본값으로 바꾸지는 않습니다.

    호출하는 함수가 ZResult를 반환한다면 물음표 연산자로 같은 오류 계열의 호출자에게 실패를 전달하거나 match로 성공과 실패를 나눌 수 있습니다. 예를 들어 ROI 범위를 잘못 지정했을 때는 유효한 이미지가 아니라 오류 경로를 처리해야 합니다. 구체 오류의 종류와 조건은 해당 함수 계약에서 확인해야 합니다.

    성공한 결과가 이미지라면 그 객체의 공유와 ROI 수명 규칙이 그대로 적용됩니다. 숫자나 모델을 반환하는 함수는 각각의 결과 계약을 따르므로 ZResult라는 공통 이름만으로 픽셀 복사나 결과의 수명을 추론할 수 없습니다. 인식 등 별도 오류 타입을 사용하는 API의 반환형과도 서명을 확인해 구분하십시오.
