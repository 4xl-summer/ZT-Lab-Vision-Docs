Rust
pub struct ImageQuery(/* private fields */);

A reusable, lazy image plan backed by the query engine. Appending an operation consumes the plan and returns a new plan. Clone a plan explicitly before branching or before an append that may fail; the original clone remains usable. execute borrows the plan and can be called repeatedly. Captures and acquired output images own independent shares. Managed SDKs retain their existing mutable builder and alias behavior.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.
