Rust
pub trait IntoCore: Sized { type Target; // Required method fn into_core(self) -> Self::Target; }

Explicit bridge for into_core.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

연결과 소유권

Facade가 소유한 Core 표현을 Core 기반 처리 경로에 넘길 때 사용하는 명시적 이동 경계입니다. 반환되는 값의 구체 타입은 해당 구현의 Target으로 정해집니다. ZImage의 경우 저장소를 새로 복사해 생성하는 것이 아니라 소유한 Core 이미지를 꺼내므로, 이후 Core API를 이용해 원래 픽셀 형식과 보이는 영역을 다룰 수 있습니다.

메서드는 self를 값으로 받습니다. 호출에 사용한 facade 객체는 이동되므로 그 이름으로 다시 접근할 수 없고, 변환을 마친 다음에는 반환된 Core 값을 사용해야 합니다. 영상 소유자를 둘 다 유지할 필요가 있다면 미리 share를 만들어 각 소유자의 수명을 관리하는 흐름을 검토하십시오. 공유와 깊은 복사는 서로 다른 동작입니다.

Rust에서 메서드가 보이지 않는다면 zvision의 bridge::IntoCore 트레이트가 스코프에 있는지 확인합니다. 이 변환은 픽셀을 재배열하거나 형식을 변환하는 함수가 아닙니다. ROI에 적용해도 구현이 전달한 이미지의 보이는 영역을 대상으로 하며, 호출자는 이후 처리에서 해당 Core 이미지의 좌표와 형식을 직접 확인해야 합니다.
