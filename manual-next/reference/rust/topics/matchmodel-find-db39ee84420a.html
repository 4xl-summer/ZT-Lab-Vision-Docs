검색 결과를 독립적인 읽기 전용 스냅샷으로 반환합니다.

관련 입력의 확인된 조건

학습된 템플릿 상태를 소유하는 매칭 모델입니다.

호출 맥락과 결과 해석

학습하거나 복원한 기본 모델을 영상의 보이는 ROI에서 검색합니다. MatchSpec의 각도·배율 축, 최소 점수, 중심 거리와 결과 수가 함께 후보를 제한합니다. 모델 기준점은 템플릿 로컬 중심이므로 반환 위치를 해석할 때 검색 ROI 원점도 확인합니다.

예를 들어 3×2 템플릿의 기준점은 (1, 0.5)입니다. 검색 결과의 위치는 템플릿 왼쪽 위가 아니라 이 기준점이 놓인 위치입니다. 결과가 비면 검색 범위와 분산, 점수 조건과 ROI를 확인하며, 결과 값은 모델과 영상이 스코프가 끝난 뒤에도 독립적으로 유지됩니다.

모델을 영상에서 검색

학습하거나 복원한 MatchModel을 image의 보이는 ROI에서 MatchSpec에 따라 검색합니다. 각도·배율 축, 최소 점수, 중심 거리와 결과 수는 모두 후보 선택에 영향을 줍니다. 반환 MatchResult는 독립적인 읽기 전용 스냅샷입니다.

반환독립 MatchResult 또는 오류

모델 기준점은 템플릿 로컬 중심이므로 반환 위치를 검색 ROI의 좌표 기준과 함께 읽습니다. 점수만 확인하지 말고 영상 위에 후보의 위치와 방향을 표시하세요. 오류와 후보가 0개인 정상 검색은 서로 다른 결과입니다.
