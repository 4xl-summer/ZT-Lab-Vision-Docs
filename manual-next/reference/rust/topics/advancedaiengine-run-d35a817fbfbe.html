사용과 결과 해석

모델 선언 순서의 입력 텐서 벡터를 실행하고 출력 텐서 벡터를 모델 노드 순서대로 반환합니다. 고정 차원과 알려진 자료형은 메타데이터와 일치해야 합니다.

기호 차원은 0이 아닌 크기를 받을 수 있습니다. 모델의 출력 노드 의미와 차원을 기준으로 결과를 해석하고, 불일치나 추론 실패는 오류로 처리하십시오.

텐서 입력과 출력 순서

run은 AiTensor 벡터의 소유권을 받아 모델의 선언된 입력 노드 순서대로 추론하고, 선언된 출력 노드 순서의 텐서 벡터를 반환합니다. 고정된 차원과 알려진 데이터 형식은 모델 메타데이터와 일치해야 하며 기호 차원은 0이 아닌 크기를 받을 수 있습니다.

예를 들어 모델이 입력 노드 A 다음 B를 선언했다면 입력 벡터도 같은 순서로 구성해야 합니다. 결과의 첫 텐서가 무엇을 뜻하는지는 모델의 출력 노드 계약으로 해석합니다. 텐서 모양·형식 불일치와 추론 실패는 RecognitionError이므로 빈 정상 결과와 구분해 처리하십시오.
