pub fn train( image: &ZImage, mask_image: Option<&ZImage>, metric: TemplateMetric, ) -> ZResult<Self>

Trains from a template and optional mask.

관련 입력의 확인된 조건

Bounded template matching model.

호출 맥락과 결과 해석

정수 평행이동 검색에 사용할 선택 템플릿 픽셀을 복사해 모델을 만듭니다. metric이 TemplateMetric::ColorNcc일 때 RGB8, TemplateMetric::GraySad일 때 Gray8 템플릿을 사용합니다. 옵션 마스크는 같은 크기와 원점의 Gray8입니다.

선택된 metric과 입력 형식은 나중의 검색 영상에도 맞아야 합니다. 모델 생성 이후 find에서 검색 범위와 허용 판정값을 별도로 정하고, 소유 모델은 스코프가 끝나면 정리됩니다. 템플릿 픽셀을 복사한 모델이므로 검색 옵션 자체를 학습하는 호출은 아닙니다.

템플릿과 마스크

train은 템플릿과 선택 마스크에서 검색 모델을 만듭니다. ColorNcc에는 RGB8, GraySad에는 Gray8 템플릿이 필요하며 마스크를 쓰면 같은 크기와 원점의 Gray8이어야 합니다. 모델은 선택된 템플릿 픽셀을 복사합니다.

항목판독할 내용
imagemetric에 맞는 템플릿 영상
mask_image선택적 Gray8 마스크
metricColorNcc 또는 GraySad의 비교 방식
반환성공 시 소유 BoundedTemplateModel

학습 성공은 검색 영상에 원하는 물체가 존재한다는 뜻이 아닙니다. 이후 find에 맞는 형식의 검색 영상과 탐색 범위를 전달하고 점수와 위치를 검토합니다. 학습 단계의 형식이나 마스크 조건이 틀리면 오류를 처리해야 합니다.
