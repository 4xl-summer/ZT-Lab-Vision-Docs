pub const fn layout(&self) -> ImageLayout

바이트 단위 스트라이드와 오프셋을 포함한 레이아웃을 반환합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언은 ImageLayout입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

이 값은 현재 영상이 보이는 영역의 크기 또는 배치를 해석할 때 사용합니다. ROI를 만든 영상에서는 원본 전체 크기와 현재 영역의 크기·원점을 혼동하지 말고 각 값을 함께 기록하세요.

영상 크기와 바이트 배치

layout은 현재 영상의 ImageLayout 값을 반환합니다. 이 값에는 폭과 높이, 행 시작 간격 row_stride_bytes, 저장소 시작으로부터의 offset_bytes가 있습니다. 폭과 높이는 픽셀 단위이고 stride와 offset은 바이트 단위입니다.

항목의미와 확인
width / height현재 영역의 픽셀 크기
row_stride_bytes행 시작 사이의 바이트 간격
offset_bytes저장소 시작에서 영역까지의 바이트
예시 유효 행Gray16 폭 3 → 6바이트
예시 stride8바이트, 2바이트 여유

사용할 때의 판독

예를 들어 Gray16 ROI의 폭이 3이고 stride가 8바이트면 한 행의 유효 픽셀 데이터는 3×2=6바이트지만 다음 행은 8바이트 뒤에서 시작합니다. ROI가 원본 중간에서 시작하면 offset도 0이 아닐 수 있습니다. 각 행을 연속된 6바이트만큼 단순 이동하면 둘째 행의 시작을 잘못 읽을 수 있습니다.
