pub fn point(&self, x: usize, y: usize) -> ZResult<Option<Point2>>

Returns a source coordinate or none outside the lattice.

계산 순서와 결과 확인

출력 맵의 정수 좌표 (x,y)에 대응하는 소스 전역 픽셀 좌표를 Option<Point2>로 반환합니다. 측정 격자 바깥 위치는 None이며 유효 격자 내부는 쌍선형 보간한 좌표입니다. 맵 범위를 벗어난 잘못된 조회와 격자 밖 None을 Result와 Option으로 구분합니다.

입력과 계산 확인

항목의미와 조건
입력출력 맵의 정수 x, y
Some(point)대응하는 소스 전역 픽셀
None측정 격자 바깥

맵 범위와 격자 범위

목적지 맵의 정수 픽셀에서 캐시된 소스 전역 좌표를 조회합니다. 맵 너비·높이를 벗어나면 Result 오류이고, 맵 안이지만 측정 격자 바깥이면 정상 결과 None입니다. 격자 내부는 주변 노드 좌표의 쌍선형 보간 결과입니다.

맵이 10×8이면 (9,7)은 맵 안이지만 (10,7)은 범위 밖입니다. (9,7)이 맵 안이어도 측정 격자 밖이면 None입니다. Some의 점은 소스 전역 좌표이므로 ROI 로컬 좌표를 사용하는 후속 연산에서는 소스 원점을 고려하십시오.
