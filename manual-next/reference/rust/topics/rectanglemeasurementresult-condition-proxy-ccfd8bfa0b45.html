pub fn condition_proxy(&self) -> Option<f64>

Returns the fit condition proxy, when available.

결과 확인 순서

사각형 측정의 결과 객체에서 호출합니다. 가능한 경우 적합의 조건 지표를 반환합니다. 지표가 없다는 상태와 숫자 0은 다르므로 반환 타입의 선택적 값을 먼저 확인하십시오. 이 값만으로 실제 장비의 정확도나 결과 형상의 합격 여부를 단정하지 말고 입력점의 분포, 적합 상태와 관측 진단을 함께 확인합니다.

확인 항목사용 기준
대상사각형 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용지표의 존재 여부와 관측 분포를 함께 확인합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

condition_proxy는 가중 Jacobian 열 노름의 최대/최소 비율이며 제공되지 않을 수 있습니다. 이 비율은 일반적인 행렬 조건수의 정확한 값과 같은 의미가 아닙니다.

None을 0으로 바꾸면 계산되지 않은 값과 실제 숫자를 혼동합니다. 사각형의 각 변에서 선택된 점의 분포와 수렴 여부, 상태를 함께 확인하고 단일 지표로 실제 장비 정확도를 보증하지 마십시오.
