pub fn run_with_fixed_sources( images: &[ZImage], edges: &[RegistrationGraphEdge], common: usize, fixed: &[bool], ) -> ZResult<Self>

Runs with initial transforms fixed for selected source images.

사용과 결과 해석

영상과 방향 그래프를 공통 격자에 정렬하되 fixed 배열로 지정된 소스의 초기 변환을 고정합니다. 고정된 간선에는 추정 결과가 없을 수 있으며 최적화 여부도 별도로 기록됩니다.

영상 인덱스와 fixed 배열의 대응을 유지하고, 결과의 edge_results와 edge_optimized를 함께 확인하십시오. 고정 항목에 추정값이 없는 것을 정합 실패와 동일하게 취급하지 않아야 합니다.

고정 소스와 간선 결과

images와 edges로 정합 그래프를 구성하고 common으로 공통 기준 영상을 선택합니다. fixed 배열은 영상 순서에 대응하며 true인 소스 영상으로 향하는 연결의 초기 변환을 고정합니다. 고정된 연결은 추정하지 않는 초기값을 사용하므로 측정 결과가 없는 경우가 있습니다.

예를 들어 fixed[1]이 true이면 영상 1을 소스로 지정한 연결의 초기 변환이 고정 대상입니다. 결과의 edge_optimized와 edge_results를 같은 간선 인덱스로 확인하십시오. 결과가 None인 고정 간선을 실패 점수 0으로 해석하지 말고, 영상별 공통→로컬 행렬과 유효 마스크도 함께 확인합니다.
