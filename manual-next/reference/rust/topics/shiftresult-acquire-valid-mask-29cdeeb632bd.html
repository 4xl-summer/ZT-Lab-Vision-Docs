pub fn acquire_valid_mask(&self) -> ZImage

Acquires the Gray8 validity mask.

결과 해석과 수명

시프트 결과의 Gray8 유효성 마스크를 소유 영상으로 얻습니다. 이동 결과의 각 위치가 유효한 입력에 대응하는지 확인할 때 출력 영상과 같은 좌표로 읽습니다. 마스크는 영상 픽셀 값 자체가 아니며 얻은 영상의 소유 수명은 결과 조회와 구분합니다.

이동 영상의 유효 영역

acquire_valid_mask는 ShiftResult의 Gray8 유효 마스크를 독립 공유 ZImage로 반환합니다. 이동 결과의 각 위치가 원본에서 유효한 표본을 얻었는지 확인하는 데 사용합니다. 결과의 acquire_image와는 서로 다른 영상입니다.

예를 들어 영상을 오른쪽으로 한 픽셀 이동하면 새로 드러나는 왼쪽 경계에는 원본에서 대응 표본이 없을 수 있습니다. 경계의 표시값이 검다고 해서 원본의 실제 검은 픽셀이라고 판단하지 말고 같은 위치의 유효 마스크를 확인합니다.

차분이나 통계를 계산할 때는 사용하려는 마스크의 포함 규칙과 입력 영상의 크기·원점을 확인합니다. 무효 경계를 정상 픽셀로 섞으면 비교 범위와 평균이 바뀔 수 있습니다. 마스크는 위치별 유효성을 나타내며 전체 제품 판정은 아닙니다.

반환된 ZImage는 ShiftResult 내부 영상을 독립 공유합니다. Rust 소유 관계에 따라 결과와 획득한 영상의 수명을 각각 관리할 수 있습니다. 여러 프레임의 마스크를 섞지 않도록 이동한 영상과 같은 요청 식별자에 연결합니다.
