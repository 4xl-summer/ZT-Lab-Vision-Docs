사용과 결과 해석

현재 프레임, 특징, 공차를 복사하고 검증하여 독립적인 불변 CompositeModel을 반환합니다. 빌더 자체를 소비하지 않으므로 이후 다른 구성을 추가해 별도 모델을 만들 수 있습니다.

예를 들어 점과 선을 만든 뒤 첫 모델을 생성하고 공차를 추가해 두 번째 모델을 만들 수 있습니다. 나중에 빌더가 바뀌어도 이미 생성한 모델의 그래프는 바뀌지 않습니다.

검증된 그래프 생성

build는 현재 프레임·특징·공차를 복사하고 검증해 독립 불변 CompositeModel을 반환합니다. &self를 받으므로 빌더를 소비하지 않습니다. 잘못된 참조나 구성은 반환 오류로 확인해야 합니다.
