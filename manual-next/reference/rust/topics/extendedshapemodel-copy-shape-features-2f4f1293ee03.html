pub fn copy_shape_features(&self) -> ZResult<Vec<(f64, f64, f64, f64)>>

Copies feature geometry from the trained shape.

관련 입력의 확인된 조건

Extended shape matching model.

호출 맥락과 결과 해석

학습 결과가 어떤 형상 표본을 보유하는지 확인할 때 사용합니다. 각 항목은 기준점 상대 로컬 위치 x, y와 방향 nx, ny를 담으며, 반환된 전체 Vec도 모델과 독립된 값입니다. 학습 템플릿의 원점이나 검색 영상의 전역 좌표로 바로 표시하지 않도록 주의합니다.

이 목록은 방향을 가진 표본 모음이지 원래 입력 contour의 연결 관계가 아닙니다. 예를 들어 이웃한 두 항목을 임의로 선분으로 연결해 원래 경계를 복원하는 용도로 쓰면 안 됩니다. 모형의 기준점을 바꾸어 학습했다면 로컬 좌표의 해석도 그 기준점을 따라 달라집니다.

상대 좌표와 법선

각 튜플은 (x,y,nx,ny) 순서입니다. x,y는 학습 기준점 상대 픽셀 위치이고 nx,ny는 기울기 방향의 정규화 성분입니다. 예를 들어 기준점이 (5,3)이고 반환 위치가 (2,1)이면 학습 템플릿 로컬 위치는 (7,4)입니다.

반환 Vec는 모델에서 복사한 소유 값입니다. 특징점들은 원본 contour의 선분 연결을 담고 있지 않으므로 배열 이웃을 원래 경계 연결이라고 가정하지 않습니다. 검색 영상에서 그리려면 찾은 포즈의 회전·배율·위치를 적용하고 ROI 원점을 확인합니다.
