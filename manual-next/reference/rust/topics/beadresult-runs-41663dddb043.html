Contiguous defect runs.

연속 결함 구간

연속된 결함 구간의 슬라이스를 빌려 반환합니다. 각 구간을 개별 탐침 결과나 전체 최장 간격과 혼동하지 말고 동일 검사 실행의 경로와 함께 읽습니다.

슬라이스는 BeadResult를 빌리므로 소유 결과의 수명 안에서 사용합니다.

연속 실패 구간

runs는 연속 결함 구간의 BeadDefectRun 슬라이스입니다. 각 구간에는 first, last와 flags가 있습니다. 개별 probe 하나의 결과, 구간의 인덱스 범위, 전체 longest_gap_length는 서로 다른 정보입니다.

항목판독할 내용
first / last결함 구간의 시작·끝 probe 인덱스
flags 1경계 쌍 누락
flags 2 / 4폭 조건 / 중심 오프셋
longest_gap_length전체 검사에서 별도로 제공되는 길이

flags는 결함 유형을 비트로 나타냅니다. 누락된 경계 쌍은 1, 폭 조건은 2, 중심 오프셋은 4이며 여러 유형이 함께 표시될 수 있습니다. 결과 객체를 빌린 슬라이스이므로 객체의 수명 안에서 읽고 필요한 장기 기록은 복사합니다.
