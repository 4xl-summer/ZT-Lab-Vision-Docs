Rust
pub fn point_count(&self, selector: u64, by_label: bool) -> ZResult<usize>

Returns the point count for an edge.

사용과 결과 해석

선택한 포함 체인의 점 수를 반환합니다. by_label이 false이면 포함 목록의 0부터 시작하는 인덱스이고 true이면 생성 시 부여된 label입니다. 제외되었거나 없는 선택자는 오류입니다.

점 목록을 별도 저장소로 복사하려는 경우 이 수로 필요한 크기를 확인한 뒤 points의 순서대로 복사할 수 있습니다. 포함 상태가 바뀌면 인덱스를 다시 선택하십시오.

점 수를 사용할 때

체인에 세 점이 들어 있으면 point_count는 3이고 points의 길이도 3입니다. 여러 체인의 점을 복사할 때 각 label과 점 수를 함께 기록하면 포함 목록이 바뀌어도 어느 체인의 데이터인지 식별할 수 있습니다.
