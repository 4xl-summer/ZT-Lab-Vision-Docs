pub fn train_contours( contours: &[Vec<Point2>], reference: Point2, spacing: f64, ) -> ZResult<Self>

Trains from ordered contours.

관련 입력의 확인된 조건

Extended shape matching model.

호출 맥락과 결과 해석

방향이 있는 선분 경로에서 표본을 만들어 형상 모델을 학습합니다. 경로는 1개에서 128개이고 각 경로에는 2점 이상이 필요하며 전체 점 수는 최대 65536입니다. 영상의 픽셀 기울기를 추출하는 train과 입력의 표현이 다릅니다.

reference는 템플릿 로컬 기준점이고 spacing은 유한한 양의 픽셀 간격입니다. 경로의 점 순서가 방향을 가진 경계를 정의하므로 입력을 구성할 때 의도한 순서를 유지합니다. 생성된 모델은 검색에 사용한 뒤 소유 값의 스코프가 끝나면 정리됩니다.

경로 방향과 표본 간격

contours는 순서가 있는 Point2 경로 목록입니다. 각 경로에는 최소 두 점이 있어야 하며 경로는 1..128개, 전체 입력 점은 최대 65536개입니다. spacing은 유한한 양의 픽셀 간격으로 선분을 따라 모델 특징을 표본화합니다.

reference는 경로 좌표와 같은 템플릿 로컬 기준점이며 생성된 특징 위치는 이 점에 상대적으로 저장됩니다. 예를 들어 경로 점 (7,4)와 기준점 (5,3)은 상대 위치 (2,1)로 해석합니다. 점 순서를 임의로 뒤집으면 방향 정보를 사용하는 형상 모델의 의미도 달라질 수 있습니다.
