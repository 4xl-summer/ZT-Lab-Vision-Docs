pub fn fit( pixels: &[Point2], world: &[Point2], unit: LengthUnit, ) -> ZResult<Self>

Fits an invertible mapping from corresponding points.

사용과 결과 판독

대응하는 픽셀점과 세계점을 사용해 역변환 가능한 평면 매핑을 적합합니다. 배열의 같은 인덱스가 같은 표적 위치여야 하므로 한쪽만 정렬하면 잘못된 대응을 풉니다. 픽셀은 글로벌 영상 좌표이고 world는 지정한 길이 단위입니다. 점의 수뿐 아니라 배치가 퇴화하지 않았는지 확인하고 학습에 쓰지 않은 점의 잔차를 별도로 평가하십시오.

단계확인할 내용
픽셀같은 영상 기준의 글로벌 픽셀 좌표입니다.
세계점같은 물리 위치를 같은 인덱스에 둡니다.
단위세계 좌표의 길이 단위를 지정합니다.
검증학습과 다른 보류점의 잔차를 평가합니다.

입력과 결과 확인

PlanarCalibration::fit은 pixels와 world의 대응점으로 역변환 가능한 평면 매핑을 적합합니다. 두 배열의 같은 인덱스는 같은 물리 위치여야 하며 pixels는 글로벌 픽셀, world는 지정한 길이 단위의 평면 좌표입니다.

합성 예에서 픽셀 x가 100에서 120으로 변할 때 세계 x가 11에서 13 mm로 변하면 해당 축의 비율은 2/20=0.1 mm/px입니다. y는 200에서 240픽셀일 때 38에서 46 mm이므로 8/40=0.2 mm/px입니다. 두 축의 단위와 대응 순서를 그대로 보존하십시오.

점 개수만 충분해도 모든 점이 퇴화한 배치라면 유효한 투영을 정할 수 없습니다. 학습에 사용하지 않은 보류점으로 예측과 기준을 비교하여 실제 검증 범위를 구분하고, ZResult 오류를 정상적인 항등 보정으로 바꾸지 마십시오.

항목확인할 내용
pixels같은 영상 프레임의 글로벌 픽셀점입니다.
world각 픽셀과 순서가 같은 세계 평면점입니다.
unit세계 좌표의 길이 단위입니다.
대응같은 인덱스가 동일한 물리 위치여야 합니다.
배치점의 수뿐 아니라 퇴화 여부를 확인합니다.
보류점학습 외 대응점의 잔차를 별도 평가합니다.
