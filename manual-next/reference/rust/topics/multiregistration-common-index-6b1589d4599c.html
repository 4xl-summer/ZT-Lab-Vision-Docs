Rust
pub fn common_index(&self) -> usize

Returns the chosen common image index.

사용과 결과 해석

정렬된 영상들의 공통 기준으로 선택한 입력 영상 인덱스를 반환합니다. 이 인덱스는 원본 영상 배열 순서에 해당합니다.

matrices의 좌표 방향은 이 기준 영상의 로컬 좌표에서 각 영상의 로컬 좌표입니다. 여러 정합 결과를 비교할 때는 기준 인덱스가 같은지 먼저 확인하십시오.

입력과 결과 확인

common_index는 다중 정합에서 공통 기준으로 선택한 입력 영상의 인덱스를 반환합니다. 반환 usize는 영상의 픽셀값이나 정합 점수가 아니라 원본 입력 배열의 어느 영상을 기준으로 삼았는지 나타냅니다.

예를 들어 입력 배열에 영상이 세 개 있고 common_index가 1이라면 두 번째 영상이 공통 기준입니다. 인덱스가 가리키는 실제 영상의 이름과 ROI를 함께 보관해야 이후 결과를 다시 읽을 때 같은 기준을 식별할 수 있습니다.

matrices는 입력 순서의 공통 로컬→각 영상 로컬 행렬입니다. 이 방향을 거꾸로 해석하거나 다른 정합 실행의 기준 인덱스와 섞으면 좌표 연결이 달라집니다. common_index 하나가 정합 정확도나 모든 픽셀의 유효성을 보증하는 것은 아니므로 유효 마스크와 정합 진단을 따로 확인하십시오.

항목확인할 내용
반환공통 기준으로 선택된 입력 영상의 인덱스입니다.
순서원본 영상 배열의 순서에 대응합니다.
예시인덱스 1은 두 번째 입력을 뜻합니다.
행렬공통 로컬에서 각 영상 로컬로 갑니다.
출력영상 ID와 ROI를 인덱스와 함께 보관합니다.
품질기준 인덱스와 정합 정확도를 구분합니다.

예를 들어 입력 순서가 영상 A, B, C이고 기준 인덱스가 1이라면 공통 프레임은 B의 로컬 좌표입니다. 이때 입력 순서에 있는 각 행렬은 공통 로컬 좌표를 해당 영상의 로컬 좌표로 연결합니다. 배열을 B, A, C 순서로 다시 정렬해 놓고 이전 인덱스를 그대로 읽으면 기준 영상이 바뀐 것처럼 보일 수 있습니다. 영상 식별자와 행렬, 기준 인덱스를 같은 실행의 묶음으로 보존하십시오.

예시에서 기준 영상 B의 로컬 원점이 공통 프레임의 기준이 됩니다. 다른 영상에 그 위치가 어떻게 대응하는지는 해당 영상의 행렬을 적용해 확인하고, 입력 배열 인덱스만으로 픽셀 위치를 추정하지 않습니다.

기준 인덱스가 유효한 한 항목을 가리킨다는 것과 선택된 모든 영상이 겹치는 영역을 갖는다는 것은 다른 사실입니다. 결과의 유효 마스크와 필요한 경우 각 영상의 정합 진단을 별도로 살펴보십시오.
