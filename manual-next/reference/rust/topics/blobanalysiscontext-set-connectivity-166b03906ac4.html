결과와 사용 순서

입력과 결과 해석

분석 설정과 현재 결과를 관리하는 컨텍스트입니다. 연결 방식이 달라지면 새 설정에 대해 다시 계산해야 합니다. 인덱스 모드는 현재 결과의 조회 방식만 바꾸며 재계산하지 않습니다. 계산 실패 시 현재 결과가 지워질 수 있습니다.

대각선 연결 사례

연결 방식은 전경 픽셀을 하나의 성분으로 묶는 기준입니다. 2×2 마스크가 첫 행 [255,0], 둘째 행 [0,255]이면 두 전경 픽셀은 대각선으로만 닿습니다. Four 연결에서는 두 성분이고 Eight 연결에서는 한 성분이며 면적은 2픽셀입니다.

대각선 마스크Four 2개, Eight 1개

결과를 사용할 때

현재 설정과 다른 연결 방식을 선택하면 기하 설정이 변경되어 dirty가 true가 됩니다. 그 뒤 calculate가 성공해야 새 설정에 대한 결과를 얻습니다. 동일한 설정을 다시 지정하는 것과 다른 설정으로 바꾸는 것을 구분하고, 계산 실패 시 현재 결과가 비워지는 점도 확인하세요.
