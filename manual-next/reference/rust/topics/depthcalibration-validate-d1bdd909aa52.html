선형 깊이 보정 계수

선형 모델은 원시 깊이 h에 대해 보정값 scale × h + offset을 계산합니다. scale은 유한한 양수이고 offset은 유한해야 하며 적용할 데이터의 단위와 모델 단위가 맞아야 합니다. 모델 생성이나 검증은 깊이 배열을 직접 바꾸지 않습니다.

scale이 2이고 offset이 1이면 입력 4의 보정값은 9입니다. 이 값은 절대 3차원 좌표 전체에 이동을 적용한 결과가 아니라 깊이 성분에 적용한 선형 보정입니다. 원시값과 기준값의 대응으로 계수를 추정한 뒤 별도의 데이터에서 잔차를 확인하는 순서가 유용합니다.
