Returns immutable trained descriptors.

반환값과 수명

방향과 다중 해상도 정보를 갖는 학습 특징을 불변 슬라이스로 빌립니다. 특징은 모델에 보관된 값이며 검색된 물체의 목록이 아닙니다. 배율과 방향을 포함한 모델 표현을 확인하고, 검색의 대응·기하 검증은 find의 별도 보고서에서 읽습니다.

결과와 조건을 함께 읽기

이 슬라이스는 검색 영상에서 찾은 물체 목록이 아니라 학습 모델에 저장된 특징들입니다. 각 특징의 위치, 배율과 방향을 확인하면 템플릿의 어느 부분이 모델 표현에 들어갔는지 살펴볼 수 있습니다. 예를 들어 대상 가장자리에만 마스크를 두었다면 반환 특징의 위치가 그 영역에 있는지 확인합니다. 이 접근자는 모델 내부 배열을 불변으로 빌리므로 모델이 살아 있는 동안 읽어야 합니다. 새로운 검색의 대응점과 변환, 내점 판정은 find가 반환하는 별도 보고서에서 해석합니다.
