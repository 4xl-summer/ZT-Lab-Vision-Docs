Rust
pub fn channel(&self, index: usize) -> Option<ZImage>

Returns a separately owned channel image, or None outside 0..3.

사용과 결과 해석

인덱스 0, 1, 2에 해당하는 성분 영상을 별도 소유 핸들로 반환합니다. 범위 밖의 인덱스에는 None을 반환합니다. 각 채널은 GrayF64이며 원본 변환 결과의 영상 기하를 유지합니다.

0은 L입니다. 1과 2는 Lab에서 a와 b, LCH에서 C와 도 단위 h입니다. 반복 처리 시 인덱스와 색 공간을 함께 보존해야 성분을 올바르게 해석할 수 있습니다.

세 평면의 선택

AdvancedPlanes.channel(index)는 0, 1, 2에 대응하는 GrayF64 성분 영상을 별도 소유 ZImage로 반환하고 범위 밖은 None입니다. Option을 확인하기 전에 무조건 성공한 영상이라고 가정하지 않습니다. 각 평면은 원래 변환 결과의 영상 기하를 유지합니다.

Lab에서 인덱스 0,1,2는 L,a,b이고 LCH에서는 L,C,h입니다. LCH의 h는 도 단위입니다. 예를 들어 인덱스 1은 Lab의 a 또는 LCH의 C를 나타내므로 같은 숫자라도 색 공간 정보를 함께 보관해야 해석할 수 있습니다.

항목확인할 내용
index 0L 평면
index 1Lab의 a 또는 LCH의 C
index 2Lab의 b 또는 LCH의 h
형식각 평면 GrayF64
범위 밖None
수명별도 소유 ZImage

색 변환의 입력 인코딩과 백색점, 선택한 색 공간을 기록한 뒤 채널을 얻습니다. 모든 평면의 값 범위가 RGB 바이트의 0–255와 같다고 가정하지 않습니다. 반환된 각 영상은 소유 값이며 원본 결과와 별도로 수명을 관리합니다.

적용과 판독을 더 살펴보기

채널을 선택하기 전에 결과가 Lab인지 LCH인지 확인합니다. 둘 다 인덱스 0은 L이지만 인덱스 1과 2의 의미가 다르며, 특히 LCH의 h는 도 단위 색조입니다. 인덱스가 3 이상이면 None이므로 Option을 분기하고 없는 채널을 빈 영상으로 취급하지 않습니다. 각 평면은 GrayF64 영상으로 반환되며 원래 결과의 기하를 유지합니다. ROI의 로컬 위치를 전역 영상에 비교할 때 원점을 적용하고, 입력 색의 인코딩과 백색점도 함께 기록합니다. 색 공간이 다른 평면에서 같은 수치가 나왔다는 이유만으로 같은 색이라는 결론은 내릴 수 없습니다.
