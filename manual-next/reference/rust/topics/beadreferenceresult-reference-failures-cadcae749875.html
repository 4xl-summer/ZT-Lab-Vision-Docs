pub fn reference_failures(&self) -> usize

Returns the number of reference failures.

기준 위반 수

기준에 대한 실패 수를 usize로 반환합니다. 위반 위치와 연결 구간은 reference_flags 및 reference_runs에서 별도로 확인하며 하나의 숫자만으로 공간적 위치를 복원하지 않습니다.

참조 또는 슬라이스를 반환하는 항목은 BeadReferenceResult의 수명에 묶입니다. 결과를 오래 보관해야 하면 필요한 값을 소유 자료로 복사합니다.

기준 위반 수의 해석

reference_failures()는 기준에 대한 실패 수를 usize로 반환합니다. 이 숫자는 위반의 공간 위치나 각각의 결함 구간 자체가 아닙니다. 위치별 정보는 reference_flags, 연속 구간은 reference_runs에서 따로 확인합니다.

예를 들어 실패 수가 3이라도 세 위반이 한 구간에 연속되었는지 서로 떨어졌는지는 수치 하나로 알 수 없습니다. flags를 경로 표본 순서와 연결하고 runs의 시작과 끝을 함께 읽어 원본 경로에 표시해야 합니다.

결과의 참조 슬라이스는 BeadReferenceResult의 수명 안에서 사용하고 오래 보관할 값은 소유 자료로 복사합니다. 입력 경로, 기준 폭과 검사 옵션이 바뀌면 실패 수도 달라질 수 있으므로 같은 조건의 실행끼리 비교합니다.

적용과 판독을 더 살펴보기

기준 폭과 중심의 위반은 표본별 플래그로 구분되며, 연속 구간은 설정한 최소 실패 탐침 수에 따른 결과입니다. 실패 개수만 보고 실제로 몇 개의 연속 구간이 있는지 또는 각 구간의 위치가 어디인지 알 수 없습니다. 원본 경로의 순서대로 flags를 확인하고 reference_runs의 시작·끝 인덱스를 연결해 표시합니다. 경로의 일부가 제외되거나 기준 모델의 폭이 달라지면 같은 영상에서도 판정 대상이 달라질 수 있습니다. 다른 검사와 비교할 때 모델, 입력 ROI, 포함 조건과 임계값을 함께 기록하고 전체 합격 여부는 해당 결과의 판정 필드에서 확인합니다.
