fn into_query(self) -> Self::Target

Transfers the owned engine representation out of the facade owner.

변환과 소유권

facade 소유 값을 소비하고 연관 타입 Target에 해당하는 내부 표현의 소유권을 반환합니다. 반환 타입과 구체적인 표현은 이 트레이트를 구현한 타입이 정합니다.

호출 후 이동된 원래 값을 다시 사용할 수 없으므로 먼저 필요한 작업을 마치십시오. 읽기만 필요하다면 해당 구체 타입의 빌림 API가 있는지 확인해 소유권 이전과 구분하십시오.

계획의 소유권 이동

IntoQuery는 facade 객체를 소비해 구현이 정한 Target 쿼리 표현의 소유권을 반환하는 bridge 트레이트입니다. self를 값으로 받으므로 호출 후 원래 facade 변수를 그대로 다시 사용할 수 없습니다. 이 트레이트 선언만으로 모든 facade가 같은 엔진 타입을 반환한다고 가정하지 않습니다.

구체적인 ImageQuery 구현은 Target을 엔진 ImageQuery로 정하고 내부 계획을 실행하지 않은 채 반환합니다. 따라서 into_query의 반환은 처리된 이미지가 아닙니다. 이후 엔진 쿼리에서 어떤 작업이 가능한지는 그 Target의 API 계약에 따라 확인해야 합니다.

같은 계획을 다른 흐름에서도 소유해야 한다면 이전 전에 구체 타입이 제공하는 복제 경로를 확인합니다. 읽기 전용 접근이 필요한 경우에는 해당 타입의 별도 빌림 API가 있는지도 확인할 수 있습니다. 소유권 이동과 픽셀의 깊은 복사나 계획의 실제 실행을 혼동하지 않습니다.
