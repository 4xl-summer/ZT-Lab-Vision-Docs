pub fn measure(&self, image: &ZImage) -> ZResult<LineMeasurementResult>

Evaluates this model on the supplied image.

사용과 결과 판독

검증된 직선 모델을 빌려 입력 ZImage의 ROI에서 관측하고 직선 계측 결과를 반환합니다. 모델의 기준 형상은 탐색 위치를 정하며 반환 형상이 반드시 기준과 같다는 뜻은 아닙니다. 프로브의 발견 상태와 최종 적합에 채택된 점을 구별하고, 형상이 없거나 피팅에 실패한 결과를 좌표 0으로 대체하지 마십시오. 다른 영상에 재사용할 때 ROI 원점과 검색 범위를 함께 확인합니다.

단계확인할 내용
모델직선의 검증된 기준과 설정을 빌립니다.
영상목적 경계가 포함된 ZImage ROI를 전달합니다.
관측발견된 프로브 점과 최종 채택점을 구별합니다.
결과형상 상태와 ROI 좌표 기준을 함께 확인합니다.

영상에서 직선 관측

measure는 LineMeasurementModel을 빌려 입력 ZImage의 ROI에서 관측을 수행하고 ZResult<LineMeasurementResult>를 반환합니다. 모델의 기준 직선은 탐침을 배치하는 기준이며 결과 직선이 반드시 그 기준과 같은 것은 아닙니다.

좌표ROI 기준과 원점을 함께 확인

각 탐침의 경계 발견 여부와 최종 피팅에 채택된 점을 구분합니다. 일부 탐침이 실패하거나 점의 배치가 부족하면 유효한 직선이 없을 수 있으므로 좌표 0으로 대체하지 않습니다. 반환 상태, 관측 잔차와 모델의 검색 범위를 원본 ROI 위에 함께 확인합니다.
