pub fn view_grayi32(&self) -> ZResult<GrayI32View<'_>>

이미지 수명에 묶인 불변 형식별 뷰를 반환합니다. 형식이 다르면 오류입니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<GrayI32View<'_>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

행 또는 뷰의 요소를 읽을 때 메서드가 지정한 픽셀 형식과 현재 영상의 형식이 맞는지 확인합니다. ROI의 보이는 영역과 행 인덱스를 기준으로 해석하고, 빌린 참조라면 이를 제공한 객체보다 오래 보관하지 않습니다.

결과와 조건을 함께 읽기

GrayI32 영상의 보이는 영역을 빌린 불변 뷰입니다. 각 픽셀은 부호 있는 i32 한 성분이며 8비트 밝기처럼 0~255로 제한된 값으로 가정하지 않습니다. 예를 들어 -3과 3은 서로 다른 유효한 정수 표현이며 이를 u8로 강제 해석하면 의미가 달라집니다. 뷰의 행은 ROI 너비와 영상의 행 간격을 사용하므로 원본 저장소의 패딩을 보이는 픽셀로 세지 않습니다. 다른 형식의 이미지는 오류이고, 뷰는 원본 이미지보다 오래 빌려 쓸 수 없습니다.
