pub fn to_packed_vec_gray16(&self) -> ZResult<Vec<u16>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<u16>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

Gray16 값의 독립 배열

to_packed_vec_gray16은 보이는 Gray16 성분을 행 우선의 독립 Vec<u16>로 복사합니다. 반환 요소는 바이트가 아니라 u16 값이며 원본 행의 패딩은 배열에 포함되지 않습니다. 다른 형식의 영상에서 호출하면 형식 검사 오류를 처리해야 합니다.

항목의미와 확인
입력Gray16 영상 또는 ROI
반환Vec<u16> 소유 복사
첫 행[1,1000]
둘째 행[2000,65535]
결과[1,1000,2000,65535]
패딩원본 행 패딩은 포함되지 않음

사용할 때의 판독

예를 들어 2×2 ROI의 두 행이 [1,1000]과 [2000,65535]라면 결과 요소 순서는 [1,1000,2000,65535]입니다. 길이는 4개 u16이며 보이는 값은 원본 영상과 별도 소유됩니다. 이 요소 수와 바이트 수를 혼동하지 말고 저장할 때 필요한 바이트 순서는 별도 형식 계약으로 정하세요.
