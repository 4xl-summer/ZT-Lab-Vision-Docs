pub fn color_correct(self, model: &ColorCorrection) -> ZResult<Self>

Plans color correction with retained coefficients.

색 보정 행렬 적용

Rust의 ImageQuery 호출은 이 처리를 실행 계획에 연결합니다. ColorCorrection의 3×3 행렬과 RGB 편향을 사용해 입력 색을 조정합니다. 각 출력 채널은 입력의 세 채널이 행렬을 통해 결합된 뒤 해당 편향이 더해진 값으로 해석합니다. 예를 들어 단위 행렬과 0 편향은 색 보정의 기준 설정입니다.

계획을 실행해 얻은 결과의 해석에서는 보정 계수는 패치 대응값을 이용한 fit_color_correction 결과에서 얻을 수 있습니다. 결과의 보정 전후 평균과 최대 색차를 함께 확인하면 소수의 패치가 크게 벗어나는 경우를 놓치지 않을 수 있습니다. 학습 패치 외의 별도 입력에서도 효과를 확인합니다.

이 호출은 Rust의 지연 쿼리 단계입니다. 빌더의 이동과 소유 관계를 확인하고 별도 분기가 필요하면 지원되는 clone을 사용합니다. execute 결과는 반환 타입의 소유 규칙에 따라 다룹니다.

색 보정 계획

ColorCorrection의 3×3 행렬과 RGB 편향을 사용하는 이미지 처리 단계를 계획에 추가합니다. 이 호출은 self를 소비하고 새 ImageQuery를 ZResult로 반환하므로 반환된 계획을 이어서 사용합니다. 계획 작성 자체는 픽셀 계산의 완료가 아닙니다.

단위 행렬과 편향 (0,0,0)은 세 채널을 유지하는 기준 설정입니다. 보정 계수를 학습했다면 측정 패치와 목표 패치의 대응, 보정 전후 색차를 함께 확인합니다. 입력 RGB의 채널 의미를 행렬의 순서와 맞춰야 합니다.

동일한 전처리에서 보정 조건을 분기하려면 기존 쿼리를 clone한 후 각 분기에 설정을 추가합니다. 이후 실제 execute의 출력과 오류를 확인합니다. 계산된 결과가 필요하기 전에 계획만으로 보정 영상이 생성되었다고 기록하지 않습니다.
