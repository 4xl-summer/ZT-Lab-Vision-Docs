Frame identifier.

좌표계 식별자 조회

frame은 좌표가 어느 좌표계에서 표현되었는지 구별하는 식별자입니다. 같은 숫자의 점이라도 frame이 다르면 같은 위치라고 가정할 수 없습니다. 이 식별자는 좌표계를 바꾸는 행렬이 아니므로 값을 읽는 것만으로 좌표가 변환되지는 않습니다.

변환의 출발 frame이 7이고 도착 frame이 8이라면 frame 7의 점군에 적용한 결과는 frame 8에서 해석합니다. 반대로 frame 8의 점을 같은 방향으로 다시 적용할 수는 없습니다. 정합이나 보정 전 데이터와 모델의 frame 조건을 비교합니다.
