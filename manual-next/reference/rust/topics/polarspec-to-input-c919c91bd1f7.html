pub fn to_input(self, p: Point2) -> Result<Point2, ZError>

Output pixel coordinate to input ROI-local coordinate; accepts fractional points.

계산 순서와 결과 확인

극좌표 출력 픽셀의 x를 각도, y를 반지름으로 보간해 입력 ROI 로컬 점으로 바꿉니다. 끝점은 width−1과 height−1에 대응하고 소수 좌표도 허용합니다. 예를 들어 시작 각도 0과 반지름 r이면 첫 각도 열은 중심에서 x 방향으로 r만큼 떨어집니다. 출력 범위 밖과 잘못된 설정은 오류입니다.

입력과 계산 확인

항목의미와 조건
출력 x각도 축; 0과 width−1이 양 끝
출력 y반지름 축; 0과 height−1이 양 끝
반환입력 ROI 로컬 점

극좌표 출력에서 입력으로

to_input은 출력의 x를 각도 축, y를 반경 축으로 보간해 입력 ROI 로컬 Point2를 반환합니다. 소수 좌표도 허용하지만 x는 0–width−1, y는 0–height−1 범위여야 합니다. 비유한 좌표나 잘못된 설정은 오류입니다.

항목의미와 사용
p.x출력 각도 축
p.y출력 반경 축
각도 단위라디안
반경 단위픽셀
반환입력 ROI 로컬 Point2
경계width−1, height−1까지 포함

각도 a는 시작과 끝 각도를 x/(width−1)로 보간하고 반경 r은 y/(height−1)로 보간합니다. 결과는 (center_x+r cos a, center_y+r sin a)입니다. a=0, r=2이면 중심에서 x 방향으로 2픽셀입니다. 전체 영상에 표시할 때 ROI 원점을 적용합니다.
