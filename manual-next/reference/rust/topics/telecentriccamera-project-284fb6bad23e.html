계산 순서와 결과 확인

축 정렬 정사영 카메라의 점을 x′=cx+sx×X, y′=cy+sy×Y로 투영합니다. 카메라 Z는 투영 위치를 바꾸지 않습니다. 예를 들어 sx=2, cx=10이면 X=3은 픽셀 x=16입니다. 좌표의 물리 단위와 camera_frame을 모델에 맞추고 유한하지 않은 입력은 오류로 처리합니다.

입력과 계산 확인

항목의미와 조건
x 픽셀cx + sx × X
y 픽셀cy + sy × Y
깊이 Z이 축 정렬 정사영의 위치에 영향 없음

정사영 투영

TelecentricCamera.project는 카메라 프레임의 Point3를 글로벌 픽셀 Point2로 투영합니다. x′=cx+sx×X, y′=cy+sy×Y이며 이 모델에서 깊이 Z는 투영 위치를 바꾸지 않습니다. 입력 길이 단위와 camera_frame을 모델에 맞춥니다.

항목의미와 사용
X / Y카메라 프레임 평면 좌표
Z투영 위치에 영향 없음
sx / sy양의 축별 배율
cx / cy글로벌 픽셀 오프셋
반환글로벌 픽셀 Point2
오류무효 모델 또는 비유한 입력

sx=2, cx=10, X=3이면 x′=16입니다. 같은 X·Y에서 Z만 달라진 점은 같은 픽셀에 놓일 수 있으므로 한 투영만으로 깊이를 구할 수 없습니다. sx와 sy는 양의 유한 값, camera_frame은 0이 아니어야 하며 비유한 입력은 오류입니다.
