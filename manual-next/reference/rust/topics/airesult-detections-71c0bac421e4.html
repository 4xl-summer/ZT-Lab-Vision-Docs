검출 결과

검출 출력이면 AiDetection 슬라이스를 Some으로 반환하고 다른 작업이면 None입니다. 각 상자의 좌표와 점수, 클래스 번호를 동일한 입력 프레임과 연결합니다.

AiTask와 입력 조건을 결과에 함께 보관합니다. 빌린 슬라이스는 AiResult가 살아 있는 동안 사용하며, acquire_map의 반환 영상은 별도의 소유 공유입니다.

사용 흐름과 결과 판독

detections는 AiResult가 검출 작업의 출력을 갖고 있을 때 Some 안에 AiDetection 불변 슬라이스를 제공합니다. 다른 작업의 결과라면 None이며, 검출 작업이지만 발견된 상자가 없는 경우에는 Some 안의 빈 슬라이스일 수 있습니다. 이 두 상태를 모두 같은 오류나 0번 클래스의 검출로 바꾸지 않습니다.

각 검출 항목의 상자 좌표, 점수와 클래스 번호는 같은 입력 프레임과 모델 설정에 연결하여 읽습니다. 예를 들어 상자 둘이 같은 클래스를 가리켜도 위치와 점수는 별개이며, 클래스 번호를 이름으로 표시하려면 해당 모델의 labels 매핑을 사용해야 합니다. 모델이 제공하지 않은 클래스 이름을 번호만 보고 추정하지 않습니다.

반환 슬라이스는 AiResult 내부의 데이터를 빌리므로 결과보다 오래 보관할 수 없습니다. 장기간 저장할 값은 필요한 항목을 소유 자료로 복사합니다. 분할 등의 작업에서 acquire_map으로 얻는 영상은 별도의 소유 공유이므로 검출 슬라이스와 같은 수명 규칙으로 취급하지 않고 AiTask와 입력 전처리 조건도 함께 기록합니다.
