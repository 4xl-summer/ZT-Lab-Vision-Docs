모델 버전 식별자

추론에 사용한 호출자 지정 모델 버전을 u64로 반환합니다. 이 값은 결과의 출처를 연결하는 식별자이며 모델 파일 내용이나 정확도를 자동 검증하지 않습니다.

AiTask와 입력 조건을 결과에 함께 보관합니다. 빌린 슬라이스는 AiResult가 살아 있는 동안 사용하며, acquire_map의 반환 영상은 별도의 소유 공유입니다.

결과 출처와 출력 종류

model_version은 AiResult에 기록된 u64 모델 식별자를 값으로 반환합니다. 이 값은 AiModelSpec에서 호출자가 지정한 추적 ID이며 모델 파일의 암호학적 해시나 성능 검증 결과가 아닙니다. 동일한 숫자를 재사용했다면 숫자만으로 두 파일이 동일하다고 증명할 수 없습니다.

추론 입력 영역은 region에서 확인하고 결과는 task에 맞는 조회를 사용합니다. classification, detections, anomaly 등의 조회는 실제 출력 종류에 따라 Option으로 제공되므로 다른 작업의 출력을 무조건 존재한다고 가정하지 않습니다. 점수나 검출 결과를 모델 버전과 입력 영역에 연결해 기록합니다.

예를 들어 model_version 12가 결과에 표시된다면 애플리케이션이 버전 12로 관리한 모델 사양을 찾아보는 데 사용할 수 있습니다. 파일 바이트를 검증하려면 별도 식별·검증 절차가 필요합니다. 반환 u64는 값이고 결과에서 빌린 슬라이스나 acquire_map의 소유 영상과 수명이 다릅니다.

판독과 확인 사례

모델 사양의 버전은 호출자가 정하는 추적 값이므로 배포 시스템에서 실제 모델 파일과 해당 번호의 대응을 보관해야 합니다. 같은 버전 번호를 다른 파일에 부여할 수도 있으므로 번호를 내용 검증으로 사용하지 않습니다. 작업 종류와 입력 전처리 정보도 결과 해석에 필요합니다.

예를 들어 classification의 점수 슬라이스는 결과 내부를 불변으로 빌리는 조회이고 segmentation 또는 anomaly 맵은 acquire_map으로 영상 공유를 얻는 경로입니다. 숫자 model_version 자체는 u64 값으로 복사되며 결과 객체를 빌리는 슬라이스의 수명과 구분됩니다.
