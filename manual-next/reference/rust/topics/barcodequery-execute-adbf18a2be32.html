pub fn execute(&self) -> RecognitionResult<QueryExecution<BarcodeRead>>

Executes the plan and preserves recognition errors and captures.

실행과 결과

계획된 바코드 인식을 실행해 BarcodeRead를 담은 QueryExecution을 반환합니다. 인식 오류는 결과 오류로 전달되며 실행은 캡처한 입력을 보존합니다.

계획 생성과 실행을 구분하고 반환된 읽기의 상태와 내용을 확인하십시오. 인식 성공과 코드의 기대 값 일치는 다른 판정입니다.

사용 흐름과 결과 판독

BarcodeQuery의 execute는 준비된 바코드 인식 계획을 실제로 실행하고 BarcodeRead를 담은 QueryExecution을 반환합니다. 함수의 RecognitionResult 오류와 정상 실행 후 BarcodeRead의 상태는 서로 다른 단계입니다. 실행 오류를 빈 문자열의 성공으로 바꾸지 말고 결과를 얻은 경우에도 읽기 상태, 형식과 내용을 확인합니다.

계획을 만들 때 설정한 입력, 영역과 바코드 조건에 따라 인식이 이루어집니다. 예를 들어 문자열이 읽혔더라도 애플리케이션이 기대한 제품 코드와 같은지 비교하는 것은 별도의 판정입니다. 인식 성공과 기대값 일치를 하나의 bool로 합치면 디코딩 실패와 다른 코드의 정상 판독을 구분하기 어렵습니다.

실행은 계획에 설정된 캡처도 보존합니다. 중간 영상이 필요하면 지정한 이름과 실행 결과의 접근 계약을 확인하고, 결과가 어느 입력 프레임에서 생성됐는지 함께 기록합니다. 인식된 위치가 ROI 로컬인 경우 글로벌 표시 전에 원점을 확인하며, Rust 소유 결과와 빌린 데이터의 수명을 혼동하지 않습니다.
