심볼 형식

인식한 BarcodeFormat을 Option으로 반환합니다. 형식이 없으면 None이며 이를 특정 형식의 정상 바코드로 대체하지 않습니다. 요청한 형식 목록과 실제 결과를 비교합니다.

BarcodeRead는 불변 결과 스냅샷입니다. 참조나 슬라이스를 반환하는 메서드는 소유 결과가 살아 있는 동안 사용할 수 있습니다.

형식 선택과 결과

이 호출은 인식된 BarcodeFormat을 Option으로 반환합니다. Some이면 실제 결과의 형식을 확인할 수 있고 None이면 형식이 제공되지 않은 상태입니다. None을 숫자 0의 형식이나 특정 심볼의 정상 판독으로 대체하지 않습니다.

입력 BarcodeSpec의 formats는 허용 형식을 고르는 비트 조합입니다. 예를 들어 Code 128 값 1과 QR 값 8을 허용하면 마스크는 9입니다. 요청에서 허용한 형식과 결과의 실제 형식을 나란히 기록하면 예상하지 못한 심볼이나 탐색 범위를 확인할 수 있습니다.

format만 보고 수락 여부를 결정하지 말고 status와 reasons, text를 함께 읽습니다. 같은 영역에 여러 코드가 존재하는 사례는 단일 판독 결과만으로 개수를 확정할 수 없습니다. 여러 심볼이 필요한 경우 복수 탐색의 설정과 결과를 따로 확인합니다.

이 접근자는 소유 BarcodeRead에서 호출합니다. 선택적 형식은 값으로 반환됩니다. 요청한 허용 형식과 실제 반환 형식을 별도 항목으로 남기면 탐색 설정을 나중에 비교할 수 있습니다.
