pub fn execute(&self) -> ZResult<QueryExecution<ConvexShapeResult>>

Executes the plan, retaining its independently shareable captures.

호출과 결과 확인

볼록 성분 분석 계획을 실행해 QueryExecution에 ConvexShapeResult를 반환하고 공유 가능한 캡처를 보존합니다. 결과의 shapes는 불변 슬라이스이며 껍질은 ROI 로컬 좌표입니다. 전경이 없는 정상 결과와 ZResult 오류를 별도로 처리합니다.

계획 실행과 결과 판독

영상 쿼리에서 전경 연결 방식과 볼록 형상 분석을 계획한 뒤 execute가 실제 처리를 수행합니다. 예를 들어 대각선으로만 닿은 두 전경 픽셀은 4연결에서 두 성분, 8연결에서 한 성분입니다. 이 차이는 실행 결과의 shapes 항목 수에 반영됩니다.

반환 QueryExecution은 출력과 캡처를 보유합니다. output으로 결과를 빌려 shapes를 읽고 캡처가 필요한 경우 실행 객체의 수명 안에서 확보합니다. into_output은 실행을 소비하고 캡처를 버리므로 순서를 구분합니다. 빈 성분 결과는 성공한 빈 결과이고 ZResult 오류와 다릅니다.
