pub fn find( &self, image: &ZImage, mask_image: Option<&ZImage>, options: FeatureMatchOptions, ) -> ZResult<MatchingReport<FeatureMatchResult>>

Searches this model in an image.

호출과 결과 해석

영상의 특징을 학습된 모델 기술자와 대응시키고 FeatureMatchOptions로 기하를 검증합니다. mask_image는 선택적 검색 마스크이며 학습 템플릿의 마스크와 구분합니다. 반환 MatchingReport에서 대응과 변환 추정, 평가 상태를 함께 확인합니다. 특징점이 검출되었다는 사실만으로 기하 변환이 성립했다고 판단하지 않습니다.

조건과 결과 판독

학습된 특징 모델을 image에서 검색합니다. mask_image는 검색 영상에 적용할 선택적 마스크이며 모델 학습 때 사용한 템플릿 마스크와 역할이 다릅니다. options는 기술자 대응과 기하 추정에 적용할 검색 설정입니다.

반환된 FeatureMatchResult에는 소스 특징과 대응 목록, 선택적인 matrix, 인라이어 수와 평가 수가 있습니다. 대응점이 하나라도 있다는 사실만으로 기하 변환이 반드시 존재하지는 않으므로 matrix의 Option과 인라이어·잔차를 함께 살피세요. 호출 오류는 검색 결과가 없는 정상 보고와 구분합니다.

예를 들어 대응점이 여러 개 검출되어도 표본의 기하 배치가 불충분하거나 인라이어 조건에 미달하면 matrix가 없을 수 있습니다. 그런 경우 영상 좌표에 변환을 적용하지 말고 대응별 inlier와 residual, 사용한 임계값과 평가 조건을 확인하세요. ZResult 오류가 발생했다면 보고서 자체가 반환된 것은 아닙니다.
