영상 피라미드 탐색

형상 모델의 영상 피라미드 탐색 경로를 사용해 입력 영상에서 후보를 찾습니다. source, ImagePyramidMatchOptions와 min_gradient를 전달하고 실행 결과의 보고 정보를 확인합니다.

피라미드는 서로 다른 해상도의 영상을 사용하는 탐색 방식입니다. 예를 들어 한 축이 절반인 영상에서 한 픽셀은 원래 영상의 두 픽셀 간격에 해당하므로, 결과를 사용할 때 보고된 좌표 기준을 확인해야 합니다. 단순한 해상도 비율만으로 모델의 자세나 정확도를 추정하지 않습니다.

모델을 학습한 영상과 검색 영상의 대비, 크기 및 허용 자세가 옵션과 맞는지 검토합니다. 결과에 후보가 없을 수 있으며 잘못된 옵션 또는 입력에서 반환한 오류와는 다릅니다. 같은 프레임의 모델과 설정을 결과와 함께 보관합니다.
