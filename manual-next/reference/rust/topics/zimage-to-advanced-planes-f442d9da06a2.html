Rust
pub fn to_advanced_planes( &self, white: LabWhitePoint, transfer: InputTransfer, space: AdvancedColorSpace, ) -> ZResult<AdvancedPlanes>

Converts to Lab or LCH planes using the selected white point and transfer.

호출에 필요한 입력

영상을 지정 백색점·입력 전달 함수의 Lab 또는 LCH 평면으로 변환합니다.

인자선언된 형식확인할 내용
whiteLabWhitePoint백색점; 기본 D50.
transferInputTransfer입력 전달 함수; None이면 sRGB.
spaceAdvancedColorSpace출력 색 공간; 기본 LAB.

white의 입력 값

필드의미와 조건
D50값 0. D65 원본 백색에서 Bradford 적응을 거친 D50 기준 백색을 사용합니다.
D65값 1. sRGB 원색의 D65 기준 백색을 사용합니다.

space의 입력 값

필드의미와 조건
LAB값 0. 변환 출력의 세 채널을 Lab로 지정합니다.
LCH값 1. 변환 출력의 세 채널을 명도·채도·색상각 LCh로 지정합니다.

결과와 사용 순서

반환 선언 ZResult<AdvancedPlanes>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

색상 처리는 채널 순서, 입력 형식과 값 범위의 영향을 받습니다. 알려진 단색 입력을 이용해 각 출력 채널이 기대한 의미를 갖는지 확인하고 서로 다른 색 공간의 값을 혼동하지 마세요.
