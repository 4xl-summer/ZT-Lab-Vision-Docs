pub fn pixel_to_ray(&self, p: Point2) -> Result<ModelRay, ZError>

Each pixel has a distinct origin on camera Z=0 and the common direction +Z.

계산 순서와 결과 확인

픽셀마다 Z=0 평면의 서로 다른 광선 원점과 공통 방향 (0,0,1)을 반환합니다. 원점은 ((x−cx)/sx,(y−cy)/sy,0)입니다. 예를 들어 픽셀 (cx,cy)은 원점 (0,0,0)의 광선입니다. 원근 카메라처럼 모든 광선이 한 원점에서 나온다고 해석하지 않습니다.

입력과 계산 확인

항목의미와 조건
원점((x−cx)/sx, (y−cy)/sy, 0)
방향모든 픽셀에서 (0,0,1)
특성픽셀마다 원점이 다름

픽셀에서 평행 광선 생성

pixel_to_ray는 픽셀 Point2를 TelecentricCamera의 광선 ModelRay로 변환합니다. 먼저 카메라 파라미터와 입력 점을 검증하고, 카메라 Z=0 평면에서 픽셀마다 다른 원점과 공통 +Z 방향을 반환합니다.

광선 원점은 ((x-cx)/sx, (y-cy)/sy, 0)이고 방향은 (0,0,1)입니다. 예를 들어 sx=2, sy=4, 중심이 (0,0), 입력 픽셀이 (4,8)이면 원점은 (2,2,0)입니다. 모든 픽셀이 하나의 중심을 통과하는 원근 모델과 구분합니다.

sx와 sy는 유한한 양수여야 하고 cx와 cy도 유한해야 하며 camera_frame은 0이 아니어야 합니다. 입력 점도 유한해야 합니다. 조건이 잘못되거나 계산된 원점이 유한하지 않으면 ZError로 반환합니다.

광선 원점의 좌표는 카메라 모델이 지정한 길이 단위와 프레임으로 해석합니다. ROI 로컬 픽셀이라면 전체 프레임 좌표에 맞춘 후 전달해야 합니다. 결과 광선은 값이며 실제 물체와의 교점이나 깊이는 별도 정보 없이 결정되지 않습니다.
