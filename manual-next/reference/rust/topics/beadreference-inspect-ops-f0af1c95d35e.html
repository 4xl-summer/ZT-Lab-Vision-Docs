기존 Ops 기준으로 검사

기존 ops::BeadReference를 빌리고 이미지, width_tolerance와 center_tolerance를 전달해 검사합니다. 래퍼 모델을 새로 학습하거나 기존 기준을 복제하지 않습니다.

폭과 중심 허용치는 서로 다른 조건이므로 각각 기록합니다. 이미지와 기준 경로의 좌표가 대응하는지 확인하고 잘못된 입력의 오류와 실제 통과 결과를 구분합니다.

기존 Ops 기준 검사

inspect_ops는 기존 ops::BeadReference를 빌려 image를 width_tolerance 및 center_tolerance로 검사합니다. 래퍼 모델을 새로 학습하거나 기존 학습 상태를 복제하는 호출이 아닙니다. 반환은 BeadReferenceResult를 담는 ZResult입니다.

폭 허용치와 중심 허용치는 각각 다른 편차에 적용됩니다. 한 조건만 통과했다고 다른 조건도 통과한다고 가정하지 말고 결과의 탐침별 폭 오차와 기준 플래그, 연속 위반 구간을 함께 살펴봅니다.

기준 모델의 경로는 학습 입력의 ROI 로컬 좌표를 기준으로 합니다. 검사 영상이 다른 원점이라면 같은 수치의 점이 다른 위치를 가리킬 수 있으므로 입력 기하와 정렬을 먼저 확인합니다. 픽셀 길이를 자동으로 물리 길이로 간주하지 않습니다.

연산이 실패한 오류와 유효한 검사 결과의 불합격을 구분합니다. 모델, 입력 프레임 및 두 허용치를 결과와 함께 기록하면 이후 동일한 기준에서 오차와 구간을 재검토할 수 있습니다.
