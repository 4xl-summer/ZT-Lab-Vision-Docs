fn into_engine(self) -> Self::Target

Transfers the owned engine representation out of the facade owner.

변환과 소유권

facade 소유 값을 소비하고 연관 타입 Target에 해당하는 내부 표현의 소유권을 반환합니다. 반환 타입과 구체적인 표현은 이 트레이트를 구현한 타입이 정합니다.

호출 후 이동된 원래 값을 다시 사용할 수 없으므로 먼저 필요한 작업을 마치십시오. 읽기만 필요하다면 해당 구체 타입의 빌림 API가 있는지 확인해 소유권 이전과 구분하십시오.

대상 타입구현별 연관 타입 Target

Rust에서 확장 메서드를 사용하려면 해당 bridge 트레이트를 스코프에 가져와야 합니다. 구체 구현의 수명과 오류 조건을 함께 확인하십시오.

facade 소유 값을 엔진으로

IntoEngine은 facade의 self를 값으로 소비해 구현별 Self::Target 엔진 표현의 소유권을 돌려줍니다. 호출은 &self 빌림이 아니므로 이동한 원래 facade 변수를 그 뒤 다시 사용할 수 없습니다. 반환 타입은 트레이트 이름만으로 공통 하나로 결정되지 않고 구체 구현에서 정해집니다.

실제 SimulatedCamera 구현은 내부 엔진 SimCamera를 반환하고 상태를 바꾸지 않고 소유권을 넘깁니다. AcquiredFrame 구현은 프레임 정보와 내부 영상을 엔진 프레임 표현으로 이전합니다. 이 두 Target이 다르므로 한 구현의 내부 타입을 다른 facade에도 일반화해서는 안 됩니다.

실행과 판독에서 확인

전달 전에 facade를 계속 사용해야 하는지 결정하고, 필요한 경우 구체 타입의 빌림이나 공유 기능이 제공되는지 확인하세요. 이동한 소유 값을 소비하는 경로와 원본을 유지하는 as_engine 빌림 경로의 역할은 다릅니다. 반환된 엔진 값의 정리와 후속 사용은 그 타입의 소유권 규칙을 따릅니다.
