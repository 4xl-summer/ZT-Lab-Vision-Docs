pub fn normalize_inspection( &self, reference: &ZImage, mask: Option<&ZImage>, options: InspectionNormalizationOptions, ) -> ZResult<ZImage>

Applies the existing reference-based photometric normalization.

검사 영상 정규화

현재 영상과 reference, 선택 마스크 및 InspectionNormalizationOptions로 검사 영상을 정규화하고 새 ZImage를 반환합니다. 선택 마스크와 기준 영상이 같은 검사 위치를 가리키는지 먼저 확인합니다.

정규화는 입력 밝기 조건을 조정하는 처리이며 기하학적 정렬을 대신하지 않습니다. 적용한 옵션과 전후의 픽셀 값을 기록하고 잘못된 입력은 ZResult 오류로 처리합니다.

기준 영상과 정규화 조건

현재 영상과 reference는 같은 너비·높이·원점과 회색 픽셀 형식이어야 합니다. 지원 입력은 Gray8, Gray16, GrayF32 또는 GrayF64이며 부동소수 값은 유한해야 합니다. 선택 mask는 같은 기하의 Gray8이고 0이 아닌 위치가 정규화 적합과 출력에 참여합니다.

InspectionNormalizationOptions의 mode는 MeanStd, Histogram, RobustLine, LocalMeanStd 또는 MatchTails를 선택합니다. LocalMeanStd에서는 양의 tile_width와 tile_height가 필요하며 다른 모드에서는 둘 다 0이어야 합니다. MatchTails의 tail_low와 tail_high는 각각 비음수이고 합은 1보다 작아야 합니다.

결과는 독립 GrayF64 영상이며 마스크에서 제외된 위치는 0입니다. 예를 들어 한 픽셀의 입력이 20이어도 mask가 0이면 반환 위치는 0이므로 이 값을 실제 정규화 관측으로 오해하지 않습니다. 빈 적합 집합이나 평균·표준편차 방식의 0인 소스 분산, 초과 작업량은 오류입니다.
