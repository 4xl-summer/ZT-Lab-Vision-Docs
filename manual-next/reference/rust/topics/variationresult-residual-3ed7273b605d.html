pub fn residual(&self) -> ZImage

Shares the signed residual image.

부호 있는 잔차

기준과 입력의 부호 있는 잔차 영상을 독립 공유 ZImage로 반환합니다. 부호는 변화 방향의 해석에 필요하므로 절대 크기인 severity나 이진 mask와 같은 값으로 읽지 않습니다.

결과를 화면에 그릴 때 표시 범위와 원본 수치를 구분합니다. 반환 영상은 결과 내부 저장소의 공유 소유권을 갖는 별도 ZImage입니다.

조건과 결과 판독

residual은 기준 대비 부호 있는 잔차 영상을 별도 ZImage 공유로 취득합니다. 부호는 변화 방향을 나타내며 절대 크기 기반 severity와 다릅니다. mask는 판정 결과이므로 세 영상을 같은 숫자 의미로 읽지 마세요.

예를 들어 서로 반대 방향으로 변한 두 픽셀은 절대 크기가 같아도 잔차 부호가 다를 수 있습니다. 화면 표시에서 음수를 잘라내면 방향 정보가 사라질 수 있으므로 수치 범위와 표시 스케일을 구분합니다. 반환 ZImage는 내부 저장소의 별도 공유 소유권을 갖습니다.

예를 들어 입력의 한 위치가 기준보다 커지고 다른 위치가 반대 방향으로 변하면 두 잔차의 부호가 서로 다를 수 있습니다. 심각도는 변화의 크기를 보는 데 쓰고 마스크는 판정 위치를 보는 데 쓰므로, 방향을 추적해야 한다면 residual의 원래 수치를 보관하세요.
