pub fn find_robust_shape_matches( &self, source: &ZImage, options: &RobustShapeSearchOptions, search_mask: Option<&ZImage>, ) -> ZResult<ExtendedMatchResult>

Searches with bounded occlusion, preserving its detached report. Zero occlusion uses the ordinary shape search, including candidate order, score and termination semantics.

호출 맥락과 결과 해석

RobustShapeSearchOptions는 기본 형상 검색 설정 base와 max_occlusion_fraction을 묶습니다. 허용 가림 비율 범위는 0부터 0.9까지이며 0이면 일반 형상 점수를 사용합니다. 가려진 표본과 완전한 표본에서 같은 검색 격자를 유지하고 결과 및 종료 상태를 비교하면 가림 허용의 영향을 살필 수 있습니다.

가림 허용 검색의 비교

모델과 source 영상, RobustShapeSearchOptions 및 선택적인 search_mask를 전달해 가림을 고려한 형상 검색을 수행합니다. max_occlusion_fraction은 0부터 0.9까지이며 0이면 일반 형상 검색 경로를 사용해 후보 순서, 점수와 종료 의미도 일반 검색과 같습니다. 이 값은 무조건 발견할 수 있는 가림 비율을 보증하지 않습니다.

항목의미와 확인
source검색할 입력 영상
options.base일반 형상 검색 설정
가림 비율 0일반 형상 검색과 같은 경로
가림 비율 >0허용 가림을 고려한 검색
search_mask선택적인 검색 영상 마스크
결과후보와 독립 검색 보고를 함께 확인

사용할 때의 판독

같은 영상에 부분 가림이 생긴 상황을 평가하려면 검색 범위와 기본 옵션을 고정하고 가림 비율만 바꿔 반환 점수와 보고를 비교하세요. 모델 특징의 일부가 가려진 경우와 잘못된 위치의 후보를 구별하려면 위치·각도뿐 아니라 후보 수와 종료 사유도 확인합니다. 마스크는 영상 검색 영역을 제한하는 입력이며 모델의 학습 마스크와 구별합니다.
