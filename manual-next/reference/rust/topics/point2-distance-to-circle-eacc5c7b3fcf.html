pub fn distance_to_circle(self, circle: &CircleFit) -> Result<f64, ZError>

Nonnegative minimum distance to a fitted circle boundary.

계산 순서와 결과 확인

점에서 적합 원의 경계까지 비음수 최소 거리를 입력 좌표 단위로 계산합니다. 원 안쪽 점도 경계까지의 거리를 갖습니다. 예를 들어 원 중심에서 경계까지의 거리는 반지름입니다. 중심까지의 거리나 부호 있는 내부·외부 판정과 구분합니다.

점에서 원 경계까지

점에서 CircleFit의 원 경계까지 음이 아닌 최소 거리를 계산합니다. 중심과 점 사이 거리를 d, 반지름을 r이라 하면 |d−r|입니다. 점이 원 안에 있어도 음수를 반환하지 않으며 거리 단위는 입력 좌표 단위입니다.

중심 (0,0), 반지름 5인 원과 점 (0,2)의 거리는 |2−5|=3입니다. 점 (3,4)는 경계 위이므로 0이고 원 중심에서는 5입니다. 내부·외부 판정이 필요하면 중심 거리와 반지름을 별도로 비교하십시오.
