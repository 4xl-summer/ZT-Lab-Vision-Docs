사용과 결과 판독

계획된 캘리퍼를 실행하고 에지 스냅샷을 담은 QueryExecution을 반환합니다. &self로 계획을 빌려 실행하며 Result의 성공을 확인한 후 에지 목록을 확인합니다. 에지가 없는 결과와 유효하지 않은 입력으로 인한 오류를 구분하고, 극성과 탐색 방향 및 ROI 원점을 같은 실행의 설정과 함께 기록하십시오.

단계확인할 내용
계획캘리퍼 쿼리를 빌려 해당 처리를 실행합니다.
반환에지 스냅샷이 포함된 실행 결과입니다.
에지위치와 진행 거리, 부호 있는 강도를 확인합니다.
빈 결과에지 없음과 호출 오류를 구별합니다.

계획 실행과 결과

CaliperQuery의 execute는 준비된 캘리퍼 측정 계획을 실제 영상에 적용합니다. 계획 구성만으로 경계가 이미 검출된 것은 아니며, 실행 시 입력 형식이나 ROI 등 조건에 따라 오류가 날 수 있습니다.

성공한 결과에서는 검출된 에지의 위치와 점수를 캘리퍼의 검색 방향 및 원본 영상과 연결해 읽습니다. 에지가 없거나 다른 후보가 선택된 경우 검색선과 임계 조건을 먼저 점검합니다. 결과의 좌표계와 실행 객체의 수명을 확인합니다.
