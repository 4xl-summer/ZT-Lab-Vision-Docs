Rust
pub fn mosaic( &self, scale: f64, overlap: MosaicOverlap, ) -> ZResult<RegistrationMosaic>

Renders the union canvas with the requested overlap policy.

사용과 결과 해석

정합 영상들의 공통 좌표 합집합 캔버스를 만들고 지정한 겹침 정책으로 영상을 합성합니다. 결과에는 영상과 유효 마스크 및 기하가 포함됩니다.

겹침 정책은 여러 영상이 같은 출력 위치에 기여할 때의 처리를 정합니다. 검은 픽셀과 영상이 없는 픽셀을 구분하려면 유효 마스크를 함께 사용하십시오.

입력과 결과 확인

MultiRegistration::mosaic은 정합된 영상들이 차지하는 공통 좌표의 합집합 캔버스에 출력을 렌더링합니다. scale은 출력 배율이고 overlap은 여러 영상이 같은 출력 위치에 기여할 때의 처리 정책입니다. 반환 RegistrationMosaic에서 영상, 유효 마스크와 기하를 함께 확인합니다.

예를 들어 두 영상이 일부 영역에서 겹치면 First, Last, Mean 같은 정책에 따라 그 위치에서 사용할 값이 달라질 수 있습니다. 정책 이름을 정합의 정확도 점수로 읽지 말고 어떤 입력을 어떻게 합성할지의 선택으로 해석하십시오.

출력 픽셀이 검은 값 0인 것과 어느 영상도 해당 위치를 채우지 않은 것은 다를 수 있습니다. 유효 마스크를 함께 읽어 두 경우를 구분하고, 캔버스의 공통 좌표 원점과 배율을 보관해야 출력 위치를 원본 영상과 연결할 수 있습니다. 유효하지 않은 설정은 ZResult 오류로 다룹니다.

항목확인할 내용
scale공통 캔버스 출력의 배율입니다.
overlap겹치는 입력의 합성 정책입니다.
캔버스변환된 영상들의 공통 좌표 합집합입니다.
영상합성된 픽셀을 읽습니다.
마스크영상이 없는 위치와 실제 0값을 구별합니다.
기하출력의 원점과 배율을 결과와 함께 보관합니다.

모자이크의 각 출력 픽셀은 캔버스 기하의 원점과 scale에 따라 공통 좌표로 해석됩니다. 따라서 같은 배열 인덱스라도 원점이나 배율이 다른 두 모자이크에서는 다른 공통 위치를 뜻할 수 있습니다. 합집합 크기는 입력 영상을 변환한 결과에 따라 정해지며, 겹침 정책과 유효 마스크를 같이 기록해야 검은 실제 화소와 입력이 채우지 않은 위치를 구별할 수 있습니다. 결과 영상과 기하를 분리해 보관할 때도 같은 실행에 속하도록 연결하십시오.

출력 좌표에서 원본 영상의 위치를 찾으려면 먼저 캔버스 원점과 배율로 공통 좌표를 구하고 각 영상의 대응 행렬을 확인해야 합니다. 단순히 같은 x, y 인덱스를 모든 원본에 적용하지 마십시오.
