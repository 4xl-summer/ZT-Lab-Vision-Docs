pub fn source_dimensions(&self) -> (usize, usize)

Source dimensions before padding.

데이터와 계산

패딩하기 전 원본 입력의 너비와 높이를 반환합니다.

이 값은 변환 격자의 크기와 다를 수 있습니다. 원본 크기로 역변환 결과를 자르려는 경우 crop과 함께 확인합니다.

항목이 호출의 의미
반환패딩 전 원본 (너비, 높이)
모델GeneralSpectrum
배열 배치행 우선
수명독립 결과와 소유자는 각각 관리

결과 확인

예를 들어 입력 3×3을 4×4 격자로 변환했다면 원본 크기는 (3,3)이고 전체 계수 크기는 (4,4)입니다. 크기를 바꾸어 읽으면 배열의 행 경계가 잘못됩니다.

GeneralSpectrum의 source_dimensions 결과를 다른 영상 또는 주파수 처리에 연결할 때는 크기, 원점 및 정규화를 함께 확인하십시오.
