이미지 수명에 묶인 불변 형식별 뷰를 반환합니다. 형식이 다르면 오류입니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<GrayI16View<'_>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

행 또는 뷰의 요소를 읽을 때 메서드가 지정한 픽셀 형식과 현재 영상의 형식이 맞는지 확인합니다. ROI의 보이는 영역과 행 인덱스를 기준으로 해석하고, 빌린 참조라면 이를 제공한 객체보다 오래 보관하지 않습니다.

조건과 결과 판독

성공하면 GrayI16의 부호 있는 16비트 픽셀을 빌린 불변 뷰로 읽습니다. 예를 들어 값 −3은 부호 없는 밝기 65533으로 바꾸어 해석하지 않습니다. 다른 픽셀 형식을 GrayI16으로 변환하는 호출이 아니며 형식이 일치하지 않으면 오류입니다.

반환 뷰의 수명은 원본 ZImage에 묶입니다. ROI의 보이는 행과 폭으로 데이터를 해석하고 각 행 사이의 원본 저장 간격이 폭과 같다고 가정하지 마세요. 영상과 독립적으로 보관할 데이터가 필요하면 해당 형식의 packed 복사 결과를 사용합니다.
