pub fn match_advanced_colors( &self, samples: &[LabColor], metric: ColorDistance, ) -> ZResult<AdvancedMatches>

Matches each pixel to its closest D50 Lab reference.

호출과 결과 확인

영상의 각 픽셀을 D50 Lab 기준 색들과 지정한 ColorDistance 방식으로 비교합니다. samples의 순서가 반환 인덱스의 기준이므로 표본 목록과 결과를 함께 보관합니다. 반환 AdvancedMatches의 indices와 distances는 각각 독립 소유 영상이며 선택 색과 거리를 구분해 읽습니다.

결과 판독과 예

영상의 각 픽셀을 D50 Lab으로 변환한 뒤 samples의 모든 기준색과 지정한 ColorDistance로 비교합니다. 가장 짧은 거리의 표본 인덱스와 그 거리를 각각 GrayF64 영상으로 반환합니다.

예를 들어 Cie76에서 픽셀이 첫 표본과 같다면 거리는 0이고 그 표본이 선택됩니다. 거리가 같은 경우 구현은 먼저 나온 표본을 유지하므로 samples의 순서를 결과와 함께 보존하십시오. 빈 표본 목록은 오류이며 0번 표본을 자동으로 만들어 쓰지 않습니다.

indices와 distances는 서로 다른 값을 담는 독립 소유 영상입니다. 두 영상을 같은 좌표에서 읽어 어떤 기준색이 선택됐는지와 얼마나 떨어졌는지를 구분해야 합니다. 반환 형식은 인덱스 영상도 GrayF64이므로 정수 영상이라고 가정하지 마십시오.

항목확인할 내용
samples비어 있지 않은 D50 Lab 기준색 목록입니다.
metric비교할 ColorDistance 방식과 설정입니다.
indices선택된 표본의 인덱스를 담은 GrayF64 영상입니다.
distances선택 거리의 GrayF64 영상입니다.
동률동일 거리에서는 먼저 나온 표본을 유지합니다.
소유두 접근자는 독립 소유 영상 핸들을 반환합니다.
