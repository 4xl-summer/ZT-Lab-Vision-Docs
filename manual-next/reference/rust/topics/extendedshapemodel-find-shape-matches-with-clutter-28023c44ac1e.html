pub fn find_shape_matches_with_clutter( &self, source: &ZImage, options: &ShapeClutterOptions, ) -> ZResult<ExtendedMatchResult>

Executes the existing find_shape_matches_with_clutter search variant and preserves its report.

호출 맥락과 결과 해석

ShapeClutterOptions는 형상 검색 설정과 max_clutter_fraction, clutter_weight, diagnostic_radius를 묶습니다. 두 비율은 0부터 1까지, 진단 반경은 최대 128픽셀입니다. 주변의 대응하지 않는 검색 에지를 후보 수락과 점수에 반영합니다. 이 경로는 search.search.subpixel을 허용하지 않으며 검색 마스크를 받지 않습니다.

후보 점수와 주변 에지

source는 검색 영상이고 options는 형상 검색 설정과 clutter 조건을 묶습니다. max_clutter_fraction과 clutter_weight는 0–1 범위이며 diagnostic_radius는 최대 128픽셀입니다. 이 경로는 검색 마스크와 search.search.subpixel을 허용하지 않습니다.

항목확인할 내용
source검색할 ZImage
max_clutter_fraction허용할 혼잡 비율; 0–1
clutter_weight점수 조정 가중치; 0–1
diagnostic_radius주변 진단 반경; 최대 128픽셀

주변의 대응되지 않는 에지를 고려하므로 점수와 후보 수를 기본 검색과 비교할 때 원본과 나머지 옵션을 유지해야 합니다. 반경을 키우면 진단에 포함되는 주변이 달라집니다. ZResult의 오류와 ExtendedMatchResult의 종료 진단을 구분해 확인합니다.
