등록된 정상 영상 학습

images 슬라이스와 선택 마스크, VariationMode, max_samples, max_values를 받아 변동 모델을 학습합니다. 입력 영상들은 비교할 위치가 일치해야 하고 각 한도는 호출의 작업 범위를 결정합니다. 실패는 ZResult의 오류로 반환됩니다.

학습 표본이 실제 정상 편차를 대표하는지 별도 영상으로 확인합니다. 입력 이미지와 마스크는 빌려 전달하며 반환된 모델은 별도 값으로 소유됩니다. 이후 검사에서 정렬 실패를 정상 모델의 변동으로 취급하지 않습니다.

결과와 조건을 함께 읽기

정상으로 간주하는 정렬된 영상 묶음에서 위치별 평균과 변동을 학습합니다. images와 선택 마스크는 빌려 전달하고 성공하면 모델을 별도 값으로 소유합니다. 같은 물체가 프레임마다 다른 위치에 있다면 이동에 따른 경계 차이도 정상 변동에 섞일 수 있으므로 입력을 같은 기준에 맞추어야 합니다. max_samples와 max_values는 표본과 처리 범위를 제한합니다. 학습에 사용한 영상으로만 성능을 판단하지 말고 별도로 준비한 정상 및 변화 영상에서 결과를 확인합니다. 마스크 밖 픽셀이 학습의 전체 대상과 같다고 가정하지 않습니다.
