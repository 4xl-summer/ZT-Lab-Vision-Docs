pub fn execute(&self) -> ZResult<QueryExecution<SurfaceDefectsResult>>

Executes the plan and retains its captures.

실행과 결과

표면 결함 계획을 실행해 SurfaceDefectsResult가 담긴 QueryExecution을 반환합니다. 실행은 캡처한 입력을 유지하며 처리 오류는 ZResult로 전달합니다.

결함 목록과 검사 조건을 함께 해석하십시오. 계획을 만들었다고 계산된 것이 아니며 execute의 반환 결과에서 결함과 오류를 확인해야 합니다.

입력과 결과 확인

SurfaceDefectsQuery::execute는 지연된 표면 결함 계획을 &self로 빌려 실행하고 SurfaceDefectsResult 스냅샷이 담긴 QueryExecution을 반환합니다. 실행은 캡처한 입력을 유지하며 처리에 실패하면 ZResult 오류가 전달됩니다. 계획만 만든 상태와 후보가 계산된 상태는 다릅니다.

결함 목록은 각 연결 성분의 종류, 면적, 위치 및 점수를 함께 읽어야 합니다. 예를 들어 후보가 하나도 없으면 정상적으로 빈 목록일 수 있지만, 실행 오류가 발생해 목록을 얻지 못한 상태를 같은 빈 목록으로 기록하면 진단할 수 없습니다.

위치와 경계는 입력 영상의 ROI 로컬 픽셀 기준을 확인하고 다른 영상의 결함과 비교할 때는 원점을 맞추십시오. 후보 추출 결과와 별도의 허용치 합격 판정도 구분해야 합니다. 캡처한 영상의 소유·참조 방식은 실행 결과의 접근 계약에 따라 관리합니다.

예를 들어 차분 결과에 둘 이상의 연결 영역이 있다면 반환 스냅샷은 각 영역을 별도 후보로 표현할 수 있습니다. 후보가 SCRATCH인지 SURFACE인지와 면적·경계는 개별 항목에서 읽고, 전체 허용치에 따른 판정은 별도 단계에서 확인해야 합니다. 계산된 결함이 0개인 경우와 모델이나 영상이 유효하지 않아 실행에 실패한 경우는 모두 화면에 아무 결함이 보이지 않을 수 있지만 처리 상태가 다릅니다. 실행의 ZResult를 우선 확인하십시오.

결함 판정 기준이 후보 개수, 면적 또는 위치를 제한한다면 추출 결과의 각 필드와 허용치 단위를 맞추어 별도로 판정하십시오. 추출 쿼리의 실행 성공은 검체의 합격을 뜻하지 않습니다.
