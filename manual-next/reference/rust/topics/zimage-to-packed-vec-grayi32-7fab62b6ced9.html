pub fn to_packed_vec_grayi32(&self) -> ZResult<Vec<i32>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<i32>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

조건과 결과 판독

현재 ROI의 GrayI32 픽셀을 행 우선 독립 Vec<i32>로 복사합니다. 한 픽셀에 부호 있는 i32 원소 하나가 있으므로 폭 2, 높이 3인 ROI의 반환 길이는 6입니다. 음수 값의 부호를 유지해 해석해야 합니다.

보이는 행만 복사하므로 원본 행 패딩은 반환 벡터에 들어가지 않습니다. 독립 벡터는 영상을 더 이상 사용하지 않더라도 보관할 수 있습니다. 픽셀 형식이 요청한 GrayI32와 다르면 성공값 대신 오류를 처리하세요.
