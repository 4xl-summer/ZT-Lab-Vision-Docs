pub fn prepare_ai_image( &self, region: ZRect, options: AiPreprocessOptions, ) -> RecognitionEngineResult<(AiTensor, AiImageTransform)>

이 멤버의 추가 계약 설명은 확인되지 않았습니다.

AI 입력 전처리

region과 AiPreprocessOptions를 사용해 AiTensor와 AiImageTransform을 반환합니다. 영상 크기 조절과 채널 설정은 모델이 기대하는 입력과 맞아야 합니다.

반환 transform은 후처리에서 모델 좌표를 원본 영상 좌표로 되돌리는 데 사용합니다. 전처리 설정을 빠뜨린 채 출력 상자에 원점이나 패딩을 임의로 더하지 않습니다.

ROI에서 모델 입력 준비

region ZRect와 AiPreprocessOptions로 영상의 선택 영역을 모델 입력 텐서로 바꾸고 AiTensor와 AiImageTransform을 반환합니다. 준비 결과는 추론의 입력이며 이 호출 자체가 분류나 검출을 수행하는 것은 아닙니다. 모델이 기대하는 크기, 채널 배치와 정규화가 설정과 일치해야 합니다.

항목의미와 사용
region입력에서 선택한 ZRect
options크기·채널·정규화 등의 전처리
AiTensor모델에 전달할 준비 데이터
AiImageTransform모델 좌표를 원본 영역에 대응
후속 단계추론은 별도로 수행
검증원본 위에 복원 좌표를 표시

모델 좌표의 검출 상자를 원본에 표시하려면 반환 transform을 사용해 크기 조절과 패딩, 선택 영역의 관계를 되돌립니다. 예를 들어 입력에 패딩이 있다면 이를 무시하고 단순히 ROI 원점만 더하면 경계가 밀릴 수 있습니다. 준비 오류와 추론 결과가 없는 상황을 구분합니다.
