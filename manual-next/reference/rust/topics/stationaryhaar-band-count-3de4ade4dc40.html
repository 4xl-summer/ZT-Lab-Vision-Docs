pub fn band_count(&self) -> usize

Number of packed bands.

호출과 계산

비감쇠 모델에 저장된 전체 해상도 밴드 수를 반환합니다.

레벨 수를 L이라고 하면 밴드 수는 1+3L입니다. 예를 들어 2레벨이면 7개입니다. 마지막 근사 밴드와 각 레벨의 세부 밴드를 단일 영상 하나로 오해하지 마십시오.
