pub fn severity(&self) -> ZImage

Shares the severity image.

결함 심각도

심각도 영상을 독립 공유 ZImage로 반환합니다. 선택한 모델과 검사 옵션이 이 값에 영향을 주며 위치별 값을 요약하는 mean_severity, max_severity와 구분해야 합니다.

같은 화면 밝기라도 표시 범위가 다르면 원본 수치가 다를 수 있습니다. 값을 비교할 때 원본 픽셀과 검사 조건을 함께 기록합니다.

위치별 심각도와 요약

severity는 변동 검사 결과의 심각도 영상을 ZImage 공유로 반환합니다. 위치별 결과이므로 mean_severity나 max_severity처럼 하나의 숫자로 요약한 값과 구별해야 합니다. 반환 영상은 결과 객체와 별도 소유권을 가지며 저장소 공유는 깊은 픽셀 복사와 다릅니다.

사용할 때의 판독

예를 들어 넓은 정상 영역에 한 픽셀만 큰 심각도를 가진다면 평균은 낮더라도 위치 영상에서 그 지점을 찾을 수 있습니다. 원본 영상과 동일한 ROI 기준으로 severity, 결함 마스크 및 검사 포함 영역을 함께 대조하세요. 표시기의 색 범위를 바꾸면 같은 수치가 다르게 보일 수 있으므로 실제 픽셀 값을 확인합니다.
