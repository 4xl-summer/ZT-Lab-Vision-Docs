pub fn mesh_normals(&self, faces: &[[usize; 3]]) -> ZResult<Normals>

Computes area-weighted mesh vertex normals.

삼각형 메시의 법선

점군의 삼각형 인덱스를 이용해 면 법선을 계산하고 꼭짓점에 면적 가중 기여를 합칩니다. 삼각형의 세 인덱스는 유효 범위의 서로 다른 위치여야 합니다. 꼭짓점이 결측이거나 삼각형이 퇴화하면 해당 면에서 유효한 기여를 만들지 못합니다.

(0,0,0), (1,0,0), (0,1,0)을 이 순서로 연결하면 외적 방향은 +z입니다. 두 꼭짓점의 순서를 바꾸면 방향은 -z가 되므로 메시의 감김 순서를 일관되게 유지해야 합니다. 여러 면의 기여가 합쳐진 꼭짓점 결과는 원본 점 슬롯과 대응합니다.

확인 항목해석
triangle indices서로 다르고 범위 안인 세 인덱스
winding면 법선의 부호를 결정
가중치면적에 비례하는 면 기여
결측·퇴화유효 면 법선 기여 없음
