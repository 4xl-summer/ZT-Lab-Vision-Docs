pub fn find_shape_with_edge_grain( &self, source: &ZImage, options: &ShapeSearchOptions, mask: Option<&ZImage>, min_size: usize, max_size: usize, ) -> ZResult<ExtendedMatchResult>

Executes the existing find_shape_with_edge_grain search variant and preserves its report.

관련 입력의 확인된 조건

Extended shape matching model.

호출 맥락과 결과 해석

검색 영상에서 연결된 에지 구성요소의 크기를 조건으로 삼아 형상 검색을 수행합니다. 학습 단계에서 특징을 거르는 train_with_grain과 달리 이 호출의 min_size와 max_size는 검색 영상의 에지 쪽에 적용됩니다.

작은 잡음과 긴 실제 경계가 섞인 영상이라면 최소 크기를 달리한 두 번의 결과를 비교해 볼 수 있습니다. 최대 크기까지 함께 좁히면 원하는 경계도 조건에서 제외될 수 있으므로 결과 목록과 종료 진단을 함께 살피고, 나머지 옵션은 동일하게 유지해 비교합니다.

검색 에지의 크기

min_size와 max_size는 검색 영상에서 연결된 에지 구성요소의 크기 조건입니다. 학습 모델의 특징을 거르는 설정과 시점을 구분해야 합니다. mask는 선택 입력이고 source는 검색할 영상입니다.

항목확인할 내용
source에지를 찾을 검색 영상
options형상 검색의 공통 조건
mask선택적인 검색 마스크
min_size / max_size검색 에지 성분의 크기 범위

작은 잡음과 긴 물체 경계가 함께 있다면 최소 크기만 바꾼 두 결과를 비교할 수 있습니다. 최대 크기까지 좁히면 필요한 긴 경계도 제외될 수 있으므로 반환 후보와 종료 진단을 함께 읽습니다. 유효하지 않은 범위 또는 검색 오류는 ZResult에서 처리합니다.
