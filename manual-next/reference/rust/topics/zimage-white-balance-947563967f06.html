pub fn white_balance(&self, gains: [f64; 3]) -> ZResult<Self>

Applies white-balance gains using the existing color kernel.

호출에 필요한 입력

색상 화이트 밸런스를 적용합니다.

인자선언된 형식확인할 내용
gains[f64; 3]세 채널 게인

결과와 사용 순서

반환 선언 ZResult<Self>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

색을 비교하거나 보정하기 전 입력 색 공간, 채널 순서와 전달 특성을 확인하세요. 같은 숫자라도 색 공간과 기준 백색점이 다르면 의미가 달라질 수 있습니다. 알려진 색 표본으로 결과를 검증하세요.
