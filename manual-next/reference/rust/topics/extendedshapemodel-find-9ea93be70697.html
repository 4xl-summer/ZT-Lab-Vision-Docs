Extended shape matching model.

호출 맥락과 결과 해석

학습한 확장 형상 모델을 검색 영상 참조와 ShapeSearchOptions 참조를 전달해 후보 포즈를 평가합니다. 검색 격자의 x와 y는 검색 ROI의 로컬 픽셀 좌표이고 각도는 라디안입니다. 모델에서 기준점으로 정한 위치가 검색 포즈를 해석하는 기준이 됩니다.

반환 보고서에서는 매치 목록과 종료 진단을 함께 확인합니다. 후보가 비었다는 사실만으로 대상이 영상에 없다고 결론 내리기보다 검색 범위와 후보 예산, 점수 및 에지 조건을 함께 비교합니다. 결과는 입력 영상과 모델에서 독립된 값입니다.

형상 검색 조건의 조합

ShapeSearchOptions.search에는 위치·각도·축별 배율 격자, 점수·커버리지 조건과 후보 예산이 있습니다. min_gradient는 검색 영상 에지의 기울기 하한이고 pyramid_levels와 retained_candidates는 위치 격자 정밀화에 관계합니다. 실제 축소 영상 피라미드 검색과는 별도 경로입니다.

모델의 각 특징은 기준점 상대 위치와 방향을 갖습니다. 결과 포즈는 이 기준점의 검색 ROI 로컬 위치로 읽고 원본 좌표에는 ROI 원점을 반영합니다. matches가 비면 min_gradient, 마스크, 격자 범위와 termination을 함께 확인하고 빈 결과를 실행 오류와 구분합니다.
