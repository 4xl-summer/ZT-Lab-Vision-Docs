pub fn freeze(&self) -> ZResult<OnlineSnapshot>

Creates an independent snapshot of the current statistics.

사용과 결과 해석

현재 누적 통계를 별도의 결과로 고정합니다. 표본이 하나 이상 있어야 하며 평균과 편차는 GrayF64 영상, 선택 영역은 Gray8 마스크로 반환됩니다. 포함 픽셀은 마스크 255이고 제외 픽셀은 0입니다.

편차는 각 픽셀에서 √(M2 / 표본 수)인 모집단 표준편차입니다. 예를 들어 값 10과 14의 평균은 12, 편차는 2입니다. 마스크 밖 수치를 실제 정상 통계로 해석하지 마십시오.

조건과 결과 판독

누적 샘플이 하나 이상인 온라인 참조의 통계를 독립 OnlineSnapshot으로 고정합니다. 평균과 표준편차 영상은 GrayF64, 선택 마스크는 Gray8이며 포함 위치가 255입니다. 마스크 밖의 값을 실제 정상 통계로 해석하지 않습니다.

표준편차는 각 픽셀의 모집단 값 √(M2/count)입니다. 예를 들어 한 위치에서 10과 14를 누적하면 평균은 12이고 편차는 2입니다. 스냅샷의 count와 평균·편차를 같은 시점의 값으로 기록하고, 이후 참조에 샘플을 더하는 일과 구분하세요.

freeze는 그 시점의 통계를 판독하는 단계입니다. 평균이 같더라도 샘플의 분포가 다르면 편차는 달라질 수 있으므로 평균과 편차를 함께 확인합니다. 이후 참조에 더 많은 샘플을 넣는 경우 새 스냅샷의 count와 이전 count를 기록해 어느 시점의 모델을 검사에 사용했는지 구분하세요.
