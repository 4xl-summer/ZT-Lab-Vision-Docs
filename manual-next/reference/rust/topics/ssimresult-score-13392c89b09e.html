pub fn score(&self) -> f64

Returns the weighted global similarity score.

전체 유사도

구조 유사도 검사에서 계산된 전체 점수를 f64로 반환합니다. 선택 마스크와 창 설정, 데이터 범위가 점수에 영향을 주므로 다른 실행과 비교할 때 같은 설정과 검사 영역인지 확인합니다.

이 값은 해당 입력과 옵션으로 수행한 한 번의 검사 결과입니다.

전체 유사도와 위치별 결과

score는 검사 결과의 전체 구조 유사도 점수를 f64로 반환합니다. 입력 이미지, 기준, 선택 마스크와 창 설정에 따른 값이므로 다른 설정의 점수와 단순히 같은 기준으로 비교하지 않습니다.

included는 검사에 포함된 픽셀 수이고 defect_count는 결함 픽셀 수입니다. 예를 들어 검사 영역이 바뀌면 같은 전체 점수라도 요약한 픽셀 집합이 달라집니다. 두 숫자를 점수와 함께 기록해야 비교 범위를 알 수 있습니다.

전체 점수가 높더라도 국소 변화가 요약값에 가려질 수 있습니다. map에서 위치별 GrayF64 유사도를, defect_mask에서 선택된 결함 위치를 확인합니다. 두 영상은 독립 공유 ZImage이며 입력 및 결과와 각각의 수명을 가집니다.
