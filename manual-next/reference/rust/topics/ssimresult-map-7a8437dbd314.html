pub fn map(&self) -> ZImage

Acquires an independent GrayF64 similarity map share.

유사도 영상 획득

GrayF64 유사도 맵의 독립 영상 공유를 반환합니다. 위치별 수치를 살펴볼 때 전체 점수만으로 드러나지 않는 국소 변화를 확인할 수 있습니다. 반환 영상은 결과와 별도의 소유 수명을 가집니다.

이 값은 해당 입력과 옵션으로 수행한 한 번의 검사 결과입니다.

조건과 결과 판독

map은 위치별 구조 유사도 값을 담은 GrayF64 ZImage의 독립 공유를 취득합니다. 전체 score는 한 번의 검사에 대한 가중 요약이고 맵은 위치마다 다른 값을 보여 주므로 둘의 역할을 구분합니다.

예를 들어 전체 점수가 비슷한 두 검사라도 낮은 유사도가 집중된 위치는 다를 수 있습니다. 포함 픽셀과 결함 판정은 검사 마스크·옵션 및 defect_mask와 함께 읽습니다. 반환 영상은 소유 ZImage이며 결과 객체의 빌린 슬라이스가 아닙니다.

예를 들어 국소 영역 하나만 달라진 영상에서는 전체 score 하나로 그 변화의 위치를 알기 어렵습니다. map으로 해당 위치의 유사도를 확인하고 defect_mask와 옵션의 판정 결과를 따로 비교하세요. map에서 받은 영상은 공유 소유 값이므로 이 호출의 결과를 빌린 행 참조처럼 취급하지 않습니다.
