각도 범위 복수 판독

MultiBarcodeSpec과 min, max, step 도 단위 각도 범위를 사용해 복수 심볼을 탐색합니다. 결과는 MultiBarcodeReads이며 오류는 RecognitionEngineResult로 전달됩니다.

탐색 범위나 간격이 바뀌면 탐색한 조건이 달라집니다. 읽기 결과의 형식과 회전, 위치, 길이 수락을 범위와 함께 기록하고 미발견을 영상에 심볼이 없다는 증거로 확대하지 않습니다.

사용 순서와 결과 보관

이 메서드는 입력 영상에서 복수 바코드를 판독할 때 min부터 max까지의 유한한 각도 격자를 사용합니다. 각도와 step은 도 단위이며 하한을 포함하고 min+k×step이 max 이하인 각도를 차례로 시도합니다. 각도 범위는 -360도부터 360도까지, step은 유한한 양수이며 시험 각도는 최대 360개입니다.

예를 들어 min=-10, max=10, step=10이면 -10, 0, 10도의 세 방향이 생성됩니다. step=6이면 -10, -4, 2, 8이 사용되고 10은 격자에 정확히 들어가지 않으므로 추가되지 않습니다. 범위와 간격이 바뀌면 실제 검사한 회전 집합도 바뀌므로 결과를 비교할 때 두 설정을 보관해야 합니다.

성공하면 MultiBarcodeReads가 여러 판독 결과를 소유합니다. 각 결과의 형식, 문자열, 위치, 회전과 길이 수락을 함께 확인합니다. 빈 결과는 해당 영상과 시도한 각도·사양에서 결과가 없다는 뜻이며 영상에 코드가 절대로 없다는 증명이 아닙니다. 잘못된 각도나 인식 실패 오류는 정상적인 빈 결과와 구별합니다.
