pub fn convex_shapes( &self, connectivity: Connectivity, ) -> ZResult<ConvexShapeResult>

Finds convex component geometry.

호출과 결과 확인

Gray8 전경을 Connectivity로 연결 성분으로 나누어 볼록 껍질과 최소 면적 회전 사각형을 즉시 계산합니다. 대각선으로만 닿은 두 전경 픽셀은 4연결이면 두 성분이고 8연결이면 한 성분입니다. 껍질은 픽셀 셀 외곽이며 좌표는 ROI 로컬입니다. 결과를 읽을 때 입력 영상의 원점과 결과 좌표의 관계를 확인합니다.

결과와 조건을 함께 읽기

전경을 지정 연결성으로 나눈 다음 각 성분의 픽셀 셀 경계로 볼록 껍질과 최소 면적 회전 사각형을 계산합니다. 한 픽셀도 중심점 하나로만 취급하지 않고 셀의 외곽을 사용하므로 껍질 좌표와 사각형의 폭을 픽셀 중심 집합의 폭과 혼동하지 않습니다. 두 전경 픽셀이 대각선으로만 닿으면 4연결에서는 두 성분, 8연결에서는 한 성분입니다. 결과 좌표는 ROI 로컬이므로 서로 다른 ROI의 중심을 비교할 때 원점을 반영합니다. 반환된 독립 결과는 이후 형상 목록을 읽는 데 사용합니다.
