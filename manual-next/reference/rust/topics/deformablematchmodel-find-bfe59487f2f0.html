호출 맥락과 결과 해석

학습할 때 명시한 변형 모델들을 검색 영상에 적용하며 예산과 시간을 공유합니다. options는 확장 NCC 검색 설정이고 mask는 선택 검색 마스크입니다. 변형 하나마다 독립적으로 무제한 검색하는 것으로 해석하지 않습니다.

반환된 독립 보고서에서 변형 인덱스와 매치를 함께 읽습니다. 같은 포즈라도 어느 변형 모델에 해당하는지에 따라 해석이 달라지므로, 학습 때 사용한 deformation 목록과 인덱스 순서를 기록해 둡니다.

공유 예산과 결과의 변형

학습 은행은 명시된 변형 모델들을 입력 순서로 검색합니다. candidate_budget과 timeout은 모델마다 새로 충전되는 값이 아니라 은행 전체에서 공유됩니다. 따라서 예산이나 시간이 먼저 소진되면 뒤에 있는 변형까지 같은 양으로 평가되었다고 가정하면 안 됩니다.

각 결과의 variant_index는 학습 때의 변형 목록을 가리키고 matched는 해당 포즈와 점수를 담습니다. 결과가 없으면 평가 수와 termination을 같이 확인합니다. 검색 마스크의 원점은 options의 mask_offset과 함께 검색 ROI 로컬 좌표로 해석합니다.
