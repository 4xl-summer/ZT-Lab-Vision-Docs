pub fn measure(&self, image: &ZImage) -> ZResult<EllipseMeasurementResult>

Measures the ellipse and returns an independent snapshot.

사용과 결과 판독

검증된 타원 모델을 빌려 입력 ZImage의 ROI에서 관측하고 타원 계측 결과를 반환합니다. 모델의 기준 형상은 탐색 위치를 정하며 반환 형상이 반드시 기준과 같다는 뜻은 아닙니다. 프로브의 발견 상태와 최종 적합에 채택된 점을 구별하고, 형상이 없거나 피팅에 실패한 결과를 좌표 0으로 대체하지 마십시오. 다른 영상에 재사용할 때 ROI 원점과 검색 범위를 함께 확인합니다.

단계확인할 내용
모델타원의 검증된 기준과 설정을 빌립니다.
영상목적 경계가 포함된 ZImage ROI를 전달합니다.
관측발견된 프로브 점과 최종 채택점을 구별합니다.
결과형상 상태와 ROI 좌표 기준을 함께 확인합니다.

기준 타원과 관측 결과

EllipseMeasurementModel은 생성 시 중심, 장·단반축, 각도 범위, ShapeProbeSettings와 RobustFitOptions의 기하·설정을 검증합니다. measure는 이 검증된 모델을 빌려 입력 ZImage에서 타원 경계를 관측하고 독립 EllipseMeasurementResult를 반환합니다. 모델의 기준 타원 자체가 곧 최종 측정값은 아닙니다.

타원의 탐침은 설정된 형상과 탐색 조건에 따라 에지를 찾고 적합 단계는 사용 가능한 관측을 결합합니다. 기준 중심이 ROI 로컬 (5,4)이고 ROI 원점이 (10,20)이면 원본에서 해당 기준 중심은 (15,24)입니다. 측정된 타원 위치를 원본에 표시할 때도 결과의 로컬 좌표계와 원점을 맞춥니다.

에지가 발견된 탐침과 최종 적합에 사용된 탐침을 구분하고 결과의 모델 상태를 먼저 확인합니다. 형상이 없거나 적합 실패인 경우를 중심 (0,0) 같은 숫자로 치환하지 않습니다. 같은 모델을 다른 영상에 재사용할 때는 목적 경계가 ROI와 탐침 범위 안에 있는지 검토합니다.
