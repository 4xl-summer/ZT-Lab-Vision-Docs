사용 순서와 결과 확인

복제본끼리 같은 상태를 공유하는 일회성 취소 토큰을 만듭니다. 초기 상태는 취소되지 않았으며 장시간 광도 검사 실행에 전달할 수 있습니다. 실행 중 취소를 요청하려면 공유 토큰의 cancel을 호출하고, 상태를 읽으려면 is_cancelled를 사용합니다.

사용 조건과 결과 판독

PhotometricCancellation::new는 초기 상태가 취소되지 않은 일회성 협조 취소 토큰을 만듭니다. 토큰을 제어형 연산에 전달하면 연산이 취소 상태를 확인할 수 있고, cancel은 그 상태에 취소 요청을 기록합니다. new 자체는 검사를 시작하거나 이미 실행 중인 작업을 찾는 호출이 아닙니다.

토큰을 clone하면 별도 상태의 새 취소기가 아니라 같은 취소 상태를 공유하는 복제본을 얻습니다. 예를 들어 한 복제본을 작업에 전달하고 다른 복제본에서 cancel하면 공유된 상태가 취소로 표시됩니다. is_cancelled로 상태를 확인할 수 있습니다.

토큰은 일회성이므로 다음 작업에 취소되지 않은 상태가 필요하다면 새 토큰을 만듭니다. 사용한 제어형 API가 반환하는 취소·시간 초과 결과를 각각 처리하고 부분 결과가 있는지 해당 API 계약을 확인하세요. 취소 요청 시점과 작업이 실제로 요청을 확인하는 시점은 동일하다고 가정하지 않습니다.

Rust의 소유 값과 clone은 공유 상태의 수명을 관리합니다. 한 복제본을 스코프에서 놓는 것과 cancel을 호출하는 것은 다른 동작입니다. 실행·토큰을 어떤 흐름이 소유하는지 정해 두면 정상 종료와 사용자 취소를 구분해 처리하기 쉽습니다.

예를 들어 실행을 시작하기 전에 토큰을 하나 만들고, 실행 흐름에는 복제본을 전달하며 제어 흐름은 원래 값을 보유할 수 있습니다. 제어 흐름에서 cancel한 뒤에는 같은 상태를 보는 복제본의 is_cancelled도 취소 상태를 관찰합니다. 취소는 협조적으로 확인되므로 호출한 직후 연산이 즉시 끝났다고 단정하지 말고 연산의 반환을 기다려 결과를 처리하세요.
