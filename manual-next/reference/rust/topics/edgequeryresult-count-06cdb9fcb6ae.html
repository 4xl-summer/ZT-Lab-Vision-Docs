pub fn count(&self) -> usize

Returns the number of selected edges.

사용과 결과 해석

현재 포함 상태인 체인의 개수를 반환합니다. 원래 생성한 전체 수가 아니라 set_included로 제외한 항목을 뺀 값이며, 다시 포함하면 다시 증가합니다. 영구 삭제한 체인은 되돌아오지 않습니다.

예: 세 체인 중 label 2를 제외하면 count는 2이고 포함 인덱스 0과 1은 각각 label 1과 3을 가리킵니다. 인덱스의 의미는 포함 상태 변경 후 다시 확인해야 합니다.

포함 상태에 따른 개수

label 1, 2, 3이 있을 때 2를 제외하면 count는 2입니다. 포함 인덱스 0은 label 1, 인덱스 1은 label 3이 됩니다. 다시 2를 포함하면 count는 3이고 인덱스는 원래 순서대로 다시 조밀하게 매겨집니다.

항목의미와 조건
초기생성한 모든 체인이 포함됩니다.
제외set_included(false)는 개수에서 제외합니다.
복귀같은 label을 다시 포함하면 개수가 증가합니다.
삭제delete는 체인을 영구 제거합니다.
인덱스포함 항목만 원래 순서대로 0부터 셉니다.
label양의 고정 식별자이며 인덱스와 다릅니다.
조회제외된 항목은 get/points 선택에 나타나지 않습니다.
