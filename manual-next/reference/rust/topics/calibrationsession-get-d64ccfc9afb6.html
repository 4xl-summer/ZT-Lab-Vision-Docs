pub fn get( &self, camera: u64, target: u64, pose: u64, ) -> Result<&CalibrationObservation, ZError>

Fetch a single indexed observation without transferring internal ownership.

사용과 결과 판독

세 ID로 관측 하나를 조회하여 세션 내부의 관측을 빌립니다. 내부 소유권을 넘기는 동작이 아니므로 반환 참조를 소유 세션보다 오래 사용할 수 없습니다. 조회의 Result를 확인한 뒤 표적점과 픽셀의 대응 순서를 유지하여 사용합니다. 조회 실패를 빈 관측이나 원점의 대응점으로 치환하지 마십시오.

단계확인할 내용
조회 키카메라·표적·자세 ID를 함께 지정합니다.
반환세션이 소유한 관측을 빌립니다.
점 순서객체점과 영상점의 대응을 보존합니다.
수명참조는 소유 세션보다 오래 사용할 수 없습니다.

세 식별자로 관측 조회

get은 camera, target, pose 세 식별자가 정확히 일치하는 관측을 찾아 &CalibrationObservation으로 빌려 줍니다. 해당 키가 없으면 ZResult 오류입니다. 반환 객체에는 두 점 배열과 세 식별자가 있습니다.

항목판독할 내용
camera / target / pose조회할 관측의 세 식별자
object대상 좌표 점 배열
pixels대응하는 영상 좌표 점 배열
반환세션에서 빌린 관측 또는 오류

object와 pixels의 같은 순번은 대응하는 한 쌍입니다. 예를 들어 object[2]와 pixels[2]를 함께 읽어야 해당 관측의 대응 관계가 유지됩니다. 결과는 세션 내부의 참조이므로 세션보다 오래 사용해야 할 때 필요한 값을 별도로 소유해야 합니다.
