관련 입력의 확인된 조건

Borrowed typed image view with byte stride.

형식과 좌표

GrayF64View의 new는 f64 슬라이스를 빌려 너비, 높이, 행 간격으로 읽기 전용 뷰를 구성합니다. 저장소를 소유하거나 새 픽셀 배열로 복사하지 않습니다.

행 간격 stride는 바이트 단위입니다. 너비 4인 GrayF64View의 한 행에는 4개 f64 성분, 즉 32바이트가 필요합니다. 행 간격이 이보다 클 수 있으므로 행 사이 패딩을 픽셀로 세지 마십시오. 슬라이스 길이와 레이아웃이 맞지 않으면 생성은 오류를 반환합니다.

수명과 후속 처리

GrayF64View는 원본 저장소의 수명에 묶인 뷰입니다. 반환된 참조를 원본 데이터보다 오래 보관할 수 없으며, 값을 다른 소유 객체로 보존하려면 별도의 소유 복사 또는 이미지 공유 계약을 사용해야 합니다. 형식이 다른 뷰로 임의 재해석하지 말고 입력 구성과 성분 순서를 확인하십시오.

좌표 계산 예

예를 들어 너비 4, 높이 3인 GrayF64View을 만들 때 width와 height는 픽셀 수이지만 stride는 바이트 수입니다. 보이는 한 행의 최소 크기는 32바이트이며 입력 슬라이스가 필요한 모든 행을 담아야 합니다. 잘못된 행 간격이나 버퍼 길이를 성공한 뷰로 간주하지 마십시오.
