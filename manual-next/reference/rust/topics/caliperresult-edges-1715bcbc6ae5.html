pub fn edges(&self) -> &[CaliperEdge]

Returns the detected edges.

사용과 결과 판독

검출된 CaliperEdge 배열을 불변 슬라이스로 빌립니다. 각 에지의 ROI 로컬 위치와 시작점에서의 거리, 부호 있는 강도는 서로 다른 정보입니다. 같은 프로파일에서 거리가 2와 7인 두 에지의 진행 방향 간격은 5픽셀입니다. 빈 슬라이스를 오류와 자동으로 동일시하지 말고 호출 자체의 Result와 선택 조건을 확인합니다.

단계확인할 내용
위치선택된 에지의 ROI 로컬 픽셀 좌표입니다.
거리프로파일 시작점부터의 진행 방향 거리입니다.
강도원시 강도/픽셀의 부호 있는 기울기입니다.
빈 목록에지가 없다는 결과와 호출 오류를 구별합니다.

판독과 사용 순서

에지의 position은 ROI 로컬 픽셀 위치이고 distance는 프로파일 시작점에서 그 지점까지의 진행 거리입니다. strength는 부호 있는 강도 기울기이므로 밝기값 자체가 아닙니다. 같은 프로파일에서 두 거리가 2와 7이면 진행 방향 간격은 5픽셀입니다. 시작과 끝을 뒤집으면 첫 번째 에지의 의미와 상승·하강의 부호도 달라질 수 있습니다. 반환 슬라이스는 결과에서 빌리며 빈 배열은 에지 조건을 만족한 항목이 없다는 유효한 결과일 수 있습니다. 생성 호출에서 발생한 오류와 별도로 처리합니다.
