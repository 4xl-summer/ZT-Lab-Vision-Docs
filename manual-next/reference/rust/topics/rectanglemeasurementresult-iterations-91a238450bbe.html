Returns the fit iteration count.

결과 확인 순서

사각형 측정의 결과 객체에서 호출합니다. 적합 계산에서 수행한 반복 횟수를 반환합니다. 횟수가 존재한다는 것과 수렴했다는 것은 별개이므로 수렴 플래그와 상태도 확인하십시오. 같은 결과를 다른 입력과 비교할 때는 프로브 관측, 초기 기하와 반복 설정을 같이 보관해야 차이의 원인을 추적할 수 있습니다.

확인 항목사용 기준
대상사각형 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용반복 기록을 수렴 상태와 비교합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

iterations는 사각형 적합이 수행한 반복 수를 나타냅니다. 단순히 반복 횟수가 많다는 이유로 결과가 더 정확하거나 수렴했다고 볼 수 없습니다.

같은 이미지에서 강건 적합 옵션을 바꾸었다면 횟수뿐 아니라 converged, 변별 관측과 최종 상태를 함께 기록하십시오. 검출점이 바뀐 경우에는 반복 수의 변화만으로 원인을 분리할 수 없습니다.
