템플릿과 선택적 마스크로 NCC 모델을 학습합니다.

관련 입력의 확인된 조건

학습된 템플릿 상태를 소유하는 매칭 모델입니다.

호출 맥락과 결과 해석

템플릿의 선택 픽셀로 기본 NCC 모델을 학습합니다. 선택 마스크는 템플릿과 크기·원점이 같은 Gray8이며 0인 위치는 제외됩니다. 마스크로 제외한 배경은 모델의 선택 표본에 포함되지 않습니다.

NCC는 선택 표본의 밝기 변화를 비교하므로 분산이 없는 템플릿이나 검색 패치에서는 정상적인 상관 점수를 만들 수 없습니다. 선택 영역에 무늬가 충분한지 확인하고, 생성된 모델을 find에 전달합니다. 모델은 스코프가 끝나면 정리됩니다.

결과와 조건을 함께 읽기

NCC 모델은 선택된 템플릿 픽셀의 강도 패턴을 검색 패치와 비교하도록 학습합니다. 마스크는 동일 크기·원점의 Gray8이며 0인 위치는 선택에서 빠집니다. 예를 들어 대상 주위의 변하는 배경을 마스크로 제외하면 그 배경은 모델의 선택 표본에 포함되지 않습니다. 정규화 상관은 선택한 값의 변화가 없을 때 분산을 이용한 비교가 퇴화하므로 무늬가 없는 단색 부분만 선택하지 않도록 학습 입력을 확인합니다. 학습 성공과 검색 결과 존재는 별개이며, 모델을 검색 영상에 적용한 보고서를 따로 판독합니다.
