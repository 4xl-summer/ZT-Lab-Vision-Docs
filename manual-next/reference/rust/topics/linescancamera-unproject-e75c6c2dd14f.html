pub fn unproject(&self, p: Point2) -> Result<Point2, ZError>

Map a cross-scan pixel and scan line back to the moving object plane.

계산 순서와 결과 확인

가로 스캔 픽셀과 행을 이동 물체 평면 좌표로 되돌립니다. x=(pixel−center_pixel)/pixels_per_unit, y=origin_y+(line−origin_line)×distance_per_line입니다. 스케일은 양수이고 행당 거리는 0이 아니어야 합니다. project 결과를 다시 넣어 같은 평면 점으로 돌아오는지 확인할 수 있습니다.
