pub fn execute(&self) -> ZResult<QueryExecution<Statistics>>

Executes and returns statistics.

결과 해석과 수명

준비된 통계 계획을 실행해 QueryExecution에 Statistics 값을 반환합니다. 계획 생성 단계에서는 계산이 아직 완료된 것이 아닙니다. 실행 결과를 읽고 오류는 ZResult로 처리하며 사용한 ROI와 입력 영상을 함께 기록해야 통계가 어떤 영역에서 계산되었는지 재현할 수 있습니다.

사용 조건과 결과 판독

StatisticsQuery::execute는 준비된 Gray8 통계 계획을 실행해 QueryExecution<Statistics>를 ZResult로 돌려줍니다. 계획을 만드는 시점과 실제 픽셀을 읽어 실행하는 시점은 구분해야 합니다. 입력 형식이나 실행에 문제가 생기면 성공한 빈 통계가 아니라 오류 경로를 처리합니다.

실행의 output()은 캐시된 Statistics에 대한 참조를 반환하므로 실행 객체가 살아 있는 동안 읽어야 합니다. Statistics는 count, min, max, mean, variance를 담는 복사 가능한 값입니다. 필요한 값을 실행보다 오래 보관하려면 참조만 남기지 말고 값을 복사해 둡니다.

variance는 평균에서의 제곱 편차를 count로 나눈 모집단 분산입니다. 예를 들어 Gray8 픽셀 [0,10,20]의 count는 3, mean은 10, variance는 (100+0+100)/3입니다. 표본 분산처럼 count−1로 나누면 다른 값이 됩니다.

이름 붙인 캡처가 계획에 있다면 get_image로 독립 ZImage 공유를 별도 취득할 수 있습니다. 반환 통계 참조와 영상 공유의 수명은 다릅니다. 어떤 ROI의 픽셀을 집계했는지 입력 영상과 원점을 함께 기록해야 다른 실행과 공정하게 비교할 수 있습니다.
