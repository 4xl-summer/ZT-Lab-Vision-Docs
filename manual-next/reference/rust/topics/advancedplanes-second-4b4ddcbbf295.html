사용과 결과 해석

두 번째 색 성분 평면을 별도 소유 영상으로 얻습니다. Lab에서는 a, LCH에서는 C 채도이며 결과는 GrayF64입니다. 의미는 변환 시 선택한 색 공간에 따라 달라집니다.

예를 들어 Lab의 a는 LCH의 C와 같은 값이 아닙니다. 성분 영상의 픽셀을 해석할 때 사용한 색 공간과 백색점을 함께 유지하십시오.

색 평면의 두 번째 채널

second는 고급 색 평면의 두 번째 채널을 독립 공유 ZImage로 얻습니다. Lab과 LCH는 두 번째 채널의 의미가 다르므로 변환 시 선택한 색 공간을 결과와 함께 확인합니다.

Lab에서는 두 번째가 a 색축이고 LCH에서는 채도 C입니다. 예를 들어 Lab의 a=3, b=4는 색축 원점에서 채도 크기 5에 대응하지만 a만 5라고 읽으면 안 됩니다. 백색점과 입력 전달 함수도 값의 해석에 중요합니다.

반환 영상은 평면 결과와 별도 소유입니다. 입력 및 다른 채널과 원점이 대응하는지 확인하고, 사용이 끝난 영상과 평면 결과의 수명을 각각 관리합니다. 화면 밝기 범위와 실제 채널 수치를 구별합니다.

LCH의 C는 a와 b의 크기이므로 동일한 L이라도 색축 좌표가 바뀌면 C가 달라집니다. Lab의 두 번째 평면 a는 부호를 가질 수 있어 표시용 색상이나 8비트 화면값과 원본 수치를 구별합니다.

색 공간 변환과 채널을 얻은 뒤에는 입력 이미지, 결과 평면 및 획득 채널이 각각 어떤 수명인지 확인합니다. 동일한 두 번째 인덱스라도 공간이 바뀌면 필드의 물리적 해석도 달라집니다.

같은 a 값이라도 b 값과 L 값이 다르면 전체 색 위치는 다릅니다. 따라서 두 번째 평면 하나의 표시로 전체 색상 차이나 최종 분류 결과를 단정하지 않습니다.

채널은 평면 결과에서 독립적으로 공유한 영상입니다. 원본 결과를 더 이상 읽지 않더라도 획득 영상은 그 소유 기간 동안 관리해야 하고, 필요가 끝나면 각각 해제합니다.

입력이 LCH인지 Lab인지는 이 채널의 이름만으로 알 수 없으므로 평면 결과의 색 공간 정보를 함께 확인합니다. 다른 공간에서 얻은 두 배열의 수치를 같은 기준으로 직접 빼지 않습니다. 실제 비교 전 두 데이터의 백색점과 전달 함수도 기록합니다.
