학습 방식 확인

현재 모델이 사용한 FontTrainingAlgorithm 값을 반환합니다. 결과를 재현할 때 훈련 샘플과 분할 옵션뿐 아니라 알고리즘도 함께 보관합니다.

알고리즘이 같다는 사실만으로 서로 다른 샘플에서 학습된 모델이 같은 결과를 낸다고 가정하지 않습니다. 실제 판독 결과의 글자별 수락과 유사도를 별도로 확인합니다.

폰트 학습 방식

algorithm은 모델의 FontTrainingAlgorithm을 값으로 반환합니다. NearestExample과 ClassMean은 학습 예제를 사용하는 방식이 다르므로 모델 비교 시 사용한 방식을 보관해야 합니다.

예를 들어 같은 문자 라벨에 여러 인쇄 모양이 있다면 학습에 사용한 샘플과 분할 셀이 무엇인지도 함께 확인합니다. 알고리즘 이름이 같다는 사실만으로 서로 다른 데이터에서 학습한 두 모델이 같은 출력을 낸다는 보장은 없습니다.

판독은 read에서 입력 영상과 옵션을 사용해 별도로 실행합니다. 각 글자의 점수는 이진 템플릿 유사도이며 보정된 정확도 확률이 아닙니다. 반환된 알고리즘 값과 모델의 소유 수명은 구분합니다.

NearestExample은 예제와의 비교를, ClassMean은 클래스 대표 형태를 사용하는 방식입니다. 서로 다른 샘플을 쓰면 같은 알고리즘이라도 학습된 내용이 달라질 수 있습니다.

판독이 기대와 다르면 라벨, 셀 분할 및 입력 임계값을 차례로 살핍니다. 학습 샘플의 정답률만으로 새 영상의 오류율을 추정하지 않고 독립 샘플에서 확인합니다.

학습 표본은 라벨과 영상의 글자 셀을 짝지은 자료입니다. 잘못된 라벨이나 인접 문자까지 포함한 셀은 선택한 알고리즘이 무엇이든 결과 해석에 영향을 줄 수 있습니다.

알고리즘 필드는 모델의 설정을 알려 줄 뿐 각 문자 판독의 결과가 아닙니다. 실제 입력에 대한 글자별 점수와 수락 여부는 read 결과에서 확인합니다.

문자 판독 오류를 분석할 때는 입력의 이진화와 셀 경계가 학습 샘플의 형태와 대응하는지 살펴봅니다. 같은 방식의 모델이라도 다른 허용 문자나 점수 기준으로 실행하면 반환된 수락 여부가 달라질 수 있으므로 모델과 실행 옵션을 함께 기록합니다.
