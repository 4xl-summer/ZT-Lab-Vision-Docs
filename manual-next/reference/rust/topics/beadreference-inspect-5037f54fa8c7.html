pub fn inspect( &self, image: &ZImage, width_tolerance: f64, center_tolerance: f64, ) -> ZResult<BeadReferenceResult>

Inspects a source image against this model.

기준과 입력 비교

현재 기준 모델과 검사 영상을 width_tolerance 및 center_tolerance로 비교하고 BeadReferenceResult를 반환합니다. 입력 영상이 기준 경로와 같은 로컬 좌표를 가리키는지 확인합니다.

폭과 중심의 편차는 다른 측정이며 하나의 합격 값만으로 어느 쪽이 벗어났는지 알 수 없습니다. 결과의 탐침 및 위반 구간과 사용한 허용치를 함께 기록합니다.

기준 경로와 허용차

inspect는 학습된 BeadReference와 검사 영상을 비교하고 BeadReferenceResult를 반환합니다. width_tolerance와 center_tolerance는 각각 폭과 중심 편차를 판단하는 설정입니다. 두 허용차는 유한한 비음수로 준비하고, 검사 영상과 기준 경로가 같은 로컬 좌표 의미를 갖는지 확인합니다.

기준의 각 탐침은 폭과 중심을 갖고 결과는 검사값과의 관계를 탐침 순서로 보관합니다. 예를 들어 기준 폭이 10이고 검사 폭이 12라면 폭 차이의 크기는 2입니다. 이 차이를 width_tolerance와 비교하는 문제와 중심 이동을 center_tolerance와 비교하는 문제를 구분합니다.

결과의 inspection, width_errors, reference_flags, reference_failures와 reference_runs를 함께 읽으면 개별 위치와 연속 위반 구간을 연결할 수 있습니다. 전체 결과 하나만 보지 말고 누락된 관측과 기준 위반 상태를 구분하고, 사용한 입력·허용차·기준 모델 버전을 함께 기록합니다.

판독과 확인 사례

폭 오차는 검사 폭에서 학습된 기준 폭을 뺀 값으로 저장되며 측정 폭이 없으면 선택적 값이 비어 있을 수 있습니다. 부호는 차이의 방향을 설명하고, 허용치 판정에는 크기를 비교합니다. 탐침을 제외한 설정이 있다면 경로 순서와 포함 여부도 함께 확인합니다.

reference_flags는 원래 탐침 플래그에 기준 폭 위반 비트 8과 중심 위반 비트 16을 반영합니다. 포함된 탐침의 위반을 세고, 설정된 최소 연속 실패 수를 만족하는 구간을 reference_runs로 제공합니다. 한 탐침의 단일 값만으로 전체 경로 상태를 대체하지 않습니다.
