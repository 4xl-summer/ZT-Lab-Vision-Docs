사용과 결과 해석

tx와 ty를 각각 x와 y 방향 이동량으로 하는 변환을 만듭니다. 좌표의 단위는 입력 점의 단위와 같으며 계수는 [1,0,tx,0,1,ty]입니다. 유한하지 않은 값은 오류입니다.

예: 이동량 (3,-2)는 점 (1,5)를 (4,3)으로 바꿉니다. 좌표계가 픽셀이면 이동량도 픽셀이고, 물리 단위의 점이면 같은 물리 단위를 사용해야 합니다.

좌표계산
x′a × x + b × y + tx
y′c × x + d × y + ty

이동의 계산

예를 들어 (3,-2) 이동은 (1,5)를 (4,3)으로 옮깁니다. 이어서 역이동 (-3,2)을 적용하면 원래 (1,5)가 됩니다. 원본이 ROI 로컬 좌표라면 이동 역시 같은 로컬 좌표계에서 해석하십시오.

항목내용
입력원본 점 (x,y)
이동량tx와 ty를 각각 더합니다.
출력 xx + tx
출력 yy + ty
역방향이동량의 부호를 바꿉니다.
단위입력 좌표와 같은 단위입니다.
