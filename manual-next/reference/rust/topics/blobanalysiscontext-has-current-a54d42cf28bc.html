pub fn has_current(&self) -> bool

Reports whether a current result exists.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언은 bool입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

분석 설정과 현재 결과를 관리하는 컨텍스트입니다. 연결 방식이 달라지면 새 설정에 대해 다시 계산해야 합니다. 인덱스 모드는 현재 결과의 조회 방식만 바꾸며 재계산하지 않습니다. 계산 실패 시 현재 결과가 지워질 수 있습니다.

현재 결과가 있는지 확인

has_current는 컨텍스트에 현재 블롭 결과가 저장되어 있는지 bool로 나타냅니다. 결과가 있는지와 기하 설정이 마지막 결과 이후 바뀌었는지는 별도이므로 dirty도 함께 읽어야 합니다. true라는 숫자 하나만으로 새 설정에 대한 계산이 끝났다고 판단하지 마세요.

단계 또는 항목확인할 내용

계산 실패현재 결과가 없음

결과를 사용할 때

calculate는 계산을 시작하며 이전 현재 결과를 버리고 성공하면 새로운 결과를 보관합니다. 오류가 나면 현재 결과가 없습니다. 반면 이전에 반환된 독립 스냅샷은 별도 값입니다. 후속 get은 현재 결과를 대상으로 하므로 has_current와 오류를 확인한 뒤 호출합니다.
