pub fn fit(points: &[Point2], inlier_threshold: f64) -> Result<LineFit, ZError>

Fits a line to points using the existing robust threshold in coordinate units.

사용과 결과 해석

점 집합에 직선을 맞추고 기준 점, 방향 및 적합 통계가 든 LineFit을 반환합니다. inlier_threshold는 입력 좌표와 같은 단위의 강건 적합 문턱입니다. 점의 기하가 직선을 결정하기에 부족하거나 유효하지 않으면 오류입니다.

예를 들어 픽셀 좌표 점을 입력하면 문턱과 오차 통계도 픽셀 단위로 해석합니다. 반환된 직선은 무한 직선이며 샘플의 양 끝을 자동으로 선분 경계로 삼지 않습니다.

입력과 결과 해석

예를 들어 (0,1), (1,1), (2,1)은 y=1 직선 위에 있으므로 이상적인 잔차는 0입니다. 픽셀 좌표를 넣었다면 거리 문턱과 오차도 픽셀입니다. 반환 직선은 표본의 첫 점과 마지막 점으로 제한된 선분이 아닙니다.

항목의미와 조건
points적합할 2차원 점 집합
inlier_threshold입력 좌표 단위의 강건 적합 문턱
point적합된 무한 직선 위의 기준점
direction적합된 직선 방향
count / inliers입력과 유효점의 수
rms_error적합 잔차의 RMS
max_error최대 잔차
