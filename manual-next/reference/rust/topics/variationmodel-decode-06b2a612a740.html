pub fn decode( template: &ZImage, bytes: &[u8], max_bytes: usize, max_pixels: usize, ) -> ZResult<Self>

Restores a model using an image-format and geometry template.

모델 복원

template 영상과 직렬화 바이트, max_bytes 및 max_pixels 한도를 받아 모델을 복원합니다. template은 모델이 사용할 영상 형식과 기하의 기준입니다. 실패는 ZResult 오류입니다.

입력 바이트가 호출 한도를 만족하고 template의 크기·원점이 사용할 영상과 맞는지 확인합니다. 복원된 모델은 소유 값이며 원본 바이트 슬라이스에 대한 장기 참조로 해석하지 않습니다.

직렬화된 모델 복원

decode는 template 영상과 bytes, max_bytes, max_pixels를 받아 VariationModel을 복원합니다. template은 영상 형식과 기하의 기준이며 두 한도는 복원에 허용할 바이트와 픽셀 수를 제한합니다. 이미지 픽셀 버퍼를 직렬화 모델로 임의 대체할 수 없습니다.

항목확인할 내용
template형식과 크기의 기준 ZImage
bytes직렬화된 모델 데이터
max_bytes허용 바이트 한도
max_pixels허용 픽셀 한도

복원 후 sample_count와 모델의 평균·편차 정보를 확인하고 inspect에 별도 영상과 옵션을 제공해 결과를 대조합니다. 복원 자체는 검사를 실행하지 않습니다. 손상되거나 템플릿과 맞지 않는 데이터 및 한도 위반은 ZResult 오류로 처리합니다.
