pub fn fit( points: &[Point2], inlier_threshold: f64, ) -> Result<CircleFit, ZError>

Fits a circle to points using the existing robust threshold in coordinate units.

사용과 결과 해석

점 집합에 원을 맞추고 중심, 반지름과 적합 통계를 반환합니다. inlier_threshold는 입력 점과 같은 좌표 단위의 강건 적합 문턱입니다. 점이 충분한 원을 결정하지 못하거나 유효하지 않으면 오류입니다.

픽셀 좌표 점을 입력했다면 반지름과 잔차도 픽셀로 해석합니다. 정상 원의 일부만 보이는 경우 중심과 반지름의 불확실성이 커질 수 있으므로 통계와 입력 범위를 함께 확인하십시오.

입력과 반환 결과

반지름 5인 원의 중심이 (0,0)이고 점이 (3,4)이면 중심까지의 거리는 √(3²+4²)=5이므로 해당 점의 반경 잔차는 0입니다. 실제 데이터에서는 점의 분포와 잔차를 함께 확인하고 입력이 픽셀이면 반지름과 거리도 픽셀로 해석하십시오.

항목의미

count입력 점 수
