pub fn histogram(&self) -> ZResult<HistogramResult>

Returns the legacy Gray8 histogram as an immutable channel snapshot.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<HistogramResult>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

이 기본 호출은 Gray8 ROI의 히스토그램을 계산합니다. 빈 범위나 마스크를 지정하는 인자는 이 선언에 없습니다.

조건과 결과 판독

이 기본 호출은 현재 Gray8 ROI의 밝기 히스토그램을 불변 채널 스냅샷으로 반환합니다. 0~255 밝기의 256개 빈을 세며 빈 인덱스는 밝기 값에 대응합니다. 예를 들어 값 0과 255가 각 한 픽셀인 ROI라면 두 빈에 각각 1이 더해집니다.

이 호출에는 마스크나 사용자 빈 범위 인자가 없습니다. 범위와 빈 수를 지정하려면 별도 histogram_with 경로를 사용하세요. 반환 HistogramResult는 값 스냅샷이고 실행 오류는 빈 히스토그램과 구분합니다.
