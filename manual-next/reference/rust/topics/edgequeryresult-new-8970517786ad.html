Constructs a bounded edge query from existing chains.

사용과 결과 해석

기존 서브픽셀 체인을 복사하여 결과를 만듭니다. flags는 크기, 닫힘, 첫 점, 경계 중 계산할 정보를 선택하며 기울기는 별도 계산합니다. 각 체인은 비어 있지 않고 좌표가 유한해야 합니다. budget은 8 × (체인 수 + 전체 점 수) 이상이어야 하고 체인 100,000개, 점 1,000,000개를 넘길 수 없습니다. 실패하면 결과 객체를 돌려주지 않습니다.

예: 두 체인에 각각 3점과 4점이 있으면 최소 작업 예산은 8 × (2 + 7) = 72입니다. 생성된 양의 label은 원래 순서대로 1부터 부여되며 이후 선택 인덱스와 구분합니다.

생성할 때 확인할 조건

체인이 2개이고 각각 3점, 4점이면 작업량은 8×(2+7)=72입니다. 이보다 작은 예산은 오류입니다. 기울기 크기와 각도는 생성 시 지원되는 기하 플래그가 아니며 프레임 결합 후 별도로 계산합니다.
