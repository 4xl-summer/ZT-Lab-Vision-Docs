pub fn new(entries: Vec<FeatureCollectionEntry>) -> Self

Creates an explicit ordered collection; the engine validates limits on execution.

호출과 결과 해석

FeatureCollectionEntry 벡터를 받아 순서가 있는 특징 모델 컬렉션을 만듭니다. 이 생성 단계는 검색을 수행하지 않으며 엔진은 실행 시 제한을 검증합니다. 항목의 모델 id와 모델별 옵션을 보존해 find 보고서의 결과를 원래 항목과 연결합니다.

조건과 결과 판독

FeatureCollectionEntry 벡터에 있는 항목을 전달한 순서대로 보유하는 컬렉션을 만듭니다. 각 항목은 호출자가 정한 id, 학습된 FeatureModel, 모델별 FeatureMatchOptions 및 최소 인라이어 수·비율을 담습니다. 모델 id는 결과를 입력 항목에 연결할 때 사용합니다.

new 자체는 영상 검색이나 엔진 한도 검사를 실행하지 않습니다. 검색 단계에서는 영상과 선택적 마스크 및 컬렉션 옵션을 별도로 전달하고, 엔진은 실행 시 제한을 검증합니다. 두 모델이 같은 영상에 매치되더라도 각각 어떤 id와 옵션을 사용했는지 구분해야 합니다.

예를 들어 두 항목을 서로 다른 id로 준비하면 검색 후 결과가 어느 모델의 것인지 구분할 수 있습니다. 두 항목의 모델별 옵션과 최소 인라이어 요구값은 각각에 속하므로 결과를 비교할 때 동일했다고 가정하지 않습니다. 컬렉션 생성과 영상 검색, 결과 보고 판독은 순서가 다른 세 단계입니다.
