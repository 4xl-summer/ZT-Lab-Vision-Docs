pub fn gap_stats( &self, world: Option<[[f64; 3]; 2]>, world_maps: Option<(&ZImage, &ZImage)>, maximum: f64, max_work: usize, ) -> ZResult<BeadGapStats>

Calculates gap statistics in pixel or optional mapped world coordinates.

사용과 결과 해석

비드 검사 결과의 누락 길이와 전체 경로 대비 비율을 계산합니다. world는 선택적 2×3 아핀 변환, world_maps는 선택적 X/Y 세계 좌표 맵이며 maximum은 허용 비율입니다.

보정이 없으면 픽셀, 보정이 있으면 세계 단위 길이이며 비율은 무차원입니다. 변환된 구간은 끝점 사이 현 길이로 계산되므로 비선형 맵의 곡선 호 길이와 구분하십시오.

경로 길이와 누락 비율

검사된 비드 경로에서 포함 길이와 누락 길이를 계산하고 전체 경로 대비 누락 비율을 maximum과 비교합니다. 보정이 없으면 픽셀 길이를 사용하며, 선택적으로 2×3 아핀 변환이나 X/Y 세계 좌표 맵 쌍을 제공할 수 있습니다. max_work는 탐침 방문 작업 상한입니다.

예를 들어 전체 경로 길이 20 중 누락이 2이면 누락 비율은 2/20=0.1입니다. 길이는 선택된 좌표계의 단위지만 비율은 무차원입니다. 맵을 사용할 때 구간은 변환된 양 끝점 사이 거리로 계산하므로 비선형 변환 아래 곡선의 실제 호 길이와 구분하십시오.
