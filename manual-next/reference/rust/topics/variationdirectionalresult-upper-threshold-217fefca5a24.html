pub fn upper_threshold(&self) -> ZImage

Acquires the upper threshold image.

밝은 허용 상한

밝은 방향의 상한 영상을 독립 공유 ZImage로 획득합니다. 동일한 기준 픽셀과 옵션에서 계산된 하한 영상과 짝지어 검사 범위를 읽습니다.

반환 영상은 결과에서 별도로 공유한 소유 ZImage입니다. 입력과 같은 ROI 좌표를 사용하는지 확인하고, 각 영상의 수명을 Rust 소유 관계에 따라 관리합니다.

밝은 방향 상한 영상

upper_threshold는 밝은 방향의 허용 상한 영상을 독립 공유 ZImage로 반환합니다. 동일 위치의 입력값과 상한을 비교할 수 있으며 lower_threshold는 어두운 방향의 별도 경계입니다.

예를 들어 어떤 픽셀의 상한이 120이고 입력이 130이라면 상한보다 10 높은 값입니다. 실제 마스크 결과는 검사 옵션과 유효 영역을 포함한 연산 결과로 확인해야 하며 이 단순 예만으로 전체 판정을 대신하지 않습니다.

반환 영상은 결과와 별도 소유 공유입니다. brighter_mask 및 darker_mask의 같은 좌표를 읽고 입력, 모델, ROI 원점을 맞춥니다. 영상의 화면 밝기와 원본 수치도 구분합니다.

하한과 상한은 각 위치의 모델 기준과 편차, 방향별 허용치에서 계산된 영상입니다. 한 위치의 상한이 다른 위치에도 같은 값이라고 가정하지 말고 해당 픽셀을 읽습니다.

입력값이 상한을 넘는 정도와 brighter_mask의 전경 여부는 관련되지만 서로 다른 출력입니다. 수치 분석과 이진 후보 추출에서 사용할 자료를 구분하고 결과 영상의 원점을 유지합니다.

상한과 brighter_mask를 비교할 때 표시된 영상의 색 범위가 자동 조정되면 값의 크기를 오해할 수 있습니다. 실제 픽셀 값과 해당 위치의 마스크를 함께 확인합니다.

밝기 변화가 전체 조명 변화에서 왔는지 국소 결함에서 왔는지는 입력 준비와 모델이 다루는 문제입니다. 상한 영상 자체가 조명 보정이나 기하 정렬을 대신하지는 않습니다.

검사에 포함되지 않은 위치를 상한 이내의 정상 표본으로 자동 취급하지 않습니다. 사용한 마스크와 입력 기하를 확인하고 상한 값의 실제 수치 및 방향별 결과를 같은 프레임에 연결합니다. 화면에서 보이는 회색 수준은 표시 범위에 따라 달라질 수 있습니다.
