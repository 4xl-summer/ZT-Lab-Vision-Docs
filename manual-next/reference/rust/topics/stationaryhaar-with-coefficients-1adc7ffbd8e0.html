pub fn with_coefficients(&self, values: &[f64]) -> ZResult<Self>

Returns a transform with validated replacement coefficients.

호출과 계산

지정한 계수로 새 독립 변환 모델을 만듭니다. values의 길이는 현재 계수 길이와 같아야 하고 모든 값이 유한해야 하며, 기존 모델은 변경되지 않습니다.

예를 들어 현재 계수가 16개라면 교체 배열도 16개가 필요합니다. 길이가 15개이거나 NaN이 포함되면 유효한 교체 결과 대신 오류를 처리해야 합니다.

결과 해석

계수는 비감쇠 변환의 전체 해상도 밴드의 원래 순서를 유지해야 합니다. 유효한 길이만 맞췄다고 다른 밴드 순서의 값이 같은 의미가 되는 것은 아닙니다. 새 모델을 역변환해 처리 효과를 확인하십시오.

이 설명은 Stationary Haar의 with_coefficients 호출에 적용됩니다. Rust의 참조는 소유 모델보다 오래 살 수 없습니다.
