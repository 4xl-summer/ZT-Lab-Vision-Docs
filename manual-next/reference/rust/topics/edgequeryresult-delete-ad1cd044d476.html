pub fn delete(&mut self, label: u64) -> ZResult<()>

Deletes an edge by stable label.

사용과 결과 해석

지정 label의 체인을 결과에서 영구적으로 제거합니다. 단순히 선택에서 제외하는 set_included(false)와 달리 이후 같은 label을 재포함할 수 없습니다. 존재하지 않는 label은 오류입니다.

삭제 후 포함 개수와 밀집 인덱스가 달라질 수 있습니다. 이전 인덱스를 저장해 두었다면 다시 조회하고, 안정적인 다른 label을 사용해 남은 체인을 식별하십시오.

제외와 삭제 비교

label 2를 삭제하면 1과 3은 계속 같은 label로 식별되지만, 포함 인덱스는 0과 1이 됩니다. 일시적인 필터링이 목적이라면 포함 상태를 변경하고, 복구할 필요가 없는 경우에 삭제를 사용하십시오.
