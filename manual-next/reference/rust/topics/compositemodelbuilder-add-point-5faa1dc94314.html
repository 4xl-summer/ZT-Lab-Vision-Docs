Rust
pub fn add_point( &mut self, id: u64, frame: Option<usize>, value: Point2, ) -> ZResult<usize>

Adds a fixed point.

사용과 결과 해석

id, 선택적 프레임 인덱스와 Point2 값으로 고정 점 특징을 추가하고 특징 목록 인덱스를 반환합니다. 프레임을 지정하면 기존 프레임을 참조해야 하며 그래프 검증을 통과해야 추가됩니다.

id는 특징을 식별하는 값이고 반환 인덱스는 후속 파생 특징이 기존 특징을 참조하는 위치입니다. 서로 다른 역할을 혼동하지 말고 저장하십시오.

고정점과 참조 인덱스

add_point는 식별자 id, 선택적 기존 프레임 인덱스와 Point2 좌표를 받아 고정 점을 그래프에 추가합니다. 성공 반환값은 추가된 특징의 목록 인덱스입니다. 사용자가 붙인 id와 다른 특징이 참조할 목록 인덱스는 역할이 다릅니다.

단계 또는 항목확인할 내용
id사용자가 지정한 특징 식별자
frame없음 또는 기존 프레임 인덱스
value프레임 기준 Point2 좌표
반환추가된 특징의 목록 인덱스
후속 참조반환 인덱스를 사용
검증잘못된 프레임·그래프 조건은 오류

결과를 사용할 때

예를 들어 점에 id 100을 지정하더라도 반환된 인덱스가 100이라고 가정하면 안 됩니다. 반환 인덱스를 보관해 후속 특징이 해당 점을 참조할 때 사용하세요. frame을 지정한다면 이미 등록된 올바른 프레임을 참조해야 하며 좌표는 그 프레임과 같은 단위 및 방향으로 해석합니다.
