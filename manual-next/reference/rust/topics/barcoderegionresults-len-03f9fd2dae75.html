pub fn len(&self) -> usize

이 멤버의 추가 계약 설명은 확인되지 않았습니다.

결과 개수

결과 항목 수를 usize로 반환합니다. 예를 들어 길이가 2면 유효한 인덱스는 0과 1이며 2는 범위 밖입니다.

이 컬렉션은 결과를 소유하고 get과 iter가 돌려주는 뷰는 그 컬렉션을 빌립니다. 뷰에서 얻은 참조는 소유 컬렉션보다 오래 사용할 수 없습니다.

결과 개수와 접근

len은 저장된 영역별 결과의 개수를 usize로 반환합니다. 예를 들어 2이면 0과 1이 유효한 인덱스이고 2는 범위 밖입니다. 이 수는 판독 결과 항목의 수이며 코드 텍스트 길이나 입력 영상의 픽셀 수가 아닙니다.

각 영역의 read에서 상태를 확인해야 하며 결과 두 항목이 모두 수락되었다는 뜻은 아닙니다. 영역별 판독은 서로 다른 ROI나 조건에서 나올 수 있으므로 region과 length_accepted도 같이 읽습니다.

결과의 개수가 0이면 이 컬렉션에 항목이 없음을 뜻합니다. 이를 모든 가능한 영상 영역에서 바코드가 존재하지 않는다는 보장으로 해석하지 않습니다. 입력 조건과 탐색 결과를 같은 실행 기록으로 보관합니다.

BarcodeRegionResults가 결과를 소유하며, 이 컬렉션이 돌려주는 뷰는 원본을 빌립니다. 필요한 데이터를 원본보다 오래 보관한다면 호출자가 소유 값으로 복사합니다.
