pub fn inspected_count(&self) -> usize

Number of inspected pixels.

검사 픽셀 수

실제로 검사한 픽셀 수를 usize로 반환합니다. 마스크나 입력 영역이 달라지면 평균 수치가 같더라도 집계 대상이 다를 수 있습니다.

검사에 포함된 수와 결함 픽셀 수는 서로 다른 통계입니다. 예를 들어 100픽셀을 검사하고 3픽셀이 결함이면 두 숫자를 각각 기록합니다.

결과와 조건을 함께 읽기

이 값은 검사에 포함되어 실제 판정한 픽셀의 수입니다. 학습이나 검사에서 제외된 영역을 포함한 영상 전체 픽셀 수와 같다고 가정하지 않습니다. 예를 들어 10×10 영상의 80픽셀만 검사하고 4픽셀이 결함이라면 inspected_count는 80이고 defect_count는 4입니다. 비율을 계산할 때 검사 수가 0인지 먼저 확인하고, 4/100과 4/80을 같은 값으로 다루지 않습니다. 결과는 usize 값으로 복사되며 해당 한 번의 검사 조건을 함께 기록해야 다른 실행과 비교할 수 있습니다.
