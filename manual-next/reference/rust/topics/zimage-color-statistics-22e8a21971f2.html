pub fn color_statistics( &self, mask: Option<&ZImage>, ) -> ZResult<ColorStatistics>

Measures color statistics under an optional mask.

색 통계의 영역과 값

Rust의 ZImage 호출은 현재 영상에 이 처리를 적용합니다. 영상의 색 통계를 계산합니다. 평균 같은 요약값은 입력의 색 분포를 하나의 값으로 압축하므로 밝은 부분과 어두운 부분이 섞인 경우 원래의 공간적 배치를 보여 주지 않습니다. 비교하려는 영상이 같은 제품 영역과 조명 조건을 가리키는지 먼저 확인합니다.

현재 영상에서 얻은 결과의 해석에서는 마스크나 ROI를 사용한 경로라면 선택 영역이 달라졌는지도 통계와 함께 살펴봅니다. 값이 달라졌을 때 원본 영상의 분포와 표본 범위를 비교하면 조명 변화와 물체 구성 변화의 가능성을 구별하는 데 도움이 됩니다.

Rust 반환 값의 소유와 참조 수명을 시그니처에서 확인합니다. 입력 오류와 실제 계산된 빈 결과는 서로 다른 경로이므로 오류를 정상 판정으로 바꾸지 않습니다.

조건과 결과 판독

반환 ColorStatistics의 count는 선택된 픽셀 수이며 min, max, mean, std_dev는 정규화된 인코딩 sRGB 채널의 RGB 순서 값입니다. std_dev는 모집단 표준편차입니다. 평균만으로 색이 영상의 어느 위치에 분포하는지는 알 수 없습니다.

mask가 Some이면 Gray8이어야 하며 원본과 폭·높이 및 origin이 같아야 합니다. 마스크의 0이 아닌 위치가 선택되고 선택 픽셀이 없으면 오류입니다. 예를 들어 두 영상을 비교할 때 마스크 영역이나 ROI 원점이 달라졌다면 통계 차이를 먼저 영역 차이와 구분하세요.
