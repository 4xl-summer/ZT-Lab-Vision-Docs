pub fn sample_count(&self) -> usize

Returns the count of trained samples.

반환값과 수명

모델이 보유한 NCC 학습 표본 수를 반환합니다. 마스크와 표본 간격은 학습에 선택되는 템플릿 표본에 영향을 줄 수 있습니다. 이 값은 검색에서 발견된 매치 개수와 다르며, 모델 기준 위치는 reference로 별도 확인합니다.

표본이 선택되는 과정

학습은 템플릿 로컬 (0,0)에서 시작해 sample_step 간격으로 각 축을 방문하고 마스크가 0인 위치를 제외합니다. 예를 들어 5×5에서 간격이 2이고 마스크가 모두 켜져 있다면 후보 격자는 3×3, 즉 9개입니다. 실제 sample_count는 학습에 선택된 표본 수입니다.

NCC 모델 생성에는 최소 3개의 선택 표본과 서로 다른 밝기값이 필요합니다. sample_count는 검출 물체 수가 아니므로 검색 평가 수나 결과 수와 비교할 때 서로 다른 단계의 수치임을 기록합니다. 모델의 기준점은 reference로 확인합니다.
