pub fn try_take_with<R, E>( &self, timeout: Duration, map: impl FnOnce(&T) -> Result<R, E>, ) -> Result<FrameQueueTake<R>, FrameQueueTakeMapError<E>>

Maps the front item while holding the queue lock and removes it only on success. The callback must be short and must not reenter this queue. A mapping error leaves the item and its FIFO position unchanged.

사용과 결과 해석

큐의 선두 항목을 잠근 상태로 콜백에 빌려주고 변환이 성공했을 때만 제거하여 변환 결과를 반환합니다. 콜백이 실패하면 선두 항목과 FIFO 순서가 유지되며 오류는 Map으로 구분됩니다.

콜백은 큐 잠금을 유지하므로 짧게 실행하고 같은 큐에 다시 진입해서는 안 됩니다. 큐 대기 및 시간 제한 오류는 Queue로 구분되며, 빈 큐에서 시간 제한 0은 즉시 시도합니다.

선두 변환과 제거

예를 들어 선두 A의 등록 변환에 실패하면 A는 다음 시도에서도 선두입니다. 성공하면 A가 제거되고 B가 다음 선두가 됩니다. 잠금 중 콜백은 짧게 끝내 다른 생산자와 소비자의 대기를 줄이십시오.
