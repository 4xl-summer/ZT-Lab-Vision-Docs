pub fn profile(self, spec: &ProfileSpec) -> ZResult<ProfileQuery>

Plans intensity profile sampling.

사용과 결과 판독

프로파일 계산을 즉시 실행하지 않고 ProfileSpec에 따른 형식화된 쿼리를 만듭니다. self를 값으로 받으므로 동일 계획에서 다른 분기를 만들려면 소유권을 넘기기 전에 필요한 복제를 해야 합니다. 실행 시 얻는 표본은 위치, 거리와 강도를 나타냅니다. ROI 로컬 선분과 폭이 영상에 맞는지 설정을 확인하십시오.

단계확인할 내용
계획지정한 ProfileSpec으로 지연 프로파일을 준비합니다.
소유권self를 값으로 넘기며 필요하면 분기 전에 복제합니다.
실행계획 생성 성공과 실제 영상 실행을 구분합니다.
결과표본의 위치·거리·강도를 각각 확인합니다.

결과 판독과 예

profile은 ImageQuery를 값으로 받아 ProfileSpec이 정한 단면 처리의 지연 계획을 만듭니다. 이 호출에서 실제 표본을 읽은 것이 아니므로 실행 단계의 성공도 따로 확인해야 합니다.

하나의 원본 계획에서 여러 분기를 만들려면 소비되기 전에 필요한 복제를 준비하십시오. 길이 4픽셀의 선분에 양 끝 포함 5개 표본을 두는 사례에서는 간격이 1픽셀이며 실행 결과는 위치·거리·평균 강도로 읽습니다.

항목확인할 내용
self원본 쿼리의 소유권을 전달합니다.
specROI 로컬 선분, 폭과 표본 수를 정합니다.
결과프로파일을 실행할 계획을 반환합니다.
실행계획 생성과 실제 이미지 처리를 구분합니다.
