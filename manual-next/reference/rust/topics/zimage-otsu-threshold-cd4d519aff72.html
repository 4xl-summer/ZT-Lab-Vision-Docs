Returns the Otsu threshold with 256 bins over 0 through 256.

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<f64>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

임계값과 비교 방향이 경계값을 어떻게 분류하는지 작은 영상으로 확인하세요. 예를 들어 경계 바로 아래, 같은 값, 바로 위의 세 픽셀을 준비하면 등호 포함 여부를 구분할 수 있습니다.

고정 히스토그램과 결과

이 호출은 0부터 256까지의 범위를 256개 빈으로 사용해 Otsu 임계값을 계산하고 f64를 반환합니다. 결과는 숫자이며 이 호출만으로 이진 마스크가 반환되는 것은 아닙니다. 계산 오류와 유효한 숫자를 구분합니다.
