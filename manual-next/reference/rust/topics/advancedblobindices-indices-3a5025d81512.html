Rust
pub fn indices(&self) -> &[usize]

Indices refer to the source analysis in original order.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 &[usize]은 빌린 참조를 나타냅니다. 이 값을 사용하는 동안 원본 소유 객체의 수명과 Rust의 빌림 규칙을 지켜야 합니다.

입력과 결과 해석

반환된 인덱스는 원래 분석의 순서를 기준으로 합니다. 블롭의 라벨이나 임의 사용자 ID와 혼동하지 말고 같은 분석 결과에서 해당 인덱스의 항목을 읽으세요. 참조의 수명은 반환 타입을 따릅니다.

인덱스를 원본 분석에 연결

이 함수가 반환하는 것은 결과 객체를 빌리는 usize 슬라이스입니다. 각 값은 필터 또는 정렬 후 새로 매긴 순번이 아니라 원래 블롭 분석에서의 인덱스입니다. 예를 들어 반환값이 [2,0]이라면 원래 분석의 2번과 0번 항목을 그 순서로 가리킵니다.

단계 또는 항목확인할 내용
형식&[usize] 읽기 전용 빌림
기준원래 분석 결과의 인덱스
예시 첫 값2는 원래 분석의 2번 성분
예시 둘째 값0은 원래 분석의 0번 성분
수명슬라이스는 소유 결과보다 오래 쓸 수 없음

결과를 사용할 때

이 인덱스를 라벨 번호나 사용자가 별도로 부여한 ID로 대체하면 다른 성분을 조회할 수 있습니다. 슬라이스를 사용하는 동안 AdvancedBlobIndices 소유 값은 살아 있어야 합니다. 더 오래 별도 보관해야 하는 경우 필요한 인덱스를 소유 컨테이너로 복사하세요.
