pub fn geometry(&self) -> MosaicGeometry

Returns the canvas geometry.

사용과 결과 해석

모자이크 캔버스의 너비, 높이, 공통 좌표 원점 및 배율을 값으로 반환합니다. 영상 픽셀을 공통 좌표와 연결하는 데 필요합니다.

원점과 배율이 다른 모자이크의 같은 픽셀 인덱스는 같은 공통 위치라고 가정할 수 없습니다. 결과 영상과 기하를 함께 보관하십시오.

캔버스 좌표를 읽는 방법

geometry는 합성 캔버스의 폭과 높이, 공통 좌표 원점과 배율을 값으로 반환합니다. 출력 영상의 픽셀 좌표를 정합 결과의 공통 좌표와 연결할 때 이 정보가 필요합니다. 이 호출은 영상을 새로 합성하지 않으며 이미 만든 모자이크의 기하를 확인합니다.

예를 들어 scale=2이면 공통 좌표의 한 픽셀 간격은 출력의 두 픽셀 간격에 대응합니다. 동일한 출력 픽셀 인덱스라도 originX 또는 originY가 다른 두 모자이크에서는 다른 공통 위치를 가리킵니다. image와 valid_mask를 같은 geometry와 함께 보관해 범위와 유효 영역을 판독하십시오.

항목의미와 사용
width / height출력 캔버스 픽셀 크기
originX / originY공통 로컬 좌표의 원점
scale공통 픽셀당 출력 픽셀 배율
예: scale 2공통 1픽셀 간격이 출력 2픽셀
반환기하 값
image해당 기하의 합성 영상
valid_mask해당 기하의 유효 위치
