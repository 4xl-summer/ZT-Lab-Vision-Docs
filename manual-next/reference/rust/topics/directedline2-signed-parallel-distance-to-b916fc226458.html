pub fn signed_parallel_distance_to( self, other: DirectedLine2, angle_tolerance: f64, ) -> Result<f64, ZError>

Signed distance to a parallel line; angle tolerance is dimensionless.

사용과 결과 해석

평행한 다른 방향선까지의 수직 거리를 현재 선을 기준으로 부호와 함께 반환합니다. angle_tolerance는 정규화 방향의 외적 크기에 적용하는 무차원 허용값입니다. 평행 조건이나 입력 검증이 실패하면 오류입니다.

예: (1,0) 방향의 y=0 선에서 y=3 평행선을 비교하면 +3입니다. 같은 좌표계를 사용하고 반환 거리의 단위를 입력 좌표의 단위로 해석하십시오.

평행 거리 확인

기준이 y=0을 따라 +x 방향이고 대상이 y=3이면 부호 거리는 +3입니다. 기준 방향을 −x로 바꾸면 같은 대상의 부호가 바뀝니다. 각도 허용값은 라디안 각도 자체가 아니라 단위 방향의 외적 크기와 비교합니다.
