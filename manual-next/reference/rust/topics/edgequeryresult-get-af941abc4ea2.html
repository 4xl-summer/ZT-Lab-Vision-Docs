pub fn get(&self, selector: u64, by_label: bool) -> ZResult<EdgeQueryInfo>

Returns selected edge metadata.

사용과 결과 해석

selector를 포함된 체인의 인덱스 또는 안정적인 label로 해석하여 EdgeQueryInfo를 값으로 반환합니다. by_label이 false이면 포함 항목만 원래 순서대로 0부터 세고 true이면 label을 찾습니다. 알 수 없거나 제외된 항목은 오류입니다.

정보의 available 비트가 요청된 특성을 알려 줍니다. 생성 시 계산하지 않은 크기나 경계의 기본값을 실제 측정값으로 해석하지 말고 비트를 먼저 확인하십시오.

선택자와 메타데이터

label 2가 제외된 상태에서 인덱스 1은 label 3을 가리킬 수 있습니다. 반면 label로 2를 요청하면 제외 상태이므로 오류입니다. 요청하지 않은 특성의 기본값을 실제 측정값으로 오인하지 않도록 available을 먼저 확인하십시오.
