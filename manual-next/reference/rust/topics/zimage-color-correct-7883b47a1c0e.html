pub fn color_correct(&self, correction: &ColorCorrection) -> ZResult<Self>

Applies an existing color correction matrix.

색 보정 행렬 적용

Rust의 ZImage 호출은 현재 영상에 이 처리를 적용합니다. ColorCorrection의 3×3 행렬과 RGB 편향을 사용해 입력 색을 조정합니다. 각 출력 채널은 입력의 세 채널이 행렬을 통해 결합된 뒤 해당 편향이 더해진 값으로 해석합니다. 예를 들어 단위 행렬과 0 편향은 색 보정의 기준 설정입니다.

현재 영상에서 얻은 결과의 해석에서는 보정 계수는 패치 대응값을 이용한 fit_color_correction 결과에서 얻을 수 있습니다. 결과의 보정 전후 평균과 최대 색차를 함께 확인하면 소수의 패치가 크게 벗어나는 경우를 놓치지 않을 수 있습니다. 학습 패치 외의 별도 입력에서도 효과를 확인합니다.

Rust 반환 값의 소유와 참조 수명을 시그니처에서 확인합니다. 입력 오류와 실제 계산된 빈 결과는 서로 다른 경로이므로 오류를 정상 판정으로 바꾸지 않습니다.

결과와 조건을 함께 읽기

보정은 RGB 입력 벡터에 3×3 행렬을 곱하고 채널별 편향을 더하는 연산입니다. 출력 R은 행렬 첫 행과 입력 (R,G,B)의 내적에 R 편향을 더한 값이며 G와 B도 각 행을 사용합니다. 단위 행렬과 0 편향이면 산술적으로 각 입력 채널이 그대로 전달됩니다. 보정 계수는 별도 패치 대응으로 추정할 수 있지만 이 메서드는 주어진 행렬을 적용하는 단계입니다. 반환 ZResult의 오류를 처리하고 생성된 영상의 형식과 수명을 확인합니다. 학습 패치의 잔차만으로 다른 색 영역의 정확도를 보장하지 않습니다.
