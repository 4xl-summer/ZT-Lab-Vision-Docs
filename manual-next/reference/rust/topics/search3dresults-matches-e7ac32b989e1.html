pub fn matches(&self) -> &[Search3dMatch]

Borrows results in kernel order.

반환값과 수명

3차원 검색 결과를 커널 순서의 불변 슬라이스로 빌립니다. 결과가 가리키는 모델 인덱스를 원래 모델 목록의 순서와 연결하고 각 정합 결과를 함께 해석합니다. 슬라이스는 결과 객체를 빌리므로 소유권을 이동하는 into_matches와 구분합니다.

모델 인덱스와 커널 순서

matches는 Search3dMatch 목록을 커널이 반환한 순서의 불변 슬라이스로 빌려줍니다. 각 결과의 모델 인덱스는 검색에 넘긴 원래 모델 목록에 연결합니다. 이 순서를 사용자가 다른 기준으로 정렬했다면 모델 인덱스와 해당 매치의 관계를 유지해야 합니다.

항목의미와 확인

사용할 때의 판독

예를 들어 입력 모델 목록의 인덱스 0과 1이 서로 다른 물체 모델이라면 결과의 모델 인덱스로 어느 모델의 후보인지 구분합니다. 슬라이스는 Search3dResults의 수명 안에서 읽습니다. 컨테이너를 소비해 소유 벡터를 받는 into_matches와 빌린 matches의 수명 관계도 다릅니다.
