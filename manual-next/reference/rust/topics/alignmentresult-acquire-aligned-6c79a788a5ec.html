pub fn acquire_aligned(&self) -> Option<ZImage>

Acquires the aligned reference image if alignment was found.

결과 해석과 수명

정렬이 발견되었을 때 정렬된 참조 영상을 Option<ZImage>로 얻습니다. 정렬이 없으면 None이므로 영상을 항상 사용할 수 있다고 가정하지 않습니다. acquire_valid_mask에서 얻는 유효 마스크와 함께 좌표별 보간 유효 여부를 확인하고 얻은 각 영상의 소유 수명을 관리합니다.
