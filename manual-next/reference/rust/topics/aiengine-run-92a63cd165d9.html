사용과 결과 해석

이미지와 영역, AiRunOptions로 엔진을 실행하여 AiResult를 반환합니다. 입력 또는 추론 실패는 인식 오류로 전달됩니다.

결과의 종류는 모델 사양에 따라 해석하고, 출력에 해당하는 점수·탐지·맵을 확인하십시오. ROI와 모델 입력 전처리의 좌표 관계도 유지해야 합니다.

입력과 결과 확인

AiEngine::run은 엔진을 빌려 영상, 로컬 영역과 AiRunOptions를 처리하고 RecognitionEngineResult<AiResult>를 반환합니다. 모델 사양의 과제와 입력 조건을 확인한 다음 같은 영상의 유효한 영역을 전달해야 합니다. 실행 오류는 후보가 없는 정상 결과와 별도입니다.

영역은 입력 영상의 좌표 기준으로 기록해야 결과를 원래 프레임에 연결할 수 있습니다. 예를 들어 영상 전체와 작은 ROI를 혼동하면 같은 (0,0) 표기라도 서로 다른 위치를 뜻할 수 있습니다. 옵션의 점수·중복 조건과 결과 수 상한은 해당 모델 과제의 계약에 맞춰 확인하십시오.

AiResult는 불변 결과이며 모델의 출력 종류에 따라 classification, detections 또는 맵 접근 경로가 다릅니다. 분류 점수 슬라이스는 결과에 묶인 참조이고 맵 획득은 별도 소유 공유입니다. 반환 종류와 좌표, 단위를 함께 기록하고 결과가 없는 경우를 클래스 0으로 대체하지 마십시오.

항목확인할 내용
image실행할 입력 영상의 참조입니다.
region해당 영상에서 처리할 영역입니다.
options실행 시 사용할 조건을 지정합니다.
결과성공 시 AiResult, 실패 시 인식 오류입니다.
과제분류·검출·맵을 모델 출력에 맞게 읽습니다.
수명빌린 슬라이스와 독립 맵의 소유를 구분합니다.

분류 결과라면 클래스별 점수와 선택된 클래스 ID를 모델의 레이블 순서에 연결해야 합니다. 검출 결과라면 각 후보의 위치와 점수를 입력 ROI 및 전처리의 좌표 관계에 맞게 읽어야 합니다. 분할 또는 이상 맵은 점수 배열이나 검출 상자와 다른 출력 형태입니다. AiResult의 과제와 model_version, region을 함께 기록하고 잘못된 과제의 접근자가 None을 반환하는 경우를 실제 클래스 0과 혼동하지 마십시오.

엔진과 입력 영상을 빌려 실행한 결과는 별도 AiResult입니다. 오류일 때 결과를 검사하려 하지 말고, 성공한 경우에만 과제에 맞는 접근자를 선택하십시오. 각 실행의 ROI와 옵션도 함께 보관합니다.
