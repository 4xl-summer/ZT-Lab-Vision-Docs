결과 순회

결과의 뷰를 순서대로 반환하는 정확한 크기의 반복자를 만듭니다. 각 항목의 내용과 형식을 읽을 때 원본 결과 컬렉션이 살아 있어야 합니다.

이 컬렉션은 결과를 소유하고 get과 iter가 돌려주는 뷰는 그 컬렉션을 빌립니다. 뷰에서 얻은 참조는 소유 컬렉션보다 오래 사용할 수 없습니다.

복수 판독 순회

iter는 MultiBarcodeReadView를 순서대로 제공하는 ExactSizeIterator입니다. 각 뷰의 형식과 텍스트, 위치를 같은 반복 항목에서 읽어 결과와 심볼의 대응을 유지합니다.

예를 들어 두 코드를 반환했다면 각각의 length_accepted와 회전 각도를 따로 확인합니다. 하나의 항목이 조건을 만족한다고 나머지 항목도 만족한다고 가정하지 않습니다. 순서만으로 위치를 추정하지 말고 points를 확인합니다.

뷰는 컬렉션이 소유한 데이터를 빌립니다. 반복 후에도 문자열이나 원시 바이트를 저장하려면 소유 값으로 복사합니다. 각 항목의 프레임 식별자와 검색 옵션을 함께 보관하면 재검토하기 쉽습니다.
