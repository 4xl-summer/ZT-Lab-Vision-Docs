fn from_core(value: Self::Target) -> Self

Transfers the supplied engine representation into the facade owner.

변환과 소유권

연관 타입 Target의 엔진 표현을 받아 facade 소유 값으로 이전합니다. 이 트레이트의 호출은 입력 값의 소유권을 받으며 정확한 Target은 구현하는 구체 타입이 결정합니다.

예를 들어 코어 영상을 facade 영상으로 바꾼 뒤에는 이동한 이전 변수를 다시 사용할 수 없습니다. 쿼리, 엔진 또는 ops 표현도 이름에 맞는 트레이트와 실제 구현 타입을 확인하십시오.

호출과 결과 판독

FromCore::from_core는 구현 타입이 정한 Target 값을 받아 facade 소유 값으로 이전합니다. 인자를 값으로 받으므로 이동한 원래 변수를 그대로 다시 사용할 수 없습니다. 트레이트 이름만으로 모든 타입의 Target이 같은 코어 표현이라고 가정하지 마십시오.

실제 ZImage 구현에서는 Target이 CoreImage이고 전달받은 코어 영상을 픽셀 복사 없이 facade 이미지로 옮깁니다. 이는 해당 구현에서 확인된 동작입니다. 다른 구현의 표현이나 복사 여부는 그 구현의 계약을 따로 확인해야 합니다.

예를 들어 코어 영상을 facade로 옮긴 뒤에는 반환된 ZImage를 새 소유자로 사용합니다. 이전과 이후 두 변수를 독립 영상으로 취급하려면 구체 타입이 제공하는 공유 또는 복제 경로를 별도로 확인하십시오. 빌려 읽는 API와 소유권 이전도 구분해야 합니다.
