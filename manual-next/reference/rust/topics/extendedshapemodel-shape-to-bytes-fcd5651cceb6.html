pub fn shape_to_bytes(&self) -> ZResult<Vec<u8>>

Serializes the shape.

호출 맥락과 결과 해석

형상 모델을 버전과 체크섬이 포함된 바이트 벡터로 직렬화합니다. 반환 벡터는 모델과 별개의 소유 값입니다. 저장된 바이트는 대응하는 shape_from_bytes로 복원하며 검색 영상과 ShapeSearchOptions는 따로 준비합니다. 동일 영상과 검색 설정에서 저장 전후의 결과를 비교할 수 있습니다.

아카이브 구성과 복원

형상 모델의 특징과 임계값을 버전 표식과 체크섬이 있는 바이트 벡터로 만듭니다. 특징 수 n은 3..65536이어야 하고 직렬화 길이는 32×n+32바이트입니다. 예를 들어 특징이 3개이면 128바이트입니다.

Vec는 모델과 독립 소유이므로 모델의 수명이 끝난 뒤에도 보관할 수 있습니다. 복원에는 shape_from_bytes를 사용하고 검색 영상과 ShapeSearchOptions는 별도로 준비합니다. 저장한 자료를 전달한 뒤 같은 조건의 검색 결과를 비교해 모델이 의도대로 연결되었는지 확인합니다.
