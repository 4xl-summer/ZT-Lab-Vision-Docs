pub fn to_packed_vec_rgba8(&self) -> ZResult<Vec<u8>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<u8>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

조건과 결과 판독

현재 ROI의 보이는 RGBA8 성분을 행 우선으로 복사해 독립 Vec<u8>을 만듭니다. 한 픽셀은 R,G,B,A 네 바이트이므로 폭 2, 높이 3인 ROI는 24개 원소입니다. 반환 값에는 원본 행의 패딩이 포함되지 않습니다.

원본의 전체 영상 크기 대신 현재 ROI의 폭과 높이로 인덱스를 계산하세요. 반환 벡터는 원본 영상에서 빌린 뷰가 아니며 영상 수명과 별도로 보관할 수 있습니다. RGBA가 아닌 픽셀 형식을 자동 변환하는 호출로 가정하지 말고 오류를 처리합니다.
