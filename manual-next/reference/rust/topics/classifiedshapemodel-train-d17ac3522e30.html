클래스별 검색 해석

템플릿과 같은 크기의 Gray8 classes 영상을 사용해 0은 무시, 1은 care, 2는 clutter로 표시합니다. 두 영상의 원점은 (0, 0)이어야 합니다. care 에지로 형상을 만들고 clutter는 별도 위치 표본으로 저장합니다. 예를 들어 배경을 0, 필요한 윤곽을 1, 에지가 나타나지 않기를 바라는 영역을 2로 구분합니다. 학습 기준점은 템플릿 로컬 좌표입니다.

클래스 영상으로 학습 영역 구분

템플릿 영상과 같은 크기의 Gray8 classes 영상에서 각 픽셀의 클래스를 지정합니다. 값 0은 무시, 1은 care, 2는 clutter입니다. care 에지로 찾을 형상을 만들고 clutter는 별도 위치 표본으로 저장합니다. 두 입력 영상의 원점은 모두 (0,0)이어야 합니다.

결과를 사용할 때

예를 들어 템플릿의 필요한 부품 윤곽에 1을 칠하고 배경에는 0을, 매칭 위치에서 에지가 나타나지 않아야 할 영역에는 2를 지정합니다. 이 숫자는 템플릿의 밝기 자체가 아니라 학습 영역의 역할입니다. 학습 기준점은 템플릿 로컬 좌표이므로 검색 결과를 원본에 표시할 때 좌표 기준을 확인하세요.
