fn into_value(self) -> Self::Target

Transfers the owned engine representation out of the facade owner.

변환과 소유권

facade 소유 값을 소비하고 연관 타입 Target에 해당하는 내부 표현의 소유권을 반환합니다. 반환 타입과 구체적인 표현은 이 트레이트를 구현한 타입이 정합니다.

호출 후 이동된 원래 값을 다시 사용할 수 없으므로 먼저 필요한 작업을 마치십시오. 읽기만 필요하다면 해당 구체 타입의 빌림 API가 있는지 확인해 소유권 이전과 구분하십시오.

소유 결과의 내부 값 이전

IntoValue는 self를 소비해 구현별 Self::Target 값을 반환하는 브리지 트레이트입니다. 원본 facade를 빌린 상태로 읽는 것이 아니라 소유 값을 넘기므로 호출 뒤 이동된 원본을 다시 사용할 수 없습니다. 정확한 Target은 구현체의 연관 타입을 확인해야 합니다.

실제 MatchingReport<T> 구현은 Target을 T로 정해 소유 보고 값을 꺼냅니다. 예를 들어 보고를 내부 어댑터에 넘기기 위해 into_value를 사용하면 T의 소유권이 반환되고 기존 MatchingReport 변수는 이동됩니다. 이 과정 자체를 검색을 다시 수행하거나 결과를 깊게 복사하는 호출로 해석하지 않습니다.

실행과 판독에서 확인

보고를 먼저 확인만 해야 한다면 구체 타입에서 제공하는 빌림 접근을 검토하고, 실제 소유권 이전이 필요한 지점에서 이 메서드를 사용합니다. 트레이트를 스코프에 가져오고 반환된 T를 새 소유자로 관리하세요. 보고의 점수와 종료 상태를 읽는 순서를 바꾸지 않도록 이전 전에 필요한 정보를 확인하는 것이 좋습니다.
