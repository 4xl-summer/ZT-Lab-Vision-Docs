점군 깊은 복사

점군의 점 데이터를 별도의 저장소에 복제하여 새 점군을 만듭니다. 같은 저장소를 공유하는 핸들을 만드는 연산과 달리 샘플 저장소도 독립적입니다. 복사된 값의 단위와 frame은 원본 좌표를 해석하는 데 계속 필요합니다.

[A, 결측, B]를 깊은 복사하면 새 점군도 세 슬롯과 같은 결측 위치를 가집니다. 이후 각 점군을 독립된 수명으로 관리할 수 있지만 좌표의 물리적 의미가 자동으로 바뀌지는 않습니다. 메모리와 복사 비용이 중요할 때는 불변 저장소를 공유하는 방법과 목적을 비교합니다.
