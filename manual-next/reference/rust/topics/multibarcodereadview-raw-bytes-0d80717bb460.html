원시 바이트

심볼에서 읽은 바이트를 &[u8]로 빌려 반환합니다. 텍스트 표현과 서로 다른 용도이므로 바이트 기반 처리가 필요할 때 문자열의 표시만 보관하지 않습니다.

이 뷰는 MultiBarcodeReads가 보유한 결과를 빌립니다. 문자열과 슬라이스를 포함해 반환 참조는 원본 컬렉션의 수명 안에서 사용합니다.

원시 바이트의 보관

이 심볼의 원시 바이트를 &[u8] 슬라이스로 빌려 반환합니다. text와는 다른 표현이므로 바이너리 전달이 필요한 경우 표시 문자열을 다시 인코딩해 원시 값과 같다고 가정하지 않습니다.

바이트 배열의 길이와 표시 문자 수는 서로 다른 양입니다. 후속 처리의 길이 검사에서 어떤 단위를 요구하는지 확인하고, 이 결과의 length_accepted와 임의의 바이트 길이 검사를 혼동하지 않습니다.

슬라이스는 상위 결과 컬렉션을 빌리는 뷰에서 나옵니다. 컬렉션보다 오래 유지할 필요가 있으면 소유 버퍼로 복사하고, 형식과 프레임 식별자를 함께 기록합니다.
