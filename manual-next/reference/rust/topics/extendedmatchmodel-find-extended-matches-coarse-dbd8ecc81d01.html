Executes the existing find_extended_matches_coarse search variant and preserves its report.

관련 입력의 확인된 조건

Extended appearance matching model.

호출 맥락과 결과 해석

원본 이미지를 축소하지 않고 거친 위치 격자에서 후보를 선택한 뒤 위치 격자를 정밀화합니다. 실제 축소 영상 피라미드를 사용하는 find_image_pyramid_matches와는 다른 절차입니다. pyramid_levels는 격자 정밀화의 단계 수입니다.

coarse_acceptance는 거친 단계에서 유지할 최소 점수이며 retained_candidates는 각 단계에서 보유할 양의 최대 후보 수입니다. 두 조건을 너무 엄격하게 정하면 뒤 단계에서 정밀화할 후보가 없어질 수 있습니다. 종료 진단과 후보 수를 함께 비교합니다. CoarseMatchOptions의 search.subpixel은 이 경로에서 허용되지 않습니다.

거친 격자에서 정밀 격자로

CoarseMatchOptions의 search는 원래 영상에서 사용할 확장 검색 격자이고 pyramid_levels는 위치 격자를 정밀화할 단계 수입니다. 여기서 pyramid라는 이름은 영상을 실제 축소한다는 뜻이 아닙니다. 축소 영상과 모델을 사용하는 find_image_pyramid_matches와 구별합니다.

각 단계는 coarse_acceptance를 통과한 후보를 retained_candidates 상한까지 유지해 다음 위치 격자로 넘깁니다. 거친 단계에서 후보가 빠지면 뒤 단계가 이를 다시 평가할 수 없으므로 임계값과 유지 수를 같이 조정합니다. 이 경로는 search.subpixel=true를 거부합니다.
