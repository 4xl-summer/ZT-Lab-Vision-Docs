pub fn distance_to_line(&self, other: &LineFit) -> Result<f64, ZError>

Distance to another infinite line: zero when they intersect.

사용과 결과 해석

두 무한 직선 사이의 최소 거리를 반환합니다. 두 선이 교차하면 0이고 평행하면 수직 간격이 됩니다. 유효하지 않은 선 기하 또는 계산은 오류입니다.

예를 들어 y=0과 y=3인 평행선의 거리는 3입니다. 반면 화면상 교점이 멀리 있더라도 무한 직선이 교차하면 거리는 0입니다.

두 무한 직선의 거리

y=0과 y=3은 평행하므로 거리는 3입니다. y=0과 x=100은 화면에서 멀리 떨어져 보일 수 있지만 무한선은 (100,0)에서 만나므로 거리는 0입니다. 선분의 끝점 간 간격과는 다른 계산입니다.

일치거리 0
부호항상 음이 아닌 값
