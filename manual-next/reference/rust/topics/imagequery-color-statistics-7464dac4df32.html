pub fn color_statistics( self, mask: Option<&ZImage>, ) -> ZResult<ColorStatisticsQuery>

Plans encoded RGB statistics.

색 통계의 영역과 값

Rust의 ImageQuery 호출은 이 처리를 실행 계획에 연결합니다. 영상의 색 통계를 계산합니다. 평균 같은 요약값은 입력의 색 분포를 하나의 값으로 압축하므로 밝은 부분과 어두운 부분이 섞인 경우 원래의 공간적 배치를 보여 주지 않습니다. 비교하려는 영상이 같은 제품 영역과 조명 조건을 가리키는지 먼저 확인합니다.

계획을 실행해 얻은 결과의 해석에서는 마스크나 ROI를 사용한 경로라면 선택 영역이 달라졌는지도 통계와 함께 살펴봅니다. 값이 달라졌을 때 원본 영상의 분포와 표본 범위를 비교하면 조명 변화와 물체 구성 변화의 가능성을 구별하는 데 도움이 됩니다.

이 호출은 Rust의 지연 쿼리 단계입니다. 빌더의 이동과 소유 관계를 확인하고 별도 분기가 필요하면 지원되는 clone을 사용합니다. execute 결과는 반환 타입의 소유 규칙에 따라 다룹니다.

색 통계 종단 계획

선택적 mask를 받아 ColorStatisticsQuery를 반환합니다. 기존 ImageQuery의 색 통계 단계를 계획하며 즉시 평균이나 픽셀 수를 반환하지 않습니다. mask와 입력 영상이 같은 영역을 가리키는지 확인합니다.

실행한 결과의 통계는 선택된 영역을 요약합니다. 예를 들어 두 영역의 평균이 같더라도 한쪽은 균일하고 다른 쪽은 밝고 어두운 픽셀이 섞였을 수 있으므로 최소·최대 등 다른 통계와 대상 범위를 함께 봅니다.

self를 소비하므로 다른 쿼리와 분기할 때는 이 호출 전에 계획을 clone합니다. 쿼리와 실행 결과의 타입에 맞게 값을 읽으며 입력 형식이나 기하 오류를 색상 0의 통계로 처리하지 않습니다.
