Rust
pub fn view_grayf64(&self) -> ZResult<GrayF64View<'_>>

이미지 수명에 묶인 불변 형식별 뷰를 반환합니다. 형식이 다르면 오류입니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<GrayF64View<'_>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

행 또는 뷰의 요소를 읽을 때 메서드가 지정한 픽셀 형식과 현재 영상의 형식이 맞는지 확인합니다. ROI의 보이는 영역과 행 인덱스를 기준으로 해석하고, 빌린 참조라면 이를 제공한 객체보다 오래 보관하지 않습니다.

GrayF64 읽기 뷰

현재 영상이 해당 픽셀 형식일 때 64비트 부동소수 회색 성분를 읽습니다. 픽셀 하나는 1개 성분이며, 예시 표본은 -1.0, 0.0, 0.5, 1.0입니다. 형식이 맞지 않으면 ZResult 오류이므로 성공 뷰나 벡터를 가정하지 않습니다.

항목확인할 내용
형식64비트 부동소수 회색 성분
픽셀당 성분1개
2×2 보이는 성분4개
반환영상 수명에 묶인 불변 뷰

반환 뷰는 영상에서 빌린 불변 참조이므로 제공한 ZImage의 수명 안에서 행과 성분을 사용합니다. 폭 2, 높이 2이면 보이는 성분은 4개입니다. 원본 행의 바이트 간격과 보이는 성분 수는 다른 값입니다.
