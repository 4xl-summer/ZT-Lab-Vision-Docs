결과 해석과 수명

측정된 RegionMoments 값들을 불변 슬라이스로 빌립니다. 각 항목은 실행된 영역 측정의 결과이며 이미지를 새로 계산하는 호출이 아닙니다. 원본 결과의 수명 안에서 읽고, 성분별 위치나 면적을 해석할 때 사용한 ROI 좌표계를 확인합니다.

사용 순서와 결과 판독

moments는 MomentsResult가 소유한 RegionMoments 값들을 &[RegionMoments] 불변 슬라이스로 빌립니다. 실행된 영역 측정의 스냅샷을 조회하는 것이며 접근할 때마다 입력 영상을 새로 분석하지 않습니다. 슬라이스의 각 항목은 한 성분의 면적, 중심 및 중심 모멘트와 형상 관련 값을 해석하는 데 사용합니다.

중심은 입력 영상의 ROI 로컬 좌표이므로 다른 ROI에서 계산한 값과 비교하기 전에 기준을 맞춥니다. 예를 들어 ROI 원점 (100,200)의 로컬 중심이 (2,3)이면 글로벌 중심은 (102,203)입니다. 면적은 영역 크기이고 중심은 위치이므로 값의 단위와 역할이 다릅니다. 결과 인덱스와 입력 성분의 식별 관계를 함께 보존합니다.

반환 슬라이스는 결과 객체의 내부 값을 빌리므로 MomentsResult보다 오래 사용할 수 없습니다. 결과를 폐기한 뒤에도 항목을 저장할 필요가 있으면 필요한 측정값을 소유 형태로 복사합니다. 빈 슬라이스와 입력 실행 오류는 서로 다르므로 실행의 ZResult를 먼저 확인한 후 결과 목록을 읽습니다.
