Applies the RGB8 map with a per-channel border.

계산 순서와 결과 확인

RGB8 소스에 맵을 적용하며 border로 세 채널의 바깥 채움값을 지정합니다. 반환 쌍은 출력 영상과 유효 마스크입니다. 단일 f64 경계값을 받는 apply와 달리 [u8; 3]의 채널별 값을 사용하므로 소스 형식과 채널 순서를 확인합니다.
