각도 목록으로 판독

입력 영상과 옵션, angles_degrees 슬라이스의 각도를 사용해 폰트 판독을 시도합니다. 결과는 RecognitionEngineResult<Option<FontAngleRead>>이므로 오류와 결과 없음이 서로 다릅니다.

각도는 도 단위이며 지정하지 않은 각도에서의 결과를 보장하지 않습니다. 선택된 각도와 글자별 결과를 입력 영상 및 분할 설정과 함께 기록합니다.

지정 각도에서 폰트 판독

angles_degrees는 도 단위 f64 슬라이스입니다. 하나 이상 최대 360개이며 각 값은 유한하고 절댓값이 360 이하여야 합니다. 모델은 제시된 각도를 순회하며 입력 캔버스 크기를 유지한 회전 영상에서 판독합니다. 목록에 없는 각도를 자동으로 검색한다고 가정하지 않습니다.

예를 들어 [-5, 0, 5]를 주면 세 각도만 시도합니다. 반환은 RecognitionEngineResult<Option<FontAngleRead>>이므로 오류, 정상적인 None, Some 판독을 분리합니다. Some에서는 선택 각도와 문자열·문자별 판정을 읽고 원본의 잘림과 대비를 확인합니다.
