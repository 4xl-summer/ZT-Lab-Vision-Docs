pub fn from_bytes(bytes: &[u8]) -> ZResult<Self>

Restores a trained model.

관련 입력의 확인된 조건

Feature descriptor model.

호출 맥락과 결과 해석

직렬화된 특징 모델 바이트를 읽어 독립 모델로 복원합니다. bytes는 비어 있지 않아야 하고 길이는 16000000바이트 이하여야 합니다. 이미지의 원본 픽셀 바이트가 아니라 해당 모델 형식의 데이터를 입력합니다.

반환 모델은 스코프가 끝나면 정리됩니다. to_bytes로 얻은 전체 바이트를 보관하고 복원 뒤 동일 검색 조건을 적용해 확인하면 됩니다. 로드가 실패하면 바이트의 길이, 완전성과 모델 종류를 살핍니다.

특징 모델 복원

직렬화된 바이트 슬라이스를 빌려 학습된 FeatureModel을 복원합니다. 반환은 ZResult이며 바이트가 올바른 모델로 해석되지 않거나 복원에 실패하면 오류를 처리해야 합니다. 반환 모델은 내부 상태를 Arc로 소유합니다.

복원은 입력 영상에서 특징을 다시 학습하는 과정이 아닙니다. 저장한 모델과 그 학습 조건, 모델이 기대하는 대상 및 버전 정보를 함께 관리하면 나중에 검색 결과의 출처를 확인할 수 있습니다. 바이트 슬라이스와 반환 모델은 서로 다른 소유 관계입니다.

복원 후 별도 검사 영상과 FeatureMatchOptions로 검색하고 결과의 후보와 보고를 확인합니다. 저장 파일이 읽혔다는 사실은 현장 영상에서 충분한 매칭 정확도를 보장하지 않습니다. 학습 및 복원 조건이 실제 입력과 맞는지도 검토합니다.
