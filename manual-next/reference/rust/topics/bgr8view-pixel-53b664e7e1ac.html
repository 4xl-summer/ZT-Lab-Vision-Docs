관련 입력의 확인된 조건

Borrowed typed image view with byte stride.

형식과 좌표

Bgr8View의 pixel은 현재 뷰의 로컬 (x,y)에서 픽셀 하나를 읽습니다. 색상 형식이라면 반환 성분의 순서를 형식의 순서와 함께 해석해야 합니다.

Bgr8View에서 한 픽셀의 저장 성분은 B, G, R이며 성분 자료형은 u8입니다. 예를 들어 너비 4, 높이 3인 뷰에서는 (3,2)가 마지막 유효 픽셀이고 x=4 또는 y=3은 범위 밖입니다. 오류를 0 픽셀과 혼동하지 마십시오.

수명과 후속 처리

Bgr8View는 원본 저장소의 수명에 묶인 뷰입니다. 반환된 참조를 원본 데이터보다 오래 보관할 수 없으며, 값을 다른 소유 객체로 보존하려면 별도의 소유 복사 또는 이미지 공유 계약을 사용해야 합니다. 형식이 다른 뷰로 임의 재해석하지 말고 입력 구성과 성분 순서를 확인하십시오.

좌표 계산 예

각 입력 x와 y는 바이트 오프셋이 아니라 Bgr8View의 픽셀 좌표입니다. 색상 픽셀의 성분을 해석할 때는 B, G, R 순서와 u8 범위를 따릅니다. 같은 숫자라도 다른 채널 순서의 영상과 비교하면 의미가 바뀌므로 변환 형식과 입력을 함께 확인하십시오.
