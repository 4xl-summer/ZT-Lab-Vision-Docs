형식과 좌표

Gray8View의 height는 현재 보이는 뷰의 행 수를 픽셀 단위로 반환합니다. 부모 전체의 높이가 아니라 이 뷰에 지정된 높이를 확인합니다.

Gray8View의 높이가 3이면 유효한 로컬 행 인덱스는 0, 1, 2입니다. 3을 row에 전달하는 것은 높이를 반환하는 것과 달리 범위를 벗어납니다. 행 간격에는 패딩이 있을 수 있으므로 높이에 행 바이트 수를 곱해 전체 저장소를 무조건 연속 배열로 가정하지 마십시오.

수명과 후속 처리

Gray8View는 원본 저장소의 수명에 묶인 뷰입니다. 반환된 참조를 원본 데이터보다 오래 보관할 수 없으며, 값을 다른 소유 객체로 보존하려면 별도의 소유 복사 또는 이미지 공유 계약을 사용해야 합니다. 형식이 다른 뷰로 임의 재해석하지 말고 입력 구성과 성분 순서를 확인하십시오.

좌표 계산 예

높이 확인은 행 범위를 정하는 데 사용하며 반환값은 저장소의 전체 바이트 길이가 아닙니다. 예시 Gray8View이 세 행이면 y=2가 마지막이고 y=3은 범위 밖입니다. ROI를 만든 다음 height를 다시 읽으면 원래 영상의 세 행이 아니라 새로 선택한 보이는 행 수를 얻습니다.
