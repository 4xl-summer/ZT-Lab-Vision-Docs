pub fn sample_count(&self) -> usize

Returns the training sample count.

학습 표본 수

모델이 기록한 학습 표본 수를 usize로 반환합니다. 이 수치는 모델의 통계가 어떤 입력으로 만들어졌는지 확인할 때 유용하지만 표본의 다양성이나 검사 정확도를 보증하지 않습니다.

표본 수가 같아도 서로 다른 정상 상태가 포함되었는지는 입력을 확인해야 합니다. 모델 생성 경로와 데이터 출처, 검사 옵션을 함께 기록합니다.

모델 학습 표본 수

sample_count는 VariationModel의 학습 표본 수를 usize로 반환합니다. 이 숫자는 원본 이미지의 픽셀 수나 현재 검사에서 검출한 결함 수가 아닙니다. 모델이 어떤 정상 영상들로 만들어졌는지 기록할 때 사용합니다.

항목확인할 내용

학습 표본 수가 같아도 입력 영상의 조명, 정렬과 변동 범위가 같다는 의미는 아닙니다. inspect 결과의 결함 마스크 및 심각도는 별도 확인하고, model_images로 평균과 편차 영상을 얻으면 각 독립 영상을 관리합니다.
