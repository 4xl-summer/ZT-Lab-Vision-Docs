사용과 결과 해석

디코딩된 기호의 버전 번호를 반환합니다. 결과의 형식에 속한 버전 체계로 해석해야 하며, 숫자 자체는 교정된 코드워드 수나 허용 한도를 뜻하지 않습니다.

기호 크기나 구성 비교에 쓰려면 format 또는 해당 진단 결과의 형식을 함께 기록하십시오. 서로 다른 코드 형식의 같은 숫자를 같은 구조로 가정하지 마십시오.

조건과 결과 판독

이 진단 객체는 QR 오류 정정 결과이므로 version은 해당 QR 심볼의 버전 번호입니다. 오류 정정 레벨이나 corrected_codewords 수와는 별도 필드이며 같은 숫자를 정정량으로 읽지 않습니다.

예를 들어 두 판독의 version이 같더라도 정정 레벨과 블록별 수정량은 다를 수 있습니다. text, error_correction_level, blocks, accepted를 함께 기록하면 해독 결과와 정정 판정을 분리해 볼 수 있습니다. 반환 u32는 빌린 텍스트나 블록 슬라이스와 다른 소유 값입니다.

예를 들어 같은 버전의 두 심볼을 비교할 때도 서로 다른 오류 정정 레벨이나 블록별 수정량을 가질 수 있습니다. 버전 번호만으로 한도 통과를 판단하지 말고 accepted와 blocks를 별도로 읽어야 합니다. 결과의 text는 문자 내용이고 version은 심볼의 구성 정보를 나타내는 숫자입니다.
