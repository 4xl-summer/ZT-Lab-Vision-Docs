Executes an existing Ops model without cloning its trained state.

Ops 모델 직접 검사

이미 존재하는 zvision_ops::VariationModel을 빌려 영상과 VariationInspectOptions로 검사합니다. 래퍼 모델을 새로 훈련하거나 학습 상태를 복제하지 않고 기존 모델의 검사 결과를 VariationResult로 감쌉니다.

영상 좌표가 학습 기준과 대응하는지 확인하고, 결과의 잔차와 심각도 및 결함 마스크를 함께 해석합니다. 호출이 실패하면 ZResult 오류이며 빈 결함 마스크가 만들어졌다는 의미가 아닙니다.

조건과 결과 판독

이미 학습된 zvision_ops::VariationModel을 참조로 받아 입력 영상과 VariationInspectOptions를 적용합니다. 학습 상태를 새 래퍼에 복제하거나 이 호출에서 다시 학습하는 작업은 아닙니다.

정상 모델을 만든 기준과 검사 영상이 같은 위치·좌표 기준을 가리키는지 확인하세요. 반환 VariationResult에서는 부호 잔차, 심각도, 결함 마스크를 각각 확인합니다. ZResult 오류는 검사가 성공했고 결함이 없었다는 뜻이 아닙니다.
