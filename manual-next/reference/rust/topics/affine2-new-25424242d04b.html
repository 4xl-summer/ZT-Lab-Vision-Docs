사용과 결과 해석

여섯 계수 [a,b,tx,c,d,ty]를 행 우선으로 받아 원본 점을 x′=a x+b y+tx, y′=c x+d y+ty로 사상합니다. 계수는 유한해야 하고 변환은 역행렬을 가질 수 있어야 합니다. 조건을 만족하지 않으면 오류를 반환합니다.

예를 들어 [2,0,3,0,2,4]는 점 (1,2)를 (5,8)로 옮깁니다. 변환 방향은 원본에서 목적지이며 영상을 역방향 샘플링하는 호출에 쓸 때는 해당 호출의 방향 계약도 확인하십시오.

좌표계산
x′a × x + b × y + tx
y′c × x + d × y + ty

계수의 위치

예를 들어 [1,0,3,0,1,4]는 x에 3, y에 4를 더합니다. (2,5)는 (5,9)가 됩니다. 회전이나 배율을 추가하면 이동 순서와 결과도 달라지므로 좌표계 방향을 먼저 정하십시오.

항목내용
a, b입력 x와 y가 출력 x에 미치는 선형 계수
tx출력 x에 더하는 이동
c, d입력 x와 y가 출력 y에 미치는 선형 계수
ty출력 y에 더하는 이동
값 검증계수와 변환은 유효하고 역변환 가능해야 합니다.
방향원본 좌표에서 목적지 좌표로 변환합니다.
