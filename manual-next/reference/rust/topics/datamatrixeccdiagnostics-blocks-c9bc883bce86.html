사용과 결과 해석

오류 정정 블록들의 진단을 읽기 전용 슬라이스로 반환합니다. 각 블록의 데이터 코드워드 수, 패리티 코드워드 수, 수정된 코드워드 수를 확인할 수 있습니다.

슬라이스는 결과의 수명에 묶이며 필요하면 복사해 보관합니다. 전체 수정량만 살피는 것보다 블록별 값을 보면 특정 블록에 집중된 교정을 확인할 수 있습니다.

블록별로 확인할 값

예를 들어 두 블록의 수정 수가 1과 2라면 전체 합계는 3입니다. 한 블록당 한도가 1이면 두 번째 블록은 한도를 초과하므로 전체 수만 보는 대신 각 블록을 확인해야 합니다.
