pub fn residuals(&self) -> &[CalibrationResidual]

Returns immutable correspondence residuals.

사용과 결과 판독

평가한 대응점의 잔차들을 불변 슬라이스로 빌립니다. 개별 잔차를 관측 위치와 짝지어 보면 집계 통계가 작은데 특정 영역에서만 오차가 큰 상황을 확인할 수 있습니다. 예측과 기준의 배열 순서가 같아야 각 잔차가 의도한 점에 대응합니다. 빌린 슬라이스는 소유하는 검증 결과의 수명 안에서 사용하십시오.

단계확인할 내용
입력 순서예측과 기준 배열의 같은 인덱스를 짝짓습니다.
세계 차이세계 좌표의 길이 단위로 해석합니다.
위치별 판독큰 잔차가 나타나는 위치를 원본 점과 대조합니다.
수명불변 슬라이스는 검증 결과 객체에서 빌립니다.

판독과 사용 순서

잔차 슬라이스의 각 원소는 검증에 사용한 대응점 순서와 연결됩니다. 집계 RMS가 작아도 특정 위치 한 곳의 오차가 클 수 있으므로 원래 픽셀과 세계 기준점을 같은 인덱스로 찾아 비교합니다. 예를 들어 세계 좌표 차이가 (0.3,0.4) mm이면 거리 잔차는 0.5 mm입니다. 픽셀 공간의 역변환 차이는 다른 단위이므로 이 값과 직접 더하지 않습니다. 접근자는 결과 내부의 불변 슬라이스를 빌립니다. 슬라이스를 결과보다 오래 보관해야 한다면 필요한 값을 소유한 형태로 복사합니다.

항목판독 기준
