pub fn probes(&self) -> &[ProbeObservation]

Returns probe diagnostics.

결과 확인 순서

원 측정의 결과 객체에서 호출합니다. 각 탐색 위치의 진단을 빌린 슬라이스로 제공합니다. 한 프로브가 에지를 찾았어도 최종 피팅에 그 점이 채택되지 않을 수 있으므로 발견 위치와 사용 여부, 잔차를 구분해 살펴야 합니다. 검색 위치와 방향을 영상 위에 표시하면 목적 경계가 아닌 인접 경계를 선택한 문제를 찾는 데 도움이 됩니다.

확인 항목사용 기준
대상원 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용결과가 살아 있는 동안 개별 관측을 확인합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

판독과 사용 순서

반환된 각 ProbeObservation은 원 둘레의 탐색 위치에서 무엇이 관찰됐는지 보여 줍니다. 에지를 발견한 탐침과 최종 원 적합에 사용된 탐침은 같은 집합이라고 가정할 수 없으므로 발견 상태, 선택 위치, 사용 여부와 잔차를 함께 봅니다. 예를 들어 주변에 두 경계가 있으면 강한 다른 경계가 선택되어도 관측 자체는 성공일 수 있습니다. 이때 탐침의 위치와 방향을 원본 영상 위에 대조하면 원치 않은 선택을 식별할 수 있습니다. 슬라이스는 결과에서 빌리므로 진단을 장기 보관하려면 필요한 관측을 별도 소유 형태로 옮깁니다.
