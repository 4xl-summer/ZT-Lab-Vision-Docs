pub fn evaluated(&self) -> usize

Returns the number of evaluated candidates.

반환값과 수명

실제로 평가된 후보 포즈 수를 반환합니다. 반환된 매치 개수와 같을 필요가 없으며 후보 예산과 검색 범위가 평가 수에 영향을 줍니다. matches의 길이와 termination을 함께 확인하면 결과가 적은 상황에서 검색 진행 상태를 구분할 수 있습니다.

조건과 결과 판독

evaluated는 실제 평가한 후보 포즈 수이고 최종 matches 길이는 결과로 남은 후보 수입니다. 예를 들어 100개를 평가한 뒤 두 개만 반환했다면 두 값은 각각 100과 2로 해석합니다. 반환 상한이나 중복 처리는 최종 개수에 영향을 줄 수 있습니다.

termination을 함께 읽어 평가가 완료되었는지 예산 등으로 중단되었는지를 확인하세요. 이 숫자는 처리 시간이나 검색 공간 전체 크기 자체가 아닙니다. 같은 조건의 다른 실행과 비교할 때 검색 범위와 후보 예산을 같이 기록합니다.
