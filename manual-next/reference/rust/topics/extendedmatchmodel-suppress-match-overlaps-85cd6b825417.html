pub fn suppress_match_overlaps( &self, matches: &[ExtendedMatch], max_iou: f64, limit: usize, ) -> ZResult<MatchingReport<Vec<ExtendedMatch>>>

Suppresses overlapping matches using the existing rectangle policy.

관련 입력의 확인된 조건

Extended appearance matching model.

호출 맥락과 결과 해석

이미 구한 ExtendedMatch 후보를 점수 순으로 비교하고 변환된 NCC 표본의 축 정렬 경계상자 IoU를 사용해 겹치는 후보를 억제합니다. 새 후보를 검색하는 호출이 아니므로 입력 matches가 어떤 검색에서 나왔는지 함께 보존합니다.

max_iou는 0에서 1 사이의 최대 겹침 기준이고 limit은 유지할 양의 최대 개수입니다. 회전된 형상의 축 정렬 상자는 실제 모양보다 클 수 있어 다각형 겹침 억제와 결과가 다를 수 있습니다. 반환 보고서의 매치 벡터를 읽습니다.

경계상자 IoU 판독

이 메서드는 이미 구한 ExtendedMatch 후보를 점수 순으로 비교합니다. 각 후보의 변환된 NCC 표본을 감싸는 축 정렬 경계상자의 교집합/합집합 비율이 max_iou를 초과하는 후보를 억제합니다. 예를 들어 같은 면적 2개의 상자 교집합이 각각의 절반이면 IoU는 1/3입니다.

limit은 유지할 양의 최대 개수이고 max_iou는 0..1입니다. 회전된 모델의 축 정렬 상자는 실제 다각형보다 넓을 수 있으므로 같은 후보에 다각형 정책을 적용한 결과와 다를 수 있습니다. 반환 Vec는 새 검색 결과가 아니라 입력 후보에서 남은 값입니다.
