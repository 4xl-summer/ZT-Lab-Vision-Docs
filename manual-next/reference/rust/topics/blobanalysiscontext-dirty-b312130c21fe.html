pub fn dirty(&self) -> bool

Reports whether geometry settings changed since the last successful calculation.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언은 bool입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

분석 설정과 현재 결과를 관리하는 컨텍스트입니다. 연결 방식이 달라지면 새 설정에 대해 다시 계산해야 합니다. 인덱스 모드는 현재 결과의 조회 방식만 바꾸며 재계산하지 않습니다. 계산 실패 시 현재 결과가 지워질 수 있습니다.

설정 변경과 결과 구분

dirty는 마지막 성공 계산 이후 기하 설정이 변경되었는지 알려줍니다. 연결 방식을 현재 값과 다르게 바꾸면 true가 되고 새 계산이 성공하면 false로 돌아갑니다. 반면 조회를 라벨 기반으로 바꾸는 set_index_mode는 기하 계산을 바꾸지 않습니다.

결과를 사용할 때

dirty와 has_current는 서로 다른 질문에 답합니다. 기존 현재 결과가 있더라도 새 연결 설정에 맞는지 확인하려면 dirty를 함께 읽어야 합니다. 재계산이 실패하면 현재 결과는 비워질 수 있으므로 반환 오류와 has_current를 점검하고 이전 결과를 새 계산의 성공으로 표시하지 마세요.
