Rust
pub fn measure(&self, image: &ZImage) -> ZResult<RectangleMeasurementResult>

Measures the rectangle and returns an independent snapshot.

사용과 결과 판독

검증된 사각형 모델을 빌려 입력 ZImage의 ROI에서 관측하고 사각형 계측 결과를 반환합니다. 모델의 기준 형상은 탐색 위치를 정하며 반환 형상이 반드시 기준과 같다는 뜻은 아닙니다. 프로브의 발견 상태와 최종 적합에 채택된 점을 구별하고, 형상이 없거나 피팅에 실패한 결과를 좌표 0으로 대체하지 마십시오. 다른 영상에 재사용할 때 ROI 원점과 검색 범위를 함께 확인합니다.

단계확인할 내용
모델사각형의 검증된 기준과 설정을 빌립니다.
영상목적 경계가 포함된 ZImage ROI를 전달합니다.
관측발견된 프로브 점과 최종 채택점을 구별합니다.
결과형상 상태와 ROI 좌표 기준을 함께 확인합니다.

입력과 결과 확인

RectangleMeasurementModel.measure는 검증된 사각형 모델과 영상 ROI를 빌려 각 변의 경계를 탐색하고 독립 결과 스냅샷을 반환합니다. 기준 사각형은 검색 위치를 정하며 최종 중심과 반축이 반드시 기준값과 같다는 뜻은 아닙니다.

각 ShapeProbeObservation의 side는 관측이 속한 변 정보를 제공하고 기본 관측의 상태와 selected, used, residual은 개별 단계의 결과입니다. 한 변에서 에지를 많이 찾아도 다른 변에서 관측이 부족하면 사각형 전체를 판단하는 데 필요한 점 분포가 달라집니다.

예를 들어 최종 반폭이 4픽셀, 반높이가 2픽셀이면 로컬 변 길이는 각각 8과 4픽셀입니다. fit이 None인 실패 상태를 이 예의 0 크기 사각형으로 대체하지 말고 status, 수렴과 관측 진단을 함께 확인하십시오. 다른 ROI와 비교할 때는 원점과 라디안 각도 기준도 기록합니다.
