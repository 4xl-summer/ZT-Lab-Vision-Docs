폰트 샘플 학습

FontSample 슬라이스와 FontTrainingAlgorithm, FontOcrOptions를 전달해 모델을 학습합니다. 각 샘플의 이미지, 문자 라벨 및 셀이 같은 글자에 대응해야 하며 입력 이미지의 공유를 학습 호출에 사용합니다.

NearestExample과 ClassMean은 템플릿을 사용하는 방식이 다릅니다. 결과 모델은 이후 별도 영상에서 평가하고, 점수를 보정된 정확도 확률로 해석하지 않습니다.

문자 샘플과 학습 알고리즘

train은 FontSample 슬라이스, FontTrainingAlgorithm과 FontOcrOptions를 검증해 폰트 OCR 모델을 만듭니다. 각 샘플의 label은 문자, image는 영상, cell은 그 문자가 들어 있는 사각 영역입니다. 같은 샘플의 라벨과 셀은 반드시 같은 글자를 가리켜야 하며, 결과는 RecognitionEngineResult로 성공 모델이나 오류를 구분합니다.

예를 들어 서로 다른 이미지의 문자 A 두 개와 문자 B 한 개를 샘플로 넣을 때 각 셀을 해당 문자에 맞게 지정합니다. NearestExample과 ClassMean은 학습 예제를 사용하는 방식이 다르므로 같은 자료라도 모델의 비교 동작이 같다고 가정하지 않습니다. threshold와 light_text는 글자 전경 해석에 영향을 주고 크기 한도는 후보 글자 영역을 제한합니다.

실행과 판독에서 확인

학습에 사용하지 않은 이미지에서 문자별 결과와 문자열 상태를 검증하세요. 점수는 이 모델의 비교 결과이지 정답 확률로 보정되었다는 보장이 아닙니다. 학습 샘플이 배경만 포함하거나 잘못된 셀을 가리키면 이후 인식 실패의 원인이 될 수 있으므로 라벨, ROI와 옵션을 함께 기록합니다. 반환 모델은 학습된 소유 값이고 입력 샘플 슬라이스의 빌림과 구분합니다.
