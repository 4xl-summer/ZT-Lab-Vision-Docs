pub fn undistort_point(&self, p: Point2) -> Result<Point2, ZError>

Finds a local inverse; convergence and uniqueness are only meaningful within the calibration domain.

계산 순서와 결과 확인

왜곡 픽셀의 국소 역변환을 반복 계산합니다. 보정 영역 안에서의 수렴과 유일성을 전제로 해야 하며 모든 영역에서 전역 역함수를 보장하지 않습니다. 모든 왜곡 계수가 0이면 입력을 그대로 반환합니다. 계산 결과를 distort_point에 다시 넣어 원래 픽셀과의 차이를 확인할 수 있습니다.

방법국소 반복 역변환
한계보정 영역 밖 전역 유일성은 보장되지 않음

사용 순서와 결과 판독

undistort_point는 왜곡된 픽셀 좌표를 Brown 렌즈 모델의 왜곡 없는 픽셀 좌표로 국소적으로 역산합니다. 먼저 렌즈 파라미터와 점의 유한성을 확인하며, 왜곡 계수가 모두 0이면 입력 점을 그대로 반환합니다. 이 값은 카메라 광선의 3차원 방향이나 세계 좌표가 아니라 여전히 픽셀 좌표입니다.

일반적인 경우 픽셀을 초점과 주점으로 정규화한 뒤 반복적으로 왜곡 모델의 오차를 줄입니다. 구현은 최대 32회 반복하고 재투영 픽셀 오차가 1e-9 이하이면 결과를 반환합니다. 야코비안이 퇴화하거나 오차를 줄이는 단계가 없거나 반복 안에 수렴하지 못하면 오류입니다. 예를 들어 모든 왜곡이 0인 경우 입력 (100,200)은 출력도 (100,200)입니다.

반환 점을 distort_point에 다시 적용하여 원래 픽셀과의 차이를 검사하면 수치 역변환을 확인하는 데 도움이 됩니다. 다만 전역 영역에서 역함수가 항상 유일하다는 보장은 없고 수렴의 의미는 보정 영역 안에서 해석해야 합니다. 영상 ROI가 달라졌다면 렌즈 파라미터와 점이 같은 픽셀 기준인지 확인한 후 사용합니다.
