pub fn train( image: &ZImage, mask_image: Option<&ZImage>, options: InvariantFeatureOptions, ) -> ZResult<Self>

Trains descriptors from an image and optional mask.

관련 입력의 확인된 조건

Scale and rotation invariant feature model.

호출 맥락과 결과 해석

방향과 다중 해상도를 갖는 특징 모델을 회색 템플릿에서 학습합니다. InvariantFeatureOptions가 검출 조건을 지정하며 선택적인 Gray8 마스크로 학습 영역을 제한할 수 있습니다.

학습된 점의 위치뿐 아니라 배율과 방향은 features에서 확인합니다. 이 모델과 일반 FeatureModel은 사용하는 모델 표현과 학습 옵션이 다르므로 저장 데이터와 복원 API를 각 모델 종류에 맞게 관리합니다. 생성된 모델은 스코프가 끝나면 정리됩니다.

결과와 조건을 함께 읽기

템플릿의 특징을 여러 해상도와 방향 정보와 함께 학습합니다. 위치만 저장하는 일반적인 점 목록이 아니라 검색 시 대응을 평가할 모델 기술자이므로 학습된 features와 찾은 인스턴스를 구분합니다. 선택 마스크가 있으면 학습 영역을 제한하고 옵션은 검출 및 표현을 제어합니다. 예를 들어 배경의 반복 무늬가 특징으로 많이 들어온다면 대상 영역을 지정한 마스크와 원본을 같은 크기·원점으로 준비하여 선택 결과를 비교할 수 있습니다. 서로 다른 모델 형식의 저장 데이터와 복원 API도 혼용하지 않습니다.
