Estimates nearest-neighbor normals.

점군 법선 추정

각 유효 점의 이웃으로 국소 면의 방향을 추정합니다. 이웃은 중심 외의 점을 뜻하며, 주어진 관측 위치는 법선 방향을 정하는 데 사용됩니다. 결측점이나 충분하지 않거나 퇴화한 이웃에서는 방향을 정할 수 없어 해당 결과도 결측이 됩니다.

평평한 z=0 면에 서로 다른 위치의 점이 충분하면 법선은 z축과 평행합니다. 수직 방향의 부호는 관측 위치에 따른 방향 정렬을 함께 확인해야 하므로 절댓값만으로 앞면과 뒷면을 판정하지 않습니다. 출력은 원본 슬롯과 같은 순서로 해석합니다.

확인 항목해석
이웃중심 외 점을 포함하는 국소 표본
viewpoint법선 방향을 정하는 관측 위치
출력각 슬롯의 단위 방향 또는 결측
실패 조건이웃 부족이나 퇴화한 기하
