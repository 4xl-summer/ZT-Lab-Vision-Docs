pub fn valid_count(&self) -> usize

Number of finite depth values.

유효 샘플 수 조회

결측이 아닌 샘플이나 점의 개수를 반환합니다. 이 값은 저장된 전체 슬롯 수와 다를 수 있으며 적합처럼 유효한 입력 수가 필요한 작업을 실행하기 전에 빠르게 확인할 수 있습니다. 개수만으로 점들의 공간 배치가 퇴화하지 않았다는 사실까지는 알 수 없습니다.

2×2 깊이 영상 [1, 결측, 3, 4]의 총 슬롯 수는 4이고 유효 수는 3입니다. 점군에도 같은 구별이 적용됩니다. 평면을 위한 점이 세 개 이상이라도 모두 한 직선에 있다면 평면을 안정적으로 결정할 수 없으므로 기하 조건을 추가로 검사해야 합니다.
