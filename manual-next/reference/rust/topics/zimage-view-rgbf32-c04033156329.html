pub fn view_rgbf32(&self) -> ZResult<RgbF32View<'_>>

이미지 수명에 묶인 불변 형식별 뷰를 반환합니다. 형식이 다르면 오류입니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<RgbF32View<'_>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

행 또는 뷰의 요소를 읽을 때 메서드가 지정한 픽셀 형식과 현재 영상의 형식이 맞는지 확인합니다. ROI의 보이는 영역과 행 인덱스를 기준으로 해석하고, 빌린 참조라면 이를 제공한 객체보다 오래 보관하지 않습니다.

결과와 조건을 함께 읽기

RGBF32 영상의 불변 뷰이며 픽셀마다 R, G, B 순서의 f32 성분을 제공합니다. 부동소수점 값은 RGB8의 바이트와 다른 표현이므로 0~255의 정수로 자동 해석하지 않습니다. 예를 들어 (0.25,0.5,1.0)은 세 실수 성분이며 각 값의 물리적 의미나 정규화 범위는 입력 생성 과정에 달려 있습니다. ROI의 행을 읽을 때 보이는 폭과 저장 행 간격을 구분합니다. 형식이 맞지 않으면 오류이며, 빌린 뷰는 이미지 수명 안에서만 유효합니다.
