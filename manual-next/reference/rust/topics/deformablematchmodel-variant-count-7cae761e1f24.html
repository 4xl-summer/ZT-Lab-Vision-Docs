pub fn variant_count(&self) -> usize

Returns the number of variants.

반환값과 수명

학습된 변형 모델의 개수를 반환합니다. 검색 결과의 수나 후보 평가 횟수가 아니라 모델 은행에 들어 있는 변형 수입니다. 학습에 전달한 deformation 순서와 결과의 변형 인덱스를 함께 보관하면 각 검출이 어떤 변형과 연결되는지 확인할 수 있습니다.

함께 확인할 값

항목해석

find변형 모델들을 이용한 검색
변형 인덱스결과를 입력 deformation 순서에 연결

모델 은행의 순서

train은 전달된 변형마다 모델을 하나씩 만들어 은행에 넣습니다. 예를 들어 [A,B,C] 세 변형으로 학습했다면 variant_count는 3이며 검색 결과의 variant_index 1은 B를 가리킵니다. 이 수는 후보 포즈를 얼마나 평가했는지 알려 주지 않습니다.

find 보고서의 evaluated와 termination은 검색의 진행을 설명하고 matches의 길이는 반환 후보 수입니다. 세 값은 각각 다른 대상을 세므로 모델 변형 수와 함께 구분해 기록합니다. 결과의 포즈는 해당 변형 모델이 실제 영상에서 찾은 위치입니다.
