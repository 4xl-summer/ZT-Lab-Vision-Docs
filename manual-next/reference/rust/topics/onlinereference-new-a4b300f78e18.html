pub fn new( template: &ZImage, mask: Option<&ZImage>, max_samples: u64, max_pixels: usize, ) -> ZResult<Self>

Starts an empty reference with an optional inclusion mask.

사용과 결과 해석

템플릿의 형식, 크기, ROI 원점과 선택 마스크로 빈 정상 영상 통계 누적기를 만듭니다. 템플릿은 Gray8, Gray16 또는 GrayF32이며 최대 샘플 수는 양수여야 합니다. 마스크가 있으면 같은 크기와 원점의 Gray8 영상이며 0이 아닌 픽셀만 포함합니다.

픽셀 수는 max_pixels 이하이며 마스크에는 포함된 픽셀이 하나 이상 있어야 합니다. 생성 직후 표본 수는 0입니다. 템플릿 영상 자체는 첫 표본으로 자동 누적되지 않으므로 필요한 정상 영상은 update로 전달하십시오.

생성 조건과 초기 상태

예를 들어 2×2 템플릿과 마스크 [255,0;255,0]을 사용하면 왼쪽 두 위치만 통계에 포함됩니다. 전체 픽셀 수는 4이므로 max_pixels는 적어도 4여야 합니다. 기준 통계를 얻으려면 생성 뒤 정상 영상을 update로 추가하십시오.

항목의미와 조건
templateGray8·Gray16·GrayF32 형식과 영상 기하
mask선택적 Gray8, 템플릿과 같은 크기·원점
포함 위치마스크가 0이 아닌 픽셀
포함 개수적어도 한 픽셀 필요
max_samples양수의 최대 누적 영상 수
max_pixels전체 영상 픽셀 수의 상한
초기 count0이며 템플릿을 표본으로 자동 추가하지 않음
