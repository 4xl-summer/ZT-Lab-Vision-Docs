pub fn train_aligned_samples( values: &[ZImage], mask_image: Option<&ZImage>, options: ShapeTrainingOptions, min_fraction: f64, ) -> ZResult<Self>

Trains from aligned sample images.

호출 맥락과 결과 해석

values로 이미 동일 격자에 정렬된 표본 영상을 전달해 공통 에지 모델을 만듭니다. ShapeTrainingOptions는 기준점과 표본화·임계 조건을 정하고 min_fraction은 유지할 에지 출현 비율입니다. 이 함수는 입력 영상들을 정렬하는 기능이 아니므로 호출 전에 대응 위치를 맞춥니다. 얻은 모델의 특징과 이후 검색 결과를 함께 확인합니다.

정렬 표본과 출현 비율

values에는 이미 같은 위치에 정렬된 영상 2..64개를 전달합니다. 모든 영상의 너비·높이와 원점은 같아야 하며 영상 픽셀 수에 표본 수를 곱한 작업 크기는 100000000 이하여야 합니다. 이 함수는 영상의 위치를 자동 정렬하지 않습니다.

min_fraction은 0보다 크고 1 이하인 에지 출현 비율입니다. 예를 들어 표본 4개에 0.75를 지정하면 비율 기준은 3/4입니다. 옵션의 reference와 sample_step, 선택 마스크를 확인하고 만들어진 모델의 특징과 실제 검색 결과를 검토합니다.
