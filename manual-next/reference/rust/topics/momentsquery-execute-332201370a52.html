pub fn execute(&self) -> ZResult<QueryExecution<MomentsResult>>

Executes the plan, retaining its independently shareable captures.

결과 해석과 수명

영역 모멘트 계획을 실행하고 QueryExecution에 MomentsResult와 공유 가능한 캡처를 반환합니다. 계획을 만들 때와 실제 측정할 때를 구분합니다. 실행 뒤 moments의 불변 값들을 구성요소 순서와 연결하고 오류는 ZResult로 처리합니다.

모멘트 계획 실행

execute는 타입 지정 MomentsQuery를 실행하고 QueryExecution<MomentsResult>를 ZResult로 반환합니다. 계획을 만든 시점과 계산을 실행하는 시점은 다르며 결과가 실제 Moments 종류인지도 실행 과정에서 확인합니다.

MomentsResult는 영역별 RegionMoments 목록을 소유하고 moments 접근자는 그 목록의 불변 슬라이스를 빌려 줍니다. 영역 개수와 각 영역의 면적·중심 등은 입력 마스크 및 연결 조건과 함께 읽어야 합니다. 빈 목록과 실행 오류는 다른 상황입니다.

예를 들어 두 대각선 전경 픽셀을 연결하는 조건을 바꾸면 한 영역 또는 두 영역이 될 수 있습니다. 동일한 픽셀 집합이라도 영역을 나누는 조건이 달라지면 결과 목록의 수와 각 중심이 달라질 수 있습니다. 사용한 입력과 연결 방식을 결과에 연결합니다.

실행은 캡처도 유지하며 별도 공유 가능한 캡처의 반환 계약을 따릅니다. moments 슬라이스는 결과를 빌리므로 결과보다 오래 사용하려면 필요한 값을 복사합니다. 쿼리 실행 결과가 다른 유형이라면 타입 오류를 정상 모멘트 값으로 바꾸지 않습니다.
