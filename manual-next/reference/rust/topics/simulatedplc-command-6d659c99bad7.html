사용 순서와 결과 확인

단조 now_ns에서 Request, Publish, Ack, Poll 또는 Reset 상태 전이를 수행하고 PlcDisposition을 반환합니다. 정상 순서는 Idle→Waiting→ResultReady→Idle이며 반복 요청은 Duplicate가 될 수 있습니다. Poll은 대기·결과 상태에서 시간 제한에 도달하면 Faulted로 바꾸고 Reset은 Faulted에서만 허용됩니다. 검증 오류는 상태를 부분 적용하지 않습니다.
