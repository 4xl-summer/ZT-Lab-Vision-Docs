사용과 결과 해석

OCR 모델 바이트의 소유권을 받아 공유 가능한 OCR 엔진을 생성합니다. 모델을 불러올 수 없으면 인식 오류가 반환됩니다.

엔진이 생성된 뒤 영상과 OCR 사양을 read_text에 전달합니다. 모델 파일의 문자 집합과 전처리 요구를 사용자가 선택한 영역·판정 조건과 일치시키십시오.

사용 흐름과 결과 판독

from_bytes는 OCR 모델의 바이트 벡터를 값으로 받아 엔진을 만듭니다. Vec의 소유권이 호출로 이동하므로 기존 벡터를 그대로 다시 사용하는 빌림 호출이 아닙니다. 모델을 읽을 수 없거나 유효하지 않으면 RecognitionEngineResult의 오류가 반환되고 정상 엔진이 생성되었다고 가정할 수 없습니다.

성공한 엔진은 이후 영상과 OCR 사양을 사용하는 read_text 경로에 전달할 수 있습니다. 모델에 맞는 문자 집합과 전처리, 입력 영역 및 판정 조건을 사용자가 선택해야 하며, 엔진 생성 성공만으로 임의 영상에서 문자가 반드시 읽힌다는 뜻은 아닙니다. 판독 결과의 텍스트와 수락·미판독 상태를 구분하여 기록합니다.

예를 들어 특정 문자만 다루는 모델에 다른 문자의 기대값을 바로 적용하면 엔진이 정상 생성되어도 목적 문자열을 판독하지 못할 수 있습니다. 모델 파일의 출처와 버전, 영상 전처리 및 ROI 설정을 함께 보관하고 별도 샘플로 결과를 확인합니다. 모델 바이트 형식이나 지원 문자 범위는 해당 모델의 실제 계약에서 확인합니다.
