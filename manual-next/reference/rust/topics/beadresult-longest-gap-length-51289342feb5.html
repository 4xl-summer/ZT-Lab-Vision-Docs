pub fn longest_gap_length(&self) -> f64

Longest gap in local image units.

가장 긴 간격

최장 간격의 길이를 f64로 반환합니다. 단위는 로컬 영상의 단위이며 별도 보정 없이 바로 밀리미터로 해석하지 않습니다. 세계 좌표 통계가 필요하면 해당 매핑을 명시합니다.

이 값은 해당 입력과 옵션으로 수행한 한 번의 검사 결과입니다.

판독과 사용 순서

검사 경로의 각 탐침에서 결손으로 표시된 연속 구간의 길이를 계산한 값입니다. 구현은 경로의 인접 점 간 거리를 사용해 양 끝 탐침에는 인접 구간의 절반을, 내부 탐침에는 좌우 인접 구간 길이 합의 절반을 가중치로 줍니다. 결손이 이어지면 이 가중치를 누적하고 중단되면 새 구간을 시작해 최댓값을 보관합니다. 예를 들어 간격 2인 직선 경로의 내부에서 결손 탐침 두 개가 이어지면 각각 2씩 더해 4입니다. 결과는 영상 로컬 길이이므로 세계 단위가 필요할 때 보정 관계를 따로 적용합니다.
