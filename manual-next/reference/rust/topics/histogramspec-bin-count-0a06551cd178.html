pub fn bin_count(self) -> usize

Number of bins.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언은 usize입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

히스토그램 구간의 빈 수와 하한·상한을 나타냅니다. 예를 들어 256개 빈과 0부터 256까지의 경계는 정수 밝기 구간을 구분하는 설정입니다. 구간 설정과 실제 입력 형식을 함께 기록하세요.

빈 개수와 범위 읽기

bin_count는 HistogramSpec에 지정된 빈의 개수를 usize로 돌려줍니다. 이것은 포함된 픽셀 수가 아니라 밝기 값을 나누는 구간의 개수입니다. 같은 빈 수라도 하한과 상한이 다르면 각 빈의 밝기 폭이 달라집니다.

사용할 때의 판독

예를 들어 256개 빈과 범위 0부터 256까지라면 균일한 구간 폭은 1입니다. 같은 범위를 16개로 나누면 폭은 16이므로 한 빈에 더 넓은 밝기가 모입니다. count를 읽을 때 lower와 upper, 결과 히스토그램의 채널과 함께 기록해야 서로 다른 설정을 혼동하지 않습니다.
