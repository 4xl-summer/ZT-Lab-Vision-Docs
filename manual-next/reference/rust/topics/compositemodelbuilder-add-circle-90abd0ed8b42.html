Adds a fixed circle.

사용과 결과 해석

중심과 반지름으로 고정 원 특징을 추가하고 특징 인덱스를 돌려줍니다. 선택적 프레임이 있으면 해당 좌표계와 연결되며 유효하지 않은 참조나 기하는 그래프 검증에서 거부됩니다.

반환된 인덱스로 add_circle_center를 추가할 수 있습니다. 중심 좌표와 반지름은 모델에서 사용하는 좌표계와 단위를 일관되게 지정하십시오.

판독과 사용 순서

이 호출은 이미지에서 원을 검출하는 대신 지정한 중심과 반지름을 가진 고정 특징을 그래프에 넣습니다. id는 특징을 식별하고 반환 usize는 그래프 내부의 특징 인덱스이므로 같은 종류의 번호로 혼동하지 않습니다. frame이 Some이면 이미 정의된 해당 프레임에서 중심을 해석합니다. 중심 (1,2), 반지름 3인 원을 지정했다면 중심에서 3만큼 떨어진 위치가 원 경계입니다. 모델에 고정 원을 등록했다고 카메라에서 그 원을 관측했다는 뜻은 아닙니다. 성공으로 받은 인덱스는 원 중심을 추출하는 의존 특징에 사용할 수 있습니다.

항목판독 기준

frame선택적 기존 좌표 프레임
