Scale and rotation invariant feature model.

호출 맥락과 결과 해석

방향과 다중 해상도를 가진 특징 모델을 바이트 형식으로 직렬화합니다. 반환 바이트 벡터는 모델과 독립된 값이며 이미지나 검색 결과 전체를 저장하는 호출은 아닙니다.

모델 종류에 맞는 from_bytes로 복원한 다음 검색 영상과 옵션을 별도로 제공합니다. 저장한 바이트를 원형 그대로 보관하고 동일한 입력으로 복원 전후의 모델 특징과 검색 결과를 비교할 수 있습니다.

조건과 결과 판독

학습된 InvariantFeatureModel을 소유 Vec<u8>로 직렬화합니다. 반환 벡터는 모델에서 빌린 슬라이스가 아니며 별도 값으로 보관할 수 있습니다. 직렬화는 검색 영상, 마스크 또는 해당 영상의 검색 보고서를 실행·저장하는 호출이 아닙니다.

같은 모델 형식의 from_bytes로 바이트를 복원한 다음, 검색할 때 영상과 FeatureMatchOptions를 다시 지정합니다. 예를 들어 저장 전후를 비교하려면 같은 입력과 옵션으로 특징·결과를 비교하고, 복원 오류를 빈 검색 결과로 해석하지 않아야 합니다.
