사용과 결과 해석

엔진에 결합된 AiModelSpec을 값으로 반환합니다. 이 설정은 모델을 생성할 때 지정된 입력 및 결과 해석 계약을 확인하는 데 사용합니다.

추론 전 처리와 출력 해석을 다른 모델의 사양과 혼동하지 마십시오. 반환 사양을 확인한 뒤 run의 이미지 영역과 옵션을 선택합니다.

모델 사양을 읽는 순서

spec은 엔진 생성 시 결합한 AiModelSpec을 값으로 반환합니다. 이 사양은 작업 종류와 입력 폭·높이·채널 수, 클래스 수, 호출자가 선언한 모델 버전으로 구성됩니다. 반환값을 읽는 것만으로 추론이 실행되거나 엔진의 모델이 변경되지는 않습니다.

task는 분류·탐지·분할·이상 중 결과 해석에 사용할 종류입니다. 예를 들어 width=64, height=32이면 모델의 지정 입력 격자는 64×32입니다. channels는 1 또는 3이며 model_version은 호출자가 지정한 추적 ID로 모델 내용의 해시가 아닙니다. 실제 추론은 영상, 영역과 실행 옵션을 run에 전달합니다.
