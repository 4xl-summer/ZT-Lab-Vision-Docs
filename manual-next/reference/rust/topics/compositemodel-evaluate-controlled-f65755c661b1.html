pub fn evaluate_controlled( &self, image: &ZImage, unit: CompositeUnit, token: Option<&PhotometricCancellation>, timeout: Option<Duration>, ) -> Result<CompositeResult, CompositeExecutionError>

Evaluates with cooperative cancellation and an optional nonzero timeout.

사용과 결과 해석

영상과 요청 단위로 평가하면서 선택적 취소 토큰과 시간 제한을 받습니다. 취소 및 시간 제한은 협력적 제어이며 실행 오류는 CompositeExecutionError로 전달됩니다.

계산이 완료되어 결과를 받은 경우에도 전체 상태와 개별 특징·공차 상태를 검사하십시오. 실행 중단을 불합격 측정값으로 바꾸지 말고 별도의 실행 실패로 다루는 것이 적절합니다.

판독과 사용 순서

모델과 영상, 단위 설정을 전달하고 취소 토큰과 시간 제한을 선택적으로 지정합니다. 취소와 제한 시간은 협력적 제어이므로 계산 단계가 취소 요청을 확인하는 지점에서 중단되며 즉각적인 선점 중단 시간은 약속하지 않습니다. 허용 시간 옵션을 제공할 때에는 0이 아닌 기간을 사용합니다. 실행에 실패하거나 취소된 경우 반환 오류를 검사하고, 정상적으로 CompositeResult를 얻었다면 그 안의 전체 상태와 특징·공차별 상태를 각각 확인합니다. 실행이 중단된 사건과 값이 계산된 뒤 공차를 벗어난 FAIL 판정은 다른 사건입니다.
