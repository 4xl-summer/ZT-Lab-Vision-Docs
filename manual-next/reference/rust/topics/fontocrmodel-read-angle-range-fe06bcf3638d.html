각도 범위로 판독

min, max, step으로 지정한 도 단위 각도 범위에서 폰트 판독을 시도합니다. 반환 타입의 오류, None과 Some 결과를 각각 구분합니다.

범위와 간격이 바뀌면 탐색 조건도 달라집니다. 선택된 각도와 판독된 문자, 전체 및 문자별 수락을 확인하고 이 실행의 조건 밖에 대한 정확도를 추정하지 않습니다.

각도 범위의 OCR 판독

FontOcrModel.read_angle_range는 image와 FontOcrOptions에 대해 min, max, step으로 지정한 도 단위 각도를 시도합니다. 반환은 RecognitionEngineResult<Option<FontAngleRead>>이므로 엔진 오류, 정상적인 None, Some 판독의 세 경우를 구분합니다.

예를 들어 -10도부터 10도까지 5도 간격을 지정하면 -10, -5, 0, 5, 10도를 시도합니다. 격자는 최소값과 min+k×step ≤ max인 값을 포함하며 최대 360회를 허용합니다. min과 max는 -360도 이상 및 360도 이하의 유한 값이고 step은 양의 유한 값이어야 합니다. 범위나 간격을 바꾸면 시도할 방향과 작업량도 달라질 수 있습니다.

적용과 판독을 더 살펴보기

각도 격자는 min에서 시작해 min+k×step이 max 이하인 값을 사용합니다. min, max, step은 유한해야 하고 min은 -360도 이상, max는 360도 이하이며 step은 양수입니다. 한 실행에서 허용되는 시도는 최대 360개이므로 너무 좁은 간격으로 넓은 범위를 지정하면 오류가 됩니다. 회전은 입력 캔버스를 유지하므로 회전된 문자가 경계에서 잘리는지 확인해야 합니다. Some 결과가 있으면 그 각도에서의 인식 내용과 문자별 판정을 읽고, 다른 각도 전체에서의 정확도가 보장되었다고 추론하지 않습니다. None은 선택 판독이 없다는 정상 결과이며 잘못된 각도 범위의 오류와 구별합니다.
