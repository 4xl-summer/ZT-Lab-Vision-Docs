pub const fn height(&self) -> usize

이미지 높이를 픽셀 단위로 반환합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언은 usize입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

이 값은 현재 영상이 보이는 영역의 크기 또는 배치를 해석할 때 사용합니다. ROI를 만든 영상에서는 원본 전체 크기와 현재 영역의 크기·원점을 혼동하지 말고 각 값을 함께 기록하세요.

ROI의 세로 행 수

height는 현재 ZImage가 보이는 영역의 세로 픽셀 수를 반환합니다. ROI 영상에서는 부모 영상 전체 높이가 아니라 ROI의 행 수입니다. 행의 개수와 한 행이 저장소에서 차지하는 바이트 간격은 다른 정보입니다.

항목의미와 확인
원본 예높이 8픽셀
ROI 예3×2픽셀
ROI height2행
로컬 행0과 1
별도 정보ROI 원점과 row stride

사용할 때의 판독

예를 들어 원본이 10×8이고 ROI의 폭과 높이가 3×2이면 그 ROI의 height는 2입니다. 로컬 행 인덱스는 0과 1이며 원본의 해당 위치는 ROI 원점을 반영해 해석합니다. 실제 행을 읽을 때는 픽셀 형식과 행 접근 함수의 조건도 확인하세요.
