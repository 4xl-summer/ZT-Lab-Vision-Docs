pub fn valid_count(&self, index: usize) -> ZResult<usize>

Returns the valid pixel count for an aligned image.

사용과 결과 해석

지정한 입력 영상 인덱스에 대응하는 정렬 영상에서 유효한 픽셀 수를 반환합니다. 존재하지 않는 인덱스는 오류입니다. 값은 영상 픽셀의 밝기 합이나 정합 점수가 아닙니다.

공통 격자의 전체 면적과 이 수를 비교하면 해당 영상이 유효하게 채운 범위를 파악할 수 있습니다. 실제 픽셀 위치가 필요하면 같은 인덱스의 유효 마스크를 획득하십시오.

유효 픽셀 수를 해석하기

index는 입력 영상 배열에서 정렬 결과를 조회할 영상의 위치입니다. valid_count는 그 영상이 공통 격자에 정렬되었을 때 유효 표본으로 채운 픽셀 수를 반환합니다. 영상의 총 밝기나 일치 점수가 아니며 존재하지 않는 인덱스는 오류입니다.

예를 들어 공통 격자가 10×10이고 해당 영상의 valid_count가 80이면 격자 100픽셀 중 80개가 유효합니다. 어느 위치가 유효한지는 개수만으로 알 수 없으므로 같은 인덱스의 validity 마스크를 획득하십시오. 영상의 0 밝기와 유효하지 않은 픽셀은 다른 개념입니다.
