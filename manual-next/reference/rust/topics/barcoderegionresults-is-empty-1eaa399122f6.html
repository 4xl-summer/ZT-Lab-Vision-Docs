빈 결과 확인

결과 항목이 없는지 bool로 반환합니다. 빈 결과는 해당 탐색에서 항목이 없다는 뜻이며 영상에 심볼이 전혀 없다는 보장은 아닙니다.

이 컬렉션은 결과를 소유하고 get과 iter가 돌려주는 뷰는 그 컬렉션을 빌립니다. 뷰에서 얻은 참조는 소유 컬렉션보다 오래 사용할 수 없습니다.

빈 컬렉션 판독

is_empty는 결과 컬렉션에 저장된 영역별 항목이 없는지를 bool로 반환합니다. len이 0인 경우 참이며 판독이 예외로 실패한 경우와 정상적으로 비어 있는 컬렉션을 구분해야 합니다.

빈 결과는 이 실행의 입력과 설정에서 반환된 항목이 없다는 사실입니다. 검색 ROI, 허용 형식과 회전 조건에 따라 심볼을 놓칠 수 있으므로 전체 영상에 코드가 없다는 단정은 하지 않습니다.

비어 있지 않다면 iter 또는 get으로 각 영역을 읽고 read의 상태와 길이 수락을 따로 확인합니다. 코드가 읽혔는지와 결과 컨테이너가 비었는지는 서로 다른 질문입니다.

BarcodeRegionResults가 결과를 소유하며, 이 컬렉션이 돌려주는 뷰는 원본을 빌립니다. 필요한 데이터를 원본보다 오래 보관한다면 호출자가 소유 값으로 복사합니다.
