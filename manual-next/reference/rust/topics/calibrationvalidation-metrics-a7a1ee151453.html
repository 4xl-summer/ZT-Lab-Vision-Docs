pub fn metrics(&self) -> &CalibrationMetrics

Returns aggregate error metrics.

사용과 결과 판독

대응점들의 보정 오차를 요약한 CalibrationMetrics를 결과에서 빌립니다. 평균이나 RMS는 한 점의 큰 오차를 가릴 수 있으므로 별도 잔차 슬라이스와 함께 살펴야 합니다. 예측 (12,42) mm와 기준 (12.3,42.4) mm의 한 점 잔차는 0.5 mm입니다. 결과가 정의한 세계 단위와 보류점의 입력 순서를 함께 기록하십시오.

단계확인할 내용
점 수집계가 포함한 평가점 수를 확인합니다.
평균각 점 오차의 평균을 세계 단위로 읽습니다.
RMS와 최대평균과 다른 요약값을 함께 살핍니다.
잔차문제 위치를 찾으려면 개별 잔차도 확인합니다.

검증 수치 읽기

metrics는 같은 보정 검증 실행의 측정 지표를 제공합니다. 지표의 수치가 어떤 잔차나 오차를 나타내는지와 단위를 확인한 뒤 결과 상태 및 입력 기준점과 함께 읽어야 합니다.

항목판독할 내용
metrics검증 실행에서 계산된 지표
단위픽셀·세계 단위 여부 확인
입력동일 실행의 기준점과 보정
해석허용 기준과 별도로 비교

예를 들어 동일한 수치라도 픽셀 단위의 잔차와 세계 좌표 단위의 거리는 직접 비교할 수 없습니다. 기준점의 분포와 검증 대상 범위를 기록하고, 반환된 값이 있다고 해서 장비 전체 범위의 정확도가 자동 보장된다고 보지 않습니다.
