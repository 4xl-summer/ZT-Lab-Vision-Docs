pub fn encode(&self, max_bytes: usize) -> ZResult<Vec<u8>>

Serializes the model using the existing codec.

비드 기준 직렬화

max_bytes 한도를 지정해 모델을 소유 바이트 벡터로 직렬화합니다. 한도를 초과하거나 저장 형식 처리에 실패하면 ZResult 오류로 반환됩니다.

바이트 벡터는 모델의 참조가 아니므로 독립적으로 보관할 수 있습니다. 입력 영상의 형식과 기하 및 학습 옵션을 같이 기록해 복원한 모델의 출처를 확인합니다.

비드 모델 바이트 저장

encode는 max_bytes 한도를 받아 모델을 소유 Vec<u8>로 직렬화합니다. 제한이나 인코딩이 유효하지 않으면 ZResult의 오류를 처리하며, 성공한 바이트는 모델을 빌리는 슬라이스가 아닙니다.

저장할 때 기준을 학습한 영상의 기하, ROI 로컬 경로 및 설정을 함께 기록합니다. 바이트를 다시 읽었다는 사실과 입력 영상에 올바르게 적용되는지는 다른 확인입니다. 다른 원점의 영상에 동일한 경로를 쓰기 전에 좌표를 맞춥니다.

decode는 template과 바이트, 최대 바이트·탐침·작업 한도를 받아 모델을 복원합니다. 복원된 기준의 경로와 실제 검사 프레임을 대조하고 별도 영상으로 성능을 점검합니다. 직렬화 성공은 판정 정확도의 보장이 아닙니다.

max_bytes는 직렬화 데이터 크기 제한이며 바이트 벡터의 원소 개수는 데이터의 바이트 수입니다. 상한을 넘는 입력을 성공한 모델 저장으로 취급하지 않습니다.

복원 후 사용할 검사용 영상이 학습 영상과 다른 ROI 원점을 가지면 저장된 로컬 경로의 기준도 확인해야 합니다. Encode는 경로를 보존하지만 현장의 정렬이나 좌표 변환을 자동으로 수행하지 않습니다.

저장 바이트와 입력 영상에 적용한 학습 옵션을 함께 보관하면 모델을 다시 찾을 때 어느 경로와 조건으로 만들어졌는지 확인할 수 있습니다. 바이트 크기가 작다는 사실은 탐침 수나 검사 정확도를 의미하지 않습니다.

복원 중 template과 저장된 모델의 형식 또는 기하가 맞지 않으면 오류가 발생할 수 있습니다. 이러한 오류와 성공적으로 복원된 모델의 실제 검사 불합격을 구분합니다.
