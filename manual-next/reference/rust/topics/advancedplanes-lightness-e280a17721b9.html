pub fn lightness(&self) -> ZImage

Returns the independently owned lightness plane.

사용과 결과 해석

Lab 또는 LCH 결과의 첫 번째 성분인 L 명도 평면을 별도 소유 영상으로 얻습니다. 생성된 각 성분 영상은 GrayF64이며 입력 영상의 기하를 유지합니다.

값을 원래 RGB 채널의 8비트 값으로 해석하지 마십시오. 같은 좌표의 second와 third를 함께 사용하면 선택한 색 공간의 한 픽셀을 구성할 수 있습니다.

사용 흐름과 결과 판독

lightness는 Lab 또는 LCh 색 공간의 첫 번째 성분 L 평면을 별도 소유 ZImage로 얻습니다. 반환 평면은 GrayF64이며 색 공간의 명도 값입니다. 원본 RGB8의 한 채널이나 0~255 바이트 배열과 같은 의미로 읽지 않으며, 결과의 크기와 좌표 기하를 나머지 평면과 함께 해석합니다.

같은 위치의 second와 third를 함께 읽으면 선택한 색 공간의 세 성분을 확인할 수 있습니다. Lab에서는 나머지가 a와 b이고 LCh에서는 채도 C와 색상각 h입니다. 예를 들어 같은 L 값이라도 a·b 또는 C·h가 다르면 색 성분은 다를 수 있으므로 명도 하나만으로 전체 색이 같다고 판정하지 않습니다.

이 접근자는 모델 내부를 빌리는 슬라이스 대신 독립 소유 영상 공유를 반환합니다. AdvancedPlanes와 얻은 ZImage는 각자의 소유 범위를 따르며, 원본을 변환하거나 평면을 조회했다고 색 판정 또는 색차 계산이 자동으로 끝나는 것은 아닙니다. 결과와 해당 색 공간 및 입력 프레임을 같이 기록합니다.
