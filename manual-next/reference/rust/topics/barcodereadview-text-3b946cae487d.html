디코딩 문자열

읽은 문자열을 &str로 빌려 반환합니다. 상태와 문자 내용을 함께 확인하고, 결과 소유자보다 오래 보관해야 하면 호출 측에서 소유 문자열로 복사합니다.

BarcodeReadView는 상위 스냅샷을 빌린 읽기 전용 뷰입니다. 반환한 참조는 원본 소유 스냅샷의 수명 안에서만 사용하고 필요하면 값을 복사합니다.

텍스트와 원시 데이터

디코딩된 문자열을 &str로 빌려 반환합니다. 문자열의 빈 여부만으로 판독 성공을 결정하지 말고 status 및 reasons를 먼저 함께 확인합니다. 인식 형식이 필요한 경우 format도 같은 결과에서 읽습니다.

backend_raw_bytes는 백엔드가 제공한 바이트 슬라이스이며 문자열과는 다른 표현입니다. 사람이 읽는 텍스트를 보여 주는 화면과 원시 데이터가 필요한 후속 처리는 각각 필요한 값을 보관합니다. 문자열을 다시 인코딩한 바이트가 원시 바이트와 항상 같다고 가정하지 않습니다.

이 메서드가 돌려주는 참조는 결과에 종속됩니다. 결과 범위 밖에서 텍스트를 유지해야 한다면 호출자가 소유 문자열로 복사합니다. 저장 시 원본 영상 식별자와 판독 상태를 함께 연결하면 이전 프레임의 결과를 새 프레임에 잘못 적용하는 일을 줄일 수 있습니다.

이 접근자는 상위 스냅샷을 빌리는 BarcodeReadView에서 호출합니다. 문자열 참조를 원본 결과보다 오래 보관하려면 소유 문자열로 복사합니다. 판독 내용이 여러 프레임을 오갈 때는 원본 프레임 식별자도 함께 보존합니다.
