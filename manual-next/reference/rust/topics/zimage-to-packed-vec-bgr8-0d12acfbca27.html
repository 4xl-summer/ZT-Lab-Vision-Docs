pub fn to_packed_vec_bgr8(&self) -> ZResult<Vec<u8>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<u8>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

BGR8의 패킹 복사

현재 영상이 해당 픽셀 형식일 때 B, G, R의 8비트 성분를 읽습니다. 픽셀 하나는 3개 성분이며, 빨강 한 픽셀은 순서상 0, 0, 255입니다. 형식이 맞지 않으면 ZResult 오류이므로 성공 뷰나 벡터를 가정하지 않습니다.

항목확인할 내용
형식B, G, R의 8비트 성분

반환패딩 없는 독립 벡터

보이는 ROI의 성분을 행 우선으로 패딩 없이 소유 벡터에 복사합니다. 폭 2, 높이 2이면 성분은 12개입니다. 반환 벡터는 영상의 빌린 참조가 아니며 원본 행 간격의 패딩과 분리해 해석합니다.
