pub fn find_relative_template_matches( &self, image: &ZImage, options: &ExtendedMatchOptions, search_mask: Option<&ZImage>, prior: MatchPosePrior, ) -> ZResult<ExtendedMatchResult>

Finds matches relative to the supplied pose prior.

관련 입력의 확인된 조건

Extended appearance matching model.

호출 맥락과 결과 해석

prior 포즈를 기준으로 위치와 각도의 오프셋, 배율의 비율 격자를 검색합니다. 절대 좌표 격자를 그대로 해석하는 검색과 달리 설정값을 기준 포즈와의 관계로 읽어야 합니다. 기준이 달라지면 같은 상대 격자도 다른 포즈들을 나타냅니다.

예상 포즈와 오프셋 범위를 함께 보관해야 같은 검색을 재현할 수 있습니다. 결과는 독립 스냅샷이고 종료 진단도 포함하므로, 후보가 없으면 기준 포즈와 상대 범위 및 검색 조건을 차례로 확인합니다.

상대 격자의 기준

이 경로는 prior의 position과 angle에 격자 오프셋을 적용하고 scale_x, scale_y에는 배율 비율을 적용합니다. 예를 들어 prior의 x가 20이고 위치 오프셋이 +3이면 해당 기준점 후보의 x는 23입니다. prior와 옵션의 위치는 검색 영상 ROI 로컬 좌표입니다.

예상 포즈는 후보를 평가하는 단순 우선순위가 아니라 상대 격자의 기준이라는 점에서 find_extended_matches_with_prior와 구분됩니다. 기준 포즈, 상대 범위와 예산을 모두 보관하고 반환 matches와 종료 상태를 같이 확인합니다.
