fn into_shared_ops(self) -> Self::Target

Transfers the owned engine representation out of the facade owner.

변환과 소유권

facade 소유 값을 소비하고 연관 타입 Target에 해당하는 내부 표현의 소유권을 반환합니다. 반환 타입과 구체적인 표현은 이 트레이트를 구현한 타입이 정합니다.

호출 후 이동된 원래 값을 다시 사용할 수 없으므로 먼저 필요한 작업을 마치십시오. 읽기만 필요하다면 해당 구체 타입의 빌림 API가 있는지 확인해 소유권 이전과 구분하십시오.

호출과 결과 판독

IntoSharedOps::into_shared_ops는 facade 소유 값을 소비하고 구현이 정한 공유 ops 표현을 반환합니다. 공유 표현이라는 말만으로 모든 구현이 동일한 타입이거나 값이 깊게 복사된다고 가정하면 안 됩니다.

실제 FeatureModel 구현의 Target은 Arc<ops::FeatureModel>이며 메서드는 모델의 공유 엔진 소유권을 반환합니다. 호출한 facade 값은 이동되지만 반환된 Arc가 공유 자원을 보유합니다. 다른 구현에서도 같은 Target을 쓴다고 추론하지 말고 해당 구현 선언을 확인하십시오.

예를 들어 변환하기 전에 원본 facade 값이 더 필요한 경우 그 타입이 제공하는 공유·복제 방법이 있는지 먼저 확인해야 합니다. 반환된 공유 표현의 수명과 facade 변수의 이동을 구별하면 사용 종료 시점과 소유권을 올바르게 관리할 수 있습니다.
