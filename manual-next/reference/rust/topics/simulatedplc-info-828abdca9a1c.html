핸드셰이크 상태 관찰

info는 모의 PLC의 현재 PlcInfo를 값으로 반환합니다. 상태와 현재·마지막 요청 ID, 결과 코드, 시간 제한과 통계를 스냅샷으로 읽습니다. 이 조회는 명령을 실행하거나 시각을 진행시키지 않으며 실제 PLC와 통신하지도 않습니다.

요청을 제출한 후 Waiting, 결과를 게시한 후 ResultReady 상태를 확인하는 식으로 흐름을 관찰할 수 있습니다. 시간 제한은 나노초이며 만료 여부는 적절한 now_ns를 사용한 Poll에서 판정합니다. info 조회만으로 시간 초과 처리가 수행되었다고 가정하지 마십시오.
