Runs the existing bead quality inspection with explicit masks and coordinate mapping.

비드 품질 검사

학습 영상과 검사 영상, BeadQualityOptions 및 선택적인 좌·우 포함 배열과 좌표 매핑을 사용해 품질 결과를 계산합니다. 결과는 BeadQualityResult입니다.

좌·우 선택 배열이 경로 표본 순서와 대응해야 하며 세계 좌표를 쓰는 경우 매핑의 기준과 단위를 확인합니다. 픽셀 단위와 물리 단위 결과를 변환 없이 비교하지 않습니다.

학습·검사 영상의 품질 비교

학습 영상과 검사 영상, BeadQualityOptions 및 선택적인 left·right 포함 슬라이스를 사용해 품질을 평가합니다. world 또는 world_maps로 좌표 매핑을 제공할 수 있으며 결과는 BeadQualityResult를 담는 ZResult입니다.

두 영상과 기준 경로가 같은 대상 위치를 가리키는지 먼저 확인합니다. 탐침별 선택 배열을 사용하면 각 값이 경로의 같은 인덱스에 대응해야 합니다. 순서를 바꾸거나 다른 ROI의 배열을 사용하면 선택된 검사 위치가 달라집니다.

픽셀 기준의 길이와 세계 좌표의 길이는 서로 다른 단위입니다. 제공한 변환 또는 좌표 맵이 경로의 프레임과 맞는지 확인하고, 결과를 다른 실행과 비교할 때 사용한 매핑과 단위를 함께 보관합니다.

품질 결과의 탐침과 위반 구간을 살펴 어느 위치에서 차이가 나타났는지 확인합니다. 정렬이 틀어진 입력에서 생긴 차이를 곧바로 비드 두께 결함으로 단정하지 말고 입력 기하와 모델 기준을 먼저 대조합니다.
