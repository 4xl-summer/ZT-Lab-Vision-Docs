점군 슬롯 읽기

점군의 점을 원래 슬롯 순서로 확인합니다. 유효하지 않은 위치는 결측으로 표시되므로 배열을 필터링해 압축하기 전에는 원래 격자나 다른 결과 배열과 같은 인덱스를 유지할 수 있습니다. 단위와 frame은 점 좌표와 별도 메타데이터로 확인합니다.

예를 들어 [A, 결측, B]를 읽으면 두 번째 위치를 건너뛰지 않습니다. 유효 수는 2지만 슬롯 수는 3이므로 이 값을 대응 배열의 길이와 혼동하지 않습니다. Rust의 points는 빌린 슬라이스이며 해당 점군의 수명 안에서 사용합니다.

확인 항목해석
슬롯결측을 포함한 저장 순서
좌표유효할 때 x, y, z를 포함
결측없는 점을 숫자 원점으로 바꾸지 않음
메타데이터좌표 해석에 단위와 frame 필요
