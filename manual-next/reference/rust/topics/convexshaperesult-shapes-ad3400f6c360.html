pub fn shapes(&self) -> &[ConvexShape]

Returns the immutable measured value.

반환값과 수명

연결 구성요소별 볼록 형상 결과를 불변 슬라이스로 빌립니다. 각 형상은 원본 구성요소 번호, 픽셀 셀 외곽으로 만든 ROI 로컬 볼록 껍질과 최소 면적 회전 사각형을 담습니다. 원본 영상 좌표가 필요하면 ROI 원점과의 관계를 적용합니다.

성분과 좌표를 확인하기

각 ConvexShape는 성분 번호와 볼록 껍질, 최소 면적 회전 사각형을 묶습니다. 껍질은 전경 픽셀 중심이 아니라 픽셀 셀 외곽을 둘러싸며 시작점을 마지막에 반복하지 않습니다. 표시 코드에서 닫힌 선이 필요하면 마지막 점에서 첫 점으로 연결합니다.

결과는 ROI 로컬 좌표입니다. 예를 들어 원본에서 ROI 원점이 (10,20)이고 로컬 점이 (2,3)이면 원본에 표시할 위치는 (12,23)입니다. 반환 슬라이스는 ConvexShapeResult를 빌리므로 결과 객체가 살아 있는 동안 읽고, 빈 성분 목록도 정상 결과로 처리합니다.
