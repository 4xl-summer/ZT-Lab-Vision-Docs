Returns the original model options.

반환값과 수명

학습 모델이 보유한 InvariantFeatureOptions를 값으로 반환합니다. 피라미드 수준, 패치와 배율·방향 범위 등 학습 구성을 확인할 때 사용합니다. 검색의 대응과 기하 검증 옵션은 find에 따로 전달하므로 두 설정을 혼동하지 않습니다.
