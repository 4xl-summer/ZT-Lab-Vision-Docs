fn into_core(self) -> Self::Target

Transfers the owned engine representation out of the facade owner.

변환과 소유권

facade 소유 값을 소비하고 연관 타입 Target에 해당하는 내부 표현의 소유권을 반환합니다. 반환 타입과 구체적인 표현은 이 트레이트를 구현한 타입이 정합니다.

호출 후 이동된 원래 값을 다시 사용할 수 없으므로 먼저 필요한 작업을 마치십시오. 읽기만 필요하다면 해당 구체 타입의 빌림 API가 있는지 확인해 소유권 이전과 구분하십시오.

호출과 결과 판독

IntoCore::into_core는 facade 소유 객체의 self를 소비하고 구현 타입의 연관 Target을 반환합니다. 호출 후 원래 facade 변수를 다시 사용하는 경로가 아니라 반환된 표현이 새 소유자가 됩니다.

ZImage 구현에서는 Target이 CoreImage이며 내부 코어 영상을 픽셀 복사 없이 꺼냅니다. 예를 들어 facade 영상을 코어 연산에 넘기기 위해 이 메서드를 호출했다면 이후에는 반환한 CoreImage를 사용하고 이동한 ZImage를 다시 참조하지 않습니다.

픽셀을 변경하지 않고 관찰만 하려는 요구와 표현의 소유권을 넘기는 요구는 다릅니다. 필요한 빌림이나 공유 API가 공개되어 있는지는 구체 타입에서 확인하십시오. 다른 구현에 대해서는 Target과 자원 관계를 해당 구현의 선언에서 검토해야 합니다.
