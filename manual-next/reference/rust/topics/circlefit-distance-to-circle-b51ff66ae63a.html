pub fn distance_to_circle(&self, other: &CircleFit) -> Result<f64, ZError>

Nonnegative minimum distance between two circle boundaries.

사용과 결과 해석

두 원 경계 사이의 음이 아닌 최소 거리를 반환합니다. 경계가 만나면 0이며 서로 떨어져 있거나 한 원이 다른 원 안에 접하지 않고 있으면 그 경계 간 간격입니다.

예: 반지름 2와 3인 원의 중심 간 거리가 8이면 간격은 8−2−3=3입니다. 동심원 반지름이 2와 3이면 경계 간 거리는 1입니다. 결과는 입력 좌표 단위입니다.

두 원 경계의 거리 계산

중심 사이 거리를 d, 반지름을 r₁과 r₂라 할 때 원이 서로 바깥에 떨어져 있으면 경계 간 거리는 d−r₁−r₂입니다. 한 원이 다른 원 안에 있으면서 경계가 닿지 않는 경우에는 |r₁−r₂|−d입니다. 두 경계가 교차하거나 접하면 최소 거리는 0입니다.

단계 또는 항목확인할 내용
외부 분리d > r₁+r₂이면 d−r₁−r₂
내부 분리d < |r₁−r₂|이면 |r₁−r₂|−d
교차·접촉경계가 만나므로 0
외부 예r₁=2, r₂=3, d=8 → 3
동심 예r₁=2, r₂=3, d=0 → 1
단위두 원의 공통 좌표 단위

결과를 사용할 때

반지름 2와 3, 중심 거리 8이면 8−2−3=3입니다. 같은 반지름의 동심원은 |3−2|=1이고 중심 거리가 5이면 외접하므로 0입니다. 결과는 중심과 반지름에 사용한 좌표 단위입니다. 입력 원이 서로 다른 좌표계라면 먼저 공통 기준으로 변환해야 합니다.
