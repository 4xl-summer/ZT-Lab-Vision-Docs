Rust
fn into_ops(self) -> Self::Target

Transfers the owned engine representation out of the facade owner.

변환과 소유권

facade 소유 값을 소비하고 연관 타입 Target에 해당하는 내부 표현의 소유권을 반환합니다. 반환 타입과 구체적인 표현은 이 트레이트를 구현한 타입이 정합니다.

Copy가 아닌 값은 호출 시 이동되므로 이후 원래 값을 다시 사용하려면 먼저 필요한 작업을 마치십시오. 읽기만 필요하다면 해당 구체 타입의 빌림 API가 있는지 확인해 소유권 이전과 구분하십시오.

호출into_ops
대상 타입구현별 연관 타입 Target

Rust에서 확장 메서드를 사용하려면 해당 bridge 트레이트를 스코프에 가져와야 합니다. 구체 구현의 수명과 오류 조건을 함께 확인하십시오.

IntoOps 브리지의 소유 관계

into_ops의 선언은 self를 받아 Self::Target를 돌려줍니다. 파사드를 소비해 Ops 표현 반환이라는 방향을 먼저 확인합니다. Target은 각 구체 구현이 정하는 연관 타입이며 트레이트 이름만으로 임의의 다른 엔진 타입과 변환된다고 추론하지 않습니다.
