이 멤버의 추가 계약 설명은 확인되지 않았습니다.

분할 또는 이상 맵

분할 또는 이상 출력이면 독립 공유 ZImage를 Some으로 반환합니다. 분류나 검출 출력에는 해당 맵이 없어 None입니다. 맵 수치와 표시색을 구분해 읽습니다.

AiTask와 입력 조건을 결과에 함께 보관합니다. 빌린 슬라이스는 AiResult가 살아 있는 동안 사용하며, acquire_map의 반환 영상은 별도의 소유 공유입니다.

작업 종류별 맵 유무

acquire_map은 AiResult가 분할 또는 이상 탐지 출력일 때 해당 맵을 독립 소유 ZImage 공유로 Some에 담아 반환합니다. 분류와 검출 출력에는 해당 맵이 없어 None을 반환합니다. None은 모든 추론이 실패했다는 뜻이 아니므로 AiTask와 실제 결과 종류를 함께 확인해야 합니다.

예를 들어 동일한 입력을 분류 모델에 사용하면 클래스 결과를 읽을 수 있어도 acquire_map은 None일 수 있습니다. 분할 모델이라면 Some 영상의 픽셀 형식과 값 의미를 해당 작업의 후처리 계약으로 해석합니다. 맵을 표시할 때 사용한 색상표와 실제 픽셀 수치는 다르므로 수치 판정에 표시색을 그대로 쓰지 않습니다.

적용과 결과 확인

반환된 Some 영상은 결과와 별도의 소유 공유입니다. AiResult를 빌리는 슬라이스와 달리 영상 핸들의 수명을 별도로 관리하고, 결과가 사용된 입력 ROI와 맵의 크기를 함께 기록하세요. 서로 다른 모델이나 전처리 설정의 맵을 비교할 때는 클래스 번호 또는 이상 점수의 의미가 일치하는지 먼저 확인합니다.

작업별 결과를 읽는 순서도 중요합니다. 먼저 실행이 성공했는지와 AiTask를 확인한 다음 분류 점수, 검출 목록 또는 맵처럼 해당 작업에 존재하는 출력을 선택합니다. 분할 결과에서 클래스 번호는 모델의 클래스 정의와 연결하고 이상 맵에서는 모델과 후처리에서 정의한 값 범위를 확인하세요. 맵의 크기가 입력 ROI와 다를 수 있는 작업이라면 좌표를 표시하기 전에 실제 반환 크기를 확인해야 합니다. None은 유효한 비맵 작업의 결과일 수도 있으므로 작업 종류를 확인하세요.
