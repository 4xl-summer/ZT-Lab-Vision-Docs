pub fn edge_results(&self) -> &[Option<RegistrationResult>]

Returns measured edge outcomes; fixed edges have no estimate.

사용과 결과 해석

입력 간선 순서의 측정 결과를 읽기 전용 슬라이스로 반환합니다. 항목은 선택적 값이며 고정 간선에는 추정 결과가 없습니다.

None을 수치 0인 추정이나 반드시 실패한 정합으로 바꾸지 마십시오. 같은 인덱스의 edge_optimized와 원래 간선 구성을 함께 확인하면 추정과 고정 상태를 구별할 수 있습니다.

간선별 결과와 고정 여부

edge_results는 입력 간선 순서에 대응하는 Option<RegistrationResult>의 불변 슬라이스를 반환합니다. Some은 해당 간선에 측정 결과가 있음을 나타내고 고정 간선에는 추정 결과가 없어 None입니다. None을 0점짜리 정합이나 반드시 실패한 계산으로 바꾸지 않습니다.

같은 인덱스의 edge_optimized와 원래 간선 설정을 함께 살피면 최적화된 간선과 고정된 간선을 구분할 수 있습니다. 예를 들어 입력 간선 0이 고정, 1이 최적화라면 각 결과도 0과 1의 입력 순서에 맞춰 확인합니다. 결과 항목 수를 영상 수로 해석하지 않습니다.

반환 슬라이스는 MultiRegistration을 빌리므로 소유 객체가 살아 있는 동안 읽습니다. 결과 품질을 보관하려면 필요한 값을 별도로 복사하고, matrices의 common-local→image-local 방향 및 common_index를 함께 기록해 각 간선과 공통 좌표를 연결합니다.

판독과 확인 사례

고정 간선은 이미 주어진 변환을 사용하는 경로이므로 측정 RegistrationResult가 없을 수 있습니다. 따라서 None을 평가 점수 0이나 검출 실패로 치환하면 그래프의 의미가 바뀝니다. 입력 간선의 고정 여부와 edge_optimized를 먼저 보고 해당 인덱스의 선택적 값을 읽습니다.

반환 결과를 데이터베이스나 파일에 남길 때는 간선의 reference·source 인덱스와 결과 순서를 함께 저장합니다. 소유 MultiRegistration을 버린 뒤 빌린 슬라이스 참조를 사용할 수 없으므로 필요한 점수와 상태는 그 전에 소유 값으로 복사합니다.
