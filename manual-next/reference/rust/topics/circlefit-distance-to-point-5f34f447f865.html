pub fn distance_to_point(&self, point: Point2) -> Result<f64, ZError>

Nonnegative minimum distance from a point to this circle boundary.

사용과 결과 해석

점에서 원의 경계까지의 음이 아닌 최소 거리를 반환합니다. 중심과 점의 거리가 d이고 반지름이 r이면 결과는 |d−r|입니다. 잘못된 기하나 비유한 값은 오류입니다.

예를 들어 중심 (0,0), 반지름 5인 원에서 점 (0,2)까지의 경계 거리는 3입니다. 원 내부에 있다는 이유로 음수가 되지 않으며 중심까지의 거리와도 다릅니다.

판독과 사용 순서

입력 점에서 원 중심까지의 거리 d를 구한 다음 반지름 r과의 차이의 절댓값 |d−r|을 반환합니다. 점이 원 내부인지 외부인지는 이 값에 나타나지 않습니다. 중심 (0,0), 반지름 5인 원에서 점 (0,2)는 중심에서 2 떨어져 있으므로 경계까지는 3입니다. 점 (0,8)도 같은 경계 거리 3을 반환합니다. 중심과 점은 같은 좌표계와 길이 단위를 사용해야 하며 유한하지 않은 좌표나 양수가 아닌 반지름은 정상 거리 대신 오류입니다. 원점이나 ROI가 다르면 먼저 공통 좌표로 옮긴 뒤 계산합니다.
