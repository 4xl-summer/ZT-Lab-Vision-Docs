pub fn run( images: &[ZImage], edges: &[RegistrationGraphEdge], common: usize, ) -> ZResult<Self>

Estimates the directed graph and aligns all images to the common grid.

사용과 결과 해석

영상 배열, 쌍별 정합을 정의하는 방향 그래프 간선, 공통 기준 영상 인덱스를 받아 전체 영상을 공통 격자에 정렬합니다. 간선의 reference와 source는 영상 배열의 인덱스를 가리키며 각각의 옵션으로 쌍별 정합을 수행합니다.

결과 행렬은 공통 영상 로컬 좌표에서 각 영상 로컬 좌표로 향합니다. 결과의 정렬 영상과 유효 마스크, 간선별 추정 결과를 함께 확인해 겹치지 않는 영역을 제외하십시오.

방향 그래프와 결과

images는 입력 영상 순서를 정하고 edges의 reference와 source는 그 배열의 인덱스를 가리킵니다. common은 공통 격자로 삼을 영상의 인덱스입니다. 각 간선은 쌍별 정합 설정을 가지며 결과는 전체 영상을 선택된 공통 격자에 맞춘 형태로 반환됩니다.

결과 행렬은 공통 영상 로컬에서 각 입력 영상 로컬로 향합니다. 예를 들어 영상 인덱스 1의 행렬을 적용하면 공통 격자의 한 점에 대응하는 영상 1의 로컬 위치를 얻습니다. 정렬 영상의 값만 보지 말고 valid_count와 유효 마스크를 함께 확인해 대응 표본이 없는 위치를 제외하십시오.

행렬공통 로컬 → 각 영상 로컬
