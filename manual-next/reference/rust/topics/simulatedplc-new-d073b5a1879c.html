사용 순서와 결과 판독

SimPlc::new는 실제 PLC 통신 없이 요청·결과 핸드셰이크를 결정적으로 재현하는 시뮬레이터를 만듭니다. timeout_ns는 나노초 단위의 0이 아닌 제한 시간이며 0은 오류입니다. 생성 직후 상태는 Idle이고 현재 요청 번호, 결과 코드와 통계는 초기값입니다.

정상 흐름에서는 Idle에서 Request를 적용하면 Waiting이 되고, 같은 요청에 Publish를 적용하면 ResultReady, Ack를 적용하면 다시 Idle이 됩니다. 예를 들어 요청 ID 1로 Request와 Publish, Ack를 순서대로 적용할 수 있습니다. 중복 요청과 중복 게시의 처리는 상태와 ID·결과값 조건에 따라 별도 disposition과 통계로 표시됩니다.

시간은 외부에서 command에 전달하는 now_ns로 판단하며 이전 호출보다 감소할 수 없습니다. Waiting 또는 ResultReady에서 시작 시각 이후 timeout_ns 이상이 지난 시점에 Poll하면 Faulted와 TimedOut으로 바뀝니다. 예를 들어 시작 100ns, 한도 50ns라면 150ns의 Poll은 만료 조건에 도달합니다. 실제 네트워크 전송이나 장비의 실행을 의미하지 않습니다.
