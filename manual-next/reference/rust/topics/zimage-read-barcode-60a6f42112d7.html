바코드 형식과 읽기 결과

Rust의 ZImage 호출은 현재 영상에 이 처리를 적용합니다. BarcodeSpec에서 허용 형식 플래그, 회전 시도와 최소 대비를 지정합니다. CODE128과 QR을 함께 허용하려면 해당 플래그를 결합합니다. 형식 선택은 영상의 바코드를 자동으로 모두 찾는다는 보장이 아니므로 입력 영역과 회전 조건을 확인해야 합니다.

현재 영상에서 얻은 결과의 해석에서는 결과의 status와 reasons, format, text, 원시 바이트 및 위치를 함께 읽습니다. NO_READ와 입력 오류는 서로 다른 상황입니다. contrast는 Gray8 (최댓값−최솟값)/255로 정규화한 대비이며 표준 검증기 품질 등급이나 판독 확률이 아닙니다.

Rust 반환 값의 소유와 참조 수명을 시그니처에서 확인합니다. 입력 오류와 실제 계산된 빈 결과는 서로 다른 경로이므로 오류를 정상 판정으로 바꾸지 않습니다.

조건과 결과 판독

BarcodeSpec의 formats는 허용 심볼 종류의 비트 마스크이고 try_rotate는 추가적인 시계 방향 90도 회전을 시도할지 정합니다. min_contrast는 0~1의 유한한 값입니다. 회전 옵션을 끄더라도 백엔드 자체의 판독 방식이 회전된 심볼을 읽을 수 있습니다.

BarcodeRead의 contrast는 Gray8 ROI에서 (최대−최소)/255로 계산한 정규화 대비입니다. backend_raw_bytes는 백엔드 코드워드로 페이로드 바이트가 보장되지 않으며 points도 반드시 모서리 다각형은 아닙니다. status/reasons와 선택적인 format·confidence를 함께 확인하고 판독 실패와 호출 오류를 구분하세요.
