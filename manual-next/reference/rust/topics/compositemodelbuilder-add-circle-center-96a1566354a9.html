Rust
pub fn add_circle_center(&mut self, id: u64, circle: usize) -> ZResult<usize>

Adds the center of an earlier circle.

사용과 결과 해석

앞서 추가한 원 특징의 인덱스를 참조하여 중심점 특징을 추가합니다. id는 새 특징을 식별하고 반환값은 새 특징의 인덱스입니다. 참조가 유효하지 않으면 빌더는 기존 상태를 유지합니다.

원을 먼저 추가하고 받은 인덱스를 circle에 전달하십시오. 파생 중심을 다른 공차나 후속 계산에서 사용할 수 있지만 원의 id와 목록 인덱스를 혼동하면 안 됩니다.

이전 원에서 중심 추가

circle은 앞서 추가된 원 특징의 목록 인덱스이고 id는 새 중심점 특징의 식별자입니다. 두 숫자는 역할이 다릅니다. 성공하면 새 중심 특징의 인덱스를 반환하며 다른 파생 계산에서 사용할 수 있습니다.

항목판독할 내용
원먼저 추가할 원 특징
circle그 원의 목록 인덱스
id새 중심 특징의 식별자
반환생성된 중심 특징 인덱스

먼저 유효한 원을 추가하고 반환된 인덱스를 circle로 전달합니다. 존재하지 않거나 원이 아닌 특징을 참조하면 검증 오류가 될 수 있으며 실패 시 빌더 상태를 확인합니다. 모델을 build한 뒤 영상 평가 결과와 파생 특징을 함께 읽습니다.
