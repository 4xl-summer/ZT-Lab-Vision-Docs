pub fn measure(&self, image: &ZImage) -> ZResult<CircleMeasurementResult>

Evaluates this model on the supplied image.

사용과 결과 판독

검증된 원 모델을 빌려 입력 ZImage의 ROI에서 관측하고 원 계측 결과를 반환합니다. 모델의 기준 형상은 탐색 위치를 정하며 반환 형상이 반드시 기준과 같다는 뜻은 아닙니다. 프로브의 발견 상태와 최종 적합에 채택된 점을 구별하고, 형상이 없거나 피팅에 실패한 결과를 좌표 0으로 대체하지 마십시오. 다른 영상에 재사용할 때 ROI 원점과 검색 범위를 함께 확인합니다.

단계확인할 내용
모델원의 검증된 기준과 설정을 빌립니다.
영상목적 경계가 포함된 ZImage ROI를 전달합니다.
관측발견된 프로브 점과 최종 채택점을 구별합니다.
결과형상 상태와 ROI 좌표 기준을 함께 확인합니다.

호출과 결과 판독

CircleMeasurementModel.measure는 검증된 모델과 입력 ZImage를 빌려 영상 ROI에서 원 경계를 관측합니다. 기준 원은 검색 위치를 정하며 반환된 CircleMeasurementResult의 중심과 반경은 실제 선택점의 적합 결과입니다.

각 프로브의 Found는 에지 후보를 선택했다는 상태이고 used는 최종 적합에 사용되었는지를 나타냅니다. 예를 들어 여덟 위치에서 에지를 찾았어도 일부 점이 다른 경계에 있으면 전부가 적합에 채택된 것은 아닙니다. 수렴과 반복 횟수도 상태와 별도로 살펴보십시오.

관측점이 원호 한쪽에 몰리면 개수만으로 둘레 전체를 확인했다고 볼 수 없습니다. 적합이 없거나 실패한 경우를 반경 0의 정상 원으로 대체하지 말고 결과 status, fit 및 probes를 함께 기록합니다. 다른 ROI의 원과 비교하기 전에 글로벌 원점과 단위를 맞춥니다.

항목확인할 내용
모델기준 중심·반경과 탐색 설정을 빌립니다.
image관측할 영상과 ROI를 전달합니다.
probes발견된 에지와 사용 여부를 구분합니다.
status적합 성공·점 부족·실패를 확인합니다.
fit있을 때 중심과 반경을 ROI 픽셀로 읽습니다.
비교다른 ROI는 공통 좌표로 변환합니다.
