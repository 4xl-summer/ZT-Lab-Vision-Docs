Rust
pub fn ssim( &self, reference: &ZImage, mask: Option<&ZImage>, options: SsimOptions, ) -> ZResult<SsimResult>

Compares this image with a reference, preserving ROI-local geometry. mask is an optional Gray8 weighting image. Options include the explicit work budget; invalid geometry, options, or exhausted work return an error.

구조 유사도 검사

현재 영상과 reference, 선택 Gray8 마스크 및 SsimOptions를 비교하고 SsimResult를 반환합니다. ROI 로컬 기하를 보존하며 잘못된 기하, 옵션 또는 작업량 초과는 오류입니다.

전체 점수, 포함 픽셀 수와 결함 픽셀 수를 구분하고 위치별 맵과 마스크를 함께 확인합니다. 비교 전에 두 영상의 위치가 대응하도록 정렬합니다.

기준과 구조 유사도 검사

현재 검사 영상과 reference, 선택적 Gray8 mask 및 SsimOptions를 사용해 구조 유사도를 계산합니다. 입력은 같은 ROI 로컬 기하를 가리켜야 하며 잘못된 기하나 옵션, 작업량 초과는 ZResult 오류로 전달됩니다.

유사도 창과 경계 처리, 데이터 범위 및 최소 점수는 계산 결과에 영향을 줍니다. 입력 위치가 어긋나면 대상의 이동이 구조 차이로 나타날 수 있으므로 먼저 정렬이 성립하는지 확인하고 원본과 기준의 좌표를 맞춥니다.

SsimResult의 score는 전체 요약, included는 포함 픽셀 수, defect_count는 결함 픽셀 수입니다. 예를 들어 결함 픽셀이 10개라도 연결된 후보가 10개라는 뜻은 아닙니다. 위치는 map과 defect_mask를 통해 별도로 살핍니다.

map은 GrayF64 유사도 영상, defect_mask는 Gray8 마스크의 독립 공유입니다. 입력 마스크가 선택하지 않은 부분을 정상 표본으로 더해 평균하지 않도록 포함 범위를 기록합니다. 결과와 획득 영상의 소유 수명을 각각 관리합니다.
