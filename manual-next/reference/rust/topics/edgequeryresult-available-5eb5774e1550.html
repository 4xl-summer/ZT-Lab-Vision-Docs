pub fn available(&self, feature: u32) -> bool

Returns whether a feature is available.

사용과 결과 해석

feature가 단일 지원 비트이고 실제 요청 또는 계산된 특성인지 반환합니다. 여러 비트를 한 번에 넣으면 true가 아닙니다.

기하 특성은 생성 시 요청해야 하고 기울기 크기·각도는 별도 계산 후 사용할 수 있습니다. 사용할 특성마다 확인하고 미계산 값을 실제 측정값으로 해석하지 마십시오.

특성 비트 하나씩 확인

available(feature)은 요청한 단일 특성 비트가 지원되고 실제로 계산 또는 요청되어 사용 가능한지 bool로 반환합니다. 구현은 비트가 정확히 하나 설정되었는지 확인합니다. 여러 비트를 합친 값이나 0을 넣어 모든 특성의 준비 여부를 한 번에 확인하는 방식이 아닙니다.

예를 들어 비트 1과 비트 2가 각각 필요한 상황이라면 available(1)과 available(2)를 따로 확인합니다. 1|2=3은 두 비트가 설정되어 있으므로 이 호출의 단일 비트 조건에 맞지 않습니다. 기하 특성과 이후 별도로 계산하는 기울기 크기·각도는 생성 및 계산 단계의 조건을 각각 확인해야 합니다.

적용과 결과 확인

true는 지정한 특성을 읽을 수 있다는 뜻이지 특정 에지의 값이 원하는 기준을 통과했다는 뜻은 아닙니다. 에지 선택 시에는 포함된 안정 라벨과 현재 인덱스 방식을 확인하고, 특성의 실제 값을 읽어 판단하세요. 미계산 값이나 지원하지 않는 비트를 0이라는 측정 결과로 대체하지 않습니다.

available은 조회할 특성의 준비 상태를 나타낼 뿐 에지의 개수, 길이나 강도를 돌려주지 않습니다. 예를 들어 크기 특성을 사용할 수 있어도 실제 특정 에지를 선택하는 단계에서 존재하지 않는 라벨을 주면 별도 오류가 발생할 수 있습니다. 지원 비트 하나의 가용성을 확인한 뒤 포함된 에지 목록과 원하는 선택자를 확인하고 해당 특성 값을 읽으세요. 조합 비트가 false라는 결과도 개별 비트가 모두 불가능하다는 뜻은 아닙니다. 지오메트리 특성에 필요한 요청 비트와 기울기를 계산한 뒤 사용할 비트의 목록을 기록하면 어느 단계에서 정보가 준비되었는지 추적하기 쉽습니다.
