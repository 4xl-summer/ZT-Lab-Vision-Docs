pub fn matrices(&self) -> &[[f64; 9]]

Returns common-local to image-local matrices in input order.

사용과 결과 해석

입력 영상 순서대로 각 3×3 변환 행렬을 읽기 전용 슬라이스로 반환합니다. 각 행렬은 공통 영상의 로컬 좌표에서 해당 입력 영상의 로컬 좌표로 향합니다.

방향을 반대로 가정하면 점이나 마스크가 잘못된 위치에 놓입니다. 행렬은 결과 객체가 소유하며 그 객체보다 오래 보관해야 하면 복사하십시오.

공통 좌표에서 각 입력으로

matrices는 공통 영상의 로컬 좌표에서 각 입력 영상의 로컬 좌표로 가는 3×3 행렬을 입력 영상 순서대로 빌립니다. 반환 타입은 &[[f64;9]]이며 행렬 하나는 9개 수치입니다. 공통 좌표에서 입력 좌표로 가는 방향을 입력에서 공통으로 가는 역방향과 혼동하지 않아야 합니다.

예를 들어 입력 영상이 A와 B 두 장이면 결과의 첫 행렬은 A, 둘째 행렬은 B에 대응합니다. 첫 행렬이 항등 변환이라면 공통점 (2,3)은 A의 로컬 점 (2,3)에 대응합니다. 다른 영상의 행렬은 그 영상에 대한 변환을 적용해야 하며 목록을 재정렬하면서 입력 순서를 잃으면 잘못된 이미지에 매핑할 수 있습니다.

적용과 결과 확인

행렬 슬라이스는 MultiRegistration 결과를 빌립니다. 결과보다 오래 숫자를 보관하려면 필요한 행렬을 소유 배열로 복사하세요. 이미지의 ROI 원점이나 유효 마스크도 별도 정보입니다. 변환된 점이 해당 입력 영상 범위와 유효 마스크 안에 있는지 확인한 뒤 차영상이나 모자이크에 사용합니다.

사영 행렬은 점에 적용할 때 동차 좌표의 마지막 성분으로 나누는 해석이 필요합니다. 단순한 이동 행렬이라면 공통점 (2,3)에 x 이동 5, y 이동 1이 적용되어 (7,4)가 될 수 있습니다. 그러나 이는 방향 확인용 예이며 모든 결과가 단순 이동이라는 보장은 아닙니다. 변환 방향을 바꾸려면 적절한 역변환이 필요하고, 역이 존재하지 않는 경우를 무시해서는 안 됩니다. 실제 결과의 유효 마스크도 함께 확인하세요. 정렬된 입력별 영상과 해당 유효 영역은 같은 결과의 입력 순서에 연결해 읽습니다. 행렬이 하나만 필요한 경우에도 어느 영상의 것인지 인덱스를 보관하세요.
