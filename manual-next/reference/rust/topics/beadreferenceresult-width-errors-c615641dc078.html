pub fn width_errors(&self) -> &[Option<f64>]

Returns per-probe width errors.

탐침별 폭 오차

각 탐침의 폭 오차를 Option<f64> 슬라이스로 반환합니다. None인 위치는 오차값이 없는 상태이며 0의 오차로 바꾸어 정상 측정으로 처리하지 않습니다.

참조 또는 슬라이스를 반환하는 항목은 BeadReferenceResult의 수명에 묶입니다. 결과를 오래 보관해야 하면 필요한 값을 소유 자료로 복사합니다.

프로브별 값과 결측 구분

width_errors는 기준 비드와 비교한 각 프로브의 폭 오차를 &[Option<f64>]로 빌립니다. Some 값은 해당 프로브의 계산된 오차이고 None은 그 위치에 오차값이 없음을 뜻합니다. 슬라이스의 순서를 검사 경로의 프로브와 연결해야 어느 위치의 오차인지 알 수 있습니다.

예를 들어 세 프로브의 결과가 [Some(0.2), None, Some(-0.1)]이면 둘째 위치는 0 오차가 아니라 값이 없는 상태입니다. 첫째와 셋째 숫자의 부호와 단위는 기준 및 검사 결과의 계약에 맞춰 해석하고, 셋의 평균을 낼 때 None을 무조건 0으로 넣으면 분모와 의미가 달라집니다.

적용과 결과 확인

inspection의 원래 프로브 상태와 reference_flags, reference_failures, reference_runs를 함께 읽으면 측정 누락과 기준 비교 실패를 구분하는 데 도움이 됩니다. 빌린 슬라이스는 BeadReferenceResult가 살아 있는 동안만 유효합니다. 결과보다 오래 보관하려면 필요한 Option 값을 소유 벡터로 복사하고 경로 및 기준 설정도 함께 남기세요.

오차 배열의 인덱스는 기준과 검사 경로의 프로브 위치를 연결하는 데 사용합니다. 예를 들어 세 개 중 둘째가 None인 상황에서 그 항목을 목록에서 제거하면 뒤의 세 번째 값이 두 번째 위치로 잘못 연결될 수 있습니다. 따라서 누락을 유지한 채 경로와 상태를 함께 표시하세요. 기준 영상과 검사 영상의 정렬이 잘못되면 폭 자체뿐 아니라 같은 위치를 비교하는 전제가 흔들리므로 비교 전에 경로와 ROI를 확인합니다.
