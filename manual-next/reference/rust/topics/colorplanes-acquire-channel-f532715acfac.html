pub fn acquire_channel(&self, index: usize) -> ZResult<ZImage>

Shares one channel; an out-of-range index is an error.

사용과 결과 해석

지정 인덱스의 채널 영상을 독립 공유 핸들로 반환합니다. 범위 밖 인덱스는 오류이며 반환 영상의 소유 수명은 결과 객체와 별도로 관리할 수 있습니다.

공간에 따라 각 채널의 의미가 달라지므로 space를 먼저 확인하십시오. 여러 채널을 획득했다면 같은 좌표의 값을 조합해 한 픽셀을 해석합니다.

채널 공간과 소유권

ColorPlanes는 여러 색 공간 채널을 보유하며 space로 채널이 속한 좌표 공간을 확인할 수 있습니다. acquire_channel(index)는 지정한 채널의 ZImage 공유를 독립 소유 값으로 반환합니다. 범위 밖 인덱스는 빈 영상이 아니라 ZResult 오류입니다.

채널 번호만 보고 어떤 물리량인지 가정하지 말고 먼저 space와 해당 색 공간의 채널 순서를 확인합니다. 여러 채널을 취득했다면 각 영상의 같은 로컬 좌표를 함께 읽어 한 픽셀의 구성 성분을 해석합니다. 예를 들어 세 평면에서 위치 (x,y)를 읽을 때는 모두 같은 위치를 사용합니다.

반환 영상은 결과 객체에서 빌린 슬라이스가 아니라 별도로 소유한 영상 공유입니다. 따라서 취득한 영상과 ColorPlanes의 수명을 구분하고, 각 영상이 더 이상 필요 없을 때 Rust 소유 값의 수명을 마칩니다. 색 변환된 영상을 다시 얻는 to_rgb는 채널 하나를 읽는 것과 별도 작업입니다.

판독과 확인 사례

반환 영상은 해당 채널 저장소를 공유하는 별도 소유 핸들입니다. 여기서 독립 소유는 핸들의 수명에 관한 설명이며 픽셀 데이터를 새로 깊은 복사했다는 뜻으로 단정하지 않습니다. 결과 객체와 반환 ZImage를 각각 변수와 수명으로 관리합니다.

예를 들어 세 채널을 개별 획득해 위치 (2,3)의 값들을 읽는 경우에도 먼저 space가 표현하는 좌표계를 확인해야 세 수치의 의미를 알 수 있습니다. 허용 인덱스가 아닌 값을 지정하면 오류이므로 채널이 없다는 상황을 0값 채널로 대체하지 않습니다.

각 평면의 영상 크기와 원점을 같은 색 변환 결과에서 확인하면 다른 ROI의 채널을 잘못 조합하는 일을 줄일 수 있습니다.
