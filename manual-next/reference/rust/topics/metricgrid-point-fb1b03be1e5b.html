pub fn point(&self, row: u32, column: u32) -> Result<Point2, ZError>

Maps an indexed grid point to world coordinates in the declared length unit.

계산 순서와 결과 확인

행과 열 인덱스를 지정 길이 단위의 물리 격자점으로 바꿉니다. (row,column)은 각각 0부터 시작하며 x=column×pitch_x, y=row×pitch_y입니다. 예를 들어 간격이 (2,3)이고 (row,column)=(1,2)이면 (4,3)입니다. 행·열 범위와 양의 유한 간격, 총 1000000점 제한을 확인합니다.

입력과 계산 확인

항목의미와 조건
입력0기반 row, column
계산x=column×pitch_x; y=row×pitch_y
예간격 (2,3), 인덱스 (1,2) → (4,3)

사용 조건과 결과 판독

MetricGrid::point는 0 기반 row와 column을 격자의 선언된 길이 단위에 있는 Point2로 바꿉니다. 원점은 0행·0열이고 x=column×pitch_x, y=row×pitch_y입니다. row는 세로 인덱스, column은 가로 인덱스이므로 둘을 바꿔 전달하면 다른 점이 됩니다.

예를 들어 pitch_x=2, pitch_y=3이고 row=1, column=2이면 결과는 (4,3)입니다. unit이 mm라면 그 좌표는 mm 기준입니다. 같은 숫자의 픽셀 좌표로 자동 변환되는 것이 아니며 카메라 영상에 투영하려면 해당 보정·포즈 경로가 별도로 필요합니다.

rows와 columns는 양수이고 전체 점 수는 1000000 이하여야 합니다. row와 column은 각각 해당 크기보다 작아야 하며 두 pitch는 유한한 양수입니다. 크기·인덱스·간격이 잘못되거나 좌표 계산이 유한하지 않으면 ZError입니다.

예를 들어 2행 3열 격자의 유효 행은 0과 1, 유효 열은 0·1·2입니다. (1,2)는 마지막 행·열이지만 (2,1)은 범위를 벗어납니다. 결과 Point2는 길이 값을 담는 복사 가능한 값이지 영상의 픽셀이나 이미지 핸들이 아닙니다.
