pub fn distance_to(self, other: Point2) -> Result<f64, ZError>

Euclidean distance to another point, in the input coordinate units.

계산 순서와 결과 확인

두 유한 점의 유클리드 거리를 입력 좌표 단위로 계산합니다. 예를 들어 (0,0)과 (3,4)의 거리는 5입니다. 픽셀 좌표를 넣으면 결과도 픽셀 단위이며 물리 단위를 얻으려면 먼저 같은 물리 좌표계로 변환해야 합니다. 잘못된 계산은 Result 오류입니다.

항목의미와 조건

예(0,0)과 (3,4) → 5
단위입력 좌표 단위

두 점 사이의 거리

distance_to는 현재 Point2와 other 사이의 유클리드 거리를 계산해 Result<f64, ZError>로 반환합니다. 두 점의 x 차이와 y 차이를 각각 제곱해 더하고 제곱근을 취합니다. 입력 또는 계산이 유효하지 않으면 오류를 처리합니다.

예를 들어 (1,2)와 (4,6)의 차이는 (3,4)이므로 거리는 √(3²+4²)=5입니다. 점의 순서를 바꾸어도 이 거리는 같습니다. 결과는 방향 벡터가 아니므로 어느 방향으로 이동해야 하는지는 별도로 계산해야 합니다.

두 점은 같은 좌표계와 단위를 사용해야 합니다. ROI 로컬 점과 전체 프레임 점을 그대로 비교하면 원점 차이가 거리에 섞입니다. ROI 원점이 (100,50)인 로컬 점 (4,3)은 단순 이동 기준으로 글로벌 (104,53)입니다.

픽셀 좌표의 거리는 픽셀 단위이며 별도 보정 없이 밀리미터로 표시하지 않습니다. 실측 길이가 필요하면 먼저 적절한 좌표 변환을 적용하고 그 결과 단위를 기록합니다. 두 점과 반환 거리는 값이어서 영상 핸들을 소유하지 않습니다.
