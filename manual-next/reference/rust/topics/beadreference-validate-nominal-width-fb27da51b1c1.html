pub fn validate_nominal_width( &self, nominal: f64, min_scale: Option<f64>, max_scale: Option<f64>, max_work: usize, ) -> ZResult<BeadNominalValidation>

Tests nominal width against optional relative bounds.

명목 폭 검증

nominal 폭과 선택적인 min_scale, max_scale, max_work를 사용해 학습 폭이 상대 한도에 맞는지 평가합니다. 결과는 BeadNominalValidation입니다.

예를 들어 기준 명목 폭을 바꾸면 같은 학습 폭의 상대 비율도 달라집니다. 폭 단위와 두 배율 한도를 함께 기록하고 호출 오류를 단순 불합격과 구분합니다.

명목 폭과 상대 범위

nominal 폭과 선택적인 min_scale, max_scale 및 max_work를 사용해 학습된 기준 폭을 검증합니다. 반환값은 BeadNominalValidation이며 함수 호출 오류는 ZResult로 구분됩니다.

예를 들어 명목 폭이 10이고 허용 배율을 0.8과 1.2로 정하면 비교를 위한 상대 경계는 8과 12입니다. 실제 결과는 입력 기준 폭과 연산의 규칙을 통해 읽고, 예제 숫자를 현장 허용치로 그대로 사용하지 않습니다.

명목 폭과 모델 폭은 같은 좌표 단위를 사용해야 합니다. 픽셀 단위로 학습한 폭을 별도 보정 없이 밀리미터 값과 비교하면 상대 비율이 의미를 잃습니다. 두 한도와 단위, 입력 모델을 함께 기록합니다.

이 검증은 학습된 기준의 폭을 확인하는 단계입니다. 새 검사 영상의 결함이나 중심 이동을 자동으로 평가하는 작업은 아니므로 해당 검사가 필요하면 inspect 또는 품질 검사 결과를 별도로 확인합니다.
