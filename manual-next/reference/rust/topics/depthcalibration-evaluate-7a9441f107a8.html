pub fn evaluate( &self, raw: &[f64], reference: &[f64], ) -> Result<DepthCalibrationMetrics, ZError>

Evaluates corrected heights against reference heights.

선형 깊이 보정 평가

원시값에 현재 모델을 적용한 뒤 같은 위치의 기준값을 빼서 잔차를 계산합니다. 두 배열은 같은 순서의 대응이어야 하며 비어 있지 않고 길이가 같아야 합니다. 평가 결과는 모델을 다시 학습하지 않고 현재 계수가 기준에 얼마나 맞는지 보여 줍니다.

원시값 0, 1, 2에 scale 2와 offset 1을 적용하면 1, 3, 5입니다. 기준이 이와 같으면 모든 잔차와 RMS가 0입니다. 기준이 하나 달라지면 평균 편향과 최대 오차가 서로 다르게 나타날 수 있으므로 샘플 수와 함께 살펴봅니다.
