Rust
pub fn offer(&mut self, frame: T) -> Result<EnqueueResult, CameraPolicyError>

Consumes one pending frame only if the queue accepts it.

사용과 결과 해석

호출자가 공급한 프레임 하나를 큐에 넣고 성공할 때만 대기 프레임 수를 하나 줄입니다. 대기 중인 트리거가 없으면 오류입니다. 이 정책 객체는 프레임의 영상 내용이나 장치 획득을 직접 검증하지 않습니다.

큐가 가득 찼을 때 RejectNew는 QueueFull을 반환하고 대기 수를 유지합니다. DropOldest는 가장 오래된 항목을 제거하고 새 프레임을 추가하며 DroppedOldest를 반환합니다. 공간이 있으면 Added입니다.

프레임 제안의 결과

예를 들어 pending=2이고 큐가 가득 찼을 때 RejectNew이면 오류 후에도 pending은 2입니다. DropOldest라면 기존 선두를 버리고 새 프레임을 넣은 뒤 pending이 1이 됩니다. 반환 상태로 유실을 구분하십시오.
