pub fn to_packed_vec_bgr16(&self) -> ZResult<Vec<u16>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<u16>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

결과 판독과 예

Bgr16의 보이는 ROI를 행 우선으로 복사하고 각 픽셀의 u16 성분을 B, G, R 순서로 보관합니다. 벡터는 원본 영상의 행 패딩을 포함하지 않는 독립 값입니다.

예를 들어 폭 2, 높이 1인 두 픽셀이 각각 [1,2,3], [4,5,6]이면 결과는 [1,2,3,4,5,6]이며 총 2×1×3=6개 성분입니다. RGB 순서로 읽으면 색이 바뀌므로 저장 형식을 확인하십시오.
