이 멤버의 추가 계약 설명은 확인되지 않았습니다.

OCR 상태

ReadStatus 값을 반환하여 수락, 읽기 실패와 거절을 구분합니다. 문자열이 있다는 사실만으로 결과가 수락되었다고 판단하지 말고 reasons와 함께 읽습니다.

OcrRead는 불변 결과 스냅샷입니다. 문자열과 문자 슬라이스는 이 결과를 빌리므로 소유자가 살아 있는 동안 사용하고 더 오래 유지할 값은 복사합니다.

문자 판독 상태

status는 OCR 결과의 ReadStatus 값입니다. 수락, 읽지 못함, 조건 거절을 구분하며 text의 빈 여부만으로 세 상태를 판정하지 않습니다. 호출 자체가 오류로 끝난 경우에는 유효한 상태 객체와 별도로 처리합니다.

상태가 예상과 다를 때 reasons, 입력 ROI와 회전, 허용 문자 및 길이 조건을 함께 확인합니다. 예를 들어 문자열이 감지되어도 지정한 문자 조건을 만족하지 않으면 애플리케이션에서 수락된 값으로 바로 사용하지 않아야 합니다.

결과를 저장할 때 상태와 텍스트, 설정 및 프레임 식별자를 묶습니다. OCR 판독은 준비 영역의 좌표 변환이나 영상 표시와 별도 단계입니다. 문자의 위치가 필요하면 chars의 각 모서리를 확인합니다.
