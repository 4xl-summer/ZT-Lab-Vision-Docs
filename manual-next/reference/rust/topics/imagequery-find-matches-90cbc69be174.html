pub fn find_matches( self, model: &MatchModel, spec: &MatchSpec, ) -> ZResult<MatchQuery>

Plans model matching.

호출과 결과 확인

현재 ImageQuery를 소비하고 MatchModel과 MatchSpec을 연결한 MatchQuery 계획을 반환합니다. 실제 포즈 평가는 이 호출에서 하지 않으며 execute로 계획을 실행합니다. spec의 각도·배율 격자와 점수·중복 억제 조건을 검색 영상 ROI에 맞춰 설정합니다.

검색 계획과 실행

find_matches는 self ImageQuery를 소비하고 model 및 spec을 연결한 MatchQuery 계획을 ZResult로 반환합니다. 호출 시점에 포즈 후보를 실제 평가하는 것은 아니며, 반환된 종료 쿼리의 execute에서 결과를 얻습니다.

항목확인할 내용
self소비되는 이미지 계획
model학습된 MatchModel 참조
spec검색 격자와 결과 선택 조건
반환실행 전 MatchQuery 또는 오류

같은 영상 계획을 다른 검색 조건에도 사용하려면 소비 전에 해당 API의 clone으로 분기할 수 있습니다. spec의 각도·배율 격자, 점수와 중복 억제 조건을 기록하고 실행 후 결과 위치를 검색 ROI 기준으로 표시합니다. 계획 생성 실패와 실행 실패는 각각 확인합니다.
