pub fn to_archive(&self, unit: CompositeUnit) -> ZResult<Vec<u8>>

Serializes the full graph with a selected default unit.

사용과 결과 해석

전체 모델 그래프와 선택한 기본 단위를 바이트로 직렬화합니다. 이 바이트에는 프레임과 특징, 공차 구성이 포함되며 모델 평가 결과 영상을 저장하는 호출은 아닙니다.

보관한 바이트는 from_archive로 복원하여 저장된 단위와 모델을 함께 얻을 수 있습니다. 저장 후 구성 변경이 필요하면 새 그래프를 만들어 다시 직렬화하십시오.

그래프와 기본 단위 보관

to_archive는 프레임, 특징, 공차가 포함된 모델 그래프를 선택한 CompositeUnit과 함께 바이트로 직렬화합니다. 반환 Vec<u8>은 모델 구성의 보관 표현이며 평가 결과 영상이나 한 번의 검사 판정을 담는 결과 객체와는 다릅니다.
