Rust
pub fn to_output(self, p: Point2, revolution: u32) -> Result<Point2, ZError>

Input ROI-local point to output pixel coordinate, selecting a full-turn branch. At the center the angle is undefined; the branch start angle is selected canonically.

계산 순서와 결과 확인

입력 ROI 로컬 점을 각도·반지름 출력 좌표로 변환하며 revolution으로 전체 회전의 가지를 선택합니다. 중심에서는 각도가 정의되지 않으므로 선택 가지의 시작 각도를 사용합니다. 지정 반지름 또는 각도 범위에 해당하지 않는 점은 오류이며 to_input과 같은 PolarSpec을 사용해 결과를 비교합니다.
