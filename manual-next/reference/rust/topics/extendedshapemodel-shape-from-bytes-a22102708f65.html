pub fn shape_from_bytes(bytes: &[u8]) -> ZResult<Self>

Restores the shape.

호출 맥락과 결과 해석

버전과 체크섬이 포함된 형상 모델 바이트를 읽어 독립 모델을 복원합니다. 입력은 shape_to_bytes로 얻은 모델 아카이브이며 이미지 바이트가 아닙니다. 복원 실패 시 전달된 데이터의 완전성과 모델 종류를 확인하고, 성공하면 검색 영상과 설정을 별도로 제공해 모델을 사용합니다.

입력 검증과 모델 수명

bytes는 shape_to_bytes가 만든 형상 모델 아카이브입니다. 길이 128..2097184바이트, ZVSHAP01 표식, 특징 수와 정확한 길이, 체크섬 및 특징 값이 검증됩니다. 예를 들어 특징 3개의 정상 형식 길이는 32×3+32=128바이트입니다.

복원한 모델은 입력 바이트와 별도의 소유 값이며 이후 find에 검색 영상과 옵션을 따로 전달합니다. 잘못된 표식이나 잘린 데이터, 체크섬 불일치는 오류이므로 빈 검색 결과로 처리하지 않습니다. 모델 자체만 보관하며 검색 설정은 별도로 기록합니다.
