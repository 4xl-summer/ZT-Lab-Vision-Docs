pub fn set( &mut self, camera: u64, target: u64, pose: u64, object: &[Point2], pixels: &[Point2], ) -> Result<(), ZError>

Insert or atomically replace an observation. IDs are nonzero, input order is preserved.

사용과 결과 판독

카메라, 표적, 자세의 세 ID로 관측을 추가하거나 같은 키의 기존 관측을 원자적으로 교체합니다. ID는 0이 아니어야 하며 object와 pixels는 같은 인덱스가 같은 표적점의 짝입니다. 입력 순서는 유지되므로 한쪽 배열만 정렬하지 마십시오. 교체가 의도한 키에 수행됐는지 기록하고 Result의 성공 또는 오류를 확인합니다.

단계확인할 내용
키0이 아닌 카메라·표적·자세 ID의 조합입니다.
대응표적점과 픽셀점의 같은 순서가 한 쌍입니다.
기존 키기존 관측을 원자적으로 교체합니다.
결과성공 또는 오류를 확인하고 관측 키를 기록합니다.

관측 쌍을 원자적으로 저장

camera, target, pose는 모두 0이 아닌 식별자이며 세 값의 조합이 관측 키입니다. object와 pixels는 순서가 대응하는 점 배열로 길이가 같고 1–4096쌍이어야 합니다. 좌표는 모두 유한해야 합니다. 같은 키에 set하면 기존 관측을 원자적으로 교체합니다.

항목판독할 내용
camera / target / pose0이 아닌 세 식별자의 조합
object / pixels순서 대응·동일 길이의 점 쌍
한 관측1–4096쌍, 좌표는 유한
세션 한도최대 128관측, 총 100000쌍

관측은 최대 128개, 전체 점 쌍은 최대 100000개입니다. 예를 들어 동일 키에서 이전 10쌍을 12쌍으로 교체하면 세션 총계에는 2쌍이 추가됩니다. 제한이나 좌표 조건이 유효하지 않으면 오류이며 기존 관측을 변경한 것으로 간주하지 않습니다.
