pub fn fit(&self) -> Option<&LineFit>

Returns the fit, if one was obtained.

결과 확인 순서

직선 측정의 결과 객체에서 호출합니다. 적합 형상이 있으면 그 형상을 빌린 참조로 제공하고 없으면 None입니다. 결과 객체보다 참조를 오래 사용할 수 없으며, None은 원점이나 0 크기의 형상이 아닙니다. 입력 영상의 ROI 로컬 좌표로 얻은 기하를 다른 ROI와 비교할 때는 원점을 공통 기준으로 맞추고 형상의 유효 상태도 함께 보존하십시오.

확인 항목사용 기준
대상직선 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용Some의 형상과 None을 분기해 처리합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

Some(&LineFit)은 결과가 소유한 직선 적합을 빌려 읽는 경로이고 None은 형상이 없는 경우입니다. 참조의 유효 기간은 결과 객체에 묶입니다.

예를 들어 (0,2), (1,2), (2,2)는 모두 y=2 위에 있습니다. 이 무한선의 방향 벡터가 반대 부호여도 같은 직선을 나타낼 수 있습니다. 결과 좌표는 입력 관측과 같은 ROI 기준으로 비교하십시오.

항목확인할 내용
Some적합된 무한선의 참조입니다.
None형상 없음이며 좌표 (0,0)이 아닙니다.
방향벡터 부호가 반대여도 같은 선일 수 있습니다.
수명빌린 참조는 결과보다 오래 사용할 수 없습니다.
