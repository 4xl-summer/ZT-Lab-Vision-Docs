Rust
pub fn distances(&self) -> ZImage

Returns an independently owned distance image.

반환값과 수명

색상 매칭에서 각 픽셀의 기준 색까지의 거리 영상을 독립 소유 ZImage로 반환합니다. 어느 색이 선택되었는지는 indices 영상에서 확인합니다. 거리의 의미는 검색에 사용한 ColorDistance 방식과 함께 해석하고 반환 영상의 소유 수명을 관리합니다.

함께 확인할 값

항목해석
distances소유 ZImage: 선택 기준 색까지의 거리
indices소유 ZImage: 선택된 기준 색 번호
ColorDistance거리를 계산하는 데 사용한 방식

판독과 사용 순서

거리 영상과 인덱스 영상은 한 번의 색상 매칭 결과를 서로 다른 관점에서 표현합니다. 거리 값은 선택된 기준 색과 입력 픽셀 사이의 차이이고 인덱스는 어느 기준 색이 선택되었는지를 식별합니다. 예를 들어 두 픽셀의 거리가 같더라도 선택된 기준 색 번호는 다를 수 있습니다. 거리의 크기를 물리 길이로 읽지 말고 계산에 사용한 색 거리 방식과 입력 색 표현을 함께 기록합니다. 이 접근자는 새 소유 영상 핸들을 반환하므로 결과 객체와 영상의 수명을 각각 관리합니다.

항목판독 기준
