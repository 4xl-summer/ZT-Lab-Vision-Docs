pub fn calculate_gradients( &mut self, image: &ZImage, kernel: usize, sigma: f64, features: u32, budget: usize, ) -> ZResult<()>

Calculates requested gradients with the existing kernel.

사용과 결과 해석

결합된 프레임과 같은 크기·원점의 영상에서 요청한 기울기를 계산합니다. kernel은 1부터 127까지의 홀수, sigma는 유한한 양수이며 features는 크기와 각도 비트 중 하나 이상이어야 합니다. 예산은 영상과 점의 작업량을 감당해야 합니다.

가우시안 처리 후 Sobel x/y를 점 위치에서 쌍선형 보간합니다. 크기는 √(gx²+gy²), 각도는 atan2(gy,gx) 라디안이며 y는 아래 방향입니다. 응답이 0이면 각도도 0입니다. 실패 시 기존 배열은 유지됩니다.

기울기 계산 조건

예를 들어 보간된 gx=3, gy=4라면 크기는 √(3²+4²)=5이고 각도는 atan2(4,3)입니다. 두 응답이 모두 0이면 각도는 0으로 둡니다. 작업 예산과 영상 크기 제한도 충족해야 성공합니다.
