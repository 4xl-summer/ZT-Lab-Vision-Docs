pub fn save(&self, path: impl AsRef<Path>) -> ImageIoResult<()>

Save the matching model using the existing versioned format.

관련 입력의 확인된 조건

학습된 템플릿 상태를 소유하는 매칭 모델입니다.

호출 맥락과 결과 해석

학습된 기본 매칭 모델을 버전 1 파일로 저장합니다. 같은 경로에 파일이 있으면 덮어쓰므로 보관할 모델을 구분하려면 경로를 명시적으로 선택해야 합니다. 저장 작업은 반환 모델을 새로 만드는 호출이 아닙니다.

이후 load로 파일에서 모델을 복원할 수 있습니다. 모델과 함께 실제 검색 영상의 ROI와 MatchSpec을 따로 기록해야 검색 조건을 다시 구성할 수 있습니다. 저장 전에 모델 학습과 검색이 의도대로 이루어졌는지 확인하는 것이 좋습니다.

모델 파일 저장

save는 학습한 MatchModel을 버전 1 형식으로 지정 경로에 기록하며 ImageIoResult<()>를 반환합니다. 같은 경로에 파일이 있으면 덮어쓰므로 보관할 모델을 구분할 경로를 선택합니다. 저장은 새 검색을 실행하지 않습니다.

항목확인할 내용
path기록할 파일 경로
기존 파일같은 경로면 덮어씀
성공Ok(())
오류ImageIoError 분기

성공은 Ok(())로 확인하고 파일 접근이나 기록 오류는 Err로 처리합니다. 이후 load로 모델을 복원하더라도 검색 영상 ROI와 MatchSpec은 별도로 준비해야 합니다. 동일 입력의 검색 결과를 복원 전후로 비교하면 전달 과정을 확인할 수 있습니다.
