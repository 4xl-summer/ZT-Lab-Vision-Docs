행 수와 저장 공간

ImageLayout.height는 현재 배치의 세로 픽셀 수, 즉 보이는 행의 수를 반환합니다. 영상 데이터의 전체 바이트 수와 동일하지 않으며 마지막 행의 주소를 계산할 때에는 offset과 행 스트라이드, 실제 행 바이트를 함께 봐야 합니다.

항목의미와 확인
height보이는 행 수
예시높이 2면 두 행
첫 행 시작offset 0
둘째 행 시작0 + 1×8 = 8
유효 데이터 끝0+(2−1)×8+6 = 14바이트

사용할 때의 판독

예를 들어 높이 2, offset 0, stride 8, 유효 행 바이트 6이면 첫 행은 바이트 0부터, 둘째 행은 바이트 8부터 시작합니다. 마지막 유효 바이트의 끝은 0+(2−1)×8+6=14입니다. 폭, 픽셀 형식과 저장 공간도 함께 확인해야 합니다.
