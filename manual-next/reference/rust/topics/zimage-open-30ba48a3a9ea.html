pub fn open(&self, kernel: usize) -> ZResult<Self>

Applies binary opening.

호출에 필요한 입력

Gray8의 비영 전경에 이진 침식 후 팽창을 적용합니다.

인자선언된 형식확인할 내용
kernelusize기본값 없는 양의 홀수 정사각형 폭(픽셀)

결과와 사용 순서

반환 선언 ZResult<Self>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

열기 연산은 침식 다음 팽창을 적용합니다. 입력에서 구조 요소보다 작은 밝은 부분이나 전경이 영향을 받을 수 있습니다. 이진 열기와 값 기반 열기는 입력 형식과 연산 계약을 확인해 선택하세요.
