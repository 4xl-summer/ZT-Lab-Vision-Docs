pub fn suppress_match_polygon_overlaps( &self, matches: &[ExtendedMatch], max_iou: f64, limit: usize, ) -> ZResult<MatchingReport<Vec<ExtendedMatch>>>

Suppresses overlaps using the existing polygon policy.

관련 입력의 확인된 조건

Extended appearance matching model.

호출 맥락과 결과 해석

변환된 템플릿 다각형끼리의 겹침을 기준으로 기존 후보를 억제합니다. 축 정렬 경계상자 IoU를 사용하는 suppress_match_overlaps와 비교하면 회전된 후보의 겹침 판단 기준이 다릅니다. 후보를 새로 찾는 기능은 아닙니다.

max_iou로 허용 겹침을 지정하고 limit으로 남길 결과 수를 제한합니다. 같은 후보 집합을 두 억제 방식에 전달해 어떤 포즈가 유지되는지 비교하면 경계상자와 실제 템플릿 다각형의 차이를 확인할 수 있습니다.

다각형 겹침 정책

입력 ExtendedMatch마다 템플릿 경계를 포즈로 변환하고 후보들의 다각형 IoU를 비교해 중복을 억제합니다. max_iou는 허용 겹침, limit은 최대 유지 수입니다. 새 후보를 생성하지 않으므로 먼저 NCC 검색에서 후보를 얻어야 합니다.

예를 들어 길쭉한 템플릿이 회전하면 축 정렬 경계상자에는 실제 다각형 밖의 공간도 포함될 수 있습니다. 따라서 같은 max_iou라도 상자 정책과 다각형 정책이 남기는 후보는 다를 수 있습니다. 포즈, 점수와 정책을 함께 기록해 결과를 비교합니다.
