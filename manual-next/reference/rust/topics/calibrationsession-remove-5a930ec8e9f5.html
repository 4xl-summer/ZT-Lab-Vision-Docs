Rust
pub fn remove( &mut self, camera: u64, target: u64, pose: u64, ) -> Result<(), ZError>

Remove one indexed observation, returning an error if it does not exist.

사용과 결과 판독

카메라·표적·자세 키에 해당하는 관측 하나를 제거합니다. 해당 키가 없으면 오류이므로 잘못된 ID 조합과 제거 성공을 구별하십시오. 세션을 가변으로 빌리며 반환 Result를 확인해야 합니다. 서로 다른 자세에 저장한 관측을 혼동하지 않도록 제거한 키와 후속 보정에 사용할 관측 목록을 기록합니다.

단계확인할 내용
선택세 ID가 가리키는 관측 하나를 고릅니다.
변경세션을 가변으로 빌려 해당 관측을 제거합니다.
없는 키존재하지 않는 관측의 제거는 오류입니다.
기록남은 관측과 삭제한 키를 구별해 저장합니다.

판독과 사용 순서

제거 대상은 카메라·표적·자세의 세 ID가 모두 일치하는 관측 하나입니다. 카메라는 같아도 pose가 다르면 다른 항목이므로 어느 촬영의 대응점을 지우는지 세 값을 함께 확인합니다. 해당 키가 없다면 성공으로 취급하지 않고 오류가 반환됩니다. 이 메서드는 세션을 가변으로 빌려 기록을 변경하며, 이후 보정에 포함되는 관측 집합에도 영향을 줍니다. 제거 전에 필요한 관측과 키를 기록하고 반환 Result를 확인한 뒤 남은 자료로 후속 계산을 진행합니다.
