전체 판독 수락

전체 판독의 accepted를 bool로 반환합니다. 문자열이 읽혔는지와 설정된 조건을 만족했는지 함께 살피고, 문자별 결과도 필요한 경우 줄을 순회해 확인합니다.

배치 검사는 별도의 결과일 수 있으므로 문자 판독 수락만으로 위치 규칙까지 통과했다고 추정하지 않습니다. 사용한 옵션과 입력 식별자를 함께 기록합니다.

판독 수락과 위치 조건

accepted는 전체 폰트 판독이 해당 조건을 만족했는지 bool로 반환합니다. 문자별 FontGlyph의 accepted와 전체 결과는 다른 수준의 정보이므로 글자별 문제 위치가 필요하면 lines를 순회합니다.

예를 들어 세 글자의 판독에서 한 글자의 유사도가 낮다면 전체 문자열의 수락만 표시해서는 어떤 셀을 확인해야 하는지 알 수 없습니다. 각 글자의 라벨과 점수, 셀을 입력 영상과 함께 살펴보고 이진화 및 분할 조건을 점검합니다.

전체 판독 수락과 별도의 배치 검사는 서로 다른 작업입니다. 좌표 조건을 검사하지 않은 경우 이 값만으로 위치가 허용 범위 안에 있다고 추정하지 않습니다. 글자 위치의 로컬 기준과 화면 확대·이동을 구분합니다.

모델과 FontOcrOptions, 입력 프레임을 결과와 묶어 기록합니다. 반환 bool은 실행이 성공한 뒤의 값이며 판독 호출 오류를 단순한 false의 유효 결과로 바꾸지 않습니다. 템플릿 점수는 확률이 아닙니다.
