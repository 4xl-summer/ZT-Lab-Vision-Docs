관련 입력의 확인된 조건

Borrowed typed image view with byte stride.

형식과 좌표

Bgra8View의 row는 현재 뷰의 로컬 행 y에 있는 성분을 빌립니다. 반환 슬라이스는 읽기 전용이고 행 패딩은 포함하지 않습니다.

너비 4의 Bgra8View에서 반환 행에는 픽셀 4개에 대응하는 16개 u8 성분이 있습니다. 한 픽셀당 순서는 B, G, R, A입니다. y가 높이 이상이면 OutOfBounds 오류이며, stride에 포함된 뒤쪽 패딩은 반환 행에서 제외됩니다.

수명과 후속 처리

Bgra8View는 원본 저장소의 수명에 묶인 뷰입니다. 반환된 참조를 원본 데이터보다 오래 보관할 수 없으며, 값을 다른 소유 객체로 보존하려면 별도의 소유 복사 또는 이미지 공유 계약을 사용해야 합니다. 형식이 다른 뷰로 임의 재해석하지 말고 입력 구성과 성분 순서를 확인하십시오.

좌표 계산 예

Bgra8View의 행 슬라이스에서 픽셀 x의 첫 성분 인덱스는 x×4입니다. 너비 4이면 마지막 픽셀의 성분은 인덱스 12부터 시작하며, 픽셀 간 성분 순서는 B, G, R, A입니다. 이 계산은 반환된 행의 성분 인덱스에 관한 것으로 stride 바이트를 직접 더하는 연산이 아닙니다.
