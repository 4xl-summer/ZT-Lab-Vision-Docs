pub fn new(entries: Vec<FeatureInstanceCollectionEntry>) -> Self

Creates an explicit collection; the engine validates bounds on execution.

호출과 결과 해석

모델별 FeatureInstanceCollectionEntry를 벡터 순서대로 묶습니다. 생성은 검색을 실행하지 않고 유효 범위의 검증은 실행 시 이루어집니다. 항목 id와 모델·검색 옵션의 관계를 유지해야 이후 find에서 반환된 여러 인스턴스를 해당 모델과 연결할 수 있습니다.

모델별 항목의 순서

entries 벡터에는 FeatureInstanceCollectionEntry를 모델별로 넣습니다. 각 항목은 호출자 정의 id, 공유 FeatureModel, 해당 모델의 FeatureMatchOptions 및 min_inliers를 담습니다. new는 입력 벡터의 순서를 보관합니다.

항목확인할 내용
id호출자가 정한 모델 식별자
model공유되는 학습 FeatureModel
options그 모델의 검색 옵션
min_inliers필요한 최소 인라이어 수

컬렉션 생성 자체는 이미지를 검색하지 않으며 엔진의 범위 검증은 실행 시 이루어집니다. 예를 들어 두 모델의 id와 옵션을 서로 바꾸어 넣으면 결과를 해석할 모델 대응도 달라집니다. 이후 find의 예산과 겹침 기준을 별도로 지정합니다.
