pub fn passed(&self) -> bool

Overall acceptance decision.

전체 통과 여부

비드 검사 조건에 대한 전체 수락 여부를 bool로 반환합니다. 한 구간의 폭이나 최장 간격만으로 이 값을 추정하지 말고 사용한 검사 조건과 결과 구간을 함께 확인합니다.

이 값은 해당 입력과 옵션으로 수행한 한 번의 검사 결과입니다.

전체 판정과 개별 결과

passed는 입력 비드와 검사 옵션에 대한 전체 수락 결과를 bool로 제공합니다. true는 이 호출이 적용한 조건의 전체 판정이고, 특정 위치의 폭만 따로 통과했다는 의미가 아닙니다. false인 경우에도 probes와 runs를 확인해야 어떤 경로 구간이 문제인지 좁힐 수 있습니다.

단계 또는 항목확인할 내용
passed해당 검사 실행의 전체 bool 판정
probes순서별 중심·경계와 상태

결과를 사용할 때

예를 들어 경로 대부분의 폭이 허용 범위여도 누락 또는 다른 조건이 전체 판정에 영향을 줄 수 있습니다. 검사에서 제외된 프로브와 실제 경계 검출에 실패한 프로브도 구분하세요. 입력 영상, 경로, 비드 극성 및 폭·간격 조건을 함께 기록해야 다른 프레임의 판정과 비교할 수 있습니다.
