pub fn read_barcode_regions( &self, spec: &BarcodeRegionsSpec, ) -> RecognitionEngineResult<BarcodeRegionResults>

이 멤버의 추가 계약 설명은 확인되지 않았습니다.

여러 영역의 바코드 판독

BarcodeRegionsSpec의 영역별 조건으로 바코드를 읽고 BarcodeRegionResults를 반환합니다. 결과의 각 뷰에서 region, read, length_accepted와 영상 통계를 확인할 수 있습니다.

결과가 비었다는 사실은 지정된 조건에서 항목이 없다는 관찰입니다. 영역과 판독 위치의 로컬·전역 좌표를 표시 대상에 맞추고 뷰의 빌린 수명을 지킵니다.

영역별 바코드 검색

BarcodeRegionsSpec을 사용해 현재 영상의 여러 지정 영역에서 바코드를 판독하고 BarcodeRegionResults를 반환합니다. 결과의 각 뷰에는 해당 region과 read, 길이 수락 및 영상 통계가 연결되어 있습니다.

예를 들어 두 ROI를 지정했다면 결과를 순회할 때 각 region과 read를 같은 항목에서 읽습니다. 컬렉션 순서만 보고 화면의 왼쪽과 오른쪽을 추정하지 말고 반환된 영역 좌표를 확인합니다. ROI 로컬 위치를 전체 프레임에 표시할 때 원점도 구분합니다.

각 판독의 status, reasons, format 및 text를 함께 확인합니다. 검색 조건에 따라 코드를 찾지 못할 수 있고, 결과 항목이 없다는 사실을 입력 전체에 심볼이 없다는 증명으로 확대하지 않습니다. 오류와 정상적인 빈 결과도 별개입니다.

BarcodeRegionResults가 뷰의 원본을 소유하므로 빌린 뷰와 참조는 컬렉션의 수명 안에서 사용합니다. 나중에 보관할 문자열이나 좌표는 소유 값으로 복사하고 프레임과 영역 정보를 함께 기록합니다.
