pub fn learn( image: &ZImage, anchors: &[Point2], include: Option<&[bool]>, options: BeadReferenceOptions, ) -> ZResult<Self>

Learns from explicitly ordered ROI-local anchors.

순서 있는 앵커로 기준 학습

입력 이미지와 순서가 지정된 ROI 로컬 앵커, 선택적 include 및 BeadReferenceOptions로 기준을 학습합니다. 앵커 순서는 경로의 진행을 정의하므로 임의로 정렬하면 다른 경로가 됩니다.

include가 있다면 각 앵커와 올바르게 대응시키고, ROI 원점과 이미지의 로컬 좌표를 확인합니다. 학습 모델은 이후 독립 검사 영상에서 폭과 중심 오차를 비교하는 기준입니다.

순서 있는 기준 경로 학습

learn은 image, ROI 로컬 anchors 슬라이스, 선택적 include 및 BeadReferenceOptions로 기준을 학습합니다. anchors의 순서는 경로의 진행을 정의하므로 점을 x좌표만으로 다시 정렬하면 곡선의 의미가 바뀔 수 있습니다.

include를 사용한다면 각 불리언이 같은 인덱스의 경로점에 대응하도록 준비합니다. 영상 ROI 원점과 로컬 점을 확인하고, 전체 프레임에 표시할 때만 올바른 좌표 변환을 적용합니다. 예를 들어 원점 (100,50)과 로컬 (4,3)의 단순 이동 결과는 (104,53)입니다.

모델의 path와 widths를 읽어 학습된 경로 및 폭을 같은 순서로 확인할 수 있습니다. 기준 영상에만 맞는지 보지 말고 다른 정상 입력과 알려진 결함 입력으로 검사 조건을 별도로 검토합니다. 학습 성공만으로 현장 정확도를 보장하지 않습니다.

이후 inspect에서 검사 영상과 폭·중심 허용치를 전달합니다. 반환 결과의 위반 위치 및 구간을 동일한 경로와 연결해 해석합니다. 입력 오류는 빈 기준 모델이 성공적으로 만들어진 것으로 처리하지 않습니다.
