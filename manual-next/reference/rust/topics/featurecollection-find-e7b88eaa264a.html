pub fn find( &self, image: &ZImage, search_mask: Option<&ZImage>, options: FeatureCollectionOptions, ) -> ZResult<MatchingReport<FeatureCollectionReport>>

Searches the collection and preserves its evaluation/budget report.

호출과 결과 해석

컬렉션의 각 특징 모델을 영상에 대응시키고 기하를 검증합니다. FeatureCollectionOptions에는 검색과 예산 조건이 있으며 선택 검색 마스크는 영상에 적용됩니다. 반환 MatchingReport에서 모델별 매치와 평가·예산 상태를 함께 확인하고 결과의 모델 id를 입력 컬렉션과 연결합니다.

모델별 대응과 예산 판독

컬렉션의 특징 모델을 영상에서 검색하고 기하 검증 결과와 평가·예산 보고를 MatchingReport로 반환합니다. image는 검색 대상이고 search_mask는 선택적인 검색 마스크이며 options는 검색 및 작업 제한을 지정합니다. 보고의 모델 ID를 원래 컬렉션 항목과 연결해야 어떤 형상이 발견됐는지 알 수 있습니다.

항목의미와 확인
image특징을 찾을 입력 영상
search_mask선택적인 검색 픽셀 제한
options검색 조건과 예산
모델 ID원래 컬렉션 항목과 연결
기하 검증대응의 포즈와 유효성
보고평가 수와 예산·종료 상태

사용할 때의 판독

예를 들어 컬렉션에 모델 A와 B가 있으면 반환 후보의 ID로 해당 모델을 구분하고, 각 후보의 대응 특징과 기하 검증 상태를 살펴봅니다. 검색 예산 때문에 모든 후보를 평가하지 못한 경우 빈 결과를 모든 모델의 부재로 단정하지 마세요. 이미지의 ROI와 마스크 위치, 설정 및 종료 보고를 같은 실행 기록으로 보관합니다.
