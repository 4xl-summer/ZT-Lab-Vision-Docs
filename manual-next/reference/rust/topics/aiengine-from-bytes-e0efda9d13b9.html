이 멤버의 추가 계약 설명은 확인되지 않았습니다.

사용과 결과 해석

모델 바이트와 AiModelSpec을 받아 원래 백엔드 및 입력 사양에 결합된 AI 엔진을 생성합니다. 모델 또는 사양이 유효하지 않으면 인식 오류가 반환됩니다.

모델이 기대하는 입력 크기, 형식과 출력 의미를 사양과 일치시키십시오. 실행 시에는 이미지 영역과 실행 옵션을 별도로 전달합니다.

모델 사양과 실행 단계

from_bytes는 모델 바이트 Vec와 AiModelSpec을 받아 AI 엔진을 구성합니다. spec에는 task, width, height, channels, classes와 호출자가 지정한 model_version이 있습니다. 바이트와 사양이 모델의 실제 입출력 계약에 맞지 않거나 초기화에 실패하면 RecognitionEngineResult 오류가 반환됩니다.

엔진을 얻은 뒤 run에 영상, ZRect 영역과 AiRunOptions를 따로 전달합니다. 내부 추론 입력 형상은 [1,channels,height,width]입니다. 예를 들어 channels=3, height=32, width=64라면 입력 형상은 [1,3,32,64]입니다. 영역을 지정하는 일과 모델 사양의 입력 크기를 선언하는 일은 구분합니다.

model_version은 호출자가 결과 출처를 연결하기 위해 지정한 식별자이며 모델 바이트의 내용 해시나 정확도 검증값이 아닙니다. 모델 파일과 사양, 실행 영역·옵션을 함께 보관하고, 반환 AiResult의 작업 종류에 맞는 출력만 읽습니다. 바이트 이동과 엔진 소유권은 Rust의 값 수명으로 관리합니다.

판독과 확인 사례

사양 검사는 width와 height가 0이 아니고 channels가 1 또는 3인지 확인합니다. classes는 작업에 따라 다릅니다. 분류와 분할은 2..256, 검출은 1..256, 이상 감지는 1이어야 하며 model_version은 0이 아니어야 합니다. 이 숫자들은 실제 모델 메타데이터와도 맞아야 합니다.

예를 들어 분류 사양에 classes=3을 지정하면 기대 출력 형상은 [1,3]입니다. 잘못된 바이트나 모델의 입력·출력 형상 불일치는 엔진 생성 또는 실행의 오류로 처리합니다. 버전 번호를 올리는 것만으로 모델의 형식이나 예측 품질이 검증되지는 않습니다.
