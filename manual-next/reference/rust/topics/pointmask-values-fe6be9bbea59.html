pub fn values(&self) -> &[bool]

Borrows all decisions in input order.

결과 해석과 수명

입력 순서대로 저장된 불변 bool 판정 슬라이스를 빌립니다. 판정의 각 위치를 원래 입력 점 목록의 같은 인덱스에 연결해야 어느 점이 선택되었는지 알 수 있습니다. 슬라이스는 PointMask의 수명에 연결되며 값의 의미는 마스크를 만든 연산의 조건을 따릅니다.

점 목록과 판정 슬라이스

values는 PointMask가 저장한 bool 결정을 원래 입력 점 순서의 불변 &[bool]로 빌립니다. 각 인덱스의 값은 마스크를 만든 연산의 판정에 해당합니다. 슬라이스 자체는 점 좌표나 법선이 아니며 PointMask 소유 값의 수명 안에서 사용해야 합니다.

예를 들어 입력이 [P0,P1,P2]이고 values가 [true,false,true]이면 첫째와 셋째가 해당 연산의 선택 판정을 받았습니다. false인 P1을 목록에서 제거한 다음 원래 인덱스를 잊으면 P2를 P1의 결과로 잘못 연결할 수 있습니다. 점 목록과 판정을 같은 순서로 함께 처리하세요.

사용과 결과 판독

true가 의미하는 구체 조건은 이 마스크를 생성한 연산의 계약을 따릅니다. 거리 기준, 영역 포함 또는 다른 조건을 메서드 이름만으로 추측하지 말고 생성 설정을 보관하세요. 마스크 객체보다 더 오래 결과를 보관할 필요가 있다면 bool 값들을 소유 컨테이너에 복사하고 원래 점 목록과의 대응도 함께 유지합니다.
