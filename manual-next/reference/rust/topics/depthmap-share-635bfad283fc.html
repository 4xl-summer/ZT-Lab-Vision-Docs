공유 저장소와 핸들

공유 연산은 같은 불변 데이터 저장소를 가리키는 별도 소유 핸들을 만듭니다. 새 객체가 생기지만 샘플 전체를 깊은 복사한 것과는 다릅니다. 언어별로 객체를 닫거나 해제하는 방식이 다르므로 공유한 각 핸들의 수명은 각각 관리합니다.

예를 들어 큰 깊이 영상을 두 처리 경로로 전달할 때 공유 핸들을 이용하면 두 경로가 같은 원본 데이터를 읽습니다. 하나의 핸들을 닫았다고 다른 소유 핸들이 가리키는 데이터를 임의로 수정하는 것은 아닙니다. 독립 메모리 사본이 필요한 경우 해당 언어의 깊은 복사 연산을 확인합니다.
