pub fn insert( &mut self, camera: u64, target: u64, pose: u64, object: &[Point2], pixels: &[Point2], ) -> Result<(), ZError>

Insert a new observation and reject an existing camera/target/pose key.

사용과 결과 판독

카메라·표적·자세 키에 새로운 대응점 관측을 추가합니다. 같은 키가 이미 있으면 이를 교체하지 않고 오류로 처리하므로 기존 자료를 덮어쓰려는 set과 역할이 다릅니다. object와 pixels의 같은 위치는 같은 표적점이어야 하고 순서를 보존합니다. ID와 관측을 함께 기록해 실패한 중복 키를 찾으십시오.

단계확인할 내용
키카메라·표적·자세의 조합을 지정합니다.
새 관측표적점과 대응 픽셀을 같은 순서로 전달합니다.
중복이미 존재하는 키는 교체하지 않고 거부합니다.
대조교체하려는 경우 set의 계약을 사용합니다.

판독과 사용 순서

세 정수의 조합은 하나의 관측을 구분하는 키이며 object와 pixels의 각 위치는 같은 표적점을 가리켜야 합니다. 예를 들어 object[0]과 pixels[0]이 다른 점이면 배열 길이가 같아도 잘못된 대응이 저장됩니다. insert는 기존 키를 덮어쓰지 않고 오류를 반환하므로 이미 기록한 관측을 바꾸려면 별도의 set 계약을 사용합니다. 세션을 가변으로 빌리기 때문에 이 호출은 관측 목록의 상태를 변경합니다. 카메라 하나가 여러 자세를 관찰할 수 있으므로 카메라 번호만으로 해당 관측을 식별하지 않습니다.

pixels같은 순서의 영상 점 배열
