이 멤버의 추가 계약 설명은 확인되지 않았습니다.

입력 영상 영역

추론에 사용한 ZRect 영역을 값으로 반환합니다. 결과의 검출 상자나 맵을 원본 영상에 표시할 때 실제 입력 영역과 좌표계를 함께 확인합니다.

AiTask와 입력 조건을 결과에 함께 보관합니다. 빌린 슬라이스는 AiResult가 살아 있는 동안 사용하며, acquire_map의 반환 영상은 별도의 소유 공유입니다.

추론 영역 확인

region은 추론에 사용한 ZRect를 값으로 반환합니다. 결과가 어느 입력 영역에서 나왔는지 확인하는 정보이며 검출된 개별 상자나 분할 맵의 값 그 자체는 아닙니다.

예를 들어 한 이미지에서 서로 다른 두 ROI를 추론했다면 같은 모델 버전이라도 결과의 region이 다를 수 있습니다. 검출 결과를 화면에 겹칠 때 입력 영상과 영역의 좌표 기준을 함께 확인합니다.

반환 사각형은 값으로 복사되며 결과의 분류·검출·이상 출력 여부는 별도 접근자로 판독합니다. 결과를 프레임 식별자 및 모델 버전과 연결해 늦게 도착한 출력이 다른 입력에 적용되지 않도록 합니다.

ZRect의 영역과 검출된 AiDetection 상자는 같은 역할이 아닙니다. 전자는 추론에 사용된 입력 범위이고 후자는 검출 출력이 있을 때 각 객체를 나타냅니다. 결과를 원본에 표시할 때 두 좌표의 기준을 확인합니다.

모델이 분류 작업이면 detections는 None일 수 있고 이상 작업이면 anomaly가 Some일 수 있습니다. region만 읽어 모델 작업 종류나 성공한 검출 수를 추정하지 않습니다.

모델이 입력 ROI를 전처리하면서 크기 조절이나 패딩을 사용했다면 그 변환 정보를 후처리에도 연결해야 합니다. 표시 좌표를 입력 영상에 되돌릴 때 ROI 이동과 패딩을 두 번 적용하지 않도록 합니다.

다른 작업 종류의 출력은 선택적 접근자에서 None으로 나타날 수 있습니다. region이 존재한다는 사실은 검출 상자가 하나 이상 있다는 뜻이 아닙니다.

프레임의 ROI에서 결과를 얻었다면 원본 전체 영상에 오버레이할 때 ROI 원점과 반환 좌표의 기준을 대조합니다. 이미 전체 프레임 기준인 좌표에 원점을 다시 더하면 결과가 이동하므로, 사각형과 상자의 좌표가 어느 기준인지 확인한 후 화면 변환을 적용합니다.
