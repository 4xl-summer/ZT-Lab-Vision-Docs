pub fn fit_sampled( points: &[Point2], options: &FitOptions, sample_size: usize, ) -> Result<FitDiagnostics<CircleFit>, ZError>

Fits using the existing configurable consensus sample size.

사용과 결과 해석

점, 적합 옵션과 sample_size로 표본 크기를 지정해 원을 적합하고 진단을 반환합니다. 표본 크기와 점 집합은 원을 결정할 수 있는 유효한 값이어야 합니다.

동일한 입력에서 후보의 표본 크기와 옵션이 달라지면 결과가 달라질 수 있습니다. 반환된 적합 통계로 잔차와 유효 점 수를 확인하고 목적에 맞는 설정을 선택하십시오.

표본 피팅의 입력

points는 피팅할 Point2 슬라이스이고 options는 FitOptions, sample_size는 합의 후보를 만들 때 사용하는 표본 크기입니다. 입력 점의 좌표 단위와 sample_size의 허용 조건을 확인해야 합니다. 반환은 원 모델뿐 아니라 FitDiagnostics를 포함합니다.

항목판독할 내용
points원 후보에 사용할 점들의 슬라이스
options합의·피팅 설정
sample_size후보 표본 크기
반환FitDiagnostics<CircleFit> 또는 오류

점이 한 직선에 몰리거나 필요한 제약이 부족하면 원을 안정적으로 결정하기 어려울 수 있습니다. 합의에 사용된 관측과 잔차, 결과 상태를 함께 확인하고 작은 유효 사례와 퇴화 사례를 구분해 시험합니다. 유효하지 않은 설정이나 계산 실패는 ZResult 오류로 처리합니다.
