pub fn defect_count(&self) -> usize

Number of defect pixels.

결함 픽셀 수

결함으로 판정된 픽셀 수를 usize로 반환합니다. 이 숫자는 연결된 결함 객체 수가 아니며 인접한 여러 결함 픽셀은 하나의 연결 요소가 될 수 있습니다.

검사 픽셀 수와 함께 기록하여 실제 비교한 범위를 파악하고, 위치는 mask를 통해 확인합니다. 입력 오류를 결함 수 0으로 바꾸지 않습니다.

조건과 결과 판독

defect_count는 결함으로 판정된 픽셀의 개수입니다. 인접한 다수의 픽셀이 하나의 연결된 영역을 이룰 수 있으므로 이 값은 결함 객체 수와 다릅니다. 예를 들어 서로 붙은 결함 픽셀 10개라도 연결 영역 수는 1개일 수 있습니다.

결함 위치는 mask로 확인하고 비교 대상의 검사 영역 크기도 함께 기록하세요. 검사에 실패한 오류와 성공적으로 계산된 결함 픽셀 수 0은 다른 결과입니다. 반환 usize는 영상 핸들이 아닌 값입니다.

예를 들어 검사 마스크가 달라지면 결함 수의 분모가 되는 검사 영역도 달라질 수 있습니다. 두 실행을 비교할 때는 동일한 ROI와 포함 영역인지 확인하고 결함 위치를 mask로 살펴야 합니다. 단순 픽셀 수만으로 결함의 크기 분포나 연결된 객체 개수를 알 수 없습니다.
