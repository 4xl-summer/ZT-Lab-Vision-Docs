결과 해석과 수명

전체 문자 배치 검사의 수락 여부를 bool로 반환합니다. 어느 문자가 조건을 통과하지 못했는지는 per_glyph의 줄별 결과를 확인해야 합니다. 이 조회는 판독이나 검사를 다시 실행하지 않으며 저장된 스냅샷 상태를 읽습니다.

전체 수락의 세 조건

accepted는 저장된 문자 배치 검사의 전체 불리언 결과를 반환합니다. 구현은 원래 판독 read.accepted가 true이고 줄 목록이 비어 있지 않으며, per_glyph의 모든 위치 판정이 true일 때만 전체를 수락합니다. 따라서 개별 위치가 모두 맞더라도 원래 판독이 거부되었다면 전체는 false입니다.

각 문자 판정은 문자 셀 중심과 기대 위치의 x·y 차이가 각각 max_dx, max_dy 이내인지 검사합니다. 예를 들어 오차가 (2,1), 허용치가 (2,1)이면 등호를 포함해 해당 문자는 통과합니다. 어느 위치가 false였는지는 per_glyph의 줄별 슬라이스로 확인합니다.

전체 false는 한 가지 원인만 뜻하지 않습니다. 원래 판독 상태, 빈 줄 목록 여부와 각 문자 판정을 차례로 살피고, 기대 줄 수와 문자 수가 일치하지 않는 입력은 검사 결과가 아닌 오류가 됨을 구분합니다. accepted 조회 자체는 인식이나 검사를 다시 수행하지 않습니다.
