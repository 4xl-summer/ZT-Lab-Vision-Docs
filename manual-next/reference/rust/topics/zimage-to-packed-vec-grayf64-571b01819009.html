pub fn to_packed_vec_grayf64(&self) -> ZResult<Vec<f64>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<f64>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

결과 판독과 예

GrayF64 영상의 보이는 ROI를 행 우선으로 복사하여 Vec<f64>를 반환합니다. 각 픽셀에 성분 하나가 있으며 원래 스트라이드의 패딩은 결과에 포함되지 않습니다.

예를 들어 폭 2, 높이 2의 두 행 [0.5,1.0]과 [1.5,2.0]은 [0.5,1.0,1.5,2.0] 네 원소가 됩니다. 이는 형식에 맞는 픽셀을 복사하는 연산이며 색상이나 물리 단위로 자동 변환하는 단계가 아닙니다.

항목확인할 내용

소유원본 행의 참조가 아닌 독립 Vec입니다.
