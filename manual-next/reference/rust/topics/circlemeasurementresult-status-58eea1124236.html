pub fn status(&self) -> ModelFitStatus

Returns the fit status.

결과 확인 순서

원 측정의 결과 객체에서 호출합니다. 측정이 끝난 뒤 적합의 상태를 반환합니다. 에지를 찾은 프로브가 있다는 사실과 유효한 최종 형상을 얻었다는 사실은 서로 다릅니다. 먼저 이 상태를 읽고 필요한 관측과 형상이 제공되는지 확인하십시오. 실패나 관측 부족을 유효한 좌표 0 또는 반경 0으로 대체하면 실제 원점의 결과와 구별할 수 없습니다.

확인 항목사용 기준
대상원 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용상태를 확인한 뒤 형상과 개별 관측을 해석합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

상태와 관측

status는 원 측정 결과의 상태를 나타냅니다. 상태값은 계산이 어떻게 끝났는지 판독하는 출발점이며 중심이나 반경 숫자 하나만 읽는 것보다 실패와 부분 결과를 구분하는 데 중요합니다.

항목판독할 내용
status계산의 결과 상태
관측검출 점과 잔차
재피팅수행 횟수 및 수렴 정보
원성공 조건에서 중심과 반경 해석

같은 실행의 관측 잔차와 인라이어, 재피팅 횟수 및 수렴 정보를 함께 확인하세요. 예를 들어 재피팅 횟수가 적다는 사실만으로 정확한 원이 검출되었다고 단정할 수 없습니다. 입력 ROI와 샘플의 좌표 단위도 결과에 연결해 보관합니다.
