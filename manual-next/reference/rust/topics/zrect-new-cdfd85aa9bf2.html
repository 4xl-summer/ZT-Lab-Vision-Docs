계산 순서와 결과 확인

x, y, width, height를 그대로 담는 상수 생성자입니다. 이 함수 자체는 영상 크기와의 교차나 양의 크기를 검증하지 않습니다. 예를 들어 (2,3,4,5)는 시작 좌표와 크기 값의 묶음이며, 실제 ROI로 적용할 때 해당 영상 경계와 연산의 유효 조건을 확인해야 합니다.

경계 검사생성자는 영상 크기와 비교하지 않음

사용 조건과 결과 판독

ZRect::new는 x,y,width,height 네 usize 값을 반열림 사각형 값으로 담는 const 생성자입니다. 이 호출은 영상 자체를 받지 않으므로 특정 영상의 경계와 비교하거나 너비·높이가 양수인지 검사하지 않습니다. 유효한 ROI인지의 판단은 실제로 영상에 적용하는 경로에서 이뤄집니다.

예를 들어 (x,y,width,height)=(2,3,4,5)는 x 시작 2, y 시작 3, 너비 4, 높이 5를 뜻합니다. 반열림 좌표 범위로는 x가 [2,6), y가 [3,8)입니다. 오른쪽 6과 아래쪽 8은 포함된 마지막 픽셀이 아니라 끝 경계입니다.

생성자가 0 크기나 큰 숫자를 보관할 수 있다는 사실과 해당 사각형을 특정 영상에 적용할 수 있다는 사실은 다릅니다. 적용할 영상의 크기와 연산이 요구하는 조건을 확인하고, 덧셈이나 범위가 유효하지 않다면 적용 단계의 오류를 처리하세요.

x,y는 이 사각형이 사용되는 좌표 기준에서의 시작 위치입니다. ROI 로컬 사각형을 전체 프레임의 위치와 비교할 때는 영상 원점을 적절히 반영해야 합니다. ZRect는 네 정수를 담는 값이며 영상을 자르거나 픽셀을 복사하는 명령이 아닙니다.

예를 들어 폭 10인 영상에서 x=2, width=4인 사각형의 x 범위는 2,3,4,5이며 끝 경계 6은 포함되지 않습니다. 그러나 같은 사각형이라도 영상 높이가 y+height보다 작으면 적용할 수 있는지는 그 영상의 ROI 경계 검사에 달려 있습니다. new는 const 값 생성이므로 영상의 실제 너비와 높이를 그 시점에 알아내지 않습니다.
