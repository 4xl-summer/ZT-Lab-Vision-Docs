pub fn image(&self) -> ZImage

Acquires an independent mosaic image share.

사용과 결과 해석

모자이크 영상의 독립 공유 핸들을 반환합니다. 결과 객체와 별도로 소유할 수 있으며 픽셀 유효성은 valid_mask에서 확인합니다.

출력의 0 밝기가 입력 부재를 뜻한다고 가정하지 마십시오. geometry와 valid_mask를 함께 읽어 위치와 유효 영역을 판독합니다.

영상·기하·유효 영역

image는 합성 영상의 독립 공유 ZImage 핸들을 반환합니다. 모자이크가 보유한 영상 데이터를 공유하는 소유 핸들이며, 결과의 geometry는 공통 좌표와 출력 픽셀의 관계를 설명합니다. 유효 위치가 필요하면 같은 결과의 valid_mask도 별도로 획득합니다.

예를 들어 합성 영상의 값이 0인 위치는 원래 검은 픽셀일 수도 있고 어떤 소스도 채우지 못한 위치일 수도 있습니다. valid_mask를 함께 확인하면 두 경우를 구분할 수 있습니다. 다른 모자이크와 비교할 때는 크기뿐 아니라 원점과 scale도 일치시켜야 같은 픽셀 위치를 비교합니다.
