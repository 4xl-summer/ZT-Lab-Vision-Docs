이 멤버의 추가 계약 설명은 확인되지 않았습니다.

사용과 결과 해석

연결 중 또는 획득 중인 모의 카메라를 0이 아닌 오류 코드로 Faulted 상태에 둡니다. 잘못된 상태나 코드 0은 오류입니다.

전환 시 대기 프레임과 트리거가 정리되고 관련 통계가 갱신됩니다. 복구는 Faulted 상태에서 recover로 수행하며 실제 장치 장애를 발생시키는 동작은 아닙니다.

장애 상태와 복구

fail은 실제 장치를 제어하지 않는 SimulatedCamera의 상태를 Faulted로 전환합니다. 현재 상태는 Connected 또는 Acquiring이어야 하고 code는 0이 아니어야 합니다. 다른 상태나 code=0은 ZResult 오류이며 정상 상태 전이로 취급하지 않습니다.

전환 시 대기 프레임과 트리거를 정리하고 관련 통계를 갱신합니다. 예를 들어 획득 중 오류 코드 7을 주면 모의 카메라는 Faulted 상태가 되고 코드 7을 기록합니다. 실패 이전에 대기 중인 항목을 정상적으로 계속 처리한다고 가정하지 말고 정보와 통계를 확인합니다.

recover는 Faulted에서만 호출할 수 있으며 성공하면 오류 코드를 지우고 Connected로 돌아갑니다. 다시 획득하려면 상태에 맞게 시작 절차를 수행합니다. 이 동작은 소프트웨어 시뮬레이터의 상태 전이이며 실제 카메라 장애를 발생시키거나 네트워크에 명령을 보내는 API가 아닙니다.

판독과 확인 사례

대기열 정리는 현재 들어 있던 프레임 수를 discarded 통계에, 취소된 대기 트리거 수를 cancelled_triggers 통계에 반영하는 경로입니다. 테스트에서 전후 상태를 비교하면 장애 시 큐가 계속 처리되는 경우와 명확히 구분할 수 있습니다. 통계는 생성된 실제 영상의 품질 점수가 아닙니다.

recover는 오류 상태를 Connected로 돌리지만 자동으로 Acquiring을 재시작하지 않습니다. 이후 프레임을 제공하려면 상태에 맞는 start와 입력 제공 절차를 다시 수행합니다. code=0이나 허용되지 않은 상태의 fail은 정상 Faulted 전환이 아니라 오류로 확인해야 합니다.
