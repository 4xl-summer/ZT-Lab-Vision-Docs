pub fn included(&self) -> usize

Returns the number of included pixels.

포함 픽셀 수

검사에 포함된 픽셀 수를 usize로 반환합니다. 같은 점수라도 포함된 범위가 달라졌다면 비교 대상이 바뀐 것이므로 마스크와 이미지 크기를 함께 기록합니다.

이 값은 해당 입력과 옵션으로 수행한 한 번의 검사 결과입니다.

포함 픽셀 수

included는 구조 유사도 계산에 포함된 픽셀 수를 반환합니다. defect_count는 그중 결함으로 분류된 수이고 score는 가중 전체 유사도입니다. 세 값은 서로 다른 단위와 의미를 갖습니다.

항목확인할 내용
included유사도 계산에 포함된 픽셀 수
defect_count결함으로 분류된 픽셀 수
score가중 전체 유사도
map / defect_mask위치별 결과와 결함 마스크

예를 들어 포함 100픽셀과 결함 4픽셀이라면 단순 비율은 4/100=4%입니다. 이 비율만으로 score의 값을 계산하거나 유사도 기준을 역으로 추정하지 않습니다. mask와 ROI 설정에 따라 포함 대상이 달라질 수 있습니다.
