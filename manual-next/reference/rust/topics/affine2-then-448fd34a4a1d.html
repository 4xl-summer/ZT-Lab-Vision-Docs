pub fn then(&self, next: &Affine2) -> Result<Affine2, ZError>

Applies self first, then next.

사용과 결과 해석

현재 변환을 먼저 적용하고 next를 그 결과에 적용하는 새 변환을 반환합니다. 두 변환의 계수 및 합성 결과를 검증하므로 유효하지 않은 입력이나 비유한 결과는 오류입니다. 객체를 수정하는 연산이 아닙니다.

순서는 결과를 바꿉니다. 점 (1,1)에 (3,0) 이동을 먼저 하고 2배 확대하면 (8,2)이지만, 확대 후 이동하면 (5,2)입니다. 원하는 좌표계의 순서에 맞춰 결합하십시오.

좌표계산
x′a × x + b × y + tx
y′c × x + d × y + ty

합성 순서 확인

점 (1,1)을 먼저 x로 3 이동하고 2배 확대하면 (8,2)입니다. 확대를 먼저 하고 이동하면 (5,2)이므로 순서는 바꿀 수 없습니다. 합성된 결과를 개별 두 단계의 결과와 비교하면 방향 오류를 찾기 쉽습니다.
