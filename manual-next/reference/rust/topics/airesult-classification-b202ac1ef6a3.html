분류 결과

분류 출력이면 점수 슬라이스와 클래스 번호를 Some으로 반환하고 다른 작업의 출력이면 None을 반환합니다. 클래스 번호는 모델의 레이블 순서와 연결해 해석합니다.

AiTask와 입력 조건을 결과에 함께 보관합니다. 빌린 슬라이스는 AiResult가 살아 있는 동안 사용하며, acquire_map의 반환 영상은 별도의 소유 공유입니다.

입력과 결과 확인

AiResult::classification은 출력이 분류인 경우에만 점수 슬라이스와 u32 클래스 번호를 Some으로 반환합니다. 검출·분할 등 다른 출력이라면 None이므로 클래스 번호 0인 정상 분류와 구별해야 합니다. 점수 슬라이스는 결과에서 빌린 참조입니다.

예를 들어 반환 점수의 인덱스 1이 모델의 두 번째 레이블에 대응한다면 그 이름은 모델의 레이블 순서에서 찾아야 합니다. 수치만 보고 임의의 클래스 이름을 붙이지 말고 모델 버전과 입력 영역을 함께 기록하십시오. 반환 클래스 번호와 점수 배열도 서로 다른 값입니다.

점수 참조는 AiResult가 살아 있는 동안 사용합니다. 필요한 값을 더 오래 보관하려면 소유 자료로 복사할 수 있습니다. 분할·이상 맵이 필요한 과제는 acquire_map으로 별도 소유 공유 영상을 얻는 경로이며 분류 점수 슬라이스와 같은 출력이 아닙니다.

맵별도 획득 영상과 분류 참조를 구별합니다.

예를 들어 점수 슬라이스가 세 클래스에 대응하면 길이와 순서가 모델이 사용하는 세 레이블의 순서와 맞아야 합니다. 반환된 클래스 번호는 정수이고 슬라이스는 결과 내부를 빌린 값이므로, 결과를 더 이상 보관하지 않을 계획이라면 필요한 점수와 번호를 소유 자료로 복사하십시오. 출력이 분류가 아니어서 None인 경우를 확률이 모두 0인 분류로 표시하면 모델 과제를 잘못 해석하게 됩니다.

예를 들어 클래스 ID가 1이라는 결과는 모델의 두 번째 레이블을 가리키는 해석이 필요하며, 숫자 1만으로 레이블 이름을 알 수 없습니다. 모델 사양과 레이블 목록을 같은 버전으로 유지하십시오.

점수 슬라이스를 소유 벡터로 복사할 때도 원래 클래스 순서를 보존해야 번호와 점수가 계속 대응합니다. 다른 과제의 None은 오류로 임의 해석하지 않습니다.
