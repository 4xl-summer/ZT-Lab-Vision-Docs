pub fn add_measured_line( &mut self, id: u64, frame: Option<usize>, model: &LineMeasurementModel, ) -> ZResult<usize>

Adds an independently owned line measurement configuration.

추가와 실행 결과

복합 모델 빌더에 직선 측정 구성을 추가합니다. id는 해당 특징을 식별하고 frame은 선택적 프레임이며 model은 검증된 직선 계측 모델의 참조입니다. 빌더에 추가된 구성은 독립 소유되므로 입력 모델의 참조만 결과로 저장하는 방식과 구별하십시오. 반환된 인덱스를 다른 특징이나 허용치 설정과 연결할 때 같은 빌더의 결과인지 확인합니다. 기준 선분을 따라 놓인 프로브가 실제 경계를 가로지르는지 확인합니다. 모델 추가 성공과 이후 영상에서 형상 적합이 성공하는 것은 별개의 단계입니다. 관측 결과의 상태와 채택점, ROI 로컬 픽셀 좌표를 실행마다 확인하고 결측 형상을 정상적인 좌표 0으로 대체하지 마십시오.

입력과 결과확인할 내용
식별자선 형상에 부여할 ID를 전달합니다.
프레임선택적 fixture 인덱스와 좌표 기준을 확인합니다.
모델검증된 선 측정 구성을 참조로 전달합니다.
반환추가된 형상 인덱스와 나중의 적합 상태를 구분합니다.
