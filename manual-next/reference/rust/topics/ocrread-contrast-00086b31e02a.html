입력 밝기 대비

인식 결과의 contrast를 f64로 반환합니다. 이는 원시 픽셀 밝기의 차이이며 신뢰도 확률이나 인쇄 품질 인증 등급으로 취급하지 않습니다.

OcrRead는 불변 결과 스냅샷입니다. 문자열과 문자 슬라이스는 이 결과를 빌리므로 소유자가 살아 있는 동안 사용하고 더 오래 유지할 값은 복사합니다.

준비 영역의 대비

contrast는 OCR 결과에 기록된 원시 픽셀 밝기 범위를 f64로 반환합니다. 수치를 읽을 때 해당 입력 영역과 OcrSpec의 min_contrast를 함께 확인합니다. 이는 인식 확률이나 표준 인쇄 품질 등급이 아닙니다.

예를 들어 밝기 값이 20과 180인 두 수준의 단순 차이는 160입니다. 실제 반환 수치가 기록된 입력 영역과 처리 조건을 확인하고, 전체 화면의 평균 밝기와 동일한 양으로 취급하지 않습니다.

대비가 기대보다 낮으면 조명, 노출과 ROI가 문자 전체를 포함하는지 살펴봅니다. contrast만으로 문자열이 맞다고 결정하지 말고 status, reasons 및 글자별 결과를 함께 읽습니다.
