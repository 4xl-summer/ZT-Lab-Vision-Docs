pub fn to_rgb(&self, format: PixelFormat) -> ZResult<ZImage>

Reconstructs an image in the requested supported color format.

사용과 결과 해석

채널 평면을 지정한 지원 색상 픽셀 형식의 영상으로 재구성합니다. 지원하지 않는 형식이나 유효하지 않은 입력은 오류입니다.

출력 채널 순서는 요청 형식에 따릅니다. 왕복 처리에서 변환 및 출력 형식의 수치 정밀도를 고려하고 원본 값과의 차이를 확인하십시오.

색 평면에서 영상으로

ColorPlanes가 보유한 각 성분 평면을 지정된 지원 PixelFormat의 색 영상으로 재구성합니다. 입력의 색 공간과 채널 순서를 알고 있어야 같은 인덱스를 올바른 성분으로 해석할 수 있습니다. 반환값은 ZResult이므로 지원하지 않는 형식이나 유효하지 않은 평면을 정상 영상으로 취급하지 말고 오류를 확인하십시오.

처리 순서는 평면의 space 확인, 필요한 채널 처리, 출력 형식 선택, to_rgb 실행, 결과 영상 사용입니다. 예를 들어 RGB와 BGR은 같은 세 색 성분을 서로 다른 저장 순서로 표현합니다. 출력 자료형의 정밀도와 범위에 따라 왕복 오차가 생길 수 있으므로 원본과 비교할 때 형식과 허용 오차를 함께 기록하십시오.
