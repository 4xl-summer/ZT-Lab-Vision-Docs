pub fn fit(&self) -> Option<&EllipseFit>

Returns the fit when available.

결과 확인 순서

타원 측정의 결과 객체에서 호출합니다. 적합 형상이 있으면 그 형상을 빌린 참조로 제공하고 없으면 None입니다. 결과 객체보다 참조를 오래 사용할 수 없으며, None은 원점이나 0 크기의 형상이 아닙니다. 입력 영상의 ROI 로컬 좌표로 얻은 기하를 다른 ROI와 비교할 때는 원점을 공통 기준으로 맞추고 형상의 유효 상태도 함께 보존하십시오.

확인 항목사용 기준
대상타원 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용Some의 형상과 None을 분기해 처리합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

Some(&EllipseFit)이면 결과가 보유한 적합 타원을 빌려 읽고 None이면 형상이 없습니다. 빌린 참조는 결과 객체가 살아 있는 동안만 사용할 수 있습니다.

중심이 (0,0), 반축이 4와 2, 회전이 0인 타원의 축 끝은 (±4,0), (0,±2)입니다. 반축은 전체 지름이 아니며 실제 결과는 관측점과 같은 ROI 로컬 픽셀 기준으로 해석해야 합니다.

항목확인할 내용
Some적합 타원의 빌린 참조입니다.
None형상을 얻지 못한 상태이며 원점이 아닙니다.
반축4와 2는 전체 축 길이 8과 4입니다.
수명참조를 결과 객체보다 오래 보관하지 않습니다.
