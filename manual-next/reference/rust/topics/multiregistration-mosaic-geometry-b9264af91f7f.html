pub fn mosaic_geometry(&self, scale: f64) -> ZResult<MosaicGeometry>

Computes the union canvas in common coordinates.

사용과 결과 해석

정합된 입력들의 공통 좌표 합집합을 포함하는 캔버스 기하를 지정 scale로 계산합니다. 유효하지 않은 배율이나 표현할 수 없는 캔버스는 오류입니다.

결과의 원점, 폭·높이, 배율을 함께 보존해야 모자이크 픽셀과 공통 좌표를 연결할 수 있습니다. 배율은 공통 픽셀당 출력 픽셀입니다.

공통 좌표와 캔버스

mosaic_geometry는 정합된 입력 영상들의 픽셀 중심 사각형을 공통 좌표계로 옮긴 뒤 합집합을 포함하는 출력 캔버스의 기하를 계산합니다. 이 호출은 모자이크 영상 자체를 렌더하지 않습니다. scale은 유한한 양수인 공통 픽셀당 출력 픽셀 배율입니다.

반환 MosaicGeometry에는 width, height, origin_x, origin_y와 scale이 있습니다. 예를 들어 scale이 2이면 공통 좌표의 한 픽셀 간격은 출력에서 두 픽셀 간격에 해당합니다. 원점과 배율을 함께 보관해야 출력 캔버스 위치를 공통 좌표와 연결할 수 있으며 크기만으로는 위치를 복구할 수 없습니다.

입력 정합이 없거나 배율이 유효하지 않은 경우, 또는 원근 변환이 무한대를 가로지르는 경우에는 오류가 될 수 있습니다. 실제 영상이 필요하면 mosaic 또는 mosaic_on_canvas를 사용하고 결과의 유효 마스크도 확인합니다. geometry 계산의 성공과 각 입력의 정합 품질은 별도로 평가합니다.

판독과 확인 사례

matrices는 공통 로컬에서 각 입력 영상 로컬로 향하는 행렬입니다. 캔버스 범위를 계산할 때 구현은 각 입력의 픽셀 중심 사각형을 공통 공간으로 연결하므로 행렬의 방향을 바꾸어 해석하면 원점과 범위를 잘못 이해할 수 있습니다. common_index도 함께 기록합니다.

geometry만 얻은 상태에서는 합성 픽셀이나 유효 마스크가 아직 만들어지지 않습니다. 이어 mosaic_on_canvas 등으로 영상을 만들고 마스크를 취득한 뒤, 겹침 정책과 같은 출력 좌표를 확인합니다. scale 변경은 해상도와 필요한 출력 크기에 영향을 주므로 저장공간도 확인합니다.
