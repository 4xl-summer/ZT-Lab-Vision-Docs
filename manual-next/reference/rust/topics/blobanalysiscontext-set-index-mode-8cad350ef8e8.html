결과와 사용 순서

입력과 결과 해석

분석 설정과 현재 결과를 관리하는 컨텍스트입니다. 연결 방식이 달라지면 새 설정에 대해 다시 계산해야 합니다. 인덱스 모드는 현재 결과의 조회 방식만 바꾸며 재계산하지 않습니다. 계산 실패 시 현재 결과가 지워질 수 있습니다.

라벨과 목록 인덱스

by_label은 현재 결과를 get으로 조회할 때 selector의 의미를 선택합니다. false이면 0부터 시작하는 성분 목록 인덱스이고 true이면 0이 아닌 블롭 라벨입니다. 두 값은 모두 정수지만 같은 숫자가 같은 성분을 뜻한다고 가정할 수 없습니다.

단계 또는 항목확인할 내용
false0부터 시작하는 목록 인덱스
true0이 아닌 성분 라벨
예시 인덱스 0현재 목록의 첫 성분
조회 방식 변경현재 결과를 유지하며 재계산하지 않음
generation조회 모드 변경만으로 증가하지 않음

결과를 사용할 때

이 설정은 조회 방식만 변경합니다. 현재 결과를 무효화하거나 재계산하지 않으며 generation도 바꾸지 않습니다. 예를 들어 목록의 첫 성분을 인덱스 모드에서는 selector 0으로 조회하지만 라벨 모드에서는 그 성분의 실제 비영 라벨을 사용해야 합니다.
