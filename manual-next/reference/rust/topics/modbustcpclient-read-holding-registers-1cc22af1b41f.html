사용 순서와 결과 확인

0기반 address에서 count개의 holding register를 Modbus 기능 3으로 읽습니다. count는 1..125이고 address+count는 65536 이하여야 합니다. 반환 Vec<u16>은 주소 순서입니다. 전송 또는 잘못된 프로토콜 응답은 연결을 끊으며 다시 사용하려면 reconnect가 필요합니다.
