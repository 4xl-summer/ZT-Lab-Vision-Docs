fn as_shared_ops(&self) -> Self::Target

Clones an Arc lease for the shared engine model.

변환과 소유권

공유 엔진 모델의 Arc 임대를 복제해 반환합니다. 기존 facade를 소비하지 않으며 공유 대상 자체를 깊은 복사하는 의미로 해석하지 않습니다.

공유 임대와 소유권

AsSharedOps는 facade에서 공유 엔진 표현의 Arc 임대를 복제해 연관 타입 Target으로 반환하는 트레이트입니다. self를 &self로 빌리므로 호출은 원래 facade의 소유권을 소비하지 않습니다. 복제되는 것은 공유 참조의 임대이며 모델 데이터 전체의 깊은 복사라고 해석하면 안 됩니다.

예를 들어 구체 모델 M과 그 공유 임대 A를 얻은 뒤에도 M은 여전히 사용할 수 있습니다. A와 M은 같은 공유 대상을 가리킬 수 있지만 각 소유 참조의 수명은 별도입니다. 어느 쪽 하나를 내려놓았다고 다른 쪽까지 동시에 무효화되는 깊은 복사 값으로 취급하지 마세요. 정확한 Target과 공유 데이터의 동작은 구현한 타입에서 확인해야 합니다.

실행과 판독에서 확인

이 메서드를 확장 트레이트 메서드로 사용하려면 AsSharedOps가 스코프에 있어야 합니다. 원본을 소비해 내부 표현의 소유권을 꺼내는 into 계열과, 빌림에서 새 공유 임대를 얻는 이 호출은 서로 다른 수명 선택입니다. Arc라는 사실만으로 구체 모델이 제공하지 않은 변경 가능성이나 동시 실행 안전성을 추가로 보장하지 않습니다.
