fn from_engine(value: Self::Target) -> Self

Transfers the supplied engine representation into the facade owner.

변환과 소유권

연관 타입 Target의 엔진 표현을 받아 facade 소유 값으로 이전합니다. 이 트레이트의 호출은 입력 값의 소유권을 받으며 정확한 Target은 구현하는 구체 타입이 결정합니다.

입력 표현을 이후에도 독립적으로 사용해야 한다면 해당 타입이 제공하는 공유 또는 복제 방법을 먼저 확인하십시오. 트레이트 이름만으로 다른 표현과의 변환 가능성을 가정하지 않습니다.

대상 타입구현별 연관 타입 Target

Rust에서 확장 메서드를 사용하려면 해당 bridge 트레이트를 스코프에 가져와야 합니다. 구체 구현의 수명과 오류 조건을 함께 확인하십시오.

엔진 값을 facade로 이동

FromEngine은 구현별 연관 타입 Target의 엔진 표현을 값으로 받아 facade 소유 값 Self로 이동하는 브리지 트레이트입니다. 입력은 빌린 참조가 아니라 소유 값이므로 호출한 뒤 원래 변수를 다시 사용하려면 별도 공유나 복제가 가능한지 구체 타입에서 먼저 확인해야 합니다.

실제 AcquiredFrame 구현에서는 Target이 엔진 AcquiredFrame입니다. from_engine은 프레임 정보를 옮기고 내부 영상을 facade ZImage로 감싸며 픽셀을 복사하지 않습니다. 반면 OcrEngine 구현의 Target은 엔진 모델의 Arc입니다. 같은 트레이트 이름이라도 Target과 공유 방식은 구현마다 다릅니다.

실행과 판독에서 확인

트레이트 메서드를 사용하려면 해당 FromEngine 구현과 연관 타입을 확인하고 트레이트를 스코프에 가져옵니다. 이 변환은 영상을 새로 취득하거나 모델을 재학습하는 연산이 아닙니다. 결과 facade의 수명과 원본 소유권 이동을 Rust 컴파일러의 이동 규칙에 맞춰 관리하고, 임의의 타입 사이에 변환이 있다고 추측하지 마세요.
