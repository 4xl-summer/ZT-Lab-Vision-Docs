pub fn inspect_directional( &self, image: &ZImage, options: VariationInspectOptions, ) -> ZResult<VariationDirectionalResult>

Runs the existing directional threshold inspection.

방향별 변동 검사

입력 영상과 검사 옵션을 사용해 하한과 상한 및 어두운 방향·밝은 방향 마스크를 가진 VariationDirectionalResult를 계산합니다. 두 방향은 다른 종류의 변화를 나타냅니다.

결과의 각 영상 접근자는 독립 영상 공유를 반환합니다. 동일 위치의 기준 및 임계 영상과 마스크를 비교하며 결과와 얻은 영상의 소유 수명을 구분합니다. 정렬 실패나 잘못된 옵션은 오류로 처리합니다.

결과와 조건을 함께 읽기

inspect와 같은 엄격한 결함 규칙을 사용하되 낮은 임계 영상과 높은 임계 영상, 어두운 쪽과 밝은 쪽의 결함 마스크를 각각 반환합니다. 기준 평균이 100이고 낮은 허용량이 5, 높은 허용량이 8이라면 하한은 95, 상한은 108입니다. 입력 94는 어두운 쪽 결함이고 109는 밝은 쪽 결함이며 95와 108은 한도와 같아 초과가 아닙니다. 제외된 픽셀은 반환 영상에서 0입니다. 각 접근자로 얻은 영상과 결과 객체의 수명을 구분하고, 마스크의 0을 모든 위치가 검사됐다는 뜻으로 해석하지 않습니다.

항목판독 기준
lower평균 − 낮은 쪽 허용량
upper평균 + 높은 쪽 허용량
dark / bright각 방향으로 한도를 초과한 마스크
제외 픽셀반환 영상의 값 0
