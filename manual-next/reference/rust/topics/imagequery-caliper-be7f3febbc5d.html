pub fn caliper(self, spec: &CaliperSpec) -> ZResult<CaliperQuery>

Plans caliper edge measurement.

사용과 결과 판독

CaliperSpec을 이용해 에지 검출 쿼리를 계획합니다. self를 소비하므로 같은 원본 계획에서 다른 처리 경로를 만들려면 먼저 적절히 복제해야 합니다. 실행 후의 에지 목록과 계획 생성은 다른 단계이며 극성은 선분의 시작점에서 끝점으로 진행하는 방향을 따릅니다. 소수 위치와 부호 있는 강도를 결과에서 함께 확인하십시오.

단계확인할 내용
계획CaliperSpec의 선분과 선택 기준을 사용합니다.
방향극성은 시작점에서 끝점으로 읽은 부호입니다.
소유권self를 넘기므로 필요한 분기는 미리 복제합니다.
실행에지 목록과 실행 오류를 따로 확인합니다.

결과 판독과 예

caliper는 ImageQuery를 소비하고 CaliperSpec이 지정한 에지 측정의 지연 계획을 만듭니다. 같은 원본에서 다른 처리를 분기하려면 이 호출 전에 필요한 복제를 해야 합니다.

극성은 선분의 시작점에서 끝점으로 강도가 변하는 부호입니다. 진행 방향을 뒤집으면 동일한 물리 경계도 반대 극성으로 나타날 수 있습니다. 실행 후 빈 목록과 호출 오류를 구분하십시오.
