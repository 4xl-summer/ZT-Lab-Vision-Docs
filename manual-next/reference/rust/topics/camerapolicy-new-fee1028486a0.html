사용과 결과 해석

제공자가 보고한 기능, 지원 픽셀 형식 식별자 목록과 초기 설정으로 소프트웨어 정책을 만듭니다. 노출·게인 범위, 센서 내부 ROI, 지원 형식, 트리거 라인, 버스트, 큐 용량과 시간 제한을 검증하고 잘못된 설정은 오류로 거부합니다.

생성 직후 큐와 대기 프레임 수는 비어 있습니다. 이 객체는 실제 장치를 검색하거나 제어하지 않으며 프레임과 트리거 이벤트를 호출자가 제공해야 합니다.

초기 설정의 검증

정책은 제공받은 기능과 형식 목록만 사용하여 설정을 검증합니다. 중첩이 필요한 경우에도 기능이 이를 지원해야 합니다. 생성 후 이벤트를 호출자가 공급하며 실제 장치 탐색이나 프레임 획득은 별도로 구현해야 합니다.
