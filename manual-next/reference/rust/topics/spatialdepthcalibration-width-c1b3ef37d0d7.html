pub fn width(&self) -> usize

Width of the calibrated grid.

가로 크기 조회

이 메서드는 보유한 깊이 격자의 가로 크기를 픽셀 수로 반환합니다. 크기는 물리적 길이가 아니라 각 행에 들어 있는 샘플의 개수입니다. 픽셀 위치를 좌표로 바꾸려면 별도의 수평 간격과 원점을 함께 사용해야 합니다.

가로 2, 세로 2인 격자의 행 우선 배열에는 네 슬롯이 있습니다. 오른쪽 열의 인덱스는 1이지만 실제 x 좌표는 원점 x에 수평 간격을 더한 값입니다. 보정 격자에서는 가로와 세로가 적용 대상 영상의 크기와 일치하는지도 검사합니다.

확인 항목해석
반환가로 방향 픽셀 수
배열 관계전체 슬롯 = 가로 × 세로
좌표 변환원점 x + 열 인덱스 × 수평 간격
보정 적용모델과 영상 크기를 비교
