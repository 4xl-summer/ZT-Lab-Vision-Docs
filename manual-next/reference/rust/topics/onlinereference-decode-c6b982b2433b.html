Restores state against a template and explicit bounds.

사용과 결과 해석

인코딩된 통계 상태를 템플릿과 함께 복원합니다. 버전, 체크섬, 입력 크기 제한 및 픽셀 수 제한을 검사하고 저장된 형식·크기·ROI 원점이 템플릿과 맞지 않으면 오류입니다.

복원된 누적기는 저장 당시의 표본 수와 통계를 이어서 사용할 수 있습니다. 잘못되거나 잘린 바이트를 정상 상태로 취급하지 마십시오. C# 래퍼는 입력 바이트를 복사하고 64 MiB 상한도 검사합니다.

저장 상태 복원

template, bytes, max_bytes, max_pixels를 전달해 OnlineReference 상태를 복원합니다. template은 복원할 상태의 영상 기준이며 바이트 길이와 픽셀 한도는 명시적으로 검사됩니다. 단순히 숫자 배열을 새 참조로 복사하는 호출이 아닙니다.

항목확인할 내용
template형식·크기 등 기준 영상
bytes직렬화된 참조 상태
max_bytes허용 바이트 한도
max_pixels허용 픽셀 한도

encode로 얻은 완전한 데이터를 사용하고 복원 후 count 및 freeze 결과를 원래 상태와 비교합니다. 템플릿이 호환되지 않거나 한도를 넘는 데이터는 ZResult 오류가 될 수 있으므로, 실패를 빈 참조의 정상 결과로 처리하지 않습니다.
