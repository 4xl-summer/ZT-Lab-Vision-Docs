Runs quality inspection in the selected coordinate mode.

좌표 모드를 지정한 품질 검사

학습 영상과 검사 영상, 품질 옵션, 좌우 선택 배열에 더해 BeadCoordinateMode를 명시하여 품질을 검사합니다. 선택적 world 또는 world_maps는 해당 매핑에 사용됩니다.

입력 경로와 선택 배열이 같은 표본 순서인지, 선택한 모드가 제공한 매핑과 맞는지 확인합니다. 반환 오류와 측정 후 불합격을 구분하고 좌표 단위를 결과와 함께 기록합니다.

좌표 모드를 지정한 품질 검사

학습 영상과 검사 영상, 품질 옵션, 선택적인 좌·우 배열에 BeadCoordinateMode를 명시해 품질을 계산합니다. world 또는 world_maps는 선택한 좌표 해석에 사용하는 선택적 입력입니다.

예를 들어 픽셀 단위 길이 10과 물리 단위 길이 10은 숫자가 같더라도 동일한 길이가 아닙니다. 좌표 변환과 단위를 함께 기록하고, ROI 로컬 점과 글로벌 위치를 혼합하지 않습니다.

left와 right 배열의 각 항목은 경로 탐침의 순서와 대응해야 합니다. 다른 프레임이나 재정렬한 배열을 사용하면 의도하지 않은 탐침을 선택할 수 있습니다. 입력 영상과 기준 경로가 같은 대상 위치를 가리키는지 먼저 살펴봅니다.

반환 BeadQualityResult의 측정값과 위반 구간을 해당 모드 및 옵션에 연결합니다. 처리 오류와 유효한 품질 결과의 불합격은 다른 경로입니다. 단위가 같은지 확인하기 전 두 실행의 폭을 직접 비교하지 않습니다.
