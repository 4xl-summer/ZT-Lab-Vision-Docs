pub fn inpaint_anisotropic( &self, mask: &Self, options: InpaintOptions, ) -> ZResult<(Self, InpaintReport)>

Fill a masked region using anisotropic diffusion and return its report.

마스크 영역 복원

현재 영상과 마스크, InpaintOptions로 비등방성 확산을 수행하고 소유 영상과 InpaintReport를 튜플로 반환합니다. 마스크의 0이 아닌 위치가 복원 대상입니다.

보고서의 반복 수, 최대 변화, 수렴 및 정체를 함께 읽습니다. 복원 결과는 추정된 픽셀이며 실제로 가려졌던 원본 값의 정확한 복구를 보증하지 않습니다.

마스크 영역의 확산 복원

mask와 InpaintOptions를 사용해 0이 아닌 마스크 픽셀만 비등방성 확산으로 복원하고 (ZImage, InpaintReport)를 반환합니다. 입력 영상과 마스크는 같은 기하를 가리켜야 합니다.

iterations는 반복 한도이며 timestep은 0보다 크고 0.25 이하, kappa는 양수, tolerance는 0 이상인 조건을 확인합니다. 예를 들어 timestep=0.5는 이 범위를 벗어나 유효한 처리 설정으로 취급하지 않습니다.

보고서의 iterations, max_change, converged 및 stalled를 함께 읽습니다. 반복이 종료됐다는 사실과 수렴했다는 사실은 구별해야 합니다. 마스크 밖에 원래 유지할 부분과 복원 대상이 올바르게 표시되었는지도 결과와 대조합니다.

결과 영상은 별도 소유 ZImage이고 보고서는 값입니다. 복원 픽셀은 주변과 설정을 이용한 추정이므로 가려졌던 실제 값을 정확히 되찾았다고 단정하지 않습니다. 입력·마스크·옵션을 보관해 같은 처리를 재검토합니다.
