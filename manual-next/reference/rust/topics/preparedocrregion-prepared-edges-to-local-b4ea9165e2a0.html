준비 좌표에서 로컬 좌표

준비 영상의 모서리 좌표를 입력 이미지 로컬 좌표로 변환하는 Affine2 값을 반환합니다. ROI의 회전과 준비 과정을 고려할 때 사용하며 전역 좌표 변환과 구분합니다.

준비 영역은 OCR 판독을 위한 입력이며 문자 인식 결과가 아닙니다. 반환된 값 또는 영상의 타입에 맞는 소유 관계를 확인하고 실제 판독 상태는 OcrRead에서 읽습니다.

준비 모서리를 로컬로 변환

이 접근자는 준비 영상의 모서리 좌표를 입력 이미지 로컬 좌표로 바꾸는 Affine2 값을 반환합니다. 좌표 변환은 한 점의 위치를 바꾸는 값이며 입력 영상을 다시 샘플링하거나 문자를 판독하지 않습니다.

ROI와 90도 단위 회전이 적용되면 준비 영상의 좌표와 입력 로컬 좌표가 달라집니다. 반환 변환을 준비된 모서리에 적용한 뒤 입력 이미지에 그립니다. 단순히 두 영상의 크기가 같다는 이유만으로 항등 변환이라 가정하지 않습니다.

로컬 점을 전체 프레임에서 사용하려면 원본의 좌표 기준을 별도로 확인합니다. 준비→전역 변환도 제공되므로 이미 전역 변환을 적용한 점에 ROI 원점을 다시 더하지 않도록 두 경로를 구분합니다.

예를 들어 ROI 원점이 (100,50)인 단순 이동이라면 로컬 (4,3)은 글로벌 (104,53)입니다. 이 예는 원점 이동만 보여 주며 실제 회전된 준비 영상에는 반환 Affine2가 필요합니다. 변환 값과 획득 영상의 수명도 서로 다릅니다.
