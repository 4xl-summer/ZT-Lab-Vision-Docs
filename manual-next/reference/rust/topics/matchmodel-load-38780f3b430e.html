pub fn load(path: impl AsRef<Path>) -> ImageIoResult<Self>

Load the existing versioned matching model format.

관련 입력의 확인된 조건

학습된 템플릿 상태를 소유하는 매칭 모델입니다.

호출 맥락과 결과 해석

save가 작성한 버전 있는 매칭 모델 파일을 읽어 독립된 모델을 복원합니다. path는 비어 있지 않은 경로여야 합니다. 템플릿 이미지 파일이 아니라 학습된 모델 형식을 입력으로 사용합니다.

복원한 모델은 스코프가 끝나면 정리됩니다. 같은 영상과 MatchSpec을 사용해 저장 전후의 검색 결과를 비교하고, 로드에 실패하면 경로와 파일 완전성 및 모델 형식을 살핍니다. 검색 옵션과 검색 영상은 이 호출에서 별도로 주어지지 않습니다.

조건과 결과 판독

load는 경로에서 버전 있는 학습 매칭 모델 형식을 읽습니다. 경로가 영상 파일을 가리키는 것과 모델 파일을 가리키는 것은 다르며, 검색할 영상과 MatchSpec은 로드 후 검색 호출에서 별도로 제공합니다.

실패 시 ImageIoResult 오류를 처리하고 파일 경로·형식·완전성을 확인합니다. 성공한 모델의 info로 종류, 템플릿 크기와 기준점을 확인한 뒤, 같은 입력 영상과 검색 옵션으로 저장 전후의 결과를 비교할 수 있습니다. Rust 모델 값은 스코프에 따라 소유권이 관리됩니다.

항목확인할 내용

반환성공한 MatchModel 또는 I/O 오류
