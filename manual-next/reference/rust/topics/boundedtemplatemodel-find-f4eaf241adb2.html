pub fn find( &self, image: &ZImage, options: BoundedTemplateOptions, ) -> ZResult<MatchingReport<BoundedTemplateReport>>

Searches bounded candidate positions.

관련 입력의 확인된 조건

Bounded template matching model.

호출 맥락과 결과 해석

학습된 템플릿을 지정 범위의 정수 평행이동 위치에서 검색합니다. 입력 영상은 학습 방식에 맞게 TemplateMetric::ColorNcc에는 RGB8, TemplateMetric::GraySad에는 Gray8을 사용합니다. 회전이나 배율을 탐색하는 확장 포즈 검색과 입력 해석이 다릅니다.

BoundedTemplateOptions의 포함 범위, 판정값, 결과 및 작업 상한이 함께 결과를 정합니다. 검색 결과가 비면 지정 범위와 판정값, 작업 한도부터 확인합니다. 반환 MatchingReport에 검색 결과와 종료 진단이 담깁니다.

검색 입력과 결과

학습된 BoundedTemplateModel로 검색 영상에서 후보를 찾습니다. 템플릿 학습에 사용한 metric과 검색 영상 형식이 맞아야 하며, 옵션이 정하는 탐색 범위와 결과의 위치 기준을 함께 확인해야 합니다.
