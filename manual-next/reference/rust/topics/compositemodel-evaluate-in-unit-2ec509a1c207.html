pub fn evaluate_in_unit( &self, image: &ZImage, unit: CompositeUnit, ) -> ZResult<UnitCompositeResult>

Evaluates using the requested physical or pixel unit.

사용과 결과 해석

영상에 대해 모델을 평가하고 요청한 CompositeUnit으로 표현된 결과를 반환합니다. 단위는 단순한 화면 표기가 아니라 결과의 해석에 영향을 주므로 측정 조건에 맞게 선택하십시오.

반환된 결과의 unit, 특징 값, 공차 결과와 전체 상태를 함께 보십시오. 부분 실패는 개별 특징 결과에서 확인해야 하며 반환 성공을 전체 공차 통과와 동일시하지 않습니다.

단위를 지정한 평가

입력 image에 불변 CompositeModel을 평가하고 요청한 CompositeUnit으로 UnitCompositeResult를 얻습니다. 픽셀 또는 물리 단위는 단순한 표시 문구가 아니라 반환 수치와 공차 해석에 연결됩니다.
