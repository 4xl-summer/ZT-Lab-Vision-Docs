pub fn bind_frame(&mut self, image: &ZImage) -> ZResult<()>

Binds frame geometry for later gradient calculations.

사용과 결과 해석

추출된 점의 좌표계를 영상의 크기와 ROI 원점에 결합합니다. 빈 영상이나 영상 경계 밖의 점이 있으면 오류입니다. 이 검사는 영상이 실제로 해당 체인을 추출한 원본임을 증명하지 않으므로 호출자가 그 관계를 유지해야 합니다.

프레임의 크기나 원점이 바뀌면 저장된 기울기 결과는 무효화됩니다. 다시 calculate_gradients를 실행한 후 읽으십시오. 예를 들어 폭 10인 프레임의 허용 x 범위는 0부터 9까지입니다.

프레임 결합 조건

폭 10, 높이 8이면 허용 로컬 좌표는 x=0~9, y=0~7입니다. 별도로 추출한 체인을 결합한다면 실제 추출에 사용한 영상을 호출자가 제공해야 합니다. 새 크기나 원점으로 바꾸면 기울기를 다시 계산하십시오.

항목의미와 조건
영상 크기너비와 높이가 0보다 커야 합니다.
점 범위각 점은 로컬 0부터 width−1, height−1 안
저장 기하영상 크기와 ROI 원점
검사 범위제외된 체인을 포함한 저장 점 전체
기울기다른 기하에 결합하면 저장 결과 무효화
원본 관계기하 검사만으로 추출 원본임을 증명하지 않음
다음 단계같은 기하의 영상으로 기울기 계산
