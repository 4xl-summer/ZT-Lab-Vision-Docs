Returns the fit iteration count.

결과 확인 순서

타원 측정의 결과 객체에서 호출합니다. 적합 계산에서 수행한 반복 횟수를 반환합니다. 횟수가 존재한다는 것과 수렴했다는 것은 별개이므로 수렴 플래그와 상태도 확인하십시오. 같은 결과를 다른 입력과 비교할 때는 프로브 관측, 초기 기하와 반복 설정을 같이 보관해야 차이의 원인을 추적할 수 있습니다.

결과 판독과 예

iterations는 타원 적합에서 수행한 반복 수입니다. 반환된 정수는 계산 기록이며 횟수가 크다는 사실만으로 더 정확하거나 수렴했다고 판정하지 않습니다.

같은 관측점으로 반복 설정을 바꾼 실험이라면 횟수, converged, 상태와 잔차를 같이 비교하십시오. 다른 프레임에서는 입력 점의 분포가 달라질 수 있어 반복 수만 비교해 원인을 결론내리기 어렵습니다.
