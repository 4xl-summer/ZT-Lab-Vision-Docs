입력과 결과 확인

AdvancedAiEngine::from_bytes는 Vec<u8> 모델 바이트의 소유권을 받아 고급 추론 엔진 생성을 시도합니다. 반환은 Result이므로 성공한 엔진과 RecognitionError를 분기해야 합니다. 모델 바이트가 존재한다는 사실만으로 지원되는 모델이거나 실행에 필요한 입력이 모두 맞는 것은 아닙니다.

생성된 엔진은 모델이 선언한 순서와 자료형·형상에 맞춰 텐서를 전달하는 Run 단계에서 사용합니다. 예를 들어 입력 노드가 두 개라면 첫 텐서와 둘째 텐서를 모델 순서에 맞게 준비해야 합니다. 순서를 바꾸면 각 텐서 값이 유한하더라도 입력의 의미가 달라질 수 있습니다.

이 호출은 영상 ROI를 모델 입력 크기로 자동 준비하거나 결과 텐서의 의미를 레이블로 바꾸는 명령이 아닙니다. 전처리와 후처리, 엔진 실행은 별도로 검토하십시오. 소유한 엔진과 텐서의 Rust 수명 및 결과를 관리하고 로드 실패를 검출 후보가 없는 정상 추론 결과로 바꾸지 않습니다.
