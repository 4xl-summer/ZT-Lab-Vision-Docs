pub fn fit(&self) -> Option<&RectangleFit>

Returns the fit when available.

결과 확인 순서

사각형 측정의 결과 객체에서 호출합니다. 적합 형상이 있으면 그 형상을 빌린 참조로 제공하고 없으면 None입니다. 결과 객체보다 참조를 오래 사용할 수 없으며, None은 원점이나 0 크기의 형상이 아닙니다. 입력 영상의 ROI 로컬 좌표로 얻은 기하를 다른 ROI와 비교할 때는 원점을 공통 기준으로 맞추고 형상의 유효 상태도 함께 보존하십시오.

확인 항목사용 기준
대상사각형 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용Some의 형상과 None을 분기해 처리합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

Some(&RectangleFit)은 결과가 소유한 사각형을 빌린 참조이며 None은 형상을 얻지 못한 상태입니다. 결과 객체를 해제한 뒤 참조를 사용할 수 없습니다.

반폭 4와 반높이 2이면 로컬 전체 폭과 높이는 8과 4픽셀입니다. 각도는 라디안이며 회전된 사각형의 변 길이와 화면 축에 평행한 외접 상자의 크기는 서로 다를 수 있습니다.

항목확인할 내용
centerROI 로컬 사각형 중심입니다.
half_width로컬 x 방향 반너비입니다.
half_height로컬 y 방향 반높이입니다.
angle로컬 축의 라디안 회전각입니다.
