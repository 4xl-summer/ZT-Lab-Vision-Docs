pub fn execute(&self) -> ZResult<QueryExecution<TopologyResult>>

Executes the plan, retaining its independently shareable captures.

결과 해석과 수명

준비된 위상 측정 계획을 실행하고 QueryExecution에 TopologyResult 및 공유 가능한 캡처를 보존합니다. 실제 측정은 이 호출에서 수행합니다. 실행 결과의 topology로 불변 값을 읽고 성분이나 구멍의 해석을 입력 전경 및 ROI와 연결합니다.

사용 순서와 결과 판독

TopologyQuery::execute는 준비된 영역 위상 계획을 실행하고 QueryExecution<TopologyResult>를 반환합니다. 계획을 정의하는 것과 연결 성분·구멍을 실제로 계산하는 것은 다른 단계입니다. 실행이 실패하면 ZResult의 오류를 처리하고 정상 실행에서 얻은 결과만 topology 값으로 읽습니다.

위상 값에는 전경 연결 성분 수, 둘러싸인 배경 구멍 수와 오일러 수가 포함됩니다. 예를 들어 전경 성분이 하나이고 내부 구멍도 하나라면 오일러 수는 1−1=0입니다. 연결성에 따라 대각선 접촉의 관계가 달라질 수 있으므로 원본 마스크와 사용한 연결 조건을 함께 보관합니다.

QueryExecution은 독립적으로 공유할 수 있는 캡처를 보존합니다. 캡처 영상은 같은 실행에서 지정한 이름과 해당 반환 소유권을 확인하고 결과와 연결합니다. 값이 0인 정상 위상 결과와 실행 오류를 혼동하지 말고 입력 ROI와 전경 정의를 기록한 다음 다른 프레임과 비교합니다.
