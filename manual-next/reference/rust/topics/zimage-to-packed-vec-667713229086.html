pub fn to_packed_vec(&self) -> ZResult<Vec<u8>>

보이는 Gray8 픽셀을 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<u8>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

Gray8을 행 우선으로 복사

to_packed_vec는 보이는 Gray8 픽셀을 패딩 없이 행 우선 순서의 소유 Vec<u8>로 복사합니다. 원본 행의 stride가 넓거나 ROI offset이 0이 아니어도 벡터에는 보이는 픽셀만 차례로 담깁니다. Gray8 형식 조건이 맞지 않으면 ZResult 오류를 처리해야 합니다.

형식ZResult<Vec<u8>>

벡터[1,2,3,4,5,6]
수명원본과 분리된 소유 복사

사용할 때의 판독

예를 들어 3×2 ROI의 첫 행이 [1,2,3], 둘째 행이 [4,5,6]이면 결과는 [1,2,3,4,5,6]입니다. 벡터의 길이는 6개 u8 성분이고 원본 저장소의 행 패딩은 포함되지 않습니다. 반환 벡터는 독립 소유이므로 원본 영상의 빌린 행과 수명 관계가 다릅니다.
