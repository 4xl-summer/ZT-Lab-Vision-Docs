pub fn find( &self, image: &ZImage, search_mask: Option<&ZImage>, options: &ShapeSearchOptions, total_budget: usize, max_results: usize, overlap: ShapeOverlapMode, max_iou: f64, ) -> ZResult<MatchingReport<ShapeCollectionReport>>

Searches all models with the existing global budget and overlap policy.

호출과 결과 해석

여러 형상 모델을 영상에서 검색합니다. ShapeSearchOptions는 공통 형상 검색 조건이고 total_budget은 공유 평가 예산, max_results는 반환 상한입니다. overlap과 max_iou는 후보 중복 처리의 범위와 기준입니다. 결과의 모델 id와 보고서 종료 상태를 입력 컬렉션 및 예산과 함께 해석합니다.

조건과 결과 판독

컬렉션의 여러 형상 모델을 같은 영상에서 검색합니다. ShapeSearchOptions는 공통 검색 조건이고 search_mask는 선택적 영역입니다. total_budget은 모델들이 공유하는 평가 예산, max_results는 반환 수 상한입니다.

overlap과 max_iou는 후보 사이 중복 처리 방식과 기준을 정합니다. 결과 후보의 모델 id를 컬렉션 항목과 연결하고, 결과 수뿐 아니라 MatchingReport의 평가 수와 종료 상태를 확인하세요. 예산이 종료 원인이면 작은 결과 수를 검색 공간에 후보가 없었다는 증거로 단정할 수 없습니다.

예를 들어 서로 다른 두 모델이 근접한 위치에서 후보를 냈다면 overlap 정책과 max_iou에 따라 최종 목록에서 중복 처리될 수 있습니다. 이때 각 후보의 모델 id와 점수, 공유 예산에 따른 평가 수를 함께 확인해야 모델별 탐색 조건과 결과 개수의 관계를 해석할 수 있습니다.
