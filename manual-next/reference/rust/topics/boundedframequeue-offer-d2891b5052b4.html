Rust
pub fn offer( &self, item: T, timeout: Duration, ) -> Result<FrameQueueOffer, FrameQueueError>

Timeout is a finite duration; zero performs an immediate attempt.

사용과 결과 해석

항목을 큐에 넣습니다. 공간이 있으면 Added, 가득 찬 큐에서 RejectNew이면 Full, DropOldest이면 가장 오래된 항목을 버리고 DroppedOldest를 반환합니다. Wait 정책은 시간 제한까지 공간을 기다립니다.

시간 제한 0은 즉시 시도이고 종료된 큐는 Closed를 반환합니다. 제한 시간이 지났으면 TimedOut이며 유효하지 않은 제한이나 잠금 오류는 별도의 오류입니다. 결과를 확인해 유실을 처리하십시오.

가득 찬 큐에서의 선택

용량 2에 A, B가 있는 상태에서 C를 제안한다고 가정하십시오. DropOldest 결과는 B, C이고 DroppedOldest가 반환됩니다. 유실 여부를 소비자에게 숨기지 않으려면 이 반환값을 기록해야 합니다.

상태동작
공간 있음항목을 뒤에 넣고 Added를 반환합니다.
RejectNew항목을 넣지 않고 Full을 반환합니다.
DropOldest선두 항목을 버리고 새 항목을 넣습니다.
Wait공간 또는 종료를 제한 시간까지 기다립니다.
시간 초과TimedOut을 반환합니다.
닫힘Closed를 반환합니다.
시간 0기다리지 않고 즉시 시도합니다.
