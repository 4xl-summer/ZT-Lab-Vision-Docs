Acquires the shifted image.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언은 ZImage입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

이동 연산 결과에서 영상을 취득합니다. 반환 영상의 크기, 원점과 경계 표현을 확인하고 결과 객체와 영상 핸들의 수명을 각각 관리하세요.

이동 결과에서 영상 취득

acquire_image는 이동 결과에 담긴 ZImage를 반환합니다. 숫자로 요약한 이동 정보와 실제 이동 영상은 다른 결과이므로 영상의 크기, 픽셀 형식 및 원점을 확인한 뒤 표시나 후속 처리에 전달하세요. 반환된 영상과 ShiftResult는 각각의 값으로 수명을 관리합니다.
