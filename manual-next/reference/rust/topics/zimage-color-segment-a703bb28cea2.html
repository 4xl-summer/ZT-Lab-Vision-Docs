pub fn color_segment(&self, target: LabColor, threshold: f64) -> ZResult<Self>

Produces a mask of colors within the given CIE76 distance.

기준 색 주변의 선택

Rust의 ZImage 호출은 현재 영상에 이 처리를 적용합니다. 기준 Lab 색상과 허용 거리에 따라 색상을 선택하는 처리입니다. 입력의 색 표현과 참조 Lab 값의 기준 조건이 일치해야 의미 있는 색 거리를 비교할 수 있습니다. 거리 기준을 바꾸면 같은 픽셀도 선택 영역에 들어오거나 빠질 수 있습니다.

현재 영상에서 얻은 결과의 해석에서는 예를 들어 기준색과 같은 Lab 좌표는 색 거리 0입니다. 입력 조명과 변환 백색점이 다르면 실제 표면이 같아도 값이 달라질 수 있으므로 설정과 결과를 함께 보관합니다. 선택된 마스크는 제품 합격 판정 자체가 아닙니다.

Rust 반환 값의 소유와 참조 수명을 시그니처에서 확인합니다. 입력 오류와 실제 계산된 빈 결과는 서로 다른 경로이므로 오류를 정상 판정으로 바꾸지 않습니다.

결과 판독과 예

입력 색을 D50/2도 Lab으로 변환한 뒤 target과 CIE76 거리를 계산하고 threshold 이하인 픽셀을 선택합니다. threshold는 유한한 0 이상의 값이며 결과는 선택 255, 비선택 0인 Gray8 마스크입니다.

예를 들어 픽셀과 기준 Lab의 성분 차이가 (3,4,0)이면 거리는 5입니다. 한계가 5이면 등호를 포함하므로 선택되고 4이면 선택되지 않습니다. 반환 ZImage는 원본과 별도 결과이며 색 선택이 곧 제품 합격 판정은 아닙니다.

항목확인할 내용
target기준 D50 Lab 색입니다.
threshold유한한 비음수 CIE76 거리이며 경계를 포함합니다.
선택거리 ≤ threshold이면 255입니다.
비선택거리 > threshold이면 0입니다.
결과입력과 독립된 Gray8 마스크입니다.
