호출과 결과 해석

방향과 다중 해상도 모델 특징을 검색 영상 특징과 대응시키고 FeatureMatchOptions로 기하를 검증합니다. 학습 설정은 모델의 options로 확인하고 검색 조건은 이 호출에 별도로 전달합니다. 반환 MatchingReport에서 대응과 변환 유무, 평가 상태를 함께 살핍니다.

조건과 결과 판독

방향과 다중 해상도 특징을 가진 학습 모델을 검색 영상에 적용합니다. 모델이 보유한 학습 설정과 이 호출의 FeatureMatchOptions는 서로 다르며, mask_image가 있으면 해당 검색 영역이 사용됩니다.

보고의 대응점에서 모델 점, 영상 로컬 점, 글로벌 영상 점과 인라이어 여부를 구분하세요. matrix는 선택적이므로 특징 대응이 존재해도 유효 변환이 없을 수 있습니다. 회전·해상도 조건을 바꿔 비교할 때 입력 영상과 나머지 검색 옵션을 함께 기록합니다.

예를 들어 회전된 검색 영상에서 특징 대응을 얻더라도 최종 변환이 추정되었는지는 matrix와 인라이어 수를 확인해야 합니다. 검색 마스크는 현재 영상의 영역을 제한하며 모델이 학습할 때의 입력 영역과 같은 객체라고 가정하지 않습니다. 평가 한도를 바꿨다면 종료 보고도 같이 비교하세요.
