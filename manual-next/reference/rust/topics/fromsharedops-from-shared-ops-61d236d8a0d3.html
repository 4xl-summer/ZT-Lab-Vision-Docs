fn from_shared_ops(value: Self::Target) -> Self

Transfers the supplied engine representation into the facade owner.

변환과 소유권

연관 타입 Target의 엔진 표현을 받아 facade 소유 값으로 이전합니다. 이 트레이트의 호출은 입력 값의 소유권을 받으며 정확한 Target은 구현하는 구체 타입이 결정합니다.

입력 표현을 이후에도 독립적으로 사용해야 한다면 해당 타입이 제공하는 공유 또는 복제 방법을 먼저 확인하십시오. 트레이트 이름만으로 다른 표현과의 변환 가능성을 가정하지 않습니다.

구체 구현의 공유 모델

FromSharedOps는 구현 타입이 정한 연관 타입 Target 값을 받아 facade 소유 값으로 옮기는 bridge 트레이트입니다. 트레이트 선언만으로 모든 타입의 Target이 같다고 가정할 수 없습니다. 호출 시 전달하는 값의 타입과 결과 소유권은 선택한 구체 구현을 확인해야 합니다.

예를 들어 FeatureModel 구현의 Target은 Arc<ops::FeatureModel>이며 전달된 공유 엔진 모델을 facade에 감쌉니다. 이 구현은 학습 상태를 다시 학습하거나 모델 내용을 깊이 복제하는 과정이 아닙니다. 다른 구현에는 다른 Target이 있을 수 있으므로 해당 타입의 선언을 봅니다.

전달한 값은 Rust 소유권 규칙에 따라 호출로 이동합니다. 같은 Arc를 다른 곳에서도 사용해야 한다면 이동 전에 해당 Arc의 공유 복제 방법을 사용해야 합니다. 반대로 이 메서드가 다른 임의의 객체를 해당 Target으로 자동 변환하거나 수명 제약을 없앤다고 해석하지 않습니다.
