Searches multiple instances with the existing overlap policy.

호출과 결과 해석

여러 특징 모델의 인스턴스를 검색하고 지정한 overlap 정책으로 후보를 처리합니다. max_per_model과 max_results는 각각 모델별·전체 개수 상한이고 total_hypotheses는 공유 가설 예산입니다. scope와 max_iou를 함께 기록해 어떤 후보끼리 중복을 비교했는지 해석하고 보고서의 예산 상태를 확인합니다.

여러 모델 인스턴스 검색

FeatureInstanceCollection의 모델 항목들을 image에서 검색하며 선택적 search_mask를 받습니다. max_per_model은 모델별 한도, total_hypotheses는 가설 관련 한도, max_results는 전체 반환 한도입니다. 세 수치를 같은 개념으로 취급하지 않습니다.

scope와 max_iou는 후보 간 겹침을 처리하는 정책에 영향을 줍니다. 예를 들어 서로 다른 모델에서 겹친 후보가 나왔을 때 어느 범위에서 비교할지는 지정한 scope에 따릅니다. 한도에 도달하면 반환 후보 수가 현장 물체의 전체 개수와 다를 수 있습니다.

반환은 MatchingReport의 FeatureInstanceCollectionReport를 담는 ZResult입니다. 보고된 후보의 모델 식별자와 자세를 같은 이미지 및 마스크와 연결해 읽습니다. 할당 실패나 잘못된 설정에서 발생한 오류를 빈 후보 목록으로 바꾸지 않습니다.
