사용과 결과 해석

각 오류 정정 블록의 진단 정보를 읽기 전용 슬라이스로 반환합니다. 각 블록에는 데이터 코드워드 수, 패리티 코드워드 수 및 수정한 코드워드 수가 있습니다.

목록은 결과 스냅샷에 종속되므로 결과보다 오래 쓰려면 복사하십시오. 블록별 수정량을 살피면 전체 수정 수만 볼 때 놓치는 한 블록의 집중된 손상을 구분할 수 있습니다.

블록별 정정량과 한계

blocks는 각 오류 정정 블록의 데이터 코드워드 수, 패리티 코드워드 수와 수정 코드워드 수를 읽기 전용 슬라이스로 반환합니다. 슬라이스는 ControlledEccResult를 빌리므로 결과 객체가 살아 있는 동안 사용해야 하며 더 오래 보관할 값은 복사합니다.

단계 또는 항목확인할 내용
data_codewords블록의 데이터 코드워드 수
parity_codewords블록의 패리티 코드워드 수
corrected_codewords해당 블록에서 수정한 수
예시 합계1 + 2 = 3
블록당 최대예시에서 2
수명소유 결과를 빌리는 슬라이스

결과를 사용할 때

예를 들어 두 블록의 수정 수가 각각 1과 2이면 전체는 3이지만 블록별 최대는 2입니다. 블록당 한계가 1이면 두 번째 블록이 그 조건을 넘습니다. 이 사후 한계를 바꾸는 것은 디코더의 정정 능력이나 심볼의 ECC 레벨을 바꾸는 일이 아닙니다. 코드워드 수를 손상 픽셀 수나 성공 확률로 해석하지 마세요.
