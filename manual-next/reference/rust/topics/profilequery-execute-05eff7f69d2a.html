pub fn execute(&self) -> ZResult<QueryExecution<ProfileResult>>

Executes and snapshots profile samples.

사용과 결과 판독

계획된 프로파일을 실행하여 ProfileResult를 포함하는 QueryExecution을 반환합니다. &self를 빌려 실행하므로 계획을 소유한 객체가 호출 중 유지되어야 합니다. 반환 상태를 확인한 후 표본의 ROI 로컬 위치, 시작점 기준 거리와 평균 강도를 읽으십시오. 계산 실패를 강도 0의 정상 샘플로 바꾸면 원인을 추적하기 어렵습니다.

단계확인할 내용
입력 계획프로파일 쿼리를 &self로 빌려 실행합니다.
반환실행 결과에 프로파일 스냅샷이 포함됩니다.
표본위치·시작점 거리·평균 강도를 구별합니다.
실패오류를 정상적인 0 강도 표본으로 치환하지 않습니다.

결과 판독과 예

ProfileQuery의 execute는 계획된 선분 표본화를 수행하고 ProfileResult 스냅샷이 포함된 QueryExecution을 돌려줍니다. 계획을 &self로 빌리므로 계획 자체의 소유권을 넘기는 호출과 다릅니다.

결과는 강도 표본이며 에지 목록이 아닙니다. 길이 4픽셀의 선분을 양 끝 포함 5개 위치에서 읽으면 간격은 1픽셀입니다. 실행 오류를 강도 0인 샘플과 구별하고 영상 ROI와 표본 설정을 함께 기록하십시오.

항목확인할 내용
계획프로파일을 읽을 선분과 설정입니다.
호출쿼리를 빌려 실제 실행을 수행합니다.
표본위치·진행 거리·평균 강도를 구별합니다.
간격 예길이 4, 표본 5면 1픽셀입니다.
