사용과 결과 해석

디코딩된 기호의 버전 번호를 반환합니다. 결과의 형식에 속한 버전 체계로 해석해야 하며, 숫자 자체는 교정된 코드워드 수나 허용 한도를 뜻하지 않습니다.

기호 크기나 구성 비교에 쓰려면 format 또는 해당 진단 결과의 형식을 함께 기록하십시오. 서로 다른 코드 형식의 같은 숫자를 같은 구조로 가정하지 마십시오.

형식별 버전으로 읽기

version은 제어된 ECC 디코드 결과의 심볼 버전을 u32로 반환합니다. 같은 결과의 format을 함께 확인해 해당 형식의 버전 체계로 해석합니다. 버전 번호는 수정한 코드워드 수, 정정 허용 한계나 결과의 accepted 값이 아닙니다.

단계 또는 항목확인할 내용
version심볼 형식에 속한 버전 번호
formatQR 또는 Data Matrix 등 결과 형식
blocks정정 블록별 진단
corrected_codewords수정된 코드워드의 수
accepted지정된 사후 판정 결과
해석서로 다른 형식의 숫자를 직접 동일시하지 않음

결과를 사용할 때

예를 들어 두 결과의 version 숫자가 같더라도 한쪽은 QR이고 다른 쪽은 Data Matrix라면 형식을 먼저 구분해야 합니다. 심볼의 버전은 내용과 구조에 관련된 결과 정보이며 손상이 몇 개 정정되었는지는 blocks와 corrected_codewords를 따로 읽습니다. 결과 텍스트와 정정 실행 여부도 해당 디코드 설정과 함께 기록하세요.
