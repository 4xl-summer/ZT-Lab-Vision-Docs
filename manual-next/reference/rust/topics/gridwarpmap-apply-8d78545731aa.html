pub fn apply( &self, src: &ZImage, interpolation: Interpolation, border: f64, ) -> ZResult<(ZImage, ZImage)>

Applies the map and returns the output and validity mask.

계산 순서와 결과 확인

미리 계산한 출력→소스 맵을 영상에 적용하고 출력 영상과 유효 마스크를 반환합니다. interpolation은 표본화 방식이고 border는 유효 영역 밖을 채울 값입니다. 결과 픽셀을 분석할 때 동일 좌표의 마스크를 함께 읽고, 컬러 RGB8에 채널별 경계값이 필요하면 apply_rgb8_border를 사용합니다.

관련 호출

호출역할
