복수 바코드 판독

MultiBarcodeSpec에 지정된 형식과 검색 조건으로 여러 심볼을 탐색하고 MultiBarcodeReads를 반환합니다. 각 뷰는 텍스트, 원시 바이트, 위치 및 길이 조건을 제공합니다.

탐색이 모든 심볼을 찾는다고 가정하지 않고 입력 영역과 허용 형식을 기록합니다. 결과 컬렉션에서 빌린 뷰나 슬라이스는 소유 컬렉션보다 오래 사용할 수 없습니다.

복수 심볼 판독

MultiBarcodeSpec을 사용해 현재 영상에서 여러 바코드를 탐색하고 MultiBarcodeReads를 반환합니다. 허용 형식과 회전 등 검색 조건이 결과에 영향을 주므로 입력 프레임과 설정을 함께 기록합니다.

결과의 각 뷰는 format, text, raw_bytes, points, rotation_degrees 및 length_accepted를 제공합니다. 예를 들어 QR과 Code 128이 각각 하나씩 검출되면 두 항목의 형식과 위치를 별도로 확인하고 텍스트를 잘못 짝짓지 않습니다.

탐색은 조건에 따라 심볼을 놓칠 수 있습니다. 빈 컬렉션은 해당 실행에서 읽힌 항목이 없다는 뜻이며 영상에 어떠한 심볼도 없다는 보장은 아닙니다. 호출 오류는 정상적으로 반환된 빈 컬렉션과 구분합니다.

컬렉션의 get은 범위 밖에서 None을 반환하고 iter는 빌린 뷰를 순회합니다. 문자열, 바이트와 점을 원본 결과보다 오래 보관하려면 소유 값으로 복사합니다. 결과의 위치는 화면 배율과 ROI 기준을 맞춘 뒤 표시합니다.
