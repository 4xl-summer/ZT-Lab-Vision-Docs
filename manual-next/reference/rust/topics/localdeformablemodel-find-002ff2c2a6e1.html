Finds a local deformation.

사용 순서와 결과 확인

학습된 NCC 템플릿을 영상에서 거칠게 찾고 제어점 격자의 국소 변형을 유한한 반복과 작업 예산으로 정밀화합니다. LocalDeformableOptions의 coarse, grid_x·grid_y, 반복·평활·최대 변형을 지정합니다. 결과는 Option 변형 결과와 coarse 종료·평가 상태를 포함하므로 매치 없음과 실행 오류를 구분합니다.

입력과 상태 비교

항목의미
coarse거친 포즈 격자와 종료 설정
grid_x / grid_y국소 변위 제어 격자 크기
max_work국소 계산의 작업 상한
result / local_status매치 유무와 국소 단계 상태
