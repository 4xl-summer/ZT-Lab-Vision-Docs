결과 해석과 수명

문자별 배치 검사 결과를 줄별 bool 슬라이스의 반복자로 빌립니다. 전체 수락 여부인 accepted와 개별 글자의 결과를 구분합니다. 예를 들어 한 줄에 false가 있다면 해당 위치를 줄의 글자 순서와 연결해 확인할 수 있습니다. 반환 참조는 검사 결과의 수명 안에서 읽습니다.

문자 셀별 위치 판정

per_glyph는 줄마다 bool 슬라이스를 제공하는 ExactSizeIterator입니다. 각 bool은 판독된 문자 셀 중심이 해당 기대 위치의 x·y 허용 범위에 들어가는지 나타냅니다. 셀 중심은 x+width/2, y+height/2로 계산하고 각 축의 절대 오차를 해당 max_dx, max_dy와 비교합니다.

예를 들어 기대 중심이 (10,20), 허용 오차가 (2,1)이고 셀 중심이 (12,21)이면 양 축이 경계와 같으므로 통과합니다. 중심이 (12.1,21)이면 x가 상한을 넘습니다. 결과는 줄과 문자 순서에 대응하므로 서로 다른 줄의 인덱스를 섞지 않습니다.

전체 accepted는 원래 판독이 수락되고 줄이 비어 있지 않으며 모든 문자 위치가 통과해야 true입니다. per_glyph의 내부 슬라이스는 결과를 빌리므로 결과 객체의 수명 안에서 읽고, 장기 보관이 필요하면 필요한 bool을 복사합니다.
