pub fn index_map(&self) -> ZImage

Acquire an independently owned frame index map.

결과 해석과 수명

초점 스택 결과에서 각 위치의 소스 프레임 인덱스 영상을 독립 소유 ZImage로 얻습니다. fused_image는 융합된 영상이고 index_map은 선택된 입력 프레임을 가리키는 별도 영상입니다. 스택 입력 순서를 보관해야 인덱스를 원래 프레임과 연결할 수 있습니다.

함께 사용하는 조회

호출역할
fused_imageAcquire an independently owned image.

선택 프레임과 결과 영상

index_map은 초점 스택에서 각 출력 픽셀이 어느 입력 프레임에서 선택되었는지 나타내는 독립 소유 Gray8 영상을 반환합니다. fused_image는 선택된 픽셀들로 구성된 별도 소유 영상입니다. 인덱스 지도의 값은 입력 영상 슬라이스의 0기반 순서와 연결해야 합니다.

입력은 원점과 크기가 같은 Gray8 영상 2..256개입니다. 각 프레임의 3×3 영역에서 네 이웃 라플라시안 제곱합을 초점 에너지로 비교하고, 정확한 동률에서는 먼저 전달된 프레임을 선택합니다. 예를 들어 [A,B]의 동률 픽셀은 인덱스 0이므로 A에 대응합니다.

입력 영상들이 같은 장면 위치에 정렬되어 있지 않으면 동일한 출력 좌표를 프레임 간에 비교하는 의미가 달라집니다. fused_image와 index_map을 같은 위치에서 원본 순서와 함께 살펴보고, 결과 컨테이너 및 각각 얻은 영상의 소유 수명을 구분합니다.
