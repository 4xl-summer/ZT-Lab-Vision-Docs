Rust
pub fn acquire_output(&self) -> ZImage

Returns an independent share of the output image.

결과 해석과 수명

영상 출력에 대한 독립 소유 ZImage 공유를 반환합니다. output은 실행 객체에 묶인 불변 참조이고 into_output은 실행 객체를 소비하며 캡처를 버립니다. 결과 영상을 실행 객체와 별도 소유 수명으로 사용하려면 acquire_output의 반환값을 관리합니다.

함께 사용하는 조회

호출역할
into_outputConsumes the execution, returning its output and dropping all captures.
outputReturns the cached output while the execution is alive.
