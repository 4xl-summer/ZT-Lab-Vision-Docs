호출 맥락과 결과 해석

학습된 특징 모델을 버전이 있는 바이트 형식으로 직렬화합니다. 반환 바이트 벡터는 모델 수명과 독립되어 있어 모델의 스코프가 끝난 뒤에도 저장할 수 있습니다. 검색 영상이나 검색 옵션이 포함된 실행 결과를 만드는 호출은 아닙니다.

동일한 모델 종류의 from_bytes로 복원한 후 검색 옵션과 영상은 따로 지정합니다. 저장과 복원 전후에 동일 입력을 사용해 features와 검색 결과를 비교하면 모델 전달 과정을 확인할 수 있습니다.

모델을 바이트로 전달

학습된 FeatureModel을 버전이 있는 Vec<u8>로 직렬화합니다. 반환 벡터는 모델의 빌린 슬라이스가 아닌 소유 값이므로 모델이 범위를 벗어난 뒤에도 보관할 수 있습니다. 실패하면 ZResult 오류를 처리해야 합니다.

항목확인할 내용
수신 객체학습된 FeatureModel
반환독립 Vec<u8> 또는 오류
보관반환 벡터를 파일 등에 별도 저장
복원 후검색 영상과 옵션을 다시 준비

반환 데이터는 모델 자체이며 검색 영상이나 그 실행의 후보 목록은 포함하는 것으로 가정하지 않습니다. 같은 종류의 from_bytes로 복원한 후 영상과 검색 설정을 다시 제공하고 결과를 대조해 보존 상태를 확인합니다. 부분적으로 잘린 바이트를 완전한 모델로 취급하지 않습니다.
