pub fn decode( template: &ZImage, bytes: &[u8], max_bytes: usize, max_probes: usize, max_work: usize, ) -> ZResult<Self>

Restores the model against a template.

비드 기준 복원

template 영상과 bytes, max_bytes, max_probes, max_work 한도로 기준을 복원합니다. template은 모델을 적용할 영상의 기하와 형식을 제공하는 기준입니다.

손상되었거나 한도를 벗어난 데이터를 오류로 처리하고 빈 경로의 성공 모델과 구분합니다. 복원 후 경로의 로컬 좌표와 실제 검사 영상이 대응하는지 확인합니다.

입력과 결과 확인

BeadReference::decode는 직렬화된 bytes와 템플릿 영상을 사용해 비드 기준 모델을 복원합니다. max_bytes, max_probes, max_work는 각각 입력 크기와 프로브 및 작업을 제한하는 값이며, 성공한 모델과 ZResult 오류를 분리해 처리해야 합니다.

template은 복원 모델이 사용할 영상의 형식과 기하를 확인하는 기준입니다. 복원에 성공했다고 새로운 검사 영상의 ROI 원점과 크기가 자동으로 같아지는 것은 아닙니다. 기준 경로의 로컬 좌표가 실제 검사 영상에서 같은 위치를 나타내는지 확인하십시오.

예를 들어 한도보다 긴 바이트 자료나 유효하지 않은 모델을 정상적인 빈 기준 경로로 대체하면 이후 검사가 성공한 것처럼 보일 수 있습니다. 모델의 입력 자료와 설정, 템플릿 및 한도를 함께 보관하고 복원 뒤에 별도의 검사 호출로 결과를 확인합니다.

항목확인할 내용
template영상 형식과 기하를 확인할 기준 영상입니다.
bytes복원할 직렬화 자료의 빌린 슬라이스입니다.
max_bytes허용할 바이트 수의 한도입니다.
max_probes허용할 프로브 수의 한도입니다.
max_work복원에 허용할 작업 한도입니다.
반환성공 모델과 ZResult 오류를 구분합니다.

max_bytes는 입력 자료의 허용 크기, max_probes는 복원할 기준의 프로브 수, max_work는 처리량의 제한이므로 서로 다른 자원 조건입니다. 한 값을 늘렸다고 다른 한도도 자동으로 늘어나는 것은 아닙니다. 템플릿이 지정하는 영상 기하와 기준 경로의 위치가 맞지 않으면 복원된 숫자를 다른 ROI에 그대로 해석할 수 없습니다. 예산과 템플릿을 재현 가능한 설정으로 보관하고 오류를 호출 시점에 확인하십시오.

복원된 기준을 실제 검사에 쓰기 전에는 경로가 영상 안의 의도한 비드 위치를 지나가는지 확인하십시오. 바이트의 버전이나 내용이 유효하지 않은 실패와 정상적으로 생성된 기준 모델을 분리합니다.
