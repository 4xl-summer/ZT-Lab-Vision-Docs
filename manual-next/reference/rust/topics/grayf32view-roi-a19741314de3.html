Borrowed typed image view with byte stride.

형식과 좌표

GrayF32View의 roi는 현재 뷰에 대한 로컬 ZRect를 적용해 같은 저장소를 빌리는 하위 뷰를 반환합니다. 좌표와 크기는 픽셀 기준이며 복사본을 만들지 않습니다.

예를 들어 4×3 GrayF32View에서 (1,1,2,2)를 선택하면 새 뷰의 로컬 (0,0)은 부모의 (1,1)에 해당하고 새 너비와 높이는 각각 2입니다. 사각형은 현재 뷰를 벗어나면 오류이며, 끝 경계는 포함되지 않습니다.

수명과 후속 처리

GrayF32View는 원본 저장소의 수명에 묶인 뷰입니다. 반환된 참조를 원본 데이터보다 오래 보관할 수 없으며, 값을 다른 소유 객체로 보존하려면 별도의 소유 복사 또는 이미지 공유 계약을 사용해야 합니다. 형식이 다른 뷰로 임의 재해석하지 말고 입력 구성과 성분 순서를 확인하십시오.

좌표 계산 예

이 사각형을 적용한 뒤 GrayF32View의 row와 pixel은 새 영역을 기준으로 좌표를 받습니다. 부모에서 (1,1)로 시작한 2×2 하위 뷰의 로컬 (1,1)은 부모의 (2,2)입니다. 부모 슬라이스를 빌린 상태는 그대로 이어지므로 하위 뷰를 별도의 소유 이미지처럼 원본 데이터보다 오래 유지할 수 없습니다.
