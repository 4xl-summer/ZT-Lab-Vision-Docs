pub fn fit( points: &[Point2], inlier_threshold: f64, ) -> Result<EllipseFit, ZError>

Fits an ellipse with the existing robust threshold in coordinate units.

계산 순서와 결과 확인

입력 Point2 목록에 타원을 강건 적합하며 inlier_threshold는 입력 좌표 단위의 거리 기준입니다. 얻은 결과는 타원의 중심·축 등을 표현하는 적합 값이고 각 입력 점이 경계에 정확히 놓인다는 보장은 아닙니다. 결과 경계에 대한 점별 거리는 distance_to_point로 확인하고 부적절한 입력은 Result 오류로 처리합니다.
