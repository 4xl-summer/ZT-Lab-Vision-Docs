호출과 결과 해석

ShapeCollectionEntry 벡터를 순서가 있는 형상 모델 컬렉션으로 만듭니다. 생성 단계는 검색을 수행하지 않으며 엔진이 실행 시 제한을 검증합니다. 각 모델 id와 입력 순서를 보존해 이후 find 보고서의 매치가 어떤 모델에 해당하는지 연결합니다.

결과와 조건을 함께 읽기

입력 Vec의 순서대로 모델 항목을 보유하는 컬렉션을 만듭니다. 생성자는 검색 영상을 받지 않으므로 후보를 찾거나 검색 예산을 소비하지 않습니다. 컬렉션의 제한과 각 모델의 유효성은 엔진 실행 시 검증됩니다. 예를 들어 두 모델을 첫째와 둘째 순서로 넣었다면 후속 보고서의 식별자와 입력 항목을 연결해 어떤 모델에서 나온 결과인지 확인합니다. Vec는 값으로 전달되므로 생성 후에는 컬렉션이 항목을 소유합니다. 생성 성공만으로 특정 영상에서 매치가 반드시 발견된다고 가정하지 않습니다.
