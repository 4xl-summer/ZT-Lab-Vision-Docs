pub fn from_envelopes( reference: &ZImage, variation: &ZImage, mask: Option<&ZImage>, ) -> ZResult<Self>

Builds a model from explicit reference and deviation images.

기준과 편차에서 모델 구성

기준 영상, 편차 영상과 선택적 포함 마스크를 빌려 변동 모델을 생성합니다. reference와 variation의 같은 픽셀이 같은 위치의 기준과 허용 편차를 의미하도록 기하와 단위를 맞춰야 합니다.

이 경로는 영상 집합을 다시 학습하는 train과 다릅니다. 반환 모델은 소유 값이며 결과를 검사에 쓰기 전에 모델 영상과 별도 시험 입력을 비교합니다. 조건이 유효하지 않으면 ZResult 오류로 처리합니다.

기준과 편차를 직접 제공

reference와 variation 영상은 같은 위치의 기준값과 음수가 아닌 픽셀별 편차를 지정합니다. mask는 선택적인 포함 영역이며 입력들의 기하가 서로 맞아야 합니다. 이 생성 경로는 정상 영상 목록에서 통계를 다시 학습하는 train과 구별됩니다.

항목의미와 확인
reference위치별 기준 영상
variation위치별 0 이상의 편차
mask선택적 포함 영역
좌표모든 입력의 기하 일치
검사 옵션절대 허용치와 편차 배수를 별도 적용
반환소유 모델 또는 유효성 오류

사용할 때의 판독

예를 들어 한 위치의 reference가 100이고 variation이 2라면 그 위치의 모델 기준은 100, 편차는 2입니다. 후속 검사에서 밝은 쪽 절대 허용치 5, 편차 배수 3, 하한 1을 쓰면 허용치는 max(5,3×max(2,1))=6입니다. 실제 검사값 107은 이 예의 위쪽 경계 106을 초과합니다.
