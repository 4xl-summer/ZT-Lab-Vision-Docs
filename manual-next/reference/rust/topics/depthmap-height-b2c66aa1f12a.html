pub fn height(&self) -> usize

Height in pixels.

세로 크기 조회

이 메서드는 깊이 격자의 세로 크기를 픽셀 수로 반환합니다. 한 열에 들어 있는 격자 위치의 개수이며 깊이값 자체의 범위나 물리적 높이가 아닙니다. 전체 샘플 배열의 길이는 가로 크기와 이 세로 크기를 곱해 구합니다.

가로 2, 세로 2인 영상은 두 행으로 구성됩니다. 두 번째 행의 인덱스는 1이고 실제 y 좌표는 원점 y에 수직 간격을 더합니다. 픽셀별 보정에서는 입력 영상의 행 수도 모델 격자와 같아야 같은 위치의 계수를 적용할 수 있습니다.

확인 항목해석
반환세로 방향 픽셀 수
배열 관계전체 슬롯 = 가로 × 세로
좌표 변환원점 y + 행 인덱스 × 수직 간격
보정 적용영상과 계수 격자의 높이를 비교
