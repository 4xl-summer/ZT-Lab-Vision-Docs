바코드 격자 진단

BarcodeGridQualitySpec이 지정한 영역과 격자를 사용해 밝기 및 규칙성 관련 통계를 계산합니다. 셀 경계가 실제 모듈과 맞는지 확인해야 측정 대상이 의도한 영역이 됩니다.

밝은 셀과 어두운 셀의 평균, 대비, 셀 수를 함께 해석합니다. 이 진단은 표준 바코드 검증기 등급이 아니며 실제 판독 성공 여부와도 구분합니다.

바코드 격자 진단

BarcodeGridQualitySpec으로 지정한 영역과 행·열 격자를 현재 영상에서 평가해 BarcodeGridQuality 값을 반환합니다. 격자가 실제 심볼의 모듈과 대응해야 밝고 어두운 셀의 통계가 의도한 위치를 나타냅니다.

예를 들어 10열과 8행은 80개의 격자 위치를 정의합니다. 샘플링 영역이 셀 경계를 벗어나면 배경 또는 이웃 셀이 섞일 수 있으므로 region과 inset 조건을 확인합니다. 입력 이미지의 원점과 표시 화면 좌표도 구분합니다.

반환값에는 대비, 변조, 규칙성, 밝은 셀과 어두운 셀 평균, 셀 수가 있습니다. 이는 주어진 입력의 진단값이지 ISO 검증기 등급이나 판독 성공 확률이 아닙니다. 실제 바코드 읽기 상태와 별도로 기록합니다.

dark_mean과 light_mean은 각각 선택된 셀 집합의 평균 밝기를 나타냅니다. 배경이 셀 내부에 섞이면 평균과 대비가 달라질 수 있으므로 영역과 격자 위치를 먼저 검토합니다.

반환된 cell_count는 진단한 격자 셀의 수이며 읽힌 심볼의 개수가 아닙니다. 실제 디코딩이 필요하면 바코드 판독 함수를 별도로 실행하고 상태, 형식 및 텍스트를 확인합니다.

cell_count는 격자에서 측정된 셀에 관한 값입니다. 이미지에 발견된 바코드 수나 디코딩된 문자열 길이와 연결해 해석하지 않습니다. 형식 및 텍스트는 별도 판독 결과에서 얻습니다.

심볼을 다른 크기로 촬영하면 같은 columns와 rows라도 각 셀의 화면상 픽셀 크기가 달라집니다. region과 격자 경계를 실제 모듈에 다시 맞추고 비교 조건을 기록합니다.

격자 측정 영역을 표시할 때 원본 영상의 좌표와 화면의 확대 상태를 분리합니다. 심볼이 회전하거나 크기가 달라졌다면 기존 격자를 그대로 사용하는 대신 지정된 region과 행·열이 실제 모듈에 대응하는지 다시 살펴봅니다.
