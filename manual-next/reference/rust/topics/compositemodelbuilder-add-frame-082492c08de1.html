Rust
pub fn add_frame(&mut self, frame: Fixture2) -> ZResult<usize>

Adds a frame whose parent, if any, already exists.

사용과 결과 해석

Fixture2 프레임을 빌더에 추가하고 그 프레임의 0부터 시작하는 인덱스를 반환합니다. 상위 프레임이 지정되어 있다면 이미 존재해야 합니다. 전체 그래프 검증에 실패하면 기존 프레임 목록은 유지됩니다.

후속 특징이 선택적으로 이 인덱스를 참조하므로 좌표계를 먼저 구성하십시오. 프레임 번호는 특징 식별자 id와 다른 값이며 서로 바꿔 쓸 수 없습니다.

판독과 사용 순서

반환값은 추가된 프레임의 0부터 시작하는 인덱스입니다. 부모가 있는 프레임은 먼저 추가한 부모를 가리켜야 하므로 아직 없는 프레임을 나중에 채울 자리로 지정할 수 없습니다. 예를 들어 루트가 인덱스 0으로 들어간 뒤 자식의 부모로 0을 지정할 수 있습니다. 인덱스는 NamedFeature에 부여하는 id와 역할이 다릅니다. 구현은 후보 목록을 복사해 전체 그래프를 검증한 뒤 성공할 때에만 빌더의 프레임 목록을 교체합니다. 실패했을 때 추가되지 않은 프레임 번호를 후속 특징에 사용하지 않습니다.
