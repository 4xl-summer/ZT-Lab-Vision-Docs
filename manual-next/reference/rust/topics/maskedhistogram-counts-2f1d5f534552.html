pub fn counts(&self) -> &[u64]

Borrowed channel-major counts.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 &[u64]은 빌린 참조를 나타냅니다. 이 값을 사용하는 동안 원본 소유 객체의 수명과 Rust의 빌림 규칙을 지켜야 합니다.

입력과 결과 해석

마스크가 적용된 히스토그램의 빈과 채널별 개수를 읽습니다. 반환된 카운트의 채널 순서와 빈 수를 함께 확인하세요. 빈 채널의 최빈값을 정상 숫자로 임의 대체하지 않습니다.

채널별 빈도 배열

counts는 마스크가 적용된 히스토그램의 u64 카운트를 채널 우선 순서의 빌린 슬라이스로 반환합니다. 한 채널의 빈들이 이어진 다음 다음 채널의 빈들이 나옵니다. bins는 채널당 빈 수이므로 배열 인덱스를 밝기 빈과 채널로 나누어 해석해야 합니다.

사용할 때의 판독

예를 들어 채널이 2개이고 채널당 빈이 3개라면 슬라이스의 처음 세 값이 채널 0의 빈 0~2, 다음 세 값이 채널 1의 빈 0~2입니다. 각 값은 선택된 픽셀 쌍이 아니라 해당 채널과 빈의 카운트입니다. 반환 참조는 MaskedHistogram을 빌리므로 결과보다 오래 보관하려면 필요한 값을 복사하세요.
