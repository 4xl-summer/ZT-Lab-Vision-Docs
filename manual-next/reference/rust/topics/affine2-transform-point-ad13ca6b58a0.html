사용과 결과 해석

입력 Point2에 이 원본→목적지 아핀 변환을 적용하여 새 점을 반환합니다. x와 y에는 여섯 계수의 선형 부분과 이동이 각각 적용됩니다. 유효하지 않은 변환 또는 비유한 입력·계산 결과는 오류가 됩니다.

예: 계수 [2,0,3,0,2,4]와 점 (1,2)는 (5,8)입니다. ROI 로컬 좌표를 전체 영상 좌표와 혼합하지 말고 변환을 정의한 좌표계에서 점을 전달하십시오.

좌표계산
x′a × x + b × y + tx
y′c × x + d × y + ty

점 변환의 순서

예를 들어 [2,0,3,0,2,4]에 (1,2)를 적용하면 x′=2×1+3=5, y′=2×2+4=8입니다. 좌표를 세계 단위로 변환하는 경우 입력 점과 행렬이 같은 단위 계약을 따르는지 확인하십시오.
