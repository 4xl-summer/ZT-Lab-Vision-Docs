pub fn project(&self, p: Point2) -> Result<Point2, ZError>

Map an object-plane point to cross-scan pixel and scan line.

계산 순서와 결과 확인

이동하는 물체 평면의 점을 가로 스캔 픽셀과 스캔 행으로 변환합니다. x′=center_pixel+pixels_per_unit×x, y′=origin_line+(y−origin_y)/distance_per_line입니다. distance_per_line은 0이 아니며 부호가 이동 방향을 표현합니다. 좌표 거리는 지정 unit을 따릅니다.

입력과 계산 확인

항목의미와 조건
가로center_pixel + pixels_per_unit × x
스캔 행origin_line + (y−origin_y)/distance_per_line
단위거리 및 이동량은 모델의 unit

물체 평면에서 픽셀과 라인으로

물체 평면의 점을 가로 스캔 픽셀과 라인 번호로 바꿉니다. x 출력은 center_pixel + pixels_per_unit × x이고 라인 출력은 origin_line + (y−origin_y)/distance_per_line입니다. 물리 좌표와 이동량의 단위는 카메라 unit을 따릅니다.

center_pixel=50, pixels_per_unit=2이면 물리 x=3은 픽셀 56입니다. origin_y=10, origin_line=100, distance_per_line=0.5이면 y=12는 라인 104입니다. distance_per_line은 0이 아니며 음수라면 물리 Y 증가와 라인 증가의 방향이 반대입니다.
