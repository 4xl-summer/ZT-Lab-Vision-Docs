결과 확인 순서

타원 측정의 결과 객체에서 호출합니다. 측정이 끝난 뒤 적합의 상태를 반환합니다. 에지를 찾은 프로브가 있다는 사실과 유효한 최종 형상을 얻었다는 사실은 서로 다릅니다. 먼저 이 상태를 읽고 필요한 관측과 형상이 제공되는지 확인하십시오. 실패나 관측 부족을 유효한 좌표 0 또는 반경 0으로 대체하면 실제 원점의 결과와 구별할 수 없습니다.

확인 항목사용 기준
대상타원 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용상태를 확인한 뒤 형상과 개별 관측을 해석합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

타원 적합 상태는 관측된 점을 모아 최종 모델을 얻었는지를 나타냅니다. 일부 프로브가 Found여도 선택된 점의 수가 부족하거나 적합이 실패할 수 있으므로 에지 발견과 형상 성공을 나누어 보십시오.

Fit 상태일 때 형상과 관측 분포를 함께 살핍니다. 타원의 중심과 반축은 영상 ROI 로컬 픽셀이고 각도는 라디안입니다. 관측된 원호가 한쪽에만 몰렸다면 상태만으로 전체 경계가 실제로 관측됐다고 판단할 수 없습니다.
