pub fn find( &self, image: &ZImage, options: &ShapeSearchOptions, search_mask: Option<&ZImage>, clutter_threshold: f64, clutter_weight: f64, ) -> ZResult<ExtendedMatchResult>

Finds classified shape candidates.

클래스별 검색 해석

학습한 care 특징으로 형상 점수를 구하고 변환된 clutter 위치의 검색 에지 밀도로 점수를 조정합니다. 보이는 clutter 표본의 에지 비율을 f, 가중치를 w라면 조정 배수는 1−w×f입니다. 예를 들어 w=0.5, f=0.4이면 배수는 0.8입니다. 보이는 clutter 표본이 없으면 감점하지 않습니다. threshold와 weight는 서로 다른 역할이므로 옵션과 종료 진단을 함께 확인합니다.

형상과 주변 혼잡도

학습한 care 특징으로 형상 점수를 계산하고 clutter 위치의 검색 에지 비율로 조정합니다. 보이는 clutter 비율 f와 가중치 w에서 조정 배율은 1−w×f입니다. w=0.5, f=0.4이면 배율은 0.8입니다.

항목판독할 내용
image검색 대상 영상
options / search_mask탐색 조건과 선택 마스크
clutter_threshold혼잡 에지 판정 기준
clutter_weight관찰된 비율에 적용할 가중치

search_mask는 선택적인 탐색 영역이며 clutter_threshold와 clutter_weight는 각각 판정과 감점에 관여하는 별도 설정입니다. 보이는 clutter 표본이 없을 때는 감점하지 않습니다. 후보 점수와 위치를 원본에 표시하고 검색 형식 및 옵션 오류를 처리합니다.
