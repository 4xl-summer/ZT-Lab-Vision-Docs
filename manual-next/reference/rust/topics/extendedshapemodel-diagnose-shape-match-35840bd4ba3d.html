pub fn diagnose_shape_match( &self, source: &ZImage, pose: &ExtendedMatch, min_gradient: f64, radius: usize, polarity: MatchPolarity, ) -> ZResult<MatchingReport<ShapeDiagnostics>>

Executes the existing diagnose_shape_match search variant and preserves its report.

호출 맥락과 결과 해석

검색 영상의 주어진 포즈를 주변 호환 에지와 비교합니다. min_gradient는 검색 에지의 최소 기울기이고 radius는 주변 검색 반경이며 polarity는 허용할 극성을 결정합니다. 이 함수는 새 포즈를 전역 검색하지 않습니다. 반환 보고서의 모델 특징 일치, 에지 커버리지, 클러터와 적합 진단을 함께 살펴 포즈가 어느 부분에서 맞지 않는지 해석합니다.

포즈의 에지 대응 진단

검색으로 얻은 ExtendedMatch 포즈와 소스 영상에 대해 모델 특징 주변의 호환 에지를 검사합니다. min_gradient는 유한한 비음수이고 radius는 0..128픽셀입니다. polarity는 허용할 기울기 극성이며 이 함수는 새 포즈를 전역 탐색하지 않습니다.

모델 특징 일치 비율과 검색 에지 커버리지는 분모가 다른 진단입니다. 주변 검색 에지 중 대응하지 않는 비율은 clutter로 읽고, 일치가 있을 때의 거리 RMS는 픽셀 단위로 해석합니다. 진단값을 포즈·반경·기울기·극성과 함께 비교해야 설정 차이를 구분할 수 있습니다.
