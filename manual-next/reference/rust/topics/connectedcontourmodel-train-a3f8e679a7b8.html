pub fn train( contours: &[Vec<Point2>], reference: Point2, spacing: f64, ) -> ZResult<Self>

Trains from ordered contours.

사용과 결과 해석

순서 있는 각 폴리라인과 기준점, 간격으로 검색 형상을 학습합니다. 입력 컨투어의 연결과 정점 순서를 모델이 독립적으로 복사해 보존합니다.

reference는 형상의 기준점이고 spacing은 표본 간격입니다. 입력 버퍼를 나중에 바꿔도 학습 모델의 보존된 폴리라인은 변하지 않으며 학습 실패는 오류로 전달됩니다.

사용 흐름과 결과 판독

순서가 있는 여러 폴리라인, reference 기준점과 spacing을 사용해 연결 윤곽 검색 모델을 학습합니다. 각 폴리라인의 정점은 입력 순서대로 연결되며, 서로 다른 컨투어를 하나의 임의 순서 점 집합으로 합치는 것과 다릅니다. 모델은 학습 과정에서 입력 컨투어를 독립적으로 복사합니다.

reference는 형상 배치에서 기준이 되는 점이고 spacing은 윤곽을 표본화할 간격입니다. 입력 좌표와 간격은 같은 기하 단위로 해석해야 합니다. 예를 들어 점 (0,0)과 (4,0)을 잇는 선분과 간격 1을 지정한다면 길이 4인 구간을 해당 간격 기준으로 해석합니다. 실제 표본 수와 끝점 처리는 모델 구현의 규칙을 따릅니다.

입력 Vec를 나중에 변경하거나 스코프에서 해제해도 모델이 복사한 폴리라인은 그 변경을 따라 바뀌지 않습니다. 잘못된 기하나 간격으로 학습하지 못하면 ZResult 오류가 반환됩니다. 학습한 모델을 검색에 전달한 뒤 반환 포즈의 기준점이 reference와 어떻게 연결되는지 확인합니다.
