영역 사각형

해당 바코드 판독에 사용된 ZRect를 값으로 반환합니다. 영역의 좌표와 크기를 입력 영상의 기준에 맞추어 표시하고, ROI 원점이 있는 경우 로컬 좌표와 전역 위치를 구별합니다.

반환된 뷰 또는 슬라이스는 상위 결과를 빌리므로 원본 결과의 수명 안에서 사용합니다. 값 타입 반환은 해당 필드의 복사본입니다.

영역과 판독의 대응

region은 이 뷰가 나타내는 판독 영역을 ZRect 값으로 반환합니다. 여러 ROI를 검사한 경우 각 결과의 region과 read를 같은 뷰에서 읽어 어느 영역의 결과인지 연결합니다. 사각형의 위치와 크기는 해당 입력 영상의 좌표 기준으로 해석합니다.

예를 들어 서로 다른 두 ROI에서 코드가 검출되었다면 두 뷰의 영역을 확인하고 해당 텍스트를 표시합니다. 컬렉션의 순서만으로 화면의 왼쪽과 오른쪽 순서를 가정하면 위치가 바뀔 수 있습니다. 영상이 ROI라면 로컬과 전역 원점도 구별합니다.

region 값과 별개로 read의 status, format, text 및 length_accepted를 확인합니다. 이 뷰는 원본 BarcodeRegionResults를 빌리며 텍스트 등에서 돌려준 참조는 컬렉션의 수명 안에서 사용합니다.
