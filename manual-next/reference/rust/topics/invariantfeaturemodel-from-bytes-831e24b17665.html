pub fn from_bytes(bytes: &[u8]) -> ZResult<Self>

Restores a model from bytes.

관련 입력의 확인된 조건

Scale and rotation invariant feature model.

호출 맥락과 결과 해석

직렬화된 불변 특징 모델을 복원합니다. bytes는 비어 있지 않고 최대 16000000바이트입니다. 검색 영상 바이트나 다른 모델의 자료를 임의로 대신 전달하지 않습니다.

복원된 모델은 스코프가 끝나면 정리되며 검색 조건은 별도로 준비합니다. to_bytes로 얻은 전체 데이터를 전달하고, 오류가 나면 바이트 길이와 완전성, 사용하는 모델 종류를 확인합니다.

불변 특징 모델 복원

from_bytes는 직렬화된 바이트 슬라이스에서 InvariantFeatureModel을 복원합니다. 데이터는 비어 있지 않고 최대 16000000바이트이며 다른 종류 모델이나 일반 이미지 파일을 무작정 전달하지 않습니다.

to_bytes로 얻은 전체 데이터를 제공하고 ZResult의 성공과 오류를 구분합니다. 복원된 모델은 소유 값이며 실제 검색에는 검색 영상과 조건을 다시 준비해야 합니다. 손상된 데이터가 오류일 때 빈 후보 결과로 해석해서는 안 됩니다.
