pub fn probes(&self) -> &[ShapeProbeObservation]

Returns per-probe diagnostics.

결과 확인 순서

타원 측정의 결과 객체에서 호출합니다. 각 탐색 위치의 진단을 빌린 슬라이스로 제공합니다. 한 프로브가 에지를 찾았어도 최종 피팅에 그 점이 채택되지 않을 수 있으므로 발견 위치와 사용 여부, 잔차를 구분해 살펴야 합니다. 검색 위치와 방향을 영상 위에 표시하면 목적 경계가 아닌 인접 경계를 선택한 문제를 찾는 데 도움이 됩니다.

확인 항목사용 기준
대상타원 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용결과가 살아 있는 동안 개별 관측을 확인합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

각 ShapeProbeObservation은 기본 관측과 선택적인 side 및 weight를 담습니다. 선택된 에지가 있어도 used가 거짓이면 최종 적합에 사용된 점이 아닙니다.

관측 위치를 영상에 표시하면 타원 원호의 한쪽에만 점이 몰렸는지 살필 수 있습니다. 결과에서 빌린 슬라이스이므로 반복 조회 중 결과 객체의 수명을 유지하고 결측 에지를 위치 0으로 바꾸지 마십시오.

항목확인할 내용
observation기준점, 상태, 선택 에지와 잔차를 담습니다.
used선택된 점의 최종 채택 여부를 확인합니다.
weight강건 적합의 가중치가 있으면 읽습니다.
수명진단 슬라이스는 결과 객체에서 빌립니다.
