pub fn train( image: &ZImage, mask_image: Option<&ZImage>, options: FeatureDetectionOptions, ) -> ZResult<Self>

Trains descriptors from an image and optional mask.

관련 입력의 확인된 조건

Feature descriptor model.

호출 맥락과 결과 해석

회색 템플릿에서 Harris 특징과 정규화 패치 기술자를 학습합니다. FeatureDetectionOptions 값은 특징 검출을 설정하고, 선택적 Gray8 마스크는 템플릿과 크기 및 원점이 같아야 합니다.

학습 후 features로 실제 저장된 특징을 확인할 수 있습니다. 이후 find에서 검색 영상의 특징과 모델 특징을 대응시키므로 템플릿에 구분할 만한 특징이 있는지 먼저 살피고, 소유 모델은 스코프가 끝나면 정리됩니다.

결과와 조건을 함께 읽기

입력 템플릿에서 코너 특징을 검출하고 각 위치의 정규화 패치를 모델 기술자로 저장합니다. 선택 마스크는 학습 픽셀을 제한하며 Gray8이고 템플릿의 크기와 원점과 같아야 합니다. 마스크가 없을 때와 배경을 제외한 경우에는 모델이 관찰하는 특징이 달라질 수 있습니다. 학습 뒤 features의 개수와 위치를 확인하고 검색 영상에 대해 find를 실행해 대응 및 기하 검증 결과를 살펴봅니다. 코너가 거의 없는 평탄한 패치에는 구별할 특징이 부족할 수 있으므로 단순히 모델 생성 여부만으로 검색 품질을 판단하지 않습니다.
