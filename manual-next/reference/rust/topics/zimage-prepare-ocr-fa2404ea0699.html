문자 인식 영역 준비

Rust의 ZImage 호출은 현재 영상에 이 처리를 적용합니다. OcrRegionSpec으로 사각형 ROI, 90도 단위 회전, 밝은 문자 여부 및 정규화를 지정해 OCR에 사용할 영역을 준비합니다. 반환 정보의 크기와 대비, 준비 좌표에서 입력 로컬 및 전역 좌표로의 변환을 함께 확인합니다.

현재 영상에서 얻은 결과의 해석에서는 회전된 준비 영상의 모서리를 원본에 표시할 때 변환을 적용해야 합니다. 동일한 폭과 높이라는 이유만으로 좌표계가 같다고 추정하지 않습니다. 준비 영상 생성은 문자 판독 자체가 아니며 인식에는 설정과 엔진이 별도로 필요합니다.

Rust 반환 값의 소유와 참조 수명을 시그니처에서 확인합니다. 입력 오류와 실제 계산된 빈 결과는 서로 다른 경로이므로 오류를 정상 판정으로 바꾸지 않습니다.

판독 전 영역 준비

OcrRegionSpec으로 ROI, 90도 단위 회전, 밝은 문자 여부와 정규화를 정해 OCR 입력 영역을 준비합니다. 반환 PreparedOcrRegion은 준비된 영상과 좌표 변환 정보를 설명하며, 문자 판독 결과 그 자체가 아닙니다.
