Borrowed typed image view with byte stride.

형식과 좌표

Rgba8View의 width는 현재 보이는 뷰의 너비를 픽셀 수로 반환합니다. 성분 수나 바이트 수가 아니며 하위 ROI에서는 하위 영역의 너비입니다.

예를 들어 너비 4의 Rgba8View 한 행은 16개 u8 성분입니다. 성분당 1바이트이므로 보이는 행에 16바이트가 있어도 width의 반환값은 4입니다. 이후 row를 읽을 때 채널 수를 다시 고려하십시오.

수명과 후속 처리

Rgba8View는 원본 저장소의 수명에 묶인 뷰입니다. 반환된 참조를 원본 데이터보다 오래 보관할 수 없으며, 값을 다른 소유 객체로 보존하려면 별도의 소유 복사 또는 이미지 공유 계약을 사용해야 합니다. 형식이 다른 뷰로 임의 재해석하지 말고 입력 구성과 성분 순서를 확인하십시오.

좌표 계산 예

Rgba8View에서 반복문의 x 범위를 정할 때 width는 마지막 픽셀의 인덱스보다 1 큽니다. 너비가 4인 경우 x는 0부터 3까지이며 4는 읽을 수 없습니다. 같은 뷰에서 row는 채널 수를 곱한 16개 u8 성분을 반환하므로 행 슬라이스 길이와 width를 혼동하지 않도록 합니다.
