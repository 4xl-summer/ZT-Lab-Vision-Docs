pub fn to_packed_vec_rgbf32(&self) -> ZResult<Vec<f32>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<f32>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

조건과 결과 판독

현재 ROI의 RGBF32 성분을 행 우선 독립 Vec<f32>로 복사합니다. 한 픽셀은 R,G,B 세 f32 원소이므로 폭 2, 높이 3인 ROI의 반환 길이는 18입니다. 이 길이는 바이트가 아닌 부동소수 원소 개수입니다.

원본 저장의 행 패딩은 반환 배열에 들어가지 않습니다. 반환 벡터는 영상 참조가 아니라 독립 소유이며, 픽셀의 실수 값을 정수 0~255로 자동 변환하지 않습니다. 형식이 RGBF32가 아니면 오류를 확인하세요.
