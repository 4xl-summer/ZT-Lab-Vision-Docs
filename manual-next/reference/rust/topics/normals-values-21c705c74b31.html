pub fn values(&self) -> &[Option<Point3>]

Borrows all normals.

결과 해석과 수명

계산된 법선들을 입력 순서의 &[Option<Point3>]로 빌립니다. 각 항목이 Some이면 법선이 있고 None이면 해당 위치에 계산된 법선이 없습니다. 빈 값을 임의의 영벡터로 취급하지 않습니다. 독립 소유 벡터가 필요하면 컨테이너를 소비하는 into_values와 구분합니다.
