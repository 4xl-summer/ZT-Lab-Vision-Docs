pub fn offer_frame( &mut self, image: &ZImage, frame_id: u64, device_ticks: u64, host_ns: u64, trigger_id: u64, ) -> ZResult<OfferDisposition>

Offer a visible image. The simulator copies it into an independent frame.

상태와 처리 순서

입력 영상을 프레임으로 제안하고 수락 또는 큐 상태를 반환합니다.

frame_id는 양수이고 host_ns와 device_ticks의 순서 조건을 지켜야 합니다. FreeRun의 trigger_id는 0이며 트리거 모드에서는 등록된 0이 아닌 ID가 필요합니다.

결과 해석

수락된 프레임은 입력 영상의 보이는 영역을 독립 복사해 큐에 보관합니다. 중복·역순 또는 가득 찬 큐는 OfferDisposition으로 구분되므로 모두 수락으로 해석하지 마십시오.

이 시뮬레이터의 상태와 시간은 호출자가 제공한 합성 이벤트에 기반합니다. 실제 카메라의 연결, 트리거 신호, 전송 지연 또는 하드웨어 인수 결과로 대신 해석하지 마십시오.
