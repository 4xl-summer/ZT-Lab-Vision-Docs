pub fn shifted(&self, shift: i32) -> ZResult<Self>

Shift integer output and preserve the mask.

결과 해석과 수명

정수 출력 값을 지정 shift로 이동한 새 결과를 만들고 계산 마스크는 보존합니다. 이 shift는 영상 위치 평행이동이 아니라 정수 출력의 값 이동입니다. 결과의 filtered_image와 computed_mask를 함께 확인하여 필터 적용 위치를 구분합니다. 연산 오류는 ZResult로 전달됩니다.

함께 사용하는 조회

호출역할
filtered_imageAcquire an independently owned filtered image.
computed_maskAcquire an independently owned 255-applied, 0-copied mask.
