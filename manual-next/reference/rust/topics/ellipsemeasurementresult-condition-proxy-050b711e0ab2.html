pub fn condition_proxy(&self) -> Option<f64>

Returns the fit condition proxy, when available.

결과 확인 순서

타원 측정의 결과 객체에서 호출합니다. 가능한 경우 적합의 조건 지표를 반환합니다. 지표가 없다는 상태와 숫자 0은 다르므로 반환 타입의 선택적 값을 먼저 확인하십시오. 이 값만으로 실제 장비의 정확도나 결과 형상의 합격 여부를 단정하지 말고 입력점의 분포, 적합 상태와 관측 진단을 함께 확인합니다.

확인 항목사용 기준
대상타원 계측 결과에서 이 값을 읽습니다.
호출 전동일 실행의 상태와 영상 ROI 기준을 보존합니다.
확인할 내용지표의 존재 여부와 관측 분포를 함께 확인합니다.
후속 비교다른 프레임은 입력 설정과 좌표 단위를 맞춥니다.

결과 판독과 예

조건 지표는 가중 Jacobian 열 노름의 최대값과 최소값의 비율이며 계산할 수 없으면 None입니다. 이는 행렬의 일반적인 조건수 자체가 아닙니다.

지표가 없다면 숫자 0으로 바꾸지 말고 None을 보존하십시오. 값이 있더라도 타원 원호에 분포한 관측점, 수렴 여부와 최종 상태를 함께 보아야 합니다. 단일 지표는 실제 카메라의 정확도 보증치가 아닙니다.

항목확인할 내용
Some계산된 열 노름 비율을 나타냅니다.
None지표가 없는 상태입니다.
의미행렬 조건수 그 자체와 구별합니다.
함께 볼 값관측점 분포와 수렴·상태를 확인합니다.
