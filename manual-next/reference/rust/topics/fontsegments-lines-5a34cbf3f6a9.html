사용 순서와 결과 판독

lines는 FontSegments가 보유한 줄별 사각형을 읽는 정확한 길이의 반복자를 반환합니다. 바깥 반복의 한 항목은 한 줄의 ZRect 불변 슬라이스이며, 그 슬라이스 안에는 해당 줄에서 분할된 여러 영역이 순서대로 들어 있습니다. 결과는 이미 계산된 분할을 읽는 것이며 이 호출이 문자를 인식하거나 새 줄을 검출하지는 않습니다.

예를 들어 첫 줄에 세 영역, 둘째 줄에 두 영역이 있다면 반복자는 길이가 3과 2인 슬라이스를 차례로 제공합니다. 이를 다섯 개의 독립 줄로 해석하면 문장 순서가 달라집니다. 각 사각형의 위치와 크기를 입력 영상의 ROI 좌표 기준과 연결하고 후속 인식 결과와 동일한 줄·영역 순서를 유지합니다.

각 슬라이스는 FontSegments의 내부 결과를 불변으로 빌립니다. 반복자나 슬라이스를 원본 결과보다 오래 사용할 수 없으므로 장기 보관할 사각형은 필요한 만큼 소유 자료로 복사합니다. ExactSizeIterator의 길이는 남은 줄 항목 수이며 모든 줄의 영역 수를 합한 글자 후보 개수와 같다고 가정하지 않습니다.
