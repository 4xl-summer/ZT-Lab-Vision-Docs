학습 경로 읽기

path는 학습된 비드 경로의 Point2 슬라이스를 빌려 반환합니다. 순서는 경로를 따라 진행하는 순서이며, 각 위치에 대응하는 widths를 다른 순서로 섞지 않습니다.

경로는 학습한 ROI의 로컬 좌표입니다. 예를 들어 ROI 원점이 (100,50)이고 경로점이 (4,3)이면 단순 이동 기준의 글로벌 점은 (104,53)입니다. 표시 시 이미 글로벌화된 좌표에 원점을 다시 더하지 않습니다.

슬라이스는 BeadReference 모델의 수명에 묶입니다. 모델을 내려놓은 뒤 경로가 필요하다면 필요한 점을 소유 벡터로 복사합니다. 폭은 픽셀 기준과 선택한 단위를 확인하고 자동으로 물리 길이라 가정하지 않습니다.

폭 목록과 경로점은 같은 순서의 기준을 나타냅니다. 어떤 점의 폭을 확인할 때 같은 인덱스를 유지하고, 값을 정렬하거나 일부만 복사했다면 원래 인덱스도 함께 보관합니다.

모델을 encode해 저장했다면 복원에 사용한 template이 실제 영상의 기하에 맞는지 확인합니다. 경로는 로컬 위치이므로 다른 ROI에서 재사용할 때 원점과 영역 크기를 먼저 검토합니다.

경로점 하나는 선 전체의 길이가 아니라 샘플 위치입니다. 연속 점들 사이의 거리와 탐침별 폭을 해석하려면 샘플 순서, 원본 좌표 단위 및 제외한 탐침 정보를 함께 봅니다.

경로를 그리는 화면의 배율이 바뀌어도 모델의 점 값은 바뀌지 않습니다. 화면 점을 다시 모델 입력으로 사용할 때는 표시 변환을 역으로 적용하고 ROI 기준을 맞춥니다.

경로가 곡선이라면 단순히 x 좌표만 기준으로 다시 정렬하면 원래 진행 순서를 잃을 수 있습니다. 각 점의 이웃과 대응하는 폭을 유지해 구간 결과를 해석합니다. 저장 또는 표시 목적으로 복사할 때도 해당 모델과 입력 프레임의 관계를 함께 보관합니다.
