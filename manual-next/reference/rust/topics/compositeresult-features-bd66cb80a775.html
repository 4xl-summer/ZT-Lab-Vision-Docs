pub fn features(&self) -> &[CompositeFeatureResult]

Returns feature values and individual failures.

반환값과 수명

복합 측정의 개별 CompositeFeatureResult를 불변 슬라이스로 빌립니다. 항목별 기하의 종류, 실패 이유와 계수를 함께 확인하고 계산할 수 없는 형상은 정상 계수로 취급하지 않습니다. 빌린 슬라이스의 사용 기간은 결과 객체의 수명에 연결됩니다.

특징별 값과 실패 판독

features는 평가 결과에 포함된 CompositeFeatureResult들의 불변 슬라이스를 빌립니다. 각 항목의 형상 종류와 계수, 실패 상태를 함께 읽어야 합니다. 모델 평가 호출이 성공했어도 개별 특징이 실패할 수 있으므로 실패한 항목의 계수를 정상 기하로 해석하지 않습니다.

결과를 사용할 때

예를 들어 영상에서 두 선을 찾아 교점을 계산하는 그래프에서 한 선의 검출이 실패했다면 교점 역시 유효한 좌표인지 별도로 확인해야 합니다. 특징 식별자와 공차 결과를 연결하면 어느 단계가 판정에 영향을 주었는지 찾을 수 있습니다. 슬라이스는 CompositeResult보다 오래 빌려 사용할 수 없습니다.
