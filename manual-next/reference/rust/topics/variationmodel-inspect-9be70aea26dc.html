pub fn inspect( &self, image: &ZImage, options: VariationInspectOptions, ) -> ZResult<VariationResult>

Evaluates an image with the original variation thresholds.

모델로 검사

모델과 입력 영상, VariationInspectOptions를 사용해 검사를 수행하고 ZResult<VariationResult>를 반환합니다. 원래 영상과 모델이 대응하지 않으면 위치 이동의 경계가 결함처럼 나타날 수 있습니다.

결과의 residual, severity, mask와 검사 픽셀 및 결함 픽셀 수를 함께 읽습니다. 결과 영상은 독립적으로 공유할 수 있고, 실패 오류는 실제 검사된 정상 결과와 구별합니다.

결과와 조건을 함께 읽기

각 포함 픽셀에서 현재 값에서 학습 평균을 뺀 잔차를 계산합니다. 양의 잔차에는 높은 쪽 절대 한도와 sigma 한도 중 큰 값을, 음의 잔차에는 낮은 쪽의 대응 한도를 사용합니다. 잔차 절댓값이 한도를 엄격히 초과할 때만 결함이므로 한도와 정확히 같으면 결함이 아닙니다. 예를 들어 평균 100, 입력 106, 해당 한도 5이면 잔차는 6이고 초과량은 1입니다. 반환된 residual과 severity, 마스크 및 검사·결함 픽셀 수를 함께 확인하며 입력의 정렬 상태도 검사합니다.

결함|residual|이 한도보다 클 때
severitymax(|residual| − limit, 0)
