Load an image using the existing signature-based decoder.

경로에서 영상 코덱으로 영상을 읽습니다.

인자선언된 형식확인할 내용
pathimpl AsRef<Path>읽을 파일 경로

결과와 사용 순서

반환 선언은 ImageIoResult<Self>입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

입력 또는 출력 경로와 선택한 형식이 일치하는지 확인하세요. 저장한 결과를 같은 형식으로 다시 읽어 크기와 내용을 비교하면 데이터 전달 과정의 오류를 찾는 데 도움이 됩니다.
