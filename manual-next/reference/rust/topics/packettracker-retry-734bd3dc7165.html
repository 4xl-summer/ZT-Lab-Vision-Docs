pub fn retry(&mut self, now: u64) -> Result<u32, CameraPolicyError>

On packet deadline, permits a resend request and restarts that deadline.

사용 순서와 결과 확인

패킷 마감에 도달한 뒤 재시도 상한이 남아 있으면 다음 기대 순번을 반환하고 패킷 마감 시각을 다시 시작합니다. 마감 전 호출은 오류이며 프레임·heartbeat 만료와 재시도 한도도 검사합니다. 반환 순번은 호출자가 전송 계층에 재요청할 정보이며 이 메서드가 네트워크 요청을 보내지는 않습니다.

항목의미
