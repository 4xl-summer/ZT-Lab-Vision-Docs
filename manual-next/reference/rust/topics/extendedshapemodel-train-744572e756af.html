pub fn train( image: &ZImage, mask_image: Option<&ZImage>, options: ShapeTrainingOptions, ) -> ZResult<Self>

Trains a shape model.

호출 맥락과 결과 해석

템플릿 기울기 방향을 표본화해 형상 모델을 학습합니다. ShapeTrainingOptions의 reference는 템플릿 로컬 기준점이고 sample_step은 양의 픽셀 간격입니다. threshold는 EdgeThreshold로 지정합니다. 자동 임계값은 선택 가능한 학습 위치의 0이 아닌 기울기 크기 평균입니다. 학습 마스크를 사용한다면 템플릿과 크기·원점이 맞는 Gray8을 전달합니다. 학습 결과의 feature_count와 copy_shape_features로 표본을 확인할 수 있습니다.

기울기 표본의 선택

중앙 차분은 위치의 좌우·상하 이웃을 사용하므로 마스크가 있으면 중심과 네 이웃이 모두 선택되어야 그 위치를 표본화합니다. 템플릿은 너비와 높이가 각각 3 이상이어야 하며 sample_step은 양수입니다. reference는 유한한 템플릿 로컬 점입니다.

자동 임계값은 선택 가능한 위치에서 0이 아닌 기울기 크기의 평균이고, 고정 임계값은 유한한 비음수입니다. 임계 이상인 특징이 3개 미만이면 학습이 실패합니다. 성공 후 feature_count와 copy_shape_features로 남은 방향 특징을 확인한 뒤 검색합니다.
