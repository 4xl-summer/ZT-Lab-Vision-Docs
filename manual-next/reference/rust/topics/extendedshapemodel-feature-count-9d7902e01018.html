pub fn feature_count(&self) -> usize

Returns the number of shape features.

호출 맥락과 결과 해석

모델에 저장된 형상 특징의 수를 반환합니다. 검색에서 검출된 물체의 개수나 후보 평가 횟수가 아닙니다. 학습 옵션과 마스크를 바꾸었을 때 표본 수의 변화를 확인한 다음 copy_shape_features로 기준점 상대 위치와 방향을 구체적으로 살필 수 있습니다.

특징 수를 사용하는 방법

이 값은 학습된 모델에 보관된 위치·방향 표본 수입니다. 예를 들어 feature_count가 40이어도 영상에서 물체가 40개 발견되었다는 뜻이 아닙니다. 실제 검출 후보는 find 결과의 matches에서, 평가 포즈 수는 evaluated에서 각각 확인합니다.

템플릿의 마스크와 표본 간격, 기울기 임계값을 바꾸면 학습된 특징의 수와 분포가 달라질 수 있습니다. 개수만으로 특징이 원하는 경계에 있는지 알 수 없으므로 copy_shape_features에서 기준점 상대 위치와 방향도 함께 봅니다.
