pub fn to_lab(&self) -> ZResult<AdvancedPlanes>

Converts LCH planes to Lab, retaining the white point.

사용과 결과 해석

LCH 평면을 Lab 평면으로 변환하여 새 결과를 만듭니다. 입력이 LCH가 아니거나 성분의 형식·크기·원점이 일치하지 않으면 오류입니다. 백색점과 전달 특성은 유지됩니다.

L은 유지하고 C와 h로부터 a와 b를 계산합니다. 예를 들어 C가 0이면 색상각과 관계없이 a와 b는 0입니다. 각도는 도 단위로 해석합니다.

LCH에서 Lab 성분 계산

to_lab은 AdvancedPlanes의 LCH 평면을 Lab 평면으로 변환한 새 AdvancedPlanes를 ZResult로 반환합니다. 입력이 LCH가 아니거나 성분 형식·크기·원점이 일치하지 않으면 오류입니다. 저장된 백색점과 전달 특성은 변환된 평면의 해석에 계속 필요합니다.

L은 그대로 두고 채도 C와 색상각 h로 a=C×cos(h), b=C×sin(h)를 계산합니다. h는 도 단위이므로 삼각함수에 대입할 때 라디안으로 변환해 생각할 수 있습니다. 예를 들어 C=0이면 h와 관계없이 a=b=0이고, C=10, h=0도라면 a=10, b=0입니다.

입력LCH 평면과 저장된 백색점
L변환 시 유지

적용과 결과 확인

반환값은 입력 LCH 평면을 바꾸는 방식이 아니라 별도 결과입니다. 각 평면을 취득해 쓸 때 모델과 채널 영상의 수명을 구분하고 동일한 ROI 크기와 원점을 확인하세요. Lab과 LCH의 두 번째·세 번째 성분은 의미가 다르므로 같은 인덱스 숫자를 그대로 비교하면 안 됩니다. 변환 오류와 정상적인 0 채도 값을 구분합니다.

색상각이 90도이고 C=10인 또 다른 손계산에서는 cos 90°=0, sin 90°=1이므로 a≈0, b≈10입니다. 부동소수 계산에서는 0 근처에 아주 작은 오차가 있을 수 있습니다. 이 예제는 LCH에서 Lab 성분으로 바꾸는 관계를 보여 줄 뿐, 백색점이 다른 두 영상의 Lab 수치가 그대로 비교 가능하다고 보장하지 않습니다. 각 평면의 폭과 높이, 원점이 같아야 같은 위치의 L, C, h를 조합할 수 있습니다. 색상각은 도 단위로 기록하세요.
