Rust
fn as_engine(&self) -> &Self::Target

Borrows the engine representation immutably for the lifetime of the facade owner.

변환과 소유권

facade가 보유한 엔진 표현을 불변 참조로 빌립니다. 반환 참조의 수명은 원래 소유자에 묶이며 원래 객체를 소비하거나 엔진 객체를 복사하지 않습니다.

빌린 참조를 사용하는 동안 소유자를 유지하십시오. 더 오래 보관하거나 소유권을 이전해야 한다면 해당 타입의 소유 변환을 확인하고 참조와 이동을 구별해야 합니다.

확인 항목이 메서드
트레이트asengine
호출as_engine
대상 타입구현별 연관 타입 Target

Rust에서 확장 메서드를 사용하려면 해당 bridge 트레이트를 스코프에 가져와야 합니다. 구체 구현의 수명과 오류 조건을 함께 확인하십시오.

AsEngine 브리지의 소유 관계

as_engine의 선언은 &self를 받아 &Self::Target를 돌려줍니다. 불변 참조로 빌림이라는 방향을 먼저 확인합니다. Target은 각 구체 구현이 정하는 연관 타입이며 트레이트 이름만으로 임의의 다른 엔진 타입과 변환된다고 추론하지 않습니다.

소유자는 유지되며 빌린 참조는 소유자의 수명을 넘을 수 없습니다. 읽기만 필요한지 소유권 이전이 필요한지에 따라 해당 구현의 빌림 또는 이동 API를 선택합니다. 트레이트 확장 메서드로 호출할 때는 필요한 bridge 트레이트를 스코프에 가져와야 합니다.
