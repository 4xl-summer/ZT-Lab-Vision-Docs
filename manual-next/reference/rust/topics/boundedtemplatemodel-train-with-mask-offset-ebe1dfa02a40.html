pub fn train_with_mask_offset( image: &ZImage, mask_image: &ZImage, metric: TemplateMetric, offset: (i32, i32), ) -> ZResult<Self>

Trains with an explicitly offset mask.

호출과 결과 해석

mask_image의 원점을 템플릿 로컬 offset (x, y)으로 지정해 정수 평행이동 모델을 학습합니다. offset은 부호 있는 32비트 좌표 쌍이고 마스크는 템플릿 전체를 덮는 Gray8이어야 합니다. TemplateMetric::ColorNcc는 RGB8, TemplateMetric::GraySad는 Gray8 템플릿을 사용합니다. 학습된 모델로 find할 때도 영상 형식을 맞춥니다.

판독과 사용 순서

offset은 마스크 픽셀 (0,0)이 템플릿 로컬 좌표의 어디에 놓이는지를 나타냅니다. 예를 들어 offset (-1,-1)이라면 템플릿의 (0,0)은 마스크의 (1,1)에 대응합니다. 마스크 전체가 템플릿 영역을 덮어야 하므로 부호만 보고 반대 방향으로 옮기지 말고 네 모서리의 대응을 확인하십시오. 마스크는 Gray8이며 ColorNcc에는 RGB8 템플릿, GraySad에는 Gray8 템플릿을 사용합니다. 이 호출은 마스크와 템플릿으로 모델을 학습하는 단계이며 검색 위치는 이후 find 호출의 입력 영상에서 결정됩니다. 다른 ROI에서 쓰는 마스크라면 로컬 기준을 먼저 맞춥니다.
