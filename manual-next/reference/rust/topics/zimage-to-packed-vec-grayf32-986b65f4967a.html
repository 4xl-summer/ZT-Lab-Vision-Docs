Rust
pub fn to_packed_vec_grayf32(&self) -> ZResult<Vec<f32>>

보이는 성분을 패딩 없이 행 우선 순서의 독립 벡터로 복사합니다.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Vec<f32>>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

현재 영상의 데이터를 선언된 형식의 배열로 읽습니다. 영상의 폭과 높이, 채널 수와 결과 요소 순서를 함께 확인하세요. ROI에서 읽었다면 전체 원본이 아니라 해당 보이는 영역의 크기로 결과를 해석해야 합니다.

GrayF32 값을 행 우선 복사

to_packed_vec_grayf32는 GrayF32 영상의 보이는 성분을 패딩 없이 행 우선의 독립 Vec<f32>로 복사합니다. 벡터의 요소 하나는 부동소수 성분 하나이며 원본 영상의 바이트 배열을 그대로 반환하는 것이 아닙니다. 형식이 맞지 않으면 오류를 처리합니다.

항목의미와 확인
입력GrayF32 영상 또는 ROI
반환Vec<f32> 소유 복사
첫 행[0.25,0.5]
둘째 행[1.0,2.0]
결과[0.25,0.5,1.0,2.0]
패딩원본 행 패딩 제외

사용할 때의 판독

예를 들어 2×2 ROI의 행들이 [0.25,0.5], [1.0,2.0]이면 결과는 [0.25,0.5,1.0,2.0] 순서의 f32 네 개입니다. 원본의 행 간 여유 바이트는 포함되지 않습니다. 벡터는 소유 복사이므로 빌린 GrayF32View처럼 원본 영상 수명에 묶이지 않습니다.
