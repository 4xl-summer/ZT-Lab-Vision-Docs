pub fn encode(&self, max_bytes: usize) -> ZResult<Vec<u8>>

Serializes the current state with an explicit byte limit.

사용과 결과 해석

현재 누적 상태를 버전과 체크섬이 포함된 바이트로 직렬화합니다. 출력 크기는 68 + 17 × 픽셀 수 바이트이며 지정한 max_bytes를 넘으면 오류입니다. 픽셀 수는 선택 마스크의 포함 개수가 아니라 전체 영상 크기입니다.

예: 2×2 영상의 상태는 68 + 17×4 = 136바이트입니다. 이후 decode에는 같은 형식, 크기와 ROI 원점의 템플릿이 필요하므로 저장한 상태와 함께 해당 기하 정보를 관리하십시오.

픽셀 수로 저장 크기 계산

encode는 현재 누적 기준 상태를 버전과 체크섬이 포함된 소유 바이트 벡터로 직렬화하며 max_bytes로 출력 상한을 정합니다. 크기는 68+17×전체 픽셀 수 바이트입니다. 마스크가 일부 픽셀을 제외해도 이 크기 계산에는 영상 전체 폭과 높이를 사용합니다.

사용할 때의 판독

예를 들어 2×2 영상이면 픽셀 수는 4이고 출력 크기는 68+17×4=136바이트입니다. max_bytes가 135이면 이 상태를 담기에 부족하고 136이면 크기 조건에 맞습니다. 복원 시에는 같은 형식, 크기와 ROI 원점을 가진 템플릿이 필요하므로 바이트와 영상 기하를 함께 저장하세요.
