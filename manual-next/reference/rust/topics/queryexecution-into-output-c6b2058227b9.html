pub fn into_output(self) -> T

Consumes the execution, returning its output and dropping all captures.

결과 해석과 수명

QueryExecution을 소비하고 저장된 출력 T를 소유 값으로 반환합니다. 이 과정에서 실행 객체가 보유하던 모든 캡처는 버려집니다. 캡처가 필요한 경우 먼저 별도로 확보하고, 단순 조회만 필요하다면 객체를 소비하지 않는 output을 사용합니다.

함께 사용하는 조회

호출역할
outputReturns the cached output while the execution is alive.
