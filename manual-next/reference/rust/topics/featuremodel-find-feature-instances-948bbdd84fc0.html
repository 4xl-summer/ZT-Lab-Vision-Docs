pub fn find_feature_instances( &self, image: &ZImage, search_mask: Option<&ZImage>, options: FeatureMatchOptions, max_instances: usize, total_hypotheses: usize, min_inliers: usize, ) -> ZResult<MatchingReport<FeatureInstanceReport>>

Finds multiple instances using the existing bounded hypothesis budget.

호출과 결과 해석

하나의 특징 모델로 영상에서 여러 인스턴스를 찾습니다. max_instances는 반환 인스턴스의 상한이고 total_hypotheses는 공유 가설 예산, min_inliers는 수락 내점 수입니다. FeatureMatchOptions와 검색 마스크는 별도로 적용됩니다. 반환 보고서의 개별 인스턴스와 예산 상태를 함께 읽습니다.

결과와 조건을 함께 읽기

하나의 모델 특징은 서로 다른 물체 인스턴스에서 반복될 수 있지만, 한 검색 영상 특징은 최대 하나의 모델 특징에 대응합니다. 수락된 인스턴스의 내점인 검색 특징은 다음 RANSAC 시도 전에 제거됩니다. max_instances는 1~64, total_hypotheses는 1~100000이며 내점 최소 수는 아핀에서 3개, 투영에서 4개 이상이어야 합니다. 이 일대다 경로는 mutual 대응을 지원하지 않습니다. 반환된 각 변환과 내점 수뿐 아니라 전체 evaluated와 incomplete를 읽어 예산 제한이 결과에 미친 영향을 판단합니다.
