pub fn train( image: &ZImage, mask_image: Option<&ZImage>, options: TrainingOptions, ) -> ZResult<Self>

Trains the model from a template and optional mask.

호출과 결과 해석

템플릿과 선택 마스크, TrainingOptions로 확장 NCC 모델을 학습합니다. 기준점은 템플릿 로컬 좌표이고 sample_step은 양의 픽셀 간격입니다. 마스크는 템플릿과 크기와 원점이 같은 Gray8입니다. 생성 모델의 reference와 sample_count를 확인하고 별도의 검색 옵션으로 find를 수행합니다.

선택 표본과 NCC 성립 조건

TrainingOptions의 sample_step으로 템플릿 로컬 (0,0)부터 격자를 표본화합니다. 예를 들어 5×5 영상에서 간격 2라면 각 축에서 0,2,4를 방문합니다. 마스크가 있으면 그 위치의 값이 0인 표본은 제외하며 크기와 원점이 템플릿과 같아야 합니다.

모델은 선택한 위치를 reference 상대 좌표와 밝기값으로 보관합니다. 유한한 reference는 템플릿 밖에도 둘 수 있습니다. 선택 표본이 3개 미만이거나 선택 밝기가 모두 같으면 NCC를 학습할 수 없어 오류입니다. 학습 뒤 sample_count와 reference로 모델 구성을 점검합니다.
