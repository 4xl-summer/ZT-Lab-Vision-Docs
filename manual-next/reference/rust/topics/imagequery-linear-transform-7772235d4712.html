결과와 사용 순서

이 메서드는 영상 연산을 쿼리 계획에 연결합니다. 설정을 마친 다음 실행 메서드에서 결과를 얻고 실행 실패를 처리하세요. 계획을 만드는 단계와 픽셀 결과를 읽는 단계를 구분해야 합니다.

Rust 선언에서 self를 값으로 받으므로 호출은 기존 계획 값을 이동합니다. 성공 시 반환된 계획을 받아 다음 단계에 연결하세요. 예를 들어 첫 연산을 추가한 결과로 두 번째 연산을 구성하며, 이동한 이전 변수를 다시 사용하는 대신 새 반환값을 사용합니다.

반환 선언 ZResult<Self>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

보정이나 변환 결과를 사용하기 전에 출발 프레임과 도착 프레임, 길이 단위를 확인하세요. 알려진 점 하나를 변환해 입력 좌표와 기대 결과를 비교하면 방향 오류를 찾는 데 도움이 됩니다.
