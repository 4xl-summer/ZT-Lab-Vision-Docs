문자별 위치

문자별 OcrChar 슬라이스를 빌려 반환합니다. 각 문자에는 코드 포인트와 모서리 좌표가 있으므로 전체 text와 원본 영상의 위치를 대응시킬 수 있습니다.

OcrRead는 불변 결과 스냅샷입니다. 문자열과 문자 슬라이스는 이 결과를 빌리므로 소유자가 살아 있는 동안 사용하고 더 오래 유지할 값은 복사합니다.

문자별 코드와 위치

chars는 OcrChar 슬라이스를 빌려 반환합니다. 각 항목은 코드 포인트와 네 모서리를 담으며, 각 모서리는 입력 로컬과 전체 프레임 전역 위치를 함께 표현합니다.

예를 들어 ROI 원점이 (100,50)이고 로컬 모서리가 (4,3)이면 단순 이동 기준의 전역 위치는 (104,53)입니다. 이미 전역 좌표로 받은 점에 원점을 다시 더하지 않습니다. 화면 확대와 이동도 별도로 적용합니다.

문자별 좌표가 존재한다는 사실만으로 전체 판독이 수락된 것은 아닙니다. status와 reasons, 전체 text를 함께 확인합니다. 슬라이스가 결과보다 오래 필요하면 필요한 문자와 점을 소유 자료로 복사합니다.
