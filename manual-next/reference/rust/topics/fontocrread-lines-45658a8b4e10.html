문자 줄 순회

줄별 FontGlyph 슬라이스를 반환하는 정확한 크기의 반복자를 만듭니다. 각 줄과 글자의 순서를 보존하면 표시된 문자열을 입력 영상의 셀 위치와 연결할 수 있습니다.

슬라이스는 FontOcrRead가 소유한 결과를 빌리므로 소유 결과보다 오래 사용할 수 없습니다. 원본 모서리를 표시할 때 화면과 입력 영상의 좌표계를 확인합니다.

줄과 문자 결과를 연결

lines는 줄마다 FontGlyph 슬라이스를 돌려주는 ExactSizeIterator입니다. 전체 문자열을 재구성할 때는 줄 순서와 각 줄의 글자 순서를 유지해야 원래 판독의 배치를 잃지 않습니다. 각 슬라이스는 FontOcrRead가 소유한 자료를 빌립니다.

예를 들어 첫 줄에 글자 세 개, 둘째 줄에 두 개가 있으면 반복자는 두 슬라이스를 내놓고 각 슬라이스의 길이는 각각 3과 2입니다. 전체 글자 다섯 개를 한 줄로 합치는 것은 원래의 줄 구조를 표현하지 못합니다. 빈 줄이나 결과가 있는지 실제 반환을 확인합니다.

글자별 라벨, 셀, 점수 및 accepted를 전체 score와 accepted에 연결해 읽습니다. 점수는 이진 템플릿 유사도이며 보정된 정확도 확률이 아닙니다. 입력을 화면에 표시할 때 글자의 원본 모서리와 현재 영상의 좌표 기준을 맞춥니다.

결과보다 오래 문자를 보관해야 한다면 필요한 값을 소유 자료로 복사합니다. 판독 결과와 학습 모델, 사용한 옵션 및 프레임 식별자를 함께 저장하면 다른 조건의 판독을 나중에 구별할 수 있습니다.
