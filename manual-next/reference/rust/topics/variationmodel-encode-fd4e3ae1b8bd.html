pub fn encode(&self, max_bytes: usize) -> ZResult<Vec<u8>>

Serializes this model subject to the existing byte limit.

모델 직렬화

max_bytes 한도 안에서 모델을 바이트 벡터로 직렬화하고 ZResult로 반환합니다. 바이트 수가 한도를 초과하거나 직렬화가 실패한 경우 오류를 처리해야 합니다.

반환 Vec는 모델의 빌린 내부 버퍼가 아닌 소유 바이트입니다. 저장된 데이터와 모델 학습 조건을 함께 관리하고, 직렬화에 성공했다는 사실을 검사의 정확성 보증으로 사용하지 않습니다.

모델 크기와 저장 한도

encode는 변동 모델을 버전이 있는 바이트 표현으로 저장하며 max_bytes가 출력 크기보다 작으면 오류를 반환합니다. 현재 형식의 크기는 전체 픽셀 수 n에 대해 56+17n+4, 즉 60+17n바이트이며 구현의 최대 크기 제한도 적용됩니다. 반환 Vec는 소유 바이트입니다.

항목의미와 확인
크기식60+17×전체 픽셀 수 바이트
2×2 예60+17×4=128바이트
127바이트 한도예시 크기에 부족
128바이트 한도예시 크기 조건에 맞음
반환소유 Vec<u8> 또는 오류
저장바이너리 바이트와 모델 조건 보관

사용할 때의 판독

예를 들어 모델이 2×2이면 n=4이고 크기는 60+17×4=128바이트입니다. max_bytes=127은 부족하며 128은 이 예의 크기 기준에 맞습니다. 이 값은 선택된 픽셀만의 개수가 아닙니다. 저장된 바이트를 복원한 뒤 같은 입력을 검사해 모델과 포함 영역이 기대대로 보존되는지 검증하세요.
