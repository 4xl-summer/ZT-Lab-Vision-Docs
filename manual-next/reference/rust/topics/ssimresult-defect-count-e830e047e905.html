pub fn defect_count(&self) -> usize

Returns the number of defect pixels.

결함 픽셀 수

결함으로 분류된 픽셀 수를 usize로 반환합니다. 이 값은 연결된 결함 후보의 개수와 다르며, 인접한 여러 전경 픽셀이 하나의 후보로 묶일 수 있습니다.

이 값은 해당 입력과 옵션으로 수행한 한 번의 검사 결과입니다.

결과와 조건을 함께 읽기

defect_count는 SSIM 검사에서 결함으로 분류된 픽셀의 수입니다. 연결 성분을 몇 개 발견했는지를 뜻하지 않습니다. 예를 들어 서로 인접한 결함 픽셀 3개는 픽셀 수가 3이지만 연결 규칙에 따라 한 성분일 수 있습니다. 이 값은 전체 검사 픽셀 수 및 임계 조건과 함께 읽어야 비율이나 결함의 크기를 이해할 수 있습니다. 픽셀 수를 바로 제곱밀리미터로 표시하지 말고 영상 해상도와 적절한 보정 조건을 확인합니다. 값은 usize로 복사되어 반환됩니다.
