pub fn features(&self) -> &[LocalFeature]

Returns trained feature descriptors as immutable references.

반환값과 수명

학습된 LocalFeature를 불변 슬라이스로 빌립니다. 모델 쪽 특징과 기술자를 살피는 조회이며 검색 영상에서 찾은 대응점이나 기하 변환 결과가 아닙니다. 빌린 특징의 수명은 모델에 연결되므로 모델을 더 이상 사용할 수 없게 하기 전에 필요한 데이터를 처리합니다.

학습 특징과 검색 결과

features는 FeatureModel에 저장된 LocalFeature 기술자들의 읽기 전용 슬라이스를 제공합니다. 이 목록은 모델 학습의 산출물입니다. 새로운 입력 영상에서 찾은 대응점이나 매치된 변환이 아니므로 검색 결과와 별도로 확인해야 합니다.

사용할 때의 판독

예를 들어 모델 특징이 여러 개라도 검색 영상의 가림이나 무늬에 따라 실제로 대응한 특징의 수는 달라질 수 있습니다. 모델 목록을 보고 학습 정보가 존재하는지 확인한 다음 find의 검색 보고에서 실제 대응과 기하 검증을 살펴보세요. 반환 슬라이스는 모델을 빌리므로 모델의 수명 안에서 사용합니다.
