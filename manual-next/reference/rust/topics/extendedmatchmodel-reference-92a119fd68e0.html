pub fn reference(&self) -> Point2

Returns the trained reference point.

반환값과 수명

학습한 템플릿 로컬 기준점을 Point2 값으로 반환합니다. 검색 포즈의 위치는 이 기준점을 기준으로 해석하므로 템플릿 좌상단과 혼동하지 않습니다. 같은 템플릿이라도 학습 기준점을 다르게 주면 반환 위치의 의미도 달라집니다.

기준점과 좌표의 관계

reference는 학습 템플릿의 로컬 좌표이며 유한하다면 템플릿 밖의 점도 지정할 수 있습니다. 모델 표본은 각각 이 점을 뺀 상대 위치로 보관됩니다. 예를 들어 템플릿 점 (7,4), 기준점 (5,3)이면 상대 위치는 (2,1)입니다.

검색 포즈의 x와 y는 이 기준점이 검색 ROI에서 놓인 위치입니다. 검색 영상이 원본의 일부라면 ROI 원점을 더해 원본 좌표를 얻습니다. 같은 템플릿이라도 기준점을 바꾸어 학습하면 결과 위치의 기준도 달라지므로 모델과 기준점 정보를 함께 보관합니다.
