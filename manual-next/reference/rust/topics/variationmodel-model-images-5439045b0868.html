pub fn model_images(&self) -> ZResult<(ZImage, ZImage)>

Reconstructs independent GrayF64 mean and deviation images. Each call allocates two new images; each image retains the source origin.

모델 영상 복원

모델의 평균과 편차를 독립된 GrayF64 영상 두 개로 재구성합니다. 호출마다 두 영상을 새로 할당하며 각각 원본 origin을 보존합니다. 순서는 평균, 편차입니다.

예를 들어 기준 위치가 특정 ROI의 원점을 가진다면 두 결과도 해당 origin을 유지하므로 다른 원점의 영상과 연결하기 전에 좌표를 확인합니다. 두 반환 영상은 Rust 소유 값으로 각자의 수명을 가집니다.

조건과 결과 판독

호출할 때마다 학습 모델에서 평균과 편차를 각각 독립 GrayF64 영상으로 재구성합니다. 튜플의 첫 번째가 평균, 두 번째가 편차이며 각각 입력 모델의 원래 origin을 보존합니다.

예를 들어 평균 영상과 다른 ROI에서 얻은 검사 영상을 비교한다면 폭·높이뿐 아니라 글로벌 원점도 확인해야 합니다. 반환 영상은 새 소유 값이므로 둘의 수명은 각각 관리됩니다. 모델의 통계 요약이며 이 호출 자체가 새 검사 판정을 수행하지는 않습니다.
