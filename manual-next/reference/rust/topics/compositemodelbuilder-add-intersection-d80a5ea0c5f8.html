pub fn add_intersection( &mut self, id: u64, first: usize, second: usize, ) -> ZResult<usize>

Adds the intersection of two earlier lines.

사용과 결과 해석

앞서 추가한 두 직선 특징의 인덱스 first와 second를 참조하는 교점 특징을 추가합니다. id는 새 특징의 식별자이며 반환값은 새 특징의 목록 인덱스입니다. 잘못된 순서나 참조는 추가 단계에서 검증됩니다.

직선 자체를 먼저 등록한 뒤 각각의 반환 인덱스를 사용하십시오. 교점의 개별 평가가 실패할 수 있으므로 결과의 특징별 상태도 확인해야 합니다.

먼저 직선, 다음 교점

add_intersection은 이미 추가한 두 직선 특징의 인덱스를 참조해 교점을 추가합니다. first와 second는 직선의 목록 인덱스이고 id는 새 교점 특징의 식별자입니다. 성공 반환값은 새 교점의 목록 인덱스이므로 세 종류의 숫자 역할을 구분해야 합니다.

결과를 사용할 때

예를 들어 y=0과 x=2라는 두 직선이 있으면 교점은 (2,0)입니다. 두 직선을 먼저 등록하고 각 반환 인덱스를 교점에 전달하세요. 평행하거나 평가에 필요한 직선이 실패한 경우 교점의 개별 평가가 실패할 수 있으므로 반환된 CompositeResult의 특징별 상태를 확인합니다.
