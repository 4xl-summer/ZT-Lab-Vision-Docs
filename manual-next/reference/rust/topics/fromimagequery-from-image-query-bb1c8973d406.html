fn from_image_query(value: Self::Target) -> Self

Transfers the supplied engine representation into the facade owner.

변환과 소유권

연관 타입 Target의 엔진 표현을 받아 facade 소유 값으로 이전합니다. 이 트레이트의 호출은 입력 값의 소유권을 받으며 정확한 Target은 구현하는 구체 타입이 결정합니다.

입력 표현을 이후에도 독립적으로 사용해야 한다면 해당 타입이 제공하는 공유 또는 복제 방법을 먼저 확인하십시오. 트레이트 이름만으로 다른 표현과의 변환 가능성을 가정하지 않습니다.

호출과 결과 판독

FromImageQuery::from_image_query는 구현 타입의 연관 Target을 값으로 받아 facade 쿼리 소유 값으로 옮깁니다. 입력을 빌리는 시그니처가 아니므로 이동한 원래 값을 이후에 그대로 사용할 수 없습니다.

실제 HistogramQuery 구현은 Target으로 engine::ImageHistogramQuery를 받고 다중 형식 히스토그램 계획으로 감쌉니다. 이 변환 자체는 히스토그램을 실행하지 않습니다. 구체 구현에서 확인된 이 예를 다른 모든 쿼리 타입의 Target으로 일반화해서는 안 됩니다.

계획의 소유권을 옮긴 후 실제 빈 계산은 해당 쿼리의 execute에서 확인합니다. 입력을 두 흐름에 사용해야 한다면 이동 전에 구체 타입이 제공하는 복제나 공유 계약을 먼저 확인하십시오. 동일한 트레이트 이름만으로 임의의 엔진 표현을 받을 수 있다고 가정하지 않습니다.
