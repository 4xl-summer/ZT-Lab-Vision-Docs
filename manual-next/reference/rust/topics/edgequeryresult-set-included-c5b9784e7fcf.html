pub fn set_included(&mut self, label: u64, included: bool) -> ZResult<()>

Updates inclusion for one label.

사용과 결과 해석

안정적인 label로 체인의 포함 여부를 설정합니다. false는 체인을 파괴하지 않으며, 같은 label에 true를 지정하면 다시 포함됩니다. label이 존재하지 않으면 오류입니다.

포함 항목만 count와 인덱스 선택에 나타납니다. 예를 들어 label 1, 2, 3에서 2를 제외하면 인덱스 1은 label 3이 되지만 label 3 자체는 바뀌지 않습니다. 추적에는 label을 사용하십시오.

선택 상태의 변화

세 label 1, 2, 3에서 2를 제외하면 포함 인덱스 1은 label 3이 됩니다. 다시 2를 포함하면 인덱스 1은 label 2가 됩니다. 상태 변경 전 저장한 인덱스를 장기 식별자로 사용하지 마십시오.

항목의미와 조건
입력인덱스가 아닌 안정 label
false체인을 선택 목록에서 제외
true기존 체인을 다시 포함
count포함된 체인 수만 계산
인덱스남은 항목이 원래 순서의 조밀한 목록을 구성
delete재포함할 수 없는 영구 삭제
없는 label오류
