pub fn termination(&self) -> MatchTermination

Returns the reason the search stopped.

반환값과 수명

검색을 멈춘 이유를 MatchTermination으로 반환합니다. matches가 비어 있더라도 종료 이유와 evaluated를 함께 살펴야 평가 진행과 후보 유무를 구분할 수 있습니다. 예산을 포함한 검색 설정과 종료 상태를 같은 실행 기록에 보관합니다.

검색 종료와 평가량

termination은 검색이 멈춘 이유를 MatchTermination 값으로 반환합니다. 결과 목록이 비어 있을 때에도 종료 이유와 evaluated 후보 수를 함께 봐야 실제로 평가가 얼마나 이루어졌는지 판단할 수 있습니다.

항목확인할 내용

설정예산과 탐색 범위

예를 들어 후보가 없다는 사실만으로 검색 범위를 충분히 모두 평가했는지 결론 낼 수 없습니다. 해당 실행의 예산, 종료 상태와 matches를 같은 기록에 보관하고 필요한 경우 입력 ROI와 탐색 격자를 조정해 비교합니다.
