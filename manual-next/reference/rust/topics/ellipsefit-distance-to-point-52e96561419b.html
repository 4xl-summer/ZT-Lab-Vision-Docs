지정 점에서 적합 타원 경계까지의 비음수 최소 거리를 입력 좌표 단위로 계산합니다. 타원 내부의 점도 경계까지의 거리를 갖습니다. 중심 간 거리나 대수식 잔차와 구분해야 하며, 유효한 EllipseFit을 준비한 뒤 결과 또는 오류를 확인합니다.

타원 경계까지의 최소 거리

distance_to_point는 EllipseFit과 입력 Point2 사이의 거리를 계산합니다. 반환값은 타원 경계 위의 가장 가까운 점까지의 음이 아닌 유클리드 거리이며, 중심까지의 거리나 타원 내부 여부를 나타내는 부호 있는 값이 아닙니다. 타원과 점은 반드시 같은 좌표계와 단위로 준비해야 합니다.

타원은 유한한 중심과 각도, 양의 minor_radius, minor_radius 이상인 major_radius를 가져야 합니다. 점과 계산값도 유한해야 하며 잘못된 기하 값은 ZResult 오류로 처리합니다. 예를 들어 중심이 (0,0)이고 반지름이 각각 2인 원형 특례에서 점 (3,0)은 경계까지 거리 1이고, 중심점은 경계까지 거리 2입니다.

입력 점이 타원 내부여도 경계로부터의 거리는 양수일 수 있고, 경계에 있는 점의 거리는 0입니다. 따라서 내부와 외부를 구분하는 판정이 필요하다면 별도의 기하 판정이 필요합니다. 동일한 단위의 허용 공차와 비교하고, 보정되지 않은 픽셀 좌표를 물리 단위 거리처럼 해석하지 않습니다.
