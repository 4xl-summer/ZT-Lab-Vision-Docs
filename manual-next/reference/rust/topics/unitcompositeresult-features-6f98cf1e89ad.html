Rust
pub fn features(&self) -> &[CompositeFeatureResult]

Returns feature values and failures in the selected unit.

반환값과 수명

선택한 단위를 적용한 복합 측정의 개별 결과와 실패 상태를 불변 슬라이스로 빌립니다. 각 항목의 kind와 failure를 확인하고 사용 가능한 계수의 좌표·길이를 해당 CompositeUnit으로 해석합니다. 독립 저장이 필요하면 필요한 값을 복사합니다.

함께 확인할 값

항목해석
features선택 단위가 반영된 개별 결과
kind / failure형상 종류와 개별 실패 상태
CompositeUnit계수의 좌표와 길이를 해석하는 단위

특징별 평가 결과

features는 단위가 지정된 복합 측정 결과의 특징 목록을 제공합니다. 각 특징의 값과 상태를 같은 실행의 공차 결과 및 전체 상태와 함께 읽어야 부분 실패를 놓치지 않습니다.

항목확인할 내용
features특징별 값과 상태
unit해당 결과의 단위
tolerances공차별 판정
전체 상태부분 실패를 포함해 함께 확인

예를 들어 두 특징 중 하나가 실패하면 모델 평가 호출 자체가 반환되었다는 사실만으로 모든 측정이 유효하다고 볼 수 없습니다. 결과 unit과 좌표 기준을 보관하고 픽셀 수치와 물리 단위의 공차를 변환 없이 비교하지 않습니다.
