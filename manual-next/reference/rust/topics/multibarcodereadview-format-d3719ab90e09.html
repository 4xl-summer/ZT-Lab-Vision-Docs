코드 형식

심볼의 MultiBarcodeFormat 값을 반환합니다. 탐색한 형식 목록과 실제 읽힌 형식을 함께 기록하고, 읽기가 없을 때 임의 형식으로 대체하지 않습니다.

이 뷰는 MultiBarcodeReads가 보유한 결과를 빌립니다. 문자열과 슬라이스를 포함해 반환 참조는 원본 컬렉션의 수명 안에서 사용합니다.

심볼 형식 읽기

이 뷰에 저장된 MultiBarcodeFormat 값을 반환합니다. 복수 스캔은 여러 심볼을 담을 수 있으므로 항목별 형식을 읽고 요청에 허용한 형식 목록과 비교합니다. 이 메서드는 선택적 형식이 아닌 형식 값을 반환합니다.

예를 들어 같은 영상의 QR과 Code 128은 서로 다른 항목의 format으로 구별합니다. 목록의 위치만으로 형식을 추정하지 말고 각 뷰의 값과 text를 짝지어 처리합니다.

형식이 반환되었다는 사실과 문자열 길이 조건 통과는 별개입니다. length_accepted도 함께 확인하고, 값을 출력할 때 해당 프레임과 검색 설정을 연결합니다.
