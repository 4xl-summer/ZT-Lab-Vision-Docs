사용과 결과 해석

이미지와 OcrSpec을 사용해 텍스트를 읽고 OcrRead를 반환합니다. OCR 모델 및 입력 문제는 인식 오류로 전달됩니다.

사양의 ROI와 전처리, 대비·길이·허용 문자 조건을 고려해 결과를 판독하십시오. 텍스트가 있는 것과 검사 조건을 통과한 것은 별개입니다.

OCR 입력과 판정

read_text는 엔진과 이미지 및 OcrSpec을 사용해 OcrRead를 반환합니다. 사양에는 현재 영상 기준의 영역과 전처리, 최소 대비, 문자열 길이와 허용 문자 조건이 포함됩니다. 모델 또는 입력 처리가 실패하면 RecognitionEngineResult의 오류를 확인해야 합니다.

텍스트가 반환된 것과 모든 검사 조건을 통과한 것은 별개입니다. 상태와 사유, 문자열을 함께 보고 공백도 예측된 문자열의 일부로 다루십시오. 예를 들어 길이 상한이 5인데 6문자가 인식되었다면 텍스트가 존재하더라도 길이 판정을 통과하지 않습니다. 모델을 제공한 측의 입력·문자 계약도 확인해야 합니다.
