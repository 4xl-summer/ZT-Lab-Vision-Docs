pub fn indices(&self) -> ZImage

Returns an independently owned index image.

반환값과 수명

색상 매칭의 기준 색 인덱스 영상을 독립 소유 ZImage로 반환합니다. 각 픽셀에서 어떤 기준 색이 선택되었는지 읽을 때 사용하며 거리 값 자체는 distances로 얻습니다. 호출 후 반환 영상은 결과 컨테이너와 별도의 소유 값으로 관리합니다.

함께 확인할 값

항목해석
indices소유 ZImage: 선택된 기준 색 번호
distances소유 ZImage: 선택 색과의 거리
samples검색에 전달한 기준 색의 순서

색 표본 번호의 의미

indices는 색상 매칭에서 픽셀마다 선택된 기준색 번호를 ZImage로 돌려줍니다. 번호는 학습 또는 검색에 전달한 표본의 순서와 함께 해석해야 합니다. 예를 들어 동일한 두 색을 반대 순서로 전달하면 선택된 색이 같아도 숫자는 달라질 수 있습니다.

항목판독할 내용
indices선택된 기준색의 인덱스 영상
distances선택된 색과의 거리 영상
표본 순서인덱스를 실제 색에 대응시키는 기준
반환 ZImage독립 소유 값

distances는 선택된 기준색과의 거리 영상입니다. 번호가 같다고 해서 거리가 같거나 설정한 판정 한도를 통과한다는 뜻은 아닙니다. 두 영상을 같은 ROI에 맞춰 읽고 결과 컨테이너와 반환 영상의 소유 관계를 구분합니다.
