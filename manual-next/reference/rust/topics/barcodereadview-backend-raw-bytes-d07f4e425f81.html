원시 바이트

백엔드가 제공한 원시 바이트를 &[u8] 슬라이스로 반환합니다. 사람이 읽는 text와 원시 바이트의 표현은 다를 수 있으므로 원본 자료가 필요하면 이 값을 별도 복사합니다.

BarcodeReadView는 상위 스냅샷을 빌린 읽기 전용 뷰입니다. 반환한 참조는 원본 소유 스냅샷의 수명 안에서만 사용하고 필요하면 값을 복사합니다.

백엔드 바이트 보관

백엔드에서 반환한 원시 바이트를 &[u8] 슬라이스로 빌려 줍니다. 화면용 text는 별도 문자열 표현이므로 원시 바이트가 필요한 시스템에 표시 문자열만 넘기고 같은 데이터라고 가정하지 않습니다.

바이트 길이는 텍스트의 문자 수와 다를 수 있습니다. 예를 들어 UTF-8 문자는 한 스칼라가 여러 바이트로 표현될 수 있습니다. 해당 바코드의 실제 원시 인코딩과 텍스트 해석은 별도로 확인하며 바이트 길이를 문자 길이 조건으로 임의 환산하지 않습니다.

슬라이스를 결과보다 오래 보관할 때는 소유 버퍼로 복사합니다. 수신 기록에는 바이트와 함께 format, status 및 결과가 나온 프레임을 연결합니다. 읽기 실패와 비어 있는 바이트 배열은 상태를 함께 보지 않으면 구분하기 어렵습니다.

이 접근자는 상위 스냅샷을 빌리는 BarcodeReadView에서 호출합니다. 바이트 슬라이스를 장기 보관할 때 소유 버퍼로 복사합니다. 바이트 배열은 문자열 표시와 별도이며 실제 원시 내용을 유지해야 하는 경우에 사용합니다.
