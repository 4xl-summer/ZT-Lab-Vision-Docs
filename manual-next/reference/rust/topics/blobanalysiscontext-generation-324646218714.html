pub fn generation(&self) -> u64

Returns the successful calculation sequence number.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언은 u64입니다. 반환값을 받는 쪽에서 해당 타입의 필드와 수명에 맞추어 사용하세요.

입력과 결과 해석

분석 설정과 현재 결과를 관리하는 컨텍스트입니다. 연결 방식이 달라지면 새 설정에 대해 다시 계산해야 합니다. 인덱스 모드는 현재 결과의 조회 방식만 바꾸며 재계산하지 않습니다. 계산 실패 시 현재 결과가 지워질 수 있습니다.

성공 계산의 순번

generation은 성공한 블롭 계산의 순번을 u64로 반환합니다. calculate가 성공할 때 다음 순번으로 진행하며, 라벨·인덱스 조회 모드를 바꾸는 것만으로는 증가하지 않습니다. 이 값은 성분 개수나 블롭 라벨이 아닙니다.

단계 또는 항목확인할 내용
성공 계산순번이 다음 값으로 증가
조회 모드 변경순번 유지
계산 실패성공 순번 증가 없음
has_current현재 결과의 존재 여부
dirty기하 설정 변경 여부

결과를 사용할 때

예를 들어 어떤 성공 계산의 순번이 3일 때 조회 모드를 바꾸어도 순번은 3입니다. 다음 계산이 성공하면 4가 됩니다. 실패한 계산은 성공 순번을 올리지 않으며 현재 결과는 비워질 수 있습니다. 순번과 has_current, dirty를 같이 기록하면 결과가 어느 계산에 속하는지 구분하기 쉽습니다.
