pub fn train( image: &ZImage, mask_image: Option<&ZImage>, options: TrainingOptions, deformations: &[TemplateDeformation], ) -> ZResult<Self>

Trains from explicit template deformations.

호출과 결과 해석

TrainingOptions와 명시된 변위 격자들로 NCC 변형 모델 은행을 학습합니다. deformations는 1..64개이고 각 격자는 2×2 이상이고 각 격자의 점 수는 1024개 이하여야 합니다. 임의의 연속 변형을 모두 학습하는 호출이 아닙니다. 학습한 격자의 입력 순서를 보관해 find 결과의 변형 인덱스를 해석합니다.

변형 격자와 학습 순서

각 TemplateDeformation은 columns×rows개의 변위점으로 한 변형을 지정합니다. 행과 열은 각각 2 이상이며 각 변형의 점 수는 최대 1024개입니다. 예를 들어 2×2 격자는 변위 네 개가 필요합니다. 변형을 1개에서 64개까지 전달하며 이 제한은 각 격자에 적용됩니다.

각 변형으로 생성한 템플릿마다 NCC 모델을 학습합니다. 원본 범위 밖 표본은 제외되고 선택 마스크가 있으면 변형된 위치에서 가장 가까운 마스크 픽셀을 검사합니다. 입력 목록 순서가 결과 variant_index의 기준이므로 변형 정의를 같은 순서로 보관합니다. 샘플이 부족하거나 값이 일정하면 NCC 학습이 실패할 수 있습니다.
