pub fn execute(&self) -> ZResult<QueryExecution<MatchResult>>

Executes and snapshots matches.

호출과 결과 확인

준비된 영상과 모델 매칭 계획을 실행하고 QueryExecution에 MatchResult 스냅샷을 반환합니다. 실행 오류는 ZResult로 전달되고 정상 실행에서 후보가 없으면 결과의 matches는 빈 슬라이스입니다. 계획의 캡처와 결과를 사용 목적에 맞게 읽으며 로컬·전역 좌표를 구분합니다.

결과와 조건을 함께 읽기

준비된 영상과 매칭 모델에 대한 계획을 실제로 실행해 MatchResult 스냅샷을 QueryExecution으로 얻습니다. 먼저 ZResult의 오류와 성공을 분기하고, 성공했다면 후보 목록이 비어 있는지 확인합니다. 후보가 없다는 정상 결과는 입력 형식이나 계획 실행 오류와 다릅니다. 캡처를 설정했다면 이름에 해당하는 중간 영상도 실행 결과를 통해 읽을 수 있으므로 원래 계획의 이름과 순서를 보존합니다. 각 매치 좌표가 현재 ROI 로컬인지 전체 영상 기준인지 확인하고 필요하면 영상 원점을 반영합니다. 실행 객체와 별도 소유 결과는 각각의 수명을 따릅니다.
