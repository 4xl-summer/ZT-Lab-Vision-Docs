pub fn into_samples(self) -> Vec<ArcProfileSample>

Transfers the owned sample buffer.

사용과 결과 판독

원호 샘플 버퍼의 소유권을 결과에서 Vec로 옮깁니다. self를 값으로 받으므로 호출 후 기존 결과를 계속 빌려 사용할 수 없으며 반환한 배열을 소유합니다. 원호 위치와 시작점부터의 거리, 평균 강도는 각 샘플에서 구분해 해석하십시오. 결과를 다른 영상과 비교할 때 원호의 ROI 원점과 각도 설정을 함께 보관합니다.

단계확인할 내용
입력소유한 원호 결과를 값으로 전달합니다.
이동샘플 버퍼의 소유권이 반환 배열로 옮겨집니다.
해석반환 항목에서 원호 거리와 평균 강도를 구분합니다.
수명이전 결과 대신 반환된 Vec를 소유해 사용합니다.

판독과 사용 순서

소유한 결과에서 샘플 벡터를 꺼내므로 호출자가 결과 객체 대신 반환된 벡터의 소유자가 됩니다. 불변 슬라이스를 빌리는 접근자와 달리 self를 값으로 전달해 소비하므로 이후 같은 결과 객체를 다시 사용할 수 없습니다. 각 원소는 원호의 위치, 시작점으로부터 원호를 따라간 거리와 평균 강도를 포함합니다. 반경 2픽셀인 90도 원호의 중심선 길이는 π픽셀이며, 이는 x 좌표의 차이와 같은 값이 아닙니다. 표본의 위치는 ROI 로컬 기준이므로 다른 영상의 표본과 비교할 때 각 ROI 원점을 함께 확인합니다.
