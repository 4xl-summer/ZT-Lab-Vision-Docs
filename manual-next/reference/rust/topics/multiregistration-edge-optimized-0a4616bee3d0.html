pub fn edge_optimized(&self) -> &[bool]

Returns whether each edge was optimized.

사용과 결과 해석

각 입력 간선이 최적화되었는지 나타내는 불리언 슬라이스를 반환합니다. 순서는 입력 그래프 간선의 순서와 대응하며 슬라이스는 결과 객체에 종속됩니다.

결과 표시 시 edge_results와 같은 인덱스를 비교하십시오. 고정된 간선에서는 측정 결과가 없을 수 있으므로 최적화 여부와 선택적 결과를 따로 해석해야 합니다.

간선 결과의 해석

edge_optimized는 입력 간선 순서에 대응하는 bool 슬라이스를 불변으로 빌립니다. 각 값은 해당 간선이 최적화되었는지 나타냅니다. 슬라이스는 MultiRegistration 결과 객체에 종속되므로 결과보다 오래 보관해야 하면 필요한 값을 복사하십시오.

고정된 초기 변환을 사용하는 간선에서는 최적화가 false일 수 있고 edge_results에 측정 결과가 없을 수 있습니다. 이는 정합 점수가 0이라는 뜻도, 반드시 정합이 실패했다는 뜻도 아닙니다. 입력 간선과 fixed 설정, 같은 인덱스의 선택적 결과를 함께 확인해 상태를 해석하십시오.
