pub fn threshold_otsu(&self) -> ZResult<Self>

Applies the legacy Gray8 Otsu threshold.

호출에 필요한 입력

이 선언에는 별도로 전달하는 이름 있는 인자가 없습니다. 선언된 수신 객체와 반환 형식을 확인한 뒤 호출합니다.

결과와 사용 순서

반환 선언 ZResult<Self>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

임계값과 비교 방향이 경계값을 어떻게 분류하는지 작은 영상으로 확인하세요. 예를 들어 경계 바로 아래, 같은 값, 바로 위의 세 픽셀을 준비하면 등호 포함 여부를 구분할 수 있습니다.

결과와 조건을 함께 읽기

이 경로는 Gray8 히스토그램으로 Otsu 기준값을 선택한 다음 그 기준 이상을 255, 미만을 0으로 만드는 이진 영상을 반환합니다. 구현의 예에서 [0,0,200,200]은 기준 1을 선택하고 출력은 [0,0,255,255]입니다. 값이 선택된 임계값과 같을 때도 전경에 포함되므로 임계값 1이면 입력 1은 255입니다. 반환 영상은 선택된 임계 숫자 자체가 아니며 필요하면 임계값 조회 기능을 별도로 사용합니다. 입력 형식이 Gray8이 아니거나 처리가 실패하면 ZResult의 오류를 처리합니다.
