소켓·유닛·시간 제한

connect는 SocketAddr, u8 unit 식별자와 0이 아닌 Duration을 받아 동기 Modbus/TCP 연결을 만듭니다. 연결 실패는 ModbusError로 반환되며 timeout은 연결과 읽기·쓰기 시간 제한에 사용됩니다. TCP 주소가 맞더라도 unit이 대상 설정과 다르면 이후 요청이 의도한 장치를 가리키지 않을 수 있습니다.

예를 들어 로컬 서버가 127.0.0.1의 특정 포트에서 대기한다면 그 주소와 실제 포트를 SocketAddr로 만들고 서버가 설정한 unit을 사용합니다. timeout은 명시적인 Duration으로 전달하며 0을 유효한 제한으로 취급하지 않습니다. 서버가 동작하지 않거나 연결이 거절되면 성공 클라이언트가 아니라 오류를 처리해야 합니다.

사용과 결과 판독

연결 후 레지스터 주소는 프로토콜의 0부터 시작하는 주소로 해석합니다. 장치 문서의 표시 주소와 프로토콜 주소가 같은지 확인한 다음 읽기·쓰기 호출을 사용하세요. 연결 객체의 수명과 서버의 수명은 별개이며, 네트워크 오류나 제한 시간 초과 시 재시도 여부는 애플리케이션의 작업 정책에 맞게 결정합니다.
