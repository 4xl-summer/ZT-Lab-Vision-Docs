영역 판독 뷰

영역의 바코드 판독을 BarcodeReadView로 빌려 반환합니다. 뷰의 status와 reasons를 확인한 다음 text, 형식과 위치를 읽습니다. 문자열을 오래 보유하려면 별도 소유 값으로 복사합니다.

반환된 뷰 또는 슬라이스는 상위 결과를 빌리므로 원본 결과의 수명 안에서 사용합니다. 값 타입 반환은 해당 필드의 복사본입니다.

판독 상태부터 확인

read는 영역의 BarcodeReadView를 빌려 줍니다. 문자열만 읽기 전에 status와 reasons를 확인하면 판독 실패와 사전 조건에 의한 거절을 구분하는 데 도움이 됩니다. 결과 영역의 위치와 형식도 같은 판독에서 함께 확인합니다.
