Finds candidate poses in the source image.

관련 입력의 확인된 조건

Extended appearance matching model.

호출 맥락과 결과 해석

확장 NCC 모델을 검색 영상에 적용합니다. ExtendedMatchOptions에서 위치·각도·배율을 각각 명시된 격자로 지정하며 위치는 검색 ROI 로컬 픽셀, 각도는 라디안입니다. 모델 학습 때 지정한 템플릿 로컬 기준점이 검출 포즈를 해석하는 기준입니다.

검색 결과의 매치 목록과 종료 진단을 함께 확인합니다. 격자가 넓거나 촘촘하면 평가할 후보가 늘어나므로 candidate_budget과 실제 평가 상태를 함께 기록합니다. 마스크를 사용하는 경우 검색 대상 영상에 맞는 마스크를 전달합니다.

격자와 결과 해석

ExtendedMatchOptions의 x와 y는 검색 ROI 로컬 기준점 위치, angle은 라디안, scale_x와 scale_y는 축별 배율입니다. 각 축의 min·max·step으로 후보가 만들어집니다. 예를 들어 x가 0부터 4까지 간격 2이면 x 후보는 0,2,4입니다.

min_score와 min_coverage는 후보 수락 조건이고 candidate_budget은 평가할 포즈의 상한입니다. max_matches는 반환 수 상한이므로 예산과 다릅니다. 반환 결과의 matches, evaluated, termination을 함께 읽으면 빈 결과와 예산으로 일찍 끝난 검색을 구분하는 데 도움이 됩니다.
