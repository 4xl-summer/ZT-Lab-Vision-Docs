pub fn general_dft( &self, width: usize, height: usize, normalization: FftNormalization, ) -> ZResult<GeneralSpectrum>

Computes an arbitrary-size DFT with explicit padding and normalization.

호출에 필요한 입력

임의 크기의 제한된 일반 DFT를 계산합니다.

인자선언된 형식확인할 내용
widthusize양의 변환 폭; 변환 크기는 입력 이상
heightusize양의 변환 높이; 폭×높이 ≤ 1,048,576, 폭×높이×(폭+높이) ≤ 25,000,000
normalizationFftNormalization정규화 방식, 기본값 BACKWARD

normalization의 입력 값

필드의미와 조건
BACKWARD순변환은 배율 1, 역변환은 1/N입니다.
ORTHONORMAL순·역변환 각각 1/√N 배율입니다.

결과와 사용 순서

반환 선언 ZResult<GeneralSpectrum>의 성공 값과 오류를 분기해 처리합니다. 호출이 실패하면 성공 값의 내용이나 출력 영상이 생성되었다고 가정하지 마세요.

입력과 결과 해석

변환 결과의 계수는 공간 영상의 원래 픽셀과 다른 표현입니다. 변환 설정과 정규화 방식을 역변환에 맞추고, 계수를 수정하지 않은 왕복과 수정한 결과를 따로 확인하세요.
