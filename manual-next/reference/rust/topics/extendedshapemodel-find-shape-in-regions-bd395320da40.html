pub fn find_shape_in_regions( &self, source: &ZImage, options: &ShapeSearchOptions, mask: Option<&ZImage>, anchor: [f64; 4], region: [f64; 4], require_full: bool, max_outside: f64, ) -> ZResult<ExtendedMatchResult>

Executes the existing find_shape_in_regions search variant and preserves its report.

관련 입력의 확인된 조건

Extended shape matching model.

호출 맥락과 결과 해석

anchor 사각형은 모델 기준점에 적용되고 region 사각형은 변환된 모델에 적용됩니다. 두 영역은 서로 다른 대상을 제한하므로 같은 사각형을 주더라도 기준점만 허용하는 것과 모델 전체의 영역 관계를 요구하는 것은 다른 조건입니다.

max_outside는 영역 밖에 허용하는 비율이며 0부터 1까지입니다. require_full의 전체 포함 요구와 함께 설정해 의도한 허용 범위를 표현합니다. 먼저 제약 없이 검색해 후보 포즈를 확인한 다음 영역 조건을 적용해 차이를 비교하면 좌표나 영역 설정 오류를 찾기 쉽습니다.

기준점과 모델 영역 구분

anchor는 모델 기준점의 허용 사각형이고 region은 변환된 모델과 비교하는 사각형입니다. require_full과 max_outside로 영역 관계를 제한하며 max_outside는 0부터 1까지의 비율입니다. 기준점이 사각형 안에 있다는 사실만으로 모델 전체가 그 안에 들어간 것은 아닙니다.

사용할 때의 판독

예를 들어 모델의 기준점이 작업 영역 내부에 있어도 큰 모델의 한쪽 끝은 영역 밖으로 나갈 수 있습니다. 전체 포함을 요구하는지와 바깥 비율 허용치를 명시하고 결과의 포즈를 영역 위에 그려 검증하세요. 선택 마스크도 함께 쓰는 경우 검색 픽셀 제한과 영역 제약을 각각 추적해야 합니다.
