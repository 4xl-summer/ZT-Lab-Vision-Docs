pub trait IntoQuery: Sized { type Target; // Required method fn into_query(self) -> Self::Target; }

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

연결과 소유권

Facade의 지연 계획을 기반 Query 엔진 표현으로 이전할 때 사용하는 트레이트입니다. ImageQuery와 BlobQuery 등은 각자 대응하는 Target을 정의하므로 반환 타입은 호출한 계획에 따라 달라집니다. 이 트레이트를 통해 변환하는 시점에 이미지 처리나 Blob 검사가 수행되는 것은 아닙니다.

메서드는 self를 소비합니다. 예를 들어 ImageQuery를 엔진 계획으로 넘긴 다음에는 기존 facade 계획 이름을 다시 사용할 수 없습니다. 별도 분기에서 facade 계획을 유지해야 한다면 변환 전에 명시적으로 clone하는 방법을 검토하십시오. 계획의 실행 결과와 캡처는 실제 execute 또는 엔진 실행 뒤에 확인해야 합니다.

이전된 계획의 입력 저장소와 연산 순서는 기반 엔진의 소유 계약을 따릅니다. 변환이 출력 이미지를 반환하는 것으로 오해하면 실행되지 않은 계획과 계산된 결과를 혼동할 수 있습니다. 트레이트 메서드는 bridge::IntoQuery를 가져와야 사용할 수 있으며, 해당 타입에 구현이 있는지도 함께 확인해야 합니다.
