Rust API · SimPlc in zvision / api-type-simplc

SimPlc in zvision의 rustdoc 공개 선언

공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 SimPlc in zvision입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub type SimPlc = SimPlc;

Legacy PLC name retained through the 0.1.x series.

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.

공개 멤버

    트레이트 구현 멤버

      사용과 결과 해석

      SimPlc는 SimulatedPlc의 이전 Rust 타입 별칭입니다. 신규 코드에는 정식 이름 SimulatedPlc가 권장됩니다. 두 이름은 별개의 PLC 장치나 다른 통신 프로토콜을 선택하는 스위치가 아니라 동일한 시뮬레이터에 대한 이름입니다.

      시뮬레이터에서는 요청, 결과 게시, 확인 같은 명령과 상태 변화를 명시적으로 시험할 수 있습니다. 예를 들어 요청 식별자를 정해 Request를 보낸 후 같은 요청에 Publish와 Ack를 순서대로 적용하면 최종 상태를 확인할 수 있습니다. 시각 인자는 시뮬레이터가 허용하는 순서로 제공해야 하며 상태에 맞지 않는 명령과 정상 적용을 구분합니다.

      명령의 적용 결과와 info의 현재 상태를 함께 확인하면 중복 요청이나 잘못된 순서를 진단하는 데 도움이 됩니다. 다만 이 합성 상태 기계는 실제 PLC의 네트워크, I/O 배선 또는 타이밍 인수를 대신하지 않습니다. 별칭의 deprecated 표기를 확인하고 기존 코드 호환과 신규 이름 사용을 구분하십시오.
