      사용과 결과 해석

      YOLO 형식의 행 단위 점수를 입력 영상의 검출 결과로 디코딩합니다. 각 행에는 상자 정보와 objectness 및 클래스 점수가 있으며, transform은 전처리에서 사용한 크기 조정과 패딩을 원래 입력 좌표에 연결합니다. options는 점수 문턱, 좌표 형식과 NMS를 지정합니다.

      행의 클래스 순서가 모델과 같아야 하며, 모델 좌표를 ROI 또는 전체 영상 좌표로 되돌릴 때는 해당 입력에 맞는 transform이 필요합니다. 예를 들어 letterbox 패딩을 무시하면 상자 위치와 크기가 원본과 어긋날 수 있습니다. 점수 또는 NMS 조건으로 후보가 제거되면 결과가 빈 목록일 수 있습니다.

      반환된 AiDetections는 독립 스냅샷이며 입력 행을 변경하지 않습니다. 이 경로는 준비된 점수 행을 해석하는 것이지 신경망 추론을 실행하지 않습니다. raw logits와 텐서 배치가 다른 모델은 그 표현을 지원하는 별도 경로와 조건을 확인하십시오.
