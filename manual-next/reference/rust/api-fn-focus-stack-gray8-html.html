      사용과 결과 해석

      정렬이 끝난 여러 Gray8 영상에서 위치마다 초점 에너지가 높은 프레임의 픽셀을 선택합니다. 입력은 2~256장의 참조 슬라이스이며 각 영상의 너비, 높이와 원점이 같아야 합니다. 이 함수가 영상을 정합하지 않으므로 입력이 이동해 있다면 합성 전에 정렬을 수행해야 합니다.

      각 후보 프레임에서 해당 위치 주변 3×3 영역의 네 이웃 라플라시안 제곱합을 비교합니다. 경계 밖 샘플은 가장자리 값을 복제합니다. 점수가 완전히 같으면 첫 번째 프레임이 선택되므로 입력 순서가 동점 결과에 영향을 줍니다. 출력 영상은 선택된 프레임의 해당 픽셀이고, 별도 Gray8 인덱스 영상은 선택된 0부터 시작하는 프레임 번호를 기록합니다.

      결과 객체에서 fused_image와 index_map을 각각 획득할 수 있으며 각 영상은 독립 소유 공유로 결과 객체 이후에도 유지할 수 있습니다. 잘못된 프레임 수, 형식, 크기 또는 원점은 오류입니다. 에너지가 크다는 것은 이 지표에서 국소 변화가 크다는 뜻이며, 실제 광학 초점의 정확도를 보장하지 않으므로 합성 장면과 실제 촬영을 구분해 검증하십시오.
