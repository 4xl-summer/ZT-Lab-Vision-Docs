공개 선언

기본 기능으로 빌드한 Rust 문서에서 확인한 Expr in zvision입니다. 소스 내부 모듈명은 공개 경로라는 뜻이 아닙니다.

Rust
pub enum Expr { Int(i128), Float(f64), Bool(bool), Field(BlobField), Unary(UnaryOp, Box<Expr>), Binary(BinaryOp, Box<Expr>, Box<Expr>), }

An owned, restricted expression over Blob measurements. Validation visits both Boolean operands even if evaluation will short-circuit. Trees are limited to depth 64 (the root is depth 1) and 4096 nodes. These limits apply to validation and evaluation, not to construction, cloning, or recursive destruction of caller-created trees. This is not an untrusted expression parser. Integer division truncates toward zero. Floating-point literals, accessed fields, and results must be finite, and division by either signed zero fails. use zvision_core::ZRect; use zvision_ops::Blob; use zvision_query::{BinaryOp, BlobField, Expr, Value}; let blob = Blob { area: 10, bounds: ZRect::new(0, 0, 2, 5), centroid: (0.5, 2.0) }; let expr = Expr::Binary(BinaryOp::Gt, Box::new(Expr::Field(BlobField::Area)), Box::new(Expr::Int(5))); assert_eq!(expr.evaluate(&blob).unwrap(), Value::Bool(true));

다른 기능 조합의 공개 범위는 별도 확인이 필요합니다. 설명에 없는 인자 제약, 오류와 장치 조건은 미확인입니다.
