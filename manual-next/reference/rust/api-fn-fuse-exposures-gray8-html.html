      사용과 결과 해석

      서로 정렬된 Gray8 영상과 각 영상에 대응하는 노출값으로 상대 방사량 영상을 계산합니다. 2~256장의 입력이 필요하고 노출 배열의 길이는 영상 수와 같아야 합니다. 모든 노출값은 유한한 양수이며 영상들은 크기와 원점이 같아야 합니다. 기하 정합은 이 함수의 입력 전제이므로 다른 위치를 같은 픽셀로 합치지 않도록 먼저 확인해야 합니다.

      각 픽셀 값 p에 대해 가중치로 min(p, 255−p)를 사용하고, 유효 노출들의 가중 p/노출값 평균을 만듭니다. 0과 255는 가중치가 0이므로 기여하지 않습니다. 예를 들어 두 유효 영상의 값이 각각 50과 100이고 노출값이 1과 2라면 두 p/노출값이 모두 50이어서 합성 상대 방사량도 50입니다.

      모든 입력이 해당 위치에서 0 또는 255라면 상대 방사량은 0이고 유효 마스크도 0입니다. 하나라도 기여하면 마스크는 255입니다. 결과의 radiance는 GrayF32, validity는 Gray8이며 각 접근자로 독립 소유 공유를 획득합니다. 이 계산은 선형 상대값 모델이지 카메라 응답 보정이나 톤 매핑을 수행하는 교정 모델이 아닙니다.
