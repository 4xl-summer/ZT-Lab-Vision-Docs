      사용과 결과 해석

      OCR 엔진에 전달할 모델 파일을 경로에서 제한된 크기의 바이트 벡터로 읽습니다. 경로는 AsRef<Path>로 받을 수 있는 파일 경로이며 성공 시 소유 Vec를 반환합니다. 이 함수는 모델을 추론하거나 이미지의 문자를 인식하지 않습니다.

      읽은 바이트를 OcrEngine::from_bytes에 전달하는 단계에서 해당 엔진이 모델을 받아들일 수 있는지 별도로 확인합니다. 파일이 있다는 것만으로 형식, 내용이나 인식 품질이 검증되는 것은 아닙니다. 실제 모델은 호출자가 준비해야 하며 예제의 합성 글꼴 학습과 구분해야 합니다.

      읽기 또는 크기 제한, 파일 접근 오류는 ImageIoResult의 오류로 전달됩니다. 경로가 사용자 환경에 맞는지 확인하고 오류를 빈 모델 바이트로 바꾸지 마십시오. 민감한 경로나 실제 모델 내용은 문서 출력에 포함할 필요가 없습니다.
