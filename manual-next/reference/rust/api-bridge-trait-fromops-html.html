연결과 소유권

기존 Ops 표현을 facade 모델 또는 결과 객체에 이전할 때 쓰는 명시적 트레이트입니다. Target은 구현마다 다르며 메서드는 Target 값을 받아 해당 facade 값을 만듭니다. 직접 Ops 모델을 보유한 기존 코드에서 facade가 제공하는 API를 사용하려는 경우가 대표적인 경계입니다.

MatchModel은 학습된 Ops 매칭 모델을 감싸는 구현을 제공합니다. 따라서 모델을 먼저 학습했는지, 사용하는 검색 설정과 입력 영상의 형식이 적합한지는 변환과 별도로 판단해야 합니다. 변환은 학습 호출이나 검색 실행을 대신하지 않으며 이 메서드 자체가 검출 결과를 반환하지도 않습니다.

이 값은 소유권을 이동하므로 변환 후 기존 Ops 변수는 사용할 수 없습니다. 트레이트 메서드를 호출하는 파일에서는 bridge::FromOps를 스코프에 둡니다. facade로 감싼 뒤 생성되는 결과의 수명과 읽기 API는 구체 모델 계약을 따르므로, 모든 Ops 객체가 동일한 공유나 복사 방식을 갖는다고 가정하지 마십시오.
