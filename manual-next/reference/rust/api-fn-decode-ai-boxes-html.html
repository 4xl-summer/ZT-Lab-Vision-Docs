      사용과 결과 해석

      6성분 상자 행을 영상 좌표의 검출 결과로 바꿉니다. rows의 각 행은 상자 좌표, 점수 및 클래스 식별자를 담고 transform은 전처리에서 모델 좌표와 입력 영역을 연결한 정보입니다. options에는 모델 크기, 좌표 표현, 점수 문턱 및 NMS 정책이 들어갑니다.

      좌표가 픽셀인지 정규화 값인지, 모서리 또는 중심 표현인지는 options와 일치해야 합니다. 전처리에서 letterbox 패딩이 있었다면 동일한 transform을 넘겨야 패딩을 제외한 입력 영상 좌표를 복원할 수 있습니다. 점수가 문턱보다 낮은 후보와 NMS에서 제거된 후보는 최종 결과에 나타나지 않습니다.

      반환 AiDetections는 읽기 전용 독립 스냅샷입니다. 이 함수는 모델을 실행하거나 행이 특정 객체라는 사실을 검증하지 않습니다. 모델 출력 형식과 클래스 순서, ROI 좌표를 확인하고 유효하지 않은 값에 대한 오류를 처리하십시오.
