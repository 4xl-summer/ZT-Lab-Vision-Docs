자동 추출한 선언 수와 실제 매뉴얼 완성률을 구분합니다.

이 수치는 API 총 개수가 아니라 실제로 읽은 일부 모듈에서 얻은 메서드 선언 후보 수입니다. Cargo feature, 외부 pub use, Rust 매크로, C# 추가 partial 파일, Python 모듈 재수출을 모두 포함하지 않아 문서 완성률의 분모로 사용할 수 없습니다.

완료로 선언할 수 없는 항목

  • Rust 공개 re-export와 모든 Wrapper의 공개 항목 전수 감사
  • 언어별 실제 설치·빌드·실행 샘플의 CI 검증
  • 상용 매뉴얼 로컬 W:\Source\Vision-Manuals 파일 직접 분석
  • 생산·실장비 정확도와 성능·GPU 검증
  • HTML 직접 링크와 실제 브라우저 접근성·배포 완료 확인

문서 완성의 인수 조건

공개 API별 입력·출력·오류·수명·단위·지원 형식·예제가 실제 코드/테스트와 일치하고, 주제별 HTML 링크·검색·브라우저 표시가 동작해야 합니다. 검증하지 못한 부분은 별도 상태로 유지합니다.
