C# · ROI 기반 임계값 검사

C#의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

C#

C#
using System;
using ZVision;
using var image = ZImage.FromGray8(3, 1, new byte[] {9, 10, 11});
using var roi = image.Roi(1, 0, 2, 1);
using var result = roi.Threshold(11.0);
Console.WriteLine(string.Join(",", result.ToArrayGray8()));

C# · 핵심 동작

C# 흐름은 원본을 만들고 Roi로 x=1, 폭 2인 영역을 얻은 뒤 그 ROI에 임계값 11을 적용합니다. 입력 값 [9,10,11]에서 처리되는 부분은 [10,11]이므로 결과는 [0,255]입니다. 임계값과 같은 11이 선택되는 이유는 비교가 크거나 같음이기 때문입니다. 원본의 첫 픽셀 9는 결과 마스크에 포함되지 않습니다.

C# · 입력과 결과

원본과 ROI는 저장소를 공유할 수 있지만 서로 관리해야 하는 핸들입니다. 임계값 결과는 입력을 변경하지 않는 별도 영상이며, 예제에서는 각각 using으로 정리합니다. 복사된 Gray8 배열은 관리형 값으로서 영상 핸들과 수명이 다릅니다. 이미 닫힌 핸들에 연산을 다시 호출하는 것과, 이미 복사해 둔 배열을 읽는 것은 구별해야 합니다.

C# · 좌표와 소유권

ROI의 원점 (1,0)은 결과 위치를 전체 영상에 맞추는 기준입니다. 로컬 x=1인 전경은 전역 x=2에 해당합니다. 단순히 결과의 배열 인덱스를 원본 좌표로 사용하면 한 픽셀 왼쪽에 표시됩니다. ROI 원점을 더할 때는 결과가 이미 전역 좌표인지 다시 확인해 중복 이동을 피하십시오.

C# · 오류와 판단

입력 사각형이 유효하지 않으면 예외를 처리하고, 정상 출력이 [0,0]인 상황과 구분하십시오. 합성 배열이 성공했다고 해서 장비의 위치 오차나 결함 검출률이 검증되는 것은 아닙니다.
