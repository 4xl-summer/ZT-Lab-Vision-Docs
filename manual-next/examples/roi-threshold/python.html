Python · ROI 기반 임계값 검사

Python의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

Python

Python
from zvision import ZImage
with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as image:
    with image.roi(1, 0, 2, 1) as roi:
        with roi.threshold(11.0) as result:
            assert result.to_array_gray8() == bytes([0, 255])

Python · 핵심 동작

Python에서는 with를 중첩해 원본 영상, ROI, 임계값 마스크의 각 수명을 명시합니다. 합성 입력 [9,10,11]에서 (1,0,2,1) ROI는 [10,11]입니다. T=11이면 10은 배경이고 11은 경계에 포함되어 결과는 [0,255]입니다. 비교 단위는 Gray8 입력의 픽셀 값과 같으며 0–1 확률이 아닙니다.

Python · 입력과 결과

ROI는 원본 저장소를 공유하지만 별도로 닫는 핸들입니다. 임계값 마스크는 독립적으로 소유하는 새 영상이므로 동일한 with 범위 안에서 검사하고 닫는 방식이 이해하기 쉽습니다. to_array_gray8()은 bytes 복사본을 제공하므로 기대값을 bytes([0,255])와 비교하거나 명시적으로 list로 변환하십시오.

Python · 좌표와 소유권

원점이 (1,0)인 ROI에서 로컬 (1,0)은 전체 영상의 (2,0)입니다. 반환 배열에는 원점이 자동으로 좌표 값에 삽입되지 않으므로 위치 계산 시 원점 정보를 별도로 확인해야 합니다. 결과가 한 칸 밀렸다면 x 인덱스를 전역 좌표로 바로 사용했는지 점검합니다.

Python · 오류와 판단

잘못된 ROI나 닫힌 영상 접근은 예외이고, 유효한 분할에서 전경이 없는 것은 빈 마스크입니다. 이 둘을 하나의 결과로 처리하지 않아야 입력 오류를 찾을 수 있습니다. 실제 촬영 영상에서는 ROI 안에 검출 대상 전체가 포함되는지도 따로 확인합니다.
