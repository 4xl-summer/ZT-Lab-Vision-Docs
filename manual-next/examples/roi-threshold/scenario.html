검사 목적과 입력 · ROI 기반 임계값 검사

검사 목적과 입력의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

검사 목적과 입력

3×1 Gray8 [9,10,11]에서 ROI (x=1,y=0,width=2,height=1)를 선택합니다. ROI는 [10,11], 원점은 (1,0)입니다. 임계값 11 이상을 255로 바꾸면 결과는 [0,255]입니다. 크기와 좌표는 로컬 픽셀 단위이며 ROI의 우측 끝은 포함하지 않습니다.

검사 목적과 입력 · 핵심 동작

이 합성 검사는 전체 영상을 복사해 잘라 내기보다, 관심 영역을 선택한 후 그 영역만 분할하는 순서를 보여 줍니다. 원본은 3×1 Gray8 [9,10,11]이며 ROI의 시작은 (1,0), 크기는 2×1입니다. 따라서 ROI의 보이는 값은 [10,11]이고 원점은 (1,0)입니다. 이 입력은 전체 좌표와 로컬 좌표가 달라지는 상황을 일부러 만듭니다.

검사 목적과 입력 · 입력과 결과

선택 영역의 로컬 좌표 (0,0)은 원본의 (1,0)에 해당합니다. T=11의 비교는 경계 포함이므로 ROI의 첫 값 10은 0, 둘째 값 11은 255입니다. 이 경우 원본의 9는 ROI 밖이므로 결과 마스크에 세 번째 값으로 나타나지 않습니다. 출력 크기는 전체 원본의 3×1이 아니라 처리된 ROI의 2×1입니다.

검사 목적과 입력 · 좌표와 소유권

ROI는 원본 저장소를 공유하는 뷰이고 임계값 결과는 새 소유 영상입니다. 따라서 결과에 대한 위치를 원본 위에 표시할 때는 결과의 원점을 고려해야 합니다. 마스크의 로컬 1번째 픽셀은 전역 x=2에 대응하며, 그 위치에 한 번 더 원점을 적용하면 실제보다 오른쪽으로 이동합니다.

검사 목적과 입력 · 오류와 판단

이 예제는 비교 및 좌표 계약을 검증하는 합성 데이터입니다. ROI가 영상 범위를 벗어나거나 크기가 0이면 입력 오류이며 빈 마스크와 구분해야 합니다. 실제 대상이 ROI 경계에 걸리면 바깥 부분은 이 예제의 처리에 포함되지 않으므로 검출 영역을 선정할 때 여유를 확인하십시오.
