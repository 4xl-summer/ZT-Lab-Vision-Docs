관련 API · 핵심 동작

관심 영역을 처리하는 흐름은 입력 생성, ROI 선택, 임계값, 결과 확인 순서로 구성할 수 있습니다. Rust의 ZRect, C#의 Roi, Python의 roi는 문법이 다르지만 이 예제에서 선택하는 사각형은 동일합니다. 호출 언어별 형식과 소유권은 해당 API 설명을 따라야 합니다.

관련 API · 입력과 결과

threshold는 각 픽셀을 T 이상인지 비교해 Gray8 마스크를 만듭니다. 이후 객체가 필요하다면 마스크에 연결 성분 분석을 적용할 수 있습니다. 마스크의 원점이 유지되더라도 Blob 경계와 중심이 ROI 로컬로 반환되는 API가 있으므로, 그 결과가 이미 전역인지 확인한 후 원점을 더하십시오.

관련 API · 좌표와 소유권

독립 보관이 필요한 경우 공유 ROI와 깊은 복사의 차이를 이해해야 합니다. ROI 선택은 사용 범위를 좁히지만 자체가 픽셀 분할 결과는 아닙니다. 반면 임계값 결과는 별도 영상이고, 언어별 배열 복사 API는 그 영상의 보이는 픽셀을 새 배열로 옮깁니다.

관련 API · 오류와 판단

정상 출력 [0,255]와 ROI 경계 오류는 서로 다른 경우입니다. 파이프라인에서는 원본 형식, 선택 사각형, 임계값, 반환 크기와 원점을 기록하면 처리 결과를 재현하기 쉽습니다.

관심 영역의 경계와 출력 좌표의 기준을 함께 기록하면 원본 영상 위에 결과를 다시 표시할 때 도움이 된다. 임계값 변경과 영역 위치 변경은 서로 다른 효과를 내므로 별도로 시험한다.
