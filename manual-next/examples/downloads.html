아래 프로젝트에는 합성 입력을 만드는 코드와 독립 기대값 검사가 포함됩니다. SDK 소스와 네이티브 라이브러리는 별도로 준비하세요. 프로젝트는 SDK 리비전 ce902e85c3405eb63df40c699ddbdf70ee1d03bd를 기준으로 합니다. 압축을 푼 뒤 각 README의 환경 설정과 실행 순서를 따르세요.

동일한 결과를 재현하는 순서

  1. SDK 소스를 지정 리비전으로 준비하고 --locked로 Release 네이티브를 빌드합니다.
  2. 언어별 프로젝트를 풀고 README에 따라 SDK 경로와 네이티브 로더 환경을 설정합니다.
  3. AI 예제를 실행할 때는 모델 묶음을 함께 풀고 ZVISION_MANUAL_MODELS를 설정합니다.
  4. 프로그램이 끝까지 성공하고 JSON 결과가 출력되는지 확인합니다. 실패하면 최초 오류와 런타임·아키텍처·SDK 리비전을 함께 확인합니다.

Rust는 Cargo.lock을 유지하세요. 새 의존성을 자동 선택하면 SDK에서 검증하지 않은 RTen 버전을 선택할 수 있습니다. 관리형 래퍼와 네이티브를 서로 다른 SDK 빌드에서 섞지 마세요.

포함 데이터와 한계

이미지는 코드로 생성하며 생산 데이터가 아닙니다. AI 그래프는 이 매뉴얼용으로 새로 만든 결정론적 입출력 예제입니다. 학습 모델이나 검출 정확도 평가 자료가 아니며, 분류·검출·분할·이상 점수의 형식과 후처리 연결을 확인합니다. OCR은 코드로 만든 단일 글리프를 학습합니다. Modbus는 로컬 루프백 상대와 통신하며 실제 PLC의 응답·타이밍을 입증하지 않습니다.
