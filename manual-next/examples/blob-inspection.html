작은 Blob 검사 · 3×1 마스크

세 픽셀의 단순한 입력으로 Threshold와 4-연결 Blob 분석의 면적을 확인합니다.

검사할 입력

검출할 후보가 두 픽셀 이어져 있는 3×1 Gray8 이미지 [0,5,5]를 사용합니다. 임계값 1을 적용하면 [0,255,255]가 되고, 4-연결 Blob 하나의 면적은 2픽셀입니다.

입력0, 5, 5
→
Threshold(1)0, 255, 255
→
FindBlobs(4)면적 2, 1개

Rust 전체 예제

Rust
use zvision::{Connectivity, ZImage};

fn main() -> zvision::ZResult<()> {
    let image = ZImage::from_vec_gray8(3, 1, vec![0, 5, 5])?;
    let plan = image.query()?.threshold(1)?.find_blobs(Connectivity::Four);
    let run = plan.execute()?;
    assert_eq!(run.output().blobs().len(), 1);
    assert_eq!(run.output().blobs()[0].area, 2);
    Ok(())
}

C# 직접 호출

C#
using ZVision;

using var image = ZImage.FromGray8(3, 1, new byte[] { 0, 5, 5 });
using var mask = image.Threshold(1.0);
BlobAnalysisResult result = mask.FindBlobs(4);
System.Diagnostics.Debug.Assert(result.Blobs.Count == 1);
System.Diagnostics.Debug.Assert(result.Blobs[0].Area == 2);

Python 직접 호출

Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([0, 5, 5])) as image:
    with image.threshold(1.0) as mask:
        result = mask.find_blobs(connectivity=4)
        assert len(result.blobs) == 1
        assert result.blobs[0].area == 2

연결, 면적과 좌표

전경은 0이 아닌 픽셀입니다. 면적은 픽셀 셀의 개수이고 무게중심은 각 전경 픽셀 좌표의 산술 평균 (Σx/N, Σy/N)입니다. 대각 두 점의 면적은 8연결에서 2, 중심은 (0.5,0.5)입니다.

선택해석
4연결상하좌우 이웃만 이어짐
8연결대각 이웃도 이어짐
면적 필터경계 포함; 단위는 픽셀 수
ROI결과 좌표계와 상위 원점의 관계를 확인하고 합산; 고급 BlobResult는 부모 원점을 보관하지 않음
영역 없음빈 결과는 성공 가능한 검사 결과

픽셀 면적과 윤곽 다각형 면적은 다른 측정량입니다. 교정된 면적은 픽셀 크기 또는 변환에 따라 별도로 계산합니다. 대각 접촉과 경계 절단 객체는 검출 기준을 정해 테스트하십시오.
