Python 직접 호출 · 작은 Blob 검사 · 3×1 마스크

작은 Blob 검사 · 3×1 마스크에서 Python 직접 호출을 이해하기 위한 입력, 동작과 결과 설명

Python 직접 호출

Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([0, 5, 5])) as image:
    with image.threshold(1.0) as mask:
        result = mask.find_blobs(connectivity=4)
        assert len(result.blobs) == 1
        assert result.blobs[0].area == 2

Python 호출은 입력 ZImage를 만든 뒤 threshold로 새 마스크를 만들고 연결 영역을 분석하는 순서입니다. 원본 [0,5,5]에 임계값 1을 적용하면 전경 두 픽셀이 255로 표시됩니다. 같은 행의 인접 픽셀은 4연결에서 하나의 후보가 되므로 Blob 개수 1, 면적 2가 예상됩니다. 입력 배열의 단위가 밝기 값이고 처리 결과 면적의 단위가 픽셀 수라는 차이를 살펴봅니다.

with 또는 close는 Python 객체가 소유한 네이티브 자원의 수명을 명시합니다. 입력을 닫는 것과 이미 얻은 별도 영상 데이터가나 실행 처리 결과를 닫는 것은 각각의 작업입니다. ROI를 사용했다면 Blob의 로컬 위치에 원본의 원점을 무심코 두 번 더하지 않도록 합니다. 배열을 확인할 때 반환 형식도 확인하여 bytes를 정수 목록과 직접 비교하는 실수를 피합니다.

같은 처리에 다른 임계값을 적용하면 전경에 들어가는 픽셀이 달라지므로 예제의 1이라는 숫자도 입력 데이터와 함께 기록해야 합니다.

Python 예제에서는 영상 데이터 객체의 close 시점과 배열 처리 결과의 타입을 함께 살펴봅니다. 같은 전경을 선택해도 bytes와 정수 목록은 직접 비교에서 다를 수 있습니다. 목록 형태가 필요하면 반환 형식에 맞게 명시적으로 변환합니다.

Python에서 입력과 결과를 분리

Python 예제는 먼저 길이 3의 Gray8 입력을 만든 뒤 임계값 처리로 새 영상을 얻습니다. 원본의 [0,5,5]에 임계값 1을 적용하면 오른쪽 두 픽셀이 전경이므로 마스크의 내용은 [0,255,255]입니다. 이 마스크에서 4연결 Blob 분석을 수행하면 영역은 하나이고 픽셀 면적은 2입니다. 입력의 밝기 배열과 처리 결과를 서로 다른 영상으로 놓고 단계별 값을 비교합니다.

원본과 결과 영상은 각각 소유 객체이므로 예제의 with 또는 close 범위를 지켜야 합니다. 배열로 읽은 값이 Python에서 bytes로 반환되는 경우 정수 리스트와 직접 비교하면 원소가 같아도 타입 때문에 비교 결과가 다를 수 있습니다. 예제 기대값을 검사할 때는 같은 형식의 bytes로 비교하거나 명시적으로 리스트로 변환합니다.

Blob 위치는 분석한 영상의 로컬 좌표입니다. 예제의 전경 중심은 (1.5,0)이며, ROI가 있는 다른 사례에서는 현재 뷰의 origin을 고려해야 부모 영상에서의 위치를 구할 수 있습니다. 연결 방식이나 임계값을 바꾸면 이 수치는 예제의 기대값과 달라질 수 있으므로 사용 조건을 함께 보관합니다.
