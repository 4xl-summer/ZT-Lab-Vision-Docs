Rust 전체 예제 · 작은 Blob 검사 · 3×1 마스크

작은 Blob 검사 · 3×1 마스크에서 Rust 전체 예제을 이해하기 위한 입력, 동작과 결과 설명

상위 목차로 돌아가기

Rust 전체 예제

Rust
use zvision::{Connectivity, ZImage};

fn main() -> zvision::ZResult<()> {
    let image = ZImage::from_vec_gray8(3, 1, vec![0, 5, 5])?;
    let plan = image.query()?.threshold(1)?.find_blobs(Connectivity::Four);
    let run = plan.execute()?;
    assert_eq!(run.output().blobs().len(), 1);
    assert_eq!(run.output().blobs()[0].area, 2);
    Ok(())
}

Rust 예제에서는 Gray8 픽셀 배열로 입력 영상 데이터를 만든 다음 임계값 처리 처리 결과를 연결 요소 분석에 전달합니다. 임계값 1을 적용한 [0,5,5]의 마스크는 [0,255,255]이며 인접한 전경 두 개가 하나의 영역을 만듭니다. 반환된 후보의 면적이 2인지 확인하는 것은 영상 데이터 처리뿐 아니라 선택한 연결 방식과 영역 해석을 함께 확인하는 과정입니다.

Rust에서는 소유 값의 범위가 끝나면 자원이 정리되고, 지연 Query를 구성할 때는 작업을 추가하는 과정에서 계획의 소유권이 이동할 수 있습니다. 즉시 실행 처리 결과와 Query 계획을 혼동하지 말고 예제의 호출 순서를 따릅니다. 처리 결과에 담긴 픽셀 면적은 카메라 보정이 적용된 물리 면적이 아닙니다. 이 작은 합성 사례를 검증한 다음 실제 영상 데이터의 형식과 조명 조건에 맞추어 임계값을 정해야 합니다.

ROI 입력의 경우 후보 위치가 현재 뷰의 로컬 좌표인지 확인하고, 부모 영상 데이터 좌표가 필요할 때 원점을 고려합니다.

Rust 예제에서는 정수 배열을 영상 데이터 생성에 전달한 후 처리 결과 마스크를 읽습니다. 실행 실패는 처리 결과가 없는 것과 구분하며, ROI를 사용하면 반환 좌표와 부모 원점의 관계를 살펴봅니다. 합성 픽셀의 면적은 물리 단위로 자동 변환되지 않습니다.
