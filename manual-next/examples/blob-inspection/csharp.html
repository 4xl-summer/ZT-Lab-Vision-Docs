C# 직접 호출 · 작은 Blob 검사 · 3×1 마스크

작은 Blob 검사 · 3×1 마스크에서 C# 직접 호출을 이해하기 위한 입력, 동작과 결과 설명

상위 목차로 돌아가기

C# 직접 호출

C#
using ZVision;

using var image = ZImage.FromGray8(3, 1, new byte[] { 0, 5, 5 });
using var mask = image.Threshold(1.0);
BlobAnalysisResult result = mask.FindBlobs(4);
System.Diagnostics.Debug.Assert(result.Blobs.Count == 1);
System.Diagnostics.Debug.Assert(result.Blobs[0].Area == 2);

C#에서는 입력과 처리 처리 결과가 각각 소유 영상 데이터가므로 예제처럼 using 범위에 두고 처리합니다. 세 픽셀 입력 [0,5,5]에 임계값 1을 적용하면 [0,255,255] 마스크가 만들어집니다. 그 뒤 Blob 분석에서 4연결을 선택하면 오른쪽 두 픽셀을 하나의 영역으로 묶고 면적 2를 얻습니다. 원래 밝기와 이진 마스크는 다른 영상 데이터가므로 반환 영상 데이터를 분석 입력으로 전달합니다.

분석 처리 결과의 위치는 현재 영상 데이터의 로컬 좌표이며 원본이 ROI인 경우 부모 원점과 구분해야 합니다. 처리 결과가 없을 때 빈 목록을 처리할 수 있도록 무조건 첫 요소를 읽지 않는 것이 좋습니다. 형식이나 해제 상태가 잘못된 호출은 빈 처리 결과와 별도의 오류입니다. 이 예제는 합성 픽셀의 예상 동작을 설명하며 실제 분석 기준이나 장비 성능을 뜻하지 않습니다.

분석할 마스크가 이미 이진화된 Gray8 영상 데이터인지 확인하면 원래 밝기 영상 데이터의 값을 전경으로 잘못 해석하는 일을 줄일 수 있습니다.

C# 예제에서는 입력과 이진화 처리 결과를 각각 using으로 관리하고 분석 스냅샷을 읽습니다. 전경 영역이 없다면 첫 처리 결과에 접근하기 전에 개수를 확인하며, 마스크의 밝기 값과 후보의 픽셀 면적을 서로 구분합니다.

C# 결과를 단계별로 읽기

C# 코드에서 FromGray8로 만든 입력은 3×1 격자를 소유하고 Threshold는 새 마스크 영상을 반환합니다. 입력 배열 [0,5,5]와 임계값 1을 사용하므로 출력은 [0,255,255]로 해석합니다. 이어지는 Blob 분석은 이 이진 마스크를 읽어 4연결 전경을 묶습니다. 오른쪽 두 픽셀이 수평으로 붙었기 때문에 후보 수는 1이고 Area는 2입니다.

로컬 경계는 시작 (1,0), 너비 2, 높이 1이며 두 픽셀 중심의 평균은 (1.5,0)입니다. 이 값은 화면 확대율이나 카메라 보정이 반영된 세계 좌표가 아닙니다. 같은 영상이 부모 영상의 ROI라면 현재 뷰의 origin을 함께 확인해 표시할 좌표계를 선택합니다. 먼저 후보 개수를 확인하면 빈 결과에서 첫 항목을 무조건 읽는 오류를 피할 수 있습니다.

using은 입력과 임계값 결과 같은 소유 영상을 각 범위의 끝에서 해제합니다. 처리 중 오류가 났을 때도 이미 만든 객체의 범위가 끝나면 정리됩니다. 반환된 값 스냅샷과 새 영상 핸들의 수명은 다를 수 있으므로 다른 예제의 결과를 같은 방식으로 추정하지 말고 해당 API의 반환 타입을 확인합니다.

Threshold[0,255,255]새 전경 마스크
Blob1개, Area 24연결 결과
