검사할 입력 · 작은 Blob 검사 · 3×1 마스크

작은 Blob 검사 · 3×1 마스크에서 검사할 입력을 이해하기 위한 입력, 동작과 결과 설명

상위 목차로 돌아가기

검사할 입력

검출할 후보가 두 픽셀 이어져 있는 3×1 Gray8 이미지 [0,5,5]를 사용합니다. 임계값 1을 적용하면 [0,255,255]가 되고, 4-연결 Blob 하나의 면적은 2픽셀입니다.

입력0, 5, 5
→
Threshold(1)0, 255, 255
→
FindBlobs(4)면적 2, 1개

이 예제는 세 픽셀짜리 Gray8 영상 데이터의 밝기를 이진 전경으로 바꾼 다음 연결 영역을 찾습니다. 입력 배열은 [0,5,5]이고 임계값은 1입니다. 지정한 조건에 맞는 두 픽셀은 255가 되고 나머지는 0이므로 마스크는 [0,255,255]가 됩니다. 이 마스크의 두 전경 픽셀은 좌우로 붙어 있어 4연처리 결과 8연결 모두 하나의 연결 요소를 이룹니다.

이 사례의 면적은 물리 면적이 아니라 전경 픽셀 수이므로 예상 값은 2입니다. 경계와 중심은 현재 영상 데이터의 로컬 픽셀 좌표로 해석합니다. 입력이 ROI라면 부모 영상 데이터에서의 위치를 얻을 때 ROI 원점을 고려해야 합니다. 형식과 임계값, 연결 방식을 바꾸면 처리 결과도 바뀔 수 있으므로 같은 출력이 나오는지만 보지 말고 실제 사용한 조건을 함께 기록합니다.

대각선 전경을 별도 실험으로 추가하면 같은 전경 수에서도 연결 규칙에 따라 후보 개수가 달라진다는 점을 확인할 수 있습니다.

임계값으로 만들어진 마스크를 눈으로 읽으면 어느 픽셀이 연결 요소의 전경으로 참여하는지 알 수 있습니다. 밝기 값 자체와 이진 전경의 값을 혼동하지 마세요.

세 픽셀을 직접 계산

입력의 인덱스를 왼쪽부터 x=0, 1, 2로 놓으면 값은 각각 0, 5, 5입니다. 임계값 1을 적용한 마스크는 x=0에서 0, 나머지 두 위치에서 255가 됩니다. 두 전경 픽셀은 같은 행에서 좌우로 이웃하므로 4연결로 분석할 때 하나의 요소입니다. 8연결에서도 이 쌍은 이미 직접 이웃이므로 역시 하나입니다.

후보의 전경 픽셀 수는 2이며 로컬 경계는 x=1부터 시작해 폭 2, y=0에서 높이 1입니다. 픽셀 중심 x 값의 평균은 (1+2)/2=1.5이고 y 값은 0입니다. 이러한 수치는 이 3×1 합성 입력을 기준으로 한 것입니다. 다른 전경 모양에서는 경계 사각형 안에 배경이 있을 수 있으므로 사각형 넓이와 후보 면적을 무조건 같은 값으로 사용하지 않습니다.

입력을 처리할 때 영상 생성의 크기와 배열 길이가 맞는지 확인한 뒤 임계값 결과를 분석합니다. 임계값 결과는 원본이 아니고 별도의 마스크 영상입니다. 원본 또는 마스크가 ROI라면 결과의 로컬 경계를 어떤 뷰에 표시하는지와 부모 origin을 같이 기록해야 합니다.
