차분 기반 점 결함 검사 · 3×1

기준 이미지와 검사 이미지의 차이가 있는 한 픽셀을 AbsDiff와 Threshold로 분리합니다.

소주제별 독립 HTML2026-11-08 소스 확인예제 실행 재검증 대기

세 픽셀의 기준 영상

정상 기준 [10,10,10]과 검사 영상 [10,70,10]을 비교합니다. 절대 차분은 [0,60,0]이고 임계값 25에서 가운데 픽셀만 255가 됩니다. 조명·정렬 문제가 없는 작은 합성 검사입니다.

기준/현재10,10,10 / 10,70,10
→
AbsDiff0,60,0
→
Threshold(25)0,255,0

Rust 검사 예제

Rust
use zvision::ZImage;

fn main() -> zvision::ZResult<()> {
    let reference = ZImage::from_vec_gray8(3, 1, vec![10, 10, 10])?;
    let current = ZImage::from_vec_gray8(3, 1, vec![10, 70, 10])?;
    let difference = current.abs_diff(&reference)?;
    let mask = difference.threshold(25.0)?;
    assert_eq!(difference.to_packed_vec()?, vec![0, 60, 0]);
    assert_eq!(mask.to_packed_vec()?, vec![0, 255, 0]);
    Ok(())
}

C# 검사 예제

C#
using System;
using ZVision;

using var reference = ZImage.FromGray8(3, 1, new byte[] { 10, 10, 10 });
using var current = ZImage.FromGray8(3, 1, new byte[] { 10, 70, 10 });
using var difference = current.AbsDiff(reference);
using var mask = difference.Threshold(25.0);
Console.WriteLine(string.Join(",", mask.ToArrayGray8())); // 0,255,0

산업용 검사로 확장할 때

  • 차분 전 기준과 현재 이미지의 픽셀 위치를 정렬합니다.
  • 조명·노출 차이가 실제 결함과 혼동되지 않도록 검증합니다.
  • 마스크를 Blob 분석에 연결하여 크기/면적 조건을 적용할 수 있습니다.
  • 미세 점을 찾는 목적이라면 전처리로 결함 자체를 지우지 않는지 확인합니다.
!입력/결과 수치는 산술적으로 계산한 합성 사례입니다. 실제 카메라 영상의 정렬, 잡음, 노출 변동에 대한 합격 판정 결과가 아닙니다.
