합성 예제와 독립 기대값 · NCC 검색 예제

합성 예제와 독립 기대값에 대한 NCC 검색 예제 사용 안내

상위 목차로 돌아가기

합성 예제와 독립 기대값

템플릿은 3×2 [3,17,1,8,2,25], 검색 영상은 4×2 [0,3,17,1,0,8,2,25]입니다. 0도, 배율 1에서 동일한 패턴은 좌상단 (1,0)에 있으며 기준점은 (2,0.5)입니다. 원점이 (0,0)이므로 전역 좌표도 같습니다. 기대 결과는 하나, 점수 약 1, 표본 6개입니다. 부동소수점 점수는 허용 오차로 비교하세요. 이 합성 예는 실장비 성능을 뜻하지 않습니다.

Rust
use zvision::{MatchModel, MatchSpec, ZImage};
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let template = ZImage::from_vec_gray8(3, 2, vec![3,17,1,8,2,25])?;
    let source = ZImage::from_vec_gray8(4, 2, vec![0,3,17,1,0,8,2,25])?;
    let model = MatchModel::train_ncc(&template, None)?;
    let spec = MatchSpec { angle_min: 0.0, angle_max: 0.0, angle_step: 1.0,
        scale_min: 1.0, scale_max: 1.0, scale_step: 1.0,
        min_score: 0.99, min_distance: 0.0, max_matches: 1 };
    let result = model.find(&source, &spec)?;
    if let Some(m) = result.best() { println!("({}, {}): {}", m.position.x, m.position.y, m.score); }
    Ok(())
}
C#
using System;
using ZVision;
using var template = ZImage.FromGray8(3, 2, new byte[] {3,17,1,8,2,25});
using var source = ZImage.FromGray8(4, 2, new byte[] {0,3,17,1,0,8,2,25});
using var model = MatchModel.TrainNcc(template);
var spec = new MatchSpec(0, 0, 1, 1, 1, 1, 0.99, 0, 1);
MatchResult result = model.Find(source, spec);
if (result.Best is Match m)
    Console.WriteLine($"({m.Position.X}, {m.Position.Y}): {m.Score}");
Python
from zvision import ZImage, MatchModel, MatchSpec
with ZImage.from_gray8(3, 2, bytes([3,17,1,8,2,25])) as template, \
     ZImage.from_gray8(4, 2, bytes([0,3,17,1,0,8,2,25])) as source:
    with MatchModel.train_ncc(template) as model:
        spec = MatchSpec(0, 0, 1, 1, 1, 1, 0.99, 0, 1)
        result = model.find(source, spec)
if result.best is not None:
    print(result.best.position, result.best.score)

적용 상황과 원리

합성 템플릿의 두 행은 각각 3,17,1과 8,2,25입니다. 검색 영상에서는 각 행 앞에 0이 하나 추가되어 있습니다. 따라서 완전히 같은 패턴은 영상의 두 번째 열에서 시작합니다. 검색 좌상단은 1,0이고 템플릿 기준점은 1,0.5이므로 반환 위치는 2,0.5입니다. 높이가 짝수라 중심이 두 행의 중간에 위치합니다.

결과를 읽는 방법

세 언어의 코드는 동일한 배열과 자세 설정을 사용하지만 소유한 객체를 정리하는 방법이 다릅니다. Rust는 소유 값을 범위에 따라 정리하고 C#은 using, Python은 with를 사용합니다. 검색 결과가 없는 경우를 먼저 분기하며, 이 사례에서는 비상수인 동일 패턴이므로 점수는 1에 가깝고 표본은 6개입니다. 코드 실행 결과에서 점수를 비교할 때 실수 오차를 허용합니다. 이 데이터는 실제 카메라 영상이 아니라 좌표를 손으로 확인하기 위한 사례입니다.

추가 점검

입력에서 패턴의 행이 한 열씩 오른쪽에 시작한다는 사실을 확인한 다음 기준점의 반 픽셀 y를 더합니다. 코드가 출력한 좌표를 다시 기대값으로 삼지 않으므로 중심과 좌상단을 바꿔 반환하는 회귀도 이 검산으로 구별할 수 있습니다. 모델 중심이 정수 좌표인 축과 반 픽셀인 축을 개별적으로 계산하는 습관이 중요합니다.

수작업 좌표 검산

조건확인할 내용
템플릿 기준점(3−1)/2, (2−1)/2 = (1, 0.5)
패턴 왼쪽 위검색 영상 로컬 (1, 0)
반환 기준점(1, 0) + (1, 0.5) = (2, 0.5)
