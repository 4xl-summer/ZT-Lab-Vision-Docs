정규화 상관으로 포즈 찾기

선택 템플릿 값 T와 후보 패치 I의 평균을 각각 빼고 Σ((T−T̄)(I−Ī)) / √(Σ(T−T̄)² Σ(I−Ī)²)를 계산합니다. 분산이 있는 동일 패턴은 1에 가깝고, 밝기 오프셋과 양의 일정 배율에 둔감합니다. 음의 상관은 음수이지만 기본 검색의 점수 하한은 0 이상이므로 음의 점수는 선택할 수 없습니다. 점수는 확률이 아닙니다. 검색 패치의 분산이 0이면 그 후보는 점수가 없어 건너뜁니다.

적용 상황과 원리

이 예의 동일 위치에서 모델과 영상은 선택된 여섯 밝기값이 모두 같습니다. 두 값 집합에서 평균을 각각 빼면 같은 벡터가 되고, 자기 자신과의 내적을 두 크기의 곱으로 나누므로 점수는 1입니다. 상수값만 반복했다면 벡터의 길이가 0이 되어 상관을 구할 수 없습니다. 이 차이가 학습 시 분산 검사가 필요한 이유입니다.

결과를 읽는 방법

정규화는 밝기 오프셋과 양의 일정 배율에 대한 민감도를 낮추지만 임의의 반사, 가림이나 무늬 변형을 제거하지 않습니다. 점수 0.99는 예제의 선택 기준이며 모든 제품에 사용할 수 있는 품질 기준이 아닙니다. 실제 영상에서는 정상 패턴과 비슷한 배경을 함께 측정해 오검출과 누락이 어떤 점수에서 발생하는지 살펴보아야 합니다. 후보 영상이 일정하면 해당 위치는 점수 후보에서 빠집니다.

추가 점검

이 사례의 여섯 값은 서로 다르므로 중심화 후에도 0이 아닌 변화가 남습니다. 검색 행에서 정확히 같은 여섯 값을 고르면 모델과 후보의 분산이 모두 존재합니다. 일정한 검색 패치라면 이 수식의 분모가 0이 되어 해당 위치는 후보가 되지 않습니다. 두 값 집합이 완전히 같은지는 선택된 여섯 쌍을 기준으로 확인합니다. 사용한 픽셀들의 평균은 두 배열에서 서로 같습니다. 선택된 템플릿 값에 차이가 있다는 조건도 확인합니다.
