관련 API

적용 상황과 원리

영상 생성은 각 언어의 ZImage Gray8 생성 경로를 사용하고, 학습은 MatchModel의 NCC 팩터리를 사용합니다. 모델 정보는 템플릿 크기, 기준점과 선택 표본 수를 제공합니다. 검색에는 각도 범위, 배율 범위, 점수 하한, 중심 거리와 최대 결과 수를 포함한 MatchSpec이 필요합니다. 이 값은 모델에 저장된 템플릿 자체와 구분합니다.

결과를 읽는 방법

검색 결과의 matches는 거리 억제와 결과 상한을 적용한 목록이고 best는 첫 결과가 없으면 비어 있는 선택 값입니다. Match의 로컬 위치와 전역 위치를 구분하며 점수는 확률이 아닙니다. 입력 영상과 모델을 해제한 후에도 이미 받은 값 스냅샷은 읽을 수 있습니다. 다른 영상을 검색할 때는 모델을 다시 열어 두어야 하며 지연 Query를 사용한다면 그 계획의 별도 수명도 확인합니다.

추가 점검

모델 학습에 사용하는 마스크와 검색 결과에 대한 중심 거리 억제는 다른 조건입니다. 마스크는 템플릿에서 사용할 표본을 선택하고 최소 거리는 검색된 후보 사이의 중복을 판단합니다. 두 설정을 혼동하면 표본 수와 반환 개수의 변화를 잘못 해석할 수 있습니다. 복원한 모델은 사용 후 언어별 소유권 규칙에 따라 정리합니다.
