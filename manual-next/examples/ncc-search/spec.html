검색 설정과 격자

아래 이름은 Rust/Python 표기이며 C#은 PascalCase입니다. 생성자에 아홉 값을 모두 지정합니다. 이 형식에 적용되는 기본값은 없습니다. 검증은 검색 시 수행됩니다.

필드단위와 유효 범위
angle_min, angle_max라디안, −π ≤ 최소 ≤ 최대 ≤ π. 영상 좌표에서 양수는 시계 방향.
angle_step라디안, 유한한 양수
scale_min, scale_max등방 배율, 0 < 최소 ≤ 최대
scale_step배율 간격, 유한한 양수
min_score0..1 포함, 점수 하한
min_distance검색 영상 픽셀, 0 이상인 중심 거리
max_matches양의 정수, 반환 개수 상한

실수 인자는 모두 유한해야 합니다. 각 축은 min + i × step, i = 0 .. floor((max−min)/step)입니다. 최댓값이 격자에 맞을 때만 끝점을 방문하며 부동소수점 반올림에 주의하세요. 각 축은 최대 4096점이고 각도×배율도 최대 4096점입니다. 위치 후보는 보이는 영상의 각 픽셀 격자에 모델 기준점의 소수 부분을 더하여 평가합니다. 이것은 후보 예산 옵션이 아니며 작업량은 대략 영상 픽셀 수 × 각도 수 × 배율 수 × 표본 수에 비례합니다.

적용 상황과 원리

이 합성 사례에서는 회전 최소와 최대가 모두 0이고 배율 최소와 최대가 모두 1입니다. 간격도 양수로 지정하므로 각 축은 한 점만 갖습니다. 양수 간격은 최소와 최대가 같은 경우에도 필수입니다. 최소 점수 0.99를 통과한 후보 중 최대 하나를 반환하고, 중심 거리 0은 거리 기반 억제를 수행하지 않습니다.

결과를 읽는 방법

실제 제품에서 각도와 크기가 변한다면 범위를 넓히되 시작부터 최댓값까지 지정 간격으로 계산된 점만 방문한다는 점에 주의합니다. 예를 들어 0부터 1까지 간격 0.4는 1을 평가하지 않습니다. 각 축 최대 4096점과 각도·배율 점 수의 곱 최대 4096점도 확인해야 합니다. 영상의 위치와 표본 수까지 곱해지는 작업량은 반환 개수를 1로 제한해도 사라지지 않습니다.

추가 점검

예제를 확장해 각도와 배율 후보를 각각 다섯 점으로 만들면 같은 위치에서 최대 스물다섯 자세를 평가합니다. 이 숫자는 영상의 위치 후보 및 선택된 템플릿 표본과 함께 처리 비용에 영향을 줍니다. 회전이나 배율을 고정해도 step 값의 양수 조건은 사라지지 않습니다. 후보가 두 배로 늘면 각 위치에서 계산할 자세 조합도 늘어납니다. 고정 범위부터 차례로 넓혀 시간을 재세요. 영상의 위치 수는 사용한 ROI의 크기에 따라 달라집니다.

끝점과 억제 예

조건확인할 내용
각도 0..1, 간격 0.4평가하는 각도는 0, 0.4, 0.8
최소 거리 5, 후보 간 거리 5경계와 같으므로 거리 규칙으로 제거하지 않음
최소 거리 5, 후보 간 거리 4먼저 선택된 후보보다 가까워 후속 후보 제거
