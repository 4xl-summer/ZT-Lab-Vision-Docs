ROI 기반 임계값 검사

ROI 기반 임계값 검사 사용 안내

검사 목적과 입력

3×1 Gray8 [9,10,11]에서 ROI (x=1,y=0,width=2,height=1)를 선택합니다. ROI는 [10,11], 원점은 (1,0)입니다. 임계값 11 이상을 255로 바꾸면 결과는 [0,255]입니다. 크기와 좌표는 로컬 픽셀 단위이며 ROI의 우측 끝은 포함하지 않습니다.

Rust

Rust
use zvision::{ZImage, ZRect};
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let image = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    let roi = image.roi(ZRect::new(1, 0, 2, 1))?;
    let result = roi.threshold(11.0)?;
    assert_eq!(result.to_packed_vec()?, vec![0, 255]);
    Ok(())
}

C#

C#
using System;
using ZVision;
using var image = ZImage.FromGray8(3, 1, new byte[] {9, 10, 11});
using var roi = image.Roi(1, 0, 2, 1);
using var result = roi.Threshold(11.0);
Console.WriteLine(string.Join(",", result.ToArrayGray8()));

Python

Python
from zvision import ZImage
with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as image:
    with image.roi(1, 0, 2, 1) as roi:
        with roi.threshold(11.0) as result:
            assert result.to_array_gray8() == bytes([0, 255])

결과와 수명

ROI는 원본 저장소를 공유하는 뷰이고 결과는 새 영상입니다. ROI 로컬 (0,0)은 원본 전역 (1,0)에 해당합니다. 크기가 0이거나 범위를 벗어나는 ROI, 잘못된 픽셀 형식은 오류로 처리하세요. share와 독립 복사인 clone_deep을 혼동하지 마세요.
