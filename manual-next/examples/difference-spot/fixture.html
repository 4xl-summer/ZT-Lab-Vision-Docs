합성 사례와 예상 · 차분 점 결함

차분 점 결함에서 합성 사례와 예상을 이해하기 위한 입력, 동작과 결과 설명

상위 목차로 돌아가기

합성 사례와 예상

5×5 기준의 (1,1)부터 3×3에 1,2,7 / 9,5,3 / 4,8,6을 넣고 나머지는 0입니다. 7×7 입력에 같은 무늬를 넣습니다. 기준 외의 픽셀은 비교에 포함됩니다.

입력예상
normal: (1,1)정렬, 유효 25, 결함 0, 통과
moved: (2,2)정렬 이동 (1,1), 유효 25, 결함 0, 통과
lighting: 전체 +20Offset 보정 후 결함 0, 통과
spot: 이동 후 (1,1)에 100정렬 후 기준 좌표 (0,0)에 점 결함, 개수·면적 한도 위반
missing: 전부 0정렬 미발견, 판정하지 않음

Python과 C#의 합성 검사 기록은 정상·이동·조명 변화에서 결함 0, 점 결함에서 1, 무늬 부재에서 검사 불가를 보여 줍니다. 점 결함은 NCC 학습 영역 밖에 배치했습니다. 전체 픽셀의 평균을 쓰는 Offset은 점 결함의 일부를 보정값에 반영합니다.

합성 기준은 작은 격자에 비대칭 무늬를 넣어 위치를 눈으로 확인할 수 있도록 구성합니다. 기준 무늬가 모두 같은 값이면 NCC 학습에 필요한 밝기 변화가 없으므로 3×3 영역에 서로 다른 값을 배치합니다. 검사 이미지에 같은 무늬를 다른 위치로 옮기면 변환을 확인할 수 있고, 무늬 외부의 한 화소를 바꾸면 정렬용 특징을 유지하면서 차분의 점 결함을 살펴볼 수 있습니다.

비교에서는 정상, 이동 정상, 전체 밝기 변화, 점 결함, 무늬가 없는 입력을 각각 별도 경우로 취급합니다. 이동된 정상 이미지는 좌표를 맞춘 뒤 결함이 없어야 하며, 밝기 변화의 해석은 선택한 보정 방식에 달려 있습니다. 무늬가 없는 입력은 분석 결과가 합격인지 평가하지 않고 정렬 미발견으로 분기합니다. 예상은 제시된 설정과 격자에만 적용되는 합성 분석 결과입니다.

예제의 설정에서 점 결함은 정렬 학습 영역 밖에 배치하므로 무늬의 상관 탐색과 한 화소 변화의 판정을 나누어 살펴볼 수 있습니다.
