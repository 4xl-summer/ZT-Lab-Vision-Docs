실패와 대안

잘못된 옵션, 빈 포함 마스크, 크기·원점 불일치, 비유한 영상 값, 상수 NCC 학습 ROI는 오류입니다. 정렬 실패는 Found를 먼저 확인하고 재촬영 또는 검사 불가로 처리하세요. 원본의 차분만 필요하면 정렬을 생략하되 두 영상의 같은 크기와 원점 및 마스크 기하를 보장해야 합니다. 실제 생산 기준과 조명 안정성은 별도 검증이 필요합니다.

정렬이 실패한 경우와 정렬 호출 자체가 오류인 경우는 다르게 처리합니다. 학습 무늬에 맞는 위치가 없거나 최소 유효 비율을 채우지 못하면 발견되지 않은 분석 결과가 돌아올 수 있습니다. 이때 차분을 생략하고 재촬영 또는 검사 불가 상태로 넘겨야 합니다. 발견되지 않은 분석 결과에서 정렬 이미지가나 유효 마스크를 바로 꺼내려고 하면 오류가 발생합니다.

반대로 ROI가 비어 있거나 입력 형식과 원점이 맞지 않는 경우, 잘못된 설정 또는 비유한 밝기 값은 입력 오류로 조사합니다. 포함 마스크가 모든 화소를 제외해도 비교할 집단이 없어 정상 합격으로 볼 수 없습니다. 실패 지점을 기록할 때에는 원본 이미지의 형식과 ROI, 검색 범위, 유효 화소 수를 함께 남기고, 이미 소유한 이미지와 분석 결과는 예외가 난 경로에서도 정리합니다.

정렬이 안 된 이미지를 원본 기준에 바로 비교하면 이동 때문에 넓은 차이가 발생할 수 있습니다. 재촬영 여부는 발견 상태와 입력 조건을 확인한 다음 결정합니다.

점 사례가 다르게 보일 때

먼저 학습 무늬가 정확한 위치에 놓였는지 확인합니다. 이 예제의 무늬는 기준 (1,1)의 3×3이고 이동 입력에서는 (2,2)에 놓입니다. 점 결함은 그 무늬 밖 (1,1)에 배치해야 합니다. 결함을 학습 무늬 내부에 넣거나 검색 점수를 바꾸면 정렬 결과부터 달라질 수 있으므로 원래 사례의 후보 1이라는 기대값을 그대로 적용하지 않습니다.

정렬이 발견되었으면 ValidCount와 마스크를 살펴봅니다. 이 입력은 7×7에 기준 5×5 전체를 담도록 만들어 유효 25개를 기대합니다. 입력 크기 또는 최소 비율을 바꾸면 보간 범위가 달라져 미발견이 될 수 있습니다. 이 상태에서 차분의 후보 수를 읽으려는 대신 정렬 설정과 입력 범위를 먼저 점검합니다.

OFFSET 보정의 bias는 선택된 모든 픽셀의 평균 차이에 영향을 받습니다. 점 하나가 100만큼 변한 25픽셀 사례에서는 bias −4로 점 잔차가 96이고 다른 곳의 잔차는 −4입니다. threshold 10에서 각각 9.6과 0.4이므로 한 점만 전경입니다. 포함 영역이나 밝기 보정을 바꾸면 이 계산도 다시 해야 합니다.
