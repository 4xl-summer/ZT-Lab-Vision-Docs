원리와 입력

매뉴얼의 시작점은 현재 해결하려는 작업에 따라 달라집니다. 처음 SDK를 연결한다면 설치 환경을 준비한 뒤 합성 영상 예제에서 입력과 출력이 맞는지 확인합니다. 이미 호출은 가능하지만 결과의 좌표나 객체 해제가 헷갈린다면 ROI, Share와 수명 개념이 더 직접적인 출발점입니다. 특정 알고리즘의 매개변수를 찾고 있다면 해당 가이드에서 입력 조건과 판독을 먼저 읽으세요.

적용과 확인

예제를 실행할 때는 SDK 리비전과 운영체제, 언어 런타임을 기록합니다. 같은 숫자 예제라도 실제로 어떤 네이티브 라이브러리가 로드되었는지 알 수 있어야 실패를 재현할 수 있습니다. 이후 언어별 API 색인에서 정확한 선언과 반환 유형을 확인합니다. 가이드는 합성 계산을 설명하고, 실측 데이터와 생산 장비의 기준은 별도의 검증으로 정해야 합니다.

읽기와 적용

처음 사용하는 사람은 설치에서 성공했다는 메시지만 보기보다 첫 입력과 출력 배열을 확인하는 편이 좋습니다. 처리할 수 있는 영상이 이미 준비되어 있고 특정 수치의 의미가 문제라면 입력 형식과 해당 알고리즘의 옵션부터 읽을 수 있습니다. 결과를 화면에 올리거나 실제 길이로 바꾸려는 경우에는 로컬·전역 좌표와 보정 단위가 선행 지식입니다. 시작점은 사용자의 현재 질문에 맞게 선택하되, 결과의 성공·빈 상태·오류를 각각 해석합니다.
