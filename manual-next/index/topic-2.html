문서 읽는 순서

처음에는 설치와 첫 예제를 실행합니다. 이후 필요한 기능의 가이드에서 원리와 입력 조건을 읽고, 언어별 API에서 정확한 시그니처와 결과 필드를 확인하세요. 전체 예제에는 입력 데이터와 기대값이 들어 있으며, 각 페이지 마지막 표에서 관련 클래스·프로퍼티·메서드로 이동할 수 있습니다.

왼쪽에서 페이지를 선택하면 해당 페이지의 서브목차가 펼쳐집니다. 검색은 한국어 주제와 API 이름을 지원하며 언어·종류를 골라 멤버 위치로 바로 이동할 수 있습니다.

원리와 입력

처음부터 모든 API 이름을 읽기보다는 하나의 입력이 결과로 바뀌는 경로를 따라가세요. 설치 안내에서 언어와 플랫폼을 선택한 뒤 첫 이미지 처리의 3×1 Gray8 예제를 실행합니다. 입력 [9,10,11]과 임계값 10의 기대 마스크 [0,255,255]를 비교하면 생성·호출·읽기 세 단계가 연결됩니다.

적용과 확인

그다음 객체 모델에서 새 영상과 값 스냅샷의 차이를 이해하고 ROI와 수명 문서를 읽습니다. 필요한 알고리즘 가이드는 원리와 설정을 설명하며, 상세 참조는 실제 인자와 반환을 확인하는 곳입니다. 예제 실행 기록은 특정 SDK와 환경의 증거로 읽고 자신의 데이터에 적용할 때는 형식·좌표·단위와 오류 처리를 다시 확인하세요. 문서 간 링크가 가리키는 상위 주제와 해당 소주제를 구분하면 필요한 설명을 빠르게 찾을 수 있습니다.

읽기와 적용

학습 순서를 하나의 작은 문제에 적용하면 문서의 역할이 드러납니다. 합성 영상 생성이 실패하면 설치와 로딩을 살피고, 생성은 되지만 출력 배열이 예상과 다르면 픽셀 형식과 임계값 계약을 봅니다. 다음으로 ROI에서 결과 위치를 읽어 본 뒤 원본 표시 좌표와 비교합니다. 필요한 가이드에서 알고리즘의 가정과 실패 상태를 읽고 마지막으로 자신의 언어에 맞는 선언 및 예제를 대조하면 각 단계의 문제가 섞이지 않습니다.

실행할 때 확인할 점

예제의 결과가 기대와 다르면 먼저 입력 영상의 크기와 픽셀 형식을 확인하고, 그다음 연산의 설정값과 출력 좌표를 순서대로 대조하세요. 각 단계의 입력을 기록하면 문제가 생긴 지점을 좁힐 수 있습니다.
