검증의 범위를 읽을 때는 문서의 API 대조, 합성 예제 실행, 사용자 화면 확인을 별개의 증거로 취급합니다. API 선언이 존재한다는 사실은 모든 형식과 경계값을 실행했다는 의미가 아닙니다. 설치 패키지 검증 역시 표시된 플랫폼과 패키지 조합에 대한 결과입니다. 재현하려는 환경이 다르면 같은 바이너리가 동작한다고 가정하지 말고 운영체제, 아키텍처, 런타임과 로딩 경로를 별도로 확인합니다.
