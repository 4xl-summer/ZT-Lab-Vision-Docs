SDK 환경 준비 및 첫 빌드

Rust·C#·Python 사용 환경, Windows 네이티브 빌드, 검증 수준과 첫 실행 경로.

독립 HTML 페이지코드 검토 기준 2026-11-08설계 v1 적용 · 소스 대조

1. 시작 전에 확인할 사항

ZVision은 Rust 코어를 기반으로 Rust Facade와 C#·Python SDK가 있습니다. 특히 C#과 Python의 영상 처리 기능은 플랫폼에 적합한 네이티브 라이브러리를 필요로 합니다. 저장소 코드에서 확인한 구성 경로를 안내하며, 배포 방식이 확정되지 않은 패키지 설치 명령을 임의로 기재하지 않습니다.

항목현재 확인된 실제 경로/규칙상태
Rust 공개 Facadecrates/zvision (Cargo workspace 패키지)소스 경로 확인
Rust 네이티브 ABIcrates/zvision-ffi / zvision_ffi.dllWindows x64 빌드 명령 확인
C# 솔루션wrappers/dotnet/ZVision.slnx빌드 명령 소스 README 확인
.NET SDK 버전저장소 global.json 기준 10.0.403, latestPatch버전 확인
C# 대상Core netstandard2.0; Windows UI는 net10.0-windows/net472기능별 대상 확인
Python 래퍼wrappers/python/src/zvision소스 경로 확인, wheel 설치명령 검증 대기

2. Windows에서 소스 빌드

아래 명령은 **저장소 루트 디렉터리에서** 실행합니다. Rust Windows MSVC 타깃과 필요한 컴파일 환경, .NET SDK 10.0.403이 준비되어 있어야 합니다.

PowerShell · 네이티브 및 C# 빌드
cargo build -p zvision-ffi --release --locked --target x86_64-pc-windows-msvc
dotnet build wrappers/dotnet/ZVision.slnx -c Release

# 예시: 설치한 SDK/빌드 산출물의 실제 경로로 조정
$env:ZVISION_NATIVE_LIBRARY = (Resolve-Path ".\target\x86_64-pc-windows-msvc\release\zvision_ffi.dll").Path

이 빌드 명령은 현재 소스 저장소의 C# SDK README를 바탕으로 합니다. 실제 의존성 설치, DLL 로딩과 샘플 실행은 이 문서 개정에서 새로 실행하지 않았습니다.

3. Rust에서 직접 시작

소스 저장소의 Rust zvision 크레이트를 사용하는 예제입니다. 별도 바이너리 프로젝트에 해당 크레이트 의존성을 추가하려면 workspace 경로를 정확히 지정하세요. 기본 Cargo feature full에는 io, recognition, acquisition이 포함됩니다.

Rust · 프로그램 본문
use zvision::ZImage;
fn main() -> zvision::ZResult<()> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    let binary = source.threshold(10.0)?;
    assert_eq!(binary.to_packed_vec()?, vec![0, 255, 255]);
    Ok(())
}

4. C# 최소 사용 흐름

C# · using/Dispose
using System;
using ZVision;

using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var result = source.Threshold(10.0);
Console.WriteLine(string.Join(",", result.ToArrayGray8())); // 0,255,255

5. Python 최소 사용 흐름

Python · with/close
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as result:
        assert result.to_array_gray8() == [0, 255, 255]

Python의 정식 wheel 설치 명령과 네이티브 검색 경로는 배포 환경별 설치 테스트를 근거로 확정해야 합니다. 해당 부분은 아직 미검증입니다.

6. 첫 실행 실패 시

현상원인 후보확인 방법
DLL 로드 실패아키텍처 불일치·실제 DLL 위치 누락x64 여부, native 빌드 산출물, 경로 확인
SDK 컴파일 오류.NET 버전 또는 프로젝트 호환성global.json, SDK 목록, slnx 지원 여부
Python 라이브러리 오류Wheel ABI/플랫폼 네이티브 불일치wheel 버전·Python 버전·환경 확인
형식 불일치 오류RGB 영상에서 Gray 전용 처리 호출지원 픽셀 형식 먼저 확인
i검증 표기: 네이티브와 C# 빌드 명령은 저장소 README 및 공개 코드 검토 기반이며, 이 세션에서 설치·컴파일을 새로 재현하지 않았습니다. 배포 호환은 사용자 환경에서 별도 검증이 필요합니다.
