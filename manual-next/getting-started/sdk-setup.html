SDK 환경 준비 및 첫 빌드 사용 안내

Rust는 SDK 소스 체크아웃의 Cargo 경로 의존성을 사용합니다. C#과 Python은 각각 해당 운영체제와 아키텍처용 NuGet 또는 wheel 소비자 패키지를 사용할 수 있습니다. 소스 빌드 출력과 패키지 설치는 서로 다른 경로입니다. 아래 명령은 배포 파일을 이미 확보한 경우의 흐름이며, 사용자의 파일 위치로 경로를 바꾸세요.

소비자 프로젝트의 Cargo.toml 에서 아래 경로를 실제 체크아웃의 절대 경로로 바꿉니다. Windows에서도 Cargo 경로에 슬래시를 사용할 수 있습니다. zvision-ops 는 일부 보조 열거형과 설정을 직접 사용하는 예제에 필요하며 직접 쓰지 않으면 생략할 수 있습니다. 기본 full 기능은 이미지 I/O, recognition, acquisition을 포함합니다.

프로젝트 디렉터리에서 cargo run 을 실행합니다. 체크아웃 루트는 예제 프로젝트 위치로 추측하지 말고 실제 경로를 지정하세요.
