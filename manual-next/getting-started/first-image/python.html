Python · 첫 이미지 처리

Python의 입력과 결과, 적용 방법을 설명합니다.

상위 목차로 돌아가기

Python

Python
from zvision import ZImage
with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as result:
        assert result.to_array_gray8() == bytes([0, 255, 255])

원리와 입력

Python 예제는 bytes에 세 Gray8 픽셀을 담아 3×1 영상을 만든 다음 threshold(10.0)를 호출합니다. 결과를 to_array_gray8로 읽어 bytes([0,255,255])와 비교하므로, 하나라도 다른 순서나 값이 나오면 assertion이 실패합니다. 값 10은 임계값과 같아 255가 됩니다. 이 경계 표본을 포함하는 이유는 출력이 단순히 이진 영상이라는 사실보다 비교 조건을 정확히 확인하기 위해서입니다.

적용과 확인

두 with 블록은 각각 원본과 반환 영상의 수명을 관리합니다. 내부 블록이 끝나면 result는 닫히므로 이후 영상 핸들로 사용하지 않아야 합니다. 바깥 블록에서는 그때까지 source를 별도로 사용할 수 있습니다. 모듈을 불러오지 못하거나 네이티브 라이브러리를 찾지 못하면 가상 환경과 설치된 wheel의 런타임 구성을 먼저 살펴보세요. assertion 실패는 예제 입력과 기대값을 확인해야 하는 다른 종류의 문제입니다.

적용할 때 살펴볼 점

세 표본을 하나씩 계산하면 9는 0, 10과 11은 각각 255입니다. bytes 비교는 표시 색상 대신 각 바이트의 값과 순서를 확인합니다. 반환된 바이트 값과 ZImage 핸들은 서로 다른 타입입니다. 바이트를 보관할 수 있다는 사실을 닫힌 영상 핸들에 새로 접근할 수 있다는 의미로 혼동하지 마세요. 문제가 발생하면 원본 생성과 결과 읽기 단계 중 어디에서 실패했는지 확인합니다.
