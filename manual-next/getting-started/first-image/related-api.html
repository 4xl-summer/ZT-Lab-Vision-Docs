관련 API

원리와 입력

이 사례의 출발점은 픽셀 형식과 크기를 가진 ZImage 생성자입니다. Gray8 배열로 3×1 입력을 구성한 다음 이미지의 threshold 또는 Threshold를 호출하고, 반환된 새 Gray8 영상의 픽셀을 읽습니다. Rust는 from_vec_gray8와 to_packed_vec, C#은 FromGray8와 ToArrayGray8, Python은 from_gray8와 to_array_gray8을 사용합니다. 메서드 이름만 바꾸는 데 그치지 말고 각 언어에서 반환 영상의 수명도 함께 확인하세요.

적용과 확인

임계값을 조정할 때는 밝기의 단위와 타입을 먼저 보아야 합니다. 이 예에서는 10이 8비트 밝기 값과 같은 수치 공간에서 비교되며 경계값도 전경입니다. 처리 계획에 여러 단계를 넣고 중간 결과를 붙잡고 싶을 때는 ImageQuery의 capture와 실행 결과를 살펴봅니다. 관심 영역만 다루는 경우에는 ROI 생성과 origin 좌표를 확인해야 후속 위치 결과를 원본에 올바르게 표시할 수 있습니다.

적용할 때 살펴볼 점

세 언어에서 배열을 읽는 이름은 다르지만 기대 순서는 입력의 왼쪽에서 오른쪽입니다. 새 마스크에 대한 해제와 원본의 해제를 각각 배치해 두면 후속 처리에서 어느 영상이 살아 있는지 확인할 수 있습니다. 더 큰 영상에서는 필요한 부분을 ROI로 선택할 수 있지만 결과 위치를 표시할 때 로컬 좌표와 origin을 함께 고려해야 합니다.
