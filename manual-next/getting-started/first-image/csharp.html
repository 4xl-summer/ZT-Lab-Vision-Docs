C# · 첫 이미지 처리

C#의 입력과 결과, 적용 방법을 설명합니다.

상위 목차로 돌아가기

C#

C#
using System;
using ZVision;
using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var result = source.Threshold(10.0);
Console.WriteLine(string.Join(",", result.ToArrayGray8()));

원리와 입력

이 코드는 관리형 배열의 9, 10, 11을 3×1 Gray8 입력으로 만들고 Threshold(10.0)의 반환을 별도 영상으로 받습니다. ToArrayGray8은 화면에 표시하기 전에 결과 픽셀을 배열로 읽는 단계입니다. 출력되는 세 값은 순서대로 0,255,255이며 중간의 10이 흰색이 되는 것이 경계 포함 규칙을 보여 줍니다. 숫자와 쉼표를 포함한 출력 형식을 확인하면 결과의 순서까지 함께 점검할 수 있습니다.

적용과 확인

source와 result에는 각각 using이 있으므로 해당 범위가 끝나면 각 영상의 소유 핸들이 정리됩니다. 한 객체를 정리했다고 다른 객체를 다시 사용해도 된다는 뜻이 아니라, 별도로 얻은 결과와 이미 닫은 핸들을 구분해야 한다는 뜻입니다. 실행 중 DLL 로딩이 실패하면 픽셀 처리 대신 패키지와 네이티브 런타임 구성을 확인하세요. 배열 길이가 크기와 맞지 않는 오류는 FromGray8 입력을 먼저 점검합니다.

값과 판독 기준

단계입력 또는 결과확인할 점
입력3×1, [9,10,11]배열 길이 3
호출Threshold(10.0)새 영상 반환
출력0,255,25510과 11이 전경
정리source와 result각각 using 범위 종료

적용할 때 살펴볼 점

출력의 두 번째 숫자가 255가 아니면 10이 포함되는 경계 조건을 먼저 확인하세요. 세 번째까지 0이면 입력 배열이나 실제 전달한 임계값이 달랐을 수 있습니다. 원본 값 10과 11이 모두 같은 마스크 값으로 바뀌므로 밝기 차이를 이후에 확인해야 한다면 source를 별도로 유지해야 합니다. 출력 영상은 더 이상 필요하지 않을 때 using 범위를 벗어나 정리합니다.
