관련 검증 사례

원리와 입력

이 페이지에서 확인할 핵심 사례는 Gray8 경계값입니다. 3×1 입력 [9,10,11]과 임계값 10을 고정하고 출력 [0,255,255]를 세 위치 모두 비교합니다. 첫 값은 하한보다 작고 둘째는 정확히 같으며 셋째는 큽니다. 이 조합은 임계값과 같은 픽셀이 전경에 들어가는지 확인하도록 의도적으로 선택했습니다. 단순히 출력 길이가 3인지 검사하는 것만으로는 가운데 픽셀의 잘못된 판정을 알아낼 수 없습니다.

적용과 확인

별도 실행 프로젝트에는 7을 기준으로 한 Gray8과 GrayF32 사례, 바이트 및 실수 임계값 호출, ROI와 Query 캡처 사례도 포함됩니다. 결과와 언어별 검증 기록은 해당 실행 환경과 SDK 버전에 묶어 해석해야 합니다. 합성 배열 통과는 해당 입력의 호출 및 기대값을 확인한 증거이며, 실제 제품에 적합한 검사 임계값을 결정하거나 카메라·조명·장비 조합을 검증한 것은 아닙니다. 자신의 영상에서는 입력 형식과 관측된 분포를 먼저 확인하세요.

값과 판독 기준

단계입력 또는 결과확인할 점
경계 아래9결과 0
경계와 같음10결과 255
경계 위11결과 255
수명입력과 결과소유 영상 각각 종료

적용할 때 살펴볼 점

기준을 9로 바꾸면 세 값이 모두 기준 이상이어서 [255,255,255]가 되고, 11로 바꾸면 [0,0,255]가 됩니다. 이는 비교식에서 손으로 계산한 추가 판독 기준입니다. 실행 기록의 실제 입력과 이 설명용 계산을 구별해 확인하세요. 기준과 같은 값을 반드시 포함하면 10을 초과하는지 이상인지의 차이를 구별할 수 있습니다.
