결과 해석과 다음 단계

원본은 여전히 세 픽셀이고 결과는 0 또는 255인 Gray8 영상입니다. C#의 using과 Python의 with는 소유 영상을 해제합니다. 형식이 맞지 않거나 크기와 버퍼 길이가 일치하지 않으면 오류를 확인하세요.

임계값 원리 · ROI · ROI 예제

환경별 실행 결과와 적용 범위는 검증 기록을 확인하세요.

원리와 입력

마스크의 0은 임계값보다 작은 입력, 255는 임계값 이상인 입력을 가리킵니다. 세 값 가운데 첫 위치만 배경이고 나머지 두 위치가 전경입니다. 결과를 어떤 후속 연산에 전달할 때는 원본 밝기와 마스크 의미를 혼동하지 않도록 두 영상을 따로 보유하세요. 원본의 10과 11은 서로 다른 밝기이지만 이 이진 결과에서는 모두 255이므로 밝기 차이를 복원할 수 없습니다.

적용과 확인

원본에 있는 대상이 어느 부분에 있는지 알고 싶다면 ROI를 만들고 그 로컬 원점과 전역 원점의 관계를 함께 기록합니다. Blob을 사용하면 마스크의 연결된 전경을 영역으로 해석할 수 있지만, 연결 방식이나 면적 조건은 별도로 선택해야 합니다. 실제 검사 임계값은 합성 예제의 10을 그대로 복사하지 말고 대상과 조명에 맞는 자료로 평가하세요. 영상이 만들어지지 않는 경우에는 비교 결과보다 앞 단계인 버퍼 크기, 픽셀 형식과 실행 환경부터 확인하는 편이 원인을 좁히기 쉽습니다.
