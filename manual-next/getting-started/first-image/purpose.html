합성 영상으로 시작

Gray8 영상 한 행 [9,10,11]에서 임계값 10 이상의 픽셀은 255, 나머지는 0입니다. 독립 기대 결과는 [0,255,255]입니다. 경계값 10이 포함되는지 확인합니다. 입력은 변경하지 않고 새 결과 영상을 만듭니다.

원리와 입력

이 예제는 카메라와 외부 영상 파일 없이 임계값 연산의 입력과 결과를 직접 확인하기 위한 출발점입니다. 한 줄에 픽셀 세 개가 있으므로 영상 크기는 너비 3, 높이 1이고 바이트 배열 길이도 3입니다. 각 Gray8 값은 하나의 밝기 표본으로 취급합니다. 순서대로 비교하면 9는 10보다 작고, 10은 경계와 같으며, 11은 경계보다 큽니다. 따라서 결과는 0, 255, 255입니다. 가운데 표본은 비교가 이상인지 초과인지 구별하는 역할을 합니다.

적용과 확인

입력과 출력은 각각의 영상 객체입니다. 처리를 호출한 뒤 원본에서 세 값을 다시 읽어도 9, 10, 11이어야 합니다. 화면에 보이는 흰색 픽셀 수만 세면 경계가 잘못 구현된 경우를 놓칠 수 있으므로, 가능하면 배열 전체를 순서대로 비교하세요. 영상 생성 시 크기와 버퍼 길이가 다르면 이후 임계값 문제가 아니라 입력 구성부터 다시 확인합니다. 이 값은 동작을 설명하기 위한 합성 자료이며 실제 카메라의 밝기 분포나 검사 합격 기준을 의미하지 않습니다.
