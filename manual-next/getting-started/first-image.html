첫 이미지 처리

첫 이미지 처리 사용 안내

합성 영상으로 시작

Gray8 영상 한 행 [9,10,11]에서 임계값 10 이상의 픽셀은 255, 나머지는 0입니다. 독립 기대 결과는 [0,255,255]입니다. 경계값 10이 포함되는지 확인합니다. 입력은 변경하지 않고 새 결과 영상을 만듭니다.

Rust

Rust
use zvision::ZImage;
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    let result = source.threshold(10.0)?;
    assert_eq!(result.to_packed_vec()?, vec![0, 255, 255]);
    Ok(())
}

C#

C#
using System;
using ZVision;
using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var result = source.Threshold(10.0);
Console.WriteLine(string.Join(",", result.ToArrayGray8()));

Python

Python
from zvision import ZImage
with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as result:
        assert result.to_array_gray8() == bytes([0, 255, 255])

결과 해석과 다음 단계

원본은 여전히 세 픽셀이고 결과는 0 또는 255인 Gray8 영상입니다. C#의 using과 Python의 with는 소유 영상을 해제합니다. 형식이 맞지 않거나 크기와 버퍼 길이가 일치하지 않으면 오류를 확인하세요.
