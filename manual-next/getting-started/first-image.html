첫 이미지 처리

외부 이미지 파일 없이 3개의 Gray8 픽셀로 생성, 임계값 처리, 결과 읽기를 이해합니다.

독립 HTML 페이지코드 검토 기준 2026-11-08초기 콘텐츠

처리 목표

3×1 회색 영상의 픽셀 값 [9, 10, 11]에 임계값 10을 적용합니다. 비교 기준은 픽셀 ≥ 임계값이므로 출력 Gray8 마스크는 [0, 255, 255]입니다. 임계값에 같은 픽셀도 전경(255)에 포함됩니다.

입력 영상Gray8 · 3×1
→
Threshold(10)픽셀 ≥ 10
→
결과 영상0, 255, 255

Rust 코드

Rust
use zvision::ZImage;

fn main() -> zvision::ZResult<()> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    let mask = source.threshold(10.0)?;
    assert_eq!(mask.to_packed_vec()?, vec![0, 255, 255]);
    Ok(())
}

from_vec_gray8은 Vec의 소유권을 가져와 픽셀을 보관합니다. threshold는 원본을 변경하지 않고 새 이미지를 반환하며, Rust의 소유권 체계가 수명을 관리합니다.

C# 코드

C#
using System;
using ZVision;

using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var mask = source.Threshold(10.0);
Console.WriteLine(string.Join(", ", mask.ToArrayGray8()));
// 0, 255, 255

FromGray8은 배열을 복사해 소유 이미지를 만들고, using은 네이티브 이미지 핸들을 안전하게 해제합니다.

Python 코드

Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as mask:
        print(mask.to_array_gray8())
        # [0, 255, 255]

Python의 with는 close()를 호출하도록 자원 수명을 관리합니다.
