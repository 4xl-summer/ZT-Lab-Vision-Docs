설치 패키지로 예제 실행

직접 만든 Linux wheel·NuGet 패키지를 소스 참조와 분리해 설치하고 실행하는 방법.

이 장에서 배우는 내용

직접 만든 Linux wheel·NuGet 패키지를 소스 참조와 분리해 설치하고 실행하는 방법.

소스 프로젝트를 직접 참조하는 실행과, 네이티브 라이브러리를 포함한 패키지를 설치하는 실행을 각각 확인했습니다. 아래 절차는 Linux x64에서 생성한 로컬 배포물 기준입니다. 공개 PyPI나 NuGet 서버에 해당 패키지가 배포되어 있다는 뜻은 아닙니다. SDK 소스 저장소의 접근 권한이 필요합니다.

Rust와 CPython 3.14 및 .NET 10 SDK가 설치된 Linux 환경에서 실행합니다. SDK_SOURCE 와 PACKAGE_DIR 은 실제 절대 경로로 바꾸세요. 두 생성 스크립트는 기존 배포물 덮어쓰기를 거부하므로 새 출력 폴더를 사용합니다.

사용자가 Cargo 출력 경로를 변경했다면 NATIVE_LIBRARY 도 실제 Release 파일 위치로 지정하세요. wheel에는 네이티브 파일과 제3자 고지가 포함됩니다. Linux wheel은 해당 호스트 형식이며 manylinux 호환성을 별도로 주장하지 않습니다.
