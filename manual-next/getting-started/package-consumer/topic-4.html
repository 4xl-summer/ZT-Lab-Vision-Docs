C#: 로컬 NuGet 피드에서 설치

다운로드에 포함한 consumer/ConsumerExamples.csproj는 ZVision.linux-x64 버전 0.1.0을 참조합니다. 소스 참조 프로젝트와 별도입니다.

Bash
unset ZVISION_NATIVE_LIBRARY
export ZVISION_MANUAL_MODELS=/absolute/path/downloads/models
dotnet restore /absolute/path/downloads/csharp/consumer/ConsumerExamples.csproj --source "$PACKAGE_DIR" --source https://api.nuget.org/v3/index.json
dotnet run --no-restore --project /absolute/path/downloads/csharp/consumer/ConsumerExamples.csproj -c Release

생성한 Linux x64 패키지의 런타임 자산을 사용해 22개 사례를 실행했습니다. Windows 네이티브 파일을 Linux 패키지에 넣거나 그 반대로 사용하지 마세요. 다른 OS·아키텍처·런타임 조합은 별도 검증이 필요합니다.

원리와 입력

consumer/ConsumerExamples.csproj는 소스 프로젝트 참조가 아닌 ZVision.linux-x64 0.1.0 PackageReference를 사용합니다. 로컬 패키지가 놓인 피드와 필요한 의존성 피드를 지정해 복원한 다음 같은 프로젝트를 실행합니다. ZVISION_NATIVE_LIBRARY를 제거하면 별도 override 대신 설치 패키지의 런타임 자산을 사용하는 경로를 확인할 수 있습니다.

적용과 확인

AI 사례가 포함되므로 모델 디렉터리를 ZVISION_MANUAL_MODELS에 지정합니다. 표시된 Linux x64 실행에서는 패키지 자산을 사용하여 22개 합성 사례를 확인했습니다. 복원 실패는 패키지 ID·버전·피드를, 실행 로딩 실패는 패키지와 프로세스의 OS 및 아키텍처를 먼저 확인하세요. Windows 자산을 Linux 패키지에 넣거나 반대로 섞으면 같은 검증 조건이 아닙니다. 다른 플랫폼은 별도 확인해야 합니다.

읽기와 적용

복원 단계는 프로젝트가 요구하는 패키지와 의존성을 확보하고, 실행 단계는 복원된 관리형 코드와 런타임 자산을 실제로 로드합니다. 따라서 restore가 성공해도 플랫폼에 맞는 네이티브 파일이 실행 중 로드되는지 별도로 확인해야 합니다. 소비 예제의 모델 디렉터리는 코드 패키지와 별개의 입력입니다. 전체 출력과 기대값을 비교할 때 모델 기반 사례가 빠지지 않았는지, 소스 참조 프로젝트가 아닌 소비 프로젝트를 실행했는지도 확인합니다.
