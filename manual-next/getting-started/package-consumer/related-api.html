관련 API

원리와 입력

패키지 설치 자체와 SDK API의 사용은 이어져 있지만 서로 다른 확인 단계입니다. 소비 환경에서 ZImage의 Gray8 생성과 Threshold를 실행하고 픽셀 배열을 읽으면 래퍼, 네이티브 자산과 호출의 기본 연결을 확인할 수 있습니다. 입력 [9,10,11], 기준 10의 결과는 [0,255,255]이며 각 소유 영상은 사용 후 정리합니다.

적용과 확인

전체 runner에는 매칭, 계측, 정렬, 공간 데이터와 AI 등도 포함되어 있습니다. MatchResult는 값 스냅샷이고 이미지나 모델은 각각 소유 핸들이므로 반환 타입에 맞는 수명을 적용하세요. AI 모델을 선택한 실행에서는 명시된 모델 디렉터리가 필요합니다. 소스 참조와 패키지 참조를 섞지 않은 실행 결과를 SDK 리비전 및 플랫폼과 함께 기록하면 재현 범위를 알 수 있습니다.

읽기와 적용

최소 검사는 작은 입력을 사용해 결과를 손으로 계산할 수 있다는 장점이 있습니다. 10 이상인 픽셀 두 개만 전경이므로 출력의 두 번째와 세 번째 값이 255여야 합니다. 결과 배열을 얻은 후 마스크 영상과 원본 영상의 소유 범위를 각각 정리합니다. 이 확인은 설치된 라이브러리의 기본 연산 연결을 검증하며, 모든 지원 형식이나 매칭 모델의 정확도를 한 번에 검사하는 절차는 아닙니다.
