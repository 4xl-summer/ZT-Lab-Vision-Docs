관련 API

점군 준비에는 좌표가 있는지 먼저 판단합니다. 직접 Point3 값을 가지고 있으면 PointCloud 생성 경로를 사용하고, 깊이 격자에서 왔다면 to_point_cloud로 각 셀의 좌표를 만들 수 있습니다. None 슬롯은 측정 누락을 나타내며 전체 인덱스와 유효점 수를 구분해야 합니다. share와 깊은 복사의 차이는 저장소 소유 관계에 관한 것이고, 좌표계를 변환하는 연산과는 별개입니다.

estimate_normals는 점마다 주변 기하의 방향을 구하고 fit_plane과 fit_cylinder는 전체 형상을 요약합니다. register_icp는 목표 점군과 초기 강체 변환을 추가로 받아 대응을 반복합니다. 각 결과에는 다른 진단이 붙으므로 평면 합의점, 법선 결측, 정합 수렴을 같은 상태값으로 합치지 않습니다. 호출 전 단위·frame·임계값을 정하고 반환 후에는 잔차와 독립 보류점을 확인합니다.

분석 결과를 연결하는 순서

깊이 격자에서 시작할 때에는 결측을 포함한 셀과 원점·간격을 함께 확인하고 직교 점군으로 변환합니다. 직접 측정된 좌표 배열이 이미 있으면 점군을 바로 만들 수 있습니다. 어느 경로든 전체 슬롯과 유효점을 구분하고 위치의 unit과 frame을 기록해야 합니다. 예를 들어 네 슬롯 중 하나가 결측이면 법선 결과도 네 슬롯으로 대조해야 누락 위치를 잃지 않습니다.

국소 방향이 목적이면 법선, 하나의 지배적인 표면이 목적이면 평면 또는 원통 피팅, 다른 스캔과 맞추려면 초기 변환을 가진 ICP를 선택합니다. 평면의 임계 거리는 합의점 조건이고 ICP의 최대 거리는 대응 조건입니다. 결과의 결측, 합의점 수, 수렴 여부와 오류는 서로 다른 진단이므로 단계별로 보존합니다. 소유 점군과 공유 객체는 각각 사용 후 정리합니다.
