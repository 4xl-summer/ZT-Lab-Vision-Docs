검증 기준

점군을 섞기 전 unit·frame을 확인하고 이상치와 피팅 잔차를 기록하세요.

관련 설명 열기

형상 결과를 검증하려면 입력의 유효점 수와 결측 슬롯 수를 먼저 기록합니다. 평면에서 inliers는 임계 거리 이내로 선택된 점이고 total은 입력의 유효점 수입니다. RMS와 최대 오차는 선택된 점의 거리 잔차이므로, 합의점이 전체의 작은 부분인데 RMS만 낮은 결과와 대부분의 점이 지지하는 결과를 구분할 수 있습니다. 임계 거리는 점군의 길이 단위로 해석합니다.

좌표 변환을 검증할 때는 학습에 쓰지 않은 점을 따로 준비하여 변환 결과와 기준점 사이의 거리를 계산합니다. 예를 들어 이동이 (2,-3,4)라면 보류점 (2,3,4)는 (4,0,8)에 놓입니다. 동일 점을 학습과 평가에 모두 쓰면 일반화나 센서 정확도를 확인하지 못합니다. 합성 결과가 맞아도 실제 잡음, 가림과 장치 보정은 별도로 평가합니다. 변환을 평가할 때는 입력과 목표의 frame 이름도 함께 남깁니다.

보류점으로 거리 확인

한 변환이 순수 이동 (2,−3,4)이고 보류점이 (2,3,4)라면 출력은 성분별 합인 (4,0,8)입니다. 기준점도 (4,0,8)이면 거리 잔차는 0이고, 기준 Z가 8.5라면 잔차는 0.5입니다. 이 거리는 변환이 지정한 길이 단위로 해석합니다. 해당 점을 피팅에 사용하지 않았다면 보류점 평가로 학습 잔차와 별도로 기록할 수 있습니다.

평면 모델의 RMS는 채택된 점들의 거리 통계이므로 별도 변환의 보류점 거리와 대상이 다릅니다. 먼저 점군 유효 수, 평면 합의점 수와 최대 잔차를 살피고, frame이 다른 자료를 변환할 때는 from_frame과 to_frame을 같이 저장합니다. 합성 산술은 좌표 처리의 재현을 확인하며 실제 센서의 오차, 표면 가림과 측정 환경은 별도의 자료로 평가합니다.

항목값·조건의미
이동(2,−3,4)길이 단위
보류점(2,3,4)변환 입력
예상 출력(4,0,8)성분별 합
기준 Z=8.5거리 0.5별도 평가
