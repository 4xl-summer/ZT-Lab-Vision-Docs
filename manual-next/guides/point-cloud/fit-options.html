평면과 원통의 inlier_threshold는 유한 양수이며 점군 단위입니다. 유효점 부족이나 퇴화, 허용치 밖 설정은 오류로 반환합니다. Python 기본 fit_plane/fit_cylinder는 threshold만 받습니다. 언어별 고급 옵션 노출 여부는 해당 참조를 확인하세요.

관련 합성 실행 사례: spatial-fit.

이 페이지는 기준 SDK 소스와 대조했습니다. 예제는 실행 환경에서 별도로 검증해야 하며 합성 데이터 결과는 실장비 정확도를 뜻하지 않습니다.

평면 후보 탐색의 hypothesis_iterations와 이후 refinement_iterations는 각각 다른 작업의 반복 한도이며 둘 다 양수입니다. outlier_fraction은 배제할 수 있는 비율을 제한하고 1 미만이어야 합니다. target_inlier_fraction이 설정되면 목표 지지율에 도달했을 때 후보 탐색을 일찍 마칠 수 있습니다. 이는 제한된 시간과 계산을 제어하는 조건이지 모든 이상치에 대한 전역 최적 보장이 아닙니다.

원통은 initial_axis를 선택적으로 받아 방향을 정규화하며, 유한하지 않거나 길이가 0인 축은 사용할 수 없습니다. step_tolerance는 매개변수 변화의 무차원 기준이고 rms_tolerance는 점군 단위의 잔차 기준입니다. 한편 inlier_threshold는 피팅 함수에 따로 전달하는 유한 양수 거리입니다. 설정과 점군 단위를 함께 보관하고, 실패할 경우 관측이 충분한 호와 축 범위를 포함하는지도 확인합니다.
