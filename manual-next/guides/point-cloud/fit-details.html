법선과 피팅 세부 결과

기본 estimate_normals는 중심점과 가장 가까운 유효 이웃을 사용해 PCA 법선을 추정합니다. neighbors는 2 이상이며 이웃 부족이나 퇴화된 이웃은 해당 슬롯을 결측으로 반환합니다. 법선은 viewpoint 쪽을 향하도록 정합니다. PlaneFit은 normal, offset, inliers, total, rms_error, max_error를 갖고 평면은 normal·p + offset = 0입니다. 임계 거리는 점군 단위이며 경계값도 포함합니다. CylinderFit은 axis_point, axis_direction, radius와 동일한 개수·오차 필드를 갖습니다. 유한 탐색이 전역 최적해를 보장하지 않으며, 원통은 짧은 호나 부족한 축 방향 범위 등에서 퇴화로 실패할 수 있습니다.

판독 기준

  • 세 거리가 1, 2, 3이면 RMS는 √(14/3) ≈ 2.16입니다.

수치와 도형은 연결된 계약의 핵심 관계를 설명하는 예입니다. 실제 SDK 출력으로 명시한 자료를 제외하면 실행 결과나 장비 실측으로 해석하지 않습니다. 좌표계·입력 형식·수명과 오류 조건은 관련 API 계약을 확인한 뒤 적용하세요.

평면의 법선과 offset은 n·p+d=0이라는 하나의 식을 이룹니다. 유효점 p와 단위 법선 n에 대해 |n·p+d|는 평면까지의 거리입니다. 따라서 (0,0,1), -4는 z=4인 평면을 뜻하고 (0,0,-1), 4도 같은 기하를 나타냅니다. inliers와 total을 보면 이 모델이 입력 유효점 중 어느 정도의 지지를 받는지 확인할 수 있습니다.

법선 추정은 중심과 이웃의 분포를 이용하므로 점이 없거나 충분한 방향 정보를 주지 못하면 해당 슬롯이 None입니다. viewpoint는 법선의 부호를 정하지만 데이터가 퇴화한 경우 새로운 기하를 만들어 주지는 않습니다. 원통 피팅은 축의 대표점·단위 방향·반지름과 잔차를 반환합니다. 좁은 호나 축 범위가 부족할 때는 퇴화나 불안정으로 실패할 수 있으므로 수치와 실제 관측 범위를 함께 판독합니다.

평면식의 거리

단위 법선 n=(0,0,1), offset d=−4는 평면 n·p+d=0, 즉 z=4를 나타냅니다. 점 (2,3,4)의 식 값은 0이고 점 (2,3,4.5)의 절대 잔차는 0.5입니다. 점군 단위가 mm라면 이 거리는 0.5 mm입니다. 법선과 offset의 부호를 함께 반대로 바꿔도 같은 평면이므로 모델을 비교할 때 수치 부호만 보지 않습니다.

법선 추정에서는 각 점의 이웃이 평면 방향을 정할 수 있어야 합니다. 점이 결측이거나 주변 점의 분포가 퇴화하면 해당 슬롯은 None입니다. 평면 결과의 inliers와 total은 서로 다를 수 있으며 rms_error와 max_error는 채택된 점에 대한 통계입니다. 원통 결과는 축과 반지름을 제공하지만 짧은 호처럼 제약이 부족한 경우 실패할 수 있으므로 관측 범위와 잔차를 함께 해석합니다.
