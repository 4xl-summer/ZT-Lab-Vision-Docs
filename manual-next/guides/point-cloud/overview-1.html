개념과 사용 흐름

PointCloud는 Vec<Option<Point3>>와 LengthUnit, frame을 보관합니다. share와 clone_deep을 구분하며 transform은 RigidTransform3를 적용합니다.

PointCloud는 점의 순서와 결측을 보존하는 공간 자료입니다. 각 슬롯은 유한한 Point3 또는 None이며 점군 전체에는 길이 단위와 0이 아닌 frame이 붙습니다. 서로 다른 frame의 점을 숫자만 비교하면 공간 관계를 잘못 해석할 수 있습니다. 점을 이미 측정한 경우 직접 생성하고, 격자 높이를 갖고 있다면 깊이 지도에서 좌표를 계산해 변환할 수 있습니다.

생성 후의 용도는 국소 법선, 전역 평면이나 원통, 다른 점군과의 정합으로 나뉩니다. 법선은 각 슬롯의 주변 기하가 충분한지에 따라 결측을 반환할 수 있고, 피팅은 채택점과 잔차를 가진 하나의 모델을 돌려줍니다. 정합은 초기 변환과 목표 점군이 필요합니다. share는 저장소를 공유하고 clone_deep은 별도 저장소를 만들므로 값의 복사와 객체의 수명을 구분합니다.

슬롯과 유효점의 차이

점군에 [(0,0,0), None, (1,0,0), (0,1,0)]을 저장하면 전체 슬롯은 4개지만 유효점은 3개입니다. None을 목록에서 삭제하면 뒤쪽 점의 인덱스가 바뀌므로 깊이 격자와의 위치 대응이 필요한 작업에서는 슬롯을 보존하는 편이 중요합니다. 반대로 (0,0,0)은 측정된 원점이며 누락값이 아닙니다. 좌표 값은 모두 점군에 지정한 단위와 frame으로 해석합니다.

평면 피팅은 유효점으로 형상을 요약하고 법선 계산은 각 점 주변 이웃을 따로 살핍니다. 위 세 유효점은 한 평면에 있지만, 실제 호출의 임계값과 이웃 조건을 만족하는지 확인해야 합니다. 정합을 하려면 목표 점군과 초기 변환이 추가로 필요하며 변환의 입력·출력 frame을 일치시켜야 합니다. 데이터를 사용한 후 소유 점군을 정리하고 결과 값의 수명을 구분합니다.

항목값·조건의미
슬롯 0(0,0,0)유효 원점
슬롯 1None결측
슬롯 2·3(1,0,0), (0,1,0)유효
