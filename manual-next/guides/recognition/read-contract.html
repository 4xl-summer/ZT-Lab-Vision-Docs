모델·문자와 판정

OCR은 신뢰할 수 있는 호환 RTen 인식 모델 바이트가 필요합니다. 인식 입력은 NCHW 4차원이며 배치 1, 고정 회색 채널 1, 높이 1–4096입니다. 출력 메타데이터가 있으면 [sequence,batch,labels]이며 고정 label 차원은 CTC 공백을 포함해 97입니다. 이는 임의 언어나 글꼴의 인식 정확도를 뜻하지 않습니다.

OcrSpec의 min_contrast는 유한한 0–1, min_length는 1 이상, max_length는 min_length 이상입니다. allowed_chars는 비어 있지 않은 출력 가능 ASCII(0x20–0x7e) 문자열입니다. 결과의 status와 reasons를 먼저 확인하고 text, chars의 codepoint와 네 모서리, contrast, 선택적 confidence를 사용하세요. 문자가 없거나 조건에 맞지 않으면 빈 문자열만으로 정상 판정하지 마세요. 대비가 임계값 미만이면 Rejected/LOW_CONTRAST, 대비가 0이고 임계값을 통과하면 NoRead/NOT_FOUND 및 EMPTY입니다.

OCR 스펙의 allowed_chars는 출력 가능 ASCII 문자의 비어 있지 않은 문자열이며, 이것은 결과에 적용하는 규칙입니다. 허용 목록을 바꾼다고 인식 모델의 학습 문자 집합 자체가 확장되는 것은 아닙니다. min_length는 1 이상이고 max_length는 그보다 작을 수 없습니다. min_contrast는 0부터 1 사이의 유한수로 원본 영역의 대비와 비교됩니다. 조건에 맞지 않는 텍스트는 이유 비트와 상태를 함께 해석합니다.

모델은 한 줄의 회색 영상 인식에 맞는 입력 메타데이터를 요구합니다. 출력 메타데이터가 제공될 때 고정 라벨 차원은 기본 문자와 CTC 공백을 포함한 97이어야 합니다. 읽힌 문자의 각 모서리는 입력 로컬과 글로벌 위치를 담고, confidence는 없을 수 있습니다. 빈 텍스트, 낮은 대비, 문자 집합 또는 길이 불일치를 서로 다른 진단으로 기록하고 실제 인식 성능은 모델과 검증 데이터에 연결합니다.

모델과 규칙의 역할

인식 모델의 라벨 차원과 후처리의 허용 문자는 서로 다른 역할을 가집니다. 모델 입력은 배치 1과 고정 회색 채널 1을 수용하는 NCHW이며 고정 높이는 1–4096입니다. 출력 메타데이터가 있을 때 고정 라벨 차원은 기본 알파벳 96개와 CTC 공백을 더한 97입니다. allowed_chars를 늘리는 것만으로 이 모델의 라벨 구성을 바꿀 수 없습니다.

예를 들어 허용 문자열이 ABC이고 읽힌 텍스트가 ABD라면 D는 허용 집합 밖이어서 문자 집합 이유를 확인해야 합니다. 길이 범위도 별도로 검사하므로 하나의 결과에 복수 이유가 있을 수 있습니다. 최소 대비는 0–1이고 원본 ROI의 밝기 범위를 255로 나눈 수치에 적용합니다. confidence는 선택값이어서 없을 수 있으며, 모델 적합성 오류와 수용 규칙에 따른 거절을 같은 상태로 처리하지 않습니다.
