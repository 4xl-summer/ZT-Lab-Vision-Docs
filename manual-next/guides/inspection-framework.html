검사 프레임워크

정렬, 차분, 후보와 판정의 연결

기준 영상과 검사 영상을 같은 좌표로 맞춘 뒤 유효한 표본에서 밝기 차이를 측정합니다. 정렬 실패는 결함 없음이 아니라 검사 불가입니다. 아래 값은 설명을 위한 합성 영상이며 현장 합격 기준이 아닙니다.

좌표와 수명

InspectionRect는 영상 로컬의 왼쪽 위와 너비·높이이며 끝 좌표는 제외합니다. 정렬 입력은 Gray8, Gray16, GrayF32이고 혼합 가능합니다. 기준 ROI는 양의 크기로 기준 영상 안에 있어야 하며 NCC 학습 영역에 밝기 변화가 필요합니다. 출력 Aligned는 기준 격자와 원점의 GrayF64, ValidMask는 같은 격자의 Gray8입니다. 변환 ReferenceToInspection은 기준 전역 좌표에서 검사 전역 좌표로 갑니다. 결과와 얻은 영상 각각을 해제하세요.

차분과 판정

포함 픽셀에서 기준 ≈ gain × 입력 + bias로 보정하고 잔차 r = gain × 입력 + bias − 기준을 계산합니다. None은 (1,0), Offset은 gain 1과 평균 차이, GainOffset은 선형 회귀를 사용하며 입력 분산이 0이면 gain 1로 처리합니다. 극성에 따라 |r|, max(r,0), max(−r,0)을 선택하고 점수 = 크기 / (threshold + textureWeight × 기준 국소 표준편차)입니다. 점수 1 이상은 마스크 255, 제외 픽셀 출력은 0입니다. 보정은 실제 결함도 흡수할 수 있으므로 보정용 영역과 한계를 검증하세요.

마스크의 연결 요소를 면적으로 필터하고 회전 사각형의 길이·폭·종횡비가 모두 스크래치 조건이면 Scratch, 아니면 Surface입니다. Judge는 개수, 총 면적, 최대 개별 면적, 허용 영역을 검사합니다. 상한과 같은 값은 허용하며 사유 비트는 함께 설정될 수 있습니다.

옵션과 결과

옵션계약
AlignmentSpecROI, MatchSpec, Nearest 또는 Bilinear, 유효 비율 (0,1]. 매치가 없거나 전체 기준 격자의 유효 비율이 미달이면 Found=false.
DifferenceSpecthreshold는 유한한 양수, 기본 correction None, polarity Absolute, textureKernel 1, textureWeight 0. 커널은 양의 홀수, 가중치는 유한한 0 이상.
DefectSpec연결성 4 또는 8, 최소 면적 양의 픽셀 수, 스크래치 길이·폭은 양의 유한값, 종횡비는 유한한 1 이상.
DecisionSpec개수·총 면적·개별 면적 상한은 0 이상 정수. 허용 사각형은 양의 크기이며 전체 후보 경계를 포함해야 합니다.

AlignmentInfo는 Found, Matched, ReferenceToInspection, ResidualRms, ValidCount를 제공합니다. RMS는 유효 픽셀의 보정 전 밝기 차이이며 위치 오차가 아닙니다. 미발견 시 정보는 기본값이고 영상 접근은 오류입니다. DifferenceInfo는 Gain, Bias, InspectedCount, MeanScore, MaxScore입니다. SurfaceDefect는 Kind, Area, Bounds, Centroid, Length, Width, Angle, MeanScore, MaxScore를 담습니다. 각도는 [−π/2, π/2) 라디안입니다. DecisionInfo는 Passed, Reasons, DefectCount, TotalArea, RejectionCount를 제공하며 개별 DefectRejection은 Index와 Reasons를 담습니다. 개수·총 면적 위반만으로 개별 기록이 생기는 것은 아닙니다.

실패와 대안

잘못된 옵션, 빈 포함 마스크, 크기·원점 불일치, 비유한 영상 값, 상수 NCC 학습 ROI는 오류입니다. 정렬 실패는 Found를 먼저 확인하고 재촬영 또는 검사 불가로 처리하세요. 원본의 차분만 필요하면 정렬을 생략하되 두 영상의 같은 크기와 원점 및 마스크 기하를 보장해야 합니다. 실제 생산 기준과 조명 안정성은 별도 검증이 필요합니다.

전체 합성 레시피와 관리형 검사 실행기를 참고하세요.

입력·출력 상세 계약

단계입력과 옵션출력과 수명
정렬검사 영상과 기준 영상은 유한한 Gray8·Gray16·GrayF32; ROI는 기준 로컬 반열림 사각형. 검색 각도는 −π ≤ 최소 ≤ 최대 ≤ π 라디안, 양의 각도 간격; 양의 최소 배율 ≤ 최대 배율, 양의 배율 간격; 점수 0–1, 억제 거리 0 이상 픽셀, 최대 매치 수 양수. 가장 높은 매치 사용.Found, Matched의 Position(검색 로컬), GlobalPosition, Angle, Scale, Score; ReferenceToInspection(전역 변환), ResidualRms(원시 밝기 RMS), ValidCount(픽셀). Aligned와 ValidMask는 각각 소유 영상. 결과도 해제.
차분reference는 Gray8·Gray16·GrayF32이며 source는 같은 형식 또는 정렬된 GrayF64입니다. 크기·원점이 같아야 합니다. includeMask는 같은 크기·원점의 Gray8, 비제로 포함, null은 전체. 선택 픽셀이 하나 이상이어야 함.SignedDifference, Score는 GrayF64, Mask는 Gray8. 모두 각각 해제. Gain과 Bias는 source 보정 계수, InspectedCount는 선택 픽셀 수, MeanScore와 MaxScore는 선택 픽셀 통계.
후보mask는 Gray8, score는 동일 크기·원점의 GrayF64. 모든 전경 점수는 유한하고 0 이상이어야 하며 면적 필터로 제거될 전경도 검사함.행 우선 발견 순서의 Defects 배열은 복사 스냅샷. 각 Bounds·Centroid는 로컬, Area는 픽셀 수, Length·Width는 픽셀 셀 외곽 회전 사각형의 길이, Angle은 라디안. 결과 핸들은 해제.
판정후보와 DecisionSpec. 영역은 비어 있지 않은 로컬 사각형이며 영상 크기로 제한되지 않음. 상한은 등호 포함.Passed; Reasons의 Count=1, TotalArea=2, SingleArea=4, Location=8; DefectCount, TotalArea, RejectionCount. Rejections는 인덱스와 SingleArea·Location 비트를 복사한 배열. 판정 결과는 해제.

오류 및 해제 분기

상황처리
유효 매치 없음 또는 유효 비율 부족정상 반환이지만 Found=false. Aligned/ValidMask 접근 시 네이티브 오류가 관리형 ZVisionException으로 전달됩니다. 검사 불가로 분기하고 결과를 해제합니다.
잘못된 ROI·범위·형식·원점, 비유한 값, 빈 마스크, 상수 학습 ROI네이티브 검증 오류가 ZVisionException으로 전달됩니다. 입력과 설정을 수정하고 재시도합니다. null 필수 참조는 ArgumentNullException입니다.
해제된 결과·영상 사용ObjectDisposedException. 자식 영상은 독립 임대이므로 결과보다 먼저 또는 나중에 각각 Dispose할 수 있습니다.
계산·크기 오버플로 또는 자원 부족실패로 처리하고 합격 판정에 사용하지 않습니다. 획득한 소유 객체는 using/finally에서 정리합니다.
