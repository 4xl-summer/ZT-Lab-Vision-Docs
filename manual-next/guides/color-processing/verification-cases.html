관련 검증 사례

색상 합성 검증은 입력 바이트의 순서와 출력 채널의 의미를 독립적으로 계산할 수 있는 값을 선택합니다. 예를 들어 RGB 빨강 (255,0,0)과 파랑 (0,0,255)은 HSV 색상각이 각각 0도와 240도입니다. 빨강을 BGR로 착각하면 결과를 반대로 해석하므로, 기대값 옆에 픽셀 형식과 채널 순서를 같이 적습니다. 각도와 Lab 거리의 단위도 구분합니다.

rust-color는 빨강의 변환과 역변환 경로를 다루는 합성 사례입니다. 채널을 획득하는 객체가 독립적으로 관리되는지도 호출 범위에서 확인해야 합니다. 합성 결과가 맞다는 것은 해당 입력과 변환 조건의 계산이 일치한다는 뜻입니다. 실물 색의 합격 기준을 정하려면 조명과 카메라, 백색점, 기준색 및 보류 샘플을 사용해 별도로 평가해야 합니다. 두 사례에서 사용한 백색점과 RGB 입력 해석 조건은 결과 비교의 일부입니다. 색 채널의 수명도 원본 영상과 분리해 확인합니다.

수치와 소유권 확인

빨강과 파랑의 합성 RGB 픽셀은 채널 순서의 점검에 적합합니다. 색상각은 각각 0도와 240도입니다. Lab 거리 계산도 손으로 검산할 수 있는 값으로 시험할 수 있습니다. 예를 들어 성분 차가 (3,4,0)이면 ΔE76은 5입니다. 이 계산은 같은 백색점과 표현의 Lab 값 사이에서만 해석해야 하며 HSV 각도에 그대로 적용하지 않습니다.

rust-color의 역변환은 별도의 빨간 합성 입력과 기대 배열을 사용합니다. 변환 전 영상과 얻은 채널, 결과 영상을 어떤 범위에서 보유했는지도 확인해 닫힌 핸들 문제를 픽셀 오차와 구분합니다. 이런 비교는 SDK 경로의 재현성을 확인합니다. 실제 장비의 측정 공차를 정할 때는 같은 조명과 노출에서 얻은 독립 표본, 기준색과 사용한 색차식을 함께 기록해야 합니다.
