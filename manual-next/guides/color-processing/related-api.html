관련 API

색 영상을 회색으로 바꾸는 to_gray는 명도 기반 처리의 출발점이고, to_hsv와 to_lab은 서로 다른 색 표현의 채널을 제공합니다. 원본 형식을 확인한 뒤 필요한 성분을 선택하고 ColorPlanes에서 해당 채널을 획득합니다. HSV의 색상각과 Lab의 L*, a*, b*는 값의 단위와 의미가 다르므로 한 표현의 임계값을 다른 표현에 그대로 적용하지 않습니다.

white_balance와 color_correct는 후속 측정에 쓰일 영상을 보정하며, color_statistics는 선택 영역의 값을 요약합니다. 두 색의 거리를 비교할 때는 기준색과 변환 조건, 거리식을 함께 저장해야 합니다. ΔE76은 Lab 좌표의 유클리드 거리이고 다른 고급 색차식에는 별도 가중 설정이 있습니다. 각 결과 평면과 채널의 소유권을 확인하고 실제 장비 측정은 합성 예와 따로 검증합니다. 채널을 획득한 후에는 원본과 결과의 해제 시점을 각각 기록하는 것이 명확합니다.

출력 표현에 따른 다음 단계

색 영상에서 밝기 기준 마스크가 필요하면 회색 변환의 입력 형식과 출력 값을 확인한 뒤 임계값 처리를 연결합니다. 색상 자체를 구별하려면 HSV의 H/S/V 또는 Lab의 L*/a*/b* 중 목적에 맞는 채널을 획득합니다. 예를 들어 빨강의 HSV H는 0도지만 Lab의 첫 채널 L*은 명도이므로 이 둘은 서로 교환할 수 있는 값이 아닙니다.

보정과 통계는 처리 순서를 명시해야 재현됩니다. 원본에 대해 통계를 낸 것인지 white_balance 또는 color_correct 후 결과에 대해 낸 것인지 기록하고, 거리 계산에는 동일 백색점과 색 인코딩의 기준색을 사용합니다. ColorPlanes 및 채널의 소유 기간을 정하고, 자료 형식이 지원되지 않거나 객체가 닫힌 호출은 결과 수치와 분리해 오류로 처리합니다. 실제 장면에 적용할 공차는 독립 검증으로 정합니다.
