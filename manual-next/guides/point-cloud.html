PointCloud · 점군

3D 점군 수명과 법선, 평면·원통 피팅, ICP 정합.

개념과 사용 흐름

PointCloud는 Vec<Option<Point3>>와 LengthUnit, frame을 보관합니다. share와 clone_deep을 구분하며 transform은 RigidTransform3를 적용합니다.

오류·주의사항

fit_plane, fit_cylinder, estimate_normals, register_icp는 각각 형상/법선/정합 결과를 반환합니다. ICP의 초기값과 국소 최소에 대한 민감도를 검증해야 합니다.

검증 기준

점군을 섞기 전 unit·frame을 확인하고 이상치와 피팅 잔차를 기록하세요.

관련 설명 열기

점군과 정합의 결과 판독

점군은 유효한 점과 결측 슬롯, 길이 단위, 0이 아닌 frame을 갖습니다. 변환의 입력·출력 frame과 단위가 데이터와 일치해야 합니다. 법선은 점별 선택값이므로 결측을 확인합니다. 평면·원통 피팅의 inliers와 total, 잔차를 보고 결과의 충분성을 판단하세요.

점대점 ICP는 초기 변환으로 원본을 대상 frame에 보낸 뒤 대응점을 찾아 정합합니다. IcpOptions의 max_iterations는 양수, max_distance는 유한 양수, trim_fraction은 (0,1], rms_tolerance는 유한한 0 이상입니다. 거리는 점군의 단위입니다. 최소 유효점은 양쪽 각각 3개이며 단위와 초기 변환의 frame이 일치해야 합니다. 결과의 transform, iterations, inliers, rms, converged를 함께 확인하세요. 수렴은 허용 정확도를 보증하지 않으므로 독립 점과 사용 공차로 검증합니다.

법선과 피팅 세부 결과

기본 estimate_normals는 중심점과 가장 가까운 유효 이웃을 사용해 PCA 법선을 추정합니다. neighbors는 2 이상이며 이웃 부족이나 퇴화된 이웃은 해당 슬롯을 결측으로 반환합니다. 법선은 viewpoint 쪽을 향하도록 정합니다. PlaneFit은 normal, offset, inliers, total, rms_error, max_error를 갖고 평면은 normal·p + offset = 0입니다. 임계 거리는 점군 단위이며 경계값도 포함합니다. CylinderFit은 axis_point, axis_direction, radius와 동일한 개수·오차 필드를 갖습니다. 유한 탐색이 전역 최적해를 보장하지 않으며, 원통은 짧은 호나 부족한 축 방향 범위 등에서 퇴화로 실패할 수 있습니다.

피팅 옵션의 기본값과 제약

옵션기본값과 의미허용 조건
PlaneFitOptions.hypothesis_iterations / refinement_iterations512 / 64, 가설 및 정제 한도각각 1 이상
PlaneFitOptions.max_outlier_fraction1−f64::EPSILON, 허용 이상치 비율유한한 [0,1)
PlaneFitOptions.rms_tolerance0, 개선 중단 허용치, 점군 단위유한한 0 이상
CylinderFitOptions.max_iterations50, 단계별 반복 한도1 이상
CylinderFitOptions.max_outlier_fraction0.5−f64::EPSILON유한한 [0,1); 실제 피팅은 과반 지지가 필요
CylinderFitOptions.initial_axisNone, 자동 시드; 지정 시 정규화해 사용유한하고 0이 아닌 축
CylinderFitOptions.step_tolerance / rms_tolerance1e−10 무차원 / 0 점군 단위유한한 양수 / 유한한 0 이상
target_inlier_fraction (양쪽)None, 조기 종료 비활성지정 시 유한한 (0,1]

평면과 원통의 inlier_threshold는 유한 양수이며 점군 단위입니다. 유효점 부족이나 퇴화, 허용치 밖 설정은 오류로 반환합니다. Python 기본 fit_plane/fit_cylinder는 threshold만 받습니다. 언어별 고급 옵션 노출 여부는 해당 참조를 확인하세요.
