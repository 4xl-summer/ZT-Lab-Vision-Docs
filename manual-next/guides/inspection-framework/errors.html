상위 목차로 돌아가기

실패와 대안

잘못된 옵션, 빈 포함 마스크, 크기·원점 불일치, 비유한 영상 값, 상수 NCC 학습 ROI는 오류입니다. 정렬 실패는 Found를 먼저 확인하고 재촬영 또는 검사 불가로 처리하세요. 원본의 차분만 필요하면 정렬을 생략하되 두 영상의 같은 크기와 원점 및 마스크 기하를 보장해야 합니다. 실제 생산 기준과 조명 안정성은 별도 검증이 필요합니다.

전체 합성 레시피와 관리형 검사 실행기를 참고하세요.

정렬이 실패한 경우와 정렬 호출 자체가 오류인 경우는 다르게 처리합니다. 학습 무늬에 맞는 위치가 없거나 최소 유효 비율을 채우지 못하면 발견되지 않은 출력이 돌아올 수 있습니다. 이때 차분을 생략하고 재촬영 또는 분석 불가 상태로 넘겨야 합니다. 발견되지 않은 출력에서 정렬 영상 데이터가나 유효 마스크를 바로 꺼내려고 하면 오류가 발생합니다.

반대로 ROI가 비어 있거나 입력 형식과 원점이 맞지 않는 경우, 잘못된 설정 또는 비유한 밝기 값은 입력 오류로 조사합니다. 포함 마스크가 모든 픽셀을 제외해도 비교할 집단이 없어 정상 합격으로 볼 수 없습니다. 실패 지점을 기록할 때에는 원본 영상 데이터의 형식과 ROI, 검색 범위, 유효 픽셀 수를 함께 남기고, 이미 소유한 영상 데이터와 출력은 예외가 난 경로에서도 정리합니다.

정렬이 안 된 영상 데이터를 원본 기준에 바로 비교하면 이동 때문에 넓은 차이가 발생할 수 있습니다. 재촬영 여부는 발견 상태와 입력 조건을 확인한 다음 결정합니다.

각 단계의 중단 기준

정렬이 성공하기 전에는 같은 기준 좌표에서의 픽셀 차분을 전제로 삼지 않습니다. NCC 학습 영역이 상수이거나 ROI가 범위 밖이면 입력 검증 오류가 발생할 수 있고, 매치가 없거나 유효 비율이 부족하면 미발견 결과가 될 수 있습니다. 두 경우 모두 후속 합격 판정이 존재하는 것처럼 기록하지 않되 원인은 서로 구분합니다.

차분까지 성공한 경우에도 후보 추출 입력을 다시 확인합니다. 마스크는 Gray8, 점수는 같은 격자의 GrayF64이며 연결 방식은 4 또는 8입니다. minimum area를 키우면 작은 전경이 후보에서 빠질 수 있으므로 원시 마스크와 후보 개수가 다른 것은 반드시 오류가 아닙니다. 반면 전경 점수가 음수이거나 비유한 값이면 검증 오류로 처리합니다.

Judge의 각 한도는 등호를 포함하고 허용 사각형은 비어 있으면 안 됩니다. 개별 면적과 위치 사유가 없는 후보라도 전체 개수 또는 총 면적이 한도를 넘을 수 있습니다. 결과가 실패한 경우 Reasons와 각 Rejections를 각각 보고, 예외가 발생한 경우는 실패한 연산 단계와 이미 소유한 자원의 정리 상태를 기록합니다.
