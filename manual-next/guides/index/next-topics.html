원리와 입력

기본 영상 처리 외에도 계측, 정렬 검사, 색과 공간 데이터처럼 다른 입력과 결과를 다루는 주제가 있습니다. 프로파일과 캘리퍼는 지정한 경로의 밝기와 에지 위치를 읽고, 평면 보정은 글로벌 픽셀과 세계 길이 단위를 연결합니다. ROI 로컬 점을 보정에 넘길 때 원점을 얼마나 적용해야 하는지 먼저 확인해야 수치가 올바른 프레임에 놓입니다.

적용과 확인

정렬 검사는 Found와 유효 마스크를 확인한 다음 차이와 결함 판정을 수행합니다. 색상과 깊이 작업은 채널 표현, 단위와 결측값 조건을 따로 가집니다. 가이드의 합성 수치와 허용 오차는 API 흐름을 설명하기 위한 것이며 실제 센서 정확도를 입증하지 않습니다. 관심 주제에서 입력·설정·출력 필드와 실패 상태를 읽고 해당 실행 예제로 연결하세요.

읽기와 적용

계측은 단순한 이미지 변환과 달리 추출한 위치의 방향, 단위와 실패 상태를 함께 해석해야 합니다. 프로파일의 에지가 충분하지 않으면 선이나 원의 피팅 결과도 충분하지 않을 수 있습니다. 정렬 기반 차이 검사에서는 먼저 정렬이 발견됐는지와 유효 영역이 있는지 확인해야 합니다. 깊이와 색상 자료는 각각 결측 및 색 인코딩이라는 다른 전제를 가지므로 필요한 가이드에서 그 조건을 먼저 읽습니다.
