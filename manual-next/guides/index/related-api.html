관련 API

원리와 입력

가이드에 연결되는 API는 작업의 단계에 따라 선택합니다. ZImage의 직접 처리로 새 영상을 얻는지, MatchModel을 학습해 결과 값을 얻는지, ImageQuery로 여러 단계를 실행하는지 먼저 구분하세요. 같은 영상에서 시작해도 각 반환 객체와 종료 방식은 다릅니다. 처리할 ROI가 있다면 원점과 보이는 크기를 입력 조건에 포함합니다.

적용과 확인

계측에는 프로파일과 캘리퍼, 보정 값과 세계 단위가 함께 등장합니다. 정렬 검사에서는 AlignmentResult의 발견 상태와 ValidMask가 다음 차이 계산의 전제가 됩니다. 공간 데이터에서는 DepthMap과 PointCloud의 단위와 프레임을 확인해야 합니다. 세부 API의 매개변수 범위 및 결과 의미는 언어별 선언을 기준으로 읽고, 합성 예제의 기대값으로 호출 순서를 검증하세요.

읽기와 적용

예를 들어 검출한 ROI 안의 에지를 세계 길이로 해석하려면 프로파일 또는 캘리퍼 결과가 로컬 좌표인지 확인하고 원본 좌표로 옮긴 뒤 평면 보정을 적용합니다. 정렬 검사의 유효 마스크는 비교 가능한 픽셀 영역을 뜻하며, 정렬 실패를 결함이 없다는 뜻으로 바꾸면 안 됩니다. 사용하려는 언어의 상세 API에서 각 결과 필드와 수명을 확인하고, 독립적으로 계산 가능한 합성 입력으로 호출 경로를 먼저 확인합니다.
