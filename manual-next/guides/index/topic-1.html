원리와 입력

알고리즘 가이드는 입력을 어떤 값으로 해석하고 결과를 어떻게 판독하는지에 따라 선택합니다. 임계값은 밝기 기준으로 이진 마스크를 만들고, Blob은 마스크에서 연결된 전경 영역을 분석합니다. 매칭은 템플릿과 검색 조건을 준비해 위치와 점수를 얻는 흐름입니다. 각 단계의 반환 형식과 좌표계가 다음 단계의 입력 조건에 맞는지 확인해야 합니다.

적용과 확인

예를 들어 [9,10,11]의 Gray8 한 행에 10을 적용하면 [0,255,255]입니다. 이 출력의 255는 전경 표시이지 원래 밝기 10과 11을 보존한다는 뜻이 아닙니다. 분석을 이어갈 때는 원본 영상도 따로 보관해야 합니다. 실제 입력의 형식과 ROI, 모델 수명, 미발견 또는 빈 결과의 처리 방법을 해당 가이드와 API 참조에서 함께 살펴보세요.

읽기와 적용

여기서 가이드는 기능을 고르는 지도 역할을 합니다. 노이즈를 먼저 줄이려면 필터의 커널과 경계 조건을 보고, 이진 영역을 찾으려면 임계값 뒤에 연결성 및 Blob 분석을 살펴봅니다. 기존 모양의 위치가 필요하다면 템플릿과 검색 범위를 갖는 매칭으로 이동합니다. 각 단계의 출력 형식이 다음 입력의 지원 형식과 맞는지 확인해야 연결된 처리가 의미 있는 결과를 냅니다.
