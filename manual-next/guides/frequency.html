FFT · 주파수 필터

주파수 스펙트럼 생성과 필터·역변환.

개념과 사용 흐름

FrequencySpectrum.Forward는 스펙트럼을 소유하고 Values는 스펙트럼 뷰를 제공합니다. Filtered·Masked는 필터링 결과를 만들고 Inverse·InverseImage는 공간 영상으로 되돌립니다.

관련 공개 API

객체/메서드구분

FrequencySpectrum.Values관련 공개 객체·메서드
FrequencySpectrum.Filtered관련 공개 객체·메서드
FrequencySpectrum.InverseImage관련 공개 객체·메서드

오류·주의사항

FftNormalization, 패딩, crop과 복소 스펙트럼을 구분해야 합니다. C# FrequencySpectrum은 IDisposable입니다.

검증 기준

원본·역변환의 오차와 주파수 마스크 해석을 시험해야 합니다.

관련 설명 열기

정규화와 복소 결과

2차원 DFT는 F(u,v)=Σ f(x,y) exp(-2πi(ux/W+vy/H))입니다. 주파수 배열은 시프트하지 않아 DC가 (0,0)에 있습니다. 크기 영상만으로 위상을 복원할 수 없으므로 필터와 역변환에는 실수부와 허수부를 함께 보존하십시오.

항목계약
입력Gray8, Gray16, 유한한 GrayF32
크기폭·높이 각각 2의 거듭제곱, 입력 이상; 곱 ≤ 4,194,304. 남는 영역은 0 패딩
Backward순변환 배율 1, 역변환 1/(W×H)
Orthonormal양방향 각각 1/√(W×H)
마스크실수/허수 양쪽에 곱함; 길이와 유한값 검사
역변환실수 영상 출력; 정수 형식은 반올림 및 범위 제한
크기 초과, 비유한 값오류; 크기와 값을 먼저 확인

합성 2×2 전부 1은 Backward 순변환에서 DC=4, 나머지=0입니다. 무필터 역변환으로 재구성 오차를 확인한 뒤 필터를 적용하십시오.

합성 입력 전체 예제

이 예제는 합성 입력을 사용합니다. 실제 촬영 데이터나 실행 성능을 나타내지 않습니다.

Rust
use zvision::{FftNormalization, FftOptions, ZImage, ZResult};
fn main() -> ZResult<()> {
    let image = ZImage::from_vec_gray8(2, 2, vec![1, 1, 1, 1])?;
    let spectrum = image.fft(FftOptions { width: 2, height: 2,
        normalization: FftNormalization::Backward })?;
    let (real, imaginary) = spectrum.parts();
    println!("real={real:?}, imaginary={imaginary:?}");
    let (_, _, restored) = spectrum.inverse_values(true)?;
    println!("restored={restored:?}");
    Ok(())
}

기대 실수부는 [4, 0, 0, 0], 복원값은 [1, 1, 1, 1]입니다. 부동소수점 허용 오차로 비교하십시오.

스펙트럼 필드와 수명

Rust 항목의미
FftOptions.width, height기본값 없는 변환 크기; 입력 이상인 2의 거듭제곱
normalizationBackward 또는 Orthonormal; 변환과 역변환에 함께 저장
dimensions(), source_dimensions(), origin()패딩 크기, 원래 크기, ROI 원점
view(mode)Amplitude=√(re²+im²), Power=amplitude², Phase=atan2(im,re), LogAmplitude=ln(1+amplitude)
parts()행 우선 복소 실수부·허수부 슬라이스; Spectrum 수명에 묶임
masked(), filtered()별도 소유 Spectrum; 길이 불일치·비유한 마스크는 오류
inverse_values(crop)true는 원본 크기로 잘라 (폭, 높이, 값 배열) 반환
수명·실패Spectrum은 입력 해제 후 유지; 크기 제한·비유한 입력·할당 실패는 오류

일반 DFT는 별도 API와 별도 크기 제한을 가집니다. 위 radix-2 FFT의 제한을 일반 DFT에 적용하지 마십시오.

주파수 필터 선택

필드조건과 의미
profileIdeal, Gaussian 또는 Butterworth; Butterworth 차수는 1..16
passLow, High, Band, Notch. 주파수 단위는 픽셀당 주기이며 각 축은 래핑됨
low, highlow는 유한 양수. Band에서는 high > low, 다른 pass에서는 high=0
center_x, center_yNotch에서는 각각 -0.5..0.5, 그 외에는 0; ±중심을 함께 억제
경계 오류유한하지 않은 값, 잘못된 차수·반경·중심은 오류. 값의 단위와 pass 조합을 확인

Ideal은 차단 경계가 날카롭고 공간 영역 링잉이 생길 수 있습니다. Gaussian은 완만하게 감쇠합니다. 결과 이미지와 스펙트럼 양쪽에서 신호 손실을 확인하십시오.
