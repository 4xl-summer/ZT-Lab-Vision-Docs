Rust 호출 부분

최소 11×5 픽셀의 ROI 영상을 호출자가 제공하는 함수입니다. Result는 입력 영상과 독립된 스냅샷이고 samples()/edges()는 그 결과를 빌려 읽습니다.

Rust
use zvision::{CaliperSpec, EdgePolarity, Point2, ProfileSpec, ZImage, ZResult};

fn inspect(image: &ZImage) -> ZResult<()> {
    let profile = ProfileSpec { start: Point2 { x: 2.0, y: 4.0 },
        end: Point2 { x: 10.0, y: 4.0 }, samples: 9, width: 1 };
    let samples = image.profile(&profile)?;
    let spec = CaliperSpec { profile, polarity: EdgePolarity::Rising, threshold: 10.0 };
    let edges = image.caliper(&spec)?;
    for sample in samples.samples() { println!("{} {}", sample.distance, sample.value); }
    for edge in edges.edges() { println!("{} {}", edge.distance, edge.strength); }
    Ok(())
}

이 함수는 호출자가 준 영상에 동일한 선분 설정을 두 번 사용합니다. 처음에는 아홉 표본의 위치와 평균 강도를 얻고, 다음에는 같은 곡선에서 상승 에지를 찾습니다. 시작점은 (2,4), 끝점은 (10,4)이므로 최소 11×5 픽셀의 ROI가 필요하며, 두 점을 포함한 간격은 1픽셀입니다. 폭 1은 각 위치에서 중심선만 샘플링한다는 뜻입니다.

프로파일 설정은 값 타입으로 캘리퍼 설정에도 들어갑니다. 반환값의 샘플 및 에지 슬라이스는 각 결과 객체에서 빌려 읽으며, 입력 영상을 버린 뒤에도 결과 스냅샷은 소유한 값을 유지합니다. 다만 빌린 슬라이스는 그 결과보다 오래 사용할 수 없습니다. 상승 피크가 없으면 에지 목록이 비어 있을 수 있으므로 출력 반복이 실행되지 않는 것과 함수 오류를 구별하십시오.

임계값 10의 단위는 밝기 자체가 아닌 원시 강도/픽셀입니다. 어두운 쪽에서 밝은 쪽으로 읽는 방향이 맞는지 확인하고, 다른 이미지 형식이나 작은 ROI를 전달한다면 타입과 선분의 유효 범위를 먼저 확인합니다.
