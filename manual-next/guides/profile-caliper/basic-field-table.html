기본 프로파일·캘리퍼 필드

필드 / 타입의미 · 단위 · 유효 조건
start, end: Point2ROI 로컬 픽셀 중심; 각 좌표 유한, 두 점 사이 길이 양수이며 전체 스트립은 영상 안에 있어야 함.
samples: usize / Samples: ulong양 끝을 포함한 표본 수 3 이상. 거리 간격 = 선분 길이/(samples−1).
width: usize / Width: ulong법선 방향 샘플 개수; 양의 홀수, 인접 표본 간격 1 픽셀.
profile: ProfileSpec에지 탐색에 사용할 위 설정.
polarity: EdgePolarityRising, Falling, Any 중 하나. 시작→끝 방향 기준.
threshold: f64 / Threshold: double원시 강도/픽셀; 유한한 0 이상. 크기가 정규화된 비율이 아님.

Rust와 C# 모두 여기에 명시된 유효한 기본값을 자동 선택하는 생성자를 가정하지 않습니다. C# 생성자는 값을 저장하며 연산 시 검증합니다. 결과 위치는 ROI 로컬 픽셀, distance는 시작점부터 픽셀, value는 원시 강도 평균, strength는 부호 있는 원시 강도/픽셀입니다.

start와 end는 단지 영역의 두 모서리가 아니라 한 방향으로 읽는 선분을 정의합니다. 표본 수가 9이고 길이가 8픽셀이면 중심 위치는 한 픽셀 간격으로 배치됩니다. 폭이 3이면 각 중심에서 법선 방향으로 −1, 0, +1 위치의 값을 평균합니다. 전체 띠가 ROI에 들어가지 않는 경우 기본 프로파일은 오류가 됩니다.

캘리퍼는 프로파일 설정 위에 극성과 강도 변화량의 최소 기준을 더합니다. 상승 또는 하강은 시작점에서 끝점으로 움직이는 방향 기준이므로 같은 영상을 반대로 읽으면 해석이 바뀝니다. 출력의 위치는 로컬 픽셀, 거리는 시작점부터의 픽셀, 강도는 부호 있는 원시 강도/픽셀입니다. 이 값들을 세계 거리로 기록할 때는 좌표 변환과 단위를 명시해야 합니다.

표본은 선분 끝을 포함하므로 개수가 늘어나면 같은 길이를 더 촘촘히 살핍니다. 이때 피크 강도는 표본 번호가 아니라 실제 거리 차이로 나눈 값입니다. 영상 형식이 바뀌면 원시 강도의 수치 범위도 함께 확인해야 합니다.
