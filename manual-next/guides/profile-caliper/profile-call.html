C# 호출 부분

아래는 기존 ROI 영상이 최소 11×5 픽셀인 경우의 호출 부분입니다. 실행 가능한 독립 fixture는 예제에서 확인합니다.

C#
// image는 해당 ROI를 가진 기존 ZImage입니다.
var spec = new ProfileSpec(new Point2(2, 4), new Point2(10, 4), 9, 1);
ProfileResult profile = image.Profile(spec);
var edgeSpec = new CaliperSpec(spec, EdgePolarity.Rising, 10.0);
CaliperResult edges = image.Caliper(edgeSpec);
foreach (var sample in profile.Samples)
    Console.WriteLine($"{sample.Distance}: {sample.Value}");
foreach (var edge in edges.Edges)
    Console.WriteLine($"{edge.Position.X}, {edge.Position.Y}: {edge.Strength}");

호출 조건은 ce902e85c340 소스의 공개 계약과 대조했습니다. 합성 예의 예상 수치는 손계산이며 실행 기록을 별도로 확인해야 합니다. 장비 실측과 생산 정확도는 미검증입니다.

이 C# 예시는 이미 존재하는 image를 받는 호출 부분입니다. 지정된 중심선은 (2,4)에서 (10,4)까지이며 영상의 ROI가 이 점들을 포함해야 합니다. 표본 수 9는 양 끝 포함이므로 수평 위치가 1픽셀 간격이고, 폭 1은 중심선 밖의 값을 평균에 추가하지 않습니다.

프로파일을 먼저 읽으면 예상한 명암 변화가 실제 입력에 있는지 확인할 수 있습니다. 이후 상승 극성과 임계값 10을 적용한 캘리퍼 결과를 거리순으로 살펴보십시오. 영상에 해당 상승 피크가 없으면 유효한 빈 결과가 나옵니다. 입력 설정이 범위를 벗어난 오류와 빈 목록을 구분하고, 다른 ROI에서 같은 숫자의 좌표를 사용한다면 그 ROI 기준으로 선이 올바르게 배치되는지 다시 확인해야 합니다.

첫 단계가 반환하는 목록은 표본이고 두 번째 목록은 그중 변화 피크를 보간한 에지입니다. 둘은 길이가 같을 필요가 없으며, 에지가 발견되지 않았다고 프로파일 표본 자체가 없는 것은 아닙니다.

예시의 선분 좌표는 화면상의 정수 픽셀 위치이지만 보간된 검출 에지는 두 표본 사이의 소수 위치일 수 있습니다. 반환 거리와 위치를 함께 읽으십시오.
