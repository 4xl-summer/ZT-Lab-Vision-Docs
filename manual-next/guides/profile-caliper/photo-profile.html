    처리 순서

    1. 프로파일 · ZImage.profile 폭 1, 양 끝 포함 표본을 원본 배열과 대조합니다.
    2. 에지 · ZImage.caliper 양쪽 극성의 에지 중 강도 절댓값이 가장 큰 결과를 표시합니다.

    표시 영역과 실제 처리 범위

    전체 영상에 중앙 가로 한 줄의 양 끝과 표본 수를 지정하여 프로파일과 에지를 계산합니다. 사각형은 전체 영상 표시 범위입니다.

    전체 영상 표시 범위: x=0, y=0, 폭=512, 높이=512 px. 이 사각형의 의미와 실제 연산 범위는 위 설명을 따릅니다.

    width = 1
