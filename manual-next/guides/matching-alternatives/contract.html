상위 목차로 돌아가기

입력, 좌표와 소유권

학습과 검색은 Gray8, Gray16, 유한한 GrayF32의 보이는 ROI를 사용합니다. 학습 마스크는 선택 사항이며 Gray8, 템플릿과 같은 크기 및 원점이어야 합니다. 0은 제외, 0이 아닌 값은 포함입니다. 선택된 픽셀은 두 개 이상이고 같은 값만 있어서는 안 됩니다. 모델은 픽셀과 마스크를 복사하므로 학습 후 템플릿을 해제해도 됩니다.

기준점은 템플릿 로컬 ((width−1)/2, (height−1)/2)입니다. 검색 결과의 위치는 검색 ROI 로컬 기준점이고 전역 위치는 여기에 검색 영상 원점을 더한 값입니다. 변환된 템플릿의 네 모서리 전체가 ROI 안에 있어야 평가합니다. 마스크로 모서리를 제외해도 이 조건은 변하지 않습니다. 회전과 배율에 따라 영상은 쌍선형 보간됩니다.

적용 상황과 원리

모델 선택 시 입력 조건도 결정 기준입니다. 기본 NCC는 Gray8, Gray16 또는 유한 GrayF32 템플릿과 검색 영상을 받습니다. 선택 Gray8 마스크는 템플릿과 크기와 원점이 같아야 하며 0이 아닌 픽셀을 학습에 사용합니다. 두 개 이상이 선택되고 모두 같은 값이 아니어야 합니다. 형상 모델은 추가로 유효한 기울기와 최소 특징점 조건을 가집니다.

결과를 읽는 방법

검색 결과의 기준점은 템플릿의 중심이며 위치는 검색 ROI 로컬 좌표입니다. 전역 좌표는 검색 영상 원점을 더해 얻습니다. 변환된 템플릿의 네 모서리가 ROI 안에 들어와야 기본 모델을 평가합니다. 별도의 bounded 색 NCC는 RGB8, Gray SAD는 Gray8을 사용하고 정수 평행이동을 검색하므로 기본 NCC의 회전·배율 결과와 좌표 기준을 그대로 혼동하면 안 됩니다. 각 모델의 입력과 좌표 정의를 검토한 후 같은 사례로 비교하세요.

추가 점검

Gray SAD에서 반환하는 좌표는 별도 bounded 모델의 정수 좌상단입니다. 기본 MatchModel의 중심 기준점과 직접 비교하려면 모델 크기를 이용해 좌표를 변환해야 합니다. 이러한 기준 차이를 무시하면 정확한 검출도 위치 오차처럼 보입니다.
