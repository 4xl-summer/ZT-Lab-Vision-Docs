관련 API

적용 상황과 원리

기본 모델의 MatchModel과 MatchSpec은 템플릿 학습, 회전·등방 배율 격자와 결과 조건을 담당합니다. Find가 반환하는 스냅샷에는 위치, 점수와 자세가 포함되며 입력 영상이 ROI인 경우 로컬 위치와 원점을 더한 전역 위치를 구분합니다. 마스크는 선택할 학습 표본을 정하지만 전체 템플릿 경계의 적합 조건을 없애지 않습니다.

결과를 읽는 방법

확장 모델은 별도의 기준점과 검색 옵션을 사용하고 후보 예산이나 피라미드 검색 등의 경로가 따로 있습니다. BoundedTemplateModel은 색 NCC 또는 Gray SAD용이고 정수 위치 범위와 작업 한도를 명시합니다. 형상 모델의 기울기 조건과 결과는 해당 모델의 계약을 확인해야 합니다. 선택한 모델을 유지할 때는 학습 입력, 옵션 및 검증 사례를 함께 관리합니다.

추가 점검

각 모델의 학습·검색 API가 요구하는 영상을 준비하고 검색 조건을 명시한 뒤 결과의 좌표와 점수 방향을 확인합니다. 필요하다면 같은 이미지의 적절한 회색 또는 색상 표현을 준비하되, 데이터 변환의 영향도 별도로 측정해야 비교가 공정해집니다. 검색이 끝난 뒤에는 각 결과 객체의 소유권과 빈 결과 표현도 따로 확인합니다. 객체를 바꿀 때 호출 순서와 반환 타입을 먼저 살펴봅니다.

작업 단계의 책임

조건확인할 내용
학습템플릿에서 모델과 기준점 정보를 만듭니다.
검색별도 설정과 영상으로 포즈 후보를 찾습니다.
판독빈 결과를 처리하고 로컬·전역 좌표를 구분합니다.
