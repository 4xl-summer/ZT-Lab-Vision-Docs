어떤 모델을 선택할까

방법적합한 조건확인할 점
NCC안정된 내부 명암 패턴과 완만한 밝기 변화가림과 비강체 변형은 기본 모델의 가정 밖입니다.
Shape명암보다 경계 방향이 식별에 유용한 경우기울기 임계값은 원시 강도/픽셀 단위이며 3×3 이상과 특징점 3개 이상이 필요합니다.
확장 NCC기준점, 별도 검색 격자 또는 피라미드가 필요한 경우별도 모델과 옵션의 검색·예산·좌표 계약을 확인합니다.
Color NCC / Gray SAD색 정보 또는 절대 밝기 차이가 판별에 중요한 경우별도 bounded 모델이며 색 NCC는 RGB8, SAD는 Gray8입니다.

같은 점수 숫자가 서로 다른 모델의 동일한 신뢰도를 의미하지 않습니다. 후보 모델을 같은 양품·불량 세트에서 누락률, 오검출, 시간으로 비교하세요.

적용 상황과 원리

모델 선택은 대상이 어떤 특징을 안정적으로 유지하는지부터 시작합니다. 내부 명암 무늬가 식별에 유용하고 조명이 대체로 일정한 오프셋이나 양의 배율로 변한다면 NCC가 출발점입니다. 평균을 제거한 패턴의 상관으로 후보를 비교하므로 선택 표본에 밝기 차이가 있어야 합니다. 부분 가림이나 큰 변형을 항상 견딘다고 가정할 수는 없습니다.

결과를 읽는 방법

형상 모델은 내부 밝기보다 경계 방향이 구별에 유용한 경우 검토합니다. 기울기 하한과 최소 특징점 수가 있으므로 대비가 약한 경계나 과도한 임계값을 확인해야 합니다. 색 정보가 필요하면 RGB8 색 NCC가 있고 절대 밝기 차이가 중요하면 Gray8 SAD 모델을 별도로 선택할 수 있습니다. 이들은 입력 형식, 점수 방향과 옵션이 다릅니다. 같은 정상·불량 및 혼동 배경에서 누락, 오검출과 처리 시간을 비교해 선택하세요.

추가 점검

선택한 방법은 모델의 최소 학습 조건도 만족해야 합니다. 형상의 3×3 이상 영상과 특징점 수 조건, 색 NCC의 색상 입력, Gray SAD의 회색 입력은 서로 다릅니다. 적합한 데이터를 준비하지 못하면 검색 전에 학습이나 형식 검사에서 실패할 수 있습니다.
