검색 설정과 격자

아래 이름은 Rust/Python 표기이며 C#은 PascalCase입니다. 생성자에 아홉 값을 모두 지정합니다. 이 형식에 적용되는 기본값은 없습니다. 검증은 검색 시 수행됩니다.

필드단위와 유효 범위
angle_min, angle_max라디안, −π ≤ 최소 ≤ 최대 ≤ π. 영상 좌표에서 양수는 시계 방향.
angle_step라디안, 유한한 양수
scale_min, scale_max등방 배율, 0 < 최소 ≤ 최대
scale_step배율 간격, 유한한 양수
min_score0..1 포함, 점수 하한
min_distance검색 영상 픽셀, 0 이상인 중심 거리
max_matches양의 정수, 반환 개수 상한

실수 인자는 모두 유한해야 합니다. 각 축은 min + i × step, i = 0 .. floor((max−min)/step)입니다. 최댓값이 격자에 맞을 때만 끝점을 방문하며 부동소수점 반올림에 주의하세요. 각 축은 최대 4096점이고 각도×배율도 최대 4096점입니다. 위치 후보는 보이는 영상의 각 픽셀 격자에 모델 기준점의 소수 부분을 더하여 평가합니다. 이것은 후보 예산 옵션이 아니며 작업량은 대략 영상 픽셀 수 × 각도 수 × 배율 수 × 표본 수에 비례합니다.

적용 상황과 원리

기본 MatchSpec은 NCC와 기본 형상 검색에서 회전과 등방 배율의 이산 격자를 정합니다. 각도 범위는 라디안 −π부터 π 이내이고 배율은 양수여야 합니다. 시작과 끝이 같은 고정 자세도 간격은 양수로 둡니다. 최댓값은 간격이 정확히 맞을 때만 격자에 들어갑니다. 예를 들어 0, 0.4, 0.8 다음에 1을 임의로 추가하지 않습니다.

결과를 읽는 방법

각 축은 최대 4096점이고 각도와 배율 점 수의 곱도 최대 4096입니다. 위치 후보와 학습 표본에 곱해지는 계산량을 생각하면 모델별 속도를 비교할 때 같은 ROI와 같은 격자 조건을 유지해야 합니다. 최소 점수, 최소 중심 거리, 최대 반환 수는 수용 및 중복 억제 조건입니다. 확장 NCC나 색 NCC·SAD 모델은 별도 옵션과 결과 형식을 사용하므로 이 아홉 값이 모든 모델에 동일하게 적용된다고 가정하지 않습니다.

추가 점검

검색 범위를 일치시키지 않으면 모델 속도를 공정하게 비교하기 어렵습니다. 기본 모델이 허용하는 회전과 배율과 다른 방식의 평행이동 범위는 표현 자체가 다를 수 있으므로 실제로 평가한 공간을 먼저 기록해야 합니다. 평가 범위와 해상도를 기록하면 시간 차이의 원인을 알고리즘과 설정으로 나누어 살필 수 있습니다.
