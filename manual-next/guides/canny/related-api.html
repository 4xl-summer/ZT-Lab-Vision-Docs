관련 API · 핵심 동작

GaussianBlur는 Canny가 수행하는 평활화의 개념을 이해하는 데 도움이 됩니다. 둘 다 양의 홀수 폭과 양의 유한 σ를 사용하지만 Canny는 평활화에 이어 Sobel, 비최대 억제, 연결 판단까지 수행합니다. 가우시안 출력은 밝기 영상이고 Canny 출력은 Gray8 에지 마스크입니다.

관련 API · 입력과 결과

밝기만으로 대상을 채우고 싶다면 Threshold의 픽셀 비교를 검토할 수 있습니다. 임계값 마스크에서 FindBlobs를 사용하면 영역별 픽셀 면적을 구할 수 있지만, Canny 에지에 같은 분석을 적용하면 경계 선분의 연결 영역을 측정하는 것이 됩니다. 반환값의 의미를 구분해야 합니다.

관련 API · 좌표와 소유권

정밀 위치가 필요한 경우에는 후속 에지·프로파일 계측에서 입력 좌표와 결과 단위를 따로 확인합니다. Canny의 0/255 픽셀 위치를 곧바로 서브픽셀 치수로 해석하지 마십시오. ROI 원점도 원본 위에 표시할 때 필요합니다.

관련 API · 오류와 판단

입력과 결과는 각자 소유 영상입니다. C#과 Python에서는 핸들을 해제하고 Rust에서는 소유값과 오류를 관리하며, 작은 ROI의 빈 성공 결과와 잘못된 파라미터 오류를 분리하십시오.

가우시안 평활화는 작은 밝기 변동을 줄이고 경계 검출은 밝기 변화 위치를 선택한다. 평활화 강도와 두 경계 임계값을 한 번에 바꾸면 차이의 원인을 분리하기 어려우므로 각각 조정한다.
