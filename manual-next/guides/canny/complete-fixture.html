합성 입력 전체 예제 · Canny · 에지 검출

합성 입력 전체 예제의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

합성 입력 전체 예제

아래 사례는 고정 합성 데이터와 명시적 기대값을 사용합니다.

Rust
use zvision::{ZImage, ZResult};
fn main() -> ZResult<()> {
    let image = ZImage::from_vec_gray8(2, 2, vec![0, 255, 0, 255])?;
    let edges = image.canny(3, 1.0, 10.0, 20.0)?;
    assert_eq!(edges.to_packed_vec()?, vec![0; 4]);
    assert!(image.canny(3, 1.0, 20.0, 10.0).is_err());
    Ok(())
}

2×2 경계 사례는 0 네 개; low > high 오류입니다.

합성 입력 전체 예제 · 핵심 동작

이 Rust 합성 사례는 경계 조건을 확인하도록 2×2 Gray8 입력 [0,255,0,255]를 사용합니다. 명암 전이가 존재하지만 두 축 모두 내부 3×3 영역을 만들기에 작으므로 결과는 0 네 개입니다. 이는 경계가 없다는 일반적인 판정이 아니라 이 구현의 작은 입력 처리 규칙을 보여 주는 값입니다.

합성 입력 전체 예제 · 입력과 결과

커널 3, σ 1, low 10, high 20은 모두 유효한 인자입니다. 두 번째 호출은 low 20과 high 10으로 순서를 뒤집어 오류를 기대합니다. 성공 반환의 전부 0인 배열과 잘못된 설정에서의 오류를 같은 검증 프로그램에서 구분하는 것이 핵심입니다.

합성 입력 전체 예제 · 좌표와 소유권

원본 배열은 행 우선이며 가로로 [0,255]인 행 두 개입니다. to_packed_vec()으로 읽은 결과도 패딩을 제외한 같은 순서입니다. 영상의 원점이 기본 위치가 아닌 ROI라면 숫자 배열에 좌표가 붙지 않으므로 위치 정보는 별도로 확인해야 합니다.

합성 입력 전체 예제 · 오류와 판단

이 사례는 입력 크기와 매개변수 유효성을 검토하기 위한 것이며 일반적인 5×5 이상 경계 위치를 검증하지 않습니다. 실제 경계 형태나 서브픽셀 위치를 평가하려면 다른 입력과 기준값이 필요합니다.
