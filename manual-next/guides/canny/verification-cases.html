관련 검증 사례 · 핵심 동작

경계 검증에는 2×2 영상과 3×3 이상의 영상을 나누어 사용합니다. 2×2 합성 입력 [0,255,0,255]은 유효한 설정에서도 전부 0을 반환하는 사례입니다. 외곽 한 픽셀을 제외하고 평가하므로 작은 입력 결과를 일반적인 가장자리 검출률로 확대해서 해석하지 않습니다.

관련 검증 사례 · 입력과 결과

설정 실패는 커널 0 또는 짝수, σ 0, low>high처럼 한 가지 조건씩 바꾸어 확인합니다. low=high는 순서 조건 자체를 만족합니다. 실패 시 예외가 보고되는지와 성공 시 빈 마스크가 반환되는지를 따로 검토하면 파라미터 오류가 무검출로 숨지 않습니다.

관련 검증 사례 · 좌표와 소유권

더 큰 합성 입력에서는 예상 에지 위치와 연결 상태를 배열로 기록해야 합니다. 강한 경계에서 시작해 약한 이웃이 이어지는지, 분리된 약한 잡음이 남는지 등을 별도 조건으로 비교할 수 있습니다. 이때 동일 장면이라도 입력 스케일이 달라지면 기울기 기준을 재설정해야 합니다.

관련 검증 사례 · 오류와 판단

영상의 ROI 원점과 결과 크기를 함께 확인하고, 실제 설비의 검출률이나 처리 시간은 합성 사례와 별도로 측정하십시오.

기대 결과를 비교할 때는 경계 픽셀의 위치를 입력 영상과 같은 좌표계에서 확인한다. 출력의 흰 픽셀 수만 같아도 서로 다른 위치에 선이 생길 수 있기 때문이다.

출력의 흰 픽셀 수만 같아도 경계가 서로 다른 위치에 나타날 수 있습니다. 따라서 입력과 결과를 동일 좌표로 겹쳐서 경계가 밝기 변화에 대응하는지 살펴봅니다. 평활화나 임계값을 바꿀 때는 한 번에 한 설정만 바꾸어 약한 선과 잡음의 변화를 비교합니다.

확인 항목해석
평탄한 영역잡음이 경계로 선택되는지 확인
밝기 변화 위치결과 선이 예상 위치에 놓이는지 확인
두 임계값강한 경계와 연결된 약한 경계의 변화를 비교
