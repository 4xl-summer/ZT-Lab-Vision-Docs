Rust 손실 열거형 경로

이 소스 버전에서 RobustFitOptions는 zvision에서 재수출하지만 필수 RobustLoss는 재수출하지 않습니다. 타원·사각형 옵션을 직접 구성할 때는 호환되는 동일 SDK 버전의 zvision-ops를 직접 의존성으로 명시하고 zvision_ops::RobustLoss를 사용합니다.

Rust
use zvision::RobustFitOptions;
use zvision_ops::RobustLoss;

형상 모델에서 견고 손실을 고르려면 옵션 구조체와 손실 열거형의 공개 경로를 각각 확인해야 합니다. 여기의 짧은 Rust 선언은 전체 측정 프로그램이 아니라 두 타입을 가져오는 부분입니다. 같은 SDK 버전의 보조 패키지가 프로젝트 의존성에 있어야 열거형을 지정할 수 있으며, 제품 코드를 수정해야 한다는 의미는 아닙니다.

손실을 고른 다음에도 척도, 초기 및 최종 잔차 기준, 반복 수와 감쇠를 직접 정해야 합니다. LeastSquares는 모든 점에 같은 가중치를 사용하고 Huber와 Tukey는 큰 잔차의 영향을 달리합니다. 모델 생성이 실패하면 사용한 타입의 경로뿐 아니라 구조체의 값 조건을 함께 검사하십시오. 구성에 성공한 뒤에는 영상에 대한 측정 결과와 수렴 여부를 별도로 확인합니다.

척도와 거리 임계값은 ROI 로컬 픽셀로 얻은 점과 같은 좌표 단위를 따릅니다. 프로그램에서 이 값을 직접 구성한다면 모든 필드가 유한하고 허용 범위에 드는지 검증한 후 생성 결과를 확인해야 합니다.

적용 순서와 결과 판독

손실 함수를 직접 지정할 때는 열거형이 어느 패키지에 공개되어 있는지와 옵션 구조체의 필드 타입을 함께 확인해야 합니다. 구조체를 제공하는 상위 경로가 모든 보조 열거형도 재공개한다고 가정하면 가져오기 단계에서 실패할 수 있습니다. 손실의 척도와 잔차는 동일한 좌표 단위로 해석하며, 알고리즘이 관측한 에지의 위치 자체를 변경하지는 않습니다. 의존성을 명시한 뒤 같은 관측점으로 손실 선택만 바꾸어 결과를 비교하면 영향 범위를 분리할 수 있습니다.

확인 단계판독과 조치
옵션 구조체공개된 경로에서 타입을 가져옵니다.
손실 열거형실제로 정의된 보조 패키지 경로를 사용합니다.
척도입력점과 같은 좌표 단위로 지정합니다.
결과 비교같은 점 집합에서 손실만 바꿔 확인합니다.
