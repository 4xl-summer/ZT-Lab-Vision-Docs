관련 검증 사례

영상 계측의 합성 사례에서는 알려진 경계에서 프로브가 어느 에지를 선택하고 어떤 형상이 반환되는지 확인합니다. rust-measurement-models의 점검은 모델 생성·영상 측정·상태 판독을 함께 연결합니다. 같은 입력에서 설정을 바꾸었다면 발견된 프로브와 채택된 프로브의 차이를 먼저 비교해야 합니다.

line-circle은 이미 주어진 점들로 선과 원을 피팅하는 경로를 따로 다룹니다. 이 점 피팅이 성공했다고 해서 영상에서 경계를 찾는 단계가 자동으로 검증되는 것은 아닙니다. 점 부족이나 형상 추정 실패에서는 fit이 없다는 상태를 확인하고, 결과가 있는 경우에는 잔차·수렴과 좌표계를 점검하십시오. 합성 입력과 실행 기록은 실제 장비에서 얻은 성능이나 정확도와 구분해 보관합니다.

진단을 재현하려면 프레임과 모델의 ROI 기준, 프로브의 진행 방향과 선택 정책, 결과의 채택 마스크를 함께 보관하십시오. 표면에 평행한 선을 예상했는데 선택점이 다른 모서리를 따른다면 피팅 임계값보다 먼저 검색 위치를 검토해야 합니다. 케이스의 실제 입력 데이터와 기대값을 읽어 언어별 실행 결과를 같은 조건에서 비교합니다.

합성 영상의 기대 형상과 실제 관측을 비교할 때 동일한 좌표 기준을 유지해야 합니다. 원점 이동은 잔차와 중심의 해석에도 영향을 줍니다.

적용 순서와 결과 판독

관측과 형상을 비교하는 검증에서는 모델의 기준 위치만 기록해서는 부족합니다. 각 프로브의 진행 방향, 선택된 에지와 최종 적합에 채택되었는지를 함께 기록해야 다른 경계를 선택한 문제와 적합 조건이 너무 엄격한 문제를 구분할 수 있습니다. 동일 영상에서 설정 하나만 바꾸어 비교하면 결과 차이가 어느 단계에서 시작됐는지 추적하기 쉽습니다. 합성 사례에서 확인한 결과를 새 장비의 정확도나 모든 영상에 대한 보증으로 확대하지 마십시오.

확인 단계판독과 조치
입력과 모델같은 프레임과 ROI 기준을 사용합니다.
프로브 진단후보의 위치와 진행 방향을 확인합니다.
적합 상태찾은 점과 채택점을 따로 확인합니다.
결과 비교바뀐 설정과 잔차를 같이 기록합니다.
