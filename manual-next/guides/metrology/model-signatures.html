Rust 모델 생성과 실행

네 생성자 모두 검증 후 결과를 반환하고, 각 모델의 measure(&self, image: &ZImage)는 독립 결과 스냅샷을 반환합니다. 좌표는 ROI 로컬, 길이는 픽셀, 각도는 라디안입니다. 전체 원에서는 마지막 각도를 중복하지 않습니다. 직선의 탐색 방향은 법선에 skew를 더한 방향입니다.

판독 기준

  • 모델마다 필요한 입력과 옵션이 다르므로 해당 API를 따릅니다.
  • 불충분한 점이나 가려진 경계에서는 결과가 불안정하거나 실패할 수 있습니다.

LineMeasurementModel::new(start: Point2, end: Point2, search_skew_radians: f64, probes: ProbeSettings) -> ZResult<Self>
CircleMeasurementModel::new(center: Point2, radius: f64, start_angle: f64, end_angle: f64, probes: ProbeSettings) -> ZResult<Self>

RectangleMeasurementModel::new(center: Point2, half_width: f64, half_height: f64, angle: f64, probes: ShapeProbeSettings, fit: RobustFitOptions) -> ZResult<Self>

모델 선택은 찾으려는 형상과 기준 기하에서 시작합니다. 선은 양 끝을, 원은 중심과 반경 및 각도 범위를 지정합니다. 타원은 긴 반축과 짧은 반축, 회전과 원호 범위가 필요하고 사각형은 중심, 두 반폭과 회전을 사용합니다. 영상에 적용하기 전 생성자는 이 기하와 프로브 설정의 유효성을 확인합니다.

그 다음 같은 모델을 영상에 전달해 측정하고, 각 호출에서 반환된 독립 결과를 읽습니다. 선의 탐색선은 기준선의 법선 방향에 지정한 기울기를 더해 만들며 원의 전체 한 바퀴에서는 마지막 위치를 중복하지 않습니다. 모델 생성 성공은 영상에 경계가 있다는 보증이 아니므로 measure 이후에는 탐색점의 상태와 선택된 에지, 피팅 유무를 순서대로 살펴보십시오.

모델의 형상 매개변수는 초기 탐색을 위한 기준입니다. 실제 결과가 기준 위치와 같아야 한다는 뜻이 아니며, 허용 탐색 구간 안에서 발견된 에지의 분포에 따라 달라집니다. 재사용 시 영상의 크기와 ROI 기준이 바뀌지 않았는지 점검하십시오.

적용 순서와 결과 판독

직선과 원 모델은 탐색할 기준 기하가 다르므로 같은 숫자를 순서만 바꾸어 전달할 수 없습니다. 직선에서는 기준을 따라 프로브를 배치하고 원에서는 원주 주변에 관측을 배치합니다. 각 실행 결과는 해당 입력 이미지에 대한 관측이므로 기준 형상과 결과 형상을 분리해 표시해야 합니다. 예를 들어 기준 중심이 영상 중앙에 있어도 반환 중심은 관측된 에지의 위치에 따라 달라질 수 있습니다. 결과가 실패한 경우 중심이나 반지름을 정상적인 0으로 대체하지 마십시오.

확인 단계판독과 조치
기준 직선탐색 위치를 배치하는 입력 기하입니다.
기준 원중심과 반지름으로 원주 탐색을 정합니다.
실행 입력같은 좌표계의 이미지와 설정을 전달합니다.
결과 형상상태와 관측을 확인한 후 치수를 해석합니다.
