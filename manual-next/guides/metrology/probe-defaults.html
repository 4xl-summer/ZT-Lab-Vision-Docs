명시적 기본 설정 함수

Rust default_measurement_probes()는 count 10, search_length 14, width 3, samples 15, Forward, Strongest, min_found 3을 반환합니다. 프로파일은 Bilinear, min_valid_width 3, filter [1]; 미분은 반경 1 Central, threshold 10, prominence 0, Any, rank Position, max_results 5입니다. fit은 Consensus, inlier_threshold 1, min_inliers 3, max_candidates 256, max_refit_iterations 5, tolerance 1e−7, min_arc_radians 0입니다. 실제 selection은 Strongest면 strength 순위, First/Last면 position 순위로 설정합니다.

처음 모델을 만들 때 제공되는 Rust 기본 설정은 열 개의 프로브와 14픽셀 탐색 구간을 사용합니다. 개별 구간은 앵커를 중심으로 배치되므로 양쪽으로 각각 7픽셀입니다. 세 픽셀 폭의 띠와 열다섯 위치는 초기 선택일 뿐이며, 대상 경계의 두께나 영상의 실제 명암을 반영해 자동 조절되지 않습니다.

기본값은 어느 극성이라도 허용하고 가장 강한 후보를 고릅니다. 한 탐색선이 제품의 두 면을 모두 지난다면 강한 쪽이 사용 목적에 맞는지 관측 결과에서 확인해야 합니다. 강도/픽셀 단위의 문턱과 픽셀 잔차 문턱은 서로 다른 설정입니다. 모델을 바꾸기 전과 후에 동일 합성 입력의 선택 위치와 채택 수를 비교하면 변경 효과를 이해하기 쉽습니다.

적용 순서와 결과 판독

기본값은 처음 실행할 설정의 출발점이지 모든 장면에 적합하다는 보증은 아닙니다. 기본 탐색 길이 안에 목적 경계가 없으면 표본이 충분해도 올바른 점을 발견할 수 없고, 반대로 여러 경계가 들어오면 선택 정책이 의도와 맞아야 합니다. 먼저 한 위치의 프로파일과 부호를 관찰한 뒤 검색 길이와 극성을 정하고, 이후 여러 위치의 결과를 비교하십시오. 설정을 변경할 때마다 개별 관측과 최종 형상의 상태를 같이 저장해야 변화 원인을 구별할 수 있습니다.

확인 단계판독과 조치
기본 개수와 길이대상 크기와 실제 경계 위치에 맞는지 봅니다.
보간과 폭소수 좌표의 표본값과 가장자리 유효성에 영향을 줍니다.
극성과 선택 순서진행 방향에서 목적 경계를 고르는지 확인합니다.
최종 상태기본값으로 성공했는지 개별 결과와 함께 봅니다.
