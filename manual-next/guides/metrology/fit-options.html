직선·원 FitOptions · 기하 계측 모델

직선·원 FitOptions의 입력 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

직선·원 FitOptions

method는 LeastSquares 또는 Consensus, inlier_threshold는 입력 좌표 단위의 유한한 양수, min_inliers는 최소점 이상 count 이하, max_candidates는 1–1,000,000, max_refit_iterations는 1–1000, tolerance는 유한한 0 이상, min_arc_radians는 0부터 2π까지입니다. max_candidates×count×max_refit_iterations는 8,000,000 이하여야 합니다. Consensus는 후보를 비교하고 LeastSquares는 최소제곱을 사용합니다. threshold와 tolerance는 입력 좌표 단위, arc는 라디안입니다.

피팅 문턱은 선택된 에지점이 후보 형상에서 얼마나 떨어져도 채택할지 결정합니다. 원시 강도에 적용하는 캘리퍼 문턱과 달리 이 값의 단위는 위치의 단위입니다. ROI 픽셀로 측정한 형상이라면 인라이어 잔차 한계도 픽셀로 해석해야 하며, 이미지의 명암 범위를 바꾸는 설정과 따로 조정합니다.

합의 방식은 서로 다른 후보를 비교하므로 이상점이 섞인 경우 유용할 수 있지만 후보 수, 점 수와 재피팅 한도의 곱이 작업량을 결정합니다. 최소제곱과 합의 방식 모두 충분하고 퇴화하지 않은 점이 필요합니다. 원의 최소 원호 범위는 라디안으로 설정하며, 점들이 한쪽에만 몰렸다면 개수가 많아도 해당 조건을 만족하지 않을 수 있습니다. 결과의 잔차와 수렴을 기준으로 설정을 다시 살펴보십시오.

적용 순서와 결과 판독

형상 적합은 선택된 점 집합에서 모델을 정하는 단계입니다. 허용 잔차를 너무 작게 잡으면 실제 경계의 점도 채택되지 않을 수 있고, 크게 잡으면 인접 경계의 점까지 통과할 수 있습니다. 따라서 임계값을 조정할 때는 결과 형상만 보지 말고 각 점의 거리와 채택 상태를 함께 비교하십시오. 원의 경우 점이 한쪽 작은 구간에만 몰려 있으면 개수가 충분하더라도 중심 해석이 민감해질 수 있으므로 점의 분포와 원호 조건을 별도로 확인합니다.

확인 단계판독과 조치
잔차 임계값각 점을 모델과 비교하는 거리 기준입니다.
최소 채택 수관측 수와 실제 채택 수를 따로 확인합니다.
후보와 반복 한도계산량 제한과 결합되는 설정을 점검합니다.
원호 분포원의 서로 다른 방향에서 관측했는지 봅니다.
