NCC 템플릿 매칭

학습한 템플릿에서 정규화 교차상관 기반 검색 모델을 만들고 위치·점수 스냅샷을 읽는 방법.

템플릿을 값이 아닌 모델로

NCC(정규화 교차상관) 매칭은 템플릿과 검색 위치의 강도 패턴을 비교하여 위치 후보를 찾습니다. ZVision은 학습된 템플릿을 MatchModel이 보유하고, 검색 조건을 MatchSpec으로 전달하여 불변 MatchResult를 반환합니다.

ZImage학습 템플릿
→
MatchModelTrainNcc
→
Find + SpecMatchResult
NCC = Σ((T − mean(T))·(I − mean(I))) / √(Σ(T − mean(T))² · Σ(I − mean(I))²)

위 수식은 일반적인 NCC 원리 설명이며 라이브러리의 회전·배율 탐색, 후보 샘플링 및 NMS 세부 구현 전체를 기술하지 않습니다.

학습과 검색 조건

항목주요 제약
학습 이미지Gray8, Gray16 또는 GrayF32
선택 마스크템플릿과 크기·원점이 같은 Gray8, 비제로 선택
NCC 학습선택 픽셀 2개 이상, 분산 0 아님
검색 이미지Gray8/16/F32
점수매칭 점수. 확률이 아님
결과최소 점수 및 중복 억제 후 점수순으로 반환

MatchSpec 파라미터 (C# 기준)

이름의미
AngleMin/Max/Step회전 각도 범위·격자(라디안)
ScaleMin/Max/Step등방 배율 범위·격자
MinScore최소 수락 점수(0..1)
MinDistance중복 억제 중심 거리(픽셀)
MaxMatches최대 결과 수

C# 모델 사용 흐름

C#
// template과 searchImage는 준비된 Gray8/16/F32 ZImage입니다.
using var model = MatchModel.TrainNcc(template);
var spec = new MatchSpec(
    0.0, 0.0, 1.0,
    1.0, 1.0, 1.0,
    0.95, 0.0, 10);
MatchResult result = model.Find(searchImage, spec);

좌표와 수명

각 매치에는 ROI 지역 좌표 Position과 원본 기준 GlobalPosition이 있습니다. MatchResult는 모델·이미지를 해제한 후에도 유효한 값 스냅샷입니다. 반면 학습 모델 자체는 네이티브 자원이므로 사용 후 해제해야 합니다.
