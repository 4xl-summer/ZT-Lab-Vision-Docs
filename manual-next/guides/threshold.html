Threshold — 임계값 분할

입력 픽셀과 유한 임계값을 비교하여 0/255의 새 Gray8 마스크를 만드는 영상 분할.

독립 HTML 페이지코드 검토 기준 2026-11-08초기 콘텐츠

알고리즘의 정의

임계값 분할은 밝기를 기준으로 물체와 배경을 분리할 때 사용합니다. ZVision의 비교는 경계값을 포함하는 크거나 같음(≥) 연산입니다.

output(x,y) = 255 if input(x,y) ≥ T; otherwise 0

입력 Gray8 · 임계값 10

91011

출력 Gray8 마스크

0255255

실제 구현 계약

항목현재 확인된 범위
입력Gray8 / Gray16 / GrayI16 / GrayI32 / GrayU32 / GrayF32 / GrayF64
출력새로운 Gray8 이미지, 픽셀은 0 또는 255
임계값유한한 실수
원본변경하지 않음
ROI처리할 수 있으며 원본 기준 origin 보존
오류비유한 임계값, 컬러 형식, NaN/무한대 부동소수 픽셀

임계값의 선택

임계값을 높이면 밝은 픽셀만 선택하고, 낮추면 더 많은 픽셀을 전경으로 선택합니다. 배경과 결함의 강도 분포가 충분히 나뉘어 있을 때 유리합니다. 조명 구배나 반사가 심한 경우에는 한 임계값만으로 안정적인 분할이 어려울 수 있습니다.

C# 사용 예

C#
using ZVision;

using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var binary = source.Threshold(10.0);
var pixels = binary.ToArrayGray8(); // [0, 255, 255]
