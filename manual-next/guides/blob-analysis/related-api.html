관련 API · 핵심 동작

Blob 분석의 입력은 0을 배경으로 해석하는 Gray8 마스크입니다. 밝기 영상에서 출발한다면 먼저 임계값이나 다른 분할 방법으로 전경을 정의해야 합니다. 그 뒤 연결성 4 또는 8을 지정하면 면적, 로컬 경계와 중심으로 구성된 결과를 읽을 수 있습니다.

관련 API · 입력과 결과

이진 열기와 닫기는 마스크의 연결 상태를 바꾸는 전처리 선택지입니다. 커널 폭이 커지면 고립점이나 작은 틈뿐 아니라 관심 결함도 없어지거나 이웃 객체와 결합할 수 있습니다. 처리 전후의 마스크 및 면적 분포를 함께 확인하고, 형태학의 숫자를 반복 횟수로 해석하지 마십시오.

관련 API · 좌표와 소유권

직접 호출과 지연 질의는 결과를 얻는 시점과 소유 방식이 다릅니다. Rust 질의에서는 계획을 실행해 결과를 읽고, 관리형 직접 호출은 값 스냅샷을 제공합니다. 영상과 ROI는 별도의 소유 핸들이므로 각 언어의 해제 규칙을 따릅니다.

관련 API · 오류와 판단

검사 결과를 실제 위치로 연결할 때는 ROI 원점과 좌표계를 보관합니다. 물리 면적이나 거리 판정은 보정된 좌표와 단위를 명시한 별도의 계산 단계입니다.

영상을 먼저 이진화한 뒤 전경을 연결 성분으로 묶고, 필요에 따라 면적과 위치로 후보를 고른다. 각 단계의 결과를 따로 살펴야 임계값 문제와 연결 조건 문제를 구별할 수 있다.
