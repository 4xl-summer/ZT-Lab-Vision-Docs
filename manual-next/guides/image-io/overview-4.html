관련 설명 열기

적용 상황과 원리

입출력을 검증할 때는 우선 사용 언어와 실행 플랫폼에서 파일을 읽고 쓸 수 있는 경로를 준비합니다. Rust 코드라면 io 기능이 활성화되어 있는지 확인합니다. 임시 파일을 쓰는 예제는 실행마다 파일 경로 충돌과 권한을 고려하고, 정리해야 하는 파일의 소유 범위를 명확히 합니다.

결과를 읽는 방법

다음으로 입력 크기와 픽셀 타입, 저장 옵션, 읽은 결과의 크기와 값을 비교합니다. 다중 페이지는 저장 순서와 0 기반 인덱스를 함께 확인하고 존재하지 않는 페이지 요청이 오류가 되는지도 별도 검사합니다. PNG나 TIFF의 특정 설정에서 확인한 결과를 모든 형식의 손실 없는 왕복 보장으로 일반화하지 않습니다. JPEG는 손실 압축이라는 점을 고려하여 비교 기준을 정합니다.

추가 점검

작은 2페이지 사례라면 서로 다른 픽셀을 각 페이지에 넣어 순서가 바뀌었는지 쉽게 찾을 수 있습니다. 저장과 읽기를 같은 형식으로 한 번 수행한 결과는 해당 옵션과 픽셀 형식의 증거입니다. 다른 압축·채널 구성까지 포함하려면 각 조합을 별도 사례로 시험해야 합니다. 입력 파일을 교체했을 때 형식과 페이지 수가 변했는지도 확인합니다.
