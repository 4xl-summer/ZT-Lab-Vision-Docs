적용 상황과 원리

읽기는 ZImage의 load 또는 TIFF 페이지 지정 경로에서 시작합니다. 파일 서명으로 형식을 식별하고 디코딩된 새 영상을 반환하므로 호출자는 결과 픽셀 형식과 원래 기대한 채널 구성을 확인해야 합니다. 파일 오류와 지원하지 않는 형식의 오류는 실제 영상에서 전경이 없다는 검사 결과와 다릅니다.

결과를 읽는 방법

저장 경로는 단일 영상을 쓰는 save, 인코더 설정을 지정하는 save_with_options, 여러 TIFF 페이지를 쓰는 save_tiff_pages로 나뉩니다. 다중 페이지에는 TiffSaveOptions가 적용되고 페이지는 입력 순서를 따릅니다. 페이지를 읽는 인덱스는 0부터입니다. 원본과 복원된 영상은 따로 소유하며, 각 언어의 자원 정리 규칙과 Rust의 io 기능 조건을 확인하세요.

추가 점검

JPEG 품질과 PNG 압축은 단일 영상의 옵션이고 TIFF의 페이지·압축 설정은 별도의 옵션 구조에서 선택합니다. 같은 영상이라도 확장자를 바꾸면 인코더가 달라지므로 반환 타입과 저장 전후의 수치 보존을 해당 형식에서 확인해야 합니다. 읽기 후 타입을 확인하면 후속 회색 전용 연산의 입력 오류를 줄일 수 있습니다. 저장할 파일 경로의 확장자를 먼저 확인합니다.
