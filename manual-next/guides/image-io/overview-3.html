오류·주의사항

save_with_options와 save_tiff_pages는 별도 코덱 옵션을 처리합니다. JPEG는 손실 압축으로 원본 측정 픽셀을 바꿀 수 있습니다.

적용 상황과 원리

파일 경로가 없거나 읽기·쓰기 권한이 없을 때의 오류와, 파일은 열렸지만 형식이나 픽셀 조합이 지원되지 않는 오류를 구분해야 합니다. TIFF에서는 페이지 번호가 범위를 벗어난 경우도 실패입니다. 호출자는 반환 오류를 검사하고 실패를 빈 영상이나 정상 페이지로 바꾸지 않아야 합니다.

결과를 읽는 방법

저장할 때 선택된 인코더는 확장자로 정해지므로 파일 이름과 실제 기대 형식이 맞는지 확인합니다. JPEG는 손실 압축이어서 검사에 쓰는 원본 밝기를 저장 전과 바이트 단위로 같다고 가정할 수 없습니다. 수치 비교나 재측정이 필요하면 선택한 형식의 지원 픽셀 타입과 왕복 결과를 합성 자료로 검증하세요. 원본 영상과 디코딩된 새 영상은 각각 별도의 소유권을 갖습니다.

추가 점검

예를 들어 두 페이지를 가진 파일에서 페이지 2를 요청하면 첫 페이지로 대체하지 않고 오류를 처리합니다. 선택한 인덱스가 0 기반인지 먼저 확인하고 원하는 페이지의 크기와 값을 검산하세요. 읽기 오류와 메모리에서 처리한 영상의 정상 빈 결과는 다른 상태입니다.
