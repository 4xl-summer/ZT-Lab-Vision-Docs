적용 상황과 원리

load는 파일의 실제 서명을 보고 디코더를 선택해 영상을 만듭니다. 다중 페이지 TIFF에서 특정 페이지만 필요하면 load_tiff_page로 0 기반 페이지를 지정합니다. 읽은 결과는 독립적으로 소유하므로 입력 파일을 읽는 과정의 실패와 이후 영상 연산의 실패를 구분할 수 있습니다.

결과를 읽는 방법

save는 경로의 확장자로 출력 형식을 결정하고, save_with_options는 JPEG 품질이나 PNG 압축 같은 설정을 지정할 때 사용합니다. 여러 TIFF 페이지를 순서대로 쓰려면 save_tiff_pages와 TIFF 저장 설정을 사용합니다. 호출 전에 영상 픽셀 형식이 선택한 인코더에서 지원되는지 확인하세요. 단순히 확장자만 바꾼다고 모든 픽셀 형식이 보존되는 것은 아니며 손실 JPEG는 원래 밝기와 다른 값을 읽을 수 있습니다.

추가 점검

출력 영상의 형식 선택은 쓰기 전에 결정해야 합니다. 예를 들어 GrayF32를 그대로 저장할 수 있는지와 RGB 영상을 BMP로 쓸 수 있는지는 서로 다른 인코더 조건입니다. 실패를 무시하고 다른 확장자를 붙이면 원래 의도한 측정 데이터가 보존되었다고 판단할 수 없습니다. 페이지를 선택하는 인덱스와 저장할 영상 배열의 순서를 같은 기준으로 관리합니다.
