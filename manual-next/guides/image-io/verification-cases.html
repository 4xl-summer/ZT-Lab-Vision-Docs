적용 상황과 원리

다중 페이지 합성 사례의 기대값은 두 번째 페이지의 3,4이며, 0 기반 페이지 번호 2는 두 페이지짜리 파일의 범위를 벗어나므로 오류입니다. 첫 페이지가 0이라는 규칙과 별개로 저장 배열의 순서를 바꾸면 기대 결과도 바뀝니다. 테스트는 임시 경로를 사용하고 파일을 닫은 뒤 정리합니다.

결과를 읽는 방법

영상 I/O의 형식별 경계와 저장 옵션은 하나의 합성 파일만으로 모두 확인할 수 없습니다. Rust의 io 기능, 사용할 인코더, 각 환경의 파일 접근 권한과 지원 픽셀 형식을 따로 점검해야 합니다. JPEG처럼 손실이 있는 형식에서는 바이트 동일성이 올바른 기대값이 아닐 수 있습니다. 기록된 실행 환경을 확인하고 실제 장비의 파일 교환 요구사항은 별도 데이터로 검증합니다.

추가 점검

원본 코드의 저장과 로드는 각각 실패할 수 있습니다. 단언문은 지정 페이지에서 얻은 픽셀이 기대값인지와 다음 페이지가 오류인지 확인하지만 권한이나 파일 시스템 장애를 모두 재현하지는 않습니다. 실행 후 파일 정리 결과도 환경에 따라 달라질 수 있습니다. 지원되지 않는 형식의 오류도 기대값과 따로 기록합니다. 추가 형식과 압축 조합은 독립적으로 시험합니다. 검사에서 사용할 파일의 디코딩 결과가 기대한 픽셀 형식인지도 확인합니다.
