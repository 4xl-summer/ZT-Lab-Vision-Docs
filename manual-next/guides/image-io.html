이미지 파일 Load · Save

파일 시그니처 로드·확장자 저장·다중 TIFF 옵션.

이 장에서 배우는 내용

파일 시그니처 로드·확장자 저장·다중 TIFF 옵션.

ZImage::load는 시그니처 기반 디코딩을 사용하고 save는 확장자로 인코더를 선택합니다. load_tiff_page는 0부터 시작하는 페이지를 읽습니다.

save_with_options와 save_tiff_pages는 별도 코덱 옵션을 처리합니다. JPEG는 손실 압축으로 원본 측정 픽셀을 바꿀 수 있습니다.

읽기는 서명 기반이며 저장은 대소문자를 구분하지 않는 확장자 png, bmp, jpg/jpeg, tif/tiff로 선택합니다. load_tiff_page 의 페이지 인덱스는 0부터 시작합니다. 기본 JPEG quality는 75이고 허용 범위는 1–100, 기본 PNG compression은 Fast입니다. JPEG는 손실 압축이므로 저장 전후 값의 일치를 가정하지 마세요.
