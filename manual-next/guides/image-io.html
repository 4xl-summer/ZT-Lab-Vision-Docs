이미지 파일 Load · Save

파일 시그니처 로드·확장자 저장·다중 TIFF 옵션.

개념과 사용 흐름

ZImage::load는 시그니처 기반 디코딩을 사용하고 save는 확장자로 인코더를 선택합니다. load_tiff_page는 0부터 시작하는 페이지를 읽습니다.

오류·주의사항

save_with_options와 save_tiff_pages는 별도 코덱 옵션을 처리합니다. JPEG는 손실 압축으로 원본 측정 픽셀을 바꿀 수 있습니다.

검증 기준

io Cargo feature, 파일 권한, 코덱 지원, 페이지 순서를 검증하세요.

관련 설명 열기

형식과 보존 범위

읽기는 서명 기반이며 저장은 대소문자를 구분하지 않는 확장자 png, bmp, jpg/jpeg, tif/tiff로 선택합니다. load_tiff_page의 페이지 인덱스는 0부터 시작합니다. 기본 JPEG quality는 75이고 허용 범위는 1–100, 기본 PNG compression은 Fast입니다. JPEG는 손실 압축이므로 저장 전후 값의 일치를 가정하지 마세요.

PNG 저장은 Gray8, Gray16, RGB/BGR8, RGBA/BGRA8, RGB/BGR16을 받습니다. BMP와 JPEG는 Gray8 또는 RGB/BGR8을 받습니다. TIFF는 Gray8/16, GrayI16/I32/U32, GrayF32/F64, RGB/BGR8/16, RGB F32, RGBA/BGRA8 등 별도 경로를 지원합니다. TIFF 다중 페이지와 compression, BigTIFF 옵션을 선택할 수 있습니다. 각 형식·입력의 지원 여부와 읽기 후 픽셀 값을 실제 파일로 검증하고, 정밀도 변환이나 손실 없는 왕복을 무조건 가정하지 마세요.

읽기 형식과 한계

PNG·JPEG·BMP 디코더는 Luma8→Gray8, Luma16→Gray16, RGB8/16→RGB8/16, RGBA8→RGBA8을 반환합니다. LumaA8은 각 회색값을 RGB로 복제하고 알파를 보존한 RGBA8로 반환합니다. 그 외 디코드 결과는 UnsupportedPixelFormat입니다. TIFF는 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64, RGB8, RGB16, RGBF32, RGBA8의 조합을 받습니다. TIFF Orientation은 1이어야 하고 planar는 chunky 또는 separate만 허용하며 RGBA extra sample은 unassociated alpha여야 합니다. 다른 조합은 형식 또는 픽셀 형식 오류입니다.

TIFF 저장 설정

필드선택값과 기본값
big_tifffalse가 기본; true는 BigTIFF
compressionNone 기본, Lzw, Deflate, Packbits
byte_orderNative 기본, Little, Big
planarChunky 기본, Separate

페이지 배열은 비어 있으면 오류이고 페이지는 입력 순서대로 저장됩니다. 각 치수는 u32 범위에 들어야 합니다. 저장 전용 경로의 픽셀 형식과 코덱 제약을 확인하세요. 페이지 밖 인덱스, 잘못된 파일, 읽기·쓰기 실패는 오류로 처리합니다. 원본 영상 객체와 로드된 영상 객체는 별도로 소유합니다.

다중 페이지 합성 예제

Rust의 io feature가 필요합니다. 사례 rust-tiff-pages에서 두 번째 페이지는 [3,4], 범위를 벗어난 페이지는 오류를 기대합니다. 실행 환경에서 확인해야 하는 예제입니다.

Rust
use zvision::{TiffSaveOptions, ZImage};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let first = ZImage::from_vec_gray8(2, 1, vec![1, 2])?;
    let second = ZImage::from_vec_gray8(2, 1, vec![3, 4])?;
    let path = std::env::temp_dir().join("zvision-example-pages.tiff");
    ZImage::save_tiff_pages(&[first, second], &path, TiffSaveOptions::default())?;
    let page = ZImage::load_tiff_page(&path, 1)?;
    assert_eq!(page.to_packed_vec()?, vec![3, 4]);
    assert!(ZImage::load_tiff_page(&path, 2).is_err());
    std::fs::remove_file(path)?;
    Ok(())
}

이 페이지는 기준 SDK 소스와 대조했습니다. 예제는 실행 환경에서 별도로 검증해야 하며 합성 데이터 결과는 실장비 정확도를 뜻하지 않습니다.
