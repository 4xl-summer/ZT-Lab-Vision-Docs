검사 결과를 표시 프레임으로 변환 · 관리형 표시와 Workbench

관리형 표시와 Workbench에서 검사 결과를 표시 프레임으로 변환을 이해하기 위한 입력, 동작과 결과 설명

상위 목차로 돌아가기

검사 결과를 표시 프레임으로 변환

C#
using System;
using System.Threading;
using ZVision;
using ZVision.Inspection;

class Program {
    static void Main() {
        byte[] pixels = new byte[64];
        for (int y=2; y<6; y++) for (int x=2; x<6; x++) pixels[y*8+x]=255;
        using var image = ZImage.FromGray8(8,8,pixels);
        var recipe = new ZInspectionRecipe(gaussianKernel:1, gaussianSigma:1, threshold:128, closeKernel:1, minArea:1);
        var executor = new ZInspectionExecutor();
        using var result = executor.Execute(image, 1, 1, recipe, CancellationToken.None);
        using var frame = result.CreateDisplayFrame("Close");
        using var stage = result.AcquireStage("Close");
        Console.WriteLine($"frame={result.FrameId}, blobs={result.Blobs.Count}, size={frame.Width}x{frame.Height}");
    }
}

합성 이미지의 가운데 사각형을 밝은 값으로 채운 다음 Gray8 이미지으로 만듭니다. 커널 크기를 1로 선택하면 이 사례에서 블러와 닫기가 공간적으로 확장된 주변부를 만들지 않으므로 임계값 128 이후 가운데의 전경을 쉽게 확인할 수 있습니다. 최소 면적 1은 남은 연결 요소를 크기로 추가 제거하지 않는 설정입니다. 입력의 형식이나 조건을 바꾸면 Blob 수가 달라질 수 있습니다.

실행기는 입력을 빌려 쓰고 검사 결과에 단계별 이미지와 Blob 스냅샷을 담아 반환합니다. Close 단계의 표시 프레임을 만들거나 같은 단계를 별도로 획득하면 각각 독립 소유 객체가 생깁니다. 입력, 검사 검사 결과, 표시 프레임과 획득 이미지를 각자의 범위에서 해제하세요. 합성 검사 결과를 보는 콘솔 호출과 실제 WPF·WinForms 화면 조작은 서로 다른 검증 범위입니다.

검사 결과 수치가 다를 때는 우선 입력 배열과 선택한 ROI가 코드의 좌표와 일치하는지 살펴보고, 그 다음에 각 단계의 설정을 비교합니다.

단계 이름을 고를 때는 검사 결과의 StageNames를 사용합니다. Close가 존재하는 기본 실행 검사 결과라면 그 단계를 AcquireStage로 얻어 화소를 살펴보고, 별도 CreateDisplayFrame의 오버레이와 대조할 수 있습니다. 두 반환 객체는 각각 해제합니다.
