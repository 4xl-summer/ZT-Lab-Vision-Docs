표시, 좌표 및 프레임

ZDisplayFrame은 영상의 독립 임대를 갖고 AcquireImage, Share는 각각 별도 소유권을 반환합니다. FrameId, RecipeVersion, Width, Height, PixelFormat, Overlays가 스냅샷입니다. CreateRaster는 최대 16,777,216 픽셀을 허용하며 CopyBgra32는 복사본을 돌려줍니다. Gray16 표시 범위의 기본값은 0–65535이며 최소·최대는 유한하고 최대가 더 커야 합니다. 표시 변환과 원본 측정값을 혼동하지 마세요.

ZViewport는 픽셀 중심을 사용해 화면 좌표 = (영상 좌표 + 0.5) × Scale + Pan으로 변환합니다. Fit, ZoomAt, PanBy, ScreenToImage를 사용하고 ROI는 CreateRoiFromScreen으로 생성합니다. ZOverlayScene은 선, 사각형, 원, 다각형, 라벨의 스냅샷입니다. ZDisplayFrameGate의 Expect와 TryAccept로 프레임 및 레시피 세대를 확인하고 오래된 결과를 표시하지 않도록 합니다.

표시 프레임은 검사 이미지의 독립 임대와 프레임·레시피 세대 및 오버레이 장면을 묶습니다. 검사 결과 단계에서 프레임을 만든 뒤 원래 검사 검사 결과를 해제해도 이미 얻은 프레임은 자신의 이미지 임대를 갖습니다. 반대로 프레임을 해제한 뒤 그 프레임에서 새 이미지를 얻을 수는 없습니다. AcquireImage로 얻은 이미지도 별도의 소유 객체이므로 사용이 끝나면 정리합니다.

화면 확대와 이동은 검사 좌표를 바꾸지 않습니다. 뷰포트는 로컬 화소 중심에 0.5를 더한 뒤 배율과 이동량을 적용하여 화면 좌표를 계산합니다. 마우스가 가리키는 화소가나 드래그 영역을 다시 이미지 좌표로 바꿀 때는 제공되는 역변환과 ROI 생성 기능을 사용합니다. 표시용 색 범위와 원본 숫자 값을 구분하면 화면의 명암을 측정값으로 오인하지 않습니다.

예를 들어 같은 숫자 이미지가라도 표시 범위의 최대값을 바꾸면 화면의 밝기가 달라집니다. 원본 화소를 읽어 표시 변환과 비교합니다.

프레임, 래스터와 도형의 역할

ZDisplayFrame은 소유 영상 임대와 원본 형식, 크기, 세대 및 불변 오버레이 장면을 묶습니다. 프레임의 Share는 새 프레임을, AcquireImage는 새 영상 임대를 반환하므로 호출자가 각각 해제합니다. CreateRaster는 화면에 쓰기 위한 관리 메모리 픽셀과 원본 채널 스냅샷을 만듭니다. 프레임의 영상 핸들과 복사된 BGRA 배열은 같은 수명을 갖는 객체가 아닙니다.

Gray16이나 부동소수 채널의 표시값은 지정한 최소·최대 범위에 따라 0–255로 변환됩니다. 예를 들어 기본 범위 0–65535에서 중간에 가까운 값과 좁은 범위를 지정했을 때의 화면 밝기는 다를 수 있습니다. GetPixel은 원본 채널 값을 문자열로 제공하므로 표시색만으로 수치를 판단하지 않고 해당 값을 확인합니다. 바이트 채널은 직접 사용합니다.

ZViewport의 Scale은 기본 1이고 PanX와 PanY는 기본 0입니다. 픽셀 중심 기준 변환과 역변환으로 포인터 위치를 읽고, 화면 드래그를 CreateRoiFromScreen에 전달하면 영상 안에서 겹치는 픽셀 셀의 사각형을 얻습니다. 이미지 바깥 드래그나 빈 영역은 null이 될 수 있으므로 후속 검사 전에 존재 여부를 확인합니다.
