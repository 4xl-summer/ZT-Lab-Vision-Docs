C# 이진 마스크 처리

C#
using ZVision;

using var source = ZImage.FromGray8(5, 5, new byte[] {
    0, 0, 0, 0, 0,
    0, 255, 255, 255, 0,
    0, 255, 255, 255, 0,
    0, 255, 255, 255, 0,
    0, 0, 0, 0, 0
});
using var opened = source.Open(3);
byte[] output = opened.ToArrayGray8();

C# 이진 마스크 처리 · 핵심 동작

C# 예제의 5×5 마스크는 0 배경 안에 3×3 전경을 놓습니다. Open(3)은 먼저 3×3 구조 요소로 침식하고 그 결과를 같은 폭으로 팽창합니다. 여기서 3은 두 단계에 공통으로 쓰이는 폭이며, 세 번 반복하라는 지시가 아닙니다.

C# 이진 마스크 처리 · 입력과 결과

침식 단계에서 3×3 블록은 중심 하나로 줄고, 팽창 단계에서 그 중심 주변이 다시 확장됩니다. 입력과 구조 요소가 같은 3×3이고 테두리에 배경 여유가 있으므로 이 이상적인 블록의 형태를 복원하는 예입니다. 더 가늘거나 작은 돌출은 같은 절차에서 남지 않을 수 있습니다.

C# 이진 마스크 처리 · 좌표와 소유권

ToArrayGray8은 처리된 마스크를 배열로 복사합니다. 값이 0 또는 255인지와 픽셀 배치를 함께 확인해야 하며 입력 영상과 결과 영상은 각각 using으로 정리합니다. 이 합성 배열은 실제 결함과 잡음을 구별하는 규칙 자체를 정해 주지 않습니다.

C# 이진 마스크 처리 · 오류와 판단

ROI가 블록에 딱 맞는 3×3인 경우와 외부 여유가 있는 5×5인 경우는 경계에서 비교할 필요가 있습니다. ROI 밖은 배경이므로 경계 접촉 여부가 중간 결과에 영향을 줍니다.

작은 흰 영역의 변화를 볼 때 원본과 결과의 같은 좌표를 비교한다. 영역 전체가 사라졌는지, 일부가 남았는지 확인하면 선택한 커널의 크기가 물체에 비해 적절한지 판단할 수 있다.
