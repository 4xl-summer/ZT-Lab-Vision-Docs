관련 API · 핵심 동작

형태학은 일반적으로 분할된 Gray8 마스크 다음에 사용합니다. Threshold는 밝기 비교로 0/255를 만들고 형태학은 그 전경의 공간 구조를 바꿉니다. 처리 후 FindBlobs로 성분 개수와 픽셀 면적을 측정하면 전처리의 영향을 수치로 확인할 수 있습니다.

관련 API · 입력과 결과

이진 열기·닫기는 비영 픽셀을 전경으로 정규화하지만 값 형태학은 밝기 값을 이용한 최소·최대 처리입니다. 둘을 같은 연산으로 두면 출력 수치와 검사 의미가 달라질 수 있습니다. 커널 크기와 입력 형식, 출력 형식을 호출 전에 확인하십시오.

관련 API · 좌표와 소유권

Python의 영상 close()는 소유 핸들을 해제하며 형태학 닫기는 close_binary()입니다. C#은 Close, Rust는 close를 사용하는 경로가 있으므로 언어별 이름과 수명 규칙을 함께 읽어야 합니다.

관련 API · 오류와 판단

ROI 안에서 처리한 결과는 원점을 보존하지만 ROI 밖을 배경으로 취급합니다. 원본 전체에 대한 위치나 실제 면적을 계산하려면 원점과 별도 보정 단계를 적용합니다.

임계 처리로 만든 마스크에 형태학을 적용하고 그 결과를 블롭 분석으로 넘길 수 있다. 마스크의 구멍이나 작은 영역이 바뀌면 성분의 면적과 개수도 바뀌므로 중간 결과를 보관해 비교한다.

예를 들어 두 객체 사이의 좁은 틈이 닫히면 뒤따르는 연결 성분 분석에서 하나의 객체로 묶일 수 있다.
