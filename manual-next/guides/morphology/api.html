언어별 공개 API 차이 · 핵심 동작

Rust와 C#의 이진 열기·닫기는 각각 open/close, Open/Close로 호출합니다. Python에서는 영상 객체의 close()가 자원 해제에 사용되므로 이진 닫기는 close_binary(kernel)입니다. 이름만 옮겨 적어 호출하면 연산 대신 영상이 닫힐 수 있습니다.

언어별 공개 API 차이 · 입력과 결과

각 언어에서 커널은 양의 홀수 정사각형 폭이고 이진 입력은 Gray8 비영 전경으로 해석합니다. 결과는 0/255인 새 영상입니다. 후속 Blob 수가 달라지는 것은 객체 목록을 정렬해서가 아니라 마스크의 연결 상태가 바뀌었기 때문입니다.

언어별 공개 API 차이 · 좌표와 소유권

밝기 값 자체의 최소·최대를 취하는 erode_values 계열은 이진 연산과 구별해야 합니다. 입력이 0과 255만 포함되어도 경계·형식·출력 계약을 확인하고 목적에 맞는 경로를 고르십시오. 3×3 폭은 세 번 반복이라는 뜻이 아닙니다.

언어별 공개 API 차이 · 오류와 판단

C#과 Python의 결과 영상은 명시적으로 해제하고 Rust 반환값은 소유권 범위 안에서 사용합니다. 지원하지 않는 형식이나 짝수 폭은 오류이며 성공한 빈 마스크와 구별해야 합니다.

침식과 팽창은 이웃의 전경 배치에 따라 결과를 바꾼다. 열기와 닫기는 이 기본 연산의 순서를 조합하므로 호출 이름뿐 아니라 처리 순서와 커널 크기를 함께 살핀다.
