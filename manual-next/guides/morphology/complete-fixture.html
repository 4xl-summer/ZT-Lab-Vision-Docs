합성 입력 전체 예제 · Morphology · 열기와 닫기

합성 입력 전체 예제의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

합성 입력 전체 예제

아래 사례는 고정 합성 데이터와 명시적 기대값을 사용합니다.

Rust
use zvision::{ZImage, ZResult};
fn main() -> ZResult<()> {
    let image = ZImage::new_gray8(3, 3, 255)?;
    let result = image.erode(3)?;
    assert_eq!(result.to_packed_vec()?, vec![0,0,0,0,255,0,0,0,0]);
    assert!(image.erode(2).is_err());
    Ok(())
}

3×3 전경의 침식은 가운데만 255; 짝수 폭은 오류입니다.

합성 입력 전체 예제 · 핵심 동작

Rust 전체 예제는 3×3의 모든 픽셀을 255로 만들고 폭 3 침식을 실행합니다. ROI 밖을 0으로 보므로 여덟 경계 픽셀은 구조 요소가 배경에 닿아 0이 되고 중심만 255로 남습니다. 행 우선 기대 배열은 [0,0,0,0,255,0,0,0,0]입니다.

합성 입력 전체 예제 · 입력과 결과

같은 예제는 폭 2를 전달했을 때 오류가 나는지도 확인합니다. 결과가 빈 마스크인 경우와 인자가 허용되지 않아 실패하는 경우를 구분하기 위한 검사입니다. 폭 1은 허용되며 공간 변형이 없는 대신 비영 값이 255로 정규화됩니다.

합성 입력 전체 예제 · 좌표와 소유권

new_gray8이 만든 원본을 침식 호출이 수정하지 않고 새 결과를 반환합니다. to_packed_vec()으로 결과의 보이는 픽셀을 복사하므로 벡터는 네이티브 영상의 공유 뷰가 아닙니다. 결과와 원본을 나란히 비교할 때 유용합니다.

합성 입력 전체 예제 · 오류와 판단

이 사례는 ROI의 외부 경계와 커널 크기를 분리해 확인하는 합성 시험입니다. 열기·닫기의 모든 모양이나 실제 결함 보존까지 이 한 배열로 검증했다고 보아서는 안 됩니다.

작은 마스크는 각 픽셀의 이웃을 직접 세어 결과를 살펴볼 수 있다. 입력의 폭과 높이, 커널과 전경 값을 함께 기록하면 다른 영상에서도 같은 설정을 재현하기 쉽다.
