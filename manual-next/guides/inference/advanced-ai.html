명시적 텐서 경로

Rust의 AdvancedAiEngine은 기본 이미지 추론과 별도입니다. 모델이 선언한 순서로 여러 AiTensor를 받고 F32, I32, I8, U8 데이터와 shape을 사용합니다. 입력 개수, 타입, 고정 차원은 메타데이터에 일치해야 하고 차원의 크기는 0이 아니어야 합니다. 결과도 모델 출력 순서이며 타입·고정 차원을 검사합니다.

AiPreprocessOptions는 width/height, resize(Stretch 또는 Letterbox), interpolation(Nearest 또는 Bilinear), channel_order(Rgb 또는 Bgr), pad, mean, std를 지정합니다. 이 별도 전처리 함수는 [0,1] 변환 후 채널별 (값−mean)/std의 F32 NCHW 텐서를 만들고 스케일·패딩·ROI 변환을 반환합니다. Letterbox는 반올림한 크기로 맞추고 기본 중앙 정렬에서 홀수로 남는 패딩을 오른쪽·아래에 둡니다. 학습 시 설정과 맞추고 좌표를 되돌릴 때 반환 변환을 사용하세요.

이 페이지는 기준 SDK 소스와 대조했습니다. 예제는 실행 환경에서 별도로 검증해야 하며 합성 데이터 결과는 실장비 정확도를 뜻하지 않습니다.

명시적 텐서 경로는 기본 AiModelSpec 기반 이미지 분류 경로와 입력 계약이 다릅니다. AdvancedAiEngine은 모델 입력 노드 순서대로 AiTensor 목록을 받아 각 텐서의 shape과 자료형을 메타데이터에 대조합니다. 정수 및 부동소수 자료를 표현할 수 있지만, 모델이 선언한 자료형과 다른 값을 자동으로 같은 것으로 취급하지 않습니다. 고정 차원은 일치해야 하며 입력 차원의 크기가 0이면 오류입니다.

별도 이미지 전처리는 Stretch 또는 Letterbox, 최근접 또는 선형 보간, RGB 또는 BGR 채널 순서를 지정합니다. 각 정규화된 성분에 (값−mean)/std를 적용하므로 학습 파이프라인과 동일한 mean과 std를 선택해야 합니다. Letterbox는 영상 비율에 맞게 크기를 정한 뒤 빈 영역을 채웁니다. 반환된 scale과 pad는 모델 좌표를 원래 ROI로 되돌릴 때 필요하며 기본 경로의 단순 비율 환산과 혼동하지 않습니다.

모양과 전처리 분리

AdvancedAiEngine은 명시적 AiTensor를 모델이 선언한 노드 순서로 받습니다. 예를 들어 모델의 고정 입력이 [1,1,8,8]이고 자료형이 F32라면 같은 차원과 타입의 데이터를 준비해야 합니다. 고정 차원이 8인데 7을 전달하거나 입력 노드 수가 다르면 자동으로 기본 이미지 경로의 스펙에 맞춰 주는 것이 아니라 오류가 납니다. 출력 텐서도 선언된 순서와 타입을 확인해 읽습니다.

별도 이미지 전처리에서는 채널 순서와 Stretch 또는 Letterbox, 보간 방식, 패딩 및 mean/std를 선택합니다. 픽셀을 0–1로 바꾼 뒤 채널별 (값−mean)/std를 적용하므로 mean=0.5, std=0.5, 정규화 값 1이면 결과는 1입니다. Letterbox의 스케일과 패딩을 무시하면 모델 상자를 입력 ROI에 잘못 표시할 수 있으므로 반환된 변환 정보를 함께 사용합니다. 이 설정은 모델 학습의 전처리와 대조해야 합니다.
