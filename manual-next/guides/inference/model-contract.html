CPU RTen 모델, ROI 추론과 분류·검출·분할·이상 결과.

상위 목차로 돌아가기

입력 텐서·결과 계약

기본 추론 경로는 RTen 모델의 입력과 출력이 각각 하나인 고정 F32 텐서를 요구합니다. 입력 shape은 [1, channels, height, width]입니다. channels=1이면 Gray8, 3이면 RGB8만 받습니다. ROI는 비어 있지 않고 영상 내부여야 하며 면적은 최대 1,048,576 픽셀입니다. ROI를 최근접 이웃으로 모델 크기에 맞추고 각 8비트 값을 255로 나누어 NCHW 순서로 만듭니다. 학습 전처리와 일치하는지 확인하세요.

작업출력 shapeclasses
Classification[1,C]2–256
Detection[1,N,6], N≤40961–256
Segmentation[1,C,H,W]2–256
Anomaly[1,1,H,W]1

모델 width×height는 최대 1,048,576, model_version은 0이 아닌 호출자 지정 추적 번호입니다. 모델은 1–64 MiB 범위가 아니라 비어 있지 않고 최대 64 MiB입니다. 기본 score_threshold와 iou_threshold는 각각 0.5, max_detections는 100이며 범위는 앞의 둘이 0–1, 마지막이 1–4096입니다. 출력 값이 유한하지 않거나 모델 shape이 맞지 않으면 오류입니다. 클래스 ID의 의미는 모델에 맞춘 외부 라벨 목록으로 관리하세요. CPU RTen 경로이며 GPU 지원을 가정하지 마세요.

기본 경로에서 ROI 픽셀은 모델 너비와 높이에 맞춰 최근접 방식으로 선택됩니다. 출력 위치 x에 대한 입력 열은 ROI 시작 열에 floor(x×ROI 폭/모델 폭)을 더한 위치입니다. 선택한 Gray8 또는 RGB8 성분은 255로 나뉘고 채널 우선으로 배치됩니다. 예를 들어 Gray8 값 0과 255는 각각 0.0과 1.0이 됩니다. 모델 학습 시 보간 또는 채널 순서가 달랐다면 같은 영상에서도 예측값이 달라질 수 있습니다.

작업별 출력 shape은 표의 C, H, W가 스펙의 클래스 수와 모델 크기를 뜻합니다. 분류의 C는 2–256, 검출은 1–256, 분할은 2–256이고 이상 탐지는 1입니다. model_version은 0이 아니어야 하며 입력과 출력의 값이 유한해야 합니다. 기본 score와 IoU 임계값은 0.5, 최대 검출 수는 100입니다. 이 값들은 결과를 제한하는 설정이지 모델 자체의 정확도를 나타내지 않습니다.
