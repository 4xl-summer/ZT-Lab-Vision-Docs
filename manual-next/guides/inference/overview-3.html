오류·주의사항

C# FromBytes는 신뢰된 RTen 바이트 및 고정 F32 입출력 계약을 요구합니다. 모든 ONNX 모델이 직접 호환된다고 단정하지 않습니다.

모델 파일을 읽었다는 사실과 해당 모델을 실행할 수 있다는 사실은 다릅니다. 기본 엔진은 비어 있지 않은 최대 64 MiB RTen 바이트를 받고, 입력과 출력이 각각 하나인 고정 F32 텐서의 메타데이터를 검사합니다. 예를 들어 스펙이 1채널이면 입력 차원은 [1,1,H,W]여야 합니다. 두 출력이 있거나 shape이 다르면 처리할 수 없으므로 모델과 스펙을 먼저 대조해야 합니다.

run에서는 영상 형식과 ROI의 범위를 다시 검사합니다. 3채널 스펙에 Gray8을 넘기거나 폭이 0인 영역을 지정하는 것은 빈 결과가 아니라 잘못된 입력입니다. 모델 출력에 유한하지 않은 값이 있거나 작업별 출력 shape이 다르면 실행 오류가 발생합니다. 검출 목록이 비어 있는 정상 결과와 이러한 오류를 분리해 기록하면 전처리 문제를 무검출로 잘못 판정하지 않을 수 있습니다.

무효 입력과 빈 결과

입력의 조건을 단계별로 나누면 오류를 좁히기 쉽습니다. 모델을 열 때에는 바이트 길이, 입출력 개수와 고정 shape을 보고, 실행할 때에는 영상의 픽셀 형식과 ROI를 확인합니다. channels=1인 스펙에 RGB8을 넘기거나 ROI의 너비가 0인 경우는 검출 대상이 없다는 결과가 아니라 호출 조건을 만족하지 않는 상황입니다.

반대로 유효한 모델과 영상에서 score 조건을 통과한 상자가 없다면 빈 검출 목록이 정상 반환될 수 있습니다. 후처리는 각 검출 행의 좌표 순서, 점수 범위와 클래스 ID를 검사하므로 결과가 잘못된 형식이면 걸러지는 상자와 별도로 오류가 납니다. 재현할 때 모델 스펙, ROI, 임계값과 실제 오류 단계를 남겨야 낮은 점수와 모델 계약 불일치를 같은 미검출로 묶지 않습니다.
