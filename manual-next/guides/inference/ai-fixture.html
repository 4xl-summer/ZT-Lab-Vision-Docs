분류 모델 호출 예제

호환 RTen 모델 파일이 따로 필요하며 모델과 입력은 합성입니다. 결과는 엔진과 영상이 닫힌 뒤에도 별도 소유합니다. 모델의 점수는 실제 실행으로 확인하세요.

Python
from pathlib import Path
from zvision import AiEngine, AiModelSpec, AiTask, ZImage
import sys

# 첫 인자: 호환되는 8×8 Gray8, 2클래스 RTen 모델 파일
model = Path(sys.argv[1]).read_bytes()
spec = AiModelSpec(AiTask.CLASSIFICATION, 8, 8, 1, 2, 1)
with AiEngine.from_bytes(model, spec) as engine:
    with ZImage.from_gray8(8, 8, bytes([96] * 64)) as image:
        result = engine.run(image, (0, 0, 8, 8))
with result:
    print(result.info.model_version, result.info.class_id, result.scores)

이 예제는 명령행 첫 인자로 호환 RTen 파일의 경로를 받습니다. 스펙은 분류, 입력 8×8, 단일 Gray8 채널, 두 클래스, 추적 버전 1입니다. 영상의 64개 픽셀을 96으로 채우고 전체 ROI를 run에 전달하므로 각 입력 텐서 값은 96/255입니다. 출력은 모델 파일에 따라 달라지며 파일이 없거나 메타데이터가 다르면 엔진 생성 또는 실행이 실패합니다.

엔진과 영상의 with 블록을 끝낸 뒤 별도 결과를 열어 버전, class_id와 scores를 출력합니다. 이 순서는 결과가 입력과 엔진의 임시 스코프를 벗어나 별도 소유됨을 확인하는 사용 흐름입니다. 라벨 이름은 모델과 함께 별도로 제공해야 하며 숫자 ID만으로 의미를 정할 수 없습니다. 제공된 결정론 모델 사례는 API 전처리와 결과 해석을 확인하기 위한 합성 그래프이므로 실제 학습 정확도에 대한 증거가 아닙니다.

정규화되는 입력 값

예제의 영상은 8×8 모든 픽셀이 96인 Gray8입니다. ROI도 전체 8×8이므로 크기를 맞추는 최근접 선택에서 각 모델 위치가 같은 밝기를 받습니다. 각 값은 F32로 255를 나눈 96/255, 약 0.37647이 됩니다. 클래스가 두 개인 모델은 [1,2] 출력을 내야 하지만 이 숫자만으로 어떤 클래스가 선택될지는 전달한 모델의 연산과 바이트에 달려 있습니다.

모델 파일은 첫 번째 명령행 인자로 별도로 제공해야 합니다. 파일이 없거나 빈 바이트, 입출력 메타데이터 불일치인 경우 결과 점수를 기대하기 전에 로딩 오류를 해결합니다. 결과는 엔진과 이미지 스코프가 끝난 뒤 읽으며 사용이 끝나면 결과도 닫습니다. 출력된 model_version은 스펙에 지정한 1이고 내용 해시는 아닙니다. 실제 라벨과 파일 식별자를 별도로 기록해 숫자 ID를 해석합니다.
