관련 API

기본 추론에서는 AiModelSpec으로 작업과 텐서 크기를 선언하고 AiEngine.from_bytes로 호환 모델을 준비합니다. run에 넣는 ROI는 현재 이미지 좌표이며 채널 수에 따라 Gray8 또는 RGB8이어야 합니다. 스펙과 모델이 맞는지 확인한 다음 결과의 작업 종류에 맞는 분류 점수, 검출 상자 또는 맵을 읽습니다. 버전은 호출자가 지정한 추적 값이므로 모델 파일과 함께 관리합니다.

고급 텐서 작업이 필요하면 AdvancedAiEngine과 AiTensor 경로를 검토합니다. 이 경로는 모델 입력 순서와 타입을 명시적으로 맞추며, 별도 이미지 전처리는 크기 조정, 채널 순서, 평균과 표준편차를 설정합니다. 기본 엔진의 고정 전처리와 동일하다고 가정하지 말고 사용한 설정을 결과와 함께 남깁니다. 결과 객체와 얻은 맵의 소유 기간도 각각 확인하고, 빈 결과와 호출 오류를 분리합니다.

작업별 결과 접근

모델을 준비할 때 AiModelSpec은 작업과 입력 크기·채널·클래스 수를 선언하고 AiEngine은 바이트를 검사해 실행 가능한 객체를 만듭니다. 이후 같은 스펙에 맞는 영상과 ROI를 run에 전달합니다. 각 픽셀은 최근접으로 선택되어 255로 나뉘므로, 모델을 바꿀 때 파일뿐 아니라 학습 입력의 정규화 방식도 확인해야 합니다. 버전 번호는 사용자가 지정한 추적 값입니다.

분류에서는 scores와 class_id, 검출에서는 상자의 좌표·점수·ID를 읽습니다. 분할과 이상 탐지는 맵을 얻는 흐름이 있으며 획득한 영상의 수명을 따로 관리합니다. 입력 전처리를 직접 정하거나 여러 명시적 텐서를 다루려면 AdvancedAiEngine 경로가 필요합니다. 기본 엔진의 F32 단일 입출력 규칙을 그 경로에 임의로 확장하지 말고 모델별 노드와 자료형을 확인합니다.
