관련 API · 핵심 동작

밝기 기반 파이프라인은 회색 영상 준비 후 threshold로 마스크를 만들고 필요하면 마스크의 연결 성분을 찾는 순서로 구성할 수 있습니다. 이 함수는 T 이상의 픽셀을 255로 표시하므로 어두운 물체를 선택하려는 작업이라면 원하는 전경 방향이 맞는지 먼저 확인해야 합니다.

관련 API · 입력과 결과

잡음이 큰 경우 가우시안 평활화를 앞에 둘 수 있지만 작은 결함이나 경계도 약화될 수 있습니다. 평활화는 Gray8·Gray16·GrayF32의 밝기 영상을 만들고, 임계값은 일곱 회색 형식에서 Gray8 마스크를 만듭니다. 두 연산의 형식과 결과 의미는 같지 않습니다.

관련 API · 좌표와 소유권

마스크의 작은 입자를 정리하기 위해 열기나 닫기를 사용할 때는 객체 면적이 변할 수 있습니다. 커널 폭과 처리 전후 마스크를 함께 확인한 뒤 Blob의 4·8 연결성을 정하십시오. ROI를 사용한 경우 로컬 중심과 부모 원점의 관계도 기록합니다.

관련 API · 오류와 판단

새 영상 결과는 언어별 소유권 규칙에 따라 해제합니다. 복사한 픽셀 배열은 별도 값이며 정상 빈 마스크와 예외를 구별하는 것이 후속 검사에서 중요합니다.

이진 마스크를 만든 뒤 형태학으로 작은 영역을 다듬거나 블롭 분석으로 연결 성분을 측정할 수 있다. 각 후속 단계는 마스크의 모양이나 해석을 바꾸므로 중간 결과를 확인한다.
