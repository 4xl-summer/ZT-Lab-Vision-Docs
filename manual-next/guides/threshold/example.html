C# 사용 예 · Threshold — 임계값 분할

C# 사용 예의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

C# 사용 예

C#
using ZVision;

using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var binary = source.Threshold(10.0);
var pixels = binary.ToArrayGray8(); // [0, 255, 255]

C# 시그니처 · Rust 시그니처 · Python 시그니처 · ROI 검사 예제

C# 사용 예 · 핵심 동작

C# 예제는 Gray8의 세 값 [9,10,11]에 T=10을 적용합니다. 원본에서 가장 작은 값만 기준 미만이므로 결과는 [0,255,255]입니다. 이 한 행의 합성 입력은 경계와 같은 값이 전경에 포함되는지 확인하도록 설계되었습니다.

C# 사용 예 · 입력과 결과

Threshold의 반환은 입력을 덮어쓴 같은 영상이 아니라 새 Gray8 이미지입니다. 예제의 원본과 결과는 각각 using으로 소유권을 정리합니다. ToArrayGray8은 보이는 결과 픽셀을 관리형 배열로 복사하므로 화면 표시 외에도 수치 검사를 할 수 있습니다.

C# 사용 예 · 좌표와 소유권

같은 배열에 T=12를 사용하면 모두 기준 미만이어서 [0,0,0]이 정상입니다. 반대로 T=9이면 모든 입력이 기준 이상이어서 [255,255,255]입니다. 이 경우 연산은 성공하지만 선택한 값이 대상 분리에 적절한지는 별도 문제입니다.

C# 사용 예 · 오류와 판단

색상 형식, 유한하지 않은 기준 또는 입력 부동소수 픽셀은 오류입니다. 실제 검사에서는 영상의 강도 스케일과 ROI를 기록하고, 합성 예제가 통과했다는 사실을 장비 성능의 근거로 사용하지 마십시오.

입력의 값 0, 6, 7, 8을 순서대로 비교하면 출력은 0, 0, 255, 255다. 특히 세 번째 값은 임계값과 같으므로 비교식에 등호가 포함된다는 사실을 보여준다.
