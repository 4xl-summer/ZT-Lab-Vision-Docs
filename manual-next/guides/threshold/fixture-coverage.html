사례는 합성 입력에 대한 기대값입니다. 실행 결과와 실제 장비 조건은 별도로 확인해야 합니다.

실행 사례와 검증 범위 · 핵심 동작

경계 사례 [9,10,11]에서 T=10은 [0,255,255]를 기대합니다. 다른 관리형 사례는 Gray8 [0,6,7,8]과 GrayF32 [-1,6.5,7,9]에 T=7을 적용하여 두 형식 모두 [0,0,255,255]를 확인하도록 설계되었습니다. 같은 값 7이 선택되는지가 핵심입니다.

실행 사례와 검증 범위 · 입력과 결과

이 사례들은 서로 다른 입력 형식에서 숫자를 직접 비교한다는 사실을 확인합니다. 부동소수 영상을 자동으로 정규화하거나 모든 색상 채널을 개별 임계값으로 처리한다는 뜻이 아닙니다. 입력의 스케일이 달라지면 T 역시 같은 단위로 선택해야 합니다.

실행 사례와 검증 범위 · 좌표와 소유권

실행 기록의 사례 ID는 입력과 언어를 연결하는 데 사용합니다. Python의 Gray8 배열 복사는 bytes이고 C#의 배열 복사는 관리형 byte 배열입니다. 값과 자료형을 모두 확인해야 같은 픽셀을 보고도 잘못된 비교로 시험이 실패하는 일을 피할 수 있습니다.

실행 사례와 검증 범위 · 오류와 판단

합성 사례는 알고리즘의 명시적 비교 규칙을 확인합니다. 촬영 조건, 생산 불량의 분포, 처리 시간에 대한 증거는 별도 데이터와 실행 결과로 준비하십시오.

정수와 부동소수 입력을 각각 확인하면 비교식이 경계에서 어떻게 작동하는지 볼 수 있다. 이 사례는 한 임계값의 예이므로 현장 영상의 밝기 범위까지 보장하지는 않는다.
