관련 API · 핵심 동작

가우시안 필터의 출력은 같은 형식의 밝기 영상입니다. 밝기에 따라 대상을 나누려면 그 결과에 임계값을 적용할 수 있으며, 이후 연결된 영역별 크기가 필요하면 Gray8 마스크에서 Blob 분석을 수행합니다. 필터와 분할은 각각 다른 결과를 만들기 때문에 중간 영상을 따로 확인하는 것이 좋습니다.

관련 API · 입력과 결과

경계 후보가 필요한 경우 Canny는 자체 가우시안 평활화 뒤 Sobel과 연결 판단을 적용합니다. 이미 흐리게 만든 영상에 다시 Canny를 적용하면 평활화가 두 번 들어가는 설계가 될 수 있으므로 커널과 σ를 의도적으로 선택해야 합니다. 결과 Canny 마스크를 원본 밝기 영상과 혼동하지 마십시오.

관련 API · 좌표와 소유권

ROI를 선택해 처리하면 ROI 가장자리를 복제하고 원점을 보존합니다. 전체 영상을 먼저 처리하는 흐름과 결과가 달라질 수 있으므로 영상 획득, ROI, 필터의 순서를 고정해 비교합니다.

관련 API · 오류와 판단

각 영상 결과는 독립 소유이며 언어별로 해제 또는 소유권 관리가 필요합니다. 숫자 범위가 다른 정수·부동소수 형식의 결과는 후속 임계값을 정할 때 각각의 픽셀 단위로 해석합니다.

노이즈를 줄인 후 경계 검출이나 임계 처리를 적용할 수 있다. 다만 평활화가 작은 물체나 날카로운 경계도 바꾸므로 후속 결과에서 보존해야 할 구조를 함께 확인한다.
