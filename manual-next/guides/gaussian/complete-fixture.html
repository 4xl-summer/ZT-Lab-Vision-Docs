합성 입력 전체 예제 · Gaussian Blur — 가우시안 평활화

합성 입력 전체 예제의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

합성 입력 전체 예제

아래 사례는 고정 합성 데이터와 명시적 기대값을 사용합니다.

Rust
use zvision::{ZImage, ZResult};
fn main() -> ZResult<()> {
    let image = ZImage::new_gray8(3, 3, 7)?;
    let result = image.gaussian_blur(3, 1.0)?;
    assert_eq!(result.to_packed_vec()?, vec![7; 9]);
    assert!(image.gaussian_blur(2, 1.0).is_err());
    Ok(())
}

3×3 상수 7 → 7 아홉 개; 폭 2는 오류입니다.

합성 입력 전체 예제 · 핵심 동작

Rust 예제의 3×3 영상은 모든 픽셀이 7입니다. 폭 3, σ 1로 처리해도 결과는 [7,7,7,7,7,7,7,7,7]입니다. 경계가 복제되고 이산 가중치의 합이 1이기 때문에 상수 입력은 평균 과정에서 바뀌지 않습니다. 이 기대값은 복잡한 소수 응답을 추정하지 않고 기본 정규화를 확인합니다.

합성 입력 전체 예제 · 입력과 결과

두 번째 단언은 커널 폭 2가 오류인지 검사합니다. σ가 1로 유효하더라도 짝수 폭은 중심을 갖는 계약을 만족하지 않으므로 성공한 빈 영상이 아닙니다. 각 인자를 따로 바꾸어 확인하면 어떤 조건이 실패 원인인지 알기 쉽습니다.

합성 입력 전체 예제 · 좌표와 소유권

new_gray8은 합성 입력을 만들고, gaussian_blur는 원본을 빌려 독립 결과를 반환합니다. to_packed_vec()은 결과의 보이는 화소를 행 우선 벡터로 복사합니다. 이 벡터는 원본 저장소를 공유하는 ROI와 구별해야 합니다.

합성 입력 전체 예제 · 오류와 판단

이 상수 예제는 에지 위치나 작은 점 결함의 보존을 검증하지 않습니다. 그런 판단에는 중앙 충격과 경계 부근 입력을 별도로 준비하고 각 출력 값을 실행 기록과 비교해야 합니다.

균일한 영상과 한 점만 밝은 영상을 나란히 보면 필터의 두 측면을 구분할 수 있다. 전자는 평탄한 영역의 유지 여부를, 후자는 주변으로 퍼지는 가중치의 효과를 보여준다.
