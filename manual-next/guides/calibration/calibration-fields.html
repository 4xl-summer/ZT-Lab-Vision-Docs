평면 보정 입출력

필드 / 타입의미 · 단위 · 유효 조건
mapping() / Mapping: Homography글로벌 픽셀→세계 평면의 가역 3×3 변환. Rust new는 역행렬 가능성 검증.

fit(pixels, world, unit)유한한 대응 좌표, 같은 수 최소 4쌍, 비퇴화 배치. 학습 픽셀은 글로벌.

evaluate(pixels, world, unit, tolerance)빈 배열 불가, 길이 일치, 유한한 tolerance ≥ 0. tolerance는 평가 world 단위.

residuals: CalibrationResidual[]observed_pixel, reference_world, predicted_world, predicted_pixel, error_world, error_pixel. 순서는 입력 대응 순서.

세계 단위와 픽셀 단위 잔차를 혼합하지 마세요. 점 배치가 퇴화하거나 역변환이 불가능한 경우, 유한하지 않은 입력 또는 계산은 오류입니다. 좌표계가 잘못됐어도 수치가 유효하면 오류 없이 잘못된 결과가 나올 수 있습니다.

평면 보정 설명은 ce902e85c340 소스와 대조했습니다. 제시된 합성 기대값은 손계산이고 실행 여부는 별도로 기록합니다. 장비 실측·생산 정확도는 검증하지 않았습니다.

보정 입력을 준비할 때 픽셀 배열에는 원본 영상 기준 위치를, 세계 배열에는 지정 단위의 대응 위치를 같은 순서로 넣습니다. 생성 결과는 호모그래피와 단위를 가지며, 변환할 때마다 출력 또는 입력 세계 단위를 명시할 수 있습니다. 이 단위 정보는 화면의 축 이름이 아니라 수치 변환에 참여하므로 보정 파일이나 측정 기록과 함께 보관해야 합니다.

예를 들어 같은 세계 위치를 밀리미터와 마이크로미터로 표현하면 숫자는 1000배 차이가 납니다. 평가의 허용치도 전달한 세계 단위와 일치해야 하며 픽셀 잔차는 그 단위 변환 대상이 아닙니다. 잘못된 대응 순서나 좌표 기준은 반드시 오류로 드러나지 않으므로 학습점이 아닌 별도 점을 변환하고 역방향 결과도 확인하십시오. 역행렬을 만들 수 없거나 계산이 비유한 경우에는 오류를 처리합니다.

입력 단위를 바꿀 때는 모든 세계점과 허용치가 같은 단위로 표현되었는지도 확인합니다. 수치의 위치만 보고 단위를 자동으로 추정하지 않으므로 변환 요청과 기록에 명시된 단위를 함께 대조하십시오.
