관련 문서

NCC 검색 예제 · Rust API · 결과

적용 상황과 원리

NCC 검색 예제는 모델, 영상, 설정과 결과를 실제 호출 순서로 보여 줍니다. 먼저 예제의 작은 배열에서 템플릿이 어느 위치에서 시작하는지 찾아보고, 템플릿 중심을 더해 반환점을 계산합니다. 원리 설명에서 계산한 점수가 예제의 고정 각도와 배율 조건에서 어떤 후보를 통과시키는지도 함께 확인하세요.

결과를 읽는 방법

Rust 모델 API에서는 소유 모델과 읽기 전용 MatchResult를 구분합니다. 별도의 결과 개념 문서는 빈 결과, 실행 객체 및 영상 임대의 수명을 다룹니다. 검색 결과를 검사나 표시 단계에 연결할 때 로컬 좌표와 전역 좌표를 확인하고, 결과 부재를 좌표 0으로 대체하지 않습니다. 사용할 모델을 바꾸는 경우 모델 선택 문서에서 입력 형식과 점수 방향도 비교해야 합니다.

추가 점검

검색 설정에 문제가 있는지 보려면 관련 예제의 각도 0과 배율 1부터 재현한 뒤 입력의 ROI와 원하는 각도를 한 번에 하나씩 바꿉니다. 자세를 넓히면서 반환 개수와 거리까지 동시에 바꾸면 어떤 조건이 결과를 바꾸었는지 판별하기 어렵습니다. 좌표와 수명 설명을 검출 결과를 소비하는 후속 단계에도 적용합니다. 기존 예제는 결과 출력의 기준점을 손으로 계산할 수 있습니다.

조건확인할 내용
원리를 확인정규화 상관과 마스크의 영향을 읽습니다.
좌표를 확인합성 패턴의 위치와 기준점을 직접 계산합니다.
반복 적용모델 수명과 저장, 결과의 독립성을 확인합니다.
