저장과 복원

모델의 save/Save는 버전 1 모델 파일을 쓰고 기존 경로를 덮어씁니다. load/Load는 별도 소유 모델을 만듭니다. 파일이 없거나 손상·지원하지 않는 형식이면 로드 오류를 처리하세요. 검색 설정과 검색 결과는 모델 파일에 포함된다고 가정하지 말고 애플리케이션 설정으로 관리하세요. Rust 저장과 로드는 이미지 I/O 기능이 필요합니다.

적용 상황과 원리

학습한 모델을 여러 번 사용하려면 저장과 복원을 선택할 수 있습니다. 모델 파일에는 학습된 데이터가 들어가지만 검색할 영상과 MatchSpec을 함께 관리해야 같은 결과를 비교할 수 있습니다. 저장은 지정 파일을 덮어쓰므로 이전 버전을 보존하려면 파일명을 구분합니다. 복원은 새 소유 모델을 만들고 파일 부재나 손상은 오류로 보고합니다.

결과를 읽는 방법

같은 합성 영상과 고정된 설정을 사용해 복원 전후 모델의 크기, 중심, 표본 수와 검색 결과를 비교하세요. 두 결과의 개수와 위치를 확인한 뒤 점수는 부동소수점 오차를 허용해 비교합니다. 저장된 모델을 잘못된 설정과 연결하면 정상적으로 로드되어도 기대 결과가 다를 수 있습니다. 파일 형식은 버전이 있는 SDK 모델 형식이며 외부 공급업체의 모델과 호환된다고 가정하지 않습니다.

추가 점검

복원된 모델의 정보에서 기준점이 의도한 템플릿 크기와 맞는지도 확인합니다. 모델 크기가 바뀌면 패턴 좌상단이 같아도 기준점이 달라질 수 있습니다. 따라서 결과 좌표 비교에는 모델 정보와 검색 영상의 원점을 같이 보관해야 합니다. 검증할 때 동일한 모델 종류와 검색 입력을 먼저 확인합니다. 설정이 달라지면 모델이 같아도 선택된 결과가 달라질 수 있습니다.

저장 후 비교 항목

조건확인할 내용
