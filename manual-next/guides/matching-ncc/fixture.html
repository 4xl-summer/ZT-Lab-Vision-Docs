합성 예제와 독립 기대값 · NCC 매칭

합성 예제와 독립 기대값에 대한 NCC 매칭 사용 안내

상위 목차로 돌아가기

합성 예제와 독립 기대값

템플릿은 3×2 [3,17,1,8,2,25], 검색 영상은 4×2 [0,3,17,1,0,8,2,25]입니다. 0도, 배율 1에서 동일한 패턴은 좌상단 (1,0)에 있으며 기준점은 (2,0.5)입니다. 원점이 (0,0)이므로 전역 좌표도 같습니다. 기대 결과는 하나, 점수 약 1, 표본 6개입니다. 부동소수점 점수는 허용 오차로 비교하세요. 이 합성 예는 실장비 성능을 뜻하지 않습니다.

Python
from zvision import ZImage, MatchModel, MatchSpec
with ZImage.from_gray8(3, 2, bytes([3,17,1,8,2,25])) as template, \
     ZImage.from_gray8(4, 2, bytes([0,3,17,1,0,8,2,25])) as source:
    with MatchModel.train_ncc(template) as model:
        spec = MatchSpec(0, 0, 1, 1, 1, 1, 0.99, 0, 1)
        result = model.find(source, spec)
if result.best is not None:
    print(result.best.position, result.best.score)

적용 상황과 원리

3×2 템플릿의 행은 3,17,1과 8,2,25이고 4×2 영상의 각 행은 그 앞에 0이 추가된 형태입니다. 완전히 같은 패턴이 검색 영상의 왼쪽 위 1,0에서 시작합니다. 모델 중심은 템플릿 로컬 1,0.5이므로 반환 기준점은 2,0.5입니다. 기본 원점이 0이어서 이 예에서는 전역 기준점도 동일합니다.

결과를 읽는 방법

설정은 각도를 0 하나, 배율을 1 하나로 고정합니다. 선택 마스크가 없으므로 여섯 픽셀이 학습에 쓰이고 동일한 비상수 패턴의 점수는 1에 가깝습니다. 검사 시 결과 개수와 좌표, 표본 수를 각각 확인하고 실수 점수에는 허용 오차를 둡니다. 이 예는 ROI 경계와 중심을 설명하는 합성 데이터이므로 회전 범위, 실제 조명이나 생산 처리 시간을 검증하는 자료는 아닙니다.

추가 점검

검색 영상 원점이 0이므로 이 사례는 글로벌 변환이 수치에 영향을 주지 않습니다. 원점이 있는 ROI에서 확인하려면 같은 로컬 좌표에 원점을 더한 별도 기대값을 만들어 비교해야 하며, 두 숫자를 같은 값으로 고정하면 안 됩니다. 마스크를 쓰지 않으므로 이 사례의 선택 픽셀 수는 템플릿 면적인 여섯입니다. 값이 같은 여섯 쌍을 비교하기 때문에 점수는 1에 가깝습니다. 결과 위치와 함께 모델의 선택 표본 수를 확인합니다.

수작업 좌표 검산

조건확인할 내용
템플릿 기준점(3−1)/2, (2−1)/2 = (1, 0.5)
패턴 왼쪽 위검색 영상 로컬 (1, 0)
반환 기준점(1, 0) + (1, 0.5) = (2, 0.5)

  • 좌표계와 적용 가능한 회전·크기 범위는 사용하는 API의 계약을 확인합니다.
