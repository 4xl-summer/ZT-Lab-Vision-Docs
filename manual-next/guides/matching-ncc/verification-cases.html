적용 상황과 원리

기록된 Python NCC 인라인 블록은 CPython 3.14, Linux x64에서 종료 코드 0으로 실행되었습니다. 코드가 값을 출력하도록 작성되어 있지만 자체 단언문은 없으므로 그 기록만을 점수와 좌표의 자동 비교로 해석하지 않습니다. 본문의 원래 코드 텍스트는 실행 기록의 해시와 대조할 수 있도록 유지합니다.

결과를 읽는 방법

별도 ncc-literal 통합 사례에는 검색 기준점 2,0.5, 선택 표본 6개, 마스크 선택 표본 4개와 일정 검색 영상의 빈 결과가 포함됩니다. 패턴의 좌상단과 모델 중심을 독립적으로 더하면 같은 기준점이 나옵니다. 이 자료는 합성 영상과 기록된 소프트웨어 환경에 한정됩니다. 카메라, 생산 샘플, 처리 속도 및 다른 플랫폼의 인수는 해당 조건에서 따로 검증해야 합니다.

추가 점검

마스크 표본 수 확인은 어떤 픽셀이 학습에 포함되었는지를, 일정 검색 영상은 평가할 수 없는 후보의 처리를 확인합니다. 완전한 일치 위치만 확인하는 테스트와 이 경계 검사는 서로 대체하지 않습니다. 모델의 저장·복원도 별도 단계로 시험해야 합니다. 기준점 좌표는 배열과 템플릿 크기로 독립적으로 계산한 값입니다. 확인한 플랫폼과 소스 버전을 사례와 연결해 보관합니다.
