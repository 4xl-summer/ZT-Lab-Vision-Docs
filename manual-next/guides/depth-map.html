DepthMap · 깊이 지도

결측을 유지하는 깊이 격자와 거리 단위·원점·프레임.

개념과 사용 흐름

DepthMap::new는 width/height, Vec<Option<f64>>, spacing_x/y, Point3 origin, LengthUnit, frame을 검증하여 깊이값을 소유합니다. roi와 share는 저장소를 공유합니다.

오류·주의사항

median은 유효 이웃 중앙값을 적용하고 fill_holes는 결측 중심만 보완합니다. to_point_cloud는 결측 슬롯을 포함하는 공간 점군으로 바꿉니다.

검증 기준

실측 깊이 0과 결측 None을 혼동하지 마세요. project 시 카메라 깊이 컨벤션을 확인하세요.

관련 설명 열기

격자·좌표·결측 계약

직교 격자의 셀 (x,y)에 값 h가 있으면 점은 (origin.x + x·spacing_x, origin.y + y·spacing_y, origin.z + h)입니다. 좌표와 h는 지정한 길이 단위를 사용하고 frame은 좌표계 식별자입니다. None은 결측이며 수치 0과 다릅니다. 각 슬롯의 순서를 유지하여 점군으로 변환합니다.

너비와 높이는 양수, 값 개수는 너비×높이, spacing은 유한한 양수, origin과 유효 높이는 유한수, frame은 0이 아니어야 합니다. ROI 좌표는 현재 맵 기준이고 저장소를 공유합니다. ROI의 원점은 x와 y 방향으로 각각 ROI 시작 좌표×spacing만큼 이동하며 z 원점은 유지됩니다. 유닛과 frame을 함께 기록하세요.

median(kernel, min_valid)과 fill_holes(kernel, min_valid)의 커널은 양의 홀수이고 유효 이웃 최소 수는 1부터 kernel²까지입니다. 경계에서는 이웃을 잘라냅니다. median은 결측 중심을 그대로 두고, fill_holes는 원본의 유효 이웃으로 결측 중심만 채웁니다. 유효 이웃이 부족하면 결측입니다.

합성 예제

다음 합성 입력의 기대값은 좌표식으로 계산할 수 있습니다. 실측 정확도 검증은 아닙니다.

Python
from zvision import DepthMap, Point3, LengthUnit

with DepthMap.from_values(3, 2, [1, None, 3, 4, 5, 6],
                          2, 3, Point3(10, 20, 30),
                          LengthUnit.MILLIMETER, 7) as depth:
    with depth.roi(1, 0, 2, 2) as roi, roi.to_point_cloud() as cloud:
        assert roi.info.origin == Point3(12, 20, 30)
        assert cloud.to_points()[1] == Point3(14, 20, 33)

관련 합성 실행 사례: spatial-depth.

원근 투영과 직교 격자

직교 변환과 별도로 PerspectiveCamera는 fx, fy, cx, cy 및 왜곡 계수 [k1,k2,p1,p2,k3]을 사용합니다. fx와 fy는 유한 양수, 나머지 값은 유한해야 합니다. DepthConvention의 Axial과 Range는 서로 다른 깊이 의미를 나타내므로 센서 정의에 맞게 선택합니다. 역왜곡 계산이 수렴하지 않거나 잘못된 파라미터면 오류를 처리해야 합니다. 투영 결과를 다시 래스터화할 때 충돌 선택은 Minimum, Maximum, Mean 중 지정합니다.

이 페이지는 기준 SDK 소스와 대조했습니다. 예제는 실행 환경에서 별도로 검증해야 하며 합성 데이터 결과는 실장비 정확도를 뜻하지 않습니다.
