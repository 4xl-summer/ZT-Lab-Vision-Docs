HSV·Lab·DeltaE76

색상 공간 변환 및 화이트밸런스·교정·색차 검사.

개념과 사용 흐름

ZImage.to_hsv와 to_lab은 ColorPlanes 결과를 반환하며 white_balance, color_correct, color_statistics는 색상 보정과 영역 통계를 제공합니다.

오류·주의사항

DeltaE76은 Lab 좌표의 유클리드 거리입니다. 조명과 카메라 색 재현성이 검사에 영향을 주므로 같은 수치를 절대 합격 기준으로 사용할 수 없습니다.

검증 기준

RGB/BGR 성분 순서와 ColorPlanes 채널 소유권을 확인하세요.

관련 설명 열기

색 인코딩과 거리

RGB는 인코딩된 sRGB로 해석하며 선형화와 백색점 변환을 거쳐 D50 2° 기준 CIELAB을 만듭니다. Lab의 세 채널은 독립 GrayF64 영상입니다. ΔE76 = √((ΔL*)²+(Δa*)²+(Δb*)²)는 Lab 좌표의 유클리드 거리이며 다른 색차식과 동일하지 않습니다.

입력계약
Rgb8/Bgr8, Rgb16/Bgr16, Rgba8/Bgra8채널 순서를 형식에 따라 해석
RgbF32각 채널 유한한 0..1
범위 밖 또는 NaN오류; 정규화와 채널 순서를 점검
알파RGB 색 변환에서 색 채널로 사용하지 않음

조명, 노출, 화이트 밸런스와 기준색이 바뀌면 거리도 달라집니다. 합성 RGB 샘플로 채널 순서를 검증하고 실제 샘플로 허용치를 정하십시오.

합성 입력 전체 예제

이 예제는 합성 입력을 사용합니다. 실제 촬영 데이터나 실행 성능을 나타내지 않습니다.

Rust
use zvision::{ZImage, ZResult};
fn main() -> ZResult<()> {
    let red = ZImage::new_rgb8(1, 1, [255, 0, 0])?;
    let lab = red.to_lab()?;
    let l = lab.acquire_channel(0)?;
    println!("{:?} {:?}", lab.space(), l.pixel_format());
    Ok(())
}

빨간색의 Lab은 대략 (54.29, 80.81, 69.89)이며 채널 인덱스는 0부터 2입니다. 결과와 획득한 채널은 소유 객체입니다.

색 평면과 수명

호출·필드입력·출력·실패
to_hsv(), to_lab()입력 이미지 외 별도 인자 없음; ColorPlanes 소유 결과, 원점과 크기 보존
space()Hsv 또는 Lab 좌표계 식별
acquire_channel(index)0, 1, 2의 독립 공유 GrayF64 이미지; 다른 인덱스는 오류
to_rgb(format)지원 RGB 형식으로 복원; 범위 밖 색은 출력 범위로 제한될 수 있음
수명평면과 획득한 채널은 각자 소유; 원본 해제 후에도 획득한 채널 유지
오류미지원 이미지 또는 RgbF32의 비유한/범위 밖 값; 형식과 0..1 정규화 확인

빨강 HSV는 (0°, 1, 1), Lab은 약 (54.29, 80.81, 69.89)입니다. 반올림 및 색 변환은 허용 오차로 비교합니다.
