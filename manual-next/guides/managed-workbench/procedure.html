검사 절차 · 관리형 Workbench

관리형 Workbench에서 검사 절차을 이해하기 위한 입력, 동작과 결과 설명

상위 목차로 돌아가기

검사 절차

  1. 이미지 열기 또는 합성 데모로 입력을 선택합니다.
  2. 입력 뷰에서 ROI를 지정하거나 ROI 해제로 전체를 선택합니다. 좌표는 입력 로컬입니다.
  3. 임계값과 최소 면적을 설정하고 검사 실행을 선택합니다. Gaussian 및 Close 설정은 설정 파일에서 가져올 수 있습니다.
  4. 결과 단계와 Blob 수, 시간 및 픽셀 값을 확인합니다. 맞춤과 1:1은 표시 배율을 바꾸며 검사 데이터를 변경하지 않습니다.
  5. 필요하면 결과 저장 또는 시도 기록 저장을 사용합니다. 기록 재실행은 현재 입력이 기록과 같은지 확인하고, 기록 비교는 저장된 조건과 결과를 비교합니다.

먼저 이미지 열기 또는 합성 데모를 선택하여 입력 영상 데이터를 준비합니다. 입력 뷰에서 관심 영역을 지정하면 그 영역은 입력 로컬 좌표로 해석되며, ROI 해제는 다시 전체 입력을 선택하는 흐름입니다. 임계값과 최소 면적을 조정하고 검사 실행을 선택한 뒤 출력 영상 데이터와 선택된 Blob을 비교합니다. 화면의 픽셀 확인 기능으로 예상한 위치와 밝기가 실제 입력에 있는지 살펴볼 수 있습니다.

처리 결과가 예상과 다르면 먼저 ROI 경계와 이진화 단계를 확인하고, 다음으로 닫기와 최소 면적 설정이 작은 요소를 어떻게 바꾸었는지 비교합니다. 맞춤과 1:1은 보기 도구이므로 검사 처리 결과를 수정하는 용도가 아닙니다. 설정 저장은 조건을, 처리 결과 저장과 시도 기록은 검사 처리 결과와 실행 내역을 다루는 별도 작업입니다. 다른 입력의 기록을 재실행할 때는 입력 일치 확인이 필요합니다.

검사 전에 설정을 저장해 두면 처리 결과를 다시 볼 때 임계값과 최소 면적이 어떤 값이었는지 함께 확인하기 쉽습니다.

설정을 변경한 후 다시 실행하면 새 처리 결과가 새 레시피 세대에 연결됩니다. 이전 입력에서 늦게 도착한 프레임은 현재 화면의 조건과 맞는지 확인해야 합니다. 저장된 조건과 처리 결과를 비교할 때에도 이용한 원본이 같은지 점검합니다.

입력에서 기록까지 확인

입력을 선택할 때 이미지 열기와 합성 데모는 출처가 다르지만, 이후에는 현재 입력의 프레임 세대와 레시피 버전이 결과를 구분합니다. ROI를 선택하면 좌표는 입력 로컬 범위입니다. ROI 해제를 누르면 선택을 지우고 전체 입력을 기준으로 검사하는 흐름으로 돌아갑니다. 픽셀 탐침을 사용할 때 화면 배율로 보이는 위치와 실제 로컬 픽셀 값을 함께 확인합니다.

임계값과 최소 면적을 바꾼 뒤 검사를 실행하고, 상태가 완료로 바뀌면 Blob 수와 경계를 봅니다. 후보가 기대보다 적으면 먼저 Threshold 단계에서 전경이 생겼는지 살펴보고, 그다음 Close 및 최소 면적 조건을 확인합니다. 예를 들어 기준보다 작은 요소는 화면에 밝은 픽셀이 있더라도 선택된 Blob 목록에 포함되지 않을 수 있습니다.

조건을 나중에 다시 사용하려면 설정 저장을, 한 번의 실행이나 여러 시도를 보존하려면 해당 결과·기록 저장을 선택합니다. 기록을 재실행할 때는 현재 입력 일치 확인을 통과해야 하며, 기록 비교는 두 저장 결과의 조건과 내용을 비교합니다. 합성 데모는 절차 확인에 편리하지만 현장의 불량 데이터와 같다고 취급하지 않습니다.

순서동작확인할 값

2임계값과 면적 설정현재 레시피
3검사와 표시세대·Blob·단계
4기록 저장 또는 재실행조건과 입력 일치
