검증 범위

이 안내는 제공된 프로젝트 소스의 정적 확인을 기반으로 합니다. 아래 콘솔 예제의 실행 여부와 별개로 WPF·WinForms 창 조작, 장비 연결과 실제 생산 판정은 여기에서 실행 확인하지 않았습니다.

이 페이지의 사례는 공개된 설정과 샘플 코드를 이해하기 위한 합성 입력을 이용합니다. 검증 사례에서 확인하는 대상은 정해진 영상 데이터와 조건에서 반환되는 상태, 픽셀 또는 후보 수처럼 구체적으로 재현 가능한 항목입니다. 검증 페이지의 사례 식별자를 통해 언어와 실제 실행 상태를 확인하고, 실행하지 않은 환경에 대해서는 소스 설명과 실행 처리 결과를 구분해서 읽어야 합니다.

관리형 표시와 Workbench의 경우 콘솔에서 처리 처리 결과를 계산하는 것과 WPF 또는 WinForms 창을 직접 조작하는 것은 다른 검증입니다. 화면 배치, 마우스 입력, 물리 카메라, 설비와의 연결 또는 실제 제품의 합격 판정은 합성 콘솔 출력만으로 확인되지 않습니다. 새 환경에 적용할 때는 이용하는 형식과 ROI, 표시 배율 및 해제 순서를 해당 환경에서 다시 검토합니다.

검증 기록에는 이용한 사례와 실행 여부를 함께 남기고, 정적 소스 대조만 한 영역을 GUI 실행 성공으로 표시하지 않습니다.

Workbench 설명의 범위

제공된 샘플 소스에는 이미지 열기, 합성 데모, ROI 해제, 검사 실행, 취소와 기록 저장 등의 동작이 연결되어 있습니다. 이 설명은 코드를 읽고 버튼과 검사 호스트의 관계를 이해하는 데 도움을 줍니다. 사용자의 실제 Windows 환경에서 창을 열고 모든 조작을 실행했다는 뜻으로 읽어서는 안 됩니다.

합성 입력을 이용한 콘솔 사례는 레시피가 기본 실행기를 거쳐 결과와 프레임을 만들 수 있는지 확인하는 별도 경로입니다. 그 성공 여부와 GUI에서 드래그한 ROI가 화면에 예상대로 표시되는지는 서로 다른 질문입니다. ROI를 검증할 때는 화면의 확대 상태, 로컬 사각형, 입력의 크기 및 결과 단계가 같은 실행을 가리키는지 함께 기록합니다.

기록 재실행도 저장한 조건만이 아니라 입력 일치 여부를 확인합니다. 실제 카메라, PLC 또는 생산 불량 영상에 대한 결과는 이 합성 샘플에 들어 있지 않습니다. 설비에 적용하기 전에는 해당 데이터와 장치, 오류 및 취소 동작을 해당 환경에서 따로 검토합니다.

범위확인 방법해석
버튼 연결샘플 소스 대조설명된 경로 확인
검사 실행합성 코드 결과지정 입력의 계산
화면 조작실제 GUI에서 확인 필요콘솔 결과와 구분
장비 적용별도 장치·데이터 시험샘플 결과로 대체 불가
