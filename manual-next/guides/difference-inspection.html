기준 영상과의 차분

AbsDiff는 현재 이미지와 기준 이미지에서 대응되는 성분의 차이 절댓값을 계산합니다. 대상이 같은 실제 위치에 정렬되어 있을 때 변화가 있는 영역을 밝게 표시할 수 있습니다.

D(x,y) = |I_current(x,y) − I_reference(x,y)|
Reference정상 기준
→
AbsDiff변화량 영상
→
Threshold변화 후보 마스크

실제 API 계약

조건의미
크기·형식두 이미지가 같아야 대응 성분 비교 가능
입력14종 이미지 코어의 형식별 경로; 비교 객체의 형식 일치 필수
부호 정수 차이양의 표현 상한을 초과하면 포화
출력새 이미지. 입력을 직접 변경하지 않음
정렬기준과 검사는 대응되는 실제 위치여야 함

C# 차분 파이프라인

C#
using System;
using ZVision;

using var reference = ZImage.FromGray8(3, 1, new byte[] { 10, 10, 10 });
using var current = ZImage.FromGray8(3, 1, new byte[] { 10, 70, 10 });
using var difference = current.AbsDiff(reference);
using var mask = difference.Threshold(25.0);

Console.WriteLine(string.Join(",", difference.ToArrayGray8())); // 0,60,0
Console.WriteLine(string.Join(",", mask.ToArrayGray8())); // 0,255,0

검사 적용 시 주의할 점

  • 정렬 오차만 있어도 차분 영상에 큰 경계가 발생할 수 있습니다.
  • 조명·노출 변화는 결함과 구분하지 못합니다.
  • 차분 후 Blob 분석으로 면적 조건을 적용할 수 있지만 검출률은 별도로 검증해야 합니다.
