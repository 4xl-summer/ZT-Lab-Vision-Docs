Morphology · 열기와 닫기

이진 침식·팽창과 합성 연산, 값 기반 Morphology를 구분하는 전처리 가이드.

이진 영역의 구조를 다루는 방법

형태학적 영상처리에서는 구조 요소에 따라 전경 영역을 축소·확장합니다. 이진 Gray8 마스크를 다루는 연산과 각 채널의 픽셀값에 직접 최소/최대 필터를 적용하는 값 Morphology는 서로 구분해야 합니다.

연산일반 원리자주 사용하는 목적
Erode / 침식전경을 줄임고립 전경 제거
Dilate / 팽창전경을 늘림연결/후보 확장
Open / 열기침식 후 팽창작은 밝은 돌출·점 잡음 정리
Close / 닫기팽창 후 침식작은 구멍·틈 보완

커널 숫자에 담긴 의미

Open(3)의 3은 반지름이 아니라 정사각형 구조 요소 한 변의 폭(픽셀)입니다. 크기가 커질수록 지워질 수 있는 세부 특성도 커지므로 결함 크기보다 큰 구조 요소를 무조건 선택해서는 안 됩니다.

언어별 공개 API 차이

작업RustC#Python
이진 열기image.open(3)image.Open(3)image.open(3)
이진 닫기image.close(3)image.Close(3)image.close_binary(3)
값 열기image.open_values(3)image.OpenValues(3)해당 언어의 실제 함수 확인
!Python의 close()는 이미지 객체를 해제하는 메서드입니다. 형태학적 닫기를 하려면 close_binary(kernel)를 호출해야 합니다.

C# 이진 마스크 처리

C#
using ZVision;

using var source = ZImage.FromGray8(5, 5, new byte[] {
    0, 0, 0, 0, 0,
    0, 255, 255, 255, 0,
    0, 255, 255, 255, 0,
    0, 255, 255, 255, 0,
    0, 0, 0, 0, 0
});
using var opened = source.Open(3);
byte[] output = opened.ToArrayGray8();

결함 제거 위험

고립점이 노이즈인지 검사해야 할 미세 결함인지는 영상처리 알고리즘이 판단해주지 않습니다. 처리 전후의 Blob 수, 픽셀 면적, 원본 이미지의 참값을 비교하고 과도한 커널이 결함을 지우지 않는지 확인합니다.

Blob 분석 · 픽셀 형식

폭, 반복과 영상 경계

이진 침식은 이웃이 모두 전경일 때, 팽창은 하나라도 전경일 때 255입니다. 0이 아닌 입력은 전경이며 결과는 0 또는 255입니다. 열기는 침식 후 팽창, 닫기는 팽창 후 침식입니다.

인자/상황의미
kernel=33×3 정사각형 폭, 반복 횟수 3이 아님
kernel=1공간 변화 없이 이진값 정규화
0 또는 짝수인자 오류
이미지 밖0으로 취급: 경계에 접한 전경은 침식될 수 있음

고급 임의 구조 요소 API의 반복 인자는 별도 계약입니다. 이진 연산과 밝기 최솟값/최댓값을 사용하는 erode_values 등은 목적이 다릅니다. 작은 간격과 가는 결함이 사라지는지 원본 마스크와 함께 확인하십시오.

입출력과 수명

항목계약
kernel기본값 없는 양의 홀수 폭; 1은 공간 변형 없이 비영값을 255로 정규화
입출력Gray8 비영 전경 → 새 Gray8 0/255; 크기와 ROI 원점 유지
실패비 Gray8, 0·짝수 폭, 크기 오버플로 또는 할당 실패. 더 작은 유효 폭과 입력을 확인
수명입력을 변경하지 않고 결과를 소유; C#은 Dispose, Python은 close 또는 with

합성 입력 전체 예제

아래 사례는 고정 합성 데이터와 명시적 기대값을 사용합니다.

Rust
use zvision::{ZImage, ZResult};
fn main() -> ZResult<()> {
    let image = ZImage::new_gray8(3, 3, 255)?;
    let result = image.erode(3)?;
    assert_eq!(result.to_packed_vec()?, vec![0,0,0,0,255,0,0,0,0]);
    assert!(image.erode(2).is_err());
    Ok(())
}

3×3 전경의 침식은 가운데만 255; 짝수 폭은 오류입니다.
