Blob Analysis · 연결 영역

이진 마스크에서 연결 성분을 찾아 면적·경계·무게중심을 값 객체로 얻는 방법.

픽셀에서 객체로

Blob은 Gray8 마스크에서 연결된 비제로 전경 픽셀들의 집합입니다. Threshold로 후보를 만들고 Blob 분석을 적용하면 면적, 경계 사각형, 무게중심을 가진 구조화된 결과를 얻습니다.

입력Gray8 영상
→
Threshold전경 분리
→
FindBlobs객체별 결과

4-연결과 8-연결

4-연결은 좌·우·상·하만 이웃으로 판단하고, 8-연결은 대각선도 포함합니다. 예를 들어 3×3 이미지에서 (0,0), (1,1), (2,2)만 전경이면 4-연결에서는 세 개의 Blob, 8-연결에서는 하나입니다.

연결성인정하는 이웃대각선 픽셀 결과
Four (4)상·하·좌·우분리된 컴포넌트
Eight (8)4방향 + 대각선 4방향연결된 컴포넌트

공개 Blob 값의 해석

필드단위·의미
Area전경 픽셀 수
X, YROI 지역 좌표의 경계 사각형 시작점
Width, Height경계 사각형의 픽셀 크기
CentroidX, CentroidY전경 픽셀 중심 평균 좌표

Rust typed Query 예제

Rust
use zvision::{Connectivity, ZImage};

fn main() -> zvision::ZResult<()> {
    let image = ZImage::from_vec_gray8(3, 1, vec![0, 5, 5])?;
    let plan = image.query()?.threshold(1)?.find_blobs(Connectivity::Four);
    let execution = plan.execute()?;
    assert_eq!(execution.output().blobs().len(), 1);
    assert_eq!(execution.output().blobs()[0].area, 2);
    Ok(())
}

이 수치는 공개 Facade의 기존 v23_query 테스트와 같은 입력·조건입니다. Rust Facade의 Blob 경로는 이 예제에서 ImageQuery를 사용하지만, C#/Python에는 직접 FindBlobs 호출도 있습니다.

검사에서 주의할 문제

  • 이진 마스크가 제대로 생성되지 않으면 Blob 분석만으로 좋은 결과가 나오지 않습니다.
  • ROI 지역 좌표와 원본 전체 좌표를 구분합니다.
  • 대각선 접촉 물체가 하나로 합쳐지는 것을 원치 않으면 4-연결을 검토합니다.
  • 면적을 원래 물리 단위로 변환할 때는 별도의 보정 계약을 적용합니다.
