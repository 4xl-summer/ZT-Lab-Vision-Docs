단계 실행, 결과 수명, 대기열과 취소

ZInspectionExecutor 는 Input → 선택 Roi → Gray → Blur → Threshold → Close → 통계 및 Blob 순서입니다. Gray8과 RGB/BGR/RGBA/BGRA 8비트 입력을 받습니다. 이것은 정렬 차분 판정기가 아니라 단계 영상과 분석 결과를 제공하는 별도의 실행기입니다. ZInspectionRecipe 기본값은 전체 ROI, GaussianKernel 3, GaussianSigma 1, Threshold 128, CloseKernel 3, MinArea 1입니다. 두 커널은 양의 홀수, sigma는 유한한 양수, 면적은 양수입니다. ROI는 입력 로컬 좌표이며 결과 Blob 경계도 단계 로컬 좌표입니다.

결과의 FrameId, RecipeVersion, StageNames, Statistics, Blobs, Metrics, Elapsed는 스냅샷입니다. AcquireStage 는 별도 해제할 영상 임대이며 없는 이름은 오류입니다. Threshold와 Close의 CreateDisplayFrame 은 선택 Blob 경계를 오버레이합니다. 프레임은 결과와 독립 소유입니다.

ZInspectionHost 는 단일 작업자와 유한 대기열을 사용합니다. capacity 기본 2, 범위 1–16이며 실행 중인 작업은 용량에 포함하지 않습니다. Submit 의 frameId와 recipeVersion은 양수입니다. Accepted에는 완료 Task가 있고 QueueFull 또는 Closed에는 없습니다. 수락 시 입력을 독립 임대하고 완료 시 해제합니다. 완료된 결과는 호출자가 해제합니다. 취소는 대기 중 또는 단계 사이에 적용되며 진행 중인 네이티브 호출을 강제 중단하지 않습니다. UI 스레드에서는 StopAsync 로 정리를 기다립니다.
