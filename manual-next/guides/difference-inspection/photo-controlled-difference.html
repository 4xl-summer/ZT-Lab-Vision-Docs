    측정 결과와 단위

    측정값결과단위해석
    통제 수정 면적384px²의도적으로 변경한 픽셀 수
    검출 픽셀384pxSDK 차분 마스크 전경
    검사 픽셀262144px전체 입력
    최대 점수7.53125ratio절대 차이를 32로 나눈 점수

    처리 순서

    1. 통제 수정 · NumPy 조건부 반전 명시된 24×16 영역만 0 또는 255로 바꾼 합성 결함입니다.
    2. SDK 차분 · ZImage.inspection_difference 보정 없음, 절댓값 및 한계 32를 사용합니다.
    3. 결과 위치 · SDK 마스크 / 독립 픽셀 비교 삽입 영역과 검출 마스크를 비교합니다.

    표시 영역과 실제 처리 범위

    표시된 24×16 사각형만 인위적으로 수정했습니다. SDK 차분 검사는 마스크 없이 512×512 전체 영상에서 수행합니다.

    인위적 수정 영역: x=220, y=180, 폭=24, 높이=16 px. 이 사각형의 의미와 실제 연산 범위는 위 설명을 따릅니다.

    파라미터

    threshold = 32
    원시 밝기 허용치
    correction = NONE
    전역 밝기 보정 없음
    injected_region = (220, 180, 24, 16)
    인위적 변화; 실제 결함 아님

    어떻게 검증했는가

    NumPy int16 절대 차이 >=32와 SDK 마스크의 전 픽셀 일치; 24×16=384

    공개 예제 사진을 입력으로 사용한 재현 예시입니다. 사용자 생산 영상이 아닙니다.

    길이와 면적은 픽셀 및 픽셀 제곱입니다. 실제 치수·장비 정확도·생산 합격 판정이 아닙니다.
