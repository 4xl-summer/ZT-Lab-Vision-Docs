실패와 대안

잘못된 옵션, 빈 포함 마스크, 크기·원점 불일치, 비유한 영상 값, 상수 NCC 학습 ROI는 오류입니다. 정렬 실패는 Found를 먼저 확인하고 재촬영 또는 검사 불가로 처리하세요. 원본의 차분만 필요하면 정렬을 생략하되 두 영상의 같은 크기와 원점 및 마스크 기하를 보장해야 합니다. 실제 생산 기준과 조명 안정성은 별도 검증이 필요합니다.

전체 레시피에서 입력 구성부터 해제까지 확인하세요.

정렬이 실패한 경우와 정렬 호출 자체가 오류인 경우는 다르게 처리합니다. 학습 무늬에 맞는 위치가 없거나 최소 유효 비율을 채우지 못하면 발견되지 않은 결과가 돌아올 수 있습니다. 이때 차분을 생략하고 재촬영 또는 검사 불가 상태로 넘겨야 합니다. 발견되지 않은 결과에서 정렬 이미지가나 유효 마스크를 바로 꺼내려고 하면 오류가 발생합니다.

반대로 ROI가 비어 있거나 입력 형식과 원점이 맞지 않는 경우, 잘못된 설정 또는 비유한 밝기 값은 입력 오류로 조사합니다. 포함 마스크가 모든 픽셀을 제외해도 비교할 집단이 없어 정상 합격으로 볼 수 없습니다. 실패 지점을 기록할 때에는 원본 이미지의 형식과 ROI, 검색 범위, 유효 픽셀 수를 함께 남기고, 이미 소유한 이미지와 결과는 예외가 난 경로에서도 정리합니다.

정렬이 안 된 이미지를 원본 기준에 바로 비교하면 이동 때문에 넓은 차이가 발생할 수 있습니다. 재촬영 여부는 발견 상태와 입력 적용 조건을 확인한 다음 결정합니다.

격자·값·옵션 순서로 점검

차분을 호출하기 전에 입력과 기준의 형식, 크기와 origin을 비교합니다. 기준은 Gray8, Gray16 또는 GrayF32이고 입력은 같은 형식이거나 정렬에서 얻은 GrayF64일 수 있습니다. 포함 마스크는 같은 기하의 Gray8이며 비제로 값이 선택을 뜻합니다. 마스크가 전부 0이면 계산할 픽셀이 없으므로 결과가 모두 정상이라는 뜻이 아니라 실패 조건입니다.

값과 옵션도 따로 살펴봅니다. threshold는 유한한 양수여야 하고 textureKernel은 양의 홀수, textureWeight는 유한한 0 이상입니다. 부동소수 입력의 비유한 값은 포함 여부만으로 안전하게 무시된다고 가정하지 않습니다. 입력 조건을 고친 뒤에도 점수가 예상과 다르면 correction과 polarity, 질감 가중치를 확인합니다.

예를 들어 DARKER 극성에서 입력이 기준보다 10 밝은 픽셀은 관심 방향이 아니므로 점수 0이 될 수 있습니다. 이는 차분이 실행되지 않았다는 뜻과 다릅니다. 정렬 결과에서 영상을 얻어 사용하는 경우에는 Found가 먼저 참인지 확인하고, 차분 실패 경로에서도 이미 얻은 정렬 결과와 영상을 각각 정리합니다.
