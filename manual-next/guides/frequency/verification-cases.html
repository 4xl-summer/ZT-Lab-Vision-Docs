관련 검증 사례

주파수 변환 사례는 rust-dft, dft, rust-fft로 구분되어 있습니다. 일반 DFT와 FFT는 서로 다른 연산 경로이므로 각 실행 기록에서 언어와 실제 함수, 입력 크기 및 정규화를 확인해야 합니다. 같은 예제 이름이 실제 장비에서 얻은 영상이나 속도 측정을 뜻하지는 않습니다.

각각의 상수 2×2 합성 영상은 Backward 순변환에서 DC 4와 나머지 0을 기대합니다. 역변환한 네 위치는 모두 1에 가까워야 하며, 부동소수 비교에는 기록된 허용 오차를 적용합니다. 배열 길이와 위치별 값을 함께 비교하면 총합은 맞지만 계수 배치가 잘못된 결과를 구분할 수 있습니다.

이 입력만으로 고주파 경계나 임의 마스크의 효과를 증명할 수는 없습니다. 특정 필터를 검토할 때는 해당 주파수 성분이 알려진 입력을 추가하고, 복소 성분을 유지한 역변환 결과까지 살펴보십시오.

사례 간 비교에서는 두 구현이 같은 정규화와 배열 순서를 썼는지 먼저 확인합니다. DC가 4인 것은 이 특정 Backward 입력의 기대값이며 정규화 설정을 바꾸면 같은 숫자를 그대로 기준으로 삼을 수 없습니다. 검증된 실행 기록과 새로운 문서 편집의 상태를 구분해 보고하십시오.

입력이 일정하지 않은 별도 패턴은 주파수 위치와 필터 적용 방향을 살피는 데 필요합니다. 검증 입력을 바꾸면 기대 계수도 다시 계산하십시오.

적용 순서와 결과 판독

검증에는 변환과 역변환을 따로 보기보다 왕복 결과를 함께 사용하는 것이 유용합니다. 2×2의 값이 모두 1이면 Backward 정규화의 순방향 결과는 DC 4와 나머지 0이고 역변환은 다시 네 개의 1입니다. 다른 정규화를 선택하면 계수 크기의 기대값도 해당 규칙으로 다시 계산해야 합니다. 필터를 적용한 사례는 마스크 없는 왕복이 맞는지 확인한 뒤 추가하여 변환 크기 문제와 필터 위치 문제를 분리하십시오.
