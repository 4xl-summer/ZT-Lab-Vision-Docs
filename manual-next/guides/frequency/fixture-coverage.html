사례는 합성 입력에 대한 기대값입니다. 실행 결과와 실제 장비 조건은 별도로 확인해야 합니다.

표에 나열된 일반 DFT와 FFT 사례는 서로 다른 공개 경로를 사용하므로 한 경로의 성공만으로 다른 경로의 크기 제약까지 검증했다고 간주하지 않습니다. 공통으로 확인할 수 있는 것은 작은 상수 영상의 DC 값과 역변환 결과입니다. 입력 네 값이 1이면 Backward 순변환 DC는 4이고 무필터 왕복의 기대 출력은 네 개의 1입니다.

사례 ID를 실행 기록과 연결할 때는 언어, SDK 소스 버전, 실제 입력과 비교 허용 오차를 함께 확인하십시오. 출력 길이가 원래 크기인지 패딩 크기인지도 점검해야 합니다. 부동소수 비교의 허용 오차는 테스트 조건이지 장비 측정 불확도가 아닙니다.

필터를 적용한 뒤에는 상수 영상 이외의 알려진 주파수 패턴으로 필요한 성분의 유지·감쇠를 따로 확인해야 합니다. 이 문서의 합성 기대값과 실제 촬영 데이터, GPU 성능 또는 생산 환경의 판단을 구분해 기록하십시오.

출력이 예상과 다를 때는 필터를 제거한 왕복부터 확인하여 크기·정규화 문제와 필터 설정 문제를 분리할 수 있습니다. 일반 DFT와 FFT 사례의 입력은 작지만, 이 사실만으로 더 큰 영상에서의 처리 시간이나 메모리 사용을 추정할 수 없습니다.

적용 순서와 결과 판독

작은 합성 입력은 인덱스와 정규화의 실수를 확인하는 기준점으로 적합합니다. 일정 영상은 DC를 확인하기 쉽지만 특정 방향의 주파수를 고르는 필터가 올바르게 동작하는지까지 혼자 입증하지는 않습니다. 따라서 다른 공간 패턴을 추가할 때는 먼저 그 패턴의 기대 계수와 배열 위치를 별도로 계산해야 합니다. 기존 2×2 왕복은 변환의 기본 경로를 확인하고, 새로운 패턴은 각각의 필터 선택과 방향을 살피는 역할로 구분합니다.

확인 단계판독과 조치
상수 영상DC와 정규화의 기본 결과를 확인합니다.
방향성 패턴목적 방향의 성분 위치를 별도로 확인합니다.
필터 없는 경로변환과 역변환의 왕복을 비교합니다.
필터 적용 경로마스크가 의도한 성분에 적용되는지 봅니다.
