주파수 필터 선택

필드조건과 의미
profileIdeal, Gaussian 또는 Butterworth; Butterworth 차수는 1..16
passLow, High, Band, Notch. 주파수 단위는 픽셀당 주기이며 각 축은 래핑됨
low, highlow는 유한 양수. Band에서는 high > low, 다른 pass에서는 high=0
center_x, center_yNotch에서는 각각 -0.5..0.5, 그 외에는 0; ±중심을 함께 억제
경계 오류유한하지 않은 값, 잘못된 차수·반경·중심은 오류. 값의 단위와 pass 조합을 확인

Ideal은 차단 경계가 날카롭고 공간 영역 링잉이 생길 수 있습니다. Gaussian은 완만하게 감쇠합니다. 결과 이미지와 스펙트럼 양쪽에서 신호 손실을 확인하십시오.

필터의 pass 종류는 어느 주파수 대역을 남길지 정하고 profile은 경계에서 응답이 어떻게 변하는지를 정합니다. Ideal은 급격한 경계를 사용하며 공간 영상에 링잉이 나타날 수 있고, Gaussian은 완만하게 감쇠합니다. Butterworth는 차수를 사용하므로 허용된 범위를 확인해야 합니다. 모두 같은 차단 반경을 입력해도 전이 모양은 같지 않습니다.

주파수는 픽셀당 주기이며 배열의 DC가 (0,0)에 있으므로 중앙을 원점으로 가정하면 마스크가 의도한 성분에 놓이지 않을 수 있습니다. Band는 두 반경의 순서가 필요하고 Notch는 중심 좌표를 이용합니다. 부적절한 pass와 필드 조합, 비유한 값은 입력 오류로 처리해야 합니다.

예를 들어 상수 2×2 영상에서는 신호가 DC에만 있으므로 저주파를 남기는 설정과 DC를 제거하는 설정의 결과가 다릅니다. 필터 적용 전후의 복소 스펙트럼과 공간 결과를 둘 다 확인해 필요한 정보까지 지워지지 않았는지 살펴보십시오.

적용 순서와 결과 판독

필터 경계의 모양과 차단 위치는 서로 다른 선택입니다. 같은 차단 주파수를 지정해도 급격한 경계와 완만한 전이는 주파수별 가중치가 다르므로 역변환 영상의 모습도 달라질 수 있습니다. 옵션을 비교할 때는 입력, 정규화, 변환 크기와 출력 영역을 고정한 뒤 한 옵션만 바꾸어 보십시오. 필터의 위치를 읽을 때는 표시를 위해 이동한 배열과 계산에 사용하는 원래 인덱스가 같은지 확인해야 합니다.

확인 단계판독과 조치
차단 위치어느 주파수 범위를 바꿀지 정합니다.
전이 형태경계 부근의 가중치 변화를 결정합니다.
배열 배치표시용 이동과 실제 마스크 위치를 구별합니다.
비교 조건크기와 정규화를 고정하고 옵션을 비교합니다.
