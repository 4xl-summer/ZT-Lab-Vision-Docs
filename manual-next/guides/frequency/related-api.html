관련 API

주파수 분석은 공간 영상에서 스펙트럼을 만드는 변환부터 시작합니다. 결과의 실수·허수 성분은 역변환에 사용하고, 진폭이나 위상은 주파수 내용을 살펴보는 표시 방식으로 선택합니다. DC 위치를 배열 원점으로 해석해야 필터 중심을 예상한 성분에 놓을 수 있습니다.

필터는 저역·고역·대역 또는 노치의 선택과 응답 곡선, 필요한 반경 및 중심을 함께 받습니다. 마스크 경로는 스펙트럼 크기에 맞는 값을 직접 준비하는 경우에 쓰며, 잘못된 길이나 비유한 값은 오류로 처리합니다. 필터링 결과를 원래 크기의 영상으로 비교하려면 역변환 후 자르기 설정을 확인해야 합니다.

스펙트럼과 필터 결과는 소유권과 해제 방법이 있는 객체입니다. 예제의 상수 영상에서 DC와 무필터 왕복을 확인한 다음 실제 목적의 주파수 패턴을 시험하면, 정규화 문제와 필터 자체의 효과를 구분하기 쉽습니다.

마스크가 복소 계수에 어떻게 적용되는지 확인하려면 마스크의 각 인덱스가 어느 주파수에 대응하는지 알아야 합니다. 화면 표시를 위해 배열을 재배치한 경우 원래 배열 순서의 마스크와 혼용하지 마십시오. 역변환 결과에 남은 경계나 진동은 필터의 전이 형태와 함께 해석해야 합니다.

실수부와 허수부가 함께 있어야 위상 정보를 유지한 왕복을 수행할 수 있습니다. 표시용 진폭 배열은 이 복소수 쌍과 다릅니다.

적용 순서와 결과 판독

주파수 작업은 공간 영상에서 복소 계수로 변환하고, 필요하면 마스크를 적용한 뒤 다시 공간 영상으로 복원하는 흐름입니다. 진폭을 보여 주는 화면은 복원에 필요한 복소수 전체와 다릅니다. 기본 왕복이 맞는지 먼저 확인하고 나서 마스크를 추가하면 변환 크기와 필터 위치의 오류를 나누어 살펴볼 수 있습니다. 2×2 상수 입력의 Backward 예에서는 순방향 DC가 4이고 역변환 결과가 다시 네 개의 1입니다.

확인 단계판독과 조치
순방향 변환영상의 복소 주파수 계수를 얻습니다.
스펙트럼 표시진폭 표시와 실제 복소 배열을 구별합니다.
마스크원래 배열 위치에 맞춰 계수에 적용합니다.
역변환복소 계수와 정규화로 공간 영상을 복원합니다.
