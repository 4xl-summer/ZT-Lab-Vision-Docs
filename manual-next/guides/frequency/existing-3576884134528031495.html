주파수 처리의 출발점은 영상으로부터 스펙트럼을 생성하는 연산입니다. 생성된 결과는 복소 성분을 소유하고 있으며, 진폭이나 위상처럼 화면에 표시할 값을 보는 연산과 원래 복소 데이터를 이용한 역변환은 목적이 다릅니다. 진폭만 저장한 그림은 허수부와 부호 정보를 모두 보존한 스펙트럼을 대체하지 못합니다.

필터링 또는 마스킹은 결과 스펙트럼을 만들고, 역변환은 다시 공간 영상이나 값 배열을 생성합니다. 크기와 정규화가 함께 맞아야 원본과 비교할 수 있으며, 패딩한 경우 원래 크기로 자르는 선택도 결과의 모양을 바꿉니다. C#의 스펙트럼은 소유 객체이므로 사용이 끝나면 지정된 해제 방법을 사용하십시오.

대표적인 확인 입력은 모든 값이 1인 2×2 영상입니다. Backward 순변환에서 DC 4와 나머지 0을 확인하고 무필터 역변환의 네 값을 1과 비교한 후, 필요한 필터가 원하는 성분을 남기는지 별도로 검사합니다.

마스크는 스펙트럼 각 위치에 적용될 값을 지정하므로 크기와 배열 배치를 일치시켜야 합니다. 스펙트럼의 표시는 복원에 사용할 복소수 자체와 구분하고, 역변환 뒤에는 패딩 크기와 원본 영역 중 무엇을 반환했는지 확인합니다. 이상적인 경계와 완만한 경계의 필터가 공간상에 다른 결과를 만들 수 있으므로 목적에 맞는 입력으로 비교하십시오.

적용 순서와 결과 판독

변환 호출을 연결할 때는 원본 크기와 변환 크기를 별도로 기록하십시오. 패딩을 사용하면 계수 배열의 크기가 원본보다 클 수 있고, 역변환 뒤 어느 영역을 사용할지도 확인해야 합니다. 표시용으로 중심을 옮긴 스펙트럼은 원래 인덱스 순서의 배열과 구별해야 마스크의 적용 위치를 잘못 읽지 않습니다. 위상은 복소수 정보에 들어 있으므로 화면에 보이는 진폭만 따로 저장한 값으로 원본을 복원한다고 가정해서는 안 됩니다.

확인 단계판독과 조치
원본 크기입력 영상의 폭과 높이입니다.
변환 크기패딩을 포함한 계수 배열의 크기입니다.
표시 배열시각화를 위한 배치와 실제 인덱스를 구별합니다.
복원 입력실수부와 허수부가 있는 복소 계수를 사용합니다.
