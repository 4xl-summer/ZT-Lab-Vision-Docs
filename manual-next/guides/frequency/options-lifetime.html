일반 DFT는 별도 API와 별도 크기 제한을 가집니다. 위 radix-2 FFT의 제한을 일반 DFT에 적용하지 마십시오.

FFT 계획의 너비와 높이는 변환 배열의 크기이며 입력 영상의 원래 크기와 구별됩니다. 이 경로에서 지정 크기는 입력 이상인 2의 거듭제곱이어야 하며 정규화 방식은 변환과 역변환을 연결하는 설정입니다. 크기를 늘려 패딩한 후 역변환할 때는 전체 배열을 볼지 원본 크기로 자를지 명시적으로 선택합니다.

진폭, 위상, 파워 등은 같은 복소 계수에서 계산한 다른 관찰값입니다. 원래 복소 성분의 슬라이스는 스펙트럼 소유자의 수명 안에서만 빌려 읽을 수 있지만, 필터나 마스크로 얻은 스펙트럼은 별도로 소유됩니다. 입력 영상을 해제했다고 이미 생성된 소유 스펙트럼이 자동으로 사라지는 것은 아닙니다.

마스크 길이가 변환 배열과 다르거나 비유한 값이 있으면 오류를 처리해야 합니다. 2×2 상수 영상의 무필터 왕복을 먼저 확인하면 크기와 정규화 설정을 진단하는 기준을 얻을 수 있습니다.

예를 들어 입력이 2×2이고 변환도 2×2이면 패딩 전후의 크기가 같습니다. 더 큰 변환 크기를 지정한 경우에는 그 전체 크기와 원본 크기가 달라지므로 어느 쪽 배열을 반환받았는지 먼저 확인해야 합니다.
