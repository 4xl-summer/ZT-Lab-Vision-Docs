오류·주의사항 · FFT · 주파수 필터

오류·주의사항의 입력 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

오류·주의사항

FftNormalization, 패딩, crop과 복소 스펙트럼을 구분해야 합니다. C# FrequencySpectrum은 IDisposable입니다.

변환 전후 결과를 비교할 때는 정규화 방식, 입력 크기와 변환 크기, 역변환 뒤 자를 영역을 함께 기록하십시오. 입력보다 큰 크기로 패딩했다면 전체 역변환 배열과 원본 크기로 자른 결과의 길이가 다를 수 있습니다. 둘 중 어느 배열을 비교하는지 정하지 않으면 올바른 계산도 크기 불일치처럼 보입니다.

복소수의 실수부와 허수부는 역변환에 함께 필요합니다. 진폭은 보기 쉬운 요약이지만 위상을 잃으므로 원래 스펙트럼으로 간주해 역변환해서는 안 됩니다. 필터나 마스크가 비유한 값이거나 길이가 스펙트럼에 맞지 않으면 오류가 발생할 수 있으므로 작성한 배열의 크기와 값 범위를 먼저 확인합니다.

C#에서 소유 스펙트럼을 더 이상 사용하지 않으면 Dispose합니다. 출력과 중간 결과가 어떤 객체에 속하는지 확인한 뒤 해제하고, 일반 DFT와 radix-2 FFT의 크기 제약을 서로 바꾸어 적용하지 마십시오.

입력의 유한성이나 마스크 길이 오류가 발생하면 계산 결과를 신호가 없는 영상으로 해석하지 마십시오. 호출이 실패한 경우와 정상적으로 성분을 0으로 만든 경우는 다른 상태입니다.

적용 순서와 결과 판독

주파수 처리에서 호출 오류는 필터가 모든 성분을 없앤 정상 출력과 다른 사건입니다. 배열 길이가 맞지 않거나 유한하지 않은 값이 전달되면 먼저 입력 준비를 고쳐야 하며, 결과가 어둡다는 이유로 오류를 성공한 0 영상으로 기록해서는 안 됩니다. 변환 크기, 마스크 길이, 정규화와 입력값을 한 번에 확인하고, 문제가 지속되면 마스크 없이 작은 입력의 왕복부터 분리해 재현하십시오. 이 순서는 입력 검증과 필터 효과를 구분하는 데 도움이 됩니다.

확인 단계판독과 조치
배열 크기 오류변환 크기와 전달 길이를 대조합니다.
비유한 입력입력 데이터의 생성 및 전달을 점검합니다.
마스크 없는 왕복필터 이전의 변환 경로를 확인합니다.
정상 0 성분성공 상태와 실제 계수를 함께 확인합니다.
