5. Python의 context manager

Python
from zvision import ZImage
with ZImage.from_gray8(2, 1, bytes([3, 4])) as image:
    with image.share() as shared:
        assert shared.to_array_gray8() == bytes([3, 4])

원리와 입력

Python에서는 ZImage와 모델처럼 close가 필요한 객체를 with로 감싸면 블록이 끝날 때 정리할 수 있습니다. 중첩된 원본과 결과 영상은 각각의 with 범위를 사용합니다. 예를 들어 원본으로 threshold를 호출하고 안쪽 블록에서 결과 배열을 복사하면, 안쪽이 끝나 결과 핸들이 닫힌 뒤에도 바깥 블록에서 원본을 계속 사용할 수 있습니다.

적용과 확인

독립 값 스냅샷과 소유 핸들은 같은 방식으로 다루지 않습니다. 이미지에서 얻은 복사된 bytes나 독립 매치 값은 핸들을 닫은 후 보관할 수 있지만, 닫힌 영상 자체에 다시 접근하면 오류가 발생합니다. Query 실행에서 캡처 영상 핸들을 얻었다면 실행을 닫기 전에 취득하고 그 영상도 별도 with 또는 close로 정리합니다. 프로그램이 길어질수록 반환 타입을 확인해 정리 범위를 작은 단위로 유지하면 예외 경로에서도 누락을 줄일 수 있습니다.

값과 판독 기준

단계입력 또는 결과확인할 점
입력with source원본 핸들 범위
결과with result반환 핸들 별도 범위
복사된 bytes영상과 별도 값핸들 종료 뒤 보관 가능
닫힘 후영상 재접근오류와 빈 결과 구분

적용할 때 살펴볼 점

바깥 with 안에서 결과를 별도 with로 열면 닫는 순서가 읽는 순서와 연결됩니다. 결과에서 bytes를 복사한 뒤 결과 블록을 빠져나오면 복사된 값과 닫힌 영상은 다른 상태입니다. 반복문에서 매번 새 영상이 반환되는 코드라면 각 반복의 범위가 끝날 때 정리되는지도 확인하세요. 예외가 발생한 경로도 같은 블록을 통해 정리됩니다.
