3. 언어별 생성/처리 예제 · ZImage

ZImage에서 3. 언어별 생성/처리 예제을 이해하기 위한 입력, 동작과 결과 설명

3. 언어별 생성/처리 예제

Rust
use zvision::ZImage;
fn main() -> zvision::ZResult<()> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    assert_eq!((source.width(), source.height()), (3, 1));
    assert_eq!(source.origin(), (0, 0));
    let mask = source.threshold(10.0)?;
    assert_eq!(mask.to_packed_vec()?, [0, 255, 255]);
    Ok(())
}
C#
using System;
using ZVision;

using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var mask = source.Threshold(10.0);
Console.WriteLine(string.Join(",", mask.ToArrayGray8())); // 0,255,255
Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as mask:
        assert mask.to_array_gray8() == bytes([0, 255, 255])

같은 픽셀 처리라도 언어별 소유권 표현이 다릅니다. Rust는 생성된 이미지 값을 소유하고 범위를 벗어날 때 정리하며, C#에서는 반환 이미지마다 using 또는 Dispose를 사용합니다. Python에서는 with나 close로 소유 객체를 정리합니다. 세 언어 모두 처리할 입력의 형식과 크기, 반환값이 새 이미지인지 값 스냅샷인지 먼저 확인해야 합니다.

예제의 [9,10,11]에 임계값 10을 적용하면 조건에 해당하는 뒤의 두 픽셀이 전경이 되어 [0,255,255]가 됩니다. 원본 배열의 숫자는 밝기이고 출력은 이진 마스크입니다. 입력 객체와 마스크는 서로 다른 소유 객체이므로 한쪽을 해제한 것을 다른 쪽의 해제로 생각하지 않습니다. 이 수치는 언어 간 호출 흐름을 비교하는 합성 사례입니다.

값을 읽는 배열의 구체적인 반환 형식은 언어별로 다르므로, 같은 숫자라도 Python bytes와 정수 목록의 비교 방식은 구별합니다.

세 언어의 예제는 같은 [9,10,11] 픽셀과 임계값 10을 사용하므로 출력 [0,255,255]를 비교하기 쉽습니다. 언어마다 객체를 닫는 표현은 달라도 각 반환 이미지가 별도 수명을 갖는다는 점은 함께 점검합니다.
