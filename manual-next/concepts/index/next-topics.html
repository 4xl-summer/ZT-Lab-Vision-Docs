원리와 입력

관심 영역을 처리할 계획이라면 ROI와 좌표 설명에서 시작하세요. ROI 로컬 (0,0)은 선택한 사각형의 좌상단이며 원본의 동일 좌표를 뜻하지 않습니다. 예를 들어 origin (1,1)에서 로컬 (1,0)은 전역 (2,1)입니다. 원본에 결과를 표시하거나 여러 영역의 위치를 비교할 때 이 변환이 필요합니다.

적용과 확인

수명과 Share 설명은 픽셀 저장소와 각 영상 핸들의 관계를 다룹니다. 원본을 닫았을 때 살아 있는 공유 핸들과 닫힌 원본을 구별하고, 별도 저장소가 필요하면 깊은 복사를 선택합니다. 픽셀 형식 설명에서는 Gray8과 GrayF32 같은 입력 형식 및 각 함수의 지원 범위를 확인하세요. 필요한 한 주제를 선택한 뒤 실제 언어 선언과 실행 예제로 이어가면 용어를 구체적인 입력과 연결할 수 있습니다.

읽기와 적용

ROI를 사용한 계산의 위치를 원본에 표시하려면 결과가 로컬인지 글로벌인지 알아야 합니다. 원점이 (1,1)인 ROI의 로컬 점 (1,0)은 원본 좌표 (2,1)이므로 보정 입력이나 화면 표시 전에 원점을 한 번 반영합니다. 반면 공유와 깊은 복사는 좌표 이동 자체가 아니라 저장소 관계에 관한 선택입니다. 자료 형식 문서에서는 같은 픽셀을 서로 다른 타입으로 넘겼을 때 호출이 허용되는지도 함께 확인합니다.

실행할 때 확인할 점

다음 주제를 고를 때에는 입력 영상이 이미 있는지부터 확인하세요. 촬영에서 시작한다면 장치 취득을, 저장된 파일이라면 영상 읽기와 픽셀 형식을 먼저 확인하면 이후 처리 결과를 해석하기 쉽습니다.
