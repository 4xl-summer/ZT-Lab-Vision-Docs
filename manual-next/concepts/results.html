결과 객체와 스냅샷

모델의 계산 결과를 이미지/모델 수명과 구분하여 안전하게 읽는 방법.

독립 HTML 페이지코드 검토 기준 2026-11-08초기 콘텐츠

Model과 Result의 책임

MatchModel은 학습 템플릿을 보유하고 find에서 탐색을 수행합니다. 결과를 담는 MatchResult는 검출된 일치 위치·점수 등의 값 스냅샷으로, 이미 해제된 원본 이미지나 모델의 네이티브 핸들에 의존하지 않습니다.

MatchModel학습 상태
→
find(image,spec)검출 실행
→
MatchResult읽기 전용 매치
언어목록 접근최고 매치
Rustresult.matches()result.best() → Option
C#result.Matchesresult.Best → nullable Match
Pythonresult.matchesresult.best → Match 또는 None

검출 결과가 없을 때

매칭 실패가 항상 함수 오류를 뜻하지는 않습니다. 검출되지 않은 경우 결과 목록은 비어 있고 best()는 Rust에서 None, C#에서 null, Python에서 None으로 표현됩니다.

C#에서 결과 읽기

C#
// model, image, spec을 정상 생성한 상태라고 가정합니다.
MatchResult result = model.Find(image, spec);
Match? best = result.Best;
if (best.HasValue)
{
    Console.WriteLine(best.Value.Score);
}

이것은 이미 준비된 객체를 사용하는 소비 코드 발췌입니다. 학습부터 전체 탐색까지 실행하는 완전한 예제는 별도 검증 후 추가합니다.

iMatch 점수는 확률이 아닙니다. ROI 지역 좌표와 원본 전역 좌표, 모델별 점수 의미를 구분해야 합니다. MatchResult의 값 스냅샷을 네이티브 자원인 MatchModel처럼 Dispose하지 않습니다.
