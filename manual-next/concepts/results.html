값 스냅샷과 소유 결과 구분

MatchModel 은 학습 템플릿을 보유하고 find 에서 탐색을 수행합니다. 결과를 담는 MatchResult 는 검출된 일치 위치·점수 등의 값 스냅샷으로, 이미 해제된 원본 이미지나 모델의 네이티브 핸들에 의존하지 않습니다.

매칭 실패가 항상 함수 오류를 뜻하지는 않습니다. 검출되지 않은 경우 결과 목록은 비어 있고 best() 는 Rust에서 None , C#에서 null , Python에서 None 으로 표현됩니다.

이것은 이미 준비된 객체를 사용하는 소비 코드 발췌입니다. 학습부터 전체 탐색까지 실행하는 완전한 예제는 별도 검증 후 추가합니다.
