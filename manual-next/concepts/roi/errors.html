6. 실패 원인과 진단

문제원인대응
범위 오류음수 좌표·0 이하 너비/높이 또는 원본 바깥 선택현재 이미지 폭·높이와 ROI 끝점 검증
픽셀값이 예상과 다름ROI 지역 좌표와 원본 전체 좌표 혼용origin·중첩 ROI 확인

원리와 입력

ROI 오류를 조사할 때는 먼저 입력의 보이는 너비와 높이, 시작점, 선택 폭과 높이를 한 묶음으로 기록합니다. 시작점이 영상 안에 있더라도 시작점에 폭이나 높이를 더한 경계가 밖으로 나가면 유효한 선택이 아닙니다. 예를 들어 폭 4인 영상에서 X=3, 폭=2를 요청하면 오른쪽으로 한 픽셀이 넘어갑니다. 이때 임계값이나 매칭 설정을 바꾸기 전에 사각형을 바로잡아야 합니다.

적용과 확인

선택 자체는 성공했는데 검출 표시가 틀리다면 origin을 더했는지, 이미 전역인 좌표에 다시 더하지 않았는지 확인합니다. 처리 결과의 데이터가 예상과 다를 때에는 packed 배열 읽기와 행 간격을 혼동하지 않았는지도 확인하세요. 닫힌 이미지 또는 ROI에서 호출하면 좌표와 무관한 수명 오류가 발생할 수 있습니다. 한 번에 여러 요소를 바꾸기보다 작은 합성 배열에서 크기·origin·픽셀 순서·해제 순서를 각각 검사하면 원인을 좁힐 수 있습니다.

값과 판독 기준

단계입력 또는 결과확인할 점
입력 폭4X 범위는 0부터 3
잘못된 선택X=3, 폭=2우측 경계 초과
표시 위치로컬과 origin전역 반영 여부 확인
접근 오류닫힌 핸들수명과 좌표 문제 구분

적용할 때 살펴볼 점

입력 크기와 사각형이 올바르다면 반환된 ROI의 크기와 원점을 기록하고 첫 행과 다음 행의 값을 각각 비교해 보세요. 보이는 폭과 stride를 혼동하면 첫 행은 우연히 맞고 둘째 행부터 틀릴 수 있습니다. 표시 오류와 별도로 데이터 자체가 다른지 확인하면 원점 문제인지 버퍼 읽기 문제인지 판단할 수 있습니다. 닫힌 객체 오류라면 좌표를 바꾸기보다 취득과 종료 순서를 먼저 확인합니다.
