2. 4×3 입력과 ROI 예제

원리와 입력

그림의 4×3 배열에서 각 행은 네 픽셀씩 왼쪽부터 읽습니다. (1,1)을 시작점으로 폭 2와 높이 2를 고르면 원본의 두 번째와 세 번째 열, 두 번째와 세 번째 행이 선택됩니다. 이 2×2 영역의 좌상단을 ROI 로컬 (0,0)으로 부르므로, 원본 좌표를 계산할 때 시작점 (1,1)을 한 번 더합니다. 오른쪽 아래는 로컬 (1,1), 원본 (2,2)입니다.

적용과 확인

그림은 선택 범위와 좌표를 설명하며 저장소 주소나 행당 바이트 수를 표현하지 않습니다. ROI의 너비가 2라고 해서 내부 행 간 간격도 반드시 2바이트인 것은 아닙니다. 안전한 픽셀 읽기는 SDK가 제공하는 행 뷰나 packed 복사 API를 사용하세요. 결과 위치를 원본에 그릴 때는 같은 원점을 두 번 더하지 않도록 로컬 결과와 전역 결과 중 어느 값을 받았는지도 확인합니다. 실제 센서 배열과 성능은 이 도식으로 판정하지 않습니다.

값과 판독 기준

단계입력 또는 결과확인할 점
원본폭 4, 높이 3행마다 네 픽셀
선택(1,1), 폭 2, 높이 2두 행과 두 열
로컬 좌상단(0,0)전역 (1,1)
로컬 우하단(1,1)전역 (2,2)

적용할 때 살펴볼 점

선택된 영역을 눈으로 검산할 때는 로컬 좌상단과 우하단을 각각 원본 배열에서 찾아보세요. 두 점 모두 일치하면 폭과 높이를 끝 좌표로 잘못 넣었는지 확인하기 쉽습니다. 처리 후 얻은 점이 ROI 안쪽에 보인다는 사실만으로 원본 위치까지 맞는 것은 아니므로 표시 단계에서 origin을 따로 기록합니다. 빈 영역이나 경계 밖 선택은 좌표 변환 결과로 취급하지 않고 입력 오류로 확인합니다.
