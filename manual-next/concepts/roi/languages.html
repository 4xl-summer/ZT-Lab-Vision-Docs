4. 언어별 ROI 호출

RustC#Python
image.roi(ZRect::new(x,y,w,h))?image.Roi(x,y,w,h)image.roi(x,y,w,h)

원리와 입력

세 언어 모두 이미지를 먼저 만들고 범위 안의 직사각형을 선택하지만 호출 인자의 모양은 다릅니다. Rust는 ZRect를 인자로 전달하는 ROI 호출을 사용하고, C#과 Python 예제는 x, y, width, height를 각각 전달합니다. 같은 네 숫자를 넣더라도 앞의 두 숫자는 시작 위치이고 뒤의 두 숫자는 끝 좌표가 아니라 크기입니다. 이 차이를 놓치면 원하는 영역보다 넓거나 좁은 결과가 생깁니다.

적용과 확인

호출이 성공한 뒤에는 결과의 크기와 origin을 확인하고 보이는 픽셀을 SDK 배열 또는 행 접근으로 읽습니다. Rust에서는 값의 소유 범위와 Drop을 따르고, C#은 using 또는 Dispose, Python은 with 또는 close로 별도 ROI 핸들을 정리합니다. ROI가 원본 저장소를 공유한다는 사실은 세 표현의 공통 개념이지만, 구체적인 매개변수 형식과 예외는 각 언어 선언을 확인하세요. 합성 4×3 입력으로 테스트하면 예상 픽셀을 직접 계산할 수 있습니다.

값과 판독 기준

단계입력 또는 결과확인할 점
Rustroi(ZRect)사각형 값으로 선택
C#Roi(x,y,w,h)네 인자를 전달
Pythonroi(x,y,w,h)네 인자를 전달
정리Drop / Dispose / closeROI도 별도 소유

적용할 때 살펴볼 점

언어별로 수명이 끝나는 지점도 표시해 두면 코드의 표면적인 차이가 실제 사용에 어떤 영향을 주는지 알 수 있습니다. 동일한 사각형을 전달했다면 반환된 폭과 높이, origin과 픽셀 순서를 세 환경에서 같은 기대값으로 비교할 수 있습니다. 다만 한 환경에서 확인한 실행 결과가 다른 런타임의 설치와 라이브러리 로딩까지 보장하지는 않습니다. 먼저 각 환경의 반환과 오류를 따로 확인하세요.
