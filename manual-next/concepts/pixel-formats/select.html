형식 선택 기준

측정 신호가 8비트 범위보다 넓다면 고비트 정수 또는 부동소수 형식을 검토합니다. 반면 Blob 분석처럼 이진 연결 영역을 계산할 때는 명확히 정의된 Gray8 전경을 사용합니다. 성분 변환 과정에서 정보 손실·반올림·NaN 오류를 확인하세요.

원리와 입력

형식은 원본이 담는 값과 다음 연산의 지원 조건을 함께 보고 고릅니다. 0–255 밝기 예제는 Gray8로 표현할 수 있지만 음수나 소수의 계산 결과를 그대로 다루려는 경우에는 해당 연산이 지원하는 부동소수점 형식이 필요한지 확인해야 합니다. 단순히 값 범위가 같아 보인다는 이유로 바이트 버퍼를 다른 형식으로 해석하지 마세요.

적용과 확인

처리 흐름에서는 입력 생성, 알고리즘 호출, 결과 읽기의 각 단계에서 형식이 바뀌는지 기록합니다. 예를 들어 GrayF32 입력에 임계값을 적용한 결과는 Gray8 마스크이므로 그다음 연결 영역 처리는 마스크 의미를 기준으로 설계합니다. 색 정보가 필요한 계산에서는 RGB 채널 순서와 변환 규칙을 확인하고, 유효하지 않은 깊이를 다룰 때는 DepthMap의 별도 계약을 확인합니다. 결과 정밀도와 허용 값은 선택한 함수의 참조에서 확인하세요.
