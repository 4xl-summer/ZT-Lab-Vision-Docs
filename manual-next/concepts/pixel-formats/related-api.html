관련 API

원리와 입력

ZImage에는 Gray8, GrayF32, RGB 등 형식별 생성과 읽기 경로가 있습니다. 입력의 폭·높이와 원소 배열이 해당 형식의 요구에 맞는지 먼저 확인하고 Info에서 실제 형식을 살펴보세요. ROI는 같은 저장소의 보이는 영역을 선택하므로 픽셀 형식을 자동으로 바꾸는 도구가 아닙니다. 보이는 영역을 packed 데이터로 얻고 싶다면 해당 형식의 복사 API를 선택합니다.

적용과 확인

Threshold는 지원되는 입력을 비교하고 Gray8 마스크를 반환하는 예입니다. Color 변환은 HSV나 Lab 결과의 채널을 얻는 별도 흐름이며, DepthMap과 PointCloud는 공간 단위와 결측 표현을 함께 다룹니다. 각 연산의 입력·출력 목록을 확인하고 다음 API에 넘길 수 있는지 판단하세요. 형식 불일치나 버퍼 길이 오류가 생기면 먼저 생성 단계의 값과 실제 Info를 비교하는 것이 빠릅니다.

값과 판독 기준

단계입력 또는 결과확인할 점
생성형식별 ZImage크기와 버퍼 길이
영역ROI / Origin형식은 자동 변경되지 않음
처리ThresholdGray8 마스크 반환
공간DepthMap / PointCloud길이 단위·결측값 확인

적용할 때 살펴볼 점

입력의 Info에 적힌 실제 형식과 다음 호출이 요구하는 형식을 비교하면 잘못된 버퍼 해석을 피할 수 있습니다. 결과가 영상이라면 출력 형식뿐 아니라 크기와 origin도 확인하세요. 특히 색 채널 값이나 깊이의 단위는 단순한 바이트 순서만으로 해석할 수 없습니다. 지원되지 않는 조합을 임의로 변환했다고 가정하지 말고 명시적 API를 사용합니다.
