ZImage · 이미지 객체

픽셀 데이터, 크기·형식·stride·origin을 갖는 소유 이미지와 실제 공개 API 사용법.

독립 HTML 페이지코드 검토 기준 2026-11-08설계 v1 적용 · 소스 대조

1. ZImage는 무엇을 소유하는가?

ZImage는 픽셀 데이터와 이미지의 크기·형식·레이아웃을 표현하는 공개 객체입니다. 이미지마다 하나의 독립된 픽셀 버퍼가 있는 것은 아닙니다. 원본, ROI, Share는 별도 소유 객체여도 같은 저장소를 공유할 수 있습니다. Rust의 공개 Facade는 코어 이미지를 감싸는 객체입니다.

범주공개 Rust API의미
생성new_gray8(width,height,value)초기값으로 채운 소유 Gray8 생성
소유권 인수from_vec_gray8(width,height,data)Vec를 이동하여 픽셀 복사 없이 저장
크기width(), height()픽셀 단위
형식/배치pixel_format(), layout()픽셀 형식, stride/offset
원점origin()원본 좌표계 좌상단
공유/선택share(), roi(ZRect)같은 저장소를 참조하는 새 소유 객체
분리clone_deep()보이는 영역을 독립 연속 저장소로 복사
처리threshold(value), query()새 소유 마스크 또는 지연 계획

2. 메모리와 원점의 관계

layout()은 현재 영상의 행 간격과 오프셋을 나타냅니다. ROI에서 가로 폭과 바이트 stride가 다를 수 있으므로 row-major로 직접 버퍼를 해석할 때는 주의하세요. 결과를 배열로 읽을 때는 Gray8이라면 Rust to_packed_vec(), C# ToArrayGray8(), Python to_array_gray8()처럼 공개된 복사 API를 활용할 수 있습니다.

3. 언어별 생성/처리 예제

Rust
use zvision::ZImage;
fn main() -> zvision::ZResult<()> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    assert_eq!((source.width(), source.height()), (3, 1));
    assert_eq!(source.origin(), (0, 0));
    let mask = source.threshold(10.0)?;
    assert_eq!(mask.to_packed_vec()?, [0, 255, 255]);
    Ok(())
}
C#
using System;
using ZVision;

using var source = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var mask = source.Threshold(10.0);
Console.WriteLine(string.Join(",", mask.ToArrayGray8())); // 0,255,255
Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as mask:
        assert mask.to_array_gray8() == [0, 255, 255]

4. 자주 혼동하는 처리 동작

호출저장소·결과사용 시점
share새 소유 이미지, 기존 저장소 공유원본을 함께 보존하면서 별도 수명 관리
roi새 소유 이미지, 기존 저장소의 부분 뷰관심 영역만 처리
clone_deep새 독립 저장소픽셀 저장소를 분리할 때
threshold새 Gray8 마스크밝기 조건으로 전경 분리
query지연 처리 계획중간 결과를 capture할 때

5. 실패·수명·검증 항목

roi는 현재 이미지 범위 내의 양수 폭·높이를 요구합니다. from_vec_gray8은 전달 데이터 길이가 픽셀 수와 맞아야 합니다. threshold는 특정 7종 Gray 형식만 지원하며 부동소수 데이터의 비유한 값이나 비유한 임계값을 오류로 처리합니다. C#에서는 각 반환 ZImage를 using으로 관리하고, Python은 with 사용을 권장합니다.

iRust ZImage의 width/height/layout/origin은 pub const fn입니다. 기존 자동 선언 색인에서 누락된 네 함수를 이 개정과 함께 보완했습니다. 함수가 단일 Rust 소스 파일에만 모여 있다고 가정해서는 안 됩니다.
