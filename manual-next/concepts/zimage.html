영상 생성, 기하와 연산의 반환

ZImage 는 픽셀 데이터와 이미지의 크기·형식·레이아웃을 표현하는 공개 객체입니다. 이미지마다 하나의 독립된 픽셀 버퍼가 있는 것은 아닙니다. 원본, ROI, Share는 별도 소유 객체여도 같은 저장소를 공유할 수 있습니다. Rust의 공개 Facade는 코어 이미지를 감싸는 객체입니다.

layout() 은 현재 영상의 행 간격과 오프셋을 나타냅니다. ROI에서 가로 폭과 바이트 stride가 다를 수 있으므로 row-major로 직접 버퍼를 해석할 때는 주의하세요. 결과를 배열로 읽을 때는 Gray8이라면 Rust to_packed_vec() , C# ToArrayGray8() , Python to_array_gray8() 처럼 공개된 복사 API를 활용할 수 있습니다.

roi 는 현재 이미지 범위 내의 양수 폭·높이를 요구합니다. from_vec_gray8 은 전달 데이터 길이가 픽셀 수와 맞아야 합니다. threshold 는 특정 7종 Gray 형식만 지원하며 부동소수 데이터의 비유한 값이나 비유한 임계값을 오류로 처리합니다. C#에서는 각 반환 ZImage 를 using 으로 관리하고, Python은 with 사용을 권장합니다.
