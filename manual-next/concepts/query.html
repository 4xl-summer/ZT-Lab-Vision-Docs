계획, typed 실행, 출력과 캡처

ZImage 의 직접 이미지 변환은 호출 즉시 계산하지만, ImageQuery 는 실행할 작업을 축적합니다. query() 가 입력 이미지 저장소를 공유하며 threshold() 등의 연산을 추가해도, 실제 픽셀 처리는 execute() 에서 발생합니다.

Rust 공개 Facade에서는 작업 추가 메서드가 self 를 소비해 새 계획을 반환합니다. 분기하려면 clone() 을 명시적으로 사용합니다. execute(&self) 는 계획을 빌려 여러 번 실행할 수 있습니다.

이 차이를 무시하고 var branch = query; 처럼 단순 별칭으로 분기하면 C#에서는 같은 계획을 함께 변경합니다. 두 언어의 객체 식별성이 동일하다고 가정하지 않습니다.
