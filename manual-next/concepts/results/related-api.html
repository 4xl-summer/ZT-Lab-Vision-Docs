적용 상황과 원리

반복 학습 상태는 MatchModel이 보유하고, 한 번의 직접 검색 값은 MatchResult가 나타냅니다. 검색이 정상 완료된 후에도 목록이 비어 있을 수 있으므로 최상위 결과의 선택 상태를 확인해야 합니다. 매치에는 로컬 위치와 원점을 더한 전역 위치가 모두 있어 다른 영역의 결과와 비교할 좌표계를 고를 수 있습니다.

결과를 읽는 방법

지연 처리에서는 Query와 실행 객체를 각각 정리합니다. QueryExecution의 값 출력과 별도로 얻은 영상은 수명이 서로 다르며, 가져온 영상은 호출자가 정리해야 합니다. InspectionDecisionResult 같은 판정 객체는 검사 상태와 사유를 제공하지만 입력 정렬이 되지 않은 것을 자동 합격으로 해석하지 않습니다. 각 API의 반환값이 값인지 자원 소유 객체인지 확인한 뒤 종료 순서를 정하세요.

추가 점검

결과가 표시용 이미지인지 계산된 값인지에 따라 다음 작업의 정리 책임이 달라집니다. 값 스냅샷은 이미 획득한 내용을 읽는 데 쓰고, 영상 출력은 별도 소유 객체로서 필요할 때만 획득해 정리합니다. 동일한 매치 좌표도 ROI 원점과 함께 보관해야 재해석할 수 있습니다. 결과 수가 0인 경우도 유효한 검사 흐름에 포함합니다.
