C#에서 결과 읽기에 대한 결과 객체 사용 안내

상위 목차로 돌아가기

C#에서 결과 읽기

C#
// model, image, spec을 정상 생성한 상태라고 가정합니다.
MatchResult result = model.Find(image, spec);
Match? best = result.Best;
if (best.HasValue)
{
    Console.WriteLine(best.Value.Score);
}

이것은 이미 준비된 객체를 사용하는 소비 코드 발췌입니다. 학습부터 전체 탐색까지 실행하는 완전한 예제는 별도 검증 후 추가합니다.

iMatch 점수는 확률이 아닙니다. ROI 지역 좌표와 원본 전역 좌표, 모델별 점수 의미를 구분해야 합니다. MatchResult의 값 스냅샷을 네이티브 자원인 MatchModel처럼 Dispose하지 않습니다.

적용 상황과 원리

이 코드는 이미 모델과 검색 영상 및 설정을 준비했다는 전제의 호출 부분입니다. Find는 독립 MatchResult 값을 반환하고 Best는 값이 있을 수도 없을 수도 있는 Match?입니다. HasValue가 참일 때만 Value를 읽으므로 결과가 없는 경우에도 안전하게 분기할 수 있습니다. Score는 모델 종류에 따른 점수이며 물체가 존재할 확률이 아닙니다.

결과를 읽는 방법

전체 예제에서는 먼저 템플릿 영상과 모델을 만들고 검색 설정을 지정해야 합니다. 영상과 모델은 네이티브 자원을 소유하므로 using이나 Dispose를 사용합니다. 반면 Find에서 이미 복사한 MatchResult에는 별도 Dispose가 필요하지 않습니다. 위치를 표시하거나 다른 측정에 전달할 때 Position은 검색 ROI 로컬, GlobalPosition은 원점이 반영된 값임을 확인합니다. 이 발췌는 그 전 과정을 대체하는 실행 프로그램이 아닙니다.
