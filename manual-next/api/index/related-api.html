관련 API

원리와 입력

언어별 색인은 동일한 목표를 각 SDK의 실제 선언으로 연결합니다. ZImage에서는 생성, ROI, 픽셀 읽기와 직접 처리를 확인하고, MatchModel에서는 템플릿 학습과 검색 결과의 관계를 확인할 수 있습니다. 임계값 예제의 입력 [9,10,11]과 기준 10은 반환 마스크 [0,255,255]를 손으로 점검하기 좋은 출발점입니다.

적용과 확인

처리를 묶을 때는 ImageQuery 및 형식별 실행 객체의 반환과 캡처를 살펴봅니다. 소유 영상이나 모델을 정리해야 하는지, 결과가 독립 값인지도 언어마다 표현이 다릅니다. 상세 참조의 타입과 인자 조건을 먼저 확인하고 관련 예제를 실행하세요. 색인 자체는 지원되지 않는 조합을 보증하지 않으며, 검증 기록은 표시된 SDK 버전과 환경에 맞춰 읽어야 합니다.

읽기와 적용

색인에서 검색한 이름을 열 때는 소속 타입과 언어도 함께 확인합니다. 예를 들어 영상의 직접 처리와 모델 검색은 둘 다 결과를 내지만, 전자는 보통 새 영상의 픽셀을 읽고 후자는 검색 위치와 점수를 판독합니다. Query 결과는 실행 후 출력이나 캡처를 획득하는 단계가 더 있습니다. 문서에 표시된 입력 조건과 결과의 수명을 따라 작은 예제를 실행한 뒤 필요한 기능으로 범위를 넓히는 것이 좋습니다.
