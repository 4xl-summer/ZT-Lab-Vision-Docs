평면 합성 예제

25개 점은 같은 평면에 있고 마지막 슬롯은 결측입니다. 실장비 정확도 시험은 아닙니다.

Python
from zvision import Point3, PointCloud, LengthUnit

points = [Point3(x, y, 2*x - 3*y + 4)
          for y in range(-2, 3) for x in range(-2, 3)]
with PointCloud.from_points(points + [None], LengthUnit.MILLIMETER, 1) as cloud:
    plane = cloud.fit_plane(1e-7)
    assert plane.inliers == plane.total == 25
    assert cloud.estimate_normals(5, Point3(0, 0, 100))[-1] is None

예제는 x와 y를 각각 -2부터 2까지 순회해 z=2x−3y+4인 점 25개를 만듭니다. 이 점들은 정확히 같은 평면에 있으므로 1e-7 길이 단위의 임계값에서 합의점과 전체 유효점이 모두 25라는 기대를 설정합니다. 목록 끝에는 None 하나를 추가해 실제 좌표와 결측 슬롯을 함께 다룹니다. 평면 점 개수는 25이고 전체 슬롯 수는 26이라는 차이가 중요합니다.

이후 5개 이웃과 시점 (0,0,100)으로 법선을 구하고 마지막 출력이 None인지 검사합니다. 마지막 원본이 결측이므로 법선이 만들어지지 않는다는 기대입니다. with 블록이 끝나면 소유 점군을 닫습니다. 평면 데이터는 코드에서 수식으로 생성한 합성 입력이므로 assert가 통과해도 센서 노이즈나 실제 표면에 대한 정확도를 보여 주지는 않습니다.

합성 평면의 표본 검산

코드의 x와 y는 각각 다섯 값이므로 5×5=25개 점이 생성됩니다. 예를 들어 x=1, y=2이면 z=2×1−3×2+4=0이고, x=0,y=0이면 z=4입니다. 두 점 모두 같은 식을 따릅니다. 마지막에 None을 추가하므로 점군 전체 슬롯은 26개이며 평면 피팅의 유효점 total은 25입니다. threshold 1e-7은 이 점군 길이 단위로 해석합니다.

코드는 inliers와 total이 각각 25인지 확인한 뒤 법선 목록의 마지막 항목이 None인지 확인합니다. 이는 마지막 원본 슬롯이 결측인 것과 대응합니다. viewpoint (0,0,100)은 법선 부호를 정하는 기준이며 결측 슬롯에 새로운 방향을 만들지 않습니다. with 범위를 나간 뒤 소유 점군은 닫힙니다. 같은 수식으로 만든 점들의 합성 성공은 실제 표면의 잡음이나 장비의 측정 정확도를 대신하지 않습니다.
