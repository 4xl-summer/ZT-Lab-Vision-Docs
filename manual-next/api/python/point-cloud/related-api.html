관련 API

PointCloud.from_points는 이미 준비된 3D 좌표와 None 슬롯을 소유 객체로 가져오는 시작점입니다. info는 프로퍼티로 크기와 유효 수, unit, frame을 제공하고 to_points()는 별도의 Python 목록을 만듭니다. 다른 좌표계로 이동할 때는 RigidTransform3의 방향과 단위를 맞춰 transform을 호출하고 반환된 새 객체를 닫아야 합니다. 입력을 공유할지 독립 데이터를 읽을지도 호출 목적에 따라 구분합니다.

국소 방향이 필요하면 estimate_normals가 슬롯별 선택 결과를 주고, 평면이나 원통이 필요하면 해당 fit 메서드의 합의점과 잔차를 판독합니다. 이들은 점군과 같은 단위의 거리 기준을 사용합니다. 상위 정합 경로는 추가로 목표 점군과 초기 자세가 필요합니다. 정상적인 결측 결과와 잘못된 값에 대한 오류를 구분하고, 결과를 실측 판정에 사용하기 전 보류 데이터를 준비합니다.

생성에서 결과 복사까지

PointCloud.from_points는 Point3 또는 None 순서와 길이 단위, frame을 묶습니다. 예를 들어 세 슬롯 중 하나가 None이면 info.count=3과 info.valid_count=2가 다른 이유를 확인할 수 있습니다. info는 값 프로퍼티이고 to_points()는 점 슬롯을 독립 목록으로 복사하는 메서드입니다. 목록을 수정해도 원래 점군에 대한 편집 호출이 되는 것은 아닙니다.

국소 방향이 필요하면 estimate_normals에 이웃 수와 viewpoint를 지정하고 슬롯별 None을 확인합니다. fit_plane과 fit_cylinder는 거리 임계값으로 전역 형상과 합의점 통계를 구합니다. 다른 점군으로 옮길 때는 frame 방향이 있는 RigidTransform3 또는 정합을 사용합니다. 입력과 새 소유 결과는 with로 각각 관리하고, 잘못된 설정 오류와 정상적인 결측 결과를 별도로 처리합니다.
