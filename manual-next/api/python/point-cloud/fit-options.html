피팅 옵션의 기본값과 제약

옵션기본값과 의미허용 조건
PlaneFitOptions.hypothesis_iterations / refinement_iterations512 / 64, 가설 및 정제 한도각각 1 이상
PlaneFitOptions.max_outlier_fraction1−f64::EPSILON, 허용 이상치 비율유한한 [0,1)
PlaneFitOptions.rms_tolerance0, 개선 중단 허용치, 점군 단위유한한 0 이상
CylinderFitOptions.max_iterations50, 단계별 반복 한도1 이상
CylinderFitOptions.max_outlier_fraction0.5−f64::EPSILON유한한 [0,1); 실제 피팅은 과반 지지가 필요
CylinderFitOptions.initial_axisNone, 자동 시드; 지정 시 정규화해 사용유한하고 0이 아닌 축
CylinderFitOptions.step_tolerance / rms_tolerance1e−10 무차원 / 0 점군 단위유한한 양수 / 유한한 0 이상
target_inlier_fraction (양쪽)None, 조기 종료 비활성지정 시 유한한 (0,1]

평면과 원통의 inlier_threshold는 유한 양수이며 점군 단위입니다. 유효점 부족이나 퇴화, 허용치 밖 설정은 오류로 반환합니다. Python 기본 fit_plane/fit_cylinder는 threshold만 받습니다. 언어별 고급 옵션 노출 여부는 해당 참조를 확인하세요.

관련 합성 실행 사례: spatial-depth, spatial-fit.

이 페이지는 기준 SDK 소스와 대조했습니다. 예제는 실행 환경에서 별도로 검증해야 하며 합성 데이터 결과는 실장비 정확도를 뜻하지 않습니다.

기본 Python fit_plane과 fit_cylinder는 각 함수에 거리 threshold를 전달합니다. 임계값은 점군의 길이 단위로 유한하고 양수여야 합니다. 값이 클수록 더 먼 점도 합의점으로 들어갈 수 있으므로 데이터의 오차 규모와 목표 공차에 맞춰 선택해야 합니다. 평면 결과의 합의점 수와 잔차를 같이 기록하면 임계값만 넓혀서 얻은 낮은 품질의 모델을 구별하기 쉽습니다.

고급 옵션을 제공하는 경로에서는 평면 가설·정제 반복, 원통 초기 축 및 반복, 이상치 비율, 목표 지지율을 추가로 제어합니다. 목표 지지율과 RMS 종료 기준은 탐색을 언제 멈출지에 관한 설정이고, 거리 임계값은 어떤 점을 지지점으로 볼지 정하는 설정입니다. Python의 기본 메서드 인자와 다른 언어의 설정 객체를 같은 시그니처로 추정하지 말고 사용 중인 경로의 선언을 확인합니다.
