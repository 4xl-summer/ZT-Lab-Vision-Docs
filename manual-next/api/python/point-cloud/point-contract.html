점군과 정합의 결과 판독

점군은 유효한 점과 결측 슬롯, 길이 단위, 0이 아닌 frame을 갖습니다. 변환의 입력·출력 frame과 단위가 데이터와 일치해야 합니다. 법선은 점별 선택값이므로 결측을 확인합니다. 평면·원통 피팅의 inliers와 total, 잔차를 보고 결과의 충분성을 판단하세요.

점대점 ICP는 초기 변환으로 원본을 대상 frame에 보낸 뒤 대응점을 찾아 정합합니다. IcpOptions의 max_iterations는 양수, max_distance는 유한 양수, trim_fraction은 (0,1], rms_tolerance는 유한한 0 이상입니다. 거리는 점군의 단위입니다. 최소 유효점은 양쪽 각각 3개이며 단위와 초기 변환의 frame이 일치해야 합니다. 결과의 transform, iterations, inliers, rms, converged를 함께 확인하세요. 수렴은 허용 정확도를 보증하지 않으므로 독립 점과 사용 공차로 검증합니다.

Python에서 frame은 좌표계 이름을 나타내는 0이 아닌 정수입니다. 원본과 목표의 좌표계가 다르면 RigidTransform3의 from_frame과 to_frame을 그 방향에 맞춰 설정해야 합니다. 이동 성분과 점 좌표는 동일한 길이 단위를 사용합니다. 변환된 점군의 info.frame은 목표 frame이고 None 슬롯은 그대로 보존됩니다. frame ID가 같다는 사실만으로 실제 보정이 정확하다는 의미까지 생기지는 않습니다.

ICP 결과의 transform은 원본을 목표 쪽으로 보내며 iterations, inliers, rms, converged가 계산 상태를 설명합니다. 대응 최대 거리는 점군 단위이고 trim_fraction은 유지 비율입니다. inliers가 적거나 RMS가 실제 허용치를 넘으면 수렴 여부와 별도로 결과를 평가해야 합니다. 합성 보류점으로 좌표식을 확인한 뒤 실측 장면에서는 가림과 잡음이 결과에 미치는 영향을 따로 검사합니다.

변환 방향과 결과 frame

원본 점군의 frame이 1이고 목표가 2인 순수 이동 (2,−3,4)를 생각해 보세요. 입력 점 (2,3,4)에 이동을 더하면 출력은 (4,0,8)이며 새 점군의 frame은 2입니다. 변환의 from_frame은 1, to_frame은 2로 준비해야 합니다. 동일한 수치라도 다른 길이 단위라면 이동량의 물리적 의미가 다르므로 점군과 변환의 unit도 일치시킵니다.

ICP는 이러한 초기 변환 뒤 대응점을 찾아 결과를 정제합니다. 최대 거리는 점군 단위이며 trim_fraction과 rms_tolerance는 각각 대응 유지 비율과 반복 종료 조건입니다. Registration의 converged가 참이어도 rms가 요구 공차 이하인지와 inliers가 충분한지를 별도로 봅니다. None 점은 변환으로 좌표가 생기지 않으며 잘못된 frame의 오류와 정상 결측을 분리해 처리합니다.

변환(2,−3,4)1 → 2
점(4,0,8)frame 2
