Python · ZImage.threshold

Python 공개 이미지 메서드의 임계값·결과 타입·컨텍스트 관리자 사용법.

공개 호출 형태

Python
from zvision import ZImage

# ZImage 객체 image가 준비되어 있을 때:
mask = image.threshold(t)

threshold(t)는 유한한 수를 입력받고 독립적으로 소유하는 Gray8 ZImage를 반환합니다.

계약

항목설명
입력7종 회색 형식의 ZImage
임계값유한한 수. 비교는 픽셀 ≥ t
출력Gray8, 각 픽셀 0 또는 255
수명close() 또는 with
실패유효하지 않은 인자 및 네이티브 연산 실패에 대한 오류

Python 전체 예제

Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as result:
        print(list(result.to_array_gray8()))  # [0, 255, 255]

기능 원리와 이미지 수명을 함께 확인하세요.

경계와 형식 선택

비교는 p ≥ T입니다. 아래 합성 입력은 경계값이 포함됨을 보여줍니다.

조건결과 또는 조치
T=10, [9,10,11][0,255,255]
유한한 T 및 7종 Gray새 Gray8 마스크
색상 이미지 또는 비유한 T/부동소수 입력오류; 입력 형식과 값을 먼저 검증

이미지 형식은 전체 14종이지만 이 연산의 입력은 그중 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64 일곱 종입니다. ROI에서 생성된 마스크는 ROI 원점을 보존합니다. 결과는 원본을 변경하지 않는 별도 소유 이미지입니다.

값과 실패 해석

조건결과·조치
픽셀 = T255; 비교 경계를 포함
T가 입력 최댓값보다 큼모든 픽셀이 0; 정상적인 빈 전경
NaN/무한 입력 또는 T오류; 유효 픽셀을 준비한 후 재호출
수명결과는 별도 소유 Gray8. C# Dispose, Python close/with, Rust 소유값 해제

실행 사례와 검증 범위

사례 ID언어확인할 기대값
threshold-gray8Python경계값 7 포함
threshold-grayf32Python부동소수 입력

사례는 합성 입력에 대한 기대값입니다. 실행 결과와 실제 장비 조건은 별도로 확인해야 합니다.

to_array_gray8()는 독립적인 bytes를 반환합니다. 위 예제는 숫자 목록으로 표시하려고 list()로 변환합니다.

관련 검증 사례

  • threshold-gray8
  • threshold-grayf32

관련 API

언어종류공개 심볼형식설명
C#메서드ZImage.ThresholdZVision.ZImage Threshold(System.Double t)7종 회색 형식에서 임계값 이상은 255, 그 외는 0인 Gray8 마스크를 만듭니다.
C#메서드ZImage.ThresholdZVision.ZImage Threshold(System.Byte t)7종 회색 형식의 픽셀을 임계값과 비교해 Gray8 마스크를 만듭니다.
Python메서드ZImage.threshold(self, t)임계값 이상을 255, 미만을 0으로 분할합니다.
Rust메서드ZImage.thresholdpub fn threshold(&self, threshold: f64) -> ZResult<Self>스칼라 픽셀이 임계값 이상이면 255, 미만이면 0인 Gray8 마스크를 반환합니다. 일곱 Gray 형식을 지원하고 원점을 보존합니다. 유한하지 않은 임계값, NaN/무한대인 부동소수 픽셀 및 컬러 형식은 기존 커널의 오류를 반환합니다.
