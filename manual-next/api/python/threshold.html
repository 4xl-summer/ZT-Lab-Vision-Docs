Python · ZImage.threshold

Python 공개 이미지 메서드의 임계값·결과 타입·컨텍스트 관리자 사용법.

독립 HTML 페이지코드 검토 기준 2026-11-08초기 콘텐츠

공개 호출 형태

Python
from zvision import ZImage

# ZImage 객체 image가 준비되어 있을 때:
mask = image.threshold(t)

threshold(t)는 유한한 수를 입력받고 독립적으로 소유하는 Gray8 ZImage를 반환합니다.

계약

항목설명
입력7종 회색 형식의 ZImage
임계값유한한 수. 비교는 픽셀 ≥ t
출력Gray8, 각 픽셀 0 또는 255
수명close() 또는 with
실패유효하지 않은 인자 및 네이티브 연산 실패에 대한 오류

Python 전체 예제

Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as result:
        print(result.to_array_gray8())  # [0, 255, 255]
