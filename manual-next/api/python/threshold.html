Python · ZImage.threshold

Python 공개 이미지 메서드의 임계값·결과 타입·컨텍스트 관리자 사용법.

이 장에서 배우는 내용

Python 공개 이미지 메서드의 임계값·결과 타입·컨텍스트 관리자 사용법.

threshold(t) 는 유한한 수를 입력받고 독립적으로 소유하는 Gray8 ZImage 를 반환합니다.

이미지 형식은 전체 14종이지만 이 연산의 입력은 그중 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64 일곱 종입니다. ROI에서 생성된 마스크는 ROI 원점을 보존합니다. 결과는 원본을 변경하지 않는 별도 소유 이미지입니다.

to_array_gray8() 는 독립적인 bytes 를 반환합니다. 위 예제는 숫자 목록으로 표시하려고 list() 로 변환합니다.
