MatchSpec은 angle_min, angle_max, angle_step, scale_min, scale_max, scale_step, min_score, min_distance, max_matches의 명시적 필드를 갖습니다.

Python에서 결과 읽기

Python
from zvision import MatchModel, MatchSpec

# template와 image는 이미 생성된 ZImage 객체입니다.
spec = MatchSpec(0.0, 0.0, 1.0,
                 1.0, 1.0, 1.0,
                 0.95, 0.0, 10)
with MatchModel.train_ncc(template) as model:
    result = model.find(image, spec)
    if result.best is not None:
        print(result.best.score)

관리되는 자원과 불변 결과

객체특성해제
MatchModel네이티브 학습 상태with / close
MatchSpecfrozen dataclass 값불필요
MatchResulttuple[Match,...] 독립 스냅샷불필요
Matchfrozen dataclass 자세·점수불필요

Python의 필드 이름은 snake_case이고 best는 메서드 호출이 아닌 속성입니다. C#의 Best 속성, Rust의 best() 메서드와 표기법이 다릅니다.

오류 상황

잘못된 데이터 타입은 TypeError/ValueError 계열의 검증 오류가 될 수 있으며 네이티브 검출 실패도 구분해야 합니다. 검출이 없으면 빈 matches와 None인 best를 정상적으로 처리합니다.
