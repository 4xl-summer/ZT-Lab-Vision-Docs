Python MatchModel

Python MatchModel의 원리와 사용 계약

학습하고 검색하기

모델과 영상은 with 또는 close()로 해제합니다. find 결과는 튜플을 보유한 독립 불변 스냅샷입니다. 지연 Query는 가변 계획이므로 호출 중 공유 수정하지 마세요.

합성 예제와 독립 기대값

템플릿은 3×2 [3,17,1,8,2,25], 검색 영상은 4×2 [0,3,17,1,0,8,2,25]입니다. 0도, 배율 1에서 동일한 패턴은 좌상단 (1,0)에 있으며 기준점은 (2,0.5)입니다. 원점이 (0,0)이므로 전역 좌표도 같습니다. 기대 결과는 하나, 점수 약 1, 표본 6개입니다. 부동소수점 점수는 허용 오차로 비교하세요. 이 합성 예는 실장비 성능을 뜻하지 않습니다.

Python
from zvision import ZImage, MatchModel, MatchSpec
with ZImage.from_gray8(3, 2, bytes([3,17,1,8,2,25])) as template, \
     ZImage.from_gray8(4, 2, bytes([0,3,17,1,0,8,2,25])) as source:
    with MatchModel.train_ncc(template) as model:
        spec = MatchSpec(0, 0, 1, 1, 1, 1, 0.99, 0, 1)
        result = model.find(source, spec)
if result.best is not None:
    print(result.best.position, result.best.score)

정규화 상관으로 포즈 찾기

선택 템플릿 값 T와 후보 패치 I의 평균을 각각 빼고 Σ((T−T̄)(I−Ī)) / √(Σ(T−T̄)² Σ(I−Ī)²)를 계산합니다. 분산이 있는 동일 패턴은 1에 가깝고, 밝기 오프셋과 양의 일정 배율에 둔감합니다. 음의 상관은 음수이지만 기본 검색의 점수 하한은 0 이상이므로 음의 점수는 선택할 수 없습니다. 점수는 확률이 아닙니다. 검색 패치의 분산이 0이면 그 후보는 점수가 없어 건너뜁니다.

입력, 좌표와 소유권

학습과 검색은 Gray8, Gray16, 유한한 GrayF32의 보이는 ROI를 사용합니다. 학습 마스크는 선택 사항이며 Gray8, 템플릿과 같은 크기 및 원점이어야 합니다. 0은 제외, 0이 아닌 값은 포함입니다. 선택된 픽셀은 두 개 이상이고 같은 값만 있어서는 안 됩니다. 모델은 픽셀과 마스크를 복사하므로 학습 후 템플릿을 해제해도 됩니다.

기준점은 템플릿 로컬 ((width−1)/2, (height−1)/2)입니다. 검색 결과의 위치는 검색 ROI 로컬 기준점이고 전역 위치는 여기에 검색 영상 원점을 더한 값입니다. 변환된 템플릿의 네 모서리 전체가 ROI 안에 있어야 평가합니다. 마스크로 모서리를 제외해도 이 조건은 변하지 않습니다. 회전과 배율에 따라 영상은 쌍선형 보간됩니다.

결과와 진단

각 매치는 위치와 전역 위치, 각도, 배율, 점수, 학습 표본 수를 담습니다. 점수 내림차순이며 동점은 로컬 y, x, 각도, 배율 오름차순입니다. 이미 선택된 중심과 거리가 min_distance보다 작으면 억제하고, 같은 거리는 허용합니다. 거리 0이면 중복도 억제하지 않습니다. max_matches에 도달하면 중지합니다.

허용 후보가 없으면 오류가 아니라 빈 결과이며 최상위 결과는 없습니다. 검색 영역이 작거나 회전된 모서리가 벗어남, 임계값 미달, 검색 패치 분산 0이 원인일 수 있습니다. 형식 불일치, 마스크 크기·원점 불일치, 비유한 픽셀, 상수 템플릿, 유효하지 않은 격자는 오류입니다. 입력과 설정을 먼저 점검하고 실제 불량 및 양품 이미지로 임계값을 조정하세요.

검색 설정과 격자

아래 이름은 Rust/Python 표기이며 C#은 PascalCase입니다. 생성자에 아홉 값을 모두 지정합니다. 이 형식에 적용되는 기본값은 없습니다. 검증은 검색 시 수행됩니다.

필드단위와 유효 범위
angle_min, angle_max라디안, −π ≤ 최소 ≤ 최대 ≤ π. 영상 좌표에서 양수는 시계 방향.
angle_step라디안, 유한한 양수
scale_min, scale_max등방 배율, 0 < 최소 ≤ 최대
scale_step배율 간격, 유한한 양수
min_score0..1 포함, 점수 하한
min_distance검색 영상 픽셀, 0 이상인 중심 거리
max_matches양의 정수, 반환 개수 상한

실수 인자는 모두 유한해야 합니다. 각 축은 min + i × step, i = 0 .. floor((max−min)/step)입니다. 최댓값이 격자에 맞을 때만 끝점을 방문하며 부동소수점 반올림에 주의하세요. 각 축은 최대 4096점이고 각도×배율도 최대 4096점입니다. 위치 후보는 보이는 영상의 각 픽셀 격자에 모델 기준점의 소수 부분을 더하여 평가합니다. 이것은 후보 예산 옵션이 아니며 작업량은 대략 영상 픽셀 수 × 각도 수 × 배율 수 × 표본 수에 비례합니다.

저장과 복원

모델의 save/Save는 버전 1 모델 파일을 쓰고 기존 경로를 덮어씁니다. load/Load는 별도 소유 모델을 만듭니다. 파일이 없거나 손상·지원하지 않는 형식이면 로드 오류를 처리하세요. 검색 설정과 검색 결과는 모델 파일에 포함된다고 가정하지 말고 애플리케이션 설정으로 관리하세요. Rust 저장과 로드는 이미지 I/O 기능이 필요합니다.

실무 설정 순서

  1. 반복되는 배경보다 물체를 식별하는 무늬를 포함하고, 가려지거나 변하는 영역을 학습 마스크에서 제외합니다.
  2. 기구 공차로 가능한 각도·배율을 한정하고 초기 간격을 정합니다. 간격 사이의 자세는 기본 검색이 직접 평가하지 않으므로 허용 오차보다 거칠지 않게 합니다.
  3. 양품·불량과 조명 변동 샘플로 점수 및 오검출을 비교하여 하한을 정합니다. 물체 간 예상 간격으로 중복 거리를 설정하고 결과 수를 제한합니다.
  4. 실제 처리 시간과 누락을 측정합니다. 넓은 범위에서 촘촘한 격자는 비용이 급격히 증가합니다. 피라미드 또는 다른 모델은 별도 API와 제약을 확인한 후 검증합니다.
