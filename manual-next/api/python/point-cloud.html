결측·단위·프레임을 보존하는 Python 점군

PointCloud.from_points(points, unit, frame) 는 Point3 또는 None 슬롯으로 생성합니다. info 는 프로퍼티이고 to_points() 는 점 목록을 반환합니다. 생성한 객체는 context manager로 닫습니다. 깊이 맵에서 생성할 때도 결측 슬롯의 위치를 보존합니다.

점군은 유효한 점과 결측 슬롯, 길이 단위, 0이 아닌 frame을 갖습니다. 변환의 입력·출력 frame과 단위가 데이터와 일치해야 합니다. 법선은 점별 선택값이므로 결측을 확인합니다. 평면·원통 피팅의 inliers와 total, 잔차를 보고 결과의 충분성을 판단하세요.

점대점 ICP는 초기 변환으로 원본을 대상 frame에 보낸 뒤 대응점을 찾아 정합합니다. IcpOptions 의 max_iterations는 양수, max_distance는 유한 양수, trim_fraction은 (0,1], rms_tolerance는 유한한 0 이상입니다. 거리는 점군의 단위입니다. 최소 유효점은 양쪽 각각 3개이며 단위와 초기 변환의 frame이 일치해야 합니다. 결과의 transform, iterations, inliers, rms, converged를 함께 확인하세요. 수렴은 허용 정확도를 보증하지 않으므로 독립 점과 사용 공차로 검증합니다.
