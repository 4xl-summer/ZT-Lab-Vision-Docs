학습하고 검색하기

모델과 영상은 with 또는 close()로 해제합니다. find 결과는 튜플을 보유한 독립 불변 스냅샷입니다. 지연 Query는 가변 계획이므로 호출 중 공유 수정하지 마세요.

적용 상황과 원리

Python에서는 템플릿 영상을 준비한 뒤 train_ncc로 모델을 만들고 MatchSpec에 아홉 값을 지정해 find를 호출합니다. 템플릿은 학습이 끝난 뒤 없어져도 모델이 보유한 복사본에 영향을 주지 않습니다. 결과의 best는 매치가 없으면 None입니다. 인덱스를 바로 사용하지 말고 먼저 이 상태를 검사하면 정상적인 미검출을 처리할 수 있습니다.

결과를 읽는 방법

영상과 모델은 with 블록 또는 close로 정리합니다. find가 반환하는 결과는 별도 네이티브 핸들을 소유하지 않는 값 스냅샷이며 matches는 불변 튜플입니다. 따라서 블록 밖에서 이미 얻은 결과를 읽는 것은 모델을 다시 호출하는 것과 다릅니다. 반대로 닫은 모델의 find를 다시 호출하거나 실행 도중 가변 Query 계획을 변경하는 설계는 피해야 합니다. 검색 결과의 좌표는 검색 영상의 ROI를 기준으로 읽습니다.

추가 점검

학습에 실패하면 그 원인이 영상 형식인지 선택 픽셀 수와 분산인지 먼저 확인합니다. 검색이 정상 완료된 뒤 결과가 없을 때는 같은 예외 분기로 바꾸지 말고 검사 대상이 없는 상태로 판독합니다. 반복 실행에서는 동일 모델을 유지하고 각 영상마다 독립 결과를 받아 기록할 수 있습니다.
