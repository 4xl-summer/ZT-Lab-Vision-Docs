입력, 좌표와 소유권 · Python MatchModel

입력, 좌표와 소유권에 대한 Python MatchModel 사용 안내

상위 목차로 돌아가기

입력, 좌표와 소유권

학습과 검색은 Gray8, Gray16, 유한한 GrayF32의 보이는 ROI를 사용합니다. 학습 마스크는 선택 사항이며 Gray8, 템플릿과 같은 크기 및 원점이어야 합니다. 0은 제외, 0이 아닌 값은 포함입니다. 선택된 픽셀은 두 개 이상이고 같은 값만 있어서는 안 됩니다. 모델은 픽셀과 마스크를 복사하므로 학습 후 템플릿을 해제해도 됩니다.

기준점은 템플릿 로컬 ((width−1)/2, (height−1)/2)입니다. 검색 결과의 위치는 검색 ROI 로컬 기준점이고 전역 위치는 여기에 검색 영상 원점을 더한 값입니다. 변환된 템플릿의 네 모서리 전체가 ROI 안에 있어야 평가합니다. 마스크로 모서리를 제외해도 이 조건은 변하지 않습니다. 회전과 배율에 따라 영상은 쌍선형 보간됩니다.

적용 상황과 원리

마스크가 없으면 템플릿의 모든 픽셀이 학습에 참여합니다. 마스크를 주면 값 0은 제외하고 그 외 값은 포함합니다. 크기뿐 아니라 원점이 같아야 같은 위치의 픽셀을 고를 수 있습니다. GrayF32 영상을 사용할 때는 실제로 읽는 값이 유한해야 합니다. 선택된 부분이 적어도 두 픽셀이고 값의 변화가 있어야 상관 모델을 만들 수 있습니다.

결과를 읽는 방법

검색 좌표는 템플릿의 왼쪽 위가 아니라 모델 중심을 나타냅니다. 폭이나 높이가 짝수이면 그 축의 기준점은 반 픽셀에 놓일 수 있습니다. ROI의 로컬 위치에 검색 영상의 원점을 더하면 전역 위치가 되므로, 원본에 표시하거나 다른 ROI의 결과와 비교할 때는 전역 좌표를 사용합니다. 검색 중 변환된 전체 템플릿의 네 모서리가 보이는 영역 안에 있어야 하며 학습 마스크는 이 경계 조건을 완화하지 않습니다.

추가 점검

마스크에서 하나의 픽셀만 남긴다면 그 값이 무엇이든 두 표본 이상 조건을 충족하지 못합니다. 두 점을 남겨도 같은 밝기라면 분산이 없습니다. 따라서 마스크 모양을 바꾼 후에는 모델 정보의 표본 수뿐 아니라 선택 값이 실제로 다른지도 확인합니다. 회전과 배율이 있는 경우 템플릿이 단순히 원래 크기의 축 정렬 사각형으로 들어가는지만 확인해서는 부족합니다.
