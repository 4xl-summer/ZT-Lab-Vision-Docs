적용 상황과 원리

관련 문서를 고를 때 먼저 어떤 문제를 확인하려는지 정합니다. 정규화 상관이 밝기 변화에 어떻게 반응하는지 이해하려면 NCC 설명을 보고, 좌표와 실제 결과를 손으로 따라가려면 합성 검색 예제를 사용합니다. 이 모델은 템플릿 전체에 대한 기준점을 반환하므로 화면에 사각형을 표시하려면 위치에서 템플릿 기준점을 빼는 계산이 별도로 필요합니다.

결과를 읽는 방법

Python에서 모델을 만드는 함수는 train_ncc이고 검색은 모델의 find입니다. 이 둘 사이에 불변 MatchSpec을 만들고, 결과에서 best가 None인지 확인한 뒤 점수와 자세를 읽습니다. 이미 얻은 MatchResult는 모델을 닫아도 유지되지만 새로운 검색을 실행하려면 열린 모델과 영상이 필요합니다. 저장과 복원은 검색 설정의 직렬화를 대신하지 않으므로 동일한 입력과 설정으로 결과를 다시 확인하는 절차를 두세요.

추가 점검

검색 후 다른 측정 단계로 넘어갈 때는 원본 좌표와 ROI 원점을 함께 보관합니다. 빈 결과에 임의 좌표를 넣으면 다음 단계에서 정상 검출처럼 보일 수 있으므로 None을 명시적으로 전파하는 편이 안전합니다. 소유 영상의 종료 시점과 복사된 결과의 수명도 별도로 기록합니다.
