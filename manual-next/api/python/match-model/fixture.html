합성 예제와 독립 기대값 · Python MatchModel

합성 예제와 독립 기대값에 대한 Python MatchModel 사용 안내

상위 목차로 돌아가기

합성 예제와 독립 기대값

템플릿은 3×2 [3,17,1,8,2,25], 검색 영상은 4×2 [0,3,17,1,0,8,2,25]입니다. 0도, 배율 1에서 동일한 패턴은 좌상단 (1,0)에 있으며 기준점은 (2,0.5)입니다. 원점이 (0,0)이므로 전역 좌표도 같습니다. 기대 결과는 하나, 점수 약 1, 표본 6개입니다. 부동소수점 점수는 허용 오차로 비교하세요. 이 합성 예는 실장비 성능을 뜻하지 않습니다.

Python
from zvision import ZImage, MatchModel, MatchSpec
with ZImage.from_gray8(3, 2, bytes([3,17,1,8,2,25])) as template, \
     ZImage.from_gray8(4, 2, bytes([0,3,17,1,0,8,2,25])) as source:
    with MatchModel.train_ncc(template) as model:
        spec = MatchSpec(0, 0, 1, 1, 1, 1, 0.99, 0, 1)
        result = model.find(source, spec)
if result.best is not None:
    print(result.best.position, result.best.score)

적용 상황과 원리

입력 바이트는 행 우선입니다. 템플릿의 첫 행은 3,17,1이고 두 번째 행은 8,2,25입니다. 검색 영상의 두 행에서 각각 첫 값을 건너뛰면 템플릿과 정확히 같은 여섯 값이 나옵니다. 왼쪽 위 위치가 1,0이므로 템플릿 기준점 1,0.5를 더한 검색 결과는 2,0.5입니다. 높이가 짝수이기 때문에 중심 y의 소수 부분은 0.5입니다.

결과를 읽는 방법

이 설정은 각도 0과 배율 1 하나씩만 평가합니다. 목표 위치에서는 점수가 1에 가깝고 여섯 픽셀이 선택되며, 최소 점수 0.99를 통과합니다. 결과가 존재하면 best의 위치와 표본 수를 확인하고 실수 점수는 오차 범위로 비교하세요. 학습과 검색의 입력은 예제에서 직접 만든 작은 바이트 배열이므로 파일 코덱, 실제 조명, 회전 허용 범위나 성능을 시험하는 사례는 아닙니다.

추가 점검

이 값은 단순히 최고 점수가 나온 위치를 베껴 적은 것이 아닙니다. 두 입력 행을 비교해 패턴의 시작 열을 찾고, 크기로부터 모델 기준점을 계산해 더한 독립 기대값입니다. 따라서 결과의 좌상단과 중심을 잘못 바꿔 반환하는 오류도 확인할 수 있습니다.

검색 ROI를 같은 픽셀로 유지하고 원점만 (7, 4)로 바꾸면 로컬 기준점은 (2, 0.5) 그대로이고 전역 기준점은 (9, 4.5)입니다. 이 변환은 예제의 모델 점수와는 별개의 좌표 계산입니다. 출력 배열의 저장 순서를 바꾸지 않도록 행과 열을 먼저 확인합니다.

수작업 좌표 검산

조건확인할 내용
템플릿 기준점(3−1)/2, (2−1)/2 = (1, 0.5)
패턴 왼쪽 위검색 영상 로컬 (1, 0)
반환 기준점(1, 0) + (1, 0.5) = (2, 0.5)
