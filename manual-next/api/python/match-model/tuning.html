실무 설정 순서 · Python MatchModel

실무 설정 순서에 대한 Python MatchModel 사용 안내

상위 목차로 돌아가기

실무 설정 순서

  1. 반복되는 배경보다 물체를 식별하는 무늬를 포함하고, 가려지거나 변하는 영역을 학습 마스크에서 제외합니다.
  2. 기구 공차로 가능한 각도·배율을 한정하고 초기 간격을 정합니다. 간격 사이의 자세는 기본 검색이 직접 평가하지 않으므로 허용 오차보다 거칠지 않게 합니다.
  3. 양품·불량과 조명 변동 샘플로 점수 및 오검출을 비교하여 하한을 정합니다. 물체 간 예상 간격으로 중복 거리를 설정하고 결과 수를 제한합니다.
  4. 실제 처리 시간과 누락을 측정합니다. 넓은 범위에서 촘촘한 격자는 비용이 급격히 증가합니다. 피라미드 또는 다른 모델은 별도 API와 제약을 확인한 후 검증합니다.

적용 상황과 원리

Python에서 같은 모델을 반복 적용할 때는 템플릿을 고정한 상태에서 입력 ROI와 설정을 함께 기록해 비교합니다. 처음에는 회전 0과 배율 1을 한 점으로 고정하고 잘 알려진 위치가 나오는지 확인합니다. 그다음 실제 장치에서 생길 수 있는 각도·배율을 추가합니다. 간격이 너무 크면 중간 자세가 평가되지 않고, 너무 작으면 영상 위치 수와 곱해 계산량이 커집니다.

결과를 읽는 방법

마스크는 조명 반사나 변형이 심한 부분을 제외하는 도구이지만 선택된 나머지 부분이 구별되는 패턴이어야 합니다. 지나치게 많은 픽셀을 빼면 학습이 실패하거나 다른 물체와 비슷한 점수를 얻을 수 있습니다. 양품·불량과 배경 사례에서 점수 분포를 비교해 하한을 정하고, 인접 물체의 중심 거리와 기대 개수를 고려해 중복 거리와 최대 결과 수를 조절합니다. 이 과정의 기준 영상과 설정은 모델 파일과 함께 추적할 수 있어야 합니다.

추가 점검

마스크를 조정한 뒤에는 동일한 정상 영상만이 아니라 제품과 비슷한 배경에서도 비교합니다. 마스크를 지나치게 줄이면 비교할 정보가 부족해 잘못된 위치의 점수도 높아질 수 있습니다. 후보 수와 위치를 함께 기록해야 이러한 변화를 볼 수 있습니다. 실제 평가 결과를 보관할 때 당시의 영상 형식과 마스크 버전도 함께 남깁니다.
