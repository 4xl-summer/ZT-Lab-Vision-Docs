정규화 상관으로 포즈 찾기

선택 템플릿 값 T와 후보 패치 I의 평균을 각각 빼고 Σ((T−T̄)(I−Ī)) / √(Σ(T−T̄)² Σ(I−Ī)²)를 계산합니다. 분산이 있는 동일 패턴은 1에 가깝고, 밝기 오프셋과 양의 일정 배율에 둔감합니다. 음의 상관은 음수이지만 기본 검색의 점수 하한은 0 이상이므로 음의 점수는 선택할 수 없습니다. 점수는 확률이 아닙니다. 검색 패치의 분산이 0이면 그 후보는 점수가 없어 건너뜁니다.

적용 상황과 원리

상관 계산은 선택된 템플릿 표본과 그 위치에 대응하는 영상 표본을 각각 평균 중심으로 바꾼 뒤, 두 벡터의 내적을 크기의 곱으로 정규화합니다. 이 방식은 일정한 밝기 덧셈과 양의 일정 배율에 영향을 덜 받지만, 패턴 자체가 가려지거나 위치 관계가 달라진 경우까지 동일하게 취급하지는 않습니다. 결과 점수는 확률이 아니며 다른 모델의 점수와 그대로 비교할 근거도 아닙니다.

결과를 읽는 방법

템플릿 마스크가 0인 표본은 평균과 상관 계산에서 빠집니다. 선택 영역에 뚜렷한 변화가 없으면 분모가 0이 되므로 학습이 실패합니다. 검색 패치가 일정할 때는 해당 후보를 평가 결과에서 제외하므로 빈 튜플이 나올 수 있습니다. 조명이 단순한 오프셋보다 복잡하게 변하거나 물체의 극성이 뒤집히는 경우에는 실제 사례로 점수 분포를 측정하고 필요한 대체 모델을 선택해야 합니다.

추가 점검

모델 표본에 같은 상수를 더하면 평균도 같은 만큼 이동해 중심을 뺀 값은 변하지 않습니다. 이 성질은 일정한 밝기 이동에 대한 설명이지, 영상 일부만 달라지는 반사나 국소 가림에도 점수가 항상 일정하다는 보장은 아닙니다. 기준점의 자세를 바꾸면 대응 영상 값이 보간될 수 있으므로 정확한 픽셀 복사 사례와 점수가 다를 수 있습니다.

분산과 점수의 해석
