검색 설정과 격자

아래 이름은 Rust/Python 표기이며 C#은 PascalCase입니다. 생성자에 아홉 값을 모두 지정합니다. 이 형식에 적용되는 기본값은 없습니다. 검증은 검색 시 수행됩니다.

필드단위와 유효 범위
angle_min, angle_max라디안, −π ≤ 최소 ≤ 최대 ≤ π. 영상 좌표에서 양수는 시계 방향.
angle_step라디안, 유한한 양수
scale_min, scale_max등방 배율, 0 < 최소 ≤ 최대
scale_step배율 간격, 유한한 양수
min_score0..1 포함, 점수 하한
min_distance검색 영상 픽셀, 0 이상인 중심 거리
max_matches양의 정수, 반환 개수 상한

실수 인자는 모두 유한해야 합니다. 각 축은 min + i × step, i = 0 .. floor((max−min)/step)입니다. 최댓값이 격자에 맞을 때만 끝점을 방문하며 부동소수점 반올림에 주의하세요. 각 축은 최대 4096점이고 각도×배율도 최대 4096점입니다. 위치 후보는 보이는 영상의 각 픽셀 격자에 모델 기준점의 소수 부분을 더하여 평가합니다. 이것은 후보 예산 옵션이 아니며 작업량은 대략 영상 픽셀 수 × 각도 수 × 배율 수 × 표본 수에 비례합니다.

적용 상황과 원리

Python의 MatchSpec은 아홉 인자를 가진 불변 값입니다. 회전 범위는 라디안, 배율은 무차원 값이며 두 단계 간격은 모두 양수여야 합니다. 각도나 배율을 바꾸지 않을 때도 최소와 최대를 같은 값으로 두고 양의 간격을 지정합니다. 예를 들어 각도 0부터 0, 간격 1과 배율 1부터 1, 간격 1은 각각 한 후보만 만듭니다.

결과를 읽는 방법

격자는 최소값에서 간격을 반복해 더하고 최댓값을 넘기기 전까지 생성됩니다. 0부터 1까지 간격 0.4라면 마지막 후보는 0.8입니다. 부동소수점 나눗셈의 반올림도 축의 실제 점 수에 영향을 줄 수 있으므로 끝 자세가 반드시 필요할 때는 설정과 결과를 시험합니다. 각 축 최대 4096점, 각도와 배율 점 수의 곱 최대 4096입니다. 반환 개수 제한과 거리 억제는 검색된 후보를 고르는 조건이지 탐색 위치의 작업 예산이 아닙니다.

추가 점검

각도 축에서 세 점, 배율 축에서 네 점이 생성되면 한 위치에 대한 자세 조합은 열두 개입니다. 모델 크기와 검색 ROI가 커질수록 후보당 평가할 표본과 위치가 늘어납니다. 먼저 허용할 위치 범위를 영상 준비 단계에서 줄이는 것이 계산량에 영향을 줍니다. 각 축의 마지막 값은 부동소수 계산으로 얻어지므로 원하는 끝 자세가 들어가는지 사례로 검사합니다.

끝점과 억제 예

조건확인할 내용
각도 0..1, 간격 0.4평가하는 각도는 0, 0.4, 0.8
최소 거리 5, 후보 간 거리 5경계와 같으므로 거리 규칙으로 제거하지 않음
최소 거리 5, 후보 간 거리 4먼저 선택된 후보보다 가까워 후속 후보 제거
