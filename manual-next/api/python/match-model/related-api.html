적용 상황과 원리

MatchModel.train_ncc는 템플릿과 선택 마스크에서 재사용할 모델을 만듭니다. info는 모델의 종류·크기·표본 수·기준점을 반환하며 이 정보로 모델이 의도한 영역을 학습했는지 확인할 수 있습니다. 검색을 시작하기 전에 MatchSpec에 각도와 배율의 범위·간격, 최소 점수, 최소 거리와 최대 개수를 모두 적습니다. 설정값만 만드는 시점과 실제 검색 시의 유효성 확인을 구분합니다.

결과를 읽는 방법

model.find의 반환값은 MatchResult이며 matches는 튜플, best는 첫 결과 또는 None입니다. Match의 position은 검색 ROI 로컬이고 global_position은 영상 원점을 더한 좌표입니다. 템플릿과 모델은 with 또는 close로 정리하지만 결과는 독립적으로 보존됩니다. 모델을 파일로 재사용할 때 save와 load를 사용하며 검사용 점수 조건과 검색 범위는 애플리케이션에서 별도로 관리합니다.

추가 점검

실제 파이프라인에서는 모델을 준비한 뒤 각 영상의 형식과 보이는 범위를 확인하고, find를 호출한 뒤 best의 존재 여부를 검사하는 순서가 기본입니다. 반환된 좌표를 다른 단계에 넘길 때 로컬 원점을 잃지 않도록 기록하고, 파일 저장 오류와 미검출을 서로 다른 상태로 처리합니다.

작업 단계의 책임

조건확인할 내용
학습템플릿에서 모델과 기준점 정보를 만듭니다.
검색별도 설정과 영상으로 포즈 후보를 찾습니다.
판독빈 결과를 처리하고 로컬·전역 좌표를 구분합니다.
