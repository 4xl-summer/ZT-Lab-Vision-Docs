적용 상황과 원리

이 페이지의 Python 예제는 CPython 3.14와 Linux x64에서 기록된 실행에 포함되어 있으며 종료 코드는 0입니다. 해당 코드 블록에는 자체 단언문이 없고 매치가 있으면 좌표와 점수를 출력하므로 종료 성공 자체를 좌표의 자동 비교 결과로 바꾸어 읽지 않습니다. 실행 기록의 코드 해시는 이 페이지에 보존한 원래 블록과 연결됩니다.

결과를 읽는 방법

별도로 기록된 ncc-literal 통합 사례는 위치 x 2, y 0.5, 전체 표본 6과 선택 마스크 표본 4를 확인하고 일정 검색 영상에서는 결과가 비는 조건을 다룹니다. 위치는 템플릿의 왼쪽 위가 아니라 기준점이라는 점에서 손으로 계산한 값과 비교합니다. 결과 스냅샷의 수명과 예외는 각각 다른 조건으로 살펴야 합니다. 이 합성 입력의 기록은 실제 조명 변화, 가림이나 설비 처리량을 검증한 자료가 아닙니다.

추가 점검

검증 기록에는 합성 실행에 사용한 소스 리비전과 운영체제, 언어 버전이 함께 남습니다. 모델 파일의 호환성이나 wheel의 설치 여부는 각각 별도 절차로 확인해야 합니다. 실제 생산 샘플에서는 정상·불량과 경계 사례를 별도로 수집해 검출 및 처리 시간을 평가합니다.

선택 마스크와 빈 검색은 같은 기대값의 중복이 아니라 서로 다른 경계 조건입니다. 마스크 사례는 학습 표본 선택을, 상수 검색 영상은 점수를 만들 수 없는 후보를 처리하는 경로를 확인합니다.
