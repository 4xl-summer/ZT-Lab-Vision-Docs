Python 전체 예제 · Python · ZImage.threshold

Python 전체 예제의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

Python 전체 예제

Python
from zvision import ZImage

with ZImage.from_gray8(3, 1, bytes([9, 10, 11])) as source:
    with source.threshold(10.0) as result:
        print(list(result.to_array_gray8()))  # [0, 255, 255]

기능 원리와 이미지 수명을 함께 확인하세요.

Python 전체 예제 · 핵심 동작

이 전체 예제는 with 두 개로 원본과 마스크의 수명을 각각 묶습니다. 입력은 [9,10,11]이고 T=10이므로 기대 값은 [0,255,255]입니다. 결과가 같은 값으로 나오는지 확인할 때는 출력이 행 우선 순서의 픽셀이라는 점을 기억하십시오. 이 입력은 합성이며 특정 장비의 결함 검출 성능을 보여 주지는 않습니다.

Python 전체 예제 · 입력과 결과

to_array_gray8()은 Python 숫자 리스트가 아니라 독립적인 bytes를 반환합니다. 예제는 보기 쉬운 정수 목록을 출력하려고 list(...)를 적용합니다. 비교 테스트에서 bytes와 리스트를 직접 비교하면 원소 값이 같아도 같은 객체 형식이 아니므로 실패합니다. 영상 자체와 복사된 바이트 배열의 수명도 구분해야 합니다.

Python 전체 예제 · 좌표와 소유권

T를 10.1로 바꾸면 10이 배경이 되고 11만 전경으로 남습니다. 3×1 영상이라도 원본에 다른 형식이나 비유한 값이 들어가면 오류가 발생할 수 있습니다. 출력 배열이 예상과 다르면 임계값의 단위와 경계 포함, 실제 입력 픽셀부터 확인하십시오.

배열에서 6과 7은 조건의 양쪽을 보여준다. 출력의 각 위치를 입력 순서와 나란히 비교하면 경계 포함 여부와 픽셀 순서를 동시에 살필 수 있다.

마지막 8도 경계보다 크므로 선택되며, 첫 번째 0과 두 번째 6은 선택되지 않는다.
