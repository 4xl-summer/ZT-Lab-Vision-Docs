관련 API · 핵심 동작

Python에서는 ZImage.from_gray8 등 형식별 생성으로 입력을 준비하고 threshold로 마스크를 만듭니다. 각 형식의 숫자 범위가 같지 않으므로 같은 장면을 다른 형식으로 옮길 때는 임계값도 그 단위에 맞춰 선택합니다. 결과를 숫자 목록으로 보려면 bytes를 list로 변환할 수 있지만, 비교 자체에 리스트 변환이 필요한 것은 아닙니다.

관련 API · 입력과 결과

객체 단위 결과가 필요하다면 마스크의 find_blobs로 연결 성분을 구합니다. 연결성 4와 8은 대각선 접촉을 다르게 처리하므로 제품의 객체 정의를 먼저 정해야 합니다. 작은 노이즈를 없애는 형태학은 면적도 바꾸므로 전처리 전후의 마스크와 Blob 결과를 함께 비교합니다.

관련 API · 좌표와 소유권

원본·마스크는 각자 소유 핸들로 with 또는 close를 사용합니다. 직접 Blob 결과는 독립 값 스냅샷이지만, 영상에서 추가 연산을 호출하려면 영상이 살아 있어야 합니다. ROI를 썼다면 결과 원점과 로컬 좌표를 기록해 전체 영상 좌표를 올바르게 환산하십시오.

임계 처리와 블롭 분석은 서로 다른 역할을 맡는다. 전자는 픽셀별 전경을 만들고 후자는 연결된 픽셀을 묶으므로 물체 개수가 다를 때 어느 단계에서 차이가 생겼는지 나누어 살핀다.

형태학을 중간에 넣으면 마스크 모양이 변하므로 개수 차이가 임계값에서 비롯됐는지 별도로 확인한다.

임계값을 먼저 검증한 후 블롭 연결 조건을 정하면 픽셀 선택과 물체 묶음의 효과를 구분할 수 있습니다. 연결된 물체가 예상보다 많으면 마스크의 작은 빈틈을 확인하고, 하나로 합쳐졌다면 두 물체 사이의 전경 연결이나 후속 형태학 처리를 살펴봅니다.
