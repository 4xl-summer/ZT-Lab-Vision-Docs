경계와 형식 선택 · Python · ZImage.threshold

경계와 형식 선택의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

경계와 형식 선택

비교는 p ≥ T입니다. 아래 합성 입력은 경계값이 포함됨을 보여줍니다.

조건결과 또는 조치
T=10, [9,10,11][0,255,255]
유한한 T 및 7종 Gray새 Gray8 마스크
색상 이미지 또는 비유한 T/부동소수 입력오류; 입력 형식과 값을 먼저 검증

이미지 형식은 전체 14종이지만 이 연산의 입력은 그중 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64 일곱 종입니다. ROI에서 생성된 마스크는 ROI 원점을 보존합니다. 결과는 원본을 변경하지 않는 별도 소유 이미지입니다.

경계와 형식 선택 · 핵심 동작

분할 규칙은 p ≥ T입니다. 도해의 9는 T=10 미만이므로 0, 10과 11은 경계 이상이므로 255가 됩니다. 각 픽셀의 비교는 독립적이라 주변 픽셀과의 연결이나 객체 크기는 고려하지 않습니다. 연결 영역을 판단하려면 마스크 생성 뒤 별도의 Blob 분석을 수행해야 합니다.

경계와 형식 선택 · 입력과 결과

입력은 일곱 Gray 형식이며 출력은 항상 Gray8입니다. 부동소수 영상에서는 소수 임계값을 전달할 수 있지만 입력과 T는 모두 유한해야 합니다. 숫자 범위 밖의 유한한 T 자체는 가능하므로, 모두 검거나 흰 결과를 오류로 단정하기보다 영상 강도 분포와 선택한 기준을 비교해야 합니다.

경계와 형식 선택 · 좌표와 소유권

ROI를 이 연산에 전달하면 해당 영역만 처리하고 그 원점을 보존하는 새 영상이 만들어집니다. 원본과 결과는 별도 객체입니다. Python에서는 결과를 더 이상 쓰지 않을 때 닫고, 복사한 bytes가 필요하면 닫기 전에 얻으십시오. 밝은 물체가 배경보다 어두운 상황이라면 이 비교 방향이 원하는 전경을 만드는지도 먼저 확인합니다.

Python 숫자와 마스크 읽기

ZImage.threshold(t)는 숫자 인자를 검사하고 임계값 연산을 호출하며, threshold_value(t)는 그 별칭입니다. 예를 들어 GrayF32 입력이 -1, 6.5, 7이고 기준이 6.5라면 결과는 0, 255, 255입니다. 가운데 값처럼 기준과 정확히 같은 표본도 전경에 포함됩니다. 이 예는 규칙을 설명하는 손계산이며 모든 부동소수점 데이터의 반올림 결과를 보증하지 않습니다.

결과는 새 Gray8 이미지이므로 원본과 결과를 각각 관리합니다. 사용이 끝나면 close하거나 컨텍스트 관리 범위를 이용하고, 닫힌 이미지에 다시 접근하지 않습니다. NaN이나 무한대가 임계값 또는 부동소수 입력에 섞였다면 마스크 판독 전에 입력을 점검합니다. 컬러 영상을 전달해 생긴 오류도 검은 마스크와 구별해야 하며, 필요한 경우 먼저 지원되는 회색 영상으로 준비합니다.
