관련 검증 사례 · 핵심 동작

합성 검증의 첫 단계는 경계값을 포함하는 세 개 이상의 픽셀을 쓰는 것입니다. T=10에 [9,10,11]을 적용하면 [0,255,255]를 기대하고, GrayF32에서는 음수와 소수도 포함해 같은 숫자 기준으로 비교되는지 확인합니다. 모든 픽셀이 T보다 낮은 경우는 예외가 아니라 빈 전경 마스크가 나와야 합니다.

관련 검증 사례 · 입력과 결과

실패 사례는 정상 빈 결과와 분리합니다. 컬러 영상, NaN 임계값, 비유한 부동소수 픽셀처럼 계약을 위반한 입력에서 예외가 보고되는지 살펴보십시오. 테스트가 예외를 가로채 같은 빈 배열로 바꾸면 입력 오류를 검출 누락으로 오인할 수 있습니다.

관련 검증 사례 · 좌표와 소유권

Python에서 픽셀 복사 결과는 bytes이므로 기대값의 형식까지 일치시켜 비교해야 합니다. ROI로 처리했다면 출력의 크기와 원점을 함께 검사하고, 결과 영상과 입력 영상 각각에 대한 close 또는 with 경계를 명시합니다. 실행된 사례와 미실행 사례는 검증 기록에서 구별합니다.

예상 배열의 각 원소는 해당 입력 픽셀의 결과다. 크기만 확인하면 경계 처리나 순서 오류를 발견할 수 없으므로 전체 배열과 함께 경계 위치의 값을 확인한다.

원소 순서가 바뀌면 영상의 위치 해석도 바뀌므로 전체 크기와 배열의 순서를 같이 대조한다.

정수와 부동소수 사례를 볼 때는 입력 값의 단위를 혼동하지 않습니다. 부동소수 입력에서 6.5는 7보다 작고 7은 경계와 같으므로 둘의 출력이 달라집니다. 기대 배열을 입력 순서에 맞게 비교하면 경계값 포함뿐 아니라 픽셀 순서의 실수도 발견할 수 있습니다.
