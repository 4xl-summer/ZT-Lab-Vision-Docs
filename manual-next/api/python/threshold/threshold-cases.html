값과 실패 해석 · 핵심 동작

입력 값과 같은 임계값이 전경이라는 점은 결과 판독에서 가장 중요한 경계 조건입니다. GrayF32의 6.5, 7, 9에 T=7을 적용하면 각각 0, 255, 255입니다. 이 검사는 7과 7.0의 Python 표기 차이가 아니라 동일한 수치의 비교 결과를 확인합니다. 영상의 숫자를 범위 밖으로 정규화하거나 반올림하는 절차는 이 호출에 포함되지 않습니다.

값과 실패 해석 · 입력과 결과

T가 전체 입력보다 높으면 전경이 없어질 수 있습니다. 반대로 T가 전체 입력 이하이면 전부 전경입니다. 이런 결과는 유효한 연산 결과이므로 후속 검사에서 빈 영역이나 전체 영역을 어떻게 취급할지 별도로 정해야 합니다. 원본의 밝기 히스토그램을 보고 하나의 고정값이 배경과 대상을 분리하는지 판단하는 것이 좋습니다.

값과 실패 해석 · 좌표와 소유권

컬러 입력, NaN 임계값, 비유한 부동소수 픽셀은 실패 조건입니다. 실패를 모두 0인 마스크로 대체하면 데이터 손상과 실제 빈 전경이 구별되지 않습니다. 재현을 위해 입력 형식, 영상의 ROI와 T를 기록하고 Python의 예외와 정상 픽셀 배열을 따로 수집하십시오.

경계 직전과 경계 자체를 한 배열에 두면 두 번의 호출 없이 비교 조건을 확인할 수 있다. 7을 전경으로 처리하는 이 사례에서는 6과 7의 출력이 각각 0과 255다.
