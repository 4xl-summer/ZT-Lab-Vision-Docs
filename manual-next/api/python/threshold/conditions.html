계약 · Python · ZImage.threshold

계약의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

계약

항목설명
입력7종 회색 형식의 ZImage
임계값유한한 수. 비교는 픽셀 ≥ t
출력Gray8, 각 픽셀 0 또는 255
수명close() 또는 with
실패유효하지 않은 인자 및 네이티브 연산 실패에 대한 오류

계약 · 핵심 동작

지원 입력은 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64의 일곱 회색 형식입니다. 영상 객체 자체가 더 많은 색상 형식을 제공하더라도 이 호출이 그것을 모두 받아들이는 것은 아닙니다. 색상 입력은 원하는 회색 변환을 명시한 후 비교하고, 채널 순서가 의도한 밝기와 맞는지 먼저 검토합니다.

계약 · 입력과 결과

임계값은 유한한 수이며 결과는 같은 처리 영역 크기의 Gray8 0/255 영상입니다. 원본이 ROI라면 결과는 ROI 원점을 유지합니다. 픽셀과 t가 같을 때 255가 된다는 점이 경계의 핵심입니다. 예를 들어 t=7인 [6.5,7,9]는 [0,255,255]입니다. 유효한 t가 모든 픽셀보다 크면 모두 0인 출력도 정상입니다.

계약 · 좌표와 소유권

Python 영상은 네이티브 핸들을 가지므로 입력과 결과를 각각 닫습니다. 부동소수 픽셀에 NaN이나 무한대가 있으면 연산이 실패할 수 있으므로 결측값을 미리 처리해야 합니다. 빈 전경 결과와 예외를 별도로 다루면 데이터 오류가 단순한 미검출로 숨겨지는 일을 줄일 수 있습니다.

입력 형식을 확인한 뒤 표본 값의 단위를 살핀다. 같은 7이라는 임계값도 영상 데이터가 정수인지 부동소수인지에 따라 실험할 값의 범위가 다를 수 있으므로 샘플을 출력해 보는 것이 유용하다.
