사례는 합성 입력에 대한 기대값입니다. 실행 결과와 실제 장비 조건은 별도로 확인해야 합니다.

to_array_gray8()는 독립적인 bytes를 반환합니다. 위 예제는 숫자 목록으로 표시하려고 list()로 변환합니다.

실행 사례와 검증 범위 · 핵심 동작

표의 합성 입력은 경계와 형식의 두 축을 분리해 확인합니다. Gray8 [0,6,7,8]과 GrayF32 [-1,6.5,7,9]에 T=7을 적용하면 각각 [0,0,255,255]를 기대합니다. 형식이 달라도 수치 비교가 같은 경계 규칙을 따르는지 볼 수 있고, 7과 같은 픽셀이 전경인지도 확인할 수 있습니다.

실행 사례와 검증 범위 · 입력과 결과

이 비교는 결과가 Python 리스트로 반환된다는 의미가 아닙니다. to_array_gray8()의 결과는 bytes이므로 테스트는 bytes([0,0,255,255])와 비교하거나 list로 명시 변환해야 합니다. 입력과 마스크는 별도로 닫으며 배열은 복사된 값입니다. GrayF32에 비유한 값이 있는 경우는 정상 배열 사례와 분리해 실패를 확인합니다.

실행 사례와 검증 범위 · 좌표와 소유권

사례 ID는 검증 기록과 연결하기 위한 식별자입니다. 자료형과 임계값이 같은지 확인하지 않고 다른 사례의 통과 여부를 옮겨 적지 마십시오. 이 합성 시험으로 실제 카메라의 조명 변화나 분할 안정성이 검증되지는 않으므로 별도 데이터가 필요합니다.

부동소수 사례의 음수와 소수는 값의 해석을 확인하는 입력이다. 별도의 카메라 데이터가 같은 범위로 정규화되어 있다고 전제하지 말고 실제 표본 범위와 임계값을 함께 기록한다.
