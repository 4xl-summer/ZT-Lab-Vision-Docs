공개 호출 형태

Python
from zvision import ZImage

# ZImage 객체 image가 준비되어 있을 때:
mask = image.threshold(t)

threshold(t)는 유한한 수를 입력받고 독립적으로 소유하는 Gray8 ZImage를 반환합니다.

공개 호출 형태 · 핵심 동작

Python의 image.threshold(t)는 회색 영상의 각 픽셀을 유한한 숫자 t와 비교합니다. 픽셀이 t 이상이면 새 마스크에 255를, 작으면 0을 저장합니다. 객체가 준비된 상태에서 호출하는 짧은 표현과 영상을 생성하는 전체 예제를 구분하십시오. t는 정규화된 확률이 아니라 입력 픽셀과 같은 수치 단위입니다.

공개 호출 형태 · 입력과 결과

예를 들어 Gray8 [9,10,11]에 10.0을 적용하면 [0,255,255]이며 경계와 같은 10이 포함됩니다. GrayF32에서 0–1로 정규화한 영상을 쓴다면 10.0이 아니라 해당 표현 범위에서 선택한 임계값이 필요합니다. 저장 형식이 다르다고 비교 전에 자동 정규화되는 것은 아닙니다.

공개 호출 형태 · 좌표와 소유권

반환된 마스크는 원본과 별도 소유 ZImage이므로 with 또는 close()로 해제합니다. 입력이 컬러 형식이거나 임계값·부동소수 픽셀이 비유한 값이면 빈 마스크가 아니라 오류입니다. 실제 검사에서는 마스크를 확인한 다음 영역 분석을 시작하십시오.

호출의 결과는 원본의 밝기 분포를 요약한 숫자가 아니라 픽셀별 선택 결과를 담는 영상이다. 다음 단계에서 크기와 좌표를 사용하려면 반환 영상을 유지하고 입력 영상과 구분하여 전달한다.
