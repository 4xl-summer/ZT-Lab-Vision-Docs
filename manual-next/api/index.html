이 장에서 배우는 내용

실제 Rust · C# · Python API에서 정확한 호출·입력·출력·수명을 확인합니다.

호출 방법과 객체 수명은 각 SDK의 실제 형태를 따릅니다. 이름이 비슷해도 기본값·단위·반환·오류가 같다고 가정하지 마세요. 가이드에서 원리를 읽은 뒤 해당 언어의 정확한 API로 연결하세요.

입력 객체 → 옵션·모델 구성 → 즉시 호출 또는 Query 실행 → 결과 필드 확인 → 독립 소유 객체 해제 순서로 읽으세요. 관리형 값 결과 스냅샷에 소유 핸들 해제를 적용하지 않습니다. 각 가이드 마지막에는 관련 클래스의 전체 공개 멤버를 확인할 수 있는 표가 있습니다.
