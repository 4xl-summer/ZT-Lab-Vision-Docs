이 장에서 배우는 내용

공개 ImageQuery의 연결 성분 종료 계획과 결과 접근 시그니처.

Rust는 ImageQuery 의 종료 연산을 통해 Typed Blob 결과를 얻습니다. C#/Python의 편의 직접 메서드와 동일한 메서드명·호출형이라고 가정하지 않습니다.

Rust에서 계획 추가는 소비형이며 일부 연산은 오류를 반환합니다. 직접 Blob 분석이 아닌 Query 종료 단계에서 실행하므로 입력 타입 및 계산 중 오류를 별도 확인해야 합니다. 캡처와 실행의 수명은 Query 개념 을 참고하세요.

전경은 0이 아닌 픽셀입니다. 면적은 픽셀 셀의 개수이고 무게중심은 각 전경 픽셀 좌표의 산술 평균 (Σx/N, Σy/N) 입니다. 대각 두 점의 면적은 8연결에서 2, 중심은 (0.5,0.5)입니다.
