Rust · BlobQuery / BlobAnalysisResult

공개 ImageQuery의 연결 성분 종료 계획과 결과 접근 시그니처.

공개 API

Rust
impl ImageQuery {
    pub fn find_blobs(self, connectivity: Connectivity) -> BlobQuery;
}
impl BlobQuery {
    pub fn filter(self, expr: Expr) -> ZResult<Self>;
    pub fn order_by(self, expr: Expr, order: SortOrder) -> ZResult<Self>;
    pub fn execute(&self) -> ZResult<QueryExecution<BlobAnalysisResult>>;
}
impl BlobAnalysisResult {
    pub fn blobs(&self) -> &[Blob];
}

인자와 반환 객체

이름형식설명
connectivityConnectivityFour / Eight 전경 연결
filterExpr지원된 순수 불리언 표현식
order_byExpr + SortOrder숫자식 기반 정렬 계획

최소 실행 예제

Rust
use zvision::{Connectivity, ZImage};

fn main() -> zvision::ZResult<()> {
    let src = ZImage::from_vec_gray8(3, 1, vec![0, 5, 5])?;
    let plan = src.query()?.threshold(1)?.find_blobs(Connectivity::Four);
    let execution = plan.execute()?;
    let blobs = execution.output().blobs();
    assert_eq!(blobs.len(), 1);
    assert_eq!(blobs[0].area, 2);
    Ok(())
}

Rust는 ImageQuery의 종료 연산을 통해 Typed Blob 결과를 얻습니다. C#/Python의 편의 직접 메서드와 동일한 메서드명·호출형이라고 가정하지 않습니다.

소유권 및 오류

Rust에서 계획 추가는 소비형이며 일부 연산은 오류를 반환합니다. 직접 Blob 분석이 아닌 Query 종료 단계에서 실행하므로 입력 타입 및 계산 중 오류를 별도 확인해야 합니다. 캡처와 실행의 수명은 Query 개념을 참고하세요.

연결, 면적과 좌표

전경은 0이 아닌 픽셀입니다. 면적은 픽셀 셀의 개수이고 무게중심은 각 전경 픽셀 좌표의 산술 평균 (Σx/N, Σy/N)입니다. 대각 두 점의 면적은 8연결에서 2, 중심은 (0.5,0.5)입니다.

선택해석
4연결상하좌우 이웃만 이어짐
8연결대각 이웃도 이어짐
면적 필터경계 포함; 단위는 픽셀 수
ROI결과 좌표계와 상위 원점의 관계를 확인하고 합산; 고급 BlobResult는 부모 원점을 보관하지 않음
영역 없음빈 결과는 성공 가능한 검사 결과

픽셀 면적과 윤곽 다각형 면적은 다른 측정량입니다. 교정된 면적은 픽셀 크기 또는 변환에 따라 별도로 계산합니다. 대각 접촉과 경계 절단 객체는 검출 기준을 정해 테스트하십시오.

결과 필드와 수명

필드·상황의미
area비영 전경 셀 개수, 픽셀 단위

수명Rust Query 단계는 self를 소비하며 execute는 결과 스냅샷을 만듦. C#/Python 직접 FindBlobs 결과는 이미지와 독립된 값
실패비 Gray8, 유효하지 않은 연결성, 크기 오버플로·할당 실패; 입력과 연결 값을 확인
