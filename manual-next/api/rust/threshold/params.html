매개변수·반환 · Rust · ZImage::threshold

매개변수·반환에 대한 Rust · ZImage::threshold 사용 안내

상위 목차로 돌아가기

매개변수·반환

항목자료형설명
thresholdf64픽셀과 비교할 유한한 임계값; 기본값 없음
반환ZResult<ZImage>0 또는 255를 갖는 새로운 Gray8 이미지

입력은 7종 회색 형식으로 제한되며, 비유한 임계값이나 비유한 부동소수 픽셀·컬러 형식은 오류입니다. 원본 픽셀은 보존되며 ROI의 origin 역시 유지됩니다.

적용 상황과 원리

threshold는 f64이고 기본값이 없으므로 호출자가 비교 기준을 명시해야 합니다. 각 입력값 p가 이 값 이상인지를 검사하며 경계와 같은 값도 전경 255가 됩니다. 예를 들어 임계값 10에서 입력이 9,10,11이면 결과는 순서대로 0,255,255입니다. 임계값이 영상의 모든 값보다 크면 모두 0인 정상 결과가 됩니다.

결과를 읽는 방법

성공하면 입력과 같은 보이는 폭·높이 및 원점을 가진 새 Gray8 영상이 반환됩니다. 입력 원본은 변경되지 않으므로 같은 원본에 다른 기준을 적용해 별도 결과를 얻을 수 있습니다. 잘못된 색상 형식, 비유한 임계값 또는 비유한 부동소수 픽셀은 오류입니다. 빈 전경 마스크는 예외와 다르므로 후속 블롭 분석에서는 전경이 없다는 상태로 처리해야 합니다.

추가 점검

원본에서 10과 같은 픽셀도 선택되므로 경계값을 의도적으로 제외해야 하는 검사라면 이 호출의 비교 규칙과 요구사항을 먼저 대조합니다. 출력의 모든 값이 0이어도 처리 자체가 성공했다면 유효한 영상이며 오류를 대신하지 않습니다.

경계에 따른 값

조건확인할 내용
9와 기준 109 < 10이므로 0
10과 기준 10경계와 같으므로 255
11과 기준 1011 > 10이므로 255
