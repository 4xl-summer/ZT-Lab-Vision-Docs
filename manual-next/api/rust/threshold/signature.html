공개 시그니처

Rust
impl ZImage {
    pub fn threshold(&self, threshold: f64) -> ZResult<Self>;
}

정식 공개 타입 zvision::ZImage; 입력을 빌리고 새 소유 ZImage를 결과로 반환합니다.

적용 상황과 원리

이 메서드는 소유한 영상을 빌려서 각 픽셀을 유한한 실수 임계값과 비교합니다. 입력이 임계값 이상이면 출력 픽셀은 255이고 그보다 작으면 0입니다. 반환은 새 Gray8 영상이므로 입력을 덮어쓰지 않습니다. 결과 자체가 오류일 수 있어 성공 여부를 확인한 뒤 영상 데이터를 읽어야 합니다.

결과를 읽는 방법

호출에 사용하는 타입은 공개 Rust façade의 ZImage입니다. 입력 영상이 ROI이면 보이는 픽셀만 처리하고 결과 원점은 그 ROI의 원점을 보존합니다. 입력은 일곱 회색 형식이며 색상 영상은 이 연산에서 직접 받지 않습니다. 부동소수 입력이나 임계값이 유한하지 않을 때는 오류로 처리합니다. 결과 마스크는 별도 소유 값이므로 원본을 수정하거나 다시 읽는 일과 수명이 구분됩니다.

추가 점검

이 호출은 비교를 수행한 결과를 반환하기 때문에 화면 표시를 위한 색상 변환과는 별도입니다. 반환된 255는 해당 픽셀이 전경 조건을 만족한다는 이진 표시이지 원래 픽셀의 밝기가 255였다는 의미가 아닙니다. 결과의 원점은 후속 위치 계산에서 계속 확인해야 합니다. 반환된 마스크를 후속 분석에 넘기기 전에 입력 ROI와 같은 원점을 유지하는지 확인합니다.
