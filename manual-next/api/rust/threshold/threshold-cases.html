적용 상황과 원리

임계값이 모든 픽셀보다 크면 반환 영상은 전부 0이며 유효한 연산 결과입니다. 반대로 모든 픽셀이 임계값 이상이면 전부 255입니다. 이 두 결과는 알고리즘이 실패했다는 뜻이 아니라 선택한 기준에서 전경이 없거나 전체가 전경이라는 뜻입니다. 후속 단계는 검출 개수가 0인 경우와 연산 자체가 오류인 경우를 따로 판정해야 합니다.

결과를 읽는 방법

경계값 자체는 포함되므로 입력이 10인 픽셀은 임계값 10에서 전경입니다. NaN이나 무한대는 숫자 비교 결과에 맡기지 않고 오류로 처리합니다. 부동소수 영상에서 하나의 비유한 픽셀이 보이는 영역에 있다면 영상 데이터를 먼저 정리해야 합니다. 결과는 원본과 독립된 Gray8이므로 원본 영상에 임계값이 적용되어 값이 바뀌었다고 가정하지 않습니다.

추가 점검

GrayF32 또는 GrayF64처럼 부동소수 영상에서는 보이는 픽셀의 NaN이나 무한대도 확인해야 합니다. 임계값만 유한해도 영상 쪽 비유한 값이 남아 있다면 성공을 기대할 수 없습니다. 반면 모든 값이 기준 미만이면 오류 없이 빈 전경이 됩니다. 표시할 마스크와 원래 밝기 영상은 서로 다른 용도로 보관합니다. 입력 값과 임계값의 단위를 같게 해석해야 합니다. 정수 형식에서 임계값이 데이터 범위 밖이어도 그 자체로 유한하면 비교할 수 있습니다.
