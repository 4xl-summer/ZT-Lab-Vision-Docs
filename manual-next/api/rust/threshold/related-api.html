적용 상황과 원리

ZImage의 threshold는 입력을 빌려 새 Gray8 마스크를 반환합니다. 임계값은 f64이고 기본값은 없으며 각 입력이 기준 이상인지 비교합니다. 생성된 영상의 바이트를 확인할 때는 to_packed_vec을 사용하고, 영상이 ROI에서 왔다면 원점도 함께 확인합니다. 값이 경계와 같으면 전경이라는 규칙을 기대값에 반영해야 합니다.

결과를 읽는 방법

전경 마스크를 만든 뒤 연결 영역을 분석하는 경우 영상 처리와 결과 판정은 별도 단계입니다. 모든 값이 0인 마스크는 정상 반환일 수 있으며 후속 단계에 전달할지 검사 정책으로 결정합니다. RGB 입력이거나 값이 유한하지 않을 때 발생하는 오류는 빈 마스크와 구별합니다. 기존 원본 영상은 변경되지 않아 다른 임계값의 결과를 독립적으로 만들 수 있습니다.

추가 점검

출력 마스크에서 연결된 물체의 수가 필요하다면 그 다음에 블롭 분석을 수행할 수 있습니다. 그 단계의 연결성이나 최소 면적은 threshold의 인자가 아닙니다. 원본 측정값을 다시 사용할 계획이라면 이진 마스크와 원본을 구분하여 보관합니다. 후속 영역 분석의 입력은 0과 비제로로 나뉜 마스크입니다. 마스크의 좌표 원점도 후속 처리에 함께 전달합니다.

처리 순서

조건확인할 내용

임계값유한 기준으로 새 마스크 생성
활용원점과 소유권을 확인하고 후속 처리
