경계와 형식 선택

비교는 p ≥ T입니다. 아래 합성 입력은 경계값이 포함됨을 보여줍니다.

조건결과 또는 조치
T=10, [9,10,11][0,255,255]
유한한 T 및 7종 Gray새 Gray8 마스크
색상 이미지 또는 비유한 T/부동소수 입력오류; 입력 형식과 값을 먼저 검증

이미지 형식은 전체 14종이지만 이 연산의 입력은 그중 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64 일곱 종입니다. ROI에서 생성된 마스크는 ROI 원점을 보존합니다. 결과는 원본을 변경하지 않는 별도 소유 이미지입니다.

적용 상황과 원리

임계값 비교에 쓰이는 방향은 크거나 같음입니다. 입력 9,10,11을 기준 10과 비교하면 9만 배경이고 10도 전경에 포함됩니다. 따라서 경계가 포함되는지 여부가 중요한 경우 임계값과 정확히 같은 픽셀을 시험해야 합니다. 단순히 큰 값만 포함된다고 가정하면 중간 픽셀의 예상이 틀립니다.

결과를 읽는 방법

입력은 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64의 일곱 형식입니다. 결과는 입력 깊이와 무관하게 0 또는 255를 가지는 Gray8입니다. 부동소수 형식의 값과 임계값은 유한해야 하며 컬러 영상은 형식 오류가 됩니다. ROI에 적용하면 출력의 원점이 유지되므로 원본 좌표와 이어 쓰기 쉽지만 결과는 원본의 별도 소유 마스크입니다.

자료형과 결과

조건확인할 내용
Gray16회색 입력 값과 유한한 임계값 비교
GrayF32유한한 입력 값만 허용
결과입력 깊이와 관계없이 Gray8

Rust에서 결과와 오류 분기하기

threshold_value(value: f64)는 threshold(value)에 위임하고 새 이미지가 담긴 ZResult를 돌려줍니다. 호출자는 성공한 마스크를 후속 처리에 넘기고 오류는 ? 또는 명시적 분기로 처리할 수 있습니다. 원본은 공유 참조로 읽으며 반환된 이미지와 별개로 사용할 수 있습니다. 소유한 이미지 값은 범위가 끝나면 해제됩니다.

경계 판독을 위해 기준 10에 값 9, 10, 11을 대입하면 각각 0, 255, 255입니다. 같은 값을 두고 10만 배경이 된다면 결과 비교 방향을 먼저 확인합니다. 지원 회색 형식이어도 부동소수 입력의 비유한 값은 실패 조건이므로 Err를 빈 검출 결과로 바꾸지 않아야 합니다. ROI의 마스크를 다른 영상의 위치와 대조할 때는 보존된 ROI 원점까지 함께 확인합니다.
