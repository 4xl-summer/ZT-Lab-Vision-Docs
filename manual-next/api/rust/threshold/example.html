실제 사용 코드 · Rust · ZImage::threshold

실제 사용 코드에 대한 Rust · ZImage::threshold 사용 안내

상위 목차로 돌아가기

실제 사용 코드

Rust
use zvision::ZImage;

fn main() -> zvision::ZResult<()> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    let result = source.threshold(10.0)?;
    assert_eq!(result.to_packed_vec()?, vec![0, 255, 255]);
    Ok(())
}

Threshold의 원리 · 첫 이미지 처리

적용 상황과 원리

예제는 세 픽셀로 이루어진 한 행을 만들어 임계값 10을 적용합니다. 먼저 9는 10보다 작아 0이 됩니다. 가운데 10은 경계와 같으므로 포함되어 255가 되고, 11은 경계를 넘으므로 역시 255입니다. 이 기대 배열은 처리 결과를 보고 추정한 것이 아니라 비교 규칙에서 직접 계산한 값입니다.

결과를 읽는 방법

코드의 물음표 연산자는 영상 생성이나 threshold가 실패했을 때 오류를 호출자에게 전달합니다. 성공한 결과에서 연속된 픽셀을 읽고 기대 바이트 배열과 비교합니다. 원본은 연산 전에 만들어진 별도 영상으로 남으며 결과만 Gray8 마스크입니다. 이 작은 합성 검사는 비교 경계와 반환 형식을 확인할 뿐 실제 제품 영상의 임계값이나 처리 시간을 정해 주지는 않습니다.

추가 점검

예제의 from_vec_gray8은 영상 너비와 높이에 맞는 입력 길이를 사용합니다. 이후 반환된 마스크를 연속 배열로 복사해 세 값을 확인합니다. 비교에 쓰는 원본을 먼저 정리할 필요가 없으며 새로운 마스크와 원본은 서로 다른 소유 값입니다. 세 번째 값도 전경이므로 이 사례는 경계 자체와 그 위쪽을 함께 확인합니다. 가운데 값이 경계와 같다는 점이 이 사례의 핵심입니다.
