Homography 보정 및 픽셀/월드 변환 메서드.

글로벌 픽셀 (x,y)에 호모그래피 H를 적용하여 X=(h₀₀x+h₀₁y+h₀₂)/(h₂₀x+h₂₁y+h₂₂), Y=(h₁₀x+h₁₁y+h₁₂)/(h₂₀x+h₂₁y+h₂₂)를 얻습니다. 결과는 보정이 저장한 길이 단위에서 요청 단위로 변환합니다. 역변환은 입력 단위를 보정 단위로 바꾸고 역행렬을 적용합니다. 평면 보정은 렌즈 왜곡을 자동 보정하지 않습니다.

PlanarCalibration 은 매핑과 단위 값을 가집니다. Rust 공개 facade의 mapping() , unit() 및 C#의 Mapping , Unit 으로 읽습니다. fit은 동일 개수의 대응점 최소 4개가 필요하며 퇴화 배치·역행렬 불가·비유한 값 등은 오류입니다. 변환 영역 바깥으로의 정확도는 이 조건에서 보장되지 않습니다.

evaluate / Evaluate 는 비어 있지 않은 같은 개수의 글로벌 pixel과 world 기준점, world 단위, 유한한 tolerance ≥ 0을 받습니다. 각 잔차에는 observed_pixel, reference_world, predicted_world, predicted_pixel, error_world, error_pixel이 있습니다. error_world=‖predicted_world−reference_world‖, error_pixel=‖predicted_pixel−observed_pixel‖입니다. metrics의 count, rms_world, max_world, rms_pixel, max_pixel은 각 거리의 개수·제곱평균제곱근·최대이며 passed는 max_world ≤ tolerance입니다. world와 tolerance 단위는 평가에 전달한 단위이고 pixel 잔차는 픽셀입니다. 학습점 외 보류점으로 평가하세요.
