DepthMap과 PointCloud의 생성·공유·기하 피팅 API.

DepthMap::new는 결측 포함 깊이 격자를 소유하며 to_point_cloud가 점군 변환을 수행합니다. PointCloud::new는 포인트, unit, frame을 보존합니다.

PointCloud::fit_plane, fit_cylinder, register_icp는 결과를 반환하며 share와 clone_deep은 메모리 소유 계약이 다릅니다.

직교 격자의 셀 (x,y)에 값 h가 있으면 점은 (origin.x + x·spacing_x, origin.y + y·spacing_y, origin.z + h)입니다. 좌표와 h는 지정한 길이 단위를 사용하고 frame은 좌표계 식별자입니다. None 은 결측이며 수치 0과 다릅니다. 각 슬롯의 순서를 유지하여 점군으로 변환합니다.
