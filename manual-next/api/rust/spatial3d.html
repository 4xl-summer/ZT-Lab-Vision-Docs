Rust · Spatial3D

DepthMap과 PointCloud의 생성·공유·기하 피팅 API.

개념과 사용 흐름

DepthMap::new는 결측 포함 깊이 격자를 소유하며 to_point_cloud가 점군 변환을 수행합니다. PointCloud::new는 포인트, unit, frame을 보존합니다.

관련 설명 열기

격자·좌표·결측 계약

직교 격자의 셀 (x,y)에 값 h가 있으면 점은 (origin.x + x·spacing_x, origin.y + y·spacing_y, origin.z + h)입니다. 좌표와 h는 지정한 길이 단위를 사용하고 frame은 좌표계 식별자입니다. None은 결측이며 수치 0과 다릅니다. 각 슬롯의 순서를 유지하여 점군으로 변환합니다.

너비와 높이는 양수, 값 개수는 너비×높이, spacing은 유한한 양수, origin과 유효 높이는 유한수, frame은 0이 아니어야 합니다. ROI 좌표는 현재 맵 기준이고 저장소를 공유합니다. ROI의 원점은 x와 y 방향으로 각각 ROI 시작 좌표×spacing만큼 이동하며 z 원점은 유지됩니다. 유닛과 frame을 함께 기록하세요.

median(kernel, min_valid)과 fill_holes(kernel, min_valid)의 커널은 양의 홀수이고 유효 이웃 최소 수는 1부터 kernel²까지입니다. 경계에서는 이웃을 잘라냅니다. median은 결측 중심을 그대로 두고, fill_holes는 원본의 유효 이웃으로 결측 중심만 채웁니다. 유효 이웃이 부족하면 결측입니다.

점군과 정합의 결과 판독

점군은 유효한 점과 결측 슬롯, 길이 단위, 0이 아닌 frame을 갖습니다. 변환의 입력·출력 frame과 단위가 데이터와 일치해야 합니다. 법선은 점별 선택값이므로 결측을 확인합니다. 평면·원통 피팅의 inliers와 total, 잔차를 보고 결과의 충분성을 판단하세요.

점대점 ICP는 초기 변환으로 원본을 대상 frame에 보낸 뒤 대응점을 찾아 정합합니다. IcpOptions의 max_iterations는 양수, max_distance는 유한 양수, trim_fraction은 (0,1], rms_tolerance는 유한한 0 이상입니다. 거리는 점군의 단위입니다. 최소 유효점은 양쪽 각각 3개이며 단위와 초기 변환의 frame이 일치해야 합니다. 결과의 transform, iterations, inliers, rms, converged를 함께 확인하세요. 수렴은 허용 정확도를 보증하지 않으므로 독립 점과 사용 공차로 검증합니다.

법선과 피팅 세부 결과

기본 estimate_normals는 중심점과 가장 가까운 유효 이웃을 사용해 PCA 법선을 추정합니다. neighbors는 2 이상이며 이웃 부족이나 퇴화된 이웃은 해당 슬롯을 결측으로 반환합니다. 법선은 viewpoint 쪽을 향하도록 정합니다. PlaneFit은 normal, offset, inliers, total, rms_error, max_error를 갖고 평면은 normal·p + offset = 0입니다. 임계 거리는 점군 단위이며 경계값도 포함합니다. CylinderFit은 axis_point, axis_direction, radius와 동일한 개수·오차 필드를 갖습니다. 유한 탐색이 전역 최적해를 보장하지 않으며, 원통은 짧은 호나 부족한 축 방향 범위 등에서 퇴화로 실패할 수 있습니다.

평면과 원통의 inlier_threshold는 유한 양수이며 점군 단위입니다. 유효점 부족이나 퇴화, 허용치 밖 설정은 오류로 반환합니다. Python 기본 fit_plane/fit_cylinder는 threshold만 받습니다. 언어별 고급 옵션 노출 여부는 해당 참조를 확인하세요.

Rust 합성 ROI 예제

2×2 격자에서 ROI 원점 x=12, 첫 점 결측, 둘째 점 z=34를 기대합니다.

Rust
use zvision::{DepthMap, LengthUnit, Point3, ZRect};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let depth = DepthMap::new(2, 2, vec![Some(1.), None, Some(3.), Some(4.)],
        2., 3., Point3 { x: 10., y: 20., z: 30. }, LengthUnit::Millimeter, 7)?;
    let roi = depth.roi(ZRect::new(1, 0, 1, 2))?;
    let cloud = roi.to_point_cloud()?;
    assert_eq!(roi.origin().x, 12.);
    assert!(cloud.points()[0].is_none());
    assert_eq!(cloud.points()[1].unwrap().z, 34.);
    Ok(())
}

이 페이지는 기준 SDK 소스와 대조했습니다. 예제는 실행 환경에서 별도로 검증해야 하며 합성 데이터 결과는 실장비 정확도를 뜻하지 않습니다.
