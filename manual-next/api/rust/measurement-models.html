Line/Circle/Ellipse/Rectangle 모델과 옵션 Result.

개념과 사용 흐름

LineMeasurementModel::new(start,end,search_skew_radians,probes)와 CircleMeasurementModel::new(center,radius,start_angle,end_angle,probes)는 검증된 모델을 생성합니다. measure(&image)는 각각 독립 결과를 반환합니다.

EllipseMeasurementModel.new관련 공개 객체·메서드
RectangleMeasurementModel.new관련 공개 객체·메서드

오류·주의사항

Ellipse/Rectangle은 ShapeProbeSettings와 RobustFitOptions를 사용하며 결과 fit()은 Option입니다. probes·status·converged 진단이 필요합니다.
