평면 보정 입출력

필드 / 타입의미 · 단위 · 유효 조건
mapping() / Mapping: Homography글로벌 픽셀→세계 평면의 가역 3×3 변환. Rust new는 역행렬 가능성 검증.
unit() / Unit: LengthUnit보정 세계 좌표의 단위: Millimeter, Micrometer, Meter.
fit(pixels, world, unit)유한한 대응 좌표, 같은 수 최소 4쌍, 비퇴화 배치. 학습 픽셀은 글로벌.
pixel_to_world(p, unit)글로벌 픽셀→요청 단위 세계점.
world_to_pixel(p, unit)지정 단위 세계점→글로벌 픽셀.
evaluate(pixels, world, unit, tolerance)빈 배열 불가, 길이 일치, 유한한 tolerance ≥ 0. tolerance는 평가 world 단위.
metrics: CalibrationMetricscount, rms_world, max_world, rms_pixel, max_pixel, passed; passed는 max_world ≤ tolerance.
residuals: CalibrationResidual[]observed_pixel, reference_world, predicted_world, predicted_pixel, error_world, error_pixel. 순서는 입력 대응 순서.

세계 단위와 픽셀 단위 잔차를 혼합하지 마세요. 점 배치가 퇴화하거나 역변환이 불가능한 경우, 유한하지 않은 입력 또는 계산은 오류입니다. 좌표계가 잘못됐어도 수치가 유효하면 오류 없이 잘못된 결과가 나올 수 있습니다.

이 보정 필드의 기준 소스는 ce902e85c340입니다. 합성 기대값은 손계산이며 별도 실행 기록을 확인해야 합니다. 실제 장비 및 생산 정확도는 평가하지 않았습니다.

Rust의 보정 값은 세계 단위와 글로벌 픽셀에서 세계 평면으로 가는 매핑을 함께 보관합니다. pixel_to_world는 호출자가 요청한 단위로 결과를 내고 world_to_pixel은 제공된 세계 단위에서 보정 단위로 환산한 뒤 역변환합니다. 보정이 밀리미터로 저장되어 있더라도 호출 단위를 달리 지정할 수 있으므로 반환값을 해석할 때 단위를 누락하지 마십시오.

evaluate는 보류 대응점 전체에 대한 집계와 점별 값을 스냅샷으로 돌려줍니다. 빈 점 배열, 서로 다른 배열 길이 또는 음수 허용치는 유효하지 않습니다. 예측 오차가 작더라도 같은 점을 학습과 검증에 모두 썼다면 독립적인 보류점 성능을 보여주지 못합니다. 여러 위치의 보류점을 마련하고 최대 오차와 RMS를 함께 기록하는 것이 진단에 유용합니다.

대응점이 같은 직선 위에 몰리면 입력이 네 개 이상이어도 투영을 정하는 데 필요한 배치 조건이 충족되지 않을 수 있습니다. 좌표가 유한한지 확인한 다음 평면 전체를 덮도록 기준점을 배치하고, 별도의 보류점으로 결과를 검사하십시오.
