Rust · ZImage::threshold

Rust 공개 Facade에서 즉시 실행되는 Gray8 마스크 생성 API.

공개 시그니처

Rust
impl ZImage {
    pub fn threshold(&self, threshold: f64) -> ZResult<Self>;
}

정식 공개 타입 zvision::ZImage; 입력을 빌리고 새 소유 ZImage를 결과로 반환합니다.

매개변수·반환

항목자료형설명
thresholdf64픽셀과 비교할 유한한 임계값; 기본값 없음
반환ZResult<ZImage>0 또는 255를 갖는 새로운 Gray8 이미지

입력은 7종 회색 형식으로 제한되며, 비유한 임계값이나 비유한 부동소수 픽셀·컬러 형식은 오류입니다. 원본 픽셀은 보존되며 ROI의 origin 역시 유지됩니다.

실제 사용 코드

Rust
use zvision::ZImage;

fn main() -> zvision::ZResult<()> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    let result = source.threshold(10.0)?;
    assert_eq!(result.to_packed_vec()?, vec![0, 255, 255]);
    Ok(())
}

Threshold의 원리 · 첫 이미지 처리

경계와 형식 선택

비교는 p ≥ T입니다. 아래 합성 입력은 경계값이 포함됨을 보여줍니다.

조건결과 또는 조치
T=10, [9,10,11][0,255,255]
유한한 T 및 7종 Gray새 Gray8 마스크
색상 이미지 또는 비유한 T/부동소수 입력오류; 입력 형식과 값을 먼저 검증

이미지 형식은 전체 14종이지만 이 연산의 입력은 그중 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64 일곱 종입니다. ROI에서 생성된 마스크는 ROI 원점을 보존합니다. 결과는 원본을 변경하지 않는 별도 소유 이미지입니다.

값과 실패 해석

조건결과·조치
픽셀 = T255; 비교 경계를 포함
T가 입력 최댓값보다 큼모든 픽셀이 0; 정상적인 빈 전경
NaN/무한 입력 또는 T오류; 유효 픽셀을 준비한 후 재호출
수명결과는 별도 소유 Gray8. C# Dispose, Python close/with, Rust 소유값 해제
