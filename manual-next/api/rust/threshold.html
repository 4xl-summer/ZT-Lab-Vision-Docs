Rust · ZImage::threshold

Rust 공개 Facade에서 즉시 실행되는 Gray8 마스크 생성 API.

독립 HTML 페이지코드 검토 기준 2026-11-08초기 콘텐츠

공개 시그니처

Rust
impl ZImage {
    pub fn threshold(&self, threshold: f64) -> ZResult<Self>;
}

정식 공개 타입 zvision::ZImage; 입력을 빌리고 새 소유 ZImage를 결과로 반환합니다.

매개변수·반환

항목자료형설명
thresholdf64픽셀과 비교할 유한한 임계값; 기본값 없음
반환ZResult<ZImage>0 또는 255를 갖는 새로운 Gray8 이미지

입력은 7종 회색 형식으로 제한되며, 비유한 임계값이나 비유한 부동소수 픽셀·컬러 형식은 오류입니다. 원본 픽셀은 보존되며 ROI의 origin 역시 유지됩니다.

실제 사용 코드

Rust
use zvision::ZImage;

fn main() -> zvision::ZResult<()> {
    let source = ZImage::from_vec_gray8(3, 1, vec![9, 10, 11])?;
    let result = source.threshold(10.0)?;
    assert_eq!(result.to_packed_vec()?, vec![0, 255, 255]);
    Ok(())
}
