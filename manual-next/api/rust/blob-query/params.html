인자와 반환 객체 · 핵심 동작

연결성 인자는 성분이 이웃하는 방식을 정합니다. Four는 가로·세로, Eight는 대각선도 이웃으로 봅니다. 같은 2×2 대각 전경에서 Four는 객체 두 개, Eight는 객체 한 개이므로 이 선택은 단순한 성능 설정이 아닙니다. 결과를 다른 레시피와 비교할 때 연결성도 함께 보존하십시오.

인자와 반환 객체 · 입력과 결과

조건식 필터는 Blob을 판정할 표현식이고 정렬식은 결과의 순서를 정합니다. Rust 메서드는 계획을 소비하고 새 계획을 반환하므로 분기할 계획이 있다면 소유권을 의식해 구성해야 합니다. 일부 빌더 연산은 ZResult를 반환하므로 실패를 확인하기 전까지 결과가 준비되었다고 가정할 수 없습니다.

인자와 반환 객체 · 좌표와 소유권

실행 결과에는 BlobAnalysisResult 값이 있고 blobs()는 성분 슬라이스를 빌려 줍니다. 각 성분은 면적, 최소 외접 사각형, 중심을 갖습니다. 면적은 픽셀 수이며 사각형의 너비×높이와 같아야 하는 것은 아닙니다.

인자와 반환 객체 · 오류와 판단

ROI에서 얻은 좌표는 ROI 로컬입니다. 원본 전체 좌표가 필요하면 원점을 한 번 적용하고, 결과의 빌린 슬라이스는 실행 결과가 살아 있는 동안 사용합니다. 빈 슬라이스는 정상적으로 전경이 없는 상황과 일치할 수 있습니다.

연결성은 이웃의 정의이고 면적 조건은 완성된 성분의 선택 조건이다. 예컨대 대각선 픽셀의 연결 여부를 바꾸면 면적 필터에 전달되는 후보 자체도 바뀔 수 있다.
