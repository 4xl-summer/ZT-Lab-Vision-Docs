연결, 면적과 좌표

전경은 0이 아닌 픽셀입니다. 면적은 픽셀 셀의 개수이고 무게중심은 각 전경 픽셀 좌표의 산술 평균 (Σx/N, Σy/N)입니다. 대각 두 점의 면적은 8연결에서 2, 중심은 (0.5,0.5)입니다.

선택해석
4연결상하좌우 이웃만 이어짐
8연결대각 이웃도 이어짐
면적 필터경계 포함; 단위는 픽셀 수
ROI결과 좌표계와 상위 원점의 관계를 확인하고 합산; 고급 BlobResult는 부모 원점을 보관하지 않음
영역 없음빈 결과는 성공 가능한 검사 결과

픽셀 면적과 윤곽 다각형 면적은 다른 측정량입니다. 교정된 면적은 픽셀 크기 또는 변환에 따라 별도로 계산합니다. 대각 접촉과 경계 절단 객체는 검출 기준을 정해 테스트하십시오.

연결, 면적과 좌표 · 핵심 동작

대각선으로만 만나는 두 픽셀은 Four에서는 이웃이 아니고 Eight에서는 이웃입니다. 따라서 2×2 마스크 [255,0,0,255]는 Four에서 면적 1인 두 성분, Eight에서 면적 2인 한 성분입니다. Eight의 중심은 두 로컬 픽셀 좌표 (0,0), (1,1)의 평균 (0.5,0.5)입니다.

연결, 면적과 좌표 · 입력과 결과

전경의 기준은 0이 아닌 값입니다. 예를 들어 1과 200이 서로 접해 있으면 밝기가 다르다는 이유만으로 나뉘지 않습니다. 밝기별 객체가 필요하다면 먼저 원하는 기준으로 마스크를 만들고, 이 API가 단순 연결 성분을 측정한다는 점을 고려해야 합니다. 영역이 비어 있으면 성분 목록은 비어 있습니다.

연결, 면적과 좌표 · 좌표와 소유권

각 성분의 면적은 전경 셀 수이고 경계는 해당 셀을 포함하는 최소 축 정렬 사각형입니다. 사각형 너비와 높이의 곱은 배경을 포함할 수 있으므로 영역 면적과 다를 수 있습니다. 중심은 전경 픽셀 중심의 평균으로, ROI의 원점을 자동으로 더한 전역 위치가 아닙니다.

연결, 면적과 좌표 · 오류와 판단

이 예시는 좌표와 연결 규칙의 수치 검증용입니다. 실제 결함이 프레임 가장자리나 ROI 경계에서 잘리면 다른 프레임과 연결되지 않으므로 면적의 해석 기준도 함께 정해야 합니다.
