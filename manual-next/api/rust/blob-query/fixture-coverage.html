실행 사례와 검증 범위 · 핵심 동작

Rust 연결성 합성 사례는 2×2 영상에서 대각선 두 위치만 전경으로 둡니다. 4연결은 대각선 이웃을 인정하지 않아 두 개의 객체로 나뉘고, 8연결은 두 점이 하나의 객체로 연결됩니다. 사례에서 확인하는 수치는 네 이웃 정의가 결과 목록의 개수에 미치는 영향입니다.

실행 사례와 검증 범위 · 입력과 결과

독립적인 면적 해석은 동일한 입력의 수동 계산으로 확인할 수 있습니다. 8연결 성분의 면적은 2이며 중심은 (0.5,0.5)입니다. 4연결에서는 각 성분이 면적 1이므로 결과 목록에서 개수와 각 영역의 값을 구분해 확인해야 합니다. 영역의 픽셀 밝기를 합한 값과 면적을 혼동하지 마십시오.

실행 사례와 검증 범위 · 좌표와 소유권

사례 ID를 통해 실행 기록과 본문의 입력을 연결할 수 있습니다. 다만 어느 속성을 실제 단언했는지는 사례별 코드를 확인해야 하며, 객체 수 검증만으로 모든 중심과 수명 조건까지 테스트했다고 볼 수 없습니다. 실행 계획과 결과의 소유권은 별도의 확인 대상입니다.

실행 사례와 검증 범위 · 오류와 판단

검사물의 실제 조명이나 ROI 가장자리를 포함하지 않는 합성 입력이므로, 생산 조건의 정확도와 처리 속도는 별도 자료로 평가해야 합니다.

대각선 두 픽셀 사례는 연결 방식을 구별하는 최소 입력이다. 넓은 영역이나 경계에 닿는 물체의 처리는 이 한 사례만으로 검증되지 않으므로 실제 조건에 맞는 사례를 추가한다.
