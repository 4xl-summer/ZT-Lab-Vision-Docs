최소 실행 예제 · Rust · BlobQuery / BlobAnalysisResult

최소 실행 예제의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

최소 실행 예제

Rust
use zvision::{Connectivity, ZImage};

fn main() -> zvision::ZResult<()> {
    let src = ZImage::from_vec_gray8(3, 1, vec![0, 5, 5])?;
    let plan = src.query()?.threshold(1)?.find_blobs(Connectivity::Four);
    let execution = plan.execute()?;
    let blobs = execution.output().blobs();
    assert_eq!(blobs.len(), 1);
    assert_eq!(blobs[0].area, 2);
    Ok(())
}

Rust는 ImageQuery의 종료 연산을 통해 Typed Blob 결과를 얻습니다. C#/Python의 편의 직접 메서드와 동일한 메서드명·호출형이라고 가정하지 않습니다.

최소 실행 예제 · 핵심 동작

이 합성 예제는 [0,5,5]를 한 행의 Gray8 영상으로 만듭니다. 임계값 1은 두 값 5를 전경으로 바꾸고 0은 배경으로 남깁니다. 그 결과 [0,255,255]에서 두 전경은 좌우로 닿아 있으므로 Four를 선택해도 하나의 성분입니다. area가 2인 이유는 두 픽셀이 선택되었기 때문입니다.

최소 실행 예제 · 입력과 결과

코드에서는 이미지에서 질의를 만든 후 임계값과 연결 성분 단계를 연결하고 execute()로 실행합니다. 실행 결과의 output().blobs()를 통해 성분 목록을 확인하며, 빌린 목록은 그 실행 결과에 연결된 수명 안에서 읽습니다. 원본 영상과 결과 스냅샷의 역할이 서로 다릅니다.

최소 실행 예제 · 좌표와 소유권

경계값을 5로 바꾸어도 원본 5는 경계 이상이므로 두 픽셀은 전경으로 남습니다. 임계값을 6으로 높이면 두 값이 모두 배경이 되어 빈 목록이 정상입니다. 이 변화는 연결성 오류가 아니라 분할 조건의 변화입니다.

최소 실행 예제 · 오류와 판단

코드가 반환한 오류는 ?로 전파합니다. 특정 결과 하나만 단언하는 합성 예제이므로 실제 입력의 ROI 경계, 대각 접촉, 조명 변화에 대한 검증은 별도로 추가하십시오.
