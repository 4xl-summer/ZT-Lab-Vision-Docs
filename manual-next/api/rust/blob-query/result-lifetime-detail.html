결과 필드와 수명 · 핵심 동작

Blob의 면적은 연결된 비영 픽셀의 수입니다. 경계 사각형은 ROI 로컬 위치와 크기를 가지며, 오른쪽과 아래 끝은 제외하는 방식으로 해석합니다. 무게중심은 전경 픽셀 중심을 평균하므로 소수가 될 수 있습니다. 직사각형 경계의 중앙과 픽셀 평균은 오목한 모양이나 구멍이 있는 모양에서 서로 달라질 수 있습니다.

결과 필드와 수명 · 입력과 결과

질의 실행으로 얻은 목록은 성분의 측정 스냅샷입니다. blobs()는 결과가 소유한 목록을 빌리므로 실행 결과보다 오래 참조를 유지할 수 없습니다. 계획에 조건이나 정렬을 추가하는 과정은 Rust에서 소유값을 이동하며, 각 단계의 오류는 ZResult로 확인합니다.

결과 필드와 수명 · 좌표와 소유권

ROI에서 측정한 x,y는 해당 영역의 로컬 좌표입니다. 원점이 (10,20)이고 Blob 중심이 (1.5,2)라면 원본 기준 중심은 (11.5,22)입니다. 면적은 좌표 이동에 따라 변하지 않으며, 실제 길이 단위로 바꾸려면 픽셀 보정이 필요합니다.

결과 필드와 수명 · 오류와 판단

배경만 있는 입력은 빈 목록이 될 수 있습니다. 반면 잘못된 입력이나 실행 실패는 오류이므로 두 상태를 분리하십시오. 둘을 혼동하면 검사 대상이 없다는 정상 판정으로 설정 오류가 묻힐 수 있습니다.

결과를 다음 처리로 넘길 때 필요한 값과 소유권 관계를 먼저 정한다. 다음 이미지에서 계산한 결과를 이전 결과의 같은 성분이라고 간주하지 말고 좌표와 면적을 기준으로 비교한다.
