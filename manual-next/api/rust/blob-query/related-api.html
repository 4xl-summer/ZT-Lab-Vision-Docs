관련 API · 핵심 동작

Rust에서 연결 성분을 얻는 방법에는 이미지에서 직접 결과를 구하는 경로와 이미지 질의의 find_blobs 종료 계획이 있습니다. 이 페이지의 예제는 후자를 사용하므로 계획을 만든 뒤 execute()를 호출하고 출력에서 blobs()를 읽습니다. 둘의 반환 형태와 소유권이 같다고 가정하면 컴파일 또는 수명 해석에서 문제가 생길 수 있습니다.

관련 API · 입력과 결과

전처리로 고정 임계값을 사용하면 각 픽셀이 T 이상일 때 255가 됩니다. 예제 [0,5,5]에 T=1을 적용하면 영역 분석에 전달되는 마스크는 [0,255,255]입니다. 전경의 수를 바꾸는 열기나 닫기를 추가할 때는 커널 폭과 ROI 경계 영향을 별도로 평가해야 합니다.

관련 API · 좌표와 소유권

Blob 결과의 기본 필드는 면적, 외접 사각형, 중심입니다. 조건식과 정렬은 이 결과를 선택하고 순서를 정하는 계획이며, 픽셀을 새로 촬영하거나 물리 보정을 자동 적용하지 않습니다. 크기 기준이 픽셀인지 실제 길이 단위인지 호출 전에 정하십시오.

관련 API · 오류와 판단

처리가 실패하면 ZResult를 통해 오류를 다루고, 성공한 빈 목록과 분리합니다. 결과 슬라이스는 소유 실행 결과를 살아 있게 유지하는 범위 안에서 사용해야 합니다.

전처리 결과를 블롭 분석으로 넘길 때 선택된 영역이 밝은 전경인지 먼저 확인한다. 연결 결과가 다르면 임계 처리의 마스크와 쿼리의 연결 조건을 각각 관찰해 원인을 구분한다.
