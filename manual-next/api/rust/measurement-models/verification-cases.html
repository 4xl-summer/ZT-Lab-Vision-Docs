관련 검증 사례

rust-measurement-models는 합성 영상에서 선과 원 측정 모델의 공개 생성·실행 경로를 살펴보는 사례입니다. 모델의 생성이 성공했는지와 영상 측정에서 형상을 얻었는지는 서로 다른 단계이므로, 테스트에서는 반환 오류뿐 아니라 결과의 상태와 피팅 유무도 확인합니다. 각 관측의 선택 에지와 채택 여부는 결과 상태를 설명하는 근거가 됩니다.

검출점이 부족한 영상도 정상 호출의 한 결과가 될 수 있습니다. 이런 경우 기대값은 임의의 원점이 아니라 적합이 없다는 상태입니다. 성공한 경우에도 수렴 플래그, 피팅 잔차와 사용된 점을 살펴보고 기준 좌표와 같은 ROI를 사용하는지 확인하십시오. 합성 사례의 결과를 공장 장비의 정확도나 처리 속도에 대한 증거로 확대하지 않으며, 실행 이력과 소스 버전을 별도로 기록합니다.

합성 영상의 경계 위치와 모델의 탐색 방향을 함께 기록하면 결과 변화가 설정에 의한 것인지 입력에 의한 것인지 구별할 수 있습니다.

검사 범위는 합성 프레임의 선택 에지, 형상 유무와 관측 상태에 한정됩니다. 예측한 위치가 나오지 않을 때는 검색선이 실제로 경계를 통과하는지, 진행 방향의 극성과 밝기 변화가 일치하는지부터 확인합니다. 같은 점 집합을 재사용한 피팅 시험과 영상 탐색 시험은 서로 다른 단계의 증거입니다.

적용 순서와 결과 판독

관측과 형상을 비교하는 검증에서는 모델의 기준 위치만 기록해서는 부족합니다. 각 프로브의 진행 방향, 선택된 에지와 최종 적합에 채택되었는지를 함께 기록해야 다른 경계를 선택한 문제와 적합 조건이 너무 엄격한 문제를 구분할 수 있습니다. 동일 영상에서 설정 하나만 바꾸어 비교하면 결과 차이가 어느 단계에서 시작됐는지 추적하기 쉽습니다. 합성 사례에서 확인한 결과를 새 장비의 정확도나 모든 영상에 대한 보증으로 확대하지 마십시오.

확인 단계판독과 조치
입력과 모델같은 프레임과 ROI 기준을 사용합니다.
프로브 진단후보의 위치와 진행 방향을 확인합니다.
적합 상태찾은 점과 채택점을 따로 확인합니다.
결과 비교바뀐 설정과 잔차를 같이 기록합니다.
