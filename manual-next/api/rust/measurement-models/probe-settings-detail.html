프로브 설정과 범위

ProbeSettings의 count는 직선 최소 2·원 최소 3에서 4096 이하, search_length는 유한한 양의 픽셀 길이, profile_width는 양의 홀수, profile_samples는 2×derivative_radius+3 이상입니다. direction은 Forward/Reverse, selection은 First/Last/Strongest, min_found는 해당 모델 최소점 이상 count 이하입니다. caliper는 고급 프로파일·미분·극성·임계값·피크 선택 설정이고 fit은 직선/원용 FitOptions입니다. ShapeProbeSettings는 같은 프로브 필드를 가지지만 fit 필드가 없고 타원·사각형 모델 자체의 RobustFitOptions를 사용합니다. default_measurement_probes()는 직선·원 설정을 제공하며 형상 설정은 별도로 지정합니다.

미분 반경과 max_results는 1 이상, threshold/prominence는 유한한 0 이상, min_valid_width는 1 이상 profile_width 이하입니다. 필터는 비어 있지 않은 유한한 홀수 길이이며 합이 유한하고 절댓값이 기계 엡실론보다 커야 합니다. 프로브 작업량 count×profile_samples×(profile_width+filter 길이+2×반경)은 8,000,000 이하여야 합니다.

모델은 기준 선분 또는 원호 위에 앵커를 배치한 다음 각 앵커 주위에서 밝기 경계를 찾습니다. count는 피팅에 기여할 기회를, search_length는 각 앵커 양쪽의 탐색 범위를 정합니다. 탐색 길이 14픽셀이면 중심에서 각 방향으로 7픽셀씩인 선분을 살펴봅니다. 개수를 늘리는 것만으로 모두 채택되는 것은 아니므로 관측별 상태도 함께 확인해야 합니다.

에지 선택과 피팅은 서로 다른 단계입니다. selection은 한 프로브의 후보 중 어떤 에지를 선택할지 정하고, fit은 선택된 점들을 어떤 조건으로 형상에 맞출지 정합니다. 모델 생성에 실패하면 count, 표본 수, 폭, 필터와 작업량을 먼저 점검합니다. 영상 경계 부근에서는 모델이 유효하더라도 개별 프로브가 유효한 표본을 충분히 얻지 못할 수 있습니다.

적용 순서와 결과 판독

기준 형상을 따라 배치한 각 프로브는 별도의 작은 탐색 구간입니다. 개수를 늘리면 관찰 위치가 많아지지만, 같은 검색 길이와 폭을 모든 위치에 적용하므로 영상 경계에 가까운 구간도 함께 확인해야 합니다. 선의 기준 방향은 탐색 구간의 방향과 다르며 검출된 점의 순서가 곧 피팅 채택 순서를 뜻하지 않습니다. 미분 반경을 키웠다면 표본 수 조건도 다시 확인하여 유효하지 않은 조합을 호출 전에 걸러냅니다.

확인 단계판독과 조치
프로브 개수관측 위치의 수이며 허용 범위를 확인합니다.
탐색 길이와 폭경계를 가로지르되 다른 경계 혼입을 살핍니다.
표본 수와 미분 반경서로의 최소 조건을 함께 충족해야 합니다.
최소 검출 수실제로 찾은 위치가 기준을 충족하는지 봅니다.
