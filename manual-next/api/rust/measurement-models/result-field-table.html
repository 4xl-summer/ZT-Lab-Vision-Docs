결과와 수명의 입력 조건과 결과 해석을 설명합니다.

결과와 수명

필드 / 타입의미 · 단위 · 유효 조건
status(): ModelFitStatusFit, InsufficientPoints, FitFailed. Fit도 converged() 확인 필요.
fit(): Option<&Fit>성공한 모델이 없으면 None; 선 point/direction, 원 center/radius, 타원 center/major_radius/minor_radius/angle/stats, 사각형 center/half_width/half_height/angle.
probes(): &[ProbeObservation]각 index와 로컬 anchor, status(Found/NoEdge/OutsideOrInvalidSamples), selected 에지, used와 residual. 선택됨과 채택됨은 별개.
converged(): bool최적화/재피팅 수렴 여부.
refit_iterations() / iterations(): usize직선·원 재피팅 횟수 / 타원·사각형 최적화 횟수.
condition_proxy(): Option<f64>타원·사각형 피팅 상태의 조건 지표. 정밀도 보증치가 아님.
side: Option<u8>, weight: Option<f64>형상 관측의 사각형 변 식별값과 견고 피팅 가중치. 사용할 수 없는 경우 None.

결과는 영상과 분리된 소유 스냅샷입니다. fit()/probes() 참조는 결과 수명 동안만 유효합니다. 잘못된 기하·설정·영상 형식은 오류이고, 유효한 입력에서 점 부족과 피팅 실패는 상태로 반환됩니다. 점 부족 시 검색 길이·ROI 경계·극성·임계값을 확인하세요.

Rust 모델 설명은 ce902e85c340 공개 소스에 근거합니다. 기대 수치는 합성 데이터의 손계산이며 실행 상태는 별도 기록하고 실장비·생산 정확도는 확인하지 않았습니다.

결과의 최상위 상태, 선택된 에지와 피팅 채택은 서로 다른 질문에 답합니다. 상태는 형상을 만들었는지 나타내고, 관측의 selected는 각 탐색선에서 어떤 에지를 골랐는지 알려 줍니다. used는 그 점이 결과 형상에 채택되었는지이며, 잔차는 선택 위치와 피팅 형상의 차이를 진단하는 데 씁니다.

결과가 Fit이어도 수렴 플래그와 잔차 분포를 확인해야 합니다. 반대로 InsufficientPoints에서는 피팅 값 대신 발견되지 않은 프로브와 필요한 최소 수를 조사하십시오. Rust의 fit()과 probes()는 결과가 소유한 데이터를 빌려주므로 참조를 결과보다 오래 보관할 수 없습니다. 수치의 소수점 표시만으로 측정 불확도를 추정하지 않습니다.

관측 순서는 탐색 앵커의 순서이며, 잔차가 없는 항목을 임의의 0으로 변환하지 않습니다. 부재는 계산 가능한 피팅 잔차가 없다는 뜻일 수 있습니다.

결과의 소유 객체를 오래 보관할 필요가 있다면 필요한 값과 관측을 명시적으로 관리합니다. 실행 중 계산된 참조를 이미 해제된 결과에 연결해서는 안 됩니다.
