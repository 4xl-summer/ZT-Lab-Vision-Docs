FitOptions 필드

필드 / 타입의미 · 단위 · 유효 조건
method: FitMethodLeastSquares 또는 Consensus.
inlier_threshold: f64채택 잔차 한계; 좌표 단위, 유한한 양수.
min_inliers: usize최종 최소 채택점 수, 모델 최소점 이상 count 이하.
max_candidates: usize후보 상한 1–1,000,000.
max_refit_iterations: usize재피팅 횟수 1–1000.
tolerance: f64수렴 허용치, 좌표 단위, 유한한 0 이상.
min_arc_radians: f64원 채택점의 최소 각도 범위; 유한한 0–2π 라디안.

표의 설정은 프로브가 이미 선택한 점들의 기하에 적용됩니다. 선의 최소 점 수와 원의 최소 점 수가 다르며 min_inliers는 해당 최솟값 이상이어야 합니다. 같은 count라도 에지 미검출 때문에 실제 선택점 수가 줄어들 수 있으므로, 임계값이나 최소 채택 수를 조정하기 전에 프로브 목록을 먼저 검사합니다.

Consensus를 쓰면 후보 수와 재피팅 횟수가 작업량에 함께 기여합니다. 무조건 큰 숫자를 넣으면 속도만 달라지는 것이 아니라 제한 초과 오류가 날 수 있습니다. 원호 각도 조건은 라디안인 반면 잔차 문턱과 수렴 허용치는 입력 좌표 단위입니다. 모델이 픽셀로 지정됐다면 거리 기준을 밀리미터 수치로 바로 대입하지 말고 해당 좌표계에서 검토하십시오.

선택점이 형상 일부에만 몰리거나 같은 위치로 겹치면 충분한 개수라도 안정된 기하를 만들기 어렵습니다. 예상되는 점의 위치 범위도 점검해야 합니다.

선택한 점이 최소 수를 넘더라도 한 위치에 겹치거나 원의 아주 짧은 부분에 몰릴 수 있습니다. 이러한 배치는 후보의 형상을 정하기에 부족할 수 있어 성공 여부와 수렴 여부를 따로 읽어야 합니다. 실패를 없애려고 허용치만 계속 키우면 원하지 않는 경계까지 채택될 수 있으니 선택 에지의 좌표도 확인하십시오.
