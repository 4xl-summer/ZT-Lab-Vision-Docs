RobustFitOptions 필드 · Rust · MeasurementModels

RobustFitOptions 필드의 입력 조건과 결과 해석을 설명합니다.

RobustFitOptions 필드

필드 / 타입의미 · 단위 · 유효 조건
loss: RobustLossLeastSquares, Huber 또는 Tukey 가중 손실.
scale: f64가중 손실 척도; 좌표 단위, 유한한 양수.
initial_threshold: f64초기 피팅 임계값; 좌표 단위, 유한한 양수.
inlier_threshold: f64최종 채택 잔차 임계값; 좌표 단위, 유한한 양수.
max_iterations: usize최적화 상한 1–1000.
tolerance: f64수렴 허용치, 유한한 양수.
damping: f64최적화 감쇠, 유한한 양수.

ShapeProbeSettings와 RobustFitOptions에는 이 문서에서 사용할 명시적 기본 생성값이 확인되지 않았습니다. 각 필드를 직접 지정하세요. 타원은 major_radius ≥ minor_radius > 0, minor/major ≥ 0.01, 호 범위 (0,2π]; 사각형은 두 반폭이 유한한 양수입니다. 중심과 각도는 유한해야 합니다.

형상 피팅에는 초기 형상, 손실 함수, 반복 종료 조건을 함께 설정합니다. initial_threshold와 inlier_threshold는 둘 다 거리이지만 전자는 초기 후보를 만들고 후자는 결과의 채택 여부를 판정합니다. scale은 Huber 또는 Tukey가 큰 잔차를 얼마나 약하게 다룰지 정하며, 양수가 아닌 값은 사용할 수 없습니다.

예를 들어 scale이 2이고 절대 잔차가 4인 점의 정규화 크기는 2입니다. Huber 가중치는 1/2이고 Tukey 가중치는 0이 됩니다. 이는 특정 점의 영향이 달라지는 계산 예이며 어떤 값이 장비에 적합하다는 뜻은 아닙니다. 반복 횟수와 감쇠는 수렴 진단과 함께 읽고, 설정과 점 수의 작업량 제한도 모델 생성 단계에서 확인하십시오.

반복 종료 조건과 최종 채택 기준은 같은 수치가 아닙니다. 전자는 정련을 언제 멈추는지, 후자는 각 점을 결과에 포함할지에 영향을 줍니다. 값이 양수라는 조건뿐 아니라 입력 좌표 단위와의 관계를 함께 살펴야 합니다.
