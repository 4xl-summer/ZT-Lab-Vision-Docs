ProbeSettings 및 ShapeProbeSettings 필드

필드 / 타입의미 · 단위 · 유효 조건
count: usize직선 2 이상, 원 3 이상, 타원 5 이상. 사각형은 변당 2 이상이며 4×count ≤ 4096; 나머지 총 수 ≤ 4096.
search_length: f64프로브 중심을 기준으로 양쪽 절반씩 뻗는 유한한 양의 픽셀 길이.
profile_width: usize프로브 스트립의 양의 홀수 샘플 수.
profile_samples: usize선분 표본 수. 2×derivative_radius+3 이상.
direction: ProbeDirectionForward 또는 Reverse. 뒤집으면 탐색 및 극성 방향이 뒤집힘.
caliper: AdvancedCaliperOptions각 프로브의 샘플링·미분·극성·에지 후보 조건. 아래 표 참조.
selection: ProbeSelectionFirst, Last, Strongest 중 하나. First/Last는 위치순, Strongest는 강도순 후보를 고름.
min_found: usize피팅 전 필요한 최소 발견 수; 모델 최소점 이상 count 이하. 사각형은 각 변마다 이 수 이상이 필요함.
fit: FitOptions직선·원 ProbeSettings에만 존재. 타원·사각형은 모델 생성 인자 RobustFitOptions 사용.

프로브 필드는 기준 형상을 따라 탐색선을 어떻게 배치할지와 각 탐색선에서 에지를 어떻게 고를지를 구분합니다. 직선에서는 앵커가 두 끝을 포함하도록 분포하며 원에서는 각도 범위를 따라 배치됩니다. direction을 역방향으로 바꾸면 각 탐색선의 진행 방향이 뒤집혀 상승·하강 극성의 해석도 달라집니다.

예를 들어 원에 세 개의 프로브와 최소 발견 수 세 개를 지정하면 세 곳 모두 선택된 에지가 있어야 피팅 단계에 도달합니다. 발견 이후에도 합의 피팅에서 점이 기각될 수 있으므로 발견 수와 채택 수는 별개입니다. 사각형의 count와 min_found는 각 변에서의 기준이고 네 변을 합친 수에도 제한이 적용됩니다. 설정이 범위를 넘으면 모델 생성 오류를 먼저 해결하십시오.

필터는 모델에 복사되는 설정이므로 다른 입력에 재사용할 때는 변경된 의도가 새 모델에도 반영되었는지 확인해야 합니다.

프로브의 탐색 구간은 기준점에 대해 양쪽으로 펼쳐집니다. 따라서 검색 길이가 14픽셀이면 앵커에서 각각 7픽셀 위치까지 보는 셈입니다. 표본 수는 양 끝을 포함하며 미분 반경이 커질수록 필요한 최소 표본 수도 증가합니다. 선택된 값이 경계 밖에서 부족하다면 영상 크기만이 아니라 폭과 보간에 필요한 유효 위치도 함께 확인해야 합니다.
