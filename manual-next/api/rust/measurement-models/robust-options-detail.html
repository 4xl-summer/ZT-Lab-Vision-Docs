견고 피팅 옵션

RobustFitOptions: loss는 LeastSquares/Huber/Tukey, scale은 잔차 가중의 양의 유한 척도, initial_threshold는 초기 피팅의 양의 유한 임계값, inlier_threshold는 최종 채택 판정의 양의 유한 임계값입니다. max_iterations는 1–1000, tolerance와 damping은 유한한 양수입니다. 점은 유한하고 최대 10,000개이며 점 수×(256+6×max_iterations) ≤ 4,000,000입니다. u=|잔차/scale|일 때 Huber 가중치는 u≤1에서 1, 그 밖에 1/u, Tukey는 u<1에서 (1−u²)², 그 밖에 0입니다. LeastSquares는 항상 1입니다.

견고 손실은 잔차가 큰 점의 영향력을 조절하는 방법입니다. 잔차가 같은 좌표 단위의 scale보다 작을 때와 클 때 가중 방식이 달라지므로, 점의 위치를 픽셀로 주었다면 해당 척도와 임계값도 픽셀 기준으로 선택합니다. Huber는 큰 잔차의 가중치를 줄이고 Tukey는 척도 밖 점의 가중치를 0으로 만들 수 있습니다. 손실 종류만 바꿨다고 자동으로 유효한 형상이 생기는 것은 아닙니다.

초기 임계값은 출발 형상을 구하는 단계에, 최종 임계값은 피팅 뒤 채택 여부에 쓰입니다. 두 값의 역할이 달라 한쪽을 다른 쪽과 같은 것으로 추론하지 마십시오. 반복 상한에 도달한 결과도 진단에서 수렴 여부를 별도로 읽어야 합니다. 점 배열이 너무 작거나 모두 비슷한 방향에만 몰려 있으면 유효한 최적화가 어려울 수 있으므로 표본 배치와 검색 범위를 함께 살펴봅니다.

적용 순서와 결과 판독

강건 손실은 점을 다시 측정하는 설정이 아니라 이미 선택한 점의 잔차가 적합에 주는 영향을 조정합니다. 작은 잔차와 큰 잔차의 가중치가 달라지므로 척도는 점 좌표와 같은 단위로 지정해야 합니다. 예를 들어 동일한 잔차라도 척도를 두 배로 지정하면 정규화된 잔차는 절반이 되어 손실 함수의 평가 위치가 바뀝니다. 반복 횟수를 늘리는 것만으로 잘못된 대상 경계를 올바른 경계로 바꿀 수는 없으므로 먼저 관측점의 분포를 확인하십시오.

확인 단계판독과 조치
손실 종류큰 잔차의 영향 감소 방식을 선택합니다.
양의 척도잔차를 정규화하는 기준이며 좌표 단위와 맞춥니다.
반복과 수렴 기준계산 종료 조건을 정하며 유효 범위를 확인합니다.
관측 분포다른 물체의 점이 섞였는지 먼저 살핍니다.
