공개 Rust Facade

impl MatchModel {
    pub fn train_ncc(template: &ZImage, mask: Option<&ZImage>) -> ZResult<Self>;
    pub fn info(&self) -> MatchModelInfo;
    pub fn find(&self, image: &ZImage, spec: &MatchSpec)
        -> ZResult<MatchResult>;
}
impl MatchResult {
    pub fn matches(&self) -> &[Match];
    pub fn best(&self) -> Option<&Match>;
}

객체 책임과 수명

MatchModel은 학습된 NCC 템플릿을 소유합니다. MatchSpec은 각도, 배율, 점수, NMS 간격 등의 검색 조건입니다. MatchResult는 검색 이미지나 모델을 해제해도 보유할 수 있는 독립 값 스냅샷입니다.

결과 접근설명
matches()점수순 정렬 및 NMS 후 매치 목록
best()최고 점수 결과가 없으면 None
position검색 ROI 로컬 위치
global_position원본 기준 위치
angle / scale / score자세·배율·점수(확률이 아님)

입력 조건과 예시

Rust
// template, image, spec은 유효하게 생성된 객체입니다.
let model = zvision::MatchModel::train_ncc(&template, None)?;
let result = model.find(&image, &spec)?;
if let Some(best) = result.best() {
    println!("score = {}", best.score);
}

이 코드는 이미 준비한 입력을 사용하는 발췌이며 정확한 전체 데이터 생성은 NCC 실전 예제에서 확인할 수 있습니다.

오류와 지원 형식

NCC는 Gray8/16/F32 학습·검색을 지원하며 학습 픽셀의 분산이 0이면 오류입니다. 잘못된 형식·검색 조건은 오류를 반환하고, 유효한 조건에서 일치하는 점이 없는 것은 빈 결과일 수 있습니다.
