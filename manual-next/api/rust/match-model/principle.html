정규화 상관으로 포즈 찾기

선택 템플릿 값 T와 후보 패치 I의 평균을 각각 빼고 Σ((T−T̄)(I−Ī)) / √(Σ(T−T̄)² Σ(I−Ī)²)를 계산합니다. 분산이 있는 동일 패턴은 1에 가깝고, 밝기 오프셋과 양의 일정 배율에 둔감합니다. 음의 상관은 음수이지만 기본 검색의 점수 하한은 0 이상이므로 음의 점수는 선택할 수 없습니다. 점수는 확률이 아닙니다. 검색 패치의 분산이 0이면 그 후보는 점수가 없어 건너뜁니다.

적용 상황과 원리

정규화 상관은 템플릿과 검색 패치의 선택 표본을 각각 평균 중심으로 만든 후 내적을 두 벡터 크기로 나누는 방식입니다. 선택 영역에 밝기 변화가 있으면 같은 패턴은 1에 가까운 점수를 갖습니다. 후보 영상에 일정한 오프셋을 더하거나 양의 배율을 곱해도 상대적인 밝기 관계가 같으면 점수는 유지되는 경향이 있습니다.

결과를 읽는 방법

이 계산은 분산이 없는 입력을 처리할 수 없습니다. 선택된 템플릿 값이 모두 같으면 학습이 실패하고, 검색 위치의 표본이 모두 같으면 그 위치에는 유효한 점수가 없으므로 후보에서 제외됩니다. 가능한 음의 상관을 점수 임계값으로 선택할 수 있는지도 별도로 확인해야 합니다. 기본 MatchSpec의 하한은 0에서 1 사이이며 모델 점수는 확률이나 물체의 존재 보증이 아닙니다.

추가 점검

실제 비교에서는 대상의 명암 구조가 같은지뿐 아니라 허용한 회전과 배율 격자에 가까운 점이 있는지도 중요합니다. 아무리 적절한 상관식이라도 평가하지 않은 자세는 이 기본 검색에서 자동으로 시험하지 않습니다.

정규화된 점수가 음수인 경우는 밝기 변화 방향이 반대인 후보입니다. 기본 검색에서 최소 점수를 음수로 지정할 수 없으므로 이러한 후보를 허용하려고 음수 임계값을 넘기면 유효성 검사가 실패합니다. 반전 요구는 다른 방법으로 검토해야 합니다.

분산과 점수의 해석

조건확인할 내용
