NCC 검색 예제

적용 상황과 원리

Rust 검색 예제는 영상 생성부터 학습, 설정과 find까지 한 번에 보여 줍니다. 모델 참조 문서의 각 필드는 그 예제에서 어떤 격자와 결과 조건을 선택했는지 확인하는 데 쓰입니다. 템플릿의 좌상단과 반환 기준점은 다르므로 예제에 적힌 입력 배열에서 두 위치를 직접 계산해 보는 것이 좌표 오류를 줄입니다.

결과를 읽는 방법

먼저 모델의 info로 학습 크기와 표본 수를 확인하고, 설정을 전달해 얻은 MatchResult에서 best를 선택합니다. 탐색 결과의 부재는 None이고 입력이나 설정 오류는 Result의 오류라는 점이 핵심입니다. 모델을 파일로 저장했다면 복원 후 같은 영상과 설정으로 다시 검색해야 결과를 비교할 수 있습니다. ROI 원점이 있는 영상에서는 표시 좌표와 로컬 좌표를 혼동하지 않도록 값의 출처를 같이 기록합니다.

추가 점검

결과 화면이나 후속 거리 측정에는 같은 좌표계를 사용해야 합니다. 검색 ROI가 원본에서 떨어져 있으면 그 원점을 더한 전역 위치가 필요합니다. 모델 크기가 짝수일 때 기준점이 반 픽셀에 있다는 점도 정수 좌상단만 사용하는 구현과 다릅니다.

입력과 모델의 픽셀 형식, 선택 마스크의 원점, 결과를 해석할 프레임을 검색 전에 정리해 두면 오류와 정상 미검출을 구분하기 쉽습니다. 저장 모델을 교체할 때는 설정을 함께 버전 관리하고 고정된 사례로 재검색하여 확인합니다.
