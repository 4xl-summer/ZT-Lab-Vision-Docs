결과와 진단

각 매치는 위치와 전역 위치, 각도, 배율, 점수, 학습 표본 수를 담습니다. 점수 내림차순이며 동점은 로컬 y, x, 각도, 배율 오름차순입니다. 이미 선택된 중심과 거리가 min_distance보다 작으면 억제하고, 같은 거리는 허용합니다. 거리 0이면 중복도 억제하지 않습니다. max_matches에 도달하면 중지합니다.

허용 후보가 없으면 오류가 아니라 빈 결과이며 최상위 결과는 없습니다. 검색 영역이 작거나 회전된 모서리가 벗어남, 임계값 미달, 검색 패치 분산 0이 원인일 수 있습니다. 형식 불일치, 마스크 크기·원점 불일치, 비유한 픽셀, 상수 템플릿, 유효하지 않은 격자는 오류입니다. 입력과 설정을 먼저 점검하고 실제 불량 및 양품 이미지로 임계값을 조정하세요.

적용 상황과 원리

find는 계산 오류가 없으면 MatchResult를 반환합니다. 그 안에 결과가 하나도 없을 수 있으므로 Result의 성공과 best의 Some 여부를 두 번 나누어 처리합니다. 잘못된 영상 형식, 비유한 값, 마스크 또는 MatchSpec 문제는 오류 경로로 보내고 정상적인 None은 검색 조건을 통과한 후보가 없는 상태로 기록합니다.

결과를 읽는 방법

목록은 점수 내림차순이고 점수가 같으면 로컬 y, x, 각도, 배율 순으로 정렬합니다. 선택된 후보와 중심 거리가 최소 거리보다 작은 후보는 제거됩니다. 거리가 정확히 같으면 통과하며 0을 지정하면 거리 조건으로는 억제하지 않습니다. 반환 개수 상한에 도달했다면 그 아래에 다른 후보가 존재했는지 결과만으로 알 수 없으므로 필요할 때 상한을 늘려 별도로 확인합니다.

추가 점검

최상위 항목만 저장하면 거리 억제 이전에 어떤 대안 후보가 있었는지 알 수 없습니다. 여러 물체를 처리해야 할 때는 결과 개수 상한과 거리 조건을 명시하고 matches 전체를 검토합니다. 반환 목록은 선택 이후의 결과입니다. 같은 점수의 tie 순서는 결과 재현을 돕지만 별도의 결함 심각도를 나타내지는 않습니다. 미검출과 오류에 서로 다른 상위 상태를 부여할 수 있습니다.
