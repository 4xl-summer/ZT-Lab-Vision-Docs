관련 API

적용 상황과 원리

MatchModel::train_ncc는 영상과 선택 마스크에서 학습 모델을 만들고 info는 종류, 크기, 기준점과 표본 수를 알려 줍니다. MatchSpec은 포즈 격자와 점수·중복 제거 조건을 지정하는 값입니다. 모델의 find는 검색 영상과 설정을 빌려 MatchResult를 만들며 오류와 빈 결과를 별도로 표현합니다. 먼저 Result를 확인하고 그 안에서 best를 읽는 순서가 자연스럽습니다.

결과를 읽는 방법

MatchResult::matches는 읽기 전용 슬라이스이고 best는 첫 매치에 대한 Option입니다. 각 Match는 position, global_position, angle, scale, score와 sample_count를 담습니다. 위치는 각각 검색 ROI 로컬과 그 원점을 더한 값입니다. I/O 기능을 사용할 때 모델을 save하고 load로 복원할 수 있지만 검색에 사용할 설정은 별도로 전달해야 합니다. 지연 처리가 필요하면 Query의 소유권 이동과 실행 결과 수명을 따로 확인하세요.

추가 점검

찾은 결과를 이어지는 측정에 넘길 때는 먼저 best가 존재하는지 확인합니다. 존재하지 않으면 가짜 기준점 대신 미검출 상태를 전파하고, 존재한다면 필요한 좌표계를 명시해 변환합니다. 모델의 정보와 검색 설정을 함께 기록하면 결과를 나중에 비교하기 쉽습니다.

작업 단계의 책임

검색별도 설정과 영상으로 포즈 후보를 찾습니다.
판독빈 결과를 처리하고 로컬·전역 좌표를 구분합니다.
