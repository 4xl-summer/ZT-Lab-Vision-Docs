저장과 복원

모델의 save/Save는 버전 1 모델 파일을 쓰고 기존 경로를 덮어씁니다. load/Load는 별도 소유 모델을 만듭니다. 파일이 없거나 손상·지원하지 않는 형식이면 로드 오류를 처리하세요. 검색 설정과 검색 결과는 모델 파일에 포함된다고 가정하지 말고 애플리케이션 설정으로 관리하세요. Rust 저장과 로드는 이미지 I/O 기능이 필요합니다.

적용 상황과 원리

Rust에서 모델 파일을 다루는 load와 save는 이미지 I/O 기능이 활성화된 경우 사용할 수 있습니다. 저장은 모델의 버전 있는 형식을 파일에 쓰며 동일한 경로의 기존 파일을 덮어씁니다. 복원은 새로운 소유 모델을 반환합니다. 존재하지 않는 경로, 읽기 권한 문제, 잘린 파일이나 지원하지 않는 인코딩은 파일 오류 또는 형식 오류로 다뤄야 합니다.

결과를 읽는 방법

재현에는 모델만이 아니라 검색 설정과 영상도 필요합니다. 로드한 모델의 info에서 크기와 표본 수가 기대한 값인지 확인하고 같은 검색 데이터 및 MatchSpec을 적용해 위치, 점수와 결과 수를 비교합니다. 임계값이나 최소 거리가 바뀌면 동일 모델에서도 선택된 후보가 달라질 수 있습니다. 모델을 성공적으로 저장했다는 사실은 다른 SDK나 외부 제품의 모델 형식과 호환된다는 보장이 아닙니다.

추가 점검

파일에 저장한 모델의 종류가 기대한 NCC인지도 info에서 확인할 수 있습니다. 다른 학습 단계의 파일을 같은 이름으로 덮어쓴 경우 정상 로드 자체는 가능하므로 기준 영상의 기대 위치와 표본 수를 함께 비교하는 편이 문제 발견에 도움이 됩니다. 파일을 읽는 경로에 대한 권한 오류 역시 검색 미검출과 다른 원인으로 기록해야 합니다.
