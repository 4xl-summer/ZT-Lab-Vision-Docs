적용 상황과 원리

기록된 Rust 인라인 예제는 Rust 1.85.1과 Linux x64 환경에서 종료 코드 0으로 실행되었습니다. 이 코드 블록은 결과를 출력하지만 자체 단언문은 없으므로 종료 성공만으로 출력된 좌표와 점수까지 자동 비교했다고 단정할 수 없습니다. 블록을 다른 문서로 옮길 때 내용과 해시를 유지하면 해당 실행 기록과의 연결을 확인할 수 있습니다.

결과를 읽는 방법

별도 ncc-literal 사례의 기대값은 여섯 학습 표본, 기준점 x 2와 y 0.5, 동일 패턴에서 1에 가까운 상관입니다. 선택 마스크를 쓰는 경우와 일정 검색 영상의 빈 결과는 각각 별도 조건으로 확인합니다. 실제 운영에서는 영상의 픽셀 형식, ROI 원점, 설정과 모델 파일을 함께 기록하고 필요한 오차 허용치를 정해야 합니다. 기록된 합성 실행은 다른 환경의 성능이나 실제 장비 검증이 아닙니다.

추가 점검

검증에 사용된 코드와 입력은 실험을 반복할 수 있는 작은 배열입니다. 패턴 시작점과 중심을 수식으로 계산할 수 있으므로 다른 크기의 템플릿에서도 같은 방법으로 별도의 기대 좌표를 만들 수 있습니다.

실제 애플리케이션에서는 ROI 원점, 허용 각도·배율과 점수 하한이 예제와 다릅니다. 그 조건을 반영한 양품과 불량 데이터에서 미검출 및 오검출을 평가하고, 이 실행 기록과 별도로 보관해야 합니다.
