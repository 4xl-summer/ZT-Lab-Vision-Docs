합성 예제와 독립 기대값 · Rust MatchModel

합성 예제와 독립 기대값에 대한 Rust MatchModel 사용 안내

상위 목차로 돌아가기

합성 예제와 독립 기대값

템플릿은 3×2 [3,17,1,8,2,25], 검색 영상은 4×2 [0,3,17,1,0,8,2,25]입니다. 0도, 배율 1에서 동일한 패턴은 좌상단 (1,0)에 있으며 기준점은 (2,0.5)입니다. 원점이 (0,0)이므로 전역 좌표도 같습니다. 기대 결과는 하나, 점수 약 1, 표본 6개입니다. 부동소수점 점수는 허용 오차로 비교하세요. 이 합성 예는 실장비 성능을 뜻하지 않습니다.

Rust
use zvision::{MatchModel, MatchSpec, ZImage};
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let template = ZImage::from_vec_gray8(3, 2, vec![3,17,1,8,2,25])?;
    let source = ZImage::from_vec_gray8(4, 2, vec![0,3,17,1,0,8,2,25])?;
    let model = MatchModel::train_ncc(&template, None)?;
    let spec = MatchSpec { angle_min: 0.0, angle_max: 0.0, angle_step: 1.0,
        scale_min: 1.0, scale_max: 1.0, scale_step: 1.0,
        min_score: 0.99, min_distance: 0.0, max_matches: 1 };
    let result = model.find(&source, &spec)?;
    if let Some(m) = result.best() { println!("({}, {}): {}", m.position.x, m.position.y, m.score); }
    Ok(())
}

적용 상황과 원리

이 코드는 행 우선 바이트를 각각 3×2와 4×2 Gray8 영상으로 만듭니다. 각 검색 행의 첫 픽셀을 건너뛰면 모델과 같은 세 값이 나타나므로 동일 패턴의 왼쪽 위는 1,0입니다. 기준점은 템플릿의 기하학적 중심인 1,0.5이므로 검색 좌표는 2,0.5가 됩니다. 기본 원점이 0,0인 이 영상에서는 전역 좌표도 같습니다.

결과를 읽는 방법

각도 0과 배율 1을 단일 격자점으로 고정했기 때문에 회전이나 배율 복원 능력은 이 사례의 검증 대상이 아닙니다. 동일한 여섯 표본에서 상관은 1에 가깝고 모델 정보의 표본 수는 6입니다. best가 Some인지 확인하고 그다음 위치와 점수를 읽어야 합니다. 점수는 부동소수점 허용 오차를 두고 비교하며 빈 후보가 오류가 아니라 None이라는 점도 별도 사례로 점검합니다.

추가 점검

이 기준점은 프로그램이 출력한 값을 근거로 역산한 것이 아니라 배열과 템플릿 크기에서 직접 계산한 기대값입니다. 따라서 좌상단을 중심으로 잘못 해석하는 오류를 찾아내는 데에도 사용합니다.

모델 폭이 3이므로 기준점 x는 1이고 높이 2의 기준점 y는 0.5입니다. 이 소수 좌표를 정수로 먼저 잘라내면 실제 반환점의 y가 달라집니다. 위치 계산은 템플릿의 좌상단과 기준점 변환을 분리해 수행하세요.

수작업 좌표 검산

조건확인할 내용
템플릿 기준점(3−1)/2, (2−1)/2 = (1, 0.5)
패턴 왼쪽 위검색 영상 로컬 (1, 0)
반환 기준점(1, 0) + (1, 0.5) = (2, 0.5)
