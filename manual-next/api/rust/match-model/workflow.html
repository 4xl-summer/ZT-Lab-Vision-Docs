학습하고 검색하기 · Rust MatchModel

학습하고 검색하기에 대한 Rust MatchModel 사용 안내

상위 목차로 돌아가기

학습하고 검색하기

모델은 소유 값이며 find(&image, &spec)가 반환하는 결과는 독립 읽기 전용 스냅샷입니다. Rust Query 체인은 값을 이동시킬 수 있습니다.

적용 상황과 원리

Rust의 MatchModel::train_ncc는 템플릿 영상과 선택 마스크를 빌려 모델을 만듭니다. 학습된 모델은 자체 상태를 소유하므로 이후 다른 영상들에 find를 반복 적용할 수 있습니다. find에는 검색 영상과 MatchSpec을 참조로 넘기고 오류 가능성을 Result로 처리합니다. 성공한 MatchResult에서 best가 None인 경우는 조건을 통과한 후보가 없다는 뜻입니다.

결과를 읽는 방법

검색 결과의 matches는 읽기 전용 슬라이스이고 개별 결과도 불변으로 읽습니다. 결과는 입력과 모델의 수명에 종속되지 않는 스냅샷이므로 이미 얻은 값을 나중에 보관할 수 있습니다. 이 직접 검색 경로와 달리 Rust의 지연 Query 체인은 값을 이동시킬 수 있으므로 사용 중인 값을 재사용하려면 소유권을 확인해야 합니다. 형식 오류와 정상 미검출을 구분한 뒤에만 검사 판정을 내립니다.

추가 점검

기준 패턴이 충분히 변하는지 학습 전에 확인하면 상수 모델 오류를 줄일 수 있습니다. 검색 후 모델 정보의 표본 수와 반환 매치의 표본 수가 기대한 선택 영역에 맞는지도 진단합니다. 이 값은 물체 수가 아니라 점수 계산에 쓰인 템플릿 표본 수입니다.
