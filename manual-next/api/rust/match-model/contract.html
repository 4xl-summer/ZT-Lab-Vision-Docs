입력, 좌표와 소유권 · Rust MatchModel

입력, 좌표와 소유권에 대한 Rust MatchModel 사용 안내

상위 목차로 돌아가기

입력, 좌표와 소유권

학습과 검색은 Gray8, Gray16, 유한한 GrayF32의 보이는 ROI를 사용합니다. 학습 마스크는 선택 사항이며 Gray8, 템플릿과 같은 크기 및 원점이어야 합니다. 0은 제외, 0이 아닌 값은 포함입니다. 선택된 픽셀은 두 개 이상이고 같은 값만 있어서는 안 됩니다. 모델은 픽셀과 마스크를 복사하므로 학습 후 템플릿을 해제해도 됩니다.

기준점은 템플릿 로컬 ((width−1)/2, (height−1)/2)입니다. 검색 결과의 위치는 검색 ROI 로컬 기준점이고 전역 위치는 여기에 검색 영상 원점을 더한 값입니다. 변환된 템플릿의 네 모서리 전체가 ROI 안에 있어야 평가합니다. 마스크로 모서리를 제외해도 이 조건은 변하지 않습니다. 회전과 배율에 따라 영상은 쌍선형 보간됩니다.

적용 상황과 원리

Rust 영상의 보이는 ROI가 학습 또는 검색의 기준 영역입니다. 템플릿 마스크를 사용하면 같은 크기와 원점의 Gray8 마스크에서 0이 아닌 위치를 선택합니다. 모델은 값을 복사하므로 학습 직후 템플릿을 폐기해도 모델은 유효합니다. 다만 find 호출에 넘기는 검색 영상과 모델 참조는 호출이 끝날 때까지 유효해야 합니다.

결과를 읽는 방법

폭 w와 높이 h인 템플릿의 기준점은 각각 (w−1)/2와 (h−1)/2입니다. 예를 들어 폭 4는 중심 x가 1.5이므로 반환점이 반 픽셀을 가질 수 있습니다. Position은 검색 ROI 로컬 값이며 GlobalPosition은 검색 영상 원점을 더한 값입니다. 회전·배율이 적용된 템플릿 사각형의 네 모서리는 보이는 영역 안에 있어야 하고 마스크는 이 기하 조건을 바꾸지 않습니다.

추가 점검

검색 이미지가 20,30 원점을 가진 ROI이고 로컬 기준점이 2,0.5라면 전역 위치는 22,30.5입니다. 템플릿 마스크의 원점 검사는 이 검색 ROI의 좌표 변환과 다른 단계입니다. 두 원점의 용도를 각각 기록해야 합니다. 마스크 없이 학습하면 보이는 템플릿의 모든 픽셀이 선택 대상입니다. 유한하지 않은 회색 실수 픽셀은 허용되지 않습니다.
