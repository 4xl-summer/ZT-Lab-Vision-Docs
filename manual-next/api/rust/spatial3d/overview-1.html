개념과 사용 흐름

DepthMap::new는 결측 포함 깊이 격자를 소유하며 to_point_cloud가 점군 변환을 수행합니다. PointCloud::new는 포인트, unit, frame을 보존합니다.

Rust의 DepthMap은 크기와 행 우선 Option<f64> 값, 두 방향 간격, 원점, 길이 단위, frame을 함께 가진 소유 객체입니다. 값 하나가 None이면 해당 위치에는 측정이 없다는 뜻입니다. 0.0은 유한한 높이이므로 유효한 샘플로 남습니다. 생성 시 width와 height는 양수이고 values의 길이는 곱과 일치해야 합니다. 간격은 유한 양수, 원점과 Some 안의 값은 유한수, frame은 0이 아니어야 합니다.

격자에서 공간 점이 필요하면 to_point_cloud로 각 슬롯을 직교 좌표로 변환합니다. 이미 좌표가 있는 경우에는 PointCloud::new로 Option<Point3>의 순서를 보존하여 직접 만들 수 있습니다. 각 호출은 Result이므로 오류를 먼저 처리한 뒤 결과를 사용하고, 빈 슬롯을 무조건 원점으로 바꾸지 않습니다. 소유 객체가 범위를 벗어나면 Rust의 수명 규칙에 따라 해제되며 공유 객체는 독립적으로 저장소를 참조합니다.

값 배열에서 공간점까지

DepthMap::new의 값은 행 우선 Option<f64>입니다. 폭 2, 높이 2의 [Some(1),None,Some(3),Some(4)]에는 전체 네 슬롯과 세 유효 높이가 있습니다. 원점 (10,20,30), 간격 (2,3)이라면 셀 (0,1)의 높이 3은 직교점 (10,23,33)이 됩니다. None은 측정이 없는 슬롯이지만 Some(0)은 원점 Z 높이의 유효점입니다.

직접 얻은 3D 좌표는 PointCloud::new의 Option<Point3> 목록으로 입력합니다. 이 경우 Point3는 이미 점 좌표이므로 깊이 격자의 Z 원점을 추가하는 단계를 거치지 않습니다. 두 경로 모두 길이 단위와 0이 아닌 frame이 필요합니다. 생성이나 변환이 반환하는 Result를 검사하고, 공유 객체와 새 저장소의 수명을 Rust 소유 관계로 관리합니다.
