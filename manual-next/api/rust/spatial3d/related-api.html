관련 API

깊이 격자를 준비할 때는 new로 값의 개수와 좌표 단위를 결합하고 values로 현재 보이는 샘플을 확인합니다. 공간 좌표가 필요하면 to_point_cloud가 행 우선 슬롯을 유지하면서 유효 높이를 점으로 바꿉니다. roi와 share는 저장소를 공유하지만 새 객체로 수명 관리되며, roi는 위치에 맞게 원점을 이동합니다. 격자를 통과하지 않는 측정점은 PointCloud::new에서 직접 표현할 수 있습니다.

형상 질의를 고를 때는 먼저 필요한 출력이 법선인지, 평면 또는 원통인지, 다른 점군과의 정합인지를 구분합니다. 법선은 슬롯마다 None이 가능하고 피팅은 합의점과 잔차를 반환합니다. ICP는 초기 frame 변환과 대응 조건이 필요한 별도 절차입니다. 원본 단위와 frame, 결과를 평가할 공차를 함께 기록해야 서로 다른 좌표계나 다른 처리 단계의 결과를 잘못 비교하지 않습니다.

반환 유형으로 선택

깊이 격자의 현재 값을 읽는 values는 행 우선 복사이고 roi는 부분 저장소를 공유하는 다른 격자입니다. 이후 to_point_cloud를 쓰면 각 셀의 직교 공간점을 얻습니다. 예를 들어 원점 Z가 30이고 유효 높이가 4이면 Z=34이며 결측 높이는 None 슬롯을 유지합니다. 단위와 frame은 점 좌표 및 후속 거리 기준의 의미를 정합니다.

점군에서 fit_plane은 평면 값과 잔차를, estimate_normals는 슬롯별 선택 법선을 제공합니다. register_icp는 목표와 초기 변환을 받아 정합 결과를 반환합니다. 각 호출의 반환은 동일한 의미의 성공값이 아니므로 Result 오류, 법선 None, 합의점 통계, 수렴 여부를 각각 확인해야 합니다. 값의 저장소 공유와 새로운 결과의 소유 관계도 Rust 수명에 맞게 다룹니다.
