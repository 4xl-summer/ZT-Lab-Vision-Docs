격자·좌표·결측 계약

직교 격자의 셀 (x,y)에 값 h가 있으면 점은 (origin.x + x·spacing_x, origin.y + y·spacing_y, origin.z + h)입니다. 좌표와 h는 지정한 길이 단위를 사용하고 frame은 좌표계 식별자입니다. None은 결측이며 수치 0과 다릅니다. 각 슬롯의 순서를 유지하여 점군으로 변환합니다.

너비와 높이는 양수, 값 개수는 너비×높이, spacing은 유한한 양수, origin과 유효 높이는 유한수, frame은 0이 아니어야 합니다. ROI 좌표는 현재 맵 기준이고 저장소를 공유합니다. ROI의 원점은 x와 y 방향으로 각각 ROI 시작 좌표×spacing만큼 이동하며 z 원점은 유지됩니다. 유닛과 frame을 함께 기록하세요.

median(kernel, min_valid)과 fill_holes(kernel, min_valid)의 커널은 양의 홀수이고 유효 이웃 최소 수는 1부터 kernel²까지입니다. 경계에서는 이웃을 잘라냅니다. median은 결측 중심을 그대로 두고, fill_holes는 원본의 유효 이웃으로 결측 중심만 채웁니다. 유효 이웃이 부족하면 결측입니다.

점 생성식의 x와 y는 현재 격자의 로컬 인덱스입니다. ROI를 잘라낸 경우 그 ROI는 원본 저장소를 공유하지만 물리 원점은 시작 셀만큼 이동합니다. 원점 (10,20,30)에서 X 간격 2를 사용해 오른쪽 열을 선택하면 새 로컬 (0,0)의 X는 12입니다. 높이가 결측인 곳에는 점을 생성하지 않고 슬롯을 보존하므로, 행 우선 배열을 원래 측정 위치와 다시 대응할 수 있습니다.

median과 fill_holes를 같은 연산으로 취급하지 않습니다. 유효한 중심에 대해 median은 유효 이웃을 모아 정렬하고 짝수 개일 때 가운데 두 값의 평균을 씁니다. 결측 중심은 그대로 남습니다. fill_holes는 결측 중심만 바꾸고 같은 실행에서 새로 채운 값을 다른 결측의 이웃으로 사용하지 않습니다. 경계에서는 창이 잘리므로 충분한 유효 이웃이 없다면 출력은 결측일 수 있습니다.

중첩 선택의 원점

원본 원점이 (10,20,30), 간격이 (2,3)이고 첫 ROI가 (1,0)에서 시작하면 첫 ROI 원점은 (12,20,30)입니다. 그 ROI에서 다시 (1,1)을 선택하면 두 번째 ROI의 원점은 (14,23,30)입니다. 두 번째 시작 위치는 첫 ROI의 로컬 셀로 해석하므로 원본 좌표를 다시 그대로 적용하면 원하는 영역과 달라집니다.

두 번째 ROI 로컬 (0,0)의 높이가 Some(6)이면 직교 점은 (14,23,36)입니다. 같은 위치가 None이면 점군 슬롯도 None이고 Some(0)이면 (14,23,30)의 유효 점입니다. 원점과 간격이 자료의 물리 의미를 정하므로 값 배열만 비교하지 않습니다. roi와 share는 불변 저장소를 공유하지만 각 객체의 소유 기간은 별개이며, 오류가 발생한 Result를 먼저 처리합니다.
