오류·주의사항

PointCloud::fit_plane, fit_cylinder, register_icp는 결과를 반환하며 share와 clone_deep은 메모리 소유 계약이 다릅니다.

공유와 복사는 코드의 소유 관계를 판단하는 기준입니다. share는 같은 불변 저장소를 참조하는 새 객체를 만들고 clone_deep은 점의 별도 저장소를 할당합니다. 한 객체를 drop했다고 다른 공유 객체까지 즉시 사용할 수 없게 되는 것은 아닙니다. 다만 별도 객체가 존재한다는 사실만으로 외부 동시성이나 임의의 수정 가능성을 추론해서는 안 됩니다.

계산 자체는 잘못된 입력에 Result 오류를 반환할 수 있습니다. 평면은 충분한 유효점이 있어야 하며 퇴화된 배치는 해결 가능한 형상을 주지 못합니다. 원통은 부분 호가 짧거나 축 방향 표본이 부족할 때 거절될 수 있습니다. 정합은 두 점군의 단위 및 초기 변환의 frame이 맞아야 합니다. 실패와 결측 법선, 성공했지만 수렴하지 않은 결과는 다른 상태이므로 한 가지 성공 불리언으로 합치지 말고 반환값을 구분합니다.

공유와 오류의 차이

PointCloud::share는 같은 불변 점 저장소를 참조하는 다른 객체이고 clone_deep은 점 목록을 별도로 할당합니다. 한 공유 객체를 drop한 뒤에도 남은 공유 객체는 자기 참조를 통해 저장소를 보유합니다. 반면 복사된 배열을 변경하는 것과 공유 점군을 수정하는 것은 같은 일이 아닙니다. 처리의 반환이 공유인지 독립 소유인지 확인한 뒤 필요한 범위를 정합니다.

fit_plane과 fit_cylinder는 유효점 수가 충분하지 않거나 기하가 퇴화하면 오류가 날 수 있습니다. ICP는 원본과 목표에 각각 최소 세 유효점이 필요하고 초기 변환의 frame과 단위가 맞아야 합니다. 법선 목록의 None은 특정 슬롯의 방향을 구하지 못한 결과이므로 잘못된 인자에 대한 Result 오류와 다릅니다. 각 분기에서 입력 개수와 설정을 기록하면 문제를 좁힐 수 있습니다.
