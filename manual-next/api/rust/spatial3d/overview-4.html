검증 기준 · Rust · Spatial3D

DepthMap과 PointCloud의 생성·공유·기하 피팅 API.

상위 목차로 돌아가기

검증 기준

LengthUnit, frame 및 결과 유효성·정합 잔차를 평가하세요.

관련 설명 열기

입력의 단위와 frame을 검증 기록의 일부로 삼습니다. 숫자 배열만 같더라도 한 자료가 밀리미터이고 다른 자료가 다른 단위라면 거리 임계값의 의미가 달라집니다. 점군 변환이나 ICP 전에는 변환의 from_frame과 원본 frame, to_frame과 목표 frame이 맞는지 확인합니다. 초기 위치가 달라지면 가장 가까운 대응점도 달라질 수 있으므로 초기 변환도 결과 옆에 남깁니다.

격자 검사는 예측 가능한 합성값으로 시작합니다. 원점 (10,20,30), 간격 (2,3), 높이 4인 오른쪽 둘째 행의 점은 (12,23,34)입니다. ROI로 오른쪽 열을 선택하면 ROI 원점은 (12,20,30)이며 같은 점을 다시 계산해야 합니다. 피팅 결과는 inliers, total, RMS, 최대 잔차를 함께 평가하고, 합성 예의 통과를 현장 센서 정확도와 분리합니다.

수치 검증을 분리하기

원점 (10,20,30), 간격 (2,3)에서 셀 (1,1)의 높이가 4라면 직교 점은 (12,23,34)입니다. 이 예상값은 입력 메타데이터와 식으로 미리 계산할 수 있습니다. ROI를 통해 같은 원본 셀을 읽을 때는 변경된 ROI 원점과 로컬 인덱스를 사용해 동일한 점이 되는지도 비교합니다. None인 셀은 유효 높이 0과 따로 셉니다.

형상 피팅 결과의 RMS와 독립 변환 평가의 거리는 같은 표에 있더라도 계산 대상이 다릅니다. 평면의 잔차는 선택된 합의점과 모델 사이의 거리이고, 보류점 오차는 학습에 사용하지 않은 대응점 사이의 거리입니다. 각각의 단위와 입력 수, 임계값을 보관하고 실제 센서에 대한 허용오차를 별도로 설정합니다. 합성 값이 통과했다는 사실만으로 실장비의 정확도를 확정하지 않습니다.
