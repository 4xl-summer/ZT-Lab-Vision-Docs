정확한 공개 시그니처

C#
namespace ZVision;
public BlobAnalysisResult FindBlobs(uint connectivity = 8);

결과는 BlobAnalysisResult 값 스냅샷입니다. 원본 이미지와 별도로 네이티브 Result 핸들을 계속 유지하지 않으므로 반환 결과에 Dispose()는 필요하지 않습니다.

정확한 공개 시그니처 · 핵심 동작

FindBlobs는 한 장의 Gray8 마스크에서 연결된 전경을 객체 목록으로 바꾸는 직접 호출입니다. 인자 connectivity를 생략하면 8이므로 대각선으로 닿은 두 픽셀이 한 영역이 될 수 있습니다. 네 방향 접촉만 하나로 볼 검사라면 4를 명시해야 합니다. 숫자는 밝기 임계값이나 최소 면적이 아니라 연결 방법입니다. 호출하기 전에 원본이 원하는 대상에 대해 비영 마스크인지 확인하십시오.

정확한 공개 시그니처 · 입력과 결과

반환된 BlobAnalysisResult는 면적과 경계, 중심을 담은 관리형 값 스냅샷입니다. 영상은 네이티브 자원을 소유하므로 사용 후 해제하고, 반환된 목록에는 별도의 Dispose가 필요하지 않습니다. 예를 들어 [0,5,5]에서는 0만 배경이고 5 두 개가 한 성분이므로 4연결에서도 개수 1, 면적 2가 됩니다. 목록이 비어 있는 상황은 입력이 유효할 때 전경이 없는 정상 결과일 수 있습니다.

정확한 공개 시그니처 · 좌표와 소유권

입력이 회색 원본이라도 0이 아닌 배경이 남으면 예상보다 큰 성분으로 합쳐집니다. 그 경우 연결성만 바꾸기보다 임계값 마스크를 먼저 살펴보십시오. 잘못된 연결값이나 해제된 영상은 실패하므로 결과 개수 0과 예외를 같은 불량 판정으로 처리하지 않습니다.
