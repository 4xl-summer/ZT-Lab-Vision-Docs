연결, 면적과 좌표

전경은 0이 아닌 픽셀입니다. 면적은 픽셀 셀의 개수이고 무게중심은 각 전경 픽셀 좌표의 산술 평균 (Σx/N, Σy/N)입니다. 대각 두 점의 면적은 8연결에서 2, 중심은 (0.5,0.5)입니다.

선택해석
4연결상하좌우 이웃만 이어짐
8연결대각 이웃도 이어짐
면적 필터경계 포함; 단위는 픽셀 수
ROI결과 좌표계와 상위 원점의 관계를 확인하고 합산; 고급 BlobResult는 부모 원점을 보관하지 않음
영역 없음빈 결과는 성공 가능한 검사 결과

픽셀 면적과 윤곽 다각형 면적은 다른 측정량입니다. 교정된 면적은 픽셀 크기 또는 변환에 따라 별도로 계산합니다. 대각 접촉과 경계 절단 객체는 검출 기준을 정해 테스트하십시오.

연결, 면적과 좌표 · 핵심 동작

면적과 중심을 산출하기 전에 연결 규칙이 객체의 정체를 결정합니다. 그림처럼 대각 두 점만 있는 2×2 마스크는 4연결에서 면적 1인 객체 두 개이고, 8연결에서는 면적 2인 객체 하나입니다. 하나로 연결했을 때 평균 중심은 (0.5,0.5)입니다. 두 결과는 계산 실수가 아니라 서로 다른 이웃 정의의 결과입니다.

연결, 면적과 좌표 · 입력과 결과

각 픽셀을 단위 면적의 셀로 세므로 두 픽셀은 면적 2입니다. 외접 사각형은 x와 y의 최소·최대를 포함하도록 계산하며 오른쪽과 아래는 제외하는 경계로 표현합니다. 중심은 사각형 중심이 아니라 성분에 속한 픽셀 좌표를 각각 더해 픽셀 수로 나눈 값입니다. 불규칙한 물체에서는 두 중심이 달라질 수 있습니다.

연결, 면적과 좌표 · 좌표와 소유권

이 좌표는 사용한 마스크의 로컬 좌표입니다. ROI가 원본의 (100,40)에서 시작한다면 로컬 (0.5,0.5)는 원본의 (100.5,40.5)에 대응합니다. 다만 이미 전역으로 변환한 위치에 원점을 다시 더하지 않도록 호출 경로를 확인하십시오. 면적에 교정 배율을 적용하는 단계도 별도로 관리합니다.
