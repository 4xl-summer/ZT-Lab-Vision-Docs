입력과 실패 · C# · ZImage.FindBlobs

입력과 실패의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

입력과 실패

  • Gray8의 0이 아닌 값을 전경으로 취급합니다.
  • 4/8 외의 연결성, 잘못된 픽셀 형식, 해제된 이미지 사용은 실패합니다.
  • ROI 로컬 좌표 결과를 그대로 이미지 전체 좌표라고 해석하지 않습니다.

원리와 연결성 · Blob 검사 예제

입력과 실패 · 핵심 동작

직접 Blob 분석은 Gray8 마스크의 비영 픽셀을 전경으로 묶습니다. 입력이 Gray16이나 색상 영상이면 직접 연결 성분 호출의 계약과 다르므로 먼저 적절한 회색 변환과 이진 분할을 선택해야 합니다. Gray8이라고 해서 값이 0 또는 255일 필요는 없지만, 작은 양의 배경 잡음도 전경으로 묶인다는 점에 주의하십시오. 마스크를 화면에 표시할 때 검은색·흰색만 보는 것보다 실제 픽셀 값 확인이 도움이 됩니다.

입력과 실패 · 입력과 결과

연결성은 4 또는 8입니다. 0이나 임의의 값은 빈 결과를 의미하지 않고 잘못된 인자로 실패합니다. 이미 Dispose한 영상으로 호출한 경우에도 성분이 없다는 뜻이 아닙니다. 예외는 설정 오류나 수명 문제로 구분해 처리하고, 정상 빈 목록만 검출 대상이 없다는 결과로 해석하십시오.

입력과 실패 · 좌표와 소유권

ROI는 독립된 처리 영역입니다. 경계 밖에 원본 픽셀이 존재해도 ROI 바깥 전경과 연결해 주지 않으며, ROI 가장자리에 걸친 물체는 잘린 면적으로 나타납니다. 관심 영역의 원점과 크기를 저장하고, 경계에 접한 객체를 판정에 포함할지 별도로 정해야 합니다.

ROI 안의 물체가 영상 경계에서 잘리면 반환 면적은 보이는 전경 픽셀만 나타냅니다. 화면 밖의 부분을 추정한 값이 아니므로 경계 접촉 객체를 정상 객체와 같은 크기 기준으로 판정할지 별도 정책이 필요합니다. 관심 영역이 바뀌면 같은 물체도 다른 위치와 면적으로 측정될 수 있습니다.
