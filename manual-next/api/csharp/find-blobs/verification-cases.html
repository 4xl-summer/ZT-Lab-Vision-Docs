관련 검증 사례 · 핵심 동작

연결 성분의 기본 검증은 입력 마스크와 연결 규칙, 기대 객체 수를 한 묶음으로 기록하는 것부터 시작합니다. 대각 두 픽셀 사례에서는 4연결 2개와 8연결 1개가 분리 기준을 직접 검증합니다. 이어서 8연결 결과의 면적 2와 중심 (0.5,0.5)를 확인하면 성분 수는 맞지만 측정 필드가 잘못된 경우도 구분할 수 있습니다.

관련 검증 사례 · 입력과 결과

경계 사례로 모두 0인 영상은 성공한 빈 목록이어야 하고, 0이 아닌 값 하나는 면적 1인 객체가 되어야 합니다. 잘못된 연결성은 빈 목록이 아닌 오류입니다. 이러한 결과를 한 가지 불량으로 합치지 않으면 설정 실패를 검출 실패로 오인하지 않습니다. ROI를 사용하는 경우에는 로컬 좌표를 원점과 함께 기록하여 전체 영상의 위치와 비교합니다.

관련 검증 사례 · 좌표와 소유권

실행 기록에서 사례 ID와 언어, SDK 버전을 함께 확인하십시오. 합성 입력에 대한 검증은 정의된 수치의 재현을 보여 주며 실제 촬영 영상의 정확도나 처리 시간을 입증하지 않습니다. 특히 모서리 잘림과 조명 변화는 별도의 평가 입력이 필요합니다.

비교할 때는 성분의 나열 순서가 아니라 각 성분의 면적과 위치를 함께 확인한다. 대각선의 두 점이 하나로 합쳐지는 경우와 두 성분으로 남는 경우를 같은 입력으로 대비하면 연결 조건의 효과가 분명해진다.

대각선 픽셀의 결과를 점검할 때 성분 목록의 순번에 의존하지 말고 각 성분의 면적과 위치를 비교합니다. 네 방향 연결에서 각각 면적 1인 두 후보가 생기고 여덟 방향 연결에서는 면적 2인 하나의 후보가 됩니다. 같은 입력으로 설정만 바꾸면 임계 처리와 연결 처리 중 어느 단계가 차이를 냈는지 구별하기 쉽습니다.

연결대각선 두 점의 기대 판독
4연결두 성분, 각 면적 1
8연결한 성분, 면적 2, 중심 (0.5, 0.5)
좌표두 점의 위치와 ROI 기준을 함께 확인
