관련 API · 핵심 동작

연결 성분을 얻는 가장 짧은 경로는 Gray8 마스크에서 FindBlobs를 호출하고 반환된 BlobAnalysisResult.Blobs를 읽는 것입니다. 원본 밝기에서 시작한다면 먼저 Threshold로 0/255 마스크를 만들 수 있습니다. 밝은 값이 전경인지 어두운 값이 전경인지에 따라 원하는 분할 방향이 달라지므로 출력 픽셀부터 확인합니다.

관련 API · 입력과 결과

잡음이나 작은 틈이 문제라면 이진 형태학의 열기·닫기를 검토할 수 있습니다. 이 단계는 영역의 경계와 면적을 바꾸므로 원본 마스크와 처리 후 목록을 함께 비교해야 합니다. 커널 인자 3은 3회 반복이 아니라 3×3 정사각형의 폭입니다. 작은 결함이 구조 요소보다 얇으면 제거될 수도 있습니다.

관련 API · 좌표와 소유권

각 Blob의 면적과 경계는 픽셀 좌표에 대한 값입니다. ROI 원점을 이용한 위치 환산과 물리 단위 교정은 후속 단계입니다. C#의 영상과 변환 마스크는 using으로 해제하고, 직접 반환된 Blob 값 스냅샷의 수명은 입력 영상과 구분해 다루십시오.

이진 마스크를 만든 뒤 연결 성분을 구하고, 반환된 영역의 크기와 위치로 판정을 구성한다. 각 단계의 입력과 출력 형식을 확인하면 임계 처리의 결과와 색상 원본을 혼동하는 오류를 줄일 수 있다.

원본 그레이 영상에서 원하는 물체가 밝은지 어두운지도 확인한다. 전경이 반대로 선택되면 배경이 큰 성분 하나로 나타날 수 있다.

마스크를 만들고 성분을 측정하는 순서는 결과 판독의 출발점입니다. 형태학으로 두 물체 사이의 작은 틈이 메워지면 이후 블롭 분석에서는 하나의 성분이 될 수 있습니다. 따라서 물체 수가 달라졌다면 원본, 이진 마스크, 형태학 결과를 각각 보고 연결 조건과 면적 필터를 확인합니다.
