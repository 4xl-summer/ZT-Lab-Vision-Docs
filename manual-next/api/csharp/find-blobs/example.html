사용 예제 · C# · ZImage.FindBlobs

사용 예제의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

사용 예제

C#
using ZVision;

using var image = ZImage.FromGray8(3, 1, new byte[] { 0, 5, 5 });
BlobAnalysisResult result = image.FindBlobs(4);
System.Diagnostics.Debug.Assert(result.Blobs.Count == 1);
System.Diagnostics.Debug.Assert(result.Blobs[0].Area == 2);

사용 예제 · 핵심 동작

이 예제의 입력은 [0,5,5]로, 5는 255가 아니어도 전경입니다. 왼쪽 배경을 제외한 두 픽셀이 가로로 인접하므로 연결성 4에서 결과는 한 개이며 면적은 2입니다. 이 수치는 물리 단위가 아니라 픽셀 개수입니다. 시작 위치는 로컬 x=1이고 두 전경 중심의 평균 x는 1.5이므로, 정수 경계와 실수 중심을 혼동하지 않는 것이 중요합니다.

사용 예제 · 입력과 결과

using으로 입력 이미지를 감싸 네이티브 핸들의 종료 시점을 명시합니다. 직접 호출의 결과는 값 스냅샷이므로 이미지가 해제된 이후에도 반환된 필드 값을 읽을 수 있습니다. 반면 이미 해제한 입력에 다시 FindBlobs를 호출하는 것은 허용되지 않습니다. 디버그 단언은 개발 환경에서 기대값을 비교하는 예이며, 프로그램이 장비에서 검출 성능을 보장한다는 뜻은 아닙니다.

사용 예제 · 좌표와 소유권

입력을 [0,0,0]으로 바꾸면 객체가 없는 정상 빈 목록을 기대할 수 있습니다. [5,0,5]는 가로로 떨어져 있어 4와 8 어느 쪽에서도 두 개입니다. 실제 영상과 비교할 때는 먼저 마스크의 0과 비영 픽셀을 확인한 후 연결 조건을 변경하십시오.

작은 입력을 눈으로 그려 각 전경 픽셀의 위치를 기록해 보자. 반환된 면적과 중심이 맞지 않으면 결과 순서에 의존하기 전에 입력의 행 순서와 전경 값부터 비교하는 것이 진단에 도움이 된다.
