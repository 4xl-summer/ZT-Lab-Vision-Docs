실행 사례와 검증 범위 · 핵심 동작

이 표의 합성 사례는 연결성의 효과를 분리해 확인하기 위한 것입니다. 대각선에 전경 두 개가 있는 2×2 마스크라면 4연결은 두 성분, 8연결은 한 성분입니다. 8연결의 성분은 면적 2와 중심 (0.5,0.5)를 갖습니다. 이 비교는 객체 수만 확인하는 경우보다 대각 합침과 좌표 해석을 함께 드러냅니다.

실행 사례와 검증 범위 · 입력과 결과

사례 ID는 실행 기록에서 동일한 입력과 기대값을 찾는 데 사용합니다. Rust와 관리형 예제가 각각 같은 연결 개념을 다루더라도 반환 타입과 자원 해제 방법이 동일하다는 뜻은 아닙니다. C#에서는 입력 영상을 해제하고 값 결과를 읽으며, Rust에서는 계획 실행 결과를 통해 목록을 확인합니다. 실행 상태는 개별 기록을 기준으로 확인해야 합니다.

실행 사례와 검증 범위 · 좌표와 소유권

이 사례는 영상의 노이즈, 조명, 실제 결함 분포를 포함하지 않습니다. 검사 조건을 정할 때는 대각선 접촉이 의도한 하나의 물체인지부터 정하고, 빈 전경·ROI 경계 절단·작은 입자 사례를 추가하십시오. 합성 결과가 맞더라도 이러한 현장 조건의 성능은 따로 평가해야 합니다.

대각선 두 픽셀 사례는 연결성에 민감하지만 내부 구멍이나 경계 접촉을 모두 대표하지 않는다. 이 사례가 통과해도 실제 검사 이미지의 잡음과 최소 면적 조건은 별도로 확인해야 한다.
