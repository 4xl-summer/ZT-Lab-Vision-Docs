깊이 데이터에서 시작하면 먼저 FromValues로 격자와 물리 메타데이터를 함께 만들고 ToValues로 값과 결측 순서를 확인합니다. 한 부분만 처리할 때 Roi는 현재 격자 기준 사각형을 사용합니다. ROI가 원래 저장소를 공유한다는 사실은 좌표가 그대로라는 뜻은 아닙니다. 새 격자의 원점은 선택한 시작 셀만큼 이동하므로 변환 이후의 점은 이동된 원점을 기준으로 계산됩니다.

직접 좌표 목록이 있는 경우 FromPoints가 점군의 진입점입니다. Point3? 배열의 null은 결측 슬롯이고 나머지는 유한한 좌표여야 합니다. FitPlane은 평면을 추정하고, 반환된 합의점 수와 잔차는 입력의 양과 품질을 해석하는 데 쓰입니다. 격자 복사, 관심 영역, 점군 생성, 피팅은 각각 다른 일을 하므로 결과를 비교할 때 같은 unit과 frame을 기록해야 합니다. 각 핸들은 별도로 해제하고 복사된 배열은 독립 값으로 다룹니다.

API 순서에 따른 좌표

FromValues 직후에는 ToValues로 행 우선 높이의 순서를 확인할 수 있습니다. 이후 Roi(1,0,1,2)를 적용하면 현재 격자의 오른쪽 열을 선택합니다. X 간격 2, 원점 X 10이면 새 ROI 원점 X는 12입니다. ToPointCloud는 이 새 원점을 기준으로 점을 만들기 때문에 원본 기준 x=1 이동을 후속 코드에서 한 번 더 더하지 않아야 합니다.

점 좌표를 이미 가진 자료는 PointCloud.FromPoints로 입력하고, FitPlane에 거리 threshold를 지정할 수 있습니다. 그 threshold와 결과 RMS는 점군의 LengthUnit으로 해석합니다. 평면 모델은 반환된 Normal·Offset과 Inliers·Total을 함께 읽어야 전체 데이터를 얼마나 지지하는지 알 수 있습니다. ToValues와 ToPoints는 복사 배열이며 Roi와 점군은 각각 닫아야 할 소유 핸들입니다.
