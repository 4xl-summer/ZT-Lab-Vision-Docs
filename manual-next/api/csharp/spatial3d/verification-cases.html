관련 검증 사례

합성 사례 spatial-depth는 격자와 ROI의 원점 이동, 결측 보존 및 점의 Z 계산을 확인합니다. 입력의 원점과 셀 간격을 알고 있으므로 기대 좌표를 API 출력과 독립적으로 계산할 수 있습니다. 값이 다르면 먼저 배열이 행 우선으로 작성됐는지와 ROI가 현재 맵을 기준으로 지정됐는지를 살펴봅니다. 전체 유효점 개수와 각 슬롯의 null 여부도 좌표 숫자와 함께 비교해야 합니다.

spatial-fit은 평면점 25개와 별도의 강체 변환 대응점을 사용하는 사례입니다. 합의점 수와 보류점 오차는 서로 다른 검증 항목입니다. 전자는 피팅 데이터가 평면을 지지하는지를, 후자는 학습에 쓰지 않은 점이 변환된 좌표에 가까운지를 확인합니다. 합성 계산의 허용오차는 수치 비교를 위한 값으로 기록하며, 실제 장비의 정확도나 검사 합격 공차로 그대로 사용하지 않습니다. 특히 보정에 사용한 점과 평가에만 쓰는 점의 역할을 구분해 결과를 기록합니다.

기대값과 수명 비교

spatial-depth의 ROI는 오른쪽 열이므로 첫 점은 null, 두 번째 높이 4의 점은 Z=34입니다. 원점 X=10과 간격 2에서 한 열 이동했으므로 ROI X=12가 됩니다. 이 계산은 코드가 제공한 배열과 별개로 손으로 재현할 수 있어 좌표 계산과 null 보존을 함께 점검합니다. null을 숫자 0으로 대체하면 첫 점이 생겨 이 기대와 달라집니다.

spatial-fit은 별도의 평면과 강체 변환 사례입니다. 25개 합성 평면점의 합의점 수와 보류점 변환 거리의 의미는 서로 다르므로 같은 통계로 묶지 않습니다. 테스트 중 반환된 ROI와 점군은 원본과 별도 핸들이어서 각각 해제하고, 복사 배열은 값으로 유지합니다. 합성 통과는 실측 정확도나 장비 재현성을 보증하지 않으므로 현장의 허용치와 데이터로 따로 평가합니다.
