관련 API

깊이 격자에서 점군으로 가는 작업은 생성, 부분 선택, 공간 변환과 결과 판독으로 나눌 수 있습니다. FromValues는 격자의 치수와 깊이, 간격, 원점, 단위, frame을 한 번에 묶는 시작점입니다. Roi는 그 격자의 일부를 별도 핸들로 표현하고, ToPointCloud는 셀별 위치와 높이를 점 좌표로 만듭니다. ToValues는 계산 결과를 복사해 확인할 때 사용하며 입력 객체를 변경하지 않습니다.

이미 점의 좌표가 있다면 PointCloud.FromPoints로 직접 시작할 수 있습니다. 평면 또는 원통 피팅은 점군의 형상을 요약하고 정합은 한 frame의 점을 다른 frame에 맞추는 별도의 목적을 가집니다. 평면의 합의점 통계와 ICP의 수렴 플래그를 같은 뜻으로 해석하지 마세요. API를 선택한 다음에는 필요한 객체의 소유 범위를 using으로 감싸고, 실패한 단계의 인자와 좌표 메타데이터를 확인합니다.

깊이와 점군의 연결

DepthMap.FromValues는 규칙적인 격자와 상대 높이를 만들고, PointCloud.FromPoints는 이미 존재하는 3D 좌표를 점군으로 만듭니다. 전자의 높이에는 원점 Z를 더해 공간점을 계산하지만 후자의 Point3 좌표에는 추가 원점 보정이 자동으로 필요한 것이 아닙니다. 입력이 어느 형태인지 먼저 정하면 서로 다른 데이터 모델을 혼동하지 않습니다.

부분 높이 격자는 Roi로 선택한 뒤 ToPointCloud로 직교 좌표를 만듭니다. 점군에서 FitPlane은 형상과 잔차를 반환하고 Register 계열은 목표 점군 및 초기 frame 변환으로 정합합니다. 정상적인 null 슬롯은 잘못된 치수나 단위 불일치 오류와 다릅니다. 각 호출의 새 소유 객체는 using으로 관리하고 배열 복사와 값 스냅샷을 구분하여 처리합니다.
