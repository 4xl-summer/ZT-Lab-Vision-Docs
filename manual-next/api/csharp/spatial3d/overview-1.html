개념과 사용 흐름

DepthMap.FromValues(width,height,double?[],spacingX,spacingY,origin,unit,frame)는 결측을 포함한 지도를 생성합니다. PointCloud.FromPoints(Point3?[],unit,frame)는 점군을 생성합니다.

깊이 격자는 영상의 각 셀에 높이를 붙인 자료이고, 점군은 각 슬롯에 세 좌표를 직접 저장하는 자료입니다. 격자를 만들 때는 가로·세로와 행 우선 배열 길이를 맞추고, 셀 간격과 원점이 실제 입력 좌표계에 어떤 의미인지 함께 지정합니다. 값이 없는 위치는 nullable 값으로 표시하므로, 높이가 0인 유효 측정과 빈 측정을 구분할 수 있습니다. 생성이 끝나면 정보에서 유효 개수와 frame을 확인한 뒤 필요한 영역을 선택하고 점군으로 바꿉니다.

예를 들어 2×2 값이 1, 결측, 3, 4이고 원점이 (10,20,30), 간격이 (2,3)이라면 오른쪽 열의 ROI 원점 X는 12입니다. 그 ROI의 두 번째 점 높이는 원점 Z에 4를 더한 34입니다. 점을 이미 갖고 있다면 격자를 거치지 않고 점군을 만들 수 있지만, 단위와 frame을 별도로 지정해야 합니다. 각 생성 객체는 using으로 소유 기간을 명시하고 결과 배열을 꺼낸 뒤에는 객체와 배열의 수명이 다르다는 점을 확인합니다.

두 생성 경로 비교

깊이 격자에는 각 셀의 높이와 규칙적인 XY 배치가 있으므로 FromValues에 폭·높이·간격과 원점을 줍니다. 값 배열이 [1,null,3,4]인 2×2 지도는 4개 슬롯 중 3개가 유효합니다. 원점이 (10,20,30), 간격이 (2,3)이면 셀 (0,1)의 높이 3은 직교 점 (10,23,33)입니다. null 셀은 원점의 점이 아니라 없는 측정입니다.

이미 3D 점의 좌표를 알고 있다면 FromPoints에 Point3? 배열을 전달합니다. 이 경우 각 점은 입력 frame과 unit에서 이미 위치를 갖기 때문에 깊이 높이식으로 Z 원점을 다시 더하면 안 됩니다. 두 경로 모두 0이 아닌 frame과 적절한 단위가 필요하지만 입력의 의미가 다릅니다. 소유 DepthMap과 PointCloud는 using으로 관리하고, 후속 결과의 좌표와 결측을 각각 확인합니다.
