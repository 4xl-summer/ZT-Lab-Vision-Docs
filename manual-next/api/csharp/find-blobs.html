C# · ZImage.FindBlobs

Gray8 이진 영상의 연결 성분을 독립 불변 결과로 만드는 메서드.

소주제별 독립 HTML2026-11-08 소스 확인예제 실행 재검증 대기

정확한 공개 시그니처

C#
namespace ZVision;
public BlobAnalysisResult FindBlobs(uint connectivity = 8);

결과는 BlobAnalysisResult 값 스냅샷입니다. 원본 이미지와 별도로 네이티브 Result 핸들을 계속 유지하지 않으므로 반환 결과에 Dispose()는 필요하지 않습니다.

매개변수와 결과 필드

항목자료형의미
connectivityuint (4 또는 8)연결 방식; 기본값 8
BlobsIReadOnlyList<Blob>연결 성분의 읽기 전용 목록
Blob.Areaulong전경 픽셀 수
Blob.X/YulongROI 지역 좌표 경계 시작
Blob.CentroidX/Ydouble전경 중심 좌표

사용 예제

C#
using ZVision;

using var image = ZImage.FromGray8(3, 1, new byte[] { 0, 5, 5 });
BlobAnalysisResult result = image.FindBlobs(4);
System.Diagnostics.Debug.Assert(result.Blobs.Count == 1);
System.Diagnostics.Debug.Assert(result.Blobs[0].Area == 2);

입력과 실패

  • Gray8의 0이 아닌 값을 전경으로 취급합니다.
  • 4/8 외의 연결성, 잘못된 픽셀 형식, 해제된 이미지 사용은 실패합니다.
  • ROI 로컬 좌표 결과를 그대로 이미지 전체 좌표라고 해석하지 않습니다.
