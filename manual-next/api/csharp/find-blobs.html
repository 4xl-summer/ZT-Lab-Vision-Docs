C# · ZImage.FindBlobs

Gray8 이진 영상의 연결 성분을 독립 불변 결과로 만드는 메서드.

정확한 공개 시그니처

C#
namespace ZVision;
public BlobAnalysisResult FindBlobs(uint connectivity = 8);

결과는 BlobAnalysisResult 값 스냅샷입니다. 원본 이미지와 별도로 네이티브 Result 핸들을 계속 유지하지 않으므로 반환 결과에 Dispose()는 필요하지 않습니다.

매개변수와 결과 필드

항목자료형의미
connectivityuint (4 또는 8)연결 방식; 기본값 8
BlobsIReadOnlyList<Blob>연결 성분의 읽기 전용 목록
Blob.Areaulong전경 픽셀 수
Blob.X/YulongROI 지역 좌표 경계 시작
Blob.CentroidX/Ydouble전경 중심 좌표

사용 예제

C#
using ZVision;

using var image = ZImage.FromGray8(3, 1, new byte[] { 0, 5, 5 });
BlobAnalysisResult result = image.FindBlobs(4);
System.Diagnostics.Debug.Assert(result.Blobs.Count == 1);
System.Diagnostics.Debug.Assert(result.Blobs[0].Area == 2);

입력과 실패

  • Gray8의 0이 아닌 값을 전경으로 취급합니다.
  • 4/8 외의 연결성, 잘못된 픽셀 형식, 해제된 이미지 사용은 실패합니다.
  • ROI 로컬 좌표 결과를 그대로 이미지 전체 좌표라고 해석하지 않습니다.

원리와 연결성 · Blob 검사 예제

연결, 면적과 좌표

전경은 0이 아닌 픽셀입니다. 면적은 픽셀 셀의 개수이고 무게중심은 각 전경 픽셀 좌표의 산술 평균 (Σx/N, Σy/N)입니다. 대각 두 점의 면적은 8연결에서 2, 중심은 (0.5,0.5)입니다.

선택해석
4연결상하좌우 이웃만 이어짐
8연결대각 이웃도 이어짐
면적 필터경계 포함; 단위는 픽셀 수
ROI결과 좌표계와 상위 원점의 관계를 확인하고 합산; 고급 BlobResult는 부모 원점을 보관하지 않음
영역 없음빈 결과는 성공 가능한 검사 결과

픽셀 면적과 윤곽 다각형 면적은 다른 측정량입니다. 교정된 면적은 픽셀 크기 또는 변환에 따라 별도로 계산합니다. 대각 접촉과 경계 절단 객체는 검출 기준을 정해 테스트하십시오.

결과 필드와 수명

필드·상황의미
area비영 전경 셀 개수, 픽셀 단위
bounds / X,Y,Width,HeightROI 로컬의 최소 외접 사각형. 오른쪽·아래 경계는 제외
centroid / CentroidX,Y정수 픽셀 중심의 평균. 물리 좌표가 아님
순서·빈 결과첫 전경 픽셀을 행 우선으로 발견한 순서; 전경이 없으면 빈 목록
수명Rust Query 단계는 self를 소비하며 execute는 결과 스냅샷을 만듦. C#/Python 직접 FindBlobs 결과는 이미지와 독립된 값
실패비 Gray8, 유효하지 않은 연결성, 크기 오버플로·할당 실패; 입력과 연결 값을 확인
