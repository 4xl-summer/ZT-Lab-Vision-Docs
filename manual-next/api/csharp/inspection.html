정렬, 차분, 결함 및 판정 API

기준 영상과 검사 영상을 같은 좌표로 맞춘 뒤 유효한 표본에서 밝기 차이를 측정합니다. 정렬 실패는 결함 없음이 아니라 검사 불가입니다. 아래 값은 설명을 위한 합성 영상이며 현장 합격 기준이 아닙니다.

InspectionRect 는 영상 로컬의 왼쪽 위와 너비·높이이며 끝 좌표는 제외합니다. 정렬 입력은 Gray8, Gray16, GrayF32이고 혼합 가능합니다. 기준 ROI는 양의 크기로 기준 영상 안에 있어야 하며 NCC 학습 영역에 밝기 변화가 필요합니다. 출력 Aligned 는 기준 격자와 원점의 GrayF64, ValidMask 는 같은 격자의 Gray8입니다. 변환 ReferenceToInspection 은 기준 전역 좌표에서 검사 전역 좌표로 갑니다. 결과와 얻은 영상 각각을 해제하세요.

AlignmentInfo 는 Found, Matched, ReferenceToInspection, ResidualRms, ValidCount를 제공합니다. RMS는 유효 픽셀의 보정 전 밝기 차이이며 위치 오차가 아닙니다. 미발견 시 정보는 기본값이고 영상 접근은 오류입니다. DifferenceInfo 는 Gain, Bias, InspectedCount, MeanScore, MaxScore입니다. SurfaceDefect 는 Kind, Area, Bounds, Centroid, Length, Width, Angle, MeanScore, MaxScore를 담습니다. 각도는 [−π/2, π/2) 라디안입니다. DecisionInfo 는 Passed, Reasons, DefectCount, TotalArea, RejectionCount를 제공하며 개별 DefectRejection 은 Index와 Reasons를 담습니다. 개수·총 면적 위반만으로 개별 기록이 생기는 것은 아닙니다.
