적용 상황과 원리

이 장의 C# 전체 예제는 기록된 Linux x64 환경에서 실행된 코드 블록입니다. 기록에는 프로세스 종료 코드 0이 남아 있지만 이 블록 자체는 단언문 없이 첫 매치가 있을 때 좌표와 점수를 출력합니다. 따라서 실행 성공 기록만으로 출력값을 자동 비교했다고 해석하지 않아야 합니다. 코드의 입력과 기대값을 독립적으로 확인하는 합성 사례와 함께 읽는 것이 좋습니다.

결과를 읽는 방법

별도 ncc-literal 통합 사례는 3×2 템플릿과 4×2 검색 영상에서 기준점 2,0.5와 표본 수 6을 확인하도록 구성되었습니다. 마스크를 주었을 때 선택 표본 4개와 일정 검색 영상의 빈 결과도 검사 범위에 포함됩니다. 점수는 부동소수점이므로 엄격한 문자열 일치보다 허용 오차로 비교합니다. 이 기록은 해당 환경과 합성 입력에 대한 것이며 다른 운영체제, 카메라나 생산 영상의 수용 시험을 뜻하지 않습니다.

추가 점검

검증 환경에는 .NET SDK 10.0.403과 해당 소스 리비전의 네이티브 라이브러리가 사용되었습니다. 같은 형식의 데이터가 다른 환경에서도 자동으로 같은 속도나 시스템 호환성을 가진다는 의미는 아닙니다. 새로운 배포 패키지에서는 경로와 아키텍처를 맞춘 뒤 다시 실행해 확인합니다.
