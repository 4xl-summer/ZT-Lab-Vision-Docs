관련 API

적용 상황과 원리

학습과 검색의 중심 객체는 MatchModel입니다. TrainNcc에 템플릿과 선택 마스크를 전달하면 이후 검색에 사용할 모델을 얻고, Info는 모델 크기와 기준점 및 학습 표본 수를 보여줍니다. 결과를 얻기 전에는 MatchSpec으로 회전·배율 격자, 점수 하한, 중복 억제 거리와 결과 개수를 지정합니다. 모든 값을 호출자가 정하며 유효성은 검색 시 확인됩니다.

결과를 읽는 방법

Find가 반환하는 MatchResult는 네이티브 영상과 모델에서 독립된 읽기 전용 결과입니다. Matches는 선택된 후보 목록이고 Best는 목록의 첫 값 또는 null입니다. 각 Match의 Position과 GlobalPosition은 각각 검색 ROI의 로컬 및 원점을 더한 좌표입니다. 저장한 모델을 다시 쓰려면 Save와 Load를 사용하되 별도의 검색 설정을 함께 관리합니다. 지연 실행을 원하면 ImageQuery.FindMatches의 계획과 실행 수명도 따로 확인하세요.

추가 점검

정보를 읽는 순서는 모델 종류와 크기 확인, 설정의 유효 범위 확인, 검색 실행과 결과 분기입니다. 복원 후에는 파일이 존재한다는 사실만 보지 말고 같은 영상에서 위치와 점수의 기대값을 비교합니다. 프로그램이 영상을 새로 취득하는 단계와 모델 검색은 서로 다른 실패 원인을 가집니다.

검색별도 설정과 영상으로 포즈 후보를 찾습니다.
