정규화 상관으로 포즈 찾기

선택 템플릿 값 T와 후보 패치 I의 평균을 각각 빼고 Σ((T−T̄)(I−Ī)) / √(Σ(T−T̄)² Σ(I−Ī)²)를 계산합니다. 분산이 있는 동일 패턴은 1에 가깝고, 밝기 오프셋과 양의 일정 배율에 둔감합니다. 음의 상관은 음수이지만 기본 검색의 점수 하한은 0 이상이므로 음의 점수는 선택할 수 없습니다. 점수는 확률이 아닙니다. 검색 패치의 분산이 0이면 그 후보는 점수가 없어 건너뜁니다.

적용 상황과 원리

중심을 뺀 각 템플릿 값과 후보 영상 값을 곱한 합을 두 값 집합의 크기로 나누면 밝기 단위가 다른 두 패턴의 구조를 비교할 수 있습니다. 예를 들어 모든 후보 값에 같은 양의 배율과 일정한 오프셋을 적용해도 선택 픽셀의 상대 관계가 유지되면 점수는 같은 방향을 가리킵니다. 따라서 임계값은 물체가 존재할 확률이 아니라 해당 모델에 대한 유사도 경계입니다.

결과를 읽는 방법

같은 템플릿이라도 마스크를 바꾸면 평균과 분모에 들어가는 픽셀이 달라져 점수가 달라집니다. 학습 시에는 선택 픽셀 두 개 이상이 서로 다른 값을 가져야 하며, 검색 시 후보 쪽 값이 모두 같으면 분모를 만들 수 없어 그 후보를 건너뜁니다. 음의 상관도 계산 자체는 가능하지만 기본 설정의 허용 점수는 0 이상이므로 반전된 패턴을 그대로 검출할 수 있다고 가정하지 마세요. 조명 역전이 검사 조건이라면 별도 모델과 데이터로 시험해야 합니다.

추가 점검

마스크가 단 두 값을 남긴 경우에도 두 값이 서로 달라야 학습 조건을 만족합니다. 그러나 최소 조건을 만족한다는 것과 서로 비슷한 부품을 충분히 구별한다는 것은 다릅니다. 선택점을 줄일 때는 잘못된 대상에 대한 점수도 함께 비교해야 합니다. 밝기의 양의 배율이 0에 가까워져 실제 영상이 상수로 양자화되면 이론적 불변성보다 분산 조건이 먼저 문제가 됩니다.
