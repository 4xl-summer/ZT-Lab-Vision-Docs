학습하고 검색하기

모델과 영상은 using 또는 Dispose로 해제합니다. Find는 독립 불변 스냅샷을 반환합니다. 지연 Query는 가변 계획이므로 호출 중 공유 수정하지 마세요.

적용 상황과 원리

학습 단계에서는 영상 한 장을 기준 패턴으로 선택하고 선택적으로 마스크를 전달합니다. 모델이 픽셀을 복사하므로 같은 모델을 여러 검사 영상에 재사용할 수 있습니다. 검색 설정은 별도로 만들고 검색 영상과 함께 Find에 전달합니다. 반환값의 Best는 결과가 없을 때 null이므로 값을 꺼내기 전에 유무를 분기해야 합니다. 모델 학습에 실패한 경우와 정상 검색에서 후보가 없는 경우는 서로 다른 처리 경로입니다.

결과를 읽는 방법

모델과 입력 영상은 네이티브 자원을 보유하므로 사용 범위를 using으로 명확히 합니다. 반면 Find의 MatchResult는 값들을 복사한 읽기 전용 결과이므로 모델이나 영상을 정리한 뒤에도 읽을 수 있습니다. 나중에 지연 계획을 쓰게 되면 계획을 명시적으로 복제하여 독립 분기를 만들고, 하나의 가변 계획을 실행 중 수정하지 않습니다. 좌표는 모델이 아니라 검색 영상의 ROI를 기준으로 해석해야 합니다.

추가 점검

학습에 사용할 템플릿이 거의 균일하면 선택 표본에 유효한 밝기 차이가 없어 모델 생성이 실패합니다. 마스크를 쓴다면 0인 곳과 비제로인 곳의 의미를 먼저 확인하고 모델 정보의 표본 수가 기대한 개수인지 살펴봅니다. 프로그램의 검사 판정은 검색 결과와 입력 오류를 별도로 기록해야 합니다.
