저장과 복원

모델의 save/Save는 버전 1 모델 파일을 쓰고 기존 경로를 덮어씁니다. load/Load는 별도 소유 모델을 만듭니다. 파일이 없거나 손상·지원하지 않는 형식이면 로드 오류를 처리하세요. 검색 설정과 검색 결과는 모델 파일에 포함된다고 가정하지 말고 애플리케이션 설정으로 관리하세요. Rust 저장과 로드는 이미지 I/O 기능이 필요합니다.

적용 상황과 원리

학습은 템플릿과 마스크에서 반복 사용 가능한 모델을 만드는 단계이고 저장은 이 모델을 파일로 기록하는 단계입니다. Save는 같은 경로의 파일을 덮어쓰므로 다른 버전을 유지하려면 호출자가 파일 이름이나 저장 정책을 관리해야 합니다. Load는 파일을 읽어 새 모델을 만들며 원래 모델과 각각 해제할 수 있습니다. 경로가 없거나 접근할 수 없고 내용이 손상되었을 때는 정상적인 빈 검색과 구분해 오류로 처리합니다.

결과를 읽는 방법

저장 후 복원한 모델을 확인할 때는 Info의 크기, 기준점, 표본 수를 비교하고 동일한 검색 영상과 별도로 보관한 MatchSpec을 다시 적용합니다. 점수와 좌표의 허용 오차, 결과 개수, 빈 결과를 함께 기록하면 모델 파일과 설정 파일이 서로 맞는지 판별하기 쉽습니다. 이 형식은 버전 1이며 다른 제품이나 임의의 형식과 호환된다는 의미는 아닙니다. 저장 성공만으로 특정 검사 조건의 성능이 보장되지는 않습니다.

추가 점검

안전한 복원 비교에는 원래 검색 결과만이 아니라 어떤 입력과 설정을 썼는지도 필요합니다. 영상 원점이 다르면 같은 로컬 점의 전역 값이 달라집니다. 파일 선택 실수와 검사 설정 변경을 분리하여 진단할 수 있도록 모델 식별자와 설정을 함께 기록하세요.
