MatchSpec 인자

인자자료형제약
angleMin / angleMax / angleStepdouble회전 범위·격자, 라디안
scaleMin / scaleMax / scaleStepdouble등방 배율 범위·격자
minScoredouble0 이상 1 이하
minDistancedoubleNMS 거리, 비음수 픽셀
maxMatchesulong양수

C# 호출 예제

C#
using ZVision;

// template와 image는 유효한 ZImage라고 가정합니다.
using var model = MatchModel.TrainNcc(template);
var spec = new MatchSpec(
    0, 0, 1, 1, 1, 1, 0.999999, 0, 10);
MatchResult result = model.Find(image, spec);
if (result.Best is Match best)
    System.Console.WriteLine(best.Score);

소유권 및 결과 형태

MatchModel은 네이티브 핸들이 있으므로 using으로 해제합니다. MatchResult는 Match 값의 불변 스냅샷이며 별도 Dispose가 없습니다. Best는 결과가 없으면 null입니다. Match.Position과 Match.GlobalPosition의 차이를 확인하세요.
