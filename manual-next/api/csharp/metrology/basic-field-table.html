기본 프로파일·캘리퍼 필드

필드 / 타입의미 · 단위 · 유효 조건
start, end: Point2ROI 로컬 픽셀 중심; 각 좌표 유한, 두 점 사이 길이 양수이며 전체 스트립은 영상 안에 있어야 함.
samples: usize / Samples: ulong양 끝을 포함한 표본 수 3 이상. 거리 간격 = 선분 길이/(samples−1).
width: usize / Width: ulong법선 방향 샘플 개수; 양의 홀수, 인접 표본 간격 1 픽셀.
profile: ProfileSpec에지 탐색에 사용할 위 설정.
polarity: EdgePolarityRising, Falling, Any 중 하나. 시작→끝 방향 기준.
threshold: f64 / Threshold: double원시 강도/픽셀; 유한한 0 이상. 크기가 정규화된 비율이 아님.

Rust와 C# 모두 여기에 명시된 유효한 기본값을 자동 선택하는 생성자를 가정하지 않습니다. C# 생성자는 값을 저장하며 연산 시 검증합니다. 결과 위치는 ROI 로컬 픽셀, distance는 시작점부터 픽셀, value는 원시 강도 평균, strength는 부호 있는 원시 강도/픽셀입니다.

표의 시작점과 끝점은 서로 독립된 두 좌표지만 함께 하나의 방향을 정의합니다. 방향을 뒤집어도 같은 선분을 지날 수 있으나 거리는 새 시작점에서 다시 증가하며, 상승과 하강의 의미가 바뀝니다. Samples는 선분을 몇 개의 위치로 나눌지, Width는 각 위치에서 수직 방향으로 몇 값을 평균할지를 결정하므로 두 수치를 혼동하지 마십시오.

가령 길이 8픽셀의 선분에서 표본 9개를 요청하면 위치 간격은 8/(9−1)=1픽셀입니다. 폭 3의 경우 각 위치에서 중심과 양쪽 한 칸을 사용합니다. 이 기본 경로는 선분뿐 아니라 전체 띠가 ROI 내부에 있어야 합니다. 결과의 Distance는 픽셀이고 Value는 강도이므로 양쪽 수치를 같은 척도로 비교하지 않습니다.

선분 방향의 간격과 횡단 방향의 간격은 다른 축입니다. 전자는 선분 길이를 표본 수에서 하나 뺀 값으로 나눈 거리이고, 후자는 이 경로에서 한 픽셀입니다. 실제 검사 영역이 세로로 좁다면 수평 선분의 끝만 보지 말고 띠의 위아래 경계가 모두 들어오는지 확인하십시오.
