기본 설정과 실패

ProfileSpec: start/end는 유한한 서로 다른 ROI 로컬 픽셀 중심, samples는 양 끝 포함 3 이상, width는 양의 홀수입니다. CaliperSpec: profile, polarity(Rising/Falling/Any), 유한한 threshold ≥ 0을 지정합니다. 생성 기본값을 가정하지 말고 모든 값을 지정하세요. 기하·포맷·유한성·범위가 잘못되면 오류이며, 조건에 맞는 피크가 없으면 빈 결과입니다. ProfileSample은 position, distance, value, CaliperEdge는 position, distance, signed strength를 제공합니다.

Rust 고급 프로파일은 경계 밖 가로 샘플을 생략하되 위치마다 min_valid_width 이상이 필요합니다. 최근접/이중선형 선택과 유한한 홀수 길이의 합이 0이 아닌 필터를 사용하며 필터는 합으로 정규화되고 끝값을 연장합니다. 기본 경로와 경계 동작이 다릅니다.

C#의 설정은 값으로 구성한 뒤 Profile 또는 Caliper에 전달합니다. 이미지 원본에서 잘라낸 ROI라면 시작점과 끝점은 그 ROI의 왼쪽 위를 기준으로 작성합니다. 두 점이 같거나 표본 수가 둘이면 거리 간격을 올바르게 만들 수 없으므로 호출을 고치고, 폭이 짝수이면 중심을 갖는 대칭 띠로 설정할 수 없어 양의 홀수로 바꿉니다.

예를 들어 너비 1과 표본 9는 중심선에서 양 끝을 포함한 아홉 위치를 뜻합니다. 값은 샘플 위치의 평균 밝기이고 에지 강도는 그 값의 거리당 변화이므로 단위가 다릅니다. Rising으로 결과가 비어 있으면 같은 입력에서 진행 방향과 밝아지는 방향이 맞는지 먼저 확인하십시오. 잘못된 설정의 오류와 유효하지만 에지가 없는 빈 결과는 이후 판정에서 별도로 취급합니다.

적용 순서와 결과 판독

프로파일 선분의 양 끝은 단순한 표시 좌표가 아니라 표본이 놓이는 위치를 결정합니다. 양 끝이 같으면 방향과 법선을 정할 수 없고, 폭이 짝수이면 중심을 기준으로 한 대칭 스트립을 만들 수 없습니다. 예를 들어 폭 3은 중심과 양쪽 한 위치를 평균하므로 영상 가장자리 근처에서는 중심만 영상 안에 있어도 전체 스트립이 벗어날 수 있습니다. 에지를 못 찾았을 때는 빈 목록을 유효한 결과로 기록하고, 인자 검증 오류는 입력 준비 단계로 되돌려 따로 처리하십시오.

확인 단계판독과 조치
서로 다른 끝점선분의 방향과 길이를 정합니다.
양의 홀수 폭중심 양쪽의 표본을 대칭으로 배치합니다.
임계값 이상의 피크 없음호출 성공과 빈 에지 목록을 구별합니다.
스트립이 영상 밖좌표와 폭을 고쳐 호출 조건을 만족시킵니다.
