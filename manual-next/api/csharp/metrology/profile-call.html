C# 호출 부분

아래는 기존 ROI 영상이 최소 11×5 픽셀인 경우의 호출 부분입니다. 실행 가능한 독립 fixture는 예제에서 확인합니다.

C#
// image는 해당 ROI를 가진 기존 ZImage입니다.
var spec = new ProfileSpec(new Point2(2, 4), new Point2(10, 4), 9, 1);
ProfileResult profile = image.Profile(spec);
var edgeSpec = new CaliperSpec(spec, EdgePolarity.Rising, 10.0);
CaliperResult edges = image.Caliper(edgeSpec);
foreach (var sample in profile.Samples)
    Console.WriteLine($"{sample.Distance}: {sample.Value}");
foreach (var edge in edges.Edges)
    Console.WriteLine($"{edge.Position.X}, {edge.Position.Y}: {edge.Strength}");

C# 계측 계약은 소스 ce902e85c340과 대조했습니다. 합성 수치는 손계산 기대값이며 실행 검증은 별도로 표시하고, 실제 장비와 생산 정확도는 검증하지 않았습니다.

이 호출 부분의 image는 호출자가 미리 준비한 영상이며, 예제 함수 내부에서 새 이미지가 생성되는 것은 아닙니다. 시작점 (2,4)와 끝점 (10,4)은 ROI 안의 수평 중심선이고 아홉 표본은 두 끝을 모두 포함합니다. 폭 1이므로 수직 방향 평균은 각 중심의 한 값에 해당합니다. 영상 크기가 작거나 ROI가 다른 경우 좌표를 먼저 그 ROI 기준으로 다시 잡아야 합니다.

먼저 프로파일 목록을 읽어 입력 밝기 변화가 예상대로 나타나는지 확인한 뒤 상승 극성과 10 강도/픽셀 임계값으로 에지를 요청합니다. 같은 설정으로 결과가 빈 목록일 수 있으며 이는 호출 성공과 양립합니다. 결과의 위치·거리·강도는 목록 항목별로 확인하고, 물리 거리로 변환할 때는 ROI 원점을 더한 글로벌 좌표와 보정 단위를 함께 사용하십시오.

이 호출은 영상 생성과 픽셀 입력을 생략하므로 단독 프로그램으로 실행할 수 없습니다. 주변 애플리케이션이 영상과 네임스페이스를 제공해야 합니다. 함수 출력의 부호는 선분 진행 방향에 따른 기울기의 부호입니다.

프로파일 선분이 영상의 오른쪽과 아래 경계 안에 드는지도 확인합니다. 필요한 영상 영역을 호출자가 먼저 준비해야 예시의 고정 좌표가 유효합니다.
