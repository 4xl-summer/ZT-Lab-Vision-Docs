C# 호출과 수명

ZImage.Profile(ProfileSpec)와 ZImage.Caliper(CaliperSpec)는 결과를 반환합니다. 결과 샘플과 에지는 값 스냅샷입니다. 같은 형상의 점 피팅은 Metrology.FitLine, FitCircle, FitEllipse를 사용합니다. 무효 입력은 오류로 구분하고 빈 에지 결과를 오류와 혼동하지 마세요.

즉시 실행 메서드는 현재 영상과 설정을 받아 프로파일 또는 에지 목록을 계산한 뒤 독립 결과 객체를 제공합니다. 결과를 읽을 때 Samples와 Edges를 각각 사용하며, 목록 원소의 위치는 해당 영상 ROI의 로컬 좌표입니다. 영상 처리가 끝난 후에도 얻은 결과 값은 계산 당시의 스냅샷이므로 다른 프레임을 처리했다고 이전 값이 갱신되지는 않습니다.

점 배열이 이미 준비된 경우에는 프로파일 검색을 다시 수행하지 않고 선·원·타원 피팅을 선택할 수 있습니다. 반대로 영상에서 경계를 찾지 못했다면 피팅 임계값을 바꾸기 전에 프로파일 경로와 극성을 조사하는 편이 문제 위치를 분리하는 데 도움이 됩니다. 처리가 실패한 호출에는 결과가 없고, 성공한 빈 에지 목록은 조건을 만족하는 후보가 없다는 결과이므로 같은 0 좌표로 치환하지 않습니다.

즉시 메서드에서 이미 얻은 결과는 해당 프레임의 값으로 남습니다. 다음 프레임을 같은 변수에 할당해도 이전 목록이 새 계산으로 바뀌는 것은 아닙니다. 여러 프레임을 비교한다면 프레임 식별자와 ROI 기준을 결과와 함께 저장하십시오. 입력 영상의 소유 객체를 정리하는 시점과 값 결과를 읽는 시점을 별도로 정하면 불필요한 핸들 보관을 줄일 수 있습니다.

적용 순서와 결과 판독

관리형 결과에서 먼저 확인할 것은 반환 값이 계산 당시의 관측을 나타낸다는 점입니다. 같은 모델을 다른 프레임에 적용해도 이전 프레임의 점과 새 프레임의 점을 섞어 한 형상으로 해석해서는 안 됩니다. 예를 들어 두 프레임에서 같은 프로브 번호가 Found여도 선택된 위치와 잔차는 각각 확인합니다. 결과를 보관할 때 입력 영상의 원점과 모델 설정도 함께 기록하면 ROI가 바뀐 뒤 같은 픽셀 좌표가 다른 전체 영상 위치를 뜻하는 문제를 추적할 수 있습니다.

확인 단계판독과 조치
입력 프레임결과를 만든 영상과 ROI 원점을 기록합니다.
개별 관측프로브 상태와 선택 위치를 함께 확인합니다.
형상 결과찾은 점과 최종 채택점을 구분합니다.
재실행 비교새 결과와 이전 결과의 설정을 대조합니다.
