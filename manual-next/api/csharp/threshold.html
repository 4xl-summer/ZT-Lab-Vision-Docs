C# · ZImage.Threshold

C# 네이티브 이미지 객체의 두 Threshold 오버로드와 반환 결과의 Dispose 책임.

독립 HTML 페이지코드 검토 기준 2026-11-08초기 콘텐츠

공개 시그니처

C#
namespace ZVision;

public ZImage Threshold(byte t);
public ZImage Threshold(double t);

byte 오버로드는 double 처리 경로로 위임합니다. 입력 픽셀의 밝기 기준으로 비교하고 새 소유 이미지를 반환합니다.

입력·출력·오류

항목계약
t원본 픽셀 단위 임계값. double의 경우 유한해야 함
입력7종 회색 형식
출력새 Gray8 ZImage, 0 또는 255
해제반환 이미지는 using 또는 Dispose()
오류미지원 컬러, NaN/무한대 임계값·픽셀 시 ZVisionException; 해제 후 접근 시 ObjectDisposedException

C# 전체 예제

C#
using System;
using ZVision;

using var image = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var mask = image.Threshold(10.0);
Console.WriteLine(string.Join(",", mask.ToArrayGray8()));
// 0,255,255

입력 배열과 결과 배열은 관리형 배열 복사를 포함합니다. 네이티브 이미지 공유와 혼동하지 마세요.
