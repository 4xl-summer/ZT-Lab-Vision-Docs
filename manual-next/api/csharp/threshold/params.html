입력·출력·오류의 사용 조건과 결과 해석을 설명합니다.

입력·출력·오류 · 핵심 동작

t는 원본 픽셀과 같은 수치 단위로 비교하는 임계값입니다. 영상 정규화를 자동으로 수행하는 비율이 아니므로 Gray8 값 10과 0–1로 저장한 부동소수 영상의 10은 서로 다른 의미입니다. 지원 회색 형식은 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64입니다. 다른 형식은 미리 목적에 맞게 변환해야 합니다.

입력·출력·오류 · 입력과 결과

각 픽셀에 대해 입력이 t 이상이면 255, 미만이면 0이 됩니다. t가 모든 값보다 크다면 결과가 모두 0이어도 정상입니다. 반대로 모든 픽셀이 t 이상이면 결과가 모두 255입니다. 이 두 경우는 유효한 분할 결과이며 연산의 성공 여부만으로 전경이 적절한지 판단할 수 없습니다.

입력·출력·오류 · 좌표와 소유권

새 마스크는 처리 영역의 크기와 원점을 보존합니다. C#에서는 입력 영상과 결과를 각자의 수명 동안 사용하고, 모두 더 이상 필요하지 않으면 Dispose합니다. 비유한 double 임계값과 부동소수 입력의 비유한 픽셀은 오류이므로 입력 데이터의 결측 처리와 영상 형식을 먼저 확인하십시오.

임계값을 원본 표본과 같은 단위로 지정해야 한다. 정수 영상의 값 범위와 부동소수 영상의 실제 값 범위를 각각 확인하고, 동일한 숫자를 두 형식에 넣었다고 동일한 분할이 보장된다고 보지 않는다.
