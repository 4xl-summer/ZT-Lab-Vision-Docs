공개 시그니처

C#
namespace ZVision;

public ZImage Threshold(byte t);
public ZImage Threshold(double t);

byte 오버로드는 double 처리 경로로 위임합니다. 입력 픽셀의 밝기 기준으로 비교하고 새 소유 이미지를 반환합니다.

공개 시그니처 · 핵심 동작

C#의 Threshold는 지정한 밝기와 입력 픽셀을 비교해 새 Gray8 마스크를 만듭니다. byte와 double 인자를 받는 오버로드가 있으며 비교 경계는 포함됩니다. 따라서 10을 지정한 입력 [9,10,11]의 출력은 [0,255,255]입니다. 값 10 자체가 전경이라는 점이 초과 비교를 사용하는 다른 처리와 결과가 달라지는 지점입니다.

공개 시그니처 · 입력과 결과

double은 소수 임계값이 필요한 GrayF32 등에도 사용할 수 있지만 무한대나 NaN을 임계값으로 쓰면 실패합니다. 결과는 입력과 같은 객체가 아니라 별도 소유 영상이므로 원본과 결과를 각각 using으로 관리합니다. ROI에 적용하면 처리 범위는 ROI 내부이고 새 마스크는 그 원점을 유지합니다.

공개 시그니처 · 좌표와 소유권

임계값을 적용한 뒤 배열을 복사하여 검사할 때는 결과 형식이 Gray8인지 확인하십시오. 잘못된 컬러 입력이나 비유한 부동소수 픽셀을 빈 전경으로 해석하지 말고 예외로 처리해야 합니다. 이미지 전체에서 지원하는 픽셀 형식과 이 연산이 받아들이는 7종 회색 형식은 별도로 확인합니다.

반환 영상의 밝은 값은 조건을 만족한 픽셀의 표시다. 원래 밝기 자체를 유지하는 영상으로 해석하면 뒤이어 연결 성분의 전경을 정할 때 잘못된 가정을 하게 된다.
