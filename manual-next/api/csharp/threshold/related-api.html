관련 API · 핵심 동작

C#에서 밝기 기반 분할을 시작할 때는 회색 ZImage와 임계값을 준비하고 Threshold를 호출합니다. 결과는 0/255 Gray8이므로 후속 연결 성분 분석에서 전경과 배경의 의미가 분명해집니다. 입력이 색상이라면 단일 밝기로 바꾸는 과정이 먼저 필요하며, 그 변환이 색 차이를 얼마나 보존하는지 검사 목적에 맞게 평가해야 합니다.

관련 API · 입력과 결과

분할 결과가 작은 잡음으로 나뉜다면 형태학적 열기, 작은 틈이 문제라면 닫기를 검토할 수 있습니다. 둘 다 경계를 바꾸므로 커널 크기를 무조건 키우지 말고 원본과 처리 후의 면적을 비교하십시오. 선택한 성분의 개수나 면적이 필요할 때는 마스크에서 FindBlobs를 호출하고 4·8 연결성을 명시합니다.

관련 API · 좌표와 소유권

배열이 필요한 경우 ToArrayGray8은 결과의 복사본을 제공합니다. 입력, 마스크, 추가 영상은 각각 using으로 소유권을 정리하고, 값 스냅샷과 영상 핸들의 수명을 혼동하지 마십시오. 임계값과 픽셀의 숫자 단위는 원본 표현에 따라 달라집니다.

임계 처리의 출력을 연결 성분 검색에 전달하면 선택된 픽셀을 개별 물체 후보로 묶을 수 있다. 검색 단계의 연결성과 면적 필터는 임계값과 독립적으로 결과 개수를 바꾼다는 점을 함께 고려한다.

결과 마스크를 원본 위에 겹쳐 보면 분할 조건이 목표 물체를 선택했는지 쉽게 확인할 수 있다.

임계 처리 후 생성된 마스크에서 흰 픽셀은 선택 조건을 만족한 위치를 뜻합니다. 블롭 분석은 이 픽셀들을 연결 방식에 따라 물체 후보로 묶으며, 형태학은 그 전에 작은 잡음이나 틈에 영향을 줄 수 있습니다. 각 단계의 중간 마스크를 확인하면 물체 수의 변화가 생긴 지점을 찾을 수 있습니다.
