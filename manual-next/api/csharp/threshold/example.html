C# 전체 예제 · C# · ZImage.Threshold

C# 전체 예제의 사용 조건과 결과 해석을 설명합니다.

상위 목차로 돌아가기

C# 전체 예제

C#
using System;
using ZVision;

using var image = ZImage.FromGray8(3, 1, new byte[] { 9, 10, 11 });
using var mask = image.Threshold(10.0);
Console.WriteLine(string.Join(",", mask.ToArrayGray8()));
// 0,255,255

입력 배열과 결과 배열은 관리형 배열 복사를 포함합니다. 네이티브 이미지 공유와 혼동하지 마세요.

C# 전체 예제 · 핵심 동작

이 예제는 3×1 합성 Gray8 영상에서 비교 경계를 확인합니다. 입력 [9,10,11]에 10.0을 적용하면 첫 번째 값만 임계값 미만이어서 출력은 [0,255,255]입니다. 콘솔 출력의 순서는 행 우선 픽셀 순서와 같습니다. 이 작은 영상은 경계 포함 여부를 명확히 보여 주며 실제 카메라나 불량 샘플을 대신하지 않습니다.

C# 전체 예제 · 입력과 결과

소스와 결과를 각각 using으로 감싼 이유는 두 영상이 각각 관리해야 하는 네이티브 핸들이기 때문입니다. ToArrayGray8으로 얻은 관리형 배열은 영상의 보이는 픽셀을 복사한 것입니다. 그 배열에 값을 바꾸어도 원본 이미지가 바뀐다고 가정해서는 안 됩니다.

C# 전체 예제 · 좌표와 소유권

값 10을 10.1로 변경하면 입력 10은 미만이 되고 11만 전경이 됩니다. 반대로 입력과 임계값이 같은지 확인하지 않은 채 눈으로만 마스크를 보면 포함·초과 차이를 놓치기 쉽습니다. 실행 중 예외가 나면 결과 배열 검사 전에 입력 형식, 값의 유한성, 개별 영상의 해제 시점을 확인하십시오.

이 예에서는 경계값과 같은 7도 전경으로 들어간다. 결과가 예상보다 한 픽셀 많다면 임계값과 정확히 같은 원소를 따로 살펴보고 비교에 등호가 포함되는지 확인한다.
