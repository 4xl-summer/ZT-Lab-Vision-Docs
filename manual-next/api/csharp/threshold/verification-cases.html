관련 검증 사례 · 핵심 동작

임계값 검증은 경계, 저장 형식, 실패 조건을 나누어 설계합니다. 경계에서는 [9,10,11]과 T=10으로 [0,255,255]를 확인합니다. 부동소수 입력에서는 [-1,6.5,7,9]와 T=7로 [0,0,255,255]를 비교하여 소수와 음수가 정수로 먼저 잘리지 않는지 확인합니다.

관련 검증 사례 · 입력과 결과

유한한 임계값이 모든 픽셀보다 높은 경우에는 모두 0인 마스크가 정상입니다. 반면 NaN 임계값이나 지원하지 않는 컬러 형식은 오류여야 합니다. 예외를 잡아 무조건 빈 마스크로 바꾸면 잘못된 입력과 실제 무검출이 구별되지 않으므로 결과와 오류를 별도로 기록하십시오.

관련 검증 사례 · 좌표와 소유권

ROI 사례에서는 출력 픽셀뿐 아니라 원점도 함께 확인합니다. 원본을 해제하기 전후에 독립 결과를 올바르게 관리하는지, 복사한 배열은 영상과 다른 저장소인지도 호출 언어의 수명 규칙에 따라 평가합니다. 이러한 합성 검증은 비교 의미를 보증하는 데 유용하지만 설비에서의 수율이나 성능을 나타내지는 않습니다.

출력 배열은 입력 순서에 맞춰 비교한다. 특히 값 7의 위치가 255인지 살피면 경계 포함 여부를 직접 확인할 수 있으며, 다른 위치의 결과만 보고서는 이 조건을 판별할 수 없다.

값 7이 들어 있는 세 번째 위치는 비교식에 등호가 포함되는지 확인하는 핵심입니다. 네 원소의 배열 길이가 같다는 것만으로 정확성을 판단할 수 없으므로 각 위치의 입력과 출력값을 맞춰 봅니다. 실제 영상에서 결과가 반대로 보이면 물체가 배경보다 밝은지부터 확인한 뒤 필요한 전경 방향을 선택합니다.
