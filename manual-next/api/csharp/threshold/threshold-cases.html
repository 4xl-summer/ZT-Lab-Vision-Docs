값과 실패 해석 · 핵심 동작

경계값을 포함하는 비교를 검증하려면 임계값 바로 아래, 같은 값, 바로 위 값을 한 번에 넣는 것이 좋습니다. 예를 들어 T=10에서 [9,10,11]은 [0,255,255]입니다. 같은 값이 0으로 나왔다면 임계값 방향이 반대이거나 다른 API의 비교 규칙을 적용했는지 확인하십시오. 밝은 전경을 255로 만드는 정의도 함께 기록해야 합니다.

값과 실패 해석 · 입력과 결과

입력의 최대보다 높은 유한한 t는 모두 0인 결과를 만들 수 있고, 최소 이하의 t는 모두 255인 결과를 만들 수 있습니다. 이들은 실패가 아니라 정상 출력입니다. 그렇기 때문에 검사 애플리케이션은 객체가 없다는 판단과 입력 형식 오류를 구별해야 합니다. 값의 범위가 다른 Gray16과 GrayF32에 Gray8용 임계값을 그대로 재사용하면 유효한 호출에서도 분할이 무의미해질 수 있습니다.

값과 실패 해석 · 좌표와 소유권

NaN 또는 무한대인 임계값과 입력 부동소수 픽셀은 유효하지 않습니다. 문제를 재현할 때는 원본 형식, ROI 원점, 임계값, 출력 픽셀 또는 예외를 함께 기록하십시오. 배열 복사는 별도 값이고 원본 영상과 결과 영상은 각자 해제해야 합니다.

경계 사례의 의미는 두 값의 차이가 아니라 비교 방향에 있다. 6은 조건을 만족하지 않고 7은 만족하므로, 임계값을 7로 둔 배열에서는 이 두 위치의 출력이 서로 달라야 한다.
