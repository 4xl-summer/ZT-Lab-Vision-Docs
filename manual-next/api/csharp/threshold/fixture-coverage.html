실행 사례와 검증 범위 · 핵심 동작

표에 제시된 Gray8과 GrayF32 사례는 같은 임계값이 서로 다른 저장 형식에서도 원래 수치와 비교됨을 보여 줍니다. Gray8 [0,6,7,8]과 GrayF32 [-1,6.5,7,9]에 각각 7을 적용하면 기대 마스크는 모두 [0,0,255,255]입니다. 특히 7이 255가 되는 것이 경계 포함을 확인하는 부분입니다.

실행 사례와 검증 범위 · 입력과 결과

두 사례의 목적은 숫자의 스케일이 같다는 가정하에 형식별 비교 경로를 확인하는 것입니다. 부동소수 픽셀을 자동으로 0–255로 변환하는 테스트가 아닙니다. 원본 영상이 정규화된 0–1 범위라면 그 범위에서 별도의 임계값을 선택해야 하며, 음수 또는 소수 입력이 가능한 형식에서 경계값을 재검토해야 합니다.

실행 사례와 검증 범위 · 좌표와 소유권

검증 기록에서 사례 ID와 언어를 맞춰 확인하고, 정상 결과와 잘못된 인자 예외를 별도로 기록하십시오. 합성 배열은 비교와 형식 변환의 계약을 점검하지만 실제 조명 변화, 검출률 또는 처리 시간의 근거는 아닙니다. 현장 설정은 대표 영상과 독립적인 판정 기준으로 평가합니다.

정수와 부동소수 입력 사례를 함께 보더라도 모든 영상 형식과 모든 임계값을 시험한 것은 아니다. 실제 영상의 범위와 원하는 전경 방향은 별도의 검사 데이터로 확인해야 한다.
