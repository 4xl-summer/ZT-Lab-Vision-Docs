경계와 형식 선택

비교는 p ≥ T입니다. 아래 합성 입력은 경계값이 포함됨을 보여줍니다.

조건결과 또는 조치
T=10, [9,10,11][0,255,255]
유한한 T 및 7종 Gray새 Gray8 마스크
색상 이미지 또는 비유한 T/부동소수 입력오류; 입력 형식과 값을 먼저 검증

이미지 형식은 전체 14종이지만 이 연산의 입력은 그중 Gray8, Gray16, GrayI16, GrayI32, GrayU32, GrayF32, GrayF64 일곱 종입니다. ROI에서 생성된 마스크는 ROI 원점을 보존합니다. 결과는 원본을 변경하지 않는 별도 소유 이미지입니다.

경계와 형식 선택 · 핵심 동작

임계값은 전경으로 만들 밝기의 경계를 정합니다. 픽셀 p와 임계값 T에 대해 p≥T이면 255, 그렇지 않으면 0입니다. 예시 [9,10,11]에서 T=10을 사용하면 10이 경계와 같으므로 11과 함께 선택됩니다. 입력의 밝기 순서를 유지하는 정렬이나 필터가 아니라 각 픽셀을 독립적으로 비교하는 연산입니다.

경계와 형식 선택 · 입력과 결과

영상 객체는 여러 픽셀 형식을 표현할 수 있지만 이 호출은 일곱 회색 형식만 처리합니다. 색상 영상을 그대로 건네는 대신 원하는 밝기 변환을 명시하고, 부동소수 영상은 NaN과 무한대를 처리한 후 사용하십시오. 임계값이 영상의 표현 범위 안에 있어야만 하는 것은 아니지만, 범위 밖에 놓이면 대부분 전경이거나 배경이 되어 실용적인 분리가 되지 않을 수 있습니다.

경계와 형식 선택 · 좌표와 소유권

결과는 입력을 변경하지 않는 Gray8 소유 영상입니다. ROI를 사용했다면 마스크의 원점을 함께 보존하므로 후속 위치 해석에 활용할 수 있습니다. C#의 byte 오버로드와 double 오버로드 중 고를 때는 저장 형식 이름보다 원하는 비교 수치의 정밀도를 먼저 고려하십시오.

C#에서 경계와 결과 관리하기

Threshold(byte)는 같은 값을 double로 넘겨 Threshold(double)을 호출합니다. 정수 기준 7에서는 입력 6, 7, 8이 각각 0, 255, 255가 됩니다. 소수 기준 7.5를 쓰면 같은 입력의 결과는 0, 0, 255이므로 정수로 반올림한 뒤 비교하는 것과 구별해야 합니다. 이는 비교 규칙을 보여 주는 손계산입니다.

반환된 마스크는 입력과 별도의 이미지입니다. 원본을 다른 계산에도 사용할 수 있고, 마스크는 사용이 끝난 뒤 별도로 Dispose하거나 using 범위에서 관리합니다. 컬러 입력이나 유한하지 않은 값이 실패하면 결과를 전경이 없는 마스크로 해석하지 말고 먼저 입력 형식과 임계값을 확인합니다. ROI의 결과 좌표를 원본의 다른 측정값과 비교할 때는 보존된 원점도 함께 고려합니다.
