첫 영상 처리 흐름

입력에서 마스크와 측정 결과까지 자료형과 결과를 따라갑니다.

그림을 읽는 순서

  1. 임계값과 같은 10도 전경이다.
  2. 블롭 결과의 면적은 연결된 전경 픽셀 수다.

동작의 원리

p ≥ T이면 255, 아니면 0이며 연결된 전경 픽셀을 성분으로 묶는다.

입력과 결과의 의미

비교는 p ≥ T 입니다. 아래 합성 입력은 경계값이 포함됨을 보여줍니다.

경계와 형식 선택 · Threshold — 임계값 분할에서 설정과 실제 API를 이어서 확인할 수 있습니다.

Blob 면적은 성분을 이루는 비영 픽셀 개수입니다. 중심은 전경 픽셀 중심 좌표를 각각 평균한 값이며, 외접 사각형은 그 성분을 모두 포함하는 가장 작은 축 정렬 경계입니다. 사각형 내부가 모두 전경이 아닐 수 있으므로 면적과 사각형 폭·높이의 곱은 서로 다른 값입니다.

공개 Blob 값의 해석 · Blob Analysis · 연결 영역에서 설정과 실제 API를 이어서 확인할 수 있습니다.

적용할 때 확인할 점

입력에서 마스크와 측정 결과까지 자료형과 결과를 따라갑니다. 그림의 화살표는 여기에서 설명하는 데이터 또는 제어 관계를 나타냅니다. 실제 호출에서 사용할 수 있는 입력 형식과 반환 객체는 연결된 API 문서의 선언과 파라미터 표를 확인하세요.
