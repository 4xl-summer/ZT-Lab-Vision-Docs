쿼리 구성과 실행

연산을 구성하고 실행 결과를 읽는 순서를 보여 줍니다.

그림을 읽는 순서

  1. 결과 객체와 영상의 소유 및 해제 규칙을 확인합니다.
  2. 언어별 실행 API와 결과 타입은 연결된 설명을 따릅니다.

동작의 원리

쿼리의 구성과 결과의 획득은 구분하여 이해합니다.

입력과 결과의 의미

ZImage 의 직접 이미지 변환은 호출 즉시 계산하지만, ImageQuery 는 실행할 작업을 축적합니다. query() 가 입력 이미지 저장소를 공유하며 threshold() 등의 연산을 추가해도, 실제 픽셀 처리는 execute() 에서 발생합니다.

연산 계획과 실행을 구분한다 · ImageQuery · 지연 실행에서 설정과 실제 API를 이어서 확인할 수 있습니다.

적용할 때 확인할 점

연산을 구성하고 실행 결과를 읽는 순서를 보여 줍니다. 그림의 화살표는 여기에서 설명하는 데이터 또는 제어 관계를 나타냅니다. 실제 호출에서 사용할 수 있는 입력 형식과 반환 객체는 연결된 API 문서의 선언과 파라미터 표를 확인하세요.
