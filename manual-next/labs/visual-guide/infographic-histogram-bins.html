히스토그램 읽기

값을 구간에 배치해 분포를 확인합니다.

그림을 읽는 순서

  1. 예시는 구간 [0,1), [1,2), [2,3), [3,4)로 계산한 합성 예입니다.
  2. 실제 함수의 범위와 경계 조건은 해당 API 계약을 따릅니다.

동작의 원리

히스토그램은 밝기 값의 공간 위치가 아니라 구간별 빈도입니다.

입력과 결과의 의미

zvision.HistogramSpec : 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._naming_preprocessing.HistogramSpec .

Python API · HistogramSpec에서 설정과 실제 API를 이어서 확인할 수 있습니다.

적용할 때 확인할 점

값을 구간에 배치해 분포를 확인합니다. 그림의 화살표는 여기에서 설명하는 데이터 또는 제어 관계를 나타냅니다. 실제 호출에서 사용할 수 있는 입력 형식과 반환 객체는 연결된 API 문서의 선언과 파라미터 표를 확인하세요.
