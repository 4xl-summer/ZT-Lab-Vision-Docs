AI 추론 좌표

모델 입력과 출력 좌표의 기준을 확인합니다.

그림을 읽는 순서

  1. 모델마다 입력 형상과 출력 의미가 다릅니다.
  2. 점수만으로 물리 치수 또는 합격 여부를 확정하지 않습니다.

동작의 원리

모델 전처리의 크기 변환과 원본 좌표 복원은 별도 단계입니다.

입력과 결과의 의미

분류는 logits에 softmax를 적용해 scores와 최대 class_id를 제공합니다. 검출의 각 모델 출력 행은 [x_min,y_min,x_max,y_max,score,class_id]이며 모델 입력 좌표를 ROI 범위로 되돌립니다. 결과 좌표는 전달한 이미지 기준입니다. 점수와 같은 클래스의 IoU 기준으로 후보를 걸러내며 빈 목록은 검출이 없다는 결과입니다. 형식이나 모델 오류와 구별하세요.

출력의 좌표와 점수 · AI 엔진과 결과에서 설정과 실제 API를 이어서 확인할 수 있습니다.

적용할 때 확인할 점

모델 입력과 출력 좌표의 기준을 확인합니다. 그림의 화살표는 여기에서 설명하는 데이터 또는 제어 관계를 나타냅니다. 실제 호출에서 사용할 수 있는 입력 형식과 반환 객체는 연결된 API 문서의 선언과 파라미터 표를 확인하세요.
