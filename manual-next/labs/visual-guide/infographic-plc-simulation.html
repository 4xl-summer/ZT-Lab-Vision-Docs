PLC 요청과 결과 시뮬레이션

요청 ID로 결과를 연결하고 확인하며, Poll의 시간 초과와 Reset을 구분합니다.

그림을 읽는 순서

  1. Request는 0이 아닌 ID와 결과 코드 0을 사용하며 Publish와 Ack는 현재 요청 ID에 일치해야 합니다.
  2. 시간 초과는 Poll에서 판정하며 Waiting 또는 ResultReady에서 제한 시간 이상이면 Faulted가 됩니다. Reset은 Faulted에서만 허용됩니다.
  3. 호출자가 전달하는 시간은 나노초이고 감소할 수 없습니다. 실제 PLC 통신이나 설비 인터록 검증은 수행하지 않습니다.

동작의 원리

요청과 결과를 같은 요청 ID로 묶고, 명령으로 상태를 전이하는 결정적 시뮬레이터입니다.

입력과 결과의 의미

zvision.SimulatedPlc : 패키지 __all__ 공개 이름입니다. 선언 출처: zvision._acquisition.SimulatedPlc .

Python API · SimulatedPlc에서 설정과 실제 API를 이어서 확인할 수 있습니다.

적용할 때 확인할 점

요청 ID로 결과를 연결하고 확인하며, Poll의 시간 초과와 Reset을 구분합니다. 그림의 화살표는 여기에서 설명하는 데이터 또는 제어 관계를 나타냅니다. 실제 호출에서 사용할 수 있는 입력 형식과 반환 객체는 연결된 API 문서의 선언과 파라미터 표를 확인하세요.
