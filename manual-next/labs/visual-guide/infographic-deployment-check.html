실행 환경과 배포

개발 환경에서 운영 환경으로 넘어갈 때 확인할 항목입니다.

그림을 읽는 순서

  1. 예제 실행 성공은 설비 환경의 운영 검증을 대신하지 않습니다.
  2. 장치 드라이버와 모델 파일은 사용 구성에 맞춰 준비합니다.

동작의 원리

영상 파일 경로와 런타임 의존성은 배포 환경에서 다시 확인해야 합니다.

입력과 결과의 의미

ZImage::load는 시그니처 기반 디코딩을 사용하고 save는 확장자로 인코더를 선택합니다. load_tiff_page는 0부터 시작하는 페이지를 읽습니다.

개념과 사용 흐름 · 이미지 파일 Load · Save에서 설정과 실제 API를 이어서 확인할 수 있습니다.

적용할 때 확인할 점

개발 환경에서 운영 환경으로 넘어갈 때 확인할 항목입니다. 그림의 화살표는 여기에서 설명하는 데이터 또는 제어 관계를 나타냅니다. 실제 호출에서 사용할 수 있는 입력 형식과 반환 객체는 연결된 API 문서의 선언과 파라미터 표를 확인하세요.
