동작의 원리

객체 소유권과 데이터 저장소 공유는 다른 관계입니다.

입력과 결과의 의미

수명 매트릭스는 객체마다 무엇을 소유하는지 나누어 읽기 위한 기준입니다. 영상, 매칭 모델, Query 빌더와 실행 결과는 네이티브 자원을 보유할 수 있으며 관리형 코드에서는 닫기 또는 Dispose가 필요합니다. 임계값 결과처럼 새로 받은 영상도 원본을 닫는 것과 별도로 정리해야 합니다. ROI와 Share는 새로운 핸들이면서 저장소를 공유한다는 두 사실을 함께 기억하세요.

2. 수명 관리 매트릭스 · 객체 수명과 메모리 관리에서 설정과 실제 API를 이어서 확인할 수 있습니다.

적용할 때 확인할 점

원본과 결과의 사용 범위를 구분합니다. 그림의 화살표는 여기에서 설명하는 데이터 또는 제어 관계를 나타냅니다. 실제 호출에서 사용할 수 있는 입력 형식과 반환 객체는 연결된 API 문서의 선언과 파라미터 표를 확인하세요.
